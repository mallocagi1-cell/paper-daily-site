UniRank: Unified List-wise Reranking via Confidence-Ordered Denoising

针对生成式列表重排中自回归 (AR) 容易误差累积、非自回归 (NAR) 又弱化候选间交互的两难，提出 UniRank：一个统一的列表重排框架，将双向 slate 建模嵌入到迭代去噪过程，并通过推理时变体在 AR 与 NAR 之间灵活切换。训练采用 confidence-ordered denoising，从高置信槽位向低置信槽位逐步揭示并精修。在多个公开和工业数据集上 UniRank 相比 AR/NAR 基线显著提升排序效果，统一架构带来更强的位置间交互建模能力。

UxSID: Semantic-Aware User Interests Modeling for Ultra-Long Sequence

Kuaishou📖 深度解读 · 10 分钟 →

针对超长用户行为序列建模的'效率 vs. 效果'两难，UxSID 提出'语义组共享兴趣记忆'这第三条路径：用 Semantic IDs (SIDs) 把语义相近的 item 聚合，配合双层注意力 (item-to-SID + SID-to-target)，在不做 item-specific 检索的前提下捕捉 target-aware 偏好。端到端架构在大型广告 A/B 实验中取得 SOTA 效果并带来 0.337% 营收提升，证明该路径在工业部署上的可行性。

INSIGHTultra-long sequence 建模长期被 SIM、ETA、TWIN 等 item-search 路线主导，UxSID 把 SID 当作'兴趣分组锚点'，用语义压缩替代显式检索，省去了检索阶段的延迟和复杂度。对推荐排序团队的启示：当 SID 已经在召回/生成式推荐链路落地后，可顺势用 SID 桥接超长序列建模，把不同模块复用的语义空间统一起来，降低系统复杂度。

Counterfactual Multi-task Learning for Delayed Conversion Modeling in E-commerce Sales Pre-Promotion

电商大促前用户加购意愿强但即时转化少，导致预热期 CVR 分布严重偏移，现有延迟反馈模型难以覆盖。论文提出一个反事实多任务学习框架：把'用户是否会在预热期内转化'与'用户是否会在大促日转化'拆分为两个相关任务，并用反事实推断显式建模'若无促销折扣'的对照分布，缓解前后两期的样本选择偏差。在某电商大促数据集上对比 ESMM、DEFER 等基线，预热期 CVR AUC 取得明显提升。

INSIGHT把'预热期延迟转化'抽象成多任务 + 反事实问题，是对经典 ESMM 框架的精准补强。对大促/秒杀/团购等强促销场景，可以借鉴该范式重新设计 CVR 链路：用反事实分支显式约束'促销折扣的因果效应'，避免模型把预热期的低 CVR 当作 negative。落地时只需把现有 ESMM tower 复制一份做促销反事实分支，对线上结构改动小。

A General Framework for Multimodal LLM-Based Multimedia Understanding in Large-Scale Recommendation Systems

传统推荐系统对多媒体物料的高维语义信号利用不足，而 MM-LLM 又难以满足工业级延迟约束。论文提出三段式架构：内容理解 (LLaMA2 生成描述性 caption) → 表征抽取 (caption 转 token 化离散特征) → 流水线集成 (作为常规类别特征接入 ranking 模型)。该方案离线 AUC 提升 0.35%，在线指标提升 0.02%，已在大规模工业推荐场景部署。

INSIGHT把 MM-LLM 当作'特征生产管道'而非'在线推理模型'，是大模型在搜推落地的最务实路径：caption 离线产出 → token 化 → 常规 ID feature 入排序模型，几乎不增加在线延迟。对短视频/UGC 社区有直接借鉴价值——可以用 MM-LLM 把封面图/首帧/标题统一生成结构化 caption，接入现有 ranking 链路，提升冷启动和长尾内容理解。

LASAR: Latent Adaptive Semantic Aligned Reasoning for Generative Recommendation

BUAABaidu

生成式推荐中显式 CoT token-by-token 输出延迟过高，难以上线。LASAR 把 CoT 推理搬到隐空间：先用 SFT 让模型在 Semantic ID (SID) 与 latent reasoning 之间对齐 (解决 SID 缺先验语义的问题)；再用 RL 学习自适应推理深度，避免全局固定步数的次优。三大创新：SID→latent 语义对齐、推理链监督防止表征漂移、自适应推理深度。在多个公开推荐数据集上相比显式 CoT 大幅降低推理延迟同时保持精度。

INSIGHT把 CoT 由 token 空间搬到 latent 空间，是生成式推荐降低推理延迟的关键工程方向。但 SID 缺乏预训练语义是核心瓶颈，LASAR 的 SFT 对齐 + RL 自适应深度提供了可复用的训练配方。对正在落地 TIGER/HSTU 路线的团队来说，可以借鉴 latent reasoning + 自适应深度的设计，避免上线时 CoT 长度难以控制的问题。

Every Preference Has Its Strength: Injecting Ordinal Semantics into LLM-Based Recommenders

KAIST

现有 CF-LLM 框架把显式评分坍缩为 implicit 或 positive-only 反馈，丢失偏好强度信息。论文提出 Ordinal Semantic Anchoring (OSA)：把 1–5 星评分等序数偏好级别表示为数字文本 token，用其 embedding 作为'语义锚点'对齐 user-item 交互表征到 LLM 隐空间，从而保留偏好强度。在多个评分数据集上相比丢弃 ordinal 信号的 baseline 取得稳定提升。

INSIGHTLLM-based 推荐器普遍只用 positive feedback (点击/购买)，而忽略了评分系统提供的 ordinal 强度信息，OSA 用数字 token 当作语义锚点是一个轻量级补强思路。对评论/打分类社区 (大众点评、豆瓣) 有直接价值——把用户打分作为 ordinal token 注入 prompt，可显著改善 LLM 推荐对'强偏好 vs. 弱偏好'的区分能力。

Jiwon Jeong, Donghee Han, Sungrae Hong, Woosung Kang, Mun Yong Yi

UserGPT Technical Report

传统判别式 user profiling 依赖手工特征工程预测离散属性，难以泛化到长尾行为。论文提出 UserGPT 生成式范式：用 LLM 把长且嘈杂的用户行为历史摘要成连贯叙事，捕捉用户兴趣演化。框架包含属性生成与摘要生成两个任务，并引入 User Behavior Simulation Engine 自动产出复杂用户轨迹解决真实数据稀缺。实验显示即使强 LLM 在复杂隐式个性化推理上仍有限，但 UserGPT 框架明显改善 persona understanding 任务表现。

INSIGHT生成式 user profile 是把'用户画像'从'属性集合'升级为'可读叙事'的关键路径，对内容平台 (社区/电商) 价值很大——可以替代或补强传统标签体系，给下游推荐/搜索/广告模型注入更丰富的用户上下文。User Behavior Simulation Engine 也提供了'合成数据训练画像模型'的可复用配方，缓解真实长行为序列采集成本高的痛点。

Brownian Bridge Diffusion for Sequential Recommendation

USTCNUS

现有扩散式序列推荐沿用'item ↔ 噪声'范式，从高斯噪声出发条件去噪重建目标 item，但额外的噪声重建负担会让模型分心于学用户偏好。论文提出'偏好桥接'设计：用 Brownian Bridge 直接构造'item ↔ 历史'的扩散过程，去掉中间噪声态，让模型专注于历史→目标的偏好转移。多个公开数据集上相比 DiffuRec、DreamRec 等扩散推荐 baseline 取得稳定提升。

INSIGHT扩散模型在推荐中的关键问题是'噪声重建 vs. 偏好建模'目标错配，Brownian Bridge 给出了直接桥接两端的优雅方案。对生成式推荐线路的启示：未必所有方法都要照搬图像扩散的'item↔noise'公式，可以根据推荐任务结构 (历史→目标) 重新设计扩散过程，更好对齐目标。

Can Recommender Systems Teach Themselves? A Recursive Self-Improving Framework with Fidelity Control

USTCHuawei

用户交互稀疏导致推荐模型优化空间崎岖、泛化差。论文提出 RSIR 递归自提升框架：当前模型自生成合理交互序列，再用'保真度质量控制'过滤出与用户偏好流形一致的样本，扩展训练集训练继任模型，闭环迭代。理论分析证明 RSIR 等价于一种数据驱动的隐式正则，平滑优化曲面。实验在多个推荐基准上相比常规训练取得稳定增益。

INSIGHTself-improving 在 LLM 端已被广泛验证，RSIR 把这个范式带到推荐场景并加上 fidelity gate，缓解了'模型自吃自合成数据导致退化'的核心问题。对数据稀缺/冷启场景 (新业务、新品类、长尾用户) 价值明显——可以在不依赖外部教师模型/外部数据的前提下显著提升泛化，部署成本相对低。

TextBridgeGNN: Pre-training Graph Neural Network for Cross-Domain Recommendation via Text-Guided Transfer

BUAA

GNN 推荐模型的 ID embedding 与具体域绑定，跨域迁移困难，且异构域间图结构差异大。论文提出 TextBridgeGNN：用文本作为'语义桥'连接不同域，通过多层图传播把域无关的文本知识注入到 GNN 表征中。预训练-微调框架在多对跨域推荐任务上相比 ID-based 与纯文本 baseline 都取得明显提升，验证了文本桥接策略的有效性。

INSIGHT跨域推荐的根本难点是 ID embedding 不可迁移，TextBridgeGNN 把 'item 文本描述' 当成统一的语义底座，用文本桥接让 GNN 的结构信息可跨域复用。对生态内多业务线 (主站 / 短视频 / 商品 / 内容) 共享 user/item 表征有直接借鉴价值——可以基于商品/内容文本预训练一个底座 GNN，再到各下游业务做轻量 fine-tune。

Yiwen Chen, Yiqing Wu, Huishi Luo, Fuzhen Zhuang, Deqing Wang, Zhao Zhang
