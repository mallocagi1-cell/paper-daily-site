CCD-Level and Load-Aware Thread Orchestration for In-Memory Vector ANNS on Multi-Core CPUs

向量近邻搜索 (ANNS) 是搜索/推荐/广告链路的核心组件，但在 CCD 多核 CPU 上简单堆核数并不能线性扩展。论文基于真实在线流量分析发现访问局部性高但缓存利用率低，提出 CCD-Level 感知的线程编排和负载感知调度，将查询绑定到合适的 CCD 以提升 cache 命中。在生产环境部署中显著提升单机吞吐与延迟，可直接复用于 UGC 搜索的向量召回服务。

Rethinking Agentic Search with Pi-Serini: Is Lexical Retrieval Sufficient?

University of Waterloo

在 deep research / agentic search 浪潮下，作者重新检视 LLM 智能体下 BM25 是否仍然够用。提出 Pi-Serini 搜索智能体，配备检索、浏览、阅读三类工具，将 BM25 与前沿 LLM 组合。在 BrowseComp-Plus 上，Pi-Serini+gpt-5.5 取得 83.1% 回答准确率与 94.7% 证据召回，超过基于密集检索的已有搜索智能体；BM25 参数微调单项即带来 +18% 准确率与 +11% 召回提升。

INSIGHT当 LLM 推理与工具调用足够强时，召回侧用 BM25 + 足够深度即可，无需上重型密集检索。这一结论对社区搜索 agentic 化路线有直接价值：先用 BM25 + 深度召回 + LLM 重排/校验，可在工程复杂度极低的情况下逼近密集检索方案，留出预算投入到工具调用与 query 改写。

Tz-Huan Hsu, Jheng-Hong Yang, Jimmy Lin

03 4.35

NumColBERT: Non-Intrusive Numeracy Injection for Late-Interaction Retrieval Models

University of Tsukuba

密集检索器对带数值条件的 query (如 "R&D 投入超过 10 亿美元") 表现差。已有方案把 query 拆成文本/数值两路并分别打分，破坏了 ColBERT 等 late-interaction 模型的部署管线。论文提出 NumColBERT，在推理期对 token embedding 做非侵入式数值增强，完全保留 ColBERT 原索引与 MaxSim 评分逻辑，因此现有 indexing/serving 生态可直接复用，在数值敏感场景显著提升 retrieval 指标。

INSIGHT对线上检索服务最友好的改进方式是"零侵入"：保持索引与评分函数不变、只在 token 表示层注入新信号。这一思路对社区搜索的数值/时间/价格类 query 同样适用——例如 "近一周"、"3000 元以下"，可在不重建索引的情况下显著提升相关性。

Haruki Fujimaki, Makoto P. Kato

A Voronoi Cell Formulation for Principled Token Pruning in Late-Interaction Retrieval Models

SSorbonneCNRS

ColBERT 等晚交互模型需存储每个 token 的稠密向量，索引体积巨大。已有 token pruning 方法基于经验/统计指标，缺乏理论依据。论文用超空间几何视角，把 token 剪枝建模为 Voronoi cell 估计问题：每个 token 的影响力由其 Voronoi 区域度量。实验证明该方法在显著压缩索引的同时基本无损检索质量，并可用作分析 token 级行为的诊断工具。

INSIGHT晚交互检索的实用化瓶颈是索引体积，而非纯精度。把 token 重要性建模为它在 embedding 空间所覆盖的几何区域，是一个比启发式更可解释、可推广的剪枝准则。对社区短文本检索，这套思路可显著降低 ColBERT-style 索引存储成本，使其在中小型场景下变得真正可部署。

Yash Kankanampati, Yuxuan Zong, Nadi Tomeh, Benjamin Piwowarski, Joseph Le Roux

Enhancing Healthcare Search Intent Recognition with Query Representation Learning and Session Context

AmazonEmory University

医疗搜索 query 意图模糊、标注稀缺、多意图共存。已有方法基于点击聚合学 pairwise query 表示，但全局统计会丢失 session 内意图差异。论文提出在 query 表示学习中显式注入 session 上下文，针对单 query 多意图问题改进对比学习目标，从而捕捉 session 内动态意图变化，意图识别准确率在内部医疗搜索数据上较 baseline 显著提升。

INSIGHT短 query 意图判断必须考虑 session 内序列上下文，而非把 query 当成无状态字符串。对 UGC 社区搜索价值很高：用户连续搜索的多个短 query 往往构成一个完整意图链，用 session-aware query 表示能直接改善排序和相关性，同时较 LLM 改写方案延迟更可控。

06 3.55

ReCoVR: Closing the Loop in Interactive Composed Video Retrieval

University of QueenslandCSIRO

传统 composed video retrieval 只支持单轮交互。论文将其扩展为多轮交互式检索，并指出现有方法的两个结构缺陷：单一检索通道与开环设计 (只消费用户反馈但不诊断检索轨迹是否漂移)。提出 ReCoVR (Reflexive Composed Video Retrieval) 双通道架构，把检索历史作为诊断证据，自反式判断是否需要切换检索策略，多个 benchmark 上显著优于现有交互式检索基线。

INSIGHT多轮搜索的核心难点是"自诊断"——系统要知道自己当前的检索轨迹是否在向用户意图收敛。这对社区搜索的 query 改写、相关推荐、连续刷帖流场景有启发：除了消费用户反馈，还要建模检索状态本身的健康度，避免陷入死循环或漂移。

Bingqing Zhang, Yi Zhang, Zhuo Cao, Yang Li, Xue Li, Jiajun Liu, Sen Wang

Qwen Goes Brrr: Off-the-Shelf RAG for Ukrainian Multi-Domain Document Understanding

在 UNLP 多领域 PDF 文档问答任务上，作者用纯开源 Qwen3 系列搭建 RAG pipeline：Qwen3-Embedding-8B 做召回、微调后的 Qwen3-Reranker-8B 做重排 (重排联合考虑 question 与候选答案选项)、Qwen3-32B 做受限答案生成。重排把 Recall@1 从 0.6957 提到 0.7935，top-2 重排后答案准确率从 0.9348 提到 0.9674，最终私榜 0.9598。

INSIGHT高质量 RAG 的关键不在花式架构，而在三件事：上下文分块策略、问题+候选答案联合重排、限制生成只能从重排后的少量证据中选。对社区搜索，问答类场景可借鉴这套"开源大模型 + Reranker 联合条件"配方，工程实现简单且效果非常稳，是当下中文/多语 RAG 的可复用模板。

Anton Bazdyrev, Ivan Bashtovyi, Ivan Havlytskyi, Oleksandr Kharytonov, Artur Khodakovskyi

Attention Grounded Enhancement for Visual Document Retrieval

CAS

视觉文档检索目前主流是 screenshot 编码 + fine-grained late-interaction，但训练只用粗粒度全局相关性标签，模型缺乏"哪块区域支持匹配"的监督，难处理非抽取式 query。论文提出 AGREE 框架，用多模态大模型 (MLLM) 的跨模态注意力作为代理监督，引导 retriever 识别相关文档区域，从而提升细粒度相关性建模，多个视觉文档 retrieval benchmark 提升明显。

INSIGHT在缺乏区域级人工标注的场景下，MLLM 的注意力可以充当"伪标注"提供细粒度监督。对社区搜索的多模态贴文/图文卡片检索具有启发性：可用现成 MLLM 离线生成区域热度，再蒸馏到轻量检索器，在不增加在线开销的前提下提升复杂 query 的相关性。

Wanqing Cui, Wei Huang, Yazhi Guo, Yibo Hu, Meiguang Jin, Junfeng Ma, Keping Bi

ASTRA-QA: A Benchmark for Abstract Question Answering over Documents

CUHK-Shenzhen

抽象式问答需要把分散在长文档/跨文档的信息综合成连贯回答，但现有 benchmark 缺乏稳定参考答案、依赖粗粒度相似度。论文构建 ASTRA-QA 基准，包含 869 个学术与新闻文档抽象问答实例，覆盖 5 类抽象问题与 3 种受控检索范围。每条样本配有答案主题集合、被排除主题与对齐证据，从覆盖度与无关内容两个维度评估生成答案。

INSIGHTRAG 评测正在从"答案字符串相似度"走向"主题覆盖度+证据对齐"。这对社区搜索内部评估很关键：传统点击/CTR 难以衡量 LLM 生成回答的可信度，而 ASTRA-QA 这种主题级标注 + 证据对齐评估方案可直接借鉴到内部 RAG 评测，减少 LLM-as-judge 的不稳定性。

Shu Wang, Shansong Zhou, Xinyang Wang, Shiwei Wang, Hulong Wu, Yixiang Fang

H-MAPS: Hierarchical Memory-Augmented Proactive Search Assistant for Scientific Literature

University of Tsukuba

主动 (proactive) 检索系统通常只看屏幕文本，忽略用户背景与意图，存在上下文歧义。H-MAPS 用三层层级记忆 (用户背景、阅读历史、即时焦点)，在用户隐式阅读行为触发下，把潜在信息需求显式化为自然语言问题，再做本地神经检索保护隐私。同一篇论文，NLP 与 HCI 两个用户得到的推荐文献完全不同，体现 persona-aware 主动检索能力。

INSIGHT主动式搜索的关键是"意图显式化"——把隐式行为编码成可被检索系统理解的问题，再走标准 retrieval。对社区搜索/Feed 流有启发：长用户行为序列可以离线浓缩成层级化记忆 (兴趣偏好、近期关注、当下意图)，作为 query 改写或 retrieval rerank 的额外条件，提升个性化相关性。

Koji Nishikawa, Makoto P. Kato
