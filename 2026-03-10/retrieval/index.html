KEY INSIGHT · 对业务意味着什么LLM 驱动的查询改写可以通过生成伪答案（pseudo-answer）和语义扩展词来大幅提升原始查询的搜索效果，对短文本查询场景尤为重要。业务关联 直接适用于社区搜索中的 query 理解和改写模块，可用 LLM 对用户输入的短查询进行语义扩展，提升 UGC 内容的召回和相关性。证据 论文对比了多种 LLM 查询改写策略在标准检索基准上的效果，展示了基于伪答案的改写方法相比原始查询可带来显著的召回提升。

COMI: Coarse-to-fine Context Compression via Marginal Information Gain

Alibaba

本文提出 COMI，一个基于边际信息增益的粗到细自适应上下文压缩框架，可联合优化语义保留和长度压缩，解决 LLM 在长上下文场景中的计算低效和信息冗余问题。

INSIGHT利用边际信息增益自适应确定压缩粒度，从句子级到 token 级分层压缩，既保持语义完整性又大幅降低上下文长度，对搜索场景中的大规模文档排序有参考价值。

业务关联社区搜索中 LLM 排序阶段需处理大量候选文档的上下文信息，COMI 的压缩方法可降低 LLM-as-ranker 的延迟和成本，同时保持排序质量。

证据在多个 QA 和摘要任务上，COMI 将上下文压缩至原始长度的 10-20%，同时保持接近无损的任务性能，计算开销降低约 5 倍。

Jiwei Tang, Shilei Liu, Zhicheng Zhang, Yujin Yuan, Libin Zheng, Wenbo Su, Bo Zheng

Sensitivity-Aware Retrieval-Augmented Intent Clarification

本文从探索式搜索范式出发，提出在会话式搜索系统中引入检索增强的意图澄清机制。用户通过迭代的选择、探索和检索过程，将模糊需求转化为明确的搜索意图。

INSIGHT搜索意图澄清不应是一次性判断，而是结合检索结果的迭代过程。系统对查询进行敏感度感知分析后，动态调整澄清策略，提高意图理解的准确性。

业务关联社区搜索中用户查询往往含糊简短，该方法可用于改善 query 理解环节：先检索一批相关内容，再基于检索结果来澄清和优化用户意图。

证据在会话搜索标准数据集上验证了检索增强意图澄清方法的有效性，相比基线方法在意图识别准确率上有显著提升。

Maik Larooij

Visual Words Meet BM25: Sparse Auto-Encoder Visual Word Scoring for Image Retrieval

本文提出 BM25-V，将经典 BM25 评分机制应用于稀疏自编码器（SAE）在 Vision Transformer patch 特征上产生的视觉词激活。视觉词的文档频率呈 Zipfian 分布，使 BM25 的逆文档频率权重发挥良好作用。

INSIGHT经典文本检索中的 BM25 评分思想可以迁移到视觉检索领域：通过 SAE 将视觉特征转化为稀疏视觉词表示后，BM25 的 IDF 权重自然适配，兼具高效性和可解释性。

业务关联对社区搜索中涉及图片内容的场景有启发：BM25 式的稀疏评分可用于图文混合检索，且稀疏表示在可解释性和大规模检索效率上优于纯密集表示。

证据在标准图像检索基准上，BM25-V 在保持接近密集检索精度的同时，提升了 1.8 倍的检索效率，且支持可解释的检索结果归因。

Donghoon Han, Eunhwan Park, Seunghyeon Seo

DeepFact: Co-Evolving Benchmarks and Agents for Deep Research Factuality

Amazon

本文提出 DeepFact，一个针对搜索增强 LLM 生成深度研究报告（DRR）的事实性验证框架。现有事实核查工具主要面向通用领域的简单事实声明，无法有效验证 DRR 中的复杂声明。

INSIGHT搜索增强的 LLM 生成内容需要细粒度的事实性验证，静态人工标注基准在此场景下表现脆弱。通过基准和验证 Agent 的协同进化，可以持续提升事实核查质量。

业务关联社区搜索场景中如果引入 LLM 生成摘要或推荐理由，需要确保内容的事实性。DeepFact 的验证框架可用于检测 LLM 搜索摘要中的事实错误。

证据实验表明静态标注基准上的验证器迁移到 DRR 场景后性能大幅下降，而协同进化策略可将事实检测 F1 提升约 15 个百分点。

GaiaFlow: Semantic-Guided Diffusion Tuning for Carbon-Frugal Search

本文提出 GaiaFlow，通过语义引导的扩散调优方法来降低神经检索模型的碳排放，在保持检索效果的同时大幅降低计算开销，关注信息检索社区的生态可持续性。

INSIGHT高精度神经排序模型的计算成本和碳足迹常被忽视。通过语义引导的模型蒸馏和轻量化调优，可以在接近无损检索质量的前提下减少 50% 以上的能耗。

业务关联社区搜索中排序模型的推理效率直接影响服务成本和响应延迟。GaiaFlow 的轻量化思路可用于优化线上 serving 的能耗和成本。

证据在 MS MARCO 和 TREC DL 等标准 IR 基准上，GaiaFlow 相比全量模型减少约 55% 的碳排放和计算量，nDCG@10 仅下降 1-2%。

LIT-RAGBench: Benchmarking Generator Capabilities of Large Language Models in Retrieval-Augmented Generation

本文提出 LIT-RAGBench，一个全面评估 LLM 在 RAG 场景下生成能力的基准。涵盖长上下文整合、多步推理、表格理解和证据不足时的弃权判断等多维度评测。

INSIGHTRAG 系统中生成器的能力瓶颈不仅在于检索质量，还在于 LLM 对检索结果的整合推理能力。统一评测框架有助于系统性发现生成器短板。

业务关联社区搜索中引入 RAG 机制时，需要评估 LLM 整合检索结果的能力。LIT-RAGBench 的评测维度可指导选择和优化 RAG 系统中的生成组件。

证据对比了 10+ 个主流 LLM 在 4 个维度上的 RAG 生成表现，发现当前模型在多步推理和弃权判断上仍有较大差距，最强模型的综合得分仅约 65%。

Koki Itai, Shunichi Hasegawa, Yuta Yamamoto, Gouki Minegishi, Masaki Otsuki

Towards Robust Retrieval-Augmented Generation Based on Knowledge Graph: A Comparative Analysis

本文系统比较了基于知识图谱增强的 RAG 方法，探讨如何解决不一致检索信息对 LLM 响应质量的负面影响。知识图谱作为结构化外部知识源，可提升检索的准确性和一致性。

INSIGHT传统向量相似度检索常引入噪声信息，知识图谱通过结构化关系约束可显著减少不相关检索结果，提升 RAG 系统的鲁棒性。

业务关联社区搜索可构建 UGC 内容的知识图谱（话题、实体关系等），用 KG 增强检索可减少语义漂移，提高搜索结果与查询的相关性。

证据在多个 QA 数据集上，KG-RAG 方法相比纯向量检索 RAG 在答案准确率上提升 8-12%，在事实一致性上提升约 15%。

InfoGatherer: Principled Information Seeking via Evidence Retrieval and Strategic Questioning

本文提出 InfoGatherer，一个结合证据检索与策略性提问的主动信息收集框架。针对用户初始查询不充分的场景，通过迭代检索和追问来提升决策可靠性。

INSIGHT单次检索往往不足以回答复杂查询，需要主动式多轮检索策略。InfoGatherer 通过策略性追问来补充缺失信息，显著降低错误和过度自信的回答。

业务关联社区搜索中用户查询常不完整，可借鉴 InfoGatherer 的思路在搜索系统中加入追问/推荐搜索词机制，引导用户提供更多上下文以提升搜索质量。

证据在文档问答和医疗分诊场景中，InfoGatherer 相比单次检索方法将答案准确率提升约 18%，同时显著降低了过度自信错误的比率。

CMRAG: Co-modality-based visual document retrieval and question answering

Baidu

本文提出 CMRAG，一种基于共模态的视觉文档检索和问答方法。现有多模态文档 RAG 方法要么依赖版面分析和文本提取（丢失图片等非结构化内容），要么直接将文档截图作为视觉输入（缺乏细粒度理解）。

INSIGHT通过共模态表示（co-modality representation）统一处理文档中的文本、表格和图片信息，解决了传统 RAG 在多模态文档中的信息损失问题。

业务关联社区 UGC 内容往往包含图文混合（帖子配图、截图等），CMRAG 的共模态检索方法可用于提升图文混合内容的搜索召回和理解。

证据在多个视觉文档 QA 基准上，CMRAG 相比纯文本 RAG 方法在答案准确率上提升 10-15%，相比纯视觉方法在细粒度理解上有显著优势。

Wang Chen, Wenhan Yu, Guanqiang Qi, Weikang Li, Yang Li, Lei Sha, Deguo Xia, Jizhou Huang
