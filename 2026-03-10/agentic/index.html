Beyond Rows to Reasoning: Agentic Retrieval for Multimodal Spreadsheet Understanding and Editing

提出 BRTR 多模态 Agentic RAG 框架，用迭代工具调用替代单次检索处理企业级电子表格。

4.35
综合分 / 5
KEY INSIGHT · 对业务意味着什么单次检索在复杂多步推理场景中严重丢失上下文，迭代式 agent 工具调用循环能在多粒度上自适应检索，对搜索系统中结构化数据理解有直接启发。业务关联 社区搜索中常涉及结构化内容（表格帖子、数据型问答），BRTR 的迭代检索+工具调用模式可应用于复杂 query 的多步骤搜索理解。证据 在 3 个前沿电子表格理解基准上取得 SOTA，经 200+ 小时专家人工评估验证，超越先前所有单次检索方法。
Anmol Gulati, Sahil Sen, Waqar Sarguroh, Kevin Paul · 2026-03-09 · arXiv

Exploratory Memory-Augmented LLM Agent via Hybrid On- and Off-Policy Optimization

Microsoft

提出 EMPO² 混合策略优化框架，用记忆增强 LLM Agent 的探索能力。

INSIGHTLLM Agent 的核心瓶颈在于探索，通过记忆增强的混合 on/off-policy RL 方案可显著提升 Agent 在陌生环境中的任务完成率，且在 OOD 场景下仅需少量试验即可适应。

业务关联搜索场景中 Agent 需要在未知 query 分布下自主探索检索策略，EMPO² 的记忆增强探索机制可用于训练搜索 Agent 应对长尾 query。

证据在 ScienceWorld 上相比 GRPO 提升 128.6%，在 WebShop 上提升 11.3%；OOD 测试中无需参数更新即可适应新任务。

Zeyuan Liu, Jeonghye Kim, Xufang Luo, Dongsheng Li, Yuqing Yang

ReflexiCoder: Teaching Large Language Models to Self-Reflect on Generated Code and Self-Correct It via Reinforcement Learning

HKUSTSSamsung

用 RL 训练 LLM 内化自我反思和纠错能力，无需外部反馈即可自主迭代修正代码。

INSIGHTRL-zero 训练范式可将生成-反思-纠错的结构化推理轨迹直接烧入模型权重，实现从依赖外部 oracle 到完全自主反思的范式转换，对搜索 Agent 的自主纠错能力建设有重要参考。

业务关联搜索 Agent 在执行多步检索时也需要自我反思和纠错能力（如发现检索结果不相关时自动调整策略），ReflexiCoder 的 RL 内化反思方法可迁移至搜索场景。

证据使用 RL-zero 训练范式，配合细粒度奖励信号，在复杂算法任务上超越标准单次生成方法的性能上限。

Juyong Jiang, Jiasi Shen, Sunghun Kim, Kang Min Yoo, Jeonghoon Kim, Sungju Kim

RM-R1: Reward Modeling as Reasoning

UIUC

将奖励建模重新定义为推理任务，提出 chain-of-rubrics 机制的生成式奖励模型。

INSIGHT奖励模型通过长链推理（chain-of-rubrics）自动生成评分标准再评估，比传统判别式 RM 更具可解释性和准确性。这为搜索排序中 LLM-as-Judge 的质量评估提供了新范式。

业务关联社区搜索中可将 RM-R1 的推理式奖励建模应用于搜索结果质量评估、相关性标注自动化，以及 RLHF 训练搜索排序模型时的奖励信号生成。

证据RM-R1 系列模型在奖励建模基准上显著提升，chain-of-rubrics 机制使评分过程可解释且准确度更高（v4 更新版）。

Agentic retrieval-augmented reasoning reshapes collective reliability under model variability in radiology question answering

评估 34 个 LLM 在 Agentic RAG 管线下的集体可靠性变化，揭示结构化证据如何重塑模型一致性。

INSIGHTAgentic 检索推理管线不仅提升单模型准确率，更显著降低模型间决策分散度（中位熵从 0.48 降至 0.13），结构化证据检索可作为均衡器提升多模型系统的可靠性。

业务关联社区搜索如使用多模型集成排序，Agentic RAG 的结构化证据注入方式可减少模型间不一致，提升排序系统整体稳定性。

证据在 169 道专家标注放射学题目上评测 34 个 LLM，Agentic 推理将模型间决策熵中位数从 0.48 降至 0.13，集体鲁棒性显著提升。

Reinforcement Learning for Long-Horizon Multi-Turn Search Agents

探索 RL 在多轮文档搜索长序列交互任务中的应用。

INSIGHT多轮搜索 Agent 需要在长时间跨度内与文档集合交互，RL 方法可有效训练 Agent 学习何时搜索、何时停止、如何调整策略，与实际搜索系统中的多轮 query refinement 高度吻合。

业务关联社区搜索中用户常进行多轮搜索，该方法可直接应用于训练搜索 Agent 在多轮交互中优化检索策略，提升用户搜索满意度。

证据在多轮文档搜索任务中验证了 RL 训练搜索 Agent 在长序列交互中的有效性，Agent 在多轮场景中显著优于单轮方法。

AutothinkRAG: Complexity-Aware Control of Retrieval-Augmented Reasoning for Image-Text Interaction

Meituan

提出复杂度感知的 RAG 推理控制框架，按 query 难度自动路由不同推理路径。

INSIGHTQuery 复杂度路由器按问题难度分配推理路径，简单问题用轻量模型、复杂问题走深度推理，实现成本与效果的最优平衡。对搜索系统中的分层处理策略有直接参考价值。

业务关联社区搜索 query 复杂度差异巨大，AutothinkRAG 的复杂度路由思路可用于设计搜索系统中的查询分流策略——简单 query 走快速匹配，复杂 query 走深度语义理解。

证据在信息密集型 DocQA 任务上，多模型协同框架相比端到端 VLM 显著突破推理瓶颈（来自美团团队）。

Latent Poincaré Shaping for Agentic Reinforcement Learning

在庞加莱双曲空间中训练 AlphaZero 式 LLM Agent，利用双曲几何提供密集过程奖励。

INSIGHT双曲空间的负曲率特性天然适合树状搜索过程建模，通过测地线距离定义节点势能可生成密集过程奖励，解决 Agent RL 训练中稀疏奖励问题。为搜索 Agent 的 test-time scaling 提供了新思路。

业务关联搜索 Agent 在推理时的树状决策过程可用该方法进行密集奖励塑形，尤其在复杂 query 需要多步推理时，双曲空间的几何特性可提升搜索效率。

证据Qwen2.5-Math-1.5B 从 66.0% 提升至 88.2%（MATH-500）；LaPha-1.5B 在 AIME24 达 56.7%，LaPha-7B 在 AIME24 达 60.0%、AIME25 达 53.3%。

Hanchen Xia, Baoyou Chen, Zelin Zang, Yutang Ge, Guojiang Zhao, Siyu Zhu

Partial Policy Gradients for RL in LLMs

Amazon

提出部分策略梯度方法，通过优化未来奖励子集来建模 LLM 中的策略结构。

INSIGHT全规划策略并非总是最优，贪心、K-step 前瞻和分段策略在不同问题上各有优势，更简单的策略类因梯度估计更准确而学习更可靠。对搜索 Agent 的策略设计有实际指导意义。

业务关联搜索 Agent 不一定需要完整的长期规划，根据任务特点选择合适的策略粒度（贪心 vs K-step）可在搜索效率和效果间取得更好平衡。来自 Amazon 的工业实践。

证据在多个人格对齐对话问题上评估不同策略类，证明不同策略在不同问题上各有优势，反映了策略结构建模的重要性。

Puneet Mathur, Branislav Kveton, Subhojyoti Mukherjee, Viet Dac Lai

MASFactory: A Graph-centric Framework for Orchestrating LLM-Based Multi-Agent Systems with Vibe Graphing

BBUPT

提出图中心的多 Agent 编排框架，通过 Vibe Graphing 将自然语言意图编译为可执行工作流。

INSIGHT多 Agent 系统的工作流可自然建模为有向计算图，Vibe Graphing 方法允许用自然语言描述意图后自动编译为可编辑可执行的 Agent 工作流，大幅降低复杂 Agent 系统的搭建门槛。

业务关联搜索系统日益涉及多 Agent 协作（如 query 理解 Agent + 检索 Agent + 排序 Agent），MASFactory 的图编排框架可简化搜索多 Agent 系统的开发和维护。

证据框架提供可复用组件、可插拔上下文集成和工作流可视化，支持自然语言到可执行 Agent 图的自动编译。
