TaoSR-AGRL: Adaptive Guided Reinforcement Learning Framework for E-commerce Search Relevance

这篇 WWW 2026 Industry Track 论文面向淘宝搜索相关性判断，解决 LLM 只靠 SFT/DPO 或标准 GRPO 时长尾查询推理不稳、业务规则难以遵守的问题。TaoSR-AGRL 将最终相关性拆成规则感知的稠密奖励，并用 Adaptive Guided Replay 把低准确 rollout 拉回到带标注的轨迹上。公开材料显示，它在淘宝搜索主场景部署，在线 4% 流量 A/B 中 Exposed PV +3.86%、Direct Clean IPV +3.89%、GMV +0.34%。

ARCHER: Shooting Straight in Multimodal E-Commerce Search at Alibaba with Progressive Alignment

AlibabaCityU

ARCHER 是 Alibaba 在 WWW 2026 Industry Track 的多模态电商搜索论文，核心目标是让商品图像与文本证据在召回/排序中更直接地对齐。方法采用 progressive alignment，把跨模态表征从粗粒度商品语义逐步推到更细的属性与视觉证据匹配。公开作者页披露该系统已在 Alibaba 真实业务上线，服务 Taobao B2B 平台 1000 万级日查询，并带来 CTR +2.1%。

INSIGHT社区搜索虽然主要是短文本，但图文笔记、封面图、评论截图同样会影响相关性；ARCHER 的启示是不要把图像只当离线特征拼接，而要训练“可被查询选择”的视觉证据。对图文 UGC 检索，可先在候选召回后引入渐进式图文对齐重排，优先覆盖商品、地点、教程类强视觉意图查询。

Maolin Wang, Lang Fu, Jun Chu, Kai Guo, Chenjie Qin, Xinxin Wang, Siyu Wu, Wen Jiang, Xiangyu Zhao

Relevance-Based Embeddings: Lightweight Candidate Retrieval via Heavy-Ranker Calls

Yandex

论文提出 Relevance-Based Embeddings（RBE），用昂贵 heavy ranker 对一组 support queries/items 的相关性分数来重写查询和文档表示，再用这些轻量表示做 ANN 候选召回。它针对传统双塔召回质量下降、cross-encoder 全量打分成本过高的问题，把 heavy ranker 的判断蒸馏进可检索向量空间。论文报告 RBE 可作为候选选择层，在保留重排器质量信号的同时减少穷举打分需求。

INSIGHT这对搜索相关性很实用：如果已有强 reranker 或 LLM relevance scorer，不必只把它放在最后一层，可以用少量 support 集把它的“相关性几何”前移到召回层。对 UGC 搜索，可按垂类、意图和热门 query 选 support 集，定期用重排器刷新 RBE 表征，让轻量召回更贴近最终相关性目标。

Kirill Shevkunov, Andrey Ploskonosov, Liudmila Prokhorenkova

Do All Visual Tokens Matter Equally? Object-Evidence Preserving Token Merging for Vision-Language Retrieval

Korea University

SaMer 面向多向量视觉-语言检索的成本问题，发现简单 token pruning/merging 会丢掉未来查询可能需要选择的物体级证据。它用训练期目标框/物体先验指导 image-side token 合并，推理时不依赖检测器，只保留 late-interaction 接口。论文报告在 K=64 时移除 93% 以上图像 token、ColPali 存储降低 16.09 倍，同时在 Flickr30K 和 MSCOCO 上提升 R@1。

INSIGHT这篇的关键价值不只是压缩，而是“压缩时保留可匹配证据”。UGC 图文搜索常见问题是封面、截图、商品局部细节被全局向量抹平；SaMer 提供了一个可落地思路：训练期用弱物体先验约束 token 合并，线上仍保持无检测器推理，从而在成本和细粒度相关性之间取得更好折中。

Suhyeong Park, Junha Jung, Jungwoo Park, Jaewoo Kang

MICE: Minimal Interaction Cross-Encoders for efficient Re-ranking

📖 深度解读 · 9 分钟 →

MICE 针对 cross-encoder 重排效果强但推理昂贵的问题，从 cross-encoder 内部交互机制出发，删去有害或不必要的 token 交互，构造 Minimal Interaction Cross-Encoder。它把 cross-encoder 改造成类似 late-interaction 的结构，在保留关键 query-document 交互的同时降低重排成本。论文称在 in-domain 与 out-of-domain 数据集上做了广泛评估，用一个架构桥接“更强一阶段检索”和“更快 cross-encoder”两条路线。

INSIGHT搜索系统通常在召回和重排之间做硬取舍：双塔便宜但弱，cross-encoder 强但贵。MICE 的启示是可以从交互矩阵本身裁剪，而不是只做蒸馏或量化；对 UGC 搜索，可优先在高流量 query、长尾歧义 query 的二阶段重排中试验 minimal-interaction reranker，观察 nDCG 与延迟曲线。

Mathias Vast, Victor Morand, Basile van Cooten, Laure Soulier, Josiane Mothe, Benjamin Piwowarski

SentAttack: A Sentence-Level Black-Box Adversarial Attack Method for Dense Retrieval Models

SentAttack 研究 dense retrieval 在 RAG/检索系统中的黑盒鲁棒性，指出现有攻击多集中在 neural reranker 或词级扰动，难以把低相关目标文档显著推高。方法分两阶段：先通过迭代检索收集排名信息训练 surrogate dense retriever，再用 surrogate 对目标 query 的相关文档编码聚类，生成句子级扰动来攻击真实 DR 模型。它直接覆盖 DR+NRM 多阶段系统中最容易被忽略的第一阶段风险。

INSIGHT对社区搜索而言，召回层一旦被恶意内容、SEO 文本或灌水帖攻破，后续重排很难完全补救。SentAttack 提醒我们把 dense retriever 当成安全边界来评估：不仅要看平均 Recall/nDCG，还要做句子级对抗样本、低相关内容上浮率和跨模型迁移攻击测试，尤其适合治理垃圾 UGC 与黑产 query。

Luping Wei, Yamin Hu, Sihan Shang, Shiyin Wang, Wenjian Luo

Aligning Query Rewriting with Human Cognition and Preference in E-Commerce Search

Alibaba

这篇 WWW 2026 Industry Track 论文来自 Alibaba Group，聚焦电商搜索中的 query rewriting 与人类认知/偏好对齐问题。它针对生成式改写可能偏离用户真实意图、只优化表面语义匹配而不符合购物决策的问题，把人类判断和偏好信号引入改写目标。公开元数据表明该工作处于工业搜索场景，作者均来自 Alibaba，主题与长尾 query 理解和改写质量控制直接相关。

INSIGHTLLM query rewriting 最大风险是“看起来更完整，但排序目标更差”。这篇的实践启示是，改写模块需要同时对齐用户认知、业务偏好和下游排序收益；对 UGC 搜索，可把改写结果分成纠错、补全、意图展开、语义规范化几类，并用点击满意度与人工偏好双通道评估，而不是只看 rewrite 文本相似度。

Ruize Ou, Kai Wang, Jianzhi Shao, Tao Zhang, Chengfu Huo

Submitted and Diagnostic Analysis of Full-Text Temporal Retrieval for LongEval-Sci

论文报告 LongEval-Sci 2026 的全文时序检索系统，比较 PyTerrier BM25、Qwen3 dense baseline、全文 BM25、temporal retrieval、citation features、RM3、cross-encoder reranking 与 RRF 等组合。最强官方提交是 FT BM25+temporal 与 FT BM25+temporal+citation，在三个快照上 nDCG@10 分别达到 0.285、0.267、0.180，并把第 3 快照相对变化从 BM25 pivot 的 0.481 降到 0.368。

INSIGHT很多 UGC 搜索不是静态集合，帖子、评论、热词和实体关系会持续变化。LongEval-Sci 的价值在于把“时间稳定性”作为检索质量的一部分：除了当前 nDCG，还要看 corpus 增长后的排名漂移。实践上可给社区搜索增加时间感知召回、内容更新时间 prior 和跨快照回归测试，避免模型更新后老内容系统性掉队。

Yingdong Yang, Haijian Wu

Claim2Source at CheckThat! 2026: Improving Multilingual Scientific Claim-Source Retrieval with Verification-based Re-Ranking

Claim2Source 面向多语言科学 claim-source retrieval，处理社交媒体 claim 与论文源在语言、表述和细节层级上不一致的问题。系统采用多阶段检索：双语 claim 表示、带元数据的 source 表示、语言自适应 dense retriever 生成候选，再用 verification-based reranking 做逐步精排。它是 CheckThat! 2026 Task 1 的参赛系统，重点在跨语言证据检索和验证式重排。

INSIGHTUGC 社区搜索也常遇到“用户说法”和“目标内容说法”不一致：口语、缩写、错别字、多语言混杂都会削弱匹配。Claim2Source 的可借鉴点是把结构化表示、语言自适应和验证式重排拆成多阶段，而不是指望单个 embedding 解决全部问题；尤其适合问答、辟谣、资料帖搜索。

Tobias Schreieder, Harsh Khandelwal, Yu-Ling Zhong, Michael F\"arber

QUEEN: Neural Query Rewriting in E-commerce

Amazon

QUEEN 是 Amazon 面向电商搜索 query rewriting 的经典工业论文，目标是把歧义购物 query 改写成更规范、可匹配的查询。方法利用电商 query processing pipeline 中自然产生的 query annotations 来建模歧义查询，而不是完全依赖人工标注。实验基于 3850 万匿名商品搜索查询，报告相对 SOTA baseline 的 sentence-level Recall 提升 6%。

INSIGHT虽然不是新论文，但它补足了今天报告的工业覆盖：query annotation 是搜索系统长期积累的副产物，能低成本转化为改写训练信号。对社区 UGC 搜索，可以借鉴同样思路，把 query-tag、query-clicked-post、搜索纠错、用户二次搜索等日志转成弱监督改写样本，优先提升短、口语、歧义 query 的召回。

Yaxuan Wang, Hanqing Lu, Yunwen Xu, R. Goutam, Bing Yin
