Next-Gen Sponsored Search: Crafting the Perfect Query with Inventory-Aware RAG (InvAwr-RAG) Based GenAI

论文聚焦 Walmart 电商 sponsored search 中约 13% 查询无法召回广告的问题，提出 Inventory-Aware RAG based GenAI（InvAwr-RAG）。系统先用 two-tower BERT 检索 top 20 个实时库存商品，再用 LoRA 适配的 Llama2-7B 生成 5 个库存感知 query，并融合历史高点击 query，最后由 cross-encoder BERT 做相关性门控。在 10,000 个历史 0% fill rate 查询上，InvAwr-RAG 达到 68% fill rate、NDCG@8=0.6847，高于 GPT-4 的 53% 和 0.6458。

SimDiffRec: Semantic Similarity-Guided Diffusion for Contrastive Sequential Recommendation

这篇论文面向序列推荐中的数据增强问题，指出随机扩散增强容易破坏用户行为序列的上下文语义。SimDiffRec 用物品 embedding 相似度生成语义一致的噪声，并在去噪阶段利用高置信度位置选择增强点，再结合 hard negative sampling 做对比学习。摘要披露的证据重点是方法在上下文和结构信息保留上优于随机位置增强，但未给出具体公开数据集提升数字。

INSIGHT对 UGC 推荐或搜索后链路排序来说，扩散增强不应只追求扰动多样性，还要约束扰动与原序列的语义邻近性。可借鉴的设计是先用 item embedding 相似度定义可替换邻域，再用去噪置信度决定哪些行为位置适合增强；这比盲目 mask 或随机噪声更贴近真实用户兴趣漂移。

Jinkyeong Choi, Yejin Noh, Donghyeon Park

Enhancement of E-commerce Sponsored Search Relevancy with LLM

论文面向电商赞助搜索相关性，使用预训练 LLaMA2-7B 并通过 LoRA 适配广告相关性模型。它处理关键词空间快速变化、用户与广告主意图歧义、多语言和多主题匹配等问题，把 LLM 语义理解能力引入 query-ad matching。摘要声称该适配显著提升搜索精度和运营效率，但未在摘要中给出具体指标。

INSIGHT相较从零训练广告相关性模型，LoRA 适配大模型更适合快速覆盖长尾 query、跨语言 query 和冷启动广告。实践上应把 LLM 放在候选扩展、相关性判别或特征蒸馏层，而不是直接替换线上低延迟排序模型；社区搜索商业化同样可先用 LoRA 模型生产训练标签和语义特征。

The New Shape of Search: How Conversational AI Recomposes Information Seeking

论文研究 conversational AI 如何重组信息搜索过程，把真实助手对话与同一用户的搜索、浏览记录连接起来，并按完整 episode 而非单 query 还原行为。结果显示 AI episode 出现分化：多数在助手内终止，不再产生后续搜索或内容步骤；约三分之一会脚手架式进入更长的多步旅程。开场问题长度是关键变量，collapse 比例从 1-token 开场的 72% 随问题变长单调下降。

INSIGHT这对搜索产品意味着，AI 搜索不是简单减少 query 量，而是把需求分成“即时答案终止”和“多步探索加速”两类。推荐实践上可以用 opening ask 长度、意图完整度和后续点击链路判断是否进入对话式澄清、传统 SERP，或混合的 RAG+浏览体验。

AI Overviews in Academic Search: Evaluating AI-generated Summaries of Search Results in a Domain-specific Search Engine

论文评估学术搜索中的 AI Overview，也就是对 SERP 前五条结果生成摘要来辅助相关性判断。研究先人工评估 10 个查询上的两个通用模型摘要，形成 6 类错误 taxonomy 和 5 条部署 safeguard；随后做 n=30 的被试内用户实验，对比有无 AI 摘要界面。确认性分析显示 workload、usefulness、satisfaction、decision confidence 均有利于 AI 摘要但未达显著，探索性分析显示 mental demand 和 frustration 有下降趋势。

INSIGHTSERP 级摘要适合提升搜索结果理解效率，但必须把错误类型和防护规则产品化，而不是只展示生成文本。对社区搜索，可先在低风险场景展示“前几条结果聚合摘要 + 来源锚点 + 不确定性提示”，并用用户实验验证是否减少翻页、改写 query 和无效点击。

HETERQA: Benchmarking Record Retrieval over Multiple Heterogeneous Sources

HETERQA 针对社交媒体、电商等系统中记录来自表格、文本、图片、空间数据库和知识图谱的现实问题，构建跨五类异构来源的记录检索 QA benchmark。数据集包含 857 个 QA pair，并以 Yelp business records 为实例；构造流程先用 record-field constraints 初始化候选，再通过异构来源扩展，最后交叉验证答案。它补足了现有 benchmark 多数只覆盖单源或两三类来源的缺口。

INSIGHTUGC 搜索常同时依赖帖子文本、用户属性、图片、地理位置和结构化标签，HETERQA 的价值在于把这些来源统一到“目标记录检索”任务。工程上可借鉴其 answer-driven 构造方式，为社区搜索建立跨模态、跨结构字段的离线评测集，避免只用纯文本相关性指标评估 RAG 或搜索摘要。

EdgeBench: Unveiling Scaling Laws of Learning from Real-World Environments

EdgeBench 研究模型部署后从真实环境学习的 scaling law，而不只看预训练阶段。论文分析约 38,000 小时 agent 与环境交互，覆盖 134 个真实任务，发现环境学习总体表现服从 log-sigmoid scaling law，拟合精度 R^2=0.998；还观察到不同模型代际之间 agent 学习速度约每三个月翻倍。任务覆盖科学发现、软件工程、组合优化、专业知识工作、形式数学和交互游戏。

INSIGHT虽然不是推荐论文，它对生成式搜推的启示是：上线后的交互反馈可能也存在可预测的 scaling 曲线。社区搜索/推荐如果要训练会学习的 agent 或 conversational recommender，应记录长时程 episode、反馈密度和任务难度，建立类似 EdgeBench 的环境学习评估，而不仅看单轮 CTR。

LLM-as-a-Verifier: A General-Purpose Verification Framework

LLM-as-a-Verifier 把“验证答案是否正确”定义为继预训练、后训练和 test-time compute 之后的新 scaling 轴。框架不要求额外训练，而是利用评分 token logits 的期望生成连续分数，并沿 score granularity、repeated evaluation 和 criteria decomposition 三个维度扩展验证能力。摘要指出更细粒度评分能更好区分正负解，从而带来更可校准的反馈。

INSIGHT生成式搜索和推荐引入 LLM 后，最大风险之一是相关性、事实性和业务规则无法稳定校验。这个 verifier 思路可用于 RAG 答案、推荐解释、query 改写和广告相关性审核：把离散 judge 改成连续概率分数，并按事实一致性、相关性、风险合规拆解评估标准。

Jacky Kwok, Shulu Li, Pranav Atreya, Yuejiang Liu, Yixing Jiang

Building an Analysis AI Agent for Industrial Alarm Management with NVIDIA Nemotron

NVIDIA

NVIDIA 这篇工程博客面向工业告警管理，描述用 Nemotron 构建分析型 AI agent 的实践场景：工业设备产生的告警超过技术人员可处理能力，重要告警需要拉取历史上下文再分析。虽然主题不是推荐排序，但它展示了企业级 agent 如何围绕检索、上下文聚合、工具调用和分析工作流落地。RSS 摘要只给出问题和场景，没有披露完整实验指标。

INSIGHT作为工业实践条目，它对搜推团队的价值在 workflow 设计：把“告警”换成“异常 query、低召回会话、推荐投诉”即可形成相似的分析 agent。关键不是让模型直接给结论，而是自动收集历史日志、检索相似案例、调用诊断工具，并把证据链交给运营或算法同学复核。
