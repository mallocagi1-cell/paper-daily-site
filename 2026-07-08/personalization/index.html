HGenPush: A Heterogeneous Generative Recommendation Architecture for Industrial Push Notification Systems

这篇论文面向快手短视频 Push 场景，解决生成式推荐只能生成单一内容类型、Semantic ID 自回归生成效率低的问题。HGenPush 将多场景、多视角用户行为理解，与视频推荐和作者推荐的双分支异构生成模块合并到端到端框架中，并用多 token 预测替代逐步自回归生成。论文报告已部署在快手 Push 通知系统，带来日活用户数 0.181% 的显著提升。

HiSAC: Hierarchical Sparse Activation Compression for Ultra-long Sequence Modeling in Recommenders

Alibaba📖 深度解读 · 12 分钟 →

HiSAC 针对超长用户行为序列在生产环境中受延迟和内存限制、难以端到端建模的问题，提出分层稀疏激活压缩框架。它把交互编码为多层 Semantic ID，构建全局分层码本，再通过投票稀疏激活个性化 interest-agents，并用 Soft-Routing Attention 在语义空间聚合历史信号。论文称已部署在淘宝“猜你喜欢”首页，线上 A/B 测试获得稳定 1.65% CTR 提升。

INSIGHT这篇论文把长序列推荐的关键矛盾拆成“压缩成本”和“长尾偏好保真”两件事，工程价值很直接。相比粗暴截断最近行为或固定兴趣中心，分层码本加稀疏激活能让系统按用户自动选择粒度，保留低频但高价值偏好；对 UGC 社区的帖子点击/停留建模，也可以借鉴这种 interest-agent 设计来压缩长期互动历史。

Kun Yuan, Junyu Bi, Daixuan Cheng, Changfa Wu, Shuwen Xiao, Binbin Cao, Jian Wu, Yuning Jiang

Generative Pseudo-Labeling for Pre-Ranking with LLMs

📖 深度解读 · 7 分钟 →

GPL 关注工业推荐预排序的训练-服务不一致：模型训练只看到已曝光交互，线上却要给大量未曝光候选打分，导致样本选择偏差和长尾内容泛化差。方法用 LLM 离线生成用户兴趣锚点，在冻结语义空间中与候选匹配，为未曝光物品生成内容感知伪标签，不增加线上延迟。论文报告在大规模生产系统部署后 CTR 提升 3.07%，同时改善多样性和长尾发现。

INSIGHT对预排序团队来说，GPL 的重点不是把 LLM 放到线上打分，而是把 LLM 当作离线监督生成器，修补曝光日志覆盖不到的候选空间。这个设计适合社区搜索/推荐里的冷内容、长尾帖子和新作者分发：用语义锚点扩充训练标签，再让轻量预排序模型承接线上流量，可在延迟约束内降低热门内容偏置。

CanniUplift: A Holistic Framework for Mitigating Seller and Incentive Cannibalization in E-commerce Uplift Modeling

CanniUplift 面向电商个性化激励分配，指出多商家场景中传统 uplift 模型会受到卖家间替代和激励噪声影响。框架用 Platform-level Global Alignment 约束全局 GMV 一致性，用 Redemption-based Decomposition Denoising 分解处理组结果并降低归因噪声，再用 Treat-Attention 建模用户历史行为与当前激励的交互。论文报告线上部署后平台级增量 GMV 相对生产基线提升 4.08%，ROI 也得到改善。

INSIGHT虽然任务是电商激励，但它对个性化排序的启发在于：多目标优化不能只看局部点击或转化，还要处理平台级替代效应。UGC 社区做补贴、流量扶持或创作者激励时，也会遇到“一个作者涨、另一个作者掉”的互相吞噬问题；PGA/RDD 这种把全局一致性和归因降噪纳入 uplift 的做法，值得迁移到流量分配实验。

UniSGR: Unified Framework for Semantic ID Generation and Ranking

UniSGR 针对生成式检索能缓解多阶段级联复杂度、但难以支持细粒度多目标排序的问题，提出 Semantic ID 生成与排序统一框架。它先做多场景预训练，再做场景对齐，联合优化 Value-Aware Parallel Multi-Token Prediction 和统一多目标排序模块；同时引入 Task-Aware Tokens、Funnel-Aware Contrastive Learning，以及重组 KV cache 的 STARK 推理策略。论文在大规模电商离线实验中验证了可扩展性。

INSIGHTUniSGR 的实践价值在于把“生成候选”和“多目标排序”从两个断开的系统拉近到同一训练目标下。对搜索推荐混合场景，如果召回阶段已经使用 Semantic ID 或生成式检索，就不应再让排序只被动消费候选；任务感知 token 和漏斗感知对比学习可以让生成空间提前理解 CTR、CVR、满意度等下游目标。

MCLMR: A Model-Agnostic Causal Learning Framework for Multi-Behavior Recommendation

MCLMR 面向多行为推荐，处理浏览、点击、购买等多种互动带来的混杂偏差、辅助行为聚合困难和语义鸿沟问题。框架先构建因果图并做干预，以获得更无偏的偏好估计；再用基于 MoE 的 Adaptive Aggregation 动态融合辅助行为，并通过 Bias-aware Contrastive Learning 对齐跨行为表示。论文在 3 个真实数据集和多种基线模型上验证了通用增益，并承诺开放数据与代码。

INSIGHT多行为推荐经常把所有行为简单加权，结果容易把“浏览习惯”“物品天然热度”和真实偏好混在一起。MCLMR 的价值是给多行为融合加入因果视角：先识别用户行为习惯和物品分布造成的偏差，再决定哪些辅助行为该被 MoE 专家吸收。对社区内容排序，可用于区分点击、收藏、评论、停留时长各自的偏置信号。

Long-Term Optimization for Large-Scale Generative Retrieval with Off-Policy REINFORCE

这篇论文把大规模生成式检索推荐建模为 session 级序列决策问题，而不是只优化下一物品预测。方法用离线日志训练 off-policy REINFORCE，提出多步重要性权重近似，并训练用户反馈模型来模拟对生成推荐的响应，从而把 doubly robust 离线评估扩展到序列推荐。实验在公开 Yambda-5B 数据集上显示，RL agent 提升累计 session reward 的离线估计，同时基本保留检索质量。

INSIGHT对个性化推荐的核心启示是：长期满意度不能靠单步点击代理指标自然涌现，需要在生成式检索阶段就建模未来反馈。它目前依赖反馈模型和离线 OPE，落地门槛高于普通监督学习，但适合用在高价值链路的重排或候选生成实验中，先验证“多看几步”的策略是否减少短期点击导向和内容疲劳。

Beyond Item Order: Temporal Gap Tokenization for Generative Recommendation with Semantic IDs

这篇论文关注 Semantic ID 生成式推荐忽略交互间时间间隔的问题。现有方法通常只把用户历史写成静态物品 ID 序列，无法表达相邻行为之间隔了几分钟还是几周；作者提出 Temporal Gap Tokenization，把时间间隔离散为可生成 token，并与 Semantic ID 共同作为序列输入，使模型在预测下一物品时同时理解物品语义和行为节奏。该问题直接对应序列推荐中的短期兴趣与长期偏好区分。

INSIGHT时间间隔是社区推荐里很容易被低估的信号：连续浏览同类帖子与半年后重新点击同类主题，含义完全不同。Temporal Gap Tokenization 的可借鉴点是把时间建模并入生成式推荐词表，而不是作为外部特征拼到排序层；这有助于模型学习复访周期、兴趣衰减和突发兴趣，对帖子、问答、创作者推荐都适用。

Chengkai Huang, Tianqi Gao, Hongtao Huang, Quan Z. Sheng, Lina Yao

LBR: Towards Mitigating Length Bias in Large Language Models for Recommendation

LBR 研究 LLM 推荐中的长度偏置：当物品被文本描述表示时，较长描述会在输入侧占用更多上下文，在输出侧也更容易影响生成概率，从而系统性偏向文本更长的物品。论文提出面向长度偏置的缓解思路，目标是在 token 级生成推荐中减少描述长度对相关性的污染。它特别适合内容型平台，因为 UGC 标题、正文、评论摘要天然长度差异大。

INSIGHT对社区搜索/推荐来说，长度偏置会让“信息量大”被模型误当成“更相关”，从而伤害短文本帖子、短问答和新内容。LBR 的实践意义是提醒 LLM-as-ranker 或 LLM recommender 上线前必须做分桶评测：按标题/正文长度检查曝光、点击和相关性，必要时在输入压缩、候选描述标准化或训练目标中显式去偏。

Hongchen Li, Bohao Wang, Jingbang Chen, Weiqin Yang, Hang Pan, Bingde Hu, Can Wang, Jiawei Chen

推荐算法日报 2026-05-28: Uniboost traffic allocation for recommendation re-ranking

Alibaba

这篇中文技术日报收录 Alibaba 的 Uniboost，聚焦电商推荐重排阶段的多业务目标耦合、分数膨胀和可解释性不足。条目概述了后验价值对齐机制：把抽象模型分数校准为有业务语义的锚定指标，再用独立线性提升范式解耦复杂权重，使每个调控计划的贡献可以归因。日报还提到线上 A/B 验证显示该框架能减少业务干扰并提升流量分配效率。

INSIGHTUniboost 对推荐平台的意义在于把“调权”从经验参数变成可解释的后验价值对齐问题。社区 Feed 或搜索推荐常有点击、停留、互动、作者生态等目标，直接加权很容易分数膨胀或互相干扰；把后验指标先转成统一业务锚点，再做线性提升和归因，有助于让多目标重排更可控。
