TRACE: Accountable Agentic Retrieval for Source Discovery in Digital Archives

TRACE 面向有噪声、跨语料且必须追溯出处的检索，将问题分解、混合召回、证据暂存复审与重规划组成免训练搜索循环。在 1,752 个历史问题上，R@10 达 0.856、MRR 达 0.653，高于稠密检索的 0.734 和 0.535；托管推理约每题 0.02 美元，但延迟不适合直接搬入同步搜索主链路。

MATCH: Model-Aware Tool Learning with Curriculum Scheduling and Hierarchically Gated Rewards

UCASHonor

MATCH 针对工具学习课程难度失配，以及选错工具仍获得参数奖励的问题，把动态课程与层级门控奖励闭环结合。只有工具名正确才评估参数键，前序条件成立后才奖励参数值；在 API-Bank 和 BFCL V3 上总体准确率分别达到 72.19% 与 62.87%，并在两个模型家族的四个基座上验证。

Closed-World Resolution Against Tool Hallucination in LLM Agents

论文研究智能体调用不存在的工具、传递未声明参数的结构性错误，并提出在执行权限判断前进行注册表和签名解析。10 个托管模型的两种调用界面共出现 322 次真实工具幻觉，虚构工具在原始 JSON 界面为 34 次、受约束界面为 3 次；多服务器 MCP 测试另发现 154 次幻觉。

INSIGHT为社区搜索接入帖子检索、评论查询与重排工具时，可先校验完整工具命名空间和参数结构，再执行后续策略判断。该机制无需训练，适合以统一入口落地；不过结构合法的错误参数仍能通过，必须继续验证业务语义，并用任务成功率和失败调用率衡量效果，不能把签名通过等同于查询正确。

AAnote

AgenticRAG-FP 在指定检索跳注入已知故障，并重新执行后续轨迹，以检验最终日志能否定位最初错误。在 80 道三跳 MuSiQue 问题的严格实验中，覆盖率归因在第 1 跳为 0.91，第 2、3 跳均为 0；内容污染实验中，第 2 跳的冻结反事实探针为 0.67，但仅有 18 个失败样本。
