ICEGR: An Intent-Coherent End-to-End Generative Retrieval Framework for E-commerce Search

针对电商生成式检索在 Semantic ID 构建、低曝光商品监督和偏好优化三个阶段出现的意图漂移，ICEGR 将查询意图贯穿 SID、统一 SFT 与相关性校准偏好学习。离线 Recall@20 提升 21.7%、NDCG@20 提升 26.6%；百度线上 A/B 中 CTR、订单量和 GMV 分别相对提升 3.52%、15.96% 和 7.53%。

Preference Shapes Relevance: Cross-component Hierarchical Semantic Alignment for Personalized Generative Retrieval

CHAP 解决内容生成的静态 SID 与动态查询、用户偏好不对齐，以及自回归 beam search 延迟过高的问题。它用分层语义对齐同步 query 与量化路径，以离散 SID 提供结构约束、连续表示补充细粒度语义，并以 Residual Cascading Generation 将多步解码压缩为单次推理；论文在 3 个公开集、1 个工业集及线上 A/B 中验证。

INSIGHT生成式召回不应只优化 item tokenizer，还要跨 tokenizer、用户序列与解码器对齐多粒度语义。对社区搜索，可把用户近期兴趣和 query 意图同时映射到帖子 SID 路径，并将昂贵的逐 token 解码改为单次残差级联，从而在个性化收益和线上吞吐之间取得更可部署的平衡。

Gaoming Zhang, Angqing Jiang, Jianchun Song, Kena Qi, Dayao Chen, Wei Lin, Defu Lian

Generative Retrieval for E-commerce: Jointly Learning Embedding and Codebook with Same Product Cluster

论文针对先训练商品 embedding、再学习 codebook 的级联方案容易累积表征误差且忽略 query-product、product-product 交互的问题，提出联合训练 embedding 与 codebook，并加入同商品簇监督。该设计让向量空间和离散 ID 同时朝检索目标收敛，实验报告电商检索、embedding 质量与 codebook 学习均显著改善，但摘要未披露具体增幅。

INSIGHT联合优化可避免上游向量偏差在离散量化后不可逆放大；同簇监督则能让相似商品共享更一致的编码路径。迁移到 UGC 搜索时，可把同主题帖子、同问答链或共点击内容定义为簇监督，使短文本 embedding 和生成式 codebook 共同适配 query—内容匹配，而非分阶段冻结。

Songtao Fang, Zihao Xu, Shaowei Wei, Jin Zhang, Zhuojun Wang

HF-SID: High-Fidelity Semantic IDs for Generative Retrieval in Location-Based Services

HF-SID 指出位置服务中的 Semantic ID 会丢失连续地理、不同尺度数值与层级归属信息，且这些损失在解码阶段无法恢复。方法用三维笛卡尔坐标、Geo-CPT/Num-CPT 类型感知编码和仅施加于末层残差的结构对比学习增强表征，同时保持 3-token SID，因此不增加生成解码长度；论文在大规模工业数据上评估。

INSIGHTSemantic ID 的关键不是一味加长编码，而是在量化前保护业务不可丢失的连续与层级信号。UGC 搜索可把时间、地域、作者层级或社区结构先做类型感知连续编码，再用结构对比目标区分文本相似但归属不同的内容，以固定 SID 长度控制线上时延。

Haowen Lin, Jing Li, Zhibin Hao, Fangye Wang, Lihui Su, Song Yang, Xiaojiang Zhou, Pengjie Wang

Beyond Polarization: The Generative Constraint of Chain-of-Thought in Pointwise Reranking

论文系统检验为何 pointwise 重排中的思维链模型持续弱于直接打分模型，并把比较扩展到 32B 参数规模。研究分别用强化学习、细粒度监督和架构解耦修复分类、分数极化与校准问题；这些干预虽提高分类准确率和绝对分数，仍未消除相对排序差距，说明离散文本会压缩连续相关性信号。

INSIGHT对 nDCG 敏感的检索系统，不宜把自然语言 CoT 直接当作细粒度相关性分数通道。更稳妥的方案是保留连续判别头负责排序，把生成式解释作为旁路能力；若必须使用 LLM，可优先测试 listwise 或 pairwise 目标，而不是继续在 pointwise CoT 上堆参数和监督。

Xiaoyang Chen, Jie Liu, Haijin Liang, Haibo Shi, Jin Ma, Ben He, Yingfei Sun, Dezhi Ye

Beyond Ranking Accuracy: Evaluating LLM-Cited Feature Rationales for Next Basket Repurchase Recommendation

研究在 2 个公开杂货数据集和 1 个私有零售数据集上，用周期、频次、时效、用户行为和商品热度特征评估 LLM 的复购排序与引用式解释。跨模型特征遮蔽实验表明，现成 LLM 的排序不如监督式 ranker，提示词与证据表示有时能改善解释的结果相关性，但效果依赖数据集且未稳定超过归因基线。

INSIGHTLLM 更适合作为经过验证的解释组件，而非替代主排序器；解释质量必须与 Recall/nDCG 分开评测。对 UGC 搜索，可让判别模型输出排序，LLM 只引用可审计的匹配特征生成理由，再通过特征遮蔽或反事实测试验证理由是否真正影响点击与相关性。

Yanan Cao, Anay Dombe, Murali Mohana Krishna Dandu, Shreeranjani Srirangamsridharan, et al.

P-Law: Predicting Quantitative Scaling Law with Entropy Guidance in Large Recommendation Models

P-Law 聚焦大型推荐模型的定量 Scaling Law 预测，引入熵引导来估计模型扩展后的效果曲线，目标是在完整大规模训练前判断参数、数据或算力投入的边际收益。当前候选元数据未返回摘要与实验数字，因此方法细节和证据质量暂按保守档评分，报告保留其作为生成式推荐扩展决策的近期信号。

INSIGHT相比只证明“模型越大越好”，可预测的定量曲线更能支持资源预算和停止扩展决策。对 UGC 搜索推荐，可用小规模实验拟合熵与 nDCG/CTR 的响应，再验证是否能外推到更长序列、更大模型；在论文全文与复现实验可用前，不应据此直接采购算力或调整线上容量。

Tingjia Shen, Hao Wang, Chuhan Wu, Jin Yao Chin, Wei Guo

Can Large Language Models Identify Meaningful Touchpoints in Conversion Attribution?

论文用人工标注揭示协同过滤规则会漏掉用户感知上相关、但交互关系隐式的转化触点，并系统比较不同 LLM、提示策略识别这些关联的能力。结果显示 LLM 能找回相当一部分隐式触点但仍有明显误差；作者进一步把 LLM 归因标签用于工业 CVR 模型训练并取得显著离线提升，论文含 4 图 3 表。

INSIGHTLLM 的价值可放在离线补标和语义监督，而非进入在线关键路径。社区搜索可让 LLM 从浏览、收藏、评论等弱信号中生成语义触点标签，再训练轻量 CTR/CVR 模型；上线前应以人工样本审计提示敏感性和伪标签偏差，避免把模型偏见固化为归因规则。

Jinqi Wu, Sishuo Chen, Zhangming Chan, Yong Bai, Chao Yi, et al.

CogEvol: Towards Efficient and Reliable Learning Environment Generation

OOpenMAIC

CogEvol 将课程简述单次生成结构化幻灯片或交互 HTML：在 22 万次生产请求中，中位生成时间分别为 17 秒和 59 秒。团队把真实失败转成 53,687 条验证 SFT 样本，并用规则与 VLM 混合奖励进行 GRPO；27B 模型在幻灯片和 500 例 HTML 基准上得分 83.7、63.7，参数量比旗舰编码模型少 26.9 倍。

INSIGHT虽然任务不是推荐本身，但其“从线上失败生成可验证训练样本”的闭环对生成式搜推非常可迁移。团队还识别并修复了视觉正确但交互不可用的奖励作弊，提示推荐系统的 RL 奖励必须同时覆盖内容质量、可点击性和业务约束；4B 开源版本也便于低成本复现数据与奖励设计。

Shangqing Tu, Daniel Zhang-Li, Yucheng Wang, Shiyu Gan, Yanpeng Wang

A milestone in expanding access to AI

OpenAI

OpenAI 披露 ChatGPT Ads 的年化收入运行率达到 10 亿美元，并向更多市场扩展，以广告收入支持免费和低价 AI 访问。该材料属于近期产品与商业化实践，未公开推荐模型架构、离线排序指标或 A/B 增量，因此本报告将其作为生成式界面中广告推荐与访问成本权衡的产业信号，而非算法论文。

INSIGHT生成式搜索中的广告不只是插入一个传统广告位，还需要处理回答相关性、商业内容标识和用户信任之间的约束。社区搜索若探索生成式答案商业化，应先建立广告与自然结果的分离评测，持续监控 CTR、回答满意度和误导率；在缺少算法细节时，不宜照搬具体排序方案。
