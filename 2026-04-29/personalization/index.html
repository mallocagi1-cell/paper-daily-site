Kwai Summary Attention Technical Report

针对推荐系统中长用户行为序列带来的 softmax 注意力二次复杂度瓶颈，快手提出 Kwai Summary Attention，通过对历史序列进行 token 级摘要压缩并与稀疏检索式注意力结合，实现 KV cache 与序列长度解耦。报告披露了在工业级长序列推荐场景下的训练与推理优化，将训练/推理成本随序列长度的恶化趋势显著缓解，同时保持下游召回排序指标。

Similar Users-Augmented Interest Network

USTC📖 深度解读 · 7 分钟 →

CTR 预估高度依赖用户历史行为序列，但实际系统中行为稀疏、序列残缺普遍存在。SUIN 在目标用户自身序列之外引入“相似用户”的行为作为补充：通过行为 embedding 检索 top-K 相似用户，将其行为子序列与目标用户序列联合输入兴趣网络，对稀疏冷启用户给出更完整的画像，公开数据集上 AUC 显著优于仅用自身序列的 DIN/SIM 等基线。

INSIGHT以“相似用户”行为弥补稀疏用户画像，是面向社区/电商常见低活跃 UGC 用户的低成本路径——不需要等待目标用户行为累积，离线即可建立相似用户索引。可在排序阶段叠加为额外子网络，对长尾 query/长尾用户的相关性与 CTR 预期收益最大；落地需注意相似度计算与隐私边界。

Xiaolong Chen, Haoyi Zhao, Xu Huang, Defu Lian

Beyond Static Collision Handling: Adaptive Semantic ID Learning for Multimodal Recommendation at Industrial Scale

Alibaba

工业级推荐中海量多模态物品的 Semantic ID (SID) 量化常因 token 冲突而损失语义保真度。AdaSID 提出两阶段自适应框架：第一阶段对“语义兼容”的冲突放松排斥，第二阶段对仍冲突的项再做高分辨率重编码，从而区分该抑制还是该保留 overlap，工业规模实验显示在召回 Recall@K、检索效率上优于固定正则的 RQ-VAE/RQ-Kmeans 基线。

INSIGHT把“冲突即坏”改为“按语义判定是否保留冲突”，回应了生成式推荐 SID 化路线中长期被忽视的细节问题。对计划上线生成式推荐/统一索引的团队，AdaSID 的自适应策略可直接迁移到 SID 训练流水线上，减少 codebook 利用率不均带来的长尾物品掉点。

Yongsen Pan, Yuxin Chen, Zheng Hu, Xu Yuan, Wenwu Ou, et al.

04 3.80

FreeScale: Distributed Training for Sequence Recommendation Models with Minimal Scaling Cost

Meta

工业级序列推荐模型分布式训练受限于数据异质性带来的 straggler 与阻塞通信。FreeScale 通过精细化 input 负载均衡缓解 straggler，将优先级 embedding 通信与计算重叠，并以 SM-Free 通信化解重叠时的 GPU 资源争用，在大规模训练中将计算气泡最高减少 90.3%。

INSIGHT推荐侧大规模训练瓶颈与 LLM 训练有显著差异——embedding 通信主导而非梯度同步，FreeScale 给出了一套针对序列推荐特征的通信-计算重叠优化。对自研推荐训练框架的团队，SM-Free 通信思路与负载均衡策略具体可借鉴，可作为后续 collective/PCIe 调度优化的参考实现。

Chenhao Feng, Haoli Zhang, Yanli Zhao, Liang Luo, Jennifer Cao, Min Si, et al.

Disagreement as Signals: Dual-view Calibration for Sequential Recommendation Denoising

Chongqing University

序列推荐对“噪声行为”（误点击、随机浏览）非常敏感，已有 LLM 静态语义编辑方法忽视模型学习动态。DC4SR 提出双视角校准：用 LLM 微调得到的语义先验估计语义噪声分布，同时用学习视角动态重加权样本，两视角“分歧”作为噪声信号，公开数据集上 NDCG/HR 优于 STEAM、HSD 等去噪基线。

INSIGHT把“语义偏差”和“学习偏差”当作互相校准的两路信号，是降噪问题中较少见的视角。对社区搜索/推荐这种 UGC 噪声大、用户兴趣漂移频繁的场景，可将该思路简化为“离线 LLM 标注 + 在线学习权重”的轻量版本，先在长尾用户/低置信样本上做 A/B。

Sijia Li, Min Gao, Zongwei Wang, Zhiyi Liu, Xin Xia, Yi Zhang

06 3.75

Modeling Behavioral Intensity and Transitions for Generative Recommendation

现有多行为生成式推荐通常把行为类型当作辅助 token 喂给统一注意力，隐式假设各历史行为对当前预测贡献均匀。BITRec 引入分层行为聚合 (HBA) 显式建模点击/收藏/购买等行为的强度差异，并通过选择性依赖激活捕获行为转移模式，在多行为转化预测上优于 MB-STR、CML 等基线。

INSIGHT对生成式推荐而言，把不同行为视为“强度+转移结构”而非简单 token，是一种更贴近实际转化漏斗的建模。社区搜索后链路的“点击→深读→关注→发评论”同样具有强烈层级性，可借鉴 HBA 的分层聚合思想优化多目标排序模型。

Wenxuan Yang, Xiaoyang Xu, Hanyu Zhang, Zhexuan Xu, Wanqiang Xiong, Zhaoqun Chen

CASP: Support-Aware Offline Policy Selection for Two-Stage Recommender Systems

两阶段推荐系统中召回器决定排序候选集，单阶段离线评估容易选中“看似高分但依赖弱支持样本”的策略。CASP（Coupled Action-Set Pessimism）将 doubly robust 价值估计与“支持负担惩罚”结合，给出了人口、有限类、重构倾向性三个层级的理论保证，并证明忽视下游延续价值的分层规则可任意次优。

INSIGHT为离线策略选择引入“支持度悲观”，给出了有别于传统 IPS/DR 的离线选择标准。对必须在“候选生成器 + 排序器”大空间中频繁切换策略的团队，CASP 是工业级离线灰度选择的可借鉴框架，可避免线上 A/B 前的策略反向选择。

Nilson Chapagain

Birds of a Feather Cluster Nearby: a Proximity-Aware Geo-Codebook for Local Service Recommendation

本地生活生成式推荐中，仅靠 Semantic ID 容易推荐“语义对但物理上够不到”的商家。Pro-GEO 引入 geo-centroid 局部坐标系建模簇内空间关系，并以 geo-rotary position encoding 把地理邻近性编码为高维 embedding 上的正交旋转，使语义与空间信号被联合建模而非弱辅助，地理可达性指标显著提升。

INSIGHT把空间结构 embedding codebook 而非作为后置过滤是关键设计。对社区搜索中的“附近吃喝玩乐”“同城问答”等地理强相关场景，借鉴 geo-rotary 思路可在召回侧直接得到“附近 + 相关”的统一打分。

Tian He, Chen Yang, Jiawei Zhang, Lin Guo, Wei Lin, Zhuqing Jiang

Prompt-Unknown Promotion Attacks against LLM-based Sequential Recommender Systems

University of Queensland

LLM 序列推荐 (LLM-SRS) 在带来推理能力的同时引入文本级攻击面。已有研究普遍假设可访问 prompt 或受害模型，PUDA 在 prompt 与模型均不可知的全黑盒设置下设计了双投毒攻击：通过受控的物品描述与序列篡改提升目标商品排序，多个公开 LLM-SRS 配置下均显著提高攻击成功率。

INSIGHT把“黑盒提示注入”引入推荐安全是必要的攻防视角。计划上线 LLM 排序/重排的团队，应将 PUDA 这类攻击纳入红线测试，在用户侧 UGC 物品描述、Prompt 模板上预设审计与噪声鲁棒训练，避免上线后被引导式攻击放大。

Yuchuan Zhao, Tong Chen, Junliang Yu, Zongwei Wang, Lizhen Cui, Hongzhi Yin

Green-Red Watermarking for Recommender Systems

Chongqing University

推荐模型权重大规模开源后，模型抽取攻击使知识产权保护变得迫切。GREW 用密钥将物品空间划分为绿色（弱推）与红色（锚点）两类，通过密钥控制的输出偏置而非数据记忆来嵌入水印，在抽取攻击下仍可验证模型归属，且对自然推荐分布的偏离显著小于现有记忆型水印。

INSIGHT从“强行记忆触发样本”切换到“密钥控制的全局排序偏置”，这是更难被检测和清洗的水印范式。对自研但需对外开源/共建的推荐模型团队，GREW 给出了一种可量化的所有权验证方案，部署成本相对较低。

Lei Zhou, Min Gao, Zongwei Wang, Yibing Bai, Wentao Li
