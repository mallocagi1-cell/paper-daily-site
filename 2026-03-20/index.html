Internalizing Multi-Agent Reasoning for Accurate and Efficient LLM-based Recommendation

本文提出 STAR 框架，通过多智能体教师系统和蒸馏方法将复杂推理能力内化到单一高效模型中。核心创新是协同信号翻译机制（Collaborative Signal Translation），将用户行为模式转化为自然语言证据以增强推理准确性。实验结果表明，STAR 模型性能超越其教师系统 8.7%–39.5%，同时消除了迭代推理延迟，实现实时推荐场景的落地。

CRE-T1 Preview Technical Report: Beyond Contrastive Learning for Reasoning-Intensive Retrieval

本文提出 Thought 1 (T1)，一种生成式检索模型，将相关性建模从静态对齐转向动态推理。T1 在 query 侧动态生成中间推理轨迹以弥合 query 与文档间的语义鸿沟，在文档侧通过多粒度索引实现高效推理检索。该方法从根本上挑战了对比学习范式在推理密集型检索中的局限性，提出了基于生成式推理的新检索范式。

INSIGHTT1 的核心洞察是：对比学习本质上是静态表征固化技术，无法根据每个 query 的具体推理需求动态调整相关性判断。对于 UGC 短文本搜索场景，当 query 与文档存在词汇不匹配或需要隐式推理才能建立相关性时，生成式推理检索方法比固定向量表征方法更具优势。T1 的动态推理轨迹生成思路值得搜索系统探索。

Guangzhi Wang, Yinghao Jiao, Zhi Liu

Exploring Training and Inference Scaling Laws in Generative Retrieval

本文系统研究了生成式检索中的训练和推理 Scaling Law，探索模型规模、训练数据规模和推理时计算量如何共同影响性能。研究发现 n-gram 方法与 Scaling Law 高度吻合，而 codebook 方法在模型扩大时无一致性提升。此外，decoder-only 架构（如 LLaMA）持续优于 T5 变体。该工作被 SIGIR 2025 接收。

INSIGHT该研究为生成式检索系统的工程实践提供了重要的 Scaling 指导：n-gram 方法比 codebook 方法更适合规模化，decoder-only 架构是更优的基础模型选择。对于搜索系统而言，这意味着在构建基于 Semantic ID 的生成式召回时，应优先选择 n-gram 方案和 decoder-only 架构，而非 T5 + codebook 方案，以获得更好的规模效益。

Hongru Cai, Yongqi Li, Ruifeng Yuan, Wenjie Wang, Zhen Zhang, Wenjie Li, Tat-Seng Chua

RALLRec+: Retrieval Augmented Large Language Model Recommendation with Reasoning

RALLRec+ 通过融合文本信号和协同过滤信号增强 LLM 推荐的检索阶段，并在生成阶段引入知识注入提示和一致性合并策略提升推理能力。该方法在三个真实数据集上验证了有效性，同时结合了检索增强和推理能力来弥补传统 LLM 推荐在 item 理解和偏好推理上的不足。

INSIGHTRALLRec+ 将 RAG 范式引入 LLM 推荐，通过检索增强弥补 LLM 对协同过滤信号的天然缺失。对于搜索场景，这种融合文本语义和用户行为信号的 RAG 推荐方法，可以启发搜索排序模型在利用 LLM 语义能力的同时，通过检索增强方式注入点击/转化等行为信号，实现更全面的相关性判断。

Sichun Luo, Jian Xu, Xiaojie Zhang, Linrong Wang, Sicong Liu, Hanxu Hou, Linqi Song

Early Quantization Shrinks Codebook: A Simple Fix for Diversity-Preserving Tokenization

本文系统研究了向量量化（VQ）中的 codebook 坍塌问题，识别了 token 坍塌和 embedding 坍塌两种模式及其触发条件。研究发现随机初始化和有限编码器容量是导致坍塌的主因，并提出了针对性的缓解方案。这对依赖 VQ 进行 Semantic ID 构建的生成式推荐系统具有直接指导意义。

INSIGHTVQ codebook 坍塌直接影响生成式推荐中 Semantic ID 的质量和多样性。本文揭示的坍塌机制和修复方法（如避免早期量化、增强编码器容量）为 TIGER/HSTU 等使用 RQ-VAE 构建 Semantic ID 的系统提供了重要的工程指导。在构建生成式召回系统时，应关注 codebook 利用率以确保 ID 空间的表达多样性。

Wenhao Zhao, Qiran Zou, Rushi Shah, Yudi Wu, Zhouhan Lin, Dianbo Liu

Efficient Training-Free Multi-Token Prediction via Embedding-Space Probing

本文发现标准 next-token LLM 具有潜在的多 token 预测能力，提出无需训练的多 token 预测方法：通过在 embedding 空间中使用 mask token 探测 LLM，实现未来 token 的并行预测。该方法构建推测性 token 树并应用树状验证解码，在无需修改模型权重或辅助草稿模型的前提下加速 LLM 推理。

INSIGHT多 token 预测对生成式推荐系统的推理效率有直接影响：生成式推荐需要自回归地生成 Semantic ID 序列，推理延迟是部署的主要瓶颈。本文的无训练多 token 预测方法可直接应用于加速生成式推荐模型的在线推理，无需额外训练草稿模型，降低了部署复杂度。

A Family of LLMs Liberated from Static Vocabularies

Aleph Alpha

本文提出基于分层自回归 Transformer（HAT）架构的无固定词表 LLM 系列，规模最大达 700 亿参数。HAT 通过编码器将字节聚合为词 embedding，主干自回归 Transformer 处理后由解码器还原为字节。研究成功将 Llama 3.1 8B/70B 转换为 HAT 架构，在无需从头训练的情况下实现了高质量的字节级生成。

INSIGHTHAT 架构摆脱固定词表的方法对生成式推荐有直接启发：生成式推荐同样面临 item 词表动态变化的挑战。HAT 的分层自回归思路——先将底层 token 聚合再在高层自回归生成——可以应用于 Semantic ID 的分层生成，解决 item 词表更新时的适应性问题。从 Llama 到 HAT 的迁移方案也为生成式推荐中复用预训练 LLM 提供了实用参考。

Aleph Alpha et al.

Adaptive Guidance for Retrieval-Augmented Masked Diffusion Models

本文提出 ARAM 框架，针对 Masked Diffusion Model (MDM) 在 RAG 场景下的检索-先验冲突问题。ARAM 在去噪过程中根据信噪比（SNR）动态校准引导强度：检索上下文可靠时增强引导，不可靠时减弱。该方法无需训练，为扩散式语言模型在检索增强场景的应用提供了新方案。

INSIGHT扩散语言模型作为自回归模型的替代范式，ARAM 展示了其在 RAG 中的独特优势：迭代去噪过程允许动态调节外部知识的影响力度。对于生成式搜推系统，这种基于信噪比的自适应引导思路，可以启发在生成式推荐中如何动态平衡模型自身知识和外部检索信号（如用户历史、item 属性）的权重。

Jaemin Kim, Jong Chul Ye

Role-Augmented Intent-Driven Generative Search Engine Optimization

本文针对生成式搜索引擎（GSE）场景提出 G-SEO 优化方法。传统 SEO 策略在 LLM+RAG 驱动的生成式搜索中失效，G-SEO 通过跨多种信息角色的反思性意图精炼来建模搜索意图，实现面向生成式检索上下文的内容优化。该方法为内容创作者在 GSE 时代提供了结构化的优化路径。

INSIGHT随着 LLM+RAG 驱动的生成式搜索引擎兴起，传统搜索优化方法需要重新设计。G-SEO 的角色增强意图建模方法表明，在生成式搜索中，内容的语义合成能力比关键词匹配更重要。对于运营 UGC 搜索的平台，理解 GSE 如何选择和合成信息，有助于优化内容展现策略。

Xiaolu Chen, Haojie Wu, Jie Bao, Zhen Chen, Yong Liao, Hu Huang
