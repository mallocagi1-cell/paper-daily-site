OPERA: Online Data Pruning for Efficient Retrieval Model Adaptation

针对稠密检索模型的领域适配问题，提出 OPERA 数据剪枝框架。研究发现静态剪枝（仅保留高相似度 query-document 对）存在排序质量与召回覆盖的固有矛盾：NDCG 提升的同时 Recall 会因 query 多样性下降而退化。为此提出两阶段动态剪枝策略，在训练过程中自适应调整 query 和 document 两个层级的采样概率，在保持对全部训练数据访问的前提下优先利用高质量样本，同时兼顾训练效率。

Negation is Not Semantic: Diagnosing Dense Retrieval Failure Modes for Trade-offs in Contradiction-Aware Biomedical QA

基于 TREC 2025 BioGen Track，系统诊断稠密检索在否定语义上的失败模式。发现「简单悖论」(Simplicity Paradox)：复杂的对抗性稠密检索策略在矛盾检测任务上表现灾难性（MRR 仅 0.023），原因是「语义坍缩」(Semantic Collapse)——否定信号在稠密表示空间中消失。研究使用 SciFact 数据集构建代理评估框架，系统优化检索架构。

INSIGHT提出稠密检索中「语义坍缩」的概念：否定词在稠密向量表示中几乎不产生区分信号，导致包含否定的查询与其对应的肯定查询检索到相同的文档。这一发现对搜索系统有直接启示——当用户 query 包含否定意图（如「不想要XXX」）时，简单的词汇匹配方法可能优于复杂的语义检索。

03 3.65

Training-Induced Bias Toward LLM-Generated Content in Dense Retrieval

研究揭示在 MS MARCO 等标准数据集上进行有监督微调后，稠密检索模型会系统性地偏向 LLM 生成的内容——在排序结果中 LLM 生成文本的排名显著高于人类撰写的同等质量文档。这种训练诱导偏差在主流检索模型上具有一致性和可复现性。

INSIGHT随着 UGC 平台中 AI 生成内容占比持续增加，这一发现对搜索系统极为重要：经过标准训练的检索模型可能不公平地偏爱 AI 生成的帖子和回答，而低估人类原创内容。在训练数据构建和排序模型评估中需要主动监控和校正这种偏差，尤其是在社区搜索等 UGC 密集场景中。

04 3.55

Visual Product Search Benchmark

面向工业场景的视觉产品搜索基准测试，系统评估了开源基础 embedding 模型、商用多模态 embedding 系统以及领域特定视觉模型在实例级图像检索任务上的表现。采用统一的 image-to-image 检索协议，在多种成像条件下测试大规模、动态演化的产品目录中精确物体实例匹配的能力。

INSIGHT该基准测试为工业级视觉搜索系统的模型选型提供了直接参考。对于同时涉及文本和图像检索的搜索系统（如社区中的以图搜图功能），了解各类 embedding 模型在实例级检索上的表现差异有助于选择合适的多模态检索方案，尤其是在产品目录持续更新的动态场景下。

05 3.55

The Reasoning Bottleneck in Graph-RAG: Structured Prompting and Context Compression for Multi-Hop QA

评估 Graph-RAG 系统发现，虽然 77%-91% 的多跳问题能在检索上下文中找到答案，但准确率仅 35%-78%，73%-84% 的错误源于推理失败而非检索失败。提出 SPARQL CoT 提示（将问题分解为三元组查询模式）和图遍历压缩（无需 LLM 调用即可压缩上下文约 60%）两种增强方法，分别带来 +2 至 +14 个百分点的准确率提升。

INSIGHT核心发现是「检索成功≠回答正确」——在 Graph-RAG 中推理才是瓶颈，而非检索。这对搜索系统设计有重要启示：当检索质量已经足够高时，应将优化重心从检索端转向生成端的推理能力。图遍历压缩技术可降低上下文长度约 60% 且不依赖 LLM，对延迟敏感的搜索场景非常实用。

Public Profile Matters: A Scalable Integrated Approach to Recommend Citations in the Wild

提出 Profiler，一个轻量级、非学习型的引用模式捕获模块，用于增强引文推荐系统的候选检索阶段。该模块无需训练即可高效建模人类引用行为模式，同时避免了现有学习方法在下游 reranker 中引入的系统性偏差。此外，指出当前引文推荐评估采用的传导式 (transductive) 设置不能反映真实场景，提出了更贴合实际的评估协议。

INSIGHT非学习型的用户行为模式建模思路值得搜索系统借鉴：通过统计方法捕获用户偏好模式（而非端到端学习），可在轻量级条件下增强候选检索，且避免学习型方法引入的偏差。该方法的无需训练特性使其特别适合需要快速部署的搜索场景。

07 3.45

From Isolated Scoring to Collaborative Ranking: A Comparison-Native Framework for LLM-Based Paper Evaluation

指出 LLM 独立打分的局限性：不同会议、时期和评估标准的分数尺度不一致，导致模型倾向于学习狭窄的上下文规则而非鲁棒的判断能力。提出 CNPE 比较原生框架，将论文评估从独立打分转向协作排序，通过基于图的相似性排序算法构建更具信息量的比较训练样本。

INSIGHT从「独立打分」到「协作排序」的范式转变，对搜索排序模型有直接借鉴意义。在搜索场景中，绝对相关性评分同样面临标注者偏差和尺度不一致问题，基于比较的 pairwise/listwise 排序方法通常更鲁棒。图结构的相似性采样方法也可用于构建高质量的搜索排序训练数据。

Learning More Effective Representations for Dense Retrieval through Deliberate Thinking Before Search

提出 Debater 方法，通过「搜索前深思熟虑」(Deliberate Thinking Before Search) 增强基于 LLM 的检索器。核心思想是在生成文档表示前引入 Chain-of-Deliberation 机制，让模型逐步思考后再编码文档，从而学习更具判别力的稠密检索表示。

INSIGHT将 Chain-of-Thought 思路引入稠密检索的表示学习，让 LLM 检索器在编码文档前先进行「思考」以提取更深层的语义特征。这种方法对于短文本场景尤为有价值——UGC 短文本的信息密度高，通过深思熟虑机制可以帮助模型捕获短文本中隐含的语义信息，提升检索质量。

09 3.45

How often do Answers Change? Estimating Recency Requirements in Question Answering

针对 LLM 在时效性问题上依赖过时知识的问题，提出基于「新鲜度-平稳性」分类法的框架，按答案变化频率和时间不变性对问题进行分类。帮助模型判断何时需要检索外部证据、如何推理过时事实、以及如何按有效性对答案排序。现有基准只定期刷新答案或依赖固定模板，而本文从答案变化频率的角度切入。

INSIGHT对搜索系统中的时效性判断提供了体系化的思考框架。在社区搜索中，不同类型的问题对内容新鲜度的要求截然不同——事实类问题可能频繁变化，而经验类问题则相对稳定。根据问题类型自适应调整检索策略（如是否使用时间衰减因子）可以在检索效果和效率之间取得更好的平衡。

PJB: A Reasoning-Aware Benchmark for Person-Job Retrieval

构建 PJB (Person-Job Benchmark)，一个面向人岗匹配的推理感知检索评估数据集。使用完整职位描述作为 query、完整简历作为 document，跨越六个行业领域，包含近 20 万份简历。从传统的 NDCG 等整体指标升级到细粒度的诊断评估，系统检测检索模型在技能迁移推理和岗位胜任力判断上的失败模式。

INSIGHT从「谁分数更高」转向「系统在哪里失败、为什么失败」的评估范式值得借鉴。在搜索系统中，通用 benchmark 上的高分可能掩盖特定场景下的系统性缺陷。构建面向具体业务场景的诊断性评估集（如 UGC 短文本搜索中的特定失败模式），比追求通用排行榜分数对改进实际系统更有价值。
