OneTrans-V2: Unifying Retrieval, Pre-rank, and Fine-rank with One Transformer in Industrial Recommender

推荐系统的召回、粗排和精排通常是三个各自训练、上线的模型，同一条用户行为序列每个阶段都要重新编码，粗排和精排还常常给同一批候选排出不同的顺序。OneTrans-V2 把三个阶段做成同一个 Transformer 的三个任务：用户历史只编码一次、三个阶段共用，各阶段的候选特征照旧保留。在一个大型工业推荐系统上，它替换原有的三模型级联后，人均 GMV 提升 9.74%，同样硬件下整条链路的 QPS 是原来的 3.2 倍。三个阶段一起训练同一份用户表征，每个阶段都比单独训练更好，这比省算力更值得关注。

SPRINT: Single-Step Generative Recommendation via Average Probability Velocity

SPRINT 把 Semantic ID 生成理解为 token 概率流的平均速度，以双向 Transformer 在单次前向中预测全部位置。针对独立生成破坏 ID 一致性的问题，联合 token 级和 SID 级流对比目标恢复约束；相对第二快的自回归或非自回归方法加速 8.39–10.04 倍，相对第二优方法平均准确率提升 7.77%。

INSIGHT社区 UGC 生成式召回的延迟瓶颈常来自多步解码，一次前向生成值得在现有 SID 目录上单独试验。位置概率预测必须配套物品级一致性监督与合法 ID 校验；论文平均准确率提升并非社区 nDCG 收益，应在同硬件、同候选规模及相同延迟预算下复核覆盖率和 CTR。

Neither Black nor White: Balancing Semantic and Collaborative Signals with Graph-Informed Semantic IDs (GrIS)

Huawei

GrIS 将 Semantic ID 构造重新表述为带语义节点与协同边的递归图划分，内容量化是空图特例。论文实现可微图池化 RecDMoN 与加入图重构目标的 RQ-GAE，分离图构造和递归划分两个可调维度；在多个真实数据集上相对含协同信号的先进方法，Hit@10 最高提升 52%。

INSIGHTUGC 搜索可把帖子内容与点击共现构成图，让生成式 ID 同时承载语义和行为信号。实施时应分别对图边质量、分层算法和内容表示做消融，避免把热门共现误当语义相关；推荐 Hit@10 不能直接代表搜索 nDCG，还需测试冷帖、长尾 query 与目录频繁更新时的 ID 稳定性。

Bootstrapping Conversational Recommendation Agents At Spotify: Synthetic Data Generation and Self-Improvement Loops

Spotify

Spotify 为对话推荐冷启动构建多轮合成对话，再利用方差驱动的对比优化与编码代理迭代修复规划、工具调用错误。相对充分优化的人工提示，离线质量提升 8%；线上相对仅支持会话细化的旧体验，收听量提升 14%、周活提升 5%、跳过率下降 5%。

INSIGHT社区搜索可将模糊查询改写为多轮澄清任务，用合成用户补齐上线前缺少交互日志的问题。优化目标应覆盖候选发现、工具参数和最终回答的证据一致性；论文线上对照是旧产品体验，不能把所有增益归因于单个提示优化组件，仍需独立评估搜索 nDCG 与 CTR。

Do Multilingual Encoders Produce Language-Consistent Semantic IDs?

AmazonRRutgers

论文用 Amazon ESCI 英语、西语和日语商品文本检查多语言编码器能否生成一致 Semantic ID。多语言 E5 与残差量化组合中，日语译文保留英语首级 ID 的比例仅 7.7%，英语改写则为 89.0%；平衡量化训练语言分布还会进一步降低跨语言前缀一致率，显示向量接近不等于离散可达。

INSIGHT社区短文本包含多语言、别名和口语改写，部署 SID 检索前应直接测量同义文本的前缀一致性，而不只测 embedding 相似度。可尝试翻译对齐监督和 codebook 使用率诊断；作者指出机器翻译会混入文本变换因素，且 ID 一致性不等同于最终检索质量，须补充真实 UGC 查询评测。

Beyond the Beam: Constructive Repair and Candidate Completion for Generative Recommendation

Beyond the Beam 研究目录扩张后合法物品 ID 落在 beam 外的召回失败，用输出不变证书区分不可修复情形，再以整数流寻找最少替换的 ID 分配。推理联合生成似然和协同证据并补全候选；在三类 Amazon 数据上，T5 的 Recall@10 相对最佳被测生成式基线提升 15.5%–46.3%，NDCG@10 提升 15.2%–44.4%。

INSIGHTUGC 帖子持续新增，生成式检索应把目录更新与候选补全作为正式模块，而非仅扩大 beam。该方法用统一评分连接候选排序和停止条件，便于分析新增帖的可达性；但全局 Top-K 证书依赖前缀界与评分假设，部署前应测量证书触发率、更新代价和端到端搜索时延。

Zhao, Zijun, Zhang, Peng, Zhang, Gang, Ma, Yuanchi, He, Hui, Niu, Zhendong

X-Rec Technical Report

ByteDance📖 深度解读 · 10 分钟 →

X-Rec 在连续物品向量空间用流匹配学习推荐分布，生成向量触发 ANN 召回，避开 Semantic ID 量化误差与逐 token 解码。方法结合锚点条件、球面黎曼流与末层交互 Transformer；吞吐比 SID 自回归方法高 3.46 倍，TikTok 垂类参与度提升 4.1484%，整体参与度提升 0.0111%。

INSIGHT对社区短文本搜索，可在现有向量索引前增加条件生成的多兴趣触发向量，降低离散 ID 迁移成本。锚点先选语义区域、后细化向量，有利于覆盖多样意图；但生成分布不保证查询相关性，应增加 query 条件并用 nDCG、CTR、召回覆盖率与 ANN 延迟共同验证。

Measuring and Mitigating Identity-Cue Preference Drift in LLM-based Recommender Systems

PromptShift 保持用户历史不变，测量身份提示导致的推荐列表成员与顺序漂移，再通过群体相对热门度定义 SliceShift 和难度加权命中指标。方法以个性化权重混合原 LLM 排序与逆群体热门度，无需训练；在两数据集、三模型的六组实验中，宏平均 SliceShift 降低 62.42%，效用代价依指标而异。

INSIGHT社区搜索若通过自然语言用户画像驱动 LLM 推荐，身份描述可能放大群体热门偏置。可先用相同历史、不同提示的对照审计，再加入轻量重排约束；应保留历史证据优先的参考列表，同时报告 nDCG、CTR 与长尾命中，避免只改善漂移指标却损害真实用户需求。

AgentWebRec: Compact Evidence Fusion over the Agent Web for Personalized Recommendation

Beihang

AgentWebRec 将 LLM 推荐看作有限证据预算下的任务时获取与融合：先增强候选语义，再检索用户私有记忆，证据不足时询问邻居代理。四个 InstructRec 领域、每域抽取 1000 用户并配九个随机负例；Books 的 NDCG@5 为 0.7483，对比 AgentCF 的 0.6718，Goodreads 达到 0.8668。

INSIGHT社区短文本搜索可借鉴候选语义引导的用户记忆检索，避免把完整历史塞入提示，并在置信度不足时补充协同证据。代理只返回任务相关摘要，可减少用户侧记忆集中化需求；但十候选随机负例评测远比全库搜索简单，必须在真实 UGC 难负例、工具预算与在线 CTR 下重新验证。

MM-VeriRec: Failure-Guided Fusion for Verifiable Agentic Multimodal Recommendation

MM-VeriRec 构建带隐含视觉约束、图文冲突和不可满足任务的推荐协议，把失败分成文本陷阱、视觉忽略与错误接受并选择修复模块。独立 CLIP 留一检测器下，电影与商品任务的视觉成功率分别为 0.7028 和 0.6111，高于普通融合的 0.5806 和 0.5000；共享验证标签的高分仅为受控上界。

INSIGHT带图片的社区帖子搜索可将用户约束拆成可核验属性，并依据错误类型决定加视觉门控、冲突处理或拒答。重要的是区分独立检测器表现与读取评测标签的上界，防止过度估计泛化；离线预计算图像属性后线上只做候选过滤，再用真实人工判断验证复杂语义条件。
