MuninAI: A Self-Hosted Agentic Framework for Independent Research Groups

研究助手把文献留在本地，再按问题调用阅读、检索和计算工具。系统同时索引语料与引用关系，并附带可重跑的评测套件。在配对文献问答上，准确率从38.7%升至87.4%。

INSIGHT固定取回几段文字，可能比不给资料更差。真正有用的是让模型按需要读原文、追踪引用并在缺证据时弃答。对内部知识助手，验收集应同时检查答案、证据位置和资料缺失后的行为。

When Does Uncertainty Measure RAG Hallucination Risk?

模型说得笃定，不代表答案有证据。作者在检索覆盖不同的条件下，检查生成概率能否识别无依据的内容。在人为插入无证据陈述的测试中，困惑度的判别曲线下面积达到0.81至0.91。

INSIGHT置信度要和证据覆盖一起看。资料缺失时，模型仍能从参数记忆生成高概率答案；多取一段真正有用的证据，风险分数才可能恢复意义。这个结果支持把证据完整性单列为监控信号。

Rajeel Ahmad Ansari, Tautik Agrahari

GLOBE: Evolving Structured Agentic Memory for E-commerce Product Optimization in Generative Search

已录用 EMNLP 2026 Workshop

商品改写代理把有效经验存成可复用的字段规则。编辑器应用规则，反思器按排名反馈修订，审核器去重并停用持续有害的行为。正文实验中，改写后排名改善的成功率比提示优化基线提高17.5个百分点。

INSIGHT把经验写成可检查的操作，比不断加长提示词更容易维护。每条规则注明能改哪些字段，再记录使用后的得失，既能去重，也能淘汰有害建议。排名收益来自实验排序器，仍受反馈模型偏好影响。

SAFE-Mem: Secure Agentic Memory with Fine-Grained Authority and Governance-Aware Retrieval

长期记忆可能把外部说法误当成用户授权。作者为每条声明标记类型、权限和适用范围，再按这些标签检索。对保留正常记忆功能的防御方案，攻击成功率比其中最强基线至少降低77%。

INSIGHT记住一句话，不等于获得执行它的权限。把来源与使用范围附在单条声明上，能让检索阶段阻断越权影响，同时留下正常事实。对社区知识助手，帖子内容与用户偏好应拥有不同的记忆权限。

Explore Separately, Adopt Selectively: Execution-Guided Tool Use over Large Tool Libraries

工具太多时，先试哪个工具会影响后续判断。作者把候选工具放进独立分支执行，再由主代理检查结果，只吸收有用证据。在工具评测集上，平均声明得分比对照提高14.37个百分点。

INSIGHT试工具的失败过程不必进入主任务上下文。隔离探索能保留不同候选的机会，也减少失败结果对后续推理的干扰。工具路由因此可以根据执行证据更新，而不是只比较名称和说明的相似度。

Build observable enterprise agentic retrieval using Managed Amazon Bedrock Knowledge Base with AWS CloudFormation

AWS

多轮知识库检索上线后，需要看清代理每步查了什么。AWS用托管知识库、工具网关和运行时串起检索循环，并用模板部署监控。示例覆盖七层观测信号；这是可复现的工程演示，没有报告答案质量提升幅度。

INSIGHT把检索质量、调用链和每次问题的成本放进同一套部署，排查才有共同依据。知识库之间的路由与库内迭代由不同层负责，错误也能分层定位。示例语料规模较小，证据质量评分因此保守。
