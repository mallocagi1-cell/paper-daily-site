ProRetrieval: Learning to Orchestrate Hybrid Search via Executable Program Synthesis

论文把混合检索从固定融合流程改写为可执行程序合成：Qwen3-4B 根据自然语言查询生成同时包含 SQL 结构化约束、文本与图像向量检索的领域专用程序，并用 SQL 逻辑代数组合候选集。模型经 GRPO 与 DAPO 训练，在亚马逊商品和 Enron 邮件基准上的 Hit@1 分别达到 0.81、0.91，高于 GPT-5.5 的 0.69、0.86。

KEY INSIGHT · 对业务意味着什么对社区短文本搜索，复杂查询常同时包含地域、时间、作者等硬约束与模糊语义意图；把过滤、集合逻辑和向量召回显式编译为程序，比固定 RRF 更容易审计和扩展。实践上可先在长尾多约束查询中引入小模型编排器，保留现有倒排与向量索引，通过执行正确性和召回命中率共同约束训练。

Requirement--Evidence Alignment for Compositional E-Commerce Queries

论文针对组合式电商查询中多个条件必须同时满足的问题，提出 REAlign 重排框架，将类型化查询需求与商品页面中的可见证据逐项对齐，避免传统相关性分数被整体主题相似度掩盖。作者在两个固定候选池电商基准上对比监督学习和策略优化方法，报告浅层排名持续提升，并减少 Top 结果中的条件违例。

INSIGHT社区搜索中的复杂 Query 同样可能包含人物、地点、时间和内容属性等联合条件，单一向量相似度容易返回主题相关却不满足关键约束的帖子。可借鉴其“需求拆解—证据定位—约束感知打分”链路，在重排阶段增加逐条件满足度特征，并重点监控 Top-K 的硬条件违例率，而不只看整体 nDCG。

Weihao Shen, Wei Chen, Fuwei Zhang, Meng Yuan et al.
