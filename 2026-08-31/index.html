PRQ-KMeans: Projection Residual Quantization for Semantic ID Tokenization

论文针对生成式检索与推荐中语义 ID 的残差量化缺陷，提出 PRQ-KMeans：先移除全局均值，再用 Top-k 相似度加权更新质心，并以投影残差替代完整码字相减。该方法在一个工业搜索数据集和四个公开推荐基准上总体最优，工业场景 HitRate 最高提升 7.4%，MRR 最高提升 11.8%。

SIGIR 2026｜统一搜索与推荐：大语言模型时代的信息获取新探索

文章解读 GEMS 统一搜索与推荐框架，通过多子空间分解和任务专家路由，将共享语义信号与搜索、推荐专属信号显式拆开，缓解联合训练中的梯度冲突。实验覆盖 Qilin、Amazon 两类数据集以及 T5-base、Qwen2.5-3B-Instruct 主干，整体达到最优或接近最优；消融表明多子空间分解是稳定收益的重要来源。

INSIGHT统一模型的主要风险不是容量不足，而是搜索相关性与推荐偏好目标在同一参数空间相互干扰。工程上可先共享底层语义表征，再为检索、排序和推荐建立轻量专家与独立校准头；对于社区搜索，建议重点监控各任务梯度夹角、单任务回退幅度和跨场景迁移收益。

LLM融合协同信息，通吃冷 / 暖启动场景

该实践针对 LLMRec 在冷启动中擅长文本语义、但在暖启动中常落后协同过滤的问题，把协同信息作为独立模态接入大模型。方案先用纯文本数据训练 LoRA 获得冷启动能力，再融合传统协同模型信号覆盖有历史交互的用户与物品，无需改动大模型主体，并强调较低的训练和推理增量成本。

INSIGHT冷启动与暖启动不必强行由单一表征解决：文本语义负责跨物品泛化，协同信号负责稳定复现真实行为偏好，二者在接口层融合更便于灰度和回滚。社区 UGC 场景可将帖子文本编码与用户—内容图嵌入并行接入，按交互稀疏度动态调节融合权重，但上线前仍需补足公开文章未给出的严格对照实验。
