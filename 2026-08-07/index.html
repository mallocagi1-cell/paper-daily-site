Recall Is Not Enough: A Reader-Context Diagnostic for Budget-Constrained Retrieval-Augmented Generation

面向固定上下文预算的 RAG，论文指出检索集 recall@k 并不等于模型真正看到答案，提出 answer-in-context 指标判断金标准证据是否存活于打包上下文。三项多跳数据集实验显示，该指标在 recall 之外带来 ΔR²=0.17–0.27；即使金标准已被召回，是否保留答案仍使 exact match 相差 4.6 倍。

Closing the Indexing-Decoding Gap in Multimodal Generative Retrieval via Prefix Retention Optimization

论文分析多模态生成式检索中 residual quantization 建立离散标识、trie beam search 解码之间的 gap，提出 PRO。它用 prefix ranking distillation、扩大 codebook 的 vocabulary scheduling、以及 geometric score fusion 改善前缀存活；在 9 个多模态检索任务上提升目标标识保留率。

INSIGHT对 UGC 搜索中的生成式召回，Semantic ID 的训练目标必须直接约束解码时的前缀竞争，否则离线索引质量可能在 beam search 中被提前截断。工程上可先复现 listwise 前缀蒸馏，再用分层词表和向量相似度重排 beam；上线前应同时看 prefix retention、召回率与解码延迟。

Yufei Chen, Zihan Wang, Yubao Tang, Yukun Zhao, Maarten de Rijke, Zhaochun Ren

MemoryCPT: An End-to-End Agent Memory Framework for Cost-Performance Trade-off

MemoryCPT 面向长轨迹 LLM 系统的上下文膨胀与重复调用，提出端到端可训练的两阶段记忆流水线：QAD 将离线记忆构建蒸馏成紧凑模型，QAR 用 RRF 检索并以 LoRA 摘要器和 GRPO 成本奖励生成查询相关上下文，同时用 Quality per Cost 衡量质量/推理成本。

INSIGHT社区搜索若引入长期用户记忆或多轮问答，可把历史压缩与在线证据选择分离，避免每次请求重跑完整 LLM 链路。QPC 适合做成本护栏：先用 RRF 保证召回，再让轻量摘要器只保留与当前 query 有关的记忆，并用质量、token 数和延迟联合验收。

Songxin Lei, Kun Ouyang, Weilin Ruan, Yuqian Wu, Zhijiang Guo, Yushi Sun, Fugee Tsung

D$^2$F-ReAG: Dynamic Decomposition and Filtering for Multi-Hop Reasoning-Augmented Generation

针对多跳 RAG 中固定深度推理带来的冗余检索与错误累积，D²F-ReAG 先判断根级推理是否可靠：可靠时直接生成答案，不可靠时才逻辑拆分子问题，并用经过验证的子推理反向修正根推理。论文在 3 个多跳基准上验证了动态分解与过滤对复杂问题处理的有效性。

INSIGHT对社区中的实体关系、帖子链路和跨文档问答，生成式检索不应默认所有 query 都执行多轮分解。可以把根推理置信度作为路由信号，形成“直答优先、失败再展开”的两级服务；同时记录子问题命中率和错误回流，防止分解层放大噪声。

Jiaoyang Li, Junhao Ruan, Shengwei Tang, Kaiyan Chang, Zhengtao Yu, Tong Xiao, Jingbo Zhu

Document Optimization for Black-Box Retrieval via Reinforcement Learning

论文把传统文档扩展改写为“面向目标检索器的文档优化”：语言模型或视觉语言模型通过 GRPO，根据黑盒检索排名改善获得奖励，离线生成更贴近 query 分布的文档表示。方法不要求访问检索器内部梯度，覆盖 single-vector、multi-vector 和 lexical 三类检索器，并在代码检索与视觉文档检索任务上验证有效。

INSIGHT这为 UGC 短文本提供了低侵入的生成式预处理路径：把帖子离线改写成更可检索的表示，而不是在线增加 LLM 重排调用。落地时要以 nDCG、召回覆盖和 query drift 同时约束 GRPO 奖励，并保留原文与生成表示的可回溯关系，避免为了检索词匹配破坏内容真实性。

Omri Uzan, Ron Polonsky, Douwe Kiela, Christopher Potts

ABSeeker: Training Long-Horizon Search Agents via Answer-Backtracked Credit Assignment

ABSeeker 用 Answer-Backtracked Credit Assignment 训练搜索 Agent，先从答案恢复中间线索，再按线索给搜索动作评分。基于 8.5k 条样本训练 Qwen3.5-4B，在 BrowseComp/BrowseComp-ZH 上得分 37.3%/39.1%，加上下文管理后升至 55.3%/52.9%，接近约 30B 模型。

INSIGHT生成式搜索的瓶颈常在“哪一步检索错了”而非最终答案监督太少。对社区搜索 Agent，可从标注答案反推关键帖子、实体和查询改写，把稀疏点击或最终正确率变成步骤级奖励；但训练与线上都要保留失败轨迹的有效动作，避免只学习成功样本的表面路径。

MOON3.0: Reasoning-aware Multimodal Representation Learning for E-commerce Product Understanding

MOON3.0 将电商商品理解从全局 embedding 提升到细粒度属性推理，针对长上下文稀释、SFT 只会模仿、局部细节在前向传播中衰减三类问题，组合多头模态融合、对比学习与强化学习，以及细粒度残差增强模块，并发布多模态电商基准 MBE3.0。实验报告其在自建与公开数据集上取得多项 zero-shot 最优。

INSIGHT社区内容的标题、图片、正文和评论同样需要细粒度属性，而不是一个不可解释的全局向量。可借鉴“融合—探索—残差保真”的三段式设计，把商品属性替换为主题、实体、质量和意图标签；上线前先用 zero-shot 属性抽取改善召回，再评估额外推理成本对 CTR/nDCG 的收益。

Toward Skill-Native LLMs: Skill Entropy for Benchmarking and Training Long-Horizon Reasoning

Toward Skill-Native LLMs 研究长程生成任务中“技能切换”带来的难度，提出 Skill Entropy 衡量相邻技能转换成本，并构建覆盖 558 个技能、9 个可验证与开放域的 Skill²-Bench。论文评测 8 个前沿模型和 4 个开源模型，发现高技能熵任务的准确率会下降，为复杂生成式搜索的路由与训练提供诊断维度。

INSIGHT社区搜索 Agent 往往要在 query 理解、召回、证据核验和回答生成之间切换，平均任务分数会掩盖某一次切换失败。可按技能序列切分日志，估计高熵转移并做专门的路由、工具提示或小模型适配；Skill Entropy 也能帮助决定哪些链路应拆成服务，哪些适合留在单一模型内。

Generate Trajectories, Reasoning Traces, and Auto-Labels with NVIDIA Alpamayo 2 Super

NVIDIA

NVIDIA 工程博客介绍 Alpamayo 2 Super 如何把轨迹生成、推理轨迹和自动标签纳入统一的数据生产流程，并将模型输出接入闭环评估与再训练。文章强调从人工标注驱动的离线训练转向“生成样本—检查推理—自动标注—迭代训练”的循环，适合作为生成式系统工程化的工业案例；公开页面未给出搜索/推荐线上指标。

INSIGHT虽然案例来自自动驾驶，但“生成候选—生成解释—自动标注—闭环验证”的接口可迁移到社区搜索：用模型生成 query 改写、相关性理由和难负例，再由规则或人工抽样做质量闸门。工程上应保留每个生成样本的来源、版本和验证结果，避免把自动标签直接回灌训练集形成反馈污染。

K-EXAONE 2.0 Technical Report

LG AI Research

K-EXAONE 2.0 是 LG AI Research 发布的开放权重多语模型，采用 750B 总参数、约 37B 激活参数的 MoE，支持 256K 上下文，并把覆盖语言从 6 种扩展到 10 种。训练包含持续预训练、难例中训和后训练，报告在 9 类实用评测上相较前代提升，重点强化推理、Agent 编码、多语和安全。

INSIGHT对中文 UGC 搜索，长上下文与多语能力可用于跨语言 query 理解、证据整合和生成回答，但 750B 规模不适合直接在线部署。更现实的路径是把它作为教师做蒸馏或离线标注，在线采用小型模型，并以激活参数、KV cache、长尾语言 nDCG 和成本共同评估。
