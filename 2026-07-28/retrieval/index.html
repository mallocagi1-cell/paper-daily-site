LoRE: Enhancing Search Relevance with Progressive Chain-of-Thought and Preference Alignment

针对电商搜索相关性判断缺乏统一推理能力定义的问题，LoRE 将任务拆成知识推理、多模态理解和业务规则三类能力，以渐进式 CoT 合成做监督微调，再用强化学习充当正则器压缩冗余推理。淘宝天猫实验中，其 Macro-F1 比 GPT-5 高 29.1%，线上相对收益提升 27%。

Joint Optimization of Relevance and Engagement in Multi-Task Ranking for E-Commerce with Efficient LLM Supervision

DoorDash📖 深度解读 · 6 分钟 →

针对单独优化点击和转化会让热门或价格锚定商品挤占语义相关结果的问题，DoorDash 在多任务排序中加入累积概率形式的序数相关性头，并用轻量 LLM 为超过 1 亿个 query-item 对生成三级标签。相关性 NDCG@10 从 0.812 升至 0.962；线上 ATCR、CVR 和成交额分别提升 1.16%、1.10% 和 0.50%。

LAMAR: An Open Language-Aware Multilingual Alignment Reranker

Korea University

LAMAR 解决多语言 RAG 重排器只看语义、忽略 query 与文档语言一致性的问题。它先用英语锚点蒸馏统一跨语言相关性分数，再以并行文档组排序损失和语言一致性偏好对齐；仅 0.6B 参数，在 XQuAD 上取得 nDCG@1 96.89、nDCG@10 98.59，在 BELEBELE 上分别达到 94.66 和 97.60。

INSIGHT多语言候选语义等价时，语言本身会影响生成答案质量，因此重排目标应把“同语种优先”作为独立约束，而不是期望相关性损失自动学会。对包含中英混排、方言或海外内容的社区搜索，可在跨语言蒸馏后加入同语种偏好损失，并保留通用 nDCG 评测，避免语言对齐提升却损害原有相关性。

Seongtae Hong, Youngjoon Jang, Jungseob Lee, Seungyoon Lee, Heuiseok Lim

Learning What Matters: Supervising Sparse Attention Routing with Causal Evidence Sets

论文指出，用稠密教师的注意力图监督稀疏路由器会把“模型看过的位置”误当成“答案真正依赖的证据”。作者通过遮蔽干预自动恢复因果证据集，无需人工标注；两跳引用任务中，注意力监督的选择器准确率仅 41%，因果证据监督达到 99%，Gemma-2-9B 在只保留两句关键证据时也从 56% 升至 99%。

INSIGHT注意力权重不等于因果相关性：教师可能关注已被忽略的旧事实，或在早期层完成中间推理后不再关注必要证据。长 UGC 文档检索或上下文路由可用遮蔽后的答案变化生成弱监督，训练 chunk 选择器直接优化因果依赖；这比蒸馏注意力更适合控制上下文预算，也能减少过时信息进入生成阶段。

Legal Nugget Extraction for Granular Retrieval over Long Jurisprudential Texts

TTCUUUFCANeuralMind

针对长判决书中真正相关论点只占很小片段的问题，论文先抽取可独立理解的法律论点 nugget，对其建立向量索引，检索后再聚合回文档排序。在四个葡萄牙语基准上，JUA-Juris 的 nDCG@10 从 0.10265 升至 0.20461，JurisTCU 从 0.20898 升至 0.32696，但在 NormasTCU 和 BR-TaxQA 上不如整文档检索。

INSIGHT细粒度语义单元并非总能替代原文：当 query 与文档中的局部论点形态一致时，nugget 能缓解长文噪声；当任务依赖完整规范或强领域编码器时，整文档仍占优。社区搜索可对长帖、问答串抽取自包含观点做召回，但应与原帖召回并行，并按 query 类型决定聚合权重，避免切片破坏上下文。

SURE-RAG: Sufficiency and Uncertainty-Aware Evidence Verification for Selective Retrieval-Augmented Generation

ZZenWeave AIGeorgetown UniversitySMU

SURE-RAG 区分“段落相关”与“证据足够”，把多个 claim-passage 关系聚合为覆盖度、关系强度、不确定性和检索质量四组可解释特征，再决定支持、反驳或证据不足。在 HotpotQA-RAG v3 上，校准后 Macro-F1 为 0.9075，高于 DeBERTa 均值池化的 0.6516 和 GPT-4o 裁判的 0.7284；30% 覆盖率下风险相对下降 37%。

INSIGHT多跳搜索不能把每段最高相关分简单做 max 或 mean：缺失关键跳、证据冲突和局部支持需要集合级判断。搜索问答系统可在生成前增加可审计的证据充分性门控，只有覆盖所有关键主张时回答；但论文在自然幻觉检测上弱于 GPT-4o，说明该门控应与通用安全检测并列，而非互相替代。

Jingxi Qiu, Zeyu Han, Cheng Huang

Synergistic multi-stage processing for enhanced context relevance in RAG architecture

CCMC University

SynRAG 组合语义切分、LLM 改写后的稠密召回、POS 与 LLM 双路关键词抽取、去重融合和神经重排，并用 PostgreSQL pgvector、批处理与缓存控制成本。系统先取 20 个语义候选，再补充关键词候选并归一化融合；在 NarrativeQA 上报告 95.3% faithfulness 和 96.1% answer relevancy，代码与实现配置已公开。

INSIGHT该方案的价值不在单个新模型，而在可落地的多阶段检索编排：语义召回覆盖表达变化，关键词通路保护专有名词和精确匹配，融合去重后再把昂贵重排留给小候选集。社区搜索可复用这一架构，但应先用真实 UGC 查询离线校准每路权重与 Top-K，论文的 RAG 指标不能直接等同于线上 nDCG 或 CTR。

Luyen Nguyen Tien, Binh Hoang Tieu

Entities as Retrieval Signals: A Systematic Study of Coverage, Supervision, and Evaluation in Entity-Oriented Ranking

MMissouri S&T

论文用 TREC Robust04 系统比较 6 个神经实体重排器、437 个无监督配置和 BM25，解释实体检索研究为何常出现条件评测好、开放世界评测差的矛盾。443 个系统在真实候选集上的 MAP 改善都不超过 0.051；即使理想选择，实体信号也只覆盖 19.7% 的相关文档，瓶颈来自实体通道而非排序架构。

INSIGHT实体与 query 在概念上相关，不代表它在当前语料和实体链接器下具有区分力；只优化语义相关标签会牺牲覆盖率，却未必改善端到端排序。UGC 搜索若引入话题、作者、地点等实体信号，应同时报告实体覆盖率和整体 nDCG，并在开放候选集上评测，不能用先筛出含实体文档后的条件收益代替真实线上价值。

When LLM Judges Inflate Scores: Exploring Overrating in Relevance Assessment

University of Queensland

论文在 TREC DL2019/2020 上比较 Gemma、Llama、Mistral、Qwen 四个开源模型的点式和成对相关性判断。细粒度分级评测中，过度打分比例达到 44.59%–66.51%，显著高于二分类；成对判断的矛盾平局率约 24%–45%，模型对正确和错误判断都保持很高置信度，并受文本长度与表面词重合影响。

INSIGHTLLM 适合扩展粗粒度相关性标注，但不能未经诊断就替代人工分级判断，尤其会把“相关但不满足需求”的文档抬高。搜索团队应保留二分类与分级两套校准集，监控 overrate、Cohen’s kappa 和顺序翻转平局；对 query 词注入、长度变化做压力测试，再决定 LLM 标签能否进入训练或离线评测。

Chuting Yu, Hang Li, Guido Zuccon, Joel Mackenzie, Teerapong Leelanupab

Benchmarking Fine-tuning and Retrieval Strategies for a Multimodal Language Model on the NRC Reactor Operator Licensing Examination

论文在 2015–2021 年 14 套 NRC 反应堆操作员考试上比较 Gemma 4 31B-IT 的 8 种微调与检索组合，包括 SFT、BM25 RAG、RAFT，以及固定窗口和结构感知切分。SFT 加固定窗口 RAG 通过 14 套中的 8 套，总准确率 79.7%、压水堆题目 80.2%；未微调配置均未达到 80% 及格线，RAFT 也不如普通 SFT。

INSIGHT切分策略与训练状态存在耦合，不能把“结构感知切分一定更好”当作通用结论；模型经过 SFT 后，最优检索配置可能反转。虽然核工业场景与社区搜索较远，但其受控实验提示：应在相同语料、相同召回器下联合比较 SFT、RAG、RAFT 和 chunking，防止把训练收益误归因于检索模块。

Isak Hwang, Yoon Pyo Lee
