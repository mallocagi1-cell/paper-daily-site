下一代搜索智能体评测基准！美团开源LoHoSearch，用知识图谱校准AI能力认知

针对 BrowseComp 已被顶尖模型刷到 90% 以上、难以区分长程搜索能力的问题，美团从 762 万实体、2.65 亿条边的维基知识图谱自动采样树形与图形约束，构建 544 道人工核验题目。GPT-5.5 仅得 34.74%；正确轨迹平均工具调用从 35 次增至 61 次，最佳上下文策略只提升 6.8 个百分点。

Bridge Evidence: Static Retrieval Utility Does Not Predict Causal Utility in Multi-Step Agentic Search

University of CalcuttaMMissouri S&T

论文用 ReAct 智能体重放 1000 道 HotpotQA 问题，对每篇已读文档做删除干预，以答案质量、下一跳检索质量和轮数变化定义反事实轨迹效用。23,322 个文档观测中，静态效用与因果效用几乎独立（Spearman ρ=-0.026），35.7% 文档属于静态低分却决定后续路径的“桥接证据”。

INSIGHT多步搜索中的好文档不一定直接包含答案，它可能只提供能改写下一条 query 的关键实体；高 OER 实体进入下一跳查询的概率是非区分实体的 4.02 倍。搜索系统若仍按单轮相关性训练 retriever，会系统性漏掉这类路径价值，实践上应增加轨迹级反事实标签或实体区分度特征。

Debayan Mukhopadhyay, Utshab Kumar Ghosh, Shubham Chatterjee

SearchOS-V1: Towards Robust Open-Domain Information-Seeking Agent Collaboration

AAnt GroupRenmin University of China

SearchOS 将开放域搜索建模为带引用的关系模式补全，把前沿任务、证据图、覆盖图和失败记忆外置为共享状态，再用流水线并行调度与中间件治理多智能体执行。系统在 WideSearch 获得 80.3 Item F1，在 GISA 获得 76.5 Set F1，后者超过最强基线 13.4 个点，并开放代码与 280 个分层搜索技能。

INSIGHT论文把长程搜索最易丢失的“还缺什么、证据来自哪里、哪些路径已失败”从对话上下文搬到可审计状态机，避免智能体靠记忆反复推断。社区搜索的深度问答可直接借鉴 coverage map 与 failure memory：按字段缺口派发子任务、原子提交证据，并在无覆盖增长时由中间件强制纠偏或停止。

Rethinking Agentic RAG: Toward LLM-Driven Logical Retrieval Beyond Embeddings

LogicalRAG 让 LLM 生成可执行的逻辑检索表达式，后端仅用倒排索引与 BM25，而非稠密向量或知识图谱。KILT 规模上其平均评判分与混合 Agent 基本持平（0.717 对 0.716），离线构建仅 1.27 小时，对方需 52.02 小时；并发 16 时达到 152.5 QPS、74.9ms，吞吐高 2.3 倍、延迟低 3.1 倍。

INSIGHTAgentic RAG 未必需要更复杂的检索后端，关键是让模型把推理意图变成可控、可修复的词法约束。答案缺失实验中，LogicalRAG 将平均幻觉率从 12.8% 降至 8.3%，说明“失败的逻辑查询”也是明确的无证据信号；对短文本社区搜索，可先用布尔条件、字段过滤和 BM25 构建低成本 Agent 接口。

Yuqi Zeng, Qixiang Deng, Yulei Wan, Ruiquan Jiang, Xiaoqing Zheng, Xuanjing Huang

WebSwarm: Recursive Multi-Agent Orchestration for Deep-and-Wide Web Search

KuaishouRenmin University of China

WebSwarm 在推理过程中动态创建搜索节点，每个节点绑定局部目标与深搜、广搜或实体收集模式，并通过父子委派、证据回传和同级经验复用同时扩展深度与覆盖。以 GLM-4.5 为底座，BrowseComp-Plus 准确率 68.0%，比 ReAct 高 17.5 点；WideSearch Item F1 达 74.37%，高 9.76 点。

INSIGHT固定在根节点一次性拆题，无法利用中途发现的新实体和约束；递归委派允许搜索树随证据生长。消融中去掉递归后 BrowseComp-Plus 从 68.0% 降至 63.5%，去掉 web-probing 则工具调用从 137.03 激增至 239.90，表明结构化委派与轻量探路应同时设计，才能控制深度搜索成本。

Molt: A Scalable PyTorch-Native Training Framework for Agentic Reinforcement Learning

NVIDIA

Molt 用单一 PyTorch/FSDP2 后端、vLLM rollout 与 Ray 异步队列贯通多轮工具调用、VLM 和 MoE 的 Agent RL 训练，并以 token 身份、策略版本和前向一致性三项不变量避免静默偏差。16 张 H100 的匹配实验中，每步 119.4±2.3 秒，对 Megatron/slime 的 109.5±10.3 秒统计相当，同一循环已跑通 700B MoE。

INSIGHTAgent RL 研究迭代慢，往往不是算法而是多后端胶水造成的；Molt 让 agent 保持普通 Python 程序，奖励函数和轨迹协议可直接修改，同时明确拒绝在未生成 token 上训练。对要尝试搜索策略 RL 的团队，它适合作为可读、可追踪的实验底座，但论文也披露 128-expert 检查点存在约 1 nat 前向偏差，收敛等价性仍待验证。

Six Agent Harness Capabilities for Higher Model Performance

NVIDIA

NVIDIA NOOA 把智能体定义为单个 Python 类，以类型化输入输出、对象引用传递、代码即动作、可编程循环、显式状态和模型可调用 Harness API 统一执行与记忆。通用 253 行 agent 在 SWE-bench Verified 达 82.2%，超过当时 79.2% SOTA；每题约 110 万 token，对比 Harness 需 220 万 token 才达 78.2%。

INSIGHT相同模型仅改变 Harness 就能出现两位数分差，说明上下文渲染、状态和终止条件应作为模型能力的一部分共同评测。对搜索 Agent，可将长文档和工具结果按引用保留在运行时，只给模型有界预览；NOOA 在 ARC-AGI-3 中类型化 SQLite 记忆比文件笔记提高 11.8 点，也支持跨会话可审计与多 Agent 共享。

Ricardo Silveira Cabral, Paul Furgale

Ground Truth First: A Longitudinal Evaluation Instrument for Agent Memory, and the Tenure Crossover in Memory-Architecture Rankings

论文先生成带有效期、波动类别和来源通道的事实脚本，再渲染对话与邮件，从源头避免记忆基准的标签污染；语料含约 380 道题、15 类任务。五种记忆架构显示明显期限反转：三周领先的预算映射到九周召回由 96% 跌至 72%，而带来源类型的图记忆升至 90%，六个用户上反转均成立。

INSIGHT短期最优的记忆结构可能在长期部署中失效，原因是预算淘汰会删除仍有效但暂时不活跃的事实；搜索 Agent 的用户偏好、查询历史和证据缓存也有同样风险。建议把事实有效期、发送/接收来源和冲突关系作为一等字段，并分别做三周与九周回放测试，而不是只在短会话问答上选架构。

TASR: Training-Free Adaptive Stopping for Iterative Retrieval

San Diego State University

TASR 用一条可审计停止规则控制迭代检索：连续两轮答案稳定，且经等距校准的首 token logit margin 超过固定阈值 0.25 即停止，无需训练控制器。三模型×两数据集上，其宏平均 F1 为 57.40、平均 3.13 次调用，比固定三轮高 3.42 F1；同时保留固定五轮 94.8% 的效果，只用其 62.6% 调用。

INSIGHT迭代检索的预算控制可先从“答案轨迹稳定性 + 模型内部 margin”做起，不必立即训练 value head。规则原样迁移到 9 个 BM25、9 个稠密检索配置和 550B 模型均无显著退化；反而加入 cross-encoder 停止信号会损失 4–14 F1，提示检索相关性不能替代“当前证据是否足以支撑答案”的判断。

Adrian Kieback, Uyiosa Philip Amadasun, Aman Chadha, Aaron Elkins

Skill Self-Play: Pushing the Frontier of LLM Capability with Co-Evolving Skills

Alibaba

Skill-SP 让任务提出者、求解器和动态技能控制器在 RL 自博弈中共同进化：技能提供可验证结构，开放探索保持任务多样性，控制器依据执行反馈扩充技能库。方法在 API-Bank、BFCL 与 ZebraLogic 上覆盖 5 个 3B–14B 底座且全部提升；Qwen3-4B 工具调用平均增 6.5 点，原本不对齐的 Ministral-3-8B 提升 42.9 点。

INSIGHT技能可以作为开放任务生成与可靠验证之间的中间层：提出者围绕求解成功率约 50% 的能力边界造题，机器可读契约负责验真，避免无约束自生成把错误奖励带入 RL。对搜索 Agent，可把查询改写、站点访问、证据核验等拆成可执行技能，让失败轨迹反向更新技能库并持续生成刚好有学习价值的任务。
