SIREN (Luring LLMs onto the Rocks): PAIR-Driven Preference Manipulation in Web-RAG Recommenders

论文聚焦带网页检索的 LLM 推荐结果可被源页面内容操纵的问题，提出 SIREN：借鉴 PAIR 越狱循环，由攻击者—裁判自动迭代 23 类内容投毒策略，并用固定来源、固定顺序的自定义 RAG 重放隔离检索波动。在两个生产 Claude 模型、8 个查询—模型场景的 124 次试验中，62 次将目标推至第 1 名；成功载荷在新会话的平均复现率为 80.5%。

Enhancing Ad Relevance: Integrating Real-Time Context into Sequential Recommender Models

Pinterest

Pinterest 针对离线序列用户向量缺少请求时上下文，在 Transformer 双塔 query 侧加入实时 context layer，以正样本合成上下文训练，并采用“离线序列编码＋在线 context/MLP”混合推理。上线后 Recall@K 提升 3–10 倍，中位相关性提高约 275%–300%，交付候选翻倍，整体广告相关性提升 1.08%，ROAS 约提升 0.7%（主要国家 1.4%）。

INSIGHT这项实践给生成式与长序列推荐的现实提醒是：长历史不能替代当下意图，且无需把整段 Transformer 搬到在线路径。社区搜索可离线缓存用户历史表征，在线只融合当前 query、主题与场景信号；合成上下文配合高 dropout 能避免模型过度依赖即时信号，后续可用 query 作为 cross-attention 去选择最相关的历史片段。

Huiqin Xin, Lakshmi Manoharan, Karthik Jayasurya, Ziwei Guo, Alina Liviniuk

The Prompt Is Not the Query: How Request State Evolves Across Multi-Turn AI Conversations

AAiso

论文指出多轮 AI 搜索中末轮提示不是稳定 query，而只是对会话请求状态的一次增量更新。作者分析 670 个商业多轮会话和 PRISM 中来自 1,389 名参与者的 7,463 个会话；末轮仅覆盖全会话用户侧独特词汇的中位数 35.6%/36.4%，50.3%/44.8% 的会话仍有显式需求维度只留在历史中，完整复现状态的比例仅 26.1%/26.2%。

INSIGHT生成式搜索或对话推荐若只把末轮送入召回与排序，会系统性丢失预算、位置、属性、纠错和证据要求等约束。可将会话状态显式维护为累积维度集合，为每轮生成可审计的独立检索表示，并按 session 而非 prompt 评估；但研究只测状态分布，未做有无历史的答案因果对照，不能直接推断线上指标增益。

Benjamin Tannenbaum
