REDSI: Addressing the Reproducibility and Evaluation Consistency of Differentiable Search Indexing for Document Retrieval

论文针对 DSI 基线难以复现、NQ320K 构造口径不统一的问题，发布覆盖原子、任意数字和语义三类标识符的 ReDSI，并拆分文档去重与文本序列化流程。在 Title/NciNorm 设置下，4400 万参数原子模型的 MRR@10 达到 62.2，超过 2.2 亿参数的任意数字标识符模型 60.1 和 Semantic ID 模型 59.7。

Exploring Bottom-Up Clustering for Creating Semantic IDs

PayPalCornell

论文用自底向上聚类构造 Semantic ID：先保留商品向量的局部邻域，再逐层合并加权质心，并通过叶内编号保证唯一性。在约 600 万商品的自建数据上，Recall@10 从 0.020 增至 0.036；Beauty 的 NDCG@10 从 0.0255 增至 0.0296，但 Sports 的同一指标从 0.0169 降至 0.0166。

INSIGHT可将该方法用于社区帖子 Semantic ID 的离线构建，重点验证近邻保持、碰撞率及新增帖子的编号稳定性。Sports 上的退化说明轮廓系数改善并不保证检索收益；应同时监控长尾覆盖与 nDCG，并把聚类分裂造成的 ID 迁移纳入更新成本评估，不能仅凭唯一性或单个数据集结果决定替换码本。
