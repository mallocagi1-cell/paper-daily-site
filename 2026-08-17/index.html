APAO: Bridging the Training-Inference Gap in Generative Recommendation via Adaptive Prefix-Aware Optimization

APAO 针对生成式推荐训练采用 teacher forcing、推理却采用 beam search 所造成的前缀错配：正确物品可能因早期 token 概率低而提前出局。方法加入 prefix-level 优化损失，并动态聚焦最脆弱的 worst prefix；论文在多个生成式推荐骨干上验证效果，实验使用 batch 1024、beam size 20 和单张 A100，并被 KDD 2026 接收。

KEY INSIGHT · 对业务意味着什么生成式召回的优化目标必须模拟线上 beam search 的真实分支裁剪，而不是只优化完整目标序列的 token likelihood。对社区搜索或推荐场景，可先统计候选在不同前缀深度的淘汰率，再把前缀保留率作为辅助训练信号；这种改造比扩大 beam 或盲目增加模型参数更容易形成可控实验。

LLM Retrieval for Stable and Predictable Ad Recommendations

论文把广告素材解析为分层语义属性，再用微调 LLM 生成语义表征，并通过图扩展召回语义相近的候选，以改善推荐系统的稳定性与可预测性。作者在大规模工业广告系统中同时做离线评测和线上 A/B，重点验证语义变体的一致投放与传统效果指标，而不是只看单次点击率。

INSIGHT对 UGC 短文本搜索，LLM 表征的价值不应只用相似度衡量，还要检查同义改写、轻微内容变化是否导致候选集合剧烈抖动。可以借鉴其“层级语义属性 + 图扩展”做稳定性回归测试，把候选集合重合率、曝光波动和 CTR 一起纳入上线门槛，降低语义模型不可解释的投放风险。

03 3.75

OneReason Technical Report

快手📖 深度解读 · 10 分钟 →

OneReason 研究 OneRec 在短视频、直播、广告和电商四类推荐场景中如何激活显式推理能力。它先用 itemic token perception 预训练让语义 ID 与真实内容对齐，再用三层 cognition-enhanced CoT 做监督微调，最后采用 specialize-then-unify 的强化学习配方；报告指出，仅堆叠 item token 的 thinking mode 并不会自然带来收益。

INSIGHT推荐系统的 reasoning 不应直接照搬文本 CoT，关键是让离散 item token 先获得可解释的内容语义，再把用户行为压缩成稳定的兴趣节点。对社区搜索可把 query、帖子实体和行为序列放入同一语义 ID 空间，先验证意图聚类与可追溯性，再尝试 RL 优化，避免在错误的 token 表示上增加推理预算。

OneRec Team, Biao Yang, Boyang Ding, Chenglong Chu, Dunju Zang, Fei Pan, Han Li
