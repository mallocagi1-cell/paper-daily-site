Semantic Trimming and Auxiliary Multi-step Prediction for Generative Recommendation

生成式推荐把每件商品拆成几个 Semantic ID 码之后，用户历史一下子长了好几倍，训练又慢又占显存，而多出来的码里很多是重复的类目和品牌。STAMP 让模型先跑一两层，再按每个码自身的激活强度和被其他码关注的程度打分，只把高分的码交给后面的层；训练时再加一个多预测一个码的辅助目标，补回剪掉的信息。在 Amazon 三个数据集上，训练快了 1.36 倍以上，峰值显存省了一半多，效果和原模型持平。它省的是训练成本，不是提效果：在工业数据上，只加辅助预测反而最准，加上剪枝后这点提升就被抵消了。

Rethinking Generative Recommender Tokenizer: Recsys-Native Encoding and Semantic Quantization Beyond LLMs

📖 深度解读 · 12 分钟 →

现有 Semantic ID 推荐方法大多沿用语义中心流水线——从基础模型学习 embedding 再用通用量化离散化，但这种设计与生成式推荐目标存在错位：语义 embedding 与协同预测弱耦合，通用量化在减少序列不确定性方面效率低下。本文提出 ReSID，包含两个核心组件：(1) Field-Aware Masked Auto-Encoding (FAMAE)，从结构化特征学习预测充分的物品表示；(2) Globally Aligned Orthogonal Quantization (GAOQ)，通过联合减少语义歧义和前缀条件不确定性生成紧凑可预测的 SID 序列。代码已在 GitHub 开源。

INSIGHTReSID 的关键洞察是：生成式推荐的 tokenizer 不应简单搬用 NLP/CV 领域的通用量化方案，而应从推荐系统原生视角设计——关注信息保留和序列可预测性。FAMAE 利用结构化特征（而非通用语义模型）学习与推荐任务对齐的表示，GAOQ 则在量化阶段同时优化语义清晰度和自回归可预测性。这为搜索推荐系统中的 item tokenization 提供了一条不依赖大语言模型的高效路径。
