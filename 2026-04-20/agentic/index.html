Mind DeepResearch Technical Report

理想汽车发布的多智能体深度研究框架技术报告。系统采用三智能体协作架构：Planning Agent 负责任务分解与规划、DeepSearch Agent 负责多轮搜索与信息抽取、Report Agent 负责生成结构化研究报告。训练流程分四阶段：SFT 冷启动、Search-RL（优化搜索策略）、Report-RL（优化报告生成）和偏好对齐。模型规模约 30B，在 BrowseComp-ZH 上达到 45.7%、BrowseComp 上 42.8%、自建 MindDR Bench（500 条真实中文查询）上 51.8 分。该系统已作为商业产品在理想汽车部署。

Enhancing LLM-based Search Agents via Contribution Weighted Group Relative Policy Optimization

FFudan University (复旦大学)

该论文提出 CW-GRPO（Contribution Weighted Group Relative Policy Optimization），将过程监督引入搜索智能体的强化学习训练。核心思路是在每一轮搜索交互中，利用 LLM 判断器评估检索效用和推理正确性，生成逐轮贡献分数，实现细粒度的信用分配。这解决了传统 GRPO 只能在最终结果上计算奖励的稀疏反馈问题。在多个知识密集型基准上分别取得 5.0% 和 6.3% 的性能提升。已被 ACL 2026 录用。

INSIGHTCW-GRPO 的关键创新在于将搜索 Agent 的每一步操作（发起搜索、选择结果、推理整合）都纳入奖励建模，而非仅对最终答案打分。这对构建可训练的搜索 Agent 有两个重要启示：(1) 过程监督比结果监督更适合多步搜索场景——agent 可能在某一步做了正确检索但后续推理失误，逐步贡献分数能准确归因；(2) 使用 LLM 作为判断器进行自动过程评估，避免了人工标注过程奖励的高成本。该方法可直接迁移到 agentic RAG 系统的策略优化中。

Junzhe Wang, Zhiheng Xi, Yajie Yang, Hao Luo, Shihan Dou, Tao Gui, Qi Zhang

03 3.50

Knowledge Graph RAG: Agentic Crawling and Graph Construction in Enterprise Documents

该论文针对传统语义搜索在复杂企业文档中无法捕获层级化、互联信息的问题，提出 Agentic Knowledge Graph（智能体驱动的知识图谱）方法。核心技术是递归爬取（Recursive Crawling）机制，能够处理文档间的替代逻辑和多跳关联。以美国联邦法规（Code of Federal Regulations）为测试场景，相比标准向量检索 RAG 系统，准确率提升 70%。该方法将 Agent 的主动探索能力与知识图谱的结构化表征结合，用于增强 RAG 系统的上下文理解。

INSIGHT该工作的核心思路是让 Agent 在构建 RAG 索引时主动探索文档间关系，而非被动地逐文档向量化。对搜索系统的实践启示：(1) 对于结构化或半结构化文档（法规、技术手册、政策文件），基于向量相似度的平面检索会丢失文档间的引用和层级关系，知识图谱可以补充这类结构信号；(2) Agentic 爬取策略允许系统动态发现相关文档，适合处理文档间存在复杂交叉引用的场景；(3) 70% 的准确率提升主要源于多跳推理能力，提示在 UGC 社区中处理引用关系密集的内容（如问答帖的追问链）时可借鉴类似思路。

Koushik Chakraborty, Koyel Guha

04 3.50

What Is Your AI Agent Buying? Evaluation, Biases, Model Dependence, & Emerging Implications of Agentic E-Commerce

已录用 WWW 2026Columbia University

WWW 2026 论文，系统研究了 AI Agent 在电商购物场景中的行为模式。论文评估了 LLM 驱动的购买 Agent 在商品选择中的偏差（bias）、对底层模型的依赖性（model dependence），以及 Agent 代理购物对电商生态的影响。研究发现 Agent 的购买决策存在系统性偏差——不同 LLM 对同一购物任务的商品偏好差异显著，且 Agent 决策不总是符合用户真实偏好。

INSIGHT该研究对搜索/推荐系统从业者的核心警示：当 AI Agent 代替用户进行搜索和购买时，传统的推荐和排序优化策略可能失效——Agent 的偏好模式与人类用户不同，且高度依赖底层 LLM 的特性。对业务的启示：(1) 电商搜索系统需要考虑 Agent 用户的涌现——SEO 和排序策略可能需要适配 Agent 的决策逻辑；(2) Agent 的模型依赖性意味着不同 LLM 驱动的 Agent 对搜索结果的响应不一致，这对 A/B 测试和用户分群带来新挑战；(3) 为 Agent 设计专门的搜索接口可能成为新的产品方向。

Amine Allouah, Omar Besbes, Josué D. Figueroa, Yash Kanoria, Akshit Kumar
