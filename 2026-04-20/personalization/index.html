GenRec: A Preference-Oriented Generative Framework for Large-Scale Recommendation

针对大规模推荐系统中生成式检索的扩展性难题，提出 GenRec 框架，包含三项核心创新：Page-wise NTP 任务将监督粒度从单个 item 提升到整页交互序列，非对称线性 Token Merger 将输入长度压缩约 2 倍，GRPO-SR 强化学习方法结合策略优化与奖励机制进行排序优化。已在京东 App 全量部署，线上 A/B 测试点击量提升 9.5%，成交量提升 8.7%。

Decoupled Multimodal Fusion for User Interest Modeling in Click-Through Rate Prediction

LazadaAlibaba📖 深度解读 · 8 分钟 →

提出 DMF（Decoupled Multimodal Fusion）方法，增强 ID 协同表征与多模态表征之间的细粒度交互。核心设计包括 target-aware 特征桥接不同 embedding 空间的语义鸿沟，以及解耦注意力机制降低计算开销。在 Lazada 电商平台实际部署，CTCVR 提升 5.30%，GMV 提升 7.43%。已被 ICDE 2026 录用。

INSIGHTDMF 的核心贡献在于解决多模态推荐中 ID 特征与内容特征的「语义鸿沟」问题——通过 target-aware 特征构建让两类表征在目标 item 维度上对齐。这对 UGC 搜索场景有直接启示：用户搜索行为（ID 特征）与帖子内容（文本/图片特征）之间也存在类似的表征脱节问题。解耦注意力设计将多模态融合的额外推理开销控制在可接受范围内，适合在线服务部署。

Alin Fan, Hanqing Li, Sihan Lu, Jingsong Yuan, Jiandong Zhang

Well Begun is Half Done: Training-Free User Representation Initialization for Multimodal Recommendation

HKU

提出 SG-URInit，一种免训练、模型无关的用户表征初始化方法。通过整合用户交互 item 的模态特征和对应聚类的全局特征来构建初始用户表征，缓解冷启动问题并加速模型收敛。该方法可即插即用地集成到现有多模态推荐系统中，无需额外训练开销。已被 SIGIR 2026 录用。

INSIGHTSG-URInit 提供了一种零成本提升冷启动性能的思路：利用已有 item 模态特征和聚类结构为新用户生成高质量初始表征。对 UGC 搜索场景，这意味着新注册用户无需积累大量行为数据即可获得较好的个性化体验。模型无关的设计使其可与任意现有排序模型叠加使用，工程落地门槛低。

Jinfeng Xu, Zheyu Chen, Shuo Yang, Jinze Li, Hewei Wang, Jianheng Tang, Wei Wang, Xiping Hu 等 9 人

LRSA: LLM-RecSys alignment for time-specific next POI recommendation

提出 LRSA 框架实现 LLM 与推荐系统的语义空间对齐。核心包含四个组件：influential trajectory collector 识别有影响力的历史轨迹，rotational alignment 将 RecSys 的 ID 空间与 LLM 的语义空间旋转对齐，fusion prompt 融合两类信息，hierarchical prompt tuning 实现分层微调。在 POI 推荐任务上验证了 LLM-RecSys 联合建模的有效性。

INSIGHTLRSA 的旋转对齐机制是连接 ID-based 推荐模型和 LLM 世界知识的有效桥梁。对搜索推荐系统而言，这提供了一条将已有排序模型的用户偏好知识迁移到 LLM 框架中的技术路径，避免从零训练 LLM-based 推荐系统。轨迹采集器的设计思路——从长历史中筛选「有影响力」的子序列——对长序列用户行为建模具有借鉴意义。

Jinhui Zhu, Xiangfeng Luo, Xin Yao, Xiao Wei

SAGER: Self-Evolving User Policy Skills for Recommendation Agent

提出 SAGER 框架，为每个用户维护独立的策略技能文档（policy skill），编码个性化决策原则并通过交互持续演化。核心设计包括双表征架构将丰富的演化基底与轻量推理注入分离，对比链式推理（contrastive CoT）增强决策质量，技能增强的 listwise 推理实现个性化排序。实验证明个性化推理过程本身是推荐提升的独立增量来源。

INSIGHTSAGER 的核心洞察是：仅仅个性化用户记忆是不够的，推理策略本身也需要个性化。每个用户拥有独立演化的决策文档，这比统一的推理模板更能捕捉个体差异。虽然目前依赖 LLM Agent 基础设施（落地门槛较高），但「个性化推理策略」的思想可以启发传统推荐系统——例如为不同用户群体学习不同的排序策略网络。

Zhen Tao, Riwei Lai, Chenyun Yu, Weixin Chen, Li Chen, Beibei Kong, Lei Cheng, Chengxiang Zhuo 等 10 人

Continuous-time Discrete-space Diffusion Model for Recommendation

PolyU

提出 CDRec，首个在离散空间上进行连续时间扩散建模的推荐框架。不同于现有方法在连续编码空间上操作（可能造成信息损失），CDRec 直接在用户历史交互的离散空间上建模扩散过程。通过连续时间公式避免了离散扩散步数的限制，能更灵活地建模用户偏好的动态演化。WSDM 2026 录用。

INSIGHTCDRec 将扩散模型从连续表征空间迁移到离散交互空间，避免了编码-解码过程中的信息损失。这一思路对推荐系统的启示在于：用户行为本质上是离散事件序列，直接在原始空间建模可能比先编码为连续向量再生成更有效。连续时间公式也允许模型自然地处理不等间隔的用户行为时间戳。

Chengyi Liu, Xiao Chen, Shijie Wang, Wenqi Fan, Qing Li

From Insight to Intervention: Interpretable Neuron Steering for Controlling Popularity Bias in Recommender Systems

TU Delft

提出 PopSteer 方法，在神经元层面解释和控制推荐系统中的流行度偏差。训练 Sparse Autoencoder (SAE) 附加到模型最后一层，通过合成用户画像识别编码流行度信号的神经元，再调整这些神经元的激活值来减弱流行度偏差、增强长尾内容曝光。无需重训模型，即可在推理阶段动态调节偏差程度。WWW 2026 录用。

INSIGHTPopSteer 提供了一种事后可解释干预的范式——先理解模型内部哪些神经元编码了偏差信号，再精确调控。这比传统的重采样或正则化方法更灵活、可控。对 UGC 搜索场景，该方法可用于平衡热门内容与长尾 UGC 的曝光，提升内容生态多样性。SAE 的方法论也可迁移到搜索排序模型的可解释性分析中。

Parviz Ahmadov, Masoud Mansoury

Adaptive Continual Learning with User-Incremental Forward Compatibility for Meta-Augmented Cold-Start Recommenders

针对推荐系统冷启动场景中新用户不断涌入的挑战，提出自适应持续学习方法，结合元学习实现对新用户的前向兼容。核心思路是在持续学习框架中引入用户增量的前向兼容性约束，使模型在学习现有用户偏好的同时保持对未来新用户的泛化能力。WSDM 2026 录用。

INSIGHT该工作将冷启动问题重新定义为持续学习中的前向兼容性问题——模型不仅要记住老用户，还要预留对新用户的适应能力。这一视角对 UGC 社区平台的用户增长场景非常贴切：新用户持续加入，模型需要在不遗忘老用户偏好的前提下快速适配新用户。元学习增强的设计降低了新用户适配所需的交互次数。

Chunyang Wang, Xuhao Zhao, Wenze Ma, Zhaobo Wang, Yanmin Zhu

Behavior-Aware Dual-Channel Preference Learning for Heterogeneous Sequential Recommendation

针对异构行为序列推荐中辅助行为带来的数据稀疏和噪声问题，提出双通道偏好学习框架。构建个性化行为感知子图捕捉行为转移关系，使用级联 GNN 聚合节点上下文信息，通过偏好级对比学习建模长短期偏好，最终用自适应门控机制融合多粒度偏好信号。在三个真实数据集上验证有效性。

INSIGHT该方法的关键创新在于将异构行为（点击、收藏、购买等）的转移模式建模为个性化子图，而非简单地拼接或加权。对 UGC 搜索场景，用户的浏览、点击、收藏、评论等多种行为同样构成异构序列，该方法的行为转移建模和双通道融合思路可直接应用于多行为用户建模。对比学习在长短期偏好间的应用也提供了处理用户兴趣漂移的有效手段。

Jing Xiao, Dongqi Wu, Liwei Pan, Yawen Luo, Weike Pan, Zhong Ming

Have We Really Understood Collaborative Information? An Empirical Investigation

Leiden UniversityShandong University

系统性地研究推荐系统中协同信息的本质，填补三个认知空白：缺乏协同信息的量化定义、不清楚其在用户-物品交互中的表现形式、以及对推荐性能的影响机制不明。从 item 共现模式出发提出量化定义，并通过大规模实证分析揭示简单协同关系更容易被模型捕获和利用。WSDM 2026 录用（接受率 16.3%）。

INSIGHT这项工作为推荐系统实践者提供了重要的认知工具——理解「协同信息」到底是什么以及如何量化它。核心发现是简单的 item 共现模式对模型性能贡献最大，这意味着在工程实践中应优先确保模型能充分捕获这些基础共现信号，而非一味追求复杂的高阶交互建模。对 UGC 搜索场景，这启示我们关注用户搜索-点击的基础共现模式。

Xiaokun Zhang, Zhaochun Ren, Bowei He, Ziqiang Cui, Chen Ma
