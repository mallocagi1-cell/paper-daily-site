Search-R3: Unifying Reasoning and Embedding Generation in Large Language Models

该论文提出 Search-R3（Reasoning-Reinforced Representation for Search）框架，首次将大语言模型的链式推理（CoT）能力与搜索 embedding 生成统一在同一模型中。通过三个关键机制实现：(1) 监督学习阶段建立高质量 embedding 生成能力；(2) 强化学习方法同时优化推理过程和 embedding 质量；(3) 专用 RL 环境避免每次训练迭代时全量重编码语料库。在多个检索基准上显著超越此前的 embedding 模型，首次证明推理过程可以提升文本表征质量。

Iterative Reranking as a Compute-Scaling Method for LLM-Based Rankers

Amazon📖 深度解读 · 11 分钟 →

该论文提出迭代重排序（Iterative Reranking）作为 LLM 排序模型的推理时计算扩展策略。核心思路是利用 LLM 的非确定性，通过反复应用 listwise 排序器来逐步优化排序结果——每次迭代可以修正前一次的排序误差。在 TREC DL19、FutureQueryEval 和 Amazon 电商难查询三个数据集上，使用三种开源 LLM 评估，迭代重排一致性地提升了 nDCG@40 指标。ECIR 2026 发表，代码开源于 github.com/amazon-science/IterativeListwiseReranking。

INSIGHT该方法提出了一种「用算力换排序精度」的新范式，区别于传统的一次性重排序。对 UGC 搜索系统的实践意义在于：(1) 在对延迟不敏感的场景（如离线索引、批量排序）中，可以通过多轮迭代显著提升排序质量；(2) 利用 LLM 的随机性而非消除它，每次迭代相当于集成多个排序假设；(3) 对于电商搜索等需要精细排序的场景，可作为精排后的额外优化步骤。实现简单、无需额外训练，适合快速验证。

Czinczoll, Liu, Betello

From BM25 to Corrective RAG: Benchmarking Retrieval Strategies for Text-and-Table Documents

该论文对 RAG 系统中的十种检索策略进行了系统性基准测试，覆盖稀疏检索、稠密检索、混合融合、cross-encoder 重排序、查询扩展、索引增强和自适应检索。测试数据为 23,088 个金融领域查询、7,318 篇包含文本和表格混合内容的文档。关键发现：混合检索 + Cohere Rerank 的两阶段流水线表现最优（Recall@5=0.816），比 BM25 高 26.7%、比纯稠密检索高 39.0%。另一重要发现：BM25 在金融领域多数指标上优于 text-embedding-3-large 稠密检索。

INSIGHT该基准测试的核心启示是「混合检索 + 神经重排序」是当前最稳健的检索架构选择。对 UGC 搜索特别有参考价值的发现：(1) 在术语密集型文档中（如金融文档），词汇匹配信号（BM25）依然强于语义 embedding，这提示 UGC 搜索中的领域特定术语也可能更适合稀疏检索；(2) 查询扩展对数值型查询效果有限，提示不能盲目应用 LLM query 改写；(3) 两阶段检索 pipeline（BM25/hybrid 召回 + 神经模型精排）应作为 baseline 架构。代码和数据已开源，可复现。

Meftun Akarsu, Recep Kaan Karaman, Christopher Mierbach

Generative Relevance Feedback with Large Language Models

已录用 SIGIR 2023University of GlasgowUniversity of Edinburgh

该 SIGIR 论文提出生成式相关性反馈（GRF），用 LLM 生成的长文本替代传统伪相关反馈（PRF）的检索文档来构建反馈模型。传统 PRF 在首轮检索结果不相关时会失效，而 GRF 通过变化零样本生成子任务（查询、实体、事实、新闻文章、文档、论文等）产生多样化文本，从中构建概率反馈模型。在标准文档检索基准上，GRF 方法显著优于传统 PRF 方法，验证了 LLM 生成内容作为检索信号的有效性。

INSIGHTGRF 的核心创新在于将查询扩展的信号来源从「检索到的文档」转为「LLM 生成的文本」，解决了传统 PRF 的冷启动问题——即便初始检索结果质量差，LLM 仍能生成有效的反馈信号。对 UGC 短文本搜索的直接应用价值在于：短查询天然面临词汇稀疏和语义模糊问题，可利用 LLM 生成的扩展文本（如实体、事实性描述）作为 query 的补充信号，增强召回和排序。该方法无需修改索引结构，仅在查询侧增加 LLM 调用，部署成本较低。

Iain Mackie, Shubham Chatterjee, Jeffrey Dalton

Scholar API: Search and Recommendations for Academic Search

Baidu

该 WSDM 2026 论文介绍了 Scholar API (SAPI)，一个用于学术搜索和推荐的联邦式 API 系统。核心设计是支持多源数据融合（mashup），提供四种可选 embedding：Specter（基于 BERT+引用图微调）、ProNE-s（基于引用图谱线性代数/谱聚类）、SciNCL 和 GNN。既包含深度神经网络方法（BERT 编码摘要），也包含高效线性方法（ProNE-s），为不同场景提供灵活选择。系统构建在已有互联网服务之上，采用灵活的联邦架构。

INSIGHT该系统设计的核心价值在于「多 embedding 可选架构」的思路——不同检索场景对 embedding 的需求不同（语义精度 vs 计算效率），通过统一 API 暴露多种 embedding 方案让调用方按需选择。对 UGC 搜索系统的启示：(1) 可考虑同时维护轻量级（ProNE 类图方法）和重量级（BERT 类语义模型）embedding，按查询场景路由；(2) 联邦式多源融合架构适合搜索系统整合多种召回通道。实践意义在于架构设计层面而非具体算法创新。

Kenneth Church, Omar Alonso
