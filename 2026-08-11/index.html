SAGEO Arena: A Realistic Environment for Evaluating Search-Augmented Generative Engine Optimization

论文提出 SAGEO Arena，把检索、重排和生成串成可复现实验环境，覆盖 9 个信息检索数据集、2700 个查询和 171003 篇网页文档，并保留标题、摘要、层级标题与 Schema 等结构字段。基线检索命中率为 0.58、引用率为 0.50；按阶段优化后，检索 H@20 达到 0.75（提升 28%），生成引用率达到 0.58。

CoinRAG: Contextualized Information Nugget KV Cache Reuse for Long-Context RAG

UUniversity of California, Santa BarbaraHHanbat National University

CoinRAG 将长文档离线拆成带上下文的信息 nugget，在线用两阶段检索选择相关片段，再组合可复用的 KV cache，减少长上下文预填充噪声。LongBench 三个多跳问答数据集在 P99 TTFT 100ms 约束下，平均 F1 为 41.7，相比 TurboRAG 的 39.6 提升 5.3%，平均上下文长度缩短 1.84 倍；无延迟约束时平均 F1 仍提升 5.2%。

INSIGHT对 UGC 搜索的 RAG 化摘要或答案生成，可以把高频帖子中的事实、实体和可引用句子预抽取为 nugget，并在查询时按需拼装上下文。关键不是盲目扩大 top-k，而是保留 nugget 的局部语义与原文位置；同时要把离线抽取、缓存存储和内容更新成本纳入整体 SLA。

Gyuwan Kim, Cheoneum Park, Tao Yang

03 4.35

DocMemo: Dynamic Evidence Discovery via Probabilistic Memory-Guided Retrieval for Multi-Modal Document Understanding

Harbin Institute of TechnologyTsinghua University

DocMemo 将长文档推理建模为动态证据探索，维护文档结构记忆、页面信念记忆和问题情节记忆，并用贝叶斯更新、Thompson Sampling 与自适应粒度访问不断修正检索状态。在 MMLongBench-Doc 上总体准确率为 71.3%，相对最强 Agent 基线在三个基准上提升 3.7、8.8 和 15.0 个百分点；移除记忆或贝叶斯更新后降至 68.5% 和 68.8%。

INSIGHT多轮搜索问答不应每轮从零检索：可以把会话中的 query 意图、已验证帖子和无效候选维护成可更新的证据状态。对社区场景，页面信念记忆适合记录帖子是否真正解决问题，情节记忆承接改写 query，探索策略则避免早期误召回把后续答案锁死。

Hanshu Yao, Jianfeng Zhong, Niu Lian, Jinpeng Wang

Exact Adaptive Hybrid Retrieval Without Fixed Top-L Cutoffs

Southwest Jiaotong University

EAHR 将完整列表加权 RRF 的有序 Top-K 设为固定结果契约，把 dense 与 sparse 通道的访问深度变成按请求自适应的执行状态，并用 PVS 与 PBM 生成可恢复的精确排名。实验显示固定深度无法跨数据集稳定迁移；在 TREC-DL 2020 上，PVS 将中位浮点评估从 8841823 降到 2664，减少 99.97%，同时保持完整融合结果语义。

INSIGHT生成式搜索的答案质量受首阶段候选上限制约，固定 top-L 既可能漏召回，也可能浪费预算。可以先定义必须保持不变的融合结果，再让每个 query 自适应拉取更多 sparse/dense 排名；线上应同时监控 nDCG、召回覆盖、P99 延迟和实际访问深度。

Chunran Zhang

Beyond Top-K: Replacing Black-Box Retrieval with Interpretable Agentic Operations

论文指出对财报、审计和监管表格直接做 chunk embedding 与 Top-K 检索会破坏数字和表头之间的关系：在一份 780 页政府财报中，86.8% 的内容行是表格行，数字继承表头单位的中位距离为 13 行。即使使用表格感知切分，仍有 27%–30% 的数字块缺少财年表头，因此作者提出可解释的 Agentic 文档搜索操作。

INSIGHT对包含价格、时间、作者和标签关系的 UGC 搜索，纯向量相似度也可能把需要共同解释的字段拆开。生成式检索 Agent 应优先执行实体展开、字段过滤、邻接上下文恢复等可审计操作，再让模型生成答案，并把每一步的证据来源暴露给评测与回滚系统。

Sagar Tamang, Ayush Vyas, Tabarakul Hazarika

Progressive Content Refinement with Decaying Reward Joint LinUCB

论文把 LLM 的迭代改写视为带上下文的 bandit 决策，针对同一 prompt 或工具臂反复使用后收益衰减的问题，用 EM 同时估计臂价值和衰减参数，并将 prompt 表示为可学习的 arms。作者在 Sentiment Reversal 与 GSM8K 两个基准上验证了方法，重点展示它能在持续 refinement 中抑制过度利用和收益饱和。

INSIGHT生成式搜索的 query 改写、摘要压缩和推荐理由生成都存在‘改得越多越好’的错觉。可以把不同改写模板、检索工具和输出约束作为 arms，按用户反馈与内容新鲜度更新衰减估计；当某模板连续带来重复结果时，主动探索比继续堆叠同一 prompt 更安全。

Shion Ishikawa, Pablo Loyola, Young-joo Chung, Yun Ching Liu

Agent评测漫谈 —— 由浅入深讲解Agent评测

美团

美团技术团队总结图灵 Agent 评测团队两年业务实践，文章从评测定义、任务拆解、指标设计到体系建设逐步介绍如何建立可迭代的 Agent 评测框架。它不是一篇生成式推荐论文，但对生成式搜索同样强调把任务成功、工具调用、证据质量和用户体验拆开衡量，而不是只看最终文本。

INSIGHT生成式搜索的离线评测应同时覆盖召回命中、证据引用、答案事实性、query 解决率和交互成本，并保留失败轨迹。可借鉴美团的业务化评测思路，把离线 benchmark、人工抽检与线上 CTR/nDCG 串成同一指标树，避免生成答案看似流畅却无法解决用户问题。

AWS Trainium Frontier competition: Co-design models and kernels on purpose-built AI chips

Amazon

Amazon Science 宣布围绕 Trainium 的 Frontier 竞赛与 NeurIPS 2026 展示，核心方向是从模型架构、训练算法到 GPU/加速器 kernel 的协同设计。该条目不是推荐论文，也没有公开可比较的推荐指标，但体现了生成式模型在规模化训练中从单纯堆参数转向软硬件共同优化的工程趋势。

INSIGHT生成式推荐或搜索模型的成本瓶颈常在 embedding、KV cache、通信和 kernel，而不只是参数量。规划 UGC 业务试点时，应把模型结构、序列长度、缓存布局和硬件利用率放在同一 profiling 表中，用每千次请求成本与 P99 延迟约束规模化，而不是只比较离线 nDCG。

Run Local Agentic AI Workflows with Meta’s Muse Glimmer on NVIDIA

NVIDIAMeta

NVIDIA 介绍 Meta Muse Glimmer 的本地 Agent 工作流：这是一个 30B 参数的开源权重稠密模型，支持 120K 以上上下文，面向本地推理和工具协作。文章重点是模型、NVIDIA 软件栈与本地部署组合，没有给出搜索或推荐场景的独立离线指标，因此更适合作为生成式系统部署信号。

INSIGHT对社区搜索而言，长上下文模型不等于应把全部历史直接塞进 prompt。更现实的用法是将其作为低频 query 的重写、证据整合或结果解释模型，并用路由器按 query 难度选择本地模型；上线前要验证 P99 延迟、显存占用和内容安全边界。
