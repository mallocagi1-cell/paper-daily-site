Learning User-Aware Recall: Personalized Retrieval in Long-Term Conversational Memory

Learning User-Aware Recall 面向长期对话记忆中的个性化检索，提出 PPRO：从历史对话构建 episodic/semantic memory bank，并从累积记忆中提取用户画像作为显式 personalized prior。框架还用 GRPO 训练 query rewriter，把证据召回质量和下游回答质量同时作为反馈，同时固定 memory bank 与 answer model。在 LoCoMo 和 LongMemEval-S 上，PPRO 相比训练免方法和训练式基线均有稳定收益。

STRUCTSURVEY: Structured Agentic Retrieval for Automated Survey Paper Generation

STRUCTSURVEY 面向自动综述生成中的检索结构缺失问题，提出层级多智能体框架，在检索阶段动态构造实体、关系和主题 taxonomy 的图表示，而不是让 LLM 在生成阶段从原始文本里临时推断结构。作者在 ACL survey 论文构成的 reference-grounded benchmark 上评估；相比 embedding-only retrieval，ROUGE-1 recall 平均提升 2.9，ROUGE-2 recall 平均提升 1.0，同时不降低 precision。

INSIGHT对生成式搜索报告和社区内容聚合有直接借鉴：复杂答案需要结构化检索，而不是简单 top-k chunk。可以先把帖子、评论、作者、主题和争议点构造成图，再让生成模型基于结构化证据合成结果，这会比纯向量召回更容易产出有层次的答案。

Paolo Pedinotti, Enrico Santus

When RAG Meets Query Planning: Logical Query Trees for Resolving Exploratory Reasoning Problems

PlanRAG 研究 RAG 在探索式推理问题（ERP）中的路径不确定、检索噪声和错误累积问题。方法借鉴数据库 query planning，把自然语言复杂问题拆成 atomic queries，再组织为 logical query trees，并用包含多维成本的动态规划来优化执行顺序。系统在树节点上迭代执行聚合、重写、检索和生成，还支持并发处理；论文在自建 WikiWeb-ERP 数据集上优于迭代式和图式 RAG baseline。

INSIGHT对 UGC 搜索的启发是：当用户问题模糊且需要多跳探索时，RAG 应先规划查询树，而不是反复追加搜索词。社区搜索可以把“找观点、找证据、找反例、找用户经验”拆成不同节点并行检索，最后再聚合生成答案，减少早期错误证据对最终结果的污染。

Program-as-Weights: A Programming Paradigm for Fuzzy Functions

Program-as-Weights 提出 fuzzy-function programming，把日志告警、JSON 修复、按意图排序搜索结果等难以规则化的任务，从自然语言规格编译成可本地执行的神经 artifact。PAW 使用在 FuzzyBench 1000 万样本上训练的 4B compiler，为冻结的轻量解释器生成参数高效 adapter。0.6B Qwen3 interpreter 执行 PAW 程序时达到直接 prompt Qwen3-32B 的性能，推理内存约为 1/50，并可在 MacBook M3 上达到 30 tokens/s。

INSIGHT对搜索推荐工程的启发是：部分 LLM 能力可以离线“编译”为本地小模型函数，而不是每次线上请求都调用大模型。对于 query 归一化、意图粗排、低风险重写或召回规则补全，这种模式可能显著降低成本和隐私风险，同时保留自然语言规格迭代的灵活性。

Wentao Zhang, Liliana Hotsko, Woojeong Kim, Pengyu Nie, Stuart Shieber

ACL 2026 精选论文分享：美团履约团队前沿技术专场

Meituan
