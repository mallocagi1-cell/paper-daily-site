Decomposing Staleness in Recommender Systems: A Dual-Filter Framework for Supersession and Decay

论文将推荐内容过时拆成“被新内容替代”和“生命周期衰减”两类，并在 Google Discover 上部署 SDF。系统由关系式陈旧度模型识别内容对之间的替代关系，再用预测流量比模型估计生命周期价值，在排序前做并集过滤；连续两年线上运行后，用户主动提交的陈旧内容反馈较基线下降 54.9%，同时减少下游服务成本。

UniDot: A Unified Network for Sequence Modeling and Feature Interaction in Large-scale Recommendation

📖 深度解读 · 16 分钟 →

排序模型通常把字段交叉和行为序列分成两个塔，到最后一层才拼在一起。UniDot 把用户、物品字段和多域行为序列都变成同一空间的 token，用两条并行通路一起处理，每层交换一次信息；同时把每层算出的点积原样拼起来，绕过融合层直接送进分类器。它在腾讯广告转化预测比赛中拿到 AUC 0.83217，排第 2。最值得借鉴的是两个便宜的部件：消融里这条点积旁路贡献最大；两条通路互相蒸馏、上线只用一条，AUC 仍有 0.83184，推理时间减半。

Rongcheng Lin, Yan Sun, Jamey Zhang, Guanglei Xiong, Ivan Ji, Xianjie Chen, Shujian Bu

TRACER: Balancing Stability-Plasticity-Cognitivity Trilemma for LLM Enhanced Continual Recommendation

TRACER 研究持续推荐中 LLM 语义先验与个体历史冲突的问题，把稳定性、可塑性、认知性定义为 SPC 三难。方法由三个专门模块分别保留历史、适应兴趣漂移、注入语义知识，并用自适应机制防止任一模块主导；在 5 个真实数据集上，相对 SOTA 最高提升 14.38%，代码已开源。

INSIGHT社区内容兴趣变化快，直接把 LLM 表征接入序列模型可能覆盖短期偏好；TRACER 的模块化分工适合做分层更新。可把长期画像、近 7/30 天行为、内容语义先验分开建塔，以门控权重和漂移检测调节融合，并用新内容 CTR、留存、长尾覆盖和旧兴趣召回率做回归测试。

WooJoo Kim, HyunSik Yoo, JunYoung Kim, JaeHyung Lim, SeongKu Kang, HwanJo Yu

Decoupled Temporal Encoding for Generative Recommendation

论文指出生成式推荐的序列不只是离散顺序，还包含近因效应、用餐时段、工作日/周末和促销突发等多级时间规律。DTE 将时间与顺序解耦：个性化宏观时间模块把紧凑时间原语注入 item embedding，微观时间门控只在交互密集时施加相对顺序偏置；方法参数高效、可插入既有系统，并以真实外卖/即时零售场景为动机。

INSIGHT短文本社区的用户兴趣同样有“近期热点”和稳定主题两层时间尺度；把所有时间特征塞进一个 embedding 容易让热点噪声污染长期兴趣。建议先保留现有 Transformer，仅增加宏观时间桶和密集交互门控，按 nDCG/CTR 分时间段、节假日、热点生命周期切片评估，确认收益来自时序建模而非数据泄漏。

Pengfei Jia, Jingjian Wang, Jingmao Li, Ge Zhang, Feng Shi

GOD: Enhancing Generalization via Deep Grafting for Sequential Recommendation

针对序列推荐历史稀疏、噪声大导致泛化差的问题，GOD 提出组件级蒸馏。它把冻结教师的部分组件替换成可训练学生组件，分别检验学生 embedding 配教师 encoder、教师 embedding 配学生 encoder 的效果，从而定位瓶颈，而非只匹配最终输出；推理阶段仅保留学生网络，3 个真实数据集上最高超过 SOTA 13.92%。

INSIGHT对 UGC 用户序列，蒸馏不应只约束最终 logits，否则无法判断是 embedding、编码器还是协同适应导致掉点。可在线下构造“教师模块×学生模块”的交叉诊断矩阵，优先蒸馏弱项；上线只部署学生网络，收益与延迟隔离，适合长序列模型压缩和冷用户泛化。

WooJoo Kim, JunYoung Kim, JaeHyung Lim, HwanJo Yu

POI Recommendation with LLM-Augmented Multi-Graph Learning and Contrastive Alignment

LLM-MGCL 面向 POI 冷启动，把 LightGCN 扩展为行为、语义、地理三图并行传播。语义图来自 LLM 生成的照片摘要/关键词，地理图用 Haversine 距离构造，再以双向 InfoNCE 对齐同一物品的三种表示；在 Yelp Multimodal 数据集上，Recall@20 和 NDCG@20 比 LightGCN 分别提升 52.0% 和 64.8%，消融显示跨视图对比对齐是主要增益来源。

INSIGHT对 UGC 新帖子或低曝光内容，语义与上下文图可以补足没有点击的协同信号；但 LLM 生成的标签必须经过去重、质量和时间一致性校验。可把内容语义图、作者/主题关系图与用户行为图做轻量多图融合，先在冷启动分桶看 Recall/nDCG，再用对齐损失和热度校正避免热门内容的伪增益。

Burak Tamer, Wolfram Höpken, Zehui Wang

SAGA: Structure-Attended Generative Action Embedding Model that encodes Multi-Surface User Action Sequences

SAGA 解决跨业务面用户行为异构的问题，把结账、转账、站内互动、邮件和账户操作编码成统一用户表示。它按事件字段拆成 product、interaction、surface 等 token，用字段级 attention 与字段级训练目标替代单 token 表示，并通过损失、粒度和数据范围消融验证设计；下游模型在多触点点击与转化任务上取得整体最强 lift。

INSIGHT社区平台的搜索、信息流、评论互动往往被不同日志体系割裂，SAGA 提供了跨面复用用户表示的实现范式。工程上应先定义稳定事件 schema 和时间边界，再共享一次序列编码给多个任务；用跨场景冷启动、长尾作者、CTR/CVR 以及 embedding freshness 监控验证统一表示没有引入业务串扰。

Tsz Fung Pang, Po Jen Chen, Nimish Ronghe, Farhad Farahani, Bo Zhang

FLAME: Condensing Ensemble Diversity into a Single Network for Efficient Sequential Recommendation

FLAME 针对单一序列网络难以覆盖多样用户行为、而完整集成训练成本高的问题，用两个网络模拟指数级表示多样性。它将网络拆成层/块级子模块动态组合，以一个预训练并冻结的语义锚点稳定互学习，训练完成后只保留单网络推理；论文在多个序列推荐数据集上验证了效率与效果的兼顾。

INSIGHT社区用户既有浏览、搜索、评论等多类行为，单路序列模型容易把不同意图平均化。可先用冻结教师提供稳定语义空间，再以模块级组合训练学生；上线只保留一网，重点比较 ensemble、蒸馏学生和 FLAME 的 nDCG、CTR、显存及 P99，避免把离线多样性转化成线上成本。

WooJoo Kim, JunYoung Kim, JaeHyung Lim, SeongJin Choi, SeongKu Kang, HwanJo Yu

Impression Share Prediction: An Offline Evaluation Task for Ranking Systems

论文提出在上线 A/B 前预测候选排序模型会如何改变不同目标桶的曝光份额，弥补只看预测准确率而忽略下游流量分配的缺口。方法用结构因果模型刻画模型分数与投放容量，再以早期互动信号和系统状态训练预测器；对已见模型，随机森林的 L1 误差比常数基线低 49%，首小时困难场景经两小时 rollout 后恢复 22% L1 改善。

INSIGHT社区搜索/推荐的多目标排序不能只看 CTR 或 nDCG，还要预估结果会把曝光推向哪些内容桶。可在离线回放中增加作者、主题、长尾和负反馈等 impression share 维度，先用历史模型校准反事实预测，再把曝光分布漂移作为 A/B 的护栏指标，减少线上试错。

Mohsen Malmir, Houssam Nassif, Danish Nasir Shaikh, Taher Rahgooy, Murat Ali Bayir

SAHC-NS: Structure-Aware and Hardness-Calibrated Negative Sampling for Implicit Collaborative Filtering

SAHC-NS 针对隐式协同过滤的负采样，指出不同用户候选池的难度差异以及多跳结构信息常被忽略。方法用逐层匹配分数的均值与标准差刻画匹配强度和结构差异，再按候选池难度动态调节负样本增强强度，生成可控难度负例；论文在多组实验中优于既有负采样方法，但摘要未给出统一提升幅度。

INSIGHT对社区 UGC，随机负样本会把未曝光内容误当成不感兴趣，过硬负样本又可能放大噪声。可按用户活跃度、候选池规模和图邻域差异分层校准负样本难度，并同时监控长尾召回、CTR、nDCG 与训练稳定性；先离线验证结构统计量，再决定是否引入在线采样。

Jiayi Wu, Zhengyu Wu, Xunkai Li, Hongchao Qin, Rong-Hua Li, Guoren Wang
