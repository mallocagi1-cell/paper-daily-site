From Token Generation to Item Ranking: Direct Generative Recommendation with Semantic IDs

论文指出 Semantic ID 逐 token 解码并不等价于 item-level 排序：若 token 接口信息不足，无法恢复精确排序；若信息充分，解码又退化为直接打分。基于这一二分结论，DiGR 将 Semantic ID 保留为物品表示，改用统一的用户—物品打分函数，并在多个真实数据集和不同规模 LLM 骨干上超过既有生成式与 ID 方法。

Noesis: Bidirectional Graph-RAG with Adaptive Parallelism and Cross-Knowledge-Base Semantic Discovery

Noesis 为 Graph-RAG 设计双向图遍历、基于 AIMD 的并发控制、面向 MoE 的选择性量化和跨知识库语义路由。实验在 1,000 个 HotpotQA 问题上达到 59.5 EM/74.7 F1，较 GraphRAG 提升 27.8 个 EM 点；并实现 23 倍并行加速、6.3 倍量化推理加速且无 OOM。

INSIGHT其价值在于把生成式检索的效果、吞吐和多知识库路由放在同一设计里：长文 UGC 可用图结构保留跨段关系，AIMD 控制器可按负载调节并发，选择性量化则降低本地部署门槛。

业务关联适合知识增强搜索、跨域社区内容问答和推荐解释链路。

证据HotpotQA 1,000 问题；59.5 EM/74.7 F1；23x 与 6.3x 加速。

Rich-Media Re-Ranker: A User Satisfaction-Driven LLM Re-ranking Framework for Rich-Media Search

Rich-Media Re-Ranker 面向多意图富媒体搜索，先用 Query Planner 拆解会话中的 query refinement，再融合文本、视觉和信息增益等信号进行整体重排。视觉信号由 VLM evaluator 生成，并通过多任务强化学习提升场景适应性；论文报告已部署到大规模工业搜索系统，线上用户参与度和满意度均有提升。

INSIGHT对社区短文本搜索，重点不是把 LLM 直接放进全链路，而是让它负责 query 规划、富媒体理解和多目标重排，再用可控原则约束输出。落地前应单独监控延迟、视觉信号漂移与满意度指标，避免 CTR 提升掩盖内容质量下降。

业务关联与社区 UGC 搜索的多意图、图文混排和满意度优化高度相关。

证据大规模工业搜索部署；线上 engagement 与 satisfaction 指标提升；多任务 RL。

04 4.20

GEO-Flag: Detecting and Measuring GEO-Optimized Web Content

GEO-Flag 构建 GEOFlagBench，覆盖 3,200 个网页、400 个 query、4 个领域和 8 类优化器。干预配对训练将 ModernBERT 的 F1 从 0.862 提升到 0.944，最差组准确率从 0.725 提升到 0.883；在 10,095 个真实页面上估计 GEO 渗透率为 8.90%，2026 年修改页面中达到 16.36%。

INSIGHT生成式搜索需要把“相关性”和“被优化出来的可见性”分开评估。对社区搜索，可将干预配对检测接入内容质量审核和引用审计，重点防止低权威、低事实性内容通过提示词或结构化写法获得异常曝光。

业务关联为生成式搜索的内容质量、来源可信度和反操纵提供可执行的检测基线。

证据GEOFlagBench 3,200 网页/400 query；F1 0.862→0.944；真实页面 10,095 个。

Ask to Be Sure: Informative Interactions for Confident Multi-Turn LLM Recommendation

针对多轮对话推荐中用户偏好难以有效 elicitation 的问题，论文把推荐分布熵的下降量定义为交互奖励，避免依赖真实推荐标签。基于 SFT 和 DPO 在 INSPIRED、ReDial 两个数据集上验证，方法同时改善推荐质量与对话效率。

INSIGHT把“问什么”从模板规则改成可优化的信息增益目标，适合社区搜索中澄清短 query、补齐用户意图。线上落地时可将熵下降作为离线奖励，并用安全模板约束追问频率，避免对话成本失控。

业务关联对社区搜索的多轮澄清和推荐式搜索有直接借鉴价值。

证据INSPIRED、ReDial 两个公开数据集；SFT 与 DPO 两种训练设置。

LineageRAG: Harnessing GraphRAG by Constructing Evidence Lineages with Source Grounding

LineageRAG 为每个 query 派生的证据需求建立独立 lineage，在图检索扩展时保留需求归属，并在完成阶段补回支持结论的原文片段。HotpotQA、2WikiMultiHopQA、MuSiQue 三个数据集上，相比 GraphRAG 基线平均提升 R@5 3.51、EM 5.96、F1 5.22 个百分点。

INSIGHT把“找到证据”和“证明证据来自哪里”绑定在同一条 lineage 上，能减少 Graph-RAG 多跳链路中的证据漂移。社区搜索可借此生成带原文 span 的回答或推荐理由，并把 lineage 作为离线可解释性与人工质检单元。

业务关联适合需要引用、溯源和多跳解释的 UGC 搜索与知识推荐。

证据HotpotQA、2WikiMultiHopQA、MuSiQue；R@5/EM/F1 平均 +3.51/+5.96/+5.22。

From IR to RecSys: Evaluating LLM-based Judges in Cranfield-style Recommendation Collections

论文把 Cranfield 评测范式引入推荐系统，在 ML-32M-ext 上发现普通 train-test 切分会产生不完整相关性标签和不稳定系统排序。LLM judge 结合更丰富的物品元数据与更长用户历史后，系统级排名与人工排名的 Kendall tau 最高达 0.92（nDCG@100，52 个系统配置），并在播客推荐工业案例中验证模型选择价值。

INSIGHTLLM judge 更适合作为系统级离线评测和候选模型筛选信号，而不是替代人工或真实交互标签。对 UGC 搜索，应采用 pooling、长历史和元数据增强 judge，并同时报告 item-level 一致性，防止评测看似稳定但用户偏好被误判。

业务关联为生成式推荐/搜索提供可扩展的自动评测方法，能降低人工标注成本。

证据ML-32M-ext；52 个系统配置；系统级 Kendall tau 最高 0.92；含播客推荐工业案例。

LlamaRec-LKG-RAG: A Single-Pass, Learnable Knowledge Graph-RAG Framework for LLM-Based Ranking

LlamaRec-LKG-RAG 在 LlamaRec 上加入轻量用户偏好模块，从用户行为和物品元数据构建异构知识图，并选择个性化关系路径注入 Llama-2 prompt。它以单次推理完成知识增强的推荐排序，在 ML-100K 与 Amazon Beauty 上的 MRR、NDCG、Recall 均持续超过 LlamaRec，并公开代码。

INSIGHT生成式推荐的 RAG 不应只做相似度召回；用户—物品关系路径能提供更可解释的个性化上下文。工程上可先把关系路径选择做成轻量模块，再将小子图注入重排 prompt，以控制上下文长度和在线延迟。

业务关联与社区用户兴趣建模、关系解释和冷启动内容推荐直接相关。

证据ML-100K、Amazon Beauty；MRR/NDCG/Recall 一致改善；代码可用。

Conversational generative retrieval with contextual denoising

CGR4CD 面向多轮对话生成式检索，使用命题式 docid 表示段落，并在解码阶段加入交叉注意力来动态捕捉上下文中的关键信息。论文以 T5-large 为骨干，强调在保持参数效率的同时抑制对话噪声传播，为对话式搜索和推荐提供轻量化生成检索路径。

INSIGHT对短文本社区搜索，命题式 docid 可以比整段文档标识更细粒度地承载内容语义；上下文去噪则适合处理多轮 query 漂移。落地时应配合候选召回兜底和事实引用校验，避免生成式检索漏召回或产生不可定位的结果。

业务关联适合对话式搜索、会话推荐和需要上下文去噪的生成式检索。

证据T5-large 骨干；命题式 docid；交叉注意力解码；摘要未给出统一数值结果。

Unbiased Recommender Systems with Implicit Feedback

本文聚焦隐式反馈中的位置偏差与流行度偏差，分别讨论学习排序、协同过滤和社交图神经推荐中的去偏方法。核心问题是点击等行为同时受到展示位置和曝光频率影响，直接训练会把“看见更多”误当成“更喜欢”，从而伤害长尾内容的真实相关性。

INSIGHT生成式推荐扩大模型容量后，偏差并不会自动消失，反而可能被长序列放大。社区场景应在训练前拆分曝光、位置和行为信号，并把长尾覆盖、校准和反事实评估与 nDCG/CTR 一起纳入验收。

业务关联为生成式序列推荐提供数据治理和离线评估的基础约束。

证据覆盖位置偏差、流行度偏差及 LTR/CF/社交 GNN 三类场景；摘要未给出统一数值结果。
