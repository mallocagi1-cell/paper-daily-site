Robustness Risk of Conversational Retrieval: Identifying and Mitigating Noise Sensitivity in Qwen3-Embedding Model

本文研究了 Qwen3-Embedding 模型在对话式短查询检索场景下的鲁棒性问题。在不使用 query prompting 的情况下，结构化对话噪声会侵入 top-k 结果，导致语义无关内容排名异常升高。该漏洞在 Qwen3 中比早期版本和其他稠密检索模型（如 BGE、E5）更为显著，且在标准 clean-query 基准测试中不可见。研究发现，轻量级的 query prompting 策略可以有效抑制噪声入侵，恢复排序稳定性，在多个模型尺度上验证了这一结论。

Improving Neural Retrieval with Attribution-Guided Query Rewriting

本文提出一种基于梯度归因（gradient-based token attribution）引导 LLM 进行查询改写的方法，用于改进神经检索。核心思路是从检索器中计算各 token 的梯度归因分数，识别查询中语义薄弱或误导性的成分，然后将归因信息作为 prompt 引导 LLM 精确地澄清和改写这些成分。在 BEIR 多个数据集上的评估表明，该方法能持续提升检索效果，尤其在查询表述不精确的场景下改善显著。

INSIGHT该工作的核心创新在于将检索器的内部信号（token 级别梯度归因）与 LLM 的改写能力结合，形成了一个可解释的查询改写闭环。对 UGC 搜索的实践意义：(1) 社区查询通常表述模糊、简短，梯度归因可精准定位查询中的弱项；(2) 该方法不需要重训检索器，只需在推理时加一步 LLM 改写，部署成本可控；(3) 为 query 理解提供了一种数据驱动的改写策略，优于纯启发式规则。

WebExpert: domain-aware web agents with critic-guided expert experience for high-precision search

WebExpert 提出了一个领域感知的 Web 搜索 Agent，包含三个关键组件：(1) 句子级经验检索与主题合并、规则蒸馏；(2) SchemaLight 自动化 facet 归纳，从弱监督中引导时间、地域、政策、行业等 facet，替代手工词表；(3) 基于偏好优化的搜索规划，联合改进查询规划和检索。在推理时，轻量级经验门控根据 active facets 偏向解码，低检索置信度时回退。在 GAIA、GPQA、HLE、WebWalkerQA 上，Answer EM 提升 1.5-3.6pp，同时减少了页面跳转次数。

INSIGHTWebExpert 的 facet 自动归纳和偏好优化规划对搜索系统设计有直接借鉴价值：(1) SchemaLight 的弱监督 facet 归纳思路可应用于 UGC 搜索的自动标签/分面生成；(2) 偏好优化的查询规划将搜索意图理解与检索策略联合优化，比传统 pipeline 更紧密；(3) 经验门控机制提供了一种在线适应策略，可在搜索质量不稳定时自动回退到保守策略。该系统证明了领域先验知识对精准搜索的重要性。

Feedback Adaptation for Retrieval-Augmented Generation

本文提出了 RAG 系统的反馈适应（Feedback Adaptation）问题设定，关注纠正性反馈如何有效且快速地传播到后续查询。引入两个评估维度：correction lag（反馈到行为改变的延迟）和 post-feedback performance（反馈后语义相关查询的可靠性）。研究表明基于训练的方法存在延迟校正与可靠适应之间的 trade-off。进而提出 PatchRAG，一种轻量级推理时方案，在不修改模型参数的情况下实现反馈的即时传播。

INSIGHTPatchRAG 提供了一种无需重训模型即可实现检索反馈实时传播的方案，对搜索系统有两个重要启示：(1) 在 UGC 搜索中，用户反馈（点击、差评标注）的快速传导对搜索质量至关重要，PatchRAG 的推理时注入方式比传统模型更新更即时；(2) correction lag 和 post-feedback performance 两个指标为搜索反馈系统的评估提供了新维度，弥补了传统离线评估的盲区。该方法特别适合需要快速响应 badcase 的在线搜索场景。

Jihwan Bang, Seunghan Yang, Kyuhong Shim, Simyung Chang, Juntae Lee, Sungha Choi

MARVEL: Multimodal Adaptive Reasoning-intensiVe Expand-rerank and retrievaL

MARVEL 提出统一的 expand-rerank 检索管线，整合 LLM 驱动的查询扩展、推理增强的稠密检索器（MARVEL-Retriever）、以及 GPT-4o 基于 chain-of-thought 的重排序。在 MM-BRIGHT 多模态检索基准上，现有最佳视觉语言编码器仅达 27.6 nDCG@10，而 MARVEL 通过三阶段协同（扩展-检索-重排）显著超越文本和多模态基线。MARVEL-Retriever 在复杂推理查询上经过专门微调，配合多轮倒数融合进一步提升效果。

INSIGHTMARVEL 的三阶段 expand-rerank 架构对文本搜索系统具有可迁移的设计启示：(1) 查询扩展→检索→推理式重排的流水线设计思路同样适用于 UGC 搜索，可在短查询上先扩展意图再检索；(2) 为复杂查询专门微调 retriever 的做法证明了 retriever 与 query 类型匹配的重要性；(3) CoT-based 重排展示了 LLM 在精排阶段的推理能力，可替代传统 cross-encoder 打分，尤其在需要理解查询意图的场景。

BRIDGE: Multimodal-to-Text Retrieval via Reinforcement-Learned Query Alignment

BRIDGE 提出了一种两组件检索系统：FORGE（基于 RL 的查询对齐模型）将嘈杂的多模态查询蒸馏为紧凑的、检索优化的搜索字符串；LENS（推理增强稠密检索器）针对复杂推理查询进行微调。核心发现是检索瓶颈不在 retriever 本身，而在查询质量——原始查询混杂了视觉描述、对话噪声和检索意图，系统性降低了 embedding 相似度。BRIDGE 不需要多模态编码器，仅通过查询对齐即可超越多模态检索基线。

INSIGHTBRIDGE 的核心洞察——'瓶颈不在检索器而在查询质量'——对 UGC 搜索极具启发：(1) 社区用户的搜索查询同样包含大量噪声（口语化表达、无关上下文），RL 训练的查询对齐模型可直接应用于 query 清洗和改写；(2) FORGE 证明了用 RL 优化 query-retriever 对齐是可行且有效的，为搜索 query 理解提供了一种端到端训练方案；(3) 将查询转化为'检索优化字符串'的思路比传统 query 改写更直接。

HIVE: Query, Hypothesize, Verify An LLM Framework for Multimodal Reasoning-Intensive Retrieval

HIVE 提出假设驱动的迭代检索框架，包含四个阶段：(1) 初始检索；(2) LLM 基于 top-k 候选生成补偿性查询，明确视觉和逻辑缺口；(3) 用细化查询二次检索；(4) LLM 对合并候选进行验证与重排。在 MM-BRIGHT 基准（2,803 个真实查询，覆盖 29 个技术领域）上取得显著提升。HIVE 是即插即用框架，可叠加在任意检索器上，无需额外训练。

INSIGHTHIVE 的'检索-假设-验证'循环为搜索系统提供了一种增量式改进检索质量的方法论：(1) 补偿性查询合成——分析初始检索结果的不足并生成改进查询——可应用于 UGC 搜索的 query refinement；(2) 即插即用的特性使其可以直接叠加到现有搜索链路上做 reranking；(3) 迭代检索+验证的模式适用于需要高精度的搜索场景，如社区内容审核或专业问答。

A Systematic Study of Retrieval Pipeline Design for Retrieval-Augmented Medical Question Answering

本文对 RAG 系统中检索管线设计进行了系统性评估，在 MedQA USMLE 基准上分析了语言模型、embedding 模型、检索策略、查询改写和 cross-encoder 重排在 40 种组合配置下的交互效果。结果表明检索增强在零样本条件下显著提升医学问答性能，但各组件之间存在强交互——最优 embedding 选择取决于 LLM 和检索策略，cross-encoder 重排的收益因上下文而异。

INSIGHT该研究的 40 种配置对比为检索系统工程实践提供了宝贵的组件交互数据：(1) embedding 模型选择不应孤立决策，需考虑与下游排序模型的匹配——这在 UGC 搜索中同样成立；(2) cross-encoder 重排并非总是有效，需评估具体场景下的成本收益；(3) 查询改写的效果高度依赖基础检索器的能力，改写策略需与检索器联合调优。系统性消融实验的方法论值得搜索团队在技术选型时借鉴。

Nusrat Sultana, Abdullah Muhammad Moosa, Kazi Afzalur Rahman, Sajal Chandra Banik

CubeGraph: Efficient Retrieval-Augmented Generation for Spatial and Temporal Data

CubeGraph 提出了一种面向时空数据的向量检索索引框架，解决高维向量相似度搜索与时空过滤混合查询的效率问题。现有系统将向量索引嵌套在低维空间结构（如 R-tree）中，导致向量空间碎片化，每次查询需调用多个不相交的子索引。CubeGraph 使用层次化网格划分空间域，在每个 cell 内维护模块化向量图，查询时动态拼接相邻 cell 的图进行联合搜索，实现了向量搜索与空间约束的原生整合。

INSIGHTCubeGraph 对搜索基础设施建设有两个重要启示：(1) 在 UGC 搜索中，帖子通常带有时间和地域属性，传统的'先向量召回再过滤'方案效率低下，CubeGraph 的原生整合方案提供了更优的思路；(2) 层次化网格+模块化向量图的架构在保持检索质量的同时减少了遍历开销，适用于需要复合条件过滤的搜索场景。该方法代表了向量检索从纯相似度搜索向结构化约束搜索演进的趋势。

Mingyu Yang, Wentao Li, Wei Wang

JU'A -- A Benchmark for Information Retrieval in Brazilian Legal Text Collections

JU'A 是一个面向巴西法律文本的信息检索基准，支持法律判例检索、立法检索、监管文本检索和问答驱动的法律搜索等多种任务。评估了词汇检索（BM25）、稠密检索和 BM25+重排管线，包括在 JU'A 数据上微调的 Qwen embedding 模型。结果表明该基准在异构文本类型上具有足够的区分度，能有效区分不同检索方法的优劣。域适应后的 Qwen embedding 在法律文本上显著优于通用模型。

INSIGHTJU'A 的评估结果为检索系统选型提供了有价值的参考：(1) 域适应微调对 embedding 模型至关重要——在 UGC 搜索中同样需要针对社区内容分布做微调，而非直接使用通用模型；(2) BM25+重排管线在结构化文本上仍有竞争力，说明在特定场景下简单方案不应被忽视；(3) 构建领域特定评测基准对搜索质量监控至关重要，该方法论可借鉴到 UGC 搜索的评测体系建设中。

Jayr Pereira, Leandro Fernandes, Erick de Brito, Roberto Lotufo, Luiz Bonifacio
