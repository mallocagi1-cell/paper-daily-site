The Unreasonable Effectiveness of Data for Recommender Systems

本文系统研究了推荐系统中训练数据量与离线推荐性能之间的关系。作者使用 LensKit 和 RecBole 两大工具包，在 11 个超过 700 万交互的公开数据集上评估了 10 种算法组合，训练数据量从 10 万扩展到 1 亿交互。实验结果表明 NDCG@10 随数据量增加持续提升，未观察到明显的饱和点——最大样本量下约 75% 的实验点同时达到了组内最优性能。这一发现对推荐系统的数据投资决策具有直接指导意义。

CASE: Cadence-Aware Set Encoding for Large-Scale Next Basket Repurchase Recommendation

Walmart📖 深度解读 · 7 分钟 →

Walmart 提出 CASE，一种面向大规模零售场景的复购推荐模型。CASE 的核心创新在于将商品级别的复购节奏（cadence）学习与跨商品交互解耦：用日历时间信号表示每个商品的购买历史，通过共享多尺度时间卷积捕捉周期性复购节奏，再用 induced set attention 以亚二次复杂度建模跨商品依赖。在三个公开基准和 Walmart 千万级用户生产数据上，CASE 的 Top-5 Precision 提升 8.6%、Recall 提升 9.9%。

INSIGHTCASE 最大的实践启示在于将「时间」从序列位置编码中解放出来——用真实日历时间而非访问顺序建模复购节奏。这种 cadence-aware 设计在电商、社区等有周期性消费/浏览行为的场景中可直接借鉴。此外，induced set attention 的亚二次复杂度设计使模型可在千万级用户规模下批量推理，证明了精细化时间建模与生产可用性可以兼得。Walmart 的大规模 A/B 结果增强了该方法的可信度。

Yanan Cao, Ashish Ranjan, Sinduja Subramaniam, Evren Korpeoglu, Kaushiki Nag, Kannan Achan

Leveraging LLMs and Heterogeneous Knowledge Graphs for Persona-Driven Session-Based Recommendation

本文提出一种面向会话推荐的 persona 驱动框架，通过异构知识图谱推断匿名用户的潜在 persona，并结合 LLM 生成丰富的物品表示。框架采用两阶段架构——个性化信息抽取（从 KG 中提取时间、语义、社交等多类型关系推断用户 persona）和个性化信息利用（将 persona embedding 注入会话推荐模型），灵感来源于 chain-of-thought 推荐方法。该方法有效缓解了匿名会话下的冷启动和数据稀疏问题。

INSIGHT本文最大的价值在于提出了一条从匿名会话中恢复用户 persona 的可行路径——不依赖显式用户画像，而是通过异构 KG 中的多维关系（时间、语义、社交）间接推断。这对 UGC 社区等匿名或弱登录场景有直接参考价值。LLM 在此处作为物品表示增强器而非直接推荐器使用，避免了 LLM 推理延迟问题。但实际部署需关注 KG 构建和维护成本。

Muskan Gupta, Suraj Thapa, Jyotsana Khatri

NestPipe: Large-Scale Recommendation Training on 1,500+ Accelerators via Nested Pipelining

Huawei

NestPipe 是面向万亿参数推荐模型的大规模去中心化 embedding 训练框架，解决了 1500+ 加速器集群上训练推荐模型时的数据移动瓶颈。框架通过嵌套流水线设计利用两层稀疏并行机会：批间层面用 Dual-Buffer Pipelining 构建无 staleness 的五阶段流水线缓解 lookup 瓶颈；批内层面基于 embedding freezing 现象设计 Frozen-Window Pipelining 重叠通信与计算。在保持同步训练语义的同时大幅提升吞吐量。

INSIGHTNestPipe 的核心发现——embedding freezing 现象（训练过程中 embedding 参数逐渐趋于稳定）——具有独立的学术价值，为推荐模型的训练优化提供了新视角。对于大型推荐系统团队，NestPipe 的分层流水线思想可借鉴：在不同粒度上分别优化数据移动瓶颈，避免吞吐量与训练一致性的 trade-off。该工作在华为 Ascend 集群上验证，展示了 NPU 在推荐训练场景的适用性。

Leveraging Artist Catalogs for Cold-Start Music Recommendation

本文将冷启动音乐推荐重新定义为「半冷启动」问题——大多数新曲目来自有历史交互的艺术家，因此可利用艺术家级别的协同过滤信号。作者发现 artist-aware 方法可将 Recall 提升超过 2 倍。核心方法是学习从艺术家目录特征到协同过滤潜空间的映射，利用艺术家与曲目之间的层次结构，而非简单地将艺术家信息当作普通输入模态。实验在多个公开数据集上验证了这一思路的有效性。

INSIGHT「半冷启动」这一问题框架值得推广到其他推荐场景——在 UGC 社区中，新帖子往往来自有历史的作者，可直接套用相同思路：利用作者级别的协同信号缓解内容冷启动。艺术家-曲目的层次建模方法可推广为创作者-内容的层次建模。该工作 2 倍以上的 Recall 提升表明，充分利用已有的层次关系是低成本高收益的冷启动解法。

EviSnap: Faithful Evidence-Cited Explanations for Cold-Start Cross-Domain Recommendation

EviSnap 是一个轻量级跨域推荐框架，其预测结果自带忠实且可审计的证据引用解释。核心方法包括：(1) 离线用 LLM 将噪声评论蒸馏为紧凑的 facet cards，每个 facet 配对原始支撑句子；(2) 通过聚类 facet embeddings 构建跨域共享的概念库；(3) 用证据加权池化计算用户正/负偏好和物品概念激活。整个推荐仅需单层线性分类器，实现了解释性与效率的统一。

INSIGHTEviSnap 的亮点在于将可解释性作为系统设计约束而非事后附加——通过 concept bank 将推荐理由内嵌于模型结构中，避免了 post-hoc 解释与实际决策不一致的问题。对搜索推荐系统的启示：在跨域推荐或冷启动场景，利用 LLM 离线蒸馏用户评论为结构化 facets，既可缓解冷启动又提供可审计的推荐理由。线性分类器的选择也意味着极低的线上推理成本。

Yingjun Dai, Ahmed El-Roby

TREASURE: The Visa Payment Foundation Model for High-Volume Transaction Understanding

Visa

Visa 推出 TREASURE，首个面向高频交易数据的多用途 Transformer 基础模型。模型同时捕捉消费者行为信号和支付网络信号（响应码、系统标志），支持异常检测、个性化推荐等多种下游任务。架构设计包括静态属性和动态属性的专用子模块，通过预训练获得通用的交易表示。在 Visa 工业级数据集上验证了模型在多任务场景下的有效性。

INSIGHTTREASURE 展示了 Transformer 基础模型在非传统推荐数据（交易流水）上的应用范式，核心设计思想可迁移到搜索推荐领域：(1) 将静态特征和动态行为序列分别建模再融合的架构设计适用于任何有用户画像+行为序列的场景；(2) 多任务预训练策略（同时捕捉用户行为和系统信号）可作为构建社区内容理解基础模型的参考。Visa 的工业部署经验也表明这类基础模型在实际业务中是可行的。
