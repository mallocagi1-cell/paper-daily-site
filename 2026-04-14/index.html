Unified Supervision for Walmart's Sponsored Search Retrieval via Joint Semantic Relevance and Behavioral Engagement Modeling

该论文解决了工业搜索系统中检索模型训练信号不一致的问题。现有系统通常使用用户行为信号（如点击）来训练 bi-encoder 检索器，但行为信号是语义相关性的不完美代理——用户可能因流行度、促销或价格等非相关因素而点击商品。Walmart 提出联合语义相关性与行为参与度的统一监督框架，在保持低延迟在线服务的同时显著提升检索质量。线上实验表明该方法在 Walmart 搜索广告系统中带来了明显的收入和相关性提升。

When & How to Write for Personalized Demand-aware Query Rewriting in Video Search

📖 深度解读 · 11 分钟 →

WeWrite 提出了个性化需求感知的查询改写框架，解决视频搜索中用户意图理解的三个关键问题：何时改写（When to Write）、如何改写（How to Write）、以及如何利用历史行为（Write with History）。通过自动化后验挖掘策略从用户日志中提取高质量样本，识别需要改写的场景，并基于用户历史行为生成个性化的查询改写。该方法在视频搜索场景中有效缓解了隐式历史特征的信号稀释和延迟反馈问题。

INSIGHT该工作的核心思路是将查询改写视为一个生成式任务，且引入了'何时触发改写'的决策机制——这在实际搜索系统中非常关键。对于 UGC 搜索场景，用户查询通常较短且模糊，需求感知的改写策略可以有效补充查询意图。后验挖掘策略提供了一种低成本获取改写训练数据的方法，避免了大规模人工标注。

Cheng cheng, Chenxing Wang, Aolin Li, Haijun Wu, Huiyun Hu, Juyuan Wang

Beyond Relevance: Utility-Centric Retrieval in the LLM Era

该论文提出在 LLM 时代，信息检索系统应从传统的相关性优化转向效用（Utility）优化。传统检索系统优化 topical relevance——文档与查询的主题匹配度，但这只是用户真实目标的近似。在 RAG 场景中，检索文档不再直接呈现给用户，而是作为 LLM 推理的证据，这从根本上改变了检索的评价标准。论文系统性地分析了效用驱动检索的理论框架和实践路径。

INSIGHT论文的核心洞察是 LLM+RAG 范式下检索目标的范式转移：从'文档是否匹配查询'转向'文档是否有助于下游任务完成'。这对搜索系统的启示在于，排序模型不应仅优化 nDCG 等相关性指标，还应考虑检索结果对用户任务完成度的贡献。在 UGC 搜索场景中，这意味着需要区分'主题相关但信息冗余'和'真正有价值'的内容。

Hengran Zhang, Minghao Tang, Keping Bi, Jiafeng Guo

BracketRank: Large Language Model Document Ranking via Reasoning-based Competitive Elimination

BracketRank 将文档重排序建模为推理驱动的竞争淘汰赛：文档在锦标赛结构中两两对比，LLM 通过逐步推理判断哪个文档更相关。该框架引入三项创新：(1) 基于模型上下文限制的自适应分组；(2) 要求逐步相关性解释的推理增强提示；(3) 处理语义近似文档的平局解决机制。相比传统 listwise/pointwise LLM 排序方法，BracketRank 在推理密集型检索任务上表现更优。

INSIGHT将排序问题转化为'锦标赛式两两比较+推理链'是一个新颖的视角，充分利用了 LLM 的推理能力。核心启示：在搜索场景中，LLM 重排序不必沿用传统的 pointwise/listwise 范式，可以设计更符合 LLM 推理特性的排序框架。该方法特别适合语义复杂、需要深层推理的检索场景，但其推理开销在延迟敏感的在线服务中需要权衡。

Abdelrahman Abdallah, Mohammed Ali, Bhawna Piryani, Adam Jatowt

Generalization and Scaling Laws for Mixture-of-Experts Transformers

该论文为 Mixture-of-Experts (MoE) Transformer 建立了泛化和缩放理论，清晰地将每个输入的'活跃参数容量'与路由组合的复杂度分离。通过条件化固定路由模式并进行联合界估计，推导出 metric entropy 与活跃参数预算成比例的上确界覆盖数界。论文进一步证明了 MoE 架构的构造性近似定理：近似误差可通过扩大活跃参数容量或增加专家数量来降低，取决于当前瓶颈。

INSIGHTMoE 架构是当前大规模推荐模型（如 Meta HSTU/GEM）的核心组件，该理论工作为理解推荐模型的 Scaling Law 提供了数学基础。核心发现：MoE 的泛化能力主要取决于'活跃参数'而非总参数量，这意味着在推荐系统中可以通过增加专家数（总参数量）而不增加推理开销来提升模型容量。这为推荐模型的 scaling 策略提供了理论指导。

Beyond Isolated Clients: Integrating Graph-Based Embeddings into Event Sequence Models

该论文解决了用户行为序列建模中忽视全局用户-物品交互图结构的问题。虽然自监督学习（SSL）能有效建模事件的时序顺序，但通常忽略用户-物品交互的全局图结构。论文提出三种模型无关的策略，将图结构信息整合到对比式自监督学习中：丰富事件序列表征、利用图 embedding 作为辅助监督信号、以及将图结构作为数据增强手段。实验在推荐和欺诈检测场景中验证了有效性。

INSIGHT核心思路是将用户行为序列的局部时序信息与全局交互图的结构信息融合，这在生成式推荐模型中同样重要：当前基于 Transformer 的序列推荐模型主要建模时序依赖，忽视了用户-物品的全局协同关系。该工作提供的模型无关整合策略可以直接应用于 HSTU 等生成式推荐架构中，增强用户表征的全局感知能力。

Dynamic Ranked List Truncation for Reranking Pipelines via LLM-generated Reference-Documents

该论文提出使用 LLM 生成参考文档来动态截断排序列表，从而提高 LLM 重排序管道的效率。LLM 重排序面临计算开销和长上下文的挑战，传统方法通过固定截断或简单启发式来控制重排序输入量。论文的方法利用 LLM 生成一个'理想参考文档'，然后基于候选文档与参考文档的相似度来决定截断点，实现按查询自适应的动态截断。

INSIGHT利用 LLM 生成'理想参考文档'作为排序锚点是一个巧妙的思路——本质上是让 LLM 先'想象'最佳答案，再用它来过滤候选。这一生成式方法可以推广到搜索系统的多个环节：例如在召回阶段生成理想文档 embedding 进行 ANN 检索，或在 UGC 搜索中生成查询的'理想回答'来辅助相关性判断。

Nilanjan Sinhababu, Soumedhik Bharati, Debasis Ganguly, Pabitra Mitra
