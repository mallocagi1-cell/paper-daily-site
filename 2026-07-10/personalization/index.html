Field Matters: A Lightweight LLM-enhanced Method for CTR Prediction

CTR 预估是推荐和广告精排的核心任务，LLaCTR 选择不把完整文本逐条送入 LLM，而是在字段级蒸馏轻量语义知识。方法先做自监督 field-feature fine-tuning，再把字段语义注入特征表征和交互层；论文在 6 个代表性 CTR 模型、4 个数据集上验证效果与效率，适合需要控制线上成本的推荐排序场景。

When and How to Ask: Dynamic Preference Elicitation Strategies for Conversational Recommendation

论文关注会话式推荐中的“何时问、问什么”问题，指出固定的属性询问策略无法适配多轮对话中不断收敛的用户偏好。作者构建带有偏好询问必要性和策略选择细粒度标注的 InPE 数据集，并提出 COPE 混合专家架构建模阶段感知的询问策略；SIGIR 2026 收录版本显示，早期属性询问更有效，后期 item-based 询问更占优。

INSIGHT对 UGC 社区搜索和推荐入口，这类策略可转化为动态澄清问题：冷启动阶段先问主题、场景、地域等属性，用户意图变窄后再给出具体帖子或商品让用户反馈。关键不是增加更多对话轮数，而是用阶段感知策略减少无效询问，把显式偏好采集接入排序特征和后续召回约束。

Feng Xia, Shuo Zhang, Xi Wang

Seeing and Reflecting: Multimodal Memory-Enhanced Agent Collaboration for Recommendation

MMEACR 面向 LLM agent 推荐系统的文本中心化和粗粒度记忆问题，引入双轨记忆架构：推理轨由 User/Item Memory Agents 维护可解释多模态记忆，匹配轨从交互叙事和商品图像构建解耦 embedding memory。两条轨道通过加权 Reciprocal Rank Fusion 融合，论文在 3 个真实领域测试，并强调视觉相关推荐场景的增益更明显。

INSIGHT这篇论文给多模态推荐提供了一个可落地的拆分方式：让 agent 记忆负责解释和偏好更新，让 embedding memory 保留图像与行为细节，最后在排序层融合。社区内容推荐可借鉴这种双轨设计，把帖子文本、封面图、用户反馈分开建模，避免所有信息都压进单一 LLM 记忆导致漂移和噪声放大。

Hao Cong, Huizu Lin, Zihan Wang, Chengkai Huang, Quan Z. Sheng, Lina Yao

Kuaishou

这篇中文工业实践报道总结快手生成式推荐技术沙龙，覆盖 OneReason、Pool-Rec、OneSearch V2、GR4AD 等系统化落地。OneReason 侧重为推荐任务构建 CoT 数据体系和 RL 数据飞轮，Pool-Rec 则从异构算力池化、调度、推理引擎支撑推荐预估系统；文章发表于 2026-06-16，是本轮报告中的中文行业实践补充。

Ad Headline Generation using Self-Critical Masked Language Model

论文把广告标题生成建模为带自批判机制的 masked language modeling 任务，目标是在生成文案时兼顾吸引力与约束。它与推荐个性化的关系不在召回模型本身，而在广告/内容分发的创意侧特征供给：标题质量会影响 CTR 标签、候选点击率和排序反馈；2026-07-09 的新近提交提高了其时效性。

INSIGHT对推荐系统来说，创意生成不应只作为独立 AIGC 模块，而应纳入排序闭环：生成标题、审核合规、预估 CTR、线上反馈需要共享实验设计。可借鉴自批判训练思想，为 UGC 标题改写或广告标题生成加入 reward/checker，避免只优化语言流畅度而牺牲点击后满意度。

SynthAVE: Scalable Synthetic Labeling for E-Commerce with LLM-Arena Validation

SynthAVE 关注电商场景的大规模合成标注，使用 LLM-Arena Validation 评估和筛选自动生成标签。它不是排序模型论文，但解决推荐系统常见的数据瓶颈：商品、内容、属性标签不足会限制召回、粗排和精排特征质量；论文标题明确指向 e-commerce，且 2026-07-09 新提交，适合纳入个性化特征工程候选。

INSIGHT推荐个性化经常卡在高质量 item/content 标签供给，而不是模型结构本身。该思路可转化为“LLM 生成候选标签 + arena/偏好验证 + 下游 CTR/召回离线回放”的数据闭环，用较低人工成本扩大属性覆盖，但上线前必须用真实点击、收藏、跳出等指标验证标签是否提升排序。

R^3: Advertisement Compliance Rectification via Group-Relative Experience Extractor and Curriculum Reinforcement

R^3 针对广告合规整改，提出 Group-Relative Experience Extractor 与 curriculum reinforcement 的组合，用于把不合规广告内容改写到可投放状态。它与个性化推荐的直接相关性弱于 CTR/用户建模论文，但广告推荐链路需要同时优化点击、转化和合规风险；新近提交使其可作为推荐安全和创意治理参考。

INSIGHT推荐系统中的多目标不只包括 CTR/CVR，也包括合规、低质内容抑制和用户体验约束。R^3 的启发是把合规反馈结构化为可学习经验，再用课程强化学习逐步提高整改质量；社区平台可以把类似机制用于标题党、违规营销或低质 UGC 的生成式修复。

From Text to Parameters: Predicting Item Parameters from Embedding Regularization with Reliability and Design Ceilings

该论文研究如何从文本预测 item parameters，并用 embedding regularization、reliability 和 design ceilings 控制预测质量。虽然原始问题更偏测量学/参数估计，但“从文本到可排序参数”的范式可迁移到推荐系统：把帖子、商品或问答文本转成可校准的质量、难度、意图等参数，再作为个性化排序特征。

INSIGHT社区推荐中大量新内容缺少交互数据，冷启动排序常依赖文本和作者侧先验。这个方向提示可以用文本 embedding 预测内容参数，并为每个参数附带可靠性估计；排序模型随后可按置信度调整特征权重，避免新内容因噪声文本参数被过度提权。

Capturing token IDs during agentic interactions for better reinforcement learning

Amazon

Amazon Science 这篇工程博客讨论在 agentic interactions 中捕获 token IDs，以便更好地进行强化学习。它不是推荐系统专文，但对推荐/搜索中的 LLM agent 或对话式推荐很实用：如果训练日志只保留文本，后续 reward learning、复现和 credit assignment 会丢失关键 token 级信息；文章发表于 2026-07-09。

INSIGHT推荐系统若引入对话 agent、生成式解释或 RLHF/RLAIF，需要从一开始就设计可训练日志，而不是只存最终文案和点击。token ID、工具调用、候选集、排序分和用户反馈应放在同一条轨迹里，后续才能做精确归因、重放训练和策略评估。

Refine Thought: A Test-Time Inference Method for Embedding Model Reasoning

Refine Thought 是一种面向 embedding model reasoning 的测试时推理方法，通过对文本 embedding 模型运行多次 forward pass 得到最终语义表征。论文报告其在 BRIGHT 语义推理任务和 PJBenchmark 人岗匹配基准上有明显提升，同时保持 C-MTEB 等通用语义理解表现；它更偏检索/匹配，但可迁移到个性化召回。

INSIGHT个性化推荐中的用户-内容匹配常需要处理短文本、隐含意图和长尾语义，单次 embedding 可能不足以表达复杂偏好。RT 的启发是把测试时额外计算预算投向高价值请求或冷启动候选，在不重训主模型的情况下增强语义推理；但线上应用要按流量分层控制多次 forward 的延迟成本。

Guangzhi Wang, Kai Li, Yinghao Jiao, Zhi Liu
