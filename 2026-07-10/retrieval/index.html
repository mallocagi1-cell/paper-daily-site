Healthier LLMs: Retrieval-Augmented Generation for Public Health Question Answering

论文把 PubHealthBench 扩展成检索增强问答评测，共包含 7,929 个来自英国政府公共卫生指南的问题，用来分析 RAG 中检索配置对最终答案的影响。作者比较 dense、sparse、hybrid retrieval、多种 embedding model、语料切分和主题差异，结论是 hybrid retrieval 在召回与排序质量上更稳定，chunk length 与主题会显著影响 ranking performance。对 UGC 短文本搜索来说，它提供了一个可复用的离线实验框架：不要只看生成答案，也要拆开评估召回、排序和上下文质量。

5ting at SemEval-2026 Task 8: Strong End-to-End Multi-Turn RAG via LLM-Based Reranking and Faithfulness Control

这篇 SemEval-2026 Task 8 系统报告聚焦多轮 RAG 检索，组合 BGE-M3 dense retrieval、FAISS 索引、双查询合并召回、LLM reranking 和受证据约束的角色分离生成。论文报告检索子任务 nDCG@5 = 0.4719，端到端任务 harmonic score = 0.5597，RL_F = 0.7692，说明简单但完整的“召回-重排-可信生成”链路仍然有竞争力。它与社区搜索中的多轮查询、上下文漂移和证据约束高度相关。

INSIGHT可借鉴点不是单个模型，而是工程化链路：用双查询扩大召回，用 LLM reranker 处理上下文相关性，再把生成阶段约束在检索证据内。对于短文本 UGC 搜索，这意味着可以把原 query、改写 query 和用户上下文 query 并行召回，再用重排模型做统一排序，同时把无证据答案或低置信结果降权。

Thien-Qua-T-Nguyen, Chi Hoang, Nguyen Tran, Tri Le, Khanh Truong, Chinh Trong Nguyen

MTEB-BR: A Text Embedding Benchmark for Brazilian Portuguese

MTEB-BR 针对巴西葡萄牙语缺少原生 embedding benchmark 的问题，构建了 22 个本地任务，覆盖分类、多标签、语义相似、聚类、retrieval 和 reranking，并排除翻译数据。作者评测 93 个模型，其中 73 个 open-weight、20 个闭源商业 API，参数规模从 23M 到 27B，还为 headline comparison 加入 bootstrap confidence interval、paired-bootstrap significance 和任务区分度分析。虽然语言是葡语，但方法直接对应多语言/方言 UGC 搜索评测。

INSIGHT这篇论文提醒搜索团队：embedding leaderboard 如果依赖翻译语料，很可能高估真实社区内容上的表现。对于中文社区搜索，可以按它的做法建设原生短文本、评论、问答和帖子检索任务，并用置信区间和任务区分度过滤“看似领先但不可复现”的模型差异，减少盲目替换 embedding 模型的风险。

Tardelli Ronan Coelho Stekel

ReContext: Recursive Evidence Replay as LLM Harness for Long-Context Reasoning

RECONTEXT 提出 Recursive Evidence Replay，把长上下文中的证据组织与最终生成分离：系统先利用模型内部相关性信号构造 query-conditioned evidence pool，再在回答前递归回放关键证据，同时保留完整原始上下文。方法不需要训练、外部 memory 或 context pruning，适合在检索召回后做轻量证据重排和上下文增强。对搜索场景，它更接近一种“生成前证据排序/压缩”策略。

INSIGHT如果 UGC 搜索结果要进入 LLM 摘要或搜索助手，瓶颈常常不是召回不到，而是证据顺序和局部上下文组织不稳定。RECONTEXT 的启发是把 top-k 结果二次组织成面向 query 的 evidence pool，让模型先看到最相关片段再生成；这可以作为 cross-encoder rerank 之外的轻量后处理方案。

Yanjun Zhao, Ruizhong Qiu, Tianxin Wei, Yuanchen Bei, Zhining Liu, Lingjie Chen, Ismini Lourentzou 等 9 人

Human-in-the-Loop Nugget Annotation for Accountable LLM-as-a-Judge Evaluations

论文讨论 LLM-as-a-Judge 评估中人类监督容易失真的问题：一种做法会让专家被模型输出锚定，另一种则让专家承担过重标注负担。作者提出 human-in-the-loop nugget annotation 工具，让人类先识别“哪些信息点重要”，LLM 再负责大规模匹配输出是否覆盖这些 nuggets，并用 nugget banks 支撑自动评测。它对搜索相关性评测、答案覆盖率评测和人工质检流程都有迁移价值。

INSIGHT社区搜索的相关性评估可以借鉴 nugget 思路：让标注者定义 query 下必须满足的信息点，再让模型批量判断候选帖子是否覆盖，而不是直接要求模型给整体相关性分。这样既能保留人工对意图的控制，又能把 LLM 用在高吞吐匹配环节，降低长尾 query 和多答案 query 的评测成本。

Laura Dietz

Riemannian Geometry for Pre-trained Language Model Embeddings

论文研究预训练语言模型 embedding 的黎曼几何结构，提出 Riemannian Mean Pooling：从编码器解析 Jacobian 提取 token 级 pullback metrics，再在 SPD 流形上用 Fréchet mean 聚合。实验显示，在 CoLA、CREAK、RTE 三个含语言结构信号的数据集上，RMP 优于欧式 mean pooling；在去除词汇伪相关的 FEVER-Symmetric 上保持 chance，说明方法对真实结构信号更敏感。它不是检索论文，但对 embedding pooling 有参考意义。

INSIGHT短文本检索常把句向量池化当成固定组件，这篇论文提示 pooling 方式本身可能决定语义信号是否被保留。实际系统不一定要直接实现 RMP，但可以把“不同 pooling 对 query/document 表征的影响”纳入 embedding 评测，尤其是在口语、方言、反事实和低资源文本上检查模型是否只学到词面捷径。

Szczepan Konior, Alexandre Quemy, Przemys{\l}aw Klocek, Gr\'egoire Cattan, Bart{\l}omiej Sobieski

MILES: Modular Instruction Memory with Learnable Selection for Self-Improving LLM Reasoning

MILES 关注 LLM 在连续任务中的自我改进：它动态扩展 step-wise memory，并在测试时用 correctness-optimized memory composition 选择可复用指令片段，避免存储整段 solution template 泛化差、启发式选择不优化最终正确率的问题。方法针对 memory 增量扩张和监督有限的现实约束设计。它不是传统 IR，但涉及 query-conditioned memory selection，可迁移到搜索助手和复杂问答。

INSIGHT如果搜索助手要长期服务同一用户或同一业务域，记忆检索不能只按相似度取“完整历史答案”。MILES 的启发是把可复用经验拆成模块化步骤，再学习组合策略；社区搜索可以把成功 query 改写、过滤条件、排序偏好拆成可检索 memory unit，用于后续会话的 query understanding。

Ruilin Tong, Dong Gong

Future Confidence Distillation in Large Language Models

论文研究 LLM 置信度如何随解题过程演化，比较回答前 Feeling-of-Knowing 与回答后 Judgement-of-Learning，并指出后验置信度通常校准更好、更有区分度；隐藏表征中的线性 probe 能恢复比显式口头置信度更丰富的信息。作者提出 Future Confidence Distillation，用未来时刻的置信信号指导当前模型。它与检索触发、工具调用和自适应计算有关。

INSIGHT搜索系统中是否触发二次召回、重排或人工兜底，本质上依赖置信度判断。该文的启发是不要只信模型在回答前说“我知道”，而要用检索后、重排后或生成后的校准信号训练 gating；对社区搜索助手而言，可用这类信号决定是否扩大召回、展示更多证据或拒答。

Sahil Kale

Event-Centric World Modeling with Memory-Augmented Retrieval for Embodied Decision-Making

ERA 框架面向 embodied decision-making，把环境表示成结构化 semantic events，并编码为可解释 latent representation；决策时从 event-action 知识库检索相似经验，再通过加权聚合生成最终动作。论文在 UAV navigation 场景展示实时性能和动态环境下的自适应行为。虽然应用不是文本搜索，但“事件表征-经验检索-聚合决策”的结构与会话记忆检索、用户行为检索有相似性。

INSIGHT对搜索/推荐从业者有价值的是其可解释检索式决策框架：把历史交互拆成事件，再用检索出的相似事件解释当前动作。社区搜索可以把用户 query reformulation、点击、停留和反馈组织成事件库，用于 query session 级别的个性化排序或失败 query 诊断，而不是只依赖黑盒序列模型。

Zhaowen Fan, Rongchao Zhang, Yunxiang Han

The power of collaboration: How we can reduce traffic congestion

Google

Google Research 这篇工程博客讨论如何通过协作机制降低交通拥堵，属于算法与系统实践而非搜索相关性论文。它被纳入是因为硬去重后缺少检索方向的行业实践候选，同时覆盖规则要求至少保留一个主要科技公司的工程实践条目。对搜索团队而言，直接方法迁移有限，但其中关于多主体协作、约束优化和现实系统落地的思路可作为排序目标设计的旁路参考。

INSIGHT该条目的实践启示主要在工程组织层面：真实系统优化往往不是单模型指标最大化，而是在多方约束和局部反馈之间求稳定改进。UGC 搜索排序也类似，需要同时平衡相关性、点击率、内容质量和供给多样性；不过它不是搜索/推荐专项内容，应在报告中视为行业覆盖补位项。
