Attention Calibration for Position-Fair Dense Information Retrieval

dense retrieval 存在位置偏置——相关信息出现在 passage 后段时检索效果下降。论文把推理期 attention calibration 适配到检索任务，无需重训练，并引入强度系数 λ 在原始注意力与完全校准之间插值。在 3 个 embedding 模型、SQuAD-PosQ 与 FineWeb-PosQ 两个基准上系统研究 basket size、校准层集合与强度的影响，发现部分校准常优于完全校准；单一配置 (B=128, λ=0.5, 50% 层深) 提升了 FineWeb-PosQ 上跨位置组 nDCG@10 的调和平均。

Col-Bandit: Query-Time Top-K Estimation for Late-Interaction Retrieval

IBM

ColBERT 等多向量 late-interaction 检索质量 SOTA，但 query 时成本被 token 级 MaxSim 穷举主导。N 个候选对 T 个 query token 构成 N×T 的 MaxSim 矩阵，其行和即 late-interaction 分数，求 top-K 很少需要全部元素。Col-Bandit 将其建成 bandit：分批揭示矩阵元素，对每个候选维护有限总体 Bernstein-Serfling 置信区间，凡上界低于第 K 大下界的文档永久剪枝，只计算分离 top-K 所需的格子。单一松弛旋钮 α_ef∈(0,1] 调节算力-精度权衡，部署用 α_ef=0.2。

INSIGHTlate-interaction（ColBERT 风格）精度高但算力贵，是落地核心障碍。Col-Bandit 把 top-K 当成统计置信问题，用置信区间提前剪枝，把 MaxSim 计算降到'够分出 top-K 即可'，且只有一个旋钮调权衡——对既要高相关性又卡延迟的社区搜索重排阶段有直接借鉴价值。

Roi Pony, Adi Raz Goldfarb, Oshri Naparstek, Idan Friedman, Udi Barzelay, Eli Schwartz

Can LLM Rerankers Predict Their Own Ranking Performance?

CAS

检索效果随 query 波动大，在拿到相关性标注前预估排序质量（QPP）很重要。论文研究 reranker-internal QPP：LLM reranker 能否估计自己刚产出排序的质量。免训练方案考察跨采样排序的 metric-specific self-consistency 和 reranker 直接给出的 verbalized confidence。在 TREC DL 2019–2022、4 个 LLM 上，self-consistency 与 SOTA 相当且几乎所有设置下校准更好，而直接 verbalized confidence 严重过度自信；论文进一步提出两种改进 verbalized confidence 的策略。

INSIGHT让 reranker 自评排序质量，可在线决定是否触发更贵重排/兜底，或对低置信 query 走扩召回。关键结论：直接问模型'你多有信心'不可靠（过度自信），但跨多次采样的自一致性可靠且校准良好——社区搜索可用 self-consistency 做 query 难度路由，而非轻信 LLM 的口头置信。

Shiyu Ni, Keping Bi, Jiafeng Guo, Jingtong Wu, Zengxin Han, Xueqi Cheng

Slipstream: Locality-Aware Graph Index Construction for Streaming Approximate Nearest Neighbor Search

University of Washington

图索引广泛用于高召回 ANNS，但很多实时应用需要 streaming ANNS：持续到达的 embedding 必须先在已有图上搜索候选邻居再更新边，反复建图成为流式摄入瓶颈。Slipstream 利用向量流的连续性——新到点从上一次插入找到的有希望候选出发，而非从入口点重新搜索；它评估不同的起始候选子集，再由自适应控制器根据流的稳定性收窄或放宽搜索范围，显著降低频繁插入的计算成本。

INSIGHT社区平台 UGC（帖子/评论）持续高频写入，向量索引的增量构建延迟直接影响新内容的可被搜性。其核心 insight 是相邻到达向量在图上的近邻高度重叠，可复用上次插入的搜索结果做'热启动'，并按流稳定性自适应调整搜索宽度——对实时召回索引的写入吞吐优化有直接工程价值。

Shubing Yang, Dongfang Zhao

Cost-Aware Query Routing in RAG: Empirical Analysis of Retrieval Depth Tradeoffs

RAG 面临三方张力：更深检索改善事实 grounding，但抬高 token 成本与端到端延迟，静态检索配置无法适应异质 query。CA-RAG 是逐 query 路由框架，从离散的 strategy bundle 目录中选择——每个 bundle 把检索深度（从免检索直接推理到 top-k=10 dense 检索）与固定生成 profile 绑定，通过最大化'质量先验线性组合延迟与 token 惩罚'的标量效用来选择。系统用 FAISS dense 检索 + OpenAI chat/embedding API 实现并评估。

INSIGHT不是所有 query 都值得深检索——定义类 query 浅召回足够，复杂分析类才需深召回。把'检索深度'做成可路由的离散策略、并用 quality/latency/cost 的标量效用统一权衡，是搜索系统降本的实用思路；社区搜索可据 query 类型动态调召回深度与重排档位，而非一刀切 top-k。

Sanjay Mishra

Do Neural Retrievers Prefer Certain Documents? Evidence of Learned Relevance Priors

神经检索器从标注 query-doc 对学习相关性，但标注协议只标了文档子集且可能偏好某些文档类型。论文研究有监督 bi-encoder 是否隐式学到 query 无关的'文档级相关性先验'：通过在冻结文档 embedding 上训练简单分类器估计该先验，在多个 IR 基准、3 个 SOTA 检索器上评估，发现这种先验可泛化到未见文档、跨模型一致，并造成'可发现性 gap'——先验低的文档即便真相关也系统性更难被检索到。

INSIGHTdense 检索器会因训练标注偏置而系统性偏爱某类文档、与 query 无关——这在 UGC 搜索里意味着某些风格/长度/类型的帖子被结构性压制，伤害长尾内容曝光与公平性。可借鉴其诊断手段（冻结 embedding 上训分类器探测先验），在上线前审计召回模型的内容偏置。

Francisco Valentini, Edgar Altszyler, Martin Fajcik

Structures Facilitate Retrieve, Rerank, and Generate

Nanjing University

文档接地对话系统通常把文档切成独立 passage 做检索与生成，既没用好文档内结构，也没给知识选择/回复足够上下文。SF-Re2G 系统性改进：一是用同 section 内 passage 互相对比来改善 passage 表示，提升检索；二是构建结构增强 reranker——利用同一轮对话的多个 grounding passage 往往在文档结构上相邻，把检索候选按文档结构分组成子图，reranker 结合其所在组重新打分。

INSIGHT把'文档结构'当作检索与重排的显式信号——同 section 对比学表示、同邻域分组重排——对长文档/结构化 UGC（如带小标题的攻略帖）的召回与重排有启发；尤其重排阶段用候选的结构邻域共现做联合打分，而非孤立 passage 评分，可提升上下文完整性。

Yeqin Zhang, Haomin Fu, Xujie Zhang, Cam-Tu Nguyen

R^{2k} is Theoretically Large Enough for Embedding-based Top-k Retrieval

HKUSTUIUCNVIDIA

论文研究最小 embedding 维度 MED：使 m 个对象向量中任意大小≤k 的子集都能被打分比较精确检索出的最小维度。结论：对内积、欧氏距离、余弦相似度，MED 是 Θ(k)，与 m 无关。进一步定义鲁棒 MED（单位归一化且要求 ε 分数间隔），推导 m 相关的可行上界 ε⋆(m,k)=m/√(k(m−1)(m−k))，当 m≫k 时趋于 1/√k，并给出高斯质心构造。合成 top-2 检索仿真与 LIMIT/LIMIT-small 实验印证理论。

INSIGHT给 embedding 维度选择提供了理论下界——精确支持 top-k 检索所需维度只与 k 成正比、与库规模 m 无关。这解释了为何小维度 embedding 在大召回集上会出现'无论怎么训都检不全'的天花板（findability），对选择 embedding 维度、理解 dense 检索容量上限有指导意义。

Zihao Wang, Hang Yin, Lihui Liu, Hanghang Tong, Yangqiu Song, Ginny Wong, Simon See

Section-Weighted Hybrid Approach for Legal Case Retrieval

找真正类似的判例需捕捉表层词重叠之外的法律推理。论文提出两阶段、section 感知框架：先用确定性 LLM 离线把判决书切成事实/争点/裁决/推理。Stage 1 用 BM25 词法与 dense ANN 语义并行全文检索经 RRF 融合成高召回候选池；Stage 2 做细粒度同类比较（如 query 推理 vs 候选推理），用 query 维 Z-score 归一化解决词法分数与余弦相似度的量纲不匹配，再用学习的 section 权重聚合信号，并对 top 结果返回相关 section 文本与简明依据。

INSIGHT工程上实用的组合拳：BM25+dense 经 RRF 召回、用 Z-score 归一化对齐异量纲分数、用 section 级学习权重做结构化聚合。Z-score 归一化解决'词法分无界、cosine 有界'导致的融合失衡，是混合检索落地的常见痛点；section 加权思路可迁移到带字段的 UGC（标题/正文/标签分别加权）。

Rajith Arulanandam, Nisansa de Silva
