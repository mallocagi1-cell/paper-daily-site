Skill Is Not Document: A Query-Conditional Benchmark and Two-Stage Retriever for LLM Agent Skill Routing

LLM agent 完成复杂任务需组合多个 skill，skill 检索是 agent 的前置环节。论文指出 skill 检索与传统文档检索的本质差异在监督信号层面：top-K 联合正确性不仅取决于单个 query-skill 对的语义相关性，还取决于被一起检索出来的多个 skill 能否协作完成任务，这种 skill 兼容性无法从独立相关性推导。论文构建 query-conditional benchmark，并提出两阶段检索器：先按语义召回候选 skill，再建模 skill 间的联合兼容性做重排。

Small RL Controller, Large Language Model: RL-Guided Adaptive Sampling for Test-Time Scaling

test-time scaling 提升大模型推理但带来计算与延迟成本。已有自适应采样靠启发式规则或分布假设决定何时停止采样。论文把自适应采样形式化为 MDP，用 RL 训练一个轻量采样控制器，在每一轮决定停止采样还是再取样本，联合平衡答案正确性、延迟与计算成本；方法轻量，只依赖少量信号，可挂在已有大模型外部。

INSIGHT用一个小 RL 控制器去调度大模型的采样预算，是小模型管大模型的解耦思路。对搜索/推荐里的多路 LLM 打分或 rerank 可借鉴按难度动态分配推理预算——简单 query 单次出结果，难 query 才多采样投票，省线上算力而不牺牲难样本质量。

Memory Retrieval for Changing Preferences

长上下文对话系统需同时决定何时访问记忆与哪些历史片段相关。已有方法靠启发式检索信号或始终开启记忆，忽视了用户偏好会随时间变化甚至前后矛盾。论文提出统一框架，把个性化记忆检索定义为识别哪些历史 turn 提供了关于用户潜在偏好状态的证据，而非基于表层语义相似度，并量化每个历史 turn 对当前偏好判断的效用。

INSIGHT把记忆检索从语义相似重构为对当前偏好状态的证据价值，直击推荐中的兴趣漂移问题。对社区个性化搜索可借鉴：用户历史点击/搜索里，近期且与当前 session 偏好一致的行为才该被召回作为上下文，过期或矛盾的行为应被显式降权而非靠相似度兜底。

Adaptive Latent Agentic Reasoning

大型推理模型靠生成长 CoT 提升性能，但应用到 LLM agent 时低效——agent 在每个决策步都生成冗长文本推理，且在多轮间几乎均匀分配推理量，造成多轮 agentic 轨迹的大量浪费。论文提出 ALAR 双模式框架：routine turn 用紧凑的 latent reasoning，需要更深思考时才升级到显式 CoT，latent reasoning 通过 agent 自身的轨迹学习得到。

INSIGHT按需分配推理深度是 agent 提效的关键——多数 routine turn 不需要展开 token 级 CoT。对搜索 agent（多轮调工具、改写 query）可借鉴：常规检索轮用 latent 决策，仅在歧义/冲突时触发显式推理，能显著压缩多轮延迟，对线上多步检索 agent 的成本控制有实操价值。

WRIT: Write-Read Intensive Trajectory Synthesis for Multi-Turn User-Facing Agents

多轮面向用户的 agent 须从不完整请求推断意图、通过对话与工具收集缺失信息、执行有效动作；训练轨迹记录这一过程为 user message / agent response / tool call 交错序列。已有合成 pipeline 多靠把多个用户请求拼成更长任务来增加难度，产出 write-intensive（偏顺序执行）轨迹。论文主张当 agent 必须先收集并比较信息再决策时，单个 write 决策本身就可以很难，提出 write-read intensive 的轨迹合成。

INSIGHT区分 write-intensive（顺序执行难）与 read-intensive（决策前需聚合比较难）两类轨迹难度，对训练搜索 agent 的数据合成有指导意义：要让 agent 学会先多轮检索比对再回答，训练数据就必须包含 read-intensive 样本，而非单纯堆长任务，这对自建 agent 数据合成 pipeline 是直接可用的设计原则。

Adaptive Auto-Harness: Sustained Self-Improvement for Agentic System Deployment on Open-Ended Task Streams

A-Evolve、GEPA、Meta-Harness 等 auto-harness 系统通过从执行反馈优化 prompt、skill、工具、记忆与支撑设施来改进 LLM agent，但通常在固定离线 benchmark 上评测。真实部署面对开放式任务流：历史无限增长、异构任务需不同 harness、问题分布随时间漂移，导致单一频繁更新的 harness 变脆、准确率早期见顶后下滑。论文提出 Adaptive Auto-Harness，做 task-wise 自适应的持续 harness 构建。

INSIGHT指出 agent 自改进系统在开放任务流下会准确率见顶后衰退，是对当前 self-improving agent 评测范式的纠偏。对线上搜索 agent 的持续迭代有警示：按任务类型分桶维护多套 harness（prompt/工具/记忆），比单套全局 harness 更抗分布漂移，离线 benchmark 上的增益不能直接外推到长期线上。

Economy of Minds: Emerging Multi-Agent Intelligence with Economic Interactions

如何让一群 agent 在无中心控制下自组织、自适应成更强的集体智能？受哈耶克去中心化市场协调理论启发，论文构建 agent 经济体：agent 通过拍卖竞争行动权、交换支付、从环境奖励中积累财富。这些经济信号诱导去中心化的 credit assignment，无需全局编排或显式通信协议即可驱动规划；种群通过经济选择演化，高效 agent 积累财富并被变异繁衍。

INSIGHT用拍卖 + 财富积累实现多 agent 间的去中心化信用分配，绕开了显式通信协议设计。这对多 agent 检索/推荐编排提供另一条思路：不预设 agent 间调用图，而用市场化奖励让有效 agent 自然胜出，适合工具/召回源很多且组合不确定的场景。偏前沿研究，距离线上落地尚远，价值在思路启发。

Generalizing Graph Foundation Models via Hyperbolic Retrieval-Augmented Generation

图基础模型 (GFM) 靠大规模预训练做跨域推理，但参数化知识难以应对分布漂移，泛化受限。RAG 被引入以在推理时注入外部知识，但已有 RAG 在欧氏空间运作存在几何局限：欧氏空间的多项式体积增长与图的树状层级结构本质不匹配。论文提出在双曲空间做 RAG，使检索表征与图的层级几何对齐，从而提升 GFM 在分布漂移下的泛化。

INSIGHT指出检索表征的几何空间应匹配数据的内在结构（层级到双曲），对带类目/标签树的社区内容召回有启发：在双曲空间嵌入话题-子话题-帖子层级，可能比欧氏 embedding 更紧凑地保留层级近邻关系。属偏前沿探索，落地需评估双曲算子的工程成本与现有向量检索基建的兼容性。
