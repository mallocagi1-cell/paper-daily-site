From Language to Behavior: Scaling Sequence Transformers for Industrial Recommendation Ranking with Rec-Native Designs

ReST 面向工业推荐排序中行为序列噪声高、时间不规则且一份用户历史需匹配大量候选的问题，采用双门控注意力、旋转位置与时间编码，并把重型可复用编码器和轻量交叉解码器拆开。生产广告平台一周 A/B 测试显示，线上 AUC 提升 1.31%，核心收入指标提升 11.93%，P99 延迟保持在 50 毫秒内。

TGR: Advancing Industrial Recommendation from Generative-Paradigm Ranking toward Unified Generation and Reasoning

Tencent📖 深度解读 · 9 分钟 →

腾讯 TGR 用 CCFormer、BARGE、HiGR 与离线 reason token 串联多任务排序、Semantic ID 生成和推理。系统已服务数亿用户：CCFormer 带来 CTR +3.57% 和广告收入 +1.71%，BARGE 的 Hit@5 提升 10.2%–16.9%，HiGR 离线列表质量提升 15.9%–21.3% 且推理提速 5 倍。

INSIGHTTGR 的价值不只是生成式召回，而是保留逐候选多任务输出，同时逐步把召回、排序和列表目标放进统一表示空间。社区推荐可先借鉴 CCFormer 的字段隔离交叉注意力与层级序列压缩，再将离线生成的语义理由作为冷启动辅助信号，避免在线执行昂贵推理。

Two-Sided State-Space Models for Sequential Recommendation with Non-Random Multimodal Review Feedback

TS-SSM 将评论是否产生视为非随机事件，同时建模用户偏好与物品状态的双向演化；模型融合缺失模式、多模态评论、局部图传播及正负反馈的非对称延续。在六个 Amazon 类目上，Recall@20 相对 BSARec 提升 14.8%–18.8%，平均超过 HM4SR 11.7%；Goodreads Fantasy 上从 0.5191 提升至 0.5847。

SwapRec: Warming Up Cold Items Through Training-Time Swaps

SwapRec 针对 ID 推荐模型遇到冷物品后用户画像失真的问题，把线上常用的“以相似热物品替换冷物品”启发式提前注入训练。作者在电商、电影和音乐三个领域、多个序列模型上验证，训练时保持同样的 swap 分布能稳定提高含冷物品场景的推荐准确率，并增加推荐列表中的冷物品占比。

INSIGHT这是低改造成本的训练—服务一致性方案：无需新增在线模型，只需按线上替换逻辑构造训练样本。社区内容冷启动可用文本或多模态相似度把新帖映射到成熟内容，同时保留新帖身份用于最终曝光；应重点监控相似热帖选择偏差，避免把长尾内容同质化。

World Model-Guided Reinforcement Learning via Counterfactual User Engagement Simulation

WMG-RL 以冻结的用户参与世界模型 UEWM，在同一用户历史下并行模拟多个候选物品的异质反馈，再转成稠密奖励优化推荐策略，从而减少真实在线探索的成本和风险。跨域实验表明，模拟奖励具有可迁移性，1.7B 学生策略在下游推荐任务上可达到或超过更大的语言模型。

INSIGHT关键设计是对同一状态生成反事实候选反馈，使策略能比较“如果推荐另一条内容会怎样”，而非依赖稀疏日志奖励。用于社区推荐前，应先把 UEWM 当离线策略筛选器，并通过小流量实验校准模拟偏差；只有模拟排序与真实 CTR、互动率保持一致时，才适合进入策略训练。

Ang Li, Xin Xu, Bin Liang, Yue Ma, Fubang Zhao, Yangyang Kang, Kam-Fai Wong

Behaviorally Grounded User Profiles from the Wild for Personalized Alignment and Multi-Perspective Reasoning

ServiceNow

论文从匿名真实社交媒体帖子抽取开放式、高保真的行为画像，替代刻板的合成人设，并分别用于监督微调和测试时多视角推理。作者在复杂推荐与开放式查询基准上观察到，行为画像持续优于合成人设并改善基础模型；同时公开了实现代码，便于复现画像构建与个性化对齐流程。

INSIGHT对 UGC 平台而言，画像应从真实行为证据归纳，而不是用固定标签替用户下定义。可把多条帖子、互动主题与时间变化压缩为可追溯的开放式画像，再作为排序特征或 LLM 重排上下文；上线时需保留证据链、最小化敏感属性推断，并设置画像过期机制。

Retrieval, Scoring, and Decoding Shape Performance and Stability in LLM-based Conversational Recommendation

该研究在 ReDial 的统一“召回后重排”协议中比较多类 LLM 与传统基线。共享语义 Top-250 候选时，最佳专有模型 NDCG@10 为 0.1497，强基线为 0.0939；改用协同过滤候选后，强模型 NDCG@10 提升超过 50%，而开放权重 LLM 均未超过调优浅层自编码器。

INSIGHTLLM 重排收益高度依赖候选池、评分约束和解码设置，不能用自由生成结果替代同池对比。社区推荐评估应固定召回集合并同时报告 candidate-aware 指标；温度从 0 提至 1.0 会让 Top-10 Jaccard 距离由 0.0900 升至 0.1240，说明线上应优先确定性解码与列表稳定性监控。

Ante Kapetanovic, Tomislav Duricic, Andro Mercep, Emanuel Lacic

Sequential recommendation via knowledge graph-enhanced multi-relational learning and temporal-aware user preference modeling

KUP-SR 同时建模语义、时间与协同信息：先构建多关系物品图并用 Fourier 时间权重刻画关系衰减，再通过注意力聚合相似用户信号，结合自注意力和双向 LSTM 预测下一次交互。论文在两个公开数据集上与代表性基线比较，显示整合三类信号能获得有竞争力的 Top-K 推荐表现。

INSIGHT多关系图解决“用户点了什么之间有何语义联系”，时间权重处理偏好漂移，相似用户聚合补足单用户稀疏性，三者职责清晰。社区场景可先在现有序列模型旁路加入关系图与时间衰减特征，但应通过消融确认 Bi-LSTM 和图传播的增益是否足以覆盖额外训练复杂度。

Multimodal generative sequential recommendation with adaptive contrastive learning

论文面向多模态序列推荐，将 Semantic ID 生成、自适应对比学习和难负例挖掘结合起来，并用“粗粒度生成、细粒度排序”的层级检索降低全量排序成本。方法以连续的用户行为为条件生成融合文本与视觉语义的候选，在四个数据集上持续优于传统及生成式推荐基线，但候选元数据未披露具体提升数值。

INSIGHT多模态 Semantic ID 可让相似新内容共享统计强度，自适应对比目标则按样本难度调整表示学习，适合 UGC 新帖冷启动。工程上可先把层级生成用于缩小候选集，再保留现有 CTR 精排；评估时需分别观察召回率、细排增益与推理耗时，避免语义量化损失被总体指标掩盖。

StudentSim: Training LLM-based Student Simulators

Microsoft

StudentSim 将稀疏的个人行为数据先用于群体共享训练，再做逐用户专门化，使模拟器既复现个体回答，也能预测不同辅导建议下的变化。StudentSimEval 覆盖国际象棋、英语写作和数学三个领域的 60 名学习者，用公开去标识数据评估个体拟合与干预响应，为低反馈场景提供可重复的用户模拟协议。

INSIGHT虽然应用在教育场景，其“群体预训练加个体适配”适合冷启动用户建模：共享模型吸收普遍行为规律，少量个人交互只更新轻量个体参数。社区推荐可借此构建离线用户代理来预筛策略，但模拟器必须按真实用户分层校准，不能把生成流畅度误当作 CTR 或满意度预测准确性。

Ke Yang, Chenglong Wang, Michel Galley, Chandan Singh, Jeevana Priya Inala
