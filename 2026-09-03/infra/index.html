BAGS: A Bit-Partitioned Quantization-Aware Architecture for Accelerating Graph-based Approximate Nearest Neighbor Search

论文针对 HNSW 在图遍历中读取高维向量造成的内存带宽瓶颈，提出 8 位分区量化、遍历与重排共用的统一硬件加速器及重排友好的内存布局。在传统 ANNS 与 RAG 向量数据集上，相比 CPU、GPU 和既有 ASIC 分别实现最高 63.4 倍、12.9 倍和 1.6 倍加速，并保持全精度基线准确率。

OCGQuant: Outlier-Companion Grouping for NVFP4 Quantization

论文发现 NVFP4 块内异常激活会主导共享缩放因子，使其余数值产生可约减的伴随量化误差，并据此提出异常值—伴随通道自适应分组的后训练量化方法 OCGQuant。它不依赖混合精度、旋转或额外残差补偿，目标是在保持 NVFP4 推理效率的同时恢复低比特模型精度。

INSIGHT该方法把量化误差治理从数值补偿转成通道布局优化，因而更容易嵌入已有 NVFP4 内核。部署搜索侧 LLM 或重排模型时，可在离线校准阶段统计异常通道与伴随误差，再将分组结果固化到权重和执行计划中，避免在线增加算子。

Yishan Yao, Binjun Li, Hanling Yi, Pengyu Li, Xiaoqing Liu, Zihan Yang, Xiaotian Yu, Zhiwen Yu

From Production Traffic to Post-Training: Building a Self-Hosted LLM That Covers the Corporate Request Mix

论文为受数据驻留约束的企业整合 200 多个内部应用流量，用生产错误分析分别构建指令遵循、函数调用和任务分布三个 GRPO 专家，再以两阶段 SLERP 合并。分轴训练规避联合奖励干扰，并分别处理语义坍缩、过度工具调用和冗长奖励投机，最终以单模型收敛碎片化 GPU 服务池。

INSIGHT企业自托管模型的瓶颈常不是基座能力，而是版本并存与生产请求分布脱节。可将真实搜索请求按失败类型分层评测，为不同轴训练轻量专家后再合并；这比把所有奖励塞进一次训练更便于定位回归，也能减少多模型常驻造成的显存碎片。

Olga Tsymboi, Dmitrii Stoianov, Ramil Latypov, Danil Taranets, Daniil Dryabin

SMELT: Scaling Laws for Compute-Matched MoE Looped Transformers

SMELT 在逐 token FLOPs、非嵌入参数量和 KV Cache 三项预算严格对齐下，比较循环与非循环 MoE Transformer，并得到“中间一半层循环两次”的结构配方。作者扩展到 540 亿非嵌入参数并拟合独立 Chinchilla 标度律，计算最优前沿可节省 6.8%—18.0% 训练 FLOPs，代码任务收益最明显。

INSIGHT论文用计算匹配实验排除了循环结构靠额外 FLOPs 获益的混淆，说明共享中层参数可提高单位训练算力产出。对自训垂域模型，可先在小规模预算上拟合结构专属标度律，再决定是否扩大训练；同时应验证更长样本和更多上下文示例是否符合线上负载。

Shaowen Wang, Ge Zhang, Kairong Luo, Yuhao Wu, Shaofan Liu

Improving Ray Serve LLM on GKE throughput and latency

GoogleAnyscale

Google 与 Anyscale 为 Ray Serve LLM 引入 HAProxy 内部路由、绕过入口路由器的 token 直流和移出数据面的 vLLM Ray v2 执行后端。在 GKE A4/HGX B200、8 副本环境下，相比旧配置实现最高 5 倍吞吐和 8 倍更低延迟，并接近原生 vLLM 的扩展表现。

INSIGHT结果表明 Python 控制面和流式返回路径会成为多副本推理的隐性瓶颈，优化重点应从单卡内核扩展到代理与数据面。生产部署可先拆分请求控制链和 token 流，观测高并发下 P99 TTFT，再评估是否需要替换编排框架。

Amazon

Amazon 介绍 Verus 如何为 Rust 程序补充数学规格，并自动验证实现是否满足功能与安全性质，从而把部分代码审查从测试样例提升为形式化证明。该实践面向高安全要求的软件组件，可减少传统单元测试难以覆盖的边界状态和并发错误。
