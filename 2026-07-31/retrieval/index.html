DSIRM: Learning Query-Bridged Discrete Semantic Identifiers for E-commerce Relevance Modeling

针对连续向量难以区分商品细粒度属性的问题，DSIRM 用 Query-Item 监督改造残差量化，让商品 SID 直接编码相关性，再由生成式 LLM 从 Query 预测 SID，并以层级前缀匹配补充稠密特征。天猫数据上离线 AUC 提升 1.54%，线上 UCTR 提升 0.13%、UCTCVR 提升 0.25%。

Synthetic Data Powers Product Retrieval for Long-tail Knowledge-Intensive Queries in E-commerce Search

Alibaba

论文把离线 LLM 多候选改写能力蒸馏为 Query-商品训练对，用语义相关、商品分布对齐和多样性三类奖励控制改写，再以强检索与相关性模型过滤伪标签。相同 2 亿训练规模下，负向意图的 Item Goodrate 提升 12.95 个点；四周线上实验中 Query Goodrate 最高提升 8.62 个点。

INSIGHT对于行为稀疏、需要常识推理的长尾 UGC Query，直接在线调用改写模型并非唯一选择；更稳妥的路径是离线生成多意图改写、检索候选并回灌双塔。论文也暴露了边界：替代品 Query 的合成数据准确率只有 64.5%，因此必须保留业务相关性模型和人工抽检，避免语义漂移扩大召回噪声。

大模型在得物社区搜索的落地实践

得得物

得物在商品与 UGC 内容混合搜索中，用二阶段属性抽取与相关性判别替代纯 BERT 方案，并以 R1 思路、课程学习和千万级自动标注完成蒸馏。新模型大盘准确率提升 9.6%、F1 提升 10.9%；亿级图文训练使 Recall@10、Recall@100、Recall@1K 分别提升 36%、48%、52%。

INSIGHT这套链路与社区短文本搜索高度同构：先建立 40+ Query 意图、商品/内容属性和四档相关性标准，再让大模型产出标签与理由，最后蒸馏到在线小模型。值得直接复用的细节包括把 Prompt 从 8K 压到 1.2K、用 1.5B 模型做 Doc2Query，以及用 listwise DPO 和 nDCG 奖励补足分档强但排序弱的问题。

赵君豪

Quality Over Clicks: Iterative Reinforcement Learning for Early-Stage E-Commerce Query Suggestion

QualEQS 面向新上线搜索建议缺少点击监督的问题，把质量拆成可回答性、事实性和信息增益，并利用同组候选分歧定位模糊上下文，持续挖掘困难样本做迭代强化学习。论文构建含 16,949 条真实电商 Query 的 EQS-Benchmark，企业级对话购物助手线上 ChatPV 提升 6.81%。

INSIGHT社区搜索的猜你想搜、相关搜在冷启动阶段不应过早把 CTR 当唯一目标；先用与业务可解释的质量奖励约束 Query，再逐步接入点击信号，能避免模型学到标题党式建议。组内分歧也是低成本难例采样器，可优先发现意图不明、事实风险高或信息增量不足的推荐词。

Qi Sun, Kejun Xiao, Huaipeng Zhao, Tao Luo, Xiaoyi Zeng

JobMatchAI-An Intelligent Job Matching Platform Using Knowledge Graphs, Semantic Search and Explainable AI

JobMatchAI 将 BM25、Transformer 语义召回和技能知识图谱并行融合，再按技能、经验、地点、薪资等因素可解释重排。JobSearch-XS 上混合重排的 nDCG@10 为 0.81，较 BM25 相对提升 7%，P50 延迟 82ms；高召回技能抽取又带来 2.6 个 nDCG 点增益。

INSIGHT对短 Query 和 UGC 文档，图谱不应单独替代语义召回，而应负责同义词、实体与硬约束扩展，再让轻量重排器抑制误扩展。论文同时提醒融合上限：混合系统 Recall@100 只有 0.35，低于 BM25 的 0.57；上线时要把候选池截断、RRF 权重和硬过滤作为独立召回指标监控。

Mayank Vyas, Abhijit Chakraborty, Vivek Gupta

DVCQR: Dual-View Conversational Query Rewriting with Stage-wise Reinforcement Learning

CCCNU

DVCQR 一次生成两种会话 Query：稀疏视图突出词法锚点，稠密视图保留完整语义约束，再用分阶段强化学习分别对齐 BM25 与 ANCE 的排序反馈。Qwen3-4B 在 TopiOCQA 上把 BM25 的 MRR 提至 39.5、ANCE 的 MRR 提至 53.5，四个会话检索基准多数指标优于既有方法。

INSIGHT同一条改写同时服务倒排和向量召回会产生目标冲突；把词法表达与语义表达显式拆开，比调一个折中 Prompt 更可控。消融显示三阶段训练将 TopiOCQA 的 ANCE MRR 从 24.8 提到 53.5，说明先做双视图 SFT、再依次对齐稀疏与稠密召回，可作为多路召回系统的标准训练顺序。

Chenyi Li, Xinhui Tu, Zaixiang Wang

Masking or Mitigating? Deconstructing the Impact of Query Rewriting on Retriever Biases in RAG

论文首次系统分析 Query 增强对稠密检索偏差的影响，覆盖长度、位置、字面匹配和重复四类偏差，并在 6 个检索器上比较 5 种方法。简单 LLM 改写的综合偏差降低幅度最高，达到 54%，但多种偏差叠加时失效；伪文档方法则通过降低偏差特征相关性改善结果。

INSIGHTQuery 改写带来的增益未必等于更好理解意图，也可能只是扩大打分方差、暂时掩盖检索器偏差。社区搜索应按失败类型选择策略：字面匹配或短 Query 偏差可先试轻量改写，复合偏差则需要文档侧训练、伪文档或重排共同处理，并用对抗切片而非整体 nDCG 验证。

Agam Goyal, Koyel Mukherjee, Apoorv Saxena, Anirudh Phukan, Eshwar Chandrasekharan, Hari Sundaram

LLM-guided Hierarchical Search for End-to-end Reasoning Intensive Retrieval

LATTICE 不依赖搜索时向量召回，而是让 LLM 在由多层文档摘要构成的层级索引中自顶向下导航，并以跨分支参考节点和路径聚合校准不稳定打分。BRIGHT 上单模型达到 46.7 nDCG@10，追平最佳微调集成基线；与廉价召回融合的 LATTICE++ 达到 49.1。

INSIGHT当相关性依赖跨句推理、首阶段向量召回始终漏掉目标时，继续堆重排器无法补救召回缺口；层级导航提供了另一条路径。其代价是 Token 和索引构建成本较高，因此更适合作为难 Query 路由分支：普通 UGC Query 走双塔，低置信度或复杂意图再进入 LLM 层级检索。

Nilesh Gupta, Wei-Cheng Chang, Ngot Bui, Cho-Jui Hsieh, Inderjit S. Dhillon

LazyMem: Retrieve Broadly, Construct Selectively for Efficient Long-Term Agent Memory

LazyMem 针对长对话证据稀疏且分散的问题，先宽召回消息，再让 4B 模型在重叠窗口中按当前 Query 选择并压缩上下文，以 SFT 与强化学习联合优化证据识别和忠实摘要。LongMemEval 准确率达到 0.85，仅使用 213 个上下文 Token，比 StructMem 少 21 倍且高 0.03。

INSIGHT这一设计可迁移到 UGC 长文或评论串检索：索引层保留原始细节，查询时再按意图构造短上下文，避免写入时摘要永久丢信息。消融中 SFT 将准确率从 0.41 提到 0.73，RL 再提到 0.85；说明在线压缩器应先保证结构化选择稳定，再用任务奖励优化保留哪些证据。

Jing Yu, Yibo Zhao, Jiaming Zhang, Xiang Li

Real-time Spatial Retrieval Augmented Generation for Urban Environments

论文用 FIWARE 与 linked data 构建实时空间 RAG，在召回前按时间和地理区域过滤实体，并以马德里旅游助手验证动态上下文接入。空间检索在目标区域内 Recall 为 1；小区域处理 10–20 个实体时，各模型最低延迟约 1–2 秒，区域扩大后响应时间近似线性上升。

INSIGHT对带地点、时间或社区频道约束的 UGC 搜索，可先用结构化条件缩小语义召回空间，再把结果交给大模型，既减少无关上下文也提高可解释性。实验表明端到端延迟主要由 LLM 而非检索组件主导，因此生产系统应限制区域实体数、缓存静态 Prompt，并把生成模型路由与召回过滤分开优化。

David Nazareno Campo, Javier Conde, Álvaro Alonso, Gabriel Huecas, Joaquín Salvachúa 等 6 人
