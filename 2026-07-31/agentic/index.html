EviBack: Search-Agent Reinforcement Learning via Evidence-Constrained Teacher Backoff

论文针对搜索 Agent 训练中整组 rollout 全为零奖励、有效中间检索无法获得比较信号的问题，提出证据约束的 Teacher 回退奖励与自动提示优化流程。7 个开放域问答集上，Qwen3-1.7B 的 F1 从 0.2509 升至 0.2911，有效答案率从 0.7317 升至 0.8611，同时平均搜索次数降至 1.5934。

Echoverse: Deep, evolving environments for computer-use agents

Microsoft

微软构建 10 个深层业务世界与 2 个能力世界，用真实状态、数据库校验器和可重置环境训练计算机使用 Agent，并让环境、任务、校验器随失败共同演化。Qwen3.5-9B 在 14 个域的平均分由 36.5% 升至 67.1%，WebVoyager 从 66.5% 升至 71.5%，浅层环境反而使 Allrecipes 从 80% 降到 75%。

INSIGHT高保真因果状态比堆积轨迹更重要：任务必须让早期动作约束后续步骤，并按数据库最终状态而非截图评分。对搜索 Agent，可把查询、筛选、打开结果、跨页验证做成可复位的深层任务，再围绕日期筛选或嵌套过滤等薄弱控件构造专项世界，形成可持续的训练闭环。

SkillRise: Agentic Reinforcement Learning for Cross-Task Skill Evolution

论文把相关但不同的任务排成递增难度序列，让同一策略在“执行任务”和“维护可复用技能文档”之间交替，并用当前结果奖励执行、用折扣后的下游结果奖励技能整理。ALFWorld、WebShop、ScienceWorld 上，Pass@1 相比最强基线提高 2.3～8.5 个百分点，且跨任务序列越长，测试时表现继续增长。

INSIGHT技能库不应是 RL 之外的离线摘要步骤，而应与任务策略共同优化，并把技能质量的信用延迟到后续任务验证。搜索业务可按意图族组织连续任务，让 Agent 在每次查询后提炼“改写、工具选择、停止条件”等技能，再以未来相关查询的收益反向评价，减少重复探索和流水线开销。

MemTX: Transactional Belief Commit for Stateful Agent Memory

University of Southern QueenslandGriffith UniversityUniversity of SydneyLLiaoning UniversitySUSTech

MemTX 将 Agent 的“写入记忆”和“提交为可执行信念”分离：记录携带证据、权限、来源与有效期，写入先进入快照隔离事务，再经验证提交；撤销信念会触发派生记录和工具副作用的级联修复。作者穷举 550 万个协议状态实现零不变量违规，并在 5 个模型骨干、8 个基线上保持唯一的全模型零下游伤害。

INSIGHT多 Agent 搜索中，检索结果、用户偏好和中间结论不能一写入就成为后续工具调用的事实。可借鉴数据库事务：先暂存证据，验证权限与新鲜度后提交；对下单、发帖、改配置等不可逆动作设置提交门，并保留依赖图，使错误来源被撤销时能定位并修复所有派生结论。

EvoLib: Turning experience into evolving knowledge

Microsoft

EvoLib 不更新模型参数，而是从推理轨迹抽取模块化技能与反思洞察，通过信息增益、未来信息增益和相似项合并持续演化知识库。HMMT 准确率由 57.0 升至 77.4，BigCodeBench 由 29.7 升至 40.8，PDDL 成功率由 62.8 升至 72.8；同预算下较基础采样提升 11%～20%。

INSIGHT长期 Agent 记忆的瓶颈不是容量，而是能否把经历压缩成可组合、可加权、会淘汰的抽象知识。搜索系统可分别保存可执行技能与失败反思，用当前任务增益和对未来技能生成的贡献共同定权；只合并语义与功能都接近的条目，避免技能库因反复改写而失去适用边界。

Weijia Xu, Alessandro Sordoni, Zelalem Gero, Michel Galley, Eric Yuan, Jianfeng Gao

How enabling two settings tripled our scores on the ARC-AGI-3 benchmark

OpenAI

OpenAI 复盘 ARC-AGI-3 低分后发现，通用 harness 每步丢弃私有推理且滚动截断旧动作，迫使 Agent 反复重新理解环境。改为跨工具调用保留推理，并在长上下文启用压缩后，GPT-5.6 Sol 的 RHAE 从 13.3% 升至 38.3%，接近人工 48%，同时输出 token 减少 6 倍。

INSIGHTAgent 基准测到的是“模型＋上下文管理＋工具框架”，错误的历史保留策略会把系统缺陷误判为模型能力不足。多轮搜索应持久化计划、已验证事实和失败查询，并在接近窗口上限时做结构化压缩，而不是简单丢弃最早轮次；这往往比更换大模型更便宜、也更可复现。

Voice Memory for Agentic Speech Recognition

NVIDIA

Voice Memory 采用 listener-thinker 架构：在线冻结纠错器读取每域一个 memory.md，自主决定纠正或保留 1-best；异步优化器只接受能提升留出集分数的有限编辑。10 个 HyPoradise 域上加权 WER 从 8.36% 降至 7.52%，金融新闻中过度纠错率从最高 64% 降至 35%，且推理路径零增参。

INSIGHT可审计文本记忆加“必要时不行动”的策略，比让生成模型无条件改写更稳健。该设计可迁移到查询改写：在线轻量决策器先判断是否需要改写，离线优化器仅在留出流量指标严格提升时更新规则文件，并按领域隔离记忆，从机制上限制过度改写损伤原本正确的查询。

MemLens: A Value-Aware Memory Management System with Interactive Analytics for LLM-based Agents

Shandong UniversityBeihang UniversityCity University of Hong Kong

MemLens 把交互记录拆成细粒度数据对象，用轻量代理模型、LLM 打分与 Shapley 式边际贡献估算其下游价值，再按阈值保留高价值记忆并注入应答上下文。学习助手原型覆盖“评估—存储—应答”3 个环节，可对比全量保存、Agent 摘要和值感知管理 3 种策略的质量、检索延迟和 token 消耗。

INSIGHT记忆价值取决于它对未来答案的边际贡献，也取决于其他记忆是否已经提供同类信息；单条相关性分数容易保留冗余。社区搜索 Agent 可对历史查询、点击证据和工具输出做近似 Shapley 估值，优先保存不可替代的高贡献记录，并把质量、延迟、上下文 token 三项放在同一面板持续审计。

Information Seeking Behavior in LLM-Based RAG: Mental Models and Missing Information

SIGIR 2026 论文以 9 名参与者完成探索、已知项、列表和缺失项 4 类“与文档对话”任务，研究用户如何理解 RAG。多数人误以为系统会穷尽阅读、持续记忆且近乎完美召回，因此很少改写查询、检查来源，并把“未找到”当成不存在；只有少数具备检索式心智模型的用户会迭代验证。

INSIGHT生成式搜索隐藏了探索、比较和综合过程，会让用户高估召回完整性，尤其在空结果和长尾 UGC 场景中形成错误确信。产品应显式展示检索范围、候选缺口与证据覆盖度，提供一键改写、扩大范围、查看原文和交叉验证入口，并把用户是否验证来源纳入交互评测。

Bruno Nadalic Sotic, Jaap Kamps
