From Delivery to Stateful Exploration: Rethinking the Index for Agentic Search

论文将 Agent 搜索从反复返回文本改为有状态的索引交互：代理先用词法条件、集合运算和候选数量反馈缩小范围，再按需读取证据。在 BrowseComp-Plus 上，IndexAct 准确率为 73.5%，高于 RARG 的 69.4%；平均上下文由 27,896 降到 13,960 tokens，并在五个基准上领先所比较方法。

Agentic AutoRAG: RAG Pipeline Optimization through Reasoning-Driven Agents

ETH Zurich

Agentic AutoRAG 用诊断代理区分检索失败与生成失败，再由提案代理结合模型排名和价格调整 RAG 配置。在三个多跳问答基准上，前 10 次试验即可匹配或超过统计基线 30 次试验的效果；医疗语料上考试准确率为 77%，强基线为 71.5%，单次查询成本约为其 58%。

INSIGHT可将社区搜索失败样本拆分为没有召回支持帖子、召回正确但生成错误两类，再分别调整切块、embedding、重排与生成设置。冻结评测题集有助于比较配置，但自动 LLM 判分仍需人工校验；应把 nDCG、CTR 与延迟加入多目标优化，避免仅优化回答评分而损失线上相关性。

Imperial College LondonDdistil labsAAgonEELLIS Institute Tübingen

INSIGHT社区搜索工具可按查询改写、检索、筛选、读取与回答定义状态和前置条件，先保证训练轨迹合法，再控制轮数及任务复杂度分布。这样能为私有部署的小模型生成多轮训练数据；状态机仍需反映真实 API 约束，并用实际工具执行成功率评测，不能只检验生成文本的格式。

DAEDALUS: Bootstrapping Agent Memory from Self-Generated Tasks

Illuin Technology

DAEDALUS 让探索代理自造环境任务，求解代理执行并从失败中提取启发式；只有加入经验后重复成功的规则才进入记忆库。在 AppWorld 上平均成功率由 44.3% 升至 60.2%，在零售 τ²-bench 上由 57.5% 升至 67.5%，跨三个基准的 pass^5 最多提高 2.2 倍，并支持跨模型迁移。

INSIGHT搜索代理可在隔离环境里练习复杂筛选、证据查找和工具调用，把常见错误转为经重试验证的操作经验，再在真实任务中复用。论文强调求解轨迹比泛化自述更有信息；社区业务应保留失败到成功的验证链，控制记忆注入长度，并针对索引或接口变化重新验证规则。

ToolSearcher: Optimizing Tool Selection at Scale via Reinforcement Learning

Zhejiang UniversityAAnt Group

ToolSearcher 针对大规模工具库的多轮搜索与选择，结合类别约束工具辨别、事件级搜索建模及轨迹对齐奖励分配。在 StableToolBench 上，Qwen2.5-7B 的工具选择 F1 为 0.513，高于 GDPO 的 0.496；Qwen3-4B 达到 0.531，高于 Search-R1 的 0.505，并在 AppWorld 测试分布外迁移。

INSIGHT社区搜索代理接入多个检索索引、过滤器或内容接口时，工具选择需要考虑功能相似性及组合兼容性，而非只优化最终答案奖励。可先构建工具类别和互斥约束，再按搜索与选择事件分配信用；线上应分别统计工具召回、选择准确率和任务成功率，防止检索到工具却组合错误。

Agent Lightning v1.0: A 3,500-Line Lightweight Agentic RL Framework for Training Agents with Real Harnesses

Microsoft

Microsoft 的 Agent Lightning v1.0 把部署时的 Agent 运行框架直接接入 RL，不必在训练系统里重写工具与环境逻辑，控制平面约 3,500 行代码并支持原生 Kubernetes 任务。官方编码代理实验用约 6,000 个训练样本，将 Qwen3.5-9B 的 SWE-bench Verified Pass@1 从 41.8% 提升到 56.4%。

INSIGHT社区搜索 Agent 的训练与部署应尽可能共用查询、检索和上下文管理代码，避免训练轨迹与线上行为脱节。该框架提供可借鉴的运行层接入方式，但博客的量化结果来自编码任务；转向 UGC 搜索时，需定义可验证的证据与相关性奖励，并重新评测 nDCG、CTR 及多轮调用成本。

The Right Memory in the Wrong Context: Verifying Retrieval Admissibility in Long-Term Agent Memory

University of Arkansas at Little Rock

论文指出长期记忆即使相关，也可能因用户、策略或生命周期不匹配而不可用于当前请求，提出可用、不可用、未决三态验证与证据曝光追踪。在 RHELM 与 MemOps 的 3,767 条查询上，top-20 锚点召回从 0.432 增至 0.533，相似度计算减少 98.3%；该结果依赖可信查询命名空间。

INSIGHT社区搜索代理使用历史对话和个性化记忆时，应先检查身份、权限与数据有效期，再评估语义相关性。论文把召回、提示曝光与最终泄露拆开统计，可借鉴为独立监控层；应用时需保持必要证据召回相当，并将元数据缺失标为未决，不能仅靠答案正确率判断记忆使用是否可靠。

From Evidence to Action: How Tool-Using Agents Fail

Princeton UniversityNUSHong Kong Baptist UniversityAmazon

SafeActBench 将证据收集、行动判断与多步执行分开评估，包含六个领域、五种协议的 656 个案例，并比较十种模型与运行框架组合。证据台账记录何时获得了哪个实体和状态的信息；结构化证据选择使 Qwen 组合成功率增 11.6 个百分点，却使 Claude 组合降 9.1 个百分点，效果并不一致。

INSIGHT社区搜索代理若进一步执行订阅、收藏或数据变更，应检查证据是否在行动之前建立，而不只看最终结果是否碰巧正确。可借鉴来源绑定的证据台账以及多步依赖检查；论文显示同一证据组织方法对不同运行框架影响不同，需分别验证停止时机、工具参数及下游任务完成率。

Hongzhan Lin, Shidong Cao, Ziyang Luo, Wenhao Chai, Mong-Li Lee

Token-Budgeted Escalation for Financial Document QA: Cost Is Predictable, Benefit Is the Bottleneck

UUniversity of Chicago

研究将深度检索升级建模为批量 token 预算分配：先做 top-1 回答，再预测追加 top-5 调用的质量收益与成本。在 150 道 FinanceBench 问题、名义 10% 预算下，按单位 token 收益分配比只按收益分配高 0.034，较一次性 top-5 少用 46.6% tokens；成本预测 R² 达 0.93。

INSIGHT对社区复杂问答可先运行轻量检索，再把有限推理预算分配给预期收益更高的请求。论文也显示收益排序 AUROC 只有 0.60，不能把准确预测成本等同于准确判断问题难度；试验应分别校准追加检索成本与收益，并核查低预算下的回答质量、尾延迟及长尾查询覆盖。

AdvSim2Real : Training Web Agents Against Adaptive Prompt Injection in a Web World Model

MBZUAIAmazonMIT

AdvSim2Real 在冻结的 Web 世界模型中共同演化任务课程、提示注入攻击者和浏览器代理：课程偏好约半数可完成的任务，攻击者只因把成功翻转为失败而获奖。在 150 个 Web 任务上，训练后的 4B 代理面对未见过的前沿模型攻击者，任务完成率较基座提高 33.6%，并观察到浏览器能力迁移。

INSIGHT社区内容和外部网页都可能携带干扰搜索代理的指令，可用自适应攻击与动态任务检验检索后阅读环节。可借鉴成功翻转奖励，区分原本就失败的任务与注入造成的失败；但模拟器训练成本和真实页面差异需要单独测量，UGC 场景仍应评估正常检索质量及攻击下的证据使用。

Sarim Hashmi, Mukul Ranjan, Kshitij Mishra, Mikhail Kuznetsov, Praneeth Vepakomma
