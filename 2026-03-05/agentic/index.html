使用大规模异步强化学习训练搜索 Agent，突破传统 10 轮对话限制，实现长链路 agentic search。

KEY INSIGHT · 对业务意味着什么开源搜索 Agent 在长链路搜索场景下的主要瓶颈在于 RL 训练的扩展性；异步 RL 架构可让 Agent 在多步搜索中持续优化检索策略，避免早期终止。业务关联 社区搜索中复杂 query（如多条件筛选、跨主题聚合）需要多步检索；该方法提供了训练 Agent 进行多轮搜索决策的可行路径。证据 在 BrowseComp 上 Pass@1 达到 42.8%，相比 Search-o1 提升 +15.3%；在 GAIA 上达到 67.2% 准确率，训练使用 512 GPU 并行的异步 PPO 框架。

MC-Search: Evaluating and Enhancing Multimodal Agentic Search with Structured Long Reasoning Chains

提出多模态 agentic search 评测基准与增强方法，通过结构化长链推理提升搜索质量。

INSIGHT多模态搜索 Agent 需要结构化的推理链而非简单的检索-生成流水线；通过显式建模推理步骤间的依赖关系，可以显著提升跨模态搜索的准确性。

业务关联社区搜索中图文混合内容（如带图帖子、视频评论）日益增多，该方法为多模态 Agent 搜索提供了评估基准和增强思路。

证据在 MC-SearchBench 上，结构化推理链方法相比基线 MLLMs 在多模态搜索任务上提升 18.5% 准确率；覆盖文本、图像、表格三种模态。

Super Research: Answering Highly Complex Questions with Large Language Models through Super Deep and Super Wide Research

结合深度搜索与广度搜索，解决需要大规模证据收集和长期规划的高复杂度问题。

INSIGHT单纯的 Deep Research 或 Wide Search 对高复杂度问题各有不足；Super Research 通过规划层统一调度深度探索和广度扫描，在需要跨领域综合推理的场景中表现更优。

业务关联社区搜索的高级功能（如主题综述、热点追踪）需要类似 deep+wide 的搜索策略；该架构可指导搜索 Agent 在答案综合场景中的设计。

证据在 HLE 上达到 31.2% 准确率（超 Deep Research 单模式 +4.6%）；在 BrowseComp 上达到 52.3%（超 Wide Search 单模式 +6.1%）。

Process vs. Outcome Reward: Which is Better for Agentic RAG Reinforcement Learning

系统比较过程奖励与结果奖励在 Agentic RAG 强化学习训练中的效果差异。

INSIGHT过程奖励（process reward）在 Agentic RAG 的检索决策训练中优于结果奖励（outcome reward），因为它能更精确地指导 Agent 在每一步选择合适的检索动作。

业务关联搜索系统中 RAG 链路的优化（何时检索、检索什么）可以借鉴该工作的 RL 训练策略，用过程级奖励信号提升搜索 Agent 的多步决策质量。

证据在 HotpotQA 上 process reward 比 outcome reward 提升 F1 +5.8%；在 2WikiMultiHopQA 上提升 +4.2%；检索效率提升 23%（减少冗余检索步骤）。

Wenlin Zhang, Xiangyang Li, Kuicai Dong, Yichao Wang, Pengyue Jia et al.

Search-o1: Agentic Search-Enhanced Large Reasoning Models

将 agentic search 嵌入大型推理模型（LRM），在推理过程中动态搜索补充知识不足。

INSIGHT推理模型在长链推理中的知识不确定性可通过动态搜索解决；Search-o1 在推理链中间插入搜索动作，让模型自主决定何时需要外部知识。

业务关联社区搜索中的复杂 query 回答（如专业领域问答）可以借鉴该方法，在生成答案过程中动态调用检索来补充实时信息。

证据在 GPQA、MATH-500、AIME 2024 等推理基准上，Search-o1 比 QwQ-32B 基线平均提升 +12.3%；搜索触发率约 35%，仅在必要时检索。

Xiaoxi Li, Guanting Dong, Jiajie Jin, Yuyao Zhang, Yujia Zhou et al.

Agentic Search in the Wild: Intents and Trajectory Dynamics from 14M+ Real Search Requests

分析 1400 万+ 真实 agentic search 请求的意图分布与搜索轨迹动态。

INSIGHT真实 agentic search 中 90% 的多轮会话不超过 10 步，Agent 复用已检索证据中 54% 的查询词；基于此可设计重复感知的早停机制和意图驱动的检索预算。

业务关联社区搜索若引入 Agent 驱动的多步检索，该数据分析结论可直接指导检索步数上限、query 复用策略和资源分配策略的设计。

MaskSearch: A Universal Pre-Training Framework to Enhance Agentic Search Capability

提出通用预训练框架 MaskSearch，通过掩码搜索任务增强 LLM 的 agentic search 能力。

INSIGHT通过在预训练阶段引入搜索工具调用的掩码任务，可以让 LLM 天然具备何时搜索、搜索什么的能力，无需复杂的 RL 训练流程。

业务关联社区搜索系统如果要将 LLM 作为搜索 Agent，该预训练方法可以降低训练成本，使模型自主学会在 query 理解和答案生成中何时调用检索。

证据在 HotpotQA 上 EM 提升 +7.3%，在 FEVER 上准确率提升 +5.1%；相比 RL-based 方法训练效率提升 3.5 倍。

自动化生成合成训练数据用于训练深度搜索 Agent，通过执行反馈迭代优化数据质量。

INSIGHT深度搜索 Agent 的训练数据瓶颈可以通过自动化合成管线解决；问题生成器与搜索 Agent 协同迭代，自动产出多样化且高质量的训练样本。

业务关联社区搜索场景中标注搜索 Agent 训练数据成本高昂，SAGE 的合成数据方法可以低成本批量生成多步搜索训练样本。

CoVe: Training Interactive Tool-Use Agents via Constraint-Guided Verification

通过约束引导的验证机制训练多轮交互式工具使用 Agent。

INSIGHT工具调用 Agent 的训练难点在于用户意图模糊且动作需确定性执行；通过约束引导验证可以自动生成高质量训练信号，避免人工标注的瓶颈。

业务关联社区搜索中 Agent 需要调用多种工具（搜索、过滤、排序），CoVe 的约束验证机制可用于训练搜索 Agent 正确地组合工具调用。

WideSeek: Advancing Wide Research via Multi-Agent Scaling

提出多 Agent 扩展的 Wide Research 框架，通过层级化多 Agent 架构实现广度搜索。

INSIGHT宽搜索（Wide Research）是深度搜索（Deep Research）的互补范式；通过动态 fork 并行子 Agent 并用 RL 优化多 Agent 协同轨迹，可以高效覆盖大规模搜索空间。

业务关联社区搜索的话题追踪、热点聚合等需要广度搜索的场景，可参考 WideSeek 的多 Agent 并行架构设计。

证据提出 WideSeekBench 基准；在广度搜索任务上比单 Agent 基线提升 +28.5% 召回率；多 Agent 数量从 2 扩展到 8 时性能持续提升。
