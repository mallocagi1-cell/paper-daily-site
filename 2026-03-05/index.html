Model Editing for New Document Integration in Generative Information Retrieval

本文针对生成式检索（GR）模型在新增文档时的泛化问题，提出了一种基于模型编辑的轻量级解决方案。传统方法需要增量训练，计算成本高且容易遗忘旧知识。该方法通过直接编辑模型参数来集成新文档的 docID，避免了全量重训练的开销。

OxygenREC: An Instruction-Following Generative Framework for E-commerce Recommendation

📖 深度解读 · 1 分钟 →

OxygenREC 提出了一个指令驱动的统一生成式推荐框架，专为大规模电商场景设计。它整合了世界知识进行演绎式意图推理，并支持在单一骨干网络上进行多场景的可扩展服务。

INSIGHT指令跟随（instruction-following）范式可以将推荐系统统一为一个通用生成式框架，通过自然语言指令控制推荐行为，实现多场景复用。这比传统的多模型方案更具扩展性。

业务关联UGC 社区搜索涉及帖子推荐、相关问答推荐等多个场景，OxygenREC 的统一指令框架可以用一个模型服务多个推荐场景，降低维护成本。其意图推理能力也可提升 query 理解。

证据框架在大规模电商推荐数据集上验证，支持多场景服务的单一骨干网络架构，整合世界知识用于演绎式意图推理，展示了工业级可扩展性。

DiscRec: Disentangled Semantic-Collaborative Modeling for Generative Recommendation

DiscRec 提出了一种解耦语义-协同建模方法，解决生成式推荐中两个核心挑战：token-item 不对齐（均匀的 token 级建模忽略了 item 级粒度）和语义-协同信号纠缠（两类信号分布不同却被强行融合）。

INSIGHT在生成式推荐中，语义信号和协同过滤信号应该被解耦建模。统一的 embedding 空间会导致两类信号互相干扰，降低推荐质量。解耦后分别建模再融合是更优的方案。

业务关联UGC 搜索中内容语义（帖子文本）和用户行为（点击、互动）是两种不同的信号源。DiscRec 的解耦思想可以指导搜索排序模型设计：分别建模内容相关性和用户偏好，避免信号混淆。

证据在标准推荐数据集上，DiscRec 通过解耦语义和协同信号，在 item-level 粒度建模上超越了统一 embedding 的基线方法，验证了信号解耦的有效性。

Order-agnostic Identifier for Large Language Model-based Generative Recommendation

本文研究 LLM 生成式推荐中的 item tokenization 问题，提出顺序无关的标识符方案。现有方法使用 token 序列或单 token 表示 item，前者存在局部最优和顺序敏感问题，后者受限于表达能力。该方法消除了 token 顺序依赖。

INSIGHT生成式推荐中的 item ID 编码不应依赖 token 顺序。顺序敏感性是 token 序列标识符的根本缺陷，会导致模型陷入局部最优。顺序无关设计能同时享受多 token 的表达力和单 token 的稳定性。

业务关联UGC 内容的 ID 编码是生成式检索的基础。该方法解决的顺序敏感性问题在大规模 UGC 系统中尤为重要——帖子数量巨大时，token 序列的顺序偏差会被放大。

证据在多个推荐数据集上，顺序无关标识符相比传统 token 序列和单 token 方法均有提升，特别在大规模 item 集上效果更明显，验证了消除顺序依赖的价值。

Learnable Item Tokenization for Generative Recommendation

LETTER 框架提出可学习的 item tokenization 方法，解决现有 ID、文本和 codebook 标识符的三大缺陷：语义编码不足、缺少协同信号、code 分配偏差。通过端到端学习优化 item 到 token 的映射。

INSIGHTItem tokenization 是 LLM 生成式推荐的核心瓶颈。LETTER 表明：token 不应该是固定分配的（如 ID 或 codebook），而应该是可学习的、端到端优化的。这从根本上改变了生成式推荐的建模方式。

业务关联在 UGC 搜索中，帖子的 ID 表示直接影响检索效果。LETTER 的可学习 tokenization 思想可用于社区内容的 Semantic ID 构建，让每个帖子获得更好的向量化表示用于生成式检索。

证据在多个公开推荐数据集上（Beauty、Toys、Sports），LETTER 相比 ID-based 和 codebook-based 基线取得了一致提升，特别在冷启动和长尾 item 上效果显著。

Multimodal Quantitative Language for Generative Recommendation

本文提出多模态量化语言方法用于生成式推荐。现有方法在利用预训练语言模型（PLM）的先验知识时，难以弥合通用语言知识和推荐领域专有知识之间的差距。该方法通过多模态量化表示来桥接这一鸿沟。

INSIGHT预训练语言模型的通用知识和推荐系统的领域知识之间存在显著鸿沟。多模态量化语言提供了一种桥接方案——将推荐信号编码为 PLM 可以理解的「量化语言」。

业务关联UGC 社区中帖子包含文字、图片等多模态信息。该方法的多模态量化思想可用于将帖子的多模态内容统一编码为生成式推荐模型的输入，提升搜索和推荐的内容理解能力。

证据论文在推荐数据集上验证了多模态量化语言方法的有效性，相比直接使用 PLM 文本编码的方法取得了改进，证明了量化表示对弥合领域差距的作用。

Q-BERT4Rec: Quantized Semantic-ID Representation Learning for Multimodal Recommendation

Q-BERT4Rec 在 BERT4Rec 基础上引入量化 Semantic-ID，将多模态信息（文本、图像）融入序列推荐。传统 BERT4Rec 依赖离散 item ID，缺乏语义信息且忽略多模态内容。该方法通过量化技术将多模态表示压缩为 Semantic ID。

INSIGHT序列推荐模型可以通过量化 Semantic-ID 来融合多模态信息，而不需要改变整体架构。量化是将连续的多模态 embedding 转化为离散 ID 的关键桥梁。

业务关联UGC 帖子通常包含文字和图片，传统搜索模型难以充分利用多模态信息。Q-BERT4Rec 的量化 Semantic ID 思路可应用于社区搜索的序列化推荐场景，提升内容理解。

证据在电商、广告和内容流推荐数据集上进行了实验，Q-BERT4Rec 相比原始 BERT4Rec 和其他序列推荐模型在多个指标上取得了一致改进。

Generative Recommendation Models: Progress and Directions

本文全面综述了生成式推荐模型的发展历程和未来方向。传统推荐模型遵循判别范式，预测 item 是否应被检索。随着 LLM 和扩散模型的进步，研究者开始构建以生成为核心的推荐系统，使用户可以主动表达需求并获得交互式体验。

INSIGHT生成式推荐正在从「被动浏览」走向「主动交互」——用户不再只是点击推荐列表，而是通过对话和指令表达需求。这一范式转变需要全新的评估体系和系统架构。

业务关联UGC 社区搜索正面临类似的范式转变：从关键词搜索走向对话式搜索。本综述梳理的技术路线图可以指导社区搜索的长期技术规划，特别是在生成式检索和对话式推荐方面。

证据综述覆盖了生成式推荐领域的主要工作，包括基于 LLM 和扩散模型的方法，提供了系统的分类和对比分析，是该领域的权威参考文献。

Diffusion-EXR: Controllable Review Generation for Explainable Recommendation via Diffusion Models

Diffusion-EXR 首次将去噪扩散概率模型（DDPM）应用于推荐系统的可解释性文本生成。通过扩散模型生成可控的推荐解释文本，帮助用户理解推荐原因，提升推荐系统透明度。

INSIGHT扩散模型在文本生成的可控性上优于自回归方法——可以精确控制生成评论的情感、主题和长度。这为推荐解释提供了新的生成式方案。

业务关联UGC 社区中用户关注内容的相关性理由。Diffusion-EXR 的可控文本生成技术可用于搜索结果解释——告诉用户为什么某个帖子与其查询相关，提升搜索体验和用户信任。

证据论文在推荐系统数据集上验证了 DDPM 生成的评论在可控性和质量上优于传统序列生成方法，同时保持了推荐性能。

Sensory-Aware Sequential Recommendation via Review-Distilled Representations

ASEGR 框架利用 LLM 从商品评论中提取结构化感官属性（如「颜色: 哑光黑」），将这些属性压缩为紧凑 embedding，增强序列推荐模型（SASRec、BERT4Rec、BSARec）的 item 表示。

INSIGHT用户评论中蕴含丰富的感官体验信息，这些信息可以通过 LLM 提取并编码为 item 表示的增强维度。语言学提取的感官属性能有效补充行为序列模式。

业务关联UGC 社区的帖子评论中包含用户的真实体验描述。ASEGR 的思路可以迁移到社区搜索：从评论和回复中提取结构化特征来增强帖子的表示，提升搜索排序质量。

证据在 Amazon 四个品类数据集上，集成感官表示的 SASRec、BERT4Rec 和 BSARec 均比纯 ID 基线有一致改进，验证了感官信息对行为推荐的互补价值。
