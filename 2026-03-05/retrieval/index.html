MICE: Minimal Interaction Cross-Encoders for efficient Re-ranking

从 cross-encoder 中剥离非必要 token 交互，衍生出 MICE 轻量级 late-interaction 架构。

📖 深度解读 · 9 分钟arXiv ↗

综合分 / 5
KEY INSIGHT · 对业务意味着什么cross-encoder 中仅少量 token 交互对排序有贡献，移除冗余交互可在保持排序效果的同时大幅降低推理成本，获得一种介于 bi-encoder 和 cross-encoder 之间的高性价比方案。业务关联 社区搜索的排序模型面临推理延迟和效果的权衡。MICE 提供了一种在保持 cross-encoder 级排序精度的同时显著降低计算开销的新路径，适合作为 UGC 搜索的精排或粗排替换方案。证据 在 BEIR（13 个数据集）域内和域外评测中，MICE 在保持与 cross-encoder 相当的 nDCG@10 的同时，推理速度提升显著；相比 ColBERT 等 late-interaction 模型，在 OOD 场景下排序效果更优。

Relevance Matters: A Multi-Task and Multi-Stage Large Language Model Approach for E-commerce Query Rewriting

在京东搜索中提出多任务多阶段 LLM query 改写框架，将相关性任务注入改写过程。

INSIGHT将 query 改写和相关性判断作为多任务联合训练，再通过 DPO 对齐用户偏好，解决了传统改写只关注生成质量而忽视相关性的问题。这种 SFT + DPO 两阶段范式可复用于 UGC 搜索。

业务关联社区 UGC 搜索中用户表达与内容之间存在明显的词汇鸿沟，query 改写是核心模块。该工作在京东线上部署验证，其多任务 + DPO 方法可直接迁移至社区搜索的 query 理解链路。

证据在京东电商搜索线上 A/B 测试中，相比现有改写模型，CTR 和转化率均有显著提升；离线评估显示改写后的 query-商品相关性（标注一致率）提升明显。

Aijun Dai, Jixiang Zhang, Haiqing Hu, Guoyu Tang, Lin Liu, Ziguang Cheng

Contrastive Retrieval Heads Improve Attention-Based Re-Ranking

提出 CoRe heads 方法，从 LLM 注意力头中筛选对检索最有判别力的子集用于重排。

INSIGHTLLM 中不到 1% 的注意力头就能捕捉到排序所需的关键相关性信号。通过对比学习度量筛选这些 CoRe heads，可以构建 SOTA 的 listwise 重排器，无需微调整个模型。

业务关联基于 LLM 做搜索重排时，使用全部注意力头效率低且噪声大。CoRe heads 方法为社区搜索提供了一种低成本利用 LLM 做精排的路径——只用 1% 的 heads 就能获得显著效果提升。

证据在 3 个 LLM（Llama、Mistral 等）上的实验表明，CoRe heads 仅占全部 heads 的不到 1%，但聚合后的重排准确率在 TREC-DL 和 BEIR 上显著超越全 heads 基线和现有 attention-based 方法。

Linh Tran, Yulong Li, Radu Florian, Wei Sun

Reproducing and Comparing Distillation Techniques for Cross-Encoders

系统复现并对比 LLM 蒸馏与 cross-encoder 集成蒸馏两条训练路线，覆盖多种 backbone。

INSIGHT使用正确的蒸馏策略，传统 cross-encoder（如 DeBERTa-v3）可以达到 LLM 重排器的效果水平。LLM 蒸馏 vs. 强 cross-encoder 教师蒸馏的效果差距因 backbone 而异，选择 backbone 比选择蒸馏来源更重要。

业务关联社区搜索通常使用 cross-encoder 做精排但计算受限。该工作给出了在不同 backbone（BERT、DeBERTa 等）上蒸馏训练排序模型的最佳实践指南，可直接指导 UGC 排序模型的训练策略选择。

证据在 MSMARCO 和 TREC-DL 2019/2020 上对比了 LLM 蒸馏（RankDistiLLM）与 cross-encoder 集成蒸馏在 4 种 backbone 上的表现，发现 DeBERTa-v3-large 搭配适当蒸馏可达到接近 GPT-4 重排效果。

Victor Morand, Mathias Vast, Basile Van Cooten, Laure Soulier, Josiane Mothe, Benjamin Piwowarski

Timehash: Hierarchical Time Indexing for Efficient Business Hours Search

提出分层时间索引算法 Timehash，在生产搜索系统中实现 99% 以上的索引体积缩减。

INSIGHT通过自适应多分辨率时间编码，Timehash 在精度为 100% 的前提下将时间范围过滤的索引大小缩减 99%+，且支持根据数据分布自动选择最优层级。这是搜索工程中时间过滤的最佳实践参考。

业务关联社区 UGC 搜索中时效性过滤（如只搜近 7 天帖子）是高频需求。Timehash 的分层时间索引方法可直接应用于 UGC 搜索中基于发帖时间的过滤和排序。

证据在 1260 万条生产 POI 数据上测试，Timehash 相比分钟级索引减少 99%+ 索引大小，查询精度保持 100%；通过数据驱动方法选择最优层级，适配不同数据分布。

Jinoh Kim, Jaewon Son

Leveraging LLM-Assisted Query Understanding for Live Retrieval-Augmented Generation

提出 Omni-RAG 框架，用 LLM 对查询进行去噪和意图分解以提升在线检索效果。

INSIGHT面对真实场景中含噪、多义的用户 query，先用 LLM 做去噪 + 意图拆解，再用 BGE 做文档重排，比直接检索效果更好。这种 query 预处理 → 检索 → 重排的三段式流水线具有很强的工程实用性。

业务关联社区搜索中用户 query 通常短且含噪（口语化、缩写、错别字），该框架的 LLM 辅助 query 理解模块可直接用于改善 UGC 搜索中的 query 预处理环节。

证据在 SIGIR 2025 LiveRAG Challenge 中验证，Omni-RAG 在 OpenSearch 上使用 BGE 重排 + Falcon-10B 生成，处理含噪多意图查询时的回答准确率相比基线有显著提升。

Guanting Dong, Xiaoxi Li, Yuyao Zhang, Mengjie Deng

From Missteps to Mastery: Enhancing Low-Resource Dense Retrieval through Adaptive Query Generation

提出 iGFT 框架，通过自适应查询生成和迭代反馈提升低资源场景下的稠密检索。

INSIGHT在标注数据不足时，用 LLM 生成合成 query-doc 对进行训练存在质量问题。iGFT 通过迭代式反馈机制自适应调整合成数据的生成策略，比一次性生成方法效果更好。

业务关联社区 UGC 搜索常面临标注数据不足的问题。iGFT 的自适应合成数据方法可帮助在有限标注下快速训练 UGC 领域的稠密检索模型。

证据在多个低资源 IR 数据集上，iGFT 相比直接使用 LLM 生成数据训练的方法 Recall@100 和 nDCG@10 均有稳定提升，尤其在训练数据少于 1000 对时优势明显。

Zhenyu Tong, Chuan Qin, Chuyu Fang, Kaichun Yao, Xi Chen

Blending Learning to Rank and Dense Representations for Efficient and Effective Cascades

在两阶段检索中融合词法特征和稠密表征，用决策树 LTR 模型重排神经检索结果。

INSIGHT将 253 个手工词法特征与神经稠密表征混合输入 LTR 决策树模型做重排，可在几乎不增加延迟的情况下大幅提升检索效果。传统特征和神经信号是互补的，混合使用优于单独使用。

业务关联社区搜索系统中通常已有 BM25 等词法特征和稠密向量两套检索链路。该方法提供了一种简单有效的融合方案——用 LTR 树模型混合两类信号做精排，工程改造成本低。

证据在 MS-MARCO 上，混合方案相比纯稠密检索 nDCG@10 提升最高 11%，平均查询延迟仅增加 4.3%。

Franco Maria Nardini, Raffaele Perego, Nicola Tonellotto, Salvatore Trani

Full Stage Learning to Rank: A Unified Framework for Multi-Stage Systems

提出广义概率排序原则 GPRP，统一建模多阶段检索系统中各阶段的选择偏差。

INSIGHT多阶段检索系统中，每个阶段的排序模型受到下游阶段选择偏差的影响。GPRP 通过估计各阶段的选择偏差并将其纳入排序目标，让每个阶段的模型都能感知全局 pipeline 的需求。

业务关联社区搜索典型的多级漏斗（召回→粗排→精排→重排）中各阶段目标不一致是常见痛点。GPRP 框架提供了一种统一优化全链路排序目标的方法论。

证据在多阶段排序实验中，GPRP 方法相比独立优化每个阶段的基线，在终端 nDCG 和 MAP 上有一致性提升。

HELIOS: Harmonizing Early Fusion, Late Fusion, and LLM Reasoning for Multi-Granular Table-Text Retrieval

融合 early fusion、late fusion 和 LLM 推理三种策略解决多粒度表格-文本检索问题。

INSIGHT单一的 early fusion 或 late fusion 都有局限，early fusion 引入噪声上下文而 late fusion 丢失关联信息。HELIOS 的三级融合思路（早期对齐 + 动态匹配 + LLM 推理验证）为复杂结构化内容的检索提供了新范式。

业务关联社区搜索中结构化内容（如表格帖子、结构化问答）的检索面临类似挑战。HELIOS 的多粒度融合检索方法论可迁移至 UGC 中混合格式内容的检索场景。

证据在 OTT-QA 等开放域表格-文本检索数据集上，HELIOS 融合方案相比单独的 early/late fusion 基线在 Recall@100 和 MRR 上均有提升。
