OneRanker: Unified Generation and Ranking with One Model in Industrial Advertising Recommendation

OneRanker 提出在广告推荐系统中，将生成（召回）和排序在同一个模型中深度融合的架构。通过价值感知的多任务解耦架构（任务 token + 因果 mask），在共享表征空间内分离兴趣覆盖和价值优化目标，有效缓解生成与排序阶段的信息断裂问题。

SOLAR: SVD-Optimized Lifelong Attention for Recommendation

SOLAR 利用推荐系统中矩阵天然的低秩结构，提出 SVD-Attention 机制，在理论上对低秩矩阵无损，保留 softmax 的同时将注意力复杂度从 O(N²d) 降至 O(Ndr)。实现了终身（Lifelong）用户行为序列建模，能处理超长序列而不需截断。

INSIGHT推荐系统的用户-物品交互矩阵本身就是低秩的，利用这个先验通过 SVD 分解降低 attention 复杂度，是序列建模 scaling 的一个优雅且理论扎实的方案。

业务关联社区搜索中用户历史行为序列往往非常长（浏览、点击、搜索历史），SOLAR 的 SVD-Attention 可以在不截断的前提下高效建模全量用户行为，提升个性化排序效果。

证据理论证明 SVD-Attention 对低秩矩阵无损，复杂度从 O(N²d) 降至 O(Ndr)。来自快手团队（Kuaishou），作者阵容表明已有工业实践基础。

Zenith: Scaling up Ranking Models for Billion-scale Livestreaming Recommendation

Zenith 提出了面向十亿级直播推荐的排序模型 scaling 方案。核心思路是将高维稀疏特征投影为少量高维 Prime Token，通过 Token Fusion 和 Token Boost 模块实现高效特征交叉，展现出优于 SOTA 的 scaling law。已部署于 TikTok Live。

INSIGHT通过将大量稀疏特征压缩为少量高维 Prime Token 再做特征交叉，既降低了 token 数量又保留了信息密度，是工业排序模型 scaling 的实用范式。

业务关联社区搜索的排序模型同样面临高维稀疏特征的建模挑战，Zenith 的 Prime Token 思路可用于搜索排序中将大量 UGC 特征高效压缩交叉，提升 CTR AUC。

证据TikTok Live 线上 A/B 测试：CTR AUC +1.05%，Logloss -1.10%，Quality Watch Session/User +9.93%，Quality Watch Duration/User +8.11%。效果显著。

NC State University, TikTok, ByteDance

MAC: A Conversion Rate Prediction Benchmark Featuring Labels Under Multiple Attribution Mechanisms

MAC 是首个支持多归因机制（Multiple Attribution）标签的 CVR 预估公开数据集。同时开源了 PyMAL 库覆盖主流 multi-attribution learning (MAL) 方法。实验发现 MAL 在长转化路径用户上效果尤为显著，且性能增益随目标数量正向扩展。

INSIGHT转化归因机制的选择对 CVR 模型影响巨大，多归因学习能带来一致性提升。这是首个系统性研究多归因 CVR 的工作，开源数据集和代码库极大降低了研究门槛。

业务关联社区搜索中用户的转化行为（点击、收藏、回复）同样涉及归因窗口选择问题，MAC 的多归因学习思路可直接应用于社区场景的 CVR 预估优化。

证据首个多归因 CVR 公开数据集；开源 PyMAL 库；三个关键发现：MAL 带来一致提升、长转化路径收益更大、性能随目标数增长而扩展。来自阿里巴巴团队。

FlashEvaluator: Expanding Search Space with Parallel Evaluation

FlashEvaluator 解决生成式推荐/搜索中 Generator-Evaluator 框架的效率瓶颈：传统评估器独立处理每个候选序列（O(K) 复杂度），缺乏跨序列比较。FlashEvaluator 通过跨序列 token 信息共享，单次前向传播处理全部候选，实现亚线性计算复杂度。

INSIGHT在生成-评估框架中，通过跨候选序列的 token 共享实现并行评估，既提升选择精度（直接跨序列比较）又大幅提升吞吐量，是生成式推荐系统落地的关键优化。

业务关联社区搜索的重排序阶段需要从大量候选中选出最优排列，FlashEvaluator 的并行评估机制可直接用于搜索重排中加速候选评估，在延迟约束下扩大搜索空间。

证据理论证明亚线性复杂度，实验显示在推荐系统和 NLP 任务上均优于传统独立评估。来自快手团队，与 SOLAR 同一研究组。

Compress, Cross and Scale: Multi-Level Compression Cross Networks for Efficient Scaling in Recommender Systems

MLCC 通过分层压缩和动态组合组织特征交叉，捕获高阶依赖的同时保持计算效率。MC-MLCC 进一步将交互分解到并行子空间实现水平扩展。在保持甚至提升 AUC（+0.52）的同时，参数量和计算量降低最多 26 倍。已部署于 B 站广告平台。

INSIGHT通过多层压缩交叉网络实现高阶特征交互的高效 scaling，在 AUC 提升和计算降本之间取得极佳平衡，是工业推荐系统特征交叉方向的实用改进。

业务关联社区搜索排序中特征交叉是核心模块，MLCC 的分层压缩思路可用于在有限计算资源下实现更高阶的特征交叉，提升排序 AUC 同时控制推理延迟。

证据AUC 提升最高 0.52，参数和计算量降低最多 26x。已部署于 B 站（Bilibili）广告平台，有线上验证。

AlphaFree: Recommendation Free from Users, IDs, and GNNs

AlphaFree 提出完全摆脱用户 embedding、物品 ID 和 GNN 的推荐方法。通过预训练语言模型的语义表征替代 ID，在推理时实时推断用户偏好（无需存储 per-user embedding），解决了高内存开销、冷启动和过平滑等问题。

INSIGHT用预训练语言表征完全替代 ID embedding，配合实时偏好推断替代用户 embedding 存储，挑战了推荐系统三大设计惯例（user/ID/GNN 依赖），对下一代推荐架构有启发。

业务关联社区搜索中 UGC 内容更新频繁，ID-based 方法面临新内容冷启动问题。AlphaFree 的 ID-free 思路可用于社区搜索中快速为新帖子建立语义表征。

证据在多个标准推荐数据集上评测，在 top-K 推荐任务上取得有竞争力的结果，同时消除了传统方法的 ID 和 GNN 依赖。

Minseo Jeon, Junwoo Jung, Daewon Gwak, Jinhong Jung

APAO: Adaptive Prefix-Aware Optimization for Generative Recommendation

📖 深度解读 · 16 分钟 →

APAO 解决生成式推荐中训练-推理不一致问题：训练用 token 级交叉熵，推理用 beam search 多步生成，导致正确物品因前缀 token 得分低而被过早剪枝。提出前缀级优化框架，自适应调整每个前缀位置的优化权重。

INSIGHT生成式推荐的 beam search 推理会因前缀 token 的低概率而丢弃正确候选，这是训练-推理 gap 的一个重要但被忽视的问题。前缀级优化提供了针对性解决方案。

业务关联生成式推荐/检索在搜索系统中应用日益广泛，APAO 揭示的训练-推理不一致问题具有普遍性，其前缀级优化思路可提升生成式搜索的召回质量。

证据在多个标准顺序推荐数据集上验证，APAO 显著提升了 beam search 的召回准确率，消融实验证明自适应权重优于固定权重。来自清华大学团队。

S2CDR: Smoothing-Sharpening Process Model for Cross-Domain Recommendation

S2CDR 提出用平滑-锐化过程模型解决跨域推荐中的用户冷启动问题。不同于传统扩散模型在前向过程中添加高斯噪声（会损害个性化偏好），S2CDR 设计了基于 ODE 的腐蚀-恢复架构，在跨域偏好迁移中保留用户个性化信息。

INSIGHT将扩散模型用于跨域推荐时，标准高斯噪声会破坏用户偏好信号。平滑-锐化范式通过 ODE 求解实现更可控的偏好迁移，为冷启动场景提供了新思路。

业务关联社区搜索面临新用户冷启动问题，S2CDR 的跨域偏好迁移方法可将用户在其他域（如浏览、购物）的行为迁移到搜索域，缓解搜索冷启动问题。

证据在多个跨域推荐基准上优于现有 DM-based CDR 方法，通过 ODE 求解保证了偏好迁移的可控性。消融实验验证了平滑-锐化各组件的贡献。

MoToRec: Sparse-Regularized Multimodal Tokenization for Cold-Start Recommendation

MoToRec 将多模态推荐转化为离散语义 tokenization 问题。通过稀疏正则化的 RQ-VAE 生成可组合的语义编码，包含三个协同组件：稀疏正则化 RQ-VAE、跨模态对比对齐、以及 token 级交互建模。有效解决新物品缺乏交互历史的冷启动问题。

INSIGHT将多模态内容通过稀疏 RQ-VAE 量化为离散 token，再用 token 级建模替代传统 ID embedding，是解决物品冷启动的一个可扩展方案。

业务关联社区搜索中大量新帖子缺乏交互历史（物品冷启动），MoToRec 的多模态 tokenization 方法可利用帖子文本、图片等内容特征生成语义 ID，改善新帖排序。

证据在多个推荐基准上优于现有 GNN 和多模态推荐方法，特别是在冷启动场景下效果显著。消融实验验证了稀疏正则化和跨模态对齐的各自贡献。
