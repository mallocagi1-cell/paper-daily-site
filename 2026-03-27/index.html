OneSearch-V2: The Latent Reasoning Enhanced Self-distillation Generative Search Framework

OneSearch-V2 是阿里巴巴在工业级生成式搜索框架 OneSearch 基础上的重大升级。论文针对生成式检索（GR）在复杂 query 理解不足、长尾稀疏性和信息茧房等问题，提出了思维增强模块（thought-augmented modules）、推理内化自蒸馏训练策略以及行为偏好对齐优化三大核心改进。在线 A/B 实验显示 CTR 提升 3.98%、转化率提升 3.05%、订单量提升 2.11%，同时显著减少了信息茧房效应和长尾稀疏问题。

PLUM: Adapting Pre-trained Language Models for Industrial-scale Generative Recommendations

Google

PLUM 是 Google 提出的工业级生成式推荐框架，核心思路是将预训练语言模型（PLM）适配到推荐场景。方法包含三步：(1) 语义物品 tokenization，将推荐物品映射为语义 token 序列；(2) 领域特定的继续预训练，使 PLM 理解推荐语义空间；(3) 针对生成式检索的微调。在 YouTube 大规模视频推荐数据集上的实验表明，PLUM 优于生产环境中的 embedding-based 模型，并提供了 scaling 分析和部署细节。

INSIGHTPLUM 验证了预训练语言模型在工业级推荐系统中的可行性路径：语义 tokenization → 继续预训练 → 任务微调。这一范式对搜索推荐系统具有直接借鉴价值——它表明不需要从零训练生成式推荐模型，而是可以复用 LLM 的语义理解能力。关键实践启示是 scaling 分析的结果：更大的 PLM 和更多的推荐数据在性能上呈现类似 LLM 的 scaling law，为搜索推荐模型的规模化提供了方向指引。

Problems with Chinchilla Approach 2: Systematic Biases in IsoFLOP Parabola Fits

论文揭示了广泛使用的 Chinchilla Approach 2 在拟合神经网络 scaling law 时存在系统性偏差。在 Llama 3 的 IsoFLOP 数据上，这种偏差导致参数分配不足，对应 3.8×10^25 FLOP 训练预算中 6.5% 的浪费（约 140 万美元）。多模态模型因 loss surface 不对称性更严重，损失更大。论文分析了三种误差来源（IsoFLOP 采样网格宽度、非居中采样、loss surface 不对称性），并证明 Chinchilla Approach 3 结合 Variable Projection 方法可消除这些偏差。

INSIGHT这项工作对搜索推荐领域大模型 scaling 规划有直接指导意义。当我们使用 Chinchilla Approach 2 为生成式推荐模型制定 scaling 计划时，可能系统性地低估了最优模型大小，导致 compute 浪费。论文推荐的 Approach 3 + Variable Projection 方法更为可靠。对于正在 scaling 搜索排序/推荐模型的团队，重新审视 scaling law 拟合方法可能带来显著的资源节省。

Eric Czech, Zhiwei Xu, Yael Elmatad, Yixin Wang, William Held

Self-Distillation for Multi-Token Prediction

Tencent

论文提出 MTP-D，一种基于自蒸馏的多 token 预测（MTP）方法，解决了现有 MTP 方案中预测头接受率低和多头联合训练困难的问题。MTP-D 通过自蒸馏策略让多个预测头相互学习，将 MTP head 的接受率提升 7.5%，同时不损害主头性能。进一步提出的 looped extension 策略使推理加速达到 220.4%。在 7 个基准测试上验证了方法的有效性和可扩展性。

INSIGHTMulti-Token Prediction 是生成式推荐（如 HSTU）中的核心技术，MTP-D 的自蒸馏策略可直接迁移至生成式推荐模型的 MTP 训练。7.5% 的接受率提升意味着在推理时可以更高效地并行生成多个 item token。Looped extension 的 2.2x 加速对在线服务的延迟控制尤为关键——生成式推荐的推理延迟一直是工业部署的主要瓶颈。

Guoliang Zhao, Ruobing Xie, An Wang, Shuaipeng Li, Huaibing Xie, Xingwu Sun

The Alignment Tax: Response Homogenization in Aligned LLMs and Its Implications for Uncertainty Estimation

论文揭示了 RLHF 对齐后的 LLM 存在「响应同质化」（response homogenization）现象：在 TruthfulQA 上 40-79% 的问题在 10 次采样中只产生一个语义聚类。通过 Base→SFT→DPO 消融实验定位问题根源为 DPO（而非 SFT）导致的认知表达抑制。在 22 个实验、5 个基准、4 个模型家族、3 种模型规模上验证了这一发现。提出的 cheapest-first cascade（UCBD）将 GSM8K 准确率从 84.4% 提升至 93.2%（50% coverage），同时节省 57% 成本。

INSIGHT对齐导致的响应同质化对生成式推荐有直接警示意义——如果生成式推荐模型使用 DPO/RLHF 做偏好对齐，可能导致推荐结果多样性严重下降（信息茧房）。论文精确定位 DPO 而非 SFT 是罪魁祸首，这意味着生成式推荐在做偏好对齐时应优先考虑 SFT-based 方法或在 DPO 中引入多样性约束。UCBD cascade 的思路也可用于推荐系统的不确定性估计和探索-利用平衡。

Why Does Self-Distillation (Sometimes) Degrade the Reasoning Capability of LLMs?

Microsoft

论文深入分析了自蒸馏（self-distillation）在数学推理任务中导致 LLM 性能退化的根因——认知表达抑制（epistemic verbalization suppression）。当 teacher 模型基于丰富上下文生成时，会抑制不确定性表达，导致学生模型在域外问题上丧失适应能力，性能下降高达 40%。在 Qwen3-8B、DeepSeek-Distill-Qwen-7B 和 Olmo3-7B-Instruct 上验证了这一发现。核心结论是保持适当的不确定性表达对鲁棒推理至关重要。

INSIGHT自蒸馏是生成式推荐模型训练的常用技术（如 OneSearch-V2 的 reasoning-internalized self-distillation），该论文揭示了自蒸馏可能带来的隐患。关键启示：在蒸馏过程中不应过度压缩 teacher 的不确定性信号，否则模型会在 OOD 场景（如长尾 query、新物品）上退化。实践建议是控制 teacher 的上下文丰富度（conditioning context），在蒸馏效率与泛化能力之间取得平衡。

Beyond Multi-Token Prediction: Pretraining LLMs with Future Summaries

Meta

论文提出 Future Summary Prediction（FSP），超越传统的 Multi-Token Prediction（MTP）。FSP 训练辅助 head 预测未来序列的紧凑表示（而非逐 token 预测），保留与长程生成相关的信息。两种变体：手工摘要（如未来序列的词袋）和学习摘要（使用从右到左训练的反向语言模型生成 embedding）。在 3B 和 8B 模型上的大规模预训练实验表明，FSP 在数学、推理和编程基准上均优于 NTP 和 MTP。

INSIGHTFSP 对生成式推荐的启发在于：传统的 next-item prediction 和 multi-item prediction 可能都不是最优的训练目标。FSP 提出的「预测未来序列摘要」理念可迁移至推荐场景——例如预测用户未来 session 的兴趣分布摘要，而非逐个预测下一个点击物品。这种更高层次的预测目标可能帮助模型捕获更长期的用户意图和兴趣演化模式，解决生成式推荐中的短视问题。

HDPO: Hybrid Distillation Policy Optimization via Privileged Self-Distillation

论文提出 HDPO，解决 LLM 强化学习训练中的「悬崖」问题——当模型完全无法解决某些 prompt 时，RL 梯度会消失。HDPO 将标准 RL 与特权自蒸馏（privileged self-distillation）结合：识别不可解 prompt，利用 ground-truth 信息生成特权 rollout，过滤正确解后将 teacher 的 token-level 分布蒸馏给 student。理论证明 R=1 过滤的特权生成在硬阈值极限下可恢复最优 KL 正则化 RL 策略。在 Qwen2.5-Math-1.5B-Instruct 上实验验证了一致性提升。

INSIGHTHDPO 的特权自蒸馏思路对生成式推荐的 RL 训练有直接借鉴价值。在推荐场景中，模型对某些冷启动物品或长尾 query 也会出现「悬崖」现象。HDPO 的解法——利用特权信息（如用户真实反馈、物品特征）生成辅助训练信号——可以帮助生成式推荐模型更好地处理这些难例，而无需放弃 RL 训练框架。

Beyond Masks: Efficient, Flexible Diffusion Language Models via Deletion-Insertion Processes

Huawei

论文提出 Deletion-Insertion Diffusion（DID）语言模型，用 token 删除-插入过程替代传统 Masked Diffusion Language Model 的掩码-去掩码范式。DID 通过消除对非信息性 mask/padding token 的计算来提升效率，原生支持变长序列，并包含生成时的自纠正机制。设计了基于 score-matching 的训练方法和并行化动态规划算法。实验在性能、采样质量和计算速度上均优于 masked diffusion 基线。

INSIGHTDID 提供了自回归之外的另一种生成范式选择。对于生成式推荐，masked diffusion（如 ContRec）已被探索用于物品序列生成，而 DID 的删除-插入机制更自然地建模了用户行为序列的动态变化——用户兴趣的消退（deletion）和新兴趣的出现（insertion）。其变长序列支持和自纠正能力对推荐场景中用户序列长度不一致的问题尤为适用。
