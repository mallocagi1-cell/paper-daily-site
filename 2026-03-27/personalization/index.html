UniScale: Synergistic Entire Space Data and Model Scaling for Search Ranking

淘宝搜索想把排序模型做大，发现瓶颈在数据：他们把未曝光候选和推荐、店铺里的行为改造成搜索样本，训练数据扩到 5 倍，再配一个按场景隔离梯度的 Transformer。同样的扩充数据放到旧结构上 AUC 反而下降 0.43%，放到新结构上提升 0.32%。线上 A/B 购买提升 1.70%，但结构、数据和工程优化一起上，线上没有拆开各自的贡献。跨场景数据不能直接混进去训，必须配上能隔离场景的结构。

Entire Space Counterfactual Learning for Reliable Content Recommendations

📖 深度解读 · 7 分钟 →

论文聚焦推荐系统中的点击后转化率 (CVR) 估计问题，指出现有整体空间多任务模型（如 ESMM）存在两个核心缺陷：内在估计偏差 (IEB) 和外在信息偏差 (EIB)。IEB 来源于行为序列分解中的条件概率估计偏差，EIB 来源于训练样本的选择偏差。作者提出基于反事实学习的整体空间建模方法，通过因果推断框架纠正这两类偏差，在多个数据集上的实验表明该方法能显著提升 CVR 预估的可靠性。

INSIGHT该工作的核心贡献在于将因果推断与整体空间多任务学习相结合，从理论层面分析了 ESMM 类模型的偏差来源。对于搜索推荐场景中的 CTR/CVR 多目标建模，这提供了一个系统化的去偏框架。实践启示包括：(1) 在构建'曝光→点击→转化'多任务模型时需关注条件概率链的传导偏差；(2) 反事实学习可作为线上 A/B 测试的补充手段来评估模型在未观测行为上的表现；(3) 该方法与现有 ESMM 架构兼容，部署成本较低。

Hao Wang, Zhichao Chen, Zhaoran Liu, Haozhe Li, Degui Yang, Xinggao Liu, Haoxuan Li

CollectiveKV: Decoupling and Sharing Collaborative Information in Sequential Recommendation

论文针对基于 Transformer 的序列推荐模型面临的推理延迟问题，提出 CollectiveKV 方法。现有 KV Cache 技术虽能减少推理延迟，但在序列推荐场景中引入了大量存储开销，且用户间的协同信息被孤立在各自的 KV Cache 中无法共享。CollectiveKV 通过解耦用户序列中的个体信息与协同信息，将协同信号提取到共享的 KV 存储中，既降低了存储开销又提升了推荐质量。

INSIGHTCollectiveKV 的关键创新在于发现序列推荐中的 KV Cache 存在'信息孤岛'问题——每个用户的注意力缓存只包含自身行为信息，忽略了协同过滤中跨用户的相似性信号。通过共享协同 KV，模型可以在不增加推理成本的情况下引入类似协同过滤的跨用户信号。这对于 UGC 搜索场景中基于 Transformer 的用户序列建模有直接参考价值：在保持低延迟的同时融入协同信息，可改善长尾用户和冷启动场景下的推荐效果。

Sequence-aware Large Language Models for Explainable Recommendation

论文提出 SELLER 框架，将大语言模型用于推荐系统的可解释性生成。SELLER 采用双路径编码器分别建模用户行为序列和物品语义，并通过 Mixture-of-Experts 适配器将序列动态信息注入 LLM 的解释生成过程。论文还提出了基于效用感知的评估指标，弥补了现有方法在评估解释质量时与实际推荐效用不对齐的问题。

INSIGHTSELLER 的核心价值在于将序列推荐中的时序行为动态引入 LLM 解释生成，解决了'静态解释无法反映用户兴趣演变'的问题。MoE 适配器设计允许不同用户行为模式激活不同的专家网络，提升了解释的个性化程度。对搜索推荐从业者而言，可借鉴其双路径编码 + MoE 适配的技术架构，在不修改主推荐模型的前提下为排序结果生成个性化解释文本，提升用户对搜索结果的信任度和点击意愿。

Gangyi Zhang, Runzhe Teng, Chongming Gao

Lightweight Fairness for LLM-Based Recommendations via Kernelized Projection and Gated Adapters

论文针对基于 LLM 的推荐系统中的公平性问题，提出轻量级偏差消除方法。现有方案要么需要额外参数微调（计算成本高），要么存在优化不稳定性。作者结合核化迭代零空间投影 (Kernelized INLP) 和门控适配器，在不修改 LLM 主干参数的情况下移除表示中的人口统计信息编码，同时通过门控机制保留推荐任务所需的有用信号。

INSIGHT该方法的核心优势是'零微调去偏'——通过在 LLM 表示空间中进行核化投影来消除敏感属性编码，再通过门控适配器恢复被误删的有用特征。这对于部署了 LLM 推荐能力的搜索系统具有实践意义：无需重新训练大模型即可实现公平性约束，适合作为模型服务层的即插即用模块。技术设计上，核化投影相比线性投影能捕获非线性偏差模式，这是一个值得借鉴的技术选择。

Nan Cui, Wendy Hui Wang, Yue Ning

SumRank: Aligning Summarization Models for Long-Document Listwise Reranking

Renmin University

论文提出 SumRank 方法，解决 LLM 在长文档列表级重排序中因上下文长度过大导致的效果和效率问题。核心思路是训练一个与下游重排序对齐的摘要模型，将长文档压缩为简洁的'排序对齐摘要'，再输入 LLM 进行列表级重排序。SumRank 通过引入排序感知的对齐训练目标，确保摘要保留与排序决策最相关的信息。

INSIGHTSumRank 的技术亮点是'排序感知摘要'——摘要模型不是通用的文本压缩，而是针对下游排序任务进行了端到端对齐。这意味着摘要会保留对排序判断最关键的信号（如相关性线索、实体信息），而非通用的内容概要。对于 UGC 搜索中的长帖子/长回答排序场景，可借鉴这一思路：先用轻量模型提取排序关键信息，再用大模型进行精排，从而在保持排序质量的同时控制推理成本。

Jincheng Feng, Wenhan Liu, Zhicheng Dou

Implicit Turn-Wise Policy Optimization for Proactive User-LLM Interaction

Meta

论文提出 ITPO (Implicit Turn-wise Policy Optimization) 方法，解决多轮人机交互优化中的两个核心挑战：中间轮次奖励稀疏和用户响应高随机性。ITPO 利用隐式过程奖励模型从稀疏的最终结果信号中推导细粒度的逐轮过程奖励，实现对话式推荐、自适应教学等多轮交互场景的策略优化。

INSIGHTITPO 的核心创新是将隐式过程奖励建模引入多轮交互优化——不需要人工标注每一轮的即时奖励，而是通过学习到的隐式价值函数自动分解最终目标到各轮次。这对搜索推荐中的对话式交互场景（如多轮 query 改写、交互式推荐）有直接应用价值：系统可以根据最终的点击/转化信号自动学习每一步交互策略，无需为中间步骤设计复杂的即时奖励函数。来自 Meta 团队的工作，具有工业应用潜力。

Haoyu Wang, Yuxin Chen, Liang Luo, Buyun Zhang, Ellie Dingqiao Wen, Pan Li

Accelerating Matrix Factorization by Dynamic Pruning for Fast Recommendation

论文针对大规模推荐系统中矩阵分解 (MF) 模型的训练效率问题，提出动态剪枝加速方法。随着用户和物品数量的急剧增长，MF 模型的训练计算复杂度大幅提升。现有加速方法依赖额外计算资源或并行系统，成本较高。作者提出在训练过程中动态识别并跳过对模型收敛贡献较小的用户-物品交互对，显著减少训练计算量而不损失预测精度。

INSIGHT动态剪枝的核心思路是'不是所有交互数据对模型训练同等重要'——训练后期大量用户-物品对的梯度趋近于零，继续计算这些交互是浪费。该方法通过实时监测梯度幅度来动态调整训练样本集，在不引入额外硬件开销的前提下实现加速。对于 UGC 搜索场景中的离线推荐模型训练，这提供了一种低成本的训练加速策略，特别适合数据量大但计算预算有限的团队。

Yining Wu, Shengyu Duan, Gaole Sai, Chenhong Cao, Guobing Zou
