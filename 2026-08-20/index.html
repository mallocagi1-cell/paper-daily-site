Once Generated, Ranked: End-to-End Generative Slate Recommendation with Unified Semantic-Collaborative IDs

论文把推荐单位从单个物品提升为完整 slate，提出端到端生成排序框架 OGR。TUSID 将物品语义信息与局部协同信号融合为层次化 Semantic ID，SPA 再用奖励引导的保守策略优化对齐列表效用，并通过位置级流水线解码建模物品间依赖。在工业数据和公开数据上，NDCG@5 相对提升 48.2% 和 27.2%；快手线上 A/B 的 Effective Views 提升 1.120%。

DEPT: Document Embedding Preservation Tuning for Unified Query Expansion and Retrieval

DEPT 用同一个 decoder-only LLM 同时生成 query 扩展、编码扩展后的 query 和文档，并用文档 embedding 保持损失抑制检索目标漂移。固定 whitening、straight-through 解码和在线 hard-negative mining 让查询侧持续适配，同时复用已有文档索引。在五个 BEIR 任务上，Qwen3-4B 的平均 nDCG@10 达 42.59，超过 ExpandR 的 41.09 和 UniRAG 的 38.62；LLaMA-3.2-3B 达 39.60。

INSIGHT这项工作把生成式 query 改写从离线 prompt 技巧变成可由最终检索损失直接训练的动作，同时用 DEP 损失把更新压力集中到 query 侧。UGC 短文本搜索可先缓存文档向量和 whitening 统计量，再训练生成器适配口语化、缩写和隐含约束；其四卡、LoRA、1k steps 的配置说明原型成本可控，但长扩展文本的在线延迟仍需单独评估。

Jingyuan Wang, Richong Zhang, Zhijie Nie, Mingxin Li, Yanzhao Zhang

ChatGPT Ads expands across Europe

OpenAI

OpenAI 公布 ChatGPT Ads 向欧洲 31 个市场扩展，广告主可在用户探索、比较和决策过程中触达受众。文章是产品与商业化公告，没有公开推荐模型、生成排序架构或线上指标，因此只能作为生成式广告推荐的行业动态观察，而不是方法论文。

INSIGHT对社区搜索团队而言，这条动态的价值在于提示生成式交互与商业推荐正在合流：广告位可能需要理解用户自然语言意图、比较过程和决策阶段。技术侧应优先建设可解释的意图抽取、候选约束和相关性评估，再讨论把生成模型接入广告排序；当前公开信息不足以支持直接复用其系统设计。
