Write, Execute, Refine: From Skill Followers to Skill Optimizers via Reinforcement Learning from Execution Feedback

WER（Write, Execute, Refine）把工具型 Agent 的技能优化拆成多阶段流程：Skill Optimizer 提议自然语言技能，冻结的 Executor 重复执行，程序化验证器评分，再将成功与失败轨迹配对为下一阶段的 refinement 状态。论文指出，Agent 自写技能比不使用技能低 8–11 个百分点，WER 用执行反馈把改进目标从提示词修补转为可训练的相对信用分配。

Token Optimization and Context Window Management in Multi-Agent AI Workflows

该论文从生产工作流总结多 Agent 的 token 与上下文管理方法，包括上下文分层、一次抓取本地处理、schema 约束提示、token 感知 fallback、语义缓存和 Agent 间通信压缩。生产仪表盘将冷加载延迟从约 3.5–10.5 分钟降到 61–116 秒，估计 token 减少 60–70%；另有 11 种模型配置、2,420 次受控试验和 661 条匿名工作项。

INSIGHT搜索 Agent 的成本瓶颈通常来自重复抓取、长上下文和无效中间状态，而不只是模型单价。可将检索结果先规范化成证据卡片，按任务阶段分层加载，用语义缓存复用相同子查询，并给每轮设置 token/延迟预算；这些改造能直接服务 UGC 搜索的高峰流量，同时保持复杂查询的多步能力。

Dvir Shamay

03 4.10

Agentic ESOpt: Fine-Tuning Long-Horizon LLM Agents with Minimal GPU Requirements

Agentic ESOpt 讨论长时程 Agent 训练中的分支交互、稀疏奖励和信用分配问题，提出用 Evolution Strategies 替代依赖反向传播的 Agentic RL。方法通过黑盒轨迹反馈做参数归因，只需推理级 GPU 内存即可支持全参数优化，并能与 prompt-space evolution、skill optimization 和 test-time compute 组合。

INSIGHT当搜索 Agent 的奖励来自最终答案、证据完整性和调用成本的组合时，反向传播式 RL 很容易受长轨迹和基础设施限制。ES 的黑盒接口允许直接接入线上回放或离线评测，但样本效率和稳定性需要严谨验证；可先用小模型在 query 改写或停止策略上做局部实验，再决定是否扩展到全参数。

Zhi Zheng, Rongsheng Chen, Yunpeng Ba, Zhenkun Wang, Yee Whye Teh

HarnessRisk: A Lifecycle-Oriented Benchmark for Agent Harness Safety

HarnessRisk 将 Agent harness 安全拆成配置、能力扩展、运行、状态持久化、动作控制和事件恢复六个生命周期阶段，构建 128 个沙箱案例，并用 Utility、Attack Success Rate、Persistence、Detection 评估轨迹。在三个 harness、六个语言模型和 14 种配置上，攻击成功率从 12.6% 到 80.9% 不等，显示安全问题会随工具、权限和状态管理组合而放大。

INSIGHT搜索 Agent 不只是召回和生成链路，还会读取不可信帖子、调用外部搜索并持久化中间状态，因此应把间接提示注入和权限越界纳入相关性实验。可按六阶段建立沙箱回归集，分别监控证据污染、错误工具调用和状态残留，并将安全失败与答案质量、成本和延迟一起纳入发布门槛。

Yajing Bai, Jinhao Duan, Jie Peng, Xianfeng Wu, Sijia Liu

05 3.95

LEGO-RL: Harness-Native Reinforcement Learning for Coding Agents

LEGO-RL 研究如何把原生 Agent harness 接入可扩展的策略梯度训练，而不修改 harness 的控制流。它用进程内 LLM proxy 捕获原始生成流并重算 token 级 log-probability，同时通过带镜像缓存和分阶段防护的 sandbox 编排处理环境崩溃、奖励攻击及训练—推理不一致问题，目标是让长时程工具调用的训练信号可靠可复现。

INSIGHT对于搜索 Agent，训练框架必须忠实记录工具调用、上下文压缩和环境失败，否则离线奖励无法代表线上行为。LEGO-RL 的 proxy 与 sandbox 思路可迁移到检索 harness：先固化可重放的搜索环境、错误分类和 token 对齐，再做策略优化；这比直接把普通 RL 套在最终答案奖励上更容易排查训练漂移。

Yiming Du, Yuxin Jiang, Tao Yuan, Jianbo Dai, Shaowei Wang

StartupBench: Benchmarking General-Purpose Agents on Market-Validated End-to-End Workflows

StartupBench 从已经被市场验证的 AI 创业产品、真实工作流和用户需求中构造端到端 Agent 基准，而不是只用研究者预设任务。它把产品流程转成有明确交付物的复杂任务，并在统一 harness 下用细粒度 rubric 评估模型是否满足完整要求，重点检验 Agent 能否完成真实工作，而非只回答单个问题。

INSIGHT社区搜索 Agent 的离线评测也应从真实查询链路抽取任务：发现、改写、跨文档取证、引用和结果交付必须整体评分。可按用户常见的复杂搜索流程设计交付物 rubric，并记录每一步工具调用与失败原因；这样才能避免模型在单跳 QA 上得分很高，却在真实 UGC 多轮搜索中无法收敛。

Liya Zhu, Xin Ma, Tao Liu, Haodong Wang, Ge Zhang

Foundation Agents Meet Agentic Deep Research: Evidence-Grounded Clinical Code Forecasting

ICD-Deepresearch 将结构化 EHR foundation model、语言模型预测、医学搜索和 ICD 词典组合成证据驱动的 DeepResearch 工作流。系统先由 SparseEHR 生成 EHR Prior，再进行两轮有界 Research Expansion，并用固定 top-K 预算连接患者证据、外部临床关系和精确代码语义；独立的 GPT-5 Direct Forecast 提供互补候选。

INSIGHT它给社区搜索的可迁移点是“先验召回 + 有界扩展 + 证据链接”，而不是让 Agent 无限浏览。可以让用户历史查询、帖子主题和实体词先生成候选先验，再允许最多两轮补充检索，并要求每个候选绑定原文片段和实体关系；固定 top-K 与预算有助于同时控制 nDCG、覆盖率和时延。

Junda Wang, Meysam Ghaffari, Akshat Choube, Mohsen Sharifi Renani, Hong Yu, Carlos Morato

TCMIIES: A Browser-Based LLM-Powered Intelligent Information Extraction System for Academic Literature

TCMIIES 是一个零安装、浏览器端的文献结构化抽取系统，用 schema-guided prompting 自动生成系统提示，支持用户自定义字段、五家主流模型、并发批处理、自动重试以及 CNKI/Wanfang 的字段映射。论文在 500 篇中医研究论文上评估多个抽取场景，结构化输出合规率超过 94%，抽取准确度接近领域专家标注。

INSIGHT虽然场景是学术文献，但它展示了 Agent 处理非结构化内容时应采用的工程边界：先用 schema 固化输出，再用并发、重试和字段映射承接模型不稳定性。社区搜索可将帖子、问答和评论先转成可校验的实体—关系卡片，并在浏览器或边缘侧做敏感内容处理，减少自由文本 Agent 直接写入索引的风险。

Hanqing Zhao

INSIGHT它不是搜索论文，但对 Agentic 生产化的启示很直接：把可执行验证器、回滚边界和阶段性验收放进 Agent loop，才能把模型能力转成稳定交付。搜索系统可采用同样的闭环，让 query rewrite、召回配置和索引变更都通过离线回放与自动测试验证，再逐步放量到线上。

ArborMem: Navigating Interaction States with Memory Forests

ArborMem 将长对话表示为可导航的 interaction-state forest：每条分支保存局部连贯的任务轨迹，整片 forest 同时保留可中断、可恢复的多条计划。与只按相似度检索历史不同，系统先判断当前输入要恢复哪一个交互状态，再在对应分支中访问记忆，面向多任务交错和计划回访场景。

INSIGHTAgentic 搜索也会出现多个并行子查询、用户改写和中途打断，单一会话摘要容易把不同意图混在一起。可把每次查询计划、证据缺口和用户反馈挂到状态树上，恢复时先选分支再取证据；但要限制树的增长、定义过期策略，并用跨轮任务完成率验证记忆是否真的改善检索。
