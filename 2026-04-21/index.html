On the Equivalence Between Auto-Regressive Next Token Prediction and Full-Item-Vocabulary Maximum Likelihood Estimation in Generative Recommendation

本文首次严格证明了生成式推荐（GR）中 k-token 自回归下一 token 预测（AR-NTP）范式与全物品词表最大似然估计（FV-MLE）在数学上严格等价，前提是物品与其对应 token 序列之间存在双射映射。该等价性同时适用于级联式和并行式 tokenization 方案。这一理论结果为当前工业界普遍采用的「tokenization + NTP 训练 + 自回归解码」GR pipeline 提供了坚实的理论基础。

From Features to Transformers: Redefining Ranking for Scalable Impact

LinkedIn

LinkedIn 提出 LiGR（LinkedIn Generative Ranking）框架，验证了 Transformer 模型在推荐排序系统中的 Scaling Law：更大模型、更多训练数据、更长上下文序列均能带来持续的性能提升。该工作从传统特征工程模式转向端到端 Transformer 架构，在生产环境中实现了显著的排序效果提升，为推荐系统走向基础模型范式提供了工业级证据。

INSIGHTLiGR 的核心启示是推荐排序也遵循类似 LLM 的 Scaling Law——模型容量、数据规模和序列长度三个维度的扩展都能带来可预测的收益。这对搜索推荐团队的架构决策具有直接指导意义：投资更大的 Transformer 模型和更长的用户行为序列编码是有回报的。同时验证了从 feature-based 到 sequence-based 的范式迁移在工业场景中的可行性。

Fedor Borisyuk, Lars Hertel, Ganesh Parameswaran, Gaurav Srivastava, Sudarshan Srinivasa Ramanujam 等 17 人

Does LLM Focus on the Right Words? Mitigating Context Bias in LLM-based Recommenders

本文发现 LLM-based 推荐模型存在严重的上下文偏差问题：模型过度依赖任务描述和前缀生成 token 等辅助信息，而忽略了真正编码用户偏好的核心交互 token。这种注意力分配失衡导致推荐质量下降。作者提出了针对性的缓解策略，通过调整 LLM 的注意力分布使其更关注用户行为信号，从而提升推荐准确性。

INSIGHT该研究揭示了 LLM-as-Recommender 范式的一个关键陷阱：prompt 设计不当会让 LLM「看错地方」——将注意力浪费在指令性文本而非用户行为特征上。这对实践的直接启示是：在构建 LLM 推荐系统时，需要精心设计 prompt 结构或引入注意力引导机制，确保模型能有效利用用户交互历史。对 UGC 搜索场景中的 LLM 排序同样适用。

Bohao Wang, Jiawei Chen, Feng Liu, Changwang Zhang, Jun Wang, Canghong Jin, Chun Chen, Can Wang

RankFlow: A Multi-Role Collaborative Reranking Workflow Utilizing Large Language Models

RankFlow 提出一种多角色协作的 LLM 重排序工作流：将 LLM 分化为 Query Rewriter（查询改写）、Answerer（伪回答生成）、Summarizer（段落摘要）和 Reranker（最终排序）四个专业角色。通过角色分工实现对 query 的深度理解、LLM 外部知识的有效利用、段落的精炼压缩和全面的相关性评估。实验表明 RankFlow 在多个基准上超越现有主流重排方法。

INSIGHTRankFlow 的设计理念是将复杂的重排序任务分解为多个可控的子任务，每个子任务由 LLM 的不同角色完成——这种多角色 workflow 模式比单次 LLM 调用更能发挥大模型的推理能力。对搜索系统的启示：可在 reranking 阶段采用类似的 pipeline 架构，让 LLM 先理解 query 意图、补充知识，再进行最终排序，而非简单地把 query+doc 丢给 LLM 打分。

Can Jin, Hongwu Peng, Anxiang Zhang, Nuo Chen, Jiahui Zhao, Xi Xie, Kuangzheng Li, Shuya Feng 等 11 人

Towards Comprehensible Recommendation with Large Language Model Fine-tuning

本文探索通过微调 LLM 为推荐系统生成可解释的推荐特征。利用 LLM 的推理能力推断用户行为模式，结合其广泛的世界知识发掘更丰富的物品信息，从而实现既准确又可理解的推荐。该方法将 LLM 作为特征生成器而非直接作为推荐模型，降低了部署成本同时保留了 LLM 的知识优势。

INSIGHT将 LLM 定位为推荐系统的「特征增强器」而非「端到端推荐器」是一种务实的工业落地策略——LLM 生成高质量特征（用户意图标签、物品语义描述等），再由轻量级排序模型消费这些特征。这种方案兼顾了 LLM 的推理优势和在线推理的延迟要求，对 UGC 搜索场景中的 query 理解和文档表示增强有直接参考价值。

Yunze Luo, Yinjie Jiang, Gaode Chen, Xinghua Zhang, Kaigui Bian

Diffusion-Based Cloud-Edge-Device Collaborative Learning for Next POI Recommendations

已录用 KDD 2024

本文提出基于扩散模型的云-边-端协作学习框架，用于下一个兴趣点（POI）推荐。采用扩散模型作为生成式推荐的核心，结合多层级计算架构实现隐私保护和低延迟推理。在 KDD 2024 发表，实验验证了扩散生成式方法在位置推荐场景中的有效性，同时探索了端侧推理的可行路径。

INSIGHT扩散模型作为生成式推荐的新范式正在获得关注——相比自回归生成，扩散方法在处理连续空间表示和多样性生成方面具有天然优势。云-边-端协作架构的思路对搜索推荐系统的端侧个性化有启发意义：将计算密集的扩散训练放在云端，轻量推理部署到边缘，既保护用户隐私又降低延迟。

Auditing Textual Context in Sequence-Aware Explainable Recommendation

已录用 WWW 2026

WWW 2026 论文，研究序列感知可解释推荐系统中文本上下文的审计方法。分析在序列推荐模型中引入文本信息（如商品描述、评论）后对推荐解释质量的影响，评估文本上下文是否真正提升了推荐的可解释性和准确性，并提出审计框架以量化文本贡献。

INSIGHT在当前 LLM 大量引入文本信息做推荐的趋势下，本文提供了一个重要的「sanity check」视角：并非所有文本上下文都能有效提升推荐质量，需要系统化的审计方法来判断哪些文本信号真正有贡献。这对搜索推荐系统选择性地引入 UGC 文本特征（帖子内容、评论）具有方法论指导意义。
