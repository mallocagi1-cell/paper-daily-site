vstash: Local-First Hybrid Retrieval with Adaptive Fusion for LLM Agents

本文提出 vstash，一个本地优先的文档记忆系统，将向量相似搜索与全文关键词匹配通过 Reciprocal Rank Fusion (RRF) 和自适应 per-query IDF 加权进行融合。系统基于单个 SQLite 文件实现（sqlite-vec + FTS5）。核心贡献是通过混合检索分歧信号进行自监督 embedding 微调：在 753 个 BEIR 查询上，74.5% 的查询在向量重和 FTS 重配置间产生 top-10 排序分歧，利用这些分歧三元组微调 BGE-small (33M) 后，在 NFCorpus 上 NDCG@10 提升高达 +19.5%。

Rethinking the Necessity of Adaptive Retrieval-Augmented Generation through the Lens of Adaptive Listwise Ranking

提出 AdaRankLLM，一个自适应检索排序框架。通过 zero-shot prompt + passage dropout 机制实现自适应 listwise 排序，能动态判断是否需要检索补充段落。为使小型开源 LLM 具备精确的列表排序和自适应过滤能力，引入两阶段渐进式蒸馏范式（数据采样+增强技术）。在 3 个数据集和 8 个模型上的大规模实验验证了方法的有效性。

INSIGHT随着 LLM 对噪声的鲁棒性不断增强，自适应检索的必要性需要重新评估。passage dropout 机制通过随机丢弃候选段落来训练排序器判断哪些文档真正有用，这一思路可直接应用于搜索重排序场景：在 UGC 搜索中，许多召回结果表面相关但实际无用，自适应过滤可显著提升精确度。两阶段蒸馏为部署小模型排序器提供了可行路径。

Jun Feng, Jiahui Tang, Zhicheng He, Hang Lv, Hongchao Gu, Hao Wang, Xuezhi Yang, Shuai Fang

Powering Job Search at Scale: LLM-Enhanced Query Understanding in Job Matching Systems

提出一个基于大语言模型的统一查询理解框架，专为大规模职位搜索场景设计。该框架解决了传统查询理解方法的局限性，包括短文本歧义消解、用户意图识别和 query-job 语义匹配。系统已在工业级搜索引擎中部署，处理大规模实时查询流量。

INSIGHTLLM 增强的查询理解不仅提供更准确的意图分类，还能统一处理 query 扩展、纠错和语义标注等多个子任务。这对 UGC 搜索高度适用：社区搜索中用户 query 通常极短（2-4 词）且充满口语化表达，统一 LLM 查询理解可一步到位解决 query 归一化、意图分类和扩展问题。工业部署经验表明在线延迟可控。

Ping Liu, Jianqiang Shen, Qianqi Shen, Chunnan Yao, Kevin Kao, Dan Xu, Rajat Arora, Baofen Zheng 等 12 人

BioHiCL: Hierarchical Multi-Label Contrastive Learning for Biomedical Retrieval with MeSH Labels

提出 BioHiCL，利用层次化 MeSH 标注为多标签对比学习提供结构化监督信号，训练生物医学检索模型。相比粗粒度的二元相关性信号，层次化标签能捕捉文档间的语义重叠程度。发布 BioHiCL-Base (0.1B) 和 BioHiCL-Large (0.3B) 两个模型，在生物医学检索、句子相似度和问答任务上取得优异表现，同时保持部署效率。

INSIGHT层次化标签体系可作为对比学习的天然监督信号，解决了传统检索训练中 hard negative 采样困难的问题。UGC 社区通常有丰富的标签/分类体系（如话题标签、板块分类），可直接借鉴这种层次化多标签对比学习方法来训练更精确的 embedding 模型。0.1B 参数量即可获得良好效果，部署成本可控。

Mengfei Lan, Lecheng Zheng, Halil Kilicoglu

UsefulBench: Towards Decision-Useful Information as a Target for Information Retrieval

引入 UsefulBench 数据集，由三位专业分析师标注文本对查询的「相关性」与「实用性」。研究发现传统基于相似度的检索方法更偏向相关性（如巴黎在法国），但不一定有用（如回答巴黎是否比柏林大）。LLM 系统可部分纠正这一偏差，但在需要领域专业知识的场景中仍有局限。

INSIGHT「相关但无用」是搜索系统的核心痛点之一，尤其在 UGC 场景中：大量帖子在语义上与 query 相关，但对用户实际需求无帮助。本文提出的 relevance vs. usefulness 区分为优化搜索排序提供了新视角——排序目标不应仅是语义匹配度，而应考虑对用户决策的实际价值。这为 nDCG 标注指南的优化提供了理论支撑。

Tobias Schimanski, Stefanie Lewandowski, Christian Woerle, Nicola Reichenau, Yauheni Huryn 等 6 人

OverCite: Add citations in LaTeX without leaving the editor

OverCite 是一个开源轻量工具，通过利用粗略的引用占位符和局部句子上下文来查询 ADS/SciX 索引文献库，对可能匹配进行排序，并直接在编辑器中插入引用。支持 Overleaf 和 VS Code 两种环境。覆盖天文、物理、计算机科学、数学、生物学及所有 arXiv 预印本。

INSIGHTOverCite 展示了一种实用的上下文感知检索模式：不是让用户构造显式查询，而是从写作上下文自动推断检索需求。这种 implicit query 生成思路可迁移到 UGC 搜索场景——基于用户当前浏览内容自动推荐相关帖子。检索排序基于局部上下文语义匹配，无需用户主动搜索。

Cheyanne Shariat

Comparative Analysis of Neural Retriever-Reranker Pipelines for Retrieval-Augmented Generation over Knowledge Graphs in E-commerce Applications

系统对比了三种检索-重排序管线配置（FRWSR/FRMR/BARMR），分别集成 dense 或 sparse 检索策略与 cross-encoder 重排序，评估其在电商知识图谱 RAG 场景中的效果。研究发现不同配置在精确度和召回率上各有权衡，为实际系统的管线选择提供了定量依据。

INSIGHT电商搜索中检索管线的架构选择（dense vs sparse 第一阶段 + cross-encoder 重排序）对最终效果影响巨大。本文的实验对比为 UGC 搜索系统的管线设计提供了直接参考：当内容偏结构化时 sparse 召回更优，当语义理解要求高时 dense 方案占优。cross-encoder 重排序在所有配置中都带来显著提升，验证了多阶段管线的价值。

Teri Rumble, Zbyněk Gazdík, Javad Zarrin, Jagdeep Ahluwalia

JFinTEB: Japanese Financial Text Embedding Benchmark

发布首个专为日语金融文本 embedding 评测设计的综合基准 JFinTEB。包含检索和分类两大类任务，反映真实金融文本处理场景。对多种 embedding 模型进行广泛评测，包括不同规模的日语专用模型、多语言模型和商业 embedding 服务。数据集和评测框架已公开发布。

INSIGHT构建领域特定的 embedding 评测基准对于选型决策至关重要。UGC 搜索同样面临通用 embedding 模型在特定领域（如游戏、二次元、方言）表现不佳的问题。本文的评测方法论——涵盖检索和分类两种下游任务、对比不同规模和类型的模型——可直接复用来构建中文 UGC embedding 评测集。

Masahiro Suzuki, Hiroki Sakaji

SIMMER: Cross-Modal Food Image--Recipe Retrieval via MLLM-Based Embedding

提出 SIMMER 方法，将多模态大语言模型 (MLLM) 的 VLM2Vec 直接用于跨模态检索，以单一统一编码器替代传统的双编码器架构。针对食谱的结构化特点（标题、食材、步骤）设计专用 prompt 模板，并引入组件级检索策略来处理食谱的多元素结构。

INSIGHT用统一 MLLM 取代传统双编码器是跨模态检索的新范式。UGC 内容天然具有多模态属性（图文帖子），传统方案需要独立训练图像和文本编码器再做对齐。SIMMER 表明 VLM2Vec 等 MLLM embedding 可以直接处理多模态输入，简化系统架构。结构化 prompt 设计（如按标题/正文/标签拆分）值得借鉴。

Keisuke Gomi, Keiji Yanai

WARBERT: A Hierarchical BERT-based Model for Web API Recommendation

提出 WARBERT，一个基于 BERT 的层次化语义匹配模型，用于大规模 Web API 推荐。通过双组件特征融合和注意力机制构建精确的语义表示，WARBERT(R) 负责初始候选过滤，WARBERT(M) 负责精排。解决了 mashup-API 描述间的语义歧义问题和大规模仓库的计算效率问题。

INSIGHT层次化两阶段检索架构（粗筛+精排）结合注意力机制的设计模式具有通用性。该模型解决的核心问题——短文本间的语义歧义和大规模候选集的效率问题——与 UGC 搜索高度吻合。双组件特征融合可用于融合 query 和文档的不同粒度特征（词级、句级、篇章级），提升短文本匹配质量。

Zishuo Xu, Yuhong Gu, Dezhong Yao
