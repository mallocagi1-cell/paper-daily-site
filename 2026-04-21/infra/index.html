Quantization for Large Language Models: A Systematic Study (ICLR 2026)

该论文发表于 ICLR 2026，系统性研究了 LLM 后训练量化（PTQ）技术，首次在应用层、负载层、并行策略层和硬件层四个维度下评估量化对在线服务的影响。实验揭示了高度任务依赖和方法依赖的量化-精度权衡，以及量化与并行策略/GPU 架构之间的复杂交互效应。

Improving Reasoning Capabilities in Small Models through Mixture-of-Layers Distillation with Stepwise Attention on Key Information

针对 CoT 蒸馏中教师模型动态注意力迁移不足的问题，提出了一种结合 Mixture-of-Layers 模块的新型蒸馏框架。该方法将教师模型在推理过程中对关键信息的渐进注意力转移（stepwise attention shift）作为结构化指导信号传递给学生模型，使小模型能够学习到推理过程中信息聚焦的动态模式。

INSIGHT核心创新在于发现并利用了 LLM 推理时注意力向关键信息渐进聚焦的规律，将其转化为可迁移的蒸馏信号。Mixture-of-Layers 模块允许学生模型动态选择和组合不同层的表示。对搜推系统部署而言，该技术可将大模型的推理能力压缩到可在线服务的小模型中，显著降低推理成本同时保持复杂查询理解能力。

Yao Chen, Jiawei Sheng, Wenyuan Zhang, Tingwen Liu

Target-Oriented Pretraining Data Selection via Neuron-Activated Graph

提出 Neuron-Activated Graph Ranking (NAG-based Ranking)，一个免训练、可解释的目标导向预训练数据选择框架。通过量化 LLM 中各层高影响力神经元，构建紧凑的 Neuron-Activated Graph (NAG)，然后按 NAG 相似度对候选数据排序。在六个基准上，该方法平均提升目标导向预训练效果 4.9%，在 HellaSwag 上超出 SOTA 基线 5.3%。

INSIGHT该方法的核心价值在于将数据选择从黑盒表征匹配转变为可解释的神经元激活图匹配，且无需额外训练。对搜索/推荐团队训练领域模型极具参考价值：可用该方法从大规模语料中精选与搜索场景最相关的数据子集进行 continual pretraining，以较低成本获得领域专家模型。

Zijun Wang, Haoqin Tu, Weidong Zhou, Yiyang Zhou, Xiaohuan Zhou, Bingni Zhang, Weiguo Feng 等 10 人

Learning Uncertainty from Sequential Internal Dispersion in Large Language Models

提出 SIVR（Sequential Internal Variance Representation），一个监督式幻觉检测框架。不同于现有方法对隐藏状态演化做出严格假设，SIVR 采用更基础的假设——不确定性体现为内部表示跨层的离散度/方差，并聚合全序列 token 方差特征学习事实错误的时序模式，兼具模型无关和任务无关特性。

INSIGHT该方法突破了现有幻觉检测方法对层间隐藏状态须符合特定演化模式的限制，仅依赖方差统计量即可工作。对搜索系统的实践价值：可作为 LLM 生成答案的在线质量监控模块，当检测到高不确定性时触发回退到传统检索结果。模型无关特性意味着可直接应用于任何在线服务的 LLM。

Ponhvoan Srey, Xiaobao Wu, Cong-Duy Nguyen, Anh Tuan Luu

Conditional Memory via Scalable Lookup: A New Axis of Sparsity for Large Language Models

提出条件内存（Conditional Memory）作为 LLM 的新稀疏性维度，与 MoE 的计算稀疏性互补。通过可扩展查找机制将知识存储在静态内存中按需检索，发现了 MoE 计算与静态内存之间的 U 形 Scaling Law：过少或过多的内存都不如最优配比。

INSIGHTU 形 Scaling Law 的发现对大模型架构设计有重要指导意义：不能简单地通过增大 MoE 专家数或增加内存来提升性能，需要找到计算与存储的最优平衡点。对搜索基建团队而言，该技术可用于设计更高效的知识密集型模型架构，在固定计算预算下通过条件内存扩展模型容量。

DALM: A Domain-Algebraic Language Model via Three-Phase Structured Generation

提出 DALM（Domain-Algebraic Language Model），用结构化去噪替代无约束的 token 生成。模型遵循三阶段生成路径：先解析域不确定性，再解析关系不确定性，最后解析概念不确定性，每阶段在显式代数约束下运行。该框架通过域格（domain lattice）从结构上防止跨域知识污染。

INSIGHTDALM 的核心贡献是从架构层面解决了 LLM 的跨域知识干扰问题。对搜索系统的启示：当 LLM 同时服务多个垂直领域（如电商搜索 vs 社区搜索）时，可借鉴域隔离思想避免不同场景知识相互干扰。三阶段结构化生成也为可控生成提供了新的技术路径。

Chao Li

Recursive Language Models

提出递归语言模型（RLMs），一种通用推理范式，将长提示视为外部环境的一部分，允许 LLM 递归调用自身处理提示片段。RLM-Qwen3-8B 在三个长上下文任务上平均性能提升 28.3%，接近 GPT-5 水平，证明递归调用可有效突破固定上下文窗口限制。

INSIGHT递归自调用范式为长文本处理提供了一种不依赖扩展上下文窗口的替代方案。对搜索基建的实践启示：可在 8K 上下文的小模型上实现等效的长文档理解能力，大幅降低 KV cache 内存需求。28.3% 的提升幅度表明该方案在长文检索场景（如多文档摘要、跨文档问答）中有显著工程价值。

Alex L. Zhang, Tim Kraska, Omar Khattab

Applied Explainability for Large Language Models: A Comparative Study

对三种 LLM 可解释性技术（Integrated Gradients、Attention Rollout、SHAP）在 DistilBERT/SST-2 上进行了系统性对比研究。结果表明梯度归因方法提供更稳定直观的解释，注意力方法计算高效但与预测特征对齐较差，模型无关方法灵活但计算成本高且变异性大。

INSIGHT该对比研究为工程团队选择 LLM 可解释性工具提供了实践指导：若需稳定可靠的归因用于调试排序模型，优先选择梯度方法；若关注推理延迟，Attention Rollout 是轻量替代。对搜索系统中模型迭代的启示：在模型开发环节引入可解释性工具可加速 bad case 分析和模型调优。

Venkata Abhinandan Kancharla
