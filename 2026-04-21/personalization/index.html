Multi-Epoch Learning with Data Augmentation for Deep Click-Through Rate Prediction

MEDA 提出首个通用可靠的深度 CTR 模型多轮训练策略。工业界 CTR 模型普遍面临多轮训练过拟合问题（样本重复暴露导致 embedding 层过拟合），现有方案需针对特定模型调参。MEDA 通过特征级数据增强和自适应正则化，在不同 CTR 模型架构（DeepFM、DCN、DIN 等）上均能稳定提升多轮训练效果，AUC 提升 0.3-0.8%。

Sample Is Feature: Beyond Item-Level, Toward Sample-Level Tokens for Unified Large Recommender Models

📖 深度解读 · 8 分钟 →

提出 Sample-Level Token 范式，突破工业推荐模型的两大瓶颈：样本信息扩展（通过更深更长行为序列丰富训练信号）和模型容量扩展（在单一 Transformer 骨干中统一序列建模与特征交互）。将每个训练样本的全部信息（用户特征、上下文、行为序列）统一编码为 token 序列，使 Transformer 自然处理跨模态交互。

INSIGHT关键创新在于打破 item-level token 的限制，将推荐模型从「每个 item 一个 token」提升到「每个样本一个 token 序列」。这使得模型能同时利用序列位置信息和特征交互信息，避免了传统方法中两个模块分离导致的信息损失。对搜索/推荐系统的启示：统一 Transformer 架构可替代「序列模型 + 特征交叉模型」的拼接方案。

What Makes LLMs Effective Sequential Recommenders? A Study on Preference Intensity and Temporal Context

系统研究 LLM 作为序列推荐器的有效性机制。发现现有偏好对齐方法多依赖二元配对比较，忽略了两个关键因素：偏好强度（用户对物品的喜好程度差异）和时间上下文（近期交互更能反映当前意图）。通过对比实验证明，引入偏好强度梯度和时间衰减机制可显著提升 LLM 推荐效果。

INSIGHT揭示了 LLM 推荐的核心改进方向：不是简单的「喜欢/不喜欢」二分法，而是建模偏好的连续强度和时间相关性。实践意义：在 UGC 搜索场景中，用户对内容的兴趣存在明显强度差异和时间衰减，该方法可直接用于 LLM-based 排序模型的偏好信号构建。

Beyond One-Size-Fits-All: Adaptive Test-Time Augmentation for Sequential Recommendation

提出自适应测试时增强（Adaptive TTA）方法解决序列推荐中的数据稀疏问题。现有 TTA 方法采用统一的、用户无关的增强策略，忽略了用户间巨大的行为异质性。论文设计了用户感知的增强策略选择器，根据用户行为模式自动选择最优增强方式，无需模型重训练即可提升推理精度。

INSIGHT核心洞察：不同用户需要不同的数据增强策略（活跃用户适合随机遮蔽，低频用户适合序列补全）。实践价值：作为即插即用模块，可在不修改已训练模型的前提下提升推荐效果，部署成本极低。对 UGC 搜索场景尤其适用——用户活跃度差异大，统一策略必然次优。

Learning Behaviorally Grounded Item Embeddings via Personalized Temporal Contexts

指出标准 Item2Vec 方法将用户历史视为无序集合（bag-of-items），隐含假设分钟级交互和月级交互具有同等语义关联性，从而抹平了用户行为的时间结构。提出基于个性化时间上下文的 item embedding 学习方法，区分短期偏好演变和长期兴趣变化，生成时间感知的 item 表征。

INSIGHT方法论创新：通过时间距离感知的上下文窗口动态调整 item 共现权重，近期共现 item 获得更强的语义关联信号。对推荐系统的实践启示：embedding 层是推荐系统的基石，时间感知 embedding 可直接替换现有 Item2Vec/Word2Vec 训练方式，对下游 CTR 模型和召回模型均有提升。

A Universal Framework for Compressing Embeddings in CTR Prediction

提出通用 embedding 压缩框架，解决 CTR 预估模型中 embedding table 超过 GPU 显存限制的核心工程问题。当 embedding table 过大需存储在 CPU 内存时，训练和推理速度显著下降。该框架通过统一的压缩策略（包括低秩分解、量化、哈希等）适配不同 CTR 模型架构。

INSIGHT工程实践价值高：工业级 CTR 模型的 embedding table 动辄数百 GB，GPU 显存放不下是普遍痛点。该框架的通用性意味着可在 DeepFM、DCN、DIN 等不同架构上即插即用，无需针对每个模型单独设计压缩方案。对大规模 UGC 搜索排序模型的 embedding 层优化有直接参考意义。

A multi-task heterogeneous graph learning with cross-attention fusion for robust recommendation

提出多任务异构图学习框架，通过 cross-attention 融合机制解决推荐系统中的数据稀疏、冷启动和多目标负迁移三大问题。利用异构图建模用户-物品-属性间的多类型关系，多任务学习架构自动平衡不同优化目标间的信息共享。

INSIGHT亮点在于同时处理冷启动和多目标冲突：cross-attention 机制让不同任务的图表征选择性地共享信息，避免负迁移。对多目标推荐场景（如同时优化 CTR 和 CVR）有参考价值，但图方法的在线推理延迟需要关注。

SRSUPM: Sequential Recommender System Based on User Psychological Motivation

从用户心理动机角度建模序列推荐。现有方法将近期行为压缩为单一向量并优化单一目标，缺乏对心理动机转移的显式建模。SRSUPM 引入动机分布建模，捕捉不同转移程度下的行为模式，利用协作信号增强动机推断。

INSIGHT新颖视角：将用户行为序列解读为心理动机的外在表现，通过建模动机转移概率预测下一步行为。对 UGC 搜索场景的启示：用户在社区中的浏览动机（信息获取、娱乐消遣、社交互动）可显式建模并用于个性化排序。

Mirroring Users: Towards Building Preference-aligned User Simulator with User Feedback in Recommendation

利用 LLM 构建偏好对齐的用户模拟器。推荐系统中用户模拟对离线评估和策略优化至关重要，但 LLM 缺乏推荐任务特定的对齐。该方法利用推荐系统中丰富的用户反馈数据训练 LLM 模拟器，使其行为模式与真实用户偏好分布一致。

INSIGHT解决了 LLM 用户模拟的核心问题：通用 LLM 不了解特定平台的用户偏好分布。通过 RLHF 式的反馈对齐训练，使模拟器能准确反映真实用户的点击、跳过、停留等行为模式。对推荐系统 A/B 测试替代方案和离线策略评估有实际价值。

Intent Propagation Contrastive Collaborative Filtering

提出意图传播对比协同过滤方法。现有解耦方法仅关注节点直接交互的局部结构特征，忽略了全局图结构信息，限制了意图解耦精度。同时对比学习中的随机增强可能破坏图语义结构。该方法通过意图传播机制在全局图上进行意图信号扩散，结合语义保持的对比学习策略。

INSIGHT改进了 GCN-based 协同过滤中的意图建模：从局部交互扩展到全局意图传播，使每个节点的意图表征融合了多跳邻居的意图信号。对实践的启示：意图解耦可用于搜索/推荐的多兴趣建模，但图方法的在线计算成本需权衡。
