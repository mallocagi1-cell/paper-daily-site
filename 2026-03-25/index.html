One Model, Two Markets: Bid-Aware Generative Recommendation

本文针对生成式推荐系统（如 TIGER）仅关注语义检索、忽略商业变现的问题，提出 GEM-Rec 统一框架。该框架引入控制 token 将「是否展示广告」与「展示哪个商品」解耦，并设计 Bid-Aware Decoding 机制在推理阶段注入实时出价信号，引导生成偏向高价值商品。实验表明 GEM-Rec 在保持推荐质量的同时显著提升广告收入。

Collaborative User Prompt for Personalized Generative Recommendation

UCL

针对现有生成式推荐方法依赖离散 ID prompt 或任务特定 soft prompt、忽略用户间协同信号的问题，本文提出基于注意力机制的组合式框架。通过融合相似用户的 embedding 构建个性化 soft prompt，动态强调共享兴趣的同时保留个体偏好。在三个真实数据集上的实验验证了该方法的有效性。

INSIGHT将协同过滤信号注入 LLM prompt 是弥合传统推荐与生成式推荐之间差距的关键一步。注意力融合机制可以直接应用于 UGC 搜索场景——为具有相似搜索行为的用户群构建 prompt，提升长尾 query 的个性化召回效果。该框架对冷启动用户也有潜在价值，可通过相似用户的 prompt 进行迁移。

Jerome Ramos, Bin Wu, Aldo Lipani

ReBOL: Retrieval via Bayesian Optimization with Batched LLM Relevance Observations and Query Reformulation

提出 ReBOL 框架，用 LLM 查询改写初始化多模态贝叶斯优化后验，再迭代获取文档批次进行 LLM 相关性评分和后验更新，从而突破传统 top-k 向量检索的召回上限。在 5 个 BEIR 数据集上使用 Gemini-2.5-Flash-Lite 和 GPT-5.2 评测，ReBOL 在召回率和 nDCG 上持续优于 LLM 重排基线。

INSIGHT将 LLM 相关性判断与贝叶斯优化结合是一种新颖的检索范式——不再局限于向量相似度 top-k，而是让 LLM 主动「探索」文档空间。对 UGC 搜索场景，这种方法特别适合处理复杂/模糊查询，通过多轮 LLM 评估逐步收敛到最相关的结果。但计算成本较高，更适合离线评估或高价值查询的精细化检索。

Anton Korikov, Scott Sanner

Query, Decompose, Compress: Structured Query Expansion for Efficient Multi-Hop Retrieval

针对 LLM 查询扩展在复杂多跳检索中引入噪声的问题，提出 DeCoR 框架。包含两个核心组件：Query Decomposition 将复杂查询分解为显式推理步骤，Query-aware Document Compression 从候选文档中提取与查询相关的精简证据。该结构化设计确保扩展后的查询表示既聚焦又完整。

INSIGHTDeCoR 的分解-压缩两阶段设计对 UGC 搜索中的复杂查询处理有直接启发：用户的搜索意图常隐含多个子需求，先分解再针对性检索可显著提升多意图查询的召回。Document Compression 组件可用于搜索结果摘要生成，为用户提供更精准的结果预览。

JungMin Yun, YoungBin Kim

Holistic Scaling Laws for Optimal Mixture-of-Experts Architecture Optimization

提出 MoE 架构全局优化的可复用框架，首先证明 FLOPs/token 不足以公平比较 MoE 模型，需联合约束 FLOPs、活跃参数和总参数三者。然后将 16 维架构搜索空间降维为两步低维优化问题，实现在有限实验预算下找到最优 MoE 配置。

INSIGHTMoE 架构的 scaling law 对生成式推荐系统的模型设计有重要参考价值——Meta HSTU 等大规模推荐模型已验证 scaling law 在推荐领域的适用性，本文提供的三约束框架（FLOPs、活跃参数、总参数）可直接用于优化推荐 MoE 模型的专家数量和容量配置，在固定推理预算下最大化模型效果。

Weilin Wan, Jingtao Han, Weizhong Zhang, Cheng Jin

AgenticGEO: A Self-Evolving Agentic System for Generative Engine Optimization

针对生成式搜索引擎（如 Perplexity、AI Overview）的优化问题，提出 AgenticGEO 自进化框架。将优化建模为内容条件控制问题，通过 agent 框架自适应调整内容策略以最大化在 LLM 生成摘要中的可见度和引用率。克服了现有方法依赖静态启发式或单次 prompt 优化的局限。

INSIGHT生成式搜索引擎正在重塑 SEO 的范式——从传统的关键词排名优化转向在 LLM 生成内容中的「引用率」优化。对 UGC 搜索平台而言，理解 GEO 机制有助于：(1) 设计更好的内容质量信号来指导生成式搜索结果；(2) 防范低质内容通过 GEO 策略操纵排名。这是生成式搜索生态的重要研究方向。

Jiaqi Yuan, Jialu Wang, Zihan Wang, Qingyun Sun, Ruijie Wang, Jianxin Li

Overview of TREC 2025 Biomedical Generative Retrieval (BioGen) Track

TREC 2025 生物医学生成式检索评测赛道概述，关注 LLM 在高风险领域生成检索结果时的幻觉问题。评测框架涵盖生成内容的事实准确性、来源可验证性和完整性，为生成式检索系统提供了标准化评估方法论。

INSIGHT生成式检索的评估方法论对搜索系统至关重要——传统指标（nDCG、MAP）无法衡量生成内容的事实准确性。BioGen Track 提出的评估框架（可验证性+完整性+准确性）可迁移至 UGC 搜索场景，用于评估 LLM 生成的搜索摘要是否忠实反映原始 UGC 内容。

Deepak Gupta, Dina Demner-Fushman, William Hersh, Steven Bedrick, Kirk Roberts
