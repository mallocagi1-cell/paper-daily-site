TagLLM: A Fine-Grained Tag Generation Approach for Note Recommendation

针对电商社区笔记推荐中 LLM 生成能力未被充分利用的问题，提出 TagLLM 框架，通过用户兴趣手册和多模态 Chain-of-Thought 提取生成细粒度标签，并用知识蒸馏技术提升推理效率。线上 A/B 测试显示，人均浏览时长提升 0.31%，人均互动次数提升 0.96%，冷启动场景下页面浏览点击率提升 32.37%。

MI-DPG: Decomposable Parameter Generation Network Based on Mutual Information for Multi-Scenario Recommendation

📖 深度解读 · 6 分钟 →

针对多场景推荐中模型参数成本高且场景多样性建模困难的问题，提出基于互信息的可分解参数生成网络 MI-DPG。核心思路是将加权矩阵分解为场景共享和场景特有的低秩矩阵组合，并通过互信息正则化增强跨场景参数多样性。在三个真实数据集上显著优于已有多场景推荐方法，论文发表于 CIKM 2023。

INSIGHT低秩分解 + 互信息正则化是一个优雅的多场景参数共享方案：共享矩阵捕捉跨场景通用模式，场景特有矩阵以极低参数成本建模差异性。对于运营多个搜索/推荐场景的平台（如主搜、发现页、相关推荐），可用该思路统一模型架构并通过场景条件生成差异化参数，避免为每个场景维护独立模型。

Optimizing Feature Extraction for On-device Model Inference with User Behavior Sequences

揭示端侧 ML 推理中被忽视的性能瓶颈——从原始应用日志提取特征的延迟。提出 AutoFeature 引擎，通过 DAG 抽象特征提取工作流、图优化融合冗余操作、高效缓存重叠数据三项机制加速端侧特征提取。在搜索、视频、电商等五个工业移动服务上验证，端到端延迟降低 1.33x–3.93x（白天）和 1.43x–4.53x（夜间）。

INSIGHT端侧推理的瓶颈往往不在模型计算本身，而在特征提取环节。AutoFeature 的核心启示是：将特征提取流程建模为 DAG 并做图级优化（算子融合、缓存复用），可获得远超模型压缩的实际延迟收益。对于依赖用户行为序列做实时排序的移动搜索/推荐系统，优化特征提取管线是低成本高回报的优化方向。

Chen Gong, Zhenzhe Zheng, Yiliu Chen, Sheng Wang, Fan Wu, Guihai Chen

TF4CTR: Twin Focus Framework for CTR Prediction via Adaptive Sample Differentiation

针对现有 CTR 模型对样本无差别处理的局限，提出 Twin Focus 框架，包含 Twin Focus Loss、样本选择 Embedding 模块和动态融合模块三个组件。核心思路是自适应区分简单/复杂样本，为不同样本分配更合适的编码器并提供定制化监督信号。在 5 个真实数据集上验证，可作为即插即用模块增强多种 CTR 基线模型，已被 IEEE TCSS 接收。

INSIGHT样本差异化处理是 CTR 模型一个被低估的优化方向。TF4CTR 的模型无关设计使其可直接集成到现有 CTR pipeline 中：为简单样本和复杂样本分别匹配编码器和损失函数，避免统一训练目标对不同难度样本的次优处理。对于已有成熟 CTR 模型的团队，这种即插即用的提升方式实施成本低且风险可控。

Honghao Li, Qiuze Ru, Yiwen Zhang, Yi Zhang, Lei Sang, Yun Yang

PreferRec: Learning and Transferring Pareto Preferences for Multi-objective Re-ranking

针对多目标重排中静态权重无法捕捉用户意图级偏好的问题，提出 PreferRec 框架，将用户对准确性、多样性、公平性等目标的偏好建模为 Pareto 最优权衡，而非手工设定的固定权重。通过 Preference-Aware Pareto Learning 捕捉个体偏好，并通过 Knowledge-Guided Transfer 在相似用户间迁移优化模式，提升个性化多目标重排效果。

INSIGHT从静态权重到用户级 Pareto 偏好学习是多目标重排的关键升级方向。PreferRec 的核心洞察在于：不同用户对准确性 vs 多样性的权衡存在本质差异，在意图级建模这种差异比在 item 级优化聚合目标更有效。跨用户偏好迁移机制进一步降低了冷启动用户的偏好估计难度，适合搜索/推荐场景中需要平衡多个业务指标的重排模块。

AgenticRec: End-to-End Tool-Integrated Policy Optimization for Ranking-Oriented Recommender Agents

针对 LLM 推荐 Agent 中间推理与最终排序反馈脱节的问题，提出 AgenticRec 框架，端到端优化决策轨迹（包括中间推理、工具调用和最终排序列表生成）。核心技术包括：推荐专用工具集成到 ReAct 循环实现证据驱动推理、List-Wise GRPO 提升排序效用和信用分配、Progressive Preference Refinement 通过硬负例挖掘和双向偏好对齐捕捉细粒度偏好。

INSIGHTAgenticRec 将推荐从 "LLM 直接输出排序" 升级为 "LLM 通过工具调用收集证据再排序" 的范式，list-wise GRPO 解决了传统 pointwise 优化无法捕捉列表级排序质量的问题。对于探索 LLM-based 推荐的团队，这提供了一个可参考的架构模式：将推荐专用工具（如用户画像查询、物品特征检索）集成到 Agent 推理循环中，比纯 prompt 方式更可靠。

Gated Rotary-Enhanced Linear Attention with Rank Modulation for Long-term Sequential Recommendation

针对 Transformer 序列推荐在长用户行为序列上的二次复杂度瓶颈，提出 RecGRELA 模型。核心方法包括：基于旋转位置编码的线性注意力模块降低计算复杂度，以及自适应秩调节器（Adaptive Rank Modulator）通过秩增强和门控选择机制平衡稳定长期偏好与短暂短期兴趣。在四个基准数据集上取得 SOTA，优于 RNN、Transformer 和 Mamba 等基线，且内存开销低。

INSIGHT线性注意力 + 旋转位置编码是处理长序列推荐的高效组合，避免了标准 Transformer 的二次复杂度。秩调节器的设计思路值得借鉴：通过控制注意力矩阵的秩来区分长期稳定偏好和短期瞬时兴趣，这比简单的时间衰减或滑动窗口更精细。对于用户行为序列较长的搜索/推荐场景，该方法可在保持建模能力的同时显著降低推理成本。

Do LLMs Understand Collaborative Signals? Diagnosis and Repair

系统诊断 LLM 能否有效理解和推理用户-物品交互矩阵中的协同信号。研究发现，当协同信息以清晰易解析的格式呈现并配合推理提示时，LLM 可超越矩阵分解等传统方法。提出基于 RAG 的修复方案，设计四种提示策略增强 LLM 对协同信号的推理能力，性能随提供信息量的增加普遍提升。

INSIGHT该研究回答了 LLM-based 推荐的一个基础问题：LLM 并非天然理解协同过滤信号，但通过恰当的信息格式化和 RAG 增强可弥补这一短板。核心启示是：将用户-物品交互数据转换为 LLM 友好的结构化文本格式，比直接将交互矩阵塞入 prompt 更有效。对于尝试 LLM 推荐的团队，信息呈现方式的优化可能比模型选择更重要。

Shahrooz Pouryousef, Ali Montazeralghaem

User Preference Modeling for Conversational LLM Agents: Weak Rewards from Retrieval-Augmented Interaction

针对 LLM 对话 Agent 缺乏持久用户模型导致用户需反复声明偏好的问题，提出 VARS（Vector-Adapted Retrieval Scoring）框架。用长期和短期双向量在共享偏好空间中表示用户，通过弱标量奖励在线更新，无需逐用户微调即可实现个性化。在 MultiSessionCollab 数学和代码任务上，匹配强基线的任务成功率同时降低超时率和用户负担。

INSIGHTVARS 的双向量设计（长期偏好 + 短期适应）提供了一种轻量级用户建模范式：不修改 LLM 参数，仅通过检索偏好空间中的向量偏移实现个性化。长期向量捕捉跨用户共性偏好、短期向量捕捉会话级适应的分离设计，可迁移到搜索/推荐的用户画像构建中，特别适合需要跨 session 记忆用户偏好但又不想维护重模型的场景。

Yuren Hao, Shuhaib Mehri, ChengXiang Zhai, Dilek Hakkani-Tür

LSA: A Long-Short-term Aspect Interest Transformer for Aspect-Based Recommendation

针对已有基于方面（aspect）的推荐方法忽略用户兴趣动态变化的问题，提出 LSA 模型，结合长期和短期方面兴趣建模。短期兴趣捕捉近期方面重要性的时序变化，长期兴趣反映包含非近期交互方面的广泛行为模式，两者融合为用户-物品交互分配精确的方面权重。在四个真实数据集上平均 MSE 提升 2.55%。

INSIGHT将评论中的方面（如价格、质量、外观）作为用户兴趣的细粒度载体，并区分长短期动态，是提升推荐解释性和精度的有效路径。对于 UGC 社区场景，帖子和评论天然包含丰富的方面信息，可借鉴 LSA 的思路从用户评论历史中提取方面级兴趣信号，用于改善内容理解和个性化排序。

Le Liu, Junrui Liu, Yunhan Gao, Ziheng Wang, Tong Li
