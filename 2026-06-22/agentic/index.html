Configurable Clinical Information Extraction with Agentic RAG: What Works, What Breaks, and Why

论文部署 ACIE（Agentic Clinical Information Extraction），一套在德国 University Medicine Essen 本地落地的 agentic RAG 系统，针对患者上下文跨数百份异构文档、文档级元数据缺失的场景。标准 RAG 在时间推理、跨文档依赖、元数据缺失上失效；ACIE 让 agent 在完整患者上下文上推理，并把每个答案锚定到来源段落供医生核验。在淋巴瘤登记回顾研究里，核医学医生对 7,326 条抽取逐条核验，整体接受率 96.5%，各类型接受率介于 80%–99%。

REVES: REvision and VErification--Augmented Training for Test-Time Scaling

REVES 提出“修订+验证”增强的训练框架用于 test-time scaling。标准后训练只优化单次目标，与多步推理动态不匹配；已有多轮 RL 直接在多步轨迹上优化，浪费了中间步里“差一点对”（near-miss）的可学信号。REVES 两阶段交替：在线数据/prompt 增强 + 策略优化，把成功恢复轨迹里的中间步拆成解耦的修订 prompt 与验证 prompt。在 LiveCodeBench 上以公开测试用例为反馈，比 RL 基线 +6.5 分、比标准多轮训练 +4.0 分；circle packing 上用 4B 小模型匹配 SOTA、rollout 远少于更大的进化搜索系统。代码已开源。

INSIGHT核心是把“改对答案”和“识别错误”两种能力解耦成独立训练信号，从恢复轨迹挖掘 near-miss 中间步，避免长程多轮采样的算力开销。对搜索/推理系统的启示：test-time 反复修订时，验证器与修订器可分开训练、各喂针对性数据，比端到端多轮 RL 更省 rollout。4B 模型即可复现、代码开源，落地门槛低。

Yuanxin Liu, Ruida Zhou, Xinyan Zhao, Amr Sharaf, Hongzhou Lin, Arijit Biswas

STARE: Surprisal-Guided Token-Level Advantage Reweighting for Policy Entropy Stability

STARE 针对 GRPO 类可验证奖励 RL 在 LLM 后训练中常见的策略熵坍缩。作者对 GRPO 下 token 级熵动态做一阶梯度分析，发现 token 级信用分配错配：每 token 熵变可分解为轨迹级 advantage 与下一 token 分布熵敏感度的乘积，形成 advantage-surprisal 四象限结构与近临界性。STARE 用 batch 内 surprisal 分位数挑出熵关键 token 子集、选择性重加权其有效 advantage，并加目标熵闭环 gate 稳定调控。在 1.5B–32B、Short/Long CoT 与 Multi-Turn Tool Use 三类任务上稳定训练数千步；AIME24/25 比 DAPO 等基线平均准确率 +4%–8%，反思 token 与回复长度同步增长。代码已开源。

INSIGHT把熵坍缩归因到 token 级信用分配错配、而不是简单加熵正则，这一诊断角度有价值。用 surprisal 分位数挑熵关键 token + 目标熵 gate 的做法，给搜索/推理类 agentic RL 训练提供了稳定数千步的实操方案，尤其覆盖 Multi-Turn Tool Use。1.5B–32B 全尺度验证、代码开源，自建 RL 训练 pipeline 的团队可直接接入 GRPO。

Haipeng Luo, Qingfeng Sun, Songli Wu, Can Xu, Wenfeng Deng, Han Hu

Context-Aware RL for Agentic and Multimodal LLMs

PPrinceton

论文提出 ContextRL，针对 LLM 在长/复杂上下文里难以定位关键证据（如工具轨迹里某一行、图像里某个细节）的失败模式。不是只监督最终答案，而是给模型一个 query、一个 answer 和两段高度相似的上下文，奖励它选出支持该 query-answer 对的那段，逼出细粒度 grounding。对编码 agent 用轨迹作上下文（条件过滤构造 1k 对），对多模态用图像作上下文（生成式编辑+相似检索构造 7K 对）。5 个长程基准上比标准 GRPO 平均 +2.2%，12 个 VQA 上 +1.8%。把同样对比上下文当普通样本的数据增强基线几乎无提升，说明增益来自上下文选择目标本身。

INSIGHT用“从两段相似上下文里选对的那段”作为辅助 RL 目标来强化证据 grounding，是可迁移到检索/RAG 的思路：对搜索 agent 可把工具轨迹或候选文档构造成对比对，奖励模型锁定真正支撑答案的证据。消融证明增益来自目标而非额外数据，这一对照设计值得借鉴——避免把方法收益误归因到数据扩充。

Peiyang Xu, Bangzheng Li, Sijia Liu, Karthik R. Narasimhan, Pramod Viswanath, Prateek Mittal

FAPO: Fully Autonomous Prompt Optimization of Multi-Step LLM Pipelines

Cisco

FAPO（Fully Autonomous Prompt Optimization）让 Claude Code 在标准化代码库里自动优化多步 LLM pipeline。多步 pipeline 的失败常来自检索、推理、格式化各步之间的交互，纯 prompt 优化会漏掉链路瓶颈。FAPO 评估 pipeline、检查中间步、诊断失败、提出有界改动并反复验证；先试 prompt 编辑，只有归因发现结构性瓶颈、prompt 优化不够时才改链路结构。在 6 个基准、3 个任务模型上，15/18 对比胜过基线 GEPA、平均 +14.1pp；升级到结构改动的 6 个 HoVer/IFBench 对比全胜、平均 +33.8pp；安全任务 CTIBench-RCM 上也有 +2.0~+7.1pp 提升。

INSIGHT把 prompt 优化升级为“先改 prompt、归因到结构瓶颈再改链路结构”的自治优化 agent，是多步 RAG/搜索 pipeline 调优的实用范式。亮点是用归因决定何时从 prompt 层跳到结构层，而不是一上来就重写链路。依赖 Claude Code 这类编码 agent 作执行器，已有 agent pipeline 的团队可复用其评估-诊断-验证循环来自动找瓶颈。

Paul Kassianik, Baturay Saglam, Huaibo Zhao, Blaine Nelson, Supriti Vijay, Aman Priyanshu

LegalHalluLens: Typed Hallucination Auditing and Calibrated Multi-Agent Debate for Trustworthy Legal AI

LegalHalluLens 是面向法律 AI 的幻觉审计框架，含三部分：在 CUAD 上按数值/时间/义务-权利/事实四类法律动机类别构建分型幻觉画像；提出 Risk Direction Index (RDI) 把“遗漏 vs 编造”偏向压成一个可跨部署比较的标量；以及一条按幅度与方向校准的分型多 agent 辩论流水线。在 510 份合同、249,252 个条款级实例上，测得义务/数值类与时间类幻觉之间约 38–40pp 的模型内差距（被聚合指标掩盖），并显示两个同为 52% 幻觉率的系统可有相反的 RDI。辩论流水线把编造性误检降低 45%，用 4B active 参数即匹配商用 API。

INSIGHT聚合幻觉率会掩盖错误在哪类、朝哪个方向；分型画像 + RDI 把它拆成可操作信号，再用测得的失败模式校准多 agent 辩论（Skeptic 质询 + 非对称 gate），比泛化调参的辩论更有效。对搜索/问答里的可信生成有借鉴：先按类别量化幻觉方向、再针对性上多 agent 校验，而不是一刀切。4B backbone 即达商用 API 水平，部署成本可控。

Lalit Yadav, Akshaj Gurugubelli

Think Again or Think Longer? Selective Verification for Budget-Aware Reasoning

SEVRA（Selective Verification for Reasoning Allocation）把 test-time 推理当作部署期算力分配问题：额外推理不一定有用，可能修好失败、也可能在已对的答案上浪费算力或引入有害改动。它是 serving 层控制器，用 serving 可见的尝试状态训练“可恢复性感知”门控，决定保留冻结 solver 的初始答案还是触发主动验证。用冻结 Qwen3-4B，在 MATH 上达 76.3%（始终验证 75.5%），生成后 token 降 26.8%，有害翻转从 2.2% 降到 1.0%；迁移到 GSM 只验证 3.0% 样本，准确率 93.4%→94.5%，验证 token 省 91.2%。作者也诚实指出：调大初始解算预算（8192 token）能用更少总 token 达到相近准确率。

INSIGHT把“是否再推理”建模为 serving 期分配决策、而非再训一个验证器，给在线推理成本控制提供了实用旋钮。最值得借鉴的是其诚实结论：先调初始解算预算，再在需要显式检查、有界重试、可审计或回归风险控制时才用选择性恢复。门控基于 serving 可见状态、用冻结 solver，落地改造小，适合搜索问答的延迟/成本敏感链路。

Sajib Acharjee Dip, Dawei Zhou, Liqing Zhang

LedgerAgent: Structured State for Policy-Adherent Tool-Calling Agents

LedgerAgent 面向客服域里需跨轮维护任务状态、调用工具并遵守域策略的 tool-calling agent。标准 agent 不单独表示任务状态，把观测、工具返回、策略指令都堆在 prompt 里，让 agent 每次重新从 prompt 重建状态，导致两类失败：取对了事实却在后续基于过期/缺失/错误信息决策；语法合法的工具调用仍违反依赖当前状态的域策略。LedgerAgent 是推理期方法，把观测到的任务状态维护在独立 ledger 并渲染进 prompt，同时在执行改变环境的工具调用前用 ledger 校验状态相关策略约束、拦截违规。在 4 个客服域、开源+闭源混合模型上，平均 passk 优于标准 prompt 式 tool-calling，在更严格的多次一致性指标上提升最大。

INSIGHT把隐式的状态管理外化成显式 ledger、并在工具调用前做状态相关的策略校验，是给多轮 tool-calling agent 加可靠性的低成本设计。对社区搜索里的对话式/工具调用 agent 有直接借鉴：用独立状态账本避免“取对事实又用错”，并把策略约束做成执行前的硬 gate。纯推理期方法、不需重训，开源闭源模型都适用，落地门槛低。

Md Nayem Uddin, Amir Saeidi, Eduardo Blanco, Chitta Baral

RODS: Reward-Driven Online Data Synthesis for Multi-Turn Tool-Use Agents

RODS（Reward-driven Online Data Synthesis）解决多轮 tool-use RL 中静态数据集“有信息量样本快速枯竭”的瓶颈。作者发现 GRPO 的梯度信号集中在 rollout 奖励方差最大的任务上（Popoviciu 上界的后果），即处于 agent 能力边界、成败各半的样本贡献了过大的策略梯度；随训练推进边界不断移动，静态数据里的有效样本逐渐耗尽。RODS 把进度奖励方差当作零成本边界探测器（无需训练 rollout 之外的额外推理），持续识别边界样本，按其结构复杂度（API 拓扑、依赖深度）经技能对齐重采样合成新多轮变体，并维护与策略共演化的动态回放缓冲。从 400 条人工种子、约 800 活跃池出发，以约 1/20 的轨迹量达到 17K 离线 pipeline 的相当性能。

INSIGHT用奖励方差做“能力边界探测器”来在线合成训练数据，是数据高效 agentic RL 的巧思——复用训练已算的 rollout、零额外推理成本。对自建多轮 tool-use agent 的团队有借鉴：与其堆大规模离线轨迹，不如围绕能力边界动态合成结构匹配的新样本，约 20x 省轨迹。需具备多轮工具环境与 RL 训练设施，工程量中等。

Ruishan Fang, Siyuan Lu, Chenyi Zhuang, Tao Lin

SciOrch: Learning to Orchestrate Expert LLMs for Solving Frontier Multimodal Scientific Reasoning Tasks

SciOrch 训练一个轻量 8B 模型来编排多个前沿商用 LLM 解科学推理题。观察到不同前沿模型在不同题型上各有所长、单模型评测会掩盖这种互补性。编排器把每题分解、通过 API 把子问题分派给选定的商用模型、再合成最终答案。训练这种编排器比常规 agentic RL 更难：每个动作触发昂贵且高延迟的 API 调用，标准在线 rollout 不可行；作者用基于 MCTS 的方法生成多样编排轨迹、抽取每节点单轮样本、再用 GRPO 式训练优化。在 SGI-Reasoning 与 Scientists' First Exam 共 240 题上达 56.66% 平均准确率，比最强单一商用模型高 3.74%、比最强多 agent 基线高 3.33%，且 API 成本不到典型多 agent 方法的一半。

INSIGHT用一个 8B 小模型做“路由+分解+合成”的编排器、把昂贵 API 动作交给前沿模型，是成本可控的多模型协同范式。针对 API 动作贵、在线 rollout 不可行的难点，用 MCTS 离线生成轨迹 + 单轮样本 + GRPO 训练，是可迁移的训练技巧。对搜索系统里混用多模型/多专家的场景有借鉴：训练轻量编排器按题型路由，比堆多 agent 更省成本（不到一半 API 开销）。

Jingru Guo, Xiangyuan Xue, Lian Zhang, Wanghan Xu, Siki Chen, Philip Torr
