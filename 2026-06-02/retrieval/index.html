Graph-GRPO: Dependency-Aware Credit Assignment for Generative E-commerce Search Relevance

针对电商搜索相关性建模，论文把 LLM 的相关性判断建成 query 理解→商品理解→facet 匹配的 CoT 推理并用 RL 优化。现有 GRPO 只有 outcome-level 奖励、把整条推理链当成单一优化单元，难以区分错误步骤；Graph-GRPO 将 CoT 各步建为节点、逻辑依赖建为边，把结果奖励沿依赖图传播得到 step-level 信用，再用主损失驱动的控制器自适应调整边上传播系数，并配合 CoT 随机掩码做 SFT 初始化和基于图节点的多头蒸馏，相关性分类指标与线上互动指标均提升。

Inference-Free Multimodal Learned Sparse Retrieval for Production-Scale Visual Document Search

NAVERSeoul National University

面向 arXiv/企业 PDF 等视觉文档的生产级检索，论文提出 V-SPLADE——一种推理无关 (inference-free) 的多模态学习稀疏检索器：服务时不对 query 做神经编码，直接用倒排索引检索视觉文档。核心是 caption-gated token supervision，仅训练期用 VLM 生成的 caption 作词法线索激活检索相关的词表维度，解决视觉稀疏表示的 lexical grounding 问题。六个视觉文档检索基准上 NDCG@5 平均 +13.8pp（对同规模 dense 基线），较 OCR/caption-BM25 最高 +6.3pp；在 1870 万文档语料上 R@5 翻倍以上，score fusion 还能给现有检索器叠加 +2.4pp R@5。

INSIGHT训练期用 caption 监督、服务期纯稀疏倒排的设计，直接绕开了 dense 检索在大规模下的 query 编码延迟与成本。对社区/文档搜索基建有参考价值：SPLADE 系学习稀疏检索可继承 BM25 倒排工程栈，又拿到接近 dense 的效果，且能通过 score fusion 给现有召回器做增量增强。

NAVER Corp.; Seoul National University; Naver Labs Europe

03 4.10

MIMO: Multilingual Information Retrieval via Monolingual Objectives

Korea University

多语言信息检索 (MLIR) 中 query 与相关文档可能语言不同，现有 embedding 多为 multi-monolingual 优化，直接套对比学习会加剧语言聚类，并在跨语对齐与 embedding uniformity 间产生权衡。MIMO 用高性能教师模型的稳定英语语义空间作锚点：第一阶段通过知识蒸馏初始化学生模型的跨语对齐，第二阶段联合优化蒸馏与跨语对比学习以提升检索判别力同时保持对齐。在多语检索基线上持续领先，并与同规模或更大的现成模型相当。

INSIGHT用英语语义空间作锚再蒸馏到多语，是缓解 MLIR 语言聚类的实用思路。社区搜索若涉及多语种 UGC（中英混排、外语帖），可借鉴"教师英语空间锚定 + 蒸馏 + 跨语对比"两阶段配方训练召回向量，避免直接对比学习带来的语言分簇与跨语对齐退化。

Youngjoon Jang, Seongtae Hong, Heuiseok Lim

Generalistic or Specific Embeddings, Which is Better? An Empirical Study on Search for Clinical Coding in Non-English Languages

语义检索的句向量模型几乎都在英语语料上训练评估，用于非英语临床检索（ICD-10 编码召回）时召回明显下降且被聚合指标掩盖。论文用大生成模型当数据工厂：从西班牙语生物医学编码器微调出 bi-encoder + cross-encoder reranker 两阶段检索器，训练数据由 Gemini 合成、覆盖英/西/加泰/意/葡/法六语。bi-encoder 单独在 MRR 上追平 BioBERT-ST (0.876 vs 0.866)、R@3 (0.650 vs 0.626)、R@5 (0.804 vs 0.790) 更优；加 cross-encoder reranker 把 R@5 提到 0.822。

INSIGHT验证了"LLM 合成多语数据 + 领域编码器微调 + 两阶段 bi/cross-encoder"在低资源语言检索上的有效性，且无需英语生物医学预训练。社区搜索做垂类或小语种召回时可复用：用 LLM 造合成 query-doc 对微调召回，再叠 cross-encoder 重排，性价比高。

SPECTRA: Synthetic IR Test Collections with Relevance Oracles and Controlled Distractor Diagnostics

大规模 IR 测试需要足够大的语料压测索引构建、排序延迟、query 路由与评测工具，但人工判定的测试集昂贵、且文档私密或尚在设计时无法获得。SPECTRA 提出可复现框架，把潜在主题结构、表层文本实现、元数据控制、query 意图生成与确定性 relevance oracle 分离，合成文本语料与检索测试集，作为 Cranfield/TREC 式评测的诊断补充。单进程 Python 原型可生成最多 6 万文档、961 万 token 的语料，并为 96 条 query 产出分级相关性标签。

INSIGHT用确定性 oracle 生成可控分级标签，让检索系统在没有人工标注时也能做压测和诊断（含可控干扰项 distractor）。对自建搜索评测有用：冷启动或隐私语料场景下，可用合成测试集先验证索引/排序工程链路与长尾词表行为，再上人工评测。

DeepImageSearch: Benchmarking Multimodal Agents for Context-Aware Image Retrieval in Visual Histories

现有多模态检索擅长语义匹配，却默认 query-图像相关性可孤立度量，忽略真实视觉流中信息分布在时序序列上的依赖。DeepImageSearch 把图像检索重构为自主探索任务：模型需在原始视觉历史上做多步推理规划、依据隐含上下文线索定位目标。论文构建 DISBench 基准，并用人-模型协同 pipeline，让 VLM 挖掘潜在时空关联以生成上下文相关 query。

INSIGHT把检索从一次性匹配升级为在历史流上多步探索，对带时序/上下文的检索场景（相册、浏览历史、会话内检索）有启发。社区搜索若涉及用户历史行为上下文，agentic 多步检索可定位靠隐含线索才能命中的目标，但需权衡多步推理的延迟成本。

Vector Linking via Cross-Model Local Isometric Consistency

论文研究 Vector Linking：给定两个黑盒编码器在部分重叠数据上产出的向量云，仅用向量恢复跨模型对象对应关系。理论与实验表明独立训练的对比编码器有局部几何一致性——短程距离近似保距（差一个尺度因子），长程因模型特异畸变而不保。据此提出基于参考锚点的迭代几何 embedding 哈希：用到采样配对锚点的距离表示每个向量，在哈希空间提候选链接，并用 Beta-Bernoulli 后验跨视图聚合证据、把高置信链接升为新锚点。多个基准与编码器对上链接准确稳健。

INSIGHT"局部保距、长程畸变"这一对比编码器几何性质，对 embedding 模型升级/迁移很实用：换召回模型时无需重编码全库，用少量配对锚点即可对齐新旧向量空间，降低双塔模型迭代的索引重建成本。

SemStruct: Contextualizing Semantic Embeddings with Structural Information for Schema Matching

Schema matching 中预训练语言模型 (PLM) 通常把表格序列化为独立列描述的文本序列，丢弃了行级共现这一关键结构（关系上下文），只能依赖列名语义。SemStruct 把表建模为列与值为节点、行为连接的异构图，用 GNN 在结构上传播消歧上下文，结合冻结 PLM 的语义能力；与需要专有 LLM 访问和微调的 SOTA 不同，它无需这些即可工作。

INSIGHT"冻结 PLM 语义 + GNN 结构归纳偏置"说明纯文本序列化会丢失结构信号，引入图结构传播上下文能在不微调大模型的前提下提升匹配。对结构化检索/实体匹配（商品属性、字段对齐）有借鉴：把行级共现等关系上下文显式建模为图，比硬塞进文本序列更有效。
