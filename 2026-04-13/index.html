DiffGRM: Diffusion-based Generative Recommendation Model

针对自回归生成式推荐模型的顺序依赖和局部最优问题，提出首个基于扩散模型的生成式推荐框架 DiffGRM。核心创新在于用掩码离散扩散模型替代自回归解码器，实现对 Semantic ID 的双向上下文建模和任意顺序并行生成。设计了三个关键模块：并行语义编码（PSE）解耦 token 并平衡信息分布、策略一致性噪声（OCN）聚焦高不确定性 token 的训练、置信度引导并行去噪（CPD）优先填充高置信度位置。在多个公开数据集上 NDCG@10 提升 6.9%–15.5%，已被 The Web Conference 2026 接收。

KEY INSIGHT · 对业务意味着什么DiffGRM 证明了扩散模型在生成式推荐中可以超越自回归范式，核心优势在于摆脱了从左到右的顺序约束，允许模型利用双向上下文并行生成所有 token。对于 UGC 搜索/推荐系统，这意味着召回阶段可以用扩散模型一次性生成多个候选 item 的 Semantic ID，避免 beam search 的局部最优陷阱。OCN 策略（聚焦不确定 token 训练）可借鉴到其他序列生成任务中，提升训练效率。

Generative Recommendation with Semantic IDs: A Practitioner's Handbook

Snap

针对生成式推荐（GR）领域缺乏统一基准和开源框架的问题，提出 GRID（Generative Recommendation with semantic ID）框架。GRID 采用模块化设计，支持 Semantic ID 构造、编码器、解码器等组件的灵活替换，便于快速迭代和公平对比。通过系统性消融实验发现多个被忽视的架构组件（如 Semantic ID 编码方式、解码策略）对性能有显著影响。框架已开源（github.com/snap-research/GRID），在多个公开基准上验证了各组件的贡献度。

INSIGHTGRID 的核心价值在于为生成式推荐提供了一个「乐高积木」式的实验平台，让从业者可以快速验证不同 Semantic ID 构造方法和解码策略的组合效果。消融实验揭示了一个重要发现：许多看似不起眼的架构选择（如 token 编码方式）对最终效果影响巨大，这提醒我们在构建 GR 系统时不能只关注模型主体架构。对于计划落地生成式推荐的团队，GRID 可作为快速原型验证的起点，大幅降低技术选型成本。

Generative Reasoning Recommendation via LLMs

Zhejiang UniversityHuawei

提出 GREAM 框架，首次将显式推理链引入基于 LLM 的生成式推荐。框架集成三个组件：协同-语义对齐（Collaborative-Semantic Alignment）弥合文本与协同过滤信号的鸿沟、推理课程激活（Reasoning Curriculum Activation）通过分阶段训练激活 LLM 的推荐推理能力、稀疏正则化组策略优化（SRPO）基于强化学习进行端到端优化。支持两种推理模式：直接序列推荐（低延迟高吞吐）和序列推理推荐（可解释推理链）。在 3 个公开数据集上均优于现有方法。

INSIGHTGREAM 的关键创新在于将「思维链推理」引入生成式推荐，让模型不仅输出推荐结果还能解释推荐理由。双推理模式的设计非常务实：线上服务用直接模式保证延迟，离线分析或需要可解释性的场景用推理模式。对 UGC 搜索系统而言，推理链可用于分析为何某些内容被推荐，辅助质量审核和策略调优。SRPO 优化策略解决了 LLM 推荐中常见的长尾分布问题，值得在 LLM 排序场景中借鉴。

Minjie Hong, Zetong Zhou, Zirun Guo, Ziang Zhang, Ruofan Hu, Weinan Gan, Jieming Zhu, Zhou Zhao

Can Explanations Improve Recommendations? A Joint Optimization with LLM Reasoning

Google

提出 RecPIE 框架，探索 LLM 生成的自然语言解释是否能反向提升推荐精度。核心思路是联合优化「预测驱动的解释生成」和「解释驱动的预测」，用可训练 LLM 生成用户偏好解释，再将解释作为额外信号反馈给神经推荐模型。在 Google Maps POI 推荐数据集上实现 3–4% 的准确率提升，仅用 12% 的训练数据即可达到基线性能。人类评测中 RecPIE 的解释被 61.5% 的评估者偏好。

INSIGHTRecPIE 验证了一个有价值的假说：LLM 生成解释的过程本身可以提炼出有用的用户偏好信号，反哺推荐模型提升精度。这打破了「解释只是锦上添花」的认知——解释生成任务与推荐预测任务可以互相增强。对 UGC 搜索系统，这意味着可以用 LLM 为搜索结果生成解释（如「为什么推荐这个帖子」），同时利用解释过程中提取的语义信号改进排序。12% 数据达到基线效果的发现，对冷启动和数据稀疏场景尤其有价值。

Yuyan Wang, Pan Li, Minmin Chen
