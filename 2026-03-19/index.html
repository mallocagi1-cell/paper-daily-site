Quantized Inference for OneRec-V2

本文研究了生成式推荐模型 OneRec-V2 的量化推理问题。作者发现 OneRec-V2 的权重与激活值分布特征与 LLM 高度相似，而非传统推荐系统，因此可以直接复用 LLM 领域成熟的 FP8 训练后量化（PTQ）技术。在华为生产环境的线上 A/B 实验中，该方案实现了端到端推理延迟降低 49%，吞吐量提升 92%，且模型性能无损。这一结果表明 LLM 量化优化技术可以直接迁移到大规模生成式推荐系统。

SpecSteer: Synergizing Local Context and Global Reasoning for Efficient Personalized Generation

USTCAlibaba

SpecSteer 提出了一种非对称协同推理框架，解决个性化 LLM 生成中隐私与能力之间的两难困境：将用户历史发送给云端大模型存在隐私风险，而纯本地小模型推理能力不足。框架的核心思想是：本地小模型利用私有用户上下文生成草稿 token，云端大模型基于公共知识进行全局推理校验并修正。两者的结合避免了用户数据上云，同时保留了大模型的推理能力，实现了质量与隐私的兼顾。

INSIGHT推测解码（Speculative Decoding）机制在个性化生成场景中具有独特价值：本地小模型天然持有用户隐私数据，大模型负责全局语义质量保障。对社区平台而言，这一框架可用于构建「本地用户偏好 + 云端内容理解」的混合个性化推荐/摘要生成系统，尤其适合对隐私敏感的 UGC 内容场景。延迟优化来自推测接受率，与大模型独立推理相比有显著加速。

UserSimCRS v2: Simulation-Based Evaluation for Conversational Recommender Systems

University of Stavanger

UserSimCRS v2 是对话式推荐系统（CRS）模拟评估工具包的重大升级版本，针对当前研究缺乏标准评测资源的痛点。新版本核心扩展包括：增强的议程驱动用户模拟器、引入基于 LLM 的用户模拟器（更真实的用户行为建模）、更广泛的 CRS 和数据集集成支持，以及 CRS 系统的多维度质量分析框架。v2 版与最新 CRS 研究对齐，填补了对话式推荐评测标准化的空白。

INSIGHT对话式推荐系统的评测难点在于无法获得真实用户的连续交互数据。UserSimCRS v2 通过 LLM 驱动的用户模拟器将评测成本降低至零：可以在无真实用户参与的情况下系统性测试 CRS 在不同用户类型（耐心程度、偏好清晰度等）下的鲁棒性。对于希望构建或评测 UGC 平台对话搜索/推荐功能的团队，这是一个开箱即用的基础设施工具。

RetailBench: Evaluating Long-Horizon Autonomous Decision-Making and Strategy Stability of LLM Agents in Realistic Retail Environments

RetailBench 是一个面向零售/电商场景的高保真长视野 LLM Agent 评测基准，专门评估 Agent 在真实动态环境中维持连贯决策的能力。基准涵盖库存管理、定价策略、需求预测等零售核心任务，要求 Agent 在多步长交互中保持策略稳定性。实验揭示了当前 LLM Agent 在长视野任务中的系统性短板：随任务时间线延长，决策连贯性显著下降，展示了将 LLM Agent 部署到复杂商业场景的实际挑战。

INSIGHTRetailBench 揭示了 LLM Agent 在电商/零售推荐场景中的关键弱点：短视野任务表现优异，但长视野多步策略任务中决策稳定性迅速崩溃。这对构建 LLM-based 推荐 Agent（如购物助手、智能客服、个性化导购）的团队具有重要警示：当前模型在跨多轮会话的用户偏好追踪和策略一致性上仍有明显差距，需要配合强化记忆机制和策略约束才能实用化。

Linghua Zhang, Jun Wang, Jingtong Wu, Zhisong Zhang

Answer Bubbles: Information Exposure in AI-Mediated Search

本文对 AI 中介搜索系统中的信息暴露模式进行大规模实证研究，分析了 11,000 条真实搜索 query 在四个系统（vanilla GPT、Search GPT、Google AI Overviews、传统 Google 搜索）中的响应差异。研究从三个层次对比：信息来源多样性、生成摘要的语言特征、以及对引用材料的忠实度。结果表明生成式搜索系统在信息呈现方式上与传统链接式检索存在系统性差异，揭示了「Answer Bubble」（信息茧房）效应——AI 摘要可能对特定信息源过度集中引用。

INSIGHT对社区搜索平台而言，这项研究有两层实践启示：（1）如果引入 AI 生成摘要替代或补充传统搜索结果，需警惕信息来源集中化带来的「平台偏见放大」风险；（2）相比传统搜索的信息多样性，生成式搜索摘要的语言更流畅但可能降低原始内容的曝光度，直接影响 UGC 创作者激励。这是生成式搜索产品化过程中必须权衡的伦理与产品设计问题。

Michelle Huang, Agam Goyal, Koustuv Saha, Eshwar Chandrasekharan

MemX: A Local-First Long-Term Memory System for AI Assistants

MemX 是一个以本地优先为设计原则的 AI 助手长期记忆系统，基于 Rust + libSQL 实现，提供持久化、可检索、可解释的对话记忆管理。检索流水线采用向量召回 + 关键词召回 + RRF+ 四因子重排序的混合策略，并引入低置信度拒绝规则以抑制内存中无对应答案时的错误召回。系统兼容 OpenAI embedding API，支持本地隐私保护部署。

INSIGHTMemX 展示了一种工程化思路：将对话记忆管理从「向量数据库黑盒」转变为「可解释的检索流水线」。对于构建 UGC 平台对话式推荐助手的团队，关键借鉴点有二：（1）RRF 融合稀疏与稠密召回可显著提升记忆命中率；（2）低置信度拒绝规则避免「幻觉式记忆」——这在推荐场景中等价于避免给用户推荐其历史中并不存在的偏好。本地化设计也是应对数据合规要求的工程选择。

AdaMem: Adaptive User-Centric Memory for Long-Horizon Dialogue Agents

AdaMem 针对长视野对话 Agent 的记忆管理三大核心痛点提出解决方案：（1）现有系统过度依赖语义相似度，遗漏用户理解所需的关键证据；（2）相关经验被存储为孤立片段，缺乏时序与因果连贯性；（3）记忆管理缺乏以用户为中心的主动更新机制。AdaMem 引入三层记忆架构（短期工作记忆、中期情节记忆、长期语义记忆）和用户中心图结构，支持跨会话的用户偏好建模与动态更新。

INSIGHTAdaMem 的三层记忆架构对于构建能够跨会话记住用户偏好的推荐对话系统具有直接参考价值。关键设计点：图结构存储用户体验的时序与因果关系（如「上周喜欢A，本周转向B」的偏好漂移），比纯向量检索更能捕捉动态偏好。对于社区搜索场景，这可以支持「有记忆的搜索助手」：理解用户兴趣演变历史，主动调整推荐策略，而非每次会话从零开始。

PREFINE: Personalized Story Generation via Simulated User Critics and User-Specific Rubric Generation

PREFINE 提出了一种无需显式用户反馈或参数微调的个性化内容生成框架，核心是「角色化 Critique-and-Refine」机制。系统从用户交互历史构建伪用户 Agent，该 Agent 代入用户角度对生成内容进行批评并提出具体评分维度（Rubric），生成器基于 Rubric 迭代优化输出。框架兼顾了实用性（无需 fine-tuning）、可扩展性和隐私保护（用户数据不上云），在个性化故事生成任务上超越了需要显式反馈的基线方法。

INSIGHTPREFINE 的 Critique-and-Refine 框架将「个性化」问题转化为「零样本 prompt 工程」问题，不需要为每个用户维护独立模型。对生成式推荐应用的启示：可将此框架迁移到 LLM 个性化推荐理由生成场景——基于用户历史生成专属评价维度，指导推荐摘要或商品描述的个性化撰写。无需微调的特性使其在用户群体规模大、偏好分布分散的 UGC 平台具有很强的工程可行性。

Kentaro Ueda, Takehiro Takayanagi

CraniMem: Cranial Inspired Gated and Bounded Memory for Agentic Systems

CraniMem 借鉴神经认知科学中的颅脑记忆机制，设计了一种带门控（Gating）和容量约束（Bounded）的多阶段记忆架构，用于 LLM Agent 的长期运行场景。系统通过目标条件门控和效用标注控制记忆的写入与淘汰，结合有界情节缓冲区防止记忆膨胀，解决了当前 Agent 记忆系统普遍存在的「ad hoc 读写规则导致保留不稳定」和「易受干扰内容污染」问题。在 LLM Agent 长任务场景下显著提升了记忆的精准性和稳健性。

INSIGHTCraniMem 的门控 + 有界设计对推荐系统的在线用户建模有启发意义：容量约束防止用户模型被噪声交互稀释（类似于遗忘曲线机制），目标条件门控使模型只保留与当前推荐目标相关的历史信号（类似于注意力机制的内存版）。对于构建 LLM-based 对话推荐 Agent 的团队，这提供了一种更接近人脑记忆运作方式的架构参考，尤其适合处理长期用户兴趣演变与短期会话意图并存的场景。

Pearl Mody, Mihir Panchal, Rishit Kar, Kiran Bhowmick, Ruhina Karani

Chronos: Temporal-Aware Conversational Agents with Structured Event Retrieval for Long-Term Memory

Chronos 针对对话 Agent 的时序推理短板提出解决方案：当前记忆系统无法对跨月交互中随时间演变的事实和偏好进行有效推理，也缺乏对多跳、时序敏感查询的有效检索策略。Chronos 引入时间感知的结构化事件检索机制，将对话历史组织为时间锚定的事件图，支持对「上周说了什么」「三个月前的偏好如何变化」等时序敏感问题的精准召回。在长视野多轮对话任务上显著优于基线记忆系统。

INSIGHTChronos 的时序事件图对于社区平台的对话式搜索/推荐具有实际意义：用户的兴趣偏好不是静态的，节假日、热点事件、个人生活阶段都会导致搜索意图的时序漂移。能够感知「这个用户最近三个月的话题关注点从 A 转向了 B」的推荐系统将显著优于只看近期行为的系统。结构化事件检索的设计也避免了纯向量检索在时序推理上的盲区，值得在长期用户建模中借鉴。

Sahil Sen, Elias Lumer, Anmol Gulati, Vamse Kumar Subbiah
