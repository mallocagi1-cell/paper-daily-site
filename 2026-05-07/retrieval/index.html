Domain-Adaptive Dense Retrieval for Brazilian Legal Search

巴西法律检索覆盖判例法、立法和问答式搜索，要求训练 dense retriever 时在领域特化与跨子任务鲁棒性之间权衡。论文以 Qwen3-Embedding-4B 为底座，对比三种训练设置：原始 base、仅在法律数据上微调、以及法律数据 + SQuAD-pt 混合微调。在 JU'A 法律 leaderboard 的 5 个数据集和 Quati 葡语通用检索基准上评估，混合训练在保持法律子任务性能的同时整体表现最均衡，将平均 NDCG@10 从 0.414 提升到 0.447、MRR@10 从 0.586 到 0.595、MAP@10 从 0.270 到 0.308。

Evaluating Reasoning Models for Queries with Presuppositions

IIISc Bangalore

用户 query 中常带有事实错误的预设（presupposition），LLM 通常不会挑战这些预设、反而会强化用户的错误认知。论文构建了覆盖健康、科学和通识三个领域、含不同程度预设的 query 集，评估当前主流大型推理模型（LRM）。结果显示：相比非推理模型，推理模型准确率仅高 2-11%，仍有 26-42% 的虚假预设未被识别；并且推理模型对 query 表述方式和提示工程仍非常敏感。

INSIGHT在社区搜索/问答场景下，相当比例的 query 携带错误前提（如'为什么 XXX 会让 YYY'但 XXX 实际不会），简单地'按 query 检索 + 直接回答'会放大误信息。该论文给出实证：开 reasoning 档位并不能根治这个问题，必须在 query 理解阶段加上 presupposition 校验/否定模块（先用 LLM 判定 query 是否合理，再决定走检索还是走澄清）。这与社区搜索'先校正、再召回'的产品策略高度契合。

Rose Sathyanathan, Kinshuk Vasisht, Danish Pruthi

Geometric Deviation as an Unsupervised Pre-Generation Reliability Signal: Probing LLM Representations for Answerability

可靠的语言模型应在生成前就能信号化'该 query 超出我的知识'。论文提出用隐藏状态几何偏差（hidden state 与'可答参考集'质心的距离）作为生成前的无监督可靠性信号，无需失败标签也无需多次采样。在 Llama-3.1-8B、Qwen 2.5-7B、Mistral-7B-Instruct 三个模型 × Math/Fact/Code 三种 prompt 上评估：数学任务的 unanswerable query 与可答中心明显分离，ROC-AUC 达 0.78-0.84，单次前向通过即可超过简单拒答 baseline、与 self-consistency 持平；但事实型 prompt 没有出现可靠的几何信号。

INSIGHT该方法给'无法回答'的 query 提供了一种轻量级、单次推理的检测信号，对依赖 LLM 兜底回答的搜索场景特别有价值——可在生成前判定是否走'明确不知道'路径，避免幻觉污染。但实验显示几何信号主要编码'任务形式'而非'知识匹配'，在事实型 query 上失效。从业者可拿来做'代码/数学类问题'的 abstain 门控，但不要奢望它解决事实问答的幻觉问题；事实场景仍需配 RAG。

Yucheng Du

SERE: Structural Example Retrieval for Enhancing LLMs in Event Causality Identification

GGDUTHHuawei Noah's Ark Lab

事件因果识别（ECI）任务上 LLM 容易过度预测因果关系（causal hallucination）。论文提出 SERE 框架，通过三个结构化指标改进 in-context 示例检索：(i) Conceptual Path Metric 用 ConceptNet 编辑距离衡量事件概念关系；(ii) Syntactic Metric 用句法树编辑距离量化结构相似度；(iii) Causal Pattern Filtering 基于因果模式过滤示例。在 ECI 标准基准上利用 LLM few-shot 能力显著缓解过度预测问题。

INSIGHT检索'语义相近'的示例并不一定带来 in-context learning 的最大收益，结构化（概念图 + 句法树）相似度往往比纯 embedding 相似度更能匹配任务的归纳偏置。这启发社区搜索/问答的 few-shot prompt 检索：除了 embedding 相似度，可叠加 entity/intent 结构信号做二次排序。对处理短文本搜索中'语义相近但意图不同'的 query 尤其有帮助，能在不改 LLM 的前提下显著降低误判。

Zhifeng Hao, Zhongjie Chen, Junhao Lu, Shengyin Yu, Guimin Hu, Keli Zhang, Ruichu Cai, Boyan Xu

SAM-NER: Semantic Archetype Mediation for Zero-Shot Named Entity Recognition

GGDUT

零样本 NER 在域和 schema 漂移下脆弱：直接将实体 mention 映射到细粒度新标签会引发系统性语义漂移。SAM-NER 提出 Semantic Archetype Mediation 三阶段框架：(i) Entity Discovery 用协作抽取与共识去噪获得高覆盖、高保真的 entity span；(ii) Abstract Mediation 将 entity 投影到一组从本体抽象蒸馏的领域无关 archetype 空间；(iii) Semantic Calibration 再将 archetype 校准到目标 schema。

INSIGHT在引入新 schema/新业务标签时，'通用 archetype 中转'比直接映射目标标签更稳健，能减少 LLM 内在语义组织与新标签定义的错位。社区搜索的 query 实体识别（人物、地点、品牌、热点话题）经常需要扩充新类目，传统做法要么重训要么加大量 prompt；SAM-NER 给出'archetype 中介 + 语义校准'的可复用范式，对快速接入新业务垂类（如新增美妆/数码品类）特别有价值。

Ruichu Cai, Juntao Gan, Miao Mai, Zhifeng Hao, Boyan Xu

Rose-SQL: Role-State Evolution Guided Structured Reasoning for Multi-Turn Text-to-SQL

GGDUT

多轮 Text-to-SQL 任务在小规模 LRM 上潜力未被充分挖掘。Rose-SQL 提出 training-free 框架：引入 Role-State 作为细粒度结构化表征，桥接 schema linking 和 SQL 生成；通过结构同构检查追踪 Role-State 在历史上下文中的演化，引导小规模 LRM 通过 in-context learning 推断当前轮次 SQL 组合。无需 API 依赖、无需大规模微调即可达成多轮 NL2SQL 解析。

INSIGHT'Role-State 演化'是处理对话式查询的实用抽象——把每一轮 query 看作 schema 状态机的转移，比单纯堆叠历史 prompt 更可控。社区搜索/推荐中的'多轮搜索 refinement'（用户连续修改 query）面临相同问题：哪些约束被继承、哪些被替换。该论文给出可行的'小模型 + in-context'方案，避免昂贵的微调，对资源受限的 query understanding 团队是值得借鉴的工程路径。

Le Zhou, Feng Yao, Fengcai Qiao, Bo Xu, Fangyuan Wang, Boyan Xu

CuraView: A Multi-Agent Framework for Medical Hallucination Detection with GraphRAG-Enhanced Knowledge Verification

出院摘要生成中 LLM 容易产生与源记录矛盾的幻觉，威胁患者安全。CuraView 是一个多 agent 框架，从患者级 EHR 构建 GraphRAG 知识图谱，实现 sentence-level 幻觉检测和证据接地解释；闭环 generation-detection pipeline 结合 sentence-level 证据检索和 4 级证据分类（E1 强支持 → E4 直接矛盾），输出可解释证据链。在 250 患者子集上验证。

INSIGHTGraphRAG 比 vanilla 向量检索更擅长'句级证据匹配 + 等级化判定'，特别适合需要做'事实核查 / 矛盾检测'的搜索场景。社区搜索中的'问答可信度'产品（医疗、法律、金融垂类）可借鉴：把召回结果和生成结果做句级双向匹配，分级标注证据强度，再决定展示策略。多 agent 闭环检测则是降低 LLM 幻觉的工程化范式。

Severin Ye, Xiao Kong, Xiaopeng He, Guangsu Yan, Dongsuk Oh

How Language Models Process Negation

USC

论文用机制可解释性技术研究 LLM 如何处理否定。首先发现 open-weight 模型虽常给错答案，但内部确实存在能正确处理否定的组件，错误源于晚期 attention 层倾向走捷径——抹除这些 attention 模块后准确率显著上升。其次比较两个假设：模型可能用 attention head 关注被否定短语并抑制相关概念，也可能直接构造整个否定短语的表示（如 'not gas' 表示促进液体/固体）。在 Mistral-7B 与 Llama-3.1-8B 上发现两种机制并存。

INSIGHT否定是搜索 query 中常见但被严重忽视的语义信号（'不要 XX'、'非 XX'），LLM 的'晚期 attention 捷径'会把否定当作未否定来匹配文档。论文给出两条可借鉴方向：(1) 在 retrieval 端可显式提取否定短语并加入负向 prompt；(2) 在 ranking 端可考虑剪枝那些被识别为'shortcut'的 attention 模块，或在评测集中提高否定型 query 占比，避免线上模型在否定查询上误召。

Zhejian Zhou, Tianyi Zhou, Robin Jia, Jonathan May

MedStruct-S: A Benchmark for Key Discovery, Key-Conditioned QA and Semi-Structured Extraction from OCR Clinical Reports

临床报告半结构化信息抽取通常含 (i) 字段头(key)发现、(ii) key-conditioned QA、(iii) 端到端 key-value 抽取三个子任务。现有评测低估了 key 表征异构与 OCR 噪声两个因素。MedStruct-S 提出含 3,582 个真实临床报告页面的标注 benchmark，专门评估 unknown key + OCR 噪声场景；对 encoder-only 序列标注 + 后处理 与 decoder-only 结构化生成两类范式（4 个 encoder-only + 5 个 decoder）做系统对比。

INSIGHT'未知 key' + '噪声输入'是工业半结构化抽取的真实挑战，benchmark 揭示 encoder-only 与 decoder-only 各有优劣（encoder 更鲁棒，decoder 更灵活）。社区搜索中很多结构化提取任务（如帖子的'机型/价格/优缺点'自动萃取）面临相同模式：key 集合不固定 + 文本质量差。该 benchmark 给出选型参考——做'灵活 key + 噪声'场景倾向 decoder-only，做'固定 schema + 高精度'倾向 encoder-only。

Yingyun Li, Yu Wang, Haiyang Qian

When Should a Language Model Trust Itself? Same-Model Self-Verification as a Conditional Confidence Signal

评估 LLM 在 selective prediction 场景下使用自我验证（让模型审视自己答案）作为置信度信号的实用性，与两个似然度 baseline（LL-AVG、LL-SUM）做对比。在 ARC-Challenge 与 TruthfulQA-MC 上跨多个模型家族、规模、prompt 评测；用 AURC 和工作点分析衡量弃答质量。结果高度任务/模型相关：ARC-Challenge 上 self-verification 对 Phi-2、Qwen 系列尤其 Qwen-7B 显著优于 LL-AVG；TruthfulQA-MC 上信号不稳，DeepSeek-R1-Distill-8B 反而退化，LL-SUM 仍是更强 baseline。

INSIGHT'让模型自验'看似自然，但任务依赖性极强，并非通用的置信度银弹。社区搜索中如果想用 LLM 输出作为答案直接呈现，需要根据 query 类型（推理 vs 事实）和后端模型选择不同的置信度方案：偏推理类 query 可接 self-verification，偏事实类仍以 token-level 似然为主。这提醒从业者：在生产 selective prediction（弃答/降级到检索结果）时，要做按 query 类型 × 模型组合的 abstention 评估，而不是上线一种通用置信度阈值。

Aditya Ajay Phalod
