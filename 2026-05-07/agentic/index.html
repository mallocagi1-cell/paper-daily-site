美团 LongCat-Flash-Thinking-2601 发布：Agentic Search 与工具调用登顶开源 SOTA

美团 LongCat 团队开源了 LongCat-Flash-Thinking-2601 模型，在 Agentic Search（智能体搜索）和 Agentic Tool Use（智能体工具调用）等核心评测基准上达到开源模型 SOTA 水平。在 τ²-Bench 多领域工具调用评测中取得 88.2 分，超越 Qwen3、Llama-3 系列开源同行；在 BFCL、Tau-Bench 等智能体评测上同样领先。模型针对 thinking + tool-use 场景做了专门的训练数据合成与 RL 对齐，目标是把 Agentic 能力做成可商用的开源底座。

Workspace-Bench 1.0: Benchmarking AI Agents on Workspace Tasks with Large-Scale File Dependencies

📖 深度解读 · 9 分钟 →

论文提出 Workspace-Bench 评估 AI Agent 处理「真实工作空间 + 大规模文件依赖」任务的能力。基准覆盖 5 类员工画像、74 种文件类型、20,476 个文件 (最大 20GB)、388 条精选任务和 7,399 条评测 rubric，并提供 100 任务 Lite 版以降低 70% 评估成本。在 4 种 Agent 框架 × 7 个基础模型上测试，最佳 Agent 完成率 68.7%，人类基线 80.7%，全体 Agent 平均 47.4%，显示当前 Agent 仍显著低于人类。

INSIGHTWorkspace-Bench 把 Agent 评估从「单工具单步」推进到「文件依赖 + 长程上下文」，对企业搜索、知识库 RAG、内部 Agent 系统的选型具有直接参考价值。72% 的人机差距说明 Agent 的瓶颈不在单步推理而在跨文件依赖追踪、状态更新与迭代纠错。社区搜索/UGC 场景可借鉴其 rubric 设计，把「多帖子相互引用、跨长尾文件检索」这类任务纳入 Agent 评测；Lite 版的成本压缩思路也值得复用到内部 Agent 自动评测流水线。

Zirui Tang, Xuanhe Zhou, Yumou Liu, Linchun Li, Yukai Wu, Weizheng Wang, Hongzhang Huang, Wei Zhou 等 22 人

小红书联合人大开源通用智能体 DeepAgent：1.6 万 RapidAPI 工具调用

XiaohongshuRenmin University

小红书联合中国人民大学研究团队开源通用智能体 DeepAgent，定位为「具备可扩展工具集的端到端推理 Agent」。核心能力包括：在 16,000+ RapidAPI 工具池中动态发现并调用合适工具、面向全局任务规划而非单步反应、自主记忆折叠 (memory folding) 长程上下文，并对推理-行动循环进行端到端训练。这是国内 UGC 平台首次开源面向通用任务的智能体框架，目标是把搜索 + 推荐 + 工具调用整合到一个统一的 Agent 能力底座。

INSIGHTDeepAgent 把 RapidAPI 这种「工具长尾」直接做成 Agent 的可发现/可调用资源池，对 UGC 短文本搜索场景启发很大：可借鉴其工具检索 + 记忆折叠机制，把帖子检索、用户画像、评论分析、外部 API 等都视为统一工具，由 Agent 端到端编排。「自主记忆折叠」尤其值得关注——长会话场景下能在不丢关键信息的前提下压缩历史，缓解长程上下文窗口与延迟成本的矛盾，比 FIFO 截断或外挂向量记忆更优雅。

阿里云 AI 搜索 Agentic RAG 技术实践

Alibaba

阿里云搜索团队系统介绍其 Agentic RAG 落地路径：针对不同类型文档 (PDF、Office、网页、代码库) 开发差异化解析策略；多源数据接入 (OSS、ADB、关系库、URL 抓取) 形成统一索引；将 Pipeline、Inference API、子服务模块化，使 Agent 可以以工具调用方式编排检索-改写-重排-生成流程。系统强调「离线索引建设 + 在线 Agent 编排」分层架构，并通过子服务复用降低企业级落地成本。

INSIGHT本文最大的工程启示是把 Agentic RAG 从「单 Agent 单链路」升级到「Agent 编排子服务」的产品化形态——文档解析、检索、改写、重排各自做成可复用 module，由顶层 Agent 决定调用顺序。社区/UGC 搜索同样面对帖子、视频转写、评论、问答等异构内容，可借鉴其分层抽象：先构建标准化子服务，再通过 Agent 决策层处理复杂查询，避免一开始就训练大一统 end-to-end Agent，更利于灰度与可解释。

AutoSurfer: Teaching Web Agents through Comprehensive Surfing, Learning, and Modeling

Microsoft

AutoSurfer 提出生成高质量 Web Agent 训练轨迹的新方法，针对现有自动轨迹生成的三大局限提出改进：(1) 系统化广度优先探索策略；(2) 任务合成基于真实导航路径而非孤立页面元素；(3) 利用探索轨迹作为 hint 引导 Agent 自我精炼。在 WebArena 基准上对 Qwen2.5-VL-7B-Instruct 进行微调，整体任务完成率达 24.23%，超过此前最佳 19.59%，相对 Explorer、OS-Genesis、SynthAgent 等基线均有显著提升。

INSIGHTAutoSurfer 关键创新是「BFS 探索 + 路径锚定的任务合成」：相较于 OS-Genesis 等单页面任务生成法，它先用 BFS 把网站结构走一遍，再基于真实路径合成多步任务，从而提升训练任务的拓扑多样性。对搜索/推荐里的 Agentic 调研型查询非常有借鉴价值——可在自家平台用类似 BFS 探索策略合成「多步对比、深度筛选」类查询训练数据。24.23% vs 19.59% 在 WebArena 这种难基准上是 4.6 个百分点的绝对提升，是当前 web agent 训练数据增强方向的强信号。

Fazle Elahi Faisal, Qianhui Wu, Baolin Peng, Jianfeng Gao

Scaling Web Agent Training through Automatic Data Generation and Fine-grained Evaluation

LG AI Research

论文提出可扩展的 Web Agent 训练数据生成 pipeline，并配套基于约束的细粒度评估框架，可对「部分成功」的轨迹也做进度评估，从而把以往被丢弃的失败/中断轨迹转化为有效训练数据。同时发布 BookingArena 基准——覆盖 20 个流行预定网站的复杂订房任务。蒸馏出的小尺寸学生模型在该基准上超过开源同行，并在多数任务上匹配或超过商用系统，展示了「自动数据合成 + 细粒度评估」对 web agent 性能的杠杆效应。

INSIGHT本文的主要贡献是把 web agent 训练数据从「成功/失败」二元标签升级为「任务进度连续评分」，让大量「差一步成功」的轨迹也能贡献梯度，等价于在轨迹层面做了 reward shaping。这一思路对所有 Agentic 系统训练都具有可迁移性，包括搜索 Agent 的多步检索-改写流程，可以把「相关结果数量、用户停留」等中间信号当作约束式奖励。BookingArena 在垂直领域复现 web 任务的方式，也为社区搜索领域自建 Agent 评测基准提供模板。

Lajanugen Logeswaran, Jaekyeom Kim, Sungryull Sohn, Creighton Glasscock, Honglak Lee

When to Think, When to Speak: Learning Disclosure Policies for LLM Reasoning

ICML 2026 论文。LLM 自回归接口存在「沉默税 (silence tax)」：多想几步再输出会延迟首条任务相关 token，但太早输出又会被错误中间状态污染后续生成。作者提出 Side-by-Side (SxS) Interleaved Reasoning，把「披露时机」做成自回归生成内的可控决策——在私有推理与对外披露之间交错切换，仅在推理已支持时才暴露内容。训练阶段用 entailment-aligned 轨迹做 SFT + RL。在 Qwen3-30B-A3B (MoE) 与 Qwen3-4B (Dense) 上、AIME25 (in-domain) 与 GPQA-Diamond (out-of-domain) 评测均改善「精度-内容延迟」Pareto。

INSIGHT把「思考-发言」时序控制做成可学习策略，是 Agentic Search/Reasoning 链路里被忽视的工程维度。在搜索 Agent 流式返回场景中，过早 streaming 会暴露未完成的检索-推理结果导致用户误读，过晚又损害交互体验。SxS 框架可直接迁移到 Agentic Search 的「检索-思考-增量输出」流水线，把首字延迟与精度做权衡。其 entailment-aligned 训练数据构造方式也为我们做 Agent 流式输出对齐提供了可借鉴样本。

Jiaqi Wei, Xuehang Guo, Pengfei Yu, Xiang Zhang, Wanli Ouyang, Siqi Sun, Qingyun Wang, Chenyu You

Rethinking Agentic Reinforcement Learning In Large Language Models

立场/综述论文重新审视 Agentic RL 与传统 RL 的根本差异：传统 RL 训练专才 Agent 优化预定义奖励，而 LLM-based Agentic RL 强调自主目标设定、长程规划、自适应策略与不确定环境下的推理。作者主张应把 meta-reasoning、self-reflection、多步决策直接嵌入学习循环，而非依赖静态目标和 episodic 交互。论文系统梳理 Agentic RL 的概念基础、方法学创新和有效设计原则，并指出当前关键挑战与未来方向。

INSIGHT对搜索/推荐团队的实践启示是：当我们把 Agentic Search/RAG 升级到 RL 训练时，应跳出「轮内 reward = 检索 nDCG」这种单步优化思路，转向轨迹级、多步、可反思的 reward 设计。论文强调的 self-reflection 与 meta-reasoning 对应到工程上就是「让 Agent 学会判断自己是否需要继续检索、是否相信当前结果」。这类能力已在 Meituan LongCat、DeepAgent 等同期工作中被验证，本综述提供了较完整的概念框架，可作为团队入门 Agentic RL 的 reading list。

Fangming Cui, Ruixiao Zhu, Cheng Fang, Sunan Li, Jiahong Li

Physics-Grounded Multi-Agent Architecture for Traceable, Risk-Aware Human-AI Decision Support in Manufacturing

论文提出 MAKA (Multi-Agent Knowledge Analysis)，面向高精度航空航天 CNC 加工的人机协同决策支持架构。该架构将 LLM 助手分解为多个职责清晰的 Agent：意图路由 Agent、纯工具量化分析 Agent、知识图谱检索 Agent，并通过明确的 provenance 链路保证可审计、可追溯。强调在风险约束的多步数值工作流中，要把工具计算、知识检索与文本生成解耦，避免 LLM 直接拼接数值与决策造成不可控风险。

INSIGHTMAKA 体现了「企业关键决策场景下 Agent 架构的核心范式」——分层、可审计、风险约束。对搜索/推荐链路同样适用：当 Agentic Search 走向客服、医疗、金融等高风险场景，应避免 end-to-end 黑盒，转而采用「意图分发 + 受限工具 + 可追溯 KG 检索」三段式拆分。该架构虽偏制造业，但其「provenance + tools-only quantitative analysis」的设计原则可直接迁移到搜索 Agent 的可解释性与 audit 需求中，对企业级 Agentic 落地具有方法论价值。

How to Build In-Vehicle AI Agents with NVIDIA: From Cloud to Car

NVIDIA

NVIDIA 开发者博客介绍如何用其 AI Agent 全栈方案构建「云到车」一体化的车载 AI Agent：云端做大模型推理与 RAG 编排，端侧做轻量 Agent + 工具调用。文章聚焦把 NeMo、NIM、cuOpt、TensorRT-LLM 串到一个落地链路中，覆盖语音交互、导航搜索、车控工具调用，并讨论端云协同的延迟与隐私权衡。

INSIGHT对 Agentic 实践者最有价值的不是车载本身，而是「端云分工 + 轻量端侧 Agent」的部署范式。该模式可直接迁移到移动 App 上的搜索 Agent：长尾、复杂查询交云端大模型推理，常见快查 + 工具调用 (导航、用户画像、热门帖子) 由端侧轻量 Agent 完成，可显著降低首字延迟。NVIDIA 的全栈推理优化 (TensorRT-LLM、NIM 微服务) 是 Agentic Search 部署成本压降的重要支点，国内团队应跟踪其端云一体化 Agent 部署模式。
