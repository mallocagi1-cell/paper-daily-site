CASI: Credit Assignment via Set Intervention for Agentic Retrieval

多条查询改写共享一个下游奖励时，CASI 固定检索快照，比较不同查询子集的收益，再用 Shapley 值分配动作信用。五个独立训练种子下，留出集回放价值为66.70±3.40，高于 Singleton 的55.00±4.00；七天、10%线上流量实验中，广告主价值提升3.51%。

RCER: Reconstructing Cross-Evidence Relations for Iterative Retrieval-Augmented Generation

XJTUBBUPT

RCER 针对迭代 RAG 中证据越积越多、跨段实体关系却未被正确串联的问题，联合重建实体对应和推理依赖，并据此调整下一轮检索。最后独立选择互补段落、构建推理上下文。在三个多跳问答基准上，相对最佳基线平均增加2.83个 EM 点和3.06个 F1 点。

INSIGHT对社区里的跨帖子比较、追问和复杂条件查询，可把“找更多内容”改为“补齐尚未建立的关系”。保留原始段落与推理关系的对应，避免中间摘要把错误关系固化；应在离线集合中同时测证据覆盖、关系正确率和最终回答质量，并监控多轮调用对搜索时延的影响。

Plan or Retrieve First? A Scale Study of Tool Discovery Architectures

Apple

论文比较先检索工具再规划与先生成抽象工具签名再检索两种架构，在46,984个 API 上发现任务复杂度决定优劣。k=5时，单工具任务召回为37.2%对27.9%，先检索更好；同类多工具任务为14.3%对18.4%，先规划更好，但额外发现调用大致使推理成本翻倍。

INSIGHT社区搜索 Agent 的工具选择宜按任务复杂度路由，简单查帖保留直接检索，跨来源聚合再尝试规划拆解。可将首次召回的最高相似度作为无需额外调用的路由信号，但论文只把它作为实践方向；落地仍需验证阈值与真实任务完成率，防止抽象签名丢失专名或虚构工具。

Mingfei Zhang, Amit Surana, Ziauddin Majid, Chenxi Wang, Michael Xu

HyWe: Unifying Search and Operation for Real-World Hybrid Web Tasks

AlibabaCASIAXJTUNorthwestern

HyWe 将信息搜索与网页操作组织成共享历史、可显式切换的两种模式，并通过自动合成且验证的混合轨迹训练35B模型。在100个人写混合任务上，成功率由基础模型配统一工具提示的11.0%升至框架下28.0%，训练后达到47.0%；WebVoyager成功率为88.3%。

INSIGHT对于既要检索社区内容又要筛选、整理或执行页面操作的助手，可以分离搜索模式和操作模式，各自使用明确的工具集与提示，并共享可追溯历史。先复现无需训练的模式隔离增益，再考虑合成轨迹；评价要核对最终信息与操作子目标，不能只统计调用是否顺利返回。

ProgAgent: Learning Tool Orchestration through Programmatic Training

HKUSTBBUPTNTU

ProgAgent 用可执行程序编排工具，把中间结果留在运行时变量中，减少工具返回内容不断堆进上下文导致的退化。其训练栈包含可验证任务合成、轻量运行时和两阶段训练，只使用215个任务的四种环境规模；14B模型在 LOCA-bench 的64k环境状态下通过率30.7%，对比同档基线为0。

INSIGHT社区长链路搜索可将批量召回、去重、过滤等机械步骤放入程序运行时，只向模型提供必要证据和聚合结果。训练任务应覆盖环境规模变化，并使用执行结果验证成功；代码接口与直接调用接口都需交叉评测，才能区分模型学会编排与仅仅占用了更有利的评测接口。

τ-Emotion-Bench: Exposing the Interaction Fragility of LLM Agents through Real-World User Emotions

τ-Emotion-Bench 在任务目标保持不变时改变用户情绪，评估长链路工具 Agent 的稳定完成能力，包含10个领域、173个工具和580个评测任务。Tracer 通过允许不满用户终止低效交互来过滤训练轨迹；8B模型三次均成功指标 Pass^3 从8.4%升至19.8%，显示交互行为同样决定可靠性。

INSIGHT社区对话搜索可增加不耐烦、含糊和情绪变化的用户模拟，但必须固定底层信息需求，避免把任务变化混入情绪影响。应同时统计平均成功与多次一致成功，以及必要追问和无效追问；论文还人工修正了101个生成任务，提示合成评测不能仅靠模型自检。

Rishitosh Kumar Singh, Amir Saeidi, Shamanthak Hegde, Shrinidhi Kumbhar, Chitta Baral

How Meta Built Forum With AI-Native Engineering

Meta

Meta 介绍 Forum 团队如何把 Agent 纳入开发、回归验证和线上问题调查：通过规则、技能、命令、检查钩子与可观察工具组织流程。团队八周完成与 Facebook Groups 的核心功能对齐，自动压力测试发现并修复内存问题，内存使用及缺页大致减半；这是工程案例，并非受控算法对照实验。

INSIGHT对社区搜索团队最可迁移的是让 Agent 读取真实状态并反复验证：提供视图层级、代码入口、示例查询和设计文档，比只改提示更有操作性。可把相关性回归样例和错误复现变成固定检查流程；业务目标与最终质量判断仍应由工程师负责，案例速度收益不能直接推算成本节省。

Of Errors and Echoes: Responsibility-Aware Credit Assignment for Tool-Use Agents

DartmouthNNotre DameUC IrvineGeorgia Tech

ECHO 将错误责任识别与奖励分配分开，冻结裁判同时回看完整轨迹和当时可见前缀，区分新错、继承错误和错过纠正机会。其奖励对共享后果只计一次，并限制修复自身错误获得的收益；在 BFCL-v3 多轮子集，8B模型总体分数49.17%，高于 Arctic-AWM 的43.70%。

INSIGHT搜索 Agent 的失败常由早期改写或证据误读引起，后续工具调用只是传播结果。可按决策时可见证据标注错误责任，防止把整条失败轨迹全部惩罚，也防止通过先犯错再修复赚奖励；社区场景需另外检查裁判能否可靠识别缺少证据、遗漏条件和用户后续澄清。

Neos: Learning to Interleave Search and Visual Reasoning

AlibabaFudanSShanghai Innovation Institute

Neos 让多模态深度搜索同时学习获取证据和利用证据指导下一步行动，用目标条件化的证据接口处理检索图像，并交替进行策略强化学习与接口监督训练。论文在10个基准上评测9B与35B模型；未训练的35B基础模型在直接回答与 Agent 工作流下总体分数分别23.8和49.2，说明工具工作流本身影响很大。

INSIGHT图文社区搜索中，图片内容应转化为与当前子目标相关、可追溯的观察，继续影响下一轮检索，而非只在最终回答时展示。复现时应分别测工作流、训练数据、强化学习和视觉接口的增益；摘要中的23.8与49.2是基础模型工作流对照，不能误当作 Neos 训练后的收益。

Putting Earth AI to work: Geospatial agents for our planet's biggest challenges

Google

Google 的地理空间 Agent 先规划、再选择领域工具和数据，在上下文窗口外执行多步分析，并以四组 Agent 配置评测领域技能与规划的作用。公开卫生研究中人口与卫星信号使预测相对人口统计基线改善12%、空间分辨率细化8倍；这些是相关研究结果，不等同于 Agent 规划的独立增益。

INSIGHT社区复杂搜索可以借鉴领域工具与前置规划的分工：模型先明确需要哪些证据，再执行检索和计算，不用网页搜索替代实际数据分析。该案例的开放任务评分依据专家工作流而非唯一正确答案，因此应把产出当可复核草稿；迁移到 UGC 时需用真实查询、证据链和 nDCG/CTR 单独验证。
