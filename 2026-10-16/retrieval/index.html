XViewRank: Overlap-Conditioned Score Fusion for LLM-Augmented Sparse Retrieval

针对多种查询改写结果既互补又可能漂移的问题，XViewRank 用三路归一化 BM25 分数与三组结果集重叠率构成六维特征，通过小型非线性网络学习融合。TREC DL19 的 nDCG@10 从同输入 RRF 的 0.6376 升至 0.6583，MAP 从 0.4225 升至 0.4437；仅后者达到显著性，DL20 的改善未显著。

Cascaded Retrieval with Cross-Modal Query Refinement for Efficient Visual Document Search

MBZUAIAASUTU Darmstadt

SCOUT 为视觉文档搜索设计级联双通路：轻量检索器缩小候选集，强多向量模型只对候选重排，另一路检索离线生成的页级与文档级摘要。通过跨模态查询细化融合语义信号，在四个基准、六个基线的对比中，作者报告最高 80.7 倍、平均 28.8 倍查询加速，NDCG 最多提高 7.8%。

INSIGHT社区搜索若包含图文帖子、截图与表格，可借鉴先粗召回再做昂贵局部交互的设计，避免对全库运行多向量匹配。应将摘要生成成本计入离线预算，单独测量文本帖子与视觉帖子的召回效果；论文加速针对其视觉文档基线，不能直接换算为现有短文本链路收益。

Diana Turmakhan, Aseem Srivastava, Vivek Gupta, Iryna Gurevych, Thamar Solorio

Reading the Neighborhood: Text-Attentive Graph Reranking for Automated Subject Indexing

ZZBWKiel University

TAGHN 针对主题标引的长尾标签问题，在初步召回的候选标签周围构建异构子图，并用文档条件化消息传递结合标签邻域与文本匹配。STW 包含 6198 个描述词，模型宏平均 F1 达到 0.380，高于微调交叉编码器的 0.346 和固定词表分类器的 0.278，体现关系结构对稀有标签的补充作用。

INSIGHT对带话题体系的社区内容，可以尝试用标签邻域增强召回后的消歧与重排，尤其适合稀有主题缺少训练样本的情况。其任务是多标签标引，F1 不等同于搜索 nDCG；迁移前应先验证话题图的边是否可靠，并控制子图大小、重排延迟及热门话题偏置。

Lakshmi Rajendram Bashyam, Ralf Krestel

Reference Wording Shapes Retrieval of Robot Task Instructions

论文研究机器人任务描述的措辞如何影响短指令检索，从 62 个任务文件提取 296 条固定描述，在 80 次随机索引描述选择下比较五种无需训练的词法排序器。字符 n-gram TF-IDF 的平均 top-1 准确率为 61.3%，BM25 为 55.6%；增加第二条索引描述后，字符方法再提高 7.0 个百分点。

INSIGHT对 UGC 短查询，索引侧保留多种自然表达可能比立即替换大模型更值得低成本试验。可围绕别名、错别字和口语变体比较字符检索与 BM25，并固定同一批查询进行配对评估；机器人指令词汇较受控，其收益不能直接外推到开放社区，需要核查歧义和反向意图错误。

Jahnavi Yelamanchi

FASHION-RQ: Mining Hierarchical Semantic Structure for Automated Evaluation of Fashion Retrieval

Glance

FASHION-RQ 利用 RQ-VAE 的分层语义簇自动生成时尚搜索查询与相关集合，以排序、相关性分类、近邻区分和改写鲁棒性四类任务评价检索。基准包含 588 个簇、5380 条扩展查询；Qwen3-Embedding-4B 的 nDCG@10 为 0.8719，BM25 为 0.7736，展示了细粒度语义评测的区分能力。

INSIGHT可将社区话题、实体和内容簇用于构造长尾检索测试，但生成查询与相关性标签必须有独立人工抽检，防止聚类模型决定评测答案。论文中更大模型并非总能胜出，说明应依据真实 UGC 查询选择模型；代码与数据仍属待发布承诺，当前不能按已完整开源计分。

Tripti Shukla, Shwetha Somasundaram, Akshat Gupta, Rohit Garg, Paul Duff, Ian Anderson

VL-DocIR: A Benchmark for Vision-Based Long Document Information Retrieval

已录用 NeurIPS 2026KKIT

VL-DocIR 将视觉文档检索的目标从找到单页扩展为找齐回答问题所需的全部证据。数据覆盖 29641 篇文档、388548 张页面图像和 271760 条查询，包含 23 个领域及六种证据结构，并将证据关联到渲染页面与 HTML 元素，以区分单页、多页和跨文档检索难度。

INSIGHT社区多图长帖或跨帖问答不宜只看首个相关结果，可增加证据完整率及多段信息覆盖指标。该基准适合检验切页、分块和上下文聚合，但其长文档分布与短文本搜索不同；上述数字是数据规模，不是模型效果提升，仍需用真实社区查询建立独立评测集。

Adaptive hybrid AI-based retrieval-augmented generation for construction and seismic regulatory question answering

AHRM 面向乌兹别克建筑与抗震法规，将规则、BM25 和 Sentence-BERT 检索按查询类型自适应融合。作者在 120 份法规、约 85000 个文本块上报告 Precision@3 为 0.88、MRR 为 0.85、回答准确率为 91%；0.6 毫秒仅指过滤后候选池的索引搜索，不包含查询编码与生成。

INSIGHT社区搜索中的型号、专有名词和数字条件可采用精确规则与语义检索互补，先识别查询类型再调整融合权重。此文属于单领域工程验证，应保留跨域泛化疑问；评估时需报告端到端 P95 延迟、过滤造成的漏召回及真实相关性收益，不能把索引耗时当成用户等待时间。

Haystack Europe 2026: the bleeding edge of retrieval engineering

这篇亲历会议笔记整理 Haystack Europe 的检索工程实践：会议持续两天、约 120 位参会者，Netflix、S&P Global、Leroy Merlin 与 Coveo 的分享都涉及稠密和稀疏召回及 RRF 融合。文中强调人类短查询与代理长查询分布不同，并讨论评测和嵌入表示；它未提供统一可比较的线上增益数字。

INSIGHT社区 UGC 可优先建立稀疏、稠密及混合召回的同集评测，按自然短查询与机器扩写查询分层分析，避免一种总体分数掩盖查询分布差异。笔记是工程经验线索，不能代替相关公司的实验报告；其中规模数字用于交代会议范围，不应当成方法性能证据。

Beyond Black Boxes: Visual Grounding for Text Embeddings

UUSTHB

论文把文本嵌入解码为拓扑草图，再编码视觉特征，检验这种表征能否帮助文本检索与解释。MS-COCO 上五个随机种子的实验中，SBERT 的 Top-5 为 58.23%，融合草图后为 59.59%，但草图单独使用仅为 45.62%；融合潜变量也有收益，显示改善未必来自图像本身。

INSIGHT对社区语义搜索，这项研究更适合用于分析辅助表征与融合机制，暂不支持替换现有文本编码器。复现时应保留潜变量和未训练草图对照，分别核算额外编码成本与 Top-1、Top-5 变化；只有在真实查询上获得稳定增益，才值得引入图像中间表示。

Slimane Larabi
