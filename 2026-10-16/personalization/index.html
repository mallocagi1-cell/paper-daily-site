Learning What to Keep: Transfer-Aware Personal Skill Learning from User Feedback

用户的一次纠正未必代表长期偏好，作者把反馈拆成小规则并学习保留哪些内容。训练分别奖励规则内容和保留决定，再联合优化后续回答；在个性化写作实验中，一个骨干模型比最强基线高1.61分。

Bridging the Topological Divide: Dual-Branch Graph Distillation with Semantic Priors for Robust Cold-Start Recommendation

HKUST (Guangzhou)📖 深度解读 · 8 分钟 →

新物品没有交互边，图推荐便无法从邻居获取兴趣信号。作者先用文本语义固定协同空间，再让独立学生网络学习表示方向，并在检索时恢复向量长度；Sports冷启动Recall@20比DropoutNet高20.8%。

INSIGHT向量方向与长度承担不同信息。语义能推断商品位置，却缺少交互频次决定的长度信息；分开学习并校准尺度，可减少新内容在混合候选池中因分数偏小被压制。

Revisiting Generative vs. Dense Retrieval: A Static Value Prior Reverses the Gap

Shopify

生成式召回的商业价值优势，可能来自热门物品而非更懂用户。作者把命中目标、最佳商品价值与整份列表价值分开比较，并为稠密召回加入静态价值先验；工业数据上的NDCG@50因此提高11.8%。

INSIGHT更好的单件商品价值，不等于整份候选列表更相关。比较召回架构时，把热门度先验固定为同一基线，再分别统计精确命中和替代商品相关性，能识别收益究竟来自个性化还是商品分布。

PersEvalBench: Can LLM Evaluators Judge Contextually Appropriate Use of Persona Information?

AmazonUIUCUCL

评估器可能记住用户历史，却判断错哪些偏好该用于当前回答。作者构造正确回答和受控错误配对，区分漏用、过用及状态误用；人工评估子集中，最强评估器仅识别63.9%的漏用错误。

INSIGHT个性化评估需要识别错误方向。漏用有效偏好与引用过期偏好会要求相反的修复，单个满意度分数容易混淆两者。对画像更新和搜索助手，可分别统计偏好遗漏与过期状态引用。

Learning Individual Scientific Taste with Privileged Hindsight Distillation

Tsinghua University

同一研究提案可能符合一人的口味，却不符合另一人的偏好。作者把共同评价维度与个人权衡分开学习，只在教师训练时使用后续科学证据；真实研究者偏好预测指标达到0.693。

INSIGHT先共享事实判断，再学习每个人如何权衡，能降低少量反馈下的画像学习负担。将来才出现的证据只能进入训练教师，不能泄漏给提案时的学生输入；这也适用于内容质量与个人兴趣的分离。

University of Waterloo

图推荐给出结果后，作者从真实计算路径中找出最有影响的邻居。模型利用线性传播分解推荐分数，并用未解释残差衡量解释保真度；Gowalla实验对每个设置抽取100个用户物品对。

Calibration and Risk-Budgeted Decisions with System One Models

看似概率的模型分数未必能直接当作可靠决策阈值。作者为保留文档等二元动作设置风险预算，并用有限样本检验挑选阈值；跨六个数据集，越过风险目标的设置比例为7.8%。

INSIGHT阈值需要匹配实际动作的失败代价。把不确定样本交给保守回退策略，并对自动放行子集单独核查遗漏风险，比只看整体校准曲线更接近排序系统的上线约束。

MgRec: Multi-granularity intent interaction based sequential recommendation method

用户下一次点击既受近期行为影响，也受更宽泛的意图影响。作者分别从行为序列和知识图谱提取两类信号，再动态融合，用于减轻热门偏置并改善推荐；出版社摘要未提供可核对的效果数字。

INSIGHT把细粒度偏好与粗粒度意图分开表示，能明确每路信息的作用。知识图谱负责商品关系，行为序列负责近期变化；摘要给出了机制，但没有足够数据判断其相对简单融合基线的收益。

Intern-Decision: Efficient Multimodal Decision Making with Autoregressive Masked Language Modeling

Shanghai AI LabSJTUFudan UniversityNTU

反复生成文字解释会拖慢闭集选择，作者让小模型一次输出多个字段及候选概率。训练把决策位置写入固定回答结构，推理保留单次因果前向；4B模型在七套任务上的平均准确率为90.02%。

INSIGHT有限候选决策可以单独建模，无需每次调用完整生成流程。候选概率便于阈值分流，但这组实验验证的是通用决策能力，不能把其准确率当成推荐CTR或搜索相关性收益。
