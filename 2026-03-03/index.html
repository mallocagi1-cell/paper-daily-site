Unlocking Scaling Law in Industrial Recommendation Systems with a Three-step Paradigm based Large User Model

提出三步范式的大用户模型 (LUM)，在保持与现有深度学习推荐基础设施兼容的同时，将模型扩展至 70 亿参数并验证 scaling law。

INSIGHT推荐系统的 scaling law 可以通过「三步走」策略来释放：先在现有 DL 推荐架构上渐进扩展，而非直接照搬端到端生成式方案。LUM 在 7B 参数下仍持续获得性能提升，超越传统 DL 模型和纯生成式方案。

业务关联对于社区搜索的排序模型，LUM 表明渐进式 scaling 比激进的端到端改造更可行——可在现有排序架构基础上逐步增大模型规模来提升 nDCG/CTR。

证据模型规模扩展至 7B 参数仍保持性能增长；工业级 A/B 测试结果正向，超越传统 DL 推荐模型和生成式推荐方案。

RAD-DPO: Robust Adaptive Denoising Direct Preference Optimization for Generative Retrieval in E-commerce

针对电商生成式检索中 DPO 的三个核心问题（梯度冲突、噪声脆弱、多标签挤压），提出 RAD-DPO 进行鲁棒偏好对齐。

INSIGHT将 DPO 直接应用于 Semantic ID 解码会遇到层级前缀梯度冲突、隐式反馈噪声和多标签概率挤压三大问题。RAD-DPO 通过 token 级梯度保护、动态奖励加权和全局对比目标逐一化解。

业务关联社区搜索场景中，基于 Semantic ID 的生成式检索正成为新范式。RAD-DPO 解决的偏好对齐问题直接关系到搜索结果与用户意图的匹配度（nDCG 提升）。

证据在大规模电商平台上通过离线评估和线上 A/B 测试验证了排序质量和训练效率的显著提升。

Generating Long Semantic IDs in Parallel for Recommendation

提出 RPG 框架，通过独立 token 预测 + 图引导解码，实现 Semantic ID 的并行生成，大幅提升推理效率。

INSIGHT生成式推荐中 Semantic ID 越长表征越精确，但自回归解码延迟也线性增长。RPG 将训练时 token 独立预测、推理时图引导约束相结合，可并行生成 64-token 长 ID，同时保证有效性。

业务关联在社区搜索中部署生成式召回时，推理延迟是主要瓶颈。RPG 的并行生成策略可在不损失召回质量的前提下大幅降低线上延迟，适合高 QPS 场景。

证据将 Semantic ID 长度扩展至 64 tokens 后，NDCG@10 比生成式基线提升约 12.6%；推理效率显著优于自回归方案。已被 KDD 2025 接收，代码已开源。

Pre-training Generative Recommender with Multi-Identifier Item Tokenization

提出 MTGRec，利用多标识符 item tokenization 和课程式预训练策略改善生成式推荐模型的 item 表征和泛化能力。

INSIGHT单一标识符对低频 item 建模不充分且限制了训练数据多样性。使用多个 RQ-VAE checkpoint 为每个 item 生成多组标识符，配合影响估计驱动的课程采样策略，可显著提升生成式推荐效果和可扩展性。

业务关联社区搜索中 UGC 内容存在大量长尾低频帖子，MTGRec 的多标识符策略可改善这类长尾内容的召回质量。课程预训练策略也可降低生成式模型的训练成本。

证据在 3 个基准数据集上显著优于传统推荐和生成式推荐基线，在效果和可扩展性两方面均有提升。

Bowen Zheng, Enze Liu, Zhongfu Chen, Zhongrui Ma, Yue Wang, Wayne Xin Zhao, Ji-Rong Wen

Scaling Sparse and Dense Retrieval in Decoder-Only LLMs

系统研究 decoder-only LLM 在稀疏和稠密检索中的 scaling 行为，涵盖对比学习、知识蒸馏等多种优化范式。

INSIGHT不同检索范式在 decoder-only LLM 上的 scaling 行为差异显著：知识蒸馏和列表式训练的 scaling 效率优于纯对比学习。这为选择检索模型的训练策略提供了直接指导。

业务关联社区搜索的召回/排序模型如果采用 decoder-only LLM 架构，该研究可直接指导模型规模和训练策略的选择，帮助在算力预算内最大化 nDCG 收益。

证据在多种检索范式上对比了不同模型规模的性能曲线，发现稠密检索 + 对比学习之外的优化方法（蒸馏、列表式训练）scaling 效率更高。

Graph Retrieval-Augmented LLM for Conversational Recommendation Systems

提出 G-CRS，通过图检索增强 + 上下文学习的免训练框架实现 LLM 对话式推荐，避免幻觉和领域微调成本。

INSIGHT对话式推荐中 LLM 的知识稀疏和幻觉问题可通过图结构的协同信号来缓解：用 GNN + Personalized PageRank 先检索候选和相似用户，再以结构化 prompt 引导 LLM 推荐。全程无需训练。

业务关联社区平台的搜索日趋对话化，G-CRS 的免训练方案可快速部署 LLM 对话式推荐能力，利用已有用户交互图提升推荐准确性，降低冷启动阶段的幻觉风险。

证据在公开对话推荐数据集上超过现有方法。采用两阶段 retrieve-and-recommend 架构，利用 GNN + PPR 检索候选和相似用户。

Zhangchi Qiu, Linhao Luo, Zicheng Zhao, Shirui Pan, Alan Wee-Chung Liew

Collaborative Retrieval for Large Language Model-based Conversational Recommender Systems

提出 CRAG，首次将协同过滤与 LLM 结合用于对话式推荐，解决 LLM 推荐幻觉和行为数据缺失问题。

INSIGHTLLM 对话推荐的核心瓶颈在于缺乏行为协同信号，导致幻觉和个性化不足。CRAG 通过将协同过滤检索结果注入 LLM 上下文，实现了语义理解与行为模式的互补，尤其在新上映电影推荐上效果突出。

业务关联在社区搜索中，用户搜索意图往往需要结合行为历史来理解。CRAG 的思路——将协同过滤信号注入 LLM——可用于增强搜索 query 理解和结果个性化排序。

证据在 Reddit-v2 和 Redial 两个电影推荐数据集上验证，item coverage 和推荐准确率均有提升，新上映电影推荐效果提升最为显著。

Yaochen Zhu, Chao Wan, Harald Steck, Dawen Liang, Yesu Feng, Nathan Kallus, Jundong Li
