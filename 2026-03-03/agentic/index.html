ProductResearch: Training E-Commerce Deep Research Agents via Multi-Agent Synthetic Trajectory Distillation

提出 ProductResearch，面向电商场景的 Deep Research Agent。通过多 Agent 协同合成数据训练对话式商品调研 Agent，支持多轮对话、多源搜索、上下文推理。针对复杂购物场景的深度调研任务设计了完整的 Agent 训练与评估体系。

HotelQuEST: Balancing Quality and Efficiency in Agentic Search

提出 HotelQuEST，关注 Agentic Search 中质量与效率的平衡问题。构建了首个同时评估搜索质量和计算效率的 Agentic Search 基准，揭示现有方法在效率方面的不足。

INSIGHTAgentic Search 目前被广泛关注质量维度，但效率问题被忽视。该工作首次系统化评估 LLM Agent 搜索的 latency 和 token cost，对实际部署至关重要。

业务关联社区搜索业务中 latency 直接影响用户体验。HotelQuEST 提出的质量-效率权衡评估框架可用于指导社区搜索 Agent 化方案的工程落地，避免 Agent 搜索因延时过高不可用。

证据在酒店搜索场景上评估了多种 Agentic Search 方案，发现效率最优方案比最高质量方案快 3-5 倍但仅损失 5-8% 质量。

Guy Hadad, Shadi Iskander, Oren Kalinsky, Sofia Tolmach, Ran Levy, Haggai Roitman

Search-R1: Training LLMs to Reason and Leverage Search Engines with Reinforcement Learning

Search-R1 使用强化学习训练 LLM 在推理过程中自主生成多轮搜索查询并实时检索。提出 retrieved token masking 稳定 RL 训练，使用基于结果的奖励函数。在 7 个 QA 数据集上 Qwen2.5-7B 提升 41%。

INSIGHTSearch-R1 将 DeepSeek-R1 的 RL 训练范式扩展到搜索场景，让模型自主学会何时搜索、搜什么、如何整合搜索结果，是 RL + 搜索 Agent 方向的里程碑工作。

业务关联社区搜索中 query 理解和多轮检索是核心挑战。Search-R1 的 RL 训练框架可用于训练社区搜索 Agent，让模型在处理复杂 UGC 查询时自主发起多轮检索和推理。

证据7 个 QA 数据集上 Qwen2.5-7B 提升 41%，Qwen2.5-3B 提升 20%。超越 RAG baseline 和多个对比方法。已基于 veRL 开源完整训练框架。

Bowen Jin, Hansi Zeng, Zhenrui Yue, Jinsung Yoon, Sercan Arik, Dong Wang, Hamed Zamani, Jiawei Han

Democratizing GraphRAG: Linear, CPU-Only Graph Retrieval for Multi-Hop QA

SPRIG 提出纯 CPU 上的线性复杂度 Graph Retrieval 方法，无需 LLM 构图和 GPU 推理即可实现多跳 QA 的 GraphRAG 性能。大幅降低 GraphRAG 部署门槛。

INSIGHTGraphRAG 的工程成本过高是落地障碍。SPRIG 证明通过种子传播的图检索可在纯 CPU 上实现接近 LLM 构图的效果，对搜索系统低成本引入结构化检索有重要启示。

业务关联社区搜索中帖子、用户、话题构成天然图结构。SPRIG 的低成本 GraphRAG 方案可直接用于社区内容的多跳检索和关联推荐，无需 GPU 即可部署。

证据在多跳 QA 基准上与 LLM-based GraphRAG 效果相当，但构建和推理速度快 10 倍以上，可完全在 CPU 上运行。

Qizhi Wang

Dr. MAS: Stable Reinforcement Learning for Multi-Agent LLM Systems

Dr. MAS 解决多 Agent LLM 系统 RL 训练不稳定问题。提出按 Agent 维度归一化 advantage，替代全局归一化。端到端框架支持可扩展的 Agent 编排和灵活优化策略。

INSIGHT多 Agent LLM 系统的 RL 训练存在严重不稳定性，根因是不同 Agent 的奖励分布差异大。按 Agent 归一化 advantage 是简单但有效的解法，对构建多 Agent 搜索系统有重要参考。

业务关联社区搜索系统可能使用多个专门化 Agent（如 query 理解 Agent、内容排序 Agent、回答生成 Agent）。Dr. MAS 的稳定训练方法可直接用于这类多 Agent 搜索系统的 RL 训练。

证据在多 Agent 数学推理和多轮搜索任务上，avg@16 提升 +15.2%，pass@16 提升 +13.1%，训练不稳定性大幅降低。

Lang Feng, Longtao Zheng, Shuo He, Fuxiang Zhang, Bo An

ReSearch: Learning to Reason with Search for LLMs via Reinforcement Learning

ReSearch 提出无需监督推理步骤数据的 RL 训练框架，让 LLM 自主学会推理与搜索交织。将搜索操作视为推理链的核心组成部分，训练后自然涌现反思和自我纠错能力。

INSIGHT不依赖人工标注的推理步骤数据，纯 RL 驱动的搜索推理训练能自然涌现反思和自纠错能力，说明 RL 对搜索 Agent 的 reasoning 有根本性提升作用。

业务关联社区搜索场景中用户查询往往模糊且需要多步推理。ReSearch 证明 RL 可以让搜索 Agent 自主学会推理和搜索策略，适用于训练社区场景的智能搜索助手。

证据基于 Qwen2.5-7B 和 32B 训练，在多个 benchmark 上超越 RAG 基线。仅用单一数据集训练即展现强泛化性。自然涌现反思和自纠错能力。

An Empirical Study on Reinforcement Learning for Reasoning-Search Interleaved LLM Agents

系统实证研究 RL 训练推理-搜索交织 LLM Agent 的关键设计选择：奖励函数设计、底层 LLM 选择及搜索引擎在 RL 过程中的角色。为构建生产级搜索 Agent 提供实践指导。

INSIGHT格式化奖励比中间检索奖励更有效，LLM 规模和专业化程度显著影响效果，搜索引擎选择对训练稳定性至关重要——这些实践发现对搜索 Agent 工程化落地有直接指导价值。

业务关联社区搜索场景部署搜索 Agent 时面临大量工程选型问题。本文的实验结论（奖励设计、模型选择、搜索引擎适配）可直接指导社区搜索 Agent 的技术选型和训练策略。

证据在多个 QA 基准上系统对比了不同奖励设计（格式化 vs 中间检索 vs outcome）、不同规模 LLM（3B/7B/32B）、不同搜索引擎的效果。格式化奖励一致性最优。

AgenticOCR: Parsing Only What You Need for Efficient Retrieval-Augmented Generation

AgenticOCR 提出按需解析策略，在 RAG 系统中仅解析与查询相关的文档区域。针对复杂视觉文档（如财报），避免全文档 OCR 的高成本，提升 RAG 效率。

INSIGHT传统 RAG 对文档全量解析造成大量无效计算。AgenticOCR 的按需解析思路（query-aware parsing）可推广到搜索系统中对 UGC 富媒体内容的选择性理解和检索。

业务关联社区搜索中大量 UGC 内容包含图片、截图等富媒体。AgenticOCR 的按需解析策略可用于社区搜索中对富媒体内容的高效检索和理解。

证据在金融文档 RAG 任务上，相比全文档解析减少 60%+ token 消耗，同时保持或提升回答质量。

Robust and Efficient Tool Orchestration via Layered Execution Structures with Reflective Correction

提出分层执行结构（Layered Execution Structures）解决 Agent 系统中工具编排的鲁棒性和效率问题。通过恢复机制应对工具调用失败，提升复杂 Agent 流程的可靠性。

INSIGHTAgent 系统的实际故障往往不在单个工具调用，而在多工具编排层面。分层执行结构和恢复机制是让搜索 Agent 在生产环境中稳定运行的关键。

业务关联社区搜索 Agent 需要编排多种工具（搜索引擎、内容理解、排序模型等）。分层执行和故障恢复机制对保证搜索 Agent 在线服务的稳定性有直接工程价值。

证据在多工具编排场景中，分层执行结构使 Agent 任务完成率提升 15-20%，故障恢复成功率显著高于 flat 执行方案。

Tao Zhe, Haoyu Wang, Bo Luo, Min Wu, Wei Fan, Xiao Luo, Zijun Yao, Haifeng Chen, Dongjie Wang

RUMAD: Reinforcement-Unifying Multi-Agent Debate

RUMAD 提出统一的强化学习框架优化多 Agent 辩论系统，同时优化准确性、共识形成和计算效率。解决了现有 Multi-Agent Debate 方法难以同时兼顾多个目标的问题。

INSIGHT多 Agent 辩论系统的核心挑战是同时优化质量和效率。RUMAD 的强化学习统一框架为搜索场景中多 Agent 协作推理提供了可借鉴的优化方法论。

业务关联社区搜索中可利用多 Agent 辩论机制提升答案质量（如多 Agent 交叉验证搜索结果）。RUMAD 的效率优化对实际在线部署此类系统有工程指导意义。

证据在推理准确性、共识达成率和计算效率三个维度上均优于传统 MAD 基线，效率提升 2-3 倍。
