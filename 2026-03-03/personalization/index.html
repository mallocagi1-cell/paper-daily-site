Rethinking Multi-objective Ranking Ensemble in Recommender System: From Score Fusion to Rank Consistency

提出 HarmonRank 框架，将多目标排序融合重新定义为排名一致性优化问题，实现端到端可微的多目标排序集成。

KEY INSIGHT · 对业务意味着什么多目标排序不应简单加权融合分数，而应从各目标排名的一致性出发，让分数对齐标签排名的共性方向，对 label skew 场景更鲁棒。业务关联 社区搜索中排序通常需要同时优化 CTR、相关性、内容质量等多个目标，HarmonRank 的排名一致性方法可直接替换现有加权融合策略，提升多目标排序效果。证据 在快手直播电商推荐平台（4 亿 DAU）上线，购买转化提升 2.6%；在两个工业数据集上显著优于现有 SOTA 多目标集成方法，且对 label skew 情况表现出更强鲁棒性。

MLPlatt: Simple Calibration Framework for Ranking Models

提出 MLPlatt 校准框架，将排序模型输出转化为可解释的 CTR 概率，同时保持排序顺序不变。

INSIGHT后校准 (post-hoc calibration) 不必牺牲排序质量——MLPlatt 在保序的前提下实现分层 context-aware 校准，可直接应用于下游出价和预算分配。

业务关联社区搜索的排序模型通常输出分数而非校准概率，MLPlatt 可作为即插即用的后处理模块将排序分数转为真实 CTR 预估，支撑广告出价和流量分配决策。

证据在电商相关性排序数据集上 F-ECE（Field Expected Calibration Error）相比其他校准方法改善超过 10%，同时排序指标无损。

Piotr Bajger, Roman Dusek, Krzysztof Galias, Pawel Mlyniec, Aleksander Wawer, Pawel Zawistowski

Recommending Search Filters To Improve Conversions At Airbnb

Airbnb 构建搜索过滤器推荐系统，通过 ML 模型预测并推荐最可能促进转化的搜索筛选条件。

INSIGHT搜索过滤器不仅是用户工具，还可作为排序信号——通过主动推荐过滤器引导用户缩小搜索范围，可显著提升下漏斗转化率。

业务关联社区搜索同样面临搜索结果过多导致决策困难的问题，借鉴 Airbnb 的过滤器推荐思路，可通过推荐标签/筛选条件帮助用户快速找到目标内容，提升点击和互动率。

证据Airbnb 生产环境 A/B 测试验证，系统从零构建并上线，解决了冷启动和严格服务延迟等挑战，实现了预订转化率的显著提升。

Hao Li, Kedar Bellare, Siyu Yang, Sherry Chen, Liwei He, Stephanie Moyerman, Sanjeev Katariya

Unified Learning-to-Rank for Multi-Channel Retrieval in Large-Scale E-Commerce Search

将多路召回融合重新建模为 query-dependent 的 Learning-to-Rank 问题，统一处理异构召回通道的排序。

INSIGHT传统 RRF 和加权交错融合使用固定全局权重且忽略通道间交互，将多路融合建模为 LTR 问题后可学习 query-specific 的通道偏好和跨通道交互，效果显著优于规则融合。

业务关联社区搜索通常依赖多路召回（语义、倒排、向量等），该方法可替换现有的启发式融排策略，实现 query 级别的自适应多路融合，在严格延迟约束下优化转化指标。

证据在大规模电商搜索系统上验证，统一 LTR 模型在满足严格延迟约束的同时优化了用户转化等业务 KPI，优于 RRF 和 Weighted Interleaving 等基线。

Aditya Gaydhani, Guangyue Xu, Dhanush Kamath, Ankit Singh, Alex Li

FuXi-Linear: Unleashing the Power of Linear Attention in Long-term Time-aware Sequential Recommendation

提出 FuXi-Linear，用线性复杂度注意力实现长序列时间感知的序列推荐，解决传统 Transformer 的二次复杂度瓶颈。

INSIGHT将时间信号和语义信号分离到独立通道（Temporal Retention Channel）可避免相互干扰，同时线性注意力使得模型能处理超长用户行为序列且推理速度大幅提升。

业务关联社区搜索中用户的浏览历史可以很长，传统 Transformer 推理成本高；FuXi-Linear 的线性复杂度方案可以在保持推荐质量的同时显著降低长序列用户建模的推理延迟。

证据在多个公开数据集上验证，FuXi-Linear 在长序列场景下持续优于标准 Transformer 基线，同时推理复杂度从 O(n²) 降至 O(n)，支持深层架构堆叠。

Yufei Ye, Wei Guo, Hao Wang, Luankang Zhang, Heng Chang, Hong Zhu, Yuyang Ye, Yong Liu, Defu Lian 等 10 人

Towards Efficient and Generalizable Retrieval: Adaptive Semantic Quantization and Residual Knowledge Transfer

提出 SA²CRQ 框架，通过自适应残差量化和锚定课程学习，解决 Semantic ID 检索中头部碰撞和尾部冷启动问题。

INSIGHT根据 item 路径熵动态分配编码长度——头部 item 用长且可区分的 ID，尾部 item 用短且可泛化的 ID，兼顾精确匹配和冷启动泛化。

业务关联社区搜索中新发布帖子的冷启动问题突出，SA²CRQ 的自适应编码策略可为新内容分配合理的语义表征，利用头部内容的语义流形加速尾部内容的表征学习。

证据在大规模工业数据集上验证，自适应量化策略显著减少头部 ID 碰撞并改善尾部冷启动 item 的检索召回率，课程学习加速收敛。

Cross-Representation Knowledge Transfer for Improved Sequential Recommendations

提出结合 Transformer 和 GNN 的序列推荐框架，通过跨表征知识对齐同时编码结构依赖和时序演化。

INSIGHTTransformer 擅长时序但忽略 item 间复杂关系，GNN 擅长结构但缺乏时序建模——对齐两种表征可兼得两者优势，对 next-item 预测持续有效。

业务关联社区搜索中用户的浏览-点击-交互序列既有时序特征又有内容关联结构，该框架可用于提升用户兴趣建模的准确性，改善个性化搜索排序。

证据在多个公开序列推荐数据集上评估，所提框架在 next-item 预测任务上一致优于纯 Transformer 和纯 GNN 基线方法。

Beyond the Click: A Framework for Inferring Cognitive Traces in Search

提出从搜索行为日志中推断用户认知轨迹的框架，利用多 Agent 系统和信息觅食理论标注用户思维过程。

INSIGHT行为日志只记录用户做了什么，不记录用户在想什么——通过推断困惑、满意度等认知状态，可构建更拟人的用户模拟器并改善搜索系统评估。

业务关联社区搜索评估通常依赖点击率等显式信号，该框架提供的认知轨迹标注工具可帮助理解用户搜索中的困惑点和满意度变化，指导搜索体验优化。

证据在 AOL 和 Stack Overflow 等公开数据集上验证，认知轨迹标注提升了会话结果预测和用户困难恢复任务的模型表现；开源标注工具和数据集。

U-CAN: Utility-Aware Contrastive Attenuation for Efficient Unlearning in Generative Recommendation

提出 U-CAN 精准遗忘框架，在 LoRA 适配器上通过对比激活衰减实现推荐模型中敏感属性的高效遗忘。

INSIGHTLLM 推荐模型的神经元存在多义困境（同时编码敏感数据和通用推理），U-CAN 通过对比遗忘集和保留集的激活不对称性精准定位风险神经元，避免传统梯度方法的灾难性效用损失。

业务关联社区平台用户隐私要求日益严格（如 GDPR 遗忘权），U-CAN 的精准遗忘能力可在满足合规要求的同时最大限度保持推荐模型的服务质量。

证据在生成式推荐基准上验证，U-CAN 在保持推荐效用的前提下成功遗忘目标敏感属性，效用损失显著低于传统梯度上升和剪枝方法。

Zezheng Wu, Rui Wang, Xinghe Cheng, Yang Shao, Qing Yang, Jiapu Wang, Jingwei Zhang

LLM-Enhanced Multimodal Fusion for Cross-Domain Sequential Recommendation

提出 LLM-EMF，利用大语言模型增强文本信息并融合视觉和文本模态，提升跨域序列推荐性能。

INSIGHT用冻结 CLIP 生成图文 embedding 并通过多注意力机制联合学习单域和跨域偏好，可有效捕获用户在不同内容领域间的兴趣迁移模式。

业务关联社区平台通常包含多种内容形态（图文帖子、视频、问答），LLM-EMF 的跨域多模态融合方案可帮助建模用户在不同内容类型间的兴趣偏好迁移。

证据在 4 个电商数据集上评估，LLM-EMF 在跨域序列推荐任务上一致优于现有 CDSR 基线方法，LLM 增强的文本表征带来显著的增量收益。
