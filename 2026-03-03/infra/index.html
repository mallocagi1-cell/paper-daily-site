veScale-FSDP: Flexible and High-Performance FSDP at Scale

重新设计了 Fully Sharded Data Parallel (FSDP) 系统，提出 RaggedShard 灵活分片格式和结构感知规划算法，原生支持 block-wise 量化训练和 Shampoo/Muon 等非逐元素优化器，解决了传统 FSDP 在大规模训练中灵活性和性能的瓶颈。

LlamaRL: A Distributed Asynchronous Reinforcement Learning Framework for Efficient Large-scale LLM Training

Meta 开源的全分布式异步强化学习框架，基于原生 PyTorch 实现单控制器架构，支持 8B 到 405B 参数模型在数千 GPU 上的 RLHF/RL 训练。提供了异步设计严格加速的理论证明。

INSIGHTLlamaRL 是 Llama 3 后训练中实际使用的 RL 框架，其单控制器 + 异步设计在工程上极具参考价值；对搜索排序模型的 RLHF 训练也可直接复用。

业务关联搜索排序模型越来越多地采用 RLHF/RLEF 进行对齐训练，LlamaRL 的分布式异步架构可显著提升 RL 训练效率，减少 GPU 空闲等待。

证据在 Llama 3 后训练中实际应用，支持 8B/70B/405B 模型规模；理论证明异步设计带来严格加速；基于原生 PyTorch 可扩展到数千 GPU。

Preference Packing: Efficient Preference Optimization for Large Language Models

提出 preference packing 方法，通过减少 DPO/reward model 训练中重复输入 prompt 的 attention 计算和 KV cache 内存使用，实现训练资源效率提升。可与 batch sorting 等现有优化技术叠加使用。

INSIGHTDPO/reward model 训练数据中同一 prompt 对应多个 response，传统方法重复计算 prompt 部分的 attention；preference packing 消除了这一冗余，训练时间减少 37%+，叠加 batch sorting 可达 3.22 倍加速。

业务关联搜索排序模型的偏好训练（如 DPO 对齐）面临相同问题——同一 query 对应多个文档排序对；该技术可直接迁移到搜索场景的偏好学习训练中。

证据在纯文本和含图数据集上实验，训练时间至少减少 37%；结合 batch sorting 实现 3.22 倍加速；同时适用于 reward model 和 DPO 训练。

LK Losses: Direct Acceptance Rate Optimization for Speculative Decoding

提出 LK losses——直接优化 speculative decoding 接受率的训练目标，替代传统 KL 散度代理目标。在 4 种 draft 架构和 6 种 target 模型（8B 至 685B）上验证，一致性地提升接受率指标。

INSIGHT传统 speculative decoding 的 draft 模型训练用 KL 散度做代理目标，但容量有限的 draft 模型在次优解处 KL 最小并不等于接受率最大；LK losses 直接优化接受率，弥合了训练目标与实际效能的鸿沟。

业务关联LLM 在线推理延迟是搜索系统的关键瓶颈，speculative decoding 是降低延迟的主流方案；LK losses 可提升 draft 模型质量，进一步加速在线搜索响应。

证据跨 4 种 draft 架构（Medusa、Eagle 等）和 6 种 target 模型（8B-685B 含 DeepSeek-V3）的全面实验，在所有配置下接受率指标均优于标准 KL 训练。

AIConfigurator: Lightning-Fast Configuration Optimization for Multi-Framework LLM Serving

面向 TensorRT-LLM、vLLM 和 SGLang 三大推理框架的数据驱动配置优化工具包。通过将推理过程分解为基本操作并测量目标硬件上的延迟，快速找到最优推理配置。

INSIGHTLLM 推理配置（batch size、量化方式、并行策略等）对性能影响巨大但组合空间爆炸；AIConfigurator 通过操作级延迟建模实现快速配置搜索，免去大量手动调参。

业务关联搜索推荐系统的在线推理需要在延迟和吞吐之间精细平衡；AIConfigurator 可帮助团队快速在 vLLM/SGLang 等框架上找到最优配置，降低部署调优成本。

证据支持 TensorRT-LLM、vLLM、SGLang 三大主流推理框架；通过操作分解方法实现比传统网格搜索更快的配置优化；适用于不同硬件平台。

Data Driven Optimization of GPU Efficiency for Distributed LLM Adapter Serving

针对分布式 LLM adapter 服务场景，提出数据驱动的 GPU 效率优化方案。通过数字孪生模型学习真实服务行为，结合蒸馏 ML 模型和贪心放置算法，在保证无请求饥饿和显存安全的前提下最小化所需 GPU 数量。

INSIGHT当数百个 LLM adapter 并发部署时，adapter 缓存和调度的复杂性远超单模型服务；数字孪生方法可以精准预测每个 GPU 的最大可行吞吐量，从而实现最优 adapter 放置。

业务关联搜索推荐团队常为不同场景（召回、排序、NLU、摘要等）部署多个 adapter；该方法可显著降低多 adapter 并发服务的 GPU 成本，提升资源利用率。

证据集成三个组件：面向 LLM-adapter 服务的数字孪生、基于 DT 数据训练的蒸馏 ML 模型、贪心放置算法；在给定 workload 下最小化 GPU 使用数量，同时避免请求饥饿和显存溢出。

QuantSpec: Self-Speculative Decoding with Hierarchical Quantized KV Cache

提出自推测解码框架 QuantSpec，draft 模型与 target 模型共享架构，但使用分层 4-bit 量化 KV cache 和 4-bit 量化权重进行加速。保持 >90% 接受率的同时实现 ~2.5 倍端到端加速。

INSIGHT传统 speculative decoding 需要额外的 draft 模型增加部署复杂度；QuantSpec 让 target 模型自身的量化版本作为 draft，既省去额外模型又通过分层量化 KV cache 同时节省内存。

业务关联搜索系统 LLM 推理的延迟和内存是核心瓶颈；QuantSpec 无需额外 draft 模型即可实现 2.5 倍加速和 1.3 倍内存节省，部署复杂度低，适合在线搜索场景。

证据接受率保持 >90%；端到端推理加速 ~2.5 倍；内存需求降低 ~1.3 倍；无需训练额外 draft 模型。

Semantic Parallelism: Redefining Efficient MoE Inference via Model-Data Co-Scheduling

提出 Semantic Parallelism 新型并行范式，通过模型-数据协同调度最小化 MoE 推理中 expert parallelism 的通信开销。实现框架 Sem-MoE 将 expert 和其激活 token 尽量放置在同一设备上，大幅减少跨设备 all-to-all 通信。

INSIGHT当前 MoE 推理的 expert parallelism 将 expert 放置和 token 调度视为独立问题，导致大量不必要的跨设备通信；Semantic Parallelism 统一考虑两者，通过建模 token-expert 亲和性实现联合优化。

业务关联DeepSeek-V3 等 MoE 模型在搜索排序中日益普及，推理通信成本是部署的主要瓶颈；Sem-MoE 框架可直接应用于降低 MoE 模型在线服务的通信延迟和成本。

证据在 DeepSeek-V3 等大规模 MoE 模型上验证，通过主动建模 token-expert 激活模式减少跨设备通信；v5 版本经过多轮修改完善。

MoSE: Mixture of Slimmable Experts for Efficient and Adaptive Language Models

为 MoE 层引入可伸缩宽度（slimmable widths），使得不仅可以选择激活哪些 expert，还可以动态调整每个激活 expert 的内部容量，在部署时提供额外的计算资源分配自由度。

INSIGHT传统 MoE 的路由只选择「用哪些 expert」，expert 容量固定；MoSE 增加了「每个 expert 用多少容量」这一维度，让同一模型在不同部署场景下可以灵活调整效率-精度平衡。

业务关联搜索推荐系统需要在高峰期和低谷期动态调整模型计算量；MoSE 的自适应 expert 容量机制可实现一个模型多种计算预算的弹性部署。

证据MoSE 在 MoE 层上实现条件计算的两个维度（expert 选择 + 容量调整），在部署时无需重新训练即可适配不同计算预算。

Taming Momentum: Rethinking Optimizer States Through Low-Rank Approximation

将 Adam/Muon 等优化器中的指数移动平均重新理解为在线线性回归器的训练，在此基础上提出 LoRA-Pre——一种面向预训练的低秩优化器。通过将动量矩阵分解到紧凑低秩子空间，大幅减少优化器内存占用。

INSIGHTAdam 等优化器的一阶和二阶动量带来巨大内存开销（通常是模型参数的 2-3 倍）；LoRA-Pre 将动量矩阵低秩分解，在保持优化性能的同时显著降低内存需求，使更大模型的训练成为可能。

业务关联搜索排序模型的参数规模持续增长，优化器内存已成为训练瓶颈；LoRA-Pre 可让同样的 GPU 资源训练更大的模型，或降低现有模型的训练成本。

证据在 Llama 架构系列（60M 到 1B 参数）上验证，LoRA-Pre 在所有规模上达到最高性能；内存占用显著减少的同时保持优化质量。
