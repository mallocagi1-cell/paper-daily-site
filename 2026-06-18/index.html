Understanding and Debugging Failures in N-Gram-Based Generative Retrieval

生成式检索 (Generative Retrieval, GR) 让模型直接生成相关文档的标识符 (docid)，但会带来传统检索没有的失败机制。本文做三件事：(1) 基于现有 GR 文献整理出一套 GR 失败模式分类法；(2) 针对 n-gram 类方法 SEAL 与 MINDER 做实证分析，发现 docid 歧义、生成标识符多样性低、个别标识符贡献过大等共性问题；(3) 发布一个基于 web 的工具，可视化生成的 n-gram 及其对最终排序的贡献，帮助定位 GR 在哪一步出错。

Non-negative Elastic Net Decoding for Information Retrieval

稠密检索按 query 与单个文档 embedding 的内积打分取 top-k，每个文档得分只依赖自身、忽略语料整体，导致召回结果语义冗余、缺乏多样性。本文把检索重构为一个联合解码问题：提出非负弹性网络 (Non-Negative elastic Net, NNN) 解码，挑选一组文档使其 embedding 作为稀疏非负线性组合共同重构 query embedding，从而在集合层面考虑文档之间的关系。论文给出主要理论分析并做了实验验证。

INSIGHT这是把'解码/生成'思路引入召回的代表性工作——不再逐个独立打分，而是把召回当成对整个候选集合的稀疏重构。社区 UGC 短文本搜索里近似帖子、重复内容扎堆是常见痛点，NNN 的集合级去冗余比事后去重更有理论依据，可作为召回多样性或重排阶段的新选项。

Koki Okajima, Yasutoshi Ida, Tsukasa Yoshida, Yasuaki Nakamura
