RSRank: Learning Relevance from Representational Shifts

针对 RAG 系统精排环节的相关性打分问题。现有 reranker 多用语言模型为 next-token 预测设计的 logit 信号判相关，并依赖启发式阈值过滤，二者都不是为相关性评估而设计。作者提出用「表征漂移 (representational shift, RS)」作为相关性信号：当 query 的内部表征以候选文档为条件被改写时会产生位移，候选文档诱导的 RS 与一个 oracle 文档集诱导的 RS 之间的对齐度，可作为稳健的相关性指示。基于该洞察构建 RSRank，把最终过滤「相关 vs 干扰/无关文档」从阈值经验值转为表征对齐度排序。

KEY INSIGHT · 对业务意味着什么把 reranker 的打分依据从「输出 logit」换成「query 隐状态在条件化文档后的位移方向」，是一个可直接迁移到社区搜索精排的新信号——它不要求生成式解码、可在 encoder 表征上计算，适合短文本精排的低延迟约束。oracle 文档集对齐的思路也提示：相关性可以相对一个参考集合来度量，而非孤立打分，对去除「语义相近但实际无关」的干扰文档有借鉴价值。

Temporal Preference Optimization for Unsupervised Retrieval

无监督稠密检索靠对比学习从无标注文档学语义相似度，扩展性好，但只抓语义、抓不住时间相关性：当语料跨多个时间段时，会召回语义相关但时间错位的文档（例：库里有 2018–2025 的文档，对「2019 年谁是总统」会引入时间歧义）。已有方法依赖带显式时间戳的有监督训练，并不总可行。作者提出 TPOUR (Temporal Preference Optimization for Unsupervised Retriever)，核心训练方法 TRPO (Temporal Retrieval Preference Optimization) 把偏好学习迁移到时间维度，引导检索器偏好时间对齐的文档。

INSIGHT把「偏好优化 (preference optimization)」这一套从对齐领域常见的范式搬到检索的时间维度，且全程无监督、不需人工时间戳标注，对社区搜索很对症——UGC 里时效性 query（热点、版本、赛事）大量存在，纯语义召回常把过期帖排上来。TRPO 的偏好对（时间对齐优于时间错位）构造思路，可直接用于在召回阶段注入时间敏感性，而不必单独训一个时间打分模型。

Beyond Parallel Sampling: Diverse Query Initialization for Agentic Search

Agentic search 的 test-time scaling 通常靠加深度（更多轮次/token）或加宽度（更多并行 rollout）。作者聚焦宽度扩展，指出标准并行采样收益递减，并把原因追溯到「首轮 query 冗余」：模型在多条 rollout 上发出相似的第一条 query，导致各线程检索到重叠证据，后续轮次都基于这份共享检索展开。为此提出 DivInit——一种 training-free 的首轮干预：不再独立采样 k 条首轮 query，而是从一次调用里抽 n 个候选，挑出 k<n 个多样化的种子再并行展开。

INSIGHT把「并行采样为什么不涨点」定位到首轮 query 同质化这一具体机制，是对召回多样性很实用的诊断。DivInit 完全训练无关、只在首轮做一次「抽 n 选 k」的多样化筛选即可，落地成本极低。对社区搜索的多路召回 / query 改写扩展同样适用：与其并行跑多条高度相似的改写 query，不如先在改写候选里做多样性挑选，避免多路召回退化成单路。

MODE-RAG: Manifold Outlier Diagnosis and Energy-based Retrieval-Augmented Generation Evaluation

多模态 RAG (M-RAG) 能增强视觉语言模型，但极易出现跨模态幻觉、因果臆造与谄媚 (sycophancy)。已有缓解管线常陷入「干预悖论」：静态规则会误伤本来正确的生成，完全不约束又会让错配级联成严重逻辑臆造。作者提出多智能体系统 MODE-RAG，用变分自由能 (Variational Free Energy, VFE) 与内部注意力状态动态决定何时干预：高风险 query 被路由到五个阶段专属 agent，结合蒙特卡洛树搜索 (MCTS) 做严格因果推导，并用 logit 扰动惩罚谄媚。

INSIGHT用变分自由能作为「这次检索增强生成是否高风险、要不要介入」的门控信号，是把 RAG 评估从离线指标推向在线动态质检的一种思路。对搜索里的 RAG 问答场景，VFE/注意力态作幻觉风险评分、再决定是否触发重检索或人工兜底，是可借鉴的风控设计。但五 agent + MCTS 的结构偏重，工程落地需权衡延迟与收益，短文本搜索场景宜取其门控思想而非整套管线。
