TSGR: Taobao Search Generative Retrieval

针对工业电商生成式检索只优化语义匹配、忽略商品业务价值的问题，TSGR 用查询感知的并行 Semantic ID 将价值次序写入编码，再以联合训练的价值感知排序模块统一召回与预排。淘宝离线 HR@1000 提升 9.16%，线上 A/B 实验带来 IPV +0.43%、成交数 +1.12%、GMV +1.64%。

02 4.60

Vectorizing the Trie: Efficient Constrained Decoding for LLM-based Generative Retrieval on Accelerators

Google

STATIC 面向 LLM 生成式检索的受限解码，把不规则 Trie 展平为 CSR 稀疏转移矩阵，使前缀约束能在 TPU/GPU 上完全向量化执行。它已部署到服务数十亿用户的视频推荐平台，每步仅增加 0.033 毫秒、占推理时间 0.25%，相对 CPU Trie 加速 948 倍，并开源实现。

INSIGHT严格业务约束不必牺牲生成式检索吞吐：把树遍历改写成静态稀疏矩阵运算，可将内容新鲜度、类目或合规白名单直接注入解码空间。社区搜推若采用 Semantic ID，可复用这一模式把在线候选约束留在加速器侧执行，避免 CPU-GPU 往返，并以极低额外时延支持冷启动和动态业务规则。

03 4.10

Topology-Aware Tokenization for Generative Recommendation

TopoTok 指出生成式推荐在量化商品向量时会破坏预训练语义空间的邻接拓扑，使模型误判商品相似性。它通过组间、组内和商品间三级蒸馏，从粗到细恢复量化层级中的关系结构；在 3 个基准数据集上持续超过现有分词器，Recall@5 最高提升 9.42%。

INSIGHTSemantic ID 的质量不只取决于重构误差，更取决于离散化后是否保留邻域关系；三级蒸馏把全局簇关系、簇内局部结构和商品级对齐分开监督，减少单一损失的盲区。对 UGC 短文本生成式召回，可优先监控量化前后近邻保持率，并将拓扑蒸馏加入内容 ID 构建流程。
