AutoIndex: Learning Representation Programs for Retrieval

论文把索引前的文档表示从固定预处理升级为可学习的“表示程序”，由智能体诊断失败样例并搜索切分、增强、归一化和重排等变换。在固定 BM25 的 CRUMB 八项任务上，Recall@100 与 nDCG@10 平均提升 8.4% 和 8.3%，最大提升达 30.5% 与 43.6%。

RAGAL: A Frugal, Fully Local Retrieval-Augmented Assistant for Technical Support at a Government Agency

AAFIR

RAGAL 在零数据外传、只读操作和单台 8GB 显存笔记本约束下处理约 2.5 万个罗马尼亚语知识块。混合稀疏—稠密召回与意图路由把内部评测从 62% 提到 81%；微调 bge-m3 仅用 72 分钟，使 Recall@10 从 0.663 升至 0.850。

INSIGHT真实系统的首要收益来自召回工程与分域评测，而非扩大生成模型；单域微调还可能让未覆盖文档域退化。对 UGC 搜索可按内容类型建立独立召回指标，采用混合召回和意图路由，并在新增训练数据后强制检查各域回归，避免平均指标掩盖长尾损失。

Dan Musetoiu

PLAID-PRF: Pseudo-Relevance Feedback with Centroid-like Tokens in PLAID

UUIBEUniversity of Glasgow

论文利用 PLAID 内部量化质心向量做伪相关反馈，从首轮结果中选取少量、多样且高效用的扩展向量追加到 ColBERT 查询，再执行第二轮召回与打分。在 MS MARCO 和四个 BEIR 域外基准上，相比 PLAID，nDCG@10 最高提升 4.3%，MRR@10 最高提升 7.3%。

INSIGHT该方法把传统 PRF 的“扩展词”替换为索引已有的质心向量，避免查询时聚类文档 token 的重成本。社区搜索可针对短 query 和别名表达，在 late-interaction 召回中复用量化中心做轻量二次扩召回，同时限制扩展向量的数量与相似性以控制漂移。

Xiao Wang, Sean MacAvaney, Craig Macdonald

Improving Neural Retrieval with Attribution-Guided Query Rewriting

IIRITUniversité de Toulouse

方法对首轮前五篇文档计算梯度式 token 归因，把完整查询及归因分数作为软提示交给 Mistral-7B-Instruct 一次性改写，无需重训检索器。在 BEIR 上，SPLADE 的 nDCG@10 相对原查询最高提升 9%、相对普通 LLM 改写提升 22%；TCT-ColBERT 对应最高提升 10% 和 16%。

INSIGHTLLM 改写若不知道现有召回器被哪些词误导，容易产生无效同义改写或语义漂移；把检索器归因作为软约束能形成闭环。线上可先在低召回、低置信 query 上触发该流程，并保留原 query 双路召回，以小流量验证收益和额外延迟。

Moncef Garouani, Josiane Mothe

Fusion Embedding: A Unified Embedding Space for Text, Image, Video, and Audio

EEximiusLabs

Fusion Embedding 在冻结的视觉语言 embedding 底座上增加音频能力：第一代只训练 1640 万参数连接器，第二代使用 4420 万参数模态门控适配器，原文本、图像和视频输出保持逐位不变。仅以音频—文本对齐即可涌现音频—图像检索，两代模型都能在单卡数小时内训练完成。

INSIGHT统一索引可以让社区帖子中的文字、图片、视频和音频接受同一种 query 检索，避免为每个模态维护孤立召回链。冻结成熟底座并按模态门控增量适配，可在不回归既有文本检索的前提下扩展能力；但应对跨模态长尾 query 单独建立评测集。

Abdul Basit Tonmoy, Kazi Fardinul Hoque, Md. Shahrier Islam Arham, Arman Luthra

Linear-Time and Constant-Memory Text Embeddings Based on Recurrent Language Models

论文以微调 Mamba2 构建通用文本 embedding 模型，并提出纵向分块推理：当输入超过分块长度后，显存占用不再随序列继续增长，计算保持线性。实验还在 Mamba2、RWKV 与 xLSTM 上验证一致的时间—内存权衡，检索质量可与 Transformer embedding 模型竞争。

INSIGHT对长帖子、评论串或拼接用户上下文，Transformer 编码的二次计算与线性显存会限制索引吞吐；循环模型可把长文本 embedding 变成常量内存任务。落地时可保留短文本 Transformer 路径，只对超长内容路由到循环 embedding 模型，并校准两路向量分布。

Tobias Grantner, Emanuel Sallinger, Martin Flechl

A Multi-Stage Hybrid Retrieval Framework for the Scientific Literature with Cross-Encoder Re-Ranking

King Faisal University

研究统一比较 BM25、SciBERT、SPECTER、SciNCL、RRF 与 MS MARCO MiniLM cross-encoder。SciFact 上最佳 SciNCL+BM25+重排达到 nDCG@10 0.523、MAP@10 0.479、Recall@10 0.642；RM3 会引发查询漂移，RRF 也可能稀释强稠密排序。

INSIGHT混合召回的价值主要是扩大候选覆盖，并不保证融合后的初排优于最强单路；真正的增益常由 cross-encoder 重排兑现。社区搜索应分别监控各召回通道贡献、融合前后 nDCG 与重排恢复率，避免把 RRF 当作无条件增益，并对短 query 谨慎使用词法反馈。

Walaa Al-Joofi, Alaa Sagheer, Hala Hamdoun

Exposure-Based Reinforcement Learning to Rank

Google

论文把排序策略的梯度估计封装为文档曝光分布，使精度、DCG、公平曝光或蒸馏目标都能写成可微损失并直接使用自动微分。通过基线校正、部分边缘化和 GPU 计算，新方法在不增加 GPU 计算时间的情况下，比定制梯度更快收敛、排名更高且长训练更稳定。

INSIGHT曝光分布是连接离散排序动作与常规深度学习工具链的实用抽象，可降低 RL 排序算法的实现门槛。业务上可先用于离线多目标排序或公平性约束，不宜直接替代成熟 CTR 排序；上线前需重点验证采样偏差、策略稳定性和长尾内容曝光变化。

Harrie Oosterhuis, Rolf Jagerman, Zhen Qin, Xuanhui Wang

Howard University-AI4PC at SemEval-2026 Task 8: Query Reformulation and Dense-Lexical Retrieval Fusion for Multi-Turn Retrieval-Augmented Generation

Howard University

该系统面向多轮检索中的省略、不可回答问题和相关性漂移，组合 LLM 查询改写、子查询分解与 HyDE。候选由 BGE-base-en-v1.5 稠密召回和 BM25 词法召回产生，经 RRF 融合后使用 BGE-reranker-large 重排，并在 ClapNQ、Cloud、FiQA、Govt 四类语料上评测。

INSIGHT这是可快速复现的强基线：先把依赖对话上下文的 query 独立化，再用稠密与词法双路保证覆盖，最后用 cross-encoder 统一相关性。社区搜索可将改写、分解和 HyDE 做成按需开关，针对短 query、追问和无答案意图分别评估，避免全量增加成本。

Sijan Shrestha, Saurav Aryal

PAGE-RAG: Evidence-Grounded Adaptive Graph Retrieval for Long-Document Question Answering

PAGE-RAG 不把自动构建图当作独立事实库，而把它视为导航原文的语义骨架；系统依据 query 动态选择检索路径，并以知识边界控制要求答案回到可访问证据，必要时拒答。实验报告在保持竞争性回答质量的同时，提高检索效率与知识可靠性，代码已公开。

INSIGHT图结构适合组织长帖子、主题和实体关系，但图抽取遗漏不应被误当成“事实不存在”。工程上可让图只负责候选导航，最终相关性与回答证据仍回源到原文；对社区知识搜索还应设置证据边界和拒答条件，减少结构化投影带来的过度推断。

Xingyu Chen, Junxiu An, Jun Guo, Li Wang
