OneModel: A Unified Foundation for Platform-Scale Multi-Scenario Ranking

OneModel 将社区推荐、广告和商家服务中的异构行为统一为事件序列，用行动导向骨干网络学习长上下文用户表示，并以场景感知信息调制平衡共享与专属能力。小红书线上测试显示，探索流时长提升0.33%、互动提升1.25%，信息流广告CTR提升8.18%，商家推荐DGMV提升1.1867%。

GateDiffInt: Gate-Mediated Controllable Diffusion and Multi-Intent LLM Distillation for User Behavior Modeling

📖 深度解读 · 12 分钟 →

GateDiffInt 将行为序列中的噪声—意图耦合显式化，利用可控前向扩散和双门控增强、去噪，再由大模型教师蒸馏长期、短期、潜在和转化四类结构化意图，轻量学生模型完成CVR预测。论文在公开与工业数据上均报告稳定收益，并在日活数亿的线上A/B测试中提升GMV、进入主流量部署。

INSIGHT对用户建模而言，先把行为清洗成可解释的多时间尺度意图，再做排序，比让一个序列编码器隐式吸收所有信号更容易控制。工程上可以采用大模型离线蒸馏、在线轻量融合的方式，把转化监督接入意图抽取；但需要重点监控扩散增强带来的延迟和教师标签漂移。

Multimedia Asset Personalization via Multimodal Embeddings at Netflix

Netflix

rEDMRec: Distilling Large Language Model Reasoning into an Editable Experience Memory for Recommendation

rEDMRec 把教师大模型对用户历史和候选的推理压缩为可编辑记忆，分成长短期偏好、物品感知和反事实难负例4类通道，由记忆控制器执行增删改留，学生模型只检索记忆完成排序。它在ML-1M、Amazon Beauty和Steam、10个学生骨干上提升HR@1，ML-1M相对次优基线最高提升13.3%，记忆去重降低7.4个百分点。

INSIGHT把昂贵推理变成可检查、可更新的用户经验库，能同时降低线上大模型调用和用户兴趣漂移带来的维护成本。推荐系统可以先离线生成偏好与反事实负例，再用轻量模型做记忆检索；消融显示短期上下文最稳定，因此应把实时意图作为主通道、长期偏好作为补充。

Think-to-Personalize: Unifying Reasoning and Retrieval for User-Centric Personalized Dense Retrieval

Think-to-Personalize 针对本地生活电商中的短、歧义查询，让模型先基于用户购买序列推理潜在需求，再生成增强查询并编码为稠密向量。两阶段训练先用SFT建立冷启动能力，再用GRPO按检索效用对齐推理；论文在公开和专有基准上验证，并报告线上订单量提升0.46%。

DEGR: Dual Exploration-Driven Generative Re-Ranking for Adaptive Recommendation

京东

DEGR 将重排视为跨请求探索问题，用即时互动与后续行为共同训练探索奖励，再以自适应奖励加权的生成式重排器扩大候选组合空间。报道的京东首页7天A/B测试中，UCTR提升1.22%、PV提升0.20%，TP99仅增加3.2毫秒，说明探索目标可以在可控时延内进入主链路。

INSIGHT只优化当前pCTR会把系统锁在已有供给和短期反馈里，探索奖励应显式建模“这次没点但促成后续行为”的价值。对UGC推荐可将后续回访、深度阅读和跨主题点击纳入重排奖励，并保留单次贪心解码和分组约束，避免生成式重排放大延迟与不可控性。

Dual-Stream MLP is All You Need for CTR Prediction

📖 深度解读 · 15 分钟 →

主流 CTR 模型都是双流结构：一路用乘法显式构造特征交叉，一路用 MLP 隐式学习，两路输出直接相加。结构越复杂越难调，乘法那一路的输出还会随交叉阶数变大，相加时容易压过 MLP 那一路。DS-MLP 让最终模型只剩两个普通 MLP：一个通过知识蒸馏学会老师模型的显式交叉，另一个从零学习、补上老师漏掉的模式，两路先做批归一化，再各自用点击标签监督。先把老师变成同构的 MLP，再对齐融合。三个公开数据集上 AUC 都排第一，但 Criteo、Avazu 上只领先最强基线 0.0003 和 0.0006，只有 MovieLens 领先 0.0035。

美团搜索3.0：LLM 语义表征在排序模型的探索与应用

美团

美团搜索团队以零售排序为场景，介绍LLM语义表征从单点特征验证、系统化表征体系到跨场景迁移复用的三期实践。文章把语义匹配信号放进排序模型，而不是只在召回阶段使用，为短文本、商品和本地生活内容的用户意图建模提供工程路径。

HyTiFRec: Hybrid Time-Frequency Dual-Branch Transformer for Sequential Recommendation

HyTiFRec 针对序列模型偏重低频信号、难以同时捕捉长期与短期兴趣的问题，用可学习混合滤波器和窗口混合滤波器构成双分支，并以高效注意力替换标准自注意力。其设计把时间域顺序信息与频域周期信息结合，重点改善用户兴趣漂移下的序列表示效率。

INSIGHT用户行为中的短期爆发、周期回访和长期偏好不应由同一种注意力模式承担，频域分支提供了一个可解释的兴趣分解视角。对推荐序列可先做频率特征诊断，再决定是否引入双分支；若线上序列很长，应优先核算高效注意力带来的显存和吞吐收益。
