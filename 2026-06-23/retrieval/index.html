E2Rank: Your Text Embedding can Also be an Effective and Efficient Listwise Reranker

文本 embedding 模型检索高效，但排序精度不及专用 reranker，尤其落后于 LLM listwise reranker。E2Rank 让同一个 embedding 模型同时承担检索与 listwise 重排：在 listwise ranking 目标上继续训练，把"原始 query+候选文档"拼成的排序 prompt 当作被 top-K 文档信号增强的 query embedding（类似 pseudo-relevance feedback），用 query 与文档 embedding 的余弦相似度作为统一打分函数。在 BEIR 重排基准上取得 SOTA，在推理密集的 BRIGHT 上有竞争力，重排延迟很低，且排序训练反过来提升了 MTEB 上的 embedding 表现。

KEY INSIGHT · 对业务意味着什么单一 embedding 模型即可统一召回与重排，省去独立 cross-encoder reranker 的部署与延迟开销，对 UGC 短文本搜索这类既要低延迟又要 nDCG 的场景很有吸引力。把 listwise prompt 复用为 PRF 式增强 query embedding 是关键设计——不引入逐对 token 交互就拿到 listwise 收益。排序训练与 embedding 训练互相增益的发现，提示召回模型可在重排数据上继续训练以同时改善两端。来自阿里 Tongyi 与人民大学。

Scaling Laws for Cross-Encoder Reranking

UMass AmherstEEmory

语言模型与一阶段检索的 scaling law 已有研究，但重排尚无。本文首次系统刻画 cross-encoder reranker 在 pointwise/pairwise/listwise 三种目标下的 scaling law：排序质量随模型规模与训练曝光量呈可预测的幂律，可用小规模实验外推大模型。用最多 150M 参数的模型，在 MSMARCO-dev 与 TREC DL 上外推出 400M 与 1B reranker 的效果；并从拟合的联合 scaling law 推导算力分配规则，与等算力 checkpoint 对比发现检索指标常更偏好"数据多"的扩展，但最优策略取决于训练目标，外推通常偏保守。

INSIGHT给重排模型训练提供了"先小规模拟合幂律、再外推大模型"的预算规划方法，对要不要投入训练更大 reranker 的决策很实用。pointwise/pairwise/listwise 三种排序目标的 scaling 行为与最优数据-参数分配各不相同，提示团队按自身目标函数定制扩展策略。预测偏保守，可作为大模型训练投入的下界参考。作者承诺开源代码与评测协议。

Rahul Seetharaman, Aman Bansal, Hamed Zamani, Kaustubh Dhole

Qwen3-VL-Embedding and Qwen3-VL-Reranker: A Unified Framework for State-of-the-Art Multimodal Retrieval and Ranking

Alibaba

Qwen3-VL-Embedding 与 Qwen3-VL-Reranker 把文本、图像、文档图像、视频映射到统一表示空间。Embedding 模型经多阶段训练，支持 flexible dimensions 与 32k token 输入；Reranker 用 cross-encoder 架构做相关性判断。两者均支持 30+ 语言，提供 2B 与 8B 两档。Qwen3-VL-Embedding-8B 在 MMEB-V2 上取得 77.8 分，发布时位列榜首。

INSIGHT一套开源、可商用的多模态 embedding+reranker，2B/8B 双档、32k 长输入、30+ 语言，对需要图文混排 UGC 内容检索的社区搜索可直接选型试用。embedding 与 reranker 配套发布、共享 Qwen3-VL 底座，便于搭召回+重排两阶段 pipeline。flexible dimensions 便于按存储与延迟预算裁剪向量维度。来自阿里 Qwen 团队。

Rethinking the Reranker: Boundary-Aware Evidence Selection for Robust Retrieval-Augmented Generation

UIUC

RAG 系统在真实检索噪声下很脆弱，即便所需证据出现在 top-K 也常失败：检索器与重排器只优化相关性，会选中"答案直白外露"的平凡段落或缺关键信息的证据。BAR-RAG 把 reranker 重构为 boundary-aware 证据选择器，瞄准生成器的 Goldilocks Zone——对生成器既非过易也非完全无解、而是"有挑战但足以推理"的证据，提供最强学习信号。它用生成器反馈做强化学习训练选择器，并用两阶段流程在诱导出的证据分布上微调生成器以缓解训练-推理分布失配。在 knowledge-intensive QA 上较强 RAG 与重排 baseline 平均提升 10.3%。

INSIGHT把重排的优化目标从"纯相关性"改成"对下游生成器最有用"，是对搜索/RAG 重排范式的有价值反思——选证据要考虑消费者（生成器）而非只看 query-doc 相关。Goldilocks Zone 思路对带 LLM 生成式摘要的搜索场景有借鉴：过于直白或过难的段落都不是最优上下文。代价是需 RL 训练加生成器联合微调，工程门槛较高。UIUC 出品。

Jiashuo Sun, Pengcheng Jiang, Saizhuo Wang, ..., Heng Ji, Jiawei Han

KuaiSearch: A Large-Scale E-Commerce Search Dataset for Recall, Ranking, and Relevance

KuaishouUSTC

电商搜索面临 query 高度模糊、商品文本噪声大且语义顺序弱、用户偏好多样等难题。现有电商搜索数据集多为启发式构造 query、过滤冷启动用户与长尾商品、文本匿名化，且只覆盖单一 pipeline 阶段。快手开源 KuaiSearch，号称当前最大的电商搜索数据集，基于快手平台真实用户搜索交互构建，保留真实 query 与自然语言商品文本，覆盖冷启动用户与长尾商品，系统性涵盖召回、排序、相关性判断三个阶段，并从商品、用户、query 多视角分析、在代表性任务上建立 benchmark。

INSIGHT一个覆盖召回/排序/相关性全链路、保留冷启动与长尾、未匿名化的真实电商搜索数据集，对研究 UGC 短文本 query 理解与短文本检索很有数据价值，可直接用于训练与评测三阶段模型。它对真实 query 模糊性与商品文本噪声的刻画，贴近社区搜索的短文本难点。局限是数据集类工作无方法消融，价值在数据与 benchmark 而非新模型。来自快手与中科大。

Yupeng Li, Ben Chen, Mingyue Cheng, Zhiding Liu, Xuxin Zhang, Chenyi Lei, Wenwu Ou

uva-irlab-conv at SemEval-2026 Task 8: Multi-Turn RAG with Learned Sparse Retrieval and Listwise Reranking

University of Amsterdam

该报告描述阿姆斯特丹大学 IRLab 参加 SemEval-2026 Task 8（多轮检索问答）的系统，任务覆盖金融、云文档、政务、维基百科四个领域，含"集合中无足够证据"的不可答 query。系统提出多轮 RAG pipeline：以 learned sparse retrieval（LION-SP，基于 LLM 底座的 LSR 模型）为主检索方法，利用其跨领域强泛化；并借 LLM 的长上下文能力做对话式 query 改写、pointwise 与 listwise 重排、最终答案生成，每一步都以完整对话历史为条件，从而在检索与生成全程融入对话上下文、提升跨领域鲁棒性。

INSIGHT用 learned sparse retrieval 作主召回换取跨领域泛化、再叠加 LLM query 改写与 listwise 重排，是一套可直接照搬的多轮对话搜索工程范式，对社区搜索的会话式 query 理解有参考。把对话历史一路贯穿改写-重排-生成的做法值得借鉴。但作为竞赛系统报告，方法新颖性低、缺消融，更多是 pipeline 组合的工程经验。

Simon Lupart, Kidist Amde Mekonnen, Zahra Abbasiantaeb, Mohammad Aliannejadi
