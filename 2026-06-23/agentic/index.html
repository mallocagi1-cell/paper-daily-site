Decoupling Search from Reasoning: A Vendor-Agnostic Grounding Architecture for LLM Agents

生产环境的 LLM agent 依赖实时检索，但厂商原生的 search grounding 把检索策略、provider 选择、证据注入、成本、延迟和生成行为全部耦合在模型边界内，难以检查、调优、复用与迁移，还会触发 Search-Induced Verbosity 破坏输出格式约束。论文提出 DSG（Decoupled Search Grounding），用 MCP 兼容网关把 grounding 移出推理模型，把 provider 路由、source-aware 上下文渲染、fallback、检索深度控制与精确+语义缓存都做成一等公民控制项。在 5 个前沿模型、SimpleQA/FreshQA/HotpotQA 上：SimpleQA 准确率 86.1% 接近原生 87.7%，但检索成本降 91%、warm-cache 命中率 99.4%、延迟降 68%；在电商 query 理解（QIU）线上负载上检索成本降超 98%。

KEY INSIGHT · 对业务意味着什么把实时 grounding 当成可优化的接口边界来设计、而不是模型自带的固定功能，这条思路对社区搜索很有价值：检索 provider、检索深度、证据渲染、缓存都能独立调优和 A/B，无需绑定单一模型厂商。精确+语义双层缓存把重复 query 的延迟与成本压到极低（99.4% warm-cache 命中），对高 QPS 的短文本搜索意味着可观的成本节省；source-aware 渲染还能避免检索内容把答案撑长，保住简洁输出契约。

CacheWeaver: Cache-Aware Evidence Ordering for Efficient Grounded RAG Inference

RAG 提升事实性的同时拉长 prompt、抬高 prefill 成本，而 vLLM 等引擎的 prefix caching 只在请求共享相同 token 前缀时才省钱。问题在于相邻 query 检索到的证据集合常有重叠但顺序不同，集合重叠无法转化为可复用的前缀重叠。CacheWeaver 是一个轻量的 prompt 层方法：维护一棵近期已服务证据序列的前缀树，用贪心游走把最可复用的前缀排在最前，不改动 serving 引擎和检索结果集。在 3 种 vLLM 配置下，相对按检索顺序的 prefix caching，中位 TTFT 降低约 20–33%，QA 答案质量不受影响；贪心策略达到 oracle 排序 TTFT 收益的 97.5%。

INSIGHT证据排序这个被忽视的环节直接决定 RAG 的 KV-cache 复用率。对社区搜索的 RAG 问答场景，只需在检索与推理之间插一个调度层重排证据顺序，就能拿到接近最优的 TTFT 收益，几乎零成本、零模型改动。前缀树+贪心的设计简单可落地，尤其适合证据集高度重叠的高频 query；可借鉴的点是把 cache 友好性纳入证据组装策略，而不是只看相关性排序。

Kaizhen Tan, Rong Gu, Mingyuan Li

Uncertainty Decomposition for Clarification Seeking in LLM Agents

交互式 LLM agent 需要在任务描述模糊时主动追问澄清，但经典的 aleatoric/epistemic 不确定性框架不够用，且黑盒 API、交互延迟预算、缺少标注轨迹排除了基于 logprob、多次采样或训练的方法。论文提出一个简单的 prompt-based 分解：把 action confidence 与 request uncertainty 分开，让 agent 在任务欠定时发起澄清。作者构造 WebShop-Clarification 与 ALFWorld-Clarification 两个基准（50% 任务故意欠定），在 5 个 backbone（GPT-5.1、DeepSeek-v3.2-exp、GLM-4.7、Qwen3.5-35B、GPT-OSS-120B）上对比 ReAct+UE 与 UAM：ALFWorld-Clarification 上澄清 F1 平均较 ReAct+UE 提升 73%、较 UAM 提升 36%，且在多数 backbone 上领先。

INSIGHT把动作置信度与请求不确定性解耦，是判断该追问还是该执行的关键，对社区搜索的 query 理解直接可用：面对歧义 query（短文本、口语化），系统应识别欠定并主动澄清而非强行召回。方法纯 prompt、不需训练、兼容黑盒 API 与低延迟预算，落地门槛低；两个澄清增强基准的构造方式（注入 50% 欠定任务）也可借鉴用于评测搜索澄清能力。

Gregory Matsnev

When Does Streaming Tool Use Help? Characterizing Tool-Intent Stabilization in Streaming Retrieval-Augmented Generation

Streaming RAG 通过在用户还在输入时就并行发出检索 query 来降低感知延迟，但增益本质上依赖 query：只有当正确的检索 query 在用户说完/打完之前就能确定时，提前检索才有用。论文定义并测量 tool-intent stabilization（投机 query 的检索收敛到含答案结果的时点），在 CRAG 基准（1371 题）上推导出可隐藏延迟比例的模型无关上界 H（关于工具延迟 L 与输入节奏 δ），并用真实流式管线验证。在 L=600ms、δ=3 词/秒、θ=0.8 的现实工作点，73.9% 的 query 可获得可观的延迟隐藏；问题类型对早/晚稳定有显著但粗粒度的影响（Kruskal-Wallis p=0.017）。全程无需训练、可在普通 CPU 上运行。

INSIGHT流式检索不是对所有 query 都划算，只在检索意图能提前确定的 query 上有效。这个量化框架（stabilization 时点 + 可隐藏延迟上界）给出了何时该触发投机检索的判据，对社区搜索的搜索建议/即时检索很实用：可据此训练一个轻量投机触发器，只在收益大于成本的 query 上提前发检索，避免无谓检索调用。无需训练、CPU 可跑，便于离线分析自家 query 分布。

Compositional Skill Routing for LLM Agents: Decompose, Retrieve, and Compose

LLM agent 依赖外部 skill（可复用工具规格），但真实任务常需组合多个 skill 而非选一个。论文把它形式化为 Compositional Skill Routing：把复杂 query 分解为原子子任务、为每个子任务检索合适 skill、再组合成可执行计划。SkillWeaver 框架由 LLM 任务分解器、bi-encoder + FAISS 的 skill 检索器、依赖感知的 DAG 规划器组成。作者构造 CompSkillBench（300 条组合 query，覆盖公共 MCP 生态的 2209 个真实 skill、24 类）。实验发现分解质量是主要瓶颈：标准 LLM 分解的步级类别召回仅 34.2%。提出 Iterative Skill-Aware Decomposition（SAD）检索增强反馈循环，一轮迭代把分解准确率从 51.0% 提到 67.7%（+32.7%，Wilcoxon p<1e-6）；SkillWeaver 把上下文窗口消耗降低超 99%。

INSIGHT先把 query 分解到正确粒度、再检索，这条 decompose-retrieve-compose 范式对社区搜索的复杂/多意图 query 处理有借鉴意义：分解粒度对齐可检索资源是检索成功的前提（DA=1 时 CatR@1 从 34% 升到 41%）。SAD 用检索可行性反过来指导分解迭代的思路，可迁移到 query 改写/子查询生成；bi-encoder+FAISS 的 skill 检索 + DAG 组合也是工具/技能库规模化的实用骨架。

Xueping Gao

Beyond Reward Engineering: A Data Recipe for Long-Context Reinforcement Learning

Tsinghua

长上下文推理是 LLM 作为 agent 处理长轨迹的核心能力，RL 是主流提升手段，但已有工作多聚焦 reward engineering，训练数据多样性不足。论文从数据视角出发，证明仅靠一份简单有效的数据配方 + 最小化的 outcome-based GRPO 就能大幅提升长上下文推理。配方覆盖检索、多证据综合、推理三类互补任务，构建并整理 8 个数据集共约 14K 样本。在 Qwen3-4B/8B/30B-A3B 上，跨 7 个长上下文基准平均提升 +7.2/+3.2/+6.4 分，超过已有 RL 训练集；增益还迁移到 agentic 任务：在 agent 调优模型上继续用该配方 RL，GAIA +4.8、BrowseComp +7.0。数据集将开源。

INSIGHT长上下文/agentic RL 的瓶颈常被误判为 reward 设计，本文显示训练数据配方才是更高杠杆：检索+多证据综合+推理三类任务的组合，约 14K 样本就拿到可观且可迁移的收益。对自建搜索/RAG agent 有直接启示：与其反复调 reward，不如先把训练任务的数据多样性补齐；GAIA/BrowseComp 的迁移增益说明这类数据对会搜索的 agent 尤其有效，开源数据集也降低了复现门槛。

Xiaoyue Xu, Sikui Zhang, Xiaorong Wang, Xu Han, Chaojun Xiao

PACMS: Submodular Context Selection as a Pluggable Engine for LLM Agents

对话与工具型 LLM agent 的上下文窗口同时被多个来源填充：用户/助手轮次、持久记忆条目，以及往往占比最大的工具调用原文（文件读取、搜索结果、API 返回）。当累计上下文超过 token 预算，主流做法是 recency truncation（按时间截断），这是 topic-blind 的：早期建立的事实仅因旧被丢弃，即便当前 query 正问它；冗长但无关的近期内容反被保留。多轮记忆场景恰是 recency truncation 失效之处。已有替代方案都在 agent 组装环节之外——RAG 取外部文档但不裁决 agent 已有的池化上下文，上下文压缩则 query-blind 且有损。PACMS 把记忆条目、对话轮次、工具输出当成单一候选池，用 submodular 选择在组装 prompt 的当下按相关性挑选。

INSIGHT把上下文该保留什么建模为 submodular 选择、且作用在 agent 组装 prompt 的当下，是相对 recency 截断/RAG/压缩的一个清晰新定位。对长会话的社区搜索助手有启示：工具/检索返回原文常占满窗口，按当前 query 相关性从已在手的全部上下文里做子模选择，比一刀切按时间截断更能保住关键事实。可插拔引擎的定位便于嵌入现有 agent 框架。注：摘要侧重问题动机，具体实验数据需读正文确认。

Manu Ghulyani, Arunabh Singh, Karan Bharadwaj, Ankit Nath, Suranjan Goswami

ScaffoldAgent: Utility-Guided Dynamic Outline Optimization for Open-Ended Deep Research

开放式深度研究（OEDR）需要系统通过多轮检索获取知识并生成连贯的长篇报告，其中 outline（提纲）作为结构骨架协调检索、证据组织与生成。已有方法要么写作前固定提纲、要么用局部启发式微调，导致信息持续累积时出现 scaffold drift，且评估提纲修改的反馈滞后。ScaffoldAgent 把提纲演化建模为含 Expansion/Contraction/Revision 三种操作的结构化决策过程，并引入 utility-guided 反馈：从检索增益、结构连贯性、试生成质量估计每次提纲操作的下游价值，用该 utility 信号指导节点选择、操作调度与终止。在 DeepResearch Bench 与 DeepResearch Gym 上一致提升长篇报告生成质量与事实 grounding。

INSIGHT把提纲当成可动态优化的决策对象、并用下游 utility（检索增益+连贯性+试生成）驱动增删改，是深度研究类长文生成的一个实用设计。对社区搜索里的生成式回答/聚合长答案有借鉴：先有可演化的结构骨架协调多轮检索，再边检索边调整提纲，能缓解证据累积导致的结构漂移。utility 信号的三要素（retrieval gain/coherence/trial-generation）也可作为长答案质量的过程性评估维度。

MetaResearcher: Scaling Deep Research via Self-Reflective Reinforcement Learning in Adversarial Virtual Environments

深度研究 agent 在自主信息收集与综合上表现亮眼，但训练受限于模拟环境的静态性、仅做 fact-retrieval 的任务设计、以及 outcome-based RL 的低效。MetaResearcher 从四个维度扩展深度研究 agent 训练：(1) Evolving Virtual World 向训练环境注入时间动态与对抗性错误信息，迫使 agent 习得 source credibility 评估与时间冲突消解；(2) Discovery-Oriented Tasks（假设生成、矛盾消解）超越简单事实检索；(3) GRPO 框架内的 Self-Reflective Meta-Reward，联合优化答案正确性、搜索路径效率、反思深度、工具调用多样性，针对重复动作循环问题；(4) 由 Scout/Filter/Synthesizer 专用模型组成的异构多智能体 swarm。基于 LiteResearcher，训练零边际 API 成本，目标提升 GAIA、Xbench-DS 表现与对抗鲁棒性。

INSIGHT亮点在训练环境与奖励设计：把对抗性错误信息+时间动态做进虚拟世界，逼 agent 学会判断来源可信度与消解时间冲突，这对社区搜索（UGC 噪声大、时效性强、存在误导信息）的检索 agent 训练思路很有启发。Self-Reflective Meta-Reward 同时奖励搜索路径效率与工具调用多样性，是缓解 agent 重复检索的可借鉴信号设计。需注意：本文为框架设计与方法论，实验为 planned validation，尚无完整结果，落地价值待正文与后续验证。

Wei Yu, Suxing Liu, Minjie Yu, Jiahao Wang, Zhijian Zheng, Haocheng Deng, Bing Li

ScholarQuest: A Taxonomy-Guided Benchmark for Agentic Academic Paper Search in Open Literature Environments

USTC

学术论文检索是科研核心一步，基于 LLM 的 search agent 正成为迭代式、意图驱动文献探索的有前景范式，但现有基准不足以在真实开放文献环境下系统评测 agentic 学术检索。ScholarQuest 是一个大规模、taxonomy-guided 的 agentic 学术论文检索基准：基于 1000+ 计算机科学主题与四类研究意图（method-oriented、setting-anchored、comparison-based、scope-controlled）构造，并提供可扩展的答案构造与共享检索后端 ScholarBase 以保证可复现。结果显示 agentic 方法优于单次检索基线，但最佳 agent 仅达 Recall@100 0.314、Recall@All 0.355，提升空间巨大；此外还提供搜索效率、意图级鲁棒性与失败案例分析。

INSIGHT该基准把研究意图显式拆成四类（方法/设定锚定/对比/范围控制），并用共享检索后端保证可复现，这套按意图分型的评测思路可迁移到社区搜索的 query 意图评测。最佳 agent Recall@100 仅 0.314 说明 agentic 检索在开放、长尾文献环境下仍远未解决，单纯多轮迭代不等于高召回。对自建搜索 agent 的启示：意图识别与召回质量是瓶颈，需要针对不同意图类型分别优化检索策略，并用失败案例驱动迭代。

Tingyue Pan, Mingyue Cheng, Daoyu Wang, Yitong Zhou, Jie Ouyang, Qi Liu, Enhong Chen
