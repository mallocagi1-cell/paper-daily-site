Interactor: Agentic RL oriented Iterative Creation for Ad Description Generation in Sponsored Search

针对赞助搜索中长文本广告描述（比广告标题更长、可融入世界知识表达用户搜索意图）的生成问题，提出 Interactor 多轮迭代生成框架：LLM 策略作为 agent，与由两个 rubric 式生成式奖励模型（GenRM，分别评估知识容量 KC 与落地页一致性 LP）和 CTR 预估模型组成的环境交互，用 <retrieve> 检索百科知识、<create> 生成、<reward> 评估三类动作多轮精修，以 GSPO 做 agentic RL，基座 Qwen3-30B-A3B。在百度搜索广告千万级数据上信息量 0.715、忠实度 0.872，超过单轮 RL 的 0.693/0.726；线上 A/B 覆盖 14 万广告主，广告收入 +0.74%、人工优质率 +7pp，2026 年 5 月已上线主流量。

KEY INSIGHT · 对业务意味着什么GenRM 不只给二元分，还返回"哪句缺知识、哪句与落地页不符"的细粒度推理反馈作为下一轮观测，这是效果关键——消融去掉 reasoning 后忠实度从 0.872 暴跌到 0.636。它把"奖励即标量"的 RLHF 升级成"奖励带可执行修改建议"的多轮自我修正，对社区搜索的 query 改写、答案/摘要生成有直接借鉴：用可验证 rubric 把开放生成的事实一致与信息量约束转成迭代信号。GenRM 用 Qwen3-8B 替换 30B 仅小幅掉点，奖励模型可适度小型化。

Intelligent Multimodal Retrieval and Reasoning for Geospatial Knowledge Discovery on the I-GUIDE Platform

UIUC

面向地理空间知识发现（数据集、地图、notebook、软件、论文及其溯源关系的异构检索），提出已部署的多模态地理空间 RAG 系统 I-GUIDE Smart Search：融合 OpenSearch 的关键词/向量/空间索引 + Neo4j 知识图谱 + 迭代式 RAG 流水线（记忆感知 query 增强、检索方法路由、相关性打分、grounded 生成、幻觉与相关性校验）。单 A100 部署支持约 100 并发、4.4 QPS、p50 约 25s（每 query 20–50 次 LLM 调用）。在 170 条人工筛选 query 基准上，证据覆盖与答案质量超过无检索与朴素 RAG 基线，精确标识、空间约束、简单推荐类 query 提升最明显。

INSIGHT价值在沉淀了一套可迁移的"空间 RAG"部署经验：检索方法路由（关键词 vs 向量 vs 空间）、图谱溯源、relevance grading、拒答感知评测、延迟-成本权衡。对社区搜索的启示是把 RAG 拆成"路由+分级+校验"的多段管线而不是单一向量召回，并正视每 query 多次 LLM 调用带来的 25s 级延迟——交互式场景必须在召回深度与延迟间显式取舍。知识图谱提供的 provenance 对可解释检索是加分项。

Yunfan Kang, Erick Li, Furqan Baig, Wei Hu, Alexander Michels, Anand Padmanabhan, Shaowen Wang

03 3.10

ScholarSum: Student-Teacher Abstractive Summarization via Knowledge Graph Reasoning and Reflective Refinement

USTC

针对科学文献摘要"语言流畅但事实不忠实"的痛点（抽取式破坏宏观逻辑、LLM 生成式事实一致性差），提出 ScholarSum 层次化反思图框架，模拟"学生-教师"写作：先把文档切成语义连贯单元构建层次知识图谱，其多层社区结构捕捉全局逻辑；学生据此生成初稿，再经细粒度证据检索精修；教师式审稿模型迭代检查、定位无支撑内容并触发定向重检索与改写，直到满足质量标准。实验在完整性与忠实度上显著超过既有基线，代码已开源。

INSIGHT把"检索-生成-审稿-重检索"做成可迭代的忠实性约束流程，教师模型专门定位 unsupported 内容，思路与本期 Interactor 的 GenRM 反馈相通：用一个独立评审模型把事实一致性转成可执行修改信号，而不是只靠一次生成。对社区搜索的 UGC 答案/摘要生成有参考——层次知识图谱的社区结构可作为长文档全局组织的先验，缓解长文摘要丢失宏观逻辑。代价是多段 LLM + 图谱构建的流水线较重，落地需权衡成本。

Bohou Zhang, Xiaoyu Tao, Mingyue Cheng, Huijie Liu, Qi Liu

04 3.05

美团海报生成 AIGC 技术创新与实践

Meituan

美团智能创作团队围绕营销海报生成 AIGC 构建"生成-编辑-评判"技术体系，覆盖外卖、品牌 IP 等场景并已全部开源。系统针对海报的多元素布局、文案与视觉一致性、可编辑性等工业需求，把生成模型与编辑、质量评判模块组合成可投产的多模态生成流程。（说明：这是偏图像/营销素材的 AIGC，与生成式搜推核心任务相邻而非同一问题，本期列入以补足国内工业实践与来源多样性。）

INSIGHT对生成式搜推从业者的借鉴主要在"生成+评判"分工：用独立评判模块对生成结果做质量把关，与本期 Interactor 的 GenRM、ScholarSum 的教师审稿是同一范式——开放式生成需要配套可验证的质量评估，而不是一次成型。全部开源使其可作为多模态生成质量评估的参考实现。落地价值集中在营销素材生产，对 UGC 文本搜索的相关性/排序无直接贡献。
