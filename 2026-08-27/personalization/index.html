TAGR: Temporally Adaptive Generative Recommendation for Industrial Live-Streaming Advertising

针对直播广告内容、商品和反馈快速变化导致静态推荐模型失效的问题，论文提出 TAGR，在广告 token、用户意图和偏好对齐三个层面做时间自适应。LSID 按周期刷新活动广告的语义—协同 ID，多尺度行为模块区分短期意图与长期偏好，再用新鲜 on-policy 反馈和稳定训练兼顾的偏好优化。候选摘要给出三层机制，但完整离线与线上增益数字需结合正文核验。

RetrievalFormer: A Dual-Encoder Transformer for Efficient Approximate Nearest Neighbor Retrieval and Cold-Item Recommendation

Amazon Web Services📖 深度解读 · 15 分钟 →

论文把搜索与推荐放进共享双塔索引，要求新物品只凭内容或属性特征即可进入 ANN 召回。公开日志中 38.6% 的查询曝光涉及从未展示或访问的物品；用户冷启动时，99 个采样负例的 Recall@20 为 0.9595，暖启动为 0.9510，未见明显损失。作者还发现 19.7% 用户受 float32 时间戳排序 bug 影响，强调离线切分校验。

INSIGHT社区内容冷启动可以先从“特征可检索”做起，而不是等 item ID 积累交互后再接入推荐索引。双塔方案适合把标题、正文、图片和作者特征统一成可增量更新的向量；同时应把时间戳、留一法目标和全目录评估做成数据质量门禁，避免看似提升其实来自切分错误。

RecGPT-Mobile-V2 Technical Report

RecGPT-Mobile-V2 将点击、收藏、购买和购后探索等异构行为转成证据保留的轨迹，用领域适配与监督对齐训练推荐原生 teacher，再按样本复杂度做分组 rollout 和推理成本优化，最后蒸馏到端侧。它同时优化意图质量和执行效率，针对一条轨迹对应多个有效 query、行为噪声和多尺度兴趣；候选摘要未给出完整线上指标。

INSIGHT个性化 query 预测可以作为“隐式行为到显式意图”的中间层，帮助社区搜索把浏览、收藏和评论串成可解释的检索需求。落地时应先把证据保留和多答案评估做好，再用难度路由控制端侧算力；简单轨迹走小模型，复杂轨迹才触发更深的推理与蒸馏模型。

Rethinking Semantic Alignment in LLM-Enhanced Collaborative Filtering: A Spectral Decoupling Approach

论文从谱分解重新审视 LLM 增强协同过滤中的语义—协同对齐：协同表示受用户—物品同质性影响，低频成分占主导；语义向量的非主奇异成分仍携带信息。训练动力学分析发现，强行共享空间会把表示集中到主导子空间，削弱非主成分覆盖；受控实验表明，保留这些成分的收益取决于对齐方式。

INSIGHT把 LLM embedding 与用户/物品协同向量直接拉到同一空间，可能会牺牲长尾语义和细粒度兴趣。推荐系统可尝试分频段或分子空间融合：低频通道服务稳定偏好，高频/非主成分保留新颖语义，再通过门控或蒸馏控制噪声，而不是单一对齐损失“一把梭”。

Yedong Jin, Shaowen Peng, Tsunenori Mine, Shoko Wakamiya, Eiji Aramaki

Native Multimodal Representation Learning for Click-Through Rate Prediction in E-Commerce Scenarios

现有 CTR 多把多模态编码器先预训练、再抽取 item 向量，预训练目标与 CTR 数据分布错位。论文直接为 CTR 任务学习原生多模态表示，将商品图文等信号与点击监督对齐，再与稀疏 ID 特征融合，面向工业电商推荐。候选摘要强调任务对齐与泛化价值，但未给出完整数据集和 AUC 增益，报告不臆造未披露数字。

INSIGHT多模态特征接入推荐不应只追求通用 embedding 的离线相似度，而要验证它是否改善点击监督下的校准与排序。对社区短文本场景，可先做 query、帖子标题、封面图的轻量联合表示，再用 CTR/nDCG 目标进行端到端对齐，并按新老内容分桶观察冷启动收益。

Tlow: Flow-based Item Tokenizer for Recommendation

Tlow 关注推荐 item tokenizer 的两个瓶颈：RQ-VAE codebook 之间存在依赖、解码慢，OPQ 又难处理语义 embedding 的维度相关性和复杂分布。方法用 flow 将原始 embedding 变换到统一标准正态潜空间，再独立量化生成语义清晰的 token ID，目标是降低生成式推荐的 token 依赖并改善冷启动。候选摘要未给出完整 benchmark 数字。

INSIGHTSemantic ID 的质量决定生成式推荐能否真正覆盖新内容。实践中可把流模型 tokenizer 当作独立离线组件，分别评估重构误差、ID 冲突率、长尾召回和生成解码耗时；若社区内容更新频繁，需支持增量重编码与版本兼容，避免 token 变化导致历史行为失效。

Nian Li, Chonggang Song, Jingtao Ding, Lingling Yi, Yong Li, Qingmin Liao

WeMM-Embedding: WeChat Multi-Modal Embedding Technical Report

Tencent

WeMM-Embedding 技术报告推出 2B、4B、9B 三种通用多模态 embedding，支持文本、图像、视频、视觉文档和交错输入。训练分为大规模多模态对齐与精细相关性监督 refinement 两阶段，并做跨规模知识迁移；摘要指出 2B 已超过此前 8B 开源基线在 MMEB-v2 上的表现，9B 进一步提升。

INSIGHT多模态推荐的关键不只是扩大模型，而是把相关性监督和跨模态难负例放进第二阶段精调。对 UGC 推荐可采用 2B 级模型生成统一内容向量，离线写入向量库并服务召回/粗排；只有在离线指标和延迟预算都达标时，才考虑更大模型或更高维输出。

Junjie Zhou, Ke Mei, Lei Li, Tianyi Wang, Fengyun Rao, Jing Lyu

Auditing Return Conditioning as a Control Knob: An Offline Diagnostic for Decision Transformer Recommendation

论文审计 Decision Transformer 推荐中的 return-to-go 控制是否真实有效，在 MovieLens 25M 与 MyAnimeList 2020 上比较不同 RTG 注入位置、无 RTG 控制、日志匹配和打乱 RTG。MovieLens 中覆盖完整真实上下文的 K=20 干预使 Crime 预测占比变化 +23.61±2.96 个百分点，而只改当前槽位仅变化 +1.77±1.17；打乱 RTG 后响应降至 +2.08±1.20。

INSIGHT离线序列推荐里的“可控性”不能只看把目标回报改大后指标是否上升，还要验证模型响应来自真实历史还是合成上下文。做长期价值或多目标推荐时，应保留 RTG locality、shuffle 和 logged-match 对照，并把可控性曲线与 nDCG、CTR、覆盖率一起看，避免把数据泄漏误判成策略能力。

Breaking User-Centric Agency: A Tri-Party Framework for Agent-Based Recommendation

TriRec 将推荐责任拆成三方：item agent 面向目标用户生成自荐，平台保留曝光预算，sequential reranker 联合相关性、item utility 与曝光公平性。四个公开数据集上同时提升准确性、公平性和 item 效用，且三项数据集的准确率增益显著；50 个候选的三臂消融进一步拆分两层机制对零曝光 item 的作用。

INSIGHT当平台只让用户侧模型决定曝光时，长尾内容很容易被热门度吞没。可借鉴 TriRec 的职责分离：让内容侧生成受约束的兴趣说明，平台侧统一控制曝光预算，重排阶段显式加入生态效用与公平性；上线前要限制自荐文本的注入范围并做反事实评估。

Category-aware dual graph disentanglement with multi-task learning for session-based recommendation

CDDM 针对匿名 session 中仅依赖 item ID 造成的数据稀疏和类别信息纠缠，分别建模 item 图与 category 图，并用类别感知对比学习增强语义相似性。多任务框架联合下一物品预测、类别预测和对比学习，配合自适应归一化捕获近期兴趣；论文发表于 2026 年 6 月，候选摘要未给出完整指标表。

INSIGHT社区冷启动和短 session 场景可以把内容类别作为稳定的中间监督，减少模型对稀疏 item ID 的依赖。工程上可先拆开内容图与交互图，再通过辅助类别任务和对比损失共享表示；要特别检查类别泄漏、热门类过采样以及匿名用户的时间漂移。
