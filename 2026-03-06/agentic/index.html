From Conflict to Consensus: Boosting Medical Reasoning via Multi-Round Agentic RAG

提出 MA-RAG 框架，通过多轮迭代同步优化外部证据检索和内部推理，实现 Agentic RAG 的 test-time scaling。

📖 深度解读 · 6 分钟arXiv ↗
4.30
综合分 / 5
KEY INSIGHT · 对业务意味着什么Agentic RAG 的核心突破：从单轮检索到多轮证据-推理协同迭代，每轮既更新检索策略也优化推理路径。这种 test-time compute scaling 方式可直接迁移到搜索问答场景。业务关联 社区搜索的复杂 query（如多条件筛选、需要综合多帖子的问答）可借鉴此多轮检索-推理框架，通过迭代证据收集提升 LLM 搜索问答的准确率和可信度。证据 在 MedQA 上 MA-RAG 将 GPT-4o 准确率从 80.3% 提升至 87.6%（+7.3pp），Llama-3-70B 从 73.8% 提升至 82.1%（+8.3pp），多轮迭代比单轮 RAG 平均提升 5-8 个百分点。

ToolRLA: Multiplicative Reward Decomposition for Tool-Integrated Agents

提出 ToolRLA 三阶段后训练流水线（SFT->GRPO->DPO），用细粒度乘法式 reward 分解训练工具调用 Agent。

INSIGHT工具调用 Agent 的 RL 对齐关键在于 reward 设计：将粗粒度的二元奖励分解为格式/选择/参数/执行四个维度的乘法组合，任一维度出错即零奖励。这种设计可迁移到搜索 Agent 的 API 调用质量优化。

业务关联社区搜索若引入 Agent 进行多步检索（如先分析 query 意图、再选择不同检索 API、最后聚合结果），ToolRLA 的细粒度 reward 分解方案可有效提升 Agent 的工具选择和参数填充准确率。

证据在 ToolBench 上 ToolRLA 将工具调用正确率从 62.4% 提升至 78.9%（+16.5pp），参数精确匹配率从 45.7% 提升至 71.3%（+25.6pp）；三阶段训练中 DPO 阶段贡献最大提升。

Memex(RL): Scaling Long-Horizon LLM Agents via Indexed Experience Memory

提出 Memex 索引式经验记忆架构，让 LLM Agent 在长程任务中按需检索历史证据而非截断或压缩上下文。

INSIGHTLLM Agent 的长程记忆瓶颈不应靠截断或摘要解决——这些是有损操作。Memex 通过将历史工具输出和推理过程索引化、按需检索，将上下文窗口从硬约束变为软约束，实质是把 RAG 思路用于 Agent 自身的经验管理。

业务关联多轮搜索 Agent（如 deep research 场景）常因上下文长度限制丢失早期检索结果。Memex 的索引式记忆可让搜索 Agent 在长对话中始终保留关键检索证据的访问能力。

证据在 WebArena 上 Memex 将长程任务成功率从 12.4% 提升至 23.7%（+11.3pp），在 50 步以上任务中比摘要式记忆高 18.2%，且 token 消耗降低 37%。

Towards Personalized Deep Research: Benchmarks and Evaluations

提出 PDR-Bench，首个评估 Deep Research Agent 个性化能力的基准，含 50 任务乘25 真实用户画像。

INSIGHTDeep Research Agent 的核心短板在个性化：同一研究问题对不同用户（专业背景、信息需求）应产出差异化报告，而当前 Agent 几乎不具备此能力。这对搜索系统中的个性化信息组织有直接启示。

业务关联社区搜索中不同用户对同一 query 的期望结果不同（新手 vs 专家、浏览 vs 精确查找）。PDR-Bench 的评估框架可用于衡量搜索 Agent 的个性化程度。

证据在 PDR-Bench 上测试 6 个主流 DRA（GPT-4o、Claude、Gemini 等），个性化得分最高仅 42.3%，平均仅 31.7%，揭示了当前 Agent 在用户适配方面的巨大差距。

MemSifter: Offloading LLM Memory Retrieval via Outcome-Driven Proxy Reasoning

提出 MemSifter，使用小型代理模型基于结果驱动的推理来筛选 LLM Agent 的长期记忆，降低检索成本。

INSIGHTAgent 记忆检索的效率-质量困境可通过小模型代理筛选加大模型精读的两阶段架构解决，类似搜索系统的召回-排序分层设计。代理模型通过结果驱动推理（预测记忆是否影响最终输出）来判断记忆相关性。

业务关联社区搜索的多轮对话场景中，历史检索结果的管理面临类似挑战。MemSifter 的代理筛选思路可用于长对话搜索中高效保留有价值的历史上下文。

证据MemSifter 在 LongMemEval 基准上记忆检索准确率达 78.4%，相比全量大模型处理仅下降 2.1%，但推理成本降低 65%；比 top-k 相似度检索高 12.8%。

Build, Judge, Optimize: A Blueprint for Continuous Improvement of Multi-Agent Consumer Assistants

提出生产级多 Agent 购物助手的评估-优化闭环方法论，含 LLM-as-judge 评估和 Agent 间协调优化。

INSIGHT多 Agent 搜索助手的落地核心难题不在单 Agent 能力，而在评估体系和持续优化机制：如何自动评估多轮交互质量、如何在紧耦合的多 Agent 系统中定位和修复问题。Build-Judge-Optimize 闭环提供了可复制的方法论。

业务关联社区搜索若引入对话式搜索助手（Agent 辅助搜索），面临同样的评估和优化挑战。该论文的 blueprint 可直接指导搜索助手的上线评估流程和迭代优化策略。

证据在杂货购物场景中部署，多轮对话完成率从 43.2% 提升至 67.8%（+24.6pp），用户满意度评分从 3.2 提升至 4.1（5 分制），Agent 间协调失败率从 28% 降至 11%。

Learning When to Act or Refuse: Guarding Agentic Reasoning Models for Safe Multi-Step Tool Use

提出 MOSAIC 后训练框架，专门对齐 Agent 在多步工具调用中的安全决策能力。

INSIGHTAgentic 系统的安全对齐与聊天模型截然不同：Agent 需要在连续决策链中每一步都做安全判断，且工具反馈可能具有对抗性。MOSAIC 将安全决策嵌入推理链的每个工具调用节点，而非仅在最终输出层。

业务关联搜索 Agent 若具备文件访问、API 调用等能力，安全边界管理至关重要。MOSAIC 的思路可用于构建安全的搜索 Agent，确保在多步检索过程中不执行危险操作。

证据在 AgentBench-Safety 上 MOSAIC 将不安全操作率从 23.4% 降至 4.7%（-18.7pp），同时任务完成率仅下降 2.1%；在对抗性工具反馈测试中安全拒绝率达 91.2%。

AriadneMem: Threading the Maze of Lifelong Memory for LLM Agents

提出 AriadneMem 结构化记忆系统，通过离线构建加在线检索两阶段解决 Agent 长期对话中的证据断裂和状态过期问题。

INSIGHTAgent 长期记忆的两大失败模式：(1) 多跳答案所需的事实分散在不同时间点无法关联，(2) 信息状态更新（如日程变更）与旧记录冲突。AriadneMem 用知识图谱离线关联事实、用时间戳机制管理状态更新。

业务关联社区搜索中用户的历史搜索行为和偏好会随时间变化，搜索 Agent 需要类似的结构化记忆来管理用户画像的演化和多源信息的关联。

证据在 LoCoMo 基准上 AriadneMem 的多跳问答准确率达 71.3%（比 MemoryBank 高 +14.2pp），状态更新准确率达 84.7%（比 MemGPT 高 +19.5pp）。

Agentics 2.0: Logical Transduction Algebra for Agentic Data Workflows

提出 Agentics 2.0 框架，将 LLM 推理调用形式化为类型化语义变换，构建可靠可解释的企业级 Agent 工作流。

INSIGHTAgent 从原型到生产落地的核心障碍是可靠性和可观测性。Agentics 2.0 将每次 LLM 调用建模为可转导函数（typed semantic transformation），通过代数组合实现 schema 验证、错误追踪和流程编排。

业务关联社区搜索系统若引入 Agent 流水线（query 理解到检索到排序到答案生成），该框架提供了类型安全和错误追踪的工程化方案，提升系统可靠性。

证据在 3 个企业级 Agent 工作流场景中，Agentics 2.0 将结构化输出违规率从 12.3% 降至 0.8%，端到端错误可追溯率从 34% 提升至 96%，开发迭代速度提升 2.4 倍。

DeepResearchEval: An Automated Framework for Deep Research Task Construction and Agentic Evaluation

提出 DeepResearchEval 自动化框架，通过 persona 驱动的任务构建和 Agent 式评估解决 Deep Research 系统的评测难题。

INSIGHTDeep Research 系统的评估瓶颈在于任务构建：传统手工标注难以覆盖多样性。该框架用 persona-driven pipeline 自动生成研究任务，配合 Agent 式评估（自适应质量评估加自主事实核查）实现大规模自动化评测。

业务关联搜索质量评估同样面临标注成本高、覆盖面有限的问题。该框架的 persona-driven 任务自动生成思路可迁移到搜索系统的自动化评测场景。

证据在 10 个研究领域生成 500+ 评测任务，人工审核通过率达 87.2%；与人类评估的 Spearman 相关系数达 0.83，优于 GPT-4 直接评分的 0.71。

Yibo Wang, Lei Wang, Yue Deng, et al.
