AgentIR: Reasoning-Aware Retrieval for Deep Research Agents

提出推理感知检索范式，将 Agent 的推理链与查询联合编码以提升 Deep Research 检索质量。

INSIGHTDeep Research Agent 在每次搜索前会生成显式推理文本——AgentIR 证明将这些推理链纳入检索 embedding 可大幅提升召回质量，4B 参数模型超越 2 倍大小的传统 embedding 模型。

业务关联社区搜索场景若引入 Agent 辅助搜索（如复杂 query 的多步检索），可借鉴 AgentIR 的推理链编码思路，让检索模型利用 Agent 内部推理上下文，显著提升复杂查询的检索准确率。

证据在 BrowseComp-Plus 基准上，AgentIR-4B 达到 68% 准确率，传统 embedding 模型（2 倍参数量）仅 50%，BM25 为 37%。

Towards Agentic Recommender Systems in the Era of Multimodal Large Language Models

系统性综述多模态大模型驱动的 Agentic 推荐系统架构与演进方向。

INSIGHT下一代推荐系统的核心转变是从「被动推荐」到「主动 Agent」——LLM Agent 通过规划、工具调用和记忆机制，实现自主决策和多轮交互式推荐，但安全性、效率和终身个性化仍是关键挑战。

业务关联社区搜索可参考该综述中 Agentic 推荐的架构设计，例如引入 Agent 进行多步查询理解和主动推荐，特别是在复杂 UGC 内容理解和个性化推荐场景中。

证据综述涵盖 40+ 相关工作，系统对比了 LLM-ARS 的规划（planning）、工具使用（tool use）、多模态推理（multimodal reasoning）三大能力维度。

SE-Search: Self-Evolving Search Agent via Memory and Dense Reward

提出自演化搜索 Agent，通过记忆净化、原子查询和稠密奖励持续优化在线搜索行为。

INSIGHT搜索 Agent 的关键问题是「信息噪声累积」和「稀疏 RL 信号」——SE-Search 的 Think-Search-Memorize 策略通过记忆净化保留关键证据、原子查询训练鼓励更短更多样的 query、稠密奖励加速训练收敛。

业务关联社区搜索中用户 query 常为短文本且意图模糊，SE-Search 的原子查询训练和记忆净化策略可用于优化搜索 Agent 的多轮检索质量，减少无关文档累积。

证据SE-Search-3B 在单跳和多跳 QA 基准上绝对提升 10.8 分，相对 Search-R1 提升 33.8%。

Succeeding at Scale: Automated Dataset Construction and Query-Side Adaptation for Multi-Tenant Search

提出多租户检索场景下的自动化数据集构建和仅微调 query encoder 的索引保留适配策略。

INSIGHT多租户检索的核心痛点是缺乏标注数据和更新代价高——DevRev-Search 用 LLM-as-Judge 自动构建训练集，仅微调 query encoder（PEFT）即可获得强性能提升，无需重建文档索引。

业务关联社区搜索作为典型的多租户/多领域检索场景，可直接借鉴 Index-Preserving Adaptation 策略：只微调 query 端 encoder，避免全量重索引开销，同时利用 LLM 自动生成伪标注提升特定领域检索质量。

证据在 DevRev-Search、SciFact 和 FiQA-2018 三个基准上，PEFT query encoder 适配实现了「强性能-高效率」的最佳折中。

IntPro: A Proxy Agent for Context-Aware Intent Understanding via Retrieval-conditioned Inference

提出代理 Agent 通过检索条件推理实现上下文感知的用户意图理解。

INSIGHT意图理解不应是静态分类任务——IntPro 通过存储历史意图解释并在推理时检索参考，结合 GRPO 多轮训练和工具感知奖励，让模型学会何时依赖历史模式、何时直接推理。

业务关联社区搜索中 query 意图理解是核心环节，IntPro 的检索条件推理方法可用于构建个性化 query 理解模块——利用用户历史意图模式提升短文本 query 的消歧和意图识别准确率。

Behind the Prompt: The Agent-User Problem in Information Retrieval

揭示 AI Agent 作为搜索用户时，传统用户模型的「行为即意图」假设失效的结构性问题。

INSIGHT当 AI Agent 成为 IR 系统的主要用户时，个体行为无法区分是自主还是受操控指令驱动（结构性不可识别），但群体级别的平台信号仍能区分 Agent 质量层级，click model 在 Agent 交互上退化 8.5%。

业务关联社区搜索正面临越来越多的 Agent 用户（AI 写作/搜索 Agent），该研究提示我们：传统 CTR 模型和 click model 在 Agent 用户上效果会退化，需要重新设计适配 Agent 行为的用户模型和相关性建模方式。

证据分析 370K 帖子、47K Agent、4K 社区数据集；click model 在 Agent 交互上性能下降 8.5%；证明个体 Agent 行为在观测层面不可分类。

OSCAR: Online Soft Compression And Reranking

提出查询依赖的在线软压缩方法，同时完成 RAG 文档压缩与重排序。

INSIGHT传统硬压缩（截断文本）或离线软压缩（预计算 embedding）都有局限——OSCAR 在推理时动态压缩检索文档为连续 embedding，同步完成重排序，实现 2-5x 推理加速且几乎无精度损失。

业务关联社区搜索若引入 LLM 进行 RAG 增强（如搜索结果摘要生成），OSCAR 的在线压缩+重排序可大幅降低 LLM 推理成本，特别适合 UGC 短文本场景的长检索列表处理。

证据在多个 RAG 基准上实现 SOTA 性能，推理速度提升 2-5 倍，精度损失极小到无。

Maxime Louis, Thibault Formal, Hervé Dejean, Stéphane Clinchant

Combating data scarcity in recommendation services: Integrating cognitive types of VARK and neural network technologies (LLM)

结合 LLM 语义分析与 VARK 认知类型建模，解决推荐系统冷启动问题。

INSIGHT冷启动不仅是数据稀缺问题，也是用户认知偏好未知问题——结合 LLM 做内容语义增强和知识图谱构建，用 VARK 认知类型做用户画像，可从极少交互数据中生成有效推荐。

业务关联社区搜索中新用户和新内容的冷启动是常见问题，该方法的 LLM 内容增强 + 知识图谱构建思路可用于 UGC 短文本的语义标签增强和新用户画像快速构建。

Towards Realistic Personalization: Evaluating Long-Horizon Preference Following in Personalized User-LLM Interactions

提出 RealPref 基准评测 LLM 在长期交互中对用户偏好的个性化跟随能力。

INSIGHTLLM 的个性化能力随上下文长度增加和偏好表达变隐式而显著退化——100 个用户画像、1300 个偏好的基准测试表明，将偏好理解泛化到未见场景仍是重大挑战。

业务关联社区搜索中用户偏好的长期建模是个性化排序的基础，该研究揭示的 LLM 在隐式偏好和长上下文下的退化现象，对使用 LLM 做个性化搜索排序有重要警示意义。

证据100 个用户画像、1300 个偏好、4 种偏好表达类型和 3 种测试题型的系统评测；性能随上下文增长和偏好隐式化显著下降。
