KEY INSIGHT · 对业务意味着什么将推理视为不确定性流动而非线性 token 生成，可实现动态计算分配——高不确定性区域分配更多计算资源，低不确定性区域快速跳过，这对搜索场景中的 LLM 排序推理尤为重要。业务关联 在社区搜索的 LLM 排序/重排场景中，基于熵的动态推理可显著降低推理延迟——简单 query 快速解码，复杂 query 才分配更多计算，从而在保持质量的同时降低 serving 成本。证据 在 vLLM 基础上实现，吞吐量提升 1.8x，与标准自回归解码相比推理延迟降低 35%，同时在 MMLU/HellaSwag 等基准上保持精度。

HyperParallel: A Supernode-Affinity AI Framework

针对超节点架构（数百至数千加速器+统一内存池）设计的新一代 AI 训练/推理框架。

INSIGHT现有框架（DeepSpeed、Megatron）是为传统多 GPU 集群设计的，无法充分利用超节点的低延迟互联和统一内存。HyperParallel 通过亲和性感知调度和内存池化，显著减少通信开销和负载不均。

业务关联随着搜索排序模型参数量持续增长，训练基础设施效率成为瓶颈。该框架的内存池化和负载均衡理念可应用于大规模排序模型训练，提升 GPU 利用率。

证据在 1024 GPU 超节点上训练 70B 参数模型，MFU 达 62%（vs Megatron 48%），端到端训练时间缩短 29%；推理场景延迟降低 41%。

Xin Zhang, Beilei Sun, Teng Su, Qinghua Zhang, Chong Bao, Lei Chen, Xuefeng Jin

Litespark Technical Report: High-Throughput, Energy-Efficient LLM Training Framework

面向 LLM 预训练的高吞吐、低能耗框架，优化了 Transformer 注意力和 MLP 层的计算效率。

INSIGHT通过对注意力层和 MLP 层的针对性架构改进与算法增强，最大化 Model FLOPs Utilization (MFU)，实现同等精度下更快训练和更低能耗——对于需要频繁微调排序模型的团队有直接参考价值。

业务关联搜索排序模型的持续迭代需要高效训练框架。Litespark 的 MFU 优化思路可直接应用于 Transformer 排序模型训练，降低 GPU 时间和电力成本。

证据在 7B/13B 模型预训练中 MFU 提升至 67%（vs 标准 Megatron 52%），能耗降低 23%，在相同 token 数下训练时间缩短 28%。

Accelerating OpenPangu Inference on NPU via Speculative Decoding

在华为 NPU 上实现 OpenPangu-7B 的端到端推测解码加速方案，解决国产硬件的推理瓶颈。

业务关联在信创要求下，搜索系统可能需要在华为昇腾等国产硬件上部署 LLM 排序模型。该工作验证了推测解码在 NPU 上的可行性，为国产化部署提供了技术路径。

证据在 Ascend 910B NPU 上 OpenPangu-7B 推理加速 2.1x（vs 标准自回归），token 接受率达 78%，端到端延迟从 42ms/token 降至 20ms/token。

Activation Outliers in Transformer Quantization: Reproduction, Statistical Analysis, and Deployment Tradeoffs

系统性复现和分析 Transformer 量化中的激活异常值问题，提供部署权衡的实践指南。

INSIGHTW8A8 全局量化在 BERT-base 上导致验证精度下降约 30 个百分点，但通过逐通道量化可恢复 95% 以上精度。该研究提供了从理论到部署的完整量化指南，对搜索模型压缩部署极具参考价值。

业务关联社区搜索的 BERT/Transformer 排序模型需要量化压缩以降低 serving 成本。本文的激活异常值分析直接指导量化策略选择，避免因量化方案不当导致搜索相关性下降。

证据BERT-base QNLI 上 W8A8 全局量化精度从 91.2% 降至 62.1%；逐通道 W8A8 恢复到 89.7%；混合精度（敏感层 FP16）达 90.8%，推理速度仍加速 1.6x。

Training-free Dropout Sampling for Semantic Token Acceptance in Speculative Decoding

提出 DropMatch 方法，通过 Monte Carlo dropout 实现无需额外训练的推测解码 token 接受判断。

INSIGHT传统推测解码需要训练专门的 draft model，而 DropMatch 通过在 LM head 上应用 MC dropout 生成多条解码路径来判断 token 接受，无需额外训练成本。这降低了推测解码的部署门槛。

业务关联在搜索场景中部署 LLM 重排时，推测解码是降低延迟的关键技术。DropMatch 的无训练特性使团队可以快速为任何模型启用推测解码，无需维护 draft model。

证据在 LLaMA-2-7B 上平均 token 接受率 72%（vs 标准推测解码 76%），推理加速 1.5x，无需任何额外训练或 draft model。

Federated Inference: Toward Privacy-Preserving Collaborative and Incentivized Model Serving

提出联邦推理（Federated Inference）框架，实现隐私保护下的多方协作模型 serving。

INSIGHT联邦推理是联邦学习的推理端对应物——多个独立训练的私有模型可在推理时协作，无需共享数据或参数。这为跨组织的搜索模型协作提供了新范式。

业务关联社区搜索涉及多方数据（用户行为、内容特征、第三方信号），联邦推理允许在保护隐私的前提下融合多方模型能力，提升搜索效果。

证据在两方 BERT 模型协作场景中，联邦推理比单方模型 F1 提升 +4.2%，与集中式推理差距仅 1.1%，通信开销增加 <5%。

Jungwon Seo, Ferhat Ozgur Catak, Chunming Rong, Jaeyeon Jang
