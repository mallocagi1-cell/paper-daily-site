CoRe: A Continuously Reward-Finetuned LLM Query Rewriter for Multi-Stage Context-Aware Relevance in Web-Scale Video Search

针对生产环境 LLM query 改写器的两难——奖励要反映改写如何被线上排序器消费，训练又必须便宜到能随数据漂移持续重训——提出 CoRe，已在某大型短视频搜索引擎按周重训上线超过 5 个月。奖励直接取自已部署的多模态相关性模型，并采用与生产融合公式一致的乘性比值形式，消除离线奖励代理与线上的偏差；半在线 Mixed Preference Optimization 用 DPO 式成对目标只对采样轨迹的 top-k/bottom-k 子集回传梯度，配合分阶段结构把训练器/推理服务的参数同步从每步降到每阶段，使百万级周训练量可承受。

TASR: Training-Free Adaptive Stopping for Iterative Retrieval

迭代式 RAG agent 常在模型已收敛答案后继续检索，这些调用既不改预测也不改证据，纯属浪费；已有停止策略需从标注轨迹学习，换模型或任务就要重训。TASR 提出一条免训练判据：当模型重复上一轮归一化答案、且经等渗校准的 logit margin 超过 0.25 时即停止，该阈值在全部 24 个(模型,检索器,语料)配置下固定不变。在 3 模型×2 数据集的干扰网格上，TASR 用 fixed-k=5 的 62.6% 调用量保留其 94.8% 的 macro F1，并比 fixed-k=3 高 +3.42 F1。

INSIGHT停止时机的判断不一定要训练分类器或 value head，答案稳定加置信度阈值这条一行规则就能跨模型/检索器迁移，省去为每个新系统重训停止器的成本。对做 agentic 搜索/RAG 的团队，这是立即可用的降本手段：在多轮检索里加一个收敛判据即可砍掉约 37% 的检索调用而几乎不掉指标，特别适合按 query 复杂度自适应控制检索预算。

Adrian Kieback, Uyiosa Philip Amadasun, Aman Chadha, Aaron Elkins

CacheRL:Multi-Turn Tool-Calling Agents via Cached Rollouts and Hybrid Reward

CacheRL 训练小型 agent 基座模型，在多步工具调用任务上达 92% 过程准确率，逼近 GPT-5 的 94%，而所需算力少 100 倍。它针对三个实际训练难题：从大模型规模化迁移工具调用知识、无需昂贵的在线工具执行即可做 RL、从带噪缓存环境稳健学习。三项创新为：混合思维轨迹流水线用 LLM 生成的推理痕迹增广轨迹，教模型调用什么工具以及为什么；CacheAgentLoop 用三级模糊缓存消除在线执行成本，并以 token 级 mask 保持轨迹保真；缓存层级感知的奖励动态调节答案质量权重以避免劣化。

INSIGHT让小模型在多步工具调用上接近前沿大模型的关键，是把为什么这样调用的推理痕迹注入训练数据，并用缓存回放替代昂贵的真实工具执行来做 RL。对要落地搜索/问答 agent 的团队，这条路线把 agent RL 的训练成本压低约两个数量级；三级模糊缓存加 token 级 mask 的设计尤其适合工具响应不稳定、在线执行昂贵的场景。

Md Amirul Islam, Sumiran Thakur, Huancheng Chen, Su Min Park, Jiayun Wang, Gyuhak Kim

The Coin Flip Judge? Reliability and Bias in LLM-as-a-Judge Evaluation

LLM-as-a-Judge 被广泛用于排名模型输出、训练奖励模型和刷榜，但它重复运行的可靠性少有刻画。作者对 2 个 OpenAI 评委(GPT-4o-mini、GPT-4.1-mini)在 10 类共 29 个任务上各做 50 次成对与 50 次逐点重复评测，并辅以温度与 prompt 敏感性消融。结果显示：成对偏好平均有 13.6% 会翻转，28% 的问题翻转率超 20%，单题最高达 56%；GPT-4o-mini 存在显著首位偏置(72% 选 A，p=0.024)；而逐点分差很小(10 分制仅 0.19–0.36)且总体不显著。

INSIGHT用 LLM 当评委做离线评估时，单次成对判断的随机性可能高到接近抛硬币，且存在系统性首位偏置，直接拿来刷榜或训练奖励模型风险很大。对搜索/推荐做 LLM 自动评测的团队，应做多次重复取多数、随机化候选顺序、并优先看逐点分而非单次成对结论，同时把评测噪声纳入显著性判断。

Abel Yagubyan

SANA: What Matters for QA Agents over Massive Data Lakes?

数据湖上的探索式问答(EQA)需要 LLM agent 发现相关源、分析检索数据并据中间结果调整动作；端到端准确率无法区分失败发生在搜索、规划、数据分析，还是 agent 的动作策略(决定下一步做什么、何时提交答案)。SANA 把 EQA 任务转成含黄金源序列、净化子问题和执行记录的运行时画像，据此构造理想化的搜索/规划/分析工具逐一消融，残差即为动作策略失败的诊断证据。作者用它改造 LakeQA、KramaBench 两个基准，评测了轻量与中等规模的 agent。

INSIGHT评估搜索 agent 不能只看最终准确率，要能把失败归因到搜索、规划、分析、动作策略哪一环。SANA 的理想化工具消融给出一套可复用的诊断方法：逐个把某能力替换为黄金版，看准确率回升多少来定位瓶颈。对自研搜索/问答 agent 的团队，这是排查到底是召回不行还是决策不行的实用评测手段。

Austin Senna Wijaya, Jiaxiang Liu, Haonan Wang, Eugene Wu

Benchmarking Web Agent Safety under E-commerce Deceptive Interfaces

随着自主 web agent 被部署执行真实任务，其安全性成为关键问题。作者研究电商场景下 web agent 面对真实欺骗式界面的行为，提出 WebDecept——一个轻量可配置的插件框架，可把欺骗式界面模式受控注入现有 web 环境。基于它实例化了开放网络上常见的 7 类欺骗模式(定向广告、域名重定向、购物诱导等)，在任务执行时注入前端并评测多个多模态 web agent。结果显示当前 web agent 对多类欺骗界面高度易感，基于 prompt 的约束往往不足以缓解这些失败。

INSIGHT多模态 web agent 在遇到广告诱导、域名重定向等欺骗界面时很容易被带偏，且加 prompt 约束并不可靠，部署购物/导购类 agent 前必须做对抗性界面测试。WebDecept 提供了可配置注入 7 类欺骗模式的红队框架，对要上线交易/电商 agent 的平台，这是评估与加固 agent 安全性的实用工具。

Zijing Shi, Meng Fang, Ling Chen

Pretrained to Imagine, Fine-Tuned to Act: The Rise of World-Action Models

NVIDIA

NVIDIA 这篇博客梳理了 World-Action Model(WAM)的兴起：与从 VLM 骨干起步的 VLA 不同，WAM 从已建模场景动态的视频预训练骨干起步，再适配为机器人控制并预测动作。文章给出三种范式(逆动力学、联合预测、仅表征)与动作整合方式，并列出 DreamZero(Wan 14B 骨干，RoboArena 得分 1750)、LingBot-VA(Wan 2.2-5B，1.6 万小时跨形态预训练)等代表模型，对比 VLA 基线 Pi-0.5(1622)；WAM 带视频生成时每动作块需 590–800ms，约为 Pi-0.5(约 190ms)的 3–4 倍。

INSIGHT机器人基座的下一代很可能是 WAM 与 VLA 的混合，而非某一路线独大：视频预训练提供世界会如何演变的先验，VLM 提供语言-视觉知识，两者都各有接地缺口。对关注 agent 范式演进的从业者，这给出一个清晰信号：把先想象再行动(预训练世界模型，再微调出动作)作为构建动作型 agent 的组织原则，同时要权衡视频生成带来的 3–4 倍推理延迟。
