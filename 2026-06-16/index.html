Is ChatGPT Fair for Recommendation? Evaluating Fairness in Large Language Model Recommendation

随着 Recommendation via LLM（RecLLM）成为新范式，LLM 自带的社会偏见可能传导到推荐结果，而传统推荐公平性基准不适配 LLM 范式。论文提出 FaiRLLM 基准，覆盖用户侧 8 个敏感属性、music 与 movies 两个推荐场景，用精心设计的指标对比“带敏感属性”与“中性”指令下 LLM 推荐结果的差异。实验发现 ChatGPT 在多个敏感属性上生成的推荐存在不公平，代码与数据已开源（RecSys 2023 短文，2026 年 6 月更新至 v4）。

KEY INSIGHT · 对业务意味着什么当把 LLM 直接当作打分 / 生成式推荐器时，公平性风险从“特征工程层”上移到“语言先验层”，仅靠传统去偏特征无法覆盖。FaiRLLM 的评测协议——构造仅在敏感属性上有差异的 prompt 对、度量推荐列表偏移——可直接迁移到中文社区搜索的 LLM 重排 / 生成场景，作为上线前的偏见回归测试。对从业者的提醒是：RecLLM 的公平性需要按 prompt 敏感属性维度单独审计，而不能沿用历史 CTR 公平指标。

Verifiable User Simulation for Search and Recommendation Systems

RMIT

基于 LLM 的用户模拟越来越多用于评测搜索引擎、推荐系统与 RAG，但多数模拟器不透明：难以判断模拟用户为何做出某选择、是否符合预设画像，且 LLM 会因语言、教育程度、文化背景产生有偏响应。该 tutorial 提出把用户模拟器当作可审计的工程制品，由 7 个可审计组件构成（结构化 Persona、任务感知 Contract、人-机匹配 Execution、可审计 Trace、画像对齐 Verification 等），形成一套设计-审计框架，保证模拟的可验证性与对弱势群体的公平对待。

INSIGHT离线评测越来越依赖 LLM 模拟用户，但“模拟器本身是否可信”常被忽视。该框架的价值在于把模拟拆成可逐项验证的组件——Persona 是否被忠实执行、Trace 能否复盘决策、Verification 能否检出画像漂移，给出了搜推团队搭建仿真评测台的审计清单。对社区搜索而言，可借此在灰度前用可控、可解释的模拟用户压测排序 / 生成策略，并把“模拟用户对少数群体是否公平”纳入验收，避免用有偏模拟器得出有偏结论。

Chenglong Ma, Xinye Wanyan, Danula Hettiachchi, Ziqi Xu, Yongli Ren, Jeffrey Chan
