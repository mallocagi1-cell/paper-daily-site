PCR-CA: Parallel Codebook Representations with Contrastive Alignment for Multiple-Category App Recommendation

针对应用商店中“多品类 App”传统类目体系无法刻画语义重叠、导致个性化效果差的问题，提出 PCR-CA 端到端 CTR 框架。先从 App 文本抽取多模态 embedding，再用并行码本 VQ-AE（区别于 RQ-VAE 的层级残差量化）在多个码本上并行学习离散语义表征，独立编码玩法、画风等不同侧面；并在用户与物品两侧引入对比对齐损失增强长尾表征，配合双注意力融合 ID 特征与语义特征。大规模数据上整体 AUC +0.76%、长尾 App AUC +2.15%；线上 A/B 实现 CTR +10.52%、CVR +16.30%，已全量部署于 Microsoft Store。

Implicit Reasoning for Large Language Model-based Generative Recommendation

📖 深度解读 · 7 分钟 →

针对 LLM 做生成式推荐（GR）时用 Semantic ID 表示物品、破坏 LLM 自然语言推理接口的问题，论文系统拆解显式推理（CoT + rationale）训练流程，指出三大缺陷：世界知识表达被削弱、SID 与自然语言 token embedding 空间错位、对 rationale 质量敏感。据此提出轻量隐式推理范式 PauseRec，无需采集推理链、无需推理对齐训练。结果：相比标准显式 CoT 方法效果最高提升 6.22%，训练 GPU 时长最多降低 65%，推理速度最高提升 71.3%。

INSIGHT该工作给出一个反直觉但实用的结论——在生成式推荐里强行让 LLM 产出显式 rationale，反而因 SID 与自然语言空间错位而受损，隐式“停顿”推理用更低成本拿到更好效果。对落地 LLM4Rec 的团队：可优先尝试隐式推理而非昂贵的 CoT 蒸馏管线，省下的 65% 训练与 71% 推理开销对线上时延敏感场景尤为关键。也印证 SID 词表与 LLM 原生词表的对齐是 GR 的核心瓶颈。

Yinhan He, Liam Collins, Bhuvesh Kumar, Jundong Li, Neil Shah, Donald Loveland

When Recommendation Denoising Meets Popularity Bias: Understanding and Mitigating Their Interaction

隐式反馈中的误点击、曝光偏置会污染推荐训练，主流去噪用 small-loss 启发式（loss 大即视作噪声而降权）。论文从流行度偏置视角重审该启发式：长尾正样本因稀疏更难拟合、loss 天然偏大，单调按 loss 降权会误伤“干净但难学”的长尾信号、加剧头尾失衡。作者用“有效头尾信号比”形式化该交互，证明当尾部正样本 loss 分布右移时 small-loss 降权会拉高头尾比。据此提出即插即用的 Popularity-Aware Denoising (PAD)：按物品流行度调节去噪强度，对高曝光物品强去噪、对长尾保守。在 3 个数据集 × 3 个 backbone 上优于代表性去噪基线，MF 类模型上 accuracy-diversity 权衡更优。

INSIGHT揭示了“去噪”与“流行度去偏”两个常被独立处理的模块其实相互冲突——单调 small-loss 去噪会变相放大流行度偏置。实践启示：在 UGC 点击日志（误点击多、长尾内容多）上做去噪时，不应对所有样本用统一 loss 阈值，而应按内容热度分层设置去噪强度，避免把冷门优质内容当噪声过滤掉。PAD 是轻量 plug-in，可直接挂到现有排序模型上。

Guohang Zeng, Jie Lu, Guangquan Zhang

ChronoID: Infusing Explicit Temporal Signals into Semantic IDs for Generative Recommendation

生成式推荐依赖 Semantic ID，但现有 Semantic ID 学习完全“时间无关”——时间只通过 session 切分、序列顺序等隐式影响，导致不同时间上下文的交互被压成同一语义表征，隐含“物品语义与用户意图时间平稳”的错误假设。ChronoID 系统刻画时间信号的三个正交维度，提出统一的时间感知 Semantic ID 学习框架，并贡献一个“时间显式”的生成式推荐 benchmark，回答时间信号该如何注入、架构如何设计、增益来源何处三个问题。

INSIGHT把“时间”从序列顺序的隐式信号升级为 Semantic ID 内部的显式编码，是对当前生成式推荐 ID 体系有针对性的补强。对内容时效性强的场景（社区热点、新闻、短视频），物品语义会随时间漂移，时间无关的 Semantic ID 会把不同时段的同一物品混为一谈；ChronoID 给出的三维时间设计空间，为“在 ID 中显式建模时间”提供了可复用的设计参考。

Dongdong Nian, Dongqi Fu, Chenliang Xu, Yinglong Xia, Hong Li, Hong Yan, Jian Kang

OdysSim: Building Foundation Models for Human Behavior Simulation

CMU

LLM 越来越多被用作“人类模拟器”做交互评测与社会模拟，但 helpfulness 导向的后训练让其收敛为同质、过度顺从的助手腔，产生行为 Sim2Real gap。OdysSim 是迄今最大规模的行为基础模型系统研究：提出 SOUL 五能力轴（CONV/SS/COG/ROLE/EVAL）统一 62 个数据集与 23 个 benchmark 任务，构建 OdysSim 语料（2140 万交互、100 亿 token，回填社会语境），用 midtraining + 任务 RL + 专家蒸馏的配方训出开源 8B 的 OSim 模型，在 23 个任务中 8 个取得第一或并列第一，超过单个前沿模型。

INSIGHT对推荐/搜索从业者，行为基础模型的价值在于“可规模化的合成用户”——用于离线评测排序策略、冷启动模拟、上线前的反事实估计。该工作指出通用 helpful 对齐会损害行为真实性，提示直接拿通用 LLM 当用户模拟器评测推荐系统会有系统性偏差，需要专门的行为训练语料与能力分轴评估；8B 开源模型也降低了自建用户模拟器的门槛。

Xuhui Zhou, Weiwei Sun, Weihua Du, Jiarui Liu, Haojia Sun, Qianou Ma, Tongshuang Wu, Yiming Yang 等 9 人

Personalization and Evaluation of Conversational Information Access

Radboud University

随着用户更偏好直接答案而非链接，会话式信息获取（CIA）需要纳入个人上下文。该博士论文从三方面切入：个人上下文抽取——研究会话中的实体链接，发布会话实体链接数据集 ConEL，提出面向会话的实体链接方法 CREL；个性化回复生成——提出 LAPS 高效构建大规模、人工撰写的个性化会话数据集，研究如何利用用户偏好生成个性化回复；以及评测——提出无参考、可自动评估整段会话且与人工判断高度一致的 FACE 方法。

INSIGHT系统梳理了“个性化会话搜索”的三块拼图：上下文抽取（实体链接）、个性化生成、可解释评测。对做 LLM 会话式搜索的团队，CREL 提示会话场景的实体链接需专门建模指代与省略，LAPS 给出低成本构造个性化对话数据的路径，FACE 则提供无需参考答案、可自动跑的整轮会话评测——这对缺乏标注的 UGC 会话搜索评测尤其实用。

Mood-Aware Music Recommendation: Integrating User Affective Signals into Ranking Systems

音乐推荐中协同过滤在交互稀疏时表现差，内容过滤多关注流派/乐器/歌词，对情绪识别关注不足；而用户情绪强烈影响选歌。论文提出 mood-conditioned 排序框架，在 energy-valence（能量-效价）二维情绪空间用 softmax 采样把用户情感信号融入推荐。通过单盲实验让参与者对比本方法与基线推荐，结果显示感知推荐质量提升，为情绪信号融入音乐推荐提供了初步证据。

INSIGHT提供了一个把“上下文情绪”显式建模进排序的轻量思路——在 energy-valence 空间做 softmax 采样，而非把情绪当普通特征拼接。对内容/UGC 推荐的启示：场景化上下文信号（情绪、时段、地点）可作为排序的条件分布而非静态特征。但证据仅为小规模单盲主观实验、无公开数据集与离线指标，落地前需补充规模化离线/线上验证。

Terence Zeng, Abhishek K. Umrawal
