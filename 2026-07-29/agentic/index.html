From Proprietary to Open-Source: Bridging the Distribution Gap via Multi-Agent Protocol Distillation in Agentic Search

针对搜索智能体仅靠结果奖励监督稀疏、闭源教师又无法提供 logits 的问题，MAPD 先让离线多智能体分解问题、检索证据并修复失败轨迹，再压缩为去风格化 JSON 协议，以特权分支的逐 token 自蒸馏联合 GRPO 训练开源模型。七个 QA 基准上，Qwen3-1.7B/4B 平均成功率达 39.4%/44.4%，相对最强 SDAR 提升 4.8%/3.3%。

VecTree-RAG: An Agentic Retrieval-Augmented Generation Framework Combining Vector and Tree Retrieval for Efficiency and Accuracy

VecTree-RAG 将“跨论文找相关文献”与“论文内定位证据”拆成两种工具：向量检索先缩小文档和章节范围，推理智能体再遍历来源可验证的章节树，并按需从页存储读取全文。它在 300 个 QASPER、54 个 LitQA2 和 49 个 MOSAIC 问题上均取得最高分，QASPER 证据页精度为 0.274，基线仅 0.046–0.071。

INSIGHT层级导航的价值不只是提高答案分数，而是让智能体在阅读前先确定结构位置，减少无关上下文与推理 token，并保留可审计的证据路径。对社区搜索可把帖子、评论串和问答楼层建成树，先用向量召回主题，再让 Agent 沿父子结构定位支持片段，缓解短文本被固定切块割裂的问题。

Xinyan Zhong, Yuwei Shi, Yuqi Wei, Chen Shen, Tianhang Zhou, Zhenghao Wu

Structure Over Scale: Schema-Constrained Causal Graphs for RAG

BBCG

HCG-RAG 不再对语料做开放式实体关系穷举，而是先蒸馏固定类型的因果变量，再构建可审计的两层层级因果图，用结构过滤辅助检索。其答案质量匹配或超过实体关系 GraphRAG，同时节点数减少 3–20 倍、建图 LLM 调用减少 8–135 倍；消融显示因果图过滤比纯向量检索提升 6 个百分点。

INSIGHT这项结果说明 GraphRAG 的关键不是图越大越好，而是图中是否编码了查询真正需要的高层结构。社区搜索可围绕“用户诉求—条件—观点—证据—结论”设计有限 schema，把图作为召回后的可解释过滤器；相比全量抽实体，成本更低，也便于运营或领域专家纠错。

让AI离开温室，走向动态世界：MineExplorer揭示顶级多模态大模型被忽视的能力断层

Meituan

美团 MineExplorer 用 Minecraft 动态沙盒评测含隐藏前置条件的分钟级长程任务，提供 813 个经人工验证的 1–4 hop 实例、每例最多 1800 个环境步，并开源多智能体造题与里程碑评测流程。18 款模型中最佳 Claude-Opus-4.6 总成功率仅 41 分，1-hop 到 4-hop 从 77 分跌至 12 分，近 60% 失败源于导航。

INSIGHT基准揭示“给更多步数或更多历史帧”不能修复长程 Agent，过期观察甚至会干扰当前状态判断，真正瓶颈是感知、状态与隐藏依赖的持续对齐。搜索团队可借鉴其 DAG 任务描述和规则化里程碑，把复杂检索拆成可自动验收的子目标，并单独监控计划、检索、导航和状态更新失败。

MPR-CiteG: Enhancing RAG with Multi-Portfolio Retrieval and Citation-Grounded Generation

Chungnam National University

MPR-CiteG 用查询扩展、同义词鲁棒、焦点平衡和全局翻译四个检索组合提升覆盖，再以 CiteG 强制答案逐条绑定来源，在 ScienceON AI Challenge 获第二名。Qwen2.5-14B 方案的检索准确率为 0.4943、总分 0.5415；去掉查询扩展后准确率降至 0.4330，总分下降 0.0729，验证了多组合召回的贡献。

INSIGHT对可核验搜索，召回多样性与引用生成应作为一个闭环优化：先让不同查询策略覆盖语义、词形和跨语言表达，再在生成阶段拒绝无来源断言。其代价也很明确，50 个查询在单张 RTX A6000 上约需 0.7 小时，因此线上应按问题复杂度动态启用组合，而非所有请求全量展开。

Kimi K3: Open Frontier Intelligence

MMoonshot AI

Kimi K3 是 2.8T 参数、每 token 激活 104B 的多模态 MoE，支持 100 万 token 上下文。Stable LatentMoE 从 896 个专家中激活 16 个，Kimi Delta Attention 改善长序列信息流；配合持久 rollout 与 Agentic RL，扩展效率较 Kimi K2 提升约 2.5 倍，并开放完整权重。

INSIGHT长程搜索 Agent 的底座能力正在从“长上下文读取”扩展到持久环境状态、跨轮 rollout 与多档推理预算的联合训练。对业务团队而言，完整 2.8T 部署门槛极高，但可优先复用其状态持久化和按难度分配推理预算的系统思路，并以开放权重做教师或离线轨迹生成。

Language-Routed RAG and Direct Option Scoring for Multilingual Financial QA: DS@GT at FinMMEval

DS@GT 在 LangGraph 中先识别语言，再从 30,209 条多语言知识库用 BGE-M3 与 FAISS 召回示例，并通过 RADS 直接读取候选选项的下一 token 概率，避免自由生成。系统覆盖英语、西语、希腊语、中文和印地语；消融发现 CoT 使希腊语准确率从 90.7% 暴跌至 20.9%，说明推理策略必须按语言路由。

INSIGHT同一套“多步推理”提示并不适合所有语言，Agent 应联合路由检索索引、底座模型和答案打分方式，而非只在入口做语言识别。对多语言 UGC 搜索，可先用离线消融建立语言级策略表；对于封闭候选或结构化动作，直接概率打分通常比生成解释更稳定、更便于校准。

The Physics of Multi-Turn Long-Horizon Planning: From Pre-training to Post-training via Single- and Multi-Teacher On-Policy Agentic Distillation

CASUCAS

论文用幻想炼金、畜牧和电子装配三个可控环境研究 Agent 长程规划在预训练、GRPO/OPD 后训练和多教师蒸馏中的形成机制。只学短任务时，中程与长程 pass@8 仅 0.83%/0%；加入 5% 中程轨迹后中程升至 51.88%，加入 5% 长程轨迹后长程升至 11.46%，表明少量完整轨迹可激活组合泛化。

INSIGHT原子工具调用能力不会自然组合成长计划，训练数据必须包含少量完整的跨步骤状态转移；低质量、长时程场景下，OPD 的稠密更新比 GRPO 的稀疏信用分配更稳定。构建搜索 Agent 时应同时保存成功动作与中间状态，并谨慎蒸馏教师独有流程，否则可能破坏学生已有世界模型。

Tianyi Men, Zhuoran Jin, Kang Liu, Jun Zhao

Robust Interpretation of Historical Documents in Knowledge Graphs Through Query Inference and Execution

CCVCUUAB

该半符号 Agentic GraphRAG 让 LLM 合成图查询，并以 word spotting 修复历史文档的 OCR/手写转写噪声，从而在近似匹配下保留可追溯查询路径。传统 RAG 的 NERO-ANLS 难超 0.50，而 GraphRAG 在 Qwen3-VL 上最高达 0.876；噪声 HTR1 下，Phi-4 经词形扩展从 0.53 提升到 0.631。

INSIGHT当文本噪声会破坏实体字符串时，单纯扩大向量召回不如把近似词形匹配与符号查询交替执行：Agent 负责提出结构化约束，检索器负责容错落地。社区搜索中的错别字、昵称和口语变体同样适用，但图模式需保持简单、可审计，并用确定性指标和 LLM 评审双重验证。

MARCH: Evaluating the Intersection of Ambiguity Interpretation and Multi-hop Inference

Chung-Ang UniversityAdobe

MARCH 从 MuSiQue 构建 2,209 个多跳歧义问题，配套两种解释、证据段落和长短答案；CLARION 先由规划 Agent 检测并分类语义、句法或约束歧义，再让 ReAct Agent 分解释检索与综合。人类无限制搜索的 STR-EM 为 73.0，最佳 CLARION 仅 38.73，显示多跳歧义仍有巨大能力缺口。

INSIGHT搜索 Agent 最危险的错误不是某一步没召回，而是第一跳过早锁定主流解释，导致后续证据链整体被剪掉。对社区短查询，应在检索前显式产出多个可验证解释，并为每条解释独立积累证据；当解释之间冲突时再请求澄清，比在单一路径上反复搜索更可靠。
