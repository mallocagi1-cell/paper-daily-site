SMART: LLM-Augmented Hybrid Retrieval for Dynamic Product Ads

面向千万级商品库的动态广告召回，SMART 将规则查询与 BM25 用于再营销，将 LLM 查询与稠密 ANN 用于新兴趣探索，并用轻量质量门控只把约 10% 用户送入 LLM 路径。该设计减少 90% 的 LLM 成本；Snap 两周线上 A/B 测试相对强向量基线提升转化率 27.6%。

EGR: Embedding-Native Generative Retrieval with a Shared LLM

Snap

EGR 用同一个共享 LLM 把商品元数据与用户行为历史编码到统一向量空间，直接以商品稠密向量建索引，并通过联合对比学习同时完成相似商品聚类和用户—目标商品对齐。它在 Amazon Reviews、Snap 工业数据和冷启动多模态场景均优于基线，生产部署带来 2.91% 的转化率提升。

INSIGHT该方法绕开 Semantic ID 的量化、词表更新和 token 到物品映射负担，同时避免分离训练 item encoder 与 query generator 造成的空间错位。对 UGC 搜索，可让同一模型编码帖子文本和用户上下文，再沿用成熟 ANN 基建；新增内容只需生成向量即可入库，适合高频更新与冷启动。

OxygenREC-v2: Internalizing Discrimination into Generative Recommendation

JD.com

OxygenREC-v2 将点击、加购、下单等行为作为指令直接条件化 SID 生成，并在后训练中用未来行为特权信息与熵感知自蒸馏实现无需外部奖励模型的策略优化。京东部署的 3B 参数、1B 激活 MoE 相比 v1 在线提升 UCTCVR 1.6%–4.4%、GMV 2.8%–6.8%。

INSIGHT关键变化是把业务目标放到生成前缀中，从第一步解码就改变候选分布，而不是生成后再交给独立排序器纠偏。社区搜索可把点击、长停留、互动等目标编码为条件指令，并用可验证命中与未来行为做训练监督；这有望减少多奖励权重调参和策略漂移下的奖励投机。

Melo: A Production LLM-Powered Music Recommendation Agent

NetEase

网易云音乐的 Melo 以确定性的五节点状态图编排 LLM 与异构工具，用线上搜索索引做实体校验，并以反思重试修复过度约束导致的长尾退化。一个月 A/B 测试使主留存指标提升超过 2 个百分点、核心播放列表参与时长增加超过 1 分钟；实体误识别下降 7.8 个百分点。

Realizing Scaling Laws in Recommender Systems: A Foundation-Expert Paradigm for Hyperscale Model Deployment

Meta📖 深度解读 · 8 分钟 →

Foundation-Expert 范式由中央基础推荐模型生成针对具体候选的 target-aware embedding，再交给各业务面的轻量专家模型与本地特征交互，避免知识蒸馏在大数据区间的传递损失。方案实现 0.64–1.0 的知识传递比，自 2025 年在 Meta 服务每日数百亿请求，跨业务面累计增益 0.359%。

INSIGHT推荐 Scaling Law 的难点已从训练大模型转向把能力经济地分发到多场景。社区搜索可让重型模型近线产出 query/用户—候选相关的动态表征，线上仍由低延迟专家排序器融合场景特征；相比静态用户向量，这种条件化特征保留候选交互，又比全量在线大模型更易控制成本。

CogRec: Structure-Cognitive Fast-and-Slow Reasoning for Generative Recommendation

CogRec 不再把层次化 Semantic ID 仅当作记忆目标，而是补充层内语义图和物品邻域，并用 Match、LateralJump、Explore 三类 SID Routing 操作实现快慢两种结构推理。三个公开序列推荐基准显示，结构路由优于对应直接生成；论文也指出路径过长会增加解码成本与累积错误。

INSIGHT把推理过程约束在最终输出所用的 SID 拓扑里，可避免自然语言 CoT 与离散物品空间脱节。对 UGC 内容生成式召回，可将类目层级、话题共现和相似帖子邻域统一为可执行路由；高置信前缀直接匹配，只有前缀不足时才横跳或探索，从而兼顾覆盖与推理开销。

ClawRec: A Claw-Native Recommender System

ClawRec 面向跨平台个人 Agent，维护带证据链接和时间结构的用户状态，按来源功能角色组织召回，再依据边际效用生成互补、去冗余的推荐列表。其 ClawRec-SimBench 以生活事件和跨平台行为轨迹评测，取得 NDCG@20 0.6134（+0.1126）与 Hit@20 0.6944（+0.0854）。

INSIGHT推荐系统的优化单元可从单平台点击序列扩展为围绕用户任务的多源证据状态，候选价值也应包含与已有结果的互补性。社区搜索若接入用户授权的浏览、收藏和外部信息，应保留来源与时间戳，并在重排中显式计算边际效用；同时需把授权范围和证据可追溯作为上线前提。

AI 对话式推荐（AI 导购）

Alibaba

阿里云 PAI 给出 AI 导购的完整落地链路：LLM 先抽取自然语言条件，再由 OpenSearch/PAI-Rec 完成真实商品召回、精排与重排，FeatureStore 保存多轮状态，最后生成带商品引用的回复。文档覆盖 3 类核心场景、4 层架构，并建议先用 50–100 条代表性商品验证索引与体验。

INSIGHT对话式推荐应坚持“模型理解需求、检索返回真实对象、排序保证业务约束、模型负责组织表达”的职责边界。迁移到社区搜索时，可把主题、排除词、时间和作者等条件结构化后执行 AND-first 召回，并用会话状态缓存约束与候选集，防止多轮对话中条件丢失或生成不存在的帖子。

A modular retrieval-generation-feedback framework for large language model recommendation

RAG-LLM-RS 用相似用户行为构造分布式提示，RPRAG-LLM-RS 再加入预训练检索器和轻量 R-Critic，以生成评分分布反向校准召回而无需微调 LLM。电影数据上，后者相对最强免调参基线的 Precision@3、HR@3、NDCG@3 最多提升 5.60、7.30、7.69 个绝对点。

INSIGHT这项工作把生成反馈用于优化检索器，使 RAG 从静态前处理变成可闭环对齐的模块，同时兼容开源模型和黑盒 API。社区搜索可用点击、满意度或小模型 judge 形成轻量 critic，周期性调整相似用户或相似会话召回分布；冻结 LLM 能降低迭代成本，但需另设机制处理长期漂移。

Beyond Recency Bias: Combining Sequential and Global Collaborative Signals in LLM-Based Generative Recommendation for Sparse Data

University of Windsor

CFs-SETRec 在并行生成语义 token 和协同 token 的 SETRec 上增加第二个全局协同信号，以同时保留短期序列偏好与长期相似性，缓解稀疏数据中的近因偏差。Amazon Toys 上 Recall@5 从 0.0443 升至 0.0542（+22.35%），四项指标平均提升 17.68%；密集 Steam 数据则略有下降。

INSIGHT单一序列协同表征容易把近期行为误当长期兴趣，第二个全局 CF token 在稀疏与冷启动场景更有价值，但密集场景可能引入冗余噪声。社区 UGC 推荐可按用户历史密度动态融合：稀疏用户提高全局邻居信号权重，活跃用户保留序列模型主导，并监控不同 K 值下收益是否衰减。

Behrad Ghiasi, CI Ezeife
