A Bag-of-Documents Model for Query Specificity

针对查询长度和 IDF 难以可靠刻画意图宽窄的问题，论文用点击或转化过的文档向量聚合成“文档袋”，以向量集中度定义查询特异性，再训练 BERT 回归器覆盖长尾查询。在 300 万条电商查询上，回归器达到 R²=0.84，特异性与 CTR、首击最低排名的相关系数分别为 0.20 和 -0.24。

Robust HNSW Vector Retrieval under Dynamic Product Updates via Local Rewiring

论文指出 HNSW 在商品频繁新增、删除和向量更新时会累积不可达节点，使相关内容静默退出召回。LR-RN 在更新节点的一跳邻域内选择代表邻居并做有界局部重连；在 SIFT-1M、Deep-100K 与 Amazon 商品集上，不可达节点增量下降约三分之二或被完全遏制，累计更新后的 Recall 损失控制在 1%–3%。

INSIGHT社区 UGC 索引同样面临帖子删除、编辑和向量重算，离线 Recall 正常并不代表动态索引长期健康。该方法无需更换 HNSW 格式，可作为更新链路的低风险修补；上线时应新增不可达节点率、分批更新后的 Recall@K 和重连延迟监控，并与周期性全量重建做成本对比。

To RAG or Not to RAG? Rethinking Multilingual Spelling Correction at Global Scale

Uber

Uber 在英语、法语、日语、西语和台湾地区中文的 3 万条查询上系统比较无检索推理模型与四类 RAG 拼写纠错。英语实验中，无 RAG 推理模型超过目录、点击转化、Lucene 模糊匹配和 Web 搜索增强版本；单一语言无关提示在五种语言上无精度损失。论文还指出错拼约占搜索流量的 15%–20%。

INSIGHT拼写纠错属于语言内推断时，更多检索上下文可能引入冲突候选而非增益，先验证强推理模型的无 RAG 基线更划算。社区搜索可把目录外实体、热点新词和专有名词作为触发检索的例外，其余流量走离线优先的统一纠错模型，并用歧义感知评测避免把合法口语改坏。

LoSparse: Low-dimensional Sparse Retrieval Model

LLY Corporation

LoSparse 用 1024 维低维稀疏表示和可调 T-overlap 条件兼顾精确词匹配、内存与召回宽度。Amazon ESCI 上，BERT 版 Recall@1000 为 0.6669，高于聚类稠密召回的 0.5665；平均仅约 10 个查询非零维和 50 个文档非零维。Yahoo! JAPAN Shopping 两周 A/B 测试中点击、订单、CTR 与 CVR 均显著提升。

INSIGHT低维稀疏向量为社区短文本提供了比纯 ANN 更可控的召回路径：保留实体、型号和热词的精确匹配，同时学习语义扩展。T-overlap 阈值可直接调节候选规模，适合与 BM25 并行；但其 Recall 与 MRR 存在明显权衡，必须按 query 类型分桶调参并持续监控零召回。

Kohei Uno, Shogo Kisa, Yohei Iseki

Problem Formulation over Feature Engineering: Evidence from a Production Reranking System in a C2C Marketplace

Mercari

Mercari 复盘三轮生产重排：前两轮点式 MLP 即使加入图文向量，虽让会话点击率提高 5%–9%，却使首触购买率下降 12%–19%。第三轮不增加特征，改用覆盖浏览到购买漏斗的分级标签与 LambdaRank，点击率提升 17.6%，购买率提升 19%–21%，最终全量上线。

INSIGHT排序失败常来自代理指标与业务目标错位，而不是特征不够多。对社区搜索，应把点击、长停留、收藏、关注和负反馈映射成分级相关性，并用 listwise 目标直接优化顺序；任何只提升 CTR 的模型都要检查满意度与后续行为，避免把“吸睛但不解决需求”的内容顶到前面。

Ryo Watanabe, Yusuke Shido, Ryo Tanaka, Yuki Yada, Shinya Yaginuma

SHIFT: Self-reconstruction Harnesses Implicit Fine-grained Thinking for Retrieval

Peking UniversityCASBeihang University

SHIFT 用残差投影与双向注意力聚合，把 LLM 的三步连续隐式思考压成面向检索的 query 向量，并以逐 token 自重建约束中间状态。模型在 81,659 条推理检索样本上训练；Bright 平均 nDCG@10 中，Qwen3-8B 版达到 31.0，高于同骨干 LaSER 的 29.3，0.6B 版也从对比学习基线 18.3 提升到 25.0。

INSIGHT与“先改写再召回”相比，隐式思考把查询消歧内化到编码器，省去额外生成链路；关键不是增加软 token，而是让每一步承担不同检索语义。社区搜索可先在复杂、歧义 query 上离线验证，并保持文档侧普通编码，避免全库重算与不必要成本；三步推理仍需严格测量 P99 延迟。

Yuxiao Luo, Da Li, Mingjie Zhang, Zhentao He, Shikun Zhang, Wei Ye

Dual-layer prompt ensembles: Leveraging system- and user-level instructions for robust LLM-based query expansion and rank fusion

论文把系统提示作为全局行为先验、用户提示作为任务指令，生成多组查询扩展，再用 SU-RankFusion 融合各自的 BM25 排名。在 6 个数据集上，Touche-2020 的 nDCG@10 从 QE-CoT 的 0.4177 提升到 0.4797；相对原始 BM25，Robust04 与 DBPedia 分别提升 24.7% 和 25.5%。

INSIGHT提示多样性只有转化为多个独立召回列表后才真正有价值，直接拼接扩展词容易被单次坏改写拖累。社区搜索可为同一短 query 生成实体补全、意图释义和同义表达三路扩展，再用无需校准分数的 RRF 合并；上线前应限制扩展数，并按收益覆盖率决定是否调用 LLM。

Minghan Li, Ercong Nie, Huiping Huang, Xinxuan Lv, Guodong Zhou

Improving Pointwise Predictions with a Pairwise Ranker

eBay

eBay 用轻量逻辑回归重排器融合点式模型的校准概率与成对模型在约 100 个候选中的名次，兼顾可解释概率和排序区分力。离线 ROC AUC 比单独点式模型高 0.3%；线上 CTR 与购买通过率均改善，同时广告收入未下降，且满足严格生产延迟限制。

INSIGHT不必把现有精排整体改成 pairwise 才能获得相对排序收益；把 pairwise rank 当作稳定特征，可避开其原始分数跨 query 不可比、重训后漂移的问题。社区搜索可用同样结构融合点击概率与相关性排序，但要对头部位置单独校准，并监控概率校准误差与顺序指标。

LLM 混合检索路由生产实战：用查询分类、RRF 与回退策略稳住 RAG 召回

文章给出可配置的 RetrievalPlan：精确短查询优先 BM25，语义查询走向量，混合查询并行两路后用 RRF，低置信度再回退。示例为 BM25 与向量各取 Top-50、重排窗口 50、最少候选 8、最大向量距离 0.45；同时要求记录每次路由、融合和回退决策。文章未提供受控线上实验数据。

INSIGHT对社区搜索而言，“所有 query 都固定混合召回”会浪费延迟并放大错误语义匹配，先做轻量意图路由更容易治理。可从规则版开始，将型号、专名和三词以内短 query 送稀疏召回，自然语言问题走混合链路；回退阈值必须从真实漏召回样本标定，而非照搬示例。

Improving E-commerce search queries using transformer-based named entity recognition

论文构建首个土耳其电商短查询细粒度 NER 数据集，覆盖品牌、颜色、尺码、价格等 17 类实体，并比较传统模型、微调 Transformer 与零样本 Gemini Pro。ELECTRA 的加权 F1 为 91.97%，BERT+Bi-LSTM+CRF 达到 92.49%；微调模型总体更准，而零样本 LLM 对错别字和语义歧义更稳健。

INSIGHT短文本缺少句法上下文时，实体标签能直接服务索引扩展、召回过滤和排序特征；CRF 对连续标签约束仍有价值，并不因 Transformer 出现而过时。社区 UGC 可按人物、地点、话题、作品等业务实体重建标签集，同时保留 LLM 处理噪声 query 的回退通道，而非完全替代小模型。
