ModelExpress: Distributing Model Artifacts at the Speed of Light

针对百 GB 到 TB 级模型在冷启动、扩缩容和强化学习重拟合中反复搬运权重的瓶颈，NVIDIA ModelExpress 按运行时能力选择 P2P RDMA、对象存储流式加载或 GDS 路径，并复用编译内核缓存。DeepSeek-V4 Pro 的权重与 JIT 缓存可在 10 秒内传到新副本，API 就绪时间由 8 分钟降至 1 分 44 秒。

ExpertPlex: A High-Goodput Disaggregated Serving System for MoE LLMs with Adaptive Persistent Kernels

ExpertPlex 面向大规模 MoE 服务中预填充与解码资源比例失配的问题，共享两阶段的专家权重、仅拆分轻量注意力模块，并以自适应持久化内核按 tile 调度专家计算。该设计消除超过 95% 的重复权重；在 MiniMax-M2.7 与 GLM-5.1-FP8 上，goodput 较实例级拆分最高提升 2.01 倍，较共置方案提升 1.66 倍。

INSIGHTMoE 服务的核心矛盾是巨大且稀疏激活的专家权重不适合按完整实例复制，而注意力模块更适合独立弹性扩缩。把专家共享、注意力拆分，再用 attention 发起通信以重叠计算，可同时降低显存重复与网络干扰；这对高并发搜索问答中的动态流量比固定预填充/解码配比更稳健。

InstantInfer: Enabling Fast LLM Cold Start with Communicating Finite Automata

Peking UniversitySScitix AI

InstantInfer 针对 LLM 冷启动初始化串行、细粒度 I/O 请求过多的问题，用通信有限自动机描述组件间依赖，在保留原顺序程序结构的同时安全并发执行。作者据此重构 vLLM 的进程树创建、张量加载和模型切换，并给出正确性证明；跨 GPU、负载和规模实验中，冷启动最高加速 7.2 倍。

INSIGHT相比手工把加载流程改成异步代码，先用可验证状态机抽象找出跨组件并发与 I/O 合并机会，更适合复杂推理栈的持续演进。社区搜索若部署多模型或频繁弹性伸缩，可优先对进程初始化、权重分片读取和版本切换建立 CFA，再逐步接入现有 vLLM，降低优化引入竞态与错误状态的风险。

Hybrid Scalar-Vector Retrieval with Alibaba Cloud EMR Serverless Spark

Alibaba

阿里云 EMR Serverless Spark 通过 DLF Global Index，把向量索引与 B-tree 标量索引统一进 Spark SQL 执行框架，在一条 SQL 内完成业务条件过滤与向量近邻召回。它避免传统“向量库 Top-K 后再到业务库过滤”的两次查询、数据搬运和结果不足 K 条问题，为湖仓中的混合检索提供工程化路径。

INSIGHT对 UGC 搜索，地域、内容类型、时效和安全状态等硬约束应尽量在向量召回阶段共同下推，而不是召回后补过滤，否则候选完整性和尾延迟都会恶化。可借鉴其统一优化器思路，把标量选择率、向量索引代价和过滤顺序纳入同一执行计划；上线前仍需补齐大规模召回率与 p99 延迟评测。

BaseRT: Advancing Best-in-Class LLM Inference with Apple M5 Neural Accelerators

BaseRT 为 Apple M5 编写原生 Metal 4 推理运行时，将稠密与 MoE GEMM、FlashAttention 预填充送入每核 Neural Accelerator，同时把内存带宽受限的解码留给专用内核。覆盖 Qwen、Llama 与 Gemma 的 15 组模型中，预填充吞吐最高为 llama.cpp 的 6.4 倍、MLX 的 3.9 倍，解码最高分别快 1.75 倍和 1.33 倍。

INSIGHT端侧优化应按算子瓶颈分流：矩阵乘法走张量单元，解码继续依赖低开销内存优化，统一把所有阶段迁到新硬件反而可能退化。对于隐私敏感的本地搜索助手，可用其公开运行时验证 1B–35B 模型；但收益高度绑定 M5 与手写 Metal 内核，迁移到其他芯片需重新做算子画像。

HyMCache: A KV Cache Framework for Multi-Turn LLM Serving with CXL-Hybrid Memory

HyMCache 为多轮与 Agent 服务构建 CXL 混合内存 KV 缓存层，以少量设备 DRAM 加大容量 SSD，在 CXL 接口后提供 TB 级共享上下文。请求级前缀预取与机会式写缓冲利用 KV 读多、可预测和追加写特征；真实原型上较本地 LMCache 快 3.0 倍，拆分服务下快 1.45 倍，并以 16 倍更少 DRAM 达到 Mooncake 约 70% 的性能。

INSIGHT当搜索对话或研究 Agent 频繁复用长前缀时，瓶颈会从计算转移到跨请求 KV 的容量与搬运。把 SSD 当容量层、DRAM 当可预测预取层，可用性能换显著成本下降；适合缓存命中稳定、上下文追加式增长的业务，随机跳读或短会话占比高时则应先验证预取放大与 CXL 设备成本。

Fine-grained Computation-Communication Overlap via Tile-level Signaling and Scheduling for Mixture-of-Experts

该工作把 MoE 专家计算与第二次 all-to-all 返回通信细化到 tile 级重叠：持久化生产者内核覆盖本 rank 全部专家并优先远端关键 tile，通信消费者占用少量 SM，tile 就绪即分段传输。四张 A100、三种 MoE 模型与四个系统的对比中，端到端最高加速 2.64 倍，MoE 层最高加速 2.74 倍。

INSIGHT传统“专家算完再通信”会把网络等待完整暴露在关键路径；让计算端主动发出细粒度就绪信号，能在不重写 GEMM 或通信原语的情况下获得重叠收益。实际部署需联合调节生产者与消费者 SM 分区，并按路由偏斜监控远端关键 tile，否则固定预留通信资源也可能形成新的空闲。

A Training-Memory Regression in MLA Sequence Parallelism: Why Megatron-Core Forbids Absorption, and LAGA -- a Communication-Efficient Fix

论文解释 Megatron-Core 为何禁止训练时使用吸收式 MLA：在 DeepSeek-V3 配置下，中间张量使激活内存增加 20%–34%，eager 内核最多多占 9.2 GB，融合内核可达 19.2 GB。LAGA 只 all-gather 压缩 latent，再本地重建每头 K/V；八张 Ascend 910B 上通信量减至约一半，跨节点吞吐提升 1.07–1.24 倍。

INSIGHT降低通信的代数改写可能扩大激活维度，系统优化必须同时核算通信、激活驻留和设备可容纳性，不能只看带宽。LAGA 展示了更稳妥的折中：传压缩表示但不采用内存膨胀的吸收重写；训练长上下文 MLA 模型时，可先用序列长度和头数做线性内存外推，再决定是否接入。

Searching for Plans You Can Actually Build: A Realizability-Aware Full-Space Optimizer for MoE Training and Serving

moefs 将“工具链能否真正生成方案”作为 MoE 训练与服务搜索的硬约束，联合搜索并行、调度和内核，并从同一计划输出 Megatron 训练栈与 SGLang 服务栈。两张 RTX 4090 上训练吞吐较最强手调基线高 0.9%，八张 H800 上服务达到手调方案的 1.0304 倍；训练失败案例也按 0.9338 倍如实披露。

Talaria: Session-Aware Serverless Serving of Hundred-Billion-Parameter LLMs

Talaria 面向工具调用 Agent 的多模型无服务器推理，把模型驻留、KV 局部性、实例压力和会话返回概率联合用于放置与准入，并通过软预留与 session-prefill 保持工具间隙后的连续性。30 个 SWE-Bench 会话、960 次调用和三个百 B 级模型实验中，p50 会话完成时间由 1000 秒降至 189 秒，p95 由 2296 秒降至 867 秒。

INSIGHT单请求负载均衡会把后续调用与已驻留模型、KV 前缀分离，Agent 服务因此应以完整会话完成时间而非单次 TTFT 为调度目标。对深度搜索链路，可在准入预算中为高概率返回会话保留软容量，并持久化可恢复 KV；但实验仅覆盖单个 TP=8 服务器，跨集群扩展仍需验证。
