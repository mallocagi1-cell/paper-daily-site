PATS: Policy-Aware Training Scaffolding for Agentic Reinforcement Learning

针对长程智能体强化学习中弱策略反复失败、同组轨迹缺乏奖励差异的问题，PATS 把近期 rollout 转成证据卡，并按策略能力动态扩展、修订或压缩训练支架，部署时再完全移除。ALFWorld 与 WebShop 上最高提升 18.6 个百分点；7 个搜索增强问答基准中，提示词开销比基线少 32.1%。

Harness-1: Reinforcement Learning for Search Agents with State-Externalizing Harnesses

CChromaUIUC

该工作把搜索智能体的候选池、证据链接、核验记录、观察压缩与预算渲染外置到有状态 harness，只让 20B 策略学习搜索、筛选、核验和停止等语义决策。覆盖 Web、金融、专利和多跳问答的 8 个基准上，平均 curated recall 达 0.730，比次强开源搜索子智能体高 11.4 个百分点。

Silent Failures in Multimodal Agentic Search: A Diagnostic Taxonomy and Cross-Judge Evaluation

论文指出只看最终答案会漏掉多模态搜索 Agent 的“静默失败”，并定义虚假落地、错证据得对答案、过度检索洗白、跨模态冲突等 6 类问题。作者在 MMSearch-Plus 的 200 个任务、4 个前沿模型共 800 条轨迹上评测，真实正确率较表面准确率下降 0.6–7.3 个百分点。

INSIGHT社区 UGC 搜索若只验最终回答，很容易放过引用不支持结论、检索形同装饰或来源凭空生成的轨迹。可直接借鉴其“答案正确且轨迹无故障”口径，把工具调用、证据支持关系和来源真实性纳入离线回放；同时保留跨模型 judge 复核，因为细粒度故障标签本身也会受评审模型偏差影响。

Zhengxian Wu, Junjie Gao, Kai Yang

Agentic retrieval for Amazon Bedrock Managed Knowledge Base

Amazon

AWS 将查询分解、并行检索、证据充分性判断和停止决策封装进 AgenticRetrieveStream，并通过流式 trace 暴露每轮规划与结果。MuSiQue 多跳问答上相对单次检索的绝对召回提升约 20 个百分点；2、3、4 跳问题分别提升 22.8、31.9、37.3 点，复杂查询可配置 3–5 轮。

INSIGHT这是可直接转化为社区搜索分层路由的工程基线：简单 query 走低延迟单次召回，比较、探索或跨库 query 才进入 Agent loop。实现时应按轮数而非仅按 token 做成本预算，记录子查询、充分性判断和去重结果，并给多知识库写清晰的路由描述；否则 Agentic 检索会把召回增益换成不可控延迟。

SearchSwarm: Towards Delegation Intelligence in Agentic LLMs for Long-Horizon Deep Research

AAnt GroupTsinghuaPeking UniversityRenmin University

SearchSwarm 用“主智能体分发、子智能体执行”解决深度研究中的上下文膨胀，并把 harness 诱导出的高质量委派轨迹蒸馏进 30B-A3B 模型。模型在 BrowseComp、BrowseComp-ZH、GAIA 和 xbench-DeepSearch 上分别达到 68.1、73.3、82.5、80.8，同规模模型中表现最佳。

INSIGHT委派的价值首先是内容感知的上下文压缩，而不是简单增加并发：主 Agent 必须说明子任务为何重要，子 Agent 只回传带引用的浓缩报告，主 Agent 保留整体验证权。对长链 UGC 调研，可把实体核验、时间线和观点对比拆成独立检索上下文，但应限制为单层委派并要求引用回传，防止摘要丢失证据。

MGFRec: Towards Reinforced Reasoning Recommendation with Multiple Groundings and Feedback.

MGFRec 将推荐 Agent 拆成 think、ground、feedback、answer 循环：每次把生成的物品概念映射到真实物品空间中最相近的 Top-10，再由用户 Agent 给出逐步反馈，并用 GRPO 与 NDCG 奖励训练。论文在 Books、Movies and TV、CDs and Vinyl 三个 Amazon 数据集上评测，多轮落地与反馈均带来稳定增益。

INSIGHT该方法对社区搜索的可迁移点是“推理必须反复落回真实索引”，而不能只在语言空间想象候选。可以把生成的兴趣描述或查询意图每轮映射到真实帖子 Top-K，再依据点击历史或模拟用户反馈继续收窄；但线上需限制 grounding 轮数，并验证模拟用户不会把已有曝光偏差放大。

Detecting silent agent failures with Amazon Bedrock AgentCore optimization

Amazon

AWS 展示了在完成率 99%、延迟健康且无错误峰值时仍主动发现错误动作的生产方案。AgentCore 从会话 trace 中识别幻觉、错误动作、指令违背、编排和上下文处理等 11 类故障，再按受影响会话占比聚类排序，并沿执行图回溯根因；示例中 116 个问题会话里有 114 个源于同一漏检模式。

INSIGHTAgent 监控不能停留在 HTTP 成功率和 P99 延迟，还要回答“系统是否做了正确动作”。社区搜索可按周聚合未调用检索却给出事实、跳过前置证据、重复搜索和错误引用等行为模式，再把根因定位到 prompt、工具说明或基础设施；按受影响流量排序比逐条人工读 trace 更适合生产规模。

MagenticLite, MagenticBrain, Fara1.5: An agentic experience optimized for small models

Microsoft

Microsoft 将浏览器与本地文件任务拆给小模型协作：14B MagenticBrain 负责规划、编码和委派，Fara1.5 的 4B、9B、27B 版本负责计算机操作，并与专用 harness 联合训练。9B 版在网页导航上接近 Fara-7B 的两倍，27B 版在 300 任务的 Online-Mind2Web 上超过 90%。

INSIGHT这项实践说明 Agent 能力取决于模型、工具格式、执行环境和委派接口的共设计，小模型也能承担高频编排。社区搜索可让轻量规划器做 query 分解、工具选择与停止判断，只把复杂浏览或跨模态步骤交给专用模型；训练与线上必须使用同一工具 schema，减少“会训练、不会调用”的接口落差。

Intelligent Firewall Rule Generation and Harmonization: A Multi-Agent Framework for Cybersecurity Using the NSL-KDD Dataset.

UUniversity of Tunis El ManarTTikrit UniversityCCarthage University

论文以多个本地 Agent 分别挖掘 DoS、R2L、U2R 等攻击规则，再由主 Agent 做冲突消解、一致性检查和隐私化共享，并原生接入 pfSense 实时部署。NSL-KDD 分析共生成 68 条规则，平均置信度 0.71；TCP 攻击最密集，20、21、23 端口最常被命中。

INSIGHT虽然业务域不是搜索，但其“局部提案—主控合并—置信度分层—冲突消解”适合迁移到多 Agent 证据整合。多个检索 Agent 可各自覆盖不同内容域，只共享高置信结果，对低置信证据先脱敏再合并；主控必须显式处理重复和冲突，避免简单投票把错误共识放大。

Amazon is investing in the Lean Focused Research Organization

Amazon

Amazon 宣布投资 Lean Focused Research Organization，目标是把 Lean 形式化证明用于高风险 AI Agent 的行为约束，使安全要求从自然语言规则转成可机器校验的证明义务。文章属于研究投入与方向发布，尚未给出搜索任务基准或线上 A/B 数字，因此证据质量与短期可落地性有限。

INSIGHT对会执行外部动作的搜索 Agent，事实核验与权限边界不能只靠提示词。可先把访问控制、禁止动作、引用存在性等少量关键不变量做成确定性校验或形式化规格，在工具调用前后强制验证；但 Lean 证明成本较高，近期更适合支付、权限变更和数据导出等高风险路径，而非全部检索逻辑。
