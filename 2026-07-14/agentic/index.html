Superintelligent Retrieval Agent: The Next Frontier of Agentic Retrieval

SIRA 将多轮探索式搜索压缩为一次面向语料区分度的检索：离线补全文档搜索词，在线预测查询缺失的证据词，再用语料统计过滤无效扩展，最终执行加权 BM25。在 10 个 BEIR 基准上取得对比方法最佳平均效果；BrowseComp-Wikipedia 的 Recall@1/10/100 分别为 9.70%、15.27% 和 36.14%。

AgentKGV: Agentic LLM-RAG Framework with Two-Stage Training for the Fact Verification of Knowledge Graphs

AgentKGV 用动态路由和迭代查询改写解决知识图谱事实核验中的表述错配，并以轮次级蒸馏 SFT 将教师推理迁移到小模型，再用轨迹级 GRPO 优化检索策略。在 T-REx 长尾关系划分上，相比单轮 RAG 的 Macro-F1 提升 5.5 个百分点，两阶段训练再提升 9.4 个百分点，平均搜索调用由 3.24 降至 1.63。

INSIGHT其价值在于把“改写质量”和“是否继续搜索”拆成可分别训练的能力：蒸馏保证每轮推理稳定，GRPO 则直接压缩无效调用。社区搜索可沿用这一结构，把长尾 query 改写作为监督任务，把答案正确性、召回覆盖和调用成本组合成轨迹奖励，以降低 Agent 搜索延迟。

Yumin Heo, Hyeon-gu Lee, Sumin Seo, Youngjoong Ko

Advancing Search-Augmented Language Models

Perplexity

Perplexity 以 SFT 建立拒答、指令遵循和语言一致性，再用可验证问答、规则化通用对话与门控奖励进行 on-policy RL，同时惩罚冗长输出和过度工具调用。单次搜索预算下 FRAMES 达 57.3%，高出 GPT-5.4 5.7 个百分点；预算为 4 时准确率 73.9%，单问成本约 0.02 美元。

INSIGHT生产级搜索 Agent 不能只优化最终答案正确率，否则容易牺牲安全、格式与调用成本。更可行的训练配方是先用 SFT 固化上线约束，再让 RL 共同优化可验证正确性和工具效率；实验还显示 7 次调用后收益明显递减，可据此设置社区搜索的硬预算与降级策略。

Mach-Mind-4-Flash Technical Report

Li Auto

Mach-Mind-4-Flash 是总参数 35B、激活 3B 的 MoE Agent 模型，通过统一 RL/OPD 基建、多领域 RL 专家融合和 HMPO 三阶段后训练提升能力。训练端获得 17% 端到端加速，推理链缩短 19%–46% 且准确率损失不超过 0.7 个百分点；BrowseComp-zh 与 ClawBench 分别达到 72.31 和 84.20。

INSIGHT报告表明 Agent 能力提升不必继续扩大预训练规模，可以通过领域专家并行训练、反向 KL 蒸馏融合和长度感知策略优化实现。对中文社区搜索，值得重点验证其搜索轨迹压缩机制：在不显著损伤正确率的前提下减少推理 Token，往往比单纯换更大模型更贴近成本目标。

正式开源！美团 LongCat-2.0 同步开放国产卡推理代码

Meituan

美团开源 LongCat-2.0 及国产卡推理代码，模型总参数 1.6T、平均激活约 48B，面向真实 Agentic Coding 场景。架构采用 LongCat 稀疏注意力、N-gram Embedding 与动态激活，目标是在增强长上下文、Token 级表示和代码执行能力的同时，提供从权重到推理栈的可落地资产。

INSIGHT这项发布的实践价值主要在完整开放与国产算力适配，而非直接改善搜索排序。对搜索 Agent 团队，可借鉴稀疏注意力处理长检索轨迹，并利用开放推理代码评估私有化部署；上线前仍需用真实 UGC query 单独测量检索准确率、工具成功率和端到端延迟。

Agentic Reinforcement Learning for Search Misaligns Instruction-Tuning

论文系统考察搜索 Agent 的强化学习是否破坏指令微调阶段的安全行为，覆盖 Qwen、Llama 两个模型族、3B–32B 参数、PPO/GRPO 以及本地与 Web 搜索。仅在生成开头加入工具调用触发，就可使拒答率最多下降 41.2%、答案安全下降 66.6%、查询安全下降 82.4%，退化最快 50 个 RL 步即出现。

INSIGHT搜索 RL 的奖励若只关心找到答案，可能把模型推向“无条件调用工具”的捷径，并绕过原有安全边界。业务训练应把查询安全、拒答一致性和工具权限纳入轨迹级评测，且在 RL 早期高频回归；对社区搜索尤其要防止 Agent 将敏感意图改写成更具执行性的外部查询。

Scoped Verification for Reliable Long-Horizon Agentic Context Evolution under Distribution Shift

GRACE 将长期演化的 Agent 系统指令维护为类型化语义图，只在被修改节点的局部邻域验证更新，再重建为增量文本指令。基于 τ²-bench 的电信 Agent 在五次独立复现实验中，最终 pass³ 从 Gemini 2.5 Flash 零样本的 0.091 提升到 0.673±0.136，高于平面文本基线的 0.191±0.051。

INSIGHT长期运行的搜索 Agent 会不断累积规则、失败修复和业务例外，平面 Prompt 很快变得难以审计。把指令拆成带类型与依赖关系的图，并对变更做局部验证，可降低更新相互污染；这适合管理 query 改写、安全过滤和工具路由规则，但仍需保留全局回归集防止跨模块副作用。

Dan C. Hsu, Luke Lu

Agentic RAG

Tencent

腾讯云把 Agentic RAG 落成可配置的 Agent Loop：反思模型判断结果相关性与完整性，按需切换混合或关键词检索，并配合重排完成多文档整合与复杂条件筛选。平台允许 0–10 轮“反思—检索”，默认 3 轮；0 轮退化为标准 RAG，1–3 轮面向常规场景，4–6 轮用于高准确度任务。

INSIGHT工程上最可借鉴的是把反思次数做成显式预算，而不是让 Agent 无界循环。社区搜索可按 query 难度分层：简单意图走单轮检索，跨主题比较或强约束查询开放 1–3 轮，并同时配置轻量与 LLM 重排器；文档未给出量化增益，正式采用前必须补做成本—准确率曲线。

Agora: Enhancing LLM Agent Reasoning Via Auction-Based Task Allocation

Agora 将 Agent 的推理步骤视为可交易任务，用激励相容拍卖在功能相近的专家模型与工具间动态分配；投标依据校准后的能力，避免把关键步骤交给最自信却不可靠的组件。论文在 5 个基准上超过匹配候选池的单模型、普通路由和级联基线，并通过单一拍卖参数控制成本与质量。

INSIGHT相比按工具描述做粗粒度路由，拍卖机制显式联合建模能力、置信校准与成本，更适合多检索器、多重排器并存的搜索栈。落地时可让 BM25、向量检索、SQL 和 Web 搜索竞争子任务，但能力估计必须来自持续回放数据，否则投标仍会放大过度自信。

RAAS: LLM Agentic System Architecture Search with GRPO

RAAS 针对 Agentic Supernet 搜索中任务难度与执行随机性污染架构评分的问题，引入同题候选对比的 CAO 和多次独立运行聚合的 MTAS，再用 GRPO 搜索工作流结构。6 个推理、代码与多步工具基准上，HumanEval pass@1 从 92.23% 升至 96.31%，MATH 准确率从 52.08% 升至 60.87%。

INSIGHT自动搜索 Agent 工作流时，单次绝对得分会把简单样本和随机好运误认为架构优势。实践中应让候选工作流在相同 query 上成组比较，并对多次运行做稳健聚合；这一评估设计可用于搜索链路的规划器、检索器和重排器组合搜索，但计算开销需要通过分阶段筛选控制。

Jiayi Yang, Guancheng Wan, Man Zhang, Mang Ye
