Improving Conversational Recommendation with Contextual Adaptation of External Recommenders and LLM-Based Reranking

针对对话推荐中大模型善于交流、但可能脱离既有协同过滤信号的问题，CARE 将外部推荐器接入对话链路，并依据当前会话上下文调整候选，再交给大模型重排。该工作发表于 ECIR 2026，公开页面确认其核心由上下文适配与 LLM 重排组成，但未披露可核验的具体提升数字。

A Modular Survey for Semantic ID-Based Generative Recommendation

该综述针对 Semantic ID 生成式推荐研究缺少统一比较框架的问题，把完整链路拆成语义分词与量化、模型骨干、训练目标和解码协议等模块。它梳理了传统单一物品 ID 向多 token 条件生成的范式变化，重点指出不同索引目标、码本设计和生成策略混用，使现有结果难以横向复现。

INSIGHT对工程团队而言，Semantic ID 并不是可独立替换的编码组件，它会同时改变候选空间、训练损失、解码约束和线上延迟。评估生成式推荐时应固定数据切分与解码预算，分别消融 tokenizer、序列模型和约束搜索；在社区内容场景中，还要额外检查新内容冷启动与 ID 更新带来的索引漂移。
