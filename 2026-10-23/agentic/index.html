Let Agents Design How They Search: Automatic Interface Optimization for Agentic Search

韩国大学和 KAIST 让 Claude Code（Claude Opus 5.5）替搜索智能体设计检索工具：它读每道题的执行记录和得分，同时修改预先生成的索引文件、可执行的检索脚本和使用说明，循环 10 轮后选优化集上最好的版本。搜索智能体用 GPT-5.4-nano，BrowseComp-Plus 答对率从 DCI 的 71.6% 升到 78.4%，BRIGHT 四个子集平均 nDCG@10 从 45.7 升到 55.0。只优化提示词能到 75.6% 和 52.0，说明另一部分提升来自生成的索引文件和检索脚本；接口原样换给 Gemini 3.5 Flash-Lite 也比 DCI 好（73.9% 对 60.9%）。

MAPS: Macro-Adaptive Parallel Reasoning for Regulating Search Momentum in Retrieval-Augmented Generation

Northeastern UniversityTsinghua📖 深度解读 · 14 分钟 →

东北大学和清华发现，边推理边检索时，后面的子查询会沿着前面子查询的移动方向继续偏离原问题，而且越往后越明显。MAPS 据此做两处改动：每轮只把提炼出的知识和一段推理摘要交给模型，不再给它看历史子查询；生成子查询前先列出几个互补方向，各写一个子查询并行检索后合并。Qwen3-32B 上六个问答集平均 Cover-EM 为 56.0，ParallelSearch 为 49.2，Search-o1 为 43.9；三个组件分别去掉后都会下降。

Xinze Li, Dingwen Zhang, Zhenghao Liu, Yukun Yan, Shuo Wang, Yu Gu, Ge Yu, Maosong Sun

Signals and Queries: Token-Efficient Agentic Context Discovery

PParlant📖 深度解读 · 13 分钟 →

Parlant 原来每轮对每条客服规则问一次大模型是否相关，36 条规则每轮约 69,000 个 token。S&Q 改为离线让大模型为每条规则写 10 条应触发的用户消息和 10 条容易混淆的反例，训练一个逻辑回归；线上每轮只需一次 embedding 和 37 微秒 CPU。在 τ²-bench 航空客服上，召回率 90% 时精确率 32%–34%，余弦阈值为 31%；从真实对话挖样例后精确率升到 43.5%，提升几乎全部来自反例。

Yam Marcovitz

A Small Model Asks Better: Fine-Tuning Query Clarification for Retrieval-Augmented Generation

IBM📖 深度解读 · 15 分钟 →

IBM 构建了约 3,900 条的多轮 RAG 反问数据集 ClariEdge，专门包含"看起来含糊、但上文已能确定指代"的难负例，用来对 Granite 小模型做 LoRA 微调，判断要不要反问并列出候选项。Granite-4.1-3B LoRA 判断准确率 96.6%，提示词方式下 GPT-4o 为 79.4%，GPT-5.6 Sol 为 73.1%（后者倾向于什么都反问）。去掉难负例训练后，难负例类准确率从 87.3% 跌到 35.4%。

Lihong He, Lucian Popa, Marina Danilevsky

Uni-Mem: Learning a Long-Horizon Agentic Memory Manager with Unified Online Policy Optimization

HuaweiSoutheast UniversitySun Yat-sen UniversityShandong Normal University

华为诺亚等提出 Uni-Mem，用一个 Qwen3-4B-Instruct 模型同时学"往记忆库里写什么"和"查询时取什么"，两部分都用在线强化学习训练。训练时交替优化写入和检索，每组对比样本里固定另一部分不变，使奖励差异只来自当前部分；奖励按"事件"（一段新对话或一次提问）分配给相关的记忆操作。LoCoMo 上 LLM 评判得分 88.80%，比最强基线 Memory-R2 (OSS) 高 10.93 个点，不做 SFT 也有 80.99%。

How AI agents search

SSapienza University of RomeGeorgetown UniversityUniversity of GlasgowUniversity of Pisa

比萨大学等发布 ASQ 数据集，记录了约 102 万条开源检索智能体（Search-R1、AutoRefine、gpt-oss-20b）在 MS MARCO、HotpotQA、Researchy Questions 上的完整检索过程，包括每一步子查询、检索结果和推理文本。分析发现，一个问题最多触发 186 次检索，人通常只查 2–3 次；智能体常回到更早用过的查询，重复取回相同结果；加重排或增大检索深度并不能稳定缩短检索链，效果因智能体和配置而异。

Francesca Pezzuti, Ophir Frieder, Fabrizio Silvestri, Sean MacAvaney, Nicola Tonellotto

BIRD-RL: Scaling Agentic Reinforcement Learning over Stateful Data-Centric Environments

已录用 NeurIPS 2026HKUNUSCCUHK Shenzhen

港大等提出 BIRD-RL，用强化学习训练小模型在真实数据库上调试 SQL。难点是 SQL 会修改数据库状态，每条采样轨迹本需独立的数据库容器；BIRD-RL 按轨迹登记并复用数据库副本，在 SQLite 负载下空间效率提升 12.8 倍，不需要 Kubernetes。训练分四阶段：模仿推理、模仿多轮工具调用、强化推理、在真实数据库上交互式强化学习。7B 和 14B 模型在 BIRD-CRITIC-SQLite 上成功率 44.40% 和 48.00%，Claude-Opus-4.6 Agent 为 48.20%。

Harness Scaling for Generalizable Agentic Reinforcement Learning

IIQuest ResearchBeihang UniversityRenmin University of China

人大等发现，只在一套固定的智能体运行框架（harness）里做强化学习，模型换框架后效果会变差。Harness Scaling 把框架拆成系统提示词、工具接口、观测格式、上下文管理、工作流五个可替换部分，用正交设计挑出一小组组合训练，每个任务配两个相近的组合。在 ClawGym-Task 上训练 Qwen3-4B-Instruct，未见过的框架组合上 GRPO 平均分从 29.81 升到 39.04；迁移到 Claude Code 时平均 37.22，高于直接在 OpenClaw 上做 SFT（35.08）或 RL（33.38）。

Fei Bai, Huatong Song, Chuan Hao, Ran Tao, Jian Yang, Bryan Dai, Wayne Xin Zhao, Ji-Rong Wen

Flint-interactive: A language for creating interactive data visualizations

MicrosoftUCLA

微软研究院发布 Flint-interactive，让智能体生成可点击、筛选、缩放、跨图联动的交互式图表。做法是把交互拆成两层：编译器负责把点击、拖动等原始操作解析成"用户选中了哪些数据"这样的语义事件，并负责渲染更新；智能体只需写"某个事件触发哪个更新操作"（如高亮、加标注、平移缩放），不用写底层渲染代码。可通过 Flint-MCP 在聊天里使用，也可用编程接口接入看板和表格。博客没有给出可靠性或成本的量化数据。

Inside NVIDIA Sentry: Secure AI Agents at Runtime

NVIDIA

NVIDIA 介绍 Sentry：一套运行在 BlueField-4 DPU 上、独立于主机软件的智能体安全框架，智能体访问模型和外网的流量都必须经过它。DOCA Tower 作为透明代理解密流量，用 Open Policy Agent 按规则审批请求；DOCA Argus 直接读取主机内存，核对发起请求的进程和容器哈希是否在批准清单内。发现异常时可在毫秒级内由硬件隔离智能体，日志存在 DPU 上，智能体改不了。计划明年初推出，文中没有性能测试数据。
