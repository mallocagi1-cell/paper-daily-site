SHEAF: Self-profiled Hardness Estimation from Answer-set Flux for Predicting Query Hardness in Graph-based ANN Search

论文发现 ANN 查询达到 95% 召回所需 beam 在 SIFT1M 上相差超过 32 倍，固定 beam 会同时浪费吞吐并伤害难查询召回。SHEAF 用两次浅层 probe 的 top-k 答案集变化量预测查询难度，在 CAGRA、HNSW 和 4 个数据集上，留出相关性最高比 5 个基线好 1.55 倍。

INSIGHT对 UGC 搜索而言，短 query、长尾实体和热门 query 的向量检索难度并不一致，按查询动态分配 ANN 搜索预算比全局调大 beam 更划算。SHEAF 只需两次浅 probe 且无需在线真值，可作为召回层的难度路由器，优先把算力留给答案集尚未稳定的查询。

Dongfang Zhao

SQuTR: A Robustness Benchmark for Spoken Query to Text Retrieval under Acoustic Noise

SQuTR 面向语音 query 到文本库检索的噪声鲁棒性，汇集 6 个英中文本检索数据集的 37,317 条唯一查询，用 200 名真实说话人的音色合成语音并混入 17 类环境噪声。论文建立统一协议，系统比较 ASR、语音编码器和检索模型在不同信噪比下的退化。

INSIGHT社区搜索若承接语音入口，离线评测不能只测干净转写后的相关性；ASR 错误会与口语短 query、实体词和噪声叠加。该基准可直接启发按噪声类型分桶的 nDCG/Recall 监控，并把语音增强、转写置信度和 query 改写作为联合链路评估。

Yuejie Li, Ke Yang, Yueying Hua, Berlin Chen, Jianhao Nie, Yueping He, Caixin Kang

Hybrid privacy-aware semantic search: SVD-truncated document geometry and CKKS-encrypted query reranking under a restricted threat model

论文把文档向量投影到截断 SVD 子空间并秘密旋转，同时用 CKKS 加密 query 做候选重排，以缓解向量泄露和查询隐私问题。在 100 万文档、5 个编码器上保持亚秒级检索；672 维设置下服务端中位耗时由 1689.1 ms 降至 224.5 ms，响应体缩小 99.5 倍。

INSIGHT方案把大规模候选生成留在便宜的受保护几何空间，只对小候选集做同态重排，适合隐私敏感的社区搜索或企业知识检索。实践中应把它视为受限威胁模型下的折中：query 机密性更强，但文档侧 SVD 与旋转只是经验性混淆，不能替代完整密码学保护。

Sergey Kurilenko

05 4.10

SHARD: cell-keyed residual splitting for alignment-resistant private dense retrieval

SHARD 将中心化向量拆成公开路由前缀和按 cell 独立密钥保护的残差，并在 CKKS 下做全维重排，避免单一全局几何被少量已知样本对齐。在 10 组 BEIR/MIRACL 配置上复现原始 nDCG@10；当 C=256 时，恢复映射所需锚点中位数从 200 增至 102,400。

INSIGHT相比全局秘密旋转，按 cell 分割密钥能显著提高批量向量反演的成本，同时保留语义召回质量。部署时应把公开前缀控制在只够粗召回的维度，并监控单 cell 泄露；作者明确指出定向攻击者仍可能用约 d_priv 个锚点恢复局部映射，因此它是攻击感知防线而非绝对保证。

Sergey Kurilenko

Beyond Semantic Similarity: Explicit Intent Modeling for Query-Product Matching.

该 SIGIR 2026 论文针对电商 query-product 匹配中过度依赖语义相似度的问题，引入显式意图建模，把用户真正要完成的任务与表面词义匹配分开处理。论文位于 SIGIR 主会检索赛道，面向 query 与商品的候选匹配，可直接对应社区短文本搜索中的意图消歧和相关性判断。

INSIGHTUGC 搜索常出现“词很像但意图不对”的误召回，例如攻略、求助、测评和交易意图共享相同实体词。工程上可把意图作为独立监督头或交互特征注入召回与精排，而不是期待单一 embedding 同时编码主题和任务目标；上线前应按意图桶检查 nDCG 与坏例。

Amanuel Alambo, Sathappan Muthiah, Diego Sierra, Zhenzhong Zhang, Atiq Islam

RAGTUM at SemEval-2026 Task 8: Contextual Query Rewriting and Dense Retrieval for Multi-Turn RAG

TUM

RAGTUM 将上下文感知 query 改写、OpenAI dense embedding、Milvus 检索和 Gemini 2.5 Flash 回答串成多轮 RAG 管线，并用轻量 LLM 过滤低相关段落。改写使 Recall@5 从 0.53 提升到 0.58；SemEval Task A 获得 nDCG@5 0.4883，在 38 个提交中排名第 11。

INSIGHT多轮社区搜索的 follow-up query 往往省略实体和约束，先生成独立 query 再向量召回比直接拼接历史更可控。该系统的价值在于组件清晰、可快速复现；但需要同时观察改写带来的召回增益和事实性损失，相关性过滤阈值也应按领域校准。

Finn Wigger, Maximilian Podolsky, Merle Wilmink, Zelong Peng

Cost-Governed RAG: Unified Per-Tenant Cost Attribution Across Retrieval and Generation in Multi-Tenant LLM Systems

论文把 TurboVec 向量索引与多租户 LLM 网关连接，统一归因 embedding、检索和生成费用，并在 Snowpark Container Services 上部署。100 个模拟租户、1000 万向量实验中端到端成本归因准确率为 99.96%，遥测开销低于查询时延的 0.04%，估算基础设施成本降低 3.1–9.0 倍。

INSIGHT搜索/RAG 平台的检索成本常被共享索引掩盖，只计 token 会误判租户和功能的真实 ROI。可借鉴三层成本模型，把向量内存、相似度计算和 embedding API 与生成账单统一打标；对社区搜索，则可进一步按 query 类型、召回深度和业务入口建立成本—相关性看板。

Navnit Shukla

Towards Building a Standard Benchmark for Low-Resource Nepali Information Retrieval.

Dublin City UniversityKathmandu University

论文指出拥有超过 2600 万使用者的尼泊尔语仍缺少带 query 与相关性标注的标准 ad-hoc 检索测试集，提出同时覆盖尼泊尔语单语、英语到尼泊尔语跨语种、以及尼英 code-mixed 三种设置。目标是系统评估形态变化、混合语言 query 和多语 embedding 迁移。

INSIGHT对中文社区中的方言、拼音、英文缩写和中英混输，平均 nDCG 很容易掩盖低资源 query 的失败。该路线提示团队建立独立测试集合与分桶标注，至少覆盖单语、跨语和 code-mixed 三类，再比较词法、稠密和多语模型，避免只凭主流中文样本选择召回器。

Praveen Acharya, Bal Krishna Bal

Scaling Laws for Retrieval-Augmented Generation: Corpus Size, Recall, and Faithfulness

技术报告从 scaling law 视角研究语料规模、检索召回和生成忠实度的联动，强调 RAG 扩容不能只看模型或上下文长度，而要同时测量候选证据覆盖率。报告发表于 2026 年 6 月，适合作为检索容量规划与端到端质量曲线设计的参考，但公开证据强度低于同行评审论文。

INSIGHT对社区搜索，索引文档增长不必然带来更好回答：若 top-k 不随语料密度调整，证据召回可能先成为瓶颈。可按索引规模绘制 Recall@k、nDCG、答案忠实度和延迟的联合曲线，再决定扩容、加深召回或改进重排；该项因匹配用户对 scaling law 的偏好获得加分。
