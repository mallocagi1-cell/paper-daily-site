ExperienceIndex: Artifact-Grounded Memory

论文针对搜索智能体反复阅读同一语料、难以复用文档经验的问题，提出按材料锚定的 ExperienceIndex。系统从历史轨迹保存单材料贡献、证据片段及材料间关系，以中间件方式增强检索；跨多类任务最高增加 11.0 分并降低在线成本 50.5%，平均成本下降 20.8%。

SkillForge: Co-Evolving Skills and Agents via Dynamic Skill Lifecycles

CAS

SkillForge 将技能划分为试用、活跃、稳定和退休状态，用适应度跟踪、预退休与变异让技能库随强化学习共同演化。ALFWorld 和 WebShop 成功率分别为 92.4% 与 78.4%，搜索增强问答达到 48.7%±0.3%；发布的 SkillFurnace 包含 5,852 条记录。

INSIGHT多步社区搜索的查询改写和工具使用技能会随模型能力与内容分布变化失效，技能库不能只增不减。可以记录技能使用次数、成功次数与衰退轨迹，周期性停用有害模板，并对变异版本开展保留集测试；该机制尤其适合防止旧流程在新的检索接口和 UGC 语料上持续误导策略。

Yuyao Ge, Yiwei Wang, Yuchen He, Baolong Bi, Lingrui Mei

MIMESIS: Learning User Simulators as Training Environments for Interactive Agents

MIMESIS 用真实对话与 13 类行为模式训练 9B 用户模拟器，再将其冻结作为交互智能体的强化学习环境。其 SOUL 指数达到 65.7，相对 Claude-Opus-5 的行为保真度高 13.4 分、图灵距离低 3.6 分；在 8 个环境训练后，对 9 个未见用户模拟器均优于使用 GPT-5.5 的训练方式。

INSIGHT社区搜索中的意图澄清和多轮追问需要真实用户难度，过度配合的通用模型会高估助手能力。可先用脱敏搜索对话校准模拟器，再将隐含用户目标转换成教练反馈，辅助策略学习；上线仍应以真人满意度、相关性和点击率验证，不能把模拟器成绩直接当作业务收益。

Hoang Phan, Dat Huynh, Andrey Zhmoginov, Qi Zeng, Wancen Mu

UniSkill: Learning Actor-Aligned Skill Proposals for an Evolving Policy

UniSkill 联合训练执行策略与技能库编辑器，允许添加、更新或不编辑技能。方法比较成功与失败轨迹的动作概率差，评价技能替换对当前策略的作用，避免为每个提案新采样；ALFWorld 成功率达到 98.4%±0.8%，WebShop 达到 84.7%±0.5%。

INSIGHT搜索智能体可将查询分解、改写与证据核验经验组织为可更新技能库，但需要把技能收益与策略自身变强分开。对同任务成功和失败轨迹的对比评价有助于降低试验成本；借鉴其编辑探索约束，可防止一次低质量内容把某类有价值的技能更新操作永久压制。

Yifei Lu, Cheng Liu, Dianzhi Yu, Hui Xiang, Ji Zhang

RunningTab: Direct Workspace Interaction with Environment-Side Tabs

KAISTDDeepAuto.ai

RunningTab 为直接搜索工作区文件的智能体增加环境维护的任务账本，记录未完成要求、已读证据及列出但未打开的候选。研究在 3 个基准和 3 个模型上验证；其诊断发现，已打开正确文件后的内容遗漏或失真占基线损失的 51.1%，19.8% 已见关键数值未进入交付物。

INSIGHT社区复杂查询不仅要召回内容，还要保证多个约束和关键证据进入最终回答。可把需求、帖子片段及来源定位保存在环境侧，在结束前核对仍未覆盖的要求；这种设计将“检索发现”和“答案采用”分别观测，适合诊断多步 RAG 中已经找到证据却没有使用的失败。

Jinheon Baek, Soyeong Jeong, Yumin Choi, Dongsu Han, Sung Ju Hwang

Building Reliable Data Analytics Agents: Lessons from the KDD Cup

NVIDIA

NVIDIA KGMON 获得 KDD Cup 2026 Data Agents 第 2 名，实践通过统一 SQLite 查询面、提前探查 schema 和持久 Python 状态减少工具错误。系统使用 schema、sql、write_answer 与 prose_helper 等固定接口，限制文档直接读取，并记录完整轨迹；文章未披露可归因的准确率消融。

INSIGHT社区搜索 Agent 可统一结构化信息与短文本证据的访问协议，减少重复工具和自由文件操作。应先提供必要的字段及关联上下文，再让助手定向读取证据；复用中间状态和原子写出答案有助于降低错误，多次尝试则应由分歧或校验失败触发，并用保留查询集防止流程过拟合。

ToolRACER: A Robust Agentic Conversation Emulation Resource for Agent Training and Evaluation

UniphoreUIUC

ToolRACER 用用户、助手和工具模拟器生成并验证多轮工具调用对话，覆盖 6 个领域、55 类人格和 5,643 条轨迹，约 66% 包含易失败情境。Qwen3-4B 在 τ²-bench 的宏平均成功率从 32.20% 提升至 39.20%，与 APIGen-MT 混合后达到 41.25%。

INSIGHT社区搜索助手的训练集应覆盖用户改口、信息缺失、工具报错与无法完成的请求，而非只收集成功路径。可以借鉴其轨迹验证和三类路径划分，分别评价端到端成功与过程正确性；ACEBench 中部分过程指标下降也提醒团队，不应只凭最终答案改善判断调用链更可靠。

From Pareto to Preference: Personalized Test-Time Scaling via Amortized Agentic Policy Discovery

PersonTTS 将推理准确率、延迟和成本约束联合建模，利用智能体发现可执行推理控制器，并复用相似需求的历史控制器及程序指导。AIME26 未见用户配置的联合满足率达到 83.85%，不复用经验为 79.22%；HMMT25 对应为 77.28% 和 69.16%。

INSIGHT社区搜索的深度检索预算同时受答案质量、响应时间和推理成本限制，可借鉴其需求配置匹配与控制器热启动。迁移对象应是可执行策略与修订经验，每个候选仍需在目标查询分布上测量；数学题实验没有验证 UGC 的 nDCG 或 CTR，因此业务适配应从离线回放开始。

Xinglin Wang, Zishen Liu, Tong Zheng, Shaoxiong Feng, Peiwen Yuan

System Switch: When Should a Fast Decision Model Stop and Think?

研究在实时 Doom 中让快速决策模型执行动作，仅在门控触发时交给慢速推理模型。900 道离线问题上，将低置信度的 30% 决策转交推理器，相对随机转交增加 0.13 准确率；但闭环 33 局均未到达出口，表明离线门控优势不能保证长程任务成功。

INSIGHT社区搜索可借鉴“简单查询走快路径、复杂查询触发深度搜索”的预算控制思路。置信度、校准和区分对错的能力需要分别测量，不能只看总体准确率；尤其应检查检索状态是否包含推理器需要的信息，并用完整用户任务评测门控，而非仅在孤立查询上调阈值。

BEACON-SP: Ontology-Grounded GraphRAG Framework for Clinical Suicide Risk Assessment

BEACON-SP 将患者知识图谱与领域本体结合，在诊断、药物、社会因素及时间关系之间开展多跳证据推理。作者在 100 名患者、15 类临床问题组成的 1,500 查询基准上与向量 RAG 比较；逐项配对评价中 GraphRAG 在 76.4% 的比较中被偏好，事实准确率仅小幅增加。

INSIGHT可迁移的设计是用类型和时间关系组织多跳证据，帮助社区搜索连接分散帖文中的事件与实体。临床本体与用户语料差异较大，适配时应只借鉴证据结构及评价协议；优先检查完整性、来源可追溯性和误关联率，不能把临床偏好比例解释为社区搜索相关性或点击率提升。

Kemal Davaslioglu, Nathan Conger, Sastry Kompella, Yalin E. Sagduyu, Nathaniel D. Bastian
