Atomic Intent Reasoning: Bringing LLM Semantics to Industrial Cross-Domain Recommendations

针对跨域推荐里 LLM 语义理解强、但在线推理太慢的矛盾，提出 AIR 框架：把 LLM 推理整体搬到离线，将用户意图拆解为可复用的“原子意图”单元并预计算，线上只做高效检索来组装用户意图表征，从而在保持语义一致性的同时获得约 400 倍推理加速。在快手电商的在线 A/B 中 GMV +3.446%，多个核心业务指标稳定且显著提升。

KEY INSIGHT · 对业务意味着什么“离线跑 LLM、线上查表”的解耦范式，是把大模型语义落到高 QPS 场景的关键手法——意图原子化让离线产物可组合复用，绕开线上逐请求调用 LLM 的延迟。对社区搜索同样可借鉴：离线用 LLM 抽取 query/UGC 的意图原子并建索引，线上检索拼装即可。+3.446% GMV 也佐证语义意图建模在真实电商流量上有可观增量。

Mult-DPO: Multinomial Direct Preference Optimization for Recommender Systems

NetflixUUVA

现实推荐反馈是“集合式”偏好：一批正样本都应排在所有未观测/负样本之前。直接套 Plackett-Luce 做 DPO 需对正样本的所有排列做边际化，组合复杂度爆炸。Mult-DPO 用多项式似然近似集合偏好事件，得到闭式、分类式的 DPO 目标，可直接让 LLM 对多候选对齐；并证明该多项式 DPO 损失是边际化 PL-DPO 损失的可计算上界，刻画了上界紧致程度与正负样本权重比的关系。代码已开源。

INSIGHT把 DPO 从成对偏好推广到集合偏好，正契合搜索/推荐里“一个 query 下多条相关结果”的监督形态——无需枚举排列即可对齐 LLM 排序器。对用 LLM 做相关性排序的社区搜索，这给出一个理论有保证、实现简单（分类式损失 + 开源代码）的偏好对齐方案，可替代逐对构造 pair 的低效做法。

Yaochen Zhu, Harald Steck, James McInerney, Aditya Sinha, Yinhan He, Nathan Kallus, Jundong Li

Generative Archetype-Grounded Item Representations for Sequential Recommendation

CUHK

序列推荐受限于物品表征质量，已有用 LLM 的方法只静态编码固定属性，忽视“目标受众”对物品身份的定义，且语义空间与真实行为脱节。GenAIR 让 LLM 分析物品元数据、推断出代表“理想目标受众画像”的 Archetype 文本描述，单次前向抽取其 embedding；再引入行为校准目标，把真实交互信号注入并调整 embedding 空间以贴合经验模式。在三个真实数据集上显著提升多种序列推荐模型并超过 SOTA 基线。

INSIGHT用“理想受众画像”而非物品固有属性来刻画物品身份，是 LLM 物品表征的一个有用视角——它把“谁会喜欢这条内容”显式编码进表征。行为校准这步很关键：纯语义 embedding 与点击/消费行为常有 gap，用交互信号校准能缓解。对 UGC 短文本，可借鉴“LLM 推断内容目标人群 + 行为校准”增强短文本语义表征，且单次前向、可插拔，落地成本低。

Yifan Li, Jiahong Liu, Xinni Zhang, Hao Chen, Yankai Chen, Wenhao Yu, Jianting Chen, Irwin King

Tau-Rec: A Verifiable Benchmark for Agentic Recommender Systems

PPrinceton

推荐系统正转向多轮对话式 agent 界面，但评测仍依赖主观的 LLM-as-judge。τ-Rec 用可验证奖励 + reveal-tagged 约束揭示机制（控制任务约束在对话中何时暴露），配合结构化目录谓词和 pass^k 可靠性指标，系统检验对话推荐 agent 的推理一致性。在 GPT-5.4、Claude Sonnet 4.6、Gemini 2.5 Flash、DeepSeek V4 Flash、Qwen3-32B 等 5 个模型族、9 种配置上，最强模型 pass^1 仅约 57%、pass^4 约 38%。代码与数据开源。

INSIGHTpass^k（重复 k 次都要对）暴露了对话推荐 agent 的稳定性短板——单次看着行、多次一致就崩。可验证奖励替代 LLM-as-judge，让多轮推荐评测摆脱主观打分。对要做对话式/agent 搜索的团队，这是个现成、可复现的压测基准；57%/38% 的差距也提示当前 LLM 直接做多轮推荐 agent 离生产可用仍有距离。

Bharath Sivaram Narasimhan, Karthik R. Narasimhan

SIDInspector: A Mapping-First Diagnostic Resource for Semantic-ID Tokenizers

生成式推荐里 Semantic ID tokenizer 常被当作独立产物复用：导出的“物品→码”映射成为后续序列生成器必须使用的地址空间，但这些映射缺乏统一检查接口，覆盖缺口、整码混叠、弱前缀、长尾压缩、前缀扇出等问题往往要等下游训练后才暴露。SIDInspector 定义了一套面向映射/元数据/交互/可选生成轨迹的适配器契约，校验契约并产出利用率、混叠、邻域对齐、热度分配、结构开销等映射级探针。在 23,742 个音乐物品上，GRID 式导出仅 3,749 个唯一整码、整码混叠率 0.977，而 ReSID/GAOQ 无混叠；确定性类目前缀对齐达 0.447，远高于学习式的 0.154 与 0.055–0.080。

INSIGHT把 Semantic ID 质量从“下游训练完才发现”提前到“训练前体检”，对生成式检索/推荐落地很实用。混叠率、前缀-行为对齐等指标直接预示 tokenizer 好坏。若团队要在搜索里用生成式检索（自回归生成 docID），这套诊断契约能在投入大模型训练前先筛掉劣质 ID 方案，省下大量试错成本；0.977 的整码混叠率这类信号一眼可判。

Jiandong Ding, Heng Chang, Huijie Qin, Tianying Liu
