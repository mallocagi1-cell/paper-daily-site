OneRetrieval: Unifying Multi-Branch E-commerce Retrieval with an Editable Generative Model

工业电商搜索的召回阶段由倒排索引、向量召回等多路分支经人工调权融合，缺乏联合优化。论文提出 OneRetrieval，用单一生成式检索(GR)模型统一多路召回，核心是 Keyword-Aligned Encoding(KAE)：把生成标识符的每个位置绑定到一个可解释的属性词，从而在保持召回质量的同时保留倒排索引“小时级新增 term、无需重训”的实时可编辑性。倒排分支虽转化率低于平台均值，却因可被运营实时干预而难以替代，KAE 正是为补齐这一能力而设计。

The Clustering Strikes Back: Building Cost-Effective and High-Performance ANNS at Scale with Helmsman

Xiaohongshu📖 深度解读 · 16 分钟 →

大规模向量检索一直放在内存里跑 HNSW，因为 SSD 太慢。小红书的经验是，SSD 慢主要慢在图索引一步等一步的串行读：召回要上千个候选时，改用聚类索引，先在内存里选好要读的簇，再一次性把读请求全部发出去，多块高速 SSD 的带宽就能接近内存方案。线上约 40 台全闪存服务器接下了原来约 35,000 个 CPU 核的内存集群。代价也要看清：同一台机器上，它的吞吐只有内存 HNSW 的四分之一到七成，省钱主要靠 DRAM 用量少了一个数量级，而且前提是 top-k 大、召回率要求不极端。SSD 上的检索快不快，主要看读请求之间有没有依赖。

CoDeR: Local Constraint-Compatible Retrieval Beyond Semantic Similarity

检索系统长期把语义相似度当作相关性的代理，但对“带约束”的查询会失效——文档主题贴近 query 却支持相反的约束方向(满足了本应排除的属性、肯定了本应否定的关系)。论文称之为 constraint-violating evidence exposure，提出 CoDeR：保留标准主题编码器负责候选覆盖，另加一个双编码器实现的“兼容性打分器”，用词法极性(lexical-polarity)监督在“满足/违反”对比样本上训练。兼容性信号既可对主题候选重打分，也可单独召回一路兼容性候选，推理时无需调用外部 LLM。

INSIGHT把“主题相关”和“约束兼容”解耦，是处理否定/排除类 query 的实用思路。社区搜索中大量 query 含隐式约束(如“不辣的火锅”“非广告测评”)，纯语义向量召回容易引入违反约束的负向证据；CoDeR 用轻量双编码器在召回/重排阶段补一路极性兼容信号，推理零 LLM 调用、延迟可控，易于嵌入现有多阶段检索。

Xingkun Yin, Xuebin Tang, Hongyang Du

RCEM: Embedder Equipped with Query Rewriting Skill for Robust Conversational Search in Distributional Shift

Microsoft

会话式检索中，多轮对话里的 query 高度依赖上下文。论文提出 RCEM，把 LLM 的 query 改写能力蒸馏进 embedding 模型，让稠密检索在推理时无需显式改写就能感知上下文。与以往直接学“对话→文档”匹配不同，RCEM 让“会话 query 的 embedding”对齐“改写后 query 的 embedding”，从而在分布漂移(distributional shift)下更稳健；训练不需要昂贵且难获取的“会话 query→文档”相关性标注。在 QReCC、TopiOCQA、TREC CAsT 上一致优于强会话检索基线。

INSIGHT“把改写能力蒸馏进 embedder、推理零改写”避开了在线 LLM 改写的延迟与成本，对社区搜索的多轮、带上下文 query 很有借鉴价值。用“对齐改写后 query 向量”作监督信号，绕开稀缺的会话级相关性标注，是一种低成本获得上下文感知召回的方法；落地只需替换或微调 embedding 模型，不改动在线检索链路。

Kilho Son, Paul Hsu, Cha Zhang, Dinei Florencio

Uncertainty-Aware Hybrid Retrieval for Long-Document RAG

RAG 的效果高度依赖检索证据的粒度：大块保留上下文但引入无关内容、稀释关键证据；细块更紧凑却因缺乏语义/词法/桥接线索而难以稳定召回。论文提出 UMG-RAG，一个免训练的不确定性感知混合检索框架：把已有的稠密与稀疏检索器当作跨多种 chunk 粒度的互补专家，对每个 query 把各“专家×粒度”的打分列表转成证据分布、用分布熵估计可靠性，再按 query 自适应融合候选，无需训练新检索器或改动生成器。

INSIGHT用“分布熵=可靠性”把 chunk 粒度选择变成 query 级的自适应问题，且全程免训练、复用现有 dense/sparse 检索器，迁移成本极低。社区搜索/RAG 落地常卡在“切多大块”，UMG-RAG 提供了一个不重训就能按 query 在多粒度间动态加权的融合方案，适合在现有召回栈上快速做 A/B 验证。

Hoin Jung, Xiaoqian Wang

Learning to Reason by Analogy via Retrieval-Augmented Reinforcement Fine-Tuning

传统基于词法/语义相似度的检索不适合复杂推理任务——语义相近的问题可能需要完全不同的解题策略，表面不同的问题却可能共享同一推理模式。论文提出 RA-RFT(Retrieval-Augmented Reinforcement Fine-Tuning)：用 gold-relevance 蒸馏训练一个“按预期推理收益而非语义重叠排序上下文”的检索器，再用强化微调让策略模型在检索到的类比示范下学习，借助可验证的结果奖励利用推理轨迹；分析显示推理感知的检索能召回更互补的上下文。

INSIGHT把检索目标从“语义相似”改为“对下游推理的预期收益”，是检索器训练目标的一次重定位，对需要多步推理的搜索/问答有启发。社区搜索中“找相似帖”未必等于“找有用帖”，用下游任务收益作相关性监督、配合 RL 微调，可让召回更服务最终答案质量，但代价是需要可验证奖励与 RL 训练成本。

Zilin Xiao, Qi Ma, Chun-cheng Jason Chen, Xintao Chen, Avinash Atreya, Hanjie Chen, Vicente Ordonez

How Fine-Grained Should a RAG Benchmark Be? A Hierarchical Framework for Synthetic Question Generation

EEmory

评估 RAG 需要能刻画问题多样性的基准，但实践中缺乏“该在哪些维度、用多细的粒度”的经验指导。论文提出 HieraRAG 分层框架，把最优粒度定义为“在给定 RAG 配置下使类别间生成质量标准差(判别力)最大”的粒度。以 FineWeb-10BT 生成 5,872 条合成 QA，覆盖问题复杂度、答案类型、语言变体三个维度×2/4/8 三档粒度：用 BM25+Falcon-3-10B 流水线发现复杂度维度受益于细粒度(判别力 0.053)，而答案类型与语言变体在中等粒度最优，并提出 Coherence Ratio 度量。

INSIGHT基准的“粒度”本身是个可优化变量，用判别力(类别间质量方差)来选粒度，给 RAG/检索评测设计提供了可量化的方法论。对自建社区搜索评测集有直接借鉴：与其凭经验切维度，不如按“哪种切分最能区分系统好坏”来定，避免评测过粗(区分不开)或过细(噪声大)。

Chase M. Fensore, Kaustubh Dhole, Jason Fan, Eugene Agichtein, Joyce C. Ho

When Does Mixing Help? Analyzing Query Embedding Interpolation in Multilingual Dense Retrieval

NUS

混合语言查询在多语社区很常见，但稠密检索器对此的敏感性研究不足。论文在 mMARCO 上做比例可控实验，通过 embedding 级插值(把混合 query 构造成单语 embedding 的插值)系统评估不同混合比例。基于 BGE-M3 发现：存在最优混合比例，在 105 个设置中的 88 个上优于最好的单语端点；并揭示由英语主导带来的不对称——检索非英语文档库时混合普遍有益，含英语的库则用纯英语 query 最好，且英语是所有非英语语言最强的混合伙伴；控制英语主导后，混合收益与类型学距离负相关。

INSIGHT在 embedding 空间对多语 query 做插值即可稳定提升跨语检索，且无需改模型，对有跨语、中英混排 query 的社区搜索是低成本增益。关键经验是“是否混、混多少”取决于目标文档库的语言构成与英语主导程度，可据此对不同语言的索引采用不同的 query 表示策略。

Tongyao Zhu, Chao-Ming Huang, Min-Yen Kan

CQC-RAG: Robust Retrieval-Augmented Generation via Cross-Query Consistency

UESTC

RAG 的可靠性对“证据如何被检索与使用”高度敏感：语义等价但句法不同的 query 会得到不同检索结果，无关或误导文档会诱发幻觉。已有多路推理方法靠采样多个候选答案做投票/置信选择，但多样性来自不可控的解码随机性、且评估局限于单一 query 视角。论文提出 Cross-Query Consistency 假设——正确答案在“语义等价但句法多样”的 query 间保持高置信，而噪声诱发的幻觉置信不稳定，据此设计 CQC-RAG 提升鲁棒性。

INSIGHT用“跨改写 query 的置信一致性”作答案可信度信号，比单纯多次解码投票更可控，因为多样性来自受控的 query 改写而非随机采样。社区搜索的问答类场景可借此降低因 query 表述差异导致的检索波动与幻觉，思路是把“同义改写”从查询扩展手段升级为答案校验信号。

Yanjia Sun, Sifan Liu, Jie Shao

X-MADAM-RAG: Diagnosing and Handling Chinese-English Evidence Conflict in Retrieval-Augmented Generation

RAG 收到的证据可能不只是有噪声，而是相互矛盾，这在多语场景尤其突出——检索到的中文与英文证据可能支持互不相容的答案。论文构造 X-RAMDocs-ZHEN 中英受控基准(300 例、6 种平衡条件，含单语支持、双语一致、反向冲突、带噪冲突)，并提出可解释流水线 X-MADAM-RAG：按文档抽取候选、可见证据修复、确定性候选分组、冲突感知聚合。在 Qwen2.5-7B-Instruct 上取得 0.9667 严格准确率与 0.9767 冲突感知成功率，优于 evidence-norm 基线。

INSIGHT把“证据冲突处理”拆成抽取→修复→分组→冲突感知聚合的可解释步骤，对多语证据相互矛盾的检索问答很有用。社区搜索常面临中英混合、版本不一的 UGC 证据，X-MADAM-RAG 显示用确定性分组加冲突感知聚合能把答案严格准确率提到 0.96 以上，且流程可解释、便于排查 badcase。

Yongqi Kang, Yu Fu, Yong Zhao
