KaLM-Reranker-V1: Fast but Not Late Interaction for Compressed Document Reranking

重排序模型多把 query 与 passage 拼接做联合编码，计算耦合限制了部署效率与灵活性。KaLM-Reranker-V1 提出 "fast but not late-interaction"（FBNL）方案：基于 encoder-decoder，用 encoder 配合 Matryoshka 池化对 passage 预编码，decoder 编码 system/user instruction 与 query intent，再以 cross-attention 建模 query 上下文与 passage 表征的相关性，从而解耦 passage 编码又保留细粒度相关性建模。提供 Nano/Small/Large 三档（0.27B/1B/4B 激活参数）。BEIR 上达到 SOTA、与 Qwen3-Reranker 系列持平；MIRACL 多语未专门训练仍表现优异；LMEB 上 0.27B Nano 即可与 7–12B embedding 模型竞争。

Dissecting Agentic RAG: A Component Ablation for Multi-Hop QA with a Local 7B Model

agentic RAG 常叠加自适应检索路由与多轮检索循环，但各组件实际贡献并不清楚。作者用本地 Qwen2.5-7B-Instruct 在 HotpotQA distractor 开发集 5000 题上做受控消融：完整 pipeline EM=53.2%/F1=61.6%，对比单轮 dense 检索基线 EM=43.1%/F1=54.0%。八组消融结论：(1) 基于 reciprocal rank fusion 的固定混合检索稳定优于规则式自适应路由（+1.8 EM/+1.9 F1），因为路由启发式会因子问题普遍含命名实体而过度路由到 BM25；(2) 对分解子问题做两轮检索即可获得五轮 95% 的收益，更深循环无明显增益；(3) query 分解与 cross-encoder 重排各自带来显著但更小的提升（p<0.01、p<0.001）。

INSIGHT结论指向简单且固定的选择往往不输甚至优于自适应版本：增益主要来自短检索循环，而非自适应路由或多轮迭代。落地启示——RRF 混合检索可作稳健默认项；检索轮数设到 2 即可，省掉深循环的延迟与成本；自适应路由要警惕命名实体触发的偏置。全程不用闭源 API、仅本地 7B，复现门槛低，适合作为社区搜索 RAG 链路的组件取舍基线。

Improving Long-Context Retrieval with Multi-Prefix Embedding

WWaterlooCMU

长文档检索存在张力：单向量 embedding 丢失细粒度信息，token 级多向量方法存储开销过大。MPE（Multi-Prefix Embedding）把文档按 EOS token 切成 chunk，用一次 causal 前向编码整段序列，在每个 prefix 边界各取一个 embedding，从而保留跨 chunk 上下文、支持 chunk 级 MaxSim 匹配，且仅用文档级相关性标签训练。在 MLDR-en、BrowseComp-Plus、LongEmbed 上，MPE 与单向量、独立分块、多向量基线相比表现持平或更优，并天然提供定位证据 chunk 的来源归因机制。

INSIGHTMPE 的巧思是单次前向 + prefix 边界取向量，兼顾多向量的细粒度与单向量的存储成本（每文档存的向量数=chunk 数，远少于 token 级）。仅需文档级标签即可训练，省去 chunk 级标注。来源归因能力对社区搜索定位为何召回某条帖子、命中哪一段很实用，对长 UGC（长帖、多段问答）召回是可直接借鉴的折中表示方案。

Zhenglin Yu, Xueguang Ma, Shengyao Zhuang, Zhichao Xu, Luyu Gao

HAKARI-Bench: A Lightweight Benchmark for Comparing Retrieval Architectures and Efficiency Settings under Unified Conditions

RAG 与语义搜索普及后，选择 embedding 与检索配置越来越难，而大型检索 benchmark 太重、开发期难以反复跑。HAKARI-Bench 把现有检索套件重构为小数据集（Nano-sets）：35 个 benchmark、551 个任务、覆盖 43 种语言，统一格式下可在相同条件比较五类检索族（BM25、dense、sparse、late interaction、reranker）及其效率变体（降维、量化、重排）。在 55 个模型上，其总体排名与官方 MTEB retrieval v2、MMTEB v2 retrieval、English BEIR(full) 的 Spearman 相关均 >0.97。MIT 许可，开放代码、数据与榜单。

INSIGHT价值在于轻量但高保真——用 Nano-sets 在开发期快速做模型选型、回归检测、读取质量-效率 Pareto 前沿，且与官方大榜排名一致性 >0.97，不必每次重跑重型评测。统一同条件对比降维/量化/重排等生产设置，正对应社区搜索上线前的 embedding/reranker 选型与压缩取舍。MIT 开源可直接接入内部评测流水线。

Yuichi Tateno

Only Ask What You Don't Know: Grounded Delta Planning for Efficient Multi-step RAG

National Taiwan University

多跳问答中现有 RAG 要么跨轮检索传播误差，要么过度生成推理步、增加成本却不提精度。GDP-RAG 是基于规划的框架，只针对信息增量（delta）：(1) 先做初步检索为规划提供 grounding；(2) 用 gap-conditioned 规划提示只索取缺失信息；(3) 用 skeletal trajectory 把每个子查询与一个携带初检证据的 Thought 配对，贯穿到最终答案。在 HotpotQA、2WikiMultiHopQA、MuSiQue 上，GDP-RAG 取得最高准确率 60.63%，cost-of-pass 为 0.51——比 PAR-RAG（0.65）低 22%、比 KnowTrace（1.57）低 68%，且无方法能同时做到更高准确率与更低成本。

INSIGHT核心是只问你不知道的——先 grounding 再按信息缺口规划，把算力集中在未解决的 gap 上，避免重复检索已知信息。skeletal trajectory 让证据在子查询间显式传递，减少误差累积。准确率与 cost-of-pass 双指标同时占优，对需要控制 LLM 调用成本的搜索问答链路很有借鉴：用初检结果约束规划范围，是降本不降质的可操作手段。

Wei-Chieh Chou, Xuanjun Chen, Jian-Ren Lin, Claire Lin, Hung-yi Lee

When Confidence Takes the Wrong Path: Diagnosing Retrieval-State Lock-In in RAG

很多黑盒不确定性方法把多次采样答案一致读作高置信，但当重复采样都条件于同一缺陷检索状态（空状态回退到参数记忆，或被一致但错误的邻域填充）时，答案会因错误稳定而一致。作者将该失败命名为 retrieval-state lock-in，并把单一置信分拆解为三个对象：答案面、检索证据、检索状态本身。在可检视的 KG-RAG 系统六个 QA 快照上测量：每题采样五次时，42% 的 KG-RAG 错误与 59% 的 dense 检索错误答案离散度为零，使一致性无从排序；而证据与检索状态检查仍能标记出多数错误。仅当三者都判为低风险才接受答案的规则达到 91.9% 池化精度（接受率 7.7%）。

INSIGHT提醒一个被忽视的盲区：RAG 里答案一致不等于可信，错误检索状态会制造稳定的错误一致。把置信拆成答案/证据/检索状态三个对象分别校验，是可审计的判定思路。对社区搜索+LLM 问答，落地启示是除答案自洽外要单独监控检索证据质量与检索状态（是否空召回、同质化邻域）；但代价是覆盖率仅 7.7%，高精度需要牺牲可回答比例。

Multi-Vector Embeddings are Provably More Expressive than Single Vector Embeddings

Google

多向量（MV）embedding 用多个向量表示数据、以非线性 Chamfer 相似度打分，检索精度高于用内积的单向量（SV）embedding，但此前缺乏 SV 在相同表示规模下无法逼近 MV 的形式化证明。近期 MUVERA 证明 D=m^O(1/ε²) 维 SV 可逼近；若能改进到 D=md 就意味着 MV 不比 SV 更强。本文排除了这一可能：构造了一族每个至多 m 个向量的 MV embedding，证明逼近它们所需的 SV 维度为 D=(ε²m)^Ω(1/ε)，建立了 MV 与 SV 在表示规模上的强分离。证明用 Pattern Matrix Method，把 Chamfer 相似度矩阵编码为 NAND_k 布尔函数的难例。

INSIGHT这是对 IR 社区长期信念的形式化背书：在固定表示规模下，多向量能表达单向量连近似都做不到的相似度。理论意义大于即时落地——它解释了 ColBERT 式多向量为何在检索精度上难以被单向量完全替代，也为是否引入多向量及其存储/检索成本提供了原理性依据。对社区搜索的取舍：当对细粒度相关性要求高时，多向量的表达力优势有理论保证，而非仅经验现象。

Rajesh Jayaram

moBERTo: A Modern Encoder for Portuguese via Continued Pretraining of ModernBERT

encoder-only transformer 仍是生产 NLP 流水线的关键。moBERTo 通过对 ModernBERT-base 做持续预训练（在 FineWeb2 经教育/STEM 分类器过滤的 12B token 语料上训练 5 个 epoch、共 60B token）得到葡萄牙语版本，保留 RoPE、局部-全局交替注意力、flash attention、unpadding 等结构。在信息检索（含 8192 token 长上下文检索）、文档分类、NER、NLU 上评测：最优变体（葡语 tokenizer + 子词匹配 embedding 迁移 + 长上下文后训练）在三个葡语检索 benchmark 上取得最高平均 reranking nDCG@10，并在 PLUE-PT 最佳。消融显示：持续预训练显著优于从头训练（尤其保留长上下文能力）；tokenizer 适配提升 token 级任务但损害长上下文检索；专门的 8192 长上下文后训练进一步提升重排与 NER。

INSIGHT给把 ModernBERT 适配到特定语言/领域做检索与重排提供了清晰配方：持续预训练优于从头训、长上下文后训练单列一阶段、tokenizer 适配对长上下文是双刃剑。对非英语社区搜索（含中文 UGC）的 encoder 选型有方法论参考——encoder-only 在判别式（召回/重排）任务上仍能与更大的 decoder-only 竞争，且权重与数据全开源便于复刻。

Thiago Laitz, Thales Sales Almeida, João Guilherme Alves Santos, Giovana Kerche Bonás

Novelty-Aware Agentic Retrieval: Comparing Research Contributions Through Structured Multi-Step Reasoning

科研文献检索中排序列表不够用——研究者需要知道论文之间如何关联、在哪重叠、有何差异、哪些问题×方法组合缺失，而标准 RAG 独立总结文档、丢掉了这种比较信号。作者提出 Novelty-Aware Research Agent 原型：在 RAG 上叠加六个 typed-contract 组件（query 分析、ReAct 式检索循环、相关性排序、schema 引导的贡献抽取、三遍比较 agent、答案生成），除返回相关论文外还产出结构化比较产物：每篇贡献记录、论文级重叠、问题×方法 gap 矩阵。在 100 篇语料上，作者标注分级相关性下排序器主查询 Precision@5=1.000、nDCG@5=0.752，优于 BM25/dense/hybrid；十查询扩展评测 Precision@5=0.980、nDCG@5=0.739；schema 合规率 84–86.7%；gap 矩阵空格精度 0.600。

INSIGHT把检索从返回 ranked list 升级为产出结构化比较产物（重叠、差异、gap 矩阵），对调研型/探索型搜索是有意思的方向。typed-contract 组件化设计便于逐环节评测与替换。局限也坦诚：100 篇小语料、作者自标注、缺独立评测、延迟-结构权衡明显。对社区搜索的启示——面向找观点对比、找空白的复杂查询，agentic 比较式检索能给出列表之外的结构化答案，但需权衡延迟与可扩展性。

Shou-Tzu Han

From Embedding Geometry to Spectral Search: Energy Dispersion Networks For Vector Retrieval

embedding 空间不必只用逐点几何分析，也可视为由列向量拓扑（特征空间结构）诱导的谱图上的能量网络。作者提出 Graph Wiring 通用框架来利用特征空间谱结构，及其面向向量搜索的具体实例 Spectral Indexing：把几何相似度与谱信息耦合，相比纯几何检索改善 head-tail 一致性与语义对齐，并通过 tau-modulation 支持自适应搜索行为以契合现代 RAG 流水线。论文给出完整算法流程，用 epiplexity 建立理论基础，并在 benchmark 与工业设置上用开源 arrowspace 库评测。

INSIGHT提供了一个不同视角：把向量检索从逐点几何最近邻扩展到谱图上的能量传播，借特征空间谱结构改善长尾（head-tail）召回一致性。tau-modulation 给检索行为一个可调旋钮以适配不同 RAG 需求。方法较前沿、落地门槛偏高，但 arrowspace 开源可供试验。对社区搜索长尾 query 的语义对齐问题，谱方法是一个值得小范围验证的探索方向。

Lorenzo Moriondo, Ilias Azizi
