Towards Fast Domain Adaptation and Fine-Grained User Simulation for Evaluating Conversational Recommender Systems

论文针对对话式推荐系统(CRS)离线评估难题，指出现有基于 LLM 的用户模拟器存在三个局限：依赖固定 prompt 与预定义动作空间导致跨领域迁移差、难以复刻细粒度语言风格与动态偏好、评估有效性不足。作者提出 AdaptSim，通过自动 prompt 生成与开放动作机制降低人工成本、提升跨域灵活性，并用 “think-then-respond” 受控文本生成精细控制语言风格；评估侧设计了基于 BFS 的轮级 pairwise 对比框架。在 3 个领域、4 个 LLM 上的实验表明其能生成真实多轮对话，对 CRS 能力与鲁棒性给出可靠评估。

URecJPQ: Memory-efficient Multimodal Recommendation Models through RecJPQ in Large-Scale Scenarios

GGlasgowBBari

论文聚焦工业级推荐中 ID embedding 的内存瓶颈，多模态特征会进一步放大显存压力。作者提出 URecJPQ，把 RecJPQ 的联合乘积量化(Joint Product Quantization)扩展到大规模多模态 top-k 推荐：每个 user/item 不再用一份完整独立 embedding，而是用一组共享子 embedding 的拼接来表示，从而大幅压缩可训练参数。在 movies/baby/sports 三个数据集上，checkpoint 体积下降 86–98%、可训练参数下降 98–99%，平均 recall 仅下降 8.5%、NDCG 下降 16%，在 baby 商品域部分指标甚至提升最高 85%。

INSIGHT量化式 ID 表示与生成式推荐的 Semantic ID（item tokenization）同源：都用共享码本把海量 item 压成离散子单元。对短文本 UGC 搜索的启示是，召回/排序侧的 item 表示可用乘积量化压到原参数量的 1–2%，显著降低在线显存与 checkpoint 存储，代价是 NDCG 有可控损失，需按业务容忍度调码本粒度。该思路也为后续把 item 表示对接生成式解码(在码本上做 beam search)预留了空间。

Giuseppe Spillo, Zixuan Yi, Aleksandr Petrov, Cataldo Musto, Craig Macdonald, Iadh Ounis

TailorMind: Towards Preference-Aligned Multimodal Content Generation

HKUHIT

论文研究“个性化多模态内容生成”——在没有现成 item 池或缺少匹配 UGC 时，直接为用户合成定制内容。作者提出 TailorMind，将协同偏好建模与可控多模态生成打通：用超图协同过滤补全稀疏用户历史，用 ranking-error 反馈与文本梯度下降优化文本画像；通过检索增强的风格控制把生成结果锚定到真实 UGC 风格，并用跨模态一致性反思抑制语义漂移。论文还构建了 TailorBench 基准，覆盖 3 个主流平台，从连贯性、新颖性、美学、幻觉等 5 个维度评估生成质量。

INSIGHT该工作把“推荐”从挑选已有内容延伸到按用户偏好生成内容，对 UGC 社区的内容冷启动/补全有想象空间：当长尾 query 无优质帖子可召回时，可用协同信号驱动生成候选。值得借鉴的是用 ranking-error 反馈做文本画像优化(把偏好误差转成可微的文本梯度)，以及用检索到的真实 UGC 作风格锚点来压制生成内容的幻觉。但生成内容的真实性与合规是落地前必须先解决的风险点。

Hengji Zhou, Ye Liu, Yufeng Liu, Si Wu, Lianghao Xia, Liqiang Nie

Towards Root Memories: Benchmarking and Enhancing Implicit Logical Memory Retrieval for Personalized LLMs

USTC

论文指出个性化 LLM 的记忆系统普遍只靠语义相似度检索，容易漏掉与当前语义重叠低、但逻辑上关键的历史记忆，且现有基准无法评估这一问题。作者先构建 IMLogic——面向长对话隐式逻辑记忆检索的高质量基准；再提出 root memory，一种结构化、保留决策过程的表示，从长期用户历史中蒸馏出可复用的个性化逻辑。配套的 RootMem 是即插即用框架：先把原始历史蒸馏成 root memory，再用基于 LLM 的路由器激活逻辑相关记忆，与语义检索形成互补。实验显示其显著优于最强检索基线。

INSIGHT对个性化搜索/助手的启示是：用户长期意图常以“决策逻辑”而非“表层语义”形式存在，纯向量相似检索会系统性漏召这类记忆。RootMem 的两段式(蒸馏结构化记忆 + LLM 路由激活)可借鉴到用户画像与 query 个性化——把零散行为蒸馏成可复用的偏好规则，再在检索时按逻辑相关性而非仅语义相似度激活。IMLogic 这类基准也提示，评估个性化记忆要专门构造“语义低重叠但逻辑相关”的难样本。

Hongxun Ding, Xiang Yu, Chengbing Wang, Jianfei Xiao, Keqin Bao, Wenjie Wang, Xiangnan He
