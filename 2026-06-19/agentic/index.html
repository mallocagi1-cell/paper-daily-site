Decoupling Search from Reasoning: A Vendor-Agnostic Grounding Architecture for LLM Agents

生产环境 LLM Agent 越来越依赖实时搜索，但模型自带的 native search grounding 把检索策略、provider 选择、证据注入、成本、延迟、生成行为捆绑在单一模型-厂商边界内，难以检视、调参、复用与迁移，还会触发 Search-Induced Verbosity 破坏严格输出格式。论文提出 Decoupled Search Grounding (DSG)，用一个 MCP 兼容网关把 grounding 移出推理模型，将 provider 路由、来源感知上下文渲染、可配置 fallback、检索深度控制、精确+语义缓存都做成一等可控项。在 SimpleQA/FreshQA/HotpotQA 上对 5 个前沿模型评测：native search 仅在时效敏感的 FreshQA 占优，DSG 在整体上给出更强 frontier。

Beyond Monolingual Deep Research: Evaluating Agents and Retrievers with Cross-Lingual BrowseComp-Plus

University of Tokyo

Deep research Agent 通常被要求检索证据、对来源推理并给出有依据的答案，但现有 browsing 基准默认 query 与证据同语种，无法回答"证据在另一种语言时 agentic search 还能否工作"。论文提出 XBCP（Cross-lingual BrowseComp-Plus），保留 BrowseComp-Plus 的英文问答空间，只改变支撑文档的语言：cross-lingual 设定下每个 query 配单一指定语言的证据，multilingual 设定下整个证据库随机均匀分布到 12 种语言。基准用于系统衡量检索器与 Agent 在跨语言证据下的检索-推理能力。

INSIGHT该基准把"证据语言"作为受控变量单独剥离，揭示 deep research 在跨语言场景的真实短板——这正是中文社区搜索面对外文资料时的痛点。启示是：跨语言召回质量直接决定 Agent 上限，单纯堆强 LLM 不够；评测搜索 Agent 时应单独考核跨语言证据定位与整合，而非只看同语种问答。

RODS: Reward-Driven Online Data Synthesis for Multi-Turn Tool-Use Agents

多轮工具调用的强化学习受限于静态数据集中有效样本快速枯竭。论文从 GRPO 的梯度分析出发，指出梯度信号集中在 rollout 奖励方差最大的任务上（Popoviciu 上界的结果），即处于 Agent 能力边界、成败各半的样本贡献了最大策略梯度；随训练推进该边界持续移动，逐步耗尽静态池中的有效样本。RODS（Reward-driven Online Data Synthesis）把进度奖励方差当作零成本的边界探测器（无需 rollout 之外的额外推理），在线持续合成处于能力边界的新任务，把 RL 训练与数据生成连成回路。

INSIGHT用"奖励方差"定位能力边界、再针对性合成训练数据，是多轮工具调用 Agent 做 RL 的实用思路：不必预先准备海量静态任务，而让数据随策略一起进化。对搜索/推荐 Agent 训练的启示是，可复用 rollout 已算出的奖励方差零成本筛选高信息样本，缓解 GRPO 后期梯度信号集中、样本利用率走低的问题。

Ruishan Fang, Siyuan Lu, Chenyi Zhuang, Tao Lin

VISUALSKILL: Multimodal Skills for Computer-Use Agents

MITUUCSB

Computer-use Agent (CUA) 在标准基准接近人类，但在长程任务和未见软件上仍吃力。已有 skill 库虽提供可复用技能，却把技能表示成纯文本，忽略 GUI 交互的视觉性。论文提出 VISUALSKILL：一种分层多模态技能，针对目标应用组织为"中心索引 + 按主题文件"，Agent 通过 load_topic 这一 MCP 工具按需取回相关主题的文字与图。技能由两阶段流水线构建——结合人工文档与真实应用 UI 探索。在 CUA-World 与 OSExpert-Eval 上，Claude Code CLI + Claude Opus 4.6 用 VISUALSKILL 平均得分 0.456，较基线提升约 +15%。

INSIGHT把技能从"纯文本"升级为带图的多模态、并用 MCP 工具按需加载，是降低 Agent 上下文占用、提升 GUI 操作成功率的实用设计。对搜索/推荐类 Agent 的启示是：可复用技能/工具说明应结构化为可检索的索引+主题分片，按需注入而非一次性塞满上下文；图文混合的技能表示在涉及界面、可视化结果的任务上明显优于纯文本。

Ziyan Jiang, Li An, Yujian Liu, Jiabao Ji, Qiucheng Wu, Jacob Andreas, Yang Zhang, Shiyu Chang

Towards Scalable Customization and Deployment of Multi-Agent Systems for Enterprise Applications

基于 LLM 的多 Agent 系统在复杂推理与任务执行上表现强，但生产部署受困于领域定制需求与 agentic workflow 的高延迟、高推理成本。论文提出统一的定制+高效部署框架：第一阶段 Agentic Model Customization 结合持续预训练、监督微调与偏好优化，把一个紧凑模型适配到专业领域同时保留 agentic 能力；第二阶段 Inference Optimization 集成投机解码与 FP8 量化并做针对性校准，在质量损失极小的前提下实现低成本服务。

INSIGHT该框架给出把多 Agent 系统真正落到生产的两段式路径：用 CPT+SFT+偏好优化把小模型"压"进垂直域、再用投机解码+FP8 把推理成本压下来。对搜索/推荐工程的启示是，agentic workflow 的成本主要来自多步推理的串行 token 生成，紧凑专用模型+量化+投机解码的组合，是在延迟与成本约束下规模化 Agent 服务的现实选择。

STARE: Surprisal-Guided Token-Level Advantage Reweighting for Policy Entropy Stability

GRPO 等可验证奖励强化学习（RLVR）已成为 LLM 复杂推理的主流后训练范式，但常在训练中出现策略熵塌缩。论文对 GRPO 下 token 级熵动力学做一阶梯度分析，发现 token 级信用分配错配：每个 token 的熵变化可分解为轨迹级 advantage 与下一 token 分布上熵敏感度函数的乘积，呈现 advantage-surprisal 四象限结构与近临界性。据此提出 STARE：用 batch 内 surprisal 分位数识别熵关键 token 子集，选择性重加权其有效 advantage，并引入目标熵项稳定策略熵。

INSIGHT把熵塌缩归因到 token 级信用分配、再用 surprisal 分位定位"熵关键 token"做精细重加权，是稳定 RLVR 训练的实用手段。对要用 RL 训练推理/搜索 Agent 的团队，启示是熵塌缩并非全局现象而集中在少数高 surprisal token；与其全局调 KL 或熵系数，不如按 token 的 advantage-surprisal 象限做差异化干预，兼顾探索与收敛。

Haipeng Luo, Qingfeng Sun, Songli Wu, Can Xu, Wenfeng Deng

LegalWorld: A Life-Cycle Interactive Environment for Legal Agents

Fudan University

民事诉讼本质是全生命周期过程——开案当天起草的内容会约束数月后庭审的走向。但现有法律基准只评测孤立子任务，已有法律 Agent 模拟器又在每个场景重置到共享 ground truth，未建模跨阶段因果依赖。论文提出 LegalWorld：把中国民事诉讼建模为五阶段（七子场景）因果相连的状态链，基于 75,309 对中文民事判决构建；并配套可复用基础设施（本地记忆、全局案件记忆、Skill/Tool 库）保持纠纷在全生命周期内一致。在此之上构建 LongJud-Bench，跨五个相连阶段评测 Agent 能力，含 18,992 条评分。

INSIGHT用"因果相连的状态链"取代孤立子任务评测，配合本地+全局记忆与 Skill/Tool 库，是评测长程、强状态依赖 Agent 的更真实范式。对搜索/推荐场景的启示是：多轮、跨会话的任务型 Agent 应显式维护可跨阶段读写的记忆与工具库，且评测要考核早期决策对后续阶段的级联影响，而非单点准确率。

Songhan Zuo, Shengbin Yue, Tao Chiang, Guanying Li, Yun Song, Xuanjing Huang, Zhongyu Wei

ActMem: Bridging the Gap Between Memory Retrieval and Reasoning in LLM Agents

Nanjing University

LLM Agent 在长期交互中依赖记忆管理，但现有记忆框架多把 Agent 当作被动"记录者"，检索信息却不理解其深层含义，在需要推理和复杂决策的场景下失效。论文提出可执行记忆框架 ActMem，将记忆检索与主动因果推理结合：把非结构化对话历史转成结构化的因果-语义图，借反事实推理与常识补全，让 Agent 推断隐含约束、化解过去状态与当前意图间的潜在冲突。论文还提出 ActMemEval 数据集评测 Agent 在此类场景的推理能力。

INSIGHT把记忆从"存取"升级为"可推理的因果图"，让 Agent 能从历史推断隐含约束，是对话/任务型 Agent 记忆设计的有价值方向。对社区搜索与个性化的启示是：用户长期行为不应只做向量检索召回，而可结构化为因果-语义图，借反事实推理识别意图冲突（如历史偏好与当前 query 矛盾），从而给出更一致的结果。

Xiaohui Zhang, Zequn Sun, Chengyuan Yang, Yaqin Jin, Yazhong Zhang, Wei Hu

CoreMem: Riemannian Retrieval and Fisher-Guided Distillation for Long-Term Memory in Dialogue Agents

Tsinghua University

个性化对话 Agent 需要持续的长期记忆以跨多会话保持连贯，但在 8GB 显存等消费级边缘设备上部署面临显存与算力瓶颈。现有系统多用各向同性余弦相似度检索 + 启发式规则压缩，缺乏统一理论、易受高维检索的 hubness 问题与压缩时的句法碎片化困扰。论文提出 CoreMem，以信息几何统一的边-云记忆架构：Riemannian 检索用局部自适应的 Fisher-Rao 度量替代余弦匹配，有效惩罚 hub 记忆；并配 Fisher 引导的蒸馏做长期记忆压缩。

INSIGHT用 Fisher-Rao 度量替代余弦做记忆检索、以信息几何统一检索与压缩，是缓解高维记忆 hubness、并把长期记忆塞进边缘设备的有新意的思路。对检索系统的启示更直接：余弦相似度在高维易产生 hub 失真，局部自适应度量可改善召回质量；边-云分工 + 蒸馏压缩也为端侧个性化记忆提供了可落地参考。

Jiaqi Chen, Yongqin Zeng, Shaoshen Chen, Yijian Zhang, Hai-Tao Zheng, Chunxia Ma, XiuTeng Zhou

Externalizing Research Synthesis and Validation in AI Scientists through a Research Harness

AI 系统日益能自动化科研流程，但连接已有证据、生成想法、实验与最终结论的推理常隐含在模型推理内部、不可检视。论文提出 Xcientist 研究 harness，把研究综合与实验验证外化为可检视、受契约约束的过程：将文献证据、想法状态、实现计划、消融记录、修复轨迹组织成持久的研究产物，使生成的机制可被 grounding、执行、测试与修订而不丢失证据依据。论文识别出 claim drift（可运行产物不再支撑最初所声称的机制）这一自动科研失败模式，并在免训练记忆系统、图结构交通预测、多尺度物理信息神经网络三个案例上验证。

INSIGHT把 Agent 的推理与证据外化为受契约约束、可检视的持久产物，并显式监控 claim drift，是提升自动化 Agent 可靠性的有价值范式。对构建研究/分析型 Agent 的启示是：长链路 Agent 容易出现"结论与实际产物脱节"，应让每步的证据、计划、实验结果留痕可审计，用契约校验绑定"声称"与"可运行产物"，降低 silent failure。

Zijian Wang, Hanqi Li, Ziyue Yang, Zijian Hu, Shenghan Zuo
