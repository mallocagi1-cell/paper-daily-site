RankGraph-2: Lifecycle Co-Design for Billion-Node Graph Learning in Recommendation

针对十亿节点规模图检索中“图构建—表征学习—在线服务”三个环节长期被孤立优化的问题，Meta 提出 RankGraph-2，把三阶段联合设计用于相似度检索（U2U2I 与 U2I2I）。核心做法：用带流行度偏置校正的子采样把数百万亿条边压到数千亿条，用 personalized PageRank 预计算多跳邻居，并把残差量化的聚类索引共同训练进检索目标，使在线服务计算成本下降 83%。线上 A/B 带来最高 +0.96% CTR、+2.75% CVR，已支撑 20+ 个召回上线；离线召回比 GAT+Deep Graph Infomax 高 3.8 倍、比 PyTorch-BigGraph 高 2.1 倍。

KEY INSIGHT · 对业务意味着什么图召回的瓶颈往往不在单个模型，而在“构建—训练—服务”相互牵制的约束：服务侧要避免在线 KNN，就得把聚类索引训练进目标函数；训练侧利用“相似度检索可容忍预计算邻居”的特性，省掉在线图基础设施；构建侧再支持小时级刷新保证物料覆盖。对大规模 UGC 召回有直接借鉴——把索引结构当成可学习对象与表征一起优化，而不是事后再单独建索引，能在保住召回质量的同时把 serving 开销压低 83%。残差量化聚类索引共训练这一招尤其值得在 U2I 召回里试。

SAERec: Constructing Fine-grained Interpretable Intents Priors via Sparse Autoencoders for Recommendation

意图建模能提升推荐的准确性与可解释性，但现有方法多直接从用户序列里聚类或原型学习意图，依赖序列质量、需预设意图数量、缺乏语义锚定。SAERec 改用稀疏自编码器（SAE）从大模型文本 embedding 的隐空间中解耦出细粒度可解释意图，构成意图集合；再为每个用户检索相关意图作为先验，区分匹配当前兴趣的个人意图与跨用户共享的公共意图（如质量、价格），最后用多分支注意力注入两类意图信号、配合自适应融合层得到用户表征。论文称在多个公开数据集上稳定超过 SOTA 基线并能给出人类可理解的解释（摘要未给出具体数值）。

INSIGHT把 SAE 这类机制可解释性工具迁移到推荐意图建模，是个少见但合理的思路：SAE 能从 LLM 文本表征里分离出“意图相关语义”与“文本噪声”，避开传统意图聚类需预设簇数、对序列质量敏感的毛病。对社区 UGC 场景的启示是，帖子/评论这类高信息密度文本可以直接当作意图来源而不仅是辅助特征，而区分“个人意图 vs 公共意图”有助于冷启动与可解释推荐。落地需自行训练 SAE 并验证意图集合在不同语料下的稳定性。

Jiangnan Xia, Xuansheng Wu, Yu Yang, Xin Wang, Ninghao Liu

LensKit-Auto

推荐算法选型与超参调优是反复出现的难题——没有一种算法在所有数据集上都最优，同一算法在不同数据上表现差异很大。LensKit-Auto 在 LensKit 生态上构建自动化推荐系统（AutoRecSys），自动完成算法选择与超参数优化，免去人工反复试错；它把 AutoML 流程套到经典推荐算法族上，输出在给定数据集上自动挑选的最优算法+配置（摘要未给出具体对比数值）。

INSIGHT这是一篇偏工具/可复用性的工作，价值在于把 AutoML 标准化到推荐算法选型这一高频环节，对中小团队或需要在多个数据集/场景快速起基线的情况很实用。对从业者的启示：在投入复杂模型前，用 AutoRecSys 扫一遍经典算法+超参，能得到一个不弱的基线参照，避免过早把精力押在某一种架构上。局限是覆盖的多为经典协同过滤类算法，未必包含最新的生成式或序列推荐方法。

Max Breit, Anass Amezian El Idrissi, Rishikesh Giriraj Kulkarni, Luca Quade

TWICE: Modeling the Temporal Evolution of Personalized User Behavior via Event-Driven Agents

用户模拟器常把用户当作静态人设或依赖泛化的历史上下文，难以刻画个体行为随时间的演变。TWICE 提出基于 LLM 的时间锚定个性化用户模拟框架：结合结构化用户画像、围绕人生事件与行为转变组织的事件驱动记忆模块，以及“事件锚定内容规划”与“个性化风格适配”分离的两阶段流程，模拟出随时间演化的个体行为（v2 版本，摘要未列具体指标）。

INSIGHT把“用户兴趣随时间漂移”显式建模成事件驱动记忆，相比静态人设模拟器是实质改进，对长期用户建模与序列推荐评估有参考价值。两阶段拆分——先规划事件锚定的内容、再做个性化风格表达——这一设计可借鉴到生成式用户画像或行为序列合成：先定“做什么”再定“怎么表达”，能减少 LLM 直接生成时的人设漂移。该方法主要用于离线评估与数据增强，落地需验证生成行为与真实日志的分布吻合度。

Bingrui Jin, Kunyao Lan, Baihan LI, Mengyue Wu
