VikingRAG: Accurate and Token-efficient Retrieval-augmented Generation over Structured Documents

VikingRAG 针对结构化文档问答的多轮检索成本，将目录、摘要与文本块统一为可寻址对象，并按证据缺口调用检索工具。系统把历史检索路径保存为经验边，再按证据充分性决定是否升级多轮搜索。在六个数据集上，基础版仅消耗高准确率基线的11.6%–51.9% Token，增强版降至5.1%–32.5%，保持相近准确率。

AREX: Towards a Recursively Self-Improving Agent for Deep Research

BAAI

AREX 将深度研究拆成内层证据搜集与外层逐约束核验，并用自主上下文更新保存已证实事实和待解决约束。论文结合关键步骤监督与长程强化学习，提供4B和122B-A10B模型。正文消融中，自主上下文更新使 BrowseComp 单轮准确率从59.6升至71.4；完整训练设置为82.5，改用随机步骤监督后降至74.1。

INSIGHT值得迁移的是保留证据来源、已排除候选及尚未满足的查询条件，避免长对话压缩只留下流畅摘要。UGC 搜索中的多条件咨询可先采用这个状态结构，再评估是否值得训练策略模型。论文首次发表于7月、9月1日修订，本次属于补充阅读；基准准确率与社区 nDCG、CTR 没有直接换算关系。

CIVI: A Framework for Diagnosing Search Agent Failures in Civic Information

CIVI 研究搜索代理为何在公共事务问答中给出错误指引，构建覆盖跨国家、跨行政层级的评测框架。作者用来源注入消融形成 ARISE，将失败拆成四类，并比较搜索调用、无搜索回答和官方来源引用情况。评测的10个前沿搜索代理均未达到认真作答的人类基线，72.1%的失败被归为检索受限。

INSIGHT社区搜索可以借用来源注入消融：对失败问题直接提供正确帖子或权威证据，再观察答案是否恢复，从而区分找不到资料与读不懂资料。这个诊断比只看最终回答分数更利于定位召回、工具使用和证据利用问题；公共事务任务的72.1%比例不能迁移为 UGC 业务结论，仍需自建样本并联看 nDCG、CTR。

《Agent 评测白皮书》系列01：Agent 评测全览

Meituan

美团以商家经营分析 Agent 为例，梳理从冷启动到扩量、自进化的评测体系，将其概括为4个模块、3种能力、2条迭代回路和1套资产。线上异常样本经归因分别进入评测标准修订或 Agent 修复，再通过回归与线上实验验证。本文是工业方法论指南，未披露可复核的准确率或线上收益数字，证据质量据此保守评分。

INSIGHT对社区 UGC 搜索，可把复杂查询、错误引用和检索遗漏沉淀为黄金集、错题集及挑战集，并记录每次改动影响的失败类型。评测标准更新与搜索代理更新需要分别追踪，避免模型评分变高却没有用户收益。上线前检查证据与引用，扩量后结合真实查询分布、nDCG 和 CTR 校准离线判断。
