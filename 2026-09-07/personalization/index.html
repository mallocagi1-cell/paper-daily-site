UniCon: A Unified Context-Centric Modeling Paradigm for CTR Prediction

UniCon把一次展示的候选、用户和环境信息组织成上下文单元，用单元内注意力学习竞争关系，再用跨单元注意力建模兴趣变化。美团搜索广告实验中，AUC从0.8558升至0.8697；七天线上测试的CTR、RPM和收入分别提升2.07%、3.09%和2.95%。上下文压缩将计算量减少75.4%，AUC仅下降0.0001。

One Size Does Not Fit All: Adaptive Interest Representation Learning for Multi-interest Recommendation

UIUC

AirRec针对固定兴趣向量数量造成的过拟合和欠拟合，先从物品共现数据分解出原子兴趣，再依据用户历史筛选并聚合相关兴趣，动态确定表示数量。出版商登记摘要报告，三个基准上的NDCG@20和NDCG@50平均相对提升14.94%和24.73%。作者公开了共现图构建、训练和评估代码；本次未取得论文全文。

INSIGHT对社区UGC用户，浏览话题集中者与跨话题用户未必需要相同数量的兴趣向量，可将自适应兴趣表示作为个性化排序特征。先按用户历史长度和话题多样性分桶，检验nDCG及CTR是否共同改善；作者实现提供原子兴趣上限、贡献阈值和多样性损失参数，但离线平均增益不能直接换算为线上收益。

Yaokun Liu, Yifan Liu, Ruichen Yao, Zelin Li, Dong Wang

DISR: Distributional Item Representations for Sequential Recommendation

DISR把物品和序列查询表示为对角高斯分布，以冻结的Sentence-BERT初始化物品均值，并用对称KL散度替代点积评分。Amazon Beauty与Sports的5万用户实验中，NDCG@10较最强非DISR基线提升12.8%和15.6%；仅有1至3次交互的用户收益达14.5%和19.3%。全量实验只有一个随机种子，证据仍需补强。

INSIGHT社区新用户及新帖子可同时利用文本语义与交互不确定性，适合先测试低频用户的个性化候选排序。应把文本初始化和分布式评分分别消融，并按时间切分检验冷启动效果；全量Sports仅比DuoRec高2.6%，Beauty仍落后最佳结果不到0.8%，说明小规模增益不能直接外推到完整UGC流量。

Abdelilah BAJJOU, El Habib NFAOUI

04 3.15

Comparative Analysis and Unified Evaluation Framework of User Simulators for Realistic Behaviour Modelling

RMITNNSTU

论文在统一框架下比较强化学习环境与LLM用户模拟器，重点检查数据稀疏性、应用领域及正负反馈分布的影响。出版商登记摘要报告，LLM模拟器在Book Crossing等稀疏、负反馈条件下性能下降44%至58%；强化学习环境更能复现长期偏好和从众行为。该结果支持按场景选择模拟器，而非用单一模型替代真实用户。

INSIGHT社区UGC搜索若用模拟用户评估个性化排序，应单独检查低活跃用户、无点击和明确负反馈，防止合成用户过度偏好正向内容。可把模拟器用于发现排序策略问题，再用真实日志及线上CTR、nDCG核验；原文摘要未给出该退化区间对应的全部指标细节，本期仅把它作为敏感性证据。

Md Faisal Ahmed, Estrid He, Chenglong Ma, Jeffrey Chan
