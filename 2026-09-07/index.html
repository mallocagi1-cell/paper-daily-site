LLM4AIGQ: LLM-based AI Guidance Query Generation Framework for Multi Interest Mining

阿里提出面向多兴趣用户的引导查询生成框架，以单兴趣样本学习表达，再用分层奖励训练兴趣拆分，最后通过偏好优化将思考能力迁移到直接生成。天猫线上实验在10%流量时报告uCTR相对提升4.46%，扩大至40%流量后的六天验证仍提升2.53%；查询由近线生成、线上读取。

EPIC: Explicit Posterior Item Conditioning for Semantic ID Diffusion Recommendation

VinUniversityGriffith UniversityAalborg University

EPIC在 Semantic ID 扩散去噪的每一步显式比较仍可到达的完整物品，将结合用户近期行为得到的物品后验反馈至未确定的ID位置。四个Amazon数据集的16组指标均优于对照，相对次优方法提升1.2%—16.8%；仅训练39.1万参数，但T4单用户推理时间由93.0增至124.8毫秒。

INSIGHT生成候选时过早剪掉正确物品，末端重排无法补救；该方法把用户偏好证据提前注入解码过程。社区UGC若试验 Semantic ID 召回，可先验证长尾帖子是否在生成途中丢失，再比较逐步反馈与同预算末端重排；冻结主干不代表线上免费，需要单独测量候选构造和后验计算的延迟。

SelfDR: Self-Distillation from Reasoning for LLM-Based Recommendation

Tsinghua UniversityQQuan Cheng LaboratoryMeituan

SelfDR先训练能为推荐提供有效解释的推理器，再让同底座学生通过动态加权自蒸馏学习教师的推荐分布，线上直接输出物品标识。Clothing上的列表NDCG@5为0.0228，对照SOFT与COT4Rec均为0.0217；单张A800测得推理109.46毫秒，接近无推理SOFT的109.48毫秒。

INSIGHT把推理用于训练监督，可在保留直接推荐输出的同时获得额外精度。对社区帖子推荐可尝试离线生成兴趣解释、再蒸馏到短输出模型，并单独评估列表排序质量；实验是在基础排序器生成的候选集上完成，不能据此宣称全库生成召回同样有效，候选覆盖仍会限制上限。

HypRQ-VAE: Hyperbolic Item Indexing for Long-Tail-Aware Generative Recommender Systems

Virginia TechAmazonMetaGoogleDDartmouth College

HypRQ-VAE将物品文本表示映射到双曲空间，再做残差量化并生成 Semantic ID，以改善长尾物品在生成式推荐中的表示。在MovieLens、Instruments和Arts上验证，Instruments的NDCG@10从最强基线LC-Rec的0.0570升至0.0650，约提升14.0%；论文同时分析头尾物品的量化误差与曝光组成。

INSIGHT社区帖子主题和热度同样存在长尾分布，Semantic ID 的几何结构可能决定稀有兴趣能否被保留。可先保持下游推荐模型不变，仅替换量化器，分别观察头部与尾部的nDCG和曝光比例；跨几何空间的量化误差绝对值不能直接比较，且重建ID涉及索引更新与训练兼容性成本。

The Dice Roll Method: A Standardized Protocol for Repeated-Query Auditing of Large Language Model Brand Recommendations

Dice Roll Method为LLM品牌推荐建立重复查询审计流程，区分采样、措辞、运行批次及模型版本带来的波动，并结合混合模型、效应量与分组自助法。研究重分析约19万条观测，并在三个外部语料中复核；可靠性预测在39个测试单元中有37个得到复现，但固定重复次数档位并不直接迁移。

INSIGHT社区若用LLM直接推荐帖子或话题，同一输入的一次输出不足以说明模型稳定性。可以固定版本与采样参数，对重复查询做分组统计，同时跟踪候选集合重合、排序和语义差异；先用小规模试验估计本业务的方差，再决定重复次数，不应机械照搬论文的5、10或15次经验档位。
