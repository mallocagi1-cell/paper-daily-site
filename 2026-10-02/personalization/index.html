Mend the Measurement Gap: Latent User Preference Modeling for Short-Form Video Recommendation

短视频观看时长、点赞和负反馈混合了真实偏好与时长、用户活跃倾向等测量偏差。FLVM用受限基线解释混杂因素，再以消费、互动、情感三个潜变量重建异构反馈。YouTube Shorts上点赞PR-AUC从0.2522升至0.3190，14天线上实验中主要愉悦度指标提升2.67%，护栏指标中性。

When LLM-Inferred User Context Adds Value in Production Streaming Recommendation

ComcastDePaul📖 深度解读 · 10 分钟 →

论文在真实流媒体平台比较聚合画像与LLM叙事画像，以及全历史和短长期融合两种范围。样本含1万用户、约24万内容，约18%属于探索型用户。叙事画像使全体Recall@10下降30.7%，但探索型用户NDCG@10提升31.5%；全体目录覆盖率同时下降79.8%，说明收益高度依赖用户状态。

INSIGHTLLM生成画像并不应默认替代行为聚合。社区UGC搜索可按历史复访、语义变化和兴趣集中度分层，先验证探索型用户是否受益，再设计线上画像选择器。原文用测试期行为划分用户，不能直接当作服务特征；还应同时审查目录覆盖与新颖度，避免列表更丰富却整体更热门。

Milad Sabouri, Neeraj Sharma, Sardar Hamidian, Shaghayegh Agah

03 4.10

RouteRec: Behavior-Guided Sparse Routing for Sequential Recommendation

KAISTSNU

RouteRec把会话节奏、物品群聚焦、重复与跨会话延续、流行度倾向作为稀疏专家路由依据。在宏观、中观和微观三个范围先选专家组，再由当前骨干状态细化组内专家选择。六个公开数据集的18组指标中，方法12次第一、3次第二，平均名次1.61，次优基线为4.11，并提供开源代码。

INSIGHT专家分配应与可观测行为模式建立联系，而不是只增加模型容量。社区UGC搜索的个性化排序可先抽取会话节奏、重复点击和主题聚焦等信号，再评估是否有足够用户差异支撑专家分工。论文的平均名次不是CTR提升百分比，落地时仍需测量特征成本、路由稳定性及线上相关性。

Junyeong Song, Jaemin Yoo

04 3.85

Routing Between Generative and Collaborative User Profiles: A Serving-Time Gate for Controllable Novelty

ComcastDePaul

论文用仅含服务时可用特征的门控，在协同序列推荐与语义画像推荐之间选择，控制新颖度和相关性的交换。整体NDCG损失预算为5%时，细粒度扫描将12.5%用户路由至叙事画像，Novelty@10提升6.5%，强于兴趣小众度规则的4.7%。普通聚合语义画像也取得相近收益。

INSIGHT关键工程价值来自有约束的选择性路由，而非生成画像本身。社区UGC搜索可把nDCG损失预算设为显式约束，以轻量门控控制探索流量，并同时保留普通语义画像对照。应区分粗阈值扫描的6.2%与细粒度扫描的6.5%结果；这些是离线新颖度收益，不能直接等同线上CTR增长。

Milad Sabouri, Neeraj Sharma, Sardar Hamidian, Shaghayegh Agah

05 3.60

Decision-Oriented Recommendation Reranking: An Empirical Study of Jev

SMUMeta

论文在Amazon Reviews三个领域和20、50、100、200候选规模下，比较决策模型Jev、SASRec、DCNv2和Qwen重排。Books的200候选实验中，Jev的MRR为0.140，Qwen逐项重排为0.074；中位延迟分别约866毫秒和14868毫秒。传统推荐模型仍只需约1毫秒，优势取决于质量与延迟目标。

INSIGHT结构化候选选择提供了一种重排实现路线，但需先明确请求预算。社区UGC搜索可在离线高价值查询上验证决策模型，再决定是否进入低频或异步链路。原文只评估召回已命中目标的用户，且Jev走远程API、其他模型本地运行，因此不能把实验延迟差异解释为硬件归一化效率优势。

Hanjia Lyu, Yinglong Xia

06 3.55

Intent-enhanced sequential recommendation via multi-view contrastive learning over stabilized essential intents

IeSRec针对随机增强破坏序列语义的问题，设计三种意图增强策略和三类对比目标，与下一物品预测联合训练。实验覆盖六个数据集，Yelp、Beauty、Sports和Toys上的指标提升范围为2.2%至11.42%。五个随机种子下的配对检验p值为0.004至0.045；收益随领域和历史长度变化。

INSIGHT行为增强需保留稳定意图，而不是机械裁剪或替换点击。社区UGC搜索可将会话主题片段用作对比视图，并对低置信行为降低权重；同时检查旧兴趣被过度强化的风险。原文在ML-1M中观察到长历史与不均匀行为会产生负面语义，说明音乐数据上的收益不能直接推广到所有社区场景。

Zhou, Wei, Guo, Feipeng, Ji, Shaobo
