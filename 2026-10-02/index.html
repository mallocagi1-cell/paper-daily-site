Generative End-to-end Ad Retrieval at Douyin

针对广告生成式检索中的码本坍缩和物品碰撞，GEAR联合训练分词器、生成器与轻量重排器。BasisVQ以正交基参数化码本，前缀感知量化增强区分能力。抖音全量部署的ADSS和ADVV分别提升0.563%和0.658%，冷启动广告激活率相对提升1.46%。

Learning Multiresolution Relevance for Hierarchical Generative Retrieval

MeituanBeihang University

RARS把文档级相关性聚合为 Semantic ID 各层的一致条件分布，显式监督同一前缀下相关性的分支分配，避免完整ID单目标训练丢失多相关文档结构。在ESCI-US的四层RQ-VAE配置下，Recall@100从38.24提升到39.62，NDCG@10从12.00提升到13.00，均为五种子均值。

INSIGHT社区短文本搜索常有多个相关帖子共享粗主题而在细节上分叉，层级软监督可减少早期前缀选择过度确定的问题。应从同一批多级相关性标注构造所有层的目标，并固定SID和解码预算进行对照。论文发现标注稀疏会制造虚假的确定性，因此先检查多正例覆盖，再比较nDCG和召回。

Weihao Shen, Wei Chen, Fuwei Zhang, Guojun Liu, Qingsong Hua, Wei Lin, Fuzhen Zhuang

Exploring Forum Post Retrieval with Generative Modeling

MetaWilliam & Mary

Facebook Forum在自身行为稀疏时，复用Facebook Groups训练行为和Feed Semantic ID，用3B语言模型直接生成帖子ID。固定训练预算下，三层ID的HR@10为0.0667，四层为0.0303；文本与ID对齐加动作描述使NDCG@10达到0.0420。更大模型和1000步GRPO均未带来收益。

INSIGHT与社区UGC业务最接近的启示是优先复用成熟内容侧语义空间，并把点赞等动作写入历史提示。三层ID优势部分来自更高碰撞率，必须接桶内重排后再比较最终帖子命中。短历史与长历史的评测用户集合不同，不能把结果解读为长历史无用；先统一用户集合、训练预算及搜索nDCG口径。

Yang Li, Yaguang Liu, Heng Liu, Shengbo Guo, Samson Komo, Jane Kou, Yulian Zhou, Gang Yang 等 17 人

When the Label Ignores the Request: Auditing Policy-Selected Targets in Synthetic Conversational Music Recommendation

论文审计LLM合成对话推荐中的标签与真实请求冲突：TalkPlay开发集82个明确歌曲请求中，41个官方标签指向其他歌曲。仅对约1.5%的训练轮次补充请求满足目标，冲突切片nDCG@20从0.5231升至0.8018，相对提升53.3%，全量官方指标从0.1908升至0.1914。

INSIGHT社区搜索用LLM生成训练样本时，应同时保留用户明确约束和生成策略给出的目标，不把后者自动当成真值。可对帖子标题、作者或实体的精确查询建立可自动验证的切片，再增加小比例纠正监督。53.3%仅对应冲突切片，不能外推为全量收益；CTR和nDCG需分别检查精确满足与主题推荐。

05 4.15

Residual Trajectory Distillation for Generative Retrieval

ResTD将冻结残差量化索引器视为过程教师，把硬 Semantic ID 丢弃的码字偏好与多步残差轨迹蒸馏到检索训练。ESCI-US在相同1200次更新预算下，Base-FT的Recall@100为37.60、NDCG@10为11.25，四步ResTD分别达到39.58和12.99；打乱教师轨迹后收益基本消失。

INSIGHT对社区搜索，码本构建过程不必只输出最终离散标签，还可保留候选码字概率作为额外监督。先固定索引器、模型和解码，再比较单层、两步及四步蒸馏，检验提升是否源于正确轨迹。该方法主要增加训练侧信息，部署仍需评估ID碰撞处理；离线商品检索增益不能直接替代UGC线上验证。

Weihao Shen, Wei Chen, Fuwei Zhang, Guojun Liu, Qingsong Hua, Wei Lin, Fuzhen Zhuang

Can Generative Retrievers Learn Semantic IDs Without Forgetting How to Speak?

BBraveUniversity of Glasgow

SpeakGR解决语言模型学习文档 Semantic ID 后自然语言能力退化的问题，在SID监督之外，对学生生成前缀施加冻结原模型的前向KL蒸馏，并可自适应调节保护强度。在三个模型上，MS MARCO的WikiText-2前向KL相对纯SFT下降81.3%至93.8%，同时保持有效检索。

INSIGHT社区搜索若同一模型既输出帖子ID又生成解释，应同步监控语言分布漂移与召回质量。保护损失只在原文本词表归一化，避免新增SID token 干扰语言蒸馏。WikiText分布恢复不等于推理、代码或所有对话能力都被保留，需要补充业务解释质量和用户指令测试，并核算冻结教师带来的训练成本。

Junchen Fu, Kleomenis Katevas, Vandana Rajan, Sofía Celi, Hamed Haddadi

FineSID: Scalable and Efficient Semantic Identifier Learning for Generative Recommendation

FineSID通过全局与局部量化和语义一致性约束，将梯度分配到整个码本，缓解Top-1硬分配导致的大量码字欠训练及ID碰撞。在Instrument数据上Recall@10从CAR的0.0624升至0.0703，Game数据上从0.0947升至0.1031；实验还检验初始化、码本利用率和训练效率。

INSIGHT社区内容规模扩大时，应把码本利用率、碰撞率与搜索相关性一起监控，不能只追求重构误差下降。可先在固定生成器下替换SID学习模块，核验软梯度是否提高长尾内容的可区分性。公开商品推荐结果与UGC检索仍有场景差异，需统一候选集、碰撞消歧和排序预算再判断可迁移收益。

Song-Li Wu, Weinan Gan, Zhaocheng Du, Xianquan Wang, Jingyi Wang

Textual User Taste: Natural-Language User Context for Foundation-Model Recommender System at Scale

Spotify

Spotify把收听历史、内容元数据和用户反馈生成结构化自然语言偏好，部署到数百万用户。文本与行为向量联合使用时，未来歌曲预测MRR从0.956升至0.962；搜索排序相对无上下文的NDCG@7提升2.2%，而单独行为上下文提升1.7%。画像还支持正向语言调节，但否定指令和短期适应存在困难。

INSIGHT社区搜索可将偏好文本作为可解释的个性化上下文，与行为向量联合输入，先验证主题意图和历史兴趣是否互补。2.2%的提升以无上下文为基线，不能当作对行为向量的增益。应分别测试无画像、文本、行为及融合四组，并审计用户纠正、隐私过滤和过期兴趣对nDCG与CTR的影响。

AdaM-Rec: Adaptive Modality Routing for Multimodal Recommendation

AlibabaUniversity of QueenslandSoutheast UniversityAAdelaide University

AdaM-Rec以LLM生成结构化物品与用户表示，根据请求动态决定依赖文本还是多模态证据，再执行推荐，减少无关视觉信息干扰。Amazon Beauty查询推荐中HR@20达到0.1711、NDCG@20达到0.0979，对照TAIRA分别为0.1497和0.0798；顺序推荐另采用1000随机负例协议。

INSIGHT社区图文帖子中，文字意图与视觉意图可先由轻量路由区分，再调节多模态证据权重。需要分别评估视觉强需求、功能性文本需求和模态缺失用户，避免静态融合平均掉请求差异。论文的查询与偏好推荐评测协议不同，离线数值不能直接相互比较，线上还需测额外LLM调用延迟与搜索CTR。

Honghao Fu, Jiacheng Chen, Manxi Lin, Junjun Zheng, Xiangheng Kong, Yiwei Wang, Xin Yu, Miao Xu 等 10 人

KUAISHOU Explorer LLM-Rec Challenge 2026: Reasoning Generative Recommendation

Kuaishou

快手LLM-Rec挑战将物品理解、用户理解、推荐和通识能力放入统一 Semantic ID 与自然语言空间，以多粒度对齐预训练和分阶段后训练研究推理推荐。公开历史统计覆盖50万用户，其中短视频行为为409416641条、平均长度818.8；短视频 Semantic ID 共享比例为20.84%，说明碰撞必须进入评测。

INSIGHT社区业务可借鉴统一评测设计，将兴趣解释质量与最终帖子命中分开度量，并避免让推理文本直接泄漏目标。历史跨度、动作含义和内容语义对齐比单纯延长思维链更值得先验证。挑战报告的资源统计不等于线上增益，推理是否改善nDCG和CTR还需匹配模型预算与数据量的消融实验。
