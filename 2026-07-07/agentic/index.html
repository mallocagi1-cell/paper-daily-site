S1-DeepResearch: Beyond Search, Toward Real-World Long-Horizon Research Agents

该论文把 Deep Research 从“多轮搜索问答”推进到真实长周期研究任务，关注规划、证据收集、文件理解、知识综合和报告生成。它提出统一轨迹构造范式，把封闭式 QA 与开放式研究任务结合，用于训练更接近研究助手的长程智能体。摘要未披露最终 benchmark 数字，但任务覆盖从检索到结构化报告的完整链路。

千亿级 AI 搜索的效能实战：从混合检索到 Agentic RAG 的三年实战

AlibabaElastic

这篇工程实践围绕千亿级 AI 搜索，讨论关键词、向量、稀疏检索融合，冷热分层、硬件降级和自研 FalconSeek 引擎等效能问题，并把 Agentic RAG 作为三年演进方向。文章强调结构化知识图谱与智能体自主推理，目标是让企业级 AI 搜索从可用走向自进化。摘要给出“千亿级”规模背景，但公开指标有限。

INSIGHT它补足了论文候选缺少的产业落地视角：Agentic Search 不是单个 Agent prompt，而是检索底座、成本治理和多源知识组织的系统工程。对 UGC 搜索，优先级应是混合召回与知识结构化先稳定，再逐步开放 Agent 决策权，否则多轮推理会放大底层召回噪声。

DEEPMED Search: An Open-Source Agentic Platform for Medical Deep Research with Introspective Verification

DEEPMED Search 是面向医疗深度研究的开源 agentic 平台，覆盖 PubMed、Web 搜索和私有图谱知识库。系统用 source-adaptive router 将子查询分发到不同来源，再用因果一致的多 Agent debate 做 introspective verification，减少长尾医学问题中的 reasoning drift。论文没有在摘要中给出线上指标，但明确给出多源路由与验证模块设计。

INSIGHT对搜索推荐实践最有价值的是“按信息密度路由数据源”与“生成前验证证据”两层设计。社区搜索可以把帖子库、百科/站外网页、用户关系图分成不同源，由 Agent 按问题类型调度；高风险回答则引入多 Agent 交叉验证，避免把弱相关召回直接写进结论。

Maolin Liu, Fanyu Xu, Ruoqing Xu, Jiahang Zhang, Hao Wang, Rui Wang

04 4.00

Hierarchical Experimentalist Agents

HExA 面向传统检索或固定训练数据无法覆盖的新领域问题，让 Agent 通过主动实验而不只是搜索来获取证据。框架迭代设计实验、沉淀可复用技能库，并把实验结果纳入回答或行动决策；论文强调它是 training-free，能接入黑盒模型。该方向适合处理搜索结果稀缺、需要外部工具验证的复杂查询。

INSIGHT它提示 Agent 搜索不应局限于“查资料”，还可以把工具调用视为可规划的实验过程。对于 UGC 搜索，可借鉴其技能库思想：把可重复的验证动作（相似帖聚合、作者可信度检查、时间线核验）沉淀为工具技能，让复杂 query 的处理路径逐步稳定。

Abhranil Chandra, Sankaran Vaidyanathan, Utsav Dhanuka, Varun Gandhi, Scott Niekum

05 3.90

TraceLab: Characterizing Coding Agent Workloads for LLM Serving

TraceLab 发布真实 coding-agent 工作负载轨迹，用于分析 Agentic LLM serving。数据包含约 4,300 个会话、350,000 个 LLM steps 和 430,000 次工具调用，覆盖 Claude Code 与 Codex 的日常使用；分析显示 workload 具有长自治循环、长上下文短输出、工具调用重尾分布和较高但不完美的 prefix cache 命中率。

INSIGHT虽然它不直接优化搜索相关性，但对部署搜索 Agent 很关键：真实 Agent 流量不是普通聊天流量，prefill、工具延迟和 cache 失效会主导成本。若要把 Agentic Search 接入生产，应单独采集工具调用、上下文长度、cache 命中和人工等待间隔，而不是沿用普通问答的 serving 假设。

Kan Zhu, Mathew Jacob, Chenxi Ma, Yi Pan, Stephanie Wang, Arvind Krishnamurthy, Baris Kasikci

06 3.80

ConCise: Training-Free Conclusion-Chain State Compression for Cost-Efficient Multi-Step RAG Services

ConCise 针对多步 RAG 服务的成本问题：随着检索-推理轮次增加，历史文档和推理轨迹会近似按 O(N^2) 膨胀，并持续引入噪声。它提出无需训练的 conclusion-chain 状态压缩，只保留对后续推理有用的中间结论，从而降低 API 服务中的上下文成本和干扰。摘要强调问题规模和复杂度增长形式，但未披露具体节省比例。

INSIGHT这篇更偏工程可落地：在 Agentic RAG 中，状态压缩往往比换更强模型更直接影响延迟和成本。对 UGC 搜索的多轮问答，可以把每轮召回内容压缩为“结论链+证据引用”，而不是把所有帖子片段反复塞进上下文，降低长对话里的噪声累积。

Kuan Yan, Zhiqing Tang, Tian Wang, Weijia Jia

阿里云携手 Elastic 定义 Agent 时代搜索新范式，解锁 Search AI 核心生产力

AlibabaElastic

Forensic Trajectory Signatures for Agent Memory Poisoning Detection

这篇研究 Agent 长期记忆投毒检测，发现成功攻击常出现 memory_recall_fact 到 email_send_email 的轨迹转移，而正常会话中很少出现。仅用该规则即可达到 AUC 0.9563，使用 19 个轨迹特征的 Random Forest 达到 AUC 0.9904，BCa 95% 置信区间为 [0.987, 0.993]。

INSIGHT对 Agent 搜索/RAG 的启发是：安全检测可以从内容审核扩展到轨迹特征。社区搜索若引入长期记忆或用户画像，需要记录“记忆检索-工具执行-外发动作”的事件链；对高风险转移设规则或轻量模型，比只检查生成文本更容易发现越权行为。

Reinforcement Learning for Tool-Calling Agents in Fast Healthcare Interoperability Resources (FHIR)

该论文把 FHIR 电子健康记录视为资源图，要求 Agent 在多类资源之间进行多步推理、过滤和聚合。作者用执行落地奖励对多轮 CodeAct 工具调用 Agent 做强化学习后训练，在 FHIR-AgentBench 上用 Qwen3-8B 将答案正确率从 o4-mini prompt baseline 的 50% 提升到 77%。

INSIGHT它的价值在于把工具调用的“正确执行”纳入奖励，而不是只看最终文本。对搜索系统中的工具型 Agent，可把查询改写、过滤器选择、召回源选择、排序解释等步骤都做成可执行动作，并通过日志回放或规则校验给中间动作提供奖励信号。

用 LangGraph 改造单一 RAG 架构：让 Agent 决定调用向量、图遍历还是网络搜索

Alibaba

这篇中文实践介绍用 LangGraph 改造单一 RAG 架构，让 Agent 根据问题自动选择向量搜索、图遍历或网络搜索。方案用状态机组织记忆、决策、重试与幻觉校验，面向政策查询、关系分析、实时资讯等场景，提供了从固定流水线转向可控 Agentic RAG 的工程范式。文章偏实践教程，缺少离线/线上指标。

INSIGHT它适合作为快速原型参考：用图状态显式管理每一步检索和校验，比把全部逻辑藏在长 prompt 中更可维护。对搜索团队，可先在低风险复杂问答场景试点“路由节点-检索节点-验证节点”三段式图编排，再逐步接入更多工具。
