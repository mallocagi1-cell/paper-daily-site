As It Was: Aligning LLM Search Evaluation with Historical User Preferences

论文关注 LLM-as-judge 在搜索评测中的线上一致性问题：只看语义相关性时，离线评测常常无法预测真实用户偏好。作者在音乐搜索场景中构造行为接地的 QRI 卡片，把历史相似查询、结果和交互信号注入评测提示；在 904 个查询的线上 A/B 对照中，行为接地评测与真实赢家方向一致率从 30.6% 提升到 36.8%，且相对纯提示评测达到统计显著。

Diffusion-GR2: Diffusion Generative Reasoning Re-ranker

MetaUUNC

论文提出 Diffusion-GR2，把自回归生成式推理重排器转换为 block-diffusion 解码器，以降低长推理链逐 token 解码的延迟。方法包含三步：conversion fine-tuning 学会输出合法候选排列，on-policy distillation 用模型自身轨迹接受 AR teacher 的逐 token 监督，最后用重排 reward 做强化学习；作者在 Amazon Beauty 上报告接近 AR-GR2 的重排精度，同时通过块内并行去噪提升解码吞吐。

INSIGHT这篇更偏生成式重排，但对搜索重排有一个清晰启示：LLM 重排真正贵的不是输出最终列表，而是生成中间推理。若社区搜索要在 Top-K 帖子上使用推理型重排，可以借鉴它的“保留候选排列约束 + 压缩推理解码成本”思路；不过当前证据集中在单一推荐数据集，落地前需要先在搜索 nDCG、CTR proxy 和延迟预算上复验。

Zhuoxuan Zhang, Kangqi Ni, Yuhang Chen, Mingfu Liang, Xiaohan Wei, Yunchen Pu, Fei Tian, Chonglin Su...

AGE: Adaptive-masking for Graph Embedding in Graph Retrieval-Augmented Generation

论文研究 Graph RAG 中检索子图表示被噪声节点稀释的问题，提出 AGE，用强化学习引导的 adaptive masking 与 mask-based self-supervised learning 学习关键节点和结构依赖。作者将 AGE 接入 G-Retriever/AMAR，并在 WebQSP、ExplaGraphs 等任务上做架构消融；附录显示 Graph Transformer 在 WebQSP/ExplaGraphs 上优于 GCN、GAT，核心组件组合的 Hit@1 也优于单独 graph encoder 或 aggregator。

INSIGHT对社区搜索的直接相关性不如 query understanding 或排序论文，但它提示了一个可迁移方向：当帖子、话题、用户和实体形成图结构时，召回阶段不能只按文本相似度拿邻居子图，否则噪声边和弱相关节点会干扰 LLM 理解。可以把 AGE 类的结构自监督用于话题图、问答引用图或商品知识图的 RAG 召回，先在长尾 query 和多跳意图场景做离线验证。

Bao Long Nguyen Huu, Atsushi Hashimoto
