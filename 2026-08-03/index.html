LLM-Based Generative Retrieval for Snapchat Content Recommendation

论文面向 Snapchat 短视频推荐，构建已上线的 LLM 生成式召回系统 SnapLGR：先用多模态表征与 PPR 共参与对比学习生成低碰撞 SID，再通过持续预训练完成新词表语义落地，并以 SFT 学习用户行为序列。7 天线上 A/B 相对 TIGER 式基线带来观看时长 +0.37%、总停留时长 +0.09%，离线 Recall@32 提升 2.40 倍。

Guess Where You Go: Generative Next Point-of-Interest Recommendation in Amap

Alibaba

高德 Gwhere 将生成式推荐落到下一 POI 场景：对文本、图像、空间和协同信号做对比式残差量化，得到更可区分的 SID，再以 Qwen2.5 继续预训练、SFT 与 EAKTO 强化学习完成时空偏好对齐。7B 版本在高德数据上较级联排序 Acc@1 相对提升 14.8%，长期线上 A/B 的 P-CTR 与 U-CTR 分别提升 5.83% 和 6.20%。

INSIGHT工业生成式推荐应把 SID 当作业务语义接口，而非仅靠重构损失得到的压缩编码；对比学习可同时约束多模态可分性，偏好优化再把距离、熟悉度和曝光反馈写入生成策略。对社区搜推可借鉴“多模态内容编码—行为序列建模—隐式反馈对齐”的三级设计，但需针对帖子时效性与内容安全重做奖励。

EvoReason: Self-Evolving Reasoning Primitive-Guided On-Policy Distillation for Latent Reasoning in Generative Recommendation

KuaishouShenzhen University

EvoReason 面向生成式推荐的低时延推理，把冗长且不稳定的显式思维链提炼为可复用“推理原语”，再让教师依据学生的 on-policy 轨迹持续修正监督，并通过 token 蒸馏与 KV 状态对齐写入潜在推理空间。Beauty、Sports 和工业数据上，Recall@10 相对最强基线分别提升 10.8%、11.1% 和 12.3%，NDCG 指标也全面领先。

INSIGHT相比直接蒸馏原始 CoT，先抽取结构化推理原语能过滤表达冗余，并让教师监督随学生分布演进，减轻离策略偏差；潜在 KV 对齐则保留推理能力而不输出长链。该方法适合延迟敏感的生成式排序，但训练依赖 QwQ-32B 教师和 8 张 A800，业务试点宜先验证少量高价值意图是否值得这套复杂度。

Zhuang Zhuang, Zhipeng Wei, Rongfeng Guo, Shijie Li, Peng Zhao, Jie Chen, Fei Pan

Think2Go: Generative Next POI Recommendation with LLM Reasoning

DDalian University of TechnologyWuhan UniversityA*STARSCUT

Think2Go 用统一输出结构同时承载 SFT 记忆与 RL 推理，使 LLM 在生成下一 POI 的 SID 时进行测试时扩展；其优势估计结合核密度得到的时空认知不确定性与奖励归一化，针对难样本增加探索并抑制熵坍塌。三个公开数据集上，Acc@1 较最强 LLM 基线 GNPR 分别提升 6.33%、5.78% 和 7.49%。

INSIGHT论文说明推荐推理的价值主要来自按样本难度分配探索预算，而不是无差别延长 CoT；将 SFT 的确定性答案与 RL 的推理段放在同一序列，也减少了记忆和探索之间的训练割裂。迁移到 UGC 搜索时，可用查询与历史行为的一致性估计不确定性，只对陌生、稀疏或歧义 query 启动更深推理以控制成本。

Zhuang Zhuang, Shanshan Feng, Hangwei Qian, Mingqi Yang, Heng Qi, Yanming Shen, Baocai Yin
