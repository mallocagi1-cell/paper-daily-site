TransX: Scaling Transformer-based Recommendation via Behavioral and Serving Stream Crossings

针对工业推荐把长期行为与实时服务事件粗暴拼成单一序列所带来的因果混淆和高成本，TransX 用编码器—解码器解耦两类数据，并以跨注意力完成动作转导。LinkedIn 大规模 A/B 测试中 CTR 提升 6.0%、转化提升 4.4%，增量编码与逐请求 KV 缓存将在线计算量降低约 80%。

Don't Contrast the Impossible: Region-Constrained Batching for Contrastive User Modeling on a Local Community Platform

Karrot📖 深度解读 · 11 分钟 →

论文指出本地社区推荐中的随机批内负样本常在地理上根本不可曝光，因而稀释用户表征学习；RCBS 将同区域用户组成批次，引入可触达的更难负样本。细粒度分区使不可能负样本占比从 98% 降至 30%，Recall@10 从 0.100 升至 0.149；线上点击量、日活观看者和广告 CTR 分别提升 10.0%、1.91% 和 7.46%。

INSIGHT这项工作与社区 UGC 场景高度同构：负样本首先要满足地域、权限、库存和分发规则等“可曝光约束”，再谈难例挖掘。RCBS 仅改批采样即可复用现有两塔、排序和广告模型；落地时应同步监控可行负样本比例，避免离线随机评测被大量容易但无效的负例虚高。

Seungho Han, Byeongchang Kim, Jin Yu

CCFormer: Efficient Cross-Field Interaction and Hierarchical Sequence Compression for Industrial Recommendation at Tencent

Tencent

CCFormer 面向长序列推荐的算力与细粒度交互矛盾，将字段分离交叉注意力、长序列子空间 token mixing 和逐级扩大感受野的层次压缩统一到一个骨干网络。腾讯视频推荐与广告排序 A/B 测试分别获得 3.57% CTR、1.71% 广告收入提升，训练速度相对 HSTU 提高 2.21 倍，并已承载主流量。

INSIGHT比起直接扩大自注意力窗口，先按用户、物品、上下文等字段控制交互，再用层次压缩保留全序列感受野，更符合线上排序的时延预算。社区场景可先在高价值行为序列上验证字段交叉与压缩比例，用训练吞吐、CTR 和收入三类指标共同决定是否替换现有 Transformer 骨干。

Yunlong Wang, Huizhe Zhang, Haonan Hu, Yudong Li, Bing Wen, Jianchao Tu, Chengxiang Zhuo, Zang Li

GALA: Generative Aligned Learning for Adaptive Multimodal Representation in the Taobao Shangou Recommender System

AlibabaTsinghua

GALA 解决图文语义预训练与行为排序目标脱节问题：先用搜索日志构造 query-image-text 三元组，再以转化奖励和 GRPO 做生成式对齐，最后通过自适应门控及混合损失融合多模态与 ID 表征。系统服务淘宝闪购超过 2 亿日活，离线 AUC 提升 0.12/0.20，线上订单量提升 0.55%。

INSIGHT多模态编码器不应只追求内容相似度，还需用点击、转化等下游反馈做中间对齐，否则长期训练会被强势 ID 特征淹没。对 UGC 图文搜索推荐，可复用“三元组预训练—业务奖励对齐—门控融合”路径，并将门控权重漂移作为多模态信号是否失效的在线诊断量。

DADF: A Distribution-Aware Debiasing Framework for Watch-Time Regression in Recommender Systems

Kuaishou📖 深度解读 · 9 分钟 →

DADF 针对观看时长回归中短样本高估、长样本低估的局部均值收缩，在冻结的一阶段模型上增加乘性残差校正，并按视频时长路由专家、引入互动任务表征。两套公开数据与 7 个骨干上平均 MAE 降低 4.33%、XAUC 提升 4.01%；生产 MAE 降低 12.57%，全量排序 A/B 的设备时长提升 0.649%。

INSIGHT成熟排序模型不一定需要整体重训；若误差在标签区间或内容时长上呈稳定结构，可用保持接口不变的二阶段校正器低风险修复。社区内容可把停留时长、完读、点赞等多任务表征作为残差特征，同时严格区分“可预测偏差”与不可约噪声，避免简单按时长分桶造成过校正。

Yiqing Yang, Xinlong Zhao, Zhao Liu, Xiao Lv, Ruiming Tang, Han Li, Kun Gai

PaletteID: Prototype-Composed Semantic Identifiers for Multimodal CTR Prediction

HUSTCCCNU

PaletteID 用真实代表物品组成“语义调色板”，通过兼顾局部密度和全局多样性的 SQ-DPP 选原型，再为目标物品检索并聚合多个相近原型，避免残差 SID 的硬量化与前缀依赖。在 TAOBAO-MM 上 DCNv2 AUC 从 0.6275 升至 0.6314，长尾 40% 物品提升 0.0128；KuaiRec 上 RankMixer GAUC 达 0.7514。

INSIGHT长尾物品不必被压成单一路径离散码；由多个可解释原型软组合，能让稀疏行为物品共享相邻内容的 CTR 知识。UGC 场景可把帖子、作者和话题原型离线入库，线上只做原型 embedding 查表与聚合；重点评估尾部 AUC，而非仅看被头部流量主导的整体指标。

Huanyu Liu, Baining Chen, Hui Liu, Zengyang Li, Ziyi Huang

UxSID: Semantic-Aware User Interests Modeling for Ultra-Long Sequence

Kuaishou📖 深度解读 · 10 分钟 →

UxSID 在逐候选检索与完全无目标压缩之间引入“语义组共享兴趣记忆”：先压缩超长行为，再用候选语义 ID 做分层探测，从全局行为和兴趣锚中提取目标相关偏好。模型支持最长 1 万次交互且保持常数时间在线推理，快手广告大规模 A/B 测试带来 0.337% 收入提升。

INSIGHT当用户历史过长时，可让同一语义组候选共享压缩记忆，既避免为每个候选重搜 1 万条行为，也比单个静态用户向量保留更多目标相关性。对社区推荐，可用内容语义 ID 连接长期主题兴趣与当前帖子，并以线上线下一致的固定长度表示控制延迟。

CaIRec: Calibrated Modality Imputation for Incomplete Multimodal Recommendation

SUSTechNUSSMU

CaIRec 面向图片或文本缺失的多模态推荐，先以 SIC 从共享潜变量补全模态并校准跨模态结构，再用 PRC 的伪缺失对齐和补全感知物品图适配个性化排序。在 50% 物品缺失一种模态时，三套 Amazon 数据的 12 个指标平均领先最强基线 3.77%；去掉 PRC 后 Clothing Recall@20 下降 10.44%。

INSIGHT补齐内容表示只是第一步，恢复后的图文关系还必须接受排序监督并重建可传播偏好的邻接结构。社区 UGC 中可用“人为遮蔽已有模态”生成成对训练信号，分别监控完整与缺失内容的 nDCG；若增益只来自完整物品，应警惕补全模块没有真正解决冷启动。

Ruiyu Liu, Xiaohao Liu, Miaomiao Cai, Yunshan Ma, See-Kiong Ng

训练推荐模型 - Azure Databricks

MicrosoftDatabricks

Microsoft Learn 给出 Azure Databricks 上两类可执行推荐范式：双塔负责从数百万物品中生成数百到数千候选，DLRM/DeepFM 处理稠密与稀疏特征做精排。示例基于 Runtime 14.3 LTS ML，使用 TorchDistributor 多 GPU 编排、TorchRec 扩展嵌入表、MLflow 跟踪参数与检查点。

INSIGHT这份实践适合作为工程基线而非算法 SOTA：召回与精排应按模型规模、特征类型和候选数量分工，避免用同一网络覆盖全漏斗。社区系统可先复刻双塔加向量索引，再逐步接入 DLRM；多点击、收藏、购买目标并训时要显式监控目标冲突导致的 embedding 质量下降。
