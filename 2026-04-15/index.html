Learning from Emptiness: De-biasing Listwise Rerankers with Content-Agnostic Probability Calibration

生成式列表重排序虽能利用全局上下文提升检索效果，但存在严重的位置偏差问题。本文提出 CapCal 框架，通过内容无关的占位符估计偏差分布，再利用熵自适应对比机制修正输出 logit，实现无需训练的位置偏差消除。该方法在 10 个基准上的实验表明，在保持单次推理效率的前提下，显著优于其他免训练方法，对轻量级模型提升尤为明显。

SHE: Stepwise Hybrid Examination Reinforcement Learning Framework for E-commerce Search Relevance

Alibaba

针对电商搜索中 LLM 相关性预测面临的训练困难（SFT/DPO 长尾泛化差、传统 RLVR 反馈稀疏），提出分步混合检验 RL 框架 SHE。核心是 SRPO（分步奖励策略优化），结合生成式奖励模型与人工标注验证器提供细粒度的步骤级信号，配合多样化数据过滤保持策略熵和多阶段课程学习。在真实电商搜索基准上，SHE 在推理质量和相关性预测精度上全面超越 SFT、DPO、GRPO 等基线。

INSIGHTSHE 将 LLM 搜索相关性从粗粒度的序列级优化推进到细粒度的步骤级奖励，解决了传统 RL 方法在中间推理错误上无法纠偏的痛点。对搜索系统而言，其混合奖励机制（生成式 + 人工验证）为平衡标注成本和模型质量提供了可行路径，课程学习策略则有效缓解了 RL 训练的不稳定性。这一框架对 UGC 短文本搜索中的长尾 query 相关性判断尤为适用。

Differentiable Semantic ID for Generative Recommendation

GoogleLeiden UniversityGGlasgow University

当前生成式推荐中 Semantic ID (SID) 的学习与推荐模型训练是割裂的：SID 优化内容重建目标，推荐模型在静态索引上训练，导致目标不一致。本文提出 DIGER，通过引入 Gumbel 噪声鼓励早期编码探索并缓解 codebook 坍塌，两种不确定性衰减策略实现从探索到利用的平滑过渡，使 SID 和推荐目标端到端可微分联合优化。在多个公开数据集上验证了一致性提升。

INSIGHTDIGER 解决了生成式推荐中「索引-推荐目标不匹配」的根本问题，核心洞察是 SID 不应被视为预训练后固定的表征，而应与推荐目标联合优化。Gumbel 噪声探索机制借鉴了离散变分推断的思路，为 codebook 学习提供了更稳健的梯度信号。该思路可推广到搜索系统中的文档 ID 学习，为生成式检索的索引优化提供新范式。

Retrieval as Generation: A Unified Framework with Self-Triggered Information Planning

PKU

本文重新审视 RAG 范式，将检索控制直接嵌入生成过程。提出 GRIP 框架，模型在单个自回归轨迹中自主决定何时检索、如何重构查询、何时终止检索，无需外部控制器或分类器。通过在结构化数据集上进行监督训练，覆盖多种查询类型，GRIP 以更少的参数实现了与 GPT-4o 等强基线的竞争性能。

INSIGHTGRIP 的创新在于将「是否检索」的决策从外部管道转移为 token 级别的生成决策，实现了检索与生成的深度一体化。这种范式消除了传统 RAG 中检索模块与生成模块之间的信息断裂，对搜索系统有直接启示：可以将查询改写、多轮检索、结果聚合等步骤统一到一个自回归模型中，简化系统架构的同时提升端到端效果。

Bo Li, Mingda Wang, Gexiang Fang, Shikun Zhang, Wei Ye

R3-VAE: Reference Vector-Guided Rating Residual Quantization VAE for Generative Recommendation

生成式推荐中 Semantic ID 的向量量化面临训练不稳定和质量评估困难两大挑战。本文提出 R3-VAE，包含三个核心组件：基于参考向量的语义锚定、通过点积评分稳定训练梯度传播、以及两种评估指标作为正则化目标。在 6 个基准上的实验显示，Amazon 数据集上 Recall@10 提升 14.2%、NDCG@10 提升 15.5%，真实平台上 MRR 提升 1.62% 且冷启动场景表现优异。

INSIGHTR3-VAE 通过引入参考向量作为语义锚点，为 SID 的向量量化过程提供了稳定的训练信号，有效解决了 straight-through estimator 梯度不足的问题。点积评分替代传统距离度量的设计简洁高效。14.2% 的 Recall 提升和线上 MRR 增益表明该方法已具备工业部署价值，特别是在冷启动场景中，参考向量可为新 item 提供语义先验。

Qiang Wan, Ze Yang, Dawei Yang, Ying Fan, Xin Yan, Siyang Liu

HARPO: Hierarchical Agentic Reasoning for User-Aligned Conversational Recommendation

IIT Patna

对话式推荐系统通常优化检索准确率等代理指标，而非推荐质量本身。HARPO 将对话推荐重构为结构化决策过程，引入层次化偏好学习（将推荐质量分解为相关性、多样性、预测满意度、参与度四个维度）、基于学习价值网络的审慎树搜索推理、以及虚拟工具操作实现跨领域可迁移推理。在 ReDial、INSPIRED、MUSE 数据集上全面优于强基线。

INSIGHTHARPO 的核心贡献在于将推荐质量显式建模为多维目标，并通过价值网络引导的树搜索在推理路径空间中优化，而非仅优化生成流畅度。虚拟工具操作的设计使推理逻辑与具体领域解耦，具有良好的迁移性。对搜索推荐系统而言，这种多维质量分解思路可用于对话式搜索场景中平衡相关性、多样性和用户满意度。

Subham Raj, Aman Vaibhav Jha, Mayank Anand, Sriparna Saha

Self-Distilled Reinforcement Learning for Co-Evolving Agentic Recommender Systems

Chongqing UniversityUniversity of Queensland

LLM 驱动的智能体推荐系统（ARS）将推荐建模为推荐智能体与用户智能体之间的多轮交互。现有 ARS 主要采用 Reflexion 式范式，存在非结构化文本记忆的误差累积和信用分配不准确问题。本文提出 CoARS，引入交互奖励机制和自蒸馏信用分配，将历史交互轨迹转化为 token 级信号，使推荐和用户智能体能够协同进化。实验表明推荐性能和用户对齐均有显著提升。

INSIGHTCoARS 的核心创新在于将 RL 的信用分配从轨迹级推进到 token 级，通过自蒸馏机制让智能体从自身交互历史中提取更精确的奖励信号。「协同进化」思想——推荐智能体和用户智能体同步优化——为构建更拟真的推荐模拟环境提供了新思路，可用于搜索推荐系统的离线评估和策略优化。

Zongwei Wang, Min Gao, Hongzhi Yin, Junliang Yu, Tong Chen, Shazia Sadiq, Tianrui Li

GroupRank: A Groupwise Paradigm for Effective and Efficient Passage Reranking with LLMs

AAnt Group

LLM 重排序面临效率-精度的根本矛盾：pointwise 高效但忽略文档间比较，listwise 精准但推理延迟过高。本文提出 GroupRank，在组级别进行比较排序，兼顾灵活性和上下文感知。通过免答案数据合成管线融合 pointwise 和 listwise 信号，结合排序效用和组对齐奖励进行 RL 优化。在 BRIGHT 上达到 SOTA 65.2 NDCG@10，R2MED 上超基线 2.1 分，同时实现 6.4 倍推理加速。

INSIGHTGroupRank 在 pointwise 和 listwise 之间找到了实用的折中点：组级比较既保留了文档间的相对关系，又将上下文长度控制在合理范围内。6.4 倍的推理加速对在线搜索系统尤为重要——这意味着可以在相近延迟预算下使用更大的 LLM 进行重排序，或在相同模型下处理更多候选文档。其数据合成管线也为构建 LLM 排序训练数据提供了低成本方案。

Bottleneck Tokens for Unified Multimodal Retrieval

SJTU

将 decoder-only 多模态 LLM 适配到统一检索任务面临两个结构性缺陷：隐式池化机制非为信息聚合设计，对比微调缺乏 token 级压缩指导。本文提出 Bottleneck Tokens 作为可学习池化机制，配合生成式信息压缩训练和 Condensation Mask，在 MMEB-V2 基准 78 个数据集上取得 59.0 的 SOTA 整体得分，在语义密集任务上提升尤为显著。

INSIGHTBottleneck Tokens 的设计哲学是：与其让 EOS token 承担非设计用途的表征聚合，不如引入专用的可学习 token 作为信息瓶颈。Condensation Mask 强制模型通过瓶颈 token 传递信息，提供了明确的压缩训练信号。对多模态搜索系统（如图文混合内容的 UGC 检索）而言，这种统一的多模态表征方法可简化跨模态检索的架构设计。

Why These Documents? Explainable Generative Retrieval with Hierarchical Category Paths

Yonsei University

生成式检索直接解码文档 ID 响应查询，但无法为用户提供「为何检索该文档」的解释。本文提出 HyPE，在解码 docid 前先逐步生成层次化类目路径（从通用到具体的语义层级），再利用路径感知排序进行推理。实验表明该方法在提升可解释性的同时也改善了检索性能，类目路径为检索结果提供了直观的语义归因。

INSIGHTHyPE 的关键洞察是：层次化类目路径不仅是解释工具，还能作为生成式检索的结构化中间表征，引导模型从粗到细地缩小候选空间。对搜索系统而言，这种「先分类再定位」的生成式检索策略可提升结果的可解释性——这在 UGC 搜索中尤为重要，因为用户需要理解为何某个帖子被推荐。路径感知排序也可用于搜索结果的分面展示。

Sangam Lee, Ryang Heo, SeongKu Kang, Susik Yoon, Jinyoung Yeo, Dongha Lee
