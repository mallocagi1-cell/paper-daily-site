SID-Coord: Coordinating Semantic IDs for ID-based Ranking in Short-Video Search

针对短视频搜索排序中哈希 ID（HID）模型在长尾 item 上泛化能力差的问题，提出 SID-Coord 框架，将可训练的离散 Semantic ID（SID）直接嵌入 ID-based 排序模型。SID 通过残差量化从多模态内容中学习，配合 SID-HID 协调损失实现语义泛化与行为记忆的平衡。该方法在大规模短视频搜索系统中部署，离线指标和线上 A/B 测试均有显著提升。

All-domain Moveline Evolution Network for Click-Through Rate Prediction

Alibaba📖 深度解读 · 6 分钟 →

电商用户在 App 内的跨场景行为形成「全域动线」（moveline），该文提出 All-domain Moveline Evolution Network，将用户从搜索→推荐→详情页→购物车的场景级行为链路建模为动线演化序列。核心方法包括场景感知的行为聚合和动线演化注意力机制，在公开数据集和工业数据集上 CTR 预测 AUC 提升 0.3%–0.5%。

INSIGHT该工作将 CTR 建模从 item 级交互提升到场景级动线建模，关键创新是捕捉用户跨场景的行为逻辑一致性。对于社区搜索场景，类似思路可以将用户在搜索→浏览→互动→回搜的完整链路纳入 CTR 模型，尤其适合短文本 UGC 平台中用户频繁切换搜索和推荐 feed 的场景。场景级特征聚合比单纯堆叠行为序列更能反映真实意图。

Chen Gao, Zixin Zhao, Lv Shao, Tong Liu

MOSAIC: Multi-Domain Orthogonal Session Adaptive Intent Capture for Prescient Recommendations

针对多域 session-based 推荐中跨域交互与域内信号混淆的问题，提出 MOSAIC 框架，将用户偏好显式分解为三个正交成分：域内偏好、跨域迁移偏好和会话自适应意图。通过正交约束确保三类信号不互相干扰，在多个基准数据集上 HR@20 和 NDCG@20 均优于 SOTA session-based 推荐方法。

INSIGHT正交分解的设计思路值得借鉴：在多场景推荐系统中，跨域信号（如搜索意图迁移到 feed 流）和域内行为（纯浏览偏好）经常混淆，导致模型难以区分短期意图和长期兴趣。MOSAIC 的正交约束提供了一种结构化解耦方案，对社区平台中搜索、关注 feed、热门 feed 等多入口的用户意图建模有实践指导意义。

Abderaouf Bahi, Mourad Boughaba, Ibtissem Gasmi, Warda Deghmane, Amel Ourici

SemaCDR: LLM-Powered Transferable Semantics for Cross-Domain Sequential Recommendation

CUHK

针对跨域推荐中域特定特征缺乏迁移性的问题，提出 SemaCDR 框架，利用 LLM 构建统一的跨域语义空间。LLM 将不同域的 item 描述映射到共享语义表征，再通过对比学习对齐源域和目标域的序列化用户行为。实验表明在 Amazon 跨域数据集上 HR@10 比 SOTA 跨域推荐方法提升 5%–12%，有效缓解目标域冷启动问题。

INSIGHTSemaCDR 的核心价值在于用 LLM 作为域间语义桥梁，免去了传统跨域方法需要显式特征对齐的复杂设计。对于社区搜索场景，当平台有多个内容类型（帖子、问答、视频等），可以用类似思路通过 LLM 语义空间统一不同内容类型的用户兴趣表征，解决新内容类型上线时的冷启动问题。

Chunxu Zhang, Shanqiang Huang, Zijian Zhang, Jiahong Liu, Linsong Yu, Ruiqi Wan, Bo Yang, Irwin King

Beyond Offline A/B Testing: Context-Aware Agent Simulation for Recommender System Evaluation

推荐系统离线评估与线上表现存在显著鸿沟，本文提出 ContextSim，利用 LLM Agent 模拟带上下文的用户行为（时间、地点、需求等）来评估推荐系统。ContextSim 为每个模拟用户注入场景化人设，使交互行为更贴近真实用户决策过程。实验显示该方法的离线评估排名与线上 A/B 测试排名的 Kendall-τ 相关性显著优于传统离线指标。

INSIGHTContextSim 的关键突破是将环境上下文（时间、场景、需求）融入 LLM 用户模拟，而非仅模拟行为偏好。对于搜索/推荐团队，这提供了一种成本更低的 A/B 测试替代方案，特别适合快速验证排序策略变更的方向性效果。在 UGC 社区搜索中，用户搜索意图高度依赖上下文（如节日、热点事件），基于上下文的模拟评估比传统 replay 更准确。

Nicolas Bougie, Gian Maria Marconi, Xiaotong Ye, Narimasa Watanabe

SRBench: A Comprehensive Benchmark for Sequential Recommendation with Large Language Models

ZJU

现有序列推荐 benchmark 过于关注准确率，无法公平比较传统 NN-SR 和 LLM-SR 模型。SRBench 提出新的评测框架，覆盖准确率、公平性、鲁棒性三大维度，设计新数据集释放 LLM 潜力，并引入可靠的 LLM 输出解析机制。Benchmark 涵盖 12+ 种序列推荐模型，揭示 LLM-SR 在长尾 item 推荐和公平性方面优于传统方法，但在热门 item 准确率上仍有差距。

INSIGHTSRBench 的核心发现是 LLM-SR 在长尾推荐和公平性上有优势，但热门 item 准确率不及传统模型，这对实际部署决策有重要参考价值。对于社区搜索，如果考虑引入 LLM 做序列化推荐，应重点关注其在冷门内容上的增量收益，而非试图替代传统模型在热门内容上的优势，hybrid 方案可能是最优路径。

Jianhong Li, Zeheng Qian, Wangze Ni, Haoyang Li, Hongwei Yao, Yang Bai, Kui Ren

Catalog-Native LLM: Speaking Item-ID Dialect with Less Entanglement for Recommendation

现有 LLM 推荐方法在融合协同过滤信号和语义理解时面临纠缠问题：协同信号 token 高效但语义不透明，LLM 语义丰富但难以建模隐式偏好。Catalog-Native LLM 提出 item-ID 方言机制，让 LLM 学习一种特殊的 item ID 编码语言，通过解纠缠训练使 LLM 同时掌握协同过滤模式和语义推理能力。在多个推荐数据集上 NDCG@10 比基线 LLM 推荐方法提升 8%–15%。

INSIGHTitem-ID 方言是一个有趣的设计思路：与其在 LLM 和传统推荐模型之间做粗暴的特征拼接，不如让 LLM 内化一套 item 编码体系。这对 UGC 搜索中将 LLM 引入排序有启示：可以为帖子/内容设计类似的 Semantic ID 体系，使 LLM 既理解内容语义，又能捕捉用户交互模式，避免两类信号的相互干扰。

Reza Shirkavand, Xiaokai Wei, Chen Wang, Zheng Hui, Heng Huang, Michelle Gong

Tuning Language Models for Robust Prediction of Diverse User Behaviors

Tsinghua

用户行为预测中，LLM 微调容易过拟合高频「锚点」行为，忽略长尾行为。BehaviorLM 提出两阶段渐进微调策略：第一阶段在全行为分布上预训练行为理解能力，第二阶段通过锚点-尾部对比学习增强长尾行为的预测鲁棒性。在多个用户行为预测数据集上，长尾行为预测准确率比标准 SFT 提升 12%–20%，同时不损失高频行为的性能。

INSIGHT长尾行为的预测鲁棒性是实际推荐系统的核心挑战：高频行为（搜索热门话题）容易建模，但用户真正的个性化需求往往体现在低频行为中。BehaviorLM 的渐进微调思路可以应用于社区搜索的 query 理解：先让模型学习通用的搜索意图理解，再通过对比学习强化对小众/冷门 query 的理解能力。

Fanjin Meng, Jingtao Ding, Jiahui Gong, Chen Yang, Hong Chen, Zuojian Wang, Haisheng Lu, Yong Li

CRAFT: Cold-Start Recommender with Attention and Federated Training

针对推荐系统冷启动场景，CRAFT 提出基于注意力机制的冷启动推荐框架，结合联邦学习实现隐私保护下的新用户/新 item 推荐。注意力模块聚焦用户-item 交互模式中的显著信号，在跨客户端数据不共享的前提下学习通用的冷启动表征。在 MovieLens 和 Amazon 数据集上冷启动 NDCG@10 比传统联邦推荐方法提升 8%–12%。

INSIGHTCRAFT 将冷启动和联邦学习结合的思路适合隐私敏感的社区平台：用户数据不出域，但通过联邦训练获取跨社区的冷启动能力。对于 UGC 搜索中新用户和新内容的排序，注意力机制在稀疏交互中提取关键信号的策略比传统 embedding 初始化更鲁棒。
