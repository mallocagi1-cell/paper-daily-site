Verbal-R3: Verbal Reranker as the Missing Bridge between Retrieval and Reasoning

针对常规 RAG 直接把检索文本喂给 LLM 上下文导致信息整合不充分的问题，论文提出 Verbal-R3 框架：用「Verbal Annotations」明确写出查询与候选文档之间的逻辑关系，再用 Generator+Verbal Reranker 双角色迭代检索-推理。Reranker 不仅给出分数还输出语言化解释，引导 Generator 的推理；推理过程加入 relevance-guided test-time scaling 在轨迹扩展时按相关性分配算力。论文在多个复杂多跳 QA 基准上取得 SOTA 表现。

KEY INSIGHT · 对业务意味着什么核心创新是把「reranker 的判定理由」从隐式 logits 升级为显式自然语言注释，等于给生成器植入一段可解释的对齐链路。这对社区搜索 UGC 场景非常有借鉴：query 与短文本之间常存在主题/口语化跳跃，仅靠相关性分数难以让排序模型「理解为什么相关」。把 verbal annotation 作为 reranker→生成式重排或答案生成的桥梁，可以显著降低幻觉、提升复杂搜索意图的 nDCG。同时 test-time scaling 思路也启发：推理阶段可按相关性弹性分配算力。

Variable-Length Semantic IDs for Recommender Systems

Yandex

针对 RQ-VAE 等定长 Semantic ID 在长尾/冷启动 item 上信息冗余而在热门 item 上又信息不足的问题，论文提出 VL-SID：用带 Gumbel-Softmax 重参数化的离散 VAE 学习「自适应长度」item 编码，让信息量大的 item 拿到更多 token、简单 item 用更少 token。框架避免 REINFORCE 式训练的不稳定性，可以无缝集成进 LLM 词表用于生成式推荐。实验显示 VL-SID 在长尾与冷启动 item 上召回与生成式推荐准确率显著优于定长 SID 基线，同时保留 full-softmax 训练效率。

INSIGHT把「编码长度」当作可学习自由度，是 Semantic ID 设计上的一次范式升级。对社区搜索 UGC 而言，帖子/问答 item 本身在信息密度上分布极不均匀（短评论 vs 高赞万字回答），定长编码必然损失头部信息或浪费尾部 token。借鉴 VL-SID 的思路，可在「item tokenizer」环节让 RQ-VAE 输出可变长度 SID 序列，配合生成式召回/排序，能把长尾 UGC 召回率与冷启动新帖曝光率同时打开。

Kirill Khrylchenko

Seeking Information with RAG-Assistants: Does Model Size Matter in Human-AI Collaborations?

TTNOLeiden University

为回答「RAG 助手到底要多大模型」，论文用 N=112 真人在多轮工作场信息搜索任务里对比 RAG-only/LLM-only/LLM+RAG 三种基线，分别接入 3B、8B、70B 三档模型。结果显示无论模型多大，「人 + RAG-assistant」组合的任务正确率都显著超过纯模型基线；3B 模型在合规性敏感场景中接入 RAG 后即可达到 70B 单模的水平，模型大小对感知可用性与满意度的影响远小于检索质量的影响。

INSIGHT这篇实证研究给生成式搜索产品一个直接结论：检索结构而非模型参数才是上限。对社区搜索/问答助手而言，与其追求大底座模型，不如把工程预算投在召回/重排和证据组织。同时 3B 级模型 + 高质量 RAG 即可在合规、敏感数据场景中胜任主线流量，给端侧或低成本部署留足空间，正契合 UGC 平台高 QPS 低成本的约束。

Lennard C. Froma, Tom Kouwenhoven, Maaike H. T. de Boer, Catholijn M. Jonker, Max J. van Duijn

Beyond Semantic Relevance: Counterfactual Risk Minimization for Robust Retrieval-Augmented Generation

PKU

传统 RAG 把「语义相关」当作效用代理，但真实查询常带认知偏差（错误前提、确认偏误），单看相关性反而会拉来「附和性证据」放大幻觉，论文称之为 Relevance-Robustness Gap。作者提出 CoRM-RAG：在因果干预框架下设计 Cognitive Perturbation Protocol，训练阶段模拟用户偏差查询，蒸馏出一个轻量 Evidence Critic，给候选文档打「能否纠偏」分数，再做检索 reranking。实验显示在带偏差查询基准上 CoRM-RAG 显著降低跟随性幻觉、提升答案稳健度。

INSIGHT把检索目标从「语义相似」转向「决策安全/反事实风险最小化」是一个值得学习的视角。社区搜索里大量 query 自带预设（「XX 真的有效吗」式），传统排序很容易把附和性内容顶到首位。借鉴 CoRM-RAG 的 Evidence Critic，可以在重排阶段加一个「反向证据通道」专门寻找能纠偏的高质量 UGC，对长期信任与社区健康指标都有正向作用，且 Critic 只是轻量模块、不重排整套召回，工程落地友好。

Peiyang Liu, Qiang Yan, Ziqiang Cui, Di Liang, Xi Wang, Wei Ye

"I Don't Know" -- Towards Appropriate Trust with Certainty-Aware Retrieval Augmented Generation

TTNOUtrecht University

针对 LLM 即使没掌握信息也会自信编造的问题，论文提出 CERTA（Certainty Enhanced RAG for Trustworthy Answers）：把「问题-上下文-答案」三段间的相关性强度作为内部不确定度信号显式输出给用户，让模型在该说「我不知道」时学会示弱。配套发布的 CertaintyQA 数据集涵盖各置信梯度问答对，实验显示 CERTA 在校准度与用户感知可信度上明显胜过普通 RAG 基线。

INSIGHT「不确定性显式化」是生成式搜索从演示走向产品化的关键缺失环节。社区搜索/AI 解答类产品里，错误自信是用户流失的头号原因，而 CERTA 仅用相关性强度就能近似 self-reflection 信号，工程改造成本低。可以把它接入答案生成阶段，配合一条「弃答/转人工/反查」的产品策略，在 CTR 与信任度之间找到新平衡点。

Daan Di Scala, Maaike de Boer, Pınar Yolum

A Hybrid Retrieval and Reranking Framework for Evidence-Grounded Retrieval-Augmented Generation

CCalifornia State University Fullerton

论文落地一套 citation-aware 生物医疗 RAG：以 Amazon Bedrock Knowledge Bases 做文档 ingestion/分块/embedding，存储用 S3 + OpenSearch Serverless，先做 Hybrid 检索（向量+BM25）再用 Cohere reranker 提候选，最后由 LLM 引用出处生成答案。实验比较多种检索器与 reranker 组合，给出可复用的 evidence grounding 基线。

INSIGHT对工程团队最有价值的是这套「云原生 RAG 流水线」：稀疏-稠密 hybrid + 商用 reranker + citation 输出，几乎可以原样照搬到社区搜索的智能问答模块。论文还给出 chunking 大小、reranker top-k 的灵敏度分析，是少有的把工程参数与离线指标关联起来的实证基线，对 RAG 选型具有直接参考价值。

Fariba Afrin Irany, Sampson Akwafuo

Q-RAG: Long Context Multi-step Retrieval via Value-based Embedder Training

AAIRISSkoltech

面向多跳长上下文问答，主流 multi-step RAG 通过微调小 LLM 反复检索、成本高且锁死了大模型路线。Q-RAG 反过来用 Value-based RL 直接微调 Embedder 模型，把多步检索建模成 Q 学习中的状态价值估计，让 embedder 学会「为后续推理保留信息量」。在 BabiLong、RULER 等长上下文基准上取得 SOTA，参数和成本远低于 LLM 微调路线。

INSIGHT把多步检索的优化目标从 LLM 端移到 embedder 端，是 RAG 训练范式的关键反转。对成本敏感的社区搜索而言，长 query/上下文的多跳召回可以用一个 RL-tuned embedder 替代昂贵的 multi-step LLM agent，QPS 与延迟控制大幅简化。Value-based 训练也比 policy-gradient 更稳定，工业落地风险更低。

Artyom Sorokin, Nazar Buzun, Alexander Anokhin, Oleg Inozemcev, Egor Vedernikov, Petr Anokhin 等 10 人

Chain of Evidence: Pixel-Level Visual Attribution for Iterative Retrieval-Augmented Generation

PKU

针对 iRAG 在视觉文档（PPT、含图 PDF）上「文本解析丢失版式信息」与「粗粒度引用」两大瓶颈，论文提出 Chain of Evidence (CoE)：retriever-agnostic 视觉归因框架，让 VLM 直接在文档截图上推理，输出像素级 bounding box 引用。实验显示 CoE 在多模态 RAG 基准上提升答案准确率与可验证性，并消除了对特定文档解析器的依赖。

INSIGHT社区搜索的视觉化内容（图片帖、笔记、菜单截图）越来越多，传统「OCR→文本检索」流水线丢失版式与图文关系。CoE 提出的 VLM 截图直读 + bbox 归因路径，等于给生成式答案配了一条「可视化证据链」，对图文社区的 trust signal 与点选行为都有提升空间。retriever-agnostic 设计也意味着可与现有召回栈正交叠加。

Peiyang Liu, Ziqiang Cui, Xi Wang, Di Liang, Wei Ye

GPT-5.5 Instant System Card

OpenAI

OpenAI 发布 GPT-5.5 Instant 系统卡，把 ChatGPT 默认模型升级为更短、更准、更个性化的版本。内部评测显示在医学/法律/金融等高风险 prompt 上幻觉率比 GPT-5.3 Instant 下降 52.5%，回答平均字数减少 30.2%、行数减少 29.2%，并首次进入「高能力」网络安全与生物领域分级。模型同时强化工具调用、自检自驱与人格一致性，在 ChatGPT 全量与 API（chat-latest）滚动上线。

INSIGHT对于以 LLM 为答案生成端的社区搜索/问答产品而言，幻觉减半 + 输出更短直接转化为 CTR 与 SAT。同时 GPT-5.5 Instant 「问得少、做得多」的特性把单轮成本拉低，是把 AI 答案接入社区搜索主线流量的窗口期信号。值得关注的是 OpenAI 把它定为高能力网络安全/生物模型，意味着开放部署需要补一层 PSafety 评估，UGC 平台需提前规划 jailbreak/合规防护。

New ways to buy ChatGPT ads

OpenAI

OpenAI 在 ChatGPT 中开放广告自助投放：beta 版 Ads Manager、CPC 出价、增强型衡量工具，同时强调隐私分隔——广告与对话流分离，并未把 chat 内容用于广告定向。这是生成式搜索时代的首次主流商业化信号，为 LLM 入口接入广告变现给出了产品形态范本。

INSIGHT对内容平台具有强战略意义：当 AI 答案逐步替代传统搜索结果，广告系统也要同步迁移到「对话流广告」形态。OpenAI 选择「对话与广告分离 + CPC 自助」的模型，避开了 chat 内容被广告污染的信任风险，对国内社区做生成式搜索商业化具有借鉴价值——保护语义可信度同时给商家提供清晰可控的投放接口，是平衡用户体验与营收的现实路径。
