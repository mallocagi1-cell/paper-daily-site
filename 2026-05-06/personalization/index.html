FEDIN: Frequency-Enhanced Deep Interest Network for Click-Through Rate Prediction

针对序列推荐中用户行为时域噪声大、难以捕捉周期性兴趣的问题，提出 FEDIN 在频域引入 target-aware 的谱滤波分支增强 DIN。核心观察是：当用 target item 条件化用户注意力分数时，正样本对应的频谱熵显著低于负样本，说明真实兴趣呈低熵周期模式而噪声呈高熵分布。FEDIN 用频域分支隔离与目标商品共振的周期信号，再与时域 DIN 融合用于 CTR 预估。

KEY INSIGHT · 对业务意味着什么工业界 DIN/SIM 系列模型长期在时域做注意力，FEDIN 提供了一条几乎正交的频域增强路径，用谱熵把噪声行为天然滤除。该思路对社区 feed 的长行为序列尤其有价值——周期型兴趣（如周末游戏、晚间美食）通常被时域注意力稀释，频域分支可作为低成本的旁路模块插入现有粗排/精排链路，且不需要重训整个用户塔。

Post-hoc Provider Fairness Adaptation via Hierarchical Exposure Alignment

HHFUT📖 深度解读 · 9 分钟 →

针对推荐系统作者/供给侧曝光公平问题，提出 PFA：在冻结的主推荐模型外挂一个轻量「公平 adapter」，用 user-item embedding 学习个性化的加性分数偏置注入到原始排序分中，无需重训主模型即可适配多种公平目标。训练目标是最小化实际曝光分布与目标公平曝光分布的 KL 散度，并通过层级化曝光对齐避免打散头部高质内容。

INSIGHTPFA 的工业价值在于解耦了「模型主链路」和「公平约束」。社区类产品的作者生态治理常需要快速调整曝光策略（扶持新手、抑制头部、品类均衡），但每次重训精排成本高昂。PFA 模式只需上线一个百万参数级 adapter，配合不同的目标曝光分布即可热切换；这与业界常用的后置 reranker 相比，由于 adapter 学的是个性化偏置而非全局阈值，对个性化 CTR 损失更小。

Jingzhi Li, Zhiyong Cheng, Richang Hong, Meng Wang

Multi-modal Relational Item Representation Learning for Inferring Substitutable and Complementary Items

AmazonUIUC

针对推断商品互补/替代关系时，行为信号 (co-view/co-purchase) 噪声大且长尾稀疏的问题，提出 MMSC：用多模态基础模型编码商品元数据 (文本+图像)，再用自监督去噪模块从噪声行为信号中学习关系感知的表征，并通过分层聚合机制统一两路。训练时引入 LLM 辅助监督来缓解行为派生标签的噪声，实验在 Amazon 公开数据集上同时报告了替代品和互补品任务上的提升。

INSIGHT对于电商/社区类二级页「相关推荐」场景，单纯依赖共现行为构图会被新品冷启动和长尾稀疏卡住；MMSC 把内容侧 (多模态 foundation model) 与行为侧 (自监督去噪) 解耦后再融合，是当前大模型时代的「标准答案」模板。LLM 辅助监督这一步对中小数据集的关系学习尤其关键——把昂贵的人工标注替换成可规模化的 LLM 弱监督，是社区相关推荐落地多模态的可行降本路径。

Junting Wang, Chenghuan Guo, Jiao Yang, Yanhui Guo, Hari Sundaram, Yan Gao

04 3.75

Bridging Behavior and Semantics for Time-aware Cross-Domain Sequential Recommendation

BBJTU

针对跨域序列推荐 (CDSR) 中现有方法忽视域特定交互频率/兴趣衰减率以及把语义偏好当作时不变的问题，提出 BST-CDSR：行为偏好演化模块用 neural ODE 建模长期兴趣与短期意图的连续时间衰减，并通过事件驱动更新；语义侧引入时间反事实增强模块，使语义偏好可以随时间漂移。在公开 CDSR 基准上同时改进短期与长期推荐指标。

INSIGHT在多业务/多场景共建的社区平台 (例如同时存在视频、笔记、电商等多个域)，跨域用户兴趣迁移既要解决稀疏冷启动也要避免域 A 的高频行为污染域 B。BST-CDSR 的关键启发是：跨域不只是「共享 embedding」，必须显式建模每个域的兴趣衰减节律（用 neural ODE 而非固定时窗），以及语义偏好的时变性。神经 ODE 部署成本目前偏高，但其「事件驱动更新」思路可以退化成更轻量的时间感知 attention 实现。

Zhida Qin, Zemu Liu, Haoyan Fu, Chong Zhang, Tianyu Huang, Yidong Li, Gangyi Ding

Learning Decomposed Contextual Token Representations from Pretrained and Collaborative Signals for Generative Recommendation

UIUC

针对生成式推荐「先 tokenizer 后 LLM」两阶段优化目标错配的问题（前者优化语义重建，后者优化用户交互序列建模），提出 DECOR：将 token 表征分解为静态预训练分量与上下文协同分量，预训练知识不再被生成式推荐训练阶段全量覆盖，从而同时保留 LLM 的语义先验和协同过滤信号。在公开生成式推荐基准上展示了对 TIGER/HSTU 风格 baseline 的稳定提升。

INSIGHTGenerative Rec 的工业落地难点之一就是 Semantic ID 的「刚性」——一个 item 在不同上下文/不同用户面前的语义其实不同，而 RQ-VAE 风格的固定 token 化无法表达这种上下文差异。DECOR 的「分解式 token 表征」思路是当前最务实的解决方案：保留 frozen pretrained embedding 作为语义骨架，用一个轻量协同分量动态修正，避免直接全量微调 LLM 所带来的语义遗忘；这对工业界用 Qwen / GLM 等开源模型做生成式精排的团队尤其值得借鉴。

Yifan Liu, Yaokun Liu, Zelin Li, Zhenrui Yue, Gyuseok Lee, Ruichen Yao, Yang Zhang, Dong Wang

Led to Mislead: Adversarial Content Injection for Attacks on Neural Ranking Models

TTMUWWaterloo

针对神经排序模型 (NRM) 长期面临 SEO 风格对抗注入的安全问题，提出 CRAFT：用 LLM 做黑盒对抗排序攻击的三阶段框架——RAG+自我修正生成对抗数据集、监督微调成攻击模型、偏好优化对齐到排名提升目标。在 MS MARCO、TREC DL 2019/2020 上促排率与排名提升均显著超过启发式与代理模型 baseline，且生成内容流畅性、语义忠实度未明显损失，攻击效果可跨模型迁移。

INSIGHT对推荐/搜索从业者，这篇并非「攻击教程」，而是给排序系统团队的红蓝对抗工具：CRAFT 风格的对抗样本可直接用作神经精排器的数据增强或鲁棒性评测集。社区搜索常面临黑灰产改写贴文以骗取排名的问题，过去依赖关键词规则与人工审核；CRAFT 揭示 LLM 时代的注入更难检测（语义忠实+流畅），意味着内容质量信号必须从纯文本转向作者行为、互动信号、跨贴文一致性等多源融合。

GPT-5.5 Instant: smarter, clearer, and more personalized

OpenAI

OpenAI 发布 GPT-5.5 Instant，作为 ChatGPT 默认模型升级版，重点是更准答案、更低幻觉以及增强的个性化控制。该版本暴露了细粒度的偏好/口吻/记忆控制开关，让用户可显式调整模型如何引用历史对话、如何定制回答风格，把个性化从隐式向用户可解释、可干预方向推进。

INSIGHT对推荐/搜索从业者最值得关注的不是模型本身，而是 ChatGPT 端把「用户控制粒度」明确暴露给最终用户，这与传统推荐系统「黑盒个性化」形成对比。社区类产品在「为何看到这条」的可解释性、隐式记忆与显式偏好的边界、用户主动管理画像的 UX 设计上，可借鉴 OpenAI 的产品形态——尤其是个性化控制与隐私保护并存的方案，以及 personalization 与 instruction following 之间的优先级仲裁。

Multimodal Data Curation Through Ranked Retrieval

针对多模态共享 embedding 空间中「按模态聚簇而非按语义聚簇」以及配对监督噪声大的问题，提出双层框架：Symmetric Nucleus Subsampling (SNS) 在样本级修剪输入和标注的核心匹配片段，Expert Embedding Engine (EEE) 用学习投影网络融合互补 embedding 专家并引入偏差感知目标，抑制模态分隔。整体框架既改训练对又改 embedding 模型本身，改善跨模态检索召回。

INSIGHT社区相关/猜你喜欢推荐越来越依赖多模态 embedding (文本+封面图+视频帧)，但实际效果常不如单模态 baseline——本文给出的诊断是经典的「模态主导聚类」问题。SNS 的核心修剪思想可以平移到社区数据治理：对作者发布的图文对，只保留语义对齐度高的核心片段做训练样本，能显著降低 embedding 训练的噪声。EEE 的多专家融合 +bias-aware 目标也能直接落到现有 two-tower 模型作为消融模块。

Investigating the Effects of Different Levels of User Control in an Interactive Educational Recommender System

UUDE

在 MOOC 平台 CourseMapper 上设计了一个交互式教育推荐系统，让学习者分别在 input (用户画像)、process (推荐算法)、output (推荐结果) 三个层面拥有不同程度的可控性，并通过 N=184 的 between-subject 用户实验，量化了不同控制粒度对感知控制感、透明度、信任、满意度和质量感知的影响。结果表明开放更多控制权显著提升信任和透明度，但对推荐质量感知影响呈非线性。

INSIGHT工业推荐系统对「用户可控」长期保守（怕影响留存指标），但本论文的实证结果给出了更精细的画面：input/process/output 三层控制带来的体验提升并不等价，output 层的「为什么/换一批」操作对信任的提升最显著但对质量感知影响小，process 层（让用户调权重）反而可能伤害质量感知。社区类产品在做「不感兴趣」「减少推荐这位作者」等特性时，可以参考此结论优先做 output 层控制并辅以解释而非让用户改算法权重。

Qurat Ul Ain, Mohamed Amine Chatti, William Kana Tsoplefack, Rawaa Alatrash, Shoeb Joarder

AlbumFill: Album-Guided Reasoning and Retrieval for Personalized Image Completion

AdobeUUC Merced

面向个人照片的个性化图像补全，提出 AlbumFill：免训练框架，先用 VLM 推断遮挡区域语义线索，引导组合式图像检索从用户个人相册中找出身份/外观一致的参考图，再用 reference-based 补全模型填充遮挡。配套构建了 54K 人物中心样本+相册的数据集；在身份一致性和外观保留上都明显优于通用 inpainting 基线。

INSIGHT对社区平台的「个性化图片/封面生成」和「形象一致性」功能 (例如博主一键生成同风格头图)，本文展示了一个轻量可行的范式：不需要 fine-tune 任何生成模型，通过 VLM 语义推断 + 个人语料检索 + reference-guided 补全的组合，就能拿到 ID 一致性。这种「检索增强生成」的多模态版本对资源紧张的应用层团队尤其友好，部署成本远低于针对每个用户做 LoRA 个性化训练。
