美团 LongCat-Flash-Thinking-2601 开源：Agentic Search、工具调用与并行推理实践

美团 LongCat 团队开源 LongCat-Flash-Thinking-2601 推理大模型，专门面向 Agentic Search、Agentic Tool Use、Tool Interaction Reasoning 三类任务。论文采用 8 路 Parallel Thinking 并行推理 + 迭代摘要（Iterative Summarization）的结构设计，配合两阶段数据策略与 128k 长上下文，并集成 60+ 工具组成的多环境强化学习框架。报告显示在 τ²-Bench 工具调用 88.2 分、VitaBench 29.3 分、BrowseComp 73.1 分、RW Search 79.5 分均达到开源 SOTA。

T^2PO: Uncertainty-Guided Exploration Control for Stable Multi-Turn Agentic Reinforcement Learning

📖 深度解读 · 10 分钟 →

本文针对多轮 agentic RL 训练崩溃问题，提出 Token- and Turn-level Policy Optimization（T²PO）。作者将训练不稳定归因于多轮场景中的低信息探索：策略反复生成既不降低不确定性也不推进任务的 token 与 turn。T²PO 在 token 级监控边际不确定性变化，一旦低于阈值就触发思考干预，强制重写探索方向；在 turn 级识别探索停滞的交互并进行动态重采样，避免无效轨迹消耗 rollout 预算。这一双层不确定性控制框架可显著缓解多轮 RL 训练中的策略坍塌。

INSIGHT对搜索/推荐 agent 训练的启示：多轮 agentic RL 在召回-排序-改写循环中常见崩溃原因是无效探索——重复发出已检索过的相似查询、生成低增益分析。T²PO 用边际不确定性变化作为触发器，是非常通用的训练加速器，可直接接入现有 GRPO/PPO 工业管线。turn 级动态重采样思想等价于放弃低 ROI 的对话分支并把预算让给高潜路径，对训练搜索 agent 具有零成本工程价值。

Haixin Wang, Hejie Cui, Chenwei Zhang, Xin Liu, Shuowei Jin

When Iterative RAG Beats Ideal Evidence: A Diagnostic Study in Scientific Multi-hop Question Answering

本文首次对迭代 RAG 是否真的能超越静态理想证据进行机制级诊断研究。作者在 ChemKGMultiHopQA 化学多跳 QA 数据集上对 11 个 SOTA LLM 进行三种条件对比：No Context（仅用参数化记忆）、Gold Context（一次性给所有 oracle 证据）、Iterative RAG（免训练控制器，交替执行检索、假设修正与证据感知停止）。结果显示，迭代 RAG 在某些场景反而比 Gold Context 更优，揭示一次性堆砌证据反而会引发 LLM 推理被噪声拖累的反直觉现象。

INSIGHT对社区搜索 RAG 的启示：把所有可能相关的 UGC 帖子一次性塞给生成模型并不总是最优——更长上下文会带来推理稀释，而迭代式问-检-停控制器允许模型在已有部分证据时形成中间假设、进而精准追问，反而提升 nDCG。该工作把何时停止检索显式建模为可观测变量，对设计 community search 答案合成模块（如知乎问题概览）极具借鉴：与其追求一次性召回完整证据，不如设计可中止的迭代召回。

Mahdi Astaraki, Mohammad Arshi Saloot, Ali Shiraee Kasmaee, Hamidreza Mahyar, Soheila Samiee

TagRAG: Tag-guided Hierarchical Knowledge Graph Retrieval-Augmented Generation

ECNU

TagRAG 针对传统片段级 RAG 难以处理 query-focused 摘要查询、以及 GraphRAG 在信息抽取与增量更新上代价过高的痛点，提出标签引导的层次化知识图谱 RAG 框架。两个核心模块：一是 Tag KG 构建——从文档抽取对象标签及其关系，组织为层级化领域标签链；二是标签引导的 RAG——在生成时按层次标签链定位领域子图，再按标签关联取片段，避免无差别全图遍历。框架支持低成本增量更新，相比 GraphRAG 在效率与可扩展性上明显占优。

INSIGHT对社区平台的启示：UGC 内容天然具有用户标签、话题标签、地理标签等多层结构，TagRAG 的层级标签链思想几乎可以直接套到知乎话题树、小红书标签树。其先标签定位、再片段细取的两段式检索是把 GraphRAG 重型推理降级为可工业化的轻量索引。增量更新友好这点尤其重要——社区内容每天百万级新增，全量重建图谱不现实，而 TagRAG 只需更新对应标签链节点。

Wenbiao Tao, Xinyuan Li, Yunshi Lan, Weining Qian

Enhancing Judgment Document Generation via Agentic Legal Information Collection and Rubric-Guided Optimization

Tsinghua

Judge-R1 框架联合优化法律信息收集与判决书生成两个子任务，针对传统 RAG+SFT 在法律领域出现证据召回不足、法条幻觉、法律推理逻辑错误的问题。第一阶段提出 Agentic Legal Information Collection：动态规划 agent 从多源（法条库、判例库、案件描述）按需检索精准的法条与先例。第二阶段引入 Rubric-Guided Optimization，使用 GRPO 强化学习按多维度法律评分细则给 agent 反馈，迭代优化检索策略与生成质量，缓解上下游链路的信号失配。

INSIGHT对垂直领域搜索（医疗、法律、教育）的启示：把证据召回与答案生成作为联合优化目标，而非分别独立训练，可以避免下游生成隐式拒绝上游召回的信号失配问题。Rubric-Guided GRPO 是一种专家可写规则即奖励的轻量化 RL 方案，相比训练 reward model 数据成本低，可被社区问答类垂类搜索复用——只需把答得是否完整、是否引用、是否合规写成 rubric 即可。

Weihang Su, Xuanyi Chen, Yueyue Wu, Qingyao Ai, Yiqun Liu

Building for the Rising Complexity of Agentic Systems with Extreme Co-Design

NVIDIA

NVIDIA 工程博客提出 agentic 系统极致协同设计（extreme co-design）理念，针对 generative AI 第二章的本质变化——agent 不再只是 request-response，而是主动规划、调用工具、跨步骤决策——重新审视 GPU、网络与调度的全栈耦合。文章给出 NVIDIA 在 agentic workload 下的硬件、内存、KV cache、调度软件层（Dynamo/NIM/Triton）的最新协同设计实践与基准对比，覆盖了短而异步的 LLM 调用对资源的全新需求。

INSIGHT对搜索/推荐 infra 团队的启示：Agentic search 工作负载的算力曲线与传统检索-生成完全不同——大量短而异步的 LLM 调用、跨工具长上下文、KV cache 频繁切换。文章揭示 GPU 利用率、batch 调度、缓存复用三方面的协同优化空间。这对国内大厂构建 LLM-native 搜索/客服中台是必读：传统按 RPS 和 token throughput 估算资源的方式已不再适用，需要 agent step-level 与 tool-call-level 双维度的资源建模。

AcademiClaw: When Students Set Challenges for AI Agents

AcademiClaw 是 OpenClaw 生态下首个学术级 agent benchmark，由 230 个大学生提交、专家筛选出 80 个跨 25+ 学科的真实复杂长任务（作业、研究、竞赛、个人项目），范围覆盖奥数、语言学问题到 GPU 强化学习训练、全栈系统调试，其中 16 个任务需 CUDA GPU 执行。每个任务运行在独立 Docker 沙箱内，通过 6 个互补打分维度的 rubric 自动评分，并辅以 5 类独立安全审计。结果揭示当前 SOTA agent 在长视野学术任务上的真实差距。

INSIGHT对国内搜索/推荐场景的启示：现有 agent benchmark 多为装作专家的 toy 任务，而 AcademiClaw 把用户真正卡住的复杂查询作为评测金标，这正是社区搜索难问题建模思路——从用户失败查询日志中沉淀长尾任务集。沙箱+rubric+安全审计三件套也可以借鉴用于内部 agent 灰度发布门禁。题目跨学科、跨硬件需求，证明 agent 系统设计必须考虑工具调度的高异质性。

Junjie Yu, Pengrui Lu, Weiye Si, Hongliang Lu, Jiabao Wu

PhysicianBench: Evaluating LLM Agents in Real-World EHR Environments

PhysicianBench 引入 100 个长视野医师任务，全部来自真实初级保健与亚专科医生会诊案例，并由独立医师小组评审。任务被部署在带真实病历的 EHR 环境中，通过商业 EHR 厂商相同的标准 API 接入；覆盖心脏、内分泌、肿瘤、精神科等 21 个专科，工作流包括诊断解读、处方、治疗规划等。相比既有医疗 agent benchmark 只考察静态知识或单步动作，PhysicianBench 强调可验证执行与多步组合工作流，更贴近真实临床部署场景。

INSIGHT对社区搜索 agent 评测体系的启示：从问答正确率转向在真实环境对真实 API 完成可验证多步动作是 agent 评估的下一阶段——和复杂搜索任务（如帮我找到 3 篇符合条件的帖子并总结）高度同构。21 专科分类思路类似于社区平台的兴趣垂类划分，建议社区搜索建立同等粒度的评测面：旅游、母婴、数码、职场各做一套真实 API 沙箱评测，用 rubric 加多审核员评审复用此范式。

Ruoqi Liu, Imran Q. Mohiuddin, Austin J. Schoeffler, Kavita Renduchintala, Ashwin Nayak

SurGE: A Benchmark and Evaluation Framework for Scientific Survey Generation

TsinghuaRenmin University

SurGE（Survey Generation Evaluation）针对 LLM 自动撰写学术综述这一典型 deep research 任务，构建首个标准化 benchmark：含主题描述、专家撰写综述与全部引用文献的测试集，以及 100 万+论文规模的学术语料库。配套自动评估框架从 4 个维度量化生成综述质量：综述完整性、引用准确性、结构组织性、内容质量。对多类 LLM 方法进行评测，揭示当前 SOTA 在覆盖度与引文准确性上仍存在显著差距，给出可复现的 deep research 评测基线。

INSIGHT对社区长答案/深度合集生成的启示：deep research 类长内容生成的核心瓶颈不在生成而在引证忠实和结构组织——这恰好对应社区搜索答案卡的两个痛点：避免幻觉、避免段落雷同。SurGE 的 4 维评估范式可被社区直接复用：把是否覆盖问题各方面、是否引用真实帖与真实数据、段落结构是否清晰、内容质量是否优于检索结果直拼做成内部 nDCG 之外的二级指标。

Weihang Su, Anzhe Xie, Qingyao Ai, Jianming Long, Xuanyi Chen, Jiaxin Mao, Ziyi Ye, Yiqun Liu

Fair Agents: Balancing Multistakeholder Alignment in Multi-Agent Personalization Systems

TTU Graz

本文聚焦多目标个性化场景下的多 LLM agent 系统：每个 agent 独立为某一利益相关方（用户、广告主、平台、内容创作者）的目标做优化，再通过聚合达成最终决策。作者识别出三大开放问题：一是利益相关方目标如何对齐到 LLM agent 可量化目标；二是 agent 输出聚合机制如何保证公平性；三是协作-竞争边界如何设计。基于此提出概念性框架，整合目标对齐方法、聚合算子设计与公平性约束，呼吁多 agent 个性化研究从单目标向多 stakeholder 形式化。

INSIGHT对社区搜索/推荐多目标平衡的启示：现行多目标排序通过 loss 加权折中，本质是黑盒；多 agent 框架把用户体验、商业收入、创作者激励显式拆成各自 agent，再通过协商机制聚合，更可解释也更易上线 A/B。文章警示了 LLM-as-judge 类聚合容易引入主导 agent 偏置，社区团队若引入多 agent 框架须设计带不确定性的聚合算子（投票而非求和）以保住长期公平。

Andrea Forster, Peter Müllner, Denis Helic, Elisabeth Lex, Dominik Kowald
