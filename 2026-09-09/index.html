WIDE: Wildcard Inference with Dynamic Expansion for Cross-Modal Generative Retrieval

针对短查询无法描述图像全部细节、生成式检索却被迫猜测离散标识的问题，WIDE用分层熵阈值触发通配符扩展，再融合生成置信度与向量相似度重排。在M-BEIR上，VisualNews的R@5从GENIUS的27.4升至30.2，CIRR从39.5升至41.5；尚未超过强向量基线U-MARVEL。

Off-Policy Evaluation for Semantic ID Recommenders: Does the Model's Own Code Hierarchy Help?

Criteo

论文研究语义ID推荐器如何在上线前做离策略评估，将物品级权重聚合到SID前缀簇以缓解日志支持不足。在KuaiRand的1000条日志设置下，SLOPE选择粒度的RMSE为0.133，低于物品级SNIPS的0.251；5000条日志下为0.109对0.155。收益主要来自聚合，而非树结构本身。

INSIGHT社区生成式召回若已有SID树，可以利用解码器直接计算前缀概率，以较低成本筛选值得A/B的解码方案。实践应先审计曝光概率和有效样本量，再从日志选择聚合深度；不能使用知道真实收益的oracle深度冒充可部署结果，也不能把离线估计误差下降解释成CTR提升。

Betlei, Artem

03 3.75

Continual Graph Memory for Adaptive Recommendation under Intent Drift

Phenikaa UniversityHHUST VietnamUTS

CGM-Rec把知识图谱作为可写记忆，以质量门控维护稳定语义关系，并用情景经验记忆记录近期失败与纠正信息。测试期间模型参数冻结，仅更新记忆；在采样候选重排下，Bundle的HR@1相对最强LLM基线最多提升29.58%，ML-100K的HR@5为0.5941，对照K-RagRec为0.4746。

INSIGHT对社区搜索，可将稳定主题偏好与短期查询意图区分存储，让LLM推荐助手通过反馈更新证据而非频繁微调。该论文最值得借鉴的是记忆写入的质量门控和可追溯修改；迁移时应防止错误点击反馈污染长期记忆，并用真实候选池验证nDCG与CTR，不能把采样重排收益直接外推。

Ngoc, Hao Nguyen, Nguyen, Tung, Hanh, Nguyen Thi, Dinh, Hoang Thai, Tung, Nguyen Xuan

04 3.65

RPCBench: A Benchmark for Proactive Premise Critique in LLM-based Recommendation

Jilin University

RPCBench面向LLM推荐助手，检查其能否主动识别用户请求中的错误前提，覆盖5个推荐领域、10类错误和11个模型。实验平均主动检测率为51.51%，综合前提批判能力为0.4376；Qwen3.5-Plus的综合分数最高，为0.5261，说明发现错误比发现后的定位与处理更困难。

INSIGHT社区搜索中的问答式推荐应检查请求是否与帖子、候选和用户证据相符，再给出推荐理由。可用该基准的检测、定位、处理策略与证据忠实度拆分评测，补充nDCG和CTR无法反映的错误前提问题；推理长度需要验证，不能默认让模型多想就能减少错误推荐。

Chen, Zhongru, Wu, Yuan, Chang, Yi
