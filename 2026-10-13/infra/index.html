ReplaySSM: Rethinking State Storage for Faster Hybrid-Model Decoding

ReplaySSM 将混合模型的 SSM 状态表示为高精度检查点与近期输入缓冲区，降低反复读写和投机验证快照的成本。在 B300、批量 256 下，状态核加速 1.46–1.80 倍，完整解码步加速 1.20–1.47 倍；两个 120B 级模型的投机吞吐提升至 1.85–2.10 倍。

并行草稿缺少块内前序 token 的真实信息，会降低投机解码接受率。DCOCO 为各位置保留多个候选，再并行评估相邻候选的上下文兼容性；在 4 个验证器和 10 个基准上，最高达到普通解码的 6.6 倍吞吐，并在 4–32 路并发下比最强对手快 6%–23%。

INSIGHT该方法在保留并行性的同时补回草稿依赖，避免顺序纠错器在并发时重新成为瓶颈。社区搜索的查询改写或摘要服务可将它作为解码层优化，不必改变相关性模型；落地应分别测试短输出、长推理与高并发，确认新增候选评分开销不会抵消接受率收益。

SGLang v0.5.21 Release

SGLang v0.5.21 汇集 779 个 PR、227 位贡献者，支持预填充与解码实例不停机切换，并默认采用 Rust 前缀缓存核心。官方发布说明报告 DeepSeek-V4.1 长提示首 token 快 22%，Kimi K3 在预填充/解码分离服务中的预填充吞吐提高 20.6%；这些是特定配置收益。

INSIGHT社区短文本搜索可先用真实 query 改写和重排提示回放，评估前缀复用、首 token 延迟和弹性切换。动态调整预填充与解码容量适合流量峰谷明显的业务；版本更新涉及并行通信和多种模型适配，应逐模型核对输出一致性，再依据尾延迟与吞吐选择服务参数。

Can we change an AI model’s architecture without retraining it from scratch?

Amazon

Amazon 提出 Priming，从预训练 Transformer 权重初始化混合状态空间模型，减少架构替换后的重新训练成本。文章报告转换成本低于原预训练的 1%，128K 上下文生成速度最高约两倍；可变迭代 GKA 进一步使解码快约 10%，准确率代价约 1%。

INSIGHT借用已训练权重能够降低比较不同注意力与状态空间组合的成本，适合先做受控架构实验。社区搜索服务可针对长帖子聚合和多轮查询开展混合模型试验，但短文本请求未必获得同样收益；需要在相同显存和上下文条件下比较答案质量、首 token 延迟及吞吐，避免只看最长上下文的最佳结果。

Surfing the Activation Wave: Analyzing the Information and Geometry of LLM Hidden States for Speculative Decoding

QualcommStanford

论文用矩阵熵衡量隐藏层信息量、用 CKA 衡量层间冗余，替代 EAGLE3 固定选层规则，并过滤低预测熵 token。在 Qwen3-4B 上，三层 ELSI 的平均接受 token 数比 EAGLE3 提高 1.6%–2.2%；Llama-3.1-8B 上单层达到默认三层约 99% 的块效率。

INSIGHT隐藏层选择应同时看信息量与互补性，层数更多并不保证投机收益。社区搜索的生成服务可离线采集业务 query 的激活，校准草稿输入层，再测接受长度与端到端延迟；论文报告的是接受 token 指标，不能直接当作吞吐提升，且不同骨干的层冗余差异需要重新校准。

Raghavv Goel, Sudhanshu Agrawal, Mukul Gagrani, Risheek Garrepalli, Mingu Lee

RAMP: Recurrent Adaptive Mixed Precision for Efficient Prefill in Recurrent-Depth Language Models

University of Virginia

循环深度语言模型反复处理长上下文，预填充开销随循环增加。RAMP 根据早期量化误差可被后续迭代衰减的观察，在早期使用低精度权重与激活、末期恢复高精度；在最长 4K 上下文与 H100 上保持接近全精度质量，首轮端到端预填充最高加速 1.16 倍，延迟下降 13.9%。

INSIGHT精度预算可以按循环阶段分配，末期高精度用于恢复表示质量。社区 UGC 搜索只有在采用循环深度模型且预填充占比较高时才适合借鉴，应结合实际帖子长度测试首 token 延迟和语义保真度；4K 与 H100 的结果不代表更长上下文或普通 Transformer，也不意味着整体搜索链路同比加速。

Ke Wan, Chen Chen

07 3.45

One Model to Loop Them All: Elastic Latent Recurrence for Language Models

NVIDIA

ELR 用门控状态更新、训练内混合循环数和循环预算条件，使一个模型检查点可按请求切换计算深度。4B 密集与 30B-A3B MoE 模型在 4 次循环时，十任务均分分别增加 7.25 和 4.75 点；复用首轮专家路由使混合深度训练更新快 11.7%，无可测准确率变化。

INSIGHT单检查点覆盖不同推理预算，有助于减少低延迟与高质量模型分别维护的复杂度。社区搜索可按查询难度给解释或答案生成分配循环次数，简单短 query 走单循环；论文主要解决模型训练与架构弹性，应用仍需训练支持，不能将普通现有模型直接改成循环服务，也应评估长尾请求的延迟。

Faisal Ladhak, Shantanu Acharya, Santiago Akle Serano, Simeng Sun, Boris Ginsburg, Krishna C Puvvada

Rethinking the Roles of Diffusion and Decoding: Predictive-State Flows for Parallel Language Generation

Georgia Tech

PSF 将连续扩散的目标从逐 token 潜变量改成块级预测状态，由流先验生成状态后让块因果解码器并行输出各块。OpenWebText 上 197M 模型、8 个块生成 1024 token 消耗 0.31 TFLOPs，困惑度 22.8；ELF-B 对应为 7.2 TFLOPs、24.0，MAUVE 为 0.93 对 0.73。

INSIGHT高层预测状态与具体 token 决策分工可以降低串行深度及扩散成本，值得作为生成基础架构研究方向。社区搜索可关注批量摘要的吞吐潜力，但当前主结果是无条件文本生成，并未证明对 query 改写或 nDCG 有益；接入前应补充条件生成、可控长度和事实准确性评估。

Jinjin He, Xinsong Feng, Lucheng Fu, Sinan Wang, Bo Zhu, Jiayun Wang

AutoIndexer: Flexible-Order Decoding by Training Causal Models on Chains of Edits

Autodesk

AutoIndexer 通过编辑标记和位置游标，把因果模型的生成过程改成可插入、删除和替换的编辑链；训练用逆向扰动构造修复任务，并支持精确 KV 缓存。每类 100 例的编辑诊断中，插入、删除与替换的精确修复为 10、53、18 例，干净草稿正确不修改为 89 例，代码已公开。

INSIGHT可编辑解码让模型不用完全重生成就能修正先前文本，为输出修复服务提供一种底层设计。社区搜索若试验摘要修订，应保留原始帖子事实并设置修改验证；目前插入成功率只有 10%，不能将架构能力视为可靠编辑质量，需要针对 UGC 草稿重新训练和建立逐条修改的回归检查。

OCP Summit 2026: Powering AI with Open Innovations in Scale-Up, Scale-Out, and Scale-Across Networks

Meta

Meta 在 OCP Summit 公布 IcePack 液冷网络机架、102.4T IceCube 交换平台，以及用于 GPU 后端连接的 Flattened Planar Fabric。文章同时介绍开放 MetaRoCE 传输协议和 OSPA 交换平台架构倡议；102.4T 是平台容量规格，文章没有给出可直接映射到搜索业务的 nDCG 或 CTR 实验。

INSIGHT多平面网络、开放传输和液冷协同设计体现了大规模训练集群的网络瓶颈处理方式。社区短文本搜索团队可用作扩容时评估网络与加速器利用率的背景材料；硬件级方案短期接入成本高，应先确认当前训练通信是否饱和，再比较链路吞吐、拥塞和故障恢复，而不将容量规格当作业务收益。
