Auditing Semantic Gains in Sequential Recommendation: A Lightweight Recovery Test

论文提出 LIME-Rec，用可审计的轻量融合检验序列推荐中的语义收益究竟来自何处。系统独立组合 SASRec、ItemCF 共现专家和冻结 BGE item embedding 语义专家，在验证集学习分数融合与有界历史校准，不依赖线上语言模型推理。在 Amazon Beauty、Toys、Sports 上，R@10 分别为 0.0996、0.1105、0.0593，相比最强基线提升 7.0%–12.0%；打乱 item-text 对应关系后 R@10 下降 13.6%–17.5%。

Cautious Context Steering for Language Model Personalization

论文针对个性化模型的数据稀疏和跨域泛化问题，提出 Cautious Context Steering。它在冻结基础模型上增加轻量适配器，逐 token 判断用户上下文是否有帮助以及应施加多强的 steering，并从 oracle context-conditioned 模型学习该决策。单个适配器只用一个数据集训练，却在域内和四个域外个性化基准上提升生成质量，同时避免每用户微调及 Context Steering 每步额外的一次前向计算。

INSIGHT如果社区搜索要对用户生成查询改写、答案或结果解释做个性化，可把用户历史作为可控上下文，而不是为每个用户维护独立 adapter。逐 token 的门控机制能在上下文不可靠时退回基础模型，降低短历史用户的误导风险。工程上应把该适配器放在查询理解或解释生成层，并用用户分桶评估 CTR、满意度和延迟，而不是只看整体语言质量。

Gihoon Kim; Jeyoung Lee; Suhan Woo; Sekwon Oh; Minsu Jeon; Hyounsoo Han; Euntai Kim

03 3.60

Shared-account recommendation with mixture-of-experts

Shandong Normal University

针对共享账户中多人行为序列混合和主导偏好随时间变化的问题，MoE-SAR 用混合专家分解行为序列，动态门控融合专家输出，并以对比学习增强不同个体表示的可分性，再用 Transformer 建模时序偏好。在 HVIDEO 数据集 E 域上，MRR@20 比次优基线提升 24.0%、Recall@20 提升 10.8%；V 域分别提升 8.0% 和 4.7%。

INSIGHTUGC 社区中家庭账号、共享设备或多人共用登录会让用户画像出现混合噪声，单一序列编码器容易把不同人的兴趣平均化。MoE-SAR 的动态路由提供了按行为模式拆分潜在用户的实现路径，可先在活跃度、设备或会话稳定性分桶上做离线验证。落地时要控制专家数量和门控开销，并检查对比学习是否放大少数用户群体的偏差。

岳厚平; 王新华; 郭磊; 刘培玉; 徐连诚
