SearchGym: Bootstrapping Real-World Search Agents via Cost-Effective and High-Fidelity Environment Simulation

论文针对搜索 Agent 强化学习依赖昂贵在线 Web API、离线快照又会产生数据错配和错误奖励的问题，构建了可验证知识图谱与对齐文档语料的 SearchGym 环境。SearchGym-RL 以课程学习逐步训练从基础交互到长程规划的策略；Qwen2.5-7B-Base 在九个基准上相对超过 Web 增强 ASearcher 10.6%，说明高保真模拟可以支撑低成本搜索 Agent 训练。

EfficientTool: A Cost-Effective Aligning Framework for Tool-Conditioned Agents in SME Scenarios

EfficientTool 面向数据和算力有限的企业 Agent，对工具调用对齐提出闭环方案：先自举生成高质量轨迹，再用工具条件化的参数高效微调迭代训练，最后用部署导向的交互评测反馈下一轮数据。论文在公开、私有基准及企业内部 Agent 上验证了工具能力提升，并保持了通用工具调用能力。

INSIGHT社区搜索可以把 query 改写、召回、重排和证据查看统一为工具轨迹，优先用 PEFT 和自举数据做小步迭代，而不是一开始训练大模型。落地时应同时保留通用工具测试集，避免只优化少数搜索模板导致 Agent 在真实 UGC 查询上的泛化能力下降。

Yuanqi Mu, Bingfeng Pi, Defei Xia, Lei Zuo, Yongqi Zhang

CostBench: Evaluating Multi-Turn Cost-Optimal Planning and Adaptation in Dynamic Environments for LLM Tool-Use Agents

CostBench 将 Agent 评测从任务是否完成扩展到是否选择成本最优路径，并模拟工具失败、价格变化等动态阻断事件。其旅行规划任务由原子和组合工具构成，结果显示即使 GPT-5 在最难静态任务上的精确匹配率也低于 75%，进入动态环境后性能继续明显下降。

INSIGHT搜索 Agent 的线上目标不应只有 nDCG、答案正确率，还应记录搜索轮数、候选文档数、Token、延迟和失败重试成本。可以把短文本 UGC 搜索拆成低成本首轮召回、按不确定性触发扩展、证据不足才继续检索的策略，并用动态工具故障和流量峰值压测重规划能力。

Jiayu Liu, Cheng Qian, Zhaochen Su, Qing Zong, Shijue Huang, Bingxiang He, Yi R. Fung

AgentGym2: Benchmarking Large Language Model Agents in De-Idealized Real-World Environments

AgentGym2 关注 Agent 在非理想化真实环境中的评测，强调任务变化、工具失败和不确定性，而不是只在静态、顺利的流程中统计成功率。该基准为规划和工具使用提供更接近生产的压力条件，适合检查多轮搜索、异常恢复以及环境变化下的行为稳定性。

INSIGHT在社区搜索中，评测集应加入歧义短 query、内容下架、召回为空、工具超时、用户改写和证据互相矛盾等情形。把一次成功回答拆成检索决策、证据覆盖、停止判断和恢复动作四类指标，才能区分模型聪明与系统偶然命中。

When Efficiency Becomes a Vulnerability: Computational Cost Attacks on WebAgents

论文提出计算成本攻击：攻击者把恶意提示注入网页内容，诱导 WebAgent 生成过长推理轨迹，却不一定降低任务成功率。CostBomb 用大模型生成候选攻击，再用强化学习增强的选择器筛出有效扰动；多个真实 Web 基准显示 Agent 会出现显著额外计算开销。

INSIGHT搜索结果页和 UGC 内容都应被视为不可信输入，不能让页面指令无条件改变 Agent 的预算和工具权限。生产系统需要设置步数、Token、单域名访问和重试上限，并监控成功率不变但成本飙升的异常；可把成本攻击样本加入安全回归集。

How HSP GRUPPE builds AI capabilities for tax advisory

OpenAI

OpenAI 介绍 HSP GRUPPE 在税务咨询中使用 ChatGPT Enterprise 的业务实践，重点是提升员工效率、工作质量和客户服务容量。该案例不是专门的搜索 Agent 论文，但展示了知识密集型业务如何把模型能力嵌入日常工作流，并以可交付结果而非单纯模型指标衡量价值。

INSIGHT社区搜索 Agent 的验证也应从模型分数延伸到业务闭环，例如有效搜索率、人工改写率、处理时长和用户后续点击。先选择高频、可审计的知识任务做小范围试点，再逐步开放多步工具调用，可降低 UGC 噪声和错误答案对用户体验的影响。

Responding to the next frontier of critical cyber capabilities

OpenAI

OpenAI 分享 Astra 的初步网络安全评测和安全控制工作，关注更强 Agent 能力带来的风险边界与防护要求。虽然内容聚焦网络安全而非搜索排序，但它提醒 Agent 系统必须把能力评估、滥用测试和防护控制作为上线流程的一部分，而不能只追求任务完成率。

INSIGHT搜索 Agent 的工具权限、网页访问和数据读写应采用最小权限与可撤销策略，并将提示注入、越权调用、敏感信息泄露纳入回归评测。对 UGC 平台尤其要区分内容理解权限和执行权限，避免一条恶意帖子同时影响检索、决策和外部操作。

Expressive Temporal Specifications for Reward Monitoring.

已录用 AAAI 2026

论文研究用表达能力更强的时间逻辑规格描述和监控奖励信号，使系统能够检查行为是否按时间顺序满足约束。它适合 Agent 规划和强化学习中的过程监督场景，可用于表达先检索、再验证、最后回答等阶段性要求，而不只对最终奖励做一次判断。

INSIGHT社区搜索 Agent 可以把证据覆盖、敏感内容过滤、查询预算和最终回答之间的先后关系写成可执行监控规则。这样能把线上策略从难以解释的总分约束，转为可定位的过程约束，并为多步检索的奖励塑形和异常回放提供统一接口。

La VIDA: Towards a Motivated Goal Reasoning Agent (Abstract Reprint).

La VIDA 探索具备动机和目标推理能力的 Agent，核心关注如何从目标、状态和行动之间形成持续的任务驱动，而非只对单轮指令给出反应。当前候选为 AAAI 的摘要重印条目，细节有限，因此更适合作为目标管理与搜索规划方向的线索，而不是直接采用的完整方案。

INSIGHT对复杂 UGC 搜索，可以把用户的真实目标、已获得证据和未解决子问题显式维护在状态中，再决定是否继续搜索或结束。实践时应先用规则和可观测状态约束目标漂移，避免把不透明的动机推理直接接入线上排序链路。

Ursula Addison
