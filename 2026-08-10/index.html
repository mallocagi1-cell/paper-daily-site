From Understanding to Action: Feedback-Grounded Policy Discovery for Generative Recommendation

论文指出，Semantic ID 生成器能捕捉行为共现，却缺少“当前需求下应该推荐什么”的策略知识。方法先由反馈驱动的智能体区分用户意图与推荐策略，再通过双空间关系蒸馏把两类知识压缩成轻量生成器的两个潜变量，线上无需调用 LLM。公开基准持续优于基线，大规模 A/B 测试带来 Revenue +4.506%、ADVV +4.621%。

Interpretable Representation via LLM-Driven Generative Disentanglement for Local-Life Service Recommendation

LGRID 针对 Semantic ID 将地理、品牌、类目等属性纠缠在单一表示中，导致量化信息损失和 ID 碰撞的问题，提出 Encode→Disentangle→Align→Quantize 流程。结构化解耦块把隐状态路由到属性槽位，双流残差量化分别编码地理和语义因素。在 Kuaishou 与 Foursquare 数据上，AUC 相对提升最高 5.44%，粗粒度地理属性解码准确率超过 99%，完整 SID 碰撞率从 LGSID 的 97.0% 降至 39.9%。

INSIGHT短文本社区搜索里的地点、话题和实体属性同样容易在统一 embedding 中互相污染。可借鉴 LGRID 的属性对齐 SID：保留可解释的地理/语义子空间，并把碰撞率、属性解码准确率作为离线门槛，再与 nDCG、CTR 联合评估，避免只看生成命中率。

Long Zhang, Hao Jiang, Sheng Yu, Fei Pan, Peng Jiang, Kun Gai

03 4.45

LoopMemGR: From Behavior Logs to Evolving Memory for Generative Recommendation

LoopMemGR 认为，传统生成式推荐只记录用户做过什么，却丢掉系统推荐过什么、用户如何反馈以及哪些探索已被验证。它新增推荐体验日志，从近期性、频次和全局规律三个视角抽取证据，再压缩成固定数量的 experience tokens，在有界上下文内持续调节生成器。论文在工业 Taobao 数据集上验证了闭环记忆和多视角抽取的有效性。

INSIGHT社区搜索的会话记忆不能只保存 query 和点击，还应记录已展示的候选、跳过结果和后续反馈，否则生成器会反复探索同一批内容。实践上可先把推荐体验日志作为独立特征层，分别做 recency/frequency/global 聚合，再通过固定 token 预算接入生成式召回，以控制延迟和上下文膨胀。

Hui Qian, Changfa Wu, Chang Liu, Binbin Cao, Jian Wu, Yuliang Yan, Han Zhu, Bo Zheng

MTGR：美团外卖生成式推荐Scaling Law落地实践

Meituan📖 深度解读 · 14 分钟 →

美团外卖把排序模型换成 Meta 的 HSTU 生成式架构，但没有照搬，而是保留了全部交叉特征，并把同一用户一天的曝光压成一行训练。单样本计算量涨到 65 倍，靠这种压缩和长度采样，训练成本与旧模型持平；首页订单量提升 1.22%。不过 Scaling 证据只有三个尺寸，线上点击率也不随尺寸单调。复购型业务换生成式架构时，交叉特征不能丢。

Hierarchical Latent Reasoning for LLM-based Recommendation

HiLaR 针对显式 Chain-of-Thought 推理过长、固定模板难以适应动态兴趣的问题，构造时间引导的层次化用户偏好，并将其对齐到多个 LLM 隐式推理状态。训练阶段使用基于目标概率边际增益的分层过程奖励，推动模型从宽泛偏好逐步收敛到当前意图。论文在 4 个 Amazon 基准上进行对比、消融和敏感性分析，验证层次表示、潜变量对齐和过程优化的作用。

INSIGHT在 UGC 搜索里，长 CoT 往往带来不可接受的 P99 延迟；HiLaR 的层次化 latent state 提供了压缩推理路径。落地时可让粗粒度兴趣负责召回、细粒度当前意图负责重排，并用目标概率增益而非自然语言长度监督中间状态，降低推理 token 和线上成本。

RecoReward: Recommender-Guided Multimodal Description Generation for Recommendation

RecoReward 用行为反馈反向训练多模态 LLM 生成商品描述：历史高互动用户作为潜在目标用户，非目标用户用于估计广泛共享的偏好，再以 Recommender Affinity Score 形成强化学习信号。这样训练出的描述不需要携带用户信息，仍可在内容侧离线生成。RecoReward-9B 在 7 个召回指标上优于 Qwen3.5-9B 和其他基线，并报告了线上 A/B 增益。

INSIGHT社区帖子和评论的摘要、标签、标题生成可以从“语言质量最优”改为“下游检索收益最优”。可把点击、停留、收藏等行为转成内容生成的奖励，离线产出稳定的 query-facing 描述，线上仍用普通倒排/向量索引服务，兼顾语义召回收益与推理时延。

Guohong Mu, Yueyang Liu, Jiangxia Cao, Changxin Lao, Zijie Zhuang, Yuhui Zhang, Jiaqi Feng 等 12 人
