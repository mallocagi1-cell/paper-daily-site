SCOReD: Student-Aware CoT Optimization for Recommendation Distillation

论文聚焦推荐场景中的 CoT 蒸馏，指出大教师模型的推理轨迹存在反复检查、答案不修正、长度过长和小学生模型分布外等问题。SCOReD 先把教师推理拆成 typed segments，再用学生模型注意力和答案 log probability lift 决定 KEEP、REWRITE、FUSE、PRUNE。相较 baseline SFT，训练后的学生模型 NDCG 提升 1.56%、Recall@5 提升 1.9%，同时推理长度减少 27.3%。

InfluMatch: Frontier-Quality KOL Search at 4B-Model Cost

InfluMatch 面向 KOL 与多条件营销需求匹配，构建 retrieval -> rerank -> reason 的三级级联：稠密召回返回 50 个候选，4B pointwise reranker 用单个 Yes token 的 log probability 保留 10 个，再由 4B reasoner 按准则打分并给出泰语理由。在 11 个 query、每个 50 候选的人工标注集上，系统 P@5 达到 94.1%，超过检索-only 近随机基线，并匹配 Kimi-K2.6 的 91.8%，输出 token 约少 35 倍。

INSIGHT这篇工作把个性化匹配拆成低成本级联，对 UGC 社区的达人、作者、帖子推荐很有参考价值：先用便宜召回扩大覆盖，再把昂贵推理限制在 top-10。它还提示 fine-tuning 位置很重要，SimPO 调 reranker 可达到 78.0 EM 的 best-pick accuracy，而 pointwise 调 reasoner 反而伤害端到端排序，说明排序目标要贴近最终选择任务。

When Should LLMs Search? Counterfactual Supervision for Search Routing

论文研究搜索增强模型何时应该调用外部搜索，方法是对同一问题比较 no-search 与 forced-search 结果，构造 NO SEARCH、SEARCH、UNSOLVED 的反事实 oracle，再用它训练 routing policy。实验把 oracle-eligible 样本的 macro-F1 从 0.7082 提升到 0.8235（Gemma E2B），从 0.7053 提升到 0.8365（Qwen3.5-4B）。分析显示 Gemma 主要学会减少不必要搜索，Qwen 则更多减少漏搜。

INSIGHT对个性化搜索和推荐解释链路，搜索/特征扩展不应是固定开关，而应由“是否能改善当前样本结果”的反事实收益驱动。社区搜索中很多短 query 已可由用户画像和语义召回回答，盲目扩展会引入噪声；该框架可迁移为 query 级、用户级的检索深度和画像调用路由器，用于控制延迟和相关性风险。

PORTS: Preference-Optimized Retrievers for Tool Selection with Large Language Models

PORTS 解决 LLM 工具选择中“检索器与下游工具调用目标不一致”的问题，用冻结 LLM 的 perplexity-inspired preference signal 训练检索器。方法通过 odds ratio preference optimization 对齐工具选择概率与下游执行效果，同时加入文档字符串之间的 contrastive semantic loss。论文在 6 个数据集、2 个 encoder 和 3 个不同先验知识的 LLM 上验证，强调低计算成本和对新 query、新工具的泛化。

INSIGHT虽然对象是工具检索，但它的偏好优化思路可迁移到推荐候选召回：召回器不只拟合语义相似，还要拟合下游排序/点击收益。对 UGC 搜索推荐，可以用冻结排序器或 LLM 评估器产生偏好信号，训练召回模型更接近最终 CTR、nDCG 或满意度目标，减少召回和精排之间的目标错位。

Lorenzo Molfetta, Giacomo Frisoni, Nicol\`o Monaldini, Gianluca Moro

快手

这篇行业报道来自快手推荐模型相关技术分享，核心是把生成式推荐与排序模型结合，探索 OneReason 将大模型推理能力引入推荐决策。文章关注用户行为理解、候选生成、排序决策从传统打分逻辑向推理式推荐迁移，适合观察国内短视频推荐团队在 2026 年的工程路线。公开材料没有给出完整离线表格或 A/B 数字，因此证据质量低于正式论文。

INSIGHT对社区个性化推荐的启发是：大模型不一定直接替代 CTR/CVR 模型，更可能先进入“理解用户意图、解释候选价值、辅助排序决策”的中间层。实践上应优先选择可灰度的链路，如用户兴趣摘要、候选重排理由、冷启动内容理解，而不是一次性重写线上精排；同时需要用真实点击、停留和负反馈约束推理输出。

Learn to Pool: Lightweight Fine-Tuning for Flexible Multi-Vector Compression

Learn to Pool 针对 late interaction 检索模型的部署成本，提出轻量 pooling-aware fine-tuning，让多向量文档表示在不同压缩率下保持效果。作者发现即使最小量的 k-means pooling 感知训练，也能优于纯 inference-time pooling，并能跨 pooling 方法和数据集迁移。最强模型在 BEIR SciFact 的 pool factors 1-6 上超过未池化 baseline，相当于在不损害检索准确率的前提下实现 83% 向量压缩。

INSIGHT个性化搜索/推荐系统常受向量存储和内存带宽限制，尤其是 UGC 长尾内容和多向量召回。该方法说明压缩策略最好进入训练目标，而不是上线前机械降维；如果线上使用 ColBERT 类 late interaction，可用小规模微调获得多压缩级别通用模型，在召回质量和成本之间做动态调节。

Retrieving a Set, Not Independent Passages: Set-Level Compatibility Learning for Efficient Set Exploration

论文把多跳检索从“独立段落打分”改成 query-set compatibility scoring，训练检索器把完整且兼容的证据集合排在不完整、噪声集合前。实现包含两个互补 scorer：ParaSet 用预计算 bi-encoder embedding 上的 self-attention 做轻量 late interaction，SetCE 用 cross-encoder 做集合级 rerank。多个 multi-hop QA benchmark 显示集合兼容学习提升检索和下游 QA，且两个检索器组合比单一路径多取段落更强。

INSIGHT对社区搜索的长 query、问答和多条件推荐，这篇工作提醒候选之间存在组合价值：单个帖子相关不代表一组内容能完整满足需求。可借鉴其 set-level objective 做多样性重排、专题页组装或多证据回答，把“覆盖不同意图且互相补足”纳入排序目标，而不是只叠加独立相关性分数。

Mooho Song, Jay-Yoon Lee

Quantifying and Expanding the Theoretical Capacity of Late-Interaction Retrieval Models

论文从理论上分析 late-interaction / MaxSim 检索模型的表示能力，证明 MaxSim 可用 O(k) 表示空间精确复现任意非负 k-sparse 向量内积，并能表达同等空间标准内积无法表达的相似度。作者提出 Signed MaxSim，使 late interaction 能复现任意实值内积，并展示 MaxSim 可解释为 soft-OR 聚合和正 CNF 逻辑表达式评估。在含否定 query 的检索任务上，Signed MaxSim 的 nDCG@10 从 0.597 提升到 1.000，negation-only query 从 0.008 提升到 0.788。

INSIGHTUGC 搜索里常见“不要某类内容”“非广告”“非教程”等否定意图，普通向量内积很容易把正相关内容误召回。Signed MaxSim 的价值在于给 late interaction 加入负向匹配能力，从模型结构上表达排除条件；这对个性化过滤、用户不感兴趣主题和安全偏好约束都有可迁移意义。

Julian Killingback, Varad Ingale, Hamed Zamani, Cameron Musco

DynaKRAG: A Unified Framework for Learnable Evidence Control in Multi-Hop Retrieval-Augmented Generation

DynaKRAG 把多跳 RAG 的证据获取建模为 state-conditioned control：每一步根据当前证据状态生成可执行动作集合，再由学习控制器选择检索、改写、批判或充分性判断等原子操作。使用 Qwen2.5-7B-Instruct 时，HotpotQA、2Wiki、MuSiQue 的 F1 分别达到 0.5998、0.5340、0.3061，优于最强 controlled baseline。去掉学习控制器改用 uniform-valid policy 会降低 3.96-5.78 个 F1 点，去掉 sufficiency feedback 三个数据集都下降。

INSIGHT这篇工作虽偏 RAG，但对搜索推荐链路有工程启发：复杂请求需要动态决定下一步操作，而不是固定召回-重排模板。社区问答、攻略搜索和个性化推荐解释可以把“是否继续检索、是否改写 query、是否已有足够证据”做成状态机加学习控制器，避免无效扩召和重复证据拖慢响应。

Faithful or Findable? Evaluating LLM-Generated Metadata for RDF Dataset Search

论文评估 LLM 生成元数据对 RDF dataset search 的影响，比较 6 种元数据生成设置，从简单 rewriting 到 profile-grounded 和 agentic graph-based generation。结果显示 unconstrained metadata rewriting 带来最强检索增益，但也是最不 faithful 的方案，说明搜索提升可能来自无依据的语义扩展。更 grounded 的设置明显改善 faithfulness，其中 profile-grounded rewriting 在检索效果与可追溯性之间最均衡。

INSIGHT对 UGC 社区内容理解，这篇工作提醒“让 LLM 给帖子补标签/摘要”会同时影响可发现性和真实性。个性化推荐可使用 profile-grounded 的补充元数据提升召回，但必须保留来源约束和事实校验，否则模型生成的标签可能短期提高点击，长期损害信任、误导排序特征，并污染训练样本。

Riccardo Terrenzi, Serkan Ayvaz
