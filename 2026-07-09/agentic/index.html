SearchEyes: Towards Frontier Multimodal Deep Search Intelligence via Search World Simulation

这篇论文面向多模态深度搜索智能体，解决训练数据、搜索环境、奖励信号各自割裂导致多跳推理难以稳定优化的问题。方法用类型化知识图谱构造可复现的模拟搜索世界，借助 Perception-Knowledge Chains 采样视觉知识交叉路径，并用 Hop-Anchored Policy Optimization 做步级奖励归因。在 6 个多模态知识密集基准上，SearchEyes-27B 相比最强开源基线平均提升 6.2 分，给出了可量化的训练收益。

CurateEvo: Data-Curation Evolving for Agentic Post-Training

CurateEvo 针对长程智能体后训练中“数据清洗策略固定、无法随失败模式演化”的问题，把数据整理策略表示为可执行代码，并利用 held-out 失败轨迹逐轮重写。每个 epoch 会把同一份原始语料转成 SFT 数据、RL 数据和推理期 memory bank，同时用成本感知目标剪掉冗余训练轮次。在 ACEBench-Agent、BFCL-V4 和 tau2-Bench 上，标注数据与野生数据两种设置分别平均提升 3.2 和 2.7 分。

INSIGHT它把数据 curation 从离线预处理变成闭环控制器：先诊断 agent 经常失败的工具调用、检索或多步决策模式，再决定增强、过滤还是精炼样本。对搜推 Agent 团队，实践价值在于可以把线上失败 query、低质量检索轨迹和人工反馈转成下一轮训练数据，而不是只扩大样本量；成本感知剪枝也能避免长轨迹训练把预算消耗在低价值尾部 turn。

Dingzirui Wang, Xuanliang Zhang, Keyan Xu, Qingfu Zhu, Wanxiang Che

TurnOPD: Making On-Policy Distillation Turn-Aware for Efficient Long-Horizon Agent Training

Tencent

TurnOPD 关注长程智能体训练中的 on-policy distillation 低效问题：完整轨迹 rollout 会在尾部 turn 浪费墙钟时间，trajectory-level KL 又把损失集中在浅层 token。论文提出两个 turn 级预算控制器，分别自适应决定 rollout 深度，并逐步把 KL 权重从 token 级转向 turn-balanced 监督。在 ALFWorld、WebShop 和 Multi-Hop Search 上，同等训练时间下验证准确率更高，并推进 accuracy-time frontier。

INSIGHT这对搜索 Agent 很直接：训练预算应围绕“决策 turn”分配，而不是围绕整段文本平均分配。多跳搜索、购物搜索和工具调用任务通常只有少数关键节点决定成败，TurnOPD 的 probe 统计和 turn-normalized loss 可以帮助团队把教师模型能力蒸馏到这些关键节点，减少长轨迹尾部噪声对学生模型的干扰。

Yuhang Zhou, Kai Zheng, Haoling Li, Dengyun Peng, Can Xu

Memory in the Loop: In-Process Retrieval as ExtendedWorking Memory for Language Agents

SStevens

论文研究把记忆从“每轮最多查一次的外部工具”移动到 agent observe-reason-act 循环内部，每一步都可读写。作者指出网络化 memory store 会让端到端延迟最高膨胀 83 倍，而进程内 store 可在约 100 微秒返回；在固定 memory-latency 预算下，冗余动作从进程内速度的 0.0/12 上升到 110ms 云往返的 7.2/12。跨 4 个 GPT-5 级模型实验中，in-loop memory 将 recall 从 0/5 提升到 3.6-4.8/5，244/244 次写入未丢失。

INSIGHT它把 Agent 记忆的瓶颈定位到“存储位置和嵌入延迟”，而不是单纯的 prompt 设计。对社区搜索中的会话式搜索、连续追问和个性化重排，低延迟内嵌记忆意味着模型可以在每个推理步检查用户上下文、历史点击和检索证据；但论文也提醒，miss 主要来自 agent 的 read policy，因此要同时训练何时读取、读取什么，而不是只换更快的向量库。

Yusuf Khan; Carlo Lipizzi

SWE-Review: Closing the Loop on Issue Resolution with Agentic Code Review

NTUHuaweiHKU

SWE-Review 把代码智能体从一次性生成 PR 扩展为 generate-review-revise 闭环：reviewer agent 会探索仓库、判断候选 PR 是否应合并，并输出可执行的修复诊断。论文构建 1,384 个候选 PR 的 SWE-Review-Bench 和 SWE-Review-Traj 轨迹数据；扩展分析显示 Claude Opus 4.6 以 24.1 平均步骤、1.3 个文件和 148K token 达到 81.8% DA，而 SWE-Review-8B 用 57.3 步、5.0 个文件和 2.36M token 仅达 69.1% DA。

INSIGHT虽然任务是代码评审，但方法对搜索 Agent 很有借鉴意义：高质量探索不是多读文件或多调用工具，而是精准定位验证点。对于 Deep Search 或复杂问答，可以复用“生成候选答案-审查证据链-请求修订”的闭环，把 reviewer 设计成事实核验和证据覆盖检查器，从而减少一次性回答里的幻觉和漏证据问题。

Ruoyu Wang, Jierun Chen, Shaowei Wang, Chaofan Tao, Sidi Yang

From Passive Retrieval to Active Memory Navigation: Learning to Use Memory as a Structured Action Space

Alibaba

NapMem 关注长期用户记忆在个性化对话智能体中的使用方式：多数系统把记忆作为被动检索上下文，模型只能消费预选证据。论文将长期记忆建模为结构化 action space，让 agent 学习主动导航、选择和更新记忆，而不是依赖固定 retriever。该方向与 Qwen/阿里大模型团队相关，核心价值在于把 memory access 从“召回模块”升级为可学习的决策过程。

INSIGHT对 UGC 搜索和推荐，长期兴趣、历史 query、点击反馈本质上也是可操作的记忆空间。相比一次性拼接用户画像，主动记忆导航允许 Agent 在多轮搜索中决定先查短期意图、再查长期偏好、最后查历史负反馈；这能减少无关画像污染，也为个性化搜索里的可解释证据链提供更清晰的动作轨迹。

Narrative World Model: Narratology-Grounded Writer Memory for Long-Form Fiction

NWM 面向长篇小说写作记忆，解决通用检索和 agent memory 只记录实体事实、无法回答叙事结构问题的缺陷，例如谁何时知道秘密、事件是否早于揭示、关系如何变化。方法把 narratology-grounded typed temporal-state graph 与 query-conditioned hybrid retrieval 结合，并用固定 Opus 4.8 reader 在 chapter-safe evidence 上评测。论文称 NWM 在两个语料的多跳叙事 QA 上显著优于 Graphiti/Zep、GraphRAG 和 flat retrieval，且优势来自结构表示和查询条件检索，而非抽取器质量或图规模。

INSIGHT虽然业务域不是搜索推荐，但它提供了一个有用模式：当查询依赖时间、状态转移和关系演化时，普通向量召回不够，需要领域类型图约束证据。社区内容搜索同样会遇到帖子事件线、用户关系、观点变化等问题；NWM 的 typed temporal-state graph 可转化为“内容事件图+用户状态图”，帮助 Agent 做多跳证据追踪。

Flint: A visualization language for the AI era

Microsoft

Microsoft Research 的 Flint 是面向 AI Agent 的可视化中间语言，目标是在简短、可编辑规格和完整 Vega-Lite 复杂配置之间取得平衡，让智能体更稳定地生成图表。研究把 Flint 与 DirectVL 基线比较，后者让模型直接生成完整 Vega-Lite；在 Tidy Tuesdays 测试数据和 LLM self-evaluation 中，Flint 在 GPT-5.1 上得分 16.27 vs. 15.91，在 GPT-5-mini 上 16.16 vs. 15.60，在 GPT-4.1 上 15.91 vs. 15.34。

INSIGHT这是一篇工程实践而非论文，但对搜索/推荐运营分析有现实价值：Agent 不应直接生成复杂低层配置，而应操作更贴近业务语义的中间表示。把这个思想迁移到搜推系统，可以为“生成实验看板、解释召回/排序指标、对比 query 分桶”设计结构化 DSL，让模型输出更可控、可审计，也方便人工二次编辑。

LLM Agents for Deliberative Collaboration: A Study on Joint Decision Making Under Partial Observability

论文研究部分可观测联合决策中的 LLM deliberative agents，把协作形式化为带共享奖励、局部且非对称观测的 cooperative joint decision problem。作者构建了可扩展 benchmark、参考 scaffold 和评估协议，覆盖多个任务和领域，要求 agent 通过 deliberation 对齐信息并做出共同决策。实验显示，即使使用外部数学工具，当前 SOTA 模型仍会在信息对齐或复杂推理上失败；但诊断分析也发现 deliberation 有时能通过反思和纠错超过 centralized baseline。

INSIGHT对多 Agent 搜索系统，关键问题不是让每个 Agent 都更强，而是让它们在证据不完整时有效共享不确定性和中间发现。论文的 partial observability 设定贴近真实搜推排障：召回、排序、内容理解、风控各自只看到一部分日志；deliberation 协议可用于设计跨模块诊断 Agent，要求它们先交换证据再给出统一决策。

Chenxu Wang, Yongkun Yang, Boyuan Du, Shiwei Lin, Huaping Liu

Image2Sim: Scaling Embodied Navigation via Generative Neural Simulator

NUS

Image2Sim 面向具身导航智能体，解决真实扫描数据规模有限、传统合成模拟器 sim-to-real gap 大的问题。它从 posed RGB-D 图像构建实时 neural simulation，并提出 Geometry-Aware One-Step Pixel Flow，把稀疏噪声 Gaussian projections 转成高质量全景 RGB-D 观察。系统还作为自动化数据引擎，将大规模视频和图像转换为近 20K 个交互场景，并合成超过 1000 万条导航训练样本。

INSIGHT它与文本搜索的直接相关性较弱，但对“环境可模拟、轨迹可生成、动作可执行”的 Agent 训练很有参考价值。搜索 Agent 也缺少可复现环境，常依赖线上搜索引擎和稀疏最终答案奖励；Image2Sim 的思路提示我们可以构建 query-session simulator，把页面、点击、反馈和任务目标合成为可训练环境，再用大规模轨迹训练策略。

Zihan Wang, Seungjun Lee, Yinghao Xu, Gim Hee Lee
