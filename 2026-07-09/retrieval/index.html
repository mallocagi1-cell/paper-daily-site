Revisiting Text Ranking in Deep Research

这篇 SIGIR 2026 论文把 deep research 场景中的“搜索组件”从黑盒 API 中拆出来系统评测，比较文档级/段落级检索单元、5 类检索器和 3 类重排器。实验在 BrowseComp-Plus 上显示，段落级 BM25 加 monoT5-3B 重排达到 0.716 recall 和 0.689 accuracy，接近 GPT-5 agent 的 0.701 accuracy；同时 Q2Q 查询改写能缓解 agent 查询与神经排序器训练查询之间的分布错配。

Scientific Code Search at Scale: A Multi-Domain Dataset and Benchmark

论文面向科学代码发现这一垂直搜索问题，指出通用代码搜索基准不能覆盖科研领域术语和任务需求。作者构建 5,264 个高质量、按 NASA 五个科学部门分类的开源仓库语料，并提出两个 IR 基准：219 个领域专家查询的仓库搜索任务，以及覆盖 7 种编程语言的 117,950 个代码片段和 119,720 个查询的大规模片段检索任务；基线结果显示不同科学领域和代码规范会显著影响检索效果。

INSIGHT它的价值不只在科学代码搜索，也提示 UGC/社区搜索应按领域构造“真实意图查询+领域语料”的评测集，而不是只复用通用 BEIR/MS MARCO 指标。对于短文本社区内容，类似做法可以把垂类术语、作者上下文、标签和外链上下文纳入索引与评测，让召回模型在真实业务语言上暴露问题。

OrchANN: Hierarchical Orchestration for Skewed Out-of-Core Vector Search

OrchANN 关注十亿级向量检索在内存不足时退化成 out-of-core ANNS 的问题：向量集合和索引超过 DRAM 后，查询延迟主要由 SSD 访问和 DRAM-SSD 数据搬运决定。它用不重叠 SSD 分区、scale-aware indexes 和内存中的图抽象来提供逻辑重叠，并在服务阶段依据 query hotness 与 cluster priority 剪枝低价值分区；在 5 个数据集和严格内存约束下，相比 SOTA 基线最高实现 17.2x QPS 提升和 25.0x 延迟降低，同时保持准确率。

INSIGHT对高并发社区搜索的语义召回层，这篇论文提供了比“简单加机器”更细的系统设计思路：把物理分区做成无重叠以控制 SSD 体积，用内存图恢复查询路由的覆盖能力，再按热点查询动态减少无效 I/O。它适合用于超大 embedding 索引、冷数据召回和成本敏感的长尾内容库。

CMDR: Contextual Multimodal Document Retrieval

CMDR 提出上下文多模态文档检索任务，针对现有页面检索只做独立页面编码、难以回答跨页聚合查询的问题。作者构建 CMDR-Bench，并提出 CMDR-Embed：联合编码多页上下文，再从共享上下文表示中派生页面级 embedding；训练上使用 CMCL 上下文多模态对比学习，在保持页面区分度的同时注入文档上下文，实验表明它显著优于非上下文 embedding。

INSIGHT如果社区搜索包含帖子长链、图文混排笔记或问答楼层，单页/单 chunk embedding 容易丢掉上下文。CMDR 的设计说明可以在召回阶段把相邻页面、图文块或楼层共同编码，再输出可检索的局部向量，从而兼顾上下文理解和页面级命中，适合作为多模态 UGC 搜索的评测与模型方向。

Ryota Tanaka, Taku Hasegawa, Kyosuke Nishida

Hybrid RAG: Dense and Sparse Retrieval for Better AI Answers

AAtlan

这篇工程指南把 hybrid RAG 定义为 dense vector search 与 sparse BM25/TF-IDF 并行召回后再融合的生产检索架构，重点解释 RRF 融合为何比直接分数加权更稳。文章给出一组实践指标：hybrid 相比 dense-only 在混合查询基准上提升 26%–31% NDCG，recall@1000 从约 0.87 提升到 0.98；加入受治理的 metadata 后，检索准确率从 33% 提升到 55%。

INSIGHT它对 UGC 搜索的实践意义很直接：社区查询既有语义型表达，也有昵称、品牌、地点、梗和错误码式精确词，dense-only 很容易漏掉后者。上线新 embedding 或 RAG 检索时，应把 BM25/SPLADE 与 dense recall 作为默认双路召回，用 RRF 做稳健融合，再用真实查询日志验证 exact-term 与 semantic query 两端的收益。

Emily Winks

Query rewriting for RAG: how to improve retrieval accuracy

Meilisearch

Meilisearch 这篇工程文章聚焦 RAG/搜索中的查询改写，问题是用户原始表达往往和知识库语言不匹配，导致召回无关文档并放大幻觉。文章梳理 template rewriting、multi-query generation、query transformation、query expansion 与 reranking 的差异，并把查询改写放在检索前，用于提升召回覆盖和让用户意图更贴近语料表达。

INSIGHT社区短文本搜索里，同义词、口语缩写、错别字和隐含意图非常常见，查询改写比单纯增大 embedding 模型更容易快速试点。可落地的做法是先对高频 bad case 做多查询生成和词面扩展，再用重排器校准精度，同时监控改写是否引入过宽召回，避免 CTR 被噪声候选稀释。

Maya Shin

Uncertainty-Aware Cross-Modal Remote Sensing Image-Text Retrieval via Evidential Learning

这篇论文研究遥感图文跨模态检索在真实测试条件下的不确定性问题：传感器、气象扰动和遥感词汇差异会让模型在错误结果上仍给出高置信度。作者提出 ELC，用 evidential learning 将图文对应关系建模为 Dirichlet 分布，从中估计每个查询的不确定性；再用 UCL 对齐不确定性与检索正确性，并在测试阶段把高不确定查询交给 RS-aware test-time augmentation 精修。

INSIGHT虽然场景是遥感，但机制可迁移到社区图文搜索：模型不应对每个查询都同等自信，尤其是低质图片、冷门词和多义 query。检索链路可以输出 uncertainty，用于决定是否触发更重的多模态重排、查询扩展或人工兜底，从而把算力集中在最容易错的请求上。

Zhuoyue Wang, Xueqian Wang, Gang Li, Chengxi Li, Yongpan Liu, Yifang Ban

Linking Hadith Narrator Identities Across Heterogeneous Arabic Biographical Databases: A Multi-Signal Entity Resolution Pipeline

论文面向伊斯兰 Hadith 文献中的叙述者身份链接问题，构建两阶段多信号实体消歧流水线。第一阶段只用姓名相似度把 Sanadset 650K 中 185,216 个姓名变体链接到 Hawramani 数据库，得到 94,628 条链接；第二阶段结合姓名相似、死亡年份接近度和可靠性等级极性，把 Hawramani 与 Muslimscholars 交叉引用，得到 95,573 条链接，覆盖 Hawramani 的 94.7%。

INSIGHT对社区搜索的迁移点在于实体归一化：用户、地点、品牌和作品名经常有多种写法，单靠 embedding 相似度不够稳定。该论文展示了可解释的多信号链接方式，适合作为 query understanding 前置模块，把名称变体、时间属性和可信度信号融合后再进入召回/排序。

Taufiq Wirahman

Text Distance from Nested and Hierarchical Repetitions: A Compression-Based Perspective

这篇论文从算法信息论出发提出 Ladderpath 方法，用嵌套和层级重复结构来刻画文本序列，并基于这些结构定义三种距离：标准化压缩距离 NCD 以及两个由 Ladderpath 表示直接派生的距离。作者把这些距离接入 kNN 分类器，在分布内、OOD 和 few-shot 文本分类任务中都取得稳定表现，尤其在 OOD 与低资源设置下超过 gzip-NCD 和 BERT。

INSIGHT它不是主流神经检索论文，但对短文本语义匹配有一个有用提醒：重复结构、格式和压缩式相似性在低资源、OOD 场景下仍有信号价值。社区搜索可把这类轻量 text distance 作为召回特征或重排特征，补充 embedding 对模板化文本、变体文本和噪声短句的不足。

Xiaojun Hu, Jing Wang, Jingwen Zhang, Fengyao Zhai, Xiao Xie, Hao Liao, Zengru Di, Yu Liu

BaFCo: A Document Understanding Benchmark for Complex Bangla Form Comprehension

BaFCo 构建复杂孟加拉语表单理解基准，覆盖 200 份多页孟加拉政府表单，任务包括 Document Layout Analysis 和 Key Information Extraction。它设计了 26 类细粒度表单实体和 5 类粗粒度实体，并评估 ChatGPT、Gemini、Claude 等最新多模态模型在低资源语言、复杂版式和真实政府表单上的表现，目标是补齐低资源文档理解数据稀缺的问题。

INSIGHT与搜索相关的价值在于多模态文档索引前的结构化理解：如果平台有截图、票据、表格或长图笔记，先做 layout/entity extraction 再检索，通常比直接对整图做 embedding 更可控。BaFCo 提醒低资源语言和复杂版式会显著影响检索前处理，社区国际化搜索也需要类似的版式与字段级评测。
