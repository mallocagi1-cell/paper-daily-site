Personalization · 个性化推荐 — 10 篇入选

头条：Progressive Learning from Content to Relevance to Personalization for CTR Prediction — 淘宝搜索的 CTR 模型主要靠商品 ID 记忆历史点击，同一件商品换一张主图，模型几乎分不出差别。FineSID 把商品图用 VAR 图像分词器编成 1×1 到 4×4 四个尺度、共 30 个离散编码，标题和 OCR 文字按字段分词，全部像普通 ID 特征一样查表输入；整个网络先用 Qwen3.5 教师标注的“搜索词—商品”相关性训练，再换上点击预测头，用点击日志微调。离线 AUC 比 HiFormer 基线高 0.25 个百分点，冷门商品上高 0.38 个百分点；淘宝主搜七天 A/B 中 GMV 提升 0.85%。

Generative · 生成式推荐 — 10 篇入选

头条：Controllable Generative Recommendation via Guided Token Refinement — 生成式推荐按左到右逐个生成物品 ID 的 token，推理时想临时提高多样性，只能中途改某一位，结果常拼出目录里不存在的 ID。ReGen 改用双向 Transformer 一次预测 ID 的全部 4 位，只在最粗的几位上给用户历史里常见的码字减分，再把置信度低的位遮住重新预测，并用全部合法 ID 建成的前缀树排除补不成真实物品的码字，全程不改模型参数。Amazon Instruments 上把 top-10 品类覆盖率从 0.41 提到 0.59，Recall@10 只从 0.0427 降到 0.0394，TIGER-MMR 同区间从 0.0433 掉到 0.0319；去掉前缀树后只有 27.63% 的 ID 对应真实物品。

Retrieval · 检索与RAG — 10 篇入选

头条：pplx-embed-v2-late Technical Report — Perplexity 发布 0.6B 和 9B 两个多向量检索模型，能编码文本、图片和文档截图：文档每个 token 存一个 128 维向量，查询的每个向量取它和文档向量内积的最大值再求和打分。两个模型都去逐 token 拟合同一个 18B 教师的输出向量，因此向量空间相同，可以用 9B 离线建文档索引、线上用 0.6B 编码查询。在 72 个领域检索任务上，9B 平均 nDCG@10 为 81.3%，比 nemotron-3-embed-8b 高 1.6 个百分点；0.6B 查询配 9B 索引得到 79.6%，高于两端都用 0.6B 的 78.0%。BrowseComp+ 上 9B 让智能体答对 64.0%，搜索次数也最少。

Infra · 系统与索引 — 10 篇入选

头条：Is 2:4 Sparsity Still Worth It? Semi-Structured Sparsity versus Quantization in LLM Inference — 独立研究者在 Llama-3.1-8B-Instruct 和 Qwen3-8B 上，按相同存储位数（稀疏位置索引也计入）和相同标称算力档位，比较"加 2:4 稀疏"和"降一档精度"，并在 L40S、H100、RTX PRO 6000 上实测。只要还能降精度，加 2:4 就既更不准也更慢：2:4 + INT8 的存储成本等于 INT5。到 FP8 底线后，H100 上 vLLM 服务的重训 2:4 模型 prefill 吞吐比稠密 FP8 高 27%，GSM8K 相当；但重训时困惑度先恢复，推理准确率恢复得慢得多。
