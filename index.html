Generative · 生成式推荐 — 1 篇入选

头条：Benchmarking LLM Next-Step Recommendations with Knowledge Space Theory — 让大模型给学生推荐下一步学哪道题，它能不能把能学的题列全，又不混进还没到时候的题？作者用知识空间理论把这件事变成能自动打分的题：先修全都掌握、本身还没学的题，就是标准答案。在几家主流模型和线性函数的几个主题上测下来，只给题目描述时，推荐集合和标准答案完全一致的只有 61.3%。让模型先自己推出先修关系再推荐，几乎没有提升。直接把先修关系写进提示，就升到 96.3%。模型自己补出来的结构帮不上忙，显式给出的结构才有用。哪个模型最好也随提示和主题变化。对做推荐的人来说，能用规则算出来的候选集合，就别指望大模型自己推出来。

  1. Benchmarking LLM Next-Step Recommendations with Knowledge Space Theory

Personalization · 个性化推荐 — 10 篇入选

头条：Exploiting Feature-invariant Scaling Laws for Efficient A/B Experimentation in Recommendation Systems — 推荐模型加一个新特征或改一处结构，小规模实验说没用，全量训练后却可能有用。Meta 的作者在一个 LLM 推荐模型上就碰到过：给提示加上电影类型，小规模时 HR@10 变差，全量时明显变好。他们发现，不管改动是好是坏，模型的验证损失随训练规模的变化都服从同一种幂律，只是系数不同。于是只在几个缩小的规模上跑几组实验，拟合出曲线外推到全量，算出新特征在全量时胜过基线的概率。这几组实验加起来约是一次全量训练成本的 55%。单个小实验会误导，一条小规模曲线却相当可靠。在 Wukong、HSTU 和 LLM 推荐模型的 40 多个改动上，这个办法都能把有益的改动和中性、有害的改动分开。

AI Search · AI 搜索 — 10 篇入选

头条：DocFS: File Systems as Agentic Reasoning Environments for Complex Multimodal Document Question Answering — 让 VLM agent 回答很长的图文混排文档，难点常常不在模型，而在文档怎么摆给它。DocFS 的做法很朴素：把文档改造成一个文件系统，章节变成嵌套目录，正文、图、表、公式各存成文件，再加上索引文件和记录图文对应关系的关联文件。agent 只用列目录、关键词搜索、读文件这几个现成操作，先定位候选证据，再顺着关联文件补全，最后回原始页面核对。在 MMLongBench-Doc 上，它的准确率比最强基线 DocLens 高 2.9 个点，推理阶段平均耗时从 359.9 秒降到 43.9 秒。文件系统本身就把结构和配套工具配好了对，不用再为每种文档结构单独设计接口。

Infra · 系统与索引 — 10 篇入选

头条：Bursts That Outlast Themselves: Persistent Degradation in Prefix-Cached Agent Serving — 给 agent 做推理服务，全靠前缀缓存撑着：命中时每轮只补算新增的内容，没命中就要把几万 token 的上下文整段重算。作者发现这会让服务掉进一个出不来的坏状态。同样的基础流量，只多来几分钟突发请求，vLLM 的缓存命中率就跌到 10% 左右，吞吐减半，突发过去后积压还在涨。原因是一个循环：服务一慢，同时在线的会话变多，它们的上下文加起来超过 KV 池，每个会话的前缀在下一轮之前就被别的会话挤掉，于是每轮都重算，服务更慢。崩了以后只挡新请求，7 次里只救回 1 次；在轮次间隙暂停一部分已在跑的会话，让活跃会话的 KV 总需求不超过池子容量，每次都能在几分钟内恢复。跑 agent 服务时，要按 KV 容量管住已经进来的会话。

  3. One-Sided Expert-Parallel All-to-All for Mixture-of-Experts Inference over NVLink
  4. SHADOWPREFILL: Keeping Your Next Model Warm for Per-Step Model Routing in Agentic LLM Serving
  5. Decode Token Parallelism: Memory-Efficient Distributed Attention Parallelism for Scalable LLM Decoding
  6. ADIndex: Layer-Adaptive Sparse Attention Indexing via Group-Level Distillation
  7. Placing LLM Lookup Tables by Per-Layer Prefetch Deadlines
