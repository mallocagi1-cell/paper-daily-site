Generative · 生成式推荐 — 4 篇入选

头条：Speculative Decoding for Semantic-ID-Based Generative Recommendations — 用 Semantic ID 做生成式推荐时，每个物品是一串离散 token，线上常用受限束搜索一次取出多个候选。这样每个请求都要固定做多步顺序模型调用，模型变平后名单还可能偏离真正的 top-K，系统却发现不了单次请求是否已经变差。SIDECAR 先用近似草稿，再在一次树注意力中给整份草稿打分，并给未展开的前缀加上概率上界；若草稿里已有精确 top-K，就可以直接认证。否则只展开仍可能改写结果的分支。用只含一次互动的用户序列做草稿时，中位请求大约 1.7 次调用就能完成，约 40% 的请求第一次就能认证。即使预算不够取出精确名单，它也会给出与精确结果之间的倍数，服务可以按质量或延迟提前停下。

  1. Speculative Decoding for Semantic-ID-Based Generative Recommendations
  2. Towards Realistic Evaluation of Uncertainty Quantification for LLM-Based Recommender Systems
  3. LazUnirec: Unifying Retrieval and Ranking in Multi-scenario Industrial Recommendation
  4. C3H: Compression-to-Consensus Criteria Hijacking in Multimodal LLM Recommender Systems

Personalization · 个性化推荐 — 2 篇入选

头条：GPU-accelerated Multi-relational Parallel Graph Retrieval for Web-scale Recommendations — 网页推荐要从海量候选里实时召回，图检索却很难把点击、观看等多种行为放进同一种相关性。高并发时，各请求的搜索路径长短不一，遍历既容易顾此失彼，不规则的神经计算也会把 GPU 拖成瓶颈。GMP-GR 用多目标度量统一这些用户-物品关系，再做兼顾广度和深度的分层并行图检索，并在 GPU 上自适应聚合不规则计算。它已在百度二十多个应用上线，服务数亿用户，每天处理超过一千亿次请求。在百度移动应用两个推荐场景的测试里，页面停留时长分别提高 1.13% 和 1.19%。两个场景的日活分别提高 0.23% 和 0.50%。系统优化之后，两个服务的查询吞吐大约翻倍。

  1. GPU-accelerated Multi-relational Parallel Graph Retrieval for Web-scale Recommendations
  2. User-Adaptive Fusion of Multiple Foundation Models for Recommender Systems

AI Search · AI 搜索 — 10 篇入选

头条：OmniEVIE: Evidence-Vector-Informed Embedding for Multi-modal Retrieval — 多模态检索既要对付密集页面、细粒度实体，也要对付有顺序的视频和智能体工具。单向量会丢掉局部证据，cross-encoder 又要在线重读每个召回结果，未压缩的迟交互则大到难以服务。OmniEVIE 用约四十五亿参数的多向量模型，覆盖文本、图像、视觉文档、视频和工具，却共用一套压缩索引和三阶段检索。每条记录最多存放一百二十八个六十四维的 int8 向量，一百万条大约只占 8.82 GiB，并能为命中定位到页面区域或视频片段。在 MMEB-V3 的一百九十项任务上，完整序列得分 60.68，压缩索引仍有 60.06，几乎没有掉点。百万条语料上，单线程查询只要 54.2 毫秒。视频直接由帧编码，不必再经过解析模型。

  1. OmniEVIE: Evidence-Vector-Informed Embedding for Multi-modal Retrieval
  2. LARF: Learning-aligned Reasoning Framework for Search Relevance
  3. Teaching Time Without Losing General Retrieval: Adapting Multimodal Embeddings for Time-Sensitive Video Retrieval
  4. SOARS: System One Assisted Reranking for Agentic Search
  5. Efficient Video Retrieval Augmented Generation via Token Allocation
  6. TableRouter: Query-Aware Evidence Construction for Long-Table Question Answering
  7. RELAY: Learning Compatible Representations One Encoder at a Time
  8. Ask Again: Answer-List Instability in Generative Engines
  9. Data Auctions for Retrieval Augmented Generation
  10. No pipeline, no second copy: Querying Amazon S3 from Elasticsearch with ES|QL

Infra · 系统与索引 — 10 篇入选

头条：Generalized Tensor Parallelism: Powering Trillion-Parameter LLM Training at 10+ EFLOP/s — 训练到万亿参数的大模型时，常见并行方案总要在单卡显存和吞吐之间让步。数据并行会复制参数，张量并行和 FSDP 每个微批次都要通信，流水线并行又会让 GPU 在填满和排空时闲着。对线性层来说，这五种常见并行其实都是同一种广义张量并行 GTP 的特例，参数和激活都可以先切分，用时再一次收集回来。它把参数收集当成每次矩阵乘之前的可选预处理，而不是整块 Transformer 前的一步，因而能更早发出通信，又不过早占显存。在 12,288 张 GB300 上，内部两万亿参数的 MoE 模型达到 13.0 EFLOP/s。从 4,096 卡扩到这一规模时，弱扩展效率为 98%。实现已放进 Megatron-Core，还能在五百多张卡上跑长达一百万 token 的序列。

  1. Generalized Tensor Parallelism: Powering Trillion-Parameter LLM Training at 10+ EFLOP/s
  2. ModelLess: A Serverless System for Multi-Tier LLM Inference on Shared GPUs
  3. LoomKV: Lossless KV Cache Compression from GPU Memory to SSD for LLM Serving
  4. FlashQLA: Efficient Context Parallelism for Gated DeltaNet
  5. Wavefront: Low-Rank Drafting with Parallel Causal Refinement for Speculative Decoding
  6. RankServe: Rank-Aware CPU-GPU Scheduling for Memory-Constrained MoE Serving
  7. Shifter Quantization: Compact Representations for Native Integer Computation
  8. VenusOCR2.0: Towards Efficient and Effective Document Parsing
  9. How to Run NVIDIA Cosmos 3 on Local AI Devices Using Hugging Face Diffusers
  10. Accelerating Direct Sparse Solvers for Computational Engineering with NVIDIA cuDSS 1.0

Embodied AI · 具身智能 — 10 篇入选

头条：RESET: One Demonstration, One Verified World, Self-Improved Skills Across Embodiments — 大模型编程智能体可以在仿真基准里反复改机器人操作技能，可真机任务既没有现成的成功评分器，也没有可随意复位的练习环境。一次真实演示其实同时给出了场景几何、终点成功标准和检验世界是否忠实的物理参考轨迹，而且这些都不依赖于源机器人的运动学。RESET 从这一条演示重建可接触的世界和只读的成功标准，用开环回放和轮廓一致性做检查，再按节点上的失败证据改写模块化任务图和技能代码，部署时不再调用大模型。在八项操作任务上，仿真里未见过的布局平均成功率为 97%，零样本代码只有 27%。得到的程序在四台真机、280 次试验里成功 80%。没有目标机演示时，结构相近的手臂还能直接复用大部分技能函数。

  1. RESET: One Demonstration, One Verified World, Self-Improved Skills Across Embodiments
  2. Exploratory Midtraining for Robot Policies
  3. OmniAct: One Policy, One Million Embodiments
  4. EgoLoAF: Learning Humanoid Loco-Manipulation from Egocentric Demonstrations with Hand-Object Affordances
  5. Duo: Towards Spatiotemporal Action Coordination in Bimanual Policies
  6. Supply Geometry, Learn Execution: Screw Attention for Zero-Shot Policy Transfer in Robot Manipulation
  7. DexLatentWorld: 3D Cross-Embodiment Latent Action World Models for Zero-Shot Robotic Manipulation
  8. ViTacLab: Physically Consistent Visuo-Tactile Simulation, Benchmarking, and Representation Learning for Robotic Manipulation
  9. More Than Picturing the Future: Motion-Oriented Latent Reasoning for Generalizable Robot Manipulation
  10. Microduck Obstacle Avoidance: A Sim2Real Workflow with Isaac Lab and Newton
