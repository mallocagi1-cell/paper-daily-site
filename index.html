头条：Stable and Granular Policy Optimization for Generative Recommendation — 生成式推荐直接生成物品的语义编号，核心指标又按整段序列来评，强化学习和它很合拍，但现成的分组算法并不好用：按 token 优化会更不稳定，按整段优化又给每个 token 同样的权重，忽略了它们作用并不相同。一种兼顾稳定与细粒度的分组优化保持序列级比率，同时注入 token 级优势：在正轨迹里提高高置信 token 的权重以巩固成功检索，在负轨迹里严格惩罚它们以鼓励探索，并用自适应缩放限制重塑后优势的方差。两个公开基准和十亿级工业数据上，该方法持续优于六个较强的强化学习基线；在商业平台的在线对照中，点击率提升 2.36%，广告收入提升 1.95%。
