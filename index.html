Personalization · 个性化推荐 — 3 篇入选

头条：A Redundancy Reduction Approach for Controllable Sequential Recommendations — 论文针对序列推荐的热门物品集中与长尾曝光问题，把相同下一物品标签的用户历史配成正样本，并在预测损失上加入 Barlow Twins 去相关正则。五个公开基准验证了这一方法；ML-1M 的 NDCG@10 为 0.0534，相比最强基线提高 6.2%，但覆盖率并非同步提高。

  1. A Redundancy Reduction Approach for Controllable Sequential Recommendations
  2. OpticalRec: Unified Optical Vision-Language Representation for Multimodal Recommendation
  3. Dynamic Task-Adaptive Meta Optimization for Cold-Start Recommendation

Generative · 生成式推荐 — 4 篇入选

头条：Beyond Sequences: Distilling Structured Decision Memory for LLM Recommendation — 阿里提出 MARI，将搜索、浏览、收藏和购买日志蒸馏为包含意图、偏好及回避因素的结构化决策记忆，再检索记忆辅助 LLM 推荐。Qwen3-4B 微调版本在跨品类下一物品预测和相似商品难选择任务的 Hit@1 分别为 0.5561、0.8868；无记忆微调基线为 0.538、0.866。结果来自工业日志离线实验，未提供线上 A/B 收益。

  1. Beyond Sequences: Distilling Structured Decision Memory for LLM Recommendation（深度解读）
  2. SPRIG: Semantic-ID-enhanced Paths for Knowledge Graph-based Generative Recommendation
  3. Multimodal Graph Retrieval-Augmented Sequential Recommendation via Collaborative Filtering Paths
  4. Personalization Matters: Long-Horizon Conversation Agent with User-Centric Information in Online Shopping Interactions

Retrieval · 检索与RAG — 7 篇入选

头条：H2CE: Modeling Geo-Semantic Interactions for POI Reranking with Heterogeneous Two-Stage Cross-Encoders — 针对本地搜索中语义、距离与口碑信号难以联合比较的问题，H2CE 将数值分桶文本与精确数值 MLP 同时输入异构交叉编码器，再对首阶段前十名进行成对重排。在 5,743 条查询上，nDCG@5 达到 67.48，比 XGBoost 高 22.82 个百分点；成对阶段额外贡献 1.98 个百分点。

  1. H2CE: Modeling Geo-Semantic Interactions for POI Reranking with Heterogeneous Two-Stage Cross-Encoders（深度解读）
  2. SkillContrast: Difference-Guided Text Selection for Agent Skill Reranking
  3. EVIE: Evidence-Vector-Informed Embeddings for Visual Document Retrieval
  4. Autoregressive Retriever: Improving Query Understanding from Item Feedback for Universal Multimodal Retrieval
  5. Syn-Omni: Structured Specialization and Progressive Collaboration for Omnimodal Embeddings
  6. NativeScope: Relation-Localized Retrieval over Native Topology with a Correct Anchor
  7. AMBER: Multi-View Adaptive Budget Allocation for Listwise Vision-Language Reranking

Agentic · 智能体搜索 — 10 篇入选

头条：RIT-RAG: Navigating Document Corpora with Retrieval-Induced Trees — RIT-RAG 将召回与阅读解耦：先用检索命中的段落及祖先节点构造跨文档子树，再让 Agent 按需读取节点、改写查询。相同混合检索器下，Haiku 在 WixQA 的答案准确率由 Agentic Search 的84.5%升至95.0%，FinanceBench由74.0%升至84.0%；284万网页语料验证了规模可扩展性。

  1. RIT-RAG: Navigating Document Corpora with Retrieval-Induced Trees（深度解读）
  2. Programmatic Search Agents: Extending Agentic Search Beyond Query Reformulation
  3. Asana cuts model costs 76x in browser tests with GPT-6.1 Sol
  4. Agentic RAG Evaluation: Budget Allocation Across Questions, Trajectories, and Reads
  5. ATLAS: Evaluating Agents on Search-Intensive Tasks
  6. PhantomEnvironments: Training LLM Agents in Fictional Worlds
  7. Evaluating Deep-Search Agents under Hierarchical Web Evidence Poisoning
  8. MemPilot: Orchestrating On-Demand Multimodal Memory Curation for LLM Agents
  9. Mechanism-centric cross-domain retrieval for scientific discovery: LLM agents for structural isomorphism beyond semantic similarity
  10. Sophos cuts threat investigation time by 96% with OpenAI Daybreak

头条：AlignQuant: Tile-Aligned Mixed-Precision Quantization for Efficient LLM Generation — AlignQuant 将二维权重块统一用作精度分配、压缩存储与 GPU 执行单元，解决细粒度混合精度难以转化为实际加速的问题。联合预填充与解码校准后，专用内核复用同一份压缩权重；在 4 个 3B–14B 模型、3 种 GPU 和最长 64K 上下文中，相对 BF16 生成速度最高达到 2.50 倍。
