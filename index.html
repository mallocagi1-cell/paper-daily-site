头条：DiLE: Discrimination-Aware Latent-Space Learning for Universal Multimodal Embeddings — 多模态大模型擅长理解多模态输入与任务指令，但压成单向量 embedding 做检索时，并不一定能留住颜色或空间位置这类区分细节，相关候选和相似干扰项依然难分开。两阶段框架 DiLE 先在第一阶段用推理指令引导少量可学习隐式 query 提取任务证据，配合共享与任务私有 LoRA 专家及辅助答案生成监督。第二阶段定期用更新后的学生快照重新召回易混负样本，借冻结重排模型的细粒度相关性分布，用反向 KL 散度校准 embedding 相似度。推理时无需教师模型，也不生成显式推理过程，单次编码即可产出可预计算的向量。在跨两代底座的配置下，DiLE 在 MMEB-V2、MRMR 和 UVRB 上均取得整体最优，其中 Qwen3-VL-2B 版在 MMEB-V2 上比同底座的 Embed-RL 高出 2.8%，速度还快了 101 倍。

Infra · 系统与索引 — 10 篇入选

头条：TideCache: Efficient Hybrid LLM Serving with Transparent Cache Management and Layer-Wise Streaming — 混合架构大模型里，全局注意力缓存随并发和上下文一起增长，有界状态缓存只随并发增长，固定切分显存容易一边闲置、一边排队。像 HiCache 这类分层缓存把历史前缀拉回后全程常驻显存，decode 期间高速 CPU 与 GPU 互联几乎空转。TideCache 在 SGLang 中保留各缓存子池的固定虚拟地址，按需重映射物理页，不改缓存布局和注意力后端就能在子池间挪动容量。decode 时趁有界状态层计算的空档，把下一层全局注意力的前缀从主机流式预取进共享槽位，新生成的 KV cache 留在显存，调度器按请求规模和队列状态选择常驻或流式。在 GB300 和 GH200 的七组配置上，相比搭配 HiCache 的 SGLang，它完成的 agent 轮次最高达 2.04 倍，整体 P50 每 token 延迟降低 20% 到 59%，agent 的 P50 TTFT 也显著缩短。
