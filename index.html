头条：Bridging the Topological Divide: Dual-Branch Graph Distillation with Semantic Priors for Robust Cold-Start Recommendation — 针对新物品没有交互边、图协同过滤表示失效的问题，DualGCN 先训练带语义锚点的协同教师，再以余弦蒸馏训练语义学生，并在推理时重建向量范数。Books 冷启动 Recall@20 达 0.1007，高于 DeepMusic 的 0.0890；Sports 达 0.1119，高于 DropoutNet 的 0.0926，但 Electronics 低于 DeepMusic，优势并不覆盖全部数据集。

头条：Revisiting Generative vs. Dense Retrieval: A Static Value Prior Reverses the Gap — 论文检验生成式召回是否真正优于稠密召回，使用相同数据与联合训练骨干比较两类输出机制，再向稠密候选加入静态价值先验。Amazon Toys 2014 上 Recall@50 分别为 0.167、0.228、0.210（生成式、稠密、稠密加先验）；工业数据上 NDCG@50 从 0.474 升至 0.530，超过生成式的 0.453。
