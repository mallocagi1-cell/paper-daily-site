Generative · 生成式推荐 — 1 篇入选

头条：ReAlign: Reward-Guided Preference Alignment for Generative Re-Ranking — 重排序要把上游候选排成对用户效用最高的列表，可两阶段的生成-评估方法把生成和评估拆开，生成器拿不到列表级效用信号；按分打分的方法又往往固定在上游顺序里，并不真正搜索排列空间。把可分解的列表奖励模型和候选感知的自回归生成器耦在一起，奖励按位置拆开，用生存函数刻画用户曝光，再用多目标头估计点赞、关注等不同互动。生成器先在已曝光列表上做监督预训练，再用池内标准化后的奖励做分布与排序对齐。在 KuaiRand 上，NDCG 从最强基线 CAVE 的 0.8450 提到 0.8551。Avito 上则从 0.7372 提到 0.7476。列表级效用只有回灌到生成过程里，排列搜索才会朝着真实互动走。

  1. ReAlign: Reward-Guided Preference Alignment for Generative Re-Ranking

Personalization · 个性化推荐 — 2 篇入选

头条：Deep Cross-Division Network for Product-and-Ratio Feature Interactions in Industrial Ranking — 工业排序模型经常要把点击率、转化率这类比值特征手工算好再喂进去，因为 DCNv2 这类交叉层只能做多项式乘积，没法直接表示倒数项。点击率要把点击除以曝光，类似的比值把互动次数除以机会次数，关系很有预测力，却会把输入撑宽、加重后续交叉的开销。给交叉层加上除法分支后，模型可以用同一批基础特征同时学乘积和比值交互，于是整类手工比值特征都可以从输入里拿掉。在一家大型短视频服务的生产排序栈里，输入特征因此减少了 40.1%。线上 A/B 测试中，点赞提高 3.25%，分享提高 16.26%，变化均达到统计显著，展示量只略降。比值不必再靠人工堆进输入，交互层自己就能学会归一化关系，模型计算时间也跟着降了下来。

  1. Deep Cross-Division Network for Product-and-Ratio Feature Interactions in Industrial Ranking
  2. Beyond Covers and Titles: Evidence-First Ranking for Robust Cold-Start Recommendation

AI Search · AI 搜索 — 10 篇入选

头条：When Visually Rich Documents Meet Multi-Vector Retrieval for Region-level Retrieval-Augmented Generation — 视觉文档的检索增强生成如果只用整页粗表示，局部证据容易被淹没，生成时整页图像也会带进大量冗余的视觉 token。一套区域级方法先把页面拆成语义完整的区域，再用多向量做延迟交互检索，并根据匹配分数估计各区域贡献，只把相关区域重排成紧凑的视觉上下文。在五套基准上，相对最强的单向量视觉基线 VDocRAG，采用 Phi3V 时平均 nDCG@5 提高 3.47 分；区域增强相对整页把视觉 token 减少 43% 到 62%。用语义完整的区域同时做匹配和选证据，可以在更少视觉输入里保住检索和生成效果。表格类数字题仍可能因表头被裁掉而变差。

Infra · 系统与索引 — 10 篇入选

头条：IsoMoE: Placement-Invariant Hybrid CPU-GPU MoE Inference with Lossless 12-bit Experts — 混合部署把部分专家放到 CPU 上，好让单卡跑下超过显存的 MoE，但专家放在哪块设备、何时换入，现有引擎的贪心解码结果往往会跟着变，因为两端算术并不相同。解码又常被 CPU 内存带宽卡住：无损压缩能少搬数据，可熵编码在 CPU 上解得太慢，跟不上内存读取。把 GPU 专家 kernel 做成对 CPU 算术的按位重放，再用便于 AVX-512 点积的内存布局计算无损的 12 bit 专家，并配上不改变输出的双微批流水线，就能让放置只影响速度。在多个 MoE 模型上，不同专家放置下的输出按位一致，也与全部专家都在 CPU 上时相同，解码吞吐平均比最快基线高 1.26 倍，最高 1.54 倍。专家放在哪只应改变快慢，不应改变同一条指令的生成结果。

  5. Speculative Decoding Is Less Speculative Than You Think
  6. Isonomy: Isolating Every Request from Timing Side Channels at Nearly Full-Sharing Throughput in Multi-Instance LLM Prefill
  7. AdaTree: Serving-Aware Adaptive Tree Construction for Speculative Decoding
  8. Contention-Aware Flexible Execution for Machine Learning Workloads
  9. Intent-Aware Caching for Efficient LLM Serving
  10. Get Started with GPU-Accelerated DuckDB Analytics Using the Sirius Core Extension

Embodied AI · 具身智能 — 10 篇入选

头条：SkiP: When to Skip and When to Refine for Efficient Robot Manipulation — 模仿学习策略往往在每个控制步都预测未来动作，不管当时是可预见的空闲运动，还是必须精细处理的接触阶段，时间分辨率被当成一成不变的。一种跳过策略把演示划成需要密修的关键段和有时间冗余的可跳过段，并在可跳过段里把行为克隆目标改写成下一段关键段入口的动作。这样就能在同一个网络里直接跃过冗余步、在关键处细修，不必再学一个跳跃规划器。划分由运动谱关键点分析轨迹速度的局部频率自动完成，不用人工标注。在 72 个仿真操作任务和三项真机任务上，它把实际执行步数减少 15% 到 40%，成功率则持平或更好。时间分辨率可以写在监督信号里，而不必另搭一套分层规划。
