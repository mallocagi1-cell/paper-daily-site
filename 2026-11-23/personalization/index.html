Cost-Aware Agentic Feature Optimization System for Fleet-Scale Ranking Models

大型平台运行着大批广告排序模型，沿用旧特征靠人工增删，很难兼顾单模型推理开销与共享链路预算。Meta 搭建了一套由 LLM 提假设、确定性工具做验证的集群级系统，提效通常来自跨类别重配特征数量，光靠放大各类配额容易遇到边际递减。系统先用跨模型持续微调的共享 LLM 召回交叉特征，经确定性重要性打分与多任务帕累托前沿混合排序，再由寻优 agent 在资源上限内跑异步实验。

02 4.10

Intelligent Embedding Pruning for Large-Scale Recommendation Models

Meta

训练大规模推荐模型时，卡住 GPU 数量的往往不是算力，而是稀疏 embedding 表占满显存。现有方法 ITEP 会在训练中动态裁掉不重要的行，但通常按表大小定剪枝比例，忽略特征贡献，有时会损伤精度。Meta 的 FI-ITEP 先用批量内打乱特征值看损失变化等方式估算特征重要度，再给低重要度表分配更高剪枝比例。在三套工业级推荐模型上，它把总显存压低 20% 到 40%，精度追平甚至超过按大小剪枝，开源 DLRM 基准也复现了这一趋势。释放显存后，一套高频重训模型能从 112 张 GPU 降到 80 张，且单卡吞吐更高。大模型低贡献 embedding 更多，省下的算力足以覆盖前期估算开销；冗余有限的小模型沿用按大小剪枝可能就够了。

Anish Khazane, Alex Saad-Falcon, Guanchu Wu, Marcio Porto, Jasper Shan, Fei Yu, Eugene Shulga 等 12 人

03 4.05

From Sessions to Serving: Integrating LLM-Based Embeddings into Retrieval for Production Content Recommendation

Autodesk

Autodesk 官网同时推荐产品、行业、客户案例和学习内容，传统物品 ID 序列模型会丢掉没有目录 ID 的网页行为，在线实时跑 LLM 又会超出延迟预算。LSER 保留现有双塔和序列编码器，用微调后的 LLM 把原始事件文本编成会话和历史 embedding，作为辅助特征拼进用户塔。重编码走近线异步刷新并写入存储，请求时直接读取做 ANN 检索。离线消融中，加入这些特征后，热门产品 HR@10 提高 9.6 个百分点，客户案例 HR@1 提高 6.0 个百分点，其余展位基本持平。目前的线上 A/B 实验对比的是未开 LLM 特征的近线双塔与旧规则引擎，产品下单率提升 14.8%，LLM 特征的线上测试排在下一步。对目录稀疏的多内容站点，近线补原始行为文本特征能在可控延迟下补上语义信号。

Zhixiong Hu, Meng Li, Maggie Zhang, Deborshi Goswami, David Bailey, James Bradley
