DiLE: Discrimination-Aware Latent-Space Learning for Universal Multimodal Embeddings

多模态大模型擅长理解多模态输入与任务指令，但压成单向量 embedding 做检索时，并不一定能留住颜色或空间位置这类区分细节，相关候选和相似干扰项依然难分开。两阶段框架 DiLE 先在第一阶段用推理指令引导少量可学习隐式 query 提取任务证据，配合共享与任务私有 LoRA 专家及辅助答案生成监督。第二阶段定期用更新后的学生快照重新召回易混负样本，借冻结重排模型的细粒度相关性分布，用反向 KL 散度校准 embedding 相似度。推理时无需教师模型，也不生成显式推理过程，单次编码即可产出可预计算的向量。在跨两代底座的配置下，DiLE 在 MMEB-V2、MRMR 和 UVRB 上均取得整体最优，其中 Qwen3-VL-2B 版在 MMEB-V2 上比同底座的 Embed-RL 高出 2.8%，速度还快了 101 倍。

4 modalities, 100+ languages, 1 vector space: Jina Embeddings v5 in Microsoft Foundry

Elastic

一条搜索 query 就能在同一结果集里同时召回视频片段和文本段落。Jina Embeddings v5 现已上架 Microsoft Foundry 模型目录，提供纯文本和 Omni 多模态两类共四款模型：多模态版把文本、图片、PDF、音频和视频映射进同一向量空间，纯文本版覆盖超过 100 种语言。两类均分 Small 和 Nano 两档，Small 参数更多、上下文更长，适合看重精度，Nano 主打吞吐。多语种文本评测 MMTEB 上，Nano 只比 Small 低约 1.5 分，文本处理却快 3.4 倍，音频上两档打平且 Nano 更快，图片和视频则是 Small 明显领先。模型以独享端点部署在自有 Azure 订阅并按计算小时计费，模型与数据留在租户内，向量可直接写入 Elasticsearch。因目录部署阻断出站访问，多模态输入须用 Base64 传入，不支持媒体 URL。

SAGE: Semantic Ambiguity Guided Capacity Expansion for Retrieval-Augmented Generation

已录用 NeurIPS 2026

结构增强的 RAG 虽然能提升多跳推理，但索引开销高，遇到简单 query 效果反而下降。作者指出，这一稳健性缺口来自固定维度内积打分的容量瓶颈。语料扩大后，语义相近的段落会聚成局部区域，基础打分器难以维持足够区分度。把文档重排成树或图能暴露或部分缓解问题，却无法提供更强的局部打分函数。轻量级 RAG 框架 SAGE 通过文档侧的局部可分性缺口识别这类区域，只在需要处扩容。它建两层语义索引，从语料段落导出原子 query 视图，校准参数高效的超网络，为选中节点生成局部的歧义条件打分器。大量实验表明，SAGE 在检索和 QA 上超过稠密检索器与结构增强基线，更好地平衡了单跳和多跳检索精度以及稳健可扩展性。

Xunlei Chen, Jinyu Guo, Yi Gong, Qirui Ye, Zhaokun Wang, Wenyi Li, Wenhong Tian

Iterate Until Retrieved: Factual Nugget Optimization for Discoverable Continual Corrections in Agentic RAG

MMosaic AIHebrew University of Jerusalem

B2B 场景的 agent RAG 系统常收到自由文本的回答反馈，相比风格、偏好或整体回答质量等笼统信号，作者聚焦可落地的事实纠错，识别并转成紧凑的知识库条目（事实片段）。他们提出索引期优化方法 INO，把生产环境的 agent RAG 当作测试台，先生成初始条目，再用触发纠错的 query 和改写探测，反思失败的检索与回答轨迹并反复修订，直到条目可被发现。评测覆盖多家使用该系统的公司的两个生产 B2B 知识助手，一个是查企业专属知识库的产品支持 agent，另一个是协助支持工程师的工单助手。在自动和人工评测中，INO 在纠错的可发现性与使用上均持续优于基线，生产对照实验也表明这些条目提升了用户对回答的满意度。

Moshe Hazoom, Gal Patel, Alon Talmor, Tom Hope

Web search in Latin America: language models use less local and diverse news than search engines

University of Oxford

在拉丁美洲用大模型联网搜新闻，看到的来源总体更集中，本地用户拿到的本土新闻占比也低于搜索引擎。牛津大学团队从九个拉美国家选出一千九百多起近期时事，按位置和语言设四种场景，对比三家搜索引擎和四个联网语言模型。本地人用本地语言在本国搜索时，搜索引擎返回的本土新闻只有 41.3%，四个模型又比均值低了 3.6 到 11.6 个百分点，其余场景则表现不一。来源多样性上，语言模型总体更依赖少数媒体，英文查单国事件时四个模型都不如搜索引擎分散。大模型联网搜索会复现传统搜索的地域偏差，部分场景下还会放大。评测联网搜索时，不能只看回答质量，还要按地区和语言审计来源检索和筛选分布。

Francisco W. Kerche, Franziska Sofia Hafner, Felix M. Simon, Luc Rocher

Beyond Entity Recognition: Vision-Centric Knowledge Visual Question Answering

CASUCASOPPO

多模态大模型回答需要视觉知识的问题时依然很吃力，闭卷测试里最强模型的整体准确率只有 57.1%，拿到标准证据后才超过 90%。以往评测大多只在认实体时用到原图，认完就纯靠文本推理。VC-VQA 基于维基百科快照构建了可追溯的图文知识库，把视觉作用拆成检索前提取图内线索、检索后回图核对定位和查询外部图片三类。实验显示，直接给出实体名称能让内部视觉推理提高约 39%，外部图片推理却只涨约 1%，说明模型认出实体后能回忆文本属性，主要瓶颈在细粒度视觉知识获取。多步规划的 agent 检索在全部受测模型上都稳定超过单步启发式检索，说明多模态检索问答需要按需迭代获取图文证据。

TableRoute: Capability-Aware Routing for Scalable Table Question Answering

University of Melbourne

用大模型做表格问答时，固定套用一种推理方式很难同时应付短表、长表和超大表。作者抽样分析发现，把问题错配到列名和数值的语义错误在各规模下都排第一，占全部错例的 42.3%，而模型在聚合与算术题上的可靠表长上限明显低于简单查找题。TableRoute 先从精简表概览抽取列名、数值与条件证据，校验可执行性并识别所需操作。接着按表长和离线标定的能力上限选定唯一路线，在直接读表、缩减子表和程序执行中只跑一条并复用这份证据。在覆盖三种规模的三个评测集上，它在三款基座模型上均高于最强基线；超大表 BirdQA 平均高出 5.3 个百分点，单题在线 token 消耗从多智能体方案 TALON 的 160.4K 降到 24.6K。新基座模型使用前需做一次离线标定。

Yuxiang Wang, Junhao Gan, Jianzhong Qi

LSP-RAG: Latent Scoring Perspectives for Knowledge Graph Retrieval-Augmented Generation

University of VirginiaUniversity of Central FloridaIBM

做知识图谱 RAG 多跳问答，不靠 ChatGPT 这类大模型带路，只用冻结的轻量模型也能在检索上超过它。以往轻量检索靠单一视角孤立打分，既抓不住多样相关性信号，又常把单独看不起眼、但承接上一步推理的关系提前滤掉。LSP-RAG 在冻结的轻量语言模型前接两组可训练的连续 prompt：一组诱导多个隐式打分视角并按问题和候选三元组自适应加权，另一组汇总上一跳候选表征来传递推理上下文。在 WebQSP 上，用 Flan-T5-3B 检索的准确率达到 88.59%，高于 ChatGPT 检索版 RoG 的 74.27%，在 WikiMovies 和 MetaQA 单跳、两跳评测上也全部超过对比基线。对做 RAG 的团队，结构化图谱的多跳筛选可以交给轻量模型，把大模型留到最终生成答案。

Haochen Liu, Guanghui Min, Song Wang, Yada Zhu, Chen Chen, Jundong Li

Seer: Guiding Small Deep-Research Agents with Shared Decision Models

Sichuan UniversityUIUCLenovo

小模型在本地跑深度研究 agent 时，单靠自身采样容易出错，靠真实执行做多路试探又会把外部工具调用花在淘汰分支上。Seer 框架把动作生成和决策引导拆开，由冻结的 agent 提候选动作，再用真实轨迹离线训好工具响应模拟器和历史价值评估器。每轮由模拟器预测候选调用的返回结果，评估器给推演历史打分，只有最终选中的那一步才发起外部调用，落选方案只花本地算力，提交的历史只留真实返回。无需重训任何模型，Qwen3.5-4B 的 GAIA 准确率从 13.6% 提到 41.7%，同套模块也能直接迁移到 Qwen3.5-9B、Gemma-4 和更大模型，在 BrowseComp-200 上真实调用次数接近基础 agent。拉宽候选能缓和模拟误差，也会放大打分噪声，实际使用需按模型和任务选定宽度。

Yuhao Zhou, Yang Zhou, Yuanxi Li, Jindi Lv, Dan Si, Qing Ye, Jiancheng Lv

FinVeriQA: Financial Research Agents for Question Answering: Routing, Retrieval, MCP Tool Use, and Provenance-Aware Evidence Verification

SSan José State University

让单个大模型回答 SEC 财报和股价问题，常算错比率、报错旧股价，还会高置信度选错工具。开源原型 FinVeriQA 把各环节拆开：决策模型 Laya 路由并拦截投资建议，Python 算全部数字，检索与实时接口取证，Mistral-7B 写作并经代码校验。这消除了算错数和旧股价，但实测里路由正确且过检的两条回答，仍把 AMD 示例数据安在 NVIDIA 和 Alphabet 名下。问题出在校验器和写作端读同一份共享证据。在 FinRank 受控上界实验里，把共享段落的一个数字改成看似合理的错数，Mistral-7B 多次采样一致性没降，准确率却归零。共享证据校验只拦下 35% 的错答，改对原始无误段落核对能拦下 77%。多 agent 问答和 RAG 的校验必须独立于写作端读到的共享证据，否则错数和错公司数据会直接放行。

Meenakshi Rajpurohit, Anna Phan, Ravikumar Komandur Narayanan, Gunanidhi Ramakrishnan 等 5 人
