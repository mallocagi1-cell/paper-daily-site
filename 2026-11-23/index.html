CACO: Coverage-Aware Coordinated Optimization for Continuous Generative Retrieval

连续生成式召回在商品 embedding 空间为同一用户采样多条 query 做并行 ANN 检索，但独立采样常落进重合近邻，把固定预算浪费在重复商品上。CACO 在冻结的流匹配和扩散主干外接轻量调整网络，结合用户历史与 query 间交互调整落点。

LQ-Rec: Late Quantization for Sequential Recommendation

TToyotaUC San Diego📖 深度解读 · 6 分钟 →

用 Semantic ID 做自回归生成式推荐一直有个难题，拉长编码本应降低量化误差，但预测变难常会拉低排序效果，编码器显存和解码开销也会急剧上升。LQ-Rec 把量化挪到候选物品侧，让序列编码器和内积打分全程留在连续空间，先联合训练编码器与残差量化器，再冻结编码器按各前缀长度微调码本。用户向量不再读取离散 token，模型误差和量化误差就能解耦拆开，排序质量也随编码长度单调提升。

Satoshi Koide, Yueqi Wang, Julian McAuley

Learning Generative Ranking Policies for Whole-Page Optimization

Meta📖 深度解读 · 7 分钟 →

推荐页内容会抢注意力也会互补，单条最好的候选拼在一起往往不是最优整页。现有生成式重排要么把整页分笼统给每次选择，要么拟合训练前固定的列表，模型变强后目标跟不上。Meta 在固定评估器下按轮次训练生成器：在部分页试放候选，用当前模型采样补全整页打分，再重加权出逐位交叉熵目标，由新模型构造下轮数据。每个位置都按补全后的整页得分调整候选分布，线上直接贪心解码，无需评估器搜索。

Chen Qiu, Zhigang Hua, Qi Xu, Jizhe Zhang, Sha Hua, Ren Mao, Luke Simon

Generative News Recommendation Reproduces Popularity: A Memorization-Based Analysis

NNikkei

直接用大模型生成新闻标题做推荐，输出会比用户实际浏览更扎堆，训练数据的字符串记忆是推手之一。作者基于日本新闻服务 Nikkei Online 约 2000 万条浏览会话，继续训练指令微调版 Llama 3 8B 预测下一篇标题，只生成 20,689 个不同标题，约占真实后续标题种类的五分之一，集中度更高、多样性更低。相关性分析显示，高频重复的目标标题更容易被逐字或近似记忆，记忆越强越会在更多前文下反复生成。探索性目标去重压低了记忆与集中度并使生成种类近乎翻倍，但训练样本缩水到约百分之一，精确匹配准确率大跌，语义多样性也没改善。作者建议生产系统结合频次与时效衰减重加权、候选约束解码和多样性重排，避免简单去重。

Shotaro Ishihara
