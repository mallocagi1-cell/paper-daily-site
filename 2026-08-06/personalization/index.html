Knowledge-Geometry Decoupling: Refreshable Pretrained Transfer for Streaming Recommendation

工业推荐在行为分布持续漂移时，传统 next-token 预训练会把跨兴趣会话的相邻物品当成依赖，迁移后还会与 CTR/排序目标争抢同一参数。KGD 用 BMTP 只预测协同或语义相关的未来物品，并以可刷新编码器、只读交叉注意力和正交 ACR 分离知识与任务几何。在 8 个公开基准上较强基线提升 4%–12%，Shopee 90 天流式验证保持优势，首页搜索 A/B 的人均 GMV +1.75%、广告收入 +1.53%。

Heterogeneous Ranking in Industrial-Scale Recommender Systems: A Case Study

Google📖 深度解读 · 15 分钟 →

Google Discover 的统一信息流同时包含网页、长短视频和 UGC，单一共享表示容易让多数内容类型压制少数类型。HA-MoE 将异质性上下文同时注入多门控专家与专家表示，并用 LENS 追踪专家分工、用 DL-AUC 衡量全局效用和跨类型正确性。10M 条 7 天样本上，pInterest DL-AUC 达 0.691；1% 流量、7 天 A/B 中 DAU +0.22%、多样互动率 +0.54%。

INSIGHT多目标推荐的“负迁移”不只是 loss 权重问题，也来自内容类型的特征密度和行为语义不一致。可以借鉴 HA-MoE 的显式类型条件、4 专家 dense MMoE 与 DL-AUC 组合：把 UGC、视频、广告的跨类型排序作为安全指标，同时监控专家塌缩；论文报告模型体积增加不到 5%、p50/p95 延迟增加不到 0.5%。

Di Bai, Jintao Liu, Zhenwei Tang, Peifan Wu, Nada Al-Thawr, Luoshu Wang

SITA: Semantic Interest Tokens for Target-Aware Compression in Long-Sequence Recommendation

SITA 解决长行为序列建模中的两难：目标相关检索需要在线逐候选计算，静态压缩又丢失目标适应性。方法用并行语义量化学习语义 ID，将用户兴趣压缩成分组 token，再按目标物品的语义码选择对应 token；在线复杂度为 O(BNd)。在 Taobao-MM 上 AUC/GAUC 为 0.6550/0.6175，在 XLong 上为 0.9149/0.9120；相对 DIN 的提升分别达 3.02%/1.56% 和 3.77%/3.82%，工业场景 AUC 最高提升 0.078%。

INSIGHT长序列推荐可把“用户画像压缩”和“候选相关性”拆成离线存储与在线选择两步，而不必为每个候选重读原始行为。SITA 的语义分组让同一用户保留全局兴趣、按 item 选择局部视图；对社区推荐可将帖子主题、作者和互动语义编码成 token，先验证 GAUC，再评估存储规模与更新延迟。

Rui Zhou, Bo Chen, Qinglin Jia, Jiezhou Ji, Chaoyi Ma, Ruiming Tang, Hao Wang, Enhong Chen

From User Sequences to Scaling Laws: A Multi-Stage Architecture for Meta’s Ads Ranking

Meta

Meta 文章总结广告排序从静态稀疏特征转向用户行为序列与多阶段架构的路线，核心是用行为发生顺序、时间间隔和跨产品信号刻画兴趣与意图，再把大规模序列模型的能力迁移到可在线服务的排序模型。文章面向每天数十亿交互的推荐平台，强调序列建模、分阶段训练和 scaling law 的组合，而不是单点替换 CTR 模型。

INSIGHT对于 UGC 搜索/推荐，用户序列不应只作为一个拼接特征，而应成为可独立扩展、可缓存和可蒸馏的建模层。工程上可先在上游用户塔学习长短期行为，再把轻量表示传给多目标排序；同时按流量、序列长度和延迟分桶，验证模型规模增长是否真正转化为 nDCG/CTR 收益。

LLM-Derived Priors for Thompson Sampling in Cold-Start Comment Recommendation

论文把用户生成评论当作冷启动 bandit arm 的语义先验，用 LLM 从文本抽取信号，分别构造 Gender Prior 与 Content Prior，再初始化 Thompson Sampling；后验按性别—年龄分段更新。真实线上 A/B/C 比较了均匀先验和两种 LLM 先验，结果显示少量交互证据出现后收益最大，且不同先验对点击漏斗和人群的作用不同。

INSIGHT文本丰富但曝光稀疏的 UGC 内容，适合让 LLM 只承担离线先验提取，而把在线探索交给 bandit，避免把 LLM 放进每次排序请求。落地时应同时监测先验—奖励一致性、不同人群的 treatment effect 和冷启动窗口；性别等敏感分段还需要公平性审计与可解释的回退策略。

Eugene Lee, Oseong Choi, Byungsoo Kang, Taeyeong Jang

ATLAS: Learning to Recommend Across Unseen Domains

ATLAS 研究推荐模型能否在没有目标域适配或语言模型预训练的情况下迁移到全新目录。它用 Gromov–Wasserstein 对齐用户关系、对抗目标消除域特定 item 表示，并以残差向量量化压缩层级交互模式；在 5 个 Amazon 源域训练、10 个未见域直接测试，平均 HitRate 相对提升 24%，消融验证了各组件和源域多样性的作用。

INSIGHT冷启动不一定要从目标域收集大量点击再微调，也可以先学习跨域稳定的用户—物品关系。对社区平台，可将帖子、问答和评论视为不同域，先用域不变表示支撑新频道或新内容形态，再用少量在线反馈校准；但应把源域覆盖度和目标域偏移作为上线前门槛。

Pervez Shaik, Prosenjit Biswas, Abhinav Thorat, Ravi Kolla, Niranjan Pedanekar

Position Bias Undermines Preference Consistency in Listwise LLM-Based Reranking

论文指出 LLM 列表式重排即使相关性变好，也可能因为候选序列化顺序不同而改变偏好。作者把等价排列视为同一偏好系统的多次观测，建立 pairwise instability、global inconsistency 和 listwise output consistency 三层指标，并在多种 LLM、数据集和列表长度上验证它们与最终效果并不等价；代码已开源，论文被 RecSys 2026 接收。

INSIGHT把 LLM 重排接入推荐主链路前，不能只看 NDCG 或曝光倾斜，还要做候选置换一致性测试。实际工程可固定随机种子并对同一候选集多次打乱，监控 pairwise 翻转率和列表一致性；若只通过调整位置权重来修补，可能降低边际偏差却保留不稳定的排序函数。

Ethan Bito, Yongli Ren, Estrid He

The Value of Personalized Recommendations: Evidence from Netflix

NetflixNorthwesternUC BerkeleyCCornell Tech

这项 Netflix 研究用离散选择模型分离推荐带来的效用与内容本身的吸引力，结合约 200 万名美国活跃用户、35 天观看数据，以及扰动推荐的随机实验验证模型。反事实结果显示，将现有推荐替换为矩阵分解或流行度算法，参与度分别下降 4% 和 12%；推荐带来的消费增量主要来自有效定向，中等流行度内容获益最大。

INSIGHT推荐系统评估应把“模型带来的曝光”与“内容本身受欢迎”拆开，否则 CTR 上升不等于个性化有效。对社区平台，建议在离线排序指标之外建立流量扰动或准实验，按内容流行度分桶测量增量点击、消费多样性和长尾收益，避免只优化头部内容的短期反馈。

Kevin Zielnicki, Guy Aridor, Aurélien Bibaut, Allen Tran, Winston Chou, Nathan Kallus

Conditionally Identifiable Latent-Environment Modeling for Out-of-Distribution Recommendation

CILER 关注推荐在时间、地域或特征分布变化下的偏好漂移，先把潜在环境建模为用户条件指数族，再用特征索引多项式描述环境如何改变偏好，最后对环境分布边际化得到预测。论文给出可识别性与部署风险界，并在 3 个数据集、特征/时间/地理三类 OOD 设置上，让 12 个排序指标全部提升。

INSIGHT当社区用户兴趣受季节、地域或事件影响时，简单把环境变量拼入特征并不能保证可迁移。CILER 的价值在于把“环境—偏好”关系显式化并给出风险边界；工程上可先用时间切片和地域切片验证 latent environment，再将其作为风险感知重排或校准模块，而不是直接替换线上模型。

Qianqian Wang, Wenwu Gong, Yunshan Li, Zhenqing Wu, Ruili Wang, Lili Yang

Circles powers telco personalization with OpenAI technology

OpenAICCircles

OpenAI 分享 Circles 使用 OpenAI API 与 Codex 构建 AI 原生电信体验的客户案例，业务目标包括个性化服务、运营自动化和更快的产品迭代。公开结果显示 ARPU 提升 22%、流失率下降 9%，同时开发效率改善；文章更偏工程落地与业务验证，而不是新的推荐模型。

INSIGHT这类案例对推荐团队的启示是先把个性化闭环接到业务结果，而不是只追求离线 AUC。可将用户意图理解、内容/套餐解释和运营实验接入现有排序系统，分开验证 ARPU、留存、满意度与 CTR；同时保留规则、人工审核和数据权限边界，避免把生成式能力直接等同于个性化质量。
