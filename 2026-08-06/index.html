DualGR: Generative Retrieval with Long and Short-Term Interests Modeling

DualGR 面向短视频推荐中的生成式召回，针对长短期兴趣互相干扰、层级 Semantic ID 解码噪声和曝光未点击信号缺失，设计长短期双分支路由、搜索式 SID 解码与曝光感知 NTP 损失。系统在快手短视频线上 A/B 实验中带来视频播放量 +0.527%、观看时长 +0.432%，说明生成式召回已具备可落地的业务收益。

Configure HSTU generative ranking in PAI-Rec: feature engineering, model training, and deployment

Alibaba

Alibaba Cloud 给出了在 PAI-Rec 中定制 HSTU 生成式排序的完整路径，覆盖公开数据集上的特征工程、模型训练和在线部署三个环节。它强调把生成式模型嵌入现有推荐平台，而不是重写全部链路；页面提供了可复现实验流程，但没有给出统一的 nDCG、CTR 或线上增益数字。

INSIGHT对于 UGC 短文本搜索，最现实的切入点是先把 HSTU 类模型放进粗排或重排灰度，保留既有召回、特征和回滚机制。应把特征版本、训练样本窗口、GPU 延迟和 nDCG/CTR 监控作为同一个交付单元，先在公开数据与小流量实验中验证收益，再扩大生成范围。

03 4.20

Training Documents Reranker with Search Rubrics for Deep Research Agent

RubricRanker 认为深度研究需要的是满足多样性、简洁性和权威性约束的文档集合，而不是逐篇相关的 Top-k。作者用 LLM 合成层级化搜索 rubric，再用 rubric 监督微调和强化学习训练重排器；在 4 个深度研究基准上较最强基线提升 2.6 个百分点，并泛化到 5 个 RAG 基准。

INSIGHT社区搜索的重排目标也应从单文档相关性升级为列表级覆盖：同时覆盖实体、观点和证据，避免 Top-k 全是同一条帖子或同一用户。可把 query 意图拆成可检查 rubric，用离线标注训练小型重排器，再以 nDCG、去重率、主题覆盖率和 CTR 联合验收。

Search, Inspect, Fetch: Exploiting Boolean Retrieval for Deep-Research Agents

SIEVE 将深度研究代理的 Search-Visit 流程改成 Search-Inspect-Fetch：先用字段化布尔检索约束标题、栏目和元数据，再展示结构化结果卡，最后只抓取选中的段落。在 3 个问答集合上，它相对最强传统配置减少 20.7%–50.6% token，同时在每个集合上取得更高准确率。

INSIGHTUGC 短文本天然带有标题、正文、话题、作者和时间等可寻址字段，适合把生成式搜索拆成轻量的字段过滤、候选检查和局部取文。这样既能减少 LLM 上下文噪声，也能把召回约束显式化；线上应重点监控 token 成本、首字延迟和结果字段覆盖，而不只是生成答案质量。

Shuai Wang, Haodong Chen, Yu Yin, Shengyao Zhuang, Bevan Koopman, Guido Zuccon

Generative Conversational Recommender System

论文把对话推荐和回复生成统一为一个自回归模型，用离散 Semantic ID 表示物品，并按“回复意图—推荐目标—回复文本”的结构化顺序联合生成。受约束解码保证生成的是有效物品；实验显示 Recall@1 最高提升 29%，同时保持有竞争力的对话质量，适合研究搜索与推荐的自然语言交互入口。

INSIGHT对社区问答或兴趣搜索，可将用户意图、候选内容和解释文本放进同一生成轨迹，但必须保留有效 ID 约束，避免模型生成不存在的帖子。工程上建议先让生成模型提出目标和解释，再由既有索引与安全策略校验内容，把自然语言体验与可控召回解耦。

Attacking and Defending Multi-Agent Collaborative Filtering Systems Through Connectivity

该工作研究由 LLM 用户代理和物品代理组成的协同过滤系统，重点考察连接度如何改变攻击与防御效果。作者在 AgentCF 中沿两条轴线系统变化候选数量和目录重合度，发现用户代理与物品代理存在角色不对称，攻击效果还会随时间呈非单调变化，并讨论了传播和抽取两类攻击目标。

INSIGHT生成式推荐上线前必须把代理交互面纳入安全评估，不能只测单模型越狱。对社区内容场景，应分别压测候选池大小、相似内容集中度、用户间热门内容重合率和多轮传播路径，并针对曝光污染、协同刷量和解释诱导建立可回滚的防御策略。

SciRet: A Compute-Aware Empirical Study of Retrieval and Reranking for Scientific RAG

SciRet 在 CORD-19 上固定 RAG 管线，比较 1,034、5,160 和 15,480 个文本块三种规模，组合 BM25、BGE-M3、RRF、可选 cross-encoder 和 grounded generation。混合召回在 1K 与 15K 规模都达到 Recall@10=1.000；反而 MS MARCO 训练的重排器降低科学语料 precision，RAGAS faithfulness 随规模上升。

INSIGHT这对 UGC 搜索的启示是先做域内验证，再决定是否引入更强的 cross-encoder：通用重排器可能因领域错配损害 precision。可先用 BM25+向量的混合召回建立基线，分别测短文本、长评论和新话题，再把生成答案的事实一致性与 nDCG、CTR 分开监控。

RAG-Stack: Co-Optimizing RAG Serving Performance and Quality

RAG-Stack 把检索索引、模型选择、调用方式和硬件服务配置放进同一个质量—性能搜索空间，包含迭代探索器 RAG-PE、工作负载抽象 RAG-IR 和性能模型 RAG-CM。相同优化迭代次数下，其 Pareto 前沿覆盖的归一化质量—性能空间比现有配置搜索方法多 52.5%–153.2%。

INSIGHT生成式搜推的瓶颈往往不是单个模型，而是召回质量、GPU 延迟、上下文长度和成本的组合。对社区搜索可以把索引、重排器、上下文截断和模型路由作为联合决策，用 Pareto 前沿选择 nDCG/CTR 与 P95 延迟的可接受点，避免只追求离线效果。

Haiqiang Zhang, Yuanqing Lei, Wanting Li, Tao Zhang, Wenqi Jiang

Fast and Efficient Approximate Nearest Neighbor Search for High-Dimensional LLM Embeddings

论文面向 SISAP 2026 两项 ANNS 任务：在 1024 维 BGE-M3 向量上构建 kNN 图，以及在未归一化 Llama-3.2-8B 特征上做 MIPS。方法使用 EVP 量化、定向重排、维度增广和 FLAS 一维预排序，重点改善图构建速度、缓存局部性和查询延迟，并公开了实现代码。

INSIGHT生成式召回最终仍需高效索引承接候选，UGC 场景应把语义向量的维度、MIPS/欧氏距离、构建耗时和 P99 查询延迟分开基准测试。先用预排序与量化改善内存访问，再用小比例精排补回 recall，通常比盲目扩大生成模型更容易在六个月内落地。

Video-DeepResearch: Towards the Next-Generation Multimodal Deepresearch Agent

Video-DeepResearch 将多模态研究代理从静态图像扩展到连续视频，针对模型偏向文字搜索和依赖参数记忆两个问题，采用感知—探索解耦、分阶段工具解锁以及 SFT 后 GRPO 的两阶段训练。作者构建了包含 200 个复杂任务的 Video-DR-Bench，用来评估跨帧视觉 grounding 与开放网络检索是否真正协同。

INSIGHT如果社区内容包含视频帖子，生成式搜索应先证明模型确实读取了关键帧，再允许它访问文本网页或生成摘要。可以借鉴工具解锁策略，把视频 grounding、候选召回和解释生成拆成可观测阶段，并用引用命中率、关键帧覆盖率和用户点击反馈共同约束模型。
