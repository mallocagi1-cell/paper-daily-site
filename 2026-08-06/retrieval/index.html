Coverage Matters: MarginMerge for Compressing Multi-Vector Visual Document Retrievers

多向量视觉文档检索依赖页面 patch 级表示，但索引体积和 late-interaction 计算成本很高。MarginMerge 以查询相关覆盖度为目标选择锚点、聚类 patch，并用轻量共享网络合成代表向量；压缩只发生在建索引阶段，线上仍使用标准 MaxSim。在 6 个数据集、ColQwen2.5 和 ColPali 上，仅保留 5%–10% 向量仍能保持原始 nDCG@5 的 97%–99%，存储向量减少 90%–95%。

Skill Is Not Document: Query-Conditioned Compatibility for LLM Agent Skill Routing

📖 深度解读 · 8 分钟 →

论文指出，Agent 技能不能按普通文档做点式相关性检索，Top-K 还必须组成当前查询可执行的技能集合。作者构建 R3-Skill 中英 benchmark，含 10,246 个去重技能、41,592 个已接受查询和 32,828 条拒绝标注，并采用 R3-Embedding 双塔召回加 R3-Reranker Cross-Encoder 重排。完整流程在 R3-Skill 达到 Hit@1 75.39%、NDCG@10 81.97%、Set-Compat 33.27%，相对最佳重排基线提升 36.6%。

INSIGHT对社区短文本搜索，双塔只能保证单条语义相似，无法表达候选之间的组合冲突；可以把 query-conditioned compatibility 作为重排阶段的额外监督。工程上可先保持高召回双塔，再在小候选集用 listwise cross-encoder 判断结果集合是否共同满足意图，尤其适合多意图查询、工具路由和带约束的结果混排。

Zifei Wang, Wei Wen, Qiang Ji, Keyu Chen, Ruizhi Qiao, Xing Sun

03 4.10

Field Aware Agent Skill Retrieval

现有技能检索常把名称、描述和正文拼成一个平面文档，容易丢失字段各自表达的使用时机与调用方式。论文保留字段结构，分别计算稀疏和稠密相似度，再用均匀权重或小型 MLP 融合字段级分数；在 SkillRet 与 SRA-Bench 两个 benchmark 上，field-aware MLP 分别达到 Recall@10 77.95% 和 83.78%，并优于拼接后学习的基线。

INSIGHTUGC 帖子、问答和评论往往同时包含标题、正文、标签、作者与上下文，不应默认拼接后再编码就是最优表示。可借鉴字段级召回与可学习融合：先保留字段身份，按查询类型学习权重，再将结果融合到现有倒排或向量召回中；候选规模越大，结构化表示的收益越值得验证。

Paimon Goulart, Liang Wu, Kelly Wan, Evangelos E. Papalexakis, Liangjie Hong

Diagnosing and Mitigating Context Rot in Long-horizon Search

论文在 4 个旗舰模型、3 个 benchmark 上研究长上下文搜索的 context rot，发现模型会在耗尽上下文窗口前提前放弃或给出不确定的错误答案，并且 premature termination 与上下文长度正相关。作者分析 3 类共 7 种上下文管理方法，将其解释为降低提前终止率的 test-time scaling；同时提出行为感知过滤的并行采样策略，在 3 种聚合方法上带来 2.6%–4.9% 的性能提升。

INSIGHT对社区搜索的多轮 query 理解或深度检索，增加上下文不等于一定提高相关性，过长历史可能让模型提前停止。线上可记录上下文长度、检索轮数与不确定性信号，按模型选择裁剪、分块或并行采样策略，并用 nDCG、答案可验证性和延迟做联合门控，而不是只扩大 token 预算。

Shijie Xia, Yikun Wang, Zhen Huang, Pengfei Liu

05 3.90

MemArena: An Ego-Centric Benchmark for On-Device Agentic Personal Memory Assistants at Scale

MemArena 用 MASim 构造单世界对话 benchmark，覆盖 50 个 Agent、15 天交互、1,030 万 dialog-text tokens 和每天每个 Agent 24.1K 个可观察 token，并从召回、推理和可信度六个维度评估记忆后端。五个开源 reader 的对比显示，在 Qwen3-0.6B 上 Memobase 换成 MemSearch 带来 32.5/19.2 个百分点收益，超过 reader 扩容的 10.6/6.8 个百分点；Spark GB10 上搜索增加 7–87ms。

INSIGHT它把检索质量与权限、长期上下文和延迟放到同一评测中，适合借鉴到社区搜索的用户历史与私密内容场景。不要只看离线 Recall：应同时测跨会话记忆命中、权限误放、过度保守和 TTFT；若 reader 较小，检索延迟更敏感，但固定的 7–87ms 预算仍可能比盲目增大模型更划算。

Jiadong Zhang, Xiaosong Ma

LegalPincite: Multi-level Legal Information Retrieval Dataset

LegalPincite 针对法律检索数据集中的查询泄漏与语料缺失问题，基于欧盟法院判决构造多层级 benchmark。数据包含移除引用信息的案件/段落查询、保留全部段落的语料库、案件级与段落级引用真值，并提供部分人工专家校验；可评估 case-to-case、paragraph-to-case 和 paragraph-to-paragraph 三种检索粒度。

INSIGHT社区 UGC 相关性标注也容易因为把答案词、引用或已过滤内容泄漏到 query 而虚高。该数据集的设计提醒我们：构建 nDCG/Recall 评测时要保留未命中、无关和长尾段落，拆分文档级与片段级标签，并对 query 脱敏；这样训练出的语义匹配模型才更接近真实搜索分布。

Theresia Veronika Rampisela, Henrik Palmer Olsen, Giovanni Colavizza

ISEE: Interactive Semantic Enrichment for Database Fields

ISEE 面向含义不完整或模糊的数据库字段，先用质量评分识别语义缺口，再搜集领域知识并与用户协作补全字段描述。论文通过用户研究、自动用户模拟、定量评估和案例研究四类验证，报告认知负担下降、描述质量改善以及下游实体链接性能提升；主题同时覆盖数据检索与实体匹配。

INSIGHT短文本搜索中，query 与内容字段的语义缺失常常比模型容量更早成为瓶颈。可以把字段语义质量作为离线数据治理指标，在训练 embedding 或 reranker 前让领域用户补充别名、口语、业务约束和字段边界；对社区帖子则可将标签、作者身份和内容类型做成可解释的语义元数据。

MultiGlobeQA: A Multilingual and Globally Diverse Benchmark for Geospatial Reasoning

MultiGlobeQA 构建了 46,060 个问答对，覆盖 14 类空间函数、15 种答案格式、201 个国家和地区，并在 3 个知识图谱上生成可执行真值，问题平行覆盖英语与另外 16 种语言。实验发现检索和工具调用能明显提升结果，但即使提供 gold facts，性能仍低于三分之二，网格索引和形状计算尤其困难。

INSIGHT对于带地点、实体关系和多语言表达的社区搜索，召回到正确事实只是第一关，后续计算与排序仍可能失败。可借鉴其执行式真值和分语言切片评测：把检索命中、工具调用、空间/关系计算分别计分，避免用一个总分掩盖低资源语言和长尾地域的真实缺口。

搜索核心算法：从召回到排序

中文工程文章以亿级甚至十亿级文档为背景，梳理查询理解、多路召回、粗排、精排和重排的级联流程：召回阶段在毫秒级捞取几百到几千个候选，粗排再从几千缩到几百，精排使用更复杂模型，重排负责去重、打散和业务混排。文章强调 Query 理解质量决定召回与排序上限。

INSIGHT对社区搜索落地，先把链路拆成可观测的查询理解、召回覆盖、粗排淘汰、精排相关性和列表级重排，再分别优化 nDCG 与 CTR。文章不是新算法论文，但提供了适合团队对齐的工程分层；可用召回漏斗和各阶段延迟预算定位问题，避免把所有损失都归因于 embedding。
