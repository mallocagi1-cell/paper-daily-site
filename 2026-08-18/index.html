GEM: A Generative Embedding Model Bridging Reasoning and Retrieval

GEM 将“理解查询”和“生成向量”合并到一个因果语言模型中：模型先生成用户意图与相关性标准，再用专用 embedding token 编码查询，并与文档向量做对比学习。在 BRIGHT 上平均 nDCG@10 达 29.1，同骨干的非生成版本在定理任务上从 19.8 提升到 32.0；FollowIR 的 p-MRR 为 +11.7，较同骨干基线 +6.8 明显更高。

RL-Index: Reinforcement Learning for Retrieval Index Reasoning

RL-Index 把查询时推理前移到索引阶段，用 LLM 为文档生成解释性增强信息，再以 GRPO 和检索相似度奖励优化索引决策。在 BGE 上 nDCG@10 从 13.6 提升到 15.4，端到端延迟为 114.6ms；相比需要 7,736.9ms 查询推理的 TongSearch，速度约快 68 倍，同时组合方案达到 19.3 nDCG@10。

INSIGHT它适合社区搜索中“文档隐含关系难以由 query 表面词表达”的场景：离线为帖子补充意图、因果或主题桥接信息，线上继续走普通向量召回。关键收益来自把昂贵推理变成可复用索引资产，但要建立增量重建、索引版本和错误解释回滚机制。

How retriever redundancy and diversity impact RAG effectiveness

The University of QueenslandCSIRO

论文在 FictionalQA 上控制答案内容不变，只比较重复文档、LLM 改写文档和不同体裁文档对生成器的影响，覆盖 1,900 个多体裁问题，并用 1,443 个筛选问题排除答案字符串泄漏。结果显示重复和改写没有显著增益，而多样文档可使答案正确率提升 17%–47%。

INSIGHTRAG 召回不应只优化单文档相关性；对社区问答生成，候选集应在保持相关的前提下覆盖不同作者、体裁和证据表达。可把 MMR、来源配额或覆盖约束放在重排层，并用“生成答案正确率”而非单纯 Recall 评估多样性是否真的有益。

Jonathan J Ross, Bevan Koopman, Anton van der Vegt, Guido Zuccon

How Much Do Legal RAG Systems Still Hallucinate?

论文评估 8 个法律 RAG 系统，覆盖 GDPR 英文语料、法国民法语料以及法律专家独立编写的 142 个问题，并按 claim-level 和 answer-level 统计幻觉。最佳系统的回答幻觉率低于 10%，最差接近一半；在 CIVIL 的错误前提问题上，BM25+Mixtral 的 claim hallucination 达 100%，而 BM25+GPT-5 为 3.5%。

INSIGHT对 UGC 搜索的生成式答案，最危险的不是检索不到，而是把用户错误前提当成事实继续生成。线上评测应增加错误 query、冲突证据和 claim 级校验，采用“拒答/纠错率+幻觉率”双指标；召回模型升级不能替代生成后的证据对齐。

Souvick Das, Sallam Abualhaija, Domenico Bianculli

HAM-RAG: Hierarchy-Aware Multimodal RAG for Structure-Faithful Interleaved Generation

HAM-RAG 用文档层级作为检索与生成的共同 grounding 信号，保留章节位置、文本—图像邻接关系，并在 Wukong、Wiki、arXiv、Recipe 四类数据上构建 HAM-Bench。跨多个骨干模型，主多模态平均指标较最强非层级基线提升 17.3%，Wukong 的 Img-CBS 提升 24.2%。

INSIGHT社区帖子、评论和图文笔记同样存在标题—段落—图片的局部结构；将层级元数据带入召回上下文，有助于避免“找到正确片段却生成错关系”。可以先在高价值图文问答场景做层级 chunk、父子证据链和位置感知重排，再观察 nDCG 与答案引用一致性。

TeachMateGPT: A Multi-Agent Knowledge-Grounded Framework for Pedagogical Assessment Generation from Science Curriculum Materials

TeachMateGPT 用 COPE 多分辨率层级索引替代平铺切块，并以路由、密集+词法融合、coverage gate 和 fail-closed 流程约束生成。实验摄入 14 个章节、793 个层级 chunk，共生成 198 道题；MCQ 结构通过率 95.8%，创意题的叙事结构通过率 100%，语言纯度达到 94.5%。

INSIGHT对社区 UGC，分层索引和“证据覆盖不足就不生成”的门控比单次 top-k 召回更稳健。可把帖子主题、楼层、评论链作为多层 lineage，并让生成器只能引用通过 coverage gate 的片段；代价是索引和路由复杂度上升，需要离线可观测性。

Fatema Tuj Johora Faria, Mukaffi Bin Moin, M. F. Mridha, Jubayer Al Mahmud

Do AI chatbots find what experts would? Effects of model, user role, and sample size on study retrieval for medical questions

研究用 20 个 Cochrane 综述问题测试 Claude Sonnet 5、Gemini 3.1 Pro 和 ChatGPT GPT-5.5，按患者、临床医生、证据综述研究者三种角色重复提问 720 次。单次回答平均找回 39.2% 的纳入研究、引用 5.0% 的排除研究；ChatGPT 纳入研究召回率 63.1%，明显高于 Claude 的 37.0% 和 Gemini 的 17.3%。

INSIGHT生成式搜索的召回表现会随模型、用户角色和样本规模系统性变化，不能只用一个 demo 评估。社区搜索应按 query 意图和用户画像分层测召回，并监控热门度偏置；对高风险答案，要同时核验纳入与排除集合，而不是只看引用数量。

Qingfang Liu, Qiao Jin, Joe D. Menke, Thorsten Kahnt, Zhiyong Lu

S2Dialog: Multimodal Dialogue Retrieval with Semantic and Acoustic-Style Modeling

S2Dialog 面向多模态对话库同时学习文本语义和音频风格，分别设置 Dialogue-level Textual Retriever 与 Acoustic Retriever，并用对比损失和 Bottom-K 难负例塑造联合空间。Recall@10 达 50.68，Recall@50 达 83.56；去掉 Bottom-K 后 Recall@10 降至 21.12，说明难负例挖掘是主要贡献。

INSIGHT虽然任务是对话检索，但它提示 UGC 搜索可把文本语义、表达风格和多模态上下文拆成可组合的检索信号。对于视频评论、语音帖等内容，建议采用多塔召回后融合，并把难负例训练作为防止“只匹配文本主题”的关键环节。

Xueqi Wang, Zhigang Wang, Runqing Zhang, Zhenqi Jia, Junfeng Zhao

HERMES: a multi-agent framework for structured knowledge extraction from ultra-long documents in geoscience

HERMES 用协调式 LLM 组织多智能体，从超长文档中联合处理正文、表格、图和图注，并把领域约束、校验规则、证据追踪纳入同一抽取流程。在 55 卷古生物专著上构建 32,277 个分类实体和 451,878 个属性，实体平均 F1 约 0.90、属性 F1 约 0.91，单卷效率提升约 6 倍。

INSIGHT对社区内容，生成式搜索的上限取决于可检索知识是否结构化。可借鉴 HERMES 的领域约束、证据链和多模态抽取，把长帖、评论树和图片说明预先转成可验证实体；但应先做小规模离线索引，避免多智能体成本吞噬搜索延迟预算。

Developing Nemotron 3.5 Lightning NVFP4 with QAD Using NVIDIA Model Optimizer

NVIDIA

NVIDIA 工程实践介绍如何用 Model Optimizer 和 QAD 将 Nemotron 3.5 Lightning 优化到 NVFP4，面向延迟、吞吐、显存和算力目标进行模型定制。该方案与生成式搜推的直接关联不在算法指标，而在于为生成式召回、重排和答案生成提供 4-bit 推理压缩路径，适合作为部署侧参考。

INSIGHT生成式检索线上落地通常先被解码成本和显存限制，而不是离线指标卡住。可把 NVFP4/QAD 作为候选优化方向，但必须在真实 query 分布上联合验证 nDCG、CTR、首 token 延迟和答案一致性，避免量化后只剩吞吐提升却损失相关性。
