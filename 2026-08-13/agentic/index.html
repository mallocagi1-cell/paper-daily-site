Critic-R: Improving Agentic Search using Instruction-tuned Retrievers with Natural Language Introspective Feedback

针对 Agentic Search 中检索器只按局部 query-passage 相似度优化、无法利用后续推理结果的问题，Critic-R 引入 critic 判断当前证据是否足以支撑下一步，并用 Critic-R-Zero 迭代改写查询、用 Critic-Embed 从成功/失败轨迹自动训练检索器。论文在 HotpotQA、2WikiMultihopQA、MuSiQue、Bamboogle 四个多跳问答基准上验证，目标是把智能体反思转成无需人工相关性标注的检索监督。

LLM Agents Factory: Retrieval of Domain-Specific LLM Agents

论文把按请求动态设计 Agent 的高成本和不稳定性转化为检索问题：预先建立超过 20K 个角色化 Agent profile，先用语义搜索选择领域 Agent，再可蒸馏为紧凑模型直接生成 Agent。MMLU、BIG-bench 和 BIG-bench Hard 的单 Agent 实验显示，检索式构造优于非 Agent 基线，并以明显更低推理成本接近 120B backbone 的 AutoGen 生成质量。

INSIGHT对社区搜索中的复杂意图，可以把查询理解、召回、事实核验等能力封装成可检索的 Agent profile，而不是让一个大模型每次从零规划。工程上应维护 profile 的版本、适用域和工具契约，并用小模型负责路由与蒸馏，大模型只覆盖低频、高不确定性的搜索任务。

Vitalii Belov, Artyom Sosedka, Andrey Sakhovskiy, Elizaveta Kovtun, Artyom Boyarskikh, Semen Budenny...

Detecting an Effect Is Not Learning to Act on It: A Reward-SNR Floor for LLM Acquisition Agents

论文研究 Agent 是否应为每个样本付费获取昂贵的 LLM 推理、慢速 Oracle 或额外观测，提出 Reward-SNR floor 区分“信号平均有效”和“策略能按实例学会何时调用”。在逐曝光、聚类、状态区间和 uplift-tree 四种路由粒度下，学习策略均未胜过随机；匹配矩噪声 placebo 还能复现至少 100% 的 Oracle 表面收益。

INSIGHT这对 Agentic RAG 的多轮搜索预算很关键：离线挑出高收益轨迹不能证明线上模型能识别高价值查询。应同时做随机对照、噪声 placebo 和 per-instance policy 评估，再决定哪些 query 值得继续检索；否则系统可能只是把排序噪声误判为可学习的调用信号。

Ying Yuan

InSight-doc: Agentic Visual Perception for Long-Document Understanding

InSight-doc 将视觉分辨率视为 Agent 在推理时可自适应分配的资源：先低分辨率浏览长文档，再对疑似证据区域选择性放大，无需外部 retriever。作者构建 17.9K 条带区域缩放轨迹的 SFT 数据和 19.2K 条 RL 数据；InSight-doc-8B 在文档 VQA 上提升 4.3–16.4 个准确率点，长文档幻觉下降超过 40%，推理延迟降低 41%–68%。

INSIGHT社区帖子、评论和图文混排内容不应默认全部塞入上下文。可以先做低成本粗读，再按实体、表格或证据密度触发局部精读，并把缩放动作纳入 Agent 轨迹；8B 模型和公开代码降低了试点门槛，但仍需用 nDCG、证据命中率、P99 延迟和图片 OCR 错误率共同验收。

Kaican Li, Weiyan Xie, Lewei Yao, Jiannan Wu, Lanqing Hong

CoHyDE: Iterative Co-Training of LLM Rewriter & Dense Encoder for Tool Retrieval

📖 深度解读 · 13 分钟 →

agent 选工具时，用户说的是口语，工具库写的是技术说明，单靠微调检索编码器在模糊查询上会掉得很厉害。SAP 的做法是让大模型改写器把用户的话写成工具说明书风格的描述，编码器只用这些描述重训，改写器再按编码器的检索得分做 DPO，两边轮流训三轮。在约 1 万个工具的 ToolBench 子集上，模糊查询的 NDCG@5 平均提高 6.3 个百分点，标准查询只提高 2.5 个百分点。代价是每条查询多一次 4B 模型生成，延迟约 546 毫秒。改写器和编码器要一起训，各自训好再拼起来反而更差。

Vaishali Senthil, Ashutosh Hathidara, Sebastian Schreiber

ENTLORE: A Graph-Grounded Benchmark for Latent Organizational Reasoning in Enterprise Question Answering

SScitiX.ai

ENTLORE 评测 Agent 是否能从未直接写出的组织关系中完成企业问答，而不只是拼接显式事实。框架用审计后的 truth graph、版本化组织规则和 proof certificate 构造 2,341 份文档、907 个问题，并比较 56 种模型与访问配置；即使提供 gold documents，潜在关系问题仍有 30.4% 未答对，显式查找和组合问题分别为 12.6% 与 6.2%。

INSIGHT社区 UGC 搜索也存在“文档找到了但关系没恢复”的问题，例如作者—话题、事件—地点或评论—帖子之间的隐含连接。评测应把单跳召回、跨文档组合、潜在关系推理拆开，并记录证据链和可验证答案；否则一个看似更高的最终准确率无法说明 Agent 究竟改进了检索还是只改进了生成。

Akrin Zheng, Alexander Wu, Alaia Liu

SPIEval: Evaluating Large Language Models as Mobile Assistants over Scattered Personal Information

SPIEval 将个人信息分散在多个 App 的真实检索困难显式化，覆盖推理、消歧、信息整合、偏好推断和多意图分解五类能力。基准包含 250 个任务、4,335 条记录、10 个 App 和 21 个工具，评估 9 个模型；最佳 GPT-5.5（xhigh）准确率只有 57.3%，最弱模型为 16.4%，且 79% 的失败来自信息定位错误。

INSIGHT对社区搜索 Agent，最危险的不是不会生成答案，而是在第一次命中后过早停止验证。应把“继续检索”作为显式动作，给 query、证据、来源和用户偏好建立可追踪状态；评测除最终答案外，还要统计定位错误、误用证据、工具调用深度和跨来源整合成功率。

Junjie Ye, Zhuohui Sheng, Shaofan Liu, Yulun Zhu, Wenjie Fu

VibeLifeBench: Can Your Life Agent Be Proactive and Persistent in a Living World?

小红书

VibeLifeBench 针对现有 Agent 基准只测静态短任务的问题，构造跨数周、世界会自行变化且约束常被省略的长期任务。基准包含 10 个生活领域、200 个任务和 22 个模拟服务，每个任务用细粒度加权检查评估最终状态、行动时效和隐含约束；7 个前沿模型整体得分都偏低，显示持续感知与主动行动仍是瓶颈。

INSIGHT社区平台的搜索需求也会随热点、作者状态和内容生命周期变化，不能把一次回答的准确率当作 Agent 能力终点。可借鉴其时间线与后端状态评测，把新帖发现、过期内容回避、用户偏好更新和主动澄清纳入长期 replay，并为“不该行动”设置明确的负奖励。

Xiaohongshu Inc

Role of Personality in Conversational Information Seeking

University of Glasgow

论文把对话式信息检索中的助手风格视为可控变量，使用同一 GPT-4.1 基座、三种风格和三类任务开展受试者实验。26 名参与者各完成旅行规划、手机比较和健康信息核验三项任务；外向风格平均回复 146.38 词，尽责风格 90.22 词且用户词量占比更高，信任和委托意愿取决于任务与风格匹配，没有全局最优风格。

INSIGHTAgentic 搜索的交互质量不应只看 nDCG 或答案正确率，澄清次数、用户信息量和信任也会改变后续 query。社区产品可以按探索、比较、核验场景动态选择对话策略，同时保留简洁基线；不要把更长回复或更主动追问直接当成更好的用户体验。

Abdisalam Abukar, Junchen Fu, Chengli Zhai, Joemon M. Jose

DSAgentBench: Can Agents Automate End-to-End Data-Science Workflows in Real Computer Environments?

DSAgentBench 把 Agent 放进真实计算机环境，要求其协调 notebook、IDE、终端、浏览器和数据库完成端到端数据科学流程，而不是只执行一段代码。基准含 275 个覆盖数据处理、建模、可视化和验证的任务，评估 15 个开源与闭源模型；最强 Claude-4.6-Sonnet 任务成功率为 56.70%，所有开源 Agent 均低于 1%。

INSIGHT这为搜索 Agent 的工程评测提供了可迁移范式：把工具编排、操作系统落地、中间结果反馈和最终业务正确性放进同一任务，而不是只测单轮 QA。社区搜索可构造带索引更新、召回失败重试、结果过滤和排序回写的长链路任务，用确定性检查器区分模型推理错与工具执行错。

Mizanur Rahman, Mohammed Saidul Islam, Ridwan Mahbub, Md Tahmid Rahman Laskar, Shafiq Joty
