Training Dense Retrievers with Multiple Positive Passages

工作系统比较多正例 dense retriever 的 JointLH、SumMargLH 与 LSEPair 三类目标，并统一到对比学习框架。它在 Natural Questions、MS MARCO、BEIR 及人工/LLM 混合标注两种设置上验证：LSEPair 整体更稳健，另外随机抽取一个正例的 Rand1LH 也是可靠基线；JointLH 与 SumMargLH 对正例质量更敏感。

When Do Anchor-Based Pointwise LLM Rerankers Help? Retriever Quality, Statistical Scope, and Anchor Design

论文复现 anchor-based pointwise LLM 重排，首次仅按论文文字实现时 nDCG@10 只有 0.24，而原报告为 0.66；补齐 8 个实现细节后，结果误差缩小到 1.6%。跨数据集实验发现，对 BM25 有帮助的对比分数在 E5 等强稠密召回器上收益很小，简单交错 top 句子即可替代复杂 anchor。

INSIGHT对社区短文本搜索，先按召回器类型决定是否启用 LLM 重排：BM25 候选更值得尝试，对强 dense 候选应先做增量收益评估。上线前必须记录 tokenizer、截断、anchor 拼接等实现细节，并用 query 分桶验证收益，避免把论文中的复杂结构直接照搬到 P99 链路。

Utshab Kumar Ghosh, Shubham Chatterjee

Post-Calibration Reliability Reranking of Relevance Decisions via Label-wise Monotone Projection

论文提出 Label-wise Monotone Reliability Projection（MRP），在保持原预测标签和类别概率的前提下，对每个标签学习单调可靠度映射，再按残余风险重排。方法在 6 个信息访问相关性数据集和多种后校准器上提升可靠性重排与 fallback utility，同时保持全覆盖准确率和 ECE；消融显示主要收益来自标签条件的残余可靠性。

INSIGHT社区搜索的低置信 query 可进入更贵的重排或人工兜底，但 raw relevance score 不能直接当路由概率。建议在现有校准层后增加 label-wise reliability 特征，分别评估 nDCG、ECE、fallback 命中和延迟；这样能把‘结果相关’与‘系统是否该相信它’拆开优化。

Inwoo Tae, Yongjae Lee

Similarity Gates Approve Reversals: A Validity Audit of Embedding-Cosine Thresholds in Agent Systems

这项审计指出固定 embedding cosine 阈值并不等价于语义一致性：被测 drift guard 对 56 个破坏含义的变体全部漏检，甚至把‘停用研究药物’改成‘给药’的反转判为 0.9608。90 个配置阈值任务单元的 balanced accuracy 中位数仅 0.525，18 个配置任务中有 13 个 AUROC 为 0。

INSIGHT搜索系统的语义缓存、去重和 query 改写门禁不能只看 cosine。应增加反转、否定、数值和实体替换样本，采用 matched-pair 离线审计，并把阈值按 query 类型校准；论文中少数配置在配对审计上达到 AUROC 0.79–0.90，说明评测设计比盲换 encoder 更关键。

Scott E. Frias

Reasoning-enhanced Query Understanding through Decomposition and Interpretation

BaiduChinese Academy of SciencesUniversity of Amsterdam

ReDI 将复杂 query 理解拆为三步：按意图分解子查询，为每个子查询生成面向 sparse 或 dense 检索的语义解释，再独立召回并融合排序。论文使用商业搜索引擎的复杂 query 数据，并在 BRIGHT、BEIR 上同时验证 sparse/dense retriever；公开材料报告 BRIGHT sparse 平均 nDCG@10 为 30.8%，BEIR 为 44.9%。

INSIGHT社区搜索的长尾短句常把多个意图压在一个 query 中，直接 embedding 容易丢掉实体关系。可先只对高复杂度 query 启用轻量分解，分别生成词法扩展和语义解释，再用 RRF 或学习融合合并候选；同时监控 query 膨胀、重复召回和额外延迟，避免所有请求都走 LLM。

Persona Conditioning as an Assessor-Sensitivity Probe for LLM-Based IR Evaluation

论文把 persona conditioning 作为 LLM 相关性评估的敏感性探针，设置意图解释、领域专家、对比判断、证据核验和全局搜索质量 5 类角色。跨 6 个 LLM、TREC DL20 与 RAG24 的结果显示，判断通常接近 UMBRELA 基线，但小模型更易放大 persona 不稳定性，敏感性集中在神经重排和 RAG 管线。

INSIGHTUGC 搜索离线评测中，LLM judge 的角色设定可能改变长尾 query 的标注门槛。建议固定一套标准 persona，同时用至少两种任务 persona 做压力测试，报告系统排序一致性和 query 级 rank displacement；发现敏感桶后再回看标注定义，而不是只追逐一个总 nDCG。

Samaneh Mohtadi, Pietro Bernardelle, Joel Mackenzie, Gianluca Demartini

07 4.20

$\mathrm{ECI}_{\mathrm{sem}}$: Semantic Residual Effective Contrastive Information for Evaluating Hard Negatives

ECIsem 用冻结目标 encoder 的表示，为 hard-negative 来源计算目标一致性、语义局部性和词汇残差性，并以加权残差方向诊断迁移价值。在 MS MARCO 负例源上，它能恢复 DistilBERT、E5-base 和 Contriever 的 BEIR transfer 排序；但 36 个门控组合中仅 1 个安全，说明相似度门槛不能直接当奖励。

INSIGHT社区短文本的 hard negative 应先做来源审计，再用于训练。可把词汇残差、语义邻近和正例一致性作为数据质量特征，按来源预估迁移性；对疑似 false negative 保留 audit profile，不要简单加权采样，否则会把‘看起来难’的错误负例灌入 retriever。

Aarush Sinha, Rahul Seetharaman, Aman Bansal

GraFine: Retrieval-Time Refinement for Efficient Graph RAG over Corpus Graphs

GraFine 面向图 RAG 的两类检索盲点，交替使用语义邻近扩展 SPX 和图平滑重排 GSR，在加入候选的同时利用拓扑结构剪枝。论文在参考网络和文本知识图谱上评估检索与生成质量，并提出 Topological Recall 衡量检索节点与 oracle 节点的拓扑接近度；代码已公开。

INSIGHT社区帖子、话题、作者和实体关系可组成轻量 corpus graph，适合在 dense 召回漏掉关键上下文时做受控扩展。工程上应把语义扩展、图剪枝和时延预算分开埋点，用 Topological Recall 类指标检查是否找到‘中间线索指向的未召回节点’，避免无界图遍历拖垮在线链路。

Seonho An, Chaejeong Hyun, Min-Soo Kim

DistilVDR: A Compact End-to-End Visual Document Retriever via Dual-Student Distillation

DistilVDR 用单个 8B 视觉语言 teacher 双向蒸馏出 524M 单向量视觉文档 retriever，采用 pointwise cosine 对齐，不需要相关性标签、负采样或对比损失。HiRes 在 ViDoRe v1+v2+v3 上平均 NDCG@5 为 61.74，达到 teacher 的 86.9%；百万文档索引比最强 sub-1B 多向量基线小 15.6 倍，索引速度提升一个数量级。

INSIGHT社区内容逐步包含图片、截图和图文混排，纯文本 dense retriever 会漏掉视觉证据。可借鉴其非对称 encoder 与 teacher-space 蒸馏，把文档侧视觉容量和 query 侧轻量编码拆开；上线前需同时测索引体积、更新速度、图文 nDCG 与纯文本回退质量。

Zhuchenyang Liu, Ziyi Wang, Yao Zhang, Yu Xiao

Self-Knowledge Retrieval Augmented Generation Framework for Patent Matching

论文提出面向专利匹配的 self-knowledge RAG：先让 LLM 从查询中抽取技术实体并构造层级本体，再做 query expansion，结合 FAISS 检索与生成式匹配处理复杂术语和多模态信息。作者在真实专利数据集上报告检索匹配效果提升，但摘要未给出具体指标，当前更适合作为复杂领域召回架构参考。

INSIGHT对社区 UGC，实体、话题和属性抽取可以作为 query expansion 的结构化中间层，但不宜直接让 LLM 自由生成扩展词。建议先把实体层级、来源和置信度落库，再与 BM25/dense 结果做可解释融合，并用长尾 query 的召回覆盖和误扩展率做门禁。
