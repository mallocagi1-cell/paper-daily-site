CoVeR: Coverage-Based Routing of Verifier Calls in Agentic Retrieval

针对多步搜索每轮重复验证证据的开销，CoVeR 用冻结句向量的覆盖缺口筛掉明显不完整状态，仅在模糊状态调用验证器。在 HotpotQA 和 2Wiki 上验证调用分别减少 62.2% 和 67.8%，EM 相对始终验证仅变化 −0.10 和 +0.20 个百分点；93% 的 MuSiQue 降幅属于饱和场景。

SpeakerMem-R1: Speaker-Centered Dual-Track Memory for Multi-Party Dialogue

Zhejiang University

SpeakerMem-R1 面向多人对话中的说话人归属与状态重建，将带身份的原始消息和个人、群组结构化状态分别存储，再按实体、事件和时间联合检索。三个多人记忆基准准确率为 47.9%、69.2%、61.9%；305 题控制实验中，强化学习使写入器准确率从 57.38% 升至 68.20%。

INSIGHT社区帖子、回复和评论常混合作者观点、他人转述及群体事实，双轨记忆能保留原话供核验，同时提供可搜索的结构化状态。可先把作者、被讨论对象与时间拆成独立字段，再试验带说话人条件的写入奖励；需要用社区语料验证归属错误是否下降，现有结果不能直接推导 nDCG 或 CTR 收益。

Haobo Zheng, Tan Tang, Yan Chen, Weijie Wang, Yingcai Wu

Knowledge-as-Skill: A Structural Design for Autonomous Knowledge-Base Use by LLM Agents

Knowledge-as-Skill 用发现、导航、知识三层结构让 Agent 自主理解知识库范围，并通过目录索引和元数据记录来源及生命周期。WixQA 初步评估中事实性为 0.889、上下文召回为 0.816，对照工作报告值为 0.767 和 0.708；模型及提示不受控，且精度和交互轮数存在代价，不能视为严格胜出。

INSIGHT社区搜索可为专题、问答合集和运营知识建立可浏览的目录说明，让 Agent 先判断内容范围，再读取相关帖子，减少盲目拼接文本块。该设计无需重写 Agent 框架，适合先做小规模原型；但目录维护成本、内容更新与多轮读取延迟必须纳入实验，并用相同模型和检索预算重做对照。

Jiangxu Wu

04 3.90

MoM: Memory of Memory

NUS

MoM 将当前知识状态与历史来源一并管理，P-Mem 用类型化溯源图区分支持、替代、争议和撤销，查询只暴露当前有效值。图引导裁剪使陈旧答案率从 19.4% 降至 10.9%；修订链准确率为 100%，查询时重建基线为 25%，同时保留历史可修复覆盖式记忆无法恢复的错误。

INSIGHT社区内容会出现编辑、辟谣和观点变化，单纯按相似度召回容易把旧结论重新放回答案。可以把来源、有效状态和修订关系做成 Agent 记忆的一等字段，保留被替代证据用于回滚；约四倍读 token 节省主要来自检索粒度变化，应与图结构带来的有效性收益分开评估。

Bowen Qin, Yao Lu

FinFIRST: Benchmarking Search Agents for Financial Information Retrieval, Sourcing and Traceability

IInclusion AIPeking UniversityCCICC

FinFIRST 将金融搜索答案与支撑证据拆成原子评分规则，覆盖信息获取、来源核验和计算成文。基准含 123 个专家任务、138 个来源及 15 种模型配置；最高原子得分为 87.59%，最高严格通过率为 71.54%，说明局部信息正确并不意味着完整任务可靠完成。

INSIGHT社区搜索的复杂问题也需要检查时间、实体和引用是否对齐，可借鉴原子规则将检索错误、证据错误和答案合成错误分别定位。首先为高价值问答建立少量人工审核任务，再同时报告局部得分与全条件通过率；金融领域的数字不能外推到社区 CTR，但其评测拆解方式可直接借用。

The Tasteful Agent: Measuring and Improving Taste in Long-Horizon Tasks

City University of Hong KongMicrosoft

Taste-Bench 从 Agent 的并行尝试与轨迹绕路中自动提取决策岔路，让模型在看不到后续结果时选择方向，评估长任务中的决策质量。最佳模型正确率仅 59.7%，增加推理预算未改善表现；利用知晓结果的教师蒸馏，可改善学生在未见任务上的选择与 SWE-bench Pro 端到端成功率。

INSIGHT社区搜索 Agent 的关键决策往往是继续查证、换查询词还是结束，可以从历史成功和失败检索轨迹构造类似岔路题。借鉴结果感知教师生成训练信号时，必须按任务隔离训练与测试，防止未来证据泄漏；先检验决策正确率是否转化为更好的证据覆盖和更低搜索成本。

Wenbo Pan, Zhichao Liu, Shujie Liu, Jingying Zeng, Chin-Yew Lin

Self-Cleaning and Captured Anyway: One Measured Primitive for Error in a Store an Agent Writes to Itself, and What a Falling Score Actually Measures

论文研究 Agent 将自身结论写回记忆库后的错误循环，用实测复制函数分析错误是否持续扩散。在 36 个 Wikidata 事实上，判据预测了 360 次运行中 353 次的漂移方向；220 次运行呈现明显双峰，均值只代表少数轨迹，作者同时披露失败、撤回和未定论的实验行。

INSIGHT社区搜索若把生成答案再次作为可检索知识，可能逐步放大未经证实的结论。可以借鉴按随机种子与事实分别报告轨迹的审计方法，并区分原始帖子和 Agent 派生记忆的来源；这项研究提供风险诊断而非现成修复方案，单看平均正确率下降不足以说明系统已经自我纠错。

Wenhui Chen, Jianlin Chen, Ziyao Lin, Chi Man Vong

Recursive self-improvement of AI research agents

WWeco AI

AIDE² 让研究 Agent 修改自身代码，通过任务基准和隐藏评估筛选版本，再让获胜版本继续迭代。8 天自主运行获得 7 次连续改进，并迁移到 4 个留出基准；独立任务族上的奖励投机率从 55% 降至 32%，该指标并非循环显式优化的目标。

INSIGHT对社区搜索，可借鉴其隐藏评测与版本晋升机制，用离线数据优化查询规划、证据压缩和记忆策略。论文研究的是研发 Agent，尚未证明搜索线上收益；应固定模型和预算，并以未参与优化的社区查询集检验 nDCG、引用准确率和成本，避免系统只学会迎合评测。

Dhruv Srikanth, Bingchen Zhao, Dixing Xu, Yuxiang Wu, Zhengyao Jiang

Agensh: Scaling Organizational Intelligence to 1,024 Agents

Microsoft

Agensh 通过共享工作区、消息接口和共享上下文让 Agent 自组织认领与核验任务，缓解中央调度瓶颈。在五个高难 ProgramBench 任务上，1 到 128 个 Agent 使平均测试通过率从 19.31% 升至 28.78%；pandoc 任务扩至 1,024 个时，通过率从 33.89% 升至 55.06%。

INSIGHT复杂社区研究查询可按子问题拆分检索，并共享已核实的帖子证据，减少多个 Agent 重复搜索。其结果来自代码构建任务和很大的并发规模，实践上应先以少量 Agent 验证工作认领、来源合并和冲突处理；必须把总 token 成本与延迟一起比较，不能由并发扩展直接推导搜索质量提升。

Zhihao Zhan, Ting Song, Li Dong, Shaohan Huang, Jianxun Lian

Ringg’s AI agents resolve up to 65% of customer calls with OpenAI

RRinggOpenAI

Ringg 的工业案例将结构化过滤、语义检索与工具编排结合，支持语音、聊天及网页中的多步客户请求。厂商报告每月处理超过 700 万通已接通电话，Agent 最多解决 65% 的常规咨询；部分实时工作负载切换模型后成本约降 90%，这些为业务自报数据，缺少统一受控对照。

INSIGHT社区问答服务可借鉴其离线历史对话评测、小流量上线和按任务路由的流程，把检索、回答与转人工串成闭环。应保留检索证据及升级处理的上下文，按引用正确率、完成率和延迟选择模型；案例中的成本降幅仅针对特定负载，不能直接用于估计社区搜索预算。
