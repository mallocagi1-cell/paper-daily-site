RQ-MoE: Residual Quantization via Mixture of Experts for Efficient Input-Dependent Vector Compression

向量量化是压缩高维 embedding 的基础工具，但传统 multi-codebook 方法用静态码本，难适配异构数据几何；QINCo 等动态量化器虽按输入自适应码本，却因严格序列依赖造成解码瓶颈。论文提出 RQ-MoE，用两级 MoE 加双流量化 (dual-stream quantization) 实现输入相关的码本自适应，把指令与量化解耦以支持并行解码。理论上证明标准 Residual Quantization 与 QINCo 都是 RQ-MoE 的受限特例，并给出专家维度设置准则。

XFP: Quality-Targeted Adaptive Codebook Quantization with Sparse Outlier Separation for LLM Inference

XFP 是面向 LLM 推理的动态权重量化器，颠倒常规流程：由部署方按 per-channel 余弦相似度指定重建质量下限 (attention 与共享专家用严格下限、MoE 路由专家用宽松下限)，XFP 自动决定每层码本大小、离群点预算与打包，无需 Hessian、无需校准数据、无需手工选 bit 宽。权重矩阵分解为稀疏 fp16 离群残差与稠密 sub-byte 索引张量。在 Qwen3.5-122B-A10B 上 V2 模式达单流 138 tok/s 解码 (RTX PRO 6000 Blackwell, TP=2)，GSM8K strict-match 94.49% (3 seeds, n=3957)。

INSIGHT把量化目标从“选 bit 宽”改为“声明质量地板”，让部署方按业务可接受的精度损失反推压缩配置，省掉校准数据与 Hessian——对需要低成本部署 LLM 重排 / encoder 的社区搜索很实用。对 attention / 共享专家严格、对路由专家宽松的差异化质量地板，是 MoE 量化的可借鉴设计。

Thomas Witt

KVServe: Service-Aware KV Cache Compression for Communication-Efficient Disaggregated LLM Serving

分离式 LLM 服务 (PD 分离、KV 状态 disaggregation) 提升扩展性与成本效率，却让 KV 成为跨网络 / 存储的显式负载、成为端到端主瓶颈。现有 KV 压缩多为静态运行配置，无法适应工作负载、带宽、SLO / 质量预算随时间变化，固定选择可能次优甚至增加延迟。KVServe 是首个面向服务、自适应的分离式 LLM 服务 KV 通信压缩框架：把 KV 压缩统一为模块化策略空间并支持跨方法重组；引入 Bayesian Profiling Engine 高效搜索该空间以匹配实时服务上下文。

INSIGHT把 KV 压缩从“静态超参”变成随 SLO / 带宽 / 负载在线自适应的策略搜索，是分离式推理服务的关键工程视角。社区搜索若用 LLM 做重排 / RAG 且采用 PD 分离部署，KV 通信往往是隐形成本，模块化策略空间 + 贝叶斯画像可作为压缩选型的参考框架。

Zedong Liu, Xinyang Ma, Dejun Luo, Hairui Zhao, Bing Lu, Wenjing Huang, Yida Gu, Xingchen Liu

Diagnosing Training Inference Mismatch in LLM Reinforcement Learning

现代 LLM RL 系统把 rollout 生成与策略优化分离，二者本应对同一序列、同一权重给出完全一致的 token 概率，但实现差异会让它们赋值不同，产生 Training-Inference Mismatch (TIM)。TIM 与 off-policy drift 及常见稳定化机制纠缠，难以排查。论文在零失配诊断设置 VeXact 中隔离 TIM，证明微小的 token 级数值分歧即可独立导致训练崩溃，并指出 TIM 改变了有效优化目标，给出一组缓解措施。

INSIGHTTIM 不是良性数值噪声，而是系统级扰动，应作为分析 LLM RL 的一阶因素。对用 RLHF / RLEF 训练搜索排序或 LLM 对齐的团队，rollout 引擎与训练引擎的概率不一致是隐蔽崩溃源——VeXact 这类零失配诊断思路可纳入 RL 训练管线的回归检查。

Tianle Zhong, Neiwen Ling, Yifan Pi, Zijun Wei, Tianshu Yu, Geoffrey Fox, Peng Wu, Xiao Yu

A Hardware-Aware, Per-Layer Methodology for Post-Training Quantization of Large Language Models

Scaled Outer Product (SOP) 是面向 LLM 权重的训练后量化 (PTQ) 方法，在支持 per-layer LUT 解码的硬件上以 4.5–6 bit / 权重达近无损保真。方法组合：固定 + 动态码本对的逐层搜索 (per-block 选择位)、有符号 per-block scale、激活加权余弦选择、对敏感层的多选背包提升加离群 / 稀疏残差修正。固定码本含 NF4 / BOF4 / Split87 / SH4，逐层优化码本 DD4 驻留 LUT SRAM，并提出硬件高效 LUT 输出格式 HIF。跨六个开源模型族，推荐 FP6 工作点 (E2M3sUE4M4, 6.5 bpw) 权重重建误差低于常规 per-layer-POT FP8 基线。

INSIGHT把码本量化与硬件 LUT 解码协同设计，让 6.5 bpw 的 FP6 在重建误差上反超 FP8，并给出可直接采纳的“推荐工作点”——对要在固定预算 GPU 上塞下更大搜索 LLM 的团队是低成本部署的实操参考。逐层固定 / 动态码本搜索 + 敏感层背包提升的分配思路可借鉴。

Earl Killian

PreFT: Prefill-only finetuning for efficient inference

Stanford

PEFT 可大规模高效个性化 LLM，但为每个用户上线专属 adapter 会损害吞吐，即便有专用 kernel 与显存管理。原因在于 prefill (一次处理大量 token) 与 decode (自回归逐 token) 存在错配：多 adapter 服务时 decode 吞吐远低。论文主张应优化“相对服务吞吐”的性能而非“相对参数量”，提出 PreFT：只在 prefill token 上施加 adapter、之后丢弃，显著提升吞吐且对效果影响极小，并开源了高效实现。

INSIGHT把多 adapter 服务的优化目标从“参数效率”换成“吞吐效率”，识别出 decode 阶段才是多 adapter 吞吐杀手——只在 prefill 用 adapter 的取舍，对社区搜索做“千人千面”个性化重排 / 改写、需同时在线大量用户 adapter 的场景很有借鉴价值。

Andrew Lanpouthakoun, Aryaman Arora, Zhengxuan Wu, Dhruv Pai, Ben Keigwin, Dan Jurafsky 等 7 人

AB-Sparse: Sparse Attention with Adaptive Block Size for Accurate and Efficient Long-Context Inference

长上下文下加载不断增长的 KV cache 成为 attention 计算瓶颈。已有 block sparse attention 把 KV 分成固定大小块并按重要性选择计算，但对所有 attention head 用统一块大小，隐含同质假设。论文分析发现该假设有缺陷：不同 head 对块粒度敏感度差异很大，统一会次优。AB-Sparse 是训练无关的算法-系统协同框架，引入轻量自适应块机制，在保持吞吐的同时提升精度。

INSIGHT不同 attention head 对稀疏块粒度敏感度异质——逐 head 自适应块大小、且训练无关，便于直接套用到现有长上下文推理栈。社区搜索做长文档 RAG / 长 query 重排时，KV 加载是延迟主因，这类训练无关稀疏注意力是性价比较高的加速选项。

Di Liu, Ruitian Wang, Chen Chen, Mingliang Gong, Yongjie Yuan, Han Zhao, Yu Feng, Quan Chen

An Interpretable Latency Model for Speculative Decoding in LLM Serving

投机解码 (SD) 用小草稿模型提议多 token、大目标模型并行验证来加速 LLM 推理；但已有工作多在隔离或固定 batch 设置验证，生产服务中请求负载随时间变化、有效 batch 由服务系统涌现而非可控可观测，SD 行为不清。论文构建简单可解释的 SD 服务延迟模型：用 Little's Law 由请求率推断有效 batch，把 per-request 需求分解为 prefill / drafting / verification 的负载无关与负载相关分量，并用 vLLM 跨多种 verifier / drafter 规模与长度的大量实测验证。

INSIGHT投机解码在固定 batch 下的加速结论未必迁移到生产；用 Little's Law + 负载相关 / 无关分解给出可解释延迟模型，便于做容量规划与“该不该开 SD”的决策。对线上用 LLM 重排且关心 P99 延迟的搜索服务，这是评估 SD 收益的实用分析框架。

Linghao Kong, Megan Flynn, Michael Peng, Nir Shavit, Mark Kurtz, Alexandre Marques

The Illusion of Power Capping in LLM Decode: A Phase-Aware Energy Characterisation Across Attention Architectures

功率封顶 (power capping) 是 LLM 服务标准 GPU 节能手段，看似有效 (吞吐降、功率读数降、达标)。论文证明对主导生产服务的自回归 decode 阶段这种有效是假象：在 GQA / MLA / Gated DeltaNet / Mamba2 四种注意力范式、NVIDIA H200 上，decode 仅吃 137–300W (700W GPU)，封顶从不触发，因 memory-bound decode 打满 HBM 带宽而非算力；固件触发的时钟节流进一步混淆测量。锁 SM 时钟可消除两种混淆，在关键路径上 Pareto 优于功率封顶，最高回收 32% 解码能耗且吞吐损失极小。

INSIGHTdecode 是 memory-bound、不吃满功率，功率封顶对它基本无效；真正该调的是 SM 时钟锁定，可省最高 32% 解码能耗。对自建 LLM 推理集群、关心电费 / PUE 的搜索团队，这是可立即验证的运维杠杆，并提醒能耗测量需排除固件时钟节流混淆。

Bole Ma, Ayesha Afzal, Jan Eitzinger, Gerhard Wellein

美团 LongCat 开源 General 365：树立推理评测新标尺

美团

美团 LongCat 团队发布通用推理能力评测基准 General 365 (非开源模型)。基准含 365 道原创种子题与 1095 个扩展变体、共 1460 道高质量题，覆盖复杂约束、分支枚举、时空推理、递归回溯、语义干扰、隐式信息、最优策略、概率推断八类挑战；全量人工审核，混合规则 + 模型评分，评分准确率 99.6%。26 款模型测评中 Gemini 3 Pro 准确率 62.8% (约 14k tokens 输出)，仅 2 款及格 (≥60%)；GPT-5-Thinking 在 BBH 92.0% 但在 General 365 仅 58.6%。

INSIGHT这是国内团队产出的高难度推理评测基准 (非基建组件，infra 关联较弱，作为产业实践覆盖项收录)。八维度 + 扩展变体 + 99.6% 评分准确率的构造方法，对需要自建“难基准”评估搜索 / 对话推理能力的团队有方法论借鉴；与 BBH 的巨大分差提示通用基准已饱和、需要更难的区分性评测。
