Thinking Broad, Acting Fast: Latent Reasoning Distillation from Multi-Perspective Chain-of-Thought for E-Commerce Relevance

针对电商搜索相关性建模，提出 Multi-Perspective CoT（MPCoT）让 LLM 从多个视角生成推理链，配合 SFT+DPO 训练教师模型；再用 Latent Reasoning Knowledge Distillation（LRKD）把推理能力蒸馏进一个推理抽取器，推理在隐空间完成、不在推理时展开显式 CoT，以此压低线上延迟。已在日活数千万的电商搜索广告平台离线与在线 A/B 验证，离线指标与线上商业、体验指标均有提升（摘要未给出具体百分比）。

KEY INSIGHT · 对业务意味着什么把“多视角思考”与“快速执行”拆开：离线用多视角 CoT 喂饱教师，线上只跑隐式推理 extractor。对社区搜索短文本相关性的启示——当相关性判断需要常识与多角度推理时，可让大模型离线产出多视角推理标注，再蒸馏成隐推理小模型挂在精排前，避免线上跑显式 CoT 的延迟。MPCoT 的多视角覆盖比单一 CoT 更稳，DPO 专门用于纠正过度判正。

From Reasoning LLMs to BERT: A Two-Stage Distillation Framework for Search Relevance

MeituanNNUAA

面向电商搜索相关性在毫秒级延迟约束下的落地，提出两阶段蒸馏：先用预训练+SFT+偏好优化构建领域自适应的推理教师 LLM，生成高质量相关性标签；再用 Contrastive Reasoning Self-Distillation 把推理决策内化进一个紧凑 BERT，学生在推理时无需显式推理路径。在美团搜索广告系统的离线评测与线上 A/B 上多项指标显著提升（摘要未给具体数字）。

INSIGHT核心是 Contrastive Reasoning Self-Distillation——允许教师与学生架构不同（生成式 LLM → 判别式 BERT），蒸馏的是“为什么相关”的对比信号而不仅是硬标签。社区搜索相关性同样卡在线上算力：可复用此路径，用推理 LLM 离线标注难样本与对比理由，再蒸馏进线上 BERT 精排，相比线上直接用 LLM 打分可省约 10–100 倍算力。

Runze Xia, Yupeng Ji, Yuxi Zhou, Haodong Liu, Teng Zhang, Piji Li

IterQR: An Iterative Framework for LLM-based Query Rewrite in e-Commercial Search System

Meituan

针对电商搜索 query 含歧义与错字导致召回不准，提出 LLM query 改写的迭代框架：用 RAG 注入领域知识、用 CoT 做 query 理解生成改写；线上收集改写效果信号并自动更新正样本；再用多任务目标对 LLM 做 post-training，循环迭代自我提升。已部署于美团外卖搜索，带来显著提升。

INSIGHT价值不在单次改写质量，而在“生成—线上信号—回流再训练”可迭代的流程。社区搜索 query 同样短、口语化、易错：可借鉴用 RAG 把站内同义词/实体知识喂给改写 LLM，把线上点击/相关性反馈自动转成正改写样本做多任务微调；难点在正样本自动判定的噪声，需结合相关性模型过滤再回流。

Shangyu Chen, Xinyu Jia, Yingfei Zhang, Shuai Zhang, Xiang Li, Wei Lin

LREF: A Novel LLM-based Relevance Framework for E-commerce Search

JD

针对 query-product 相关性预测，指出 BERT 类模型表达力不足、直接用 LLM 又有数据质量、推理优化与过度判正（over-recall）问题，提出三阶段框架：带数据筛选的 SFT、多条 Chain-of-Thought 微调、用 DPO 做去偏。已在知名电商应用部署，离线与在线指标显著提升并带来商业收益。

INSIGHT直接拿 LLM 做相关性最大的坑是“乐观偏置/过度判正”，LREF 用 DPO 专门纠偏值得借鉴。社区搜索相关性同样常见 LLM 倾向判“相关”导致精排放水：可引入偏好对（人工或规则产生的难负例）做 DPO，配合多 CoT 提升判别一致性；其经验是数据筛选阶段对训练稳定性影响最大。

Mira-Embeddings-V1: Domain-Adapted Semantic Reranking for Recruitment via LLM-Synthesized Data

把候选搜寻建模为两阶段召回+重排，用 LLM 五阶段 prompt 流水线合成训练数据，做两轮 LoRA 适配（JD-JD 对比 + JD-CV 三元组对齐），并加一个轻量 BoundaryHead MLP 做 Top-K 边界消歧。本地评测（300 JD）Recall@50 由 68.89% 升到 77.55%、Precision@10 由 35.77% 升到 39.62%；全局评测（44138 候选）Recall@200 由 0.5969 升到 0.7047。

INSIGHT无需大规模人工标注，靠 LLM 合成数据加两轮 LoRA 重塑 embedding，再用一个轻量 reranking head 纠正 Top-K 边界混淆——这套低成本范式可迁移到社区搜索冷启动与垂域适配。BoundaryHead 只解决“召回头部排序边界模糊”，比整体替换 reranker 成本低；JD-JD 对比加 JD-CV 三元组的双目标对齐，对 query 短、文档长的非对称匹配有参考价值。

Zhaohua Liang, Zhilin Wang, Renjie Cao, Yining Zhang

PairSem: LLM-Guided Pairwise Semantic Matching for Scientific Document Retrieval

UIUCPOSTECHNIH

针对科学文献检索中实体被当成独立片段、忽略概念多面性的问题，提出把相关语义表示为“实体-方面”（entity-aspect）对来刻画复杂多面概念；方法无需标注 query-文档对或实体标注，retriever 无关、即插即用。在多个数据集与多种检索器上检索效果均有提升，WWW 2026 接收。

INSIGHT把“实体+其所属方面”成对建模，而不是孤立实体，可更细粒度地捕捉语义匹配。社区搜索 UGC 文本概念零散、口语化，可借鉴 entity-aspect 对的思路在 query 与帖子间做细粒度对齐；且方法 unsupervised、retriever-agnostic，可作为现有 dense 召回之上的免训练增强层先做小流量 A/B。

Wonbin Kweon, Runchu Tian, SeongKu Kang, Pengcheng Jiang, Zhiyong Lu, Jiawei Han, Hwanjo Yu

Conventional Contrastive Learning Often Falls Short: Improving Dense Retrieval with Cross-Encoder Listwise Distillation and Synthetic Data

WWaterlooVVectara

研究 embedding 模型语料内微调，发现用常规 InfoNCE 对比损失微调反而常常降低 SOTA 模型效果；改用 cross-encoder 的 listwise 蒸馏，并用多类型（claim/keyword/question）合成 query，提升更稳定，合成 query 与人工 query 的训练效用相当，在 BERT 量级 embedding 模型中达到 SOTA，模型与代码已开源。

INSIGHT一个反直觉但实用的结论：盲目用 InfoNCE 继续微调可能掉点，listwise cross-encoder 蒸馏更稳。社区搜索做垂域 embedding 适配时值得警惕——优先用强 cross-encoder 产生 listwise 软标签做蒸馏，并用多类型合成 query（关键词式/问句式/陈述式）覆盖社区多样表达，可省人工标注且效果不弱。

Manveer Singh Tamber, Suleman Kazi, Vivek Sourabh, Jimmy Lin

Automated Query-Product Relevance Labeling using Large Language Models for E-commerce Search

面向电商搜索排序所需相关性 ground truth 标注昂贵耗时的问题，用 LLM 自动化 query-product 相关性标注，结合 Chain-of-Thought、In-Context Learning、RAG+Maximum Marginal Relevance 等技术，在大规模电商搜索上以远低于人工的时间与成本接近人工标注准确率。

INSIGHT把 LLM 当“可扩展标注员”而不是线上模型，是当前性价比最高的落地姿势之一。社区搜索相关性训练同样缺标，可用 CoT+ICL+RAG（注入站内类目/同义词上下文）批量产标，再喂给线上小模型；用 MMR 挑选有区分度的示例值得借鉴，关键是抽样校验 LLM 标注与人工的一致率以控偏。

Jayant Sachdev, Sean D Rosario, Abhijeet Phatak, He Wen, Swati Kirti, Chittaranjan Tripathy

In a Few Words: Comparing Weak Supervision and LLMs for Short Query Intent Classification

RRadboud

实证比较弱监督（ORCAS-I 基线）与 LLM（LLaMA-3.1 8B/70B 的 ICL 与 8B 微调）在短 query 意图分类（信息型/导航型/事务型）上的表现，发现 LLM 在召回上优于弱监督，但精度仍不足。SIGIR 2025 接收。

INSIGHT短 query 意图识别正是社区搜索 query 理解的核心环节，本文给出务实结论：LLM 召回高但精度不够，不能裸用。可借鉴的取舍是让 LLM 出高召回候选意图，再用轻量判别模型或规则把精度收回；微调 8B 相比 70B ICL 的性价比，也值得在自有意图体系上复测。

Enhancing Retrieval-Augmented Generation with Two-Stage Retrieval: FlashRank Reranking and Query Expansion

针对 RAG 中召回率与 LLM 上下文窗口受限的矛盾，提出两阶段检索：LLM 驱动的 query 扩展提升候选召回，再用 FlashRank——一个按相关性、新颖性、简洁性与 cross-encoder 分做边际效用选择的快速重排器，在 token 预算内挑选最优证据子集。

INSIGHT把重排目标从单点相关性改成“边际效用”（已选证据下的增量价值），对社区搜索结果去冗余、提升 Top-K 信息覆盖有启发：相似帖子扎堆时，按新颖性+简洁性做边际选择能提升结果多样性与 nDCG。论文偏短、缺乏量化实验，落地前需自建基准验证收益。

Sherine George
