Agentic AI and Retrieval-Augmented Models in Straight-Through Underwriting

论文在 635 个合成但经人工校验的承保案例上，对比单模型、朴素 RAG 与多智能体 Agentic RAG。后者把定向检索、第三方数据检查、多步规则计算和反思串成可审计流程，在 GPT-5.2 上总体准确率达 86.5%，高于单模型的 77.6% 和朴素 RAG 的 76.9%。

Towards Retrieving Interaction Spaces for Agentic Search

论文指出搜索 Agent 的瓶颈不是只找到相关文档，而是把可探索的证据空间暴露给模型；RISE 将候选文档组织为受限工作区，让 Agent 用搜索、命令和分段读取逐步核验。BrowseComp-Plus 的 100 查询实验中，RISE 在 mimo-v2.5-pro 与 GPT-5.4-mini 上达到 78% 准确率，并只需 DCI 三分之一的调用预算。

INSIGHTAgentic Search 的检索接口应优化“可交互性”而不只是静态召回率：先用检索建立有边界的工作区，再允许模型局部扫描、交叉验证与读取全文。该设计在语料从 10 万扩到 100 万文档时未出现准确率退化，适合社区搜索把候选帖子簇包装成可探索证据空间，避免 Agent 在全库工具调用中耗尽预算。

知识库检索 Agent

Tencent

腾讯云把传统“一次检索、一次生成”改造成可自主拆解任务的知识库 Agent，面向多文档整合、复杂条件筛选与表格计算。系统可多次组合调用检索、Text2SQL、SQLExecutor 和 Code Interpreter，并能作为 Multi-Agent 子 Agent 参与协作，给出了从导入文档到配置应用的工程路径。

INSIGHT工业实现的关键是把检索、结构化查询与计算拆成显式工具，让规划器依据中间证据选择下一步，而不是让一个提示词同时承担所有职责。社区搜索可借鉴其分层路由：单跳事实走低延迟检索，多文档比较或带时间、地区、指标约束的请求再进入 Agent Loop，并保留每次工具调用轨迹。

用两行代码将 AgentRun 集成到你的应用

Alibaba

文章展示 AgentRun 以兼容 OpenAI 的接口降低接入成本，应用只需替换 base_url 等两处配置即可连接完整 Agent 运行时。运行时统一管理 MCP Server、Function Call、Skill 三类工具，并整合 RAG 数据源、长短期记忆、安全护栏和基于 OpenTelemetry 的全链路可观测能力。

INSIGHTAgent 上线难点往往不在规划算法，而在协议适配、知识接入、权限与可观测性。对搜索业务而言，可保持现有模型调用接口稳定，把工具注册、检索数据源和追踪能力下沉到运行时；这样能小步灰度 Agentic Search，同时用统一 trace 定位查询改写、召回或工具失败发生在哪一环。

Accelerating End-to-End Co-Folding Performance with NVIDIA BioNeMo Agent Toolkit

NVIDIA

NVIDIA 以 BioNeMo Agent Toolkit 编排 OpenFold3 等生物分子共折叠工作负载，展示 Agent 如何连接专用模型、数据准备与端到端执行。内容虽非搜索领域，但提供了近期生产级工具编排案例：将长流程拆成可观测步骤，并围绕昂贵模型调用优化执行路径与资源使用。

INSIGHT对搜索团队可迁移的不是生物模型本身，而是“Agent 编排专用计算服务”的工程模式：规划层负责选择工具，领域模型保持独立部署，运行时记录每步输入输出与耗时。复杂搜索也可将召回、重排、事实核验和生成做成独立能力，便于按查询选择性执行并单独扩缩容。

How Deutsche Telekom is rewiring telecommunications with AI

OpenAIDeutsche Telekom

该案例介绍 Deutsche Telekom 将生成式 AI 扩展到客服、员工工作流、网络运营与语音交互，体现大型企业从单点助手转向跨系统任务执行的路线。文章重点是组织与平台落地，而非新算法实验，可作为 Agent 能力接入真实业务流程、权限边界和运营体系的近期行业样本。

INSIGHT社区搜索引入 Agent 时，价值不应只用回答质量衡量，还要看是否缩短客服或运营人员跨系统查找、核验和处置的链路。可先选择权限清晰、结果可复核的内部搜索场景，保留人工确认和审计日志，再逐步扩展到面向用户的自动执行，避免把开放式生成直接接入高影响操作。
