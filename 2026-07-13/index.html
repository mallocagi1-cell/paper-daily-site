OneRec-Think: In-Text Reasoning for Generative Recommendation

论文把对话、显式推理与生成式推荐统一到 OneRec-Think：先用跨模态 Item-Textual Alignment 对齐 Semantic ID，再以推理脚手架和面向多解偏好的奖励函数训练。Beauty 数据集 Recall@5 从 ReaRec 的 0.0450 提升至 0.0563，线上 Think-Ahead 架构使 APP 停留时长提升 0.159%。

ReRec: Reasoning-Augmented LLM-based Recommendation Assistant via Reinforcement Fine-tuning

ReRec 用强化微调增强复杂推荐推理：奖励同时融合 NDCG、query 对齐和偏好对齐，RAEE 对错误推理步骤施加惩罚，在线课程调度器按难度组织样本。以 Llama-3.2-3B 为骨干时，Movie 各类任务较次优方法提升 3.76%–13.2%，困难误导查询较未训练模型提升 440%。

INSIGHT推荐助手的奖励不应只看最终命中，还应把查询理解、历史偏好一致性和中间推理正确性拆开监督。社区搜索可将 nDCG、query-item 语义对齐和用户长期兴趣联合成可解释奖励，并用课程学习先覆盖简单意图再加入冲突、误导与多约束查询，降低强化训练早期的不稳定。

Jiani Huang, Shijie Wang, Liang-Bo Ning, Wenqi Fan, Li Qing

From ID to LLM: Rethinking Representation Learning for Recommendation

PtE 先让 LLM 对用户—物品交互做双向推理，生成稳定的语义画像，再将画像编码成任务对齐向量，从而连接行为 ID 与语言语义空间。三套冷启动数据上，相对最强基线的指标提升最高 57.71%；长尾 Fashion 的尾部物品 NDCG@10 从 0.1646 提升到 0.2457，增幅 49.27%。

INSIGHT直接把 LLM embedding 注入排序模型容易随单次交互剧烈波动，先生成压缩画像再做个性化 embedding 更稳。对于短文本社区，可将稀疏点击、帖子主题和作者信息先归纳为用户/内容画像，再以协同对齐损失训练向量；该设计尤其适合冷启动帖子、长尾作者和低活跃用户。

Song-Li Wu, Zhaocheng Du, Weinan Gan, Jingyi Wang, Xianquan Wang

Retrieval-Augmented Diffusion with Structural Uncertainty for Sequential Recommendation

论文针对序列推荐数据稀疏与统一增强策略造成语义漂移的问题，将相似序列检索、结构不确定性估计和扩散生成结合，为不同用户序列自适应地产生增强视图。作者在 2026 年 7 月 8 日发布的实验中同时评估推荐、对比学习、消融与效率，结果显示该设计提升鲁棒性，但公开摘要未给出具体提升数值。

INSIGHT增强强度应由行为序列的结构置信度决定：稳定兴趣可接受更强扩散扰动，短序列或兴趣跳变用户需要更保守的条件生成。社区场景可先检索相似用户/帖子序列，再用不确定性控制增强幅度；落地前应重点验证生成成本、语义漂移率及对长尾 query 的 nDCG 收益。

Dongjin Yu, Changgeng Li, Yayu Hou, Dongjing Wang, Tong Wu
