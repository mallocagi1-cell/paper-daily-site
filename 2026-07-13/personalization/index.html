UCGRec: User-Centric Graph Learning for LLM-based Sequential Recommendation

针对 LLM 序列推荐难以整合用户多种兴趣、独立偏好信号又容易引入噪声的问题，UCGRec 将与用户相关的偏好组织成统一的用户中心图，再通过图神经网络与 LLM 端到端联合训练注入结构知识。论文在四个真实序列推荐数据集上进行广泛实验，并报告其性能显著超过传统方法及近期 LLM 推荐基线。

02 4.05

TriSSR: Tri-expert fusion in state space models for sequential recommendation

TriSSR 针对 Transformer 自注意力的低通特性导致序列表示过平滑、短期兴趣波动被压制的问题，采用高效状态空间模型作为骨干。它用三频段滤波器分解短期、周期与长期行为，引入对数频率基的时间傅里叶编码器，并通过三专家门控融合频域、时间域和序列状态信息，在多个大规模真实数据集上验证多尺度偏好建模能力。

INSIGHT把行为序列按频率而非仅按时间窗口拆分，是该方法对推荐系统最值得借鉴的部分：高频对应突发兴趣，中频对应周期习惯，低频承载稳定偏好。社区场景可在现有序列模型旁增加轻量频域分支和时间间隔编码，再由门控按请求动态融合，以较低复杂度缓解长序列注意力的过平滑与二次计算开销。

03 3.85

Hierarchical long and short-term user preference modeling for sequential recommendation

该工作聚焦序列推荐中长期兴趣缺乏多样性、短期兴趣变化快以及二者层级关系难以统一表达的问题，提出端到端的层级长短期偏好模型。模型不是简单把两类表示相加，而是显式捕捉稳定偏好与即时意图之间的层级依赖，用于预测用户下一次交互，适合具有明显兴趣漂移和多时间尺度行为的内容平台。

INSIGHT长期画像应当作为短期兴趣的条件和约束，而非与最近行为等权融合；这一层级关系能减少偶发点击对画像的污染。社区业务可把长期主题分布作为上层先验，把会话内查询、浏览和互动作为下层动态状态，并在线监控门控权重，判断推荐结果究竟由稳定偏好还是当下意图驱动。

Jiye Liang et al.

04 3.65

A multi-task learning-based fully connected neural network for personalized news recommendation

XXi'an Jiaotong University City College

论文面向个性化新闻推荐中的动态兴趣、准确率与多样性平衡及冷启动退化，利用用户行为序列 embedding 刻画兴趣演化，并以多任务框架联合优化点击意图预测和兴趣分布学习。作者报告相对基线的 AUC、NDCG@5 与 CTR 分别提升 12.4%、10.7% 和 8.9%，说明辅助兴趣任务可改善共享表示。

INSIGHT将点击预估与兴趣分布学习绑定，比单一 CTR 损失更容易让表示保留可解释的用户偏好结构，也能为冷启动提供额外监督。迁移到社区场景时，可把点击、停留、收藏和主题分布设计为共享底座上的多任务头，同时使用不确定性或动态权重平衡任务，避免高频点击标签压制稀疏但高价值的互动信号。

ZhuoMin Ren, Hong Xie

05 3.60

Distilling Long-Tail User Behavior into Scalable Embeddings for Job Search

Indeed

Indeed 的工程实践讨论如何把用户长尾行为蒸馏为可扩展 embedding，用于职位搜索中的推荐和排序。文章指出，直接聚合职位标题词会让“software”等泛化词获得过高权重，从而掩盖用户持续而具体的求职意图；其方案通过行为蒸馏压缩长历史，在在线系统可承受的表示规模内保留稳定偏好。

INSIGHT长行为序列的关键不是无损保存全部事件，而是压缩时保住能区分用户的长尾信号，并削弱高频通用特征。社区搜索可把历史帖子、话题和作者交互蒸馏成固定维度画像，与当前查询表征分开维护；离线以检索或排序蒸馏损失训练，在线只读取紧凑向量，兼顾个性化收益、存储成本和尾延迟。

Marsan Ma

06 3.40

Building an AI-Powered Product Recommendation Engine for E-Commerce Using Alibaba Cloud PAI

Alibaba Cloud

这篇工程指南给出基于 Alibaba Cloud PAI、MaxCompute、EAS 与 DataWorks 构建实时电商推荐服务的完整路径，覆盖行为数据加工、候选生成、已曝光内容去重、用户和商品特征读取、排序以及在线 API 部署。它强调生产推荐不是单个模型，而是数据、召回、过滤、特征、排序和服务编排共同组成的持续迭代系统。

INSIGHT对社区个性化最直接的启示是把模型迭代放进可观测的端到端流水线：曝光去重、特征新鲜度和服务稳定性往往与离线模型精度同样重要。可借鉴其分层架构，将离线行为加工、近线画像更新和在线排序解耦，并为每层记录候选缩减率、特征延迟和请求耗时，便于定位 CTR 波动来源。
