Training-Free LLM-Based Recommendation with Post-LLM Item Refinement Using Collaborative Signals

CoRRe 针对 LLM 生成的用户兴趣过于宽泛、难以细粒度召回的问题，提出“后置协同增强”框架：先由 LLM 生成用户与物品表示，再用物品共购图修正向量方向、用流行度修正向量幅度，最后进行匹配排序。论文在真实数据集上显示无需训练或任务微调即可稳定超过训练免调基线，并与训练式方法竞争；摘要未披露具体数据集指标，需复核全文。

SSR-GRPO: Integrating Supervision and Semantic IDs into Reinforcement Learning for Dense Retrieval in E-commerce

SSR-GRPO 面向电商稠密召回中的复杂语义和强化学习噪声，联合使用 Semantic ID 与向量表示进行双视角相关性评估。方法利用层级 Semantic ID 挖掘难负样本，一路通过掩码过滤同组噪声，一路构造 Retrieval-DPO 正负对，再与 GRPO 训练结合。论文报告了离线、在线实验，并称已部署于大规模电商平台。

INSIGHT对 UGC 短文本搜索，Semantic ID 不只是物品编码，也可作为难负样本分组信号，帮助 RL 训练区分“主题相近但意图不同”的内容。落地时应先复现双视角相关性标注和噪声掩码，再评估 DPO 对 nDCG、CTR 与召回覆盖的共同影响，避免只优化离线 top-K。

Guangxin Song, Xing Fang, Mingmin Jin, Jing Wang, Bokang Wang, Zhentao Song, Junjie Bai, Jianbo Zhu

03 4.10

SmartGR: Hierarchy and Beam-Aware Knowledge Distillation for Generative Recommendation

SmartGR 针对生成式推荐蒸馏中的两个特有问题设计轻量化方案：Semantic ID 层级越深，蒸馏难度越不均衡；Beam Search 又可能因前缀分数偏低提前剪掉教师偏好的条目。它分别提出层级感知 SID 蒸馏与 Beam 感知排序蒸馏，在四个基准数据集上报告平均性能提升 8.6%，推理速度提升 2.39 倍。

INSIGHT生成式召回的压缩不能只蒸馏逐 token 概率，还要蒸馏层级编码难度和候选前缀的保留策略。对社区 UGC，适合用大模型教师生成高质量 Semantic ID，再训练小模型服务；上线前必须单独压测 beam 宽度、前缀剪枝率、长尾覆盖和端到端延迟。

Ziheng Zhang, Yu Cui, Bohao Wang, Yong He, Chao Yu, Chuan Yuan, Wujie Sun, Can Wang, Jiawei Chen

04 4.10

SCoRD: Semantic-Assisted Continual Retriever-Reranker Distillation for LLM-Based Recommendation

SCoRD 关注推荐兴趣随时间变化时，反复更新 LLM 重排器并蒸馏的成本过高、仅更新召回器又难以从稀疏数据适应的问题。它用语义推理助手抽取可复用的意图级指导，只在低置信序列上选择性蒸馏，并把意图漂移信号反馈给重排器，从而让召回器与重排器持续协同适应。论文在真实数据流上验证了效率与效果。

INSIGHT可以把 LLM 重排器定位为低频“教师”和意图漂移探针，而不是每次请求都调用的在线组件。社区搜索可按低置信 query、主题漂移和新实体触发蒸馏，日常流量只运行轻量召回；同时保留回灌接口，让新意图影响重排而不破坏既有 nDCG 与 CTR。

Seunghyun Baek, Gyuseok Lee, Seunghan Lee, Wonbin Kweon, Dong Wang, SeongKu Kang

05 3.25

CD-LLMCARS: Cross Domain Fine-Tuned Large Language Model for Context-Aware Recommender Systems

CD-LLMCARS 试图用跨域数据缓解上下文感知推荐的冷启动和信息稀疏问题，基于 Llama 2 做跨域微调，并采用 LoRA 与 FP16 降低训练资源。框架面向电影、音乐、书籍和 CD 等多类物品生成上下文相关推荐，候选摘要称其在冷启动场景进行了广泛测试，但没有公开具体数据集、指标或提升幅度，因此证据评分保守。

INSIGHT跨域迁移适合社区平台中新用户、新话题和新内容的冷启动，但不能把通用文本相似度直接当作相关性。工程上可先用 LoRA 将领域术语、内容类型和用户上下文对齐，再用点击、收藏等行为信号做后置校准，并把跨域收益拆解到新用户、新内容和长尾 query。

A. Cheema, M. Sarfraz, Usman Habib, Q. Zaman, E. Boonchieng

06 2.75

Recommender Systems Meet Large Language Model Agents: A Survey

这篇综述系统讨论推荐系统与大语言模型 Agent 的结合，覆盖用户建模、候选生成、交互式推荐、工具调用和多步决策等方向。它适合作为生成式搜推的术语地图，帮助区分把 LLM 当特征抽取器、重排器、对话助手和端到端生成器的不同范式；由于候选元数据未提供完整摘要和实验数字，不能替代具体方法论文。

INSIGHT阅读综述时应把“Agent 化”拆成可验证的链路：意图理解、候选召回、偏好推理、排序决策和反馈学习。对于 UGC 搜索，优先选择能落到召回或重排指标的模块，给工具调用设置预算与可回退路径，并用离线 nDCG、CTR 代理指标和长期留存分别验证收益，避免只凭生成文本质量判断推荐效果。

Xi Zhu, Yu Wang, Hang Gao, Wujiang Xu, Chen Wang
