Scaling Search Relevance: Augmenting App Store Ranking with LLM-Generated Judgments

针对商业搜索中行为信号丰富、文本相关性标注稀缺的问题，论文先比较不同 LLM 配置，选择专门微调的模型生成数百万条文本相关性判断，再与点击/下载标签共同训练多目标排序器。离线文本 NDCG@1 从 0.867 升至 0.868、行为 NDCG@1 从 0.646 升至 0.652；全球 App Store A/B 测试转化率显著提升 0.24%，尾部 query 收益更明显。

ColBERTSaR: Sparsified ColBERT Index via Product Quantization

针对 ColBERT 多向量索引需要大量存储、查询时还要聚集和解压 token 向量的问题，论文在冻结 ColBERT 上训练产品量化码本，把每个 passage token 映射为 centroid ID，使用倒排索引召回，并可用原始 MaxSim 做二阶段重排。在 BEIR 复现实验中，索引相较 one-bit PLAID 缩小 50%–70%，同时保持检索效果；开源实现支持分片、断点续跑和 CPU 搜索。

INSIGHT对于短文本 UGC 检索，ColBERTSaR 提供了在效果与索引成本间折中的清晰路径：先用 centroid 倒排做高召回候选，再只对小集合恢复完整 MaxSim。落地前应重点测量量化误差、nprobe、Top-K 与尾部 query 的召回损失，并把 query-aware codebook 训练纳入索引更新流程。

Eugene Yang, Andrew Yates, Dawn Lawrie, James Mayfield, Saron Samuel, Rohan Jha

Learning to Route Queries to Heads for Attention-based Re-ranking with Large Language Models

Université de MontréalCapital OneMcGill UniversityMila

针对 LLM 零样本重排把所有 attention head 混合、造成冗余和冲突的问题，RouteHead 学习一个轻量路由器，根据 query 表征选择稀疏 head 集合，再聚合这些 head 的注意力信号计算相关性。由于没有真实 query-head 标签，作者用离线搜索构造伪标签，并在多种 benchmark 与多种 LLM backbone 上验证，结果持续优于强基线。

INSIGHT它把重排器的计算预算从“每个 query 看全部 head”改成 query-conditioned 的稀疏选择，适合 UGC 搜索中意图差异大的短 query。工程上可先冻结主 LLM，只训练路由器和稀疏正则；上线应同时记录选择 head 分布、nDCG、延迟与跨域稳定性，避免伪标签把原有偏差固化。

Yuxing Tian, Fengran Mo, Zhiqi Huang, Weixu Zhang, Jian-Yun Nie

How mobility gives language models a deeper understanding of place

GoogleUniversity of Southern California

Google 的 ME-POIs 将静态 POI 文本与匿名移动轨迹融合成 place embedding，通过访问时间对齐、多尺度邻近地点传播和文本—移动信号余弦对齐，补足新店和长尾地点的稀疏信息。模型在洛杉矶、休斯顿的未见地点上评测 5 项任务，访问意图预测相对提升 81.9%、价格等级分类提升 75.1%、繁忙度估计提升 24.7%。

INSIGHT虽然不是直接的排序模型，ME-POIs 对社区本地搜索的启发是把供给的动态功能信号作为可复用 embedding，而不只依赖帖子文本。可将时间、地点和人群聚合特征作为召回或重排侧上下文，但必须做隐私、冷启动和城市迁移评估，且不能把群体 mobility 表征误用为个人画像。

Maria Despoina Siampou, Shushman Choudhury, Neha Arora, Cyrus Shahabi, Shang Ling Hsu

Beyond Chunk-Then-Embed: A Comprehensive Taxonomy and Evaluation of Document Segmentation Strategies for Information Retrieval

University of Queensland

论文系统比较文档切分与 embedding 时机，将固定长度、句子/段落、语义或 LLM 引导切分，与先切分再编码和 contextualized chunking 统一到二维框架。评测覆盖 in-document needle-in-a-haystack 与 in-corpus retrieval 两类设置，发现简单结构切分在语料内检索胜过 LLM 引导方案，LumberChunker 在文档内检索最佳，而 contextualized chunking 对前者有利、对后者有损。

INSIGHTUGC 短文本常见问题不一定是 backbone 不够大，而是切分破坏了语义边界；该研究提示要按检索形态选择 chunk 策略，而不是全站统一规则。建议把正文、标题、评论串联成可控的最小单元，分别评估文档内定位与语料召回，并把 chunk 长度、重叠和上下文注入纳入 nDCG 与召回率分桶实验。

Yongjie Zhou, Shuai Wang, Bevan Koopman, Guido Zuccon
