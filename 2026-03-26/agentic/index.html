Rethinking the Role of Entropy in Optimizing Tool-Use Behaviors for Large Language Model Agents

针对 LLM Agent 在长轨迹中频繁触发低质量工具调用导致延迟增加和推理性能下降的问题，通过熵分析实验发现：高质量工具调用与熵降低存在强正相关。基于该发现，提出以熵降低作为奖励信号优化工具使用行为，有效减少冗余工具调用并提升推理质量。

Reasoner-Executor-Synthesizer: Scalable Agentic Architecture with Static O(1) Context Window

针对 LLM Agent 中 RAG 系统的上下文窗口扩展问题，提出 Reasoner-Executor-Synthesizer (RES) 三层架构：Reasoner 解析用户意图，Executor 以确定性方式执行数据检索和聚合（零 LLM token），Synthesizer 生成叙述性回答。该架构将上下文窗口固定为 O(1)，token 成本不随数据集规模增长，同时降低了幻觉风险。

INSIGHTRES 架构的核心创新在于将检索与推理彻底解耦：Executor 层不使用 LLM，完全依赖确定性代码执行数据操作，避免了长上下文带来的幻觉和高成本问题。这种分层设计对搜索系统中的 Agent 架构设计具有直接借鉴意义——在社区搜索场景中，可将 query 理解、文档检索、结果合成三个阶段分离，用轻量确定性模块处理召回，仅在最终合成阶段使用 LLM。

Ivan Dobrovolskyi

From Questions to Trust Reports: A LLM-IR Framework for the TREC 2025 DRAGUN Track

为 TREC 2025 DRAGUN Track 提交的 UR_Trecking 系统，结合 LLM 生成关键问题与语义过滤、多样性聚类、以及多种查询扩展策略（含 Chain-of-Thought 推理扩展），从 MS MARCO v2.1 中检索相关证据，构建新闻可信度评估报告。系统在两个任务上展示了 LLM+IR 的集成框架。

INSIGHT该框架展示了 LLM 与 IR 系统的深度集成范式：通过 LLM 生成结构化关键问题来引导检索，再用检索结果增强生成。Chain-of-Thought 查询扩展策略对社区搜索中的 query 理解有直接参考价值——将用户的模糊 query 分解为多个结构化子问题，分别检索后合成回答，可显著提升搜索相关性。

SpecEyes: Accelerating Agentic Multimodal LLMs via Speculative Perception and Planning

针对 Agentic 多模态 LLM（如 OpenAI o3、Gemini Agentic Vision）中感知-推理-工具调用级联循环导致的高延迟问题，提出 SpecEyes 框架。核心思路是将推测性执行（Speculative Execution）引入 Agent 层面，通过预测性感知和规划并行执行多步操作，打破顺序瓶颈，显著降低 agentic depth 带来的延迟。

INSIGHTSpecEyes 将计算机体系结构中的推测执行思想迁移到 Agent 系统，这一思路对搜索 Agent 性能优化极具启发：在多轮检索-推理循环中，可以推测性地并行发起多条检索路径，而非等上一步结果返回后再决定下一步。这对降低搜索 Agent 的端到端延迟有重要实践意义。

Haoyu Huang, Jinfa Huang, Zhongwei Wan, Xiawu Zheng, Rongrong Ji, Jiebo Luo

GraphRAG for Engineering Diagrams: ChatP&ID Enables LLM Interaction with P&IDs

提出 ChatP&ID，一个基于 Graph Retrieval-Augmented Generation (GraphRAG) 的 Agentic 框架，实现对工程图纸（P&ID）的自然语言交互。将图纸解析为知识图谱，通过图结构化检索替代直接图像处理或文本 RAG，在成本和准确率上均有显著优势。

INSIGHTGraphRAG 将结构化知识图谱与 Agent 检索结合，避免了传统 RAG 在处理结构化关系数据时的局限。对社区搜索场景的启示：UGC 内容中的实体关系（用户-帖子-话题）天然形成图结构，GraphRAG 的图检索增强方式可提升对复杂关系查询的回答质量。

FIPO: Eliciting Deep Reasoning with Future-KL Influenced Policy Optimization

提出 Future-KL Influenced Policy Optimization (FIPO)，一种针对 LLM 推理瓶颈的强化学习算法。不同于 GRPO 等基于结果的全局 advantage 均匀分配策略，FIPO 引入折扣未来 KL 散度进行精细化 credit assignment，识别推理轨迹中的关键逻辑转折点，给予更精确的梯度信号。

INSIGHTFIPO 解决了 RL 训练 LLM 推理能力时的关键瓶颈——粗粒度 credit assignment 无法区分关键推理步骤和琐碎 token。对搜索 Agent 的 RL 训练有直接启示：在多步搜索-推理轨迹中，能够识别哪些检索决策是关键转折点，进而优化 Agent 的搜索策略决策。这为用 RL 训练搜索 Agent 提供了更精准的优化方法。

Chiyu Ma, Shuo Yang, Kexin Huang, Jinda Lu, Haoming Meng, Shangshang Wang, Bolin Ding 等 10 人

Rethinking Token-Level Policy Optimization for Multimodal Chain-of-Thought

对多模态 Chain-of-Thought 推理进行 token 级别分析，发现成功推理的特征是结构化的 token 动态——反映感知定位与逻辑推理的交替。基于此发现，提出区分视觉感知 token 和推理 token 的差异化 RL 优化策略，替代现有 RLVR 方法对 CoT 的粗粒度均一处理。

INSIGHT该工作揭示了多模态推理中不同类型 token 需要不同的 RL 优化粒度。对搜索 Agent 中的推理链优化有启示：在检索增强推理中，「检索决策 token」和「推理 token」应区别对待。这一思路可迁移到搜索 Agent 的训练中，对何时检索、何时推理的决策进行差异化优化。

Yunheng Li, Hangyi Kuang, Hengrui Zhang, Jiangxia Cao, Zhaojie Liu

EVA: Efficient Reinforcement Learning for End-to-End Video Agent

提出 EVA，一个基于 RL 的端到端视频理解 Agent。不同于将 MLLM 作为被动识别器处理整个视频的现有方法，EVA 通过 RL 训练模型自适应决定何时使用外部工具、如何选择关键帧，实现高效的长视频理解。

INSIGHTEVA 的核心思想是用 RL 训练 Agent 学习「何时检索」和「检索什么」，而非依赖手工设计的工作流。这一端到端训练范式对搜索 Agent 有直接借鉴：可通过 RL 让搜索 Agent 自动学习在多轮对话中何时触发检索、检索哪类文档，取代基于规则的检索策略。

STRIATUM-CTF: A Protocol-Driven Agentic Framework for General-Purpose CTF Solving

提出 STRIATUM-CTF，基于 Model Context Protocol (MCP) 的模块化 Agentic 框架，用于解决 CTF 网络安全挑战。框架通过标准化工具交互协议实现状态化多步推理，支持搜索式试错和战术效用最大化。在真实 CTF 竞赛中验证了有效性。

INSIGHTSTRIATUM-CTF 展示了 MCP 协议在 Agent 工具交互标准化中的实际应用价值。MCP 作为工具调用的统一协议，对构建可扩展的搜索 Agent 系统有架构层面的参考意义——通过标准化搜索工具接口（如向量检索、关键词检索、重排序等），可以让 Agent 灵活组合不同搜索能力。

AwesomeLit: Towards Hypothesis Generation with Agent-Supported Literature Research

提出 AwesomeLit，一个面向学术文献研究的 Agent 系统，专注于从文献综述到假设生成的全流程支持。与通用 deep research 工具不同，AwesomeLit 针对学术场景进行了定向设计，支持不同经验水平研究者的需求，通过可解释的检索过程降低了黑盒 Agent 的幻觉风险。

INSIGHTAwesomeLit 将 deep research 产品的思路聚焦到学术文献场景，强调了针对特定领域定制 Agent 搜索策略的重要性。对搜索产品设计的启示：通用搜索 Agent 在垂直场景效果有限，需要根据用户角色和使用场景定制搜索策略和结果呈现方式。
