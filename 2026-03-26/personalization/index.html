KARMA: Knowledge-Action Regularized Multimodal Alignment for Personalized Search at Taobao

该论文针对 LLM 在个性化搜索任务中的微调难题，揭示了「知识-行为鸿沟」(Knowledge-Action Gap) 现象：直接用判别式目标微调 LLM 会导致语义坍缩 (Semantic Collapse)，注意力出现 sink 现象，模型泛化能力严重退化。为此提出 KARMA 框架，通过知识正则化和行为对齐的双重约束，在保持 LLM 预训练语义知识的同时有效学习个性化搜索行为。该方法已部署于淘宝搜索系统，在个性化推荐指标上取得显著提升。

GateSID: Adaptive Gating for Semantic-Collaborative Alignment in Cold-Start Recommendation

Alibaba

针对冷启动场景中协同信号稀缺导致的马太效应问题，提出 GateSID 框架。核心思路是通过自适应门控网络 (Adaptive Gating Network) 根据物品成熟度动态平衡语义信号和协同过滤信号。当物品处于冷启动阶段时侧重语义信息，随着交互数据积累逐步增加协同信号权重。该方法解决了传统方法中协同-语义权衡 (collaborative-semantic tradeoff) 的固有矛盾。

INSIGHTGateSID 的核心洞察是冷启动推荐中语义信息和协同信号的最优配比应随物品生命周期动态变化，而非使用静态权重。自适应门控机制允许模型在物品不同成熟阶段自动调整信息融合策略。这对 UGC 平台尤为重要——新帖子/新内容天然面临冷启动问题，可借鉴此方法设计从语义匹配到行为反馈的渐进式排序策略。

Hai Zhu, Yantao Yu, Lei Shen, Bing Wang, Xiaoyi Zeng

03 3.75

Quality Over Clicks: Intrinsic Quality-Driven Iterative Reinforcement Learning for Cold-Start E-Commerce Query Suggestion

Alibaba

针对电商搜索中冷启动 Query Suggestion 场景，提出 Cold-EQS 迭代强化学习框架。传统方法依赖 CTR 模型反馈优化查询建议，但冷启动时缺乏点击数据导致 CTR 模型不可靠。Cold-EQS 转而利用可回答性 (answerability)、事实性 (factuality) 和信息增益 (information gain) 作为内在质量奖励，摆脱对点击数据的依赖。同时引入不确定性估计选择困难样本进行持续优化。

INSIGHTCold-EQS 的核心启发在于：冷启动场景下应使用内在质量指标替代外部点击反馈作为优化信号。可回答性、事实性、信息增益三维奖励设计为搜索建议提供了不依赖用户行为数据的优化路径。对社区搜索场景的启示是：当新话题或新场景缺乏足够行为数据时，可以用内容质量指标 (如内容完整性、信息丰富度) 作为排序信号的冷启动替代方案。

Training-free Adjustable Polynomial Graph Filtering for Ultra-fast Multimodal Recommendation

提出一种免训练 (training-free) 的多模态推荐方法，基于图信号处理中的多项式图滤波 (Polynomial Graph Filtering) 技术。该方法为每种模态 (文本、图像、视频) 构建独立的相似性图，通过可调多项式滤波器在频域进行信息融合，避免了传统神经网络方法的高计算开销。核心优势在于无需训练即可完成多模态推荐，推理速度极快，同时保持有竞争力的推荐精度。

INSIGHT该工作的实践意义在于：多模态推荐不一定需要昂贵的端到端训练。通过图信号处理的理论框架，可以用解析方法高效整合多模态特征。对 UGC 搜索平台的启发是：社区内容天然包含文本、图片等多种模态，可以借鉴图滤波思路构建轻量级的多模态内容理解和推荐管道，特别适合对延迟敏感且计算资源有限的场景。

Yu-Seung Roh, Joo-Young Kim, Jin-Duk Park, Won-Yong Shin

Variational Bayesian Personalized Ranking

提出变分贝叶斯个性化排序 (VarBPR)，将隐式反馈的 pairwise 学习重新表述为对离散潜变量的变分推断问题。该框架显式建模噪声和索引不确定性，将训练分为变分推断和变分学习两阶段。关键创新是引入曝光可控性——通过变分推断控制曝光偏差的影响，同时提供理论可解释性，将经典 BPR 统一为特例。

INSIGHTVarBPR 为隐式反馈中的曝光偏差问题提供了概率论视角的优雅解法。通过变分推断框架显式建模曝光不确定性，比启发式的负采样策略更有理论根基。对搜推实践的启示：(1) 社区搜索中用户点击行为存在严重曝光偏差，VarBPR 的曝光可控性机制可用于去偏排序训练；(2) 两阶段训练范式可借鉴到现有排序模型中作为正则化手段。

E-CARE: An Efficient LLM-based Commonsense-Augmented Framework for E-Commerce

Huawei

提出 E-CARE 框架，高效利用 LLM 的常识推理能力增强电商场景中的查询-商品匹配。核心挑战是 LLM 实时推理成本高且需要人工标注和微调。E-CARE 通过离线挖掘 LLM 常识知识并缓存为特征，在推理时无需调用 LLM，大幅降低了在线服务成本，同时保持了 LLM 带来的语义理解提升。该方案可推广至多种电商任务。

INSIGHTE-CARE 的核心价值在于解决了 LLM 在推荐/搜索系统中的落地难题——如何在不增加在线推理成本的前提下利用 LLM 的语义理解能力。离线知识蒸馏 + 特征缓存的模式是工程上非常实用的 LLM 集成方案。对社区搜索场景直接可借鉴：用 LLM 离线理解 UGC 内容的语义关系，将结果作为特征注入在线排序模型，既能提升语义匹配质量又不增加线上延迟。

On-device Semantic Selection Made Low Latency and Memory Efficient with Monolithic Forwarding

SJTU

提出 PRISM 系统，针对端侧 (on-device) 语义 Top-K 选择任务优化延迟和内存效率。关键洞察是 Top-K 选择只需要相对排名而非精确分数，且排名在 Transformer 中间层即已趋于稳定，可以提前剪枝。PRISM 通过 Monolithic Forwarding 维护所有候选的全局视图，实现渐进式候选淘汰，在边缘硬件上显著降低延迟和内存消耗，同时保持选择精度。

INSIGHTPRISM 的核心发现——排名在中间层即稳定——为重排序模型的加速提供了理论依据。Monolithic Forwarding 技术可推广至云端场景的大规模重排序。对搜推实践的启示：(1) cross-encoder 重排序的计算开销可以通过层级早停大幅削减；(2) 该思路可用于在线排序模型的延迟优化，特别是当候选集较大时，通过渐进式淘汰减少不必要的全量计算。

Personalized Federated Sequential Recommender

提出个性化联邦序列推荐器 (PFSR)，引入 Associative Mamba Block 从全局视角捕获用户画像，同时将计算复杂度从二次降至线性，解决了现有序列推荐方法在实时场景中的效率瓶颈。该框架结合联邦学习实现跨设备的个性化推荐，保护用户隐私的同时维持推荐质量。

INSIGHTPFSR 将 Mamba 架构引入序列推荐，用线性复杂度替代 Transformer 的二次复杂度，为长序列用户行为建模提供了更高效的选择。联邦学习框架使模型可以在保护用户数据隐私的前提下进行协同训练。对注重用户隐私的社区平台有参考价值，但联邦学习在工业搜推中的落地仍面临通信开销和异构数据等挑战。

A Collaborative Ensemble Framework for CTR Prediction

提出一种协作集成框架用于 CTR 预估，通过组合多个模型的预测结果提升整体点击率预测精度。不同于传统的模型集成方法，该框架强调模型间的协作学习而非简单的预测融合，使各子模型在训练过程中互相增强，最终实现比单一模型更优的 CTR 预估效果。

INSIGHT协作集成思路对工业级 CTR 预估有实践参考价值。在搜索推荐系统中，多模型集成是提升排序质量的常见手段，但传统方法缺乏模型间的协同优化。该框架的协作学习机制可以在不显著增加推理成本的情况下提升预测精度，适合作为现有 CTR 模型的增强方案进行评估。

Multi-objective Recommendation via Multi-population Auxiliary Evolution Framework (MOEA-MIAE)

提出基于多种群辅助进化的多目标推荐算法 MOEA-MIAE，针对现有多目标推荐算法在超体积 (HV) 指标上表现不佳的问题，引入多种群进化策略增强解的多样性和新颖性。该方法通过辅助种群探索不同的帕累托前沿区域，改善推荐结果在精度、多样性、新颖性等多目标间的平衡。

INSIGHT多目标优化是推荐系统工程中的核心挑战——搜索推荐系统需要同时优化 CTR、停留时长、内容多样性等多个指标。MOEA-MIAE 提供了进化算法视角的解决方案，但其计算开销和工业可部署性仍需验证。该方向的价值在于提醒实践者：多目标推荐不应简单用加权求和处理，帕累托优化可能带来更好的整体效果。（注：因源多样性需要纳入，分数低于阈值）
