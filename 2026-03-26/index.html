Masked Diffusion Generative Recommendation

本文提出 MDGR（Masked Diffusion Generative Recommendation），摒弃传统自回归解码范式，采用 masked diffusion 进行生成式推荐。通过并行码本提供扩散基础结构、自适应掩码监督信号以及基于 warm-up 的两阶段并行解码策略，解决了自回归方法在全局特征依赖捕获、解码顺序假设和推理效率方面的限制。在公开数据集上相比十个基线模型提升达 10.78%，在大规模广告推荐平台的线上 A/B 测试中实现广告收入提升 1.20%、GMV 提升 3.69%、CTR 提升 2.36%。

Causal Direct Preference Optimization for Distributionally Robust Generative Recommendation

Northeastern University

本文揭示 Direct Preference Optimization (DPO) 在生成式推荐中的关键缺陷：DPO 倾向于在对齐过程中放大环境混杂因素引起的虚假相关性，严重削弱 LLM 推荐器的泛化能力。提出 CausalDPO，通过因果不变性学习和后门调整消除混杂干扰，使用软聚类建模潜在环境分布并施加不变性约束。在多种分布偏移条件下，四个评估指标平均提升 17.17%。

INSIGHTCausalDPO 将因果推断引入生成式推荐的偏好对齐，解决了 DPO 的根本性缺陷——对数据分布的过度依赖导致分布外场景表现骤降。通过后门调整剥离环境混杂因素，模型学到的用户偏好更具因果不变性。这对搜索推荐系统有直接启示：当训练数据和线上数据存在分布差异时（如新品类、新地区），因果对齐策略可显著提升模型鲁棒性。

Chu Zhao, Enneng Yang, Jianzhe Zhao, Guibing Guo

Reasoning over Semantic IDs Enhances Generative Recommendation

NUS

本文提出 SIDReasoner，增强 LLM 对 Semantic ID 的推理能力以提升生成式推荐效果。核心方法包括：利用更强的教师模型合成丰富的 SID 中心语料进行多任务训练，强化 Semantic ID 与自然语言之间的对齐；然后通过结果驱动的强化优化引导推理过程，无需显式标注。在三个真实数据集上验证了方法的有效性，同时带来了可解释性提升和跨域泛化能力。

INSIGHTSIDReasoner 的关键洞察是：当前 Semantic ID 方法中 LLM 并未真正「理解」ID 序列的语义，仅是机械地生成 token。通过教师模型蒸馏的 SID 语料和强化学习优化，LLM 能够在生成推荐时进行有意义的推理。这为生成式推荐系统指明了重要方向：Semantic ID 不应只是离散化的 embedding，而应成为 LLM 可推理的语义载体，从而提升推荐的可解释性和泛化性。

Yingzhi He, Yan Sun, Junfei Tan, Yuxin Chen, Xiaoyu Kong, Chunxu Shen, Xiang Wang, An Zhang 等 9 人

ImplicitRM: Unbiased Reward Modeling from Implicit Preference Data for LLM alignment

Peking University

本文提出 ImplicitRM，解决从隐式偏好数据（如点击、复制等行为信号）学习无偏奖励模型的挑战。识别了隐式反馈的两个根本问题：缺乏明确负例和用户偏好偏差对不同响应的差异化影响。通过分层模型将训练样本划分为四个潜在组，并推导出基于似然最大化的无偏学习目标，实现跨隐式偏好数据集的准确奖励建模。

INSIGHTImplicitRM 架起了推荐系统中广泛使用的隐式反馈（点击、浏览）与 LLM 对齐（RLHF）之间的桥梁。其分层无偏学习框架可直接迁移到基于 LLM 的推荐系统中：利用海量用户行为日志构建奖励模型，无需昂贵的人工标注。对搜索推荐实践者的启示：现有的点击/转化数据可以作为 LLM 推荐对齐的信号源，但需注意偏差校正。
