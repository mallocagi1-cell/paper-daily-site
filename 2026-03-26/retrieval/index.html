AI Co-Scientist for Ranking: Discovering Novel Search Ranking Models alongside LLM-based AI Agents with Cloud Computing Access

本文提出首个面向搜索排序模型研发的 AI Co-Scientist 框架，自动化完成从创意生成、代码实现到 GPU 训练调度的完整研究流水线。系统采用单 LLM agent 处理日常任务，多 LLM 共识 agent（GPT 5.2、Gemini Pro 3、Claude Opus 4.5）协同处理结果分析与创意生成等高难度阶段。该框架成功发现了一种处理序列特征的新技术，所有模型改进均由 AI 自动产生。

TIPS: Turn-Level Information-Potential Reward Shaping for Search-Augmented LLMs

针对搜索增强型 LLM 训练中奖励稀疏和信用分配困难的问题，提出 TIPS（Turn-Level Information-Potential Reward Shaping）框架。TIPS 基于教师模型为每个推理+工具调用段分配密集的 turn 级奖励，利用 potential-based reward shaping 提供细粒度、策略不变的训练信号。在 7 个 QA 基准上，TIPS 持续优于 GRPO/PPO 基线，使用 Qwen-2.5 7B 模型显著提升训练稳定性和性能。

INSIGHTTIPS 解决了 search-augmented LLM 训练中的核心难题：多轮搜索场景下的奖励稀疏。其 turn 级奖励设计避免了 advantage collapse 问题，对于需要多轮检索的复杂搜索场景（如社区 UGC 搜索中的长尾 query）具有直接参考价值。potential-based 方法保证了策略不变性，这是工程实践中稳定训练的关键。

Yutao Xie, Nathaniel Thomas, Nicklas Hansen, Yang Fu, Li Erran Li, Xiaolong Wang

Information Gain-based Policy Optimization: A Simple and Effective Approach for Multi-Turn Search Agents

提出基于信息增益的策略优化方法（IGPO），解决 LLM 搜索 agent 多轮交互中奖励稀疏导致的三大问题：advantage collapse（所有轨迹获得相同奖励）、缺乏细粒度信用分配、以及低样本效率。IGPO 通过衡量每轮搜索交互带来的信息增益来提供中间奖励信号，从而在长轨迹任务中实现有效的策略学习。

INSIGHTIGPO 与 TIPS 形成互补，共同揭示了搜索 agent RL 训练的前沿方向。其信息增益度量为每轮搜索调用提供了直观且可计算的奖励信号，特别适合需要多步检索才能回答的复杂问题。对于社区搜索中的意图理解和多跳查询场景，信息增益作为中间奖励的设计思路值得借鉴。

Guoqing Wang, Sunhao Dai, Guangze Ye, Zeyu Gan, Wei Yao, Yong Deng, Xiaofeng Wu, Zhenzhe Ying

flexvec: SQL Vector Retrieval with Programmatic Embedding Modulation

提出 flexvec 向量检索内核，将 embedding 矩阵和分数数组暴露为可编程接口，支持在查询时对两者进行算术运算（称为 Programmatic Embedding Modulation, PEM）。系统集成到 SQL 接口中，在 24 万 chunk 的生产语料上三组组合调制操作端到端执行仅需 19ms（桌面 CPU），100 万 chunk 规模下为 82ms，无需近似索引。

INSIGHTflexvec 提出了向量检索的新范式：将检索管道的更多控制权暴露给调用方（特别是 AI agent），通过可组合的查询原语实现灵活的 embedding 操作。这对于社区搜索中需要动态调整召回策略的场景（如个性化权重、多意图融合）提供了轻量级解决方案。SQL 接口的设计降低了使用门槛，19ms 的延迟在实际系统中可接受。

Damian Delmas

SkillRouter: Retrieve-and-Rerank Skill Selection for LLM Agents at Scale

面对 LLM agent 生态中技能（工具/插件）数量已达数万级的挑战，提出 SkillRouter 检索-重排两阶段技能选择框架。研究发现现有 agent 架构仅依赖技能名称和描述进行选择的假设不成立——在约 8 万技能、75 个专家标注查询的基准上，系统性实验表明技能的完整实现代码（skill body）对准确选择至关重要，特别是在功能高度重叠的场景下。

INSIGHTSkillRouter 的 retrieve-and-rerank 架构本质上是一个大规模检索+精排系统，其发现（仅靠元数据不够，需要看完整内容）直接映射到搜索领域的经典问题：snippet 级别的匹配不足以判断文档相关性。对于搜索系统中的 query-document 匹配，这项工作提供了实证支持：精排阶段应利用更丰富的文档表示，而非仅依赖标题/摘要。

A Brief Comparison of Training-Free Multi-Vector Sequence Compression Methods

针对多向量检索模型（如 ColBERT）索引体积过大的部署瓶颈，系统评估了无需训练的 token 序列压缩方法。核心发现：token merging 在减少索引大小的同时保持检索效果方面严格优于 token pruning。该结论对于多向量检索模型的实际部署具有直接指导意义。

INSIGHT多向量检索（如 ColBERT 系列）的索引膨胀是工业部署的主要障碍。本文提供了明确的工程指导：应优先采用 token merging 而非 pruning 进行压缩。这一无训练方法的优势在于可直接应用于已训练好的模型，对于需要在有限硬件上部署多向量检索的团队（如社区搜索的语义召回模块）具有即时价值。

Rohan Jha, Chunsheng Zuo, Reno Kriz, Benjamin Van Durme

ProGRank: Probe-Gradient Reranking to Defend Dense-Retriever RAG from Corpus Poisoning

提出 ProGRank，一种面向稠密检索 RAG 系统的后处理、无训练防御方法。通过对每个 query-passage 对施加随机扰动并提取 probe gradient，计算表征一致性和分散风险两个不稳定性信号，结合 score gate 进行重排序，有效识别和降权被投毒的段落。方法完全在检索侧实现，无需修改生成器。

INSIGHTProGRank 揭示了一个重要洞察：被注入的恶意文档在梯度空间中表现出与正常文档不同的不稳定性模式。这一发现可推广到搜索系统中的 spam/SEO 检测场景。对于 UGC 社区搜索，用户生成内容中的 SEO spam 是现实挑战，ProGRank 的梯度探测思路提供了一种不依赖内容过滤的检测方法。

Xiangyu Yin, Yi Qi, Chih-hong Cheng

Less is More: Adapting Text Embeddings for Low-Resource Languages with Small Scale Noisy Synthetic Data

挑战了 embedding 模型适配需要大规模高质量数据的常见假设。以亚美尼亚语为例，仅使用 1 万条由开源模型翻译的 Reddit 标题-正文对（有噪声的合成数据）微调多语言编码器 mE5，在综合基准上平均提升 11-12%，部分任务提升超过 20%。提出了「Less is More」现象：少量噪声数据即可显著改善低资源语言的语义搜索效果。

INSIGHT「少即是多」的发现对搜索系统中的多语言支持具有实践意义：不需要大规模人工标注数据，仅凭少量 LLM 生成的翻译对就能有效适配 embedding 模型到新语言。对于需要支持多语言 UGC 内容检索的社区平台，这提供了一条低成本的多语言扩展路径。

Zaruhi Navasardyan, Spartak Bughdaryan, Bagrat Minasyan, Hrant Davtyan

LGSE: Lexically Grounded Subword Embedding Initialization for Low-Resource Language Adaptation

提出 LGSE（Lexically Grounded Subword Embedding）框架，通过形态学感知的分词策略初始化新 token 的 embedding。不同于随机初始化或任意子词分割，LGSE 将词汇分解为语素成分，利用预训练子词或 FastText 语素表示构建语义连贯的 embedding。无法分割为语素的 token 则使用字符 n-gram 表示捕获结构信息。

INSIGHTLGSE 的形态学感知初始化策略对于搜索系统中的 query 和 document 表示质量具有间接但重要的影响。在社区搜索中，UGC 内容常包含非标准词汇、缩写、新造词，传统子词分词可能产生碎片化表示。LGSE 的语素级初始化思路可借鉴到处理这类「形态学丰富」的用户生成文本。

Hailay Teklehaymanot, Dren Fazlija, Wolfgang Nejdl

DALDALL: Data Augmentation for Lexical and Semantic Diverse in Legal Domain by leveraging LLM-Persona

提出 DALDALL，一种基于 LLM persona 的数据增强框架，专为法律信息检索设计。方法利用领域特定的专业角色（律师、检察官、法官）生成合成查询，在词汇和语义多样性上显著优于普通提示方法（Self-BLEU 指标衡量）。在 CLERC 和 COLIEE 基准上，基于 persona 增强数据微调的稠密检索器表现优于基线。

INSIGHTpersona-based 数据增强的核心思想——让 LLM 扮演不同角色生成多样化查询——可直接迁移到搜索系统的 query 增强场景。在社区搜索中，不同用户群体（如新手 vs 专家）的检索意图和表达方式差异很大，利用角色化 LLM 生成多样化训练 query 可改善检索器对长尾查询的泛化能力。

Janghyeok Choi, Jaewon Lee, Sungzoon Cho
