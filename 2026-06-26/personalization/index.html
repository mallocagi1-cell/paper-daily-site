TokenMinds: Pretrained User Tokens and Embeddings for User Understanding in Large Recommender Systems

工业级推荐系统的用户建模通常依赖固定维度稠密向量，表达能力受限；用 LLM 生成文本型用户 token 又只能捕捉话题共现、难以对齐物品属性。TokenMinds 把 PLUM 框架从物品检索扩展到用户建模，用改编自预训练 LLM 的 encoder-decoder 同时产出基于 Semantic ID (SID) 的离散用户 token 与稠密用户 embedding，兼顾语义可解释和对下游稠密精排模型的兼容。共享 SID 词表把长视频与短视频行为统一进单一模型，降低训练与服务成本。系统已在 YouTube 多个场景全量上线（数十亿用户），通过异步架构将表征生成与下游打分解耦，主要服务于排序。

02 3.70

S2-CAR: Segmentation-Supervised Complexity-Adaptive Recommendation

序列推荐中用户兴趣随时间隐式漂移，现有模型要么把整段序列当作同质上下文，要么用固定时间窗切分，导致与真实意图边界错位、在序列中间位置产生跨意图干扰并过度依赖短期信号。S2-CAR 提出"分段监督 + 复杂度自适应"框架，把用户意图建模为连续隐能量状态：用 Context-Aware Soft Temporal Point Process (Soft-TPP) 按隐状态能量自然衰减触发边界切分（而非固定间隔），再用 Segment-Count-Adaptive 多意图抽取模块把意图连贯片段层次化聚合为紧凑多兴趣表征。在电影、电商、游戏 3 个公开数据集、对比 13 个基线上全面超越 SOTA，且作为即插即用模块能稳定提升已有序列推荐骨干。

INSIGHT关键创新是"用能量衰减做软意图分段"，比固定时间窗更贴合真实兴趣边界，缓解长序列建模中的跨意图干扰。最实用之处是它被验证为 plug-and-play 模块，可直接嵌入现有序列推荐骨干带来增益——对已有 SASRec/transformer 类召回或精排的团队，是低成本试点的好选择；其"意图边界检测 + 多兴趣自适应聚合"也可迁移到搜索中的会话/长序列用户意图建模。

Linjiang Guo, Nitin Bisht, Shiqing Wu, Xianzhi Wang, Guandong Xu

03 3.40

Causal-Invariant Cross-Domain Out-of-Distribution Recommendation

跨域推荐 (CDR) 用数据丰富的源域补齐稀疏目标域，但通常假设目标域训练/测试同分布；现实中单域分布漂移 (SDDS) 与跨域分布漂移 (CDDS) 同时存在，形成 OOD 环境，损害知识迁移与泛化。CICDOR 提出因果不变的跨域 OOD 推荐框架：先学习双层因果结构，分别推断域特有与域共享的因果不变用户偏好以同时应对 CDDS 与 SDDS；再用 LLM 引导的混杂因子发现模块，把 LLM 与传统因果发现结合抽取可观测混杂因子做去混杂，从而更准确地推断因果不变偏好。在两个真实数据集、多种 OOD 场景下准确率超越 SOTA。（本文为 2025-05 首版的 2026-06 修订版）

INSIGHT亮点是"用 LLM 辅助因果发现"——把大模型的世界知识注入混杂因子识别，缓解纯统计因果发现在推荐场景下的不足，是 LLM 与因果推断结合的一个值得关注方向。启示：冷启动/跨域迁移场景下，区分"域共享"与"域特有"的不变偏好有助于抵御分布漂移；不过因果框架落地仍需较多假设与工程投入，建议先在离线评估中验证其对 OOD 鲁棒性的收益。

Jiajie Zhu, Yan Wang, Feng Zhu, Pengfei Ding, Hongyang Liu, Zhu Sun
