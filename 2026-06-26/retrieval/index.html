AutoRelAnnotator: Calibrated Model Cascades for Cost-Efficient Relevance Evaluation in Sponsored Search

针对搜索排序系统所需的相关性标注（训练数据准备、NDCG 评估、badcase 归因），人工标注慢、通用 LLM 在领域任务上精度不足。论文提出 calibrated model cascade：把 query 按难度路由经过逐级增大的微调分类器，再叠加 per-class isotonic calibration 校准。作者拆解收益来源——领域微调贡献约 20 个准确率百分点，级联近似不损精度但把算力减半，校准再提供小而稳定的增益。

KEY INSIGHT · 对业务意味着什么把精度与成本当作正交优化、分别用微调和级联求解，是离线相关性标注流水线的实用范式：小模型兜住简单 query、只把困难 query 升级到大模型，可在保持 NDCG 评估质量的同时把标注算力减半。对社区搜索的相关性样本生产与 badcase 归因有直接借鉴；按类别做 isotonic calibration 的做法可迁移到任意多级分类打分场景。

Adaptive Re-Ranking

UUMass

现代 IR 的 retrieve-then-rerank 流水线对所有 query 无差别套用重型 cross-encoder，简单 query 上浪费算力并抬高延迟。论文提出 Adaptive Re-Ranking，用基于效用（utility）的标注框架做 per-query 成本感知路由，在 BM25（稀疏）、MiniLM-L6-v2（轻量重排）、BGE-v2-m3（重型神经重排）三档间选择。相比全程 BGE，中位延迟降低 1.15–53 倍、平均延迟降低 1.11–5.22 倍。

INSIGHT按 query 复杂度动态选重排档位，是搜索排序降本的直接抓手：简单 query 走 BM25/轻量模型，困难 query 才上重型 cross-encoder。作者坦言路由器在有限监督下难以学好、oracle 分析显示潜力大但落地是难点，提示工业上需重点投资效用标签的构造。社区搜索可借此在大流量低难度 query 上释放 GPU。

Ata Cinar Genc, Emir Kaan Korukluoglu, James Allan

03 3.75

Extreme Meta-Classification for Large-Scale Zero-Shot Retrieval

Microsoft

面向新（零样本）item 持续高速涌入的大规模检索场景。Siamese 双塔便于增删新 item 但小编码器容量不足；extreme classification 为每个训练集 item 学独立分类器、表达力强却覆盖不到新 item。论文提出 EMMETT 框架，on-the-fly 合成分类器以兼顾两者——保留双塔对新 item 的可扩展性，又借分类器范式提升表征容量。

INSIGHTUGC 短文本搜索同样面临帖子/笔记持续新增的零样本检索问题。EMMETT 为新 item 动态合成分类器的思路，给出了双塔与极端分类之间的折中：无需为新内容重训分类头即可逼近 extreme classification 的表达力。出自 Microsoft 极端分类团队（Manik Varma 等），对大规模冷启动召回有参考价值。

Sachin Yadav, Deepak Saini, Anirudh Buvanesh, Bhawna Paliwal, Kunal Dahiya, Siddarth Asokan 等 9 人

Is GraphRAG Needed? From Basic RAG to Graph-/Agentic Solutions with Context Optimization

面对 GraphRAG、Agentic RAG 等高级变体，何时用、怎么用缺乏系统答案。论文在半结构化知识库上构建评测框架，对 regular RAG、GraphRAG、Modular RAG、Agentic RAG 提供 9 个标准化场景实现并系统对比，覆盖从纯文档检索到 text-graph 混合检索、领域知识图谱集成、agentic 多步规划等真实约束。同时提出一种 context engineering 方法缓解 GraphRAG/Agentic RAG 的 context/memory 溢出。

INSIGHT与其盲目上 GraphRAG，不如先按数据/领域约束做场景化选型——论文的 9 场景标准实现可作为搜索问答选型的对照基线。其针对 graph 与 text 检索的上下文管理（新表征 + agentic loop）对控制长上下文成本有借鉴价值。结论提醒：高级 RAG 并非总优，收益需按场景验证。

Long Chen, Ryan Razkenari, Yuxuan Zhou, Yuan Tian, Rahul Ghosh, Venkatesh Pappakrishnan, Disha Ahuja 等 8 人

Tracing Target Answers in Poisoned Retrieval Corpora via Token Influence Attribution

IBMNNYCU

RAG 系统易受语料投毒攻击——恶意文档通过被检索来操纵输出。已有检测多依赖辅助分类器或额外 LLM 验证，开销大。论文提出 TRACE：用 token influence attribution 追踪与答案相关的 token，先发现检索文档中反复出现的高影响关键词，再做二次验证确认其对模型预测的影响。在 3 个 QA benchmark、6 个 LLM 上检测性能强，并能反向揭示攻击者植入的目标答案。

INSIGHTUGC 语料天然含 spam 与对抗内容，TRACE 的轻量 token 影响归因思路（无需额外分类器/LLM）适合在线检索的低开销内容可信度检测。把反复出现的高影响关键词当作投毒信号，可迁移到社区搜索的作弊/灌水文档识别。来自 IBM Research（Pin-Yu Chen）与 NYCU，检测同时还原目标答案、便于 badcase 溯源。

Yan-Lun Chen, Pin-Yu Chen, Chia-Mu Yu, Ying-Dar Lin, Yu-Sung Wu, Wei-Bin Lee

Hybrid-IR: Dual-Path Hybrid Retrieval with Iterative Reasoning for Complex Medical Question Answering

医疗 QA 中 LLM 易幻觉、知识过时；RAG 缓解但有两点不足：医疗知识跨文档碎片化，单一检索路径难以同时保留细粒度语义与结构化全局关联；静态检索不足以支撑复杂推理。论文提出 Hybrid-IR——双路检索（图检索捕捉显式结构关联 + 语义检索保留细粒度信息）配合 iterative retrieval-reasoning 迭代机制，按推理进展动态补充检索。

INSIGHT图 + 语义双路检索配迭代检索-推理的设计，对需要跨文档聚合的复杂 query（如社区多跳问答）有迁移价值：单路召回常在细粒度语义与全局结构间二选一，双路并行可兼顾。迭代式按需检索而非一次性 top-k，是控制复杂 query 召回质量的通用思路；医疗域之外仍需评估图构建成本。

Sheng Wan, Jiahui Zhang, Zicheng Zhao, Shougang Ren

Error-Aware TF-IDF Retrieval-Augmented Generation for ASR Error Correction

端到端 ASR 常对稀有实体、领域术语产生幻觉，低资源语言尤甚。已有 RAG 纠错要么用忽略语音误识的标准稀疏检索，要么用高延迟跨模态 embedding。论文提出纯词法的 error-aware 框架：对称文本归一化模块 + 新颖的 error-aware TF-IDF——基于历史错误构造稀疏对角惩罚矩阵，让检索器在数学上优先召回含特定高风险误识的纠错文档。

INSIGHT用历史错误统计构造稀疏对角惩罚矩阵来改造 TF-IDF 权重，是把领域先验注入轻量稀疏检索的低成本范式，无需跨模态 embedding 即可定向召回。对社区搜索的 query 拼写/误输入纠错召回有启发：把高频误识与改写对编码进检索权重，可在不引入重型模型的前提下提升纠错召回。纯词法方案延迟友好，适合在线。

Mohammad Aref Jafari-Raddani

08 3.00

CausalRAG2: Hierarchical Causal Knowledge Graph Design for RAG

基于图的 RAG 擅长结构化检索与推理，但现有方法过度依赖以实体为中心的节点匹配、缺乏显式因果建模，导致答案不忠实或出现伪相关；既有引入因果的尝试多局限于局部/单文档，且模块化图结构造成信息孤岛、难以跨模块因果推理与扩展。论文提出 CausalRAG2，通过跨层级模块的 causal gating 重组知识，显式建模因果以抑制伪相关，同时支持在大规模知识图谱上可扩展推理。

INSIGHTcausal gating 抑制伪相关，针对的是图 RAG 常见的实体共现≠因果问题，对需要因果链而非表面关联的检索推理有借鉴价值。分层模块设计试图解决图 RAG 的信息孤岛与扩展性瓶颈，思路可迁移到大规模知识图谱召回。本文为 v2 修订版，工业落地需评估因果图构建与维护成本。

Nengbo Wang, Tuo Liang, Vikash Singh, Chaoda Song, Van Yang, Yu Yin, Jing Ma, Jagdip Singh 等 9 人
