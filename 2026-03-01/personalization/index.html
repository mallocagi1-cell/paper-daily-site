CADET: Context-Conditioned Ads CTR Prediction With a Decoder-Only Transformer

📖 深度解读 · 14 分钟 →

LinkedIn 提出 Decoder-Only Transformer 架构 CADET 用于广告 CTR 预估，引入上下文条件解码和自门控注意力机制。

INSIGHT将 NLP 领域成熟的 Decoder-Only Transformer 范式迁移到 CTR 预估场景。关键创新在于 context-conditioned decoding 显式建模位置等后评分信号，以及 timestamp-based position embedding 捕捉用户行为的时序模式。这表明 CTR 模型架构正在向统一 Transformer 范式收敛。

业务关联社区搜索排序模型可借鉴 CADET 的架构思路：用 decoder-only transformer 统一建模用户特征序列，通过 context-conditioned 机制引入展示位置、时间等上下文信号。自门控注意力可缓解搜索排序模型训练中的不稳定问题。

证据在 LinkedIn 广告平台上线，CTR 相比生产模型 LiRank 提升 11.04%。采用 tensor packing 和定制注意力 kernel 优化推理性能以满足线上延迟要求。

RQ-GMM: Residual Quantized Gaussian Mixture Model for Multimodal Semantic Discretization in CTR Prediction

提出 RQ-GMM 方法将多模态 embedding 通过高斯混合模型和残差量化离散化，用于 CTR 预估中的多模态特征融合。

INSIGHT多模态内容特征融入 CTR 模型的核心挑战是如何有效离散化连续 embedding。RQ-GMM 用概率建模（GMM）替代硬量化，再叠加残差量化逐层精化，显著提升 codebook 利用率和重建精度。这为搜索中引入图片/视频等多模态特征提供了新方案。

业务关联社区搜索中帖子包含图文视频等多模态内容，当前排序模型多依赖文本特征。RQ-GMM 提供了将多模态 embedding 高效融入 CTR 模型的可行路径——用 GMM 概率离散化替代简单量化，可直接用于社区内容排序模型的多模态特征引入。

证据在公开数据集和大规模视频平台上验证，广告主价值（Advertiser Value）相比强基线提升 1.502%。模型已部署服务数亿用户。

Multi-Behavior Sequential Modeling with Transition-Aware Graph Attention Network for E-Commerce Recommendation

阿里提出 TGA 用图注意力网络建模用户多行为（点击、收藏、加购、购买）之间的转移关系，线性复杂度实现序列推荐。

INSIGHT多行为序列建模的关键在于捕捉行为间的转移模式。TGA 从 item 级、category 级和邻居级三个粒度构建稀疏图来编码行为转移，且保持线性复杂度。这比 Transformer 基方法更适合长序列行为建模。

业务关联社区搜索用户同样存在多种行为（点击、浏览、收藏、评论、分享），TGA 的多行为转移建模思路可直接迁移：通过图注意力捕捉「搜索→点击→收藏」等行为链路的模式，增强排序模型对用户意图的理解。

证据WWW2026 短论文录用。在阿里电商场景部署验证，相比现有方法在准确性上有显著提升，同时计算成本降低（线性复杂度 vs 二次复杂度）。

LLM Reasoning for Cold-Start Item Recommendation

Netflix 提出利用 LLM 推理能力解决新 item 冷启动问题，通过监督微调和强化学习方法推断用户偏好。

INSIGHTLLM 的推理能力可以弥补冷启动场景中交互数据不足的问题。关键发现是 reasoning-based 微调比直接预测效果更好，且 RL 方法可以进一步提升——这暗示搜索排序中的冷启动问题也可以通过 LLM 推理链来解决。

业务关联社区搜索面临新帖子/新话题的冷启动排序问题（新发布的帖子缺少点击/互动数据）。可参考该方法用 LLM 基于帖子内容推理其可能的用户偏好匹配度，作为冷启动阶段的排序信号补充。

证据WWW2026 录用。在 Netflix 推荐场景中，reasoning-based 微调模型在特定冷启动评测上超过生产排序模型 8%。评估了监督微调、RL 和混合方法三种策略。

DAIAN: Deep Adaptive Intent-Aware Network for CTR Prediction in Trigger-Induced Recommendation

提出 DAIAN 解决触发式推荐中的「意图近视」问题，通过自适应意图建模避免推荐结果过度集中于触发 item。

INSIGHT触发式推荐（如「看了又看」）的核心问题是系统过度关注触发 item 而忽略用户更广泛的兴趣。DAIAN 通过关联分析 trigger-click 对来提取个性化意图，并融合 ID 特征和语义特征进行自适应增强。

业务关联社区搜索中的相关推荐（如「相关帖子」）面临类似的意图近视问题。DAIAN 的 hybrid enhancer（ID + 语义）思路可用于搜索结果页的相关推荐模块，避免推荐过于集中在与当前帖子高度相似的内容。

证据在公开数据集和工业电商数据集上验证有效性。相比基线方法在 CTR 预估的 AUC 和 LogLoss 上有显著提升（具体数值需参阅原文）。

Contrastive Learning for Cold Start Recommendation with Adaptive Feature Fusion

提出结合对比学习和自适应特征融合的冷启动推荐方法，动态调节用户属性、item 元信息和上下文特征的权重。

INSIGHT冷启动场景下特征的重要性分布与热门场景显著不同。自适应特征选择模块可以根据交互数据的稀疏程度动态调整特征权重——交互越少的 item/user，内容特征权重越高。对比学习进一步增强稀疏特征的表征质量。

业务关联社区搜索中新用户和新帖子的冷启动是常见挑战。该方法的自适应特征融合策略可应用于搜索排序：对新用户更依赖画像特征，对新帖子更依赖内容特征，并用对比学习增强特征表征。

证据在 MovieLens-1M 上验证，AUC 和 NDCG 均优于 Matrix Factorization、DeepFM 等基线。消融实验确认各模块（自适应选择、对比学习、多模态融合）均有正向贡献。

Jiacheng Hu, Tai An, Zidong Yu, Junliang Du, Yuanshuai Luo
