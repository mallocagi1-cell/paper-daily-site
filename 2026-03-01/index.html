AgenticTagger: Structured Item Representation for Recommendation with LLM Agents

用多 Agent LLM 系统自动为推荐系统中的 item 生成结构化、分层次的标签词表，提升生成式和基于词项的推荐检索效果。

INSIGHTAgenticTagger 把 item 表征问题转化为 LLM agent 协作任务：由 Architect LLM 迭代构建低基数层次词表，由 Annotator LLM 并行为 item 打标，实现可解释、可控的 item ID 生成——比单纯用 embedding 的生成式推荐更具落地灵活性。

业务关联UGC 社区内容（帖子、评论）天然缺乏结构化标签。AgenticTagger 可作为离线 item 标注流水线，为社区搜索的生成式召回提供语义可控的 item 标识符，同时支持 term-based 检索路径，与现有搜索系统兼容性好。

证据在生成式推荐、基于词项的检索、排序以及可控-批评式推荐等多种场景下均取得一致性提升；具体数值因场景而异，论文报告多数据集跨场景验证有效。

Multimodal Enhancement of Sequential Recommendation

MuSTRec 将多模态内容特征（文本+视觉）与序列用户行为统一融合，通过 item-item 图和频率自注意力捕捉长短期偏好。

INSIGHT多模态与序列推荐的融合可以显著缓解稀疏反馈和长尾问题——item-item 相似性图能在协同信号稀缺时补充内容信号，频率自注意力则平衡短期兴趣漂移与长期稳定偏好。

业务关联社区 UGC 内容（图文帖子）往往存在反馈稀疏问题，且用户兴趣随话题热点快速变化。MuSTRec 的多模态增强思路对社区搜索中的相关内容推荐有参考价值，尤其适用于图文混合内容场景。

证据在多个 Amazon 数据集（含 Clothing、Sports、Beauty 等）上，相比多模态和序列推荐 SOTA 基线取得最高 33.5% 的指标提升（Hit Rate, NDCG）。

Bucher Sahyouni, Matthew Vowels, Liqun Chen, Simon Hadfield

SimGR: Escaping the Pitfalls of Generative Decoding in LLM-based Recommendation

📖 深度解读 · 16 分钟 →

SimGR 识别出 LLM 生成式推荐中 beam search 覆盖不完整和并行解码概率偏差两大缺陷，提出在共享隐空间直接建模 item 偏好分布并按相似度排序。

INSIGHT当前主流的 LLM 生成式推荐方法存在系统性偏差：自回归解码因 beam search 剪枝导致候选覆盖不全，并行解码因独立性假设而扭曲概率。SimGR 绕过 token 级生成，直接在 item 空间建模分布，提供了更本质的修复路径。

业务关联对于考虑引入 LLM 做生成式召回的社区搜索团队，SimGR 揭示的两类解码陷阱是绕不开的工程问题。在 LLM 推荐系统设计阶段了解这些系统性偏差，可避免在错误的解码策略上耗费大量调优成本。

证据在多个推荐数据集和不同 LLM backbone 上，SimGR 均一致性优于现有生成式推荐方法；实验覆盖多模型对比，但具体 NDCG/HR 数值未在摘要中列出。
