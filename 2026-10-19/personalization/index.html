TransX Technical Report: Scaling Sequence Transduction for Recommendation

把用户历史预先压成可复用的记忆，能减少每次排序时的重复计算。TransX 将序列编码、行为记忆和候选融合拆开扩容，并由离线、近线服务更新状态。独立线上实验中，基础模型的点击率相对生产基线提升 6.02%。

RecSoup: Efficient Model Merging Approach for Controllable Multi-Objective Recommendation

已录用 CIKM 2026📖 深度解读 · 7 分钟 →

要随时调整准确率与多样性的取舍，可以复用各自训练好的模型。RecSoup 先按目标重要性裁剪参数增量，再用小网络把偏好权重映射为合并系数。在三个基准上，构造推理参数的延迟比超网络方案低约 165—228 倍。

INSIGHT控制目标取舍不一定要重新生成整套参数。先保留各目标关键的参数增量，再学习怎样组合，能减轻目标间干扰。论文的加速数字衡量参数构造阶段，不能读成整条推荐链路同倍数加速。

Agentic-Priors: Using Large Language Models to Address the Cold Start Problem in Preference Elicitation

新用户还没留下行为时，可以让语言模型先给出可解释的偏好估计。作者将支付意愿、时间价值等判断转成贝叶斯先验，再用真实选择逐步更新。在七个选择数据集上，冷启动准确率比无信息先验高 5—40 个百分点。

INSIGHT先验可以表达不确定性，而不必把语言模型的猜测当成固定标签。用真实选择持续修正偏好，能让启动阶段的外部知识逐渐让位于个人证据；收益主要集中在部署初期，已有大量调查数据时优势会缩小。

Understanding and Mitigating Training Instability in Large-Scale Recommender Systems: A Cascade Perspective

Google

推荐模型训练发散，可以沿梯度、权重、损失的先后变化定位原因。Google 将防护分成梯度控制、权重与激活稳定、损失整形，并比较各类干预。联合方案在第二个二分类任务中，AUC 相对基线提高 0.38%。

INSIGHT单看最后的损失尖峰容易错过起点。把梯度范数、参数或激活幅度、各任务损失放到同一时间线上，有助于区分触发源和传播结果。不同干预对分类与回归任务并不一致，稳定性和任务收益要同时观察。

Hybrid transformer-based recommender system with LLM-assisted semantic modeling for sequential and federated learning

IIIT (ISM) DhanbadSSt. Ann’s College

稀疏交互不足以描述新物品时，可以把文本和类别信息一起送入序列模型。作者融合物品编号、类型特征与 BERT 文本向量，并用注意力预测下一项。在四个基准上完成离线评测，联邦训练部分仅做了可行性实验。

INSIGHT内容语义与行为信号可以在同一个小型序列骨干中融合。论文附录实际使用 BERT 文本表示，不能把标题里的大模型理解成线上调用生成模型；公开页面未给出主要指标的提升幅度，证据强度据此保守计分。

CalendarRec: Multi-Order Temporal Context for Sequential Recommendation

Korea UniversityChung-Ang University

只看点击先后会漏掉用户偏好的周期变化。CalendarRec 将月份、日期和星期分别编码，与点击序列一起交给状态空间模型处理。在健康食品点击日志上，NDCG@10 比 Mamba4Rec 相对提高 14.2%。

INSIGHT日历位置与行为顺序包含不同的信息。把时间拆成多种周期，可以表达每周或每月重复的需求，无需靠增加序列长度来猜测。该结果主要来自健康食品电商场景，适合借鉴其特征设计和消融方法。

Encoded but Exposed: Language Embeddings can Reveal More Than They Should in Recommender Systems

CCTU

推荐系统输出的语义向量，可能暴露原本隐藏的物品身份。作者用公开描述计算向量，再做余弦匹配；即使描述来源不同，也能找到对应物品。两个真实数据集表明，物品泄露还可能沿稀疏评分传播到用户重识别。

INSIGHT向量难以人工阅读，不代表物品身份已被隐藏。公开目录与同类编码器就可能成为辅助信息。对外共享向量时，要同时评估物品匹配和用户重识别；混淆文本会牺牲推荐效用，并非免费保护。

Reliability-aware ensemble recommendation for open-network commerce: a dual-metric framework for jointly evaluating ranking accuracy and serving correctness

VVIT

推荐列表排得准，用户也可能点不开商品。作者把排序效果与服务正确性分开评测，检查跨服务编号映射、路由和回退逻辑。在固定请求轨迹的受控实验里，路由解析成功率从 60.0% 提高到 99.8%。

INSIGHT排序指标无法反映链接失效或物品身份不一致。社区内容推荐也可以把可访问性作为独立指标，与点击预测一起监控；本文的工程结果来自可重放的受控系统，而不是生产线上实验。

MARS: A Momentum-Aware Adaptive Rating System for Personalized Assessment

自适应测验既要估计能力，也要在时间预算内挑选题目。MARS 用知识图谱组织题库，并把作答质量与近期能力变化纳入评分更新。在带负分的限时实验中，超时违规率从 50% 降至 5.6%。

INSIGHT用户状态的变化速度也能参与下一步决策。这里把评分稳定性、题目收益和剩余时间一起考虑，适合启发有预算约束的序列决策；实验对象是教育测验，指标并非内容推荐的点击率。
