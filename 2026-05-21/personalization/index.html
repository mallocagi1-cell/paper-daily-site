Divergence Meets Consensus: A Multi-Source Negative Sampling Framework for Sequential Recommendation

序列推荐隐式反馈下的负采样长期被 self-guided hard negative 主导：模型用当前参数挑硬负，结果是采样和模型互相强化、被困局部最优。论文提出 MDCNS（Multi-source Divergence-Consensus），借鉴 Vygotsky 最近发展区理论搭建 Teacher-Peer-Self 三源打分框架：用辅助模型扩大采样空间、引入分歧度过滤、再用共识投票决定最终负样本。在多个公开数据集上 Recall@10 与 NDCG@10 显著优于 DNS、SRNS 等基线。

KEY INSIGHT · 对业务意味着什么核心创新是把负采样从“单模型自洽”改成“多模型分歧 + 共识”——分歧扩展搜索空间避免坍缩，共识抑制噪声。对搜推系统的启示是：硬负样本不必依赖在线全库打分，可以蒸馏出 teacher/peer 离线打分缓存，再用 voting threshold 控制 precision-recall trade-off，工程上比 in-batch hard negative + ANN 召回更可控。

LWGR: Lagrangian-Constrained Personalized World Knowledge for Generative Recommendation

Alibaba

LLM-based 生成式推荐通常用一套固定 prompt 抽取世界知识再拼接进 GR，问题是：prompt 不可个性化、知识与行为信号容易冲突。LWGR 引入两层 Lagrangian 约束——一层用 soft instruction 让 prompt 随用户兴趣多维分布动态生成 personalized 知识；另一层把 GR 的知识融合显式建模为带约束的优化问题，限制知识 token 对行为 token 的影响幅度。阿里团队在公开和工业数据集均验证 NDCG/Recall 提升。

INSIGHT把“LLM 世界知识何时听、听多少”从手工 prompt 工程升级成显式约束优化，是生成式推荐拉齐离线知识与在线行为的关键。对落地的启示是：不要让 LLM 输出无条件参与排序，而应在 fusion 阶段用 bounded constraint（Lagrangian 或 KL）控制知识漂移，否则在 head item 上行为信号会被语义噪声反向覆盖。

Lingyu Mu, Hao Deng, Haibo Xing, Kaican Lin, Zhitong Zhu, Yu Zhang, Xiaoyi Zeng, Zhengxiao Liu 等 10 人

03 3.75

SynGR: Unleashing the Potential of Cross-Modal Synergy for Generative Recommendation

BUAACAS

多模态生成式推荐现有方法多是 alignment-centric fusion（文本/图像对齐到同一空间再拼接），忽视了模态间“协同信息”——即任何单模态都无法单独表达的 emergent 物品属性。SynGR 显式建模 cross-modal 依赖，并通过约束抑制对优势模态（通常是文本 ID）的过度依赖，让 token-level 生成可以引用模态互补信号。多个公开 GR 基准上对比 TIGER 系列变体均有提升。

INSIGHTalignment-only 的多模态推荐其实只是模态拼接，真正决定上限的是“协同信息”——比如菜品图像 + 评论中“油烟味”这种单模态都无法独立暴露的属性。对短文本社区搜索的启示是：图文 token 在做生成式排序时不能让文本侧主导 attention，应该加 modality dropout 或显式 cross-modal regularization 暴露图像独有信号。

Wei Chen, Xingyu Guo, Shuang Li, Fuwei Zhang, Meng Yuan, Jing Fan, Zhao Zhang, Deqing Wang 等 9 人

ClusterRAG: Cluster-Based Collaborative Filtering for Personalized Retrieval-Augmented Generation

University of Arkansas

个性化 RAG 通常只读当前用户 profile，忽略相似用户的协同信号，且全量检索成本高。ClusterRAG 把每个用户表征成 profile document，用 density-based clustering 切成语义聚簇，检索时先做 cluster-level 相似度筛选再做 document-level fine ranking——两层结构既保留相似用户的协同信号又压缩了检索域。LaMP 基准上联合当前用户 profile + Top-K 相似用户 profile 在多任务上一致最优。

INSIGHTRAG 检索阶段把“相似用户”视为可复用知识，是把推荐系统经典 user-based CF 思想搬进 LLM pipeline 的一次干净落地。对社区搜索的启示是：query rewriting/personalization 不需要为每个用户单独维护行为 index，可以按 user cluster 维度预算 K 个 cluster centroid，线上仅检索用户所属 cluster 的 representative profiles，省了大量长尾用户的存储和检索成本。

Gibson Nkhata, Uttamasha Anjally Oyshi, Quan Mai, Susan Gauch

RecoAtlas: From Semantic Plausibility to Set-Level Utility in LLM Recommendation Agents

Criteo

LLM 推荐 Agent 越来越输出“一组商品 + 自然语言解释”的结构化推荐报告，但已有评测要么退化成 reranking 小候选，要么只判断 semantic plausibility。Criteo 推出 RecoAtlas（Agentic Tool-Level Assessment for Shopping），用真实交互数据学到 relevance/complementarity/diversity 三类 utility proxy，再配合 semantic coherence、explanation quality 单独打分；并设计可控工具环境（语义工具 / 行为对齐工具 / 故障工具）拆分“推理强 vs 信号好 vs 工具用得好”。

INSIGHT对评估推荐 Agent 的实用启示是：单独看 semantic plausibility 会被花言巧语欺骗，必须把 utility proxy 学在交互行为上才能 hold 住业务指标。社区搜索如果未来切到 LLM Agent 模式，建议借鉴它的“工具消融”做法——分别替换 retrieval/排序/解释工具，定位 Agent 收益到底来自推理还是来自后端信号。

Imad Aouali, Flavian Vasile, Otmane Sakhi, Alexandre Gilotte, Benjamin Heymann

SAGE: Scalable Automatic Gating Ensemble for Confident Negative Harvesting in Fraud Detection

Spotify

音乐流媒体作弊检测的核心难题是“正面边界样本”——超级粉丝、睡眠音乐场景的播放模式与协调作弊高度相似，传统 PU learning 会把这些样本当作疑似正例污染训练。SAGE 用 SimHash 分层抽样从未标注数据中抽样，再串联可插拔的统计 gate（Mahalanobis 距离 + k-NN 密度），通过 voting threshold 决策哪些样本是“高置信度负样本”，从而修复 representation bias。

INSIGHT把 PU learning 的“可信负样本挖掘”从单一阈值升级成多 gate ensemble，对推荐系统的迁移价值在于：CTR/CVR 模型也有未观测负样本（曝光未点击 ≠ 不喜欢）。可借鉴 SimHash 分层 + 多统计 gate 的范式，按 voting threshold 调整 negative 高质量样本的比例，直接喂入双塔/排序模型，比简单的 down-sampling 更稳健。

Sudheer Tubati, Amit Goyal

Query-Conditioned Graph Retrieval for Contextualized LLM Reasoning in Personalized Wearable Data

UUCI

可穿戴数据给 LLM 推理时面临 context 选择困境：太少推不动、全塞进上下文又冗余降质。WAG 把用户的可穿戴指标和个体信号建模成 personalized 知识图，针对 query 检索 subgraph：通过分层贝叶斯建模融合 global（人群/个体先验）和 local（短期偏离）关系，再用 query openness signal 控制 subgraph 大小。在多模态健康问答数据集上优于直接 prompt + 全量数据。

INSIGHT针对“per-user 知识图 + query-conditioned subgraph 检索”这套思路，推荐系统也能借鉴：长行为序列建模如果直接拼 token 会爆，可以把行为按层级抽象成 personalized graph（场景节点 / 兴趣节点 / 实体节点），线上根据 query openness 动态决定剪到哪一层，比固定窗口截断更能保留相关信号。

Zhenyu Lu, Mahyar Abbasian, Amir M. Rahmani

AllSERP: Exhaustive Per-Element Enrichment of the Versatile AdSERP Dataset

IIndependent

AllSERP 是对 AdSERP 商业意图搜索结果页面数据集的全元素增强版本：原始 AdSERP 提供 2776 trial、150Hz Gazepoint 眼动 + 鼠标 telemetry，但 bbox 只覆盖广告位（占可归因点击 15.5%）。AllSERP 用截图锚定 CV 补充像素级 organic 与 widget bbox，按 13 类 element type 做语义标注，X+Y 点击归因覆盖率提升到 91.7%，并给出 typed_gapfill 处理结果间隙。

INSIGHT对短文本社区搜索的研究价值在于：罕有公开数据集同时提供眼动 + 鼠标 + 像素级元素标注，可以用来研究 “SERP 元素曝光—注视—点击”这条全链路漏斗。建议作为离线 SERP 元素布局/卡片设计 A/B 的 prior 数据，例如校准 attention bias 对 CTR 的影响、训练 position-aware CTR 校准模型。

A Reproducibility Analysis of PO4ISR: Diagnosing and Mitigating Semantic Drift in LLM-Based Session Recommendation

IIIT BHU

PO4ISR 等 reasoning-based LLM 在 session-based 推荐上刷新了 benchmark，但跨语义域的可复现性未被验证。该工作复现 PO4ISR 并指出关键失效：标准 reasoning prompt 在长 session 上出现严重 contextual drift，在 Games、Bundle 等语义复杂域上性能显著退化。作者提出 PO4ISR++，加入 reflexive prompting 与 consistent rank detection 做动态自适应，在 ML-1M / Games / Bundle 三个数据集上把退化指标拉回。

INSIGHT这篇复现报告暴露了一个被忽视的现象：LLM-as-recommender 的“reasoning” 在长 session 上会因为 attention 漂移而压低 hit-rate。对线上建议：使用 LLM 做 session 推荐时不要无限制拼接历史，要么周期性 self-reflect 重述偏好（reflexive prompting），要么用 rank consistency check 做兜底，避免“推理越多越偏”。

Aditya Tiwari, Konduri Naga Lakshmi Rekha, Rajesh Kumar Mundotiya

Towards FairRAG: Preventing Representational Harm in Retrieval-Augmented Generation by Enforcing Fair Exposure at Retrieval Time

IIndependent

RAG pipeline 的多组件易在检索阶段引入偏差。论文基于 TREC 2022 Fair Ranking 数据集（Wikipedia 文章带 protected/non-protected 标注），对比四种排序：Standard、Stochastic、Forced-Exposure、Representative Stochastic，从 exposure bias 和 utility 双维度评估 LLM 引用情况。结果显示 Representative Stochastic 在保留 utility 的同时取得统计显著的 near-parity exposure。

INSIGHT把“Fair Exposure 在 retrieval 阶段就强加”是比下游 rerank 重排更稳定的路径。对社区搜索的启示是：UGC 内容里冷门/新作者/小众 query 极易被 RAG/LLM 排序漏掉，可以在 retrieval 侧引入 representative stochastic 采样（按 protected 属性分层加权采样），既能保留主路径相关性，又能给长尾作者稳定曝光配额，比 post-hoc rerank 更难被规避。

Riddhi Tikoo
