CopT: Contrastive On-Policy Thinking with Continuous Spaces for General and Agentic Reasoning

CopT 把传统 think-then-answer 的 CoT 流程倒过来：先让模型直接产出 draft answer，再把这个草稿作为条件输入，让模型在 on-policy 阶段对其进行反思、纠错。为了判断 draft 是否可信，作者把连续 embedding 作为推理期 contrastive verifier — 对同一段 token，分别以离散 token 输入和连续 embedding 输入算 likelihood，序列级的差值给出置信度。无需额外验证器即可避免 performative reasoning 带来的多余 token 成本，论文报告 token 用量大幅降低且 agentic reasoning 任务的准确率不下降。

KEY INSIGHT · 对业务意味着什么对搜索/推荐 agent 直接可借鉴：把昂贵的多步 reasoning 改成 draft → 自检 → 修正，模型自己决定哪些 query 不需要展开复杂规划。线上典型 query 短 + 高 QPS 场景里，先出 draft 召回排序结果、再对置信度低的 query 触发完整 agentic RAG，本质上是把 reasoning 预算按 query 难度分配。连续 embedding contrastive verifier 的设计也提供了一个不依赖外部 reward model 的轻量自验证路径。

GoLongRL: Capability-Oriented Long Context Reinforcement Learning with Multitask Alignment

GoLongRL 提出 capability-oriented 的长上下文 RLVR 后训练方案，作者完全开源了 23K 训练样本、整套构造 pipeline 和训练代码。区别于以前一味堆复杂 retrieval path 的数据构造，论文按长上下文能力建立 taxonomy，覆盖 9 类任务（书籍、论文、多轮对话等），每类配一个原生评估指标。在相同 vanilla GRPO 设置下，仅替换数据集就在多个长上下文 benchmark 上拿到显著提升，并通过 multitask alignment 让能力可叠加而不互相抵消。

INSIGHT对做 agentic search 的团队意义在于打通了「数据 → RLVR → 能力评估」的开源闭路：以前自研长上下文 RL 最大成本不是算法而是高质量训练数据，现在可以直接拿来微调内部 search agent，再按自家任务能力分布补样本。多任务对齐的实证结论也很重要 — 与其训练一个通用长上下文 agent，不如把任务拆成正交能力分别训练。

Minxuan Lv, Tiehua Mei, Tanlong Du, Junmin Chen, Zhenpeng Su

Improving Retrieval-Augmented Generation without Taxonomy-based Error Categorization

ColumbiaCornell

目前 agentic RAG 普遍依赖 critic agent 把错误分到细粒度类别 (factual / hallucination / coverage…) 后再对应修复策略，但作者实证发现细粒度 taxonomy 既难维护又会把 critic 误分类的噪声放大。论文提出 RePAIR，一种 response-action learning 范式，跳过显式错误分类，直接学习「flawed RAG 输出 → 纠错 action plan」的端到端映射。在多个 RAG benchmark 上 RePAIR 稳定优于带 critic taxonomy 的 baseline，并明显减少 critic 误分类引起的级联错误。

INSIGHT社区搜索的 agentic RAG 链路上，常见做法是把答案不准切成几十种细粒度类别再写不同 prompt 修复，工程负担和噪声都很大。RePAIR 的启示是：与其依赖 critic 把错误标对，不如让模型直接学到「这种 output 该做哪种 action」，对应到生产就是把人工写的 reflection prompt 改成端到端学到的纠错策略。配合内部 case 库做 SFT 即可上线，迭代成本远低于持续维护错误 taxonomy。

Gongbo Zhang, Yifan Peng, Chunhua Weng

M3DocDep: Multi-modal, Multi-page, Multi-document Dependency Chunking with Large Vision-Language Models

Korea University

针对工业长文档 RAG 里的切块问题，M3DocDep 用 LVLM 先恢复 block 之间的父子依赖、再沿依赖树切 chunk。pipeline 包含 SharedDet 做 DP+OCR 预处理、boundary-aware SoftROI pooling 抽多模态 block 表征、biaffine head 打父子边分、最小生成树解码出合法依赖树，最后基于依赖树切出带 section path 与 page range 的 chunk。在 shared-block 评估协议下，M3DocDep 的分块质量和下游 RAG 答案准确率均显著超过传统 text-chunker 与 LVLM 层次解析 baseline。

INSIGHT对处理 UGC 长帖、图文混排笔记的搜索/问答系统直接可借鉴：传统 RAG chunker 看不到帖子结构（章节、引用、图表 caption），切出来的 chunk 要么割裂上下文要么冗余重复。M3DocDep 把切块重新定义为图结构恢复，用 biaffine + MST 保证 chunk 边界跨页 / 跨模态都合法，相当于在 retrieval 层就把语义完整性提前保证。在生产里可以把 LVLM block 表征蒸馏到轻量模型来控成本。

Joongmin Shin, Jeongbae Park, Jaehyung Seo, Heuiseok Lim

OpenComputer: Verifiable Software Worlds for Computer-Use Agents

Yale

OpenComputer 用四个组件构造可验证的计算机操作 agent 训练/评测环境：app-specific 状态 verifier 暴露真实应用的结构化检查端点；self-evolving verification layer 用执行反馈持续迭代 verifier；task-generation pipeline 自动合成 machine-checkable 桌面任务；trajectory + 部分奖励的评估 harness。当前覆盖 33 个桌面应用、1000 个任务（浏览器、Office、IDE、文件管理、通讯等）。实验显示其硬编码 verifier 与人类判分的对齐显著好于 LLM-as-judge，前沿模型在 1000 个任务上的成功率与 verifier 颗粒度强相关。

INSIGHT想用 RL 训练 agent 调用内部 search/推荐工具的团队最大瓶颈是 reward — LLM-as-judge 在细粒度状态判断上不稳。OpenComputer 给出的范式是「应用级状态 verifier + self-evolving 校准」，对应到内部场景就是把每个搜索/推荐工具的合法状态、副作用挑出来写 deterministic checker，再用执行轨迹反馈持续修。短期还可以借用其 task-generation pipeline 反向生成训练样本。

Jinbiao Wei, Qianran Ma, Yilun Zhao, Xiao Zhou, Kangqi Ni

Time to REFLECT: Can We Trust LLM Judges for Evidence-based Research Agents?

YaleIBM

REFLECT 是面向 deep research agent 的 LLM-as-judge meta-evaluation benchmark。作者认为以往评估方法依赖粗粒度的人偏好一致性或只测 instruction-following，没法判断 LLM judge 在 evidence-grounded 长 trajectory 上是否可靠。REFLECT 在 controlled intervention 协议下，对原始 agent trajectory 中的证据使用、推理链、事实陈述做细粒度干预，再观察 judge 是否能稳定识别这些差异。结果表明大量 LLM judge 对看似合理但证据错误的 trajectory 几乎无法区分，给依赖 judge 做 RL reward 的 deep research 工作敲响警钟。

INSIGHT搜索/推荐里越来越多团队想用 LLM-as-judge 替代离线人评做答案质量 / 证据使用率的批量验收。REFLECT 提醒：在引入 LLM judge 上线之前必须先 controlled intervention 测它对证据替换 / 推理跳步 / 数字篡改是否敏感，否则得到的离线指标会与人评严重背离。可借鉴的工程做法是在自家评测集上注入若干受控扰动构造判官稳健性测试。

AutoResearchClaw: Self-Reinforcing Autonomous Research with Human-AI Collaboration

AutoResearchClaw 把自动科研 agent 从线性 pipeline 升级为带跨 run 进化的多 agent 系统，包含五个机制：(1) 假设生成与结果分析用 structured multi-agent debate；(2) self-healing executor 配 Pivot/Refine 决策环，把失败变成下一步信息；(3) verifiable result reporting 防止编造数字和幻觉引用；(4) 7 种粒度的 human-in-the-loop 介入模式，从全自治到 step-by-step 监管；(5) cross-run evolution 把过往错误固化成下一次的 safeguard。在 ARC-Bench 等 autonomous research benchmark 上显著优于单 agent baseline。

INSIGHT对线上 agentic search 来说最具借鉴的是 self-healing executor + cross-run evolution 这两块：把每一次执行失败（如调用超时、工具返回空、JSON 解析错）写成 Pivot/Refine 决策模板，并跨 session 累积成 safeguard 列表，逐步把容易翻车的 case 提前拦截。verifiable result reporting 也可以直接搬到引用类回答里抑制数字幻觉。

Jiaqi Liu, Shi Qiu, Mairui Li, Bingzhou Li, Haonian Ji

MMoA: An AI-Agent framework with recurrence for Memoried Mixure-of-Agent

MMoA 在传统 Mixture-of-Agents 之上引入 LSTM-based gating 做记忆化 router：router 同时看当前输入和历史路由决策来动态调节各 agent 的贡献权重。区别于固定 router 难以跨层捕获时序依赖，recurrent gate 让上层聚合可以基于下层的路由历史决定要不要继续激活某个 agent。在 AlpacaEval 2.0、MT-Bench、Arena-Hard 上 MMoA 与全激活 MoA 持平，但平均激活 agent 数显著下降 — AlpacaEval 2.0 上 win rate 58.0% 与 baseline 接近，FLOPs 节省明显。

INSIGHT多 agent 联调最大的成本是每层都把所有 agent 都跑一遍。MMoA 的 recurrent router 等价于把哪个 agent 这次要不要被激活建模成时序问题，对搜索/推荐里召回链 + 多种 ranker + 重写器的级联场景很合身：每条 query 只激活历史路由暗示真正需要的子模块，节省调用次数同时保持质量。LSTM gating 本身实现简单，可以挂到现有 routing 框架后端。

Mastering Agentic Techniques: AI Agent Evaluation

NVIDIA

NVIDIA 发布的 agent 评估实践指南，强调从静态模型 benchmark 转向 trajectory-based 动态评估。核心五个维度：(1) Task Success Rate，把任务定义为 intent + constraints 并在 normal / degraded tools / ambiguous instruction 等 scenario 下分别测；(2) 全轨迹分析：记录计划、子目标、所有工具调用与中间推理；(3) 工具使用为主要信号 — tool selection 的 precision/recall、schema 合规、API 幻觉、慢工具滥用；(4) 推理质量与效率，含 token / 工具调用预算（例如 95% 任务在 N token 内）；(5) 自研、透明、与原型阶段集成。配套开源 NVIDIA NeMo Agent Toolkit。

INSIGHT落地 agentic search 时常见误区是沿用旧式离线 IR 指标只看最终答案对错。NVIDIA 给出的 trajectory + 预算两层评估框架可以直接照抄：把工具调用 schema 合规率、单 query 工具次数中位数、tool selection precision/recall 当成与 nDCG / CTR 并列的核心指标。它对 agent 系统稳态的指示性比终态准确率更早 — 工具调用次数飘升通常是 reasoning 退化的领先信号。

Agentic GraphRAG: Navigating Unstructured Financial Data with Collaborative AI

ETH Zurich

面向商业登记数据（结构化字段 + 大量非结构化法律文本）的 multi-hop / 实体 / 时序检索场景，作者构造 Neo4j 知识图谱：(i) 从可信结构化字段 deterministic ingest 强节点；(ii) LLM 从非结构化公告中抽取弱节点；(iii) deterministic identity resolution 与去重。其上的 analytical agent 整合 zero-shot intent routing、bounded reflection loop、secure tool-mediated graph access 与 state-aware response synthesis，配 human-in-the-loop dashboard 同时暴露证据与执行轨迹，相比纯向量检索在多跳、时序、实体类问题上效果显著更优。

INSIGHT社区 UGC 检索里同样存在结构化作者/标签 + 非结构化正文的混合数据，传统 vector-only retrieval 很难处理某用户提及的某产品在某时间段的评价这类多跳查询。该论文的工程组合可以借鉴：先用 deterministic 规则建强节点（用户 / 话题 / 产品），再让 LLM 抽弱节点（实体提及 / 立场），最后 agent 用 bounded reflection 调 graph 工具组合查询。bounded reflection loop 控住 agent 不会反思无限是落地关键。

Arthur Capozzi, Dirk Helbing
