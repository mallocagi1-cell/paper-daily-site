Why Gated DeltaNet Survives 4-Bit Quantization: NVFP4 W4A4 for the Recurrent Half of a Hybrid 27B LLM

研究混合大模型循环层能否安全量化，作者对 Qwen3.8-27B 的全部 496 个线性层应用 NVFP4 W4A4，并修复融合算子的全局缩放不一致。Minima 占用 17.5 GiB，预填充提速 14–19%；五项任务均值相对 BF16 下降 0.52 分，检索评估覆盖 64K 上下文。

SWE-Serve: Benchmarking Agentic Engineering For Production Inference Serving

SWE-Serve 用来自 SGLang 的 53 个真实工程任务评估推理服务修改，覆盖六类功能，采用 CPU 或单张 H100 的隐藏回归、端到端服务与性能门槛。11 个模型、31 种配置中最佳平均 pass@1 为 75%；19 个端到端任务的通过率从省略该检查时的 69.4% 降至 45.9%。

INSIGHT推理框架的质量验证必须覆盖模型加载、执行路径和公开 API，局部单测通过仍可能无法正确服务。社区搜索接入新模型或量化后端时，可沿用真实请求的端到端回放，联合检查输出、延迟与回归；代码生成工具的成功率不能直接替代生产验收，也不能推导搜索 nDCG 或 CTR 收益。

03 3.80

Telescopic Language Models

Telescopic Language Models 用随机截断前缀监督配合全容量锚定，使同一 Transformer 在任意深度都能预测下一 token，每步执行两次前向与反向。在 200M 参数、20B FineWeb-Edu token 的对照中，20 个层前缀均有效；相对固定出口方案，质量预算曲线面积降低 43–44%，单次训练 GPU 成本约降 12%。

INSIGHT弹性推理的关键在训练目标覆盖各个预算点，单纯允许提前退出不足以保证质量。UGC 搜索可探索按查询复杂度分配模型深度，在延迟预算内处理语义理解；应先复现质量与预算曲线，并用真实社区查询验证相关性。现有结果来自 200M 代理模型，尚不能直接推断大模型服务收益。

AutoLoCo: Communication Efficient Distributed LLM Training via Adaptive Synchronization

AutoLoCo 面向跨数据中心预训练的同步通信瓶颈，依据标量训练统计动态调整本地更新步数，并用累积内层学习率校正外层动量及学习率。通信受限实验中，它相对 DiLoCo 将通信频率降低 27%，同时维持训练表现；核心区别是同步间隔随训练阶段变化，而非全程固定。

INSIGHT减少同步不能只延长本地更新间隔，还要补偿外层优化器与更新尺度的变化。社区搜索团队跨集群训练语义模型时，可先测通信占比，再试验自适应间隔及外层校正，并对齐最终质量和训练耗时。27% 是通信频率降幅，不能当作端到端加速或线上 CTR 提升来使用。

05 3.55

Lower the Cost of Building and Running Visual AI Agents with NVIDIA VSS Blueprint 3.3

NVIDIA

NVIDIA VSS 3.3 的 Adaptive EVS 比较相邻帧视觉 token，过滤未变化区域并按事件批处理。在 RTX PRO 6000 Blackwell、Cosmos 3 Super FP8 上，告警上下文化延迟由 1021 ms 降至 844 ms，并发流由 13 路增至 19 路；60 分钟视频摘要使用的输入 token 减少 80%。

INSIGHT视觉推理成本可通过消除跨帧冗余和跳过无事件片段降低，收益取决于场景运动与阈值。社区视频内容理解及索引生成可借鉴这种预处理，先对真实 UGC 视频测试漏检、字幕变化和吞吐，再配置批处理。它对少量帧产生长输出的任务收益有限，不能用展示数字推断所有搜索业务的提升。

Measured Joules, Learned Routes: Learning to Route for Energy-Efficient LLM Serving

University of AlbertaUCSDHHKUST(GZ)NYU

论文先离线测量九个候选模型的正确率、延迟、功率和 GPU 能量，再用 SFT 与 GRPO 训练查询路由器。在七项基准混合评估中，KL-GRPO 路由达到与 UniRoute 接近的准确率，平均回答能耗从 2192 J 降至 1692 J，约节省 23%；约 60% 准确率附近出现明显能耗跃迁。

INSIGHT参数量和 API 价格不能完整代表真实服务能耗，路由目标应使用同一硬件与请求条件下的测量值。社区 UGC 查询可以按难度选择模型，但评估必须加上路由器开销，并检查长尾查询的 nDCG、CTR 与尾延迟。论文回放离线测量日志，仍需在线并发测试确认收益能否保留。

Scheduling Recursive Reasoning in Looped Transformers

SUSTechCUHK-ShenzhenSShenzhen Loop Area Institute

TAPS 针对循环 Transformer 固定更新步长造成的计算浪费，将轨迹分解为持续进展和居中波动，并据此在线调节隐状态更新幅度。它能在无需重训时改善结构化推理准确率，进一步联合训练后，在匹配基线准确率的条件下获得最高 1.56 倍实际时间加速，提供循环深度之外的控制变量。

INSIGHT循环模型的计算预算可同时通过循环次数与更新尺度控制，持续同向更新和来回振荡应采用不同策略。社区搜索中的复杂 query 理解可作为小规模试验场景，但要把控制器计算计入总延迟，并区分事实知识与推理任务。该方案依赖循环架构，不能直接套用到现有普通 Transformer 服务。

Expanding AI Storage Access with NVIDIA cuObject and the NVIDIA SCADA Server SDK

NVIDIAGoogleMicrosoftIBM

NVIDIA 发布 cuObject 客户端和服务端库，并扩展 xio-sig 与 SCADA Server SDK，让 GPU 发起的存储请求通过 RDMA 访问文件与对象数据。IBM 已展示与 Storage Scale 的互操作原型，Storage-Next 有超过 40 家参与方；文章给出协议和接入路径，但没有量化吞吐或延迟对照实验。

INSIGHT语义搜索和推荐训练的数据搬运可从 CPU 转发改为 GPU 发起的 RDMA 路径，前提是存储端和网络支持一致协议。UGC 索引与训练管线可先定位 I/O 瓶颈，再测 CPU 占用、读延迟及总体吞吐。互操作演示不能替代生产基准，因此证据质量仅给 2 分，暂不承诺 nDCG 或 CTR 收益。

Full-Stack FP4: Stable LLM Pretraining with Quantized Projections, Optimizers, and Attention

Full-Stack FP4 将 NVFP4 扩展到投影、优化器状态、Root/Muon 计算和注意力，敏感子空间与 softmax 运算保留 BF16。3B 模型、64B token 预训练中，损失由 BF16 的 2.267 变为 2.286，差距 0.838%；单张 RTX 5090 的四块测量显示 Root 提速 2.50–2.83 倍，AdamW 峰值内存降低 37.9–42.5%。

INSIGHT低比特训练需要针对投影、优化器与注意力分别设计误差控制，不能对全链路统一替换精度。训练社区搜索语义模型时，可先隔离验证模块质量及显存收益，再决定是否组合使用。报告保留 7 月真实发表日期；四块微基准的加速不等于完整预训练提速，线上相关性仍需单独验证。

What Makes Recurrence Effective in Looped Language Models?

MBZUAICUHK

研究通过匹配物理深度、有效深度及训练预算，分析循环语言模型的知识与推理表现，并提出历史状态注入结合时间步条件。在有效深度 84 的分析中，该组合跨循环平均交互较两个对照高 18.6% 和 10.4%；额外循环有时改善推理，却会降低知识任务表现，说明统一增加计算预算并不稳妥。

INSIGHT部署循环模型时应按任务类型决定预算，保留非循环输出层，并考虑历史状态与时间步联合条件。社区搜索的实体知识判断和多步 query 理解应分别建立评估集，防止增加推理深度损伤知识准确率。18.6% 和 10.4% 是机制分析中的交互指标，并非搜索效果或服务吞吐增幅。

Xinlin Zhuang, Siyuan Wang, Imran Razzak, Weiyang Liu
