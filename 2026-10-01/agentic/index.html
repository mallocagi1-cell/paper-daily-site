Mnemon: Raw Records, Fast Judgments, Slow Thoughts

Mnemon 保留带日期的原始记录，让大模型规划检索、Jev 决策模型批量判断相关性，再用明确预算组装回答上下文。使用 gpt-4.1-mini 时，LoCoMo 准确率为 91.7%、LongMemEval-S 为 83.8%，每题上下文不到 4K tokens；历史从 100K 增至 10M tokens 时，每题成本仅增长 1.11 倍。

INSIGHT对社区用户的长期搜索助手，原始帖子和对话记录比写入时抽取的固定事实更容易追溯与纠错。可把慢速查询规划与快速候选判断分开，并保留时间与来源；先验证过时信息过滤和跨会话问题，再评估是否值得引入专门决策模型，避免直接套用问答基准结论。

Environment Steering: Using Data Flow Control to Improve Agent Utility and Safety

Environment Steering 把 Agent 和执行框架状态建模为数据库表，追踪记录级数据流，并在运行时用声明式策略检查越权。系统在违规时返回与策略、上下文相关的反馈，引导安全替代路径；在 AgentDyn 上达到 0% 攻击成功率，同时任务成功率超过无防护系统。

INSIGHT社区搜索 Agent 会读取不可信 UGC 并调用外部工具，可用执行环境控制数据流，而不只靠提示词拒绝注入。将搜索结果视为证据而非指令，限制跨来源敏感数据输出，并提供可恢复反馈；0% 是特定基准结果，不能推断真实业务攻击均能被阻止。

ARCagent: An Adaptive Retrieval Calibration Agent for Clinical Question Answering

ARCagent 面向存在相互矛盾指南的临床问答，构建 1,706 个片段、10 个来源的知识库和冲突登记表，并按查询焦点及冲突信号校准检索。系统报告 95.3% 的评测结果；关键词匹配相对模型裁判平均低估 10.1 个百分点，说明评价方式会明显改变结论。

INSIGHT社区帖子常包含互相冲突的经验与不同时间版本，检索不能只返回最相似的单一立场。可借鉴显式冲突登记与分歧展示，把观点、日期和来源作为可核查证据；其医学结果来自特定知识库与模型裁判，迁移时必须用社区人工相关性标注重新校准。

Tracing Agent Harness Behavior with NVIDIA NeMo Relay

NVIDIA

NeMo Relay 为 Hermes Agent 记录会话、模型与工具调用生命周期，并输出 ATOF、ATIF 和 OpenTelemetry 三种表示。文中已验证的简单任务记录 74 个事件、2 次模型调用、1 次工具调用和 0 个工具错误，输出 VALUE=42；这些是运行实例，并非总体性能提升实验。

INSIGHT复杂社区搜索可用父子调用关系定位重复搜索、截断读取和失败后的重试，先核查工具开始及结束事件，再判断调用是否真正完成。把正确性与 token、耗时一起观测，能发现答案正确但路径昂贵的流程；示例的具体计数不应被当作通用吞吐能力。

IIIT Sri LankaUUniversity of Sri Jayewardenepura

研究把自由文本映射为 SFIA 的技能及责任等级，比较词法检索、向量检索加重排、零样本模型、单 Agent RAG 与三 Agent 流程。框架包含 147 种技能和 7 个责任等级；相似度选等级的错误超过显式判断的两倍，三角色流程延迟翻倍却没有提高准确性。

Can Agents Design Libraries for Agents?

UW–MadisonMITSnorkel AIStanford

LibraryDesignBench 让一个 Agent 设计库，再让三个不同模型家族的使用者执行任务，以正确性与代码简洁度衡量设计质量。基准覆盖 242 个专家验证问题、15 项库设计任务和 4 种语言；11 项任务重现了生产库抽象，但使用者仍经常重新实现已有功能。

INSIGHT搜索工具库设计应通过实际调用轨迹验收，关注模型能否发现并复用接口，而不只看函数测试通过。可用统一参数、短示例和错误反馈降低重复实现；本文显示僵硬或难用的 API 会增加下游代码量，适合用来评估社区搜索 Agent 的工具封装。

EngiWorld: What Can Frontier Agents Deliver in Professional Engineering Environments?

TsinghuaZZhimanPeking University

EngiWorld 用最终与中间产物验证专业工程 Agent，覆盖 1,301 个专家任务、6 个工程领域和 26 个软件平台，并同时支持 GUI 与 CLI。七个前沿模型中最强 EngiScore 仅为 44.3，多软件任务只有 3.6% 成功，说明完成声明远不足以证明真实交付。

INSIGHT社区搜索 Agent 的验收同样应检查可验证的产物：引用是否支持结论、任务约束是否满足、报告是否完整。可把每轮工具调用和最终证据表纳入评分，而非仅让模型判断自己已完成；工程任务的低成功率不能直接等同于社区检索表现。

Add Runtime Controls to AI Agents with NVIDIA OpenShell

NVIDIA

OpenShell 0.1.0 通过 Gateway、Supervisor 与 Sandbox 三个组件，在 Agent 工作负载外实施权限、凭据与网络控制。文章演示同一 GitHub API 的读请求允许、POST 写请求拦截，并说明 HTTP、GraphQL 和 MCP 检查；提供工程步骤，但没有搜索质量或线上 A/B 的量化结果。

INSIGHT社区检索助手可获得只读文档和查询接口，而让真实凭据留在隔离环境之外；运行时策略应明确区分读取与写入操作。该内容作为工具执行治理实践收录，证据评分较低；若业务只需检索，先验证读权限及审计事件，再考虑扩大工具能力。
