Layer-wise Token Compression for Efficient Document Reranking

针对 Transformer cross-encoder 重排序器推理成本高的问题，提出 Layer-wise Token Compression (LTC)，把自适应 token 池化放到中间层而非输入层。在 MS MARCO passage/document 排序上，中间层压缩在保持排序质量的同时把 QPS 最多提升 25%（passage）和 116%（document），并可直接扩展到 listwise LLM 重排，长上下文场景收益更大。

DIVE: Embedding Compression via Self-Limiting Gradient Updates

LLM 高维 embedding 给向量检索带来存储与算力压力。已有压缩适配器（Matryoshka-Adaptor、Search-Adaptor、SMEC）在标注稀缺时严重过拟合，效果反低于冻结基线。DIVE 用自限制 hinge 三元组损失（满足 margin 后梯度归零，限制对预训练空间的扰动）加 head-wise NT-Xent 多视图对比损失，在 6 个 BEIR 数据集、所有压缩比上均超过三个基线适配器，实现仅 14M 参数且开源。

INSIGHT核心思路是“少改动”：自限制损失避免小数据上破坏预训练 embedding 分布，多视图对比损失补偿三元组信号稀疏。对需要给召回向量降维、又缺乏大量领域标注的搜索场景有直接价值——14M 适配器可挂在现成 embedding 上，无需重训基座。

Dongfang Zhao

Beyond Semantic Similarity: A Two-Phase Non-Parametric Retrieval Workflow for Corporate Credit Underwriting

标准 RAG 按语义相似度检索，常召回话题相关但对决策无用的段落（作者称为 similarity-utility gap）。提出两阶段非参数检索：第一阶段用词法加稠密多语检索构建高召回候选池；第二阶段用自适应检索控制器按 query 意图与文档结构过滤，再用 LLM-as-a-Judge 按“分析有用性”而非语义接近度排序。在 800 多名信贷分析师的生产部署中，文档审阅时间从数小时降到约 3 分钟。

INSIGHT把“相关”与“有用”拆成两个阶段、用 LLM-as-Judge 做 utility 重排，是对纯向量相似度排序的有益补充，尤其适合长文档、决策导向的检索。全程本地部署满足数据合规要求，对企业内搜索与 RAG 落地有参考意义。

Linus Ng Junjia, Ezekiel Tee Kongquan, Kelvin Heng, Kenneth Zhu Ke, Zhao Jing Yuan

Efficient Table QA via TableGrid Navigation and Progressive Inference Prompting

表格问答需要精确的单元格检索与多步结构化推理。提出免训练的两套结构化提示：TableGrid Navigation (TGN) 用三模块循环迭代遍历行列定位证据并修正答案；Progressive Inference Prompting (PIP) 强制按 query 先识别列再渐进选行。在 17 个 LLM、6 个基线上评测，TableBench 上 TGN 比最强基线高 3.8 分，FeTaQa 上 PIP 超过 ReAct 与 CoT 达到 SOTA。

INSIGHT不微调、靠结构化提示约束模型“怎么在表里找证据”，并能作为蒸馏小模型的监督模板缩小与大模型的差距。对涉及结构化数据（表格、属性字段）的搜索与问答场景，提供了一种低成本、可验证检索路径的实现思路。

Amritansh Maurya, Navjot Singh, Mohammed Javed, Omar Moured

GraphRAG on Consumer Hardware: Benchmarking Local LLMs for Healthcare EHR Schema Retrieval

系统评测 GraphRAG 在消费级硬件（单张 8GB 显存 GPU、Ollama 部署）上做 EHR schema 检索的可行性，对比 Llama 3.1 8B、Mistral 7B、Qwen 2.5 7B、Phi-4-mini 3.8B。结果：Llama 3.1 构建的知识图谱实体最多（1172 个），Qwen 2.5 答案质量最高（3.3/5），Phi-4-mini 因结构化输出错误无法跑通；约 7B 以下模型难以稳定产出有效结构化输出。

INSIGHT关键发现是 local 检索在延迟与事实 grounding 上持续优于 global 摘要、且幻觉更低，indexing 质量与答案质量在不同模型间是解耦的。对在隐私敏感、资源受限环境落地 GraphRAG 的团队，给出了模型选型（不低于 7B）与检索模式（优先 local）的实证依据。

Peter Fernandes, Ria Kanjilal

Legal Retrieval for Public Defenders

与新泽西公设辩护人办公室合作，构建 NJ BriefBank——检索相关上诉状以辅助法律检索与写作。发现现有检索 benchmark 无法迁移到真实公设辩护检索，而加入领域知识能提升质量：包括用法律推理做 query 扩展、领域专用数据、以及人工筛选的合成样本。同时发布了贴近真实辩护人查询的 taxonomy 与人工标注评测集，与专家标注的私有集高度相关。

INSIGHT现成检索 benchmark 与真实业务存在显著分布差异；query 扩展（注入推理）加领域合成数据是弥合差距的实用手段。对垂直领域搜索冷启动、缺乏标注时如何评测与提升检索，提供了可操作的方法论参考。

SG-LegalCite: A Principle-Augmented Benchmark for Legal Citation Retrieval in Singapore Law

普通法系的法律引用不仅看事实相似，还取决于先例确立的“法律原则”，而现有 benchmark 多以案件事实或引用上下文为输入，原则常缺失或被上下文淹没，导致检索到事实相似但法理无关的先例。提出 principle-augmented 检索范式：用“案件事实加显式法律原则”作为 query 排序被引案例，并构建 SG-LegalCite（8523 份新加坡最高法院判决、100,890 对 case-principle），11 个基线验证显式原则提供强判别信号。

INSIGHT把隐含的“为何相关”显式化进 query，是提升检索精度的通用思路，对社区搜索同样适用：若能把用户意图或原因结构化进 query 表示，可减少“话题相似但无关”的召回。该范式与构建带原因标注检索数据集的做法值得借鉴。

Shannon Lee Yueh Ern, Kaidong Feng, Yingpeng Du, Chloe Lee En Jia, Zhu Sun

Stage-Audit: Auditable Source-Frontier Discovery for Cross-Wiki Tables

LLM 整理的表格可能“看似有出处”实则包含来自参数记忆、事后硬贴引用的无支撑行。Stage-Audit 针对 Seed2Frontier（从种子页发现互补维基页面以拼表）任务，用 curator-auditor 写权限分离、行级 source-citation 门控、以及覆盖 key/schema/角色/基数/范围的 12 项审计 taxonomy。在 51 实例、15 个领域的评测集上，source-frontier 精度从 0.356 提升到 0.505（相对 +42%），F1 从 0.334 到 0.451（+35%）。

INSIGHT把“生成”与“审计”角色分离、对每一行强制可追溯的来源门控，是对抗 LLM 检索与整理结果幻觉的有效机制。对需要保证召回结果可溯源、可审计的搜索与知识构建场景（如带引用的 RAG），其行级 grounding 校验思路可迁移。

Chen Shen
