OneBar: An End-to-End Content-Grounded Generative Query Recommendation Framework for E-Commerce Video Feeds

针对短视频播放器下方“可点击搜索入口”的 query 推荐场景：传统 query 推荐受在线延迟约束、目标不对齐，已有生成式方案又易被 content 侧噪声元数据和偏好漂移干扰。OneBar 提出端到端实时生成式 query 推荐框架，三个核心模块：(1) 协同-多模态意图锚定，把多模态视频理解与行为派生的协同 anchor 融合；(2) 带 prompt 压缩机制的统一端到端架构，支撑在线低延迟服务；(3) 渐进式偏好学习，将层级行为偏好内化进生成模型。快手电商视频流线上 A/B：query 曝光 +16.91%、query 点击 +18.68%、query CTR +0.19%、引导订单 +20.36%、GMV +21.67%。

KEY INSIGHT · 对业务意味着什么把 query 推荐直接做成“内容到意图到 query”的端到端生成，比“先召回候选 query 再排序”的级联范式更能抓住视频内容诱发的即时搜索意图。多模态视频理解 anchor 与行为协同信号的融合，是压住生成式 query 推荐 content 侧噪声的关键；prompt 压缩则是把生成模型塞进在线延迟预算的主要手段。社区搜索的“猜你想搜/搜索发现”位可借鉴：用内容理解直接生成候选 query，配合渐进式偏好内化降低对曝光-点击回流数据的依赖。

HoloRec: Holistic Encoding and Interleaved Reasoning for Generative Recommendation

CASJD

生成式推荐把推荐建模为序列生成，缓解了级联架构的目标割裂，但现有方法语义表征扁平、缺乏多步推理所需的层级结构，且外部构造的 CoT 依赖昂贵标注、与生成目标脱节。HoloRec 提出内生式 CoT 机制：用多粒度嵌套残差量化构造层级语义编码矩阵，由整体重建损失优化；支持两种推理模式——非思考模式做轻量多粒度监督对齐快速预测，思考模式用交错推理在生成过程中产出 CoT 步骤。在 Amazon Beauty/Instruments 上相比 TIGER：Beauty Hit@5 0.0451 对 0.0395（+14.2%）、NDCG@5 +17.2%，稀疏场景增益最显著。

INSIGHT内生 CoT 把推理步骤直接编进生成轨迹，省掉了 TIGER 类 Semantic ID 方案外挂 CoT 标注的成本，是生成式推荐做可推理的一条更省的路径。多粒度嵌套残差量化让 Semantic ID 带上层级结构，配合整体重建损失，缓解扁平 token 难以支撑多步推理的问题。消融显示多粒度监督拓宽语义覆盖、交错推理锐化 top 结果，二者在长尾/稀疏物品上协同收益最大——对 UGC 长尾内容多的社区推荐尤其有参考价值。

Shuqi Zhao, Jingsong Su, Xiang Liu, Xingzhi Yao, Yiming Qiu, Huimu Wang, Liang Lin, Pengbo Mo 等 12 人

Combining Retrieval-Augmented Text Generation with LLMs for Reading Content Recommendations

该工作设计并评估了一套用 LLM + RAG 生成个性化阅读内容的系统，含 Input、RAG、Generation、Judging 四个模块，用户可同时指定问题与目标阅读难度。RAG 从互联网检索相关信息，为三个 LLM（Meta LLaMA 4 Scout、LLaMA 3.1 8B Instant、Google Gemma2 9B）的生成提供事实 grounding；用 CoT、zero-shot、few-shot 三种 prompting 生成材料，并以 LLM-as-a-Judge 自动评估答案质量与可读性对齐度。实验显示 RAG 在所有模型与 prompting 策略下都一致提升相关性与可读性匹配。

INSIGHT这是把检索增强、难度可控生成与 LLM 自动评判串起来的内容生成范式，工程上用现成开源 LLM 即可搭建。对内容平台的启示是：RAG 不只服务问答，也能做按用户画像与可读性需求定制生成内容；LLM-as-a-Judge 提供了一条无需大量人工标注、自动校验生成质量与目标难度对齐的评估路径，适合内容推荐的离线质检环节。
