Beyond Positive Signals: Unlocking Implicit Negative Behaviors for Enhanced Sequential User Modeling

现代 CTR 预估普遍只用正向行为（点击、购买、完播）构建用户行为序列，而数量更庞大的隐式负反馈（划过、跳过、低完播）被忽视。论文提出按时间戳把正负行为混合成单一序列，并设计 Target-Aware Polarity Fusion (TAPF) 门控：对每个候选做 target-aware 交互、内容自适应 sigmoid 门控，再按极性符号做带符号残差融合，把正向 token 推向目标、负向 token 推离目标。在 KuaiRec、KuaiRand、腾讯广告 TAAC-2025 三个数据集、DIN/Transformer/OneTrans/HyFormer/MixFormer 五种架构上，相对 AUC 提升 +1.9%~+9.6%，且额外计算开销可忽略。

PIANO: Personalized Reranking via Information Aggregation Node for Music Search Optimization

NetEase📖 深度解读 · 7 分钟 →

音乐搜索重排需同时对齐用户当前 query 与长期偏好，并联合优化 CTR 与 CVR，但已有序列方法只用 item 交互历史、无法用历史 query 判断哪些偏好匹配当前意图，且多数 listwise 模型只优化单目标。论文提出 PIANO：Query-Driven Interest Refiner (QDIR) 用当前 query 对历史 query 序列做 cross-attention 筛选相关历史交互、融合长短期兴趣；Information Aggregation Node (IAN) 用一个 [CLS] 式可学习 token 在列表级聚合并预测 CTR/CVR，配合 list-level + item-level 联合损失。工业音乐数据集 NDCG@5 0.8606 优于 PEAR 0.8586；网易云音乐线上 4 周 A/B，CTR 相对 +0.62%、CVR 相对 +4.45%（p<0.05）。

INSIGHT两个设计值得借鉴：一是用历史 query 序列而非仅 item 序列刻画“搜索意图下的长期偏好”，解决了序列推荐在搜索场景下意图错配的问题；二是用列表级 [CLS] token 把多目标（点击/转化）的权衡放到整列粒度而非单 item 粒度优化（消融显示去掉 QDIR 掉 ~1.9% NDCG@5、去掉 IAN 掉 ~1.2%）。对社区搜索而言，QDIR 的“query 感知历史筛选”可直接迁移到 UGC 搜索重排，把用户历史搜索词作为意图锚点对齐当前 query，同时用列表级损失协调相关性与点击/互动多目标。

Weisheng Li, Chuqiao Huang, Pengcheng Li, Zhengchao Peng, Qiang Xiao, Zhongqian Xie, Qiang Huang 等 8 人

OneRank: Unified Transformer-Native Ranking Architecture for Multi-Task Recommendation

RUCNTUShopee

工业排序已从 DNN 转向 Transformer，但仍把 Transformer 当作任务无关编码器、与多任务预测头解耦，导致信息瓶颈、梯度干扰（跷跷板）和“动态注意力表征→静态前馈预测”的数据流割裂。论文提出 OneRank：为每个候选配 K 个任务私有 token，用结构化注意力掩码实现任务条件信息选择、候选感知上下文化与可控跨任务交互（前向传递知识）；反向用 cross-task gradient detachment 只放行对角梯度、阻断跨任务梯度（隔离优化）；并用动态内积匹配打分替代静态 MLP。Shopee 数据集（3300 万用户、266 亿曝光）上 C-AUC 0.7910 优于 PLE 0.7770，参数更少（4.9M vs 6.1M）；线上 7 天 A/B，GMV/UU +1.01%、付费 GMV/UU +1.17%、坏 query 率 -2.29%。

INSIGHT关键思想是把多任务的“前向知识共享”与“反向梯度隔离”解耦——跨任务注意力当成只读记忆做知识迁移，梯度上做对角放行规避跷跷板，比 MMoE/PLE 用专家网络硬分容量更优雅。动态匹配打分让同一 user-item 在不同 session 拿到不同分数，实现上下文个性化。对搜推平台的启示：多任务排序未必要 encoder+多塔，可在一个序列模型内用注意力掩码同时完成表征与多目标预测，工程上还更省参数；其“前向共享/反向隔离”范式可直接借鉴到点击/互动/转化多目标的统一排序模型。

Jiakai Tang, Sunhao Dai, Kun Wang, Zhiluohan Guo, Yu Zhao, Cong Fu, Kangle Wu, Yabo Ni, Anxiang Zeng 等 11 人

Harmonizing Semantic and Collaborative in LLMs: Reasoning-based Embedding Generator for Sequential Recommendation

序列推荐受长尾问题困扰，LLM 被用作 item embedding 生成器来补充语义，但现有方法没用上 LLM 的内在推理能力，且只靠监督微调隐式注入协同信号、缺乏显式对齐。论文提出 ReaEmb：Latent Reasoning-enhanced Contrastive Learning (LRCL) 用两遍前向激发 LLM 的隐式推理来增强对比学习；Collaborative Reward Reinforcement Learning (CRRL) 用定制的强化学习奖励把协同信号显式注入 LLM，把“语义理解”与“协同过滤”在 LLM 内部统一为推理增强的 embedding 生成器。

INSIGHT思路是把 LLM-as-embedding-generator 从“只取语义”升级为“语义+推理+协同”三合一，用 RL reward 而非纯 SFT 来对齐协同信号，是 LLM4Rec 在表征层的一个有价值方向。对长尾 item 多的社区内容推荐，LLM 推理增强的 embedding 有助于冷启动与语义召回；但两阶段（对比学习 + RL）训练成本较高，落地需权衡离线指标收益与推理/训练开销，更适合 item 语义丰富、长尾严重的场景。

Qidong Liu, Mingyao Huang, Moranxin Wang, Wenxuan Yang, Haiping Zhu

One Sequential Recommendation Model Pretrained from Synthetic Priors Predicts Multiple Datasets

KAIST

现有序列推荐模型依赖逐数据集训练、换域要从头重训。论文提出 SRPFN，把 Prior-data Fitted Network 引入序列推荐：离线在 2560 万条来自合成先验（覆盖多样 item-to-item 转移模式）的序列上预训练，学会输出“下一个 item 的后验预测分布”；推理时以目标域的 item-item 转移示例作为 support set 做 in-context 适配，单次前向预测下一个 item、无需任何梯度更新。五个 benchmark、10 个基线上几乎都取得最优或次优，且计算上显著更高效。

INSIGHT这是把 TabPFN 式“预训练即贝叶斯推断、推理靠 in-context”范式搬到推荐的尝试——用合成先验替代真实数据预训练，换域时零样本、免重训。对需要快速扩展到新品类/新场景或冷启动的推荐系统，提供了“一次预训练、多域复用”的思路；局限在于合成先验能否覆盖真实长尾转移模式、以及 support set 选择策略对效果影响较大，工业落地前需在自有数据上验证零样本迁移的稳健性。

Woosung Kang, Jiwon Jeong, Jonghyeok Shin, Jeongwhan Choi, Noseong Park

How Much Do Reviews Really Contribute? A Study on Text-Enriched Matrix Factorization for Recommendations

把评论文本融入推荐以补充协同信号很流行，但在强协同基线下文本到底贡献多少仍存疑。论文在统一的矩阵分解骨干上系统对比三种文本增强策略：可学习门控自适应平衡协同与文本信号、聚合主题画像、全文 embedding 表征，并引入 cross-attention 强调最有信息量的维度。结论是：自适应融合机制虽提升了表征灵活性，但在典型评分预测设置下文本信号的边际贡献有限，协同信息仍主导效果。

INSIGHT这是一篇“反直觉负结果”研究，提醒别高估评论文本的增量价值——当协同基线足够强时，堆文本特征收益有限，投入产出比需重新评估。对社区/UGC 推荐有现实意义：上线复杂的文本-协同融合前，先确认协同基线是否已吃掉大部分信号；若要用文本，可学习门控比硬拼接更稳健，但别期待它单独翻盘。

Eduardo Ferreira da Silva, Mayki dos Santos Oliveira, Joel Machado Pires, Denis Dantas Boaventura 等 5 人

Guiding Federated Graph Recommendation with LLM-encoded knowledge

图推荐能很好地抽取协同信号，联邦学习可在保护隐私下训练，但跨非 IID 客户端聚合图表征困难——本地学的结构 embedding 易错位、朴素平均无法捕捉跨端关系，且现有联邦图方法只做结构聚合、忽略 LLM 提供的全局语义。论文提出用 LLM 编码的知识引导联邦图推荐：客户端在本地学结构表征的同时，用冻结 LLM 把典型交互模式总结成紧凑语义向量，中心服务器据此做语义对齐的聚合。

INSIGHT把“冻结 LLM 提取的语义画像”作为联邦聚合的对齐锚点，是缓解非 IID 客户端表征错位的新思路，兼顾隐私与跨端知识共享。对有数据合规/隐私约束、需多端联合建模的推荐场景（跨 App、跨地域）有参考价值；但联邦 + 图 + LLM 三者叠加的工程复杂度和通信开销较高，更适合隐私要求强、可接受较重架构的场景。

Thi Minh Chau Nguyen, Hien Trang Nguyen, Duc Anh Nguyen, Van Ho-Long, Thanh Trung Huynh, Zhao Ren

08 3.05

Leveraging Code-Mixed Product Metadata and User Feedback for Personalized Recommendation on Daraz Bangladesh

孟加拉电商评论混用孟加拉文、英文与 Banglish（拉丁字母拼写的孟加拉语），但混合语码评论对推荐的影响鲜有研究。论文首次在 Daraz Bangladesh 评论上做基准测试，用 per-user 时间留一协议评估六类模型，并针对极端长尾稀疏（59.3% 用户只有 1 次交互）做五档 k-core 阈值消融。结果显示 Item-based CF 在各设置下稳定，隐式矩阵分解随密度下降急剧退化，显式矩阵分解在高阈值下反而提升。

INSIGHT对多语言/混合语码 UGC 平台有现实参考：在极稀疏长尾下，基于 item 的协同过滤比矩阵分解更稳健，数据密度（k-core 阈值）的选择会显著改变模型排名结论。提醒从业者在低资源、多语种社区场景做离线评测时必须报告数据稀疏度配置，否则模型优劣结论不可比；混合语码本身也需要专门的文本归一化处理。

KM Fahim A Bari, Muhammad Abdullah Adnan, Nafis Sadeq
