Retrieval-as-a-Service: A System-Oriented Analysis of Industrial Retrieval Pipelines in Web Systems

面向工业级 Web 服务中检索系统日益独立成层（Retrieval-as-a-Service, RaaS）的趋势，本文从系统而非算法视角综述工业检索流水线的架构设计与部署权衡。作者提出统一的 RaaS 多阶段流水线抽象，涵盖高效候选生成、基于 embedding 的语义召回与多阶段排序/重排，并系统分析延迟约束、可扩展性与资源限制如何反向塑造生产环境下的系统设计。

SCAR: Semantic Continuity-Aware Retrieval for Efficient Context Expansion in RAG

针对 RAG 中固定长度切块导致的"边界碎片化"（关键证据被切到相邻 chunk、召回率下降）问题，提出 SCAR 自适应检索策略：对每个命中 chunk，按 query-邻居相关性与结构连续性惩罚的权衡决定是否扩展相邻块；扩展阈值是相对于该 chunk 自身相关性的相对阈值，因而近似尺度不变、跨 embedding 模型无需重新标定。在 RFC/GDPR/10-K/并购协议四个语料（N=320 query，含 160 个边界碎片化 query）上，边界碎片化 query 召回率达 92.8%，平均仅用 7.84 个 chunk，比静态窗口减少 22.9% 的 token 开销。

INSIGHT相对阈值这一设计很巧妙——把"是否扩展上下文"的决策锚定到每个 chunk 自己的相关性分位，而非全局绝对阈值，从而换 embedding 模型时不用重新调参。对自建 RAG/检索的团队，这是一个低成本、可直接替换 parent-retrieval/静态窗口的召回扩展策略，在召回率与 token 成本之间给出更优的帕累托点。

Nathanaël Langlois

Entity Labels Are Not Entity Signals: A Framework for Observable Relevance in Document Re-Ranking

实体感知检索默认"语义相关的实体也是有用的排序信号"，本文证明该假设不成立并解释原因：与词项是真实观测不同，实体链接是不完美 linker 产生的假设——一个实体即便主题相关，若 linker 在相关/不相关文档上无差别触发就毫无判别力。作者形式化区分"概念实体相关性"(CER) 与"可观测实体相关性"(OER)，在四个数据集（含人工实体标注）上发现 CER 与 OER 几乎零一致 (κ≈0)，而不同 OER 操作化之间高度一致。

INSIGHT这对依赖知识图谱/实体标签做召回与排序的搜索系统是一记警钟：实体"主题相关"不等于"能区分相关与否"，盲目把实体当排序特征可能引入噪声。实践上应改用基于集合统计的可观测判别力（类似 IDF 思路衡量实体在相关/不相关文档间的分布差异）来筛选实体信号，而非只看语义相关性。

Utshab Kumar Ghosh, Shubham Chatterjee

RL-Index: Reinforcement Learning for Retrieval Index Reasoning

Adobe

当 query 与目标知识的关系需要隐式复杂推理（如依赖同一定理的数学题、需深度推理的代码）时，仅靠表层语义/词面匹配的检索会失败。已有方法多做 query 侧推理（如 query rewriting），带来在线延迟且未利用对语料本身做推理的机会。RL-Index 提出"索引侧推理"的 agentic indexing 框架：用强化学习训练，在建索引阶段为文档生成显式编码潜在 query-知识关系的 LLM rationale，把推理成本从在线 query 时转移到离线建索引时。

INSIGHT"把推理前移到索引侧"是很有工程价值的思路——在线检索延迟敏感，而离线建索引可以重计算。对社区搜索，可借鉴为帖子/文档预生成"可被检索的推理标注/扩展表述"，让需要推理才能匹配的 query 在召回阶段就命中，而不必每次在线改写 query。用 RL 按下游检索效果反馈优化索引增广，也提示索引内容本身可以是一个可学习的对象。

MAGE-RAG: Multigranular Adaptive Graph Evidence for Agentic Multimodal RAG in Long-Document QA

BBIT

长文档多模态问答需在长 PDF 中定位稀疏证据并融合文本、表格、图像、图表与复杂版式。现有 RAG 多用固定 Top-k 文本/页面检索：文本检索丢失视觉版式信息，页面级视觉检索又把大量无关区域塞给阅读器，形成证据覆盖、噪声与推理成本的静态权衡。MAGE-RAG 以页面检索为入口，离线构建含"页节点+元素节点"的证据图，编码包含、阅读顺序、版式邻接、章节层级与语义近邻关系；在线由 agent 自适应地做多粒度证据扩展。

INSIGHT它把"检索粒度"从固定 chunk/页升级为可按 query 在图上自适应游走的多粒度证据，兼顾覆盖与噪声控制。对需要处理图文混排 UGC（如带图帖子、长测评）的社区搜索，构建"页/块/元素"多层证据图、按 query 动态决定取哪一层证据，是平衡召回完整性与上下文成本的可借鉴范式。

Yilong Zuo, Xunkai Li, Jing Yuan, Qiangqiang Dai, Hongchao Qin, Ronghua Li

Understanding the Behaviors of Environment-aware Information Retrieval

当前 RAG 研究忽视了一个关键事实：不同检索器需要根本不同的 query 表述策略才能发挥最佳效果。本文首次系统分析 LLM 如何通过强化学习自适应地为不同检索器调整 query 表述，实证发现 RL 能有效教会 LLM 针对特定检索器特性定制 query，且不同检索器偏好的最优 query 风格差异显著（如描述式 vs 问题式），为一个检索器学到的策略对另一个往往失效；引入检索器特定的人类指导并扩大模型规模可进一步提升效果。

INSIGHT"没有放之四海皆准的最优 query 改写"——query 改写必须与下游检索器协同优化，这对多路召回/混合检索系统很重要：不能用同一套 query rewriting 同时服务 BM25、dense、ColBERT 等不同召回通道。实践上应针对每条召回链路分别学习/适配 query 表述策略，或在 query 理解层显式把"目标检索器"建模为条件变量。

Ruifeng Yuan, Chaohao Yuan, David Dai, Yu Rong, Hong Cheng, Hou Pong Chan, Chenghao Xiao

Beyond Chunks and Graphs: Retrieval-Augmented Generation through Triplet-Driven Thinking

AmazonEEmory

进阶 RAG 在效果与效率间存在权衡：多轮 RAG 推理强但 LLM 调用与 token 成本高，Graph RAG 则受困于昂贵且易错的图构建与检索冗余。T2RAG 提出一个不依赖图、只基于原子三元组(triplet)知识库的框架：用 LLM 把问题分解为带占位符的可检索三元组，再迭代地从三元组库检索证据来逐步求解占位符。在六个数据集上平均比 SOTA 的多轮 RAG 与 Graph RAG 方法最多高出约 11%。

INSIGHT用"带占位符的三元组"作为检索单元，把多跳问答拆成结构化、可迭代求解的子检索，既保留多跳推理能力，又避免 Graph RAG 的重图构建开销。对需要多跳/组合式问答的搜索场景，这是一条比 Graph RAG 更轻量的折中路线：知识库构建成本低、检索目标明确，适合工程上快速落地多跳检索。

Shengbo Gong, Xianfeng Tang, Qi He, Carl Yang, Wei Jin

LLM-Driven Usefulness Judgment for Web Search Evaluation

传统搜索评测主要依赖相关性标签，但"相关"无法刻画系统是否真正帮用户达成搜索目标，因此"有用性"(usefulness) 是更关键的评测维度。本文用 LLM 生成有用性标签，融合隐式与显式用户行为信号，并提出 TRUE（任务感知、基于评分细则的有用性评测）方法，通过迭代采样与推理建模复杂搜索行为。研究发现 LLM 借助完整搜索会话历史能生成中等质量的有用性标签。

INSIGHT把评测信号从"文档与 query 是否相关"升级为"文档是否帮用户完成任务"，更贴近 CTR/满意度等业务指标。对社区搜索，可用 LLM 结合会话上下文与行为信号自动生成有用性标注，缓解人工标注瓶颈，并作为排序模型训练/离线评测更贴近业务的标签来源；但论文也坦言当前只能达到"中等"质量，高 stakes 评测仍需谨慎。

Mouly Dewan, Jiqun Liu, Aditya Gautam, Chirag Shah

TechRAG: Evidence-Gated Multimodal Agentic RAG for Technical Literature Reasoning

Goodyear

面向专业领域文献推理，TechRAG 提出 agentic 多模态 RAG 框架：自主、证据门控的流水线先对 query 意图分类，分别生成文本与视觉 query 改写，做 FAISS+BM25 混合文本检索并经 cross-encoder 重排，再沿 Neo4j 知识图谱做图引导的 chunk 扩展，并用 ColSmol late-interaction embedding 配合 MUVERA 定维编码、ANN 检索与 MaxSim 重排来检索视觉文档证据；最后用 100 分制规则+LLM 混合评审打分证据充分性，不足则触发再检索。

INSIGHT亮点是"证据门控"——用打分判断当前证据是否足够，不够才迭代再检索，避免无谓的多轮调用，是对 agentic RAG 成本的实用控制。其混合检索栈（稀疏 BM25+稠密 FAISS+cross-encoder 重排+图扩展+视觉 late-interaction）是一份可直接参考的工业级多模态检索流水线配方，适合需要图文混合证据的垂类搜索/问答系统。

Kanwar Bharat Singh

Co-Scraper: query-aware DOM Pruning and Reusable Scraper Synthesis for Lightweight Web Data Extraction

Shanghai AI Lab

针对网页数据自动抽取，Co-Scraper 提出两阶段框架处理长 HTML 文档的层级复杂性：先做 query-aware 的 DOM 剪枝，再做稳定的抽取策略归纳，用微调的 Qwen3-8B 把网页内容转成可复用、可执行的程序化 wrapper。在 SWDE 测试集上达到 SOTA，F1 94.78%、跨相似页面的复用成功率 90.39%。

INSIGHT"query 感知的 DOM 剪枝 + 生成可复用 wrapper"把 LLM 抽取从"每页都调一次大模型"变成"一次合成、多页复用程序"，大幅降低规模化抽取成本。对依赖网页语料构建搜索索引或 RAG 知识库的团队，这是一条降本路径：用小模型(8B)合成稳定抽取器，而非长期在线调用大模型解析每个页面。

Shoupeng Wang, Jiantao Qiu, Wuyang Zhang, Conghui He
