R1-Searcher: Incentivizing the Search Capability in LLMs via Reinforcement Learning

R1-Searcher 提出了一种两阶段强化学习方法，训练 LLM 在推理过程中自主调用外部搜索引擎。第一阶段通过 SFT 初始化模型的搜索调用格式，第二阶段通过 RL（基于结果奖励）训练模型学习何时搜索、搜索什么。该方法无需过程奖励或知识蒸馏，在多跳 QA 任务上显著超越传统 RAG 方法，甚至优于闭源的 GPT-4o-mini。模型自然涌现出反思和自纠错能力。

WebThinker: Empowering Large Reasoning Models with Deep Research Capability

Renmin University of China

WebThinker 为大型推理模型（LRM）赋予了自主网页研究能力。系统包含 Deep Web Explorer 模块（支持搜索、页面导航、信息抽取）和 Autonomous Think-Search-and-Draft 策略，使模型在推理过程中无缝交错信息检索与报告撰写。通过基于 iterative online DPO 的 RL 训练策略优化工具使用。在 GPQA、GAIA、WebWalkerQA 等基准上显著超越现有方法和商业系统。被 NeurIPS 2025 接收。

INSIGHTWebThinker 的「思考-搜索-起草」三位一体策略是 deep research 系统设计的范例：模型在推理过程中动态决定搜索时机、导航网页、提取信息，同时实时整合到报告中。其 DPO 训练策略值得借鉴——通过在线生成的搜索轨迹对进行偏好优化，而非依赖预标注数据。对搜索系统而言，这种 reasoning-interleaved-search 模式可应用于复杂信息需求的多轮检索场景。

MA-RAG: Multi-Agent Retrieval-Augmented Generation via Collaborative Chain-of-Thought Reasoning

MA-RAG 提出多 agent 协作的 RAG 框架，将 RAG 流程分解为多个专业化 agent：Planner 负责任务分解、Step Definer 定义子任务、Extractor 提取证据、QA Agent 生成答案。各 agent 通过 chain-of-thought 推理交换中间结果。在 NQ、HotpotQA、TriviaQA 等基准上，小模型通过多 agent 协作可超越大模型单体表现，且可零样本迁移到医疗问答等专业领域。

INSIGHTMA-RAG 的核心设计思路是将 RAG 的「检索-推理-生成」流程拆分为多个专业 agent，每个 agent 负责一个阶段并输出可解释的中间推理步骤。这种分治策略的实践意义在于：(1) 可根据各阶段特点选择不同规模模型，降低成本；(2) 中间推理步骤提供了可调试性；(3) 零样本跨域迁移能力意味着不需要领域特定训练数据。对搜索系统可借鉴其「分阶段-多 agent」架构来处理复杂查询意图。

Thang Nguyen, Peter Chin, Yu-Wing Tai

Knowledge-Aware Iterative Retrieval for Multi-Agent Systems

该论文提出了一种知识感知的迭代检索框架，核心创新是将外部信息源与内部知识缓存分离。内部知识缓存持续更新，用于引导查询生成和证据选择，避免检索偏差的强化。在多步问答任务上，该方法随任务复杂度增加优势更显著。框架支持竞争性和协作性多 agent 配置，收敛步数与任务难度成本效益地扩展。

INSIGHT知识缓存与外部检索分离的设计理念值得搜索系统借鉴：在迭代检索中维护一个动态更新的「已知信息」缓存，避免重复检索相同内容，同时利用已积累的知识来改进后续查询。这对多轮搜索交互场景（如对话式搜索）有直接参考价值，可减少冗余检索并提高信息获取效率。

Seyoung Song

Characterizing Deep Research: A Benchmark and Formal Definition

Microsoft Research

该论文提出了 deep research 的形式化定义和 LiveDRBench 基准。作者指出 deep research 的核心特征是搜索过程中对概念的「高扇出」（high fan-out），而非仅产生长文本输出。基准包含 100 个跨科学和公共事件的挑战性任务，各系统 F1 分数从 0.02 到 0.72 不等，OpenAI 以 0.55 的 F1 得分领先，Perplexity 为 0.41，Gemini 为 0.35。

INSIGHT该工作的最大贡献是将 deep research 从模糊概念提升为可量化评估的任务：核心度量是「概念扇出」——需要搜索和综合多少不同概念才能回答问题。这为评估搜索 agent 质量提供了新视角：好的搜索 agent 不仅要生成长文本，更要展示对多样概念的广泛检索和综合能力。LiveDRBench 可作为评估搜索系统 deep research 能力的标准基准。
