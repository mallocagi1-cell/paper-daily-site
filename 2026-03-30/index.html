MiniRec: Data-Efficient Reinforcement Learning for LLM-based Recommendation

MiniRec 提出了一种面向 LLM 推荐系统的数据高效强化学习框架。针对 RL 微调 LLM 推荐器时训练数据需求量大的问题，MiniRec 整合了三重数据选择策略：基于奖励信号的可学习性筛选（选择难度适中的样本）、基于梯度的代表性度量（确保样本梯度与理想优化方向对齐）、以及多样性感知的子集构建。结合课程学习策略，MiniRec 在大幅降低训练成本的同时基本保持了推荐性能。

KEY INSIGHT · 对业务意味着什么该工作的核心启示在于：RL 微调 LLM 推荐器时，数据质量远比数据数量重要。通过奖励驱动的难度筛选和梯度对齐选择，可以用少量高质量样本达到接近全量训练的效果。这对工业场景中降低 LLM 推荐系统的 RL 训练成本有直接参考价值，尤其适用于计算资源受限但希望引入 RL 优化推荐策略的团队。

LLM-Enhanced Reinforcement Learning for Long-Term User Satisfaction in Interactive Recommendation

LERL 提出了一种分层交互推荐框架，解决推荐系统因过度拟合短期偏好导致的内容同质化和信息茧房问题。框架包含两层决策：高层 LLM 语义规划器负责选择语义多样的内容类别，低层 RL 策略在指定类别内进行个性化物品推荐。这种双层设计有效缩小了动作空间，减少了重复内容的过度曝光，在真实数据集上展示了长期用户满意度的提升。

INSIGHTLERL 的设计思路值得借鉴：将 LLM 的语义理解能力用于高层策略规划（选类别），而非直接生成推荐结果，再由 RL 在缩小的动作空间内做精细化推荐。这种分层架构既利用了 LLM 的语义多样性感知能力，又避免了 LLM 直接推荐的延迟和成本问题。对于搜索/推荐系统中的多样性优化和长期留存提升场景有参考意义。

Chongjun Xia, Yanchun Peng, Xianzhi Wang
