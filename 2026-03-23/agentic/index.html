Evaluating the Search Agent in a Parallel World

本文提出 Mind-ParaWorld (MPW) 评估框架，通过采样真实实体名称合成超出模型知识截止期的未来场景和问题，配合 ParaWorld Engine 生成基于预设事实的搜索结果，从而解决搜索 Agent 评估中的静态基准过时、归因模糊和商用搜索引擎不可复现等问题。发布的 MPW-Bench 包含 19 个领域共 1,608 个评估实例。实验发现搜索 Agent 擅长证据综合，但在陌生搜索环境中的证据收集覆盖和何时停止决策方面表现不佳。

RAPO: Expanding Exploration for LLM Agents via Retrieval-Augmented Policy Optimization

RAPO 提出检索增强的策略优化框架，解决传统 Agentic RL 训练中探索受限于自生成输出的问题。核心包含两个阶段：混合策略 rollout 阶段让 Agent 在检索到的 off-policy 轨迹上进行推理，检索感知优化阶段通过奖励校准稳定训练过程。在 14 个数据集上实现平均 5% 的准确率提升，训练速度提高 1.2 倍。

INSIGHTRAPO 的核心贡献在于打破了 Agent RL 训练中的「自我探索瓶颈」——通过检索历史优质轨迹扩展探索空间，这一思路可直接应用于搜索 Agent 的在线学习场景。对于搜索推荐系统而言，off-policy trace 的复用机制可降低线上探索成本，奖励校准机制则有助于解决搜索场景中奖励信号稀疏的问题。14 个数据集的广泛验证和 1.2x 训练加速使其具备较强的工程落地价值。

Siwei Zhang, Yun Xiong, Xi Chen, Zi'an Jia, Renhong Huang, Jiarong Xu, Jiawei Zhang

TopoChunker: Topology-Aware Agentic Document Chunking Framework

TopoChunker 提出拓扑感知的 Agentic 文档分块框架，通过构建结构化中间表示 (SIR) 显式保留文档跨段依赖关系，解决传统分块线性化丢失结构信息的问题。采用双 Agent 架构：Inspector Agent 将文档路由到优化提取路径，Refiner Agent 审计容量并厘清拓扑关系。在生成准确率上超越最佳 LLM baseline 8.0%，Recall@3 达 83.26%，token 消耗减少 23.5%。

INSIGHTTopoChunker 的结构化中间表示 (SIR) 思路对搜索系统有启发意义——UGC 内容虽然是短文本，但帖子中的层级回复、引用关系等结构信息在传统检索中常被忽略。双 Agent 的分工模式（提取路由 + 质量审计）为 RAG 系统的工程化提供了可参考的架构模式。23.5% 的 token 节省在推理成本敏感的搜索场景中尤为实用。

Xiaoyu Liu

MemMA: Coordinating the Memory Cycle through Multi-Agent Reasoning and In-Situ Self-Evolution

MemMA 提出协调 LLM Agent 记忆生命周期的多 Agent 框架。前向路径中 Meta-Thinker 生成结构化指导，引导 Memory Manager 进行记忆构建；反向路径通过探针问答对实现自进化记忆构建，将失败转化为修复。在 LoCoMo 基准上跨多个 LLM 后端（包括不同规模模型）展示了一致的性能提升，代码已开源。

INSIGHTMemMA 的前向-反向双通道记忆管理思路对搜索场景有迁移价值：前向构建对应搜索系统中的用户画像和会话上下文构建，反向自进化对应在线纠错和反馈学习。探针 QA 驱动的记忆修复机制可借鉴为搜索系统中的 query-document 对验证方法。跨 LLM 后端的一致改进说明该架构具有较好的模型无关性。

Minhua Lin, Zhiwei Zhang, Hanqing Lu, Hui Liu, Xianfeng Tang, Qi He, Xiang Zhang, Suhang Wang

RLRF: Competitive Search Agent Design via Reinforcement Learning from Ranker Feedback

Technion

RLRF 提出基于排序器反馈的强化学习框架，用于训练竞争性搜索 Agent。与 RLHF 对齐人类偏好不同，RLRF 将 Agent 行为（文档修改策略）对齐到排序器偏好上，采用 Direct Preference Optimization (DPO) 替代 PPO，更稳定且样本效率更高。Agent 在跨未知排序函数和适应对抗策略方面超越了此前的 LLM 方法。

INSIGHTRLRF 将 RLHF 思路引入搜索排序场景的做法极具创新性——用排序器作为奖励信号训练内容生成 Agent，本质上是搜索博弈论的 LLM 化。对搜索系统而言，这揭示了一个重要趋势：当 LLM Agent 大规模介入内容生成和搜索时，排序系统需要从「被动排序」转向「对抗感知」的鲁棒性设计。DPO 替代 PPO 的选择也为搜索 RL 训练提供了更稳定的实践路径。

Tommy Mordo, Sagie Dekel, Omer Madmon, Moshe Tennenholtz, Oren Kurland

A Picture of Agentic Search

本文系统性地分析了 Agentic Search 给信息检索带来的范式转变——自动化系统开始与人类一起生成搜索查询。指出当前 IR 系统、评估指标和用户模型仍以人类为中心，与 Agent 实际部署场景存在错位。发布了 Agentic Search Queryset (ASQ) 数据集，涵盖三种 Agent 和两条检索管线在 HotpotQA、Researchy Questions 和 MS MARCO 上的推理查询、检索文档和系统推理。

INSIGHT本文的核心洞察是 Agent 生成的查询与人类查询在分布上显著不同，现有检索系统可能同时对两者都次优。对搜索系统实践者而言，这意味着在接入 LLM Agent 流量时，可能需要为 Agent 查询和人类查询分别优化检索策略。ASQ 数据集为这一方向的研究提供了标准化基准，可用于评估搜索系统是否能同时服务好人类和 Agent 用户。

Francesca Pezzuti, Ophir Frieder, Fabrizio Silvestri, Sean MacAvaney, Nicola Tonellotto

Retrieval-Augmented LLM Agents: Learning to Learn from Experience

Naver Labs

本文研究如何通过经验检索增强 LLM Agent 对未见任务的泛化能力。建立了基于 LoRA 的高效微调基线，分析了检索和选择历史经验的最优策略，并提出将经验检索整合进训练过程的方法。实验表明组合策略显著提升了 Agent 在未见任务上的泛化表现。

INSIGHT「从经验中学习如何学习」的思路对搜索 Agent 有直接启示：搜索系统中存在大量历史查询-检索-反馈轨迹，将这些经验作为检索增强的训练信号可减少 Agent 在新查询类型上的冷启动问题。LoRA 微调的选择也适合搜索场景中需要频繁更新模型的需求。Naver Labs 的工业背景增加了该方法在实际搜索产品中的适用可信度。

Thomas Palmeira Ferraz, Romain Deffayet, Vassilina Nikoulina, Hervé Déjean, Stéphane Clinchant
