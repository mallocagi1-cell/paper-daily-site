From Past To Path: Masked History Learning for Next-Item Prediction in Generative Recommendation

该论文针对生成式推荐系统中仅依赖自回归训练的局限性，提出了 Masked History Learning (MHL) 方法。MHL 通过重建被遮蔽的历史交互项作为辅助任务，迫使模型理解用户行为序列的因果关系——即"为什么"用户路径如此形成，而非仅预测"下一个是什么"。核心创新包括基于信息熵的遮蔽策略（优先遮蔽信息量大的历史项）和课程学习调度器（从历史重建逐步过渡到未来预测）。在三个公开数据集上，MHL 显著优于现有生成式推荐模型。

KEY INSIGHT · 对业务意味着什么MHL 揭示了一个被忽视的训练信号：生成式推荐不仅需要预测未来，更需要理解历史。通过遮蔽-重建的方式让模型学习用户行为的深层逻辑，而非表面的序列共现。对搜索推荐实践的启示：(1) 在自回归推荐训练中加入历史重建辅助任务，可以用较低成本提升模型对用户意图的理解；(2) 基于信息熵选择性遮蔽的思路可迁移至 query 理解和用户建模场景；(3) 课程学习策略为生成式推荐的训练稳定性提供了实用方案。

UNGER: Generative Recommendation with A Unified Code via Semantic and Collaborative Integration

Huawei

该论文提出 UNGER，一种将语义知识和协同过滤知识统一编码的生成式推荐方法。现有方法通常分别生成语义 ID 和协同 ID，导致信息割裂和量化损失。UNGER 通过跨模态对齐和预测任务的联合优化，将两类知识融合到统一的离散编码中。同时引入模态内知识蒸馏，减少向量量化过程中的信息丢失。在 Amazon Sports、Yelp、Amazon Beauty 三个数据集上均取得了显著提升。

INSIGHTUNGER 的核心贡献在于打破了生成式推荐中语义 ID 和协同 ID 割裂的现状。在实践中，搜索推荐系统通常需要同时捕捉内容语义（文本、图像特征）和行为信号（点击、购买共现），UNGER 提供了一种在 token 级别统一这两类信号的思路。(1) 跨模态对齐的思路可借鉴到搜索场景中 query-doc 的多模态表征融合；(2) 模态内知识蒸馏解决了 RQ-VAE 量化损失问题，这是所有基于 Semantic ID 的生成式推荐系统面临的共性挑战；(3) Huawei 团队的参与暗示该方法可能已有工业验证基础。
