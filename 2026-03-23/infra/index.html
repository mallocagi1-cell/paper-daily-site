SpecForge: A Flexible and Efficient Open-Source Training Framework for Speculative Decoding

SpecForge 是一个面向生产环境的开源投机解码训练框架，全面支持 EAGLE-3 模型训练。通过 target-draft 解耦、混合并行和优化的训练内核，SpecForge 将 Qwen3-235B-A22B 的 EAGLE-3 训练加速 9.9 倍。在序列长度 4096 下，优化的注意力内核在单块 NVIDIA H200 GPU 上实现了 62.1% 的执行时间缩减和 93.5% 的峰值显存降低。配套的 SpecBundle 提供了一系列针对主流开源 LLM 的生产级 EAGLE-3 draft 模型。

inference-fleet-sim: A Queueing-Theory-Grounded Fleet Capacity Planner for LLM Inference

inference-fleet-sim 是一个基于排队论的 LLM 推理集群容量规划工具，结合解析式 M/G/c 排队模型和离散事件仿真（DES）来寻找满足 P99 TTFT SLO 的最低成本集群配置。该工具内置了物理信息驱动的 GPU 性能模型，覆盖 A10G、A100 和 H100 三种 GPU，支持单体式、双池路由和 prefill-decode 分离三种部署拓扑。论文在 LMSYS、Azure 和合成 agent 工作负载的 7 个场景上验证了该工具的有效性。

INSIGHT该工作将 LLM 推理集群规划从经验驱动转向理论驱动，核心发现是简单的分析模型在重尾负载下会系统性低估所需 GPU 数量。对搜索系统基建的启示是：当搜索链路引入 LLM（如 query 理解、重排序等），集群规划不能仅靠平均延迟估算，需要考虑 token 长度分布和排队效应。工具开源且支持主流 GPU 型号，可直接用于评估 LLM 搜索服务的硬件采购决策。

Huamin Chen, Xunzhuo Liu, Yuhan Liu, Junchen Jiang, Bowei He, Xue Liu

LookaheadKV: Fast and Accurate KV Cache Eviction by Glimpsing into the Future without Generation

LookaheadKV 提出了一种轻量级的 KV 缓存淘汰框架，核心创新是在不进行实际 token 生成的前提下'预览未来'，通过为 Transformer 层添加参数高效的辅助模块来预测各 token 的真实重要性得分。该方法在 prefill 阶段使用可学习的特殊 token 进行 KV 缓存淘汰，相比近期的竞争基线方法取得了更好的效果，淘汰计算成本降低高达 14.5 倍，从而显著加速了首 token 生成时间（TTFT）。

INSIGHTLookaheadKV 的核心思路是'用少量参数预测未来注意力分布'，避免了传统方法中基于历史注意力得分的滞后性问题。这种前瞻性淘汰策略对搜索/推荐系统中的 LLM 推理服务有直接价值：在长上下文搜索场景（如多轮对话搜索、长文档理解）中，KV 缓存是显存瓶颈，14.5 倍的淘汰加速意味着在不牺牲质量的前提下支持更长的上下文窗口或更高的并发数。

ARKV: Adaptive and Resource-Efficient KV Cache Management under Limited Memory Budget for Long-Context Inference in LLMs

ARKV 是一种自适应的 KV 缓存管理方案，在 prefill 阶段收集每一层注意力的简单统计量（熵、方差、峰度）来计算层级别的原始-量化（OQ）比例。在解码阶段，token 被动态分配到三种状态：原始精度（Original）、低精度量化（Quantization）或淘汰（Eviction），采用快速的 heavy-hitter 打分策略。实验表明 ARKV 在长上下文基准上保持约 97% 的基线精度，同时将 KV 显存占用减少 4 倍。

INSIGHTARKV 的设计哲学是'用统计指标自动决定每层的压缩策略'，避免了手工调参。三态管理（保留/量化/淘汰）比单一策略更灵活，适合不同层具有不同注意力分布的实际模型。对搜索系统的启示是：在显存受限的部署环境下（如边缘推理或单卡部署），ARKV 提供了一种无需重新训练即可减少 4 倍 KV 显存的实用方案，适合将 LLM 排序/理解模块部署到更低成本的硬件上。

Jianlong Lei, Shashikant Ilager

UniComp: A Unified Evaluation of Large Language Model Compression via Pruning, Quantization, and Distillation

UniComp 提出了一个统一的 LLM 压缩评估框架，系统性地对比了剪枝、量化和知识蒸馏三大主流压缩技术在性能、可靠性和效率三个维度上的表现。该框架支持对各种压缩技术的单独使用和组合使用进行直接比较，为从业者在部署约束下选择合适的压缩方案提供了实证指导。

INSIGHTUniComp 的价值在于建立了一个公平的压缩技术对比基线，解决了当前文献中不同压缩方法因实验设置差异而难以直接比较的问题。对搜索系统从业者的启示是：在选择 LLM 压缩策略时，4-bit 量化通常是性价比最优的方案（30-50% 推理提速，精度几乎无损），而组合使用多种压缩技术时，先量化再剪枝的顺序通常优于反向操作。这为搜索场景中 LLM 模型瘦身提供了决策参考。

ASAP: Attention-Shift-Aware Pruning for Efficient LVLM Inference

George Mason University

ASAP 针对大型视觉语言模型（LVLM）中高分辨率视觉 token 的二次计算成本问题，提出了一种免训练、兼容 KV 缓存的剪枝方法。核心创新在于引入动态双向软注意力掩码来缓解 LVLM 中的'注意力偏移'现象，确保选取的是真正有信息量的 token。该剪枝模块嵌入在解码器层之间，在推理前向传播过程中压缩视觉 token 序列。

INSIGHTASAP 发现了 LVLM 中'注意力偏移'这一关键现象——即模型在不同层对视觉 token 的注意力分布会系统性偏移，导致基于单层注意力分数的剪枝策略失效。对搜索/推荐系统的启示是：当系统需要处理图文混合内容（如 UGC 中的图片+文字搜索），ASAP 的免训练剪枝可以显著降低多模态模型的推理成本，使得多模态搜索在资源受限环境下可行。

Surendra Pathak, Bo Han
