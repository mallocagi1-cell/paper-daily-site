提出统一 Transformer 架构同时处理特征交互和用户行为序列建模。

KEY INSIGHT · 对业务意味着什么将特征交互和序列建模统一到一个 Transformer 中，通过统一分词器将序列和非序列属性转化为单一 token 序列，并借助因果注意力和 KV 缓存大幅降低训推成本，是工业推荐系统架构统一化的关键实践。业务关联 社区搜索场景中用户行为序列（浏览、点击、搜索）与静态特征的联合建模可直接复用该架构，有望提升排序模型的 CTR 预估精度。证据 在字节跳动工业级数据集上 CTR AUC 提升 +1.53%，线上 A/B 测试每用户 GMV 提升 5.68%。已被 WWW 2026 录用。

LLaTTE: Scaling Laws for Multi-Stage Sequence Modeling in Large-Scale Ads Recommendation

📖 深度解读 · 9 分钟 →

验证推荐系统序列建模遵循类 LLM 的幂律缩放定律。

INSIGHT语义特征是推荐系统 Scaling Law 的前提条件，它使模型能有效利用更深更长架构的容量。通过两阶段架构将大规模长上下文模型的计算异步卸载到上游用户模型，可在不增加在线延迟的前提下持续扩展模型能力。

业务关联社区搜索的排序模型可借鉴该多阶段架构，将用户长期兴趣建模异步化处理，在保持低延迟的同时提升个性化排序精度和转化率。

证据作为 Meta 最大规模用户模型部署在 Facebook Feed 和 Reels，实现 4.3% 的转化率提升，在线服务开销极低。

FairFS: Addressing Deep Feature Selection Biases for Recommender System

识别并修正工业推荐系统中深度特征选择的三类偏差问题。

INSIGHT在工业推荐系统的特征选择中存在层偏差、基准偏差和近似偏差三类问题，导致特征重要性估计不准确。修正这些偏差可显著提升特征选择的可靠性和下游模型性能。

业务关联社区搜索的排序模型通常涉及数千特征候选，准确的特征选择可减少计算成本并提升线上 nDCG 和 CTR，该方法可直接应用于排序模型的特征工程流程。

证据通过真实工业案例分析验证三类偏差的存在及修正效果，在大规模电商推荐系统中特征选择准确率显著提升，同时改善在线服务性能。

RAIR: A Rule-Aware Benchmark Uniting Challenging Long-Tail and Visual Salience Subset for E-commerce Relevance Assessment

构建中文电商搜索相关性评估基准，含通用、长尾和视觉子集。

INSIGHT现有相关性基准缺乏复杂度和标准化评估。RAIR 建立了通用规则框架并划分通用集、长尾难例集和视觉显著性子集，揭示了当前 LLM 在长尾 query 和视觉理解上的显著不足。

业务关联直接可用于社区搜索的相关性评估体系建设，特别是中文 UGC 场景下的长尾 query 处理和多模态相关性判断能力评估。

证据基于真实中文电商场景构建标准化数据集，含通用集、长尾难例集、视觉子集三个评估维度，对多个主流 LLM 进行系统评测并量化其在不同难度水平下的表现差异。

ReAttn: Improving Attention-based Re-ranking via Attention Re-weighting

提出注意力重加权策略改进 LLM 零样本重排序效果。

INSIGHTLLM 重排序中注意力信号高度集中于少量 token 且偏向与 query 词法相似的短语，导致排序偏差。通过跨文档 IDF 加权降低高频 token 的注意力权重，可有效缓解此问题。

业务关联在社区搜索中使用 LLM 做结果重排序时，可直接作为后处理方法应用，无需重新训练模型即可提升搜索相关性 nDCG。

证据提出跨文档 IDF 加权和注意力再分配策略，作为即插即用后处理方法在注意力重排序基线上实现一致性排序效果改进。

E2E-GRec: An End-to-End Joint Training Framework for Graph Neural Networks and Recommender Systems

提出端到端联合训练框架统一 GNN 与推荐系统的训练流程。

INSIGHT工业推荐系统中 GNN 通常采用两阶段解耦训练，导致计算冗余和优化不一致。端到端联合训练使推荐系统的梯度直接影响 GNN 学习过程，获得更优的图嵌入表示。

业务关联社区搜索中用户—帖子、帖子—帖子之间的图结构关系丰富，端到端 GNN 训练可将图信号直接融入排序模型，提升基于图结构的召回和排序效果。

证据在标准推荐数据集上验证端到端训练相比两阶段解耦方案在推荐准确率上的提升，同时减少大规模 GNN 推理的重复计算开销。

DeepInterestGR: Mining Deep Multi-Interest Using Multi-Modal LLMs for Generative Recommendation

📖 深度解读 · 11 分钟 →

利用多模态 LLM 挖掘用户深层多兴趣用于生成式推荐。

INSIGHT现有生成式推荐仅依赖标题等浅层文本特征编码 item，导致「浅兴趣」问题。通过多个 LLM 的 Chain-of-Thought 提示挖掘深层文本和视觉兴趣表示，并用奖励标签过滤噪声兴趣，可显著提升个性化深度。

业务关联社区搜索中 UGC 内容具有丰富的多模态信息（文本+图片），可借鉴该方法通过 LLM 挖掘用户深层意图以提升个性化推荐和搜索结果质量。

证据提出 Multi-LLM Interest Mining (MLIM)、Reward-Labeled Deep Interest (RLDI) 和层次化 SID 生成三项创新，在生成式推荐框架中验证深层兴趣挖掘对推荐准确率的有效提升。

GrIT: Group Informed Transformer for Sequential Recommendation

引入时变潜在群组表示增强序列推荐中的 Transformer 建模。

INSIGHT序列推荐中仅建模个体用户历史忽略了群组级行为模式的影响。通过可学习的时变群组隶属权重，将群组集体行为融入个体偏好建模可提升下一项预测的准确性。

业务关联社区平台中用户天然形成兴趣群组（如运动社区、美食社区），可利用群组信息增强个性化内容推荐和搜索排序。

证据在多个序列推荐基准数据集上验证引入群组特征后的性能提升，模型通过短期和长期偏好建模动态计算每个时间步的用户群组隶属权重。

Parallel Latent Reasoning for Sequential Recommendation

通过并行多样化推理轨迹扩展序列推荐的测试时计算能力。

INSIGHT不同于简单加深推理链条，该工作通过可学习触发 token 构建并行推理流，并用混合推理流聚合 (Mixture-of-Reasoning-Streams) 自适应综合多路输出，在宽度维度扩展推荐模型的推理能力。

业务关联搜索/推荐系统在推理阶段增加计算预算以提升个性化排序质量的思路值得借鉴，尤其适合对延迟不敏感的离线推荐或异步重排场景。

证据在三个真实世界数据集上验证并行潜在推理相比序列推理链方法的性能提升，同时保持高效的推理速度。

DReX: An Explainable Deep Learning-based Multimodal Recommendation Framework

提出基于 GRU 的多模态推荐框架实现增量式表示更新。

INSIGHT将多模态反馈中的交互级特征通过门控循环单元增量融入全局表示，避免了多模态数据缺失和模态间不对齐问题，同时提供可解释的推荐理由。

业务关联社区搜索中帖子具有文本+图片等多模态特征，该框架的增量更新机制适合处理 UGC 内容的多模态信息并提升推荐可解释性。

证据在多模态推荐基准上验证增量式表示更新机制相比静态融合方法在推荐准确率上的提升，同时展示可解释性输出能力。
