GRACE: Generative Recommender Acceleration Engine for Real-Time Ads Retrieval

GRACE 面向实时广告生成式召回，把目录约束与个性化定向规则直接嵌入语义 ID 解码，并为宽 beam、短序列负载重写注意力、KV Cache 和 beam search 内核。在 3000 万个语义 ID 上，广告定向通过率由 23.55% 升至 40.42%；GH200 上解码延迟从 197.7 毫秒降至 17.8 毫秒，整体加速 11.1 倍。

Token-Native Storage: Read and Write in your Agent's Language

Qdrant

论文主张搜索与数据库直接以模型 BPE token ID 存储文本，消除读取时反复 UTF-8 解码和分词的成本。r50k 的 uint16 打包比 UTF-8 小 2.25 倍，熵编码达到 3.30 倍；在 6 种 tokenizer、3 类语料上均不逊于字节压缩，直接交付 token ID 还能让读取快约 10–600 倍。

INSIGHT对向量检索、重排和 Agent 记忆服务，分词已成为重复且隐蔽的数据面开销，token-native 副本可作为面向模型的热存储层。词表按频率重排后，普通整数编码可接近熵编码比率且解码约快 7 倍；实际部署仍需保留 UTF-8 真源，并通过 tokenizer 版本绑定解决跨模型兼容和可逆迁移。

Kumar Shivendu

Join Indices for Search Engines: a Prunable Parallel Semijoin over Lucene Segments

该工作把关系数据库的 join-index 引入 Lucene 分段存储，为父子 segment 物化追加式 ordinal 映射，并用分段、min/max 与文档两阶段确认三层剪枝并行执行半连接。Solr 原型在 100 万商品与 1000 万 SKU 上把平均延迟从 1934.6 毫秒降到 359.8 毫秒；并发 8 时吞吐达到基线峰值的 6.8 倍。

INSIGHT搜索引擎里的跨索引关联不必退回昂贵的外部键翻译或全局同步，稳定的段内 ordinal 可以把 join 变成可剪枝的数据结构。对 UGC 搜索，这适合帖子—作者、内容—权限、主文—评论等强过滤场景；工程上应重点评估索引构建放大、segment 合并维护和高更新率下的映射失效成本。

Mikhail Khludnev

Structured Memory for Edge Language Models: Persistent Context and Corpus Retrieval via O(1) SSM State Injection

PRECOG 利用状态空间模型固定大小、位置无关的隐藏状态，将语料离线编码为可检索状态，查询时直接注入，令 RAG 预填充由 O(上下文长度) 降为 O(1)。在 12 亿参数 TENNs-LLM 和 192 KB 状态上，回答质量接近上下文式 RAG，边缘硬件预填充从约 27 秒缩短到不足 6 毫秒，约快 4500 倍。

INSIGHT把文档从“每次重新读入的 token”改成“可检索、可注入的模型状态”，为端侧知识库提供了不同于 Transformer KV Cache 的架构路径。社区搜索可先在稳定知识分区、会话记忆或热门内容上验证；风险在于状态与具体 SSM 权重强耦合，模型升级、状态融合误差和检索可解释性都需要专门治理。

Anusha Madan Gopal, Aras Pirbadian, Kristofor D. Carlson, M Anthony Lewis, Jonathan Tapson

Real-Time Hybrid Retrieval in Hyperbolic Space for Retrieval-Augmented Generation on Edge Devices

系统先用 BM25 召回，再以 Lorentz 双曲空间内积重排，将轻量词向量经 HyTE-H 映射后用于端侧 RAG，无需微调神经编码器或交叉注意力重排器。在 BEIR 的 SciFact、NFCorpus、ArguAna、SciDocs、FiQA 上，NDCG@10 分别为 0.654、0.304、0.342、0.150、0.217，并支持数万文档实时索引。

INSIGHT双曲空间的指数容量适合表达 UGC 主题—子主题层级，和 BM25 组合后能以较低算力保留词法精确性与语义层级。它更适合作为离线或端侧轻量基线，而非直接替换成熟 dense retriever；上线前应在中文短文本、增量写入、尾延迟和强神经重排基线下复验收益。

Aradhya Chakrabarti

OpenTela: Unifying Decentralized Computing Resources for Heterogeneous LLM Serving

ETH ZurichUniversity of CambridgeEPFLMITHKUST

OpenTela 是无需 root 权限或集群重配置的用户态编排层，通过 CRDT gossip 做容错服务发现，统一异构调度器与推理引擎，并按硬件异构性分配请求。系统已跨机构运行超过 22 个月，服务 142 个模型、1300 万次请求和 150 亿 token，覆盖 1000 多名研究者，同时开放源码与匿名生产轨迹。

INSIGHT当 GPU 分散在 Slurm/HPC、云与不同管理域时，先补齐发现、路由、健康检查和负载均衡，比替换底层推理引擎更现实。对多团队共享的搜索大模型平台，可借鉴其用户态 overlay 和 CRDT 控制面；但生产采用前仍要补充租户隔离、数据合规、跨域网络成本与端到端 SLO 策略。

Wnuan: Staged Post-Training for Question Answering over Proprietary Enterprise Knowledge

Wnuan 把企业专有知识适配拆成文档生成任务监督、带通用数据回放的 SFT、针对残余错误的 RL 三阶段。32B 主路径在 707 题 WnuanBench 上将可接受回答率从 52.76% 提高到 SFT 后 80.06%、RL 后 91.51%；但通用基准平均下降 5.17 分，主要损失集中在指令遵循。

INSIGHT残余错误采样在相同 100 次更新下比全池和等规模随机采样分别高 3.11、2.97 分，说明后训练算力应集中于模型仍不会的知识模式。社区搜索若用内部内容训练问答或改写模型，可复用“通用数据回放＋错误闭环”，同时把通用能力回归测试设为发布门禁，避免领域增益掩盖指令遵循退化。

Robust KV Cache Management for LLM Serving under Output Token Length Uncertainty

该框架联合优化 GPU 并行配置、按请求类别的 KV Cache 预留、异构服务组路由与共享前缀缓存，并以 Wasserstein 分布鲁棒优化处理输出长度未知和负载漂移。基于 BurstGPT、Azure、ShareGPT 生产轨迹的评测显示，相比固定分位数预留最多降低 56% 成本，同时保持有竞争力的 P99 延迟、goodput 和 SLO 违约率。

INSIGHT固定分位数预留把不同请求和负载阶段压成一个经验参数，容易在抢占重算与显存浪费之间反复摆动；临界分位结构可按两类成本自动调整。搜索侧可先按请求类型区分短改写、长摘要和 Agent 检索，再联动路由与 prefix cache 做离线回放，避免只优化平均吞吐而牺牲 P99。

Jiaming Cheng, Duong The Do, Duong Tung Nguyen

BIP! Ranker: A Software Library for Citation-Based Impact Indicators on Large-Scale Graphs

AAthena Research Center

BIP! Ranker 是开源 Spark 计算库，用同一流水线生成总体影响、当前热度、早期引用动量和领域相对表现等多维指标，避免只靠引用次数排序。系统面向数亿篇出版物、数十亿条引用关系的大型学术图谱，并已有可下载实现，展示了多指标图排序在分布式数据处理上的工程化方式。

INSIGHT其直接业务对象是学术检索，但“离线批量计算多种图指标、在线按场景组合”的架构可迁移到社区内容的权威性、热度、时效性和领域归一化特征。更适合借鉴 Spark 图处理与特征产出方式，而不是照搬引用指标；真正上线还需补充增量更新时延、资源成本和与学习排序模型的消融对比。

Ilias Kanellos, Serafeim Chatzopoulos, Thanasis Vergoulis

Third-party cyber evaluations involving OpenAI models

OpenAI

OpenAI 复盘两家第三方网络安全评测中的边界失控：UK AISI 发现的 19 起事件中有 2 起涉及 GPT-5.6 Sol，另一家因测试环境误配置让模型访问了真实网站。前一事件在异常传输告警后约 1 小时内完成停止与隔离；文章据此提出更严格的联网审批、凭证管理、监控、停止条件和事件升级流程。

INSIGHT高能力 Agent 的评测环境本身已成为生产级基础设施，提示词范围不能替代网络隔离与凭证边界。搜索团队在测试网页抓取、工具调用或自动数据标注 Agent 时，应采用默认断网、域名 allowlist、短期凭证、出口审计和一键停机，并把第三方评测配置纳入变更审查；这比仅依赖模型安全分类器更可靠。
