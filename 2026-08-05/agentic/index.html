Fetch-then-Explore: Decoupling Selection from Extraction over a Persistent Workspace for Search Agents

针对搜索 Agent 打开网页即把内容塞入上下文、离开页面后证据易丢失的问题，论文提出 Fetch-then-Explore：先将全文存入每题独立的持久工作区，再用 grep/read 按需抽取。三种模型上 BrowseComp 准确率分别达 44.5%、52.5% 和 70.5%，比瞬态 Open+Find 高 2.0–4.5 个百分点。

Diagnosing Search Behavior and Failure Modes in Long-Horizon Search Agents

Renmin University of ChinaNUS

论文固定检索器与 ReAct 框架，在 BrowseComp-Plus 的 830 个问题上比较 6 个长程搜索 Agent，并以人工文档相关性标注区分“没找到证据”和“找到但没用好”。累计召回与准确率相关系数达 0.99，而最终上下文规模仅 0.16；77%–94% 的搜索回合没有增加新证据。

INSIGHT长链路并不等于高质量，强 Agent 的特征是更少重复查询、更早命中证据并及时停止。线上系统应分别监控检索缺口与利用缺口：前者优化 query 改写和方向切换，后者加强证据核验与答案归一化；以证据覆盖驱动停止，比固定轮数或 token 预算更合理。

Verification Without Sufficiency: Per-Chunk Filtering Fails on Multi-Hop RAG, and Decomposition Repairs It

论文指出多跳 RAG 逐 chunk 做蕴含过滤存在结构性错误：单段本就不足以回答原问题。HotpotQA、2WikiMultihopQA、MuSiQue 上 AUC 仅 0.643、0.523、0.560，而单跳 SQuAD 为 0.951；把核验条件换成分解后的子问题后，MuSiQue 后续跳 AUC 从 0.546 升至 0.840。

INSIGHT多跳搜索的核验单位应与当前推理子目标对齐，而不是让每段材料单独证明最终答案。社区复杂问答可保留 Agent 已生成的子问题，将召回结果按“它支持哪一步”评分；这样既避免过早删掉桥接证据，也能把检索、核验和最终合成串成可追踪的证据链。

HindSearch: Trajectory-Level Hindsight Critique for Search-Augmented Reinforcement Learning

针对搜索增强 Agent 只用二元 exact-match 奖励、失败轨迹信息被浪费的问题，HindSearch 在 GRPO rollout 后让冻结评审器借助标准答案为每条失败轨迹生成简短批评，再蒸馏到学生的搜索动作。Qwen2.5-3B-Instruct 在 7 个基准上的平均 EM 达 39.4%，优于既有 search-RL 基线。

INSIGHT方法把“最终答错”分解成可学习的搜索动作反馈，特别适合训练 query 生成、工具选择和停止策略。业务侧可先在有标准答案或人工审核结果的离线日志上试验，将 hindsight critique 作为辅助损失；消融显示拿掉评审器的标准答案后增益大幅消失，监督质量是成败关键。

LongHorizon-Harness: Advancing Long-Horizon Agents for Real-World Tasks

Alibaba

LongHorizon-Harness 把长任务改写为显式任务状态管理，用 Manager–Execute–Audit 循环让执行器在新上下文完成子任务，再由只读审计器核验环境事实。Qwen 3.7-Plus 在 WeaveBench 从 51.8% 升至 80.7%，Terminal-Bench 2.1 从 69.7% 升至 77.2%，OSWorld 2.0 从 2.8% 升至 8.3%。

INSIGHT可靠长程 Agent 的核心不是无限延长同一上下文，而是只让经过独立核验的状态跨轮次持久化。对深度搜索任务，可由管理器维护问题分解与证据缺口，执行器专注检索，审计器只读核对引用和页面事实；这种职责隔离能阻止自我误判进入后续推理前提。

Deep Agentic Search for Repository-Level Code Question Answering: An Empirical Study

论文在 SWE-QA 上对比预建向量索引的语义检索与“规划器委派隔离子 Agent 做 grep 搜索”。语义检索正确率为 65.2%，深度 Agentic 搜索仅 46.2%，且每个正确答案成本不足后者一半；深搜失败中最大的一类 41.8% 发生在规划器与子 Agent 的交接处。

INSIGHT隔离上下文能缓解 context rot，却会引入任务说明压缩、搜索范围遗漏和结果交接失真。可索引的稳定语料应优先走确定性召回，把子 Agent 留给无法预建索引或需要动态探索的长尾任务；同时必须记录委派请求、返回证据和最终引用，专门监控静默交接失败。

V-Mem: Modality-Routed Retrieval for Long-Term Multimodal Agentic Memory

V-Mem 针对多模态 Agent 记忆中的模态鸿沟与“相似但不相关”问题，先从查询判断目标证据模态，再以同轮内容路由和 LLM 生成的跨模态 anchor 检索。Mem-Gallery 上 LLM-judge 得分 0.82，对比次优 0.56；带图问题达 0.87，而基线均不超过 0.47，LoCoMo 也从 0.58 升至 0.69。

INSIGHT统一向量空间并不保证跨模态证据彼此靠近，直接 top-k 相似度会系统性漏掉图片、文字之间的桥接关系。社区搜索若引入图文会话记忆，应先识别问题要找的是图还是文，再生成目标模态 anchor，并利用同一交互轮次做跨模态跳转，而不是把所有内容塞进一个索引后统一检索。

千问联网检索Agent产品简介

Alibaba

阿里云百炼给出可配置的联网检索 Agent：支持 query 智能改写、垂域工具选择、时间范围约束、最多 100 个指定站点、网页深度阅读和按难度决定轮次的“边想边搜”。文档同时公开成本边界，基础联网检索为 22 元/千次，词条增强 16 元/千次，图片或视频检索 20 元/千次。

INSIGHT这是把 Agentic Search 产品化时很有价值的控制面清单：触发策略、检索范围、深读开关、时效约束、引用与成本都应成为显式配置，而非藏在 prompt 中。社区搜索可按 query 难度分层，仅对复杂问题启用边想边搜和深读，并用站点白名单、引用角标及单次预算控制质量与费用。

DeepVoyager-VL: Incentivizing Vision-in-the-Loop Search for Long-Horizon Multimodal Agents

Peking UniversityHKUSTNNUDTOOcean University of ChinaHHIT ShenzhenHuawei

INSIGHT视觉材料不应只在入口识图或结尾佐证，而要进入“观察—改写查询—继续检索”的循环。图文 UGC 搜索可先返回轻量图片引用，只有当视觉证据能缩小实体或事件范围时才加载原图或裁剪区域；这种 discoverability 与 observability 分离能显著压低长链路视觉 token 成本。

Progressive Agent Skill Generation via Reinforcement Learning

Skill-α 把 Agent 技能生成建模为逐步编辑过程，并用 rollback reward 比较原技能与修改后技能在锚定任务上的下游执行效果，从而给每次编辑提供可评估信号。以 GPT-4o 为执行器时，它相对最强技能生成基线把 CL-Bench 平均成功率提高 3.3 个点，在 tau2-bench 提高 6.7 个点。

INSIGHT技能质量不能只靠语言流畅度或静态规则判断，关键是修改是否真的提高后续任务成功率。搜索 Agent 可把查询拆解、来源筛选、证据核验等经验沉淀为可编辑技能，并通过离线回放比较修改前后表现；rollback 机制可阻止一次有害更新污染整套技能库。
