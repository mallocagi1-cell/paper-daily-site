Context Features Are Cheap: Rank-Aware Decomposition for Efficient Feature Interaction in Recommender Systems

工业排序模型对同一用户/上下文特征重复打分 N 个候选，标准实现把上下文特征在前向早期广播，导致 context-only 计算每请求重复 N 次。论文提出 rank-aware 分解：对 FM 两两内积、DCNv2 cross 层、self-attention、FC 投影这些主流交互算子，基于“秩划分输入上的线性/双线性运算可做精确块分解”这一代数原理，把 context-only 计算从 per-candidate 降到 per-request，且与原模型输出逐位等价。在生产 DLRM 排序器上零改结构即让单 pod 吞吐 +87.5%、峰值 pod 数减少 47%；进一步提出 rDCN 变体跨层保持秩纪律，在训练噪声内匹配 DCNv2 精度且总 FLOPs 减少 67%。

Joint Optimization of Relevance and Engagement in Multi-Task Ranking for E-Commerce with Efficient LLM Supervision

DoorDash📖 深度解读 · 6 分钟 →

工业搜索排序只用参与度信号优化会引入系统性偏差，偏向热门或价格锚定商品而不满足语义意图。论文提出生产级多任务排序系统，把语义相关性作为首要优化目标：用 ordinal relevance head 预测跨相关性阈值的累积概率以保留标签序关系，再与 engagement head 通过统一 value model 融合，实现可控的相关性-参与度权衡。用微调的轻量 LLM 在 1 亿+ query-item 对上批量生成三级序数相关性标签。离线 NDCG@10 与在线 A/B 均报告提升（摘要未给具体数值）。

INSIGHT对“相关性(nDCG)+CTR 双目标”的社区搜索场景高度对口。ordinal head 用累积概率建模有序标签，比多分类更契合相关性等级语义；用轻量 LLM 产 1 亿级相关性标签解决了相关性标注稀缺，是把 LLM 当离线标注器而非在线打分器的实用路线，在线无额外推理成本。

Fine-Tuned LLM as a Complementary Predictor Improving Ads System

LLM 在广告/生产级推荐的落地仍稀少。已有 LLM-in-RecSys 成功多落在三类：(a) 生成式召回直接预测下一个候选，(b) 后期重排，(c) 辅助信号增强。论文为广告提出第四类互补范式：把微调过的开源 LLM 用作“广告主预测器(advertiser predictor)”而非排序器，为候选生成提供补充并给下游排序提供先验。在生产广告系统报告了显著离线提升与可度量的在线业务收益（摘要未给具体数值），23 位作者、production setup。

INSIGHT跳出“LLM 直接当 ranker”的惯性，把 LLM 定位成产出 advertiser 维度先验的互补预测器，与既有排序链路解耦，降低在线推理压力。对广告/推荐团队提供了一条 LLM 增量接入路径：不替换主排序模型，只补充难以由 ID 特征学到的语义先验。

LRanker: LLM Ranker for Massive Candidates

LLM 排序受上下文长度与算力限制，难以应对百万级候选池。LRanker 面向大候选排序：candidate aggregation encoder 用 K-means 聚类显式建模全局候选信息；graph-based test-time scaling 把候选切分为子集、生成多个 query embedding 并通过集成融合。RBench 7 任务/3 场景评测：RBench-Small >30% 提升，RBench-Large MRR +3~9%，RBench-Ultra（>680 万候选）仍保持 20~30% 提升，消融验证各组件有效。

INSIGHT关键是“聚合多个 query embedding 而非依赖单一表征”以提升鲁棒性与表达力，并用 K-means 全局建模+图划分把 LLM 排序扩展到百万级。test-time scaling 走推理期增算力换效果，落地需权衡延迟成本，更适合离线或对延迟不敏感的粗排环节。

Ocean4Rec: Offline LLM-Derived OCEAN Profiles for Request-Time VOD Reranking

SSamsung

工业 VOD 推荐需要更丰富的内容理解，但 LLM-as-reranker 每请求都要重复 prompt 构造、token 生成、模型调用、解析与兜底，在高并发低延迟服务里难做吞吐规划与尾延迟控制。Ocean4Rec 只在离线用 LLM 把物品内容元数据物化成 OCEAN（开放/尽责/外向/宜人/神经质）五维画像；用户画像由近期点击/深度访问物品在同一五维空间做时间衰减聚合。请求时只 join 预计算画像+基础打分+目录新鲜度做数值重排，不调 LLM。Samsung Smart TV VOD 日志上，相对更强的 Base+Recency 基线，NDCG@20 在 NCF 生成器 +7.6%、LightGCN +61.5%；HR@20 在 NCF 不确定、LightGCN +67.3%。

INSIGHT“LLM 只在离线物化画像、在线零 LLM 调用”是规避 LLM-as-reranker 延迟与容量隔离难题的实用模式，把语义理解成本前置到离线。用 OCEAN 五维做统一的物品/用户表征空间值得借鉴；但单数据集、HR@20 对 NCF 不确定，说明收益对弱基线/稀疏精确回放标签更明显。

Looking Farther with Confidence: Uncertainty-Guided Future Learning for Sequential Recommendation

序列推荐建模动态兴趣但受数据稀疏困扰。多数方法训练只做即时 next-item 预测，忽略更长期未来交互的信息；少数用未来数据的工作对所有样本施加均匀强度的未来监督，易得次优解。UFRec 提出自适应未来学习：Uncertainty-Guided Future Supervision 按模型对当前状态的置信度调节多步未来监督权重（置信则看更远、不确定则聚焦即时任务）；Future-Aware Contrastive Learning 把未来轨迹整体对待。两模块仅训练期生效、无推理开销，四个基准上显著超过 SOTA（摘要未给具体数值）。

INSIGHT把“未来监督强度”做成随模型置信度自适应而非固定，是对已有 future-data 方法的针对性改进；训练期增强、推理零开销对线上序列模型友好。思路可迁移到任何带长期未来反馈的推荐序列建模。

Ziqiang Cui, Xing Tang, Xiuqiang He, Chen Ma, 等

Affective Music Recommendation: A Rollout-Based World Model for Offline Preference Optimization

LLUCID

功能性音乐（专注/助眠/临床干预）的推荐目标是听者的情感状态，但对情感做在线实验在伦理上受限（尤其无法可靠跳歌或报告不适的临床人群）。AMRS 部署在 LUCID 健康平台，核心是 rollout-based world model：因果 transformer 在日志收听数据上联合预测参与度、二元评分与自报 valence/arousal，既当离线策略训练的 in-silico 模拟器，也作上线前压测工具。推荐策略由行为克隆初始化，再用 DPO 针对可配置多目标效用函数离线微调。严格冷启动协议下 world model 对行为与情感信号都有可用保真度；DPO 在保持多样性、避免贪心优化的分布坍缩的同时提升预测 valence/arousal。

INSIGHT当在线实验不可行时，用因果 world model 当模拟器 + 离线 DPO 做策略优化，是一条“离线对齐多目标效用”的可复制方法论。对在线实验昂贵或受限的推荐场景（医疗、敏感人群）有参考价值；DPO 相比贪心优化能避免分布坍缩这点值得注意。

LiDDA: Data Driven Attribution at LinkedIn

LinkedIn

数据驱动归因(DDA)按从数据中学到的因果模式给营销触点分配转化信用，是现代营销智能与广告平台的基础。LiDDA 提出统一的 transformer 归因方法，可同时处理 member 级数据、聚合级数据以及外部宏观因子的整合，并详述了在 LinkedIn 的大规模落地与显著业务影响，分享了对营销与广告技术广泛适用的经验。（v3 replace-cross，原始 2025-05 提交。）

INSIGHT用单一 transformer 统一 member 级/聚合级/宏观因子三类异构数据做归因，避免多套归因模型并存。对广告/增长团队的多触点转化归因有直接借鉴；注意这是 2025 年提交、近期更新的工作，非全新成果。
