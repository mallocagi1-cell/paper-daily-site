SSRLive: Live Streaming Recommendation with Dynamic Semantic ID

SSRLive 面向直播推荐，将生成式模块与判别式模块统一在一个架构里。生成式部分用 encoder-decoder 同时产出静态与动态 Semantic ID（SID），让 SID 能及时反映直播间内容的快速变化并融合多模态信息；判别式部分把 SID 与用户特征结合，再注入用户-主播交互信号（点赞、下单）做多任务预估。线上 A/B 显示观看时长 +3.38%、GMV +0.72%、关注数 +3.12%、互动量 +2.92%，已全量部署服务数亿日活用户。

Mind the Gap: Bridging Behavioral Silos with LLMs in Multi-Vertical Recommendations

DoorDash

针对 DoorDash 这类多业务线电商平台中生鲜、零售等新业务线的用户冷启动问题，论文提出用大模型做生成式推理，从用户在成熟业务线（餐饮）的下单与搜索历史中合成稀疏高维特征。具体用分层 RAG 管线抽取多级品类（taxonomic）特征，同时编码长期跨业务线偏好与短期意图，再注入生产环境的多任务学习（MTL）排序模型。离线与线上评测均显示新业务线的个性化与互动指标提升（摘要未给出具体数值）。

INSIGHT用 LLM 把数据丰富业务线的行为合成成跨业务线可迁移的品类级用户画像特征，是缓解新业务线冷启动的可落地思路。分层 RAG 抽取的多级 taxonomy 特征同时承载长短期偏好，作为稠密特征接入既有 MTL 排序模型，对现有 ranking 架构改动小。对社区搜索的启示：可借鉴成熟域行为→LLM 合成可迁移特征→注入排序模型的范式来缓解新内容/新用户冷启动。

Nimesh Sinha, Raghav Saboo, Martin Wang, Sudeep Das

PaperFlow: Profiling, Recommending, and Adapting Across Daily Paper Streams

PaperFlow 把科学论文推荐从固定候选集上的静态排序重构为日级、纵向的过程，分为三个耦合阶段：Profiling 从异构冷启动证据构建可检视的结构化学者画像；Recommending 在固定展示预算下对每日论文流做多信号聚合排序；Adapting 从语义不同的反馈信号更新用户状态并建模跨天兴趣漂移。论文还定义了固定用户、日期、候选池、可见输入与隐藏模拟相关性标签的纵向 user-day benchmark。

INSIGHT论文推荐的真实场景是每天到达的新论文流 + 持续累积的反馈 + 漂移的兴趣，PaperFlow 的 Profiling-Recommending-Adapting 三段式强调可检视的结构化用户画像与跨天兴趣漂移建模。对个性化系统的启示：长周期、流式内容场景下，用户状态需要随语义不同的反馈信号增量更新，固定展示预算下的多信号聚合排序更贴近线上约束。

Bradley-Terry Rankings for Recommender Systems Across Dataset Taxonomies

推荐算法排名对数据集特性（稀疏度、序列结构、规模）敏感，简单地对 NDCG 等指标跨基准平均会得到误导性排名。论文提出基于 Bradley-Terry（BT）模型的数据驱动排名方法，证明所得排名依赖关键数据集统计量；并提出一个评估排名一致性的新指标，验证其对不完整数据的鲁棒性；进一步给出在未见数据集上无需实际运行算法即可排名的数据集相关方法。

INSIGHT用 BT 这种成对比较模型替代跨基准平均指标来给推荐算法排序，能显式刻画排名对数据集统计量的依赖，是模型选型方法论上的改进。提出的排名一致性指标与未见数据集上的预测式排名对工程选型有参考价值——可在不跑全量实验的情况下预估算法在新数据分布上的相对优劣。对实践的启示：模型选型评测应考虑数据集特性差异，避免被平均指标误导。

Re-Centering Humans in LLM Personalization

多数 LLM 个性化评测依赖合成数据，真实用户上的表现不明。论文采集真实人类对话（550 段）与三阶段判断：从对话中抽取用户属性（5949 条判断）、把相关属性与新 prompt 配对（11919 条）、把相关属性融入个性化回复（1101 条）。引入人类数据后暴露出系统在每个阶段的局限：模型难以从真实对话抽取属性、与人类对相关属性的判断存在分歧、生成的个性化回复人类并不买账。

INSIGHT用合成数据评测 LLM 个性化会高估真实表现——属性抽取、相关属性匹配、个性化生成三个环节在真实人类数据上都出现明显退化。论文的三阶段拆解（抽取→匹配→融入）给个性化评测提供了可操作的诊断框架。对搜索/推荐中引入 LLM 个性化的启示：评测必须用真实用户数据，并分阶段定位失效环节，警惕合成数据带来的乐观偏差。

Lechen Zhang, Jiarui Liu, Tal August
