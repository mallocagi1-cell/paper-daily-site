Zero-shot Cross-domain Knowledge Distillation: A Case study on YouTube Music

本文研究跨域知识蒸馏（KD）在推荐系统中的应用，将 YouTube 大规模视频推荐平台（100倍数据量）的排序知识迁移至 YouTube Music 音乐推荐场景。核心挑战在于源域与目标域的特征空间、用户界面和预测任务存在显著差异。作者提出零样本跨域 KD 方法，无需目标域数据即可从教师模型提取知识，评估了多种 KD 技术（包括 logit 蒸馏、特征蒸馏等）在多任务排序模型上的效果，并提供了线上 A/B 实验结果，验证了该方法在低流量推荐系统中的可行性和效果。

MemRerank: Preference Memory for Personalized Product Reranking

📖 深度解读 · 7 分钟 →

针对 LLM 购物代理中用户历史记录过长、噪声大、与当前查询相关性低等问题，提出 MemRerank 偏好记忆框架。该方法将用户购买历史蒸馏为简洁的、与查询无关的偏好信号，用于个性化商品重排序。构建了基于 LLM 的 1-in-5 选择任务的端到端评测框架，并使用强化学习（RL）训练记忆提取器，以下游重排序性能作为反馈信号。实验表明，MemRerank 在两个 LLM 重排序器上均优于无记忆、原始历史和通用记忆基线，1-in-5 准确率提升高达 +10.61 个绝对百分点。

INSIGHT用户偏好的「蒸馏式记忆」是解决 LLM 个性化的一个优雅方案：与其将冗长的行为序列直接塞入 prompt，不如先提取用户级别的结构化偏好表示。RL 训练记忆提取器的思路值得借鉴——将下游任务指标直接作为记忆质量的优化目标。在社区搜索场景中，可以类比为从用户历史搜索和互动记录中提取偏好摘要，用于重排序个性化。

Zhiyuan Peng, Xuyang Wu, Huaixiao Tou, Yi Fang, Yi Gong

GISTBench: Evaluating LLM User Understanding via Evidence-Based Interest Verification

提出 GISTBench 评测基准，专门评估大语言模型从推荐系统用户交互历史中理解用户兴趣的能力。与传统关注物品预测准确率的基准不同，GISTBench 评估 LLM 能否从用户行为数据中提取和验证兴趣标签。引入两个新指标族：Interest Groundedness（兴趣扎根度，分为精度和召回率衡量幻觉和覆盖度）和 Interest Specificity（兴趣特异性，评估预测的用户画像是否具有区分度）。在全球短视频平台的真实用户交互数据上构建合成数据集，包含隐式和显式参与信号，并通过用户调查验证数据保真度。评测了 8 个 7B 到 70B 的开源 LLM。

INSIGHTGISTBench 揭示了 LLM 做用户画像时的核心问题——容易产生兴趣幻觉（hallucinated interests），即预测出用户实际不感兴趣的类别。Interest Groundedness 指标的精度/召回率分解设计非常实用，可以帮助搜推团队量化评估 LLM 用户理解模块的可靠性。对于社区搜索中基于 LLM 的用户画像和个性化功能，这个评测框架可以直接用于检验模型的用户理解质量。

Aligning Multimodal Sequential Recommendations via Robust Direct Preference Optimization with Sparse MoE

系统研究了直接偏好优化（DPO）在隐式反馈下的多模态序列推荐中的行为。核心发现是：将确定性硬负样本替换为从动态 top-K 候选池中的随机采样，能持续提升排序性能。原因有二：（1）减少假负样本导致的错误抑制梯度；（2）在保留信息量较大的硬信号同时，通过受控随机性平滑优化过程。可选的稀疏 Mixture-of-Experts（MoE）模块进一步提升多模态融合效果。实验在多个多模态序列推荐数据集上系统比较了不同负样本选择策略与 DPO 训练的交互效果。

INSIGHTDPO 在推荐系统隐式反馈场景下的负样本策略至关重要——简单的硬负样本会引入大量假负样本噪声。随机化 top-K 采样策略既保留了困难负样本的信息量，又避免了假负样本问题，这一发现对搜索排序中使用对比学习或偏好学习的场景有直接借鉴意义。稀疏 MoE 在多模态推荐中的应用也值得关注，它在不显著增加推理开销的情况下提升了模型容量。

Hejin Huang, Jusheng Zhang, Kaitong Cai, Jian Wang, Rong Pan

ShapE-GRPO: Shapley-Enhanced Reward Allocation for Multi-Candidate LLM Training

MIT

在推荐、头脑风暴、代码建议等场景中，LLM 需要生成候选集合并最大化集合整体效用。但现有 RL 训练范式（如 GRPO）对集合中每个候选分配相同的标量奖励，导致低质量候选「搭便车」于高质量候选的高奖励，训练信号噪声大。本文提出 ShapE-GRPO，利用博弈论中 Shapley 值的排列不变性，将集合级奖励分解为候选粒度的信号。Shapley 增强的公式化能够识别每个候选对集合整体效用的边际贡献，实现更精确的奖励分配和更高效的策略探索。

INSIGHTShapley 值在 LLM 推荐训练中的应用揭示了一个被忽视的问题：集合级奖励的粗糙分配会严重影响 RL 训练效率。这个思路可以直接迁移到搜索排序场景——例如在使用 LLM 生成多个搜索结果摘要或推荐列表时，需要区分每个结果对整体用户满意度的贡献。从博弈论视角设计奖励信号，比简单的 pointwise 或 listwise 方法更能捕捉候选间的交互效应。

Rui Ai, Yu Pan, David Simchi-Levi, Chonghuan Wang

Cold-Starts in Generative Recommendation: A Reproducibility Study

University of AmsterdamShandong University

对基于预训练语言模型（PLM）的生成式推荐在冷启动场景下进行了系统性的可复现性研究。冷启动包括用户冷启动（新注册用户）和物品冷启动（新上架物品）两种场景。研究发现，现有生成式推荐器虽然利用物品语义信息（标题、描述）有望缓解冷启动，但冷启动很少被作为主要评估设置，且关键设计选择（模型规模、标识符设计、训练策略）往往同时变化，使得已报告的效果难以解释。本文统一了冷启动评估协议，系统分离了各设计因素的影响。

INSIGHT可复现性研究揭示了生成式推荐冷启动效果的「归因模糊」问题——许多论文声称的冷启动改进可能来自于模型规模增大而非方法本身。统一评估协议的实践价值在于帮助业界清晰判断哪些技术真正有效。对于社区搜索中的新用户/新内容冷启动，这些发现提醒我们需要在受控条件下评估个性化方法，避免被混杂因素误导。

Zhen Zhang, Jujia Zhao, Xinyu Ma, Xin Xin, Maarten de Rijke, Zhaochun Ren

Drift-Aware Continual Tokenization for Generative Recommendation

生成式推荐采用两阶段流水线：可学习 tokenizer 将物品映射为离散 token 序列（标识符），自回归模型基于标识符做预测。近期方法引入协同过滤信号让相似行为模式的物品获得相似编码。然而现实环境持续演化：新物品导致标识符碰撞和漂移，新交互导致协同信号漂移（共现模式和流行度变化）。全量重训代价高昂，而朴素微调会改变大量已有物品的 token 序列，破坏模型已学习的 token-embedding 对齐关系。本文提出漂移感知的持续 tokenization 方法，平衡可塑性和稳定性。

INSIGHT协同信号漂移是生成式推荐实际部署中的关键挑战——用户行为模式的变化会导致 tokenizer 编码空间失效。本文的漂移感知方法提出了「选择性重编码」策略，仅更新漂移显著的物品编码。这个思路对于搜索推荐系统中的 embedding 持续更新也有启示：不必全量重训 embedding，而是检测和定向更新漂移最大的部分。

Yuebo Feng, Jiahao Liu, Mingzhe Han, Dongsheng Li, Hansu Gu, Peng Zhang, Tun Lu, Ning Gu

Xuanwu: Evolving General Multimodal Models into an Industrial-Grade Foundation for Content Ecosystems

提出 Xuanwu VL-2B 多模态基础模型，专为内容生态系统打造。采用紧凑的 InternViT-300M + MLP + Qwen3 1.7B 架构（约 2B 参数），在细粒度视觉感知、语言语义对齐和部署成本间取得平衡。通过三阶段渐进训练（预训练、中期训练、后训练）和数据迭代筛选机制，实现了业务专业化与通用能力保持的平衡。针对内容审核和对抗场景中主流模型泛化退化和灾难性遗忘的问题，Xuanwu 在长尾噪声和细粒度视觉理解上取得显著改进。

INSIGHT从通用多模态模型到工业级垂直模型的演化路径值得借鉴：三阶段渐进训练 + 数据迭代筛选是在保持通用能力的同时适配业务需求的有效范式。2B 参数量级的模型在部署成本和效果间的权衡点对搜索推荐场景有参考价值——在内容理解（用于物品理解和用户画像辅助）场景中，紧凑模型可能比大模型更适合在线服务。

UniRank: End-to-End Domain-Specific Reranking of Hybrid Text-Image Candidates

针对多模态重排序中文本和图像候选混合的场景，提出 UniRank 框架。核心问题是模态偏差（modality gap）：文本重排序器天然偏向文本候选，导致跨模态排序效果不佳。现有 VLM 重排序器将所有候选编码为图像，对文本候选引入计算开销；且通用域训练数据在垂直场景表现不佳。UniRank 基于 VLM 构建，原生处理文本和图像混合候选，支持端到端的域特定微调。在多个垂直领域数据集上验证了效果。

INSIGHT多模态搜索重排序中的模态偏差是一个实际但常被忽视的问题。UniRank 的域特定微调方案提醒我们：在社区搜索中，当搜索结果包含图文混合内容（如图片帖、文字帖）时，需要特别注意排序模型对不同内容形式的公平性。VLM 作为统一的跨模态排序器是一个值得探索的方向。

Yupei Yang, Lin Yang, Wanxi Deng, Lin Qu, Shikui Tu, Lei Xu

Pseudo Label NCF for Sparse OHC Recommendation: Dual Representation Learning and the Separability Accuracy Trade off

研究极端交互稀疏场景下的推荐问题。在在线健康社区中，每位用户仅提供 16 维入口向量，每个支持小组有结构化特征。扩展 NCF 架构（MF、MLP、NeuMF），引入基于特征余弦相似度的伪标签辅助目标，学习双重嵌入空间：主嵌入用于排序，伪标签嵌入用于语义对齐。在 165 用户 × 498 小组的数据集上，留一法评估显示伪标签变体显著提升排序性能。研究还揭示了嵌入空间可分离性与排序准确率之间的权衡关系。

INSIGHT极端冷启动场景下的双重嵌入空间设计思路有一定借鉴价值：主嵌入负责排序优化，辅助嵌入负责语义对齐，通过伪标签桥接两者。在社区搜索冷启动阶段，可以考虑利用用户注册信息或初始偏好调查构建类似的辅助监督信号，加速个性化推荐的建立。

Pronob Kumar Barman, Tera L. Reynolds, James Foulds
