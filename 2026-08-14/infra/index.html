Previewing Ultrafast mode: GPT-5.6 Sol at up to 14X the speed

OpenAI 公布 Ultrafast API 服务层，为 GPT‑5.6 Sol 提供最高 14× 加速，输出速度可达 750 tokens/s，底层由 Cerebras 提供算力。它不是新模型训练方法，而是把高吞吐推理资源包装成可直接调用的服务档位，适合需要低延迟 query 改写、重排解释或在线 Agent 的场景。

Retrofitting Recurrent Depth into a Pretrained Language Model: Installation, Extrapolation, Transfer, and Retention at Two Parameter Budgets

论文把 Qwen2.5‑0.5B‑Instruct 拆成 Prelude、权重共享 Recurrent Block 与 Coda，以循环深度替代堆叠参数；冻结底座时只训练 6M 参数，全块训练为 180M。适配器整体准确率 83.8% 对 84.0%，深度 10 后仍保留 53% 对照 2.5% 的能力，并快 7.6×。

INSIGHT它给搜索/推荐基础模型提供了“固定参数、增加内部计算步”的效率路径：可把循环块放到 query 理解或难例重排的慢通道，按请求难度动态决定深度。需要警惕超过训练深度后的退化，以及反向规则学习引发的灾难性干扰；上线应设置深度上限和回退模型。

Defending against Model Extraction for GNNs with Model Reprogramming

GraphRP 面向 MLaaS 黑盒 GNN 的模型抽取攻击，提出由可学习拓扑原型驱动的结构感知门控，把模型重编程噪声变成动态“结构防火墙”。方法在保持正常查询效用的同时，沿对抗扰动方向放大 Fisher 信息，并在 hard-label 与 soft-label 两类攻击下验证防护效果；论文已被 KDD 2026 接收。

INSIGHT社区搜索的 embedding、召回和重排服务一旦以 API 形式暴露，也存在蒸馏、探测和模型抽取风险。可借鉴其“正常流量保真、异常查询结构化扰动”的分层策略，把查询频率、候选分布漂移和相似度探针作为安全信号，并将攻击成功率与 nDCG 损失一起纳入发布门禁。

ODE-Based Transformer Decoders for Iterative Sign Language Translation

论文不增加 Transformer 解码器参数，而把迭代式残差更新重写为 ODE 数值积分，用 RK‑2/RK‑4 替代普通一步更新。RK‑2 在 PHOENIX‑2014‑T 与 CSL‑Daily 上分别达到 22.96 和 19.34 BLEU‑4，并在 CSL‑Daily 用更少解码层与 refinement 迭代超过 IPSLT 基线。

INSIGHT对线上排序或向量编码服务，参数量不是唯一成本，更新动力学和函数调用次数同样决定延迟。可把高阶更新作为小模型质量增强模块，在离线先比较质量/显存/函数调用三维曲线；若每步多次计算抵消了少层收益，就应只部署在低并发或难例流量。

Grounding at scale: Engineering the retrieval system for the agentic web

Microsoft

Microsoft 将 grounding 明确放进 Agent 的 inference loop，介绍一个 model‑agnostic、MCP‑native 的生产检索层，把证据获取、模型调用和工具执行放在同一服务边界内。文章面向 Copilot 及企业系统，重点讨论检索层如何在多模型、多工具场景持续提供可追溯上下文；文中未给出可复现实验指标。

INSIGHT社区 UGC 搜索可以借鉴“检索是推理环节”的架构边界：召回结果、过滤理由、文档版本和引用片段都应成为可观测状态，而不是隐藏在 Prompt 中。落地时建议把 freshness、证据覆盖率、工具失败率与 nDCG/CTR 统一打点，并允许在证据不足时降级到传统检索。

Diffuse to Compress: Leveraging Diffusion LMs for Lossless Compression

论文针对神经文本压缩中“压缩率高但逐符号自回归吞吐低”的矛盾，把扩散语言模型引入无损压缩，并设计适配 DLM 多位置、多符号编码的策略。在 enwik8 上与 zstd、gzip、bzip 3 类通用压缩器及 LLM 压缩方案比较，结果显示 DLM 路线可提升无损文本压缩的状态，但工程吞吐仍是关键问题。

INSIGHT它对搜索基础设施的启示不是立刻替换压缩库，而是把“存储率—解码吞吐—随机访问”作为联合目标。UGC 索引和长文档缓存可先在离线归档层试验神经压缩，在线倒排、向量和 rerank 特征仍应优先采用可预测延迟的传统编码。

Angelo Nardone, Paolo Ferragina

Easper: An Accessible ASR Pipeline for Language Documentation

Easper 是面向语言记录的开源、无代码 ASR 工作流：从 ELAN 标注直接调用云资源迭代微调，并把冷启动时“先转录哪些录音”纳入管线设计。作者在 Bislama、Nafsan、Nguna 3 种瓦努阿图语言上比较声学干净度与词汇丰富度优先策略，用 Character Error Rate 轨迹评估数据选择。

INSIGHT这类“数据选择—训练—评估—再选择”的闭环可迁移到社区搜索的 embedding 和 reranker 更新。相比一次性全量重训，更实际的做法是按难例覆盖、长尾 query 和标注信息增益选样，并把每轮 CER 类似的离线相关性曲线接入模型注册与回滚流程。

Aso Mahmudi, Ting Dang, Ekaterina Vylomova, Nick Thieberger

LLM Inference Serving 2026 — Comparing vLLM, SGLang, and TensorRT-LLM

这篇工程对比围绕 vLLM、SGLang、TensorRT‑LLM 3 个常用推理引擎，整理连续批处理、前缀缓存、量化、OpenAI 兼容接口和分布式推理 5 类能力。它适合作为选型清单，但不是统一硬件、统一模型和统一负载下的可复现实验，因此不能直接把文中的框架排序当成生产结论。

INSIGHT搜索团队选推理引擎时应先定义负载画像：短 query 高并发、长上下文低并发、批量离线 embedding 的最优解不同。建议用真实流量回放比较 TTFT、TPOT、p99、KV cache 命中率、显存碎片和故障恢复时间，再以模型覆盖度与升级成本做第二层决策。
