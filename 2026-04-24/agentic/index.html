LiteResearcher: A Scalable Agentic RL Training Framework for Deep Research Agent

本文提出 LiteResearcher，一个面向 Deep Research Agent 的可扩展强化学习训练框架。核心创新在于构建轻量级虚拟世界（lite virtual world）来模拟真实搜索动态，解决了 Agentic RL 训练中合成数据无法激发真实搜索能力、而依赖真实搜索又导致不稳定和高成本的两难困境。仅 4B 参数的 LiteResearcher-4B 在 GAIA 和 Xbench 基准上分别达到 71.3% 和 78.0%，超越了通义 DeepResearch 和 Claude-4.5 Sonnet 等大规模模型。

Stanford

SWE-chat ��首个大规模真实编码 Agent 交互数据集，从开源开发者的实际使用中采集。数据集揭示了用户如何与 AI 编码 Agent 交互、Agent 输出中多少内容在实践中真正有用等关键问题。研究发现真实用户行为与实验室基准存在显著差异，为 Agent 设计提供了宝贵的实证依据。

A Reproducibility Study of Metacognitive Retrieval-Augmented Generation

本文系统复现了元认知 RAG（Metacognitive RAG）方法，研究在多跳问答场景中 Agent 何时应停止检索。该方法让模型具备自我评估能力，判断已检索信息是否足够回答问题，从而避免过度检索或检索不足。实验覆盖多个多跳 QA 基准，验证了元认知停止策略的有效性和可复现性。

INSIGHT元认知检索策略（Agent 自主判断何时停止搜索）是提升多轮检索效率的关键。对搜索系统的直接启示：在多轮检索场景（如复杂 query 的多步召回）中，引入自我评估机制可以显著减少冗余检索步骤，同时保证回答质量。这种 know when to stop 的思路可直接应用于 UGC 搜索的多轮召回优化。

Gabriel Iturra-Bocaz, Petra Galuscakova

SkillLearnBench: Benchmarking Continual Learning Methods for Agent Skill Generation on Real-World Tasks

SkillLearnBench 是首个面向 LLM Agent 持续技能学习的评测基准。Skills 已成为 LLM Agent 执行复杂任务的标准方式（通过定制指令、工作流和工具），但如何自动且有效地学习新技能仍是开放问题。该基准评估了多种持续学习方法在真实任务上的 Agent 技能生成能力。

INSIGHTAgent 技能的持续学习是构建实用搜索/推荐 Agent 的核心挑战之一。该基准的建立表明：Agent 不能仅靠预训练知识，还需在部署后持续学习新技能。对实践的启示：搜索 Agent 应设计为可扩展的技能框架，支持在线新增搜索策略、召回方法等新技能，而非固定能力集。

Shanshan Zhong, Yi Lu, Jingjie Ning, Yibing Wan, Lihan Feng

Deep Researcher Agent: An Autonomous Framework for 24/7 Deep Learning Experimentation with Zero-Cost Monitoring

本文提出一个自主深度学习实验框架，让 LLM Agent 全天候自动执行实验。核心创新包括：零成本训练监控、约 5K 字符的内存约束架构、以及每 worker 3-5 个工具的多 Agent 设计，将 token 开销降低 73%。系统在 30+ 天内完成 500+ 实验循环，单项目通过 200+ 自动实验获得 52% 改进，单日运行成本仅 $0.08。

INSIGHT该框架展示了 Agent 在持续实验中的实用性设计原则：内存约束避免上下文爆炸、多 Agent 分工降低 token 成本、零成本监控实现长期运行。对搜索/推荐团队的启示：可借鉴此架构设计自动化 A/B 实验 Agent，通过 Agent 自动调参、监控在线指标、迭代优化搜索/排序模型，极大降低人工实验成本。

Xiangyue Zhang

SweRank: Software Issue Localization with Code Ranking

SalesforceUIUC

SweRank 针对软件 Issue 定位任务，将自然语言 issue 描述（bug 报告、功能请求）映射到精确代码位置（文件、类、函数）。该方法将问题建模为代码排序任务，结合多步推理和检索策略实现 Agent 式的 issue 定位。来自 Salesforce 和 UIUC 的团队验证了该方法在标准基准上的有效性。

INSIGHT将代码 issue 定位建模为排序问题的思路可迁移到搜索场景：类似于从自然语言 query 定位相关文档，SweRank 的多步检索和排序策略对复杂 query 理解有借鉴意义。Salesforce 的工业背景也增加了该方法的可信度。

Do Hallucination Neurons Generalize? Evidence from Cross-Domain Transfer in LLMs

本研究发现 LLM 中存在一组稀疏的幻觉神经元（H-neurons），仅占 FFN 神经元的不到 0.1%，能可靠预测模型何时会产生幻觉。更重要的发现是这些 H-neurons 具有跨领域泛化能力：在通用知识 QA 上识别的幻觉神经元，同样适用于其他领域。

INSIGHT幻觉检测对 Agentic RAG 系统的可靠性至关重要。如果 Agent 在多步推理中产生幻觉，错误会沿推理链放大。H-neurons 跨域泛化的发现意味着：可以在通用数据上训练幻觉检测器，然后直接应用于搜索/推荐的垂直领域，为搜索 Agent 增加低成本的幻觉防护层。

Snehit Vaddi, Pujith Vaddi

ESGLens: An LLM-Based RAG Framework for Interactive ESG Report Analysis and Score Prediction

ESGLens 是一个基于 LLM 的交互式 RAG 框架，用于 ESG（环境、社会、治理）报告的分析和评分预测。面对 ESG 报告篇幅长、内容异构、缺乏标准化结构的挑战，该框架实现了自动化分析和交互式查询，降低了人工分析的成本和不一致性。

INSIGHTESGLens 展示了 RAG 在垂直领域长文档分析中的完整设计模式：处理异构内容、交互式查询、以及结构化评分输出。对 UGC 搜索的借鉴：社区内容同样具有异构性和缺乏标准化的特点，其交互式分析和自动评分思路可用于社区内容质量评估和搜索排序。

Tsung-Yu Yang, Meng-Chi Chen

LLM Agents Predict Social Media Reactions but Do Not Outperform Text Classifiers: Benchmarking Simulation Accuracy Using 120K+ Personas of 1511 Humans

本文基于 120K+ 个人物画像和 1511 名真实用户，系统评估了 LLM Agent 模拟社交媒体用户反应的准确性。研究发现 LLM Agent 能够预测社交媒体反应，但在准确度上并未超越传统文本分类器。实验规模大（120K+ personas）、方法严谨，提供了 Agent 模拟真实用户行为的可靠基线。

INSIGHTLLM Agent 模拟用户行为有其上限：在大规模评测中不如专业分类器。对搜索/推荐系统的启示：虽然 LLM Agent 可用于模拟用户进行离线测试，但不应过度依赖 Agent 模拟替代真实用户反馈。在搜索质量评估中，LLM Agent 评估可作为补充但非替代人工标注。

Enhancing Research Idea Generation through Combinatorial Innovation and Multi-Agent Iterative Search Strategies

本文提出组合创新与多 Agent 迭代搜索策略相结合的方法来增强科研创意生成。面对科学文献爆炸式增长带来的知识过滤成本上升，该方法通过多个 Agent 协同搜索和迭代筛选，帮助研究者从海量文献中发现新颖的研究方向。

INSIGHT多 Agent 迭代搜索的架构设计（多个 Agent 分工协作、迭代精化搜索结果）可迁移到搜索系统场景：例如用不同 Agent 负责 query 理解、召回、重排序等环节，通过迭代交互提升复杂 query 的搜索质量。组合创新思路也适用于搜索策略的自动发现。
