Optimizing Generative Ranking Relevance via Reinforcement Learning in Xiaohongshu Search

提出一种将相关性建模形式化为多步推理任务的强化学习范式。将领域特定的相关性标准嵌入结构化 prompt，并提出 Stepwise Advantage Masking (SAM) 实现步级别的 credit assignment，使生成式排序模型能够更精准地学习相关性判断。该方法已在小红书搜索系统中部署。

KuaiSearch: A Large-Scale E-Commerce Search Dataset for Recall, Ranking, and Relevance

Kuaishou

发布目前规模最大的电商搜索数据集 KuaiSearch，基于快手真实用户搜索交互构建。包含约 33 万用户、1800 万商品、250 万真实搜索 query，覆盖召回、排序、相关性判断三个搜索链路阶段，同时包含冷启动用户和长尾商品场景。

INSIGHT首个同时覆盖搜索全链路（召回→排序→相关性）的大规模真实数据集，且保留了模糊 query、噪声商品文本、多样用户偏好等真实场景难点，为搜索算法的端到端研究和评测提供了标准化基准。

业务关联快手作为 UGC 短视频平台，其搜索场景（短文本 query、用户意图模糊、内容质量参差）与社区搜索非常相似。该数据集可用于评测我们的召回和排序模型，也可作为迁移学习的预训练数据源。

证据数据集规模：33 万用户、1800 万商品、250 万 query。已开源发布在 GitHub (github.com/benchen4395/KuaiSearch)，包含完整的数据字段和评测基准。

Automatic In-Domain Exemplar Construction and LLM-Based Refinement of Multi-LLM Expansions for Query Expansion

提出一个全自动化、域自适应的 query 扩展框架。通过 BM25-MonoT5 管线构建领域内示例池，利用聚类策略选择多样化的 demonstration。核心创新是双 LLM 集成：两个异构 LLM 独立生成扩展，再由一个精炼 LLM 合并和过滤，无需任何人工标注或手写 prompt。

INSIGHT双 LLM 集成 + 自动示例构建的组合解决了 LLM query 扩展的两大痛点：(1) 手动 prompt 工程不可扩展；(2) 单一 LLM 对领域偏移敏感。这种 training-free 的方案对短文本 UGC 搜索中的 query 理解不足问题有直接帮助。

业务关联社区搜索中用户 query 往往很短（2-5 个词），语义不完整，query 扩展是提升召回率的关键手段。该框架无需训练即可适配新领域，适合快速验证 LLM 在 query 扩展上的效果。

证据在 TREC DL20、DBPedia、SciFact 三个数据集上，精炼后的集成方案相比 BM25、Rocchio、零样本和固定 few-shot 基线均取得一致且统计显著的提升。

Minghan Li, Ercong Nie, Siqi Zhao, Tongna Chen, Huiping Huang, Guodong Zhou

Exploring the Effectiveness of Multi-stage Fine-tuning for Cross-encoder Re-rankers

系统性研究了 Cross-encoder 重排序模型的单阶段与多阶段微调策略。对比了对比学习目标与 LLM 教师排序蒸馏两种方法，在 BERT 到 ModernBERT 多种骨干网络上进行了全面实验。结论是：单阶段对比学习的效果与多阶段方法相当。发表于 ECIR 2025。

INSIGHT多阶段微调（先蒸馏再对比学习）未必优于简单的单阶段对比学习——这是一个重要的负面结果。对于搜索工程师而言，这意味着可以简化重排序模型的训练流程，无需复杂的多阶段 pipeline。

业务关联Cross-encoder 重排序是搜索排序 pipeline 的关键组件。该研究表明在训练 reranker 时不必追求复杂的多阶段策略，对比学习即可达到最优效果，这有助于简化我们的模型训练流程。

证据在 TREC DL 基准上跨 BERT、RoBERTa、ModernBERT 等多种骨干网络进行了系统实验。代码已开源 (github.com/fpezzuti/multistage-finetuning)。论文经 ECIR 2025 同行评审。

Francesca Pezzuti, Sean MacAvaney, Nicola Tonellotto

Still Fresh? Evaluating Temporal Drift in Retrieval Benchmarks

研究时间漂移对检索基准的影响。对比 FreshStack 检索基准在 2024 年 10 月与 2025 年 10 月两个独立语料快照上的表现，发现相关文档会在仓库间"迁移"（如从 LangChain 到 LlamaIndex），但模型排名仍高度相关（Kendall τ 达 0.978@Recall@50），表明经时间漂移重新标注的基准仍可靠。

INSIGHT虽然技术语料库随时间快速变化（API 弃用、代码重构），但检索模型的相对排名基本稳定。这为我们使用"较旧"的检索评测集提供了信心——不需要频繁更新评测数据即可做出有效的模型选择决策。

业务关联社区搜索的评测集同样面临内容更新快的挑战。该研究表明，即使评测语料与线上数据有时间差，离线评测的模型排序结论仍然可信，有助于我们建立稳定的离线评测体系。

证据对比 FreshStack 两个时间快照，覆盖多个检索模型。所有 query 在新版语料中仍有对应文档（仅 1 个例外），模型排名相关性 Kendall τ 高达 0.978@Recall@50。

Nathan Kuissi et al.

Autoregressive Ranking: Bridging the Gap Between Dual and Cross Encoders

为自回归排序 (Autoregressive Ranking, ARR) 建立了严格的理论基础。证明 ARR 的表达能力严格优于双塔模型 (Dual Encoder)：双塔模型需要 embedding 维度随语料规模线性增长才能实现任意排序，而 ARR 仅需常数隐藏维度。同时指出标准 next-token prediction loss 对排序无感知，提出了新的 LLM 排序微调方法。

INSIGHT首次从理论上证明了自回归排序范式相对于双塔模型的本质优势——这解释了为什么 LLM-based ranking 能以更小的参数量实现更好的排序效果。对搜索系统架构选型（双塔 vs LLM 排序）有重要指导意义。

业务关联该理论结果为我们在搜索排序中引入 LLM-based autoregressive ranking 提供了理论依据。尽管目前 ARR 还不够实用，但其表达能力优势暗示这是排序模型的未来方向。

证据提供了严格的数学证明：DE 需要 O(N) 维 embedding 而 ARR 只需 O(1) 维隐藏层。理论分析辅以初步实验验证，但缺少大规模实验。

Benjamin Rozonoyer, Chong You, Michael Boratko et al.
