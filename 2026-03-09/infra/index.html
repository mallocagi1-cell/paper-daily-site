Qwen3 Embedding: Advancing Text Embedding and Reranking Through Foundation Models

阿里 Qwen 团队发布 Qwen3-Embedding 系列，提供 0.6B/4B/8B 三种规模的 Embedding 和 Reranking 模型。采用多阶段训练流程：大规模弱监督预训练 + 有监督微调 + 模型合并。支持 100+ 语言（含编程语言），可自定义指令以适配特定领域。8B 模型在 MTEB 多语言排行榜排名第一（70.58 分）。

PilotANN: Memory-Bounded GPU Acceleration for Vector Search

提出 PilotANN，一个面向图索引近似最近邻搜索的混合 CPU-GPU 系统。同时利用 CPU 的大内存和 GPU 的并行计算能力，在显存受限条件下实现大规模向量搜索的 GPU 加速。

INSIGHT传统 GPU 向量搜索受限于显存容量，PilotANN 通过 CPU-GPU 协同调度突破了这一瓶颈。对于搜索系统中的向量召回层，这意味着可以在不购买更多 GPU 显存的情况下处理更大规模的向量库。

业务关联社区搜索中语义召回依赖大规模向量检索，PilotANN 的内存受限 GPU 加速方案可以在现有硬件条件下显著降低向量搜索延迟，提升 p99 响应时间。

证据在大规模向量搜索基准上测试，实现了内存受限条件下的 GPU 加速。利用 CPU 大容量 RAM 与 GPU 并行能力的混合架构，适用于图索引的 ANN 检索场景。

Collaborative Speculative Inference for Efficient LLM Inference Serving

提出 CoSine 系统，将推测性解码中的顺序生成与并行验证解耦，使多个异构 GPU 节点能够高效协作完成大模型推理。专门针对 DeepSeek-R1（685B 参数、需 1500+ GB 显存）等超大 MoE 模型的多节点推理场景设计。

INSIGHTCoSine 解决了异构 GPU 集群部署超大模型的关键问题——通过将投机解码拆分为可并行的子任务分配到不同算力节点，大幅提升了多节点推理效率。这对使用混合硬件的团队尤其有价值。

业务关联若搜索系统引入大型 LLM（如 DeepSeek-R1）做查询理解或重排，CoSine 的异构集群推理方案可显著降低推理延迟和硬件成本，使大模型 serving 更经济可行。

证据针对 DeepSeek-R1（685B 参数）等超大 MoE 模型进行测试；在多节点异构 GPU 集群上实现显著加速；解耦投机解码与验证阶段的并行化设计。

Dynamic Model Routing and Cascading for Efficient LLM Inference: A Survey

综述了动态模型路由与级联推理的最新进展，覆盖基于查询难度评估、聚类、不确定性量化等多种路由范式。系统梳理了在保证推理质量的前提下降低 LLM 推理成本的各类策略。

INSIGHT将不同难度的请求路由到不同规模的模型是降低 LLM serving 成本的关键策略。本综述首次系统梳理了路由决策的各种范式——从简单的阈值到基于不确定性的方法——为工程落地提供了全景参考。

业务关联社区搜索中不同 query 的理解难度差异很大，简单 query 用小模型、复杂 query 用大模型的路由策略可以在保持搜索质量的同时大幅降低 GPU 推理成本，直接可用于 LLM 增强的搜索排序系统。

证据综述覆盖了多种路由范式（查询难度、聚类、不确定性量化、级联），涵盖最新研究进展。提供了各方法在成本-质量权衡上的系统比较。

Mist: Efficient Distributed Training of Large Language Models via Memory-Parallelism Co-Optimization

CCentML

提出 Mist 分布式训练系统，首次全面协同优化内存优化技术（activation checkpointing、参数卸载、优化器卸载）和并行策略（数据/张量/流水线并行）。发表于系统领域顶会 EuroSys'25，已开源。

INSIGHT现有分布式训练系统只优化部分技术子集，Mist 通过感知内存-重叠-不均衡三要素的全局协同搜索，打破了手工调优的天花板。其核心启示：训练优化需要系统级的联合搜索而非单点改进。

业务关联搜索/推荐模型训练（如 embedding 模型、排序模型微调）可以直接受益于 Mist 的自动化训练配置搜索，减少工程师手动调参时间，加速模型迭代周期。

证据发表于 EuroSys'25（系统顶会）；代码已开源（GitHub CentML/Mist）；支持各种内存缩减技术与并行策略的联合优化；采用细粒度重叠感知调度。

SpeCache: Speculative Key-Value Caching for Efficient Generation of LLMs

提出 SpeCache，利用 CPU 内存存放完整 KV Cache，在 VRAM 中保留低比特 KV 副本作为重要性估计。在每个解码步骤中投机性预测下一个 token 需要关注的 KV 对，提前从 CPU 预取，避免 CPU-GPU 通信带来的推理延迟。

INSIGHTSpeCache 巧妙地将 KV Cache 管理转化为「预测+预取」问题——用低精度副本在 GPU 上快速估计重要性，提前拉取高精度数据。这一思路可推广到所有需要在有限显存下处理大 KV Cache 的场景。

业务关联搜索系统若使用 LLM 做在线排序或查询理解，长序列推理的 KV Cache 管理是核心瓶颈。SpeCache 的投机预取方案可以在不增加 GPU 显存的前提下支持更长的上下文窗口。

证据利用 CPU-GPU 异构内存架构实现 KV Cache 管理；通过低比特副本进行重要性预测；投机预取避免通信延迟。

GPU-Accelerated Algorithms for Graph Vector Search: Taxonomy, Empirical Study, and Research Directions

对 GPU 加速的图索引向量搜索算法进行了全面的综述和实证研究。建立了详细的 GPU 优化策略分类体系，在 8 个大规模基准数据集上评估了 6 种主流算法，为向量搜索引擎的 GPU 加速选型提供了系统参考。

INSIGHT首个系统性评估 GPU 向量搜索算法的工作，覆盖了从内存管理到线程调度的全栈优化维度。对于搜索系统选择向量检索引擎的工程决策具有直接指导价值。

业务关联社区搜索的语义召回依赖高性能向量检索。本综述的 8 个数据集 × 6 个算法的全面评测，可帮助团队根据自身数据规模和延迟要求选择最优的 GPU 向量搜索方案。

证据在 8 个大规模基准数据集上评估 6 种 GPU 向量搜索算法；建立了从内存优化到线程调度的完整分类体系；提供了各算法的性能-精度权衡对比。

Bielik-Q2-Sharp: A Comparative Study of Extreme 2-bit Quantization Methods for a Polish 11B Language Model

对 6 种前沿的训练后量化方法（QuIP#、SpinQuant+GPTQ、ButterflyQuant、QTIP、VPTQ、AQLM）在极端 2-bit 精度下进行了全面对比评测。以波兰语 11B 模型为基准，系统评估了各方法在极低比特下的质量保持能力。

INSIGHT极端 2-bit 量化是将大模型部署到边缘设备的关键技术。本文首次在同一模型上横向对比 6 种方法，揭示了各方法在极低比特下的真实表现差异，为量化方案选型提供了可靠依据。

业务关联若需要将搜索排序模型或 query 理解模型部署到端侧或低资源环境，极端量化是必经之路。本文的对比结论可直接指导量化方案选择。

证据在 11B 参数模型上系统对比 6 种极端量化方法（QuIP#、SpinQuant+GPTQ、ButterflyQuant、QTIP、VPTQ、AQLM）；涵盖质量保持、压缩比等多维度评估。

SLO-Aware Compute Resource Allocation for Prefill-Decode Disaggregated LLM Inference

针对 Prefill-Decode 分离式 LLM 推理架构，提出了基于 SLO 约束的计算资源分配方法。结合理论建模（M/M/1 排队论）和实证基准测试，为确定 Prefill 和 Decode 阶段的最优硬件资源数量提供了系统方法论。

INSIGHTPD 分离是当前 LLM serving 的主流架构，但如何合理分配 prefill 和 decode 的 GPU 资源一直缺乏理论指导。本文用排队论建模提供了定量分析工具，让资源配置从经验驱动变为数据驱动。

业务关联搜索系统部署 LLM 时（如 query 理解、摘要生成），需要在吞吐量和延迟 SLO 之间权衡。本文的资源分配模型可直接用于 LLM serving 的容量规划。

证据提出基于 M/M/1 排队论的理论模型计算资源需求；结合实证基准验证模型准确性；覆盖吞吐量和 SLO 双重约束下的优化。

Mixture of Universal Experts: Scaling Virtual Width via Depth-Width Transformation

提出 Mixture of Universal Experts（MoUE），引入「虚拟宽度」这一新的 MoE 扩展维度。核心思想是复用跨层通用的专家池，将模型深度转化为虚拟宽度，在固定的单 token 激活预算下实现更高效的缩放。

INSIGHTMoUE 提出了 MoE 架构的新扩展方式——通过层间共享专家池将深度转化为宽度。这为大模型的参数效率和推理效率提供了新的权衡维度，可能影响未来 MoE 模型的设计范式。

业务关联MoE 架构是当前大模型（DeepSeek-V3、GLM-5 等）的主流选择。MoUE 的虚拟宽度概念可在不增加激活参数的情况下提升模型容量，对搜索/推荐系统中使用 MoE 模型的团队有参考价值。

证据在多个 scaling regime 下，MoUE 一致性地超越同等规模的 MoE 基线最多 1.3%；在固定单 token 激活预算下实现了更好的参数效率。
