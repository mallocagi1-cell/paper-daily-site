When Retrieval Metrics Mislead: Measuring Policy Signal in Long-Horizon Tool-Use Agents

论文质疑“检索召回率(exact-match recall)能代表检索内容对下游决策是否有用”这一常见假设。作者在 tau-bench 上用 Qwen2.5-3B/7B 做 action 前的策略分类：在金标准策略条件下，把原始轨迹换成紧凑的结构化状态后 macro-F1 提升 0.13–0.17；但当用检索 rank-1 的条款替换基准指定策略条款时，即便正确条款被检索到 rank-1，下游分类性能仍未对应提升，说明检索指标与真实策略信号之间存在脱节。

OpenThoughts-Agent: Data Recipes for Agentic Models

针对“如何为通用 agent 模型构造训练数据”这一公开度极低的问题，OpenThoughts-Agent(OT-Agent) 给出了一套完全开源的数据筛选管线，并做了 100+ 组受控消融，系统研究 agent 数据各环节（任务来源、轨迹生成、过滤、配比）的影响。区别于 SWE-Smith、SERA、Nemotron-Terminal 等只针对单一 benchmark 的工作，OT-Agent 目标是训练能跨多种 agentic 任务泛化的模型。

INSIGHT这是少见的把 agent 训练数据“配方”公开化、可复现的工作，100+ 消融厘清了哪些数据环节真正决定 agent 泛化能力。对要自建搜索/工具调用 agent 的团队，可直接借鉴其数据筛选与配比策略，避免在数据工程上重复踩坑。

Negin Raoof, Richard Zhuang, Marianna Nezhurina, Etash Guha, Atula Tejaswi

Qwen-AgentWorld: Language World Models for General Agents

Alibaba

提出语言世界模型(language world model)用于 agentic 环境模拟：基于当前观测与动作预测环境动态，作为推理与规划的核心认知机制。作者放出 Qwen-AgentWorld-35B-A3B 与 397B-A17B 两个 MoE 模型，是首个能通过长链思维(long CoT)模拟覆盖 7 个领域 agentic 环境的语言世界模型，训练使用了超过 10M 条环境交互数据。

INSIGHT世界模型可作为 agent 的“沙盒”，在不真实调用工具/环境的情况下做 reasoning 与 planning，对训练搜索 agent、做离线策略评估很有价值。但 35B/397B 的体量与 10M 级交互数据门槛较高，短期更适合作为研究参考而非直接落地。

Yuxin Zuo, Zikai Xiao, Li Sheng, Fei Huang, Jianhong Tu

Metis: Bridging Text and Code Memory for Self-Evolving Agents

针对自进化 agent 的经验记忆表示问题，Metis 做了首个受控研究，隔离“文本记忆”(注入上下文的自然语言经验)与“代码记忆”(暴露为可调用工具的经验)两种形式。现有系统通常在设计时就拍板用哪种，缺乏对二者权衡的理解；Metis 系统比较了两者的适用条件，并提出桥接文本与代码记忆的方法。

INSIGHT经验记忆“用文本还是用代码”不该拍脑袋决定，而应由经验本身的特性驱动：结构化、可复用的流程更适合代码记忆，开放语义的洞察更适合文本记忆。对构建带长期记忆的搜索/任务 agent，提供了可操作的记忆表示选型依据。

Zijie Dai, Siuhin He, Hui Li, Qihui Zhou, Jiajun Li, Mingcong Song, Guoping Long, Hongjie Si, Xin Ya...

EXPO-SQL: Execution-based Clause-level Policy Optimization for Text-to-SQL

Text-to-SQL 的 RL 方法普遍用 query 级统一奖励，对一条 SQL 里所有子句一视同仁，正确/错误子句拿同样奖励，导致正确 SQL 生成的学习信号不足。EXPO-SQL 提出基于执行的子句级(clause-level)策略优化，把执行反馈细化到子句粒度做信用分配，为正确子句生成提供更精准的奖励信号。

INSIGHT细粒度奖励/信用分配是 agentic RL 的通用难题，EXPO-SQL 的“子句级 reward shaping”思路可迁移到多步检索、工具链编排等场景——把稀疏的最终奖励拆解到中间步骤，缓解长程任务里学习信号稀疏的问题。

Jaehoon Lee, CheolWon Na, Suyoung Bae, Jin-Seop Lee, Jihyung Lee, YunSeok Choi, Jee-Hyong Lee

Escaping the Self-Confirmation Trap: An Execute-Distill-Verify Paradigm for Agentic Experience Learning

LLM agent 的经验自进化大多依赖单 agent 循环：同一个 agent 执行任务、总结结果、决定写入什么记忆，容易陷入“自我确认陷阱”——错误但自洽的轨迹被误判为成功经验，检索复用时累积放大错误。论文提出 EDV(Execute-Distill-Verify) 框架，用执行—蒸馏—验证三阶段、引入独立验证来保证经验可靠。

INSIGHT把“经验生成”和“经验验证”解耦、用独立 verifier 把关，是缓解 agent 记忆污染的关键设计。对线上自学习的搜索/推荐 agent，盲目把“看似成功”的轨迹写回记忆库风险很高，EDV 的验证环节值得在经验回写前引入。

Shiding Zhu, Yudi Qi, Yajie Wang, Jiaze Li, Chao Song

AGORA: An Archive-Grounded Benchmark for Agentic Workplace Document Reasoning

AGORA 是面向 agentic 工作场景文档推理的 benchmark：要求 agent 在大量杂乱的真实办公文档中定位稀疏证据、调和不一致的术语/单位/时间表述并计算答案。包含 362 个问题、8 个领域、共 9664 份真实文档，同时考察 archive-groundedness、agentic 探索与跨领域覆盖三方面，是现有 benchmark 未联合压测的设定。

INSIGHT对企业/社区内容搜索很有参考价值——真实场景的难点不是单文档问答，而是跨海量异构文档的证据定位与对齐。AGORA 把“在脏数据档案里做 agentic 检索”标准化，可用来评测自建文档搜索 agent 的鲁棒性与多跳证据整合能力。

Honglin Guo, Qi Zhang, Yu Zhang, Weijie Li, Rui Zheng

ReMMD: Realistic Multilingual Multi-Image Agentic Verification for Multimodal Misinformation Detection

多模态虚假信息检测面临新挑战：病毒式传播的帖子常混合长篇多语言叙述、多张图片、混杂来源与细微的图文框架错误。现有 benchmark 多只处理短标题、单图、二分类或单一篡改源。ReMMD 提出面向真实场景的多语言多图 agentic 验证框架，并构建 ReMMDBench 真实世界基准，让 agent 在可控成本下做证据搜索与验证。

INSIGHT社区/UGC 平台的内容治理正是多语言、多图、混杂来源的真实战场，ReMMD 的“agentic 验证”范式(主动检索外部证据再裁决)比静态分类器更贴合实际。对做 UGC 搜索与内容安全的团队，提供了可借鉴的取证式验证流程与评测基准。

Chenhao Dang, Dantong Zhu, Jun Yang, Conghui He, Weijia Li

Talos: Scaling rare disease diagnosis with automated, iterative genomic reanalysis

Microsoft

微软研究院开源系统 Talos 用于罕见病基因组诊断，主攻“人工复核耗时”这一瓶颈：通过自动化、迭代式的基因组再分析，在恢复 90% 范围内诊断(in-scope diagnoses)的同时，每位患者只需专家复核约 1.3 个候选变异，大幅压缩人工审阅量。

INSIGHT这是一个落地的 agentic 自动化案例——把专家高成本的迭代复核流程自动化，用“高召回 + 极低人工候选量”的设计平衡查全与人力成本。其“自动迭代再分析 + 把人留在关键决策点”的模式，对需要人机协同审核的搜索质检/内容审核流程有直接借鉴意义。

Are We Ready For An Agent-Native Memory System?

LLM agent 的记忆已从简单的检索增强演化为支持持久存储、检索、更新、整合与动态生命周期治理的数据管理系统，但现有评测仍主要用端到端任务指标(F1、BLEU)把记忆当黑盒，忽视了系统级关切。论文主张从“数据管理系统”视角审视 agent 记忆，指出当前评测在系统层面的盲点，并探讨 agent-native 记忆系统的设计要求。

INSIGHT把 agent 记忆当成数据库/数据管理系统来设计与评测(关注一致性、更新、生命周期、运维)，是比“刷任务分”更工程化的视角。对要把 agent 记忆做成线上长期服务的团队，提示需要建立系统级(而非仅任务级)的可观测与评测指标。

Wei Zhou, Xuanhe Zhou, Shaokun Han, Hongming Xu, Guoliang Li, Zhiyu Li, Feiyu Xiong, Fan Wu
