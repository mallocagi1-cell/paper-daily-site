PACE: Publisher-Adaptive Content Extraction via Agentic Automation

PACE 面向网页内容抽取中通用解析器易碎、直接调用 LLM 成本高、手写站点规则维护重的问题，让智能体从代表性页面和用户要求中学习发布商专属抽取配置。训练期由 LLM 归纳页面结构与可复用模式，推理期改用固定的确定性模板执行，从而兼顾适配性、吞吐与可审计性。

PRISM: Agentic Retrieval with LLMs for Multi-Hop Question Answering

PRISM 将多跳问答检索拆为问题分析、精选证据和补充证据三个专职智能体：先分解子问题，Selector 保精度，Adder 补召回，并在两者间迭代形成紧凑证据集。论文报告该机制既提升检索准确性、过滤干扰上下文，也让下游问答优于直接读取完整上下文。

INSIGHT核心价值是把传统一次性 Top-K 检索改造成可解释的精度—召回闭环，避免子问题串行传播错误或不断堆积噪声。社区搜索可将复杂 query 拆成实体、意图和约束，再由精排与补召回角色交替校验；应同时记录每轮新增证据和停止原因，控制成本并便于离线复盘。

Md Mahadi Hasan Nahid, Davood Rafiei

03 4.15

Knowing Before Answering: Decoding Language Models for Reliable RAG

论文把 RAG 回答前的可靠性判断建模为“证据充分、证据不足、证据冲突”三分类，构造含虚构信息的受控数据集，并从隐藏层激活与注意力特征训练轻量线性路由器。作者在 16 个不同架构和规模的语言模型上评估，验证内部信号能在生成前识别不宜直接作答的情形。

INSIGHT对生产搜索问答而言，拒答与二次检索不应只依赖生成后的自评文本，可在解码前增加低成本证据状态路由。若判为不足就扩展查询，判为冲突则触发多源核验，充分时直接生成；这种三路策略比统一增加检索轮次更节省延迟，也能把幻觉风险转成可监控的分类指标。

Syed Mahbubul Huq, Christopher Child, Tillman Weyde, Pranava Madhyastha

MetaRAG: Belief-Action Aligned Policy Optimization for Agentic RAG

MetaRAG 将智能体每一步的搜索决策质量重述为内部信念与外部动作是否对齐，并据此设计策略优化框架，而非只奖励最终答案。论文在 7 个公开问答基准上报告更优的准确率—效率权衡，收益还能迁移到深度研究任务、不同优化器和多个模型骨干。

INSIGHT仅用最终正确率训练搜索智能体，容易奖励偶然命中的低质量轨迹；显式约束“当前已知什么”与“下一步为何搜索”更利于学习可泛化策略。社区搜索中的 Agent 可把证据覆盖、查询增量信息和调用成本合成过程奖励，并单独监控无效重复检索，减少轮数膨胀。

ToolSense: A Diagnostic Framework for Auditing Parametric Tool Knowledge in LLMs

ToolSense 审计把工具编码为虚拟词表 token、经记忆与检索两阶段 SFT 训练的参数化工具检索器。它指出 ToolBench 的完整描述 query 与受限解码会高估真实理解能力，并可针对任意工具目录自动生成三类诊断基准，覆盖更贴近用户表达和工具知识边界的测试。

INSIGHT工具路由的离线高分可能来自候选约束，而非模型真正理解 API 语义；上线前必须加入含糊、缺参和目录外请求测试。对搜索 Agent，可将召回器、重排器、用户画像和网页工具统一纳入目录审计，同时比较开放生成与约束解码的差距，避免在长尾 query 上静默误调用。

Ashutosh Hathidara, Sai Shruthi Sistla, Sebastian Schreiber, Sahil Bansal

XHotpotQA: A Benchmark for Cross-Lingual Knowledge Composition in Multi-Hop Question Answering

XHotpotQA 用显式证据依赖图构造混合语言多跳问答，分别标注问题、桥接证据、答案证据与干扰项的语言。数据包含 15,661 条训练和 7,405 条验证样本；验证集中 99.81% 跨越问题—证据语言边界，95.60% 的金标段落来自不同语言，完全语言错配使三类阅读器指标下降 10.25–15.79。

INSIGHT多语言 Agent 的瓶颈并非只在最终翻译，而在证据链中间节点跨语言组合。面向中英混合 UGC，应分别评估 query 到桥接证据、桥接到答案证据的召回与推理损失，并保留句级支持标注；只把整条样本翻译成单一语言会掩盖真正的检索失败点。

Iman Barati, Arash Ghafouri, Behrouz Minaei-Bidgoli

Multi-Source Retrieval and Reasoning for Legal Sentencing Prediction

MSR² 针对量刑预测同时需要客观法条知识与主观裁量推理的问题，把多源检索嵌入 LLM 推理过程，并以强化学习的过程级奖励约束中间推理步骤。论文在两个真实世界数据集上验证，报告准确性与可解释性同步提升，并公开了实现代码。

INSIGHT其可迁移点是让检索动作随当前推理缺口变化，并对中间证据链给奖励，而不是只看最终答案。社区复杂搜索可把帖子事实、用户经验和权威资料视作不同来源，针对查询分解、来源选择、证据引用分别设过程信号，以降低单一来源偏置。

The Landscape of LLM-Based Search Agents: A Survey

该综述按完整系统设计梳理 LLM 搜索智能体，覆盖规划、检索、记忆、验证、工具使用与编排，而非按时间罗列论文。作者进一步区分短答案浏览、长报告深度研究和多模态工具智能体，强调这些任务虽共享搜索环节，却不能用单一、不分场景的总分直接比较。

INSIGHT评测 Agent 前应先固定任务形态和资源预算，再选择答案正确性、证据覆盖、引用质量、轮数与成本指标。对社区搜索，可将即时问答和深度研究拆成不同产品链路：前者强调低延迟和少轮检索，后者允许规划、记忆和核验换取更完整证据。

Fan Zhang et al.

A Wolf in Sheep's Clothing: Targeted Routing Hijacking in Federated RAG

论文揭示联邦 RAG 依赖客户端自报语义画像进行路由所产生的 Routing Hijacking 攻击：恶意节点伪造画像吸引目标 query，即使本地数据无关。攻击在三类代表性 FedRAG 路由架构上持续造成错路由、缺失证据、投毒与幻觉；MedQA-USMLE 压测还显示不同规模模型都会受污染证据误导。

INSIGHT多源或多租户搜索不能把路由画像当成可信元数据，应以抽样内容验证、历史命中质量和异常流量共同校准。Agent 每次跨库调用还应保留来源信誉与证据一致性检查，并为单节点设置 query 吸附率告警；否则检索层被劫持后，生成层再强也只会放大错误。

Junjie Mu, Qiongxiu Li

Run NVIDIA BioNeMo NIM Microservices for Protein Structure Prediction in Claude Science

NVIDIA

NVIDIA 展示在 Claude Science 中调用 BioNeMo NIM 蛋白质结构预测微服务的工程链路，使科研智能体能够阅读论文、提出假设、调用领域模型并决定后续实验优先级。文章重点是把专业模型封装成标准工具，让通用 Agent 在可组合工作流中使用，而非把全部能力塞进单一模型。

INSIGHT虽然案例来自生命科学，但其“领域能力微服务化”模式可直接借鉴到搜索：把召回、重排、实体识别与质量审核封装为边界清晰的工具，由 Agent 负责编排。上线时应对每个工具定义输入约束、超时、幂等与结果溯源，避免长链路中一次失败演变为不可解释答案。
