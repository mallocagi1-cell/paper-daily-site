1. Unifying Sparse Attention with Hierarchical Memory for Scalable Long-Context LLM Serving
4.00
Relevance 4 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: 针对长上下文 LLM 推理在 KV 缓存膨胀下成为成本和延迟瓶颈的问题，论文提出 SPIN 框架，将多种稀疏注意力算法与分层 KV 存储进行系统级协同设计。SPIN 包含三大组件：统一的稀疏分区抽象（兼容 token 级、block 级、cluster 级稀疏度）、面向 GPU 的局部性感知 KV 缓存管理器，以及两层级元数据布局来减少元数据访存开销。在多种长上下文工作负载上，SPIN 相对 vLLM 实现 9× TTFT 降幅，请求率越高优势越明显。

Key insight: 稀疏注意力与分层存储原本是两条独立优化路线，SPIN 将二者统一为执行流水线的一等公民，是面向长 query 召回与多文档 LLM rerank 的关键参考。社区搜索若将多帖串联给 LLM 判官打分，长上下文 KV 是首要成本项；统一抽象意味着不必为不同稀疏算法重写调度，能直接复用 vLLM/SGLang 的部署形态。可借鉴的是其元数据两层布局——把热数据元数据驻留在 GPU、冷数据元数据下沉到 CPU，避免元数据本身成为新瓶颈。

3. ZipCCL: Efficient Lossless Data Compression of Communication Collectives for Accelerating LLM Training
3.80
Relevance 3 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: ZipCCL 是一个在 Megatron-LM 与 TorchTitan 之上即插即用的无损通信压缩库，针对分布式 LLM 训练中 AllReduce/AllGather 占比高的问题。三大创新：基于 LLM 张量近高斯分布特性提出有理论支撑的指数编码、设计访存友好的 GPU 压缩/解压 kernel、根据负载动态切换集合通信策略。在多个工业规模训练任务上把通信时间最多降 1.35×，端到端训练加速 1.18×，且不影响模型质量。

Key insight: 通信压缩此前多用有损量化，常常牺牲收敛性；ZipCCL 把无损压缩做到 1.35× 增益是工程突破。其指数编码的洞察——LLM 梯度/权重张量大体上服从高斯——意味着压缩比可以从张量统计直接预估，不需要经验调参。对自研训练栈的团队，相比直接换硬件 NIC 升级带宽，软件层的无损通信压缩可以零迁移成本拿到 18% 训练吞吐。社区搜索的 reranker pretraining 若上千卡量级，这个收益足以覆盖一次集群扩容。

Summary: AMPD 把 prefill-decode 解耦的思路扩展到多轮对话/Agent 场景：核心是按实时负载自适应地决定 prefill 在何处执行、如何调度，并配套资源分配规划算法满足 SLO goodput。基于 NVIDIA Dynamo 与 NIXL（RDMA P2P 传输库）实现，在多轮 Agent 工作负载下相对静态 PD 解耦显著提升 SLO goodput。

5. DUAL-BLADE: Dual-Path NVMe-Direct KV-Cache Offloading for Edge LLM Inference
3.70
Relevance 3 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: DUAL-BLADE 提出双路径 KV 驻留框架：动态把 KV tensor 分配到 page-cache 路径或 NVMe 直访路径。NVMe 直访绕过文件系统，配合应用层批写/批读和 SSD 内部并行度，把 KV offload 的开销从硬件层根治。对边缘端低显存设备，端到端延迟最多降 42.4%，SSD 利用率提升 2.2×。被 IEEE ICDCS 2026 接收。

Key insight: 传统 KV offload 走文件系统，syscall 与 page cache 抖动都吃延迟；DUAL-BLADE 把 KV 视作裸块设备读写，是从存储栈层级而非显存层级思考的少见尝试。对中端 GPU + 大 NVMe 的部署形态（社区搜索的中等流量、对长尾延迟敏感的检索-排序混部场景）有直接借鉴价值。配合 io_uring 与 SPDK 这套异步 I/O 栈，可以做到 KV 加载与解码计算重叠，避免长尾抖动击穿 SLO。

9. LAER-MoE: Load-Adaptive Expert Re-layout for Efficient Mixture-of-Experts Training
3.15
Relevance 3 | Novelty 4 | Practical 3 | Evidence 3 | Timely 2

Summary: LAER-MoE 提出 Fully Sharded Expert Parallel 范式：允许在每个 iteration 都按当前负载重新分配 expert 到设备的 layout。把 re-layout 与 FSDP 的参数预取、梯度 reduce-scatter 融合到同一通信窗口，使重排不引入额外内存。在 A100 集群上相对现有 MoE 训练系统加速最多 1.69×，且不依赖额外 token 重路由。

Key insight: MoE 训练负载不均衡是工业级痛点，常规做法是冻结一段 layout 再算 token reroute；LAER-MoE 选择更激进的方向——layout 本身按 iteration 重排，但通过通信复用避免代价。来自 PKU + 字节，意味着工程合理性较高。社区搜索若用 MoE 做 query intent 分类或多场景 reranker，按数据集流分布动态 re-layout 能避免特定 expert 长期空闲；但配套需要稳定的负载预测器，否则 layout 抖动会反过来吃通信吞吐。
