Summary: 美团 LongCat 团队发布并开源 LongCat-Flash-Thinking-2601，在 τ²-Bench (88.2) 与 VitaBench (29.3) 等 Agentic Tool Use 基准上拿到开源 SOTA。核心做法是"环境扩展+多环境强化学习"：构建多套训练环境，每套集成 60+ 工具并形成密集依赖图谱；并新增专门强化总结归纳能力的 RL 阶段，最后用"双路径推理框架"自动筛选最优查询样本，将智能体推理与工具使用对齐。

2. Escaping the Context Bottleneck: Active Context Curation for LLM Agents via Reinforcement Learning
3.90
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 3

Summary: 针对长程 Agent 在自身上下文中"自我溺死"的问题，本文提出 ContextCurator：在冻结的大基础模型旁边外挂一个轻量策略模型，通过 RL 训练它在每一步主动决定保留/摘要/驱逐哪些信息，基础模型只看裁剪后的上下文。实验显示在长程 Agent 基准上，被裁剪 Agent 的成功率显著超越满上下文基线，token 用量却只有零头。

Key insight: 把上下文管理从"被动截断"升级为"被主动训练的策略"，避免了直接对超大基础模型做 RL 的成本。对线上搜索 Agent 很有价值：可以让大模型只读裁剪后的会话历史与已检索证据，长链路 Agent 既不爆显存也不被噪声分心；而且策略本身轻量，可独立蒸馏到小模型并在多种业务场景里复用。

3. Experiential Reflective Learning for Self-Improving LLM Agents
3.80
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 2

Summary: ERL（Experiential Reflective Learning）提出一种无需微调即可自我改进的经验记忆框架：让 Agent 反思过去的轨迹，从中析出可复用的成功策略与失败模式，构建启发式池，规划阶段被作为额外上下文检索回来。在 Gaia2 基准上，ERL 在不更新模型参数的前提下将 ReAct 基线成功率提升 7.8%。

Key insight: 用一组从历史轨迹中提炼的可读"启发式"代替昂贵的 RL 微调，是中小团队提升 Agent 能力的高性价比选项。对搜索 Agent 实践尤其友好：可以把每天线上失败 case 的 reflection 自动落库，形成持续生长的检索式启发式库，用 RAG 的方式把最相关启发式喂给 Planner，落地几乎不依赖训练资源。

5. Memory for Autonomous LLM Agents (AgeMem): Mechanisms, Evaluation, and Emerging Frontiers
3.45
Relevance 4 | Novelty 4 | Practical 3 | Evidence 3 | Timely 2

Summary: AgeMem 把 Agent 的记忆当成可调用工具：store / retrieve / update / summarize / discard 五种操作都纳入策略空间。训练分三段：先 SFT 暖启动记忆使用模式，再用任务级 outcome reward 做 RL，最后用 step-level GRPO 精调每一步的记忆动作选择。在长程 Agent 基准上较仅有静态 RAG 的基线显著提升。

Key insight: 把记忆从"外挂存储"重构为"由策略学出来的工具"，与近期 Curator 类工作思路一致：让模型自己决定何时记住/遗忘。对企业级 Agent 系统尤为重要——线上长会话场景里，记忆的取舍策略远比静态向量库容量更影响最终效果，是值得做"工具化记忆 + step-level RL"的工程方向。

6. Graph-of-Agents: A Graph-based Framework for Multi-Agent LLM Collaboration
3.35
Relevance 3 | Novelty 4 | Practical 3 | Evidence 4 | Timely 3

Summary: Graph-of-Agents (GoA, ICLR 接收) 把多 Agent 协作建模为图：节点是从模型池中按 model card 匹配选出的候选 Agent，边权由 Agent 间互评的相关性分数决定，再通过图遍历聚合输出。相比固定拓扑的 multi-agent baseline，GoA 在推理、代码、QA 任务上稳定有提升。

Key insight: 核心洞察是"协作拓扑应当随任务动态生成"：先用 model card 做粗筛，再让 Agent 互评做精筛与边权学习。这套 pattern 对企业内 Agent 平台很有借鉴意义——当业务方上传越来越多 specialized Agent，靠人手编排链路的成本会爆炸，GoA 提供了一种自动选 Agent + 自动连边的可工程化方案。

7. The Amazing Agent Race: Strong Tool Users, Weak Navigators
3.35
Relevance 3 | Novelty 4 | Practical 3 | Evidence 4 | Timely 3

Summary: AAR (The Amazing Agent Race) 构建 1400 个 DAG 形态的工具链谜题：Agent 需要在 Wikipedia 上多步导航、执行带分叉与合并的工具链、并聚合结果。结论很直接：前沿 LLM Agent 在单步工具调用上很强，但随 DAG 深度从 3 涨到 6，长程导航与聚合的成功率下降超过 40%，暴露 Agent 真正的瓶颈不在工具调用而在轨迹组织。

Key insight: 实验数据把"Agent 弱在哪里"量化得很清楚：单步工具调用已饱和，分叉/合并/聚合的轨迹组织能力远未到位。落地启示是搜索/RAG Agent 的优化重点应从"调用更准的单一工具"转向"训练更稳的多分支信息整合策略"，比如显式建模 sub-question 分解、引入 verifier 检查分支结果一致性。

8. Towards Trustworthy Report Generation: A Deep Research Agent with Progressive Confidence Estimation and Calibration
3.25
Relevance 3 | Novelty 4 | Practical 3 | Evidence 3 | Timely 3

Summary: 提出一个深度研究 Agent：在生成研究报告的同时给每一条断言打置信分。系统由 Deliberative Search Model 驱动，做深度检索 + 多跳推理，并随证据累积渐进校准置信度。报告级与断言级的事实性、置信度校准指标均较闭源 Deep Research baseline 有可量化提升。

Summary: 提出"数字资产 Agent 化"概念：把网页、结构化表格、API 等内容/服务统一封装成可被 Agent 调用的对象，并定义 A2A (Agent-to-Agent) 协议骨架。配套发布 A2A-Agentization Bench——首个专门评估 agentization 保真度与互操作性的基准。在跨资产任务上较 MCP-only 基线有显著提升。

10. DR3-Eval: Towards Realistic and Reproducible Deep Research Evaluation
3.10
Relevance 3 | Novelty 3 | Practical 3 | Evidence 4 | Timely 3

Summary: DR3-Eval 是面向 Deep Research Agent 的真实可复现评测：基于真实用户提交材料构造任务，每个任务都配有静态研究沙箱语料以保证可复现。评测框架沿 5 个维度——Information Recall、Factual Accuracy、Citation Coverage、Instruction Following、Depth Quality。结果表明前沿 Deep Research Agent 在 Citation Coverage 与 Depth Quality 上明显落后。

Key insight: 把 Deep Research 评估从"看最终答案对不对"细化为可独立分析的 5 维度，对内部团队搭评测体系非常有借鉴意义：应当把"引用覆盖度""指令遵从""深度"等维度独立打分，不要只看 BLEU/ROUGE 一类弱信号。这样在做 RL/SFT 时可以针对真正的短板（如 Citation Coverage）定向喂数据。
