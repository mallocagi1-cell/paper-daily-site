Agentic-R: Learning to Retrieve for Agentic Search

针对现有搜索智能体仍沿用单轮相似度检索器、相似段落未必能支持最终答案的问题，论文同时用局部查询—段落相关性与全局答案正确性定义段落效用，并让智能体和检索器双向迭代优化。在 7 个单跳与多跳问答基准上，Agentic-R 面对不同搜索智能体均持续优于强基线。

AgentCompass: A Unified Evaluation Infrastructure for Agent Capabilities

AgentCompass 将智能体评测拆为 Benchmark、Harness 与 Environment 三个独立组件，减少不同任务反复重写执行逻辑的问题；系统还提供容错异步运行时和轨迹分析工具，可定位奖励投机等细粒度失效。当前原生支持 5 类能力维度、20 多个基准，强调可复现与可扩展。

INSIGHT搜索智能体上线前需要把任务集、执行框架和外部环境解耦，否则模型升级或工具变化都会污染横向对比。该设计适合建立社区搜索 Agent 的统一回归平台：固定查询与环境快照，替换规划器、检索器或工具策略，并从完整轨迹而非最终答案单点诊断问题。

KnowAct-GUIClaw: Know Deeply, Act Perfectly, Personal GUI Assistant with Self-Evolving Memory and Skill

论文提出 Know-Route-Act-Reflect 框架，以可归因经验记忆和自演化技能库补足 OpenClaw 的跨平台 GUI 操作与持续学习能力，并覆盖 Android、iOS、HarmonyOS 和 Windows。基于开源 Kimi-2.6 的 GUIClaw 在长程 MobileWorld 上达到 64.1%，跨模型迁移记忆与技能还能带来 8.5% 提升。

INSIGHT长期智能体的价值不只来自更强基础模型，而来自把用户反馈、任务分解经验和可复用操作技能沉淀为可检索资产。社区搜索可借鉴其“知识路由—执行—反思”闭环，将成功的改写、工具调用与失败修复轨迹写入分层记忆，降低重复探索成本并支持跨端迁移。

QUBO-Optimized Evidence Selection for Retrieval-Augmented Question Answering with Unconventional Solvers

论文把多跳问答的证据集合选择写成 QUBO 能量最优化，同时权衡相关性、需求覆盖、支持强度、冗余、互补性和上下文紧凑度，再把低能量证据交给语言模型生成答案。在 HotpotQA 上，该方法的精确匹配与 token-F1 可竞争 LLM 集合选择器，并兼容 Ising/QUBO 求解器。

INSIGHT多跳检索的关键不是逐段取 Top-k，而是选择彼此互补、共同覆盖信息需求的最小证据集合。对搜索系统可先把复杂查询拆为若干信息约束，再用轻量组合优化做上下文裁剪，把昂贵 LLM 留给语义推理；不过上线前仍需验证求解耗时和规模扩展性。

How Cars24 scales conversations and builds faster with OpenAI

OpenAICCars24

Cars24 将语音、聊天与内部工作流智能体嵌入车辆交易全旅程，每月处理超过 100 万分钟对话。案例报告客服解决率提升 50%，关键服务流程周转时间降低 80%，并通过 AI 再触达找回 12% 原本流失的卖家线索，展示了面向真实业务链路的规模化效果。

INSIGHT工业落地应以端到端业务结果衡量智能体，而不是只看回答准确率：检索、对话、跟进和人工接管必须串成可观测流程。社区搜索场景可把“找到内容—完成决策—后续互动”作为完整轨迹，重点监控解决率、耗时、挽回率及人工升级比例。

Ring-Zero: Scaling Zero RL to a Trillion Parameters for Emergent Reasoning

Ring-Zero 将无人工标注、可验证奖励的 Zero RL 扩展到 1T 参数，并用裁剪重要性采样、训练—推理比例校正和混合精度控制稳定训练。模型在 7 个数学基准上取得有竞争力表现，训练呈现“发现—锐化”两阶段，还自发出现自验证、并行推理和自适应推理深度等行为。

INSIGHT可验证奖励能在超大模型上诱发比手工提示更丰富的推理策略，但算力门槛使其难以直接复制。搜索团队更可行的借鉴是构造可自动判定的检索任务奖励，并同时评估推理轨迹的可理解性、可复现性和效率，避免只优化最终答对率导致冗长搜索。

Can Induced Emotion Bias LLM Behaviors in Sequential Decision Making?

研究把想象式情绪诱导与 Iowa Gambling Task 结合，考察自主 LLM Agent 在不确定环境中的连续决策。总体上，诱导情绪不会像人类一样显著改变平均决策动态；但愤怒会降低模型对错误决策惩罚的敏感度，并在早期减少探索，使选择过早锁定在少数动作上。

INSIGHT用户语气和上下文情绪可能不改变最终平均指标，却会改变 Agent 的探索与风险响应方式。面向搜索交互，应把情绪化或对抗性上下文纳入轨迹测试，观察工具选择、停止条件和错误恢复，而不能只用静态问答准确率判断稳定性。

Minh Khoi Ho, Zihao Zhu, Runchuan Zhu, Levina Li, Zhiwen Fan, Zhangyang Wang, Junyuan Hong
