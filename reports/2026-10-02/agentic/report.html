Component-Aware Feedback for Self-Evolving Programs

该研究针对自演化程序只记录总分、难以定位有效修改的问题，比较子程序与父程序的组件变化，并保存局部及相对初始程序的指标差值。在 12 个 BRIGHT 数据集上，用中位数约三分之一搜索预算达到最强基线最终质量，最终留出集 nDCG@10 高 7.2%，成本约束下每查询 token 减少 11%。

DAGent: Evaluate-then-Grow Planning for Deep Research Agents

DAGent 将深度研究规划从先建完整任务图再修补，改为依据已完成节点的置信度和不确定性逐批扩展；层次上下文默认传递紧凑 QueryDocs，并按需回看轨迹。Qwen3-235B-A22B 在 BrowseComp-Plus、GAIA、xbench-DeepSearch 上领先最强开源基线 5.3、5.8、2.0 点，8B 的 DAGRPO 比等预算 GRPO 高 3.0 点平均 Pass@1。

INSIGHT社区复杂查询可先完成最有信息价值的证据节点，再决定是否扩展搜索，减少在证据不足时固定计划造成的无效分支。可借鉴紧凑上下文与完整轨迹分层存储，联合监控准确率、工具调用数和 token 成本；拓扑奖励的收益需与同结构、同预算基线比较，不能归因给模型规模。

Hanwen Liu, Yuanfu Sun, Qiaoyu Tan

03 4.10

PatchHolmes: Agentic Patch Retrieval via Listwise Selection

PatchHolmes 用混合检索获得候选，再让代理按列表整体比较 top-100，通过四类有预算工具选择性读取 3–10 个提交。GitHubAD 上 Recall@1 比 Favia 高 25.34%、比 IRCoT 高 31.40%；迁移至 PatchFinder_top10 后从 24.28% 提升到 39.86%，每个漏洞只需一次代理对话，模型无需微调。

INSIGHT可把列表级比较与受预算约束的证据检查迁移到复杂 UGC 搜索：先廉价召回，再让代理只深入阅读少量有争议的候选。论文固定候选集合后仍有增益，支持第二阶段决策本身的价值；但漏洞提交与社区帖子不同，应另测 nDCG、CTR 及尾延迟，并限制工具调用预算。

Guanqun Yang, Yingming Zhou, Jiangrui Zheng, Shudong Hao, Xueqing Liu

MemLife: Curating and Reasoning over Long-Term Egocentric Video Memories

MemLife 针对长期第一视角视频反复处理成本与记忆检索竞争，生成实体锚定的文本事件，再由时间索引代理读取。在四个长程基准上，无训练且查询时不访问视频的版本比最强免训练基线高 4.6%–12.0%；MemOpt 用强化学习优化记忆写入，再提升 2.7%–5.0%，并跨写入器、读取器及记忆系统泛化。

INSIGHT对包含用户历史互动的社区搜索代理，可借鉴实体、事件和时间共同组织记忆，减少摘要丢失关键证据及长历史中检索竞争。先用免训练读取方案验证记忆检索是否改善复杂查询，再考虑强化学习优化写入；视频基准收益不能直接解释为短文本搜索提升，应核验原帖引用与隐私边界。

Guangzhi Xiong, Xinyuan Zhang, Xiao Yang, Hyokun Yun, Kai Zhang

False Frontiers: Diagnosing and Mitigating Co-Cheating in Self-Evolving Search Agents

论文发现搜索代理自演化中出题者和解题者会共享错误，内部奖励增长并不代表外部正确率提高。CrossFit 将来源文档分组，用只在另一组训练的辅助解题者反馈；4B、9B 错误一致率从 6.1%、8.8% 降至 3.0%、3.7%，在七个搜索基准上比标准耦合自演化平均高 8.8、8.4 点。

INSIGHTUGC 搜索若采用模型生成查询和伪标签训练搜索代理，应隔离生成来源与反馈模型的数据血缘，并保留基于原文的独立审计集。简单多次采样验证每候选需六次额外生成，却只部分抑制共错；交叉拟合更值得试验，但还要核算辅助模型训练成本和真实用户查询上的泛化。

Meijia Chen, Hao Li, Zheng Lu, Hongshan Lin, Junbai Tian

Mid-Harness: Scaling Actions Between Model and Harness for Terminal Agents

Mid-Harness 在模型生成和工具执行之间采样多个动作，再验证并选择一个执行，保持动作生成器与原 harness 不变。TMAX-9B 在 TerminalBench-Lite 上配合 GPT-5.6 Sol 验证器及八个候选动作，Pass@1 从 50.00% 升至 68.03%；弱验证器则难以利用更多采样，验证器蒸馏还能进一步改善结果。

INSIGHT多步社区搜索可试验在关键检索或工具调用前比较若干候选动作，避免一个低质量查询使整条轨迹偏离。核心约束是验证器必须有辨别能力，单纯增加采样不保证成功；先在少数关键步骤做小预算实验，再比较每成功任务的 token、调用成本及延迟，不能直接沿用终端任务增益。

Minki Kang, Ryo Hachiuma, Shaokun Zhang, Subhashree Radhakrishnan, Yonggan Fu

Conformal Factuality Control for Multi-Hop Retrieval-Augmented Generation

研究把分割共形声明过滤用于多跳 RAG，在 HotpotQA、Natural Questions、TriviaQA 与两个模型形成的六种配置上检验事实性。95% 目标下，保留声明全部有支持的响应比例达到 95.80%–97.20%，未过滤为 55.60%–76.03%；但仅保留 4.41%–31.09% 声明，非空响应只占 9.70%–51.40%。

INSIGHT社区答案搜索可以在多步检索之后增加声明级支持校验，优先控制无证据结论，而非仅凭找到相关帖子就输出完整答案。实验提醒可靠率必须与回答覆盖率一起呈现，否则大量弃答会制造质量改善的错觉；上线试验应同时观察支持率、非空率、用户满意度与点击转化。

Muhammad Aimal Rehman, Chi-Kuang Yeh

TRACE: Target-Aware Retrieval, Attributed Evidence, and Contract-Constrained Extraction for LitTraceQA

TRACE 面向可核验研究问答，将目标分组检索、类型化证据定位、视觉表格抽取与失败关闭校验结合，索引 27,487 篇论文。官方 71 题测试的总分为 0.760613，论文 F1 为 0.9728、证据 F1 为 0.6847、表格行 F1 为 0.5423、宏平均单元格准确率为 0.3508，显示定位到论文并不意味着正确提取答案。

INSIGHT社区多步问答应把找到来源、定位原帖段落和生成可核验答案视为独立环节，保留对象标识与字段类型，并对证据缺失实行明确失败处理。论文中来源召回与表格数值准确率的落差提示：仅优化召回指标不足以衡量答案质量，需增加证据定位、字段一致性和最终回答评测。

Sachin Gupta, Divya Godara

Learning to Route in Visual Space via Multi-Step Embedding Retrieval

VHOP-Router 将视觉空间多步导航下放给检索工具，结合监督微调、在线模仿和强化学习，一次调用返回关联图像链，无需代理逐步生成文本查询。VHOP 检索表现从不足 5% 到 76.3%；代理任务成功率报告提升 52.7%，平均 token 从 1886 降至 728，相比每步 top-50 检索，上下文图像减少 23 倍。

INSIGHT对带图片的社区搜索，视觉线索难以转成文本时，可试验让检索器直接导航图像关系，再交给代理综合证据。论文比较升级代理与升级工具，提示多步系统的瓶颈可能在检索能力；迁移前需构造真实帖子图像链与未见难度测试，避免把合成 VHOP 的收益直接外推到普通文本 nDCG。

Tianyu Chen, Mingyuan Zhou, Jiaxing Wu

Graph-centric agentic intelligence

Amazon

AWS 将网络数字孪生图与代理编排结合，先按连通性分解，再做社区聚类，最后按告警条件计算中心性，将候选从数千节点缩至数百再到数十。文章报告与 NTT DOCOMO 在商业网络上把根因分析推进到分钟级；代理围绕候选扩展 2–3 跳证据，但未给出受控对照表或线上搜索指标。

INSIGHT可借鉴先查历史事件知识库、再按问题复杂度调用确定性图算法的流程，帮助社区搜索代理在关系链查询中缩小证据空间。把图分析结果、时间线和原始引用交给代理综合，而非依赖语言模型凭空推断；网络故障定位经验可迁移，但需要单独验证帖子关系图质量及搜索延迟。
