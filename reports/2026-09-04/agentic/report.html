KGVoyager: Knowledge Graph Agnostic Question Answering via Agentic Navigation

论文面向缺少本体和文本—SPARQL 样本的领域知识图谱问答，提出 KGVoyager，以思考—行动—观察循环动态发现图结构、映射 IRI，并依据执行反馈修正查询。它只需轻量类别索引，在四个基准上把 F1 提高约 8 个点，同时将成本和运行时间各降低约 22%。

Repo-To-Skill: Distilling GitHub Repositories Into AI4AI Skills

论文指出端到端科研 Agent 缺少可复用的操作知识，提出 DisCo，把 GitHub 仓库和论文中的实现经验压缩为紧凑、可验证的技能。系统同时支持面向领域的任务无关蒸馏与针对具体任务的定向蒸馏，使规划、执行、记忆和验证环节不必在每次运行中重新发现工程做法。

INSIGHT创新点不只是检索代码，而是将仓库证据编译成 Agent 可直接执行和验证的技能单元。对搜索团队而言，可把查询分析、召回诊断、离线评测等成熟流程技能化，并保留来源与验证条件，从而减少 Agent 在长仓库中反复搜索造成的上下文和执行成本。

Jianlyu Chen, Yuyang Hu, Hongjin Qian, Jiawei Liu, Wenqing Wei

Imagine Before Retrieval: Prospective Skill Retrieval for LLM Agents

论文识别出技能检索中的查询—技能错位：任务查询描述目标，而技能文本描述操作步骤，单纯语义相似度难以匹配。SkillDreamer 借鉴前瞻认知，先想象完成任务所需的过程性线索，再据此检索技能，从表示层桥接目标语言与操作语言。

INSIGHT这项工作提示 Agent 检索不应直接拿用户问题匹配工具说明，而应先生成计划或预期执行轨迹作为中间查询。社区搜索 Agent 可将自然语言需求改写成检索、过滤、核验等步骤，再匹配对应技能，有望提高长尾任务的工具选择准确率。

Shuo Liu, Yutong Yang, Haohao Xiao, Mouxing Yang, Xi Peng

Multi-Agent Retrieval-Augmented Generation for Efficient Cloud Knowledge Base Search in Telecom SNOC Environment

Vodafone Idea

论文为 Vodafone Idea 网络运营中心构建离线多 Agent RAG 系统 Athena，联合 E5-Large-V2 稠密召回、BM25 稀疏召回和知识图谱扩展。系统在 LangGraph 中编排检索，使用 Weighted CombSUM 融合候选，再经交叉编码器重排与多样性约束筛选，面向 SOP、故障单和厂商手册搜索。

INSIGHT工业启示是多 Agent 的价值来自可分解、可审计的混合检索流水线，而不是简单增加对话角色。UGC 搜索可复用稠密与词法召回、图扩展、融合、重排的分层结构，并让 Agent 仅负责查询拆解和策略选择，以控制延迟与错误传播。

Harish Saragadam, Sudhanshu Sharma, Ipsha Routray

Incident Memory: Training-Free Operational Memory through Sequential Pattern Mining and Velocity-Stratified Retrieval

论文提出无需训练的运维记忆系统：按事实变化速度分层检索，以带故障指纹条件的 PrefixSpan 从成功调查中挖掘有序处置剧本，并用可执行检查维护指标来源。UCI ITSM 的 141,712 个事件形成 23,110 条轨迹和 39 个剧本，覆盖 6,934 个留出故障中的 84.3%。

INSIGHTAgent 记忆需要同时保存顺序、新鲜度和出处，而不是把历史记录统一嵌入向量库。搜索系统可把查询诊断与运营处置轨迹按稳定性分层，并挖掘高成功率步骤序列，作为故障 Agent 的可解释先验；无需再训练也便于灰度落地。

Adarsh Agrawal, Rahul Suresh Babu

EarlyEval: Cheaper Agent Evaluation via Early Outcome Prediction

论文针对一次前沿模型 Agent 基准评测可花费数百至数千美元的问题，提出 EarlyEval，在单个任务尚未结束时预测最终成败。系统用行为、文本和参考解特征训练成功与失败两组 LightGBM 分类器，任一置信度超过校准阈值便提前终止，且每步额外开销很低。

INSIGHT与缩减测试集不同，EarlyEval 从单条轨迹内部节省成本，适合频繁迭代的搜索 Agent。实践中应分别校准成功和失败阈值，并保留不确定轨迹完整执行；这样可以优先砍掉已明显失败的循环调用，同时控制错误提前停止对评测可信度的影响。

Yuling Shi, Zhensu Sun, Junsen Dong, Chengcheng Wan, David Lo

Beyond Context Windows: Persistent Discovery Context for Data-Centric Agents

论文把数据 Agent 反复执行的发现过程沉淀为持久化上下文，保存历史意图到数据对象的映射，并在未来检索时复用。三个结构化数据环境的实验显示，它持续优于只依赖元数据的搜索；自动生成的记忆仍有效，在词汇稀疏场景中甚至可由记忆单独超过元数据检索。

INSIGHT可复用的不是整段对话，而是经过验证的意图—对象映射，这比无限扩展上下文窗口更轻量。社区搜索 Agent 可沉淀用户任务到索引、字段或数据源的发现结果，但必须监测论文揭示的记忆干扰，以版本、置信度和失效策略控制错误复用。

Counter-GEO-Bench: Evaluating Defenses Against Information-Distorting Generative Engine Optimization

论文构建 Counter-GEO-Bench，评估生成式搜索遭遇信息扭曲型 GEO 内容时的防御能力。基准含 247 个经人工核验的问题，为每题配置信息保持与信息扭曲改写，并在三个受害模型上测攻击成功率、误报率和答案质量；三种现成防御最多只将攻击成功率相对降低 5.7%。

INSIGHT传统安全分类器难以识别外观正常、却针对生成式检索排序优化的误导内容，检索可信度不能只靠生成后审核。搜索 Agent 应在召回、来源信誉、跨源佐证和答案生成各层设置防线，并把攻击成功率与误报率共同纳入离线评测。

Bing Zheng, Zongyao Zhao, Wenming Yang

Cite or Decline: A Strict Course-Grounded Chatbot for STEM Lecture Videos

论文报告 VideoPoints 在一个学期内的真实部署：聊天机器人仅检索当前课程，用章节摘要辅助转录文本排序，并返回可点击的时间戳引用；证据不足时选择拒答。833 条消息中 70.5% 带引用，且没有回答越过课程边界，用户认为引用是最稳定有用的功能。

INSIGHT严格限定语料域、证据可点击和允许拒答，能比开放式生成更有效地建立检索 Agent 信任。UGC 搜索问答可采用同样的“引用或拒答”契约，把帖子级证据和定位信息暴露给用户，并持续监控跨域泄漏而非只看回答流畅度。

S M Masrur Ahmed, Jaspal Subhlok

Legora reviewed 41 documents in minutes with GPT-6 Astra

OpenAILLegora

这项产业实践展示 Legora 用 GPT-6 Astra 在数分钟内审阅 41 份财务文件，并找出全部 4 个预置错误，相比此前模型将该工作流表现提高近 40%。它验证了面向多文档证据检索、交叉核验与异常定位的 Agent 工作流可以进入高要求的专业审阅场景。

INSIGHT对搜索团队最有价值的是以预置错误和端到端任务完成率评估多文档 Agent，而不是只测试单次问答。可在 UGC 搜索中构造已知冲突、遗漏和时效陷阱的文档包，衡量 Agent 是否完整检索、交叉验证并准确定位证据，同时记录分钟级处理成本。
