1. PCR: A Prefetch-Enhanced Cache Reuse System for Low-Latency RAG Serving
3.85
Relevance 4 | Novelty 3 | Practical 4 | Evidence 3 | Timely 5

Summary: RAG 系统在引入外部文档后输入序列极长，prefill 阶段 KV 计算成本高昂，成为在线服务瓶颈。PCR 系统通过三项关键技术解决 KV cache 复用的实际难题：基于语义感知的缓存淘汰策略提升命中率、异步 CPU-GPU 预取隐藏传输开销、以及分层 SSD 溢出管理降低 IO 延迟。实验表明 PCR 在高并发 RAG 场景下显著降低首 token 延迟（TTFT），适用于搜索增强生成的在线 serving。

Key insight: PCR 将 RAG 场景的 KV cache 复用从简单的前缀匹配扩展到语义感知的智能缓存管理，核心创新在于将缓存淘汰与文档检索频率关联。对搜索系统启示：在 LLM-based 搜索中，检索文档的 KV cache 复用可以大幅降低推理成本，尤其当多个 query 共享相似检索结果时。该方案无需修改模型本身，工程落地门槛低。

2. Sparser, Faster, Lighter Transformer Language Models
3.80
Relevance 3 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: 提出一种新的稀疏打包格式和 CUDA kernel 集合，专门针对 Transformer FFN 层的非结构化稀疏进行高效计算。通过简单的 L1 正则化即可在 FFN 层诱导 99% 以上的稀疏度，且对下游性能几乎无损。配合定制 kernel，稀疏化在推理和训练中均带来显著的吞吐量提升、能效改善和内存节省，且收益随模型规模增长而增大。

Key insight: 该工作的核心发现令人意外：简单的 L1 正则化就能在 FFN 层实现极端稀疏（99%+）而不损失性能，关键是配套的 CUDA kernel 能将理论稀疏转化为实际加速。对搜索/推荐系统中部署的 LLM 而言，这提供了一条不需要改变模型架构、仅通过正则化+定制 kernel 即可降低推理成本的实用路径。Llion Jones（Transformer 原作者之一）参与使本文可信度较高。

3. EchoKV: Efficient KV Cache Compression via Similarity-Based Reconstruction
3.80
Relevance 3 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: 针对 LLM 长上下文场景中 KV cache 内存瓶颈，提出 EchoKV —— 一种基于相似性重建的灵活 KV cache 压缩方案。与传统不可逆压缩不同，EchoKV 支持在压缩和全精度推理之间按需切换。利用轻量网络从部分子集重建残差 KV 分量，利用注意力头间的层内和层间相似性。两阶段微调策略使训练成本极低（7B 模型仅需约 1 个 A100 GPU 小时），在 LongBench 和 RULER 基准上持续优于现有方法。

Key insight: EchoKV 的灵活性是最大亮点：可根据运行时内存状况动态切换压缩/全精度模式，这对搜索系统非常实用——高峰期启用压缩节省内存，低峰期切回全精度保证质量。训练成本极低（1 A100 小时），使其可快速适配到生产环境的各种模型。层间/层内相似性的利用为后续 KV cache 优化提供了新的设计空间。

4. FAAR: Format-Aware Adaptive Rounding for NVFP4
3.80
Relevance 3 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: 在边缘设备部署 LLM 需要极低比特量化，NVFP4 格式提供了有前景的解决方案。然而现有量化方法忽略了 NVFP4 数值网格的非均匀特性，导致次优舍入。FAAR 提出格式感知的自适应舍入策略，将 NVFP4 非均匀网格显式纳入优化过程，通过损失梯度引导自适应调整舍入决策。配合 2FA（两阶段格式对齐）微调策略，在 LLaMA、Qwen 等模型上实现了 NVFP4 量化的最优精度。

Key insight: FAAR 的核心贡献在于揭示并解决了一个被广泛忽视的问题：FP4 格式的非均匀数值网格要求量化舍入策略也是非均匀的。这对搜索/推荐系统的模型部署有直接启示——随着 NVIDIA Blackwell 架构原生支持 FP4，格式感知的量化将成为标配。2FA 微调策略（先对齐格式再微调权重）提供了一种通用的低比特量化流程。

5. Characterizing CPU-Induced Slowdowns in Multi-GPU LLM Inference
3.65
Relevance 3 | Novelty 3 | Practical 4 | Evidence 4 | Timely 5

Summary: 通过对现代 LLM 推理和 serving 工作负载的详细研究，发现多 GPU 性能下降的根因往往不是 GPU 饱和，而是 CPU 无法让 GPU 保持忙碌。在有限 CPU 分配下，系统出现 kernel 启动延迟、通信停滞、tokenization 延迟增加等症状，导致 GPU 严重利用率不足。即使采用进程级隔离和 CUDA Graphs 等 GPU 端优化，CPU 瓶颈仍然持续存在。额外 CPU 核心的边际成本远低于 GPU 实例定价。

Key insight: 这是一项极具实践价值的系统分析工作。核心发现颠覆常识：多 GPU LLM 推理的瓶颈往往不在 GPU 而在 CPU。对搜索/推荐系统的 LLM serving 部署有直接指导意义——在资源配置时应确保充足的 CPU 核心数，CUDA Graphs 等 GPU 端优化无法掩盖 CPU 不足。该研究提供了定量的 CPU-GPU 配比建议，可直接用于生产环境的容量规划。

6. Scaling Attention via Feature Sparsity
3.55
Relevance 3 | Novelty 4 | Practical 3 | Evidence 3 | Timely 5

Summary: 提出 Sparse Feature Attention (SFA)，从特征维度而非序列维度切入降低自注意力成本。将 query 和 key 表示为 k-sparse 编码，在保持高维表达力的同时将注意力成本从 O(n²d) 降至 O(n²k²/d)。配套的 FlashSFA kernel 扩展了 FlashAttention，在稀疏重叠上直接计算而无需构建密集得分矩阵。在 GPT-2 和 Qwen3 预训练中，SFA 匹配密集基线同时加速达 2.5 倍，FLOP 和 KV cache 减少近 50%。

Key insight: SFA 提出了一个全新的注意力加速方向——特征稀疏，与现有的序列维度稀疏（local window、token pruning）正交，两者可组合使用。FlashSFA kernel 是关键工程贡献，使理论加速落地。对搜索系统中的 LLM serving 而言，KV cache 减少 50% 意味着可在相同硬件上服务更多并发请求。2.5 倍加速在 Qwen3 上验证，说明在主流开源模型上可直接应用。

7. MKA: Memory-Keyed Attention for Efficient Long-Context Reasoning
3.55
Relevance 3 | Novelty 4 | Practical 3 | Evidence 3 | Timely 5

Summary: 提出 Memory-Keyed Attention (MKA)，一种层次化注意力机制，整合多级 KV cache（本地、会话、长期）并学习在不同缓存间动态路由注意力。进一步引入 Route-Fused MKA (FastMKA)，在注意力计算前融合记忆源以提升效率。实验表明 FastMKA 在不同序列长度下实现了准确度-效率的优良权衡：困惑度与 MLA 相当，同时推理速度提升最高达 5 倍，KV cache 内存占用大幅降低。

Key insight: MKA 的层次化 KV cache 设计（local/session/long-term）与搜索系统的多级缓存架构天然对齐。FastMKA 的广播路由融合策略避免了为每个注意力头独立查询多级缓存的开销。对于需要处理长上下文的搜索场景（如文档级排序、多轮对话搜索），5 倍推理加速和 KV cache 节省具有直接价值。但该方法需要从头训练或大规模微调，短期落地成本较高。

8. KDFlow: A User-Friendly and Efficient Knowledge Distillation Framework for Large Language Models
3.55
Relevance 3 | Novelty 3 | Practical 4 | Evidence 3 | Timely 5

Summary: 现有 LLM 蒸馏框架对 teacher 和 student 模型使用同质训练后端（如 FSDP 或 DeepSpeed），导致效率次优。KDFlow 采用解耦架构，teacher 推理使用 SGLang、student 训练使用 FSDP2，在统一系统中充分发挥两者优势。通过零拷贝传输 teacher hidden states（而非全量 logits）并在 student 端重算 logits，有效平衡通信成本和蒸馏效果。

Key insight: KDFlow 的架构设计思路值得借鉴：将推理引擎（SGLang）和训练框架（FSDP2）解耦组合，比传统同质后端效率高得多。hidden states 传输替代 logits 传输的设计减少了 90%+ 的通信量。对搜索/推荐团队而言，这提供了一个高效的 LLM 蒸馏方案——用大模型的知识训练适合在线 serving 的小模型，是模型压缩落地的实用框架。

9. Adaptive Multi-Objective Tiered Storage Configuration for KV Cache in LLM Service

Relevance 3 | Novelty 3 | Practical 4 | Evidence 3 | Timely 4

Summary: 提出 Kareto（KV-cache Adaptive REsource managemenT Optimizer），一种面向 LLM 服务的 KV cache 多目标分层存储配置系统。Kareto 能根据不同优化目标自适应调整 KV cache 在 GPU HBM、CPU 内存和 SSD 间的分配策略：吞吐量优化模式提升 9.3%、延迟优化模式降低 58.3%、成本优化模式节省 20.2%。系统支持多目标间的灵活权衡。

10. Arena: Efficiently Training Large Models via Dynamic Scheduling and Adaptive Parallelism Co-Design
3.35
Relevance 3 | Novelty 4 | Practical 3 | Evidence 3 | Timely 3

Summary: GPU 集群中大模型训练涉及作业间动态调度和作业内自适应并行两个维度，但现有动态调度器因静态并行策略与自适应并行执行的不匹配而效率低下。Arena 协同设计动态调度与自适应并行：通过低成本解耦 profiling 和负载感知性能估算降低调度开销，并通过网格抽象统一调度-并行联合优化空间，在弹性和异构维度上动态调度已 profiled 的作业。

Key insight: Arena 的核心创新在于打破了训练调度和并行策略之间的隔阂——传统系统先固定并行策略再调度，Arena 则将两者联合优化。网格抽象为这一联合优化提供了可扩展的搜索空间划分。对需要持续训练/微调搜索排序模型的团队，Arena 的自适应并行策略可提升 GPU 集群利用率，尤其在多模型混合训练场景下效果显著。
