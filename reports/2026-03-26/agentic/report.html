1. Rethinking the Role of Entropy in Optimizing Tool-Use Behaviors for Large Language Model Agents
4.00
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 4

Summary: 针对 LLM Agent 在长轨迹中频繁触发低质量工具调用导致延迟增加和推理性能下降的问题，通过熵分析实验发现：高质量工具调用与熵降低存在强正相关。基于该发现，提出以熵降低作为奖励信号优化工具使用行为，有效减少冗余工具调用并提升推理质量。

Key insight: 该工作揭示了一个重要信号：LLM Agent 在决定调用工具时的信息熵变化可以作为工具调用质量的指标。对搜索 Agent 设计有直接启示——在多轮检索场景中，可通过监控模型对下一步行动的熵来判断是否需要额外检索，避免无效的重复搜索调用。这为搜索 Agent 的调用策略优化提供了可量化的信号。

2. Reasoner-Executor-Synthesizer: Scalable Agentic Architecture with Static O(1) Context Window
4.00
Relevance 4 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: 针对 LLM Agent 中 RAG 系统的上下文窗口扩展问题，提出 Reasoner-Executor-Synthesizer (RES) 三层架构：Reasoner 解析用户意图，Executor 以确定性方式执行数据检索和聚合（零 LLM token），Synthesizer 生成叙述性回答。该架构将上下文窗口固定为 O(1)，token 成本不随数据集规模增长，同时降低了幻觉风险。

Key insight: RES 架构的核心创新在于将检索与推理彻底解耦：Executor 层不使用 LLM，完全依赖确定性代码执行数据操作，避免了长上下文带来的幻觉和高成本问题。这种分层设计对搜索系统中的 Agent 架构设计具有直接借鉴意义——在社区搜索场景中，可将 query 理解、文档检索、结果合成三个阶段分离，用轻量确定性模块处理召回，仅在最终合成阶段使用 LLM。

4. SpecEyes: Accelerating Agentic Multimodal LLMs via Speculative Perception and Planning
3.70
Relevance 3 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: 针对 Agentic 多模态 LLM（如 OpenAI o3、Gemini Agentic Vision）中感知-推理-工具调用级联循环导致的高延迟问题，提出 SpecEyes 框架。核心思路是将推测性执行（Speculative Execution）引入 Agent 层面，通过预测性感知和规划并行执行多步操作，打破顺序瓶颈，显著降低 agentic depth 带来的延迟。

Key insight: SpecEyes 将计算机体系结构中的推测执行思想迁移到 Agent 系统，这一思路对搜索 Agent 性能优化极具启发：在多轮检索-推理循环中，可以推测性地并行发起多条检索路径，而非等上一步结果返回后再决定下一步。这对降低搜索 Agent 的端到端延迟有重要实践意义。

6. FIPO: Eliciting Deep Reasoning with Future-KL Influenced Policy Optimization
3.55
Relevance 3 | Novelty 4 | Practical 3 | Evidence 4 | Timely 5

Summary: 提出 Future-KL Influenced Policy Optimization (FIPO)，一种针对 LLM 推理瓶颈的强化学习算法。不同于 GRPO 等基于结果的全局 advantage 均匀分配策略，FIPO 引入折扣未来 KL 散度进行精细化 credit assignment，识别推理轨迹中的关键逻辑转折点，给予更精确的梯度信号。

Key insight: FIPO 解决了 RL 训练 LLM 推理能力时的关键瓶颈——粗粒度 credit assignment 无法区分关键推理步骤和琐碎 token。对搜索 Agent 的 RL 训练有直接启示：在多步搜索-推理轨迹中，能够识别哪些检索决策是关键转折点，进而优化 Agent 的搜索策略决策。这为用 RL 训练搜索 Agent 提供了更精准的优化方法。

7. Rethinking Token-Level Policy Optimization for Multimodal Chain-of-Thought
3.55
Relevance 3 | Novelty 4 | Practical 3 | Evidence 4 | Timely 5

Summary: 对多模态 Chain-of-Thought 推理进行 token 级别分析，发现成功推理的特征是结构化的 token 动态——反映感知定位与逻辑推理的交替。基于此发现，提出区分视觉感知 token 和推理 token 的差异化 RL 优化策略，替代现有 RLVR 方法对 CoT 的粗粒度均一处理。

Key insight: 该工作揭示了多模态推理中不同类型 token 需要不同的 RL 优化粒度。对搜索 Agent 中的推理链优化有启示：在检索增强推理中，「检索决策 token」和「推理 token」应区别对待。这一思路可迁移到搜索 Agent 的训练中，对何时检索、何时推理的决策进行差异化优化。

8. EVA: Efficient Reinforcement Learning for End-to-End Video Agent
