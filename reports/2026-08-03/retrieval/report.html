DenseOn with the LateOn: Fully Open Dense and Late-Interaction Models for Multilingual, Long-Context, and Code Search

论文公开了从数据到训练代码的完整检索配方：从 34 个公开来源的 14 亿对数据中筛出 6.65 亿对，并构建 188 万条含难负例的微调集。149M 参数 DenseOn 与 LateOn 在 BEIR 上分别达到 56.20、57.22 nDCG@10；多语版扩展到 28 亿训练对，并覆盖长文档和代码检索。

QASP: Query-Adaptive Robust Vector Search Policy

QASP 针对固定 ANN 搜索参数导致不同 query 召回波动的问题，用一次监督回归预测每条查询的完整 recall-progress 曲线，再按目标召回率生成搜索深度策略，并用无额外推理的反馈修正偏差。实验在大规模与分层索引上无需重训即可泛化，在 99% recall 目标下减少 80% 数据访问。

INSIGHT平均召回率会掩盖尾部 query 的坏体验，QASP 把搜索预算从全局常数改为 query 自适应控制，尤其适合社区搜索中短 query、实体 query 与长尾意图混杂的流量。落地时可先以离线 recall 曲线训练轻量策略模型，将数据访问量、P99 recall 偏差和 query 满足率作为联合护栏，再逐步接管固定 nprobe/efSearch。

Hakan Ferhatosmanoglu, Kushal Kumar, Tal Wagner, Andy Warfield

OneShot: Index-in-Ranking with Neural Scoring for Large-Scale Retrieval

Meta

OneShot 将层次索引学习放进排序目标，用 Straight-Through Estimator 训练离散 one-hot 路径，再以神经打分突破点积交互上限，并通过全局均衡损失防止索引塌缩。它已部署到 Instagram 短视频推荐：离线 recall 提升 20%，等召回效率提高 10 倍，线上 session +0.04%、观看时长 +0.14%。

INSIGHT论文证明索引不必是排序模型之后的离线附属物；把索引分配、粗排交互和业务目标联合训练，可同时降低 rank-index 错位与候选漏失。对大规模 UGC 搜索，可先在单路召回上试验可学习层次码与 beam search，并严格监控簇均衡、索引刷新成本和线上尾延迟，再考虑替换成熟 ANN 主链路。

OPERA: Online Data Pruning for Efficient Retrieval Model Adaptation

📖 深度解读 · 7 分钟 →

OPERA 研究领域检索器微调中的样本异质性：静态裁剪只保留高相似样本，动态方案则在 query 与 document 两层随训练调整采样概率，兼顾质量和覆盖。跨 6 个领域、8 个数据集，动态裁剪令 nDCG@10 提升 1.9%、Recall@20 提升 0.7%，并用不到标准微调 50% 的时间达到相当性能。

INSIGHT社区 UGC 的点击对噪声大且长尾意图覆盖稀疏，单纯按相似度删数据容易让 nDCG 上升却损害召回；OPERA 的双层动态采样更适合保留 query 多样性。可在 embedding 领域适配中把样本权重接入现有 sampler，以训练时长减半为第一目标，同时分头监控头部 query 排序与长尾 Recall@20。

Bridging the Question-Answer Gap in Retrieval-Augmented Generation: Hypothetical Prompt Embeddings

HyPE 把 HyDE 的在线假想答案生成移到建库阶段：为每个 chunk 预生成多个可能问题，使线上检索转化为 query-query 匹配，从而避免运行时 LLM 调用。六个常用数据集上，相比标准方法，检索上下文精度最高提升 42 个百分点、claim recall 最高提升 45 个百分点，且可叠加重排和多向量检索。

INSIGHTUGC 文档口语化、标题弱而用户 query 更像问题，离线为帖子生成多视角“可能被问到的问题”能显著缩小表达鸿沟，同时不增加线上延迟。工程上应控制每文档生成问题数与索引膨胀，先针对少无结果和长尾意图做灰度，并用原始 doc 向量与 HyPE 向量双路召回防止生成偏差。

Domen Vake, Jernej Vičič, Aleksandar Tošić

SaFRO: Satisfaction-Aware Fusion via Dual-Relative Policy Optimization for Short-Video Search

Kuaishou📖 深度解读 · 7 分钟 →

SaFRO 面向短视频搜索多任务融合，把 query 级行为代理汇成满意度奖励，并以组内、跨批次双重相对偏好更新融合策略；Task-Relation-Aware 模块再按上下文调整各目标权重。论文给出 9 页、8 幅图的离线评测和快手大规模线上 A/B，报告排序质量与长期留存均显著优于强基线。

INSIGHT搜索 CTR 并不等于满意度，特别是结果页快速返回、重复改写或后续留存等 query 级行为能补足 item 点击信号。社区搜索可借鉴其分层奖励与目标关系建模，但应先离线回放验证奖励代理是否抗位置偏差，再以小流量优化融合层，避免 RL 直接改变召回与精排主模型造成不可控波动。

Renzhe Zhou, Songyang Li, Feiran Zhu, Chenglei Dai, Yi Zhang, Yi Wang, Jingwei Zhuo

When Iterative RAG Beats Ideal Evidence: A Diagnostic Study in Scientific Multi-hop Question Answering

论文在 ChemKGMultiHopQA 上让 11 个模型分别运行无上下文、一次性 Gold Context 与迭代 RAG，诊断检索覆盖、anchor 丢失、query 质量、组合忠实度和停止校准。训练免费的“检索—假设修正—证据感知停止”控制器持续超过理想静态证据，最高提升 25.6 个百分点。

INSIGHT多跳问题的关键不只是把所有相关内容一次塞给模型，而是按推理进度逐步取证并允许修正早期假设；这对复杂社区问题和专题搜索同样适用。上线前应把 hop 覆盖率、干扰证据锁定和过早停止设为可观测指标，因为论文也发现即使检索完美，证据组合失败仍可能很高。

Mahdi Astaraki, Mohammad Arshi Saloot, Ali Shiraee Kasmaee, Hamidreza Mahyar, Soheila Samiee

CMT-RAG: Complementary Memory Traces for Multi-turn Multi-hop RAG

CMT-RAG 不再把多轮历史压成原始对话或无结构摘要，而用状态空间生成器拆出检索型子问题，并把证据落成 session 级 DAG 的持久 reasoning trace。作者同时发布带跨轮子问题依赖标注的 MuMu-QA；在该基准和语料级 RAG 评测上，方法的答案准确率持续超过 5 类 RAG 基线。

INSIGHT多轮搜索真正需要记住的是“上轮用了什么证据、解决了哪一步”，而不是整段聊天文本；结构化 trace 能减少后续 query 重写时的语义漂移。社区搜索助手可把实体、约束、已验证证据和未完成子问题写入轻量 DAG，但要限制 trace 生长并提供过期机制，避免旧证据持续污染新意图。

Lang Zhou, Yingjian Chen, Shuxuan Li, Kun-Yu Lin, Zhilin Zhao

Reproducing LightMem: Naive RAG Is Just as Good for Memory Management

University of QueenslandCSIROGoogle

这项复现把 LightMem 的结构化记忆与直接检索原始用户轮次的 Naive RAG 对齐比较，发现只更换检索器就会让同一记忆库的答案准确率从 58.1% 变到 75.5%。相同检索深度下 Naive RAG 通常更好，LightMem 只在回答 token 预算紧张时占优，oracle 还显示记忆构建会丢失答案相关信息。

INSIGHT复杂记忆层可能把检索问题伪装成摘要问题；在引入记忆压缩前，应先把原始交互当文档建立强召回与重排基线。对搜索对话，可按 token 预算动态选择原始轮次或压缩记忆，并把 retriever 作为独立变量评测，否则 17.4 个百分点的模型差异会被错误归因给记忆架构。

Yongjie Zhou, Shuai Wang, Bevan Koopman, Guido Zuccon

GoldenRetriever: Non-Interactive Homomorphic Encrypted Retrieval for Privacy-Preserving RAG

GoldenRetriever 用 CKKS 同态计算在密文上完成相似度评估，并以阈值筛选替代加密 top-k 排序，把计算复杂度从语料规模的平方级降到线性级；precision-stable mask polarization 负责可靠恢复命中文档。标准检索基准显示其效果接近明文方案，同时延迟显著低于基于排序的加密检索。

INSIGHT当社区搜索需要处理私密草稿、企业知识或敏感用户画像时，阈值检索比在密文上精确排序更现实，也能隐藏 query、分数和命中索引。当前证据尚未给出生产级绝对延迟，适合先用于小规模高敏知识库验证阈值校准、返回集合大小与召回损失，不宜直接替换公共内容主检索。

Yang Gao, Gang Quan, Scott Piersall, Qian Lou, Dongdong Wang, Liqiang Wang
