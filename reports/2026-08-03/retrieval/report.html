QASP: Query-Adaptive Robust Vector Search Policy

QASP 针对固定 ANN 搜索参数导致不同 query 召回波动的问题，用一次监督回归预测每条查询的完整 recall-progress 曲线，再按目标召回率生成搜索深度策略，并用无额外推理的反馈修正偏差。实验在大规模与分层索引上无需重训即可泛化，在 99% recall 目标下减少 80% 数据访问。

OPERA: Online Data Pruning for Efficient Retrieval Model Adaptation 深度解读

1. 问题与动机

稠密检索模型在实际应用中需要针对特定领域进行微调，但并非所有训练数据对学习过程的贡献相同。现有的数据剪枝方法（如 InfoBatch）假设训练样本是独立同分布的，忽略了检索训练独特的两阶段采样结构——先采样 query，再为每个 query 选择正负 document。这种层次化结构意味着传统剪枝方法无法直接迁移。

作者首先研究了静态剪枝（SP），即在训练前仅保留余弦相似度最高的 query-document 对。实验揭示了一个关键矛盾：SP 提升了排序质量（NDCG），但会因 query 多样性下降而损害召回率（Recall）。具有较少高质量正样本的 query 被整体排除，导致模型在这些 query 上的泛化能力退化。这一「质量-覆盖权衡」(quality-coverage tradeoff) 是检索场景特有的问题。

2. 方法详解

OPERA 框架包含两种互补的剪枝策略：

静态剪枝 (SP)：使用预训练模型计算 query-document 对的余弦相似度，按保留率 k 截取得分最高的训练对。保留率定义为 k = Σ_q Σ_d I_d / Σ m_q，其中 I_d 为保留指示函数。SP 方法速度极快（<500 迭代即可收敛），但存在上述质量-覆盖权衡。

动态剪枝 (DP)：保持完整训练集，通过自适应调整采样概率来优先利用高质量样本。关键创新在于分层调度：

  • Query 级别：对高质量 query 赋予 α 倍的采样权重（α>1），低质量 query 保持基础权重。高质量 query 的判定阈值在训练过程中动态调整，截断比例从 r_s=0.25 逐步增加。
  • Document 级别：对每个 query 下的正样本按质量赋予 β 倍采样权重，截断比例从 v_s=0.25 渐进到 v_e=0.5。
  • 余弦退火调度：采样强度参数 α(t) = α_e + ((1 + cos(t/t_max·π))·(α_s - α_e))/2，从 α_s=2 退火到 α_e=5，即训练后期对高质量样本的偏好更强。

训练配置方面：bge-large-en-v1.5（335M 参数）使用学习率 1e-6、batch size 64、FP16 精度、温度 0.02；Qwen3-Embedding-0.6B（解码器架构）使用学习率 1e-5、训练 2000 步、BF16 精度。为降低计算开销，DP 每 100 步（I_u=100）才重新计算采样权重，将额外开销从 4.5% 降至 1.64%。

两阶段组合 (SP+DP)：先用 SP 过滤噪声数据（保留 50%-75%），再在过滤后的数据上运行 DP，适用于标注噪声较大的场景。

3. 核心技术贡献

贡献一：揭示检索训练中的质量-覆盖权衡。与分类任务不同，检索训练的两阶段采样结构导致静态数据过滤必然牺牲 query 多样性。这一发现解释了为什么简单的数据筛选在检索场景中效果不稳定——NDCG 和 Recall 无法同时优化。

贡献二：分层动态剪枝策略。通过在 query 和 document 两个层级独立调整采样概率，DP 在不丢弃任何数据的前提下优先利用高质量样本。消融实验表明两个层级提供互补信号：单独使用 query 选择得到 NDCG@10=0.517，单独使用 document 选择得到 0.516，组合使用达到 0.524。

贡献三：理论保证。通过 Theorem 1 建立了剪枝优于标准微调的充要条件：当选择质量 γ > m_q^+/m_q（即真正例率超过基线率）时，剪枝必然优于全量训练。

贡献四：跨架构验证。在 encoder-only（BGE）和 decoder-based（Qwen3）两种架构上验证了方法的有效性，证明 OPERA 不依赖特定模型结构。

收敛速度：DP 在 FEVER 数据集上仅需不到 8000 步即达到 FT 在 16000 步时的水平，实现了 <50% 训练时间达到同等性能 的目标。SP 收敛更快（<500 步），但以牺牲 Recall 为代价。

Qwen3-Embedding 结果：即使在训练预算受限（2000 步 vs BGE 的 8000-32000 步）的不利条件下，DP 在 TriviaQA 上达到 NDCG@10=0.504（vs FT 的 0.489），验证了方法对 LLM 检索器的适用性。

5. 局限与未来方向

作者指出的主要局限包括：(1) 方法在训练预算极度受限时效果减弱——Qwen3 实验中 DP 的提升幅度小于 BGE，可能因为过少的训练步数限制了动态调度的发挥空间；(2) 超参数设置（如截断比例 r_s、采样强度 α_s/α_e）需要针对数据集调整，尽管默认设置在多数场景下表现稳健；(3) 当前仅在正样本层面进行剪枝，未探索对负样本采样策略的联合优化。

6. 工业实践意义

直接可用的实践指导：

  • 排序优先场景（如搜索结果排序）：使用 SP，训练速度极快且 NDCG 提升最大
  • 排序+召回兼顾场景（如社区搜索）：使用 DP，在两个维度上均获得提升
  • 标注噪声较大时：使用 SP+DP 两阶段流水线

部署优势：DP 的计算开销仅 1.64%（I_u=100），但能将达到同等性能所需的训练时间缩短 50% 以上。对于需要频繁针对新领域迁移的搜索系统（如社区搜索中的新话题域适配），这意味着显著的 GPU 成本节约。

架构兼容性：在 encoder-only 和 decoder-based 两种主流检索架构上均验证有效，说明该方法可直接应用于当前从传统 bi-encoder 向 LLM-based retriever 的技术迁移过程中。

数据效率启示：对于训练数据有限或质量参差的场景，OPERA 的分层采样策略比简单的数据清洗更优——它不丢弃任何数据，而是通过智能采样充分利用数据中的有效信号。

HyPE 把 HyDE 的在线假想答案生成移到建库阶段：为每个 chunk 预生成多个可能问题，使线上检索转化为 query-query 匹配，从而避免运行时 LLM 调用。六个常用数据集上，相比标准方法，检索上下文精度最高提升 42 个百分点、claim recall 最高提升 45 个百分点，且可叠加重排和多向量检索。

SaFRO 面向短视频搜索多任务融合，把 query 级行为代理汇成满意度奖励，并以组内、跨批次双重相对偏好更新融合策略；Task-Relation-Aware 模块再按上下文调整各目标权重。论文给出 9 页、8 幅图的离线评测和快手大规模线上 A/B，报告排序质量与长期留存均显著优于强基线。

INSIGHT搜索 CTR 并不等于满意度，特别是结果页快速返回、重复改写或后续留存等 query 级行为能补足 item 点击信号。社区搜索可借鉴其分层奖励与目标关系建模，但应先离线回放验证奖励代理是否抗位置偏差，再以小流量优化融合层，避免 RL 直接改变召回与精排主模型造成不可控波动。

1. 问题与动机

短视频搜索系统中的多任务融合（Multi-Task Fusion, MTF）是将异构预测信号（点击率、播放时长、点赞率等）聚合为统一排序分的关键环节。现有方法主要优化即时参与度指标，但这往往与长期用户满意度不一致——用户可能点击了但并不满意。

将强化学习（RL）应用于搜索满意度优化面临两个根本挑战：(1) 数据极度稀疏——在快手平台上，搜索的正向交互密度仅为推荐 feed 的十分之一，用户搜索行为序列长度比推荐序列短两个数量级；(2) 意图约束——搜索由明确的 query 驱动，用户通常只浏览少量结果就结束会话，使得将长期结果归因到具体排序决策变得极其困难。

2. 方法详解

2.1 满意度感知奖励建模

SaFRO 创新性地构建 query 级（而非 item 级）满意度代理信号：

  • 查询重构（Query Reformulation）：用户是否发出语义相关的后续查询，作为不满意的强负向指标。若发生重构，满意度奖励直接置零。
  • 会话间隔（Session Gap）：当前查询与下次查询的时间间隔，经用户历史 β 分位数基线归一化后指数衰减：$s_{gap} = \exp(-\tilde{g}/T)$。

两者通过复合公式融合：$r_{sat} = (1-\mathbb{I}_{reform}) \cdot [\alpha \cdot \exp(-\tilde{g}/T) + (1-\alpha) \cdot \mathbb{I}_{ret}]$，其中 α=0.5 为最优平衡点（Pearson 相关性分析验证）。

在此基础上训练列表级奖励模型 $R_\phi$，将用户-query 上下文和排序列表特征映射为标量满意度分数。

2.2 Dual-Relative Policy Optimization (DRPO)

DRPO 是论文的核心算法创新，在标准 GRPO 的组内相对优势之上引入批次级上下文：

双重优势分解：对每个状态 $q_i$ 生成 G 个候选动作，计算：

  • 组内相对优势：$A_g^{i,group} = (r_g^i - \mu^i) / \sigma^i$
  • 批次相对优势：$A_g^{i,batch} = (\mu^i - \mu_{batch}) / \sigma_{batch}$
  • 双重优势：$A_g^{i,dual} = A_g^{i,group} + A_g^{i,batch}$

关键性质：(1) 不变局部排序——任意两个动作的偏好序仅由组内项决定，保持细粒度区分；(2) 梯度自然分解为两项——Term I 负责组内排序，Term II 作为动态调制因子，放大高质量 query 的梯度并抑制低质量 query 的梯度。

2.3 复合奖励与 TRAF 模块

训练使用复合奖励 $r = r_{eng} + r_{sat} + r_{fmt}^a + r_{fmt}^r$，包含参与度奖励（NDCG 风格）、满意度奖励、以及格式约束（权重和约束和相关性约束）。

Task-Relation-Aware Fusion (TRAF) 模块通过可学习的 task 关系矩阵建模任务间依赖：$\tilde{z}_i = gate_i \cdot z_i + \sum_j softmax(e_{ij}) \cdot z_j$，使融合权重能根据上下文自适应调整。

2.4 训练设置

基于快手搜索平台 21.5 亿 session 数据训练。DRPO 使用组大小 G=32，熵系数 β=0.05，PPO 风格的裁剪比率。

3. 核心技术贡献

  1. Query 级满意度建模：首次在工业搜索系统中提出基于查询重构率和会话间隔的满意度代理，解决了搜索场景中 item 级信号稀疏的问题。相比 item 级建模，query 级信号与搜索的"一次查询多次浏览"交互模式更匹配。
  1. DRPO 算法：在 GRPO 基础上引入批次级上下文，数学上证明了梯度分解为组内排序项和批次重加权项。消融实验显示去除批次优势后 NDCG 和满意度均显著下降。
  1. TRAF 融合模块：通过注意力机制建模任务间关系，使权重分配能感知任务间的耦合关系（如长播与点击的正相关、相关性与点击的互补关系）。
  1. 端到端 RL 优化搜索满意度：将参与度、满意度和格式约束统一到复合奖励函数中，在工业规模搜索系统上实现了 RL 的成功应用。

4. 实验结果分析

离线实验

在快手 21.5 亿 session 数据集上，SaFRO 在所有 7 个指标上达到 SOTA：

指标SaFRO最强基线(AURO)提升
NDCG0.64310.6384+0.7%
Satisfaction0.80220.7962(RLUR)+0.8%
Relevance0.86560.8467(AURO)+2.2%
User Retention0.81730.8054(DCN)+1.5%

值得注意的是，传统 LTR 方法（LambdaRank/NeuralNDCG）在 NDCG 上表现可接受，但满意度和留存显著落后，验证了即时指标与长期满意度的脱节。

消融实验

  • 去除满意度模型（w/o SAT）：满意度和留存急剧恶化，NDCG 也下降——证明满意度信号对短期指标也有正向作用
  • 去除批次优势（w/o Batch-Adv）：NDCG 和长期指标均显著下降
  • 去除 TRAF 模块：除相关性外各指标一致下降

在线 A/B 实验

在快手搜索平台 10% 流量部署两个月：

  • 查询重构率：-0.319%（满意度提升的直接证据）
  • 点击率：+0.136%
  • 长播比率：+0.495%
  • 观看时长：+0.611%

留存轨迹在 60 天内持续与基线拉开差距（p<0.05）。

超参数敏感性

  • 组大小 G：G=32 在满意度和留存上最优，G=16 在 NDCG 上最优，选择 G=32 作为平衡
  • 熵系数 β：倒 U 形曲线，β=0.05 最优；β=0.01 探索不足，β=0.30 过度正则化

5. 局限与未来方向

作者明确指出的局限：

  • 当前聚焦于离散动作空间（通过权重分箱），尚未探索连续动作空间
  • 满意度模型的训练数据质量依赖性
  • 超参数需要针对数据集调优

作者提出的未来方向包括扩展到其他搜索模态、利用 LLM 获取更丰富的状态表征、以及探索生成式架构突破传统打分方法的局限。

6. 工业实践意义

直接可采纳点：

  • 满意度代理设计：查询重构率和会话间隔是低成本且通用的满意度信号，任何搜索系统都可以构建。对 UGC 社区搜索，用户是否重新搜索、何时离开是现成的满意度度量。
  • DRPO 算法：相比标准 GRPO，实现复杂度增加有限（仅额外计算批次级统计量），但提供了更稳定的训练和更好的泛化。

部署考量：

  • SaFRO 已在快手搜索（4 亿+ DAU、8 亿+ 内容、21.5 亿 session）上线，证明了工业可行性
  • RL 训练需要在线策略采样，对基础设施有一定要求
  • 满意度奖励模型需要定期更新以适应用户行为变化

适用场景：

  • 特别适合即时参与度与长期满意度不一致的场景（短视频、UGC 内容、新闻搜索等）
  • 搜索场景中 RL 数据稀疏是普遍问题，DRPO 的双重相对性设计为此提供了通用解法
