Strata: Hierarchical Context Caching for Long Context Language Model Serving

针对长上下文服务中 KV 缓存跨 GPU HBM、CPU 内存和 SSD 搬运时易受碎片小传输、加载停顿与延迟命中拖累的问题，Strata 以 GPU 辅助大块 I/O 配合缓存感知调度。系统已集成 SGLang 并投入生产，相比 vLLM-LMCache 吞吐最高提升 5 倍、相比 TensorRT-LLM 提升 3.75 倍，且不损害短上下文性能。

Efficient LLM Serving on Commodity GPU Clusters with Data-Reduced Cross-Instance Orchestration

Sun Yat-sen University

EcoServe 面向普通以太网 GPU 集群，提出部分解耦的 prefill/decode 协作方式，并用实例循环激活、自适应路由和 mitosis 扩缩容缓解阶段干扰。在 32 张 NVIDIA L20 上服务 30B/70B 模型时，相对 vLLM、Sarathi、DistServe 与 MoonCake 的 goodput 提升 1.96～2.51 倍，代码已公开。

INSIGHT该工作说明中等规格集群无需照搬高带宽机房的完全解耦架构，按时间切分 prefill/decode、减少跨实例数据量往往更合算。搜推团队部署生成式改写或摘要模型时，可把网络带宽纳入路由和弹性策略，用宏实例封装多卡协作，并通过线上负载校准部分解耦比例。

MPK: A Compiler and Runtime for Mega-Kernelizing Tensor Programs

CMUTsinghuaNVIDIAMichiganPeking University

MPK 将多 GPU 模型推理自动编译为单个持久化 mega-kernel：先构造 SM 粒度依赖图，再做跨算子流水、计算通信重叠，并由核内去中心化运行时调度任务。公开评测显示，它相对传统一算子一 kernel 的 LLM 服务系统可将端到端推理时延最多降低 1.7 倍，Mirage 实现已经开源。

INSIGHT真正的低时延优化正从单算子内核转向跨算子的 SM 级联合编排，这能消除 kernel launch 与全局同步造成的空洞。对于搜索链路中的小批量 reranker 或生成模型，可先识别稳定计算图和通信热点，再评估 mega-kernel；动态 shape 很多的业务仍需保留传统执行路径作为回退。

Mixture-of-Translators: Translating KV Caches Across Heterogeneous Large Language Models

MoT 解决异构 LLM 无法复用彼此 KV cache、同一检索证据需反复 prefill 的问题，以多个 translator 建模源—目标映射，并用 Context Correction Loss 对齐目标模型原生轨迹。在 Qwen2.5、GPT-2、OPT 间转换时，7B 级闭集 QA 平均准确率为 51.0%、抽取式 QA F1 为 0.43；长上下文生成保留直接输入质量的 96.3%。

INSIGHT多模型路由系统若能转换 KV cache，就可让大模型接续小模型已读取的证据，显著减少重复 prefill 和缓存副本。工程落地时要同时控制早注入导致的累计偏移与晚注入造成的末状态偏移，并先在固定模型对、只读共享上下文上试点，监控质量保真和翻译开销是否抵消节省。

BLADE: Boundary-Expanded and Layer-Adaptive Dynamic Exit for Efficient LLM Reasoning

BLADE 在句子、自我怀疑和段落边界设置多粒度检查点，以重复续答生成退出标签，再自动挑选少量信息层训练探针，并用校准概率与确认规则决定提前终止。在 5 个基准和两种 Qwen3 推理模型上，它基本保持原始准确率，同时将 Qwen3-8B 与 4B 的生成 token 分别减少 24.8% 和 15.8%。

INSIGHT推理提速不必只做固定 token 上限，利用自然语义边界判断“答案是否已充分”更能减少冗余复核。社区搜索中的 query 改写、解释生成可先在离线回放中训练轻量退出探针，并按任务风险设置二次确认；对答案可验证性弱的场景，应保留最大推理预算和置信度回退。

06 3.45

RareSense: Rarity-Aware Similarity Search for Anomaly Retrieval in Transactional Data

RareSense 针对稀疏集合检索被高频背景属性主导的问题，挖掘最小稀有项集并生成可靠关联规则，再把对象映射为稀疏规则画像，用融合逆支持度、置信度、lift、复杂度与稳定性的加权 Jaccard 比较。跨网络安全和通用类别数据的 4 类基准中，它取得评测相似度方法里最高的宏平均查询检索表现，配对检验显著优于原子特征基线。

INSIGHT当异常内容由多个低频特征共同定义时，单字段 IDF 无法表达高阶共现，规则画像能让近邻由“共享稀有证据”决定。该思想可用于社区风控检索、冷门主题聚类或作弊样本排查，但收益依赖异常模式可重复；上线前需限制规则数量，并测量建库成本与查询稀疏度。

Benchmarks Are Not Validation: A System-Level View of Financial LLM Applications

该立场论文指出，金融 LLM 应用同时包含数据、检索、生成、工具、编排、监控与人工升级，仅凭静态 benchmark 无法证明可上线。作者给出覆盖整条栈的多层验证框架，并要求 LLM-as-a-judge 配置多评审、明确 rubric、一致性与可审计性检查；论文基于行业验证经验，未报告新的基准提升数字。

INSIGHT对搜索/推荐 GenAI 服务，质量门禁应从模型分数扩展为检索失败、无依据生成、工具误用、升级错误和运行不稳定等系统证据。可借鉴其持续验证思路，把离线集合、线上回放、Agent 轨迹审计与人工抽检接入发布流水线；因论文缺少实证对照，具体阈值仍需业务自行校准。

08 3.20

Demystifying Entropy-based Selection for Chain-of-Thought Compression in Large Reasoning Models

论文系统复核用熵选择步骤压缩思维链的有效性，覆盖多种模型与推理任务，发现高熵或低熵筛选在全部评测设置中都不优于随机剪枝；低熵 token 只在数学任务看似有效，原因是数字 token 本身低熵且携带语义。激活修补少量原始 token 可恢复接近完整链的性能，说明任务信息分散在整条推理链。

INSIGHT若服务侧准备用 token 熵裁剪推理链，这项结果提示不要把启发式相关性误当成因果重要性。工程上应至少加入随机剪枝对照，并按任务类型分层评估准确率、token 节省和尾延迟；数学场景的收益可能来自数字分布偏差，不能直接迁移到 query 改写或文本排序解释。

Sara Candussio, Daniel Scalena, Luca Bortolussi, Elisabetta Fersini, Malvina Nissim, Gabriele Sarti

Benchmarks Are Not Monolithic: Sample-Level Auditing and Orchestration for LLM Evaluation

该工作把 benchmark 从单一总分拆为样本级审计，沿认知与知识需求、语言质量、任务属性、上下文及伦理安全 5 个潜在维度标注样本。作者在 MMLU、ARC、WinoGrande、HellaSwag、TruthfulQA 共 5 个常用基准上揭示总准确率掩盖的内部异质性，并据条件重组跨数据集评测子集。

INSIGHT模型平台应保存样本级能力标签，而非只展示一个平均分；这样可以按社区搜索任务需要组合“短文本理解、深层推理、事实性或安全”测试切片。落地时可把该框架接入评测数据仓库，跟踪版本在各切片的退化，但论文未提供线上部署或效率收益，需控制标注成本。

Evaluating Federated Pre-Training: On the Reliability of Downstream Fine-Tuning and Intrinsic Evaluation

论文比较联邦预训练模型的评测协议，在相同客户端数据上训练一组集中式与联邦式 16M 参数 Transformer，再将预训练测试集排序作为参照。GLUE 的全量、仅头部与少数据微调都不能稳定保留该排序，而直接在 GLUE 文本做 next-token prediction 与预训练 perplexity 呈强对应，说明下游微调可能误判预训练质量。

INSIGHT跨数据孤岛训练搜索语言模型时，单看下游微调分数可能把适配噪声误认为基座能力差异。平台可同时保留贴近预训练目标的内在指标与业务任务指标，并用模型排序一致性监控评测可靠性；但结论来自 16M 小模型，扩展到大规模参数和非独立同分布 UGC 前仍需复验。

Claudia Grosser, Maike Heuer, Denis Krompass, Thomas A. Runkler
