Align Then Adapt: Label-Efficient Adapter Learning for Asymmetric Dense Retrieval

论文针对复杂指令式查询与静态文档表征不对称、重建全库索引成本过高的问题，提出查询侧 Efficient Retrieval Adapter。方法先用无标注文档对齐强查询编码器与轻量文档编码器，再以少量查询—文档对适配；在六领域 126 个 MAIR 任务上，对称场景 nDCG@10 最高提升 8.2 点，非对称场景提升超过 12 点。

PEIR: Modeling Performance in Neural Information Retrieval

University of AmsterdamJohns Hopkins

PEIR 针对神经检索延迟高度依赖硬件、不同模型难以公平比较的问题，引入面向 Learned Sparse Retrieval 的硬件无关性能建模框架。它为 BlockMax-MaxScore 等查询执行方式估算内存访问与浮点运算量，并证明这些代理指标对模型效率优劣的判断与实测延迟结论相近，从而减少反复占用多套硬件基准测试的成本。

INSIGHT对搜索团队，PEIR 的价值是把“效果—效率”筛选提前到模型评审阶段：在 nDCG 之外统一记录访存量、FLOPs 与稀疏倒排执行特征，再只对候选方案做真实压测。论文较早，但用户偏好的工程可实施性很高；应把模型预测用于横向筛选，最终上线判断仍需生产硬件上的 P95/P99 延迟。

Pooya Khandel, Andrew Yates, A. Varbanescu, M. D. Rijke, Andy D. Pimentel

Multi-stage Literature Retrieval System Trained by PubMed Search Logs for Biomedical Question Answering

NIH

该系统以 PubMedBERT 初始化 bi-encoder 与 cross-encoder，第一阶段融合稠密检索和 BM25，第二阶段用交叉编码器重排；训练数据来自约 2.55 亿个 PubMed 查询—点击文章对。BioASQ 2023 文献检索任务要求返回 Top-10 文章，系统在三个批次中取得一次第二、两次第三，验证大规模真实搜索日志对领域召回与排序的价值。

INSIGHT它对 UGC 搜索最重要的启示是：真实 query—点击日志既可训练双塔召回，也可训练精排，并能让两个阶段共享领域语言。迁移时应加入去偏采样和曝光校正，避免把位置偏差当相关性；同时保留 BM25 通道覆盖实体名和新内容，再用 cross-encoder 消化语义难例。

Ashley Shin, Qiao Jin, Zhiyong Lu

PUMA: Post-Hoc Sparsification of Universal Multimodal Embeddings for Efficient Retrieval

PUMA 用稀疏自编码器把通用多模态模型的稠密向量映射为紧凑稀疏码，不重新训练原始 backbone；先保持稠密点积几何，再针对检索微调稀疏编码器。五个文本到图像及组合图像检索基准显示，在 Qwen3-VL-Embedding-2B 上四项效果不低于稠密检索，同时 FP32 向量存储减少 8–16 倍，检索最高加速 25 倍。

INSIGHT这项工作给图文 UGC 检索提供了“模型不动、索引瘦身”的工程路径，尤其适合已有多模态向量库但内存和延迟吃紧的系统。落地时应重点监控预 TopK 支撑不足和激活维度与检索目标错位两类失败模式，并按内容类目分桶验证召回损失，避免只看平均指标。

Pointing the Way, Hiding the Destination: Practical Private Dense Retrieval at Scale

论文面向托管 RAG 与语义搜索中的查询、命中文档隐私，使用学习式深度哈希生成随机二进制码以缩小候选集，再结合加密重排和 oblivious key transfer 隐藏精确查询及最终选择。仅保留 200–500 个候选即可在五个、规模 2.5 万至 540 万文档的零样本语料上接近全库效果，并在 268 万段落 NQ 语料上验证协议。

INSIGHT核心创新是把昂贵的全库密码学检索改造成“隐私过滤—加密精排”的级联结构，以可控候选宽度换取规模化可行性。对含私密搜索词或权限内容的社区场景，可把它用于企业知识库和敏感内容检索；但上线前必须同时压测网络带宽、候选泄漏面、授权校验和加密重排尾延迟。

Peichun Hua, Danyang Chen, Junan Zhang, Haifeng Sun, Jingyu Wang, Diwen Xue, Mingyu Li, Yunming Xiao

06 4.10

DocPC: Document-Level Visual Retrieval via Representative Page Composition

Google

DocPC 将多页文档中的代表页拼成单张网格图，直接构建文档级视觉索引，避免逐页召回后聚合造成的线性成本和跨页相关性损失。方法结合多正例对比学习与稀疏调度的 listwise 优化，并发布 DocViRe 基准；摘要报告索引图像、向量及存储量减少 10.1 倍，端到端建索引时间约缩短 7.7 倍。

INSIGHT代表页组合把文档级检索前移到索引阶段，适合图片帖、长图攻略、PDF 笔记等无法可靠 OCR 的 UGC。实践中可用版面多样性和文本覆盖率联合选页，再把网格召回结果接入现有文本精排；需要单独评估小字号信息丢失、跨页证据分散及不同页数文档的公平性。

Chengsong You, Junwei Zhou, Nan Du

Corpus2Skill: Distilling Enterprise Knowledge into Navigable Agent Skills for QA and RAG

Corpus2Skill 把边界明确的企业语料离线编译为层级 skill 目录，在线由 LLM 从全局摘要逐层导航到文档，并在错误分支回退，改变单次向量召回只看到局部结果的模式。作者在企业客服基准上报告其答案质量与 grounding 优于稠密、混合、层级检索及 agentic RAG 基线，并通过编码器对齐控制和配对显著性检验确认优势。

INSIGHT对结构化较强的社区知识内容，层级导航可显式告诉模型“已看过什么、还有哪些分支”，有助于复杂 query 的探索式召回。可先把类目、话题和实体图谱编译成轻量目录，与现有倒排和向量召回并行；但它增加多轮调用成本，应设置深度、回退次数和置信度停止条件。

Yiqun Sun, Pengfei Wei, Lawrence B. Hsieh

PlanSightRAG: A Visual-First Multimodal RAG for Automating Question Answering and Compliance Checking for Civil Standard Plans

PlanSightRAG 直接索引工程图像，组合 ColNomic-3B 多向量检索、Planner–Retriever–Auditor–Synthesizer 流程和 MaxSim 热力图证据，绕开 OCR 丢失几何布局的问题。其 4,056 对、1,898 页基准覆盖五个州交通部门，零样本 Recall@5 为 91.47%，在留出的 Michigan DOT 语料上仍达 91.40%。

INSIGHT虽然领域是工程图纸，但“视觉多向量召回＋可审计热力图”可迁移到社区长图、截图教程和信息图搜索。建议把热力图作为相关性标注与失败分析工具，而不是只展示最终答案；上线时要分别评估召回、规则解析和生成三个环节，避免端到端准确率掩盖检索缺陷。

Query-Side Attacks on GNN-Based KGQA: Tracing Failures from Entity Linking to Answer Generation

论文把 GNN 知识图谱问答拆成实体链接、子图召回、GNN 推理和答案生成四阶段，用保持答案不变的组合重写与关系同义替换分别攻击管线。ComplexWebQuestions 与 WebQSP 实验显示，只要子图完整，GNN 推理接近基线；主要脆弱点来自查询变化导致的实体链接及子图构建，而非推理模块本身。

INSIGHT对社区搜索的启示是，复杂 query 的端到端掉点应先定位到理解、召回还是排序，不能统一归因于大模型推理。可以仿照其阶段隔离协议构造口语改写、同义替换和语序变化测试集，并追踪实体链接成功率、候选覆盖率与最终 nDCG，优先修复真正造成损失的上游模块。

Pankaj Kumar, Subhankar Mishra

Reranking and two-stage retrieval: precision after recall

文章系统梳理两阶段检索：先用 BM25 或双塔向量模型从海量文档快速召回，再用 cross-encoder 或生成式模型进行高精度重排。它以 DPR、monoBERT 和 monoT5 为代表解释 bi-encoder 可离线索引、cross-encoder 保留完整交互的取舍，为选择候选规模、重排模型和延迟预算提供工程入门框架。

INSIGHT工业实践上，不应把“加重排”当作固定答案，而要先测首阶段 Top-K 覆盖率及分数间隔，再决定是否对低置信 query 选择性启用昂贵模型。对社区短文本搜索，可从 BM25＋向量混合召回、RRF 融合、轻量 cross-encoder 精排开始，并以分桶消融确认每一层对 nDCG、CTR 和尾延迟的净贡献。
