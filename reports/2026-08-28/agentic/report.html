论文把 Agent 的记忆、规划、动作协议与工具编排抽象为四模块可生成 Harness，并训练 JIT-Agent 针对任务即时合成、修复和自演化执行框架。搭配该系统后，DeepSeek-V4-Flash 在 DeepSearchQA 和 OdysseyBench 上分别超过 GPT-5.6 9.1 与 4.3 分，GLM-5.2 的部分任务增益最高达 20 分。

VoiceMem: Streaming Dual-Brain Memory for Real-Time Interaction

VoiceMem 为实时对话 Agent 构建并行的“信息左脑”和“情感右脑”，配合流式记忆读写、记忆感知训练及可替换后端部署。其 top-5 检索比 Mem0 的 top-200 高近 30 分，三个人设基准综合分较此前最佳提升 4.29 分，检索仅需 134 毫秒，已覆盖真实部署验证。

INSIGHT将事实记忆与情感、人格记忆分开建模，可避免单一向量库同时承担精确召回和个性化表达而相互干扰。对搜索对话产品，可把用户事实、会话情绪和长期偏好拆成独立索引并并行召回，再在生成阶段融合；134 毫秒结果说明记忆增强可以嵌入交互链路而不额外拉长语音等待。

When Stale Constraints Go Unchecked: Budgeted Verification Failures in Inherited Agent Memory

论文研究 Agent 继承摘要记忆后，如何在仅能核验两条记录的预算下识别已被撤销的约束。原生策略只有约五分之一会检查关键来源路径，导致三组实验中 74.7%—77.3% 的决策仍服从过期约束；把一个核验槽位定向分配给关键溯源路径，可将正确决策提高 61.3—74.0 个百分点。

INSIGHT记忆检索的相关性排序无法替代新鲜度和版本语义，尤其是策略、权限或商品状态会被后续记录撤销时。Agent 搜索链路应为约束类记忆保存来源、有效期和 superseded 指针，并在有限工具预算中预留一次权威源核验；这比简单扩大 top-k 更能减少高置信度的陈旧决策。

Kazuki Nakayashiki

GeoRA: 为RLVR设计的LoRA——ACL 2026杰出论文解析

Meituan

美团解析 ACL 2026 杰出论文 GeoRA，针对监督微调型低秩适配直接用于 RLVR 时出现的谱塌缩与训练不稳定问题，利用 RL 更新子空间的各向异性和可压缩结构，通过 SVD 提取主方向初始化低秩适配器。文章同时介绍该方法在履约业务 Agentic RL 中的落地经验。

INSIGHTRLVR 的梯度几何与 SFT 不同，LoRA 初始化不应继续沿用面向监督学习的经验配置。若要用可验证奖励训练搜索 Agent，可先分析真实 RL 更新的主子空间，再配置低秩方向与容量；这种做法有望降低全参训练成本，并让工具调用、记忆管理等策略在业务任务上更稳定收敛。

Addressing Corpus Knowledge Poisoning Attacks on RAG Using Sparse Attention

论文针对攻击者向语料库注入误导文档的 RAG 知识投毒，提出 Sparse Document Attention RAG：通过块稀疏注意力禁止不同检索文档之间相互注意，只需在推理时修改 attention mask。作者在多种问答模型与攻击策略上验证，该机制显著优于标准因果注意力 RAG，并保留文档内推理能力。

INSIGHT多文档联合注意力会让恶意证据污染其他正常证据，风险并非只来自召回排序。生产搜索 Agent 可在证据编码阶段隔离文档，再由受控聚合层融合结论；这种最小化改动适合先作为高风险知识库的防护开关，并应与来源信誉、重复内容检测和答案引用校验共同部署。

Sagie Dekel, Moshe Tennenholtz, Oren Kurland

Prefix Sliding for efficient test-time scaling

Prefix Sliding 观察到长推理中大多数中间 token 会随推理推进而失去作用，因此只保留包含指令与工具定义的前缀，以及最近数千 token 的滑动窗口。该方法无需训练即可把推理内存限制在固定规模，并使现有模型在基本保持任务性能的前提下最高提速 3 倍。

INSIGHT深度搜索 Agent 的轨迹会随检索轮次持续增长，而工具协议和当前推理状态比早期草稿更重要。工程上可固定保留系统约束、query 意图与工具 schema，把旧观察压缩进结构化记忆并滑动淘汰原始思维链；这样能把长程检索的显存和延迟从随步数增长改为近似有界。

Niklas Muennighoff, Zhengyang Wang, Zeyi Chen, Weijia Shi, Binyuan Hui

A Storage-Retrieval Gap in Parametric Knowledge Graph Memory

论文把知识图谱离线编译成“每实体一个 LoRA”的参数化记忆，以零查询上下文成本注入事实。MetaQA 单值关系上正确适配器比近乎失明的闭卷基座提高 0.243 exact match，但向量和权重空间相似检索都接近随机；权重几何与语义仅有 ρ=0.329 的相关性，无法保证功能可检索。

INSIGHT参数化存储能省去重复塞入上下文的 token 成本，却把难题从“存什么”转移到“如何选对适配器”。在搜索 Agent 中，不能直接把 embedding 近邻当作可组合知识模块；更稳妥的方向是训练 query 条件路由器，并保留文本 RAG 作为可追溯回退，尤其适合高频实体知识的分层缓存。

Martino M. L. Pulici, Cuong Xuan Chu, Evgeny Kharlamov, Volker Tresp

Experiment with Qwen3.8-Flash-Next on NVIDIA GB300 NVL72 for Agentic Coding

NVIDIAAlibaba

NVIDIA 提供在 GB300 NVL72 上试验阿里 Qwen3.8-Flash-Next 的 Agentic Coding 工程指南，覆盖模型权重、推理环境与面向工具执行的评测路径。该模型作为 Qwen4 架构预览，重点面向开发者验证长程代码理解、生成和执行能力，为搭建低延迟工具 Agent 提供可复用部署参考。

INSIGHT对搜索团队而言，价值不在单一代码基准，而在“模型—推理硬件—Agent Harness”联合验证的方法。上线工具型搜索 Agent 前，应在目标硬件上测量多轮调用吞吐、上下文增长、失败重试和结构化输出稳定性，并把模型版本切换封装在可回滚的服务层，避免只依据离线准确率选型。

Code World Model: Coding Agent as World Brain

Code World Model 将世界演化与视觉渲染解耦：编码 Agent 作为“世界大脑”，根据事件推理后果、生成可执行代码来维护持久状态并执行规则一致的演化，再把逐帧时空约束编译为代理视频供生成模型使用。该设计用显式程序状态弥补纯视频世界模型难以保持长期因果后果的问题。

INSIGHT把 Agent 的关键状态外化为可执行、可检查的程序，比完全依赖自然语言记忆更容易维持长期一致性。搜索与研究 Agent 可借鉴这种分层：用代码或结构化状态保存已验证事实、约束和任务进度，再让语言模型负责规划与解释，从而降低长轨迹中的状态漂移并提升失败后的可恢复性。

Yiwen Chen, Guosheng Lin, Chi Zhang

How to Train a Cross-Embodiment Robot Navigation Policy with AI Agents

NVIDIA

NVIDIA 介绍如何借助 AI Agent 训练跨形态机器人导航策略，把感知、规划、策略训练与仿真评估组织成可迭代工程流程。文章关注不同机器人本体之间的策略迁移和工具化训练，使 Agent 能围绕环境反馈持续调整导航方案，为长程自主任务提供产业级实践样本。

INSIGHT虽然场景不是文本搜索，但其闭环范式对 Agent 搜索有直接借鉴：把规划、执行、环境反馈和策略更新拆成明确接口，并用可复现实验环境验证每轮改动。搜索系统可将网页检索器视作环境工具，以证据覆盖率、引用正确率和成本作为反馈，避免只凭最终答案奖励训练黑盒策略。
