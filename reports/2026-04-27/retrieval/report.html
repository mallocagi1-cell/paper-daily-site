From Tokens to Concepts: Leveraging SAE for SPLADE

SPLADE 用 BERT 词表作为稀疏表征基底，存在多义/同义词膨胀的问题。作者用稀疏自编码器(SAE)从 LLM 隐层中提炼出"概念维度"，再以这些概念替换 SPLADE 的 vocab 投影头，得到 SAE-SPLADE。在 in-domain (MS MARCO) 与 out-of-domain (BEIR) 上检索效果与原版 SPLADE 持平，但 posting list 更短、推理更高效。论文已被 SIGIR 2025 收录。

KEY INSIGHT · 对业务意味着什么把稀疏检索的基底从词替换为概念，是稀疏召回的范式升级：UGC 短文本里同义、错别字、缩写极多，词级 SPLADE 容易膨胀到上万个非零维度，概念维度天然合并这些变体。落地启示：可在生产 SPLADE 之上叠加 SAE 投影头复用倒排索引，几乎零额外推理开销，是社区搜索召回端的优良候选方案。

RealRoute: Dynamic Query Routing System via Retrieve-then-Verify Paradigm

传统 RAG 中的 query routing 多为预测式分类器：先决定该走哪个数据源再去检索。RealRoute 反其道而行：先在所有源上做并行 source-agnostic 检索，再用一个动态 verifier 在检索结果上交叉验证，从而决定哪些源真正贡献了相关证据。在 multi-hop RAG 推理任务上显著优于预测式 baseline，且开放源码并提供可视化界面。

INSIGHT对多渠道社区搜索（帖子/问答/评论库分库召回）而言，retrieve-then-verify 比传统的硬分类路由更稳：把"我应该走哪条链路"延迟到证据出现之后再决定，相当于把先验决策替换为后验验证。落地代价是要并行触发多源召回并多算一次 verifier，可在 long-tail / hard query 上选择性开启，而不是全量铺开。

Jiahe Liu, Qinkai Yu, Jingcheng Niu, Xi Zhu, Zirui He, Zhen Xiang, Fan Yang, Jinman Zhao

A Technical Report on the Second Place Solution for the CIKM 2025 AnalytiCup Competition

CIKM 2025 AnalytiCup 多语言电商类目相关性赛题的亚军方案：用单个 Qwen2.5-14B 微调模型 + Chain-of-Thought 任务分解，依次执行翻译、意图理解、类目对齐、相关性判断四步。Public 0.8902 / Private 0.8889。结构简单但稳定，省去复杂 ensemble。

INSIGHT该方案验证了"提示工程 + CoT 任务分解"对相关性判定的有效性：把单步打分拆成可解释、可调试的 4 步小任务，效果接近模型集成且推理代价低。社区短文本搜索可直接借鉴：把"query→post 相关性"分解为"query 改写→意图槽位提取→候选语义对齐→最终评分"，用一个 14B 模型即可在工业延迟下完成。

Haotao Xie, Ruilin Chen, Yicheng Wu, Zhan Zhao, Yuanyuan Liu

Beyond Retrieval-Ranking: A Multi-Agent Cognitive Decision Framework for E-Commerce Search

JD.com

把电商搜索从 retrieve-rank 升级为多 agent 认知决策框架：query 理解 agent、候选生成 agent、对比 agent 与决策 agent 协同。针对带否定、多约束、推理需求的复杂 query 表现尤为突出，并在京东主搜进行了线上 A/B 验证，准确率与用户满意度均有提升。

INSIGHT多 agent 认知框架的真实价值不在"换架构"，而在把搜索系统从被动匹配升级为主动决策——能处理用户没显式表达的约束。对社区搜索而言，类似"反向意图("求避雷")、多条件帖子筛选"等 query 也存在；但落地代价高（多次 LLM 调用、长延迟），更现实是在长尾难 query 走 agentic 链路、其他场景维持原有 pipeline。

Zhouwei Zhai, Mengxiang Chen, Haoyun Xia, Jin Li, Renquan Zhou, Min Yang

Combining Structural and Textual Knowledge for Knowledge Graph Link Prediction via Large Language Models

TTongji University

WSDM 2026 论文。对 KG Link Prediction 任务，作者把结构子图（局部关系子图）与文本描述同时喂给 LLM，再用 LLM 进行候选关系打分。相比纯结构方法（TransE/RotatE）和纯文本方法，混合方案在多个 KG 基准上 hits@10 显著提升。

INSIGHT对社区搜索的可借鉴点：UGC 库内部本身有大量 entity-link 结构（用户、话题、地点、商品），把结构特征（共现图、tag-tag 图）和文本一起喂给 LLM 进行候选打分，可补足单一向量召回在 entity-centric query 下的短板。要点是别让 LLM 看完整图——只送 1-2 跳子图，否则上下文成本会爆。

Shijie Luo, Xinyuan Lu, Qinpei Zhao, Weixiong Rao

06 3.20

PEIR: Modeling Performance in Neural Information Retrieval

University of Amsterdam

ECIR 2025 论文。Learned Sparse Retrieval (LSR) 的效率评测严重依赖硬件，结果难复现。PEIR 借鉴 HPC 领域的性能建模方法，对 BlockMax-MaxScore 等查询求值算法构造硬件无关的性能模型，用 FLOPs/内存读写量作为 proxy。优点：(i) 标准化 efficiency 比较；(ii) 减少硬件依赖；(iii) 嵌入到 IR benchmark 中代价小。

INSIGHT对工程实践的启示：稀疏/稠密检索引擎的离线选型不应仅看实测 QPS，而要建立硬件无关的成本模型（FLOPs / cache miss），否则换一台机器全部要重跑。社区搜索做检索算法选型时，可在公司内沉淀类似 PEIR 的成本估算工具，加快新模型的上线评估。

Pooya Khandel, Andrew Yates, Ana-Lucia Varbanescu, Maarten de Rijke, Andy Pimentel
Semantic Scholar·2025-04-01·Relevance 3 · Novelty 4 · Practical 4 · Evidence 4 · Timely 1

An Empirical Analysis of Pruning Techniques: Performance, Retrievability and Bias

RMIT UniversityUniversity of Strathclyde

CIKM 2017 经典工作。对倒排索引 pruning（截断长 posting list）三类常用方法做全面实证：在 effectiveness、retrievability（每个文档被检出的概率）、bias（系统倾向偏好哪类文档）三个维度做权衡分析，揭示 pruning 在性能与公平之间存在系统性偏差。

INSIGHT经典文献提醒：所有 pruning / 召回截断都不是中立优化——它会系统性地把某些文档（如长文、低频词文档）排除在结果池外。社区搜索做召回截断时，应额外监控"被检出概率分布"的偏移，避免长尾内容被工程优化"压死"。这是当代向量 ANN 也一样会遇到的问题。

Ruey-Cheng Chen, Leif Azzopardi, Falk Scholer
