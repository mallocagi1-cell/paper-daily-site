π-Play: Multi-Agent Self-Play via Privileged Self-Distillation without External Data

针对深度搜索 Agent 训练中稀疏奖励、弱信用分配和标注数据不足的问题，提出基于特权信息自蒸馏的多 Agent 自博弈框架 π-Play。核心发现：自博弈过程中生成的「问题构造路径」(QCP) 天然包含逆向求解过程，可作为教师模型的特权上下文，无需外部人类反馈或人工标注即可实现高效自蒸馏训练。该方法为 deep search agent 的可扩展训练提供了全新范式。

RAG or Learning? Understanding the Limits of LLM Adaptation under Continuous Knowledge Drift in the Real World

提出面向真实世界持续知识漂移场景的系统性评测基准，基于带时间戳的证据数据比较 RAG、持续微调和知识编辑三种 LLM 适应策略。实验表明：当知识快速变化时，RAG 在保持时效性方面显著优于微调方法，但在需要深层推理的场景中存在局限。该工作为搜索系统选择 RAG vs 微调策略提供了定量决策依据。

INSIGHT该研究首次在连续知识漂移条件下系统比较了多种 LLM 适应方案的表现边界。对 UGC 搜索场景的实践启示：社区内容更新极快，纯微调方案无法跟上知识漂移速度，RAG 在时效性上有天然优势，但需要搭配有效的检索策略。实际部署时应采用 RAG + 定期微调的混合策略，根据知识变化频率动态调整两者比例。

Hanbing Liu, Lang Cao, Yang Li

ToolSpec: Accelerating Tool Calling via Schema-Aware and Retrieval-Augmented Speculative Decoding

PolyU

针对 LLM 多步多轮工具调用的延迟瓶颈，提出 ToolSpec——基于工具 schema 感知和检索增强的推测解码方法。利用有限状态机在确定性 schema 填充和推测生成间交替，结合检索历史调用模式加速变量字段生成。该方法可直接集成到现有 LLM 服务框架中，显著降低 agentic 系统中工具调用的端到端延迟。

INSIGHTToolSpec 的核心洞察是工具调用 trace 具有高度结构化特征且遵循固定 schema，可利用这种结构性进行推测解码加速。对搜索 Agent 系统的实践启示：当搜索 Agent 需频繁调用多个外部工具（召回、排序、改写等）时，schema-aware 的推测解码可大幅降低推理延迟。该技术可直接应用于 vLLM/SGLang 等推理框架的 tool calling 场景。

Heming Xia, Yongqi Li, Cunxiao Du, Mingbo Song, Wenjie Li

MM-Doc-R1: Training Agents for Long Document Visual Question Answering through Multi-turn Reinforcement Learning

Fudan

针对传统 RAG 系统在复杂多跳查询中单次检索不足的问题，提出 MM-Doc-R1 框架：用 agentic 视觉感知工作流实现迭代式信息发现与综合。核心创新是 Similarity-based Policy Optimization (SPO)，通过语义相似度加权的 baseline 估计解决多轮 RL 中 GRPO 的偏差问题。实验显示在多个文档 VQA 基准上超越开源基线，接近闭源模型水平。

INSIGHTSPO 方法揭示了多轮 RL 中一个重要洞察：轨迹越相似，其共享 baseline 估计越精确。这一原理超越了文档 VQA 本身，可迁移至任何 agentic 检索场景的强化学习训练。对搜索 Agent 的启示：当用 GRPO/PPO 训练多轮检索 Agent 时，应基于轨迹相似度而非简单平均来计算 advantage baseline，以提升训练稳定性和效率。

Bridging Protocol and Production: Design Patterns for Deploying AI Agents with Model Context Protocol

基于大型云厂商 MCP 服务器的企业级部署经验，识别了 MCP 标准中三个缺失的协议原语：身份传播、自适应工具预算分配和结构化错误语义。提出三个补充机制：Context-Aware Broker Protocol (CABP)、Adaptive Timeout Budget Allocation (ATBA) 和结构化错误传播协议。截至 2026 年初 MCP 已有 10,000+ 活跃服务器和 9,700 万月 SDK 下载量。

INSIGHT该论文从生产环境实际部署中提炼了 MCP 的关键缺陷和解决方案，是目前最具实操价值的 MCP 工程实践论文。对搜索 Agent 系统的启示：在构建多工具协作的 agentic search 系统时，需要在协议层解决身份作用域路由、异构延迟下的工具超时预算分配以及跨工具的错误传播三个关键工程问题。ATBA 的预算分配思路可直接应用于搜索 Agent 的多阶段检索超时管理。

The Long-Horizon Task Mirage? Diagnosing Where and Why Agentic Systems Break

UW-MadisonUC Berkeley

提出 HORIZON——首个跨领域长序列任务诊断基准，系统性地分析 LLM Agent 在长步骤任务中的退化模式。评估了 GPT-5 变体和 Claude 系列模型共 3,100+ 条轨迹，提出基于轨迹的 LLM-as-a-Judge 失败归因管线，并通过人工标注验证。揭示了 Agent 随任务步骤增长性能急剧退化的关键失败模式。

INSIGHT该工作首次量化证明了当前 SOTA Agent（包括 GPT-5 和 Claude）在长序列任务上的系统性退化，为 Agent 可靠性研究提供了科学基础。对搜索 Agent 的启示：多步检索 Agent 的失败通常不是单点失误，而是随步骤累积的系统性退化。设计 agentic search 系统时应在轨迹层面而非单步层面进行质量监控，并在关键步骤设置检查点。

The Cognitive Companion: A Lightweight Parallel Monitoring Architecture for Detecting and Recovering from Reasoning Degradation in LLM Agents

针对 LLM Agent 在多步任务中高达 30% 的推理退化率（循环、漂移、卡死），提出轻量级并行监控架构 Cognitive Companion。包含两种实现：LLM-based Companion（降低 52-62% 重复率，约 11% 开销）和 Probe-based Companion（基于隐层状态训练探针，AUROC 0.840，零推理开销）。在 Gemma 4 E4B 上验证了可行性。

INSIGHTProbe-based Companion 的零开销特性是最大亮点：通过在 LLM 第 28 层隐层状态上训练轻量探针，实现零额外推理成本的推理退化检测。这对搜索 Agent 部署有直接启示：可在 Agent 推理过程中旁路接入探针检测器，实时发现循环/漂移等异常状态并触发恢复机制，不增加线上延迟。

ToolOmni: Enabling Open-World Tool Use via Agentic Learning with Proactive Retrieval and Grounded Execution

HIT

针对开放世界场景中海量且持续演化的工具库，提出统一 agentic 框架 ToolOmni，通过主动检索和接地执行实现开放世界工具使用。先用冷启动多轮交互数据 SFT 注入基础 agentic 能力，再引入 Decoupled Multi-Objective GRPO 算法同时优化工具检索准确率和执行效果。解决了静态 embedding 检索和参数记忆方案在工具语义对齐和泛化上的不足。

INSIGHTToolOmni 的 Decoupled Multi-Objective GRPO 将工具检索和执行解耦为两个独立优化目标，避免了两者在联合优化中的冲突。这对搜索系统的启示：当 Agent 需要同时优化「选对工具」和「用好工具」两个目标时，解耦优化比端到端联合训练更有效。该 SFT→RL 的两阶段训练范式可直接应用于搜索 Agent 的工具调用能力训练。

Shouzheng Huang, Meishan Zhang, Baotian Hu, Min Zhang

KG-Reasoner: A Reinforced Model for End-to-End Multi-Hop Knowledge Graph Reasoning

针对 LLM 在知识图谱多跳推理中的精确度不足问题，提出 KG-Reasoner 端到端框架，将多步推理统一为一个整体的「思考「阶段而非孤立的管线步骤。克服了传统方法将推理分解为独立步骤、缺乏灵活性和中间信息丢失的问题。该方法整合了 LLM 理解能力与 KG 结构化知识的优势。

INSIGHTKG-Reasoner 的关键设计是将多跳推理从流水线式分解转为端到端统一推理，保留了步骤间的上下文依赖。对搜索 Agent 的启示：构建基于知识图谱增强的搜索 Agent 时，应避免将推理过程分解为独立的「实体识别→关系查找→答案生成」管线，而是设计端到端的推理框架以保持中间状态的连贯性。

Shuai Wang, Yinan Yu

WebXSkill: Skill Learning for Autonomous Web Agents

Microsoft

针对自主 Web Agent 在长序列任务上的瓶颈，提出 WebXSkill 框架：引入「可执行技能「概念，将参数化动作程序与自然语言引导配对，同时支持直接执行和 Agent 驱动的自适应调整。三阶段流程：从合成轨迹中挖掘技能、组织为 URL 图谱索引、运行时按需检索组合。来自 Microsoft Research，基于真实浏览器任务评估。

INSIGHTWebXSkill 的核心创新是弥合了「文本技能描述（可理解不可执行）」与「代码技能（可执行不可理解）」之间的鸿沟。对搜索 Agent 开发的启示：当构建复杂搜索 Agent 时，应将常用操作序列提炼为可复用的「可执行技能」，每个技能既有明确的代码实现又有自然语言说明，使 Agent 在出错时能理解技能语义并自适应调整。
