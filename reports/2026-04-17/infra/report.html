1. Sandwich: Joint Configuration Search and Hot-Switching for Efficient CPU LLM Serving
4.30
Relevance 4 | Novelty 4 | Practical 5 | Evidence 3 | Timely 4

Summary: CPU 在 LLM 推理中因成本低、可用性高而具有重要价值，但 prefill 和 decode 阶段资源需求冲突导致性能瓶颈。Sandwich 提出了一套全栈 CPU LLM 推理优化方案，通过联合配置搜索（考虑 sub-NUMA 硬件结构）和热切换机制消除跨阶段干扰。该方法在非拆分部署约束下，通过动态切换 prefill/decode 配置实现最优资源利用，显著提升 CPU 推理的吞吐量和延迟表现。

Key insight: Sandwich 的核心创新在于将 CPU LLM 推理建模为资源配置优化问题，并引入 sub-NUMA 感知的搜索空间和运行时热切换机制。对于搜索推荐系统而言，CPU 推理优化提供了一条低成本部署 LLM 的路径，特别适合边缘场景或成本敏感的在线推理服务。热切换思路可借鉴于 prefill/decode 分离部署中的资源动态分配。

2. Calibrated Speculative Decoding: Frequency-Guided Candidate Selection for Efficient Inference
4.10
Relevance 4 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: 投机解码通过小模型草稿绕过全量验证来加速自回归生成，但传统框架因频繁误拒（语义正确但词汇不同的输出）而效率受限。本文提出 Calibrated Speculative Decoding (CSD)，一种无需训练的框架，通过频率引导的候选选择机制恢复被标准验证丢弃的有效 token，显著提升推理加速比，同时保持输出质量。

Key insight: CSD 的核心思路是在投机解码验证阶段引入频率校准，解决了 draft model 语义正确但词汇不匹配导致的误拒问题。对搜索推荐系统中 LLM 在线推理场景，这种免训练的加速方案可以直接应用于现有投机解码管线，降低部署复杂度的同时提升解码吞吐量。

3. Robust Ultra Low-Bit Post-Training Quantization via Stable Diagonal Curvature Estimate
4.10
Relevance 4 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: 大语言模型部署面临显存和算力瓶颈，训练后量化 (PTQ) 是关键压缩手段。现有基于 Hessian 的 PTQ 方法在低比特场景下因校准数据有限导致曲率估计噪声大而性能退化。本文提出 DASH-Q，通过稳定的对角曲率估计替代跨通道依赖的 Hessian 方法，在超低比特（W2/W3）量化下仍保持较高精度，无需重训练即可大幅压缩模型体积。

Key insight: DASH-Q 的关键创新在于用稳定的对角曲率估计替代传统 Hessian 矩阵方法，解决了低比特量化中小样本校准导致的噪声问题。对搜索推荐系统，W2/W3 级别的量化可以将 LLM 推理显存需求压缩到原来的 1/4 甚至更低，适用于多模型并行部署或资源受限场景。

Key insight: SpecBranch 通过分支并行执行打破了投机解码中 draft-verify 的串行瓶颈，配合回滚感知机制减少无效计算。对搜索推荐的 LLM 在线推理场景，这种架构级优化可与 CSD 等验证层优化互补，进一步压缩首 token 延迟和端到端推理时间。

7. Event Tensor: A Unified Abstraction for Compiling Dynamic Megakernel
3.80

10. Vec-LUT: Vector Table Lookup for Parallel Ultra-Low-Bit LLM Inference on Edge Devices
3.70
Relevance 3 | Novelty 4 | Practical 4 | Evidence 3 | Timely 4

Summary: 随着 LLM 量化从 8-bit 推进到 4-bit、2-bit 甚至 1.58-bit，基于查表 (LUT) 的推理使得 CPU 在超低比特 LLM 上甚至快于 NPU。但本文发现 LUT 推理存在并行度不足的性能瓶颈。Vec-LUT 提出向量化查表方案，通过 SIMD 并行化将超低比特 LLM 在边缘设备上的推理性能大幅提升。

Key insight: Vec-LUT 揭示了 LUT 推理在超低比特场景下的并行瓶颈并给出了向量化解决方案。对搜索推荐系统中边缘推理和端侧部署场景，1-2 bit 量化 + 向量化 LUT 推理的组合提供了极低算力需求下的 LLM 部署路径，适合移动端搜索和嵌入式推荐。
