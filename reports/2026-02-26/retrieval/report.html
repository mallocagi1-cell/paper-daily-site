The Wisdom of Many Queries: Complexity-Diversity Principle for Dense Retriever Training

提出复杂度-多样性原则(CDP)，通过为每篇文档生成多条合成查询来优化稠密检索器训练。

arXiv ↗
4.40
综合分 / 5
KEY INSIGHT · 对业务意味着什么查询复杂度决定最优多样性：内容词<7时避免多样性，>10时启用多样性，可显著提升域外检索性能。业务关联 在 UGC 短文本搜索中，用户 query 多样且长尾。CDP 原则可直接指导训练数据构造策略，根据 query 复杂度动态调整合成查询的多样性，提升长尾 query 的召回效果。证据 在 31 个数据集上测试，多样性策略在域外 (out-of-domain) 和多跳检索任务上显著优于单查询基线；提出的 CDP 加权训练策略即使在单查询数据集上也能提升域外性能。
Xincan Feng, Noriki Nishida, Yusuke Sakai, Yuji Matsumoto · 2026-02-25 · arXiv

Multi-Vector Index Compression in Any Modality

提出四种多向量检索压缩策略，其中注意力引导聚类(AGC)在固定向量预算下保持高检索性能。

INSIGHTAGC 利用注意力机制识别文档中语义最显著的区域作为聚类中心，在 ColBERT 等 late-interaction 模型中可大幅降低存储和计算开销。

业务关联社区搜索中短文本量大，ColBERT 等多向量模型虽然精度高但存储成本高。AGC 压缩策略可在保持检索质量的同时显著降低索引存储和在线计算成本。

证据在 BEIR 文本检索、ViDoRe 视觉文档检索和 MSR-VTT/MultiVENT 2.0 视频检索数据集上，AGC 在固定向量预算下一致优于其他参数化压缩方法，同时保持与无压缩模型接近的检索性能。

Hanxiang Qin, Alexander Martin, Rohan Jha, Chunsheng Zuo, Reno Kriz, Benjamin Van Durme

Repurposing Synthetic Data for Fine-grained Search Agent Supervision

提出 E-GRPO 框架，利用实体匹配率为搜索代理构建密集奖励信号，让"差一点正确"的样本也能产生学习价值。

INSIGHT搜索代理推理过程中识别出的正确实体数量与最终答案准确率强正相关；利用此信号构建密集奖励可显著提升搜索代理的准确率和效率。

业务关联UGC 搜索中常需理解查询意图并匹配多个实体。E-GRPO 的实体感知奖励思路可迁移至社区搜索场景的 LLM 搜索代理训练，尤其在处理含多实体的复杂查询时提升相关性。

证据在多个 QA 和深度研究基准上，E-GRPO 一致且显著优于 GRPO 基线；且 E-GRPO 训练的代理需要更少的工具调用次数即可达到更高准确率，证明了更高效的推理策略。

Multi-Probe Zero Collision Hash (MPZCH): Mitigating Embedding Collisions and Enhancing Model Freshness in Large-Scale Recommenders

Meta 提出基于线性探测的零碰撞哈希索引 MPZCH，在大规模推荐系统中消除 embedding 碰撞并保持模型新鲜度。

INSIGHT传统哈希方法的碰撞会导致不同用户/物品共享同一 embedding，严重损害个性化质量。MPZCH 通过线性探测和主动淘汰策略实现零碰撞，同时防止过时 embedding 的继承问题。

业务关联社区搜索系统的用户和帖子 ID 量级巨大，embedding 碰撞直接影响搜索个性化效果。MPZCH 已集成到 TorchRec 中，可直接应用于提升用户/帖子 embedding 的质量和新鲜度。

证据线上实验证明用户 embedding 实现零碰撞；物品 embedding 新鲜度和质量显著提升；训练 QPS 和推理延迟与现有方法持平。方案已开源发布在 TorchRec 中。

Meta (TorchRec Team)

RL-based Query Rewriting with Distilled LLM for online E-Commerce Systems

结合离线知识蒸馏与在线强化学习，构建轻量级 LLM 查询改写框架，解决大模型在实时搜索场景的成本和延迟问题。

INSIGHT先用大模型蒸馏出小模型，再用 RL 结合相关性、增量和命中率作为多维奖励在线优化改写质量；用 LLM 模拟人工反馈替代人工标注，大幅降低标注成本。

业务关联UGC 搜索中短 query 语义模糊是核心痛点。该框架的蒸馏+RL 路线可直接应用于社区搜索的查询改写模块：用大模型训数据蒸馏轻量模型，线上用 RL 根据点击/相关性反馈持续优化。

证据在 Amazon ESCI 数据集上，蒸馏+RL 框架在相关性指标、输出多样性和系统响应速度上均优于纯 LLM 方案；LLM 模拟人工反馈获得正向评价。

Duy A. Nguyen, Rishi Kesav Mohan, Van Yang, Pritom Saha Akash, Kevin Chen-Chuan Chang

What Makes a Good Query? Measuring the Impact of Human-Confusing Linguistic Features on LLM Performance

从经典语言学出发构建 22 维查询特征向量，揭示查询结构特征与 LLM 幻觉风险之间的可度量关系。

INSIGHT深层从句嵌套和意图不明确的查询与高幻觉率显著相关；明确意图锚定和可回答性则与低幻觉率相关。这为查询质量评估和改写干预提供了量化依据。

业务关联社区搜索中用户 query 口语化且结构多样。该研究的 22 维特征框架可用于构建查询质量评分模型，识别高风险 query 并触发改写或提示干预，提升搜索准确率。

证据基于 369,837 条真实查询分析，发现查询语言学特征与幻觉倾向存在显著统计关系；不同数据集和模型之间存在一致的"风险图谱"，领域特异性效果可变。

William Watson, Nicole Cho, Sumitra Ganesh, Manuela Veloso

Mitigating Preference Leakage via Strict Estimator Separation for Normative Generative Ranking

针对生成式检索(GenIR)中 LLM-as-Judge 评估的偏好泄露问题，提出严格分离监督与评估模型的双裁判框架。

INSIGHT当用同一模型既做排序训练的监督信号又做评估时，会产生虚假的性能膨胀。严格分离 Judge A (评估) 和 Judge B (监督) 后，蒸馏到 BGE-M3 的 bi-encoder 在无泄露评估下大幅优于 Cross-Encoder。

业务关联社区搜索如果使用 LLM 做排序评估或标注，需警惕偏好泄露导致的指标虚高。该双裁判框架可用于构建更可靠的搜索质量评估流程。

证据在 NGR-33k (33,052 条文化相关故事) 基准上，蒸馏后的 BGE-M3 在无泄露 Judge A 评估下显著优于提供监督信号的 Cross-Encoder；在人工标注的 Moral Stories 数据集上与人类规范强对齐。

Dalia Nahhas, Xiaohao Cai, Imran Razzak, Shoaib Jameel

Naver Labs Europe @ WSDM CUP | Multilingual Retrieval

Naver Labs 在 WSDM Cup 2026 多语言检索任务中展示 SPLARE 稀疏检索模型结合 Qwen3-Reranker 重排序的有效组合。

INSIGHT学习型稀疏检索模型 (SPLARE) 在跨语言泛化场景中仍具竞争力，结合分数融合策略和大语言模型重排序可逐步提升检索质量。

业务关联社区搜索中稀疏检索 (如 BM25) 仍是基础召回手段。SPLARE 模型证明学习型稀疏检索可替代传统稀疏方法，且与重排序模型的组合策略可直接迁移。

证据在 WSDM Cup 2026 多语言文档检索任务中，五次逐步增强的实验 (从基础 SPLARE 到融合 Qwen3-Reranker-4B) 展示了稀疏检索 + 重排序的持续提升效果。

Thibault Formal, Maxime Louis, Hervé Déjean, Stéphane Clinchant

Hybrid Deep Searcher: Scalable Parallel and Sequential Search Reasoning

提出混合深度搜索器，结合并行查询扩展与序列化证据聚合，解决推理模型在测试时搜索扩展的瓶颈。

INSIGHT单纯并行多查询搜索缺少证据整合，而纯序列搜索证据覆盖不足。先并行扩展再聚合证据、最后深入序列推理的混合策略可持续提升搜索性能。

业务关联社区搜索中复杂查询常需多步推理 (如"对比A和B的评价")。混合搜索策略的思路可用于构建多跳搜索 pipeline，在保持效率的同时提升复杂查询的满足度。

证据在 FanOutQA 上 F1 提升 +15.9，在 BrowseComp 子集上 F1 提升 +9.2；且搜索迭代越多性能持续提升，而竞争方法到达性能平台期。

RMIT-ADM+S at the MMU-RAG NeurIPS 2025 Competition

提出路由式 RAG 架构 R2RAG，根据查询复杂度和证据充分性动态调整检索策略，在单消费级 GPU 上实现高效运行。

INSIGHT轻量组件的精心设计可媲美大模型方案：通过动态路由根据查询难度选择检索深度，在资源受限条件下实现高效研究级 RAG。

业务关联社区搜索场景中不同 query 复杂度差异大，R2RAG 的动态路由思路可用于根据 query 难度自适应调整召回和排序策略，在保持效果的同时优化计算成本。

证据获得 NeurIPS 2025 MMU-RAG 竞赛开源赛道最佳动态评估奖；在单消费级 GPU 上运行，扩展自 ACM SIGIR 2025 LiveRAG Challenge 冠军系统 G-RAG。
