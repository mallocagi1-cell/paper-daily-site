1. mimalloc: A new, high-performance, scalable memory allocator for the modern era
4.35
Relevance 4 | Novelty 4 | Practical 5 | Evidence 4 | Timely 5

Summary: Microsoft Research 发布的 mimalloc 是面向现代多核架构的开源高性能内存分配器，作为 malloc/free 的零侵入替代。整套实现仅约 12K 行代码，几乎完全基于无锁原子操作，提供有界的最坏分配延迟、有界空间开销、低内部碎片以及极低的多线程竞争。该分配器已被广泛集成进生产系统，与 jemalloc、tcmalloc 等对比时在吞吐和尾延迟上均有显著优势，是搜索/推荐在线服务、向量检索引擎等高并发系统的关键基础组件。

Key insight: 对搜索/推荐 serving 的启示：检索召回、ANN、特征服务等服务在百万 QPS 下，malloc 抖动是 P99 延迟的隐性杀手；切换到 mimalloc 是几乎零成本的尾延迟优化。其设计思想——线程本地堆 + 分桶 freelist + 跨线程归还队列——也可借鉴到自研对象池/embedding-cache 中。同时 12K 行可读实现是研究并改造内存分配器的良好基线，便于按业务定制 NUMA-aware 或大对象优化。

2. Useful Memories Become Faulty When Continuously Updated by LLMs
4.05
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 论文系统研究了 agentic 系统常用的 "持续整合记忆" (consolidated memory) 范式：让 LLM 将历史交互改写成文本知识条目并持续更新。作者发现 GPT-5.4 在 ARC-AGI 上，对那些原本无记忆也能解决的题目，开启 consolidated memory 后失败率高达 54%；记忆质量随更新呈先升后降的非单调曲线，最终甚至跌破无记忆基线。问题根源被归因到 consolidation 这一步而非底层经验——同一条轨迹被反复改写后会发生语义漂移和事实污染。

Key insight: 对工业 agent/RAG 系统的警示：把 LLM 写好的 "经验总结" 当作可信知识库长期累积是一个工程陷阱。落地建议是保留 episodic 原始 trace 作为权威源、对 consolidated 摘要做版本化与可回滚、限制 LLM 自更新的递归深度，并定期用基准任务回归测试记忆库价值。对搜索场景的 query log → 知识沉淀流水线尤其重要：不能用 LLM 持续改写问答库本身，需要 human-in-the-loop 或确定性合并策略。

3. Sampling More, Getting Less: Calibration is the Diversity Bottleneck in LLMs
4.00
Relevance 4 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: 论文提出 validity–diversity 框架，将 LLM 推理时输出多样性塌缩归因到 token 级概率分布的两类校准失配：(1) order calibration —— 有效 token 未稳定排在无效 token 之前，导致基于 rank 的 cutoff（如 top-k、top-p）必须在召回有效续写与混入无效续写之间艰难权衡；(2) shape calibration —— 概率质量过度集中在少数有效续写上，温度上调虽提升多样性却同时引入大量无效续写。作者用该框架解释了为何提温/扩 top-p 在工业部署中常 "增多样性即降质量"。

Key insight: 对 LLM 检索改写、query 扩写、生成式推荐 SID decoder 等场景的核心启示：单纯调温度/调 top-p 已经触顶，真正的瓶颈是模型概率分布的校准而非采样策略。落地方向是引入 logit calibration 后处理或在训练阶段加入 calibration loss，让有效 token 的排序与概率形状同时改善。对依赖多样化输出（多 query 改写、多候选生成、探索-利用平衡）的系统尤其重要——这是一项可复用、可叠加到现有 serving stack 的零结构改动优化。

4. Decomposing Evolutionary Mixture-of-LoRA Architectures: The Routing Lever, the Lifecycle Penalty, and a Substrate-Conditional Boundary
3.55
Relevance 3 | Novelty 4 | Practical 3 | Evidence 4 | Timely 5

Summary: 作者在约 150M 参数的 widened-1536 substrate（D=1536，V=32000）上，对 evolutionary mixture-of-LoRA 系统进行 2^3 部分因子拆解：路由器改写（带可学下限与温度退火的并行 sigmoid gate、输入改为 post-stack hidden state 而非 token-embedding 均值）、leave-one-out 每域评估、死亡+α-混合继承+SVD 变异的生命周期机制。在 25k 步×3 seed 的 5/8 因子格点实验中，结论锐利：router rewrite 单因子承担了 +0.0426 nat 平衡 log-PPL 改进的全部贡献（t=12.86, p=0.006），lifecycle 反而是惩罚项。

Key insight: 对推荐/搜索领域采用 MoE/LoRA 做多任务多领域适配的工程团队是一记冷水：evolutionary 那一套 "种群—变异—淘汰" 看似性感，但真正的收益来源是路由器结构本身。可借鉴的实践：(1) 路由器输入改为 deep 层 hidden state 比浅层均值显著更好；(2) per-adapter 可学下限避免少数 expert 饿死；(3) 在引入复杂生命周期机制前应该用因子实验隔离路由器与 lifecycle 的独立贡献，避免错误归因。同时该论文展示了 LoRA-MoE 训练的因子化评估方法论，对内部 ablation 设计有方法论价值。

5. On the LSH Distortion of Ulam and Cayley Similarities
3.20
Relevance 3 | Novelty 4 | Practical 2 | Evidence 3 | Timely 5

Summary: 本文研究两种排列相似度（Ulam 与 Cayley）的 LSH distortion 上下界——即一个相似度函数 S 与某存在精确 LSH 方案的相似度之间的最小乘性差距。作者证明 Ulam 相似度存在 O(n/√log n) 的次线性 distortion 上界，并给出 Ω(n^0.12) 下界；对 Cayley 相似度同样给出新的分析。LSH 是近似最近邻搜索的核心原语，distortion 越小意味着越容易构造高召回 ANN 索引。

Key insight: 对向量检索/ANN 基础设施团队的意义：Ulam/Cayley 这类排列相似度直接对应序列重排距离、点击序列相似度、用户行为序列相似度等场景，传统上很难直接 LSH。论文给出的近似 LSH 构造为这些 "非欧空间" 相似度提供了可工程实现的近似检索方案。对搜索系统中的 "用户行为序列召回"、"重排打分相似性聚类" 等业务场景可作理论基底；但当前结果偏纯理论，落地仍需具体构造与常数项优化。

6. GridSFM: A new, small foundation model for the electric grid
3.05
Relevance 2 | Novelty 3 | Practical 4 | Evidence 3 | Timely 5

Summary: GridSFM 是 Microsoft Research 面向电力网络的 "小基础模型"（small foundation model），能够在毫秒级预测 AC 最优潮流（AC optimal power flow），相比传统数值优化提速若干个数量级。模型规模相对紧凑、推理成本低，可在边缘部署，为电网运营方提供阻塞、稳定性、系统健康度的实时可视化，目标是兼顾准确性与可商用部署成本。

Key insight: 对搜索/推荐基建团队的横向启示：行业正在收敛到 "领域专用小基础模型" 这一范式——参数量从大模型的百亿级回落到十亿/百亿以下，换取毫秒级推理和低部署成本。同样的思路可以平移到搜索：query 改写小 FM、相关性打分小 FM、用户兴趣 small FM。GridSFM 的工程要点（小 FM + 强领域先验 + 毫秒推理 + 边缘部署）是当下 LLM-as-a-service 之外的另一条可落地路径。
