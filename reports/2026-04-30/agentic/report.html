Why Does Reinforcement Learning Generalize? A Feature-Level Mechanistic Study of Post-Training in Large Language Models

论文针对 RL 后训练能让 LLM 推理能力跨域泛化、SFT 却倾向遗忘通用能力这一对照现象，提出特征级机理分析框架。研究在统一基模型与同份数据上分别做 RL 与 SFT，使用可解释性方法把两者激活对齐到共享特征空间，逐层追踪特征演化。结果发现 SFT 会快速引入大量高度专门化、训练早期就稳定的特征，而 RL 引发的特征变化更克制、持续演化，且大体保留基模型的表征结构，从而解释了 RL 泛化优势的微观来源。

KEY INSIGHT · 对业务意味着什么对搜索/推荐 agent 的训练实践有直接启示：单纯 SFT 容易把模型固化到训练分布上的快捷特征，无法应对线上多样的 query 与 RAG 场景；而 RL（包括 RLHF/RLEF/Search-R1 这类 reasoning-search 联合训练）通过保留底座表征、缓慢演化特征，更适合做 agent 的能力扩展。论文的特征对齐方法也可被借鉴用于诊断自家 agent 在领域迁移时的能力衰减点，为 RL/SFT 配比与冻结策略提供量化依据。

Deep Research Max: a step change for autonomous research agents

Google

Google 在 4 月 21 日发布基于 Gemini 3.1 Pro 的 Deep Research 与 Deep Research Max 两档自主研究 agent。Deep Research Max 通过显著加大检索迭代轮数与跨源比对深度生成更长且引用更完整的报告，并新增 MCP 协议支持以接入企业私有数据，原生生成可视化图表。性能上 DeepSearchQA 由 2025 年 12 月的 66.1% 跃升至 93.3%，Humanity's Last Exam 由 46.4% 提升至 54.6%。当前以 paid tier 形式经 Gemini API 公测开放，FactSet、S&P Global、PitchBook 等已搭建配套 MCP server。

INSIGHT这次产品化用真实指标确认了 agentic deep research 的两个工程信号：一是搜索迭代深度本身可以作为产品的可调参数（fast vs Max 双档），把 test-time scaling 直接映射成定价策略；二是 MCP 是接入企业知识库的事实标准，决定了 agent 能否落到行业搜索/检索增强场景。对自建社区搜索 agent 的启示：把多轮检索与跨源验证作为可计费产品维度，并优先用 MCP 暴露内部库以减少胶水代码与重复评测。

Google (Gemini Team)

Dual-Track CoT: Budget-Aware Stepwise Guidance for Small LMs

面向 7–8B 量级小模型推理瓶颈，论文提出 Dual-Track CoT：在 CoT 解码过程中引入预算感知的逐步指导，结合过程监督与简单的测试时控制（token 预算上限、冗余步骤拒绝）。两条 track 分别承担探索与收敛，在不依赖大规模采样投票或 ToT 搜索的前提下实现细粒度的 step-level 控制。论文论证小语言模型在相同甚至更少 token 预算下能稳定输出多步推理，特别适合端侧、低延迟、成本敏感的部署场景。

INSIGHT对线上社区搜索的 query 改写、多跳召回 agent 是直接可用的手段：用 7–8B 小模型替代频繁调用的大模型，通过预算与过程约束控制响应延迟与 token 成本。其 step-level 拒绝冗余步骤的设计可借鉴到 RAG 多轮检索 agent 中，避免无意义的重复 search action。相比 self-consistency/ToT，预算感知 CoT 更贴近工业落地的成本曲线。

Sagnik Chatterjee, Atharva Patil, Sricharan Ramesh

BenchGuard: Who Guards the Benchmarks? Automated Auditing of LLM Agent Benchmarks

UUWashington

论文指出 agent 评测中很多“失败”其实源于基准本身的破损：模糊规范、隐式假设、僵化评测脚本会把合法的替代解判为错误。BenchGuard 是首个面向任务驱动、基于执行的 agent 基准的自动审计框架，通过结构化 LLM 协议交叉核对所有基准 artifact，并可注入 agent 解或执行 trace 作为额外诊断证据。在 ScienceAgentBench 上识别出 12 个被作者确认的问题（含使任务无解的致命错误），在 BIXBench Verified-50 上 83.3% 命中专家发现的缺陷。

INSIGHT对自建 agent 评测体系是高优先级工具：在自家 search agent / RAG agent 评测集上跑一遍 BenchGuard 可以避免“agent 实际改进了，但被评测脚本误判”这种长期暗坑。其用 frontier LLM 做交叉核验的协议同样可移植到内部线上回归评测，把评测本身视为可被审计的代码资产。

Xinming Tu, Tianze Wang, Yingzhou Lu, Kexin Huang, Yuanhao Qu, Sara Mostafavi

A Survey on LLM-based Conversational User Simulation

AdobeVVanderbilt

针对 LLM 驱动的会话型用户模拟，论文系统综述了近两年研究：提出按用户粒度（个人画像、群体、动态行为）和模拟目标（评测、训练数据生成、对齐）划分的新分类法，梳理了核心技术（角色提示、记忆建模、对话策略、多轮一致性）与评测方法（自动指标、人工评估、下游任务表现）。文章指出当前 LLM 用户模拟在保真度、评测可比性与开放挑战集上仍有大量空白，并提供了开源资源与未来研究方向。

INSIGHT对搜索/推荐 agent 的训练数据闭环是关键参考：高质量 LLM 用户模拟是 agentic RL（Search-R1、CoSearch 等）训练数据的源头，本身决定了 agent 能学到怎样的 query 分布与点击行为。综述给出的“用户粒度 × 模拟目标”二维分类法可直接用来盘点自家社区搜索的离线模拟设计是否覆盖了长尾用户与边界场景；也提示评测体系要从单轮指标转向多轮一致性与策略对齐评估。

Large Language Models Explore by Latent Distilling

ShanghaiTech

论文提出 Exploratory Sampling (ESamp)，在 LLM 解码阶段显式增加语义多样性。核心思路是利用神经网络对相似输入预测误差较低的特性：在测试时训练一个轻量 Distiller，从浅层隐表征预测深层隐表征，建模 LLM 的逐层表征演化；解码时 Distiller 不断适应当前生成上下文，将其预测误差作为新颖性信号，对候选 token 做 logit 重加权。相比标准随机采样仅产生表层词面差异，ESamp 能在更深层语义维度上提升 test-time scaling 的多样性。

INSIGHT对 agentic search 的多 rollout 训练与多分支推理具有方法论价值：现有 Search-R1、Tree-GRPO 等方法依赖大量 rollout 提升信息覆盖率，但温度采样下 rollout 间相似度高、收益递减；ESamp 用隐层 Distiller 的预测误差作为 novelty 奖励项，可以直接嵌入到 search agent 的 trajectory 采样、planner 候选枚举里，把固定计算预算下的有效探索率拉高，是非常通用的解码侧补丁。

Yuanhao Zeng, Ao Lu, Lufei Li, Zheng Zhang, Yexin Li, Kan Ren

PaperMind: Benchmarking Agentic Reasoning and Critique over Scientific Papers in Multimodal LLMs

UIUC

PaperMind 提出面向多模态 LLM 的 agent 化科学论文理解评测，覆盖农业、生物、化学、计算机、医学、物理、经济 7 个领域真实论文。基准定义了 4 类互补任务，用以分别测量文本-图表 grounding、实验证据解释、跨段落信息综合与科学主张批判性评估这 4 种认知能力，并强调评估“整合性的”推理而非孤立 QA。论文同时给出多模态前沿模型的对比结果与失败模式分析，作为评估 agentic 科学阅读能力的统一基准。

INSIGHT对“deep research / 文献调研”类 agent 的能力盘点是直接可用的诊断工具：当下 deep-research-max 这类产品越来越强调跨源综合与批判性核验，但缺乏覆盖多领域、多模态的统一基准；PaperMind 的 4 个任务族正好把整合推理拆成可单独定位的能力维度，便于在自家 RAG/agent 上做 ablation，找出是 grounding 弱、还是综合弱、还是批判弱。对社区平台“知识帖”类深度搜索也有迁移价值。

Faithful Autoformalization via Roundtrip Verification and Repair

Stanford

论文针对 LLM 把自然语言形式化为逻辑表达式时缺乏忠实度验证的问题，提出无需 ground truth 的回环验证：先形式化，再把结果回译成自然语言并再次形式化，用形式化工具核验两次表达式的逻辑等价性；不一致时由诊断步骤定位失败阶段并触发针对性的修复算子。在 150 条交通规则上用 Claude Opus 4.6 与 GPT-5.2 评测，等价率从基线 45–61% 提升到 83–85%，明显优于随机修复，独立 NLI 分析验证形式等价与语义漂移之间存在相关性。

INSIGHT把“roundtrip + 诊断式修复”作为 agent 工具调用阶段的通用安全网很值得借鉴：搜索 agent 在做 query 改写、SQL/DSL 生成、API 调用 schema 填充时也存在类似的“形式化是否忠实”问题，可以套用同样的回环检查。其阶段定位（identify which stage failed）的设计也启发把 agent 多步 trace 拆成可被独立修复的子操作，避免整轮重做带来的成本爆炸。

Daneshvar Amrollahi, Jerry Lopez, Clark Barrett

GAIA-v2-LILT: Multilingual Adaptation of Agent Benchmark beyond Translation

Lilt

论文指出现有 agent 基准多以英文为主，简单机器翻译的多语版本会因 query-answer 错位与文化偏离破坏基准有效性。作者提出含功能对齐、文化对齐、难度校准的精细化适配工作流，结合自动检查与人工审校，在此基础上构建 GAIA-v2-LILT，覆盖 5 种非英语语言。实验显示精细适配让 agent 成功率较直接机翻版提升最高 32.7%，最佳设置距英文性能仅差 3.1%，但不同语种之间仍有较大差距，揭示了表面性能差异中相当部分来自基准伪噪声而非模型能力差距。

INSIGHT对中文社区平台的 agent 评测有强参考意义：直接把英文 GAIA/BrowseComp 类基准机翻进中文做评测，结论容易被翻译噪声主导；论文的功能对齐 + 文化对齐 + 难度校准三步骤可作为内部多语 / 中文搜索 agent 评测集建设的最小工序。32.7% 这一巨大 gap 也提醒在做跨语种横评时，先验证基准本身再下结论。

Yunsu Kim, Kaden Uhlig, Joern Wuebker

AURA: Affordance-Understanding and Risk-aware Alignment Technique for Large Language Models

IIIT-Kharagpur

AAAI 2026 录用论文 AURA 提出面向 LLM 的“可供性理解与风险感知对齐”技术：在对齐阶段显式建模动作可供性（affordance）—— 即模型在给定上下文中可行的动作空间—— 并将风险评估融入对齐目标，区分“能做”与“应做”。该工作旨在让 LLM 在工具调用、生成内容时能基于环境约束自动收敛到风险更低的动作集合，从而比纯偏好对齐更稳健地避免越界与不可逆操作。

INSIGHT对生产环境的 search/rec agent 是值得跟进的安全方向：当前 RLHF/DPO 对齐主要解决“偏好”，但 agent 一旦能调用真实工具（搜索、写库、外部 API）时，更需要的是“affordance × risk”联合建模 —— 让模型在搜索 agent 中自动避开成本高、副作用大的动作。AURA 的对齐目标可以借鉴到自家 agent 的工具调用 policy 中，作为补充安全层。

Sayantan Adak, Pratyush Chatterjee, Somnath Banerjee, Rima Hazra, Somak Aditya
