1. VectorSmuggle: Steganographic Exfiltration in Embedding Stores and a Cryptographic Provenance Defense
3.80
Relevance 3 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 论文提出 VectorSmuggle 攻击框架，证明 RAG 系统使用的向量数据库存在隐写式数据外泄风险：攻击者只需对 embedding 做噪声注入、旋转、缩放、偏移、分片等扰动，即可在保留正常检索行为的同时将敏感载荷隐藏于向量中。作者在 text-embedding-3-large 及 4 个开源 embedding 模型上、并在 BEIR NFCorpus 等基准上验证攻击可行性，同时提出基于密码学溯源签名的防御方案，使向量存储具备完整性与摄入侧异常检测能力。

Key insight: 对搜索/推荐系统的启示：向量数据库不能再被视为黑箱数值仓库，企业自建 RAG/语义召回链路必须在摄入端加上 embedding 分布异常检测和加密溯源；论文给出的扰动模式（旋转、分片、组合）可直接复用为 red-team 测试用例。对 UGC 搜索而言，社区数据集中包含大量 PII 与用户隐私，落地向量召回前必须把这一类摄入侧攻击纳入威胁建模。

5. Same Image, Different Meanings: Toward Retrieval of Context-Dependent Meanings
3.45
Relevance 3 | Novelty 4 | Practical 3 | Evidence 3 | Timely 5

Summary: 论文研究图片含义的上下文依赖性问题：同一张照片在不同叙事中表达完全不同的含义。作者提出 L1-L4 框架，把图片语义从'与上下文无关'(L1) 到'高度上下文相关'(L4) 分级；并用合成故事上下文和 query 在控制实验中检验在 embedding 中注入叙事上下文对各抽象层级检索的影响。结果显示具体 query 不依赖上下文即可召回，但抽象层级越高越依赖叙事 grounding，且上下文在图像端注入往往优于 query 端。

Key insight: 对搜索/推荐系统的启示：UGC 搜索里大量 query 都是高度依赖语境的抽象描述（'治愈系的雨天'），论文的 L1-L4 分级提示我们：embedding 模型应根据 query 抽象度动态决定是否引入上下文 token；上下文注入在 doc 端比 query 端往往更稳。可作为社区图片/视频检索的 prompt 工程指南，用极小成本拿到抽象 query 的召回提升。
