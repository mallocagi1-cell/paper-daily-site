Let the Agent Steer: Closed-Loop Ranking Optimization via Influence Exchange

针对推荐排序中离线指标与线上效果系统性偏差的问题，提出 Sortify——首个全自主 LLM 驱动的排序优化 Agent。核心思路是将排序优化重新定义为「影响力交换」问题，通过基于 Savage 主观期望效用理论的双通道框架（Belief 通道校正离线-线上迁移偏差 + Penalty 通道调整约束惩罚），以及 7 张关系表构成的记忆数据库实现跨轮学习。线上部署结果：A 国 GMV 从 -3.6% 提升至 +9.2%（7 轮优化），B 国冷启动 7 天 A/B 测试达 +4.15% GMV/UU 和 +3.58% 广告收入。

1. 问题与动机

推荐排序本质上是一个影响力分配问题：排序公式在多个竞争因子间分配排序影响力，业务结果取决于找到因子间的最优「汇率」。然而，现有的排序优化面临三个结构性难题：(1) 离线代理指标系统性地误判影响力重新分配对线上效果的传导，且不同指标间存在非对称偏差，单一校准因子无法纠正；(2) 诊断信号在多目标下互相纠缠，操作者难以区分「我预测会发生但没发生」（认知错误）和「发生了但危害超出预期」（价值错误）；(3) 人工调参是无状态的——每轮优化从零开始，无法积累跨轮经验。此前的 ParaDance 系统经过 20 个月迭代仍无法解决这些问题，促使团队探索全自主 LLM 驱动的解决方案。

2. 方法详解

双通道框架：基于 Savage 主观期望效用理论，Sortify 将排序优化解耦为两个正交控制轴：

  • Belief 通道（离线-线上迁移校正）：维护线性迁移模型 ũ_online = α·u_offline + β，通过 LMS 回归（学习率 η=0.2）持续更新斜率和截距。LLM 作为元控制器在 20 轮回溯窗口内识别系统性模式，进行选择性截距跳跃（±0.1），处理认知层面的偏差。
  • Preference 通道（约束惩罚适应）：计算违约压力 p_j = v_j(θ)/v_j^threshold，使用非对称乘法更新（δ_up=0.25, δ_down=0.08，收紧速度约为放松速度的 3 倍），惩罚权重范围 [1000, 80000]。

影响力份额指标：基于对称群论和排列结构推导，将排序分解为原子成对交换，每个因子的贡献以可分解的百分比呈现（总和为 100%）。通过位置敏感权重 w_qij = exp(-min(r_qi,r_qj)/τ) 进行聚合。相比 Kendall τ 只能产生单一标量，影响力份额支持因子级归因和定量交换推理。

LLM 元控制器：输入 20 轮历史、30 条更新记录和当前状态，输出两个正交旋钮（截距调整 ∈ [-0.1, +0.1]，惩罚乘数 ∈ [0.5, 2.0]）。使用 7 层安全管线（prompt 约束 → JSON 提取 → Schema 验证 → 白名单校验 → 硬限幅 → 全局边界 → 失败回退）确保鲁棒性。基于 OpenAI Codex 扩展推理模式，300 秒超时，零样本 prompt。

记忆数据库：7 张关系表（episodes、offline_candidates、prior_relations、prior_observations、prior_update_history、penalty_wt_upd_hist、memory_events），复合键防重复写入，仅追加不可变设计支持审计追溯。

搜索引擎：使用 Optuna TPE 采样器执行参数搜索，每轮 5000 次试验、25 个并行 worker（Constant Liar 策略），7 维参数向量，二次惩罚形式（1% 违约惩罚比 10% 小 100 倍）。

3. 核心技术贡献

(1) 影响力交换范式：首次将排序优化形式化为影响力分配问题，通过可分解的影响力份额指标使排序因子贡献透明化。相比传统的 Kendall τ 相关性度量，该指标支持因子级归因，使 LLM 能在语义层面理解排序策略。

(2) 双通道正交解耦：将 Savage 决策理论操作化为两个独立控制轴，认知校正（Belief）和价值适应（Preference）互不干扰。当 Belief 通道发生大幅更新时，Preference 通道自动冻结一轮，隔离影响。这种设计解决了传统方法中多目标诊断信号纠缠的问题。

(3) LLM 框架层控制：LLM 不直接操作底层排序参数，而是在框架层面调整迁移模型截距和惩罚乘数。这种「元控制器」定位利用了 LLM 的模式识别能力，同时通过 7 层安全管线约束其输出范围，实现了自主性与安全性的平衡。

(4) 跨市场冷启动：记忆数据库架构支持无需修改即可跨市场部署，B 国冷启动在第一轮就正确识别了特定市场的信号欠权重问题（ps_org_wc 调整 +271%）。

5. 局限与未来方向

作者明确指出的局限包括：(1) 残余参数振荡：即使经过 7 轮（热启动）和 23 轮（冷启动），系统在波动性参数（特别是 ps_ads_wo，振荡比 4.5 倍）上仍展现特征性摆锤效应；(2) 统计不确定性：低流量窗口（如 R7 仅 ~12K 展示）引入更高方差；(3) 持久多目标张力：A 国实验中广告主价值在 R3-R7 持续为负，表明 GMV/订单与广告主 ROI 之间存在根本性约束冲突；(4) 极端结构性变化的恢复滞后：LMS 从重大分布偏移中恢复需要约 15 轮才能达到 95%。

6. 工业实践意义

可直接借鉴的设计：(1) 影响力份额指标为任何多因子排序系统提供了可分解的归因工具，实现成本低（基于成对比较，无需修改模型）；(2) 双通道架构的正交解耦思想可应用于任何需要同时处理校准和约束的在线优化场景。

部署考量：系统资源需求极低——单机搜索引擎、共享 Redis、无 GPU 需求，唯一外部依赖是 LLM API 调用。每轮周期约 4 小时（3.5 小时数据窗口 + 25-50 分钟处理），每天可执行约 6 轮优化。

风险提示：(1) 系统经过 20 个月从 ParaDance 迭代而来，工程复杂度不低；(2) 7 层安全管线虽然必要但增加了维护成本；(3) 在流量较低的场景下，统计显著性不足可能导致错误决策。建议在充足流量的场景下首先验证。

PANTHER: Generative Pretraining Beyond Language for Sequential User Behavior Modeling

Tencent📖 有深读 · 7 分钟

将 LLM 的生成式预训练范式拓展到用户行为建模领域，提出 PANTHER 混合生成-判别框架。核心方法是对用户行为序列中的多维属性（时间、上下文、交易类型）进行结构化 token 化，结合序列模式识别模块捕捉周期性交易模式，并构建统一的用户画像 embedding（融合人口统计信息与交易历史）。在微信支付场景部署：下一笔交易预测 HitRate@1 提升 25.6%，欺诈检测 Recall 提升 38.6%；公开基准上 HitRate@1 最高提升 21%。通过离线 embedding 缓存实现实时推理。

INSIGHTPANTHER 证明了生成式预训练可以有效地从用户行为序列中提炼出可迁移的行为知识表征，类似于 LLM 从文本中学习世界知识。对推荐系统从业者的核心启示是：用户行为可以作为独立模态进行大规模预训练，生成的 user embedding 能跨场景迁移（如从交易预测到欺诈检测）。这种预训练-微调范式特别适合数据稀疏或标注有限的推荐场景，通过无监督行为预训练获得泛化的用户表征。

1. 问题与动机

大语言模型通过生成式预训练将海量世界知识蒸馏为紧凑的 token 表征，但 LLM 的知识局限于文本模态，无法建模用户交互历史中蕴含的行为知识。用户行为构成一种独立模态——每个动作由多维属性（时间、上下文、交易类型）定义为一个行为 token，建模这种高基数序列面临两大挑战：(1) 判别式模型在有限监督下表现不佳；(2) 现有方法缺乏跨场景迁移能力。例如，在微信支付场景中，传统 Transformer baseline 在下一笔交易预测上的 HitRate@1 仅为 0.1952，难以满足实时风控和个性化推荐需求。PANTHER 的动机是将 LLM 的「预训练-微调」范式扩展到用户行为模态，通过无监督行为预训练获得可迁移的用户表征。

2. 方法详解

结构化 Token 化：将原始交易转换为可解释 token，通过笛卡尔积 τ = (channel, amount_range, merchant_category, risk_level) 构建。原始词表约 200 万种组合，通过基于频率的过滤压缩到 60K token，覆盖 96% 的历史交易，同时减少 97% 的稀疏性。

序列模式识别模块（SPRM）：包含两个组件：

  • 局部模式聚合：使用深度可分离膨胀卷积（核大小 w=3，膨胀率 r=1,2）捕捉多尺度时间簇。小膨胀率捕捉即时模式，大膨胀率捕捉周期性规律。计算复杂度 O(T)，相比 vanilla attention 的 O(T²) 具有显著优势。
  • 原型驱动匹配：m=64 个可学习原型代表典型消费模式（如周末休闲、工作日通勤）。通过交叉注意力 X_p = Softmax(QK^T/√d_k)V 将序列片段压缩到最近原型上，强制稀疏可解释编码。

用户画像编码：将人口统计信息（年龄、地区等）与交易历史融合为统一 embedding，作为序列的首 token 输入（positional encoding 方式优于 first-token 方式）。

训练目标：采用双目标联合训练：

  • 生成式损失 L_gen = E_u~U[∑-log Pr_θ(x_t | x_<t, x_profile)]（自回归下一行为预测）
  • 对比学习损失 L_CL：共享人口属性（年龄±2、相同地区）的用户对构成正样本对，温度参数 τ 控制浓度
  • 组合目标 L = (1-λ)L_gen + λL_CL，λ=0.1 为最优（Table 9 超参调优结果）

训练配置：微信支付数据集包含 53 亿笔交易、3800 万用户、6 个月数据。Batch size 128，学习率 1×10⁻³，多 GPU 集群训练。模型配置：4 层、2 头注意力（MovieLens 用 2 层 1 头），64 个原型，推理使用最近 100 笔交易。

实时推理：通过离线 embedding 缓存实现，运行时仅需对最近 100 笔交易用 TextCNN 编码并与缓存 embedding 融合，额外延迟仅 5ms，总决策延迟保持在 100ms 以内。

3. 核心技术贡献

(1) 行为模态的生成式预训练：首次系统性地将 LLM 的预训练范式扩展到用户行为序列。通过结构化 token 化将连续多维行为属性离散化为可预测的 token，使自回归预训练目标能有效应用于行为建模。相比此前的判别式方法（如 SASRec），PANTHER 在 MovieLens-1M 上 HR@1 提升 21.8%。

(2) SPRM 的线性复杂度设计：用膨胀卷积 + 原型匹配替代标准自注意力，实现 O(T) 复杂度。在序列长度 4096 时 Transformer OOM 而 SPRM 仅需 5.7GB 内存，8192 长度时仍可运行（10.8GB）。这对长行为序列建模至关重要。

(3) 跨场景迁移能力：预训练 embedding 可直接迁移到下游任务。在微信支付预训练后迁移到 MBD-mini/CCT 数据集，HR@1 平均提升 16.66%。冷启动用户通过用户级迁移，HR@1 从 0.0581 提升到 0.2332（+301%）。

(4) 生成-判别混合框架：统一的两阶段设计——离线生成式预训练 + 在线判别式微调（通过 DeepFM 融合），在保持实时性的同时利用预训练知识。

5. 局限与未来方向

作者明确指出的主要局限是可解释性不足：复杂表征可能阻碍在高风险金融应用中的透明度要求。在受监管的金融领域，这一局限影响了更广泛的适用性。作者建议可解释性改进作为未来工作方向。

额外观察到的局限：(1) 60K token 词表的频率过滤可能丢失低频但高信息量的交易模式（如异常大额交易）；(2) 固定 100 笔交易的推理窗口可能不适用于低频用户；(3) 对比学习的正样本对定义（年龄±2、相同地区）可能引入人口统计偏差。

6. 工业实践意义

可直接采纳的技术：(1) 结构化 token 化方案——将多维行为属性通过笛卡尔积 + 频率过滤转化为可管理的词表大小，适用于任何具有多维属性的用户行为序列（搜索查询、浏览、点击等）；(2) 离线预训练 + embedding 缓存的两阶段部署模式，额外延迟仅 5ms，适合在线推荐系统的严格延迟要求。

值得尝试的方向：将生成式预训练应用于搜索场景的用户行为建模——将用户的搜索-点击-浏览序列进行结构化 token 化，预训练得到的 user embedding 可用于个性化排序、冷启动推荐和 query 意图理解。

需要注意的风险：(1) 预训练数据规模要求较高（论文使用 53 亿条交易），小规模数据下效果存疑；(2) 60K 词表的压缩率适用于支付场景，搜索/推荐场景的行为属性维度可能更高，需要重新设计 token 化方案。

部署参考：单 GPU 即可完成公开数据集训练，但生产级（53 亿条）需要多 GPU 集群。推理通过 embedding 缓存实现毫秒级延迟，不需要实时运行完整模型。
