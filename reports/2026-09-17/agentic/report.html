Spurious Tool Use: When RL Agents Learn the Wrong Reason to Act

研究构造事实问答与数学推理环境，在训练数据中加入与搜索或计算工具相关、但与真实需求无关的表面线索。反事实测试显示，强化学习后的伪工具调用率最多增加 39%；作者进一步引入逐次判断调用必要性的密集奖励，在保持任务表现的同时抑制依赖线索的错误调用。

Predicting Partial Answer Quality and Utility in Agentic Retrieval-Augmented Generation

University of Glasgow

论文在每轮检索与推理后强制生成临时答案，分别测量当前答案质量和相邻轮次的质量增量，并利用轨迹特征预测继续检索的价值。多跳问答实验中，质量预测的 Pearson 相关系数超过 0.43；基于预测早停后，平均迭代次数减少约 11%，保留自然终止时约 98% 的最终答案质量。

INSIGHT对社区帖子与问答的多跳搜索，可记录每轮证据、临时答案和新增事实，用少量标注训练停止策略。实践时应同时衡量答案正确率、引用完整性和尾延迟，先在高成本查询上做离线回放；论文的 98% 是相对答案质量保留比例，不能理解为绝对准确率，也不能直接换算为 CTR 收益。

Fangzheng Tian, Debasis Ganguly, Craig Macdonald

03 4.15

Diagnosing the Fact-Grounding Gap in Multi-Hop Question Answering

Northwestern University

论文将多跳问答中的逐跳缺陷拆成未召回支持段落与已召回段落仍缺少所需事实两类，并在三个基准中检查这一差别。MuSiQue 的 6,401 个推理跳中，检索失败占 30.7%，事实抽取缺口占 27.3%，后者约占全部缺陷的 47%；更换检索器并不能消除该缺口。

INSIGHT社区短文本常省略实体关系和背景，文档相关并不保证足以支持答案。可在每个子问题上单独标注证据是否包含必要事实，再决定继续搜索、寻找其他来源或保留不确定结论；这里的抽取失败包含段落本身不提供事实的情况，不应简单归咎于阅读模型，更不能只靠提高召回率解决。

Kevin Mo, Nathan Mo, Richard Zhu

04 4.10

How KDDI built Buffmee, a faster, reliable consumer RAG app

KDDIGoogle

KDDI 的 Buffmee 面向百余内容来源提供检索问答，通过自动评测、生产日志分析和按需加载 ADK Skills 定位延迟与提示词问题。工程案例报告总体响应延迟降低 38%、首 token 时间改善近 18%、事实依托评分提高 25%；按格式与媒体构成抽样，使评测工作量减少 75%。

INSIGHT社区搜索可先按帖子长度、图文形式和问题复杂度建立评测矩阵，用产品人员校准二元通过标准，再依据调用轨迹压缩提示词和调整路由。此案例说明质量评测与延迟分析应一起做；其收益来自多项联合优化，文章未隔离每项改动的贡献，应在自身流量上分别验证，不能承诺相同幅度。

Junichi Kashino, Miki Katsuragi

Retrieval-Driven Memory Reconsolidation for Long-Term LLM Agents

Shanghai Jiao Tong UniversityNUSOPPO

REALM 将长期记忆组织为异构认知图，自适应组合图搜索操作，并把检索反馈用于记忆再巩固，使读取过程也能改变后续证据组织方式。它在 LoCoMo 和 LongMemEval 上分别达到 75.97% 与 65.11% 平均准确率，比最强基线高 7.17 和 1.31 个百分点，消融验证了再巩固环节的贡献。

INSIGHT对于持续追问的社区搜索助手，可借鉴检索后重组相关记忆的机制，把分散帖子、用户补充条件与证据关联起来。应保留原始出处和版本，以免模型生成的关联覆盖用户事实；先在历史会话回放中评估跨轮召回、答案正确率和维护成本，再决定是否引入比向量索引更复杂的记忆图。

AURA: Agentic Diagnosis and Refinement for Production Recommender Systems at Scale

AURA 用专门智能体读取生产会话日志，归纳推荐失败类型，再结合代码、数据和训练流程提出修复方案。在两个消费平台上，诊断量规达标项分别从 15/25 提高到 23/25、从 17/25 提高到 24/25；候选修复在三天离线评测中的全局指标变化均处于 ±0.1% 内，未证明线上增长。

INSIGHT可将该诊断链路迁移到社区搜索的低点击或相关性差评会话，输出可回查的帖子、查询和失败模式，并把原因映射到召回或排序代码。其价值在于把定性反馈转成可验证假设；修复仍需人工审查、独立相关性评测及 A/B 验证，不能用量规达标项增加代替 nDCG 或 CTR 的实际改善。

SungGeun Kim, Abhinav Narain, Daniel Nemirovsky

ToolLoop: Closed-Loop Tool-Use Data Synthesis via Decomposed Generation and Dynamic Self-Feedback

vivo

ToolLoop 把工具数据合成拆成函数组合采样、反向生成用户查询、正向生成调用三步，在各阶段加入动态验证与修正。仅用 11K 样本训练的 4B 模型在 BFCL 非推理模式达到 86.40%，去除重叠函数后仍有 86.07%；ACEBench 总分为 72.1%，比 ToolMind-4B 高 1.9 个百分点。

INSIGHT社区搜索工具集可先采样搜索、帖子读取和筛选等有效组合，再反推自然查询，逐步验证参数与用户意图是否一致。值得借鉴的是修复中间错误的闭环，而非扩大无差别合成量；应隔离评测函数，并额外测试用户偏好，因为论文中的个性化 Profile 子项在微调后仍弱于原始模型。

The Immutable Past: Formalizing State Mutability and Conflict Resolution in Mutable RAG

论文分析只追加不更新的 Agent 记忆如何让旧事实淹没新状态，提出 GC-Mem，以时间支配关系配合矛盾检测清理过期上下文。在包含 137,760 个记忆块的行为评测与累积扫描中，作者报告冲突消解准确率超过 90%；其保证依赖可变状态假设及冲突检测质量，不能外推为通用 RAG 定理。

INSIGHT社区问答里的帖子修订、用户条件变更和事件进展都可能造成新旧事实冲突，可先按实体与属性维护带时间的事实版本，再在生成前过滤被明确替代的值。不要简单删除较旧帖子：历史观点、独立作者意见与状态更新应分别处理；部署时重点测量误删有效证据的比例和矛盾检测精确率。

ScienceBuddy: Recursive-in-Recursive Self-Improvement for Interactive Scientific Agents

ScienceBuddy 将科研协作反馈转换为任务与评测量规，内层固定模型改进工具编排和流程，外层再用强化学习更新模型。工作区提供 224 个工具、22 个功能模块，任务库涵盖 895 个任务；三个循环中的流程优化使验证准确率分别由 38.9% 到 44.4%、34.4% 到 46.7%、61.1% 到 70.0%。

INSIGHT可借鉴交替优化的实验设计，先固定社区搜索模型，改进查询拆解、证据读取与停止流程，再评估是否值得训练模型。每次更新需要保存任务、工具和模型版本，并使用独立验证集；科研任务的准确率增益不能直接迁移为搜索收益，仍应以社区问题的引用正确率、nDCG 和响应成本重新检验。

Shuhan Xue, Jianyuan Zhong, Ziyuan Nan, Wenbin Li, Zhaochen Yu

Emergence World: Adversarial Stress-Testing of Long-Horizon Multi-Agent Systems

EEmergence AI

Emergence World 在 8 个世界中各运行 10 个智能体，持续 16 天并产生超过 85 万次模型调用、近 500 亿 token，再注入提示攻击、错误信息与记忆泄露事件。没有一个世界抵御全部三类压力；系统即使识别攻击，也可能把内容写入持久记忆，并在最多 46 小时后继续受其影响。

INSIGHT社区搜索 Agent 会接触用户帖子和外部网页，可把该评测思路缩小为跨会话回放：检查污染证据是否进入摘要、记忆和后续工具参数。重点记录攻击来源到最终答案的传播链，而非只测单轮拒绝率；完整实验成本很高，业务试验应优先复现与自身检索和记忆接口相关的少数故障场景。

Deepak Akkil, Tamer Abuelsaad, Karthik Vikram, Matthew Pace, Aditya Vempaty
