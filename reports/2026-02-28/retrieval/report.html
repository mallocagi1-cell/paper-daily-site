Domain-Adaptive and Scalable Dense Retrieval for Content-Based Recommendation

构建基于 two-tower bi-encoder 的可扩展 dense retrieval 系统，用对比学习微调并通过 FAISS + INT8 量化实现高效部署。

INSIGHT该方案完整展示了从 BM25 到 dense retrieval 的迁移路径：对比学习微调 + FAISS 索引 + INT8 量化，Recall@10 从 0.26 飙升至 0.66，且推理延迟仅 6.1ms。

业务关联社区搜索中 UGC 短文本语义匹配正是 dense retrieval 的典型场景，该方案的 two-tower 架构和量化部署策略可直接复用于帖子/问答的语义召回。

证据Amazon Reviews 2023 Fashion 数据集上 Recall@10 从 BM25 的 0.26 提升到 0.66（+153%）；826,402 条目录项；中位推理延迟 6.1ms（CPU）；INT8 量化实现 4x 模型压缩。

Mritunjay Pandey

LLM-Confidence Reranker: A Training-Free Approach for Enhancing Retrieval-Augmented Generation Systems

提出免训练的 LLM-Confidence Reranker (LCR)，利用黑盒 LLM 置信度信号进行即插即用的重排序。

INSIGHTLCR 无需任何训练即可提升重排效果，利用 LLM 生成答案时的 token 置信度作为文档相关性信号。这为搜索系统提供了零成本引入 LLM 重排能力的路径。

业务关联社区搜索可在现有排序管线后叠加 LCR 做精排，无需额外标注数据和训练成本即可提升 nDCG，特别适合快速验证 LLM reranking 的业务价值。

证据多个基准测试上 NDCG@5 最高提升 20.6%；即插即用设计，无需微调或额外训练数据。

Learning to Select: Query-Aware Adaptive Dimension Selection for Dense Retrieval

提出 query 感知的自适应维度选择框架，为每个查询动态选择最优 embedding 维度子集以提升 dense retrieval 效果。

INSIGHT并非所有 embedding 维度对所有 query 都有用。通过学习 per-query 的维度重要性预测器，可以在不增加推理开销的前提下同时提升检索质量和效率。

业务关联UGC 搜索中 query 类型多样（关键词、问句、口语化表达），自适应维度选择可为不同类型 query 动态调优 embedding 表征，提升语义匹配精度。

证据在标准 IR benchmark 上，相比全维度 baseline 和其他 masking 方法均有提升；推理时无需 pseudo-relevance feedback。

Zhanyu Wu, Richong Zhang, Zhijie Nie

Towards Dynamic Dense Retrieval with Routing Strategy

引入动态 dense retrieval (DDR)，通过 prefix tuning 模块和动态路由策略实现零样本域适应，仅用 2% 训练参数。

INSIGHT用 prefix tuning 将领域知识封装为可组合模块，通过路由策略动态选择和组合模块，实现了参数高效的跨域检索能力。

业务关联社区搜索内容覆盖多个话题领域（美食、旅行、技术等），DDR 的动态路由机制可为不同话题自动匹配最佳检索模块，无需每个领域单独训练完整模型。

证据6 个零样本下游任务上超越传统 dense retrieval；仅需 2% 的训练参数量；支持模块化组合。

Zhan Su, Fengran Mo, Jinghan Zhang, Yuchen Hui, Jia Ao Sun, Bingbing Wen, Jian-Yun Nie

HubScan: Detecting Hubness Poisoning in Retrieval-Augmented Generation Systems

发现向量检索中的 hubness poisoning 攻击向量，并提出 HubScan 检测方法来保护 RAG 系统安全。

INSIGHT高维向量空间中的 hubness 现象（某些向量成为大量 query 的近邻）可被攻击者利用来毒化检索结果。HubScan 通过检测异常 hub 节点来防御此类攻击。

业务关联社区搜索依赖向量检索做语义召回，hubness poisoning 可能导致恶意内容被高频召回。部署 HubScan 可作为内容安全的额外防线。

证据在 RAG 系统场景下验证了 hubness poisoning 攻击的有效性和 HubScan 检测方法的可靠性；覆盖多种 embedding 模型。

MTRAG-UN: A Benchmark for Open Challenges in Multi-Turn RAG Conversations

发布 MTRAG-UN 多轮 RAG 对话基准，包含 666 个任务、2800+ 轮对话，覆盖 6 个领域。

INSIGHT多轮检索对话中存在上下文依赖、指代消解和查询演化等独特挑战，现有单轮 RAG 方法在多轮场景下性能显著下降。

业务关联社区搜索中用户常有多轮交互需求（追问、细化搜索意图），MTRAG-UN 的评测框架可帮助评估和改进社区搜索的多轮对话检索能力。

证据666 个任务，2800+ 对话轮次，6 个领域；提供多轮 RAG 系统的标准化评测方案。

Decoder-based Sense Knowledge Distillation

将词义知识蒸馏从 encoder 扩展到 decoder 模型，利用结构化词典知识增强 LLM 的词义区分能力。

INSIGHTLLM 的上下文 embedding 虽然语义丰富，但忽略了结构化词义知识。通过 sense knowledge distillation 可补全这一短板，提升下游语义匹配效果。

业务关联UGC 短文本中一词多义现象普遍（如「苹果」指水果还是品牌），词义消歧能力的提升可直接改善搜索语义匹配的准确性。

证据将 sense dictionary 知识蒸馏到 decoder 模型中，在词义消歧和语义理解任务上验证了有效性。

Enriching Taxonomies Using Large Language Models

利用 LLM 自动扩充和完善知识分类体系，解决现有 taxonomy 覆盖不足和节点过时的问题。

INSIGHTLLM 可以高效地识别 taxonomy 中的覆盖盲区并生成补充节点，大幅降低人工维护分类体系的成本。

业务关联社区搜索依赖内容分类体系做查询理解和结果组织，利用 LLM 自动扩充分类树可提升 query 归类准确性和搜索结果的结构化展示。

证据在多个领域的 taxonomy 上验证了 LLM 扩充节点的覆盖率提升和质量保持能力。

Knowledge Graph Retrieval-Augmented Generation for LLM-based Recommendation

将知识图谱检索与 RAG 框架结合，增强 LLM 推荐系统的知识准确性和可解释性。

INSIGHT在 LLM 推荐中引入知识图谱作为外部检索源，不仅提升推荐精度，还通过 KG 路径提供可解释的推荐理由。

业务关联社区搜索中可借鉴 KG-RAG 思路，利用社区内容知识图谱增强搜索结果的关联性和可解释性，如展示搜索结果与 query 的知识关联路径。

证据在推荐任务上验证了 KG-RAG 方法的效果提升，提供了 KG 检索与 LLM 生成的端到端框架。
