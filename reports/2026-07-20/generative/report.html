LLM is Knowledge Graph Reasoner: LLM's Intuition-Aware Knowledge Graph Reasoning for Cold-Start Sequential Recommendation

论文面向冷启动序列推荐，把 LLM 限定为知识图谱推理策略生成器：先用带时间顺序的提示预测用户未来偏好，再以 LLM 直觉与 KG 嵌入共同构造强化学习奖励，避免把全量物品塞入上下文。在 MovieLens-1M 上，LIKR 的 Recall@20、nDCG@20 分别为 4.83% 和 19.14%，均高于所列序列与图谱基线。

KEY INSIGHT · 对业务意味着什么关键价值在于让 LLM 负责生成可解释的探索方向，而把大规模候选约束、路径搜索和打分交给知识图谱，兼顾开放知识与线上可扩展性。对社区 UGC 的新用户或新兴趣冷启动，可将主题、作者、实体关系建成 KG，并把 LLM 偏好信号作为奖励的一部分；实验也显示纯 LLM 或纯 KG 奖励都不如二者混合。
