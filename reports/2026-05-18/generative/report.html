Efficient Generative Retrieval for E-commerce Search with Semantic Cluster IDs and Expert-Guided RL

针对生成式检索在大规模电商搜索中难以落地的问题，论文把它定位为召回阶段的增量通道，不替换原有多级检索。CQ-SID 结合类目感知与 query-item 对比学习，叠加 Residual Quantized VAE，压缩 beam search 复杂度；EG-GRPO 用稀疏奖励让生成式检索对齐下游排序目标。离线语义点击 hitrate 相对提升最高 26.76%、个性化点击 hitrate 提升 11.11%，beam size 减半；线上 A/B GMV +1.15%、UCTCVR +0.40%；生产环境中生成式召回通道贡献 50.25% 曝光、58.96% 点击、72.63% 成交。

1. 问题与动机

论文针对生成式检索在大规模电商搜索中难以直接落地的三个障碍展开。其一，端到端从数亿量级商品库中生成，存在覆盖率、延迟与马太效应（Matthew effect）问题；其二，one-item-one-ID 的 Semantic ID 映射需要海量训练数据和很大的 beam size，与线上延迟约束冲突；其三，仅用点击信号训练的召回模型与下游排序目标不对齐，召回出的候选不一定是下游愿意曝光的高质量候选。基于此，作者明确把生成式检索定位为召回阶段的增量通道（recall-stage supplement），而不是整链路替换，从而把问题约束在"可控延迟下补充长尾语义召回"这一可部署的范围内。这一动机来自真实生产约束：论文最终在天猫 App（TmallApp）上以 200 QPS / 8 GPU、~40ms 端到端延迟、99.9% 可用性部署，说明问题设定是从工程可行性反推的。

2. 方法详解

方法由 CQ-SID（语义聚类 ID 构造）+ 渐进式 Query-to-SID 训练 + EG-GRPO（排序对齐 RL）三段组成。

CQ-SID 把 Semantic ID 当作聚类标识而非物品唯一 ID，遵循三原则：语义聚合（相似物品映射到同一 SID）、簇间可区分、层次结构（共享前缀便于 beam search 剪枝）。骨干是三层 RQ-VAE，码本规模 K1×K2×K3 = 2048×1024×1024。第一层用类目引导残差量化（Category-Guided Residual Quantization）：第一层码本被约束到 1711 个有效类目 ID，已知物品直接用类目 ID 索引第一层码本，其余走最近邻量化；码本用 EMA 更新（衰减因子 λ∈(0,1)）并配 codebook restart 防坍缩。第二个组件是 query-item 对比学习，对高置信 query-item 对施加双向 InfoNCE 损失（cosine 相似度、温度 τ），无关联 query 的物品做 mask。联合目标 L = L_recon + β·L_commit + γ·L_InfoNCE，超参 β=1.0、γ=0.001、τ=0.1、对比 batch=128。SID 后处理（Algorithm 1）用 T_max=50、G_max=100：簇大小超过 T_max 时随机切成 G 组并拼接组后缀，缓解大簇内不可区分。

渐进式训练用 Qwen2.5-0.5B，分四阶段：Stage1 Item-to-SID（物品标题，batch 128，LR 1e-4，2k steps）；Stage2 Query-to-SID（query + N=3 采样 SID，90.3M 样本，batch 256，LR 4e-5，2.5k steps）；Stage3 个性化 UQ2SID（用户特征 + query + 近期点击，73.7M 样本，batch 64，LR 4e-5，5k steps）；Stage4 排序对齐用 EG-GRPO（rollout batch 512，group size 8）。CQ-SID 训练数据共 37.5M（21.1M 含 query-item 对，16.4M 仅物品）。

EG-GRPO 的奖励分层（Eq.8）：购买 1.0、点击 1.0、曝光 0.5、合法 SID 0.1、其余 0.0；优势用 GRPO 标准的组内归一化 A(oi)=[R(oi)-mean]/[std+ε]。关键创新是专家注入（Algorithm 2）：从 P_clk∪P_exp 采样 K 个 ground-truth SID 作为伪生成输出注入组内，扩展组 G=G_sampled∪G_expert 共同参与奖励与梯度，在稀疏奖励下提供稳定高质量信号，避免标准 GRPO 的 mode concentration（过度集中到高置信 SID 而坍缩探索）。超参 K=2 或 4、group size 8、KL 权重 1.0、LR 1e-6、1k steps。

3. 核心技术贡献

第一，CQ-SID 用语义聚类 ID 替代 one-item-one-ID，配合类目引导量化与 query-item 对比学习，把 beam search 复杂度显著降低——这是它能在 ~40ms 延迟内服务的根因，机制在于层次前缀让 beam search 可早剪枝，且聚类降低了需要区分的目标空间。第二，四阶段渐进式 SFT 把 query→SID 映射从物品语义对齐逐步细化到个性化，解决了直接训练个性化生成数据需求过大的问题。第三，EG-GRPO 通过注入 ground-truth 样本稳定稀疏奖励优化，并用分层奖励同时平衡点击与曝光两个目标；相比标准 GRPO（K=0）在 clk@10/pvr@10 上反而下降，EG-GRPO 在 clk/exp/pvr 全指标一致正向。第四，完整的线上 A/B 与生产占比数据，验证了该范式作为召回增量通道的真实业务价值。

4. 实验结果分析

语义召回（同 beam，Table 1）：CQ-SID 在 beam@1 达 0.0758，相对 RQ-VAE 0.0598 提升 26.76%，beam@10/@100 分别 +22.57%/+18.89%；消融显示去掉类目（w/o Cate）提升降到 +13.71%，去掉 query-item（w/o QI）在 beam@1 甚至 -0.33%，说明 query-item 对比对低 beam 预算最关键。效率（Table 2）：CQ-SID 在 beam@30 取得 0.4422，超过 RQ-VAE 在 beam@65 的 0.4275，等价 beam 数减少约 53.85%。个性化召回（Table 3）：同 beam 下 beam@1 0.1510（+11.11%）、beam@100 0.7431（+7.51%）；top-1K 截断下 CQ-SID 在 beam@160 达 0.7984，优于 RQ-VAE beam@195 的 0.7607（beam 数 -17.95%）。EG-GRPO 对齐效果（Table 4）：标准 GRPO（K=0）出现 mode concentration——clk@1 升但 clk@10、pvr@10 降；EG-GRPO（K=2/4）在 clk@1/clk@10/exp@1/exp@10/pvr@10 全部正向。线上：天猫 App 两周 A/B，GMV +1.15%、UCTCVR +0.40%；生产中该通道贡献 50.25% 曝光、58.96% 点击、72.63% 成交，成交占比远高于曝光占比，说明语义召回带来的候选转化质量高。

5. 局限与未来方向

作者明确指出 EG-GRPO 增益幅度有限，原因是 SFT 已把模型带到接近局部最优，RL 提升空间被压缩；且 hitrate 是二值指标，一旦目标 SID 已在 beam 内便无法进一步体现增益，低估了 RL 的实际作用。作者也强调点击与曝光之间的权衡是"真实而尖锐"的，EG-GRPO 是在 Pareto 前沿上导航而非单目标最大化，这意味着收益依赖业务对两目标的相对偏好。此外方法显式限定为多级漏斗中的召回增量通道，top-1K 截断把数亿库压到 21M，未覆盖端到端排序-生成统一；聚类 ID 的随机分组后缀对极大簇仍是近似手段，簇内可区分性是潜在天花板。

6. 工业实践意义

对社区 UGC 短文本搜索，最直接的借鉴是把生成式语义召回作为现有倒排/向量召回旁挂的一路增量通道，而非替换主链路——72.63% 成交占比说明它能补足长尾语义覆盖且转化质量高。具体可落地的设计：用类目（或社区话题/标签体系）引导第一层码本，使 SID 天然带业务先验并支持 beam 早剪枝；用高置信 query-item 点击对做双向 InfoNCE，把相关性信号注入 tokenizer；用聚类 ID 而非物品唯一 ID 控制 beam 规模，是 ~40ms / 200QPS / 8GPU 可服务的关键。EG-GRPO 的专家注入对稀疏奖励场景（社区搜索点击/互动稀疏）尤其有用，可缓解 GRPO 的 mode concentration；奖励分层（互动>点击>曝光>合法）可直接映射到社区的点赞/收藏/点击/曝光分层。部署要点：动态 beam [20,50,100]、层次 SID 剪枝、top-1K 截断控制候选规模，是延迟可控的工程前提。

Making LLMs faster without sacrificing accuracy (Surefire architectural scaling law)

Amazon

AWS AI Labs 在 Chinchilla scaling law 基础上引入三个架构因子（hidden size d_model、MLP-to-attention 比例、GQA），把架构选择直接纳入 loss 预测。发现 LLaMA-3.2 风格模型最优 MLP/attention 比约为 1.0，远低于现有开源权重（LLaMA-3.2-1B 为 4.8），即现有模型在 MLP 层过度分配参数。据此训练的 Surefire-1B 在 H200+SGLang 上吞吐提升 47% 且精度不降，Surefire-3B 提升 12–17%，结论在 A100/H200 与 vLLM/SGLang 上一致。ICLR 2026。

INSIGHTscaling law 不只决定参数量，架构比例本身可纳入 loss 预测来指导设计：MLP/attention 比从 4.8 降到 1.0 即换来 47% 吞吐。对搜索/推荐的实践启示：若用 LLM 做 query 理解、生成式召回或重排，backbone 的 MLP 膨胀系数与 GQA 配置直接决定线上延迟和单卡吞吐成本，按该 scaling law 重选架构比单纯堆参数更划算。

Asymmetric Generative Recommendation via Multi-Expert Projection and Multi-Faceted Hierarchical Quantization

论文指出生成式推荐把物品表示为离散 Semantic ID，并对称地同时用作输入与预测目标，存在双阶段信息瓶颈：输入瓶颈（有损量化损失细粒度语义、流行度偏置使表示偏向高频物品）与输出瓶颈（不精确的离散目标限制监督质量）。AsymRec 用非对称连续-离散框架解耦输入输出：Multi-expert Semantic Projection（MSP）用专家化投影把连续 embedding 映射进 Transformer 隐空间，保留语义并提升对低频物品的泛化；Multi-faceted Hierarchical Quantization（MHQ）用多视图多层量化加语义正则构造高容量结构化离散目标，防止维度坍缩。相比 SOTA 生成式推荐平均提升 15.8%，代码将开源。

INSIGHTSemantic ID 作输入与目标的对称用法是当前生成式推荐的隐性瓶颈。AsymRec 的解法是输入侧保连续（多专家投影抗流行度偏置、利好长尾）、输出侧造高容量结构化离散目标（多层量化抗维度坍缩）。对生成式召回/推荐的借鉴：tokenizer 不必让输入输出共享同一套 SID，输入连续表示 + 输出结构化离散目标的非对称设计能同时缓解长尾与监督质量问题，15.8% 的平均增益说明瓶颈定位准确。
