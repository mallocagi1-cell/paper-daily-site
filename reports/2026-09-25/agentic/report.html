Just-in-Time Memory: Learning to Curate Task-Adaptive Memory for LLM Agents

JitMem 保留原始任务轨迹，在新任务到来后才按需整理记忆，而不是提前写成固定摘要；整理器可直接利用当前任务成功信号训练。在 ALFWorld、WebShop、τ²-bench 上，相对最强基线的成功率分别提高 16.2、16.3 和 3.9 个百分点，未训练整理器也有竞争力。

INSIGHT社区搜索 Agent 可先检索历史成功轨迹，再围绕当前查询提炼可用步骤，减少提前压缩造成的细节丢失。建议从不训练的读取时整理开始，与固定记忆摘要做等预算比较，测量多轮问题解决率、引用正确性和额外延迟，并明确区分用户事实与操作经验。

Verifiable Hidden Dynamics Play: Generating Agentic RL Environments from Solved Mechanisms

VHD-Play 先采样并求解数学机制，再将机制呈现为有状态工具，使环境动态与评分依据共享来源。系统以每个数美分生成 3,300 个 Agent 环境；Qwen3.6-35B-A3B 在三个机制族训练后，五族诊断的平均得分从 0.204 升至 0.815，并评估未见机制迁移。

INSIGHT对搜索 Agent 的 RL 训练，可借鉴先确定可验证目标和状态转移、再生成交互任务的顺序，减少奖励与工具行为脱节。社区试验可构造具有明确证据覆盖条件的多步检索任务，但机制模拟得分不能替代真实用户满意度，需另外检查查询分布和工具噪声。

Meet, Compare, or Abstain: LatWeave for Deterministic Multi-Hop Question Answering on Knowledge Lattices

LatWeave 将多跳问答编译为知识格上的交集、比较和拒答三类确定性算子，仅在构建及查询规划阶段使用 LLM。MetaQA 的 39,093 道题上 any-hit 为 0.9975，2WikiMultihopQA 的 1,258 道留出题 EM 为 0.865；IIRC 拒答准确率为 0.971。

INSIGHT可将社区中的结构化条件筛选交给确定性执行，搜索 Agent 负责把问题转成约束，并保留每一步可重算的证据。优势依赖知识抽取覆盖率与条件可表达性，不能把完整知识库结果外推到开放短帖；建议单独统计证据缺失拒答与错误规划。

COMED: The Missing Middle Between Routing and Collaboration in Multi-LLM Inference

COMED 针对多模型协作既能修复错误、也可能破坏正确答案的问题，利用主模型自一致性、路由间隔及轻量同伴探测决定是否升级协作。在 16 个开放权重设置均取得增益，MedQA 最高提升 10.7 个百分点；HLE 上 GPT-5.5 从 23.1% 升至 28.1%。

INSIGHT社区搜索 Agent 可按不确定程度选择接受、核验或升级多模型讨论，避免每个短查询都承担完整协作成本。实践中需同时测量修复了多少错误和引入了多少新错误，并以查询难度分层评估答案质量、token 消耗和尾部延迟，而非只看整体正确率。

Dual-Hypergraph Indexing: Bridging Knowledge Islands for Multi-Hop Reasoning in Retrieval-Augmented Generation

双超图索引针对多跳 RAG 中事实彼此孤立的问题，同时建立事实超图与深层洞察超图，通过重要性驱动的枢纽聚合和时间片段链连接证据。作者在五个基准上评估，报告 Mix 逻辑连贯性提升 1.53，复杂医学病理推理得分为 85.78%。

INSIGHT对社区 UGC 搜索，可借鉴事实层与跨帖结论层分离的组织方式，让搜索 Agent 同时沿实体关联和时间顺序寻找证据。优先试验需要追踪事件变化的复杂问答，并保留原帖引用；上述离线推理结果不能直接解释为社区 nDCG 或 CTR 增益。

Large Knowledge Model: From Papers to a Scientific Reasoning Landscape

LKM 把论文转成带来源的推理图，将结构遍历与语义检索连接到同一知识对象，并组织问题、工作流和证据三种视图。固定回答模型时，作者报告 ChemBench、PubMedQA 和 SciBench 准确率分别提升 9.30%、4.20% 和 14.69%，增益口径沿用原文。

INSIGHT对社区深度搜索，启示是把帖子中的问题、结论、条件和支持材料关联起来，使 Agent 能检索推理链而不只找语义相近段落。可先在专业问答板块建立带原帖出处的证据图，并比较固定生成模型下的答案正确率、引用覆盖与检索成本。

UniDataAgent: An Ontology-Grounded Agent for Enterprise Question-to-Report Automation

China Unicom

UniDataAgent 将企业本体获取验证与在线问答执行分开，先构建版本化语义约定，再检索约定、协调业务技能和数据工具生成报告。在 27 张企业表及约数千类指标上，本体构建由约一周缩短到数小时，业务问题严格准确率为 95.0%，文档 RAG 为 72.5%。

INSIGHT对社区搜索运营分析，可以把指标定义、时间窗口及统计口径作为可检索的语义约定交给 Agent，减少工具调用正确但业务解释错误的情况。适合先用于 nDCG、CTR 实验分析和问题诊断报告；企业表格结果不能代表开放 UGC 内容检索质量，仍需人工抽检。

Parallel cut research time and cost in half with GPT‑6 Astra

ParallelOpenAI

Parallel 的案例介绍网页研究 Agent 如何完成跨站点的信息收集与汇总。测试任务覆盖四个州、六个月及六类劳动力指标，官方报告使用 GPT-6 Astra 后研究耗时减半、代码成本约降 50%，同时保持研究质量；案例未披露公开基准及完整对照细节。

INSIGHT社区深度搜索可借鉴更聚焦的子查询和更少的研究步骤，按任务衡量端到端时间与费用。试验应固定问题集并核对答案及引用，区分模型升级、调用次数减少和任务拆分各自的贡献；该案例属于厂商自报结果，证据强度低于可复现论文。

LEGO: Synergizing Expert GraphRAG and Expert Chain-of-Thought for Legal Reasoning

LEGO 把专家标注的法规关系图与结构化推理结合，先用规范覆盖贪心算法抽取相关条文子图，再按条文、事实、结论组织推理。基于 Qwen3-8B，在 LawExamQA_Civil 上取得 40.53% 精确匹配率，作者另报告开放式任务比较及双模块消融。

INSIGHT值得借鉴的是以任务所需关系覆盖来组织检索，并让生成步骤显式消费这些关系。社区规则问答可先对版规及适用条件建立小型图谱，再映射到帖子证据；普通兴趣搜索缺乏稳定规范关系，迁移前应验证图谱标注成本及实际覆盖率。
