jina-reranker-v3.5：基于混合注意力机制与自蒸馏的更高效列表式重排器

论文发布 0.6B 参数的列表式重排器，保留 LBNL 跨文档交互，并用三层滑动窗口加两层全局注意力替代统一全局注意力，再通过三阶段自蒸馏迁移质量。在 BEIR 上取得 63.20 nDCG@10，MIRACL 为 74.11，Struct-IR 比 v3 提升 9.6 点，长文档重排速度提升 1.56 倍。

ES 向量搜索介绍

Tencent

腾讯云将 ES 扩展为文本、向量、聚合与模型推理一体的搜索底座，生产规模建议使用支持十亿到百亿向量的 ANN，并可用 HNSW、BM25 与 RRF 组合。其自研 Multi-Path 查询并行化在相同召回率下最高加速 4 倍，混合检索性能提升 30%–80%，召回率提升 10%–20%。

INSIGHTUGC 搜索不宜只部署孤立向量库：把关键词精确匹配、业务过滤、向量召回、RRF 融合和 Embedding/Rerank 推理放在同一条可观测链路，更容易维护 nDCG 与 CTR 的共同目标。落地时应先用离线流量校准 HNSW、量化和过滤顺序，再核验厂商宣称的 4 倍加速是否适用于自身数据分布。

腾讯云

Best Practice Critic Optimization

BPCO 针对基于 critic 的大模型强化学习训练不稳定问题，组合 DPPO、奖励范围内的 value 预测、Monte Carlo 目标、未归一化 advantage 与长度自适应 GAE，并允许 critic 使用策略不可见的参考答案或评分规则。受控实验覆盖 1.5B 到 30B-A3B MoE 模型，逐项隔离这些设计并持续优于强 critic 基线。

INSIGHT如果社区搜索要用点击偏好、相关性判断或规则评分做 RL 后训练，critic 的稳定性会直接决定 GPU 利用率和实验迭代速度。BPCO 提供了可拆分的训练配方：先固定奖励范围与目标估计，再分别验证 GAE、长度校正和特权信息，避免一次改动掩盖数据或奖励函数问题。

Penghui Qi, Xiangxin Zhou, Wee Sun Lee

NVIDIA NVLink Fusion Brings NVHBM to Next-Generation AI Infrastructure

NVIDIA

NVIDIA 介绍用 NVLink Fusion 将定制 XPU、CPU 与 GPU 接入机架级互联，并以 NVHBM 缓解大模型权重和 KV Cache 的带宽瓶颈。相较标准 HBM4e，方案宣称内存带宽最高增加 30%、计算 die 面积增加 25%、HBM 功耗降低 15%，综合 XPU 端到端性能提升 30%。

INSIGHT长上下文检索、MoE 重排和高并发 Embedding 服务的瓶颈会逐步从算力转向内存与互联；因此容量规划要同时记录 KV Cache 命中率、跨卡通信和每 token 能耗。对社区搜索团队，这更像硬件路线信号而非六个月内可直接采用的组件，应先用现有 GPU 的带宽压测验证是否值得走机架级扩展。

Farshad Ghodsian, Jesse Clayton, Varun Nanda Kumar

MoTE: Mixture of Task Experts for Multi-Task Video Understanding

MoTE 把语言模型 FFN 改造成按任务划分的专家，同时共享多模态骨干；每个样本只激活一条任务路由，因此存储更多专家不会线性增加单样本计算。作者在五个 COIN 基准上评估五专家 VideoLLM-MoTE，激活约 2B LLM 参数，为多任务能力扩展提供了条件计算方案。

INSIGHT搜索与推荐平台常把语义匹配、内容理解和质量判别堆在同一模型里，任务级专家路由可作为隔离能力与控制成本的设计参考。迁移到 UGC 场景前，应先验证任务标签质量和路由负载均衡，并分别测量专家数量、激活参数量与 p99 延迟，而不是只看离线平均指标。

Muhammad Asad Ali, Umar Khan, Nadia Robertini, Didier Stricker

TorchMorph: CUDA-accelerated Morphological Transforms

TorchMorph 用融合 CUDA kernel 把形态学处理、距离变换和熵正则最优传输直接放在 PyTorch CUDA tensor 上，解决 scipy.ndimage 仅支持 CPU、单数组而导致的设备往返。它提供 22 个公开算子，兼容 scipy 参数约定，并支持最多 8 个空间维度，便于插入 GPU 训练或预处理流水线。

INSIGHT它的直接价值不在文本检索算法，而在提醒基础设施团队优先消除数据预处理中的 CPU/GPU 往返；同样的 profiling 方法可用于 UGC 图片、OCR 和多模态检索管线。若接入生产，应核对不同 batch、dtype 和张量维度下的 kernel 吞吐，并把算子兼容性测试纳入模型发布门禁。

Kai Zhao

LAION-BVD: A 10-Million-Hour Open Video Dataset for Multimodal Pre-training

LAION

LAION-BVD 从 CommonCrawl 收集 13 亿个视频 URL，下载 8000 万段、总计 1000 万小时的视频，并用场景切分生成视频与音频描述，覆盖多模态预训练和图文检索。作者报告模型在视频文本、音频文本基准上随数据或模型规模扩大而持续改善，同时释放了可复用数据资源。

INSIGHT对 UGC 搜索而言，大规模视频数据的价值取决于可检索的元数据、版权边界与增量更新能力，而不只是小时数。可借鉴其场景切分和多模态标注思路，先建立小规模、可审计的数据闭环，用召回覆盖率、标签噪声和索引成本评估是否值得扩大训练集。

Andreas Hochlehnert, Marianna Nezhurina, Mehdi Cherti, Andrej Radonjic, Thaddäus Wiedemer
