Data Quality over Capacity: Internalizing Documents into LoRA Adapters for Closed-Book QA

论文把文档通过 LoRA 直接写入 4-bit Gemma-4-e4b 权重，以消除 RAG 的检索与上下文开销。约 100 次训练显示，15 文档语料经一次答案清洗后，闭卷准确率由 57.7% 升至 85.7%；适配器召回率 84.2%，高于 BM25-RAG 的 58.9% 和金标分块上限的 65.6%。

NVIDIA Nemotron 3 Ultra Leads Open Models on Accuracy and Efficiency in Agentic RTL Coding

NVIDIA

NVIDIA 将 Nemotron 3 Ultra 与 ACE-RTL 的“生成—测试—反思”循环结合，用于芯片 RTL 生成、修改、调试和验证。该模型采用 550B 总参数、55B 激活参数的混合 Mamba-Attention MoE 架构，在 CVDP 九类任务上平均通过率 97.1%，每轮仅用 6,629 tokens，较 Kimi K2.6 少 71%。

INSIGHT开放模型的基础设施价值不只看单轮代码能力，而要看能否在工具反馈闭环中以更少 token 稳定收敛。对内部代码或配置生成平台，可复用 ACE-RTL 的协调器、执行器与反思器分层，并把“每次成功所需 token/验证轮数”加入成本与延迟看板。

Enough is as good as a feast: A Comprehensive Analysis of How Reinforcement Learning Mitigates Task Conflicts in LLMs

BaiduCASUCAS

论文系统比较 SFT 与强化学习训练模型在合并后的任务冲突，覆盖数学、代码、指令遵循、逻辑谜题和排序五类任务。结果表明 RL 模型在不同基座、合并算法和 RL 算法下均有更小性能退化；机理来自 on-policy 数据的小梯度更新、收敛时冲突参数减少，以及正负样本联合优化形成更无偏的任务子空间。

INSIGHT模型合并的质量应从后训练阶段开始设计，而不是只在合并算子上补救。需要组合多个搜索、排序或工具能力时，可优先合并 RL 后训练检查点，并监控参数更新符号冲突和梯度范数；这可能比对多个 SFT 模型做复杂剪枝更稳，也能减少保留多套模型的服务成本。

Zixuan Ren, Jinliang Lu, Junhong Wu, Yang Zhao, Dai Dai, Hua Wu, Haifeng Wang, Chengqing Zong

MEUSLI: a Multilingual Projector for LLM-based ASR and Beyond

MEUSLI 用轻量线性 projector 连接 Whisper 编码器与开源多语 LLM，构建覆盖 28 种欧洲语言的全开源 SpeechLLM。乌克兰语仅用 30 小时数据微调后 WER 为 16.34%，优于从头训练的 20.43%；每语言回放 1,000 个样本即可把旧语言平均 WER 从灾难遗忘后的 54.22% 恢复到 10.65%。

INSIGHT共享 projector 是扩展多语言语音入口的低成本路径，核心不在扩大主模型，而在保持编码器、投影层和语言分布的可迁移接口。面向社区搜索语音查询，可先冻结 Whisper 与 LLM，只训练 projector；新增低资源语言时加入小规模 replay buffer，避免旧语言整体退化。

Lorenzo Concina, Seraphina Fong, Marco Matassoni, Alessio Brutti

MoE$^2$-LoRA: When MoE Models Meet MoE-style Low-Rank Adaptation

Shanghai AI LabKTHUSTCFudanCUHK

MoE²-LoRA 通过双通道 Routing-Conditioned Projection 复用基座 MoE 路由信号，并让所有层共享一个全局 LoRA 专家池，实现按 token 动态适配与跨层知识共享。它在 OLMoE、DeepSeek-V2-Lite、Qwen3 和 Qwen3.5 四种 MoE 基座上评测，域内平均准确率最多超过最强 PEFT 基线 2.56 分。

INSIGHT为 MoE 搜索或推荐模型做领域适配时，不应给每个专家机械挂同构 LoRA；基座路由本身就是可复用的专家先验。共享 LoRA 池可避免参数随层数线性膨胀，并保持专家利用均衡，但上线前需同时压测路由计算、显存峰值和多租户适配器隔离。

Qingyu Yang, Haonan He, Minglei Li, Jingqi Ye, Tao Chen, Lei Bai, Peng Ye

NVIDIA Ising Enables Fully Automated Quantum Computer Calibration with Enhanced In-Context Learning

NVIDIA

NVIDIA Ising Calibration 1.5 是面向量子处理器校准的开放 31B 多模态模型，并配套 NIM、QCalEval 与 agent 工作流。QCalEval 含 243 个样本、87 类场景和 22 个实验族；该模型可利用同实验上下文自动提出校准动作，Ising 系列还提供比传统解码器最高 2.5 倍低延迟、347 倍逻辑错误率改善的专用模型。

INSIGHT这套发布展示了垂直模型基础设施的完整形态：开放权重、领域基准、容器化推理、微调样例和 agent 闭环缺一不可。其领域离搜推较远，但“图表理解—参数提取—工具执行—复测”的模式可迁移到集群诊断、模型监控和自动调参，重点是让评测集覆盖真实故障族。

grapheme-kit: Grapheme-Level Metrics and Text Processing for Multilingual NLP

grapheme-kit 是面向多语言 NLP 的开源 Python 库，把编辑距离、相似度和评测指标从 Unicode code point 提升到真实字素簇。库中特别补齐 Tamil 与 Sinhala 两种复杂书写系统的字素识别、组合和分解能力，并通过 OCR 案例证明 code-point 指标会把同一视觉字素拆开，从而失真地计算错误率。

INSIGHT多语言搜索的离线评测与 query 归一化不应默认“一个码点就是一个字符”。对南亚及组合字符密集语言，可把字素级切分放到 tokenizer 前的规范化层，并同步改造拼写纠错、OCR 质量和召回评测指标；该库体量小、接入成本低，适合先做影子评估。

Scaling Native Multimodal Pre-Training From Scratch

论文首次系统刻画原生多模态模型从零预训练的缩放规律，在固定计算预算下联合求解模型规模、token 数量与文本/多模态数据配比。结果显示最小目标损失遵循可预测计算律，但语言与多模态分配律不同：文本占比高的数据混合只有在更大模型规模时才具备计算效率，并据此给出三变量效率前沿。

INSIGHT规划多模态搜索基座时，不能直接沿用纯文本 Chinchilla 式配比；模型越小，过多文本可能挤占视觉学习预算。更稳妥的做法是先用小规模 sweep 拟合本域计算律，再按效率前沿决定参数、token 与图片比例，并把纯文本空间推理作为跨模态迁移的额外验收项。

Haoyuan Wu, Aoqi Wu, Hai Wang, Jiajia Wu, Jinxiang Ou, Bei Yu

The Hard Decision Layer: Evidence for Committed Inference in Transformers

论文在 Qwen、Llama、Granite、Mistral 四类模型和四个问答基准上发现 Hard Decision Layer：候选答案排序会在某一层突然稳定，且该位置对微调基本不变。Qwen 在 CommonsenseQA 到达该层时准确率最高跃升 0.61，之后继续计算收益趋稳；标签格式和题目复杂度消融仍保留该现象。

INSIGHTHDL 为自适应早退和中间层路由提供了无需额外训练的观测信号，但当前证据来自多选题，不能直接等价为生成式服务加速。基础设施团队可先在 reranker 或分类模型上记录层间排名稳定度，离线验证准确率—延迟曲线，再决定是否跳过后续层或触发更强模型。

Ashwath Vaithinathan Aravindan, Mayank Kejriwal

Advancing Semiconductor Innovation Across Materials Engineering and Manufacturing

NVIDIAApplied Materials

NVIDIA 与 Applied Materials 展示从材料发现、工艺仿真到晶圆厂数字孪生的连续计算链路。Ginestra 结合 cuDSS/cuEST 加速原子级器件模拟，ACE+ 与 PhysicsNeMo 将多物理场拓扑仿真最高提速 35 倍，把原需数天的流程压缩到当天；Omniverse 再用于整厂布局和物料流验证。

INSIGHT文章与搜索业务距离较远，但体现了 AI 基建的关键方法：把离散仿真工具、代理模型与数字孪生串成可追踪的数据闭环，而非单点部署模型。对大规模训练和推理平台，可借鉴其“高保真慢模拟校准、快速代理在线探索、统一场景回放”的分层验证架构。
