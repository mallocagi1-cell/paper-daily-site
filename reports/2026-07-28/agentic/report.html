1. 下一代搜索智能体评测基准！美团开源LoHoSearch，用知识图谱校准AI能力认知
4.70
Relevance 4 | Novelty 5 | Practical 5 | Evidence 5 | Timely 5

Summary: 针对 BrowseComp 已被顶尖模型刷到 90% 以上、难以区分长程搜索能力的问题，美团从 762 万实体、2.65 亿条边的维基知识图谱自动采样树形与图形约束，构建 544 道人工核验题目。GPT-5.5 仅得 34.74%；正确轨迹平均工具调用从 35 次增至 61 次，最佳上下文策略只提升 6.8 个百分点。

Key insight: 搜索智能体的新瓶颈已从“能否联网”转向大候选空间收敛、冷门实体验证和长轨迹状态管理。对社区搜索团队而言，可借鉴其知识图谱约束采样方法，用真实内容关系自动制造高难 query，并把工具调用数、证据链完整性和上下文恢复能力纳入离线评测，而不只看最终答案准确率。

2. Bridge Evidence: Static Retrieval Utility Does Not Predict Causal Utility in Multi-Step Agentic Search
4.30
Relevance 5 | Novelty 5 | Practical 3 | Evidence 5 | Timely 3

Summary: 论文用 ReAct 智能体重放 1000 道 HotpotQA 问题，对每篇已读文档做删除干预，以答案质量、下一跳检索质量和轮数变化定义反事实轨迹效用。23,322 个文档观测中，静态效用与因果效用几乎独立（Spearman ρ=-0.026），35.7% 文档属于静态低分却决定后续路径的“桥接证据”。

Key insight: 多步搜索中的好文档不一定直接包含答案，它可能只提供能改写下一条 query 的关键实体；高 OER 实体进入下一跳查询的概率是非区分实体的 4.02 倍。搜索系统若仍按单轮相关性训练 retriever，会系统性漏掉这类路径价值，实践上应增加轨迹级反事实标签或实体区分度特征。

4.15

Summary: NVIDIA NOOA 把智能体定义为单个 Python 类，以类型化输入输出、对象引用传递、代码即动作、可编程循环、显式状态和模型可调用 Harness API 统一执行与记忆。通用 253 行 agent 在 SWE-bench Verified 达 82.2%，超过当时 79.2% SOTA；每题约 110 万 token，对比 Harness 需 220 万 token 才达 78.2%。

8. Ground Truth First: A Longitudinal Evaluation Instrument for Agent Memory, and the Tenure Crossover in Memory-Architecture Rankings
3.80
Relevance 3 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 论文先生成带有效期、波动类别和来源通道的事实脚本，再渲染对话与邮件，从源头避免记忆基准的标签污染；语料含约 380 道题、15 类任务。五种记忆架构显示明显期限反转：三周领先的预算映射到九周召回由 96% 跌至 72%，而带来源类型的图记忆升至 90%，六个用户上反转均成立。

Key insight: 短期最优的记忆结构可能在长期部署中失效，原因是预算淘汰会删除仍有效但暂时不活跃的事实；搜索 Agent 的用户偏好、查询历史和证据缓存也有同样风险。建议把事实有效期、发送/接收来源和冲突关系作为一等字段，并分别做三周与九周回放测试，而不是只在短会话问答上选架构。

9. TASR: Training-Free Adaptive Stopping for Iterative Retrieval
3.70
Relevance 4 | Novelty 3 | Practical 5 | Evidence 3 | Timely 2

Summary: TASR 用一条可审计停止规则控制迭代检索：连续两轮答案稳定，且经等距校准的首 token logit margin 超过固定阈值 0.25 即停止，无需训练控制器。三模型×两数据集上，其宏平均 F1 为 57.40、平均 3.13 次调用，比固定三轮高 3.42 F1；同时保留固定五轮 94.8% 的效果，只用其 62.6% 调用。

Key insight: 迭代检索的预算控制可先从“答案轨迹稳定性 + 模型内部 margin”做起，不必立即训练 value head。规则原样迁移到 9 个 BM25、9 个稠密检索配置和 550B 模型均无显著退化；反而加入 cross-encoder 停止信号会损失 4–14 F1，提示检索相关性不能替代“当前证据是否足以支撑答案”的判断。
