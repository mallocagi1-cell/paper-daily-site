Where Reasoning Matters: Rethinking Latent Reasoning in Semantic ID-based Generative Recommendation

论文针对语义 ID 生成式推荐中“每个 token 使用相同推理步数”的低效做法，以位置级信息增益衡量各段 ID 对目标物品不确定性的消减程度，并提出 IBA 动态分配隐式推理预算。多组公开数据实验表明，优先计算高信息增益位置可持续提升强基线，并获得更优的准确率—算力折中。

KEY INSIGHT · 对业务意味着什么生成式推荐的推理算力不应平均铺在整段语义 ID 上：前部 token 往往决定物品大类，边际信息更高，应获得更多隐式迭代。工程上可把 IBA 作为预算控制层，在总推理步数不变时重排计算位置，先验证精度收益，再逐步压缩尾部 token 的计算。

MESH: Scaling Up Retrieval with Heterogeneous Content Unification

Pinterest

MESH 面向新鲜、长尾与高频内容并存的大规模推荐召回，以模块化特征域和门控偏差校正隔离稀疏信号与高频互动信号的梯度干扰。Pinterest Related Pins 线上实验中，新内容 repin 提升 5.5%，漏斗效率提升 55%，留存提升 0.46%，异步服务吞吐提高 2.87 倍。

INSIGHT论文说明扩大统一召回模型时，收益不会自然均匀覆盖不同内容层级；保护长尾与新内容的独立梯度通路比继续堆专用召回器更可扩展。社区 UGC 可按内容新鲜度、热度和语义域拆分表示，再用门控校正融合，以一套骨干兼顾冷启动覆盖和在线吞吐。

Jiaxing Qu, Yilin Chen, Junpeng Hou, Jinfeng Rao, Olafur Gudmundsson, Sai Xiao, Huizhong Duan

jina-embeddings-v5-text: Compact and Robust Text Embedding Models using Task-Targeted Distillation.

Jina AIElastic

该工业论文把教师蒸馏与任务定向对比学习结合，训练 677M 的 small 与 239M 的 nano 多语言文本向量模型，并提供任务 LoRA、Matryoshka 维度和量化版本。small 在 MTEB English v2 平均 71.7、MMTEB 67.7，支持 119 种以上语言与 32K 上下文，模型权重已公开。

INSIGHT小型 embedding 不必在通用蒸馏和任务对比学习之间二选一：先继承强教师的几何结构，再用检索任务损失定向校正，更适合低延迟召回。社区短文本搜索可优先试验 nano/small 的自托管版本，并通过 Matryoshka 降维与二值量化控制索引内存，再按业务语料补充 LoRA。

E-GEO: A Testbed for Generative Engine Optimization in E-Commerce

E-GEO 构建电商生成式引擎优化测试集，包含 13,747 条多约束消费者查询，每条配 10 个 Amazon 商品，并系统比较 5 种生成引擎、7 个 LLM 改写器与 15 类人工启发式。论文进一步用轻量提示元优化寻找稳定改写策略，并通过攻击与提示内防御区分内容改进和操纵。

INSIGHT当用户从关键词搜索转向对话式购物，排序目标会扩展为“能否被生成引擎正确理解和引用”。对社区内容可建立相似的生成可见性离线集，把帖子重写、证据保真和引用率联合评估；同时必须加入红队测试，避免优化退化为关键词堆砌或模型诱导。

Puneet S. Bagga, Vivek F. Farias, Tamar Korkotashvili, Tianyi Peng, Yuhang Wu

Are LLM-Based Retrievers Worth Their Cost? An Empirical Study of Efficiency, Robustness, and Reasoning Overhead.

论文在 BRIGHT 的 12 项推理密集任务上复现并扩展评估 14 个检索器，同时测量索引冷启动、延迟、吞吐、规模鲁棒性与置信度。Diver 达到 29.4 nDCG@10 和 47.3 QPS；通用大模型向量器仅约 5–6 QPS，而其原始相关性分数普遍缺乏可靠校准。

INSIGHT大参数量不是复杂查询检索的充分条件，专门化推理检索器可能同时占据效果与吞吐的 Pareto 前沿。上线前应把 nDCG、P99 延迟、QPS 和置信度校准放进同一评测表；若用分数触发重写或降级路由，需额外训练校准器，不能直接相信向量相似度。

Abdelrahman Abdallah, Jamie Holdcroft, Mohammed Ali, Adam Jatowt

Transforming LLMs into Efficient Cross-Encoders via Knowledge Distillation for RAG Reranking

论文将 LLaMA 3 8B 通过 Unsloth、LoRA 监督微调为查询—文档重排器，再做 4 bit 量化，接入 BM25 与稠密召回组成的双路 RAG。领域问答评测中，相比原 cross-encoder，答案相关性、上下文精度、答案相似度和答案正确性分别提升 14%、16%、19% 与 21%。

INSIGHT通用指令模型可经低成本参数高效微调转为领域重排器，但论文的“高效”主要来自 LoRA 与量化，仍需在真实候选规模上验证延迟。社区搜索可先用于小 Top-K 精排或难查询兜底，并保留传统轻量重排器作为主路径，以免 8B 模型吞吐拖累全量请求。

Towards Vision-Free CIR: Attribute-Augmented Scoring and LLM-Based Reranking for Zero-Shot Composed Image Retrieval

论文探索将图像先文本化后完成组合图像检索，提出属性增强混合打分补回描述中丢失的细粒度视觉属性，再用 LLM 对候选语义一致性重排。CIRR 上实现 44.04% R@1，较既有零样本方法提高 8.79 个百分点；FashionIQ 实验揭示语义推理和细粒度视觉匹配的权衡。

INSIGHT文本化多模态内容可复用成熟搜索栈，但描述生成会遗漏颜色、材质等属性，因此必须把显式属性匹配与 LLM 语义判断分层组合。对图文 UGC 搜索，可用结构化属性分数守住精确匹配，再让 LLM 只处理 Top-K 的组合意图，以控制成本和幻觉风险。

Ryotaro Shimada, Yu-Chieh Lin, Yuji Nozawa, Youyang Ng, Osamu Torii, Yusuke Matsui

Explaining When PRF Fails: Participatory Auditing for Selective Query Expansion

论文把伪相关反馈的失败视为可解释性与风险控制问题：108 名用户审计 43 条 TREC DL 2019 查询发现，仅 20.9% 查询受益，25.6% 的体验反而下降，避免伤害的价值接近利用成功扩展的两倍。随后以 LLM 重排器预测系统偏好，自动复现用户标签并提供可检查证据。

INSIGHT查询扩展不能只看平均 nDCG，长尾查询漂移会被总体收益掩盖；应先用用户审计明确“何时不扩展”，再自动化选择性策略。社区搜索可给改写模块增加 harm-aware 门控，以原查询结果为安全基线，并记录触发依据，优先减少明显退化而非追逐少数高收益样本。

SkillSelect-Serve: QoS-Aware Budgeted Skill Service Recommendation for LLM Agents

SkillSelect-Serve 将 Agent 技能从普通文档改造成含依赖、上下文成本、风险与 QoS 的结构化服务，由微型需求规划器解析任务，再以技能级边际效用和组合级校准完成预算约束打包。在 35,353 个技能、586 条任务查询上，相同预算下的组合召回率与平均效用持续优于固定 Top-K。

INSIGHTLLM 推荐或检索工具时，相关性只是约束之一；依赖可满足性、上下文占用、冗余和风险必须在组合层统一优化。其双粒度思路可迁移到生成式推荐：先估计单个候选贡献，再对列表覆盖与成本校准，避免逐项高分却整体重复、超预算。

TREC iKAT 2025: A Test Collection for the Offline and Interactive Evaluation of Conversational Search.

TREC iKAT 2025 提供面向个性化对话搜索的离线与交互式测试集合，重点覆盖多会话对话、动态演化用户模型、混合主动交互以及大规模人工和自动评估。资源同时包含人工设计用户画像、参赛系统与用户模拟器生成的对话，并公开评测结果、源代码和模型权重。

INSIGHT对话式推荐的真实难点不是单轮回答，而是跨会话维护偏好、处理偏好变化并允许系统主动澄清。社区搜索团队可用该集合补齐传统单轮 nDCG 的盲区，分别评估画像记忆、澄清策略和最终答案质量；用户模拟器适合回归测试，但仍需真实用户校验。
