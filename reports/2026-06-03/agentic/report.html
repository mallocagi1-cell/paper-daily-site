Harness-1: Reinforcement Learning for Search Agents with State-Externalizing Harnesses

针对搜索 agent 在长 transcript 上既要做语义检索决策、又要在策略里维护「看过什么、哪条证据有用、哪些约束未闭合、哪些论断已核实」这类簿记状态的问题，本文提出 Harness-1：一个 20B 检索子 agent，在一个有状态的 search harness 内用强化学习训练。harness 在环境侧维护工作记忆——候选池、按重要性打标的 curated set、压缩去重后的 observation、verification 记录，以及预算感知的上下文渲染；策略只保留语义决策（搜什么、保留哪些文档）。核心论点是把可由环境可靠维护的 recoverable bookkeeping 从策略里剥离，让 RL 专注优化语义搜索决策。

KEY INSIGHT · 对业务意味着什么把 agent 状态拆成「环境可恢复的簿记」与「策略需学习的语义决策」两层，是这篇最值得借鉴的设计：RL 不该被迫同时优化检索语义和上下文管理这种本可由代码确定性维护的部分。对社区搜索的 agentic 检索而言，候选池、去重 observation、证据链与预算感知渲染都可放到 harness 侧，既稳定训练又压缩 token 成本，策略模型规模可控（20B）。

Masking Stale Observations Helps Search Agents -- Until It Doesn't: A Regime Map and Its Mechanism

UCSDUIUC

长程搜索 agent 在多次工具调用中累积大量检索内容，上下文预算效率愈发关键。一个最小干预是随轨迹推进把 stale observation 从上下文里 mask 掉，但何时有效、为何有效并不清楚。本文在 4B 到 284B 多种 agent backbone、3 种 retriever、离线与 live-web agentic search benchmark 上做系统 sweep，发现 masking 带来的精度增益相对「无上下文管理时的模型精度」呈非对称倒 U 形：弱 retriever 下是平台、强 retriever 配中等容量模型时出现峰值、模型饱和时急剧崩塌。该模式反映 retriever recall 与模型隐式过滤能力之间的交互，而非单一因素。

INSIGHTobservation masking 不是无脑收益：它的效果取决于 retriever recall 与模型自身过滤能力的匹配关系。实践启示明确——当召回强但模型容量中等时收益最大，模型本身已能过滤噪声时 mask 反而有害。社区搜索若上线长程 agentic 检索，应按「模型容量×召回质量」分区决定是否启用上下文裁剪，而不是默认全局开启。

Haoxiang Zhang, Qixin Xu, Zhuofeng Li, Lei Zhang, Pengcheng Jiang, Yu Zhang, Julian McAuley

Critic-R: Improving Agentic Search using Instruction-tuned Retrievers with Natural Language Introspective Feedback

UMass Amherst

agentic search 系统反复与检索模型交互回答复杂 query，但为 agentic search 优化 retriever 通常需要重度协同训练或 gold 标注，限制落地。本文提出 Critic-R，在推理与训练两阶段显式闭合 reasoning agent 与 retriever 之间的反馈回路：引入 critic 模型，在 agent 消费检索证据后评估其 introspective reasoning trace，判断检索上下文是否足以支撑下一步推理。两个互补机制——Critic-R-Zero 是推理期 query refinement 回路，迭代改写 query 与检索指令；Critic-Embed 则把成功/失败的 refinement 轨迹当作训练信号来优化 retriever。

INSIGHT用 critic 评估「检索证据对下一步推理是否充分」来驱动 query 改写，并把 refinement 轨迹回收为 retriever 的训练信号，避免了对 gold 标注或重度 co-training 的依赖。对社区搜索 query 理解/改写很有借鉴：以下游推理是否被支撑为信号反向优化召回，比单纯相关性标注更贴近 end-to-end 目标，且 Critic-R-Zero 可在不重训检索器时先以推理期回路取得增益。

Md Zarif Ul Alam, Alireza Salemi, Hamed Zamani

MCP-Persona: Benchmarking LLM Agents on Real-World Personal Applications via Environment Simulation

Model Context Protocol (MCP) 已成为连接 LLM 与外部数据/工具的标准并被个人应用与开发平台快速采用，但现有 benchmark 多聚焦通用信息检索工具，无法刻画「工具操作个人账户或本地数据库」的社交个人应用场景。本文提出 MCP-Persona——首个面向真实个性化 MCP 工具的 agent 评测基准，覆盖从社交平台 Reddit、小红书 (Rednote) 到企业协作套件 Lark (飞书)、Slack 的多样应用，通过环境模拟构造任务。对多个 SOTA agent 的实验表明它们在个性化工具调用上明显吃力，暴露了这一关键能力缺口。

INSIGHT把评测从「通用搜索工具」推进到「操作个人账户/本地库的社交应用工具」，并包含小红书、飞书等中文社区/协作场景，对社区平台做 agent 化工具调用直接相关。启示是：当前 SOTA agent 在个性化工具上的失败说明，社区搜索若要接入 MCP 工具（如站内发帖、私信、本地数据查询），需专门的环境模拟评测与针对性训练，不能假设通用 agent 能直接迁移。

Wenhao Wang, Peizhi Niu, Gongyi Zou, Xiyuan Yang, Jingxing Wang

TVIR: Building Deep Research Agents Towards Text--Visual Interleaved Report Generation

Deep Research Agent 在多步信息检索、推理与长文报告生成上能力很强，但现有 benchmark 与系统多为纯文本，缺乏对「视觉元素是否事实可靠、是否与周边分析对齐」的评测。本文提出 TVIR (Text--Visual Interleaved Report Generation)：TVIR-Bench 是含 100 个专家精选多模态深度研究任务的基准，要求视觉元素服务于特定分析子目标；TVIR-Agent 是层级式多 agent 框架，负责构建大纲、检索图像、生成可溯源图表、并通过上下文感知的顺序写作组装报告，作为强 baseline。配套一个结合文本评估与视觉评估的 dual-path 评测框架，覆盖 9 个深度研究系统。

INSIGHT把 deep research 从纯文本推进到「文图交错且视觉可溯源」的报告生成，并用 dual-path（文本+视觉）评测约束图表与分析的对齐，是这篇的关键。对社区搜索的 AI 总结/聚合卡片有启示：当答案含图表/截图时，视觉元素的事实可靠性与来源可溯需单独评测，层级式多 agent（大纲→检索→图表→写作）可作为可溯源生成的工程范式。

Xinkai Ma, Zhiqi Bai, Dingling Zhang, Pei Liu, Yishuo Yuan

OpenWebRL: Demystifying Online Multi-turn Reinforcement Learning for Visual Web Agents

构建强视觉 web agent 需要长程推理、精确 grounding 与对动态真实网站的稳健交互。最强系统多为闭源，开源 agent 仍重度依赖在大量精选 web 轨迹上的监督后训练，造成可扩展性瓶颈——高质量示范昂贵、静态数据集覆盖有限。在线 RL 在文本 agent 上有前景，但用于在 live 网站上直接训练视觉 web agent 仍少有人探索。本文提出 OpenWebRL，一个用在线多轮 RL 在真实网站上训练视觉 web agent 的开放框架，覆盖完整训练流水线：可扩展的 live-browser 基础设施、监督初始化、多模态上下文管理、轨迹级成功判定等。

INSIGHT用在线多轮 RL 直接在 live 网站训练视觉 web agent，绕开对昂贵静态轨迹监督数据的依赖，并把 live-browser 基础设施、多模态上下文管理、轨迹级 reward 判定整套开源。对需要操作真实页面的 agentic 搜索/抓取场景有参考价值：与其攒大规模人工轨迹，不如投资 live 环境的 RL 基础设施，让 agent 在真实分布上自我提升。

Rui Yang, Qianhui Wu, Yuxi Chen, Hao Bai, Wenlin Yao

Policy and World Modeling Co-Training for Language Agents

RL 通过教 LLM agent「哪些动作带来高 reward」来提升能力，但几乎不监督「这些动作对环境做了什么」。world modeling (WM) 可补这一缺口，但已有方法常需独立 simulator、额外训练阶段或推理期额外计算。作者观察到 on-policy RL rollout 本身就含所需信号：每个 transition 把一个动作与其产生的 next observation 配对。据此提出 PaW，一个 Policy 与 World modeling 协同训练框架，在同一策略上加辅助 WM 监督而不改变推理范式。为使 WM 监督有效且稳定，PaW 引入三个组件：基于 action-entropy 的 WM 数据选择、噪声容忍 WM loss、reward-adaptive loss 平衡。在三个 agentic 任务 benchmark 上一致优于强 RL baseline。

INSIGHT不需要额外 simulator——直接复用 RL rollout 里「动作→下一观测」的 transition 作为 world modeling 的免费监督信号，与策略同步协同训练。这对工业 agent 训练很友好：用现成 rollout 即可加一路环境动力学监督，不改推理范式、不加部署成本。action-entropy 数据选择与噪声容忍 loss 是把 WM 信号用稳的关键工程细节。

Ning Lu, Baijiong Lin, Shengcai Liu, Jiahao Wu, Haoze Lv

Don't Ask the LLM to Track Freshness: A Deterministic Recipe for Memory Conflict Resolution

LLM 记忆系统越来越多维护随时间演化的事实，一个反复出现的失败是 conflict resolution：当一个事实有多个互相矛盾的取值时该返回哪个？MemoryAgentBench (MAB) 的 FactConsolidation 任务把它显式化：事实带编号、反事实序号更高、并告诉 agent 序号越大越新。然而所有已发表系统都表现不佳——HippoRAG-v2 在单跳 (FC-SH) 仅 54%、BM25 48%、Mem0 18%、时序 KG Zep/Graphiti 仅 7%；多跳几乎未解 (22 个系统中最高仅 7%)。作者认为瓶颈在 assembly 步：baseline 把冲突消解交给 LLM 中介的检索或生成，而非版本感知的聚合。在同 backbone、检索、chunking、TOP_K 的对照下，用 candidate-extraction 加 Python max 替换 LLM 判断的答案管线即大幅提升。

INSIGHT记忆里的「新鲜度/版本冲突」不该交给 LLM 去判断——把冲突消解换成确定性的「候选抽取 + Python max（按版本序号取最新）」就能从 54% 等水平显著拉升。对带时效信息的社区搜索记忆/会话很实用：版本号、时间戳这类可结构化的元数据应走确定性聚合，把 LLM 留给真正需要语义判断的环节，既准又省 token。

Vikas Reddy, Sumanth Challaram

MemGraphRAG: Memory-based Multi-Agent System for Graph Retrieval-Augmented Generation

XXiamen University

RAG 通过引入外部知识缓解 LLM 幻觉，但传统 RAG 在大规模非结构化语料、信息高度碎片化时表现不佳。GraphRAG 引入知识图谱捕捉结构关系以支撑复杂推理，但现有方法依赖孤立的 fragment 级抽取做图构建，缺乏对整个语料的全局视角，常导致主题不一致、逻辑冲突、结构碎片化的图，反过来损害检索性能。本文提出 MemGraphRAG，引入一个基于记忆的多 agent 系统来保证高质量图构建，让多个 agent 在带记忆的协作中维持全局一致性，从而改善 GraphRAG 的检索与下游推理质量。

INSIGHTGraphRAG 的质量瓶颈在「图构建」而非检索本身——fragment 级孤立抽取会产生主题不一致、逻辑冲突的图。用带记忆的多 agent 协作维持全局视角来构图，是值得借鉴的方向。对社区 UGC 这类碎片化、跨帖关联强的语料，知识图谱式 RAG 的收益高度依赖构图一致性，把记忆与多 agent 协作放在构图阶段比只优化检索更关键。

Chuanjie Wu, Zhishang Xiang, Yunbo Tang, Zerui Chen, Qinggang Zhang, Jinsong Su
