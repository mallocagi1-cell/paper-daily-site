FEDIN: Frequency-Enhanced Deep Interest Network for Click-Through Rate Prediction

针对序列推荐中用户行为时域噪声大、难以捕捉周期性兴趣的问题，提出 FEDIN 在频域引入 target-aware 的谱滤波分支增强 DIN。核心观察是：当用 target item 条件化用户注意力分数时，正样本对应的频谱熵显著低于负样本，说明真实兴趣呈低熵周期模式而噪声呈高熵分布。FEDIN 用频域分支隔离与目标商品共振的周期信号，再与时域 DIN 融合用于 CTR 预估。

1. 问题与动机

FEDIN关注工业CTR预估里一个很具体的失效模式：用户历史行为同时包含长期周期性习惯和短期随机噪声，而常见的时间域序列模型容易把一次误点、探索性点击或缺失行为当成连续兴趣。论文的动机不是简单地“把FFT接到推荐模型上”，而是先观察目标商品条件下的注意力分布：当历史行为确实与候选商品相关时，注意力在频域往往呈现集中、低谱熵的峰；当行为是无关噪声时，频谱更分散、熵更高。也就是说，是否存在周期信号不能脱离当前候选商品判断，目标商品本身可以充当频率选择器。

这一区分对CTR尤其重要。DIN、DIEN等目标注意力模型能回答“哪些历史行为与目标相关”，却仍主要在时间域处理逐点序列；DIFF等频域方法可以提取稳定模式，却通常先对用户序列独立滤波，忽略了候选商品改变兴趣解释方式的事实。论文把问题定位为目标无关的频域滤波不足，而不是单纯的模型容量不足。对社区UGC或电商推荐而言，同一用户的长期“数码产品”兴趣和当前“露营装备”兴趣，可能在不同候选下激活不同历史片段；如果预估模型只看最近若干次点击，长期周期和抗噪能力都会受损。

2. 方法详解

FEDIN的输入是用户行为序列X和目标物品向量X_tar，整体输出用户兴趣表示U。模型采用双分支去噪结构：时间域分支保留局部行为演化，频域分支提取全局周期共振，最后由User Interest Aggregator融合。两路可以并行执行，论文强调这一点是为了让频域增强不必把线上推理变成串行的重型模块。

第一步是Reversible Instance Normalization（RevIN），用于缓解用户行为分布的非平稳性和不同序列之间的分布漂移。时间域分支先使用目标注意力做粗过滤，但不同于传统注意力池化，它保留加权后的完整序列：X_attn = Softmax(X_tar X^T / sqrt(d))^T ⊙ X。这样模型不仅知道哪些行为与目标相关，还保留这些行为的时间位置。随后将序列切成不重叠patch，不足一个patch的部分补零，再线性投影并送入Transformer encoder，得到X_time。patching同时降低长序列注意力开销，也把连续的局部行为片段作为更稳定的建模单元。

频域分支的关键是目标感知。模型先计算历史行为对目标商品的相关分数X_score，再对该分数做FFT得到目标条件频谱。随后对频谱幅值做softmax，并与行为序列的FFT逐元素广播相乘：这一步不是对原始行为盲目做固定滤波，而是先用候选商品决定哪些频率更值得保留。接着使用复值MLP学习频谱到干净兴趣频谱的非线性映射，再做IFFT还原为时域表示X_freq。使用复值MLP是为了保留复频谱中的相位-幅值耦合，不把周期位置关系简单丢掉。

作者进一步加入Adaptive Resonance Scaling。它根据目标条件频谱的幅值生成门控系数，用sigmoid动态缩放X_freq：谱结构清晰、低熵时提高频域分支权重；周期性弱或噪声占主导时降低频域贡献，让模型回退到时间域。两分支相加得到X_mix，再用Top-k Target Attention聚合最终兴趣U。Top-k做法把非前k个注意力分数掩为负无穷后再softmax，保留候选相关的少量兴趣，避免弱相关信号稀释预测。

训练设置是可复现的：论文在Tmall、Taobao、Alipay三个公开数据集上按全局时间切分训练、验证、测试，用AUC和GAUC评价；模型以FuxiCTR实现，优化器为Adam，学习率5×10^-4，batch size 2048，embedding维度32，最大行为序列长度100。噪声实验额外以0.0、0.2、0.4、0.6、0.8五个污染比例，分别模拟随机删除历史行为和用随机物品替换真实行为。

3. 核心技术贡献

第一，论文给出目标条件谱熵这一可解释观察：正样本注意力更集中、负样本更像高熵白噪声。它把“频域有用”从经验技巧变成了与候选物品相关的判别信号，改进了只对用户序列独立滤波的做法。

第二，FEDIN把时间域和频域设计为互补而非替代。时间域保留即时兴趣和局部顺序，频域负责稳定周期与抗噪；消融显示去掉时间域后Tmall GAUC从0.9658降到0.9482，去掉频域后降到0.9605，说明两类信号都不可缺。

第三，目标感知频域注意力是方法的核心增量。把它替换成静态可学习滤波后，Tmall AUC从0.9666降至0.9626，Alipay AUC从0.9320降至0.9293，Taobao AUC从0.9729降至0.9724，说明候选商品确实参与了频率选择，而不是装饰性条件。

第四，自适应频域缩放解决了“所有用户都存在周期兴趣”的错误假设。去掉缩放后，Taobao GAUC从0.9740降至0.9662、AUC从0.9729降至0.9655；这说明频域分支应该按样本的谱清晰度启用，而不是固定加权。

数据集差异也很有信息。DIN在Tmall和Taobao表现很强，但在Alipay相对弱；论文将其归因于数据稀疏性和行为复杂度差异。FEDIN三个场景都稳定领先，说明频域分支并不只是在某一个数据集上过拟合周期，而是能补偿时间域兴趣在稀疏、噪声环境中的不稳定性。

消融实验揭示了贡献排序。去掉时间域分支造成最大幅度的结构性损失，表明频域不能独立承担即时兴趣预测；去掉频域分支也在三个数据集上普遍下降，证明全局周期模式提供了增量信息。将目标感知滤波替换为静态滤波后，三个数据集都下降，验证“目标商品是频率选择器”的核心假设。去掉自适应缩放后Taobao下降尤其明显，说明不是每个用户-商品对都存在强周期共振。

噪声实验进一步支持这一解释。随机删除或替换行为比例从0.0增加到0.8时，频域分支的相对性能衰减比时间域分支更缓；随机噪声在频域表现为分散的高熵波动，而真实兴趣保留集中能量。复杂度上，FFT分支主导成本为O(L log L)，而标准自注意力为O(L^2)，长序列时有潜在优势。不过论文的复杂度优势是模块级分析，真正线上收益仍取决于FFT、复值MLP、Top-k筛选和特征搬运的实现常数。

5. 局限与未来方向

论文明确的局限信息较少，结论部分主要强调三数据集效果和频域、时间域联合建模，并没有给出线上A/B、真实QPS、显存占用或端到端延迟。实验使用公开电商日志，行为序列最大长度固定为100，尚不能直接证明在更长的社区UGC历史、强实时流式行为和冷启动用户上同样成立。复值频域过滤器与patch超参还需要在不同业务分布上重新调节；论文的噪声实验使用合成删除/替换，和真实曝光偏差、机器人流量、埋点缺失并不完全等价。

后续更值得做的是把谱熵作为可监控信号接入线上诊断：区分哪些用户-候选对真正受周期兴趣驱动，哪些只需要短期行为。还可以探索在线增量FFT、低秩复值MLP、动态序列长度和蒸馏到轻量CTR塔，验证频域收益是否能在延迟预算内保留。

6. 工业实践意义

对于社区短文本搜索与推荐，FEDIN最可借鉴的不是直接照搬FFT，而是“候选条件下的兴趣去噪”。可以在精排阶段增加一个轻量频域支路：输入用户最近一段点击、停留、收藏或负反馈序列，用当前帖子/商品向量生成目标注意力频谱；频谱清晰时利用周期兴趣，频谱高熵时主要依赖时间域即时信号。这样能够把长期主题偏好和当前意图分开处理，减少偶发点击对CTR的污染。

落地建议分三步。第一，在现有DIN/DIEN或Transformer基线旁加入离线频域特征，不改变主排序塔，先检查GAUC、nDCG和分用户活跃度分桶的收益。第二，复现论文的两个污染实验，但把随机噪声替换成业务中的真实缺失、误触和曝光截断，确认收益来自抗噪而不是数据集偶然性。第三，针对长序列压测FFT和复值MLP的CPU/GPU成本，并以候选相关Top-k聚合替代全量注意力。

论文没有线上A/B证据，因此不应直接承诺CTR提升。对于生产系统，建议保留时间域兜底、对频域门控做灰度开关，并监控不同内容垂类的谱熵、延迟、内存和校准误差；如果频域支路只改善高活跃用户，应考虑分层启用，避免把复杂度扩散到冷启动流量。

Post-hoc Provider Fairness Adaptation via Hierarchical Exposure Alignment

HHFUT📖 有深读 · 9 分钟

针对推荐系统作者/供给侧曝光公平问题，提出 PFA：在冻结的主推荐模型外挂一个轻量「公平 adapter」，用 user-item embedding 学习个性化的加性分数偏置注入到原始排序分中，无需重训主模型即可适配多种公平目标。训练目标是最小化实际曝光分布与目标公平曝光分布的 KL 散度，并通过层级化曝光对齐避免打散头部高质内容。

INSIGHTPFA 的工业价值在于解耦了「模型主链路」和「公平约束」。社区类产品的作者生态治理常需要快速调整曝光策略（扶持新手、抑制头部、品类均衡），但每次重训精排成本高昂。PFA 模式只需上线一个百万参数级 adapter，配合不同的目标曝光分布即可热切换；这与业界常用的后置 reranker 相比，由于 adapter 学的是个性化偏置而非全局阈值，对个性化 CTR 损失更小。

1. 问题与动机

推荐系统长期被「赢者通吃」(winner-takes-all) 动力学困扰：当模型只优化点击/转化等用户侧准确率指标时，曝光会快速集中到头部供给方（作者/品牌/创作者），导致长尾内容被压制、生态多样性下滑、长期用户留存反而受损。Provider exposure fairness（供给侧曝光公平）因此是社区/电商/UGC 类平台的硬约束。论文系统梳理了既有方案的两条死路：(a) in-processing 把公平约束写进训练 loss——能拿到效果但任何公平目标的调整都意味着重训整个推荐主模型，工业 7 天一次的迭代节奏受不了；(b) post-processing 在打分后用固定规则 rerank（FairRec、CPFair、TaxRank、ElasticRank 等）——部署便利但策略刚性，对"扶持新人 30%、品类均衡 70%"这种细粒度的 stakeholder 协商无能为力。

作者把核心问题精炼成一句话：能否在不重训主模型的前提下，给冻结推荐器外挂一个轻量、可学习、可适配的公平模块？这个 framing 直接对应工业现实——大多数公司已经有数 T 级的 sparse 召回/精排模型，每次要满足新公平诉求都重训既不现实也违反成本约束。论文进一步指出，传统全局 KL 公平 loss 隐式假设所有 provider 等权重，忽视了真实生态里 provider 群体规模天然不均衡（头部 20%占据大多数曝光、中部 60%、尾部 20%）。这一观察直接驱动了 Hierarchical Exposure Fairness Alignment (HEFA) 的设计。

2. 方法详解

PFA 的核心结构：在冻结的推荐主链路（base scorer Ŷ）后挂一个"公平 adapter"，输出个性化加性偏置 Δ，最终重排分数为 Ỹ = Ŷ + Δ。Adapter 输入为 user embedding 与 item embedding 拼接（broadcast 到形状 B×N×2d），结构为三层 MLP（2d→h→h→1，前两层 ReLU，输出 1 维 Δ）。主模型完全冻结，只训 adapter 参数——这意味着在 Beauty 这类规模的数据上仅有数十万到百万级可训练参数。

HEFA 的关键洞察是把全局 KL 公平 loss 显式分解成两层：inter-group（组间）和 intra-group（组内）。Provider 按训练集曝光量排序划分为 C 组（论文常用 C=3：head 20% / mid 60% / tail 20%）。Inter-group component 衡量组级曝光分布与目标分布的 KL 散度；intra-group 在每个组内继续衡量 provider 级的均匀性；论文（Theorem 4.1）证明全局 KL 可解析地分解为 inter+intra+calibration 三项。这种分层让"扶持中部、抑制头部、保护尾部"成为独立可调的旋钮。

可微分 NDCG loss 用 differentiable sorting network 把硬排序位置替换为软概率，position bias 函数 1/log₂(1+rank) 加权高位次，使得 NDCG 可端到端梯度训练。Provider 期望曝光通过 soft permutation matrix 计算：把 item 在某 rank 位置的概率乘以 position weight 求和，再按 provider 聚合。

最终训练目标：L_total = L_diffNDCG · λ_acc + λ_inter · KL(inter) + λ_intra · Σ_c (group_weight_c · KL(intra-c))，多个 λ 提供细粒度调控。HEFA 的部分梯度只回传到 adapter 参数，主模型完全不动，这是 PFA 与 in-processing 公平方法本质区别。

3. 核心技术贡献

(1) 把"frozen backbone + lightweight fairness adapter"的范式工程化，将公平约束与主模型训练解耦，是当前生成式/超大规模推荐时代下少有的可上线方案。(2) HEFA 把全局 KL 分解为 inter/intra/calibration 三项并给出形式化证明 (Theorem 4.1)，相比一刀切的 KL 提供了细粒度策略表达能力——这对运营/产品的多 stakeholder 谈判非常有价值。(3) 把 differentiable sorting network 与 NDCG/expected exposure 同时引入端到端训练，证明可在保持 frozen backbone 的前提下做联合 fairness+accuracy 优化。(4) 实验上 PFA 在 NDCG 和 Gini 同时占优——比 in-processing 的最佳 baseline (Ada2Fair) NDCG 高 ~8% 同时 Gini 降低 14%。

4. 实验结果分析

数据集：Amazon Beauty (11.7K user / 6.5K item / 196 provider)、Movies&TV (10.1K/3.8K/77)、RateBeer (12.5K/49K/1645 brewer / 2.7M interaction)。Base scorer 用 BPRMF、LightGCN、SGL 三种 frozen 模型；与 SDRO/Multi-FR/Ada2Fair/FairDual (in-proc) 和 FairRec/CPFair/TaxRank/ElasticRank (post-proc) 对比；指标双侧——utility (NDCG@20/HR@20/MRR) 和 fairness (Gini↓/Entropy↑/CV↓)。

Beauty 上 PFA 拿到 NDCG 0.0943 (base 0.1000，仅掉 5.7%) + Gini 0.6282 (base 0.7260，降 13.5%) + Entropy 6.3544 (base 6.0759)，相比 Ada2Fair NDCG 0.0872 在公平性接近时多出 8.1% NDCG。Movies&TV 上 NDCG 0.1066 + Gini 0.6403。RateBeer (大数据集) NDCG 0.4284 (base 0.4952) + Gini 0.8467（最低）+ Entropy 7.7781。Cross-model 实验显示 PFA 在 LightGCN/SGL backbone 上同样有效（LightGCN+PFA NDCG 0.1204 vs base 0.1254；SGL+PFA NDCG 0.1507 vs base 0.1639），证明 model-agnostic 通用性。

消融：(a) 只加 L_diffNDCG 几乎不动 Gini，证明纯 NDCG loss 不带公平意识；(b) 只加 L_HEFA Gini 大幅改善 (0.62-0.84) 但 NDCG 中等下滑；(c) PFA 同时使用两 loss 取得最佳 trade-off——L_diffNDCG 起到"恢复 accuracy 的正则化"作用。HEFA vs 全局 KL 对比：HEFA 在同等公平度下 accuracy 显著更高，验证分层分解的价值。

5. 局限与未来方向

作者隐式承认三个局限：(1) Provider 分组是静态的（按历史曝光），生态演化时分组不更新会偏；(2) 框架假设 frozen embedding，无法处理新 provider 的冷启动；(3) λ_acc / λ_inter / λ_intra 三超参敏感，论文给出的搜索范围跨多个数量级，工业落地需投入调优成本。论文明确给出的 future work：动态 provider grouping、冷启 provider 处理。

6. 工业实践意义

PFA 几乎是为社区/UGC 平台量身打造的供给侧公平治理方案。第一，部署成本极低——adapter 是百万参数级 MLP，可在一张消费级 GPU 上分钟级训练，相比重训精排省下数千 GPU 小时。第二，热切换能力——同一冻结主模型可挂载多个不同 λ 配置的 adapter（"扶新手 adapter"、"品类均衡 adapter"、"双十一倾斜 adapter"），运营按需切换，对 A/B 测试和动态运营场景友好。第三，HEFA 的 inter/intra 分解直接对应业务诉求："抑制头部 30%曝光、中部 60% 内部均衡、尾部保底曝光"等运营策略可以分别由 λ_inter、λ_intra、组目标向量精确表达。第四，fairness 与 accuracy 联合优化的 differentiable NDCG 训练范式可以推广到其他多目标场景（如多样性、多目标组合优化），不仅限于公平。落地建议：先在已有冻结精排模型上做离线复现（数据集准备 1-2 周、训练调参 1-2 周），用 Gini/Entropy 监控生态指标，再小流量灰度对比 NDCG/CTR/作者留存，预估总周期 2-3 个月可完成 PoC。需要警惕的是 RateBeer 上 NDCG 掉了 13.5%，社区类高个性化场景上线前必须做用户侧体验保护。
