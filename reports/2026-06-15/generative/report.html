The Injection Paradox: Brand-Level Suppression in Safety-Trained LLM Recommendations via RAG Context Injection

论文揭示了安全对齐 LLM 在 RAG 推荐场景下一个可复现的失效模式——“注入悖论”：检索文档中嵌入的 prompt injection 不仅没抬高目标品牌，反而把它压制到低于无注入基线。在 Claude Opus 4.6 上，含注入的语料让目标品牌从 54% 的基线推荐率跌到 50 次试验中 0 次进入 top-2，且这种压制会从被注入文档扩散到同品牌的其他未修改文档（4 篇品牌文档中仅 1 篇含注入）。在三个品牌和反事实实验中均可复现；而 GPT 系列方向相反（注入反而提升推荐），显示模型家族行为差异。

KEY INSIGHT · 对业务意味着什么对在搜索/推荐中接入 RAG+LLM 的团队，这是一个直接的信任边界警示：安全训练会让“被注入”的文档及其同源内容被整体降权，并可被对手反向利用（在竞品文档里植入注入以打压竞品）。落地启示是检索上下文不能默认可信，应对召回文档做注入检测与来源隔离，并在评测中纳入“注入是否引发品牌级连带压制”这一指标；同时不同基座模型（Claude vs GPT）对注入的反应方向相反，选型和红队测试需分别验证。

From Prompt to Purchase: How AI Brand Recommendations Move Consumers on the Open Web

论文用因果方法量化对话式助手的品牌推荐对开放网络用户行为的真实影响。在把 opt-in 点击流与同一批用户的 ChatGPT/Claude/Gemini 对话拼接的面板上，当助手向此前无相关行为的用户推荐某品牌后，该用户的同名 Google 搜索上升 +4.3pp [3.1,5.5]、访问品牌官网 +2.4pp、访问零售页 +1.0pp。作者用 pre-trend 事件研究、立场分类器、非老客户条件化和同类目 within-response 对照剔除混淆，区分出“顺带提及”（仅 +1.8/+1.1/+0.3）与真正推荐的差异，并发现转化路径主要经由搜索中介。

INSIGHT该研究指出基于 referrer/last-click 的传统归因会系统性漏掉 LLM 助手制造的“上游曝光”——用户被推荐后多经由搜索再转化，路径被归因到别处。对搜推与增长团队的启示：要建立面向生成式助手曝光的新归因口径，并把“是否被生成式助手提及”作为流量与转化分析的独立变量；方法上，其 pre-trend 对照 + 同类目 within-response 对照的识别框架，可迁移到评估推荐/搜索干预的真实增量。

MetaPlate: Counterfactual-Guided RAG-LLM Tool for Personalized Food Recommendation and Hyperglycemia Prevention

MetaPlate 是一个反事实解释（CF）引导的上下文感知决策支持框架，用 LLM+RAG 生成个性化餐食推荐以抑制餐后血糖波动。系统融合 25 名受试者的 CGM 血糖读数、可穿戴生理信号和用户餐食输入来建模餐前情境：机器学习模型预测血糖响应，CF 优化模块调整宏量营养素配比以把血糖维持在目标区间（≤140 mg/dL），再由 RAG 层在 USDA 食物库上做约束检索生成可读建议。注册营养师的专家在环评估显示，经 prompt 精修后餐食真实性、份量合理性和推荐可采纳性均提升，从“临床不可行”转为“可操作”。

INSIGHT该工作示范了“预测模型给目标、反事实优化给方向、LLM+RAG 在受约束知识库上生成可读结果”的三段式范式，对需要把黑盒打分转成用户可执行建议的生成式推荐有借鉴意义。关键经验是：在 LLM 生成层施加领域知识与结构化约束（这里是 USDA 库 + 营养约束）能显著降低不可行输出；专家在环 + prompt 迭代是把生成结果拉回可用区间的有效手段，对任何“约束式生成推荐/可解释推荐”场景都适用。
