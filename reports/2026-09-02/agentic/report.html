Hi-Q: Hierarchical Evidence-guided Query Refinement for Multi-Hop Question Answering

论文把多跳问答中的关键瓶颈定义为“可检索粒度发现”，由证据判定器决定当前查询是否已获支持，未解决节点再通过保持依赖关系的二叉算子细分。Hi-Q 在三个全语料多跳基准平均达到 52.3 EM、64.0 F1，较 IRCoT 分别提升 15.1 和 18.2 分。

ASTRA - Agentic System for Ticket Resolution and Analysis

ASTRA 以中央编排器协调历史工单、海量日志和领域知识三个专职 Agent，再用 Judge–Orchestrator 循环把低分项转成定向补检索。系统在 987 个真实电信故障工单上获得 4.13/5 平均质量分，59.9% 的报告定位到组件族或更细粒度，虚构技术细节低于错误案例的 3%。

INSIGHT其可迁移价值在于把生成前的多源检索与生成后的证据审计统一成“主张—原文证据—支持等级”结构，且禁止跨来源错误归因。社区搜索中的复杂问答可复用这一模式：按来源拆 Agent、用裁判定位证据缺口、限制迭代轮数，比单体长提示更容易追踪召回失败。

Shashidhar Reddy Javaji, Mohamed Trabelsi, Jin Cao, Huseyin Uzunalioglu

CAST: Critique-Aware Supervision for Training Reliable Long-Horizon Tool-Calling Agents

CAST 将稀疏任务结果转化为动作级批判监督：分析长轨迹，在部分可观测条件下生成动作有效性的结构化理由，再用批判模型构造策略训练数据。微调 Qwen3 系列后，Retail 任务的 pass^4 超过 GPT-OSS-120B 逾 10%，并在域外 Telehealth 场景再提升 9%。

INSIGHT长链 Agent 的可靠性不能只看单次最终成功率，应对每个高风险工具动作训练可解释的前置验证器，并用 pass^k 衡量重复运行稳定性。搜索 Agent 可在执行改写、过滤或外部写操作前先生成政策依据与反例，让错误在不可逆动作发生前被截获。

INSIGHT开放式任务的奖励不宜压成单一总分；应把方法创新、实验设计和证据要求拆成可验证准则，再用于生成指导与 RL 奖励。对深度搜索报告，可从高质量历史报告自动抽取覆盖度、来源质量、引用完整性等 rubric，降低模型靠复述任务描述“投机得分”的空间。

You Know What I Mean: A Benchmark for Agentic Conversational Reference Grounding

论文定义会话指代落地 CoRG：Agent 需结合对话中的词汇、语义和时间线索，通过工具在外部工作区定位唯一对象。RepoRef 收录 92 个仓库的 400 段开发者对话，关联 issue、PR 与 commit；最佳 Agent 成功率仅 67.0%，仍有三分之一指代无法解析。

INSIGHT真实搜索意图经常以“昨天讨论的那个修复”这类省略表达出现，单轮向量召回无法可靠解决。产品可把候选发现、元数据检查、正文核验和排除近似项设计为显式多步策略，并保留时间与会话实体状态；67% 的上限也说明该能力应配置澄清或人工确认兜底。

InsightToast: Proactive Information Retrieval & Glanceable Visualization in the Side Channel of Data-Rich Meetings

InsightToast 实时监听会议话语，识别正在出现的信息需求，再由多 Agent RAG 主动检索异构内外部来源，将可溯源结果压缩为短文本与可扫读交互图表，以临时侧边提示呈现。作者用立法文档知识库演示，并开展 N=16 对照研究，考察参与者在维持自然对话时完成知情决策的表现。

INSIGHT搜索入口可以从显式 query 扩展为对话流中的潜在信息缺口，但主动触发必须控制打扰成本。可借鉴“识别需求—检索—压缩—短暂侧显”的链路，将出处和图表随结果展示；同时应为触发置信度、消失时机和用户忽略信号建立在线反馈。

LLMs Interpret, Embeddings Organize, Graphs Emerge: Agent-Driven Compilation of Scientific Knowledge

ASKS 让 LLM 为每个来源生成可读 Wiki 和机器语义，经确定性检查形成文档级 GraphDelta，再用 embedding 几何与显式图规则并入持久知识状态。作者按时间顺序编译同一研究计划的 56 篇论文，利用分支存活、跨论文支持、谱系、覆盖与 churn 构建可追溯研究画像。

INSIGHT持续型研究 Agent 不应每次从零生成摘要，而应把每次摄取视为可检查的状态迁移，并保存来源到节点与关系的谱系。用于搜索知识库时，可先在单文档范围生成增量图，再经规则合并，降低 LLM 直接改全局图造成的实体漂移和错误关系扩散。

Building an Adaptive Agentic Cybersecurity System with NVIDIA Nemotron

NVIDIA

NVIDIA 的工程实践围绕 Nemotron 构建自适应安全 Agent，将长周期目标拆成可协调的安全运营任务，并让专门组件持续感知、分析和响应威胁。文章于 2026-09-01 发布，重点不是离线榜单，而是展示模型、Agent 编排与安全工具如何组成可落地的闭环系统。

INSIGHT工业 Agent 的核心不是单次生成质量，而是把感知、决策、工具执行和反馈接成受控循环。迁移到搜索场景，应把检索、证据核验与动作权限分层，并为长任务设置状态、超时和审计记录；安全运营的最小权限原则同样适用于会访问内部数据或执行外部操作的搜索 Agent。
