1. SetMIR: Multi-Interest Retrieval as Set Prediction
5.00
Relevance 5 | Novelty 5 | Practical 5 | Evidence 5 | Timely 5

Summary: 工业推荐中的单一用户向量难以覆盖多兴趣，而固定多路召回又会产生兴趣坍缩和无效 ANN 查询。SetMIR 用 Transformer 与 K 个可学习查询把兴趣建模为集合，以匈牙利匹配保证一对一分工，并用 presence 分数和查询级 NMS 动态发起召回；在 Snap DPA 中减少 33% ANN 查询，整体 CVR 提升 3.1%。

Key insight: 把多兴趣召回改写成“带存在概率的集合预测”，同时解决表征冗余和服务预算浪费，适合长行为序列与兴趣数量变化大的用户。实践上可先复用现有向量索引，只替换用户塔和 dispatch 策略；同索引同配额下相对 I2I 源 CTR 提升 44%、CVR 提升 51%，说明动态兴趣路由值得优先验证。

独立页面阅读 ↗

1. 问题与动机

工业推荐的召回层通常要从数亿乃至数十亿商品中，在一次请求内取回几千个候选。经典双塔只输出一个用户向量，当用户最近同时浏览街头服饰、婴儿用品和护肤品时，向量平均会偏向主导兴趣，短期或窄兴趣容易消失。多兴趣模型虽输出 K 个向量，却有两个生产问题：其一，MIND、ComiRec 一类 argmax 目标分配允许多个正样本同时选择同一个兴趣向量，未被选中的 query 没有梯度，最终出现 interest collapse；其二，线上固定发起 K 次 ANN 查询，不区分用户实际有几个有效兴趣，重复 query 会瓜分固定候选预算并增加调用成本。

SetMIR 的出发点是把多兴趣召回看成“可变大小集合预测”，而不是 K 个彼此独立的向量预测。这个转换借鉴 DETR 的 learnable query 与匈牙利匹配，但预测对象从边界框变成冻结商品向量空间里的兴趣方向。论文强调，未匹配 query 并不代表用户永远没有该兴趣，只表示未来监督窗口内没有更多高意向目标；presence 头因此是请求级调度信号，而不是永久用户标签。

2. 方法详解

输入是用户按时间排序的行为历史，最近三天的 purchase、add-to-cart、swipe-up 构成目标集合，目标按商品去重、按意向强度保留，最多 15 个；窗口之前最近 40 个事件作为模型输入。每个历史商品先由冻结的内容模型根据标题、品牌、类目、图片生成 128 维归一化向量，再叠加位置向量和事件类型向量。事件类型前有可学习标量 α，且 α 从 0 初始化，使训练从稳定的纯内容空间逐步吸收行为类型差异。

两层、8 头 Transformer encoder 编码历史；6 层 decoder 持有 K=10 个全局可学习 query，每层先让 query 自注意力交互，再 cross-attend 用户历史。每个 decoder 输出经两个头得到：L2 归一化兴趣向量 e_k，以及 sigmoid presence 概率 p_k。query 间自注意力让它们在读取历史前协调分工，避免各自追逐同一主兴趣。

训练的关键是小规模匈牙利匹配。对每个 query—目标对，代价为负的向量内积加负的 presence 对数概率：嵌入项权重 1，分类项权重 0.5；分类项在前 10% 步数线性 warm-up，避免早期错误 presence 干扰几何分配。K=10 时只是 K×W 的小矩阵，求解成本可忽略。匹配后的 query 用跨 8 卡 all-gather 的目标向量做 InfoNCE，温度 0.05；所有 query 再用匹配/未匹配标签训练二元 presence loss。活跃 query 之间另加 margin=0.3 的余弦排斥损失，只惩罚相似度超过阈值的 pair。总损失权重为 retrieval 1.0、presence 0.5、diversity 0.1。

模型约 300 万可训练参数，AdamW 峰值学习率 5e-4、4000 步 warm-up、weight decay 0.01、余弦衰减、BF16；使用 8 张 A100 40GB，每卡 batch 1536。论文没有披露总训练步数，而是让每种模型训练到各自收敛点。

推理先保留 p_k>0.3 的 query；若全部未通过则保留最大 p_k。随后按 presence 降序做 query 级 NMS，余弦相似度超过 0.9 的低优先级 query 被删除。剩余 query 各取 ceil(N/有效 query 数) 个 ANN 结果，重复商品用各兴趣内积的最大值合并。该设计不改商品单向量索引，只动态减少用户侧 ANN 请求。

3. 核心技术贡献

第一，匈牙利一对一分配从目标函数层面消除“多个目标挤到同一 query”的结构性原因。与靠辅助正则缓解坍缩的方法不同，每个匹配 query 都获得检索梯度，每个未匹配 query 都获得明确的 absence 监督。消融中改回 argmax 后，平均有效 query 从 6.70 降到 2.16，R@10 只剩完整模型的 63.5%，说明匹配机制是最大贡献项。

第二，presence 既参与匹配又驱动线上 dispatch，把表征学习和系统预算统一。去掉 presence loss 后平均 query 反而升至 8.23，但 R@10 降至 91.4%、HR@100 降至 88.4%，说明“多发 ANN”并不能替代 query 质量判断。

第三，训练期多样性约束和推理期 NMS 分工明确：前者塑造兴趣几何，后者删除请求级重复。去掉 diversity loss 后 R@1 仅为完整模型的 88.5%，表明兴趣去重不仅节省调用，还改善头部命中。

5. 局限与未来方向

论文没有单列 limitations。正文明确的边界包括：所有离线和线上证据来自 Snap DPA，绝对指标因公司披露政策被隐藏；item encoder 已冻结，因此实验没有回答联合优化商品塔是否继续增益；未匹配 query 只表示三天目标窗口内未观察到兴趣，presence 可能把低频或延迟转化兴趣误判为不存在；历史仅保留 40 个事件，也未研究超长序列。作者的 K 扫描表明 10 之后收益饱和，但不同业务的兴趣数量和 ANN 成本曲线未必一致。论文也未披露端到端训练时长、线上 latency 分位数和 presence 阈值漂移，这些是复现与长期运维需要补齐的指标。

6. 工业实践意义

最现实的落地路径是保持现有商品 embedding 与 ANN 索引不动，只替换用户兴趣抽取和 query dispatch。先离线记录每请求有效 query 数、query 间余弦分布、按兴趣分桶的召回覆盖，再影子运行 presence+NMS；确认固定总候选预算下重复率下降后，才接入主召回。阈值应按流量、用户活跃度和候选预算分层校准，并保留“至少一个 query”兜底。

对社区 UGC，可把高意向目标换成收藏、长停留、关注或高质量评论，把帖子文本/图片的冻结向量当 item space。匈牙利匹配尤其适合同时有长期主题和突发兴趣的用户。不过，应避免把点击全部视为同质量目标，可借论文的事件强度优先级和 α 门控逐步引入行为。生产监控除 CTR/CVR 外，还应关注 ANN 调用数、兴趣覆盖、长尾召回、重复候选率、冷启动用户 presence 分布，以及模型更新后 query 语义是否发生置换。

2. CAMIE: Co-Engagement-Aware Multimodal Item Embeddings for Snap Dynamic Product Ads Retrieval
4.75
Relevance 5 | Novelty 4 | Practical 5 | Evidence 5 | Timely 5

Summary: CAMIE 面向 Snap 动态商品广告的 I2I 召回，把图像与商品元数据送入同一 LLM/MLLM 原生多模态接口，再用用户旅程挖掘的共参与商品对和对称式 in-batch InfoNCE 对齐转化行为。线上替换两个内容编码器后，相对多模态对照 CTR +0.390%、CVR +10.832%，整体 DPA 流量 CTR +0.211%、CVR +1.911%。

Key insight: 关键不是继续堆独立视觉/文本塔，而是让统一内容空间接受真实共参与信号监督，使相似性直接靠近转化目标。该方案可作为现有 I2I 向量源的低风险替换：保持 ANN 基础设施不变，以统一 checkpoint 支持多模态和纯文本召回，并通过离线 Recall@10 与线上 CTR/CVR 双重把关。

独立页面阅读 ↗

1. 问题与动机

大规模 I2I 召回通常离线编码商品、构建 ANN 索引，在线只做一次向量查询，因此时延低且能覆盖冷启动商品。但生产系统往往分别维护图像、文本和多模态编码器，每套模型都有独立训练、刷新和索引链路；同时，CLIP/SigLIP 等内容相似度并不等于用户行为上的共同转化。两个视觉相似商品可能只是替代品，而用户连续互动的商品可能在图像上差异很大但业务上互补。

CAMIE 的目标是用一个原生 LLM/MLLM 多模态接口统一商品表征，并用真实用户旅程中的 co-engagement 而非内容标签对齐召回空间。作者特别区分“更强 backbone”和“更合适监督”：后续 matched recipe 实验表明，大部分收益来自共参与监督，不是简单换成 2B MLLM。该问题重要之处在于可作为现有 I2I encoder 的 drop-in replacement，不改变线上 ANN 形态。

2. 方法详解

数据由 30 天 Snap DPA 用户旅程构建。每条事件包含用户、商品、时间和 view/click/add-to-cart/purchase 类型；同一用户旅程按 item_id 去重，再在局部 session 或 attribution window 内产生无序商品 pair。过滤要求 EXACT attribution、标题与图片非空、同一广告主、顶级类目一致，时间衰减权重至少 0.5；衰减半衰期为 7 天，每用户最多采样 2 对。离线实验用 1000 万训练 pair、10 万测试 pair，线上 checkpoint 用同流程扩到 1 亿 pair。

每个商品可含主图、标题、品牌、描述和类目路径。renderer 根据 multimodal、text-only、image-only 模式选择字段，图像走 backbone 原生视觉接口，文本走 tokenizer，不增加模态专用 projection。共享编码器 f 与 projection g 输出 L2 归一化向量；decoder-only 模型采用 last-token pooling。相同 checkpoint 通过改变 renderer 支持三种表面。

训练目标是加权、对称的 in-batch InfoNCE。对 pair(i,j)，既计算 i 查询 j 的 softmax，也计算 j 查询 i；分母含同 batch 其他商品，分布式 all-gather 提供跨卡负例。对称性符合 co-engagement 无方向关系，时间可靠度 ω 可作为样本权重。主模型是 Qwen3-VL-Embedding 2B，backbone 冻结，仅在 q/k/v/o attention projection 加 LoRA（r=32、α=64）并训练 projection head。AdamW 峰值学习率 2e-5、200 warm-up steps、余弦衰减、BF16，温度从 0.07 可学习；8 张 A100 40GB，有效 batch 32–64，训练 1 epoch。离线向量 512 维，线上取前 128 维以匹配既有 I2I_MM 索引占用。

部署时每次 catalog refresh 离线编码所有活跃商品并写入 ANN。在线 seed 商品优先查缓存 embedding，新商品才即时编码，然后只发一次 ANN top-K；因此昂贵 MLLM 主要在索引构建期，不进入绝大多数请求关键路径。

3. 核心技术贡献

第一，原生多模态输入加统一 projection，避免为视觉、文本、多模态分别设计融合塔。一个多模态训练 checkpoint 在 text-only R@10 上达到专用文本 fine-tune 的 87.9% 对 89.0%，仅差 1.1 个百分点，说明文本链路可以合并。

第二，co-engagement pair 把预训练语义空间对齐到转化相关性。相同 Qwen3-VL 2B 从未经微调到 CAMIE，归一化 R@10 从 100.0% 提到 137.7%。在 matched backbone 实验中，三种 backbone 的多模态结果落在 5.5pp 范围内，而共参与微调本身带来 37.7% 相对增益，证明监督是主因。

第三，论文把“数据纯度还是规模”做了可行动的拆解。高意向 pair 在同样三分之一数据量时只比全事件子集高 1.6% R@10；保留全部事件把 R@10 提高 8.9%，最终比只用高意向高 7.2%。对稀疏转化场景，这支持用可靠过滤后的全漏斗数据，而非过度追求 purchase 标签。

5. 局限与未来方向

论文未设置独立 limitations 章节，但正文明确指出图像-only 是统一方案的例外：专用 SigLIP2 视觉塔明显更强，生产上仍应保留专用视觉 encoder。所有数据和线上实验来自 Snap DPA，绝对指标、pair 数之外的目录规模、A/B 时长与流量分桶未公开；离线测试候选池由测试 pair 中出现的商品构成，也不等同完整线上目录。作者还指出离线 co-engagement 测试天然偏好同类监督，真正归因必须依靠线上 A/B。未被充分讨论的风险包括同一广告主/同类目过滤会限制跨商家和跨类目的互补发现，co-engagement 也可能继承曝光与流行度偏差。

6. 工业实践意义

最值得复制的顺序是“先改监督，再换大模型”。团队可先用现有双塔或 SigLIP 在同一套可靠 co-engagement pair 上训练，验证行为监督带来的离线/线上收益；只有文本与多模态统一确有运维价值时，再引入 MLLM。pair 生成要记录 attribution 置信度、时间差、广告主/类目边界和事件类型，避免同页曝光造成伪共现；同时用时间切分防止近邻泄漏。

对社区 UGC，可把帖子或商品换成内容单元，将同一会话内的点击、收藏、长停留、关注作者构成 pair，用时间半衰与来源一致性过滤。线上仍可保持“离线全量编码 + 缓存 seed + 单次 ANN”，从而把 2B 模型成本放在索引刷新。部署监控应拆分总体流量与被替换召回源，分别观察 CTR、深度消费、转化、候选覆盖和长尾分布；总体 lift 会被召回源流量占比稀释。若图像-only 是关键入口，应保留专用视觉塔，避免为了模型统一牺牲约 18.5pp 的离线 R@10。

3. PRIME: Mitigating Subgroup Optimization Competition in Shared CTR Top Networks with Plug-in Residual Input-Conditioned Mixture of Expert
4.65
Relevance 5 | Novelty 4 | Practical 5 | Evidence 4 | Timely 5
