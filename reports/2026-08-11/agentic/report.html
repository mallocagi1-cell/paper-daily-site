LLMRouter: Unified Infrastructure for Developing, Evaluating, and Deploying LLM Routers

论文把 LLM 路由统一建模为顺序决策过程，拆成上下文编码器、模型编码器、打分函数、决策规则和学习信号五个组件，并发布覆盖通用、记忆增强、视觉、时序和个性化任务的 xRouteBench。开源 LLMRouter 收录 16 个以上路由器；实验显示学习型路由相对最强固定模型基线提升 14.6%，紧预算下轻量路由更有竞争力。

The Horizon Gap: Planning, Memory, Execution, Training, and Evaluation for Long-Horizon LLM Agents

这篇 39 页综述收集并分析 2024—2026 年 1,547 篇 arXiv 论文，明确区分长任务、长上下文与跨会话长期记忆，并把研究按规划、记忆、执行、训练、评测和安全六类整理。作者以 26.8% bleed filter 控制文献污染，指出任务变长后 outcome-only reward 迅速失去区分度，系统必须引入过程级信号和轨迹诊断。

INSIGHTUGC 搜索 Agent 的失败不一定来自召回器，可能是计划漂移、记忆丢失或工具执行未完成。落地时应把一次回答拆成可观测的 query 分解、检索、证据校验和生成节点，分别记录 nDCG、证据覆盖、工具成功率与最终 CTR，避免用单一答案分数掩盖长链路瓶颈。

Pre-Inference Routing for Cost-Efficient Document Field Extraction

论文在文档抽取前用图像质量、版式等低成本可见特征预测任务难度，再决定调用小模型还是大模型，并在 5 类文档上验证路由是否真的有收益。收据场景成本下降 31%–33%，退化广告采购表下降 77%，质量仍保持在始终使用大模型的 0.02 F1 以内；干净发票和营养标签则不适合路由。

INSIGHT搜索 Agent 读取帖子、长文或附件时，不应默认每一步都调用强模型。可先用轻量特征估计 query 与文档复杂度，只有在预测到召回歧义、表格结构或跨文档证据缺口时升级模型；上线前必须验证‘便宜模型确实会失败’和‘失败可被特征预测’两个前提。

PHASE-Tree: Modeling Character-State Evolution in Long-Horizon Role-Playing Dialogue

PHASE-Tree 用不可变身份根、可变 persona/session/moment 三层状态树记录长对话中的局部变化，并提出 LongEvoRoleBench，包含 4 个跨轮长对话语料和 4 个短对话状态跟踪语料。文本版本在 12 个数据集—指标单元中 11 个领先内部变体，角色、语义和 embedding 指标分别提升 19.7%、12.4% 和 15.1%；200 条盲评与 GPT-4.1 评分相关系数为 0.65。

INSIGHT对社区搜索的长期 Agent 记忆，可把用户偏好、会话目标和当前 query 分开存储，只允许对应层局部更新，避免一次新对话覆盖长期兴趣。上线评测应加入跨会话状态一致性与局部更新回归，而不只测单轮答案相关性。

Ask-E: An Environment for Calibrated Question Generation

Ask-E 把‘生成刚好能区分两个模型能力的问题’做成 Agent 训练与评测环境：目标难度由两个已有模型的能力区间界定，只有恰好一个模型答对才算校准成功。实验发现，即使前沿模型在该基准上的校准率仍低于 50%；在没有新增数学数据、没有更强教师交互和没有 correctness reward 的情况下训练，仍能改善多个下游数学基准。

INSIGHT搜索 Agent 的难例构造可以从固定模板转为能力边界校准：让强弱检索器或不同 Agent 配置竞争同一 query，生成只被其中一个配置解决的难例。这样能持续发现 query 分解、工具调用和证据核验的边界，补足随机抽样无法覆盖的长尾 UGC 查询。

Sarah Pratt, Jae Sung Park, Scott Geng, Ali Farhadi

Do AI Personas Grow? Analyzing and Benchmarking Personality Evolution in LLM Agents After Life Events

论文围绕 11 个重大生活事件研究带人格条件的 LLM Agent 是否会稳定演化，并以 Big Five 为锚点、从 4 个诊断轴比较 14 个模型。结果显示，Agent 会出现事件条件化的特质变化，但幅度通常低于人类效应量，persona 间离散度比人类样本压缩 3–4 倍；作者发布 BFI-Adapt 基准，并验证变化能超过无事件重测噪声。

INSIGHT搜索 Agent 的用户画像也可能在连续交互中被错误地‘人格化’或过度收敛。可借鉴 BFI-Adapt 的对照思想，为用户长期兴趣建模加入无事件重测、改写 query 稳定性和跨会话持久性检查，区分真实偏好变化与上下文噪声。

Ming Wang, Peidong Wang, Xiaocui Yang, Daling Wang, Shi Feng, Fiona Fui-Hoon Nah, Ee-Peng Lim

Is Grep All You Need? How Agent Harnesses Reshape Agentic Search

智源社区对该研究的解读把 Agent harness 放在 Agentic Search 的系统中心，讨论检索策略、Agent 架构和工具调用范式之间的耦合，而不是把 RAG 退化为单次 top-k。文章强调应按端到端任务评估检索、工具使用、长流程推理和最终答案，适合作为工程评测设计的补充入口。

INSIGHT对社区搜索，真正需要优化的不是某个孤立 reranker，而是 query 规划、检索器切换、证据读取、工具权限和终止条件的组合。建议建立 harness 级 trace，至少统计每次搜索的子 query 数、重复调用率、证据覆盖率、耗时和最终点击反馈。

Stockmark-Nemotron-3-Nano-Omni-JapanDocReader: Structured Document Parsing via Capability Injection and Forgetting Control

论文把结构化日文文档解析能力注入 Nemotron-3-Nano-Omni-30B-A3B-Reasoning-BF16，同时控制原有文档 VQA 能力遗忘，比较了 parsing-centric SFT、混合 SFT 和基于 DAPO 的 parsing-centric RL。结果显示单一解析 SFT 会带来 VQA 遗忘，混合 SFT 能基本保住解析效果，随后 RL 再突破 SFT 上限；数据由日文 Document VQA 与程序化解析两条合成流构成。

INSIGHT搜索 Agent 需要读取表格、卡片和附件时，工具模型的增量训练不能只看新任务分数。更稳妥的做法是混合保留原能力的回放数据，再用任务级奖励优化结构化输出，并用奖励方差过滤低价值 prompt，避免文档解析升级反过来损伤通用问答。

Shi Chen, Hayato Aida, Makoto Morinaga, Shohei Tanaka, Kosuke Arima

AURA: Affordance-Understanding and Risk-aware Alignment Technique for Large Language Models

IIT KharagpurCiscoEindhoven University of Technology

AURA 关注 Agent 在隐含情境中给出‘看似合理但会促成危险行为’的 affordance 风险，采用自我批评循环、逐步 Process Reward Model 和安全感知解码，对推理轨迹而非只看最终答案进行干预。其 AFFORDRANKER 在目标导向类别的误判低于 12%，财产损害类别的合计误差超过 16%，物理伤害类别最高超过 28%，揭示了隐含风险识别仍是瓶颈。

INSIGHTUGC 搜索 Agent 可能把危险操作、隐私泄露或越权建议包装成正常答案，因此安全评估应放进检索—工具—生成链路的每一步。可采用‘逻辑连贯 + 情境安全’双奖励，并保留高风险 query 的轨迹级审计，而不是只对最终文本做关键词过滤。

Sayantan Adak, Pratyush Chatterjee, Somnath Banerjee, Rima Hazra, Somak Aditya

Model ML completes finance work more efficiently with GPT-5.6 Sol

OpenAI

OpenAI 介绍 Model ML 使用 GPT-5.6 Sol 把财务工作从资料研究、分析延伸到可编辑且可追溯的 PowerPoint 和 Excel 交付物。该案例没有给出社区搜索 nDCG 或 CTR，但展示了 Agent 从信息检索、结构化处理到业务产出的完整闭环，适合作为企业级工作流落地的工程参照。

INSIGHT迁移到 UGC 搜索时，重点不是照搬财务场景，而是保留‘检索证据—中间分析—可编辑交付—过程可追溯’的链路。对搜索 Agent，应让每个工具调用留下证据与版本信息，使线上点击下降时能定位到 query 改写、召回、重排还是生成环节。
