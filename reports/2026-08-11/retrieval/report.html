PROBES: Performance and relevance observation for better search

PROBES 面向电商、社交和企业搜索，提出由大模型驱动的端到端语义搜索评估系统。它结合 query 类别、特征级意图和类别感知特征重要性，把结果标成 exact、substitute、complement、irrelevant，并进一步区分精度错误与 missed recall。在 100 个商品类目上，Actionable Error Rate 达到 76%，可直接定位召回选择或排序环节的问题。

Factorized Hypothesis Search for Evidence-to-Taxonomy Retrieval

FHS 针对“证据本身没有直接表达目标概念”的检索准备度缺口，维护多个按语义维度分解的部分假设，再将假设渲染成结构化 query 并并行检索，最后用维度级候选验证器重排。在金融标签任务上 R@1/MRR/Acc 为 0.185/0.257/0.255，在 CodiEsp 上为 0.264/0.352/0.330；去掉因子化路径后金融 R@1 从 0.185 降至 0.116。

INSIGHT短文本搜索里，用户 query 常只给出实体、属性或场景的一部分，直接 embedding 容易把正确帖子压到深处。可将 query 拆成实体、意图、时间、地域等槽位，生成少量互补假设后做 RRF 融合，再用轻量 verifier 只修正头部排序；论文显示 verifier 提升 R@1 而不改变 R@50，适合将预算集中在 Top-K。

03 4.00

Rhetorical-Role-Aware Retrieval-Augmented Generation for Legal Question Answering over Indian Supreme Court Judgments

NNational Institute of Technology, TiruchirappalliNNational Institute of Karnataka

论文把法律判决按 Argument、Fact、Statute、Precedent、Ratio 和 Ruling 等修辞角色切块，建立 dense 与 BM25 双索引，再按 query 意图做角色过滤并用 cross-encoder 重排。实验覆盖民事、公司和刑事 30 份判决、9,102 个句子和 1,122 个 chunks；民事域 Gemini-2.5-Pro 的 Faithfulness/Answer Relevancy/Contextual Relevancy 为 0.973/0.901/0.376。

INSIGHTUGC 帖子也有“问题描述—经历事实—结论—评论建议”等结构，固定长度切块会把关键关系拆开。可以先训练轻量结构分类器，再将结构标签作为召回过滤和重排特征；同时保留 BM25 以保护专名、数字、标签等字面信号，并用 query 意图决定需要哪些段落。论文的局限是只评估印度最高法院语料，指标也完全来自 LLM judge。

Sayed Ayaan Ahmed Sha, Sangeetha Sivanesan, Anand Kumar Madasamy, Navya Binu

Efficient, Property-Aligned Fan-Out Retrieval via RL-Compiled Diffusion

Google

R4T 将集合级检索目标转成可训练数据：先用带多样性、覆盖性和互补性奖励的 RL 训练 fan-out LLM，再合成目标一致的 query–set 样本，最后训练轻量 diffusion retriever 一次性生成结果集合。在 Polyvore 与大规模音乐 playlist 两个数据集上，作者报告相对强基线提升集合检索质量，并将 query-time fan-out 延迟降低一个数量级。

INSIGHT社区搜索常需要同时满足主题相关、作者多样和时间覆盖，单文档独立打分无法表达集合目标。可把线上点击、作者去重和新鲜度约束先蒸馏成离线集合样本，再训练轻量召回器；但 R4T 的 RL 数据合成和 diffusion 训练复杂，建议先在离线 rerank 或多路召回融合中做小流量验证。

Measuring the Cross-Lingual Comprehension Gap: How the language of the evidence shapes what language models understand

论文定义跨语言理解差距 CLCG，在内容、问题、参考答案和模型都不变的配对设置下，只替换证据语言。作者用 5 个模型、150 篇文章和 18 种语言评估 ParallelQA-18， pooled CLCG 为 0.078（95% CI 0.072–0.084），相对英文质量下降约 17%；高资源语言回答在盲评中赢得 61.6% 的决定性比较。

INSIGHT社区 UGC 搜索不能把英文或高资源语言上的 embedding、query rewrite 和 RAG 结果直接外推到中文方言、夹杂英文或低资源语言。建议按语言与 query 类型分别监控召回率、重排质量和最终答案，并采用同内容跨语言对照集；CLCG 可作为线上多语言搜索的回归指标，而不是只看总体平均 CTR。

Rafael da Silva, Jeff Eicher

06 3.25

TA-RAG: Tone Awareness as a Design Imperative for Retrieval-Augmented Generation

TA-RAG 是一篇概念框架，指出检索文档的专业术语和语气会在生成前塑造回答，导致事实正确但沟通不合适。它把语言无污名、可读性匹配、接收者适配和同理表达四类约束分布到 query 处理、检索、上下文构建、生成和校验 5 个阶段，并把最终修订限制为最多 3 个周期。

INSIGHT社区搜索结果不只有“相关/不相关”，还涉及口语化程度、敏感词和用户身份适配。可先将可读性、术语偏好和内容安全作为轻量 rerank 特征，再在摘要生成后做约束校验；但论文没有实证数据，且作者明确把联合 benchmark、自动分类器和治理阈值列为开放问题，应把它当作评测设计启发而非可直接上线的模型。

Yong-Bin Kang, Anthony McCosker
