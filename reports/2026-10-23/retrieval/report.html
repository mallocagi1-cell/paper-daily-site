Directional Posterior Feedback Fusion for Query Reformulation in Dense Retrieval

TsinghuaRenmin University

短查询的反馈改写容易被噪声文档带偏。DIFF 把每条反馈看成查询应调整的方向，按置信度融合，再限制更新幅度；原检索器保持冻结。在使用生成式反馈的实验设置中，BGE 的平均 nDCG@10 从 0.5492 升至 0.5717。

INSIGHT反馈只约束它能够说明的方向，可以保留多条反馈之间的互补信息。检索器无需重新训练，适合在查询向量输出之后增加一层改写；控制更新角度能降低短查询因反馈噪声发生意图漂移的风险。

Yiteng Tu, Qingyi Pan, Weihang Su, Jiaxin Mao, Yiqun Liu, Qingyao Ai

How to Read Data into GPU Memory in Python with NVIDIA GPUDirect Storage

NVIDIA

批量生成向量或载入索引时，CPU 中转可能增加数据搬运。教程用 KvikIO 将文件直接读入 GPU，并用 cuFile 计数器确认实际路径。示例读取 1 GiB 文件，全部 256 次读取都走加速路径；这是一项路径验证，并非吞吐提升实验。

INSIGHT读取成功和启用直读是两项独立检查。KvikIO 可以回退到 CPU 中转路径，因此要核对底层计数器。对 GPU 向量索引或嵌入批处理，可沿用这种验证方法判断数据加载瓶颈是否真的被消除。

Amazon

把 PyTorch 模型迁到 Trainium，需要兼顾运行效率与回归覆盖。TorchNeuron 共享编译结果，并用算子形状记录构建快速测试，再扩大到模型级测试。团队筛出 841 个代表模型，用来覆盖主要架构特征。

NVIDIA

本地大模型服务常受内存容量和节点通信限制。NVIDIA 展示多台 DGX Spark 的部署配置，并用专用集合通信后端减少解码同步开销。所测八节点配置在指定 Qwen 模型上的解码加速达到单节点的 4.43 倍。

PACE: Periodic and Channel-Aligned Encoding of Four-Bit Recurrent States

线性注意力模型为每个请求保存循环状态，低比特存储能扩大并发。PACE 每隔几个生成词再量化一次，并按列共享缩放参数，对误差保留较久的头使用更高精度。在较大模型上，它用约三分之二内存达到八比特基线的相近表现。

INSIGHT减少量化次数可以和调整量化尺度一起降低累计误差。对使用循环状态的搜索辅助模型，内存评估应包含中间词缓冲区和保留高精度的头，不能只按标称四比特估算。

FrontierCS 2: A Benchmark for Computer Science R&D

研发代理可能提高总分，却仍在关键工作负载上失败。FrontierCS 2 删除真实论文代码中的贡献，让代理在可运行仓库中补回，并在隐藏测试中评价。基准的 48 个任务中，有 16 个任务没有任何一次运行通过。

INSIGHT自动研发的验收可以同时约束多个指标和负载。用单一综合分数选出的方案，可能牺牲其中一项关键指标。将检索代码交给代理优化时，可同时约束召回、延迟和资源消耗，并隔离开发反馈与最终测试。

MemoryTax: The Bitter Lesson of Agent Memory

对话记忆可以提前压缩，也可以保留原始记录后按需检索。MemoryTax 比较记忆系统、全文上下文和代理检索，并记录构建与查询成本。实验仅覆盖一段含 152 个问题的对话，适合观察机制差异。

INSIGHT记忆写入阶段丢掉的事实，之后换用更强的阅读模型也难以恢复。比较摘要记忆与原文检索时，把预处理费用和每次请求费用分开统计，能避免低估记忆构建成本。这项实验规模较小。

Zedong Peng
