GPU-Native Approximate Nearest Neighbor Search with IVF-RaBitQ: Fast Index Build and Search

提出 GPU 原生的 IVF-RaBitQ 向量检索方案，实现快速索引构建与高吞吐搜索。

arXiv ↗
4.35
综合分 / 5
KEY INSIGHT · 对业务意味着什么将 IVF 聚类与 RaBitQ 低比特量化结合的 GPU 原生流水线，可在保持高召回的同时大幅降低存储和计算成本，对大规模 embedding 检索系统的硬件成本控制具有直接参考价值。业务关联 社区搜索的语义召回层依赖向量检索，该方案可替代现有 CPU-based ANN（如 FAISS-CPU），在 GPU 上实现亚毫秒级延迟和更高吞吐，适合处理社区帖子的大规模 embedding 索引。证据 在 SIFT1M/GIST1M/Deep1M 等标准数据集上，IVF-RaBitQ(GPU) 在 Recall@10=0.95 时吞吐量达 graph-based 方案的 2-4 倍，索引构建速度提升 10 倍以上，存储降低 4 倍；在 10 亿级数据集上可线性扩展。

Synthetic Data Powers Product Retrieval for Long-tail Knowledge-Intensive Queries in E-commerce Search

提出面向长尾知识密集型查询的合成数据框架，通过离线 query 改写模型蒸馏提升电商检索。

INSIGHT将强大离线 query 改写 LLM 的能力蒸馏到轻量在线检索模型中，用合成数据解决长尾 query 缺乏行为日志的问题——这一思路可直接迁移到 UGC 搜索中处理小众/冷门 query。

业务关联社区搜索中大量长尾 query（如特定话题讨论、专业术语搜索）同样面临行为数据不足的问题，该合成数据框架可帮助改善这类 query 的召回质量，无需依赖用户点击日志。

证据在淘宝搜索线上部署，长尾 query 的商品召回覆盖率提升 15%+，整体搜索 GMV 提升 0.8%；离线实验中长尾 query 的 nDCG@10 提升 +6.3%。

Query-focused and Memory-aware Reranker for Long Context Processing

提出利用语言模型注意力头的 listwise 重排序框架，产生连续相关性分数。

INSIGHT直接利用 LM 注意力分数衡量 passage-query 相关性的 listwise 方法，避免了传统 pointwise/pairwise 重排的低效问题；4B 参数的轻量设计使其可在搜索排序的精排阶段实际部署。

业务关联社区搜索的精排阶段需要高效的重排序模型来提升 nDCG，该方法可作为现有 cross-encoder 重排的替代方案，利用 listwise 信息更好地处理 UGC 短文本的上下文排序。

证据在多个标准检索基准上超越现有 reranker 模型；在 LoCoMo 对话理解评测上达到新 SOTA，4B 参数模型的推理效率优于同等精度的 7B 级 reranker。

Yuqing Li, Jiangnan Li, Mo Yu, Guoxuan Ding, Zheng Lin, Weiping Wang, Jie Zhou

From Generator to Embedder: Harnessing Innate Abilities of Multimodal LLMs via Building Zero-Shot Discriminative Embedding Model

提出将生成式多模态 LLM 零样本转化为判别式 embedding 模型的高效框架。

INSIGHT通过层级 embedding prompt 和自感知困难负例采样（SaHa），无需大规模对比预训练即可从生成式 MLLM 构建高质量 embedding 空间——这为利用现有 LLM 快速构建搜索 embedding 模型提供了新思路。

业务关联社区搜索可利用此方法从已有的多模态 LLM 快速构建文本/图文 embedding 模型，降低训练成本；SaHa 方法解决的假负例问题在 UGC 搜索场景中尤为常见。

证据在零样本条件下，多个多模态检索基准上的 MAP 提升 3-8%，且无需任何对比学习预训练数据；SaHa 负例采样比传统方法减少 40% 假负例污染。

Yeong-Joon Ju, Seong-Whan Lee

Truncated Step-Level Sampling with Process Rewards for Retrieval-Augmented Reasoning

提出 SLATE 框架，通过截断步级采样和 LLM 判官奖励解决检索增强推理中的信用分配问题。

INSIGHT针对 LLM 调用搜索引擎的 RL 训练，SLATE 用截断步级采样替代完整轨迹采样，配合 LLM-as-judge 的密集奖励，有效降低梯度方差——这对训练搜索质量优化的 RL 模型具有直接启发。

业务关联随着 LLM 在搜索系统中的深度应用，用 RL 优化 LLM 的检索决策成为趋势。SLATE 的步级信用分配方法可指导社区搜索中 query 改写/检索策略的 RL 优化。

证据相比 Search-R1 基线提升 8-12% 任务完成率，相比 StepSearch 梯度方差降低 60%+；在 3 个检索增强推理基准上均达到 SOTA。

Chris Samarinas, Haw-Shiuan Chang, Hamed Zamani

PTEB: Towards Robust Text Embedding Evaluation via Stochastic Paraphrasing at Evaluation Time with LLMs

提出 PTEB 动态评估协议，通过随机释义在评估时检测 embedding 模型的鲁棒性。

INSIGHT在固定 MTEB 基准上反复调优会虚高分数、掩盖真实鲁棒性；PTEB 通过随机生成语义不变的释义来动态评估，揭示 embedding 模型对 token 空间变化的敏感性——选型 embedding 模型时应关注此类鲁棒性指标。

业务关联UGC 短文本充满口语化表达、错别字、缩写等 token 变体，PTEB 的评估方法可帮助选择对这类噪声更鲁棒的 embedding 模型，避免在干净测试集上表现好但实际场景中退化的模型。

证据在 MTEB 7 类任务、20 个数据集上多次运行，发现所有 embedding 模型在语义保持释义下性能波动 1-5%，证实了 token 敏感性问题；统计鲁棒性通过多轮实验验证。

Manuel Frank, Haithem Afli

Reason to Contrast: A Cascaded Multimodal Retrieval Framework

提出 TTE-v2 级联式多模态检索框架，通过推理驱动的重排序增强检索质量。

INSIGHT在 bi-encoder 检索后增加推理驱动的重排序步骤，并将重排结果反馈用于改进困难负例挖掘和假负例过滤——这种级联反馈设计可提升检索-重排管线的整体效果。

业务关联社区搜索中图文混排场景（如搜索带图帖子）可参考该级联架构，先用轻量 bi-encoder 召回、再用推理增强的重排序精筛；其困难负例反馈机制也适用于纯文本检索的训练优化。

证据在 CIRR 和 FashionIQ 多模态检索基准上，TTE-v2 的检索性能随推理 token 预算增加而持续提升，相比原始 TTE 在 Recall@5 上提升 +4.2%。

UniFAR: A Unified Facet-Aware Retrieval Framework for Scientific Documents

提出 UniFAR 统一框架，通过多粒度聚合和多面对齐同时支持文档-文档和问题-文档检索。

INSIGHT用 facet（主题方面）感知的表示来统一「文档找文档」和「问题找文档」两种检索模式，解决了文档中心模型无法适配问题驱动检索的系统性错配——这种多面表示思路可迁移到 UGC 搜索中。

业务关联社区搜索中同样存在「帖子找相似帖子」和「用户 query 找帖子」的双重需求，UniFAR 的统一框架思路可减少维护两套独立模型的成本，通过 facet 感知更好地匹配不同粒度的搜索意图。

证据在 SciDocs/SCIDCR 等科学文档检索基准上，UniFAR 在 doc-doc 和 q-doc 检索上分别比最佳基线提升 +2.8% 和 +3.5% nDCG@10。

Zheng Dou, Zhao Zhang, Deqing Wang, Yikun Ban, Fuzhen Zhuang

Toward General Semantic Chunking: A Discriminative Framework for Ultra-Long Documents

基于 Qwen3-0.6B 构建轻量判别式语义分块模型，支持超长文档的段落边界检测。

INSIGHT用 0.6B 参数的小模型配合跨窗口上下文融合层实现高质量语义分块，单次输入支持 13K tokens 并可扩展到超长文档——对 RAG/检索系统中的文档预处理具有直接实用价值。

业务关联社区搜索中长篇帖子和问答内容的分块质量直接影响检索召回率，该轻量分块模型可替代固定长度切分策略，以更低的计算成本实现语义连贯的分块。

证据在长文档分割基准上，基于 Qwen3-0.6B 的模型在 F1 上接近 GPT-4 级别分块效果，但推理速度快 20 倍以上；支持 13K token 单次输入，远超传统 512-token 窗口模型。

Geodesic Semantic Search: Learning Local Riemannian Metrics for Citation Graph Retrieval

提出基于黎曼几何的语义检索系统，为图中每个节点学习局部度量张量实现几何感知搜索。

INSIGHT抛弃固定欧氏距离的 embedding 检索范式，为每个节点学习局部黎曼度量，使检索距离自适应于语义空间的局部结构——这是一种全新的检索几何建模思路，可能启发搜索 embedding 空间的非均匀距离设计。

业务关联虽然直接应用于 UGC 搜索需要较大改造，但其「局部自适应距离度量」的思想可启发社区搜索中的 embedding 空间优化，例如对不同类型 query/内容使用不同的距离度量策略。

证据在 169K 论文的引文预测基准上，Recall@20 相比 SPECTER+FAISS 基线提升 23%；层级粗到细搜索策略将计算成本降低 4 倍，同时 MRR 仅下降 2%。

Brandon Yee, Lucas Wang, Kundana Kommini, Krishna Sharma
