Summary: 该论文提出 GTA-2，一个面向通用工具型 Agent 的分层基准测试，覆盖从原子工具调用到开放式工作流两个层次。研究发现前沿模型在原子任务上准确率不到 50%，在工作流任务上仅达 14.39% 成功率，揭示了当前 Agent 系统在复杂真实任务中的能力悬崖现象。采用递归检查点评估机制，能统一衡量模型能力与执行框架的贡献。

2. PolicyBank: Evolving Policy Understanding for LLM Agents
4.10
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 论文提出 PolicyBank，一种让 LLM Agent 通过交互和纠正反馈来迭代进化策略理解的记忆机制。针对自然语言策略规范中不可避免的歧义和逻辑缺口问题，PolicyBank 维护结构化的工具级策略洞察并持续优化，相比现有记忆机制在策略缺口场景中从近乎零成功率提升到缩小 82% 的人类与 AI 差距。

Key insight: PolicyBank 将策略视为可演化实体而非固定规则，通过部署前测试的纠正反馈来消除规范歧义。这一思路对搜索 Agent 极具启发：搜索系统的排序策略和内容过滤规则同样存在自然语言规范的模糊性，可借鉴 PolicyBank 的迭代进化方法让 Agent 逐步学习正确的检索和排序策略。

Summary: 论文通过 ACES 框架系统评估 AI 购物 Agent 的决策行为，揭示了严重的选择同质性问题：Agent 倾向将需求集中在少数模态产品上。随机实验发现 Agent 存在强位置偏差（跨模型版本不一致）、惩罚赞助标签但奖励平台推荐标签的倾向，且对价格、评分、评论的敏感度因模型而异。卖方 Agent 通过简单的描述优化即可显著提升市场份额。

4. W&D: Scaling Parallel Tool Calling for Efficient Deep Research

Summary: Salesforce 提出 Wide and Deep (W&D) 研究型 Agent 框架，通过在单个推理步骤内并行调用多个工具（宽度扩展）来提升深度研究效率。在 BrowseComp 基准上，使用 GPT-5-Medium 达到 62.2% 准确率，超过 GPT-5-High 的 54.9% 基线，且无需上下文管理等额外技巧。该方法避免了复杂的多 Agent 编排，仅利用模型内在的并行调用能力。

5. LookAhead Tuning: Safer Language Models via Partial Answer Previews
3.95
Relevance 3 | Novelty 4 | Practical 5 | Evidence 4 | Timely 4

Summary: 浙江大学提出 LookAhead Tuning，通过在训练数据中预览部分答案前缀（True Answer Preview 和 Virtual Answer Preview 两种策略），最小化对模型初始 token 分布的扰动，从而在微调过程中保留内置安全机制。该方法无需额外参数，适用于任何模型，在所有安全指标上达到 SOTA，同时不牺牲下游任务性能。

Key insight: LookAhead Tuning 揭示了微调破坏安全性的根因是初始 token 分布的偏移。通过预览答案前缀锚定初始分布即可有效缓解。对于搜索 Agent 的安全对齐，这提供了一个轻量级解决方案：在对 Agent 进行任务特定微调时加入答案前缀预览，可在不牺牲搜索能力的同时保持安全边界。代码已开源，可直接应用。

Summary: Microsoft 研究团队提出 DELEGATE-52 基准，模拟覆盖 52 个专业领域的长流程委托任务，系统评估 19 个 LLM 在文档编辑委托中的可靠性。结果显示前沿模型（Gemini 3.1 Pro、Claude 4.6 Opus、GPT 5.4）在长工作流中会悄然损坏约 25% 的文档内容，且工具使用和 Agentic 方法并未改善表现。错误随文档大小、交互长度和干扰文件增多而加剧。

7. GroupDPO: Memory efficient Group-wise Direct Preference Optimization
3.80
Relevance 3 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: Google 提出 GroupDPO，一种内存高效的组级偏好优化算法，在反向传播时解耦样本以保持梯度完整性同时大幅降低峰值内存。相比传统 DPO 仅用单对正负样本，GroupDPO 能同时对比多个候选响应，在离线和在线对齐场景中均超越单对训练。关键发现是正样本的负对数似然（NLL）项对性能和训练稳定性至关重要。
