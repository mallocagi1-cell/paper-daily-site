Multi-Epoch Learning with Data Augmentation for Deep Click-Through Rate Prediction

MEDA 提出首个通用可靠的深度 CTR 模型多轮训练策略。工业界 CTR 模型普遍面临多轮训练过拟合问题（样本重复暴露导致 embedding 层过拟合），现有方案需针对特定模型调参。MEDA 通过特征级数据增强和自适应正则化，在不同 CTR 模型架构（DeepFM、DCN、DIN 等）上均能稳定提升多轮训练效果，AUC 提升 0.3-0.8%。

1. 问题与动机

CTR 预估模型面临一个独特的训练困境：单轮过拟合现象（one-epoch overfitting）。与 CV/NLP 领域模型通常需要多轮训练才能收敛不同，CTR 模型在第二轮训练开始时性能即显著下降。

根本原因在于 embedding 层过拟合：CTR 模型处理数十亿稀疏分类特征（如用户 ID、物品 ID），大量低频特征的 embedding 向量仅有极少训练样本，重复暴露导致 embedding 记忆训练数据而非学习泛化表征。作者通过控制实验验证：固定 embedding 层时 MLP 几乎不过拟合；固定 MLP 后 embedding 过拟合仍然出现。

工业意义：多轮训练对于以下场景至关重要——(1) 数据量有限但模型容量大；(2) 需要无监督域适应或标签噪声修正；(3) 计算资源充足但训练时间有限。快手实际部署中，MEDA 使基线 2 周训练效果仅需 1 周达到。

2. 方法详解

核心思想：解耦 Embedding 与 MLP

MEDA 发现 MLP 层学习的是 embedding 间的相对关系（方向）而非绝对位置（数值）。因此可通过在每轮训练时重新初始化 embedding 来实现隐式数据增强——MLP 被迫在不同的 embedding 空间中学习稳健的匹配函数。

Non-Continual MEDA (Algorithm 1)

  1. 随机初始化 MLP 参数 θ₀
  2. 对每轮 r (1 到 k)：

- 随机重新初始化 embedding 层 Eᵣ（Glorot/均匀分布）
- 使用上轮 MLP θ_{r-1} 作为初始化（保留 MLP 知识）
- 在完整数据集上训练一轮
- 同时更新 θ 和 E

关键洞察：embedding 重新初始化 = 隐式数据增强。每轮的 embedding 空间不同，MLP 看到的是"同一数据的不同表示"，等效于在特征空间做增强。

Continual MEDA (Algorithm 2)

适用于连续数据流（如日增量训练）：维护 k 个独立初始化的 embedding 组：

  1. 初始化共享 MLP θ^c 和 k 个 embedding 层
  2. 对每个数据集 t (日增量)：对每轮 r 选择 embedding Eᵣ^{t-1}，初始化 MLP 为 θ^c，训练一轮

训练细节

  • 损失函数：BCELoss（分类）/ AUC scoring（回归/LTV）
  • 优化器：Adam (lr=0.001) 公开数据集；Adagrad (lr=0.01) 业务数据集
  • Embedding 初始化：Glorot（公开）；uniform [-0.01, 0.01]（业务）
  • 验证 MLP 收敛性：跨轮 MLP 参数的 cosine similarity 单调递增

3. 核心技术贡献

  1. 首次系统诊断 CTR 模型单轮过拟合根因：通过控制实验明确归因于 embedding 层的高维稀疏性过拟合。推翻了此前模糊的"整体模型过拟合"认知。
  1. 通用多轮训练策略：MEDA 可无缝集成到 DNN、DIN、DIEN、MIMN、ADFM 等不同架构中，无需修改模型结构。2 轮训练即带来 +0.73% 到 +5.17% AUC 提升。
  1. 数据效率翻倍：在 Taobao 数据上，50% 数据 + 2 轮训练即达到基线 100% 数据单轮的性能，节省一半数据采集成本。
  1. MLP 学习相对关系的发现：余弦相似度分析证明 MLP 参数方向跨轮收敛，为 embedding 重新初始化策略提供理论基础。

5. 局限与未来方向

作者承认：

  1. 信息损失：随机重新初始化丢弃了高频特征积累的有价值 embedding。建议未来借鉴差分隐私思想，根据特征频率设计差异化噪声水平。
  2. 在线学习时效性：多轮方法牺牲时效性，但 batch+online 混合方案可容纳。

未被作者提及的局限：(1) 十亿级特征表重新初始化的显存和 IO 开销；(2) 高频特征的冷启动效应。

6. 工业实践意义

直接可采纳：

  • 零代码改动提升 CTR 模型效果：仅需在训练脚本中加入 embedding 重新初始化逻辑
  • 在数据量有限的垂类场景（如 UGC 社区搜索排序），多轮训练增益更显著
  • 数据效率翻倍意味着可用更短数据窗口训练出等效模型

部署考量：

  • 训练时间增加 k 倍，但可并行化
  • 在线 serving 无额外开销：最终只保留一套 embedding + MLP
  • 与增量训练兼容：Continual MEDA 专为日更场景设计

对 UGC 搜索排序的适用性：社区搜索的 CTR 模型通常面临样本稀疏（长尾 query/帖子组合多）、特征高维稀疏特点，正是 MEDA 增益最大的场景。建议在现有 CTR 模型上尝试 2-3 轮 MEDA 训练，预期 AUC +0.3-1.0%。

Sample Is Feature: Beyond Item-Level, Toward Sample-Level Tokens for Unified Large Recommender Models

📖 有深读 · 8 分钟

提出 Sample-Level Token 范式，突破工业推荐模型的两大瓶颈：样本信息扩展（通过更深更长行为序列丰富训练信号）和模型容量扩展（在单一 Transformer 骨干中统一序列建模与特征交互）。将每个训练样本的全部信息（用户特征、上下文、行为序列）统一编码为 token 序列，使 Transformer 自然处理跨模态交互。

INSIGHT关键创新在于打破 item-level token 的限制，将推荐模型从「每个 item 一个 token」提升到「每个样本一个 token 序列」。这使得模型能同时利用序列位置信息和特征交互信息，避免了传统方法中两个模块分离导致的信息损失。对搜索/推荐系统的启示：统一 Transformer 架构可替代「序列模型 + 特征交叉模型」的拼接方案。

1. 问题与动机

工业推荐模型的扩展遵循两条并行范式：样本信息扩展（通过更深更长的行为序列丰富训练信号）和模型容量扩展（在统一 Transformer 骨干中融合序列建模与特征交互）。然而两者存在结构性瓶颈：

  1. 样本信息扩展瓶颈：当前序列延长方法仅将 item embedding 或少量特征子集编码为历史 token，丢失了大量原始样本上下文（用户画像、情境信号、行为结果）。论文举例："考虑两个用户都点击了同一家餐厅：一个在深夜使用优惠券的 session 中，另一个在工作日午餐高峰期——裸 item embedding 将这两次交互视为完全相同。"
  1. 模型容量扩展约束：统一 Transformer 架构在处理序列 item token（稀疏）和当前请求的稠密多字段 token 时存在表征不对称，限制了模型容量的实现。

该工作建立在 HyFormer、OneTrans 等先前统一架构之上，但指出它们在 sequence length > 500 时效果饱和。

2. 方法详解

核心创新：Sample-Level Token

SIF 将每个历史交互的完整特征快照（用户画像、item 特征、上下文信号、交叉特征）编码为 token 序列，替代裸 item ID。原始样本定义为 S = [f_user | f_item | f_ctx | f_cross]。

Sample Tokenizer: 层次化分组自适应量化 (HGAQ)

Step 1: 分组分解 — 将原始样本划分为 G=4 个语义组，防止信息稀释。高基数特征（如 item ID）独占一个组。

Step 2: 自适应组内子 token 化 — 每组 g 划分为 K_g 个子 token：K_g = ⌈|F_g|/B⌉，粒度 B=32 控制每个子 token 的特征字段数。特征投影维度 d₀=16，总子 token 数约 T≈27。

Step 3: 残差向量量化 (RVQ) — 对每个子 token 施加 M=3 级 RVQ，codebook 大小 V=256。总存储为 T×M=81 个离散索引，实现 237× 压缩比（相比 float32 原始快照）。

Step 4: 标签监督 Codebook 训练 — RVQ 重建结果通过 MLP 做辅助 CTR 预测，损失 L_token = L_BCE(ŷ^token, y)，确保 codebook 按预测相关性组织，而非仅按重建误差。

SIF-Mixer 架构

输入布局为 (L+1)×T 矩阵（L 个历史 + 1 个目标），堆叠 N=4 个 SIF Block：

  • Token-Level Mixer：行内 self-attention，捕获单个样本内 T 个子 token 间的交互（用户-物品-上下文跨组关联），复杂度 O(T²·(L+1)·d₀)
  • Sample-Level Mixer：列内 self-attention，跨 L+1 个样本的时序注意力，复杂度 O((L+1)²·T·d₀)
  • Token-Level FFN：逐位置非线性变换

预测头：对 T 个子 token 输出做 mean pooling 后接两层 MLP + sigmoid。

训练目标

总损失 L = L_BCE + β·L_VQ + γ·L_align，其中 β=1.0, γ=0.25。L_align 确保目标样本投影与 codebook 空间兼容。训练配置：Adam (lr=10⁻³)，batch size 4096，sequence length L=1000，8×A100-80G GPU。

3. 核心技术贡献

  1. Sample-Level Token 范式：首次将推荐模型从 item-level token 提升到 sample-level token，使 Transformer 自然建模跨模态交互（用户×物品×上下文），对比 HyFormer/OneTrans 在 L=1000 时 GAUC 提升 +0.0088/+0.0093。
  1. HGAQ 量化压缩：237× 压缩比下保持全快照语义——相比 raw embedding (9× 压缩) AUC 更优。创新在于 label-supervised codebook 训练，使离散索引按 CTR 预测信息量组织。
  1. 双轴分解注意力：Token-Level × Sample-Level 的因子化设计，复杂度 O(L²T·d₀) 优于 flat attention O((LT)²)，同时保留了 pooled-then-attend O(L²) 丢失的组内结构（GAUC 差 -0.81%）。
  1. 序列长度外推能力：在 L 从 100 增至 2000 时，SIF 优势从 +0.0013 单调扩大至 +0.0102（vs HyFormer），证明 sample-level 信息在更长序列中释放更多价值。

5. 局限与未来方向

作者指出：(1) 序列特征的时序排列信息未纳入 sample 量化，由 Sample-level Mixer 单独处理；(2) HGAQ 需精心校准子 token 粒度 B 以平衡分解精度和模型紧凑性；(3) 当前 codebook 为静态训练，未来可探索在线自适应更新。

未提及但值得注意：(1) 237× 压缩仍需离线预计算和 KV 存储所有历史快照；(2) 特征字段变更需重训 codebook。

6. 工业实践意义

直接可借鉴点：

  • 对于行为序列较长的平台（L>100），sample-level 编码可释放显著信息增益——美团数据显示 L≥500 用户 CTR 提升 3%+
  • HGAQ 的 codebook 训练方式（label-supervised）值得在 embedding 压缩任务中借鉴——比纯重建目标更对齐业务指标
  • 双轴分解注意力是 compute-quality 的 Pareto 优选方案

部署考量：

  • 推理延迟：0.93 TFLOPs（vs baseline 0.31），约 3× 计算开销，需 GPU 推理或 TensorRT 优化
  • 存储需求：每用户 1000 个历史样本 × 81 个离散索引 ≈ 81KB/用户
  • 特征工程依赖：需要能获取历史交互时刻的完整特征快照

对 UGC 搜索推荐的适用性：社区搜索中用户浏览帖子时的上下文（搜索 query、时段、位置、前序浏览轨迹）高度异质，SIF 的 sample-level 编码可有效利用这些被传统方法忽略的信号。

What Makes LLMs Effective Sequential Recommenders? A Study on Preference Intensity and Temporal Context

系统研究 LLM 作为序列推荐器的有效性机制。发现现有偏好对齐方法多依赖二元配对比较，忽略了两个关键因素：偏好强度（用户对物品的喜好程度差异）和时间上下文（近期交互更能反映当前意图）。通过对比实验证明，引入偏好强度梯度和时间衰减机制可显著提升 LLM 推荐效果。

INSIGHT揭示了 LLM 推荐的核心改进方向：不是简单的「喜欢/不喜欢」二分法，而是建模偏好的连续强度和时间相关性。实践意义：在 UGC 搜索场景中，用户对内容的兴趣存在明显强度差异和时间衰减，该方法可直接用于 LLM-based 排序模型的偏好信号构建。

Beyond One-Size-Fits-All: Adaptive Test-Time Augmentation for Sequential Recommendation

提出自适应测试时增强（Adaptive TTA）方法解决序列推荐中的数据稀疏问题。现有 TTA 方法采用统一的、用户无关的增强策略，忽略了用户间巨大的行为异质性。论文设计了用户感知的增强策略选择器，根据用户行为模式自动选择最优增强方式，无需模型重训练即可提升推理精度。

INSIGHT核心洞察：不同用户需要不同的数据增强策略（活跃用户适合随机遮蔽，低频用户适合序列补全）。实践价值：作为即插即用模块，可在不修改已训练模型的前提下提升推荐效果，部署成本极低。对 UGC 搜索场景尤其适用——用户活跃度差异大，统一策略必然次优。

Learning Behaviorally Grounded Item Embeddings via Personalized Temporal Contexts

指出标准 Item2Vec 方法将用户历史视为无序集合（bag-of-items），隐含假设分钟级交互和月级交互具有同等语义关联性，从而抹平了用户行为的时间结构。提出基于个性化时间上下文的 item embedding 学习方法，区分短期偏好演变和长期兴趣变化，生成时间感知的 item 表征。

INSIGHT方法论创新：通过时间距离感知的上下文窗口动态调整 item 共现权重，近期共现 item 获得更强的语义关联信号。对推荐系统的实践启示：embedding 层是推荐系统的基石，时间感知 embedding 可直接替换现有 Item2Vec/Word2Vec 训练方式，对下游 CTR 模型和召回模型均有提升。

A Universal Framework for Compressing Embeddings in CTR Prediction

INSIGHT工程实践价值高：工业级 CTR 模型的 embedding table 动辄数百 GB，GPU 显存放不下是普遍痛点。该框架的通用性意味着可在 DeepFM、DCN、DIN 等不同架构上即插即用，无需针对每个模型单独设计压缩方案。对大规模 UGC 搜索排序模型的 embedding 层优化有直接参考意义。
