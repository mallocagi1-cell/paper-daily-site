Procedural Graphs: Self-Evolving Execution Structures for LLM Agents

论文把智能体的操作顺序与执行条件表示为过程图，每步只读取当前节点附近的子图，再根据成功与失败轨迹修改结构。在图构建对照实验中，从零在线演化使 HotpotQA 答案 EM 从 58.8 升至 66.3，F1 从 71.21 升至 78.79；修改需通过留出验证集才会保留。

Environments as Scaffold: Enriching Feedback to Bootstrap Self-Evolving Agents in Long-Horizon Tasks

Fudan UniversityCASIASShanghai Innovation Institute

论文通过改造训练环境缓解长程 Agent 的稀疏奖励：前期提供行动提示，后期丰富工具观察，并逐渐让策略内化这些信息。Qwen3-4B 配合 DAPO 时，BFCL 与 SciWorld 的平均分从 43.88 升至 47.81；Qwen3-8B 配合 GSPO 时从 41.78 升至 46.39，但部分子任务出现退步。

INSIGHT训练社区搜索 Agent 时，可先帮助它识别合法检索动作，再提供命中状态、证据缺口等可验证反馈，最后在无提示环境测试迁移。原文强调同组样本反馈的一致性，否则会干扰相对优势估计。应同时监控任务成功率、搜索次数和长上下文退化，避免只根据平均收益扩大上线范围。

Hongbang Yuan, Zhuoran Jin, Yixin Cao

Explore Before Committing: Hypothesis-Guided Search for Deep Research Agents

MeituanCityUHKUniversity of Oxford

深度搜索容易过早选定一个看似合理的方向，后续调用不断强化最初判断。HypoSearch 先生成轻量假设，在受限分支中分别找证据，再比较各分支后作答；在 4 个基准、3 个骨干模型上评估，Qwen3.5-122B 的 BC-small 得分从 46.7 升至 60.0，工具调用少于 5 条独立轨迹。

INSIGHT社区 UGC 搜索常有同名实体、隐含条件和多个可能意图，可先保留少量竞争性解释，再以帖子证据决定方向。试验时应固定总检索预算，同时记录分支覆盖、无效调用和最终答案准确率；论文结果支持推迟承诺，但不能直接换算成社区搜索的 nDCG 或 CTR 收益。

Ruochen Zhou, Zhengyu Chen, Luan Zhang, Siyang Gao, Yee Whye Teh, Shiqi Chen

Audit Without Verification: When LLM Accountability Layers Relay Rather Than Check

IInstitute for Future Technologies

研究在六智能体流水线中注入缺陷，检验审计层能否独立定位问题。上游没有指出真实来源的子集中，审计者仅凭报告的定位准确率为 4.1%，读取同批原始记录则为 60.3%；移除报告中的结论字段后升至 45.2%。原先关于责任表述随链长影响升级行为的预注册假设未获支持。

INSIGHT社区搜索的多 Agent 核验应保留原始帖子、工具输出和时间戳，避免裁判只复述检索 Agent 的结论。可分别传递观察与推断，盲测裁判在错误候选集合下能否恢复真实证据。移除结论会损失正确提示的价值，因此应分层报告误导与正确提示条件下的准确率，不能只看整体均值。

Paul-Peter Arslan

RuleMem: Active Rule Memory for Long-Term Conversational Agents

Sun Yat-sen UniversityHKUST GuangzhouSShenzhen Institute of Computing SciencesPolyUTsinghua University

RuleMem 从历史对话归纳自然语言 Horn 规则，并用规则困惑度一致性机制校验，让记忆主动指导证据检索与推理。在 LoCoMo 的 14 个基线对比中，其准确率超过基线平均值 27.47 个百分点，相对提升 54.3%；论文还在 LongMemEval_s* 上检验长程对话问答。

INSIGHT可将社区多轮问答中反复出现的条件关系整理成规则，用于召回语义距离较远但逻辑相关的帖子。关键是将规则与原始证据绑定，并对时间变化、反例和规则冲突做验证。论文的 54.3% 是相对基线平均值的提升，不能解读为相对最强系统；业务验证仍应回到相关性与答案可靠性。

Xingyuan Zeng, Zuohan Wu, Quanming Yao, Yue Wang, Wei Liu, Libin Zheng, Jiuke Wang, Jian Yin

EdgeMem: LLM-Free Agent Memory Construction and Retrieval via Evidence-Preserving Multi-Anchor Hypergraph

PolyUChina Mobile

EdgeMem 针对智能体记忆摘要丢失细节和生成成本高的问题，用内容、时间与事件锚点构建超图，直接检索原始对话轮次。记忆构建和检索均不调用生成式大模型；在统一提示的 7 个复现系统中，LoCoMo 严格裁判得分为 61.01，高于最强对照的 58.70，并在 LongMemEval-S 验证。

INSIGHT社区帖子和评论往往信息短碎、时间关系强，可保留原文并用实体与时间锚点连接多轮证据，降低反复摘要造成的信息损失。适合先验证追问场景的证据召回与回答可追溯性。公开仓库仍是与论文差异较大的早期实现，当前版本尚待同步，因此落地需要自行补齐实现和复现。

Zeyang Cui, Jiannong Cao, Zhiyuan Wen, Bo Yuan, Junlan Feng, Shengyuan Chen

NeoHorse-1: Towards Recursive Self-Improvement via Agentic Post-Training with Routing Harness

NeoHorse-1 将模型路由记录转化为训练课程，保留推理、工具调用与执行环境，经结构和六维语义检查后开展三阶段训练及在线策略蒸馏。4B 模型的十项评测平均分从 Qwen3.5-4B 的 58.94 升至 64.87；9B 从 65.60 升至 69.04，收益主要集中于多步交互和执行反馈任务。

INSIGHT社区搜索系统可记录查询难度、路由层级、检索轨迹和失败类型，再据此分配轻量与高能力模型的训练样本。其启示是让调度日志成为能力诊断数据，而不是只保存最终回答。不同模型的指令遵循并非全面提升，迁移时应保留独立测试集，单独核对引用正确率、工具成功率和每次查询成本。

NeoHorse Team, Guoliang Cao, Guohao Dai, Tianyu Guo, Kai Han

Beyond Agent Harnesses: Cross-Substrate Authority for Multi-Agent Systems

HKUJJiangxi Science and Technology Normal UniversityHKUSTShenzhen University

论文指出，文件内容相同并不代表执行者拥有相同权限，授权信息可能位于智能体观察之外。128 单元的消融中，无授权证据为 0/32 成功，加入原始回执或类型化关系均为 32/32；重放 32 个固定动作时，确定性执行检查拦住全部 6 个不安全意图，并放行 12 个合法发布意图。

INSIGHT社区搜索 Agent 访问私密帖子、跨群数据或执行内容操作时，应把数据可见性与执行授权分开记录，并在实际调用边界检查权限。向规划器增加说明不足以保证正确执行，原文类型化关系也未优于等量原始信息。可先在受控回放中测误放行和误拦截，再评估其对查询可用性与延迟的影响。

Yang Li, Sergey Volkov, Hai Liu, Zongsi Xu, Xiyu Chen, Tuo Zhou, Dian Shao, Hao Sun, Ye Lu

CAPMAS: Capability-Based Delegation of Privileges in Multi-Agent Systems

EPFLSwisscom

CAPMAS 用对比学习把自然语言请求映射为有限权限，再以 Macaroon 令牌在多智能体间逐步收缩授权范围，减少集中身份服务通信。在常见委托深度不超过 10 时，令牌生成与本地收缩比两种签名基线快逾 10 倍；根权限约 193 字节，每次追加限制约 119 字节。

INSIGHT社区 Agent 的跨工具检索可把用户可访问的群组、时间范围与操作类型编入可收缩授权，而不是把完整用户身份一路传下去。语义范围识别仍可能漏判，需结合显式权限校验并测试过度授权与误拒绝。论文性能数字来自授权微基准，不能当作整个搜索请求的加速倍数。

Rasmus Moorits Veski, Rachid Guerraoui, David Froelicher

Omni Interaction Agent Technical Report

TencentZhejiang UniversitySJTUCUHKNTU

腾讯 Gander 用前端“小脑”处理流式音视频交互，后端“大脑”执行长程推理与工具任务，并通过运行时同步状态。在 Full-Duplex-Bench v3 的 100 个场景中，适时接话率达 100%、打断率为 8.0%；但端到端 Pass@1 为 0.400，低于 GPT-Realtime 的 0.600。

INSIGHT对语音社区搜索，可借鉴交互响应与深度检索解耦、持续反馈任务进展的设计，让用户能够补充问题和调整检索方向。部署评估需区分接话自然度和任务正确率，不能用更少打断掩盖检索失败。原文仅运行后端时 Pass@1 为 0.520，说明语音输入与委派链路仍会损失任务能力。

Orantqing, Shengpeng Ji, Junlong Tong, Jialong Zuo, Dongjie Fu
