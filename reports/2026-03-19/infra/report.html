VQKV: High-Fidelity and High-Ratio Cache Compression via Vector-Quantization

VQKV 针对 LLM 长上下文场景中 KV 缓存占用过大的问题，提出基于向量量化（VQ）的 KV 缓存压缩方法。与低秩近似和标量量化等传统方法相比，VQ 通过将键值张量映射到共享码本中的紧凑编码，在保持高重建保真度的同时实现更高的压缩比。该方法无需重新训练，可即插即用地集成到现有推理栈中。实验表明，在多个 LLM 基准测试上，该方法以更低的显存占用保持了接近原始模型的性能。

Not All Prefills Are Equal: PPD Disaggregation for Multi-turn LLM Serving

PPD 系统针对多轮对话 LLM 服务中预填充-解码分离（PD 分离）场景的效率问题，提出基于工作负载感知的动态路由策略。传统 PD 分离方案将所有预填充请求路由到专用节点，忽略了多轮对话中第 2+ 轮的上下文复用特性。PPD 将部分预填充请求路由到解码节点，利用已有 KV 缓存，在保持吞吐量的同时将第 2+ 轮 TTFT（首 Token 延迟）降低 48–73%。

INSIGHT多轮对话在生产 LLM 系统中占比极高，PPD 揭示了不同轮次预填充请求的异构性——后续轮次因可复用 KV 缓存而计算成本更低。对于在搜索系统中使用 LLM 进行多轮 query 改写或对话检索的场景，此方案可显著降低实际延迟。工程团队应在服务层区分首轮与续轮请求，针对性地分配计算资源，避免将全部预填充请求平等对待。

FlashSampling: Fast and Memory-Efficient Exact Sampling

FlashSampling 针对大词表语言模型解码时的采样操作瓶颈，提出将采样原语融合进 LM head 矩阵乘法（matmul）中，避免在 HBM（高带宽显存）中显式化 logits 张量。该方法消除了采样阶段额外的显存搬运和 CUDA kernel 启动开销，在不影响采样精确性的前提下显著降低了解码延迟和显存峰值占用。在 vLLM 框架中的集成测试中，该方法在大词表场景下带来显著的吞吐量提升。

INSIGHT大词表模型（词表 100K+）的解码在生产系统中面临隐性开销：logits 张量的 HBM 读写往往成为解码速度的瓶颈。FlashSampling 的 kernel 融合思路与 FlashAttention 一脉相承，值得在 vLLM/SGLang 等推理框架中集成。对于高 QPS 的搜索/推荐 LLM 服务，此方案可在不修改模型权重的情况下提升吞吐量，降低服务成本。

Tomas Ruiz, Zhen Qin, Yifan Zhang, Xuyang Shen, Yiran Zhong, Mengdi Wang

Filtered Approximate Nearest Neighbor Search in Vector Databases: System Design and Performance Analysis

本文对向量数据库中的过滤近似最近邻搜索（Filtered ANNS）进行系统性研究，覆盖主流系统设计方案（预过滤、后过滤、索引内过滤），分析各类混合关键词-向量查询场景下的性能权衡，并提出生产环境的设计准则。基准测试涵盖多种过滤选择率（低、中、高），揭示了不同场景下的最优策略差异，为向量数据库的系统选型和索引策略提供了实践指导。

INSIGHTFiltered ANNS 是搜索系统中混合语义+结构化过滤（如「最近 7 天内、价格 < 100 元、与 query 语义相关」）的核心能力。本文的设计准则直接指导向量数据库选型：低过滤选择率时预过滤效果好，高选择率时后过滤更优。工程团队可用此框架评估 Milvus、Weaviate、Qdrant 等系统在实际业务查询分布下的表现，指导索引策略的设计决策。

Compressed Convolutional Attention: Efficient Attention in a Compressed Latent Space

Compressed Convolutional Attention（CCA）提出在压缩的潜在空间中计算注意力，通过将 Q/K/V 在序列维度上先卷积压缩再做注意力，同步缩减预填充计算复杂度（训练速度）和 KV 缓存大小（解码速度）。相比 GQA 仅减少缓存、MLA 需要复杂分解，CCA 在单一机制中解决了两个核心开销。在标准语言建模基准上，CCA 保持了与 MHA 相当的模型质量，同时显著降低了训练和推理成本。

INSIGHT传统注意力优化往往顾此失彼——FlashAttention 降低 IO 但不减计算，GQA 减缓存但未改善训练速度。CCA 的压缩潜在空间注意力思路为下一代 Transformer 架构设计提供了新的权衡点。对于需要从头训练或大规模微调长上下文模型（>32K 上下文）的团队，CCA 提供了一个值得在基线对比中纳入的架构候选，尤其适合计算和显存双重受限的场景。

Tomas Figliolia, Nicholas Alonso, Rishi Iyer, Quentin Anthony, Beren Millidge

SQuat: Subspace-orthogonal KV Cache Quantization

SQuat 提出以「子空间正交」原则量化 KV 缓存中的键张量：量化误差方向与未来查询向量正交，从而使量化噪声对注意力分数的影响最小化。相比传统 INT8/INT4 量化直接最小化张量重建误差，SQuat 将优化目标与下游注意力计算对齐，在相同位宽下显著降低了模型输出质量损失，尤其在长上下文和敏感 token 位置效果突出。

INSIGHT传统量化误差指标（如 MSE）与注意力质量之间存在错位——张量重建精确不等于注意力计算准确。SQuat 的子空间正交视角为 KV 缓存量化提供了新的理论基础。对于在生产系统中使用 INT4/INT8 KV 缓存（如 vLLM 的 fp8_e5m2 模式）的团队，SQuat 提供了一个精度损失更低的替代方案，值得在长上下文检索和 RAG 场景中实测对比。

Cracking Vector Search Indexes: CrackIVF Adaptive Index

CrackIVF 提出自适应向量索引，初始以近似暴力搜索方式构建，随后根据实际查询工作负载在线调整分区结构。与 HNSW 等静态索引相比，CrackIVF 无需预先全量构建索引，可在服务实时查询的同时逐步优化，召回率与 HNSW 相当但构建开销显著更低，特别适合数据持续更新的场景。

INSIGHT线上向量搜索系统面临的关键挑战之一是索引与实时数据更新的一致性。CrackIVF 的自适应设计在数据流场景（如新帖子/商品持续入库）中具有天然优势——无需等待全量重建即可服务最新数据。对于 UGC 内容实时搜索场景，这种边服务边优化的索引策略是值得试验的工程方向，可有效降低索引更新延迟，改善新内容的曝光时效性。

Frequency Matters: Fast Model-Agnostic Data Curation for Pruning and Quantization

本文针对 LLM 压缩中校准数据集选择的关键问题，提出基于频谱特征的快速数据筛选方法，识别和选择最能代表模型激活分布的校准样本。该方法模型无关，同时适用于剪枝和量化两类压缩任务。在多个 LLM 基准上，使用更少校准样本达到与大规模随机采样相当甚至更优的压缩质量，显著加速了压缩前的数据准备流程。

INSIGHT实际工程中 PTQ（训练后量化）的效果对校准数据集非常敏感，但这一环节往往被忽视。Frequency Matters 提供了一个快速、自动化的校准数据筛选方案，可在不访问训练集的情况下有效提升压缩质量。对于在业务数据上部署 INT4 量化模型的搜索/推荐团队，此方法可作为 SmoothQuant、GPTQ 等量化工具的前置数据准备步骤，尤其适合垂直领域分布的模型压缩。

CacheSolidarity: Preventing Prefix Caching Side Channels in Multi-tenant LLM Serving Systems

CacheSolidarity 识别了多租户 LLM 服务系统中自动前缀缓存（APC）存在的侧信道安全漏洞：攻击者可通过测量 TTFT 差异推断其他租户的 KV 缓存命中情况，从而泄露敏感上下文信息。论文提出 CacheSolidarity 防御框架，通过添加噪声和缓存隔离策略，在保护隐私的同时最小化性能开销。

INSIGHT随着企业 LLM API 服务大规模采用前缀缓存（vLLM、SGLang 均支持），跨租户信息泄露成为真实安全威胁。CacheSolidarity 提醒基础设施团队：性能优化与安全隔离需同步考量。对于向多个业务方提供共享 LLM 服务的平台团队，应评估现有 APC 实现的隔离边界，必要时引入租户级缓存命名空间隔离或 TTFT 扰动机制。

Where Matters More Than What: Decoding-aligned KV Cache Compression via Position-aware Pseudo Queries

本文针对 KV 缓存驱逐策略，提出位置感知伪查询（Position-aware Pseudo Queries）方法，将驱逐决策与解码阶段的实际注意力模式对齐。传统驱逐方法（如 H2O、SnapKV）基于静态注意力分数选择保留的 token，未充分考虑位置信息对未来注意力的影响。实验表明，位置上下文比 token 内容对缓存命中率更为关键，位置感知驱逐策略在长上下文任务上优于现有方法。

INSIGHTKV 缓存驱逐是长上下文推理中最直接的显存优化手段。该工作揭示了重要设计原则：驱逐决策应考虑「哪个位置的未来 token 更可能关注它」，而非简单基于历史注意力分数。对于在 vLLM 等框架中使用 sliding window 或 attention sink 方案的团队，可将位置感知策略作为驱逐决策的额外信号，尤其在 RAG 长文档问答场景中效果显著。
