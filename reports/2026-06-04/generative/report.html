1. TalkPlay-Tools: Conversational Music Recommendation with LLM Tool Calling
3.25
Relevance 3 | Novelty 4 | Practical 3 | Evidence 3 | Timely 3

Summary: TalkPlay-Tools 把 LLM 作为端到端对话式音乐推荐系统，并引入工具调用统一「检索-重排」流水线。针对纯生成式推荐忽视元数据/属性过滤等简单但关键组件的问题，让 LLM 在生成推荐时调用检索与属性过滤工具，兼顾自然语言交互与精确过滤。实验显示工具增强的对话推荐在推荐行为丰富度与可控性上优于纯生成基线。

Key insight: 生成式推荐不必抛弃传统检索/过滤算子——让 LLM 以工具调用方式编排它们，可在保留语言交互能力的同时利用结构化元数据。对社区搜索的启示：面向对话式搜索可把 query 理解、属性过滤、召回封装为工具交由 LLM 调度，形成 agentic 的检索-重排统一管线，比端到端生成更可控、可解释，也更易复用既有搜索基础设施。

arXivKAIST2025-10-02Seungheon Doh, Keunwoo Choi, Juhan Nam
2. TalkPlayData 2: An Agentic Synthetic Data Pipeline for Multimodal Conversational Music Recommendation
3.25
Relevance 3 | Novelty 3 | Practical 4 | Evidence 3 | Timely 3

Summary: TalkPlayData 2 提出一个 agentic 合成数据流水线，为多模态对话式音乐推荐生成训练数据。流水线中多个 LLM 智能体被赋予不同角色与信息访问权限：Listener LLM 与 Recsys LLM 对话并记录日志，通过为每段对话设定不同场景覆盖多样化交互，产出可用于训练对话推荐模型的合成数据集。

Key insight: 用多智能体角色扮演 + 信息隔离来合成对话推荐数据，绕过真实对话日志稀缺与隐私问题。对搜索/推荐的启示：可借鉴「用户 LLM × 系统 LLM」对话日志生成范式，低成本构造对话式搜索/推荐的训练与评测语料；信息访问隔离的设计能让合成数据更贴近真实的信息不对称场景，提升下游模型的鲁棒性。

arXivKAIST2025-09-11Keunwoo Choi, Seungheon Doh, Juhan Nam
