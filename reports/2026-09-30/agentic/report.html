Post-Generation Verification Dominates Retrieval Optimization: A 2^4 Factorial Ablation of RAG Pipeline Features

论文把章节扩展、Agent 搜索、完整性检查和目录引导检索做成 2⁴ 全因子实验：16 种配置、24 个问题、两类模型，共 768 个条件。生成后完整性检查的效应量为 +0.48，单独启用得到 4.31/5，超过未启用检查的三功能组合 4.11；目录检索增益为 +0.22。

Relevance Is Not Sufficient Evidence: Detecting Evidence Gaps Before Generation in RAG

论文指出相关文段可能只提到正确实体，却没有回答所需事实；在证据不足的问题上，12 个生成器仍有 40.0%–99.3% 会给出答案。作者用替换、删除和问题交换构造成对测试，在生成前仅根据问题和证据判断支持是否充分，避免把弃答能力绑在生成模型权重上。

INSIGHT社区搜索的答案卡片应先检查检索证据是否真正包含结论所需事实，再交给生成器。可把“相关性高但证据缺口大”的样本单列评测，并在证据不足时触发定向补检或展示原始结果；这比单纯提高相似度阈值更贴近幻觉风险。

Suting Chen, Peichun Hua, Yunming Xiao

Follow the Entities: A Corpus Map for Agentic Search

论文针对多文档证据分散问题提出 CorpusMap，把语料中反复出现的实体组织成导航层，让搜索 Agent 从一篇文档沿实体关系找到互补材料。它避免每轮都在平铺文件集合中重新发现关联，目标是减少漏证与重复检索；当前候选摘要未提供可核对的量化结果。

INSIGHTUGC 搜索里的帖子、评论、作者和话题天然构成实体关系。可先构建轻量实体到文档的邻接表，检索命中后扩展相关评论或后续帖子，再比较多跳任务的证据召回、token 消耗和答案质量，避免无界扩展。

Socrates-RAG: Premise-Directed Inquiry against Coordinated Evidence Poisoning

Socrates-RAG 面对协同证据投毒，不只筛选初始检索集，而是维护相互竞争的答案，找出能区分它们的待验证前提，再用新增证据改写下一次查询。论文采用有限检索预算，并与普通相关性查询共享初始证据及两次查询、每次前三条结果的预算；候选摘要未给出最终准确率。

INSIGHT对争议性社区内容，可把检索目标从“找到更多同主题帖子”改为“寻找能证伪关键前提的证据”。系统需要记录候选答案、未决前提与来源冲突，在预算耗尽时允许弃答；评估应同时覆盖答案正确率和被操纵内容的传播率。

Renyu Zhao, Xinyuan Zou, Lanbin Liu

05 3.85

BITEM at the NTCIR-19 R2C2 Task: Predicting Confidence from Agentic RAG Pipeline Signals

BITEM 在 NTCIR-19 R2C2 中让 Agent 多轮检索、阅读并记录电影语料证据；编排器用蕴含检查控制可提交的主张，并根据运行轨迹计算置信度。每题运行三到四次且移除已见语料；两次检索提交在 22 队中排第 4 和第 5，合并轮次使 nDCG@20 增加 0.0709。

INSIGHT多轮社区问答可把证据记录和置信度计算交给可审计的编排层，而不是让生成模型自报把握。去重后的多轮检索对多跳问题尤其有用；落地时应限制轮数并记录每个结论的引用片段、蕴含结果和成本。

Julien Knafou, Luc Mottin, Alexandre Flament, Paul van Rijen, Esteban Gaillac, Patrick Ruch

Structured Interaction, Visual Localization, and Robust Execution for Complex Web Tasks: A Technical Report on the WebRetriever Challenge

WebRetriever Challenge 技术报告采用结构化网页交互优先，仅在语义页面信息不足时调用视觉定位，并结合网格辅助定位、分层上下文管理和故障感知执行。系统本地 Protocol 1 通过率最高 79%；官方 Protocol 3 在 8 个并发浏览器工作者下达到 59%，获得第一名。

INSIGHT面向站外内容采集或搜索任务，先使用 DOM 与语义控件，再按需启用视觉感知，可降低无谓的图像推理成本。分层压缩历史和失败恢复值得移植到长链路搜索 Agent；对 UGC 平台需单独验证动态页面和并发浏览器的稳定性。

Ziqi Zhang, Shaohui Li, Bing Li

Backdoor in the Loop: Compromising Agentic Search via Malicious Retrievers

论文研究恶意检索器如何在 Agentic RAG 的反复检索回路中影响后续决策：即便攻击者不能改写语料，仍可压制有效证据、反复推送指定文档或拖长搜索。作者还提出注入后再移除较弱后门的伪净化流程，以掩盖检测信号；候选摘要未列出可核对的成功率。

INSIGHT搜索 Agent 的安全边界应覆盖检索模型与索引版本，而非只检查文档内容。上线前可在固定查询集上监测证据覆盖、重复命中和检索轮数的异常变化，并保留可信检索器回退；尤其要关注第三方模型更新后成本和答案来源的漂移。

Asking for What Was Never Requested: Horizontal and Vertical Proactivity in Agents

论文将 Agent 主动补充信息分成横向与纵向两类：前者追查当前上下文可见但用户未明说的需求，后者根据先前证据发现新的信息缺口。作者用需求图评估问题是否覆盖必要证据，并提出 Q&D 训练提问器选择更有助于后续取证的问题；候选摘要未给出可核对的最终得分。

INSIGHT社区搜索中的模糊任务可能需要主动追问或补检隐含约束，例如时间、地点和帖子可信度。需求图可用于离线标注“该问什么、何时停止”，避免 Agent 为了显得主动而无限追问；上线应观察任务成功率与用户打断率。

《AgentScope 2.0实战指南》09 - RAG 检索增强生成

Alibaba

阿里云开发者社区给出 AgentScope 2.0 的 RAG 工程指南：把 PDF、Word、Markdown 解析切块、向量化后建立知识库，再通过 RAGMiddleware 接入 Agent。文章建议把 256–512 token 作为通用切块起点，并讨论多租户和动态更新；它是实施指南，未报告对照实验指标。

INSIGHT对社区帖子和评论，可借用中间件式接入方式，把检索能力作为 Agent 可调用工具，并保留来源溯源。256–512 token 只是文档类内容起点，UGC 短文本应按帖子及评论串结构重新调参；上线需测证据召回率、回答延迟和索引更新时效。

EpiCon: Collective Agent Learning through Co-Evolving Multimodal Memory

EpiCon 让多个 Agent 共享多模态经验库，无须更新宿主模型参数；两个独立训练的 2B 模型分别负责记忆控制和树形经验整理。论文在四类多模态任务、11 个基准和多个骨干模型上评估；更换运行框架后，原系统跨 11 个基准的宏平均分提高 2.6 分。

INSIGHT搜索 Agent 可借鉴“经验写入控制器 + 分层检索库”的设计，让历史查询改写、失败证据和有效工具序列成为可复用资产。由于该工作偏多模态通用任务，需先在社区搜索任务上验证迁移收益，并控制经验污染与持续存储成本。

Ziyun Zeng, Hang Hua, Shaden Alshammari, Rogerio Feris, William T. Freeman
