Detecting and Correcting Reference Hallucinations in Commercial LLMs and Deep Research Agents

该论文系统评估了 10 个商业 LLM 和深度研究 Agent 在引用 URL 生成中的幻觉问题。通过对 DRBench（53,090 条 URL）和 ExpertQA（168,021 条 URL，涵盖 32 个学科）的大规模实验，发现 3-13% 的引用 URL 为幻觉（从未存在），5-18% 无法解析。深度研究 Agent 虽然生成了更多引用但幻觉比例更高。论文提出了基于 Wayback Machine 的检测方法和自动修正策略，将引用有效率提升至 90% 以上。

Single-Agent LLMs Outperform Multi-Agent Systems on Multi-Hop Reasoning Under Equal Thinking Token Budgets

Contextual AI

该论文通过信息论中的数据处理不等式（Data Processing Inequality）从理论上论证了在等量推理 token 预算下，单 Agent 系统在信息保留方面优于多 Agent 系统。实验在多跳推理任务上验证了这一结论：当计算量标准化后，单 Agent 系统能匹配甚至超越多 Agent 系统（MAS），因为 Agent 间通信会导致信息压缩损失。

INSIGHT这是一个反直觉但极具实践意义的发现：多 Agent 架构的性能提升往往来自更多的计算资源而非架构优势。对搜索 Agent 系统设计的直接启示是，在固定延迟和成本预算下，应优先投资于单 Agent 的推理深度（如更长的思维链），而非盲目引入多 Agent 协作。这为 agentic search 系统架构选择提供了理论依据——简洁架构配合充分的推理预算可能优于复杂的多 Agent 编排。

Dat Tran, Douwe Kiela

Prompt Compression in the Wild: Measuring Latency, Rate Adherence, and Quality for Faster LLM Inference

该论文首次在真实 RAG 系统部署环境中系统评估了 prompt 压缩技术的延迟、压缩率遵从度和生成质量三方面权衡。研究指出，RAG 系统中检索到的长文段导致 prompt 过长成为推理延迟瓶颈。通过对多种压缩方法在实际工作负载上的测量，发现压缩预处理带来的额外开销在某些场景下可能抵消推理加速，需要针对具体延迟预算和质量要求做精细调优。

INSIGHT对搜索系统最直接的启示：prompt 压缩不是银弹。论文通过实测揭示了压缩率遵从度（实际压缩率 vs 目标压缩率）的差异，这在工程部署中常被忽视。对 RAG 搜索系统而言，应根据查询类型动态调整压缩策略——事实型查询可以激进压缩，而复杂推理查询需保留更多上下文。该工作为 Agent 搜索系统的延迟优化提供了实证基准。

Cornelius Kummer, Lena Jurkschat, Michael Färber, Sahar Vahdati

InfoSeeker: A Scalable Hierarchical Parallel Agent Framework for Web Information Seeking

UCL

该论文针对现有 agentic search 系统在大规模信息综合中的瓶颈（上下文饱和、级联错误传播、高端到端延迟），提出 InfoSeeker 框架。该框架采用分层并行架构，将信息搜索任务分解为层次化子任务，由并行 worker agent 执行检索和证据聚合，orchestrator agent 负责协调和综合，解决了数据密集型场景下的可扩展性问题。

INSIGHTInfoSeeker 直接解决了 agentic search 在工业级部署中最关键的痛点：当需要跨越大量异构数据源时，单一顺序推理 agent 会遇到上下文窗口溢出和延迟爆炸。分层并行的设计思路对社区搜索场景有很强的借鉴意义——例如，将用户复杂查询分解为多个子查询并行检索 UGC 内容，再由高层 agent 综合排序。相比纯深度推理的 agent，这种宽度优先的架构更适合数据密集型搜索。

Ka Yiu Lee, Yuxuan Huang, Zhiyuan He, Huichi Zhou, Weilin Luo, Kun Shao, Meng Fang, Jun Wang

Self-Optimizing Multi-Agent Systems for Deep Research

Zeta Alpha

该论文探索了深度研究系统中多 Agent 的自动优化方法。传统 Deep Research 系统依赖手工 prompt 和静态架构，改进成本高且脆弱。论文在 orchestrator-worker 架构基础上，测试了多种 Agent 优化方法（如 prompt 自动调优、架构搜索等），展示了通过自优化让系统自动改进 retrieval 和 synthesis 质量，降低人工调参依赖。

INSIGHT该研究的核心价值在于将 Deep Research Agent 从手工调优推向自动化优化。对搜索系统的启示：当构建复杂的 agentic 搜索管线时，与其投入大量人力微调每个 agent 的 prompt，不如建立自动优化循环。这与推荐系统中 AutoML/超参搜索的思路一致——让系统自身学习最优的检索策略和综合方式。论文的比较实验为选择 Agent 优化方法提供了实证参考。

Arthur Câmara, Vincent Slot, Jakub Zavrel

Terminal Agents Suffice for Enterprise Automation

该论文挑战了当前 agentic AI 领域的复杂化趋势，论证仅配备终端（terminal）和文件系统的编程 agent 即可完成大量企业自动化任务，无需 MCP (Model Context Protocol)、Web GUI agent 等复杂抽象。实验表明简单的终端 agent 在成本和可靠性上优于基于 MCP 和 Web 交互的复杂 agent 方案。

INSIGHT这是一篇极具实践指导意义的 agent 架构论文。核心观点是：在工具集成成本和运维复杂度面前，最简单的 agent 架构（terminal + filesystem）往往是最优选择。对搜索 Agent 系统的启示：不要过度工程化 Agent 的工具层——在很多场景下，让 Agent 通过简单的 API 调用和脚本执行即可完成检索和数据处理任务。MCP 等高级协议应在简单方案确实不足时才引入。

Patrice Bechard, Orlando Marquez Ayala, Emily Chen, Jordan Skelton, Sagar Davasam, Srinivas Sunkara

Failing to Falsify: Evaluating and Mitigating Confirmation Bias in Language Models

UUT Austin

该论文将心理学中经典的规则发现实验（Wason 2-4-6 任务）应用到 11 个 LLM 上，系统评估了确认偏误（confirmation bias）现象。研究发现所有 LLM 均展现出显著的确认偏误——倾向于搜索支持已有假设的证据而非尝试证伪。论文进一步提出了基于反事实提示和证伪引导的缓解策略。

INSIGHT这一发现对 agentic search 系统设计有深刻警示：当 LLM agent 在执行多步搜索推理时，天然倾向于检索和采纳支持其初始假设的信息，导致搜索结果偏向性。对搜索系统的实践启示是，agent 搜索管线中应显式引入证伪（falsification）机制——例如在生成搜索查询时同时生成支持和反对查询，或在综合阶段加入对立证据检查。这能有效提升搜索结果的全面性和客观性。

Ayush Rajesh Jhaveri, Anthony GX-Chen, Ilia Sucholutsky, Eunsol Choi

Textual Equilibrium Propagation for Deep Compound AI Systems

该论文解决了深层复合 AI 系统（包含 retriever、tool、verifier 等多模块的长 pipeline）中的端到端优化问题。发现 TextGrad 等基于文本反馈的全局优化方法在系统深度增加时性能退化，存在两种深度缩放失效模式：文本梯度爆炸（反馈文本随深度指数增长）和梯度内容漂移。论文提出 Textual Equilibrium Propagation (TEP)，通过局部文本反馈传播实现稳定优化。

INSIGHT这是一个解决复合 AI 系统（如 RAG + Agent + 验证器组成的搜索管线）核心优化难题的方法。关键发现是全局文本反馈在深层 pipeline 中会失效，局部传播策略更为稳健。对搜索 Agent 系统的启示：当构建多阶段 agentic search pipeline（查询理解 → 检索 → 精排 → 综合 → 验证）时，不应使用端到端的文本反馈优化全链路，而应采用分阶段的局部优化策略。TEP 为长链路 Agent 系统的训练和调优提供了新范式。

Minghui Chen, Wenlong Deng, James Zou, Han Yu, Xiaoxiao Li

APEX-EM: Non-Parametric Online Learning for Autonomous Agents via Structured Procedural-Episodic Experience Replay

该论文解决 LLM Agent 缺乏持久过程记忆的问题——agent 每次遇到结构相似的任务都从头推理。APEX-EM 提出非参数化在线学习框架，在不修改模型权重的前提下，积累、检索和复用结构化的过程性计划。核心组件包括：(1) 编码完整过程-情节轨迹的结构化经验表示；(2) 基于相似度的经验检索机制；(3) 质量评分驱动的经验筛选。

INSIGHT对搜索 Agent 系统的直接价值：让 agent 从历史搜索交互中学习并复用成功的检索策略。例如，当用户发起类似的复杂查询时，agent 可以直接调用之前成功的查询分解和检索路径，而无需每次重新推理。这种非参数化的经验记忆方案无需重新训练模型，适合在线部署。对 UGC 搜索场景，可记忆特定类型查询的最优检索策略组合。

Pratyay Banerjee, Masud Moshtaghi, Ankit Chadha

ProGraph-R1: Progress-aware Reinforcement Learning for Graph Retrieval Augmented Generation

ProGraph-R1 提出进度感知的强化学习框架用于图检索增强生成（Graph RAG）。该方法训练 agent 在 LLM 与知识图谱之间进行迭代交互，通过 RL 优化 agent 的检索决策——何时检索、检索什么、何时停止。进度感知机制让 agent 能评估当前推理进展并据此调整后续检索策略。

INSIGHTGraph RAG 与强化学习的结合为 agentic search 提供了新思路。进度感知机制的核心价值在于让 agent 学会自适应检索——不是固定步数的检索，而是根据当前信息充足度动态决定。对搜索系统的启示：在复杂查询的多轮检索中，引入类似的进度评估机制可以平衡检索质量和延迟——信息足够时提前终止，不足时追加检索。该方法虽针对知识图谱场景，但核心思路可迁移至文本检索中的自适应 RAG。
