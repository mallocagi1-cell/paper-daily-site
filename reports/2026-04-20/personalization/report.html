GenRec: A Preference-Oriented Generative Framework for Large-Scale Recommendation

深度解读：GenRec

1. 问题与动机

GenRec 关心的不是生成式推荐在公开小数据上能否跑通，而是它为何在亿级互动、翻页请求和严格延迟约束下容易失效。作者在京东首页信息流归纳了三个具体断点。第一，一次翻页会产生多个点击或成交，但传统 point-wise NTP 把相同历史分别配上不同正标签，迫使模型在同一前缀上拟合均匀混合分布，导致梯度方差增大、单物品概率被稀释。第二，一个物品用 3 个语义 ID 表示时，长行为序列的 item token 部分会膨胀到原来的 3 倍，prefill 延迟成为线上瓶颈。第三，真实点击与成交稀疏，直接用稠密奖励模型做 RL 又会诱导模型生成形式合法但语义无关的 SID 组合，出现 reward hacking。这些问题在摘要中只是三个名词，正文则用 5.6 亿条用户互动序列和一个月线上实验证明，训练目标、推理表示与业务奖励必须联合设计。

2. 方法详解

物品端先用 Qwen2.5-VL 联合编码图像外观和文本描述，再用领域内协同样本微调 embedding，使连续表征不只重建内容，还包含点击与购买相似性。随后用 residual-quantization K-means 逐级聚类残差，把每个物品映射成分层 SID 三元组。主干选用 decoder-only Qwen2.5，实验覆盖 1.5B、3B 和 7B 三种规模。

SFT 阶段的核心是 Page-wise NTP（PW-NTP）。给定页面到达前的用户历史，目标不再是单个物品，而是当页交互物品列表，并按成交、点击、曝光等交互强度组织成序列。损失仍是对完整响应序列的标准自回归负对数似然，但每次前向同时获得多个正样本信号，消除相同输入对应多个独立标签的基数错配。服务时却不输出整页，而是保留产线的 point-wise beam search，每个 query 生成 beam width 个物品；这种训练—推理非对称是有意的，训练获得稠密梯度，推理与已有候选管线兼容。

Token Merger 只在 prefill 侧压缩。它拼接同一物品的 3 个 SID embedding，通过一层线性投影变成单个潜向量；<sep> 等结构 token 保持不变。因为解码端仍按原始 SID 粒度生成，这是一种非对称压缩：历史读取成本减半，生成空间和训练目标不被粗化。

RL 阶段的 GRPO-SR 与线上 beam search 对齐，每个 rollout 只生成一个物品序列，在同组多个候选之间学相对优势。SIM 类奖励模型输出稠密偏好分，相关性 gate 把语义无关结果压到小常数；若候选命中真实成交或点击集，其奖励被校准为当组最大值，避免奖励模型低估真实正反馈。最终目标一部分是 group-relative policy loss，另一部分是正轨迹的 NLL 正则。作者特意不用普通 KL 拘束：NLL 直接把策略锚定在真实用户行为上，更能抑制奖励过度优化。数据是京东大型推荐平台一个月的约 5.6 亿条用户互动序列，最后一天作测试，其余训练。三个模型均在 8 张 NVIDIA H100 上分布式训练，优化器为 AdamW，前 1% 步数线性 warm-up，之后 cosine decay；论文未披露 batch size、总步数和精确学习率。

3. 核心技术贡献

第一，PW-NTP 把生产翻页机制本身变成监督单元。它改进的不是更大的 backbone，而是标签结构：一次前向学整页正例，因此比 LC-Rec 的 point-wise NTP 收敛更快，并将无效 SID 幻觉率从 7.80% 降到 4.96%，相对降幅超过 36%。

第二，非对称 Token Merger 把“长历史贵”和“细粒度生成有用”拆开处理。去掉 Merger 后 HR@10 只从 0.4456 变为 0.4467、NDCG@10 从 0.2635 变为 0.2653，质量差异极小，而输入 token 长度约减半，说明压缩主要去除了冗余而非有用信息。

第三，GRPO-SR 把点击/成交真值、稠密偏好模型与语义合法性 gate 组成混合奖励，再用 NLL 约束守住行为分布。完整 GRPO-SR 相对 SFT 在 Reward@1 上提升 18.01%，同时将 HaR 从 4.96% 降至 2.68%；普通 GRPO 反而将 HaR 推高到 6.03%，说明工业 RL 不能只看奖励均值。

第四，论文给出了容量选择的反直觉结论。3B 模型有 36 层、2048 隐层宽度，7B 只有 28 层、3584 宽度；从 1.5B 到 3B 的收益明显，但 3B 到 7B 参数增加约 2.3 倍后，NDCG@10 仅从 0.2635 到 0.2649。对推荐互动建模，深度可能比宽度更有容量密度，不应盲目追求更大参数。

GenRec 相对 LC-Rec 的 NDCG@10 提升约 22.8%，HR@10 提升约 21.5%；同为 Qwen2.5 3B 的对照使收益更能归因于 PW-NTP 和框架设计，而非单纯增参。规模实验中，1.5B/3B/7B 的 HR@10 分别为 0.4103/0.4456/0.4483，NDCG@10 为 0.2484/0.2635/0.2649；3B 是明显的效率拐点。RL 消融更关键：SFT、GRPO、GRPO-SR 的 HR@50 为 0.7192、0.7248、0.7438，HaR 为 4.96%、6.03%、2.68%。去掉相关性 gate 后，GRPO-SR 的 HR@50 降至 0.7016，表明奖励模型会被利用，看似更高的局部奖励不等于更好的召回。

线上 A/B 在京东首页 Feed 持续一个月，SFT 和 RL 版本各承接 10% 流量。基础 SFT 使曝光率提高 48.7%、点击数提高 8.5%、成交数提高 7.3%；加入 GRPO-SR 后三项变为 57.3%、9.5%、8.7%。对长尾物品，曝光、点击、成交分别提升 10%、16%、13%，说明语义 ID 与偏好对齐不只改善热门物品。结果也有一个值得警惕的模式：曝光增幅远大于点击和成交，上线时应同时监控曝光扩张是否稀释单次效率。论文表示完整 GRPO-SR 版本已全量生产部署。

5. 局限与未来方向

论文没有独立 Limitations 章节。作者在结论中明确把未来方向放在框架的 reasoning 能力，意味着当前 GenRec 仍是偏好对齐的物品生成器，并未展示可审计的多步理由。正文可确认的边界还包括：只在京东一个大型平台验证，数据不公开；未披露奖励模型精确结构、gate 阈值、beam width、batch size、学习率、训练步数、线上延迟与算力成本，外部团队无法完整复现。论文也没有报告多样性、公平性、用户留存或长期满意度，而且大曝光增幅可能改变整体供给分布。作者未明说的限制是，以交互强度安排页内目标顺序可能把业务价值偏好写入序列位置，在社区内容、新闻或知识推荐中需重新校准。

6. 工业实践意义

对社区 UGC 搜索与推荐，最值得先实验的不是直接上 7B，而是三个可拆分的设计。第一，把一页搜索结果或 Feed 中的点击、长停留、收藏、评论组成 page-wise 目标，并在线下对比 point-wise 训练的 NDCG、无效 ID 率和收敛速度。第二，若帖子用多级语义 ID 编码，可仅在历史 prefill 合并 ID embedding，保留解码粒度；这比全链路减少 SID 层级的可逆性更好。第三，RL 奖励必须有硬的相关性/合法性 gate 与行为 NLL 锚点，否则应同时上升的不是 CTR，而是幻觉率。

实施路线可分四阶段：先在现有候选集上训练 1.5B 或 3B PW-NTP 对照；再加 Token Merger 测量 prefill token 数、P95/P99 延迟与 HR 损失；第三阶段只做离线 GRPO-SR，绘制 reward—HR—HaR 三维曲线；最后以小流量分别验证 SFT 和 RL，不要一次合并实验。容量上应优先 3B：论文中 7B 比 3B 的 NDCG@10 只多 0.0014，但参数约 2.3 倍。监控除点击和成交外，还要包含 SID 无效率、长尾曝光集中度、重复物品率、新内容冷启动、用户负反馈和单请求成本。这篇论文最具价值的信息是：生成式推荐的工业上限不只由模型规模决定，更由页级标签结构、输入压缩位置和奖励防黑客机制共同决定。

Decoupled Multimodal Fusion for User Interest Modeling in Click-Through Rate Prediction

LazadaAlibaba📖 有深读 · 8 分钟

提出 DMF（Decoupled Multimodal Fusion）方法，增强 ID 协同表征与多模态表征之间的细粒度交互。核心设计包括 target-aware 特征桥接不同嵌入空间的语义鸿沟，以及解耦注意力机制降低计算开销。在 Lazada 电商平台实际部署，CTCVR 提升 5.30%，GMV 提升 7.43%。已被 ICDE 2026 录用。

INSIGHTDMF 的核心贡献在于解决多模态推荐中 ID 特征与内容特征的「语义鸿沟」问题——通过 target-aware 特征构建让两类表征在目标 item 维度上对齐。这对 UGC 搜索场景有直接启示：用户搜索行为（ID 特征）与帖子内容（文本/图片特征）之间也存在类似的表征脱节问题。解耦注意力设计将多模态融合的额外推理开销控制在可接受范围内，适合在线服务部署。

1. 问题与动机

工业推荐系统中，多模态信息（商品图片、文本描述）蕴含丰富的语义信号，但如何将其有效融入 ID-based CTR 预测模型是一个长期挑战。现有方法存在两个根本性问题：语义鸿沟——ID 协同表征和多模态表征处于不同的嵌入空间，直接拼接或简单融合会造成信息错位，模型难以建立 ID 行为模式与内容语义之间的细粒度关联；计算瓶颈——当融合机制需要感知「目标 item」（target-aware）时，每个候选 item 都要重新计算融合后的表征，在工业场景中（1000+ 候选）计算量呈线性膨胀。作者指出现有的 modality-centric 策略「孤立地处理 ID 和多模态信号，无法捕捉行为动态与内容语义之间的细粒度交互」。Lazada 电商平台需要一种既能充分利用多模态信号又不显著增加推理延迟的方案。

2. 方法详解

DMF（Decoupled Multimodal Fusion）框架包含三个核心模块：

Target-Aware 多模态相似度特征提取：使用冻结的 Vision Transformer 和 RoBERTa 分别提取视觉和文本特征，通过对比学习融合为 128 维多模态向量。计算目标 item 与历史交互 item 之间的余弦相似度：c_j = (m_c^T · m_j) / (||m_c|| · ||m_j||)，得到长度为 L 的相似度序列。

Decoupled Target Attention (DTA)：这是论文的核心创新。传统 early fusion 将 ID embedding 和相似度分数拼接后投影为 Key/Value，导致所有计算依赖目标 item（target-aware），需要对 B 个候选各计算一次，复杂度 O(2BLd²)。DTA 将计算解耦为两条路径：(1) target-agnostic ID pathway：K_id = S·W_k^T，V_id = S·W_v^T，仅需计算一次，跨所有候选复用；(2) target-aware multimodal pathway：将连续相似度分数 c_j ∈ [-1,1] 离散化到 M=35 个桶，每个桶有可学习的 embedding e_m^K 和 e_m^V，通过查表（O(1)）获取多模态修正。最终 K_DTA = K_id + E_sim^K，V_DTA = V_id + E_sim^V。理论证明（Theorem 1）：当桶数 M 足够大时，离散化逼近可达到任意精度 ε。在 B=1000, L=400, d=128 的工业设定下，DTA 相比 early fusion 实现约 100 倍 FLOPs 降低（13.10 GFLOPs → 0.13 GFLOPs）。

Complementary Modality Modeling (CMM)：融合两种互补的用户表征。Modality-Centric (r_mc)：将相似度分数构造为直方图特征（将 [-1,1] 均分为 N 个区间统计频次），经 MLP 编码，提供不依赖具体 ID 的语义泛化能力。Modality-Enriched (r_me)：DTA 的输出，整合了 ID 信号和多模态上下文。最终用户表征 r_u = α·r_me + (1-α)·r_mc，α 控制个性化与泛化的权衡。

训练设置：二元交叉熵损失，Adam 优化器，ID embedding 维度 32/128，注意力 4 头，工业数据集 batch size 1024，M=35 个离散化桶。

3. 核心技术贡献

解耦注意力设计（DTA）：将 target-aware 计算从线性投影转化为查表操作，在理论上保证近似精度的同时实现 100 倍 FLOPs 降低。这是多模态 CTR 预测领域中「效率-精度」困境的首个系统性解决方案。相比 early fusion（TA_early），DTA 在精度上仅差 0.01% AUC，但吞吐量提升 3 倍。

互补建模策略（CMM）：揭示了多模态融合中的关键规律——短行为序列用户（L≤10，占 Amazon 数据集 84.75%）更受益于 modality-centric 泛化（α_opt=0.3），长行为序列用户（L>10，占工业数据集 89.35%）更受益于 modality-enriched 个性化（α_opt=0.7）。

Target-Aware 相似度特征：相比直接使用多模态 embedding 拼接，相似度分数提供了更紧凑且可解释的 target-aware 信号。案例分析显示 DTA 能正确识别语义相关但不热门的历史行为（如「柚木展示柜」vs 目标「柚木组合柜」的注意力权重从 0.2127 提升到 0.6586），有效克服热门偏差。

4. 实验结果分析

离线对比（Amazon 数据集）：DMF 达到 AUC 0.8251，比最强基线 MAKE 高 1.06%，比 DIN 高 4.45%。在工业数据集上，DMF AUC 0.6663，GAUC 0.6177。

DTA 消融：

结果表明：early fusion 精度最优但计算不可行；late fusion 损失信息过多；DTA 在精度和效率间取得最佳平衡。

α 敏感性分析：Amazon 数据集最优 α=0.3，工业数据集最优 α=0.7。这一差异与用户行为序列长度分布高度相关：Amazon 用户行为序列较短，需要更多语义泛化；Lazada 用户行为序列较长，ID-based 个性化信号更丰富。

线上 A/B 测试（Lazada 泰国市场，12 天）：CTCVR 提升 5.30%，GMV 提升 7.43%。作者指出「资源成本的增加相比业务收益微乎其微，证明了 DMF 的投资回报率和可部署性」。

5. 局限与未来方向

作者未设专门的局限性章节，但论文中隐含以下限制：(1) 依赖冻结的预训练多模态编码器（RoBERTa、ViT），编码器质量直接影响效果；(2) 离散化桶数 M=35 为经验设定，论文未讨论桶数敏感性；(3) α 参数需要针对不同数据集调优，全局统一的 α 无法适配不同活跃度的用户群体——作者暗示未来可研究 activity-aware 的自适应融合策略；(4) 仅探索了余弦相似度，其他相似度度量或多模态融合策略未涉及。

6. 工业实践意义

DMF 为搜索推荐系统的多模态融合提供了高效可行的工程方案。DTA 的解耦设计是最值得借鉴的技术：在 UGC 搜索场景中，帖子的文本/图片特征与用户历史搜索行为之间同样存在 target-aware 融合需求，DTA 的离散化查表策略可直接迁移，将 target-aware 注意力的复杂度从 O(B) 降至 O(1)。

CMM 的互补建模揭示了一个重要的实践规律：对低活跃用户（新用户、低频用户），多模态语义泛化更有效；对高活跃用户，ID-based 个性化更有效。这意味着工业系统应根据用户活跃度动态调整融合策略，而非使用统一的融合权重。

部署考量方面，DMF 在 Lazada 的落地表明额外的多模态推理开销可通过水平扩展吸收，不增加端到端延迟。对于需要快速迭代的团队，直接使用冻结的预训练多模态编码器（无需微调）降低了落地门槛。相似度离散化的设计也便于在线服务的 KV 缓存优化。
