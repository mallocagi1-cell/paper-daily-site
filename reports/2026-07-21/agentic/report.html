1. PCTD: Preference-Guided Counterfactual Task Decomposition for Agent Tool Retrieval
4.40
Relevance 5 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 针对复杂指令拆解后进行 Agent 工具检索时，直接用 Recall 或 nDCG 作强化学习奖励会诱发重复拆解与奖励投机，论文提出 PCTD。它用反事实奖励估计任务拆解对检索排序的边际因果增益，并以偏好奖励约束逻辑连贯性和原子性；在新建的移动端多轮交互 MTDTool 基准上，同时提升检索、拆解质量与未见工具的域外泛化。

Key insight: 工具检索优化不能只追逐表面排序指标，否则模型会学会复制子任务等捷径。社区搜索 Agent 若要把用户复合意图拆成查询、筛选和工具调用步骤，可借鉴“反事实增益＋结构偏好”双奖励：前者确认拆解是否真正改善候选排序，后者约束步骤可执行且不重复，从训练目标层面提升新工具和新场景泛化。

2. Agentic Deep Research: How LLM Search Agents Plan, Retrieve, and Synthesize Across Dozens of Sources
4.20
Relevance 5 | Novelty 3 | Practical 5 | Evidence 3 | Timely 4

Summary: 文章从生产系统视角拆解深度研究 Agent 如何规划问题、跨数十个来源迭代检索、压缩上下文、核验证据并生成带引用的结论。它强调“给 LLM 接一个搜索工具”并不等于研究 Agent，真正的工程难点在于多轮错误传播、来源可信度、上下文预算、延迟和成本的联合控制，并给出可落地的编排模式与常见失败点。

8. EpiNarrate: Agentic Generation of Grounded Narratives from Epidemiological Scenario Projections
3.55

Summary: EpiNarrate 解决大模型直接总结大规模流行病情景投影时数字不一致、维度遗漏和行为脆弱的问题，将结构化数值推理与自然语言生成分离。系统先抽取干预、地域、人口、时间和不确定性等情景轴并构建偏序结构，再由 Agent 按可验证的中间表示生成有依据的叙事，从而在多维集合数据上维持数字与上下文一致。
