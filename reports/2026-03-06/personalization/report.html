Scaling Laws for Reranking in Information Retrieval

首次系统研究重排序模型的 Scaling Law，覆盖 pointwise、pairwise、listwise 三种范式。实验表明 NDCG 和 MAP 等指标随模型规模增长遵循可预测的幂律关系，可用小模型实验预测大模型性能。

KEY INSIGHT · 对业务意味着什么排序模型的 scaling 行为具有可预测性——用 400M 参数以下的模型即可准确预测 1B 参数模型的 NDCG 表现。这为搜索排序模型的 scaling 规划提供了实用的成本预估方法。业务关联 社区搜索的排序模型从小到大扩展时，可利用本文的 scaling law 做资源预算和模型选型，避免盲目堆参数。对 nDCG 指标的 scaling 预测直接适用于 UGC 搜索排序优化。证据 在 MSMARCO 和 TREC DL 等标准基准上，使用 6 种规模（70M~1B 参数）的 cross-encoder 模型验证。NDCG@10 的 scaling 预测误差低于 2%，MAP 同样遵循幂律。listwise 方法在大规模时优势更明显。

Debiasing Sequential Recommendation with Time-aware Inverse Propensity Scoring

提出 Time-aware Inverse Propensity Scoring (TIPS) 方法来去除序列推荐中的选择偏差和曝光偏差。传统序列推荐模型只关注点击/购买等显式交互，忽略了已曝光但未点击的物品信息，导致模型误判用户偏好。TIPS 作为即插即用模块，可增强现有序列推荐模型。

INSIGHT序列推荐中存在两种被忽视的偏差：选择偏差（将曝光未点击误解为不感兴趣）和曝光偏差（将未曝光物品视为不相关）。TIPS 通过建模时间依赖的倾向性分数来同时纠正这两种偏差，且不改变原有模型架构。

业务关联社区搜索场景中，用户浏览行为天然存在曝光和选择偏差。本文的去偏方法可直接应用于基于用户行为序列的 CTR 预估模型，提升推荐准确性，尤其适用于搜索结果的个性化重排序。

证据在多个公开推荐数据集上验证，TIPS 作为插件增强 SASRec、GRU4Rec 等主流序列推荐模型时，性能一致性提升。实验覆盖了不同偏差程度的场景，展示了方法的鲁棒性。

Sirui Huang, Jing Long, Qian Li, Guandong Xu, Qing Li

Efficient Sequential Recommendation for Long Term User Interest Via Personalization

提出一种高效的长期用户兴趣建模方法，将长用户行为序列压缩为可学习的 token，再与近期交互组合生成推荐。该方法可直接应用于 HSTU 和 HLLM 等主流序列推荐模型，在大幅降低计算成本的同时保持推荐精度。

INSIGHT长期用户行为序列的压缩不需要复杂的注意力机制——通过个性化的可学习 token 即可有效编码长期兴趣。这使得 Transformer 类推荐模型能够在工业级规模下高效利用完整用户历史。

业务关联社区搜索中用户历史行为序列往往很长（搜索、浏览、点击），直接建模计算开销大。本文的压缩方法可嵌入现有 CTR 模型，以低成本捕获长期兴趣，改善个性化搜索排序。

证据在 ICDM 2025 发表，适用于 HSTU 和 HLLM 模型。实验显示计算成本大幅降低，推荐精度损失极小。代码已开源，工业可复现性强。

Think-While-Generating: On-the-Fly Reasoning for Personalized Long-Form Generation

提出 FlyThinker 框架，在长文本生成过程中动态推理用户偏好，而非生成前一次性推理。通过独立的推理模型提供 token 级别的个性化引导信号，实现生成与推理的并行执行，既保证个性化质量又不增加延迟。发表于 ICLR 2026。

INSIGHT个性化生成中「先想后说」的静态推理范式在长文本场景会失效——用户偏好需要在生成过程中动态捕获。FlyThinker 将推理与生成解耦为双流架构，推理流程不阻塞生成流程。

业务关联社区搜索中 LLM 辅助的个性化内容推荐和摘要生成正变得越来越重要。本文的动态个性化推理方法可用于搜索结果的个性化摘要展示，根据用户偏好实时调整呈现方式。

证据ICLR 2026 会议论文，在 LaMP 和 LongLaMP 等真实个性化生成基准上验证。相比 think-then-generate 方法，FlyThinker 在长文本场景的个性化得分显著提升，同时推理延迟与非个性化生成持平。

Chengbing Wang, Yang Zhang, Wenjie Wang, Xiaoyan Zhao, Fuli Feng, Xiangnan He, Tat-Seng Chua

LBM: Hierarchical Large Auto-Bidding Model via Reasoning and Acting

提出分层大型自动出价模型 LBM，结合语言模型推理能力和动作生成来优化广告竞价。高层推理组件负责策略规划，低层动作生成器负责出价执行。通过双嵌入机制融合语言和数值两种模态输入，并采用专用微调技术减少 LLM 幻觉。

INSIGHT将 LLM 的推理能力引入广告出价系统，通过分层架构实现「思考」与「行动」的分离。高层模型理解竞价语境和广告主目标，低层模型生成具体出价决策，避免了端到端黑盒模型的不可解释性问题。

业务关联社区平台的广告系统需要智能出价来优化 CTR 和转化率。LBM 的分层推理+行动架构为广告排序和出价策略提供了新思路，尤其适用于需要理解复杂业务约束的场景。

证据在动态广告环境中测试，LBM 在泛化能力和训练效率上优于纯 offline RL 和生成式方法。实验展示了双嵌入机制对数值输入理解的提升效果。

Yewen Li, Zhiyi Lyu, Peng Jiang, Qingpeng Cai, Fei Pan, Bo An, Peng Jiang

PrefDisco: Benchmarking Proactive Personalized Reasoning

提出 PrefDisco 评测框架，衡量 LLM 在无用户历史（冷启动）条件下主动发现并适应个体偏好的能力。构建了基于心理学的 persona 评测集，定义了 PrefAlign 细粒度偏好对齐指标。测试 21 个前沿模型，发现近 30% 的朴素个性化尝试反而不如通用回复。

INSIGHT冷启动场景下的个性化推理不会自然涌现——即使是最强的 LLM 也经常在个性化尝试中「帮倒忙」。这意味着推荐系统在用户冷启动时不能简单依赖 LLM 的通用能力，需要专门的偏好发现机制。

业务关联社区搜索中新用户冷启动是核心挑战。本文揭示了 LLM 在无历史信息时个性化推理的局限性，对设计 LLM 辅助的冷启动推荐策略有直接参考价值，避免过度依赖 LLM 的「猜测」能力。

证据测试了 21 个前沿 LLM（包括 GPT-4、Claude 3 等），在 10 个任务上使用 PrefAlign 指标评估。定量发现 ~30% 个性化回复的质量低于通用回复。论文 65 页，实验详尽。

Knowledge-informed Bidding with Dual-process Control for Online Advertising

提出 KBD（Knowledge-informed Bidding with Dual-process control）方法，将人类专家知识作为归纳偏置嵌入到广告出价模型中。采用 Decision Transformer 全局优化多步出价序列，并实现快速规则式 PID 控制（System 1）与 DT 决策（System 2）的双过程融合。

INSIGHT广告出价中纯数据驱动的黑盒模型在稀疏数据和分布外场景下容易失效。通过将人类出价经验编码为先验知识（informed ML），结合快慢双系统决策，可显著提升泛化能力和分布外适应性。

业务关联社区平台的广告变现需要高效的出价策略。KBD 的双过程控制思想可推广到搜索广告的竞价排序中——快速系统处理常规出价，慢速系统处理复杂竞争场景，兼顾效率和效果。

证据在在线广告模拟环境中验证，KBD 在泛化性和分布外适应性上优于纯 offline RL 方法。Decision Transformer 的序列建模能力在多步出价优化中表现突出。

Huixiang Luo, Longyu Gao, Yaqi Liu, Qianqian Chen, Pingchun Huang, Tianning Li

Towards Unified Multi-Modal Personalization: Large Vision-Language Models for Generative Recommendation and Beyond

提出使用大型视觉语言模型（VLM）实现统一的多模态个性化推荐。将用户偏好建模与多模态内容理解整合到单一生成式框架中，支持图文混合的个性化推荐场景。探索了 VLM 在推荐系统中超越传统 ID-based 和文本-based 方法的潜力。

INSIGHT推荐系统的个性化不应局限于 ID 或文本——多模态内容（图片+文字）才是用户决策的真实依据。VLM 可以统一建模视觉和语言偏好，实现「所见即所推」的个性化体验。

业务关联社区 UGC 内容天然是多模态的（图文帖子、视频截图等）。本文的 VLM 推荐方法为 UGC 搜索的个性化排序提供了新方向——利用多模态理解能力提升推荐相关性，而非仅依赖文本匹配。

证据在电商和时尚推荐数据集上实验，VLM 方法在多模态推荐任务上显著优于传统 ID-based 和纯文本 LLM-based 方法。支持图文联合的个性化推荐。

VISA: Value Injection via Shielded Adaptation for Personalized LLM Alignment

提出 VISA 框架，通过屏蔽式适配实现 LLM 的个性化价值对齐。解决微调时 LLM 价值系统漂移（alignment tax）问题：模型在任务适配过程中会吸收训练数据的隐性偏差，导致价值表达偏移和幻觉增多。VISA 通过价值检测、语义到价值转换器和 GRPO 训练实现精细化价值控制。

INSIGHTLLM 微调存在「对齐税」——为了任务性能付出价值一致性的代价。VISA 通过隔离价值层和任务层，实现「改任务不改价值」的精准适配。这对需要个性化但又不能偏离核心价值的场景至关重要。

业务关联社区平台需要 LLM 提供个性化服务的同时保持内容安全和价值一致性。VISA 的屏蔽式适配思路可应用于搜索结果的个性化呈现——根据用户偏好调整展示方式，但不改变内容安全准则。

证据实验表明 VISA 在价值对齐方面优于标准微调和包括 GPT-4o 在内的基线方法，同时保持事实一致性和通用能力。使用 GRPO 训练的核心价值重写器展示了精准的价值控制能力。

Jiawei Chen, Tianzhuo Yang, Guoxi Zhang, Jiaming Ji, Yaodong Yang, Juntao Dai

Knowledge Graph-Based Multi-Objective Optimization Recommendation Model

提出基于知识图谱的多目标优化推荐模型，同时优化新颖性、多样性、准确率和召回率四个推荐目标。基于用户行为偏好和物品关联特征构建偏好集合，改进多目标优化算法实现四目标帕累托最优。

INSIGHT推荐系统不能只关注准确率——新颖性和多样性同等重要。基于知识图谱构建的用户偏好集合可以为多目标优化提供更丰富的先验信息，实现四目标的同时优化。

业务关联社区搜索需要平衡准确性和内容多样性，避免信息茧房。本文的四目标（准确率、召回率、新颖性、多样性）优化框架直接适用于 UGC 搜索结果的多维度排序策略设计。

证据在推荐数据集上验证，多目标优化方法在新颖性和多样性指标上显著优于单目标方法，同时保持接近最优的准确率和召回率。帕累托前沿分析展示了四目标间的平衡关系。

Hua Pang, Long Wang
