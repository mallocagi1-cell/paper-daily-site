From Exact Hits to Close Enough: Semantic Caching for LLM Embeddings

本文系统研究了 LLM embedding 的语义缓存问题。证明最优离线语义缓存策略是 NP-hard 的，并提出多种多项式时间启发式算法。同时设计了结合最近性、频率和局部性的在线语义缓存策略。

INSIGHT语义缓存打破了传统精确匹配缓存的假设，相似但不完全相同的请求也可以复用。对搜索系统中的 embedding 服务来说，可显著降低重复查询的计算开销。

业务关联社区搜索中大量用户查询存在语义相似性，语义缓存可直接应用于 embedding 推理服务，降低延迟和计算成本。

证据在多个多样化数据集上评估，语义缓存命中率显著优于传统精确匹配缓存。论文提供了离线最优策略的 NP-hard 证明和多种在线启发式的对比实验。

Dvir David Biton, Roy Friedman

ChatRetriever: Adapting Large Language Models for Generalized and Robust Conversational Dense Retrieval

提出 ChatRetriever，利用 LLM 的强泛化能力来鲁棒地表示复杂的多轮对话会话，用于稠密检索。通过对比学习适配 LLM 做检索，结合 masked instruction tuning 增强复杂会话理解。

INSIGHTLLM 的对话理解能力可以直接迁移到检索任务中。通过 dual-learning（对比学习 + 指令微调）适配 LLM 做稠密检索，比传统 query rewriting 更直接有效。

业务关联社区搜索中用户查询往往简短且上下文依赖，ChatRetriever 的多轮理解能力可提升对模糊、简短 query 的检索效果，尤其适合连续搜索和追问场景。

证据在 QReCC、TopiOCQA、TREC CAsT 等 5 个对话搜索基准上全面超越此前 SOTA，MRR 和 Recall@100 均有显著提升。

Kelong Mao, Chenlong Deng, Haonan Chen, Fengran Mo, Zheng Liu

04 3.65

ConvMix: A Mixed-Criteria Data Augmentation Framework for Conversational Dense Retrieval

针对对话式搜索中训练数据稀缺的问题，提出 ConvMix 框架，通过混合多种标准的数据增强方法来提升对话稠密检索模型。覆盖了比现有数据增强方法更多的维度。

INSIGHT对话检索的数据增强不应只关注单一维度，多标准混合增强（覆盖 query 变体、文档变体、负样本挖掘等）能更全面地提升模型鲁棒性。

业务关联社区搜索的训练数据标注成本高，ConvMix 的多维度数据增强策略可直接用于扩充搜索训练集，提升短文本检索模型的效果。

证据在多个对话搜索基准上验证，数据增强后的检索器在 Recall@100 和 MRR 上均有稳定提升，证明了混合增强的有效性。

Fengran Mo, Jinghan Zhang, Yuchen Hui, J. Sun, Zhichao Xu

MMTEB: Massive Multilingual Text Embedding Benchmark

推出 MMTEB，覆盖 500+ 评估任务、250+ 语言的大规模多语言文本 embedding 基准。包含指令跟随、长文档检索、代码检索等新任务类型，发现 560M 参数的 multilingual-e5-large-instruct 在公开模型中表现最佳。

INSIGHTembedding 模型的选择不应只看英文基准。MMTEB 提供了迄今最全面的多语言评估框架，且小模型（560M）也能胜出，说明 embedding 模型不一定越大越好。

业务关联社区搜索需要高质量的多语言 embedding 模型，MMTEB 可直接用于指导 embedding 模型选型，且其发现（小模型可能更优）对部署成本控制有参考价值。

证据评估覆盖 500+ 任务、250+ 语言，对比了 20+ embedding 模型。560M 参数的 multilingual-e5-large-instruct 在公开模型中排名第一，超越多个更大的模型。

Kenneth Enevoldsen, Isaac Chung, Imene Kerboua et al.

Retrieval or Representation? Reassessing Benchmark Gaps in Multilingual and Visually Rich RAG

重新评估多语言和视觉丰富文档 RAG 中检索方法的表现差距。发现通过改进文档表示（如更好的 OCR 和 layout 解析），传统 BM25 在部分场景下可接近甚至超越端到端多模态检索器。

INSIGHT检索效果的提升不一定来自更复杂的模型。改善文档表示质量可能比换用更大的 embedding 模型更有效。启示是：先优化数据质量再优化模型。

业务关联社区搜索中 UGC 内容格式多样，本文关于文档表示质量 vs 检索模型复杂度的结论，对社区搜索的技术选型有直接参考价值。

证据在多语言和视觉丰富文档基准上系统对比 BM25 与端到端多模态检索器，BM25 + 更好的文档表示可缩小或消除与学习型检索器的差距。

Martin Asenov, Kenza Benkirane, Dan Goldwater, Aneiss Ghodsi

ExcluIR: Exclusionary Neural Information Retrieval

首次系统研究文档检索中的排除性查询，即用户表达不想要什么的检索场景。构建了 ExcluIR 基准（3,452 条高质量排除性查询），揭示了现有检索模型在处理否定/排除性语义时的严重不足。

INSIGHT当前检索模型几乎无法理解用户的排除意图。这对搜索引擎的 query 理解模块提出了新挑战：不仅要理解用户想要什么，还要理解用户不想要什么。

业务关联社区搜索中用户经常使用排除性表达（如不要广告、排除某类内容），ExcluIR 的发现说明这一能力仍是搜索系统的盲区，值得关注和改进。

证据在 3,452 条高质量排除性查询上评估，现有 SOTA 检索模型（BM25, DPR, ColBERT 等）的排除性检索效果显著低于常规检索，nDCG@10 下降超过 30%。

Wenhao Zhang, Mengqi Zhang, Shiguang Wu, Jiahuan Pei, Zhaochun Ren

Linguistically Informed Graph Model and Semantic Contrastive Learning for Korean Short Text Classification

提出 LIGRAM，一个基于语言学的异构图模型，用于韩语短文本分类。通过构建融合字符、词素和词三层的层次异构图，结合语义对比学习，有效解决短文本信息稀缺的问题。

INSIGHT短文本分类/理解需要充分利用语言学先验。层次化图结构可以捕捉字符到词的多粒度语义关系，这对中文等同样具有丰富形态学特征的语言也有启发。

业务关联社区搜索的核心对象就是 UGC 短文本，本文提出的短文本理解方法（层次图 + 对比学习）可迁移用于中文短文本的 query 理解和文档表示。

证据在韩语短文本分类基准上评估，LIGRAM 相比 BERT 等基线模型在准确率上有显著提升，验证了语言学先验的有效性。

JaeGeon Yoo, Byoungwook Kim, Yeongwook Yang, Hong-Jun Jang

Towards Effective and Efficient Sparse Neural Information Retrieval

系统发展了稀疏表示学习在信息检索中的框架，统一了 term weighting 和 expansion 的监督学习方法。基于 SPLADE 模型，展示了训练改进（蒸馏、课程学习、高效负采样）带来的显著效果提升。

INSIGHT稀疏神经检索（如 SPLADE）兼具倒排索引的高效率和神经模型的语义理解能力。训练技巧（知识蒸馏、难负样本挖掘）对稀疏检索模型的效果提升至关重要。

业务关联社区搜索系统通常依赖倒排索引，SPLADE 类稀疏神经检索可在不改变索引架构的前提下引入语义召回能力，适合渐进式升级。

证据在 BEIR 等多个检索基准上，改进后的 SPLADE 模型在效果上接近 ColBERT v2，同时保持了倒排索引的检索速度优势。

Thibault Formal, Carlos Lassance, Benjamin Piwowarski, S. Clinchant

RAG vs. GraphRAG: A Systematic Evaluation and Key Insights

系统对比了传统 RAG 和 GraphRAG 在文本检索场景下的表现。GraphRAG 通过将非结构化文本组织为图结构来增强推理和事实依据，但在部分场景下传统 RAG 仍然更有效。

INSIGHTGraphRAG 并非在所有场景下都优于传统 RAG，其优势主要体现在需要多跳推理的复杂查询上。对搜索系统来说，应根据查询复杂度选择合适的检索策略。

业务关联社区搜索中部分查询涉及多实体关联，GraphRAG 的评估结论可指导社区搜索是否以及何时引入图增强检索。

证据在多个基准数据集上系统对比，GraphRAG 在多跳推理任务上优势明显（准确率提升 15-20%），但在简单事实查询上与传统 RAG 持平或略低。

Haoyu Han, Li Ma, Yu Wang et al.
