1. Write, Execute, Refine: From Skill Followers to Skill Optimizers via Reinforcement Learning from Execution Feedback
4.50
Relevance 4 | Novelty 5 | Practical 4 | Evidence 4 | Timely 5

Summary: WER（Write, Execute, Refine）把工具型 Agent 的技能优化拆成多阶段流程：Skill Optimizer 提议自然语言技能，冻结的 Executor 重复执行，程序化验证器评分，再将成功与失败轨迹配对为下一阶段的 refinement 状态。论文指出，Agent 自写技能比不使用技能低 8–11 个百分点，WER 用执行反馈把改进目标从提示词修补转为可训练的相对信用分配。

Key insight: 搜索 Agent 的 query planner、证据筛选器和停止策略都可以按技能对象迭代，但必须让执行器保持冻结并用可重复的检索评测打分。实践上可把 nDCG、引用覆盖率、重复搜索率和延迟组合成程序化 verifier，再把成功/失败轨迹做成对比训练数据；这比只收集最终答案更容易定位规划错误。

2. Token Optimization and Context Window Management in Multi-Agent AI Workflows
4.15
Relevance 4 | Novelty 3 | Practical 5 | Evidence 4 | Timely 5

Summary: 该论文从生产工作流总结多 Agent 的 token 与上下文管理方法，包括上下文分层、一次抓取本地处理、schema 约束提示、token 感知 fallback、语义缓存和 Agent 间通信压缩。生产仪表盘将冷加载延迟从约 3.5–10.5 分钟降到 61–116 秒，估计 token 减少 60–70%；另有 11 种模型配置、2,420 次受控试验和 661 条匿名工作项。

Key insight: 搜索 Agent 的成本瓶颈通常来自重复抓取、长上下文和无效中间状态，而不只是模型单价。可将检索结果先规范化成证据卡片，按任务阶段分层加载，用语义缓存复用相同子查询，并给每轮设置 token/延迟预算；这些改造能直接服务 UGC 搜索的高峰流量，同时保持复杂查询的多步能力。

3. Agentic ESOpt: Fine-Tuning Long-Horizon LLM Agents with Minimal GPU Requirements
4.10
Relevance 3 | Novelty 5 | Practical 4 | Evidence 3 | Timely 5

Summary: Agentic ESOpt 讨论长时程 Agent 训练中的分支交互、稀疏奖励和信用分配问题，提出用 Evolution Strategies 替代依赖反向传播的 Agentic RL。方法通过黑盒轨迹反馈做参数归因，只需推理级 GPU 内存即可支持全参数优化，并能与 prompt-space evolution、skill optimization 和 test-time compute 组合。

Key insight: 当搜索 Agent 的奖励来自最终答案、证据完整性和调用成本的组合时，反向传播式 RL 很容易受长轨迹和基础设施限制。ES 的黑盒接口允许直接接入线上回放或离线评测，但样本效率和稳定性需要严谨验证；可先用小模型在 query 改写或停止策略上做局部实验，再决定是否扩展到全参数。

4. HarnessRisk: A Lifecycle-Oriented Benchmark for Agent Harness Safety
3.95
Relevance 3 | Novelty 4 | Practical 4 | Evidence 5 | Timely 5

Summary: HarnessRisk 将 Agent harness 安全拆成配置、能力扩展、运行、状态持久化、动作控制和事件恢复六个生命周期阶段，构建 128 个沙箱案例，并用 Utility、Attack Success Rate、Persistence、Detection 评估轨迹。在三个 harness、六个语言模型和 14 种配置上，攻击成功率从 12.6% 到 80.9% 不等，显示安全问题会随工具、权限和状态管理组合而放大。

Key insight: 搜索 Agent 不只是召回和生成链路，还会读取不可信帖子、调用外部搜索并持久化中间状态，因此应把间接提示注入和权限越界纳入相关性实验。可按六阶段建立沙箱回归集，分别监控证据污染、错误工具调用和状态残留，并将安全失败与答案质量、成本和延迟一起纳入发布门槛。

5. LEGO-RL: Harness-Native Reinforcement Learning for Coding Agents
3.95
Relevance 3 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: LEGO-RL 研究如何把原生 Agent harness 接入可扩展的策略梯度训练，而不修改 harness 的控制流。它用进程内 LLM proxy 捕获原始生成流并重算 token 级 log-probability，同时通过带镜像缓存和分阶段防护的 sandbox 编排处理环境崩溃、奖励攻击及训练—推理不一致问题，目标是让长时程工具调用的训练信号可靠可复现。

Key insight: 对于搜索 Agent，训练框架必须忠实记录工具调用、上下文压缩和环境失败，否则离线奖励无法代表线上行为。LEGO-RL 的 proxy 与 sandbox 思路可迁移到检索 harness：先固化可重放的搜索环境、错误分类和 token 对齐，再做策略优化；这比直接把普通 RL 套在最终答案奖励上更容易排查训练漂移。

3.60

Summary: TCMIIES 是一个零安装、浏览器端的文献结构化抽取系统，用 schema-guided prompting 自动生成系统提示，支持用户自定义字段、五家主流模型、并发批处理、自动重试以及 CNKI/Wanfang 的字段映射。论文在 500 篇中医研究论文上评估多个抽取场景，结构化输出合规率超过 94%，抽取准确度接近领域专家标注。

10. ArborMem: Navigating Interaction States with Memory Forests
3.45
Relevance 3 | Novelty 4 | Practical 3 | Evidence 2 | Timely 5

Summary: ArborMem 将长对话表示为可导航的 interaction-state forest：每条分支保存局部连贯的任务轨迹，整片 forest 同时保留可中断、可恢复的多条计划。与只按相似度检索历史不同，系统先判断当前输入要恢复哪一个交互状态，再在对应分支中访问记忆，面向多任务交错和计划回访场景。

Key insight: Agentic 搜索也会出现多个并行子查询、用户改写和中途打断，单一会话摘要容易把不同意图混在一起。可把每次查询计划、证据缺口和用户反馈挂到状态树上，恢复时先选分支再取证据；但要限制树的增长、定义过期策略，并用跨轮任务完成率验证记忆是否真的改善检索。
