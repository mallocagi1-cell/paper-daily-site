1. AngelSlim: A More Accessible, Comprehensive, and Efficient Toolkit for Large Model Compression
4.30
Relevance 4 | Novelty 4 | Practical 5 | Evidence 5 | Timely 4

Summary: 腾讯混元团队推出的大模型压缩工具包 AngelSlim，整合了量化、投机解码、token 剪枝和蒸馏等前沿算法。首次实现工业可用的 2-bit 大模型 HY-1.8B-int2，FP8/INT8 PTQ 算法达到无损精度；训练对齐的投机解码框架兼容多模态架构和主流推理引擎，实现 1.8x-2.0x 吞吐提升；免训练稀疏注意力方案在 128K 上下文下实现 11.6x 注意力加速。

Key insight: AngelSlim 的核心价值在于将多种压缩技术统一到一个工业级 pipeline 中，解决了算法碎片化和部署链路断裂的问题。2-bit 量化方案首次在工业环境验证可行性，为极端资源受限场景（如端侧部署）提供了新选择。投机解码框架的训练对齐设计确保了输出一致性，这是生产环境采用的关键前提。对于搜推场景的 LLM serving，该工具包提供了开箱即用的加速方案。

2. DRTriton: Large-Scale Synthetic Data Reinforcement Learning for Triton Kernel Generation
4.15
Relevance 3 | Novelty 5 | Practical 4 | Evidence 5 | Timely 5

Summary: DRTriton 提出一个可扩展的学习框架，通过大规模合成数据和强化学习训练 LLM 自动将 PyTorch 代码转换为高度优化的 Triton kernel。核心包含三个组件：CSP-DAG 数据合成算法保证算子空间的全覆盖和无偏采样；课程强化学习通过解耦奖励同时优化转换成功率和推理速度；测试时计算扩展策略将成功率从 62.5% 提升至 91.2%。在 KernelBench 上达到 SOTA，成功率超越 GPT-5.2 和 Claude-Sonnet-4.5。

Key insight: 这项工作展示了 RL + 合成数据在底层系统优化领域的巨大潜力。CSP-DAG 算法解决了 kernel 训练数据稀缺和分布偏差的根本问题，课程学习策略有效平衡了正确性和性能两个目标。对于搜推系统的自定义算子优化（如注意力机制、特征交叉等），这种自动化 kernel 生成方案可以显著降低系统工程师的手工优化成本，加速从算法到部署的迭代周期。

3. Chimera: Latency- and Performance-Aware Multi-agent Serving for Heterogeneous LLMs
4.05
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: Chimera 是一个面向异构 LLM 集群的多 Agent 工作流 serving 调度系统，联合优化端到端延迟和任务性能。通过语义路由估算每个模型对请求的置信度分数，预测工作流剩余总输出长度，并利用在途预测 token 量估算各模型拥塞状态。系统在多阶段工作流场景下，相比现有同构部署方案显著降低延迟，同时维持或提升任务完成质量。

Key insight: Chimera 的关键洞察是异构部署（不同大小的模型混合）可以在延迟和性能之间实现更精细的权衡。语义路由和拥塞预测的结合解决了异构集群下的调度难题。对于搜推系统中越来越常见的多 Agent 流水线（如 query 理解→检索→重排→生成），这种异构 serving 方案可以在同等硬件预算下提升整体 QPS，适合有多模型编排需求的在线系统。

5. Beyond Token Eviction: Mixed-Dimension Budget Allocation for Efficient KV Cache Compression
3.90
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: MixedDimKV 提出混合维度 KV cache 压缩方法，突破传统 token 淘汰策略的「全或无」限制。将 token 淘汰视为粗粒度降维（分配 0 或全维度），转而以更细粒度为每个 token 分配不同维度数。MixedDimKV-H 进一步整合 head 级重要性信息。在 LongBench 上仅用 6.25% 的 KV cache 即达到与全注意力相当的性能，显著超越 HeadKV 等现有方法。

Key insight: 将 KV cache 压缩重新定义为维度分配问题是一个优雅的视角转换。6.25% 的 cache 比率意味着 16x 内存节省，对长上下文 LLM serving 的实际部署有巨大价值。对于搜推系统中的长文档理解和多轮对话场景，该方法可以在不牺牲质量的前提下大幅降低 GPU 内存需求，从而提升单卡可服务的并发量。head 级重要性分析的引入也为后续的结构化稀疏优化提供了新思路。

6. Scaling DoRA: High-Rank Adaptation via Factored Norms and Fused Kernels
3.80
Relevance 3 | Novelty 4 | Practical 5 | Evidence 4 | Timely 5

Summary: 解决 DoRA（Weight-Decomposed Low-Rank Adaptation）在高秩场景下的内存瓶颈问题。当 d_in=8192、rank=384 时，单模块 norm 计算需要约 512MB 临时内存。提出分解范数（factored norm）将复杂度降至 O(d_out·r + r²），消除密集矩阵乘积；融合 Triton kernel 将四步 DoRA 组合压缩为单次 pass，内存访问减少约 4x。使高秩 DoRA 在单 GPU 上可行，同时保持数值稳定性。

Key insight: DoRA 在高秩适应场景下的实用性一直受内存限制。分解范数和融合 kernel 的组合巧妙地解决了这一工程瓶颈，使得 LoRA 的后续方法在实际部署中不再受限于低秩假设。对于搜推领域的模型微调（如将通用 LLM 适配到搜索排序任务），高秩适应可以捕获更丰富的任务特定信息。该方案的 Triton kernel 实现也为类似的矩阵分解优化提供了可复用的工程模式。

8. TIDE: Token-Informed Depth Execution for Per-Token Early Exit in LLM Inference
3.65
Relevance 3 | Novelty 3 | Practical 5 | Evidence 4 | Timely 5

Summary: TIDE 是一个 post-training 的 LLM 推理早退系统，在周期性检查点层添加轻量 learned router，推理时为每个 token 选择最早可退出的层。无需模型重训，兼容任意 HuggingFace causal LM，支持 float32/float16/bfloat16。在 A100 + DeepSeek R1 Distill 8B 上，prefill 延迟降低 7.2%，单 batch 吞吐提升 6.6%；自回归解码中 98-99% 的 token 提前退出。Qwen3 8B 上 batch=8 吞吐提升 8.1%。

Key insight: TIDE 的核心优势是零训练成本和即插即用的特性——仅需 2000 条 WikiText 样本校准。虽然 7-8% 的吞吐提升幅度有限，但作为无需任何模型改动的加速方案，其工程价值在于可以与其他优化（量化、投机解码等）正交叠加。对于搜推系统中的 LLM serving，这类低风险增量优化可以快速上线验证收益。

9. Speculating Experts Accelerates Inference for Mixture-of-Experts
3.55
Relevance 3 | Novelty 4 | Practical 3 | Evidence 3 | Timely 5

Summary: 针对 MoE 模型推理中 CPU-GPU 数据传输瓶颈，提出 expert 预取方案。利用模型内部表示预测未来需要的 expert，使内存传输与计算重叠。该方案无需修改预训练模型，已集成到开源推理引擎 YALIS 中。对于 offloading 场景（expert 权重存储在 CPU 内存中）可以显著降低解码延迟。

Key insight: 随着 DeepSeek-V3 等大规模 MoE 模型的普及，expert offloading 成为资源受限环境下的重要部署策略。通过 speculative prefetching 将 expert 加载延迟隐藏在计算中，是一个优雅且实用的工程优化。与 YALIS 推理引擎的集成提供了即用方案。对于搜推系统在多 GPU 或 CPU-GPU 混合环境下部署 MoE 模型有直接参考价值。
