TagLLM: A Fine-Grained Tag Generation Approach for Note Recommendation

针对电商社区笔记推荐中 LLM 生成能力未被充分利用的问题，提出 TagLLM 框架，通过用户兴趣手册和多模态 Chain-of-Thought 提取生成细粒度标签，并用知识蒸馏技术提升推理效率。线上 A/B 测试显示，人均浏览时长提升 0.31%，人均互动次数提升 0.96%，冷启动场景下页面浏览点击率提升 32.37%。

1. 问题与动机

电商社区（如得物）中笔记推荐是核心场景，现有方法主要利用 LLM/MLLM 将笔记编码为隐式 embedding，但忽略了 LLM 生成能力在可解释标签表示上的潜力。传统闭式标签方法依赖预定义标签池，扩展性差；已有开式生成方法缺乏引导，产出标签冗余且不聚焦，无法反映用户兴趣维度。作者指出两个关键缺陷：（1）MLLM 在标签生成时缺乏引导（lack of guidance），导致冗余标签缺乏焦点；（2）生成的标签粒度过粗（coarse-grained），无法捕捉笔记表示所需的细微差异。这一问题在冷启动场景尤为突出——新发布笔记缺乏交互信号，高质量标签可作为内容理解的替代特征。

2. 方法详解

TagLLM 包含四个核心模块：

用户兴趣手册生成（User Interest Handbook）：采用 LLM 扩展 + 人工精炼两步法，为平台 18 个品类各设计类目特定的兴趣维度定义。手册定义了标签生成时需要关注的用户兴趣方向，作为 prompt 的结构化引导。

多模态 CoT 标签提取：输入包括视频采样帧、图片、标题、正文、商品描述、ASR 转写（SenseVoice 转录 + LLM 后纠错）。分三步 Chain-of-Thought 处理：Step 1 按手册维度生成候选标签；Step 2 合并低信息量标签、删除无关内容、丢弃图文不一致项；Step 3 对标签按重要性打分（1-5分）并排序。

标签知识蒸馏（Tag Knowledge Distillation）：两阶段训练将大模型能力迁移到小模型。SFT 阶段在 119,318 条笔记上用 next-token prediction 微调（lr=1e-4, 3 epochs）。DPO 阶段在 19,976 条笔记上通过 MLLM-as-judge（Doubao-1.6-thinking）评估构建偏好对，用参考答案作正样本、劣质生成作负样本进行对齐（lr=5e-6, 1 epoch）。评估采用基础属性评分（Truth/Coverage/Importance 三维度 0-1 打分）和成对比较两种策略。

推荐特征转换：用户画像侧，累积用户历史交互笔记的标签，按行为类型加权（点击 +x%、点赞 +y%、收藏 +z%）构建用户兴趣标签画像。内容侧，将笔记所有标签拼接后通过预训练编码器映射到潜空间作为笔记特征。在线模型联合优化 BCE 损失 + 对比学习损失 + L2 正则。

3. 核心技术贡献

1) 手册引导的细粒度标签生成：将 LLM 生成从无约束扩展为手册引导的结构化生成，使标签同时满足语义丰富性和用户兴趣对齐性。这是该领域首个将用户兴趣手册融入标签生成的方法。

2) 两阶段知识蒸馏：SFT + DPO 两阶段训练使 Qwen3-VL-4B 级别小模型接近大模型教师水平（基础属性评分 2.678 vs 大模型水平，成对比较得分 -0.029 接近零差异），实现了生产可用的推理效率。

3) 多模态 CoT 信息融合：通过消融实验验证了正文（body text）对性能影响最大，视觉信息次之，商品描述在特定品类（玩具）影响显著。三步 CoT 实现了噪声过滤和重要性排序。

4) 冷启动场景的突破性提升：标签特征在新笔记缺乏交互数据时提供了有效的内容理解信号。

4. 实验结果分析

蒸馏效果：基础模型（未训练）表现差——InternVL3-2B 基础属性评分仅 1.935，成对比较 -1.380。经 SFT 后分别提升至 2.596 和 -0.292。最终 Tag Knowledge Distillation 使 Qwen3-VL-4B-Instruct 达到 2.678 和 -0.029，接近教师模型水平。

品类差异：美妆品类（Beauty）表现较差，因覆盖范围广、一致性低；穿搭品类（Dressing）表现最优，因方向性强。

评估模型选择：Doubao-1.6-thinking 与人类判断的一致性最高（基础属性 MAE 0.15, 一致性 100%；成对比较 MAE 0.34, 一致性 95.99%），优于 GPT-4.1、GPT-4o 和 GPT-5。

线上 A/B 测试：整体指标——人均浏览时长 +0.31%、人均互动 +0.96%、GMV +0.15%、UV CTR +0.06%、有效点击 +0.21%。冷启动场景（24小时内新笔记）——PV CTR +32.37%、PV 互动率 +46.91%，效果极为显著。简化版 TagLLM- 仍获 +31.66% PV CTR 和 +34.03% PV 互动率，验证方法鲁棒性。

失败案例分析：两类典型失败——推理幻觉（关键信息不完整时模型编造联系）和用户误导（用户提供矛盾内容导致识别错误）。

5. 局限与未来方向

作者明确提出三个局限：（1）视频理解不足——固定频率帧采样难以处理复杂长视频，需集成 VideoLLM；（2）推理幻觉——笔记信息不完整时模型可能不准确补全，需知识检索工具和纠错机制；（3）逻辑推理——用户错误创建的矛盾内容会误导模型，需通过 RLHF 和思维过程训练改进。

6. 工业实践意义

直接可借鉴的设计：（1）用户兴趣手册的思路可迁移到任何 UGC 平台——为每个内容品类定义结构化的兴趣维度，用于引导 LLM 生成焦点化的内容标签；（2）SFT + DPO 两阶段蒸馏管线已验证可行，4B 级模型即可达到生产水平，推理成本可控。

冷启动价值：+32.37% PV CTR 的提升表明，在新内容缺乏交互信号时，LLM 生成的细粒度标签可作为强有力的替代特征。对于社区搜索场景，新帖子的质量和相关性评估是核心难题，标签化内容理解可显著改善冷启动内容的曝光效率。

部署考量：标签生成可异步执行（内容发布时触发），不影响在线推理延迟。用户画像侧的标签累积机制简单高效，无需复杂的实时计算。但需注意品类差异（美妆等泛化品类可能需要更精细的手册设计），以及视频内容的帧采样策略对标签质量的影响。

MI-DPG: Decomposable Parameter Generation Network Based on Mutual Information for Multi-Scenario Recommendation

📖 有深读 · 6 分钟

针对多场景推荐中模型参数成本高且场景多样性建模困难的问题，提出基于互信息的可分解参数生成网络 MI-DPG。核心思路是将加权矩阵分解为场景共享和场景特有的低秩矩阵组合，并通过互信息正则化增强跨场景参数多样性。在三个真实数据集上显著优于已有多场景推荐方法，论文发表于 CIKM 2023。

INSIGHT低秩分解 + 互信息正则化是一个优雅的多场景参数共享方案：共享矩阵捕捉跨场景通用模式，场景特有矩阵以极低参数成本建模差异性。对于运营多个搜索/推荐场景的平台（如主搜、发现页、相关推荐），可用该思路统一模型架构并通过场景条件生成差异化参数，避免为每个场景维护独立模型。

Wenzhuo Cheng, Ke Ding, Xin Dong, Yong He, Liang Zhang, Linjian Mo

1. 问题与动机

多场景推荐是工业推荐系统的常见需求——同一平台需同时服务多个业务场景（如主搜、发现页、广告位），为每个场景维护独立模型成本高昂。现有统一模型方案分两类：（1）显式参数方案（PLE、STAR）为每个场景维护独立参数模块，参数开销大；（2）参数生成方案（APG）通过辅助网络动态生成参数，但存在两个核心缺陷：APG 仅用输出门控（output gating）对参数空间影响有限，且在缩小低秩矩阵尺寸时性能急剧下降（sharp performance decrease），同时生成参数的跨场景分布多样性不足。作者指出关键挑战在于：如何在低参数成本下实现有效的跨场景性能提升，以及如何鲁棒建模多场景多样性。

2. 方法详解

骨干网络：L 层全连接网络，输入拼接场景无关 embedding（e_i^ag）和场景感知 embedding（e_i^aw）。核心公式为 ỹ_i = {F_{S_i^l ⊙ W^l}(h^l)}，其中 S_i^l 是动态生成的加权矩阵，⊙ 为逐元素乘，W^l 为骨干参数矩阵。

可分解加权矩阵（DWM）模块：提出四种分解变体。（1）Non-decomposable：直接通过辅助网络生成完整加权矩阵 S_i^l = σ(G(e_i^aw, h^l))；（2）RC 变体：分解为行特有矩阵 S_R^l 和列特有矩阵 S_C^l 的乘积，通过 repeat 函数扩展到目标维度；（3）R 变体（最优）：行特有 + 列共享，共享列矩阵 C_share^l 促进跨场景泛化；（4）C 变体：行共享 + 列特有。关键创新在于分解加权矩阵而非直接分解骨干参数——这避免了 APG 在小低秩尺寸下的性能坍塌。

互信息正则化（MIR）模块：最大化场景感知输入与加权矩阵之间的互信息。损失公式为 L_mi = -1/n Σ[log T_+ + log(1-T_-)]，其中 T_+ 衡量加权矩阵与对应场景的相关性，T_- 通过随机打乱场景特征衡量与非对应场景的无关性。判别器 T 为轻量级神经网络，基于 F-GAN 框架估计散度。

总损失：L_CVR = -1/n Σ[y_i log ỹ_i] + λ L_mi，二元交叉熵 + 互信息正则化（λ=1）。训练使用 Adam 优化器（lr=0.001），batch size 512，3 层 DNN backbone（维度 128-64-32），每实验 10 次重复取平均。

3. 核心技术贡献

1) 加权矩阵分解 vs 参数分解：MI-DPG 对加权矩阵（而非骨干参数本身）进行低秩分解，使场景特化作用于参数调制层面而非参数本身。实验证明这种设计在低秩矩阵尺寸缩小到 1/4 时仍能保持稳定性能，而 APG 在相同条件下性能急剧下降。

2) 灵活的共享-特有分解策略：R 变体（行特有、列共享）表现最优，说明行方向的场景特有低秩矩阵捕捉场景差异，列方向的共享矩阵提供跨场景泛化能力——这为多场景架构设计提供了明确的分解方向指导。

3) 互信息驱动的参数多样性：MIR 显式优化场景-参数对应关系。t-SNE 可视化显示，无 MIR 时不同场景的加权矩阵分布重叠严重，加入 MIR 后同场景分布聚拢、异场景分布分离。场景相似度矩阵进一步证明学到的参数关系与语义类目相似度对齐。

4. 实验结果分析

三数据集一致性提升：

Amazon 数据集（10 品类，1.29M 样本）：MI-DPG AUC 0.6745（vs APG 0.6697, +0.72%）；IAAC 数据集（电商搜索广告，478K 样本）：MI-DPG AUC 0.6504（vs APG 0.6457, +0.73%）；Advertising 工业数据集（蚂蚁集团广告，108.6M 样本，3 场景）：MI-DPG AUC 0.7580（vs APG 0.7488, +1.23%）。所有结果通过 paired t-test 验证显著性（p ≤ 0.05）。

消融分析：（1）DWM 模块——四种分解变体均优于非分解基线，R 变体（行特有列共享）整体最优，C 变体次之，验证了低秩分解的有效性和共享策略的重要性；（2）低秩尺寸敏感性——网格搜索 d_k ∈ {1,2,4}, d_r ∈ {d_m/8, ..., d_m}, d_c ∈ {d_n/8, ..., d_n}，MI-DPG 在各尺寸下性能稳定，APG 则随尺寸缩小性能急剧下降；（3）MIR 模块——对比 DPG（无 MIR）和 MI-DPG，MIR 在所有数据集上均带来额外提升（Amazon +0.43%, IAAC +0.39%, Advertising +0.62%），t-SNE 和相似度矩阵直观展示了参数多样性的改善。

5. 局限与未来方向

论文未明确声明局限，但存在以下隐含问题：（1）MIR 模块引入额外判别器网络，增加训练计算开销；（2）超参数 λ 仅测试了 λ=1 一个值，缺乏敏感性分析；（3）最大工业数据集来自蚂蚁集团内部，可复现性受限；（4）缺乏对为何加权矩阵分解优于参数分解的理论分析。另外，论文未报告任何线上 A/B 实验结果，仅有离线评估。

6. 工业实践意义

多场景统一架构设计：对于运营多个搜索/推荐场景的平台，MI-DPG 提供了一个参数效率高的统一方案——共享骨干网络 + 场景条件化加权矩阵生成。R 变体的设计原则可直接借鉴：行方向做场景特有参数（捕捉差异），列方向做共享参数（促进泛化）。

与 APG 的对比选择：如果团队已使用 APG 类方案且面临低秩尺寸受限（因推理延迟/内存约束），MI-DPG 的加权矩阵分解策略可在更小的低秩尺寸下保持性能，是直接的升级路径。

互信息正则化的通用性：MIR 的设计思路可推广到任何需要保持多组参数差异性的场景，如多任务学习中不同任务 tower 的参数分化、多市场推荐模型中不同地域的特化等。实现简单（额外一个轻量判别器 + 打乱对比损失），可作为即插即用模块。

部署考量：3 层 DNN + 低秩分解的设计推理成本可控。但工业落地需关注：（1）场景数量扩展时 DWM 模块的参数增长是否可控；（2）互信息正则化在大规模分布式训练中的稳定性；（3）冷启新场景时共享矩阵的迁移效果。

Optimizing Feature Extraction for On-device Model Inference with User Behavior Sequences

揭示端侧 ML 推理中被忽视的性能瓶颈——从原始应用日志提取特征的延迟。提出 AutoFeature 引擎，通过 DAG 抽象特征提取工作流、图优化融合冗余操作、高效缓存重叠数据三项机制加速端侧特征提取。在搜索、视频、电商等五个工业移动服务上验证，端到端延迟降低 1.33x–3.93x（白天）和 1.43x–4.53x（夜间）。

INSIGHT端侧推理的瓶颈往往不在模型计算本身，而在特征提取环节。AutoFeature 的核心启示是：将特征提取流程建模为 DAG 并做图级优化（算子融合、缓存复用），可获得远超模型压缩的实际延迟收益。对于依赖用户行为序列做实时排序的移动搜索/推荐系统，优化特征提取管线是低成本高回报的优化方向。

TF4CTR: Twin Focus Framework for CTR Prediction via Adaptive Sample Differentiation

针对现有 CTR 模型对样本无差别处理的局限，提出 Twin Focus 框架，包含 Twin Focus Loss、样本选择 Embedding 模块和动态融合模块三个组件。核心思路是自适应区分简单/复杂样本，为不同样本分配更合适的编码器并提供定制化监督信号。在 5 个真实数据集上验证，可作为即插即用模块增强多种 CTR 基线模型，已被 IEEE TCSS 接收。

INSIGHT样本差异化处理是 CTR 模型一个被低估的优化方向。TF4CTR 的模型无关设计使其可直接集成到现有 CTR pipeline 中：为简单样本和复杂样本分别匹配编码器和损失函数，避免统一训练目标对不同难度样本的次优处理。对于已有成熟 CTR 模型的团队，这种即插即用的提升方式实施成本低且风险可控。
