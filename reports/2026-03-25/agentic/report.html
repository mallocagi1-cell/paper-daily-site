1. s3: You Don't Need That Much Data to Train a Search Agent via RL
4.35
Relevance 4 | Novelty 4 | Practical 5 | Evidence 4 | Timely 3

Summary: 现有 RAG 搜索 agent 训练方法要么用 NDCG 等检索指标优化，忽略下游生成效果，要么端到端微调整个 LLM 导致检索与生成耦合。s3 提出轻量化框架，将搜索器与生成器解耦，冻结生成器仅训练搜索器，并引入 Gain Beyond RAG (GBR) 奖励——量化检索上下文相比朴素 RAG 的增益。仅需 2.4k 训练样本即可超越使用 70 倍以上数据训练的基线方法（EMNLP 2025 发表）。

Key insight: 将搜索能力从 LLM 中解耦是一个重要设计选择：冻结生成器使框架可适配任何闭源或开源模型，同时 GBR 奖励直接优化「检索对生成的边际贡献」而非传统检索指标。这种模块化设计对搜索系统有直接借鉴意义——可在不修改现有排序/生成模型的前提下，独立优化搜索策略。极高的数据效率（2.4k 样本）使其在工业场景中快速落地成为可能。

2. PivotRL: High Accuracy Agentic Post-Training at Low Compute Cost
4.25
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 长链路 agent 任务的后训练面临效率与泛化的矛盾：SFT 高效但 OOD 退化，端到端 RL 泛化好但算力消耗大。PivotRL 提出在现有 SFT 轨迹上操作的新框架，通过两个关键创新——轨迹中的「关键决策点」识别和局部 RL 微调——将 SFT 的效率与端到端 RL 的泛化能力结合。在 agentic 基准测试中以极低计算成本达到接近 E2E RL 的精度。

Key insight: 找到轨迹中的「关键决策点（pivot）」并仅对这些节点做 RL 微调，是一种极其务实的 agent 训练策略。这避免了长链路完整 rollout 的高昂成本，同时保持了 RL 的探索优势。对搜索/推荐系统中需要多步决策的 agent（如多轮检索、对话推荐）有直接的训练范式借鉴——可先用 SFT 初始化，再用 PivotRL 精调关键步骤。

3. AgentHER: Hindsight Experience Replay for LLM Agent Trajectory Relabeling
4.25
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: LLM agent 在真实任务中失败率极高（GPT-4o 在 WebArena 上成功率不到 15%），而失败轨迹通常被丢弃。AgentHER 借鉴经典 RL 中的 Hindsight Experience Replay 思想，将失败轨迹重新标注为「假设目标」下的成功轨迹，从而将丢弃的数据转化为有效训练信号。这种离线数据增强方法大幅提升了 agent 在 WebArena 和 ToolBench 上的表现。

Key insight: 在 agent 交互数据极其稀缺且昂贵的场景下，AgentHER 提供了一种「从失败中学习」的实用方案。对于搜索 agent 系统，大量的失败检索轨迹（如多轮检索未找到答案）可以通过目标重标注转化为有效训练数据。这一思路可直接应用于搜索 agent 的离线训练——降低对高质量正例数据的依赖。

4. Bypassing Document Ingestion: An MCP Approach to Financial Q&A
4.10
Relevance 4 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: 金融问答通常被视为信息检索问题，但大量结构化信息已存在于专业数据供应商系统中。本文研究 Model Context Protocol (MCP) 作为标准 RAG 的替代方案——让 LLM 直接与数据系统交互，绕过文档切片和向量检索。在金融 Q&A 场景下，MCP 方法在定量分析任务中表现出更高的可靠性，特别是在需要精确数值查询时优于传统 RAG。

Key insight: MCP 代表了一种「让 agent 直接调用数据源」的新范式，对比 RAG 的「先检索再生成」模式有本质区别。这对搜索系统有重要启示：当数据已经被结构化存储时，直接 API 查询可能比向量检索更高效可靠。在 UGC 搜索场景中，结构化元数据（标签、类别、用户属性）可以通过 MCP 方式直接获取，而非全部依赖文本检索。

5. Demystifying Reinforcement Learning for Long-Horizon Tool-Using Agents: A Comprehensive Recipe
4.00
Relevance 3 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 将 LLM 通过 RL 训练为自主 agent 是当前热点，但在复杂多轮环境中如何 scale RL 缺乏系统指南。本文使用 TravelPlanner（需要工具编排满足多维约束的基准）进行系统实证研究，将 agentic RL 设计空间分解为 5 个轴：奖励设计、模型规模、数据组成、算法选择、环境稳定性。提供了从 1.5B 到 32B 模型的完整 scaling 分析。

Key insight: 这是目前最系统的 agentic RL 训练实践指南，5 个设计轴的分解方式为搜索 agent 的 RL 训练提供了清晰的决策框架。特别是奖励设计（稠密 vs 稀疏）和数据组成（on-policy vs off-policy 混合）的实验结论可直接指导搜索 agent 的训练策略选择。对于正在探索 RL 训练搜索 agent 的团队，这篇论文是必读的实操参考。

6. KG-Hopper: Empowering Compact Open LLMs with Knowledge Graph Reasoning via Reinforcement Learning
3.95
Relevance 3 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: LLM 在知识密集推理任务上表现不佳，传统 KBQA 方法逐步推理易产生错误级联。KG-Hopper 提出用 RL 训练紧凑型开源 LLM（7-8B），将整个知识图谱遍历和决策过程嵌入统一的「思考」阶段，实现单次推理完成多跳 KG 推理。在复杂多跳推理任务中，7-8B 模型一致超越 SFT 模型（含 13B、70B），并匹配或超越 GPT-4o-mini + KG 的表现。

7. OpenResearcher: A Fully Open Pipeline for Long-Horizon Deep Research Trajectory Synthesis

Summary: 训练 deep research agent 需要大量交错搜索、证据聚合和多步推理的长链路轨迹数据，但现有数据收集依赖专有 Web API，成本高且难以复现。OpenResearcher 提出完全开放的管线，将一次性语料构建与多轮轨迹合成解耦，通过三个显式浏览器原语（search、open、read）完全离线执行搜索-浏览循环，实现大规模可复现的轨迹合成。

8. WebNavigator: Global Web Navigation via Interaction Graph Retrieval
3.55
Relevance 3 | Novelty 4 | Practical 3 | Evidence 3 | Timely 5

Summary: 当前自主 Web 导航方法因「拓扑盲视」——agent 只能通过试错探索而无法感知全局环境结构——距离人类水平仍有很大差距。WebNavigator 将 Web 导航从概率探索重新定义为确定性检索与路径查找问题，通过零样本构建交互图（Interaction Graph），将网页间的导航关系显式建模，从而在复杂 Web 环境中实现精准导航。

9. Toward a Theory of Hierarchical Memory for Language Agents
3.55
Relevance 3 | Novelty 4 | Practical 3 | Evidence 3 | Timely 5

Summary: 大量 long-context 和 agentic 系统通过分层记忆来应对上下文窗口限制，但缺乏统一的形式化框架来比较设计选择。本文提出用三个算子统一描述分层记忆：抽取（α）将原始数据映射为原子信息单元；粗化（C）对单元进行分组和压缩构建多层表示；遍历（T）在 token 预算下检索内容。提供了信息保持和检索效率的理论界。

Key insight: 为 agent 记忆系统提供了第一个统一的理论框架，三个算子的形式化使不同记忆设计可以公平比较。对搜索系统的实践价值在于：当构建多轮搜索 agent 时，如何在有限上下文窗口内高效组织历史检索结果是核心挑战。本文的理论界可指导记忆压缩策略的选择——在信息保持和 token 效率之间找到最优平衡。

10. The Library Theorem: How External Organization Governs Agentic Reasoning Capacity
3.55
Relevance 3 | Novelty 5 | Practical 2 | Evidence 3 | Timely 5

Summary: 外部化推理（如 chain-of-thought）已被 agent 广泛使用，但「在自身推理状态上建立索引」的结构化检索仍未被充分探索。本文将 transformer 上下文窗口形式化为 I/O 页，证明具有索引外部记忆的工具增强 agent 可实现指数级更低的检索代价：O(log_b N) vs Ω(N) 每次查询，O(T log_b T) vs Θ(T²) 累积代价。

Key insight: 从理论上证明了「外部索引记忆」为 agent 推理带来指数级效率提升，这是对 agent 系统设计的基础性贡献。对搜索 agent 的实践启示明确：在多步推理过程中，为中间推理结果建立索引（而非仅靠顺序扫描上下文）是关键的架构选择。这一理论结果为搜索 agent 的记忆架构设计提供了坚实的理论基础。
