SAM-D2Q: Aligning Multimodal Doc2Query with Search Demand and Conversion for E-commerce

针对短标题遗漏商品属性、用户表达与商家用词不一致的问题，SAM-D2Q 用图文监督、反事实视觉增强和业务奖励优化生成扩展查询，补充布尔索引中的有效召回词。AliExpress 线上 A/B 显示 GMV 提升 3.38%、支付笔数提升 2.27%；扩展内容离线写入索引，线上无需运行生成模型。

Embedding Surgery: Localized Updates for Adaptive Ranking Correction in Dense Retrieval

CCNRSSeltz

针对离线文档向量难以及时响应反馈的问题，Embedding Surgery 将排序纠错建模为凸优化，在满足偏好约束的同时最小化局部向量改动。论文在 TREC 与 MS MARCO 系列集合验证；编辑反馈条件下，DL-Hard 的 nDCG@10 最高相对提升 60.64%，并测试了无需重建 ANN 索引的原位更新。

INSIGHT社区搜索可把人工纠错或高置信反馈转换为文档之间的排序约束，只修正受影响的向量，并观测相邻查询是否同时受益。试验应包含未被纠错的查询作为回归集合，跟踪 nDCG、错误传播和索引召回；论文最高收益来自编辑反馈，不能按同样幅度外推到有位置偏差的点击日志。

证据摘要与第 4 节：DL-Hard 编辑反馈最高 nDCG@10 相对提升 60.64%；表 2 与 ANN 索引分析。

CAGE: Coherence-Aware Graph Encoding for Retrieval-Augmented Generation

CAGE 认为逐段计算相关性会选出各自相关、组合后却不连贯的证据，因而把候选段落转换为有向异构实体图，用节点重加权与关系图卷积刻画段落间一致性，再融合查询相关性重排。在四个多跳基准中，2Wiki 的 Recall@5 为 85.4%，较普通 RAG 高 5 个百分点；HotpotQA 为 84.2%，与 monoT5 持平。

INSIGHT社区问答常需要正文、评论和补充说明共同解释问题，可先在候选集内部引入实体关系与一致性特征，检查它是否改善重排与答案证据覆盖。该方法属于候选重排而非多步搜索规划；应分开验证召回、答案准确性和建图延迟，避免把生成指标改善直接解释为点击率改善。

证据表 1：2Wiki Recall@5 85.4，Vanilla RAG 80.4；HotpotQA 84.2；表 3 为组件消融。

LentEx: Generalizable Latent Entity Extraction via Synthetic Data and Instruction-Tuned LLMs

Amazon

LentEx 用模板组合生成跨领域隐式实体监督，再对 Mistral-7B 做 LoRA 微调，从未直接写出实体名称的文本中抽取主题或概念。训练覆盖 100 个领域组合、约 1 万条合成样本；检索实验中 COLIEE 的 F1 从 RAG+Claude 的 0.688 升至 0.732，BioASQ 从 0.603 升至 0.660。

INSIGHTUGC 经常描述经历却不点明概念，可将隐式实体作为独立索引字段或召回扩展信号，保留原文以便检查推断是否可靠。优先用人工标注的中文长尾查询评估新增召回与误召回；论文在 COLIEE 的 F1 仍低于专用系统 CAPTAIN 的 0.745，不能据此认定通用抽取已替代领域方法。

GUIR at SemEval-2026 Task 8: Training-Free Multi-Query Fusion for Robust Conversational Retrieval

Georgetown University

GUIR 将当前轮原句、消解上下文后的改写、历史用户问题拼接分别检索，每路取前 10 个候选，合并去重后用 MonoT5 重排。在 SemEval 多轮检索官方评测中，nDCG@5 达到 0.5387，高于基线 0.4795，相对提升 12.3%；赛后换用更大的 MonoT5 后达到 0.5490。

INSIGHT社区搜索中的连续追问可保留原句、改写和历史问题三种视角，减少单一改写丢失口语、专有名词或上下文的风险。先合并候选再统一重排，并按查询类型与领域拆解收益；论文金融领域 nDCG@5 仅 0.3413，说明通用融合仍需领域词汇适配。

证据正文第 3.2 节、表 2：每路 top-10；官方 0.5387 vs 0.4795；第 5.4 节赛后 0.5490。

SAGE: Semantic Attribute Graphs for Multi-Entity Visual Retrieval

Korea UniversityKT

SAGE 针对密集图文被单向量压缩后细粒度实体信号混杂的问题，解析语义属性并组织为分层图，用多向量表征和实体子图匹配定位证据。作者构建含 1,055 个查询图像对、四类问题的 DEAR；在多实体视觉比较问题上，Recall@3 达到 0.849，生成评分为 2.746，并提供研究代码。

INSIGHT含截图、攻略长图或多商品对比的社区帖子，可尝试按实体和属性建立细粒度索引，再把命中证据聚合到帖子级结果。其价值是减少整图向量对关键局部的稀释，但实体解析和多向量存储会增加成本；DEAR 的图文指标尚不能证明中文短文本搜索的 nDCG 或 CTR 收益。

证据摘要、第 5 节与表 3–6：DEAR 1,055 对；多实体视觉比较 Recall@3 0.849，生成评分 2.746。

DS@GT-ARC at eRisk 2026 Task 3: Sparse, Semantic, and LLM Reranking for ADHD Symptom Sentences

Georgia Tech

论文比较无任务标注条件下的五种 Reddit 短句排序方案：先用 BM25 召回，再用语义向量、查询原型或 Gemini 分块重排，覆盖 18 类症状查询。官方多数票相关性标签下，Gemini 的 P@10 为 0.300、nDCG@1000 为 0.207；BM25 分别为 0.094 和 0.109，但该方案仍落后于榜首。

INSIGHT可借鉴的是短句相关性判定：区分用户自身经历、泛泛讨论和他人建议，并用稀疏召回控制候选规模。社区搜索可试验这种语境特征及小批量重排，同时检查跨批次分数校准和 API 成本；文中的 53.9% 是单人抽查相关率，应与官方 P@10 分开解读。

You Really Didn't Get That? Benchmarking Social Pragmatic Inference for Indirect and Playful Chinese Online Comments

George Mason UniversityVirginia TechUniversity of TorontoCityUHKDuke Kunshan University

这项研究从超过 20 万条中文社交互动记录构建 4,735 个人工验证题目，要求模型结合前文识别评论的间接表达、玩笑及互动意图，并在跨出题模型设置下评估八个 LLM。最强模型准确率为 81.42%，模型平均为 68.70%，人工为 90.8%，表明识别表面讽刺仍不足以理解具体语用含义。

INSIGHT社区搜索的语义匹配评测可以加入这类上下文依赖切片，检查模型是否把玩笑、反话或回应对象误当成评论的真实主题。应同时保留目标评论与必要前文，再与仅评论文本的设置对照；这里衡量的是语用理解准确率，其对检索排序和点击率的影响还需要业务实验验证。

AutoConcept: Training-Free Concept-Guided Reranking for Metadata-Available Composed Image Retrieval

Soochow UniversityIINSA Lyon

AutoConcept 在固定图像召回候选池上，从可用概念证据构建正向属性约束和辅助负向惩罚，再将元数据匹配与基础检索分融合，无需训练。FashionIQ 上，WeiMoCIR 的 Recall@10 从 0.1125 升至 0.1379；换用 LinCIR 候选池后，从 0.2605 升至 0.3009，比较均采用元数据可用的实验协议。

INSIGHT社区图文搜索中含颜色、款式或排除条件的查询，可将显式属性约束作为可检查的重排特征，先在同一候选池上比较基础分与约束融合。该方法依赖图库元数据，不能与没有元数据的图像检索系统直接比较；还需评估用户属性证据稀疏、错误标注和候选池变化时的稳定性。

Aggregating Neighbor Embedding Projection and Rank-Based Manifold Learning for Image Retrieval

研究把原始图像向量的邻域重排与 UMAP 投影空间中的排序通过 Borda 投票融合，利用两种表示的互补邻域信息。Dogs 数据集、五次随机种子实验中，ResNet152 的 MAP 从 UMAP 基线 80.59% 提高到 82.39%，DINOv2 从 66.87% 提高到 68.22%；配对检验均报告 p<0.001。

INSIGHT这项方法适合作为社区图文检索的离线排序融合对照，帮助判断低成本投影能否补充现有向量的邻域关系。实验显示仅将原空间与投影排序做 Borda 融合并不总能改善结果，邻域重排组件同样关键；上线前还要核算全局邻域计算及内容持续更新的成本。
