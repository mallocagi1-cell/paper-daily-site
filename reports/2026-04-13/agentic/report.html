1. Agentic-R: Learning to Retrieve for Agentic Search
3.95
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 2

Summary: 该论文提出 Agentic-R，一种面向 agentic 搜索场景的检索器训练框架。核心思路是同时利用查询-文档相关性和最终答案正确性作为训练信号，通过 agent 和 retriever 的双向迭代优化，使检索器能更好地服务于多步推理 agent。在 7 个 QA 基准上实验表明，Agentic-R 显著优于传统检索器，为搜索系统中 agent-retriever 协同优化提供了可行路径。

Key insight: 该工作的核心创新在于打破了 retriever 独立训练的范式，将 agent 的推理反馈（答案正确性）引入检索器优化循环。这对搜索系统的启示是：当搜索流程引入多步推理 agent 时，检索器需要与 agent 联合训练而非独立优化。双向迭代优化机制可借鉴到 query-document 匹配模型的训练中，特别是在需要多轮交互的复杂查询场景。

2. Quantifying the Accuracy and Cost Impact of Design Decisions in Budget-Constrained Agentic LLM Search
3.70
Relevance 4 | Novelty 3 | Practical 4 | Evidence 4 | Timely 3

Summary: 该论文系统评估了预算约束下 agentic LLM 搜索系统的设计决策影响。通过在 6 个 LLM 和 3 个基准上测试 Budget-Constrained Agentic Search 框架，发现：搜索深度增加到一定阈值后准确率提升趋缓；混合检索+重排序带来最大收益；更大的生成预算主要帮助综合型任务。这些发现为搜索系统中 agentic 架构的成本-效果权衡提供了量化指导。

Key insight: 该研究的实践价值在于为 agentic 搜索系统的工程部署提供了量化决策依据。核心发现——搜索深度存在边际效益递减阈值、混合检索+重排序是最优策略——直接可用于指导搜索系统架构选型。对于社区搜索场景，可据此确定合理的 agent 搜索轮数和 token 预算，在准确率和成本间取得最优平衡。

3. Reasoning Graphs: Deterministic Agent Accuracy through Evidence-Centric Chain-of-Thought Feedback
3.60
Relevance 3 | Novelty 4 | Practical 3 | Evidence 3 | Timely 5

Summary: 该论文提出推理图（Reasoning Graphs），一种将 agent 推理过程持久化为图结构的新方法。与传统基于查询相似度的记忆机制不同，推理图以证据项为中心，将推理链作为连接证据的结构化边进行存储，使 agent 能跨历史查询复用证据评估。同时引入检索图优化流水线规划。两者结合形成无需重训基座模型的自改进反馈循环，降低推理方差并提升准确率。

Key insight: 推理图的核心创新在于将 agent 记忆从「查询中心」转向「证据中心」，使得同一证据在不同查询中的评估结果可以复用和对比。这对搜索系统的设计启示是：当引入 LLM agent 做多步推理搜索时，应持久化每次推理对检索结果的评估，而非仅缓存查询-答案对。这种设计可减少重复推理开销，提升搜索 agent 在相似问题上的一致性和效率。
