One prompt is not enough: Instruction Sensitivity Undermines Embedding Model Evaluation

指令式 embedding 模型通常只用单条 prompt 评测，忽略了对指令措辞的敏感性。作者在 6 个 embedding 模型、11 个数据集、每数据集 15 条任务 prompt（共 990 次评测）上做实证研究，发现单点评测严重偏离 prompt 分布：默认 prompt 既可能高估也可能低估性能；通过挑选有利 prompt，研究中任一模型都能被推到榜首。结论是单 prompt 评测不足以衡量指令式 embedding 模型，benchmark 应纳入 prompt 鲁棒性。

02 3.85

Integrating Chain-of-Thought into Generative Retrieval: A Preliminary Study

Shandong University

生成式检索（GR）直接把 query 映射到 docid，缺少中间推理，难以应对需要多跳推理的复杂 query。ThinkGR 在单个生成过程内把 CoT 与 docid 生成交错：用混合解码在「自由思考」与「受约束 docid 解码」间动态切换；两阶段训练先用 SFT 对齐思考-检索模式，再用 retrieval-grounded RL 优化思考质量。在 4 个多跳检索 benchmark 上取得 SOTA，平均提升 +6.86%。

INSIGHT把显式推理引入生成式检索的 docid 生成，是解决复杂/多跳 query 召回的一条新路径。混合解码（思考段不约束、docid 段用前缀树约束）的设计值得借鉴：它在保留 LLM 推理能力的同时保证检索目标的结构合法性。社区搜索中「绕弯子」的长尾 query 同样受益于 query 侧多跳推理，但需权衡生成式检索的解码延迟与索引更新成本。

Wenhao Zhang, Ruihao Yu, Yi Bai, Zhumin Chen, Pengjie Ren

03 3.60

IdioLink: Retrieving Meaning Beyond Words Across Idiomatic and Literal Expressions

习语的含义无法从字面推断，考验模型超越词面重叠的语义抽象。IdioLink 构建了一个检索 benchmark，测试模型能否把习语表达链接到字面/改写形式的等义内容：含 10,700 篇文档、2,140 条 query、107 个习语（含字面与比喻用法），并标注承载核心语义的 span。评测 BGE、E5、Contriever、Qwen 等强 embedding 基线后发现，现有模型难以跨差异表面形式检索等义内容，主要依赖主题词和浅层语义线索。

INSIGHT该 benchmark 揭示主流 embedding 在「语义等价但词面差异大」场景下的系统性短板——这正是社区 UGC 搜索的高频痛点（网络黑话、缩写、比喻表达）。可借鉴其用 span 标注核心语义、区分字面/比喻用法的数据构造方法，搭建自有的习语/黑话检索评测集；选型时也应专门测此类 hard case，而非只看通用 MTEB 分数。

Kai Golan Hashiloni, Daniel Fadlon, Lior Livyatan, Ofri Hefetz, Jiahuan Pei, Kfir Bar

04 3.55

Search-E1: Self-Distillation Drives Self-Evolution in Search-Augmented Reasoning

把语言模型训成搜索增强推理 agent 通常靠在标准后训练流程上叠加外部监督、过程奖励模型、树搜索或手工奖励等机制。Search-E1 反其道而行，只用原始 GRPO 交错离线自蒸馏（OFSD）：每轮 GRPO 后策略在自身训练问题上 rollout，再用 token 级 forward KL 把策略的推理期分布对齐到它在「特权上下文（暴露更高效的兄弟轨迹）」下的分布，从而自然提供稠密的逐步监督。在 7 个 QA benchmark 上用 Qwen2.5-3B 取得 0.440 平均 EM，超过同规模全部开源基线。

INSIGHT该工作说明搜索 agent 的自我进化未必需要外部 teacher 或复杂奖励工程——自蒸馏即可提供稠密 step 级信号。对预算有限、难以接入更强外部模型的团队，「用自己更高效的轨迹蒸馏自己」是低成本提升 agentic search/RAG 的可行方案；token 级 forward KL 对齐高效兄弟轨迹的思路也可迁移到多步检索改写的训练。

Zihan Liang, Yufei Ma, Ben Chen, Zhipeng Qian, Xuxin Zhang, Huangyu Dai

BeLink: Biomedical Entity Linking Meets Generative Re-Ranking

UUniversity of MilanCCU Boulder

用 LLM 做生物医学实体链接（BEL）算力开销大、难以落地。作者发现在 BEL 流程的重排阶段做开源生成模型的指令微调是有效解法：提出 set-wise 指令微调形式，让模型一次性对候选集做快速准确的筛选。在多个 BEL benchmark 上链接准确率提升 3%–24%，同时相比 SOTA 降低推理时间，并集成进模块化端到端系统 BeLink。

INSIGHT把 LLM 限定在重排阶段、且用 set-wise（对候选集整体打分）而非逐条 pointwise 的指令微调，是兼顾效果与延迟的实用折中。社区搜索的精排/重排环节可借鉴这一形态：用小参数开源生成模型做 set-wise 重排，既拿到 LLM 的语义判别力，又把推理成本控制在可上线范围；3%–24% 的区间也提示效果增益高度依赖候选质量。

Darya Shlyk, Stefano Montanelli, Lawrence Hunter

06 3.55

Structure Retention in Embedding Spaces as a Predictor of Benchmark Performance

UUniversity of Turku

作者发现高性能 embedding 模型会以一致的方式组织其表示空间。在 25 个当代 embedding 模型、5 个 MTEB 任务（检索、bitext mining、句对分类、摘要）的英文与多语设置上评测，发现成对文本实例间的最近邻重叠度与 ICA（独立成分分析）幅度差异，与对应任务性能强相关（最高达 0.97）。结果表明不同 embedding 任务在线性程度和对局部信息保留的依赖上存在差异。

INSIGHT该研究给出一个无需下游标注就能预测 embedding 模型检索表现的代理指标——最近邻重叠/ICA 结构保留度。对需要在多个候选 embedding 间快速选型的检索团队，可用这类几何诊断在小样本上预筛模型，降低全量评测成本；其「检索任务更依赖局部信息保留」的结论也为定制 embedding 训练目标提供了方向。

Amanda Myntti, Jenna Kanerva, Veronika Laippala, Filip Ginter
