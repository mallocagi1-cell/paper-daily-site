1. Reasoning to Rank: An End-to-End Solution for Exploiting Large Language Models for Recommendation (R2Rank)
3.60
Relevance 3 | Novelty 4 | Practical 3 | Evidence 5 | Timely 2

Summary: 针对“如何有效优化 LLM 以提升推荐效用”这一仍欠探索的问题，提出 R2Rank：把推荐解耦为对每个候选 item 的独立 pointwise 推理（规避 listwise 生成的位置偏置），先用 DeepSeek-R1 做 self-reflective SFT 冷启动（初步分析→自检→最终判断三段式），再以 PPO 训 LLM 主干、REINFORCE 训打分头，借 Plackett-Luce 概率代理把分数映射成排序分布、以 NDCG 为奖励端到端反传。在 Amazon 三类目与一个工业数据集上，3B 模型 NDCG@10 达 0.564/0.581/0.596，工业集 0.818（较 DeepSeek-R1 的 0.500 相对提升 63.6%）。

Key insight: 关键启示：(1) 让 LLM 对单 item 先出结构化推理再打分，显著优于冻结 LLM 直接打分（0.564 vs 0.368），说明收益来自“推理对齐”而非复用静态表征；(2) 显式 CoT 文本提供更丰富梯度（0.596 vs 无 CoT 0.458），self-reflective SFT 冷启动让 RL 更稳（0.581 vs 纯 RL 0.562）；(3) 长尾/冷启动收益最明显（工业集 56% 测试 item 训练未见过），对 UGC 短文本搜索里稀疏 query-doc 的相关性排序有借鉴。代价：pointwise 推理缺乏跨候选的全局比较一致性、对 user history 顺序敏感（方差偏大），且“每候选一次 LLM 推理”的在线延迟是落地门槛。
