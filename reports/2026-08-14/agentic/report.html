1. QueryAgent-R1: Bridging Query Generation and Product Retrieval for E-Commerce Query Recommendation
4.30
Relevance 5 | Novelty 4 | Practical 4 | Evidence 5 | Timely 2

Summary: 论文针对推荐 query 的点击率与后续商品转化脱节问题，提出带记忆的 QueryAgent-R1：先生成 query，再调用真实商品检索验证结果，并用一致性奖励做 Agentic RL。它在两个离线数据集上提升端到端 Cons@1，线上 1% 流量、7 天 A/B 测试使 Query CTR 提升 2.9%、guided CVR 提升 3.1%，GMV 提升 4.9%。

Key insight: 对社区 UGC 搜索，query 改写不应只优化 query-document 语义相似度，还要让改写后的 query 在真实索引中检出可消费的内容。可借鉴其“记忆压缩—混合召回—交叉编码器重排—轨迹奖励”闭环，并把 item click 或停留等下游信号纳入 query 理解训练。

2. Lost in Compaction: Evaluating Side-Constraint Loss under Context Compaction
4.15
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 论文研究长上下文 Agent 在压缩历史时丢失用户约束的问题，构建 COMPINT 评测多轮对话、Agent 轨迹和长程研究三类场景。实验发现现有压缩器平均只能保留 17% 的注入约束，且多数情况下不如不压缩；作者进一步提出可插拔的约束感知抽取器来恢复关键信息。

Key insight: 社区搜索 Agent 若把用户过滤条件、隐私要求或“不要删除/不要推荐”类会话约束压进摘要，后续 query 改写和工具调用可能悄悄越界。上线前应把约束保留率作为独立指标，在压缩前抽取结构化约束，并让检索、重排和执行工具读取同一份可审计状态。

3. Mechanist: AI as a Scientific Instrument for Discovering the Mechanisms of Intelligence
3.90
Relevance 4 | Novelty 4 | Practical 3 | Evidence 4 | Timely 5

Summary: Mechanist 把科学发现流程做成可检索、可验证的 Agent：构建约 13,000 篇论文的可解释性知识图谱，连接覆盖 26 个领域的约 4,300 万篇论文，并整理 32 类机制分析、因果干预和验证方法。系统围绕假设生成、文献检索和实验验证形成闭环，并与 Claude Code 等系统比较机制假设质量。

Key insight: 对于 UGC 搜索，Agent 不应只返回相似帖子，而应把实体、证据和可验证关系组织成可迭代的检索状态。可借鉴其“领域知识图谱 + 方法库 + 假设验证”结构，将 query 意图、候选证据和失败原因持久化，支持多跳检索与结果解释。

4. Beyond Single-Turn Confidence: Trajectory-Adapted Uncertainty Quantification for LLM Agents
3.90
Relevance 4 | Novelty 4 | Practical 3 | Evidence 4 | Timely 5

Summary: 论文把 Agent 的不确定性从单轮答案扩展到包含澄清、工具调用和状态更新的完整轨迹，在 5 个 LLM、BFCL-v4 与 τ²-bench 的 4 个多轮工具数据集上比较 token 概率、一致性重采样和模型自评三类方法。结果表明单轮置信度迁移并不稳定，跨轮聚合方式会显著影响风险判断。

Key insight: 搜索 Agent 的置信度应覆盖“是否选对工具、query 是否需要改写、证据是否足够、最终答案是否可引用”四个节点，而不是只看生成 token 概率。可在召回和重排链路加入轨迹级拒答/补搜阈值，用重采样一致性与证据覆盖率共同触发下一轮检索。

5. AI4AI at Test-Time: Strong-to-Weak Capability Transfer via Harnesses
3.85
Relevance 3 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 论文研究强模型能否在推理时为弱模型构造可复用的执行外壳，而不更新弱模型参数。强模型用仅占 5% 数据的验证集迭代生成 harness，在 4 个 Theory-of-Mind 基准上把目标模型平均表现从 0.49 提升到 0.91，收益主要来自把不稳定推理外包给确定性代码。

Key insight: 社区搜索中的轻量模型可以通过确定性 query 规范化、召回路由、证据去重和重排校验获得大模型能力增益，不必把所有逻辑塞进模型权重。建议将 Agent harness 拆成可测试模块，用离线验证集迭代，明确区分模型判断与可回放的检索程序。

6. Ready Cohorts: Bounding GPU Opportunity and Avoiding Host Round Trips in LLM-Agent Control
3.85
Relevance 3 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 论文分析 LLM Agent 在模型调用与工具调用之间执行路由、状态更新等小型控制步骤时的 GPU 并发机会，并给出固定分区份额 F、最优离线份额 P* 和在线份额 A 的边界。对 851 个会话的回放显示，在 100,000 个活跃会话、K=256、50ms 截止期下，精确打包可恢复固定窗口边界损失机会的 81.83%。

Key insight: Agentic 搜索的瓶颈不只在 embedding 或 LLM，也在每轮工具调用之间的控制路径。对社区搜索应优先把 query 路由、缓存命中、过滤条件更新等确定性步骤留在设备侧或批处理队列中，减少 host round trip，避免多跳检索把延迟线性放大。

7. Spark-to-Paper: End-to-End Research Paper Generation as a Composable Skill
3.80
Relevance 4 | Novelty 3 | Practical 4 | Evidence 3 | Timely 5

Summary: Spark-to-Paper 将文献检索、实验设计、代码执行、结果核验和论文撰写拆成 13 个可组合技能，部署在现有 coding assistant 内，不依赖独立 Agent 平台。系统把模型判断与可执行的确定性操作分离，并在观察结果后回修声明，针对长轨迹中的 Self-Refutation Loop 增加完整性检查和自我批评。

Key insight: 搜索 Agent 的可靠性可以通过“技能化”而非继续堆提示词来提升：把 query 生成、召回、证据引用、冲突检测和报告输出分别做成可观测技能。对 UGC 场景尤其要把排序结果与最终摘要解耦，先固定证据集合，再生成答案，便于重放和定位错误。

8. Better, Faster, Stronger: Programmatic Skill Learning Best Reduces Agent Cost
3.75
Relevance 3 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: 论文比较 LLM Agent 学习技能的不同方式，主张把成功轨迹压缩成可执行程序，而不是只保存自然语言经验。程序化技能能确定性地复用动作序列，减少长程探索中的试错和退化；Agent 还可在推理时增量发现技能，并在后续任务中直接调用。

Key insight: 对于重复出现的社区搜索任务，可把 query 分类、过滤器选择、召回失败后的补搜和结果去重沉淀为版本化程序技能。这样能降低每次都让 LLM 重新规划的 token 与延迟成本，但必须配套技能命中率、回退率和过期检查，避免旧规则污染新内容。

3.70
