First Things First: Teaching LLM-Based Agents to Prioritize Must-Haves before Nice-to-Haves

FTF-rl 将用户需求区分为必须满足与可选偏好，并覆盖唯一解、多解和无解三种情形。FTF-bench 包含 3,649 道电商、预订及出行问题；在留出的 10% 测试集上，Qwen2.5-VL-7B 平均正确率由 39.78% 升至 55.80%，但无解场景从 44.26% 降至 42.62%。

Dense Process Supervision for Search Agents via Fact Utility Estimation

Nanjing UniversityAnt Group

FactAgent 将搜索推理过程表示为证据事实的积累，从原始观测抽取结构化事实并聚合同义事实，再用组内轨迹的贝叶斯估计生成密集步骤奖励。研究覆盖 7 个单跳及多跳问答基准，7B 模型平均 EM 超过最强基线 3.2 点；系统只使用本地 Wiki-18 索引，每题最多运行 8 轮。

INSIGHT对需要串联多条帖子和问答的社区查询，可把奖励归因到新增有效事实，减少重复检索和偶然答对带来的训练噪声。实施时应保留帖子标识、证据出处和事实合并过程，用多跳问题检验事实覆盖率与最终相关性；论文显示未经过强化学习适配的事实工作流可能弱于单次 RAG。

CoBRA: Learning Tool-Use Boundaries via Counterfactual Margins

TencentUCASWuhan University

CoBRA 针对搜索智能体不必要调用工具的问题，比较同一问题使用与不使用工具的收益差，再结合边界感知监督微调和反事实强化学习训练路由策略。在 Qwen3-4B 上，相对 Search-R1-3B，域内与域外工具调用分别减少 20.1% 和 22.2%，效用指标分别增加 0.0759 和 0.0866。

INSIGHT社区搜索可以把是否扩展检索作为独立决策：对知识不足或时效敏感的问题追加证据，对已有充分依据的问题及时停止。建议用同题双轨执行构造训练样本，联合观察答案正确率、调用次数、nDCG 与 CTR；论文的效用函数带有成本权重，迁移时应按业务延迟预算重新校准。

Skill Following: Evaluating Actual Skill Use in Retrieval-Enabled LLM Agents

Soongsil University

论文提出 RAE：只在实际取回技能的任务上，比较同题开启与关闭技能后的结果，避免把不同难度任务混在一起。研究评估 17 个模型；MBPP+ 的 s42 划分中，Gemini-2.5-Flash-lite 的总体检索增益为 +6.2 个百分点，但同题实际使用效果为 −15.6 个百分点。

INSIGHT社区搜索 Agent 的检索触发本身会选择特定难度的查询，因此直接比较检索与未检索流量可能产生误导。可用同题配对回放统计检索挽救和损害的答案数量，再与线上随机实验的 nDCG、CTR 结果交叉检查；该指标诊断的是完整使用链路，不等同于单独评判召回器质量。

Cho, Seonghyeon, Park, Chanjun

Multi-Step Tool-Calling over Korean Open Public APIs: A Benchmark and a Data-Synthesis Recipe

LG CNS

EDGE 通过真实 API 执行验证工具输出到后续输入的依赖边，再沿图生成多步调用轨迹，减少仅靠模型想象产生的无效数据。KOPA-Bench 包含 145 个任务；使用 1,781 条样本进行 GRPO 训练后，9B 模型 pass@1 从约 0.33 提升至 0.43，接近未微调 27B 的 0.45。

INSIGHT将社区搜索、帖子读取、评论聚合和结构化筛选工具建立成可执行依赖图，有助于生成贴近真实链路的训练数据。建议先验证接口契约和动态返回值，再训练模型选择执行路径；评估同时报告单次成功率与多次尝试成功率，并把最终证据相关性和用户点击反馈接回搜索业务指标。

Kim, Dain, Cho, Eungi, Kim, Kyumin, Noh, Shinyeong, Lim, Kyuseong

Harness Engineering in LLM Tool Use via Agent-Native Reusable Tool Primitives

UIUCStarc Institute

HEART 用带语言接口的 Tool Primitives 封装 API 解析与执行，再由规划、路由和验证组件组织嵌套调用及失败恢复。ToolFace 收录 25,519 个函数，按需检索避免一次塞入全部工具；论文报告 50 个真实任务完成率为 84%，三种商业模型平均为 22%，API 成本最高减少 85%。

INSIGHT社区搜索 Agent 接入多种内容接口时，可借鉴按需发现工具与统一执行封装，减少接口描述占用上下文的问题。试点应分别测量工具召回率、参数解析错误和恢复成本；论文不同系统的完成率差距属于其具体实验设置，不能直接换算成线上 nDCG、CTR 或同等规模的成本收益。

Trace2Tower: Transition-Aware EigenTrace Induction of Multi-Level Skills for LLM Agents

Trace2Tower 将执行轨迹抽象为事件图，同时编码语义兼容性、状态转移和成功结果，再用对比谱分解生成动作、流程及任务策略三级技能。ALFWorld 成功率达到 87.31%，平均 10.35 步、0.26 次无效动作；WebShop 的严格成功率为 50.67%，展示了分层经验复用的效果。

INSIGHT复杂社区搜索可从成功的检索、追问和证据核对链路中提炼可复用流程，同时记录失败路径，避免仅按文字相似度重放历史轨迹。图结构和验证反馈具有借鉴价值，但实验主要来自交互环境；用于 UGC 内容时还需检验时间变化、帖子删除及技能过期对答案相关性和调用成本的影响。

Sun, Jiazheng, Yang, Boyu, Yuan, Binhao, Li, Mingxuan, Peng, Xin

Polished but Unresolved: Identifying Late-Stage Pressure States in Long-Horizon Tool-Use Agents

Nanjing UniversityAlibaba

PSPR 研究长程工具调用智能体在约束未解决时提前交卷的问题，通过线性探针检测隐状态并实施分级干预。探针 AUROC 为 0.916；DeepPlanning-Travel 上，Qwen3-32B 的 ReAct 加入 PSPR 后 CP 从 29.3 升至 33.2，DeepPlanning-Shop 严格准确率由 19.0 升至 23.0。

INSIGHT社区多步搜索的完成条件应绑定证据充分性和用户约束，避免答案文字完整却遗漏关键限定。可先借鉴高压力时重新整理约束、映射剩余动作的策略，再考虑需要模型隐状态的激活干预；评估应同时检查提前停止率、证据覆盖和响应延迟，论文结果采用 pass@3，不能视为单次成功率。

Chen, Haoyang, Liu, Yi, Shao, Jianzhi, Xu, Xiaozhou, Sun, Zhe, Hu, Wei

Multi agent retrieval validation and knowledge reasoning for enhanced retrieval augmented generation

JAIN UniversityDES Pune UniversityVishwakarma Institute of TechnologySymbiosis International University

MARCO 将检索、推理、验证和综合划分为 4 个协作智能体，通过共享记忆池及通信协议协调稠密稀疏检索、查询分解和跨来源验证。作者在 Natural Questions、HotpotQA 与 MuSiQue 上报告 EM 改善 4.2–8.1%、F1 改善 4.5–7.8%；当前可读页面未展开完整实验表。

INSIGHT面向观点不一致的社区帖子，可借鉴独立验证阶段，把证据一致性与答案组织分开处理，并为结论保留原帖依据。现有页面只提供摘要级实验描述，未明确百分比是否为绝对百分点，也未展示完整成本和消融细节；建议补齐原文再决定实现规模，暂不将其视为已验证的线上相关性收益。

1Password increases engineering productivity 21% with Codex

1PasswordOpenAI

1Password 将 Codex 接入规划、代码实现、测试、审查与跨服务故障调查，在明确的工程边界内完成多步工具工作流。案例报告活跃用户群生产率改善 20.9%，PR 周期中位数缩短 10.9%；一个涉及 10 多个微服务的问题，调查由约两小时缩短到 5–20 分钟，属于企业自报观察。

INSIGHT对社区搜索团队，更直接的借鉴是用智能体串联故障证据、验证假设和运行回归检查，缩短搜索实验与问题定位周期。案例未提供搜索 nDCG 或 CTR 增益，也不能证明全部生产率变化由工具导致；试点应记录任务类型、人工复核时间和交付周期，用真实交付效果衡量多工具编排价值。
