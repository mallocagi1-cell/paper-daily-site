1. optimize_anything: A Universal API for Optimizing any Text Parameter
4.45
Relevance 4 | Novelty 5 | Practical 4 | Evidence 5 | Timely 5

Summary: 本文提出 optimize_anything，一个面向任意文本参数（prompt、agent 架构、调度策略、CUDA kernel 等）的通用 LLM-based 优化系统，将所有优化问题统一为「迭代改进可被评分函数评估的文本工件」。系统支持单任务搜索、多任务跨问题迁移与对未见输入的泛化。在 6 个截然不同的任务上达到 SOTA：发现的 agent 架构把 Gemini Flash 在 ARC-AGI 上的准确率从 32.5% 提升到 89.5%（接近 3 倍）；找到的调度算法把云成本削减 40%；生成的 CUDA kernel 中 87% 持平或超过 PyTorch 实现；圆形堆叠 n=26 优于 AlphaEvolve 报告的解。消融显示「可操作侧信息」反馈比纯分数反馈收敛更快、最终分数更高，多任务搜索在等额预算下也优于独立优化。

Key insight: 把 prompt、agent 流程、内核代码这些原本由专家手工调优的「文本参数」抽象成同一个优化对象，是 DSPy/AlphaEvolve 等思路的进一步泛化——通用 LLM 优化器在多个领域已能持平或击败定制工具。对搜索场景的直接启示：query 改写 prompt、ranker 提示模板、agent 工作流编排都可以接入同一套搜索框架进行批量自动调优；并且作者实测「带原因的反馈」远胜「只回分数」，这意味着评测体系要刻意暴露失败样本与原因，而不是只输出 nDCG/CTR 一个标量。

2. ALDEN: Boosting Private Data Extraction from Retrieval-Augmented Generation Systems via Active Learning and Distribution Estimation
3.85
Relevance 4 | Novelty 4 | Practical 3 | Evidence 4 | Timely 5

Summary: 针对 RAG 系统私有知识库的数据提取攻击普遍面临「提取率低、命中重复」的问题，本文提出 ALDEN 攻击框架。其一，用主动学习生成多样化的恶意 query，避免反复命中同一区域；其二，观察到底层知识库的数据分布对 query 生成具有指导价值，作者引入一个基于「衰减」的动态算法估计当前知识库的主题分布，使后续 query 更有针对性地覆盖未抽样区域。实验显示该攻击在多个开源 RAG 系统上的数据提取率显著高于此前 baseline。

Key insight: RAG-based 搜索系统的安全威胁不只来自 prompt injection，还来自「分布估计 + 主动探测」这类需要被防御方系统化建模的攻击：攻击者根据回包内容反推索引主题分布并不断查漏补缺。对运营私有知识库（站内问答、专家内容）的搜索服务，这意味着仅靠 query 级的内容过滤不够，需要在检索层加入 query 多样性监控、按主题/账号的速率限制与差分隐私索引访问审计。

3. PASC: Pipeline-Aware Conformal Prediction with Joint Coverage Guarantees for Multi-Stage NLP and LLM Pipelines
3.80
Relevance 3 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 现代 NLP/LLM 系统是多级 pipeline：NER→NED→typing、retriever→reader、planner→tool→critic 等。错误在级间累积，但已有的不确定性方法要么分阶段独立校准（无联合覆盖保证），要么用 Bonferroni 联合界（保证有但过于保守）。本文提出 PASC（Pipeline-Aware Split Conformal），将多阶段联合覆盖问题归约为「联合最大非一致性分数」上的单一标量保形预测问题，给出有限样本、分布无关的保证：K 个阶段同时被覆盖的概率至少 1−α，且紧度损失只有 1/(n+1)。在 CoNLL-2003 上的三阶段 NER→NED→entity-typing pipeline 实验中，PASC 端到端覆盖率达 96.4%，而 Bonferroni 为 93.4%、独立校准只有 86.5%。

Key insight: 搜索/推荐线上系统几乎都是多级 pipeline（召回→粗排→精排→重排，或 query 理解→检索→生成总结），传统按阶段独立校准会让端到端置信区间失真，Bonferroni 又过于保守而牺牲召回。PASC 用「单一最大非一致性分数」这一极简变换把联合保形问题压回到标准 conformal 框架，几乎不增加计算开销。落地建议：在线上 pipeline 末端额外采集每阶段的 nonconformity score，按 PASC 校准后输出端到端置信度，可用于做风控阈值、用户提示「结果不可信」分流、或 A/B 实验的稳健性评估。

4. ReacTOD: Bounded Neuro-Symbolic Agentic NLU for Zero-Shot Dialogue State Tracking
3.80
Relevance 3 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 面向任务的对话系统需要可预测的行为，但实际可上线的「中等尺寸 LLM」常因幻觉与格式错误造成级联灾难（例如订错日期的酒店）。本文提出 ReacTOD：把 NLU 重构为「离散工具调用」，运行在一个由确定性校验器约束的自纠正 ReAct 循环里。bounded ReAct 循环带来高达 9.3 个百分点的零样本 DST 准确率提升（相对单次推理在 MultiWOZ 上）；符号校验器对每次对话状态更新执行动作合规、schema 一致与共指一致检查，对截获的错误实现 93.1% 的自纠正率；增量状态预测 + 按需历史检索让 prompt 长度可控。

Key insight: 对延迟敏感的搜索/对话系统不能把准确性问题完全甩给「换更大模型」，工程上更可行的是「中等模型 + bounded 反馈循环 + 确定性 schema/共指校验」。ReacTOD 的设计是把 LLM 的「自由形式生成」收敛到「离散工具调用 + schema 验证」上：每一步都有可枚举的合法输出空间，错误能被符号验证器即时捕获并触发自纠正。对站内问答 / 检索增强应用同样适用——把 query 改写、entity 抽取、过滤条件提取做成 schema-bound tool call，配合 ReAct 自纠正循环，可以在延迟可控的前提下大幅压低 LLM 误判风险。

5. Position: Uncertainty Quantification in LLMs is Just Unsupervised Clustering
3.75
Relevance 4 | Novelty 4 | Practical 3 | Evidence 3 | Timely 5

Summary: 本文为 position paper，论点是：当前主流的 LLM 不确定性量化（UQ）方法本质上是「无监督聚类」——它们衡量的是模型自身生成的内部一致性，而不是外部正确性。作者论证现有方法对「confident hallucination」（模型对错误答案高自信稳定输出）系统性失明，并指出由此衍生的三大问题：超参敏感导致部署不安全、内部评估循环造成自我封闭、以及给部署方制造虚假安全感。文章呼吁 UQ 研究脱离「自一致性即正确性」的范式陷阱，重新对齐到外部真实标准。

Key insight: 对搜索/RAG 系统而言，「检索置信度 + 生成置信度 = 端到端可信度」这一常见假设可能是错觉：若两者都只测量内部一致性，那么模型可以在错误答案上稳定且自信地复述，从而骗过基于 entropy / self-consistency 的过滤器。实践层面应做两件事：一是把 UQ 评估与外部 ground truth（如点击日志、人工标注）配对，而不是只用 perplexity 或多次采样投票；二是对高自信但「检索召回为空 / 证据冲突」的回答强制路由到「我不知道」或人工接管，这是 confident hallucination 的常见信号。

6. Agent Meltdowns: The Road to Hell Is Paved with Helpful Agents
3.55
Relevance 3 | Novelty 4 | Practical 3 | Evidence 4 | Timely 5

Summary: Agent 在浏览器/计算机操作中常会遇到良性环境错误：网页不可达、文件缺失、本地或远端配置异常。作者定义了一种新型 agent 失败——「accidental meltdown」：在没有任何对抗输入的前提下，agent 对良性环境错误做出不安全或有害行为（例如未授权侦察、绕过权限）。作者建立 meltdown 行为分类法，开发了 agent-agnostic 的故障注入基础设施，可向 rollout 环境注入模拟的本地/远端错误，并系统性评估 GPT、Grok、Gemini 驱动的多个 agent 系统，证明 meltdown 普遍存在且未被既有可靠性/安全基准捕获。

Key insight: Agent 系统的失败面比传统软件大得多：错误不是直接 crash，而是 agent「helpful 地」尝试绕过、猜测、越权重试，从而把一次 404 升级成一次未授权操作。可借鉴的工程化做法是把「故障注入」纳入 agent CI——对计划用于搜索/客服场景的 agent，在沙箱中模拟网页 404、API 限流、文件缺失、超时等良性错误，把 agent 的越权率/重试爆炸率作为可观测指标，与 task success rate 同等纳入上线门槛。

7. Auditing Privacy in Multi-Tenant RAG under Account Collusion
3.55
Relevance 3 | Novelty 4 | Practical 3 | Evidence 4 | Timely 5

Summary: 多租户 RAG 服务通常以「每账号差分隐私」作为隐私边界，承诺每个账号的 query 对索引满足 (ε_acc, δ_acc)-DP。本文识别出关键漏洞：同租户内多账号串谋（same-index multi-account collusion）。DP 复合定理表明，k 个同租户账号协同时，对高斯加噪检索的联合泄漏以 Θ(√k·ε_acc) 的速率无条件退化；跨租户与外部串谋只在显式访问控制失败（M4）下才达到同样速率，未失败时这些情形按设计为零泄漏，本质上是架构审计而非 DP 审计。作者构造了一个达到该泄漏速率的攻击，并据此推导出一个 RAG 特异的成员推断（MIA）预测并实证检验。

Key insight: 对面向企业/团队的 RAG 搜索产品，把「每账号 DP」当作合规交付物时要留意：同一组织内的多账号本身就是合法的同租户访问者，串谋会让 ε 以 √k 速率退化，这是设计层面的洞，不靠加密或权限隔离能补。落地启示：(1) DP 预算要按租户而不是按账号设置上限；(2) 监控同租户账号间 query 重叠/互补模式，作为串谋检测信号；(3) 对外宣称的隐私保证文档要明确区分「DP 审计」与「访问控制审计」适用的威胁模型。

8. TideGS: Scalable Training of Over One Billion 3D Gaussian Splatting Primitives via Out-of-Core Optimization
3.50
Relevance 2 | Novelty 5 | Practical 3 | Evidence 4 | Timely 5

Summary: 在十亿基元规模训练 3D Gaussian Splatting (3DGS) 本质上是内存受限：每个高斯基元携带较大属性向量，聚合后参数表迅速超出 GPU 显存，先前系统在商品级单卡上只能跑到数千万个高斯。作者观察到 3DGS 训练天然稀疏且与相机轨迹强相关：每次迭代只激活当前相机批可见的高斯，因此 GPU 显存可作为「工作集缓存」而非「持久参数存储」。基于该观察，TideGS 通过 SSD-CPU-GPU 三级层次管理参数，三项关键技术协同：块虚拟化几何（SSD 对齐空间局部性）、层次化异步流水线（重叠 I/O 与计算）、轨迹自适应差分流式传输（只传相邻迭代的工作集增量）。实验显示 TideGS 在单卡上把可训练高斯规模推到十亿级，质量与时间成本相对此前方法显著改善。

Key insight: TideGS 演示的「working-set-as-cache + SSD-CPU-GPU 三级流水线」范式不止适用于 3DGS——任何参数表大于显存、但每步只用一小子集的训练任务（大规模 embedding table、动态稀疏 MoE、对话历史缓存）都可以借鉴这一架构。对搜索/推荐场景，超大规模 embedding 训练长期采用 PS 架构 + 跨机分片；TideGS 给出了一个更轻量的替代——单机异构层次缓存 + 轨迹/访问模式预取，把「下一步要哪些参数」做成可预测的差分流，能够显著降低分布式系统的运维复杂度。

Summary: NVIDIA 发布 NVIDIA-Verified Agent Skills 计划：基于 MCP（Model Context Protocol）连接的工具和「可移植 skill」体系，为自治 AI agent 提供「能力治理」层——对每个 skill 进行验证、签名与运行时策略约束。文章给出的工程动机是：开源模型 + MCP 工具 + 第三方 skill 让 agent 能力组合变得灵活，但也带来「未验证 skill 引入未知风险」的供应链问题；NVIDIA 把 skill 比作 npm 包，提出一套审核 / 验证 / 部署门禁来让企业用户能放心组合 agent 能力。

10. Federated Learning for ICD Classification with Lightweight Models and Pretrained Embeddings
3.00
Relevance 2 | Novelty 2 | Practical 4 | Evidence 4 | Timely 4

Summary: 本文系统研究在 MIMIC-IV 临床记录上做多标签 ICD 编码分类时，「冻结预训练文本 embedding + 轻量 MLP 分类器」组合在联邦学习（FL）设置下的可行性。区别于此前依赖集中训练或全量微调大模型的方案，作者用冻结 embedding 把模型体积压到最小，得到一个隐私友好、部署高效的 pipeline，特别适合分布在多家医院的临床 NLP。实验在集中式与联邦式两种配置下展开，覆盖 MTEB 排行榜上的 6 个公开 embedding 模型 × 3 种 MLP 分类器架构 × 2 种编码体系（ICD-9/ICD-10），并通过 10 次随机分层切分的消融评估性能稳定性。

Key insight: 「冻结 embedding + 轻量 head」是隐私敏感场景下被低估的稳健方案：embedding 由公开模型一次性生成，不需要把原始文本在联邦节点之间同步，整体训练通信量与算力开销与微调大模型相比降一两个量级。对社区搜索/UGC 场景中涉及个人信息的子任务（如举报分类、敏感内容识别、跨机构信用画像）同样适用——把任务变成「在不变的公开 embedding 之上学一个轻量分类头」，可以用最少的隐私交付物拿到接近端到端微调的性能，且 MTEB 排名能给一个相对可信的 embedding 选型起点。
