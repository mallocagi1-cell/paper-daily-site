1. Learning User Simulators with Turing Rewards
3.55
Relevance 3 | Novelty 4 | Practical 3 | Evidence 4 | Timely 5

Summary: 现有用户模拟器多用 LLM 去拟合单条 ground-truth 回复（最大化 log 概率或相似度奖励），难以覆盖真实用户回复的多样性。本文提出 Turing-RL：用一个 LLM 判别器充当“图灵奖励”，给定用户历史，对生成回复与真实用户回复的不可区分程度打分，再用强化学习训练模拟器去“骗过”判别器。在对话聊天与 Reddit 论坛讨论两个域上，Turing-RL 在 LLM 自动评测与人工评测上均稳定超过 log 概率/相似度奖励基线。

Key insight: 把“用户模拟”从监督拟合改成判别式 RL：奖励来自“像不像真人”而非“是不是那一条标准答案”，绕开了单点监督导致的回归到均值、回复趋同。对社区搜索/推荐的启示：可借此造更真实的 UGC 行为数据与离线评测环境（query 改写、点击/回帖模拟），Turing 奖励也能迁到会话推荐的用户侧仿真。代价是要额外训练判别器并跑 RL rollout，判别器质量直接决定模拟上限。

2. SAERec: Constructing Fine-grained Interpretable Intents Priors via Sparse Autoencoders for Recommendation
3.45
Relevance 3 | Novelty 4 | Practical 3 | Evidence 3 | Timely 5

Summary: 意图推荐通常直接从用户行为序列做聚类或原型学习抽意图，受序列质量影响大、需预设意图数、缺乏显式语义对齐，导致意图集粗糙不全。SAERec 用稀疏自编码器（SAE）从文本语料自动构建细粒度、可解释的意图空间来引导推荐：不把文本当旁路信号，而当作高信息密度证据，先抽出一组可解释意图，再据此组织推荐。本质是把机制可解释性常用的 SAE 单义特征思路迁移到推荐意图建模。

Key insight: 借 LLM 可解释性领域的 SAE 单义特征思路，解推荐意图“数目要预设、语义不明”的老问题——意图变成 SAE 的稀疏激活维度，天然可解释且无需人工设定意图数。对社区搜索的启示：UGC 短文本意图多变，从帖子/评论语料抽稀疏意图可用于 query 意图识别与结果解释；落地路径是先训 SAE 再接推荐，文本语料覆盖度决定意图完整性。

3. TWICE: Modeling the Temporal Evolution of Personalized User Behavior via Event-Driven Agents
3.15
Relevance 3 | Novelty 4 | Practical 3 | Evidence 3 | Timely 2

Summary: 用户模拟器常把用户建成静态人设或只喂通用历史，难刻画行为随时间演变。TWICE 是基于 LLM 的时间锚定个性化用户模拟框架：结构化用户画像 + 围绕人生事件/行为转变组织的事件驱动记忆模块 + 两阶段流程（事件 grounded 的内容规划 与 个性化风格适配相分离），让模拟器不只模仿“说什么”，还模仿“过往经历如何塑造后来的表达”。在大规模纵向 Twitter 数据上评测，并提出同时度量真实性、一致性、拟人度的评测框架。

Key insight: 把用户模拟的时间维度显式拆成“事件记忆 + 内容规划 + 风格适配”，相比静态人设能产出随时间漂移的行为轨迹。对社区搜索/推荐的启示：可用于长期兴趣漂移的离线仿真与冷启动数据生成，事件驱动记忆也可借鉴到长周期用户兴趣建模。局限：依赖纵向行为数据，本文为 2026-02 论文（已出近 7 天窗口），评测集中在社媒文本生成而非排序指标。

arXivSJTU2026-02-26Bingrui Jin, Kunyao Lan, Baihan Li, Mengyue Wu
