OpenZL: Using Graphs to Compress Smaller and Faster

Meta（Zstd 团队）提出 OpenZL，将无损压缩抽象成一个有向无环图（DAG）：图中每个节点是一种可组合的压缩算子（如 transpose、tokenize、字典编码、熵编码等），不同数据结构（列存表、时序、嵌入向量、protobuf 等）对应不同图拓扑。运行时携带极小的图描述，单一通用 decoder 即可解出全部应用专属压缩格式。在工业级数据集上，OpenZL 在压缩率与吞吐两方面同时超过 zstd 与多个特定领域压缩器，且新增数据格式无需为其单独开发/部署专用 codec。

KEY INSIGHT · 对业务意味着什么OpenZL 揭示出工业压缩长期的二选一困境（通用压缩器易部署但效率差 / 应用专用压缩器效率高但维护成本极高）可以用『图模型 + 单一 decoder』打通：搜索/推荐场景里的特征转储、向量索引快照、点击日志、用户行为序列等结构化数据，过去多采用零散的列存或自研编码，未来可用一套 OpenZL DAG 描述统一压缩管线，存储成本与冷启动加载延迟有望同时下降。来自 Zstd 原班团队、Meta 已在内部规模化部署，工程化可信度极高。

Migrating Data Ingestion Systems at Meta Scale

Meta

Meta 工程团队披露了将整个数据摄入（data ingestion）系统从『客户自管道』模式迁移到『自管理数仓服务』模式的过程：覆盖数万个摄入 Job、PB 级 MySQL → 数仓增量同步。迁移采用三阶段生命周期（shadow → reverse shadow → cleanup），通过持续行数/校验和对比、自定义调试工具、按问题区分批量回填策略、以及在元数据中标记问题分区实现快速回滚，最终 100% 平滑切换。

INSIGHT推荐/搜索系统对每日特征拼接、行为日志归档、画像维表的稳定性极度敏感，是『管线坏一点就全链路连环报警』的典型场景。Meta 这一套 shadow→reverse-shadow→cleanup 三段式迁移、双跑校验、分区级回滚的标准方法论，可以直接套到自研 Hive/Iceberg 升级、特征库换代或 ODPS 跨集群搬迁，避免一次性切换带来的特征断流和模型评估错位风险。

How to Eliminate Pipeline Friction in AI Model Serving

NVIDIA

NVIDIA 系统梳理了从训练到生产环节常见的『管线摩擦』：导出格式失败、目标 runtime 不支持的算子、动态 shape 引起的引擎重建、库/驱动版本错配引发的静默退化。给出的解决工具栈包括 TensorRT 做图简化与算子融合、Dynamo-Triton（原 Triton Inference Server）做多框架后端 + 动态 batching + 模型版本化，配合 trtexec / Nsight DL Designer / Nsight Systems 做层级与系统级 profiling。

INSIGHT搜索/推荐线上若要把 LLM 重排或多模态特征模型从离线训练顺利推到线上，最大的隐性成本不是模型质量而是 export / kernel 兼容 / version drift 这三类摩擦。文中给出的实操要点（在 CI 中加入导出可用性测试、用 min/opt/max 动态 shape profile 替代每次重建、NGC 容器锁版本、训练侧避开难部署算子）可以直接写进自研推理平台的发布规范，把『模型上线 P1 故障』数大幅压低。

Introducing NVIDIA Fleet Intelligence for Real-Time GPU Fleet Visibility and Optimization

NVIDIA

NVIDIA 推出 Fleet Intelligence：基于开源 host-side agent（构建于 DCGM、GPUd 与 Attestation SDK 之上）将整个 GPU 集群的功耗、温度、利用率、显存带宽、互联健康度（NVLink/PCIe）、ECC/XID/HBM 异常、驱动/固件/BIOS 一致性等遥测信息汇聚到云端控制面，提供实时告警（邮件/Slack）、历史回溯与基于密码学证明的 GPU 完整性校验。

INSIGHT对搜推 ML 平台，GPU 多租户/混合调度环境下的『静默退化』（个别节点 ECC、NVLink 降速）会直接导致训练 step time 突增或推理 P99 上升，但传统 Prometheus + DCGM Exporter 很难做到跨集群配置一致性比对与异常溯源。Fleet Intelligence 提供的『硬件×固件×驱动×负载』四维一致性视图与 cryptographic attestation 路线，适合作为内部 GPU 平台自建可观测体系的参考蓝本，尤其是在 H100/H200/B200 异构集群中。

To Redact, or not to Redact? A Local LLM Approach to Deliberative Process Privilege Classification

University of Amsterdam

论文围绕政府透明公开（FOIA / Woo）场景的敏感信息自动判定问题，提出在消费级硬件即可部署的本地 LLM（Qwen3.5 9B）方案：对每个句子设计 8 种 LLM 使用变体（zero-shot、few-shot、上下文窗口大小、判定与解释拆分等），系统比较其在 FOIA Exemption 5『审议过程特权』分类上的表现，证明本地小模型在合理 prompt 设计下可逼近第三方云 API 的效果。

INSIGHT对搜索/推荐侧的核心启发不在于 FOIA 业务本身，而在于『不能上云的判别任务用 9B 本地模型 + prompt 变体』的工程范式。社区搜索里大量审核/合规/隐私判定（违禁词、暴露 PII、未成年人保护）面临同样的『线上 API 不可用』约束。该论文给出了 prompt 变体的对比方法学，可作为内部本地小模型替换云端 LLM 的评估模板，特别是 Qwen3.5 9B 这一档位的可用性证据值得搜索安全策略团队收藏。

Maik Larooij, David Graus

Retrieval Mechanisms Surpass Long-Context Scaling in Time Series Forecasting

论文系统检验时间序列基础模型（TSFM, 含 PatchTST）的『长上下文越长越好』假设，发现 ETTh1 上存在明显反向缩放定律：3000 步窗口比短窗口性能下降超过 68%。作为对照，提出 Retrieval-Augmented Forecasting (RAFT)：以 720 步固定窗口 + 选择性检索历史片段，MSE 降到 0.379，全面超越长上下文 PatchTST 与同窗口非检索基线。

INSIGHT结论对搜索/推荐基建有重要参考：扩张 context window 是高成本（KV cache、attention 平方复杂度）路线，但在『信号-噪声比偏低』的业务序列（用户行为、广告 CTR 时序）里收益反而可能为负。RAFT 提供了一个低成本替代——固定短窗 + 检索式拼接相关历史片段——这条思路与生成式推荐中的长序列建模（item-specific 检索 vs item-agnostic 压缩）方向高度同构，值得在 ultra-long 用户行为序列建模上做平移验证。

Rishi Ahuja, Kumar Prateek, Simranjit Singh, Vijay Kumar

Neural at ArchEHR-QA 2026: One Method Fits All: Unified Prompt Optimization for Clinical QA over EHRs

University of Wisconsin-Madison

ArchEHR-QA 2026 共享任务获奖方案 Neural1.5：将临床记录上的 QA 任务拆分成『问题理解 → 证据识别 → 答案生成 → 证据对齐』四阶段独立模块，每阶段用 DSPy 的 MIPROv2 自动优化器联合搜索指令与 few-shot 示例；推理时通过 self-consistency 投票降低随机性，并对答案对齐阶段加入 self-reflection / chain-of-verification 等阶段专属验证机制。

INSIGHT这是 DSPy + MIPROv2 在严肃 QA 评测里的一次实战验证：把 prompt 工程从手工试错升级为可复现、可回溯、模块化的『编译流程』。搜索/推荐场景里 LLM 重排、query 改写、长尾问题理解等环节多被『跑几条 prompt 就收工』式工程拖累，借鉴该论文的『模块化 + MIPROv2 + self-consistency + 阶段专属校验』pipeline，可显著降低 prompt 漂移与回归风险，提升 prompt 资产的工程化程度。

Abrar Majeedi, Viswanatha Reddy Gajjala, Sai Prasanna Teja Reddy Bogireddy, Siddhant Rai

Sanity Checks for Long-Form Hallucination Detection

Los Alamos National Laboratory

论文提出受控不变性方法论评估幻觉检测器是否真的在评估推理链而非在『偷看答案』：Force 测试把每条响应的最终答案替换为 ground truth、保留推理轨迹；Remove 测试剥离答案宣告步骤、保留推理过程。结果显示多种主流幻觉检测器主要依赖答案级伪信号。在排除这些伪信号后，作者证明轻量级评分器 TRACT（基于 hedging 趋势、步长动态等词汇轨迹特征）即可与复杂学习表征齐平。

INSIGHT搜索/推荐线上对 LLM 答复做幻觉/不可信内容检测时，常见做法是再叠加一个『幻觉判别模型』，但这一模型可能只是学到了『最终答案模板』层面的相关性，离线表现好上线没收益。该论文的 Force/Remove 评测协议给搜索质量评估团队提供了一种验证『检测器是否捕捉到真正的推理质量』的标准化方法；同时 TRACT 类轻量词汇特征评分器在生产成本上比 LLM-as-judge 低数量级，是可落地的备选方案。

Geigh Zollicoffer, Minh Vu, Hongli Zhan, Raymond Li, Manish Bhattarai

Complete Evidence Extraction with Model Ensembles: A Case Study on Medical Coding

Fraunhofer IAIS

论文把『完整证据抽取』形式化：高风险决策（医保编码、合规审计）不仅要给出充分证据，更要枚举所有支持决策的输入 token。基于 Rashomon 效应，作者将多个性能相近模型的 token 级归因聚合为『集成证据』，仅用 3 个模型集成即超过任何单模型最佳，证据召回率显著上升，仅带来很小的 token 开销。

INSIGHT对搜索/推荐风控、推荐解释、广告合规审查等需要『完整证据』而不仅『充分证据』的场景，单模型 + SHAP/Grad-Cam 风险偏低召回。本文给出『多模型集成 + token 级归因聚合』的简单基线，工程化成本低（仅需 3 个性能近似模型并行推理），可作为现有解释/审查系统的快速升级路径，尤其在 LLM-as-explainer 不可控的情况下提供可量化的证据覆盖度指标。

Katharina Beckh, Sven Heuser, Stefan Rüping

Global-local Spatial-temporal Aware Graph Attention Network for Network Traffic Forecasting

NC State University

GLSTaGAT 针对网络流量预测中『预定义邻接矩阵丢失底层时间信息』与『空间/时间分离建模丢失联合依赖』两个痛点，提出数据驱动的时空融合图：在节点表示中同时编码全局长程依赖与局部窗口模式，再用图注意力做端到端学习。在多个公开网络流量数据集上稳定优于 GNN 及 STGNN 类基线。

INSIGHT对搜推基建侧的实际价值在于：CDN 流量、数据中心间链路、推荐服务 QPS、特征查询热度这些拓扑化时序信号都符合 GLSTaGAT 的『图结构 + 时空联合依赖』假设。论文证明把『全局长程』与『局部窗口』两类信号融合进图注意力可显著提升预测稳定性——可启发自研容量规划（capacity planning）与异常检测系统将原本独立的时空模型升级为时空融合图模型。

Jinming Xing, Guoheng Sun, Hui Sun, Linchao Pan, Shakir Mahmood, Xuanhao Luo, Muhammad Shahzad
