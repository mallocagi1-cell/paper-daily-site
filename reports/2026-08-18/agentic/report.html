1. Not All Tokens Are Equal: Inflation-Aware Routing for Agentic LLM Systems
4.15
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 论文指出，Agent 失败后的重试会让真实工作流成本显著高于单次模型调用，并将这一差异定义为 token inflation。InflationAgent 用四阶段路由器估计任务难度：多跳问答中 7B 模型的膨胀最高达 4.25 倍，局部推理得到的 CBE 信号预测高膨胀任务的 AUROC 为 0.887，再据语义交换率选择模型。

Key insight: 对社区搜索的多步检索或复杂问答，模型路由不能只看单次 token 价格，应把重试、反思和工具调用纳入端到端预算。可先在网关记录每类 query 的实际膨胀率，再用轻量难度信号把高风险请求升级到强模型，简单 query 则保持低延迟路径。

2. Amplified Does Not Mean Predictive: Reasoning Behaviors in Thinking Models
4.15
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 研究提出 Behavioral Lift，用来衡量某种推理行为出现时正确率的变化，并在 15 个模型、6 个基准和 15,282 条推理轨迹上分析行为与正确性的关系。结果发现，思考模型会放大自我纠错、假设检验和不确定性表达，但真正具有最高提升关联的行为是置信度校准、知识对齐和自我认知，存在明显的 Amplification-Lift Gap。

Key insight: Agent 的轨迹更长、更像在思考，并不等于检索答案更可靠。在线评测应把工具调用成功、证据对齐、置信度校准与最终答案分开打分，训练反思器时优先奖励能改变正确率的行为，而不是单纯奖励更长的 CoT 或更多自我纠错句子。

3. Repair, Not Improvement: Decomposing Constrained Decoding in Tool-Call Abstention
4.15
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 论文把工具调用约束解码拆成两个作用：限制生成何时停止，以及限制哪些 token 可以出现，并专门研究模型是否应该 abstain、不调用工具。作者在 0.6B 到 4B 的开源模型上，用匹配的英语和韩语样本评测；六个条件中有四个相对无约束解码出现显著负向差异，最差达到 29.5 个百分点。

Key insight: 搜索 Agent 的 JSON Schema 或 grammar 约束可能只修复格式，却意外压低“暂不调用工具”的正确决策。工程上应分别监控 tool-call validity、是否该调用和参数正确率，给 abstention 保留显式动作，并用无约束/约束双轨回放验证约束层到底是在纠错还是改变策略。

4. GRPO Beyond English: A Large-Scale Study of GRPO in Non-English and Multilingual Settings
4.00
Relevance 4 | Novelty 3 | Practical 4 | Evidence 4 | Timely 5

Summary: 这项大规模实证研究考察 GRPO 在非英语和多语言推理中的训练语言、基础模型与奖励语言效应。作者发现，用母语进行推理训练通常只与英语训练存在小幅差距，并且一种语言的训练可以迁移到多种语言；但趋势依赖模型和语言，部分组合会让其他语言的域外能力出现严重回退。

Key insight: 面向中文 UGC 搜索的 Agent 训练不能直接照搬英语 RLVR 配方。应按语言分别检查 query 改写、证据选择和工具参数的成功率，同时把跨语言迁移收益与域外回退放在同一张评测表里，避免总体平均分掩盖中文或方言 query 的能力损失。

5. CLAIR-Fin: An Adversarial Multi-Agent Framework for Claim-Level Verification and Adaptive Debate in Cross-Modal Financial QA
3.85
Relevance 4 | Novelty 4 | Practical 3 | Evidence 3 | Timely 5

Summary: CLAIR-Fin 用九个 Agent 处理跨模态金融问答中的事实核验，把问题拆成原子 claim 并放入类型化的 Financial Claim Ledger。框架按 claim 类型决定证据权威性，在草稿交接处检查 grounding，并按争议程度自适应增加反驳深度。

Key insight: 对社区搜索的高风险答案，统一在最终生成后做一次事实检查往往太晚。可以借鉴 claim ledger，把每个结论绑定到检索证据、来源类型和工具交接记录，再按争议程度分配验证预算；普通 query 走轻量检查，跨文档冲突才触发多 Agent 辩论。

6. Envs-FORGE: Frontier-Optimized Reward-Grounded Environment Synthesis for Agent RL
3.80
Relevance 3 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: Envs-FORGE 针对 Agent RL 中环境难度固定、奖励稀疏的问题，把验证器回报转成逐样本的环境生成动作。系统围绕目标学习前沿评估六个难度投影方向，再用混合整数线性规划选择动作，同步改写指令、fixture、标准答案、测试和 Docker 环境，只有金标准验证通过的任务包才进入训练。

Key insight: 搜索 Agent 的训练数据不应只靠静态 Self-Instruct 堆规模。可以按 query 通过率动态生成更难或更易的多跳检索任务，并把检索证据、工具返回和最终答案一起纳入可执行测试；这样更容易构造能暴露失败边界的难负样本，而不是只增加表面多样性。

7. A Survey of Large Language Model-Based Search Agents
3.80
Relevance 5 | Novelty 3 | Practical 4 | Evidence 3 | Timely 2

Summary: 这篇 ACL 2026 综述系统整理了 LLM 搜索 Agent 的架构、优化、应用和评测，重点覆盖动态规划、多轮检索以及自主信息搜寻。它把研究问题从“模型能否回答”扩展到“如何决定检索、怎样组织工具和如何评价全过程”，并归纳了当前搜索 Agent 的开放挑战。

8. Batch-wise Adaptive Pruning: Periodic Neuron Activation-Aware Weight Pruning for Language Reasoning Model
3.75
Relevance 3 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: 论文指出，面向长思维链的训练无关剪枝方法在批量推理时会失效：一个 batch 共享剪枝 mask，样本聚合后的激活分布与离线阈值不匹配，导致稀疏率漂移并使推理准确率崩溃。作者改用按周期执行的 top-k 选择，并围绕 batch 聚合激活设计适配批量场景的神经元剪枝流程。

Key insight: Agent 搜索通常同时处理多个 query，单请求上有效的推理稀疏化不能直接搬到批量服务。部署前应按 batch size、query 难度和工具调用轮次测量真实稀疏率与 nDCG/答案准确率，优先采用能随批次分布更新的 top-k 策略，并保留难例回退路径。

9. SimpleOPD: Simple Tokenizer-Agnostic On-Policy Distillation for Long-Context Reasoning
3.70
Relevance 3 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: SimpleOPD 研究长上下文教师向短上下文学生迁移推理能力时的 tokenizer 不一致、分布偏移、输出过长和训练不稳定问题。方法在共享文本空间中只对齐教师与学生占据相同文本跨度的 token，并加入 student reference KL loss，同时屏蔽终止 token 的优势，减少学生漂移和频繁截断。

Key insight: 深度研究 Agent 的成本瓶颈常在长上下文与多轮证据，而不是单次检索。可用共享文本跨度做 tokenizer-agnostic 蒸馏，把强模型的多步推理能力压到短上下文模型；上线前需单独检查证据完整率和提前终止率，避免压缩延迟却截掉关键引用。

10. Think in Latent, Explain in Language: Self-Explainable Latent Reasoning
3.50
Relevance 3 | Novelty 4 | Practical 3 | Evidence 2 | Timely 5

Summary: 论文提出 Self-Explainable Latent Reasoning，试图同时保留隐式推理的计算效率与可读解释能力。它用一个多任务训练目标让同一模型既在紧凑 latent 表征中完成推理，又生成与内部思考绑定的语言解释，针对既有黑盒 latent reasoning 和额外后验解码器之间的取舍进行统一设计。

Key insight: 搜索 Agent 可以把隐式规划用于节省 token，但检索、工具和权限决策仍需要可审计说明。实践上可让 latent planner 负责候选动作压缩，再要求它输出短的 query、证据和拒答理由摘要；不要把最终可解释性完全交给事后生成器，否则很难判断解释是否真正对应决策。
