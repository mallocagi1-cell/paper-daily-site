LASER: An Efficient Target-Aware Segmented Attention Framework for End-to-End Long Sequence Modeling

针对推荐系统中超长用户行为序列建模面临的 I/O 延迟高和注意力计算复杂度呈二次增长的问题，提出 LASER 框架。核心包含两大创新：(1) SeqVault——基于 DRAM-SSD 混合索引的统一 schema 感知服务基础设施，将检索延迟降低 50%、CPU 占用减少 75%；(2) 全局堆叠目标注意力 (GSTA) 模块，通过 sigmoid 过滤机制压缩长序列并捕获跨段依赖。在小红书超过 1 亿日活用户的大规模线上 A/B 测试中，ADVV 提升 2.36%，收入提升 2.08%。

问题与动机

现代推荐系统在实时建模超长用户行为序列时面临双重瓶颈：(1) 系统 I/O：获取数千条行为记录带来大量磁盘 IO、网络和序列化开销；(2) 模型计算：标准 self-attention 的 O(L²) 复杂度使实时推理变得不可行。传统方法要么截断序列（~100 条），要么使用两阶段检索管道（信息损失）。

方法概述

LASER 采用「先压缩后精化」策略：将用户序列分为固定长度段，每段通过分段目标注意力（STA）使用 sigmoid 门控聚合压缩；压缩后的段再通过全局堆叠目标注意力（GSTA）建模跨段依赖，生成精化表示用于 CTR 预测。配套 SeqVault 基础设施支持毫秒级长序列访问。

核心技术贡献

  1. SeqVault 服务：混合 DRAM-SSD 索引策略，检索延迟降低 50%，CPU 使用率降低 75%
  2. 分段目标注意力（STA）：用 sigmoid 替代 softmax 实现「静默机制」——不相关段趋近于零；低维投影降低计算成本
  3. 全局堆叠目标注意力（GSTA）：在压缩序列上操作，先执行全局变换再重塑的向量化实现替代逐段迭代
  4. 端到端系统设计：从基础设施到模型的完整方案，支持多场景统一长序列建模

实验结果分析

  • 离线评测（小红书广告数据集）：LASER 达 0.7826 AUC（+0.24%），超越 DIN (+0.12%)、HSTU (+0.20%)、Transformer (+0.22%)；FLOPs 仅为 Transformer 的 1/9（4.0×10⁷ vs 3.6×10⁸）
  • 在线 A/B 测试（7 天，10% 流量，1 亿+ DAU）：ADVV +2.36%，收入 +2.08%
  • SeqVault 基建：CPU 核数减少 14.8%，CPU 使用率降 75%，P99 延迟从 3-5ms 降至 ~2ms，磁盘使用减少 45%
  • 消融实验：时效性嵌入最关键（-0.09% AUC），多分辨率融合次之（-0.08%），sigmoid 优于 softmax（-0.03%）

局限与未来方向

优化针对特定工业场景（广告排序）；4000 条以上序列的扩展性未充分探索；非 CTR 推荐任务的效果未验证。

工业实践意义

LASER 是小红书在 1 亿+ DAU 上验证的端到端长序列解决方案。分段注意力的「先压缩后精化」设计在保持效果的同时将 FLOPs 降低 9 倍，是长序列建模的实用范式。SeqVault 基建设计（混合存储、schema 感知压缩）具有很强的工程借鉴价值。

CAMMSR: Category-Guided Attentive Mixture of Experts for Multimodal Sequential Recommendation

HKU📖 有深读 · 3 分钟

针对多模态序列推荐中现有方法依赖启发式融合策略、无法捕捉用户-模态交互的动态性和上下文敏感性的问题，提出 CAMMSR。核心创新是类别引导的注意力混合专家 (CAMoE) 模块，从多视角学习专化的 item 表征并显式建模跨模态协同，通过辅助类别预测任务动态分配模态权重。同时引入模态交换对比学习增强跨模态表征对齐。在 4 个公开数据集上持续超越 SOTA 基线。被 ICDE 2026 录用。

INSIGHTCAMMSR 的核心启示在于：用户对不同模态信息（文本、图片）的偏好并非固定不变，而是随品类和上下文动态变化。MoE 结构天然适合处理这种异质性——不同专家负责不同模态视角的特征提取，通过类别信号引导门控实现自适应融合。对于社区搜索场景中帖子包含文字、图片等多模态内容的情况，该方法可直接借鉴：根据搜索 query 的类别动态调整对不同模态特征的关注权重，提升多模态内容排序的精准度。

问题与动机

多模态序列推荐面临动态、上下文敏感的用户-模态交互挑战。用户在不同个体间甚至同一用户不同物品上的模态偏好差异显著。现有模型采用静态融合策略，无法捕捉组合模态信号产生的协同效应——某些情况下单独模态无法触发兴趣，但组合后可以。

方法概述

CAMMSR 集成四个核心组件：使用预训练 BERT 和 ViT 的物品表示初始化；类别引导的注意力专家混合（CAMoE）通过 K 个专用 FFN 专家进行注意力路由；基于 Transformer 的用户兴趣学习（使用 DyT 替代 LayerNorm）；模态交换对比学习增强跨模态对齐。

核心技术贡献

  1. 类别引导的模态权重分配：首个利用辅助类别预测来动态分配模态权重的框架
  2. CAMoE 架构：通过拼接专家输入高效捕获多视角表示和模态间协同
  3. 模态交换对比学习：序列级数据增强增强跨模态对齐
  4. DyT 替代 LayerNorm：动态 Tanh 操作作为高效归一化替代

实验结果分析

  • Toys 数据集：NDCG@5/MRR@5 = 0.0477/0.0421，分别提升 14.66%/15.98%
  • Games 数据集：提升 6.67%/9.72%
  • Beauty 数据集：提升 15.32%/21.04%（最大提升）
  • Home 数据集：提升 10.53%/15.50%
  • 噪声鲁棒性：30% 误导性类别噪声下仍保持优势（Toys NDCG@10: 0.0482 vs 去除类别引导的 0.0391）
  • 收敛效率：最快收敛（Games 65 轮），单轮训练 84 秒

局限与未来方向

30% 误导标签导致 11% 性能下降；需要可访问的类别元数据（可用 LLM 生成虚拟类别解决）；偏好驱动数据集（Toys/Beauty）上优势更大，功能性数据集（Games/Home）上优势较小。

工业实践意义

CAMoE 的类别引导模态融合思路可用于社区搜索中图文内容的动态融合——根据内容类别自适应调整文本和图片特征的权重。MoE + 对比学习的组合在多模态推荐中是高效的实践方案。ICDE 2026 论文，学术认可度高。

FlexRec: Adapting LLM-based Recommenders for Flexible Needs via Reinforcement Learning

YaleSnap

提出 FlexRec 框架，通过强化学习训练 LLM 在不同推荐场景下按需调整排序行为。核心解决两个问题：(1) 序列级奖励导致的粗粒度信用分配无法提供精细训练信号；(2) 交互反馈稀疏且噪声大，导致更新不稳定。采用闭集自回归排序设定，LLM 基于用户上下文和显式需求指令生成候选集的排列。方法通过 token 级奖励分解和课程式 RL 训练策略提升训练效率和稳定性。

INSIGHTFlexRec 的核心价值在于探索了 LLM + RL 在推荐排序中的新范式：通过自然语言指令定义推荐需求（如「偏重新鲜度」或「偏重相关性」），让排序模型按需灵活切换。这与传统固定目标函数的排序模型形成鲜明对比。对搜索推荐系统的启示是：未来排序模型可能从「训练时固定目标」演进到「推理时动态指令驱动」，实现更灵活的个性化。Token 级奖励分解的思路也可借鉴到现有 RL 调优的推荐模型中。

Yijun Pan, Weikang Qiu, Qiyao Ma, Mingxuan Ju, Tong Zhao, Neil Shah, Rex Ying

Refine-POI: Reinforcement Fine-Tuned Large Language Models for Next Point-of-Interest Recommendation

UNSWUUvA

针对 LLM 用于 POI 推荐时语义 ID 拓扑盲编码和 SFT 方法「答案固化」两大问题，提出 Refine-POI。核心创新包括：(1) 层次化自组织映射 (SOM) 量化策略生成拓扑感知语义 ID，确保码本中坐标邻近性反映语义相似性；(2) 强化微调 (RLFT) 替代 SFT，支持 top-k 排序列表生成和推理能力学习。方法突破了传统 SFT 只能产生 top-1 预测的局限。

INSIGHTRefine-POI 中的拓扑感知语义 ID 设计值得关注：传统推荐系统中 item ID 的编码往往与语义无关，而该方法通过 SOM 层次量化确保 ID 空间保持语义拓扑结构，使 LLM 能更好地利用 ID 间的相对关系进行推理。对社区搜索场景的启示是：UGC 内容的 ID 编码如果能融入语义信息（如主题、发布者社区属性），可能有助于提升 LLM 辅助排序的效果。RLFT 替代 SFT 训练排序模型也是重要趋势。

Social Knowledge for Cross-Domain User Preference Modeling

University of Haifa

提出利用大规模社交网络建模实现跨领域用户偏好预测。将用户投射到从 Twitter 大规模社交网络学习的社交嵌入空间中，在目标领域零样本设定下实现有效的个性化推荐。实验表明，该方法相比强基线（popularity-based）有显著提升，并揭示了嵌入空间中的人口统计特征与用户偏好的相关性。研究还探索了 LLM 辅助社交建模的潜力。

INSIGHT该工作的核心启示是社交关系图谱蕴含丰富的用户偏好信息，且这种信息具有跨领域迁移能力。在社区搜索场景中，用户的社交关系（关注、互动、社区归属）可作为冷启动和跨域推荐的重要信号源。零样本偏好预测能力对新用户或新内容品类的个性化排序特别有价值。社交嵌入 + LLM 的组合思路值得探索。

Nir Lotan, Adir Solomon, Ido Guy, Einat Minkov

Sharpness-Aware Minimization for Generalized Embedding Learning in Federated Recommendation

ZJU

针对联邦推荐系统中通用 item 嵌入学习的稳定性问题，提出 FedRecGEL 框架。在跨设备场景下，本地数据分布的异质性和稀疏性导致学习泛化嵌入极为困难。FedRecGEL 将联邦优化重构为寻找嵌入损失景观中的平坦最小值问题，通过锐度感知最小化 (SAM) 确保嵌入在不同客户端数据分布上的泛化能力。提出适配联邦场景的高效 SAM 变体，降低计算和通信开销。

INSIGHTFedRecGEL 的技术贡献在于将 SAM 引入联邦推荐场景，但其核心洞察——通过寻找平坦最小值提升嵌入泛化性——具有更广泛的适用性。在集中式推荐系统中，不同用户群体（子场景）之间的数据异质性同样会导致嵌入过拟合局部分布。SAM 类正则化方法可借鉴用于提升社区搜索中 item 嵌入在多样化用户群体上的泛化表现。

Fengyuan Yu, Xiaohua Feng, Yuyuan Li, Changwang Zhang, Jun Wang, Chaochao Chen
