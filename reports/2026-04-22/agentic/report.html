1. MemSearch-o1: Empowering Large Language Models with Reasoning-Aligned Memory Growth in Agentic Search

Relevance 4 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: 迭代式 agentic search 中 think-search 循环积累大量系统记忆，导致记忆稀释问题。本文提出 MemSearch-o1 框架，通过从查询中动态生长细粒度记忆片段（memory seed tokens），并利用贡献函数回溯和深度精炼记忆。在 8 个数据集上验证，该方法有效缓解记忆稀释，提升 LLM 在复杂多步搜索中的推理能力。

Key insight: MemSearch-o1 提出了「推理对齐的记忆增长」机制，核心创新在于将记忆管理与推理过程绑定：通过贡献函数评估每个记忆片段对最终答案的贡献度，动态裁剪低价值记忆。这对构建长会话搜索 agent 非常实用——在多轮搜索中保持上下文质量是工程关键痛点。seed token 机制可迁移到 UGC 搜索中的多轮对话场景。

2. AutoSearch: Adaptive Search Depth for Efficient Agentic RAG via Reinforcement Learning
4.10
Relevance 4 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: Agentic RAG 系统的多步检索交互常包含冗余搜索步骤，带来大量计算成本和延迟。本文研究搜索深度对准确率的影响，发现存在最小充分搜索深度（由问题复杂度和 agent 能力联合决定）。提出 AutoSearch RL 框架，在每步生成中间答案评估搜索充分性，奖励达到最优深度、惩罚过度搜索，实现 agent 自适应调整检索深度。

Key insight: AutoSearch 解决了 agentic RAG 中的关键效率问题：如何在不牺牲准确率的前提下减少检索轮次。其核心思路——通过自生成中间答案判断是否需要继续搜索——对搜索系统有直接借鉴意义。在 UGC 搜索场景中，复杂查询（如多条件筛选）与简单查询（如关键词搜索）需要不同检索深度，AutoSearch 的自适应机制可降低延迟和成本。Meituan 参与研发，有工业落地潜力。

Summary: 现有 GraphRAG 系统采用一刀切设计，对所有查询使用固定检索框架和单一大模型生成器，无法适配不同复杂度问题。本文提出 GraphRAG-Router，采用分层路由策略协调异构 GraphRAG 和多种生成器 LLM。通过 SFT 预热后两阶段 RL 优化（第二阶段引入课程式成本感知奖励），在 6 个通用和多跳 QA 基准上减少大模型使用近 30%，同时保持强泛化能力。

Summary: 通过 RLVR（带可验证奖励的强化学习）提升 LLM 推理能力已取得显著进展，但随着模型能力增长，构建高质量奖励信号愈发困难。本文系统研究三种弱监督设定（稀缺数据、含噪奖励、自监督代理奖励）下 RLVR 的效果。关键发现：能泛化的模型展现长时间的「预饱和阶段」（训练奖励和下游性能同步提升），快速饱和的模型则倾向记忆。推理忠实度是泛化成功的关键预测因子。

7. On the Reliability of Computer Use Agents
3.65
Relevance 3 | Novelty 3 | Practical 4 | Evidence 4 | Timely 5

Summary: 计算机使用 agent 在网页导航、桌面自动化等任务上快速进步，但即使任务和模型不变，同一任务重复执行也可能失败。本文通过 OSWorld 平台分析三类不可靠因素：执行随机性、任务规范歧义性、行为变异性。通过重复执行和统计检验发现，可靠性同时取决于任务规范方式和 agent 行为变化方式，建议采用重复评估协议并优先稳定性策略。

Key insight: 该研究为部署搜索 agent 提供了重要的可靠性视角：agent 的「一次成功不代表可靠」是关键发现。对生产系统的启示：(1) 搜索 agent 需要重复测试而非单次评估；(2) 任务规范越精确，agent 行为越稳定；(3) 执行随机性是固有属性，需通过多样本聚合或确定性回退策略应对。这些经验可直接迁移到搜索/推荐系统中 LLM agent 的线上部署。

Summary: LLM 控制器何时优于规则遍历的知识图谱探索？本文通过 RLM-on-KG 系统研究该问题，将 LLM 作为 RDF 编码 mention graph 上的自主导航器进行有依据的问答。与依赖离线 LLM 索引的 GraphRAG 不同，RLM-on-KG 在查询时执行实体优先的多跳探索，使用确定性图构建和固定工具集。核心发现是条件优势：LLM 控制的价值取决于证据分散程度——当证据集中时规则方法足够，分散时 LLM 导航显著优势。

10. A Reference Architecture for Agentic Hybrid Retrieval in Dataset Search
3.50
Relevance 3 | Novelty 3 | Practical 4 | Evidence 3 | Timely 5

Summary: 数据集搜索需要将欠规范的自然语言查询匹配到稀疏异构的元数据记录，单纯词法或稠密检索难以胜任。本文将数据集搜索重新定位为软件架构问题，提出有界可审计的 agentic 混合检索参考架构：通过倒排排序融合（RRF）组合 BM25 词法搜索与稠密嵌入检索，由 LLM agent 反复规划查询、评估结果充分性并决定何时终止。

Key insight: 该工作的参考架构设计思路对搜索系统有借鉴价值：(1) BM25 + dense retrieval + RRF 的混合检索被 LLM agent 协调，形成「有界的 agentic 检索」——agent 有明确的终止条件而非无限搜索；(2) 可审计性设计确保每步检索决策可追溯；(3) 将 agentic 检索建模为架构问题而非纯模型问题，更适合工程落地。
