Before Reasoning Can Fail: Pre-Evidence Procedural Failures in Agentic RAG

论文指出，Agentic RAG 可能已经搜到候选片段，却在未阅读证据前直接结束，导致错误并非来自最终推理。作者在 HotpotQA、2WikiMultiHopQA 和 MuSiQue 的 1.2 万条成对轨迹上分离两类失败，并加入 Read-Gate，要求搜索后先执行 read；对原本跳过阅读的轨迹，LLM-Acc 提升 14.9–19.9 个百分点。

HALT: Verification-Aware Stopping for Retrieval-Augmented Search Agents

HALT 将搜索智能体的停止条件从生成器置信度改为逐跳证据覆盖：先从问题生成预期 hop claims，再用轻量验证器为累计证据标记 MATCH、PARTIAL 或 NULL，只有所有 claim 被覆盖时才停止。论文在三个多跳问答基准上显示可减少冗余搜索，同时基本保持 Exact Match；消融表明收益来自 claim–evidence 对齐，而非固定轮数或词面重叠。

INSIGHT在 UGC 复杂检索中，搜索轮数上限不是好的成本控制信号，按子问题证据覆盖停止更容易解释和审计。可将 HALT 作为冻结现有 Agent 的旁路策略，输出每个 hop 的覆盖状态，并在无法可靠验证时主动 abstain；部署前需单独评估 claim 生成错误对召回和延迟的影响。

Daeyoung Roh, Donghee Han

SOP-Bench: A new benchmark for evaluating AI agents on real business procedures

Amazon

Amazon 的 SOP-Bench 将真实标准作业程序转为可执行 Agent 任务，覆盖 12 个业务领域、2,000 多个任务、工具接口与可核验答案。作者用 11 个前沿模型和两类 Agent 进行测试，发现工具从必需的 6 个扩展到 26 个时成功率近乎减半，最易与最难流程的正确率约为 90% 和 25%。

INSIGHT社区搜索 Agent 的评测不能只测单轮问答或工具选择，应把歧义理解、多工具协同、状态保持、失败恢复和最终结果一起纳入。SOP-Bench 的可执行任务与 ground truth 适合迁移为 UGC 搜索流程集：按业务意图拆 SOP、限制工具面、记录全轨迹，并用任务成功率而非 LLM 评审单一分数做上线门槛。

Rohith Nama, Nandi Subhrangshu

HyMem: Hierarchical Context Management for Long-Horizon Agents via Information Isolation

HyMem 针对长程 Agent 的上下文污染问题提出分层记忆管理：把高层计划、任务状态、执行轨迹等功能不同的信息隔离，而不是把所有历史当作一个扁平上下文统一压缩或检索。论文的核心假设是，长链路失败常来自中间输出挤占计划信息；分层存取可让 Agent 在持续检索和工具调用中保持目标。

INSIGHT短文本 UGC 搜索要支持多轮澄清、补搜和证据汇总时，应把用户目标、query 改写、已确认事实、候选证据和工具轨迹分层存储。工程上可先做轻量 schema 与不同 TTL，再比较全量上下文、摘要记忆和分层记忆的 nDCG、答案完整性、token 成本及长链路失败率。

NVIDIA AVO Reaches 100% on ARC-AGI-3, Demonstrating a Frontier-Level General-Purpose Architecture for Long-Horizon Autonomous Agents

NVIDIA

NVIDIA 的 AVO 将 Agent harness 设计成带持久记忆、监督器、工具调用和执行反馈的长程循环：检查上下文、规划、修改、运行验证，再根据结果继续搜索。其 GPU kernel 实验连续运行 7 天、探索 500 多个方向并提交 40 个版本，性能最高超过 cuDNN 3.5%、超过 FlashAttention-4 10.5%；在 ARC-AGI-3 公共集上完成 183 个关卡，RHAE 为 100.00。

INSIGHT对搜索 Agent，真正可迁移的不是某个模型的知识，而是‘假设—工具动作—反馈—记忆—恢复’闭环。可将 query 改写、检索、阅读、引用校验视为候选变更，把 nDCG、证据覆盖和 CTR 作为反馈；同时设置 supervisor 监控停滞与循环，避免无界搜索把成本转化为噪声。

Terry Chen, Yeyin Zhu, Zhifan Ye, Jean-Francois Puget, Humphrey Shi

Where Security Fits in an AI Agent Stack

NVIDIA

NVIDIA 将 Agent 栈拆为模型、harness、meta-harness、安全运行时和推理基础设施，主张把最终授权放在 Agent 无法修改的运行时与基础设施层。文章给出四级风险配置（隔离、连接、生产、对抗）以及最小权限、即时授权、隔离、审计等五条设计规则，并强调每个外部副作用都必须经过强制执行点。

INSIGHT社区 UGC 搜索会接触不可信帖子、链接和工具返回值，不能让 prompt 或 harness 单独承担安全边界。应把文档内容视为数据而非指令，按任务发放短时权限，对网络、数据库和发布动作做运行时拦截，并保留不可篡改的 search/read/tool/final 审计轨迹；这比单纯增加安全提示词更稳。

Johnny Greco, Kirit Thadaka, Ali Golshan, Alex Watson

Screenshots or Tools? Eliciting Tool Use and Managing Multimodal Context in Hybrid GUI-MCP Computer-Use Agents

论文研究 Agent 在截图操作与文本工具之间的选择，并在 309 个 OSWorld-MCP 任务上发现，同一套工具对推理模型提升 4.0 个百分点，却让非推理模型下降 5.9 个百分点。推理模型只在 309 个可用工具任务中的 55 个调用工具；去掉成功工具调用后冗余截图并重新训练，准确率达到 37.8% 对 33.0%，输入成本降到 53%。

INSIGHT工具接入不等于工具能力，Agent 是否理解调用语义和何时调用才是瓶颈。对搜索链路，应记录工具可达率、有效调用率、参数错误率和调用后的证据增益，而不是只统计工具数量；上下文压缩也必须与训练时的观察策略一致，否则节省 token 可能转化为理解损失。

EigentSearch-Q+: Enhancing Deep Research Agents with Structured Reasoning Tools

EigentSearch-Q+ 研究如何用结构化、工具介导的思考改善深度研究 Agent。系统让 Agent 在搜索与浏览之间进行显式规划、推理和证据整合，而不是只依赖自由形式的 ReAct 轨迹；论文围绕研究效率与鲁棒性比较结构化工具思考和常规研究流程。

INSIGHT在社区搜索中，结构化动作空间可以把‘继续搜什么、打开哪页、何时结束’从不可解释的长思维链变成可监控状态机。落地时可先用 schema 约束 query decomposition、search、open、extract、verify 五类动作，再用轨迹质量和单位答案成本评估是否值得引入更复杂的规划器。

ParEvalLayer: When Partial LLM-Agent Evaluations Support a Decision

ParEvalLayer 将 Agent 评测从‘提前公布一个部分分数’改为基于预先约定策略的 promote、reject、continue 或 abstain 决策层。它读取两个系统在相同任务上的成对结果，并在已完成基准的重放实验中验证：三个公开基准只观察 15%–25% 的任务结果就能得到与完整评测一致的结论，另一些基准则必须继续运行。

INSIGHTAgentic 搜索的离线评测应同时报告样本覆盖、未决比较和停止规则，避免早期任务偏简单造成虚假提升。对 nDCG、CTR、答案正确率和成本的联合实验，可以把 ParEvalLayer 的 abstain 机制用于自动决定是否扩大 query 集、是否进入 A/B 测试，而不是用一个不稳定的 partial score 直接做模型替换。

Wei-Jung Huang, Bonan Shen
