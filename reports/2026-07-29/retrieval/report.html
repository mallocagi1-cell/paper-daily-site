CORE: A Unified Cascaded Ordinal Relevance Estimation Framework for E-commerce Search

针对电商搜索相关性标签天然有序、普通多分类却把相邻与跨级误判等价的问题，CORE 将 High→Mid→Low 估计拆成级联二分类：LLM 侧采用逐级推理、剪枝与分层奖励，在线 BERT 侧使用多级分类头并承接蒸馏。美团离线工业集与线上 A/B 均验证有效，线上 bad-case 率下降 15.94%。

KEY INSIGHT · 对业务意味着什么核心价值不是替换更大模型，而是把业务标注规则的“等级顺序”直接写入推理、损失和蒸馏链路。社区搜索可按强相关、可替代、弱相关逐级判定，并让大模型生成的分层判断监督轻量线上模型；这样既减少严重跨级误判，也保留 BERT 级在线时延。

02 4.65

Towards a Relevance Posterior in Neural Information Access

University of Glasgow

论文把神经检索重述为“查询条件似然 × 查询无关先验”的近似后验推断，将文档效用等稳定信号移到离线计算，在线只做分数融合。学习到的先验使 TREC DL-2019/2020 一阶段 nDCG@10 最高分别增加 0.046/0.029，并让 RankZephyr 在 DL-2020 重排上增加 0.054。

INSIGHT搜索排序不必把所有判断都压在请求时的 query-document 交互中；内容质量、文档效用、作者可信度等查询无关信号可先形成可审计先验，再与语义相关性融合。对 UGC 搜索，这能在几乎不增加在线计算的情况下补偿纯相关性模型的偏差，并为后续个性化先验留下接口。

Andrew Parry, Emmanouil Georgios Lionis, Debasis Ganguly, Sean MacAvaney

03 4.45

Do Current Retrievers Cover All the Evidence? A Controlled Study of Conjunctive Cross-Page Retrieval

LG Uplus

论文用 1000 个查询、2021 份长文档和 70 种配置区分“找到相关文档”与“完整覆盖全部条件”。最强词法-视觉融合虽有 81.1% 的 Gold Hit@10，却只有 35.8% 能把全条件文档排在部分匹配前；按条件拆解提升 6.8–7.3 个点，融合再增 8.7 个点，而通用重排器反而退化。

INSIGHT多条件 query 的主要瓶颈不是召回率，而是排序分数允许某个强匹配条件掩盖其他条件缺失。社区搜索遇到“地点＋品类＋属性”组合需求时，应显式维护逐条件覆盖状态，以最弱条件或乘积聚合，并把部分满足样本作为硬负例；单纯扩大 embedding 模型或追加通用 reranker 并不可靠。

Sungguk Cha, DongWook Kim, Mintae Kim, Youngsub Han, Byoung-Ki Jeon, Sangyeob Lee

04 4.15

A corrective agentic hybrid RAG and an operations-grounded evaluation for a scientific facility

AArgonne

APS-RAG 将稠密、稀疏与知识图谱通道通过按查询类型自适应的 RRF 融合，再加入纠错循环和 MCP 工具执行，已部署于先进光子源运维知识检索。其 50 题 APS-Bench 上，严格关键事实召回从 BM25 的 63.8% 提升到 70.3%；移除 cross-encoder、改由 LLM 判相关会骤降 32.8%。

INSIGHT生产检索的可靠性来自可测的多路召回和专用相关性模型，而不是让生成模型包办排序。对企业或社区知识搜索，可先用 query 类型决定稀疏、稠密、图通道权重，再对低置信结果触发纠错；论文也提醒，图通道与 agent 循环的边际收益有限，应先把 cross-encoder 和评测集做扎实。

Rajat Sainju, Dariusz Jarosz, Hairong Shang, Michael Prince, Ryan M. Aydelott, Mathew J. Cherukara, ...

05 4.00

SOTA Search Over Academic Publications

EExa

Exa 上线面向约 3.5 亿篇出版物和 3000 万作者的生产搜索，使用 OCR/文档解析构建全文索引，融合开放网页与专用论文索引后再重排，支持用模糊记忆或实验事实查论文。其公开对比中召回率 86.4%、MRR 0.726、平均延迟 0.578 秒；Google Scholar 召回率为 28.0%。

INSIGHT垂直搜索的增益来自“专用语料结构＋开放网页覆盖＋统一重排”，而不只是更换 embedding。社区 UGC 搜索也可把正文、作者、话题、互动关系分别建模，再与全站索引融合；同时应增加“已知目标”和“模糊回忆”两类评测，避免只用关键词明确的查询高估线上体验。

The Exa Team

06 3.90

uircis at SemEval-2026 Task 8: A Unified Lightweight Pipeline for Multi-Turn RAG Evaluation

UUIR

该可复现单 GPU 管线用 Qwen2.5-7B 把多轮问题改写为独立 query，以 BGE-M3 召回 100 段，再由 BGE-reranker-v2-m3 输出 Top 10，官方 nDCG@5 为 0.4422。消融中重排将整体分数从 0.2705 提至 0.4210；改写帮助 CLAPNQ，却使 FIQA 从 0.2076 降到 0.1399。

INSIGHTquery 改写不是默认正收益：口语化、省略严重的社区对话可受益，但包含金额、日期、型号等精确约束的查询容易被改写漂移。可落地做法是先用规则或分类器判断是否需要改写，保留实体与数值约束，并把原 query 与改写 query 并行召回；reranker 则是更稳定的第一优先级。

Jiaqi Zhang, Wenbin Duan, Yingqi Zhang, Yan Li, Binyang Li

Query Refinement in Dense Retrieval Using LLM-Driven Relevance Feedback

FFerdowsi UniversitySShahrood UniversityUniversity of GonabadUniversity of Guelph

论文让本地 Mistral/Llama 判断首轮 Top 20 文档相关性，再用相关文档向量更新原 query，比较四种提示与两种更新公式。混合提示相对零样本最高提升 20.26% nDCG@10；加权更新 WRQU 在 DL19/20 最高提升 13.53%/11.99%，CQU 在 TREC-COVID 零样本设置提升 53.79%。

INSIGHT低资源搜索不一定先做领域微调，可把首轮召回当作伪反馈池，用 LLM 产生分级相关性，再以小权重更新 query embedding。实践中应优先试混合提示与 α≈0.1–0.5 的受控融合，并离线缓存或使用小模型；同时要防止错误伪相关文档把查询方向持续拉偏。

Seyedehfatemeh Karimi, Maryam Khodabakhsh, Havva Alizadeh Noughabi, Fattane Zarrinkalam

DeCoRAG: Cognitive Decoupling and Semantic-Aware Cropping for Complex Document Understanding

QQiYuanLabBBUPT

DeCoRAG 针对图表、表格等高密度文档中的“视觉注意力沉没”，先生成宏观语义锚点，再用 RAP-Crop 按意图剪枝和裁剪区域，将定位、语义解释与关系抽取解耦后构图并混合检索。复杂文档基准上语义通过率最高提升 12.5 个百分点，离线构图提示 token 减少 40.8%。

INSIGHT当有效证据只占页面很小区域时，整页送入 VLM 会同时浪费 token 并稀释语义；正确顺序是先用低成本全局锚点确定意图，再裁剪局部高价值区域精读。该设计可迁移到含截图、长图、商品参数表的 UGC 搜索，但需要可靠版面解析和离线构图管线。

Shuo Wang, Kai Zhang, Wenyuan Huang, Yizheng Yu, Xia Liao, Junming Su, Qing Wang, Fang Xi

TechSSN at SemEval-2026 Task 8: MTRAG Retrieval and Generation using Ensemble Re-encoders and Anchor Prompting

SSSN

TechSSN 将 BM25、BGE-base、E5-base 通过 RRF 融合，再用三个 cross-encoder 加权重排，官方检索 nDCG@5 达 0.5337、位列 38 队第 7。开发集消融显示，BM25 的 0.1274 经混合召回升至 0.2958，加入 query 改写到 0.3561，再增加 E5 通道后达到 0.4573。

INSIGHT词法、不同稠密编码器和 cross-encoder 的误差具有互补性，简单 RRF 往往比强行统一分数空间更稳。社区搜索可保留 BM25 保障实体词和新词召回，再让两类 embedding 扩大语义覆盖，最后把有限候选交给重排；上线前应按 query 类型监控各通道增益与延迟。

Anne Jacika J, Anishka K, Guruprakash K, Rajalakshmi Sivanaiah, Angel Deborah S

Caraman at SemEval-2026 Task 8: Three-Stage Multi-Turn Retrieval with Query Rewriting, Hybrid Search, and Cross-Encoder Reranking

UUBB

该系统用 699 条样本 LoRA 微调 Qwen2.5-7B 做多轮 query 改写，再以 BM25+BGE 召回、RRF 融合和 BGE-v2-m3 重排，官方 nDCG@5 为 0.531，较主办方基线高 10.7%。BGE-v2-m3 在 50 候选时为 0.416，明显高于 MiniLM 的 0.375；多 query 扩展反而降低效果。

INSIGHT精简、可控的单次改写优于盲目生成更多 query，且技术类语料适合确定性解码，开放域才需要少量随机性。可在社区搜索按领域设改写温度，并跳过已独立完整的首轮 query；论文实测跳过首轮改写保持 nDCG 不变，同时将该阶段耗时降低 29%。

David-Maximilian Caraman, Gheorghe Cosmin Silaghi
