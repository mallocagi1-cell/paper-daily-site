SIDScope: A Diagnostic Resource for Semantic-ID Interfaces in Generative Recommendation

论文提出SIDScope，用于系统诊断生成式推荐中的Semantic ID接口。它统一规范item-to-code映射、校验来源与连接关系、分析前缀结构，并追踪生成路径能否解析到候选物品；在Amazon与Yelp的9组tokenizer导出、7个家族上发现，接口健康度不是单一指标，前缀对齐在前缀检索时更能预测候选暴露。

Semantic Trimming and Auxiliary Multi-step Prediction for Generative Recommendation

📖 深度解读 · 8 分钟 →

STAMP针对高粒度Semantic ID带来的序列膨胀和效果波动，提出语义裁剪与辅助多步预测的双端优化框架。作者将问题归因于Semantic Dilution Effect：冗余token增加训练计算，却稀释本就稀疏的推荐监督；方法同时提高输入信息密度和输出监督密度，并在多个公开推荐数据集上验证。

INSIGHTSemantic ID不是越细越好，过长的物品码会让推荐模型承担大量低价值自回归步骤。工程上可先按信息增益裁剪尾部token，再用多步辅助目标补足稀疏监督，并同时监控训练吞吐、序列长度和召回覆盖，而不是只看最终命中率。

Tianyu Zhan, Kairui Fu, Chengfei Lv, Zheqi Lv, Shengyu Zhang

How Generative Recommenders Are Redefining RecSys at Scale

NVIDIA

NVIDIA工程文章从训练与推理基础设施角度总结生成式推荐的规模化路径，聚焦序列化用户行为、Transformer式建模以及GPU加速下的吞吐和时延权衡。它将生成式推荐放回消费互联网的大规模候选排序场景，强调训练数据、模型容量、缓存和服务系统需要协同设计。

INSIGHT生成式推荐落地不是替换一个排序网络，而是重新设计数据管道、序列缓存、并行训练和在线服务。实践中应先拆分离线重模型与在线轻模型，建立每次扩容带来的效果、显存、吞吐和P99时延曲线，再决定是否继续放大模型。

ICICLE: Expanding Retrieval with In-Context Documents

ICICLE将生成式检索的增量建库改写为in-context retrieval：新文档及其docid在推理时提供，模型同时利用参数记忆与上下文证据生成标识。框架用[COPY]路由区分上下文检索和参数检索，再配合偏好校准与大上下文适配；在MS MARCO和NQ320K上评估了新增文档检索能力。

INSIGHTUGC或商品目录持续增长时，完全参数化的生成式检索会被反复训练和灾难性遗忘拖慢。可把新内容先放入上下文证据池，以路由器选择参数记忆或显式复制，再用离线校准控制新旧文档之间的偏置，降低增量上线成本。

Yu-Chen Den, Yung-Yu Shih, Zhi Rui Tam, Kuan-Yu Chen, Pu-Jen Cheng, Yun-Nung Chen, Eugene Yang

PILOT Technical Report

PILOT把推荐系统优化建模为受约束的在线树实验，由三个角色组成：Experiment Manager负责实验全生命周期，Search Planner为用户分群提出决策树，确定性服务负责安全、统计和权限边界。它针对现有方案只响应指标变化、不能复用实验方法的问题，把任务接入、观测治理、异常恢复和复盘放进统一控制回路。

INSIGHT推荐Agent应被放在可审计的实验控制面，而不是直接修改线上策略。对社区搜索或推荐业务，可让LLM生成分群假设和实验树，但由规则引擎限定合法命令、流量边界和停止条件，最终沉淀可复用的实验知识。

AI in Search Reduces Publisher Referrals Without Improving User Experience: Experimental Evidence

论文对Google Search开展预注册现场实验，样本量为1,100人，比较AI Overviews、AI Mode及无生成摘要条件。结果显示，移除两类生成体验会提高用户向出版商的点击率，而仅使用AI Mode会降低出版商点击率，并削弱用户对搜索信息的体验与信任，说明生成式搜索改变了注意力流向。

INSIGHT生成式答案不能只用回答质量或CTR评估，还要同时看外链点击、用户信任和内容生态收益。对UGC搜索，建议保留可展开的证据卡和作者页入口，做分流实验观察答案摘要是否吞噬原帖点击，并把长期留存纳入目标函数。

Stephanie T. Wang, Jeffrey Gleason, Yakov Bart, Christo Wilson, Dana\'e Metaxa

推荐系统进入“大模型时刻”：昇腾NPU如何支撑千亿级生成式推荐落地

Huawei

这篇中文工业实践围绕昇腾NPU支撑千亿级生成式推荐，讨论端到端用户行为建模、FuXi模型、多阶段统一建模、分布式训练和低时延推理。文章报告引入真实熵后，Performance Law曲线的R²从0.8776提升到0.9881，为用可解释的性能定律规划模型规模和算力投入提供了工程案例。

INSIGHT推荐Scaling Law需要和业务真实熵、样本分布及硬件效率绑定，单看参数量容易误判收益。可以先用真实熵校准离线损失与线上指标的关系，再按训练成本、显存、吞吐和P99时延建立扩容门槛，避免盲目追求千亿参数。

More Context, Same Budget: Dual-Bounded Relational Recall Beyond Top-K Retrieval

DBRR研究在固定检索单元数和token预算下，把相关性选出的seed与受限的图邻接证据组合起来，突破扁平Top-K只能返回独立片段的限制。在7,405个FullWiki问题上，主要配置将完整支持证据恢复率提高23.8个百分点，说明关系扩展可以在不增加预算时补齐多跳证据。

INSIGHT社区问答和长帖搜索常把相关片段分散在同一实体、事件或对话链上。可以在召回后增加小范围关系扩展，但必须保留总token上限，并用完整证据集恢复率而非单段相关性衡量扩展是否真正帮助生成答案。

Tunable LLM-based Proactive Recommendation Agent

Tunable LLM-based Proactive Recommendation Agent把主动推荐建模为LLM Actor-Critic Agent，根据实时反馈动态调整推荐，并用三类奖励函数优化长期收益。论文针对传统推荐容易固化用户既有兴趣、难以持续培育潜在兴趣的问题，报告了在多步推荐与反馈适应上的实验优势，并公开代码。

INSIGHT主动推荐的关键不是让LLM一次生成更长的理由，而是定义跨多轮行为的奖励与安全边界。落地时应把短期点击、内容满意度、探索率和负反馈共同纳入奖励，限制连续探索次数，并为每次策略调整记录可回放的用户状态。

Mingze Wang, Chongming Gao, Wenjie Wang, Yangyang Li, Fuli Feng

CG-MAR: LLM-Based Multi-Agent Recommendation System via Community Graph

CG-MAR提出基于社区图的多Agent推荐框架，把用户时间信息、社区关系、主题TF-IDF表示、下一跳转移先验和会话共现模式放入可追踪的候选闭环。系统通过多个Agent协同生成与融合证据，试图缓解单纯Prompt推荐的时序缺失、跨域复用不足和幻觉不稳定问题。

INSIGHT对社区平台，用户兴趣既来自个人行为，也来自群体结构和会话共现。可先把图特征与LLM生成的兴趣解释作为离线重排信号，保留确定性候选集合和证据链，再通过小流量实验验证多样性、长尾曝光和CTR是否同时改善。

Xingfa Yang, Jun Yin
