Cognition on Graph: Navigating Massive Knowledge Space via Cognitive Cycles and Bidirectional Graph-Text Synergy

CoG 面向大规模图谱与文本混合知识库，通过计划、探索、反思的循环组织多跳检索，并从文本抽取实体反向引导图谱遍历。七项问答基准使用相同 Qwen3-32B 骨干；MuSiQue 的 EM 为 27.8%，高于 IRCoT 的 20.6%，平均访问文档数为 2.6，而 ToG-2 为 32.5。

MemRetriever: Learning to Search, Reflect, and Retrieve from Long-Term Memory

MMemTensor

针对跨会话记忆需要多轮补全、静态召回混入噪声的问题，MemRetriever 将并行搜索、串行补证和反思去噪交给独立策略模型，并用监督预热与 GRPO 训练。在 LOCOMO 上，4B 模型经强化学习后评判准确率由 0.785 升至 0.830，平均 token 从 754 降至 673。

INSIGHT社区帖子、评论和历史问答可复用其搜索决策层，让模型先判断证据缺口，再决定补查或停止。应把证据覆盖、噪声比例与回答充分性分别评估，并联动观察 nDCG 和调用成本；LongMemEval 的部分 nDCG 指标并未随 RL 提升，不能将整体收益理解成所有检索指标全面领先。

Ruiyang Jiang, Chunyu Li, Zhiyu Li

Iris: Climbing to the Search Frontier

Iris 从网页链接图反向构造多跳任务，筛选需要证据才能回答的问题，再交替进行 SFT 与真实搜索环境中的 RL，并回收高质量轨迹。开启上下文管理后，Iris-pro 在 BrowseComp、中文版本、DeepSearchQA 和 HLE 上分别达到 88.6、85.1、92.9 和 56.4；结果来自单个 ReAct Agent。

INSIGHT社区复杂搜索可借鉴从已有证据链反向构造训练问题，再过滤闭卷可解样本，减少模型依赖记忆而绕过检索的情况。评估时应固定工具、上下文长度及裁判，并分别报告启用和禁用上下文管理的表现；论文还只是计划发布权重与完整方案，实际复现成本和社区短文本迁移效果仍需核验。

GAUGE: When Not to Trust LLM-as-a-Judge in User-Simulated Evaluation of Task-Oriented Agents

GAUGE 检查模拟用户与 LLM 裁判构成的离线发布门槛，是否与可验证任务成功一致，覆盖六家提供方的 25 个 Agent。被评为满意的对话中有 57.5% 实际未完成任务；能力差距较大模型对的排序分歧低于 1%，但接近的强模型对达到 31%，说明主观评分容易失去区分度。

INSIGHT社区问答 Agent 的体验评分不能替代可验证的证据覆盖和任务完成率，尤其是两个候选系统表现接近时。可先用真实完成信号校准裁判，再把主观满意度作为辅助观察，并监测回复截断；上线前应将 nDCG、引用正确性与 CTR 分开评估，防止选择了措辞更好但解决问题更差的模型。

Umesh Bodhwani, Thanh Tran, Kai Wei

ToolGrad: Efficient tool-use dataset generation with textual "gradients"

Google

Google 的 ToolGrad 先生成可执行的工具链，再生成对应问题，以提议、执行、选择和更新四个模块逐轮扩展合成数据。官方报告数据生成通过率 99.8%；用 ToolGrad-500 微调的 Gemma-3-12B 在 BFCL 得分 83.1，对照 Gemini-2.5-Pro 为 83.2，展示了少量高质量调用数据的价值。

INSIGHT可从社区搜索真实接口出发，先验证搜索、读帖和补查链路，再反向生成训练需求，减少不可执行样本进入训练集。实践时应把参数合法性、证据相关性和最终回答质量分别过滤；BFCL 衡量工具调用能力，与搜索 nDCG 或 CTR 不同，还需要在未见过的社区意图及接口组合上做迁移验证。

Zhongyi Zhou, Ruofei Du

Autonomous Research for Open-Ended Problems: A Case Study on Telecom Ticket Retrieval

论文以电信工单检索为开放式工业研究案例，让商业和开源 Agent 探索表示、架构与训练数据构造。少量人工监督下，自动研究达到 Recall@1 0.34，对照人工方案为 0.38；研究周期约十周，对照十个月，每轮 Cursor 研究活动成本最高约 200 美元，同时仍存在创造性和运维开销限制。

INSIGHT对社区短文本搜索，可把 Agent 用于有明确离线反馈的参数、样本和表示实验，并保留人工对研究方向的判断。论文显示自动化较擅长狭窄优化空间，不能从接近九成的离线检索表现推导出完全替代研究人员；应预先冻结评测集，记录每轮成本，并以 nDCG 和线上 CTR 重新验证迁移价值。

Junghyun Min, Huseyin Uzunalioglu, Mohamed Trabelsi

Local Edits, Global Ripples: Replay-Informed Policy Adaptation for Workflow Synthesis

RIPPLE 针对 Agent 提示策略的局部修改会影响下游执行、多个独立有效修改组合后可能有害的问题，先定位失败所属策略段，再在同一起始策略上比较单项收益，并重放组合后的执行。合成留出基准 Flow-HO 上验证成功率最高提升 23.1%，另两种冻结骨干也取得正向收益。

INSIGHT对社区搜索 Agent 的查询改写、工具选择和结果核验提示，可采用局部修改加完整轨迹重放的发布流程。单项改写通过测试之后，仍需在累计修改上检查证据选择、资源解析和最终回答，避免局部收益互相抵消；目前证据来自合成工作流，应在真实搜索日志上验证 nDCG、失败率和运行成本。

Persistent Teacher Anchoring for Tool-Using Agents

Sogang UniversityUniversity of Michigan

PTA 针对学生工具调用在教师监督前已经执行、导致后续状态偏移的问题，将分块验证扩展为整轮提交：只有教师验证完一轮，工具调用才进入环境。相同下游 RL 预算下，检索与感知任务的宏平均 best@4 相较 OPKD 分别增加 2.5 和 2.8 个点，持久前瞻调度使吞吐提升 24%。

INSIGHT训练社区搜索 Agent 时，可在轨迹采集阶段验证整轮查询和工具参数，减少错误调用产生的状态污染。教师检查应覆盖执行前边界，而不仅校正自然语言；同时需要衡量教师成本及并发利用率，论文中的吞吐收益来自特定采样调度，不能直接等同于线上搜索延迟下降或 CTR 上升。

R2VC: Modular Fact-Checking with Retrieval, Verification, and Confidence Calibration

R2VC 将事实核验拆为混合检索、候选生成、外部验证与置信度校准四个模块，生成器采用监督微调和 DPO，NLI 交叉编码器选择证据支持的判定。8B 骨干在 FEVER 上较基线报告 13.74% 的准确率提升；移除候选选择后准确率降至 76.24%，移除校准后 Brier 分数达到 0.161。

INSIGHT社区搜索回答可借鉴独立验证器和可拒答置信度，将检索错误与推理错误分开归因，而不是让生成器同时裁判自身输出。作者分析的 250 个错误中，错误实体证据仍是主要瓶颈，因此应先改进 query 实体消歧和证据召回，再验证校准效果；这些离线核验指标不能直接当作 CTR 增益。

Dhruv Dixit, Paritosh Pandey

Repair Before Reinforce: Context-Augmented Knowledge Graph Reasoning for Multi-Hop Question Answering

论文研究多跳知识图谱问答，将同一文本块的支持三元组加入目标关系，构成上下文图监督，并在强化学习前修复低跳事实错误。Qwen3-14B 在清洗后保留的一跳验证集达到 100% 准确率，随后以低跳样本训练 RL，考察三、四、五跳泛化；实验使用胃轻瘫和糖尿病两个领域图谱。

INSIGHT其启示是先排查证据和低跳知识错误，再增加复杂推理奖励；社区搜索可借鉴同源帖子上下文保留及错误样本隔离流程。这里的 100% 只针对清洗后保留的一跳验证集，不能解释为原始问题完全解决；迁移到 UGC 还需处理观点冲突、时间变化及实体歧义，并验证多跳答案的引用完整性。

Tharaka D. Fonseka, Niraj K. Jha
