Kimi K3 Is Here: Efficient Day-0 Support on vLLM

vLLM 为 2.8 万亿参数 Kimi K3 提供首日可用的生产服务方案：每 token 激活 896 个专家中的 16 个，并联合管理 KDA 循环状态与全注意力 KV 缓存。在 16 张 NVIDIA GB300 上，DSpark 将单用户输出从 118 提升到 370 token/s，达到 3.14 倍加速；自研集合通信核较 NCCL 快 1.7–4.5 倍。

How GPT-5.6 fuses frontier intelligence with frontier efficiency

OpenAI

OpenAI 将 GPT-5.6 的效率优化扩展到模型推理与多智能体工作流。Sol 在 Agents’ Last Exam 得分 53.6，比 Claude Fable 5 高 13.1 分；中等推理档仍高 11.4 分且估算成本约为四分之一。其 max 档在 Artificial Analysis 指数中以约一半成本、少 61% 的耗时达到相差不到 1 分的能力。

INSIGHT模型选型应从“单次 token 单价”转向每个成功任务的端到端成本，并把工具轮次、输出 token 和完成时延一并纳入。对社区搜索，可将 query 改写、意图分类和轻量摘要路由给较小档位，仅把长链路诊断或复杂检索升级到 Sol/max；并用固定离线集校验质量—成本前沿，避免默认使用最高推理强度。

Parallel All the Way Down: Beyond Single-Token Generation with Speculative Decoding

Red HatVvLLM

vLLM 与 Red Hat AI 开源支持 P-EAGLE、DFlash、DSpark 三种并行草稿算法，把逐 token 自回归草稿改为一次预测整块候选。P-EAGLE 稀疏化未来位置，DFlash 将验证器状态注入 KV 缓存，DSpark 再加入顺序校正与置信头；公开配置覆盖 Qwen3-8B 单 A100、Qwen3-30B-A3B 双 A100 和 Gemma-4-31B 双 A100。

INSIGHT并行草稿把草稿成本与候选块长度解耦，使更强的草稿模型和更长的候选块变得可用，但验证计算仍可能成为新瓶颈。搜索链路部署 LLM 重排时，可从低熵、模板化输出先试用 DSpark，并基于接受 token 数、验证器浪费和尾延迟调参；论文博客未给统一数值表，必须在自有 query 分布上复测。

Announcing vLLM AFD Plugin: Disaggregating Attention and FFN for Flexible MoE Serving

VvLLM

AFD 插件把 MoE 的有状态 Attention 与路由 FFN 拆成可独立扩缩的服务，同时保留 vLLM 调度器和 OpenAI 兼容接口。DeepSeek-V3.2 W8A8 在昇腾 910C 上采用 64A16F 拓扑时，16K/32K 输入的单位芯片吞吐较 EP64 提升 11.3%/9.0%；异步 prefill 小规模实验把 12 RPS 下 P50 TTFT 从 15.1 秒降到 8.0 秒。

INSIGHTAttention 的瓶颈随序列长度和 KV 压力变化，FFN 则受专家路由与通信支配，统一拓扑往往无法同时高效。社区搜索的 MoE 推理池可按短 query、高并发和长上下文三类流量分别测算 A/F 比例；但当前结果使用强制均衡和缩减模型，只适合验证架构方向，不能直接外推生产收益。

How to Self-Host a Validated AI Coding Assistant with NVIDIA NeMo Guardrails

NVIDIA

NVIDIA 给出可复制的内网编码助手链路：以 BF16 StarCoder2-7B NIM 提供兼容 OpenAI 的服务，前置 NeMo Guardrails，再由 CI 检查测试、SAST、密钥、幻觉依赖和许可证。试点只需一张至少 24GB 显存的 A10、L4、L40S 或 A100；提交 trailer 与 Prometheus/Grafana 继续追踪缺陷逃逸和回滚。

INSIGHT可审计 AI 服务的控制面应放在模型外部：策略拒绝、依赖验证、版本固定和结果指标分别由成熟工程系统负责。社区搜索团队部署内部 LLM 工具时，可沿用同一分层，把敏感索引与权限路径设为人工专属，并要求 AI 变更通过比基线更严格的门禁；模型升级时无需重写治理链路。

ScoreShield: Differentially Private Release of Similarity Scores

ScoreShield 面向会返回余弦相似度的 RAG、检索和推荐 API，先按全局敏感度加入高斯噪声，再把结果投影回合法余弦对象集合，从而满足向量或 Gram 矩阵发布的 (ε,δ)-DP。完整两两相似度发布时，其平方 Frobenius 风险随记录数的依赖由朴素高斯机制的 Θ(n³) 改善到固定隐私参数下的 O(n²)，并在 5 类任务上评测。

INSIGHT向量检索接口即使不返回原始 embedding，相似度分数也可能泄露成员关系；隐私治理不能只保护索引文件。社区 UGC 搜索若向外提供相似内容 API，可按批量查询、top-k 和全矩阵三种发布模式分别校准敏感度，并把隐私预算、排序损失和投影开销纳入上线门槛，避免简单逐维加噪造成不可用结果。

Behrooz Razeghi, Parsa Rahimi

07 3.85

Shieldstral

MMistral AI

Shieldstral 是 3B 参数、可按策略适配的多模态安全分类器，将不同审核体系统一为二元问答，从而混合训练异构内容安全数据。团队公开约 5,410 万样本的数据构建方案与细粒度策略适配评测；该模型在文本安全基准上匹配或超过参数量近 7 倍的模型，并在多模态安全分类上达到新 SOTA。

INSIGHT二元问答接口把“策略变化”与“模型结构”解耦，适合内容规则频繁调整的社区平台。可将帖子、图片和评论审核统一为策略文本加 yes/no 判断，先让 3B 模型承担高召回初筛，再把边界样本升级到更强模型或人工；上线时必须按具体社区规则重建校准集，不能只依赖公开安全榜单。

Antonia Calvi, Avinash Sooriyarachchi, Giada Pistilli, Guillaume Lample, Maarten Buyl

OmniDelta: Skill-Driven Budget Allocation for Token Compression in OmniLLMs

OmniDelta 是免训练的全模态 token 预算分配器：先用音频/视频技能池按 query 意图调整模态间预算，再依据局部复杂度与时间冗余分配到片段和帧，并可叠加现有剪枝器。在 4 个音视频基准、两种 Qwen2.5-Omni 模型上形成新的精度—效率前沿；7B 模型仅保留 25% token 时，显存降低 22.0%，端到端加速 1.64 倍。

INSIGHT固定比例剪枝忽略了不同 query 对声音、画面和时间片段的需求差异，预算分配应先于 token 选择。社区视频搜索可按意图动态侧重语音、字幕或关键帧，并在不改变总保留率的前提下复用现有剪枝器；上线需分内容类型检查召回损失，防止少数弱信号 query 被过度压缩。

Haoyang Huang, Wenjie Huang, Tianqi Xu, Hongyaoxing Gu, Kang Tan

Reinforcement Learning for Code Optimization

该工作把执行时间变成可学习的 RL 信号：DMC-Optim 提供校准沙箱和大规模优化测试，离线模拟器筛选奖励配置，再针对稀疏、带噪计时改造 GRPO。严格 top-50% pass@1 在 Qwen2.5-7B 上由 18.0% 升至 31.3%，CWM-32B 由 30.7% 升至 50.4%；沙箱退化时仍比标准 RLVR 高 100%–200%。

INSIGHT性能奖励若受计时抖动和稀疏正确样本支配，直接套用 RLVR 会同时损害速度与正确性。搜索基础设施可借鉴其校准沙箱与离线配置模拟器，让模型生成向量算子、SQL 或特征代码时先过语义等价测试，再优化真实硬件延迟；奖励需基于多次稳健统计，不能用一次 wall-clock 结果更新策略。

Pierre Chambon, Kunhao Zheng, Juliette Decugis, Benoit Sagot, Gabriel Synnaeve

Parallel Decoding Distillation for Fast Image and Video Generation

PDD 用轨迹蒸馏让一次网络计算并行预测多个去噪步骤，避开 VSD 与对抗损失常见的优化不稳和模式坍塌；训练不依赖 JVP 或有限差分，可接入预训练扩散/流模型并支持可变 NFE。在 LTX-2.3 文生视频音频、Wan-14B 文生视频和 Qwen-Image 文生图上，4–8 次函数评估达到 SOTA，同时明显改善视频多样性。

INSIGHT把多步迭代折叠为一次并行预测，是降低生成式多媒体服务延迟的通用方向；可变 NFE 也便于按流量和质量要求动态降级。它与社区搜索主链路关联较弱，但对封面生成、视频摘要等离线任务有参考价值；采用前应逐项检查多样性、运动一致性与峰值显存，避免只看平均生成速度。

Neta Shaul, Chao Liu, Arash Vahdat, Julius Berner
