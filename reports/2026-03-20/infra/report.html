1. FlashAttention-4: Algorithm and Kernel Pipelining Co-Design for Asymmetric Hardware Scaling
4.25
Relevance 4 | Novelty 5 | Practical 4 | Evidence 4 | Timely 4

Summary: 针对 NVIDIA Blackwell (B200) GPU 上 attention 计算的新瓶颈——张量核吞吐翻倍但共享内存带宽和指数运算单元未同步扩展——FlashAttention-4 重新设计了算法与 kernel 流水线。核心技术包括全异步 MMA 操作、软件模拟指数与条件 softmax 缩放（减少非矩阵运算）、以及利用 tensor memory 和 2-CTA MMA 模式降低共享内存流量。在 B200 上实现 BF16 下 1613 TFLOPs/s（71% 利用率），比 cuDNN 9.13 快 1.3 倍，比 Triton 快 2.7 倍。

Key insight: FlashAttention-4 的核心洞察是硬件代际升级存在「非对称扩展」问题——计算单元快速提升而内存带宽和辅助运算单元增长缓慢，因此算法设计必须随硬件演进同步调整。对搜索/推荐系统的启示：部署在 Blackwell GPU 上的 Transformer 模型（如 embedding、reranker）可直接受益于该优化，长序列推理延迟可显著降低。全部使用 CuTe-DSL (Python) 实现，编译速度比 C++ 模板快 20-30 倍。

2. ZipServ: Fast and Memory-Efficient LLM Inference with Hardware-Aware Lossless Compression
4.15
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: ZipServ 提出面向 GPU 架构的无损模型压缩推理方案，解决现有方法因变长比特流与 GPU 并行执行模型不匹配导致推理减速的问题。核心设计包括：kernel 级别的定长编码方案适配 GPU warp 执行、算子级别的压缩感知内存管理、以及系统级别的自适应选择压缩/非压缩路径。在保持比特精确推理的前提下，实现显著的内存节省和推理加速。

Key insight: 无损压缩在 LLM serving 中常被忽视，原因是 GPU 上解压开销抵消了内存节省收益。ZipServ 证明通过硬件感知的编码设计可以同时实现内存压缩和推理加速——这对资源受限场景（如搜索排序模型的在线部署）有直接参考价值。关键技术思路是将压缩粒度对齐 GPU warp 大小，消除序列化解压瓶颈。

3. The 1/W Law: An Analytical Study of Context-Length Routing Topology and GPU Generation Gains for LLM Inference Energy Efficiency
4.05
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 论文推导出 LLM 推理的「1/W 定律」：每瓦特可处理的 token 数量在上下文窗口翻倍时减半。在 64K 上下文下，H100 仅能并发 16 个序列，而 4K 下可并发 256 个。同一硬件集群上，因上下文长度不同，能效差异可达 40 倍。基于此推导出按上下文长度路由的最优拓扑，分析了 H100 到 B200/GB200 的代际收益。

Key insight: 1/W 定律为搜索/推荐系统的 LLM serving 容量规划提供了理论基础：短查询（如 UGC 搜索的 query 理解）和长文档处理应路由到不同的 GPU 集群。论文量化了 KV-cache 对并发度的影响，对实际部署中的 GPU 选型和上下文长度策略制定有直接参考价值。Blackwell 代际升级在长上下文场景收益更大。

4. BATQuant: Outlier-resilient MXFP4 Quantization via Learnable Block-wise Optimization
3.95
Relevance 4 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: MXFP4 格式是新一代加速器（如 NVIDIA Blackwell）的原生量化标准，但现有 PTQ 方法（尤其是旋转基方法）在 MXFP4 下性能严重崩溃。BATQuant 分析发现根因是 block-wise 缩放和细粒度格式之间的不匹配，提出可学习的 block-wise 优化策略，包括自适应 block 划分和异常值感知的缩放因子学习，显著提升 MXFP4 量化质量。

Key insight: MXFP4 是下一代 GPU 硬件原生支持的量化格式，掌握其高效量化方法对未来模型部署至关重要。BATQuant 揭示了现有 rotation-based PTQ 在 MXFP4 上失败的根因——block 缩放粒度与格式特性不匹配——并提供了针对性解决方案。对搜索排序模型的 4-bit 部署具有前瞻性参考价值。

7. Speculative Decoding: Performance or Illusion?
3.65

Summary: 首个在生产级推理引擎上系统评估 speculative decoding (SD) 的研究。发现在研究原型和小 batch size 下报告的加速在真实部署场景中大幅缩水：当 batch size 增大、请求并发提升时，SD 的额外计算和内存开销抵消了跳步收益。论文量化了 SD 的有效适用范围，并分析了其在 vLLM/SGLang 等框架上的实际表现。

9. Learning When to Attend: Conditional Memory Access for Long-Context LLMs
3.45
Relevance 3 | Novelty 4 | Practical 3 | Evidence 3 | Timely 5

Summary: 论文观察到大部分 token 不需要对整个序列做全局 Attention，可以仅依赖局部上下文。提出条件内存访问机制：为每个 token 学习一个门控信号决定是否激活全局 Attention，大部分 token 仅使用局部窗口。这将 Attention 的二次复杂度降低到近似线性，同时保持长距离依赖能力。

Key insight: 条件 Attention 是对「全局 vs 局部」注意力的自适应折中——比固定窗口更灵活，比全局 Attention 更高效。对长文档搜索场景（如 UGC 内容理解、文档排序）中的 Transformer 推理优化有直接启发：大部分位置无需全局信息，按需激活可大幅降低推理延迟。

10. PRISM: Demystifying Retention and Interaction in Mid-Training
3.35
Relevance 3 | Novelty 3 | Practical 4 | Evidence 4 | Timely 5

Summary: PRISM 对 LLM mid-training（预训练后、指令微调前的中间训练阶段）进行了系统性实证研究。在 7 个基座模型（Granite, LLaMA, Mistral, Nemotron-H）、两种架构（dense Transformer 和 attention-Mamba 混合）、3B 到 24B 参数规模上开展对照实验，揭示了 mid-training 中数据混合比例、学习率策略和知识保留之间的关键权衡。

Key insight: Mid-training 正成为 LLM 训练流水线的标准阶段，但缺乏系统性的设计指南。PRISM 首次跨模型、跨架构验证了 mid-training 的关键设计选择，对搜索/推荐领域的垂直模型训练（如领域自适应）有直接实践参考价值。特别是 attention-Mamba 混合架构的实验为新型架构选型提供了数据支撑。
