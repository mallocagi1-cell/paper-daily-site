Adaptive Model Compression (AMC): Saliency-Driven Resource Allocation for Ultra-Low-Power Transformer Inference

针对边缘设备上 Transformer 静态推理对所有 token 使用同等精度、导致能耗与内存浪费的问题，AMC 按 token 显著性动态分配计算资源：高显著信息保留全精度，低显著信息同时降低秩与位宽。45nm CMOS 实验显示，系统能耗下降 59.2%，吞吐提升 2.24 倍，准确率代价仅 3.6%。

Post-Train NVIDIA Cosmos 3 in One Day Using Agent Skills

NVIDIA

NVIDIA 将 Cosmos 3 Nano 的 LoRA、评测、数据检查和 AutoML 搜索封装为 TAO Agent Skills，使编码代理可自动修补数据配置并启动训练容器。8 张 A100 上约 30 分钟把验证准确率从 54.41% 提升至 87.14%，43 组并行 AutoML 试验在 19.5 小时内进一步达到 93.35%，LoRA 所需 GPU 时约为全参 SFT 的七分之一。

INSIGHT这项实践的价值不只是“用 Agent 跑训练”，而是把训练配方、数据格式、基线评测、容器启动和部署约束固化成可复用技能。搜索团队可借鉴这种受控自动化：让代理负责可审计的配置生成与故障修复，同时强制先跑基线、保留实验记录，并把超参搜索与最终线上灰度分开。

Supercharging LLM inference on Google TPUs: Achieving 3X speedups with diffusion-style speculative decoding

GoogleUCSD

Google Cloud 与 UCSD 将 DFlash 块扩散式投机解码接入开源 vLLM TPU 栈，让草稿器以一次 O(1) 前向生成整块候选 token，消除传统自回归草稿的 K 次串行瓶颈。TPU v5p 上平均 tokens/s 提升 3.13 倍，复杂数学任务峰值接近 6 倍；端到端服务加速 2.29 倍，高于 EAGLE-3 的 1.30 倍。

INSIGHT投机解码的上限常由草稿阶段而非大模型验证阶段决定，因此优化重点应从“更小的自回归草稿器”转向与硬件并行单元匹配的块级提议。若搜索系统使用生成式 query 改写或答案生成，应按真实批量和接受长度测试 DFlash，并把草稿开销、验证吞吐与输出质量拆开监控。

Weiren Yu, Yarong Mu, Lihao Ran, Zhaoxiang Feng, Yiming Zhao, Hao Zhang

Context by Distinct Information: An Auditable Dirichlet-Process Working Memory for Long, Redundant Context Streams

论文把长上下文的计量单位从 token 改为“不同信息”：新键仅在足够新颖时占用缓存槽，并按任务依赖将内容分别送入新颖性缓存、状态空间摘要或近期窗口。字符级对照中，新颖性门控仅关注约一半 token 即达到全注意力性能；在千事件医疗序列上，组合组件优于全注意力及固定预算淘汰策略。

INSIGHTUGC 搜索会反复出现模板化帖子、重复评论和近似行为事件，按 token 扩展 KV 缓存会为冗余内容持续付费。可审计的新颖性缓存提供了另一条路径：保留可回溯的代表模板，把统计性历史交给摘要状态，把局部依赖留给滑窗；但作者也表明短而局部的序列仍更适合普通滑窗。

GIGP+: A CPU-GPU Co-Processing Engine for Multi-Vector Retrieval.

PolyUSUSTech

GIGP+ 面向 ColBERTv2 等多向量检索，把 CPU 方案 IGP 的低候选开销与 GPU 大规模并行结合，设计并行候选生成内核、降低同步成本的分数重排及批处理调度。SIGIR 2026 摘要报告，相比 PLAID-GPU，QPS 提升 11.0 倍、延迟降低 7.6 倍且精度相当；相对先进 CPU 方案，每美元查询量提升 2.3 倍。

INSIGHT多向量召回的系统瓶颈并非只能靠扩大 GPU 暴力解决，候选剪枝质量、同步次数和批调度必须共同设计。对短文本社区搜索，可先以真实 token 数和候选分布复现延迟收益，再决定是否将 late-interaction 用于全量召回或仅用于高价值 query 的精排补充。

LightMem-Ego: Your AI Memory for Everyday Life

Zhejiang University

LightMem-Ego 为手机和 AI 眼镜上的持续视听流构建轻量级多模态记忆：先把视频与音频对齐到统一时间线，再组织为当前、短期和长期三层记忆，并按查询动态路由检索层级。系统支持寻物、对话回忆、生活摘要和习惯发现，代码已公开；当前摘要未给出延迟、内存或准确率的量化对比。

INSIGHT分层记忆与动态路由同样适用于搜索用户上下文：即时会话、近期兴趣和长期偏好不应进入同一个索引或共享同一刷新频率。工程试点应明确每层的写入成本、保留周期、召回触发条件和隐私边界，并用消融实验确认路由器确实减少无关上下文而非隐藏召回损失。

Xiaomi

FAIR GraphRAG: A Retrieval-Augmented Generation Approach for Semantic Data Analysis

RRWTH Aachen

FAIR GraphRAG 以 FAIR Digital Object 作为知识图节点，把核心数据、元数据、持久标识符和语义链接统一封装，并用 LLM 辅助构建 schema 与抽取内容。胃肠病 RNA 测序案例构建了 1,038 个节点，除因原数据缺失许可而未满足 R1.1 外覆盖其余 FAIR 条件，并改善复杂元数据与本体链接问题的问答覆盖和可解释性。

INSIGHTGraphRAG 的长期维护问题往往不在图算法，而在数据对象缺少稳定身份、许可、血缘和可复用元数据。社区搜索若要把帖子、作者、话题和审核规则组织成图，可借鉴 FDO 式节点契约；不过该论文的生物医学规模较小，迁移前需验证增量更新、权限过滤与高并发查询成本。

LATO.2: Factorized 3D Mesh Generation with Vertex and Topology Flow

HUSTMMeshy AITUM

LATO.2 将 3D 网格生成解耦为顶点流与条件连接流，两阶段共享粗体素骨架并分别使用 VAE，从而避免连续几何与离散拓扑在同一潜空间中互相干扰。分块生成可在固定潜变量容量下提高网格分辨率，移动第一阶段顶点即可自适应更新拓扑且无需重新优化；实验报告几何与连接质量超过现有拓扑感知方法。

INSIGHT该工作与搜索业务相关性有限，但代表了新模型基础设施中常见的有效原则：把统计性质不同的对象拆成独立生成阶段，再通过共享骨架维持一致性。多模态 UGC 团队可关注其开源资产管线和分块生成方式，但在进入生产候选前仍需补齐速度、显存和版权数据评测。
