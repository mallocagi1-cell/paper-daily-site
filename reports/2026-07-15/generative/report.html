Serving the Long Tail: Training-Free LLM Candidate Generation for Vacation Rental Marketplaces

VrboExpedia Group

Vrbo 面向无行为信号的长尾房源提出免训练候选生成：LLM 依据静态属性生成多样语义查询，文本编码器向量化后在 1170 万房源 ANN 索引中检索，再以 Union 策略与 IBKNN 合并。该方案保证不损害原行为通道排序，同时为零候选和稀疏房源补充可解释的语义邻居。

INSIGHT对新帖子、低曝光内容等社区长尾，LLM 更适合离线生成检索意图，而不是直接承担在线全库排序。将生成查询、向量召回与既有协同召回做保序融合，可低风险增加覆盖；上线时应分别监控长尾覆盖、候选重合率与主通道指标，避免语义通道挤压成熟行为信号。

An LLM-powered Agentic Recommendation System for Connected TV Content Discovery

Meta

Meta 构建面向 Connected TV 内容发现的混合 Agent 推荐架构，用 LLM 吸收热点、新闻、文化事件和跨端行为等异构信号，再由主题检索、媒体检索排序和主题排序等专门组件协作。工程重点是组件级缓存、链式检索和吞吐优化，以缓解 LLM 推理时延并保留传统模型的检索效率。

INSIGHT生成式推荐的现实落点往往不是单模型替换，而是让 LLM 负责解释和编排非结构化上下文，让成熟召回排序模型负责规模、延迟与精度。社区搜索可采用“LLM 生成主题/约束—传统检索执行—轻量模型重排”的分工，并用可缓存的中间主题表示降低在线成本。

Bi-Level Optimization for Generative Recommendation: Bridging Tokenization and Generation.

USTCBeihang UniversityNUSUpwork

BLOGER 将物品 tokenizer 与自回归推荐器建模为双层优化：内层训练推荐器，外层同时利用重构损失和推荐损失更新 tokenizer，并用元学习与梯度手术处理目标冲突。在 Amazon Beauty 上 R@5 从 ETEGRec 的 0.0413 升至 0.0444；移除梯度手术后降至 0.0329。

INSIGHT语义 ID 的质量必须由下游推荐目标反向约束，单独优化重构往往只得到“语义相似”却不利于行为预测的码。工程上可先以低频外层更新接入现有 tokenizer，并监控码本利用率和梯度冲突；该方法每轮 26.6 秒，对比 TIGER 的 23.7 秒，具备渐进式试验空间。

RouteRec: Strict Evaluation of Recommender-Agent Selection and Aggregation

RouteRec 在严格五折无泄漏协议下比较请求级选路与物品级聚合，覆盖 4 个传统推荐 Agent 和 1 个 LLM 重排器。MovieLens-1M 上请求级硬选择 HR@10 仅 0.223，低于 BM25 的 0.254；门控全 Agent 聚合达到 0.295，但需 70.2% 的 LLM 调用。

INSIGHT在候选稀疏场景中，整单选择一个 Agent 的动作粒度过粗，物品级融合更能利用互补信号。社区搜索若组合协同召回、语义召回和 LLM 重排，应先做逐候选分数校准与成本门控，并以严格 OOF 数据训练路由器，防止离线泄漏制造虚假的选路收益。

User Preference Induction with LLMs for Offline Top-N Recommendation Evaluation

UUniversidade da Coruña

论文用两阶段 LLM 补全离线 Top-N 评测标签：先从历史交互归纳可复用的用户偏好画像，再对多推荐器 pooled candidates 中的未标注物品做个性化相关性判断。实验覆盖 MovieLens 32M 与 Goodbooks-10k、每库 31 个运行；500 用户子样本的 NDCG@100 排名相关分别达 0.9525 和 0.9532。

INSIGHT把未曝光当负例会系统性偏向热门内容，尤其不利于评估生成式或长尾召回通道。可将 LLM judge 限制在多系统候选池内，并同时输入紧凑偏好摘要与原始行为证据；实践中应把它定位为补充 qrels 的审计工具，而非替代线上点击或人工标注。

Generative Chinese Statute Retrieval

Tsinghua University

GCSR 将中文法条检索改写为序列生成任务，用同时编码法律层级与语义信息的多粒度结构化 DocID，把法条知识内化进生成模型，并通过多任务训练缩小口语化查询与正式法条语言的鸿沟。论文报告其在法条数据上持续优于稀疏、稠密及法律领域专用基线。

INSIGHT多粒度 DocID 能把显式内容层级与语义匹配统一到生成路径，对社区短文本可迁移为“频道—主题—帖子”的结构化标识。关键是保留稳定的业务分类前缀，再让细粒度 token 学习语义；上线前需补充 item-level 碰撞检查和增量内容更新机制。

Beyond the Single Path: Divergent Reasoning for LLM-based Recommendation.

该 SIGIR 2026 工作针对 LLM 推荐中过度依赖单一路径推理的问题，引入发散式推理，让模型并行探索多种偏好解释与候选选择路径，再汇总形成最终推荐。会议元数据确认其属于 LLM-based Recommendation 核心方向；当前抓取记录未提供完整摘要和可核验的具体实验数字。

INSIGHT社区兴趣往往具有多面性，单条思维链容易把一次行为误当成稳定偏好。可在离线阶段生成若干互补意图假设，再由轻量排序器按历史一致性和候选覆盖度聚合；但在拿到完整实验前，不宜直接把推理路径数量当作效果提升，应先验证成本、稳定性与可复现性。

Consensus vs. Dissent: Dynamic LLM Modeling of Subjective Preferences in Group Recommenders

论文用 DeepSeek-V3.1 蒸馏推理数据和人工真值微调 Judgmental Llama/OLMo，在多个社会选择聚合策略产生候选后，动态选择最符合公平、满意与共识感知的结果。面向 284 名参与者的用户研究显示，该方法在满意度和群体共识评分上最高，并能识别少数派与联盟结构。

INSIGHTLLM 的价值不是直接生成唯一推荐，而是把难以写成固定公式的主观公平约束转为可学习评审器。对社区多人场景或多目标推荐，可先保留若干可解释的聚合候选，再让判断模型按群体结构选择；同时必须独立评估少数意见覆盖，避免“共识”掩盖弱势偏好。

Cedric Waterschoot, Nava Tintarev, Francesco Barile

Generative Conversational Recommender Systems: A Comprehensive Survey

这篇已被 ACM TORS 接收的综述系统整理生成式会话推荐，将架构划分为统一式、模块式与 Agent 式，并覆盖基础模型适配、推荐与回复联合生成以及评测方法。它提供的是方法版图而非单一模型结果，适合用于梳理偏好询问、物品选择和自然语言解释之间的接口。

INSIGHT会话推荐的关键设计选择是模块边界：统一模型一致性更强但难控，模块化链路便于替换和审计，Agent 架构适合多步工具调用但成本更高。社区搜索可优先采用模块化基线，把 query 澄清、召回、排序和解释分别评测，再逐步合并确有协同收益的环节。
