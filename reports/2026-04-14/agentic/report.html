1. VISOR: Agentic Visual Retrieval-Augmented Generation via Iterative Search and Over-horizon Reasoning
4.30
Relevance 4 | Novelty 5 | Practical 4 | Evidence 4 | Timely 5

Summary: VISOR 解决了 agentic 视觉检索增强生成(VRAG)中的两个关键瓶颈:视觉证据稀疏性和短视推理问题。该方法通过跨页面推理和超视野规划机制,在多步迭代检索中实现了更精准的证据聚合。在多个视觉文档问答基准上,VISOR 显著优于现有 agentic VRAG 系统。

Key insight: VISOR 的核心创新在于将跨页面证据整合与超视野推理相结合,让 agent 在检索时不仅关注当前页面,还能规划后续检索步骤。这种先规划后检索的范式对搜索系统中的多轮查询理解和长链路推理有直接借鉴意义,尤其适用于需要跨文档综合信息的复杂搜索场景。

2. EigentSearch-Q+: Enhancing Deep Research Agents with Structured Reasoning Tools
4.25
Relevance 4 | Novelty 5 | Practical 4 | Evidence 3 | Timely 5

Summary: EigentSearch-Q+ 提出了一组结构化推理工具(Q+),受 Anthropic think 工具范式和信息检索文献启发,使 deep research agent 的搜索行为更加有目的性。Q+ 通过引导查询规划、监控搜索进度和从长网页中提取证据,解决了现有 agent 隐式无结构搜索导致的冗余探索和脆弱证据聚合问题。

Key insight: Q+ 将搜索过程从隐式推理转为显式工具调用,核心设计包括查询规划工具、搜索进度监控器和证据提取器。这种结构化方法可直接应用于搜索系统的 query 分解和多轮检索场景,为构建可控可解释的搜索 agent 提供了工程化思路。

3. From Reasoning to Agentic: Credit Assignment in Reinforcement Learning for Large Language Models
4.20
Relevance 4 | Novelty 5 | Practical 3 | Evidence 4 | Timely 5

Summary: 系统性分析了 LLM 强化学习中的信用分配问题,区分了推理 RL(单次 CoT 生成中 500-30K+ token 的信用分配)和 agentic RL(多轮环境交互中的信用分配)两个范式。论文提出了统一框架来理解 token 级和 step 级信用分配方法的优劣,为搜索推荐系统中的 agent 训练提供了理论基础。

Key insight: 论文首次系统性地将 reasoning RL 和 agentic RL 中的信用分配问题统一分析,揭示了长链路推理中 sparse reward 的根本挑战。对搜索系统而言,这项工作为训练能进行多步检索和推理的搜索 agent 提供了关键的 RL 训练方法论指导。

4. Process Reward Agents for Steering Knowledge-Intensive Reasoning
4.15
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 针对知识密集型推理任务,现有过程奖励模型(PRM)无法有效验证中间推理步骤的正确性--不同于数学或代码,知识密集领域的步骤验证需要综合大量外部知识源。本文提出 Process Reward Agent,将检索增强的验证机制嵌入推理过程的每一步,有效防止错误在推理链中传播。

Key insight: 将过程奖励模型升级为 Agent 形式,在每一步推理中主动检索外部知识进行验证,这是对 RAG + reasoning 结合范式的重要推进。对搜索系统而言,这种逐步验证机制可应用于复杂查询的分步推理过程,提升搜索结果的事实准确性。

4.05
Relevance 4 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

7. SPPO: Sequence-Level PPO for Long-Horizon Reasoning Tasks
3.85
Relevance 3 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: SPPO 提出序列级 PPO 方法解决 LLM 长链路推理任务中的信用分配和内存效率问题。标准 token 级 PPO 在长 CoT 场景下不稳定且内存开销大,而 GRPO 等无 critic 方法虽缓解了这些问题但计算开销显著。SPPO 在保持训练稳定性的同时降低了计算和内存成本。

Key insight: SPPO 是对 GRPO 和标准 PPO 的折中方案,通过序列级奖励分配避免 token 级信用分配的不稳定性。对于需要长链路推理的搜索 agent 训练(如多步检索加推理),SPPO 提供了更实用的 RL 训练框架选择。

8. MemReader: From Passive to Active Extraction for Long-Term Agent Memory
3.75
Relevance 3 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: MemReader 将 agent 长期记忆从被动提取转为主动提取。现有系统将记忆提取视为一次性被动转录,难以处理对话中的噪声、缺失引用和跨轮依赖,导致记忆污染和低价值写入。MemReader 家族通过主动提取策略,提升了长期记忆的质量和一致性。

Key insight: 从被动记忆到主动记忆的转变是构建个性化搜索 agent 的关键。MemReader 的设计理念(在写入前主动验证和过滤)可直接应用于搜索系统中的用户意图建模和 session 历史管理,避免低质量信号污染用户画像。

10. Distributionally Robust Token Optimization in RLHF
3.55
Relevance 3 | Novelty 4 | Practical 3 | Evidence 4 | Timely 5

Summary: DRTO 结合 token 级 RLHF 与分布鲁棒优化(DRO),解决 LLM 在输入分布偏移时的推理能力下降问题。当 prompt 的措辞、格式或语言发生微小变化时,标准 RLHF 训练的模型会出现显著性能下降,尤其在多步推理问题上。DRTO 通过最坏情况分布优化提升了模型的鲁棒性。

Key insight: DRTO 关注的分布偏移问题在搜索系统中非常常见--用户 query 的表述方式千变万化,模型需要对 query 格式变化保持鲁棒。将 DRO 引入 RLHF 训练流程是提升搜索推荐模型在真实分布下稳定性的可行方案。
