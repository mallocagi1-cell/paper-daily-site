QCFuse: Query-Centric Cache Fusion for Efficient RAG Inference

针对 RAG 推理中 KV cache 复用效率低的问题，提出 QCFuse——一种查询中心的缓存融合方法。现有 cache fusion 方法仅从局部视角选择 token 进行重算，缺乏对用户 query 的全局感知。QCFuse 通过低成本获取上下文感知的 query 表征，在 token 选择阶段引入全局 query 信号，使重算 token 的选择更精准。实验表明，在多个 RAG 基准上，QCFuse 相比现有方法在相同缓存预算下准确率提升 2-5%，同时保持了接近的推理延迟。

Flash-KMeans: Fast and Memory-Efficient Exact K-Means

重新审视经典 k-means 算法在现代 AI 系统中的定位，将其从离线预处理工具提升为在线系统的一等原语。论文发现现有 GPU 实现的瓶颈在底层系统约束（内存带宽、warp 调度）而非算法复杂度。通过重新设计 GPU kernel 的内存访问模式和并行策略，Flash-KMeans 在 50M 量级 embedding 数据上实现了数量级的加速，同时保持精确结果（非近似）。

INSIGHT将 k-means 作为在线原语而非离线工具，对搜索推荐系统意义重大：embedding 聚类可实时驱动索引分片、召回路由和用户分群。Flash-KMeans 的系统级优化思路——从 GPU 内存访问模式入手而非改变算法——对所有涉及大规模 embedding 操作的基础设施都有借鉴价值。该方法可直接应用于在线向量索引的动态聚类更新，降低向量检索系统的索引重建延迟。

CSAttention: Centroid-Scoring Attention for Accelerating LLM Inference

针对长上下文 LLM 推理中 attention 和 KV cache 成为解码瓶颈的问题，提出 CSAttention——一种无需训练的稀疏注意力方法。核心思路是通过质心评分解决高稀疏度下 Query 和 Key 分布偏移导致的精度下降问题。CSAttention 将 Key 聚类为质心，用 Query 对质心的评分作为 token 重要性代理，实现更精准的 top-k token 选择。在 prefill 和 decode 阶段均可显著减少计算量和内存传输。

INSIGHT稀疏注意力在高稀疏度下失效的根本原因是 Q-K 分布偏移，而非稀疏本身。CSAttention 通过质心作为中间桥梁缓解了这一问题，且无需重新训练模型。对搜索系统中部署 LLM reranker 或 LLM-based 摘要生成而言，这是一个即插即用的推理加速方案。特别适合长文档理解场景（如 UGC 长帖搜索），可在保持输出质量的前提下显著降低 serving 成本。

FP8-RL: A Practical and Stable Low-Precision Stack for LLM Reinforcement Learning

LLM 强化学习的瓶颈在于 rollout（生成）阶段，长输出序列下 attention 和 KV cache 的内存开销主导了端到端步时。FP8 能通过降低计算和内存传输成本加速 RL，但在 RL 中使用 FP8 面临独特挑战：策略权重每步都变化，导致量化校准漂移。FP8-RL 提出了一套完整的工程和算法解决方案，集成到 vLLM 推理引擎中，在多个模型上实现了接近 2 倍的 RL 训练加速，且不损失最终策略质量。

INSIGHTFP8-RL 解决了一个被忽视但关键的问题：RL 训练中推理引擎的低精度适配。与静态推理不同，RL 场景下模型权重每步更新，传统 FP8 校准方案会失效。其与 vLLM 的深度集成表明，推理引擎需要为训练-推理一体化场景（如 RLHF）提供原生低精度支持。对正在用 RLHF 优化搜索/排序模型的团队，该方案可直接降低训练成本。

OASIS: Online Activation Subspace Learning for Memory-Efficient Training

LLM 训练中激活值内存占总内存的主要部分。现有方法通过低秩权重参数化或梯度子空间优化减少内存，但激活值压缩仍依赖架构修改或基于周期性更新投影的压缩方案。OASIS 提出一种在线激活子空间学习算法，在训练过程中持续跟踪和更新激活值的低秩投影基，无需预计算或定期刷新。该方法可作为 drop-in 模块集成到标准训练流程中，在多个 LLM 训练任务上减少 30-50% 的激活值内存，同时保持训练收敛性。

INSIGHT激活值内存优化的关键在于投影基的时效性——静态或周期性更新的投影基无法跟踪训练过程中激活值分布的快速变化。OASIS 的在线学习策略解决了这一问题。对于需要在有限 GPU 资源上微调大模型的搜索推荐团队，OASIS 可直接增大可训练的模型规模或 batch size。该方法与 gradient checkpointing 互补，可叠加使用进一步降低内存峰值。

Google Gemma 4 Family: Open-Source Models in Four Sizes with Apache 2.0 License

Google

Google 于 2026 年 4 月发布 Gemma 4 系列开源模型，包含四个规格：E2B、E4B（轻量）、26B MoE 和 31B Dense，全部采用 Apache 2.0 许可证。Gemma 4 支持复杂逻辑推理和 agentic 工作流，26B MoE 版本在推理效率上优于同等参数量的 dense 模型。该系列显著扩展了 Google 在开源模型领域的布局，提供了从边缘部署到服务端推理的完整尺寸覆盖。

INSIGHTGemma 4 的 MoE 变体（26B）为搜索推荐系统提供了一个高效的开源选项：稀疏激活使得实际推理成本远低于 dense 31B，同时保持相当的模型能力。Apache 2.0 许可证意味着可直接用于商业搜索系统。对于需要在成本和效果间取平衡的团队，26B MoE 是值得优先评估的 backbone。E2B/E4B 轻量版本也适合作为搜索系统中的辅助模型（如 query 理解、意图识别）。

Dynamic sparsity in tree-structured feed-forward layers at scale

在典型上下文长度下，前馈 MLP 块占 transformer 计算预算的主要份额。论文研究了树结构稀疏前馈层作为 dense MLP 的 drop-in 替代方案，通过硬层级路由实现条件计算，无需独立的 router 网络。首次证明该类树结构稀疏层可在深层 transformer 架构中稳定训练至大规模，在保持模型质量的前提下减少 40-60% 的 FFN 计算量。

INSIGHT树结构稀疏 FFN 的创新在于去掉了 MoE 中独立 router 网络的开销，通过层级二叉树实现隐式路由。这比 MoE 的 top-k 路由更简洁且更易于硬件优化。对搜索推荐系统中大规模 LLM 的 serving 场景，该方法提供了一条不同于 MoE 的稀疏推理路径。FFN 占推理计算的 60%+ 意味着该优化的收益空间非常可观，值得关注后续是否有成熟的开源实现。

ALTO: Adaptive LoRA Tuning and Orchestration for Heterogeneous LoRA Training Workloads

LoRA 已成为大模型参数高效微调的主流方法，但其性能对超参数（rank、learning rate、dropout 等）高度敏感，实践中需要大量并发调参任务。ALTO 针对多租户环境下异构 LoRA 训练工作负载的调度问题，提出自适应调参和编排框架。通过动态感知不同 LoRA 任务的资源需求和收敛状态，ALTO 实现了跨任务的 GPU 资源最优分配，相比独立调度减少 30-40% 的总训练时间。

INSIGHTLoRA 微调在搜索推荐团队中已广泛使用（如为不同垂类定制 ranking 模型），但调参开销被严重低估。ALTO 的调度思路表明，LoRA 训练的瓶颈已从算法转向系统：如何在共享 GPU 集群上高效运行大量异构 LoRA 任务。对于拥有多业务线、需频繁微调模型的搜索推荐团队，ALTO 的自适应资源分配策略可显著降低训练集群的总体成本。
