Bridging Passive and Active: Enhancing Conversation Starter Recommendation via Active Expression Modeling

针对会话起始词推荐依赖“曝光—点击”闭环、热门泛化查询不断自我强化的问题，PA-Bridge 将用户主动输入的开放查询引入双塔检索，以对抗式分布对齐消除主动 query 与候选 starter 的域偏移，并用 RQ-VAE 离散语义支持流行度去偏。基于 90 天、72 亿条工业样本，离线 AUC 相对提升 6.27%；线上 Starter 渗透率提升 0.54%，用户活跃天数提升 0.04%。

深度解读：PA-Bridge 用主动表达打破会话起始词推荐闭环

1. 问题与动机

论文研究的是会话式搜索开始之前的 Conversation Starter 推荐：系统从预先构建的候选库中为用户挑选若干查询建议，帮助用户发起对话。传统做法把它当成普通 Top-K 推荐，完全依赖候选被曝光后的点击训练。作者指出，这形成了“曝光—点击—再训练”的自循环：模型只能学到自己曾经展示过的内容，用户没看到的开放意图永远进不了监督信号。在其生产系统中，最热门的 1% Starter 占总曝光的 70%，说明闭环已明显把分布推向通用、平庸的头部查询。

会话搜索与电商商品推荐的差异在于，用户可以绕过候选菜单直接键入自由文本。主动 query 是用户显式探索开放世界的信号，比被动点击更接近真实意图，但直接加入训练会遇到两个具体障碍。第一，主动 query 往往口语化、未规范化且来自无限开放空间，而 Starter 是编辑良好的封闭候选，二者存在严重样本选择偏差。第二，自由文本近乎条条唯一，没有稳定 item ID；工业界常用的 LogQ 采样偏差校正需要统计每个 item 的流式频率，套到 query 上会退化为几乎一致的 1/N。论文要解决的不是“多加一种特征”，而是如何把开放文本监督安全地迁移到可低延迟召回的封闭候选库。

2. 方法详解

PA-Bridge 保留生产友好的双塔骨架。用户塔 ΦU 编码用户特征，查询塔 ΦQ 以预训练语言模型编码主动 query 或 Starter 文本，用户与 query 的分数是两向量内积。基础训练使用 batch 内负采样的交叉熵：对一个 batch 中每个用户的正 query，分子是其正样本内积经温度缩放后的指数，分母是该用户与 batch 内全部 query 的指数和。这一结构允许候选向量离线预计算，线上继续走 ANN，而不是让 LLM 进入请求路径。

第一个新增组件是 Distribution Aligner。查询塔先产生文本向量 z，随后用两层 MLP 形式的 Intent Mapper G 把主动 query 和被动 Starter 投影到共享意图空间；另一个两层 MLP 作为域判别器 D，预测表征来自主动域还是 Starter 域。训练采用经典极小极大目标：D 尽量分清两个域，G 则让二者不可分。这样保留下来的不是措辞风格，而是两类文本共同表达的潜在意图。论文的关键消融也证明，简单把主动 query 当正样本会让 AUC 从基础模型的 60.58% 降到 58.94%，说明不做对齐的数据扩充反而有害。

第二个组件是 Semantic Discretizer。作者用 RQ-VAE 将连续意图向量逐级量化成 3 个 code index，得到有限的 Semantic ID 序列 c={c1,c2,c3}。系统可在流式训练中统计每个 code 组合的频率 P(c)，以语义簇频率近似高维空间密度。损失在每个 logit 上减去 log P(c)，把 item-ID 版本的 LogQ correction 延伸到非 ID 文本。样本权重 β=1-D(G(z)) 来自域判别器，表示当前样本更接近 Starter 域的程度；离封闭候选分布过远的主动 query 不会被等权硬塞进训练。最终目标是去偏推荐损失与对抗损失的加权和，λ 控制域对齐强度。

实验数据来自平台连续 90 天生产日志，共 72 亿条样本。测试集严格只保留 Starter 候选，避免用主动 query 作为测试目标造成与线上不一致。所有基线共享同一用户塔和特征，比较 ID 检索、纯语义双塔、直接混入主动 query、移除对齐、移除重加权与完整模型。论文没有报告优化器、学习率、batch size、RQ-VAE codebook 大小、训练步数、硬件或总训练成本；这些复现所需信息不能从正文推断。

3. 核心技术贡献

第一项贡献是把“用户主动表达”定义成打破推荐闭环的外生监督，而不是继续在系统曝光集合内调采样。它把开放查询中的长尾兴趣引入 Starter 推荐，同时保持最终输出仍来自经过审核和预编码的封闭候选库。相比直接生成 query，这种做法保留了召回速度、内容控制和线上可回滚性。

第二项贡献是把域适配与采样去偏拆成两个互补问题。对抗式 Aligner 解决主动文本与候选文本的表面分布差异；RQ-VAE Semantic ID 解决自由文本无法统计 item 频率的问题。少任何一个组件都明显退化：去掉对齐仅得到 60.71% AUC，去掉重加权降到 58.00%，而完整模型为 64.65%。这说明“共享语义空间”本身不等于“可无偏学习”，两步都需要。

第三项贡献是提供生产闭环证据。作者不只报告 AUC，还观察曝光和点击的唯一 query 数量，直接验证系统是否走出头部回音室。独特曝光 query 增加 30.65%，独特点击 query 增加 56.50%，说明多样性扩张并非只制造无人点击的尾部内容。相较此前主要在对话中生成追问、澄清或引导话题的工作，PA-Bridge 聚焦对话开始前，并坚持检索式范式以满足延迟要求。

ID 模型低于语义双塔，符合 query ID 稀疏且容易记忆历史曝光的特点。直接混入主动 query 比基础模型低 2.71%，是论文最重要的反例：主动监督虽更丰富，但开放域和封闭域的条件分布不同，错误混训会把 query 塔拉离候选空间。去掉对齐只比基础模型高 0.21%，说明域适配承担主要迁移作用；去掉重加权甚至比直接混训更差，表明长尾主动 query 在 batch 内负采样中会产生严重频率偏差。

线上 A/B 结果显示，用户活跃天数提升 0.04%，Starter 功能渗透率提升 0.54%，独特曝光 query 数提升 30.65%，独特点击 query 数提升 56.50%。对成熟大规模产品，0.04% 留存类指标可能有业务意义，但论文没有给出实验持续时间、样本量、置信区间或显著性检验，不能独立复核稳定性。多样性指标的增幅远高于活跃指标，说明模型首先改变了候选分布，长期留存收益仍需更长窗口验证。

论文只以 AUC 作为离线主指标，没有给 Recall@K、NDCG、校准、分人群结果和长尾意图覆盖率。也没有展示 RQ-VAE 层数、codebook、λ、温度 τ 的敏感性，无法判断提升对量化容量或对抗训练稳定性的依赖。尽管如此，72 亿样本、严格限制为线上 Starter 候选的测试协议，以及完整线上部署，比只在公开小数据集验证更接近真实工程风险。

5. 局限与未来方向

论文没有单独的 Limitations 章节，也未在结论中列出明确未来工作。作者明确说明目前缺少同时包含主动 query 与 Starter 的公开数据集，因此全部实验依赖单一平台私有日志；这限制了外部复现和跨产品泛化判断。正文也未披露优化器、batch、硬件、训练时长、RQ-VAE 码本规模和线上实验统计口径，属于方法复现的实质缺口。

作者未讨论的明显边界包括：主动 query 可能包含隐私、敏感意图与安全风险，进入用户表征前需要权限、脱敏和保留期限治理；对抗域适配可能掩盖真正有用的域特征，训练也可能不稳定；语义量化会合并细粒度差异，codebook 过小造成意图碰撞，过大又让频率统计重新稀疏。β 由域判别器产生，若判别器校准不佳，样本权重会系统偏移。

线上只报告整体指标，尚未说明新用户、低活用户、语言、地区和敏感人群是否一致受益。模型仍从封闭 Starter 库输出，能否覆盖主动 query 揭示的新意图取决于候选库刷新机制；如果候选生成不跟进，对齐只能把开放意图投影到最近的旧候选。未来实践应把“发现新意图—审核生成候选—更新向量索引—监控分布”纳入完整闭环，而不是只优化双塔。

6. 工业实践意义

对搜索推荐团队，最值得复制的是信号分层。可把用户行为分为系统诱导的被动信号和用户自主产生的主动信号：点击、停留受曝光强烈影响，手输 query、改写、收藏和关注更接近显式意图。训练前先测两域分布差异，建立只含合法候选的时间切分测试集；若直接混训下降，应先做共享意图对齐，而不是继续调主动样本权重。

社区 UGC 搜索可以复用同一结构：用户塔编码近期搜索、浏览和互动，帖子主题词或查询建议走文本塔；主动 query 经过离线 LM 编码和 MLP 对齐，再用 RQ-VAE 生成语义 ID。Semantic ID 可同时服务频率校正、长尾采样、聚类分析和候选运营。线上仍用 ANN 从经过审核的 query 建议或内容候选中召回，不需要请求时调用大模型。建议先以 1% 影子流量测 AUC、Recall@K、NDCG、建议点击率、搜索后成功率、唯一意图覆盖与负反馈，再逐步扩大。

部署时要把三个风险单独监控：域判别准确率若长期接近 100%，说明对齐失败；若瞬间接近 50% 且推荐效果下降，可能是表示坍塌。Semantic ID 需监控 code 使用率、碰撞率、尾部 code 样本量和漂移；LogQ 校正需设最大幅度，避免极低频簇被过度抬升。主动 query 的隐私和内容安全应在进入训练前完成脱敏、过滤与最小化存储。

还应建立候选库补全流程：从高频但无合适 Starter 的语义簇中抽样，由人工或受控生成模型产出候选，经过安全审核后入库。这样 PA-Bridge 才真正把开放世界需求转成可服务的封闭候选，而不只是重排旧模板。论文的线上结果提示，覆盖和多样性会先显著变化，留存提升较小；业务评估应采用数周以上观察窗，防止把短期新鲜感当作长期个性化收益。

深度解读：ReST 的空间约束长尾物品表征增强

1. 问题与动机

ReST 面向本地生活推荐，候选通常先按用户当前位置过滤，例如只展示 5 公里内的餐饮或服务。空间约束让许多用户—物品组合在业务上根本不可能曝光，却仍可能被标准随机负采样当成负例；与此同时，连锁品牌凭借更广覆盖和更多交互持续强化 ID embedding，小商户则因曝光区域窄、交互稀疏而表征退化，形成更强的马太效应。

现有方法大多从用户侧加深序列、图或时空建模，但作者认为问题的根源在物品侧：受地理限制的长尾 item 没有足够协同信号，用户塔再复杂也不能凭空修复其 ID。通用长尾方法又常忽略本地服务的空间关系，把远距离、用户永远看不到的 item 纳入对比，稀释了有效梯度。ReST 因而采用 item-centric 路线，把属性语义、空间可达性和协同相似度共同写入 ID 表征增强，而且作为辅助模块挂到既有 DIN、TRISAN、BASM 等主干上。

2. 方法详解

整体由可替换的基础推荐塔和 SIDENet 组成。第一步是 Meta ID Warm-up Network。品牌、类目等稠密属性比稀疏 ID 更快收敛，模型先用 Squeeze-and-Excitation Network 对属性 embedding 自适应重标权，再通过带残差的 MLP 把属性语义注入原始 item ID。残差保留协同身份，避免多个属性相同的物品完全坍缩到同一表示。

第二步是空间约束 ID 增强。难样本构造分四层：先以共享品牌或类目形成先验正候选，以不同属性形成负候选；再按当前 embedding 相似度选择 Top-K 难负例；随后用 Haversine 公式计算经纬度距离，只保留业务空间内的关系；最终正对是空间阈值内且共享品牌或类目的物品，负对则是空间接近、embedding 高相似但属性不同的物品。与全局随机负样本相比，这些 pair 更接近“同一用户确实可能同时看到但偏好不同”的决策边界。

第三步是 Dynamic Representation Alignment。模型把品牌、类目属性经 MLP 投到语义空间，并用 K-means 得到若干语义中心。每个 item 根据 ID embedding 与最近中心的余弦相似度计算增强权重 α：越接近语义中心，说明 ID 已获得足够语义，注入权重越小；越偏离，说明表征较弱，需要更强属性补偿。增强表示是原 ID 与 α 乘属性 MLP 输出的残差和。这一机制避免所有物品接受固定强度的正则，尤其保护已经有充足协同信号的头部 item。

训练采用主推荐交叉熵与辅助 InfoNCE 对比损失的多任务目标。InfoNCE 的正负样本由上述空间难采样产生，动态权重的平方和 batch 平均项调节辅助损失强度。论文没有报告优化器、学习率、batch size、embedding 维度、训练 epoch、GPU 或端到端训练时长，因此无法给出这些未披露参数；正文可复现的是模块连接、采样逻辑、损失形式和关键阈值实验。

离线数据包括 Eleme 与 Kuaishou 两个真实工业集。Eleme 有 1,440,600 条样本、70,389 个用户、2,092,944 个物品，平均行为长度 41.008；Kuaishou 有 1,046,100 条样本、72,805 个用户、81,487 个物品，平均行为长度 8.895。评测覆盖 AUC、MRR、NDCG@5/10，并单独定义交互少于 3 次的冷启动 item。线上实验在快手本地生活短视频平台运行于 2025 年 3 月 14—26 日，覆盖数百万 DAU。

3. 核心技术贡献

第一，ReST 把本地生活长尾问题从“用户偏好建模不足”重述为“空间约束导致 item ID 表征退化”，因此能在不替换主推荐塔的情况下修复召回和排序共同依赖的底层 embedding。其 plug-and-play 结果显示，DIN+ReST 的 NDCG@5 相对提升 4.55%，TRISAN+ReST 提升 12.57%，高级 BASM 也保持正收益。

第二，空间约束不是新增一个经纬度特征，而是直接改变对比学习的样本定义。无距离约束时 AUC 只有 0.6811；正样本 30 公里、负样本 10 公里时 AUC 达 0.7436、NDCG@5 达 0.4345。机制上的解释是：正样本可在较大服务圈捕捉同类供给，难负例需要更近才代表真实竞争，太远会引入不可能曝光的噪声。

第三，动态语义对齐解决属性增强的副作用。头部 item 已有可靠协同 embedding，不应被品牌、类目强行拉向粗粒度中心；长尾 item 才需要更大 α。论文消融中去掉 warm-up 仅使 AUC 降 0.17%，而去掉品牌或类目约束分别降 1.49% 和 1.99%，说明核心价值不是简单属性初始化，而是属性参与的空间 pair 构造与动态对齐。

第四，论文给出真正的线上交易与体验指标。ReST 不只增加长尾曝光，在数百万 DAU 的 A/B 中 GMV 提升 2.804%、订单提升 1.285%，同时播放时长提升 4.188%、点击提升 1.226%。这表明表征增强同时改善消费和交易，而不是以牺牲头部体验换尾部覆盖。

4. 实验结果分析

主结果中，ReST 在快手全量数据上 AUC 0.7436、MRR 0.4266、NDCG@5 0.4345；BASM 分别为 0.7193、0.4168、0.4187。冷启动快手数据上 ReST AUC 0.6866，高于 BASM 的 0.6623。Eleme 全量 AUC 为 0.5830，超过 BASM 的 0.5752；但 MRR 和 NDCG@5 分别为 0.2194、0.1973，低于 BASM 的 0.2318、0.2115，说明方法更稳定地改善二分类区分能力，不保证每个排序指标都领先。

5. 局限与未来方向

论文没有独立 Limitations 章节，结论主要重申 ReST 在空间约束、冷启动和长尾场景的有效性，没有明确列出未来工作。作者披露的方法边界是本地生活固定半径候选与品牌、类目、经纬度可用的场景；因此它并非无需侧信息的通用长尾方案。Eleme 上 MRR/NDCG 未全面领先也说明 AUC 改善不能自动转化为所有 Top-K 指标收益。

正文缺少优化器、学习率、batch、embedding 维度、K-means 中心数最终取值、训练时间、显存和服务延迟。虽然称为 plug-and-play，但空间 Top-K 难样本、Haversine 过滤和周期性 K-means 会增加训练与数据管道成本，论文没有量化。线上测试发生在 2025 年 3 月、持续 13 天，尚不能判断季节、城市扩展和商户生命周期变化下的长期稳定性。

作者未讨论的其他局限包括：品牌和类目可能不完整或被商家操纵；固定公里阈值在高密城市与低密地区含义不同；物理距离不等于配送时间、交通可达性或行政边界。长尾分桶的极高相对增幅可能由低基数放大，需要同时报告绝对订单、商户覆盖和置信区间。动态 α 依赖语义聚类质量，目录漂移或新品批量进入时需重估中心。

6. 工业实践意义

工业落地可先从“不可能负样本审计”开始。对每个训练 pair 检查用户在当时是否真的可能看到该 item；本地生活用距离，社区 UGC 可用地域、语言、频道权限、关注圈层、发布时间或内容安全资格。若大量负样本业务上不可曝光，模型正在学习错误边界。第一版不必改主塔，只需在 batch sampler 中构建 region-homogeneous 或 constraint-aware mini-batch，并比较 AUC、NDCG、长尾覆盖和线上负反馈。

第二步再加入 Meta ID warm-up：选择稳定、难伪造的属性，如内容主题、作者领域、帖子类型，而不是直接把所有稀疏标签注入。保留 ID 残差，让协同信号决定个体差异。对比样本应遵循“正样本共享核心属性且在可达范围内，负样本可达、语义相近但属性不同”，这样才是真正难例。距离阈值需按城市密度或业务圈层分桶调参，不能照搬 30/10 公里。

动态对齐适合防止属性过正则。可用聚类中心或教师 embedding 衡量 ID 的语义完备度，只增强偏离较大的长尾 item；头部 item 权重下调。K-means 与难样本池应离线或准实时刷新，在线服务只读取增强后的 embedding，因此请求路径不必增加复杂模型。上线前需测 embedding 刷新耗时、索引一致性和 P99 延迟，论文未提供这些数字。

A/B 设计应同时观察交易、消费和生态：CTR、播放时长、订单、GMV之外，增加新商户覆盖、长尾曝光后转化、用户投诉、头部商户损失和城市分层结果。先在一个供给密度适中的地区做 1%—5% 流量实验，至少跨两周，并保留原 ID 表征的快速回滚开关。ReST 的最佳价值不是制造尾部曝光，而是用业务可达性定义更真实的对比关系，让长尾 item 获得可转化的表示质量。

CASE: Cadence-Aware Set Encoding for Large-Scale Next Basket Repurchase Recommendation

Walmart📖 有深读 · 7 分钟

CASE 指出按购物篮序号建模会丢失真实日历间隔，因而把每件商品的购买历史编码为固定时间窗信号，用多尺度时间卷积学习周、双周、月度等复购节律，再以诱导集合注意力建模商品间关系，将复杂度从 O(n²) 降到 O(nK)。在千万级用户生产评估中，Top-5 Precision、Recall 和 NDCG 相对现网分别提升 8.63%、9.90% 和 10.46%。

INSIGHT行为发生的真实间隔本身就是强个性化特征，不能被“第几次交互”的序号替代。社区产品可将这一思路迁移到周期性访问、内容复看或主题回访：先以共享多尺度卷积提取时间节律，再用集合编码器处理候选间依赖；共享滤波器且不引入 per-user 参数，使推理成本与候选数线性增长，适合大用户规模的批量刷新。

Yanan Cao, Ashish Ranjan, Sinduja Subramaniam, Evren Korpeoglu, Kaushiki Nag, Kannan Achan

1. 问题与动机

复购行为是零售推荐中的核心信号——大量用户的下一个购物篮中包含此前购买过的商品，且复购时间遵循稳定的商品特定节奏（如牛奶每周、洗衣液每月）。然而，现有 Next Basket Repurchase Recommendation（NBRR）模型将购买历史表示为按访问顺序索引的离散篮子序列，存在根本性缺陷：(1) 在第 1、8、36 天购买的商品与第 1、2、3 天购买的商品获得相同表示；(2) 两次购买间隔期内推荐无法动态更新；(3) 无法区分已逾期和尚未到期的商品。

现有方法的具体不足：KNN 方法（如 TIFUKNN）需要在推理时计算用户间相似度，在千万级用户规模下计算开销不可接受（O(|U|·d) per query）；先前的日历时间方法依赖用户级别的卷积滤波器和二次复杂度的物品交互模块，限制了生产环境的可扩展性。

2. 方法详解

日历时间历史表示：对每个商品 i，构建 T 天滚动窗口内的二值购买指示向量 h_i ∈ {0,1}^T，h_{i,t}=1 表示第 t 天购买了商品 i。这保留了精确的购买间隔信息。

多尺度时间 CNN：使用共享 Conv1d 滤波器在五个预设核尺寸上处理 h_i——7 天（周频）、14 天（双周频）、28 天（月频）、91 天（季度频）、182 天（半年/趋势）。每个尺度使用非重叠步长 stride=w，⌊T/w⌋ 个激活值在所有尺度上拼接后经两层 FC+ReLU 投影为 cadence embedding c_i ∈ R^{d_c}，d_c=128。

Induced Set Attention (ISAB)：将 cadence embedding 和物品 embedding e_i ∈ R^{d_e}（d_e=128）拼接为组合表示 x_i = [c_i || e_i]，输入 Set Transformer 编码器。使用两层 ISAB，K=32 个 induced points，H=4 注意力头。ISAB 将 O(n²) 的成对注意力降至 O(nK)，n 为用户候选商品数。

评分与训练：每个表示 z_i ∈ R^{d_h}（d_h=256）经两层 MLP 产生标量分数 s_i，按 s_i 排序推荐。训练使用 BCE 损失，下一个篮子中的复购商品为正样本。训练 30 个 epoch，Adam 优化器（lr=10^{-3}，weight decay=10^{-5}），batch size=64，ISAB 和 MLP 后 dropout=0.1。

关键设计选择：(1) 时间卷积滤波器跨所有用户共享（非用户级），大幅减少参数量；(2) 使用 induced points 而非完整 self-attention，使复杂度与候选集大小线性相关而非二次；(3) 解耦 cadence 学习与跨商品交互——CNN 独立捕捉每个商品的时间节奏，ISAB 处理商品间的互补/替代关系。

3. 核心技术贡献

贡献一：日历时间 vs 序列索引的问题重构。论文明确指出 basket-index 公式化是阻碍生产部署的结构性限制，提倡以日历时间节奏作为更优的建模基础。这一重构使模型能在两次购买之间动态刷新推荐。

贡献二：可扩展的 cadence 学习架构。通过共享多尺度 CNN + induced set attention 的组合，实现了显式日历时间建模与生产级可扩展性的兼得。推理复杂度 O(n(T+K))，与用户总数无关。

贡献三：嵌入依赖降低。消融实验表明移除物品 embedding 仅导致 1.75% 的 Precision 下降，说明 cadence 信号本身已携带大量信息，减少了对频繁刷新的大规模 embedding 表的依赖。

贡献四：首个 NBRR 的生产级评估。在千万级用户规模上的评估表明 CASE 在工业环境中可行，而非仅限于学术基准。

5. 局限与未来方向

作者指出以下局限：(1) 依赖历史日历时间戳，缺失时间戳时需重建相对日期，可能引入噪声；(2) 在数据密集的场景（如 Instacart）上增益相对较小，暗示当历史信息足够丰富时 cadence 的边际收益递减；(3) 尚未进行在线 A/B 测试——论文明确提到「online A/B test is planned to validate offline gains on user-facing metrics」。

此外，模型仅处理复购推荐场景，对全新商品（无历史购买）的推荐需要与其他冷启动方法结合。

6. 工业实践意义

直接可借鉴的设计：多尺度时间卷积的思路不限于购物篮推荐——任何有周期性行为模式的场景（社区平台的周期性浏览、视频平台的观看节奏、音乐平台的收听习惯）都可套用。核心思想是「用真实时间间隔而非事件序号建模行为节奏」。

生产部署友好：推理复杂度 O(n(T+K)) 与用户总数无关，这对千万级 DAU 平台至关重要。共享权重设计避免了用户级参数爆炸。

减少 embedding 依赖：消融显示 cadence 信号本身携带大量信息，这启示团队在 embedding 基础设施受限时可以优先投入时间建模。

Walmart 的工业验证：在千万级用户上 +8.6% Precision / +9.9% Recall 的提升具有显著业务价值，表明 cadence-aware 设计在真实工业环境中可行且高效。但需注意该评估为离线指标，在线效果有待 A/B 验证。
