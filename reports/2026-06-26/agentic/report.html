Constraint Tax in Open-Weight LLMs: An Empirical Study of Tool Calling Suppression Under Structured Output Constraints

论文报告了生产级 Agent 系统中一个可复现的现象：当同时开启 Tool Calling 与 JSON Schema 结构化输出约束时，多个开源权重模型会停止调用工具（却仍保持高 schema 合规），作者称之为 Tool Suppression（工具抑制）。通过跨多个模型家族与部署设置的受控实验稳定复现后，作者定位根因——JSON Schema 约束被编译为基于语法的 token mask，使工具调用所需的 token 在解码时变得不可达，从实现层面解释了该行为。单独评估时工具执行与 schema 合规均正常，只有联合约束下才触发抑制。

KEY INSIGHT · 对业务意味着什么对构建『边推理边调工具』的搜索 Agent 极具警示意义：当你用 constrained decoding 强制 JSON 输出、又依赖函数调用触发检索/排序工具时，两者叠加可能让 Agent 静默地不再调工具，而表面输出却完全合规、极难察觉。实践上应分阶段解耦（先自由生成工具调用、再单独约束最终结构化输出），或检查 grammar mask 是否屏蔽了 tool-call 起始 token，避免把『工具不可达』误判为『模型不想调』。

Memory Makes the Difference: Evaluating How Different Memory Roles Shape Conversational Agents

MicrosoftDartmouth

已有 RAG 对话系统研究多关注记忆『如何存取』，本文转而研究不同功能角色的记忆如何影响回复质量。作者提出对话记忆的细粒度分类法，把检索到的记忆按角色类型归类，并设计模拟用户视角的 user-centric 评估框架（区别于传统 reference-based 评估）。在长程对话数据集与前沿 LLM 上的对比实验表明，不同角色的记忆会实质性地改变 Agent 的回复行为。作者来自 Microsoft 与 Dartmouth。

INSIGHT对做社区对话式搜索/问答的团队提示：检索回来的『记忆/历史』并非同质，按功能角色（用户偏好、事实约束、上下文线索等）区分并差异化使用，比单纯堆叠召回更能影响回复质量。其 user-centric（模拟用户偏好）的评估思路也值得借鉴——reference-based 指标往往捕捉不到回复对用户个性化需求的满足程度。

Autodata: An agentic data scientist to create high quality synthetic data

Meta

Autodata 让 AI Agent 充当『数据科学家』，自动构建高质量的训练与评估数据，并可对该 Agent 进行 meta-optimize（元优化）使其学会生成更强的数据；论文给出具体实现 Agentic Self-Instruct。在计算机科学研究、法律推理、数学对象推理三类任务上，相比经典合成数据方法取得更好结果，且元优化数据科学家 Agent 本身带来更大幅度提升。核心主张是把增加的推理算力转化为更高质量的模型训练数据。作者来自 Meta。

INSIGHT把『增加推理算力』转化为『更高质量训练数据』的范式，对搜索/推荐里长期缺标注数据的环节（相关性标注、query-doc 对、难负样本挖掘）很有启发：与其人工标注，不如训练一个会自我改进的数据生成 Agent。可借鉴 Agentic Self-Instruct 的闭环——生成数据→训练/评估→反馈优化生成策略，尤其适合冷启动域或长尾 query 的数据扩充。

Ilia Kulikov, Chenxi Whitehouse, Tianhao Wu, Yixin Nie, Swarnadeep Saha

Efficient and Trainable Language Model Test-Time Scaling via Local Branch Routing

针对 test-time scaling 的两难（长 CoT 采样是单线程、句/解级搜索昂贵且难端到端训练），提出 token 级框架 Local Branch Routing（LBR）：展开一棵小的局部前瞻树，把所有采样分支前向通过模型，再用轻量 router 基于候选局部未来的 hidden states 选择要 commit 的 depth-1 子树。其 prune-shift-grow 解码过程保留离散分支身份，并定义了可处理的树轨迹似然，使整个机制可端到端训练，让每个 token 决策都能利用超出 root next-token 分布的证据，同时避免完整 solution-level 搜索的开销。

INSIGHT为需要多步推理的搜索 Agent 提供了一条『廉价且可训练』的 test-time scaling 路径——在 token 级做局部前瞻+路由，避免完整 solution-level 搜索的算力开销。轻量 router 基于 hidden states 决策的设计，可类比到 query 改写/检索决策中『是否继续推理/检索』的门控，对延迟敏感的在线搜索尤其有参考价值。

Yutong Yin, Mingyu Jin, Jin Pan, Changyi Yang, Zijie Xia, Dhruv Pai, et al.

The Hitchhiker's Guide to Agentic AI: From Foundations to Systems

一本面向工程实践者的 Agentic AI 全栈参考资料，核心论点是『做好 Agent 系统需要理解管线的每一层而非只优化一层』。内容从 LLM 底座（Transformer、GPU 系统、SFT/LoRA/MoE、模型压缩与推理优化）讲起，到对齐与推理层（RLHF、PPO、DPO 及变体、GRPO、reward modeling、面向大推理模型的 RL 与 test-time scaling、CoT），下半部分专注 Agentic AI 本体（agentic 训练、基于轨迹的 RL、RAG 与 Agentic RAG 等），直到生产部署。单作者 Haggai Roitman。

INSIGHT适合作为团队搭建 agentic 搜索/RAG 系统的体系化入门与对照手册——它把『底座→对齐/推理→Agent』三层串起来，强调不能只优化单层。对从业者的价值在于查漏补缺（如 GRPO、trajectory-based RL、Agentic RAG 的取舍）而非具体 SOTA 方法；作为综述/参考类资料，实证性弱，需结合实证论文落地。

AgentOdyssey: Open-Ended Long-Horizon Text Game Generation for Test-Time Continual Learning Agents

Johns Hopkins

为评估『测试时持续学习』Agent 的关键能力（探索、获取新世界知识与技能、保留情景记忆、长程规划），提出 AgentOdyssey 评估框架：程序化生成富含实体、世界动态与长程任务的开放式文本游戏，并打破『测试时不再学习』的常规假设，把 Agent 置于学习与推理交织的长程部署环境。配套多维评估方法，不仅看游戏进度，还诊断世界知识获取、情景记忆、对象/动作探索、动作多样性与模型成本。作者含 Johns Hopkins 团队。

INSIGHT对评估 agentic 搜索/助手系统有方法论借鉴：真实部署中 Agent 需在交互中持续学习，单轮静态 benchmark 无法刻画其长程能力。其『程序化生成 + 多维诊断（记忆/探索/成本）』的评测设计，可迁移到评估搜索 Agent 在长会话中的记忆保持与多步检索规划能力；但本身是评测框架，离直接落地搜索业务尚远。

Zheyuan Zhang, Zehao Wen, Alvin Zhang, Andrew Wang, Jianwen Xie, Daniel Khashabi, Tianmin Shu
