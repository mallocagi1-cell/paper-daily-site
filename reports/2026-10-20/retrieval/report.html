EKLAV: Elicited Key CoT Learning via Answer only superVision

让学生模型读懂教师的推理，却不要求它逐字复述。训练把教师推理放进输入，只监督最后答案，减少生成推理文本的训练负担。在 BRIGHT 重排的 48 组模型与领域比较中，作者报告赢下 41 组。

Jev-as-a-Judge for Brazilian Portuguese Information Retrieval: Relevance Assessment and Reranking

用快速判别模型给葡语搜索结果标相关性，再用同一模型重排。作者在四套检索集合上比较模型与人工标签，也检查不同检索系统的相对名次。在 Quati 上，重排后的 nDCG@10 从 0.3329 提高到 0.6331。

INSIGHT单条标签不完全一致，系统之间的优劣次序仍可能很稳定。制作搜索评测集时，可以同时检查逐条标注一致性与模型排序一致性；这比只看标签准确率更接近选型目的。

Steering beyond Language: Improving Multilingual Training-Free Text Embeddings via Paired-Residual Subspace Removal

不同语言的相同意思，可能在向量空间里相隔很远。作者利用平行句找出语言差异方向，再从冻结模型的表示中去掉这些分量，无须重新训练模型。单语言评测覆盖 18 种语言。

INSIGHT向量中的语言特征可能干扰语义匹配。平行句的表示差能帮助定位这种干扰，让多语言召回的改进落到一个可独立替换的表示处理步骤上。

Ailiang Lin, Zhuoyun Li, Yusong Wang, Keyu Mao, Kotaro Funakoshi, Manabu Okumura

Evidence-Gated Bilingual RAG for Reliable Consumer Banking Search

用户用口语找银行产品，网页却使用正式术语，双语表达又增加了匹配困难。系统组合词面召回、向量召回与重排，并按证据决定回答或拒答。在 210 条标注查询上，首位命中率从 50.48% 升至 79.05%。

INSIGHT找到了相关页面，不等于证据足够回答。把相关但不匹配的结果单独标出来，可以区分召回错误与回答越界；文中的查询集较小，且答案判断依赖自动评审。

Code Skill Server: A Large-Scale Search Engine for Code Generation Skills

代码助手需要为当前任务找到合适的技能，手工整理越来越困难。作者把公开技能持续收集、建立索引，再比较检索策略对代码生成的影响。最优配置的首次生成通过率最多提高 13.91%。

INSIGHT检索对象可以是可执行的技能说明，效果要看下游任务能否完成。它给工具和技能搜索提供了端到端评测思路，而不仅是检查返回条目与查询是否相似。

ReaLiC: Reward-aligned latent reasoning for conversational query rewriting

多轮对话中的省略和指代会让查询改写偏离原意。作者把指代消解、主题跟踪等推理策略显式写出，再用检索效果与上下文一致性的共同奖励训练。实验覆盖两套对话检索基准；公开预览未提供可核查的提升幅度。

INSIGHT改写奖励需要同时约束检索效果和原意保留。把推理策略显式化，能帮助定位改写为何改变主题；当前可访问证据只支持机制介绍，数值结果未补写。

Liang Xu, Guanyu Qin, Zibo Yi, Yunbo Cao, Zhunchen Luo, Lei Shi, Feifei Kou

SAG2: Embedding-Free Multi-Hop Retrieval with BM25 and JEV

多跳问题不一定需要提前把所有文档转成向量。系统先用关键词检索，再从已找到的段落提取线索继续搜索，并由判别模型选择证据。MuSiQue 子集上的 Recall@10 达到 86.62%。

INSIGHT可以把语义判断推迟到查询时，换取更轻的索引构建。原文用单个数据库保留词面索引，代价则转移到查询阶段的模型判断与多轮检索。

Gap Detection: Mitigating Homogenization through Demand and Defensibility

开放问题的答案容易重复，作者让模型寻找既相关又尚未被覆盖的方向。系统在文本向量空间中同时优化查询匹配与内容差异，再把方向转为生成提示。在五个人工主题上，内容碰撞的平均相对降幅为 12.8%。

INSIGHT相关性与新颖性可以分别度量，再组合成候选方向的评分。向量距离只是寻找空白的手段，最终生成内容仍要接受任务规则检查，避免只追求差异。

Xucheng Yu, Haibo Jin, Xiaoqi Wang, Runze Kong, Haohan Wang

Inside Prometheus: Meta’s Journey to a Gigawatt-Scale Supercluster

Meta

大规模模型训练需要同时解决算力供给、供电和散热。Meta 介绍训练集群建设及液冷等基础设施，目标是让设备扩容与机房能力一起增长。文章描述了约百万张 GPU 的扩展目标，而非已经验证的检索收益。

INSIGHT设备规模需要与供电和散热一起规划。这篇文章补充工业工程视角，与社区搜索排序的直接关系较弱；集群建设目标也不等于已上线的实际规模。
