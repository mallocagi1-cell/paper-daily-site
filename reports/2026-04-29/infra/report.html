1. Self Knowledge Re-expression: A Fully Local Method for Adapting LLMs to Tasks Using Intrinsic Knowledge
4.00
Relevance 4 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: 针对 LLM 在 NTP（next-token prediction）范式下处理非生成式专精任务效率低的瓶颈，论文提出 Self-Knowledge Re-expression (SKR) ——一种完全本地、任务无关的适配框架。SKR 不依赖人工标注与模型蒸馏，仅用未标注数据将 LLM 输出从通用 token 生成转换为任务特定的高效表达。在大型金融文档数据集上，SKR 把信息检索 Recall@1 提升超过 40%，对象检测延迟下降超过 76%，异常检测 AUPRC 提升 33% 以上，并在 MMDocRAG 上验证了多模态 RAG 场景的有效性。

Key insight: SKR 的核心洞察是：限制 LLM 在专精任务上的并非知识储备，而是知识表达机制——只要把序列式 token 生成改造为任务特定的稠密输出，就能用同一份模型权重撬动检索、检测、异常识别等不同任务。对搜索/推荐工程而言，这意味着不必为每个下游任务单独 SFT 或蒸馏一个小模型，可以基于现有 LLM backbone 用未标注语料就近构建任务头，显著降低部署多任务 LLM 的复杂度，并且大幅压缩在线推理延迟，对 UGC 搜索等 query 多变、任务多样的场景尤为友好。

2. How Much Is One Recurrence Worth? Iso-Depth Scaling Laws for Looped Language Models
3.90
Relevance 3 | Novelty 5 | Practical 3 | Evidence 5 | Timely 5

Summary: 论文系统研究了循环 (looped / depth-recurrent) 语言模型的 scaling 行为。基于 116 次预训练 (recurrence count r ∈ {1,2,4,8}、跨 ~50× 训练算力)，作者拟合了联合 scaling law L = E + A·(N_once + r^φ N_rec)^{-α} + B·D^{-β}，得到全新的 recurrence-equivalence 指数 φ = 0.46。结论是：当 r=4 时，410M 循环模型与 580M 非循环模型表现相当，但训练成本却接近 1B 非循环模型；用 truncated BP 训练时 φ 进一步降至 0.38。

Key insight: 这是首次将循环语言模型的“块复用收益”量化为一条可外推的 scaling law。φ=0.46 介于完全等价（1）与完全无效（0）之间，给了工程团队一条清晰的 ROI 公式：循环能省参数但不省训练算力。对于推理侧的搜索/推荐系统，循环架构常被作为参数压缩手段（小模型反复调用），论文提醒我们：要在“参数预算 vs 训练预算 vs 推理 latency”三角中真正算清楚帐，并且 truncated BP 这种省内存技巧会进一步稀释循环的收益。

3. Identity-Decoupled Anonymization for Visual Evidence in Multi-modal Retrieval-Augmented Generation
3.75
Relevance 4 | Novelty 4 | Practical 3 | Evidence 3 | Timely 5

Summary: 针对多模态 RAG (MRAG) 系统在检索图像证据时频繁暴露真人面部隐私的问题，论文提出 Identity-Decoupled MRAG。该框架在 retrieval 与 generation 之间插入一个生成式匿名模块，包括三部分：(i) disentangled VAE 把人脸分解为身份编码和空间属性编码，并以互信息正则与梯度独立项约束；(ii) 流形感知拒绝采样器，用合成身份替换原始身份；(iii) 经过证明的隐私 → 实用 trade-off 评估方法。

Key insight: MRAG 在企业落地时最大的合规阻力是图像证据携带的人脸/身份信息。该论文给出一个可即插即用的“身份脱敏中间件”思路：不重新训练 retriever / generator，只在两者之间套一个生成式的“身份-属性解耦”模块，既保住下游推理需要的姿态、表情、场景信息，又给隐私一个可证明的上界。对要把 UGC 图像/视频纳入检索证据池的搜索系统而言，这是一种比传统模糊/打码更友好的工程范式，可显著降低法务对开放图像 RAG 的阻力。

4. Tuna-2: Pixel Embeddings Beat Vision Encoders for Multimodal Understanding and Generation
3.55
Relevance 3 | Novelty 4 | Practical 3 | Evidence 4 | Timely 5

Summary: Tuna-2 是一种原生统一多模态模型，直接基于像素级 patch embedding 同时完成视觉理解与生成，彻底抛弃 VAE 或独立视觉编码器（CLIP/ViT 等模块化设计）。论文展示在多模态基准上达到 SOTA，证明纯像素空间建模可以与 latent-space 方法媲美。同时观察到：基于编码器的变体早期收敛更快，但 Tuna-2 的无编码器设计在 scale 上去后多模态理解更强，且训练栈更简洁。

Key insight: Tuna-2 给业界一个反直觉信号——“先训一个视觉编码器，再接 LLM” 的两阶段范式正在被端到端的 patch embedding 替代。对搜索/推荐内容理解而言：一是模型链路更短、训练/推理依赖更少，便于把多模态向量直接复用到检索 backbone；二是 patch embedding 与文本 token 同处一个 embedding 空间，可消除目前“图像塔 + 文本塔”常见的语义错位问题，对图文混合 UGC 检索的双塔/单塔重构是个重要参考。

5. Credal Concept Bottleneck Models for Epistemic-Aleatoric Uncertainty Decomposition
3.55
Relevance 3 | Novelty 4 | Practical 3 | Evidence 4 | Timely 5

Summary: 概念瓶颈模型 (CBM) 通常输出点估计的概念概率，将认知不确定性 (epistemic) 与数据本身不确定性 (aleatoric) 混在一起，难以解释也难以付诸行动。论文提出 CREDENCE：用 credal 预测 (概率区间) 表示每个概念，从多个概念头之间的分歧度估算 epistemic 不确定性，再用专门的 ambiguity output 拟合标注者分歧来估算 aleatoric 不确定性。两种不确定性可分别驱动“自动决策 / 数据补采 / 人工复核 / 拒答”等差异化策略。

Key insight: 把不确定性分解为“可减少 vs 不可减少”，等于给排序/分类模型加了一份带语义的“弃权按钮”。对搜索/推荐工程而言：可以用 epistemic 信号驱动主动学习采样（高 epistemic = 缺训练样本），用 aleatoric 信号驱动放量阈值（高 aleatoric = 自然多义，需要展示更多元结果），用两者同时高的样本触发兜底策略（人工审核或保守 fallback）。比传统单值置信度更精细，是 LLM 时代“对齐 + 可控”工程化落地的实用工具。

6. IIRSim Studio: A Dashboard for User Simulation
3.45
Relevance 3 | Novelty 3 | Practical 4 | Evidence 3 | Timely 5

Summary: 现有信息检索用户仿真框架以代码库形式存在，搭建成本高、复用性差。IIRSim Studio 提供一个 Web 工作台，覆盖四项贡献：(1) 可视化拼装仿真 pipeline 的环境，兼顾教学和大规模实验；(2) 基于 Git 的组件生命周期管理，支持自定义组件的版本化、共享与运行时注入；(3) 端到端实验设计–执行–分享统一工作流；(4) 在已有仿真引擎上做 orchestration，而不是再造引擎。

Key insight: 搜索系统的离线评估长期受“用户仿真器组装难度大”制约。该框架把 IR 仿真升级为类似 ML 平台的可视化、可版本化的工作流，意味着可以把“query 改写实验、新排序模型 A/B 对照、reward model 离线打分”这类工作做成可复用的组件库。对于业务团队，这是一种把 IR 离线评估从“一次性脚本”变成“工程化资产”的范式，对建立长期可信、可比较的评估护城河非常有借鉴价值。

7. ReVSI: Rebuilding Visual Spatial Intelligence Evaluation for Accurate Assessment of VLM 3D Reasoning
3.00
Relevance 2 | Novelty 3 | Practical 3 | Evidence 4 | Timely 5

Summary: ReVSI 指出当前视觉-语言模型的空间智能评测有两类系统性失效：一是基于点云 3D 标注转写出的视频 QA 在重建/标注误差下错答率高；二是评测假设“全场景可见”，但 VLM 实际只能看到 16–64 个稀疏帧。ReVSI 重新标注了 381 个场景、5 类数据，构建了一个保证“在模型实际输入下可答且唯一正确”的基准与评测协议。

Key insight: 对所有依赖 VLM 做内容理解的系统（如视频/图像搜索的属性抽取、空间关系判定），评测有效性常常被低估。ReVSI 给出的方法论——把“模型实际看到的输入”作为评测设计的硬约束，并审计原始 3D 标注是否仍成立——非常值得借鉴：在内部做 VLM 评测时，应同时审视采样策略（关键帧/稀疏帧）和 GT 标注的视频可见性，否则模型上线后会被“看不见但要回答”的样本拖低线上效果。

8. World-R1: Reinforcing 3D Constraints for Text-to-Video Generation
3.00
Relevance 2 | Novelty 4 | Practical 2 | Evidence 4 | Timely 5

Summary: 面对视频生成模型几何不一致的痛点，World-R1 不修改 backbone 架构，而是通过 RL 把 3D 约束注入视频生成。框架使用 Flow-GRPO 在专门构造的“世界仿真”纯文本数据集上做对齐训练，借助预训练的 3D 基座模型与 VLM 输出反馈作为奖励，并用周期解耦策略平衡刚性几何一致性与动态场景流畅度。实验显示能显著提升 3D 一致性，同时保持原视觉质量。

Key insight: World-R1 的工程启示是：把“架构改造”问题转换成“奖励设计 + RL 微调”问题。同样的范式可推广到 LLM 检索/推荐场景——例如，把昂贵的“事实一致性”、“多样性”、“相关性”约束做成 reward model，用 GRPO/Flow-GRPO 类方法在不动主模型架构的前提下注入软约束。Flow-GRPO 给出了一个低门槛的 RL 注入路径，对 RL-for-LLM 工程化是个具体可参考的样本。
