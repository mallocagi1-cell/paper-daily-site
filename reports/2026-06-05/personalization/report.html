Bridging Short Videos and Live Streams: Reasoning-Guided Multimodal LLMs for Cross-Domain Representation Learning

针对直播推荐行为稀疏、冷启严重的问题，快手提出 RGCD-Rep，把短视频域的用户兴趣迁移到直播域。方法分两阶段：先用冻结的多模态大模型（MLLM）作 teacher 生成结构化的跨域推理知识，蒸馏进一个轻量 student；再把 item 表征拆成「可迁移表征」与「域残差表征」，全部离线预计算后接入下游推荐，serving 端不需实时跑 MLLM。已在快手直播推荐系统部署、服务日活 4 亿+ 用户，A/B 实验在多个核心业务指标上取得显著正向。

Le Zhang, Xiaolan Zhu, Yuchen Wang, Shilong Kang, ..., Lantao Hu, Kun Gai · 2026-06-04 · arXiv

RGCD-Rep 深度解读：用 MLLM 推理把短视频兴趣迁移到直播冷启

1. 问题与动机

快手要解决的是直播推荐的稀疏与冷启问题。论文给出明确量化对比：短视频域人均 224.93 次交互，直播域人均仅 20.78 次；数据量上短视频 2463.5 万次交互（10.95 万用户、378.7 万 item），直播只有 227.6 万次（9.19 万 item），约为短视频的 9.2%。更棘手的是高价值行为（关注 follow、虚拟礼物 gifting）极度稀疏，测试集里 14.65% 的用户完全没有直播历史，尾部 item 占 50% 的 item 却只贡献 10.90% 的交互。已有多模态跨域方法依赖静态特征、缺乏对多模态内容的深层语义推理，无法解释"为什么两个域的 item 在行为上可迁移"，导致迁移信号不可靠、易引入负迁移。RGCD-Rep 的出发点是：把"可迁移性"这件事显式地交给大 MLLM 去推理判断，而不是让模型隐式地从稀疏行为里猜。

2. 方法详解

RGCD-Rep 分两阶段。阶段一 推理感知蒸馏（Reasoning-Aware Distillation）：用一个冻结的 35B Qwen3.6 MLLM 作 teacher，对从同一时间窗用户日志构造的"行为-协同对"(sᵢ, lᵢ) 生成结构化推理。迁移强度 bᵢ 由行为共现频率与行为强度（视频侧看时长/完播率/点赞/评论/分享，直播侧看时长/送礼/关注/点赞）算出。teacher 把每个 item 沿三个语义维度 K={垂类 vertical, 关键主体 key subject, 内容话题 content topic} 拆解，每个维度输出语义标签+证据描述+对级匹配 mᵢᵏ∈{0,1}，并得语义迁移分 rᵢ=(1/|K|)Σmᵢᵏ。这些对级推理再拆成 item 级样本（让任意单个视频/直播都能被独立编码），蒸馏进一个轻量 2B Qwen2-VL student：student 用 16 个可学习的 chorus tokens 聚合多模态语义，输出隐状态 Hₓ∈ℝ^(16×d)，训练目标是标准 NTP（next-token prediction）让 student 复现 teacher 的结构化推理文本。这一步的关键是把 35B 的推理能力压到 2B，既保住推理质量又能上线。

阶段二 迁移性引导的跨域表征学习：双域共享同一 student MLLM 编码器映射到统一语义空间。用两个可学习 query 向量从 chorus tokens 抽取双视图——可迁移视图 z^T 与域残差视图 z^R，均为 α=softmax(Hₓq/√d) 加权聚合后做 Norm。跨域对比损失 L_con=½(L_{s→l}+L_{l→s})，把行为-协同对作正样本、batch 内未匹配 item 作负样本，余弦相似度、温度 τ=0.05。为防负迁移，引入迁移路由：按 qᵢ=bᵢ+rᵢ（行为+语义迁移性）排序，Top 20% 设为高纯度对 π=1、Bottom 20% 低纯度 π=0，中间丢弃；路由概率 P_T=σ(γ(s_T−s_R))（γ=10，s_T/s_R 分别是对在可迁移/残差空间的相似度），路由损失 L_route=−mean[π·logP_T+(1−π)·log(1−P_T)] 把高纯度对推向可迁移空间、低纯度对推向残差空间。总目标 L_stage2=L_con+0.05·L_route。最终可迁移表征 z^T（1536 维）对全量 item 离线预计算并建近邻索引，serving 阶段只查索引、零 MLLM 推理。训练用 8 张 H800，LoRA rank=32，阶段一 batch 8 / lr 1e-4 / 6 万样本，阶段二 batch 64 / lr 1e-4 / 25 万样本。

3. 核心技术贡献

(1) 首个把大 MLLM 推理引入跨域推荐（CDR）的工作，且推理带显式迁移性判断，而非泛化的内容描述。(2) 推理感知蒸馏：把 35B teacher 的链式推理沿三语义维度拆解后蒸到 2B student，兼顾推理质量与可部署性。(3) 行为接地（behavior-grounded）框架：监督信号同时来自真实行为共现与语义推理，抑制 MLLM 产生与任务无关的解读。(4) 可迁移-残差解耦 + 路由：显式区分跨域共享信号与域特有信号，并用 Top/Bottom 20% 硬路由防负迁移——消融显示这是性能主力。

4. 实验结果分析

离线 HR@10 / NDCG@10：最强基线 UniEmbedding 为 0.0216 / 0.0097，RGCD-Rep 达 0.0254 / 0.0127，分别 +17.59% / +30.93%；其余基线 FREEDOM(0.0040/0.0018)、SMORE(0.0089/0.0032) 差距更大。消融最有说服力：去掉阶段二 HR 暴跌到 0.0101（约 −60%），去掉阶段二的 MLLM 微调降到 0.0189（−26%），而去掉阶段一只掉到 0.0249（约 −2%）——说明跨域表征学习（阶段二）是主力，蒸馏（阶段一）是锦上添花。尾部 item 与冷启用户（14.65%）上增益更明显，印证兴趣迁移对稀疏侧的价值。线上一周 A/B（快手主站/极速版双端）：曝光 +0.37%/+0.38%，点击 +0.34%/+0.13%，有效进房 +0.28%/+0.22%，关注 follow +0.83%/+0.93%——follow 提升最大，正好对应"帮用户发现冷启主播"这一目标，也说明迁移来的是真实兴趣信号而非曝光偏置。

5. 局限与未来方向

作者未单列局限。可观察到的约束：训练成本不低（8×H800，虽然部署轻量）；高度依赖高质量行为-协同对，对极稀疏域效果未知；只验证了短视频→直播的单向迁移，反向未探索；三个固定语义维度（垂类/主体/话题）未必适配所有内容类型，跨品类泛化待验证。

6. 工业实践意义

最值得借鉴的是落地姿势：teacher 推理→蒸馏到小 student→阶段二对全量 item 离线算 1536 维表征→建近邻索引，serving 端零大模型推理，已在快手服务日活 4 亿+，召回（matching）阶段用跨域近邻索引、亚毫秒级查表。这套范式对任何想用 MLLM 做表征但卡在线上延迟的团队都适用。对社区搜索，"主帖/长内容富行为域 → 问答/评论稀疏冷启域"的兴趣迁移可直接套用可迁移-残差解耦 + 路由防负迁移的设计；行为接地（用真实共现+强度构造监督，而非纯让 LLM 描述内容）也比纯语义匹配更稳，能抑制大模型的任务无关幻觉。需要注意迁移路由的 Top/Bottom 20% 硬切分、温度 τ=0.05、γ=10、λ_route=0.05 等超参需按业务重调，且离线预存 1536 维全量 item 表征对存储与索引更新链路有要求。

Dual-Stream MLP is All You Need for CTR Prediction

RUC📖 深度解读 · 15 分钟 →

主流 CTR 模型都是双流结构：一路用乘法显式构造特征交叉，一路用 MLP 隐式学习，两路输出直接相加。结构越复杂越难调，乘法那一路的输出还会随交叉阶数变大，相加时容易压过 MLP 那一路。DS-MLP 让最终模型只剩两个普通 MLP：一个通过知识蒸馏学会老师模型的显式交叉，另一个从零学习、补上老师漏掉的模式，两路先做批归一化，再各自用点击标签监督。先把老师变成同构的 MLP，再对齐融合。三个公开数据集上 AUC 都排第一，但 Criteo、Avazu 上只领先最强基线 0.0003 和 0.0006，只有 MovieLens 领先 0.0035。

Kesha Ou, Zhen Tian, Wayne Xin Zhao, Long Zhang, Sheng Chen, Ji-Rong Wen
arXiv·2026-06-04·Relevance 4 · Novelty 3 · Practical 5 · Evidence 4 · Timely 5

DS-MLP：先把复杂 CTR 模型蒸馏进一个三层 MLP，再并联一个独立 MLP 纠正老师的错，三个公开数据集上 AUC 小幅领先

我的判断：维护 CTR 排序模型、又被各种特征交叉结构折腾得够呛的团队值得一读，但别指望大幅提升。它要解决的问题是：主流 CTR 模型（DeepFM、DCNv2、GDCN（Gated Deep Cross Network，门控深度交叉网络）等）都是“双流”结构，一路用乘法显式构造特征交叉，一路用 MLP 隐式学习，两路输出直接相加；结构越复杂越难调，而且乘法那一路的输出会随交叉阶数变大，相加时容易压过 MLP 那一路。DS-MLP 的结论是：最终上线的模型只要两个普通 MLP 就够。一个 MLP 通过知识蒸馏学会老师模型的显式交叉，另一个从零学习、补上老师漏掉的模式，两路先做 batch normalization，再各自用点击标签监督，所以谁也压不过谁。作者在 Criteo、Avazu、MovieLens 三个公开数据集上和 17 个基线比较，DS-MLP 的 AUC 都是第一，但领先幅度很小，前两个数据集甚至低于论文自己给的显著线。

它到底在解决什么问题？

CTR 预估的输入是一堆离散特征：用户 ID、性别、广告类目、设备、时段等。单个特征的信息有限，真正有用的是组合，比如“晚上十点 + 手机端 + 游戏类广告”。怎么学这些组合，是 CTR 模型过去十年的主线。

两种学法的取舍：

学法怎么做代表模型问题
显式交叉用内积、逐元素乘法直接构造特征组合，叠几层就是几阶交叉FM、CrossNet、DCNv2阶数越高结构越复杂、越难调；乘法让输出数值随阶数放大
隐式交叉把所有特征拼起来过 MLP，让网络自己学组合DNN、FinalMLP学到了什么说不清，作者认为单靠它学不好显式组合
双流（两者相加）两路并联，输出直接相加DeepFM、xDeepFM、GDCN两路结构差异大，输出尺度不一致，一路容易压过另一路

作者把第三行的问题叫作不平衡融合：显式那一路做的是逐元素乘法，高阶交叉的数值会越乘越大；MLP 那一路经过 ReLU 之类的激活，输出范围有限。两者相加时，显式那一路就主导了最终预测。

先看全景

训练分两步，上线时只保留两个 MLP：

阶段做什么训练谁
0. 准备老师先按常规训练好一个强 CTR 模型（Criteo 用 GDCN，Avazu 用 DCNv2，MovieLens 用 FinalMLP）老师
1. 蒸馏冻结老师，学生 MLP 同时拟合点击标签和老师的预测学生 MLP
2. 对齐微调加入并联 MLP，两路隐藏层做 batch normalization，总损失 = 融合预测的交叉熵 + 每一路各自的交叉熵两个 MLP 一起
上线两路 logit 取平均，过 sigmoid 得到点击率只有两个 MLP，没有老师

第一步：把老师的显式交叉蒸馏进一个三层 MLP

老师 GDCN 每一层做的事可以这样理解：拿原始特征向量和上一层结果逐元素相乘，得到更高一阶的组合，再乘一个 sigmoid 门过滤掉没用的组合，最后加回上一层。叠 L 层就是 L+1 阶交叉。最终预测是这个交叉网络的输出加上一个普通 DNN（深度全连接网络，结构上就是 MLP）的输出。

学生是一个三层 MLP，宽度比基线常用的 400 更大：Criteo 上每层 600，Avazu 900，MovieLens 1000。损失是点击交叉熵加上 λ 倍的蒸馏损失，λ 在 Criteo 和 Avazu 上取 1.0，MovieLens 取 0.5。

为什么 MLP 能学会乘法结构？论文第 3.5 节给了一个理论论证：MLP 是通用函数逼近器，只要容量够，就能在输出上逼近老师；再假设函数足够光滑，输出接近意味着二阶导数也接近，而二阶混合偏导正好衡量两个特征之间的交互强度。这个论证的前提（光滑性、过参数化优化能收敛）在实际训练里无法验证，它说明的是“可能学会”，不是“一定学会”。

作者在实验里做了一个更直接的检查：用老师 GDCN 在三个合成特征上生成标签，看谁能拟合这些显式交叉。

这张图可以读出两点。一是学生的误差比并联 MLP 低得多，说明蒸馏确实把老师的交叉模式传了过去，而并联 MLP 没有学老师，留给它去学别的东西。二是 CrossNet 本身的误差忽高忽低，这正是作者说的显式结构难优化，而 MLP 的曲线平稳得多。

第二步：并联一个 MLP，用两种对齐让两路平起平坐

作者在初步实验里发现，老师本身就是不平衡的双流，显式那一路主导预测，所以学生蒸馏到的也主要是显式交叉，隐式那部分被忽略了。补救办法是再并联一个 MLP，专门学隐式交叉。这个并联 MLP 不用老师的特征 embedding，而是从零学习，因为它的任务不是模仿老师。

两路训练方式不同，输出差别会很大，直接相加又会回到“一路压过另一路”的老问题。作者用了两种对齐：

对齐方式做法解决什么
隐藏状态对齐两路的隐藏层都做 batch normalization，把每个维度按批内均值和方差标准化两路输出落在相近的数值范围，谁也不会因为数值大而主导
预测对齐除了融合预测的交叉熵，每一路单独再算一次点击交叉熵，分别乘 α 和 β每一路自己也要能预测点击，不能只靠另一路兜底

α 和 β 不能太大也不能太小。作者在 0.5 到 1.5 之间扫 α，效果在 1 附近最好：这是因为太大时两路被逼得几乎一样，失去互补；太小时对齐不够。各数据集最终选的 α 在 0.8 到 1.5 之间，β 在 0.6 到 1.2 之间，说明这组权重需要按数据集调。

效果：领先多少，算不算数

实验沿用 BARS（CTR 领域的开源可复现基准）的设置：embedding 维度 10，batch 4096，基线的 MLP 都是三层 400。指标是 AUC（随机取一个点击样本和一个未点击样本，模型把点击样本排在前面的概率）和 LogLoss（预测概率与真实点击的交叉熵，越低越好）。论文表头写明，AUC 高 0.001 或 LogLoss 低 0.001 在 CTR 任务里就算显著。下表里出现的两个基线：FCN（Fusing Cross Network，2024 年的融合交叉网络，把线性和指数增长的交叉子网络合在一起）和 Final（2023 年的因子化交互层模型，用改造过的线性层显式学二阶交叉，和 FinalMLP 是两个不同的模型）。

按论文自己的 0.001 标准，Criteo 和 Avazu 上 DS-MLP 相对最强基线的领先都不到显著线，只有 MovieLens 上是明确的提升。论文没有报告多次运行的标准差，也没有做显著性检验，所以 0.0003 这种差距很可能落在随机种子的波动里。

延迟方面，DS-MLP 在 Criteo 上是 59.43 ms，和 FinalMLP 的 56.71 接近，但比 Final 和 DeepFM 慢一倍多，比老师 GDCN 的 45.02 也慢。原因不难理解：学生每层 600 宽，再加一个并联 MLP，计算量并不比 GDCN 小。论文说的“简单高效”更多指结构单一、好部署，而不是更快。另外论文没说明延迟是按单条样本还是按一个 batch 测的。

换个老师也行吗

加大模型会更好吗

论文据此说 DS-MLP 随容量增长持续提升，而 GDCN 饱和甚至下降。看散点会更谨慎一些：DS-MLP 在约 200 万参数后也已经饱和，拟合直线的上升主要来自左边几个很小的配置。这张图能说明的是，加宽 MLP 不会像 GDCN 那样不稳定，但说不上“越大越好”。Avazu 上的情况类似，DS-MLP 的点散布在 0.7647 到 0.7660 之间，GDCN 的波动更大。

我认为它的局限

第一，提升幅度和统计证据都偏弱。两个大数据集上领先最强基线不到 0.001，又没有多次运行的方差，结论“全部 SOTA”站得不太稳。

第二，总成本没有算全。上线模型是两个 MLP，但训练前必须先训好一个强老师，再蒸馏、再微调，整个流程要依次跑老师训练、蒸馏、对齐微调三轮。延迟也没有比主流双流模型低。

第三，方法描述前后不一致。第 3.1.3 节说蒸馏的是 logit、用带温度的交叉熵；算法 1 写的是对隐藏表示算 KL 散度；理论部分又用均方误差。融合方式也是一处写 logit 取平均、一处写概率按 γ=0.5 加权。复现时应以开源代码为准。

第四，embedding 表的数量不清楚。正文说并联 MLP 不复用老师的 embedding、从零学习，这意味着可能有两套 embedding；而对比表里又标注 DS-MLP 只用单个 embedding 表。CTR 模型的参数大头在 embedding，这一点直接影响线上内存。

第五，“显式那一路压过隐式那一路”是全文动机，但论文只给了文字描述，没有展示两路输出的数值分布。此外，超参数图里 MovieLens 的最高 AUC 约为 0.9711，和主表的 0.9752 对不上，可能是不同配置，论文没有解释。

一个排序团队可以怎么试

  1. 拿线上现有的交叉网络模型当老师，不必换成 GDCN，兼容性实验说明换老师基本都有收益。
  2. 先只做第一步，训练一个比现有 MLP 更宽的学生，看它单独能否追平老师；如果追平了，就已经得到一个结构更简单的模型。
  3. 再加并联 MLP 和两种对齐，α、β 从 1 附近开始调，同时盯 AUC 和 LogLoss，后者变差时要补校准。
  4. 用自己的线上延迟标准测一遍，不要假设它比现有模型快。

结论

一句话：把复杂交叉网络的知识蒸馏进 MLP，再并联一个独立 MLP 纠正老师的偏差，能得到一个结构单一、效果不输复杂模型的 CTR 模型，但离线提升很小，成本也没有省下来。

维度评价
问题重要性中。双流结构的复杂度和融合不平衡是真问题，但多数团队已有成熟方案
方法创新性中。蒸馏加双 MLP 都不新，新在“先变成同构的 MLP 再对齐融合”这个组合
实验证据偏弱。只有公开数据集，大数据集上提升低于显著线，无方差、无线上实验
工程成本中。上线结构简单，但训练流程变长，延迟没有优势
是否值得尝试可以小规模试。适合想把复杂交叉结构换成纯 MLP、便于部署和扩展的团队

Breaking the Likelihood Trap: Consistent Generative Recommendation with Graph-structured Model

Kuaishou

重排（reranking）决定最终曝光。生成式重排把重排建模成整段序列生成，但存在「似然陷阱」：高似然序列往往重复单调、人感知质量差，反而压低用户参与。快手提出 CONGRATS：用图结构模型替代线性自回归解码，通过图上多路径探索扩大解码空间、提升序列多样性，同时用图转移显式建模 item 间依赖来提升预测准确性；再配一个可微的一致性训练（带 evaluator）直接从用户偏好学习。离线优于现有重排方法，已在快手（日活 3 亿+）线上验证，论文被 KDD 2026 接收。

INSIGHT似然陷阱是生成式重排/生成式推荐的共性坑：最大似然解码偏好「安全但重复」的序列，与真实用户体验（要多样、要新鲜）背离。CONGRATS 把自回归链式解码换成图结构多路径解码 + 用 evaluator 做偏好对齐，相当于在生成端同时引入多样性与一致性约束。对做生成式重排/list-wise 排序的团队，这是一个直接可借鉴的解码结构改造，而非简单加多样性正则。

Beyond Retrieval: Learning Compact User Representations for Scalable LLM Personalization

LLM 个性化现有两条路都有短板：输入级（检索用户历史 / 拼 profile prompt）依赖检索质量和 prompt 设计；参数级（每个用户存一个 PEFT 模块）存储维护成本随用户量线性增长。本文提出 TAP-PER（Temporal Attentive Prefix for PERsonalization），把用户偏好编码成可学习的 prefix 表征，省掉显式 prompt 构造，也用轻量「用户状态 prefix embedding」替代每用户一个 adapter，并把用户建模拆成 user-state 与 query-conditioned 两部分、引入时序信号捕获兴趣演化。在 6 个 LaMP 任务（分类/打分/生成）上优于基线，per-user 参数比 OPPU 少 130×，千用户规模下总参数量约为 PER-PCS 的一半。

INSIGHT把「每用户一个 adapter」换成「每用户一个轻量 prefix 表征」，是 LLM 个性化在大规模用户下控存储成本的关键设计——参数从 O(用户数 × adapter) 降到 O(用户数 × prefix 维度)。user-state（长期偏好）与 query-conditioned（当前意图）解耦 + 时序 attention，思路和推荐里的长期/短期兴趣建模一致。对社区做个性化 LLM 搜索/问答的场景，这套 prefix 化用户状态的方案比拼长 prompt 更省 token、更易扩展。

SAILRec: Steering LLM Attention to Dual-Side Semantically Aligned Collaborative Embeddings for Recommendation

Northeastern University

LLM 推荐里给模型喂了协同过滤 embedding，不等于模型在推理时真用上了它。作者做了一个 attention 诊断分析，发现协同 embedding 的利用是深度依赖、对齐敏感的：浅层会过早引入协同干扰，深层才该让协同证据起决策作用。SAILRec 据此做两件事：双侧语义对齐（item 侧 embedding 对齐 item 文本语义，user 侧对齐基于 codebook 的语义画像）+ 分层注意力引导（抑制浅层协同干扰、强化深层协同证据）。在 MovieLens-1M 和 Amazon-Book 上稳定优于代表性基线。

INSIGHT把协同信号塞给 LLM，和 LLM 真正在正确的层用上协同信号，是两回事——这个 attention 诊断视角对所有做 LLM+ID / 协同 embedding 融合的工作都有提示：融合位置和层次比是否融合更关键。双侧对齐（item 对文本、user 对语义画像 codebook）+ 分层注意力引导，提供了一个让协同 embedding 在 LLM 内部「该浅则抑、该深则用」的可操作机制。当前为公开学术数据集验证，工业级规模与在线效果尚待检验。

Xi Wu, Jiale Wang, Zihan Wang, Yichen Gao, Xiaocui Yang, Shi Feng, Daling Wang, Yifei Zhang
