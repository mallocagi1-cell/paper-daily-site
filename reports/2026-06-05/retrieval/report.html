1. DSIRM: Learning Query-Bridged Discrete Semantic Identifiers for E-commerce Relevance Modeling
4.40
Relevance 5 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 针对电商搜索相关性中连续 embedding 难以刻画细粒度属性差异的问题，提出离散语义标识符相关性模型 DSIRM。在 item 侧采用 query-bridged 对比量化，把 query-item 交互监督注入 SID 生成，取代传统无监督量化，使同一 SID 下聚合的 item 更符合 query 维度的排序需求。论文给出量化码本学习与相关性打分的联合训练方案。

Key insight: 把判别式相关性监督引入语义 ID 的生成过程，是对 TIGER 类无监督量化路线的修正：SID 不再只压缩 item 内容，而是按 query 区分度聚类。社区搜索若要用生成式/SID 召回，可借鉴这种 query-bridged 对比量化来缓解短文本属性区分不足的问题。

2. Training-Free Lexical-Dense Fusion for Conversational-Memory Retrieval
4.40
Relevance 5 | Novelty 3 | Practical 5 | Evidence 4 | Timely 5

Summary: 面向长对话记忆检索（LoCoMo、LongMemEval），研究 training-free、纯 CPU 的检索增强方案。核心发现：将晚期交互稠密分数与 BM25 做分数级融合（单一 leave-one-conversation-out 权重），在 6 个 encoder 上把 LoCoMo Hit@1 提升 +8.8~17.2 分（均 p<1e-4），e5-large-v2 达到 Hit@1 0.752 / NDCG@5 0.829，较纯 BM25 高 11.2 个百分点。

Key insight: 在已有稠密晚期交互（Turn Isolation）之上叠加 BM25 分数融合，零训练即可拿到两位数 Hit@1 增益，说明词面信号在短文本/对话检索中仍不可替代。社区搜索的混合召回可直接照搬 score-level fusion + 单一融合权重的轻量做法，无需重训 encoder。

3. Argus-Retriever: Vision-LLM Late-Interaction Retrieval with Region-Aware Query-Conditioned MoE for Visual Document Retrieval
3.80
Relevance 3 | Novelty 5 | Practical 3 | Evidence 4 | Timely 5

Summary: 晚期交互视觉检索（ColPali/ColQwen 等）的文档 embedding 不看 query，导致同一页面对表格查找、图表问答、版式定位都用同一表示。Argus 基于 Qwen3.5-VL 提出 query-conditioned 晚期交互：query 编码器同时产出检索向量与上下文向量，文档页按空间区域池化，再由 query 感知路由为每个区域选择潜在专家（region-aware MoE），输出仍是兼容 ColPali 的多向量索引。

Key insight: 用 query 条件化 + 区域级 MoE 让同一文档对不同 query 呈现不同表示，突破了双塔晚期交互'文档表示与 query 无关'的固有局限。这一 query-conditioned 思路对文本多向量检索同样有启发：可按 query 意图动态加权 token/片段表示。

4. EviRank: Evidence-Based Confidence Estimation for LLM-Based Ranking
3.75
Relevance 4 | Novelty 4 | Practical 3 | Evidence 3 | Timely 5

Summary: LLM 做排序存在可靠性问题：面向问答的全局置信度无法定位排序列表中哪些位置不可靠，而从模型内部抽取的细粒度置信度在所有位置都偏低、无法筛选。EviRank 在单次前向中抽取三类互补证据并用可靠意见聚合，且认识到排序位置本身不等权，引入位置相关的置信度估计来识别不可靠预测。

Key insight: 把'排序位置不等权'纳入置信度建模，单次前向即可定位不可靠的排序位置，比全局置信度更适合做级联/兜底决策。用 LLM 重排的搜索系统可借此对低置信位置触发降级或人工复核，控制 badcase。

5. BEATS: Bootstrapping E-commerce Attribute Taxonomies for Search through Iterative Human-AI Collaboration
3.75
Relevance 4 | Novelty 3 | Practical 4 | Evidence 3 | Timely 5

Summary: 新兴市场电商目录常只有类目而缺结构化属性 schema，限制了 faceted 过滤、query 理解与语义表示。BEATS 是 human-in-the-loop 的 LLM 框架，从零 bootstrap 商品属性体系：在多阶段 LLM 生成流水线上加入两个生产级环节——开发者主动质检过滤错误输出，以及本地领域专家人工校验，迭代式按反馈优化各阶段 prompt。

Key insight: 用'LLM 生成 + 主动质检 + 专家校验'迭代构建属性体系，把无结构 UGC/商品文本转成可用于 faceted 检索与 query 理解的结构化信号。社区搜索若要给 UGC 内容补结构化标签/属性，这套人机协同的 bootstrap 流程值得参考。
