1. ANN Search: Recall What Matters
4.00
Relevance 4 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: 近似最近邻（ANN）检索普遍用 Recall@k（召回的真实 kNN 占比）来评测和调参，论文指出这会强制系统为追求与精确 kNN 的集合重合而付出不必要的算力。作者主张真正重要的是检索结果的距离质量，而非与真值集合的重合度，提出用 1/Ratio@k（逆近似比，衡量检索邻居与真实邻居的距离差异）替代 Recall@k：该指标无需裁判模型、无超参，仅用标准 ANN benchmark 输入即可计算。论文在覆盖不同内在维度（intrinsic dimensionality）的多个数据集上对 SOTA ANN 算法做了系统对比。

Key insight: 对短文本召回与向量库选型有直接启发：用 Recall@k 调 HNSW/IVF 参数往往过度保守、浪费算力，而 1/Ratio@k 直接反映“召回项离真值多近”，更贴合下游 nDCG。落地上可在现有 benchmark 上零成本替换评测口径，据此重新选择 ef/nprobe 等参数，在相同结果质量下换取更高吞吐。

2. Distributional Approximate Nearest Neighbour Search for Uncertainty-Aware Retrieval
4.00
Relevance 4 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: 推荐系统的 ANN 索引通常为每个用户/物品学习单点 embedding，但稀疏交互数据使表示充满噪声，检索因此系统性偏向少数 embedding 估计良好的热门头部物品，牺牲长尾、多样和惊喜内容。论文提出 DINOSAUR：为每个 embedding 引入分布式（带不确定性）表示，并设计与现有 ANN 基础设施兼容的检索框架，在召回阶段显式考虑表示不确定性，从而缓解头部偏置、提升长尾覆盖与多样性。

Key insight: 直指 UGC 社区召回的头部偏置问题——冷门优质帖子因 embedding 估计不准而被结构性埋没。亮点是“基础设施兼容”：不必替换现有向量库，而是在 embedding 层引入不确定性建模。可借鉴其分布式 embedding 思路改造短文本召回，在不重建索引的前提下缓解长尾内容曝光不足。

3. More Than Efficiency: Embedding Compression Improves Domain Adaptation in Dense Retrieval
3.90
Relevance 4 | Novelty 3 | Practical 5 | Evidence 4 | Timely 3

Summary: 稠密检索器在专业领域常因训练域与目标域分布不匹配而退化，传统域适配需要昂贵的标注与 query-document 对重训练。论文重新审视一个被忽视的替代方案：对领域 embedding 做 PCA 降维，保留域相关判别成分、丢弃非判别噪声维度。结果表明这种压缩不仅省存储/算力，还能改善域适配效果——即“压缩即正则”，在无需重训练的前提下提升专业域稠密检索质量。

Key insight: 对社区垂类搜索很实用：切换领域时不必重训 encoder，仅用目标域语料估计 PCA 子空间即可同时降本与提质。可作为短文本稠密召回的轻量域适配基线，与 Matryoshka 截断维度思路互补；建议先在自有 UGC 语料上验证“PCA 压缩提质”能否复现，再决定上线维度。

4. Cartridges at Scale: Training Modular KV Caches over Large Document Collections
3.80
Relevance 3 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: Cartridge 通过把文档集合蒸馏成可复用的 KV cache 来消除长上下文 prefilling，但单个 cartridge 是整体式、不可组合的：把整个集合编码进单一 KV 块无法扩展，而把独立训练的 cartridge 简单拼接会让性能塌缩到接近随机。论文提出 Cartridges at Scale（CAS）训练框架，引入动态干扰项混合（dynamic distractor mixing）与内存高效的预算管理器，在 GPU 与持久化存储间轮换数百个 per-document cartridge。方法可扩展到超百万 token 的集合，在相当 token 预算下比单体 cartridge 提升 10–31 个百分点。

Key insight: 面向“大语料 + 高频复用”的 RAG 服务（如社区知识库问答）很有价值：把静态文档预蒸馏成 KV cache，请求时跳过 prefilling 直接降延迟。亮点是组合性与 GPU/存储分级调度——把 KV cache 当作可分页轮换的物料管理。可借鉴其 distractor 混合训练来避免多文档 cache 互相干扰导致的性能塌缩。

5. Supportive Token Revealing for Fast Diffusion Language Model Decoding
3.70
Relevance 3 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: 离散扩散语言模型通过并行更新多个 mask 位置来加速生成，但并行带来质量-延迟权衡：激进解码会过早确定相互依赖的 token，保守解码又需要很多去噪步。已有方法靠置信度/依赖准则判断哪些 token 可安全揭示，但“避免不安全提交”并不能让剩余 mask 序列更易解码——不确定 token 仍可能依赖其它 mask token，形成去噪瓶颈。论文提出 AXON：一个 training-free 模块，可叠加在现有并行解码策略之上，监控剩余不确定 mask token，仅在其状态表明“需要更多上下文”时才介入，从而打破瓶颈、减少去噪步数。

Key insight: 对延迟敏感的生成式检索/摘要场景有参考价值。亮点是 training-free 且即插即用，不替换基础解码器而是按需干预。若团队在试扩散式 LLM 做 query 改写或答案生成，可叠加 AXON 在不重训的情况下压缩解码步数；其“揭示能降低剩余序列不确定性的支撑 token”思路也可迁移到其它并行解码框架。

7. Prompt-Level Distillation: A Non-Parametric Alternative to Model Fine-Tuning for Efficient Reasoning
3.35
Relevance 3 | Novelty 3 | Practical 4 | Evidence 4 | Timely 3

Summary: 高级推理通常依赖 Chain-of-Thought，准确但延迟高、test-time 成本大；用小模型微调又牺牲可解释性并带来资源/运维开销。论文提出 Prompt-Level Distillation（PLD）：从 Teacher 模型抽取显式推理模式，组织成结构化的“指令清单”写入 Student 的 System Prompt。在 Gemma-3 4B 上，StereoSet 的 Macro F1 从 57% 提升到 90.0%，Contract-NLI 从 67% 到 83%，LogiQA 准确率提升到 70%；在 Mistral Small 3.1 上结果类似，表明跨架构泛化。

Key insight: 提供一条“非参数蒸馏”路径：不微调，仅把 Teacher 的推理范式落成 system prompt 指令，让小模型以近乎零延迟开销逼近前沿表现。对成本敏感的 query 理解/相关性判断很实用——可先用强模型在自有任务上提炼判别规则，再灌入小模型 system prompt，决策过程也更可审计。需注意指令清单可能过拟合特定任务，要在多任务上验证稳健性。
