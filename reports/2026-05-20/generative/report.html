RAGR: Review-Augmented Generative Recommendation

论文指出当前生成式推荐 (GR) 虽然引入了 semantic ID、自回归解码、统一 token 空间等新机制，但仍沿用「只建模 item 序列」的假设，无法捕捉用户为什么选择某个 item 的评价性因素。RAGR 提出 Review-Augmented User Sequence Modeling：把用户撰写的 review 反馈直接编入生成式用户序列，与 item token 交错排列，而不是作为辅助 side information。review 文本暴露的潜在评价维度被纳入自回归生成目标，使 GR 在序列推荐任务上同时建模「选了什么」与「为何选」。

From Volume to Value: Preference-Aligned Memory Construction for On-Device RAG (EPIC)

面向端侧个人 AI agent 的 RAG，论文认为内存预算受限时真正的瓶颈是「该存什么」才能让检索与用户对齐。EPIC (Efficient Preference-aligned Index Construction) 把用户偏好作为紧凑且稳定的个人上下文形式，贯穿整条 RAG 管线：从原始数据中选择性保留与偏好相关的信息，并把检索引导向偏好对齐的上下文。在覆盖对话、辩论、解释、推荐四类任务的 4 个 benchmark 上，EPIC 把索引内存压缩 2,404 倍，同时提升偏好遵循能力。

INSIGHT「以用户偏好为索引压缩的核心信号」对社区搜索的个性化召回有借鉴价值：与其全量存储用户行为再检索，不如先抽取稳定偏好画像作为索引锚点。2,404 倍的内存压缩说明偏好导向的索引裁剪在不显著损失偏好遵循的前提下极其激进，可用于端侧/低成本个性化重排，以及对长期用户兴趣做稳定建模而非依赖近期行为噪声。

The Impact of AI Search on the Online Content Ecosystem: Evidence from Google and Reddit

研究生成式 AI 搜索（Google AI Overviews）对 UGC 社区平台（Reddit）的影响。识别策略利用 Google 内容审核政策的差异：SFW 社区会被 AI Overviews 引用，NSFW 社区虽被自然搜索索引但被禁止出现在 AI 摘要中，从而构成准实验。采用双重差分 (difference-in-differences) 设计发现：AI Overviews 使 SFW 社区参与度上升——日评论数相对 NSFW 社区提升 12.0%、评论用户数提升 12.3%，即生成式摘要并未单纯「截流」，反而为被引用社区带来回流。

INSIGHT这是少见的、用因果识别量化「生成式搜索 vs UGC 社区流量」关系的实证，与社区搜索业务高度相关。结论提示：被生成式答案引用的优质 UGC 社区会获得参与度增益（+12%），因此社区平台的策略不应是抵制 AI 摘要，而是优化内容被检索/被引用的可发现性（类似 Answer Engine Optimization）。对内部搜索而言，生成式摘要+可点击溯源链接的组合可能同时提升满意度与社区互动，值得做线上对照实验。

04 3.55

LERA: LLM-Enhanced RAG for Ad Auction in Generative Chatbots

面向 LLM 对话机器人的广告竞价。已有 retrieve-then-generate 范式把检索与生成解耦以做轻量广告插入和计费，但检索仅靠文本 embedding 相似度，易造成商业意图误判和重复插入。LERA 提出两阶段 retrieve-then-generate 竞价框架：第一阶段用 embedding 粗筛预选少量候选广告主；第二阶段用精心设计的 prompt 直接查询 LLM 产出 logits，作为相关性/竞价信号，从而在相关性、效率与用户体验之间取得平衡。

INSIGHT「embedding 粗筛 + LLM logits 精排」的两段式结构对社区搜索的 LLM 重排有直接参考价值：用廉价向量召回控规模，再用 LLM 对小候选集打分，可在可控延迟下引入 LLM 的语义判别力。其对「商业意图误判」「重复插入」的处理，对 UGC 搜索中广告/推广内容与自然结果混排的相关性与去重也有借鉴意义。

S2GR: Stepwise Semantic-Guided Reasoning in Latent Space for Generative Recommendation

生成式推荐 (GR) 多数方法只从交互序列直接生成 semantic ID，未激活类似 LLM 的深层推理能力。论文指出现有「推理增强 GR」的两个缺陷：(1) 推理与生成步骤严格串行分离，导致跨层级 SID code 的算力分配失衡、降低 SID code 质量；(2) 生成的推理向量缺乏可解释语义，推理路径监督不可验证。S2GR 提出在隐空间做 stepwise semantic-guided reasoning：先通过 codebook 优化建立稳健语义基础，再以分步语义引导的隐空间推理替代串行推理，缓解算力失衡并提升推理可解释性。

INSIGHT把「推理」嵌入生成式推荐的解码过程、并在隐空间分步进行而非串行外挂，是 GR 向 LLM 式推理靠拢的关键路径。对实践的启示：semantic ID 的 codebook 质量是推理增强 GR 的前提（先优化 codebook 再上推理），以及推理算力应在层级 SID code 间均衡分配，避免高层 code 主导、低层 code 质量塌陷。

MARQUIS: A Three-Stage Pipeline for Video Retrieval-Augmented Generation

视频 RAG 需要从大规模音视频语料检索证据并合成有溯源的连贯文本。现有方法两端都弱：检索方法无法用单一 embedding 表达复杂多面 query；生成方法缺乏跨多视频综合的高层推理且受长上下文内存限制。MARQUIS 提出三阶段管线：(1) query 扩展、融合与重排；(2) 校准的结构化证据抽取；(3) 由 RLM 可选控制的文章生成。在 MAGMaR2026 共享任务上检索 nDCG@10 从 0.195 提升到 0.759；文章生成上 ITER-QA-BASE 把人工平均分从 3.09 提升到 3.83（相对 CAG 基线）。

INSIGHTquery 扩展+融合+重排的组合带来 nDCG@10 0.195→0.759 的大幅提升，印证「单 embedding 表达复杂多面 query 不足」这一痛点在社区搜索同样存在——长尾、多意图的 UGC query 适合用 query 扩展/改写+多路融合再重排。结构化证据抽取这一中间层，对生成式搜索摘要的可溯源性（每句话挂证据）也提供了可落地的工程范式。

Navigating the Shift: A Comparative Analysis of Web Search and Generative AI Response Generation

大规模实证量化 Google Search 与主流生成式 AI 服务返回结果的根本差异：在引用的来源域、域类型（earned media vs owned/social）、query 意图、信息时效性等多个维度上，AI 生成答案与网页搜索结果显著背离。论文进一步分析 LLM 预训练知识库如何与实时网页搜索交互、共同塑造这些差异，并就新兴的 Answer Engine Optimization (AEO) 提出关键观察。

INSIGHT生成式答案与传统网页搜索在「来源类型/意图/时效」上的系统性差异，意味着社区平台需要分别评估「在传统搜索中可见」和「在生成式答案中被引用」两套可发现性指标。AEO 的兴起提示：内容结构化、可被 LLM 抽取引用的程度会成为社区内容分发的新变量，内部搜索若引入生成式摘要也应监控其对来源多样性与时效性的偏置。

Dual-Diffusional Generative Fashion Recommendation (DualFashion)

个性化生成式推荐用于时尚推荐时，现有方法主要依赖历史交互的隐式视觉 embedding，混入大量与偏好无关的信息，且通常只生成 item 图像、可解释性差。DualFashion 提出双扩散生成架构：采用带图像分支和文本分支的 dual-diffusion Transformer，把结构化属性级 caption 与视觉穿搭信息共同作为条件信号建模用户行为，同时生成时尚 item 图像与文本描述，保证视觉兼容性与可解释性。

INSIGHT图文双分支扩散联合生成的思路说明：生成式推荐输出不必局限于 item ID/图像，可同时生成解释性文本，提升可解释性。对社区场景，「属性级结构化 caption 作为条件信号」这一做法可迁移到 UGC 内容的多模态生成式推荐——用结构化标签约束生成，缓解隐式 embedding 引入的偏好无关噪声；但扩散模型的推理成本使其短期更适合离线/低 QPS 场景。

Advancing content provenance for a safer, more transparent AI ecosystem (OpenAI)

OpenAI

OpenAI 推进 AI 内容溯源：通过 Content Credentials、SynthID 水印与一个验证工具，帮助用户识别并信任 AI 生成媒体。该工业实践面向生成式 AI 内容生态的可信与透明，提供从生成端打标到消费端验证的链路。（注：本条因低于 min-score，按覆盖规则作为「工业实践/工程博客」纳入。）

INSIGHT对社区平台的直接意义在于 AI 生成 UGC 的识别与治理：Content Credentials/SynthID 这类来源标记可作为生成式内容在社区搜索/推荐中的一个可信度特征，用于排序降权或标注。随着生成式答案与 AIGC UGC 增多，「内容是否可溯源」会成为相关性与质量评估之外的新治理维度，值得在内容质量分中预留该信号位。
