1. Generative Retrieval Overcomes Limitations of Dense Retrieval but Struggles with Identifier Ambiguity
3.60
Relevance 4 | Novelty 3 | Practical 3 | Evidence 4 | Timely 5

Summary: 本文系统对比了生成式检索（Generative Retrieval）与稠密检索（Dense Retrieval）的能力边界。在 LIMIT 合成数据集上，生成式检索模型 SEAL（0.92 R@2）和 MINDER（0.99 R@2）显著超越稠密检索（<0.03 R@2）和 BM25（0.86 R@2），证实了生成式检索在 embedding 空间失效场景下的优势。然而，当引入标识符歧义（hard negatives）后，所有模型性能急剧下降（SEAL 降至 0.51 R@2），暴露了生成式检索在解码机制上的固有缺陷：无法生成对相关文档唯一的标识符。

Key insight: 本文揭示了生成式检索的核心瓶颈在于标识符歧义问题——当多个文档共享相似的标识符前缀时，解码过程无法有效区分相关文档。这对生成式推荐系统（如 TIGER、HSTU 等使用语义 ID 的模型）具有重要启示：语义 ID 的设计不仅要考虑编码质量，更需确保 ID 在解码过程中的唯一性和可辨识性。未来方向包括设计更适合解码的标识符方案或改进解码/评分算法。

2. Multi-Faceted Self-Consistent Preference Alignment for Query Rewriting in Conversational Search
3.75
Relevance 4 | Novelty 3 | Practical 4 | Evidence 3 | Timely 5

Summary: 提出 MSPA-CQR 框架，通过多维度自一致性偏好对齐来优化对话式搜索中的查询改写。核心思路是从改写质量、检索效果和响应生成三个维度构建自一致性偏好数据，然后使用前缀引导的多维 DPO（Direct Preference Optimization）联合学习三个维度的偏好信息。实验表明该方法在分布内和分布外场景下均有效提升查询改写质量。

Key insight: 将 DPO 引入对话式查询改写具有创新性，尤其是多维度偏好信号的融合方式值得借鉴。对搜索推荐系统的启示在于：传统 query 改写只优化改写文本本身，而 MSPA-CQR 将下游检索效果和响应质量作为反馈信号反向优化改写模型——这种端到端偏好对齐思路同样适用于生成式推荐中的 query-item 匹配优化，以及 LLM-based 推荐系统的 RLHF 训练。

3. DMax: Aggressive Parallel Decoding for dLLMs
3.70
Relevance 3 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: 提出 DMax，一种面向扩散语言模型（dLLMs）的高效并行解码范式。与传统 masked dLLM 从掩码到 token 的二元转换不同，DMax 将解码重新构建为从掩码嵌入到 token 嵌入的渐进自精炼过程，有效缓解了并行解码中的错误累积问题。核心创新包括 On-Policy Uniform Training 策略，统一了 masked 和 uniform dLLMs 的训练方式，使模型能从两种噪声中恢复干净 token。

Key insight: DMax 对生成式推荐系统具有直接技术参考价值。当前基于扩散模型的生成式推荐（如 MDGR、LLaDA-Rec）面临并行解码效率与质量的权衡难题。DMax 提出的渐进自精炼解码策略避免了一步式解码的高错误率，同时保持了并行性，这为扩散式推荐模型的推理加速提供了新思路。On-Policy Uniform Training 的统一训练策略也可迁移到推荐场景中的 semantic ID 生成任务。

4. MARS: Enabling Autoregressive Models Multi-Token Generation
3.70
Relevance 3 | Novelty 3 | Practical 5 | Evidence 3 | Timely 5

Summary: 提出 MARS（Mask AutoRegreSsion），一种轻量级微调方法，使指令微调的自回归模型能在每次前向传播中预测多个 token。该方法不需要修改架构、不增加额外参数，生成的单一模型可完全兼容原始 AR 模型的调用方式且不损失性能。与投机解码（需维护独立的 draft model）或多头方法不同，MARS 只需简单微调即可获得 1.5-1.7 倍的吞吐量提升。

Key insight: MARS 的「零架构改动、零额外参数」设计理念对生成式推荐部署具有重要参考。在自回归生成式推荐模型（如 TIGER、HSTU）中，semantic ID 的逐 token 生成是推理瓶颈。MARS 通过掩码策略教会模型一次生成多个 token，可直接应用于加速 semantic ID 序列的生成，且不需要维护额外的 draft 模型。其 1.5-1.7 倍加速比在推荐系统的在线服务场景中意义重大。

6. STDec: Spatio-Temporal Stability Guided Decoding for dLLMs
3.45
Relevance 3 | Novelty 3 | Practical 4 | Evidence 3 | Timely 5

Summary: 提出 STDec，一种面向扩散语言模型的时空稳定性引导解码方法。观察到 dLLM 解码过程中存在强时空稳定性：新解码 token 倾向于出现在已解码邻居附近（空间稳定性），且预测的 token ID 在不同步骤间高度一致（时间稳定性）。基于此观察，STDec 利用局部上下文和跨步骤一致性信号指导解码，替代传统的全局置信度阈值方法。在多个基准上实现最高 14.17 倍加速。

Key insight: STDec 的时空稳定性观察对扩散式生成推荐具有启发意义。在基于扩散模型的推荐系统（如 MDGR）中，semantic ID 的并行解码同样面临效率瓶颈。STDec 的「无需训练、即插即用」特性使其可直接应用于推荐模型的推理优化。其核心思想——利用局部上下文（已推荐 item 的 ID 模式）和时间一致性（多步骤间的 ID 稳定性）引导解码——为推荐场景的解码策略设计提供了新视角。

9. Fast-dVLM: Efficient Block-Diffusion VLM via Direct Conversion from Autoregressive VLM
3.15
Relevance 2 | Novelty 4 | Practical 3 | Evidence 3 | Timely 5

Summary: 提出将已有的自回归 VLM 直接转换为块扩散（Block-Diffusion）VLM 的方法，实现单阶段训练即可完成范式迁移。引入块大小退火、因果注意力机制和自动截断掩码等技术，在 11 个多模态基准上保持与 AR 基线相当的质量，同时通过 FP8 量化等优化实现超过 6 倍的端到端推理加速。

Key insight: 从 AR 到扩散模型的「直接转换」思路对生成式推荐架构演进具有启发价值。当前主流生成式推荐模型（TIGER、HSTU）基于 AR 范式，而扩散式推荐（MDGR、LLaDA-Rec）展现了并行解码的潜力。Fast-dVLM 证明了无需从头训练即可将 AR 模型迁移到扩散范式，这意味着已有的 AR 推荐模型可以低成本地升级为扩散模型，获得并行推理加速。其 6 倍加速对推荐系统的在线服务延迟优化意义重大。

10. HingeMem: Boundary Guided Long-Term Memory with Query Adaptive Retrieval for Scalable Dialogues
3.10
Relevance 3 | Novelty 3 | Practical 3 | Evidence 3 | Timely 5

Summary: 提出 HingeMem，一种基于事件分割理论的边界引导长期记忆方案。通过人物、时间、地点、话题四元素的边界触发超边构建可解释的索引接口，当元素发生变化时划定边界并写入当前片段。引入查询自适应检索机制，联合决策检索内容和检索量。在 LOCOMO 数据集上实现约 20% 的性能提升，同时减少 68% 的计算成本。论文被 TheWebConf 2026 录用。

Key insight: HingeMem 对对话式推荐系统的用户记忆管理具有直接借鉴价值。在基于 LLM 的对话式推荐中，长期用户偏好记忆是核心挑战。HingeMem 的事件分割思想——通过场景变化自动划分记忆段——比连续摘要或固定 Top-k 检索更自然。其查询自适应检索策略可用于推荐系统中的个性化上下文管理：根据用户当前意图动态调整历史偏好的检索量和检索内容，提升推荐的精准度和效率。
