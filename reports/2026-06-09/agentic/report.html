ToolRec: Calibrated Preference Alignment for Query Recommendation in On-Device Assistants

LLM 显著提升了生成式 query 推荐，但已有对齐多面向标准 chatbot，不适配端侧助手——用户主要期望快速调起系统级工具。直接用真实点击日志对齐会因用户活跃度差异、未强调执行导向 query 引入严重噪声。ToolRec 提出校准的偏好对齐，面向 on-device 助手的工具调用 query 推荐。

TrustMargin: Training-Free Arbitration between Parametric Memory and Retrieved Evidence in Large Language Models

LLM 回答知识密集问题同时用参数化记忆与检索证据，但两者都非一致可靠：检索能补空缺，干扰段落也可能盖过正确的闭卷答案。本文把这种生成后的来源冲突建模为答案级来源仲裁：给定同一冻结模型的 Direct 与 RAG 答案，判定信哪个。提出 TrustMargin，免训练、即插即用。

INSIGHTRAG 不是“检索了就更好”——给出免训练的“信检索还是信记忆”仲裁，直击 RAG 可靠性痛点。对 Agent/RAG 搜索“何时该采信检索结果”有直接工程价值。

03 3.45

Adaptive Loss Balancing for Noise-Robust GRPO in Generative Recommendation

生成式推荐里用 GRPO 等 RL 做对齐时，奖励噪声会损害训练稳定性。本文提出噪声鲁棒的自适应损失平衡，缓解 GRPO 在生成式推荐中的噪声敏感，提升训练稳定与效果。

INSIGHT把 LLM 后训练的 GRPO 迁移到生成式推荐并解决噪声敏感，是“RL 对齐 + 生成式推荐”的具体一步。对想用 RL 微调生成式召回/排序的团队有参考。

Bidirectional Semantic Complementary Tool Retrieval for Remote Sensing Agents

LLM Agent 处理遥感数据依赖庞大专用工具库，但工具文档常超出上下文窗口，精确工具检索成为 agentic workflow 关键。已有工具检索面临“语义不对称”：自然语言 query 表达宏观意图、工具文档描述微观功能。本文提出双向语义互补的工具检索缓解该不对称。

INSIGHT“query 宏观意图 vs 工具微观功能”的语义不对称是工具检索通用难题，双向语义互补可迁移到任何大工具库 Agent。对 Agent 搜索的工具/技能路由有借鉴。

07 3.45

FLOWREADER: Min-Cost Flow Optimization for Multi-Modal Long Document Q&A

长多模态文档迫使 RAG 从分散在文本、表格、幻灯片(甚至跨单元格/跨页/图文分离)的碎片拼装答案。Top-k chunk 检索独立看待每个碎片，无法表达证据连接。FLOWREADER 把证据组装重构为多部图上的最小费用流问题，显式建模证据如何连接。

INSIGHT把“证据组装”从 top-k 独立检索升级为图上最小费用流优化，是对碎片化证据的结构化建模。对长文档/多模态 RAG 的证据聚合有方法论价值。

08 3.10

Constrained Dominant Sets for Multimodal Document Question Answering

长多模态文档问答受限于“哪些证据到达 reader”而非检索数量。长文档里结论常在图、caption、引言句反复出现，相似度检索器会把资源分给近重复、漏掉互补证据。本文提出基于 Constrained Dominant Sets 的检索器，优先选互补而非冗余的证据。

INSIGHT点出多模态 RAG“近重复挤占、互补遗漏”问题，用 Constrained Dominant Sets 选互补证据集。对长文档检索的“去冗余+补互补”有借鉴。
