Unlocking large scale AI training networks with MRC (Multipath Reliable Connection)

OpenAI 提出 MRC（Multipath Reliable Connection），通过 OCP 开源的新一代超算网络协议，专门针对超大规模 AI 训练集群中常见的链路抖动、瞬态丢包和网卡级故障问题。MRC 在传输层将多条物理链路聚合为单一可靠流，故障切换无需上层感知，从而在数千 GPU 互联场景下显著降低 collective 通信的尾部延迟。OpenAI 将其提交到 OCP 标准，希望与其他超算厂商共建多路径以太网生态。

SHIELD: A Diverse Clinical Note Dataset and Distilled Small Language Models for Enterprise-Scale De-identification

Stanford

论文针对临床文本去标识化任务的企业级落地难题，构建了 1394 篇标注笔记、10505 个 PHI 跨度的多样化数据集 SHIELD，并将四个 LLM（含两个开源、两个商用）的能力蒸馏到可本地部署的小模型 SLM。采用集合覆盖（set-cover）多样性采样和人在回路审校，最终用 Frechet 距离做分布对齐评估。SHIELD 验证了：在合规要求严格、PHI 不能上云的场景下，蒸馏 SLM 可以替代大模型 API。

INSIGHT对社区 UGC 搜索的启示：当数据敏感（用户隐私、风控）或推理预算紧（亿级 QPS）时，由教师 LLM 标注、再蒸馏到学生 SLM 部署，是跑得通的工业范式。论文用集合覆盖采样保证训练数据多样性，避免长尾下分布漂移；这种分布感知蒸馏的思路可迁移到 query 改写、实体识别、内容审核等高 QPS 在线模块。

Jose D. Posada, David Love, Somalee Datta, Priya Desai

Benchmarking Parameter-Efficient Fine-Tuning of Large Language Models for Low-Resource Tajik Text Generation with the Tajik Web Corpus

作者发布了 Tajik Web Corpus（11 亿字符、31 万文档），并系统对比 17 种配置下的 LLM 微调方案：覆盖自回归、encoder-decoder、encoder-only 三类模型，全量微调、LoRA、QLoRA（rank=8/16）三种策略。最优结果由 Mistral 7B + QLoRA(r=16) 取得，困惑度 5.03 ± 0.03；将 rank 从 8 提到 16 收益不显著但显存翻倍；GPT-2 等小模型反而是全量微调最优。论文同时记录峰值 GPU 内存与训练时长。

INSIGHT工程价值在于算力收益权衡的清晰证据：rank=16 vs 8 性能差异统计上不显著，搜推团队做领域微调时不必盲目堆 rank。论文也明确小模型适合 full FT、中模型适合 QLoRA 的经验法则——这与社区搜索常用的 query rewriter / reranker 模型规模（0.5B~7B）刚好对齐，可直接套用其训练栈选型表。Cyrillic 低资源语料的处理思路也对国内多方言、多脚本 UGC 场景有参考价值。

Mullosharaf K. Arabov

Benchmarking Document Parsers on Mathematical Formula Extraction from PDFs

IIMLA Offenburg

针对 LLM 训练语料中数学公式 PDF 解析这个长期未解的环节，论文提出基于合成 PDF + LaTeX ground truth 的评测框架，并用 LLM-as-a-judge 评估语义等价性。30 名评估者在 250 个公式对上的人类研究显示，LLM 评判与人类一致性 Pearson r=0.78，远高于字符匹配 (CDM, r=0.34) 和文本相似度 (r≈0)。两阶段匹配 pipeline 可对接现有解析器（Nougat、MinerU 等）做端到端评测。

INSIGHT训练数据质量已成为基模团队的关键竞争力。论文揭示了科学文献解析的关键工程问题：解析器误差直接污染下游 RAG 与预训练，传统 BLEU/ROUGE 指标会低估这种污染。对国内做行业知识库（医疗、法律、专利）的 RAG 团队，这个评测框架可直接用于解析器选型；LLM-as-judge 的语义等价性思路也可迁移到 query 改写质量评测、UGC 文本归一化等场景。

Pius Horn, Janis Keuper

The TTS-STT Flywheel: Synthetic Entity-Dense Audio Closes the Indic ASR Gap Where Commercial and Open-Source Systems Fail

针对 Indic ASR 在数字、货币、地址、品牌名、英印混合等实体密集场景的失败模式（Whisper Indic SOTA EHR 仅 0.027，商用 Deepgram Nova-3 也只有 0.16），作者构建 TTS↔STT 飞轮：用开源 TTS 合成约 22000 条实体密集 Indic-English 混合语句（边际成本不到 50 美元），LoRA 微调 Whisper Telugu 后 EHR 提升至 0.473（17 倍于开源 SOTA、3 倍于商用），且通用 prose 上 WER 仅退化 +6.6 pp。

INSIGHT这是一种典型的合成数据飞轮加廉价 LoRA 打法：用现有 TTS 系统针对长尾 query 类型批量生成训练数据，闭环优化 ASR/NLU 弱项。社区搜索里的长尾 query（型号代码、品牌简写、新词组合）也有类似失败模式——可借鉴这套合成 query 加伪标签加 LoRA 微调的低成本飞轮，专项治理冷启动 query 改写或商品检索的实体覆盖率问题。

PatRe: A Full-Stage Office Action and Rebuttal Generation Benchmark for Patent Examination

DDLUTUNSWSSIAT

PatRe 是首个建模专利审查全流程（审查意见 + 申请人答辩）的多轮 LLM 评测基准，含 480 个真实案例并支持 oracle 与检索仿真两种评估模式。评测覆盖主流开源/商用 LLM，结果显示 closed-source 在 Office Action 生成上明显领先，但 retrieval-augmented 设置下 open-source 可显著缩小差距，多轮对话能力是分水岭。

INSIGHT对搜索/推荐工程团队的启示有二：一是 RAG 在专业领域知识密集任务上的杠杆效应——配置合适的检索模块可以让开源模型逼近闭源；二是多轮交互式 benchmark 的设计模式：把任务拆成 Office Action → Rebuttal → Final Decision 多阶段评估，比单轮 QA 更接近真实 production agent。社区搜索里的多轮 query 改写、检索、重排链路评测也可用类似多阶段 oracle/retrieval 双视图设计。

Chat2Trade: Automating Financial RFQ Parsing with Fine-Tuned LLMs

IICT-CAS

KDD 2026 Applied Track 工作。Chat2Trade 是一个针对金融 RFQ（Request-for-Quote）非结构化询价文本的解析系统：将自由文本中的标的、数量、价格、有效期等关键字段抽取为结构化交易意图，并在产线上落地。论文展示了从指令调优（SFT + LoRA）、领域 schema 注入、到错误回退策略的完整工程方案，强调微调 LLM 在严格 schema 解析任务上的可控性优于纯 prompt 工程。

INSIGHTChat2Trade 是把 LLM 当作结构化抽取引擎的典型工业实践，对社区搜索的 query understanding 模块有直接借鉴：把短文本 query 解析为 (intent, entity, modifier, time, location) 等结构化字段时，类似的 SFT 加 schema-constrained decoding 比 zero-shot prompt 鲁棒得多。论文给出的金融词典加噪声 RFQ 加拒识回退三段式工程化策略也可平移到 UGC query 解析。

Yixuan Cao, Chunhao Yang, Yifan Wang, Jian Wang, Kun Wan

S^2tory: Story Spine Distillation for Movie Script Summarization

IIIE-CAS

针对电影剧本非线性、多线程叙事难以用 saliency-based 方法摘要的问题，提出 S²tory 框架：先由 Narrative Expert Agent (NEAgent) 在叙事学约束下推理出 plot nuclei（推动情节的核心事件）与 satellite events（仅烘托氛围的次要事件），再把 NEAgent 的推理蒸馏给小模型，由小模型基于 plot nuclei 生成摘要。MovieSum 上达到 SOTA 语义保真度（约 3.5x 压缩比），BookSum 零样本评估也表现强劲。

INSIGHTS²tory 是 Agent-as-Teacher 蒸馏范式的又一例：用大模型加领域理论做思维链推理生成训练信号，蒸馏到可在线部署的小模型，从而把推理成本压回低水位。对社区搜索的启示：长帖子摘要、多模态笔记摘要等高成本场景，可借鉴专家 Agent 到结构化中间表征再到小模型生成的两段式架构，把 LLM 推理预算从在线推到离线训练阶段。

Mingzhe Lu, Yanbing Liu, Qihao Wang, Jiarui Zhang, Jiayue Wu, Yue Hu, Yunpeng Li, Yangyan Xu

A Comprehensive Analysis of Tokenization and Self-Supervised Learning in End-to-End Automatic Speech Recognition applied on French Language

LLIA AvignonLLIUM Le Mans

本文系统比较了端到端 ASR 在法语上的子词分词算法（BPE、Unigram、SentencePiece 变体）与多种 SSL 表征模型（wav2vec2、HuBERT、WavLM 等）的组合，并跳出 WER/CER 单一指标，引入语言学（形态学、句法）与声学（噪声鲁棒性）多维评测。结论：分词粒度对长尾词与命名实体识别影响最大，SSL 模型对噪声鲁棒性差异显著。

INSIGHT对搜索系统的启示在于评估维度的扩展思路：单一离线指标（WER/CER 或 nDCG）会掩盖真实业务问题。论文用语言学维度（形态、句法、命名实体）拆解错误，与社区搜索按 query 类型/intent/长度分桶分析 nDCG 的做法异曲同工。子词分词算法的选型经验也对中文 query embedding 模型的训练有参考意义。

Thibault Bañeras-Roux, Mickael Rouvier, Jane Wottawa, Richard Dufour

coTherapist: A Behavior-Aligned Small Language Model Framework to Support Mental Healthcare Experts

IIT Delhi

WWW 2026 录用工作。coTherapist 提出面向心理治疗辅助场景的小模型对齐框架：先用治疗师标注的行为轨迹（共情、引导、风险识别等）做行为监督，再以小模型蒸馏加 RLHF 双阶段训练，目标是用 7B 量级模型在敏感对话上对齐专业行为规范，同时控制部署成本与隐私合规。框架强调可解释的行为信号而非端到端 RL 黑盒。

INSIGHT对生产系统的启示：当业务场景对模型行为有强约束（合规、安全、专业性）时，行为轨迹监督加小模型蒸馏比堆参数更高效。社区搜索/推荐里的反低俗、反诱导、反诱标等内容安全模块可借鉴这种行为信号化的对齐方法，把不可观测的专家直觉显式化为可监督信号，让 7B 量级模型在合规场景对齐 LLM 大模型的判断质量。

Prottay Kumar Adhikary, Reena Rawat, Tanmoy Chakraborty
