1. Frozen LVLMs for Micro-Video Recommendation: A Systematic Study of Feature Extraction and Fusion
3.70
Relevance 3 | Novelty 4 | Practical 4 | Evidence 4 | Timely 4

Summary: 本文系统研究了如何把冻结的大型视觉-语言模型 (LVLM) 接入微视频推荐链路，对比两条核心设计轴：（1）整合策略——用 LVLM 表征替换 ID embedding 还是与之融合；（2）特征抽取范式——LVLM 生成的字幕文本表征 vs. 解码器中间隐藏态。结论：中间隐藏态显著优于字幕表征（字幕在压缩时丢失了细粒度视觉信号），ID embedding 仍贡献关键协同信号，因此融合严格优于替换；不同层的有效性差异显著。作者据此提出一个轻量插件式 Dual Feature Fusion 框架，自适应组合多层冻结 LVLM 表征与 item ID embedding，在两个微视频推荐基准上取得 SOTA。

Key insight: 对所有想接入 LVLM 多模态特征的搜推团队，这项工作给出了三条可直接抄作业的工程结论：用解码器中间层隐藏态而不是 caption（避免文本压缩损失）；做 fusion 而不是 replace（不要丢掉 ID 协同信号）；不同任务最优层不同，必须做 layer-wise 消融。社区 UGC 搜索同样需要把视觉/视频信号融入排序，可直接借鉴该 Dual Feature Fusion 的层选择 + 自适应门控融合范式，避免重新走一遍'caption 全替换'的弯路。

2. Federated User Behavior Modeling for Privacy-Preserving LLM Recommendation
3.35
Relevance 3 | Novelty 4 | Practical 3 | Evidence 3 | Timely 4

Summary: 针对跨域推荐中的隐私痛点（用户行为数据稀疏且不能跨域传输），论文提出 SF-UBM：以自然语言为跨域桥梁，将 item 文本表征加密后联邦共享，用户行为数据始终留在本地；用 Fact-counter 知识蒸馏模块融合域无关与域特定知识；并通过软提示空间对齐用户偏好与跨域 item 表征，让 LLM 能在不接触原始用户数据的前提下完成跨域推荐学习。在三对真实跨域数据集上一致优于近期 SOTA 隐私保护跨域方法。

Key insight: 这套'文本作桥+联邦item表征+软提示对齐'三段论给国内业务一个低改造成本的隐私推荐范式：跨业务线推荐时不必上送原始行为，只需把 item 的文本/语义表征加密同步即可。社区搜索若涉及多 App / 多内容池协同（例如旅行+笔记+电商），可借此范式做'冷启用户的跨场景偏好迁移'，并用软提示让 LLM 排序器吃到目标域的 item embedding，避开数据合规红线。

3. WPGRec: Wavelet Packet Guided Graph Enhanced Sequential Recommendation
3.45
Relevance 3 | Novelty 4 | Practical 3 | Evidence 4 | Timely 4

Summary: WPGRec 针对图神经+序列推荐的两个核心失败模式——局部模式和长程依赖纠缠、时间尺度错位——引入小波包变换：用 full-tree undecimated stationary wavelet packet transform 把行为序列分解为等长、平移不变的多尺度子带；在每个尺度上做匹配尺度的图传播；最后用基于子带能量与谱平坦度的门控融合模块自适应组合各子带并抑制噪声。SIGIR 2026 录用，在 4 个公开基准上一致优于序列与图基线，在稀疏数据集与复杂行为模式上提升幅度更大。

Key insight: 把信号处理里的小波多分辨率分解搬到序列+图推荐上，是一种'多尺度对齐'的新角度——长短期偏好不再需要靠超参或固定窗口拆分，而是由频带自然分离。社区 UGC 搜索的用户行为同样存在'秒级浏览 vs 周级兴趣演化'的尺度差异，这套频域+尺度匹配传播的方法可直接迁移到点击/收藏序列建模，特别适合行为稀疏、长尾用户多的场景。

4. LambdaRankIC: Directly Optimizing Rank IC for Financial Prediction
3.50
Relevance 2 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 金融预测领域的事实标准评估指标是 Rank IC（信息系数排序相关性），但模型却普遍用 MSE 或 NDCG-style ranking loss 训练，存在训练-评测目标错配。LambdaRankIC 推导了 pairwise rank-swap 在 Rank IC 上界下产生的封闭形式 lambda 梯度，并把它做成 XGBoost 的自定义目标函数，从而直接对生产指标做梯度优化。理论上可证它优化的是 Rank IC 的上界；模拟实验显示低信噪比下能精确恢复真实排序；在真实市场数据上 Rank IC、ICIR、月度收益与 Sharpe 都全面超越回归与 NDCG-style 基线。

Key insight: 本文给所有'排序模型评测指标 ≠ 训练指标'场景一个清晰范式：直接对线上指标推导 lambda 梯度并嵌入 GBDT 即可，几乎零改造成本。社区 UGC 搜索同样存在 nDCG/CTR 与训练 loss 错配的问题，可借鉴这种'闭式 pairwise lambda + XGBoost 自定义目标'套路做相关性精排——尤其在已经重度使用 GBDT 而短期不能上深度模型的链路里，性价比极高。

5. Ensembles at Any Cost? Accuracy-Energy Trade-offs in Recommender Systems
3.45
Relevance 3 | Novelty 3 | Practical 4 | Evidence 4 | Timely 4

Summary: 推荐系统的集成方法是否值得它消耗的算力？作者用 EMERS + 智能插座实测 93 组对照实验，覆盖 Surprise/RMSE 显式打分与 LensKit/NDCG@10 隐式排序两类框架，4 个数据集（ML-100K/1M、ModCloth、Anime），4 种集成策略（Average、Weighted、Stacking/Rank Fusion、Top Performers）。结论：集成带来 0.3–5.7% 的精度提升，但能耗膨胀 19%–2549%；ML-1M 上 Top Performers 提升 0.96% RMSE 仅多耗 18.8% 能耗；ML-100K 上 Average 提升 5.7% NDCG@10 却多耗 103% 能耗；Anime CO2 排放从 2.6 mg 升到 53.8 mg。Selective ensembles 在 Pareto 前沿全面碾压 exhaustive averaging。

Key insight: 推荐系统能耗审计是一个被严重低估的运维议题。本文给出一份可直接照抄的'是否要做 ensemble'决策矩阵：选 Top-Performers 类的稀疏 selective ensemble，避免全模型 averaging。社区搜索/推荐做精排集成时，该把指标从'NDCG@10 提升幅度'升级为'每瓦提升幅度'（NDCG/W）来选模型，尤其在 GPU 紧张或绿电指标考核的环境里，这个视角可能直接改变线上模型组合。

6. Aspect-Aware Content-Based Recommendations for Mathematical Research Papers
3.20
Relevance 3 | Novelty 3 | Practical 3 | Evidence 3 | Timely 5

Summary: 面向数学论文的内容推荐在过去主要被忽视，因为数学论文之间的相关性更多体现在共享证明技巧、逻辑推论、概念泛化等隐式关系上而非显式文本/引用相似度。作者构造了两个新数据集 GoldRiM（专家标注）与 SilverRiM（自动派生），并提出 AchGNN：一个 aspect-conditioned 异构 GNN，联合建模文本语义、引用结构、作者谱系，并按 aspect（如证明方法、应用领域）做条件传播。在 MaRDI 数学平台部署，且通过 Papers with Code 数据迁移到 ML 论文上同样有效，验证了 aspect-aware 范式的跨领域可迁移性。

Key insight: '相关性是多面而非单一'是这篇论文最值得借鉴的一点：实际推荐里同一对 item 在不同维度（兴趣、风格、地理、时序）下的相关程度并不一致，常规一维相似度损失了大量信号。社区 UGC 搜索可借鉴 aspect-aware GNN 把'话题相关''行文风格相关''作者圈相关'拆成多个条件分别建模，再在排序阶段融合，对小众话题或长尾用户的检索质量提升尤其有效；而其异构图 + 条件传播的方法学也可直接搬运。

7. Adaptive Long-term Embedding with Denoising and Augmentation for Recommendation
3.10
Relevance 3 | Novelty 3 | Practical 3 | Evidence 3 | Timely 4

Summary: ALDA4Rec 直击 GNN 序列推荐的两个老问题：交互图噪声和静态长期表征。先构造 item-item 图并用社区检测剔除虚假/弱关联边以降噪；短期偏好用 GCN 提取，长期偏好结合 averaging、GRU 与 attention 三路建模；最后用 MLP 自适应加权动态融合长短期信号，按 user/上下文动态调整长期偏好的权重。在 4 个真实数据集上一致优于 SOTA 基线，并在精度与鲁棒性指标上同时取得提升，代码开源。

Key insight: '社区检测过滤交互图 + 三路并行长期建模 + MLP 自适应加权'是一套对工程友好的轻量改造方案——不需要替换 backbone，只需在已有 GNN 序列推荐链路前加一层降噪 + 后加一个长期偏好融合头。社区 UGC 搜索里的 user-content 二部图天然有大量噪声边（误点、爬虫、刷单），照搬其社区检测过滤思路可直接降低召回与精排训练数据噪声；自适应加权则给冷启动新用户与重度活跃老用户提供同一套架构两套参数。

8. CPGRec+: A Balance-oriented Framework for Personalized Video Game Recommendations
3.10
Relevance 2 | Novelty 3 | Practical 3 | Evidence 3 | Timely 4

Summary: CPGRec+ 在游戏推荐场景沿两个方向扩展前作 CPGRec：（1）在 user-game 图上引入有符号边权，定性区分'强喜欢''强不喜欢'并量化偏好强度，弥补无符号 GNN 推荐器无法刻画 disinterest 的盲点；（2）用 LLM 生成上下文化的游戏与玩家描述，作为偏好推理的 prompt 注入，缓解多层 GNN 的过平滑问题。在 Steam 数据集上同时改善准确率与多样性，相对原 CPGRec 与其他 GNN 基线均有提升。

Key insight: 把'不喜欢/负反馈'从隐式信号升级为图上的负权边、再用 LLM 把 item/user 自然语言上下文喂回 GNN，这两个手段独立且都可直接迁移。社区搜索 UGC 数据里负反馈 (划走、踩、不感兴趣) 通常被简单当作负采样目标处理，但有符号图权重能捕捉强度差异；LLM 上下文化描述也可作为低成本特征注入排序模型，缓解纯 ID 嵌入在长尾物品上的语义缺失。
