FinSAgent: Corpus-Aligned Multi-Agent RAG Framework for Evidence-Grounded SEC Filing Question Answering

SimpleWay.AIMcGillUniversity of TorontoMila

FinSAgent 针对 SEC 长文档中模型先验与语料结构错位的问题，用 10-K 条目角色 Agent、数据库感知查询分解和多路径检索共同约束搜索。学习式特征门控重排器把证据有效性与语义相似度分开；方法在 5 个离线金融问答基准上提升覆盖与正确率，并完成含 1,000 个匿名评分的三臂在线实验。

INSIGHT核心启示是让查询规划器先读取目标语料的轻量摘要与结构，再生成子查询，能减少通用 LLM 对领域术语和证据位置的误判。社区 UGC 搜索可把版块、内容类型、时间和作者关系作为 corpus-side conditioning，并在重排阶段显式建模“能否支持答案”，而不只优化文本相似度。

DRNOISE: Benchmarking Deep Research Agents in Misleading Evidence Environments

DRNOISE 构造 100 个深度研究任务，每题由两条相互印证的间接记录链支持唯一答案，并在噪声条件中加入一篇给出冲突答案的可信外观文档。该单点干预让原本表现强的 Agent 准确率骤降 66–88 个百分点；轨迹分析显示主要故障是提前停止核验、转而相信更像答案的直接陈述。

INSIGHT检索到真证据不等于完成可靠研究，Agent 还必须主动闭合并核对证据链。社区搜索中的热点帖、搬运摘要和过时内容同样会形成“答案捷径”，可把双来源交叉验证、时间一致性检查和冲突证据触发再检索设为硬状态机条件，而不是仅追加一句泛化核验提示。

RIMS: Preference Optimization via Smoothed Multi-pair Aggregation for Small-Scale LLM Retrieval-Augmented Generation

RIMS 面向易受噪声证据干扰的小模型 RAG，先由目标模型通过拒绝采样合成思维链偏好数据，再用可微平滑算子聚合全部偏好对，替代只保留最难样本的硬选择。理论分析给出可控近似误差，4 个多跳问答基准上的多种小模型均在噪声检索条件下稳定提升 EM 与 F1，代码已开放。

INSIGHT方法的价值在于用全部偏好对保留排序梯度，同时仍强调高判别力样本，适合数据有限、无法依赖闭源教师的业务。对社区搜索 Agent，可从点击、跳过、纠错和证据采纳轨迹构造多对偏好，在轻量模型上联合优化“答案质量与抗噪性”，降低线上调用大模型的成本。

MagicSelector: Joint Optimization for Agent Tool Selection via Counterfactual Decomposition and Progressive Reranking

HONOR

MagicSelector 将含糊指令分解为原子任务，再通过自蒸馏难负例驱动的渐进式重排筛选工具，并以重排分数断崖和工具间语义突变动态决定 Top-K。团队同时构建带过程标注的移动端多轮 MTDTool 基准；实验显示其在工具检索准确率、域外泛化和 token 效率上均优于现有方法。

INSIGHT工具选择可被视为“查询分解加多阶段排序”问题，搜索团队已有的难负例挖掘、点式与列表式联合学习经验可以直接迁移。动态 Top-K 尤其适合工具库持续增长的 Agent：依据置信度边界截断候选，既保留相关工具召回，又避免把长尾噪声塞入上下文造成误调用。

Real-World Evaluation of an AI Agent Drafting Translational Impact Summaries

研究把带来源证据的资料搜集 Agent 接入一个 CTSA 机构的真实影响报告流程，对 10 名学者、507 条发现进行双人审核。两位审核者共同认为 81.7% 的发现可直接接受或编辑后使用；每名学者的中位审核时间降至 14 分钟，对比原人工汇集约 15 小时，综合准确性和实用性分别获 4.5 与 4.8 分。

INSIGHT这项实证说明深度检索 Agent 更适合作为“有出处的初稿作者”，由人负责终审，而非直接替代专业判断。社区搜索可采用同一交付边界：Agent 汇集跨帖证据、标注来源并生成候选结论，同时保留逐条接受、编辑、拒绝反馈，既控制风险又形成后续排序和提示优化数据。

From Memory to Skills: Evidence-Grounded Co-Evolution Governance for Long-Horizon LLM Agents

MSCE 是无需训练的记忆—技能共演化框架，把长程 Agent 经历组织为有依据的步骤轨迹、可复用程序策略和环境认知。它仅将预估收益为正的二级策略固化为可调用技能，并保留适用边界、验证规则和可靠度；在 EvoAgentBench 与 LoCoMo 上优于技能增强和记忆驱动基线。

INSIGHT长期记忆不应只是相似轨迹拼接，而应经过收益评估、证据回链和边界声明后晋升为技能。搜索 Agent 可把成功的查询改写、站点选择、证据核验流程固化为可版本化策略，并用局部反思回填稀疏终局反馈；这样既能复用经验，也能在分布变化时追溯并撤销失效技能。

NVIDIA Vera CPU: Olympus Cores Built for Maximum Single-Thread Performance in Agentic AI

NVIDIA

NVIDIA 从 Agent 沙箱、工具调用、检索和数据库交互的分支密集型负载出发，解析 Vera CPU 的 Olympus 核心、空间多线程及统一互连设计。平台提供最高 3.4 TB/s 片上互连、164 MB 统一 L3，以及 1.2 TB/s 总内存带宽和单核最高 14 GB/s，目标是在高并发下维持可预测的单线程进度。

INSIGHTAgent 延迟常由 CPU 侧编排、脚本解释、沙箱和不规则数据访问决定，单看 GPU token 吞吐会漏掉关键瓶颈。部署深度搜索时应分解每轮的模型推理、工具等待、检索处理和状态搬运耗时，并重点观察满载下的单线程与尾延迟；硬件指标来自厂商内部测试，仍需业务压测复核。

WorldCupArena: Fine-Grained Evaluation of Language Models and Deep-Research Agents on Football Forecasting

WorldCupArena 用赛前动态信息评估深度研究 Agent，要求预测胜负、精确比分、球员事件和比赛统计，赛后再与真实结果比对。首轮覆盖世界杯 104 场比赛和 13 个系统；结果显示胜负准确率相近的模型在细粒度预测上差异更明显，最佳系统相对博彩市场与球迷基线只取得小幅胜负收益，但 Scoreline 优势更清晰。

INSIGHT动态、未来不可知的任务能有效抑制训练集泄漏，比静态问答更接近真实搜索产品。社区搜索 Agent 的评测也可建立滚动事件集，在结果发生前冻结检索证据和预测，再按事实、细节与置信度分层计分；这样能区分“碰巧答对”与真正完成高质量检索推理的系统。

Bayesian Uncertainty Propagation for Agentic RAG Pipelines: A Proof-of-Concept Study on Multi-Hop Question Answering

论文让规划器、评估器与生成器分别产生基于语义分歧和自评的不确定性信号，再通过贝叶斯网络传播为系统级风险与节点级故障指示。作者在 StrategyQA、HotpotQA 上测试 GPT-3.5-Turbo 与 GPT-4.1-Nano，并以 AUROC、AUARC、ECE 和 Brier Score 衡量判别、拒答与校准；多跳 HotpotQA 收益更明显。

INSIGHTAgentic RAG 的置信度不应只取最终模型的一次自评，而应沿规划、检索评估和生成节点逐层累积。业务上可将高不确定节点映射为重写查询、增加证据或转人工，但该研究仍是概念验证，且 StrategyQA 暴露上游信号失准问题，落地前必须按业务查询类型重新校准阈值。

Louis Donaldson, Connor Walker, Koorosh Aslansefat, Yiannis Papadopoulos
