1. Agent Against Agent: An Agentic System for Automatic Prompt Injection Red Teaming
4.30
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 针对工具调用型 LLM Agent 容易遭受提示注入的问题，PIMiner 让攻击智能体在多个数据集—目标模型组合上逐步建立可迁移的策略库，测试时无需重新训练。它每个样本只需约 10 次目标 Agent 查询，在 IPIArena 上对 Gemini-2.5-Pro 的攻击成功率为 76.2%，对 GPT-5.1 为 61.9%。

Key insight: 这项工作把 Agent 安全评测从一次性生成攻击升级为可复用的策略检索与迁移，适合接入搜索 Agent 上线前的红队流水线。对社区 UGC 搜索而言，应将检索工具、网页内容和用户输入放进同一威胁模型，并用跨模型、低查询预算的攻击集持续回归，而不是只测单一模型的静态样例。

2. Eliciting Intrinsic Hallucinations in LLMs via Semantically Equivalent Adversarial Attacks
3.93
Relevance 4 | Novelty 4 | Practical 3 | Evidence 4 | Timely 5

Summary: 论文研究 RAG 已提供证据时仍会出现的 intrinsic hallucination，提出保持语义等价的自然语言对抗变体生成框架，在白盒、灰盒和黑盒设置下压力测试模型。实验覆盖 5 个开源模型、5 个闭源模型和 3 个数据集，重点检验检索证据存在时答案是否仍然忠实。

6. FocusMem: Factorizing Content, Readout, and Trust in Latent GUI Memory
3.78
Relevance 3 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: FocusMem 解决 GUI Agent 将多模态轨迹压成一个固定记忆块后，细节丢失、不同决策阶段共用同一表示以及无关记忆误导动作的问题。方法把潜在记忆拆成角色感知的内容基、状态条件化 readout 和轻量 trust gate，分别服务可复用经验、当前进度和相关性抑制。

7. When Memory Lies: An Empirical Study of Spatial Memory Staleness in VLM Agents
3.73
Relevance 3 | Novelty 3 | Practical 4 | Evidence 5 | Timely 5

Summary: 论文在动态 FrozenLake 环境中研究 VLM Agent 如何识别已经过期的空间记忆，并把检测结果与后续导航联系起来。实验覆盖 3 个闭源模型、3 个开源 VLM，完成 1,800 次检测和 12,000 个文本导航回合；相同网格上视觉 F1 从 0.887 到 0.067，说明文本上能识别冲突并不代表真正完成视觉 grounding。

Key insight: Agentic 搜索的缓存、用户画像和历史摘要同样会过期，且过期内容往往比缺失内容更危险。建议为记忆附带时间、来源和冲突检测信号，在 query 命中旧内容时触发轻量复检或重新检索，并把“是否审计记忆”作为离线指标，避免 Agent 以高置信度复述陈旧 UGC。

10. ToolArtist: Tool-Using Unified Multimodal Models for Agentic Image Generation
3.53
Relevance 3 | Novelty 4 | Practical 3 | Evidence 3 | Timely 5

Summary: ToolArtist 面向需要外部知识和多步推理的开放世界图像生成，将搜索工具、推理和原生图像生成统一到一个多模态模型策略中。训练时先让教师 Agent 同时调用搜索与图像生成工具，再把轨迹转换为统一模型可学习的格式，使模型能够动态决定何时检索、何时生成，而不是执行固定工作流。
