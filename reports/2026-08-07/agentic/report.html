Eliciting Intrinsic Hallucinations in LLMs via Semantically Equivalent Adversarial Attacks

论文研究 RAG 已提供证据时仍会出现的 intrinsic hallucination，提出保持语义等价的自然语言对抗变体生成框架，在白盒、灰盒和黑盒设置下压力测试模型。实验覆盖 5 个开源模型、5 个闭源模型和 3 个数据集，重点检验检索证据存在时答案是否仍然忠实。

INSIGHTAgentic 搜索的质量门槛不应只看召回率或最终答案准确率，还要测同一意图的不同表达是否诱发不受证据支持的生成。可以把语义等价改写加入离线评测，按 query 意图、检索证据和最终 claim 三层记录失败样本，再将高风险模式反馈给重排、拒答和工具路由策略。

FinReportBench: Measuring and Improving Institution-Grade Financial Report Generation

FinReportBench 面向机构级研究报告生成，先通过专家审查归纳报告身份、来源纪律、机构要素和视觉交付等缺口，再用 35 项细则构建评测框架。数据从 10,000 条中英文研究资料中整理出 244 个双语任务，并把公开问题、研究轨迹和隐藏来源包分离，检验 Agent 是否真正完成了可审计的深度研究。

INSIGHT对 Agentic 搜索，评测对象应从“回答像不像”扩展到检索轨迹、来源覆盖、引用可核验性和交付格式。社区搜索可借鉴其 hidden source packet 设计：给 Agent 真实可用的 UGC 集合，同时保留不可见的证据包与标准答案，分别评估找全、找准、引用和总结四个环节。

Hallucinations on the Board: Tool-Augmented Evaluation of LLM Chess Commentary

ACT-Eval 针对 LLM 生成的棋局解说，先把长文本拆成原子事实，再路由到棋力引擎和专家标注参考进行核验，同时评估事实正确性、概念覆盖和走法判断。作者发布包含 325 个局面—走法样本的基准，其中 125 个带专家核验的原子事实，并定义五类错误。

INSIGHT它提供了一个适合 Agentic RAG 的“声明级”验证范式：最终答案不是一个整体分数，而是多个可追溯 claim，每个 claim 都要绑定检索证据或确定性工具结果。社区搜索可以对帖子摘要、实体属性和比较结论分别验证，减少 Agent 把局部正确证据拼成整体错误结论的风险。

Google Search's I/O 2026 updates: AI agents and more

Google

Google 在 I/O 2026 的 Search 更新中，将 AI Mode 与更强的 Agent 能力结合，并探索直接在搜索框内构建可交互的定制体验。产品方向从一次查询返回结果，转向理解复杂意图、调用能力并协助用户完成多步骤任务；这是大规模搜索产品对 Agentic Search 的明确工程信号。

INSIGHT对 UGC 搜索，Agent 不必替换传统召回和排序，而应作为复杂意图的上层编排器：先判断是直接检索、改写 query，还是需要多轮收集与比较，再把稳定的 nDCG、CTR 与任务完成率一起纳入评估。Google 的产品路线也提示，交互式结果和可控动作会成为搜索体验的一部分。

FocusMem: Factorizing Content, Readout, and Trust in Latent GUI Memory

FocusMem 解决 GUI Agent 将多模态轨迹压成一个固定记忆块后，细节丢失、不同决策阶段共用同一表示以及无关记忆误导动作的问题。方法把潜在记忆拆成角色感知的内容基、状态条件化 readout 和轻量 trust gate，分别服务可复用经验、当前进度和相关性抑制。

INSIGHT对搜索 Agent 的长期会话记忆，应把“记住什么”“当前要读什么”和“是否可信”分开建模。社区场景可以将用户历史 query、已看帖子和未完成任务存为 episodic/working memory，再由当前 query 生成不同读出视图，并在内容更新或冲突时通过 trust gate 降权，而不是把所有历史文本直接拼进上下文。

Zhuoran Zhang, Bowen Li, Jingcheng Ju, Yang Shi, Qixun Wang

When Memory Lies: An Empirical Study of Spatial Memory Staleness in VLM Agents

论文在动态 FrozenLake 环境中研究 VLM Agent 如何识别已经过期的空间记忆，并把检测结果与后续导航联系起来。实验覆盖 3 个闭源模型、3 个开源 VLM，完成 1,800 次检测和 12,000 个文本导航回合；相同网格上视觉 F1 从 0.887 到 0.067，说明文本上能识别冲突并不代表真正完成视觉 grounding。

INSIGHTAgentic 搜索的缓存、用户画像和历史摘要同样会过期，且过期内容往往比缺失内容更危险。建议为记忆附带时间、来源和冲突检测信号，在 query 命中旧内容时触发轻量复检或重新检索，并把“是否审计记忆”作为离线指标，避免 Agent 以高置信度复述陈旧 UGC。

Yushi Sun, Yanjie Zhang

Characterizing the Evolving Landscape of Modern Information Seeking

这项博士研究考察生成式 AI 出现后信息寻求过程的变化：界面更多、交互更复杂、系统能力更强。研究结合在线众包调查实验、信息寻求理论框架和实验室神经生理信号实验，分析用户对现代搜索界面的偏好以及完成信息寻求时的认知负担，并为个性化、认知感知的系统设计提供依据。

INSIGHTAgentic Search 不应只追求多走几轮工具调用，还要控制用户的理解成本。对社区搜索可以将任务拆解过程以可折叠的 query、证据和下一步建议呈现，分别测量点击、改写、返回和任务完成；当复杂流程没有带来更好的决策时，应回退到熟悉的列表检索体验。

WorldCycle: Self-Verifiable Reinforcement Learning for Long-Horizon Video World Models

WorldCycle 针对长时程世界模型缺少未来状态标注、难以验证累积误差的问题，利用可逆动作循环构造无标注监督：动作序列与逆序动作组合后应回到初始状态。训练同时优化空间闭合奖励和重复执行的时间一致性奖励，为强化学习 Agent 提供可自检的长期规划信号。

INSIGHT搜索 Agent 也需要对多步计划提供中间可验证信号，而不是只在最终答案处给奖励。可以把“检索—阅读—引用”设计成可回放闭环，例如重新执行同一子任务时应找回相同证据、引用能还原到原文；这类一致性奖励有助于降低长链路 Agent 的漂移和无效工具调用。

Bohai Gu, Yueyang Yuan, Taiyi Wu, Dazhao Du, Jian Liu

ToolArtist: Tool-Using Unified Multimodal Models for Agentic Image Generation

ToolArtist 面向需要外部知识和多步推理的开放世界图像生成，将搜索工具、推理和原生图像生成统一到一个多模态模型策略中。训练时先让教师 Agent 同时调用搜索与图像生成工具，再把轨迹转换为统一模型可学习的格式，使模型能够动态决定何时检索、何时生成，而不是执行固定工作流。

INSIGHT其可迁移的设计是把工具调用轨迹转成模型训练数据，并让工具选择与最终任务目标共同优化。对搜索 Agent，可记录 query 改写、召回、重排、阅读和引用的完整轨迹，训练一个能按意图动态路由的策略；但仍应保留确定性检索和权限控制，避免把所有决策都交给生成模型。

Jiahao Zhao, Xiaomin Yu, Zhongxiang Sun, Fengwei Teng, Chengwei Qin
