Skills Know Their Neighbors: Cluster-Contrastive Capability Pages for Skill Retrieval

论文把技能文档造成的检索误差显式化：文档往往只描述“能做什么”，却没有说明哪些相似请求不该路由到该技能。方法用离线编译器为每个技能生成正向触发、负向边界和判别正文，分别服务召回与拒绝。在包含26,262个技能、5,400个问题的SRA-Bench上，5种检索器的Recall@10平均提升2.94个百分点，端到端任务成功率平均提升3.62个百分点。

EdgeLM: Edge Demonstrations for Language Models' Table Understanding

EdgeLM指出，示例检索若只按查询相似度选上下文，容易重复模型已有判断，难以暴露真正的决策边界。它同时检索两类边界证据：近邻但标签不同的数据边界，以及相似却被部署模型误判的模型边界，无需重训或任务特化。在5类数据整理任务、15个数据集和5种开源/闭源大模型上，各设置均达到最佳或接近最佳表现。

INSIGHT短文本搜索的难例评测也应主动检索“可区分的反例”，而不只是最相似样本。可以在离线日志中维护相似但相关性标签相反、以及线上模型误判的两类样本池，用于重排训练、标注审核和Bad Case解释；两个边界信号互补，改造成本低。

Soroush Omidvartehrani, Mohammadamin Habibollah, Mohammadreza Daviran, Davood Rafiei

LLM-confidence reranker: A training-free approach for enhancing retrieval-augmented generation systems

这项工作提出无需训练的LLM置信度重排器：先由BM25或Contriever获取候选，再用轻量级7–9B大模型的置信信号重新排序，不需要额外标注或微调。作者在BEIR和TREC上同时测试两类初始检索器，报告NDCG@5持续提升，最高相对增益达20.6%，且没有观察到性能退化。

INSIGHT当团队暂时没有高质量点击标注时，置信度重排提供了可插拔的相关性增强路径，但线上成本必须单独核算。建议只对Top-50以内候选调用小模型，并用nDCG、零结果率、CTR和P95延迟分层验证；它适合做离线收益探针，不应直接替代稳定的监督重排模型。

Neighborhood-Aware Dual Biomedical Entity Linking

PILOT面向大规模生物医学实体链接，将检索误差拆成邻域感知召回、表面形式与上下文双视角重排、分数融合三阶段。模型同时利用查询侧和知识库侧的本体邻域信息，避免同名实体只靠字面相似度竞争；论文在5个常用基准上取得平均最佳结果。其结构对社区帖子、实体别名和短查询的语义匹配具有直接迁移价值。

INSIGHTUGC搜索中的品牌、地点和人名消歧可以借鉴“双视角+结构邻域”设计：召回阶段扩展实体关系，重排阶段分别看表面词形与上下文，再做可解释融合。这样能把“字面命中但意图错误”和“语义相关但实体错位”分开处理，降低单一向量相似度的误召。

Yicheng Tao, Jie Liu

Right Reset: Chunking by Prefix Removal

Right Reset用因果语言模型移除左侧上下文时的隐藏状态保持程度来识别文本边界，再用动态规划生成可变长度切块。对删除分隔符和版式、拼接主题相近记录后的扁平文本，它恢复出47.7%的原始记录完整单元，高于BGE边界基线的25.9%；收益在渲染和OCR后仍保留，并在6个语言模型上复现。

INSIGHT社区帖子和评论切块不应只按固定长度或向量相似度切分。可把“右侧内容是否因左上下文移除而改变”作为无标注边界信号，优先保护主题完整的短文本单元，再送入embedding和重排；它尤其适合版式丢失、串流拼接和OCR噪声较大的内容库。

Mike Vegeto

Caching for the Future: Scrub Jay Episodic Memory Principles for Agent Memory Systems

ScrubJay-MEM针对长期Agent记忆被过期事实污染的问题，为每条记忆估计与类型相关的衰减系数和有效时间窗，并以What–Where–When元组和查询自适应打分完成检索、回溯修订。TGT上它是唯一取得明显正GenGap（+0.108）的检索系统；在MemoryAgentBench EventQA-64k上，F1比Mem0高2.66、比Qwen3-Embedding-4B高3.09，去掉衰减后GenGap缩小5.7倍。

INSIGHT社区搜索同样需要区分“长期知识”和“时效帖子”，不能让统一的向量相似度决定所有内容的排序。可把发布时间、事件结束时间和内容类型作为可学习的衰减特征，在召回后做时间感知重排；但对事实固化类任务收益会反转，应保留任务路由和新鲜度护栏。

Kartikey Singh Bhandari, Aarya Wadhwani, Dhruv Kumar, Pratik Narang

UniHEAR: Unified Heterogeneous-Source Attentive Retrieval for Knowledge-Based Visual Question Answering

UniHEAR解决知识型视觉问答中的单一来源召回和忽略来源先验的重排问题。它为候选实体构造粗粒度检索描述符，用检索引导的注意力门控动态分配不同来源权重，再通过熵加权融合先验，并以对比学习和模态保持损失联合训练。在E-VQA与InfoSeek上，Recall@1较最强基线分别提升6.7和1.2个百分点，同时保持轻量重排结构。

INSIGHT多路召回不应简单拼接或固定加权；候选来自哪一路、该路的置信度和来源熵都应进入重排特征。对社区搜索可将标题、正文、评论、标签和知识图谱看作异构来源，先保留互补候选，再用来源感知门控减少某一路的重复覆盖，兼顾召回率与Top-K多样性。

Ganzhong Luo, Yang Ren, Hanyong Wang, Shuyu Zheng, Menglong Yang

GigitAI at SemEval-2026 Task 8: Hybrid Sparse-Dense Retrieval and ...

GigitAI在SemEval-2026 Task 8中搭建混合稀疏—稠密检索系统，联合比较查询处理、稀疏检索、向量检索和神经重排对最终结果的影响。它把关键词精确匹配与语义近似匹配放在同一流水线中，再通过重排处理候选间的细粒度相关性，适合检验不同查询类型下的召回互补性。

INSIGHT对短文本UGC搜索，混合召回仍是最稳妥的工程基线：实体词、数字和新词依靠稀疏通道，改写和语义表达依靠稠密通道，重排只处理合并后的有限候选。上线前应按Query长度、实体密度和新鲜词比例切分评测，避免一个全局权重掩盖不同意图的失败。

A Theoretical Framework for Risk Analysis of Stochastic Rankers

论文研究为公平曝光或多样性而随机采样排序时的“重排风险”，把风险定义为固定召回列表经随机置换后DCG可能产生的最大绝对变化。理论表明，风险主要由初始列表中相关文档的召回位置分布决定；在TREC Fairness 2022的随机重排提交结果上，理论预测与实际DCG变化接近。

INSIGHT如果搜索系统用随机探索、去重或公平约束改变Top-K，离线平均nDCG不足以描述线上波动。可以先统计候选池中相关结果的首个命中位置和位置分布，再估计重排风险，并将风险上限作为实验护栏；这有助于在CTR探索与相关性稳定之间做可量化权衡。

Debasis Ganguly

How Google Search helps you find original, high-quality content

Google

Google Search团队介绍近期搜索更新及其识别原创、高质量内容的方向，强调结果质量不仅取决于表面关键词匹配，还要结合内容原创性、用户需求满足度和页面整体质量。该条目没有公开统一的离线或线上指标，因此更适合作为工业实践背景，而不是可直接复现实验的论文。

INSIGHT社区搜索可把“原创性、内容完整度和需求满足”拆成可观测的重排特征，避免只用文本相似度把重复搬运内容推到前列。工程上应将质量信号与相关性分层评测，并监控新内容冷启动、作者生态和用户点击的长期反馈，防止短期CTR优化损害内容供给。
