Curated retrieval versus open web search in public AI information services: a coverage-trust trade-off

论文比较公共 AI 信息服务中的 curated RAG 与 open web search。研究在冰岛 2026 年 8 月 29 日欧盟入盟公投前，对 University of Iceland 运营的 Evrópuvefur 做预发布专家评估：5 名领域专家评价 449 个 AI 答案，共 551 次评分，并单独标记引用来源；开放 Web 搜索答案中 35%（65/187）至少有一个引用源被标记为不可信。

KEY INSIGHT · 对业务意味着什么这给搜索产品一个很直接的取舍：开放 Web 搜索覆盖更广，但引用可信度会显著拖累用户信任；curated RAG 覆盖受限却更容易治理。对社区搜索，可以用“可信内容池 + 必要时开放补搜”的双通道策略，并把来源可信度、引用风险和覆盖缺口作为排序/生成特征，而不是只优化答案相关性。

02 4.30

A-RAG: Scaling Agentic Retrieval-Augmented Generation Through Hierarchical Retrieval Interfaces

这篇论文把检索接口显式暴露给模型，提出 A-RAG：模型可以在关键词搜索、语义搜索和 chunk read 三类层级工具之间自主选择，从而按问题难度调整检索粒度。它针对传统 RAG “一次召回后直接生成” 的限制，让模型参与检索决策，适合需要多轮查证、分层阅读和证据补全的复杂搜索任务。当前检索结果只提供方法框架与工具设计，实验细节需要后续阅读原文确认。

INSIGHT对社区搜索最有价值的是“检索动作成为模型可控工具”这一点：短文本 UGC 查询经常需要先粗召回、再读片段、再补查实体或上下文。把 keyword、semantic、chunk read 拆成可观测工具后，可以记录每一步检索轨迹，用于调试召回不足、上下文污染和过度阅读成本。

03 4.10

TRIAGE: Trustworthy Retrieval Instrumentation And Graph Evaluation

TRIAGE 面向自动构建知识图谱的 Graph-RAG，解决“最终答案错了但不知道错在哪一环”的评估问题。框架把评估拆到 KG 抽取、图构建/专家校验、查询推理三个阶段，并给出 triple confidence、source coverage、schema/canonicalization checks、结构质量、正确性与完整性等独立指标。它关注的不只是图是否可信，还包括查询成本和阶段级故障定位。

INSIGHTGraph-RAG 在搜索系统里常被用来补全实体、关系和证据链，但如果只看最终答案，线上问题很难回溯到抽取、归一化还是推理阶段。TRIAGE 的阶段化指标适合迁移到 UGC 搜索的实体图、话题图和证据图评估：先把召回证据覆盖率、schema 一致性、图结构质量做成可观测指标，再让生成层消费。

04 4.10

Candidate-Constrained Retrieval-Augmented Generation for LongEval-RAG: System Design and Empirical Analysis

这篇论文提交 LongEval-RAG 的 candidate-constrained RAG 系统：每个问题都有组织方给定候选集，所有证据和最终引用必须留在候选集内。系统组合了确定性 provenance tracking、passage retrieval、query expansion、PRF、RRF、轻量 reranking、citation prior、evidence aggregation 和可选 MiniLM 句级重排；10 个 pipeline 变体中，rule-minilm 在 BERTScore、retrieval precision、nugget coverage 等指标上最均衡。

INSIGHT它的工程价值在于把“可引用候选集约束”和检索链路绑定，避免 RAG 在开放搜索中引用不可控来源。社区搜索可以借鉴这种设计：先用权限、时间、作者、内容安全规则生成候选池，再在池内做查询扩展、RRF 和轻量重排，最后让生成式摘要只引用可追溯帖子或评论。

Yingdong Yang, Haijian Wu

05 4.10

Progressive Disclosure for LLM-Maintained Wiki Knowledge Bases: a Preregistered Ablation

论文对 LLM 维护的 709 页 Markdown wiki 做预注册消融，检验 progressive disclosure 是否比大索引更省成本：四个语料版本正文完全相同，只改变 agent 到达内容的方式，并交叉测试 protocol-constrained、free self-routing、catalog-preload 三种访问条件。作者用冻结 git tag 保证内容一致，再用跨模型评审对照 verified gold references。

INSIGHT结论方向对搜索 agent 很重要：省 token 的目录式访问并不天然等于更好，关键在 agent 是否真的按协议加载必要页面。对 UGC 搜索/问答知识库，不能只上线“目录+摘要”结构，还要记录 agent 的页面加载轨迹、遗漏证据和答案质量，否则 progressive disclosure 可能只是把召回问题隐藏到工具选择里。

A new era for AI Search

Google

Google Search 在 I/O 2026 宣布把高级模型能力引入搜索产品，强调新的 AI 搜索框和可以“通过提问使用 agents”的体验。该条不是论文，而是产品实践信号：主流搜索正在从一次性 query-result 页面，转向模型理解意图、拆解任务、调用搜索能力并辅助完成动作的交互形态。

INSIGHT对社区搜索团队，Google 的方向说明 agentic search 不只是后端 RAG，而会改变前台交互和指标体系：用户可能用自然语言给目标，系统需要规划多步检索、解释证据并持续追问。短文本 UGC 场景可以先从高意图 query、复杂消费决策、问答聚合页试点，而不是替换全部搜索结果页。

Improving Access to Historical Archives with Real-time RAG-based Systems

University of GenevaNUS

论文面向数字化历史档案检索，提出端到端 RAG 框架：先用 LLM 做 OCR refinement，再用语义检索 + cross-encoder reranking 支持自然语言问答。实验数据集包含 50 万段瑞士报纸片段，时间跨度 1762-2001 年，并在 384 个自然语言测试查询上评估；摘要显示 LLM refinement 能降低 OCR 错误并改善后续检索质量。

INSIGHT它对 UGC 搜索的启发是“内容清洗质量会直接影响召回和 RAG 答案”。社区短文本同样存在错别字、口语缩写、OCR/ASR 噪声和低质量标题，先做轻量纠错/规范化，再进入语义召回和 cross-encoder 重排，可能比直接堆更大 embedding 模型更稳。

Stergios Konstantinidis, Hayman Lotfy, Alexis Erne, Faruk Zahiragic, Min-Yen Kan, Michalis Vlachos

RAG 是什么？16 种 RAG 方案一次讲清！AI 应用开发必学

Tencent

Agentic and Generative AI for Open-Source Intelligence and Cyber Investigations: Taxonomy, Evaluation, Challenges, and Future Directions

这篇 survey 系统回顾 74 项关于 OSINT 与网络调查的 agentic/generative AI 研究，并把 agentic AI 作为独立分析类别，而不是 LLM prompt 的延伸。论文提出 11 类 taxonomy，覆盖 LLM 基座、agent 架构、RAG、知识图谱、prompt engineering、领域适配、评测基准和风险，并指出 hallucination-validation gap 是跨语料层面的共性问题。

INSIGHT虽然场景是 OSINT/安全调查，但方法论可迁移到复杂搜索：agentic 系统必须把检索、推理、验证和风险控制分开评估。社区搜索中的舆情、投诉、攻略、事实核查类 query 也存在同样问题，不能只看答案生成质量，还要设计证据验证和幻觉拦截指标。

GaP: A Graph-as-Policy Multi-Agent Self-Learning Harness For Variational Automation Tasks

GaP 面向机器人 Variational Automation，提出 Graph-as-Policy 多智能体自学习框架：由 multi-agent coding harness 从 Modular Open Robot Skill Library 生成包含 perception、planning、control 节点的有向计算图，再生成内部仿真环境并行演练不同图结构，迭代改进图结构和参数。论文关注的是开放变化任务中解释性程序化策略与 model-free policy 的可靠性差距。

INSIGHT它不是搜索论文，但对 agentic 系统工程有借鉴：把 agent 产物限制为可解释的计算图，而不是自由文本计划，可以让执行、回放和调参更可控。搜索 agent 也可采用类似图策略，把查询改写、召回、重排、阅读、验证、回答拆成节点，并用离线仿真/回放评估不同策略图。
