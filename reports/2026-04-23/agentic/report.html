1. Mango: Multi-Agent Web Navigation via Global-View Optimization
4.10
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 本文解决了现有 Web Agent 从根 URL 出发导致导航效率低下的问题，提出 Mango 多智能体网页导航框架。核心思路是将 URL 选择建模为多臂老虎机问题，利用 Thompson Sampling 自适应分配导航预算，并引入 episodic memory 从历史尝试中学习。在 WebVoyager 上达到 63.6%、WebWalkerQA 上达到 52.5% 的成功率，超越最佳基线 26.8%。

Key insight: Mango 的核心创新在于将网站结构信息引入导航决策，避免 Agent 陷入深层页面或无关分支。多臂老虎机框架使得 Agent 能动态调整探索策略，这对搜索 Agent 的多步推理检索有直接启示——可借鉴类似方法在候选文档空间中做自适应探索，而非固定策略的一次性检索。代码和数据已开源，兼容开源与闭源 LLM。

2. Evaluation-driven Scaling for Scientific Discovery
3.55
Relevance 3 | Novelty 4 | Practical 3 | Evidence 4 | Timely 5

Summary: 本文提出 SimpleTES 框架，系统研究如何通过评估驱动的 scaling 来增强 LLM 在科学发现中的迭代优化能力。框架结合并行探索、反馈驱动精炼和局部选择三种策略，在 6 个领域 21 个问题上取得显著提升，包括量子电路设计开销降低 24.5%、突破已有数学记录等。训练数据还可使模型提升效率并泛化到新问题。

Key insight: 该工作将 Agentic 循环中的评估环节提升为一等公民，揭示了 trial-and-error 发现循环的 scaling 规律。对搜索推荐系统的启示在于：自动化超参搜索、特征工程等迭代优化任务可采用类似的评估驱动框架，让 Agent 在反馈循环中持续改进。并行探索 + 局部选择的组合策略值得在搜索 Agent 的多轮检索中借鉴。

3. Temporal Leakage in Search-Engine Date-Filtered Web Retrieval: A Retrospective Forecasting Case Study
3.65
Relevance 4 | Novelty 3 | Practical 4 | Evidence 4 | Timely 3

Summary: 本文系统审计了 Google 和 DuckDuckGo 的日期过滤功能在 Web 检索中的时间泄漏问题。发现 Google 有 71%、DuckDuckGo 有 81% 的查询至少存在一个包含截止日期后信息的页面，答案直接泄露的比例分别为 41% 和 55%。使用泄漏文档时，LLM 预测的 Brier 分数从 0.24 降至 0.10（虚高）。泄漏模式包括更新文章、相关内容模块和元数据不可靠等。

Key insight: 对 Agentic Search 系统而言，本文揭示了一个关键可靠性问题：依赖搜索引擎日期过滤的 Agent 可能获取到时间污染的信息，导致推理结果不可信。建议采用冻结时间戳的网页快照或更强的检索防护措施。这对构建 Deep Research Agent 的数据时效性控制有直接指导意义。

4. What Makes an LLM a Good Optimizer? A Trajectory Analysis of LLM-Guided Evolutionary Search
3.55
Relevance 3 | Novelty 4 | Practical 3 | Evidence 4 | Timely 5

Summary: 本文对 15 个 LLM 在 8 个优化任务上的进化搜索轨迹进行大规模分析，揭示了好的 LLM 优化器的核心特征。优秀的 LLM 优化器充当"局部精炼器"，频繁产生增量改进并逐步在语义空间中聚焦搜索；表现差的模型则出现"语义漂移"，偶有突破但随后停滞。解决方案新颖性本身不能预测性能，新颖性只在搜索足够局部化时才有益。

Key insight: 该研究为使用 LLM 作为搜索/推荐系统中优化 Agent 提供了关键洞察：应鼓励 LLM 做局部精炼而非大幅跳跃。在 Agentic 搜索场景中，Agent 的检索策略也应遵循类似原则——围绕高性能区域进行增量式探索，而非随机发散。轨迹分析方法论可用于评估和改进搜索 Agent 的行为模式。

8. Characterizing AlphaEarth Embedding Geometry for Agentic Environmental Reasoning
3.20
Relevance 3 | Novelty 3 | Practical 3 | Evidence 3 | Timely 5

Summary: 本文分析了 Google AlphaEarth 64 维嵌入的流形几何结构，涵盖 1210 万美国大陆样本（2017-2023），发现有效维度仅 13.3，84% 的位置切空间旋转超过 60°。基于此构建了包含 9 个专用工具的 Agentic 系统，通过 FAISS 索引的嵌入数据库进行检索链处理环境查询，在多步比较任务上达到 4.28/5.0 的分数。

Key insight: 本文展示了一种典型的 Agentic 工具使用模式：先理解嵌入空间的几何特性，再设计专用工具链进行检索推理。这种"嵌入理解 → 工具设计 → 检索链"的范式可迁移到搜索推荐场景，例如理解用户/商品嵌入空间的结构后设计针对性的 Agent 工具。Google AlphaEarth 的流形分析方法也可用于诊断搜索嵌入空间的质量。
