Embedding-Based Sparse Retrieval in E-Commerce Search

提出 EBSR 框架，将查询和文档编码为由 ID-权重对组成的稀疏嵌入向量，用于电商搜索召回。

KEY INSIGHT · 对业务意味着什么稀疏嵌入可同时利用倒排索引的高效检索能力和语义模型的泛化能力，是兼顾效率与语义的新范式。业务关联 对 UGC 短文本搜索场景，EBSR 可直接替换传统倒排索引中的 term matching，在保持毫秒级延迟的同时提升语义召回率。证据 在 MS MARCO 上 MRR@10 达 0.382，优于 SPLADE++；工业级电商搜索 A/B 实验中相关性指标 +1.8%、CTR +0.9%。

Scaling Laws for Embedding Dimension in Information Retrieval

系统研究了稠密检索中嵌入维度与检索性能之间的幂律关系。

INSIGHT嵌入维度与检索性能遵循幂律：与训练数据对齐的任务上持续收益递减，但分布外任务可能随维度增加反而退化。

业务关联为社区搜索选择 embedding 维度提供理论依据——可在存储成本、计算效率和检索质量之间找到最优平衡点。

证据跨多个模型族（BERT/T5/大语言模型）和多个 IR 基准实验，发现对齐任务上 nDCG@10 提升遵循 d^(-α) 幂律衰减，最优维度因模型和数据而异。

Julian Killingback, Mahta Rafiee, Madine Manas, Hamed Zamani

HierGR: Hierarchical Semantic Representation Enhancement for Generative Retrieval in Food Delivery Search

美团在外卖搜索中部署生成式检索，通过层次化语义标识符解决规模和延迟问题。

INSIGHT生成式检索在工业场景落地的三大关键：空间层次化语义 ID 编码、query 缓存降延迟、与 dense retrieval 联合部署。

业务关联社区搜索同样面临 UGC 内容规模大、query 短文本语义模糊的问题，HierGR 的层次化 ID 编码思路可直接迁移至帖子/问答的生成式召回。

证据ACL 2025 Industry Oral；美团外卖搜索线上 A/B 实验：每千次搜索订单量 +0.68%。

Meituan Search Team (ACL 2025 Industry Oral)

CMAQ: Consistency-Aware Online Multi-Objective Alignment for Related Search Query Generation

利用 DPO 多目标优化生成相关搜索 query 推荐，平衡 CTR 和主题多样性。

INSIGHT相关搜索 query 生成需同时优化点击率和主题一致性，迭代 DPO 配合精确奖励建模是有效方案。

业务关联社区搜索的「相关搜索」模块可直接借鉴：用 LLM 生成候选 query，通过 DPO 对齐用户偏好与平台风格。

证据大众点评 A/B 实验 CTR +2.3%；人工评估显示 query 质量和主题相关性显著优于基线。

Meituan Search Team (ACL 2025 Industry Track)

RAIR: A Rule-Aware Benchmark Uniting Challenging Long-Tail and Visual Salience Subset for E-commerce Relevance Assessment

构建中文电商搜索相关性评估基准，包含长尾 query 和视觉显著性子集。

INSIGHT即使 GPT-5 在长尾 query 和视觉显著性场景下仍表现不足，暴露了 LLM 相关性判断的系统性缺陷。

业务关联社区搜索中大量长尾 UGC query 恰好是相关性模型最薄弱的环节，RAIR 的规则化标注框架可直接用于构建内部评估集。

证据评测 14 个模型；GPT-5 最佳但在长尾子集准确率仅 67.2%；VLM 在视觉显著性子集上比纯文本模型高 +4.1%。

ReAttn: Improving Attention-based Re-ranking via Attention Re-weighting

提出跨文档 IDF 加权和熵正则化策略，改进 LLM 零样本 attention-based 重排。

INSIGHTLLM 重排时 attention 过度集中在少数 token 上，跨文档 IDF 降权 + 熵正则化可有效缓解，且无需额外训练。

业务关联社区搜索排序可直接在现有 LLM 重排环节叠加 ReAttn，零成本提升短文本排序的区分度。

证据EACL 2026 录用；在 TREC-DL 2019/2020 等基准上 nDCG@10 比 vanilla attention reranking 提升 +2.1~3.8%。

Yuxing Tian, Fengran Mo, Weixu Zhang, Yiyan Qi, Jian-Yun Nie

PinRec: Unified Generative Retrieval for Pinterest Recommender Systems

Pinterest 部署统一生成式检索模型，跨 home feed、搜索、相关推荐三个场景。

INSIGHT跨 surface 预训练 + surface-specific 微调 + 目标条件生成，使一个生成式模型能统一服务多种推荐场景。

业务关联社区平台同样有信息流、搜索、相关推荐等多场景，PinRec 的统一生成式检索架构可减少多模型维护成本。

证据Pinterest 线上实验：搜索收藏量 +4%；home feed engagement +2.1%；跨 surface 预训练较单 surface 训练 Recall@100 +6.3%。

When LLM Judges Inflate Scores: Exploring Overrating in Relevance Assessment

系统研究 LLM 在信息检索相关性标注中的过度评分行为。

INSIGHTLLM 相关性评估存在系统性膨胀偏差，受文档长度和表面语言模式影响——直接替代人工标注前必须做偏差校准。

业务关联若社区搜索使用 LLM 做离线相关性标注或自动评估，需警惕过度评分导致的数据集污染和指标虚高。

证据跨 TREC-DL 2019/2020/2023 和多个 LLM（GPT-4o、Claude、Llama-3 等）实验；LLM 在 Highly Relevant 标签上 F1 虚高 15~25%。

Generative Reasoning Re-ranker (GR2)

Meta 提出用强化学习增强 LLM 推理能力的推荐重排框架 GR2。

INSIGHTLLM 重排中 RL 训练容易出现 reward hacking（保留原始排序），条件奖励机制可有效缓解。

业务关联社区搜索的精排/重排阶段可引入 LLM reasoning 能力，但需注意 RL 训练中的 reward hacking 问题。

证据在 Amazon Review、Yelp 等真实数据集上 NDCG@5 比 RankGPT 提升 +3.2%；RL 训练后比 SFT 基线 +1.8%。

Mingfu Liang, Yufei Li, Jay Xu, et al. (Meta)

Diagnosing LLM Reranker Behavior Under Fixed Evidence Pools

通过固定证据池的受控实验，诊断 LLM 重排器的排序策略差异。

INSIGHTLLM 重排器在小候选集上词汇覆盖率不如 BM25，且不同模型的冗余控制策略差异显著。

业务关联在社区搜索中部署 LLM 重排前，可参考该诊断方法评估模型的排序行为是否符合业务预期。

证据使用 Multi-News 8 篇文档固定池；LLM 在 k=2 时词汇覆盖率比 BM25 低 12~18%；GPT-4o 在大 k 时多样性提升，而 Llama-3 反而增加冗余。

Baris Arat, Emre Sefer
