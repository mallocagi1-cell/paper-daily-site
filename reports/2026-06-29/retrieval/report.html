Temporal Validity in Retrieval Memory: Eliminating Stale-Fact Errors for AI Agents over Evolving Knowledge

RAG 让 agent 能调用累积知识，却没有时间模型：一个事实被更新后（如函数改名、API 重构），RAG 会以几乎相同的 embedding 相似度同时召回旧值和新值，于是 agent 要么弃答、要么给出过时事实。作者证明这是结构性问题——在校准数据集上，cosine 相似度区分“被推翻的事实”和“换了说法的重复事实”的 AUROC 只有 0.59（接近随机），因为矛盾值往往比改写的重复值更接近原文。提出的 MemStrata 像 RAG 一样存事实、保留静态召回，但当某事实的值被矛盾时，用确定性的 (subject, relation, object) supersession 规则在双时态账本里退役旧值——不设相似度阈值、不调 LLM。在 6 个 benchmark、本地 7B 模型上，静态知识与 RAG 持平、演化知识达 0.95–1.00（RAG 仅 0.20–0.47）；stale-fact-error 率从 RAG 的 15–40% 压到约 0%，检索延迟 ~2.1s vs LLM 重排基线的 16–18s。

KEY INSIGHT · 对业务意味着什么这篇点破了向量检索一个被忽视的盲区——embedding 相似度无法表达“谁取代了谁”，矛盾事实和重复事实在向量空间里几乎不可分（AUROC 0.59）。解法不是更强的 embedding，而是在召回层外挂一个确定性的时态账本，靠 (S,R,O) 三元组 supersession 规则退役旧值，全程不调 LLM、延迟低一个量级。对维护演化型内容（帖子被编辑、答案被更新）的社区搜索/RAG 系统，这提供了一个可借鉴的“召回不动、加一层 validity 元数据”的低成本设计；作者还开源了 harness、数据集和 marker-free 评测协议。

KARLA: Knowledge-base Augmented Retrieval for Language Models

Télécom Paris

KARLA 让 LLM 在生成 token 的过程中自动从知识库拉取事实知识。核心做法是训练模型产出特殊 token，触发对知识库的查询；由此带来三个好处：(1) 输出中的事实知识可通过编辑知识库更新、无需重训 LLM；(2) 输出里的事实可追溯回知识库，具备透明性与可解释性；(3) 小模型借此能达到大模型的事实准确率。实验显示该方法在短文本与长文本生成中都提升了事实 grounding，且事实修订可通过 KB 编辑而非参数更新生效。

INSIGHTKARLA 把“何时检索”交给模型自己学——训练它在需要事实时吐出触发 token 去查 KB，类似 Toolformer 的思路用在知识库检索上。对搜索/问答系统有两点启示：一是事实更新走 KB 编辑而非重训，运维代价低；二是输出可溯源到具体 KB 条目，适合需要可解释、可审计的场景。不足是摘要未给出具体数据集与提升幅度，证据偏弱，落地前需自行验证 trigger token 的训练稳定性与 KB 查询的召回质量。

Francois Crespin, Fabian M. Suchanek, Nils Holzenberger
