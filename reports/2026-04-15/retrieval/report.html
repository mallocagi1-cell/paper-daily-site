NSFL: A Post-Training Neuro-Symbolic Fuzzy Logic Framework for Boolean Operators in Neural Embeddings

标准稠密检索器缺乏对多条件布尔查询（AND/OR/NOT）的原生支持。本文提出 NSFL 框架，将模糊逻辑中的 t-norm 和 t-conorm 适配到神经嵌入空间，无需重训模型即可实现布尔逻辑运算。核心创新是引入 Neuro-Symbolic Delta（NS-Delta）一阶边际差分来引导表征调整，避免传统几何方法中的表征坍塌问题。同时提出 Spherical Query Optimization（SQO）将模糊逻辑公式投影为流形稳定的查询向量，支持实时检索。在 6 种编码器配置和 2 种模态（含零样本）上验证有效性。

CMedTEB & CARE: Benchmarking and Enabling Efficient Chinese Medical Retrieval via Asymmetric Encoders

LLM 级别的 embedding 模型虽然检索能力强，但推理延迟和计算成本限制了实时场景应用。本文构建了中文医疗文本嵌入评测基准 CMedTEB，涵盖检索、重排序和语义相似度三类任务，通过多 LLM 投票管线并经临床专家验证确保标签质量。在此基础上提出非对称检索架构 CARE，使用轻量 BERT 编码器处理查询端，LLM 编码器处理文档端，在保证检索精度的同时大幅降低在线推理延迟。

INSIGHT非对称编码架构是解决「大模型精度高但延迟大」矛盾的实用方案：查询端用小模型（低延迟）、文档端用大模型（高精度，离线编码）。这一思路直接适用于 UGC 搜索：文档侧可在入库时用 LLM 离线编码，查询侧保持轻量编码器满足实时性要求。CMedTEB 的多 LLM 投票 + 专家验证的标注管线也值得借鉴，可用于构建高质量的中文搜索评测集。

Angqing Jiang, Jianlyu Chen, Zhe Fang, Yongcan Wang, Xinpeng Li, Keyu Ding, Defu Lian

ARHN: Answer-Centric Relabeling of Hard Negatives with Open-Source LLMs for Dense Retrieval

稠密检索器训练依赖三元组数据（query、正例、硬负例），但硬负例挖掘常引入假负例和歧义负例，导致监督信号不一致、检索效果下降。本文提出 ARHN 框架，利用开源 LLM 通过两阶段方式精炼硬负例：第一阶段让 LLM 为每个 query-passage 对生成基于段落的答案片段或标记为不支持；第二阶段通过 LLM 基于 listwise 排序对候选集按直接可回答性重新排列。排在原正例之上的段落被提升为正例，从而修正标签噪声。

INSIGHT硬负例质量是稠密检索训练的关键瓶颈。ARHN 的核心思路是将「相关性」判断转化为「可回答性」判断——如果一个段落能回答查询问题，即使原始标注为负例也应被视为正例。这种以答案为中心的重标注策略比传统基于相似度的方法更鲁棒。使用开源 LLM（而非闭源 API）完成标注，成本可控且可复现，适合工业界大规模训练数据清洗场景。

Hyewon Choi, Jooyoung Choi, Hansol Jang, Hyun Kim, Chulmin Yun, ChangWook Jun, Stanley Jungkyu Choi

Reproduction Beyond Benchmarks: ConstBERT and ColBERT-v2 Across Backends and Query Distributions

对 ColBERT-v2 和 ConstBERT 进行五维度复现评估，发现 ConstBERT 在 MS-MARCO 上 MRR@10 偏差仅 0.05%，但两者在长叙事查询（TREC ToT 2025）上性能下降 86-97%。消融实验证明这是架构性缺陷：MaxSim 算子的均匀 token 加权在超过 20 词后无法区分信号与噪声。此外，未文档化的后端参数导致 8 个点的性能差距，3 倍数据量的微调反而使性能下降最高 29%。代码已开源。

INSIGHT多向量检索模型（ColBERT 系列）在标准短查询基准上表现优异，但在长查询场景存在架构性上限——MaxSim 的均匀 token 加权是根本原因。对于 UGC 搜索场景（查询通常较短），ColBERT 仍是可行选择，但若需处理复杂长查询则需重新考虑架构。更重要的启示是：后端实现细节（如 centroid 覆盖率参数）可能比模型本身影响更大，工程部署时必须控制这些隐含变量。

Utshab Kumar Ghosh, Ashish David, Shubham Chatterjee

Visual Late Chunking: An Empirical Study of Contextual Chunking for Efficient Visual Document Retrieval

多向量模型在视觉文档检索中占主导地位，但存储和计算成本过高。本文提出 ColChunk 即插即用框架，通过多模态 late chunking 构建高效上下文化多向量表征。核心方法是对 patch 级嵌入进行层次聚类，融合 2D 位置先验确保空间-语义一致性，实现内容自适应分组。在 24 个视觉文档检索数据集上评测，ColChunk 实现超 90% 的存储压缩，同时在代表性单向量模型上平均提升 nDCG@5 达 9 个百分点。

INSIGHTColChunk 的层次聚类 + 空间先验思路可以迁移到文本检索场景：将文档切分为语义连贯的 chunk 而非固定长度片段，能显著减少存储同时保持检索精度。90% 的存储压缩对于大规模 UGC 索引极具吸引力。即插即用的设计理念值得借鉴——作为后处理模块叠加在现有编码器上，无需修改模型架构。

Yibo Yan, Mingdong Ou, Yi Cao, Jiahao Huo, Xin Zou, Shuliang Liu, James Kwok, Xuming Hu

Mycelium-Index: A Streaming Approximate Nearest Neighbor Index with Myelial Edge Decay, Traffic-Driven Reinforcement, and Adaptive Living Hierarchy

提出 mycelium-index，一种受生物菌丝体自适应生长模式启发的流式近似最近邻（ANN）索引。系统通过菌丝边衰减与增强、流量驱动的活层次结构以及混合删除策略（冷节点 O(1) 旁路 + 热节点 O(k) beam-search 修复）持续适应拓扑变化。在 SIFT-1M 基准上，100% 数据更新条件下 recall@5 达 0.927，与 FreshDiskANN（~0.95）在置信区间内，同时 RAM 使用仅为 1/5.7（88MB vs >500MB），QPS 提升 4.7 倍。静态索引上匹配 HNSW M=16 的召回率，内存仅为 1/5.2。

INSIGHT对于需要频繁更新的 UGC 搜索场景，流式 ANN 索引至关重要。Mycelium-Index 的核心优势在于：(1) 自适应拓扑——高频访问的边被增强、低频边衰减，天然适配热点内容分布；(2) 极低内存占用（HNSW 的 1/5），适合大规模部署；(3) 流式更新能力，无需离线重建索引。虽然召回率略低于 FreshDiskANN，但内存和吞吐量优势在资源受限场景下更具实用价值。

Anton Pakhunov

HyEm: Query-Adaptive Hyperbolic Retrieval for Biomedical Ontologies via Euclidean Vector Indexing

面向层级知识体系（如 HPO、MeSH 等本体）的检索增强生成存在层级感知难题：生产系统依赖欧几里得嵌入和 ANN 索引，而双曲嵌入虽适合层级结构但缺乏向量数据库原生支持。HyEm 提出轻量检索层：先学习半径控制的双曲嵌入，将其 log-map 投影到原点后存入标准欧几里得数据库完成候选检索，再用精确双曲重排序。查询自适应门控输出连续混合权重，在重排阶段融合欧几里得语义相似度与双曲层级距离，并通过 bi-Lipschitz 保证投影质量。

INSIGHTHyEm 巧妙解决了「理论最优表征空间与工程基础设施不兼容」的矛盾：双曲空间更适合层级数据，但没有向量数据库支持。其 log-map + 重排序的两阶段方案提供了通用模式——先用标准工具召回，再用专用距离重排。查询自适应门控的设计值得注意：对实体查询偏向欧几里得、对层级查询偏向双曲，这种动态混合策略可推广到其他需要融合异构相似度信号的检索场景。

Ou Deng, Shoji Nishimura, Atsushi Ogihara, Qun Jin

LANCER: LLM Reranking for Nugget Coverage

传统 LLM 重排序方法关注单文档相关性，忽略了文档集合对信息需求的整体覆盖。LANCER 提出基于信息粒度（nugget）覆盖的 LLM 重排序方法：先由 LLM 预测满足信息需求所需的子问题集合，再根据文档对各子问题的覆盖程度进行重排序。在 alpha-nDCG 和信息覆盖度指标上优于其他 LLM 重排序方法，特别是在多方面信息需求的查询上提升显著。

INSIGHTLANCER 的子问题分解思路为 UGC 搜索提供了新视角：用户搜索一个话题时，往往隐含多个信息需求维度。通过 LLM 自动分解查询意图为多个子问题，可以优化搜索结果的多样性和覆盖度，减少用户需要翻页查找不同方面信息的频率。这种 nugget-aware 重排序策略可以与现有排序系统的多样性模块结合使用。

RECIPER: A Dual-View Retrieval Pipeline for Procedure-Oriented Materials Question Answering

针对材料科学论文中操作步骤信息分散、段落级稠密检索难以有效捕获的问题，提出 RECIPER 双视图检索管线。系统同时索引段落级上下文和 LLM 提取的紧凑操作摘要，合并两路候选后用轻量词法重排序。在 4 种稠密检索骨干模型上一致改善早期排名，平均 Recall@1 提升 +3.73、nDCG@10 提升 +2.85、MRR 提升 +3.13。使用 BGE-large-en-v1.5 时，Recall@1/5/10 分别达 86.82%/97.07%/97.85%。

INSIGHT双视图索引（原文 + LLM 结构化摘要）的思路有较强的通用性：UGC 内容中经常存在信息分散、关键信息嵌套在长文中的情况。可以借鉴 RECIPER 的做法，对 UGC 帖子同时建立原文索引和 LLM 提取的结构化信息索引（如关键观点、步骤、结论），提高对特定信息检索的召回率。轻量词法重排序的选择也体现了实用主义——不必所有环节都用重模型。

Zhuoyu Wu, Wenhui Ou, Pei-Sze Tan, Wenqi Fang, Sailaja Rajanala, Raphaël C.-W. Phan

LITHE: A Query Rewrite Advisor using LLMs

发表于 EDBT 2026 的工作，展示了利用 LLM 的探索能力进行查询重写优化。LITHE 作为查询重写顾问，目标是将 LLM 生成的查询改写纳入优化器的原生搜索空间。系统通过 LLM 理解查询语义，自动生成等价或语义增强的查询变体，并评估各变体的执行效率和结果质量，最终选择最优重写方案。

INSIGHT虽然 LITHE 面向数据库查询优化，但其「LLM 作为查询重写顾问」的框架对搜索查询理解有借鉴意义：在 UGC 搜索中，可以用 LLM 生成多个查询改写版本（同义词替换、意图澄清、缩写展开等），然后评估各版本的检索效果，选择最优改写。这种「生成-评估-选择」的三步范式比直接让 LLM 一次性改写查询更稳健，也更适合线上部署。

Sriram Dharwada et al.
