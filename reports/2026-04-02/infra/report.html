1. CRAFT: Cost-aware Expert Replica Allocation with Fine-Grained Layerwise Estimations
4.10
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 针对 Mixture-of-Experts (MoE) 大模型推理中专家并行带来的 token 级负载不均问题，本文提出 CRAFT 框架。现有专家复制策略往往过度复制，大量副本仅带来边际收益，却消耗大量 GPU 显存甚至导致资源竞争和吞吐量下降。CRAFT 通过细粒度逐层复制估计，在给定显存预算下最大化负载均衡效果，实现了更高效的 MoE 模型服务。

Key insight: 核心创新在于将专家复制建模为逐层预算约束优化问题，而非全局统一复制。通过对每层专家负载进行细粒度估计，避免了传统方案中的「过度复制」现象。对于搜索/推荐系统中部署 MoE 架构的场景，该方法可直接降低 GPU 显存占用并提升推理吞吐量，是 MoE serving 优化的实用参考。

Summary: 现代 LLM 推理依赖稀疏注意力、RAG 和压缩上下文记忆等优化机制，本文将这些优化统一为四步记忆处理流水线（准备记忆→计算相关度→检索→推理应用），并通过系统性 profiling 发现 22%-97% 的推理开销来自记忆处理环节。基于此洞察，作者在 GPU-FPGA 异构系统（AMD MI210 GPU + Alveo U55C FPGA）上将稀疏、不规则的记忆操作卸载至 FPGA，实现了端到端推理加速。

Key insight: 将 LLM 推理中的 RAG、稀疏注意力等操作抽象为统一的记忆处理流水线是关键贡献，揭示了推理瓶颈不在计算而在记忆处理。GPU-FPGA 异构加速方案为搜索系统中的长上下文 LLM 推理提供了新思路，尤其适合 RAG 增强的搜索场景，可显著降低首 token 延迟和长文本处理开销。

3. PolarQuant: Optimal Gaussian Weight Quantization via Hadamard Rotation for LLM Compression
3.80
Relevance 3 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 提出 PolarQuant 后训练权重量化方法，利用神经网络权重的分布结构实现近无损压缩。方法分三阶段：块归一化到单位超球面、Walsh-Hadamard 旋转将坐标变换为近似高斯随机变量、使用高斯匹配质心量化。消融实验表明 Hadamard 旋转贡献了 98% 的质量提升，将 Qwen3.5-9B 的困惑度从 6.90 (absmax Q5) 降至 6.40（与 FP16 仅差 0.03），无需校准数据即可实现近无损。

Key insight: PolarQuant 的核心洞察是利用 Hadamard 旋转将权重分布高斯化后再量化，这一简洁的预处理步骤消除了 98% 的量化质量损失。该方法还可作为 INT4 量化的预处理：PolarQuant Q5 反量化后再用 torchao INT4 可达 6.56 困惑度（直接 INT4 为 6.68）。对搜索排序模型的部署压缩具有直接参考价值。

7. Stronger Normalization-Free Transformers
3.60
Relevance 3 | Novelty 4 | Practical 4 | Evidence 4 | Timely 3

Summary: 在 Dynamic Tanh (DyT) 证明归一化层并非不可替代之后，本文进一步探索能超越 DyT 的逐点函数设计。通过研究逐点函数的内在性质对训练和性能的影响，经大规模搜索发现 Derf(x) = erf(αx + s)（基于缩放的高斯累积分布函数）是最优设计。Derf 在视觉识别、生成、语音、语言等广泛领域均超越了 LayerNorm、RMSNorm 和 DyT。

Key insight: Derf 作为 LayerNorm/RMSNorm 的即插即用替代，在不改变模型架构的情况下提升性能和训练稳定性。对于搜索/推荐模型（如 Transformer-based 排序模型），替换归一化层即可获得免费的性能提升。该工作延续了「去归一化」趋势，表明 Transformer 的基础组件仍有优化空间，值得在新模型训练中尝试。

8. ITQ3_S: High-Fidelity 3-bit LLM Inference via Interleaved Ternary Quantization with Rotation-Domain Smoothing
3.45
Relevance 3 | Novelty 4 | Practical 3 | Evidence 3 | Timely 5

Summary: 提出 ITQ3_S，一种新的 3-bit 权重量化格式，融合 TurboQuant (TQ) 和基于快速 Walsh-Hadamard 变换 (FWHT) 的旋转域策略。传统 3-bit 方法受重尾权重分布和通道间异常值影响精度损失严重。ITQ3_S 在量化前通过 FWHT 预旋转权重空间，将异常值能量扩散至整个向量并诱导近高斯分布，使三值编码更有效。反量化过程将 256 点逆 FWHT 融入 CUDA 共享内存加载阶段。

Key insight: ITQ3_S 在 3-bit 这一极低比特宽度下实现了高保真推理，关键在于旋转域平滑消除了权重分布中的异常值。将 FWHT 逆变换融入 CUDA kernel 的设计确保了重建误差仅来自三值量化网格本身。3-bit 量化可将模型显存占用压缩至原来的约 1/5，对于 GPU 资源受限的搜索服务场景具有重要参考价值。

9. Spark-LLM-Eval: A Distributed Framework for Statistically Rigorous Large Language Model Evaluation
3.45
Relevance 3 | Novelty 3 | Practical 4 | Evidence 3 | Timely 5

Summary: 大规模 LLM 评估是组织面临的实际瓶颈，现有评估框架在数据集规模达到数十万或百万级别时难以胜任。Spark-LLM-Eval 基于 Apache Spark 构建，将评估视为数据并行问题，在 executor 间分区样本并聚合结果。该框架强调统计严谨性：每个指标都包含 bootstrap 置信区间，模型比较配备显著性检验（配对 t 检验、McNemar 检验或 Wilcoxon 符号秩检验）。
