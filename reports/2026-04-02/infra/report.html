CRAFT: Cost-aware Expert Replica Allocation with Fine-Grained Layerwise Estimations

针对 Mixture-of-Experts (MoE) 大模型推理中专家并行带来的 token 级负载不均问题，本文提出 CRAFT 框架。现有专家复制策略往往过度复制，大量副本仅带来边际收益，却消耗大量 GPU 显存甚至导致资源竞争和吞吐量下降。CRAFT 通过细粒度逐层复制估计，在给定显存预算下最大化负载均衡效果，实现了更高效的 MoE 模型服务。

Understand and Accelerate Memory Processing Pipeline for Disaggregated LLM Inference

AMDUCLA

现代 LLM 推理依赖稀疏注意力、RAG 和压缩上下文记忆等优化机制，本文将这些优化统一为四步记忆处理流水线（准备记忆→计算相关度→检索→推理应用），并通过系统性 profiling 发现 22%-97% 的推理开销来自记忆处理环节。基于此洞察，作者在 GPU-FPGA 异构系统（AMD MI210 GPU + Alveo U55C FPGA）上将稀疏、不规则的记忆操作卸载至 FPGA，实现了端到端推理加速。

INSIGHT将 LLM 推理中的 RAG、稀疏注意力等操作抽象为统一的记忆处理流水线是关键贡献，揭示了推理瓶颈不在计算而在记忆处理。GPU-FPGA 异构加速方案为搜索系统中的长上下文 LLM 推理提供了新思路，尤其适合 RAG 增强的搜索场景，可显著降低首 token 延迟和长文本处理开销。

Zifan He, Rui Ma, Yizhou Sun, Jason Cong

PolarQuant: Optimal Gaussian Weight Quantization via Hadamard Rotation for LLM Compression

提出 PolarQuant 后训练权重量化方法，利用神经网络权重的分布结构实现近无损压缩。方法分三阶段：块归一化到单位超球面、Walsh-Hadamard 旋转将坐标变换为近似高斯随机变量、使用高斯匹配质心量化。消融实验表明 Hadamard 旋转贡献了 98% 的质量提升，将 Qwen3.5-9B 的困惑度从 6.90 (absmax Q5) 降至 6.40（与 FP16 仅差 0.03），无需校准数据即可实现近无损。

INSIGHTPolarQuant 的核心洞察是利用 Hadamard 旋转将权重分布高斯化后再量化，这一简洁的预处理步骤消除了 98% 的量化质量损失。该方法还可作为 INT4 量化的预处理：PolarQuant Q5 反量化后再用 torchao INT4 可达 6.56 困惑度（直接 INT4 为 6.68）。对搜索排序模型的部署压缩具有直接参考价值。

Caio Vicentino

OneComp: One-Line Revolution for Generative AI Model Compression

针对基础模型部署中显存占用、延迟和硬件成本的瓶颈，提出 OneComp 开源压缩框架。该框架将后训练压缩从专家手工流程转化为可复现、资源自适应的自动化流水线：输入模型标识符和硬件配置后，自动完成模型检查、混合精度分配规划和渐进量化（层级→块级→全局精炼）。核心设计理念是将首个量化检查点作为后续优化的锚点。

INSIGHTOneComp 的最大价值在于极致的工程易用性——一行代码完成模型压缩。框架自动根据硬件配置选择最优压缩策略，免除了从业者在量化算法、精度预算、校准策略间反复试验的成本。对于搜索/推荐团队快速部署压缩模型到生产环境，OneComp 提供了开箱即用的解决方案，显著降低了模型压缩的工程门槛。

Training-Free Dynamic Upcycling of Expert Language Models

提出 Dynamic Upcycling MoE (DUME)，一种无需训练即可将不同领域微调的 dense 模型组装为统一 MoE 模型的方法。传统 MoE 构建需要多任务微调，面临干扰和灾难性遗忘问题。DUME 直接复用已有的领域专家模型，通过动态路由机制实现多领域能力整合，避免了昂贵的联合训练过程。

INSIGHTDUME 的实践意义在于：搜索/推荐团队通常针对不同子任务（如 query 理解、文档排序、用户建模）微调了独立模型，DUME 提供了一种零成本将这些专家模型整合为统一 MoE 架构的路径。无需多任务训练即可获得多领域能力，显著降低了 MoE 模型的构建门槛，适合快速实验和迭代。

Eros Fanì, Oğuzhan Ersoy

Accelerating Diffusion Large Language Models with SlowFast Sampling: The Three Golden Principles

针对扩散语言模型 (dLLM) 推理中现有采样策略的静态行为问题，提出 SlowFast Sampling 动态采样策略。该方法基于三条黄金原则（确定性原则、收敛原则、位置原则）自适应地在探索性解码和加速解码之间切换，并与 dLLM-Cache 结合减少冗余计算。在多个基准测试和模型上实现了最高 15.63 倍的加速效果。

INSIGHT扩散语言模型是自回归 LLM 的新兴替代方案，可并行生成 token 从而大幅降低推理延迟。SlowFast Sampling 的三条原则为 dLLM 推理优化提供了系统化框架：确定性高的 token 快速解码、尚未收敛的 token 继续探索、位置信息指导解码顺序。15.63x 加速表明 dLLM 的推理效率还有巨大提升空间，值得关注这一新范式。

Stronger Normalization-Free Transformers

在 Dynamic Tanh (DyT) 证明归一化层并非不可替代之后，本文进一步探索能超越 DyT 的逐点函数设计。通过研究逐点函数的内在性质对训练和性能的影响，经大规模搜索发现 Derf(x) = erf(αx + s)（基于缩放的高斯累积分布函数）是最优设计。Derf 在视觉识别、生成、语音、语言等广泛领域均超越了 LayerNorm、RMSNorm 和 DyT。

INSIGHTDerf 作为 LayerNorm/RMSNorm 的即插即用替代，在不改变模型架构的情况下提升性能和训练稳定性。对于搜索/推荐模型（如 Transformer-based 排序模型），替换归一化层即可获得免费的性能提升。该工作延续了「去归一化」趋势，表明 Transformer 的基础组件仍有优化空间，值得在新模型训练中尝试。

ITQ3_S: High-Fidelity 3-bit LLM Inference via Interleaved Ternary Quantization with Rotation-Domain Smoothing

提出 ITQ3_S，一种新的 3-bit 权重量化格式，融合 TurboQuant (TQ) 和基于快速 Walsh-Hadamard 变换 (FWHT) 的旋转域策略。传统 3-bit 方法受重尾权重分布和通道间异常值影响精度损失严重。ITQ3_S 在量化前通过 FWHT 预旋转权重空间，将异常值能量扩散至整个向量并诱导近高斯分布，使三值编码更有效。反量化过程将 256 点逆 FWHT 融入 CUDA 共享内存加载阶段。

INSIGHTITQ3_S 在 3-bit 这一极低比特宽度下实现了高保真推理，关键在于旋转域平滑消除了权重分布中的异常值。将 FWHT 逆变换融入 CUDA kernel 的设计确保了重建误差仅来自三值量化网格本身。3-bit 量化可将模型显存占用压缩至原来的约 1/5，对于 GPU 资源受限的搜索服务场景具有重要参考价值。

Spark-LLM-Eval: A Distributed Framework for Statistically Rigorous Large Language Model Evaluation

大规模 LLM 评估是组织面临的实际瓶颈，现有评估框架在数据集规模达到数十万或百万级别时难以胜任。Spark-LLM-Eval 基于 Apache Spark 构建，将评估视为数据并行问题，在 executor 间分区样本并聚合结果。该框架强调统计严谨性：每个指标都包含 bootstrap 置信区间，模型比较配备显著性检验（配对 t 检验、McNemar 检验或 Wilcoxon 符号秩检验）。

INSIGHTSpark-LLM-Eval 填补了大规模 LLM 评估工具链的空白。对于搜索/推荐团队，模型迭代需要在海量 query-document 对上做回归测试，该框架的分布式能力和统计严谨性（置信区间、显著性检验）直接解决了「评估规模上不去」和「指标波动难判断」两大痛点。基于 Spark 的架构也易于与现有大数据基础设施集成。

Big2Small: A Unifying Neural Network Framework for Model Compression

针对模型压缩领域的碎片化现状（低秩分解、剪枝、量化、知识蒸馏等基于不同启发式），本文基于测度论构建了统一数学框架。证明了每种压缩技术在数学上等价于带特定正则化的神经网络。基于此结构等价性，提出 Big2Small 框架，利用隐式神经表示 (INR) 从数据域转换到网络参数域，实现免数据的模型压缩。

INSIGHTBig2Small 的理论贡献在于首次将多种模型压缩方法统一在测度论框架下，揭示了它们的数学等价性。INR-based 的免数据压缩路径避免了对校准数据的依赖。虽然目前更偏理论，但统一框架有助于理解不同压缩技术的本质差异和适用场景，对搜索/推荐模型的压缩策略选择具有指导意义。

Jing-Xiao Liao, Haoran Wang, Tao Li, Daoming Lyu, Yi Zhang, Chengjun Cai, Feng-Lei Fan
