1. CLAUSE: Agentic Neuro-Symbolic Knowledge Graph Reasoning via Dynamic Learnable Context Engineering
4.20
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 4

Summary: 针对知识图谱上多跳问答中静态扩展效率低、上下文膨胀和运行时不可控的问题，提出 CLAUSE——一个三智能体神经符号框架，将上下文构建建模为知识图谱上的序列决策过程。核心创新在于引入 Lagrangian-Constrained Multi-Agent PPO (LC-MAPPO) 算法协调三个智能体（子图扩展、路径选择、证据保留），用户可指定延迟和成本预算，实现每查询级别的准确率-延迟-成本权衡，无需重新训练。实验表明在多个多跳 QA 基准上达到 SOTA，同时将推理成本降低 40%以上。

Key insight: 将知识图谱上下文构建转化为多智能体强化学习问题是一个范式创新，尤其是将延迟和 token 成本作为拉格朗日约束暴露给用户。这对搜索系统的启示在于：(1) 复杂的多跳检索可以通过 RL 智能体自动学习最优扩展策略，避免手工规则；(2) 成本-质量权衡可以在查询级别动态调整，适合不同场景的 SLA 要求；(3) 神经符号结合保留了推理链的可解释性，便于线上问题排查。

2. A Systematic Framework for Enterprise Knowledge Retrieval: Leveraging LLM-Generated Metadata to Enhance RAG Systems
3.90
Relevance 4 | Novelty 3 | Practical 4 | Evidence 4 | Timely 4

Summary: 提出一套面向企业知识库的系统化 RAG 增强框架：利用 LLM 动态生成文档片段的结构化元数据（关键词、摘要、实体等），显著提升语义表征和检索精度。通过 3×3 实验矩阵对比三种分块策略（语义/递归/朴素）与三种嵌入技术（纯内容/TF-IDF 加权/前缀融合），系统消融分析各组件贡献。实验证明元数据增强方法在检索准确率上一致优于基线，其中语义分块 + 前缀融合组合效果最佳，Recall@5 提升约 15%。

Key insight: LLM 生成的元数据作为「语义桥梁」增强文档检索是一个实用且低门槛的方案。对搜索系统的启示：(1) 可以用 LLM 批量为 UGC 内容生成结构化标签和摘要，弥补短文本语义稀疏问题；(2) 前缀融合嵌入（将元数据拼接到原文前再编码）是一种简单有效的工程技巧；(3) 3×3 消融设计提供了模块化评估 RAG 组件的方法论参考。

3. ContractSkill: Repairable Contract-Based Skills for Multimodal Web Agents
3.85
Relevance 3 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 针对 Web 智能体自动生成的技能不稳定、甚至降低性能的问题，提出 ContractSkill 框架。核心思想是将隐式技能转化为具有显式过程结构的可执行制品（artifact），支持确定性验证、故障定位和最小化局部修复，将技能优化从全量重写变为局部编辑。在 VisualWebArena 真实 Web 环境实验中验证有效性，MiniWoB 提供机制级验证。修复后的制品在移除源模型后仍可复用，证明了技能的可移植性。

Key insight: 「合约化」技能是提升 Agent 可靠性的关键设计模式：将技能从黑盒函数变为带前置/后置条件的结构化制品，使得验证和修复成为可能。对搜索 Agent 的启示：(1) 搜索工具调用链可以类似地合约化，每步都有可验证的输入输出规范；(2) 局部修复优于全量重生成，大幅降低迭代成本；(3) 技能可移植性意味着可以在离线环境训练技能，在线环境直接复用。

4. MemFactory: Unified Inference & Training Framework for Agent Memory
3.85
Relevance 3 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: 提出 MemFactory——首个统一的记忆增强智能体训练与推理框架。针对当前记忆增强 LLM 实现碎片化、缺乏统一基础设施的问题，MemFactory 将记忆生命周期抽象为原子化、即插即用的组件（提取、更新、检索、遗忘），支持通过「乐高式」架构灵活组合自定义记忆智能体。框架原生集成 GRPO（Group Relative Policy Optimization）算法用于记忆操作的强化学习优化，支持端到端训练。类似 LLaMA-Factory 对微调的统一化作用。

Key insight: 将记忆操作的 RL 优化标准化是推动 Agent 记忆研究从手工设计走向自动学习的重要一步。对搜索系统的启示：(1) 搜索 Agent 的对话历史管理可以用 RL 自动学习何时保留/更新/遗忘信息，替代硬编码规则；(2) GRPO 用于记忆优化的思路可迁移到搜索排序模型的在线学习；(3) 「乐高式」模块化设计便于快速实验不同记忆策略组合。

5. Trace2Skill: Distill Trajectory-Local Lessons into Transferable Agent Skills
3.75
Relevance 3 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: 提出 Trace2Skill 框架，模拟人类专家编写技能的方式：先全面分析大量执行轨迹，再蒸馏为统一的综合指南。不同于逐条轨迹顺序反应，Trace2Skill 派遣并行子智能体分析多样化的执行池，提取轨迹特定经验并通过归纳推理进行层次化整合，消除冲突生成统一的技能目录。支持「深化已有技能」和「发现新技能」两种模式，解决了自动化技能生成中「碎片化」和「过拟合单轨迹」的核心瓶颈。

Key insight: 从执行轨迹到可迁移技能的蒸馏路径解决了 Agent 技能扩展性的核心问题。对搜索 Agent 的启示：(1) 可以收集搜索 Agent 的历史工具调用轨迹，自动提炼最佳实践；(2) 并行子智能体 + 层次化整合的架构可用于从海量搜索 session 中学习查询策略；(3) 「冲突消解」机制在多场景搜索策略合并时尤为重要。来自 Microsoft Research，工程落地可行性较高。

6. Near-Miss: Latent Policy Failure Detection in Agentic Workflows
3.70
Relevance 3 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: 提出一种检测 Agent 工作流中潜在策略失败的新方法。传统方法通过比较最终状态与预定义真值来检测策略违规，但会遗漏「近失误」——Agent 绕过了必要的策略检查却因有利条件达到了正确结果。基于 ToolGuard 框架将自然语言策略转化为可执行保护代码，分析 Agent 的工具调用轨迹以判断决策是否基于充分信息。这类潜在失败在部署后遇到边界条件时可能导致严重问题。

Key insight: 「近失误」检测填补了 Agent 可靠性评估的关键盲区：结果正确不等于过程正确。对搜索系统的启示：(1) 搜索 Agent 的工具调用链需要过程级验证，不能仅看最终搜索结果；(2) 将策略规则编译为可执行 guard code 是实现合规性检查的可行方案；(3) 在 A/B 测试中关注「侥幸成功」的 case 可以发现潜在的系统性风险。来自 IBM Research，在企业级 Agent 部署中有直接应用价值。

7. Nomad: Autonomous Exploration and Discovery

Relevance 3 | Novelty 4 | Practical 3 | Evidence 3 | Timely 5

Summary: 提出 Nomad 系统——一个自主数据探索与洞察发现平台。不同于查询驱动的问答和提示驱动的 deep research 系统受限于人工问题框定，Nomad 采用「探索优先」架构：在领域上构建显式的 Exploration Map，系统化遍历以平衡广度和深度；生成并筛选假设，由 explorer agent 使用文档搜索、Web 搜索和数据库工具进行调查；候选洞察由独立验证器检查后进入报告管道。提供了全面的评估框架用于衡量发现的覆盖度和质量。

9. FlowPIE: Test-Time Scientific Idea Evolution with Flow-Guided Literature Exploration
3.55
Relevance 3 | Novelty 4 | Practical 3 | Evidence 3 | Timely 5

Summary: 提出 FlowPIE——一个将文献探索与创意生成作为共同演化过程的紧耦合检索-生成框架。不同于传统「先检索再生成」的静态范式，FlowPIE 通过 GFlowNet 启发的流引导蒙特卡洛树搜索（MCTS）扩展文献轨迹，利用 LLM 生成式奖励模型评估当前创意质量作为监督信号，引导自适应检索并构建多样化、高质量的初始种群。在此基础上，将创意生成建模为测试时演化过程，应用选择、交叉和变异操作。

Key insight: 检索与生成的紧耦合共演化是突破当前 RAG 系统「检索一次、生成一次」局限的关键方向。对搜索系统的启示：(1) GFlowNet 引导的自适应检索可以用于动态调整搜索策略，避免固定检索模式；(2) 将搜索结果质量作为奖励信号反馈给检索过程，形成闭环优化；(3) MCTS 式的文献探索路径对 deep research 类产品有直接借鉴价值。

10. AI Mode in Google Search adds personalization, agentic features

Summary: Google 在搜索中推出更多 Agent 化和个性化能力：AI Mode 增加了帮助用户完成复杂任务的 Agent 功能，以及更精准的个性化搜索结果。Google VP Vidhya Srinivasan 称公司正在「重新定义广告」以适应 Agent 搜索时代。WebMCP（Web Model Context Protocol）作为提议的 Web 标准，允许 AI Agent 通过结构化工具而非 HTML 抓取与网站交互，代表着 Agent 化 Web 的早期基础设施。
