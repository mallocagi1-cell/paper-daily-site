Understanding Generative Recommendation with Semantic IDs from a Model-scaling View

本文首次系统研究生成式推荐（GR）的模型缩放特性，对比分析了基于语义ID（SID）的GR和LLM-as-RS两种范式在44M到14B参数规模上的表现。研究揭示SID-based GR存在固有的缩放瓶颈——随着模态编码器、量化分词器和推荐系统本身的扩大，性能快速饱和，根本原因在于SID编码item语义信息的容量有限。相比之下，LLM-as-RS范式展现出优越的缩放特性，通过扩大模型规模可获得比SID-based GR最佳性能高出20%的提升。

GFlowGR: Fine-tuning Generative Recommendation Frameworks with Generative Flow Networks

AlibabaCity University of Hong Kong

本文针对生成式推荐（GR）中LLM微调阶段的曝光偏差（exposure bias）问题，提出基于生成流网络（GFlowNets）的微调框架GFlowGR。现有GR微调方法主要依赖SFT的下一个token预测损失或DPO策略，都忽视了对未观察到的正样本的探索。GFlowGR将GR建模为多步生成任务，整合传统推荐系统的协同知识构建自适应轨迹采样器和综合奖励模型，在两个真实数据集和两种GR骨干网络上验证了有效性和鲁棒性。该工作入选ACM Web Conference 2026。

INSIGHTGFlowGR揭示了当前GR系统微调的关键缺陷——SFT和DPO都未充分探索潜在正样本空间。GFlowNets的「按奖励比例采样」特性为解决曝光偏差提供了优雅方案。对从业者的启示：生成式推荐系统的性能瓶颈可能不在模型架构或item编码，而在微调策略本身。引入多样化采样和轨迹级奖励建模可显著改善推荐覆盖度和多样性，阿里巴巴参与验证了该方法的工业可行性。

Yejing Wang, Shengyu Zhou, Jinyu Lu et al.

EventChat: Implementation and user-centric evaluation of a large language model-driven conversational recommender system for exploring leisure events in an SME context

本文实现并以用户为中心评估了一个基于LLM的对话式推荐系统（CRS），用于休闲活动探索推荐。研究从终端用户体验和中小企业战略视角进行评估，结果显示系统推荐准确率达85.5%，但单次交互中位成本$0.04、延迟5.7秒，暴露了LLM-CRS在运营经济性方面的挑战。论文还提出了修订版ResQue评估模型，并指出仅依赖Prompt-based ChatGPT方法不足以达到生产级推荐质量。

INSIGHT本文是少数对LLM驱动的对话式推荐系统进行端到端用户评估的研究。85.5%推荐准确率表明LLM-CRS已具实用水平，但$0.04/次的成本和5.7秒延迟揭示了部署的关键瓶颈。对从业者的核心启示：对话式推荐的挑战已从技术可行性转向运营经济性——需要在模型推理成本、响应延迟和推荐质量间寻找最优平衡，单纯的Prompt工程无法满足生产需求。

Hannes Kunstmann, Joseph Ollier, Joel Persson, Florian von Wangenheim

Measuring the Predictability of Recommender Systems using Structural Complexity Metrics

本文提出了一套数据驱动指标来度量推荐系统输出的可预测性，通过分析用户-物品交互矩阵的结构复杂度实现。方法基于数据扰动和奇异值分解（SVD）评估潜在结构的稳定性。关键发现：在低数据场景下，使用低结构扰动误差的精选交互子集训练的模型，性能持续优于使用全量数据训练的模型。该指标与先进推荐算法的性能高度相关，为推荐数据集提供了量化的难度评估工具。

INSIGHT该工作为推荐系统提供了一个通用的数据难度评估框架。在生成式推荐背景下，理解数据集的结构复杂度有助于判断何时需要更强大的模型（如LLM-based GR），何时简单模型已足够。「精选子集优于全量数据」的发现对大模型微调时的数据筛选有直接指导意义——与其投入更多训练数据，不如精选低噪声、高结构性的交互样本。入选WWW 2024 Workshop。

Andrés Abeliuk, Alfonso Valderrama, Simón Campos, Marcelo Mendoza
