Evidence: 在 agentic 工作流上实现约 65% 峰值 token 用量降低，准确率损失最小；仅需 215 个训练样本；优于传统启发式压缩方法。

3. DualPath: Breaking the Storage Bandwidth Bottleneck in Agentic LLM Inference
3.80
Relevance 3 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 通过双路径 RDMA 传输 KV-Cache，打破预填充-解码分离架构中的存储带宽瓶颈。

Key insight: 在 PD 分离架构中，prefill 引擎的存储网卡带宽饱和而 decode 引擎空闲，DualPath 利用 RDMA 让 KV-Cache 同时从两条路径加载，并做动态负载均衡——这种思路可推广到任何分离式部署场景。

Business connection: 社区搜索中若部署 LLM 用于实时排序或 query 理解，PD 分离架构是常见的生产方案，DualPath 直接解决其中最大的存储带宽瓶颈，可提升在线吞吐。

Evidence: 离线推理吞吐提升 1.87x，在线服务在不违反 SLO 的前提下吞吐提升 1.96x。

4. PrefillShare: A Shared Prefill Module for KV Reuse in Multi-LLM Disaggregated Serving
3.70
Relevance 3 | Novelty 4 | Practical 4 | Evidence 4 | Timely 4

Summary: 在多模型 agent 场景中，通过共享 prefill 阶段实现跨模型 KV 复用，大幅降低延迟和提升吞吐。

Key insight: 多 LLM agent 系统中各模型处理相同上下文会产生大量冗余计算，PrefillShare 将模型分解为 prefill 和 decode 组件，让多个模型共享 prefill 结果，这对搜索系统中的多模型 ensemble 有直接参考价值。

Business connection: 社区搜索中若同时部署多个模型（如召回模型 + 排序模型 + LLM 理解模型），PrefillShare 的共享 prefill 方案可减少重复计算，降低整体延迟和 GPU 开销。

Evidence: 多模型 agent 工作负载下 p95 延迟降低 4.5x，吞吐提升 3.9x，精度与全量微调持平。

9. POP: Prefill-Only Pruning for Efficient Large Model Inference
3.25
Relevance 3 | Novelty 3 | Practical 4 | Evidence 3 | Timely 3

Summary: 发现深层网络在 prefill 阶段冗余而在 decode 阶段必需，提出仅在 prefill 时剪枝深层以加速推理。

Key insight: POP 揭示了一个实用洞察：LLM 深层在处理上下文（prefill）时大量冗余，但在生成 token（decode）时不可或缺，因此可安全地仅在 prefill 阶段移除深层，获得免费加速。

Business connection: 社区搜索中 LLM 处理长 query 或文档的 prefill 是延迟主要来源，POP 可在不影响生成质量的前提下加速 prefill 阶段，降低首 token 延迟 (TTFT)。

Evidence: 在 Llama-3.1 和 Qwen3-VL 上 prefill 延迟加速 1.37x，性能损失最小；优于现有结构化剪枝方法。
