Reasoning in Trees: Improving Retrieval-Augmented Generation for Multi-Hop Question Answering

提出 RT-RAG 框架，将复杂多跳问题分解为推理树结构，通过实体分析和共识选择机制提升 RAG 的多跳问答性能。

INSIGHT将多跳问题建模为推理树而非线性链，能有效区分核心子查询与已知/未知实体，避免了传统迭代 RAG 的错误传播——这对社区搜索中需要跨多篇帖子综合回答的复杂 query 尤为关键。

业务关联社区搜索中常见的「对比帖」「追问链」等多跳 query，可采用 RT-RAG 的树形分解策略在检索阶段拆解子问题，逐步召回并综合答案，提升复杂 query 的回答完整度。

证据在多跳问答基准上 F1 提升 7.0%、EM 提升 6.0%，通过结构化实体分析和共识树选择实现了一致性的改进。

Agentic Reasoning: Reasoning LLMs with Tools for the Deep Research

提出 Agentic Reasoning 框架，通过 Mind-Map Agent 构建知识图谱维护推理上下文，配合 Web-Search Agent 实现深度研究能力。

INSIGHTMind-Map Agent 通过构建知识图谱来管理推理过程中的上下文信息，使开源模型 (DeepSeek-R1) 逼近 OpenAI Deep Research 水平——说明 Agent 架构设计比底层模型能力更关键。

业务关联社区搜索可借鉴 Mind-Map 式的知识图谱构建模式，在用户连续搜索/追问场景中维护上下文状态，提供更连贯的搜索体验和更准确的结果。

证据Humanity's Last Exam 达 23.8%（比基础模型提升 14.4%，接近 OpenAI Deep Research 的 26.6%）；GPQA 达 81.2%（超越 o3-mini-high 的 79.7%）；人工评估中组织性 4.6/5（vs Gemini Deep Research 2.5/5），覆盖度 4.1/5，相关性 4.2/5。

From Web Search towards Agentic Deep Research: Incentivizing Search with Reasoning Agents

系统论述从传统 Web 搜索向 Agentic Deep Research 范式转变的路线，提出搜索推理 Agent 的 test-time scaling law。

INSIGHT提出 test-time scaling law 概念——增加推理时的计算深度可持续提升搜索质量，这为搜索系统的 Agent 化改造提供了理论基础和扩展路径。

业务关联社区搜索的 Agent 化升级可参考该论文的范式转变框架：从单轮召回-排序 pipeline 进化为多轮推理-检索-综合的闭环，并利用 test-time scaling 在复杂 query 上投入更多计算资源以提升质量。

证据在多个基准上显著超越现有方法；提出的 test-time scaling law 得到了实验验证——随着推理计算量增加，搜索质量持续提升。12 所顶尖学术机构联合研究。

Agentic Retrieval-Augmented Generation: A Survey on Agentic RAG

综述 Agentic RAG 体系，将自主 AI Agent 嵌入 RAG 流程，利用反思、规划、工具使用和多 Agent 协作动态管理检索策略。

INSIGHTAgentic RAG 的四大设计模式（反思、规划、工具使用、多 Agent 协作）为 RAG 系统提供了从静态管道到动态智能体的升级路线图——每一种模式都对应不同复杂度的搜索需求。

业务关联社区搜索的 RAG 系统可按该综述的四层模式逐步升级：先引入反思（结果自检）→再加入规划（多步检索策略）→工具使用（调用排序/摘要服务）→最终实现多 Agent 协作处理超复杂 query。

证据综述覆盖医疗、金融、教育等行业应用案例；提出 Agentic RAG 架构分类体系；详细讨论了实现策略和扩展性挑战。GitHub 配套资源库持续更新。

Towards Agentic RAG with Deep Reasoning: A Survey of RAG-Reasoning Systems in LLMs

提出统一框架梳理 RAG 与推理的三类融合模式：推理增强 RAG 各阶段、检索支持多步推理、以及 LLM 迭代交织搜索与推理。

INSIGHTRAG-Reasoning 存在三种渐进融合路径，最高级形态是 LLM 自主交替搜索与推理形成闭环——这为搜索系统选择合适的 Agent 化程度提供了清晰的决策框架。

业务关联社区搜索可根据 query 复杂度选择不同融合层级：简单 query 用推理增强检索，中等复杂度用检索辅助推理，高复杂度 query 启用完整的搜索-推理迭代闭环，实现计算资源的分层投入。

证据综述覆盖 2024-2025 年 RAG-Reasoning 领域主要论文；提出三层融合框架并配合详细分类体系；在知识密集型基准上的对比分析显示迭代式方法持续领先。
