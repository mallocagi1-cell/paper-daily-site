1. Your Embedding Model is SMARTer Than You Think
4.10
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: SMART 是一种 plug-and-play 框架，让标准单向量 embedding 模型在推理时具备多向量（late-interaction）能力。论文先在理论与梯度流上证明：用 pooled embedding 做对比训练时，前序 hidden states 的检索几何已经被隐式塑造；据此在推理阶段对冻结的 token-level hidden states 直接做 late-interaction，即可零训练成本拿到多向量检索的精度收益，在多模态检索基准上稳定改进当前 SOTA。

Key insight: 社区搜索普遍部署的是单向量稠密召回，SMART 提供了一条几乎零成本的“多向量化”升级路径：检索阶段重用已有 single-vector 模型的中间层 hidden states 做 MaxSim 后期交互，不必再训练一个 ColBERT-style 模型。代价是召回侧需要存 token-level embedding 与额外的 late-interaction 计算开销，需要权衡索引体积；但对相关性敏感的关键 query 段（长 query、长 doc）尤其值得加这层。

2. MVR-cache: Optimizing Semantic Caching via Multi-Vector Retrieval and Learned Prompt Segmentation
4.00
Relevance 4 | Novelty 4 | Practical 4 | Evidence 3 | Timely 5

Summary: MVR-cache 把 LLM 语义缓存的“新 prompt 是否命中已缓存 prompt”问题升级为多向量检索：先用一个可学习的 segmentation 模型对 prompt 做细粒度切分，再用 MaxSim 做 segment 级相似度比较；训练目标从理论上对应“严格正确性约束下命中率最大化”，并采用 RL 训练策略，把基于理论的目标作为 reward 来解非可微的组合优化问题。在多个公开语义缓存基准上提升命中率。

Key insight: 社区搜索接入 LLM rerank/总结/Agent 后，语义缓存是降本最直接的杠杆，但传统单向量相似度对“同义但局部改写”的 query 召回不准。MVR-cache 的启示是：把 prompt 切成 segment 再 late-interaction，可以捕捉到“同主题、局部信息变化”的 prompt 等价类；训练时把“严格正确性 + 命中率最大化”写成 RL reward，是工程上把缓存错误率与收益对齐的可行做法。

3. Selective Test-Time Compute Scaling for Click-Through Rate Prediction via Uncertainty-Triggered Feature Path Exploration
3.75
Relevance 4 | Novelty 4 | Practical 3 | Evidence 3 | Timely 5

Summary: UTTSI 把语言模型上"test-time compute scaling"思想移植到工业 CTR：在推理阶段按"每条样本不确定性"动态加深推理深度。它用 logit 置信度 + 数据级频率先验组成双信号估计器，区分认知不确定（epistemic）与偶然模糊（aleatoric）；不确定样本进入自适应 feature filtering，移除不可靠的 embedding 后做 feature path 探索。框架训练无关、模型无关，可挂到现有 CTR 模型上获得增益。

Key insight: CTR 模型固有的非对称性——常见特征组合可信、稀疏组合不可信——长期靠训练阶段的 gating 解决，但 gating 本身受同样稀疏性影响。UTTSI 给社区搜索/推荐的启示是：把推理算力按不确定性分配，把"高置信样本一刀切、低置信样本多算几步"做成 deployment-time 机制；其代价是每 instance 推理预算非定长，对在线服务的资源调度提出新要求。

4. Spectral Retrieval: Multi-Scale Sinc Convolution over Token Embeddings for Localized Retrieval in LLM Multi-Agent Systems
3.75
Relevance 4 | Novelty 4 | Practical 3 | Evidence 3 | Timely 5

Summary: Spectral Retrieval 是一个 plug-in 重排阶段：在标准稠密检索"一个 doc = 一个 mean-pooled 向量"的极端与 ColBERT-style 的 per-token MaxSim 之间做插值。具体做法是复用 late-interaction 索引中的 token-level embedding，再对它们卷上多尺度 normalized sinc 核——尺度 L=1 时退化为 MaxSim，L 增大时趋近于 mean-pooling；在 1000 doc + 单 spike 的可控合成基准上，mean-pool 几乎随机（Recall@10≈0.02），Spectral Retrieval 能稳定召回。

Key insight: 社区 UGC 短文本里相关性常常聚焦在某个短 span（关键词、品牌词、地理实体），mean-pool 对此最不友好。Spectral Retrieval 的实用价值在于：给已有 multi-vector 索引一种"无须重训、可调粒度"的重排器，把信息量介于 MaxSim 与 mean-pool 之间的中间尺度也用上。代价是合成基准为主、真实业务集上的稳健性需自己验证。
