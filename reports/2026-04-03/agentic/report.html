Experience as a Compass: Multi-agent RAG with Evolving Orchestration and Agent Prompts

针对多智能体 RAG 系统中静态行为和固定编排导致多跳任务表现脆弱的问题，提出 HERA 框架，在全局层面通过奖励引导采样和经验积累优化查询特定的 agent 拓扑结构，在局部层面通过角色感知提示进化（Role-Aware Prompt Evolution）基于信用分配和双轴自适应来优化各 agent 行为。该方法实现了编排策略和角色提示的联合演化，可直接应用于搜索推荐场景中的复杂多步检索和推理任务。

Asymmetric Actor-Critic for Multi-turn LLM Agents

提出非对称 Actor-Critic 框架，用于提升多轮 LLM agent 的可靠性。利用强大的商业 LLM 作为 actor 执行任务，同时训练小型开源 critic 在同一交互轨迹内实时监督并干预。巧妙利用了生成-验证不对称性：高质量生成困难但验证相对容易。该设计不需要修改 actor 模型参数，可直接应用于商业 API 场景。

INSIGHT核心创新在于将 actor-critic 的不对称性应用到 LLM agent 场景——大模型生成、小模型监督，实现了不改模型参数即可提升可靠性的实用方案。这对搜索场景下使用商业 LLM API 构建多轮搜索 agent（如 deep research）非常有价值：可以在推理过程中实时纠偏检索策略，避免级联错误。生成-验证的计算不对称性也可用于搜索排序中的 reranker 验证。

Oblivion: Self-Adaptive Agentic Memory Control through Decay-Driven Activation

提出 Oblivion 记忆控制框架，将遗忘建模为可访问性的衰减驱动降低而非显式删除。将记忆控制解耦为读写路径：读路径根据 agent 不确定性和缓冲充足度决定何时查询记忆（避免冗余的 always-on 检索）；写路径通过强化对回答有贡献的记忆来决定保留什么。这种分层记忆组织在保持高层策略的同时动态加载细节，显著降低长历史场景下的干扰和延迟。

INSIGHTOblivion 将认知科学中的衰减-重激活记忆模型引入 LLM agent，核心价值在于按需检索替代始终检索。对搜索推荐系统的启示：(1) 用户建模中可采用类似衰减机制管理长期行为历史；(2) agent 搜索中的上下文管理可借鉴读写路径分离设计减少无效检索调用；(3) 层次化记忆组织可用于构建更高效的多轮对话搜索系统。

DeepResearcher: Scaling Deep Research via Reinforcement Learning in Real-world Environments

首个针对 LLM deep research agent 的端到端 RL 训练框架，直接在真实 web 搜索环境中训练，而非在封闭 RAG 语料库上。相比提示工程基线提升 28.9 分，相比 RAG-based RL agent 提升 7.2 分。训练过程中自发涌现了计划制定、跨源交叉验证、自我反思和诚实拒答等认知行为。开源代码可用。

INSIGHTDeepResearcher 的核心突破在于证明了直接在开放 web 环境中端到端训练搜索 agent 的可行性和优越性。对搜索系统实践者而言：(1) RL 训练可在真实搜索引擎交互中完成，无需构建封闭语料库；(2) 涌现的认知行为（规划、交叉验证、自省）为设计搜索 agent pipeline 提供了参考架构；(3) 开源框架可直接用于训练垂域搜索 agent。

Agent Q-Mix: Selecting the Right Action for LLM Multi-Agent Systems through Reinforcement Learning

提出 Agent Q-Mix，将多 agent LLM 系统的拓扑选择重新表述为协作式多智能体强化学习（MARL）问题。使用 QMIX 值分解学习去中心化的通信决策，每个 agent 从通信动作集中选择以联合构建轮次级通信图。核心架构结合拓扑感知 GNN 编码器、GRU 记忆和 per-agent Q-heads，在 CTDE 范式下训练。在七项核心基准上评估，奖励函数平衡任务准确率和 token 成本。

INSIGHTAgent Q-Mix 将多 agent 协作通信的拓扑结构优化问题转化为 MARL 问题，使用 QMIX 实现了集中训练分布式执行的范式。对搜索推荐实践的启示：(1) 多阶段搜索 pipeline 中各模块的通信和协调可用类似框架建模；(2) 拓扑感知 GNN 加 QMIX 的组合方法可用于优化多 agent 搜索系统的路由和调度决策。

06 3.90

ARPO: Agentic Reinforced Policy Optimization

RUC

ARPO 是专为多轮 LLM agent 训练设计的强化学习算法（ICLR 2026）。核心发现：LLM 在外部工具交互后会展现高度不确定行为（生成 token 的熵分布增大）。据此提出基于熵的自适应 rollout 机制，在工具调用后的高不确定性时刻增强探索；同时引入优势归因估计，使 LLM 内化逐步工具交互的优势差异。在 13 项基准上仅用一半工具调用预算即超越 trajectory-level RL 算法。

INSIGHTARPO 揭示了 LLM agent 训练中的关键洞察：工具交互后的熵激增是训练瓶颈，需要在这些时刻增强探索而非压制。这对搜索 agent 的 RL 训练有直接指导意义：(1) 在搜索引擎返回结果后 agent 面临最大不确定性，应在此处设计更精细的探索策略；(2) 逐步优势归因可帮助 agent 学习哪些检索步骤真正有贡献；(3) 节省一半工具调用预算意味着显著降低推理成本。

Internal APIs Are All You Need: Shadow APIs, Shared Discovery, and the Case Against Browser-First Agent Architectures

指出自主 agent 与为人类设计的 web 界面之间存在根本不匹配。提出 Unbrowse 系统，通过共享路由图将浏览器端的路由发现转化为可调用的第一方接口索引。系统从真实浏览流量中被动学习路由，通过直接 API 调用服务缓存路由。在 94 个域的信息检索任务中，完全预热的缓存执行比浏览器首选架构快数倍。这为 Agentic Web 提供了一种结构性解决方案。

INSIGHTUnbrowse 揭示了 agent 系统设计的重要范式转变：与其让 agent 模拟人类浏览行为（慢且脆弱），不如直接调用网站已有的内部 API。对搜索系统的启示：(1) 搜索 agent 应优先使用结构化 API 而非网页解析；(2) 共享路由图的概念可扩展为搜索 agent 的工具注册表，减少重复的接口发现开销；(3) 这种方法可将搜索 agent 的延迟降低一个数量级。

Agentic Tool Use in Large Language Models

系统性综述了 LLM agent 的工具使用能力，将现有文献组织为三种范式：提示即插即用（prompting as plug-and-play）、监督式工具学习（supervised tool learning）和奖励驱动的工具策略学习（reward-driven tool policy learning）。分析了各范式的方法、优势和失败模式，梳理了评估体系并指出关键挑战。填补了当前工具使用研究碎片化的空白。

INSIGHT作为综述，该论文的价值在于提供了 LLM 工具使用的统一演化视角。三种范式的分类对搜索系统实践者的选型有直接指导：(1) 快速原型阶段用 prompting；(2) 生产系统需要 supervised learning 保证可靠性；(3) 最优性能需要 RL-based 策略学习但成本较高。失败模式分析可帮助搜索 agent 开发者提前规避常见陷阱。

When Users Change Their Mind: Evaluating Interruptible Agents in Long-Horizon Web Navigation

首次系统研究了长序列 web 导航任务中可中断 agent 的行为。形式化定义了三种中断类型（添加、修改、撤回），并构建了 InterruptBench 基准（基于 WebArena-Lite）。在统一的中断模拟框架下评估了六种强 LLM agent。发现当前 agent 在状态持久化的环境中处理中途需求变更时表现显著下降。

INSIGHT该研究揭示了当前 LLM agent 的关键短板：无法优雅地处理用户中途改变意图。对搜索 agent 实践的启示：(1) deep research 类产品必须支持用户中途修改搜索目标而非从头开始；(2) agent 状态管理需要设计部分回滚机制；(3) 三种中断类型的形式化为搜索 agent 的需求变更处理提供了设计框架。这是搜索 agent 从实验走向生产的必要能力。

OmniMem: Autoresearch-Guided Discovery of Lifelong Multimodal Agent Memory

利用自主研究 pipeline 发现 OmniMem，一个用于终身 AI agent 的统一多模态记忆框架。从朴素基线（LoCoMo 上 F1=0.117）出发，pipeline 自主执行约 50 次实验，诊断失败模式、提出架构修改并修复数据管道 bug，全程无需人工干预。最终系统在 LoCoMo 上 F1 提升 411%（0.117 到 0.598），在 A-LoCoMo 上提升 172%（0.250 到 0.681），达到 SOTA。

INSIGHTOmniMem 的方法论创新在于用自动研究替代人工设计来发现最优记忆架构，这本质上是 NAS 思想在 agent 记忆系统上的应用。对搜索推荐实践者而言：(1) 自动化实验 pipeline 可用于搜索 agent 的超参和架构搜索；(2) 多模态终身记忆是搜索 agent 处理用户长期偏好的关键模块；(3) 411% 的 F1 提升说明记忆系统设计空间巨大，值得投入自动化探索。
