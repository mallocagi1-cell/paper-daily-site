PinRec: Outcome-Conditioned, Multi-Token Generative Retrieval for Industry-Scale Recommendation Systems

Pinterest 提出的工业级生成式检索模型 PinRec，使用 outcome-conditioned generation 让建模者灵活控制多个业务指标（如 save、click）的平衡，并引入 multi-token generation 提升输出多样性。在 Pinterest 实际场景中成功部署，超越传统 two-tower 架构。

KEY INSIGHT · 对业务意味着什么生成式检索可以通过 outcome conditioning 实现多目标可控生成，这比传统的 two-tower + 多目标排序更灵活；multi-token 生成策略解决了自回归生成多样性不足的问题。业务关联 对搜索推荐场景高度相关：生成式检索替代传统召回架构，outcome conditioning 可用于平衡搜索相关性和点击率等多目标。证据 在 Pinterest 工业级数据上验证，PinRec 在 Recall@K 和业务指标上均超越 two-tower baseline，multi-token 生成比标准自回归方式提升了候选多样性。

Can LLMs Outshine Conventional Recommenders? A Comparative Evaluation

提出 RecBench 基准，系统性地对比 LLM-based 推荐器与传统推荐模型。探索了多种 item 表示形式（唯一 ID、文本、语义嵌入、语义 ID），在 CTR 预估和序列推荐两个核心任务上进行全面评测。

INSIGHTLLM 推荐器在 CTR 场景中 AUC 提升最多 5%，在序列推荐中 NDCG@10 提升高达 170%，但效果高度依赖 item 表示形式的选择——语义 ID 表示在生成式推荐中表现最佳。

业务关联直接回答了搜索推荐从业者最关心的问题：LLM 能否替代传统模型？实验结论帮助团队评估是否以及如何引入 LLM 做 CTR 预估或序列推荐。

证据在多个公开数据集上进行系统评测，LLM 在 CTR 任务上 AUC 提升 ~5%，在 SeqRec 上 NDCG@10 提升高达 170%。对比了 4 种不同 item 表示方式。

Rec-R1: Bridging Generative Large Language Models and User-Centric Recommendation Systems via Reinforcement Learning

提出 Rec-R1 框架，通过强化学习将 LLM 生成能力与推荐系统进行闭环对齐。核心思路：将推荐模型视为黑盒环境，LLM 作为策略模型，直接用推荐反馈优化 LLM 的生成行为。

INSIGHT将 R1 式 RL 训练范式（类似 DeepSeek-R1）引入推荐场景，实现 LLM 生成与推荐目标的闭环优化，无需修改底层推荐模型即可适配。这为'LLM-as-recommender'提供了可扩展的对齐方案。

业务关联对于已有推荐系统想引入 LLM 能力的团队非常相关：Rec-R1 允许将现有推荐模型作为黑盒，通过 RL 训练 LLM 来增强推荐效果，降低迁移成本。

证据在多个推荐基准上验证，Rec-R1 相比 SFT 方式训练的 LLM 推荐器显著提升推荐质量，闭环 RL 优化带来的提升在序列推荐任务上尤为明显。

04 3.90

Process-Supervised LLM Recommenders via Flow-guided Tuning

提出 Flower 框架，用生成式流网络（GFlowNet）替代传统 SFT 来微调 LLM 推荐器。核心发现：SFT 训练的 LLM 推荐器会放大流行度偏差，而 Flower 通过过程监督（process supervision）引导生成多样性，缓解马太效应。

INSIGHTLLM 做推荐时的流行度偏差问题首次被系统性分析并解决：GFlowNet 框架让 LLM 以正比于奖励的概率采样推荐结果，而非贪心选择最高概率的 item，从根本上提升推荐多样性。

业务关联搜索推荐中的流行度偏差是长期痛点。如果团队考虑用 LLM 做推荐，Flower 提供的 GFlowNet 微调方案可以有效缓解冷门内容曝光不足的问题。

证据在推荐基准数据集上实验，Flower 相比 SFT 微调的 LLM 推荐器在多样性指标上显著提升，同时保持推荐准确性。消融实验验证了过程监督的有效性。

05 3.30

Towards Next-Generation Recommender Systems: a Benchmark for Personalized Recommendation Assistant with LLMs

构建了一个评估 LLM 作为个性化推荐助手的综合基准。涵盖多种 query 类型（直接推荐请求、偏好描述、对话式交互），系统评估不同 LLM 在推荐助手角色下的表现。

INSIGHTLLM 推荐助手的能力高度依赖 query 类型：在明确推荐请求上表现较好，但在需要深度偏好理解的对话场景中仍有明显差距。基准揭示了 LLM 推荐从'能用'到'好用'的关键瓶颈。

业务关联为搜索推荐团队评估引入 LLM 推荐助手提供了标准化基准，帮助量化 LLM 在不同交互模式下的实际能力边界。

证据在构建的基准上评估了多种主流 LLM（包括 GPT-4、Llama 等），给出了不同 query 类型下的详细对比结果。

06 3.30

REGEN: A Dataset and Benchmarks with Natural Language Critiques and Narratives

发布 REGEN 数据集，包含自然语言批评和叙事性偏好描述，用于评测推荐 LLM 的对话能力。弥补了现有数据集仅关注序列 item 预测、缺乏自然语言交互评测的空白。

INSIGHT现有推荐 LLM 评测数据集过于简化（仅 item ID 序列），REGEN 引入自然语言批评（'我不喜欢这个因为...'）和叙事偏好，更贴近真实用户交互，揭示了当前模型在理解否定偏好方面的不足。

业务关联对于想要构建对话式推荐系统的团队，REGEN 提供了更贴近真实场景的评测基准，特别是在处理用户负反馈和复杂偏好表达方面。

证据在 REGEN 数据集上评测了多个推荐 LLM，结果显示现有模型在处理自然语言批评和复杂叙事偏好时性能显著下降。

ChatSearch: a Dataset and a Generative Retrieval Model for General Conversational Image Retrieval

提出 ChatSearcher——面向开放域图像的对话式生成检索模型，支持多轮多模态对话作为检索 query。模型端到端训练，可接受交错的图文输入输出，在多模态上下文推理和世界知识利用方面表现出色。

INSIGHT将生成式检索扩展到多模态对话场景：不再是简单的 query→结果，而是通过多轮对话逐步精化检索意图。这为搜索系统引入对话式交互提供了生成式检索的技术路径。

业务关联多模态对话式检索是搜索系统的演进方向。ChatSearcher 展示了如何用生成式模型统一处理多轮对话理解和检索，可为社区搜索中的图文混合搜索场景提供参考。

证据在自建的 ChatSearch 数据集上取得最佳结果，在其他图像检索任务和视觉对话任务上也达到了有竞争力的表现。

Zijia Zhao, Longteng Guo, Tongtian Yue, Erdong Hu, Shuai Shao

A Survey of Large Language Model Empowered Agents for Recommendation and Search: Towards Next-Generation Information Retrieval

全面综述 LLM Agent 在推荐和搜索中的应用，系统梳理了 LLM Agent 的架构设计（规划、记忆、工具使用、多 Agent 协作）在信息检索任务中的应用方式和发展趋势。

INSIGHTLLM Agent 正在重塑搜索推荐系统的架构范式，从'模型即系统'转向'Agent 即系统'。综述总结了规划（Planning）、记忆（Memory）和工具使用（Tool Use）三大核心能力在搜推场景的具体应用模式。

业务关联为搜索推荐团队提供了 LLM Agent 应用的全景式参考。综述涵盖的多种架构模式可帮助团队评估哪种 Agent 范式最适合自身业务场景。

证据综述论文，汇总了大量已发表的研究成果和工业实践案例，但未提供新的实验数据。
