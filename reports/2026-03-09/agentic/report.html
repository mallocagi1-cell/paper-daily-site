SIGHT: Reinforcement Learning with Self-Evidence and Information-Gain Diverse Branching for Search Agent

提出 SIGHT 框架，通过自证据支持和信息增益驱动的多样分支机制，解决搜索 Agent 多轮检索中的「隧道视野」问题。

偏好调整 4.20
KEY INSIGHT · 对业务意味着什么搜索 Agent 在多轮检索时容易被早期噪声结果锁定，SIGHT 通过信息增益分数识别关键决策节点，在这些节点触发去重、反思或自适应分支，有效打破错误累积链。这对构建多轮迭代检索的搜索系统有直接参考价值。业务关联 社区搜索中，复杂 query 往往需要多轮检索和推理。SIGHT 的信息增益分支策略可用于优化搜索 Agent 在多步推理场景中的检索质量，减少噪声结果对最终排序的干扰。证据 在多轮搜索问答任务上，SIGHT 通过 Self-Evidence Support 将检索信噪比显著提升，Information Gain 驱动的分支机制在关键决策节点有效减少冗余，整体问答准确率优于基于 GRPO 的基线方法。
Wenlin Zhong, Jinluan Yang, Yiquan Wu, Yi Liu, Jianhang Yao, Kun Kuang · 2026-02-12 · arXiv

Exploring Reasoning Reward Model for Agents

提出 Agent-RRM 多维奖励模型，为 Agent 轨迹生成推理链、针对性批评和过程评分三层结构化反馈。

INSIGHT当前 Agentic RL 主要依赖稀疏的结果奖励，无法区分中间推理质量。Agent-RRM 通过多层反馈信号（推理链 + 缺陷批评 + 过程评分）提供细粒度的过程监督，显著提升 Agent 在复杂工具调用和搜索任务上的表现。

业务关联在搜索场景中训练 Agent 进行多步检索和推理时，细粒度的过程奖励模型可替代粗粒度的结果奖励，有助于提升搜索 Agent 的检索策略学习效率和最终答案质量。

证据在 12 个基准测试上评估，GAIA 达到 43.7%，WebWalkerQA 达到 46.2%，相比纯结果奖励的 Agentic RL 方法有显著提升。

Kaixuan Fan et al.

DeerFlow: A Modular Multi-Agent Framework for Deep Research Automation

ByteDance

字节跳动开源多 Agent 深度研究框架 DeerFlow V2，结合搜索、爬虫、沙箱和记忆管理实现自动化研究。

INSIGHTDeerFlow 采用模块化多 Agent 架构，将深度研究拆分为规划、执行、反思等子 Agent，V2 版本新增沙箱执行和记忆管理。作为工业级开源项目（GitHub Trending #1），它为构建基于搜索的 Agent 系统提供了可直接复用的工程实践。

业务关联DeerFlow 的多 Agent 架构和搜索集成方案可为社区搜索场景中构建深度研究 Agent（如自动化信息聚合、多源检索综合）提供参考框架和可复用组件。

证据2026 年 2 月 28 日 V2 版本发布后登上 GitHub Trending 第一名，项目获得社区广泛关注。支持 16K+ 工具集成，提供完整的多 Agent 编排能力。

Agentic Reasoning for Large Language Models

系统性综述 Agentic Reasoning，将 LLM 从静态推理重构为能规划、执行和持续学习的自主 Agent 范式。

INSIGHT该综述将 Agentic Reasoning 分为三层：基础单 Agent 能力（规划、工具使用、搜索）、自进化能力（反馈、记忆、适应）和多 Agent 协作（协调、知识共享）。这个分层框架为搜索推荐从业者理解和设计 Agent 系统提供了清晰的架构指南。

业务关联综述中关于搜索 Agent 的规划和工具使用模式，可直接指导社区搜索中 LLM Agent 的系统设计，特别是多步检索和自适应查询改写场景。

证据综述覆盖科学、机器人、医疗、自主研究、数学等多个应用领域的代表性框架和基准，提供了 Agentic Reasoning 领域的全面技术图谱，配套 GitHub 资源库收录 200+ 篇相关论文。

Tianxin Wei et al.

Step-DeepResearch Technical Report

SStepFun

阶跃星辰发布 32B 参数的 Deep Research Agent 模型，通过原子能力分解和 Agent 中训练实现高性价比深度研究。

INSIGHTStep-DeepResearch 将 Deep Research 分解为可训练的原子能力（领域知识、高层规划、行为反思、信息摘要、跨源验证），并针对每种能力合成训练数据进行 agentic mid-training。这种能力分解方法论对训练搜索 Agent 有重要参考价值。

业务关联Step-DeepResearch 的原子能力分解思路可用于训练社区搜索中的 Agent：例如将复杂搜索任务拆分为 query 理解、多步检索、结果验证等子能力分别训练，再端到端整合。

证据在 Scale AI ResearchRubrics 上得分 61.42，仅 32B 参数。在 ADR-Bench 专家评估中 Elo 分数显著超越同规模模型，接近 OpenAI DeepResearch 和 Gemini DeepResearch 的表现。

StepFun Agent Team
