1. SIGHT: Reinforcement Learning with Self-Evidence and Information-Gain Diverse Branching for Search Agent
4.20
Relevance 4 | Novelty 5 | Practical 4 | Evidence 4 | Timely 3

Summary: 提出 SIGHT 框架，通过自证据支持和信息增益驱动的多样分支机制，解决搜索 Agent 多轮检索中的「隧道视野」问题。

Key insight: 搜索 Agent 在多轮检索时容易被早期噪声结果锁定，SIGHT 通过信息增益分数识别关键决策节点，在这些节点触发去重、反思或自适应分支，有效打破错误累积链。这对构建多轮迭代检索的搜索系统有直接参考价值。

Business connection: 社区搜索中，复杂 query 往往需要多轮检索和推理。SIGHT 的信息增益分支策略可用于优化搜索 Agent 在多步推理场景中的检索质量，减少噪声结果对最终排序的干扰。

Evidence: 在多轮搜索问答任务上，SIGHT 通过 Self-Evidence Support 将检索信噪比显著提升，Information Gain 驱动的分支机制在关键决策节点有效减少冗余，整体问答准确率优于基于 GRPO 的基线方法。

2. Exploring Reasoning Reward Model for Agents
4.05
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 3

Summary: 提出 Agent-RRM 多维奖励模型，为 Agent 轨迹生成推理链、针对性批评和过程评分三层结构化反馈。

Key insight: 当前 Agentic RL 主要依赖稀疏的结果奖励，无法区分中间推理质量。Agent-RRM 通过多层反馈信号（推理链 + 缺陷批评 + 过程评分）提供细粒度的过程监督，显著提升 Agent 在复杂工具调用和搜索任务上的表现。

Business connection: 在搜索场景中训练 Agent 进行多步检索和推理时，细粒度的过程奖励模型可替代粗粒度的结果奖励，有助于提升搜索 Agent 的检索策略学习效率和最终答案质量。

Evidence: 在 12 个基准测试上评估，GAIA 达到 43.7%，WebWalkerQA 达到 46.2%，相比纯结果奖励的 Agentic RL 方法有显著提升。

Summary: 阶跃星辰发布 32B 参数的 Deep Research Agent 模型，通过原子能力分解和 Agent 中训练实现高性价比深度研究。

Key insight: Step-DeepResearch 将 Deep Research 分解为可训练的原子能力（领域知识、高层规划、行为反思、信息摘要、跨源验证），并针对每种能力合成训练数据进行 agentic mid-training。这种能力分解方法论对训练搜索 Agent 有重要参考价值。

Business connection: Step-DeepResearch 的原子能力分解思路可用于训练社区搜索中的 Agent：例如将复杂搜索任务拆分为 query 理解、多步检索、结果验证等子能力分别训练，再端到端整合。

Evidence: 在 Scale AI ResearchRubrics 上得分 61.42，仅 32B 参数。在 ADR-Bench 专家评估中 Elo 分数显著超越同规模模型，接近 OpenAI DeepResearch 和 Gemini DeepResearch 的表现。
