Bridging Sequential and Contextual Features with a Dual-View of Fine-grained Core-Behaviors and Global Interest-Distribution

针对传统 CTR 模型将用户行为序列聚合为单一向量后再与上下文特征交互导致行为信息丢失的问题，提出双视角建模框架：一方面通过细粒度核心行为视角精准捕捉用户与候选物品的关键交互信号，另一方面通过全局兴趣分布视角建模用户整体偏好的宏观分布特征。该方法在保持计算效率的同时，避免了朴素逐行为交互带来的噪声问题，有效提升了对用户实时兴趣变化的感知能力。

1. 问题与动机

CTR 预估任务的核心在于建模用户行为序列与候选物品上下文特征之间的交互。现有方法面临一个根本性的 trade-off：传统方案（如 DIN、DIEN）先将用户行为序列通过各种 pooling 方式压缩为单一向量，再与上下文特征交互，这种「先聚合后交互」的范式不可避免地丢失了行为级别的细粒度信息，导致模型无法捕捉特定行为与上下文特征之间的精准关联。而另一极端方案（如 OneTrans）将完整行为序列展开与上下文特征做联合注意力交互，虽然保留了细节但计算复杂度为 O((L+N_f)²)，且大量无关行为引入显著噪声。中间方案（多窗口聚合）虽降低了计算量，但本质上仍在聚合阶段丢失信息。本文提出的 CDNet（Core-behavior Dual-view Network）试图在这两个极端之间找到最优平衡点。

2. 方法详解

CDNet 由三个核心模块构成：

细粒度核心行为模块（Core-Behaviors Module）：首先计算候选物品特征与每个历史行为的余弦相似度 a_j = (f_i^T·s_j / (||f_i||·||s_j||) + 1) / 2，然后通过 top-k 选择机制筛选出与候选物品最相关的 k 个核心行为。选择过程使用 Straight-Through Estimator（STE）解决 top-k 操作的不可微问题：前向传播使用离散 mask 做硬选择，反向传播将 mask 近似为可微概率。在 Taobao 数据集上 k=16（序列长度 600），工业数据集上 k=100（序列长度 1600）。

全局兴趣分布模块（Global Interest-Distribution Module）：将相似度区间 [0,1] 等分为 n 个区间（默认 n=5），统计每个区间内的行为数量构成兴趣分布直方图，再通过 embedding 将计数转化为稠密表征。该模块的设计意图是保留完整行为序列的宏观分布信息——即使某些行为未被选为核心行为，其兴趣倾向仍通过分布统计被捕获。

特征交互与预测层：将 k 个核心行为 + 1 个兴趣分布向量 + N_f 个上下文特征拼接，输入标准 Transformer 进行联合注意力交互。最终通过 MLP 输出点击概率，使用交叉熵损失训练。核心优势在于交互矩阵从 OneTrans 的 (L+N_f)² 降为 (k+1+N_f)²，其中 k << L。

3. 核心技术贡献

贡献一：双视角互补建模。细粒度核心行为提供局部精准匹配信号，全局兴趣分布提供宏观偏好概览，两者在信息粒度上形成互补。消融实验证实两者都不可或缺：移除核心行为模块 AUC 下降 0.18%，移除兴趣分布模块 AUC 下降 0.08%。

贡献二：噪声与信号的平衡。通过 top-k 选择机制过滤无关行为噪声，同时通过分布统计保留全局信息。实验表明，全序列展开（k/L=1）反而不如最优选择比例，证明了行为选择去噪的必要性。

贡献三：计算效率与精度的 Pareto 改进。在工业级 7B 交互数据上，CDNet 相比 OneTrans 在 AUC 和 GAUC 上均有提升，同时序列交互规模从 1600 降为 100+1+N_f。

4. 实验结果分析

在 Taobao 公开数据集（8900万条记录）上，CDNet 相比最强基线 OneTrans 在 AUC 上提升 +0.58%（0.6351→0.6388），GAUC 提升 +0.33%（0.6319→0.6340）。在工业数据集（70亿交互）上，AUC 提升 +0.12%（0.7239→0.7248），GAUC 提升 +0.26%（0.6214→0.6230）。

对比基线覆盖了三类方案：（1）聚合方案（DCN/AutoInt/Hiformer/Wukong/RankMixer + Mean/Target-attention/Self-attention pooling）；（2）联合交互方案（InterFormer、OneTrans）。CDNet 在所有基线组合中均取得最优。值得注意的是，Hiformer+Target-attention pooling 和 Wukong+Self-attention pooling 这些较强的聚合基线与 OneTrans 差距不大，说明聚合方案的天花板已接近联合交互方案。

消融实验在工业数据集上进行：移除核心行为（CDNet-RCore）AUC 从 0.7248 降至 0.7230（-0.18%），移除兴趣分布（CDNet-RGid）AUC 降至 0.7240（-0.08%）。核心行为模块的贡献约为兴趣分布的 2 倍，这与直觉一致——局部精准匹配比全局统计更关键。

在线 A/B 测试：在大规模电商平台部署 10 天，CDNet 实现 CTR 相对提升 2.24%，且无额外推理延迟开销。

5. 局限与未来方向

论文未显式陈述局限性。主要隐含局限包括：（1）核心行为数量 k 和分布区间数 n 需要针对数据集调优，论文未提供系统的选择指南；（2）未讨论冷启动场景下行为序列过短时双视角方法的表现；（3）兴趣分布模块使用简单的等间距分箱，未探索自适应分箱策略。

6. 工业实践意义

CDNet 对搜索推荐系统有三个直接实践价值：

可迁移的架构范式：「核心行为选择 + 全局分布补偿」的双视角设计适用于任何需要处理长行为序列的排序模型。在 UGC 社区搜索中，可将用户的浏览、点击、收藏行为分别建模为不同信号源，用核心行为捕捉与当前查询最相关的行为，用分布模块反映用户的整体内容偏好。

零延迟部署友好：在线实验确认无额外推理延迟，这对延迟敏感的 CTR 场景至关重要。核心行为选择本质上是一次 top-k 操作，兴趣分布是简单的分箱计数，两者的计算开销远低于节省的注意力计算。

增量优化路径：该方法不要求替换现有模型架构，只需在序列建模模块中引入核心行为选择和分布补偿，适合在现有 CTR 模型上做增量迭代。线上 2.24% 的 CTR 提升在工业级别是相当显著的。

Deferred is Better: A Framework for Multi-Granularity Deferred Interaction of Heterogeneous Features

Alibaba📖 有深读 · 7 分钟

揭示了 CTR 预估中特征异构性（categorical vs numerical、稀疏 vs 稠密）被普遍忽视的问题：现有模型将所有特征同时输入交互层，导致低信息量特征注入噪声、掩盖高信息量特征信号，甚至引发模型坍缩。提出多粒度信息感知延迟交互框架（MGID），根据特征的信息密度分层引入交互，先让高信息量特征建立稳健表征，再逐步融入低信息量特征，从而学习更鲁棒的特征表征。

INSIGHT「延迟交互」思想对工业 CTR 系统有直接启发：在实际特征工程中，ID 类特征（极稀疏）与统计类特征（相对稠密）的信息密度差异巨大，一刀切的特征交互策略确实可能导致稀疏特征的噪声信号干扰稠密特征的学习。该框架提供了一种即插即用的特征交互改进思路——按信息粒度分层交互，不需要改变现有模型架构，适合在现有 CTR 模型上做增量优化。

1. 问题与动机

当前主流 CTR 模型（DeepFM、DCN、AutoInt 等）对所有特征采用统一的交互策略——将全部特征同时输入交互层进行建模。论文指出这种「一刀切」策略忽视了特征的固有异构性：categorical 特征（如 item ID）极度稀疏，其 embedding 在训练初期严重欠拟合；而 numerical 特征（如价格、时长）则相对稠密、信息量充足。当稀疏特征的噪声表征过早参与交互时，其噪声信号会「淹没」稠密特征的有效信号，导致学到的表征质量退化甚至出现灾难性坍缩（representation collapse）。已有工作通过多模态语义来缓解 item ID 的稀疏问题，但忽略了其他特征之间同样存在的信息密度差异，形成性能瓶颈。

2. 方法详解

MGDIN（Multi-Granularity Deferred Interaction Network）包含两个核心阶段：

阶段一：多粒度特征分组（Multi-Granularity Feature Grouping）。将 n 个原始特征按不同窗口大小分组，K 个并行窗口分支同时操作，第 h 个窗口的粒度为 g_h。每个分支将相邻 g_h 个特征拼接为一个组，产生 n/g_h 个特征组。例如工业配置使用 K=4 个并行窗口，粒度分别为 {32, 64, 96, 128}。多粒度设计的目的是在不同抽象层级上捕捉特征间的信息密度模式。

阶段二：信息感知延迟交互（Information-Aware Deferred Interaction）。核心创新在于分层掩码策略：

  1. 在第 0 层计算初始注意力分数矩阵 A_0^h，反映特征组之间的原始信息关联强度
  2. 在第 l 层，通过 Top-k_l 掩码选择性地激活特征交互：Z_l^h = [(Q·K^T) ⊙ I(A_0 ∈ Top-k_l)] · V
  3. 激活阈值随层数线性递增：k_l = ⌊(l/L)·n²⌋，第 1 层只激活约 1/L 的交互对，逐层增加直到最后一层激活全部

这种设计确保信息量丰富的特征（注意力分数高）优先参与交互建立稳健表征，而稀疏/欠训练的特征被「延迟」到后续层才逐步引入。每层后接残差连接、Layer Normalization 和 Per-token FFN。

预测层：K 个窗口分支的输出通过 Pooling 聚合后输入 MLP 预测点击概率，使用标准交叉熵损失训练。

工业数据集配置：3 层交互、4 个并行窗口（粒度 32/64/96/128）、逐层稀疏比 {0.33, 0.66, 1.0}。Amazon-Sports 配置：3 层、2 个窗口（粒度 2/4）。

复杂度分析：空间复杂度为 Σ(n/g_h)²，通常小于标准注意力的 O(n²)；时间复杂度为 max{(n/g_h)²}，因为 K 个窗口并行计算。

3. 核心技术贡献

贡献一：首次将「延迟交互」概念引入 CTR 特征建模。不同于此前所有工作将特征同时输入交互层的做法，MGDIN 根据特征的信息密度决定其参与交互的时机。高信息量特征优先交互、建立稳健表征后，再逐步引入低信息量特征，从根本上避免了噪声信号对有效信号的干扰。实验验证移除延迟交互（w/o DI）导致 AUC 从 0.6994 降至 0.6971。

贡献二：多粒度并行策略。通过不同窗口粒度在多个抽象层级上同时捕捉特征交互模式，缓解了信息分布不均匀的问题。移除多粒度（w/o MG，退化为单窗口）AUC 从 0.6994 降至 0.6964，降幅大于移除延迟交互。

贡献三：基于初始注意力的交互调度。利用第 0 层计算的注意力分数作为特征信息密度的代理指标，指导后续各层的交互激活顺序。这避免了需要显式定义「特征信息量」的困难——让模型自动通过注意力机制发现哪些特征对应该优先交互。

4. 实验结果分析

公开数据集 Amazon-Sports：MGDIN 相比最强基线 OneTrans 在 AUC 上提升 +0.21%（0.6775→0.6789），GAUC 提升 +0.41%（0.6517→0.6544）。对比基线涵盖经典模型（FM、DNN、Wide&Deep、DeepFM、DCN）和近期模型（AutoInt、GDCN、MaskNet、RankMixer、OneTrans）。

工业数据集（70亿交互）：MGDIN 相比 OneTrans 在 AUC 上提升 +0.54%（0.6956→0.6994），GAUC 提升 +0.25%（0.5921→0.5936）。值得注意的是工业数据集上 MGDIN 相比 OneTrans 的提升（AUC +0.54%）远大于公开数据集（+0.21%），说明特征异构性问题在大规模真实数据中更为严重。

消融实验（工业数据集）：

  • 完整 MGDIN：AUC 0.6994，GAUC 0.5936
  • w/o MG（单窗口）：AUC 0.6964（-0.43%），GAUC 0.5910（-0.44%）
  • w/o DI（无延迟交互）：AUC 0.6971（-0.33%），GAUC 0.5917（-0.32%）

多粒度模块的贡献略大于延迟交互模块，两者均不可缺。

超参数分析：（1）窗口数量 K 增加通常带来性能提升；（2）延迟比例 k_l 的变化对性能影响较小，论文解释为「稀疏特征在数据集中占比不大，关键是确保它们被延迟到后期阶段引入」。

在线 A/B 测试：在主要电商平台部署 10 天，MGDIN 实现 CTR 相对提升 3.04%，无额外推理延迟。

5. 局限与未来方向

论文未显式列出局限性。隐含局限包括：（1）多粒度窗口的粒度配置（如 {32, 64, 96, 128}）需要手动设定，未提供自动搜索方案；（2）延迟交互的线性递增策略（k_l = l/L·n²）可能不是最优调度策略；（3）该方法目前仅在广告 CTR 场景验证，尚未在其他推荐任务（如视频推荐、内容推荐）上验证。

6. 工业实践意义

MGDIN 对搜索推荐系统的实践价值体现在三个层面：

即插即用的特征交互优化：延迟交互策略不需要改变现有模型的整体架构，只需在特征交互层引入分层掩码机制。对于已有 CTR 模型的团队，这是一种低成本的增量优化手段。线上 3.04% 的 CTR 提升非常显著，证明了工业级效果。

通用的特征工程指导：论文揭示的特征异构性问题具有普遍意义——在任何包含高稀疏 ID 特征和稠密统计特征的 CTR 系统中，都可能存在类似的噪声干扰问题。即使不采用 MGDIN 的具体方案，也可以通过简单的启发式规则（如先训练稠密特征子网络，再逐步引入稀疏特征）来缓解该问题。

零延迟部署实践：MGDIN 的多窗口并行设计天然适合 GPU 并行计算，且掩码操作本身计算开销极低。在线部署确认无额外推理延迟，说明延迟交互的「延迟」仅体现在训练逻辑中，不影响推理效率。对于延迟敏感的广告和搜索排序场景，这是关键的部署优势。

Taming the Long Tail: Efficient Item-wise Sharpness-Aware Minimization for LLM-based Recommender Systems

AAnt GroupZhejiang University

首次系统研究 LLM 作为推荐系统主干时面临的长尾问题，发现存在两种不同类型的长尾效应：（i）先验长尾，继承自预训练语料的隐式偏差；（ii）数据长尾，源于推荐数据集的分布倾斜。分析表明两者的头部交集会产生更强的头部效应，但整体性能差异主要由数据长尾主导。提出高效的逐物品锐度感知最小化方法（Item-wise SAM），在不显著增加计算开销的前提下改善长尾物品的推荐表现。

INSIGHT该研究揭示了 LLM 推荐系统中长尾问题的独特双重来源——预训练语料偏差叠加推荐数据偏差，这是传统推荐模型不存在的新挑战。对于实际搜索推荐系统，这意味着简单地将 LLM 作为推荐主干并不能自动解决长尾问题，反而可能因预训练偏差加剧不公平。Item-wise SAM 的设计思路（逐物品级别的优化平滑）为缓解长尾问题提供了一种低成本方案，值得在 LLM-based 排序模型中尝试。

Anchored Alignment: Preventing Positional Collapse in Multimodal Recommender Systems

INSIGHTAnchorRec 的锚点对齐策略解决了多模态推荐中的一个关键工程问题：直接在统一空间中强制对齐不同模态会破坏各模态的固有结构（图像的视觉聚类、文本的语义拓扑），最终退化为 ID 特征主导。对于 UGC 搜索场景，帖子往往包含图文混合内容，该方法的解耦对齐思路可用于构建更好的多模态物品表征，同时保持计算轻量，适合在线部署。

The Privacy-Utility Trade-Off of Location Tracking in Ad Personalization

INSIGHT该研究为搜索推荐系统中的数据策略提供了定量依据：在冷启动阶段应积极利用地理位置等上下文信号弥补行为数据不足，而非一刀切地限制或使用位置数据。随着用户行为积累，系统应动态调整特征权重，逐步降低对位置信号的依赖。这一发现对 UGC 社区搜索中新用户的个性化策略有直接参考价值——可在冷启动期优先利用用户位置、设备等上下文特征，热启动后平滑过渡到行为特征主导的排序。

VLM4Rec: Multimodal Semantic Representation for Recommendation with Large Vision-Language Models

重新审视多模态推荐中的语义对齐问题：传统方法将文本和视觉信号视为特征融合问题，但原始视觉特征保留的是外观相似性，而用户决策往往受到更高层语义因素（风格、材质、使用场景）驱动。提出 VLM4Rec 框架，利用大型视觉-语言模型将物品图像转化为显式自然语言描述，在语义空间中组织多模态内容，实现与用户偏好匹配的语义对齐，而非直接特征拼接。

INSIGHTVLM4Rec 的核心启示在于：多模态推荐的瓶颈可能不在融合策略，而在于原始特征的语义粒度不匹配。将视觉特征通过 VLM 转化为语言描述（如「简约风格、棉质面料、适合日常穿搭」），本质上是用 VLM 做了一次语义提升，使得图文特征在同一语义层级上交互。对于 UGC 搜索中包含图片的帖子，该方法可用于生成结构化的语义标签，提升图文混合内容的检索效果。

Can Fairness Be Prompted? Prompt-Based Debiasing Strategies in High-Stakes Recommendations

研究 LLM 推荐系统中的隐式偏见问题：LLM 可从姓名、代词等间接线索推断性别、年龄等敏感属性，进而产生偏见推荐。提出三种基于 prompt 的公平性去偏策略，在 3 个 LLM、4 种 prompt 模板、9 种敏感属性值和 2 个数据集上的实验表明，指示 LLM 保持公平的 prompt 策略可将公平性提升至 74%，同时基本保持推荐效果，但可能在某些场景过度补偿。
