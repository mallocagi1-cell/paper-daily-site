1. Query-Adaptive Semantic Chunking for Retrieval-Augmented Generation: A Dynamic Strategy with Contextual Window Expansion
3.90
Relevance 4 | Novelty 3 | Practical 5 | Evidence 2 | Timely 5

Summary: QASC 针对 RAG 固定分块在精度-召回上无法兼顾的问题，把用户 query 引入分块阶段：用句子向量与 query 向量的余弦相似度选种子句，再做上下文窗口扩展保持连贯，最后用 chunk 级分数聚合判定整体相关性。在 100 篇技术文档、200 条 query（四种类型）上 F1 达 0.85，较固定分块提升 18–27%，较语义/agentic 分块提升 8–12%；三人标注一致性 Cohen κ=0.82。

Key insight: 分块按查询动态切分，对社区搜索里同一篇长帖对不同 query 应截取不同片段的场景直接可用。方法无需训练，仅靠 embedding 相似度、窗口扩展、分数聚合三步，落地成本低；消融显示三个组件各有贡献，可按需裁剪。需注意 200 query/100 文档的评测规模偏小，上线前应在自有 UGC 语料上复测。

2. RAS: Reflection-Augmented Scaling with In-Context Learning for Executable Cypher Query Generation
3.80
Relevance 3 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: RAS 研究 Text2Cypher 中 LLM 生成不可执行查询的问题：数据库对语法错误会返回报错信息，而推理时通常被丢弃。RAS 把每次重试都用 in-context learning 喂入上一次的执行报错，对照无记忆重采样的 Independent Scaling (IS)。在 3 个 Neo4j 数据集、5 个代码专用模型上，n=5 时 RAS 将查询执行错误率降低 41–50%，IS 仅降 32–38%。

Key insight: 把执行器报错当作可学习信号回灌给模型，比单纯增加独立采样候选更省算力。对搜索中调用工具、生成结构化查询（自然语言转图谱或 SQL 检索）的 agent 流程有借鉴：报错日志本身是高质量反馈来源。方法无需训练，只改推理时的 prompt 拼接，适合快速验证。

3. LFRAG: Layout-oriented Fine-grained Retrieval-Augmented Generation on Multimodal Document Understanding
3.45
Relevance 3 | Novelty 4 | Practical 3 | Evidence 3 | Timely 5

Summary: LFRAG 针对多模态 RAG 依赖页级检索、无法捕捉细粒度版面结构的问题，把检索粒度从 page-level 推进到 block-level：先做版面分割构造语义连贯的检索单元，再用语义-版面融合编码器以 cross-attention 把局部语义与全局上下文结合。在自建 LFDocQA（带 block 级标注的基准）上，答案准确率较最佳基线提升 7.20%，生成阶段 token 消耗下降 73.07%。

Key insight: block 级检索同时改善了答案准确率与上下文冗余，73% 的 token 节省说明细粒度召回能显著压缩送入 LLM 的无关内容，对成本敏感的搜索 RAG 很有价值。版面分割加融合编码器适合图文混排的 UGC（含图、表、长文的帖子），但需要 block 级标注数据，冷启动需自建标注或蒸馏。

5. What Training Data Teaches RL Memory Agents: An Empirical Study of Curriculum Effects in Memory-Augmented QA
3.30
Relevance 3 | Novelty 3 | Practical 3 | Evidence 4 | Timely 5

Summary: 该研究固定架构、RL 算法与全部超参，只改训练课程，考察记忆增强 QA agent 学到什么。三种课程：in-domain (LoCoMo)、mixed (LoCoMo+LongMemEval)、out-of-domain (LongMemEval)。结论：课程组成是控制专精方向的细粒度杠杆；mixed 课程在两个评测集上 F1 最高；纯 out-of-domain 虽整体分低却能迁移出时序推理这一专项能力。分类型差异远大于聚合差异，说明单一总分会系统性低估课程效应。

Key insight: 两条训练经验对搜索、对话 agent 直接有用：跨 benchmark 混合训练要先过滤 memory bank 里的格式噪声以保留训练信号；在单 GPU 小 group（G=4）下二值精确匹配奖励无梯度信号，必须改用连续奖励函数。同时提示评估 agent 时别只看总分，要看分问题类型的表现差异。

Summary: SciAtlas 面向自动化科研中的信息爆炸：现有学术检索靠关键词或向量语义匹配，缺乏拓扑推理；agentic deep-research 框架又易逻辑幻觉、推理成本高。SciAtlas 构建跨 26 学科、4300 万篇论文、1.57 亿实体、30 亿三元组的异构知识图谱，并设计 neuro-symbolic 检索算法（tri-path 协同召回加图重排），把语义匹配推进到确定性关联发现，降低 AI agent 的推理成本。
