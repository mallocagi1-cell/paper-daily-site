1. Search-G1: Grounded Search Agents via Representation-Based Intrinsic Rewards
4.85
Relevance 5 | Novelty 5 | Practical 4 | Evidence 4 | Timely 5

Summary: Search-G1 面向搜索增强智能体的“是否需要检索、检索证据是否真正被使用”问题，提出两个经过干预校准的表示读出：提示状态读出估计闭卷可答性，答案提交读出通过删除证据测量依赖度。论文在多个搜索问答基准和两种模型规模上验证，可在无需过程标注或 LLM 裁判的情况下改善 grounding—搜索成本权衡，并缩短回答轨迹。

Key insight: 把检索必要性和证据依赖度从外部稀疏奖励中拆出来，可为社区短文本搜索构造低成本的 agentic rerank/检索策略奖励。工程上应周期性重拟合读出器以跟随策略漂移，同时将“重复搜索”设为显式负奖励，避免智能体用工具调用堆叠思考步数。

2. DocAtlas: Long-Document Understanding as Mutable-State Interaction
4.55
Relevance 4 | Novelty 5 | Practical 4 | Evidence 5 | Timely 5

Summary: DocAtlas 把长文档问答建模为可变状态的信息寻路过程，外部 harness 提供搜索、阅读、记笔记和复核工具，并维护层级树与证据笔记。GPT-5.4 在 MMLongBench-Doc 上达到 71.4%，超过人类专家参考的 65.8%；经端到端 RL 训练的 Qwen3.5-4B VLM 达到 63.7%，高于直接输入基线的 54.4%。

Key insight: 对社区搜索而言，核心借鉴不是把更多文档塞进上下文，而是把证据状态外置并允许“搜—读—记—复核”循环。可以把帖子、评论和引用关系组织成轻量层级笔记，配合固定 context budget，降低多跳问答的上下文污染。

3. FitText: Evolving Agent Tool Ecologies via Memetic Retrieval
4.55
Relevance 4 | Novelty 4 | Practical 5 | Evidence 5 | Timely 5

Summary: FitText 将工具选择视为有预算的测试时检索，让智能体在执行中生成、改写和进化伪工具描述，从而修复初始 query 找不到正确 API 的问题。StableToolBench 的 16,464 个 API 上，Memetic FitText 达到 84.3% pooled pass rate，较静态检索提升 26.7 个百分点；40 路并发时批处理墙钟时间仅为 Single-Pass 的 1.01 倍。

Key insight: 工具生态的动态 query rewriting 与搜索中的 query 改写/多阶段召回高度同构。可将伪工具描述的演化机制迁移到 UGC 意图、过滤器和检索器选择上，但必须设置调用预算、缓存和停止条件，控制迭代检索的延迟。

arXivKyle Zheng, Han Zhang, Renliang Sun, Chenchen Ye, Wei Wang
4. VDGR-RAG: Vectors, Directories, Graphs, and Reflection Are All You Need for Unified Reasoning over Hierarchical Enterprise Knowledge
4.50
Relevance 5 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: VDGR-RAG 面向层级企业知识，统一向量检索、目录路由、图遍历和迭代反思。系统先从文档 chunk 构建保留目录与语义关系的层级异构知识图，再组合目录增强路由、多路检索、目录回溯和动态反思四类原子工具；在四个无线通信领域的产品文档上，检索召回与 QA 准确率均超过多种 RAG 基线。

Key insight: 它提供了一个适合 UGC 搜索的工具化蓝图：先用目录/版块等结构做粗路由，再用向量与图关系联合召回，最后用反思触发补搜。目录回溯尤其适合纠正“语义相似但主题版块错误”的短文本结果。

arXivWenqi Chen, Haofei Yang, Rui Yang, Fangming Li
5. LLM within MCP Matters: Measuring Inefficient Resource Utilization Driven by LLMs
4.30
Relevance 4 | Novelty 4 | Practical 4 | Evidence 5 | Timely 5

Summary: 论文研究 MCP 中“把参考数据写进系统提示”与“让模型调用搜索工具”之间的资源利用冲突，基于生产法律信息 MCP 服务开展 54,000 次试验，覆盖 24 个模型（9 Claude、6 Gemini、9 GPT）。无搜索工具时 24 个模型中 23 个对嵌入数据达到至少 98% 命中；提供搜索工具后，模型会偏好重新搜索而浪费已有上下文。

Key insight: Agentic 搜索不只要优化召回，还要测量工具选择的机会成本。对 UGC 场景应显式记录“上下文已含答案却再次检索”的轨迹，按 query 难度配置工具可见性，并用离线工具调用率、延迟和 token 成本共同约束策略。

6. Chaining the Evidence: Robust Reinforcement Learning for Deep Search Agents with Citation-Aware Rubric Rewards
4.15
Relevance 5 | Novelty 4 | Practical 3 | Evidence 4 | Timely 3

Summary: Chaining the Evidence 针对深度搜索智能体只用二元结果奖励、容易走捷径或产生幻觉的问题，提出 Citation-aware Rubric Rewards（CaRR），把复杂问题拆成可验证的单跳 rubric，并检查隐藏实体、引用正确性和完整证据链；再用 C-GRPO 将 rubric 奖励与 outcome reward 联合训练。ACL 2026 实验显示其在多个深度搜索基准上稳定优于 outcome-only RL，并能泛化到开放式 deep research。

Key insight: 搜索奖励应从“答案对不对”细化到“每个关键事实是否有可追溯证据、证据链是否闭合”。这适合 UGC 搜索的事实型回答与摘要生成：把帖子/评论引用作为 rubric，训练智能体减少无证据扩写，但需控制标注和奖励计算成本。

Web SearchJiajie Zhang, Xin Lv, Ling Feng, Lei Hou, Juanzi Li
7. RoMeRL: Balancing Feedback Coverage and the Memory-Reward Trap in Self-Evolving Agent Memory via Reduced-Order Utility States
4.05
Relevance 4 | Novelty 4 | Practical 3 | Evidence 4 | Timely 5

Summary: RoMeRL 研究自进化 Agent 记忆中的反馈稀释和 memory-reward trap：轨迹索引的效用空间会随历史膨胀，联合分配的轨迹奖励还会误提升无关记忆。方法用固定维度、按结果极性和记忆动态分解的任务状态替代无限增长的效用表，让新经验通过固定语义坐标更新或替换，并从理论上提高单条记忆获得的反馈密度。

Key insight: 长期搜索 Agent 的记忆不能只按相似度堆积，应把“被检索—被引用—带来正确答案”的反馈压缩到有界状态。对短文本 UGC 可按意图、主题和时效维护有限记忆槽，并将错误召回的负反馈与内容过期信号分开建模。

HuggingFaceYi Yang, Zhennan Chen, Yihong Zhuang, Tiehan Fan, Yinan Chen
8. A^2E : An End-to-End Agent Auditing Engine
3.90
Relevance 3 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: A^2E 是面向 Agent harness 的端到端审计引擎，通过 Agent Task Protocol 快速接入不同 harness，自动插桩 Monitor 采集标准化执行轨迹，再以多维指标评估能力，而不只看最终正确率。该设计针对 agent 评测碎片化和难以复现实验的问题，适合作为搜索智能体的统一评测外壳。

Key insight: 把规划、检索、工具调用、证据使用和最终答案拆成可观测事件，才能定位 CTR/nDCG 之外的 agent 失败点。落地时应保留每步 query、候选集、工具返回、引用和成本，并按任务类型建立可回放的评测协议。
