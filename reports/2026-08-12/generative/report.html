1. Preserving Item Semantics for Free: Rethinking Token Initialization in LLM-Based Generative Recommendation
5.00
Relevance 5 | Novelty 4 | Practical 5 | Evidence 5 | Timely 5

Summary: 论文分析 LLM 生成式推荐中语义 ID（SID）随机初始化会丢失物品语义、转而编码流行度，并提出直接用语义空间质心初始化 SID embedding 的零参数改动。基于 Amazon Beauty、Sports、Toys、Steam、MovieLens 五个数据集，纯 SFT 的 Recall@5 平均提升 6.5%，SFT 步数平均减少 27%，冷门物品 Recall@5 平均提升 37%，额外 CPT 可从 6–10 个 epoch 降至 1–4 个。

Key insight: 对社区 UGC 推荐或语义召回，先检查离散 ID 是否在词表扩展时丢掉了内容几何，再决定是否堆叠持续预训练；质心初始化只需一次 embedding 赋值，不增加在线延迟。它还能削弱流行度吸附，适合作为 nDCG/CTR 链路中生成候选的低风险 ablation，并重点观察长尾帖子和新内容。

2. Fine-grained Semantics Integration for Large Language Model-based Recommendation
4.70
Relevance 5 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: TS-Rec 针对生成式推荐的两个瓶颈设计 SA-Init 与 TS-Align：前者用教师模型抽取关键词并对预训练 embedding 做均值池化，初始化 SID token；后者把 SID 序列中的单 token 与对应物品簇语义对齐。作者在三个真实世界基准上对比传统与生成式基线，所有标准推荐指标均保持领先，并公开实现。

Key insight: 对于社区短文本，物品语义不应只在整条帖子级别注入；主题、实体和意图词可分别映射到 SID 层级，帮助生成模型区分相似但意图不同的内容。落地时可把 SA-Init 作为离线词表构建步骤，把 TS-Align 作为辅助损失，并用 query 分桶 nDCG 验证 token 级语义是否真正改善匹配。

3. SAGE: SLO-Aware Adaptive Retrieval for Production RAG Systems
4.65
Relevance 4 | Novelty 4 | Practical 5 | Evidence 5 | Timely 5

Summary: SAGE 用初始检索的分数分布、排名间隔和词法信号训练轻量策略，按 query 难度动态决定 RAG passage 数量 k，不增加 LLM 调用。Natural Questions 在 5 秒 P95 SLO 下合规率为 95%，静态 k=20 仅 30%；P95 延迟下降 36%、检索成本下降 51%，EM 仅损失 2 个百分点，并迁移到 HotpotQA、UnSeenTimeQA 和四个 LLM 家族。

Key insight: 社区搜索的生成式回答不应固定召回深度：简单 query 用小预算保 CTR 与延迟，复杂 query 再扩展证据。SAGE 提供了可直接接入现有召回层的控制器形态，建议按 query 长度、意图置信度和候选分数间隔训练 k 策略，同时以 nDCG、首 token 延迟和 P95 成本做联合门槛。

4. What Would Fix This RAG Failure? Auditing Counterfactual Response with Paired Evidence Interventions
4.35
Relevance 4 | Novelty 4 | Practical 4 | Evidence 5 | Timely 5

Summary: Pair-ID 用“补充缺失证据+删除已验证非支持证据”的成对干预，固定 query、检索状态和 reader，审计一次失败是否真的能被证据修复。它从 19,981 个 benchmark query 中筛出 11,105 个 Qwen 失败，再生成 1,200 个样本；1,190 个有效重生成中，JOINT 修复率为 197/600（0.328），删除修复率为 162/1,190（0.136）。

Key insight: 对 UGC 搜索生成答案，离线评估应区分“召回缺证据”和“证据已在但模型没用好”，不能只看最终答案对错。Pair-ID 的双向干预可形成可解释的回归集：按支持新增、噪声删除和 reader 类型拆分，分别优化召回、重排与生成，避免把 nDCG 下降误判成模型生成问题。

5. BOUND: Brief-Guided Corrective Preference Distillation at Search-Control Boundaries
4.30

Summary: BOUND 针对深度搜索中的错误锚定、约束漂移和局部主题漂移，先让教师根据搜索 brief 判断决策边界，再构造纠错偏好或“停止继续检索”的终止偏好，最后用 DPO 蒸馏到学生模型。它在四个多跳问答和三个深搜基准上评估，在六个重跑基准中赢下五个、14 项指标中赢下 12 项；Bamboogle 提升 5.6 个 EM 点，BrowseComp-Plus 提升 4.8 个准确率点。

6. Guardian Crawler: Retrieval-First Knowledge Discovery with Bounded LLM Augmentation for Noisy Web Intelligence
4.25
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: Guardian Crawler 构建检索优先的生成式知识发现测试床，把 BM25、风险感知重排、embedding 增强和混合重排接到带显式引用的受约束 RAG。合成 900 文档、10 个 query 的实验中，风险重排达到 P@10=1.00、NDCG@10=0.94，BM25 为 0.94/0.81；41 条生成 bullet 全部通过词法覆盖，LLM judge 判定 36 条有支持、1 条部分支持、4 条不支持。

7. Not Worth Another Token: Marginal Value Estimation for Efficient Deep Research Agents
3.95
Relevance 3 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 论文系统比较深度研究 agent 在检索前、检索后和合成前的上下文裁剪策略，覆盖轻量启发式与 learned value model。结果表明，裁剪发生的位置比评分规则更关键：尽早裁剪带来最大的端到端收益，轻量启发式最多减少 73% token，质量仅小幅变化，而没有一种方法同时统治质量、效率和忠实性。

9. Evo-Bench: Can Language Models Improve Agent Harness?
3.55
Relevance 3 | Novelty 4 | Practical 3 | Evidence 3 | Timely 5

Summary: Evo-Bench 面向“模型能否改进自己的 agent harness”建立评测，使用 harness-guided construction 生成对框架改动敏感的任务，并用 sensitivity-aware stratified split 检查跨套件泛化。基准覆盖 Search、Office、General 三类 agent 场景，重点隔离 harness 改进、基础模型能力、任务过拟合和长程研究效果。
