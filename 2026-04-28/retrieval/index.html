LLMs as Assessors: Right for the Right Reason?

论文聚焦 LLM 作为 IR 相关性评估员能否给出可解释的判断。作者基于 INEX Wikipedia 测试集，要求 LLM 不仅判断文档相关/不相关，还高亮文档内回答信息需求的相关段落，并与人工评估员标注的段落对比。实验比较了多种主流 LLM 在文档级判断与段落级标注的一致性，发现即使 LLM 判断准确率与人工高度一致，其高亮的段落与人工标注的重叠度仍显著偏低，表明 LLM 评估的可解释性远不如表面准确率。

Can QPP Choose the Right Query Variant? Evaluating Query Variant Selection for RAG Pipelines

GoogleDatabricksUC Berkeley

针对 LLM 改写带来的多 query 变体执行成本，作者把 Query Performance Prediction (QPP) 用作变体选择器：在执行下游检索/生成之前预测每个变体的效果，从而仅运行最优变体。重点研究 intra-topic（同一信息需求内多变体之间）的判别能力，区别于传统 cross-topic QPP。基于 TREC-RAG，使用稀疏与稠密两类检索器、综合评估了 pre-retrieval 与 post-retrieval QPP 指标在 correlation 与 decision 两类任务下的表现。

INSIGHT对社区搜索 query 改写链路有直接价值：当用 LLM 生成多个改写变体时，可在 retriever 之前用轻量 QPP 信号（如 query clarity、SCQ、IDF 分布）做早期路由，避免对每个变体都跑全量召回+排序+RAG。此外文章揭示 intra-topic 判别比 cross-topic 难得多，提示我们短文本社区搜索若想用 QPP 做改写选择，需要专门训练能感知细粒度差异的预测器，而非沿用经典 ad-hoc 检索的 QPP 模型。

Negar Arabzadeh, Andrew Drozdov, Michael Bendersky, Matei Zaharia

An End-to-End Ukrainian RAG for Local Deployment. Optimized Hybrid Search and Lightweight Generation

UUCU

论文展示 UNLP 2026 共享任务亚军方案：面向乌克兰语文档问答的端到端 RAG 系统。检索侧采用两阶段管道（关键词召回 + 重排序）实现 hybrid search；生成侧使用乌克兰语小模型在合成数据上微调，并通过模型压缩支持本地部署。在严格算力限制下取得高质量、可验证的答案。

INSIGHT对 UGC 社区搜索的工程化启示明显：在算力受限场景下，hybrid（lexical + semantic）召回 + 轻量重排是高性价比组合，关键词召回保证短文本/低资源 query 的召回率，语义重排弥补术语不匹配。生成侧的合成数据微调 + 模型压缩路径可移植到“站内回答生成”等子任务。社区搜索往往面临稀有 query 与多语言长尾，本文的两阶段流水线值得作为 baseline 复用。

Mykola Trokhymovych, Yana Oliinyk, Nazarii Nyzhnyk

CLARITY: A Framework and Benchmark for Conversational Language Ambiguity and Unanswerability in Interactive NL2SQL Systems

Oracle

针对工业 NL2SQL 系统在多轮对话中频繁遇到的“歧义/不可回答”问题，作者提出 CLARITY 框架：用约束驱动的 pipeline 将可执行 SQL 反向构造成多面歧义自然语言查询，并自动生成对话式澄清回合及 schema 元数据。基于 Spider 与 BIRD 评估发现，最强 LLM 在多面歧义下显著退化，模型能检测出歧义却难以精确定位歧义类型与所属 schema 元素。

INSIGHT将 NL2SQL 的歧义处理范式直接平移到 UGC 搜索的 query 理解：站内搜索同样存在“一词多义、需求不明、不可回答”等多面歧义，主动澄清 (clarification question) 是提升 satisfaction 的关键。本文指出“能识别但定位错”的失败模式，提示我们不仅要训练歧义检测分类头，还要明确给出可澄清维度（实体、意图、时间），并把 schema-aware/类目-aware 的元数据注入 prompt，才能让 LLM 提出精确的澄清问句。

AgentSearchBench: A Benchmark for AI Agent Search in the Wild

UCL

论文将“为给定任务找合适的 AI Agent”形式化为检索 + 重排问题，并发布 AgentSearchBench：来自多个平台的近 10,000 个真实 agent，覆盖可执行任务 query 与高层任务描述两种检索场景。评估时不再只看文本匹配，而是用执行级表现信号（agent 能否真正完成任务）作为相关性 ground truth，揭示了文本相似度与实际能力之间的显著鸿沟。

INSIGHT对“能力检索/服务搜索”类 UGC 场景（例如社区里搜“能解决 X 的回答者/工具/教程”）有强烈借鉴意义：相关性不等于词面匹配，而要锚定下游可验证的执行/转化信号。可借鉴其“执行级 ground truth”的离线标注思路，在 UGC 搜索中以 “点击-停留-互动” 等行为级正负样本替代点击单一信号；构建 ranker 时融合文本特征 + 候选历史表现 (post-click feedback)，缓解 surface-form bias。

Bin Wu, Arastun Mammadli, Xiaoyu Zhang, Emine Yilmaz

Lightweight Retrieval-Augmented Generation and Large Language Model-Based Modeling for Scalable Patient-Trial Matching

Mayo Clinic

针对患者-临床试验匹配中需要在长 EHR 文本上推理复杂入排标准的难题，作者提出 RAG + LLM 编码的轻量框架：先用 RAG 从长病历中抽取与入排标准临床相关的片段，再用 LLM 把片段编码成稠密表征送入下游分类器。该设计显式分离“检索做信息精简”与“LLM 做语义建模”两阶段，避免直接对全文档调用大模型的算力瓶颈。

INSIGHT“RAG 做候选精简 + 小模型/编码器做最终判别”的两段式架构对 UGC 搜索有较强工程价值：当文档为长帖子或多回答聚合体时，可先用稀疏召回+轻量 reranker 抽出与 query 强相关的若干段落，再交给参数量较小的 cross-encoder 做语义打分，从而把 LLM-级别的语义能力以可控成本接入检索 pipeline。该思路也适用于站内的合规过滤、风险审核等需要长文本理解但延迟敏感的场景。

Xiaodi Li, Yang Xiao, Munhwan Lee, Konstantinos Leventakos, Young J. Juhn, David Jones 等 10 人

Knowledge-driven Augmentation and Retrieval for Integrative Temporal Adaptation

UU Memphis

针对模型“训练于历史、部署于未来”导致的语义与知识漂移问题，作者提出 KARITA 框架：同时建模语义 shift 与特征 shift，引入丰富的外部知识源（如 MeSH 医学本体），并以“漂移感知”策略选择最相关的外部知识做 retrieval-augmented 学习。在临床、法律、科学等多领域分类任务上验证了知识增强检索带来的稳定提升。

INSIGHTUGC 社区搜索同样面临剧烈的概念/趋势漂移（新梗、新事件、新商品），KARITA 的两个设计可借鉴：(1) 把热门 query 与近期热点条目做漂移检测，把高漂移区域定向触发知识增强检索；(2) 基于站内本体/类目体系做外部知识链接（类似把 MeSH 替换为内部类目图），在 ranker 输入端融合“类目 embedding + 实体描述检索结果”，提升对新词、新意图的泛化能力。

Weisi Liu, Guangzeng Han, Xiaolei Huang

ReLeVAnT: Relevance Lexical Vectors for Accurate Legal Text Classification

ReLeVAnT 提出一种用于法律文档二分类的轻量级框架：先做一次性 n-gram 关键词抽取，再用对比式打分函数构造判别向量，最后用一个浅层神经网络分类。整个 pipeline 不依赖外部元数据、不需要大模型，主要依靠关键词级别的判别特征，强调可在算力受限或私有部署场景中应用。

INSIGHT对 UGC 短文本搜索有现实价值：在召回链路里，简单 n-gram + 对比打分的“判别词典”仍然是低成本高 ROI 的特征源，尤其适合作为 LLM/dense retrieval 的兜底通道，对小语种、高延迟敏感、高 QPS 的子场景特别有用。该方法可被复用为 query-tag 分类器、低质内容过滤器，与稠密向量召回形成互补的双链路检索。

Ishaan Gakhar, Harsh Nandwani

Navigating Large-Scale Document Collections: MuDABench for Multi-Document Analytical QA

CAS

论文针对“需要跨多文档抽取并综合做定量分析”的任务，构建了 MuDABench：基于金融数据库 distant supervision 生成 80,000+ 页文档与 332 个分析型 QA 实例。每个问题需要跨数十乃至上百文档做信息抽取与聚合，远超已有 multi-doc QA 仅 2-3 篇文档的设定。评估协议同时度量最终答案准确率与中间事实覆盖率，作为推理过程的诊断信号。实验显示标准 RAG 把所有文档当扁平 chunk 处理时性能急剧下降。

INSIGHT对站内“聚合型查询”（如“最近一周关于 X 主题的主要观点”）有方法论启示：当检索目标是跨文档汇总时，把所有候选 chunk 平铺给 LLM 是失败模式；应引入“intermediate fact coverage”作为离线与在线评估指标，并在检索阶段引入文档级 metadata（时间、版块、作者）做分层路由。该 benchmark 也提供了构造内部分析型 QA eval set 的范式，可用 distant supervision + 内部数据库自动生成评估样例。

Zhanli Li, Yixuan Cao, Lvzhou Luo, Ping Luo

Dynamically Acquiring Text Content to Enable the Classification of Lesser-known Entities for Real-world Tasks

UU Utah

针对“给定实体名 + 标签即可生成专属分类器”的诉求，作者提出动态文本获取框架：通过 web 搜索 + LLM 联合生成关于每个实体的描述性文本，再以这些文本为基础训练分类器，实现对长尾或新出现实体的有监督建模。在 SIC 行业代码与医疗服务方分类两个场景上验证了方法的可迁移性。

INSIGHT对 UGC 实体识别与冷启动检索有借鉴价值：当站内出现新词/新品牌/新事件时，可用“web 检索 + LLM 摘要”自动构造该实体的描述语料，喂给类目分类器或实体 embedding 模型，实现近乎零标注的冷启动覆盖。该 pipeline 也能服务 query 理解模块，把陌生 query token 在线扩写成可被 retriever 命中的描述短语，缓解纯 dense 检索在长尾词上的失配。

Fahmida Alam, Ellen Riloff
