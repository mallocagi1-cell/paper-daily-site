AgenticQwen: Training Small Agentic Language Models with Dual Data Flywheels for Industrial-Scale Tool Use

针对工业级 Agent 应用的成本/延迟约束，论文提出 AgenticQwen——通过多轮强化学习训练的小尺寸 Agentic 语言模型家族。核心是“双数据飞轮”机制：推理飞轮通过错误样本不断提升任务难度，而 Agentic 飞轮把线性工具链扩展为多分支决策树，更贴近真实业务的复杂决策。在公开 Agentic 评测中，AgenticQwen 与体量大得多的开源模型旗鼓相当；在内部业务系统的日常搜索与分析任务上几乎追平 Qwen3-235B，但推理成本显著更低。

KEY INSIGHT · 对业务意味着什么工业落地最痛的问题是“能用大模型，但用不起大模型”。AgenticQwen 给出可复制的方案：用合成数据 + 双飞轮自动构造越来越难的训练任务，把 Reasoning RL 与 Agentic RL 串起来，让小模型也能掌握多步工具调用。对社区搜索的启示是——可以把 query 改写、意图分解、工具调用等 Agentic 流程下沉到 4–7B 级别小模型，配合飞轮持续生成 badcase 进行 RL 微调，从而以可承受的成本上线 Agentic 搜索能力。

PRAISE: Prefix-Based Rollout Reuse in Agentic Search Training

RUCXiaohongshuUSC

Agentic Search RL 训练有两大痛点：长程 rollout 计算昂贵但利用率低，且只有最终答案有奖励、信号稀疏。PRAISE 提出“前缀复用”：从一条完整的搜索轨迹中抽取不同搜索轮次的前缀状态，用模型补出每个前缀的中间答案，从而 (1) 把同一条 rollout 切成多条训练样本，(2) 用前缀间的性能差作为 step-level reward。在多跳 QA 任务上，PRAISE 在不增加额外采样开销的前提下显著提升了样本效率与训练稳定性。

INSIGHT“RL 训练 Agent 太贵、奖励太稀疏”是 Search-R1 路线的两个核心瓶颈，PRAISE 用一个简单优雅的工程技巧同时缓解：每条轨迹被截成多个前缀，并通过中间答案差分构造 step-level reward。对生产团队的启示是——在做 Agent RL 时不必盲目堆砌轨迹采样，而应充分挖掘已有 rollout 的中间状态，把“最终对错”切分成可分配到每一步的密集奖励，这一思路也可迁移到推荐重排、复杂会话搜索等长程决策训练中。

AgentGL: Towards Agentic Graph Learning with LLMs via Reinforcement Learning

AgentGL 是首个 RL 驱动的 Agentic 图学习框架，将图任务表述为 LLM Agent 多轮决策过程。它给 Agent 配置了三类“图原生工具”：局部邻居扩展、跳数受限遍历、全局证据探针，从而在不同尺度上探索图结构。框架引入“search-constrained thinking”约束工具使用次数以平衡精度与效率，并采用 graph-conditioned curriculum RL 稳定长程训练。多项基准实验显示 AgentGL 显著超越传统监督学习与 prompt 推理基线。

INSIGHT社区/UGC 搜索本质上也是“在用户–帖子–标签–作者”超大异构图上做证据推理，AgentGL 把图遍历显式拆成可调用的工具、用 RL 学策略，给图上 reasoning 提供了一个比 GNN 更灵活的范式。对工业团队的可操作借鉴：把“相邻召回 / 多跳跨域召回 / 全局热点探查”等召回策略封装为 Agent 工具，再用 RL 学习何时调用哪个工具、调用多少步，这比硬规则的多路召回更有泛化与扩展空间。

DR-Arena: an Automated Evaluation Framework for Deep Research Agents

DR-Arena 是面向 Deep Research 类 Agent 的自动化评测框架，提供 arena 风格的两两对比评测，覆盖多步网页研究、跨源验证与综合报告生成等核心能力。框架给出可复现的任务集与 LLM-as-judge 评分流程，对 OpenAI Deep Research、Gemini Deep Research、Grok-4 Deep Research 与 Claude-Sonnet-4.5 Deep Research 等主流系统进行了排名。它定位为 DeepResearchEval 等 benchmark 的补充，用对抗式比较揭示不同系统在事实性、引用质量、报告结构上的差异。

INSIGHTDeep Research 已从“能跑通”进入“量化对比”阶段。对自建 Agent 团队，DR-Arena 提供了一套标准化、可自动化的 head-to-head 评测协议，可直接用于：(1) 内部不同 prompt/工具栈方案的离线对照实验；(2) 第三方接入选型对比；(3) Agent RL 训练中的 reward proxy。把 arena 评测纳入 CI/CD，可避免 Agent 在长尾查询上无声回归。

Agentic-MME: What Agentic Capability Really Brings to Multimodal Intelligence?

Agentic-MME 系统性地评测了 Agentic 能力（规划、工具使用、多轮推理）究竟给多模态模型带来多大收益。框架在多种多模态任务上对比 MLLM 的“单次推理”与“Agent 模式”，结果显示 Agentic 脚手架在复杂任务上能显著提升表现，但在简单任务上呈现明显的边际收益递减；论文还总结出多模态 Agent 特有的失败模式（如视觉证据丢失、工具调用过度冗余等）。

INSIGHT并非所有任务都值得套上 Agentic 框架——Agentic-MME 量化地说明了“包装成 Agent”的边际成本与收益。给搜索/推荐团队的启示是：复杂、多步、需要外部证据的查询（如社区里的事实核查、跨帖子比较）值得用 Agent 路线；而短文本意图清晰的纯检索查询，单次推理 + 检索就足够。Agentic 路由（决定哪些查询走 Agent、哪些走轻量路径）应是上线前的必做实验。

Hierarchical Reinforcement Learning with Augmented Step-Level Transitions for LLM Agents

STEP-HRL 提出基于“步级转移”的分层强化学习框架：相比传统 outcome-only RL 把整条轨迹当作一个状态，STEP-HRL 在每个单步转移上都做信用分配，并在 state 表示中显式注入步级信息，以便策略更新能够直接归因到具体决策。多个 Agentic 基准实验显示其训练更稳定，并在长程任务上获得更好的最终成功率。

INSIGHT“奖励稀疏 + 信用分配”是 Agentic RL 训练效率低下的核心症结。STEP-HRL 与本期 PRAISE 给出的两条互补思路——前者从奖励侧（分层 + 步级）解决，后者从数据侧（前缀复用 + 中间答案）解决——值得搜索/推荐团队同时借鉴：在落地 Agent RL 时，应优先把 trajectory 拆成 step transitions，并构造能区分“整体成功但中间偏差”的步级信号，否则训练曲线很容易陷入大方差。

Incentivizing Neuro-symbolic Language-based Reasoning in VLMs via Reinforcement Learning

论文研究在视觉-语言模型中通过强化学习激励“神经-符号语言推理”能力——即让 VLM 在多模态场景下产生带符号结构的推理链而非纯自然语言。作者构造了带符号约束的 RL 任务，观察到经过 RL 微调后的 VLM 能在概念表示和组合推理上展现出更接近显式逻辑的行为，并在几项推理基准上获得了精度提升。

INSIGHTAgent 在多模态搜索/推荐场景常常需要做组合化推理（“同时满足风格 A 与价格段 B 的笔记”），纯自然语言 reasoning chain 在长链路下容易飘移。该工作提示一条工程路线：用 RL 把符号化中间状态强行接入推理链，以约束模型生成可解析、可校验的中间结构。这与社区搜索里“可解释筛选条件”需求高度匹配，值得在召回 + 重排 Agent 中尝试。

Source-Modality Monitoring in Vision-Language Models

论文定义并研究“源模态监测”——多模态模型追踪并报告每条信息来自何种输入模态的能力，将其视作 binding problem 的实例。在 11 个 VLM 上做目标模态检索任务的实验显示，模型同时利用语法信号（如“image”一词的位置）与语义信号；当模态分布差异较大时，语义信号占主导。论文进一步讨论了这一发现对 multi-modal Agentic 系统鲁棒性的影响。

INSIGHT在多模态 Agent 中，模型常需准确说出“这个结论来自图 / 来自文档 / 来自 web”——而 Source-Modality Monitoring 的实验表明 VLM 对此并不天然可靠，容易把不同来源的信息搅在一起。对落地团队的启示是：在 Agentic 多模态搜索的 prompt 设计与 trace 渲染时，必须在每段证据上显式打 source tag，并用 RL 或 SFT 让模型学会引用来源，否则用户引用核查就会出现错配。

Optimal Question Selection from a Large Question Bank for Clinical Field Recovery in Conversational Psychiatric Intake

针对精神科问诊这一典型“多轮信息收集”任务，论文把它形式化为从 655 道临床问题题库中做 Optimal Question Selection 的序列决策问题，并构造了带 5 种行为模式的合成病人。比较随机问、固定 intake form 与 LLM 自适应策略后，LLM-guided 方案在 300 次访谈上显著提升了关键临床字段的恢复率，但在罕见行为模式下仍存在偏差。

INSIGHT“多轮提问以收集字段”是 Agent 在 conversational search/会话推荐中的核心子任务（如一步步澄清用户的搜索意图）。这篇工作给出了可复现的评估框架：固定 question bank、合成 user persona、信息恢复率作为奖励信号——这套范式可迁移到“社区搜索意图澄清助手”的离线评估，避免直接靠人工拉群试用。

Intelligent Firewall Rule Generation and Harmonization: A Multi-Agent Framework for Cybersecurity Using the NSL-KDD Dataset

ICAART 2026 论文提出一个多 Agent 协作的智能防火墙规则生成与协调框架。各 Agent 分工承担流量分类、规则生成、规则冲突检测与协调；以 NSL-KDD 为基准数据集验证整体管线在攻击检测与规则生成上的效果。框架展示了 Multi-Agent 在“感知 → 推理 → 动作”闭环上的工程可行性。

INSIGHT尽管业务场景是网络安全，但其 Multi-Agent 分工模板（分类 Agent + 决策 Agent + 协调 Agent）对搜索/推荐场景里“低质内容审核 + 规则生成 + 规则冲突协调”有直接借鉴意义：把单一“一锤定音”模型拆成多个职能 Agent，可以更好地约束输出格式、提升可解释性，并便于灰度独立迭代。
