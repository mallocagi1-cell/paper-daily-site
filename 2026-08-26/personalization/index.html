Hierarchical Exponential-Gaussian Mixtures for Watch-Time Distribution Prediction

论文针对短视频观看时长分布的零膨胀、长尾和多峰特征，提出分层 Exponential-Gaussian Mixture（HEGM），用 skip-watch 分解、KL 方差正则和结构化初始化修复 EGMN 的方差塌缩、组件冗余与失活问题。实验覆盖公开数据集和大规模工业数据，论文报告排序准确率与阈值事件预测均提升，并通过 1.5 个月生产 A/B 测试确认统计显著的参与度提升。

Towards a Densing Law for User Representation Learning at Billion-Scale Capacity

📖 深度解读 · 14 分钟 →

论文在十亿级支付宝用户行为数据上研究用户表示学习的扩展瓶颈：原始行为文本继续扩展时收益递减，而 token 化容量如何随数据规模增长缺乏定量规律。作者提出 User Behavioral Densing Law，发现最小充分 token 化容量与输入 token 数的对数近似线性，并据此设计自适应变长 token 化方法 ALGN；实验覆盖多种数据源、token 化方式和下游任务，ALGN 优于既有基线。

INSIGHT工业用户建模的关键不只是堆长序列和大模型，而是让 token 化容量与行为数据规模匹配。对社区 UGC 推荐，可先按用户活跃度和行为来源估计最小充分容量，再用变长历史压缩替代一刀切的截断；这能把表示能力扩展与线上内存、序列长度预算绑定起来。

Bin Dou, Junru Zhang, Zhaoyi Yuan, Wuliang Huang, Letian Gong, Baokun Wang, Huan Li, Yu Cheng 等 9 人

Cascading Relevance-driven Recommendation Network for CTR Prediction in Trigger-Introduced Recommendation

论文研究触发式推荐（TIR）：用户先点击触发商品，后续承接页需要围绕即时兴趣继续推荐目标商品。CRRN 由 Trigger-Target Interaction、Cascading Interest Fusion 和 Category-assisted Pairwise Loss 三部分组成，分别刻画触发与目标的个性化交互、融合即时与长期兴趣，并用类别关系增强相对排序。作者在工业与公开数据集上超过近期方法，并通过线上 A/B 测试验证有效性，代码已开源。

INSIGHT触发式推荐的强信号不是静态用户画像，而是“刚刚点击了什么”。对于社区搜索后的相关推荐，可以把 query、首个点击帖子和后续候选组织成触发—目标对，使用门控兴趣融合区分即时意图与长期偏好，再以类别或主题关系构造难负样本。

Kaixuan Chen, Wenwen Wang, Xing Fang, Yang Huang, Jing Wang

A Dual-Expert Strategy Integrating LLMs to Mitigate Negative Transfer in Cross-Domain Sequential Recommendation

DuELRec 面向跨域序列推荐中的负迁移问题，将 LLM 的 token 级文本建模改造成 item 级协同表示。模型用 domain-gated dual experts 分别限制域内注意力和允许跨域注意力，再以门控融合抑制跨域噪声，并通过单域/跨域双重采样的 token-to-item 对比学习补足协同信号。实验覆盖 2 个真实数据集、10 个域，并击败 26 个先进方法；论文已被 CIKM 2026 接收。

INSIGHT跨域推荐接入 LLM 时，语义相似并不等于协同相似，域间迁移必须有可控的路由和负样本。社区平台可把帖子、话题或兴趣圈视为域，用域内专家守住稳定偏好、跨域专家发现迁移机会，并用 item 级对比目标避免文本 subtoken 主导表示。

Hyeongjun Yun, Kihyuk Song, Jaegul Choo, Chung Park

05 4.15

One Polluted Page Is Enough: Evaluating Web Content Pollution in LLM Recommenders

FORGE 评估搜索增强型 LLM 推荐器受到网页内容污染时的脆弱性：作者把 225 个真实商品、15 个品类和 5 种消费场景中的网页商品替换为伪商品，再测试 12 个商业与开源模型。单页污染最高可使模型推荐伪商品的比例达到 27%，将前三条结果全部替换后升至 73.8%；推理过程并不能消除风险，且模型缺少稳定先验知识时更脆弱。

INSIGHT个性化系统把实时网页、UGC 或商家内容接入 LLM 后，排序质量与内容可信度必须一起评估。上线前应建立商品或帖子实体校验、来源一致性和多页面交叉证据，并将“污染后仍推荐”的比例作为安全回归指标；仅增加 reasoning token 不能替代检索源治理。

Minghao Luo, Liang Chen

06 3.75

Enhancing Group Recommendation with Memory-Augmented Reasoning in LLM Agent

AGR 将群组推荐拆成 Memory Module 与 Reasoning Module：基于 token hash table 动态执行历史插入、更新、检索、遗忘和摘要，再按群组兴趣收集、共识细化、多维评估和解释生成完成多步推荐。训练采用先 SFT、后 GRPO 的强化微调，使模型学会自主调用记忆与推理模块；在 LastFM 和 Douban 数据集上，作者报告准确率与可解释性均显著优于现有方法，并开源模型。

INSIGHT群组推荐的难点是偏好随时间变化以及成员之间的冲突，不应把整段历史当静态 prompt。记忆的更新、遗忘和摘要可以迁移到社区共享账号或兴趣小组；但 RFT/GRPO 的成本较高，实际落地应先用结构化记忆和离线 rerank 验证共识建模价值。

Qimeng Niu, Bowen Hao, Zixuan Zhang, Shuyu Qu, Hongzhi Yin

Why didn't more people see it? Recommendation: Transparency for providers

论文从内容提供者视角研究推荐曝光透明度，训练 surrogate model 近似推荐系统在全体用户上的曝光分布，并量化各特征对曝光决策的贡献。作者在 2 个数据集、3 个推荐模型上评估，结果显示代理模型能够高保真复现三类推荐器的全局行为，且不同模型与领域的主导因素存在明显差异。

INSIGHT社区平台的个性化不只影响用户点击，也决定创作者能否获得曝光。与解释单个 user-item 对相比，全局 surrogate 更适合做供给侧诊断：可按作者、主题和内容质量切片检查曝光偏差，再将解释结果反馈给多目标排序，而不是把 CTR 当作唯一优化目标。

Meysam Varasteh, Robin Burke

08 3.58

Revisiting N2DCG: An Empirically Grounded Reformulation of Carousel Recommendation Evaluation

论文重新审视轮播推荐中的 N2DCG，指出传统单列表假设带来两个问题：理想排序违反二维轮播约束，折扣函数也不符合真实浏览行为。作者提出尊重轮播约束的新归一化方式和基于经验的折扣函数，并用真实眼动数据及依据眼动模式模拟的布局比较验证，新的指标更能反映用户行为和布局优劣。

INSIGHT当社区首页同时呈现多个主题栏、相关推荐和内容卡片时，单一 nDCG 会把展示布局影响误归因于模型。应把行、视口和卡片位置纳入评估，先用眼动或曝光—停留日志拟合折扣，再分别报告相关性、探索性与跨栏覆盖，避免只优化一个列表指标。

Jingwei Kang, Santiago de Leon-Martinez, Maarten de Rijke, Harrie Oosterhuis

Why This, Not That? Mining User Profiles for Pair-wise Counterfactuals

论文提出推荐解释的新任务：不再只回答“为什么推荐 A”，而是比较“为什么 A 排在 B 前面”。方法基于 counterfactual learning，从用户 profile 中挖掘影响相对排序的历史项目；在多个数据集上，作者展示了识别潜在解释依据的可行性。其核心是让解释与推荐算法的实际排序逻辑保持一致，而非事后生成与模型脱钩的文本。

INSIGHT对搜索和推荐从业者，pair-wise counterfactual 比单 item 解释更接近真实调试问题。可以把用户历史中的兴趣证据做遮蔽或替换，观察候选相对分数的变化，再用于发现用户画像污染、特征泄漏和排序理由不稳定；但上线前需要校准反事实与真实因果贡献的差异。

Meysam Varasteh, Veronika Bogina, Noam Koenigstein, Robin Burke

Balancing preference and compatibility: A multiobjective optimization framework for outfit recommendation

论文把服装搭配推荐建模为偏好与兼容性的多目标优化问题，搜索 Pareto 最优方案。框架结合异构图用户偏好模型捕获稀疏高阶信号，并用多模态兼容性模型评估视觉、文本和属性一致性；该设计为同时优化个性化偏好与内容组合质量提供了可解释的重排路径。

INSIGHT当推荐结果需要“用户喜欢”与“组合合理”同时成立时，单一加权分数会掩盖目标冲突。社区内容可借鉴双目标重排：先用用户兴趣召回，再用主题连贯性、作者多样性或内容互补性形成 Pareto 候选，并按业务阶段选择折中点；部署前要验证多模态特征的成本与冷启动覆盖。

Jing Wang, Cuiqin Lan, Xiaoyi Wang
