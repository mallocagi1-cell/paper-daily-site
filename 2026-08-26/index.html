Faithful Evaluation of Semantic-ID Tokenizers for Generative Recommendation

语义 ID 推荐通常直接比较生成的 SID 序列，但碰撞会让指标高估真实命中。论文提出碰撞校正评估（CCE）和零碰撞重分配（ZCR），在 4 个数据集、5 种 tokenizer 上发现碰撞率最高达 30.52%，SID-level Hit@10 最高被夸大 103.36%。

GRAFT: Graph-Distilled Generative Retrieval for Facet-Aware Scientific Literature Exploration

GRAFT 将论文图谱中“问题、方法、结果、贡献”4 类关系蒸馏为生成式检索器，让模型直接生成带语义标签的论文标识。朴素枚举只能覆盖 84% 语料；在 11,359 篇 NLP 论文的 LitWeave 上，覆盖感知训练达到教师图谱 Recall@20 的 91%，facet 标签精度为 0.922。

INSIGHT生成式召回不应只生成一个黑盒 item ID，关系类型可以成为可解释的检索控制面。对社区搜索，可把帖子、作者、主题之间的关系蒸馏为带 facet 的候选生成，并用约束解码保证 ID 有效，再用关系权重过滤无依据结果。

Italo Luis da Silva, Hanqi Yan, Yujing Wang, Jiangnan Ye, Lin Gui, Yulan He

Rethinking Item Tokenization in Generative Recommenders: From Fixed Atoms to Semantic Subwords

固定长度语义 ID 会让生成式推荐把过多注意力花在同一物品内部的低层 token 依赖上。SST 用 IST 合并稳定相邻 atom token，再用 BCA 注入语义前缀的行为共现信号，历史物品采用变长 subword、目标仍保持定长解码，并在 3 个公开数据集、3 个生成式推荐 backbone 上验证。

INSIGHT社区短文本的内容粒度差异很大，统一长度 token 容易在短帖子上浪费容量。可先离线统计 token 共现和行为转移，采用变长历史编码、定长目标解码的折中，重点观察序列长度、长尾 item 和 beam 解码延迟的变化。

Xinrui Miao, Mingjia Yin, Jiaqing Zhang, Wei Guo, Yong Liu, Yuyang Ye, Hao Wang, Enhong Chen

Adaptive Item-based Collaborative Structures via Noise Rescheduling in Diffusion for Generative Recommendation

ANR-DiffRec 针对离散扩散推荐缺少协同过滤先验、且对所有 token 使用统一噪声日程的问题，把 item 共现矩阵注入语义 ID 生成，并按局部可恢复性与行为依赖动态重排去噪权重。论文在多个推荐基准上报告其持续超过现有生成式推荐模型。

INSIGHT扩散式生成推荐不能只编码内容语义，还要把“哪些 item 经常共同出现”作为结构先验。工程上可从共现图提供噪声或采样权重，但需要单独监控热门 item 放大、冷启动 item 覆盖和多步去噪带来的线上延迟。

Jiaqi Wang, Tianying Liu, Heng Chang, Jihong Guan, Wengen Li, Shuigeng Zhou

The Disconnect Between Better Descriptive Reasoning Trace Quality and Recommendation Effectiveness

论文用 2×2 因子实验比较 Title 与 SID、最小与充分 SID 对齐，在 3 个 Amazon 商品域和 Qwen3-1.7B 上检验推荐推理轨迹。结果显示，显式描述性推理虽然让自然语言轨迹更有依据、更可解释，却会在 SFT 与 RL 下削弱传统离线推荐效果；加强 SID 对齐也未自动带来效果提升。

INSIGHT“解释更好”不等于“推荐更准”。对 UGC 搜索/推荐，应把推理轨迹质量与 nDCG、CTR、长尾覆盖分开评估，先做无推理生成基线，再用奖励函数把可解释性成本与最终点击或相关性目标对齐。

Gustavo Penha, Juan Elenter, Claudia Hauff, Hugues Bouchard, Paul Bennett, Mounia Lalmas

RAG Collapse: LLM Responses Collapse When Retrieved Documents Are Self-Authored

RAG Collapse 研究模型检索自己或其他 AI 生成的参考内容时的反馈闭环，在 3 个模型家族、1,019 个信息寻求 prompt 和 1,528 次模拟中观察到 79.6%（1,216/1,528）最终发生 collapse，总调用量超过 100 万次。现象表现为回答多样性和事实分布逐步收缩。

INSIGHT生成式搜索和推荐的内容池需要记录来源与生成链路，不能把模型生成文本当作普通 UGC 继续回灌。应建立 AI 生成内容标记、采样隔离和分布漂移监控，并在离线评估中比较原生内容与递归污染内容的覆盖和多样性。

Gregory Druck, Ethan Smith

The Laws of Context Allocation: Causal Measurement and Closed-Loop Orchestration in Generative Search

论文把 RAG 的证据使用拆成因果 leave-one-out 测量和闭环上下文编排，指出单纯扩大上下文会因相关性衰减而形成架构陷阱。把计算预算分配到多轮顺序生成后，组合式 portfolio recall 获得 16.7–20.5 个百分点的绝对提升，且在不同配置下保持稳健。

INSIGHT对复杂 query，不要默认把更多帖子塞进一个 context。可将召回、证据验证、答案生成拆成可观测轮次，用 leave-one-out 估计每批候选的真实贡献，再依据增量 recall 与延迟动态分配预算。

Peiyang Liu, Xi Wang, Di Liang, Wei Ye

Restore LLM Inference Capacity in Seconds with Shadow Engine Recovery in NVIDIA Dynamo

NVIDIA

NVIDIA 介绍 Dynamo 的 Shadow Engine Recovery，用检查点与影子状态恢复替代 LLM 引擎故障后的冷启动流程；传统路径需要重新加载权重、编译 kernel 并重建运行时。对生成式搜推服务而言，核心价值是把弹性扩缩和故障恢复从分钟级重启问题转为可持续的在线容量管理。

INSIGHT生成式推荐的线上瓶颈不只在模型精度，也在长上下文、KV 状态和权重恢复。部署时应把恢复路径纳入 SLO，分别测量权重加载、kernel 初始化、KV 状态恢复与首 token 延迟，并为低峰弹性缩容保留可快速唤醒的影子实例。

The full stack behind abundant intelligence

OpenAI

OpenAI 用全栈视角说明芯片、模型、服务软件和产品协同优化的价值，并给出 Jalapeño 在 InferenceX、GPT-OSS 120B 上的实测结果，同时覆盖 DeepSeek R1 与 Kimi K2。文章还称 GPT-5.6 Sol 在 Coding Agent Index 上用少 54% 的输出 token 达到新高。

INSIGHT生成式推荐系统可借鉴“模型—服务—硬件”共同设计，而不是只替换 Transformer。评估时应把每次成功推荐的 token、延迟、能耗和重试成本纳入统一账本，用 useful intelligence per dollar 约束模型规模扩张。

Solving Agentic AI Fleet Challenges with NVIDIA Vera CPU

NVIDIA

NVIDIA 基于 163,594 个 agent session 的遥测指出，超过 97% 的轨迹 profile 独一无二，工作负载同时包含长串行路径和短时并发 fan-out。文章据此主张 CPU fleet 应平衡单线程延迟与并发吞吐，并报告 Vera CPU 在 4 类 agentic workload 上相对 AMD Venice 的估算最高达 1.5 倍每核性能。

INSIGHT生成式搜推服务中的工具调用、重排和内容后处理也会形成串行关键路径与突发并发。容量规划应看完整 session 的完成数，而不是只看核数或峰值吞吐；对线上链路要单独测量串行 tail latency、fan-out 并发和内存利用率。
