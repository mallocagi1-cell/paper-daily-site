Towards Transfer-Efficient Multi-modal Sequential Recommendation with State Space Duality

该论文提出 MMM4Rec 框架，将 Mamba 状态空间模型引入多模态序列推荐，解决了现有 Transformer 方案在迁移学习中收敛慢和负迁移的问题。核心创新是结合 State Space Duality (SSD) 的时间衰减特性设计了 Cross-SSD 模块，实现跨模态时序融合。通过约束两阶段过程（序列级跨模态对齐 + 时序融合），在 5 个公开数据集上相比 Transformer 基线提升 3-8% 的推荐准确率，同时微调收敛速度快 2-3 倍。

MemoryCD: Benchmarking Long-Context User Memory of LLM Agents for Lifelong Cross-Domain Personalization

📖 深度解读 · 7 分钟 →

该论文提出 MemoryCD，首个基于真实用户行为（Amazon Review 数据集）的大规模跨域用户记忆基准。不同于依赖脚本化人设的合成数据，MemoryCD 追踪用户跨越多年、多领域的真实交互，构建了包含 14 个 LLM 基座模型和 6 种记忆方法基线的评估管线，覆盖 12 个领域的 4 种个性化任务。实验揭示现有记忆方法在用户满意度方面远未达标，尤其在跨域个性化场景下表现差距显著。

INSIGHT首次系统评估 LLM 长上下文记忆在跨域个性化中的效果，发现百万 token 上下文窗口并未解决用户建模问题——关键瓶颈在于信息检索和整合而非上下文长度。这对社区搜索中利用 LLM 做用户兴趣理解有重要警示：简单增大上下文窗口不够，需要结构化的用户记忆组织方式。该基准的跨域设计（12 个领域）为评估搜推系统中的冷启动和跨场景迁移提供了实用工具。

Weizhi Zhang, Xiaokai Wei, Wei-Chieh Huang, Zheng Hui, Chen Wang, Michelle Gong, Philip S. Yu

The Value of Personalized Recommendations: Evidence from Netflix

Netflix

Netflix 团队通过离散选择模型量化个性化推荐系统的增量价值。模型嵌入了推荐诱导效用、低秩异质性和灵活状态依赖，利用推荐算法引入的特异性变异进行因果识别。研究发现：将当前推荐系统替换为矩阵分解算法会导致用户参与度下降 4%，替换为热门排序则下降 12%，同时消费多样性降低。反事实分析还揭示了个性化推荐在长尾内容消费中的关键作用。

INSIGHT工业级因果推断框架量化推荐系统的增量商业价值——这是推荐系统领域长期缺乏的「ROI 证明」方法论。4% vs 12% 的参与度差距为不同推荐算法的优劣提供了具体数字参考。对社区搜索的启示：可借鉴其因果识别策略（利用算法变异作为工具变量）来量化搜索排序改进的真实业务增益，解决 A/B 测试中归因困难的问题。状态依赖建模对理解用户搜索习惯演变也有参考价值。

Kevin Zielnicki, Guy Aridor, Aurélien Bibaut, Allen Tran, Winston Chou, Nathan Kallus

NextQuill: Causal Preference Modeling for Enhancing LLM Personalization

NUS

NextQuill 提出基于因果推断的 LLM 个性化对齐框架。核心思想是将用户偏好视为因果变量，通过因果干预技术估计用户历史对每个 token 预测的真实偏好效应，区分用户偏好与其他混杂因素的影响。框架包含偏好发现（从数据中识别真实偏好信号）和偏好对齐（将 LLM 输出与用户偏好因果对齐）两个阶段，在多个个性化任务上显著优于直接基于历史的方法。

INSIGHT因果视角重新定义了「个性化」——不是简单拟合用户历史行为，而是识别历史中真正反映偏好的因果信号。这一区分对搜索排序模型同样重要：用户的点击历史包含大量非偏好因素（位置偏差、展示偏差），通过因果干预去除这些混杂可提升 CTR 模型的泛化能力。NextQuill 的 token 级偏好效应估计方法可迁移到搜索 query 理解中，帮助识别 query 中真正体现搜索意图的信号。

Rethinking Recommendation Paradigms: From Pipelines to Agentic Recommender Systems

Alibaba

阿里巴巴提出 AgenticRS 范式，将传统多阶段推荐流水线（召回-排序-重排序）中的关键模块升级为具有自主进化能力的 Agent。论文定义了模块升级为 Agent 的三个条件：功能闭环、独立可评估、可进化决策空间。针对模型 Agent 提出两种自进化机制：RL 风格的优化（适用于结构化动作空间）和 LLM 驱动的架构生成与选择（适用于开放式探索），为推荐系统的自动化演进提供了系统性框架。

INSIGHT将推荐系统的演进从「工程师驱动的手工优化」转向「Agent 驱动的自动化进化」，代表了推荐系统架构的范式转变。对搜索系统的启示：搜索排序管线同样面临「模块间耦合导致优化困难」的问题，AgenticRS 的模块化 Agent 设计（AutoTrain、AutoFeature、AutoPerf）可借鉴用于搜索系统的自动化 feature 工程和模型选择。但当前仍偏概念性，缺乏端到端的在线实验验证。

Jinxin Hu, Hao Deng, Lingyu Mu, Hao Zhang, Shizhun Wang, Yu Zhang, Xiaoyi Zeng

Diffusion Recommender Models and the Illusion of Progress: A Concerning Study of Reproducibility and a Conceptual Mismatch

对 SIGIR 2023-2024 发表的 9 篇基于扩散概率模型 (DDPM) 的推荐算法进行系统复现研究。结果发现仅 25% 的报告结果可完全复现，且由于原始论文使用了弱基线，扩散模型并未真正超越 SOTA。在控制实验中，调优后的简单基线一致性地超过扩散模型。论文进一步指出推荐场景与扩散模型之间存在概念性不匹配：扩散模型的去噪生成范式并不自然适配推荐任务的离散交互预测。

INSIGHT对推荐领域「新模型幻觉」的重要警示——复杂模型（扩散模型）未必优于调优的简单基线。这对搜索排序的实践启示极为直接：在引入新架构前，必须确保基线经过充分调优（超参搜索、数据处理对齐）。25% 的复现率数据也提醒我们在技术选型时要谨慎对待论文报告的 SOTA 数字。扩散模型与推荐任务的概念不匹配分析为评估新范式的适用性提供了分析框架。

Michael Benigni, Maurizio Ferrari Dacrema, Dietmar Jannach

AgenticRS-Architecture: System Design for Agentic Recommender Systems

Alibaba

阿里巴巴提出 AutoModel 架构，将工业推荐系统全生命周期组织为多个交互式进化 Agent。三个核心 Agent：AutoTrain（模型设计与训练）、AutoFeature（数据分析与特征进化）、AutoPerf（性能、部署与在线实验），通过共享的协调层和知识层连接。案例研究 Paper AutoTrain 展示了从论文方法解析到代码生成、大规模训练、离线对比的自动化闭环，大幅减少方法迁移的人工成本。

INSIGHTAutoModel 的核心价值在于「方法论文到生产模型」的自动化闭环——Paper AutoTrain 自动解析论文方法、生成代码并训练比较。这对搜索排序团队的效率提升有直接参考：大量排序模型论文的复现和对比测试占据了团队大量时间。但需注意其自动化质量依赖 LLM 的代码生成能力和方法理解深度，对复杂模型可能存在偏差。AutoPerf 的部署监控思路对在线系统运维也有启发。

Hao Zhang, Jinxin Hu, Hao Deng, Lingyu Mu, Shizhun Wang, Yu Zhang, Xiaoyi Zeng

CTR Prediction on Alibaba Taobao Advertising Dataset Using Traditional and Deep Learning Models

Alibaba

在阿里巴巴淘宝广告数据集上系统比较传统机器学习和深度学习模型的 CTR 预估效果。提出基于 Transformer 架构的自注意力机制模型，学习用户行为序列中的上下文依赖关系，相比逻辑回归基线 AUC 提升 2.81%。论文提供了从 LR 到 DNN 到 Transformer 的完整性能对比和实现细节。

INSIGHTTransformer 在淘宝广告 CTR 预估中 AUC 提升 2.81% 的数据为行为序列建模的有效性提供了工业级验证。对社区搜索的直接参考：行为序列建模（用户历史搜索和点击序列）通过自注意力捕获上下文依赖是提升 CTR 的有效路径。但 2.81% 的提升幅度需结合模型复杂度和推理成本综合评估。

Hongyu Yang, Chunxi Wen, Jiyin Zhang, Nanfei Shen, Shijiao Zhang, Xiyan Han

mSFT: Addressing Dataset Mixtures Overfitting Heterogeneously in Multi-task SFT

提出 mSFT 算法解决多任务 SFT 中不同子数据集过拟合速度不均的问题。核心方法是迭代式、过拟合感知的数据混合搜索：训练过程中识别并排除已过拟合的任务数据集，让欠拟合任务获得更多训练资源。该方法解决了传统均匀计算预算分配导致的「快任务过拟合、慢任务欠拟合」问题，在多个多任务基准上提升了整体性能。

INSIGHT多任务训练中的异质过拟合问题在推荐排序中同样普遍——CTR/CVR/停留时长等多目标的学习速度差异显著。mSFT 的动态数据混合策略（自动识别过拟合任务并降权）可直接应用于推荐多目标联合训练，替代手工调节任务权重的传统做法。该方法的迭代搜索开销需要评估，但对于离线训练场景是可接受的。

Woosung Koh, Jeyoung Jeon, Youngjin Song, Yujin Cheon, Soowon Oh, Jaehyeong Choi, Se-Young Yun

Reproducibility and Artifact Consistency of the SIGIR 2022 Recommender Systems Papers Based on Message Passing

对 SIGIR 2022 发表的 10 篇基于消息传递的图推荐系统论文进行系统复现和一致性分析。发现三个关键问题：(1) 普遍存在数据分割错误或训练测试信息泄漏等不良实践；(2) 代码和数据工件与论文描述频繁不一致；(3) 偏好使用新的复杂基线而非简单但经过调优的方法。这些问题导致报告的性能提升不可靠，对后续研究产生误导性影响。

INSIGHT对图推荐系统研究方法论的系统性批判，与 Diffusion 推荐论文的复现研究形成互补。核心启示：在技术选型时，「能否复现」比「论文数字」更重要。对搜索排序团队的实践建议：建立标准化的基线评估流程（固定数据分割、统一超参搜索、代码审查），避免引入看似先进但实际不优于简单方法的复杂模型。

Maurizio Ferrari Dacrema, Michael Benigni, Nicola Ferro
