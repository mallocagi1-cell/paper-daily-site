Stabilizing Rubric Integration Training via Decoupled Advantage Normalization

本文提出 Process-Aware Policy Optimization (PAPO)，通过解耦优势归一化将过程级评估整合进 GRPO 训练框架。针对现有奖励设计的两大缺陷——结果奖励模型 (ORM) 忽略推理质量且优势信号随训练逐渐消失，过程奖励模型 (PRM) 直接使用导致奖励攻击——PAPO 将优势分解为结果分量和过程分量并独立归一化，有效稳定了 RL 训练过程。实验在多个推理基准上取得持续提升，数学推理任务上 Pass@1 提升约 3-5 个百分点。

Attention-Aligned Reasoning for Large Language Models

本文提出 ATAR（Attention-Aligned Reasoning），一种利用推理链内在结构来引导 LLM 注意力的新方法。当推理链变长时，关键中间步骤和原始 prompt 会被淹没在上下文中，导致注意力不足而产生错误。ATAR 通过将注意力对齐到推理结构上的关键节点来解决此问题。实验表明 ATAR 在六个基准上超越 SOTA 方法，最高实现 15.39% 的绝对提升，且无需额外训练即可让非推理模型达到同等规模推理模型的水平。

INSIGHTATAR 揭示了长推理链中注意力衰减是多步推理错误的核心原因，并提供了一种无需训练的即插即用解决方案。对搜索 Agent 和 Agentic RAG 系统而言，这一发现极具实践价值：深度搜索 Agent 在多轮检索-推理过程中面临同样的注意力衰减问题，ATAR 的结构化注意力引导可直接集成到搜索 Agent 的推理流程中，改善多跳检索和长链推理的准确性。15.39% 的绝对提升表明该方法有显著的工程回报。

Hongxiang Zhang, Yuan Tian, Tianyi Zhang

AgentCollab: A Self-Evaluation-Driven Collaboration Paradigm for Efficient LLM Agents

本文提出 AgentCollab，一种自驱动的协作推理框架，通过动态协调不同推理能力和成本的模型来执行 Agent 任务。低成本模型负责快速执行，遇到推理瓶颈时通过自我评估信号自动切换到更强的模型。该框架无需外部路由模块，Agent 自身的反思信号即可决策何时升级推理能力。在多个 Agent 基准上，AgentCollab 在保持甚至提升任务完成率的同时，显著降低了计算成本。

INSIGHTAgentCollab 的自评估驱动的模型协作机制对搜索 Agent 部署有重要启示。在实际的搜索系统中，可以用小模型处理简单查询意图识别，仅在复杂多步推理（如深度搜索）时调用强模型，实现成本-效果的最优平衡。该方法的核心创新在于无需额外训练路由模型，而是利用 Agent 自身的不确定性信号做升级决策。对于需要控制推理成本的工业搜索 Agent 系统，这是一个极具实用价值的方案。

AtomMem: Learnable Dynamic Agentic Memory with Atomic Memory Operation

本文提出 AtomMem，将 Agent 记忆管理重新定义为动态决策问题。通过将高层记忆操作分解为原子级 CRUD（增删改查）操作，将记忆工作流转化为可学习的决策过程。结合监督微调与强化学习，AtomMem 学习出自主的、任务对齐的记忆管理策略，替代传统的静态手工设计的记忆机制。实验表明 AtomMem 在多个长周期 Agent 任务上优于现有记忆方案，记忆利用效率提升显著。

INSIGHTAtomMem 将 Agent 记忆管理从静态规则设计转变为可学习的动态策略，这对搜索 Agent 和对话式搜索系统具有直接价值。在多轮检索场景中，Agent 需要记住已检索的信息、用户偏好和历史交互，AtomMem 的原子 CRUD 操作框架提供了一种优雅的形式化方式。其 SFT+RL 的训练范式为搜索 Agent 的记忆模块提供了可复现的实现路径，特别适合需要长期记忆的深度搜索和个性化搜索场景。

Yupeng Huo, Yaxi Lu, Zhong Zhang, Haotian Chen, Yankai Lin

Defending Against Knowledge Poisoning Attacks During Retrieval-Augmented Generation

本文针对 RAG 系统中的知识投毒攻击（PoisonedRAG）提出了 FilterRAG 和 ML-FilterRAG 两种防御方法。PoisonedRAG 通过注入对抗文本引导模型生成攻击者选定的回答。FilterRAG 发现并利用对抗文本与正常文本在 embedding 空间中的可区分属性，ML-FilterRAG 进一步引入机器学习分类器来提升过滤精度。实验表明两种方法均能有效降低攻击成功率，同时对正常检索质量的影响较小。

INSIGHTRAG 系统在工业搜索中广泛部署，知识投毒攻击是实际安全威胁。本文的防御方案揭示了对抗文本在 embedding 空间中的可辨识特征，这为搜索系统的安全加固提供了实用方向。对于社区搜索场景中的 UGC 内容，恶意用户可能通过注入特定内容操纵 RAG 搜索结果，FilterRAG 的检测思路可直接应用于内容质量过滤模块。该方法无需修改底层模型，可作为即插即用的安全层集成到现有 RAG pipeline 中。

Consistency Amplifies: How Behavioral Variance Shapes Agent Accuracy

本文研究 LLM Agent 的行为一致性与准确性之间的关系。在 SWE-bench 上对 Claude 4.5 Sonnet、GPT-5 和 Llama-3.1-70B 进行了 50 次独立运行，发现行为一致性越高的模型准确率越高：Claude 的变异系数最低（15.2%）且准确率最高（58%），而 Llama 的变异系数最高但准确率最低。结果表明，Agent 的可靠性不仅取决于能力上限，更取决于行为的稳定性。

INSIGHT该研究揭示了 Agent 可靠性的核心维度——行为一致性——对实际部署至关重要。在搜索 Agent 场景中，用户期望相同查询得到一致的搜索结果，行为不一致会严重损害用户体验和信任度。本文的发现提供了评估搜索 Agent 质量的新视角：除了准确率外，还需要关注多次执行的一致性指标。对于工业级搜索 Agent 的选型和评估，变异系数是一个实用的补充指标。

Aman Mehta

Ask or Assume? Uncertainty-Aware Clarification-Seeking in Coding Agents

本文系统评估了 LLM Agent 在指令不明确时的澄清能力。在 SWE-bench Verified 的欠规约变体上，提出了一种不确定性感知的多 Agent 框架，将欠规约检测与执行逻辑解耦。研究发现当前 Agent 主要倾向于直接假设执行，而非主动寻求澄清，导致在模糊指令下表现不佳。提出的框架通过显式的不确定性估计决定何时应该提问，何时可以直接执行。

INSIGHT对搜索 Agent 而言，查询意图的模糊性是核心挑战——用户搜索 query 往往是短文本且意图不明确。本文将'何时提问、何时执行'形式化为不确定性感知的决策问题，这一框架可直接迁移到搜索 Agent 中：Agent 判断用户意图是否清晰，不清晰时主动发起澄清（如搜索建议、关联搜索），而非盲目返回可能不相关的结果。该思路对提升社区搜索中短文本 query 的意图理解准确性有实际参考价值。

Nicholas Edwards, Sebastian Schuster

Learning to Commit: Generating Organic Pull Requests via Online Repository Memory

Microsoft

本文来自 Microsoft Research，研究 LLM 编程 Agent 生成的 PR 被真实维护者拒绝的根本原因：不是功能错误，而是'有机性'不足——生成的代码忽视项目约定、重复内部 API 功能、违反隐式架构约束。本文提出基于在线仓库记忆（Online Repository Memory）的方法，让 Agent 不仅看到仓库当前快照，还能学习仓库的演化历史和隐式约定。该方法显著提升了生成 PR 的接受率。

INSIGHT该论文从工业实践角度揭示了 Agent 系统的关键缺陷：仅基于当前状态的推理不足以产生'有机'的输出。对搜索 Agent 而言，类似的问题存在于搜索策略的适配——Agent 需要理解特定业务场景的隐式规则和演化历史，而非仅根据当前索引内容做决策。在线记忆机制的设计思路可借鉴到搜索系统中，让搜索 Agent 学习业务场景的历史偏好和隐式约束。来自 Microsoft 的工业实践验证增加了可信度。

Mo Li, L. H. Xu, Qitai Tan, Ting Cao, Yunxin Liu

Can AI Scientist Agents Learn from Lab-in-the-Loop Feedback? Evidence from Iterative Perturbation Discovery

本文通过 800 次独立重复实验，研究 LLM Agent 能否从实验反馈中进行真正的上下文学习。在 Cell Painting 高通量筛选的迭代发现任务中，与仅依赖预训练知识的零样本基线相比，有实验反馈的 Agent 平均每个特征发现量提升 53.4%（p=0.003）。通过随机化控制实验验证了这一提升来自真正的反馈驱动学习，而非虚假关联。

INSIGHT该研究以严格的实验设计（800 次重复+随机化控制）回答了一个关键问题：LLM Agent 能否从迭代反馈中真正学习。53.4% 的提升和统计显著性表明 Agent 确实能进行反馈驱动的探索。对搜索系统的启示在于：搜索 Agent 通过多轮检索-反馈循环（如用户点击信号、相关性反馈）可以实现实质性的搜索质量提升，而非仅凭预训练知识做静态推理。实验方法论本身也为评估搜索 Agent 的学习能力提供了参考范式。

The Dual-State Architecture for Reliable LLM Agents

本文提出 Dual-State Action Pair (DSAP) 架构，将 LLM Agent 的随机生成行为与确定性后置条件验证耦合。通过引入 Guard 函数作为感知动作，将不透明的 LLM 输出投射到可观察的工作流状态上，实现了有限确定性状态与无限随机状态的双状态分解。形式化证明了失败概率 P(fail) <= (1-ε)^R_max → 0，并提出三层恢复层级防止多步工作流中 O(R^K) 的重试爆炸。

INSIGHTDSAP 为 LLM Agent 的可靠性提供了形式化保证，这对搜索 Agent 的工程落地至关重要。搜索系统要求高可用性和确定性行为，而 LLM Agent 天然具有随机性。DSAP 的双状态分解和 Guard 函数设计可直接应用到搜索 Agent 架构中：每个检索步骤的输出经过确定性验证后再进入下一步，三层恢复机制防止多步检索中错误级联。该形式化框架为工业级搜索 Agent 的稳定性设计提供了理论基础和实现参考。

Matthew Thompson
