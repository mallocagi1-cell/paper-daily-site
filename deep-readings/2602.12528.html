DiffuRank: Effective Document Reranking with Diffusion Language Models

Qi Liu, Kun Ai, Jiaxin Mao, Yanzhao Zhang, Mingxin Li, Dingkun Long, Pengjun Xie, Fengbin Zhu, Ji-Rong Wen · Renmin University / Alibaba · arXiv 2602.12528 · 发表 2026-02-13

扩散语言模型为搜索重排序提供了自回归 LLM 之外的新范式选择。其核心优势在于并行解码（parallel decoding）——不需要逐 token 生成，可一次性评估多文档的相关性，这在 listwise 重排序场景下有天然的效率优势。对于实际搜索系统，logit-based listwise 策略尤其值得关注：它直接从模型 logit 层提取排序信号，避免了自回归模型中复杂的 prompt 工程和位置偏差问题。

1. 问题与动机

当前基于 LLM 的文档重排序（reranking）主要依赖自回归语言模型（如 LLaMA、Qwen），但存在两个核心瓶颈：

  1. 高延迟：自回归模型逐 token 生成，在 listwise 重排序场景下需要依次输出每个文档的排名标识符，延迟随候选文档数线性增长。对于实时搜索系统，这是不可接受的。
  1. 错误传播：固定的从左到右生成顺序意味着早期的预测错误会向后传播。例如在 permutation-based 重排序中，如果第一个位置排错了，后续排名都会受影响——这在排序任务中尤为致命，因为排序本质上是一个全局优化问题，不应被局部生成顺序所约束。

为什么重要？ 重排序是现代搜索系统中精排阶段的核心模块。LLM-based reranker 已经展现出超越传统 cross-encoder 的能力，但其效率问题严重制约了工业部署。如果能找到一种既保持 LLM 级别语义理解能力、又具备并行推理效率的新范式，将对搜索系统的精排架构产生深远影响。

2. 方法概述

DiffuRank 提出将扩散语言模型（diffusion LLMs, dLLMs） 引入文档重排序，核心思路是利用 dLLMs 的两大特性：双向注意力（bidirectional attention）和并行解码（parallel decoding）。

框架包含三种重排序策略：

Pointwise 策略 (DiffuRank_Pointwise)

  • 独立评估每个 query-document 对
  • 在 prompt 末尾添加一个 mask token [M]，让模型预测该位置为 "1"（相关）或 "0"（不相关）的概率
  • 得分公式：s(q,di​)=p1​/(p0​+p1​)
  • 各文档得分独立计算后排序

Logit-based Listwise 策略 (DiffuRank_Logits-List)

  • 将多个文档放入同一个 prompt，每个文档对应一个 mask 位置
  • 一次前向传播同时获得所有文档的相关性得分
  • 文档间无序列依赖，所有得分并行计算
  • 对于长文档列表采用滑动窗口策略

Permutation-based Listwise 策略（两个变体）

Perm-Samp（采样式）：通过多步去噪迭代生成排列。采用约束采样算法——维护可行标识符集合，每步基于置信度贪心分配，避免重复。参数 K 控制采样步数（效率-效果权衡）。

Perm-Assign（分配式）：单次前向传播生成 N×N 概率矩阵，将排序建模为二部图匹配问题，用匈牙利算法求解最优分配，一步到位得到最终排列。

3. 核心技术贡献

3.1 首次系统验证 dLLMs 在 IR 任务上的可行性

这是第一篇将扩散语言模型用于文档重排序的工作，填补了 dLLMs 在信息检索领域的空白。

3.2 约束采样算法 (Constrained Sampling)

这是最具工程价值的贡献之一。实验表明，朴素的采样策略只能产生 16.54% 合法排列（存在大量重复标识符），而约束采样达到 100% 合法输出率，同时显著提升性能。具体做法是：

  • 维护可行标识符集合 Ut​
  • 每步根据置信度得分动态贪心分配
  • 同时保证位置唯一性和标识符唯一性约束

3.3 将排序建模为匹配问题

Perm-Assign 变体将重排序转化为最优分配问题：构造代价矩阵 Cij​=−logPij​，用匈牙利算法 O(N3) 求解。这完全绕过了自回归生成的顺序依赖，是一个优雅的范式转换。

3.4 结构感知的训练策略

  • DocID-aware masking：训练时只对文档标识符位置做 mask，而非随机 mask 所有 token。这让模型专注于学习排序信号而非语言建模。
  • RankNet loss 替代 Cross-Entropy：实验证明 RankNet 在排序任务上一致优于 CE loss（DL19 上 +2.5 NDCG@10）。
  • RoPE scaling 支持 16K 上下文长度，适应长文档列表。

4. 实验结果分析

评测设置

  • 数据集：TREC DL19、DL20 + BEIR（8个子集：Covid、NFCorpus、Touche、DBPedia、SciFact、Signal1M、News、Robust04）
  • 指标：NDCG@10
  • 候选集：BM25 top-100
  • 基线：LLaMA-3.1-8B、Qwen3-8B 等同等规模自回归模型

Zero-shot 结果

方法平均 NDCG@10
DiffuRank_Logits-List48.27
DiffuRank_Perm-Assign49.30
自回归 LLM 基线~48-49

关键发现：dLLMs 在零样本设置下已可媲美自回归 LLM，其中 Perm-Assign 表现最优。

Fine-tuned 结果（40K MS MARCO 样本，LoRA 微调）

方法平均 NDCG@10
DiffuRank_Perm-Samp55.10
DiffuRank_Perm-Assign55.21
所有自回归 LLM 基线< 55

微调后 DiffuRank 的 permutation 变体全面超越自回归基线，且展现出强跨域泛化能力（在 MS MARCO 上训练，在 BEIR 多领域数据集上测试）。

效率分析

最亮眼的结果：DiffuRank_Perm-Samp 在 K=2 步时，性能已超越两个自回归 LLM 基线，而延迟不到后者的三分之一。 Perm-Assign 更是单次前向传播即可完成排序。

行为分析

模型展现出粗到细（coarse-to-fine） 的排序策略：

  • 早期步骤：先确定最相关和最不相关的文档（解决排名两端）
  • 中间步骤：精细化中间区域的模糊排序
  • 最终步骤：确定性地完成剩余位置

这与人类的排序直觉高度吻合。

5. 局限与未来方向

当前局限

  1. 模型生态不成熟：dLLMs 目前的预训练模型选择远少于自回归 LLM（论文主要基于 DREAM 等少数模型），模型规模也相对有限，尚无 70B+ 级别的 dLLM。
  1. 上下文窗口受限：虽然用了 RoPE scaling 支持 16K，但在需要处理大量长文档的 listwise 重排序中，上下文容量仍是瓶颈。
  1. Pointwise 和 Logit-based 方法相对弱：实验中 permutation-based 方法明显优于前两种，说明简单的评分方式未能充分发挥 dLLMs 的优势。
  1. 训练数据依赖：微调需要 MS MARCO 等监督数据，零样本性能虽可用但仍有差距。

未来方向

  • 更大规模 dLLM 预训练：随着 dLLM 基础模型的进步（更大规模、更好的预训练），排序性能有望进一步提升。
  • 可微松弛（differentiable relaxations）：论文提到可探索连续松弛方法替代离散的匈牙利算法，实现端到端可微训练。
  • 更丰富的约束融合：将业务约束（如多样性、新鲜度、公平性）直接编码到扩散过程中。
  • 多阶段排序流水线整合：将 dLLM 与传统检索模型（如双塔、cross-encoder）更深度地集成。

6. 工业实践意义

6.1 精排延迟优化的新思路

对于搜索/推荐系统的精排阶段，延迟是核心约束。DiffuRank 的并行解码特性提供了一条从根本上降低 LLM-reranker 延迟的路径。特别是 Perm-Assign（单次前向传播 + 匈牙利算法）的范式，延迟接近单次模型推理，远优于逐 token 生成。

6.2 Logit-based Listwise 值得优先探索

在工业场景中，DiffuRank_Logits-List 策略最具落地潜力：

  • 一次前向传播为所有候选文档打分，计算图简单
  • 无需复杂的 prompt 工程来控制输出格式
  • 天然避免了自回归 listwise 方法中的位置偏差问题
  • 可直接替换现有的 cross-encoder 打分模块

6.3 排序建模范式的启示

将排序建模为二部图最优匹配（Perm-Assign）是一个值得深入研究的方向。这种思路可以扩展到：

  • 广告竞价排序：同时考虑广告主约束和用户体验
  • 推荐 re-ranking：在满足多样性、类目均衡等约束的同时优化排序
  • 搜索结果组织：结合分组展示等结构化展现需求

6.4 约束采样的工程价值

约束采样算法解决了一个实际问题：如何保证模型输出的排列合法性。这在工业系统中至关重要——线上系统不能容忍非法输出。该算法的思路（维护可行集 + 贪心分配）也可迁移到其他需要结构化输出的场景。

6.5 对模型选型的启示

这篇论文传递了一个信号：自回归不是 LLM 用于排序的唯一范式。随着 dLLM 生态的成熟（更多预训练模型、更好的推理框架），工业团队应该关注这一技术路线。尤其是在以下场景中 dLLM 可能优于自回归模型：

  • 需要同时评估大量候选（listwise）
  • 延迟约束严格
  • 需要结构化输出保证
  • 排序需要全局一致性（双向注意力的天然优势）

总结：DiffuRank 是一篇开创性的工作，首次系统验证了扩散语言模型在文档重排序中的可行性和优越性。其核心价值不在于当前绝对性能（虽然已经 competitive），而在于打开了一个新的技术范式空间——并行解码 + 双向注意力 + 结构化输出控制，这三者的组合恰好契合排序任务的本质需求。对于搜索/推荐领域的从业者而言，这是一篇值得认真跟踪的方向性工作。
