Divergence Meets Consensus: A Multi-Source Negative Sampling Framework for Sequential Recommendation

4.10
Relevance 4 | Novelty 4 | Practical 4 | Evidence 4 | Timely 5

Summary: 序列推荐隐式反馈下的负采样长期被 self-guided hard negative 主导：模型用当前参数挑硬负，结果是采样和模型互相强化、被困局部最优。论文提出 MDCNS（Multi-source Divergence-Consensus），借鉴 Vygotsky 最近发展区理论搭建 Teacher-Peer-Self 三源打分框架：用辅助模型扩大采样空间、引入分歧度过滤、再用共识投票决定最终负样本。在多个公开数据集上 Recall@10 与 NDCG@10 显著优于 DNS、SRNS 等基线。

Key insight: 核心创新是把负采样从“单模型自洽”改成“多模型分歧 + 共识”——分歧扩展搜索空间避免坍缩，共识抑制噪声。对搜推系统的启示是：硬负样本不必依赖在线全库打分，可以蒸馏出 teacher/peer 离线打分缓存，再用 voting threshold 控制 precision-recall trade-off，工程上比 in-batch hard negative + ANN 召回更可控。

1. 问题与动机

序列推荐 (Sequential Recommendation, SR) 在隐式反馈下训练时，几乎所有 hard negative sampling 都属于"self-guided"范式——以模型当前打分为依据从候选池里挑硬负样本（如 DNS、SRNS、MixGCF）。作者将这一族方法归为"L1 级别 self-learning"，并指出三个被忽视的固有失效模式：(1) negative self-reinforcement loop：采样策略与模型当前状态紧耦合，模型一旦挑到坏负样本，下一轮的梯度反过来污染判别能力，循环把模型困在局部最优；(2) restricted sampling diversity：负样本只在模型当前关注的 item 子空间内搜索，采样分布逐步坍缩，泛化能力被严重抑制；(3) inefficient resource allocation：为挑一个 hard negative 必须对整个候选池打分，绝大多数分数被丢弃，computational cost 与 information gain 不匹配。论文借鉴 Vygotsky 的 Zone of Proximal Development (ZPD) 理论，把单模型自学习扩展为 Teacher-Peer-Self 三方协作，用 divergence 拓展边界、用 consensus 巩固知识，提出 MDCNS (Multi-source Divergence-Consensus for Negative Sampling)。论文已被 SIGIR'26 接收。

2. 方法详解

MDCNS 主要由三个模块组成，整套流程是 model-agnostic 的，可即插即用接入任何 SR backbone。

(1) Multi-source Scoring (3.1)：对每个用户序列 $S_u$，先从未观测物品空间均匀采样得到候选集 $C_N$（排除历史和 ground-truth 正样本）。随后两个对等的 student 模型——self 和 peer（如 self=SASRec、peer=Mamba4Rec），分别对 $C_N$ 打分，dot product 形式为 $s_{u,v}^ = h_u^ \cdot e_v$。teacher 模型不是独立训练的网络，而是把两位 student 的打分直接相加：$s^{teacher} = s^{self} + s^{peer}$。这种 additive teacher 极大降低了部署成本，因为它没有第三个参数。

(2) Divergence Re-ranking (3.2)：对每个候选 item 计算 divergence score $d_{u,v} = |s^{self} - s^{peer}|$，再把它叠加到原始打分上得到 divergence-aware score $\tilde{s}_{u,v}^ = s_{u,v}^ + d_{u,v}$。然后对 self/peer/teacher 三个视角分别取 top-M，再在 top-M 池里均匀采样一个负样本——既保证 hard 又引入随机性以缓解 false negative。对应损失 $L_{rec} = \alpha L_{self} + \beta L_{peer} + \gamma L_{teacher}$ 是三个负样本视角的 BPR/BCE 加权之和。

(3) Consensus Distillation (3.3)：先前对 $C_N$ 计算出的全套分数本来只用了一两个 token，作者把 teacher 的全候选打分作为 soft target，最小化 self 与 teacher 在 $C_N$ 上的 KL 散度 $L_{dis}$。总目标变为 $L_{rec} + \mu L_{dis}$，几乎免费地利用了已有的 forward 计算。

训练算法见论文 Algorithm 1：每个 epoch 对每条 sequence 走一遍"候选采样 → 多源打分 → divergence 重排 → 三视角负采样 → 共识蒸馏 → 反传更新"。实验默认 backbone 是 SASRec，loss 使用 BCE 或 BPR，candidate 大小 N、top-M、$\alpha\beta\gamma\mu$ 视数据集略调。

3. 核心技术贡献

贡献 1：用 peer 模型打破自强化循环。引入异构 peer（SASRec ↔ Mamba4Rec），让 peer 的归纳偏置主动暴露 self 模型从未关注过的负样本子空间，从根上解掉 self-guided 采样的退化问题——这比 SRNS 用单模型 + uncertainty 估计更稳健，因为后者本质仍是 self-loop。

贡献 2：以 prediction divergence 量化"有信息量"的硬负样本。divergence 高意味着两个 student 对该 item 看法不一致，对模型学习的边际信息最大。把 divergence 当作 ranking signal 显式加进打分，比 SRNS、AdaSIR 那种基于 uncertainty 的隐式重赋权更直观、训练曲线更稳定（Figure 3）。

贡献 3：免费的 teacher 蒸馏。teacher 是 self + peer 的 additive 组合而非独立大模型，KL 蒸馏复用 multi-source 阶段已经算好的全候选分数，几乎不增加 forward 成本，把原本被丢弃的打分转化为额外梯度。

贡献 4：model-agnostic + loss-agnostic。在 SASRec、GRU4Rec、FMLP4Rec、LinRec、Mamba4Rec 五种主流 backbone 上，无论 BPR 还是 BCE 损失都能跑通且持续胜过 baseline，证明它不是 backbone-specific trick。

4. 实验结果分析

实验覆盖六个公开数据集：Amazon 系列的 Beauty / Toys / Sports / Health（5-core 过滤）、Kuaishou 的 KuaiRand（含随机曝光日志）、LastFM（音乐艺人推荐）。划分 70/20/10，指标 Recall@K、NDCG@K (K ∈ {5,10,20})，paired t-test 显著性 p<0.05。

主表 (Table 3, SASRec + BPR)：MDCNS Recall@5 全面领先，相对最强基线提升幅度为 Beauty +39.49%、Sports +23.31%、Toys +16.06%、Health +25.81%、LastFM +15.02%、KuaiRand +12.59%；NDCG@5 提升幅度 11.65%–39.56%。值得注意的是，在最稀疏的 Sports 与 Toys 上提升幅度最大，说明 multi-source 采样确实把模型从局部最优拽了出来。在工业级别的 KuaiRand 上提升相对温和（约 7–13%），符合工业数据噪声多、行为更密集的特征。

Cross-backbone (Table 4–5)：在 SASRec / LinRec / FMLP4Rec / GRU4Rec / Mamba4Rec 上 MDCNS 都是 SOTA，证明非 backbone-specific。值得注意 LinRec 与 FMLP4Rec 这种轻量化架构同样受益，意味着 MDCNS 的收益主要来自采样质量而非容量补偿。

Ablation (Table 6)：依次剥离 CD → CD+DR → CD+DR+MS 性能阶梯式下降，三者均不可替代。移除 multi-source scoring (MS) 退化最大，与作者关于"打破自强化循环是最关键"的假设一致；移除 consensus distillation (CD) 影响次之，说明 teacher 蒸馏不仅省算力也确实在传递可用知识。

Training Dynamics (Figure 3)：值得玩味的反直觉发现是——常规蒸馏会让 student 与 teacher 损失 gap 不断收敛，但 MDCNS 的 KD loss gap 反而长期维持或扩大。作者解释这正是 divergence re-ranking 在主动阻止 teacher 与 self 表征同质化，从而让 teacher 持续提供有效梯度。这条曲线对调参（增大 μ 是否会导致同质化）是个很有用的诊断信号。

5. 局限与未来方向

作者在 Conclusion 中明确承认两个局限：(1) 训练成本——multi-source 架构需要同时维护并 forward self + peer 两个 backbone，训练阶段开销大约翻倍；(2) 效率优化未深入——目前候选池 $C_N$ 仍是 uniform 采样，未探索更聪明的 candidate pool 构造（如基于流行度或 cluster）。作者明确表态未来会探索"lighter and more efficient alternatives"。

另外一些隐含的局限没有在 paper 中讨论：(a) peer 模型架构如何选择——SASRec + Mamba4Rec 这种 transformer + SSM 组合在 inductive bias 上差异较大，但若两者过于相似 divergence 将退化；(b) 推断阶段只用 self 模型，因此论文报告的延迟与原始 backbone 相同；(c) 没有报告 online A/B test，工业线上效果待验证。

6. 工业实践意义

对搜索 / 推荐工程团队的核心可借鉴点：

(1) 不必上线 peer 网络：MDCNS 的核心 cost 在训练阶段，线上推断只跑 self 模型，部署成本与 baseline 完全一致——这是最关键的工业友好属性，意味着可以在不改造 serving 链路的前提下拿到 15–40% 的离线指标提升。

(2) Peer 模型选择有讲究：建议选与现有线上 backbone 不同 inductive bias 的架构（线上是 SASRec/Transformer，可以挑 Mamba4Rec 做 peer；线上是 GBDT/MLP，可以挑序列化 Transformer），避免 divergence 退化。Peer 不需要追求强精度，反而需要"看世界的方式不同"。

(3) 复用算力做蒸馏：consensus distillation 几乎不增加 forward 成本，是把"原本要丢的全候选打分"转化为正则信号的一种通用技巧。对 CTR/CVR 排序场景，可以直接借鉴：每个 mini-batch 算 in-batch all-pair score 时，把 teacher（如双塔模型 + 协同过滤召回的混合）打分作为 soft target 蒸进单塔 ranker，既稳泛化又不额外费 GPU。

(4) 多 gate 负采样替代单一硬负：直接把"top-M 内均匀采样" + "三视角负样本加权"的范式搬到曝光未点击负样本里——可以缓解工业数据中 false negative 高发的痛点（曝光未点击不一定 = 真不喜欢）。

(5) 监控指标：上线时可以加一个 divergence loss gap 监控曲线，若发现 gap 持续收缩，说明 peer 与 self 出现同质化，需要调整 peer 架构或重启 peer 训练——这是论文 Training Dynamics Analysis 提供的额外运维 insight。

部署考量：训练阶段 GPU/时间近似翻倍，但若在 A/B 上能拿到 5–10% 的 nDCG 提升，对大体量推荐场景仍然 ROI 显著；KuaiRand 上 +12% Recall@5 的工业实证给了一个相对保守的预期参考。
