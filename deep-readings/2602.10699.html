Spend Search Where It Pays: Value-Guided Structured Sampling and Optimization for Generative Recommendation

Jie Jiang, Yangru Huang, Zeyu Wang, Changping Wang, Yuling Xiong, Jun Zhang, Huan Yu · arXiv 2602.10699 · 发表 2026-02-11

V-STAR 首次系统性地揭示了生成式推荐中 RL 微调的结构性缺陷——传统 GRPO 在树状解码空间中存在探索偏差和优势估计失真。其提出的 Sibling-GRPO 通过兄弟节点间的对比来降低方差，类似于搜索系统中 listwise 排序对比的思路。对于正在部署生成式推荐的团队，这提供了从 beam search 向 RL 优化过渡的实用路径，特别适合需要在延迟预算内最大化多样性的场景。

1. 问题与动机

生成式推荐系统将推荐问题建模为序列生成任务：给定用户历史行为序列，自回归地解码出推荐物品的语义 ID (Semantic ID, SID)。然而，当使用强化学习 (RL) 对这类模型进行微调时，存在一个根本性的概率-回报错位 (probability-reward mismatch) 问题。

具体来说，论文识别了两个关键缺陷：(1) 探索不足——高回报但起始概率低的物品在 beam search 中被不可逆地剪枝，导致这些物品完全不可达；(2) 优势压缩——共享高概率前缀的候选物品具有高度相关的回报，组内方差极低，严重削弱了 RL 学习信号的区分度。这两个问题导致传统 GRPO 在生成式推荐中无法充分优化推荐质量。论文的核心洞察是：额外的探索不需要在每个生成步骤均匀分配，而应集中在不确定性高、价值有前景的「决定性」前缀上。

2. 方法详解

V-STAR 框架包含三个核心组件，形成自进化循环：

语义感知价值模型 (Semantic-Aware Value Model)：训练一个轻量级价值函数 V_φ，从任意前缀状态 s_ℓ = (x, y_≤ℓ) 估计期望下游回报。关键创新在于稠密监督策略：不使用稀疏的精确匹配信号，而是构建「采样前缀桶」，通过平均物品 embedding 计算上下文条件的「前缀嵌入」，定义逐步回报 r_ℓ（使用与真实物品 embedding 的余弦相似度来奖励匹配前缀、惩罚不匹配前缀）。价值函数通过单步时序差分学习训练，强制执行跨前缀深度的 Bellman 一致性。

价值引导高效解码 (Value-Guided Efficient Decoding, VED)：在语义 ID 前缀树上执行预算约束的扩展。前缀优先级评分为 G(s) = V_φ(s) + λ·H_θ(s)，其中 H_θ 是策略熵衡量下一 token 的不确定性。解码分四阶段：(1) 用低宽度 beam search 初始化，揭示模型偏好和早期剪枝分支；(2) 使用 UCB 风格评分选择节点，平衡利用和探索：U(s) = G(s) + β·√(ln(N_root+1)/(N(s)+1))；(3) 门控扩展——仅展开 G(s) ≥ 深度平均优先级的「决定性」前缀，每次扩展添加一个新子节点；(4) 反向传播更新访问计数。当计算预算耗尽时终止，从高价值叶节点采样最终候选。

兄弟 GRPO (Sibling-GRPO)：解决优势压缩问题的核心创新。定义兄弟组为共享父前缀 h 的所有采样物品，在兄弟组内（而非全局）计算相对优势。节点级评分为 A_node(x;h,v) = [R̄(x;h,v) - μ_h(x)] / [σ_h(x) + ε]，其中 R̄ 是通过子节点 v 路由的候选物品的平均回报。优化目标将梯度集中在每个深度的关键分支决策上，执行 GRPO 风格的更新。

训练流程：两阶段——先在全部数据上做监督微调 (SFT)，再进行 RL 微调（联合 GRPO + Sibling-GRPO）。基座模型为 Qwen2.5-1.5B，3 层语义 ID（RQ-VAE 码本），VED 每查询生成 16 个候选，层权重 [0.3, 0.5, 1.0]，8 GPU 训练。

3. 核心技术贡献

(1) 预算化探索原则：「把搜索花在值得的地方」——仅在高价值、高不确定性节点上分配计算，而非无差别扩展。这通过价值函数 + 策略熵的联合评分实现，比纯价值或纯熵引导分别提升 0.15 和 0.19 NDCG@10 百分点。

(2) 树结构学习信号：利用层级 SID 结构在兄弟组内归一化优势，产生更强的 RL 信号。Sibling-GRPO 相比标准 GRPO 在 Industrial 数据集上 NDCG@10 提升 1.5 个百分点（0.1189→0.1204），联合使用提升至 0.1217。

(3) 稠密语义监督：使用与真实物品 embedding 的余弦相似度提供中间步骤的丰富监督信号，替代传统的稀疏精确匹配。这使价值函数能更准确地预测前缀的长期价值。

(4) 自进化循环：改进的采样提供更清晰的训练信号，更新后的策略反过来锐化价值函数。这形成正反馈循环，持续提升推荐质量。

在线 A/B 测试 (微信视频号)：5 天 5% 流量测试，相比 BeamSearch+GRPO 基线：

  • GMV 提升 +1.23%
  • GMV-Normal（点击/转化优化广告）提升 +1.87%
  • 这在大规模广告推荐系统中是显著的业务提升

消融实验关键发现：

  • VED vs beam search：在相同训练模型上，VED 达到 0.1217 NDCG@10，beam search 仅 0.1194（+1.9%），top-K 更低至 0.1090
  • 计算效率：在匹配的训练预算下，VED 在 1× 预算时常能达到 beam search 3-4× 预算的性能
  • 候选多样性：VED 最高多样性 0.8167（vs beam search 0.7892），同时最大回报也最优

5. 局限与未来方向

论文未明确讨论局限性，但从技术细节可识别：(1) 价值模型依赖冻结文本编码器的物品 embedding，对 embedding 质量敏感；(2) VED 的树搜索增加了训练时的计算开销（虽然推理时可退回标准 beam search）；(3) 实验仅在 Amazon Review 和微信视频号两个场景验证，泛化性待进一步确认；(4) 3 层语义 ID 的设定可能对更细粒度的推荐场景不够灵活。

6. 工业实践意义

可直接借鉴的设计：(1) Sibling-GRPO 可作为任何使用 SID 的生成式推荐系统的 RL 训练改进方案，实现简单且无额外推理成本；(2) 稠密语义监督的价值函数训练方法可迁移到其他需要中间步骤信号的序列决策场景。

部署考量：论文明确指出推理时使用标准 beam search 以兼容现有 serving 流水线，VED 仅在训练时使用。这大幅降低了部署门槛——团队可以只替换训练流程而不改动推理架构。在微信视频号的线上验证（GMV +1.23%）证实了工业可行性。

适用场景：特别适合拥有大规模物品库（百万级）、已部署 SID-based 生成式推荐、且希望在不增加推理成本的前提下提升推荐质量和多样性的团队。对于尚未使用 RL 微调的生成式推荐系统，V-STAR 提供了从 SFT 向 RL 过渡的完整方案。
