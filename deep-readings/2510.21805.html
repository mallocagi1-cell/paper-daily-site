DiffGRM: Diffusion-based Generative Recommendation Model

3.80
Relevance 4 | Novelty 5 | Practical 3 | Evidence 4 | Timely 2

Summary: 针对自回归生成式推荐模型的顺序依赖和局部最优问题，提出首个基于扩散模型的生成式推荐框架 DiffGRM。核心创新在于用掩码离散扩散模型替代自回归解码器，实现对语义 ID 的双向上下文建模和任意顺序并行生成。设计了三个关键模块：并行语义编码（PSE）解耦 token 并平衡信息分布、策略一致性噪声（OCN）聚焦高不确定性 token 的训练、置信度引导并行去噪（CPD）优先填充高置信度位置。在多个公开数据集上 NDCG@10 提升 6.9%–15.5%，已被 The Web Conference 2026 接收。

Key insight: DiffGRM 证明了扩散模型在生成式推荐中可以超越自回归范式，核心优势在于摆脱了从左到右的顺序约束，允许模型利用双向上下文并行生成所有 token。对于 UGC 搜索/推荐系统，这意味着召回阶段可以用扩散模型一次性生成多个候选 item 的语义 ID，避免 beam search 的局部最优陷阱。OCN 策略（聚焦不确定 token 训练）可借鉴到其他序列生成任务中，提升训练效率。

1. 问题与动机

生成式推荐（GR）近年成为推荐系统的重要范式，其核心思路是将物品表示为 n 位语义 ID（SID），然后用自回归模型（ARM）逐位生成目标物品。然而，DiffGRM 指出自回归范式存在两个结构性缺陷：

物品内一致性问题（Intra-item consistency）：一个物品的 n 个 SID 数字共同唯一指定一个物品，但自回归模型强制从左到右的因果约束，导致模型无法利用双向跨数字的验证信息，所有监督信号被压缩到一条因果路径上。例如，第 3 位数字的预测无法利用第 4 位已知的信息来修正自身。

数字间异质性问题（Inter-digit heterogeneity）：不同的 SID 数字编码了不同粒度的语义信息（类别、品牌、类型、尺寸等），预测难度差异很大。但统一的 next-token 目标函数对所有数字分配相同的监督权重，导致简单数字过训练、困难数字训练不足。

这两个问题本质上源于将自然语言的自回归范式机械套用到推荐场景的结构化 ID 预测任务上。DiffGRM 提出用掩码离散扩散模型（MDM）替代自回归解码器，从根本上解决顺序依赖问题。

2. 方法详解

DiffGRM 采用编码器-解码器架构，编码器将用户交互历史压缩为上下文表征 H_u，掩码扩散解码器（MD-Decoder）则通过双向非因果自注意力机制并行预测 n 位 SID。系统包含三个核心模块：

并行语义编码（PSE）：传统方法使用残差量化（RQ）构造语义 ID，但 RQ 引入层级依赖关系，与并行预测的目标矛盾。PSE 采用基于 OPQ 的「分区-量化」策略：首先学习正交旋转矩阵 R_o 降低量化失真，然后将旋转后的向量分割为 n 个独立子向量，每个子向量独立映射到对应数字的码本 C^(k)（大小 M=256）。这种设计解耦了各位数字之间的依赖，每位数字承载大致均衡的信息量。语义编码器使用 sentence-t5-base（768 维）。

策略一致性噪声（OCN）：掩码扩散训练面临组合爆炸问题——n 位 SID 有 n·2^(n-1) 种目标-上下文组合，需至少 2^n - 1 种掩码配置才能完整覆盖。OCN 通过以下步骤高效解决：(1) 首先在全掩码输入上运行一次 MD-Decoder，获得每位数字的预测分布；(2) 用最大预测概率 p_max^(k) 量化置信度，计算困难度 δ(k) = 1 - p_max^(k)；(3) 按困难度排序，构造从轻到重的嵌套掩码视图，优先掩码最不确定的数字；(4) 在这些一致性视图上计算掩码位的交叉熵损失。核心思想是将训练资源聚焦在模型最不确定的位置，避免随机掩码导致的信号分散。

置信度引导并行去噪（CPD）：推荐系统需要生成多样化的 Top-K 候选，而非单一输出。CPD 执行全局并行束搜索：从完全掩码状态 t_R=1 开始，每步选择置信度最高的数字优先填充，维护 B_act 个活跃分支，逐步反向去噪直到所有数字被填充，最终返回去重后的 Top-K 输出。这避免了自回归束搜索的局部最优陷阱。

训练使用 AdamW 优化器，线性预热 10,000 步，dropout 0.1，标签平滑 α=0.1-0.15，滑动窗口数据增强。Transformer 编码器 1 层 + MD-Decoder 4 层。

3. 核心技术贡献

贡献一：首个扩散式生成推荐框架。DiffGRM 首次将掩码离散扩散模型应用于推荐的结构化 SID 预测，摆脱了自回归的顺序约束。相比 RPG（此前最强的 GR 基线），NDCG@10 提升 6.9%–15.5%。核心机制在于双向自注意力允许每个数字位置利用所有其他位置的信息，这对于 SID 这种各位之间高度相关的结构化标识符尤为重要。

贡献二：自适应训练信号分配（OCN）。通过 on-policy 困难度估计，OCN 将训练资源聚焦在模型最不确定的数字上。实验显示，去掉 OCN（使用随机掩码）在三个数据集上 NDCG@10 分别下降 18%、27%、26%。关键发现是「最不确定优先、静态排序」策略最优，动态刷新排序反而有害。

贡献三：PSE 解耦语义编码。消融实验证明 PSE 对性能影响最大：替换为 RQ-KMeans 后 NDCG@10 下降 34%–42%，因为 RQ 的层级依赖与扩散模型的并行去噪冲突。此外，DiffGRM 比自回归基线更能受益于更强的语义编码器（bge-large 和 gte-large 带来额外 4%–12% 提升）。

贡献四：CPD 多样化生成。束宽从 32 增加到 256 时 NDCG@10 持续提升，表明 CPD 能有效利用更大搜索空间发现高质量候选。

消融实验的关键发现：

  • PSE 是最关键的组件（去掉后性能下降最大）
  • OCN 的有效样本通道数（ESP）分析表明，策略一致性噪声在更低的训练开销下达到或超过 k 倍一致性路径采样的效果
  • 隐藏维度 d_m 的最优值因数据集而异（Sports/Beauty: 256, Toys: 1024），表明模型容量需匹配数据复杂度
  • 更强的文本编码器（bge-large、gte-large）对 DiffGRM 的增益大于对 RPG 的增益

值得注意的是，DiffGRM 在 Toys 的 Recall@10 上略低于 RPG（0.0834 vs 0.0869），但 NDCG@10 更高，说明其排序质量优于召回覆盖度。

5. 局限与未来方向

论文明确指出的局限：

  • 推理效率：虽然理论复杂度分析表明 DiffGRM 仅引入 O(n) 的额外因子（n 为 SID 位数，通常较小），但作者承认需要进一步研究实际推理延迟和可扩展性。
  • 超参数敏感性：隐藏维度、学习率等需按数据集单独调优（如 d_m 在不同数据集上最优值差异明显）。
  • 数据增强依赖：滑动窗口增强显著增加训练样本量（如 Toys 从 19,412 增加到 87,180），训练开销不可忽视。

作者未提及但值得注意的局限：实验仅在 Amazon Review 数据集上验证，缺少工业级大规模数据集的验证；SID 位数 n 的选择对性能的影响未充分讨论。

6. 工业实践意义

可采纳方向：

  1. PSE 语义 ID 构造方法：用 OPQ 替代 RQ 来构造语义 ID 是一个立即可实施的改进，不依赖扩散模型本身。对于已有语义 ID 的系统（如基于 TIGER 或 HSTU 的生成式召回），可以单独替换 ID 构造模块来获得性能提升。
  2. OCN 训练策略：「聚焦不确定位置训练」的思想可迁移到任何序列生成任务中。对于 UGC 搜索系统的 query 理解或文档 ID 生成，可以借鉴这种自适应训练信号分配策略。
  3. CPD 多样化召回：并行束搜索适合需要多样化候选的召回场景。

部署考量：

  • 推理延迟是核心瓶颈——扩散模型的多步去噪过程天然比单次前向推理慢，需要与蒸馏或减步策略结合。
  • 模型参数量适中（1 层编码器 + 4 层解码器），但需要存储 n 个独立码本（n × 256 × 维度）。
  • 滑动窗口数据增强在工业级数据量下可能带来存储和训练时间压力。

对 UGC 搜索系统的启示：DiffGRM 的扩散范式特别适合「一次请求、多个候选」的召回场景。在 UGC 短文本搜索中，可以将帖子编码为语义 ID，用扩散模型并行生成多个候选帖子的 ID，避免自回归模型的顺序瓶颈。但在延迟敏感的在线排序环节，自回归模型可能仍更实用。
