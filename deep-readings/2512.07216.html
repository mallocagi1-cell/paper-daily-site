MUSE: A Simple Yet Effective Multimodal Search-Based Framework for Lifelong User Interest Modeling

Bin Wu, Feifan Yang, Zhangming Chan, Yu-Ran Gu, Jiawei Feng, Chao Yi, Xiang-Rong Sheng, Han Zhu, Jian Xu, Mang Ye, Bo Zh... · Alibaba · arXiv 2512.07216 · 发表 2025-12-08

长序列建模不必全程堆多模态：粗筛(GSU)用便宜的余弦召回、精排(ESU)再上重的多模态融合，这种按阶段分配算力的设计能在 10 万级行为序列下压住延迟。UGC 短文本场景里物品冷启动与长尾普遍，把多模态 embedding 当作 ID 之外的语义先验值得借鉴；开源的超长序列+多模态数据集也降低了复现门槛。

1. 问题与动机

现有 CTR 工业系统在终身用户行为建模的两阶段框架（GSU 通用搜索单元 / ESU 精确搜索单元）中几乎只用 ID 特征，带来两个失效点：GSU 阶段，长尾或过时物品的 ID embedding 学习不充分，检索质量下降；ESU 阶段缺乏语义表达力，无法泛化到共现信号之外。作者用实验量化：ID-based GSU 的 GAUC 为 0.6356，换成带 SCL 的多模态 GSU 升到 0.6377（+0.33%）；更关键的是 ESU 对表征质量远比 GSU 敏感——同样换表征，ESU 侧 GAUC 在 0.6345（OpenCLIP）到 0.6377（SCL）间摆动约 0.5%，远超 GSU 侧（图 2）。这说明"在哪个阶段、用多重的多模态"不能想当然，必须把两阶段拆开做系统消融。淘宝展示广告要把行为序列从 5K 拉到 100K，长尾物品占比与语义稀疏问题被进一步放大，这正是 MUSE 的出发点。

2. 方法详解

MUSE 沿用 GSU→ESU 两阶段。GSU 用冻结的 SCL 多模态 embedding 做轻量余弦相似度检索：r_i = <v_a, v_i>，v_a 为目标物品 embedding、v_i 为历史行为 embedding，取 top-K 最相关行为。作者发现简单余弦反而胜过复杂检索——把 GSU 换成注意力式检索 GAUC 退到 0.6369（对 0.6377），即在粗筛阶段堆复杂度反而有害。ESU 在这条 K 长度序列上叠两个互补组件：(a) SimTier——把相似度分数序列 R=[r_1,…,r_K] 转成 N 个 bin 的直方图，刻画"有多少行为高度/弱相关"的多层语义分布，几乎零额外参数；(b) SA-TA（语义感知目标注意力）——用多模态相似度增强 ID 注意力，融合式 α^Fusion = γ1·α^ID + γ2·R + γ3·(α^ID⊙R)，γ1/γ2/γ3 为可学习标量，等于让 ID 注意力与语义相似度既相加又相乘地交互。多模态 embedding 横向比较了三种冻结表征：OpenCLIP（2 亿图文对的通用语义，0.6345）、I2I（物品共现对比学习）、SCL（搜索-购买行为对的语义对比学习，0.6377），最终选 SCL 因细粒度语义最贴合电商意图。训练：embedding 层 lr=2e-3、DNN 参数 lr=2e-4、batch=8000、Adam、冻结 embedding 不微调、单 epoch（未跑到完全收敛即取得收益，说明信号强）。

3. 核心技术贡献

(1) 提炼出清晰的两阶段设计原则：GSU"简单即够"——轻量余弦优于注意力/融合；ESU"需要丰富+融合"——显式多模态序列建模（SimTier）叠 ID-语义融合（SA-TA）。(2) 三条被实验验证的洞察：多模态相似度检索胜过 ID 检索（+0.33% GAUC）；ESU 引入多模态序列建模收益大（单 SimTier +0.70%）；表征质量对 ESU 影响远大于 GSU，因此投入应优先放精排侧。(3) 工程上用"匹配阶段异步预取 GSU 特征 + GPU 缓存 embedding"把 GSU 重活挪出在线关键路径，消除 100K 序列延迟瓶颈。(4) 开源首个大规模多模态终身行为数据集 Taobao-MM（99M 样本、8.79M 用户、35.4M 物品、1K 序列、128 维 SCL embedding），含用户 ID/年龄/性别/城市与物品 ID/类目。

4. 实验结果分析

离线用 GAUC。整体（表 5）：DIN 基线 0.6271；SIM-Hard 0.6351、SIM-Soft 0.6356、TWIN 0.6304、MISS 0.6308；MUSE 0.6377（相对 DIN +1.69%），开源集 0.6154（+1.18%），均为最优。ESU 组件消融（表 3）：纯 ID 的 Target Attention 0.6301；单 SimTier 0.6345（+0.70%）；TA+SimTier 0.6361；单 SA-TA 0.6339（+0.60%）；完整 SA-TA+SimTier 0.6377（+1.21%）——两组件互补、缺一掉点明显，验证"序列直方图 + 语义增强注意力"各司其职。序列长度（图 5）：从 5K 扩到 100K 再 +0.38% GAUC，且多模态 ESU 的优势随序列变长而扩大。分层（图 6）：9 个用户分组里相对提升随序列长度单调上升，最冷门物品组相对收益最大，直接印证多模态对长尾的泛化。线上 A/B（表 6，淘宝展示广告 2025 年中，100K MUSE vs 5K SIM）：CTR +12.6%、RPM +5.1%、ROI +11.4%——线上提升量级远大于离线 GAUC，符合工业大流量放大效应。生产数据集规模：37.1 亿样本、1.9 亿用户、236 亿物品、最长 100K、一周数据（6 天训 1 天测）。

5. 局限与未来方向

作者未显式列局限。从行文看：实验中生产数据集被截到 5K，完整 100K 仅用于线上测试，离线/线上口径不完全一致；开源集为发布可行性截到 1K；SCL embedding 全程冻结、不具备端到端微调能力，表征上限受预训练阶段约束；论文未分析失败案例或负迁移场景。隐含约束还包括方法依赖高质量预训练多模态表征（SCL 需搜索-购买行为对这类强监督信号），缺这类数据的中小平台收益可能打折，需要自建语义对比预训练。

6. 工业实践意义

对社区搜索/推荐的直接启示：(1) 长序列建模别全程上重多模态——粗筛（GSU）用冻结 embedding 的余弦召回足矣，把算力留给精排（ESU）的多模态序列建模与 ID-语义融合，这种按阶段分配算力能在 100K 行为下控住延迟。(2) SimTier 的"相似度直方图"是低成本好特征——把 top-K 相似度分布离散成 bin，几乎零额外开销却带来 +0.70%，值得直接照搬到现有精排。(3) 延迟落地关键在"匹配阶段异步预取 + GPU 缓存 embedding"，把语义检索从在线关键路径剥离。(4) UGC 短文本场景物品冷启动与长尾普遍，引入多模态 embedding 作为 ID 之外的语义先验、并优先强化精排侧，是性价比高的路线；开源 Taobao-MM 数据集也便于先离线复现验证再决定投入。部署考量：SCL 表征需离线预训练并缓存，在线主要承担 top-K 检索与 ESU 计算，对在线算力增量友好。
