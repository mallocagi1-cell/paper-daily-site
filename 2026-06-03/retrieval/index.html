Semantic Retrieval for Product Search in E-Commerce

针对电商搜索中 query 短、口语化、噪声大且商品属性细粒度的问题，提出基于孪生 LLM 双塔编码器的两阶段语义召回方案。第一阶段用对比学习训练，并引入 false-negative margin mask 避免把近似重复商品当负样本惩罚；第二阶段提出 ROAR（Relative Odds Alignment for Retrieval）偏好优化目标，把 Bradley-Terry 扩展到可变长度的分级相关性分组，用相邻档位的 odds-ratio margin 做排序对齐。训练语料同步分级：Stage1 用替代品 query-商品对提供粗粒度语义监督，Stage2 用分级相关性标注驱动细粒度排序。

Scaling Search Relevance: Augmenting App Store Ranking with LLM-Generated Judgments

Apple📖 深度解读 · 13 分钟 →

商业搜索同时优化行为相关性（用户点击/下载）与文本相关性（语义匹配），但专家标注的文本相关性标签相对海量行为标签极度稀缺。论文系统评估多种 LLM 配置，发现经过专门微调的小模型在生成高相关性标签上显著优于规模大得多的预训练大模型；以该最优模型为「放大器」生成数百万条文本相关性标签，用于增强 App Store 生产排序器。结果显示注入 LLM 生成判断后线上排序相关性获得提升。

INSIGHT直接回应「文本相关性标注稀缺」这一搜索团队普遍痛点：与其用超大模型零样本打标，不如用领域微调的小模型批量生产标签做数据扩增，性价比更高。把 LLM 判断作为弱监督信号注入生产排序器、而非直接替换排序器，是工业界落地 LLM-as-judge 的稳妥路径，可直接迁移到社区搜索的相关性样本扩充。

Whole-Pool Setwise Reranking with Long-Context Language Models

University of QueenslandCSIRO

传统 LLM 重排因上下文受限需要大量相互依赖的模型调用，既慢又贵。论文研究长上下文 LLM 如何改变这一问题：当全部候选段落能一次性喂入模型时，排序不再需要从大量局部比较中重构。提出 Whole-Pool Setwise 重排——每次调用考虑当前所有未排序候选；并提出 DualEnd，一次调用同时识别最相关和最不相关段落，从两端向中间填充排序，对 100 个候选仅需 50 次串行调用（对比逐段方法的 99 次）。在 9 个开源权重 LLM、两个段落重排基准上验证。

INSIGHT长上下文重排的「从两端夹逼」思路把串行调用次数近乎减半，是 LLM listwise 重排在延迟敏感线上场景的实用优化。相比逐段/滑窗重排，whole-pool 一次看全局避免了局部比较的不一致，对召回池规模适中（百量级）的搜索重排直接可用；9 个开源模型的横向验证也降低了选型风险。

Hang Li, Chuting Yu, Teerapong Leelanupab, Bevan Koopman, Guido Zuccon

Test-Time Training for Zero-Resource Dense Retrieval Reranking

稠密检索擅长一阶段召回但在零资源场景缺乏有效重排：cross-encoder 重排质量高却需昂贵监督训练且延迟高，而无监督 BM25 重排在 BEIR 多数子集上反而拉低稠密检索效果。提出 DART（Dense Adaptive Reranking at Test-time），在推理时为每个 query 自适应打分函数——把 top 文档当伪正例、bottom 文档当伪负例，提供噪声但即取即用的监督，对一个双线性打分矩阵 W 做少量梯度更新；并引入置信度加权 margin loss 与跨 query 机制。

INSIGHT在完全无标注的新域上做重排，DART 用「检索自身的排序」造伪标签做测试时自适应，避免训练 cross-encoder 的成本，是冷启动域、缺标注垂搜场景的轻量增益方案。仅更新一个双线性矩阵 W 把测试时训练的开销压到可接受范围，思路可借鉴用于社区新话题/新品类的零样本重排。

Shiyan Liu, Yichen Li

Reconstructing Content via Collaborative Attention to Improve Multimodal Embedding Quality

CASBaidu

基于 MLLM 的多模态 embedding 多依赖大规模对比学习，少有人研究 MLLM 的架构与训练范式如何影响 embedding 质量。论文指出 MLLM 的因果注意力与 next-token 预测范式不显式鼓励形成全局紧凑表征，限制了其作为多模态 embedding backbone 的效果。提出 CoCoA：一种基于协同注意力（Collaborative Attention）的内容重建预训练范式，重构注意力流并引入 EOS 相关机制来优化多模态 embedding，在检索与分类任务上提升表现。

INSIGHT点出 MLLM 直接当 embedding 模型的根本缺陷——因果注意力不利于全局表征——并用内容重建预训练补足，对要做图文混排 UGC 内容召回的团队有直接参考价值。相比单纯堆对比学习数据，从注意力结构和预训练目标层面改造 backbone 是提升 embedding 质量的另一条路径；来自中科院+百度的组合也意味着有工业检索场景验证。

Rerank Before You Reason: Analyzing Reranking Tradeoffs through Effective Token Cost in Deep Search Agents

University of Waterloo

Deep research agent 依赖迭代检索与推理回答复杂 query，但扩展测试时计算带来显著效率问题。论文研究如何在深搜流水线中分配推理预算，聚焦 listwise 重排的作用，用 BrowseComp-Plus 基准、提出新的 effective token cost（ETC）指标，分析模型规模、推理强度、重排深度与总 token 成本之间的权衡。结果表明重排稳定提升检索与端到端准确率，且适度重排往往比增加搜索时推理带来更大收益，能以显著更低成本达到相当准确率。

INSIGHT用统一的 ETC 指标把「重排」和「多想（推理）」放在同一成本尺度上比较，给出可操作结论：在深搜/Agentic RAG 中先把重排做好，比盲目堆推理 token 更划算。对预算敏感的检索增强应用，这是一个明确的资源分配先验——优先投入重排深度而非推理长度，代码已开源便于复现。

Sahel Sharifymoghaddam, Jimmy Lin

Self-Conditioned Positional HNSW for Overlap-Aware Retrieval in Chunked-Document RAG Systems

分块文档检索是 RAG 常见组件：文档切成重叠 chunk 后计算 embedding 并用 HNSW 等近邻检索索引。重叠能改善边界覆盖，却带来失效模式——top-k 常返回相邻 chunk，重复证据并浪费 prompt 预算。提出 SCP-HNSW：给 chunk embedding 追加低维位置编码，用两遍 query 流程估计并施加 query 相关的文档位置先验；保持 HNSW 图构建与遍历不变，仅在最终上下文构造时加一个可审计的最小索引间隔选择器，并给出工业级证据质量审计。

INSIGHT针对 RAG「召回回来一堆相邻重复 chunk」这一实际工程痛点给出轻量解法：不改 HNSW 索引本身，只加位置先验与最小间隔去重，落地成本极低且可审计。对做长文档/帖子内容检索的团队，这类「overlap-aware 去冗余」技巧能直接节省 prompt 预算、提升上下文多样性。

Nataraj Agaram Sundar, Tejas Morabia

Lighting the Way for BRIGHT: Reproducible Baselines with Anserini, Pyserini, and RankLLM

University of Waterloo

面向 RAG 中常见的长、推理密集型 query，检索基准应反映这类场景。论文系统研究 reasoning 导向检索基准 BRIGHT，并把强、可复现的参考方法集成进 Anserini、Pyserini、RankLLM，在长 query 设定下评测词法、稀疏、稠密、融合检索与 LLM 重排。复现 BRIGHT 词法基线时发现一个被低估的细节——query 端 BM25（BM25Q），即对 query 本身做 BM25 加权；在长多句 query 上 BM25Q 持续优于标准 BM25，是 reasoning 检索最强词法基线。同时审计语料发现影响评测的数据质量问题。

INSIGHTBM25Q 这一「对长 query 自身做词频加权」的小改动能让经典词法基线在 reasoning 检索上反超，提醒做 LLM 检索评测时不要轻易认定 BM25 弱、再用它当 strawman。集成进 Anserini/Pyserini/RankLLM 的可复现 pipeline 对搭建内部检索评测基线极有价值，语料质量审计也是评测可信度的必要环节。

Sahel Sharifymoghaddam, Yijun Ge, Jimmy Lin

From Noise to Order: Learning to Rank via Denoising Diffusion

MicrosoftUniversity of Toronto

传统 learning-to-rank（LTR）多为判别式方法，建模给定 query-文档特征下文档相关的概率。论文提出一种基于去噪扩散的生成式 LTR：建模特征向量与相关性标签的完整联合分布。作者假设，相比判别式过参数化模型可能以不同方式拟合训练数据，能解释完整数据分布的生成式候选解更善于估计相关性。据此提出 DiffusionRank，扩展已有的 TabDiff 去噪扩散框架到排序任务。

INSIGHT把 LTR 从判别式重构为生成式（建模 query-文档-标签联合分布）是范式层面的新尝试，理论动机是生成式解的泛化性更好。虽然当前仍偏研究阶段、线上延迟与扩散采样成本待验证，但对探索下一代排序模型范式的团队值得关注，可作为判别式 LTR 之外的对照思路。
