MBD: A Model-Based Debiasing Framework Across User, Content, and Model Dimensions

现代推荐系统通过聚合多种行为信号（如观看时长、循环播放率、评论概率）来排序候选内容，但这些信号存在异质性偏差——观看时长偏向长视频，循环播放率偏向短视频，评论概率偏向视频而非图片。MBD（模型驱动去偏）框架从用户、内容、模型三个维度系统性地建模和消除这些偏差，通过条件期望估计"内在信号"（independent of heterogeneous biases），使排序分更好地反映用户真实偏好。论文还指出，去偏框架可防止值模型规则变更引发的生态突变，提升系统稳定性。

KEY INSIGHT · 对业务意味着什么该框架的核心创新是将多信号去偏从样本层面提升到模型层面：不是修改训练目标，而是通过对用户×内容×模型三个维度的偏差因子建模，在推断阶段校正信号期望。对于社区搜索的CTR/排序模型实践启示：(1) 不同类型内容（长文/短文/图/视频）的行为信号存在结构性偏差，需要分维度建模；(2) 跨内容类型的多信号聚合需要先"对齐"偏差再融合，否则会压制特定格式的内容；(3) 该去偏方法可以无缝嵌入已有排序模型，工程成本低。

R3-REC: Reasoning-Driven Recommendation via Retrieval-Augmented LLMs over Multi-Granular Interest Signals

序列推荐面临两大顽疾：冷启动稀疏导致证据不足，以及跨时间维度的多层次用户意图建模不透明。R3-REC（推理-检索-推荐）是一个以提示为核心的检索增强框架，统一了五种模块：多层次用户意图推理、物品语义提取、长短兴趣极性挖掘、同类用户协同增强，以及基于推理的兴趣匹配与打分。在ML-1M、Games、Bundle三个数据集上，R3-REC相比强基线模型取得了最高+10.2%（HR@1）和+6.4%（HR@5）的提升，展示了RAG与多粒度意图建模结合的有效性。

INSIGHTR3-REC最大的技术价值在于"可解释的多粒度意图"：传统序列推荐将用户历史压缩为单一向量，无法区分短期兴趣与长期偏好。R3-REC通过LLM推理显式分解多层次意图，再用检索增强补充稀疏证据。实践启示：(1) 长短兴趣极性挖掘可借鉴到社区搜索的用户会话建模；(2) 同类用户协同增强是冷启动问题的可行方案；(3) 该框架的模块化设计便于按需集成到已有推荐流水线；(4) 端到端延迟需测试，LLM推理可能带来响应时间开销。

Yuchen Miao, Mingxuan Cui, Yitong Zhu, Yu Wang, Siyang Xu

Post-hoc Popularity Bias Correction in GNN-based Collaborative Filtering

协同过滤（CF）训练数据的长尾分布导致模型学到"热门偏差"：少数高曝光物品占据大部分交互，GNN的消息传递机制进一步通过邻域聚合放大这一偏差。本文提出一种"事后纠偏"（post-hoc）方法——不修改训练目标，而是在已训练的GNN-CF模型的推断阶段直接校正因热门偏差引入的节点 embedding 偏移。这意味着该方法可无需重新训练地插入到已部署模型，大幅降低工程成本。在多个基准数据集上，v2版本进一步验证了跨GNN架构的泛化能力。

INSIGHT事后纠偏的核心价值在于"解耦训练与部署"：生产环境中的推荐系统往往因训练成本高而难以频繁迭代，但偏差问题又需要及时修正。post-hoc方法允许在不改变模型权重的前提下动态调整推断阶段的表示。对社区搜索的实践启示：(1) UGC内容同样存在严重的热门偏差（头部帖子获得大量曝光），可借鉴该方法；(2) 节点 embedding 校正框架可推广到双塔模型的用户/物品 embedding 后处理；(3) 对于已上线的GNN召回模型，可以低成本插入偏差校正层进行AB测试。

Md Aminul Islam, Elena Zheleva, Ren Wang

04 3.45

Iterative Semantic Reasoning from Individual to Group Interests for Generative Recommendation with LLMs

现有LLM推荐方法将用户历史行为语义化后直接进行语义集成，忽略了从显式个体兴趣到隐式群体兴趣的推理过程。ISRF（迭代语义推理框架）提出三步流程：(1) 对物品属性进行多步双向推理；(2) 从个体兴趣向群体兴趣的跨层次语义推理；(3) 迭代精化用户兴趣表示。该框架将用户行为理论中的"社会性兴趣推断"引入生成式推荐，通过LLM的推理能力填补个体兴趣表达与群体偏好模式之间的语义鸿沟，在多个推荐数据集上超越基线方法。

INSIGHT从个体到群体的"兴趣推理"是该框架的创新核心——传统协同过滤在embedding空间做用户相似度，而ISRF在语义空间做群体兴趣推断，两者互补。实践启示：(1) 群体兴趣推断可以作为冷启动用户的兴趣初始化手段；(2) 多步双向物品属性推理可提升对话式推荐场景下的意图理解准确性；(3) 迭代精化框架较一次性生成更稳定，但需要权衡推理次数与延迟；(4) 该方法对社区UGC的标签/类目体系质量有依赖，需确保物品属性的丰富度。

Xiaofei Zhu, Jinfei Chen, Feiyang Yuan, Zhou Yang

Bringing Model Editing to Generative Recommendation in Cold-Start Scenarios

生成式推荐（GR）在冷启动场景下存在严重的"冷启动崩溃"问题：新物品的推荐准确率可降至接近零。现有解决方案依赖于重新训练，但稀疏反馈、高计算成本和延迟更新限制了其实用性。本文借鉴NLP中的模型编辑（Model Editing）范式——无需重新训练即可向LLM注入新知识——将其迁移到生成式推荐系统。论文解决了GR与LLM的关键差异（缺乏显式主-宾结构），提出专门的编辑方法使GR模型在无需重训的情况下快速感知新物品，显著缓解冷启动崩溃。

INSIGHT将NLP模型编辑迁移到推荐系统是一次有价值的范式迁移：知识注入取代重训在语言模型中已成熟，但推荐系统的"隐式知识结构"（行为历史而非事实三元组）给迁移带来了障碍。实践启示：(1) 对于新品上线频繁的电商/社区场景，模型编辑可作为快速"暖身"手段，在累积足够交互数据前保持推荐可用性；(2) 无需重训的特性使其可集成到在线学习流水线；(3) 模型编辑通常有容量限制，大规模物品更新时仍需周期性全量重训；(4) 冷启动物品的内容特征（标题、标签）是编辑注入的核心输入。

Chenglei Shen, Teng Shi, Weijie Yu, Xiao Zhang, Jun Xu

06 3.20

Multi-Scenario User Profile Construction via Recommendation Lists

用户画像构建是推荐个性化的基础，但不同信息条件下画像构建的能力差异缺乏系统评估。本文提出RAPI（基于推荐列表的用户属性分析框架），通过代理推荐模型+预训练BERT内容 embedding 来模拟原始推荐模型的行为，从推荐列表中推断用户属性（无需直接访问私有交互数据）。研究设计了四种分析场景评估画像能力：仅有历史交互、仅有曝光列表、有/无显式反馈等，揭示了不同信息条件对画像质量的影响规律，为隐私保护下的用户建模提供了实用框架。

INSIGHTRAPI的核心价值在于"仅依赖推荐列表推断用户属性"——不需要用户的原始行为日志，只需知道系统给用户推荐了什么，即可估计用户偏好。这对于隐私监管严格的场景（GDPR、App隐私政策）特别重要。实践启示：(1) 社区平台的AB测试中，可通过分析实验组的推荐列表变化来检测用户画像的漂移；(2) 在用户冷启动阶段，可以用平台已有的曝光列表作为初始画像信号；(3) BERT内容 embedding+代理模型的组合可推广到多模态UGC内容；(4) 四场景评估框架可直接借鉴用于自身画像系统的能力评测。

Hui Zhang, Jiayu Liu

Federated Personal Knowledge Graph Completion with Lightweight Large Language Models for Personalized Recommendations

FedTREK-LM 融合联邦学习（FL）、演化个人知识图谱（PKG）、轻量级LLM（Qwen3 0.6B/1.7B/4B）和Kahneman-Tversky优化，实现无需集中用户数据的个性化推荐。框架用结构化PKG提示LLM进行上下文感知推理，在电影和菜谱推荐任务上，三种Qwen3模型（0.6B至4B）均显著优于基线。该工作是首个将联邦学习与演化知识图谱+LLM推理深度集成的推荐框架，探索了在本地设备上实现高质量个性化的可行路径。

INSIGHT联邦+PKG+LLM的组合揭示了一条在严格隐私约束下实现强个性化的技术路径：PKG在设备本地维护用户的偏好图谱，LLM基于图谱进行推理而非直接暴露原始数据。实践启示：(1) Kahneman-Tversky优化（基于前景理论的损失函数）比传统BCE更能捕捉用户的非线性偏好——可单独借鉴到中心化推荐模型中；(2) 轻量级LLM（0.6B）的引入表明边缘部署推理能力逐渐可行；(3) 演化PKG的动态更新机制可借鉴到用户兴趣的在线学习；(4) 当前联邦通信开销仍是工程难点，暂不适合大规模生产部署。

Fernando Spadea, Oshani Seneviratne

08 3.20

A Counterfactual Approach for Addressing Individual User Unfairness in Collaborative Recommender System

协同过滤模型在更新所有用户embedding时会忽略对"低活跃度用户"的个体化偏差——这部分用户往往获得质量更差的推荐，造成个体不公平（Individual User Unfairness，IUUP）。本文提出反事实（Counterfactual）方法直接建模每个低活跃度用户的个体偏差：通过构建反事实用户档案（假设该用户有足够交互历史时应有的embedding），计算实际embedding与理想embedding之间的差距，并在训练阶段对此差距进行校正，提升低活跃度用户的推荐质量，同时对高活跃度用户影响最小。

INSIGHT反事实建模是处理推荐公平性的有效思路：不从数据增强角度弥补稀疏，而是从模型的"假设推理"角度量化偏差。对社区搜索的实践启示：(1) UGC平台新注册用户（低活跃度）的推荐体验是关键留存指标，该框架的个体纠偏思路可直接应用；(2) 反事实用户档案构建可与现有冷启动内容特征方案结合（利用内容embedding估计理想交互embedding）；(3) 该方法的额外计算开销主要在训练阶段，推断阶段无额外成本；(4) 对于内容侧公平性（如新创作者曝光），类似的反事实物品偏差建模思路也值得探索。

Nikita Baidya, Bidyut Kr. Patra, Ratnakar Dash

09 3.20

Shopping Companion: A Memory-Augmented LLM Agent for Real-World E-Commerce Tasks

电商LLM Agent在长对话场景下面临两大挑战：(1) 缺乏可评估长期偏好感知购物任务的基准；(2) 现有设计将偏好识别与购物辅助视为独立模块，无法端到端优化。Shopping Companion提出统一框架，同时处理记忆检索与购物辅助，并发布新基准（覆盖120万真实商品、两类购物任务、长期记忆设置）。框架采用记忆增强LLM捕捉跨对话轮次的用户偏好演化，在基准上显著优于无记忆的基线Agent，展示了记忆机制对个性化推荐质量的关键作用。

INSIGHTShopping Companion的核心贡献是将"长期记忆"与推荐推理联合优化——这解决了传统对话推荐中每次对话从头理解用户偏好的问题。实践启示：(1) 120万商品规模的基准为社区电商搜索的LLM Agent评估提供了参考框架；(2) 记忆增强模块可作为独立组件嵌入现有推荐系统，将对话历史转化为结构化用户偏好；(3) 端到端优化偏好识别+推荐的思路可推广到社区搜索中的"会话级个性化"；(4) 需关注记忆存储与检索的延迟开销，特别是在实时推荐场景中。

Zijian Yu, Kejun Xiao, Huaipeng Zhao, Tao Luo, Xiaoyi Zeng
