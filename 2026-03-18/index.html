Not All Queries Need Rewriting: When Prompt-Only LLM Refinement Helps and Hurts Dense Retrieval

本文系统研究了仅基于 prompt（无检索反馈）的单步 LLM query 改写对稠密检索效果的影响。在 BEIR 基准、多个稠密检索器和不同训练配置下进行了全面实验，发现改写效果具有强烈的领域依赖性：在 FiQA 数据集上 nDCG@10 下降 9.0%，在 TREC-COVID 上提升 5.1%。研究揭示了 query 改写在 RAG 生产流水线中的适用边界，提示「并非所有 query 都需要改写」。

KEY INSIGHT · 对业务意味着什么LLM query 改写并非万能：对于本身已明确的 query，无反馈的 prompt-only 改写反而可能引入噪声、降低检索精度。在社区搜索场景中，建议根据 query 类型（模糊/清晰）动态决策是否触发 LLM 改写，而非统一应用。实验结论支持构建「改写必要性分类器」，在推理成本与效果之间取得平衡，避免无效 LLM 调用。

Retrieval-Feedback-Driven Distillation and Preference Alignment for Efficient LLM-based Query Expansion

本文针对 LLM query 扩展的高推理成本问题，提出「检索反馈驱动的蒸馏与偏好对齐」框架（RFDA），将大型 teacher LLM 的扩展能力迁移至小型 student 模型。框架分两阶段：首先利用检索反馈生成高质量扩展对，然后通过偏好对齐训练 student 模型优先生成「对检索友好」的扩展词。相比直接使用大模型或 few-shot 方式，在保持扩展质量的同时大幅降低推理成本。

INSIGHTLLM query 扩展的核心瓶颈在于推理延迟，而非扩展质量本身。本框架通过将「检索反馈」纳入偏好对齐训练信号，使小模型习得大模型对检索有益的扩展行为。对于社区搜索而言，可基于此思路构建轻量级在线扩展模块：先用大模型离线生成偏好数据，再蒸馏为可部署的小模型，实现生成式 query 理解的低延迟落地。

Minghan Li, Guodong Zhou

Learning Retrieval Models with Sparse Autoencoders

Naver Labs

本文提出将稀疏自动编码器（SAE）应用于学习型稀疏检索（LSR），利用 LLM 内部可解释的稀疏特征构建检索表示。与现有 LSR 方法（将序列投影至词汇空间）不同，SAE-based LSR 将 LLM 稠密表示分解为高维稀疏特征，具有更强的可解释性。在标准检索基准上验证了方法有效性，打通了 SAE（近期 LLM 可解释性研究热点）与信息检索的结合路径。

INSIGHTSAE 作为 LLM 内部表示的「分解工具」，在可解释稀疏检索领域具有独特价值。相比传统词汇空间 LSR（如 SPLADE），SAE-based LSR 的特征更具语义意义，可在模型可解释性与检索效率之间实现更好权衡。对于社区搜索，稀疏检索天然适配倒排索引系统，SAE 路径进一步提升了特征的可调试性，在调试「相关但未召回」问题时具有优势。

Thibault Formal, Maxime Louis, Hervé Dejean, Stéphane Clinchant

FlashHead: Efficient Drop-In Replacement for the Classification Head in Language Model Inference

CChalmers University

本文提出 FlashHead，一种针对语言模型推理中分类头（classification head）的高效即插即用替换方案。随着词汇量不断扩大，分类头占模型参数量高达 60%、推理计算量达 50%，成为关键瓶颈。FlashHead 无需重新训练，通过近似矩阵运算实现硬件友好的加速，在不损失精度的情况下显著降低推理延迟。对于基于 LLM 的生成式检索系统（如 TIGER、生成式推荐），词汇表通常包含数百万 item ID，该方法尤为相关。

INSIGHT生成式推荐的核心瓶颈之一是 autoregressive 解码时对大词汇表的 softmax 计算。FlashHead 提供了一种无训练成本的工程优化路径，直接作用于 classification head，适配所有基于词汇生成的序列推荐模型。在部署 LLM-based 生成式召回时，若 item 词汇量达到百万级，该技术可带来显著的延迟和内存优化，是生产环境落地的实用加速方案。

Wilhelm Tranheden, Shahnawaz Ahmed, Devdatt Dubhashi, Jonna Matthiesen, Hannes von Essen

AMES: Approximate Multi-modal Enterprise Search via Late Interaction Retrieval

本文提出 AMES（近似多模态企业搜索系统），基于 Late Interaction 检索架构实现多模态统一检索。文本 token、图像 patch 和视频帧被编码至共享表示空间，无需针对不同模态进行架构改造即可部署在生产级搜索引擎中。通过近似最近邻（ANN）方法支持多向量的高效检索，在标准多模态检索基准和生产指标上均取得优于单模态基线的效果，并可无缝集成到现有搜索基础设施。

INSIGHTAMES 的核心贡献是将 ColBERT 风格的 late interaction 扩展至多模态场景，且保持「后端无关」（backend-agnostic）特性。对于 UGC 搜索平台（帖子通常包含图文混合内容），统一多模态检索意味着同一 query 可跨文本/图像/视频一次性完成召回，无需维护多套独立索引。生产部署的关键是 ANN 对多向量的支持，AMES 给出了一套可落地的工程参考。

Tony Joseph, Carlos Pareja, David Lopes Pegna, Abhishek Singh

Location Aware Embedding for Geotargeting in Sponsored Search Advertising

Yahoo

本文来自 Yahoo，研究如何将地理位置上下文融入搜索广告的 query 理解与匹配。提出位置感知 embedding 方法，将用户位置（经纬度、城市、地区）和 query 联合编码，用于赞助搜索的 geotargeting。在实际搜索流量上评估，证明位置感知 embedding 显著提升了 query-广告相关性匹配，尤其对「本地意图」 query 效果明显，在线 A/B 实验验证了方案的有效性。

INSIGHT地理位置是 query 上下文中最常被忽略的强信号之一。在社区搜索中，用户的位置信息同样可用于增强 query 理解（如本地生活、同城内容检索）。Yahoo 的实践表明，将位置 embedding 与 query 表示联合训练比后处理过滤效果更好，且可直接集成到现有双塔召回架构。对于有 LBS 属性的社区平台，地理感知 query 编码是提升本地内容相关性的低成本高收益方案。

Jelena Gligorijevic, Djordje Gligorijevic, Aravindan Raghuveer, Mihajlo Grbovic, Zoran Obradovic

A Survey of Model Architectures in Information Retrieval

UUWaterlooUtah

本综述系统梳理了 2019 年至今信息检索领域的模型架构演变，从 BERT 时代的 encoder-only 方法到当前的 decoder-only 生成式 LLM 方法。覆盖了稠密检索、稀疏检索、cross-encoder 重排序、生成式检索（DocID 生成）以及 LLM-based 多步推理检索等架构范式。特别分析了大模型在零样本和复杂推理场景下的突出表现，为从业者提供了从架构选择到部署决策的全面参考。

INSIGHTIR 架构已进入「生成式范式」时代：从 bi-encoder 召回到 cross-encoder 重排，再到 autoregressive 文档标识符生成，每个阶段都对应不同的延迟/效果权衡。综述指出，decoder-only LLM 在零样本迁移上表现突出，但推理延迟是生产环境的主要障碍。对搜索工程师而言，这份综述提供了架构选型的系统性视角，特别是对「generative retrieval 是否值得落地」这一问题给出了客观的分析框架。

Zhichao Xu, Fengran Mo, Zhiqi Huang, Crystina Zhang, Puxuan Yu, Bei Wang, Jimmy Lin, Vivek Srikumar

Learning Image-Text Matching with Optimal Partial Transport

Zhejiang University

本文提出 OMIT（跨模态 Sinkhorn 匹配网络），将最优偏运输（Optimal Partial Transport）引入图文跨模态匹配。传统跨模态匹配方法要求 query 与文档的所有 token 都参与对齐，而 OPT 允许部分对齐，更适合处理图文内容部分相关的现实场景。在标准图文检索基准（MS-COCO、Flickr30K）上取得最新最优结果，同时在效率上优于 late interaction 方法。

INSIGHT图文匹配中「部分相关」是常见现实：一张含多个物体的图片与一段文本可能只有部分内容重叠。OMIT 的偏运输框架在理论上更贴合真实 UGC 内容（图文帖子中图片和文字的局部相关性），可作为多模态召回的精排模型。对于社区搜索中的图文混合内容，OMIT 相比标准 CLIP 双塔能更精细地处理局部语义匹配，适合在精排/重排阶段部署。

Zhengxin Pan, Haishuai Wang, Fangyu Wu, Bailing Zhang, Jiajun Bu, Hongyang Chen

Compute Allocation for Reasoning-Intensive Retrieval Agents

本文研究在推理密集型检索 Agent 流水线中如何分配计算资源。随着 Agent 运行时间延长，记忆库不断增大，检索成为关键瓶颈。LLM 增强的 query 扩展和候选重排可以提升检索质量，但引入显著的推理开销。文章系统研究了在 query 扩展、候选生成和重排三个阶段中，不同计算预算下的最优分配策略，为实际部署中的推理成本控制提供了实证依据。

INSIGHT在 LLM-based 检索系统中，计算分配是工程落地的核心决策之一。研究发现并非每个检索步骤都需要等量的计算投入：在固定总预算下，将更多计算分配给 query 扩展往往比重排更具收益。这与社区搜索的实践相符——query 理解质量直接决定召回质量，而重排更多是锦上添花。该研究为构建「计算预算约束下的 LLM 检索系统」提供了实操参考。

Sreeja Apparaju, Nilesh Gupta

Towards Foundation Models for Consensus Rank Aggregation

本文研究将基础模型（Foundation Models）用于共识排名聚合（Consensus Rank Aggregation）问题。从多个输入排名中聚合出最优共识排名是 NP-hard 问题（Kemeny 距离最小化），现有方法难以规模化。作者探索用预训练 Transformer 直接学习排名聚合策略，在推荐系统、搜索引擎、选举等场景下的多排名融合任务上取得了比传统算法更好的效果，且支持大规模实例的推理。

INSIGHT多路排名融合在工业搜推中极为常见（如多模型融合、多业务线结果聚合）。传统方法依赖手工设计的投票或加权策略，而基础模型方法可直接从历史数据中学习最优聚合策略，具有更强的适应性。对于社区搜索中的多策略混排场景（如相关性分、时效分、质量分的融合），可将此类方法作为「自适应融合器」来替换固定权重规则，降低人工调参成本。

Yijun Jin, Simon Klüttermann, Chiara Balestra, Emmanuel Müller
