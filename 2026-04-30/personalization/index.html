Versioned Late Materialization for Ultra-Long Sequence Training in Recommendation Systems at Scale

针对 DLRM 超长用户行为序列训练时存储与 I/O 成为瓶颈、超过 GPU 训练算力的问题，本文提出 Versioned Late Materialization 范式：将 UIH 在归一化、不可变层中只存一份，训练时通过轻量化的版本指针即时重建序列。系统通过双协议保证流式与批量训练下的 O2O 一致性，并设计读优化的索引层支持多模型共享数据。论文报告该方案显著降低数据冗余，使数据基础设施使用率与 GPU 训练能力对齐，已在大规模工业训练中部署。

From Local Indices to Global Identifiers: Generative Reranking for Recommender Systems via Global Action Space

📖 深度解读 · 10 分钟 →

传统 list-wise 重排把任务建模为「从输入列表里选择本地下标」，导致同一个 logits 神经元在不同样本上代表不同物品，模型难以建立稳定的内在物品表征。论文提出 GloRank：用离散 token 序列把每个候选 item 编码成全局标识，再把重排重写成 token 生成任务。这样打分机制与可变长输入解耦，模型在所有样本上学习的是同一套物品语义。在公开数据集上 GloRank 在多项指标上明显优于传统 list-wise 重排基线。

INSIGHTReranking 的「行动空间」是一个常被忽略的设计变量，把 action space 从 local index 改成 global semantic ID 之后，模型获得跨样本可迁移的物品表征，从根上缓解了 list-wise 排序的语义不一致问题。对社区搜索 / 推荐重排的启示：当我们已经在召回侧构建了 Semantic ID（OneRec / TIGER 风格），重排端也可以复用同一套 ID 体系做生成式重排，让召回-重排共享物品表征空间，减少多阶段误差累积。

Pengyu et al.

Harmonizing Generative Retrieval and Ranking in Chain-of-Recommendation

OneRec 类生成式推荐通过 Semantic ID 自回归生成下一物品，但「next-item-agnostic」会 beam 出大量候选却难以排序。作者提出 RecoChain：在同一 Transformer 内同时承担候选生成与候选排序。推理阶段先按层次 Semantic ID 生成 top-N 候选，再用 SIM 风格的连续打分对候选进行点击概率估计，从而把生成与排序串联起来。在大规模真实数据集上 RecoChain 在端到端指标上同时优于纯生成式与传统两阶段基线。

INSIGHT生成式推荐和判别式排序长期被设计成两套不同范式，本文用一个 Transformer 同时承担两件事，证明 Semantic ID 表征足以承载排序所需的细粒度区分能力。对工业系统启示：在转向 OneRec / HSTU 风格生成式架构时，没必要保留旧的判别式精排塔；用同一 backbone 做检索 + 排序还能把训练目标对齐，减少召回与排序在偏好刻画上的偏差，是生成式推荐走向端到端的关键一步。

Yu Li et al.

Break the Inaccessible Boundary: Distilling Post-Conversion Content for User Retention Modeling

在 RTB 用户再激活广告中，留存模型需要在出价时刻预测未来回访概率，但此时用户尚未转化更没有消费 onboarding 内容。直接把 onboarding 内容当作训练特征会导致严重特征泄漏。OCARM 提出两阶段蒸馏对齐框架：阶段一刻意暴露 onboarding 内容训练 hierarchical encoder 作为 teacher；阶段二把仅依赖可观测特征的 user encoder 与 teacher 对齐，让线上模型在不直接看 onboarding 的情况下也能隐式捕获其信号。线上 A/B 显著提升留存预测精度。

INSIGHT训练-服务特征不一致是一个被低估的真实工业难题，OCARM 把这一问题形式化为「教师可见、学生不可见」的蒸馏对齐，比简单的特征屏蔽或时间窗对齐更优雅。对社区/电商再激活场景的启示：转化后内容 (onboarding 帖子、首日浏览、首次发言等) 蕴含极强信号，过去因为泄漏被弃用，蒸馏对齐让我们能把这部分信号「合规」灌入早期出价/排序模型，是处理迟到标签与未来特征的可复用范式。

Tianbao et al.

05 4.10

Action-Aware Generative Sequence Modeling for Short Video Recommendation

短视频内部不同片段用户态度差异大，传统二分类把视频当成整体的建模丢失了细粒度意图信息。作者通过统计分析发现「用户动作发生时间」本身能反映多种意图，进而提出 A2Gen：沿时间维度细化用户动作并串成动作序列，引入 Context-aware Attention 模块统一处理与预测。模型把传统多任务 (完播、点赞、关注…) 重写为同一个生成式序列预测目标，在短视频推荐基准与线上 A/B 上均显著优于传统多任务模型。

INSIGHT「用户在第几秒做了什么动作」携带的信号比传统二值标签丰富得多，把它当成一个生成序列建模能自然把多目标融合在一起，规避多任务塔之间的冲突。对推荐与 UGC 社区的启示：短视频/长帖/直播这种连续消费内容里，时序动作序列是更细粒度的偏好载体，未来精排可以从「分桶 0/1 标签 + 多塔」迁移到「细粒度动作生成」的统一范式，对完播率、停留时长等深度行为预估更友好。

Wenhao et al.

MemRec: Collaborative Memory-Augmented Agentic Recommender System

现有 LLM-based agentic 推荐为每个用户/物品维护独立的语义记忆，忽略了用户-物品共现、社区中同好关系等协同信号，对稀疏用户尤其不友好。MemRec 提出 collaborative memory：用一个共享的关系记忆把用户与物品语义连起来，并将记忆管理与推理解耦——用一个轻量记忆控制器决定调用哪条记忆，再把精炼后的相关条目交给下游 LLM，避免上下文爆炸与噪声。多个公开基准上 MemRec 在稀疏用户分桶下提升尤为显著。

INSIGHT把协同过滤的关键信号「peer 行为」显式编码进 LLM 推荐 agent 的记忆系统，是把协同信号与语义信号融合的一条可行路径；同时通过「记忆管理 vs 推理」解耦，缓解了 LLM agentic 推荐普遍存在的 context overload 与推理成本问题。对工业落地启示：纯 LLM agent 模式短期成本仍高，但 MemRec 这种「memory controller + LLM reasoner」架构可以让 LLM 只在必要时介入，是把 agentic 推荐裁剪到现实预算内的合理工程范式。

Weixin et al.

The Attention Market: Interpreting Online Fair Re-ranking as Manifold Optimization under Walrasian Equilibrium

作者在 20 个不同设置上系统评测了主流在线公平重排方法，发现各方法效果差异极大且原因不明。文章把公平重排重新形式化为「注意力市场」：把公平当作税收成本嵌入瓦尔拉斯均衡，并证明寻找该均衡等价于在由市场构造的排序流形上做梯度下降；不同重排场景导致不同的流形几何，从而决定了梯度景观和优化轨迹差异。该框架统一解释了多种 baseline 在不同流量/库存设置下表现波动的根因。

INSIGHT把公平/多样化目标当成「税收」纳入显式经济学均衡，比常见的硬约束/惩罚项更能描述长尾物品和热门物品在流量分配上的真实博弈；从流形几何角度看，许多重排方法只是在不同曲率的同一流形上滑动，效果差异更多是几何决定而非算法本身。对社区/内容推荐启示：在做长尾扶持、新作者冷启动等公平相关重排时，先识别业务流形几何，再选择对应的梯度策略，比盲目堆叠 fairness 损失更有效。

Personalized Multi-Interest Modeling for Cross-Domain Recommendation to Cold-Start Users

现有跨域冷启 (CDR) 方法要么共享一个映射函数忽略个性化，要么走 meta-learning 路线为每个用户单独学映射但忽略用户间共性偏好。作者提出 PMICDR：从源域用户行为中抽取多兴趣表征，再在目标域上通过个性化兴趣聚合得到用户画像，兼顾共享偏好与个性化映射。在多个公开 CDR 数据集上对冷启动用户的 Recall@K / NDCG@K 均显著优于 EMCDR、PTUPCDR 等基线。

INSIGHT跨域冷启动里，「共享映射 vs 个性化映射」长期是二元争论，本文用多兴趣作为中间粒度把两者统一起来：兴趣是用户共享的语义结构，但用户对兴趣的偏重是个性化的。对多产品矩阵 (社区+商城、长帖+短视频) 业务的启示：跨产品冷启可以围绕「兴趣 cluster」 而非用户 ID 或产品 ID 做迁移，新业务上线时不必等到用户行为足够再开始排序，可以借助源域兴趣分布即刻给出个性化首屏。

Disentangling Popularity and Quality: An Edge Classification Approach for Fair Recommendation

GNN 推荐普遍存在流行度偏置：高频被交互的物品权重被进一步放大，淹没了「冷门但优质」的物品。本文提出基于边分类的 GNN 框架：把用户-物品交互边分成「源于流行度」与「源于质量」两类，用代价敏感学习放大被错分代价，避免高质量长尾被无差别衰减。在多个公开数据集上公平性指标平均提升约 32%，相关性指标基本持平。

INSIGHT「长尾」并非同质，要区分「真低质量长尾」与「优质但冷门长尾」，否则统一去偏会牺牲整体推荐质量。在社区 UGC 场景下，新作者高质量内容、小众话题优质问答都属于第二类，这种「边类型分类 + cost-sensitive」的范式比单纯 IPS 去偏更可控；不过该方法依赖额外的边标签，工业落地时需考虑用代理信号 (停留、互动深度) 自动构造质量标签。

Nematollahi et al.

10 3.00

Measuring the stability and plasticity of recommender systems

传统离线评估只在固定 train/test 切分上给出快照分数，无法回答「线上用户行为模式漂移、模型频繁重训之后，过去的离线评测是否还可信」。作者提出从「稳定性 (保留旧模式) 」与「可塑性 (吸收新模式) 」两个维度系统评测推荐算法在多次重训中的行为，并设计了对应数据流和指标。在多个公开数据集上对若干主流模型族进行刻画，揭示出表面相近的算法在 stability/plasticity 上差异巨大。

INSIGHT离线 nDCG 单分数远不足以衡量推荐模型的真实生命周期质量，stability/plasticity 是工业推荐里更接近真实成本的维度——稳定性差意味着重训波动伤害用户体验，可塑性差意味着新内容/新趋势上不来。对社区搜索/推荐启示：在评测新精排或召回模型时，应增加「连续重训」类基准，把模型在 t、t+1、t+2 周的预测一致性与新热点吸收速度作为上线门槛之一，而不仅仅看单期 AUC。
