UnIte: Uncertainty-based Iterative Document Sampling for Domain Adaptation in Information Retrieval

针对神经检索器跨域泛化中的伪查询生成痛点，论文提出 UnIte：基于不确定性的迭代式文档采样方法。通过 (1) 过滤高随机性 (aleatoric) 的噪声文档；(2) 优先选择高认知不确定性 (epistemic) 的高学习价值文档来生成伪查询。在 BEIR 基准的小型与大型检索模型上，仅用平均 4k 训练样本就实现 +2.45 / +3.49 nDCG@10 的提升，显著优于以多样性为导向的现有采样基线。

KEY INSIGHT · 对业务意味着什么在 UGC 短文本搜索的领域迁移场景中，采样策略往往比模型规模更关键。UnIte 把贝叶斯不确定性分解显式地引入数据筛选，给出了"少而精"的伪查询生成范式，可直接复用到社区搜索冷启动域、新版块召回器微调等场景。其核心启示是：以 epistemic uncertainty 作为高学习价值信号、aleatoric uncertainty 作为噪声过滤信号，可将 fine-tune 数据量降到 4k 量级仍获得稳定提升，对线上低成本迭代非常友好。

MCGI: Manifold-Consistent Graph Indexing for Billion-Scale Disk-Resident Vector Search

University of Washington

论文针对图索引型 ANN 检索在高维空间下的 Euclidean-Geodesic 失配问题，提出 Manifold-Consistent Graph Indexing (MCGI)。其核心是利用局部内禀维度 (LID) 在搜索过程中动态调整 beam search 预算：用一段几何信息感知的范围替代单一标量超参，从而在不同维度的数据集上保持鲁棒性。论文给出流形一致连通性保持的理论分析，并在十亿级磁盘驻留检索上验证了召回—延迟权衡。

INSIGHT对短文本召回这类高维稠密向量检索场景，MCGI 提示我们：图索引最大的痛点不是构图，而是"统一参数" 在不同子空间表现差异巨大。把 LID 等几何特征作为路由预算调度依据，是 HNSW/DiskANN 之上少有的几何启发式优化思路。可考虑将 LID 估计接入现有图索引的 beam search 控制，理论上能在长尾 query 上把召回率与延迟同时改善，对社区搜索这种 query 分布极度长尾的业务尤其有价值。

Dongfang Zhao

Stop Using the Wilcoxon Test: Myth, Misconception and Misuse in IR Research

TU Delft

本文系统反驳了 IR 评估中将 Wilcoxon 符号秩检验作为 t-test 安全替代的常见做法。作者通过统计学教材综述、TREC 数据上的实证分析揭示：Wilcoxon 检验对独立性、对称性等关键假设的违反在 IR 检索指标中普遍存在，长期以来被误用且伪装为"非参数安全"。论文给出了在 nDCG/MAP 等指标上 Wilcoxon 与 paired t-test 的差异表现，并建议回归 paired t-test 或 bootstrap 替代。

INSIGHT对线上搜索 A/B 实验和离线 BEIR 类评估的工程实践直接相关：长期沿用的 Wilcoxon 显著性可能高估真实差异，导致错误上线决策。建议社区搜索团队在离线相关性评估中采用 paired t-test 或 bootstrap 来计算 nDCG@k 的置信区间，并对历史结论做敏感性回测。这是少有的"读完即可立刻改流程"的方法论文，比新模型更关键。

Julián Urbano

ADE: Adaptive Dictionary Embeddings -- Scaling Multi-Anchor Representations to Large Language Models

传统词嵌入用单向量表示一个词，对多义词和短文本检索的语义表达存在表征瓶颈。ADE 把多锚点 (multi-anchor) 词向量首次扩展到 LLM 规模：(1) Vocabulary Projection 把原本两阶段的 anchor 查找合并为单次矩阵运算；(2) Grouped Positional Encoding 让同一词的多个 anchor 共享位置编码以保留语义协同性。论文展示了在大模型规模上保持效率的同时获得多义性更丰富的词表示。

INSIGHT在 UGC 短文本检索中，一词多义和领域漂移是命中率瓶颈，单向量稠密检索表现尤其差。ADE 给出了"多锚点 + 单矩阵 lookup" 的高效实现路径，启示我们可以把多义 token 的多 anchor 直接接入双塔检索器或 query encoder，不引入太多在线计算开销。对社区里"苹果(水果) vs 苹果(公司)"、"小米(食物) vs 小米(品牌)" 这类典型多义词搜索是潜在解题方案。

(arXiv 2604.24940)

Controlling Authority Retrieval: A Missing Retrieval Objective for Authority-Governed Knowledge

论文提出 CAR (Controlling Authority Retrieval) — 一个区别于传统语义相似度的检索目标：检索给定语义锚点 q 当前"有效权威边界"。给出了 Theorem 4 (TCA=1 当且仅当满足 frontier inclusion 与 no-ignored-superseder)，以及 Proposition 2 关于任意 scope-indexed 算法 worst-case 上界的对抗证明。在三个真实数据集 (security advisories、SCOTUS overruling 等) 上，dense 召回 TCA@5 仅 0.270，二阶段方案达 0.975。

INSIGHTCAR 把"语义最相似" 与"事实权威性" 分离的视角，对社区搜索同样有借鉴：在涉及"最新版本""已被纠正/更新的回答""已被官方判定为正确答案"等任务上，纯 cosine 相似度天然失配。论文给出的 frontier-inclusion + no-ignored-superseder 的二阶段管线 (dense 召回 0.270 → 二阶段 0.975) 暗示：作弊回答覆盖、冲突纠错回答覆盖等任务，应单独建权威性目标，而不是塞进相关性 loss。

Andre Bacellar

IoDResearch: Deep Research on Private Heterogeneous Data via the Internet of Data

Peking University

针对现有 Deep Research 框架以 web search 为主、忽视私有数据的局限，IoDResearch 把异构资源封装为 FAIR-compliant 数字对象，进一步抽取为原子知识单元和知识图谱，构建出可多粒度检索的异质图索引。其上构建多 agent 系统支持可靠问答与结构化研究输出，强调对私有/本地科研数据的检索效率与可重用性。

INSIGHT把 deep research 思路从公网搜索迁移到企业/社区自有内容池，是端内 RAG 系统的重要演化方向。IoDResearch 启示我们：原始文档块 + 单一 dense 索引在长尾领域查询下检索效率低，应做好原子知识单元抽取 + 多粒度异质图，再上多 agent 编排。对社区搜索的"问题—回答—引用—衍生帖" 这种半结构化数据，FAIR 数字对象封装思想可作为统一表征接口的设计参考。

Zhuofan Shi, Zijie Guo, Xinjian Ma, Gang Huang, Yun Ma, Xiang Jing

Make Any Collection Navigable: Methods for Constructing and Evaluating Hypergraph of Text

UIUC

针对任意文档集合的浏览/导航问题，论文形式化了 Hypergraph of Text (HoT) 概念：用超图捕获文档间的隐式语义结构，使得集合可被像"加了超链接的网页" 一样浏览。提出多种 HoT 构造方法，并设计了 effort ratio 这一面向"用户找到目标所需努力" 的定量评估指标。实验显示即使简单 TF-IDF 基线也能在 effort ratio 上匹配 LLM 方法。

INSIGHT对社区搜索而言，"搜索" 与"探索/逛" 的边界正在模糊，HoT 把文档集合从无结构 list 升级为可导航超图，对 UGC 内容尤其契合 (帖子-评论-引用本就是隐式超边)。值得思考的是：TF-IDF 已能匹配 LLM —— 重型语义建模并不一定是结构化导航的关键，结构本身才是；可先用低成本特征构造导航超图，再叠加重排或个性化路径优化。

Dean E. Alvarez, ChengXiang Zhai
