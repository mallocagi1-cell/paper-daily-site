K-CARE: Knowledge-driven Symmetrical Contextual Anchoring and Analogical Prototype Reasoning for E-commerce Relevance

本文针对电商搜索相关性中 LLM 在工业场景里持续遭遇的 corner case 问题，指出主要瓶颈不是推理路径而是知识边界——参数化记忆缺乏对小众 query/商品的领域知识。作者提出 K-CARE 框架，包含两个互补模块：Symmetrical Contextual Anchoring (SCA) 用对称双向锚点把外部知识填入 LLM 的认知盲区；以及 Analogical Prototype Reasoning，通过原型类比把已知商品的判断模式迁移到不熟悉的长尾商品上。在多个工业相关性数据集上方法相比纯 RL 优化推理路径的基线取得显著提升。

From Citation Selection to Citation Absorption: A Measurement Framework for Generative Engine Optimization Across AI Search Platforms

面向 ChatGPT、Google AI Overview/Gemini、Perplexity 等生成式搜索引擎，论文提出“引用选择 + 引用吸收”两阶段测量框架，量化一篇网页是仅被检索到、被引用，还是真正被吸收进生成答案的语言/证据/事实结构。基于公开 geo-citation-lab 数据集（602 个受控 prompt、21,143 条搜索层引用、23,745 条引用级特征记录、18,151 个成功抓取页面、72 个特征）实证分析，发现引用广度与深度发散：Perplexity/Google 引用源更多但平均吸收率低，ChatGPT 引用源少但单源吸收率显著更高。

INSIGHT对社区平台是核心的“分发 vs 内容被消费”洞察：生成式搜索时代，UGC 内容能否被 AI 答案吸收取决于结构化、证据密度、措辞清晰度，不仅仅是被检索到。可借鉴的工程方向：(1) 给社区内容做“AI 友好度”评分（事实密度、可引用片段、结构化标签），(2) 监测站内内容在外部生成式搜索中的吸收率作为内容质量信号反哺排序，(3) 借鉴该论文 72 个特征体系做内容侧 GEO 优化。

Zhang Kai, Yao Jingang

Health System Scale Semantic Search Across Unstructured Clinical Notes

CCHOP

工业部署型论文：在大型儿童医院落地了一套语义搜索系统，索引 1.68 亿患者的 1.66 亿条临床笔记、4.84 亿条向量。系统使用 instruction-tuned qwen3-embedding-0.6B embedding 模型，向量存储在 storage-optimized 索引的托管数据库，全文元数据放在低延迟 KV 库，整体运行在 HIPAA 合规治理框架下。论文报告了 embedding 模型与 chunking 策略选型实验、医师标注的相关性评估、以及在跨笔记检索任务上的工程开销和可运营性数据。

INSIGHT对社区搜索语义召回的工程参考价值极高：qwen3-embedding 0.6B 在 4.84 亿向量级别可用，远低于很多团队默认的 1B+ 模型；chunking 策略与 instruction-tuned 提示工程对召回质量影响巨大。社区可借鉴的设计：把帖子按段落 + 评论楼层做混合 chunking，配合短指令版 embedding 提升 nDCG；同时用“廉价 0.6B + 重 reranker”两阶段架构控制成本，避免直接上 7B+ embedding 带来的索引爆炸。

BridgeRAG: Training-Free Bridge-Conditioned Retrieval for Multi-Hop Question Answering

多跳检索本质上不是单步相关性问题，但既有 RAG 方案常用对原 query 的相似度统一打分，导致后跳证据被错误排序。BridgeRAG 提出一个 training-free、graph-free 的检索方法，核心是三元打分器 s(q, b, c)（query, bridge, candidate），把“覆盖”与“打分”显式解耦：dual-entity ANN 扩展第二跳候选池保覆盖，bridge-conditioned LLM 判官在并发的推理链中选出正确链条做精排。在四个受控实验中显示该 conditioning 信号有选择性（并行链 query +2.55pp p<0.001、单链子集 ~0）且不可替代（用 LLM 生成的 SVO 文本替换检索段落性能崩盘）。

INSIGHT把“扩召回”和“判别推理链”显式分开，是一个非常清晰的 RAG 工程范式：召回阶段不要做太聪明的事，靠 entity ANN 把候选池搞大；判别阶段交给 LLM 做条件打分。社区搜索可类比：复杂 query（“x 和 y 的对比体验”）也可以拆成 bridge 实体 + 候选段落，让 LLM 判官在 dual-entity 候选里选最相关的桥接证据。最大的启发是 training-free 也能拿到显著增量，节省了维护 graph 索引的运维成本。

Andre Bacellar

Don't Stop Early: Scalable Enterprise Deep Research with Controlled Information Flow and Evidence-Aware Termination

Salesforce

针对企业深度研究 agent 频繁出现的“信息覆盖不均、context 爆炸、过早终止”三类失败模式，论文提出 EDR (Enterprise Deep Research) 架构。核心三件套：(1) 用 outline + reflection 把请求拆成覆盖驱动的目标列表；(2) 依赖图引导的执行 + 显式跨子任务信息共享，把 context 局部化；(3) 基于证据充分性的完成判定，强制 agent 持续收集直到达标。在内部销售赋能任务和公开 DeepResearch Bench 上整体优于多种深度研究基线，结果显示 dependency-controlled context 与显式证据充分性可以同时减少 premature stop 并提升报告深度与一致性。

INSIGHT对搜推团队做“AI 答主/搜索体验报告”等长程查询场景的设计参考：把 agent 的“何时停”从启发式（stagnation 信号）改成证据驱动（覆盖 + 充分性双门槛）能显著降低浅答比例。可借鉴的是 dependency-guided execution，把多步检索做成显式 DAG 而不是裸 tool-loop，避免 context 互相污染；以及 outline-reflection 拆解策略，对应 query 改写场景里的“先列大纲再分批召回”模式，比一次大召回更稳。

Prafulla Kumar Choubey, Kung-Hsiang Huang, Pranav Narayanan Venkit, Jiaxin Zhang, Vaibhav Vats 等 8 人

LLM-ReSum: A Framework for LLM Reflective Summarization through Self-Evaluation

首先做一次大规模 meta 评估：14 个自动摘要指标 × 7 个数据集 × 5 个领域（短新闻到 2K-27K 词的科学/政府/法律长文）× 1500+ 人工标注摘要。核心结论：ROUGE/BLEU 这类词面重合指标与人类判断弱相关甚至负相关，task-specific 神经指标和 LLM-as-judge 评估器对齐度显著更高，尤其在语言质量维度。基于此提出 LLM-ReSum 框架，无需微调，把 LLM 评估器与 LLM 生成器闭环耦合：生成 → 自评 → 反思修改，端到端做迭代摘要质量提升。

INSIGHT对 UGC 内容理解链路（标题改写、答案抽取、热门帖摘要）有直接应用价值：ROUGE 类离线指标对 LLM 生成内容的判别力已经失灵，应该把 LLM-as-judge 加进离线评估流水线。可借鉴 ReSum 的闭环范式做自动质检——生成的标题/摘要由独立 LLM 判官打分，低分自动反思修改，全程不需要新训练数据。值得注意的是该路径在模型规模较小时也跑得通，部署成本可控。

Huyen Nguyen, Haoxuan Zhang, Yang Zhang, Junhua Ding, Haihua Chen

Recursive Multi-Agent Systems

把 looped/recursive language model 这一新兴 scaling 维度从单模型扩展到多 agent。提出 RecursiveMAS 框架，把整个多 agent 系统统一建模为隐空间递归计算：用轻量 RecursiveLink 模块连接异构 agent 形成协作循环，支持隐式思维生成与跨 agent 隐状态传递；并设计了 inner-outer loop 学习算法做整系统协同优化（共享梯度跨递归轮做 credit assignment）。理论分析显示比纯文本通信的多 agent 系统计算复杂度更优，实验侧报告在多个推理任务上以更少 token 取得更强表现。

INSIGHT为搜索推荐里日益常见的“多模块协作 LLM 流水线”（query 改写 + 召回 + 重排 + 解释）提供了一个新思路：与其用文本互相 prompt（token 成本爆炸），不如让模块在隐空间共享中间状态。短期落地有难度（需要异构模型对齐隐表示），但中长期对降低 agent 推理延迟、提升迭代深度有想象空间。可作为研究跟进的方向，先在内部一致体系（同源模型 head 共享）上小步试。

Xiyuan Yang, Jiaru Zou, Rui Pan, Ruizhong Qiu, Pan Lu

AutoResearchBench: Benchmarking AI Agents on Complex Scientific Literature Discovery

BAAI

AutoResearchBench 是面向自主科研 agent 的文献发现 benchmark，包含两类互补任务：Deep Research（通过渐进多步探测精确定位某篇目标论文）与 Wide Research（综合收集满足条件的论文集合）。相比已有的 agent 浏览基准，该 benchmark 更突出研究导向（要求理解科学概念）、文献聚焦（细粒度文献利用）、复杂度（多步推理 + 海量证据综合），用以测试当前主流 agent 框架在科学文献场景下的真实能力上限。

INSIGHT对内部“AI 搜索答主”或“专家级查询”场景的评估体系建设有借鉴：现有 agent 基准多偏 web 通用浏览，离社区垂直领域（如学术/医疗/技术问答）的真实任务还有较大 gap。可参考 Deep / Wide 两类任务结构，自建社区版“目标定位 + 综合归纳”评测集——既测召回完整性，又测多步推理。该方法论比单纯看 nDCG 更能驱动 agentic search 产品迭代。

Lei Xiong, Kun Luo, Ziyi Xia, Wenbo Zhang, Jin-Ge Yao

GeoSearch: Augmenting Worldwide Geolocalization with Web-Scale Reverse Image Search and Image Matching

面向全球图像地理定位任务，传统 RAG + LMM 方法依赖固定参考库，对库外场景泛化弱。GeoSearch 把 web-scale 反向图像搜索集成到 RAG 流水线：用图搜从公开网页获取候选坐标 + 网页文本证据，作为额外上下文增强 LMM 提示。为抑制噪声，引入两层过滤——先做图像匹配筛选视觉相关页面，再用置信度门控丢弃不可靠证据。在 Im2GPS3k 与 YFCC4k 在去除数据泄漏的评估协议下显著优于既有基线。

INSIGHT对多模态 UGC 搜索（图片帖子、视频缩略图）有迁移意义：固定 embedding 库 + RAG 是当前主流，但社区图像分布快速漂移，开放域反向图搜可以补“长尾未见”场景。可借鉴的工程模式是“双层过滤管道”——视觉匹配先粗筛 + 置信度二次门控，避免低质 web 页面污染 LMM 上下文。该思路也适用于文本侧：当内部知识库缺位时，通过受控外部搜索 + 二次证据校验补足。

Tung-Duong Le-Duc, Hoang-Quoc Nguyen-Son, Minh-Son Dao

Four ways Google Research scientists have been using Empirical Research Assistance

Google

Google Research 博客分享了内部 Empirical Research Assistance（ERA）系统的四类使用方式：科研人员让 LLM agent 协助跑实验、分析数据、查找/综述文献、复现先前工作。文章给出一线团队的真实案例，说明 LLM agent 不是替代研究者而是把“调研 + 数据探查 + 实验配置”等耗时环节自动化，让科研聚焦在假设设计与结论解读上。属于对生成式 AI 在专业知识工作的内部最佳实践分享。

INSIGHT对“AI 答主/技术问答”产品的产品形态有启示：与其追求“一问一答的全能 agent”，不如把搜推工程师/研究员日常工作流（数据探索、文献调研、实验复现）拆成可由 agent 加速的独立 chunk，用更窄但更高完成质量的工具体验赢得用户。社区 UGC 平台可类比：让 agent 帮用户做“前置调研 + 经验汇总”而不是直接生成答案，在专业场景下更可控、更易获得用户信任。
