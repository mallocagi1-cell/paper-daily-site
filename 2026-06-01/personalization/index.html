Rec-Distill: An Industrial Distillation Pipeline for Large-Scale Recommendation Models

大推荐模型在 scaling law 下有明显收益，但工业系统受在线 serving 延迟约束只能上线轻量模型，造成离线扩参与在线部署的鸿沟。Rec-Distill 通过解耦训练、黑盒蒸馏、去偏机制和混合 batch-streaming 流水线，把大教师的收益迁移到小学生模型。教师规模扩到 24B dense 参数、行为序列长度 20K，在多个推荐与广告场景上学生模型蒸馏迁移率超过 60%。

KEY INSIGHT · 对业务意味着什么核心是用「黑盒蒸馏+解耦训练」把超大教师（24B、20K 序列）的能力压进满足延迟约束的在线学生模型，并用去偏机制缓解教师-学生分布差异。对工业搜推的启示：scaling 的收益不必直接上线，可先训大教师再蒸馏，>60% 迁移率说明这条「离线扩参、在线蒸馏」路线在广告/推荐多场景可复用；混合 batch-streaming 流水线适配推荐数据动态更新的特点。

LoopFM: Learning frOm HistOrical RePresentations of Foundation Model for Recommendation

📖 深度解读 · 9 分钟 →

传统知识蒸馏只把基础模型(FM)的单个标量预测传给垂直模型(VM)，随 FM 增大「迁移率」递减——单标量无法承载丰富的中间知识。LoopFM 把 FM 的中间层 embedding 结构化为 VM 的输入特征（如用户历史序列），开辟高带宽迁移通道，且 serving 时无需实时 FM 推理、不耦合两者架构。论文给出增益分解与迁移率理论分析，在三个公开数据集上 AUC 提升 6%+（TaobaoAd），工业级（十亿样本、万亿参数 FM）上把迁移率在 KD 基础上约翻倍。

INSIGHT关键洞察是「迁移什么」比「怎么蒸馏」更重要：用 FM 中间表示作为下游特征，比单标量蒸馏带宽高得多，且与 KD 互补、可叠加。工程上最大价值是解耦——离线缓存 FM 表示，在线 VM 不需实时跑 FM，规避了大模型 serving 延迟。对搜推团队：在已有 KD 管线上叠加「表示注入」即可再拿一部分 FM 收益，万亿参数 FM 场景迁移率翻倍证明其规模化可行。

Shali Jiang, Hua Zheng, Boyang Liu, Laming Chen, et al.

UniNote: A Unified Embedding Model for Multimodal Representation and Ranking

Xiaohongshu

Item-to-Item(I2I)检索是内容平台推荐与内容审核的基础环节，但通用多模态 embedding 在 I2I 上难以兼顾全局内容表示与细粒度局部检索，且 embedding 与 ranking 解耦管线效率低、精度-延迟难权衡。UniNote 提出统一的工业级多模态 I2I embedding 模型：两阶段训练，第一阶段用对比式 SFT 建立基础表示，第二阶段用强化学习(RL)按内容相关性精调排序质量，并针对不同粒度内容设计检索策略。

INSIGHT最值得借鉴的是「embedding 与 ranking 统一进一个模型」并用 RL 对齐相关性，避免了召回-排序两段式管线的累积误差与重复算力。对社区/UGC 短文本场景启示直接：小红书 Note 这类多模态 UGC 内容的 I2I 既要全局语义又要细粒度匹配，两阶段(对比 SFT→RL)范式可作模板；第二阶段用 RL 而非纯监督来精调 ranking，是把「相关性目标」直接写进 embedding 训练的实用做法。

Jinghan Zhao, Wenwei Jin, Anqi Li, ..., Yao Hu

Generative Spatiotemporal Intent Sequence Recommendation via Implicit Reasoning in Amap

AAmap

真实用户行为常是受时空依赖支配的意图流，而非孤立动作。论文定义生成式时空意图序列推荐(GSISR)任务：生成逻辑连贯且在复杂时空上下文中物理可执行的意图序列。LLM 推理能力强但直接工业部署受高延迟与「上下文不匹配/物理不可行计划」限制。GPlan 框架用两点解决：渐进式隐式 CoT 蒸馏，把显式推理压进保留的 latent token，让小模型继承规划逻辑而无需生成长推理文本；并引入机制对齐通用知识与真实世界时空约束。

INSIGHT亮点是「隐式 CoT 蒸馏」——把 LLM 的多步推理压缩进少量 latent token，使小模型在严格延迟下也能做复杂规划，避免在线生成长 reasoning。对搜推的启示：当业务需要 LLM 的推理能力但扛不住延迟时，可用 latent token 承载推理而非显式文本；高德的时空场景还提醒，生成式推荐要叠加「物理可执行性」约束，否则会产出不可落地的计划。

Sicong Wang, Ruiting Dong, Yue Liu, Bowen Zheng, et al.

ACE: Anisotropy-Controllable Embedding for LLM-enhanced Sequential Recommendation

SSKKU

LLM-as-Extractor 范式用大模型生成语义丰富的 item embedding 注入序列推荐(SR)，但 LLM 生成的 embedding 各向异性(anisotropy)严重——向量集中在相似方向，几何不均衡，微调时难以适配协同信号。ACE 用线性自编码器(LAE)重塑 embedding 分布：L2 正则项通过控制各维度离散度缓解各向异性，重构损失保持 item 间语义关系，在几何均匀性与语义保持间取得平衡，多数据集上稳定优于现有 LLM-enhanced SR 模型。

INSIGHT指出了 LLM embedding 直接用于推荐的一个被忽视的几何问题：各向异性导致协同信号难学。解法很轻——一个线性自编码器加 L2 正则即可重塑分布，几乎零额外推理成本，非常适合工业落地。对搜推团队：凡是把 LLM/预训练 embedding 接入召回或序列模型，都应先检查并校正各向异性（白化/LAE），这是用好语义向量的低成本前置步骤。

Dongcheol Lee, Hye-young Kim, Jongwuk Lee

ProRL: Effective Reinforcement Learning for Proactive Recommendation via Rectified Policy Gradient Estimation

Fudan

主动推荐(PRS)通过生成中间推荐路径引导用户偏好向目标 item 迁移，RL 适合优化这类序列决策。但朴素策略梯度有两个缺陷：路径级奖励分解成步级奖励后均值为正，产生与路径长度相关的偏置，使梯度偏好「延长路径」而非有意义探索；用整条路径奖励加权每一步忽略了分解结构，导致高方差。ProRL 提出两机制：Stepwise Reward Centering 减去期望奖励中和长度偏置（保证路径延长的期望梯度为零）；以及降方差的奖励分配修正。

INSIGHT价值在于把「主动引导用户偏好」形式化为 RL 并精确诊断出策略梯度的两类偏差(长度偏置、高方差)，再给出可解释的修正项。对搜推 RL 实践的直接启示：做多步/序列推荐的策略优化时，要警惕路径长度带来的系统性梯度偏置，reward centering 是简单有效的纠偏手段；该思路可迁移到会话推荐、多轮重排等需要长期收益建模的场景。

Hongru Hou, Tiehua Mei, ..., Jiaqing Liang, Deqing Yang

STAP: A Shuffle-Tokenized App Predictor with Ultra Long Context for Vocabulary-Free Mobile App Prediction

预测用户下一个要打开的 App 对资源管理与主动服务很重要，但现有模型依赖固定 App 词表，无法跨 App 生态泛化，且多依赖用户专属知识、冷启动困难。STAP 是无固定词表的 Transformer：通过 shuffle 机制把真实 App 身份随机重映射为虚拟索引，用超长上下文弥补丢弃的语义信息。理论证明在足够长上下文下，即便映射匿名，预测分布也会收敛到正确分布。跨大洲两数据集上取得强跨数据集零样本预测精度（固定词表方法此设定下完全不适用）。

INSIGHT最具启发的是「shuffle 去身份 + 超长上下文」实现词表无关的序列预测——靠行为序列的结构而非 item ID 语义建模，天然解决跨域迁移与新 item/冷启动。对推荐召回的启示：当 item 词表巨大或频繁变化(UGC、商品)时，可借鉴这种匿名化+长上下文的 ID-free 思路提升零样本/冷启动泛化；理论上的收敛保证也为「上下文长度换语义」提供了依据。

Chengyu Fan, Hang Liu

Quotient DAGs for Off-Policy Evaluation: Forward-Flow Importance Sampling and Exact Slate Propensities

离线策略评估(OPE)用行为策略采集的数据估计目标策略表现，在推荐/医疗等在线测试代价高的场景关键。标准重要性采样会把生成过程的细节当作有意义信息，例如自回归 slate 推荐器生成有序 item 序列，而奖励只依赖无序 slate——这造成冗余方差且计算昂贵(精确无序 slate 倾向需对所有生成顺序求和)。论文提出 quotient-DAG 视角，合并对评估等价的历史，并在合并图上用 target-to-behavior 前向流比分配权重；对集合充分的 next-item 接口给出 Forward-DP 动态规划，无需阶乘枚举即可算出精确无序倾向。

INSIGHT针对 slate/列表推荐 OPE 的一个真实痛点：自回归生成顺序引入的伪方差。解法是把「对评估等价的轨迹」商掉，用动态规划精确计算无序 slate 倾向，避免阶乘级枚举。对搜推离线评估的启示：当用生成式/自回归召回器且评估指标与顺序无关时，应在 OPE 中显式消除顺序这一 nuisance，可显著降低估计方差、让离线指标更可信——这是生成式推荐上线前评估的实用工具。

Ziwen Xie, Shaowen Xiang, Hongyu He, Dianbo Liu

Toward User Preference Alignment in LLM Recommendation via Explicit Context Feedback

传统推荐主要从点击/观看/购买等隐式信号推断偏好，忽视了用户通过评论、点评等文本提供的显式上下文反馈——这类反馈捕捉了用户选择背后的细致原因，是偏好对齐和可解释推荐的重要异质信息。忽视它会导致偏好错配并强化信息茧房。论文主张在下一代 LLM-based RecSys 中优先利用显式上下文反馈，系统梳理了推荐范式的演进，并论证当前 LLM 推荐仍偏重 item 元数据、低估了用户生成内容这一资源。

INSIGHT这是一篇方向性主张文，但对社区/UGC 搜索场景特别契合：评论、点评等显式文本反馈直接揭示「为什么喜欢」，是隐式行为信号无法替代的偏好对齐与可解释信号。实践启示是把 UGC 文本反馈纳入 LLM 推荐的输入与对齐目标，而不仅用 item 元数据；这能缓解茧房、提升可解释性。需注意该文以综述/主张为主、缺少强实验，落地仍需自建反馈抽取与对齐方案。

Weizhi Zhang, Wooseong Yang, ..., Liangwei Yang, Henry Peng Zou

Causal Representation Learning for Generalisable Recommendation

Spotify

在观测数据上训练的预测模型部署时常难以泛化，推荐系统尤甚：训练日志被部署策略、历史用户行为和平台过滤混杂，训练分布与 serving 时打分的候选分布差异大，使离线指标无法可靠预测在线表现。论文用因果表示学习(CRL)应对该分布漂移：提出信息论的解耦判据并证明其最优解只依赖输入的因果成分，再推导可从有限观测数据优化的可处理变分下界；作用域聚焦「分布漂移下更好泛化」，而非完整因果可识别。

INSIGHT切中工业推荐的核心痛点——离线-在线鸿沟与日志反馈回路偏置。思路是只保留输入的因果成分来抵御分布漂移，用变分下界使其可从普通观测日志优化，落地门槛低于完整因果识别。对搜推团队的启示：当离线 AUC 涨而线上不涨时，可能是被部署策略混杂的分布漂移所致，引入因果解耦表示有助于让离线指标更能预测线上；但该文偏理论、实验规模有限，需在自有数据上验证。

Yorgos Felekis, Michael O'Riordan, Oriol Corcoll, Ciarán M. Gilligan-Lee
