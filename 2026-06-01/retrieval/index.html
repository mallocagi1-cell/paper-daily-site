CoHyDE: Iterative Co-Training of LLM Rewriter & Dense Encoder for Tool Retrieval

agent 选工具时，用户说的是口语，工具库写的是技术说明，单靠微调检索编码器在模糊查询上会掉得很厉害。SAP 的做法是让大模型改写器把用户的话写成工具说明书风格的描述，编码器只用这些描述重训，改写器再按编码器的检索得分做 DPO，两边轮流训三轮。在约 1 万个工具的 ToolBench 子集上，模糊查询的 NDCG@5 平均提高 6.3 个百分点，标准查询只提高 2.5 个百分点。代价是每条查询多一次 4B 模型生成，延迟约 546 毫秒。改写器和编码器要一起训，各自训好再拼起来反而更差。

A Unified Structured Query Understanding Framework for Industrial Semantic Search

论文（LinkedIn，KDD-ADS 2026）提出统一的结构化查询理解框架，把 query 切分、成分标注、意图与属性抽取等子任务统一建模，产出结构化 query 表示供下游召回与排序使用，并在生产语义搜索上验证收益。

INSIGHT工业搜索常把 query 理解拆成多个互不一致的子模型；统一结构化框架既减少维护成本，又让下游召回/排序拿到一致信号。社区搜索的意图识别、属性抽取、改写可共享这一框架，是 query 理解工程化的直接参考。

Ping Liu, Qianqi Shen, Jianqiang Shen, et al. (LinkedIn)

No More K-means: Single-Stage Sparse Coding for Efficient Multi-Vector Retrieval

论文（ICML 2026）用稀疏自编码器替代多向量检索中的聚类（K-means）量化，使多向量表示可直接走倒排索引。相比 ColBERTv2，索引构建快 15 倍、检索延迟减半，且效果还有提升。

INSIGHT多向量检索精度高但量化/索引开销大；用单阶段稀疏编码替代聚类，让 late interaction 也能吃到倒排索引的效率红利。对想上多向量召回又顾虑成本的社区搜索，这条路径显著降低索引与延迟门槛。

Lixuan Guo, Yifei Wang, Tiansheng Wen, Aosong Feng, Stefanie Jegelka, Chenyu You

Latent Terms: Dense Retrievers Contain Trivially Extractable BM25-ready Zipfian Vocabularies

论文发现稠密检索器内部已学到「可检索」的稀疏特征，用稀疏自编码器即可把它们抽取出来，从而无需任何学习式扩展目标就能做稀疏（倒排）检索。

INSIGHT稠密语义能力可被「翻译」回稀疏词表，让已有倒排架构无需训练 SPLADE 式扩展即可获得语义召回。对存量倒排系统的社区搜索，这是把 dense 语义迁移到 sparse 通路的低成本桥梁，兼顾效率与可解释性。

Search for Coverage: Learning Coverage-Aware Retrieval with Augmented Sub-Question Answerability

论文提出 CoveR，用覆盖式的对比与蒸馏目标训练稠密检索，使召回结果覆盖 query 的多个信息侧面；在 90K 对的 SCOPE 数据上训练，nugget 覆盖率提升约 10%。

INSIGHT传统检索只追相关性，易召回大量同质结果；以「覆盖多个子问题」为目标能提升结果多样性与信息完整度。社区搜索中一个 query 常隐含多个意图，覆盖感知召回有助于一次性满足多面需求。

On the Practice of Scaling Search Conversion Rate Prediction

论文是搜索转化率（CVR）预估的生产级 scaling 实证：沿主干算力、embedding 参数、训练数据三个维度扩展，发现三者收益基本独立且可叠加，在低延迟 GPU 服务下综合提升 2.6%。

INSIGHT三条 scaling 轴近似独立可叠加，给出了在固定延迟预算下如何分配扩展资源的实证依据。社区搜索的相关性/CTR 模型同样面临算力-数据-参数取舍，这套 scaling 拆解可直接指导工程投入。

FLASH-MAXSIM: IO-Aware Fused Kernels for Late-Interaction Scoring

论文提出 IO 感知的 GPU 融合算子，计算 ColBERT 的 MaxSim 打分时不物化完整相似度张量，而是把 query/doc 分块流式经过片上 SRAM。在 A100 上获得 3.9 倍加速、推理显存降低 16 倍。

INSIGHTlate interaction 的瓶颈常在 MaxSim 打分的显存与带宽；借鉴 FlashAttention 式 IO 感知融合可大幅降显存提速。对要上多向量重排的社区搜索，这类底层算子优化决定了 late interaction 能否在线落地。

Beyond Similarity: Task-Aligned Retrieval for Language Models

论文主张纯语义相似度不足以选出真正有用的证据，提出任务对齐检索：以 passage 对下游 LM 任务的有用性、而非表面相似度来选取，从而召回更契合任务目标的内容。

INSIGHT相似 ≠ 有用，按下游任务有用性检索能避免召回高相似但低价值的内容。对接入 LLM 问答的社区搜索，这提示召回目标应从相似度转向「对最终回答的贡献」，与下游指标对齐。
