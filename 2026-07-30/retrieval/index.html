Bekko Embedding: Parameter-Efficient Multilingual Retrieval with Ultra-Compact Encoders

Bekko 将 22 层 mmBERT-small 裁剪为 4/13 层，并以约 11 亿多语对比样本、长文硬负例和 Matryoshka 目标训练超小型检索编码器。8M 活跃参数版本在 MMTEB 多语检索 nDCG@10 达 56.2，超过活跃参数多 40 倍的 BGE-M3；模型仅 124 MiB，单 GPU 约 3 天即可训完。

The Case Against Generation for Retrieval: Discriminative Language Models as Effective Retrievers

Meta

Meta 用共享 LLM 编码器、EOS 池化、跨域迁移、cross-encoder 蒸馏和用户塔潜在推理重做双塔召回。0.6B 双塔在 Amazon Toys 上 R@10 达 0.1078，较 8B OneRec-Think 高 35.3%；生产实验仅用传统 DLRM 0.5% 的训练数据即可达到同等 NE，并可通过量化获得 13.6% QPS 增益。

INSIGHTLLM 的语义能力不必以自回归生成方式进入全库召回；更稳妥的路径是让强 cross-encoder 做教师，把候选集排序分布蒸馏回可 ANN 服务的双塔。对社区搜索，这能保留现有向量索引和毫秒级链路，同时利用跨域预训练缓解新内容与模型陈旧问题，适合作为生成式召回的低风险对照组。

Beyond Self-Knowledge: Propagating Uncertainty Across Reasoning and Retrieval in LLMs

BeyondUncertainty 先让黑盒模型给出临时答案与置信度，只对低置信问题触发 top-5 TF-IDF 检索和第二次回答。六个 QA 基准、2.7 万个策略实例上，平均 token F1 为 0.483，高于全量检索的 0.467，同时少取回 20.4% 段落；但置信探测使总 token 用量反增 28.2%。

INSIGHT自适应检索不能只看召回次数，还要把探测成本计入端到端预算。社区搜索问答可先用离线验证集为不同模型冻结置信阈值，把低置信 query 升级到深检索；上线时同时监控回答 F1、检索量和探测 token，避免“少检索但更贵”的局部最优。

Chandan Kumar Sah, Xiaoli Lian, Li Zhang

AI-Assisted Knowledge Access for Legacy Enterprise Asset Management in Energy Operations: A Practical Retrieval System

OOPGDalhousie University

OPG 在遗留资产管理系统上叠加意图识别、query 改写、混合检索、语义增补与可追溯回答，覆盖文档、数据表结构和界面操作三类知识。试点中 P@5 从 0.56 升至 0.72、MRR 从 0.43 升至 0.58、nDCG@5 从 0.51 升至 0.66，任务中位耗时由 14.2 分钟降到 8.3 分钟。

INSIGHT工业收益主要来自数据侧语义治理：补齐表字段描述、统一缩写、索引代表性行，比单纯更换向量模型更可控。社区 UGC 搜索可照此为短文本补充主题、实体和上下文描述，并把离线 nDCG 与真实任务耗时联合验收；论文样本较小，适合做试点设计参考而非直接外推收益。

SciClaimSeekers at CheckThat! 2026: Retrieving Scientific Sources for Social Media Claims with LLM Reranking

UUNT

SciClaimSeekers 面向社交媒体口语化陈述找原始论文，先并行运行 BM25 与零样本 multilingual-E5，再以 RRF（k=60）融合，最后用 Qwen2.5-14B 点式重排。英语开发集 MRR@5 达 64.36%，比 BM25 高 13.67 个点、比未重排混合检索高 10.17 个点，正式测试集为 64.39%。

INSIGHT该任务与社区搜索的语言错配高度相似：用户短句口语化，而目标内容更正式、更长。可先用稀疏召回保留实体与术语，用多语向量补语义，再仅对融合后的窄候选调用 LLM 重排；这种级联比让 LLM 直接检索全库更易控制成本，也便于逐层定位召回损失。

Mohotarema Rashid, Nansu Baniya, Anirban Saha Anik, Xiaoying Song, Lingzi Hong

Influence of Prompt Engineering on Small Language Models for Guarded Query Routing

SSDU

论文评测 22 个小模型能否在一次路由中同时识别合法意图并拒绝越域 query。少样本提示把 Mistral 7B 的 GQR-Score 从 81.79 提到 90.87，Qwen3.5 9B 达 95.74，距未优化的 Gemma 3 27B 仅 0.3 分；仅用 DSPy 签名还把 Granite 4 Tiny 从 54.29 提至 83.05。

INSIGHTquery 路由位于每次请求的关键路径，先做提示和输出格式优化，常比立刻微调更便宜。社区搜索可把垂类、敏感、越域和无结果意图合并为受保护路由任务，用调和平均数约束“分对类”和“拒绝错误请求”两端；弱模型若仍不稳定，再升级到 schema-aware 训练。

Structure-aware Relative Policy Optimization for Ranking

Tsinghua UniversityRUC

SRPO 不再只比较排序列表的标量奖励，而以头部加权 Kendall-tau 衡量排列差异，再用单位结构变化的奖励增益更新策略。组大小 8 时，Istella NDCG@10 为 0.7174、Yahoo 为 0.7707，分别高于 GRPO 的 0.7150 和 0.7671；在 7 个 BEIR 域外集上的平均 NDCG@10 也从 0.5124 提到 0.5286。

INSIGHT同样的 nDCG 奖励可能对应完全不同的重排幅度，若把它们视作等价样本，会造成头部位置过激更新。社区搜索用 RL 优化列表时，可将“收益/排列距离”作为相对优势，优先学习小而有效的头部交换；但上线前仍需用点击偏差和噪声奖励做压力测试。

CodeNib: A Multi-View Data System for Serving Repository Context to Coding Agents

UCSDStanfordUUCRUSC

CodeNib 为每个代码仓库提交维护词法、稠密和结构三类可复用视图，并统一提供排序搜索、符号导航和有界上下文。100 个快照上，图与向量增量更新中位速度分别快 8.7 倍和 25.4 倍；五个模型使用筛选后的上下文策略时，可在保持定位能力的同时减少 50%–87% 轨迹 token。

INSIGHT虽然场景是代码检索，但其“多视图、按变更维护、统一服务”的思路适用于高频更新 UGC。社区搜索可按内容版本维护词法、向量和关系视图，并明确各视图失效边界；这样既避免每次全量重建，也能按 query 类型选择证据，降低后续 LLM 阅读成本。

Three Sides of Retrieval: Factorial Evidence for Document-Side, Query-Side, and Answer-Side Complementarity in RAG

论文以文档目录引导页级检索：从视觉格式推断标题、建立并行标题索引，再加载完整章节，无需逐文档调用 LLM。8 份企业文档、1,280 个条件下，目录检索对回答质量效应量 d=0.41；与答案验证结合时比 query 分解加验证高 d=0.32，且只多取 2.9 页便贡献 20% 引用。

INSIGHT召回优化不应只盯 query 改写，文档结构和答案验证具有互补增益。对长帖子、问答串或专题页，可将标题层级、楼层和引用关系做成独立轻量索引，在命中后加载完整语义单元；这种零 LLM 索引方式比固定 chunk 更能保留上下文，也更容易解释引用来源。

Mapping CVEs to MITRE ATT&CK Techniques: A Curated Gold-Set Classifier and the Limits of LLM-Assisted Label Expansion

CCIRCL

论文用 1,207 条专家标注训练多标签排序模型，recall@5 约为零样本向量基线的两倍；校正验证流程后达到 0.673±0.019。加入 100–984 条 LLM 标签均无可靠收益：其与专家一致率仅约 0.39，接近 1,000 条时宏 F1 反而下降 0.04，测试集选 checkpoint 还可制造 0.05 的 recall@5 假差。

INSIGHT这是一条对 LLM 伪标签的强警示：扩大弱标签数量可能只放大评估噪声，而不是提升排序。社区搜索构造相关性标签时，应固定验证集做 checkpoint 选择、跨随机种子复验，并单独观察长尾 query；只有专家金标规模曲线持续改善后，才应把 LLM 标签接入训练主链路。

Cédric Bonhomme, Alexandre Dulaunoy
