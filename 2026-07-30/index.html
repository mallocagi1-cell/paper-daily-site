Reward Guided Decoding for Generative Recommendation

针对生成式推荐只按序列概率做束搜索、导致高业务价值候选被过早剪枝的问题，RGD 将解码写成带 KL 约束的奖励最大化，并在每个 SID 层注入奖励模型。三组 Amazon 数据上 Recall@10、NDCG@10 最高提升 11.49% 和 8.30%；快手两周 A/B 中页面 CTR、直播时长分别提升 0.392% 和 0.689%。

Tokens are All You Need: Dual-purpose Semantic IDs for Achieving LLM-Level I/O Efficiency in recommendation systems

YouTubeGoogle

论文让同一组 Semantic ID 同时承担协同身份与内容重建：层次量化把稠密向量压成离散 token，轻量 SiDec 在模型内按需还原语义，典型存储压缩达 50–100 倍。YouTube 线上排序中观看页满意互动提升 0.80%，离线检索 HitRate@100 达 0.2910，训练速度 14.53 step/s，高于直接输入稠密向量的 12.07。

INSIGHT这项工作的价值不只是“用 SID 做生成”，而是把 SID 变成跨日志、网络与模型执行图的语义传输格式，从根源缓解长历史的 I/O 墙。社区 UGC 可先对帖子多模态向量做层次量化，再以嵌套 n-gram 保留协同记忆、以 SiDec 补足冷启动内容信号。

Baolei Li, Yiping Yuan, Yilin Zheng, Likang Yin, Ling Liu, Fabio Soldo, Romer Rosales, Xinyang Yi 等 9 人

SPARC: Sequence-aware Progressive Attribute Routing and Compression Framework for Generative Recommendation

Alibaba

SPARC 解决生成式推荐中类目、品牌、价格、行为类型等字段显式展开会拉长序列、静态压缩又丢失上下文的问题；它先逐字段建模，再路由互补信息并把每次交互压成一个 token。在含 2100 万用户、2.6 百亿交互的淘宝数据上，HRclick@20 从 RankGR 的 0.1568 提升到 0.1669，Amazon Beauty 的 HR@100 从 0.1117 升到 0.1843。

INSIGHT关键顺序是“先上下文化、再压缩”：行为类型、时间衰减和卖家字段只有放进相邻行为后才知道是否值得保留。对社区短文本，帖子主题、作者、互动类型和新鲜度也可按同一思路动态路由，在不增加主干输入长度的前提下补足 SID 难以表达的瞬时上下文。

Chang Liu, Changfa Wu, Hui Qian, Binbin Cao, Jian Wu, Yuliang Yan, Han Zhu, Bo Zheng

VaLiDRec: Variable-Length LLM-Aligned Semantic IDs for Generative Recommendation

UQCASGriffith University

VaLiDRec 从原生 LLM 词表挑选可变长度 Semantic ID，经重要性估计、语义剪枝与碰撞修正后，用 token 集合预测替代自回归束搜索。Luxury 冷启动集上 Recall@100 为 0.2571，优于 RPG 的 0.2509；单样本推理从 LC-Rec 的 6.824 秒降到 0.078 秒，速度提升 87.49 倍。

INSIGHT固定长度、人工量化的 SID 同时造成语义过压缩和串行解码成本，VaLiDRec 说明“ID 长度适配内容复杂度”与“并行 token 打分”可以一起设计。对长尾 UGC，新帖可直接借助文本词表获得可解释标识，并用图软提示吸收互动结构，尤其适合冷启动召回。

Shutong Qiao, Wei Yuan, Tong Chen, Hao Wang, Quoc Viet Hung Nguyen, Hongzhi Yin

Grevo: A Unified Generative Recommendation Framework with Evolutionary Item Indexing

BBUPTUUIC

Grevo 不再把 SID 固定为内容 tokenizer 的一次性产物，而把标识分配视作可由用户行为反馈演化的离散变量；单一多任务推荐器同时做行为生成与语义落地，再用自身后验评估器重分配高风险 ID。在 5% 演化预算下，TIGER 于 Amazon Beauty 的 Recall@10 从 0.0648 提升至 0.0778，三个生成主干均获益。

INSIGHT索引不必与推荐器联合连续训练，也能随行为信号更新；这避免双模型、对齐损失和交替优化带来的不稳定。工程上可把 SID 演化做成低频离线作业，只替换冲突或高风险标识，并以固定词表和长度约束控制线上缓存、回滚与版本迁移成本。

Huanjie Wang, Liwei Guan, Zekai Sun, Hongwei Zhang, Honghui Bao

Two Views, One Voice: Evidence-Grounded Conversational Music Recommendation

NaverSSamsung

该系统将对话推荐的检索与回答生成解耦：词法—稠密混合池负责实体精确匹配，微调 Qwen-8B 池捕捉对话意图，LightGBM 校准后再由 PAS 框架生成有证据的解释。其外部元数据覆盖 47071 首曲目的 96.6%，公开测试 nDCG 达 0.2208、Recall@20 达 0.4400，并获 RecSys Challenge 盲测工业赛道第三名。

INSIGHT先把候选曲目和证据固定，再生成自然语言，是避免对话漂移与解释幻觉的有效边界。社区搜索可把帖子召回、排序与答案组织拆开：BM25 保住人名和话题词，语义池理解多轮意图，最终生成器只能引用已排序内容及其元数据。

Sungwook Yoo, Sewook Yoo

TopoGR: Revealing and Preserving Latent Structure of Semantic ID in Generative Recommendation

Xidian UniversityAlibabaUSTC

TopoGR 指出普通生成器把 SID 当独立类别，丢掉 tokenizer 已学到的邻域拓扑；它以可按位分解的二进制 SID、基 embedding 和 Hamming 一致性目标保留结构。在四个 Amazon 数据集上均居首，Toys 的 Recall@10 达 0.0995，较最强对照 0.0903 提升约 10.2%；同重叠数下 Hamming 近邻的 NDCG@10 可高出 1.99–6.22 倍。

INSIGHTSID 的价值不只在前缀共享，完整码之间的距离也应进入生成和重排。对语义相近但码位不重叠的 UGC，Hamming 软目标能提供平滑监督，减少热门内容独占精确匹配；部署前需评估二进制码本、碰撞率与现有向量索引的兼容成本。

Ziyu Zheng, Zhengshun Du, Yaming Yang, Bin Tong, Guan Wang, Meng Yan, Ziyu Guan, Wei Zhao

PAI-Rec HSTU Generative Ranking Algorithm Customization Best Practices

Alibaba

阿里云 PAI-Rec 给出 HSTU 生成式排序的可复现配置路径，覆盖数据准备、特征工程、推荐场景创建和模型方案配置 4 个环节，并提供公开数据集供验证。文档截至 2026-07-10 仅开放 1 类 DLRM-HSTU 配置，重点是模块化部署流程，没有给出新的离线对照或线上 A/B 指标。

INSIGHT这份实践的价值在于把论文架构映射为可操作平台组件，可用来快速搭建 HSTU 基线、验证特征与训练链路，再决定是否投入更复杂的 SID 和奖励对齐。评估时应自行补齐 nDCG、CTR、延迟和资源成本实验，不能把“配置可跑”直接等同于业务有效。

Alibaba Cloud PAI

LLM-as-a-Judge for Evaluating System Responses in Conversational Music Recommendation

KAISTDeezerSiriusXMIIdiap

论文用 20 个多轮音乐推荐会话、20 名领域专家和 400 条评分，检验 LLM 裁判对个性化与解释质量的可信度。GPT-5.4 与人工评分的 Pearson 相关在两维均为 0.51，Gemini-3.1-Pro 的个性化相关为 0.55；BLEU、ROUGE-L 等参考指标相关最高仅 0.16，且解释维度出现负相关。

INSIGHT对话推荐的生成质量不能继续只靠 BLEU 或单一 LLM 分数。可采用“多裁判相关性校准＋小规模专家金标＋偏差监控”：既看相关系数，也检查系统性高估；论文还显示冗长、流利但语义不变的回答会诱发偏差，适合加入社区搜索答案评测集。

Seungheon Doh, Bruno Sguerra, Sergio Oramas, Elena V. Epure, Juhan Nam

Sharpness-aware Model Merging with Salience Recovery for LLM-based Cross-Domain Sequential Recommendation

Zhejiang UniversityHHangzhou Dianzi University

SharpRec 面向 LLM 跨域序列推荐的参数冲突与多域融合饱和，先做锐度感知几何对齐，再恢复被合并过程抹平的显著参数。六个 Amazon 域上重复 5 次实验；Book→Movie 的 NDCG@5 达 79.93%，对比 LLM4CDSR 的 57.72% 提升约 38.5%，去掉几何对齐后 Sport→Toy 的 NDCG@5 从 0.6605 降到 0.4817。

INSIGHT跨域扩展未必需要集中训练或共享用户，模型合并可作为更灵活的知识拼装层，但必须显式处理参数方向冲突和显著性被平均的问题。迁移到社区多频道推荐时，应先做域间冲突诊断，并保留单域回滚模型，避免离线大幅增益掩盖线上分布偏移。

Huwei Ji, Jiajie Su, Yuyuan Li, Xiaohua Feng, Chaochao Chen
