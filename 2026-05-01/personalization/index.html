ProMax: Exploring the Potential of LLM-derived Profiles with Distribution Shaping for Recommender Systems

面向 LLM-as-feature-extractor 范式：作者提出 ProMax，将 LLM 生成的用户/物品 profile 作为辅助信号注入推荐主模型，但摒弃常用的非线性对齐与融合策略，转而从「检索视角」重新审视 profile，引入双向 distribution shaping 机制——用 dense retrieval 暴露 profile 之间的协同关系，再让 profile 分布反向引导主模型对未见物品的偏好分布。在 3 个公开数据集 × 4 类经典推荐模型上均显著优于直接拼接 / 对齐式基线及现有 LLM-rec 方法，论文已被 SIGIR 2026 接收。

KEY INSIGHT · 对业务意味着什么LLM profile 不应被「投影对齐」回 ID embedding 空间——这条主流路径会丢失 LLM 抽出的语义结构。ProMax 的关键启示是把 profile 当成监督信号去重塑主模型的输出分布，而不是当作输入 feature 拼进去；这恰好契合 UGC 短文本搜索中「LLM 抽出的查询/帖子主题画像」往往很稀疏却分布性强的特点，可作为排序模型的分布矫正项使用，比硬塞向量更鲁棒，且不增加在线推理成本。

Understanding DNNs in Feature Interaction Models: A Dimensional Collapse Perspective

USTC📖 深度解读 · 10 分钟 →

为「DNN 在 CTR/特征交互模型里到底起什么作用」这一长期争论提供新解释：作者通过对 parallel-DNN（如 DCN-V2）和 stacked-DNN（如 DeepFM）做整体与组件级消融，结合梯度理论分析，证明 DNN 的真正贡献并非隐式学高阶交叉，而是缓解 embedding 表征的「维度坍缩」（dimensional collapse），从而提升表示鲁棒性。论文给出 DNN 不同分支/组件对维度坍缩的影响机制，并用经验现象佐证理论推导。

INSIGHT这篇论文颠覆了「加 DNN = 学高阶交互」的常见认知：CTR 模型里 DNN 的真实价值在于稳住 embedding 的有效维度。对工业排序的直接启示——评估 DNN 分支时不要只看 AUC 增量，要监控 embedding 的奇异值分布；遇到表征坍缩（少量稀疏特征主导）时，加 parallel DNN 比堆叠 DNN 更有效。也为「最近大家观察到 DCN-V2 比 DeepFM 更稳」提供了理论解释，对调参与架构选型很有指导意义。

Jiancheng Wang, Mingjia Yin, Hao Wang, Enhong Chen

Hierarchical Long-Term Semantic Memory for LinkedIn's Hiring Agent

LinkedIn

LinkedIn Hiring Agent 的工业级长期记忆系统 HLTM：将候选人/招聘者长尾行为数据组织成 schema-aligned 的层次化语义树，每层捕获不同粒度的偏好（从 «想找远程后端» 到 «偏好 Python+AI 创业公司»），同时支持低延迟检索、隐私脱敏与可观测性。论文系统性梳理工业级 agent 长期记忆的 5 大挑战（规模化、低延迟、隐私、跨域泛化、可观测），并设计了从 ingestion 到 retrieval 的完整流水线。线上评估显示在答题正确率与召回 F1 上 +10%+，在「索引延迟–查询延迟」Pareto 前沿上显著优于现有方案。

INSIGHT把 agent 个性化记忆做成「分层语义树」而非「向量记忆池」是工业落地的关键工程选择。三个直接可借鉴的设计：(1) 层次化让审计/隐私字段可在 tree node 粒度操作，比扁平向量更易合规；(2) schema-aligned 节点天然支持冷启动（schema 模板可以拉新业务）；(3) 多粒度结构让排序时既能匹配粗主题又能命中细偏好，对社区搜索中「兴趣演化 + 实时帖子搜索」混合 query 的场景特别有价值。

Zhentao Xu, Shangjing Zhang, Emir Poyraz, Yvonne Li, Ye Jin, Xie Lu, Xiaoyang Gu, Karthik Ramgopal 等 10 人

Explaining the "Why": A Unified Framework for the Additive Attribution of Changes in Arbitrary Measures

AAnt Group

针对「指标为什么涨/跌」这一日常 A/B 与 root cause 分析痛点，提出基于合作博弈论（Shapley value 体系）的统一可加归因框架：作者按测度的数学结构分类（线性 / 平均型 / 比率型 / 复合型），从而对每类导出从近似到 closed-form 的算法谱系，在通用性与性能之间提供严格 tradeoff。实验部分包含数值精度仿真、Simpson 悖论可解释性 case，以及与现有 root-cause 分析系统对比的实用性评估，结果显著优于已有方案。

INSIGHT搜索/推荐场景里几乎每个核心指标——nDCG、CTR、人均 PV、相关性占比——都是 ratio/复合型测度，单纯按维度切片做归因（常见做法）会产生 Simpson 悖论。这篇论文的最大实践价值在于给出了不同测度类的归因算法选择——对线性测度可走 closed-form 秒级算，对 ratio 测度则要 Shapley 近似——直接可用来重做内部 metric explainer。对相关性团队尤其重要：模型上线后看到 nDCG 涨 0.5%，可以严谨拆出来「query 类目 × 排序位置 × 文档来源」哪一项贡献最多，避免误判 query 改写带来的伪收益。

Changsheng Zhou, Dajun Chen, Zhitao Shen, Wei Jiang, Yong Li, Peng Di

CARD: Non-Uniform Quantization of Visual Semantic Unit for Generative Recommendation

UESTC

针对生成式推荐 Semantic ID（SID）构建的两个核心问题——两阶段范式（SID 量化 + 自回归生成）监督割裂、非均匀 embedding 分布导致 codeword 失衡——提出 CARD 框架：先把文本/视觉/协同信号统一压成「visual semantic unit」结构化表示，再做 non-uniform 量化以缓解 codebook 长尾偏置。结果在多个公共数据集上对生成质量与 token 利用率有显著提升，论文核心是把 SID 构建从「单纯压缩」升级为「考虑后续生成的 codebook 设计」。

INSIGHT非均匀量化是 SID 长期被忽视的瓶颈——多数工作直接套 RQ-VAE/RVQ，但热门物品 / 冷门物品的 embedding 密度天然非均匀，会导致少量 codeword 承担过多生成概率（即 codebook collapse）。CARD 的启示：构建 SID 时要联合考虑下游 LLM 的 token 频次分布，必要时引入熵约束或非均匀切分。这对正在跑 TIGER / OneRec 类生成式推荐的团队非常有借鉴价值，能直接缓解 cold item 召不出来的问题。

Yibiao Wei, Jie Zou, Pengfei Zhang, Xiao Ao, Weikang Guo, Zeyu Ma, Yang Yang

The Bandit's Blind Spot: The Critical Role of User State Representation in Recommender Systems

UFSCar

聚焦上下文 bandit 推荐（CMAB）中长期被忽视的「用户状态表示」环节：作者用矩阵分解派生的多种 embedding（SVD / PMF / NMF / NeuMF）+ 多种聚合策略（mean / last-N / GRU），系统比较其对 LinUCB、Thompson、Greedy 等 CMAB 算法的影响。大规模实验得到一个反直觉结论——更换 state representation 带来的提升 > 更换 bandit 算法本身；并且没有任何单一 embedding 或聚合策略在所有数据集上占优，最佳选择高度依赖数据特征（稀疏度、序列长度、物品 catalog）。

INSIGHT工业 CMAB 团队大量精力花在 algorithmic bandit 上（探索机制、置信区间、prior），但本文实证证明：先把 user state 选好，比换 bandit 算法 ROI 高得多。可直接迁移的工程结论：(1) bandit 上线前先做 state representation A/B；(2) 没有银弹聚合策略，要按业务做实验；(3) 短序列+sparse 用 last-N，长序列+dense 用 GRU。对短文本社区搜索的实时排序也适用——把 query session 的 last-N 表征质量当 bandit 上限的关键来评估。

Pedro R. Pires, Gregorio F. Azevedo, Rafael T. Sereicikas, Pietro L. Campos, Tiago A. Almeida

Factorized Latent Reasoning for LLM-based Recommendation

UNSW

LLM-based 序列推荐普遍把用户意图压成单个 latent vector，但用户偏好天然多面（价格 / 风格 / 时效 / 情绪等）。作者提出 FLR（Factorized Latent Reasoning）：用一个轻量的多因子注意力模块迭代精炼 latent thought 表示，每个 factor 关注用户历史交互的不同侧面；再通过正交、注意力多样性、稀疏性三类正则约束保证因子之间的解耦与专注度，最后动态加权聚合各因子贡献做下一物品预测。论文同时给出 FLR 与现有 latent-reasoning LLM-rec 框架的兼容性集成方案。

INSIGHT这是 latent reasoning 在推荐里的「混合专家化」尝试——把 chain-of-thought 类的隐状态拆成多个语义维度，类似 MoE 但走 latent token 路线。对工业团队最有借鉴价值的是三个正则项设计（正交 + 多样性 + 稀疏），它们让 latent factor 不会塌成同一表示，是 latent reasoning 落地的关键工程细节。社区搜索中「短文本意图多重」的场景（一个 query 同时承载兴趣 + 时效 + 情绪）特别契合这种多因子分解。

Tianqi Gao, Chengkai Huang, Zihan Wang, Cao Liu, Ke Zeng, Lina Yao

TimeMM: Time-as-Operator Spectral Filtering for Dynamic Multimodal Recommendation

Xiaohongshu

针对多模态推荐中「不同偏好因子按不同速率演化」的非平稳性问题，提出 TimeMM 框架：把交互时间映射为参数化的时序 kernel 族（Time-as-Operator），按 recency 重新加权 user-item 图上的边，再通过谱滤波在不同频率分量上做模态特异的衰减——视觉信号让其更快衰减（短期视觉吸引），文本信号让其慢速衰减（长期内容偏好）。模型在多个动态多模态推荐基准上优于静态图与粗粒度时序基线，验证了「时间是算子而非 feature」这一观点。

INSIGHT把时间从「输入特征 / 位置编码」升级为「图谱操作算子」是这篇的最大创新点。对小红书这类多模态 UGC 平台尤其相关——视觉是冲动偏好，文本是稳定偏好，传统 GNN 混在一起反而互相污染。直接的工程启示是：训练多模态 rec 时给视觉 / 文本通道分别学衰减率，可以拆出更稳定的长期兴趣信号。社区搜索若要扩展到图文搜索，可借鉴这种模态分频谱衰减做相关性融合。

Wei Yang, Rui Zhong, Zihan Lin, Xiaodan Wang, Cheng Chen, Huan Ren, Yao Hu

PBiLoss: Popularity-Aware Regularization to Improve Fairness in Graph-Based Recommender Systems

GNN 推荐的 popularity bias 长期被预处理（数据再采样）/ 处理中（约束优化）/ 后处理（分数 re-rank）三类方案分别治理，但都各有副作用。作者提出 PBiLoss——一个直接嵌入训练目标的正则项，对模型偏好热门物品的倾向显式惩罚，从源头矫正 GNN 表示空间的分布偏移。在多个标准 GNN 推荐基线（LightGCN 等）上叠加 PBiLoss 后，长尾召回率和 unfair exposure 指标均明显改善，且对头部物品命中率几乎无损。

INSIGHTPBiLoss 是「一行代码就能加上的去偏方法」——不改模型结构、不改采样、不改 inference，只是在训练 loss 里加一项流行度惩罚。对工业团队的价值在于工程成本极低；但需要警觉的副作用是过强的去偏会牺牲短期 CTR，社区搜索中 UGC 长尾内容质量参差不齐，盲目去偏可能让低质内容上位，因此使用前要做「内容质量 × 流行度」联合标签，避免误伤优质头部内容。

Mohammad Naeimi, Mostafa Haghir Chehreghani

Meta-Learning and Targeted Differential Privacy to Improve the Accuracy-Privacy Trade-off in Recommendations

TTU GrazJJKU Linz

差分隐私（DP）和推荐准确率长期是 trade-off：均匀加噪保护强但精度下降明显。作者提出双层方案：数据层面只对「可能泄露敏感属性（性别 / 年龄）的代表性用户数据」做 targeted DP，避免对低风险数据的不必要扰动；模型层面用 meta-learning 让模型对剩余 DP 噪声更鲁棒。实验显示该方案在 empirical privacy risk（成员推理攻击成功率）和推荐准确率两条曲线上同时优于均匀 DP 和 full DP 基线。

INSIGHT对国内/欧洲合规驱动的推荐系统有直接价值：DP 不必一刀切，可以先用属性推断攻击模型识别「最危险数据子集」，只对该子集加噪。Meta-learning 部分是工程兜底——让推荐模型在训练阶段就见识各种噪声扰动，提升上线后对真实 DP 噪声的稳健性。社区搜索若要做用户画像隐私加固，这套「targeted DP + meta robustness」组合是当前 accuracy-privacy 帕累托前沿上比较实用的一种。

Peter Müllner, Dominik Kowald, Markus Schedl, Elisabeth Lex
