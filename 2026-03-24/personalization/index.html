SaFRO: Satisfaction-Aware Fusion via Dual-Relative Policy Optimization for Short-Video Search

该论文针对短视频搜索场景中多任务融合排序问题，提出 SaFRO 框架。现有方法主要优化即时参与度指标（如点击率），难以与长期用户满意度对齐。SaFRO 首先构建基于 query 级行为代理的满意度感知奖励模型，捕捉超越单次交互的整体用户满意度；然后引入 Dual-Relative Policy Optimization (DRPO)，一种高效的策略学习方法，通过双重相对性约束优化融合策略。该方法有效缓解了搜索场景中数据稀疏和意图约束带来的 RL 应用难题。

AIGQ: An End-to-End Hybrid Generative Architecture for E-commerce Query Recommendation

Alibaba📖 深度解读 · 9 分钟 →

AIGQ 是淘宝首页「猜你想搜」（HintQ）场景的首个端到端生成式 query 推荐框架。传统方法依赖 ID 匹配和共点击启发式，面临语义浅层、冷启动差、偶然发现率低等问题。AIGQ 提出三大创新：Interest-Aware List SFT (IL-SFT) 通过 session 感知行为聚合和兴趣引导重排序构建训练样本；Interest-aware List GRPO (IL-GRPO) 设计列表级策略优化算法；以及适合工业部署的混合生成架构。该系统已在淘宝上线部署。

INSIGHTAIGQ 的实践价值在于将 LLM 生成能力引入 query 推荐这一高流量入口场景：(1) 列表级而非单条级建模用户意图，更贴近实际搜索行为；(2) IL-GRPO 将 GRPO 从文本生成扩展到推荐列表优化，平衡相关性与多样性；(3) 混合架构兼顾生成质量和在线延迟。对 UGC 搜索场景，query 推荐是引导用户发现内容的关键环节，AIGQ 的生成式方案可有效解决长尾 query 和冷启动问题。

Jingcao Xu, Jianyun Zou, Renkai Yang, Zili Geng, Qiang Liu, Haihong Tang

GenFacet: End-to-End Generative Faceted Search via Multi-Task Preference Alignment in E-Commerce

JD.com

GenFacet 是京东部署的工业级端到端生成式分面搜索框架。传统分面搜索依赖静态规则或统计排序，面临新词汇覆盖不足、语义鸿沟、分面选择与检索脱节等问题。GenFacet 将分面搜索重构为统一 LLM 内的两个耦合生成任务：上下文感知的分面生成（动态合成响应趋势的导航选项）和意图驱动的查询改写（将用户交互转化为精确搜索查询）。训练采用结合师生蒸馏与 GRPO 的多任务训练管线，实现对复杂用户偏好的对齐。

INSIGHTGenFacet 的关键启示在于用 LLM 统一分面搜索的两个核心子任务（分面生成+查询改写），形成端到端闭环：(1) 生成式分面可动态响应新词汇和趋势，解决传统方法的静态性问题；(2) GRPO 用于多任务偏好对齐，在搜索效用和生成质量间取得平衡；(3) 师生蒸馏使大模型能力迁移到可部署模型。这为搜索系统中引入 LLM 提供了实际落地参考，尤其是在 query 理解与搜索导航的结合上。

Zhouwei Zhai, Min Yang, Jin Li

From Token to Item: Enhancing Large Language Models for Recommendation via Item-aware Attention Mechanism

该论文重新审视 LLM 推荐系统中 token 的角色，发现现有方法继承标准 attention 机制导致只建模 token 级关系，忽视了 item 作为推荐基本单元的重要性。论文将 token 关系分为两类：item 内 token 关系（表达内容语义，如名称、颜色、尺寸）和 item 间 token 关系（编码协同过滤信号）。基于此洞察，提出 item-aware attention 机制框架，在 attention 层面区分并分别建模这两类关系，从而在 LLM 推荐中有效捕捉 item 级协同关系。

INSIGHT该论文揭示了 LLM 推荐中一个被忽视的根本问题：标准 attention 将 item 打散为 token 序列后，丧失了 item 作为推荐基本单元的整体性。item-aware attention 的设计思路是在 attention 计算中引入 item 边界感知，分离语义理解和协同信号。这对构建 LLM 推荐系统有直接指导意义——简单地将 item 文本拼接输入 LLM 是不够的，需要在架构层面保留 item 级别的结构信息。

Xiaokun Zhang, Bowei He, Jiamin Chen, Ziqiang Cui, Chen Ma

MOSAIC: Modular Opinion Summarization using Aspect Identification and Clustering

MOSAIC 提出一个面向工业部署的模块化评论摘要框架，将端到端摘要分解为可解释的组件：主题发现、结构化观点提取和有据摘要生成。论文通过在线产品页面的 A/B 实验验证，展示中间输出（如结构化观点和主题聚类）在完整摘要部署之前就能改善用户体验并带来可衡量的商业价值。离线实验表明 MOSAIC 在方面覆盖度和忠实度上优于强基线。

INSIGHTMOSAIC 对 UGC 搜索场景有直接参考价值：(1) 模块化设计使系统可渐进部署，中间结果（主题标签、结构化观点）本身就有商业价值；(2) 观点聚类可用于搜索结果的多角度展示和 facet 生成；(3) 在线 A/B 实验证明了评论结构化对用户体验的正向影响。对社区搜索而言，用户生成内容的结构化摘要是提升搜索结果可读性和相关性的重要方向。

Piyush Kumar Singh, Jayesh Choudhari

How Well Does Generative Recommendation Generalize?

该论文系统性地验证了「生成式推荐模型泛化能力更强」这一假设。通过将数据实例分为记忆类（复用训练中观察到的 item 转移模式）和泛化类（组合已知模式预测未见过的 item 转移），发现：GR 模型在需要泛化的实例上表现更优，而 item ID 模型在记忆更重要时更强。进一步从 token 级分析揭示，GR 模型的 item 级泛化本质上常归结为 token 级记忆。

INSIGHT该研究对推荐系统选型有重要指导意义：(1) GR 模型和 ID 模型各有优势领域，选择应取决于场景中记忆 vs 泛化的需求比例；(2) GR 看似在 item 级泛化的能力，实际可能源于 token 级的模式复用而非真正的组合泛化——这提醒我们不要过度解读 GR 的泛化能力；(3) 对 UGC 搜索等长尾分布明显的场景，需要评估 GR 在冷启动 item 上的真实表现。

The Prosocial Ranking Challenge: Reducing Polarization on Social Media without Sacrificing Engagement

该论文报告了首次在多个社交媒体平台上直接对比多种替代排序算法的大规模实验。通过浏览器扩展修改桌面用户的 feed 排序，将 9,386 名用户随机分配到对照组或 5 种替代排序算法，跨 Facebook、Reddit、X/Twitter 三个平台运行 6 个月（覆盖 2024 美国大选期间）。结果显示替代算法平均降低情感极化 0.03 标准差（p<0.05），Facebook 使用时长减少 0.37 分钟/天，但 X/Twitter 增加 0.32 分钟/天。

INSIGHT该研究是排序算法社会影响的里程碑式实验：(1) 证明了可以在不大幅牺牲用户参与度的前提下降低极化——这对内容社区的排序策略设计有重要参考；(2) 跨平台效果差异（Facebook 降低使用时长 vs X 增加）揭示了排序算法效果的平台依赖性；(3) 实验方法（浏览器扩展进行 A/B 测试）为第三方评估排序算法提供了可行范式。

Maximizing mutual information between user-contexts and responses improve LLM personalization with no additional data

该论文提出 Mutual Information Preference Optimization (MIPO)，一种无需额外数据的 LLM 个性化自改进框架。MIPO 通过对比数据增强构建偏好对：正样本基于正确 prompt 生成响应，负样本基于随机无关 prompt 生成。使用 DPO 学习该偏好数据等价于最大化 prompt 和模型响应之间的逐点条件互信息。实验表明 MIPO 在个性化任务上提升 LLM 对用户上下文的敏感度，无需人工标注或外部验证器。

INSIGHTMIPO 的核心思路——通过最大化用户上下文与响应的互信息来提升个性化——可迁移到推荐场景：(1) 将用户画像/行为序列视为 context，推荐结果视为 response，同样可以通过互信息最大化增强个性化；(2) 对比增强的思路（正确用户 vs 随机用户）可用于训练更敏感的用户表征模型；(3) 不依赖外部标注的自改进范式对数据获取困难的搜索个性化场景有吸引力。

Hyunji Nam, Haoran Li, Natasha Jaques

DALI: LLM-Agent Enhanced Dual-Stream Adaptive Leadership Identification for Group Recommendations

DALI 框架结合 LLM 的符号推理能力与神经网络表征学习，解决群组推荐中的领导者识别问题。现有方法无论是手工聚合规则还是神经聚合模型，都难以区分领导主导型和协作型群组。DALI 引入两个关键创新：动态规则生成模块自主制定和评估群组动态假设；双流自适应识别机制区分不同群组决策模式。这使系统能更准确捕捉真实群组偏好，尤其在单个成员影响力不成比例时。

INSIGHTDALI 将 LLM 的推理能力引入群组推荐的一个具体问题（领导者识别），提供了 LLM+传统模型结合的参考模式：(1) LLM 负责高层推理（动态规则生成），神经网络负责表征学习，各取所长；(2) 双流架构区分不同群组决策模式，避免了一刀切的聚合策略。对社区搜索中的社群/小组内容推荐有一定参考价值。

Boxun Song, Min Gao, Jiawei Cheng

Reviewing the Reviewer: Graph-Enhanced LLMs for E-commerce Appeal Adjudication

该论文针对电商平台层级审核流程（Maker-Checker 模式）中的纠正信号学习问题，提出 Evidence-Action-Factor-Decision (EAFD) 模式和冲突感知图推理框架。EAFD 通过操作接地约束防止 LLM 幻觉，显式冲突建模使系统能从纠正信号中学习。该方法将审核流程中隐含的信息不对称问题转化为可建模的图结构推理任务。

INSIGHTEAFD 框架的操作接地（operational grounding）思路对搜索/推荐系统中的质量控制有借鉴意义：(1) 在 LLM 推理中引入可验证的操作约束，有效降低幻觉风险——这对任何使用 LLM 做决策的搜索系统都重要；(2) 从 Maker-Checker 纠正信号中学习的方法可迁移到搜索相关性标注的质量提升；(3) 图结构对冲突信息的建模为复杂决策提供了系统化方案。

Yuchen Du, Ashley Li, Zixi Huang
