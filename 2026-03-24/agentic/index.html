R3-RAG: Learning Step-by-Step Reasoning and Retrieval for LLMs via Reinforcement Learning

提出 R3-RAG，通过强化学习训练 LLM 进行逐步推理和检索。方法分两阶段：冷启动训练建立迭代推理-检索模式，然后通过 RL 优化。设计了双奖励机制——结果奖励（答案正确性）和过程奖励（文档相关性），在多跳 QA 任务上显著超过基线，且跨检索器迁移性强。

KEY INSIGHT · 对业务意味着什么R3-RAG 的核心创新在于将 RL 引入 RAG 的推理-检索循环训练。对搜索系统的启示：传统 RAG 的检索策略是固定的（retrieve-then-read），而 R3-RAG 让模型自主学习何时检索、检索什么，形成动态检索策略。过程奖励的设计思路可迁移到搜索排序模型的训练中。

Utility-Guided Agent Orchestration for Efficient LLM Tool Use

解决 LLM Agent 工具使用中质量与成本的根本矛盾。固定工作流稳定但不灵活，自由推理（如 ReAct）可能过度调用工具。提出效用引导的 Agent 编排框架，在答案质量和执行成本间自动寻找最优平衡，避免不必要的工具调用。

INSIGHT该工作直击 Agent 系统工程化的核心痛点：成本控制。在 agentic search 中，每次工具调用都有延迟和成本，效用引导机制可帮助 Agent 判断是否值得再搜一次，从而在搜索深度和响应速度间取得平衡。这对生产环境的 search agent 至关重要。

A Subgoal-driven Framework for Improving Long-Horizon LLM Agents

针对 LLM Agent 在长序列任务（如网页导航、操作系统交互）中的规划能力不足，提出子目标驱动框架。将复杂的长程任务分解为可管理的子目标序列，引导 Agent 逐步完成，有效应对动态内容和长动作序列的挑战。

INSIGHT子目标分解是解决 Agent 长程规划的关键思路。对搜索 Agent 的启示：deep research 类任务本质上是长程搜索任务，将复杂研究问题分解为子目标可显著提升 Agent 的搜索效率和结果质量。

HyEvo: Self-Evolving Hybrid Agentic Workflows for Efficient Reasoning

指出现有 agentic workflow 自动生成方法依赖预定义算子库和同质 LLM-only 工作流，效率低且效果欠佳。提出 HyEvo，一种自进化的混合 agentic workflow 框架，突破纯 LLM 工作流的限制，实现异构计算节点的自动组合优化。

INSIGHTHyEvo 的核心洞察是 agentic workflow 不应局限于 LLM 调用链——混合异构计算的自动组合能更高效地解决复杂任务。搜索 Agent 的最优工作流可能是 LLM 推理 + 传统检索 + 规则过滤的混合组合，而非纯 LLM 驱动。

All-Mem: Agentic Lifelong Memory via Dynamic Topology Evolution

解决长生命周期交互式 Agent 的记忆管理问题。随着历史交互增长，现有记忆系统出现冗余和检索退化。提出 All-Mem，通过动态拓扑演化维护 Agent 长期记忆，在固定上下文和延迟预算下持续写入长期记忆并精准检索。

INSIGHT长期记忆管理是 Agent 走向实用化的关键基础设施。All-Mem 的动态拓扑演化思路可用于构建搜索 Agent 的用户画像系统——随交互增长自动压缩和更新记忆，而非简单累积。

06 3.55

The Autonomy Tax: Defense Training Breaks LLM Agents

揭示 LLM Agent 安全性与自主能力的矛盾——防御训练（如 prompt injection 防御）在提升安全性的同时显著降低 Agent 的工具使用和自主决策能力，称之为自主性税。这一发现对 Agent 系统的安全部署策略具有重要启示。

INSIGHT该研究揭示了一个被忽视的工程权衡：过度的安全防护会削弱 Agent 的核心能力。在设计 search agent 的安全策略时，需在防御 prompt injection 和保持检索/工具调用能力间做精细权衡，而非一刀切地加强防御。

DLLM Agent: See Farther, Run Faster

探索扩散大语言模型（Diffusion LLM）在 Agent 多步决策中的应用。与自回归解码不同，DLLM 可并行生成完整动作序列，具有更好的全局规划能力。研究了生成范式变化对 Agent 推理和决策的影响。

INSIGHT将扩散模型引入 Agent 决策是一个新颖的研究方向。自回归生成的 Agent 倾向于贪心的逐步决策，而 DLLM 的并行生成特性可能更适合需要全局规划的搜索任务，为 search agent 的架构设计提供新思路。

LongCat-Flash-Prover: Advancing Native Formal Reasoning via Agentic Tool-Integrated Reinforcement Learning

560B 参数的开源 MoE 模型，通过 agentic 工具集成强化学习推进 Lean4 形式化推理。将形式化推理分解为自动形式化、构架和证明三个独立能力，在数学定理证明领域取得 SOTA。

INSIGHT该工作展示了 agentic RL + 工具集成在复杂推理中的强大潜力。其方法论——将复杂推理任务分解为独立能力并通过 RL 训练 Agent 使用工具——可迁移到 search agent 的训练中。

ClawWorm: Self-Propagating Attacks Across LLM Agent Ecosystems

研究 LLM Agent 生态系统中的自传播攻击。以 OpenClaw（4万+活跃实例）为案例，展示恶意攻击如何在互联的 Agent 网络中自主传播，揭示了长运行 Agent 进程在多 Agent 环境中的安全隐患。

INSIGHT随着 LLM Agent 生态的发展，安全威胁从单点攻击升级为生态级传播。当搜索系统集成多个 LLM Agent 时，需要防范跨 Agent 的攻击传播，设计隔离和校验机制。
