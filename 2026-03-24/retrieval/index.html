Spectral Tempering for Embedding Compression in Dense Passage Retrieval

针对稠密检索系统大规模部署中的维度压缩问题，提出 Spectral Tempering 方法。现有 PCA 压缩保留主成分方差但浪费表示容量，而 MRL 在训练时增加开销。该方法通过频谱调温在后处理阶段重新分配方差到低阶分量，无需重训练即可实现更优的维度压缩效果，在 BEIR 等标准检索基准上优于 PCA 和 MRL 基线。

A Super Fast K-means for Indexing Vector Embeddings

提出 SuperKMeans，一种专为高维向量 embedding 聚类优化的 K-means 变体。在现代 CPU 上比 FAISS 和 Scikit-Learn 快 7 倍，在 GPU 上比 cuVS 快 4 倍。该方法直接服务于向量检索索引构建（如 IVF 索引），可显著加速大规模向量数据库的索引构建过程。

INSIGHT针对向量检索系统中 IVF 索引构建的核心瓶颈——K-means 聚类速度——提出专用优化算法。对搜索系统的实践价值在于：当 embedding 库规模达到亿级时，索引重建耗时可能长达数小时，SuperKMeans 的 4-7 倍加速可大幅缩短索引构建周期，提升系统迭代效率。

Spelling Correction in Healthcare Query-Answer Systems: Methods, Retrieval Impact, and Empirical Evaluation

首次在受控实验中系统研究拼写纠错对 QA 检索系统的影响。发现用户查询中拼写错误率远高于被检索文档，且不同纠错方法对检索效果的影响差异显著。通过在医疗 QA 场景的实验，量化了拼写纠错在检索管线中的收益和风险。

INSIGHT该研究揭示了 query 预处理中一个被低估的环节：拼写纠错对检索相关性的影响。对 UGC 搜索场景尤其重要——社区内容中用户输入的 query 拼写错误率高，系统性地引入拼写纠错模块可直接提升召回和排序质量。研究还提醒纠错可能引入新错误，需在纠错精度和检索效果间做权衡。

The End of Rented Discovery: How AI Search Redistributes Power Between Hotels and Intermediaries

审计 1,357 条 AI 搜索引擎的引用来源，研究 AI 搜索（如 Perplexity、ChatGPT Search）如何重新分配酒店搜索中不同来源的流量和权力。发现 query 的表述方式（framing）显著影响 AI 搜索的引用偏好，揭示了 AI 搜索对传统搜索生态的颠覆性影响。

INSIGHT该研究从搜索生态视角揭示了 AI 搜索（Generative Search）对传统搜索排序范式的冲击。对搜索从业者的启示：AI 搜索的 grounding citation 机制本质上是一种新的排序逻辑，query framing 对结果影响显著。这意味着传统 SEO 策略在 AI 搜索时代需要根本性调整，搜索系统设计也需考虑 AI 引用的公平性。

URAG: A Benchmark for Uncertainty Quantification in Retrieval-Augmented Large Language Models

提出 URAG，首个系统性的 RAG 不确定性量化基准。涵盖检索阶段和生成阶段的不确定性评估，揭示当前 RAG 系统在正确性之外的可靠性盲区。通过多维度评估框架，量化不同 RAG 配置下的不确定性表现。

INSIGHT当前 RAG 评估过度关注正确性指标，忽视了检索和生成阶段的不确定性。对搜索系统的启示：在将 LLM 集成到搜索管线时，需要引入不确定性量化机制来判断检索结果的可靠程度，避免高置信度但错误的生成结果。该基准为搜索+LLM 系统的质量保障提供了评测工具。

Ranking Engineer Agent (REA): The Autonomous AI Agent Accelerating Meta's Ads Ranking Innovation

Meta

Meta 发布 REA（Ranking Engineer Agent），一个自主管理广告排序模型全生命周期的 AI Agent。REA 可自主生成假设、启动训练任务、调试失败并迭代优化。初步生产测试中，模型平均精度提升一倍，3 名工程师借助 REA 完成了原本需要更多人力的 8 个模型优化工作。

INSIGHTREA 代表了 AI Agent 在搜索/排序领域工程实践中的前沿应用——用 Agent 自动化 ML 实验全流程。对搜索团队的启示：排序模型的迭代瓶颈往往不在模型本身，而在实验管理的人力成本。借助 Agent 自动化假设生成、训练调试、结果分析，可大幅提升模型迭代速度和工程效率。

Enhancing Hyperspace Analogue to Language (HAL) Representations via Attention-Based Pooling for Text Classification

在经典的 HAL（Hyperspace Analogue to Language）词共现模型基础上引入注意力池化机制，提升文本分类性能。HAL 模型通过全局词共现矩阵构建分布式语义表示，本文通过注意力机制改善其表示质量。

INSIGHT该研究探索了经典分布式语义模型的现代化改进路径。虽然 HAL 模型在工业搜索系统中不常直接使用，但其核心思想——词共现信号+注意力机制——可为轻量级语义匹配模型的设计提供灵感，特别是在对延迟敏感的在线匹配场景。
