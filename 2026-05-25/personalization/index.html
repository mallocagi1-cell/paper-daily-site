FLUID: From Ephemeral IDs to Multimodal Semantic Codes for Industrial-Scale Livestreaming Recommendation

FLUID 针对直播推荐的冷启动难题——直播间存续时间短，候选侧 item ID embedding 永远学不热。方法分两部分：用短视频+直播跨域多模态编码器生成离散分层语义码 LUCID；再用去 ID 的后融合排序结构，把 slice 级与 room 级语义码作为独立 token 输入，并在在线增量训练中分阶段 warmup。线上 A/B：优质观看时长 +0.55%、冷启动直播间曝光 +2.05%、活跃时长 +0.05%，已部署服务超十亿用户。

Reinforced Preference Optimization for Reasoning-Augmented Recommendations

KuaishouCityU

RPORec 针对'LLM 推理过程与推荐目标不对齐'的问题，提出两阶段强化偏好优化：阶段一让 LLM 生成思维链推理，指导专用推荐头 Rechead 学习面向表征的特征；阶段二把 Rechead 的预测作为奖励，用强化学习反过来精炼 LLM 的推理质量与任务对齐。在公开基准与快手大规模线上部署中均稳定超过现有 LLM-based 推荐方法。

INSIGHT推理增强推荐的核心痛点是 LLM '会推理'不等于'推得对（对推荐目标有用）'。RPORec 用推荐头预测信号作为 RL 奖励，闭合推理与排序目标，是把通用 LLM 推理能力定向到推荐任务的可行范式。对社区搜索而言，可借鉴'推理→任务头→奖励回灌'的对齐思路，让 LLM 的 query/内容理解推理真正服务于相关性与点击目标，而非生成漂亮但无用的解释。

03 3.75

Behavior-Guided Candidate Calibration for Multimodal Recommendation

论文研究多模态信号在排序中的相互作用，通过谱分析发现：跨视图适度一致有益，过强一致反而抑制推荐特有的判别信号——低频分量承载共享结构，高频分量保留判别性。方法把训练数据中的共同用户重叠模式转成带符号候选证据，仅作用于多模态主干输出的候选 shortlist，在保持主干表征稳定的同时于排序决策点注入行为信号。在 Amazon Baby/Sports/Electronics 三数据集上稳定优于强多模态基线。

INSIGHT'多模态对齐越强越好'是常见误区，该工作用谱分析量化了过度对齐会抹平判别信号。其'主干稳定 + 仅在 shortlist 决策点用行为证据校准'的两段式设计，避免行为信号污染内容表征。社区搜索的文本/图片多模态匹配同样需平衡语义对齐与判别力，可借鉴在召回后、精排决策点轻量注入协同/行为证据的做法。

Zesheng Li, Chengchang Pan, Honggang Qi

04 3.55

LLM Retrieval for Stable and Predictable Ad Recommendations

面向广告库存规模化后对'稳定性与可预测性'的需求，提出 LLM 驱动的语义候选生成框架：用微调 LLM 从广告创意中抽取分层语义属性，基于图扩展检索语义近邻候选，使投放结果对输入微小扰动更鲁棒，并缓解冷启动与探索不足。离线与线上 A/B 均有显著提升。

INSIGHT传统广告/推荐召回过度追求精度，忽视了对输入扰动的稳定性——同一广告因微小特征变化被分到完全不同候选集会损害投放可预测性。用 LLM 抽取的分层语义属性 + 图扩展做'语义变体'召回，是兼顾鲁棒性与冷启动的思路。社区搜索召回也可引入内容语义层级表示，降低对稀疏 ID 与精确匹配的依赖。

Vinodh Kumar Sunkara, Satheeshkumar Karuppusamy, Hangjun Xu, et al.

Research on CTR Prediction Based on Deep Learning

该工作聚焦互联网广告 CTR 预估中的特征交互建模，指出传统人工特征提取未考虑广告数据的高度稀疏与特征间高度非线性关联，采用深度学习自动学习高阶特征交互以提升点击率预测精度。方法较为常规，属对深度 CTR 范式的工程化梳理。

INSIGHTCTR 预估的本质仍是稀疏特征下的高阶交互建模。虽方法常规，但其对'稀疏性 + 非线性特征关联'的问题刻画对社区搜索排序仍有参考——短文本 UGC 的标签/类目特征同样高度稀疏，需要自动化的特征交互结构而非人工组合。

Online Advertising with Spatial Interactions

Google

论文研究广告位的'空间外部性'：一条广告的效果不仅取决于自身位置，还受邻近广告的拥挤/竞争影响，而既有拍卖与分配模型多把广告位视为独立或单维有序。作者提出将广告位建模为度量空间中的点、广告价值由出价与邻居配置折扣因子共同决定的新框架；对最近邻模型给出多项式时间常数近似且可实现为真实机制，对乘积距离模型证明除非 P=NP 否则无多项式因子近似的强难解性。

INSIGHT该工作提醒：列表/版面级排序中相邻 item 之间存在外部性，逐条独立打分会高估整体收益。虽为机制设计理论工作、与 UGC 社区搜索的直接落地距离较远，但'位置 × 邻居配置'的价值建模视角对 feed/搜索结果页的重排、多样性与拥挤控制有启发——重排阶段应显式建模相邻结果的相互抑制。

Gagan Aggarwal, et al.
