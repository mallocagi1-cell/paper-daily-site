MDL: A Unified Multi-Distribution Learner in Large-scale Industrial Recommendation through Tokenization

针对工业推荐系统中多场景多任务学习的两大瓶颈——大规模参数未能充分与复杂特征模块交互、场景和任务信息难以在统一框架中联合建模——提出了 MDL 框架。核心思路借鉴 LLM 的 prompting 范式，将场景和任务信息转化为专用 token 而非辅助输入或门控信号。框架包含统一信息 token 化模块，以及特征 token 自注意力、领域-特征注意力和领域融合聚合三种机制。在抖音搜索平台上线 A/B 测试取得显著提升，现服务数亿日活用户。

The Confidence Gate Theorem: When Should Ranked Decision Systems Abstain?

📖 深度解读 · 4 分钟 →

研究排序决策系统（推荐系统、广告竞价、医疗分诊队列）应在何时对排序输出进行干预、何时选择放弃干预（abstain）的问题。提出 Confidence Gate 定理，给出基于置信度的放弃机制单调改善决策质量的充要条件：rank-alignment（排序对齐）和 no inversion zones（无反转区）。区分了结构性不确定性（缺失数据，如冷启动）和上下文不确定性（缺失上下文，如时序漂移）。在 MovieLens 协同过滤、广告竞价和医疗分诊三个领域验证。

INSIGHT该定理揭示了排序系统「何时不该出手」理论边界，对推荐和搜索系统的实践启示是：在冷启动用户（结构性不确定性高）上强行出排序结果可能适得其反，此时放弃干预（fallback 到热门/探索策略）反而更优。对于社区搜索场景，可以用该框架识别哪些 query-user 组合下排序模型的置信度不足，对这些请求切换到备选策略，从而提高整体 CTR 和用户体验。

TaoSR1: The Thinking Model for E-commerce Relevance Search

Alibaba📖 深度解读 · 5 分钟 →

针对电商搜索中 query-商品相关性预测任务，提出直接部署 LLM 的框架 TaoSR1，解决三个关键挑战：Chain-of-Thought (CoT) 推理中的错误累积、判别式幻觉（discriminative hallucination）和部署可行性。框架分三阶段：(1) 监督微调建立推理基础；(2) 基于强化学习的 CoT 错误纠正机制；(3) 工程优化实现在线部署。该模型已在淘宝搜索系统上线，解决了 BERT 类模型擅长语义匹配但缺乏复杂推理能力的问题。

INSIGHTTaoSR1 验证了 LLM「思考式」排序在工业电商搜索中的可行性路径：SFT→RL 纠偏→在线部署三步法。核心经验是 CoT 推理并非开箱即用，直接 fine-tune 会产生判别式幻觉（模型编造理由来合理化错误判断），需要 RL 阶段专门纠正这一问题。对于社区搜索中复杂 query（如长尾问题、含歧义的 UGC 搜索词），这种思考式相关性模型可能比传统 BERT 排序提供更好的语义理解。

Evoking User Memory: Personalizing LLM via Recollection-Familiarity Adaptive Retrieval

CityU📖 深度解读 · 5 分钟 →

针对个性化 LLM 中记忆检索的两大问题——将所有历史记忆塞入 prompt 成本高且不可扩展、单次相似度检索只能捕捉表面匹配——提出基于认知科学双过程理论的自适应检索框架。借鉴人类记忆的双过程机制：Familiarity（快速但粗略的识别）和 Recollection（深层链式重建），实现对用户历史偏好和上下文的精确召回。系统能根据 query 复杂度自适应选择快速检索或深度重建路径。

INSIGHT该工作的核心启示是：用户记忆检索不应是简单的 top-k 相似度匹配，而应区分「我认识这个」（快速模式匹配）和「让我想想之前的经历」（深层链式推理）两种模式。对于社区搜索的个性化排序，可以借鉴这种双通道设计：对频繁交互的 topic 使用轻量级匹配（familiarity），对长尾或新兴话题使用深度用户偏好推理（recollection），在个性化质量和推理成本间取得平衡。

The qs Inequality: Quantifying the Double Penalty of Mixture-of-Experts at Inference

揭示了 Mixture-of-Experts (MoE) 模型在推理阶段的「双重惩罚」现象：第一，专家路由导致 microbatch 碎片化，降低权重复用率；第二，大量驻留的专家参数池挤占 HBM 空间，压缩 KV cache 容量。将这一现象形式化为 reuse fragmentation，并提出 qs 不等式作为预测准则，判断何时 MoE 在推理阶段结构性地劣于 dense 模型，特别是在长上下文场景下。

INSIGHT随着 TokenMixer-Large (ByteDance)、Kunlun (Meta) 等大规模推荐模型大量采用 MoE 架构，qs 不等式为推荐系统 MoE 部署提供了关键判据：在在线推理时，MoE 的训练效率优势可能因 routing 碎片化和内存竞争而大幅减弱。对于社区搜索的排序模型，若考虑引入 MoE 架构，需要评估线上 batch size 和序列长度是否处于 qs 不等式的安全区间，否则应考虑 dense 或混合方案。

Albus Yizhuo Li, Matthew Wicker

RecThinker: An Agentic Framework for Tool-Augmented Reasoning in Recommendation

RUC

针对 LLM 推荐 agent 在用户画像不完整或商品元数据稀疏时推荐效果不佳的问题，提出 RecThinker 框架，将推荐代理从被动信息获取范式转向主动信息获取。核心创新是让推荐 agent 能够在推理过程中主动判断信息充分性，并通过调用外部工具（用户画像查询、商品详情检索、评论分析等）动态补充缺失信息，形成「思考→判断→获取→推理」的闭环。

INSIGHTRecThinker 的核心设计理念对推荐系统有重要启示：当用户画像和商品信息不完整时，与其强行基于残缺数据做推荐，不如让系统主动识别「还需要知道什么」并动态获取。对于社区搜索中的冷启动场景（新用户、新帖子），可以借鉴这种 tool-augmented 方式，在排序阶段主动调用用户行为日志、内容画像等外部数据源来补充上下文，提升稀疏场景下的排序质量。

ThinkQE: Query Expansion via an Evolving Thinking Process

University of Amsterdam

针对 LLM 生成式查询扩展往往过于聚焦单一语义、忽略多义和多面性的问题，提出 ThinkQE 框架。核心是两个组件：(1) thinking-based 扩展过程，通过深层思考鼓励更全面的语义探索；(2) corpus-interaction 策略，迭代地利用检索反馈来优化扩展方向，避免语义漂移。无需额外训练即可提升检索性能，具有良好的跨领域泛化能力。

INSIGHTThinkQE 揭示了传统 LLM 查询扩展的核心缺陷：模型倾向于生成与原始 query 语义高度重叠的扩展词，忽略了歧义和多面性。「先思考后扩展」+ 语料库交互反馈的设计对社区搜索直接有价值——UGC 搜索中 query 往往短而模糊（如「该怎么选」「求推荐」），需要扩展出多个可能的意图面。无需训练的特性也降低了上线门槛。

Yibin Lei, Tao Shen, Andrew Yates

Expressivity-Efficiency Tradeoffs for Hybrid Sequence Models

UW-Madison

系统研究混合序列模型（Transformer + 状态空间模型）相对于单一架构的表达力与效率权衡。在一组核心合成任务上证明了非混合模型的基本局限性：纯 Transformer 和纯 SSM 在特定任务上分别存在无法克服的计算瓶颈。揭示了混合模型受益的底层机制——attention 层处理全局关联，SSM 层高效处理局部序列模式，两者互补才能同时保证表达力和效率。

INSIGHT对于基于序列建模的推荐系统（如 HSTU、SASRec 等），该研究的理论结果提供了架构选型指导：纯 Transformer 在超长用户行为序列上面临二次复杂度瓶颈，纯 SSM（如 Mamba）在需要全局关联的场景下表达力不足。混合方案（如底层用 SSM 处理长序列局部模式，高层用 Attention 捕捉全局偏好）可能是用户行为序列建模的最优架构方向，尤其适合社区搜索中用户长期行为与短期意图并存的场景。

John Cooper, Ilias Diakonikolas, Mingchen Ma, Frederic Sala

What Do We Care About in Bandits with Noncompliance? BRACE: Bandits with Recommendations, Arms, Compliance, and Exploration

研究推荐系统中的一个根本问题：当用户不完全遵循系统推荐时（noncompliance），系统应该优化什么目标？形式化了推荐福利（recommendation welfare）vs 治疗学习（treatment learning）两种目标可能冲突的问题。证明当用户完全遵循推荐时两个目标一致，但在存在不服从行为时，推荐福利可能严格超越所有基于治疗效果的策略。

INSIGHTBRACE 框架指出了一个被多数推荐系统忽略的问题：用户并不总是按照系统推荐行事（如搜索结果排序不等于用户点击顺序），因此优化「推荐效果」和优化「用户实际接收的治疗效果」可能是两个不同的目标。对于社区搜索场景，这意味着排序模型的离线评估（假设用户完全服从排序）可能高估真实效果，需要考虑用户的实际行为模式来修正优化目标。

Decoupling Reasoning and Confidence: Resurrecting Calibration in Reinforcement Learning from Verifiable Rewards

CAS

揭示了 RLVR（基于可验证奖励的强化学习）在提升 LLM 推理能力的同时会严重破坏模型校准——模型对错误答案变得过度自信。理论分析表明推理目标和校准目标之间存在根本性梯度冲突。提出解耦方案：将推理能力和置信度估计分离优化，在推理 token 上优化 RL 奖励，在置信度 token 上独立优化校准损失，成功恢复校准性能而不损失推理准确率。

INSIGHT该研究的核心发现——RL 提升推理但破坏校准——对搜索排序系统意义重大。当前越来越多的排序模型采用 RLHF/RLVR 训练，如果不注意校准问题，模型可能对低质量结果给出过高置信度分数，导致排序失真。解耦推理和置信度的设计思路可以迁移到搜索排序中：让模型的相关性判断和置信度评估走不同的训练路径，确保排序分数既准确又校准。

Zhengzhao Ma, Xueru Wen, Boxi Cao, Yaojie Lu, Hongyu Lin, Jinglin Yang, Min He, Xianpei Han, Le Sun
