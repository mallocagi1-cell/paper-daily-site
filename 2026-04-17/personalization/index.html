On the Practice of Deep Hierarchical Ensemble Network for Ad Conversion Rate Prediction

针对广告转化率（CVR）预测中 Deep Hierarchical Ensemble Network (DHEN) 的工程实践问题，本文提出了以 DHEN 为统一 backbone 的多任务学习框架，同时预测多种 CVR 任务。核心贡献包括：(1) 系统研究了 MLP、DCN、Transformer 等特征交叉模块在 DHEN 中的最优组合策略；(2) 构建了站内实时行为序列和站外转化事件序列作为个性化特征；(3) 提出自监督辅助损失预测序列中的未来动作，缓解 CVR 标签稀疏问题。在美国头部电商平台上线验证，相比单一特征交叉模块取得 SOTA 效果。

TokenFormer: Unify the Multi-Field and Sequential Recommendation Worlds

Tencent📖 深度解读 · 7 分钟 →

推荐系统长期存在两个独立范式：多域特征交互模型（建模类别特征相关性）和序列模型（捕捉用户行为动态）。本文揭示了朴素统一两者会导致“序列坍塌传播（SCP）”——非序列域的维度不匹配导致序列特征的维度坍塌。为此提出 TokenFormer，通过统一的 token 化表示和专门的注意力机制，在单一架构中有效融合多域特征交互与序列建模，避免 SCP 问题。在腾讯广告平台的实验中验证了该方法的有效性。

INSIGHTSCP（序列坍塌传播）是工业推荐系统中一个被忽视但普遍存在的问题：当多域特征和序列特征简单拼接送入共享 backbone 时，维度不匹配的非序列特征会“污染”序列表征。TokenFormer 的 token 化统一策略为解决该问题提供了实用方案。对于社区搜索的排序模型，如果同时使用 query/用户画像等类别特征和用户行为序列，应特别关注特征维度对齐，避免序列建模能力退化。

DUET: Joint Exploration of User Item Profiles in Recommendation System

Microsoft

传统推荐系统用稠密向量表征用户和物品，新兴的 LLM 推荐器则使用自然语言表征。本文研究如何构建有效的用户-物品文本画像并对齐它们用于推荐。核心难点在于最优画像格式未知——手工模板脆弱且可能与任务目标不对齐，且独立生成的用户/物品画像可能语义不一致。DUET 提出联合优化用户和物品画像的框架，通过迭代探索找到推荐效果最优的画像表述方式，实现文本空间中用户-物品的高效匹配。

INSIGHTLLM 用于推荐的一个关键瓶颈是文本画像的质量——独立生成的用户画像和物品画像在语义空间可能不对齐（如用户画像强调'喜欢科技内容'但物品画像描述的是'产品参数'），导致匹配效果差。DUET 的联合探索策略为此提供了系统化解决方案。对于 UGC 搜索场景，可借鉴此思路：用 LLM 生成 query 画像和帖子画像时，需要确保两者在语义粒度和维度上对齐，而非独立优化。

SPRINT: Scalable and Predictive Intent Refinement for LLM-Enhanced Session-based Recommendation

LLM 在推荐中的用户画像生成已取得进展，但直接应用于会话推荐（SBR）面临会话上下文极度稀疏和可扩展性差的挑战。SPRINT 提出了一个可扩展的 SBR 框架：通过全局意图池约束 LLM 生成的意图空间，并基于推荐效果验证推断出的意图，以减轻上下文不足导致的噪声和幻觉。为保证可扩展性，LLM 仅在离线阶段选择性调用，在线推理时通过轻量级意图匹配模块高效服务。

INSIGHTSPRINT 解决了 LLM 用于推荐中的两个核心工程问题：(1) 意图幻觉——会话数据太短时 LLM 容易产生不可靠的意图推断，全局意图池作为约束有效降低了噪声；(2) 在线延迟——将 LLM 调用限制在离线阶段、在线仅做意图匹配的架构设计保证了可部署性。这种'离线 LLM 意图挖掘 + 在线轻量匹配'的范式对社区搜索中的 session 理解和 query 意图识别有直接参考价值。

RoTE: Coarse-to-Fine Multi-Level Rotary Time Embedding for Sequential Recommendation

现有序列推荐模型按时间戳排列用户交互序列，但仅考虑顺序而忽略交互间的实际时间跨度，导致用户时间动态建模粗糙。RoTE 提出多层级旋转时间编码：借鉴 RoPE（Rotary Position Embedding）的思想，将绝对时间信息编码为旋转角度，并通过从粗到细的多层级结构（如年-月-日-小时）捕捉不同粒度的时间模式。该方法可作为即插即用模块集成到主流序列推荐模型中。

INSIGHT将 NLP 中的 RoPE 位置编码迁移到推荐系统的时间建模是一个巧妙的跨领域应用。多层级时间编码的核心价值在于同时捕捉长期趋势（月/周周期性）和短期模式（小时级实时兴趣），这对社区搜索中理解用户的时间敏感行为模式有实用价值。该模块的即插即用特性使其工程集成成本低——可直接嵌入现有的 Transformer-based 排序模型中增强时间感知能力。

Enhancing Local Life Service Recommendation with Agentic Reasoning in Large Language Model

本地生活服务推荐与通用推荐不同，具有强需求驱动特性——准确识别用户即时生活需求和推荐对应服务是不可分割的。现有方法将需求预测和服务推荐独立建模。本文提出基于 LLM 的 agentic reasoning 框架，联合完成生活需求预测和服务推荐。通过行为聚类方法过滤偶发因素、保留典型消费模式，使 LLM 能够更准确地推理用户的真实需求并推荐匹配的服务。

INSIGHT将需求预测与推荐统一建模的思路具有普遍意义：在社区搜索场景中，理解用户'为什么搜索'（需求）和'推荐什么内容'（服务）同样紧密关联。行为聚类去噪的预处理策略值得借鉴——用户的偶发行为（如误点击）会干扰 LLM 的推理，通过先聚类过滤再输入 LLM 可以提升推理质量。LLM agentic reasoning 范式在复杂意图理解场景中展现了优势。

Shiteng Cao, Xiaochong Lan, Yuwei Du, Jie Feng, Yinxing Liu, Xinlei Shi, Yong Li

Beyond the Trigger: Learning Collaborative Context for Generalizable Trigger-Induced Recommendation

电商中触发式推荐（TIR）在用户点击触发项后推荐相关商品。现代平台依赖持续涌现的短期促销场景（如黑五），现有方法要么陷入'触发依赖陷阱'（推荐过于相似的商品），要么陷入'数据饥渴陷阱'（短期场景缺乏足够数据建模意图）。CCN（Collaborative Contrastive Network）从不同视角切入：不直接建模模糊的入场意图，而是学习跨场景的协同上下文表征，通过对比学习增强泛化能力。

INSIGHTCCN 的核心思路是'跳过意图建模、直接学习协同信号'，这在数据稀疏的新场景冷启动中特别有效。对社区搜索而言，运营活动频繁变化（如话题挑战、节日活动），每个活动场景都面临类似的冷启动问题。CCN 的对比学习框架——从已有场景中迁移协同信号到新场景——提供了一种轻量级的跨场景知识迁移方案，无需为每个新活动重新收集训练数据。

Chen Gao, Zixin Zhao, Lv Shao, Tong Liu

From Transfer to Collaboration: A Federated Framework for Cross-Market Sequential Recommendation

跨市场推荐（CMR）旨在提升多个市场的推荐效果，但面临数据隔离、用户不重叠、市场异质性等挑战。现有方法沿用跨域推荐的'一对一迁移'范式（源市场预训练到目标市场微调），存在源市场性能退化和负迁移问题。本文提出联邦协作框架，将范式从单向迁移转变为多方协作，各市场在保护数据隐私的前提下共同学习，避免源市场牺牲自身性能。

INSIGHT从'迁移'到'协作'的范式转变值得关注：传统的预训练-微调模式在异质场景下容易出现负迁移，而联邦协作允许多方对等参与、互惠互利。对于多产品线、多地域的社区平台，该思路可用于不同子社区（如不同主题板块）的推荐模型协同训练——既共享通用用户行为模式，又保留各子社区的独特特征，避免主要板块的推荐效果因小众板块数据而退化。

Jundong Chen, Honglei Zhang, Xiangmou Qu, Haoxuan Li, Han Yu, Yidong Li

Dual-Enhancement Product Bundling: Bridging Interactive Graph and Large Language Model

商品组合推荐通过推荐互补商品组合提升电商收入。现有方法面临两个关键挑战：(1) 协同过滤方法依赖历史交互，对冷启动商品效果差；(2) LLM 缺乏直接建模交互图的能力。本文提出双增强方法，通过 Dynamic Concept Binding Mechanism (DCBM) 将图结构翻译为自然语言 prompt，实现图学习和 LLM 语义理解的双向增强。DCBM 在对齐领域实体与 LLM token 空间方面起到关键桥梁作用。

INSIGHT图到文本（Graph-to-Text）的范式是连接图神经网络和 LLM 的一种实用方案。DCBM 的动态概念绑定机制将图中的节点关系翻译为 LLM 可理解的自然语言描述，解决了 LLM 不擅长处理结构化图数据的问题。在社区搜索中，用户-帖子交互图同样丰富，可借鉴此思路：将社区交互图中的关联关系转换为文本 prompt 输入 LLM，增强 LLM 对社区关系结构的理解，用于冷启动内容推荐。

ID and Graph View Contrastive Learning with Multi-View Attention Fusion for Sequential Recommendation

序列推荐在电商领域日益重要，目标是从历史交互序列中提取用户偏好并预测下一个交互。近期方法利用对比学习和图神经网络增强表征——图捕捉关系结构，对比学习提升泛化性。本文提出同时利用 ID 视角和图视角进行对比学习，并通过多视角注意力融合机制自适应地整合两种视角的信息，在多个电商数据集上取得了改进。

INSIGHT多视角融合的思路在推荐系统中持续有效：ID 视角侧重个体唯一性，图视角捕捉全局关系结构，两者互补。对于社区搜索排序，可类比地构建'内容视角'（帖子文本语义）和'社交视角'（用户互动图谱）的对比学习框架，通过注意力机制自适应融合两种信号。该方法的通用性较强，但具体提升幅度需在目标场景上验证。

Xiaofan Zhou, Kyumin Lee
