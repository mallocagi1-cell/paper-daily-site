From Relevance to Authority: Authority-aware Generative Retrieval in Web Search Engines

NAVER 想让生成式检索在相关度差不多时偏向可信来源。做法是让视觉语言模型看网站截图和文字打 0 到 100 的权威分，再把这个分数当 GRPO 的奖励，训练一个直接生成网站域名的 3B 模型；上线时不替换原排序，只给生成的网站加分。离线 P@3 从 0.3555 提到 0.3856，和 14B 模型打平，R@5 还略低。奖励里只有权威分，相关性全靠 SFT 和 KL 约束兜住。线上 A/B 的对照组本身也有涨幅，口径不清，需要打折看。

Mitigating Collaborative Semantic ID Staleness in Generative Retrieval

生成式检索通过 Semantic ID (SID) 将每个 item 分配一个离散标识符，将检索转化为序列生成问题。融合了用户-item 交互信息的 SID 虽然效果更好，但随着交互模式随时间漂移，SID 的协作语义会变得陈旧。本文首次系统研究了严格时序评估下的 SID 陈旧问题，并提出轻量级、模型无关的 SID 对齐更新方法。该方法将新日志衍生的 SID 对齐到现有词汇表，使检索器 checkpoint 保持兼容，无需全量重建重训。在三个公开基准上，Recall@K 和 nDCG@K 指标持续优于使用陈旧 SID 的朴素微调，训练计算量降低约 8-9 倍。

INSIGHT这篇论文解决了生成式检索落地中一个非常实际的工程问题：SID 随时间老化导致检索质量下降。其提出的轻量对齐方法可以在不重训模型的情况下更新 SID 词汇表，这对于需要频繁更新 item 库的推荐/搜索系统（如 UGC 社区）具有直接借鉴价值。8-9 倍训练计算节省意味着 SID 刷新可以变成低成本的日常操作而非昂贵的全量重训，显著降低了生成式检索的运维成本。

Driving Engagement in Daily Fantasy Sports with a Scalable and Urgency-Aware Ranking Engine

日常梦幻体育 (DFS) 中比赛推荐具有强时效性要求，用户需在比赛开始前的窄窗口内行动。本文设计并部署了基于 Deep Interest Network (DIN) 架构的推荐引擎，通过两层时序信号注入：(1) 候选比赛的实时紧迫性特征（如距离锁定时间）；(2) 用历史交互时间间隔的时序位置编码动态加权过去行为的时效性。结合 listwise neuralNDCG 损失函数，在多节点多 GPU 架构（Ray + PyTorch）上实现。实验基于超过 65 万用户、1000 亿+交互记录，相比优化过的 LightGBM 基线取得 +9% nDCG@1 提升。

INSIGHT本文的核心价值在于将时间紧迫性建模融入推荐排序——这一思路可迁移至任何有时效性约束的推荐场景（如限时活动、直播推荐、实时热点内容推送等）。DIN 架构中注入时序位置编码来建模历史行为衰减是一个实用的工程技巧。+9% nDCG@1 的离线提升在工业级基线上非常可观，虽然尚未有线上 A/B 数据，但架构选择（Ray 分布式训练）表明已为大规模部署做好准备。

Unmesh Padalkar

MUSE: Multi-Domain Chinese User Simulation via Self-Evolving Profiles and Rubric-Guided Alignment

Renmin University

用户模拟器是交互式 AI 系统可扩展训练和评估的关键，但现有方法存在用户画像浅层化、长交互中人设一致性差、且多限于英文或单领域等问题。MUSE 提出多领域中文用户模拟框架：(1) 迭代画像自进化 (IPSE) 通过对比模拟轨迹与真实对话行为的差异逐步优化用户画像；(2) 角色反转监督微调提升局部响应真实性；(3) 专用评分标准奖励模型结合多轮强化学习实现细粒度行为对齐。在话语级和会话级评估中均优于强基线。

INSIGHTMUSE 对搜索推荐从业者的实践意义在于提供了一个高质量的中文用户模拟框架。在推荐系统的训练和评估中，真实用户交互数据获取成本高且存在隐私限制，而高保真的用户模拟器可以：(1) 加速推荐策略迭代测试；(2) 生成多样化训练数据解决冷启动问题；(3) 作为离线评估的替代指标。IPSE 画像自进化机制尤其值得关注，它解决了 LLM 模拟用户时常见的角色漂移问题。

Zihao Liu, Hantao Zhou, Jiguo Li, Jun Xu, Jiuchong Gao, Jinghua Hao, Renqing He, Peng Wang

Agentic Conversational Search with Contextualized Reasoning via Reinforcement Learning

多轮对话中用户意图随交互演变，需要上下文化的查询重写和检索-生成的动态协调。现有方法通常采用固定的 rewrite-retrieve-generate 流水线，各阶段独立优化。本文提出一种对话式搜索 Agent，通过强化学习训练交替执行检索和推理，学习针对不断演变的用户目标的探索性和自适应行为。相比单轮深度搜索 Agent，该方法能处理多轮交互中的混合主动行为优化。在四个广泛使用的对话基准上超越多个强基线，被 ACL 2026 (Findings) 录用。

INSIGHT该工作将对话式搜索从固定流水线升级为 RL 驱动的自适应 Agent，核心创新在于联合优化检索和推理动作的混合主动决策。对 UGC 搜索场景的启示：(1) 社区搜索中用户意图往往模糊且多轮演化，RL-based 对话 Agent 比传统 query 理解更能捕捉真实需求；(2) 交替搜索-推理的范式可应用于复杂信息需求场景（如跨帖子的综合问答）。ACL 2026 录用确认了方法的学术认可度。

RecNextEval: A Reference Implementation for Temporal Next-Batch Recommendation Evaluation

NTU

推荐系统研究中已开发了多种工具包以促进公平评估和可复现性，但近期对评估协议的审视揭示了现有评估流水线的有效性问题。RecNextEval 是一个专为 next-batch 推荐设计的评估框架参考实现，采用时间窗口数据划分确保模型沿全局时间线评估，有效减少数据泄露。框架突出了推荐系统评估的固有复杂性，推动模型开发更准确地模拟生产环境。开源并提供 GUI 界面。

INSIGHTRecNextEval 解决了推荐系统学术研究中长期存在的评估方法论问题：传统随机划分训练/测试集会导致数据泄露，使得离线指标虚高而无法反映线上效果。时间窗口划分更贴近生产场景。对从业者的启示：(1) 如果团队的离线评估仍使用随机划分，建议迁移到时序划分；(2) 该工具可作为新模型上线前的标准化评估基础设施；(3) 开源 + GUI 降低了使用门槛。

Tze-Kean Ng, Joshua Teng-Khing Khoo, Aixin Sun

Indexing Multimodal Language Models for Large-scale Image Retrieval

多模态大语言模型 (MLLM) 展现了强大的跨模态推理能力，但其在纯视觉任务上的潜力尚未充分探索。本文研究将 MLLM 作为免训练的相似性估计器用于实例级图像检索。方法将配对图像输入模型，将 next-token 概率转化为相似性分数，实现大规模检索流水线中的零样本重排序。结合高效索引和 top-k 候选重排策略解决可扩展性问题。实验表明 MLLM 在非原生领域优于任务专用重排器，且对杂乱、遮挡和小目标展现更强鲁棒性。

INSIGHT将 MLLM 的 next-token 概率转化为相似性分数用于检索重排序——这一技术路线对文本搜索/推荐同样适用。对搜索从业者的启示：(1) LLM 的生成概率可以作为文档相关性的 zero-shot 打分信号，无需专门训练重排器；(2) 与传统 embedding 方法的互补性值得探索（LLM 擅长语义推理，embedding 擅长效率）；(3) 论文中的高效索引策略（先粗召回再 LLM 重排）是将大模型引入检索的实用架构模式。

Bahey Tharwat, Giorgos Kordopatis-Zilos, Pavel Suma, Ian Reid, Giorgos Tolias
