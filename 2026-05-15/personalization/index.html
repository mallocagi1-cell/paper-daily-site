RAG-Enhanced Large Language Models for Dynamic Content Expiration Prediction in Web Search

本文针对商业搜索中“内容时效性与用户意图不一致”的问题，提出一种基于 RAG 增强的 LLM 动态内容过期预测框架，已部署在百度搜索线上。系统从文档中抽取细粒度时间上下文，并通过 LLM 推断 query 相关的“有效期边界”（validity horizon），即在该 query 意图下信息何时变得语义过期。框架引入了幻觉缓解策略以保证可靠性。离线评测与线上 A/B 实验均验证了显著的时效性收益。

KEY INSIGHT · 对业务意味着什么传统时间窗口过滤是“一刀切”，而“语义过期”才是搜索时效性的本质：同一篇 2 年前的帖子对一个 query 仍然有效，对另一个 query 已经过期。论文用 LLM 把“过期”建模为 query 相关的语义判断而非时间硬阈值，对社区 UGC 搜索（帖子/问答的有效期长短差异巨大）非常有借鉴价值——可以把 freshness 信号从规则改造成可学习的 query-document 二元判断特征接入排序。

MLPs are Efficient Distilled Generative Recommenders

📖 深度解读 · 13 分钟 →

针对基于 Semantic ID（SID）的生成式推荐模型在线推理延迟过高、beam-expanded autoregressive 解码代价昂贵的问题，提出 SID-MLP：一种以 MLP 为核心的轻量蒸馏框架。作者发现 SID 的层次结构使第一个 token 之后的预测难度急剧下降，重型 Transformer 解码器属于“结构性 over-kill”。SID-MLP 用一次性全局用户上下文编码替代逐 token attention，再将自回归 teacher 蒸馏到 position-specific MLP head 中，去除了密集 attention 开销。

INSIGHT本文对生成式推荐落地的关键瓶颈（推理延迟）给出了简单且工程友好的解法。核心洞察是：SID 的层次性意味着大部分注意力计算冗余，可以用 position-specific MLP head + 知识蒸馏来取代。对正在尝试落地 HSTU/TIGER 类生成式推荐的团队是直接可借鉴的“轻量化”方案——可以保持生成式范式的召回质量，同时把 latency 拉回到 DLRM 量级。

Zitao Liu et al.

F-GRPO: Factorized Group-Relative Policy Optimization for Unified Candidate Generation and Ranking

本文研究 LLM 在“统一候选生成 + 排序”任务中的端到端 RL 优化问题。当 LLM 在一次自回归 pass 中同时生成候选子集并排序时，奖励只在整条序列完成后给出，无法区分错误来自“没生成相关候选”还是“排序错误”，导致 credit assignment 困难、训练不稳定。F-GRPO 提出因子化的 group-relative policy optimization，把候选生成与排序两个子动作的优势函数解耦，再用组内相对优势抑制方差，使统一模型的训练更稳定、样本效率更高。

INSIGHT对未来“用一个 LLM 同时做召回+精排”的统一生成式排序范式，这是关键的训练算法基础。论文揭示了 reward 信号只能落在序列末端时 RL 极易塌缩到只学排序、不学召回（或反之），并用因子化优势函数解决——可以借鉴到任何“先生成集合再排序”的 list-wise 生成场景，例如 LLM-as-ranker 的 listwise 微调。

Rohit Kumar et al.

Task-Aware Automated User Profile Generation for Recommendation Simulation Using Large Language Models

LLM-based agent simulation 是评估推荐系统的新兴方向，但已有工作主要优化 memory/action 模块，profile 模块（决定 agent 行为是否真实）长期被手工模板拖累，难以跨数据集扩展。本文提出 task-aware 自动化用户 profile 生成框架，根据下游评估任务从用户交互序列中自动抽取多粒度画像（兴趣、行为风格、决策偏好），并通过 LLM 合成成自然语言 profile，显著缩小模拟用户与真实用户的行为分布差距。

INSIGHT对推荐系统的“线下评估”长期受真实用户日志稀缺与隐私约束困扰，LLM agent simulation 是绕过限制的有效路径。本文指出 profile 模块决定了模拟的上限，并把它从手工模板升级为可自动生成。对社区推荐/搜索同样适用——可以用同一框架为新业务、新国家、新场景快速搭建模拟评估管道，把 A/B 之前的离线评估从 offline metric 升级为 agent-level 行为评估。

Xin Zhang et al.

A Standardized Re-evaluation of Conversational Recommender Systems on the ReDial Dataset

ReDial 是会话推荐系统（CRS）最常用的 benchmark，但实验设置（预处理、ground-truth item 定义、外部 LLM、外部数据源）差异巨大，论文间结果难以比较。本文在统一条件下对来自 3 个架构家族的 7 个主流 CRS 方法做了标准化复评，发现 Recall@1 等细粒度排序指标对实现细节高度敏感，并且约 50% 报告精度其实来自数据中的“重复 shortcut”——即模型学到的是“用户已经提到过的 item 倾向于成为 ground-truth”。

INSIGHT本研究对推荐评测方法学是一记重击：很多看似 SOTA 的 CRS 收益其实来自“信息泄露”型 shortcut。对生产实践直接的启示是：构建任何“对话/Query → 推荐”的离线指标时，必须显式排除候选集中已经被用户提及/看过的 item，否则线下增益完全无法迁移到线上。复评方法也可推广到自家 CRS / 多轮搜索系统。

Ivica Kostric et al.

Beyond Centralization: User-Controlled Federated Recommendations in Practice

传统推荐系统依赖集中化的用户数据，存在隐私与用户控制权问题。本文部署了一个允许用户切换“个性化”与“多样性增强”排序目标的联邦推荐系统，开展为期 53 天、22 个真实用户、8807 个 item 目录的活体实验。结果显示：用户在拥有显式选择权时仍偏好个性化（CTR 65.37% vs 62.07%）；用户对控制机制满意度 3.93/5，期间累计调整设置 248 次；用户通过即时反馈逐渐理解控制旋钮与推荐结果的因果关系。

INSIGHT在隐私监管趋严背景下，“用户可控的推荐”是一条值得探索的产品方向。论文的实证发现可以直接用于产品策略：用户即便有“多样性”开关，多数时间仍倾向选择个性化——意味着我们不必担心放开开关会显著伤 CTR；但用户活跃调整设置（平均 11 次/人）说明这种“可见的控制感”本身就是用户体验红利，对社区类产品的留存可能有正向价值。

Manel Slokom et al.

PersonalAI 2.0: Enhancing Knowledge Graph Traversal/Retrieval with Planning Mechanism for Personalized LLM Agents

PAI-2 针对 GraphRAG 在个性化 LLM agent 场景下的局限，提出一种基于规划机制的多阶段动态查询处理管线，能根据抽取实体、命中图节点和生成的 clue-query 自适应迭代检索。在 NaturalQuestions / TriviaQA / HotpotQA / 2WikiMultihopQA / MuSiQue / DiaASQ 等 6 个 benchmark 上对比 LightRAG、RAPTOR、HippoRAG 2，LLM-as-a-Judge 平均提升 ~4%，显著降低幻觉率。

INSIGHT对长期记忆型个性化 agent 而言，“如何检索”比“存什么”更关键。本文的贡献是把“图遍历 + 规划”做成可迭代的多阶段过程，而非单次 retrieval。可借鉴的工程模式：把用户兴趣图谱当作可被 LLM 推理调度的工具，通过 clue-query 把检索拆成“先找入口实体—再扩散—再聚合”，比单次 dense retrieval 更适合社区 UGC 这种关系密集型语料。

Mikhail Petrov et al.

GAAMA: Graph Augmented Associative Memory for Agents

面向多会话个性化 agent 的持久记忆问题：flat RAG 丢失结构关系；entity-centric KG 在会话数据中产生 mega-hub 问题（高频实体节点稀释了相关性传播）。GAAMA 构建概念中介的知识图谱：通过 (1) 原始 episode 保留、(2) LLM 抽取原子事实与 topic 级 concept 节点、(3) 高阶反思合成的三步管线，使用 episode/fact/reflection/concept 四类节点和五类结构边，由 concept 节点提供跨切横向遍历路径，缓解 mega-hub 问题。

INSIGHT对长期记忆个性化（用户跨多日多 session 的兴趣演化）有直接借鉴价值。核心洞察是：以“实体”为中心的图无法承担会话级语义结构，会被高频实体（如“看电影”“喜欢”）拖垮；引入“概念”层节点作为跨切轴，能在不损失实体关系的同时绕开 mega-hub。对长尾用户兴趣建模、跨会话 query 改写都是可借鉴模式。

Swapnil Bhattacharya et al.
