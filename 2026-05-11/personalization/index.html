UniVA: Unified Value Alignment for Generative Recommendation in Industrial Advertising

UniVA 是腾讯视频号广告团队提出的生成式推荐框架，统一建模用户兴趣对齐与商业价值对齐两条目标。框架包含三个核心模块：把广告价值属性嵌入 Semantic ID 的 value-aware tokenizer；通过强化学习联合训练生成与排序的 decoder；以及面向在线服务的个性化 beam search。在腾讯视频号场景上，UniVA 离线 Hit Rate@100 提升 37.04%，线上 A/B 测试 GMV +1.5%。

KEY INSIGHT · 对业务意味着什么把'广告价值'从损失函数级别下沉到 token 级别——直接把出价/转化属性编码进 Semantic ID，是把生成式推荐范式从纯内容兴趣扩展到广告主目标的关键一步。配合 RL 同时优化召回与排序，避免了传统两阶段中重排稀释生成式分布的问题。对社区/UGC 平台的启示：当推荐目标同时包含内容质量、用户兴趣与商业目标时，统一在生成空间中建模比串联多个目标头更有效。

EKTM: Effective Knowledge Transfer for Multi-Task Recommendation Models

Huawei📖 深度解读 · 8 分钟 →

EKTM 针对 CVR 预估在多任务排序框架中的数据稀疏问题，提出有效跨任务知识迁移方法。引入 router 模块按任务相关性分发共享表示，并通过 transmitter 模块做任务特定的特征变换后再融入目标任务，避免硬共享带来的负迁移。在线上 A/B 测试中带来 3.93% 的 eCPM 提升，已在某商业广告平台的两个主流量场景部署。

INSIGHTEKTM 揭示了多任务推荐里被忽视的细节：CVR 样本极少时，单纯共享底层 embedding 会让强势任务的梯度淹没弱势任务。router+transmitter 的双层路由相当于在 MMoE 之上加了一层任务特定的'整形'，比直接共享专家更安全。对社区 UGC 平台多目标排序（点击、停留、互动、转化）有直接借鉴价值：先用 router 做知识分发，再用 transmitter 做任务自适应变换，是缓解长尾任务负迁移的实用 pattern。

Guohao Cai, Jun Yuan, Zhenhua Dong

Latte: Expressiveness Limits of Autoregressive Semantic ID Generation in Generative Recommendation

UCSDSnap

Latte 系统性分析了生成式推荐中自回归 Semantic ID 解码的表达力上限：当 item 共享 Semantic ID 前缀时，模型产出的概率会与 RQ-VAE 树结构强相关，导致同分支下的 item 概率被人为拉平，与真实用户偏好无关。作者提出在 Semantic ID 序列前插入一段可学习的 latent token，重塑解码空间，使 item 概率脱离树状偏置；在多个公开基准上 NDCG@10 平均提升约 3.45%。

INSIGHT这是对 TIGER/HSTU 系列生成式推荐范式的一个关键理论补丁：之前大家把 RQ-VAE 量化误差当作工程问题，Latte 指出真正的瓶颈是自回归解码的'树状归纳偏置'。在 ID 序列前加 latent prefix 等价于让模型在第一步先输出一个用户/上下文 embedding，再展开 ID 路径，可大幅缓解'同分支同概率'问题。对生成式召回的工程化启示：要么改 codebook 结构，要么在 prefix 上注入丰富的上下文，二选一是必须的。

Yupeng Hou, Haven Kim, Clark Mingxuan Ju, Eduardo Escoto, Neil Shah, Julian McAuley

TriAlignGR: Triangular Multitask Alignment with Multimodal Deep Interest Mining for Generative Recommendation

TriAlignGR 针对生成式推荐中 Semantic ID 构造与多模态用户兴趣对齐的难题，提出两阶段多模态语义传播：先做视觉编码，再做描述解码生成 Semantic ID；并设计三角形多任务训练，在视觉-描述-行为三类信号间共享一个统一解码器，覆盖 8 个生成任务（含新颖的视觉-语义映射），无需独立任务塔或复杂的损失加权。多模态深度兴趣挖掘模块使用 LLM 推理抽取潜在意图。

INSIGHTTriAlignGR 把'多模态'与'多任务'两条独立技术线拧到一起：用三角形对齐避免了多任务训练里常见的塔间不平衡问题，并把 LLM 推理当作隐式兴趣抽取器。对社区 UGC 内容（图文混合）有直接价值：可以用图像/文本双侧对齐生成 Semantic ID，再用 LLM 抽取笔记主题作为隐式兴趣输入。需要注意的是论文未给出线上 A/B 数据，工程落地前需要验证图像编码器的端到端延迟。

Yangchen Zeng, Hao Peng, Rongfeng Guo, Zhenyu Yu, Zhiyuan Hu, Jinze Wang

Light-FMP: Lightweight Feature and Model Pruning for Enhanced Deep Recommender Systems

Light-FMP 针对深度推荐系统中模型与特征共同膨胀带来的训练/推理成本问题，提出联合特征-模型剪枝框架。方法分两步：先用 hard concrete 分布在小样本上预训练一个 mask 层识别重要特征，再剪掉模型与冗余特征，并以领域自适应参数在剩余数据上继续训练。在多个公开推荐数据集上相比已有剪枝/蒸馏 baseline 取得更好的精度-效率平衡。

INSIGHT把'特征选择'和'模型剪枝'合并到同一阶段是一个被忽视的工程方向——以往两者通常串行，互相产生偏差。hard concrete mask 在小样本上预训练再迁移，可以避免在全量样本上学 mask 带来的高昂代价，适合特征维度大、训练数据周期短的场景。对社区搜索/推荐：当线上特征达到上百万维时，可以把 Light-FMP 作为一个'特征瘦身'前置步骤，再喂给主排序模型。

Nghia Bui, Yue Ning, Lijing Wang

Hesitator: Decision-aware User Simulation Agent for Evaluating Conversational Recommender Systems

NTU

Hesitator 是一个面向对话式推荐系统 (CRS) 评估的决策感知用户模拟 agent。已有 LLM-based 模拟器普遍存在'用户太爽快'的问题，会无脑接受推荐导致评估失真。Hesitator 把用户决策拆成模块化的 Decision Module：基于效用的 item 选择与基于'选择过载'的承诺决策分离，复现心理-经济学文献中的犹豫、回避、回退等行为模式。

INSIGHT对话式推荐评估的核心问题不是 LLM 模拟器'不像人'，而是它们'决策过快'——少了真实用户面对长候选列表时的认知负担。Hesitator 把效用打分与承诺判断显式拆开，本质上是为模拟器加了一个 'choice-overload prior'。社区平台做 CRS / agentic search 评估时可以借鉴：不要直接用 LLM 当用户，而要先注入决策心理模型再让 LLM 执行，能更准确预测真实场景的承诺率与流失率。

Yuan-Chi Li, Li-Chi Chen, Sung-Yi Wu, Yu-Che Tsai, Shou-De Lin
