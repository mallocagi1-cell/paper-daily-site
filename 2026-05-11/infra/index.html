MemReranker: Reasoning-Aware Reranking for Agent Memory Retrieval

针对 agent 长期记忆检索中现有 reranker 校准失真、时间/因果查询失效、忽略对话上下文的三类问题，作者基于 Qwen3-Reranker 用多阶段 LLM 蒸馏（multi-teacher pairwise + BCE pointwise + InfoNCE 对比）训练出 0.6B/4B 的 MemReranker 系列。0.6B 版显著超过 BGE-Reranker；4B 版在评测集上拿到 0.737 MAP，已与 Gemini-3-Flash 持平，但推理延迟仅为大模型 10-20%，且在金融、医疗等域外数据上保持竞争力。

When Is the Same Model Not the Same Service? A Measurement Study of Hosted Open-Weight LLM APIs

本文把开源权重 LLM 当作 service 而非静态制品来度量：定义 service = (provider, 时间) 上的端点，在模型版本、协议行为、上下文上限、价格、延迟、吞吐、可靠性、可用性 8 个维度系统测量同名模型在不同 provider 上的差异。关键观察：需求高度集中（前 5 版本占 87.4%）；列表可用 ≠ 实际被调用；不同应用诱导出迥异的 token 长度分布；通过基于度量的智能路由，单模型成本下降 37.8%、另一模型吞吐提升约 90%。方法学和复现物料已开源。

INSIGHT对正在用云端 LLM 做 query 改写、reranker、生成式答案的搜索团队，这篇是直接落地的基础设施读物：同样的 'Qwen3-32B' 在不同 provider 上 SLA 与定价差异巨大，盲目按公开价签做选型会留 30-90% 的钱在桌上；建议在自己的工作负载上跑一份多 provider 微型基准、把延迟/吞吐/价格写进路由策略；论文也提示我们 'token 长度分布是负载的一阶特征' — 短文本社区搜索请求与长文 RAG 完全不同，应分通道路由。

Haorui Li, Zhenghui He, Xuanzi Liu, Yang Xu, Dongsheng Liu, Jiakang Ma, Lupan Wu, Yangjie Wu 等 10 人

DITRON: Distributed Multi-level Tiling Compiler for Parallel Tensor Programs

ByteDancePKUTsinghua

DITRON 是面向 LLM 训推一体的 tile 级分布式编译器，通过 Core / Device / Task 三层抽象将 tensor / sequence / expert / pipeline 并行映射到异构集群；中端把算子级集合通信下降到 tile 级语义，原生支持计算-通信重叠。在 NVIDIA 与 AMD 双平台上 kernel 端 6-30%、vLLM 端到端推理 5-30% 提升；在企业级部署中训练效率 +10% 以上，推理 +20% 以上。

INSIGHT对自研推理/训练栈的搜推平台值得深读：'tile 级集合通信' 把 overlap 从手写 fused kernel 升级成编译器自动生成，可省下专家大量手工 CUDA/HIP 工作；多并行原语统一抽象意味着 EP/SP 切换不再要重写 megatron；跨 NVIDIA/AMD 的可移植性对当前 GPU 货源不稳的国内场景有现实价值。直接落地门槛是与 vLLM / Megatron 的 runtime 集成路径，建议先把作者开源 kernel 在自家 LLM 推理服务上做小规模 A/B。

Statistically-Lossless Quantization of Large Language Models

IISTARed Hat

提出三种 'lossless' 量化定义：任务无损（保持基准准确率）、分布无损（保持下一 token 分布）、以及 Expected Acceptance Rate 作为细粒度保真度指标。理论上证明对称量化相对非对称把噪声方差放大 γ²，由此推出 SLQ 方法：4 bit 以下即可任务无损，5-6 bit 可达到分布无损；配合优化 kernel 推理相对 FP16 加速 1.7-3.6x。

INSIGHT把量化讨论从 'PPL 涨多少' 推到 'KL/接受率有多接近原模型'，对线上需要严格一致行为的搜推系统（A/B 实验、合规、guardrail）非常关键。结论之一是工业界默认的对称量化在低比特带噪明显劣于非对称，建议线上 reranker / 生成式排序模型迁到非对称 4-bit 时配合 SLQ 风格校正；分布无损所需的 5-6 bit 也给出了工程下限，避免盲目压到 3-4 bit 后接受率塌方。

Michael Helcig, Eldar Kurtic, Dan Alistarh

FASQ: Flexible Accelerated Subspace Quantization for Calibration-Free LLM Compression

UC Irvine

FASQ 用 product quantization 对 LLM 权重做免校准压缩，通过调整 sub-vector 大小与 codebook 基数得到一条占 FP16 体积 27-49% 的连续设计曲线，填上固定比特方案够不到的中间区间。在 Meta-Llama-3-8B 上以 37-42% 体积取得 67.1-67.7 平均分，超过 4-bit GPTQ/AWQ；在 Qwen3-8B / Qwen3.5-9B-Base 上结论一致。配套 CUDA kernel 在消费级 GPU 上做到等效 4-bit 45.2 tok/s、等效 3-bit 51.8 tok/s，超过 FP16 与同档压缩方法。

INSIGHT对预算敏感的搜推线上服务（reranker、查询改写、问答生成），FASQ 提供两个新自由度：免校准（部署不再需要带样本上线流程）+ 任意中间体积（可以按显存/吞吐目标精确切档）。对 Qwen3 系列直接可用，建议先在自家 reranker 上跑 38-42% 档比对 GPTQ 4-bit；CUDA kernel 已开源，工程接入主要成本在 vLLM/SGLang 算子注册。短板是 PQ 反量化对 batch 形状敏感，大 batch 解码场景需要重新基准。

Ye Qiao, Yian Wang, Zhiheng Chen, Hyoukjun Kwon, Sitao Huang

Microbenchmark-Driven Analytical Performance Modeling Across Modern GPU Architectures

University of Delaware

为 NVIDIA Blackwell (B200) 与 AMD CDNA3 (MI300A) 系统性建立解析性能模型：B200 模型纳入 Tensor Memory、TMA 异步拷贝与第 5 代 tensor core；MI300A 纳入 Infinity Cache 层级与 occupancy 约束。在 21 个 B200 kernel 上 MAE 1.31%，27 个 MI300A kernel 上 MAE 0.09%，naive roofline 误差 >95%。模型可平滑迁移到 H200 / MI250X，作者承诺接收后开源全部模型与 microbench。

INSIGHT对自建训推平台、要做容量规划与新硬件选型的团队是难得的工程级参考：在 'B200 还是 MI300A' 的真金白银决策前，与其依赖厂商 marketing 数据，不如先用作者的 microbench 框架对自家 LLM 关键 kernel（FlashAttention、GroupGEMM、AllReduce）跑一遍解析模型，预测 latency / 占用率到 1% 级精度。该工作也说明 roofline 在新一代 GPU 已基本不可用；要继续依赖容量模型做调度与定价，必须升级到带 TMEM/TMA 的层级模型。

Aaron Jarmusch, Sunita Chandrasekaran

VibeServe: Can AI Agents Build Bespoke LLM Serving Systems?

University of Washington

VibeServe 提出一种对通用推理引擎的反向思路：用 agent 自动合成 '一次性' 的 bespoke serving 栈。外层 loop 规划与搜索系统设计；内层 loop 实现候选、做正确性校验并用目标 benchmark 测性能。在标准部署上与 vLLM 持平，在 6 个非标准场景（新模型架构、特定工作负载、硬件特化）上明显胜出。代码开源。

INSIGHT把 'serving 引擎' 从静态产品变成可由 LLM agent 即时合成的代码艺术品 — 这对总是有奇怪长尾负载的搜推平台（如多模态 reranker、特定 query 长度分布、特殊 GPU SKU）特别有启发。短期内不会替代 vLLM，但其方法论可以反哺自家平台：把'写一个针对短文本 batch 的轻量 prefill kernel' 这类工作下沉给 coding agent，在边缘场景做差异化优化。落地门槛是 sandbox + 验证回路的工程投入，不是模型能力。

Keisuke Kamahori, Shihang Li, Simon Peter, Baris Kasikci

EdgeRazor: A Lightweight Framework for Large Language Models via Mixed-Precision Quantization-Aware Distillation

NNJU

EdgeRazor 把混合精度与 sub-2-bit 权重量化和 QAD（蒸馏）合到一起，三个组件：Mixed-Precision QAD、Adaptive Feature Distillation、Entropy-Aware KL Divergence。1.88-bit 模型超过所有 3-bit 基线、比 SOTA 2-bit PTQ 高 11.3 分；1.58-bit 的 Qwen3-0.6B 体积从 1.41GB 压到 0.28GB，解码相对 FP16 提速 15.1x，训练资源也明显低于其它 QAD。

INSIGHT对端侧搜推（移动端 query 改写、本地小型推荐生成）有直接价值：1.5-bit 区间内 QAD 比单纯 PTQ 强一个量级，足以让 0.6B 量级 LLM 在手机/小盒子里跑起来。云端通用 LLM 服务收益相对有限，因为 1.58-bit 在 7B+ 模型上保真度仍不稳定，且通用 kernel 对超低比特支持还在演进。建议把它作为端侧路线的 baseline，但同 batch / 大长度 throughput 仍以 4-bit 量化（GPTQ / FASQ）为主流。

Shu-Hao Zhang, Le-Tong Huang, Xiang-Sheng Deng, Xin-Yi Zou, Chen Wu, Nan Li, Shao-Qun Zhang
