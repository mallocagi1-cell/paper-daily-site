Scaling Laws for Behavioral Foundation Models over User Event Sequences

该工作把语言模型的 scaling law 方法论迁移到用户行为序列基础模型。针对“特征化事件 embedder + decoder-only Transformer 预测下一个事件”的两段式架构，在真实交互数据上跑了约 600 组实验，训练算力覆盖 10^15–10^19 FLOPs，联合调节两段参数配比、critical batch size、模型/数据分配、冻结 embedder 后的负采样数四个部署相关维度。核心发现：embedder 仅占约 2% 参数时算力最优（embedder 每步更新更贵且重复 item 暴露更多）；低算力下最优配置偏数据密集，随算力增大 D/N 比向 Chinchilla 经验靠拢。

Bridging the Semantic-Collaborative Gap: An Asymmetric Graph Architecture for Cold-Start Item Recommendation

TubiKKumo AI📖 深度解读 · 7 分钟 →

Tubi 流媒体把物品冷启动建模成时序二部“设备-内容”图上的归纳式图补全问题。提出 Shallow-RHS 非对称双塔：左侧设备塔用时序有效的观看历史做消息传递抓协同信号；右侧内容塔故意做“浅”——不用 ID embedding、不做邻居聚合、不用任何交互派生表征，只从内容固有特征编码，强制内容编码器把固有特征映射到“协同感知”的 embedding 空间。训练后该编码器为冷/热内容统一产出 embedding，通过检索热门近邻代理实现隐式图补全；设备冷启动则用人口属性 cohort embedding 同理处理。大规模线上实验在内容冷启动互动、推广速度、曝光获取、设备冷启动互动上均取得稳定相对提升。

INSIGHT关键设计是“非对称”——只让有交互的一侧用图结构，无历史的一侧被逼着学纯特征到协同空间的映射，从而绕开“新内容必须立即拿到独立 embedding 且要适配 ANN 检索”的线上约束。对 UGC 社区的启示：新帖/新作者冷启动可借鉴这种“浅塔强制特征映射”，避免给新内容临时拼凑 ID 向量导致召回质量塌陷。

Anh Truong, John Trenkle, Yuanbo Chen, Honghong Zhao, Abdullah Alchihabi, Effy Fang, Michael Tamir

PHKT:Personalized Dynamic Hypergraph-enhanced KAN-Transformer for Multi-behavior Sequential Recommendation

面向多行为序列推荐（点击/加购/购买等辅助行为辅助预测目标行为），提出 PHKT（Personalized Hypergraph-enhanced KAN-Transformer）。设计个性化动态超图模块，依据用户历史行为序列对 item 相似度做行为感知加权，捕捉用户特定的异构高阶关系；用 Transformer 作时序骨干建模长短期偏好演化；并用 KAN（Kolmogorov-Arnold Network）替换前馈层里的传统 MLP，增强对不同潜在模式非线性响应的细粒度建模。在 Tmall、RetailRocket、IJCAI 三个真实数据集、多项指标上稳定超过 9 个强基线。

INSIGHT两个可借鉴点：一是把超图权重做成“随用户行为序列动态变化”而非全局共享，解决了标准超图用户无关加权的问题；二是用 KAN 替换 Transformer FFN 的 MLP——KAN 的可学习激活更适合拟合多行为场景下异构潜在模式的差异化非线性。社区多行为（点赞/评论/收藏/关注）建模可尝试这种“个性化超图 + KAN-FFN”组合。

Ruijie Du, Hao Chen, Xin Zhang, Dongjing Wang, Ze Zhang, Xudong Shen, Runze Wu, Dongjin Yu

ANCHOR: Agentic Noise Creation Framework for Human Simulation and Denoising Recommendation

针对隐式反馈去噪缺乏显式噪声标注、现有方法依赖启发式或无监督先验导致噪声误判的问题，提出 Creation-Recognition 新范式：不再间接推断噪声，而是主动“制造”带标签的噪声交互再训练专门识别器，把去噪从启发式过滤变成监督学习。ANCHOR 受 LLM-as-User 启发，用 agent 模拟用户行为生成噪声标签，分两阶段：噪声制造阶段用 recommender-in-the-loop 的 agentic 架构合成“偏好外噪声”（五种可扩展机制模拟主要噪声来源）与“边界邻近噪声”（对抗式边界精修生成挑战决策边界的模糊交互）；噪声识别阶段训练融合协同信号与语义表征的可复用参数化识别器。

INSIGHT核心转换是把“无标注去噪”变成“自造标注的监督去噪”，用 agent 主动构造正负噪声样本（尤其逼近决策边界的难样本）训练一个可复用识别器，而非每次靠规则过滤。对社区场景：误点击/诱导点击等噪声可用 LLM 模拟器批量造标签，训练独立噪声识别模块挂在召回/排序前做清洗。

Xiangming Li, Hua Chu, Chengyu Feng, Jianan Li, Yangtao Zhou

When Does Latent Reasoning Help? MeRa: Metric-Space Bias for Spatial Prediction

探讨潜在推理（latent reasoning，预测前迭代精炼表征）在空间预测中是否有效。发现关键在于推理是否“锚定在底层度量空间”：没有度量锚定时，潜在推理反而把空间预测拉到基线以下；用成对距离学到的“度量空间偏置”才带来稳定增益。提出 MeRa——轻量、与骨干无关、可插在任意序列编码器与预测头之间的模块。在 GETNext 骨干上，有/无度量空间偏置的推理差距达 4.5% NDCG@10；三个空间预测基准 NDCG@10 均最优，超过 GeoMamba、HMST。理论上证明度量约束推理收敛到唯一不动点，且 N 步推理严格比 N-1 步更具表达力。

INSIGHT给“在表征上迭代推理再预测”提供了一个重要边界条件：推理必须有几何/度量约束，否则越推越差。这对正在尝试“思考再推荐”的序列推荐有直接警示——盲目堆推理步数可能伤指标，需把推理约束在合理的度量/语义空间内。MeRa 即插即用、代码随附，迁移成本低。

Zhenyu Yu, Shuigeng Zhou

Rethinking Sales Lead Scoring with LLM-based Hierarchical Preference Ranking

销售线索打分（汽车、房产等长决策周期、多阶段漏斗）与电商推荐本质不同，传统规则卡、ML、pointwise CTR 模型面临监督稀疏、非结构化 CRM 日志语义鸿沟、无法刻画线索相对优先级三大难题。提出基于 LLM 的判别式打分框架，联合建模结构化 CRM 特征与非结构化客户交互；在其上提出 HPRO（Hierarchical Preference Ranking Optimization），用 margin-aware 的 Bradley-Terry 公式把稀疏二值标签转成稠密、漏斗感知的偏好对，使打分同时利用 pointwise 与 pairwise 监督。在某头部新能源车企大规模数据上取得 SOTA：分类 AUC 0.8161，排序精度相对提升 39.7%。

INSIGHT把稀疏二值转化标签通过 Bradley-Terry 构造成漏斗内的偏好对，是从 pointwise CTR 升级到 pairwise 排序的低成本做法，尤其适合转化信号稀疏的长周期场景。对社区/电商：当点击/转化标签稀疏时，可借鉴 margin-aware 偏好对把弱监督变稠密，并用 LLM 同时吃结构化特征与非结构化文本日志。

Chenyu Zhang, Yiwen Liu, Yin Sun, Xinyuan Zhang, Yuji Cao, Junming Jiao, Juyi Qiao

CausalPOI: Spatio-Temporal Graph-Based Causal Modeling for Cold-Start POI Check-in Forecasting

提出“冷启动 POI 签到预测”新问题：预测新引入 POI 的未来签到模式，需建模其时序演化与周边 POI 的功能交互。指出现有时空图方法多依赖邻近性图和相关性建模，忽略 POI 间功能依赖、也无法刻画城市干预的因果效应。提出 CausalPOI 因果时空图表征框架，用“时空功能交互图”建模 POI 间语义与空间关系，并构造结构对齐的处理图与对照图模拟事实/反事实场景以估计因果效应。在真实 SafeGraph 数据集上全面超过 SOTA 基线。

INSIGHT用处理图/对照图构造反事实、把因果效应引入时空图表征，是冷启动预测里区分“相关”与“因果”的一种思路。对社区/本地生活推荐：新 POI、新店、新话题的冷启动可借鉴“功能交互图 + 反事实对照”估计引入后的真实影响，而非只看与历史相关的邻居。

Zhaoqi Zhang, Miao Xie, Yi Li, Linyou Cai, Siqiang Luo, Gao Cong
