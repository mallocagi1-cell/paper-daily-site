Where Post-Training Quantization Breaks Text Embedders: A Measured Map Across Four Embedder Families

论文检验 embedding 模型能否直接沿用大语言模型的权重量化经验，覆盖四类架构的五个检查点，并分别保护 embedding、注意力和前馈模块。INT2 下相近重建误差对应的质量保留率竟为 1.3%—65.9%；面向特定任务蒸馏的 109M 学生经 INT3 量化后，以 68.4 MB 达到 78.04 NDCG@10，优于其教师的极低比特方案。

Accelerating Long-Context and Agentic Inference with NVFP4 KV Cache

SSGLangAlibabaNVIDIA

SGLang 联合 Qwen 与 NVIDIA 为长上下文推理加入 NVFP4 KV 缓存，以块级缩放压缩键值并配套解码内核。相同并发下，Qwen3.8-27B 峰值批次解码吞吐提升约 26%—30%；但 SWE-bench Verified 从 FP8 的 77.80% 降至 76.20%，说明容量收益仍伴随任务相关精度损失。

INSIGHT社区搜索若使用多轮查询理解或长上下文生成，应分别测试固定并发和容量驱动负载，区分缓存压缩本身与扩大批次的收益。该实现仍属实验支持，硬件与注意力后端存在约束；先以真实 UGC 查询回放测量 nDCG、答案质量和尾延迟，再决定是否用约 56% 的 KV 存储换取更多常驻会话。

03 3.55

TensorRT Edge-LLM Completes the MLPerf Edge Agentic Benchmark 6.4x Faster on Jetson AGX Thor

NVIDIA

NVIDIA 在单台 Jetson AGX Thor 上运行 Qwen3.6-27B，结合 NVFP4、跨轮 KV 与循环状态复用及树形多 token 预测。MLPerf Edge Agentic 的 1,007 轮工作负载在 24 分 36 秒完成，相比 llama.cpp 参考提交快 6.4 倍，输出吞吐为 52.33 token/s，BFCL 准确率为 87.94%。

INSIGHT对端侧社区搜索或本地查询助手，可借鉴跨轮缓存复用与完整状态恢复，避免每轮重复处理相同前缀。该测试约 96% 提示 token 命中热缓存，因此加速比高度依赖会话重用；单并发、特定量化配置和 Thor 硬件的结果，不能直接代表服务端高并发短查询的收益，仍需单独回放验证。

Translating CUDA Tile Operations from Python to Rust Using Agentic AI

NVIDIA

文章展示将 cuTile Python 与 Triton-TileIR 算子迁移到 cuTile Rust 的工程流程，通过中间表示对比、真实测试及性能验收约束自动生成代码。24 个 TileGym 公开算子在 DGX B200 的 347 组配对配置上达到 0.995 的整体几何平均相对性能，全部通过不低于基线 0.95 倍的门槛。

INSIGHT对社区搜索中自研向量运算或排序推理算子，值得借鉴的是把语义等价、实际后端执行和设备耗时分别设为验收条件。测试通过不代表掩码、归约轴或内存访问语义全部正确，应补充中间表示审查；当前流程依赖 Blackwell、CUDA 13.1 及 Rust 工具链，适合已有底层优化需求的团队试用。
