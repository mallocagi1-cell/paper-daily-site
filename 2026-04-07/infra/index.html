KernelEvolve: Scaling Agentic Kernel Coding for Heterogeneous AI Accelerators at Meta

Meta 提出 KernelEvolve，一个基于 LLM Agent 的自动化 kernel 编写与优化系统，能为 NVIDIA/AMD GPU、Meta MTIA 芯片和 CPU 等异构硬件自主生成生产级优化 kernel。系统将 kernel 优化建模为搜索问题，自动探索数百种候选实现。在广告排序模型推理中实现 60% 吞吐提升，在 KernelBench 的 250 道题目上达到 100% 通过率。该系统已在 Meta 生产环境大规模部署，每天为数十亿用户优化数百个模型的 Triton kernel。将在 ISCA 2026 发表。

FluxMoE: Decoupling Expert Residency for High-Performance MoE Serving

针对 MoE 模型推理中大量 expert 权重闲置占用 GPU 显存、与 KV Cache 竞争内存的问题，提出 FluxMoE 系统。核心思想是将 expert 权重从 GPU 常驻内存中解耦，引入 expert paging 抽象，按需加载 expert 并在使用后立即驱逐，将 GPU 内存优先分配给 KV Cache 等性能关键状态。系统基于 vLLM 实现，在严重内存受限场景下显著提升 MoE 模型的服务吞吐。

INSIGHTFluxMoE 提出的 expert paging 抽象将 MoE 推理的内存管理从静态驻留转向动态流式，类似操作系统的虚拟内存管理思想。这一设计洞察对搜索推荐系统部署 MoE 排序模型具有直接参考价值：在 GPU 显存受限的线上服务环境中，通过按需加载 expert 权重可以腾出更多显存给 KV Cache，从而提升并发请求处理能力和整体服务吞吐。

Qingxiu Liu, Cyril Y. He, Hanser Jiang, Zion Wang, Alan Zhao, Patrick P. C. Lee

03 4.10

Fast NF4 Dequantization Kernels for Large Language Model Inference

USC

针对 NF4（4-bit NormalFloat）量化模型在 NVIDIA GPU 上推理时反量化开销大的问题，提出基于共享内存的轻量优化方案。利用共享内存相比全局内存 12-15 倍的延迟优势，在 Gemma 27B、Qwen3 32B、Llama3.3 70B 三个模型上实现 kernel 级别 2.0-2.2 倍加速，端到端推理提升高达 1.54 倍。方案完全兼容 BitsAndBytes 生态，可即插即用。

INSIGHT该工作的实用价值在于以极低的工程成本获得显著的推理加速。通过精细的 GPU 内存层级利用（shared memory vs global memory），在不改变模型精度和框架兼容性的前提下大幅减少反量化延迟。对搜索推荐系统的启示：4-bit 量化是在单卡上部署大型排序模型的主流方案，该优化可直接集成到现有 BitsAndBytes 推理流程中，几乎零成本获得 1.5 倍以上的端到端加速。

Xiangbo Qi, Chaoyi Jiang, Murali Annavaram

Patterns behind Chaos: Forecasting Data Movement for Efficient Large-Scale MoE LLM Inference

针对大规模 MoE 模型（200B-1000B 参数）推理中 expert 随机选择导致的数据搬运开销问题，对 2025 年发布的 4 个前沿开源 MoE 模型进行了大规模分析（24000+ 请求）。从时间和空间两个维度系统性地总结出 6 条关键洞察，并在 wafer-scale GPU 和现有 GPU 系统上验证。在 wafer-scale GPU 上，基于洞察的轻量架构修改可带来显著的推理效率提升。

INSIGHT该工作首次系统化地揭示了 MoE 模型 expert 选择看似随机但实际存在可预测的时空模式。这一洞察对搜索推荐系统部署 MoE 架构的排序/召回模型意义重大——通过预测数据搬运模式可以预取 expert 权重，减少 All-to-All 通信延迟，在多卡/多机部署中显著提升推理效率。

Zhongkai Yu, Yue Guan, Zihao Yu, Chenyang Zhou, Zhengding Hu, Shuyi Pei, Yangwook Kang, Yufei Ding

When RL Meets Adaptive Speculative Training: A Unified Training-Serving System

提出 Aurora，首个统一投机解码训练与推理的在线系统。现有投机解码方案将 speculator 训练和服务分离，导致部署前离线训练时间长、真实加速效果只在部署后才能评估、目标模型迁移新领域时 speculator 退化等问题。Aurora 通过从实时推理流量中持续在线学习 speculator，以强化学习直接优化端到端解码加速指标，闭合训练-服务的反馈环路。

INSIGHTAurora 的核心贡献是将投机解码从离线训练加在线部署的两阶段范式升级为在线持续学习的统一范式，用 RL 信号直接优化真实解码加速而非代理指标（如 acceptance rate）。对搜索推荐系统 LLM 服务的启示：在线搜索场景中 query 分布持续变化，Aurora 的在线自适应机制可以让 speculator 持续跟踪流量变化，保持高效加速而无需频繁重训。

Junxiong Wang, Fengxiang Bie, Jisen Li et al.

TokenDance: Scaling Multi-Agent LLM Serving via Collective KV Cache Sharing

PKU

针对多 Agent LLM 应用中 All-Gather 通信模式导致的大量 KV Cache 冗余问题，提出 TokenDance 系统。通过 KV Collector 在整轮执行中一次性完成 KV Cache 复用，以及 Diff-Aware Storage 将同级 agent 的 cache 编码为主副本的稀疏差分，实现 11-17 倍压缩。在 GenerativeAgents 和 AgentSociety 基准上支持多达 2.7 倍的并发 agent 数。

INSIGHTTokenDance 的关键洞察是多 Agent 系统中的 KV Cache 冗余具有高度结构化的模式（All-Gather），可以通过集体化的 cache 共享而非逐对比较来高效消除。Diff-Aware Storage 的块稀疏差分编码思想对搜索推荐系统也有借鉴：多路召回或多模型集成的在线 serving 场景中，不同模型/策略共享大量相同上下文，类似的差分编码可显著节省显存。

Zhuohang Bian, Feiyang Wu, Chengrui Zhang, Hangcheng Dong, Yun Liang, Youwei Zhuo

Evaluating Small Language Models for Front-Door Routing: A Harmonized Benchmark and Synthetic-Traffic Experiment

研究使用小型语言模型（SLM，1-4B 参数）做推理时 model routing 的可行性。现有路由方案依赖 LLM 分类器或偏好训练的路由器，本身成本高延迟大。本文在 Azure T4 硬件上对 Phi-3.5-mini、Qwen2.5-1.5B、Qwen-2.5-3B 进行统一基准评估，Qwen-2.5-3B 达到最佳精确匹配准确率 0.783。在合成流量实验中验证了 SLM 路由器在多目标优化（质量、成本、延迟、治理约束）中的实用价值。

INSIGHT该工作验证了一个重要假设：1-4B 参数的小模型已具备足够的推理能力用于亚秒级、零边际成本的请求路由分类。这对搜索推荐系统的多模型服务架构有直接启示：可以用轻量级 SLM 作为前置路由器，根据 query 复杂度将请求分发到不同大小的模型，在保证质量的同时大幅降低平均推理成本和延迟。

Warren Johnson, Charles Lee

JoyAI-LLM Flash: Advancing Mid-Scale LLMs with Token Efficiency

JoyAI

JoyAI-LLM Flash 是一款高效 MoE 语言模型（48B 总参数，仅激活 2.7B），在 sub-50B 参数级别重新定义了性能与 token 效率的平衡。基于 20 万亿 token 预训练，经过 SFT、DPO 和大规模 RL 后训练。创新点包括 FiberPO 算法（受纤维化理论启发的 RL 算法，将信赖域维护分解为全局和局部分量），以及 thinking/non-thinking 认知模式的动态平衡以提升 token 效率。

INSIGHTJoyAI-LLM Flash 展示了 MoE 架构在极致稀疏方向的潜力：48B 总参数中仅激活 2.7B（约 5.6% 激活率），在保持强大性能的同时大幅降低推理计算量。FiberPO 算法的多尺度稳定性控制思想值得关注。对搜索推荐系统的启示：极高稀疏率的 MoE 模型可能成为在线服务部署大型模型的理想选择，在有限算力下获得接近稠密大模型的效果。

SLMQuant: Benchmarking Small Language Model Quantization for Practical Deployment

首个系统性的小型语言模型（SLM）量化基准。通过多轨评估覆盖多种架构和任务，揭示了 SLM 与 LLM 在量化敏感性上的根本差异：直接迁移为 LLM 优化的量化技术到 SLM 会导致次优结果。为不同架构和部署场景提供了实用的量化策略选择指南。

INSIGHT该工作的重要发现是量化技术不能一刀切：在大模型上表现最佳的量化方法在小模型上可能严重退化，反之亦然。这对搜索推荐系统部署不同规模模型时的量化策略选择具有直接指导意义——例如用于在线 serving 的小型排序模型和用于离线特征生成的大型 LLM 需要采用不同的量化方案。

How Hungry is AI? Benchmarking Energy, Water, and Carbon Footprint of LLM Inference

提出基于基础设施感知的 LLM 推理环境足迹基准框架，覆盖 30 个前沿模型在商业数据中心的能耗、水耗和碳排放评估。结合公开 API 性能数据、厂商环境系数和硬件配置统计推断，建立了跨模型的能效对比体系。采用交叉效率数据包络分析（DEA）识别最优能效前沿。

INSIGHT随着搜索推荐系统越来越多地引入 LLM 推理（query 理解、生成式召回等），LLM 推理的能耗和环境成本成为不可忽视的基础设施规划因素。该框架为基础设施团队提供了量化决策依据：在模型选型时除了关注性能指标，还应考虑单位推理的能耗和碳排放，特别是在大规模在线服务场景下，节能优化的累积效益可能非常可观。
