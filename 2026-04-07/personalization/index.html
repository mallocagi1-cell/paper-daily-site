MBGR: Multi-Business Prediction for Generative Recommendation at Meituan

针对工业级生成式推荐在多业务场景下面临的「跷跷板效应」（NTP 无法捕捉跨业务行为模式）和「表征混淆」（统一 SID 空间混淆不同业务语义）两大关键问题，提出 MBGR 框架。核心设计包括：(1) 业务感知 Semantic ID (BID) 模块通过领域感知 tokenization 保持语义完整性；(2) 多业务 token 预测框架捕捉跨业务行为依赖。该工作是首个面向多业务场景设计的生成式推荐框架，已在美团工业系统中部署验证。

2026 大模型×智能体×搜广推深度调研报告

系统性梳理 2024–2026 年大模型在搜索推荐广告全链路的工业实践。涵盖 Meta HSTU/GEM 架构（Instagram 广告转化率 +5%）、字节 LHSTU、美团生成式推荐、NVIDIA 与美团合作的 HSTU 加速方案等核心案例。同时覆盖 CTR 预估、多目标优化、冷启动等关键问题的 LLM 解决方案，以及从 MoE 到端到端生成式模型的架构演进路线。报告显示当前主流方案采用渐进式架构演进策略，模型规模正从 0.1B–1B 向 10B 扩展。

INSIGHT该报告最重要的工业洞察是：搜广推领域正从「LLM 辅助传统模型」向「端到端生成式模型」架构转型。Meta GEM 在 Instagram 广告上的 +5% 转化率提升验证了生成式推荐的商业价值。对于搜索/推荐团队，最直接的行动项是：(1) 评估 HSTU 架构替换现有排序模型的可行性；(2) 关注 MoE scaling 在推荐场景的收益规律；(3) 利用 NVIDIA recsys-examples 加速生成式推荐的训练推理实践。

Jump Start or False Start? A Theoretical and Empirical Evaluation of LLM-initialized Bandits

📖 深度解读 · 7 分钟 →

系统性研究利用 LLM 生成的用户偏好数据对 contextual bandits 进行 warm-start 的效果与边界。实验发现：在偏好对齐的场景中，warm-start 在数据损坏率达 30% 时仍有效，40% 时优势消失，50% 以上时反而损害性能。当 LLM 偏好与真实用户存在系统性偏差时，即使无噪声注入，LLM 先验也会导致比冷启动更高的 regret。理论分析将随机噪声和系统性偏差的影响进行了分解量化。

INSIGHT该工作为「LLM 辅助冷启动」设定了清晰的适用边界：LLM 生成的用户偏好只有在与目标用户群大致对齐时才能加速 bandit 学习，否则反而有害。这对推荐系统的冷启动实践有直接指导意义——在部署 LLM warm-start 前，必须先验证 LLM 的偏好分布与目标人群的匹配度。30% 损坏率阈值为工程上设置数据质量 gate 提供了量化参考。

Modeling and Controlling Deployment Reliability under Temporal Distribution Shift

提出以部署为中心的可靠性框架，将模型可靠性建模为由判别力（discrimination）和校准度（calibration）组成的动态状态。通过在连续评估窗口间跟踪可靠性轨迹，定义了可量化的波动性指标，并将部署适配形式化为平衡可靠性稳定性与干预成本的多目标控制问题。定义了一系列状态依赖的干预策略（如重训练、重校准），并通过实证分析了不同策略在成本-波动性空间中的帕累托前沿。

INSIGHT该工作将「何时重训练/重校准模型」从经验驱动提升为可量化的控制问题。对于搜索/推荐系统，模型部署后的时序分布漂移是持续性挑战，传统做法是按固定周期重训练。该框架提供的关键工具是：将 discrimination 和 calibration 拆分跟踪，识别出需要重校准而非完整重训练的场景，从而在保持排序质量的同时大幅降低重训练的计算开销。

LiME: Lightweight Mixture of Experts for Efficient Multimodal Multi-task Learning

提出 LiME（轻量级混合专家），通过轻量调制而非适配器复制实现专家特化。核心创新是使用单个共享 PEFT 模块，以轻量级专家向量调制其输出，使专家参数不随专家数线性增长。引入零参数路由机制，利用已有的冻结和适配后表征消除传统 MoE 中每层所需的学习路由参数。理论证明更多专家能保留更多任务相关信息，且调制可以有界误差近似完整的专家特定 PEFT。

INSIGHTLiME 的零参数路由机制和共享 PEFT 调制方案对推荐系统的多任务学习有直接启发：传统推荐 MoE（如 MMoE、PLE）中每增加一个 expert 就需等比增加参数和路由开销。LiME 证明了通过轻量向量调制实现专家特化的可行性，这为推荐场景中需要同时优化 CTR/CVR/时长等多目标的 MoE 架构提供了参数高效的替代方案，尤其适合在线推理延迟敏感的场景。

Bilateral Intent-Enhanced Sequential Recommendation with Embedding Perturbation-Based Contrastive Learning

提出 BIPCL 框架，通过双边意图增强机制显式地将多意图信号整合到 item 和序列表征中。用户侧和 item 侧的共享意图原型从行为模式中蒸馏集体意图语义，避免现有方法中的信息孤岛问题。同时设计基于 embedding 扰动的对比学习方法，通过在 embedding 空间添加可控扰动构建语义一致且判别力强的对比视图，替代传统的 item 重排序/替换等数据增强策略。

INSIGHTBIPCL 的双边意图增强思路值得关注：在用户侧和 item 侧同时引入共享意图原型，让意图信号在两个视角间流通，有效打破了传统序列推荐中用户意图和 item 特征的信息壁垒。对于社区搜索场景中「用户搜索意图多样」的问题，该方法的多意图原型机制提供了比单一用户向量更细粒度的用户兴趣建模方式。

Relative Contrastive Learning for Sequential Recommendation with Similarity-based Positive Pair Selection

提出 RCL（相对对比学习）框架用于序列推荐。核心创新是利用相似序列（目标 item 不同但行为模式相似的序列）作为额外正样本，突破传统监督对比学习中 same-target 序列稀缺的瓶颈。设计双层对比学习机制：第一层拉近 same-target 序列，第二层通过相对对比损失区分相似序列和不相似序列，使模型在更丰富的正样本信号下学习更鲁棒的序列表征。

INSIGHTRCL 解决的核心问题——same-target 序列稀缺导致对比学习信号不足——在工业推荐系统中非常常见。其「相似序列作为正样本」的思路可以推广到搜索场景：将点击了相似文档的 query 序列作为正样本对，增强 query 表征学习的监督信号。双层对比损失的设计避免了将所有非 same-target 序列等同对待，提供了更细致的监督梯度。

Zhikai Wang, Yanyan Shen, Zexi Zhang, Li He, Yichun Li, Hao Gu, Yinghua Zhang

VALOR: Value-Aware Revenue Uplift Modeling with Treatment-Gated Representation for B2B Sales

针对 B2B 销售中零膨胀收入分布下的 uplift 建模问题，提出 VALOR 框架。核心设计包括：(1) Treatment-Gated Sparse-Revenue Network 通过双线性交互防止因果信号在高维空间中的坍塌；(2) Cost-Sensitive Focal-ZILN 目标函数结合 focal 机制增强分布鲁棒性，同时引入基于金额加权的排序损失。还提出 Robust ZILN-GBDT 树模型变体，提供可解释性。在合成和真实 B2B 数据上验证了效果。

INSIGHTVALOR 的 Treatment-Gated 机制和 Focal-ZILN 损失设计虽然针对 B2B，但其核心思想可迁移到推荐系统：(1) 双线性交互防止 treatment signal 坍塌的思路适用于推荐中的因果效应估计（如估计干预对 CTR 的真实提升）；(2) 基于价值加权的排序损失可借鉴到推荐场景中高价值用户/商品的差异化排序优化。

Vamshi Guduguntla, Kavin Soni, Debanshu Das

User-Aware Conditional Generative Total Correlation Learning for Multi-Modal Recommendation

提出 GTC（生成式全相关学习）框架用于多模态推荐。指出现有多模态推荐中「解耦模态不变/模态特定信号」的范式存在两个根本缺陷：(1) 假设 item 内容对所有用户偏好的相关性相同，忽略了偏好的用户条件性；(2) 仅优化模态间的成对对比损失，忽略了多模态联合影响用户选择时的高阶依赖。GTC 通过交互引导的条件生成模型和全相关最小化/最大化机制同时解决这两个问题。

INSIGHTGTC 揭示了多模态推荐中一个被广泛忽视的问题：不同用户对 item 不同模态信息（文本/图片/视频）的关注度存在显著差异，而非 one-size-fits-all。对于 UGC 社区搜索，帖子往往包含文字、图片、标签等多种模态，不同用户搜索同一 query 时，对文字内容 vs 配图的关注权重不同。GTC 的用户条件化思路为多模态 UGC 排序提供了理论基础。

Jing Du, Zesheng Ye, Congbo Ma, Feng Liu, Flora. D. Salim

Dual-Perspective Disentangled Multi-Intent Alignment for Enhanced Collaborative Filtering

提出 DMICF 框架用于协同过滤中的多意图建模。从用户和 item 两个互补视角建模交互，通过宏观-微观原型感知变分编码器解耦细粒度的潜在意图。创新性地引入交互级监督，在用户意图和 item 意图之间执行维度对齐约束，使潜在因子可解释且协同优化。该方法在稀疏交互场景下展现出更好的鲁棒性和可解释性。

INSIGHTDMICF 的交互级意图对齐约束解决了协同过滤中一个关键问题：用户和 item 的潜在意图空间如何精确对齐。传统方法通过间接监督（如 BPR loss）隐式对齐，而 DMICF 显式地在每个交互上约束用户-item 意图的维度匹配。对于搜索推荐系统，这种显式对齐可以提升在稀疏用户场景下的推荐准确性，特别适用于社区平台中长尾用户的偏好建模。

Shanfan Zhang, Yongyi Lin, Yuan Rao, Bingcan Xia, Tingting Xin, Chenlong Zhang
