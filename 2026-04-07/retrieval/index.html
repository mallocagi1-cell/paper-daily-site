Meta Adaptive Ranking Model: Bending the Inference Scaling Curve to Serve LLM-Scale Models for Ads

Meta 公开了其广告排序系统 Wukong Turbo 的核心架构升级：将排序模型扩展至 LLM 级别（万亿参数）的同时，通过推理效率优化使计算成本从线性降为亚线性。核心创新包括：从逐对 user-ad 打分转为 request 级别批处理（一次计算 user 信号复用给所有候选广告）、选择性 FP8 量化实现 35% 模型 FLOPs 利用率、多 GPU 卡分片支撑万亿级 embedding 表。Instagram 上线后实测广告转化率 +3%、目标用户 CTR +5%，推理延迟稳定在 100ms 以内。

DiffuRank: Effective Document Reranking with Diffusion Language Models

Renmin UniversityAlibaba📖 深度解读 · 10 分钟 →

本文首次系统探索了扩散语言模型（dLLMs）在文档重排序中的应用，提出 DiffuRank 框架，实现了三种重排序策略：(1) pointwise 方法利用 dLLMs 估计 query-document 对的相关性分数；(2) 基于 logit 的 listwise 方法联合评估多文档相关性并直接从模型 logit 导出排序列表；(3) 基于排列的 listwise 方法。实验表明 dLLMs 在文档重排序上性能可与同等规模的自回归 LLM 相媲美甚至超越，同时因并行解码带来效率优势。代码已开源。

INSIGHT扩散语言模型为搜索重排序提供了自回归 LLM 之外的新范式选择。其核心优势在于并行解码（parallel decoding）——不需要逐 token 生成，可一次性评估多文档的相关性，这在 listwise 重排序场景下有天然的效率优势。对于实际搜索系统，logit-based listwise 策略尤其值得关注：它直接从模型 logit 层提取排序信号，避免了自回归模型中复杂的 prompt 工程和位置偏差问题。

Efficient Learning of Sparse Representations from Interactions

Charles University

本文提出一种从用户交互数据直接学习高维稀疏 embedding 的训练策略，修改 ELSA 协同过滤自编码器来生成稀疏表示，取代传统稠密 embedding。实验实现了高达 10 倍的 embedding 压缩而不损失精度，100 倍压缩仅损失 2.5% 精度。学到的稀疏表示还展现出与模型潜空间对齐的可解释结构，可用于分群级别的推荐和检索。代码和 demo 已开源。

INSIGHT稀疏表示的核心价值不仅在于存储压缩，更在于可解释性——稀疏维度自然对应语义概念，使得检索和推荐的结果可以追溯到具体特征。10 倍压缩零损失的结果表明，传统稠密 embedding 存在大量冗余。对搜索系统而言，稀疏表示可同时服务于倒排索引和语义检索，天然支持 hybrid search 架构，减少工程复杂度。

Vojtěch Vančura, Martin Spišák, Rodrigo Alves, Ladislav Peška

DGAI: Decoupled On-Disk Graph-Based ANN Index for Efficient Updates and Queries

Northeastern UniversityTsinghua University

针对十亿级近似最近邻搜索（ANNS）的磁盘图索引，提出解耦存储架构 DGAI：将重型向量数据与轻量图拓扑物理分离。现有系统的耦合存储在索引更新时产生大量冗余 I/O，DGAI 通过解耦设计，配合相似性感知动态布局优化和基于层级 PQ 的两阶段查询机制，实现了插入 8.17 倍、删除 8.16 倍的性能提升，混合工作负载下峰值查询延迟降低 67%。

INSIGHT解耦存储是 ANN 索引在动态数据场景下的关键设计选择。UGC 搜索场景中内容实时更新频繁（新帖子、删帖），传统 HNSW 等图索引的更新成本高昂。DGAI 的核心洞察是：向量数据和图拓扑的访问模式完全不同——更新主要涉及图结构而非向量本身，分离后可将更新 I/O 减少一个数量级。两阶段查询（先 PQ 粗筛再精排）弥补了解耦带来的查询性能损失。

LLM4Ranking: An Easy-to-use Framework of Utilizing Large Language Models for Document Reranking

Renmin University

LLM4Ranking 是一个统一的 LLM 文档重排序框架，支持 pointwise、pairwise、listwise 三种主流重排序策略，兼容开源和闭源 LLM。提供简洁可扩展的接口，以及开箱即用的评估和微调脚本。在多个标准检索数据集上进行了全面实验，覆盖不同模型规模和排序策略的组合对比。代码完全开源，降低了 LLM 重排序的实验和落地门槛。

INSIGHTLLM4Ranking 的最大价值在于标准化——它将三种排序策略和多种 LLM 后端统一在同一框架下，使得从业者可以快速对比不同策略在自己数据上的表现，而无需从零搭建。对于搜索团队评估 LLM 重排序方案，这是目前最实用的起步工具。框架设计也提示了一个趋势：LLM 重排序正在从研究探索走向工程标准化。

AnnoRetrieve: Efficient Structured Retrieval for Unstructured Document Analysis

HKUST

提出 AnnoRetrieve，一种从 embedding 范式转向结构化标注的新型检索方法。通过 SchemaBoot 自动为非结构化文档生成结构化 schema，再用结构化语义检索（SSR）基于标注进行精准匹配，替代传统的向量相似度检索。该方法大幅减少 LLM 调用次数和整体成本，在实际数据集上实现高精度检索，同时解决了 embedding 检索在粗粒度语义匹配上的局限。

INSIGHTAnnoRetrieve 挑战了'一切皆 embedding'的主流检索范式：在非结构化文档场景中，先将文档结构化标注再做精准匹配，比直接做向量相似度检索更准确、更省资源。这对 UGC 搜索有直接启发——社区帖子虽然是非结构化文本，但可以通过 LLM 提取结构化字段（话题、实体、情感等），再用结构化检索替代部分 embedding 召回，提升精度并降低计算开销。

Teng Lin, Yuyu Luo, Nan Tang

Principled and Scalable Diversity-Aware Retrieval via Cardinality-Constrained Binary Quadratic Programming

University of Virginia

将 RAG 中的多样性检索问题形式化为基数约束二次二值规划（CCBQP），通过可解释的权衡参数显式平衡相关性与语义多样性。开发了基于 Frank-Wolfe 的求解算法，提供了景观分析和收敛性理论保证。实验表明在相关性-多样性权衡上优于现有方法，同时具备更好的计算可扩展性。

INSIGHT搜索结果的多样性是用户体验的关键维度，但现有方法缺乏理论保证。CCBQP 框架的贡献在于将多样性检索从启发式方法提升到有理论根基的优化问题——可解释的权衡参数让搜索团队精确控制相关性与多样性的平衡。Frank-Wolfe 算法的收敛保证也使得该方法适用于线上 serving，不会出现优化不收敛导致超时的风险。

Qiheng Lu, Nicholas D. Sidiropoulos

Overcoming the "Impracticality" of RAG: Proposing a Real-World Benchmark and Multi-Dimensional Diagnostic Framework

YYahoo Japan

针对企业级 RAG 系统评估的多维复合问题，提出四轴难度分类法（推理复杂度、检索难度、文档结构多样性、可解释性要求），构建面向真实场景的 RAG benchmark。研究发现高性能模型在实际部署中常常失败，高分不等于高可用。该工作被 AAAI 2026 Workshop 接受，为 RAG 系统的实用化评估提供了标准化框架。

INSIGHTRAG 评估的核心问题在于现有 benchmark 过于简化——只看最终答案准确率忽略了检索难度、推理链复杂度等维度。四轴诊断框架让搜索团队可以定位 RAG 系统的具体瓶颈：是检索不准、文档理解不足、推理能力不够、还是结果不可解释。这对于搜索系统中 RAG 模块的优化方向选择有直接的指导价值。

Kenichirou Narita, Siqi Peng, Taku Fukui, Moyuru Yamada, Satoshi Munakata, Satoru Takahashi

Domain-Adapted Retrieval for In-Context Annotation of Pedagogical Dialogue Acts

Cornell University

提出领域自适应 RAG 方法用于对话标注：不微调生成模型，而是在检索端微调轻量 embedding 模型，并将对话按 utterance 级别索引来检索标注示例。在两个教学对话数据集上（TalkMoves、Eedi），三种 LLM 后端测试，Cohen's kappa 从基线的 0.160–0.413 提升至 0.526–0.743。分析表明 utterance 级别索引粒度是提升的主要驱动因素，而非 embedding 质量本身。

INSIGHT本文揭示了 RAG 系统中一个被忽视的优化维度：索引粒度比 embedding 质量更重要。将长文档拆到 utterance（语句）级别索引，检索出的示例更精准地匹配查询意图。这对搜索系统的启示是：在 UGC 短文本场景中，索引粒度的选择（帖子级 vs 段落级 vs 句子级）可能比花精力优化 embedding 模型带来更大的检索质量提升。

Jinsook Lee, Kirk Vanacore, Zhuqian Zhou, Bakhtawar Ahtisham, Rene F. Kizilcec

LogicPoison: Logical Attacks on Graph Retrieval-Augmented Generation

HKUST

发现 GraphRAG 系统的安全性从根本上依赖于底层知识图谱的拓扑完整性。提出 LogicPoison 攻击框架，通过类型保持的实体交换机制扰动全局逻辑枢纽和特定查询的推理桥梁，在保持文本表面可信的同时将有效推理路径引入死胡同。该方法在攻击效果和隐蔽性上超越现有 RAG 攻击方法，且能绕过 GraphRAG 对传统文本投毒和 prompt 注入的固有防御。

INSIGHTGraphRAG 被认为比传统 RAG 更安全（因为有结构化图约束），但本文证明其安全性依赖于图拓扑而非文本——攻击者无需修改文本内容，只需操纵图中实体关系就能破坏推理。对搜索系统的警示是：引入知识图谱增强检索时，图的完整性校验和实体关系验证必须作为安全基线，尤其在用户可贡献内容（UGC）场景下，恶意内容可能通过逻辑层面而非文本层面污染检索结果。
