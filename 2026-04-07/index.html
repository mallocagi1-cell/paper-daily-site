Realizing Scaling Laws in Recommender Systems: A Foundation-Expert Paradigm for Hyperscale Model Deployment

多个推荐场景都想用上一个大模型，蒸馏和静态用户向量只能传过去一小部分收益。Meta 的做法是让中心大模型为每个候选物品实时算一个结合用户全部历史的向量，各场景的小模型把它当输入特征，而不是当软标签去模仿。中心模型变强后，下游能吃到 64% 到 100% 的提升；已在 Meta 全量上线，单场景大盘指标提升 0.050%。

Optimizing RAG Rerankers with LLM Feedback via Reinforcement Learning

Nanjing University

提出 RRPO (ReRanking Preference Optimization)，用强化学习框架将 reranking 模型与 LLM 生成质量直接对齐。将重排序建模为序列决策过程，使用 LLM 反馈替代人工标注作为奖励信号，并引入 reference-anchored deterministic baseline 保证训练稳定性。在知识密集型基准上显著超越 RankZephyr 等强基线，且能泛化到不同 LLM (如 GPT-4o) 和查询扩展技术。

INSIGHTRRPO 的核心洞察是：传统 reranking 模型基于静态人工标注的相关性训练，与 LLM 实际生成所需的上下文存在根本性错位。通过将 reranking 视为 RL 问题、直接用 LLM 生成质量作为奖励，实现了 retrieval-generation 的端到端对齐。这一思路可直接迁移到搜索场景：用下游效果（CTR/nDCG）而非离线标注来优化排序模型，是 LLM 时代 reranking 的新范式。

Yuhang Wu, Xiangqing Shen, Fanfan Wang, Cangqi Zhou, Zhen Wu, Xinyu Dai, Rui Xia

03 4.10

Reinforced Latent Reasoning for LLM-based Recommendation

提出 LatentR3，通过在隐空间中进行推理来实现推理高效的 LLM 推荐，无需显式 Chain-of-Thought 生成。采用两阶段训练：(1) SFT 热启动初始化隐推理模块；(2) 基于改进的 GRPO 算法进行 RL 训练，用规则化奖励设计和连续奖励信号实现高效学习。少量隐 token 即可捕获完整推理过程，在多种 LLM 推荐方法上显著提升性能。

INSIGHTLatentR3 解决了 LLM 推荐中推理能力与推理效率的矛盾：显式 CoT 推理能提升推荐质量但推理延迟过高，而直接跳过推理又损失了性能。隐空间推理提供了第三条路径——在不增加输出 token 数的情况下获得推理增益。改进的 GRPO 算法避免了对高质量 CoT 数据的依赖，更适合推荐场景（因为推荐的 CoT 标注极其困难）。这对搜索/推荐系统中部署推理增强的 LLM 具有重要参考价值。

Yang Zhang, Wenxin Xu, Xiaoyan Zhao, Wenjie Wang, Fuli Feng, Xiangnan He, Tat-Seng Chua

Synapse: Evolving Job-Person Fit with Explainable Two-phase Retrieval and LLM-guided Genetic Resume Optimization

提出 Synapse 多阶段语义招聘系统，将高召回候选生成与高精度语义重排分离。使用 FAISS 稠密检索进行初筛，结合对比学习和 LLM 推理的集成模型进行精排。创新性地引入差分进化 + LLM 引导变异的简历优化框架，将简历优化建模为黑盒优化问题。集成模型在 nDCG@10 上比纯 embedding 基线提升 22%，进化优化在推荐得分上获得超过 60% 的相对增益。

INSIGHTSynapse 将进化算法与 LLM 推理结合用于推荐系统优化，是一种新颖的思路。两阶段（稠密检索 + LLM 语义精排）架构对 UGC 搜索有直接借鉴价值：先用高效的 embedding 检索做召回，再用 LLM 做细粒度语义匹配。进化优化用于 query/document 表示优化的思路，可迁移到搜索场景中的 query 改写和文档理解。

Ansel Kaplan Erol, Seohee Yoon, Keenan Hom, Xisheng Zhang

SelRoute: Query-Type-Aware Routing for Long-Term Conversational Memory Retrieval

提出 SelRoute 框架，根据查询类型将检索路由到专门的管线——词汇、语义、混合或词表增强——实现长期对话记忆的高效检索。使用仅 109M 参数的 bge-base-en-v1.5 即达到 Recall@5=0.800，无需 GPU 或 LLM 推理。正则表达式分类器达到 83% 路由准确率，在 8 个额外基准（62K+ 实例）上泛化良好。发现词表扩展有助于词汇检索但损害语义 embedding。

INSIGHTSelRoute 的查询感知路由思想对搜索系统有重要启示：不同类型的 query（关键词型、语义型、混合型）适合不同的检索策略，自适应路由比单一检索管线更高效。用轻量正则分类器做路由决策（83% 准确率）说明不需要复杂模型即可实现有效分流。无 GPU 推理的设计使其特别适合延迟敏感的在线搜索场景。

Matthew McKee

06 3.30

Towards Position-Robust Talent Recommendation via Large Language Models

Tsinghua University

提出 L3TR，一种基于 LLM 的列表级推荐框架。通过 block attention 机制和局部位置编码解决 LLM 在列表推荐中的位置偏差和 lost-in-the-middle 问题。引入 ID 采样方法解决训练和推理阶段候选集大小不一致的问题，并设计了位置偏差检测指标和免训练去偏方法。在两个真实数据集上一致优于现有基线。

INSIGHTL3TR 揭示了 LLM 做列表推荐时的关键挑战——位置偏差：LLM 倾向于关注列表首尾的候选而忽略中间位置。Block attention 和局部位置编码提供了轻量级的解决方案。这对所有使用 LLM 做候选排序的搜索/推荐系统都是重要警示：直接将候选列表输入 LLM 排序会引入系统性偏差，需要针对性的去偏设计。

Silin Du, Hongyan Liu

Dependency-Guided Parallel Decoding in Discrete Diffusion Language Models

提出 DEMASK，通过依赖关系预测实现离散扩散语言模型的高效并行解码。在单次前向传递中估计 masked 位置间的 pairwise 条件影响，用贪心算法选择依赖度有界的位置进行同时解码。提供理论保证，证明并行采样与模型真实联合分布之间的总变差距离有界。在 Dream-7B 上实现 1.7-2.2 倍加速，同时保持甚至提升准确率。

INSIGHTDEMASK 解决了扩散语言模型并行解码的核心问题——token 间依赖导致的质量退化。通过显式建模依赖关系并选择性并行，在加速和质量之间取得了理论有保障的平衡。随着扩散模型在推荐系统中的应用（如 DiffRec、ContRec），这类加速技术对降低扩散式推荐的推理成本具有直接价值。

Liran Ringel, Ameen Ali, Yaniv Romano
