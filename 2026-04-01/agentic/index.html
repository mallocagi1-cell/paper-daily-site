Seed1.8 Model Card: Towards Generalized Real-World Agency

ByteDance 发布 Seed1.8 基础模型，目标是通用的真实世界代理能力：从单轮预测扩展到多轮交互、工具使用和多步执行。该模型保持了强大的 LLM 和视觉语言性能，同时支持统一的 agentic 接口——搜索、代码生成与执行、GUI 交互。部署层面提供延迟和成本感知推理，包括可配置的思考模式和优化的视觉编码。在标准 benchmark 和应用对齐工作流上进行了涵盖基础能力、多模态理解和 agentic 行为的全面评估。

AgentSwing: Adaptive Parallel Context Management Routing for Long-Horizon Web Agents

针对 LLM 自主代理在长时域信息搜索中有限上下文容量的瓶颈，提出 AgentSwing 自适应并行上下文管理路由框架。现有方法在整个轨迹中使用单一固定上下文管理策略，无法适应累积上下文的有用性变化。AgentSwing 引入概率框架，从搜索效率和终端精度两个维度刻画长时域成功率，在每个触发点并行扩展多个上下文管理分支，通过前瞻路由选择最优延续路径。在多个多样化 benchmark 上验证了有效性。

INSIGHTAgentSwing 揭示了搜索代理上下文管理的关键矛盾：保留更多历史信息提升终端精度，但压缩上下文提升搜索效率。其并行分支 + 前瞻路由的设计思路可直接借鉴到多轮搜索系统中：当用户 query 复杂时，系统并行尝试不同的上下文压缩策略（摘要、关键词提取、截断），然后选择最优分支继续搜索。这对构建社区搜索中的 deep research 功能有直接参考价值。

Marco DeepResearch: Unlocking Efficient Deep Research Agents via Verification-Centric Design

Alibaba

深度研究代理在自主执行开放式调查任务时，可靠的验证机制是维持长时域推理能力的关键。Marco DeepResearch 提出以验证为核心的三层框架设计：(1) QA 数据合成阶段引入验证机制控制问题难度并确保答案唯一正确；(2) 轨迹构建阶段设计验证感知的训练流程；(3) 测试时扩展阶段通过验证驱动的搜索策略提升推理质量。该方法解决了现有范式中错误在各阶段向下游传播的核心瓶颈。

INSIGHTMarco DeepResearch 揭示了 deep research 代理的核心痛点：缺乏显式验证导致错误在数据合成→轨迹构建→推理全链路传播。其「验证优先」的设计理念可借鉴到搜索系统中：在 query 改写阶段验证改写质量、在检索阶段验证文档相关性、在排序阶段验证排序一致性。三层验证框架的思路特别适合构建可靠的多步搜索 pipeline。

MiroEval: Benchmarking Multimodal Deep Research Agents in Process and Outcome

现有深度研究系统的评估主要关注最终报告质量（使用固定评分标准），忽略了对底层研究过程的评估。MiroEval 引入兼顾过程与结果的评估框架，覆盖多模态场景，使用反映真实用户查询复杂度的任务，并支持随知识演进动态刷新。该 benchmark 是首个同时评估深度研究代理的搜索策略质量（过程）和最终输出质量（结果）的综合评测工具。

INSIGHTMiroEval 指出了深度研究系统评估的关键缺陷：仅评估最终报告忽略了搜索过程的质量。对搜索系统从业者的启示是，评估 agentic 搜索时不应仅看最终排序指标，还需评估中间搜索策略的效率和质量——比如 query 改写次数、检索轮数、无效搜索比例等过程指标。这为构建搜索代理的 offline 评测体系提供了参考框架。

Gen-Searcher: Reinforcing Agentic Search for Image Generation

Gen-Searcher 是首个尝试训练搜索增强图像生成代理的工作，通过多跳推理和搜索来收集文本知识和参考图像，解决知识密集型或需要最新信息的真实场景。构建了 Gen-Searcher-SFT-10k 和 Gen-Searcher-RL-6k 两个高质量数据集，并引入 KnowGen benchmark 从多维度评估需要搜索外部知识的图像生成能力。训练流程结合 SFT 和 RL，使代理学会何时搜索、搜索什么以及如何利用搜索结果指导生成。

INSIGHTGen-Searcher 将「搜索增强」范式从文本生成拓展到图像生成，核心创新在于用 RL 训练代理自主决定搜索时机和策略。其 SFT→RL 的两阶段训练范式（先学搜索格式，再通过 RL 优化搜索质量）对搜索代理的训练方法论有直接参考价值。特别是通过构建搜索密集型任务的专用数据集来训练代理的思路，可以迁移到社区搜索场景中训练 query 理解和多轮检索代理。

GroupRAG: Cognitively Inspired Group-Aware Retrieval and Reasoning via Knowledge-Driven Problem Structuring

针对 RAG 和 CoT 方法在现实场景中性能退化的问题，提出 GroupRAG——受认知科学启发的群体感知检索与推理框架。该方法识别问题中的潜在结构分组，从多个概念出发点执行检索和推理，实现检索与推理过程的细粒度交互。核心思想是将人类问题求解视为结构化问题空间搜索而非单一推理链。在 MedQA 数据集上验证了有效性。

INSIGHTGroupRAG 引入了「问题结构感知」的新视角来改进 RAG：不是简单地对 query 做单一检索，而是先识别问题的多个子结构（关键点分组），然后从不同角度分别检索和推理。对社区搜索的启示是，复杂 query 可以通过结构化分解来改进检索质量——例如将「有没有适合带狗的海边民宿」分解为「海边民宿」+「允许宠物」两个结构组分别检索再融合，比直接整句检索更有效。

PubMed Reasoner: Dynamic Reasoning-based Retrieval for Evidence-Grounded Biomedical Question Answering

可信的生物医学问答系统不仅需要准确回答，还需提供可验证的证据支持。现有 RAG 方法缺乏迭代优化差查询的机制，自反思方法只在完成检索后才介入。PubMed Reasoner 提出三阶段生物医学 QA 代理：自我批评（评估 query 质量）→ 动态 query 优化 → 证据锚定回答生成，实现了检索过程中的实时推理干预而非事后修正。

INSIGHTPubMed Reasoner 的「检索中推理」思路比传统 RAG 的「检索后推理」更进一步。其三阶段设计——先自我批评 query 质量、动态优化检索查询、最后基于证据生成答案——是构建可靠搜索代理的实用模式。对社区搜索系统，特别是需要高精度答案的问答场景（如医疗、法律社区），这种迭代式 query 优化 + 证据锚定的方法可以显著提升搜索结果的可信度和准确性。

Dynamic Dual-Granularity Skill Bank for Agentic RL

针对 agentic RL 中经验复用的难题，提出 D2Skill 动态双粒度技能库。将可复用经验组织为任务级技能（高层指导）和步骤级技能（细粒度决策支持和错误纠正）。通过配对的基线和技能注入 rollout 联合训练策略和技能库，利用性能差异推导事后效用信号。在 ALFWorld 和 WebShop 上使用 Qwen2.5-7B-Instruct 和 Qwen3-4B-Instruct-2507 验证了有效性。

INSIGHTD2Skill 提出的双粒度技能库思路对构建搜索代理有启发：任务级技能对应「搜索策略模板」（如针对长尾 query 的处理策略），步骤级技能对应「原子操作经验」（如某类 query 改写技巧）。其效用感知的检索和剪枝机制确保技能库不会无限膨胀。在 WebShop 上的实验直接验证了该方法在电商搜索-购买场景中的有效性，说明其对搜索类 agentic 任务有较好适配性。

Courtroom-Style Multi-Agent Debate with Progressive RAG and Role-Switching for Controversial Claim Verification

针对 LLM 在高风险声明验证中的幻觉和浅层推理问题，提出法庭式多代理框架 PROClaim。该方法将验证过程重新定义为结构化对抗审议，集成专职角色（原告、辩护、法官）和渐进式 RAG（P-RAG），在辩论过程中动态扩展和优化证据池。采用证据协商、自反思和异构多法官聚合机制。在 Check-COVID benchmark 上零样本评估达到 81.7% 准确率，比标准多代理辩论高 10.0 个百分点，其中 P-RAG 是性能提升的主要驱动力。

INSIGHTPROClaim 的 Progressive RAG（P-RAG）设计最具实践价值：不同于传统一次性检索，P-RAG 在多轮辩论中逐步扩展证据库，每轮根据辩论状态定向补充所需证据。这种「按需渐进检索」模式比一次性大批量检索更高效且更精准。对搜索系统的启示是，在事实核查或争议性内容搜索场景中，可以采用多代理协作+渐进式检索来提升搜索结果的可靠性和全面性。

MuSEAgent: A Multimodal Reasoning Agent with Stateful Experiences

针对研究代理依赖轨迹级检索的局限，提出 MuSEAgent 多模态推理代理，通过有状态经验学习范式增强决策能力。核心方法是将交互数据通过事后推理（hindsight reasoning）抽象为原子级决策经验，组织到质量过滤的经验库中，支持推理时的策略驱动经验检索。MuSEAgent 通过互补的广搜和深搜策略实现自适应经验利用，可在不同组合语义视角下动态检索多模态引导。实验证明其一致优于强轨迹级检索基线。

INSIGHTMuSEAgent 的核心创新是将搜索经验从「轨迹级」细化到「原子决策级」——不是记住整个搜索过程，而是提取每个决策点的可复用经验。这对搜索代理的经验学习机制有直接启发：系统可以从历史搜索会话中提取「遇到 X 类 query 时，策略 Y 更有效」的原子级经验，而非简单记录完整搜索轨迹。其广搜+深搜的双策略检索也可用于搜索结果的多维度探索。
