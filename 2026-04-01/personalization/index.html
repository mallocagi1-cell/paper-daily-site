Let the Agent Steer: Closed-Loop Ranking Optimization via Influence Exchange

针对推荐排序中离线指标与线上效果系统性偏差的问题，提出 Sortify——首个全自主 LLM 驱动的排序优化 Agent。核心思路是将排序优化重新定义为「影响力交换」问题，通过基于 Savage 主观期望效用理论的双通道框架（Belief 通道校正离线-线上迁移偏差 + Penalty 通道调整约束惩罚），以及 7 张关系表构成的记忆数据库实现跨轮学习。线上部署结果：A 国 GMV 从 -3.6% 提升至 +9.2%（7 轮优化），B 国冷启动 7 天 A/B 测试达 +4.15% GMV/UU 和 +3.58% 广告收入。

PANTHER: Generative Pretraining Beyond Language for Sequential User Behavior Modeling

Tencent📖 深度解读 · 7 分钟 →

将 LLM 的生成式预训练范式拓展到用户行为建模领域，提出 PANTHER 混合生成-判别框架。核心方法是对用户行为序列中的多维属性（时间、上下文、交易类型）进行结构化 token 化，结合序列模式识别模块捕捉周期性交易模式，并构建统一的用户画像 embedding（融合人口统计信息与交易历史）。在微信支付场景部署：下一笔交易预测 HitRate@1 提升 25.6%，欺诈检测 Recall 提升 38.6%；公开基准上 HitRate@1 最高提升 21%。通过离线 embedding 缓存实现实时推理。

INSIGHTPANTHER 证明了生成式预训练可以有效地从用户行为序列中提炼出可迁移的行为知识表征，类似于 LLM 从文本中学习世界知识。对推荐系统从业者的核心启示是：用户行为可以作为独立模态进行大规模预训练，生成的 user embedding 能跨场景迁移（如从交易预测到欺诈检测）。这种预训练-微调范式特别适合数据稀疏或标注有限的推荐场景，通过无监督行为预训练获得泛化的用户表征。

RCLRec: Reverse Curriculum Learning for Modeling Sparse Conversions in Generative Recommendation

Alibaba

针对大规模推荐系统中转化目标稀疏难以优化的问题，提出 RCLRec（反向课程学习）框架。在生成式推荐（GR）的统一 token 序列基础上，为每个转化目标从用户历史中逆向选取转化相关子序列构建短课程，其语义 token 作为解码器前缀与目标转化 token 联合输入；同时引入课程质量感知损失确保所选课程对转化预测具有信息量。线上部署效果：广告收入 +2.09%，订单量 +1.86%。

INSIGHTRCLRec 的核心创新在于「反向课程」设计——不是按时间正序遍历全部历史，而是从转化事件出发逆向追溯相关行为构建精简子序列。这种方法有效解决了 GR 模型中转化信号被大量非转化行为淹没的问题。对实践的启示是：在多行为类型的推荐场景中，针对稀疏目标设计定向的序列提取策略比简单的全序列注意力更有效。该技术可直接迁移到搜索场景中的稀疏转化预测（如下单、关注）。

Design Once, Deploy at Scale: Template-Driven ML Development for Large Model Ecosystems

Meta

Meta 对其大规模广告推荐 ML 生态系统进行了系统性实证研究，比较标准化模型构建方法与独立逐模型优化的效果。提出 Standard Model Template (SMT) 框架，能生成适应不同数据分布和优化目标的高性能模型。核心结果：交叉熵在中性算力下提升 0.63%，单模型迭代工程时间减少 92%，技术-模型对采纳吞吐量提升 6.3 倍，技术传播复杂度从 O(n·2^k) 降至 O(n+k)。

INSIGHT该研究挑战了「不同优化目标必然需要差异化模型设计」的传统观点。对搜索/推荐团队的核心启示：当模型生态规模达到一定程度后，标准化模板带来的工程效率收益（92% 迭代时间缩减）远超个性化优化的边际增益。这种「一次设计、规模化部署」的思路特别适合需要同时维护多个 CTR/CVR 预测模型的广告和推荐平台，显著降低了新技术在全生态传播的成本。

Off-Policy Learning with Limited Supply

研究供给受限场景下的离线策略学习（Off-Policy Learning），针对推荐系统和在线广告中优惠券分配、电商库存有限等现实约束。理论分析表明传统贪心策略（为当前用户选择最高期望收益物品）在有限供给下会导致物品过早耗尽，使后续高价值用户无法获得最优推荐。提出新的策略学习算法，在供给约束下实现全局最优分配。

INSIGHT这项工作揭示了一个推荐系统实践中常被忽视的问题：不考虑供给约束的逐用户最优策略在全局层面并非最优。对电商搜索和推荐系统尤其重要——当展示位有限或商品库存受限时，简单的「为每个用户推最好的」策略可能损害整体效率。该方法为有限供给场景（如限时优惠、稀缺商品推荐、广告预算约束）提供了理论基础和可行的策略优化框架。

On the Accuracy Limits of Sequential Recommender Systems: An Entropy-Based Approach

Tsinghua

提出基于信息熵的免训练方法来量化序列推荐系统的准确率理论上限，解决了现有可预测性分析对候选空间规模敏感、在低可预测性场景下 Fano 不等式失真的问题。实验在可控合成数据和多个真实基准上验证：与 Oracle 控制的难度度量 Spearman 相关性达 0.914；用户分层分析揭示了不同新颖性偏好和活跃度水平用户间的系统性可预测性差异；基于高可预测性用户训练集可以在减少数据预算的同时保持竞争力表现。

INSIGHT这项研究提供了一个实用工具：在投入大量资源开发新模型之前，先评估当前数据集上的准确率天花板。对搜索/推荐团队的实际价值在于：(1) 用熵估计器判断是否还有提升空间，避免在已接近理论极限的数据集上无效投入；(2) 用户分层分析可以识别哪类用户行为更可预测，指导差异化建模策略；(3) 高可预测性用户子集可用于高效训练，降低数据需求。

En Xu, Jingtao Ding, Yong Li

Prototype-Aligned Federated Soft-Prompts for Continual Web Personalization

针对持续 Web 个性化中非平稳数据分布与隐私约束的挑战，提出 ProtoFed-SP 框架。核心设计是在冻结骨干模型上注入双时间尺度 soft prompt：快速稀疏短期 prompt 追踪会话意图，慢速长期 prompt 锚定到服务端原型库（通过差分隐私联邦聚合持续刷新），查询路由到 Top-M 原型组合个性化 prompt。在 8 个基准上 NDCG@10 提升 +2.9%，HR@10 提升 +2.0%，Amazon-Books 上 NDCG 相比最强基线提升 +5.0%。

INSIGHTProtoFed-SP 的关键设计是用双时间尺度 prompt 分离短期意图捕捉和长期偏好建模：短期 prompt 快速适应当前会话，长期 prompt 通过联邦原型库稳定记忆。这种稳定性-可塑性控制机制对推荐系统中用户兴趣漂移问题有直接借鉴价值。实践启示：在用户数据不能集中存储的场景下，基于 prompt 的参数高效个性化方案是一种轻量且隐私友好的替代方案，避免了全模型微调的高成本。

Canran Xiao, Liwei Hou

AlpsBench: An LLM Personalization Benchmark for Real-Dialogue Memorization and Preference Alignment

USTC

构建了首个基于真实人-LLM 对话的个性化评测基准 AlpsBench，包含 2,500 条交互序列和人工验证的结构化记忆。定义了个性化信息管理全生命周期的四项评测任务：个性化信息提取、更新、检索和利用。实验发现：模型在可靠提取用户特征方面存在困难，记忆更新性能有限，检索准确率随干扰项增加显著下降，显式记忆机制提升了召回但不保证偏好对齐的回复。

INSIGHTAlpsBench 揭示了当前 LLM 个性化的关键瓶颈：即使有显式记忆机制，模型也难以将检索到的用户信息有效转化为偏好对齐的回复。对搜索/推荐系统中的 LLM 应用具有警示意义：简单地让 LLM 记住用户画像不等于能生成个性化的推荐结果，需要专门的偏好对齐训练。该基准可作为评估 LLM-based 推荐系统个性化能力的标准工具。
