1. Is 2:4 Sparsity Still Worth It? Semi-Structured Sparsity versus Quantization in LLM Inference

The study compares lower-bit quantization with structured sparsity at matched storage cost, including metadata and online processing. On H100, a retrained sparse FP8 model delivers 27% higher prefill throughput than dense FP8.

Key insight: Choose compression steps against the hardware precision floor. Sparsity becomes useful after lower precision is exhausted; recovering perplexity does not establish that reasoning quality has recovered.

2. SGLang Low-Latency Mode: Kernels and Runtime

SSGLangAMDNVIDIA

SGLang integrates low-latency decode kernels through a plugin interface with compatibility checks and existing graph execution. In AgentX trace replay on four MI355X GPUs, P90 per-user token generation speed rises by 45–56%.

Key insight: Kernel fusion and cross-GPU communication need joint optimization. Explicit contracts for weight binding, cache writes, and fallback let specialized kernels operate within a serving runtime.

3. RCSD: Reinforcement and Continual Learning for Domain-Specific Speculative Decoding

RCSD trains speculative drafts against acceptance length using preference pairs from accepted and rejected sequences. It achieves 1.35× end-to-end speedup over HASS, an existing draft-training baseline.

Key insight: Train the drafter against verifier behavior. Masking target-aligned tokens concentrates updates on rejection points, while inference traces provide continued training data.

4. UlaCache: Unified Logical Addressing for Sparse LLM Serving

UlaCache separates sparse KV selection from physical placement through stable logical addresses and local reuse buffers. With matched memory budgets and speculative decoding, peak tensor-parallel decode throughput on B300 reaches 2.51× the baseline.

Key insight: Stable references make sparse access compatible with tiered storage. Transfer only missing state, and preserve the ordering between completing a transfer and updating its address mapping.

5. SPARE: Sparsity Allocation via Routing Entropy for Efficient MoEs

SPARE allocates expert-pruning budgets across layers using routing entropy. At the same pruning budget, Qwen3 eight-task average accuracy improves by 6.6 percentage points over uniform allocation.

Key insight: Separate expert selection from per-layer budget allocation. Holding the selector fixed isolates the value of entropy-based allocation and makes the method usable without retraining.

6. NormTune: Norm-Guided Parameter-Efficient Fine-Tuning for Reasoning-Intensive Tasks

NormTune strengthens layers whose weight-update norms indicate insufficient adaptation during parameter-efficient tuning. The paper reports a 24.24% average accuracy improvement for rank-8 LoRA across its reasoning benchmarks.

Key insight: Limited adaptation can reflect weak update magnitudes as well as parameter count. Per-layer norms provide a diagnostic for targeted adjustment instead of uniformly increasing adapter rank.

7. FlashNext-RL: A System Optimization Study for Long-Horizon Agentic RL of Qwen3.8-Flash-Next

FlashNext-RL combines host offload, gradient accumulation, and architecture-specific kernels for long-context RL training. Its optimized development configuration reaches 4,438 non-padding tokens/s/GPU, with a separate controlled ablation.

Key insight: Memory layout and model-specific operators can determine training feasibility. The development configurations also change context length, so use the controlled eight-layer study to assess individual contributions.

8. TrainBridge: Agentic NPU Training Optimization Guided by GPU Compilation Evidence

TrainBridge extracts optimization intent from mature GPU compilation and uses it to guide Ascend NPU program rewrites with iterative profiling. It averages 1.7× speedup across four training workloads.

Key insight: Transfer optimization intent across hardware, then validate the implementation locally. GPU traces can identify fusion opportunities without assuming the same kernel code will work on an NPU.

9. Looped Uniform Diffusion Language Models

Looped uniform diffusion language models reuse early layers while keeping the objective and sampler unchanged. On FineWeb-Edu, they match validation negative log-likelihood with up to 3.3× fewer training FLOPs.

Key insight: Early-layer reuse turns depth into an adjustable compute budget. Holding the objective and sampler fixed isolates this effect, while the training distribution over loop counts also affects inference cost.

10. Sparsity Should Be ALLOTted by Output: Training-Free Allocation of Block-Sparse Attention for Video Diffusion Transformers

ALLOT allocates block-sparse attention density using final-video error and measured latency, without retraining. With XAttention on HunyuanVideo, it reports an 11.8 dB PSNR gain at equal or shorter runtime.

Key insight: Allocate sparsity against final-output quality. Keeping selection strategies and kernels fixed isolates the contribution of layer-step allocation and offers a design pattern for compute budgeting.
