1. Controllable Generative Recommendation via Guided Token Refinement

XXJTLUUniversity of LiverpoolPolyU

ReGen replaces left-to-right item generation with parallel masked refinement. Coarse-code guidance changes diversity at inference time, while confidence-based repair and trie constraints preserve coherence and catalog validity. Its controlled Instruments configuration achieves 99.97% valid IDs.

Key insight: Control the generator before the candidate pool is fixed. Coarse semantic codes steer exploration; iterative repair restores fine details, and trie constraints keep results grounded in the catalog.

2. From Habits to Discovery: Deploying LLMs for Personalized Generative Recommendations at Spotify

Spotify

Spotify deploys GLIDE for podcast discovery. It generates Semantic IDs from recent listening context and injects long-term user embeddings as soft prompts. Online experiments involving millions of users increased new-show discovery by up to 14.3%.

Key insight: Give stable preferences and immediate intent separate input channels. User embeddings preserve long-term taste, recent history captures current context, and Semantic IDs ground generation in the catalog.

3. Where Do LLMs Learn to Recommend AI?

This study traces why language models disproportionately recommend AI-related options. It compares training stages and controlled prompt variants. Explicit AI recommendations rise from roughly 27% in released base models to 59% in their instruction-tuned counterparts.

Key insight: Audit topic exposure across training stages as well as prompts. Matched comparisons separate effects from data composition, preference objectives, and wording.

4. Transaction Foundation Models for Retrieval-Augmented Generation over Financial Transaction Data: A Comparative Evaluation with Text Embeddings

A controlled transaction-QA study compares a domain encoder with size-matched text embedders and an engineered-summary baseline. On synthetic data, the domain model reaches Recall@5 of 0.81 versus 0.25–0.39 for matched generic models.

Key insight: Input aggregation is part of the retrieval method. Separate its contribution from encoder quality by comparing matched inputs and an explicit engineered-summary baseline.

5. A Diagnostic Study of Faithfulness in Diffusion Language Models for Table-to-Text Generation

This table-to-text study evaluates reference similarity separately from source grounding. With more demonstrations, LLaDA raises BLEU from 11.3 to 22.0 while source-table entailment falls from 0.78 to 0.52.

Key insight: A better reference-matching score can hide weaker factual grounding. Track source support and entity errors separately when evaluating generated search summaries.

6. Don't Stop Long-Context Continual Pre-Training Too Early: An Empirical Scaling Law

An additive scaling law separates short-context pretraining from long-context continuation. Constant learning rates and averaging the latest four checkpoints stabilize monitoring. In billion-parameter experiments, gains continue through roughly 100 billion continuation tokens.

Key insight: Use a sustained training trajectory to assess long-context returns. Checkpoint averaging reduces observation noise and makes budget comparisons easier to interpret.

7. CSD: Common-Support Distillation for Cross-Tokenizer Knowledge Transfer

CSD aligns text chunks and constructs a common event space for teacher and student distributions, including residual probability mass. With an 8B base student, average accuracy improves by up to 4.2 points over the strongest evaluated baseline.

Key insight: Align prediction events before matching probabilities. Chain-rule probabilities provide shared support even when token boundaries differ across model families.

8. DiffResearch: Accelerating Deep Research with Diffusion Language Models

DiffResearch replaces an autoregressive backbone with a diffusion model while holding the agent scaffold, retrieval code, prompts, and evaluation fixed. Across 100 Deep Research Bench tasks, it runs roughly six times faster end to end.

Key insight: Dispatch retrieval from usable intermediate generation states. A fixed scaffold helps distinguish backbone speed from changes to search orchestration.

9. TraceForge: Distilling with Your Own Thinking

TraceForge synthesizes reasoning in the student model family’s style from teacher answers, then uses a critic to select traces. Holding 3,500 training questions and teacher answers fixed, it improves MBPP+ by 7.1 points over using the teacher’s own traces.

Key insight: The form of supervision affects transfer. Keeping answers fixed while changing trace generation isolates whether student-native reasoning is easier to learn.

10. Build more responsive apps with the Decisions API

OpenAI

The Decisions API returns probabilities, predefined choices, or rubric scores for bounded tasks. This pattern can support query routing and candidate screening. OpenAI reports up to 10 times faster decisions than the same Luna model through its general API.

Key insight: Treat bounded decisions as a distinct serving path. Explicit answer spaces simplify outputs and calibration; the reported speed figures are vendor and customer claims.
