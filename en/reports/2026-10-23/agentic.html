1. Let Agents Design How They Search: Automatic Interface Optimization for Agentic Search

KAISTKorea University

SearchWeaver optimizes the search interface itself: corpus artifacts, executable tools, and usage instructions. It uses execution traces and downstream rewards to revise all three. On BrowseComp-Plus, GPT-5.4-nano accuracy rises from 71.6% to 78.4%.

Key insight: Treat the tool interface as part of the retrieval system. For short-text community search, compare document organization, targeted-reading tools, and tool instructions on a fixed query set, measuring both answer quality and retrieval cost.

2. MAPS: Macro-Adaptive Parallel Reasoning for Regulating Search Momentum in Retrieval-Augmented Generation

Northeastern UniversityTsinghua

MAPS addresses repeated or drifting queries in iterative retrieval. It keeps accumulated knowledge, refines the reasoning state, and retrieves along complementary directions in parallel. Across six QA benchmarks with Qwen3-32B, its average score is 63.1 versus 57.3 for ParallelSearch.

Key insight: Separate accumulated facts from the reasoning history used to formulate the next query. In multi-hop community QA, track how much new evidence each parallel query contributes to determine whether the branches are complementary.

3. Signals and Queries: Token-Efficient Agentic Context Discovery

PParlant

Signals and Queries reduces the cost of deciding which behavioral policies apply to an agent turn. It generates positive and hard-negative examples offline and trains an independent logistic classifier for each policy. Embedding-based filtering removes at least 30% of policies while retaining high recall.

Key insight: Give each policy its own relevance boundary rather than relying on a global similarity threshold. A search agent can use this inexpensive stage to shortlist rules and tool descriptions before the language model evaluates the remaining items.

4. A Small Model Asks Better: Fine-Tuning Query Clarification for Retrieval-Augmented Generation

IBM

ClariEdge trains a small LoRA adapter to decide when a query needs clarification. It considers both dialogue context and retrieved documents, including hard negatives that look ambiguous but are already resolvable. The reported classification accuracy is 96.6%.

Key insight: Hard negatives help prevent unnecessary follow-up questions. Include queries whose wording seems ambiguous but whose context already resolves the issue. The same clarification check can run before retrieval and before answer generation.

4.36

5. Uni-Mem: Learning a Long-Horizon Agentic Memory Manager with Unified Online Policy Optimization

HuaweiSoutheast UniversitySun Yat-sen UniversityShandong Normal University

Uni-Mem jointly learns memory construction and retrieval under one policy. It alternates stage-specific optimization and assigns feedback to responsible memory events. On LoCoMo, it reaches an overall LLM-judge score of 88.80%.

Key insight: Memory writing and retrieval affect one another. Control variation in one stage while optimizing the other. For persistent community assistants, retain both update and retrieval traces so failures can be attributed to missing memories or failed recall.

6. How AI agents search

SSapienza University of RomeGeorgetown UniversityUniversity of GlasgowUniversity of Pisa

How AI agents search introduces ASQ, a dataset of agentic search traces collected under controlled agent and retrieval configurations. It examines query reformulation and workload variation. A single question can trigger up to 186 retrieval calls in this benchmark setting.

Key insight: Capacity planning needs task-level call counts and tail lengths, not just user-query volume. ASQ provides reusable traces for offline workload tests; its findings describe controlled experiments rather than production traffic.

4.01

7. BIRD-RL: Scaling Agentic Reinforcement Learning over Stateful Data-Centric Environments

HKUNUSCCUHK Shenzhen

BIRD-RL trains agents that interact with stateful databases using a four-stage curriculum. Its execution infrastructure safely reuses replicas while isolating each trajectory. The paper reports a 12.8-fold improvement in spatial RL efficiency.

Key insight: State isolation is part of training correctness. For database-backed search agents, use trajectory-scoped execution boundaries and account for restoration cost so writes from one rollout cannot contaminate another rollout’s reward.

8. Harness Scaling for Generalizable Agentic Reinforcement Learning

IIQuest ResearchBeihang UniversityRenmin University of China

Harness Scaling trains an agent across structured variations in tools, context management, and control flow. It selects configurations for balanced coverage. With Qwen3-4B and group-relative policy optimization, the reported average Pass@1 rises from 29.81 to 39.04.

Key insight: Execution-framework diversity is a training variable. Hold the model, tasks, and rollout budget fixed while varying tool organization, context handling, and control flow, then test transfer to an unseen framework.

9. Flint-interactive: A language for creating interactive data visualizations

MicrosoftUCLA

Flint-interactive lets agents specify semantic events and chart-update operators while a compiler handles rendering dependencies. The post describes three usage paths: chat integration, embedded applications, and custom interactions. It provides examples but no quantitative comparative evaluation.

Key insight: Expose user selections as structured events that an analysis agent can use in its next turn. Search-analysis interfaces can map chart selections into explicit filters and share state management across views.

3.15

10. Inside NVIDIA Sentry: Secure AI Agents at Runtime

NVIDIA

NVIDIA Sentry moves communication inspection and runtime observation into an independent BlueField-4 hardware trust domain. It combines identity, policy, and runtime signals to enforce access. NVIDIA claims millisecond-scale containment, without publishing a reproducible latency benchmark in this post.

Key insight: Keep enforcement and audit records outside the agent’s writable environment. Internal-search deployments can combine workload identity, requested resources, and runtime integrity when authorizing access. This implementation requires dedicated hardware.
