1. Progressive Learning from Content to Relevance to Personalization for CTR Prediction

Alibaba

FineSID progressively learns content representations, query relevance, and personalized CTR. Fine-grained visual and text IDs feed a shared interaction network that transfers in full from relevance pretraining to click prediction. A seven-day Taobao A/B test reports a 0.85% GMV gain.

Key insight: Transfer the whole interaction network from relevance training, including its normalization state. Comparing creatives that share an item ID provides a useful test of content understanding beyond ID memorization.

2. Generative Recommenders Forget the Long Tail: Restoring Memorization in Retrieval and Ranking

USTC

CAPE adds item co-occurrence memory to both candidate retrieval and ranking in generative recommenders. On Industrial & Scientific, tail HR@10 rises by 3.39 percentage points.

Key insight: Repair candidate admission and scoring together. A larger beam alone leaves tail items disadvantaged by the same likelihood score. Tail gains can coexist with small overall accuracy losses.

3. PerSPL: Personalized Semi-supervised Preference Learning

Duke UniversityGGeorge Washington University

PerSPL stabilizes personalized reward scores across prompts with pair-mean centering, then uses unlabeled responses for iterative self-training. It reaches 95.5% preference accuracy on unseen PersonalLLM users.

Key insight: Pairwise losses identify score differences but leave prompt-dependent offsets ambiguous. Centering those offsets makes response-level pseudo-labeling more usable.

4. Think Harder Where It Matters: Item-Level Adaptive Recursion for Sequential Recommendation

Renmin University of China

LoopRec learns how much encoder computation each historical item needs. A shared recursive block and binary stopping gates are trained through next-item prediction. On Software, it improves SASRec NDCG@20 by 5.68% relative.

Key insight: Make computation depth a learned variable for each historical item. Newer and rarer interactions often receive more recursion. Measure wall-clock latency separately from skipped computation.

5. RESEARCHHUB: A Personalized Literature Discovery System for Biomedical Preprints

ResearchHub combines a domain-adapted bi-encoder with controllable novelty, diversity reranking, and reading order. On its biomedical corpus, Recall@10 exceeds SPECTER2-Search by 12.4 percentage points.

Key insight: Separate relevance retrieval from exploration controls. This allows novelty and reading difficulty to change without retraining the retriever.

6. PreCoMem: Predictive Cognitive Memory for Self-Evolving Long-Term Dialogue Agents

PreCoMem maintains confidence-weighted user beliefs and routes new observations to maintenance, provisional storage, or correction. Its default configuration achieves 73.57% overall accuracy on LoCoMo.

Key insight: Buffer ambiguous observations as low-confidence hypotheses before revising established beliefs. Confidence can also guide retrieval and optional pruning.

7. SOAR: Social and Opinion-Aware Recommendations

AAristotle University of Thessaloniki

SOAR combines friendship links, review similarity, and sentiment for personalized point-of-interest recommendation. Its main configuration reports 42.22% Top-5 recall.

Key insight: Review semantics and friends’ opinions offer complementary signals. Hold the geographic candidate radius fixed when comparing ranking variants.

8. Retrieval Augmented Generation Compositionality

LASAGNA tests RAG component interactions across 450 configurations and eight benchmarks. Three retrieval techniques imply a 47% combined gain from isolated tests but achieve only 17% together.

Key insight: Evaluate combinations directly and separate retrieval quality from answer faithfulness. Isolated component gains can overlap or interfere.

9. 从 LOOP 到图探索 —— 算法模型的 AutoResearch 自进化系统架构演进之路

Meituan

Meituan describes a graph-based research automation system with explicit state, validated tools, and auditable experiment records. In one multi-objective project, all 12 prediction targets exceeded the human baseline.

Key insight: Enforce executable constraints in code and retain raw metrics and diffs. Review reusable lessons before promoting them into a shared knowledge base.

10. Memory-Centric Continual Learning for AI Agents

MCCL organizes agent memory along three axes and uses nested loops to update memory state and management policies. Its evaluation asks whether memory improves future actions.

Key insight: Judge memory by downstream behavior as well as recall. For personalization, test whether stored user information changes later decisions in useful ways.
