ECHO: Efficient Cascade with Homogeneous Operators for Distillation-Guided 100K-Sequence Modeling

Wenhao Li, Qinglin Jia, Chenghou Jin, Zihong Xian, Jiezhou Ji, Yanzhi Liu, Zezheng Wang, Ruiming Tang, Chaoyi Ma, Zhaojie Liu, Wenwu Ou
20 minread4.75score

ECHO (Kuaishou) is a three-stage funnel: 100K raw behaviors → a user-side learned top-K (candidate-agnostic, computed outside the request path and cached per user) keeps 10K → each candidate runs GSU-style retrieval for 100 → target attention aggregates them for the ranker. Because the user-side selector never sees the candidate, it is trained by knowledge distillation from a target-attention teacher that sees the full history and the candidate, plus a boundary loss that pushes "teacher-preferred but not in top-K" events over the cut. Retrieval and the final attention reuse the teacher's relevance parameters; that is the "Homogeneous Operators" in the title. By the paper's analytical estimate, sequence-branch FLOPs are ~160× lower than STCA; GAUC on KuaiRand Comment improves 1.520% relative to the strongest baseline, and a 7-day online A/B test shows +0.613% app usage time.

1. Architecture: funnel, sizes, online/offline split

Terms used throughout:

  • Target attention: attention with the candidate (target) as query and history events as keys/values, producing a candidate-specific interest vector (DIN is the classic example).
  • GSU / ESU: SIM's two-stage design. The General Search Unit retrieves a few candidate-relevant events from a long history with a light scorer; the Exact Search Unit runs full target attention over them.
  • Top-K: keep the K highest-scoring positions.
  • Knowledge distillation (KD): train a student to match a teacher's soft output distribution.

Two graphs train concurrently: the selector graph trains the teacher and DS and writes top-K records; the ranking graph reads them and trains TFR, aggregation and the ranker. Online requests only read the store. Offline experiments use 50K → 10K → 100. Retained items are original records (item ID, timestamp, side features), unlike latent-token compressors such as C-Former or SequenceO1, so each one stays individually matchable.

2. Title keywords mapped to mechanisms

  • Cascade: the 100K → 10K → 100 → attention budgets. 10K bounds interest coverage; 100 bounds per-candidate compute.
  • Homogeneous Operators: TWIN shares relevance parameters between GSU and ESU; ECHO extends this to the teacher, exporting its query/key relevance parameters Θ_rel to both TFR and the final target attention, so coarse retrieval and fine ranking use the same notion of relevance. DS has its own encoder and learns from the teacher only through distillation.
  • Distillation-Guided: DS is trained by KD plus the boundary loss (Section 3).
  • 100K-Sequence Modeling: online raw history up to 100K events.

3. Method: DS scoring, distillation, boundary loss

DS scoring (user features e, event encoding z_j, H_s heads), then top-K:

s^S_j = \frac{1}{H_s}\sum_{h=1}^{H_s}\langle W^S_{Q,h} e,\; W^S_{K,h} z^S_j\rangle,\qquad
\mathcal{I}^K = \mathrm{TopK}_{j\in[1,L]}\, s^S_j

Teacher scoring (query from context c and target v):

s^T_{v,j} = \frac{1}{H_t}\sum_{h=1}^{H_t}\langle W^T_{Q,h} f_T(c, x_v),\; W^T_{K,h} z^T_j\rangle

KD loss (temperature-T softmax over history positions; sg = stop-gradient):

\mathcal{L}_{KD} = -\frac{T^2}{|\mathcal{B}|}\sum_{b}\sum_{j=1}^{L_b}\mathrm{sg}[p^T_{b,j}]\,\log p^S_{b,j},\quad
p_{b,j} = \mathrm{softmax}_j(s_{b,j}/T)

Several training targets of the same user each give a teacher distribution; the student fits them with one candidate-independent score, learning an ordering useful for most of that user's candidates.

Boundary-targeted auxiliary loss. With a sharper teacher p̃ (T_m < T), mine the n highest-teacher-mass positions outside the student's top-K (j⁺, missed positives) and the n lowest inside it (j⁻), pair them by rank and apply a weighted pairwise softplus with margin δ:

\omega_{b,i} = \mathrm{sg}\big[\max(\tilde p^T_{b,j^+_{b,i}} - \tilde p^T_{b,j^-_{b,i}},\,0)\big]

\mathcal{L}_{aux} = \frac{\sum_b\sum_i \omega_{b,i}\,\mathrm{softplus}\big((s^S_{b,j^-_{b,i}} - s^S_{b,j^+_{b,i}} + \delta)/T_{rank}\big)}{\sum_b\sum_i \omega_{b,i} + \epsilon}

Mining and weights are detached, so no gradient passes through the discrete top-K.

Selector objective (L_pred updates only the teacher; L_KD and L_aux update only DS; the teacher trains live, it is not frozen). The ranking graph uses its own L_rank.

\mathcal{L}_{sel} = \alpha\,\mathcal{L}_{pred} + \beta\,\mathcal{L}_{KD} + \gamma\,\mathcal{L}_{aux}

4. Deployment optimizations

  1. Common-feature sharing: user-side features, including the long history, are loaded into GPU memory once per user group in a batch.
  2. Compact record encoding: 8 int64 fields = 64 B/event, 640 KB at K = 10K; fields are packed with fixed widths sized to their value ranges.
  3. Key-projection absorption: instead of projecting every history position (or caching projected keys), move W_K to the query side once per request:
\langle q W_Q,\; h W_K\rangle = \langle (q W_Q) W_K^{\top},\; h\rangle

5. Experiments

Baselines: DIN (target attention over the latest 100 events); SIM (GSU/ESU retrieval); TWIN (SIM with shared GSU/ESU relevance parameters); STCA (end-to-end stacked target-aware cross-attention, trained at ~2K, extrapolated to 10K); TWIN V2 (clusters the latest 50K events into ~10K units); SequenceO1 (a fixed 100-token sketch with cache reuse). GAUC = per-user AUC, weighted-averaged.

1.520% is relative: (0.6347 − 0.6252) / 0.6252; the absolute gap is 0.0095. ECHO is best on all 8 tasks. Versus TWIN (latest 10K), the gain grows from 0.045% for users with < 10K history to 1.279% for > 50K.

Selection quality vs. teacher: teacher top-100 recall 99.976% (recency 57.905%, random 49.443%); 98.509% of teacher relevance mass retained. Against the teacher's top-10K, budgets of 100 / 1K / 10K capture 70.84% / 91.65% / 99.38% of attention mass (recency: 0.43% / 5.14% / 55.93%). 46.08% of DS-selected events lie outside the latest 10K (75.09% for the longest-history group).

Cost: at L = 100K, K = 10K, per-target sequence-branch FLOPs are 14.26 vs 0.089 GFLOPs in training (160.3×) and 1.346 vs 0.0085 in inference (159.2×), an analytical estimate against STCA; end-to-end latency is not reported. On accuracy STCA reaches 0.6645 at 50K vs ECHO's 0.6630, so ECHO trades a small gap for ~1/160 of the sequence compute.

Ablation: training the student with prediction loss only (no L_KD, no L_aux) lowers GAUC; full ECHO is +0.272% / +0.925% / +2.371% / +0.317% on Click / Like / Comment / Long-view (Comment 0.6200 → 0.6347). Both losses are removed together, so the boundary loss alone is not isolated.

Online A/B: Kuaishou's largest short-video scenario (400M+ DAU), 5% traffic, 7 days, against a production system that already has TWIN retrieval and C-Former/SequenceO1-like compression: +0.613% total app usage time, +0.640% per user.

6. Limitations

The 100K → 10K cut is hard: events DS drops cannot be recovered by TFR, which the authors note may hurt extremely long-tail targets. DS updates with real-time training and store refresh, so new interests enter with a delay; retention quality for new users, interest shifts and new candidate types is not evaluated separately. The industrial data is not public.

7. Practical takeaways

  • Existing SIM/TWIN stacks: add a user-side learned top-K before the GSU and compare it with recency and random at the same storage budget; monitor teacher top-100 recall and attention-mass coverage offline.
  • Parameter reuse: an existing full-history or long-window target-attention model can serve as teacher and export query/key parameters to both GSU and ESU.
  • Key-projection absorption is usable on its own in any online target attention.
  • Refresh metrics: track how fast new events enter top-K, model/store version compatibility, and rollback.
