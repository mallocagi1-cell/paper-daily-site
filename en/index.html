Daily GenAI papers for search & recommendation engineers — scored, summarized, deep-read.

Every morning we screen several hundred new arXiv, conference and industry papers across five tracks — personalization, generative recommendation, retrieval, agentic search and ML infrastructure — score each on business relevance, novelty, practicality, evidence and timeliness, and write long-form deep dives with figures for the best ones.

1. ECHO: Efficient Cascade with Homogeneous Operators for Distillation-Guided 100K-Sequence Modeling

ECHO makes 100K-event histories affordable by retaining reusable original records before candidate-aware retrieval. A full-history teacher supervises selection, while retrieval and aggregation share relevance parameters. Kuaishou reports a 0.613% increase in app usage time in an online test.

Key insight: Compression can preserve individually addressable events rather than only latent interest vectors. Reusable user-level selection moves work out of the request path and leaves candidate-specific matching to a smaller evidence set.

4.55

2. KuaFu: Compressing Long User Behavior into Understanding at Billion Scale

KuaFu avoids repeatedly encoding the same content across users and profiling tasks. It caches compact item representations, assembles them chronologically and uses staged training to preserve evidence. Tencent reports a 1.37% overall GMV increase against a long-term holdout.

Key insight: Make items the unit of reuse. Encode shared content once, while preserving actions and sequence order on the user side. The cache then scales with item inventory, supporting more frequent multi-task profile refreshes.

1. Evolving Semantic Indexes for Generative Retrieval

An LLM evolves executable semantic-index programs while a tiny retriever screens them. With the target training recipe fixed, NQ320K Recall@100 rises from 85.82% to 90.57%.

Key insight: Index construction and collision handling are coupled. A cheap proxy can rank index changes well, yet become misleading when the search also changes the generator objective.

4.30

2. LightCRS: Lightweight Multi-Domain Conversational Recommendation System

LightCRS caches frozen multimodal product representations offline and uses a shared query-conditioned module to compare candidates online. HR@1 improves by 35.4% over the strongest baseline.

Key insight: Separate reusable product evidence from dialogue-dependent matching. Query-conditioned fusion enables a compact shared model to serve multiple domains.

1. UIBK-Embedding: Effective Text Retrieval by Unifying Dense and Late-Interaction Retrieval

One encoder combines global semantics with token matching. Tagged extra vectors make standard MaxSim equal token-level matching plus a weighted dense score, so existing late-interaction indexes remain usable. BEIR nDCG@10 reaches 59.79.

Key insight: A hybrid representation can remove the need for separate encoders, indexes and score fusion. Distilling the final combined score also aligns training with the score actually served.

4.45

2. FLINT: Fixed-budget Late Interaction

FLINT pools both queries and documents into a fixed number of vectors. This preserves late interaction while bounding storage and matching work. On long-query corpora, end-to-end retrieval is 1.5–2.8 times faster than ConstBERT.

Key insight: Budget vectors on both sides of retrieval. Compressing documents alone reduces storage, but long queries still drive many comparisons; symmetric pooling bounds both costs.

4.61

1. FALCA: Falsification-Aware Reinforcement Learning with Hierarchical Credit Assignment for Long-Horizon Deep Search Agents

Deep search can reinforce an early mistaken hypothesis. FALCA separates answer proposals from independent counterevidence searches and trains research-state revision with hierarchical credit. Its 4B model reaches 56.0% accuracy on BrowseComp.

Key insight: Give counterevidence checking its own context. A useful falsification report names conflicting evidence and unmet constraints, giving the next search a specific gap to resolve.

4.45

2. DeclineCraft: A RAG Abstention Benchmark for Jointly Measuring Combined Retrieval and Parametric Knowledge

DeclineCraft tests whether models abstain when neither retrieved evidence nor internal knowledge supports an answer. Version-specific Minecraft questions allow controlled knowledge cutoffs. Iterative retrieval reduces correct abstention in 30 of 40 configurations.

Key insight: Evaluate retrieval depth separately from reliability. Track both accuracy on answerable questions and abstention when evidence is missing; a willingness to answer is not evidence coverage.

1. E8-QAT: Efficient 2-Bit Quantization-Aware Training with Implicit Lattice Codebooks

Grouped weight quantization avoids an explicit codebook search by projecting onto a structured lattice. At each format’s largest feasible batch, decoding reaches 1.97 times BF16 throughput. This comparison includes the batch-size benefit of lower memory use.

Key insight: Treat storage format and feasible batch size as coupled decisions. Arithmetic lattice projection reduces codebook search overhead, while memory savings create additional serving capacity.

4.40

2. Large Flow Language Models

Lafa adapts pretrained autoregressive models into blockwise continuous-flow language models. A single model proposes flow-based drafts and verifies them autoregressively, reaching 2.54 times autoregressive throughput at comparable quality.

Key insight: Drafting and verification can share a model. Retaining autoregressive capability creates a verification path for parallel flow proposals without a separately maintained drafter.
