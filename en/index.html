LEAD STORY · Alibaba

1. Progressive Learning from Content to Relevance to Personalization for CTR Prediction

Alibaba

FineSID progressively learns content representations, query relevance, and personalized CTR. Fine-grained visual and text IDs feed a shared interaction network that transfers in full from relevance pretraining to click prediction. A seven-day Taobao A/B test reports a 0.85% GMV gain.

Key insight: Transfer the whole interaction network from relevance training, including its normalization state. Comparing creatives that share an item ID provides a useful test of content understanding beyond ID memorization.

2. Generative Recommenders Forget the Long Tail: Restoring Memorization in Retrieval and Ranking

USTC

CAPE adds item co-occurrence memory to both candidate retrieval and ranking in generative recommenders. On Industrial & Scientific, tail HR@10 rises by 3.39 percentage points.

Key insight: Repair candidate admission and scoring together. A larger beam alone leaves tail items disadvantaged by the same likelihood score. Tail gains can coexist with small overall accuracy losses.

LEAD STORY · XXJTLU / University of Liverpool / PolyU

1. Controllable Generative Recommendation via Guided Token Refinement

XXJTLUUniversity of LiverpoolPolyU

ReGen replaces left-to-right item generation with parallel masked refinement. Coarse-code guidance changes diversity at inference time, while confidence-based repair and trie constraints preserve coherence and catalog validity. Its controlled Instruments configuration achieves 99.97% valid IDs.

Key insight: Control the generator before the candidate pool is fixed. Coarse semantic codes steer exploration; iterative repair restores fine details, and trie constraints keep results grounded in the catalog.

4.30

2. From Habits to Discovery: Deploying LLMs for Personalized Generative Recommendations at Spotify

Spotify

Spotify deploys GLIDE for podcast discovery. It generates Semantic IDs from recent listening context and injects long-term user embeddings as soft prompts. Online experiments involving millions of users increased new-show discovery by up to 14.3%.

Key insight: Give stable preferences and immediate intent separate input channels. User embeddings preserve long-term taste, recent history captures current context, and Semantic IDs ground generation in the catalog.

LEAD STORY · Perplexity

1. pplx-embed-v2-late Technical Report

Perplexity

Large late-interaction models improve matching but make query encoding costly. Perplexity distills two model sizes into a shared embedding space, allowing a large document encoder and a small query encoder. The 9B model reaches 74.8% Recall@1000 on its Q2D-Web Combined evaluation.

Key insight: Shared-space distillation separates document indexing quality from query latency. Compare symmetric and asymmetric encoders on short-text queries, including the storage cost of document token vectors.

2. Directional Posterior Feedback Fusion for Query Reformulation in Dense Retrieval

TsinghuaRenmin University

Short queries are vulnerable to noisy relevance feedback. DIFF treats feedback as confidence-weighted directions and bounds the query update while keeping the retriever frozen. With HyDE-generated feedback, BGE average nDCG@10 rises from 0.5492 to 0.5717.

Key insight: Directional constraints preserve complementary feedback without forcing each item to define a complete target embedding. The frozen-retriever design offers a compact query-vector intervention; the update-angle bound controls drift.

LEAD STORY · KAIST / Korea University

1. Let Agents Design How They Search: Automatic Interface Optimization for Agentic Search

KAISTKorea University

SearchWeaver optimizes the search interface itself: corpus artifacts, executable tools, and usage instructions. It uses execution traces and downstream rewards to revise all three. On BrowseComp-Plus, GPT-5.4-nano accuracy rises from 71.6% to 78.4%.

Key insight: Treat the tool interface as part of the retrieval system. For short-text community search, compare document organization, targeted-reading tools, and tool instructions on a fixed query set, measuring both answer quality and retrieval cost.

2. MAPS: Macro-Adaptive Parallel Reasoning for Regulating Search Momentum in Retrieval-Augmented Generation

Northeastern UniversityTsinghua

MAPS addresses repeated or drifting queries in iterative retrieval. It keeps accumulated knowledge, refines the reasoning state, and retrieves along complementary directions in parallel. Across six QA benchmarks with Qwen3-32B, its average score is 63.1 versus 57.3 for ParallelSearch.

Key insight: Separate accumulated facts from the reasoning history used to formulate the next query. In multi-hop community QA, track how much new evidence each parallel query contributes to determine whether the branches are complementary.

1. Is 2:4 Sparsity Still Worth It? Semi-Structured Sparsity versus Quantization in LLM Inference

The study compares lower-bit quantization with structured sparsity at matched storage cost, including metadata and online processing. On H100, a retrained sparse FP8 model delivers 27% higher prefill throughput than dense FP8.

Key insight: Choose compression steps against the hardware precision floor. Sparsity becomes useful after lower precision is exhausted; recovering perplexity does not establish that reasoning quality has recovered.

2. SGLang Low-Latency Mode: Kernels and Runtime

SSGLangAMDNVIDIA

SGLang integrates low-latency decode kernels through a plugin interface with compatibility checks and existing graph execution. In AgentX trace replay on four MI355X GPUs, P90 per-user token generation speed rises by 45–56%.

Key insight: Kernel fusion and cross-GPU communication need joint optimization. Explicit contracts for weight binding, cache writes, and fallback let specialized kernels operate within a serving runtime.
