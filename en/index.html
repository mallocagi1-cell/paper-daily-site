1. LSNR: Learned Sparse News Recommendations with Attentive User Modeling

Encode articles separately, then learn which ones matter. LSNR combines weighted sparse article vectors with a user-level semantic expansion, improving MIND NDCG@10 by about 11% over STAR.

Key insight: Article boundaries matter beyond context length. A lexical path preserves evidence from individual clicks, while a semantic path adds aggregate interests. Gains with a single history article show that truncation is only part of the problem.

4.35

2. Predictable Scaling: Efficient Model Exploration via Scaling-Law Prediction

Predictable Scaling evaluates ranking-model changes with reduced-scale proxies and estimates their full-scale effects using historical learning curves. Training compute falls by 88% and 79% on two industrial ranking models.

Key insight: A useful proxy preserves which changes are better, not merely a small average prediction error. Scaling must be chosen for each architecture: reducing embedding width alone can scramble the ordering of candidate changes.

1. Chinese Decision: A Family of Language Models for Single-Pass Probabilistic Decision-Making

Some applications need candidate probabilities rather than generated explanations. Chinese Decision normalizes candidate-letter logits from a single forward pass for Boolean, categorical, and ordinal decisions. Its completed 0.8B model reaches 72.24% general-domain accuracy on CJ-Bench.

Key insight: Expose candidate probabilities directly when a task only needs a finite decision. This avoids autoregressive answer generation, while calibration and individual prediction changes still require their own evaluation.

3.60

2. The Thin Orchestrator: How We Made Our AI Agents More Reliable by Giving the Router Less to Do

A single agent mixed up rules when onboarding data columns across recommendation pipelines. Meta moved routing and reliability checks into a thin orchestrator and isolated domain reasoning in specialist agents. Configuration preparation fell from three to four days manually to under an hour.

Key insight: Keep workflow sequencing deterministic and load domain knowledge only in the relevant specialist. Recombining existing workflows can add capabilities without expanding the central agent’s context.

4.30

1. EKLAV: Elicited Key CoT Learning via Answer only superVision

EKLAV provides teacher reasoning as training context while supervising only answers. It wins 41 of 48 model-domain comparisons on BRIGHT reranking.

Key insight: Reasoning traces need not be imitation targets. Changing where supervision applies can reuse a fixed teacher corpus with less training and inference work.

4.15

2. Jev-as-a-Judge for Brazilian Portuguese Information Retrieval: Relevance Assessment and Reranking

Jev supplies relevance labels and reranks Portuguese search results. On Quati, nDCG@10 rises from 0.3329 to 0.6331 over BM25.

Key insight: Label agreement and agreement on system rankings measure different things. An assessor can preserve comparative evaluation even when individual judgments differ.

4.51

1. Grounded Credit Assignment in Reinforcement Learning for Multi-Turn Search Agents

A search agent can answer correctly without using retrieved evidence. Grounded Credit Assignment separates credit for finding evidence from credit for answering. On the larger evaluated model, it improves average exact match over Search-R1 by 6.3 percentage points.

Key insight: Reward evidence acquisition separately from answer correctness. Otherwise, a lucky answer from memory credits the entire retrieval trace and can improve accuracy while weakening grounding. The proposed correction uses verifiable sub-outcomes without an extra reward model.

4.30

2. MuninAI: A Self-Hosted Agentic Framework for Independent Research Groups

Munin indexes a local literature corpus and citation graph, then equips an open-weight model with reading, search, and computation tools. On paired literature questions, accuracy rises from 38.7% without the harness to 87.4% with it.

Key insight: A fixed retrieve-then-answer pipeline underperforms the unaided model on every tested backbone. The useful unit is the whole reading harness, including citation tracing and abstention when evidence is missing. The released evaluation suite lets adopters test their own corpus.

4.35

1. Acceptance Is Not Speed: Length Inflation in Training-Free Lossy Speculative Decoding

Relaxed speculative verification can inflate completions enough to erase apparent decoding gains. Across matched prompts, the study tracks completion length, verifier rounds, runtime and accuracy. At the most relaxed settings, accepted tokens per round rise 1.34× while completions grow 1.54×.

Key insight: Acceptance length is an incomplete speed metric when verification changes the output distribution. Track request completion time, output length and answer accuracy together; longer reasoning can consume the budget needed to return an answer.

4.10

2. Where Prefill Expert Reduction Hurts MoE Models: A Few Prompt Tokens Carry Most of the Short-Answer F1 Loss

Reducing experts during prompt processing saves compute, but a few prompt positions account for much of the quality loss. Token-level interventions favor preserving full expert computation near task interfaces over random document positions. Time to first token falls about 14% on long prompts.

Key insight: Allocate expert compute by prompt position rather than uniformly. Instructions and answer boundaries deserve attention, but the sensitive positions also occurred at prompt ends, so these experiments do not distinguish interface-aware rules from simply preserving both ends.
