Daily GenAI papers for search & recommendation engineers — scored, summarized, deep-read.

Every morning we screen several hundred new arXiv, conference and industry papers across five tracks — personalization, generative recommendation, retrieval, agentic search and ML infrastructure — score each on business relevance, novelty, practicality, evidence and timeliness, and write long-form deep dives with figures for the best ones.

1. FLMNet: Self-Ensemble Distillation from Masks to Seeds for Single-Tower CTR Prediction

CTR self-distillation can be replaced with a computable disagreement penalty. FLMNet keeps gates on clean inputs and distills independently trained towers into one serving model. The distilled model reaches 0.8169 AUC on Criteo.

Key insight: Separate mask disagreement from seed disagreement: regularize the former within a run and distill the latter across runs. The moment formulas require gates that do not read masked intermediate activations.

4.35

2. DuoLM: Fast and Effective Personalized Recommendation with Language Models

DuoLM precomputes one vector per item and uses a personalized ranker with user history and feedback. Shared history computation and a specialized runtime reduce online work. Throughput reaches about 26,400 candidate scores per second on one H100.

Key insight: Train reusable content representations and personalized judgments jointly. Compression pays off in end-to-end serving only when repeated history prefill, input transmission, and scheduling are reduced too.

4.90

1. AGR: Agentic Generative Retrieval with Tool-Augmented Search

Generative retrieval need not encode every available feature up front. AGR requests intent, location, or behavioral evidence while decoding item identifiers, then resumes generation with a compact observation. A Kuaishou online experiment reports a 0.205% increase in requests with strongly relevant top-four results.

Key insight: Feature value depends on the current identifier prefix. Learning when to request evidence can reduce redundant history encoding, although tool use still costs more than the feature-free baseline.

4.20

2. Learning Complementary Agent Groups via Task Hypergraphs for Next-POI Recommendation with Missing Modalities

POI recommendation often lacks text or images. CATH selects complementary agents for each request, shares candidate-specific evidence, and adjusts a fixed base ranking. Across three naturally incomplete datasets, relative NDCG@20 gains over the strongest evaluated prior baseline range from 8.4% to 9.1%.

Key insight: Agent complementarity matters alongside agent count. Jointly optimizing group selection, ranking quality, and execution cost directs work toward candidates with missing evidence.

1. Optimal Fusion Weights Form Intervals, Not Points: A Latency-Aware Study of Query-Adaptive WRRF

Adaptive fusion need not predict one exact weight. Across 128 configurations, 74 significantly outperform standard RRF after multiple-testing correction.

Key insight: Treat optimal weights as sets rather than arbitrary point targets, and include predictor latency in deployment decisions.

4.25

2. Preference Is Not Position: Evaluating Reranking on NevIR in Fixed Hybrid Candidate Pools

Correct pairwise preference does not guarantee a useful list position. Bounded Qwen3 reranking reaches preferred-passage MRR of 0.7509 in fixed hybrid pools.

Key insight: Evaluate pair preference and full-list position separately; optimizing one can degrade the other.

4.70

1. OpenSaC: A Python Library for Search as Code in Deep Research Agents

OpenSaC lets research agents write programs that combine search, reading, reranking, and local processing, returning selected evidence to the model. On BrowseComp, it cuts model-token use by 37.8%.

Key insight: Process intermediate evidence in code and preserve source links for reuse. The library reduces repeated model reading, but requires an execution environment. WideSearch row F1 falls slightly, so efficiency gains do not guarantee better answers.

4.53

2. EG-GRPO: Evidence-Guided Step-level Credit Assignment for Deep Search Agents

EG-GRPO rewards the first search step that finds support for a required claim, then compares actions from similar evidence states. The 4B agent reaches 45.9% accuracy on GAIA.

Key insight: Reward newly acquired evidence rather than repeated citations. Conditioning comparisons on what an agent already knows reduces unfair comparisons between early and nearly finished trajectories; fallback grouping handles sparse state matches.

4.50

1. RemoteANN: A Native Vector Search Engine for Cloud Object Storage

RemoteANN co-designs vector indexing and query execution for cloud object storage. Quantized inverted lists, reordered data, merged range reads and local SSD caching reduce remote I/O. At matched target recall, the authors report up to 5.9× higher throughput than representative baselines.

Key insight: The useful optimization target is remote requests per query. Data locality makes request merging and caching effective; faster distance computation alone cannot remove object-store latency.

4.45

2. TokenGate: Adapting LLMs for Fast and Memory-Efficient Prefill with Learned Token Pruning

TokenGate trains an existing model to skip less useful tokens in later layers. Token-gated attention supplies a learning signal for token selection. Across the tested tasks, the authors report up to 11.3× faster time to first token without measured accuracy loss.

Key insight: Token selection can be learned during lightweight adaptation instead of imposed as a fixed heuristic. This targets prefill latency and memory, with an adaptation step required before deployment.
