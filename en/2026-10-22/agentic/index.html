1. FALCA: Falsification-Aware Reinforcement Learning with Hierarchical Credit Assignment for Long-Horizon Deep Search Agents

Deep search can reinforce an early mistaken hypothesis. FALCA separates answer proposals from independent counterevidence searches and trains research-state revision with hierarchical credit. Its 4B model reaches 56.0% accuracy on BrowseComp.

Key insight: Give counterevidence checking its own context. A useful falsification report names conflicting evidence and unmet constraints, giving the next search a specific gap to resolve.

2. DeclineCraft: A RAG Abstention Benchmark for Jointly Measuring Combined Retrieval and Parametric Knowledge

DeclineCraft tests whether models abstain when neither retrieved evidence nor internal knowledge supports an answer. Version-specific Minecraft questions allow controlled knowledge cutoffs. Iterative retrieval reduces correct abstention in 30 of 40 configurations.

Key insight: Evaluate retrieval depth separately from reliability. Track both accuracy on answerable questions and abstention when evidence is missing; a willingness to answer is not evidence coverage.

3. Do Conversational Agents Need Explicit Memory? A Controlled Comparison with Raw-History Retrieval

A controlled comparison asks whether explicitly constructed memories outperform retrieval over raw conversation history. Across six systems and two benchmarks, gains are localized rather than consistent. Oracle retrieval separates construction losses from access failures.

Key insight: Diagnose preservation and access separately. Oracle retrieval can reveal whether to improve memory construction or retrieval, before paying for more elaborate persistent representations.

4. Outcome-Anchored Credit Reallocation for Agentic Knowledge Graph Question Answering

OACR estimates how adjacent knowledge-graph search states change the expected outcome, then reweights token updates without reversing the trajectory advantage. With Qwen2.5-7B, it improves CWQ F1 by 4.6 points over outcome-only GRPO.

Key insight: Use local progress to change update magnitude while leaving final success in charge of its direction. The state evaluator runs only during training, avoiding an extra inference-time judge.

5. COMPASS: Routing via Capability-Oriented Model Profiling with Adaptive Search, Selection, and Tool Use

COMPASS chooses models by consulting performance and cost records through tools, rather than training a dedicated router. It can inspect candidate answers before selection and update its choices as records change. LLMRouterBench accuracy reaches 69.85%.

Key insight: Make model capabilities queryable records. Count the router and candidate inspections in end-to-end cost when assessing whether this approach saves money.

6. Evolving Self-tuning Benchmarks for Long-Horizon Tool Use

TURTLE evolves tool-use evaluations with a task proposer, solver, and feedback generator. Solver traces guide tasks toward a difficult but solvable range. On AppWorld, the share of hard tasks increases by 165%.

Key insight: Use execution traces to calibrate task difficulty continuously. Failure locations give a task generator more useful guidance than a single success bit.

7. FinHopper: A Progressive Multi-Hop Benchmark for Complex Financial Agents with Step-wise Evaluation

EMNLP 2026

FinHopper evaluates financial search chains whose intermediate entities, dates, and indicators determine later queries. Gold intermediate answers expose where a chain breaks. The study compares 20 model-agent configurations.

Key insight: Use typed intermediate checkpoints. Separate a wrong inherited constraint from missing evidence or a final synthesis error, rather than collapsing every failure into an incorrect final answer.

8. Evolving Agent Interfaces

Agent S4 evolves tool interfaces and usage knowledge from execution traces, then selects repositories on unseen validation tasks. With the same model, its OSWorld V2 binary score is 3.8 times the fixed-interface baseline.

Key insight: Treat interfaces as an optimization target. Select interface versions on independent tasks and record the underlying model, so improvements remain attributable and reusable.

9. Harness Self-Evolution for Long-Horizon Terminal Agents

RiseHarness compares successful and failed runs of the same task, using internal execution traces to revise shared harness mechanisms without changing model weights. DeepSeek-V4-Flash gains 7.25 percentage points in mean TBH success.

Key insight: Attach executable evidence to completion decisions. Record command dispatch, observations, and completion checks separately to locate reliability failures in the harness.

10. Terminal X matches senior investor judgment 88.6% with GPT-6.1

Terminal XOpenAI

Terminal X encodes firm-specific investment standards and uses a separate evaluation agent to check research outputs. The vendor case study reports 88.6% agreement with senior investor judgment.

Key insight: Make institutional standards explicit and inspectable. This customer case does not publish a complete test set; its transferable contribution is the separation of research generation and firm-specific evaluation.
