Query Expansion Is More Than Generation: Improving Dense Retrieval through Better Integration

论文指出，LLM 生成的扩展词让冻结稠密检索器退化，问题常不在生成文本本身，而在融合方式。AnchorQE 分别编码原查询与扩展，再依据小规模无标注测试流在线估计插值权重；只有当扩展既能带来强检索信号、又与原查询证据一致时才提高信任。

Retrieve, Match, Escalate: Accurate and Scalable Product Linking with VLM-Distilled Cross-Encoders and Agentic VLMs

Amazon

Less can be More: Relieving RAG Bottlenecks via Evidence Frontloading and Pressure-Adaptive Budgeting

论文发现 RAG 的瓶颈会随查询并发和重排预算在上游重排与下游生成之间迁移；盲目压缩重排候选虽能提速，却可能丢失关键证据。PACE 无需训练，先把高价值证据前置，再根据系统压力动态调整预算，以较小候选集维持证据覆盖。

INSIGHT这项工作把生成式搜索优化从单模型指标提升到端到端资源调度：线上应同时观测重排队列、生成吞吐与证据召回，再动态决定每个请求的候选预算。对高并发 UGC 搜索，可优先保障多样证据覆盖，而不是固定 top-K 后统一交给大模型。

Weibin Cai, Reza Zafarani

STORM: Stepwise Token Optimization with Reward-Guided Beam Search

STORM 面向 BM25 的词汇失配，用检索奖励逐 token 训练查询扩展器。生成过程中每一步都在真实倒排索引上评价候选扩展并剪掉低奖励路径，把原本延迟到整句结束的序列级反馈转化为细粒度监督，从而减少流畅但无效甚至有害的扩展词。

INSIGHT它展示了生成式检索的实用结合点：保留稳定、透明且无需重建的 BM25 索引，只学习能够直接提升检索指标的扩展策略。对快速变化的社区语料，可把 nDCG、点击或长尾召回作为奖励，并审计每个扩展词的边际收益，降低黑盒改写风险。

RetrievalRouter: Joint Modality and Architecture Selection for Document Retrieval

针对文本/多模态、稠密/晚交互检索之间的精度与延迟冲突，RetrievalRouter 仅根据查询文本选择最合适的检索管线。作者在金融与科学文档基准上发现不存在始终占优的静态方案，并用单一可调参数给出从低成本到高精度的完整折中曲线。

INSIGHT生成式搜索的前置检索无需所有请求都走最昂贵模型。可先训练轻量路由器识别需要视觉理解、细粒度 token 交互或普通稠密召回的查询，再把成本集中到困难样本；对 UGC 搜索，这一思路也能用于短文本、图文帖子和长内容之间的动态路由。

E2Rank: Unifying Text Embedding and Listwise Reranking for Effective and Efficient Search

📖 深度解读 · 14 分钟 →

LLM listwise 重排把查询和几十篇候选一起塞进提示词、让模型输出排好序的编号，效果最好，但要逐个 token 生成，一个查询动辄几秒到十几秒；embedding 召回很快，排序精度却不够。E2Rank 把查询和前 20 篇候选拼成的提示词整体编码成一个新的查询向量，再和预先算好的文档向量算余弦来重排，不需要任何生成。文档向量召回时算好直接复用，只有查询向量吸收候选信息。BEIR 上 E2Rank-8B 和同底座生成式重排相当或略好，TREC-COVID 上每个查询的重排延迟从 16.93 秒降到 3.40 秒。

Qi Liu, Yanzhao Zhang, Mingxin Li, Dingkun Long, Pengjun Xie, Jiaxin Mao

The "Curse of Knowledge" in LLM Query Simulation: Concept Provenance for Tracing Answer-Side Intrusion

论文研究 LLM 模拟搜索查询时偷带答案侧知识的问题，并提出概念溯源框架，将查询概念划分为背景支持、人类核心、人类长尾和候选答案侧四类。在 100 个 UQV100 主题、8 个 LLM、5 种提示条件共 77,004 条查询上，答案侧概念占非通用概念 7.40%，影响 97 个主题。

INSIGHT用生成查询扩充搜索评测或训练数据时，仅检查多样性和检索效果会掩盖信息泄漏。实践中应保留“用户在搜索前能否知道该概念”的边界标签，并把答案侧侵入率作为质量门槛；否则离线指标会因模型提前看到答案语义而虚高，误导 UGC 召回优化。

Chenglong Ma, Xinye Wanyan, Danula Hettiachchi, Ziqi Xu, Jeffrey Chan

Netflix Artwork Personalization via LLM Post-training

Netflix

Netflix 将个性化从“推荐哪个标题”推进到“为同一标题展示哪张海报”：利用 LLM 后训练理解用户偏好以及作品中不同主题、情绪和视觉侧重，再匹配最可能吸引该用户的 artwork。该任务直接建模同一内容的多种展示语义，论文以新版形式在本次窗口重新发布。

INSIGHT生成式推荐可以不替换现有召回排序，而先切入展示层个性化：保持内容候选不变，利用语言模型生成或判断用户偏好与素材语义的对应关系。对社区搜索可迁移为封面、摘要和结果卡片选择，但需通过离线偏好一致性和线上 CTR 联合约束，避免只优化视觉吸引力。

09 4.10

Rank-Deviation Quality: A Distance-Aware Metric for Multi-Answer Retrieval and Ranking Evaluation

RDQ 为单答案到多答案查询提供统一的排序评价：命中参考列表的结果按输出位置权重计分，再乘以与参考次序的偏差惩罚，参考集外结果记零。参数可在“先召回有效答案”和“严格匹配参考顺序”之间调节，并支持列表、轮播等不同展示位置。

INSIGHT生成式推荐常有多个同样合理的答案，单一 gold 或严格相关等级容易惩罚有效多样性。RDQ 只需成对或列表式序标注，适合评估对话推荐、结果卡片和多答案搜索；上线前应依据界面曝光曲线校准位置权重，避免评价指标与真实用户可见性脱节。

Xiaokun Zhou, Alessandro Moschitti, Danielle Class

ReliableRAG: Combating Misinformation in Retrieval-Augmented Generation via Reliability-Guided Reasoning Chains

ReliableRAG 针对新闻和社交媒体中的欺骗性错误信息，显式评估检索片段的细粒度可靠性，并用可靠性引导多跳推理链。其目标是解决语义上高度相关、事实却错误的证据：这类片段可能在任一步误导后续推理，传统相关性排序或隐式对齐难以及时识别。

INSIGHTUGC 搜索接入生成答案后，相关性与可信度必须分开建模。可在重排之后增加来源、时间、交叉证据和陈述一致性信号，让生成链优先消费高可靠片段，并保留冲突证据；但该方案引入额外推理开销，落地时应先用于高风险、多跳请求。
