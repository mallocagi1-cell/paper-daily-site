TransRetrieval: Scaling Up Transformer-Based Retrieval for Industrial Recommendation

召回阶段一直很难像排序那样靠加大模型变好，因为召回要在几千万广告里几十毫秒内选出几千个，每个被访问的候选都要过一遍模型，算力被候选数放大。阿里展示广告的 TransRetrieval 把召回打分模型换成 Transformer，先把多值特征从求和改成加权平均来拉齐尺度，再把广告侧所有特征压成一个 token，省下的算力投到更宽更深的模型上。候选侧压成一个 token，算力花在模型本身。随着每个候选的计算量增加，Recall@2000 从 0.464 稳步升到 0.657。线上一个月平台收入提升 2.53%，延迟不变。

An Event is Worth One Token: Event Tokenization for Industrial-scale LLM Recommendation

📖 深度解读 · 9 分钟 →

论文指出现有 LLM 推荐把一次交互压成文本、语义 ID 或少量类别特征，会持续丢失用户、物品、上下文与结果信号。AMBER 将完整时间快照压缩成一个可缓存的 Event Token，把“快照分辨率”变成新的扩展维度；工业排序和召回实验显示其改善计算—质量帕累托前沿，并可作为历史特征迁移到优化后的非 LLM 排序器。

INSIGHT值得借鉴的不是简单增加序列长度，而是提高每个行为事件携带的信息密度，并通过离线预计算隔离线上成本。社区推荐可把点击时的 query、内容语义、位置、停留与互动结果联合编码为事件 token，再让召回和排序共享，减少多套特征管线之间的信息损耗。

DCEO: Direct Causal Effect Optimization for Long-Term User Value Modeling in E-commerce Search

Alibaba

DCEO 针对用户级长期价值与请求内物品排序的粒度错位，以相对因果效应衡量代理指标和最终目标的对齐程度。其 actor 根据上下文动态生成点击、加购、购买和交易额等目标的融合权重，critic 估计长期结果；在大型电商搜索系统的 41 天线上 A/B 测试中，相比传统 GMV 代理使 GMV 提升 0.36%。

INSIGHT多目标排序不应长期依赖全站统一的手调权重，关键是学习“什么用户、什么上下文下哪类反馈更能预测长期价值”。社区搜索可将点击、停留、收藏、负反馈等先聚合为用户级代理指标，再用因果对齐训练动态权重，避免单纯追逐 CTR 带来的标题党和短期化。

SWIM: Step-Wise Integrated Measure for Session-supervised List Evaluation in Generative Re-ranking

SWIM 解决生成式重排评估器把列表内物品独立打分、忽视跨列表连续消费的问题，将会话建模为有限时域的前缀生存过程。模型把当前列表的贡献分解为递归生存分布与到达位置后的条件收益，并用因果掩码 Transformer 并行估计继续消费概率和效用；论文在列表重排实验中报告整体互动指标显著优于基线。

INSIGHT短视频和社区信息流的真实消费边界是 session，而不是服务端切出的单个列表，因此重排评价应显式建模继续浏览概率、上下文依赖与重复内容的边际效用。该设计可作为生成器之外的轻量 evaluator，在严格延迟预算内比较多个候选列表，而无需把所有目标退化为逐点分数相加。

MOTIF: Motivation-guided Topology Inference for Cold-start Multimodal Recommendation

MOTIF 同时处理冷启动交互稀疏、冷物品拓扑孤立和相似度图语义漂移，组合动机语义推理、知识增强图重建、加权图对比学习及语义—结构对齐。LLM 只在线下推断用户动机，不把生成文本注入线上预测；在三个多模态基准上均超过图、多模态、冷启动及 LLM 增强基线，最高相对提升 6.07%。

INSIGHT冷启动的核心不是为新内容生成更长描述，而是用意图语义重建可迁移的物品关系，再让结构学习吸收这些关系。对 UGC 新帖推荐，可离线提炼发布动机与消费动机，构建受知识约束的邻接边，并把 LLM 隔离在线上链路之外，以控制延迟和生成噪声。

CRAMER: Control via Request-Aware Masking for Editing Recommenders

CRAMER 让用户用自然语言即时修改序列推荐器行为，避免重训整个骨干或在线调用大模型。它把请求视为控制信号，通过 request-aware mask 调制冻结模型参数；在多个大规模基准上超过四种请求感知基线，并保持很小的额外开销，同时展示了跨域适配与可控性。

INSIGHT对“少看某类内容”“最近只想看某主题”等即时偏好，长期画像更新过慢，而在线 LLM 重排成本又高。可将请求编码为稀疏参数掩码，直接作用于冻结的序列模型，使临时意图成为可撤销的控制层；上线时应重点监控请求解析错误和长期画像之间的冲突。

D3ER: Supporting Multi-Modal Recommendation via Disentangle and Distillation-based Dynamic Ensemble

D3ER 针对多模态推荐中模态共有信息与特有信息联合学习时彼此削弱的问题，首次用梯度提升形式化两类信息的交替优化，让不同子模型聚焦各自擅长的样本。框架再以知识蒸馏降低 boosting 的存储成本，并加入全局校正正则抑制局部最优；论文在多个真实数据集上报告优于现有多模态推荐方法。

Hamiltonian Spectral-Temporal Dissipative Dynamics for Sequential Recommendation

HSR 将用户偏好演化从一阶序列过程改写为耗散哈密顿系统，以位置表示稳定兴趣、动量表示短期趋势，并利用线性时不变结构在频域求闭式解。可学习耗散项刻画兴趣衰减，局部脉冲模块补充突然行为变化；在三个基准数据集上持续超过 Transformer 与状态空间模型推荐器。

INSIGHT长期兴趣、周期行为和突发转向对应不同动力学，单一注意力序列可能把三者混在一起。该模型为显式拆分稳定偏好、短期趋势与局部冲击提供了结构化方案，适合周期明显的内容消费；落地前仍需从正文核实具体增益、频域计算成本和对极短序列的稳健性。

Generative artificial intelligence model for knowledge transfer in data-sparse cross-domain recommender systems

论文面向目标域交互稀疏的跨域推荐，提出 SPARGAN，通过生成对抗学习迁移源域知识并合成用户—物品交互，以缓解冷启动和数据稀疏。文章于 2026 年 8 月 13 日发表，公开摘要称其推荐准确率优于既有方法，但搜索补充信息未提供数据集、指标与具体提升数值，因此证据质量按中等计分。

INSIGHT跨域迁移的可用价值取决于合成行为是否保留目标域偏好而非复制源域流行度。可把该方法视为冷启动数据增强候选，但上线前必须检查域间用户/物品对齐、负迁移和合成样本校准，并与更简单的表征迁移及重要性加权基线比较；当前公开证据不足以支持直接采用。
