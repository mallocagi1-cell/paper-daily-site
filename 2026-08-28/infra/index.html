DataKernelBench: Can LLMs Optimize Database Queries on GPUs?

DataKernelBench 将 SQL 转换为经过验证的 PyTorch TorchPlan，并让模型通过执行反馈修复 CUDA 或 Triton 实现，专门覆盖不规则、异构且数据搬运密集的数据库算子。10 个闭源与开源模型在 H100、TPC-H SF10 上测试，最佳全查询 CUDA 方案以完整通过率达到 torch.compile 的 2.11 倍速度。

INSIGHT高性能实现主要依靠算子融合和执行策略重写，而不是简单替换内核；完整查询上下文的价值也高于额外硬件描述。对搜索基础设施，这说明可把 LLM 优化器用于特征处理、批量重排和索引构建，但必须保留编译、执行、正确性校验组成的闭环。

Does Fine-Tuning Undo Activation Steering? Behavioural Recovery Without Weight-Edit Reversal

研究在 5 个、规模 3B 至 14B 的指令模型上测试 embedding 权重的激活引导能否承受后续 SFT 与 RLHF。与目标行为冲突的 SFT 使拒答抑制效果平均损失 64%，但权重编辑本身几乎未被逆转，平均向量恢复相关仅为 0.004，揭示行为恢复与参数回滚并不等价。

INSIGHT模型发布链路不能仅凭权重差异确认安全或风格控制仍然有效；后续微调可能通过近乎正交的更新覆盖行为表现。工程上应在每次 SFT、RLHF、量化和合并后重跑行为回归集，并把控制效果作为模型注册与上线门禁的一部分。

Philipp E. Glass, Allan Tucker, Yongmin Li, Alina Miron

Gated Recurrent Transformers: Expressive Depth through Recurrent Modulation

论文以固定前导层和收尾层包围可循环执行的共享核心层，并用依赖当前隐藏状态、前导输出及逐步重采样噪声的门控更新保持不同深度的功能分工。该设计在参数共享降低模型内存的同时，避免普通循环 Transformer 因每层执行同一变换而损失表达多样性。

INSIGHT这类结构把“参数量”与“有效计算深度”部分解耦，适合显存受限但可接受额外计算轮次的服务环境。落地前应分别测量权重内存、KV Cache、首 token 延迟和循环次数带来的吞吐变化，避免只依据参数压缩比例判断线上收益。

Amr Hegazy, Amr Alanwar, Mostafa Elhoushi

Unsupervised Post-Training of Foundation Models: A Survey

OpenSanctions Pairs: Large-Scale Entity Matching with LLMs

OpenSanctions

OpenSanctions Pairs 提供 755,540 个专家标注实体对，覆盖超过 100 万实体、293 个数据源与 45 个司法辖区，包含多语言、结构不一致和时变来源信息。生产规则基线达到 91.3% F1，GPT-4o 达到 99.0% F1，并同时评估本地可部署的 14B 开源模型与提示优化。

INSIGHT该工作展示了面向真实异构数据构建评测基础设施的方法：保留来源、时间和语言差异，并让规则系统与闭源、开源模型在同一协议下比较。搜索团队可将类似配对基准用于作者、商家或内容实体归一化，同时保留规则回退以控制成本和可解释性。

Chandler Smith, Magnus Sesodia, Friedrich Lindenberg, Christian Schroeder de Witt

A Programming Paradigm for Spatiotemporal Composability

论文把动态插件与自演化 Agent 系统的组合问题拆成时间与空间两维：可逆 effect 让组件移除时完整撤销上下文副作用，响应式 coeffect 则声明依赖并驱动组件启停。运行时同时持有变换及其逆操作，再依据上下文变化分类管理依赖，形成统一组合机制。

INSIGHTAgent 和搜索插件平台最难处理的是卸载后的残留状态与隐式依赖，而不只是接口调用。可借鉴该范式为每个插件记录可逆变更、资源所有权和依赖声明，让灰度发布、动态关闭与故障回滚成为运行时原生能力。

Yifan Shi, Wei Zhang, Tianyi Cui

Data Citation for Large Language Models: A Challenge

论文指出 LLM 引用不仅要验证文本来源，还应覆盖数据贡献者的署名与可追溯性，并区分训练数据归因、推理时数据集或查询结果引用，以及知识图谱中的结构化证据。核心难点是把影响估计转换成稳定引用，并选择可复现的数据粒度与版本。

INSIGHTRAG 与搜索平台需要把数据血缘作为一等元数据：索引条目应保留数据集、分片、版本、查询快照和授权信息，生成答案再引用到可固定的证据单元。这样既便于纠错和合规审计，也能在内容更新后复现当时的召回与回答。

Gianmaria Silvello
