The Generative Recommender Behind Shopify's Commerce Engine

Shopify 将购买旅程建模为因果序列，采用自回归模型预测用户下一个交互商品。核心创新包括：(1) 基于 RoPE 旋转编码的 Time-Aware Attention，将时间戳直接编入注意力机制捕捉季节性和时效性；(2) 结合 shared negatives 和 positive-aware sampling 的高级负采样策略；(3) 基于 boosting 思想的 incremental recall 集成方法，弥补其他检索模型的覆盖盲区。训练流水线加速 7.3 倍。线上 A/B 测试结果：订单量 +0.94%，高质量点击率 +5%，转化率 +0.71%，recall@2 +4.8%。

R3A: Reinforced Reasoning for Relevance Assessment for RAG in User-Generated Content Platforms

Xiaohongshu📖 深度解读 · 7 分钟 →

针对 UGC 平台 RAG 系��中相关性评估的两大挑战——用户意图模糊和非对称相关性（相关性由局部答案片段驱动而非全局相似度），提出 R3A 框架。方法将相关性评估分解为意图推理和证据锚定两个阶段：利用高点击文档作为辅助信号推断潜在查询意图，再提取原文证据片段锚定相关性判断，降低噪声敏感性。蒸馏后的 R3A-1.5B 模型在大规模线上 A/B 测试中取得显著提升，兼顾了效果和部署效率。

INSIGHTR3A 的核心创新在于将相关性评估从「端到端打分」重构为「推理链式分解」：先推断用户真实意图，再基于证据片段做判断。这种设计对 UGC 短文本搜索极具实践意义——短文本中用户 query 天然模糊，而答案往往隐藏在帖子的某个段落中。通过强化学习优化推理过程（而非直接优化评分），模型能学到更鲁棒的相关性判断策略。1.5B 蒸馏版本在线上验证了可部署性，是大模型能力落地到搜索场景的良好范例。

Xiaowei Yuan, Lei Jin, Haoxin Zhang, Ziyang Huang, Yan Gao, Yi Wu, Yao Hu, Jun Zhao, Kang Liu

HeadRank: Decoding-Free Passage Reranking via Preference-Aligned Attention Heads

针对免解码（decoding-free）重排序方法中注意力分数同质化的问题——中间位置文档获得近乎相同的注意力分数导致排序区分度丧失——提出 HeadRank。方法通过偏好对齐技术识别和选择 LLM 中与相关性判断最相关的注意力头（attention heads），直接从这些头的注意力权重读取排序信号，无需自回归解码。相比传统 listwise reranking 方法，延迟大幅降低的同时保持了排序质量。

INSIGHTHeadRank 揭示了一个重要发现：LLM 的不同注意力头对相关性的「理解」差异巨大，大部分头产生同质化分数，但少数头天然编码了强排序信号。通过偏好对齐筛选这些头，可以在不进行任何解码的情况下完成高质量重排序。这对搜索系统���有直接的工程价值：生成式大模型的推理延迟是线上部署的核心瓶颈，而 HeadRank 提供了一条「零解码开销」的替代路径，特别适合延迟敏感的 UGC 搜索场景。

LLMAR: A Tuning-Free Recommendation Framework for Sparse and Text-Rich Industrial Domains

面向数据极���稀疏但文本丰富的工业 B2B 场景（如建筑风险预测、物料采购），提出 LLMAR 框架。核心思路是利用 LLM 将用户行为模式解释为语义动机（semantic motives），无需任何微调即可完��推荐。三大创新：(1) LLM 直接从行为序列推断用户语义意图；(2) 自纠错机制减少 LLM 幻觉导致的推荐错误；(3) 仅需推理（inference-only）运行，成本约 $1/1000 用户。在 MovieLens-1M、Amazon Prime Pantry 及企业数据集上验证了有效性。

INSIGHTLLMAR 代表了 LLM-as-Recommender 范式的实用化方向：不微调、不训练，纯靠 LLM 的推理能力做推荐。自纠错机制是关键设计——LLM 先生成推荐理由再自我验证，减少了「看似合理但实际不相关」的幻觉推荐。$1/1000 用户的成本估算表明该方案在冷启动或长尾场景具有实际可行性。对于 UGC 搜索中的新用户、新话题等数据稀疏问题，这种零训练的 LLM 推荐思路值得探索。

Bayesian Active Learning with Gaussian Processes Guided by LLM Relevance Scoring for Dense Passage Retrieval

提出 BAGEL 框架，解决 LLM 作为相关性评估器时的高计算成本问题。核心方法：基于 LLM 相关性分数构建查询特定的高斯过程（GP），在 embedding 空间中建模相关性分布，通过贝���斯主动学习策略平衡「高置信区域的利用」和「不确定区域的探索」来选择最值得 LLM 评估的段落。在四个基准数据集和两种 LLM 后端上，BAGEL 在相同 LLM 预算下全面超越传统重排序方法。已被 ACL 2026 Findings 接收。

Transparent and Controllable Recommendation Filtering via Multimodal Multi-Agent Collaboration

针对 LLM 推荐过滤中的两大瓶颈——缺乏多模态感知和严重的「过度关联」问题（将用户对特定内容的不喜欢错误泛化到相似但无害的内容），提出端云协同的多智能体框架。系统包含事实锚定裁决管线消除推理幻觉，以及动态双层偏好图支持用户显式修改（Delta 调整）防止意图遗忘。在 473 个对抗样本上，误报率降低 74.3%，F1 分数达到纯文本基线的近 2 倍。19 人参与的 7 天纵向实验验证了意图对齐的鲁棒性。

INSIGHT该研究揭示了 LLM 推荐系统中一个被忽视的问题：过度关联（over-association）。当用户标记不喜欢某类焦虑营销内容时，LLM 会错误地泛化到教育类相似内容，导致大量误过滤。双层偏好图的设计思路值得借鉴——通过分离「全局偏好」和「局部调整」来防止灾难性遗忘。对于 UGC 平台的内容过滤和推荐质量控制，这种细粒度的用户偏好管理机制具有直接应用价值。

Chi Zhang, Zhipeng Xu, Jiahao Liu, Dongsheng Li, Hansu Gu, Peng Zhang, Ning Gu, Tun Lu

COSEARCH: Joint Training of Reasoning and Document Ranking via Reinforcement Learning for Agentic Search

现有 agentic search 方法（如 Search-R1）将检索系统视为固定工具，仅优化推理 agent 而检索组件不变。实验表明 oracle 检索器与固定检索器的差距高达 +26.8% F1，证明检索是性能瓶颈。COSEARCH 通过 Group Relative Policy Optimization (GRPO) 联合训练多步推理 agent 和生成式文档排序模型。关键设计：(1) 语义分组策略按 token 相似度聚类子查询形成优化组；(2) 复合奖励结合排序质量信号和轨迹级结果反馈。在 7 个单跳/多跳 QA 基准上持续优于强基线。

INSIGHTCOSEARCH 最重要的发现是：在 agentic search 中，检索组件（而非推理 agent）才是真正的性能瓶���。+26.8% 的 oracle 差距表明，固定检索器严重限制了推理能力的发挥。通过 GRPO 联合优化推理和排序，模型能学到「什么样的排序结果最有利于后续推理」。对于搜索系统的 LLM 集成，这意味着不应孤立地优化 LLM 排序或 LLM 推理，而应将两者作为一个端到端系统来训练。

Hansi Zeng, Liam Collins, Bhuvesh Kumar, Neil Shah, Hamed Zamani

Latent Preference Modeling for Cross-Session Personalized Tool Calling

用户向 LLM agent 发出请求时常省略关键细节，导致工具调用输入不完整。提出 MPT 基准（265 个多会话对话、三个难度级别：偏好回忆、偏好归纳、偏好迁移）和 PRefine 方法。PRefine 将用户偏好建模为动态工作假设，通过 generate-verify-refine 迭代循环从历史对话中提取可复用约束，增强工具调用的个性化。关键优势：仅需完整历史 prompting 的 1.24% token 消耗即可实现有效的偏好建模。

INSIGHTPRefine 的核心设计思想——将偏好建模为「假设-验证-修正」循环而非静态画像——为生成式推荐的个性化提供了新思路。传统推荐系统依赖用户画像特征，而 PRefine 证明 LLM 可以通过动态推理理解用户偏好的深层逻辑（为什么做这个选择），而不仅是记录选择本身。1.24% 的 token 效率提升尤为突出，表明高效的偏好压缩是可行的。这对 UGC 搜索中的个性化 query 理解具有启发意义。

Yejin Yoon, Minseo Kim, Taeuk Kim

Hypercomplex Knowledge Graph-Aware Recommendation

将超复数代数（hypercomplex algebra）引入知识图谱感知推荐系统。与传统实数空间 embedding 不同，超复数 embedding 的多分量结构（如四元数）能够更高效地编码用户、物品和实体间的复杂关系。通过在知识图谱上学习超复数表示，模型用更少的参数获得更强的表达能力，特别是在捕捉多元关系和旋转变换方面优于传统方法。发表于 SIGIR 2025。
