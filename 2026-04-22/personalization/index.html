RankUp: Towards High-rank Representations for Large Scale Advertising Recommender Systems

本文揭示了推荐系统 Scaling Law 中一个关键盲区：虽然 MetaFormer 架构在增加深度和维度后性能提升，但 token 表征的有效秩（effective rank）并未随参数增长而线性扩展，甚至在深层出现退化。作者提出 RankUp 架构，通过随机排列分裂稀疏特征、多 embedding 范式、全局 token 集成、交叉预训练 embedding token 和任务特定 token 解耦等五大机制缓解表征坍塌。RankUp 已全量部署于微信视频号、公众号和朋友圈广告系统，分别带来 3.41%、4.81% 和 2.21% 的 GMV 提升。

Modular Representation Compression: Adapting LLMs for Efficient and Effective Recommendations

HuaweiSJTU📖 深度解读 · 8 分钟 →

本文发现一个反直觉现象：LLM 中间层表征在推荐任务上优于最终层输出，说明 LLM 的深层语义压缩可能丢失了推荐所需的特征多样性。基于此洞察，作者提出 MARC（Modular Representation Compression），显式引入压缩和任务适配模块，利用信息约束解耦不同任务的表征需求。MARC 已被 SIGIR 2026 接收，在大规模商业搜索广告场景的在线 A/B 测试中取得 2.82% 的 eCPM 提升。

INSIGHT"中间层优于最终层" 的发现对 LLM+推荐的工程实践有重要指导意义：直接使用 LLM 最后一层 embedding 做推荐可能并非最优，应该系统性地评估各层表征质量。MARC 的模块化设计使其可以作为即插即用组件集成到现有推荐 pipeline 中，降低 LLM 表征的存储和计算成本。2.82% eCPM 提升在搜索广告场景下是非常可观的收益，验证了 LLM 表征压缩在工业界的实用价值。

Yunjia Xi, Menghui Zhu, Jianghao Lin, Bo Chen, Ruiming Tang, Yong Yu, Weinan Zhang

Modernizing the Facebook Groups Search to Unlock the Power of Community Knowledge

Meta

Meta 对 Facebook Groups 搜索系统进行了根本性升级，采用混合检索架构并实施基于模型的自动化评估体系，解决用户在社区内容搜索中的核心痛点。新框架帮助用户更可靠地发现、筛选和验证最相关的社区内容，在发现效率、内容排序准确性和用户信任度等维度均取得显著提升。这是一个典型的 UGC 社区搜索现代化改造案例。

INSIGHTMeta Groups Search 的升级路径对 UGC 搜索场景极具参考价值：混合检索（hybrid retrieval）架构能同时兼顾精确匹配和语义理解，特别适合社区短文本搜索中 query 表达模糊、内容多样的特点。自动化模型评估（model-based evaluation）替代人工标注的实践值得借鉴——在 UGC 内容快速增长的场景下，传统标注方式已无法跟上迭代速度。

HORIZON: A Benchmark for In-the-wild User Behaviour Modeling

Microsoft Research

现有用户建模基准局限于单领域短序列和 next-item 预测，难以反映真实用户行为的多样性和长期性。HORIZON 基于 Amazon Reviews 构建了覆盖 5400 万用户、3500 万物品的跨领域大规模基准，从数据集、任务和评估三个维度重新定义用户建模评测。引入时间泛化、序列长度变化和未见用户建模等新评估维度。实验揭示当前序列推荐模型和 LLM 方法在真实场景下存在显著性能差距。已被 ACL 2026 (Findings) 接收。

INSIGHTHORIZON 的三轴评估框架（数据、任务、评估）揭示了当前推荐模型在跨域泛化和长时间窗口上的短板，这对 UGC 搜索平台的用户建模有直接启示：用户在社区中的行为跨越多个兴趣域且具有时序演化特征。5400 万用户级别的评测规模使其成为验证工业级用户模型的可靠标准。LLM 方法在长序列建模上未能显著优于传统方法这一发现值得关注。

Arnav Goel, Pranjal A Chitale, Bhawna Paliwal, Bishal Santra, Amit Sharma

Diagnosing LLM-based Rerankers in Cold-Start Recommender Systems: Coverage, Exposure and Practical Mitigations

本文系统性诊断了 LLM/Cross-encoder 重排器在冷启动推荐场景中的实际表现。通过在 Serendipity-2018 数据集上的 500 用户控制实验，揭示 LLM 重排器与简单基线之间存在显著性能差距。研究聚焦覆盖率（coverage）、曝光分布（exposure）和实用缓解策略三个维度，为 LLM 在冷启动推荐中的部署提供了清晰的诊断框架和改进方向。

INSIGHTLLM 重排器在冷启动场景中的"性能差距"发现对 UGC 平台意义重大——新用户和新内容是社区搜索的常态。研究揭示的覆盖率和曝光不均问题说明 LLM 可能加剧冷启动内容的"马太效应"。实用缓解策略为在 CTR 预估系统中合理使用 LLM 重排提供了工程指导：不应盲目信赖 LLM 的零样本能力，而需要结合传统方法进行混合排序。

Response-Aware User Memory Selection for LLM Personalization

Purdue

提出 RUMS（Response-Utility optimization for Memory Selection），通过度量用户记忆子集与模型输出之间的互信息来选择记忆项，而非依赖传统的 query-memory 语义相似度。核心思想是识别那些能减少响应不确定性、锐化预测结果的用户记忆。方法在提升响应质量的同时实现高达 95% 的计算成本降低。

INSIGHTRUMS 的互信息选择机制为推荐系统中的用户画像构建提供了新思路：不是选择与当前 query 最相似的历史行为，而是选择对预测结果最具区分度的行为特征。这种"响应感知"的思路可迁移到 CTR 预估中的用户行为序列选择——从长序列中筛选真正影响点击决策的关键行为。95% 的计算成本降低使其在在线服务场景中具有实际可行性。

Jillian Fisher, Jennifer Neville, Chan Young Park

Modeling User Exploration Saturation: When Recommender Systems Should Stop Pushing Novelty

公平性推荐系统通常通过增加长尾内容曝光来缓解偏差，但探索强度通常由全局超参数控制，忽略了用户间差异。本文提出用户探索饱和度建模，核心论点是同一级别的探索干预并不适用于所有用户、上下文和交互阶段。模型能自适应地判断何时停止推送新奇内容，在推荐多样性和用户满意度之间取得更好平衡。

INSIGHT探索饱和度的概念对 UGC 搜索平台的内容分发策略有直接参考价值：在信息流推荐中，持续推送新奇内容可能导致用户疲劳和 CTR 下降。自适应探索强度控制可替代固定的多样性权重，根据用户实时状态动态调整推荐策略。这种用户级个性化的干预粒度是提升长期留存指标的关键方向。

Enock O. Ayiku, Evelyn Osei, Onyeka Emebo

Multi-LLM Token Filtering and Routing for Sequential Recommendation

提出 MLTFR 框架，探索一个新颖问题：能否仅使用 LLM 的 token embedding（不需要文本输入）来提升序列推荐？系统性实验表明，直接注入单个 LLM 的 token embedding 效果有限，但通过用户引导的 token 过滤选择任务相关 embedding，并以 Mixture-of-Experts 方式融合多个 LLM 的 token 空间，可以显著提升序列推荐性能。

INSIGHT"无需文本输入即可利用 LLM 知识" 这一发现拓展了 LLM 在推荐系统中的应用方式——LLM 的 token embedding 本身就蕴含了丰富的语义结构，可被序列推荐模型直接利用。用户引导的 token 过滤和多 LLM MoE 路由机制为推荐系统融合多个预训练模型提供了新的技术路径，在需要轻量化部署的 UGC 场景中值得探索。

HorizonBench: Long-Horizon Personalization with Evolving Preferences

StanfordUUW

提出 HorizonBench，一个用于评测长时间窗口个性化能力的基准，包含 360 个模拟用户的 6 个月对话历史、4245 个评测项，并提供每次偏好变化的因果溯源标注。对 25 个前沿模型的测试显示，最佳模型仅达到 52.8% 准确率，大多数模型在或低于 20% 的随机基线水平，暴露出 LLM 在追踪用户偏好演化方面的严重不足。

INSIGHTHorizonBench 揭示了 LLM 个性化的核心瓶颈：模型难以更新已改变的用户偏好信念。对搜索推荐系统而言，这意味着基于 LLM 的用户建模方案需要显式设计偏好更新机制，不能依赖模型自身的上下文学习能力。52.8% vs 20% 基线的巨大差距也说明，长期用户画像维护仍是工程难题，需要结合传统的增量更新策略。

Balanced Co-Clustering of Users and Items for Embedding Table Compression in Recommender Systems

大规模推荐系统中的 embedding table 包含海量用户/物品向量，带来巨大的计算和存储开销，限制模型部署。现有压缩方案要么严重损害推荐质量，要么压缩比有限。本文提出基于平衡协同聚类的 embedding table 压缩方法，同时对用户和物品进行聚类以实现结构化压缩，在保持推荐质量的同时大幅减少参数量。

INSIGHTEmbedding table 压缩是推荐系统工程化的关键问题，尤其在 UGC 平台中用户和内容规模持续增长的背景下。平衡协同聚类的思路兼顾了用户侧和物品侧的结构信息，避免了单侧压缩导致的信息损失。对于需要在边缘设备或资源受限环境中部署推荐模型的场景（如移动端搜索），该方法的压缩效率值得关注。

Runhao Jiang, Renchi Yang, Donghao Wu
