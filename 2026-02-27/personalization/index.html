MTGR: Industrial-Scale Generative Recommendation Framework in Meituan

基于 HSTU 架构构建美团工业级生成式推荐框架 MTGR，在保留传统深度学习交叉特征的同时实现生成式推荐的可扩展性。

INSIGHT生成式推荐落地的核心挑战是放弃精心构建的交叉特征会导致性能下降；MTGR 证明可以在 HSTU 生成式架构中兼容传统特征工程，两者并非对立。

业务关联对社区搜索的排序系统升级有直接参考价值：可在现有特征工程基础上逐步引入生成式推荐架构，降低迁移风险。

证据美团线上全量部署，Scaling Law 在推荐系统中得到验证；与纯生成式方法相比，保留交叉特征后模型性能显著优于丢弃交叉特征的基线。

Offline Reasoning for Efficient Recommendation: LLM-Empowered Persona-Profiled Item Indexing

提出 Persona4Rec，利用 LLM 离线推理构建 item 的多角色表征，实现轻量级实时推荐推理。

INSIGHT将 LLM 的昂贵推理从在线阶段移至离线阶段——通过分析评论生成多维 persona 表征，在线只需做 persona 匹配，兼顾 LLM 语义理解能力与低延迟需求。

业务关联可直接应用于社区搜索的内容理解：对 UGC 帖子离线生成 persona 标签（如「技术问答型」「经验分享型」），在线搜索时通过 persona 匹配提升相关性。

证据推荐性能媲美 LLM reranker（如 RankGPT），推理延迟大幅降低；提供基于评论的可解释推荐理由。

Deogyong Kim, Junseong Lee, Jeongeun Lee, Changhoe Kim, Junguel Lee, Jungseok Lee, Dongha Lee

Massive Memorization with Hundreds of Trillions of Parameters for Sequential Transducer Generative Recommenders

提出 VISTA 框架，将 target attention 分解为两阶段，支持百万级用户历史序列建模，参数量达数百万亿。

INSIGHT通过将 target attention 分解为「用户历史摘要」和「候选注意力」两阶段，可以在固定计算成本下处理百万级用户交互历史——这是序列推荐模型扩展的关键突破。

业务关联对社区搜索中的用户建模有启发意义：长期用户行为序列（浏览/搜索/互动历史）的高效建模可提升个性化排序效果，VISTA 的两阶段分解思路可在现有序列模型中采用。

证据在工业平台部署，离线和在线指标均有提升；支持处理长达 100 万 item 的用户历史；训练和推理成本固定，不随序列长度增长。

OneRec-Think: In-Text Reasoning for Generative Recommendation

📖 深度解读 · 13 分钟 →

在快手 OneRec 基础上引入 in-text reasoning 机制，实现对话、推理与个性化推荐的统一框架。

INSIGHT现有生成式推荐模型是隐式预测器，缺乏显式可控推理能力；OneRec-Think 通过 Itemic Alignment（跨模态对齐）和 in-text reasoning 让推荐过程可解释、可控。

业务关联可解释推荐对社区搜索意义重大：用户能理解为何看到某个搜索结果，OneRec-Think 的推理链路可迁移到搜索结果排序的可解释性改进中。

证据快手 OneRec 系统在线上内容推荐场景中已验证，用户观看时长和点赞率均有提升（session watch time +1.78%，like-through rate +3.36%）。

Trie-Aware Transformers for Generative Recommendation

提出 TrieRec，为生成式推荐中的 Transformer 引入 trie 结构感知的位置编码，使模型理解 item 层次化 token 的树形关系。

INSIGHT标准 Transformer 忽略了 item tokenization 产生的树形结构；通过注入局部结构上下文和成对结构关系到自注意力中，无需超参数调优即可提升生成式推荐效果。

业务关联层次化分类在社区搜索中很常见（帖子分类-子分类-标签）；TrieRec 的结构感知方法可迁移到利用分类层级信息提升搜索排序效果。

证据四个真实数据集上平均提升 8.83%；模型无关（model-agnostic），无需额外超参数调优。

Zhenxiang Xu, Jiawei Chen, Sirui Chen, Yong He, Jieyu Yang, Chuan Yuan, Ke Ding, Can Wang

Accelerating Generative Recommendation via Simple Categorical User Sequence Compression

📖 深度解读 · 9 分钟 →

利用 item 类别特征压缩长用户交互序列，在保留兴趣信号的同时大幅降低生成式推荐的计算成本。

INSIGHT不需要复杂的序列压缩技术——简单地利用 item 的类别属性进行分组压缩就能实现 6 倍计算成本缩减，且推荐精度反而提升，说明冗余信号是序列推荐的主要效率瓶颈。

业务关联社区搜索中用户历史行为序列同样面临长度爆炸问题；该方法的按类别压缩思路可直接应用于 UGC 平台的用户行为序列建模。

证据WSDM 2026 录用；对比 HSTU 模型：计算成本降低 6 倍，同等计算量下准确率提升 39%。

ActionPiece: Contextually Tokenizing Action Sequences for Generative Recommendation

借鉴 BPE 分词思想，提出对用户行为序列进行上下文感知的 token 化方法 ActionPiece，使同一行为在不同上下文中获得不同表征。

INSIGHT现有生成式推荐对每个 action 独立 tokenize，忽略了上下文关系；ActionPiece 通过上下文敏感的 tokenization 让模型捕捉同一商品在不同场景下含义不同的信号。

业务关联用户在社区搜索中的相同查询在不同上下文（如浏览帖子后搜索 vs 直接搜索）含义不同；ActionPiece 的上下文感知方法可应用于搜索 query 的上下文建模。

证据在多个推荐数据集上优于独立 tokenization 的基线方法，验证了上下文感知 tokenization 的有效性。

Yupeng Hou, Jianmo Ni, Zhankui He, Noveen Sachdeva, Wang-Cheng Kang

Killing Two Birds with One Stone: Unifying Retrieval and Ranking with a Single Generative Recommendation Model

提出 UniGRF 框架，用单一生成式模型同时完成召回和排序，消除多阶段推荐管道中的信息损失。

INSIGHT传统多阶段推荐管道（召回-粗排-精排）的级间信息损失是性能瓶颈；UniGRF 证明单一生成式模型可以端到端地统一召回与排序，避免跨阶段的特征/信号丢失。

业务关联社区搜索的多阶段管道（查询理解-召回-排序）同样存在信息损失问题；UniGRF 的统一思路可启发搜索系统从多阶段向端到端架构演进。

证据在推荐系统标准 benchmark 上，统一模型在召回和排序指标上均优于分离的多阶段基线。

Luankang Zhang, Kenan Song, Yi Lee, Wei Guo, Hao Wang

Reasoning-Based Personalized Generation for Users with Sparse Data

提出 GraSPer 框架，通过图推理预测稀疏用户可能交互的内容来丰富上下文，解决冷启动个性化问题。

INSIGHT冷启动用户的稀疏历史是 LLM 个性化的核心挑战；通过先预测用户可能感兴趣的 item，再利用这些预测内容增强上下文，可以有效弥补数据稀疏性。

业务关联社区平台新用户/低活用户的搜索个性化是核心痛点；GraSPer 的预测交互-丰富上下文思路可应用于社区搜索的冷启动排序优化。

证据在三个数据集上显著提升稀疏用户场景下的个性化生成效果，PersonalLLM 任务上表现突出。
