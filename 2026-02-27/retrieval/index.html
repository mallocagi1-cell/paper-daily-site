Semantic Search At LinkedIn

LinkedIn 构建了一套基于 LLM 的语义搜索框架，通过多教师蒸馏将大模型能力压缩到小模型，实现生产级语义排序。

KEY INSIGHT · 对业务意味着什么通过 prefill-oriented 推理架构配合模型剪枝和上下文压缩，在固定延迟约束下将排序吞吐量提升 75 倍，同时保持接近教师模型的 NDCG，这是首个效率可比传统方案的生产级 LLM 排序系统。业务关联 社区搜索同样面临语义匹配与效率的平衡问题，LinkedIn 的多教师蒸馏 + SLM 方案可直接借鉴：用大 LLM 做离线标注和评估，训练轻量小模型上线，兼顾相关性和吞吐。证据 排序吞吐量提升 75 倍以上（固定延迟约束下）；蒸馏后的 SLM 保持接近教师模型的 NDCG 水平；已在 LinkedIn Job Search 和 People Search 全量上线，用户参与度显著提升。

AQR-HNSW: Accelerating Approximate Nearest Neighbor Search via Density-aware Quantization and Multi-stage Re-ranking

提出密度感知自适应量化 + 多阶段重排的 HNSW 优化框架，大幅提升向量检索的吞吐与内存效率。

INSIGHT通过密度感知量化实现 4 倍压缩且保持距离关系，配合 SIMD 优化和多阶段重排，在保持 98% 以上召回率的同时将 QPS 提升 2.5-3.3 倍。这为大规模向量索引的降本增效提供了即插即用的方案。

业务关联社区搜索中基于 embedding 的语义召回依赖高效 ANN 检索，该方法可在不牺牲召回质量的前提下将索引内存降低 75%，直接降低向量检索的基础设施成本。

证据QPS 提升 2.5-3.3 倍（对比 SOTA HNSW 实现）；召回率保持 >98%；索引图内存消耗降低 75%；索引构建速度提升 5 倍。已被 DAC 2026 接收。

Ganap Ashit Tewary, Nrusinga Charan Gantayat, Jeff Zhang

PiPNN: Ultra-Scalable Graph-Based Nearest Neighbor Indexing

提出 PiPNN 图构建算法，通过 HashPrune 在线剪枝避免传统图方法的搜索瓶颈，首次在单机上 20 分钟内构建十亿级 ANN 索引。

INSIGHT传统图索引（HNSW/Vamana）构建慢的根因是依赖随机访问密集的 beam search，PiPNN 通过分区 + 批量距离计算 + 动态稀疏剪枝绕过了这个瓶颈，实现数量级的构建加速。

业务关联社区搜索的向量索引需要频繁更新（新帖子持续产生），PiPNN 的超快构建速度（十亿级 <20 分钟）使得近实时索引刷新成为可能，大幅缩短新内容的搜索可见延迟。

证据索引构建比 Vamana (DiskANN) 快 11.6 倍，比 HNSW 快 12.9 倍，比 MIRAGE 快 19.1 倍以上；十亿级数据集在单台多核机器上 20 分钟内完成构建，查询吞吐量优于同类快速构建算法。

Tobias Rubel, Richard Wen, Laxman Dhulipala, Lars Gottesbüren, Rajesh Jayaram, Jakub Łącki

MAAQR: An LLM-based Multi-Agent Framework for Adaptive Query Rewriting in Alipay Search

📖 深度解读 · 12 分钟 →

支付宝搜索部署的 LLM 多智能体协作 query 改写框架，通过知识增强微调提升 LLM 对 query 和 item 语义的理解。

INSIGHT多 Agent 协作改写架构（而非单一 LLM 直接改写）能更好地适配不同 query 类型，通过 Agent 间的分工和协调提升改写质量，特别是在减少零结果率方面效果显著。

业务关联社区搜索中 UGC query 通常简短且含义模糊，与 Alipay 小程序搜索场景高度相似。MAAQR 的多 Agent 改写架构可直接应用于 query 理解和扩展，降低短 query 的零结果率。

证据2024 年 12 月起在支付宝小程序搜索全量上线；通过线下实验和线上 A/B 测试，CTR 和交易量显著提升，零结果率（ZRR）大幅下降。发表于 SIGIR 2025。

Alipay Research Team

Embedding-Based Context-Aware Reranker

提出 EBCAR，利用 passage embedding 的结构信息和混合注意力机制实现跨段落推理的上下文感知重排序。

INSIGHT文档切段后丢失了跨段落的上下文关系（指代消解、实体消歧、证据聚合），EBCAR 通过结构化信息和混合注意力在 embedding 层面恢复这些关系，在准确率和效率上优于 SOTA 重排序器。

业务关联社区搜索中 UGC 内容（帖子+评论+回复）天然存在跨文本的上下文依赖，EBCAR 的跨段落推理能力可提升帖子-评论联合检索场景下的相关性排序质量。

证据在 ConTEB 基准上超越 SOTA 重排序器，兼具准确率和效率优势。已被 ICLR 2026 接收。

Ye Yuan, Mohammad Amin Shabani, Siqi Liu

Revisiting Text Ranking in Deep Research

📖 深度解读 · 14 分钟 →

系统评估了经典文本排序方法在 Deep Research 场景下的表现，揭示了检索单元、pipeline 配置和 query 特性三个维度的关键发现。

INSIGHTLLM Agent 生成的 query 倾向于 web 搜索语法（如引号精确匹配），这使得词法/稀疏/多向量检索器反而优于纯稠密检索；将 Agent query 转换为自然语言问题可显著缓解 query 不匹配问题。

业务关联社区搜索的 query 理解同样面临用户输入与训练分布不匹配的问题，该论文关于 passage-level 检索和 re-ranking 的配置建议可直接指导搜索 pipeline 的组件选择和调优。

证据在 BrowseComp-Plus 上使用 2 个 Agent、5 个检索器、3 个重排序器进行系统评测；passage-level 检索在有限上下文窗口下更高效；re-ranking 在所有配置中均带来显著提升。

Chuan Meng, Litu Ou, Sean MacAvaney, Jeff Dalton

Multi-Vector Index Compression in Any Modality

提出注意力引导聚类（AGC）等四种方法，在固定向量预算下压缩多向量文档表示，支持文本/图像/视频多模态检索。

INSIGHTLate interaction 模型（如 ColBERT）的存储和计算成本随文档长度线性增长，AGC 利用注意力机制识别语义最显著的区域作为聚类中心，在大幅压缩索引的同时保持甚至提升检索性能。

业务关联社区搜索中若采用 ColBERT 等多向量模型做精细化语义匹配，索引成本是一大瓶颈。AGC 压缩方案可在保持检索质量的前提下将索引体积降低到固定预算，降低部署成本。

证据在 BEIR（文本）、ViDoRe（文档图像）、MSR-VTT 和 MultiVENT 2.0（视频）上评测；AGC 一致优于其他参数化压缩方法（序列缩放、记忆 token），比非参数层次聚类更灵活，与未压缩索引性能持平或更优。

Hanxiang Qin, Alexander Martin, Rohan Jha, Chunsheng Zuo, Reno Kriz, Benjamin Van Durme

Revisiting RAG Retrievers: An Information Theoretic Benchmark

提出 MIGRASCOPE 信息论框架，从检索质量、冗余度、协同效应和边际贡献四个维度系统评估 RAG 检索器。

INSIGHT不同检索机制（词法匹配、稠密 embedding、图引用）之间存在互补关系，基于信息论指标策略性地组合检索器的 ensemble 始终优于任何单一检索器，且 MIGRASCOPE 能量化每个检索器的独特贡献。

业务关联社区搜索通常融合多路召回（BM25 + 稠密向量 + 标签匹配），MIGRASCOPE 提供了科学评估各路召回贡献和冗余度的方法论，可指导召回策略优化和资源分配。

证据在多个 RAG 基准上系统评测 SOTA 检索器；ensemble 检索在所有配置中优于单一检索器；框架量化了各检索器在不同查询类型上的边际贡献差异。

Wenqing Zheng, Dmitri Kalaev, Noah Fatsi, Daniel Barcklow, Owen Reinert, Igor Melnyk, Senthil Kumar 等 8 人

Compression then Matching: An Efficient Pre-training Paradigm for Multimodal Embedding

提出 CoMa 两阶段预训练范式，先压缩再匹配，用少量数据将多模态大模型高效转化为 embedding 模型。

INSIGHTembedding 学习的两个目标（全面理解输入 vs 下游任务区分力）可以解耦：先通过压缩阶段热身获得语义理解能力，再通过对比学习获得匹配区分力，用远少于传统方案的数据量即可达到 SOTA。

业务关联社区搜索中可借鉴 CoMa 范式，用少量标注数据将预训练多模态模型快速适配为搜索 embedding 模型，降低语义召回模型的训练数据需求。

证据在 MMEB 多模态 embedding 基准上达到 SOTA，涵盖跨模态检索、聚类和分类任务；使用少量预训练数据即可将 MLLM 转化为竞争力强的 embedding 模型。

Da Li, Yuxiao Luo, Keping Bi, Jiafeng Guo, Wei Yuan, Biao Yang, Yan Wang, Fan Yang, Tingting Gao 等 10 人

Interact-RAG: Reason and Interact with the Corpus, Beyond Black-Box Retrieval

提出 Interact-RAG，让 LLM Agent 从被动 query 发起者转变为检索过程的主动控制者，通过细粒度动作原语直接操作语料库。

INSIGHT现有 Agentic RAG 将检索视为黑盒查询操作，限制了 Agent 处理复杂信息需求的能力。Interact-RAG 通过 Corpus Interaction Engine 提供细粒度检索操作原语，配合推理增强工作流和 RL 优化显著提升复杂查询的检索效果。

业务关联社区搜索中复杂 query（如多条件组合、隐含意图）可借鉴 Interact-RAG 的细粒度检索操作思路，让搜索系统具备更主动的 query 分解和多步检索能力。

证据在 6 个基准数据集上显著优于现有高级 RAG 方法；通过 SFT + RL 训练的端到端 Agent 实现自主检索；支持 zero-shot 执行和合成轨迹数据生成。

Yulong Hui, Chao Chen, Zhihang Fu, Yihao Liu, Jieping Ye, Huanchen Zhang
