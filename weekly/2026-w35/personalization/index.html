  1. 1. SORT: A Systematically Optimized Ranking Transformer for Industrial-scale Recommenders · 📖 深度解读

    SORT 将工业推荐排序重构为请求中心的 Transformer：把用户历史、画像和候选集合拼成一条序列，用局部注意力、query pruning、QKNorm、门控注意力和稀疏 MoE 处理高稀疏特征，再以生成式预训练缓解标签稀疏。在 0.6B 训练请求、9B 曝光的数据上，AliExpress 线上订单提升 7.47%、买家提升 6.67%、GMV 提升 8.65%，延迟下降 61%，吞吐提升 589%。

    出现于日报：08-25

  2. 2. TAGR: Temporally Adaptive Generative Recommendation for Industrial Live-Streaming Advertising · 📖 深度解读

    针对直播广告内容、商品和反馈快速变化导致静态推荐模型失效的问题，论文提出 TAGR，在广告 token、用户意图和偏好对齐三个层面做时间自适应。LSID 按周期刷新活动广告的语义—协同 ID，多尺度行为模块区分短期意图与长期偏好，再用新鲜 on-policy 反馈和稳定训练兼顾的偏好优化。候选摘要给出三层机制，但完整离线与线上增益数字需结合正文核验。

    出现于日报：08-27

  3. 3. Hierarchical Exponential-Gaussian Mixtures for Watch-Time Distribution Prediction · 📖 深度解读

    论文针对短视频观看时长分布的零膨胀、长尾和多峰特征，提出分层 Exponential-Gaussian Mixture（HEGM），用 skip-watch 分解、KL 方差正则和结构化初始化修复 EGMN 的方差塌缩、组件冗余与失活问题。实验覆盖公开数据集和大规模工业数据，论文报告排序准确率与阈值事件预测均提升，并通过 1.5 个月生产 A/B 测试确认统计显著的参与度提升。

    出现于日报：08-26

  5. 5. An Event is Worth One Token: Event Tokenization for Industrial-scale LLM Recommendation · 📖 深度解读

    论文指出现有 LLM 推荐把一次交互压成文本、Semantic ID 或少量类别特征，会持续丢失用户、物品、上下文与结果信号。AMBER 将完整时间快照压缩成一个可缓存的 Event Token，把“快照分辨率”变成新的扩展维度；工业排序和召回实验显示其改善计算—质量帕累托前沿，并可作为历史特征迁移到优化后的非 LLM 排序器。

    出现于日报：08-28

  6. 6. One Hierarchy, Two Systems: Semantic Product IDs for Discovery-Surface Ranking and Search-Page Query Reformulation · 📖 深度解读

    DoorDash 用产品内容 embedding 学习三层 Semantic ID（每层 512 个码），再将 SID 前缀上的用户偏好、商品表现和序列特征接入个性化排序，同时把查询转成商品概念做层级改写。排序离线 MRR@5 相对生产基线提升 6.98%、NDCG@5 提升 6.76%；线上首位加购率提升 8%，搜索滚动深度下降 1.866%。

    出现于日报：08-25

  7. 7. Towards a Densing Law for User Representation Learning at Billion-Scale Capacity · 📖 深度解读

    论文在十亿级支付宝用户行为数据上研究用户表示学习的扩展瓶颈：原始行为文本继续扩展时收益递减，而 token 化容量如何随数据规模增长缺乏定量规律。作者提出 User Behavioral Densing Law，发现最小充分 token 化容量与输入 token 数的对数近似线性，并据此设计自适应变长 token 化方法 ALGN；实验覆盖多种数据源、token 化方式和下游任务，ALGN 优于既有基线。

    出现于日报：08-26

  9. 9. Towards Faithful Simulation of Human Shopping Behavior

    RecVerse 面向数十页的真实购物会话，使用工作记忆、情景记忆和偏好记忆三层结构保存短期视觉信息、会话轨迹与长期意图，并把记忆写入本身作为动作。作者发布包含 5,274 条轨迹、69,842 个动作和 8 类行为的 USB 基准，用轨迹级 GRPO 同时优化宏观行为分布和微观意图一致性；GUI+RL 的 F1 从 4.27 提升到 7.19，HCO 从 23.11 提升到 32.64。

    出现于日报：08-25

  10. 10. RetrievalFormer: A Dual-Encoder Transformer for Efficient Approximate Nearest Neighbor Retrieval and Cold-Item Recommendation · 📖 深度解读

    论文把搜索与推荐放进共享双塔索引，要求新物品只凭内容或属性特征即可进入 ANN 召回。公开日志中 38.6% 的查询曝光涉及从未展示或访问的物品；用户冷启动时，99 个采样负例的 Recall@20 为 0.9595，暖启动为 0.9510，未见明显损失。作者还发现 19.7% 用户受 float32 时间戳排序 bug 影响，强调离线切分校验。

    出现于日报：08-27
