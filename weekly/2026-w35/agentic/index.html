  1. 1. Before Reasoning Can Fail: Pre-Evidence Procedural Failures in Agentic RAG

    论文指出，Agentic RAG 可能已经搜到候选片段，却在未阅读证据前直接结束，导致错误并非来自最终推理。作者在 HotpotQA、2WikiMultiHopQA 和 MuSiQue 的 1.2 万条成对轨迹上分离两类失败，并加入 Read-Gate，要求搜索后先执行 read；对原本跳过阅读的轨迹，LLM-Acc 提升 14.9–19.9 个百分点。

    出现于日报：08-24

  2. 2. Enrich-Retrieve-Rank: Scaling Capability Discovery Beyond In-Context Routing

    论文把 Agent 生态中的能力发现重构为检索问题：先离线补全模型、Agent、工具和技能的可搜索画像，再在线执行 retrieve-then-rank，而不是把整个注册表塞进上下文。在能力规模从 10 增至 7,278 时，in-context routing 的 Match@1 从 0.85 降至 0.12，检索排序仍为 0.81 至 0.39…

    出现于日报：08-26

  3. 3. JIT-Agent: Scaling Harness Intelligence via Just-in-Time Harness Evolution

    论文把 Agent 的记忆、规划、动作协议与工具编排抽象为四模块可生成 Harness，并训练 JIT-Agent 针对任务即时合成、修复和自演化执行框架。搭配该系统后，DeepSeek-V4-Flash 在 DeepSearchQA 和 OdysseyBench 上分别超过 GPT-5.6 9.1 与 4.3 分，GLM-5.2 的部分任务增益最高达 20 分。

    出现于日报：08-28

  4. 4. Prompt-Based Abstention Fails Under Misleading Context: A Controlled Study of Small Frozen RAG Models

    论文提出 GRAB-RAG，使用 Natural Questions 和 HotpotQA，把上下文分成支持、退化、缺失和误导四种条件，测试 3.8B–8B 冻结模型的 5 种拒答策略。模型面对缺失证据时能拒答，但面对误导证据仍有 41.6% 的问题直接作答，其中 63% 原样复述被植入的错误实体；生成侧冲突检查可将错误率降到 13.3%，代价是丢失大量正确答案。

    出现于日报：08-26

  5. 5. HALT: Verification-Aware Stopping for Retrieval-Augmented Search Agents

    HALT 将搜索智能体的停止条件从生成器置信度改为逐跳证据覆盖：先从问题生成预期 hop claims，再用轻量验证器为累计证据标记 MATCH、PARTIAL 或 NULL，只有所有 claim 被覆盖时才停止。论文在三个多跳问答基准上显示可减少冗余搜索，同时基本保持 Exact Match；消融表明收益来自 claim–evidence 对齐，而非固定轮数或词面重叠。

    出现于日报：08-24

  6. 6. SOP-Bench: A new benchmark for evaluating AI agents on real business procedures

    Amazon 的 SOP-Bench 将真实标准作业程序转为可执行 Agent 任务，覆盖 12 个业务领域、2,000 多个任务、工具接口与可核验答案。作者用 11 个前沿模型和两类 Agent 进行测试，发现工具从必需的 6 个扩展到 26 个时成功率近乎减半，最易与最难流程的正确率约为 90% 和 25%。

    出现于日报：08-24

  7. 7. Training a Knowledge Base: Supervised Structure Learning for Agent-Curated Document Stores

    论文把知识库从静态文档集合改成可训练的结构：训练 Agent 根据带标准答案的问题编辑文档关系，读者 Agent 在固定动作预算下使用冻结快照回答。相对覆盖全部实体的无监督索引，它用 1,913 条链接对比 196,112 条链接，单位语料动作节省提高 1.6 倍、准确率提高 1.8 倍；训练过的问题动作数减少 31%，双 key 覆盖时未见问题 F1 还提升 0.167。

    出现于日报：08-26

  8. 8. VoiceMem: Streaming Dual-Brain Memory for Real-Time Interaction

    VoiceMem 为实时对话 Agent 构建并行的“信息左脑”和“情感右脑”，配合流式记忆读写、记忆感知训练及可替换后端部署。其 top-5 检索比 Mem0 的 top-200 高近 30 分，三个人设基准综合分较此前最佳提升 4.29 分，检索仅需 134 毫秒，已覆盖真实部署验证。

    出现于日报：08-28

  9. 9. Risk-Aware Reranking for Agentic Tool Retrieval

    论文指出工具检索本身就是 Agent 的执行前安全边界：相关工具可能带来不必要的高风险动作。方法在冻结的首阶段检索器上增加轻量重排，分别建模 query 条件相关性与工具暴露风险，用显式参数控制安全—效用权衡，并通过 ToolGraph 平滑分数；作者在 UltraTool 和 Seal-Tools 的 6,108 个工具上做了 5 级风险标注，结果显示相较只看相关性的重排器能改善风险—相关性折中。

    出现于日报：08-26

  10. 10. Better Retrieval, Worse Robustness:How Multi-hop RAG Amplifies Upstream ASR Errors

    论文研究语音查询中的上游 ASR 错误是否会被多跳 RAG 修复，比较实体图链接、迭代改写和朴素稠密检索在 HotpotQA、2WikiMultiHopQA、MuSiQue 三个数据集上的表现。结构更丰富的方案绝对 F1 更高，但在最高 WER 口音上，组合方案相对干净文本的 F1 缺口反而扩大 36%–67%；87%–96% 的损失来自查询实体被识别错误。

    出现于日报：08-26
