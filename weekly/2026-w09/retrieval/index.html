  1. 1. Semantic Search At LinkedIn · 📖 深度解读

    LinkedIn 构建了一套基于 LLM 的语义搜索框架，通过多教师蒸馏将大模型能力压缩到小模型，实现生产级语义排序。

    出现于日报：02-27

  2. 2. Kunlun: Establishing Scaling Laws for Massive-Scale Recommendation Systems through Unified Architecture Design

    Meta 提出统一架构 Kunlun，首次为大规模推荐系统建立可预测的 scaling law，将 MFU 从 17% 提升至 37%。

    出现于日报：02-28

  3. 3. Embedding-Based Sparse Retrieval in E-Commerce Search

    提出 EBSR 框架，将查询和文档编码为由 ID-权重对组成的稀疏 embedding，用于电商搜索召回。

    出现于日报：02-25

  4. 4. The Wisdom of Many Queries: Complexity-Diversity Principle for Dense Retriever Training

    提出复杂度-多样性原则(CDP)，通过为每篇文档生成多条合成查询来优化稠密检索器训练。

    出现于日报：02-26

  5. 5. Domain-Adaptive and Scalable Dense Retrieval for Content-Based Recommendation

    构建基于 two-tower bi-encoder 的可扩展 dense retrieval 系统，用对比学习微调并通过 FAISS + INT8 量化实现高效部署。

    出现于日报：02-28

  6. 6. Scaling Laws for Embedding Dimension in Information Retrieval

    系统研究了稠密检索中 embedding 维度与检索性能之间的幂律关系。

    出现于日报：02-25

  7. 7. AQR-HNSW: Accelerating Approximate Nearest Neighbor Search via Density-aware Quantization and Multi-stage Re-ranking

    提出密度感知自适应量化 + 多阶段重排的 HNSW 优化框架，大幅提升向量检索的吞吐与内存效率。

    出现于日报：02-27

  8. 8. PiPNN: Ultra-Scalable Graph-Based Nearest Neighbor Indexing

    提出 PiPNN 图构建算法，通过 HashPrune 在线剪枝避免传统图方法的搜索瓶颈，首次在单机上 20 分钟内构建十亿级 ANN 索引。

    出现于日报：02-27

  9. 9. CMAQ: Consistency-Aware Online Multi-Objective Alignment for Related Search Query Generation

    利用 DPO 多目标优化生成相关搜索 query 推荐，平衡 CTR 和主题多样性。

    出现于日报：02-25

  10. 10. HierGR: Hierarchical Semantic Representation Enhancement for Generative Retrieval in Food Delivery Search

    美团在外卖搜索中部署生成式检索，通过层次化 Semantic ID 解决规模和延迟问题。

    出现于日报：02-25
