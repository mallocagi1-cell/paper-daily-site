Weekly Top 10 · 第38周

2026-09-14 ~ 09-20 · 生成式推荐

生成式推荐 · 个性化推荐 · AI 搜索 · 智能体搜索 · 系统与索引

  1. 1. VARG: Value-Aware and Ranking-Aligned Generative Retrieval for Dynamic E-commerce Search · 📖 深度解读

    VARG 将生成式召回候选直接送入天猫精排，以两级语义前缀和价值排序第三码构建标识符，并结合三阶段监督训练、Prefix-GRPO 与每日增量更新。覆盖 20% 搜索流量的 14 天 A/B 实验中，GMV 提升 1.45%、PCTR 提升 0.31%，说明候选配额内的价值对齐可以产生线上收益。

    出现于日报：09-16

  2. 2. One-Step Retrieval Framework for Real-Time Sponsored Search Ads Using Hierarchical Text Representations · 📖 深度解读

    ANGLE 将搜索广告表示为“商业意图×广告摘要”，以生成、相关性判别和偏好优化联合训练同一模型，并用动态约束解码过滤无效广告。腾讯在一万条查询上取得 HR@100 0.5273，表3报告 WTS 场景 GMV 提升2.16%；消费增幅在正文与表格间不一致，需保留核验。

    出现于日报：09-18

  3. 3. EAGER: Enrich-and-Align Generative Query Recommendation from Clicked Items in E-commerce Search · 📖 深度解读

    EAGER面向用户点击商品后返回推荐流的场景，根据商品属性和用户行为生成搜索建议。方法先通过四阶段课程学习、多样性正则与自蒸馏扩展意图，再用规则及点击偏好混合奖励进行GRPO对齐。阿里团队在5%流量上开展9天实验，PCTR提高1.28%，支付订单数提高3.49%，L2P提高2.38%。

    出现于日报：09-14

  4. 4. LIGE-GR: A Smooth Leap from Ranking to Generative Recommendation in the LLM Era

    LIGE-GR 将逐条打分升级为列表生成，利用上下文感知预测器、列表价值函数和 Palette 解码器建模已选内容对后续推荐的影响。七天线上实验中，Instagram Reels 和 Facebook Video 的观看时长分别提升1.14%与0.72%；后者视频浏览量下降0.52%，显示不同指标存在取舍。

    出现于日报：09-18

  5. 5. The Wisdom of the Loudest: A Large-Scale Audit of Generative Search on Reddit

    论文审计 Reddit Answers 在 20 个社区、1 万条查询上的 3 万次回答，考察检索选择与生成改写如何影响社区声音。被选评论中 92% 为顶层评论，而总体占比仅 53%；原评论第一人称单数占比从 3.3% 降至回答中的 0.06%，揭示生成式搜索对个人经验表达的系统性削弱。

    出现于日报：09-16

  6. 6. Self-Evolving Memory for Generative Recommendation

    LION 针对生成式推荐持续更新时不同用户偏好互相干扰的问题，利用稀疏记忆、兴趣聚焦与巩固监督隔离行为模式。三个 Amazon 数据集的四期评测中，Games Recall@10 从 TIGER 的 0.0558 升至 0.0724，CDs 从 0.0331 升至 0.0449；收益来自离线实验，尚不能等同线上点击率提升。

    出现于日报：09-16

  7. 7. Preference-Drift-Aware Subsequence Learning and Hierarchical Context Fusion for Long-Sequence Generative Recommendation

    DRIFT 使用语义、时间和兴趣变化学习软分段边界，将长历史压成偏好一致的子序列，再通过交叉注意力与门控融合近期和长期兴趣。KuaiRec 上 DRIFT-HSTU 的 Recall@20 从 0.1540 升至 0.1872，相对提升 21.6%；每轮训练时间从 3.06 秒降至 1.91 秒。

    出现于日报：09-15

  8. 8. InitGen: Candidate Generation for Interaction Initiation in Intelligent Assistants · 📖 深度解读

    InitGen 面向用户尚未表达当次意图的助手首页，一次生成整组候选问题，以用户活跃度和下游排序分数加权 KTO，并每日滚动更新。OPPO 线上实验中，CTR 从 0.95% 升至 1.61%，作者报告相对提升 69.1%，候选曝光增加 17.9%；整组生成控制在 180 毫秒内。

    出现于日报：09-15

  9. 9. ReliGRec: Reliability-Oriented LLM-Based Generative Recommendation via User-Risk-Aware Prompt Routing

    针对用户行为突变或重复导致生成式推荐不稳定的问题，ReliGRec 融合时序图与行为序列，用评论反馈构建弱风险标签，并据此切换提示模板。模型采用 Qwen2.5-1.5B 与语义 ID 约束生成；Beauty 的 NDCG@10 从 LETTER-TIGER 的 0.03100 升至 0.03698，但 Yelp 为 0.01701，略低于基线 0.01714。

    出现于日报：09-17

  10. 10. Recommendation Retrievers Need Verifiers: Universal Generative Reranking for Sequential Recommendations

    论文冻结原有召回器，增加两层轻量生成式验证器，用物品标识符的条件似然重排候选，再与原召回顺序融合。Amazon Industrial 与 Office 上，SASRec 的 Recall@10 分别相对提升 6.2% 和 9.9%；MiniOneRec 的提升为 2.6% 和 4.6%，说明强生成式召回也可受益。

    出现于日报：09-15
