2026-08-10 ~ 08-16 · 智能体搜索

  1. 1. Search-G1: Grounded Search Agents via Representation-Based Intrinsic Rewards

    Search-G1 面向搜索增强智能体的“是否需要检索、检索证据是否真正被使用”问题，提出两个经过干预校准的表示读出：提示状态读出估计闭卷可答性，答案提交读出通过删除证据测量依赖度。论文在多个搜索问答基准和两种模型规模上验证，可在无需过程标注或 LLM 裁判的情况下改善 grounding—搜索成本权衡，并缩短回答轨迹。

    出现于日报：08-12

  2. 2. SearchGym: Bootstrapping Real-World Search Agents via Cost-Effective and High-Fidelity Environment Simulation · 📖 深度解读

    论文针对搜索 Agent 强化学习依赖昂贵在线 Web API、离线快照又会产生数据错配和错误奖励的问题，构建了可验证知识图谱与对齐文档语料的 SearchGym 环境。SearchGym-RL 以课程学习逐步训练从基础交互到长程规划的策略；Qwen2.5-7B-Base 在九个基准上相对超过 Web 增强 ASearcher 10.6%，说明高保真模拟可以支撑低成本搜索 Agent 训练。

    出现于日报：08-10

  3. 3. DocAtlas: Long-Document Understanding as Mutable-State Interaction

    DocAtlas 把长文档问答建模为可变状态的信息寻路过程，外部 harness 提供搜索、阅读、记笔记和复核工具，并维护层级树与证据笔记。GPT-5.4 在 MMLongBench-Doc 上达到 71.4%，超过人类专家参考的 65.8%；经端到端 RL 训练的 Qwen3.5-4B VLM 达到 63.7%，高于直接输入基线的 54.4%。

    出现于日报：08-12

  4. 4. FitText: Evolving Agent Tool Ecologies via Memetic Retrieval

    FitText 将工具选择视为有预算的测试时检索，让智能体在执行中生成、改写和进化伪工具描述，从而修复初始 query 找不到正确 API 的问题。StableToolBench 的 16,464 个 API 上，Memetic FitText 达到 84.3% pooled pass rate，较静态检索提升 26.7 个百分点；40 路并发时批处理墙钟时间仅为 Single-Pass 的 1.01 倍。

    出现于日报：08-12

  5. 5. VDGR-RAG: Vectors, Directories, Graphs, and Reflection Are All You Need for Unified Reasoning over Hierarchical Enterprise Knowledge

    VDGR-RAG 面向层级企业知识，统一向量检索、目录路由、图遍历和迭代反思。系统先从文档 chunk 构建保留目录与语义关系的层级异构知识图，再组合目录增强路由、多路检索、目录回溯和动态反思四类原子工具；在四个无线通信领域的产品文档上，检索召回与 QA 准确率均超过多种 RAG 基线。

    出现于日报：08-12

  6. 6. LLM within MCP Matters: Measuring Inefficient Resource Utilization Driven by LLMs

    论文研究 MCP 中“把参考数据写进系统提示”与“让模型调用搜索工具”之间的资源利用冲突，基于生产法律信息 MCP 服务开展 54,000 次试验，覆盖 24 个模型（9 Claude、6 Gemini、9 GPT）。无搜索工具时 24 个模型中 23 个对 embedding 数据达到至少 98% 命中；提供搜索工具后，模型会偏好重新搜索而浪费已有上下文。

    出现于日报：08-12

  7. 7. QueryAgent-R1: Bridging Query Generation and Product Retrieval for E-Commerce Query Recommendation

    论文针对推荐 query 的点击率与后续商品转化脱节问题，提出带记忆的 QueryAgent-R1：先生成 query，再调用真实商品检索验证结果，并用一致性奖励做 Agentic RL。它在两个离线数据集上提升端到端 Cons@1，线上 1% 流量、7 天 A/B 测试使 Query CTR 提升 2.9%、guided CVR 提升 3.1%，GMV 提升 4.9%。

    出现于日报：08-14

    出现于日报：08-13

  9. 9. LLMRouter: Unified Infrastructure for Developing, Evaluating, and Deploying LLM Routers

    论文把 LLM 路由统一建模为顺序决策过程，拆成上下文编码器、模型编码器、打分函数、决策规则和学习信号五个组件，并发布覆盖通用、记忆增强、视觉、时序和个性化任务的 xRouteBench。开源 LLMRouter 收录 16 个以上路由器；实验显示学习型路由相对最强固定模型基线提升 14.6%，紧预算下轻量路由更有竞争力。

    出现于日报：08-11
