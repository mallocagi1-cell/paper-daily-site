2026-08-17 ~ 08-23 · 智能体搜索

  1. 1. SkillGate: Training In-Policy Skill Selection in Long-Horizon Agents

    论文指出长程 Agent 选择技能时存在“选择器信用饥饿”：候选技能名称只占少量 token，却被整条轨迹的结果奖励淹没。SkillGate 将执行 token 的结果信用与技能选择 token 的局部优势分成两条通道，在 16 个候选技能的设置下，把 9B 策略的试验成功率从 40.8% 提升到 53.2%，误导性候选暴露减少三分之二。

    出现于日报：08-21

  2. 2. When Deep Research Agents Stagnate: Enhancing Reasoning with Retrieval-Aware Agent Control

    论文分析深度研究智能体的推理轨迹，发现大量迭代几乎不带来新信息，提出结合搜索新颖度与信息覆盖度的 Retrieval-Aware Agent Controller（RAAC）。在 BrowseComp-Plus 及多类深度研究智能体上，RAAC 平均减少 14 次搜索调用，准确率平均提升 3%，最高提升 10%。

    出现于日报：08-19

  3. 3. The Commercial Tax: Rent-vs-Own Blind Spots in Multi-Hop Retrieval Benchmarks

    论文审计多跳检索基准中常被忽略的商业许可和构建成本，并在统一 MuSiQue 测试框架中比较 8 家厂商的 13 个 embedding 模型。此前商用模型在 Recall@5 上落后 2.31 个百分点；2026 年 7 月发布的 Nemotron-3-Embed-8B 已缩小差距至 +0.24，差异不显著。

    出现于日报：08-19

  4. 4. Write, Execute, Refine: From Skill Followers to Skill Optimizers via Reinforcement Learning from Execution Feedback

    WER（Write, Execute, Refine）把工具型 Agent 的技能优化拆成多阶段流程：Skill Optimizer 提议自然语言技能，冻结的 Executor 重复执行，程序化验证器评分，再将成功与失败轨迹配对为下一阶段的 refinement 状态。论文指出，Agent 自写技能比不使用技能低 8–11 个百分点，WER 用执行反馈把改进目标从提示词修补转为可训练的相对信用分配。

    出现于日报：08-20

  5. 5. SPADE: Self-Play in Adaptive Synthetic Executable Environments

    SPADE 让同一个 LLM 同时担任环境设计者和推理 Agent：前者生成带 reset()/step()、状态转移、奖励与验证代码的长程环境，后者在其中学习工具调用。环境设计器依据“有无特权提示”的 regret 自适应制造接近能力边界的任务；在 30B 模型上，八个留出基准平均提升 5.3，BFCL-v4 多轮工具调用提升 5.7，ACEBench-Agent 提升 13.9。

    出现于日报：08-21

  6. 6. Can David Beat Goliath? On Multi-Hop Reasoning with Resource-Constrained Agents

    论文针对低资源 RL 训练多跳搜索 Agent 时有效轨迹稀少的问题，提出 David-GRPO。方法把少量专家轨迹引入更新，并把部分成功轨迹转成证据覆盖分数来继续扩展；在最多 1.5B 参数、4 张 RTX 3090 的训练预算下，于 6 个多跳问答基准优于同预算 RL 基线，并学会增加检索深度与证据覆盖。

    出现于日报：08-21

  7. 7. The Recall Trap: A Recall-Maximizing Retriever Configuration Reduces Issue Resolution in Fixed-Budget Code Context

    论文在 SWE-bench Verified 中研究固定 12 槽上下文预算下的检索配置，发现提高 Recall@K 不一定提高任务成功率。关闭按文件去重后，gpt-5.6-sol 单次修复率从 39.2% 升到 46.8%（+7.6 个百分点），Qwen3.6-27B 复现提升 3.6 个百分点。

    出现于日报：08-19

  8. 8. FM-Bench: A Benchmark for Long-Horizon Management with Competing Agents

    FM-Bench 用确定性足球经营引擎评估 Agent 的长程决策：一个 Agent 要管理 20 个赛季、调用 26 个工具并经历约 340–400 个决策节点，最终由引擎累计得分而非 LLM 评审。基准覆盖 15 个前沿模型、单机与共享 Arena 两种赛制及 6 类行为能力；结果显示模型排序往往到长时域后期才稳定，规模、价格和厂商不能解释排名。

    出现于日报：08-21

  9. 9. Plan Before Search: Search Agents Need Plan

    Plan 让搜索 Agent 在第一次检索前先把问题拆成有序子问题，使每步搜索锚定既定目标，减少被部分相关文档带偏。作者在 3B–14B 的三个模型家族上发现相同奖励会产生不同 RL 失败模式，并用小模型筛选轨迹自举，在多跳问答基准上稳定超过基线。

    出现于日报：08-19

  10. 10. SkillForge: Self-Distilling Agents for Project-Specific Issue Resolution

    SkillForge 不等真实问题出现后才学习，而是从仓库中测试覆盖的核心功能合成项目特定问题，Agent 先解决这些问题，再把经验蒸馏为绑定实体的可复用技能。论文在开源与闭源模型上均报告相对强基线的持续改进，重点解决 Agent 缺少项目上下文以及逐问题探索成本过高的问题。

    出现于日报：08-21
