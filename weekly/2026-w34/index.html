  1. 1. Once Generated, Ranked: End-to-End Generative Slate Recommendation with Unified Semantic-Collaborative IDs · 📖 深度解读

    论文把推荐单位从单个物品提升为完整 slate，提出端到端生成排序框架 OGR。TUSID 将物品语义信息与局部协同信号融合为层次化 Semantic ID，SPA 再用奖励引导的保守策略优化对齐列表效用，并通过位置级流水线解码建模物品间依赖。在工业数据和公开数据上，NDCG@5 相对提升 48.2% 和 27.2%；快手线上 A/B 的 Effective Views 提升 1.120%。

    出现于日报：08-20

  2. 2. GEM: A Generative Embedding Model Bridging Reasoning and Retrieval · 📖 深度解读

    GEM 将“理解查询”和“生成向量”合并到一个因果语言模型中：模型先生成用户意图与相关性标准，再用专用 embedding token 编码查询，并与文档向量做对比学习。在 BRIGHT 上平均 nDCG@10 达 29.1，同骨干的非生成版本在定理任务上从 19.8 提升到 32.0；FollowIR 的 p-MRR 为 +11.7，较同骨干基线 +6.8 明显更高。

    出现于日报：08-18

  3. 3. From Token Generation to Item Ranking: Direct Generative Recommendation with Semantic IDs · 📖 深度解读

    论文指出 Semantic ID 逐 token 解码并不等价于 item-level 排序：若 token 接口信息不足，无法恢复精确排序；若信息充分，解码又退化为直接打分。基于这一二分结论，DiGR 将 Semantic ID 保留为物品表示，改用统一的用户—物品打分函数，并在多个真实数据集和不同规模 LLM 骨干上超过既有生成式与 ID 方法。

    出现于日报：08-19

    出现于日报：08-20

  5. 5. SIDScope: A Diagnostic Resource for Semantic-ID Interfaces in Generative Recommendation · 📖 深度解读

    论文提出SIDScope，用于系统诊断生成式推荐中的Semantic ID接口。它统一规范item-to-code映射、校验来源与连接关系、分析前缀结构，并追踪生成路径能否解析到候选物品；在Amazon与Yelp的9组tokenizer导出、7个家族上发现，接口健康度不是单一指标，前缀对齐在前缀检索时更能预测候选暴露。

    出现于日报：08-21

  6. 6. Semantic Trimming and Auxiliary Multi-step Prediction for Generative Recommendation · 📖 深度解读

    生成式推荐把每件商品拆成几个 Semantic ID 码之后，用户历史一下子长了好几倍，训练又慢又占显存，而多出来的码里很多是重复的类目和品牌。STAMP 让模型先跑一两层，再按每个码自身的激活强度和被其他码关注的程度打分，只把高分的码交给后面的层；训练时再加一个多预测一个码的辅助目标，补回剪掉的信息。在 Amazon 三个数据集上，训练快了 1.36 倍以上，峰值显存省了一半多，效果和原模型持平…

    出现于日报：08-21

  7. 7. Noesis: Bidirectional Graph-RAG with Adaptive Parallelism and Cross-Knowledge-Base Semantic Discovery

    Noesis 为 Graph-RAG 设计双向图遍历、基于 AIMD 的并发控制、面向 MoE 的选择性量化和跨知识库语义路由。实验在 1,000 个 HotpotQA 问题上达到 59.5 EM/74.7 F1，较 GraphRAG 提升 27.8 个 EM 点；并实现 23 倍并行加速、6.3 倍量化推理加速且无 OOM。

    出现于日报：08-19

  8. 8. Rich-Media Re-Ranker: A User Satisfaction-Driven LLM Re-ranking Framework for Rich-Media Search

    Rich-Media Re-Ranker 面向多意图富媒体搜索，先用 Query Planner 拆解会话中的 query refinement，再融合文本、视觉和信息增益等信号进行整体重排。视觉信号由 VLM evaluator 生成，并通过多任务强化学习提升场景适应性；论文报告已部署到大规模工业搜索系统，线上用户参与度和满意度均有提升。

    出现于日报：08-19

  9. 9. APAO: Bridging the Training-Inference Gap in Generative Recommendation via Adaptive Prefix-Aware Optimization · 📖 深度解读

    APAO 针对生成式推荐训练采用 teacher forcing、推理却采用 beam search 所造成的前缀错配：正确物品可能因早期 token 概率低而提前出局。方法加入 prefix-level 优化损失，并动态聚焦最脆弱的 worst prefix；论文在多个生成式推荐骨干上验证效果，实验使用 batch 1024、beam size 20 和单张 A100，并被 KDD 2026 接收。

    出现于日报：08-17

  10. 10. GEO-Flag: Detecting and Measuring GEO-Optimized Web Content

    GEO-Flag 构建 GEOFlagBench，覆盖 3,200 个网页、400 个 query、4 个领域和 8 类优化器。干预配对训练将 ModernBERT 的 F1 从 0.862 提升到 0.944，最差组准确率从 0.725 提升到 0.883；在 10,095 个真实页面上估计 GEO 渗透率为 8.90%，2026 年修改页面中达到 16.36%。

    出现于日报：08-19
