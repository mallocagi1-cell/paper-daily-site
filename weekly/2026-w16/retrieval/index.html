  1. 1. NSFL: A Post-Training Neuro-Symbolic Fuzzy Logic Framework for Boolean Operators in Neural Embeddings

    标准稠密检索器缺乏对多条件布尔查询（AND/OR/NOT）的原生支持。本文提出 NSFL 框架，将模糊逻辑中的 t-norm 和 t-conorm 适配到神经 embedding 空间，无需重训模型即可实现布尔逻辑运算。核心创新是引入 Neuro-Symbolic Delta（NS-Delta）一阶边际差分来引导表征调整，避免传统几何方法中的表征坍塌问题…

    出现于日报：04-15

  2. 2. CMedTEB & CARE: Benchmarking and Enabling Efficient Chinese Medical Retrieval via Asymmetric Encoders

    LLM 级别的 embedding 模型虽然检索能力强，但推理延迟和计算成本限制了实时场景应用。本文构建了中文医疗文本 embedding 评测基准 CMedTEB，涵盖检索、重排序和语义相似度三类任务，通过多 LLM 投票管线并经临床专家验证确保标签质量。在此基础上提出非对称检索架构 CARE，使用轻量 BERT 编码器处理查询端，LLM 编码器处理文档端，在保证检索精度的同时大幅降低在线推理延迟。

    出现于日报：04-15

  3. 3. Masking or Mitigating? Deconstructing the Impact of Query Rewriting on Retriever Biases in RAG

    针对 RAG 系统中稠密检索器存在的简短偏差、位置偏差、字面匹配偏差和重复偏差等系统性问题，本文首次系统性地研究了查询增强技术对检索器偏差的影响。通过在多个检索器上的实验，发现基础 LLM 改写可将偏差降低 54%（通过增加分数方差），而文档生成方法则通过特征去相关机制起效。研究表明没有单一方法能在所有检索器上一致解决所有偏差类型，并区分了查询-文档交互偏差和文档编码偏差两类根本不同的问题。论文已被 ACL 2026 录用。

    出现于日报：04-14

  4. 4. ARHN: Answer-Centric Relabeling of Hard Negatives with Open-Source LLMs for Dense Retrieval

    稠密检索器训练依赖三元组数据（query、正例、硬负例），但硬负例挖掘常引入假负例和歧义负例，导致监督信号不一致、检索效果下降。本文提出 ARHN 框架，利用开源 LLM 通过两阶段方式精炼硬负例：第一阶段让 LLM 为每个 query-passage 对生成基于段落的答案片段或标记为不支持；第二阶段通过 LLM 基于 listwise 排序对候选集按直接可回答性重新排列。排在原正例之上的段落被提升为正例，从而修正标签噪声。

    出现于日报：04-15

  5. 5. Reproduction Beyond Benchmarks: ConstBERT and ColBERT-v2 Across Backends and Query Distributions

    对 ColBERT-v2 和 ConstBERT 进行五维度复现评估，发现 ConstBERT 在 MS-MARCO 上 MRR@10 偏差仅 0.05%，但两者在长叙事查询（TREC ToT 2025）上性能下降 86-97%。消融实验证明这是架构性缺陷：MaxSim 算子的均匀 token 加权在超过 20 词后无法区分信号与噪声。此外，未文档化的后端参数导致 8 个点的性能差距，3 倍数据量的微调反而使性能下降最高 29%…

    出现于日报：04-15

  6. 6. Align then Train: Efficient Retrieval Adapter Learning

    针对稠密检索中查询编码器复杂度与文档索引效率不匹配的问题，提出 ERA（Efficient Retrieval Adapter）框架。该方法分两阶段训练检索适配器：首先通过自监督对齐将大型查询编码器与轻量文档编码器的 embedding 空间对齐，然后在少量标注数据上进行有监督适应。在 MAIR 基准（覆盖 126 个检索任务、6 个领域）上，ERA 在低标注场景下显著提升了检索效果，同时避免了对文档库的重新索引。

    出现于日报：04-13

  7. 7. MultiDocFusion: Hierarchical and Multimodal Chunking Pipeline for Enhanced RAG on Long Industrial Documents

    MultiDocFusion 提出了一种面向长文档的多模态分块管线，集成视觉文档解析、OCR 文本提取、LLM 层级结构重建和 DFS 分组四个阶段，将文档内容组织为层级结构化 chunk。在工业基准测试中，该方法将检索精度提升 8-15%，ANLS QA 分数提升 2-3%，证明了显式利用文档层级结构对检索质量的关键作用。

    出现于日报：04-16

  8. 8. Hybrid Retrieval for COVID-19 Literature: Comparing Rank Fusion and Projection Fusion with Diversity Reranking

    本文提出一套面向 COVID-19 科学文献的混合检索系统，在 TREC-COVID 基准（171,332 篇论文、50 个专家查询）上进行评估。系统实现六种检索配置，涵盖稀疏检索（SPLADE）、稠密检索（BGE）、排名级融合（RRF）和基于投影的向量融合（B5）方法。RRF 融合在相关性上表现最优（nDCG@10 = 0.828），超越纯稠密检索 6.1%、纯稀疏检索 14.9%…

    出现于日报：04-17

  9. 9. Beyond Factual Grounding: The Case for Opinion-Aware Retrieval-Augmented Generation

    该论文指出当前 RAG 系统存在「事实偏见」——将观点和多元视角视为噪声而非有价值信息，导致在社交媒体讨论、产品评论等主观内容场景下表现不佳。作者从不确定性视角形式化了这一局限：事实查询涉及可通过证据消减的认知不确定性，而观点查询涉及反映真实多元性的偶然不确定性。论文系统分析了当前 RAG 基准和数据集的客观性偏向，并提出了面向观点感知的检索增强生成框架。

    出现于日报：04-16

  10. 10. The Effect of Document Selection on Query-focused Text Analysis

    该论文系统评估了 7 种文档选择策略（从随机选择到混合检索）在 4 种文本分析方法（LDA、BERTopic、TopicGPT、HiCode）和 2 个数据集、26 个开放式查询上的效果。核心发现：语义检索或混合检索是可靠的通用方案，既避免了弱策略的陷阱，又减少了复杂策略的不必要计算开销。该研究将数据选择从「实际权宜」提升为「方法论决策」。

    出现于日报：04-16
