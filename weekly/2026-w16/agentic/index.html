  1. 1. HiPRAG: Hierarchical Process Rewards for Efficient Agentic Retrieval Augmented Generation

    针对 Agentic RAG 中普遍存在的过度检索（检索已知信息）和不足检索（遗漏必要检索）问题，提出 HiPRAG 方法。该方法在 RL 训练中引入层级化过程奖励（Hierarchical Process Reward），将 agent 的推理轨迹分解为可解析的离散步骤，在每步检索决策点评估其必要性，从而实现细粒度的搜索行为优化。实验表明 HiPRAG 在多个 QA 基准上显著降低冗余检索次数的同时提升回答准确率。

    出现于日报：04-15

  2. 2. Do We Still Need GraphRAG? Benchmarking RAG and GraphRAG for Agentic Search Systems

    提出 RAGSearch 统一基准，系统性评估稠密 RAG 与 GraphRAG 在 agentic search 系统下的表现差异。核心发现：当引入动态多轮检索和序列决策的 agentic 搜索能力后，标准 RAG 的性能大幅提升，GraphRAG 所带来的显式图结构优势被显著削弱。这一结论对搜索架构选型有重要参考价值，表明在多数场景下无需承担构建 GraphRAG 管线的高昂成本。

    出现于日报：04-15

  3. 3. HTAA: Enhancing LLM Planning via Hybrid Toolset Agentization & Adaptation

    针对 LLM agent 大规模工具调用中的效率和错误累积问题，提出 HTAA 层级化工具使用框架。核心思路是将高频共现工具封装为专门的 agent 工具（Toolset Agentization），缩小 planner 的动作空间；并通过非对称 planner 适配（Asymmetric Planner Adaptation）实现高层 planner 与 agent 工具的对齐…

    出现于日报：04-15

  4. 4. Self-Correcting RAG: Enhancing Faithfulness via MMKP Context Selection and NLI-Guided MCTS

    提出 Self-Correcting RAG 框架，将 RAG 的检索和生成重新建模为约束优化与路径规划。输入端首次将上下文选择形式化为多维多选背包问题（MMKP），在严格 token 预算下最大化信息密度并消除冗余；输出端引入自然语言推理（NLI）引导的蒙特卡洛树搜索（MCTS），在推理时动态探索推理轨迹并验证答案忠实度。在 6 个基准上的实验表明该方法显著提升了 RAG 的准确性和忠实度。

    出现于日报：04-15

  5. 5. AgentWebBench: Benchmarking Multi-Agent Coordination in Agentic Web

    提出 AgentWebBench 基准，评估 Agentic Web 新范式下的多 agent 协调能力。在该范式中，内容提供方部署自己的 agent 管理数据并通过受控接口提供服务，信息获取从集中式检索转向去中心化协调。覆盖四类任务：网页搜索、网页推荐、问答和深度研究。在 7 个先进 LLM 和 3 种协调策略上的评估表明，多 agent 协调整体落后于集中式检索，但差距随模型规模缩小，部分场景甚至可以超越集中式方案。

    出现于日报：04-15

    出现于日报：04-15

  7. 7. Deep-Reporter: Deep Research for Grounded Multimodal Long-Form Generation

    出现于日报：04-15

  8. 8. Controllable and Verifiable Tool-Use Data Synthesis for Agentic Reinforcement Learning

    提出 COVERT 两阶段管线，解决工具使用 agent 的 RL 训练缺乏可执行环境的痛点。第一阶段通过自演化合成生成可靠的基础工具使用轨迹，结合多层验证；第二阶段应用保留 oracle 的增强策略，系统性增加环境复杂度（干扰工具、模糊查询、噪声/多格式工具输出），同时严格保留 oracle 工具调用和最终答案作为 ground truth。在 Qwen2.5-Instruct-14B 上的实验证明该方法有效提升工具调用策略。

    出现于日报：04-15

  9. 9. How You Ask Matters! Adaptive RAG Robustness to Query Variations

    首次大规模评估 Adaptive RAG 对查询表述变化的鲁棒性。构建了包含人工和模型生成的语义等价查询变体基准，从三个维度系统评估：回答质量、计算成本和检索决策。核心发现：查询表面形式的微小变化会剧烈改变 Adaptive RAG 的检索行为和准确率，暴露出严重的鲁棒性缺口。即使模型规模增大，虽性能提升但鲁棒性并未相应改善。

    出现于日报：04-15

  10. 10. VISOR: Agentic Visual Retrieval-Augmented Generation via Iterative Search and Over-horizon Reasoning

    VISOR 解决了 agentic 视觉检索增强生成(VRAG)中的两个关键瓶颈:视觉证据稀疏性和短视推理问题。该方法通过跨页面推理和超视野规划机制,在多步迭代检索中实现了更精准的证据聚合。在多个视觉文档问答基准上,VISOR 显著优于现有 agentic VRAG 系统。

    出现于日报：04-14
