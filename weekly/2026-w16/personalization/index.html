  1. 1. IAT: Instance-As-Token Compression for Historical User Sequence Modeling in Industrial Recommender Systems · 📖 深度解读

    针对工业推荐系统中用户历史序列建模的信息瓶颈问题，提出 Instance-As-Token (IAT) 两阶段压缩框架。第一阶段将每次交互的全部特征（约6000维）压缩为64维统一实例 embedding，支持时序和用户两种压缩模式；第二阶段通过标准序列建模学习长程偏好模式。在字节跳动的电商广告、商场营销、直播电商等多个真实场景部署，AUC 提升 +0.31%，广告主分数在线 A/B 提升 +1.557%，GMV 提升 +0.151%。

  4. 4. GRADE: Personalized Multi-Task Fusion via Group-relative Reinforcement Learning with Adaptive Dirichlet Exploration · 📖 深度解读

    针对推荐系统多任务融合中'一刀切'权重无法适配异质用户群体的问题，提出 GRADE 个性化多任务融合框架。通过组相对强化学习将用户分组并为各组学习个性化融合策略，结合自适应 Dirichlet 探索平衡探索与利用。在快手应用内搜索场景全量上线，日活用户数亿级，A/B 实验取得 CTR +0.595%、CVR +1.193%、OPM +1.788%、订单量 +1.568% 的显著提升。

    出现于日报：04-14

  5. 5. SID-Coord: Coordinating Semantic IDs for ID-based Ranking in Short-Video Search · 📖 深度解读

    针对短视频搜索排序中哈希 ID（HID）模型在长尾 item 上泛化能力差的问题，提出 SID-Coord 框架，将可训练的离散 Semantic ID（SID）直接嵌入 ID-based 排序模型。SID 通过残差量化从多模态内容中学习，配合 SID-HID 协调损失实现语义泛化与行为记忆的平衡。该方法在大规模短视频搜索系统中部署，离线指标和线上 A/B 测试均有显著提升。

    出现于日报：04-15

  6. 6. xMTF: A Formula-Free Model for Reinforcement-Learning-Based Multi-Task Fusion in Recommender Systems

    针对推荐系统多任务融合（MTF）中现有 RL 方法受限于预定义公式形式的问题，提出 xMTF 无公式 MTF 框架。利用 Sprecher 表示定理证明任意融合函数可分解为单变量单调函数的组合，从而将搜索空间从有限的公式参数扩展到任意函数空间。结合两阶段混合（TSH）训练策略有效训练。在快手平台部署，服务超 1 亿用户，离线实验总观看时长较最强基线提升约 7%。

    出现于日报：04-14

  10. 10. Is Sliding Window All You Need? An Open Framework for Long-Sequence Recommendation

    该工作证明了在学术级别的计算资源上进行长序列推荐训练不仅可行而且有效。发布了完整的端到端框架，包含数据处理、训练和评估全套脚本，实现了工业级的滑动窗口长序列训练。主要贡献包括：(1) 运行时感知的消融实验，量化了不同窗口大小和步幅下的精度-计算前沿；(2) k-shift embedding 层，以极小的精度损失支持百万级词表在消费级 GPU 上训练。实验取得了 MRR +6.04%、Recall +6.34% 的提升。
