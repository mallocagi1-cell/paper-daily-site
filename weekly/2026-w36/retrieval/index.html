  1. 1. Staged Linguistic Seeding: Grounded Query Expansion for Verified-Unit QA in AI Contact Centers

    论文面向电话客服中低延迟且错误代价高的封闭式问答，提出分阶段语言播种 SLS：由人工为每个已验证问答单元编写槽位配方，再用 GPT-4.1-mini 离线生成变体并轻量审核，线上只需一次检索。两个工业领域的混合检索 R@1 达 0.881/0.930，分别提升 0.27/0.34；同等生成预算下比 doc2query 高 0.20/0.32。

    出现于日报：09-03

  2. 2. Mine and Refine: Optimizing Graded Relevance in E-commerce Semantic Search Retrieval

    论文聚焦电商语义召回中的分级相关性、难负例误标和不同相关等级分数不可分三类问题。方法先用经行为数据审计微调的轻量 LLM 生成符合业务规范的多级标签，以标签感知监督对比学习建立全局空间；再挖掘难样本、重新标注，并用多级 circle loss 细化相似度分布，使召回分数更适合后续融合与排序。

    出现于日报：09-01

  3. 3. Closed Forms and Synthetic Twins: Predicting Approximate Nearest Neighbor Recall from Embedding Statistics

    论文指出向量模型的离线精确检索指标无法预示 HNSW、IVF、PQ 或 late-interaction FDE 索引中的真实召回，某现代编码器经原始 FDE 索引仅恢复精确 Top-10 的 14%。作者用原始向量的无标签统计量、固定网格量化的闭式矩以及保持簇统计的“合成孪生”语料，在建索引前预测不同索引族的召回行为。

    出现于日报：09-03

  4. 4. The Vocabulary Gap Is an Equity Gap: Register Mismatch in Retrieval Systems for Public-Benefits Access

    论文研究用户口语化查询与政府公文表述不一致造成的检索失效，在 51 条福利规则、25 类信息需求上构造同义双版本查询。BM25 的 Recall@5 从正式语体的 100% 跌至口语语体的 44%，而可审计的词汇桥接将其恢复到 80%。

    出现于日报：09-04

  5. 5. Learning from What You Retrieve: Online RL Fine-Tuning for Semantic Retrieval

    论文针对电商双塔召回与下游重排偏好不一致的问题，提出仅更新正优势样本的 PAO 在线强化学习方法。在文档索引冻结的工业约束下，它只把查询向量拉向高奖励区域，避免常规策略梯度推离负样本时破坏预训练语义流形，并以重排器反馈直接优化端到端检索质量。

    出现于日报：09-02

  6. 6. PULSAR: Pooled Unified Late-Interaction Search and Retrieval for Enterprise Visual Document RAG

    针对高频更新的投研演示文稿、董事会材料等视觉文档，PULSAR 以冻结的 ColPali 风格骨干直接索引页面图像，并用紧凑页级摘要做首轮召回、细粒度池化表示做 MaxSim 精排。ViDoRe V3 上中位检索延迟降低 15.1 倍，nDCG@10 与 Recall@10 损失均低于 0.01；生产延迟为 156 毫秒，并发吞吐提升约 88 倍。

    出现于日报：09-01

  7. 7. MIDR: Enrichment-Augmented Indexing for Multimodal Document Retrieval

    MIDR 解决 OCR 会丢失表格、图表和版面关系的问题，把多模态推理从查询时搬到索引时：多模态 LLM 将页面转成经验证的结构化文本字段，再由 BM25F 建索引并可与稠密检索融合。ViDoRe V3 五个英文领域的平均 nDCG 达 0.6219，比 BM25 相对提升 23.0%，同时保持纯文本在线服务路径。

    出现于日报：09-03

  8. 8. Retrieved but not ranked: surface-form bias in structural retrieval, from mathematics to agent trajectories

    论文刻意分离表面措辞与底层结构，在 500 个数学查询、117,088 条语料及 118 个代理查询上审计生产级向量模型。最强伪装条件下，两种模型的严格 Hit@1 均为 0%，但正确项几乎总在 Top-10；95.2%–99.8% 的错误中，首位结果只是与查询字面更相似，证明问题主要出在排序而非召回。

    出现于日报：09-03

  9. 9. Hybrid Retrieval-Augmented Generation with Knowledge Graph Expansion, RRF Fusion, and Per-Chunk Grounded Evaluation for Enterprise Document Search

    DocuSearch 面向电信生产文档搜索，将 BGE-Large 向量召回、BM25 与知识图谱扩展按 0.50/0.35/0.15 权重进行 RRF 融合，再经 cross-encoder 重排和 MMR 去冗余。相对纯稠密 RAG，Precision@10、Recall@10 与有依据回答率分别达到 0.69、0.79 和 89.6%，提升 15、16 与 18.4 个百分点。

    出现于日报：09-04

  10. 10. ProRetrieval: Learning to Orchestrate Hybrid Search via Executable Program Synthesis · 📖 深度解读

    论文把混合检索从固定融合流程改写为可执行程序合成：Qwen3-4B 根据自然语言查询生成同时包含 SQL 结构化约束、文本与图像向量检索的领域专用程序，并用 SQL 逻辑代数组合候选集。模型经 GRPO 与 DAPO 训练，在亚马逊商品和 Enron 邮件基准上的 Hit@1 分别达到 0.81、0.91，高于 GPT-5.5 的 0.69、0.86。

    出现于日报：08-31
