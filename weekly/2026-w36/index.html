2026-08-31 ~ 09-06 · 生成式推荐

  1. 1. ICEGR: An Intent-Coherent End-to-End Generative Retrieval Framework for E-commerce Search · 📖 深度解读

    针对电商生成式检索在 Semantic ID 构建、低曝光商品监督和偏好优化三个阶段出现的意图漂移，ICEGR 将查询意图贯穿 SID、统一 SFT 与相关性校准偏好学习。离线 Recall@20 提升 21.7%、NDCG@20 提升 26.6%；百度线上 A/B 中 CTR、订单量和 GMV 分别相对提升 3.52%、15.96% 和 7.53%。

    出现于日报：09-02

  2. 2. SPAR: Enhancing Industrial-Scale Generative POI Recommendation via Real-World Spatial Perception · 📖 深度解读

    论文面向工业级生成式 POI 推荐，指出仅依赖行为序列和协同信号生成 Semantic ID，会让结果兴趣相符却远离用户实时位置。SPAR 从 Semantic ID 构造、空间知识学习与生成保持三个阶段显式注入距离、方向和可达性，使生成目标同时满足偏好与真实城市空间约束。

    出现于日报：09-04

  3. 3. hLLM: Single Pass Decoding for Generative Reranking

    hLLM 针对生成式排序逐 token 解码的时延瓶颈，把输出看成候选与名次之间的排列分配问题。模型从预填充隐状态一次性读出 N×K 的位置得分矩阵，再用匈牙利算法求最优匹配，从而以 O(1) 次前向传播生成合法全排列，避免自回归解码及事后修复。

    出现于日报：09-04

  4. 4. Preference Shapes Relevance: Cross-component Hierarchical Semantic Alignment for Personalized Generative Retrieval

    CHAP 解决内容生成的静态 SID 与动态查询、用户偏好不对齐，以及自回归 beam search 延迟过高的问题。它用分层语义对齐同步 query 与量化路径，以离散 SID 提供结构约束、连续表示补充细粒度语义，并以 Residual Cascading Generation 将多步解码压缩为单次推理；论文在 3 个公开集、1 个工业集及线上 A/B 中验证。

    出现于日报：09-02

  5. 5. PRQ-KMeans: Projection Residual Quantization for Semantic ID Tokenization · 📖 深度解读

    论文针对生成式检索与推荐中 Semantic ID 的残差量化缺陷，提出 PRQ-KMeans：先移除全局均值，再用 Top-k 相似度加权更新质心，并以投影残差替代完整码字相减。该方法在一个工业搜索数据集和四个公开推荐基准上总体最优，工业场景 HitRate 最高提升 7.4%，MRR 最高提升 11.8%。

    出现于日报：08-31

  6. 6. It Takes Two to Match: Co-Evolving Generative Retriever with Reinforcement Learning · 📖 深度解读

    针对现有 LLM 检索通常只增强 query、最终匹配仍依赖下游检索器的问题，论文提出 CoGR，让查询端与物品端生成器共同产出紧凑关键词并直接通过倒排索引匹配。模型先监督微调对齐关键词空间，再用交替 GRPO 协同进化；在应用市场数据与 WANDS 上，相对最强基线的 F1 分别提升 10.9% 和 36.1%。

    出现于日报：09-03

  7. 7. Difficulty-Aware Semantic-ID Optimization for Generative Recommendation · 📖 深度解读

    针对 Semantic ID 生成式推荐中 GRPO rollout 常错过目标分支、组内奖励退化的问题，DASO 在线统计前缀匹配深度，在瓶颈层分配有限的目标前缀引导，并加入分级 SID 奖励和 SFT 锚点。两类 Amazon 数据上优于 MiniOneRec 式 GRPO 的 11/12 项指标，3B 模型在 Office 的 HR@5 从 0.1313 提升到 0.1683。

    出现于日报：09-01

  8. 8. RecEvolve: A Knowledge-Driven Autonomous Agent System for Recommender Systems

    RecEvolve 将推荐模型研究的构思、代码实现、离线训练和指标评估交给知识驱动的闭环智能体，并直接在生产级双塔召回模型上验证。系统从零完成 40 余次自主训练，识别并突破隐藏架构瓶颈，使 NDCG 相对提升约 20%，线上用户满意度进一步提升 3.77%。

    出现于日报：09-04

  9. 9. MERGED: Multimodal Entity Resolution via Generated Expert Reasoning Distillation

    MERGED 解决电商多模态实体消歧规则频繁变化、人工标注慢且缺少推理依据的问题。多个大视觉语言模型同时为商品对生成标签和结构化理由；一致样本用于监督微调，分歧样本经元评审器转成 DPO 偏好对，再把判断能力蒸馏到 7B 学生模型，全程无需人工标注。

    出现于日报：09-04

  10. 10. Generative Retrieval for E-commerce: Jointly Learning Embedding and Codebook with Same Product Cluster

    论文针对先训练商品 embedding、再学习 codebook 的级联方案容易累积表征误差且忽略 query-product、product-product 交互的问题，提出联合训练 embedding 与 codebook，并加入同商品簇监督。该设计让向量空间和离散 ID 同时朝检索目标收敛，实验报告电商检索、embedding 质量与 codebook 学习均显著改善，但摘要未披露具体增幅。

    出现于日报：09-02
