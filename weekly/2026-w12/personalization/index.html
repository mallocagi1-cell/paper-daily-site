2026-03-16 ~ 03-22 · 个性化推荐

  1. 1. Deploying Semantic ID-based Generative Retrieval for Large-Scale Podcast Discovery at Spotify · 📖 深度解读

    Spotify 提出 GLIDE，一个生产级 Semantic ID 生成式推荐系统，用于播客发现场景。系统将 LLM 的语义推理能力与用户级个性化结合，通过 Semantic ID 表示物品并实现目录锚定生成，解决了 LLM 推荐系统中的幻觉、延迟和个性化三大落地难题。GLIDE 已在 Spotify 全量上线，服务于大规模播客推荐场景。

    出现于日报：03-20

  2. 2. Bridging Sequential and Contextual Features with a Dual-View of Fine-grained Core-Behaviors and Global Interest-Distribution · 📖 深度解读

    针对传统 CTR 模型将用户行为序列聚合为单一向量后再与上下文特征交互导致行为信息丢失的问题，提出双视角建模框架：一方面通过细粒度核心行为视角精准捕捉用户与候选物品的关键交互信号，另一方面通过全局兴趣分布视角建模用户整体偏好的宏观分布特征。该方法在保持计算效率的同时，避免了朴素逐行为交互带来的噪声问题，有效提升了对用户实时兴趣变化的感知能力。

    出现于日报：03-17

  3. 3. Deferred is Better: A Framework for Multi-Granularity Deferred Interaction of Heterogeneous Features · 📖 深度解读

    揭示了 CTR 预估中特征异构性（categorical vs numerical、稀疏 vs 稠密）被普遍忽视的问题：现有模型将所有特征同时输入交互层，导致低信息量特征注入噪声、掩盖高信息量特征信号，甚至引发模型坍缩。提出多粒度信息感知延迟交互框架（MGID），根据特征的信息密度分层引入交互，先让高信息量特征建立稳健表征，再逐步融入低信息量特征，从而学习更鲁棒的特征表征。

    出现于日报：03-17

  4. 4. A Unified Language Model for Large Scale Search, Recommendation, and Reasoning · 📖 深度解读

    Spotify 提出 NEO 框架，将预训练 decoder-only LLM 适配为无工具依赖的、目录锚定的统一搜索/推荐/推理生成器。NEO 使用 Semantic ID (SID) 表示物品，通过单一模型同时支持检索、推荐和推理三种行为，避免了工具编排的复杂性。系统能处理多类型实体和异构目录，在严格延迟约束下运行。

    出现于日报：03-20

  5. 5. HierarchicalKV: A GPU Hash Table with Cache Semantics for Continuous Online Embedding Storage

    NVIDIA 提出 HierarchicalKV (HKV)，首个支持缓存语义的通用 GPU 哈希表库，专为超大规模 embedding table 设计。HKV 采用缓存行对齐桶、行内评分驱动 upsert、双桶动态选择和三组并发四大机制，在 H100 GPU 上实现 3.9B key-value/秒的查找吞吐，并支持 HBM 之外的分层存储扩展。

    出现于日报：03-20

  6. 6. MBD: A Model-Based Debiasing Framework Across User, Content, and Model Dimensions · 📖 深度解读

    现代推荐系统通过聚合多种行为信号（如观看时长、循环播放率、评论概率）来排序候选内容，但这些信号存在异质性偏差——观看时长偏向长视频，循环播放率偏向短视频，评论概率偏向视频而非图片。MBD（模型驱动去偏）框架从用户、内容、模型三个维度系统性地建模和消除这些偏差，通过条件期望估计"内在信号"（independent of heterogeneous biases），使排序分更好地反映用户真实偏好…

    出现于日报：03-18

  7. 7. Taming the Long Tail: Efficient Item-wise Sharpness-Aware Minimization for LLM-based Recommender Systems

    首次系统研究 LLM 作为推荐系统主干时面临的长尾问题，发现存在两种不同类型的长尾效应：（i）先验长尾，继承自预训练语料的隐式偏差；（ii）数据长尾，源于推荐数据集的分布倾斜。分析表明两者的头部交集会产生更强的头部效应，但整体性能差异主要由数据长尾主导。提出高效的逐物品锐度感知最小化方法（Item-wise SAM），在不显著增加计算开销的前提下改善长尾物品的推荐表现。

    出现于日报：03-17

  8. 8. Learning Evolving Preferences: A Federated Continual Framework for User-Centric Recommendation

    提出 FCUCR，一种联邦持续推荐框架，解决联邦学习场景下用户偏好随时间演变导致的「时序遗忘」和「协作个性化弱化」问题。引入时间感知自蒸馏策略，在本地模型更新时隐式保留历史偏好；设计跨用户原型迁移机制，利用相似用户的知识丰富每个客户端的表征。框架在隐私保护的前提下实现了长期个性化。

    出现于日报：03-20

  9. 9. VLM2Rec: Resolving Modality Collapse in Vision-Language Model Embedders for Multimodal Sequential Recommendation

    提出 VLM2Rec 框架，将视觉-语言大模型 (VLM) 作为协同过滤感知的多模态编码器用于序列推荐。研究发现标准对比监督微调会加剧 VLM 的模态坍塌问题——优化被单一模态主导，另一模态退化。VLM2Rec 引入弱模态增强机制，确保视觉和语言模态的均衡利用，从而提升多模态序列推荐的准确性。

    出现于日报：03-20

  10. 10. Is Your LLM-as-a-Recommender Agent Trustable? LLMs' Recommendation is Easily Hacked by Biases (Preferences)

    提出 BiasRecBench，首个系统评估 LLM-as-a-Recommender 范式偏差漏洞的基准。覆盖论文评审、电商推荐和招聘三个高价值领域，构建了带有校准质量差距的偏差合成流水线，可定量衡量 LLM 推荐在偏好注入攻击下的脆弱性。实验揭示了当前主流 LLM 在推荐场景中的系统性偏差问题。

    出现于日报：03-20
