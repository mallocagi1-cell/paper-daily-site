2026-08-03 ~ 08-09 · 生成式推荐

  1. 1. LLM-Based Generative Retrieval for Snapchat Content Recommendation · 📖 深度解读

    论文面向 Snapchat 短视频推荐，构建已上线的 LLM 生成式召回系统 SnapLGR：先用多模态表征与 PPR 共参与对比学习生成低碰撞 SID，再通过持续预训练完成新词表语义落地，并以 SFT 学习用户行为序列。7 天线上 A/B 相对 TIGER 式基线带来观看时长 +0.37%、总停留时长 +0.09%，离线 Recall@32 提升 2.40 倍。

    出现于日报：08-03

  2. 2. Recall Is Not Enough: A Reader-Context Diagnostic for Budget-Constrained Retrieval-Augmented Generation · 📖 深度解读

    面向固定上下文预算的 RAG，论文指出检索集 recall@k 并不等于模型真正看到答案，提出 answer-in-context 指标判断金标准证据是否存活于打包上下文。三项多跳数据集实验显示，该指标在 recall 之外带来 ΔR²=0.17–0.27；即使金标准已被召回，是否保留答案仍使 exact match 相差 4.6 倍。

    出现于日报：08-07

  3. 3. Closing the Indexing-Decoding Gap in Multimodal Generative Retrieval via Prefix Retention Optimization

    论文分析多模态生成式检索中 residual quantization 建立离散标识、trie beam search 解码之间的 gap，提出 PRO。它用 prefix ranking distillation、扩大 codebook 的 vocabulary scheduling、以及 geometric score fusion 改善前缀存活；在 9 个多模态检索任务上提升目标标识保留率。

    出现于日报：08-07

  4. 4. Guess Where You Go: Generative Next Point-of-Interest Recommendation in Amap

    高德 Gwhere 将生成式推荐落到下一 POI 场景：对文本、图像、空间和协同信号做对比式残差量化，得到更可区分的 SID，再以 Qwen2.5 继续预训练、SFT 与 EAKTO 强化学习完成时空偏好对齐。7B 版本在高德数据上较级联排序 Acc@1 相对提升 14.8%，长期线上 A/B 的 P-CTR 与 U-CTR 分别提升 5.83% 和 6.20%。

    出现于日报：08-03

  5. 5. EvoReason: Self-Evolving Reasoning Primitive-Guided On-Policy Distillation for Latent Reasoning in Generative Recommendation

    EvoReason 面向生成式推荐的低时延推理，把冗长且不稳定的显式思维链提炼为可复用“推理原语”，再让教师依据学生的 on-policy 轨迹持续修正监督，并通过 token 蒸馏与 KV 状态对齐写入潜在推理空间。Beauty、Sports 和工业数据上，Recall@10 相对最强基线分别提升 10.8%、11.1% 和 12.3%，NDCG 指标也全面领先。

    出现于日报：08-03

  6. 6. DualGR: Generative Retrieval with Long and Short-Term Interests Modeling · 📖 深度解读

    DualGR 面向短视频推荐中的生成式召回，针对长短期兴趣互相干扰、层级 Semantic ID 解码噪声和曝光未点击信号缺失，设计长短期双分支路由、搜索式 SID 解码与曝光感知 NTP 损失。系统在快手短视频线上 A/B 实验中带来视频播放量 +0.527%、观看时长 +0.432%，说明生成式召回已具备可落地的业务收益。

    出现于日报：08-06

  7. 7. MMGRec: Multimodal Generative Recommendation with Transformer Model · 📖 深度解读

    针对多模态推荐依赖全库向量内积、交互表达有限及假负样本的问题，MMGRec 先用 Graph RQ-VAE 融合协同图与视听文特征，将物品量化为语义 token 加热度 token 的 Rec-ID，再由关系感知 Transformer 自回归生成候选。在 MovieLens、TikTok、Kwai 上，NDCG@10 较最强基线分别提升 7.17%、6.79% 和 6.58%。

    出现于日报：08-04

  8. 8. Configure HSTU generative ranking in PAI-Rec: feature engineering, model training, and deployment

    Alibaba Cloud 给出了在 PAI-Rec 中定制 HSTU 生成式排序的完整路径，覆盖公开数据集上的特征工程、模型训练和在线部署三个环节。它强调把生成式模型嵌入现有推荐平台，而不是重写全部链路；页面提供了可复现实验流程，但没有给出统一的 nDCG、CTR 或线上增益数字。

    出现于日报：08-06

  9. 9. Search, Inspect, Fetch: Exploiting Boolean Retrieval for Deep-Research Agents

    SIEVE 将深度研究代理的 Search-Visit 流程改成 Search-Inspect-Fetch：先用字段化布尔检索约束标题、栏目和元数据，再展示结构化结果卡，最后只抓取选中的段落。在 3 个问答集合上，它相对最强传统配置减少 20.7%–50.6% token，同时在每个集合上取得更高准确率。

    出现于日报：08-06

  10. 10. Training Documents Reranker with Search Rubrics for Deep Research Agent

    RubricRanker 认为深度研究需要的是满足多样性、简洁性和权威性约束的文档集合，而不是逐篇相关的 Top-k。作者用 LLM 合成层级化搜索 rubric，再用 rubric 监督微调和强化学习训练重排器；在 4 个深度研究基准上较最强基线提升 2.6 个百分点，并泛化到 5 个 RAG 基准。

    出现于日报：08-06
