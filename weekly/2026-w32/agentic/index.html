2026-08-03 ~ 08-09 · 智能体搜索

生成式推荐 · 个性化推荐 · AI 搜索 · 智能体搜索 · 系统与索引

  1. 1. DeepResearch Agent System

    面向深度检索与自主研究，系统采用总参数 300 亿、单 token 激活 30 亿的稀疏模型，结合 128K 分层注意力、最多 20 步 IterResearch、四类工具和 GRPO 后训练。作者报告其推理较同级稠密模型快 3.2 倍，单轮基线准确率提升 31.2%，WebWalkerQA 达 91.2%。

    出现于日报：08-04

  2. 2. Fetch-then-Explore: Decoupling Selection from Extraction over a Persistent Workspace for Search Agents · 📖 深度解读

    针对搜索 Agent 打开网页即把内容塞入上下文、离开页面后证据易丢失的问题，论文提出 Fetch-then-Explore：先将全文存入每题独立的持久工作区，再用 grep/read 按需抽取。三种模型上 BrowseComp 准确率分别达 44.5%、52.5% 和 70.5%，比瞬态 Open+Find 高 2.0–4.5 个百分点。

    出现于日报：08-05

  3. 3. RecHarness: A Bandit-Routed Agentic Harness for Self-Evolving Recommender Systems

    针对推荐模型优化依赖工程师反复试验且 LLM 在有限预算下探索不稳的问题，RecHarness 用 Thompson Sampling 路由选择修改方向，再让 LLM 生成假设与可执行代码，并以 jump-basin 跳出局部最优。7 天短视频广告 A/B 测试中，ADVV、收入和曝光分别提升 2.084%、0.534% 和 0.559%。

    出现于日报：08-03

  4. 4. Orchard: An open framework for scalable agentic AI

    微软开源 Orchard，将 Kubernetes 隔离环境从具体训练框架中解耦，使 Codex、OpenClaw 等真实 harness 可直接用于蒸馏、强化学习和评测。Orchard-SWE 由 61.4% 提至 69.7%，价值模型重排后达 73.0%；4B 的 Orchard-GUI 在三项网页任务平均成功率为 68.4%。

    出现于日报：08-04

  5. 5. Rethinking Agentic Search with Pi-Serini: Is Lexical Retrieval Sufficient?

    Pi-Serini 重新检验深度搜索是否必须依赖稠密检索，为智能体仅提供检索、浏览、阅读三个工具，并把 BM25 与更强推理模型配对。在 BrowseComp-Plus 上，gpt-5.5 版本取得 83.1% 答案准确率和 94.7% 证据召回；BM25 调优分别带来 18.0% 与 11.1% 的提升。

    出现于日报：08-04

  6. 6. Diagnosing Search Behavior and Failure Modes in Long-Horizon Search Agents

    论文固定检索器与 ReAct 框架，在 BrowseComp-Plus 的 830 个问题上比较 6 个长程搜索 Agent，并以人工文档相关性标注区分“没找到证据”和“找到但没用好”。累计召回与准确率相关系数达 0.99，而最终上下文规模仅 0.16；77%–94% 的搜索回合没有增加新证据。

    出现于日报：08-05

  7. 7. Verification Without Sufficiency: Per-Chunk Filtering Fails on Multi-Hop RAG, and Decomposition Repairs It

    论文指出多跳 RAG 逐 chunk 做蕴含过滤存在结构性错误：单段本就不足以回答原问题。HotpotQA、2WikiMultihopQA、MuSiQue 上 AUC 仅 0.643、0.523、0.560，而单跳 SQuAD 为 0.951；把核验条件换成分解后的子问题后，MuSiQue 后续跳 AUC 从 0.546 升至 0.840。

    出现于日报：08-05

  8. 8. HindSearch: Trajectory-Level Hindsight Critique for Search-Augmented Reinforcement Learning

    针对搜索增强 Agent 只用二元 exact-match 奖励、失败轨迹信息被浪费的问题，HindSearch 在 GRPO rollout 后让冻结评审器借助标准答案为每条失败轨迹生成简短批评，再蒸馏到学生的搜索动作。Qwen2.5-3B-Instruct 在 7 个基准上的平均 EM 达 39.4%，优于既有 search-RL 基线。

    出现于日报：08-05

  9. 9. TurnSight: Turn-Level Hindsight Self-Distillation for Tool-Integrated Reasoning

    长链工具调用中的奖励通常只在轨迹末端给出，难以判断哪一轮检索或工具动作真正有效。TurnSight 以执行轨迹为条件构造多种 hindsight 视角，用跨视角方向一致性筛选可靠监督，再按 turn 粒度蒸馏并调节 RL 优势。论文在 3 个基准上验证方法有效，并公开代码。

    出现于日报：08-06

  10. 10. AgenticRAG: Agentic Retrieval for Enterprise Knowledge Bases

    AgenticRAG 在现有企业搜索栈上叠加 search、find、open、summarize 四类工具，让推理模型多轮检索、文内导航并管理长上下文，无需微调或建图。其在 BRIGHT 上 Recall@1 达 49.6%，比最佳 embedding 基线高 21.8 个百分点；FinanceBench 正确率 92%，距证据 oracle 仅 2 个百分点。

    出现于日报：08-03
