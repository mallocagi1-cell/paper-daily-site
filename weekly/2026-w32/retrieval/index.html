  1. 1. SPEAR: Selection-aware Personalized End-to-end Adaptive Rewriting and Retrieval for Community Search · 📖 深度解读

    把推荐里的 PDN（Path-based Deep Network）搬到搜索里挑改写词，会学出一条捷径：“手机壳”“女士连衣裙”这类高频泛词能连上大量内容，也确实带来点击，于是总被选中，用户写下的品牌、型号等限定却丢了。SPEAR（一种端到端训练的个性化改写选择与检索框架）让改写选择直接接受最终点击的监督，再加两道约束：改写的选择权重和它对内容的相关性相乘，两者都高才得分…

    出现于日报：08-05

  2. 2. Douyin Multimodal Embedding Model Technical Report

    DME 面向抖音十亿级多模态检索，用大规模对比预训练建立统一向量空间，再以证据落地的隐式推理和跨条件重建补足细粒度语义；重建仅用于训练，线上仍保持单次双塔编码。2B/9B 模型在 MMEB-v2 得分 74.8/78.4，抖音离线总分相对提升 2.92%，搜索 A/B 的 Lifetime 提升 0.1%。

    出现于日报：08-05

  3. 3. DenseOn with the LateOn: Fully Open Dense and Late-Interaction Models for Multilingual, Long-Context, and Code Search

    论文公开了从数据到训练代码的完整检索配方：从 34 个公开来源的 14 亿对数据中筛出 6.65 亿对，并构建 188 万条含难负例的微调集。149M 参数 DenseOn 与 LateOn 在 BEIR 上分别达到 56.20、57.22 nDCG@10；多语版扩展到 28 亿训练对，并覆盖长文档和代码检索。

    出现于日报：08-03

  4. 4. CeQe: Grounding Lexical Retrieval in Semantic Evidence

    CE-QE 从语义检索 Top 结果中读取 cross-encoder 的 token 归因，只把决定相关性的原文词追加到 BM25 query，避免传统伪相关反馈自我强化，也不引入生成式扩展的幻觉词。七个 BEIR 数据集上，NQ Recall@100 从 0.32 提升到 0.47；SESF 融合在 nDCG@10 上分别超过 SPLADEv2 和 ColBERTv2 5.3% 与 4.6%。

    出现于日报：08-05

  5. 5. Semantic Retrieval for Product Search in E-Commerce · 📖 深度解读

    Flipkart 以 Qwen3-Embedding-4B 构建 256 维双塔，先在 700 万查询商品对上做带假负例掩码的对比学习，再用 200 万分级偏好样本进行 ROAR 对齐。2.5 万查询离线评测中 MAP@8 提升 5.57 个点，线上 CTR、加购和订单分别提升 2.39%、4.58%、2.62%。

    出现于日报：08-04

  6. 6. Skills Know Their Neighbors: Cluster-Contrastive Capability Pages for Skill Retrieval

    论文把技能文档造成的检索误差显式化：文档往往只描述“能做什么”，却没有说明哪些相似请求不该路由到该技能。方法用离线编译器为每个技能生成正向触发、负向边界和判别正文，分别服务召回与拒绝。在包含26,262个技能、5,400个问题的SRA-Bench上，5种检索器的Recall@10平均提升2.94个百分点，端到端任务成功率平均提升3.62个百分点。

    出现于日报：08-07

  7. 7. Advancing Relevance Measurement with Vision-Language Models for Web-Scale Search

    Pinterest 将微调 VLM 用作图文搜索 A/B 实验的五级相关性裁判，并通过分层 query 抽样计算 sDCG@25，降低人工标注的成本与周转限制。VLM 与人工标签完全一致率为 82.9%，94.2% 的差异不超过一级；新方案把相关性指标的最小可检测效应从 1.3%–1.5% 降至不高于 0.25%。

    出现于日报：08-05

  8. 8. Tevatron Meets Megatron: Expert-Parallel LLM Reranker Training on an Academic Budget

    Tevatron 3.0 把 Megatron-Core 后端接入重排训练链路，补齐张量、流水线和专家并行，同时保留既有数据、评测流程及 Hugging Face 检查点兼容性。推荐的单机配置训练速度比 FSDP 快 22%，专家并行让 30B MoE 重排器可在原预算内训练；BEIR-15 上 MoE 以不足一半激活参数匹配 dense-8B 质量。

    出现于日报：08-05

  9. 9. QASP: Query-Adaptive Robust Vector Search Policy

    QASP 针对固定 ANN 搜索参数导致不同 query 召回波动的问题，用一次监督回归预测每条查询的完整 recall-progress 曲线，再按目标召回率生成搜索深度策略，并用无额外推理的反馈修正偏差。实验在大规模与分层索引上无需重训即可泛化，在 99% recall 目标下减少 80% 数据访问。

    出现于日报：08-03

  10. 10. Behavioral Feature Boosting via Substitute Relationships for E-commerce Search

    Amazon 为缺少交互的新商品寻找平均 5 个、最多 10 个替代品，再聚合点击、加购、购买和销量等行为特征，为排序模型提供冷启动信号。基于约 300 万查询的 LambdaMART 实验中，购买量提升 1.32%、销量提升 0.51%、点击提升 1.82%，并完成四周线上 A/B 测试后投入生产。

    出现于日报：08-04
