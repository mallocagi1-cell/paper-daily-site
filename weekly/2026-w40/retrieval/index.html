  1. 1. Generated Query Expansion Still Helps Strong Sparse Retrieval: A Controlled Study with SPLADE-v3 · 📖 深度解读

    研究把词表、伪文档、多条伪引用和语料引导文本四类生成扩展统一接入 SPLADE-v3，在 NFCorpus、TREC-COVID、SciDocs 的冻结索引上比较。十二组方法与数据集组合的 nDCG@10 全部提高，最佳相对增益分别为 4.81%、8.92% 和 9.47%；114 个插值设置中有 103 个保持收益。

    出现于日报：09-30

  2. 2. MERGE: Multi-LLM Ensemble for Retrieval via Generative Enrichment

    MERGE 用三个 7–8B 开源模型分别扩展查询，再由较大模型合成为单条查询，并以真实下游检索指标自动优化两阶段提示词。它仍只运行一次 BM25，无需重建索引或多路融合；在五个 BEIR 数据集上，相对原查询的 nDCG@10 提高 2.1 至 14.9 个百分点。

    出现于日报：09-30

  3. 3. SkillSeek: Revisiting Agent Skill Retrieval at Marketplace Scale

    针对技能市场中的语义检索，SkillSeek 使用 BGE 双编码器召回与小型 cross-encoder 重排，在 89 个 SkillsBench 任务和两种技能池中比较确定性检索与 LLM 精炼循环。34K 技能池上的 Qwen 设置达到相同的 0.442 平均任务得分，总试验费用从 51.30 美元降至 27.54 美元。

    出现于日报：10-02

  4. 4. Context Engineering Has a Retrieval Issue: Introducing rerank-3 and Native Reranking

    MongoDB 发布 rerank-3 系列及聚合管线原生重排，将候选召回和相关性排序接到同一数据流程。厂商报告相对于不重排，BM25、OpenAI v3 large、voyage-4-large 三种首阶段的 nDCG@10 分别提高 20.56%、12.77%、5.08%；这些是厂商评测结果。

    出现于日报：10-02

  5. 5. Beyond Relevance: Structured Semantic Supervision for Product Search with LLM-Augmented Annotations

    论文为查询与商品增加 LLM 生成的结构化属性，以及人工验证的相关性、解释和中心性信号，用双编码器与 MLP 重排评估监督价值。ESCI 子集上人工特征上限 nDCG@10 为 0.9382，无人工输入的 Q+P 方案为 0.9258，合成信号方案为 0.9150。

    出现于日报：10-02

  6. 6. Sieve and Sage: Efficient Distraction Filtering for Reliable RALM Abstention

    Sieve and Sage把证据缺失与混入冲突、否定或对抗证据分开处理，先用Longformer筛查检索集，再由Llama-3-8B生成或拒答。在NQ-google上系统准确率为0.796，对比DTA-chatQA的0.230；平均延迟379.6毫秒，对比756.3毫秒，约快1.99倍。

    出现于日报：10-01

  7. 7. Semantically Similar, Yet Not Answerable: Diagnosing the Semantic-Answerability Gap in Table RAG

    论文用同schema、同实体但答案不同的兄弟表构造TCR-Bench，隔离语义相关与能否回答之间的差距。稠密检索的目标表Top-1命中仅18.2%，Qwen3-E8B取Top-5表后的问答F1为0.330，而直接提供目标表为0.755；研究进一步检验结构绑定与答案充分性重排。

    出现于日报：10-01

  8. 8. Financial Evidence Crowding: Diagnosing and Mitigating Constraint-Induced Displacement in Retrieval-Augmented Generation

    论文研究 RAG top-k 中的证据拥挤：候选段落主题相似，却在时间、实体或指标范围上与查询冲突。受控测试中，不兼容候选让 Recall@10 下降 0.147；加入类型兼容性和局部词汇竞争的门控重排后，受控候选的证据覆盖率从 0.757 提至 0.902，真实索引条件下从 0.420 提至 0.492。

    出现于日报：09-30

  9. 9. Towards Semi-Automatically Comparing Keyword-Based and Semantic Search Accuracy

    论文用领域等价类把关键词结果列表和RAG回答中的信息完整性映射到统一有序尺度，并在工业知识库上比较检索质量。63条查询的Mann-Whitney检验中，RAG与Confluence的p值为0.0195，单独检索组件的p值为0.0015；对应A12为0.397和0.353。

    出现于日报：10-01

  10. 10. AI-based semantic search improves e-commerce product search more consistently when augmenting keyword matching than when replacing it

    这项电商搜索研究在 WANDS 与 ESCI 测试集上比较 BM25、TF-IDF、MiniLM 稠密向量、词法语义混合和 cross-encoder 重排。其核心结论是语义检索作为关键词匹配的补充更稳定，实验采用固定候选集与离线体验代理指标；公开摘要没有给出可安全引用的统一提升百分比。

    出现于日报：09-30
