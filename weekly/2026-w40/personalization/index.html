  1. 1. Soft Curriculum Learning for Optimizing Fresh and Generalized Recommendations · 📖 深度解读

    针对热门内容反馈循环和新内容曝光不足，论文在加速器计算图内用周期性损失权重替代动态丢弃样本，并以互动量或 SNGP 不确定性估计难度。7 天线上实验中，双向互动量课程使用户满意度提升 0.54%，最新内容桶互动提升 5.70%，序列召回独特互动提升 7.7%。

    出现于日报：10-01

  2. 2. Learned Cross-Task Relationships in Multi-Task Models · 📖 深度解读

    论文为多任务模型增加交叉标签和无条件辅助头，显式学习点击、收藏等行为的联合关系，再把预测传给下游策略。YouTube 通知实验中 CTR 提升 7.67%、发送量下降 7.21%、退订下降 1.05%；首页额外关系特征使低质量曝光下降 0.64%。

    出现于日报：10-01

  3. 3. HELIX: Purified and Unified - Rethinking Feature Interaction and Sequence Modeling for Large-Scale Recommendation · 📖 深度解读

    论文面向大规模推荐排序中异构特征交互与长行为序列建模难以同时扩展的问题，提出 HELIX：交替执行序列检索和特征交互，并让可复用的用户序列状态单向流向候选相关的混合 token。该设计把用户侧计算摊销到多个候选上。TikTok 电商线上 A/B 测试报告每用户视频成交额约提升 6%，同时离线 CTR 与 CVR AUC 改善。

    出现于日报：09-30

  4. 4. Beyond Interaction Capacity: Estimator Scaling with Recursive Models for CTR Prediction

    论文发现继续加深特征交叉网络收益递减，提出 RECAP，在共享递归骨干上融合跨随机种子蒸馏、训练轨迹 EMA 和推理路径聚合。5 个公开 CTR 基准上，Criteo AUC 达 81.76%，FCN 为 81.62%；与五模型集成 81.771% 接近，部署参数约为其五分之一。

    出现于日报：10-01

  5. 5. Mend the Measurement Gap: Latent User Preference Modeling for Short-Form Video Recommendation · 📖 深度解读

    短视频观看时长、点赞和负反馈混合了真实偏好与时长、用户活跃倾向等测量偏差。FLVM用受限基线解释混杂因素，再以消费、互动、情感三个潜变量重建异构反馈。YouTube Shorts上点赞PR-AUC从0.2522升至0.3190，14天线上实验中主要愉悦度指标提升2.67%，护栏指标中性。

    出现于日报：10-02

  6. 6. SnooRec: A Shared Retrieval Foundation for Reddit Recommendations

    SnooRec 将任务专属专家放在用户塔，物品塔和 ANN 索引共享，通过在线混合点击、点赞、有效访问用户向量调整推荐目标。Reddit 首页有效访问专家使会话增长 0.28%、长停留访问增长 1.21%；物品向量 256 维，排序器可用 32 或 64 维前缀。

    出现于日报：10-01

  7. 7. A Unified Generative Re-ranking Framework with Adaptive Multi-objective Fusion

    MAMGR 处理电商重排序中点击、交易等目标被静态融合的问题。模型用多目标自适应模块实时学习个性化权重，并在生成器与评估器之间共享；双通道上下文模块兼顾局部两两交互和全局列表依赖。RecSys 会议摘要报告支付宝线上 CTR 提升 0.78%、GMV 提升 1.43%，CPU 使用降低 23.53%，延迟仅增加 1.12%。

    出现于日报：09-30

  8. 8. RouteRec: Behavior-Guided Sparse Routing for Sequential Recommendation

    RouteRec把会话节奏、物品群聚焦、重复与跨会话延续、流行度倾向作为稀疏专家路由依据。在宏观、中观和微观三个范围先选专家组，再由当前骨干状态细化组内专家选择。六个公开数据集的18组指标中，方法12次第一、3次第二，平均名次1.61，次优基线为4.11，并提供开源代码。

    出现于日报：10-02

  9. 9. When LLM-Inferred User Context Adds Value in Production Streaming Recommendation · 📖 深度解读

    论文在真实流媒体平台比较聚合画像与LLM叙事画像，以及全历史和短长期融合两种范围。样本含1万用户、约24万内容，约18%属于探索型用户。叙事画像使全体Recall@10下降30.7%，但探索型用户NDCG@10提升31.5%；全体目录覆盖率同时下降79.8%，说明收益高度依赖用户状态。

    出现于日报：10-02

  10. 10. Inherit4Rec: Parameter Inheritance for Efficient Scaling of Recommendation Models

    Inherit4Rec 针对流式推荐模型扩容时重新训练成本高的问题，设计保持前向函数和优化状态的稠密扩容，以及基于共激活分区的稠密转稀疏。KuaiRand-1K 上扩容 GAUC 相对最强继承基线平均提升 0.15%，工业集提升 0.05%；摘要前正文报告稀疏增量训练成本减少 72%。

    出现于日报：10-01
