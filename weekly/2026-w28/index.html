  3. 3. LLMs Meet Isolation Kernel: Lightweight, Learning-free Binary Embeddings for Fast Retrieval · 📖 深度解读

    论文提出 Isolation Kernel Embedding (IKE)，把高维 LLM embedding 转换成二值 embedding，目标是在保持检索精度的同时降低向量检索的存储和计算成本。方法不需要额外训练，利用 Isolation Kernel 进行二值编码，实验显示相比原始 LLM embedding 最高可实现 16.7 倍检索加速和 16 倍内存降低，同时保持相近准确率。

  4. 4. SimDiffRec: Semantic Similarity-Guided Diffusion for Contrastive Sequential Recommendation

  9. 9. Modality Relevance is not Modality Utility: Post-hoc Selective Modality Escalation for Cost-Aware Multimodal RAG

    论文研究多模态 RAG 中何时调用昂贵 VLM 的问题，指出“问题是否涉及图片”并不等于“答案是否必须依赖图片”。作者在 MultiModalQA 上做 oracle headroom 分析，发现大量 gold support 含图片的问题仍可由文本和表格回答；因此提出后验选择式 modality escalation：先走低成本 text/table 管线，只有答案不充分时再升级到视觉模型，以降低多模态检索生成成本。
