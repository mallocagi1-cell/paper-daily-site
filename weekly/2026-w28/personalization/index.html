  1. 1. HGenPush: A Heterogeneous Generative Recommendation Architecture for Industrial Push Notification Systems · 📖 深度解读

    这篇论文面向快手短视频 Push 场景，解决生成式推荐只能生成单一内容类型、Semantic ID 自回归生成效率低的问题。HGenPush 将多场景、多视角用户行为理解，与视频推荐和作者推荐的双分支异构生成模块合并到端到端框架中，并用多 token 预测替代逐步自回归生成。论文报告已部署在快手 Push 通知系统，带来日活用户数 0.181% 的显著提升。

    出现于日报：07-08

  2. 2. Generative Pseudo-Labeling for Pre-Ranking with LLMs · 📖 深度解读

    GPL 关注工业推荐预排序的训练-服务不一致：模型训练只看到已曝光交互，线上却要给大量未曝光候选打分，导致样本选择偏差和长尾内容泛化差。方法用 LLM 离线生成用户兴趣锚点，在冻结语义空间中与候选匹配，为未曝光物品生成内容感知伪标签，不增加线上延迟。论文报告在大规模生产系统部署后 CTR 提升 3.07%，同时改善多样性和长尾发现。

    出现于日报：07-08

    出现于日报：07-08
