  1. 1. Optimizing Large Batched LLM Inference with Global Prefix

    BatchLLM 针对批量 LLM 推理场景重新设计 prefix 共享调度：传统 vLLM/SGLang 只在请求局部范围内复用前缀 KV-cache，本文提出全局前缀挖掘 + 全局调度，把具有相同前缀的请求重排到同一批次执行，使 KV-cache 在更大范围内被复用。在含共享前缀的 microbenchmark 上 token 节省率从 vLLM 的 40.1% 提升到 85.2%，端到端吞吐显著提升。

    出现于日报：04-27

  2. 2. PolyKV: A Shared Asymmetrically-Compressed KV Cache Pool for Multi-Agent LLM Inference

    面向多 Agent 共享同一上下文的推理场景，提出共享非对称压缩 KV cache 池：压缩仅写入一次，N 个独立 agent 上下文共享读取。在 Llama-3-8B、15 个 agent 共享 4K-token 上下文场景下，KV cache 内存从 19.8 GB 降至 0.45 GB（97.7% 缩减），稳定 2.91× 压缩比，质量影响有限。

    出现于日报：05-01

    出现于日报：04-29

  4. 4. DASH-KV: Accelerating Long-Context LLM Inference via Asymmetric KV Cache Hashing

    把注意力计算重构为基于非对称深度哈希的近似最近邻搜索：query 与 key 用不同的哈希映射，仅检索 top-k 相关 token 参与 softmax 计算。引入动态混合精度机制，对关键 token 自适应保留全精度计算。在长上下文（64K+）下实现可观加速，质量损失低于 1%。

    出现于日报：05-01

  5. 5. Scheduling the Unschedulable: Taming Black-Box LLM Inference at Scale

    针对调用 OpenAI、Claude 等黑盒 LLM API 时的负载相关性能退化（congestion），提出客户端拥塞感知调度。通过在线估计有效服务容量、基于响应延迟反馈做自适应限流、并对突发流量做请求合并，使尾延迟在高负载下可控。该工作不依赖服务端任何特性，纯客户端可部署。

    出现于日报：05-01

  6. 6. GEAR: An Efficient Error Reduction Framework for KV Cache Compression in LLM Inference
