2026-07-27 ~ 08-02 · 生成式推荐

  1. 1. OxygenREC: An Instruction-Following Generative Framework for E-commerce Recommendation · 📖 深度解读

    OxygenREC 将近线 LLM 的“慢思考”意图推理与实时编码器—解码器的“快生成”拆开，并用 Q2I 对齐、指令引导历史检索及 SA-GCPO 统一六个电商场景。京东 10% 流量 A/B 中，订单量提升 1.49%–8.03%、GMV 提升 1.46%–11.80%，线上延迟为 50–80ms。

    出现于日报：07-27

  2. 2. EGR: Embedding-Native Generative Retrieval with a Shared LLM

    EGR 用同一个共享 LLM 把商品元数据与用户行为历史编码到统一向量空间，直接以商品稠密向量建索引，并通过联合对比学习同时完成相似商品聚类和用户—目标商品对齐。它在 Amazon Reviews、Snap 工业数据和冷启动多模态场景均优于基线，生产部署带来 2.91% 的转化率提升。

    出现于日报：07-29

  3. 3. SMART: LLM-Augmented Hybrid Retrieval for Dynamic Product Ads · 📖 深度解读

    面向千万级商品库的动态广告召回，SMART 将规则查询与 BM25 用于再营销，将 LLM 查询与稠密 ANN 用于新兴趣探索，并用轻量质量门控只把约 10% 用户送入 LLM 路径。该设计减少 90% 的 LLM 成本；Snap 两周线上 A/B 测试相对强向量基线提升转化率 27.6%。

    出现于日报：07-29

  4. 4. Reward Guided Decoding for Generative Recommendation · 📖 深度解读

    针对生成式推荐只按序列概率做束搜索、导致高业务价值候选被过早剪枝的问题，RGD 将解码写成带 KL 约束的奖励最大化，并在每个 SID 层注入奖励模型。三组 Amazon 数据上 Recall@10、NDCG@10 最高提升 11.49% 和 8.30%；快手两周 A/B 中页面 CTR、直播时长分别提升 0.392% 和 0.689%。

    出现于日报：07-30

  5. 5. Tokens are All You Need: Dual-purpose Semantic IDs for Achieving LLM-Level I/O Efficiency in recommendation systems

    论文让同一组 Semantic ID 同时承担协同身份与内容重建：层次量化把稠密向量压成离散 token，轻量 SiDec 在模型内按需还原语义，典型存储压缩达 50–100 倍。YouTube 线上排序中观看页满意互动提升 0.80%，离线检索 HitRate@100 达 0.2910，训练速度 14.53 step/s，高于直接输入稠密向量的 12.07。

    出现于日报：07-30

  6. 6. PSG: Pair-Space Generation for Efficient Generative Reranking · 📖 深度解读

    现代生成式重排以单物品为自回归单元，序列越长，推理开销与教师强制误差越重。PSG 将生成原子提升为有序物品对，使长度为 L 的列表只需生成 L/2 个 token，并用大规模曝光日志预训练物品对表示。理论速度提升 2–4 倍，工业环境实测 1.83 倍；在快手 4 亿日活场景上线后，人均停留时长提升 0.178%。

    出现于日报：07-31

  7. 7. Bridging the Structural Gap: Adapting Autoregressive Generation for Recommendation

    BARGE 针对 Semantic ID 展平后物品边界消失、层级解码早期错误造成语义漂移，加入 Item Context-Aware Attention、Hierarchical Path Reranking 与双路径解码。腾讯商业媒体平台以 6% 流量验证，相比现网多阶段系统 CTR 提升 0.60%、点击用户数提升 1.34%、总阅读时长提升 1.70%。

    出现于日报：07-27

  8. 8. Understanding Semantic IDs: From Item Representation to Item Selection in Generative Recommendation

    论文从编码、SID 构造、自回归生成到最终选品系统审视 Semantic ID。三个 Amazon 领域、八种 SID 方案中，SID 邻域平均只保留编码器前十近邻的 32.2%；替换商品描述会改变 38.4% 的精确 SID，TIGER 最终仅保留 29.9% 原本可行的目标。作者提出无需训练的 ISD，在所有设置提升 NDCG@10，最高相对增益 31.2%。

    出现于日报：07-31

  9. 9. Structuring and Tokenizing Distributed User Interest Context for Generative Recommendation

    G2Rec 以 O(M log M) 稀疏共参与图和软聚类提取分布式兴趣原型，再把兴趣 token 与物品 token 交替输入生成模型。四个公开数据集上均领先，例如 Yelp NDCG@10 达 0.4927；Meta 多产品面 7 天与长期 A/B 中，会话指标提升超过 0.03%，时长、点赞、分享等提升 0.06%–0.19%。

    出现于日报：07-27

  10. 10. OxygenREC-v2: Internalizing Discrimination into Generative Recommendation

    OxygenREC-v2 将点击、加购、下单等行为作为指令直接条件化 SID 生成，并在后训练中用未来行为特权信息与熵感知自蒸馏实现无需外部奖励模型的策略优化。京东部署的 3B 参数、1B 激活 MoE 相比 v1 在线提升 UCTCVR 1.6%–4.4%、GMV 2.8%–6.8%。

    出现于日报：07-29
