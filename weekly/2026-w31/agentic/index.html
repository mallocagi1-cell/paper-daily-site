Weekly Top 10 · 第31周

2026-07-27 ~ 08-02 · 智能体搜索

生成式推荐 · 个性化推荐 · AI 搜索 · 智能体搜索 · 系统与索引

  1. 1. EviBack: Search-Agent Reinforcement Learning via Evidence-Constrained Teacher Backoff

    论文针对搜索 Agent 训练中整组 rollout 全为零奖励、有效中间检索无法获得比较信号的问题，提出证据约束的 Teacher 回退奖励与自动提示优化流程。7 个开放域问答集上，Qwen3-1.7B 的 F1 从 0.2509 升至 0.2911，有效答案率从 0.7317 升至 0.8611，同时平均搜索次数降至 1.5934。

    出现于日报：07-31

  2. 2. From Proprietary to Open-Source: Bridging the Distribution Gap via Multi-Agent Protocol Distillation in Agentic Search

    针对搜索智能体仅靠结果奖励监督稀疏、闭源教师又无法提供 logits 的问题，MAPD 先让离线多智能体分解问题、检索证据并修复失败轨迹，再压缩为去风格化 JSON 协议，以特权分支的逐 token 自蒸馏联合 GRPO 训练开源模型。七个 QA 基准上，Qwen3-1.7B/4B 平均成功率达 39.4%/44.4%，相对最强 SDAR 提升 4.8%/3.3%。

    出现于日报：07-29

  3. 3. SearchArt: Training Long-Horizon Search Agent with Scalable Synthetic and Verified Task

    针对搜索智能体缺少可扩展长链任务与过程监督的问题，SearchArt 从网页和自动生成的证据图合成问答及搜索轨迹，再以问答一致性、轨迹质量和证据相关性三重验证过滤数据，最后结合 SFT 与强化学习优化策略。仅用 Qwen3.5-27B，BrowseComp-ZH、BrowseComp 和 DeepResearch-Bench 分别达到 74.39、70.06 和 52.55。

    出现于日报：07-30

  4. 4. 下一代搜索智能体评测基准！美团开源LoHoSearch，用知识图谱校准AI能力认知

    针对 BrowseComp 已被顶尖模型刷到 90% 以上、难以区分长程搜索能力的问题，美团从 762 万实体、2.65 亿条边的维基知识图谱自动采样树形与图形约束，构建 544 道人工核验题目。GPT-5.5 仅得 34.74%；正确轨迹平均工具调用从 35 次增至 61 次，最佳上下文策略只提升 6.8 个百分点。

    出现于日报：07-28

  5. 5. Echoverse: Deep, evolving environments for computer-use agents

    微软构建 10 个深层业务世界与 2 个能力世界，用真实状态、数据库校验器和可重置环境训练计算机使用 Agent，并让环境、任务、校验器随失败共同演化。Qwen3.5-9B 在 14 个域的平均分由 36.5% 升至 67.1%，WebVoyager 从 66.5% 升至 71.5%，浅层环境反而使 Allrecipes 从 80% 降到 75%。

    出现于日报：07-31

  6. 6. PATS: Policy-Aware Training Scaffolding for Agentic Reinforcement Learning

    针对长程智能体强化学习中弱策略反复失败、同组轨迹缺乏奖励差异的问题，PATS 把近期 rollout 转成证据卡，并按策略能力动态扩展、修订或压缩训练支架，部署时再完全移除。ALFWorld 与 WebShop 上最高提升 18.6 个百分点；7 个搜索增强问答基准中，提示词开销比基线少 32.1%。

    出现于日报：07-27

  7. 7. SkillRise: Agentic Reinforcement Learning for Cross-Task Skill Evolution

    论文把相关但不同的任务排成递增难度序列，让同一策略在“执行任务”和“维护可复用技能文档”之间交替，并用当前结果奖励执行、用折扣后的下游结果奖励技能整理。ALFWorld、WebShop、ScienceWorld 上，Pass@1 相比最强基线提高 2.3～8.5 个百分点，且跨任务序列越长，测试时表现继续增长。

    出现于日报：07-31

  8. 8. VecTree-RAG: An Agentic Retrieval-Augmented Generation Framework Combining Vector and Tree Retrieval for Efficiency and Accuracy

    VecTree-RAG 将“跨论文找相关文献”与“论文内定位证据”拆成两种工具：向量检索先缩小文档和章节范围，推理智能体再遍历来源可验证的章节树，并按需从页存储读取全文。它在 300 个 QASPER、54 个 LitQA2 和 49 个 MOSAIC 问题上均取得最高分，QASPER 证据页精度为 0.274，基线仅 0.046–0.071。

    出现于日报：07-29

  9. 9. Harness-1: Reinforcement Learning for Search Agents with State-Externalizing Harnesses

    该工作把搜索智能体的候选池、证据链接、核验记录、观察压缩与预算渲染外置到有状态 harness，只让 20B 策略学习搜索、筛选、核验和停止等语义决策。覆盖 Web、金融、专利和多跳问答的 8 个基准上，平均 curated recall 达 0.730，比次强开源搜索子智能体高 11.4 个百分点。

    出现于日报：07-27

  10. 10. Silent Failures in Multimodal Agentic Search: A Diagnostic Taxonomy and Cross-Judge Evaluation

    论文指出只看最终答案会漏掉多模态搜索 Agent 的“静默失败”，并定义虚假落地、错证据得对答案、过度检索洗白、跨模态冲突等 6 类问题。作者在 MMSearch-Plus 的 200 个任务、4 个前沿模型共 800 条轨迹上评测，真实正确率较表面准确率下降 0.6–7.3 个百分点。

    出现于日报：07-27
