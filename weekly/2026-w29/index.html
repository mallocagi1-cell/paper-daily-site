  1. 1. Beyond Semantic IDs: Encoding Business-Value Ranking into Document Identifiers for Generative Retrieval · 📖 深度解读

    针对生成式检索中语义 DocID 碰撞且与业务目标脱节的问题，阿里提出 CRID：前两级做语义聚类，末级按转化价值排序，天然保证一物一码并支持增量重排。在淘宝 3 亿商品语料上，CRID 的 HR@20 达 41.20%，较强基线提升 3.72 个百分点；全流量部署带来 GMV +1.06%。

    出现于日报：07-15

  2. 2. Where Reasoning Matters: Rethinking Latent Reasoning in Semantic ID-based Generative Recommendation · 📖 深度解读

    论文针对 Semantic ID 生成式推荐中“每个 token 使用相同推理步数”的低效做法，以位置级信息增益衡量各段 ID 对目标物品不确定性的消减程度，并提出 IBA 动态分配隐式推理预算。多组公开数据实验表明，优先计算高信息增益位置可持续提升强基线，并获得更优的准确率—算力折中。

    出现于日报：07-16

  3. 3. OneRec-Think: In-Text Reasoning for Generative Recommendation · 📖 深度解读

    论文把对话、显式推理与生成式推荐统一到 OneRec-Think：先用跨模态 Item-Textual Alignment 对齐 Semantic ID，再以推理脚手架和面向多解偏好的奖励函数训练。Beauty 数据集 Recall@5 从 ReaRec 的 0.0450 提升至 0.0563，线上 Think-Ahead 架构使 APP 停留时长提升 0.159%。

    出现于日报：07-13

  4. 4. Serving the Long Tail: Training-Free LLM Candidate Generation for Vacation Rental Marketplaces

    Vrbo 面向无行为信号的长尾房源提出免训练候选生成：LLM 依据静态属性生成多样语义查询，文本编码器向量化后在 1170 万房源 ANN 索引中检索，再以 Union 策略与 IBKNN 合并。该方案保证不损害原行为通道排序，同时为零候选和稀疏房源补充可解释的语义邻居。

    出现于日报：07-15

  5. 5. An LLM-powered Agentic Recommendation System for Connected TV Content Discovery

    Meta 构建面向 Connected TV 内容发现的混合 Agent 推荐架构，用 LLM 吸收热点、新闻、文化事件和跨端行为等异构信号，再由主题检索、媒体检索排序和主题排序等专门组件协作。工程重点是组件级缓存、链式检索和吞吐优化，以缓解 LLM 推理时延并保留传统模型的检索效率。

    出现于日报：07-15

  6. 6. MESH: Scaling Up Retrieval with Heterogeneous Content Unification

    MESH 面向新鲜、长尾与高频内容并存的大规模推荐召回，以模块化特征域和门控偏差校正隔离稀疏信号与高频互动信号的梯度干扰。Pinterest Related Pins 线上实验中，新内容 repin 提升 5.5%，漏斗效率提升 55%，留存提升 0.46%，异步服务吞吐提高 2.87 倍。

    出现于日报：07-16

  7. 7. ReRec: Reasoning-Augmented LLM-based Recommendation Assistant via Reinforcement Fine-tuning

    ReRec 用强化微调增强复杂推荐推理：奖励同时融合 NDCG、query 对齐和偏好对齐，RAEE 对错误推理步骤施加惩罚，在线课程调度器按难度组织样本。以 Llama-3.2-3B 为骨干时，Movie 各类任务较次优方法提升 3.76%–13.2%，困难误导查询较未训练模型提升 440%。

    出现于日报：07-13

  8. 8. Bi-Level Optimization for Generative Recommendation: Bridging Tokenization and Generation.

    BLOGER 将物品 tokenizer 与自回归推荐器建模为双层优化：内层训练推荐器，外层同时利用重构损失和推荐损失更新 tokenizer，并用元学习与梯度手术处理目标冲突。在 Amazon Beauty 上 R@5 从 ETEGRec 的 0.0413 升至 0.0444；移除梯度手术后降至 0.0329。

    出现于日报：07-15

  9. 9. Unleashing the Native Recommendation Potential: LLM-Based Generative Recommendation via Structured Term Identifiers · 📖 深度解读

    论文用5个标准化自然语言关键词组成 Term IDs，以替代易幻觉的自由文本标识和需扩词表的 Semantic IDs；GRLM 联合上下文词项生成、指令微调与弹性标识落地。Beauty、Sports、Toys 上 Recall@5 相对最强基线分别提升7.8%、30.2%、14.9%，跨域 Recall@K 平均提升超过50%。

    出现于日报：07-17

  10. 10. jina-embeddings-v5-text: Compact and Robust Text Embedding Models using Task-Targeted Distillation.

    该工业论文把教师蒸馏与任务定向对比学习结合，训练 677M 的 small 与 239M 的 nano 多语言文本向量模型，并提供任务 LoRA、Matryoshka 维度和量化版本。small 在 MTEB English v2 平均 71.7、MMTEB 67.7，支持 119 种以上语言与 32K 上下文，模型权重已公开。

    出现于日报：07-16
