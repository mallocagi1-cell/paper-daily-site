2026-07-13 ~ 07-19 · AI 搜索

  1. 1. Scaling Laws for Embedding Dimension in Information Retrieval

    论文把向量维度从编码器隐藏维度中独立出来，在 BERT 与 Ettin 两个双塔家族上联合改变模型规模和 embedding 维度，覆盖约 439 万至 10.28 亿参数、32 至 28672 维，并拟合联合 scaling law。MS MARCO 与 TREC DL 上维度增大呈稳定但递减收益，论文进一步给出固定推理 FLOPs 下的成本最优配置。

    出现于日报：07-14

  2. 2. When to Repair a Graph ANN Index: A Matched-Budget Negative Result, and the Interpolated-Baseline Trap That Hid It · 📖 深度解读

    论文检验 HNSW、DiskANN/Vamana 在增删抖动下按导航退化信号触发局部修复，是否优于固定周期维护。作者在 SIFT-128 与 Fashion-MNIST-784 上按真实修复次数匹配预算后发现，所有运行点的尾部召回优势都与零无显著差异；一次合并已取得超过一半可达收益，原先正结果源于错误的线性插值基线。

    出现于日报：07-14

  3. 3. Multilingual Semantic Retrieval for Apple Music Search

    Apple 面向 150 多个地区的音乐搜索，训练 3.05 亿参数多语种双塔，并用分位数分布匹配把稠密召回与词法索引融合，无需重训下游排序。离线 Hit@10 相对提升 69%；全球 A/B 中转化率提升 2.28%，无结果率下降 86%，尾部查询转化率提升 7.93%。

    出现于日报：07-15

  4. 4. Scaling and Stabilizing Large-Scale Embedding-Based Retrieval

    Walmart 针对双塔训练候选窄、线上需区分数亿商品的落差，结合跨批次在线采样与交叉编码器、元数据驱动的离线难负例挖掘，使负例多样性扩大一个数量级；再用热启动蒸馏把 DistilBERT 平滑迁移至 GTE-base。线上部署后 NDCG@5 提升 7.34%，总营收提升 0.50%。

    出现于日报：07-15

  5. 5. MMRM: A Multiplex Multimodal Representation Model for Product Ranking in E-commerce Search

    京东提出 MMRM，用共享多模态骨干、任务专属 token 与投影层，在一次推理中同时学习多种协同信号，再基于搜索行为序列构造任务专属用户表示用于多任务排序。该系统已在京东搜索部署并服务数百万日常用户，论文报告离线与线上均取得显著收益，但摘要未披露具体增幅。

    出现于日报：07-15

  6. 6. Optimizing RAG Rerankers with LLM Feedback via Reinforcement Learning

    论文针对 RAG 重排器只优化静态相关性、与下游生成效用错位的问题，提出 RRPO，把文档排序建模为序列决策并直接使用 LLM 回答质量反馈训练。HotpotQA 上 GTE-RRPO 的 Top-3 EM/F1 达 36.56/49.67；结合 Query2Doc 后 Top-3 F1 达 54.10。

    出现于日报：07-16

  7. 7. With Argus Eyes: Assessing Retrieval Gaps via Uncertainty Scoring to Detect and Remedy Retrieval Blind Spots

    针对神经检索器会把相关实体映射到低可达区域的“盲点”问题，论文提出检索概率分数 RPS，在建索引前仅凭实体向量几何预测风险，并用知识库文本定向增强高风险实体。ARGUS 在 BRIGHT、IMPLIRET 与 RAR-B 上跨检索器稳定提升，平均带来 nDCG@5 绝对值 +3.4、nDCG@10 +4.5。

    出现于日报：07-17

  8. 8. HOBIT: Hardness Optimized Batch Sampling for InfoNCE Training

    HOBIT 不重建全库负样本索引，而是在每个 epoch 重排 query-positive 对，使 InfoNCE 批内负例同时“难”且不与正例矛盾；单调次模目标支持 O(1-1/e) 贪心近似。三套数据、两类编码器上，MS MARCO MRR@10 提升 0.6–1.5 点，NQ Recall@10 提升 1.6–3.3 点，缓存版每 epoch 最快提速 29%。

    出现于日报：07-14

  9. 9. Score-Only Distillation for Compact Dense Retrieval

    论文只使用教师的候选打分向量蒸馏紧凑稠密检索器，不依赖隐藏状态；核心是行中心化分数目标与节省内存的全对 PairMSE。八项任务上最多追回基座到教师差距的 50%；0.6B 学生的 query 编码快 4.7 倍、文档编码快 9.7 倍，但跨协议迁移效果仍不稳定。

    出现于日报：07-15

  10. 10. SHEAF: Self-profiled Hardness Estimation from Answer-set Flux for Predicting Query Hardness in Graph-based ANN Search

    论文发现 ANN 查询达到 95% 召回所需 beam 在 SIFT1M 上相差超过 32 倍，固定 beam 会同时浪费吞吐并伤害难查询召回。SHEAF 用两次浅层 probe 的 top-k 答案集变化量预测查询难度，在 CAGRA、HNSW 和 4 个数据集上，留出相关性最高比 5 个基线好 1.55 倍。

    出现于日报：07-16
