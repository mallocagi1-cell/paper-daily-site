  1. 1. An In-Depth Study of Filter-Agnostic Vector Search on a PostgreSQL Database System · 📖 深度解读

    本文首次在生产级 PostgreSQL 兼容数据库中系统评估了 Filter-Agnostic 向量搜索 (FVS) 算法。研究发现，在企业级数据库系统中，常用假设（如距离计算主导开销）并不成立，最优算法取决于选择率和相关性等多维因素。论文系统比较了 post-filtering 和 inline-filtering 策略，揭示了与独立库评估截然不同的性能特征和算法权衡，为生产环境下的语义搜索和 GenAI 应用提供了关键的系统级指导。

    出现于日报：03-27

  2. 2. ECI: Effective Contrastive Information to Evaluate Hard-Negatives

    提出基于信息论的 ECI 指标，在不进行实际微调的情况下预测难负例集合对稠密检索模型的训练效果。ECI 综合考量信息容量与判别效率，并对生成式方法中常见的假阳性负例进行惩罚。在 BM25、cross-encoder 和 LLM 生成的难负例集上验证，ECI 能准确预测检索性能，发现 BM25+cross-encoder 混合策略效果最优，大幅降低了选择难负例的计算成本。

    出现于日报：03-25

  3. 3. GEM: A Native Graph-based Index for Multi-Vector Retrieval

    针对多向量检索（如 ColBERT）的索引效率问题，提出 GEM 框架：直接在向量集合上构建邻近图，引入集合级聚类减少冗余、分离构图度量与最终打分、并通过语义快捷边加速导航。在多个基准上实现最高 16 倍加速，同时保持或提升精度，为 ColBERT 类多向量检索的工程落地提供了关键基础设施。

    出现于日报：03-25

  4. 4. Spectral Tempering for Embedding Compression in Dense Passage Retrieval · 📖 深度解读

    针对稠密检索系统大规模部署中的维度压缩问题，提出 Spectral Tempering 方法。现有 PCA 压缩保留主成分方差但浪费表示容量，而 MRL 在训练时增加开销。该方法通过频谱调温在后处理阶段重新分配方差到低阶分量，无需重训练即可实现更优的维度压缩效果，在 BEIR 等标准检索基准上优于 PCA 和 MRL 基线。

    出现于日报：03-24

  5. 5. DSL-R1: From SQL to DSL for Training Retrieval Agents across Structured and Unstructured Data with Reinforcement Learning

    提出 DSL-R1 框架，通过自定义 DSL 将 SQL 风格的结构化过滤与向量语义检索统一到一个检索代理中，并使用强化学习（基于执行反馈和检索质量奖励）联合优化 DSL 生成的结构正确性和语义对齐。在大规模工业邮件检索基准上，Hit@1/3 提升 12.3%，显著优于解耦式基线方案。

    出现于日报：03-25

  6. 6. E2Rank: Your Text Embedding can Also be an Effective and Efficient Listwise Reranker · 📖 深度解读

    E2Rank 提出将文本 embedding 模型同时用于检索和 listwise 重排序的统一框架。通过在 embedding 模型上继续训练 listwise 排序目标，利用 query 与 document embedding 之间的余弦相似度作为统一打分函数，从候选文档构建增强 query。在 BEIR 和 BRIGHT 基准上取得了强劲表现，同时几乎不增加延迟开销，并提升了 MTEB embedding 性能。

    出现于日报：03-23

  7. 7. AI Co-Scientist for Ranking: Discovering Novel Search Ranking Models alongside LLM-based AI Agents with Cloud Computing Access · 📖 深度解读

    本文提出首个面向搜索排序模型研发的 AI Co-Scientist 框架，自动化完成从创意生成、代码实现到 GPU 训练调度的完整研究流水线。系统采用单 LLM agent 处理日常任务，多 LLM 共识 agent（GPT 5.2、Gemini Pro 3、Claude Opus 4.5）协同处理结果分析与创意生成等高难度阶段。该框架成功发现了一种处理序列特征的新技术，所有模型改进均由 AI 自动产生。

    出现于日报：03-26

  8. 8. A Super Fast K-means for Indexing Vector Embeddings

    提出 SuperKMeans，一种专为高维向量 embedding 聚类优化的 K-means 变体。在现代 CPU 上比 FAISS 和 Scikit-Learn 快 7 倍，在 GPU 上比 cuVS 快 4 倍。该方法直接服务于向量检索索引构建（如 IVF 索引），可显著加速大规模向量数据库的索引构建过程。

    出现于日报：03-24

    出现于日报：03-26

  10. 10. Retrieval Improvements Do Not Guarantee Better Answers: A Study of RAG for AI Policy QA

    本文在 AI 治理与政策分析领域研究了 RAG 系统中检索质量提升与端到端问答质量之间的脱节现象。使用 947 篇 AI 政策文档构建的 AGORA 语料库，结合基于 ColBERT 的检索器（对比学习微调）和 DPO 对齐的生成器进行实验。结果表明，领域特定微调虽然提升了检索指标，但并不总能带来端到端问答的一致性提升，揭示了检索改进和生成质量之间的复杂关系。

    出现于日报：03-27
