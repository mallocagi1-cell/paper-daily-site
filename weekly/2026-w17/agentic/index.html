    出现于日报：04-20

  3. 3. Mango: Multi-Agent Web Navigation via Global-View Optimization

    本文解决了现有 Web Agent 从根 URL 出发导致导航效率低下的问题，提出 Mango 多智能体网页导航框架。核心思路是将 URL 选择建模为多臂老虎机问题，利用 Thompson Sampling 自适应分配导航预算，并引入 episodic memory 从历史尝试中学习。在 WebVoyager 上达到 63.6%、WebWalkerQA 上达到 52.5% 的成功率，超越最佳基线 26.8%。

    出现于日报：04-23

  4. 4. GTA-2: Benchmarking General Tool Agents from Atomic Tool-Use to Open-Ended Workflows

    该论文提出 GTA-2，一个面向通用工具型 Agent 的分层基准测试，覆盖从原子工具调用到开放式工作流两个层次。研究发现前沿模型在原子任务上准确率不到 50%，在工作流任务上仅达 14.39% 成功率，揭示了当前 Agent 系统在复杂真实任务中的能力悬崖现象。采用递归检查点评估机制，能统一衡量模型能力与执行框架的贡献。

    出现于日报：04-21

  5. 5. MemSearch-o1: Empowering Large Language Models with Reasoning-Aligned Memory Growth in Agentic Search

    迭代式 agentic search 中 think-search 循环积累大量系统记忆，导致记忆稀释问题。本文提出 MemSearch-o1 框架，通过从查询中动态生长细粒度记忆片段（memory seed tokens），并利用贡献函数回溯和深度精炼记忆。在 8 个数据集上验证，该方法有效缓解记忆稀释，提升 LLM 在复杂多步搜索中的推理能力。

    出现于日报：04-22

  6. 6. PolicyBank: Evolving Policy Understanding for LLM Agents

    论文提出 PolicyBank，一种让 LLM Agent 通过交互和纠正反馈来迭代进化策略理解的记忆机制。针对自然语言策略规范中不可避免的歧义和逻辑缺口问题，PolicyBank 维护结构化的工具级策略洞察并持续优化，相比现有记忆机制在策略缺口场景中从近乎零成功率提升到缩小 82% 的人类与 AI 差距。

    出现于日报：04-21

  7. 7. AutoSearch: Adaptive Search Depth for Efficient Agentic RAG via Reinforcement Learning

    Agentic RAG 系统的多步检索交互常包含冗余搜索步骤，带来大量计算成本和延迟。本文研究搜索深度对准确率的影响，发现存在最小充分搜索深度（由问题复杂度和 agent 能力联合决定）。提出 AutoSearch RL 框架，在每步生成中间答案评估搜索充分性，奖励达到最优深度、惩罚过度搜索，实现 agent 自适应调整检索深度。

    出现于日报：04-22

    出现于日报：04-24

  9. 9. GraphRAG-Router: Learning Cost-Efficient Routing over GraphRAGs and LLMs with Reinforcement Learning

    现有 GraphRAG 系统采用一刀切设计，对所有查询使用固定检索框架和单一大模型生成器，无法适配不同复杂度问题。本文提出 GraphRAG-Router，采用分层路由策略协调异构 GraphRAG 和多种生成器 LLM。通过 SFT 预热后两阶段 RL 优化（第二阶段引入课程式成本感知奖励），在 6 个通用和多跳 QA 基准上减少大模型使用近 30%，同时保持强泛化能力。

    出现于日报：04-22

  10. 10. W&D: Scaling Parallel Tool Calling for Efficient Deep Research

    Salesforce 提出 Wide and Deep (W&D) 研究型 Agent 框架，通过在单个推理步骤内并行调用多个工具（宽度扩展）来提升深度研究效率。在 BrowseComp 基准上，使用 GPT-5-Medium 达到 62.2% 准确率，超过 GPT-5-High 的 54.9% 基线，且无需上下文管理等额外技巧。该方法避免了复杂的多 Agent 编排，仅利用模型内在的并行调用能力。

    出现于日报：04-21
