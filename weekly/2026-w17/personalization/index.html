    出现于日报：04-23

  3. 3. Modular Representation Compression: Adapting LLMs for Efficient and Effective Recommendations · 📖 深度解读

    本文发现一个反直觉现象：LLM 中间层表征在推荐任务上优于最终层输出，说明 LLM 的深层语义压缩可能丢失了推荐所需的特征多样性。基于此洞察，作者提出 MARC（Modular Representation Compression），显式引入压缩和任务适配模块，利用信息约束解耦不同任务的表征需求。MARC 已被 SIGIR 2026 接收，在大规模商业搜索广告场景的在线 A/B 测试中取得 2.82% 的 eCPM 提升。

    出现于日报：04-22

  4. 4. GenRec: A Preference-Oriented Generative Framework for Large-Scale Recommendation · 📖 深度解读

    针对大规模推荐系统中生成式检索的扩展性难题，提出 GenRec 框架，包含三项核心创新：Page-wise NTP 任务将监督粒度从单个 item 提升到整页交互序列，非对称线性 Token Merger 将输入长度压缩约 2 倍，GRPO-SR 强化学习方法结合策略优化与奖励机制进行排序优化。已在京东 App 全量部署，线上 A/B 测试点击量提升 9.5%，成交量提升 8.7%。

    出现于日报：04-20

  5. 5. Multi-Epoch Learning with Data Augmentation for Deep Click-Through Rate Prediction · 📖 深度解读

    MEDA 提出首个通用可靠的深度 CTR 模型多轮训练策略。工业界 CTR 模型普遍面临多轮训练过拟合问题（样本重复暴露导致 embedding 层过拟合），现有方案需针对特定模型调参。MEDA 通过特征级数据增强和自适应正则化，在不同 CTR 模型架构（DeepFM、DCN、DIN 等）上均能稳定提升多轮训练效果，AUC 提升 0.3-0.8%。

    出现于日报：04-21

  6. 6. Sample Is Feature: Beyond Item-Level, Toward Sample-Level Tokens for Unified Large Recommender Models · 📖 深度解读

    提出 Sample-Level Token 范式，突破工业推荐模型的两大瓶颈：样本信息扩展（通过更深更长行为序列丰富训练信号）和模型容量扩展（在单一 Transformer 骨干中统一序列建模与特征交互）。将每个训练样本的全部信息（用户特征、上下文、行为序列）统一编码为 token 序列，使 Transformer 自然处理跨模态交互。

    出现于日报：04-21

  7. 7. Modernizing the Facebook Groups Search to Unlock the Power of Community Knowledge

    Meta 对 Facebook Groups 搜索系统进行了根本性升级，采用混合检索架构并实施基于模型的自动化评估体系，解决用户在社区内容搜索中的核心痛点。新框架帮助用户更可靠地发现、筛选和验证最相关的社区内容，在发现效率、内容排序准确性和用户信任度等维度均取得显著提升。这是一个典型的 UGC 社区搜索现代化改造案例。

    出现于日报：04-22

  8. 8. Decoupled Multimodal Fusion for User Interest Modeling in Click-Through Rate Prediction · 📖 深度解读

    提出 DMF（Decoupled Multimodal Fusion）方法，增强 ID 协同表征与多模态表征之间的细粒度交互。核心设计包括 target-aware 特征桥接不同嵌入空间的语义鸿沟，以及解耦注意力机制降低计算开销。在 Lazada 电商平台实际部署，CTCVR 提升 5.30%，GMV 提升 7.43%。已被 ICDE 2026 录用。

    出现于日报：04-20
