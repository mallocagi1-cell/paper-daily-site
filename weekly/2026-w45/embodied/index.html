  2. 2. LeRobot: An Open-Source Library for End-to-End Robot Learning

    机器人学习的工具链很碎：电机通信、数据采集、数据集格式、训练算法和推理部署往往各用一套，换一台机器人或一个数据集就要重新拼一遍，别人的结果也很难复现。LeRobot 把整条链路放进一个开源库：从底层电机控制和低成本硬件接入，到统一的数据集格式和流式读取，再到多种主流策略算法的实现和异步推理。它的价值不在提出新算法，而在于让不同实验室的数据和结果能放在同一套工具里对比和复用。

    出现于日报：11-03

    出现于日报：11-02
