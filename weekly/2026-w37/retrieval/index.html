2026-09-07 ~ 09-13 · AI 搜索

  1. 1. SAM-D2Q: Aligning Multimodal Doc2Query with Search Demand and Conversion for E-commerce

    针对短标题遗漏商品属性、用户表达与商家用词不一致的问题，SAM-D2Q 用图文监督、反事实视觉增强和业务奖励优化生成扩展查询，补充布尔索引中的有效召回词。AliExpress 线上 A/B 显示 GMV 提升 3.38%、支付笔数提升 2.27%；扩展内容离线写入索引，线上无需运行生成模型。

    出现于日报：09-08

  2. 2. Matryoshka Hash Representations for Model-Aware Compact Semantic Retrieval

    论文用分阶段训练解决二值向量在多种存储预算下相互干扰的问题：先学习完整哈希码，再冻结主模型，用残差适配器组织可独立检索的短前缀。在七个 BEIR 数据集上，32 字节编码的平均 nDCG@10 为 0.556、Recall@100 为 0.653，高于同预算 JPQ-FT 的 0.524、0.638，但低于完整浮点向量。

    出现于日报：09-10

  3. 3. DoPR: Reusable Compressed Document Prefixes for Efficient LLM Reranking · 📖 深度解读

    针对同一文档被不同查询反复编码的开销，DoPR 离线选择显著 token，将其转换为可复用的多层前缀状态，在线仅处理查询与评分 token。在 TREC DL、BEIR 和 BRIGHT 上，0.6B 至 8B 模型保留对应完整重排器平均 nDCG@10 的 97.1%–99.5%；长文档 Covid 设置最高加速 8.04 倍，短文档 DL19 为 1.21–1.84 倍。

    出现于日报：09-07

  4. 4. Embedding Surgery: Localized Updates for Adaptive Ranking Correction in Dense Retrieval

    针对离线文档向量难以及时响应反馈的问题，Embedding Surgery 将排序纠错建模为凸优化，在满足偏好约束的同时最小化局部向量改动。论文在 TREC 与 MS MARCO 系列集合验证；编辑反馈条件下，DL-Hard 的 nDCG@10 最高相对提升 60.64%，并测试了无需重建 ANN 索引的原位更新。

    出现于日报：09-08

  5. 5. Q2D-Web: A Large-Scale Benchmark for Retrieval in Agentic RAG Systems

    Q2D-Web 面向生产搜索的一阶段召回评测，提供 1.9 亿网页、7 万条来自真实用户需求的代理改写查询，覆盖十种语言，并比较 13 个词法、稠密及晚交互检索器。基于 RRF 选取三分之一语料能保持组合标注下的模型排序，但 Recall@1000 绝对值仍虚高 3 至 7 个百分点。

    出现于日报：09-10

  6. 6. EigenLI: Spectral Approximations to Late Interaction

    EigenLI 利用文档 token 向量的低秩结构，通过主特征方向压缩晚交互表示，并构造可用于 ANN 的单向量近似。在 ColBERTv2 的 32 维子空间设置下，nDCG@10 相对 KMeans++ 压缩的几何平均提升为 13.8%，但相对完整 MaxSim 仍低 3.3%；GTE-ModernColBERT 上部分聚类方案更优。

    出现于日报：09-10

  7. 7. Tracing Query Expansion Effects through Sparse Autoencoder Features

    论文通过稀疏自编码器分解检索器逐层表征，定位查询扩展引起的潜在特征变化，再对意图和实体属性相关特征施加激活干预。SimLM 在 TREC DL19 的 nDCG@10 从 59.438 升至 60.941，DL20 从 62.968 升至 64.372；Qwen 检索器上的收益更小，说明效果依赖底座与数据集。

    出现于日报：09-10

  8. 8. Tool Retrievers Are Underestimated: Annotation Expansion Reveals True Capability

    ToolEX 通过查询拆解、功能验证和组合审计扩充工具检索的等价答案。原始基准含 7360 条查询，其中 67.9% 的子查询存在替代工具，扩充后每条查询平均有 5.3 组有效组合；八个基础检索器的 nDCG@10 平均增加约 6.5 个百分点，而原先报告的部分微调增益有 30% 至 47% 来自标注偏差。

    出现于日报：09-10

  9. 9. Better Together: Complementary Query Rewriting Under a Strong RAG Baseline

    研究在固定 BGE 召回、cross-encoder 重排及 MMR 流程中比较查询改写。企业合成语料上，四路结果事后合并使 HIT@10 从 39.22 升至 51.70；仅在低置信查询上触发改写的模拟路由带来约 4.3 个百分点收益，改写比例低于 40%。但 AmbigNQ 上盲目融合反而比最佳单路低约 2.4 个百分点。

    出现于日报：09-10

  10. 10. From Topical Relevance to Answerability: Entailment Distillation for Conversational Retrieval

    CLEAR 解决对话检索中主题相近却无法回答当前问题的错配：把答案与段落的蕴含监督蒸馏给重排器，并离线生成段落可回答的查询补充召回。同一 RRF 候选池上，TopiOCQA 的 MRR 从普通 cross-encoder 的 31.2 升至 46.2，QReCC 从 68.2 升至 69.3；单 A6000 测得总在线时延为 171.9 毫秒。

    出现于日报：09-07
