2026-09-07 ~ 09-13 · 生成式推荐

  1. 1. LLM4AIGQ: LLM-based AI Guidance Query Generation Framework for Multi Interest Mining · 📖 深度解读

    阿里提出面向多兴趣用户的引导查询生成框架，以单兴趣样本学习表达，再用分层奖励训练兴趣拆分，最后通过偏好优化将思考能力迁移到直接生成。天猫线上实验在10%流量时报告uCTR相对提升4.46%，扩大至40%流量后的六天验证仍提升2.53%；查询由近线生成、线上读取。

    出现于日报：09-07

  2. 2. REDSI: Addressing the Reproducibility and Evaluation Consistency of Differentiable Search Indexing for Document Retrieval · 📖 深度解读

    论文针对 DSI 基线难以复现、NQ320K 构造口径不统一的问题，发布覆盖原子、任意数字和语义三类标识符的 ReDSI，并拆分文档去重与文本序列化流程。在 Title/NciNorm 设置下，4400 万参数原子模型的 MRR@10 达到 62.2，超过 2.2 亿参数的任意数字标识符模型 60.1 和 Semantic ID 模型 59.7。

    出现于日报：09-10

  3. 3. PDMR: Passage-Driven Multi-ID Document Retrieval · 📖 深度解读

    PDMR 将文档拆成多个语义片段，用“文档标题／片段标题”构建标识，并通过多目标损失学习多个有效访问路径。MS MARCO Doc 上 R@1 为37.71、MRR@10为48.66；NQ320K上 R@1 为67.6，高于MINDER的62.7，但R@10略低于后者。

    出现于日报：09-11

  4. 4. AtomRec: Evolving Atomic Memory for Agentic Recommendation · 📖 深度解读

    AtomRec 把用户与内容历史拆成带关键词、标签、时间和关联链接的原子记忆，用大模型更新局部字段，再沿两跳语义路径汇集证据完成推荐。四个公开基准上相对最强基线平均提升约 8.5%；Books 的 NDCG@5 从 MemRec 的 0.6480 升至 0.7130，主实验每次仅重排 10 个候选。

    出现于日报：09-08

  5. 5. EPIC: Explicit Posterior Item Conditioning for Semantic ID Diffusion Recommendation

    EPIC在 Semantic ID 扩散去噪的每一步显式比较仍可到达的完整物品，将结合用户近期行为得到的物品后验反馈至未确定的ID位置。四个Amazon数据集的16组指标均优于对照，相对次优方法提升1.2%—16.8%；仅训练39.1万参数，但T4单用户推理时间由93.0增至124.8毫秒。

    出现于日报：09-07

  6. 6. WIDE: Wildcard Inference with Dynamic Expansion for Cross-Modal Generative Retrieval · 📖 深度解读

    针对短查询无法描述图像全部细节、生成式检索却被迫猜测离散标识的问题，WIDE用分层熵阈值触发通配符扩展，再融合生成置信度与向量相似度重排。在M-BEIR上，VisualNews的R@5从GENIUS的27.4升至30.2，CIRR从39.5升至41.5；尚未超过强向量基线U-MARVEL。

    出现于日报：09-09

  7. 7. Collaborative Memory Augmentation for Generative Recommendation

    OMEGA 为生成式推荐增加跨用户协同记忆：先将行为片段压成少量潜在向量，再按序列与目标相似性检索，并用门控交叉注意力融合。Game 数据集上，TIGER 的 NDCG@5 从 0.0380 升至 0.0470，提升 23.68%；Pctx 从 0.0416 升至 0.0480，提升 15.38%。

    出现于日报：09-08

  8. 8. SelfDR: Self-Distillation from Reasoning for LLM-Based Recommendation

    SelfDR先训练能为推荐提供有效解释的推理器，再让同底座学生通过动态加权自蒸馏学习教师的推荐分布，线上直接输出物品标识。Clothing上的列表NDCG@5为0.0228，对照SOFT与COT4Rec均为0.0217；单张A800测得推理109.46毫秒，接近无推理SOFT的109.48毫秒。

    出现于日报：09-07

  9. 9. HypRQ-VAE: Hyperbolic Item Indexing for Long-Tail-Aware Generative Recommender Systems

    HypRQ-VAE将物品文本表示映射到双曲空间，再做残差量化并生成 Semantic ID，以改善长尾物品在生成式推荐中的表示。在MovieLens、Instruments和Arts上验证，Instruments的NDCG@10从最强基线LC-Rec的0.0570升至0.0650，约提升14.0%；论文同时分析头尾物品的量化误差与曝光组成。

    出现于日报：09-07

  10. 10. Distill Globally, Adapt Locally: Reasoning Distillation and Product-Type Test-Time Training for Scalable Trade-Up Recommendation

    该工作将 LLM 对商品升级推荐的关系判断与理由蒸馏到 15.5M 参数分类器，再用少量品类样本适配冻结学生。8,352 对人工标注样本上，四分类学生 AUC 从仅标签训练的 0.912 升至 0.924，品类适配后达 0.941；最终服务只读取两条预计算的 768 维商品向量。

    出现于日报：09-08
