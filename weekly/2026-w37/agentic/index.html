2026-09-07 ~ 09-13 · 智能体搜索

  1. 1. Inventory-Grounded Policy-Level Optimization for Training-Free AI Search

    IGPO 针对商品目录持续变化、缺少训练标签的 AI 搜索，把稳定的策略规则与实时库存事实分离，通过探测库存、离线对比轨迹和回放验证更新检索策略。华为团队在商业智能助手部署该方案，14 天线上 A/B 的 CTR 相对提升 3.17%，人工审计坏例减少 38.9%。

    出现于日报：09-08

  2. 2. Procedural Graphs: Self-Evolving Execution Structures for LLM Agents

    论文把智能体的操作顺序与执行条件表示为过程图，每步只读取当前节点附近的子图，再根据成功与失败轨迹修改结构。在图构建对照实验中，从零在线演化使 HotpotQA 答案 EM 从 58.8 升至 66.3，F1 从 71.21 升至 78.79；修改需通过留出验证集才会保留。

    出现于日报：09-10

  3. 3. First Things First: Teaching LLM-Based Agents to Prioritize Must-Haves before Nice-to-Haves

    FTF-rl 将用户需求区分为必须满足与可选偏好，并覆盖唯一解、多解和无解三种情形。FTF-bench 包含 3,649 道电商、预订及出行问题；在留出的 10% 测试集上，Qwen2.5-VL-7B 平均正确率由 39.78% 升至 55.80%，但无解场景从 44.26% 降至 42.62%。

    出现于日报：09-09

  4. 4. Making Every Tool Call Count: Necessary Tool-Evidence Path Rewards for Agentic Vision-Language Models

    为减少视觉搜索 Agent 的无效调用，论文以必要工具证据路径标注每个问题，分别奖励调用前的证据目标对齐、调用后的信息获取，并惩罚重复目标。NTEP-8B 在统一三工具框架下的七个评测切分平均准确率为 70.34，比复现的 SenseNova-MARS 高 2.03 点；搜索类任务平均调用次数由 2.54 降至 1.89。

    出现于日报：09-07

  5. 5. When Users Don't Ask: Benchmarking Context-Driven Memory Retrieval in Conversational Agents

    LoCoMo-Conv 将记忆问答改写成对话、隐式、反事实和组合四类请求，分别评估五种记忆系统的检索与回答。AnchorMem 的隐式查询 recall@10 为 0.368，多角度改写加 RRF 后升至 0.524；组合查询从 0.279 升至 0.432。摘要型记忆并未稳定受益，说明显式问答成绩难以代表真实对话。

    出现于日报：09-07

  6. 6. A Tree-based RAG Framework for Evidence-Intensive QA via Adaptive Planning and Topology-Aware Evidence Gathering

    APT-RAG 面向答案分散在大量文档中的复杂问答，按依赖关系动态扩展问题树，复用兄弟节点证据并汇聚子节点结果，再把共享证据的子问题合批生成。Qwen3-30B 下，MoNaCo 的答案 F1 从普通 RAG 的 46.64 提升到 50.84，QAMPARI 从 20.46 提升到 23.28。

    出现于日报：09-08

  7. 7. Environments as Scaffold: Enriching Feedback to Bootstrap Self-Evolving Agents in Long-Horizon Tasks

    论文通过改造训练环境缓解长程 Agent 的稀疏奖励：前期提供行动提示，后期丰富工具观察，并逐渐让策略内化这些信息。Qwen3-4B 配合 DAPO 时，BFCL 与 SciWorld 的平均分从 43.88 升至 47.81；Qwen3-8B 配合 GSPO 时从 41.78 升至 46.39，但部分子任务出现退步。

    出现于日报：09-10

  8. 8. CoBRA: Learning Tool-Use Boundaries via Counterfactual Margins

    CoBRA 针对搜索智能体不必要调用工具的问题，比较同一问题使用与不使用工具的收益差，再结合边界感知监督微调和反事实强化学习训练路由策略。在 Qwen3-4B 上，相对 Search-R1-3B，域内与域外工具调用分别减少 20.1% 和 22.2%，效用指标分别增加 0.0759 和 0.0866。

    出现于日报：09-09

  9. 9. Dense Process Supervision for Search Agents via Fact Utility Estimation

    FactAgent 将搜索推理过程表示为证据事实的积累，从原始观测抽取结构化事实并聚合同义事实，再用组内轨迹的贝叶斯估计生成密集步骤奖励。研究覆盖 7 个单跳及多跳问答基准，7B 模型平均 EM 超过最强基线 3.2 点；系统只使用本地 Wiki-18 索引，每题最多运行 8 轮。

    出现于日报：09-09

  10. 10. AgenticRag-R1: Agentic Reinforcement Learning with Stack Memory for Multi-Step Reasoning, Retrieval and Memorizing

    AgenticRag-R1 将推理、检索和记忆栈操作纳入细粒度动作空间，配合分层动作奖励及信息感知轨迹筛选训练长程搜索行为。Qwen2.5-3B 在七项评测上的平均 F1 为 33.55，高于 Search-R1 的 30.16；移除记忆动作或轨迹筛选后分别降至 27.37 和 25.43。

    出现于日报：09-08
