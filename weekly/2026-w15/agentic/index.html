  1. 1. Detecting and Correcting Reference Hallucinations in Commercial LLMs and Deep Research Agents

    该论文系统评估了 10 个商业 LLM 和深度研究 Agent 在引用 URL 生成中的幻觉问题。通过对 DRBench（53,090 条 URL）和 ExpertQA（168,021 条 URL，涵盖 32 个学科）的大规模实验，发现 3-13% 的引用 URL 为幻觉（从未存在），5-18% 无法解析。深度研究 Agent 虽然生成了更多引用但幻觉比例更高…

    出现于日报：04-07

  2. 2. Single-Agent LLMs Outperform Multi-Agent Systems on Multi-Hop Reasoning Under Equal Thinking Token Budgets

    该论文通过信息论中的数据处理不等式（Data Processing Inequality）从理论上论证了在等量推理 token 预算下，单 Agent 系统在信息保留方面优于多 Agent 系统。实验在多跳推理任务上验证了这一结论：当计算量标准化后，单 Agent 系统能匹配甚至超越多 Agent 系统（MAS），因为 Agent 间通信会导致信息压缩损失。

    出现于日报：04-07

  3. 3. Multi-Turn Reinforcement Learning for Tool-Calling Agents with Iterative Reward Calibration

    针对多轮工具调用 agent 训练中奖励稀疏和信用分配困难的问题，本文首次将 MT-GRPO（多轮 Group Relative Policy Optimization）与 GTPO（Generalized Token-level Policy Optimization）结合用于训练工具调用 agent。核心创新是提出 Iterative Reward Calibration（迭代奖励校准）方法论…

    出现于日报：04-10

  4. 4. Beyond Stochastic Exploration: What Makes Training Data Valuable for Agentic Search

    当前基于 RL 的搜索 agent 依赖随机探索和精心设计的结果奖励进行训练，导致推理轨迹低效、训练不稳定。本文提出 HiExp（Hierarchical Experience）框架，从训练数据质量而非策略探索角度优化 agentic search 的 RL 训练。核心思路是构建层次化的经验库，分层管理不同粒度的搜索经验，让 agent 从高价值轨迹中学习而非随机采样…

    出现于日报：04-10

  5. 5. Prompt Compression in the Wild: Measuring Latency, Rate Adherence, and Quality for Faster LLM Inference

    该论文首次在真实 RAG 系统部署环境中系统评估了 prompt 压缩技术的延迟、压缩率遵从度和生成质量三方面权衡。研究指出，RAG 系统中检索到的长文段导致 prompt 过长成为推理延迟瓶颈。通过对多种压缩方法在实际工作负载上的测量，发现压缩预处理带来的额外开销在某些场景下可能抵消推理加速，需要针对具体延迟预算和质量要求做精细调优。

    出现于日报：04-07

  6. 6. InfoSeeker: A Scalable Hierarchical Parallel Agent Framework for Web Information Seeking

    该论文针对现有 agentic search 系统在大规模信息综合中的瓶颈（上下文饱和、级联错误传播、高端到端延迟），提出 InfoSeeker 框架。该框架采用分层并行架构，将信息搜索任务分解为层次化子任务，由并行 worker agent 执行检索和证据聚合，orchestrator agent 负责协调和综合，解决了数据密集型场景下的可扩展性问题。

    出现于日报：04-07

  7. 7. Self-Optimizing Multi-Agent Systems for Deep Research

    该论文探索了深度研究系统中多 Agent 的自动优化方法。传统 Deep Research 系统依赖手工 prompt 和静态架构，改进成本高且脆弱。论文在 orchestrator-worker 架构基础上，测试了多种 Agent 优化方法（如 prompt 自动调优、架构搜索等），展示了通过自优化让系统自动改进 retrieval 和 synthesis 质量，降低人工调参依赖。

    出现于日报：04-07

  8. 8. SealQA: Raising the Bar for Reasoning in Search-Augmented Language Models

    提出 SealQA 基准，专门评估搜索增强语言模型在网页搜索结果冲突、噪声或无用时的事实推理能力。SealQA 包含三个变体：Seal-0（主评测）和 Seal-Hard 评估事实准确性和推理能力，其中 Seal-0 聚焦于 GPT-4.1 等聊天模型准确率接近 0 的最具挑战性问题；第三个变体侧重不同场景。评测覆盖多种前沿搜索增强 LM，揭示当前系统在面对矛盾搜索结果时的推理瓶颈。

    出现于日报：04-10

  9. 9. Terminal Agents Suffice for Enterprise Automation

    该论文挑战了当前 agentic AI 领域的复杂化趋势，论证仅配备终端（terminal）和文件系统的编程 agent 即可完成大量企业自动化任务，无需 MCP (Model Context Protocol)、Web GUI agent 等复杂抽象。实验表明简单的终端 agent 在成本和可靠性上优于基于 MCP 和 Web 交互的复杂 agent 方案。

    出现于日报：04-07

  10. 10. SubSearch: Intermediate Rewards for Unsupervised Guided Reasoning in Complex Retrieval

    面向复杂查询需要多步推理但无预定推理路径的检索场景，提出 SubSearch 方法，通过中间奖励引导 LLM 在无监督条件下进行复杂检索推理。核心思路是在强化学习框架中引入检索中间步骤的奖励信号，而非仅依赖最终检索结果的稀疏奖励，从而指导模型学习有效的多步检索策略。该方法无需预标注推理路径，适用于推理结构未知的开放式检索任务。

    出现于日报：04-10
