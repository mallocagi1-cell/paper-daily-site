  2. 2. Realizing Scaling Laws in Recommender Systems: A Foundation-Expert Paradigm for Hyperscale Model Deployment · 📖 深度解读

    Meta 提出 Foundation-Expert 范式，解决超大规模推荐基础模型的部署挑战。核心架构为：一个在跨平台、多模态用户终身数据上训练的中央基础模型，通过 target-aware embedding 将知识迁移到轻量级、平台专属的"专家"模型。该系统已在 Meta 生产环境部署，每日服务数百亿用户请求，在线指标相比单阶段系统有显著提升，是首个在此规模成功部署 Foundation-Expert 范式的案例。

    出现于日报：04-07

    出现于日报：04-08

  4. 4. AdaptFuse: Training-Free Sequential Preference Learning via Externalized Bayesian Inference

    该论文提出 AdaptFuse，一种无需训练的框架，通过外部化贝叶斯推理实现 LLM 多轮交互中的偏好累积学习。框架由两个模块组成：符号模块维护离散假设集上的贝叶斯后验，冻结 LLM 通过多样本 Dirichlet 聚合贡献语义推理。两个信号通过熵自适应融合组合——随证据累积自动从 LLM 依赖转向符号后验。在航班推荐、酒店推荐和网购三个场景上，在 Gemma 2 9B、Llama 3 8B 和 Qwen 2.5 7B 上验证有效。

    出现于日报：04-08

    出现于日报：04-07

  6. 6. Retrieval Augmented Conversational Recommendation with Reinforcement Learning

    该论文提出 RAR，一种两阶段检索增强对话推荐框架。针对现有 LLM-based 对话推荐系统依赖预训练知识、缺乏外部检索机制、无统一语料库等问题，构建了包含 30 万+ 电影及丰富元数据（标题、演员、剧情简介）的大规模电影语料库。RAR 通过对齐检索与生成过程来增强推荐性能和事实准确性，使用强化学习优化两阶段流程的端到端表现。

    出现于日报：04-08

  7. 7. NVIDIA recsys-examples: Efficient Training and Inference for Generative Recommender Systems

    NVIDIA 发布开源 recsys-examples 项目，为生成式推荐系统提供工业级训练和推理最佳实践。基于 HSTU (Hierarchical Sequential Transduction Units) 架构，覆盖了从数据预处理、分布式训练到部署优化的完整工程链路。提供 GPU 加速的高效实现，支持大规模序列推荐模型的训练。

    出现于日报：04-08

  8. 8. LLaDA-Rec: Discrete Diffusion for Parallel Semantic ID Generation in Generative Recommendation

    该论文提出 LLaDA-Rec，首次将离散扩散模型应用于生成式推荐中的 Semantic ID 并行生成。传统自回归解码在生成式推荐中存在三大局限：(1) 难以联合捕获多维特征间的全局依赖；(2) 假设所有用户以相同顺序关注物品属性；(3) 推理时效率低。LLaDA-Rec 通过离散扩散过程实现并行生成，克服了这些局限。

    出现于日报：04-08

  9. 9. Reinforced Latent Reasoning for LLM-based Recommendation

    提出 LatentR3，通过在隐空间中进行推理来实现推理高效的 LLM 推荐，无需显式 Chain-of-Thought 生成。采用两阶段训练：(1) SFT 热启动初始化隐推理模块；(2) 基于改进的 GRPO 算法进行 RL 训练，用规则化奖励设计和连续奖励信号实现高效学习。少量隐 token 即可捕获完整推理过程，在多种 LLM 推荐方法上显著提升性能。

    出现于日报：04-07

  10. 10. Beyond Hard Negatives: The Importance of Score Distribution in Knowledge Distillation for Dense Retrieval

    该论文揭示了知识蒸馏训练密集检索模型时，仅关注难负例 (hard negatives) 的局限：学生模型无法学习教师模型的完整偏好结构，影响泛化能力。提出分层采样 (Stratified Sampling) 策略，均匀覆盖教师打分的整个分布频谱。实验在领域内和领域外基准上证明，保持教师分数方差和熵的分层采样显著优于 top-K 和随机采样。

    出现于日报：04-08
