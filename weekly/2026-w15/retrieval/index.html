  4. 4. Efficient Learning of Sparse Representations from Interactions

    本文提出一种从用户交互数据直接学习高维稀疏 embedding 的训练策略，修改 ELSA 协同过滤自编码器来生成稀疏表示，取代传统稠密 embedding。实验实现了高达 10 倍的 embedding 压缩而不损失精度，100 倍压缩仅损失 2.5% 精度。学到的稀疏表示还展现出与模型潜空间对齐的可解释结构，可用于分群级别的推荐和检索。代码和 demo 已开源。

    出现于日报：04-07

  5. 5. Improving Neural Retrieval with Attribution-Guided Query Rewriting

    本文提出一种基于梯度归因（gradient-based token attribution）引导 LLM 进行查询改写的方法，用于改进神经检索。核心思路是从检索器中计算各 token 的梯度归因分数，识别查询中语义薄弱或误导性的成分，然后将归因信息作为 prompt 引导 LLM 精确地澄清和改写这些成分。在 BEIR 多个数据集上的评估表明，该方法能持续提升检索效果，尤其在查询表述不精确的场景下改善显著。

    出现于日报：04-10

  6. 6. DGAI: Decoupled On-Disk Graph-Based ANN Index for Efficient Updates and Queries

    针对十亿级近似最近邻搜索（ANNS）的磁盘图索引，提出解耦存储架构 DGAI：将重型向量数据与轻量图拓扑物理分离。现有系统的耦合存储在索引更新时产生大量冗余 I/O，DGAI 通过解耦设计，配合相似性感知动态布局优化和基于层级 PQ 的两阶段查询机制，实现了插入 8.17 倍、删除 8.16 倍的性能提升，混合工作负载下峰值查询延迟降低 67%。

    出现于日报：04-07

  9. 9. AnnoRetrieve: Efficient Structured Retrieval for Unstructured Document Analysis

    提出 AnnoRetrieve，一种从 embedding 范式转向结构化标注的新型检索方法。通过 SchemaBoot 自动为非结构化文档生成结构化 schema，再用结构化语义检索（SSR）基于标注进行精准匹配，替代传统的向量相似度检索。该方法大幅减少 LLM 调用次数和整体成本，在实际数据集上实现高精度检索，同时解决了 embedding 检索在粗粒度语义匹配上的局限。
