  1. 1. Spend Search Where It Pays: Value-Guided Structured Sampling and Optimization for Generative Recommendation · 📖 深度解读

  3. 3. To Memorize or to Retrieve: Scaling Laws for RAG-Considerate Pretraining

    该论文系统研究语言模型预训练中参数化知识（模型记忆）与非参数化知识（检索增强）之间的 scaling trade-off。作者训练了从 30M 到 3B 参数的 OLMo-2 模型，预训练数据量达 100B tokens，同时变化预训练语料和检索库大小。核心发现：检索在所有模型规模上一致优于纯参数化基线，但检索的边际价值随模型大小、任务类型和训练饱和度显著变化。提出了可预测数据资源分配的 scaling 框架。

    出现于日报：04-03

    出现于日报：04-01

  7. 7. ATLAS-RTC: Closing the Loop on LLM Agent Output with Token-Level Runtime Control

    提出 ATLAS-RTC，一种面向自回归语言模型的运行时控制系统，在每步解码时检测输出偏离预设结构约束的信号，并通过 biasing（概率偏移）、masking（token屏蔽）、rollback（回退重生成）三种干预手段实时校正。与后验校验或静态约束解码不同，ATLAS-RTC 构成闭环控制，能在错误产生前纠正。在结构化生成和工具调用任务上，首次成功率提升 20-37.8 个百分点，在失败主导场景下延迟降低最多 88%。

    出现于日报：04-01

  8. 8. Retrieval-of-Thought: Efficient Reasoning via Reusing Thoughts

    该论文提出 Retrieval-of-Thought (RoT)，通过复用历史推理步骤来加速大型推理模型。将推理步骤组织为带有顺序和语义边的思维图（thought graph），支持快速检索和灵活重组。推理时检索与查询相关的节点，通过奖励引导遍历组装定制化模板指导生成。实验结果显示：输出 token 减少 40%，推理延迟降低 82%，成本降低 59%，同时保持准确性。

    出现于日报：04-03

  9. 9. Universal YOCO for Efficient Depth Scaling

    该论文提出 Universal YOCO (YOCO-U)，将 YOCO decoder-decoder 架构与递归计算相结合。通过浅层注意力层的参数共享实现多次迭代，保持恒定的全局 KV 缓存和线性预填充。部分递归增强了表示深度。在通用和长上下文基准测试中保持强竞争力，为高效注意力架构与递归计算的结合提供了新范式。

    出现于日报：04-03

  10. 10. Using Predefined Vector Systems to Speed Up Neural Network Multimillion Class Classification

    该论文提出利用预定义向量系统将神经网络百万级别分类的复杂度从 O(n) 降至 O(1)。通过将标签预测与已知几何性质的向量系统中的最近聚类中心搜索关联，仅需识别 embedding 的最大和最小值即可完成预测。实验表明，相比传统方法实现了高达 11.6 倍的整体加速，同时保持训练精度并支持新类别检测。

    出现于日报：04-03
