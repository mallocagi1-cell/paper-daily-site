  1. 1. Seed1.8 Model Card: Towards Generalized Real-World Agency · 📖 深度解读

    ByteDance 发布 Seed1.8 基础模型，目标是通用的真实世界代理能力：从单轮预测扩展到多轮交互、工具使用和多步执行。该模型保持了强大的 LLM 和视觉语言性能，同时支持统一的 agentic 接口——搜索、代码生成与执行、GUI 交互。部署层面提供延迟和成本感知推理，包括可配置的思考模式和优化的视觉编码。在标准 benchmark 和应用对齐工作流上进行了涵盖基础能力、多模态理解和 agentic 行为的全面评估。

    出现于日报：04-01

  2. 2. Experience as a Compass: Multi-agent RAG with Evolving Orchestration and Agent Prompts

    针对多智能体 RAG 系统中静态行为和固定编排导致多跳任务表现脆弱的问题，提出 HERA 框架，在全局层面通过奖励引导采样和经验积累优化查询特定的 agent 拓扑结构，在局部层面通过角色感知提示进化（Role-Aware Prompt Evolution）基于信用分配和双轴自适应来优化各 agent 行为。该方法实现了编排策略和角色提示的联合演化，可直接应用于搜索推荐场景中的复杂多步检索和推理任务。

    出现于日报：04-03

  3. 3. AgentSwing: Adaptive Parallel Context Management Routing for Long-Horizon Web Agents

    针对 LLM 自主代理在长时域信息搜索中有限上下文容量的瓶颈，提出 AgentSwing 自适应并行上下文管理路由框架。现有方法在整个轨迹中使用单一固定上下文管理策略，无法适应累积上下文的有用性变化。AgentSwing 引入概率框架，从搜索效率和终端精度两个维度刻画长时域成功率，在每个触发点并行扩展多个上下文管理分支，通过前瞻路由选择最优延续路径。在多个多样化 benchmark 上验证了有效性。

    出现于日报：04-01

  4. 4. Asymmetric Actor-Critic for Multi-turn LLM Agents

    提出非对称 Actor-Critic 框架，用于提升多轮 LLM agent 的可靠性。利用强大的商业 LLM 作为 actor 执行任务，同时训练小型开源 critic 在同一交互轨迹内实时监督并干预。巧妙利用了生成-验证不对称性：高质量生成困难但验证相对容易。该设计不需要修改 actor 模型参数，可直接应用于商业 API 场景。

    出现于日报：04-03

  5. 5. CLAUSE: Agentic Neuro-Symbolic Knowledge Graph Reasoning via Dynamic Learnable Context Engineering

    针对知识图谱上多跳问答中静态扩展效率低、上下文膨胀和运行时不可控的问题，提出 CLAUSE——一个三智能体神经符号框架，将上下文构建建模为知识图谱上的序列决策过程。核心创新在于引入 Lagrangian-Constrained Multi-Agent PPO (LC-MAPPO) 算法协调三个智能体（子图扩展、路径选择、证据保留），用户可指定延迟和成本预算，实现每查询级别的准确率-延迟-成本权衡，无需重新训练…

    出现于日报：04-02

  6. 6. Oblivion: Self-Adaptive Agentic Memory Control through Decay-Driven Activation

    提出 Oblivion 记忆控制框架，将遗忘建模为可访问性的衰减驱动降低而非显式删除。将记忆控制解耦为读写路径：读路径根据 agent 不确定性和缓冲充足度决定何时查询记忆（避免冗余的 always-on 检索）；写路径通过强化对回答有贡献的记忆来决定保留什么。这种分层记忆组织在保持高层策略的同时动态加载细节，显著降低长历史场景下的干扰和延迟。

    出现于日报：04-03

  7. 7. DeepResearcher: Scaling Deep Research via Reinforcement Learning in Real-world Environments

    首个针对 LLM deep research agent 的端到端 RL 训练框架，直接在真实 web 搜索环境中训练，而非在封闭 RAG 语料库上。相比提示工程基线提升 28.9 分，相比 RAG-based RL agent 提升 7.2 分。训练过程中自发涌现了计划制定、跨源交叉验证、自我反思和诚实拒答等认知行为。开源代码可用。

    出现于日报：04-03

  8. 8. Attention-Aligned Reasoning for Large Language Models

    本文提出 ATAR（Attention-Aligned Reasoning），一种利用推理链内在结构来引导 LLM 注意力的新方法。当推理链变长时，关键中间步骤和原始 prompt 会被淹没在上下文中，导致注意力不足而产生错误。ATAR 通过将注意力对齐到推理结构上的关键节点来解决此问题。实验表明 ATAR 在六个基准上超越 SOTA 方法，最高实现 15.39% 的绝对提升，且无需额外训练即可让非推理模型达到同等规模推理模型的水平。

    出现于日报：03-31

  9. 9. Stabilizing Rubric Integration Training via Decoupled Advantage Normalization

    本文提出 Process-Aware Policy Optimization (PAPO)，通过解耦优势归一化将过程级评估整合进 GRPO 训练框架。针对现有奖励设计的两大缺陷——结果奖励模型 (ORM) 忽略推理质量且优势信号随训练逐渐消失，过程奖励模型 (PRM) 直接使用导致奖励攻击——PAPO 将优势分解为结果分量和过程分量并独立归一化，有效稳定了 RL 训练过程…

    出现于日报：03-31

  10. 10. Marco DeepResearch: Unlocking Efficient Deep Research Agents via Verification-Centric Design

    深度研究代理在自主执行开放式调查任务时，可靠的验证机制是维持长时域推理能力的关键。Marco DeepResearch 提出以验证为核心的三层框架设计：(1) QA 数据合成阶段引入验证机制控制问题难度并确保答案唯一正确；(2) 轨迹构建阶段设计验证感知的训练流程；(3) 测试时扩展阶段通过验证驱动的搜索策略提升推理质量。该方法解决了现有范式中错误在各阶段向下游传播的核心瓶颈。

    出现于日报：04-01
