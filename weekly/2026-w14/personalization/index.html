    出现于日报：04-01

  4. 4. RCLRec: Reverse Curriculum Learning for Modeling Sparse Conversions in Generative Recommendation

    针对大规模推荐系统中转化目标稀疏难以优化的问题，提出 RCLRec（反向课程学习）框架。在生成式推荐（GR）的统一 token 序列基础上，为每个转化目标从用户历史中逆向选取转化相关子序列构建短课程，其语义 token 作为解码器前缀与目标转化 token 联合输入；同时引入课程质量感知损失确保所选课程对转化预测具有信息量。线上部署效果：广告收入 +2.09%，订单量 +1.86%。

    出现于日报：04-01

  8. 8. MemoryCD: Benchmarking Long-Context User Memory of LLM Agents for Lifelong Cross-Domain Personalization · 📖 深度解读

    该论文提出 MemoryCD，首个基于真实用户行为（Amazon Review 数据集）的大规模跨域用户记忆基准。不同于依赖脚本化人设的合成数据，MemoryCD 追踪用户跨越多年、多领域的真实交互，构建了包含 14 个 LLM 基座模型和 6 种记忆方法基线的评估管线，覆盖 12 个领域的 4 种个性化任务。实验揭示现有记忆方法在用户满意度方面远未达标，尤其在跨域个性化场景下表现差距显著。

    出现于日报：03-31

  9. 9. Aligning Recommendations with User Popularity Preferences · 📖 深度解读

    本文研究推荐系统中的流行度偏差问题，提出 Popularity Quantile Calibration 度量框架来量化用户历史流行度偏好与推荐结果之间的不对齐程度。基于此提出 SPREE，一种面向序列推荐模型的推理时激活引导方法——在表示空间中识别流行度方向，并根据每位用户的个人流行度偏好自适应地调节模型激活，实现个性化的流行度校准。

    出现于日报：04-03

  10. 10. GRank: Towards Target-Aware and Streamlined Industrial Retrieval with a Generate-Rank Framework

    GRank 提出一种无结构化索引的工业级检索范式，统一了目标感知学习与以用户为中心的检索。核心创新包括：(1) 基于 GPU 加速 MIPS 的目标感知生成器，实现个性化候选生成；(2) 解决了传统双塔架构表达力不足和生成式模型缺乏精确目标感知匹配的问题；(3) 避免了树/图/量化等结构化索引的高昂构建和维护成本。

    出现于日报：04-03
