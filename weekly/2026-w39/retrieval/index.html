2026-09-21 ~ 09-27 · AI 搜索

  1. 1. Reasoning Quality Matters: Combating Reasoning Collapse in LLM-based Embedding Learning · 📖 深度解读

    CoFree 针对检索 embedding 训练造成的推理退化，先用参考模型约束的监督微调恢复生成能力，再以 embedding 和推理双奖励强化学习。4B 模型在 22 个数据集上的平均 nDCG@10 从 38.0 升至 40.8；工业搜索新增召回通道报告 CTR 绝对增加 0.02 个百分点，订单相对增加 13.56%。

    出现于日报：09-21

  2. 2. BoundaryMORPH: Budgeted Reranking via Active Set Selection for Diffuse Retrieval

    针对重排预算小于最终候选集合的问题，BoundaryMORPH 用高斯过程传播已评分文档的信息，并把计算集中在 top-k 集合边界。NeuCLIR 上预算为 25 次时，nCG@100 从 BAGEL 的 51.4 提高到 55.1；Robust04 同设置从 41.0 提高到 46.4。该结果衡量集合覆盖质量，不等同于首屏排序收益。

    出现于日报：09-25

  3. 3. ItColBERT: An Italian-Specialised Late-Interaction Retriever

    ItColBERT 将已有检索检查点适配为 1.35 亿参数的意大利语多向量检索器，在单张 RTX 3090 上训练约 14.5 小时。四个基准的比较显示，域外 MLDR-it 仅调整推理分块就带来 0.0602 的 nDCG@10 增量，超过额外两轮训练的收益；自挖难负样本和长序列训练均未通过预设决策门槛。

    出现于日报：09-25

  4. 4. Test-Time Adaptation with Query-Dependent Residuals for Visual Document Retrieval

    Q-REACT 固定文档向量与编码器，用低秩变换学习查询相关残差，并在完整页面索引上归一化蒸馏目标。ViDoRe V3 的八个任务、五个骨干中，仅使用 145 个查询反馈时，任务模式平均 nDCG@10 从 54.73 到 56.61；完整反馈时达到 62.61，对应直接重排为 60.25，指标均按百分制报告。

    出现于日报：09-25

  5. 5. From Ranked Documents to Reliable Contexts: An Answer-Oriented Context Construct Framework for AI Search · 📖 深度解读

    论文把 AI 搜索的检索目标扩展为答案支持、内容可信和上下文组织三个阶段，并给出百度工业实现。文档压缩为可离线缓存的瓶颈表示，在线按查询评分；答案支持排序升级使答案通过率增加 4.8 个百分点，抽取式内容精简的人评净收益为 8.9%。各组件增益对应独立基线，不应相加。

    出现于日报：09-24

  6. 6. WARP: Wasserstein-Aligned RAG for Population Opinions

    WARP 面向评论观点检索，先找回被相似度排序掩盖的少数观点，再用 Wasserstein-1 距离让入选集合贴近总体情绪分布。三个评论领域包含 3.5 万文档、156 个查询和 26 个实体，适配领域的变体将分布误差至少降低 43%，延迟低于一秒；在 k≤5 的已判定比较中，五个 LLM 裁判对其答案偏好率为 86%。

    出现于日报：09-25

  7. 7. Think Thrice Before Reranking: Multi-perspective Evidence and Reasoning Integration for Text Reranking

    MERIT-Rank 从语义对齐、意图满足和文档证据三个角度生成推理，再合并为最终排序，并采用从相对收益到绝对排序指标的渐进强化学习。在 ReasonIR 召回前 100 篇的 BRIGHT 设置下，4B 模型 nDCG@10 为 36.6，高于 ERANK-4B 的 30.5；32B 版本达到 40.3。

    出现于日报：09-21

  8. 8. MAGIC: Marginal-Guided Compression with Optimal Transport for Efficient Visual Document Retrieval · 📖 深度解读

    针对视觉文档多向量检索的索引与打分成本，MAGIC 用查询需求加权源边际和均衡目标边际做最优传输压缩，无需重训编码器。在 ViDoRe v1 保留 1% 向量时，nDCG@5 为 71.04，较 Light-ColPali 高 2.70 个百分点；测量设置下索引缩小约 99 倍、打分延迟降低约 17 倍。

    出现于日报：09-22

  9. 9. Parameterized Dense-Sparse Fusion for Hybrid Retrieval: Tuning a Rank-Score Mix on BEIR SciFact with Qdrant

    研究在 Qdrant 中组合 BGE 稠密召回和 BM42 稀疏召回，通过训练集搜索稠密权重、分数与名次混合比例及 RRF 平滑参数。SciFact 的 809 条训练查询用于选参，300 条测试查询上 nDCG@10 为 0.753，高于稠密基线 0.742 和等权 RRF 的 0.707；20 个独立检索单元中有 16 个超过稠密基线。

    出现于日报：09-24

  10. 10. When Learned Context Planning Fails to Beat Strong Retrieval: A Controlled Study of Planning, Routing, and Reranking for Long-Context QA

    该研究在 LongBench-v2 上比较学习式上下文规划与强检索基线。503 题、1.8 万字符预算下，锚定混合检索准确率为 36.18%，BM25 为 35.98%，最佳直接规划方法为 34.19%；独立的 152 题测试集上，混合检索仍以 42.11% 高于规划的 36.84%，说明复杂选择器未稳定超越检索。

    出现于日报：09-25
