  1. 1. MTFM：美团统一推荐基座大模型在外卖多业务场景的落地实践 · 📖 深度解读

    美团面向外卖多业务精排，提出统一推荐基座 MTFM，以异构 Tokenizer、动态掩码和混合注意力共享用户行为建模，保留业务独立任务塔。官方实践报告显示，多业务订单量提升 2.06%–6.68%，推理成本下降 24%；Target 与 Full Attention 按 3:1 堆叠时，样本吞吐达到全注意力架构的 2.9 倍。

    出现于日报：09-25

  2. 2. Robust Fusion of Semantic and Behavioural Signals for LLM Reranking in Personalised Search · 📖 深度解读

    论文研究个性化排序过度依赖历史成功率的问题，将查询、内容、用户历史和离散行为特征共同输入 cross-encoder，并用保留与移除行为特征的成对样本训练。双样本模型的 NDCG@7 为 0.622，移除特征时为 0.547，高于仅含特征训练的 0.526；线上搜索成功率提升 2.05%，但与另一实验组差异不显著。

    出现于日报：09-24

  3. 3. Tie Handling Is Part of the Evaluation Protocol: An Order-Invariance Audit for Tie-Heavy Recommender Scores

    论文审计推荐评测中的同分排序：正样本若固定排在首位，稳定排序会让其赢得全部平局。在 3 万条 Amazon Beauty 评测记录上，仅把输入顺序打破平局改为用户与物品 ID 哈希排序，NDCG@10 就从 0.85 降至 0.17；均匀随机平局的精确期望与 100 个哈希种子的均值吻合。

    出现于日报：09-25

  4. 4. When LLM-Based User Profiling Adds Value in Production Streaming Recommendation · 📖 深度解读

    论文在真实流媒体数据上比较聚合向量与 LLM 画像，并交叉测试长短期兴趣拆分，共评估 4 种策略、1 万名用户和约 24 万个内容。全体用户中，长短期聚合向量使 NDCG@10 相对提升 4.7%；LLM 整体画像在探索型用户中提升 31.5%，但在总体上下降 26.9%，收益明显依赖人群。

    出现于日报：09-25

  5. 5. Beyond a Scalar: Distributional Serving Interfaces for Watch-Time Prediction

    DSI 针对观看时长单一预测值丢失行为分布的问题，输出观看状态概率、相对时长和不确定性摘要，再接轻量任务读出层。在 KuaiRec 上，MAE 从最强基线的 3.8327 秒降至 3.5059 秒；三个公开数据集相对降幅为 1.9%–8.5%。固定读出层后增益缩小，说明完整系统优势不能全部归因于分布接口。

    出现于日报：09-25

  6. 6. Dual stream adaptive sequential recommendation

    针对短期意图与长期兴趣混合的问题，DSASR 使用两个独立因果 Transformer，并依据兴趣漂移与用户属性门控融合，联合 BCE 和 BPR 训练。在 MovieLens 1M 上 HR@10 为 0.8043、NDCG@10 为 0.5832；Amazon Beauty 上 NDCG@10 为 0.2686，代码已公开。

    出现于日报：09-22

  7. 7. Dense Feature Representation over Sequence Modeling: A Solution to the KDD Cup 2026 UniRec Challenge

    该研究分析腾讯 UniRec 竞赛中 CVR 模型收益的来源，在 3482 万条点击记录上逐步改进稠密特征表达与优化器。最终测试 AUC 从基线 0.813237 提升至 0.828535；去掉稠密特征模块损失 0.0095 AUC，单个序列模块影响不超过 0.0005。作者另发现同时间窗验证集会高估榜单 AUC 约 0.014。

    出现于日报：09-21

  8. 8. Calibrating Reproduced Claims in Recommender Systems

    论文通过 5 对推荐系统原始研究与复现研究，分析数值一致、方法排序一致和结论成立之间的区别，提出 Claim Evidence Profile 记录主张及适用条件。例如一个复现案例增加 15 项指标，另一个增加 4 个数据集，比较范围因此发生变化。研究未重新运行实验，证据来自论文与公开材料的结构化分析。

    出现于日报：09-25

  9. 9. TailSpec-EASE: Knowledge-Graph-Regularized Linear Recommendation for Web Long-Tail Discovery

    该方法用关系类型感知的知识图谱先验约束局部线性推荐，并让长尾物品获得更强语义正则。Amazon-book 上 NDCG@20 从 Local EASE 的 0.0953 提升至 0.0994，长尾 Recall@20 从 0.0329 提升至 0.0553，CPU 训练耗时 37 秒。原文发表于 8 月 8 日，本次由近期 RSS 发现，并非近三天新作。

    出现于日报：09-24

  10. 10. DiSAM4Rec: distilled and sparsity adaptive Mamba for sequential recommendation

    DiSAM4Rec 面向稀疏交互下序列推荐的表示退化，采用 Mamba 稀疏感知双分支，并用层间语义对齐自蒸馏保持深层表示一致。论文摘要报告，在四个真实数据集上 HIT@10、NDCG@10、MRR@10 平均提高 4.12%、9.24%、9.97%；这些数值来自作者摘要，当前公开页面未提供完整实验表。

    出现于日报：09-21
