2026-10-12 ~ 10-18 · 智能体搜索

  1. 1. CASI: Credit Assignment via Set Intervention for Agentic Retrieval · 📖 深度解读

    多条查询改写共享一个下游奖励时，CASI 固定检索快照，比较不同查询子集的收益，再用 Shapley 值分配动作信用。五个独立训练种子下，留出集回放价值为66.70±3.40，高于 Singleton 的55.00±4.00；七天、10%线上流量实验中，广告主价值提升3.51%。

    出现于日报：10-16

  2. 2. SOAR: Source-Aware Reinforcement Learning with Precise Credit Assignment for Search Agents · 📖 深度解读

    将模型内部知识与外部检索证据分为可观察的两条信息流，并用来源一致性奖励约束搜索 Agent，避免答对却编造依据。3B 模型七项问答平均准确率为 0.414，Search-R1 为 0.372；证据编造率从 16.08% 降至 4.05%，相对下降 74.81%。这些是离线问答结果，尚不能等同社区搜索的线上收益。

    出现于日报：10-14

  3. 3. SEEDS: Preview-Guided Evidence Admission for Search Agents · 📖 深度解读

    SEEDS 将证据准入独立于召回：先展示轻量预览，再由智能体根据当前推理状态选择任意子集，而非固定读取前几条。论文覆盖9个问答基准；Search-o1接入后，本地平均全文阅读数从30.2降至12.6，在线搜索准确率从9.28升至11.78，页面阅读数从27.81降至8.30。

    出现于日报：10-13

  4. 4. RCER: Reconstructing Cross-Evidence Relations for Iterative Retrieval-Augmented Generation

    RCER 针对迭代 RAG 中证据越积越多、跨段实体关系却未被正确串联的问题，联合重建实体对应和推理依赖，并据此调整下一轮检索。最后独立选择互补段落、构建推理上下文。在三个多跳问答基准上，相对最佳基线平均增加2.83个 EM 点和3.06个 F1 点。

    出现于日报：10-16

  5. 5. Benchmarking and Training Reward Models for Cross-Source Evidence Grounding in Search Agents

    搜索智能体的引用正确，并不代表多个来源相互独立或冲突已经解决。CSEG 用六层决策树评价完整轨迹，构建覆盖九类路径的 1,160 条核实样本；奖励模型路径精确率达 83.9%，以其监督冻结检索的回答策略后，独立评判均值从 2.83 升至 4.19。

    出现于日报：10-15

  6. 6. RIT-RAG: Navigating Document Corpora with Retrieval-Induced Trees · 📖 深度解读

    RIT-RAG 将召回与阅读解耦：先用检索命中的段落及祖先节点构造跨文档子树，再让 Agent 按需读取节点、改写查询。相同混合检索器下，Haiku 在 WixQA 的答案准确率由 Agentic Search 的84.5%升至95.0%，FinanceBench由74.0%升至84.0%；284万网页语料验证了规模可扩展性。

    出现于日报：10-12

  7. 7. Frustratingly Easy Agentic RAG via Portable Skills: A Case Study in Customer Support

    论文以客服流程生成展示轻量 Agentic RAG：自然语言技能、检索与格式检查工具，加上 LLM 生成的类维基导航层。实现约需 1—2 个工程日，流程等价率达 99.2%，证据充分率为 83.3%；单例约 90 秒，明显慢于生产助手的 8—9 秒。

    出现于日报：10-15

  8. 8. PANINI-DR: Controlled Deep Research through Generative Semantic Workspaces

    PANINI-DR 将总体协调与子问题研究、证据核查分离，用共享语义工作区记录依赖关系、结论和来源。研究在固定语料和相同骨干下对比七套框架，在 BrowseComp-Plus 达到 73.3% 准确率，领先次优框架 16.0 个百分点，并检查保存证据能否重建答案。

    出现于日报：10-15

  9. 9. Plan or Retrieve First? A Scale Study of Tool Discovery Architectures

    论文比较先检索工具再规划与先生成抽象工具签名再检索两种架构，在46,984个 API 上发现任务复杂度决定优劣。k=5时，单工具任务召回为37.2%对27.9%，先检索更好；同类多工具任务为14.3%对18.4%，先规划更好，但额外发现调用大致使推理成本翻倍。

    出现于日报：10-16

  10. 10. Locate, Judge, Read: Role-Specialized Tool Agents over a Knowledge-Point Index for Open-Domain Multimodal Document QA

    KnowForge 将定位、补跳、阅读与答案生成拆成工具互斥的工作阶段，解决智能体持续搜索却不读取表格和图像的问题。在包含2441个问题、3368份PDF的M3DocVQA上，F1达到47.5，比同索引同模型的单轮基线高7.1点；MultiHop-RAG准确率为73.5。

    出现于日报：10-13
