  3. 3. BaRA: Budget-constrained and Reliable Web Data Collection Agent

    BaRA 将 LLM Web agent 的目标从“完成单个网页任务”扩展为预算受限的网站级多模态数据采集：agent 需要在固定交互次数内发现站内页面，并可靠提取文本、图像、视频等资产。方法采用 BFS 链接发现、存活性验证过滤幻觉和死链、基于 provenance 与可访问性的规则校验，以及历史自反思模块恢复执行失败；论文在合成和真实网站上显示 BaRA 能更稳定地发现有效页面并减少无效采集。

  5. 5. LongCat 开源 VitaBench 2.0：长期动态智能体基准新标杆

    美团 LongCat 开源 VitaBench 2.0，定位为长期、真实、动态用户互动场景下的智能体评测基准，重点衡量大语言模型在长期记忆、用户建模、个性化响应和主动性上的能力。它把评测从静态单轮问答推进到连续用户互动，更贴近社区产品中“用户偏好随时间变化、agent 需要记住并调整策略”的真实问题。

    这篇腾讯云开发者社区文章展示了把已有文档 RAG/MCP 服务升级为 EdgeOne Makers 托管 Agent 的工程路径。实践中作者将工具规划阶段改为非流式 Chat Completions，模型返回 tool call 后由 Agent 执行工具并把 tool_call/tool_result 传给前端，最终回答再用 streaming；同时用 tracing 记录知识库查询、工具调用、LLM 阶段和 token 用量。

    出现于日报：07-03

  7. 7. Safeguarding LLM Agents from Misalignment through Provenance Analysis

    ProvenanceGuard 针对 LLM agent 工具调用偏离用户意图的风险，提出用 provenance analysis 判断一个动作是否被上下文中的可追溯证据支持。论文把 misalignment detection 形式化为“拟执行工具调用是否能从 agent 上下文中找到支撑链”，并构建多阶段流水线分析 action 与用户意图、上下文证据之间的关系，以替代难审计且不稳定的 LLM-as-judge 守卫。

    出现于日报：07-03

  8. 8. PACE: A Proxy for Agentic Capability Evaluation

    出现于日报：07-03
