2026-06-29 ~ 07-05 · AI 搜索

  1. 1. Can Language Models Actually Retrieve In-Context? Drowning in Documents at Million Token Scale

    这篇论文直接检验“把百万 token 语料塞进上下文，让语言模型自己检索”能否替代向量检索。作者提出 0.6B 参数的 BlockSearch LM retriever，通过结构和训练改造实现最长可泛化到训练长度 10 倍的检索场景，但在更极端长度外推时仍会崩溃；失败原因被归因于 attention dilution，即无关文档撑大 softmax 分母后稀释相关证据权重。

    出现于日报：07-03

  2. 2. Sifei at SemEval-2026 Task 8: Hybrid Retrieval and Query Rewriting for Multi-turn RAG

    该系统面向 SemEval-2026 Task 8 的多轮 RAG 检索，采用无需训练的混合检索链路：稠密召回、稀疏召回、受控 query rewriting 和 cross-encoder reranking 组合使用。公开结果显示，其 Task A nDCG@5 达到 0.5453，在 38 支队伍中排名第 3，并超过最强 baseline 的 0.4795，说明工程化组合策略仍能显著提升多轮检索相关性。

    出现于日报：07-03

  3. 3. Deep Learning to Rank in Industrial Search Engines, Recommender Systems, and Online Advertising - An Overview and New Perspectives

    这是一篇面向工业搜索、推荐和广告的 learning-to-rank 综述，覆盖 matching、pre-ranking、ranking、post-ranking、relevance ranking、LLM ranking 与强化学习等多阶段链路。它的价值不在单一模型指标，而在系统化梳理工业排序栈：从召回后的粗排、精排到后处理，每一层都有不同延迟、特征和目标约束。

    出现于日报：07-03

  4. 4. HNSW with Accuracy Guarantees Using Graph Spanners -- A Technical Report

    论文针对工业向量检索常用的 HNSW 图提出“Certify-then-Rectify”框架：先用分布无关统计 certifier 低开销判断 HNSW greedy search 的邻居质量，若质量不足再升级到严格 exact recovery。作者将 HNSW 图重新解释为 geometric spanner，并用极值理论估计最大经验拉伸，从而把启发式检索速度与可证明正确性连接起来。

    出现于日报：07-03

  5. 5. Hybrid Search: BM25, Vector & Reranking Reference 2026

    这篇工程参考聚焦生产级 hybrid search，拆解 BM25、dense vector search、Reciprocal Rank Fusion、向量数据库实现差异和 cross-encoder reranking。文章强调 RRF 以排名而非原始分数融合，能绕开 BM25 分数和向量相似度不可直接比较的问题，是很多 RAG 与企业搜索系统的默认稳健方案。

    出现于日报：07-03

  6. 6. Learned Sparse Retrieval and Dense-Sparse Hybrid: Why Agents Need Both Vocabularies

    这篇实践文章解释 learned sparse retrieval 与 dense-sparse hybrid 的互补性：BM25 保留精确词匹配，SPLADE 类模型能在词表空间做语义扩展，dense embedding 负责相似语义召回，最后通过 RRF 或相对分数融合合并排序。它特别指出纯 dense 召回容易丢失精确实体、型号、术语和罕见词。

    出现于日报：07-03

  7. 7. Embedding Inference Attack

    论文研究密集检索系统的黑盒安全风险：攻击者只观察无序召回文档集合，不需要排名或相似度分数，就可以通过定制查询推断后端使用的 embedding 模型。作者称之为 Embedding Inference Attack，并指出即使系统加入 reranker，部分查询仍保持区分能力；论文还在真实 RAG 系统上验证了该攻击方向。

    出现于日报：07-03

  8. 8. mamabench and mamaretrieval: Benchmarks for Evaluating Medical Retrieval-Augmented Generation in Maternal, Neonatal, and Reproductive Health

    论文发布 mamabench 与 mamaretrieval 两个医疗 RAG 基准，覆盖母婴、生殖健康和助产士真实问题。mamabench 包含 25,949 个问答项，来自 7 个专家来源；mamaretrieval 则把 3,185 个临床查询与 63,650 个 guideline chunk 绑定，并给出 0-6 级相关性标签，区分“真正回答问题”和“只是主题相关”的文本块。

    出现于日报：07-03

  9. 9. Evaluating Chunking Strategies for Retrieval-Augmented Generation on Academic Texts

    论文比较长篇学术文本 RAG 中的 chunking 策略，重点评估 cluster-based semantic chunking 是否优于 fixed-size 和 recursive chunking。作者使用 RAGAs 框架评估检索与回答质量，发现 RAGAs faithfulness 在该设置中可靠性有限，且固定问题与文档特定问题表现差异较大；在测试配置下，cluster-based chunking 没有超过更简单策略。

    出现于日报：07-03

  10. 10. Temporal Validity in Retrieval Memory: Eliminating Stale-Fact Errors for AI Agents over Evolving Knowledge

    RAG 让 agent 能调用累积知识，却没有时间模型：一个事实被更新后（如函数改名、API 重构），RAG 会以几乎相同的 embedding 相似度同时召回旧值和新值，于是 agent 要么弃答、要么给出过时事实。作者证明这是结构性问题——在校准数据集上，cosine 相似度区分“被推翻的事实”和“换了说法的重复事实”的 AUROC 只有 0.59（接近随机），因为矛盾值往往比改写的重复值更接近原文…

    出现于日报：06-29
