    出现于日报：06-29

  4. 4. Kara: Efficient Reasoning LLM Serving via Sliding-Window KV Cache Compression

    Kara 针对推理模型长 CoT 解码时 KV cache 持续膨胀的问题，提出只在最近生成窗口内做滑动式压缩。方法用双向注意力为窗口内 KV 打分，再用 Token2Chunk 把关键 token 扩展为可变长语义块，并适配 PagedAttention 实现 KvLLM。摘要未披露具体吞吐百分比，但强调在多组实验中能降低 KV 内存并提升输出吞吐。

    出现于日报：07-03

  5. 5. Meta’s AI Storage Blueprint at Scale

    Meta 这篇工程文章讨论 AI 训练数据和模型能力快速增长后，存储访问如何成为训练速度与计算成本的关键基础设施。文章指出前沿模型发布节奏已从“数月”压缩到“数周”，可靠、快速的数据访问直接影响 AI 创新的迭代速度。它不是论文式算法贡献，但提供了超大规模 AI 存储架构的产业实践信号。

    出现于日报：07-03

  6. 6. ASAP: A Disaggregated and Asynchronous Inference System for MoE Prefill

    ASAP 面向 MoE 大模型在线服务的 prefill 阶段，指出现有注意力 DP 与专家 EP 混合并行会在阶段切换处产生全局同步屏障。论文把 attention 与 MoE stage 解耦为异步流水线，并结合异步通信原语、请求调度和模型执行优化。在 CloudMatrix384 super-node 上，相比同步 serving 方案，SLO-compliant prefill throughput 提升 90%。

  7. 7. Geometry-Aware Online Scheduling for LLM Serving: From Theoretical Bound to System Practice
