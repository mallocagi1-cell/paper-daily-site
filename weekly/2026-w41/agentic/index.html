2026-10-05 ~ 10-11 · 智能体搜索

  1. 1. Harness-Search: Guiding Long-Horizon Search through Multi-Agent Coordination · 📖 深度解读

    针对长程搜索中重复检索、证据丢失和过早停止的问题，Harness-Search 将检索提案、记忆提交与终止审核分给三个权限受限角色，形成共享状态驱动的搜索循环。在七个基准上评测，同骨干比较的证据召回提高4.60至27.92个百分点；BrowseComp-Plus召回为57.81%，移除记忆组件后降至44.74%。

    出现于日报：10-07

  2. 2. Agentic AutoRAG: RAG Pipeline Optimization through Reasoning-Driven Agents

    Agentic AutoRAG 用诊断代理区分检索失败与生成失败，再由提案代理结合模型排名和价格调整 RAG 配置。在三个多跳问答基准上，前 10 次试验即可匹配或超过统计基线 30 次试验的效果；医疗语料上考试准确率为 77%，强基线为 71.5%，单次查询成本约为其 58%。

    出现于日报：10-08

  3. 3. From Delivery to Stateful Exploration: Rethinking the Index for Agentic Search

    论文将 Agent 搜索从反复返回文本改为有状态的索引交互：代理先用词法条件、集合运算和候选数量反馈缩小范围，再按需读取证据。在 BrowseComp-Plus 上，IndexAct 准确率为 73.5%，高于 RARG 的 69.4%；平均上下文由 27,896 降到 13,960 tokens，并在五个基准上领先所比较方法。

    出现于日报：10-08

  4. 4. APDMem: Agent-Controlled Progressive Disclosure for Query-Adaptive Long-Term Memory

    APDMem 将长期对话组织为主题摘要、个人事实、轮次证据和原始消息四层，由控制器按查询需求逐层展开，并合成带时间与冲突信息的回答依据。在 500 题 LongMemEval-S 上，GPT-4.1 配置准确率达 87.8%，对照 SimpleMem 为 84.0%，平均只深入读取 8% 的会话；这并不代表完整推理成本同步降低 92%。

    出现于日报：10-06

  5. 5. ExperienceIndex: Artifact-Grounded Memory

    论文针对搜索智能体反复阅读同一语料、难以复用文档经验的问题，提出按材料锚定的 ExperienceIndex。系统从历史轨迹保存单材料贡献、证据片段及材料间关系，以中间件方式增强检索；跨多类任务最高增加 11.0 分并降低在线成本 50.5%，平均成本下降 20.8%。

    出现于日报：10-09

  6. 6. SkillForge: Co-Evolving Skills and Agents via Dynamic Skill Lifecycles

    SkillForge 将技能划分为试用、活跃、稳定和退休状态，用适应度跟踪、预退休与变异让技能库随强化学习共同演化。ALFWorld 和 WebShop 成功率分别为 92.4% 与 78.4%，搜索增强问答达到 48.7%±0.3%；发布的 SkillFurnace 包含 5,852 条记录。

    出现于日报：10-09

  7. 7. DAEDALUS: Bootstrapping Agent Memory from Self-Generated Tasks

    DAEDALUS 让探索代理自造环境任务，求解代理执行并从失败中提取启发式；只有加入经验后重复成功的规则才进入记忆库。在 AppWorld 上平均成功率由 44.3% 升至 60.2%，在零售 τ²-bench 上由 57.5% 升至 67.5%，跨三个基准的 pass^5 最多提高 2.2 倍，并支持跨模型迁移。

    出现于日报：10-08

  8. 8. Turnslide: Scalable Multi-Turn Data Synthesis by Walking a Finite-State Machine

    Turnslide 把 API 交互建模为有限状态机，采样合法工具序列后用单次 LLM 调用生成多轮对话，减少环境模拟与逐轮生成成本。用这些数据微调小模型后，完整准确率达到 70.7%，对照方法为 63.4% 和 53.7%，同时少用 3.6–6.6 倍生成 tokens，适合低成本工具调用训练。

    出现于日报：10-08

  9. 9. Beyond Correctness: Resolving Underspecification in Agentic Text-to-SQL

    PlanPool 针对交互式 Text-to-SQL 过早停止澄清的问题，把待解决歧义外置为可增删的问题池，提交前要求逐项询问或明确放弃。在 BIRD-Lite 上，歧义召回从朴素代理的 73.9% 升至 87.5%，执行准确率从 74.3% 升至 81.3%，静默失败从 17.0% 降至 8.2%，代价是平均提问由 2.3 次增至 4.2 次。

    出现于日报：10-06

  10. 10. CUEing User Simulators: Calibrated User Embeddings for Multi-Turn Benchmarking

    CUE 用连续用户表征编码真实交互，再解码成人设指令来驱动用户模拟器，重点校准代理何时失败，而不只模拟说话风格。在 τ²-Bench 的 Gemini 3.5 Flash Lite 配置中，CUE 的成功率偏差为 0.12，对照 RealUserSim 为 0.32；失效模式宏 F1 为 0.62，对照为 0.46，表明不同模拟器会改变评测结论。

    出现于日报：10-06
