  1. 1. Training with Missed Targets in Generative Recommendation: Separating Supervision from Probability Competition · 📖 深度解读

    生成式推荐漏召回目标后，训练时补入目标会同时改变监督权重与概率竞争。论文固定生成器和候选池，用 WN、Cond、Full 三种损失隔离这些效应；在 Amazon Video Games 四组预设比较中，去掉跨组竞争使 FT-NDCG 提升 7.8%–22.2%，开发集选择规则还避免了另一类别 1.7% 的损失。

    出现于日报：10-09

  2. 2. A Systematic Study of Semantic ID Spaces for Generative Information Retrieval · 📖 深度解读

    论文系统研究生成式检索的文档标识符设计，把乘积量化、残差量化及混合结构放入同一空间，并提出无需训练检索模型的内在诊断指标。在 MS MARCO 上混合量化的 MRR@10 达到 46.30%，NQ 上 R-VQ 达到 56.64%；短码预算下，唯一率可帮助识别碰撞和空间坍缩。

    出现于日报：10-08

  3. 3. Disentangling Paradigm, Identifier, and Decoding in Generative Retrieval

    论文在 NQ320K 与 MS300K 上交叉比较自回归、掩码扩散和块扩散模型，固定标识符长度和训练预算后分离解码影响。仅更换解码就能让扩散模型 Hit@1 改变 6.6–13.7 个百分点；全掩码单次前向评分在 12 个设置中的 11 个达到或超过生成后匹配，自回归仍在 Hit@1 领先。

    出现于日报：10-08

  4. 4. OneTrans-V2: Unifying Retrieval, Pre-rank, and Fine-rank with One Transformer in Industrial Recommender · 📖 深度解读

    OneTrans-V2 将召回、粗排和精排统一为共享用户上下文的 Transformer，同时保留各阶段候选特征与计算预算。DCGR 先预测决策前缀再生成语义 ID，SNT 按用户序列复用训练计算；线上用户 GMV 提升 9.74%，同硬件端到端吞吐达到原级联的 3.2 倍，训练加速 4.4 倍。

    出现于日报：10-05

  5. 5. When History Misleads: Asymmetric Margin Supervision for Instruction-Guided LLM Generative Recommendation · 📖 深度解读

    AIMS解决当前指令被历史偏好覆盖的问题：冻结模型逐条删除历史事件，筛选同时提高目标得分与边界竞争间隔的删除结果，再用完整历史学习该间隔，辅助梯度仅抑制竞争项。在6个模型骨干上，Recall@10较继续交叉熵训练提高4.0%–10.9%；Llama-8B工业数据从6.902%升至7.223%。

    出现于日报：10-06

  6. 6. Rethinking Semantic ID Construction for Generative Recommendation: SimHash with Parallel Decoding and Semantic Alignment

    FLASH 重新审视生成式推荐的语义 ID 构建：以免训练 SimHash 生成离散码，配合并行解码和连续语义对齐，缓解无序哈希与自回归结构不匹配及离散化的信息损失。四个 Amazon 数据集上 NDCG@5 相对最强基线提高 5.51%–14.46%，各数据集 CPU 标识符构建耗时均低于 0.5 秒。

    出现于日报：10-08

  7. 7. Neither Black nor White: Balancing Semantic and Collaborative Signals with Graph-Informed Semantic IDs (GrIS)

    GrIS 将语义 ID 构造重新表述为带语义节点与协同边的递归图划分，内容量化是空图特例。论文实现可微图池化 RecDMoN 与加入图重构目标的 RQ-GAE，分离图构造和递归划分两个可调维度；在多个真实数据集上相对含协同信号的先进方法，Hit@10 最高提升 52%。

    出现于日报：10-05

  8. 8. SPRINT: Single-Step Generative Recommendation via Average Probability Velocity

    SPRINT 把语义 ID 生成理解为 token 概率流的平均速度，以双向 Transformer 在单次前向中预测全部位置。针对独立生成破坏 ID 一致性的问题，联合 token 级和 SID 级流对比目标恢复约束；相对第二快的自回归或非自回归方法加速 8.39–10.04 倍，相对第二优方法平均准确率提升 7.77%。

    出现于日报：10-05

  9. 9. Bootstrapping Conversational Recommendation Agents At Spotify: Synthetic Data Generation and Self-Improvement Loops

    Spotify 为对话推荐冷启动构建多轮合成对话，再利用方差驱动的对比优化与编码代理迭代修复规划、工具调用错误。相对充分优化的人工提示，离线质量提升 8%；线上相对仅支持会话细化的旧体验，收听量提升 14%、周活提升 5%、跳过率下降 5%。

    出现于日报：10-05

  10. 10. Generate What You Can Trust: Content Credibility in Generative Recommenders

    CreGR 将内容可信度纳入生成式推荐的分词与生成两个阶段，先学习区分可信和不可信内容的语义 token，再用离散扩散与非对称掩码控制生成。三个真实数据集实验中，PolitiFact 的 CR@5 从 LLaDA-Rec 的 0.8887 升至软版本的 0.9855，HR@5 从 0.2720 升至 0.2762，体现可信度与命中率可联合优化。

    出现于日报：10-09
