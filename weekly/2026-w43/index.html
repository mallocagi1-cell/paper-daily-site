2026-10-19 ~ 10-25 · 生成式推荐

  1. 1. AGR: Agentic Generative Retrieval with Tool-Augmented Search · 📖 深度解读

    生成式检索不必把全部特征一次塞进模型。AGR 在生成物品短编码时，按当前分支调用意图、位置或历史行为工具，把结果压成观察标记继续解码。快手线上实验中，强相关前四结果请求占比提升 0.205%。

    出现于日报：10-21

  2. 2. Evolving Semantic Indexes for Generative Retrieval · 📖 深度解读

    用大模型反复修改文档编码程序，自动寻找更好学的检索索引。小型生成器负责快速筛选，最终再用目标模型检验，训练方法保持一致。NQ320K 的前百条召回率从 85.82% 升至 90.57%。

    出现于日报：10-22

  3. 3. UniRec: A Unified Expressive-Aligned Generative Recommendation Framework for E-commerce · 📖 深度解读

    生成式推荐逐层生成商品的 Semantic ID，在生成第一层之前看不到任何商品侧信息，这是它和判别式排序模型之间的差距：判别模型给候选打分时能直接看到商品的类目、店铺、品牌这些特征，和用户特征做交叉。UniRec 先让模型生成商品的类目，再在已知类目的条件下生成 Semantic ID，相当于在解码路径里补回判别模型能用的商品特征。上线后订单提高 4.76%，GMV 提高 5.60%。

    出现于日报：10-24

  4. 4. OneLatent: Latent Reasoning for Efficient Foundation Recommendation Models · 📖 深度解读

    把大语言模型当作推荐底座时，让模型先写一段自然语言推理再输出下一个物品的语义编码，推理文本比语义编码长得多，解码时间和吞吐都被它拖住。OneLatent 的做法是在用户上下文后面接 3 个固定的特殊 token，训练分几步：先让模型在这些 token 之后复现教师大模型写的推理文本，再改成在它们之后直接输出目标语义编码；上线时只接这些 token，不生成任何推理文字…

    出现于日报：10-24

  5. 5. Controllable Generative Recommendation via Guided Token Refinement · 📖 深度解读

    生成式推荐按左到右逐个生成物品 ID 的 token，推理时想临时提高多样性，只能中途改某一位，结果常拼出目录里不存在的 ID。ReGen 改用双向 Transformer 一次预测 ID 的全部 4 位，只在最粗的几位上给用户历史里常见的 token 值减分，再把置信度低的位遮住重新预测，并用全部合法 ID 建成的前缀树排除补不成真实物品的 token 值，全程不改模型参数…

    出现于日报：10-23

  6. 6. GenPage: Towards End-to-End Generative Homepage Construction at Netflix · 📖 深度解读

    Netflix 首页原来由多阶段推荐系统拼出来，先召回候选行和候选影片、再分别排序、最后组页，GenPage 改用一个 decoder-only Transformer 直接生成整页。首页由多行组成，每行是一个主题。用户历史、账号属性和请求信息编码成 prompt，模型按从左到右、从上到下的顺序逐个生成行 token 和影片 token。训练照搬大模型的流程，先在线上获得正反馈的首页上做下一 token 预测预训练…

    出现于日报：10-24

  7. 7. Gryphon-v2: One Model in Place of a Cascade - Generate-and-Rank Recommender with Rollout Distillation · 📖 深度解读

    推荐系统可以把召回与排序合并到一个模型里。Gryphon-v2 只编码一次用户历史，先生成 Semantic ID（物品的短编码），再用轻量排序头打分；教师只参与训练。Yandex Music 线上实验中，活跃用户数提升 1.41%。

    出现于日报：10-19

  8. 8. LightCRS: Lightweight Multi-Domain Conversational Recommendation System

    跨品类对话推荐不必给每个领域单独部署大模型。商品图文表征离线算好，线上用共享的小模块按对话融合证据，再比较候选商品。论文报告命中率相对最强基线提高 35.4%。

    出现于日报：10-22

    Spotify 想在首页多推用户还没养成习惯的播客（过去 28 天听某节目不足 10 分钟）。GLIDE 基于 Llama 3.2 1B，先学会单集 Semantic ID 和文字描述互译，再读入最近收听单集的 Semantic ID、地区等文字信息、一个由协同过滤用户向量投影出的软提示 token，以及“推熟悉的/推没听过的”指令，直接生成 30 个候选单集…

    出现于日报：10-23

  10. 10. Coarse-to-Fine Long-term Interest Modeling for Generative Recommendation · 📖 深度解读

    生成式推荐一个码一个码地生成下一个物品的 Semantic ID，注意力计算量随序列长度平方增长，所以这类模型通常只吃最近几十条行为，用不上长期历史。GLASS 按 Semantic ID 的层级分开用长期历史。生成第一层码之前，它给每个一级码取该类物品向量的平均当原型。再把余弦相似度区间等分成若干档，统计长期历史里和原型的相似度落在每一档的物品数，所有一级码的计数拼起来经一个小网络压成一个兴趣 token 送进编码器…

    出现于日报：10-24
