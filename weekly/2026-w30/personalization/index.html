  1. 1. RecGPT-V3 Technical Report · 📖 深度解读

    RecGPT-V3 面向淘宝推荐中重复处理全量历史、文本标签到商品的信息损失和显式推理延迟三类瓶颈，引入持续演化的 Memory Hub、文本与 Semantic ID 混合推理及潜在意图 token。系统将用户建模计算降低 55.8%、输出 token 成本降低 200 倍；线上 A/B 中 CTR 提升 1.00%、GMV 提升 3.97%。

    出现于日报：07-21

  2. 2. CAPTS: Channel-Aware, Preference-Aligned Trigger Selection for Multi-Channel Item-to-Item Retrieval · 📖 深度解读

    面向短视频多频道 I2I 召回中触发器价值难归因、频道竞争难协调的问题，CAPTS 用 VAM 按下游观看反馈回传触发器价值，再由 CATR 联合分配触发器与频道。快手线上 A/B 显示，总应用时长提升 0.713%，设备日均时长提升 0.586%。

    出现于日报：07-24

  3. 3. RECAP: Feedback-Driven Streaming Semantic User Profiles for Short-Video Recommendation · 📖 深度解读

    RECAP 把短视频用户画像从开放环摘要改为由历史推荐反馈驱动的离线闭环优化：结构化有界记忆负责流式更新，LLM 过滤标签一致行为对，双塔评估器的匹配分作为 GRPO 奖励。快手数据上 uAUC 提升 0.0084、Recall@2000 提升约 4.9%，7 天线上实验的人均使用时长提升 0.139%。

    出现于日报：07-21

  4. 4. Uncertainty as Remedy: Mitigating Satisfaction Label Bias in Short Video Multi-Objective Ensemble Ranking · 📖 深度解读

    针对短视频多目标排序中点击、时长、点赞等代理标签互相冲突并偏离真实满意度的问题，快手提出 UAME：把满意度分数建模为高斯变量，以均值预测排序分、方差刻画冲突不确定性，再用概率成对损失和样本级自适应加权直接修正训练偏差。离线实验中，相对 EASQ 的 pCTR GAUC 从 0.672 提至 0.734，问卷满意度 NDCG@5 提升 8.71%。

    出现于日报：07-22

  5. 5. UniRank: Benchmarking Ranking Models for Unified Sequential Modeling and Feature Interaction · 📖 深度解读

    UniRank 把序列建模与特征交互统一到同一基准，覆盖 15 种排序模型、5 个公开数据集，最大数据超过 7 亿样本、最长序列超过 10 万。其分布式、模型并行与高效注意力优化在 4 张 GPU 上带来 14.24 倍加速，并降低 69.2% 单卡峰值显存。

    出现于日报：07-24

  6. 6. WHALE: A Scalable Unified Model for Recommendation with Wukong-HSTU Architecture · 📖 深度解读

    Meta 提出 WHALE，把擅长高阶静态特征交互的 Wukong 与擅长长行为序列的 HSTU 放进每一层，并让 Wukong 表征通过注意力逐层查询 HSTU 历史证据。模型在 800 亿训练样本、40 亿评测样本上验证；14 天线上 A/B 中主指标提升 0.113%，两个辅助指标提升 0.824% 和 1.820%，推理 QPS 仅回退 5%。

    出现于日报：07-22

  7. 7. Long-term User Engagement Optimization through Model-agnostic Downstream Rewards Learning · 📖 深度解读

    论文针对留存信号稀疏、延迟且难归因的问题，把深层会话、负反馈和场景采纳转成可挂接任意排序器的下游奖励头。Pinterest 以 1.5% 流量运行 3–4 周实验：深层会话奖励令核心/非核心用户成功会话提升 0.24%/0.48%，负奖励使总时长提升 0.46%/0.24%。

    出现于日报：07-23

  8. 8. Deep-learning Causal Retrieval Optimization for Efficient e-commerce Distribution in Pinterest · 📖 深度解读

    论文把是否触发购物召回器建模为个性化因果决策，以随机流量、双重稳健伪结果、DCNv2 与 12 专家 MMoE 联合学习多事件结果和 uplift。线上在不增加端到端时延的情况下最多减少 85% 触发，同时总会话提升 0.26%、Pin 收藏提升 1.10%。

    出现于日报：07-23

  9. 9. Learning Sparse Representations of Multimodal Content for Enhanced Cold Item Recommendation

    论文面向新物料缺少交互 embedding 的冷启动难题，将文本、图像或音频内容编码为仅激活 32 个维度的稀疏表示，并在稀疏化前加入受线性注意力启发的激活函数，以锐化、去噪物料相似度。四个多模态推荐数据集上，冷启动 NDCG@20 相对最佳稠密内容模型提升 16.6%–75.5%，同时显著降低向量存储与检索成本。

    出现于日报：07-22

  10. 10. Zero-Observation User Reactivation with Gap-Driven Dimensional Gating

    针对长期沉默用户没有新行为可学习的问题，DeltaGate 冻结原推荐骨干，仅用离线时长驱动的维度门控修正历史兴趣表示。模块约 6.6 万参数、仅增加 2%–4% 推理开销；在 Amazon Video Games 的 365 天以上间隔组，DG-BERT4Rec 的 Hit@10 从 0.025 提升到 0.046。

    出现于日报：07-24
