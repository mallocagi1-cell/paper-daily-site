2026-07-20 ~ 07-26 · 生成式推荐

  1. 1. Rethinking Generative Recommender Tokenizer: Recsys-Native Encoding and Semantic Quantization Beyond LLMs. · 📖 深度解读

    论文针对生成式推荐中 Semantic ID 与协同目标错位的问题，提出 ReSID：用字段感知掩码自编码器学习推荐原生表征，再以全局对齐正交量化降低前缀条件不确定性。在 10 个 Amazon-2023 子集上，相对最佳 SID 基线的 Recall@5/10 提升 16.0%/13.8%，分词成本最高降低 122 倍。

    出现于日报：07-21

  2. 2. GenRec: A Preference-Oriented Generative Framework for Large-Scale Recommendation · 📖 深度解读

    GenRec 面向京东 App 大规模推荐中的翻页输出不一致、长行为序列成本与偏好对齐难题，在单一解码器中引入页级下一词预测、非对称 Token Merger 和 GRPO-SR。Token Merger 将输入长度约压缩 2 倍；持续一个月的线上 A/B 实验中，点击数提升 9.5%，成交数提升 8.7%。

    出现于日报：07-22

  3. 3. Internalizing Multi-Agent Reasoning for Accurate and Efficient LLM-based Recommendation · 📖 深度解读

    腾讯提出 STAR，把多智能体教师的规划、工具调用、自反思轨迹以及协同信号翻译能力，蒸馏进单个实时推荐模型。训练先由教师合成带行为证据的复杂轨迹，再进行监督微调与强化学习；实验中 STAR 比教师高 8.7%–39.5%，同时消除迭代式多智能体推理带来的在线时延。

    出现于日报：07-21

  4. 4. SilverTorch: Index as Model — A New Retrieval Paradigm for Recommendation Systems · 📖 深度解读

    Meta 将推荐检索中的索引、过滤、重排和多任务打分统一为一个 PyTorch 模型，把索引本身变成模型张量，并在不足 100 毫秒内完成全链路。面向 8000 万物品的评测中，SilverTorch 吞吐提升 23.7 倍，估算算力成本效率提升 20.9 倍。

    出现于日报：07-24

  5. 5. TSGR: Taobao Search Generative Retrieval · 📖 深度解读

    针对工业电商生成式检索只优化语义匹配、忽略商品业务价值的问题，TSGR 用查询感知的并行 Semantic ID 将价值次序写入编码，再以联合训练的价值感知排序模块统一召回与预排。淘宝离线 HR@1000 提升 9.16%，线上 A/B 实验带来 IPV +0.43%、成交数 +1.12%、GMV +1.64%。

    出现于日报：07-23

  6. 6. Eliminating Out-of-Domain Recommendations in LLM-based Recommender Systems: A Unified View

    微软 RecLM 在同一 LLM 与提示设置下统一比较三种落地范式：向量检索、受约束的标题生成和离散物品 token 生成。三种变体都把域外推荐 OOD@10 严格降到 0；其中 RecLM-cgen 与 RecLM-token 在公开基准达到整体 SOTA，并开放于 Microsoft RecAI 代码库。

    出现于日报：07-21

  7. 7. Intent-Driven Semantic ID Generation for Grounded Conversational News Recommendation

    腾讯针对新闻对话中隐式意图难以先检索的问题，提出 Generate-then-Match：7B LLM 先生成层级 Semantic ID 前缀，再与实时新闻池模糊匹配，并以双信号推理覆盖冷启动。在 15.2 万 SID 空间中实现 0% 幻觉、12.4% L1 命中，成本约为 GPT-4+混合 RAG 的 1/100，冷启动 L1 达 18.0%。

    出现于日报：07-21

  8. 8. Vectorizing the Trie: Efficient Constrained Decoding for LLM-based Generative Retrieval on Accelerators

    STATIC 面向 LLM 生成式检索的受限解码，把不规则 Trie 展平为 CSR 稀疏转移矩阵，使前缀约束能在 TPU/GPU 上完全向量化执行。它已部署到服务数十亿用户的视频推荐平台，每步仅增加 0.033 毫秒、占推理时间 0.25%，相对 CPU Trie 加速 948 倍，并开源实现。

    出现于日报：07-23

  9. 9. Towards Generalizable and Efficient Large-Scale Generative Recommenders · 📖 深度解读

    论文把生成式推荐骨干从 200 万参数扩展到 10 亿参数，并用带偏移项的 Scaling Law 判断不同下游任务是否接近收益上限。作者结合多 Token 预测、采样 Softmax、投影解码头及语义冷启动塔，在 100 万用户的一周生产影子实验中让 10 亿模型在全部任务上取得更高 MRR。

    出现于日报：07-24

  10. 10. Differentiable Semantic ID for Generative Recommendation

    DIGER 解决 Semantic ID 分词器只优化内容重建、无法接收推荐损失的问题，以 Gumbel 噪声和两种不确定性衰减实现端到端可微索引并抑制码本坍塌。在 3 个公开数据集上，B-Shop 的 NDCG@10 从两阶段基线 0.0331 提至 0.0376，I-Shop 从 0.0797 提至 0.0844。

    出现于日报：07-22
