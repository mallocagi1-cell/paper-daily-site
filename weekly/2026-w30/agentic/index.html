Weekly Top 10 · 第30周

2026-07-20 ~ 07-26 · 智能体搜索

生成式推荐 · 个性化推荐 · AI 搜索 · 智能体搜索 · 系统与索引

  1. 1. Search-on-Graph-R1: Training Large Language Models to Search Knowledge Graphs with Reinforcement Learning

    针对知识图谱问答依赖前沿大模型多轮探索、推理成本过高的问题，论文用带黄金 SPARQL 路径的教师模型在真实 Freebase 上生成可验证搜索轨迹，再以 SFT 与强化学习训练 8B 模型。该模型在 WebQSP、CWQ、GrailQA 上超过所有对比的冻结前沿模型，并以更少 Search 调用完成推理。

    出现于日报：07-23

  2. 2. Evidence-in-the-Loop: Trace-Driven Optimization for Customer-Service LLM Agents

    论文面向真实客服 Agent 的持续迭代，构建由 BM25、标题与描述向量召回、加权 RRF 融合及 cross-encoder 重排组成的可审计证据链。固定 LangGraph DAG 再融合规则证据、对话记忆和澄清状态，并用运行轨迹定位召回、排序、候选选择或动作策略中的具体故障。

    出现于日报：07-22

  3. 3. OpenSkillRisk: Benchmarking Agent Safety When Using Real-World Risky Third-Party Skills

    论文从公开技能市场收集 263 个高风险第三方技能，按 7 类威胁配套标准任务与沙箱，系统测试 3 种主流 CLI Agent 框架和 13 个先进模型。即使最安全的配置仍在约 17% 的案例中执行危险动作，暴露出识别风险、及时阻断和权限收敛三类失效。

    出现于日报：07-24

  4. 4. SmartSearch: Process Reward-Guided Query Refinement for Search Agents · 📖 深度解读

    论文针对搜索 Agent 多轮推理中间查询质量差、一次偏航拖垮整条轨迹的问题，提出双层信用评估、低质查询定点改写与 SFT→DPO→GRPO 三阶段训练。基于 Qwen2.5-3B，在四个知识密集型基准上平均 EM/F1 达 37.5/47.2，较次优方法分别提升 25%/19%。

    出现于日报：07-20

  5. 5. FinSAgent: Corpus-Aligned Multi-Agent RAG Framework for Evidence-Grounded SEC Filing Question Answering

    FinSAgent 针对 SEC 长文档中模型先验与语料结构错位的问题，用 10-K 条目角色 Agent、数据库感知查询分解和多路径检索共同约束搜索。学习式特征门控重排器把证据有效性与语义相似度分开；方法在 5 个离线金融问答基准上提升覆盖与正确率，并完成含 1,000 个匿名评分的三臂在线实验。

    出现于日报：07-22

  6. 6. TriAgent: Divergence-Aware Multi-Agent Committees for Cost-Efficient Financial Sentiment Analysis

    TriAgent 用 VADER、FinBERT 与 Qwen2.5 组成不同粒度的委员会，再以三方语义分歧指数动态决定是否调用昂贵推理模型。LLM 作为评论员时 F1 在 1.5B–7B 模型上稳定约 0.87，同尺寸三角色投票仅 0.66；分歧信号检测幻觉的 AUC 达 0.90，并估算千万用户规模年省 930 万美元。

    出现于日报：07-24

  7. 7. 重构搜索范式：阿里云 Elasticsearch 开启“Agent 原生”时代，打造企业级 AI 记忆湖

    阿里云把搜索结果改造为 Agent 可直接消费的 JSON/Markdown，并以 Skills、Agent Builder、混合检索上下文引擎和 FalconSeek 组成完整栈。公开生产数据称 FalconSeek 覆盖 90% 线上查询，整体性能提升 50%–300%，排序、聚合和向量查询最高分别提升 3.54、6.8 和 4 倍。

    出现于日报：07-24

  8. 8. PCTD: Preference-Guided Counterfactual Task Decomposition for Agent Tool Retrieval

    针对复杂指令拆解后进行 Agent 工具检索时，直接用 Recall 或 nDCG 作强化学习奖励会诱发重复拆解与奖励投机，论文提出 PCTD。它用反事实奖励估计任务拆解对检索排序的边际因果增益，并以偏好奖励约束逻辑连贯性和原子性；在新建的移动端多轮交互 MTDTool 基准上，同时提升检索、拆解质量与未见工具的域外泛化。

    出现于日报：07-21

  9. 9. DeepResearch-9K: A Challenging Benchmark Dataset of Deep-Research Agent

    论文发布 DeepResearch-9K：包含 9000 个可验证问题、三级难度和 Tongyi-DeepResearch-30B-A3B 生成的完整检索轨迹，并开源支持多轮联网、GRPO/PPO 与多种奖励的 DeepResearch-R1。教师模型总准确率仅 55.84%，最高难度降至 23.73%，显示长链搜索仍有巨大缺口。

    出现于日报：07-20

  10. 10. VizRAG: Enhancing Retrieval-Augmented Generation with Hypergraph Visualization

    VizRAG 将知识超图渲染为视觉线索，让多模态模型同时利用文本证据与高阶实体结构，并通过 HyperViz 缓解视觉拥挤和渲染偏差。在 5 个数据集上相对 GraphRAG 的回答胜率达 70.2%–82.2%；结构消歧准确率由 71.5% 升至 79.0%，每次查询只增加约 0.21 秒。

    出现于日报：07-24
