2026-07-20 ~ 07-26 · AI 搜索

  1. 1. LLM-Based Re-Ranking for Real Estate Search

    面向房产平台多轮对话中难以用固定筛选项表达的复杂意图，论文用 LLM 对首阶段召回结果重排，并构建含 96 万个 query-item 对、经人工校验的离线数据集。生产 A/B 测试显示点击率提升 5.3%，预约看房量提升 4.8%，证明对话上下文可直接改善商业搜索排序。

    出现于日报：07-21

  2. 2. jina-reranker-v3.5: An Efficient Listwise Reranker with Hybrid Attention and Self-Distillation

    论文面向生产级列表重排，提出 6 亿参数 jina-reranker-v3.5：以三层滑窗注意力接两层全局注意力保留跨文档比较，并用三阶段自蒸馏迁移全注意力教师能力。模型在 BEIR 达到 63.20 nDCG@10，以约七分之一参数匹配 40 亿模型，半结构化检索提升 9.6 点，推理最高加速 1.56 倍。

    出现于日报：07-22

  3. 3. AutoIndex: Learning Representation Programs for Retrieval

    论文把索引前的文档表示从固定预处理升级为可学习的“表示程序”，由智能体诊断失败样例并搜索切分、增强、归一化和重排等变换。在固定 BM25 的 CRUMB 八项任务上，Recall@100 与 nDCG@10 平均提升 8.4% 和 8.3%，最大提升达 30.5% 与 43.6%。

    出现于日报：07-23

  4. 4. RAGAL: A Frugal, Fully Local Retrieval-Augmented Assistant for Technical Support at a Government Agency

    RAGAL 在零数据外传、只读操作和单台 8GB 显存笔记本约束下处理约 2.5 万个罗马尼亚语知识块。混合稀疏—稠密召回与意图路由把内部评测从 62% 提到 81%；微调 bge-m3 仅用 72 分钟，使 Recall@10 从 0.663 升至 0.850。

    出现于日报：07-23

  5. 5. An Efficient Framework for Whole-Page Reranking via Single-Modal Supervision · 📖 深度解读

    针对搜索结果页同时混排文本、图片、视频和大模型答案时整页标注成本过高的问题，论文提出 SMAR：先训练各模态排序器，再筛选预算受控的跨模态页面做少量标注，并蒸馏模态内偏好。Qilin 与 CrossRank 实验将标注成本降低 70%—90%，仍超过全量标注基线，并在百度 App 完成离线与在线 A/B 验证。

    出现于日报：07-20

  6. 6. Negative Data Mining for Contrastive Learning in Dense Retrieval at IKEA.com.

    论文面向 IKEA 加拿大站商品搜索，以层级类目和商品属性构造难负样本，再用 LLM-as-a-judge 为候选商品生成相关性标签，形成 44.8 万条训练三元组。真实用户查询离线实验的平均类目准确率提升 2.6%，但两周线上 A/B 测试的参与度差异不显著（p>0.05）。

    出现于日报：07-24

  7. 7. AnnoRetrieve: Efficient Structured Retrieval for Unstructured Document Analysis

    AnnoRetrieve 将非结构化文档检索从向量相似度改写为结构化标注查询。SchemaBoot 通过多粒度模式发现与约束优化自动生成标注模式，SSR 则执行属性值抽取、表格生成和渐进式 SQL 推理；三个真实数据集显示，它在保持高准确率的同时显著减少 LLM 调用频次与检索成本。

    出现于日报：07-22

  8. 8. Approximate Nearest Neighbor Search for Modern AI: A Projection-Augmented Graph Approach · 📖 深度解读

    PAG 将随机投影统计检验嵌入图索引，用 PRT、反馈缓冲区和概率边选择减少无效精确距离计算，并同时支持快速建索引、在线插入和大 top-k。六个 384–3072 维现代数据集上，其 QPS–Recall 最多达到 HNSW 的 5 倍，检索规模覆盖 top-10 至 top-1000。

    出现于日报：07-24

  9. 9. Improving Neural Retrieval with Attribution-Guided Query Rewriting

    方法对首轮前五篇文档计算梯度式 token 归因，把完整查询及归因分数作为软提示交给 Mistral-7B-Instruct 一次性改写，无需重训检索器。在 BEIR 上，SPLADE 的 nDCG@10 相对原查询最高提升 9%、相对普通 LLM 改写提升 22%；TCT-ColBERT 对应最高提升 10% 和 16%。

    出现于日报：07-23

  10. 10. PLAID-PRF: Pseudo-Relevance Feedback with Centroid-like Tokens in PLAID

    论文利用 PLAID 内部量化质心向量做伪相关反馈，从首轮结果中选取少量、多样且高效用的扩展向量追加到 ColBERT 查询，再执行第二轮召回与打分。在 MS MARCO 和四个 BEIR 域外基准上，相比 PLAID，nDCG@10 最高提升 4.3%，MRR@10 最高提升 7.3%。

    出现于日报：07-23
