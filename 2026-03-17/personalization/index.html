Bridging Sequential and Contextual Features with a Dual-View of Fine-grained Core-Behaviors and Global Interest-Distribution

针对传统 CTR 模型将用户行为序列聚合为单一向量后再与上下文特征交互导致行为信息丢失的问题，提出双视角建模框架：一方面通过细粒度核心行为视角精准捕捉用户与候选物品的关键交互信号，另一方面通过全局兴趣分布视角建模用户整体偏好的宏观分布特征。该方法在保持计算效率的同时，避免了朴素逐行为交互带来的噪声问题，有效提升了对用户实时兴趣变化的感知能力。

Deferred is Better: A Framework for Multi-Granularity Deferred Interaction of Heterogeneous Features

Alibaba📖 深度解读 · 7 分钟 →

揭示了 CTR 预估中特征异构性（categorical vs numerical、稀疏 vs 稠密）被普遍忽视的问题：现有模型将所有特征同时输入交互层，导致低信息量特征注入噪声、掩盖高信息量特征信号，甚至引发模型坍缩。提出多粒度信息感知延迟交互框架（MGID），根据特征的信息密度分层引入交互，先让高信息量特征建立稳健表征，再逐步融入低信息量特征，从而学习更鲁棒的特征表征。

INSIGHT「延迟交互」思想对工业 CTR 系统有直接启发：在实际特征工程中，ID 类特征（极稀疏）与统计类特征（相对稠密）的信息密度差异巨大，一刀切的特征交互策略确实可能导致稀疏特征的噪声信号干扰稠密特征的学习。该框架提供了一种即插即用的特征交互改进思路——按信息粒度分层交互，不需要改变现有模型架构，适合在现有 CTR 模型上做增量优化。

Taming the Long Tail: Efficient Item-wise Sharpness-Aware Minimization for LLM-based Recommender Systems

AAnt GroupZhejiang University

首次系统研究 LLM 作为推荐系统主干时面临的长尾问题，发现存在两种不同类型的长尾效应：（i）先验长尾，继承自预训练语料的隐式偏差；（ii）数据长尾，源于推荐数据集的分布倾斜。分析表明两者的头部交集会产生更强的头部效应，但整体性能差异主要由数据长尾主导。提出高效的逐物品锐度感知最小化方法（Item-wise SAM），在不显著增加计算开销的前提下改善长尾物品的推荐表现。

INSIGHT该研究揭示了 LLM 推荐系统中长尾问题的独特双重来源——预训练语料偏差叠加推荐数据偏差，这是传统推荐模型不存在的新挑战。对于实际搜索推荐系统，这意味着简单地将 LLM 作为推荐主干并不能自动解决长尾问题，反而可能因预训练偏差加剧不公平。Item-wise SAM 的设计思路（逐物品级别的优化平滑）为缓解长尾问题提供了一种低成本方案，值得在 LLM-based 排序模型中尝试。

Jiaming Zhang, Yuyuan Li, Xiaohua Feng, Li Zhang, Longfei Li, Jun Zhou, Chaochao Chen

Anchored Alignment: Preventing Positional Collapse in Multimodal Recommender Systems

针对多模态推荐系统中统一 embedding 空间对齐导致模态特有结构模糊化和 ID 主导的问题，提出 AnchorRec 框架。核心思路是在轻量投影域中进行间接的锚点对齐，将对齐过程与表征学习解耦，从而保留每个模态的原生结构同时维持跨模态一致性，避免位置坍缩。在四个 Amazon 数据集上的实验表明，AnchorRec 在 Top-N 推荐准确率上具有竞争力，同时多模态表达力和连贯性明显改善。代码已开源。

INSIGHTAnchorRec 的锚点对齐策略解决了多模态推荐中的一个关键工程问题：直接在统一空间中强制对齐不同模态会破坏各模态的固有结构（图像的视觉聚类、文本的语义拓扑），最终退化为 ID 特征主导。对于 UGC 搜索场景，帖子往往包含图文混合内容，该方法的解耦对齐思路可用于构建更好的多模态物品表征，同时保持计算轻量，适合在线部署。

Yonghun Jeong, David Yoon Suk Kang, Yeon-Chang Lee

Meta Andromeda: Supercharging Advantage+ with Next-Gen Personalized Ads Retrieval Engine

Meta

Meta 发布新一代个性化广告检索引擎 Andromeda，在模型架构、特征表征、学习算法、索引结构和推理范式五个维度进行了系统性创新，并基于 NVIDIA Grace Hopper 超级芯片和自研硬件进行推理加速。在线 A/B 实验中，Andromeda 实现了检索系统 +6% 的召回提升和特定场景 +8% 的广告质量提升，显著改善了 Advantage+ 自动化广告投放的效果。

INSIGHTAndromeda 体现了大规模广告检索系统从「单点优化」到「全栈协同优化」的演进趋势——模型架构、特征工程、学习算法、索引结构和硬件推理五个维度的联合设计才能释放最大性能收益。对于搜索推荐系统，其在检索阶段就引入深度个性化（而非仅在排序阶段）的设计理念值得借鉴，特别是当系统面临海量候选池时，前置化个性化可以显著提高后续排序阶段的上限。

The Privacy-Utility Trade-Off of Location Tracking in Ad Personalization

结合经济学理论、机器学习和因果推断方法，基于亚洲某头部 App 内广告平台的真实数据，量化地理位置数据对广告个性化的价值。研究发现地理数据在冷启动阶段最有价值——当用户行为历史有限时，地理数据与行为数据形成互补关系，显著提升定向效果。随着行为数据积累，地理数据的边际价值逐渐递减，行为数据逐步替代地理数据的作用。

INSIGHT该研究为搜索推荐系统中的数据策略提供了定量依据：在冷启动阶段应积极利用地理位置等上下文信号弥补行为数据不足，而非一刀切地限制或使用位置数据。随着用户行为积累，系统应动态调整特征权重，逐步降低对位置信号的依赖。这一发现对 UGC 社区搜索中新用户的个性化策略有直接参考价值——可在冷启动期优先利用用户位置、设备等上下文特征，热启动后平滑过渡到行为特征主导的排序。

VLM4Rec: Multimodal Semantic Representation for Recommendation with Large Vision-Language Models

重新审视多模态推荐中的语义对齐问题：传统方法将文本和视觉信号视为特征融合问题，但原始视觉特征保留的是外观相似性，而用户决策往往受到更高层语义因素（风格、材质、使用场景）驱动。提出 VLM4Rec 框架，利用大型视觉-语言模型将物品图像转化为显式自然语言描述，在语义空间中组织多模态内容，实现与用户偏好匹配的语义对齐，而非直接特征拼接。

INSIGHTVLM4Rec 的核心启示在于：多模态推荐的瓶颈可能不在融合策略，而在于原始特征的语义粒度不匹配。将视觉特征通过 VLM 转化为语言描述（如「简约风格、棉质面料、适合日常穿搭」），本质上是用 VLM 做了一次语义提升，使得图文特征在同一语义层级上交互。对于 UGC 搜索中包含图片的帖子，该方法可用于生成结构化的语义标签，提升图文混合内容的检索效果。

Ty Valencia, Burak Barlas, Varun Singhal, Ruchir Bhatia, Wei Yang

AgentDrift: Unsafe Recommendation Drift Under Tool Corruption Hidden by Ranking Metrics in LLM Agents

揭示了工具增强 LLM 推荐 Agent 中一个严重的评估盲区：当外部工具输出被污染时，标准排序指标（如 NDCG）显示推荐质量基本不变（效用保持比≈1.0），但 65-93% 的对话轮次中出现了风险不适当的产品推荐。通过在 7 个 LLM（7B 到前沿模型）上重放真实金融对话，验证了安全违规主要由信息通道驱动、在首个被污染轮次即出现、且 23 步对话中无自我纠正。

INSIGHT该研究对搜索推荐系统的安全评估提出了重要警示：传统排序质量指标（nDCG、MRR 等）无法检测到推荐内容的安全性漂移，需要专门的安全维度评估。对于引入 LLM Agent 进行推荐的系统，工具输出的可信验证变得至关重要——一个被污染的外部数据源可以在不影响排序指标的情况下系统性地引入不安全推荐，且模型不会自行修正。

Zekun Wu, Adriano Koshiyama, Sahan Bulathwela, Maria Perez-Ortiz

Can Fairness Be Prompted? Prompt-Based Debiasing Strategies in High-Stakes Recommendations

研究 LLM 推荐系统中的隐式偏见问题：LLM 可从姓名、代词等间接线索推断性别、年龄等敏感属性，进而产生偏见推荐。提出三种基于 prompt 的公平性去偏策略，在 3 个 LLM、4 种 prompt 模板、9 种敏感属性值和 2 个数据集上的实验表明，指示 LLM 保持公平的 prompt 策略可将公平性提升至 74%，同时基本保持推荐效果，但可能在某些场景过度补偿。

INSIGHTPrompt-based 去偏策略的实用价值在于其零成本特性：无需访问模型权重、无需重训练、普通用户即可使用。对于实际推荐系统，这意味着在 LLM 推荐链路中只需调整 prompt 即可缓解人口统计偏见，是一种高性价比的公平性改进方案。但研究也揭示了过度补偿的风险——简单的「请保持公平」指令可能导致系统刻意回避与敏感属性相关的合理推荐，需要细粒度的 prompt 设计。

Mihaela Rotar, Theresia Veronika Rampisela, Maria Maistro

Competition-Aware CPC Forecasting with Near-Market Coverage

基于 Google Ads 竞价日志，研究 CPC（每次点击成本）的预测问题。利用预训练 Transformer 表征从关键词文本、CPC 时间轨迹和地理市场结构三个维度构建互补信号：语义邻域和语义关键词图（来自关键词 embedding）、行为邻域（通过 DTW 对齐 CPC 轨迹）、以及地理意图特征（捕捉本地化需求和市场异质性），用于 1,811 个关键词序列的周级 CPC 预测。

INSIGHT该研究展示了如何将 Transformer embedding 应用于搜索广告竞价预测——将关键词文本语义、历史出价行为和地理结构作为三路互补信号，构建时空图预测器。对于搜索推荐系统中的商业化场景（如竞价排名、广告 CTR 预估），这种多信号融合的建模思路可迁移用于预测广告主的出价行为，从而优化广告分配和收入。
