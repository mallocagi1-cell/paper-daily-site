ToolTree: Efficient LLM Agent Tool Planning via Dual-Feedback Monte Carlo Tree Search and Bidirectional Pruning

针对 LLM Agent 工具规划中贪心式选择缺乏前瞻性、忽略工具间依赖关系的问题，提出 ToolTree——一种基于蒙特卡洛树搜索（MCTS）的新型工具规划范式。核心设计包括双阶段 LLM 评估机制和双向剪枝（执行前后均进行），使 Agent 在长程工具调用序列中做出更优决策。在 4 个开放/封闭工具规划基准上，ToolTree 在保持最高效率的同时持续提升性能。

KEY INSIGHT · 对业务意味着什么ToolTree 将 MCTS 引入 LLM Agent 工具规划，核心创新在于双向剪枝机制——执行前通过 LLM 评估预判分支价值，执行后根据实际反馈裁剪无效路径。这种'先评后剪'的模式对搜索系统中的多步工具调用链（如先召回、再排序、再生成）有直接借鉴意义：在每步决策时前瞻性地评估后续工具组合的价值，避免在低效路径上浪费计算资源。

Structured Distillation for Personalized Agent Memory: 11x Token Reduction with Retrieval Preservation

研究个性化 Agent 记忆压缩问题：将用户与 Agent 的对话历史蒸馏为紧凑的检索层。每条交互压缩为包含 exchange_core、specific_context、thematic room_assignments 和 files_touched 四个字段的结构化对象，平均仅 38 tokens。在 6 个软件工程项目的 4,182 次对话（14,340 条交互）上，实现 11 倍压缩（371→38 tokens），最优纯蒸馏检索配置达到 74% 精度，跨层融合配置达到 81% 精度。

INSIGHTAgent 记忆的核心瓶颈不是存储而是检索——11 倍压缩后仍保持 81% 检索精度的关键在于结构化蒸馏而非简单摘要。四字段模式（核心交互、具体上下文、主题标签、涉及文件）可直接迁移到搜索系统的用户行为记忆中，将用户的搜索历史、点击行为压缩为结构化记忆块，在个性化排序和 query 理解中实现高效检索增强。

Sydney Lewis

Spend Less, Reason Better: Budget-Aware Value Tree Search for LLM Agents

针对 LLM Agent 测试时计算（test-time scaling）中计算资源浪费问题，提出 Budget-Aware Value Tree（BAVT）——一种免训练的推理时框架。将多跳推理建模为动态搜索树，结合步级价值估计；核心创新是预算条件化节点选择机制，利用剩余资源比率作为自然缩放指数，在预算耗尽时从广泛探索无参数地平滑过渡到贪心利用。通过引入外部验证器对抗 LLM 自评估的过度自信。

INSIGHTBAVT 提出了一种优雅的预算感知机制：随着资源消耗，搜索策略自动从探索转向利用，这对搜索系统中的 Agent 推理有直接启示。在社区搜索场景中，Agent 需要在有限的 token 和 API 调用预算内完成多步推理（如 query 理解→召回→精排），BAVT 的资源比率指数方法提供了一种无需调参即可实现动态资源分配的方案。免训练特性也意味着可即插即用。

Yushu Li, Wenlong Deng, Jiajin Li, Xiaoxiao Li

Efficient and Interpretable Multi-Agent LLM Routing via Ant Colony Optimization

针对 LLM 多 Agent 系统部署中推理成本高、延迟大、透明度低的问题，提出 AMRO-S——基于蚁群优化（ACO）的多 Agent 语义路由框架。将 MAS 路由建模为语义条件化路径选择问题，通过三个关键机制提升性能：监督式语义路由层、基于信息素的动态负载均衡、以及可解释的路由决策追踪。在混合意图和动态负载场景下实现更稳定的性能和更高效的资源利用。

INSIGHTAMRO-S 将蚁群优化引入 LLM Agent 路由是一个新颖视角：信息素机制天然支持动态负载均衡和历史经验积累。对搜索系统而言，当多个专业 Agent（如 query 理解 Agent、召回 Agent、排序 Agent）构成管道时，AMRO-S 的语义感知路由可根据 query 类型和实时负载动态选择最优 Agent 组合，避免固定管道的资源浪费。可解释性也有助于诊断搜索质量问题。

AI Planning Framework for LLM-Based Web Agents

通过将 Web 任务形式化为序列决策过程，建立 Web Agent 架构的规划分类学：Step-by-Step 对应广度优先搜索（BFS），Tree Search 对应最优优先树搜索，Full-Plan-in-Advance 对应深度优先搜索（DFS）。提出 5 个超越简单成功率的评估指标，并构建包含 794 条人工标注轨迹的新数据集，系统分析上下文漂移和不一致任务分解等失败模式。

INSIGHT将 Agent 规划映射到经典搜索算法（BFS/DFS/Best-First）的思路为搜索系统中的 Agent 设计提供了理论框架。关键发现是不同规划策略在不同任务复杂度下表现差异显著——简单任务适合 DFS（快速执行），复杂任务需要 Best-First（灵活探索）。这意味着搜索 Agent 应根据 query 复杂度动态切换规划策略，而非固定使用单一架构。5 个新评估指标也可迁移用于评估搜索 Agent 的轨迹质量。

Orit Shahnovsky, Rotem Dror

Prompt Injection as Role Confusion

MIT

从机制层面解释 Prompt 注入攻击的根因：模型通过文本风格推断角色（'谁在说话'），而非基于文本来源。设计新型角色探针（role probes）捕获模型内部角色识别机制，发现不受信任的文本模仿特定角色风格即可继承该角色权限。在 StrongREJECT 上平均攻击成功率 60%，Agent 数据窃取场景成功率 61%，且内部角色混淆程度可在生成前预测攻击成功率。

INSIGHT该工作揭示了 LLM Agent 安全的根本性缺陷：安全边界定义在接口层，但权限实际在隐空间中分配。对搜索 Agent 而言，当处理用户 UGC 内容（如社区帖子）时，帖子中的恶意文本可能被模型误认为系统指令，导致 Agent 行为被劫持。这意味着搜索 Agent 需要在检索到的文档和系统指令之间建立更强的隔离机制，而非仅依赖 prompt 模板。

Charles Ye, Jasmine Cui, Dylan Hadfield-Menell

XSkill: Continual Learning from Experience and Skills in Multimodal Agents

提出 XSkill——多模态 Agent 的双流持续学习框架，解决 Agent 在开放场景中工具使用效率低和编排不灵活的问题。识别两种互补的可复用知识：经验（action 级的工具选择指导）和技能（task 级的规划与工具使用指导）。通过视觉观察驱动知识提取和检索，在积累阶段通过多路径 rollout 的可视化摘要和跨 rollout 批判进行蒸馏，无需参数更新即可持续改进。

INSIGHTXSkill 的双流知识复用架构（经验 + 技能）对搜索 Agent 的自我改进有重要启示。在搜索系统中，action 级经验（如'此类 query 用 BM25 召回效果更好'）和 task 级技能（如'长尾 query 的完整处理流程'）需要不同粒度的积累和检索机制。无参数更新的持续学习方式特别适合生产环境中搜索 Agent 的在线自适应。

Guanyu Jiang, Zhaochen Su, Xiaoye Qu, Yi R. Fung

OpenSage: Self-programming Agent Generation Engine

提出 OpenSage——首个支持 LLM 自动创建 Agent（含自生成拓扑和工具集）的 Agent 开发套件（ADK）。提供 Agent 自主创建和管理子 Agent 及工具包的功能，引入层次化图式记忆系统用于高效管理，并配备专门面向软件工程任务的工具集。在 SWE-bench 等 3 个基准上，使用多种骨干模型进行了广泛实验验证。

INSIGHTOpenSage 的自编程范式（Agent 自动生成子 Agent 和工具）代表了 Agent 系统构建的新方向。对搜索系统而言，这意味着搜索 Agent 可根据具体搜索场景自动组装最优工具链（如针对 UGC 短文本搜索自动选择分词器、语义匹配器、排序器），而非依赖人工预定义管道。层次化图式记忆也提供了 Agent 间知识共享的实用模式。

Building Effective AI Coding Agents for the Terminal: Scaffolding, Harness, Context Engineering, and Lessons Learned

介绍 OPENDEV——面向终端的开源 CLI 编码 Agent，采用复合 AI 系统架构。核心设计包括：基于工作负载的专业化模型路由、规划-执行分离的双 Agent 架构、懒加载工具发现机制、以及自适应上下文压缩（渐进式缩减旧观测数据）。配备自动化记忆系统，在 SWE-bench Verified 和 Terminal-Bench 等基准上验证了长期自主开发任务的有效性。

INSIGHTOPENDEV 的工程实践经验对构建搜索 Agent 有高度参考价值：规划-执行分离避免了单一 Agent 在长期任务中的上下文退化；懒加载工具发现减少了不必要的上下文膨胀；自适应上下文压缩解决了长对话中推理质量下降的问题。这些设计模式可直接应用于搜索系统中的 Deep Research Agent，确保在多步检索-推理循环中保持稳定的推理质量。

ARL-Tangram: Unleash the Resource Efficiency in Agentic Reinforcement Learning

针对 Agentic RL 训练中外部云资源（代码执行 CPU、奖励模型 GPU）严重低效的问题，提出 action 级资源编排范式。ARL-Tangram 通过统一的 action 级抽象和弹性调度算法，实现细粒度外部资源共享和弹性伸缩，最小化 action 完成时间（ACT），同时满足异构资源约束。相比静态过度配置的现有方案，显著提升资源利用率。

INSIGHTARL-Tangram 揭示了 Agentic RL 与传统 RL 的关键区别：大量外部交互资源（非训练 GPU）成为瓶颈。action 级编排的思路可迁移到搜索 Agent 的推理服务中——当搜索 Agent 需要调用多个外部工具（如搜索引擎 API、排序模型、知识图谱）时，基于 action 粒度的弹性调度可避免资源锁定在长生命周期的 trajectory 上，提升吞吐量和成本效率。
