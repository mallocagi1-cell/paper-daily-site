Mask-Enhanced Autoregressive Prediction: Pay Less Attention to Learn More

针对大语言模型在长序列中难以准确检索关键信息的问题，提出 MEAP（Mask-Enhanced Autoregressive Prediction）训练范式，将 Masked Language Modeling 无缝集成到 Next-Token Prediction 中。核心思路是在训练时随机遮蔽少量输入 token，然后直接进行标准的自回归预测，无需双向注意力或编码器-解码器架构，预训练和推理零额外开销。实验表明 MEAP 在 lost-in-the-middle 场景下的监督微调中提升 11.77 个百分点，同时在常识推理任务上表现持平或更优。

When Right Meets Wrong: Bilateral Context Conditioning with Reward-Confidence Correction for GRPO

针对 GRPO（Group Relative Policy Optimization）在训练推理模型时忽略组内正确与错误样本之间对比信号的问题，提出对比式重构方法。首先证明 GRPO 目标函数隐式地最大化正确与错误样本策略比率之间的间距，基于此提出 Bilateral Context Conditioning（BICC）机制，允许模型在优化过程中交叉引用成功和失败的推理轨迹。同时引入 Reward-Confidence Correction（RCC）通过奖励-置信度协方差动态调整 GRPO 的优势基线以稳定训练。两种机制无需额外采样或辅助模型，可适配所有 GRPO 变体，在数学推理基准上实现一致提升。

INSIGHTBICC 的核心贡献在于揭示了 GRPO 训练中被忽视的结构化信号——同组内正确与错误推理轨迹的对比关系。通过让模型在优化时直接对比成功和失败的推理过程，实现了跨样本的信息流动，这比独立处理每个样本效率更高。对于生成式推荐系统的训练，GRPO 已成为关键的对齐算法（如 DiffuReason 中的排序优化），BICC 的即插即用特性意味着可以直接应用于推荐模型的 GRPO 训练流程中，通过对比好/差推荐结果的生成轨迹来提升模型的排序质量。代码已开源。

Yu Li, Tian Lan, Zhengling Qi

Multi-Step Semantic Reasoning in Generative Retrieval

University of Amsterdam

针对生成式检索（GR）模型在处理涉及数值推理的复杂查询时能力不足的问题，提出 ReasonGR 框架。该框架采用结构化提示策略，将任务特定指令与逐步推理引导相结合，同时集成推理聚焦的适配模块来增强推理相关参数的学习。在 FinQA（金融报表查询）数据集上的实验表明，该方法显著提升了检索准确率和一致性，验证了推理能力增强对 GR 模型在实际应用中的重要性。已被 ECIR2026 接收。

INSIGHTReasonGR 揭示了生成式检索的一个重要盲区：现有 GR 模型虽然能生成文档标识符，但在需要多步语义推理（特别是数值推理）的查询上表现不佳。结构化提示+推理适配模块的双重策略为 GR 模型增添推理能力提供了一条可行路径。对搜索系统而言，这意味着生成式检索不能仅依赖模式匹配，还需要具备推理能力才能处理复杂查询（如'营收同比增长超过 20% 的公司'）。该思路可迁移至 UGC 搜索中涉及条件筛选和逻辑推理的查询场景。

Steven Dong, Yubao Tang, Maarten de Rijke

Swap-guided Preference Learning for Personalized Reinforcement Learning from Human Feedback

针对标准 RLHF 假设单一全局奖励导致无法捕捉多样化用户偏好的问题，首次识别出 Variational Preference Learning（VPL）中的后验坍缩现象——在稀疏偏好数据和过度表达性解码器下，用户特定的隐变量被忽略，模型退化为单一奖励模型。提出 Swap-guided Preference Learning（SPL），通过构造虚拟交换标注者并利用其偏好的镜像特性来引导编码器，包含三个组件：交换引导基础正则化、Preferential Inverse Autoregressive Flow（P-IAF）和自适应隐变量条件化。已被 ICLR 2026 接收。

INSIGHTSPL 的核心发现是个性化 RLHF 中 VPL 方法的后验坍缩问题——这意味着看似学到了用户偏好的模型实际上可能退化为忽略用户差异的统一模型。对生成式推荐系统而言，这一发现具有警示意义：基于 LLM 的推荐模型在使用 RLHF 进行个性化对齐时，同样可能遭遇后验坍缩，导致推荐结果趋同化。SPL 的交换引导机制提供了一种在偏好数据稀疏时仍能有效学习用户特定偏好的方法，可借鉴用于推荐系统中的个性化奖励建模。

Gihoon Kim, Euntai Kim

Information-Consistent Language Model Recommendations through Group Relative Policy Optimization

针对 LLM 在企业关键领域（金融、教育、客户支持）中提供推荐时对语义等价但措辞不同的提示产生不一致结果的问题，提出基于 GRPO 的强化学习框架。现有方法如 RAG 和温度调整虽能改善事实性或降低随机性，但无法保证跨等价提示的稳定性。该框架通过 GRPO 训练 LLM 对语义等价的推荐请求生成一致的输出，适用于 HR 入职引导、客户服务、政策披露等需要确定性信息传递的场景。

INSIGHT该工作指出了 LLM 推荐系统中一个常被忽视的问题：推荐一致性。即使查询语义相同，LLM 可能因措辞差异产生不同推荐结果，这在企业场景中会带来合规风险和用户信任问题。GRPO 被证明是解决此类一致性问题的有效工具——通过将一致性作为奖励信号进行优化。对搜索推荐系统而言，这提供了一个重要启示：在追求推荐质量的同时，推荐的稳定性和可预测性同样是关键质量指标，尤其在 LLM 驱动的生成式推荐中需要显式优化一致性。

Sonal Prabhune, Balaji Padmanabhan, Kaushik Dutta

Collaborative Multi-Agent Optimization for Personalized Memory System

USTC

针对个性化 LLM 记忆系统中多个 Agent 独立优化无法保证全局系统性能的问题，提出协作强化学习框架 CoMAM。将多 Agent 的执行过程建模为序贯马尔可夫决策过程，将 Agent 间依赖关系嵌入状态转移中，同时产生局部任务奖励（如信息覆盖度）和全局系统奖励（如问答准确率）。通过组级排序一致性进行信用分配，使局部 Agent 的优化方向与全局系统性能对齐。实验表明 CoMAM 优于现有主流记忆系统。

INSIGHTCoMAM 解决了多 Agent 系统中局部优化与全局性能不一致的根本问题——各 Agent 各自优化自身任务（记忆构建、记忆检索），但拼凑起来的全局效果可能不如协同优化。这一思路对推荐系统中的多阶段流水线（如召回→粗排→精排→重排）具有启发意义：各阶段独立优化可能导致全局次优，通过协作 RL 框架可以实现端到端的全局优化。个性化记忆检索的能力也与对话式推荐中的长期用户建模高度相关。

Wenyu Mao, Haoyang Liu, Zhao Liu, Haosong Tan, Yaorui Shi, Jiancan Wu, An Zhang, Xiang Wang

TERMINATOR: Learning Optimal Exit Points for Early Stopping in Chain-of-Thought Reasoning

针对大型推理模型（LRM）在 Chain-of-Thought 推理中严重的「过度思考」问题——即使答案已经生成仍继续消耗大量计算资源——提出 TERMINATOR 早期退出策略。核心思路是利用 LRM 最终答案首次出现的可预测性，训练一个早期停止机制来自动判断最优推理长度。在 MATH-500、AIME 2025、HumanEval、GPQA 四个数据集上平均将 CoT 长度缩短 14%–55%，同时性能优于现有最优方法，精度损失微乎其微。

INSIGHTTERMINATOR 的实用价值在于大幅降低推理型 LLM 的推理成本——CoT 长度缩短 14%–55% 意味着同等算力可以服务更多请求。对于生成式推荐场景，当推荐模型引入推理能力（如 DiffuReason 的 Thinking Tokens）时，过度推理将成为在线服务延迟的主要瓶颈。TERMINATOR 式的早期退出机制可以在保持推荐质量的前提下显著降低推理延迟，是推理增强型推荐模型走向线上部署的关键优化技术。

Alliot Nagle, Jakhongir Saydaliev, Dhia Garbaya, Michael Gastpar, Ashok Vardhan Makkuva, Hyeji Kim
