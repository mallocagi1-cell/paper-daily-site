H2CE: Modeling Geo-Semantic Interactions for POI Reranking with Heterogeneous Two-Stage Cross-Encoders

针对本地搜索中语义、距离与口碑信号难以联合比较的问题，H2CE 将数值分桶文本与精确数值 MLP 同时输入异构 cross-encoder，再对首阶段前十名进行成对重排。在 5,743 条查询上，nDCG@5 达到 67.48，比 XGBoost 高 22.82 个百分点；成对阶段额外贡献 1.98 个百分点。

SkillContrast: Difference-Guided Text Selection for Agent Skill Reranking

SkillContrast 针对相似技能共享大段描述而适用条件不同的问题，比较候选之间的差异，保留区别性片段及邻近上下文供预训练重排器使用。在 1,235 条请求中，相同输入长度下比 TF-IDF 多得到 54—72 次干净命中；相对完整正文减少 51.1%—58.8% 的输入 token。

INSIGHT社区搜索常有标题相近但适用对象不同的帖子，可把候选间的差异作为重排截断信号，减少重复背景占用输入预算。应在帖子和问答数据上比较完整正文、query 相关截断及差异截断；原文的干净命中同时考查危险兄弟技能排除，并非一般相关性指标。

Ding, Jiandong, Ji, Honglei, Liu, Ming, Duan, Tao

EVIE: Evidence-Vector-Informed Embeddings for Visual Document Retrieval

Tencent

EVIE 面向视觉文档检索，联合证据判别的数据清洗、双向师生排序蒸馏及前缀嵌套表征，并以空间约束聚类压缩页面向量。在 138 项任务上，8B 教师的 ViDoRe V3 nDCG@10 为 66.75，超过外部最强基线 1.43 点；压缩学生以每百万页 3.81 GiB 向量载荷保留 59.58 分。

INSIGHT社区若包含截图、图文帖子，可将答案证据核验用于正负样本治理，并用同一检查点提供不同维度表征。128 倍压缩比较的是最大视觉 token 配置的向量载荷，不包含索引开销；迁移到短文本时，应分别验证证据标签质量与压缩后长尾召回，而不能直接套用视觉基准收益。

Autoregressive Retriever: Improving Query Understanding from Item Feedback for Universal Multimodal Retrieval

ARR 让多模态检索器先检索反馈条目，再据其内容更新 query 向量，最终仍通过固定文档索引匹配。训练采用逐步对比监督和以最终倒数排名为奖励的强化学习。M-BEIR 上 8B 模型平均指标为 61.0，比 TRACE 的 58.8 高 2.2 点；零样本平均为 79.01。

INSIGHT可借鉴反馈训练来改善社区含糊 query 的语义表征，但多轮向量更新增加查询侧成本，需要和一次召回严格比较。论文显示只使用初始向量也能受益，宜先评估这种无需在线反馈的模式；多模态离线平均指标不等于社区 UGC 的 nDCG 或 CTR 提升。

Syn-Omni: Structured Specialization and Progressive Collaboration for Omnimodal Embeddings

已录用 EMNLP 2026SonyKAIST

Syn-Omni 将共享语义 LoRA 与各模态专家分开，用正交约束降低重复，并逐步引入跨模态协作路由。作者以 112 万混合样本训练，在图像、视频、音频等 81 项任务上评估；3B 消融中完整结构整体 Hit@1 达 49.4，优于只用共享路径的 47.7。

INSIGHT对含图像或音频的社区内容，表征训练可先保证模态各自可用，再逐步学习跨模态协同，避免所有输入争用一个适配通道。该方案使用 3B/7B 全模态基座，短文本搜索应先验证共享加专家是否带来收益，再承担训练和服务成本；81 任务平均包含分类及问答。

Oh, Youngtaek, Wu, Qiyu, Wakaki, Hiromi, Kim, Junmo, Mitsufuji, Yuki

NativeScope: Relation-Localized Retrieval over Native Topology with a Correct Anchor

NativeScope 将带锚点和关系的查询拆成定位、范围限制与目标词排序，利用章节归属及对话先后关系筛选候选。对 QASPER 和 LongMemEval 派生的 200 条控制样本，在 1,024 token 预算下文档与记忆召回分别为 89.28% 和 72.50%；自动 Top-1 锚点时记忆召回降至 35.50%。

INSIGHT社区的楼层、引用和问答串有天然拓扑，可以先约束到指定讨论或某回复前后的范围，再做语义排序。收益主要来自关系范围，目标词排序相对完整 query 的差异不显著；锚点错定位会放大硬过滤风险，应保留全局召回兜底，并用真实会话检验定位质量。

AMBER: Multi-View Adaptive Budget Allocation for Listwise Vision-Language Reranking

SJTUOPPOUCL

AMBER 将小视图的视觉语言排序结果视作局部比赛，用连续 Elo 更新维护全局次序，并按候选歧义和预期信息增益分配调用预算。在每 query 八次调用下，CIRCO mAP@5 为 56.80，高于滑窗的 54.32；PhotoBench 平均 nDCG@10 为 50.97。

INSIGHT可借鉴候选歧义驱动的资源分配，让社区难 query 获得更多重排计算，简单 query 早停。但原文针对视觉语言候选，不能把调用预算直接换成短文本时延收益；应以同一重排器、相同总预算比较固定调度和自适应调度，并统计尾延迟与难 query 的 nDCG。
