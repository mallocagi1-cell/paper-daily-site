RIT-RAG: Navigating Document Corpora with Retrieval-Induced Trees

RIT-RAG 将召回与阅读解耦：先用检索命中的段落及祖先节点构造跨文档子树，再让 Agent 按需读取节点、改写查询。相同混合检索器下，Haiku 在 WixQA 的答案准确率由 Agentic Search 的84.5%升至95.0%，FinanceBench由74.0%升至84.0%；284万网页语料验证了规模可扩展性。

Programmatic Search Agents: Extending Agentic Search Beyond Query Reformulation

PSA 将搜索动作扩展为候选集合上的可执行程序单元，结合持久候选工作区、检索原语组合和选择性证据展示。五种策略模型在InfoSeek-Eval和BrowseComp-Plus上无需专项训练，相比查询式Agent的宏平均成功率分别提高4.00和7.56个百分点，末步token分别减少28.3%和33.9%。

INSIGHT只允许改写query会把候选处理和证据展示固定在搜索接口中，即使召回正确段落也可能未被Agent看见。社区搜索可尝试让Agent复用候选、合并证据并精确选择展示内容；实现时要保持统一检索底座进行对照，区分接口收益与模型收益，代码尚待审批发布使复现存在工程成本。

Jiaming Qian, Huiyan Yang, Mandi Liu, Jie Liu, Wenkai Shen, Pengyang Zhou, Jing Jin, Jin Ma 等 10 人

Asana cuts model costs 76x in browser tests with GPT-6.1 Sol

AsanaOpenAI

Asana通过144次浏览器Agent实验优化历史缓存、文本保留与截图裁剪，较原生产方案实现估算模型费用降低76倍、耗时降低5倍。优化后的GPT-6.1 Sol每次约0.47美元和4分钟；同模型对照费用由1.97降至0.47美元，保留历史增大后18次任务全部正确完成。

INSIGHT多步搜索助手的成本可能主要来自反复发送并改动历史，而非query本身。可借鉴保持稳定前缀、延后批量裁剪截图及扩大证据保留预算，减少缓存失效和重复访问；76倍包含模型切换与流程优化，应优先参考同模型约4倍的对照结果，并在社区搜索任务上测试费用、正确性和响应时间。

Agentic RAG Evaluation: Budget Allocation Across Questions, Trajectories, and Reads

论文研究Agentic RAG评测预算在问题数、搜索轨迹及重复作答之间的分配，在HotpotQA和MuSiQue上比较检索反馈方案。34.14–34.39百万token预算下，扩大问题覆盖相对五次阅读降低标准误33%，相对三条轨迹降低12.6%；温度零使答案分歧由14.3%降至3.4%。

INSIGHT社区搜索评测应先覆盖更多真实query，再决定是否为单个query追加轨迹或阅读次数，避免把算力集中在少量问题上而无法稳定判断方案差异。论文的一次阅读相对最优配置方差损失为0–9.9%，但部分模型不确定性较大；应根据本地query分布和检索价格重新估计预算，而非直接套用比例。

Jingjie Ning, Xueqi Li, Yibo Kong

05 3.95

ATLAS: Evaluating Agents on Search-Intensive Tasks

EExa

Exa发布ATLAS，面向真实需求中的实体发现与信息补全任务，以核验标准答案和可更新流程减少基准过时。547个任务中，其无搜索记忆命中为9%，对照BrowseComp为48%、WideSearch为59%；官方估算十轮完整评测判分约2美元，并区分实体、整行和单元格F1。

INSIGHT社区搜索问答不应只评估能否找到一个名字，还要验证多个候选及其属性是否完整且正确。可借鉴ATLAS把发现与补充分开计分，定期刷新时效性query和证据；9%记忆率及费用来自供应商自身设置，不能直接视为独立复现结论，业务侧仍需构建真实UGC任务并验证与nDCG、CTR的关系。

Alexander Goldberg, Joshua Ahn, Scott Langille

PhantomEnvironments: Training LLM Agents in Fictional Worlds

CornellStanford

PhantomEnvironments用规则和Prolog生成虚构世界、文章及可核验多跳问答，不依赖LLM生成环境，再开展多轮RL训练。四种模型在六个真实搜索基准上均获提升，旧基准平均F1为基座的1.7倍、新困难基准为2.2倍；Llama-3.2-3B在SynthWorlds-SM由3.8升至27.0。

INSIGHT社区搜索Agent缺少可靠多跳训练标签时，可用可控实体关系和虚构帖子构造廉价交互环境，重点训练查询、证据串联与停止行为。论文发现跳数比约束和比较更影响迁移，值得先从简单规则图开始；虚构环境能训练搜索行为，却不能替代真实UGC中的噪声、时效及用户满意度验证。

Evaluating Deep-Search Agents under Hierarchical Web Evidence Poisoning

HAE-GEO追踪搜索Agent从接触网页投毒到核验、修正和恢复的完整轨迹，包含72039张干净页面、每层770张投毒页面、8类商品和154个品牌。10个Agent评测显示，防御提示把严格核验率从约2%提高到17%，但高级伪佐证仍会导致错误推荐，且平均token消耗增加24.5%。

INSIGHTUGC搜索易遇到重复营销内容和多页相互引用，不能把“检索到多个支持页面”自动当作可信证据。应分别记录证据识别、独立核验、错误撤回和最终答案质量；论文展示核验增加未必带来恢复，因此社区搜索Agent需要可追踪的独立证据来源与纠错机制，并同时评估额外调用的费用和时延。

MemPilot: Orchestrating On-Demand Multimodal Memory Curation for LLM Agents

NTUTsinghuaUIUC

MemPilot 用RL训练多步策略，在既有压缩记忆检索与按query调用不同LLM/VLM整理原始历史之间分配计算，联合控制证据数量、模型和视觉访问。五个多模态记忆基准的消融中，去掉外部整理使平均Judge分数从37.40降至14.58；去掉目标维度优势解耦则降至21.94。

INSIGHT对需要跨轮保存用户线索的社区搜索助手，可保留低成本通用记忆，再在问题需要时整理原始内容，而不是预先压缩所有信息。方法以质量、费用和延迟分别估计优势，能显式调节服务预算；目前证据来自多模态记忆任务，迁移到UGC文本搜索需要单独验证，不可把Judge提升当成CTR收益。

Mechanism-centric cross-domain retrieval for scientific discovery: LLM agents for structural isomorphism beyond semantic similarity

MCDF研究跨领域科学检索中语义相似度难以识别机制同构的问题，以神经符号框架分离主题与机制，并通过26个领域专家Agent生成专业搜索词。在谣言传播和模型坍塌两个案例中，平均机制对齐分数MAS超过0.82，优于包括BM25、RRF和RankGPT在内的六类基线。

INSIGHT机制相似但措辞不同的内容可能更有帮助，可借鉴其先抽取因果结构、再生成领域query的流程，为社区问题寻找跨主题经验。当前证据只有两个科学发现案例，MAS并非nDCG或CTR，出版商全文访问受限；应将其作为探索性设计启示，先测量是否能找出可解释的相关经验再考虑线上使用。

Huajun Zhou, Guozhu Jia

Sophos cuts threat investigation time by 96% with OpenAI Daybreak

SophosOpenAI

Sophos将威胁情报、客户上下文及操作手册接入调查Agent，由计划模型组织计划、执行与复核闭环，再为分析员生成响应建议。官方案例报告相关案件平均响应由约38分钟缩短至89秒，调查时间降低96%，52%的MDR案件可由AI端到端处理；文章未给出独立随机对照实验。

INSIGHT这一案例对社区搜索的价值在于任务拆解和证据整合：搜索复杂投诉或风险线索时，可让Agent收集上下文、执行检索并形成可复核建议。应把自动化适用范围与人工判断边界分开记录，并在同类查询上测量效率和准确率；安全运营的96%时间收益不能直接外推为社区搜索的相关性或点击率提升。
