CAR: Query-Guided Confidence-Aware Reranking for Retrieval-Augmented Generation

针对 RAG 中传统重排只看 query-document 相关性、忽视生成器实际「有用性」的问题，提出 CAR：一个无需训练、即插即用的重排框架。它把生成器在 query-only 与 query+document 两种条件下的多次采样答案做语义一致性比对，用置信度变化作为文档有用性信号——显著提升置信度的文档上调，降低置信度的下调，模糊样本保持原序，并通过 query 级门控避免在已确定查询上做无效干预。BEIR 四个数据集上验证表明，相比基线和现有重排基线均有稳定提升。

Storage Is Not Memory: A Retrieval-Centered Architecture for Agent Recall

提出 True Memory——一个把 agent 记忆当作多阶段检索而非存储 schema 的六层架构，核心思想是「在写入时不丢失任何信息，所有抽取/路由都推迟到 query 时」，让被丢弃的内容仍可恢复。整套系统跑在单个 SQLite 文件、纯 CPU 上，不依赖向量库、图库或 GPU。在 LoCoMo（1540 题）上 True Memory Pro 跑出 93.0% 准确率（vs Mem0 61.4%、Supermemory 65.4%、Zep 71%、EverMemOS 94.5%），LongMemEval 500 题上 87.8%，BEAM-1M 百万 token 长上下文 76.6%（高于此前 SOTA 73.9%）。

INSIGHT对短文本社区搜索很有借鉴的反共识结论：早 extraction（写入时抽取实体/摘要）会永久丢失原始证据；把抽取推迟到 query-time 的多阶段检索流水线，反而能用更轻的存储拿到更高准确率。这套「verbatim 存原文 + 多阶段召回+精排」的设计与社区 UGC 搜索高度同构——尤其是无需 GPU、单文件 SQLite 即可达成接近 SOTA 的工程取舍，对中小团队推荐系统/搜索冷启动阶段极具参考价值。

Joshua Adler, Guy Zehavi

Hybrid Pooling with LLMs via Relevance Context Learning

针对「LLM 当 IR 相关性评估器」存在的可靠性问题，提出 Relevance Context Learning (RCL)：先用 Instructor LLM 从已标注样本中显式抽取 topic-specific 的相关性标准（context），再让评估 LLM 在该 context 下打分，避免标准 ICL 把例子当独立实例的弱点。还引入 hybrid pooling 把多种相关性证据组合，提升对未见 query-document 对的泛化。在多个 IR 评估基准上相比 zero-shot 与标准 ICL 显著提升一致性。

INSIGHTLLM-as-judge 落地搜索相关性评估的关键不在「换更大模型」，而在把人类标注标准显式建模为 prompt-context。这条路径对社区 UGC 搜索特别相关——业务上需要持续做相关性回归测试，但人工 annotation 成本高且漂移；RCL 这种「先学标准、再判断」的两阶段框架可直接降低标注成本、提升评估稳定性。短期可用于离线相关性评测、相关性模型迭代过程中的 silver label 生产。

David Otero, Javier Parapar

OpenSearch-VL: An Open Recipe for Frontier Multimodal Search Agents

OpenSearch-VL 是首个完整开源的多模态 deep search agent 训练配方，覆盖数据合成、轨迹生成、SFT+RL 训练全流程。核心组件包括：基于 Wikipedia 路径采样、模糊实体改写与 source-anchor 视觉 grounding 的数据 pipeline（产出 SearchVL-SFT-36k 和 SearchVL-RL-8k），统一文本/图像/工具调用的 tool environment，以及 agentic RL 训练。在多个深度搜索 benchmark 上拿到 frontier 水平，并附带可复现的 trajectory synthesis 细节。

INSIGHT对社区搜索而言，「多模态 deep search agent」的训练方法可以下放到更窄的搜索任务（图文混合 UGC、视频帖子）。开源数据 pipeline 中的「fuzzy entity rewriting + source-anchor grounding」直接解决「one-step retrieval collapse」这类工业搜索常见 failure mode，这两个数据合成 trick 比单纯堆 RL 经验更可借鉴。但落地成本不低：完整 SFT+RL 链路需要可控工具环境与高质量轨迹合成，建议先复用其 SearchVL-SFT 数据，再决定是否上 RL。

Shuang Chen, Kaituo Feng, Hangting Chen, Wenxuan Huang, Dasen Dai

DoGMaTiQ: Automated Generation of Question-and-Answer Nuggets for Report Evaluation

针对 RAG 长文报告评估中「nugget 必须人工标注、跨语种 scaling 差」的痛点，提出 DoGMaTiQ：自动从源文档集合中生成 query-相关的 question-answer 形式 nugget，把信息需求（question）与可满足该需求的多种答案（answers）解耦，使评估更细粒度且可推广到 cross-lingual 场景。系统化讨论了 QA-nugget 生成的 pipeline 设计与质量控制策略。

INSIGHT「自动 nugget 生成」是把 RAG/搜索评估从开发阶段推向持续监控的关键基建。对社区搜索做长答案/聚合答案场景（如帖子摘要回答），可借鉴 QA-form nugget 自动生成代替整段文本匹配——它更适合衡量「关键事实是否覆盖到」而非「文本是否相似」。短期可用于建立离线 RAG eval pipeline 的 nugget 自动化生成模块，省去人工标注成本。

Reproducing Complex Set-Compositional Information Retrieval

针对「集合组合查询（合取/析取/排除）」做了一项可复现性研究，对主流检索家族与 reasoning-targeted 方法（ReasonIR、Search-R1）在 QUEST 与 QUEST+Variants 上重测，并提出受控的 LIMIT+ benchmark——其相关性由任意属性谓词与约束满足决定，不依赖预训练知识。结论：(i) QUEST 上最好的 neural retriever Recall@100>0.41 较 BM25 0.20 有翻倍优势，但 reasoning-targeted 方法并未一致超越通用 retriever；(ii) 在 LIMIT+ 上 QUEST 最强方法 Recall@100 从 0.42 暴跌到很低水平，说明现有方法多在「shortcut」而非真正约束推理。

INSIGHT这篇 reproducibility 论文给出一个被低估的 finding：复杂检索查询（如「帮我找 X 但排除 Y」）在 LLM 重排和 reasoning retriever 加持下并不能稳定胜出，更多是依赖训练分布的语义捷径。对社区搜索来说，UGC 长尾约束查询是真实场景，不能盲信 reasoning retriever 的 marketing 数字；建议引入 LIMIT+ 风格的合成约束 benchmark 做内部回归，识别我们的 retriever 在哪个谓词类型上崩坏，再针对性补 hard negative。

Vincent Degenhart, Dewi Timman, Arjen P. de Vries, Faegheh Hasibi, Mohanna Hoveyda

TabEmbed: Benchmarking and Learning Generalist Embeddings for Tabular Understanding

AAnt Group

蚂蚁集团团队工作。针对「表格数据缺乏统一 embedding」的问题：LLM 方法没有 retrieval-friendly 的向量输出，文本 embedding 模型抓不住表结构与数值语义。先建 TabBench 评估表格 embedding 能力，再训 TabEmbed——首个把分类与检索统一到同一向量空间的通才表格 embedding 模型。把多种表格任务统一成 semantic matching 任务，用大规模对比学习配合 positive-aware hard negative mining 学结构与数值语义。TabBench 上拿到 SOTA。

INSIGHT工业团队把「分类、检索、表语义」统一到一个 embedding 空间的尝试，对搜索召回侧很有启发：业务里 UGC 帖子也常带结构化字段（标签、价格、地区、评分），把结构化与非结构化字段统一进同一向量空间能简化召回链路。可借鉴的两个具体工程点：(1) 把多任务统一为 semantic matching 形式做对比学习；(2) positive-aware hard negative mining——既保留困难负例又避免假负例污染，对短文本社区搜索的负采样策略尤其值得复用。

Caesar: Deep Agentic Web Exploration for Creative Answer Synthesis

Caesar 把 agent web 搜索从「flat document sequence」升级为「动态构建知识图」：探索阶段用上下文感知策略最大化网页拓扑信息覆盖率，合成阶段用对抗性精炼主动寻找新颖、非显然的关联，避免现有 agent 容易产出衍生式 summary 的问题。整体架构强调「associative synthesis」——把检索到的零碎事实显式建图后再做新洞察生成。

INSIGHT对社区搜索做「探索式问答/聚合答案」类场景（如热搜聚合、专题生成）有借鉴价值：用动态知识图作为 agent 多跳检索 scaffold，而非 flat 文档列表，可显著降低生成内容同质化。但当前形态偏研究原型——工业落地需要解决知识图构建延迟与 deduplication 成本。短期可借鉴的设计思路是把「文档关联结构」显式建模为 agent 的 retrieval state，而非寄希望于 LLM 上下文窗口自动发现。

Jason Liang, Elliot Meyerson, Risto Miikkulainen
