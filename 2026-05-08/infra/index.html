Telegraph English: Semantic Prompt Compression via Structured Symbolic Rewriting

本文提出 Telegraph English (TE)，一种语义级 prompt 压缩协议：将自然语言重写为符号丰富、形式化结构的电报式方言。与 LLMLingua-2 等基于分类器按固定比率删词的方法不同，TE 把输入分解为原子事实行，并用约 40 个逻辑/关系符号替换冗长短语，让压缩比根据信息密度自适应。在 LongBench-v2 的 4081 个 QA 上跨 5 个 OpenAI 模型评估：约 50% token 削减下，GPT-4.1 关键事实准确率仍保 99.1%，超过相同压缩比的 LLMLingua-2。线结构使压缩与语义切片合一，输出天然就是可寻址的语义索引。

KEY INSIGHT · 对业务意味着什么对生产侧 LLM 检索/排序：TE 把 prompt 压缩与 chunk 索引统一为一个操作——每行一个事实即一个可独立检索的语义单元，对 RAG/长上下文搜索极有价值，可同时降低输入 token 成本与召回粒度。语义重写 vs 删词的对比也提示我们：在社区搜索 LLM 化时，与其训分类器删停用词，不如先建结构化 fact 重写器，把帖子/问答压成符号化要点流，再用同一份压缩去喂下游召回与排序。

The First Token Knows: Single-Decode Confidence for Hallucination Detection

Self-consistency 通过对同一问题多次采样并比较一致性来检测幻觉，但需要重复解码且对词面变化敏感；语义自一致性虽用 NLI 聚类提升鲁棒性却额外引入推理开销。本文提出 phi_first：取单次贪心解码下首个内容 token 的 top-K logits 归一化熵作为置信度信号。在 3 个 7-8B 指令模型 ×2 个闭卷短答 QA benchmark 上，phi_first 平均 AUROC 0.820，优于语义自一致 0.793 和表面自一致 0.791，并且与语义自一致中度到强相关，二者结合可进一步提升 AUROC。

INSIGHT第一个内容 token 的 logits 熵就足以指示幻觉风险——这意味着我们能用单次贪心解码把幻觉检测的成本从 N 次采样降到 1 次，几乎零额外延迟。对 LLM 在搜索/问答的部署：可在 ranking/answer-generation 链路中实时把 phi_first 作为可信度信号（例：触发 fallback、人工审核或抑制低置信结果），既不破坏 latency SLO，又比语义采样集成便宜一个数量级。线上 A/B 落地门槛极低。

NVIDIA: Real-Time Performance Monitoring and Faster Debugging with NCCL Inspector and Prometheus

NVIDIA

NVIDIA 介绍 NCCL Inspector：一个把 NCCL 集合通信库内部指标导出到 Prometheus、并以 Grafana 面板做实时可视化的官方工具。聚焦分布式深度学习中常见的 "训练突然变慢" 问题，提供按 rank/通信组的 latency、bandwidth、operation kind 分布等运行时遥测，并能定位掉队 rank、bandwidth 抖动、stragglers 与异常 NCCL 调用。文章给出从最小例子到生产级 K8s 多节点训练的接入方法。

INSIGHT对要把 LLM/embedding 模型大规模训练 + 推理一体化的搜推平台：通信往往是训练时序的真正瓶颈，但缺乏 SRE 友好的可观测性。NCCL Inspector 把训练域指标完整接入业界最常用的 Prometheus/Grafana 工具链，可作为 "分布式训练的 APM"——把 stragglers、AllReduce p99、bandwidth 抖动变成 SLO 看板，方便算法/平台同学共建。落地 ROI 高、零代码侵入，是搜推训练平台值得马上跟进的基础设施件。

Gradients with Respect to Semantics Preserving Embeddings Tell the Uncertainty of Large Language Models

HIT

现有 LLM 自由生成的不确定性估计 (UQ) 普遍依赖多次采样，开销大且方差高。本文提出 SemGrad：首个面向自由生成的、采样无关 (sampling-free) 的梯度型 UQ 方法。区别于以往面向分类、在参数空间求梯度的做法，SemGrad 在语义空间取梯度——核心直觉是 "自信的模型在语义等价输入扰动下应保持稳定输出分布"。论文提出 Semantic Preservation Score (SPS) 用于挑选最能表示语义的 embedding 维度，再以这些 embedding 为基进行梯度敏感度分析，相对采样基线在多个开放问答基准上达到或超越 SOTA，且推理开销显著更低。

INSIGHT对要把 LLM 接入到搜索结果摘要/问答场景的团队：采样型 UQ（self-consistency / SE）虽然好用但成本高，难以放进低延迟链路。SemGrad 把 "语义稳定性" 重新表述为 embedding 空间梯度，等价于一次前向 + 一次反向，可在线服务里直接计算并作为可信度门槛。和上一篇 phi_first 思路互补：一个看 logits 熵，一个看语义梯度，两者都属于 "无采样可信度" 这条对生产部署极友好的路线，值得在 LLM-as-Search 中并行评测。

Mingda Li, Rundong Lv, Xinyu Li, Weinan Zhang, Ting Liu

Paraphrase-Induced Output-Mode Collapse: When LLMs Break Character Under Semantically Equivalent Inputs

本文系统性研究 LLM 的 "输出模式坍缩" 现象：当用户用语义等价的不同表达重写请求时，模型是否仍按原始任务期望的格式作答？作者构建了 150 个查询的评测集，对 5 个 2025 年代主流紧凑型 LLM 在 temperature=0 下做对照实验，发现即便温度归零、语义不变，输出 schema/格式仍频繁漂移。文章给出按 paraphrase 类型与任务类型的细粒度故障分布，并指出现有 instruction-following 评估忽略了此类语义鲁棒性维度。

INSIGHT对线上 LLM 搜索/排序服务：用户 query 千差万别但语义高度等价，本文表明哪怕 T=0 输出也会 "破格"——这意味着当 LLM 被用作结构化字段抽取器（query rewrite、cat tag、ranker explanation）时，下游契约容易破裂。建议把 paraphrase robustness 作为正式上线门槛，加 schema-validation + 结构化解码（JSON mode/工具调用）双保险，并把 paraphrase 故障率纳入回归基线。这类 "语义等价但表面不同" 的 query 在社区搜索极常见，本文给出了一个可马上落地的回归方案。

Aofan Liu, Jingxiang Meng

Lightning Unified Video Editing via In-Context Sparse Attention

ICL 范式视频编辑的二次注意力开销是关键瓶颈。本文提出 In-Context Sparse Attention (ISA)：基于 "context token 显著性远低于 source token" 与 "query 锐度与近似误差相关" 两点观察，先做 pre-selection 剪掉冗余 context，再用 dynamic query grouping 把高误差 query 路由到 full attention、低误差 query 走 0 阶 Taylor 稀疏注意力。配套构建 1.7M 高质量视频编辑数据集，训出 LIVEditor 模型，在保持几乎无损质量的同时显著降低延迟。

INSIGHTISA 的两个工程意义对推理基础设施同行很重要：(1) Query 锐度作为路由指标——把决策从 "全注意 vs 全稀疏" 升级为 "按 query 难度做混合"，是 attention 加速领域很值得借鉴的思路，可移植到长 context LLM 推理（例如长 query 召回扩展、长文档 ranker）；(2) 0 阶 Taylor 稀疏注意作为 cheap path 也提示我们 attention 加速器的近似函数库还远未饱和。建议关注 ISA 的开源实现，评估能否在我们的多模态搜索 ranker 上做注意力代价压缩。

Shitong Shao, Zikai Zhou, Haopeng Li, Yingwei Song, Wenliang Zhong

PhysForge: Generating Physics-Grounded 3D Assets for Interactive Virtual World

PhysForge 提出物理可交互 3D 资产合成的两阶段解耦框架：(1) VLM 充当 "物理建筑师"，规划 "分层物理蓝图"，定义材料、功能与运动学约束；(2) 物理感知 diffusion 模型通过 KineVoxel Injection (KVI) 同时合成高保真几何与精确运动学参数。配套发布 PhysDB——含 15 万条带四级物理标注的资产数据集。实验显示生成资产对 simulation 即用，在交互保真度与功能合理性上显著超越仅几何方法。

INSIGHT对搜推基础设施的启示在于 "VLM 规划 + diffusion 实体生成" 这条 pipeline 范式：把 "功能/约束" 与 "几何/参数" 解耦，让大模型先做 schema/约束规划，再交给小专家模型落地。该模式可直接复用到 LLM-driven 个性化内容生成（例如 query→搜索结果摘要、query→交互式答案）：先让 LLM 生成结构化蓝图（字段、可点击模块、安全约束），再让小模型做高分辨率渲染。其三亿规模数据 + 四级标注的发布也提示物理交互生态正快速成型，值得作为 multimodal infra 的长尾观察。

Yunhan Yang, Chunshi Wang, Junliang Ye, Yang Li, Zanxin Chen

zkGPT: An Efficient Non-interactive Zero-knowledge Proof Framework for LLM Inference

HKUST

服务方可能用更小的模型替代付费的大模型来欺骗用户，零知识证明 (ZKP) 可以让服务方在不暴露模型参数的前提下证明 LLM 推理结果的正确性。zkGPT 针对 LLM 中线性/非线性层提出新的高效证明方法，量级降低计算开销；通过 "约束融合" 削减非线性层证明开销，"电路压缩" 提升并行度。在 GPT-2 上实现并优化，证明一次完整 GPT-2 推理只需 <25 秒，相对 USENIX'24 Hao 等人和 EuroSys'24 ZKML 分别达到 ~279× 与 ~185× 加速。USENIX Security 2025 录用。

INSIGHT对 LLM 服务化基础设施而言，可验证推理 (verifiable inference) 是个长期被忽视的维度，但在 LLM-as-a-Service 商业化、合规与第三方审计场景下会变得越来越重要：客户希望验证 "我付的是 GPT-4 而不是 GPT-3.5-turbo"，监管希望验证 "内容审核确实跑了那个声明的模型"。zkGPT 把这条路径的算力成本压到 GPT-2 量级 25 秒，仍不能直接服务大模型，但 279× 的加速曲线非常陡峭，提示 1-2 年内可能会与 TEE 一起进入主流推理栈。建议把 verifiable LLM inference 列入合规架构 roadmap 的观察项。

Wenjie Qu, Yijun Sun, Xuanming Liu, Tao Lu, Yanpei Guo et al.

Stream-T1: Test-Time Scaling for Streaming Video Generation

Test-Time Scaling (TTS) 是无需重训增强视频生成的一条诱人路径，但 diffusion 视频生成的 candidate exploration 成本高、缺乏时间维指导。本文把视角转到 streaming 视频生成，发现其 chunk 级合成 + 少量 denoising step 天然契合 TTS。Stream-T1 由三个组件构成：(1) Stream-Scaled Noise Propagation，借助历史已验证的高质量 chunk 噪声去精炼当前 chunk 的初始噪声，建立时间依赖；(2) … (3) … 在公开 benchmark 上以更低算力达到或超过非 streaming TTS 基线。

INSIGHT对推理基础设施研究：Stream-T1 是把 "模型架构特性 (streaming, chunk decode)" 与 "推理时计算重分配 (TTS)" 共同优化的一个范例。其方法论——把生成轨迹按时间切片、用历史已 verified 的高质量结果做下一段的 conditioning——对 LLM 长生成 (e.g. agent 长链路推理、reranker 长解释生成) 也有借鉴价值：与其单纯加 sampling/beam，不如把过去 chunk 的 verification 信号沉淀回噪声/状态。结合上文 phi_first，可设计 "streaming + per-chunk confidence + selective regeneration" 的低成本 TTS 框架。

D-OPSD: On-Policy Self-Distillation for Continuously Tuning Step-Distilled Diffusion Models

高性能图像生成正从多步 diffusion 转向 few-step 模型 (Z-Image-Turbo, FLUX.2-klein 等)，但常规监督微调会破坏其少步推理能力。D-OPSD 提出 on-policy self-distillation 训练范式：利用现代 diffusion 中 LLM/VLM encoder 自带的 in-context 能力，让模型同时充当 teacher 与 student——student 仅以 text feature 为条件，teacher 则获得更丰富的 context；通过同一权重在不同 context 下的对比实现 on-policy 自蒸馏，从而在持续 SFT 中保留 few-step 推理速度。在多种 benchmark 上质量与速度均不退化。

INSIGHT对 "压缩后再继续微调" 这一普遍痛点提供了优雅解：先把模型蒸到 few-step / 小规模，再持续 fine-tune 时通常会牺牲压缩收益；D-OPSD 把同一权重在 "富 context (teacher)" 与 "贫 context (student)" 下做 self-distill，给出了一种保持原推理速度的持续学习范式。这一思路可直接迁移到搜推领域的 distill-encoder 与 distill-LLM：例如线上用 1-step embedding 模型，每周新业务数据持续 fine-tune 时若用 D-OPSD 风格的 "context 不对称 self-distill"，理论上能保留压缩后的低延迟特征。值得复现验证。

Dengyang Jiang, Xin Jin, Dongyang Liu, Zanyi Wang, Mingzhe Zheng
