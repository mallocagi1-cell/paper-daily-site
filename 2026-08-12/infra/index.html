SuperLocalMemory 4.0: The Governed Memory Operating System for AI Agents

SuperLocalMemory 4.0 将密集语义、BM25、时间、Hopfield 关联和扩散激活五路检索通过倒数排名融合，配合双时间召回、个人/共享/全局记忆以及访问控制。其可靠写入链路包含代际隔离、策略注册表、可验证事务和哈希完成清单；11 类故障与机制场景各重复 200 次，2200/2200 次满足设定属性，受控写入额外开销为 p50 1.687 毫秒、p99 2.728 毫秒。

BEAM: Joint Resource–Power Optimization for Energy-Efficient LLM Inference under SLO Constraints

BEAM 针对在线大模型推理中“已经满足 SLO 仍在浪费能耗”的问题，在 vLLM 上联合调节 GPU 频率、chunk size 和 microbatch 数，按请求到达与完成事件动态分配 TTFT/TBT 延迟余量。控制器配套轻量预测模型，单次决策低于 1 毫秒；论文报告端到端 GPU 能耗最高比 vLLM 降低 51%。

INSIGHT搜推系统常把 P95 延迟当作唯一约束，BEAM 提供了把剩余延迟预算转化为能耗收益的可插拔控制层。落地时可先在 vLLM 的离线回放和灰度流量上联合观测频率、批大小、chunk 策略与 TTFT/TBT，确认节能没有侵蚀 CTR 相关的实时特征或长尾请求。

Hyunjae Lee, Sangjin Choi, Seungjae Lim, Youngjin Kwon

Motif 3: Technical Report

Motif 3 是总参数 314B、每 token 激活 13.2B 的 decoder-only MoE；每层包含 384 个路由专家，每次选择 8 个，以稀疏激活控制计算量。模型引入 Grouped Differential Latent Attention，将差分注意力与压缩 KV 表示结合，并配合流形约束超连接、专家专属 PolyNorm 和多 token prediction；预训练语料约 12.5T tokens。

INSIGHT这份技术报告的价值在于把“模型能力”和“推理成本”同时当作架构目标：专家容量可以继续扩展，但激活路径、KV 表示和预测步数必须协同设计。对搜索/推荐基础设施而言，值得拆解其稀疏路由与 KV 压缩对显存、通信和 batch 调度的影响，再决定是否适配现有 serving runtime；报告未给出足够的业务线上指标。

Junghwan Lim, Joon Son Chung, Sungmin Lee, Wai Ting Cheung, Gihun Cho

NVIDIA JetPack 7.2.1 Adds Agentic Video Skills and T3000 Emulation

NVIDIA

NVIDIA JetPack 7.2.1 面向 Jetson 生态更新 Agentic Video Skills，并加入 T3000 仿真能力，覆盖机器人、智能视频分析、工业自动化和医疗等视频数据路径。作为开发者平台更新，它更关注端侧运行时与硬件仿真入口，而不是提出新的模型结构；当前候选信息确认了版本号和应用范围，但未提供可核验的延迟或吞吐数字。

INSIGHT对需要在社区内容流或边缘设备上处理视频的团队，端侧工具链和仿真能力能提前暴露算力、编解码、内存和模型部署问题。建议先用 T3000 仿真复现摄取—编码—推理—检索链路，再以真实 Jetson 设备测量 P95 延迟、功耗和升级回滚，避免把开发机结果直接外推到线上。

How Much Does It Cost to Answer My Question? Benchmarking Cloud VLM-based VQA Systems

VQABench 把云端 VLM 的客户端输入预处理设为可控变量，评估 12 种预处理方法、3 个 VQA 数据集和 3 家供应商的 4 个商业 VLM，共完成 95,168 次 API 调用。结果显示预处理并非普适增益：效果取决于目标模型、API 范式、token 计费规则和任务定义，错误策略可能同时增加成本或延迟并降低准确率。

INSIGHT当搜索系统把图片、视频或多模态文档送入云端模型时，输入裁剪、压缩与重采样应和模型质量一起做成本—延迟—效果评测。可借鉴其“多预处理 × 多模型 × 多任务”的矩阵设计，建立自己的 token 账单和 P95 监控；不要只在单一模型、单一离线数据集上选择预处理策略。

Henri Vanhuynegem, Weitao Xu, Yiran Shen, Guohao Lan

A decade of mathematical certainty: Reflections on the Automated Reasoning Group

Amazon

Amazon Science 回顾 Automated Reasoning Group 十年研究如何进入生产服务，重点是用数学逻辑支撑面向数百万客户工作负载的可靠性与安全性。它不是一篇给出单一模型指标的论文，而是一条工业实践信号：当 AI 基础设施承担关键业务时，形式化约束、可证明属性和服务级治理需要与模型推理共同设计。

INSIGHT社区搜索的索引、权限、删除和内容安全链路同样适合引入可验证不变量，例如文档版本、访问范围和引用来源必须在流水线中保持一致。实践上可以从小范围策略验证、属性测试和审计日志开始，把“模型大致正确”逐步升级为“关键系统状态可证明、可追责”。

HaloMark: A Spectral Threshold for Embedding-Vector Watermarking under C2PA

HaloMark 针对嵌入向量经过量化、投影或微调后无法稳定哈希的问题，将正交旋转、公开白化、输入相关 LSH commitment 和逐向量 nonce 绑定到 C2PA sidecar。实验覆盖 8 个基线、10 类自适应攻击和 11 个编码器；有效秩阈值约为 0.19 时 AUROC 至少 0.98，Qdrant admission filter 的验证耗时为 284 微秒、每向量额外 24 字节。

INSIGHT向量库正在成为 UGC 搜索和 RAG 的核心资产，来源证明不能只保护原始图片或文本。HaloMark 的工程启示是把签名元数据放在索引准入层，并将量化与投影后的验证延迟纳入 SLA；但部署前仍需在自己的 embedding 模型、增量更新和跨版本迁移上验证阈值稳定性。

Tarun Sharma

Controlled Memory Interference in Continual LLM Agents

Controlled Memory Interference 提出 CMI 诊断与数据生成框架，专门研究持续学习 Agent 的记忆在状态、时间有效性和更新权限不同的情况下如何互相干扰。结果表明，词法检索与稠密检索存在不同干扰路径；投毒行为对更新权限线索比对新旧时间更敏感，针对性训练样例能改善有效更新与干扰记忆的区分。

INSIGHT对带用户画像、会话记忆或长期反馈的搜索系统，新增内容不应仅凭相似度和时间戳覆盖旧记忆。可以把 CMI 的干扰关系转成回归测试：分别检查同义冲突、过期事实、低权限写入和词法/向量双通路，确保记忆更新不会在提升召回的同时破坏稳定性。

Ao Ding, Hongzong LI, Shiqin Tang, Li Zhang, Liang Chen, Xuyang Chen, Zi Liang

Macaron-V1: Towards Open Continual Learning with Self-Improvement and Mixture-of-LoRA

MMind Lab

Macaron-V1 将持续学习建模为“版本化模型—harness”递归改进，并用 Mixture-of-LoRA 让冻结的基础模型按每轮请求选择专长适配器。旗舰 Venti 使用 744B GLM-5.2 基座配 4 个 LoRA，面向本地部署的 Tall 版本基于 50B Qwen3.6；报告将模型、评测契约、经验回放和运行基础设施放在同一闭环中。

INSIGHT这类架构适合把搜索 query 理解、内容安全、代码工具等能力拆成可回滚的专家适配器，降低频繁全量微调的成本。落地时要把 adapter 路由、版本兼容、灰度指标和失败回退纳入 serving 控制面；当前报告更像系统方案，缺少可直接迁移到社区搜索的线上 A/B 证据。

RynnValue: Scaling Robotic Value Foundation Models with Temporal Distance

RynnValue 用从时间戳直接推导的 temporal distance（观测到语言目标的有向 cost-to-go）替代偏好或进度标注，构建可扩展的机器人 value foundation model。该方案已覆盖超过 7,000 小时、约 300 万段 instruction-conditioned clips，并结合随机时间采样、时间顺序打乱和 value-isolation attention，减少模型利用数据捷径。

INSIGHT对搜索/推荐基建而言，最可迁移的不是机器人任务本身，而是用低成本、可自动生成的时间关系标签扩充长尾训练数据。若要用于用户行为或内容生命周期建模，可以先验证“距离目标事件”的弱监督是否稳定，再通过时间切分和防泄漏采样避免把未来行为带入训练特征。

Dongchi Huang, Hongyin Zhang, Bohan Hou, Siteng Huang, Zhian Su
