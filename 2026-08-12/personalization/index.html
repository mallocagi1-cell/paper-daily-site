MetaStrategy: Generative Ranking with Executable LLM Strategies

MetaStrategy 不直接生成物品序列，而是让 LLM 根据请求上下文输出受约束的 JSON 排序策略，控制 CTR/CVR/GMV 权重、内容偏好、体验约束和位置规则；验证器与编译器把策略隔离接入现有重排链，LLM 推理放在近线。淘宝“猜你喜欢”七日 A/B 中，点击 PV 提升 2.11%、详情页 PV 提升 3.12%、交易额提升 2.83%，在线响应时间无可观测增加。

PushDualGen: Enabling LLMs to Generate Semantic IDs with Interpretable Copy for Industrial Push Recommendation

Kuaishou📖 深度解读 · 9 分钟 →

针对推送推荐中长行为序列难压缩、生成式模型难解释且在线成本高的问题，PushDualGen 用并行语义 ID 压缩历史，先生成 SID，再按需复制文本解释，并把 Top-20 SID 与用户特征融合做 ANN 召回。模型以约 0.72B token 做 SID 适配、每日增量训练约 3.6B token；在 1.5 亿用户、14 天 A/B 中，有效播放率从 64.46% 升至 69.94%（+8.50%），不喜欢率下降 37.70%。

INSIGHT它把可解释性放在可跳过的复制头，把主路径留给轻量 SID 生成，兼顾推荐质量、吞吐和审计。实现上可先用 M=8、K=512 的离散语义码压缩长历史，再将 Top-N 生成结果回灌用户向量；论文的约 100K QPS 部署说明这种“生成偏好、向量召回”的混合架构比同步 CoT 更适合线上。

IntHQ: Task-Interactive Hierarchical Query on Dual-Stream Representations for Generative Recommendation

AlibabaAAmap📖 深度解读 · 10 分钟 →

IntHQ 针对多任务推荐中共享表示造成的 source、relation、hierarchical 三类信息坍缩，设计双流解耦、任务交互建模和分层查询：任务 token 从第一层注入，跨任务注意力动态建依赖，再按任务从不同深度读取表示。在 41 亿交互、1.63 亿用户、730 万 POI 的 IntTravel 上全面优于基线；高德线上服务数亿用户，平均延迟控制在 40ms 内，UVCTR 相对提升 1.60%。

INSIGHT多目标推荐不应只在共享 encoder 后挂多个 head；任务信号需要早注入、独立参数空间和可变深度读取。可将 CTR、停留、转化等任务 token 化，在浅层保留即时意图、深层保留长期偏好，并用任务间因果可见性避免标签泄漏；线上应预计算用户序列，把请求路径留给 GPU 打分和 ANN。

DREAM Technical Report

AlibabaTaobaoTmall

DREAM 在检索、排序、重排级联链路之上增加感知式、可编排且可审计的策略层：Intent Engine 把端上信号归纳为 L0/L1/L2 意图，Meta Engine 用 M1→M2→M3 规划并翻译参数，边云触发链将上报量压到约 8.7%。淘宝首页大规模 A/B 中，仅控制重排就让 IPV/Core IPV/GMV 提升 2.06%/2.39%/0.88%，扩展到精排后提升 2.71%/3.06%/1.31%。

INSIGHT它的关键不是让 Agent 替换推荐模型，而是让 Agent 只调有限的 CTR、IPV、CVR、GMV 权重和品类配额，并通过 schema、白名单、范围校验和默认回退守住生产边界。对社区推荐可先在 replay 中学习会话意图到重排参数的映射，再用差异触发减少调用；任何策略失败都应局部回退，不能污染全局配置。

TSPORec: Token Selection via Preference Optimization for LLM-Based Sequential Recommendation

TSPORec 针对 LLM 序列推荐推理成本高的问题，不再只截取物品描述开头的少量 token，而是在完整文本中选择对用户偏好最有信息量的 token，并通过偏好优化训练选择器。方法的目标是保留长描述里的关键属性，同时减少输入长度和无效计算；论文围绕 LLM 序列推荐的候选 token 选择、偏好对齐与效率权衡进行实验比较。

INSIGHT长文本推荐的压缩应由用户目标驱动，而不是固定保留前缀；品牌、规格、场景词往往出现在描述中后段。落地时可先离线蒸馏 token 重要性，再把选择器放在召回后的精排阶段，并同时监控 HR@K、输入 token 数、P99 延迟和缓存命中，避免“省 token”却损失冷门物品语义。

Give the Long-tail More SPACE: Promoting Provider Fairness in Next POI Recommendation

Southeast UniversityHong Kong Baptist University

SPACE 将 POI 推荐中的长尾曝光定义为同时受用户可执行距离和 POI 供给约束的公平问题，依次使用社区推断、非平衡最优传输配额分配和约束引导的潜空间扩散生成虚拟用户。在 NYC、TKY、CA 三个数据集上，它接入多种骨干后普遍提高公平性；例如 CA 上 GETNext 的 HR@10 从 0.3613 升至 0.6059，论文报告准确性提升 54.85%，长尾覆盖也同步改善。

INSIGHT多目标推荐的公平约束不能脱离供给和用户行动成本，否则只是把曝光搬给不可到达的内容。可把社区画像、库存/供给配额和虚拟用户生成作为重排前的约束层，并用 LTC、CE@K、GINI 与 nDCG 联合监控；SPACE 的消融说明社区先验、物理锚点和生成补偿缺一都会伤害效果。

Structure-Preserving Projection for Mitigating Modality Bias in LLM-Based Sequential Recommendation

National Taiwan University

论文发现把协同嵌入直接投影进 LLM 空间会产生模态偏置：在 MovieLens 上打乱协同向量，Direct 的 HR@1 几乎不变（0.4531→0.4542）。作者用 MLP 投影器加余弦相似度保持和序列对比保持两项损失，在 LastFM/MovieLens 上 Contrastive-LM 的 HR@1 达到 0.5546/0.4881，优于 LLaRA 的 0.4344/0.4421，并显著提高协同结构利用率。

INSIGHTLLM 推荐的多模态融合不能只看生成 loss；如果协同空间的邻域和正负偏序被投影破坏，文本会掩盖真正的行为信号。工程上可先冻结序列模型预训练投影器，再用几何保持初始化、对比损失微调，并用 embedding shuffle 作为线上前的诊断；不要把更高的空间保真度误当成更高的推荐收益。

Tzu-Wei Chiu, Song-Duo Ma, Hsin-Yu Lin, Pu-Jen Cheng

Don't Scroll Back: Missing-Evidence Memory for Streaming Dialogue Summarization

Don't Scroll Back 研究流式对话摘要中的长历史记忆：当当前窗口缺少解释所需证据时，系统从无界历史中选择性取回缺失信息，而不是把全部上下文重新塞回模型。它把“摘要是否遗漏关键证据”作为记忆触发信号，面向固定上下文预算下的连续交互场景；对推荐而言，这对应保留长期偏好、近期意图和关键负反馈的用户状态。

INSIGHT用户画像存储不应等价于不断追加日志；更实用的是用当前请求诊断缺口，再按证据价值检索历史。可以把点击、停留、跳过和不喜欢等行为先压成可验证记忆，在召回或排序请求触发时只取与当前候选相关的片段，并将记忆命中率、上下文 token、误召回率作为联合指标。

Intent Speaks Louder: Controllable User Simulation Beyond Response Imitation

Intent Speaks Louder 将用户模拟从“复述历史回答”推进到“生成带局部交互意图的多种后续行为”。论文强调同一用户画像和对话上下文可能对应多个合理选择，模拟器应显式控制当前意图，而不是只追求表面语言相似度；该思路可用于推荐策略离线评估、反事实用户轨迹生成和多目标体验测试。

INSIGHT推荐离线评估最怕把单一历史轨迹当成唯一真实偏好；用户模拟器应区分探索、比较、购买、拒绝等状态，并允许同一状态产生多样反馈。工程上可将意图标签接到点击/停留/转化模拟头，按意图分桶评估排序策略，避免平均指标掩盖对冷启动或长尾用户的伤害。

Testing ads in ChatGPT

OpenAI

OpenAI 公布在 ChatGPT 中测试广告的产品实践，强调广告与回答明确区分、回答独立于广告、保护隐私并让用户拥有控制权。虽然文章不是 CTR 模型论文，但它把商业化推荐中的相关性、用户信任、标识和数据边界放在同一上线框架里，适合作为社区内容/广告混排的产品约束参考。

INSIGHT个性化排序不应只优化点击，广告或商业内容必须在策略层显式建模“可识别、可解释、可退出”和回答独立性。对 UGC 搜索推荐，可把商业目标作为受硬约束的候选类型，分开记录自然内容与广告的 CTR/负反馈，并在实验中同时看相关性、投诉率和长期留存。
