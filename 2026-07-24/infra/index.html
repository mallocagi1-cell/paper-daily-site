Akashic: A Low-Overhead LLM Inference Service with MemAttention

面向 Agent 长时会话中历史持续增长、重复 Prefill 成本高的问题，Akashic 用 MemAttention 将上下文切成有界块，并联合优化跨块语义关系与内存放置。四类负载、三种模型规模的实验显示，任务准确率最高提升 10.2 个点，吞吐提升 1.21 倍，可持续请求率提升 1.88 倍。

SLAI T-Rex: Full-Parameter Post-training of the DeepSeek-V4 Family on Ascend SuperPOD

论文给出在昇腾 SuperPOD 上对 DeepSeek-V4 系列进行万亿参数 MoE 全参数后训练的完整实践，优化覆盖模型并行、计算通信编排与底层算子。系统达到 34.22% MFU，较开源基线提升 2.93 倍；配套 1 万条 OR 指令数据后，零样本 Pass@1 达 71.81%。

INSIGHT结果表明，大模型后训练效率往往受通信暴露和算子执行拖累，单纯扩卡并不能线性提速。搜推团队在国产算力上训练大规模排序或生成模型时，可沿“并行策略—通信重叠—热点算子”三层逐级剖析，并把 MFU 与训练稳定性同时设为上线门槛。

Making LLMs faster without sacrificing accuracy

Amazon

Amazon 将隐藏维度、MLP 与注意力参数比及 GQA 纳入 Scaling Law，使模型设计同时预测精度和推理效率。实验发现，同参数量、同精度模型的吞吐可相差 40%；Surefire 架构在 A100、H200 及多种推理框架上保持或超过 LLaMA 3.2 精度，吞吐提高 12%–47%。

INSIGHT模型选型不能只看参数量和离线损失，内部宽深比与注意力配置会直接决定线上吞吐。社区搜索若要自研小型 Query 理解模型，可在固定精度预算下联合搜索隐藏维度、MLP/Attention 比和 GQA 组数，并把每卡 QPS 纳入 Scaling Law 拟合。

Tao Yu, Youngsuk Park

Scaling Laws for Hypernetwork-Based Knowledge Injection in Large Language Models

论文训练超网络为目标 LLM 生成固定 LoRA 适配器，以研究事实知识注入随网络深度、宽度和目标模型规模的变化。作者构建覆盖 39 个领域、数千万多跳问答的 MegaWikiQA，观察到各架构轴均呈可预测的幂律，并且规模增大时 OOD 泛化优于普通 LoRA 或全量微调。

INSIGHT超网络把“每批新知识重新微调”改成“学习生成适配器”，为高频更新的社区知识提供了可扩展路径。落地时应按知识域分别拟合容量曲线，比较适配器生成成本、事实命中率和旧知识遗忘，再决定是否替代周期性 LoRA 训练。

Understanding Inference Scaling for LLMs: Bottlenecks, Trade-offs, and Performance Principles

这项 ISCA 2026 工业研究系统测量 8B–671B 模型在数据、张量和流水线并行下的推理表现。长推理链会把系统推向容量受限区：小模型的数据并行受 KV 碎片拖累，约 32B 后张量并行开始释放内存；405B 稠密模型受带宽限制，而 MoE 受路由和同步限制。

INSIGHT并行策略应由模型结构和输出长度共同决定，不能沿用短回答负载下的固定配置。对搜索问答服务，可按短 Query、长推理和批量离线生成三类流量分别压测 DP/TP 混合度，并把 KV 碎片率、互联带宽和路由等待纳入容量规划。

Moiz Arif, Avinash Maurya, Sudharshan Vazhkudai, Bogdan Nicolae

Solar Open 2 Technical Report

University of Seoul

Solar Open 2 是 250B 总参数、15B 激活参数的开源 MoE，采用每三层线性注意力插入一层 Softmax 注意力的混合栈，实现 100 万 Token 上下文。团队迁移 Solar Open 1 的 56.9 亿参数骨架，将 20T Token 池筛成 10T 高价值混合，并用 12 个领域教师进行在策略蒸馏。

INSIGHT它展示了固定算力预算下的三项可复用策略：保留兼容骨架、按每 Token 价值筛数据、再合并领域专家。社区搜索团队无需照搬 250B 规模，可在中型 MoE 上验证线性/Softmax 混合注意力是否降低长会话成本，并用多教师蒸馏合并搜索、问答和内容理解能力。

Sungrae Park, Sanghoon Kim, Gyoungjin Gim, Jungho Cho, Hyunwoong Ko, Minbyul Jeong, Minjeong Kim 等 53 人

ABot-World-0: Infinite Interactive World Rollout on a Single Desktop GPU

Alibaba

ABot-World-0 将教师强制、ODE 蒸馏和 LongForcing 结合，把双向视频教师压缩为可实时交互的因果学生，并配套低比特 DiT、轻量 VAE、内存感知调度与流式推理。在单张 RTX 5090 上可用约 19 GiB 峰值显存输出 720P、最高 16 FPS 视频，动作到首帧延迟约 1.2 秒。

INSIGHT论文的价值在于把模型蒸馏、低比特执行和运行时调度作为一个整体共同设计，而非事后单点量化。对多模态搜索预览或内容生成服务，可借鉴“离线强教师、在线因果学生”路线，并以峰值显存、首帧延迟和长时漂移共同验收。

Fan Jiang, Zhaoxu Sun, Mengchao Wang, Ziyu Zhu, Chiyu Wang et al.

Make Long-Running NVIDIA TensorRT Engine Builds Observable and Cancelable in Python or C++

NVIDIA

NVIDIA 给出 TensorRT 长时间引擎构建的可观测与可取消实现：通过 IProgressMonitor 的 phase_start、step_complete、phase_finish 三个回调追踪嵌套阶段，并在步骤边界安全终止。示例同时覆盖 Python 与 C++，可把进度流接入终端、IDE、HTTP 服务或 Agent 运行时。

INSIGHT这是容易被忽略但直接影响 GPU 成本和自动化可靠性的工程环节；构建卡死会占用 GPU 小时并阻塞发布流水线。搜推推理平台可将监控器封装进模型编译服务，统一暴露阶段进度、取消信号和超时策略，同时处理多线程回调与取消延迟。

Efficient Chain-of-Modality Reasoning via Progressive Compression for Spoken Language Models

ECoM 用压缩文本同时承担语音生成引导与推理表征，并通过渐进式课程把完整推理链逐步压缩，减少语音模型的中间 Token 开销。在语音数学问答上，它比无显式推理的 CoM 准确率高 21%，比完整推理链方案高 3%，但只使用 40% 的文本 Token。

INSIGHT推理压缩不应直接删减链路，而应在训练期逐步缩短中间表示，让模型学会保留决策所需信息。对语音搜索或多模态 Query 理解，可先以完整文本链作教师，再按阶段压缩，并同时观察准确率、Token 数和端到端时延。

Pengchao Feng, Chao-Hong Tan, Qian Chen, Wen Wang, Xiangang Li, Xie Chen

Towards Efficient Large Language Model Serving: A Survey on System-Aware KV Cache Optimization

这篇 ACL 2026 Findings 综述把 KV Cache 基础设施归纳为时间维的执行与调度、空间维的放置与迁移、结构维的表示与保留三类行为。作者进一步梳理跨行为协同与延迟、吞吐、显存和成本目标的对应关系，为评估单点缓存优化是否引入新瓶颈提供统一框架。

INSIGHTKV 优化的收益取决于调度、存储层级和压缩格式是否协同，单独追求更高压缩率可能换来迁移或解码开销。社区搜索问答服务可用这三个维度盘点现有链路，优先测试对首 Token 延迟、TPOT、缓存命中率和每请求成本都有净收益的组合。

Jiantong Jiang, Peiyu Yang, Rui Zhang, Feng Liu
