Negative Data Mining for Contrastive Learning in Dense Retrieval at IKEA.com.

论文面向 IKEA 加拿大站商品搜索，以层级类目和商品属性构造难负样本，再用 LLM-as-a-judge 为候选商品生成相关性标签，形成 44.8 万条训练三元组。真实用户查询离线实验的平均类目准确率提升 2.6%，但两周线上 A/B 测试的参与度差异不显著（p>0.05）。

Approximate Nearest Neighbor Search for Modern AI: A Projection-Augmented Graph Approach

UUniversity of YamanashiBBITNNagoya UniversityOOsaka UniversityShenzhen University📖 深度解读 · 8 分钟 →

PAG 将随机投影统计检验嵌入图索引，用 PRT、反馈缓冲区和概率边选择减少无效精确距离计算，并同时支持快速建索引、在线插入和大 top-k。六个 384–3072 维现代数据集上，其 QPS–Recall 最多达到 HNSW 的 5 倍，检索规模覆盖 top-10 至 top-1000。

INSIGHT向量检索优化不应只盯单一 QPS，而要同时测建库时间、内存、高维退化、top-k 稳定性与增量更新。社区内容持续新增且召回规模变化大，PAG 的“先用廉价统计检验筛边、必要时才算精确距离”可作为 HNSW 路由层的可落地替换思路。

Kejing Lu, Zhenpeng Pan, Jianbin Qin, Yoshiharu Ishikawa, Chuan Xiao

Rethinking Retrieval-Augmented Generation as a Cooperative Decision-Making Problem

Jilin University

CoRAG 不再把重排器视作生成器的单向上游，而以共享任务奖励联合优化两者，使文档排序和答案生成协同决策。模型仅用约 1 万条 PopQA 训练，在 NQ 上准确率达到 72.4，较 InstructRAG-FT 的 65.7 提升 6.7 点；在 PopQA、TriviaQA 与 2Wiki 上也保持领先。

INSIGHTRAG 的最终目标不是获得唯一“正确”的文档全序，而是让生成器从一组足够好的证据中稳定作答。社区搜索若上线答案摘要或智能问答，可用答案质量与引用正确性反向监督重排；但消融显示生成器贡献更大，需防止联合训练弱化重排器本身的判别压力。

Lichang Song, Ting Long, Yi Chang

Why These Documents? Explainable Generative Retrieval with Hierarchical Category Paths

Yonsei UniversityKorea University

HyPE 让生成式检索先逐级生成语义类目路径，再解码 docid，并以路径感知排序聚合多个主题信号，从而同时给出召回解释。NQ320K 上标题 docid 的 Recall@10 从 78.7 提升至 83.5（+6.1%）；MS MARCO 上多种 docid 的 Recall@10 也获得 1.4%–3.6% 增益。

INSIGHT把“为何召回”变成可生成的层级路径，可为黑盒式 docid 解码增加可审计中间状态，也能把社区话题树和内容类目直接转为排序信号。实践中可先在已有 taxonomy 上验证路径生成与多路径聚合，再观察解释一致性是否能辅助 bad case 定位和运营干预。

Sangam Lee, Ryang Heo, SeongKu Kang, Susik Yoon, Jinyoung Yeo, Dongha Lee

Reinforcement Learning for Large Language Model Selective Evidence Adoption from Contaminated Retrieval Results

ECNUShandong University

论文构建 SelectBench，并用规则奖励或冻结语义裁判配合 DAPO 后训练 Qwen3.5-4B，使模型从混杂误导内容和提示注入的检索结果中选择性采纳证据。325 条测试上严格成功率由 22.46% 升至 26.46%，禁用内容采纳率由 72.62% 降至 68.92%，但校正后统计显著性不足。

INSIGHT搜索增强模型的关键不只是召回正确证据，还要拒绝同一上下文中的错误指令和污染片段。可把“答案正确、证据完整、未采纳禁用内容”组合成硬奖励；不过该研究的注入跟随率未改善，说明上线前仍需独立的检索内容隔离、来源白名单与安全评测。

Yanyu Chen, Yue Li, Yongyi Cui, Dongsheng Shi, Lichang Dai

Do Data Agents Need Semantic Metadata? A Comparative Study in Agentic Data Retrieval

Google

研究以相同 Gemini 2.5 Pro Agent 对比开放网页搜索与含 9000 万条 schema.org 记录的 Google Dataset Search。58 个查询中，结构化 Agent 的机器可读数据比例为 71.4%，高于基线的 48.7%；严格 FAIR 数据精度由 28.0% 升至 46.4%，相对提升 65.7%。

INSIGHTLLM 能扩大探索覆盖，却不能替代结构化元数据解决“最后一公里”的可执行性；结构化检索更适合高精度、低容错任务。社区搜索可将作者、主题、地点、时效和内容类型等字段显式入索引，用结构化过滤保证候选可用，再让 LLM 负责长尾扩展与自然语言解释。

uva-irlab-conv at SemEval-2026 Task 8: Multi-Turn RAG with Learned Sparse Retrieval and Listwise Reranking

University of Amsterdam

该系统把全对话 query 改写、学习型稀疏召回、Qwen3 点式重排和 GPT-4.1 列表式重排串成多轮 RAG 流水线，覆盖金融、云文档、政府和 Wikipedia。最终 nDCG@5 为 0.5475，在 38 个提交中排名第 2；两级重排把 nDCG@1 从 0.4910 提升到 0.5331。

INSIGHT多轮社区搜索要在每一阶段持续携带会话上下文，而非只在生成端拼历史消息。结果表明主要收益来自稀疏召回和第一阶段点式重排，昂贵的列表式 LLM 重排主要改善最顶部结果；可据此把算力集中在 top-20，并为无答案查询增加显式拒答分支。

Simon Lupart, Kidist Mekonnen, Zahra Abbasiantaeb, Mohammad Aliannejadi

CIR at iKAT SCAI 2026: Exploring Clarification Need Prediction in Agentic Conversational Search

TH Köln

CIR 将 query 改写、BM25+monoT5 检索重排、回答生成和澄清需求预测封装为可调用工具，对比 MuSIc 与 Zef-CNP 两种预测器。两条提交的混合主动性约为 3/5；较优 run 的检索工具仅覆盖 41.5% 用户轮次，nDCG@5 最高仅 0.0343，暴露编排失败。

INSIGHTAgent 化并不会自动改善搜索：若编排器跳过召回工具，再好的澄清模型也无法补救相关性。社区搜索助手应把“需要回答时必须检索”写成受约束状态机，并分别监控工具调用率、执行失败率和 passage nDCG；澄清问题应只在意图确实不足时触发。

Nolwenn Bernard, Jüri Keller, Philipp Schaer

Progressive Re-ranking for Multimodal Retrieval-Augmented Generation via Curriculum Learning

TencentUUSTBCAS

论文以 CLIP 粗召回为起点，先做细粒度 section 重排，再用多模态模型复核，并通过课程学习逐步加入视觉或语义相近但会误导答案的难负样本。Enc-VQA 的 Recall@1 从 13.4 提至 43.6，InfoSeek 从 46.7 提至 66.4；零样本 VQA 准确率分别达到 50.32 和 35.07。

INSIGHT多模态 UGC 检索需要将“看起来像”与“能回答 query”分开建模：粗召回保覆盖，section 级交互捕捉局部证据，最后按答案置信度复核。训练时加入相似却错误的图片和文本，可显著提升 top-1；代价是两块 H20 训练和多级推理，需先评估线上延迟。

Zhu Min, Yanchao Hao, Jian Liu, Shizhu He, Xi Chen

Using Hierarchical Controlled Vocabularies to Understand CLIP Retrieval Failures in Historical Photo Collections

TTIBLLeibniz University HannoverMMarburg Universityhessian.AIGGoethe University Frankfurt

研究用 AAT 层级词表拆解三套历史照片库中的 CLIP 失败，将视觉聚类一致性与标签—图像对齐分开测量。563 个术语上的零样本平均 nDCG@10 为 0.114；LoRA 与逐层解冻分别升至 0.252 和 0.259，但主要修复文本对齐，未改善图像簇本身的离散。

INSIGHT统一 nDCG 会掩盖两类根因：内容表征不成簇，或 query 标签落不到已有图像簇。社区图文搜索应先用类内相似度和 query—类中心相似度诊断，再选择对策：前者需要监督式对比学习，后者更适合 query 扩展、同义词映射或轻量领域微调。

Ratan Sebastian, Anett Hoppe, Christoph Rippe, Ralph Ewerth
