1. 问题与动机

电商平台中用户的行为具有跨场景的逻辑一致性：搜索「自行车」-> 领取运动优惠券 -> 逛品牌店铺 -> 浏览 feed -> 购买，这一连串多场景行为构成「全域用户动线」（all-domain user moveline）。传统 CTR 预测方法（DIN、DIEN、SIM 等）聚焦于 item 级交互序列建模，但忽略了场景级行为（搜索行为、领券行为、店铺访问等非 item 级交互）的信号价值。论文指出两个核心挑战：(1) item 和 scene 是异构载体，难以统一表征；(2) 固定长度的动线序列与 item 级行为之间存在时间错位，无法精确匹配哪些场景行为对应了后续的具体购买决策。阿里巴巴淘宝营销团队基于 618 大促数据验证了该思路。

2. 方法详解

AMEN（All-domain Moveline Evolution Network）采用双向对齐架构：

Scene-to-Item 路径：从搜索和店铺访问场景中提取「主动意图序列」（Active Intention Sequence, AISeq），包含这些场景中曝光的具体 item。然后以目标 item 为 query，对 AISeq 应用多头目标注意力（MHTA）：H_ais = MHTA(e_t, E_ais) = concat(head_1,...,head_h)，其中 head_i = W_i^V E_ais Softmax(W_i^Q e_t (W_i^K * E_ais)^T / sqrt(d))。这将场景信号转换为 item 空间的表征。

Item-to-Scene 路径：构造「虚拟场景级目标提示」（virtual scene-level target prompt），以目标 item 为主键结合场景上下文信息。以此为 query，对用户前序动线序列 M 应用场景级 MHTA：G = MHTA(m_t, M)，输出经 Reward Net 生成动线奖励 r。最终预测为 y_hat = sigmoid(y_main + r)，即动线奖励作为偏置加到主 CTR 输出上。

时序顺序配对机制（TSP）：训练阶段的辅助学习机制。对每个样本，找到「差异 item」（diff item）——与目标 item 在不同时间点出现且反馈标签不一致的 item。约束条件：时间间隔 60 秒 ~ 7 天，必须来自同一营销频道。对正负 diff 对应用 BPR 损失。总损失为 L = w1L_CE + w2L_bpr，其中 w1=1.0, w2=0.1。

训练使用 AdaGrad（学习率 0.001，时间衰减），batch size 1024，MHTA 4 个头，基于分布式 TensorFlow 的 CPU 集群。训练数据来自 2024 年 1-6 月淘宝营销频道，包含 1.807 亿用户、2190 万 item、67 亿样本。测试集为 618 大促期间 2320 万用户、770 万 item、6 亿样本。

3. 核心技术贡献

贡献一：从 item 级到动线级的 CTR 建模范式转变。首次将跨场景非 item 级行为系统性纳入 CTR 预测，通过注意力机制实现场景级和 item 级行为空间的双向对齐。

贡献二：双向对齐方法论。Scene-to-Item 路径捕捉「用户在搜索中看了什么类似 item」，Item-to-Scene 路径捕捉「当前动线状态是否支持该 item 的购买」。两条路径互补。

贡献三：TSP 时序配对机制。通过在不同时间点寻找标签不一致的 diff item，有效捕捉动线状态变化对 CTR 的影响。关键发现：diff item 必须限制在同一频道——全局采样（DifGS）导致 AUC 暴跌 0.63%。

贡献四：大规模工业验证。淘宝 618 大促 A/B 测试充分验证商业价值。

AMEN 比 DBA 基线 AUC +0.73pt。消融实验关键发现：Item-to-Scene MHTA 单独贡献 AUC +0.39pt 但 GAUC -0.31pt；加入 TSP 后 GAUC 反弹 +0.36pt；全局采样 DifGS 导致 AUC -0.63pt 和 GAUC -1.47pt（灾难性影响）。

线上 A/B 测试（淘宝 618 大促）：Feed 场景 CTCVR +11.6%（CVR +7.4%），Floor 场景 CTR +20.6%（GMV +20.1%）。线上效果远超离线指标预期。

5. 局限与未来方向

作者明确指出：(1) TSP 限制 diff item 来自同一频道，有效配对覆盖率仅 32%；(2) TSP 仅用于离线训练，线上推理无 diff item 分支，存在训练-推理不一致；(3) 时间约束（60s ~ 7天）排除同 session 内配对。此外，动线建模依赖平台多场景数据采集能力，对单一场景应用价值有限。

6. 工业实践意义

对社区搜索的启示：UGC 社区中用户的典型动线为「搜索 -> 浏览帖子 -> 评论/点赞 -> 继续搜索/刷 feed」。将跨场景信号纳入 CTR 模型可更准确判断搜索意图。

关键工程注意事项：(1) 全域采样是反模式——diff item 必须限制在同一域/场景；(2) 线上线下差距大（CTCVR +11.6% vs AUC +0.73pt），建议优先做线上实验；(3) 部署在 CPU 集群，无需 GPU 推理，适合成本敏感团队。

A/B 关注点：AMEN 在不同场景作用机制不同（Feed 主要提升 CVR，Floor 同时提升 CTR 和 GMV），部署需按场景分开评估。
