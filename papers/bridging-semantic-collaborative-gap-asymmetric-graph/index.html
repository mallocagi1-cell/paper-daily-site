1. 问题与动机

协同过滤/图推荐之所以强，是因为它们利用观测到的用户交互；但这也带来根本冷启动困境：新内容没有任何观看历史。在 Tubi（广告支撑的流媒体，数亿设备、数十万内容）的生产检索系统里，这个困境还被线上服务接口进一步约束——新内容必须"立刻"拿到一个独立 embedding，且设备/内容 embedding 都要能进 ANN 近邻检索，不能靠 query 时遍历图或两两打分。已有做法要么给新内容拼凑 ID 向量、要么靠交互派生子图，都无法满足"零历史也要即时出向量且可 ANN"的工程约束。作者把它形式化成时序二部"设备-内容"图上的归纳式图补全（inductive graph completion）的极端情形：暖内容是有观看边的内容节点，冷内容是无任何观看边的节点；内容编码函数必须对暖、冷内容（含零历史新片）都适用，且只能依赖内容固有特征。

2. 方法详解

Shallow-RHS 是非对称双塔。左塔（设备）用设备特征 + 时序有效的观看历史消息传递编码：初始 h_d^(0)=HeteroTF_D(x_d)（基于 PyTorch Frame 的 FTTransformer），从历史边构造内容→设备消息 m_{d←c,τ}^(ℓ)=ψ^(ℓ)(z_c, γ(TVT_{d,c,τ}), η(t−τ))，其中 γ 编码观看时长信号、η 编码时间衰减，多层置换不变聚合得 z_d(t)=h_d^(L)。右塔（内容）故意对图"浅"：z_c=HeteroTF_C(x_c)，只用内容固有特征，不做设备消息传递、不做内容侧子图、不用 ID embedding、不做邻居聚合、不用任何交互派生表征——这逼着内容编码器把固有特征映射进"协同感知"的 embedding 空间。训练用时序 softmax 链接预测损失：对每个（设备,时间戳）正样本是未来观看内容、负样本是未观看候选，打分用余弦 s(d,c,t)=cos(z_d(t),z_c)、温度 τ_s。训练后对暖内容 embedding 建 ANN 索引；冷内容直接用内容塔产出 embedding，再检索 top-M 暖"代理近邻"S_M(c)=TopM_{w∈warm} cos(z_c,z_w) 做隐式图补全，作为推广/检索的行为代理，且不改观测图。设备冷启动：把暖设备按人口属性（国家/地区、设备类型、平台、账户属性）聚成约 K_D 个 cohort，取 cohort 均值 z_g=(1/|D_g|)Σz_d 给新设备初始化，让刚激活账户首屏即可用 ANN 出结果。

3. 核心技术贡献

（1）"非对称"是核心而非小技巧：只让有交互的设备侧吃图结构、无历史的内容侧被强制学纯特征→协同空间映射，从而绕开"新内容必须即时独立 embedding 且可 ANN"的线上约束。（2）用"代理近邻检索"做隐式图补全：不合成假边，而是在学到的 embedding 空间里检索暖门近邻当桥，可解释、模块化，且推广决策不污染观测交互图。（3）设备冷启动用人口属性 cohort 均值做首触表征，让刚激活的新设备也能首屏出可用推荐。（4）时序监督分离：用一年历史做上下文、只取截止前最后 K 天做监督标签，既防标签泄漏又保留长程行为上下文。

4. 实验结果分析

数据为 Tubi 一年观看日志，365 天回看、最小观看时长 r_min 过滤，训练边 E_train={(d,c,τ,r)|t0−365≤τ≤t0, r≥r_min}，图规模数亿设备节点/数十万内容节点/数十亿时序边。内容特征含 title 文本、类型、genre、语言、年份、时长、分级、演职员、外部评分/票数，以及"基于脚本/元数据的 LLM 语义 embedding"。评测全部用线上 A/B，指标为 TVT（日均观看时长）、Qualified View Days、homepage 5 分钟转化。结果按四阶段渐进上线（Table 1）：V1（GNN+语义替换为 CF-aware embedding）全局 TVT +0.10%、冷标题推广速度 +13%；V2（+推广决策标定）+0.16%；V3（+内容特征补全，特征覆盖较前提升约 10%）+0.42%，是单阶段最大增益；V4（+代理补全与长尾语义增强）+0.17%。设备冷启动 A/B：Qualified view days +0.29%、capped 日 TVT +0.39%、homepage 5 分钟转化 +0.43%。作者承认这四个变体是"连续上线迭代"而非隔离离线消融，但在真实服务条件下提供了对冷启动管线的实用消融——逐级贡献中，特征丰富（genre/预算/票房/LLM embedding 覆盖）贡献最大（约 +0.26 个百分点），明显超过最初"语义→CF 替换"的 +0.10%，表明数据覆盖的边际收益高于架构复杂度。值得注意的是 V4 加入代理补全后整体 TVT 反而从 +0.42% 回落到 +0.17%，提示代理近邻主要利好长尾，对大盘是权衡而非纯增益。

5. 局限与未来方向

作者明确：（1）特征覆盖是关键经验约束——初期 LLM embedding 与外部元数据（评分/票数/预算/票房）覆盖不全，本质是表征质量问题，关键特征缺失则映射可用信息少；（2）为训练可扩展性，每个训练实例只保留最近 K 条内容交互（有界历史采样），可能损失超长程行为；（3）embedding 维度需经验调——10 月实验把输出维度翻倍以容纳更丰富元数据/脚本语义，说明容量规划要迭代；（4）没给非对称架构的表征容量或收敛性理论分析。消融为渐进上线而非隔离组件移除，单组件归因不够干净，跨阶段还混入了特征覆盖变化的影响，难以判定增益究竟来自架构还是数据。

6. 工业实践意义

对内容平台/UGC 社区冷启动有直接借鉴：一是"浅塔强制特征映射"——给无历史的新内容/新作者一侧禁用 ID embedding 与邻居聚合，逼内容编码器学到协同感知表征，避免临时拼凑 ID 向量导致召回塌陷；二是特征覆盖比架构复杂度更值钱——本文最大单阶段收益（+0.42% TVT）来自把特征覆盖提升约 10%，而非换更复杂模型，提示优先补元数据与 LLM 语义；三是代理近邻做隐式补全，比合成假边更可解释、可模块化，且不污染线上交互图，但要注意它主要利好长尾、对大盘是权衡；四是设备/用户冷启动可用人口属性 cohort 均值做首触；五是一年上下文+最后 K 天监督的时序切分可防泄漏。工程上整套建在 Kumo GNN 平台、产出可 ANN 的独立 embedding，符合大规模检索服务约束。社区里"新帖/新问答/新用户"冷启动可直接套这套非对称双塔思路：用户侧用行为图、内容侧只用文本/类目/作者等固有特征，再用代理近邻把新内容挂到行为相近的老内容上做推广，同时用 A/B 而非离线指标验收冷启动收益。
