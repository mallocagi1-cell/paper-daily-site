1. 问题与动机

工业推荐的候选生成通常同时包含直接 U2I 和两跳 U2I2I。后者先从用户历史中挑出少量触发物品，再让多个 I2I 频道扩展候选；因此触发器实际上决定了后续候选空间的上限。现有系统常按触发视频自身的观看、点赞、分享或最近性选 Top-K，也有 PDN 一类学习式方法，但它们存在两个生产失配。第一是归因偏差：触发视频本身受欢迎，不等于它能从下游 I2I 带回用户之后真正消费的内容。第二是频道各自贪心：Swing 协同过滤、Marm 深度匹配、MMU 多模态等频道共享有限配额，却独立争抢同一批高分触发器，造成候选重复和配额浪费。

CAPTS 将问题重新定义为带频道预算的触发器—频道路由：一个触发器的价值由它在某频道带回的物品所产生的未来互动决定，而不是由触发器自身反馈决定。这个切入点建立在 Pinterest Pixie、阿里 Swing、Twitter TwHIN 等 U2I2I 实践上，又补上既有研究主要优化 I2I 模型、很少研究多频道入口协调的空白。对成熟短视频平台而言，召回层的微小增益会作用于海量请求，因此作者强调只替换触发选择而保持索引、I2I 召回器和下游排序不变。

2. 方法详解

框架由离线 Value Attribution Module（VAM）和在线 Channel-Adaptive Trigger Routing（CATR）组成。VAM 对历史请求时刻 t 做时间对齐回放：对每个候选触发器 i 和频道 c，调用当时可用的 I2I 快照得到 Top-50 集合 R(i,c,t)，再与请求后的固定有效观看窗口相交。原始前向奖励是交集中各视频观看时长之和；为处理观看时长长尾，先按频道缩放和截断得到有界强度，再按生产阈值转成频道级二元价值标签。强度不会直接作为主回归目标，而是用于样本重加权和校准，避免连续观看时长的非线性及多任务梯度干扰。为防止离线回放偷看未来索引，系统只查询不晚于请求时刻减约 20 分钟的构件快照。

CATR 用共享编码器融合用户、请求上下文、候选触发器及近期有效观看序列；以触发器表示作为 query 对行为序列做 target attention，形成触发器感知摘要。每个频道有独立价值头，sigmoid 输出基础概率；随后接有界校准器，对概率做幅度受控的修正。训练主项是按 VAM 强度加权的二元交叉熵，并加入强度感知校准损失。第二条支路是 uniqueness head：先计算某触发器在频道 c 的结果中、不被其他频道召回的比例，再阈值化为唯一性监督，以同样的强度权重训练。推理分数是校准价值与唯一性预测的加权和，每个频道按自己的预算取 Top-K。

系统部署分三条路径。离线链路构造 VAM 标签、训练 CATR 并周期同步权重；在线链路只给近期交互轻量打分和路由；nearline 链路在低峰刷新长历史的高价值触发缓存，请求时再与近期触发合并。因此改造局限于触发层，不需要重建 Swing、Marm、MMU 等索引，也不改变精排。离线实验使用 Kwai 生产日志：1,071,280 个用户、27,361,781 个物品、1,230,150,824 次交互、723,971,024 次有效观看；按时间划分训练，最后 100 次有效观看只用于 Recall@K。对比 TagTop、LTV、NIC、Recent、PDN、LIC，三频道配置完全相同。作者未披露优化器、batch size 与硬件，这是复现训练成本时的重要缺口。

3. 核心技术贡献

第一，VAM 把触发价值从 on-trigger feedback 改成 downstream utility。时间对齐 I2I 回放让监督直接回答某触发器在某频道能否带回未来消费内容，同时用约 20 分钟回滚消除索引刷新造成的时间泄漏；这比按最近性或触发视频观看时长更贴近端到端目标。第二，CATR 把多频道选择从多个独立 Top-K 变成联合路由。唯一性头不直接追求列表表面多样性，而是估计每个频道对合并候选集的独有贡献，因此能在共享配额下减少重叠。

第三，论文给出可控的工业接入面：共享编码器配轻量频道头、校准器和近线缓存，已有 I2I 召回与下游排序均保持不变。第四，校准价值和唯一性不是简单等权拼接。消融显示去掉校准器时 Overall R@2000 从 0.1994 降至 0.1977；去掉多样性目标则降到 0.1944。多样性权重从 0 增至 0.4 时 R@2000 从 0.1944 升到 0.1994，但 R@100 从 0.0262 略降到 0.0255，说明大 cutoff 的联合覆盖与小 cutoff 的单频道尖峰之间存在可量化权衡。

频道差异揭示了 VAM 的价值来源。Swing 在 R@100/R@2000 上比最强基线提升 27.73%/14.10%，Marm 提升 11.64%/2.77%，而多模态 MMU 提升 156.25%/84.02%。MMU 绝对召回仍小（R@2000 为 0.0311），但传统直接反馈明显低估了它能捕获的视觉与语义长尾兴趣。唯一性实验中，Swing 的 U@100 从 0.8327 升到 0.8895，Marm 从 0.8299 升到 0.8895，MMU 从 0.9468 升到 0.9595；说明路由确实扩大每条通道的独有贡献。

消融也给出反直觉结果：移除多样性后，Swing R@100 反而由 0.0152 升到 0.0162，Marm 由 0.0163 升到 0.0178，但合并 R@2000 下降 2.5% 左右。单频道局部最优并不等于联合候选最优。未来窗口方面，Swing 与 Marm 在中等窗口达到最好，继续扩到 150 或 200 个有效观看变化很小；MMU 随窗口加长略有改善，暗示不同召回机制的价值兑现速度不同。

线上实验保持四个 I2I 频道、配额和下游排序完全相同，只替换触发策略。DAD +0.115%，全站总时长 +0.713%，设备日均时长 +0.586%，视频总观看时长 +0.506%，设备日均视频观看 +0.395%。四频道总曝光占比从 26.24% 升到 27.55%，有效观看率、长观看率、点赞率平均分别增加 1.83、1.78、0.44 个百分点。效果不是靠让 I2I 粗暴抢曝光：其候选进入下游后质量也同步提高。

5. 局限与未来方向

作者在结论中明确指出当前 formulation 使用固定的频道预算，未来应联合学习或动态调整预算；现有监督只观察固定未来窗口，也应扩展到窗口外的长期互动。实验还表明统一窗口对 MMU 未必最优，说明频道特异的归因跨度值得继续研究。论文没有单独的 Limitations 章节，也未披露训练超参数、模型参数量、线上 P99 延迟和 A/B 流量比例，外部团队难以完整评估成本。

另一个明显边界是 VAM 依赖历史时点的 I2I 构件快照和逐触发、逐频道回放，数据基础设施开销可能很大；没有稳定快照治理的团队难以直接复制。证据来自 Kwai 富交互用户，短历史、新用户与低频社区场景未分组报告。观看时长是主要强度信号，也可能强化沉浸而非满意度；负反馈、安全与创作者公平尚未纳入路由目标。

6. 工业实践意义

社区搜索与推荐最值得复用的是分层改造顺序。第一步先不训练 CATR，只建立时间一致的 trigger→channel→retrieved item→future engagement 归因表，比较最近性、直接互动和下游价值标签的分歧。第二步用共享主干加频道价值头替换各频道独立规则，并保留原策略作回退。第三步再加入唯一性头，用合并候选 Recall、重复率和每频道独有曝光共同调多样性权重，不能只看单频道 Recall。

部署时应复制其离线、在线、近线三分法：近期兴趣在线打分，长历史低频刷新并缓存；严格版本化 I2I 索引，防止标签偷看未来。对于 UGC 社区，频道可对应协同共现、语义 embedding、作者关系和多模态内容，强度信号不应只用停留时长，还应加入收藏、长点击、负反馈和会话成功。线上指标需同时监控总时长、设备均值、活跃、频道曝光与内容多样性。

+0.713% 总时长在成熟召回层具有生产意义，但它来自快手特定流量和四频道配置，不能直接外推。小团队可先以影子回放验证：若去重后联合候选覆盖没有提升，就不应上线复杂路由；若提升集中在大 cutoff，还要确认下游排序能真正消费这些新增候选。CAPTS 最重要的工程结论是，召回器本身不变时，重新定义入口监督和协调配额也能抬高系统上限。
