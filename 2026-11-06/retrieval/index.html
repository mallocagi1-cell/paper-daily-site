RAGCompass: Generalizable Retriever Routing via Reranking

同一个问题交给不同 检索器，返回的段落对最终答案的帮助可能不同。RAGCompass（从各路取回结果中选一组的路由模型）先运行各路检索，再让一个经过训练的 reranker 比较这些结果，选择一组交给大模型作答。在全部测试问题上，答案 F1 比最佳固定 检索器 高 2.28 个百分点。摘要中的相对提升 28% 来自筛选后的问题集合，不能当作全量收益。

CORE: Coarse-to-Fine Search with Context Management for Deep Research

研究 agent 越搜越多，不一定需要把整段材料反复塞进上下文。CORE 先找候选段落，再在段内挑与子问题最相关的短片段；信息不够时，回到已见文档找相关段及其前一段。重复片段只留引用，新片段仍完整展示。在固定语料的 BrowseComp-Plus 对照中，同一 agent 从仅粗检索的62.61%准确率，升至完整方案的80.12%。提升来自检索和上下文管理的组合，不是只靠把上下文裁短。

Hoang Tran Vuong, Ngoc Quan Pham, Hung Bui, Fatih Porikli, Dat Quoc Nguyen

RAG without Forgetting: Continual Query-Infused Key Memory

已录用 ICML 2026

一次成功的查询扩写，能留作下次检索的文档记忆。ERM 给每份文档的每条扩写记分：检索或回答判对后，先筛出加到文档向量后能提高原查询相似度的扩写。对同一文档，把同一查询各扩写的增益做 softmax，用各权重乘对应增益，累加到该文档各条扩写的分数。每批选累计分最高的若干条扩写，作为一组送入编码器，再将所得向量加到文档向量。不训练模型，测试问题也不参与记忆更新；结果不能外推为长期线上无偏差。

Yuntong Hu, Sha Li, Naren Ramakrishnan, Liang Zhao

Reducing Representational Interference in Retrieval Embeddings with Trainable Prefix Tokens

文本压成检索向量时，位置和低信息 token 的影响也可能混进去。这项方法给问题和文档都加可训练的 [DUMP] 前缀，让它们与正文一起参与注意力；编码器仍取 [CLS] 的表示，decoder 取最后 token 的表示，不改检索损失。EuroBERT 在标准检索集合上的平均 NDCG@10 从0.5786升至0.5884。前缀与模型共同微调，推理时也保留；不是随手加几个特殊 token，就能让原模型零训练提分。

Seongtae Hong, Youngjoon Jang, Jungseob Lee, Chanjun Park, Heuiseok Lim

CONFRAG: Confidence-Guided Retrieval-Augmented Generation

已录用 EMNLP 2026

先判断要不要查资料，判断本身也可能增加等待。CONFRAG 先由分类模型识别需要最新信息的问题，直接走 RAG；其余问题把直接答题和 RAG 并行启动。答题模型经过事实问答微调，训练时把答错样本改成表达不确定；上线若没输出不确定，就返回其答案并提前停止 RAG 后续流程，否则等检索答案。这里没有在线核验答案真伪，搜索 API 也已经调用，主要省的是后续抓取、处理和总结。

Yin Huang, Yifan Ethan Xu, Kai Sun, Vera Yan, Alicia Yi Sun

Signed but Steerable: Measuring and Closing the Text-Vector Integrity Gap in Offline Retrieval-Augmented Generation

知识包签名有效，检索仍可能被改过的向量带偏。这项研究把威胁放在持有签名权限的发布方：文本通过审查，配套向量却被定向调整。在 SQuAD 的 BGE-M3 实验中，若存储向量与按文本重算的向量只需余弦相似度达到0.999，相关段落原本排首的问题里，24.6%存在可夺走首位的扰动。这是逐问题选择攻击的暴露度，不是一个坏索引同时劫持全部这些问题；来源签名与文本、向量的一致性需要分开验证。

Georgios Feretzakis, Alexandros Papaspyridis

Axis-LoRA: Probing and Adapting Embedding Models for Personal-Memory Retrieval

个人记忆里，同一件事换了时间、地点或人物，通用向量未必分得清。Axis-LoRA 分别学习时间、空间、实体和事件的适配器，再由问题决定各项相似度的权重，加到冻结模型的原分数上；训练负例只改其中一类信息，逼模型看清差别。各编码器在个人记忆测试上的平均 R@10 提高1.28–1.56个百分点，单项仍有回退；Qwen 的通用检索 NDCG@10 均值也下降0.50点。它是在放大特定记忆线索，不是无代价提升全部检索。

Dohoon Kim, Junho Park, Hyunwoong Bae, Seyoon Kim, Taesup Moon

Test-Time Optimization of Query Embeddings with Ranking Aware Reward Maximization

重排器打过的分，不一定只能用来调整眼前几个候选。TTT-Embed 用这些分数学习任务内共享的偏移向量，让修改后的查询排序接近重排判断；再把偏移加到查询向量上，归一化后重新从全库召回，不改 embedding 模型或文档索引。MTEB 测试中，平均每问题十次文档评分预算下，任务共享方案的 NDCG@10 提高6.36点，同预算直接重排提高3.21点。评分仍有成本，最合适的共享范围也随预算变化。

Tianyu Chen, Jiaxing Wu

ModalSearcher: Weaving Visual Evidence into Autonomous Cross-Modal Deep Search

找答案有时要先找图，再顺着图里的人或物继续查。ModalSearcher 离线造题时，例如把维基词条连到其中提及、可稳定搜到的场景图，再把图中经核实的人或物接回词条。从这些连接里抽取路径，为末端词条或图片写问题，再倒着用前一步的关系描述替换中间实体名，避免直接搜名字就跳过前面的查找。图只用于造数据，线上由 agent 自选文本或图片搜索。同工具环境下，训练后比原始 Qwen3-VL-8B 的平均问答准确率高16.2点。收益属于整套数据与训练方案，不保证每题都只能靠图解答。

QE-RAG: A Robust Retrieval-Augmented Generation Benchmark for Query Entry Errors

已录用 SIGIR 2026

问题输错了，先让大模型润色一遍，未必比直接检索好。QE-RAG 保持答案标注不变，给部分问题注入输入错误，检查检索和生成会在哪一步受影响。它还训练纠错模型：先读带错问题取回的文档，再输出原本正确的问题，用改好的问题重新做 RAG。在40%问题带错的测试中，该方案平均答案 F1 从普通 RAG 的34.39升至37.52，直接提示纠错反而更差。要测的是保住原意，而不只是把句子改顺。

Kepu Zhang, Zhongxiang Sun, Weijie Yu, Xiaoxue Zang, Kai Zheng
