利用多模态大语言模型为新物品生成代理 ID embedding，解决广告和推荐中冷启动 CTR 预估问题。

KEY INSIGHT · 对业务意味着什么通过将 MLLM 生成的内容特征显式对齐到已有 ID embedding 空间，可以在无交互数据的情况下为新物品生成高质量的代理 embedding，实现端到端与排序模型联合优化。这为冷启动场景提供了一个即插即用的工业级解决方案。业务关联 社区搜索中新帖子/问答的冷启动是常见痛点——新内容缺乏交互数据导致 CTR 预估不准。IDProxy 的方法可直接应用于 UGC 内容的冷启动排序，利用多模态特征（文本+图片）生成代理 embedding 来提升新内容的曝光质量。证据 在小红书广告和推荐场景大规模部署验证。代理 embedding 与真实 ID embedding 空间显式对齐，在 CTR 目标下端到端优化，可无缝集成到现有大规模排序流水线中。

Stop Treating Collisions Equally: Qualification-Aware Semantic ID Learning for Recommendation at Industrial Scale

提出资格感知的 Semantic ID 学习框架，区分性处理推荐系统中 token 空间的碰撞问题。

INSIGHTSemantic ID 的碰撞并非都是有害的——有些碰撞反映了语义相似性，应当被保留。QAS-SID 通过资格打分区分「有害碰撞」和「合理碰撞」，从而在工业级规模下显著提升 item 表征质量。这对于 UGC 内容理解和 item embedding 质量改进具有直接参考价值。

业务关联社区搜索中大量 UGC 内容需要高效的 item 表征。Semantic ID 的碰撞问题直接影响排序模型区分相似内容的能力。资格感知学习框架可应用于 UGC 内容的离散化表征，提升检索和排序的区分度。

证据在快手工业级推荐场景部署验证。论文详细对比了有害碰撞与合理碰撞的比例和影响，在大规模在线实验中验证了资格感知策略的效果。

Beyond the Flat Sequence: Hierarchical and Preference-Aware Generative Recommendations

提出 HPGR 框架，在 HSTU 基础上引入层次化 session 建模和偏好感知注意力机制。

INSIGHTHSTU 的「扁平序列」假设忽略了用户行为的内在层次结构（session 粒度）。HPGR 通过两阶段范式注入时间层次（session 感知）和偏好感知信号，既提升了表征质量又降低了计算开销。这为序列建模中 session 粒度的行为理解提供了新思路。

业务关联社区搜索用户的浏览行为天然具有 session 结构（每次搜索 session 内的交互逻辑不同）。HPGR 的层次化建模可帮助更好地理解用户在不同搜索 session 中的意图变化，提升 CTR 预估准确性。

证据在 HSTU 基础架构上验证，dense attention 中的噪声会模糊真实偏好信号。HPGR 通过稀疏化 session 内注意力减少计算开销，同时提升推荐质量。具体实验在多个标准推荐数据集上验证。

MuonRec: Shifting the Optimizer Paradigm Beyond Adam in Scalable Generative Recommendation

将 Muon 优化器引入推荐系统训练，通过正交化动量更新替代 Adam，提升大规模推荐模型训练效率。

INSIGHT推荐系统几乎无一例外地使用 Adam/AdamW，但这并非最优选择。MuonRec 通过 Newton-Schulz 迭代的正交化动量更新，促进更多样的参数更新方向，在多个推荐模型和数据集上一致性地超越 Adam。这是一个即插即用的训练优化方案。

业务关联排序模型训练是搜索推荐系统的核心环节。MuonRec 提供的开源训练方案可直接替换现有 Adam 优化器，有望在不改变模型架构的前提下提升 CTR 模型的训练效果和收敛速度。

证据在多个推荐基准上评估（含 SASRec、HSTU 等架构），MuonRec 一致性优于 Adam/AdamW。提供开源训练配方，跨数据集和模型架构验证了通用性。

CSRv2: Unlocking Ultra-Sparse Embeddings

提出 CSRv2 训练框架，在超稀疏场景下（80%+ 神经元不活跃）大幅提升稀疏 embedding 的表征质量。

INSIGHT密集 embedding 的高维度带来存储和推理成本问题。CSRv2 将密集向量映射为高维 k-sparse 向量，在极端稀疏度下（仅 20% 神经元活跃）仍保持接近密集 embedding 的检索质量。这为推荐/搜索系统的 embedding 层提供了重大的部署效率提升方案。

业务关联UGC 搜索场景中，embedding 的存储和在线推理延迟是关键瓶颈。CSRv2 的超稀疏 embedding 方案可显著降低 embedding 存储和检索开销，在保持排序质量的前提下大幅减少基础设施成本。

证据CSRv2 在超稀疏场景下（80%+ 神经元不活跃）解决了原始 CSR 方法的严重退化问题，在多个检索和分类基准上验证了性能保持能力。

Rejuvenating Cross-Entropy Loss in Knowledge Distillation for Recommender Systems

揭示了推荐系统知识蒸馏中交叉熵损失与 NDCG 的理论联系，提出闭合感知的 CE 损失改进方案。

INSIGHT在子集上做知识蒸馏时，最小化 CE 损失等价于最大化 NDCG 的下界，但前提是子集由学生模型的 top 物品构成（闭合性假设）。传统蒸馏中教师 top-K 采样违反此假设，导致效果退化。改用学生 top-K + 教师概率的方案可显著提升蒸馏效果。

业务关联搜索排序中的知识蒸馏（将大模型蒸馏到在线 serving 的小模型）是常见优化手段。本文的理论指导可直接改进蒸馏策略——使用学生模型的 top-K 而非教师模型的 top-K 做采样，有望提升 CTR 排序模型的蒸馏效果。

证据理论证明 CE 与 NDCG 的下界关系在闭合性假设下成立。在推荐数据集上验证了 student-top-K 采样策略相比 teacher-top-K 的蒸馏效果提升。

MealRec: Multi-granularity Sequential Modeling via Hierarchical Diffusion Models for Micro-Video Recommendation

提出基于层次化扩散模型的多粒度序列建模框架，用于短视频推荐中的用户偏好捕获。

INSIGHT短视频/UGC 推荐中多模态内容噪声和隐式反馈不可靠导致行为与真实兴趣的对应关系弱化。MealRec 通过层次化扩散模型在多粒度上进行去噪和序列建模，有效分离噪声与真实偏好信号。

业务关联UGC 社区中用户对帖子的浏览、点击、收藏等行为也面临隐式反馈噪声问题。MealRec 的多粒度去噪思路可迁移到社区搜索的用户行为序列建模中，提升基于历史行为的个性化排序。

证据在短视频推荐数据集上验证，与传统序列推荐方法（行为增强建模和内容多模态分析）对比，MealRec 在处理偏好稀释和幻觉交互问题上表现更优。

RAIE: Region-Aware Incremental Preference Editing with LoRA for LLM-based Recommendation

提出区域感知的增量偏好编辑方法，通过 LoRA 实现 LLM 推荐系统中用户偏好漂移的高效更新。

INSIGHT用户偏好漂移是推荐系统的常见挑战。全局微调会扰乱无关行为，逐点编辑又无法捕获更广泛的偏好变化。RAIE 通过区域感知策略，在 LoRA 参数空间中定位和编辑特定偏好区域，实现精准且稳定的增量更新。

业务关联社区搜索中用户兴趣会随热点话题变化而漂移。RAIE 的增量编辑思路可用于在不重新训练全模型的情况下快速适应用户偏好变化，提升个性化排序的时效性和稳定性。

证据与全局微调和逐点编辑策略对比，RAIE 在保持已有偏好的同时有效更新目标偏好，解决了重复编辑导致的先前适配干扰问题。在多个推荐基准数据集上验证。

CLEAR: Null-Space Projection for Cross-Modal De-Redundancy in Multimodal Recommendation

利用零空间投影消除多模态推荐中跨模态冗余，释放互补信息的潜力。

INSIGHT现有多模态推荐方法过度强化跨模态一致性，导致模态间共享成分高度重叠（跨模态冗余），反而限制了互补信息的利用。CLEAR 通过零空间投影去除冗余共享成分，保留各模态的独特贡献。

业务关联社区搜索的 UGC 内容天然是多模态的（文本+图片+视频）。CLEAR 的跨模态去冗余方法可提升 UGC 内容的多模态表征质量，避免仅靠强化一致性而忽略了不同模态间互补信息带来的排序增益。

证据在标准多模态推荐数据集上验证，CLEAR 在添加更多模态时一致性地提升了推荐效果，解决了「增加模态不一定提升性能」的反直觉现象。

NextAds: Towards Next-generation Personalized Video Advertising

提出下一代个性化视频广告框架，用生成式 AI 替代传统的检索式广告素材选择。

INSIGHT传统视频广告依赖从预制素材库中检索最优广告，个性化粒度有限且无法实时优化。NextAds 提出用 AI 生成个性化广告素材，并基于用户反馈持续优化，突破了「有限素材库」的瓶颈。这是广告个性化从「选择」到「创造」的范式转变。

业务关联虽然 UGC 搜索场景与视频广告不完全相同，但 NextAds 的核心理念——从检索候选到生成式个性化内容——可启发社区搜索的个性化结果展示和摘要生成，提升用户搜索体验中的个性化程度。

证据论文提出了生成式广告素材的完整框架，包括用户画像建模、素材生成、和在线反馈循环。具体指标数据需参考原文实验部分。
