FrugalRAG: Less is More in RL Finetuning for Multi-Hop Question Answering

用 RL 自适应裁剪检索步数，在仅约 1000 样本上训练即可将多跳 QA 的检索成本砍半且保持准确率。

INSIGHTRL 在多跳 QA 的正确打开方式不是增加推理步数，而是按题目难度自适应减少不必要的检索，实现效率和准确率的最优平衡。

业务关联UGC 搜索中大量简单 query 不需要多步检索，该方法可让搜索 agent 根据查询复杂度动态调整检索深度，降低延迟和成本。

证据在 HotPotQA 上达到 SOTA 效率-准确率权衡，检索成本减少约 50%；在 BrowseCompPlus 上零样本泛化超越 SLM 和其他 baseline。

Abhinav Java, Srivathsan Koundinyan, Nagarajan Natarajan, Amit Sharma

03 4.25

Tiny-Critic RAG: Empowering Agentic Fallback with Parameter-Efficient Small Language Models

用 LoRA 微调的小模型替代大模型做 Agentic RAG 的检索质量路由判断，延迟降低一个数量级。

INSIGHTAgentic RAG 中不需要每次都调用大模型做路由决策；用参数高效的小模型做二分类门控，即可达到 GPT-4o-mini 级别的路由准确率，延迟降低 10 倍。

业务关联UGC 搜索的高并发场景下，用大模型做 RAG 路由成本过高；该方案可低成本部署 agentic fallback 机制，在检索不充分时触发二次检索。

证据在噪声注入数据集上路由准确率与 GPT-4o-mini 相当，延迟降低一个数量级；使用约束解码和 non-thinking 推理模式实现超低延迟。

Yichao Wu, Penghao Liang, Yafei Xiang, Mengwei Yuan, Jianan Liu, Jing Yang, Xianyou Li, Weiran Yan

GraphScout: Empowering Large Language Models with Intrinsic Exploration Ability for Agentic Graph Reasoning

提出以训练为中心的 agentic 图推理框架，让小模型自主与知识图谱交互生成训练数据并内化推理能力。

INSIGHT让 LLM 自主探索知识图谱生成训练样本再 post-train，比依赖人工设计的图推理工具链更灵活、效果更好——4B 小模型可超越 Qwen-Max。

业务关联UGC 搜索中用户查询常涉及实体关系（如人物、话题），该框架可增强搜索系统的知识图谱推理能力，提升实体相关查询的准确性。

证据Qwen3-4B + GraphScout 在 5 个知识图谱领域平均超越 Qwen-Max 16.7%，且推理 token 消耗显著更少；具备跨领域迁移能力。

Yuchen Ying, Weiqi Jiang, Tongya Zheng, Yu Wang, Shunyu Liu, Kaixuan Chen, Mingli Song

Let the Agent Search: Autonomous Exploration Beats Rigid Workflows in Temporal Question Answering

提出 AT2QA——无需训练的自主 agent，在时序知识图谱问答上零样本超越 SOTA 10.7%。

INSIGHT给 LLM 自主决策权（让它自己决定下一步做什么）比精心设计的固定检索流程更有效，即便是在零样本设定下也能大幅超越微调方法。

业务关联UGC 搜索中大量查询含时间约束（如「昨天的热帖」「最近的讨论」），该 agent 方法可直接提升时序敏感查询的检索准确率。

证据在 MultiTQ 上 Hits@1 达 88.7%，比先前 SOTA +10.7%；在多目标查询上 +20.1%，证明 agentic 自主性在复杂时序推理中决定性优于微调。

Xufei Lv, Jiahui Yang, Yifu Gao, Linbo Qiao, Houde Liu

MM-DeepResearch: A Simple and Effective Multimodal Agentic Search Baseline

提出多模态 deep research agent：用超图 QA 生成、工具专家分解-重组、离线搜索引擎实现低成本 agentic RL 训练。

INSIGHT三步法解决 agentic 搜索训练难题：Hyper-Search 生成搜索密集型多模态 QA → DR-TTS 分工具专家优化再重组 → 离线搜索引擎避免 API 成本。

业务关联UGC 平台常含图文混合内容，该方法为构建多模态搜索 agent 提供了低成本训练路径——离线搜索引擎思路可直接复用。

证据在多个多模态搜索基准上取得优异结果；通过离线搜索引擎成功避免了在线 API 调用的高昂成本。

Huanjin Yao, Qixiang Yin, Min Yang, Ziwang Zhao, Yibo Wang, Haotian Luo, Jingyi Zhang, Jiaxing Huang

RLAR: An Agentic Reward System for Multi-task Reinforcement Learning on Large Language Models

让 LLM agent 自主从互联网检索最优奖励模型并通过代码生成合成验证器，实现奖励系统的动态自进化。

INSIGHT将奖励获取转化为「工具合成 + 调用」任务，agent 可自主检索和组装奖励函数，解决静态奖励模型在 RL 迭代中的 OOD 泛化问题。

业务关联搜索排序模型的 RLHF 对齐需要高质量奖励信号；RLAR 的动态奖励合成思路可用于搜索相关性模型的持续优化和自动化奖励设计。

证据在数学、编码、翻译、对话任务上性能提升 10-60 分；在 RewardBench-V2 上显著超越静态 baseline，逼近性能上界。代码已开源。

Andrew Zhuoer Feng, Cunxiang Wang, Bosi Wen, Yidong Wang, Yu Luo, Hongning Wang, Minlie Huang

Expanding LLM Agent Boundaries with Strategy-Guided Exploration

提出 SGE——在语言策略空间而非动作空间做探索，通过混合温度采样和策略反思机制提升 LLM agent 的 RL 效率。

INSIGHTLLM agent 的 RL 探索瓶颈在于动作空间太大；将探索提升到自然语言策略层面，可实现更结构化、多样化的探索，让 agent 学会解决基础模型无法完成的任务。

业务关联搜索场景中 agent 需要在多种检索策略间探索（精确匹配 vs 语义召回 vs 多跳推理），SGE 的策略级探索方法可直接用于优化搜索 agent 的策略选择。

证据在 UI 交互、工具调用、编码、具身 agent 四类环境中一致超越探索导向 RL baseline，同时提升学习效率和最终性能。

Andrew Szot, Michael Kirchhof, Omar Attia, Alexander Toshev

HiMAC: Hierarchical Macro-Micro Learning for Long-Horizon LLM Agents

提出 HiMAC 分层 RL 框架，将 LLM agent 的长周期决策显式分解为宏观规划和微观执行两层。

INSIGHT引入结构化层次比单纯增大模型更关键——无 critic 的分层策略优化 + 规划器-执行器迭代共进化可显著提升 LLM agent 的长周期任务表现。

业务关联复杂搜索任务（如多轮对话搜索、深度研究）本质上是长周期决策问题；HiMAC 的宏观规划 + 微观执行架构可直接用于搜索 agent 的多步规划。

证据在 ALFWorld、WebShop、Sokoban 三个基准上一致超越强 prompting 和 RL baseline，达到 SOTA；样本效率显著提升。

Hongbo Jin, Rongpeng Zhu, Jiayu Ding, Wenhao Zhang, Ge Li

Securing the Floor and Raising the Ceiling: A Merging-based Paradigm for Multi-modal Search Agents

通过跨模态模型融合（无需训练）赋予 VLM 自主搜索能力，并提出 OBM 算法缓解参数干扰。

INSIGHT无需额外多模态训练数据，通过将文本搜索 agent 与 VLM 融合即可组合出多模态搜索能力——OBM 基于显著性的融合策略解决了跨模态参数干扰问题。

业务关联UGC 平台内容含大量图片，该方法提供了低成本构建多模态搜索 agent 的路径——模型融合的思路也可用于将搜索能力注入现有排序模型。

证据在 InfoSeek、MMSearch 等搜索密集型基准上：模型融合零样本即达合理性能底线；OBM 作为热启动策略收敛更快、峰值准确率更高。

Zhixiang Wang, Jingxuan Xu, Dajun Chen, Yunfang Wu, Wei Jiang, Yong Li
