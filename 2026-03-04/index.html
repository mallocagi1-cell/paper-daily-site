SODA: Semantic-Oriented Distributional Alignment for Generative Recommendation

提出分布级监督范式 SODA，用多层 codebook 上的概率分布替代离散码级监督来训练生成式推荐模型。

INSIGHT现有生成式推荐方法依赖离散 code-level 监督导致信息损失且无法端到端优化 tokenizer。SODA 通过负 KL 散度对齐语义丰富的分布来实现端到端可微训练，是 plug-and-play 框架可插入各种生成式推荐骨架。

业务关联SODA 的即插即用特性意味着可以直接应用到社区搜索的生成式排序/召回模型中，提升 UGC 内容推荐的语义对齐质量，改善 nDCG 和 CTR。

证据在 Beauty/Pet/Upwork 3 个数据集上，SODA 对 TIGER 基线 Recall@10 分别提升 +17.5%/+24.2%/+14.3%；对 LETTER 提升 +10.6%/+0.3%/+11.1%；对 ETEGRec 提升 +4.4%/+1.5%/+0.1%。

Fine-grained Semantics Integration for Large Language Model-based Recommendation

提出 TS-Rec 框架，解决 LLM 生成式推荐中语义 ID (SID) 初始化无语义和对齐粒度粗糙两大挑战。

INSIGHTSID token 随机初始化会切断与预训练语言空间的语义关联，而 item-level SFT 忽略了 SID 序列内部 token 的语义。TS-Rec 通过 SA-Init（用关键词均值池化初始化 SID embedding）和 TS-Align（token 级语义对齐）解决这两个问题。

业务关联社区搜索排序模型如果采用 LLM 生成式范式，TS-Rec 的 token 级语义对齐方案可以显著改善 SID 的语义表达质量，提升 UGC 内容的 CTR 预估精度。

证据Amazon Industrial 数据集 HR@5 达 0.1153（比 LC-Rec 提升 +7.17%）；Amazon Office HR@5 0.1307（+4.27%）；集成 RL 后 NDCG@3 提升 +15.68%、NDCG@5 提升 +15.08%；SID 理解准确率提升 +120.97%。

Trinity: A Scenario-Aware Recommendation Framework for Large-Scale Cold-Start Users

微软提出 Trinity 框架，通过特征工程、模型架构和稳定更新三位一体策略解决新场景大规模冷启动问题。

INSIGHT冷启动问题的有效解决不能仅靠模型架构创新，需要特征工程（跨场景信息提取）、模型架构（预测有效性和准确性保障）和稳定模型更新三者协同。这是工业级推荐系统的系统性方法论。

业务关联社区搜索产品迭代（如新社区上线替代旧产品）会面临用户行为稀疏和模型不稳定问题，Trinity 的跨场景迁移框架可直接参考，加速新场景搜索模型的冷启动。

证据在微软十亿级用户产品迁移场景中验证，离线和在线实验均显示显著提升（WWW 2026 接收论文）。

Unleashing the Native Recommendation Potential: LLM-Based Generative Recommendation via Structured Term Identifiers

📖 深度解读 · 11 分钟 →

提出 Term IDs (TIDs) 作为结构化文本关键词型 item 标识符，配合 GRLM 框架实现 LLM 原生生成式推荐。

INSIGHTSemantic ID 虽然压缩了 item 表示但丢失了语义可理解性。Term IDs 用语义丰富且标准化的文本关键词作为标识符，使 LLM 可以直接理解 item 语义，通过上下文感知生成和指令微调实现更强的泛化能力。

业务关联社区搜索中 UGC 内容（帖子、问答）天然具有丰富的文本描述，Term ID 方案比 Semantic ID 更适合此类场景——可以用标签/关键词作为 item 标识符，发挥 LLM 的原生语义理解优势。

证据在真实推荐数据集上相比现有方法取得显著提升（快手团队出品，作者包含推荐系统核心成员 Guorui Zhou 等）。

LaSER: Internalizing Explicit Reasoning into Latent Space for Dense Retrieval

提出 LaSER 自蒸馏框架，将 LLM 的显式 CoT 推理能力内化到稠密检索模型的隐空间中。

INSIGHTLLM 已成为检索模型骨架，但当前方法仅用它做静态编码器，浪费了推理能力。LaSER 通过双视角训练（显式推理路径 + 隐式潜在思考）和多粒度对齐策略，在零额外延迟下让检索模型获得推理能力。

业务关联社区搜索中需要理解短查询背后的复杂意图（如需推理类查询），LaSER 可以让排序模型在不增加延迟的前提下获得推理能力，提升复杂 query 的 nDCG。

证据BRIGHT 基准 nDCG@10 从 25.7 提升到 29.3（+15%）；比 rewrite-then-retrieve 管道延迟降低 99.7%（仅需其 0.3% 延迟）；在 8/9 实验设置中优于 GIRCSE 基线。

Scaling Retrieval Augmented Generation with RAG Fusion: Lessons from an Industry Deployment

在企业生产环境中评估 RAG Fusion 技术，发现多查询检索融合在 reranking 和截断后并不优于单查询基线。

INSIGHTRAG 融合在独立检索基准上确实提升 recall，但在固定检索深度、reranking 预算和延迟约束的生产环境中，这些收益在 re-ranking 和截断后被抵消。这是一个重要的负面结果——提醒从业者不要盲目堆叠检索融合。

业务关联社区搜索如果计划引入 RAG 融合（多查询改写 + RRF 融合）来提升搜索质量，该论文的生产级评估结果是重要参考——在有 reranking 管道和延迟约束时，简单的单查询基线可能更优。

证据多种融合配置下 KB 级 Hit@10 从基线的 0.51 下降至 0.48；Reciprocal Rank Fusion 在 reranking 后收益被抵消；raw recall 提升未转化为端到端精度提升。

Luigi Medrano, Arush Verma, Mukul Chhabra

Uncertainty Quantification of Click and Conversion Estimates for the Autobidding

提出 DenoiseBid 方法，用贝叶斯方法修正 CTR/CVR 预估中的不确定性，提升广告自动出价效率。

INSIGHT广告竞价系统中 ML 模型的 CTR/CVR 预测存在不确定性，会严重影响自动出价算法的表现。DenoiseBid 用贝叶斯方法将噪声的点预估替换为从恢复分布中得到的估计，使出价更高效。

业务关联社区搜索如果涉及广告竞价场景，CTR/CVR 预估的不确定性修正可直接改善竞价策略的效率。即使非广告场景，该贝叶斯降噪思路也可用于搜索排序模型的预测校准。

证据在合成数据集、iPinYou 和 BAT 3 个数据集上进行了广泛实验，验证了在合成噪声和真实 ML 模型噪声两种设置下的有效性。

Ivan Zhigalskii, Andrey Pudovikov, Aleksandr Katrutsa, Egor Samosvat

Mag-Mamba: Modeling Coupled spatiotemporal Asymmetry for POI Recommendation

提出 Mag-Mamba 框架，用复数域中相位驱动的旋转动力学统一建模 POI 推荐中的时空非对称性。

INSIGHT位置间的转移意图具有高度非对称性且随时间动态变化，传统对称算子无法捕捉。Mag-Mamba 将时空非对称性建模为复数域的旋转动力学，通过时间条件磁相位编码器和复值 Mamba 模块实现全局方向性建模。

业务关联虽然 POI 推荐场景与社区搜索不同，但其时空序列建模思路（用 Mamba 架构替代 Transformer 处理长序列）可迁移到用户行为序列建模中，提升 CTR 预估的序列建模效率。

证据NYC 数据集 NDCG@1 提升 +1.96%、MRR +2.30%；TKY 数据集 NDCG@1 提升 +14.71%、MRR +6.08%；CA 数据集 NDCG@1 提升 +13.85%、MRR +3.14%。在稀疏数据集上提升尤为明显。

Token-Efficient Item Representation via Images for LLM Recommender Systems

提出 I-LLMRec，用图像替代冗长文本描述作为 LLM 推荐系统中的 item 表示，降低 token 开销同时保留语义信息。

INSIGHTLLM 推荐系统中 item 表示面临效率-效果权衡：属性表示简洁但信息不足，描述表示丰富但 token 开销大。由于图像与描述存在大量信息重叠，用图像可以在大幅减少 token 的同时保留描述级别的语义信息。

业务关联社区搜索中帖子通常包含图片和文本，I-LLMRec 的图像代替文本方案可用于 UGC 内容的高效表示——在 LLM 排序模型中用帖子图片替代冗长文本描述，减少推理成本。

证据在多个推荐数据集上的实验表明，I-LLMRec 在显著减少 token 使用的同时保持甚至超越纯文本描述方案的推荐性能。
