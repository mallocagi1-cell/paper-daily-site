Latent-Condensed Transformer for Efficient Long Context Modeling

针对大语言模型处理长上下文时 KV 缓存线性增长和自注意力二次复杂度的瓶颈，提出 Latent-Condensed Attention (LCA)，在 Multi-head Latent Attention (MLA) 的低维潜在空间中直接压缩上下文。核心设计将表征解耦为语义潜在向量和位置键，分别通过查询感知池化和锚点选择进行聚合。该方法联合降低计算成本和 KV 缓存占用，无需额外参数，能原生作用于 MLA 压缩结构，避免了稀疏注意力与 MLA 各自独立优化的局限。

MoBiE: Efficient Inference of Mixture of Binary Experts under Post-Training Quantization

提出首个面向 MoE 大模型的二值化框架 MoBiE，解决现有二值化方法在 MoE 架构上的三个难题：跨专家冗余、任务无关的权重重要性估计、量化导致的路由偏移。核心创新包括联合 SVD 分解减少跨专家冗余、将全局损失梯度融入局部 Hessian 度量提升权重重要性估计精度、基于输入零空间的误差约束缓解路由扰动。在 Qwen3-30B-A3B 上困惑度降低 52.2%，零样本平均性能提升 43.4%，推理加速超 2 倍。

INSIGHTMoBiE 揭示了 MoE 模型量化与 dense 模型量化的根本差异：路由机制对权重扰动极为敏感，直接套用 dense 方法会导致专家选择严重偏移。其零空间误差约束的设计思路值得借鉴——在不改变激活的前提下约束权重误差方向，可推广到其他需要保持路由稳定性的场景。对于搜索/推荐系统中部署 MoE 模型，这是目前最激进的压缩方案，2 倍加速的代价是精度损失可控，适合对延迟敏感但可容忍少量质量下降的场景。

Zhixiong Zhao, Zukang Xu, Zhixuan Chen, Dawei Yang

VFA: Relieving Vector Operations in Flash Attention with Global Maximum Pre-computation

分析了 FlashAttention 在现代加速器上逼近张量核峰值吞吐时的新瓶颈：online softmax 的非矩阵乘操作（逐块 rowmax/rowsum 归约和 rescale 链）成为向量/SIMD 限制。提出 VFA (Vector Relieved Flash Attention)，通过从键块表征中廉价预估全局最大值、重排键块遍历顺序优先处理 sink 和局部块、冻结剩余块最大值来减少重复归约和 rescaling 操作，在保持 online-softmax 结构的同时显著降低向量操作开销。

INSIGHTVFA 揭示了 FlashAttention 在下一代硬件上的新性能瓶颈不在矩阵乘而在标量/向量操作。随着 tensor core 算力翻倍而 SIMD 单元未同步扩展，这一瓶颈将日趋严重。其「预估全局最大值 + 冻结策略」的思路适用于任何需要 online softmax 的场景。对搜索系统来说，Attention 计算是 reranker 和 embedding 模型的核心开销，VFA 的优化可直接降低在线推理延迟，特别是在升级到 Blackwell 等新硬件时效果更明显。

Yupeng Sun, Yanzhao Li, Zhiqiang Zou, Bai Du, Zhiyuan Zhang, Hui Dong, Gaoyige Fan, Hui Wang

PipeLive: Efficient Live In-place Pipeline Parallelism Reconfiguration for Dynamic LLM Serving

解决 LLM serving 中流水线并行静态配置无法适应 serverless 平台和异构 GPU 环境的问题。现有系统重配需停服重部署，PipeLive 实现了在不中断推理的前提下实时原地重配流水线并行。核心挑战在于 GPU 已被模型权重和 KV 缓存饱和，需要同时处理层迁移、KV 缓存调整和一致性维护。提出增量式层迁移和后台 KV 同步方案，避免了 stop-and-copy 的大暂停和后台同步的不一致风险。

INSIGHTPipeLive 的核心价值在于使 LLM 推理服务具备「热重配」能力——无需停服即可适应 GPU 拓扑变化、负载波动或硬件故障。这对搜索系统中大模型在线 serving 有直接意义：弹性扩缩容、异构硬件调度、故障快速恢复等场景都需要动态调整流水线配置。其增量式迁移设计思路可与 vLLM 等推理框架集成，为 LLM 推理服务的 SLA 保障提供了新的基础设施能力。

Lightning OPD: Efficient Post-Training for Large Reasoning Models with Offline On-Policy Distillation

分析了在线策略蒸馏 (OPD) 在大型推理模型 post-training 中的基础设施开销问题：标准 OPD 需要全程运行教师推理服务器。提出离线替代方案 Lightning OPD，发现使 offline OPD 有效的关键条件是「教师一致性」——SFT 和 OPD 阶段必须使用同一教师模型。违反该条件会引入不可约梯度偏差，导致在线和离线 OPD 均收敛到次优解。通过保证教师一致性，Lightning OPD 无需实时教师服务器即可匹配标准 OPD 性能。

INSIGHTLightning OPD 解决了一个重要的工程痛点：在线蒸馏需要持续运行大型教师模型推理服务器，基础设施成本极高。其发现的「教师一致性」条件具有普遍指导意义——在搜索/推荐系统中进行模型蒸馏时，确保 SFT 数据生成和蒸馏阶段使用同一教师模型至关重要。这对实际训练 pipeline 的设计有直接影响：预计算教师 logits 的离线方案可将训练成本降低约 50%，适合资源有限但需要频繁迭代模型的团队。

OSC: Hardware Efficient W4A4 Quantization via Outlier Separation in Channel Dimension

系统研究了 LLM 中 W4A4 量化面临的激活异常值分布规律，发现高幅度异常值呈现「token 持久的结构化聚类效应」——固定通道上跨 token 持续出现。基于此洞察提出 OSC 框架，推理时采用双路径计算：低精度 4-bit GEMM 路径处理正常通道，高精度 16-bit 分支 GEMM 路径处理异常值聚集通道。通过离线分组策略识别异常值通道，并执行结构化子张量抽取将分散的激活通道合并为紧凑稠密张量，适配硬件高效计算。

INSIGHTOSC 的「通道维度异常值分离」策略在工程上极具吸引力：离线一次性标定异常值通道，运行时仅需一次简单的通道索引即可完成分流，几乎无额外延迟。相比 SmoothQuant 等需要在线变换的方案，OSC 更适合搜索/推荐系统中需要极低延迟的 ranking 场景。W4A4 量化可将模型内存和计算需求同时降至约 1/4，双路径 GEMM 设计保证了精度，是部署大型 reranker 的实用方案。

Zhiyuan Zhang, Yanzhao Li, Zhiqiang Zou, Bai Du, Yupeng Sun, Hui Dong, Hui Wang

SpecBound: Adaptive Bounded Self-Speculation with Layer-wise Confidence Calibration

针对自草稿推测解码中浅层过度自信和困难 token 导致冗余计算的问题，提出 SpecBound 框架。核心技术包括层级温度退火抑制早退决策中的虚假置信度、基于 token 难度自适应限制推测长度。草稿 token 的隐状态在深层通过统一并行 pass 重新处理，保持与原始模型完全一致的输出。该方法无需辅助草稿模型，仅利用基座 LLM 自身进行推测，在最大化计算效率的同时保证了输出等价性。

INSIGHTSpecBound 解决了 self-speculation 的核心工程难题：如何在不引入额外模型的前提下可靠加速推理。层级温度退火是一个简洁有效的技巧——浅层 logits 的过度自信是 early exit 方法的通病，温度退火几乎无额外开销。对搜索系统中的 LLM serving 场景，self-speculation 避免了维护 draft model 的运维复杂度，自适应推测长度确保在简单 query 上获得更大加速，在复杂 query 上避免浪费计算。

Zhuofan Wen, Yang Feng

ZoomR: Memory Efficient Reasoning through Multi-Granularity Key Value Retrieval

IBM

针对 LLM 推理中长输出生成导致 KV 缓存持续增长的问题，提出 ZoomR 多粒度 KV 检索方法。核心思路是将冗长的中间推理过程自适应压缩为摘要，使用摘要键作为粗粒度索引，在解码时根据查询动态检索细粒度细节实现「缩放聚焦」。该方法同时优化了输出端的 KV 缓存，区别于现有主要关注输入端上下文压缩的工作，为长推理链场景提供了一条内存高效路径。

INSIGHTZoomR 识别了一个被忽视的优化方向：长输出生成中的 KV 缓存增长。在搜索系统中越来越多地使用 Chain-of-Thought 推理来提升相关性判断质量，但推理链越长 serving 成本越高。ZoomR 的「摘要索引 + 细节检索」双粒度设计，可在保持推理质量的同时控制 KV 缓存增长。这对部署推理增强型 reranker 或 query 理解模型有直接的工程价值——无需截断推理链，而是智能管理缓存。

Efficient Inference for Large Vision-Language Models: Bottlenecks, Techniques, and Prospects

系统综述大型视觉语言模型 (LVLM) 的推理效率瓶颈和优化技术。识别出「视觉 token 主导」的系统性效率障碍，涵盖高分辨率特征提取、二次注意力缩放和内存带宽约束三个维度。围绕推理生命周期（编码、预填充、解码）构建分类体系，揭示上游决策如何决定下游瓶颈，覆盖计算密集型视觉编码、大规模上下文预填充和带宽受限解码中的「视觉内存墙」问题。

INSIGHT该综述对搜索/推荐系统中部署多模态模型有重要参考价值。核心发现是视觉 token 数量是 LVLM 推理效率的主导因素——编码阶段的特征密度直接决定了后续所有阶段的计算和内存开销。对于图文搜索场景，选择视觉 token 压缩策略时需要权衡三个维度：信息密度、注意力复杂度和内存带宽。该综述提供了端到端 pipeline 视角的技术选型指南，避免了局部优化的陷阱。

An Engineering Journey Training Large Language Models at Scale on Alps: The Apertus Experience

NVIDIACCSCS

详细记录了在欧洲最大公共超算 Alps 上训练 70B 参数开放多语言基座模型 Apertus 的完整工程历程。基于 NVIDIA GH200 Grace Hopper Superchips，涵盖存储系统就绪化、大规模分布式训练配置优化、故障容错机制设计等关键工程挑战。该项目是学术界首次在 70B 规模上完成的完整预训练，为公共机构独立训练大模型提供了可复制的工程经验。

INSIGHT该工程报告对大规模训练 infrastructure 建设有实践参考价值。GH200 Grace Hopper 架构（CPU-GPU 统一内存）在大模型训练中的实际表现和调优经验是稀缺信息。对搜索/推荐团队来说，如果计划在 GH200 或类似新硬件上训练自有模型，该报告中的存储 I/O 瓶颈分析、分布式训练配置选择和故障恢复策略可直接借鉴，避免重复踩坑。
