NaviRAG: Towards Active Knowledge Navigation for Retrieval-Augmented Generation

针对传统 RAG 依赖平面检索范式、难以应对需要多粒度条件检索与动态信息合成的复杂任务问题，提出 NaviRAG 框架，将被动片段检索转变为主动知识导航。核心思路是将知识文档组织为层级结构，保留语义关系，再由 LLM agent 迭代导航以识别信息缺口并跨粒度定位证据。在长文档问答基准上，检索召回和端到端答案质量均优于传统 RAG 基线，消融实验证实增益来自多粒度证据定位和动态检索规划。

Retrieval as a Decision: Training-Free Adaptive Gating for Efficient RAG

Stony Brook University

针对 RAG 系统中「每次查询都检索」导致的质量下降和延迟增加问题，提出 TARG（Training-free Adaptive Retrieval Gating），一种无需训练的自适应检索门控策略。利用基座模型生成的短 draft 前缀的 logits 计算不确定性分数（token 熵均值、top-1/top-2 logit 间距、小规模随机前缀方差），仅在不确定性超过阈值时触发检索。在 NQ-Open、TriviaQA、PopQA、MuSiQue、ASQA 五个 QA 基准上，TARG 减少 70–90% 的检索调用，同时保持或超越 Always-RAG 的 EM/F1 分数，端到端延迟大幅降低。

INSIGHTTARG 最突出的实践价值在于其零训练成本和即插即用特性——不需要额外的判别头或微调，仅通过 draft logits 的不确定性信号即可决策是否检索。对于搜索/推荐系统而言，这提供了一条低成本优化检索效率的路径：在 LLM 辅助搜索场景中，可以用类似的不确定性门控策略减少 70%+ 的外部检索调用，在不牺牲结果质量的前提下大幅降低延迟和 API 开销。margin signal 作为鲁棒默认策略值得优先尝试。

Yufeng Wang, Lu Wei, Haibin Ling

Nemotron 3 Super: Open, Efficient Mixture-of-Experts Hybrid Mamba-Transformer Model for Agentic Reasoning

NVIDIA

NVIDIA 发布 Nemotron 3 Super，一个 120B 总参数（12B 活跃参数）的混合 Mamba-Attention MoE 模型，专为 agentic reasoning 设计。三项核心技术创新：(1) 首个在 NVFP4 精度下预训练的模型；(2) LatentMoE 架构，同时优化每 FLOP 和每参数的精度；(3) MTP 层支持原生推测性解码加速推理。在 25 万亿 token 上预训练，推理吞吐量比 GPT-OSS-120B 高 2.2 倍，比 Qwen3.5-122B 高 7.5 倍。模型权重、数据集全部开源。

INSIGHTNemotron 3 Super 的工业意义在于验证了混合 Mamba-Attention MoE 在 agentic 推理任务上的可行性——12B 活跃参数即可驱动长链推理和工具调用，而不需要全量激活 120B。LatentMoE 架构对搜索 agent 的基座模型选型有直接参考价值：在保持推理质量的同时大幅降低部署成本。NVFP4 预训练和 MTP 推测解码的组合为大模型在线服务提供了一条高吞吐低延迟的部署路径，特别适合需要实时响应的搜索场景。

04 3.89

Advancing Multi-Agent RAG Systems with Minimalist Reinforcement Learning

CUHKHuawei

针对多轮 RAG 交互中上下文长度指数增长、LLM 难以有效利用长中间上下文的问题，提出 Mujica-MyGO 框架。Mujica 采用分治策略将多轮交互分解为协作子交互，缓解长上下文瓶颈；MyGO 是一种轻量级 RL 算法，消除对 in-context learning 的依赖并提供理论收敛保证。在文本语料和知识图谱上的多样化 QA 基准测试中表现优越。该工作被 AAMAS 2026 接收。

INSIGHT该工作揭示了 multi-agent RAG 的核心工程挑战：多轮搜索交互产生的上下文长度随探索深度指数增长，而非线性增长。分治式多 agent 协作策略是解决这一问题的实用思路——将复杂检索任务分解为独立子任务，每个 agent 处理短上下文，最后汇总。MyGO 的理论收敛保证使得 RL 训练 RAG agent 有了更可靠的基础。对 UGC 搜索中需要多步推理的复杂 query（如「对比 A 和 B 产品的用户评价」），多 agent 协作检索是值得探索的方向。

Transforming External Knowledge into Triplets for Enhanced Retrieval in RAG of LLMs

UUniversity of Electronic Science and Technology of China

针对 RAG 系统中检索到的非结构化文本片段存在冗余信息、语义对齐差、上下文过度积累等问题，提出将外部知识转化为三元组（triplets）结构以增强检索质量。核心思路是在检索和生成之间引入结构化表示层，将非结构化文本片段转换为精炼的实体-关系三元组，减少噪声信息并提高与查询的语义对齐度。实验表明该方法在多个 QA 基准上改善了 RAG 系统的答案准确性和生成质量。

INSIGHT该工作的实践启示在于：RAG 的瓶颈不仅在检索器或模型本身，还在于检索证据的表示形式。将非结构化文本转化为结构化三元组是一种轻量且有效的信息提纯手段，可以减少上下文噪声并提升语义对齐。对搜索系统而言，在 UGC 短文本检索场景中，用户帖子内容往往噪声较高，引入类似的结构化表示（如实体-关系抽取后的精炼上下文）可以提升基于 LLM 的搜索质量，同时降低 token 开销。

Towards Long-horizon Agentic Multimodal Search

Renmin University of China

针对多模态深度搜索 agent 在长周期任务中面临的上下文爆炸和视觉信号丢失问题，提出 LMM-Searcher 框架。核心创新是基于文件的视觉表示机制：将视觉资产卸载到外部文件系统并映射为轻量级文本标识符 (UID)，减少上下文开销的同时保留多模态信息的按需访问能力。配合 fetch-image 工具实现渐进式视觉加载策略。通过数据合成流水线生成 12K 高质量轨迹训练数据，微调 Qwen3-VL-Thinking-30A3B。在 MM-BrowseComp 和 MMSearch-Plus 等基准上成功扩展到 100 轮搜索，达到开源模型 SOTA。

INSIGHTLMM-Searcher 解决了多模态 agent 的核心工程难题——上下文爆炸。文件系统 + UID 映射的思路巧妙地将视觉信息管理从模型上下文中解耦，使 agent 能够在 100 轮长周期搜索中保持稳定。这种「外部存储 + 按需加载」的范式对搜索 agent 设计有普遍意义：无论是多模态还是纯文本场景，长链搜索 agent 都需要外部状态管理来避免上下文窗口耗尽。12K 合成轨迹训练数据的生成方法也为搜索 agent 的数据飞轮提供了参考。

Yifan Du, Zikang Liu, Jinbiao Peng, Jie Wu, Junyi Li, Jinyang Li, Wayne Xin Zhao, Ji-Rong Wen

From Imitation to Discrimination: Progressive Curriculum Learning for Robust Web Navigation

针对文本 Web agent 在真实 HTML 环境中因噪声和异构性导致的鲁棒性不足问题，提出渐进式课程学习方案。指出标准 SFT 在两个关键维度上失败：缺乏在密集页面中拒绝「看似正确实则错误」元素的辨别能力，以及对未见过的网站布局泛化能力有限。引入 Triton 数据集（59 万实例）和从模仿到辨别的渐进式训练课程：先通过结构化轨迹学习基础导航能力，再通过对比学习训练辨别和拒绝错误元素的能力。在多个 Web 导航基准上显著提升了鲁棒性。

INSIGHT该工作的核心洞察是 Web agent 不仅需要学会「做什么」（模仿），还需要学会「不做什么」（辨别）——这对搜索 agent 的训练设计有直接借鉴价值。在 UGC 搜索场景中，搜索 agent 需要在大量噪声结果中辨别相关与不相关内容，单纯的 SFT 可能不够，需要对比学习或 DPO 等方法培养拒绝能力。59 万级别的 Triton 数据集也为 Web agent 研究提供了重要的开源资源。

Chuang Peng, Wei Zhang, Renshuai Tao, Xinhao Zhang, Jian Yang

Aligning Agents via Planning: A Benchmark for Trajectory-Level Reward Modeling

针对 LLM agent 从单轮问答演进到自主工具调用和复杂推理后，传统 Reward Model 在 agent 轨迹评估上力不从心的问题，提出 Plan-RewardBench 基准。覆盖四类代表性任务：安全拒绝、工具无关/不可用、复杂规划、鲁棒错误恢复。在统一成对比较协议下评测了生成式、判别式和 LLM-as-Judge 三类 Reward Model，发现所有评估器在长周期轨迹上性能急剧下降，揭示了 agent 场景下轨迹级奖励建模的严峻挑战。

INSIGHTPlan-RewardBench 揭示了一个关键瓶颈：现有 Reward Model 在 agent 长链轨迹上的评估能力急剧退化。这对搜索 agent 的 RLHF 训练有重要警示——如果我们用标准 RM 来训练搜索 agent 的多步检索策略，RM 本身可能在长轨迹上产生错误信号。该基准的四个任务类别（特别是复杂规划和鲁棒错误恢复）为搜索 agent 的奖励模型设计提供了评测框架。未来搜索 agent 的 RL 训练需要专门针对长周期场景优化 RM。

Jiaxuan Wang, Yulan Hu, Wenjin Yang, Zheng Pan, Xin Li, Lan-Zhe Guo

Long-Horizon Plan Execution in Large Tool Spaces through Entropy-Guided Branching

Amazon

针对大型工具库中 LLM agent 执行多步任务面临的评估框架缺失和搜索空间爆炸两大瓶颈，提出 SLATE 基准和 Entropy-Guided Branching (EGB) 算法。SLATE 是面向电商场景的大规模上下文感知基准，支持多条功能等效的执行轨迹，弥补了静态指标无法评估多样化合法路径的不足。EGB 是不确定性感知的搜索算法，在预测熵高的决策点动态扩展分支，优化探索-利用权衡。两者结合显著提升了任务成功率和计算效率。

INSIGHTSLATE 基准的设计理念值得搜索 agent 评估借鉴：真实场景中完成任务的合法路径通常不唯一，静态指标（如精确匹配单一标准答案）会低估 agent 能力。EGB 的不确定性驱动分支策略与 TARG 的不确定性门控形成互补——前者用于执行阶段决定何处探索更多路径，后者用于检索阶段决定是否触发外部检索。两者的组合为搜索 agent 的全链路不确定性管理提供了思路。该工作来自 Amazon 实习，电商场景的工具调用设定与搜索推荐密切相关。

Rongzhe Wei, Ge Shi, Min Cheng, Na Zhang, Pan Li, Sarthak Ghosh, Vaibhav Gorde, Leman Akoglu

Knowledge Is Not Static: Order-Aware Hypergraph RAG for Language Models

针对现有 RAG 方法（包括图和超图方法）将检索证据视为无序集合、隐式假设置换不变性的问题，提出 Order-Aware Knowledge Hypergraph RAG (OKH-RAG)。指出在许多真实推理任务中，结果不仅取决于哪些交互发生，还取决于交互发生的顺序。OKH-RAG 将顺序视为一等结构属性，通过有序超图表示知识，捕捉证据间的时序依赖关系，在需要序列推理的 QA 任务上优于传统无序 RAG。

INSIGHTOKH-RAG 提出了一个被普遍忽视的 RAG 盲点：证据顺序对推理结果的影响。大多数 RAG 系统默认证据无序拼接，但在时间敏感、因果推理、流程追踪等场景中，顺序信息至关重要。对 UGC 搜索场景的启示是：社区帖子和评论天然具有时间序列属性（如讨论演进、观点变化），在构建 RAG 上下文时保留时序结构可能提升回答质量。有序超图的建模思路虽然实现复杂度较高，但其核心理念——「顺序即结构」——可以通过更简单的排序策略近似实现。
