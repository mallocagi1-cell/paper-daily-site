PCTD: Preference-Guided Counterfactual Task Decomposition for Agent Tool Retrieval

针对复杂指令拆解后进行 Agent 工具检索时，直接用 Recall 或 nDCG 作强化学习奖励会诱发重复拆解与奖励投机，论文提出 PCTD。它用反事实奖励估计任务拆解对检索排序的边际因果增益，并以偏好奖励约束逻辑连贯性和原子性；在新建的移动端多轮交互 MTDTool 基准上，同时提升检索、拆解质量与未见工具的域外泛化。

Agentic Deep Research: How LLM Search Agents Plan, Retrieve, and Synthesize Across Dozens of Sources

You.com

文章从生产系统视角拆解深度研究 Agent 如何规划问题、跨数十个来源迭代检索、压缩上下文、核验证据并生成带引用的结论。它强调“给 LLM 接一个搜索工具”并不等于研究 Agent，真正的工程难点在于多轮错误传播、来源可信度、上下文预算、延迟和成本的联合控制，并给出可落地的编排模式与常见失败点。

INSIGHT对社区搜索而言，深度模式应被设计成独立服务等级，而不是无条件替代低延迟检索：简单问题走单轮召回，复杂问题才触发规划、证据充分性检查和多源交叉验证。落地时应把查询轨迹、来源判断和上下文压缩作为可观测模块，避免只看最终回答，才能定位究竟是召回、规划还是合成阶段造成错误。

Process Reward Informed Tree Rollout for Effective Multi-Turn RL

PATR 针对 GRPO/RLOO 在长程 Agent 任务中独立采样完整轨迹、浪费预算于死路的问题，把多轮动作与观察组织成树。过程评分器对部分轨迹打分，只从有希望的状态分支、复用共享前缀并提前终止退化路径，同时保持与标准策略优化兼容；在 SWE-Bench 上最高提升 5.0 分，在 FrozenLake 上最高提升 9.3 分。

INSIGHT多轮搜索 Agent 的训练瓶颈往往不是奖励缺失，而是采样预算错误地平均分配给低价值轨迹。PATR 的“过程评分—选择性分支—前缀复用”可迁移到查询改写与工具调用训练：对出现高质量证据的中间状态增加探索，对无结果或循环搜索及时止损，在相同 rollout 预算下获得更多有效学习信号。

SkillCorpus: Consolidating and Evaluating the Open Skill Ecosystem for Real-World LLM Agents

SkillCorpus 将公开仓库中约 82.1 万个 SKILL.md 经多阶段清洗压缩为 96,401 个技能，按 16 类及效用、鲁棒性、安全性三维组织，并训练检索与选择栈按任务匹配技能。论文在 SkillsBench、GDPVal、QwenClawBench 三个基准、两套运行框架和两个开放模型上端到端评测，SkillsBench 最大提升 7.5 个百分点。

INSIGHT技能生态的价值不在于无限扩库，而在于覆盖边界、质量治理和运行框架是否支持正确调用。搜索 Agent 可以把查询改写、站内检索、重排、事实核验封装成可检索技能，并在入库阶段加入安全与鲁棒性过滤；在线选择器只暴露少量任务相关技能，可降低工具过载，同时保留对长尾搜索意图的扩展能力。

Yanze Wang, Pengfei Yao, Tianyi Sun, Chuanrui Hu, Yan Xiao, Yunyun Han, Jun Sun, Yafeng Deng

Safety and alignment in an era of long-horizon models

OpenAI

OpenAI 总结长时运行模型在真实部署中的新型安全与对齐风险、已观察到的失败模式，以及通过迭代部署逐步增强防护的经验。文章关注模型在更长任务链中累积决策、调用工具和改变环境状态后，传统单轮评测无法覆盖的风险，并主张把监控、权限边界、恢复机制和持续评估纳入系统设计。

INSIGHT搜索与研究 Agent 的风险会随任务时长和工具权限非线性放大：一次错误查询尚可纠正，连续错误检索、错误引用和外部动作则会形成级联。工程上应为长链任务设置分段检查点、最小权限、预算上限和可回滚状态，并把轨迹级评测加入上线门槛；这比只在最终答案层做安全过滤更适合生产系统。

ToolSciVer: Multimodal Scientific Claim Verification with Visual Tool Augmented Reinforcement Learning

ToolSciVer 面向科学论文中图表、图像与文本共同支撑的声明核验，为视觉语言模型提供表格行列聚焦、图表结构化解析和高分辨率区域缩放三类工具。模型通过 GRPO 学习调用策略，奖励同时约束答案正确、格式、长度、工具效率与调用合法性；在 SciVer 和 MuSciClaims 上覆盖 Qwen、InternVL、Gemma 三个家族共 5 个模型，并优于 4 类提示或强化学习工具基线。

INSIGHT当证据藏在长文档和结构化视觉内容中，通用“看整页”工具既贵又不稳定，按内容类型提供小而专的证据提取工具更有效。社区搜索若扩展到帖子截图、商品表格或数据图，可将区域放大、表格定位、图表转结构分别做成工具，并在奖励中显式惩罚无效调用，兼顾核验准确率与推理成本。

What Is Your AI Agent Buying? Evaluation, Biases, Model Dependence, & Emerging Implications of Agentic E-Commerce.

已录用 WWW 2026Columbia University

论文构建可编程电商沙箱 ACES，随机化位置、价格、评分、评论、赞助与平台标签，因果审计不同视觉语言模型代理的购买决策。代理普遍偏好首行但列偏好随模型变化；卖方 Agent 仅改写商品描述即可让目标商品份额提升 3.66–14.89 个百分点，部分商品在模型升级后份额从 45% 升至 77%，另一些则从 25% 降至 6%。

INSIGHTAgent 成为搜索和交易主体后，传统面向人的位置偏差与排序评估不再稳定，同一页面在不同模型或版本上会形成完全不同的选择分布。平台需要建立按模型版本分层的 Agent 流量监控，审计赞助标签、平台背书与文案优化是否造成不公平集中，并避免把单一模型上的离线排序收益外推到整个代理生态。

Amine Allouah, Omar Besbes, Josué D. Figueroa, Yash Kanoria, Akshit Kumar

EpiNarrate: Agentic Generation of Grounded Narratives from Epidemiological Scenario Projections

EpiNarrate 解决大模型直接总结大规模流行病情景投影时数字不一致、维度遗漏和行为脆弱的问题，将结构化数值推理与自然语言生成分离。系统先抽取干预、地域、人口、时间和不确定性等情景轴并构建偏序结构，再由 Agent 按可验证的中间表示生成有依据的叙事，从而在多维集合数据上维持数字与上下文一致。

INSIGHT该工作对搜索报告生成的启发是：不要让一个模型同时承担数据选择、数值运算和文案组织。对于趋势检索或社区舆情研究，可先把时间、地域、用户群与指标约束显式化，生成可审计的结构化证据，再交给语言模型叙述；这种“先计算、后表达”的 Agent 分工能显著降低引用与数字漂移。

Scholar API: Search and Recommendations for Academic Search.

该 WSDM 2026 系统论文围绕学术搜索场景提供统一 Scholar API，把论文检索与相关推荐能力封装为可供上层应用和 Agent 调用的接口。相比让研究 Agent 直接依赖网页搜索，结构化 API 能返回稳定标识、元数据与关联结果，便于多轮检索、去重和来源追踪；当前 crawler 仅获得 DBLP 元数据，实验细节需以正式论文为准。

INSIGHT研究型 Agent 的可靠性首先取决于检索底座能否提供稳定 ID、可追溯元数据和明确的搜索/推荐语义。社区内容系统也可借鉴这一接口边界：把关键词检索、相似内容推荐、作者或主题扩展拆成清晰工具，并统一返回内容 ID 与证据字段，可减少 Agent 在网页解析、去重和引用阶段的脆弱性。

CoWeaver: A Bi-directional, Learnable and Explainable Matching Engine for Mixed Human-Agent Science Collaboration

CoWeaver 面向人类与 LLM Agent 混合科研网络中的双向、动态协作匹配，先以能力缺口连接请求方与候选方，再通过两阶段排序筛选，并用带不确定性的能力估计和反馈持续更新。其 UCB 探索与贪心结合的选择机制在 20 个任务中有 6 个超过理论上的纯贪心解，其余任务总体保持相当的选择表现。

INSIGHT当搜索系统要为复杂任务匹配专家 Agent 或人工审核者时，只按当前相关度贪心排序会长期忽略新成员。CoWeaver 提示可把“补足任务能力缺口”作为主匹配信号，再用不确定性驱动少量探索，并从任务结果回写能力画像；这种探索—利用机制适合构建持续学习的专家路由和人机协作检索系统。

Jiayao Gu, Kexin Chu, Peidong Liu, Yue Yang, Lynn Ai, Qi Zhang, Ling Yang, Tianyu Shi
