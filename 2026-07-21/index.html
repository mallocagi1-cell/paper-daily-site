Rethinking Generative Recommender Tokenizer: Recsys-Native Encoding and Semantic Quantization Beyond LLMs.

Internalizing Multi-Agent Reasoning for Accurate and Efficient LLM-based Recommendation

Tencent📖 深度解读 · 6 分钟 →

腾讯提出 STAR，把多智能体教师的规划、工具调用、自反思轨迹以及协同信号翻译能力，蒸馏进单个实时推荐模型。训练先由教师合成带行为证据的复杂轨迹，再进行监督微调与强化学习；实验中 STAR 比教师高 8.7%–39.5%，同时消除迭代式多智能体推理带来的在线时延。

INSIGHT工业系统不必在每次请求中运行昂贵的多智能体链路，可以离线让强教师探索并把轨迹内化到轻量学生。对社区搜推，可把用户点击序列先翻译成可读兴趣证据，再蒸馏规划与反思逻辑；线上只保留单模型推理，在维持延迟预算的同时获得更强的意图解释和候选选择能力。

Intent-Driven Semantic ID Generation for Grounded Conversational News Recommendation

TencentSun Yat-sen University

腾讯针对新闻对话中隐式意图难以先检索的问题，提出 Generate-then-Match：7B LLM 先生成层级 Semantic ID 前缀，再与实时新闻池模糊匹配，并以双信号推理覆盖冷启动。在 15.2 万 SID 空间中实现 0% 幻觉、12.4% L1 命中，成本约为 GPT-4+混合 RAG 的 1/100，冷启动 L1 达 18.0%。

INSIGHT先生成可约束的语义目标、再映射到真实库存，能同时解决开放生成幻觉和检索 query 缺失。社区搜索可把模糊自然语言意图转换为帖子主题层级码，再在实时 UGC 池中做前缀匹配；用户画像与当前对话双通道尤其适合历史稀疏的新用户，并能保证最终结果始终来自可展示内容。

Hongyang Su, Beibei Kong, Lei Cheng, Chengxiang Zhuo, Zang Li, Chenyun Yu

Eliminating Out-of-Domain Recommendations in LLM-based Recommender Systems: A Unified View

Microsoft

微软 RecLM 在同一 LLM 与提示设置下统一比较三种落地范式：向量检索、受约束的标题生成和离散物品 token 生成。三种变体都把域外推荐 OOD@10 严格降到 0；其中 RecLM-cgen 与 RecLM-token 在公开基准达到整体 SOTA，并开放于 Microsoft RecAI 代码库。

INSIGHT生产级 LLM 推荐首先要把候选空间约束为真实库存，而不是只追求语言流畅度。社区搜推可以按延迟与更新频率选择三种接口：向量召回最稳、受约束文本生成便于解释、离散 token 生成利于端到端扩展；统一骨干和提示也让离线评测能公平比较准确率、幻觉率与成本。

Distilling LLM Reasoning into Dense Encoders: Bridging the Accuracy-Efficiency Gap in Recommendation

R2END 不蒸馏逐 token 输出，而以语义对齐把 LLM 的推荐推理压入 0.3B 文本编码器的稠密向量。在 4 个数据集上相对最强基线平均提升 29%、最高 45%；各项提升为 2.79%–45.16%，推理延迟约 92ms，显著低于 916ms 和 2232ms 的生成式学生。

INSIGHT推荐服务需要的是推理后的表征，不一定需要在线生成完整思维链。社区短文本场景可离线生成用户—内容关系理由，再把这些语义蒸馏进双塔或稠密编码器，线上沿用成熟 ANN 召回；这种设计既保留 LLM 对隐含兴趣的理解，又避免自回归生成拖慢高 QPS 搜索链路。

Donghee Han, Daeyoung Roh, A Young Kim, Hwanjun Song, Mun Yong Yi

06 4.20

Continuous-time Discrete-space Diffusion Model for Recommendation.

CDRec 在原始离散交互上运行连续时间扩散，加入流行度感知噪声日程、快速一致性采样和多跳协同对比学习，避免连续潜空间的信息损失。在 Ciao、MovieLens-1M、点评三组数据上，Recall 与 NDCG 相对最强基线提升 2.90%–6.88%，单步恢复已达到传统扩散基线水平。

INSIGHT离散扩散能直接建模点击集合并探索多样兴趣，但必须控制采样成本。对于社区推荐，可让热门度决定加噪难度，并用预训练图协同表示引导去噪；一致性参数化支持少步甚至单步生成，适合作为候选扩展器，与现有召回排序并行实验，而不必一次替换整条链路。

Chengyi Liu, Xiao Chen, Shijie Wang, Wenqi Fan, Qing Li

Data-Efficient Adaptation to Contextual Shifts in LLM-based Conversational Recommendation

CAPT 把趋势漂移样本分为熟悉、可学习和异常三类，以相对可学习性打分选择少量数据并指导 LLM 对话推荐器更新。在 Reddit 24 阶段实验中，仅用 28.3%–39.4% 数据即可达到或超过全量训练的 Recall/MRR/NDCG，NDCG@10 为 0.1510，高于全量训练的 0.1463。

INSIGHT热点与语言变化频繁时，周期性全量微调既贵又会重复学习旧模式。社区搜推可按时间窗估计样本的可学习性，只选择能代表新梗、新实体和兴趣迁移的数据进行 LoRA 更新；同时排除模型已熟悉或无法学习的异常样本，使小预算更新更快跟上内容分布变化。

Hyeongjun Yang, Donghyun Kim, Seokju Hwang, Midan Shim, KyuHwan Yeom, KaeHyun Um, Kyong-Ho Lee

What Makes LLMs Effective Sequential Recommenders? A Study on Preference Intensity and Temporal Context

ByteDanceDartmouthUniversity of Notre Dame

RecPO 指出二元偏好对会丢失喜爱强度与交互新鲜度，因而把显式、隐式反馈映射到统一偏好信号，并用强度和时间共同调整奖励间隔。在 5 个数据集上，完整模型的 Hit Ratio@1 分别达到 0.3451、0.5802、0.5771、0.4672、0.6830，整体优于去掉时间或强度的变体。

INSIGHT点击与未点击并非强度相同的二元标签，近期行为也应比陈旧历史获得更大权重。社区搜索可把点赞、收藏、长停留、跳出与负反馈映射到连续强度，并让奖励 margin 随时间衰减；这比简单 DPO 对更贴近用户当前意图，也能减少模型重复推荐早已失效的兴趣。

HARPO: Hierarchical Agentic Reasoning for User-Aligned Conversational Recommendation

IIT PatnaIIIIT Allahabad

HARPO 用层级偏好学习分解相关性、多样性、满意度和参与度，再由价值网络引导树搜索，并通过虚拟工具操作与多智能体细化完成对话推荐。在 ReDial、INSPIRED、MUSE 上相对最强基线平均提升 17%–21%；INSPIRED 的 Recall@10 比 GPT-4 高 45.7%，人工总体评分由 3.40 提至 3.90。

INSIGHT对话推荐不能只优化 Recall 或语言流畅度，应显式建模满意度与参与度之间的权衡。社区搜索助手可在候选路径上进行小规模价值引导搜索，并把工具调用抽象为领域无关操作；但完整多智能体推理成本较高，更适合作为离线策略教师或高价值复杂 query 的按需分支。

Subham Raj, Aman Vaibhav Jha, Mayank Anand, Sriparna Saha

CEILLM: Confidence-Aware Dynamic Fusion of Collaborative Embedding-Infused Large Language Models for Conversational Recommendation

Jeju National UniversitySSoongsil University

CEILLM 用图协同过滤骨干学习用户与物品表示，再以轻量适配器注入 LLM；动态门控同时读取对话上下文、模型置信度和用户交互深度，在表征与打分阶段调整两类信号。论文以 Recall@K、NDCG@K、MRR@K 评估，在多组对话推荐数据上稳定领先，最大收益出现在冷启动用户。

INSIGHT冷启动时应更多相信语言语义，历史充足后再提高协同信号权重，而非固定拼接两类 embedding。社区场景可把门控值做成可观测特征：随会话轮次、候选置信度和用户历史长度动态调整；这种渐进融合既服务新用户，也避免长期用户被通用 LLM 知识稀释个性偏好。

Yeo-Chan Yoon, Chanjun Park, Jaechoon Jo
