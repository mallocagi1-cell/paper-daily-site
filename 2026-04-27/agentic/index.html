IG-Search: Step-Level Information Gain Rewards for Search-Augmented Reasoning

本文提出 IG-Search，一个基于步骤级信息增益（Information Gain）奖励的强化学习框架，用于训练搜索增强推理模型。核心思路是为每一步检索计算 IG 分数：度量当前检索结果相对于随机文档基线，对模型给出正确答案的置信度提升幅度，作为稠密奖励信号注入 GRPO 的 token 级 advantage。基于 Qwen2.5-3B，在 7 个 QA 基准上较轨迹级奖励基线提升 1.6 分，较已有步骤级方法提升 0.9 分，且训练开销极低、推理速度无影响。

GenericAgent: A Token-Efficient Self-Evolving LLM Agent via Contextual Information Density Maximization

Fudan

GenericAgent 提出以「上下文信息密度最大化」为单一原则构建通用自演化 LLM Agent。系统包含：精简的工具接口（默认隐藏冗余字段）、分层记忆（按需展开摘要 vs 全量）、把历史交互固化为可复用的过程/代码模板、以及在长时序运行中持续保持信息密度的上下文管理层。在多个 Agent 基准上同时提升任务完成率与工具效率，token 与交互轮数均显著降低。

INSIGHT把 Agent 的 context 视为有限带宽资源，通过密度优化而非简单扩窗解决长时序成本爆炸。对搜索/推荐 Agent 的实践意义：线上多轮 Agent（深度搜索、复杂推荐解释）经常因检索结果与中间推理塞爆 context 导致延迟与费用飙升，借鉴该思路构建分层记忆 + 经验沉淀为代码模板，可大幅降低生产环境的 token 成本，并让 Agent 在多轮任务中保持稳定。

Jiaqing Liang, Jinyi Han, Weijia Li, Xinyi Wang, Zhoujia Zhang, Zishang Jiang, Ying Liao, Tingyun Li 等 18 人

Stateful Evidence-Driven Retrieval-Augmented Generation with Iterative Reasoning

本文将多跳问答建模为「证据渐进累积」过程：把每轮检索结果转换为带有相关性与置信度标记的结构化推理单元，存入持久化证据池；通过对证据池做 deficiency analysis 识别缺口与冲突，迭代生成新的检索 query 来补全证据。在多个多跳 QA 基准上稳定优于单轮 RAG 基线，且在显著的检索噪声下仍保持稳定表现。

INSIGHT把检索状态从「最近一次结果」升级为「跨轮可累积、带置信度的证据池」，是把 RAG 从单步问答升级为多跳推理的关键一步。对社区搜索的启示：复杂 query（如多约束的购物决策类提问）天然多跳，可借鉴该证据池设计，让搜索 Agent 在多轮检索间共享并校准证据，避免每轮独立检索带来的信息断层与重复召回。

Qi Dong, Ziheng Lin, Ning Ding

Forage V2: Knowledge Evolution and Transfer in Autonomous Agent Organizations

Forage V2 把单次任务式的探索 Agent 升级为「学习型组织」：通过多轮次运行积累并转移知识，引入审计分离、契约协议、组织记忆三类制度性安全机制。实证显示 6 轮运行后知识条目从 0 增长到 54、denominator 估计趋稳；用强模型生成的知识喂给弱模型可使覆盖缺口降低 5.5 个百分点、成本减半；3 次独立运行收敛到相同的 denominator（266），验证组织知识能跨实例自校准评估。

INSIGHT提出「denominator blindness」概念——开放世界 Agent 系统性低估任务范围，并给出制度化解法（组织记忆 + 跨模型知识转移）。对搜索 Agent 的启示：当 Agent 自主决定检索深度时容易自满终止；可借鉴该工作把跨用户/跨任务的探索经验沉淀为组织级知识库，作为在线 Agent 的「外部校准器」，既降低成本，也让弱模型继承强模型的探索能力。

Huaqing Xie

MTA-Agent: An Open Recipe for Multimodal Deep Search Agents

Salesforce

MTA-Agent 提供了一个完整开源的多模态深度搜索 Agent 训练食谱：构建经过验证的多步视觉-语言数据集（21K 高质量样本），覆盖数据/训练/评估全流程。32B 模型在多模态搜索基准上击败 GPT-5（51.86%）、Gemini-2.5-Pro（50.98%）和 Gemini-3-Pro。通过缓存交互回放显著降低训练成本，平均推理步数从 2.27 提升到 4.28，证明深度多步推理对多模态搜索的关键作用。

INSIGHT公开了端到端可复现的多模态搜索 Agent 训练管线，是当前少数能让中等规模 32B 模型超越超大闭源模型的开放方案。对社区搜索的实践意义：UGC 内容天然多模态（帖子常含图片），该工作给出了「数据合成 → 多步轨迹训练 → 缓存回放降本」的清晰范式，可直接借鉴用于训练社区图文搜索 Agent，无需依赖闭源大模型。

Xiangyu Peng, Can Qin, An Yan, Xinyi Yang, Zeyuan Chen, Ran Xu, Chien-Sheng Wu

Google Cloud Next 2026: Agentic AI tooling, A2A protocol, and Workspace Studio

Google

Google 在 Cloud Next 2026 宣布企业级 Agent 工具集：Agent Builder 升级、开放的 A2A（agent-to-agent）协议、Workspace Studio。重点是把多 Agent 协作从研究原型推向生产环境，提供跨 Agent 的标准通信协议、任务编排框架，以及 Agent 与企业数据/工作流的集成。给出了多个企业级 Agentic 搜索的真实案例（如基于内部知识库的智能问答 Agent）。

INSIGHTA2A 协议把多 Agent 协作的接口标准化（类似 MCP 之于工具调用），为生产环境的多 Agent 系统提供了关键基础设施。对搜索系统的启示：复杂业务（如社区搜索 + 个性化推荐 + 内容审核）天然需要多 Agent 协作，与其自研编排，不如关注 A2A、MCP 等开放协议生态；尤其在多团队、多模型的企业环境，标准化通信比单点 Agent 能力更重要。

Visual Reasoning through Tool-supervised Reinforcement Learning

Amazon

本文提出「Tool-supervised RL」范式训练多模态模型的视觉推理能力：使用 zoom-in、rotate、flip、绘图等可解释的视觉工具作为可监督的中间动作。训练分两阶段——先用工具特定奖励优化工具调用能力，再在保持工具使用的同时优化最终答案准确率，避免不同目标互相冲突。该 curriculum 设计高效培养了多步视觉推理能力。

INSIGHT把工具调用本身作为可监督的中间目标（而非只看终端答案）是个值得借鉴的训练范式。对搜索 Agent 的启示：当 Agent 调用 query 改写、过滤器、二次召回等多个工具时，可对每类工具设计独立的中间奖励（例如「query 改写后召回提升」「过滤器命中率」），通过 curriculum 先让 Agent 学会正确使用每类工具，再做端到端联合优化，能显著提升训练稳定性。

Qihua Dong, Gozde Sahin, Pei Wang, Zhaowei Cai, Robik Shrestha, Hao Yang, Davide Modolo
