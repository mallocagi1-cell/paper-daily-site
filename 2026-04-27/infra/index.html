Optimizing Large Batched LLM Inference with Global Prefix

BatchLLM 针对批量 LLM 推理场景重新设计 prefix 共享调度：传统 vLLM/SGLang 只在请求局部范围内复用前缀 KV-cache，本文提出全局前缀挖掘 + 全局调度，把具有相同前缀的请求重排到同一批次执行，使 KV-cache 在更大范围内被复用。在含共享前缀的 microbenchmark 上 token 节省率从 vLLM 的 40.1% 提升到 85.2%，端到端吞吐显著提升。

GEAR: An Efficient Error Reduction Framework for KV Cache Compression in LLM Inference

GEAR 提出一个面向 KV-cache 压缩的误差还原框架：在低比特量化的基础上，引入轻量误差校正分支与稀疏修正项，把压缩引入的精度损失迁移到一个可学习的低秩残差中。在主流 LLM 与长上下文任务上以约 4× 的 KV-cache 体积压缩仍保持接近全精度的生成质量，对长 query / 长会话场景的内存占用下降明显。

INSIGHT线上 LLM 重排或 Agent 服务的最大显存瓶颈往往不是模型权重而是 KV-cache，本文给出一条「量化 + 误差残差」式的压缩路径，工程上易与现有 paged-attention/vLLM 路径叠加。对社区搜索高 QPS 的多轮问答 / 长文本理解链路，可借鉴该方法显著扩大单卡并发上限，间接降低单 token 成本。

Scalable AI Inference: Performance Analysis and Optimization of AI Model Serving

系统性 profiling 当前主流 LLM serving 引擎（vLLM、SGLang、TensorRT-LLM）在生产负载下的瓶颈：KV-cache 管理、attention kernel、batching/scheduling、请求队列等环节的耗时分布与扩展性，并给出对应的优化建议（如调度参数、并行策略、kernel 选择）。给出基于真实 trace 的性能数据。

INSIGHT对正在选型/调优 LLM 服务栈的搜索团队是一份高价值参考——它把「该选哪个引擎」「调哪些 knob」从经验直觉转为可对比的量化曲线。对 UGC 搜索的 LLM 重排链路，可以直接照搬其 profiling 方法，定位自家集群在 prefill / decode / scheduling 上的真实瓶颈，避免盲目升级硬件或换框架。

Can You Trust the Vectors in Your Vector Database? Black-Hole Attack from Embedding Space Defects

本文揭示向量数据库存在「黑洞攻击」：攻击者只需在已存储向量的几何中心附近注入极少量恶意向量，即可让大范围 query 的 ANN 检索结果都落到这些恶意向量上。在多个开源向量数据库与主流 embedding 模型上系统验证了攻击的可行性与隐蔽性，并讨论了上线检测困难的原因。

INSIGHT对依赖向量召回的社区搜索/推荐链路是一记警钟——只要 UGC 内容贡献者能间接影响 embedding 索引（例如可发帖即可被入库），就存在中心化污染的攻击面。落地建议：在 ANN 索引侧增加几何中心点稠密度监测、对疑似中心点附近向量做来源审计与下线，并在 RAG 链路加入「答案与召回上下文一致性」校验。

05 3.45

vLLM-Omni: Fully Disaggregated Serving for Any-to-Any Multimodal Models

vLLM-Omni 把现有 vLLM/SGLang 的「文本生成 + 单 GPU 共置」假设彻底拆开，为多模态 any-to-any 模型设计完全解耦的服务栈：encoder、prefill、decode、modality-specific 后处理被拆到异构硬件上，通过统一调度层组合。多模态请求在 throughput 与 SLO 上较单体 vLLM 显著改善。

INSIGHT在社区搜索逐步进入「图文/视频混合 UGC」时代后，多模态生成与重排会成为基础能力。把 prefill / decode / 模态特化阶段解耦既能让昂贵的视觉 encoder 集中部署，也能让文本 decode 池保持通用 LLM 服务的高吞吐。是从今天的「贴一个多模态模型」升级到「多模态服务平台」的参考架构。

06 3.45

WorldDB: A Vector Graph-of-Worlds Memory Engine with Ontology-Aware Write-Time Reconciliation

WorldDB 是一种向量+图融合的 LLM Agent 长期记忆引擎，写入时即基于预定义本体进行去重与类型一致化（write-time reconciliation），让下游查询直接看到归一化后的事实图谱并与向量索引联动。强调把「记忆质量」前置到写入路径，而非依赖每次查询时再做实体消解。

INSIGHT对社区搜索 Agent 与 RAG 长期记忆是有意义的工程范式：把「实体消解 + 关系合并」从 query 时延中拿掉，挪到离线/写入时完成，可显著降低多轮 Agent 的检索时延与幻觉率。可借鉴其 ontology-aware write 思路，在 UGC 入库阶段就建立实体级别的归一化索引，而非全部交给 embedding 相似度。

07 3.35

Cache Saver: A Modular Framework for Efficient, Affordable, and Reproducible LLM Inference

Cache Saver 是一个面向研究/生产共用的 LLM 推理框架，把请求级缓存、提示模板缓存、序列级 KV 缓存解耦为三个可独立替换的模块，在中等规模工作负载上以较低工程成本获得显著的成本下降，并保证不同实验设置下的可复现性。

INSIGHT对中小型搜索/推荐团队是一份「便宜版 LLM 服务化」的可借鉴蓝本——尤其是在评估、AB 实验、离线脚本等场景，请求级与提示级缓存的复用率高、收益直接，工程成本远低于自建分布式 KV-cache 集群。可作为线上 vLLM 之外的「实验通道」基础设施。

Computational Caching-Empowered Collaborative LLM Inference Framework in VEC Networks

在车辆边缘计算（VEC）网络场景下提出一种协同 LLM 推理框架：通过引入计算缓存层，让多车之间复用相似请求的中间结果，减少端侧重复推理与回传带宽。在仿真环境下显著降低端到端时延与能耗。

INSIGHT其方法学「跨用户复用相似 query 的部分推理结果」对端侧/边缘部署的搜索助手有借鉴意义：在 UGC 短文本搜索这类高度同质化、长尾分布的请求中，对 query 做语义聚类后共享首段 prefill 或中间表征，能在 CDN/边缘节点降低重复算力。前提是有合适的隐私边界设计。
