Dual-Rerank: Fusing Causality and Utility for Industrial Generative Reranking

针对快手短视频搜索（每日数亿 query × 数百亿候选视频）的生成式重排难题，论文提出 Dual-Rerank 解决两大痛点：自回归模型精度高但推理慢、非自回归模型快但精度差；以及监督学习与强化学习目标错位。方法结合 Sequential Knowledge Distillation（蒸馏自回归 teacher 到非自回归 student）和 List-wise Decoupled Reranking Optimization（拆解 list-wise RL 信号实现稳定线上学习）。线上 A/B 实验显示用户满意度和观看时长双升，同时推理时延显著下降。

KEY INSIGHT · 对业务意味着什么生成式重排在工业搜推中的典型瓶颈是「精度 vs 时延」和「SFT vs RL」的双重 trade-off，本文给出的「自回归蒸馏 + 解耦 list-wise RL」组合拳值得搜索排序系统借鉴：在线上系统先用慢但准的自回归 teacher 离线生成排序信号，再蒸馏到快的非自回归 student 部署，可以同时保住相关性和时延预算。短视频搜索与社区 UGC 搜索（长尾 query、海量内容）量级相近，重排阶段可直接复用类似两段式优化框架。

Pre-trained LLMs Meet Sequential Recommenders: Efficient User-Centric Knowledge Distillation

AAIRISSber AI Lab

论文提出「LLM 离线生成用户画像 → 蒸馏到序列推荐模型」的高效融合框架，核心理念是把 LLM 的语义理解能力固化到传统 SR 模型权重里，线上服务无需调用 LLM。具体做法：用预训练 LLM 为每个用户生成自然语言画像（兴趣、消费偏好、行为模式），再通过知识蒸馏让 SR 模型在 forward 阶段隐式重建该画像。无需修改主干架构、不需要 LLM 微调、不需要 LLM 在线推理，serving 成本与原始 SR 模型一致。

INSIGHT对延迟敏感的搜索/推荐场景，「LLM 离线增强 + 传统模型在线 serving」是当前最务实的落地范式。该工作把 LLM 的产出从「item 增强」拓展到「用户画像增强」，给搜索系统留下两条可借鉴路径：(1) 用 LLM 离线生成 query 改写/意图标签作为蒸馏信号；(2) 把 LLM 对用户长期兴趣的总结蒸馏到 user encoder。社区 UGC 搜索的用户长期兴趣本就难以用 ID 特征建模，LLM 文本画像 + 蒸馏路线非常契合。

Filling the Gaps: Selective Knowledge Augmentation for LLM Recommenders

POSTECHKorea University

针对 LLM 直接做推荐器时「不同 item 知识覆盖不均」的核心问题（流行 item 信息丰富、长尾 item 信息缺失），论文提出 KnowSA_CKP：先用协同信号探针（Collaborative Knowledge Probe）评估 LLM 对每个 item 的内置知识强度，再仅对知识缺失 item 注入外部增强信息。该选择性增强策略既节省 LLM 上下文 token 预算，又避免对已熟知 item 重复添加噪声。无需 LLM 微调，零样本即可生效。在多个真实推荐数据集上效果与效率双提升。

INSIGHTLLM-as-Recommender 落地的最大瓶颈是上下文预算，「均匀增强所有 item」既费 token 又稀释信号。本文的「先探针、后选择性增强」是一个朴素但高 ROI 的工程范式：可迁移到搜索场景，只对长尾 query 或冷门文档做 LLM 知识注入，省去对头部内容的重复包装。对社区搜索来说，可结合点击日志识别哪些 query/post 是 LLM 已掌握的「热点」，对剩余 long-tail 才走 RAG/外挂检索路线，平衡相关性和成本。

Jaehyun Lee, Sanghwan Jang, SeongKu Kang, Hwanjo Yu

04 3.45

Deep Interest Mining with Cross-Modal Alignment for SemanticID Generation in Generative Recommendation

针对生成式推荐中 Semantic ID 生成的三大缺陷（语义压缩损失、文本-图像模态错位、SID 质量参差），论文提出三模块组合：DCIM（Deep Contextual Interest Mining）从广告上下文中挖掘深层语义信号；CMSA（Cross-Modal Semantic Alignment）借助视觉语言模型 VLM 对齐文本与图像表征；QARM（Quality-Aware Reinforcement Mechanism）通过强化学习为高质量 SID 加权。在多个公开生成式推荐基准上一致超越 SOTA SID 生成方法。

INSIGHTGenerative Recommendation 的「item tokenization」环节正成为竞争焦点——模型再强，SID 表达力不足就无法生成相关候选。本文给出三个对工业落地有用的 design choice：(1) 用 VLM 而非纯文本编码器构造 item embedding，对图文混合的 UGC 内容（带图帖子、视频缩略图）尤其重要；(2) 用 RL 机制反推 SID 生成质量，避免 RQ-VAE 离线训练后没有反馈闭环；(3) 接受 SID 不是「一锤子买卖」，需要持续迭代。社区搜索如果引入生成式召回，SID 质量是第一道关卡。

05 3.25

End-to-End Semantic ID Generation for Generative Advertisement Recommendation

Tencent

传统生成式推荐用「先训 embedding → 再做 RQ-VAE 量化 → 得到 SID」两阶段流水线，导致 embedding 与 SID 解耦优化。论文提出 UniSID 端到端框架：直接从原始广告数据联合优化 embedding 和 SID。核心机制：(1) 多粒度对比学习对齐不同语义层级的表达；(2) 广告重建任务作为辅助 loss，确保 SID 不丢失关键信息。在腾讯广告真实数据上 Hit Rate 提升最高 4.62%，验证端到端联合优化的有效性。

INSIGHT「embedding 与 tokenizer 解耦优化」是当前生成式推荐落地的隐形瓶颈：两阶段流水线导致 SID 既丢信息、又难调优。本文证明端到端联合训练可解锁 4–5% 的 Hit Rate 增量，对工业系统有直接借鉴意义。落地到搜索场景，可参考其多粒度对比学习思路：把 query-doc 对齐作为辅助任务，让 doc 的 SID 同时编码内容语义和检索相关性。重建任务亦可改造成 query 重建，强化 SID 对短文本的表达力。

Uncertainty-aware Generative Learning Path Recommendation with Cognition-Adaptive Diffusion

教育场景下，传统学习路径推荐难以处理两类不确定性：学习者「侥幸答对」「失误答错」造成的能力估计偏差，以及不同目标学习者需要差异化路径。论文提出 U-GLAD：(1) Gaussian LSTM 把认知状态建模为概率分布而非点估计，刻画不确定性；(2) 目标导向 attention encoder 为每个学习者定制概念 embedding；(3) 用扩散模型生成下一概念分布，跳出传统的 ranking 框架。3 个公开教育数据集验证有效性。

INSIGHT「概率化用户状态 + 扩散生成候选」是 GR 在长决策序列下的有趣组合。对搜索/推荐的启示：(1) 当 query 意图模糊或用户行为稀疏时，把用户兴趣建模为分布而非向量可改善 cold-start 表现；(2) 扩散式候选生成在 list-wise 场景下提供天然的多样性，比 ranking-then-mmr 更优雅。教育数据集量级和 UGC 短文本搜索差距较大，工业落地需要解决扩散步数与时延的取舍，但其概率建模思路在用户冷启动建模上可以借鉴。

Xiangrui Xiong, Hang Liang, Baiyang Chen, Zifei Pan, Yanli Lee
