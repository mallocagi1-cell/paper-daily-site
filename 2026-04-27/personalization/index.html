Mixture of Sequence: Theme-Aware Mixture-of-Experts for Long-Sequence Recommendation

针对长用户行为序列里『session hopping』（兴趣在 session 间突变、不连续）的问题，提出 Mixture of Sequence (MoS)：用 codebook+EMA 的主题感知路由保证语义一致的子序列被同一 expert 处理（Proposition 1），并以 Global/Item/Window 三类 expert 多尺度融合。Mamba4Rec / TransAct / TWIN / SDIM 四个 backbone × 三公开数据集，AUC/GAUC 平均 +0.68% / +0.72%，FLOPs 约比同规模 MoE 低 50%。

KEY INSIGHT · 对业务意味着什么把『一条长序列由一个模型吃完』拆成『多个 expert 按主题分工』是抓住 session hopping 的关键。Codebook + EMA 取代标准 top-k routing 大幅降低专家坍塌风险，三阶段训练让 MoE 工业可控。对社区搜索/推荐里用户兴趣多样、跨版块切换频繁的场景非常对位，n=4 expert 即饱和，可作为长序列 backbone plug-in。当前缺线上 A/B 数据是落地前最大未知数。

The Tencent Advertising Algorithm Challenge 2025: All-Modality Generative Recommendation

Tencent

Tencent 公开 2025 广告算法挑战赛数据与方案：覆盖图片、视频、文本三模态生成式推荐。论文总结基线、获胜解法与离线 AUC 提升，多数 top 方案是『模态感知 embedding + 序列排序头』的组合。该挑战为工业广告里的生成式推荐提供了可复现公开基准。

INSIGHT工业级公开基准对社区/UGC 排序团队是稀缺资源——多模态 + 生成式 + 排序的组合贴近真实业务。挑战赛的获胜模板（modality embedding 接序列排序头）是值得在 UGC 帖子混排里直接复用的实操路径，无需从零摸索。

ADS-POI: Agentic Spatiotemporal State Decomposition for Next Point-of-Interest Recommendation

针对单状态用户表示在下一个 POI 推荐里的行为纠缠问题，ADS-POI 把用户行为分解到多个并行的潜在子状态，每个子状态以 agentic 框架关注用户时空上下文的不同侧面。在 Foursquare 和 Gowalla 上 Hit@10 与 NDCG@10 持续优于单状态 baseline。

INSIGHT『多状态 + agentic』是对传统单一 user embedding 的有力反思。把意图拆成多子状态可缓解长行为序列里的语义干扰，思路可迁移到 UGC 搜索的 query intent 分解、多目标排序。落地需考虑子状态数量与推理成本之间的权衡。

Zhenyu Yu, Chunlei Meng, Yangchen Zeng, Mohd Yamani Idna Idris, Shuigeng Zhou

Following the Eye-Tracking Evidence: Established Web-Search Assumptions Fail in Carousel Interfaces

通过眼动追踪实验证明：单列搜索结果上的 F-pattern、examination hypothesis 等假设并不适用于 carousel 流式界面，基于这些假设的 click model 与排序评估指标存在系统性误判。作者提出针对 carousel 布局校准过的 examination model，更贴近真实点击行为。

INSIGHT对社区/电商常用的卡片流、横滑 carousel UI，传统 PBM/UBM 类 click model 直接套用会偏。论文给出的校准 examination model 是工业团队自建 click model 时可直接借鉴的形式，能改善偏差校准与 CTR 模型训练的样本权重。

Jingwei Kang, Maarten de Rijke, Harrie Oosterhuis

Revisiting Content-Based Music Recommendation: Efficient Feature Aggregation from Large-Scale Music Models

重新审视基于内容的音乐推荐：以大规模自监督音乐编码器抽取的内容表征，配合高效特征聚合，能在召回与 CTR 任务上达到与协同过滤平齐的性能，并在冷启动区间显著领先。论文给出在生产音乐推荐日志上的对比结果。

INSIGHT结论可推广到 UGC 短文本：当大语料预训练编码器（如多语 BERT、多模态 CLIP）的内容表征质量足够高时，纯内容路线在长尾 / 冷启动上能稳定打过协同过滤。聚合方式（pooling、selector）的工程细节是发挥潜力的关键。

CaST-POI: Candidate-Conditioned Spatiotemporal Modeling for Next POI Recommendation

现有 POI 排序模型把用户历史轨迹一次性编码成单一表示后复用于所有候选 POI 的打分，丢失了候选感知信号。CaST-POI 提出候选条件化的时空建模——用户历史表示按候选 POI 进行调制，在标准 POI 数据集上取得显著提升，推理成本可控。

INSIGHT『user repr 一次编码、所有候选共享』是搜推系统的常见简化，CaST-POI 反向证明 candidate-conditioned 的 user 编码值得付一些算力。这种 cross-attention 形态可下沉到精排/重排的候选交互层，对 UGC 短文本里 query-doc 相关性建模也有迁移价值。

Zhenyu Yu, Chunlei Meng, Yangchen Zeng, Mohd Yamani Idna Idris, Jihong Guan, Shuigeng Zhou

Collaborative Filtering Through Weighted Similarities of User and Item Embeddings

用一个加权融合 user-similarity 与 item-similarity 的简单集成方法，结合学得的 embedding，在 MovieLens、Yelp 等基准上与现代神经协同过滤打平，在交互图稀疏时与序列模型有竞争力。作者强调它是被近期工作忽略的强基线。

INSIGHT提醒：社区/UGC 团队上线复杂神经召回前，先把 user-CF + item-CF 加权集成 baseline 跑稳，是性价比最高的对照实验。简单基线在稀疏长尾上反而更鲁棒，能让后续复杂方案的增益归因更可信。

Adaptive Knowledge Transfer for Cross-Disciplinary Cold-Start Knowledge Tracing

针对跨学科知识追踪的小样本冷启动问题，提出基于门控机制的自适应跨域映射桥与对抗判别器：前者动态接桥源/目标域特征，后者强制特征分离。在 20 个极端跨学科冷启动场景上稳定优于现有迁移学习 baseline。WWW '26 接收。

INSIGHT『门控映射 + 对抗特征分离』是跨域冷启动的通用范式。社区里新版块、新兴趣点的冷启动场景可借鉴：把已成熟版块的用户行为做源域，新兴版块做目标域，加一个对抗判别器避免负迁移。比纯 meta-learning 更易在工程侧落地。

Two Heads Are Better Than One: Generalized Cross-Domain Federated Learning via Dual-Prototype

已录用 KDD 2026

针对跨域联邦学习中『单一聚合 prototype 难以同时表达共性与特异性』的问题，提出 Dual-Prototype 框架：双原型分别承担域共享与域特异表达，由轻量校准头完成对齐。KDD '26 接收，覆盖跨域推荐、跨平台用户建模等场景。

INSIGHT对多 App / 多业务线共享用户兴趣却又要保护隐私的场景，dual-prototype 给出比 FedAvg 更细粒度的方案。在隐私要求收紧、跨业务复用兴趣信号需求上升的趋势下，是值得跟进的工程范式。落地难点在客户端算力与原型同步频次的权衡。
