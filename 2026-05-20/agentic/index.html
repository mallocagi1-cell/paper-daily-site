SD-Search: On-Policy Hindsight Self-Distillation for Search-Augmented Reasoning

搜索增强推理 agent 在内部推理与外部检索调用之间交替，整条 rollout 只有一个轨迹级 outcome reward，单次 search query 拿不到 step 级信用。已有 process-supervision 方法要么依赖更大的 teacher 模型，要么依赖外部系统标注的子问题。SD-Search 让同一个模型扮演两个只在 conditioning 上不同的角色：student 只看推理时可见的上下文，teacher 额外条件于一段紧凑的 hindsight block（汇总本次 rollout 发出的 search query 与最终成败）。训练时在每个 search 决策点最小化 student 与 teacher 输出分布的 Jensen-Shannon 散度，把 step 级信号叠加到轨迹 reward 上，整个过程在标准 RL 训练 loop 内完成，不需外部 teacher 推理、额外标注或辅助训练阶段。

KEY INSIGHT · 对业务意味着什么核心是用 on-policy hindsight self-distillation 做 query 级信用分配：teacher 知道哪些 rollout 成功，其 query 分布隐式标出哪些 search 决策值得做，再用 JS 散度蒸馏回 student。对社区搜索的启示是，用 LLM 做多轮 query 改写或迭代检索时，可用同一模型加后见上下文构造 step 级监督，省掉维护更大 teacher 或人工标注子问题，降低 query 改写策略训练的标注与算力门槛；hindsight block 只传 query 摘要与成败这一极简接口，本身就是一种轻量信用分配设计。

OPERA: A Reinforcement Learning-Enhanced Orchestrated Planner-Executor Architecture for Reasoning-Oriented Multi-Hop Retrieval

面向复杂推理型多跳检索，OPERA 指出现有 RAG 的三个失效点：规则式 decomposer 在非模板问题上规划差、有限的 query 改写导致迭代检索打转找不到 golden doc、缺乏细粒度推理无法从噪声结果里过滤有用信息，根因是检索与推理弱耦合。方法上拆成 Goal Planning Module（把复杂问题分解成可执行子目标）与 Reason-Execute Module（按子目标做精确推理与有效检索），并提出 Multi-Agents Progressive Group Relative Policy Optimization（MAPGRPO）——GRPO 的多 agent 渐进式变体，对规划与检索全链路做 RL 优化。论文已被 AAAI 2026 接收，在复杂多跳基准上优于现有方法。

INSIGHT把 planner 与 executor 拆成独立 agent、用 MAPGRPO 分阶段做 RL，是缓解检索-推理弱耦合的一条可借鉴路径。对社区搜索的复杂 query（多实体、多条件问答帖检索），可借鉴 Goal Planning Module 的子目标分解加 Reason-Execute 的逐目标检索结构，把一次性 query 改写换成带推理的迭代检索；MAPGRPO 的多 agent 渐进式 group-relative 优化也提示，当规划和执行两个角色 reward 尺度不同时，分阶段训练比端到端联合训练更稳。

DecoupleSearch: Decouple Planning and Search via Hierarchical Reward Modeling

Agentic RAG 引入自主 agent 后面临三个问题：每一步成败同时依赖高质量 planning 和准确 search、中间推理步骤缺监督、planning 与 search 的候选空间随步数指数膨胀。DecoupleSearch 用 dual value models 把 planning 和 search 解耦，分别独立优化 plan reasoning 与 search grounding；构造一棵 reasoning tree，每个节点代表一次 planning 加 search 步，用 Monte Carlo Tree Search 评估每步质量，推理时再用 Hierarchical Beam Search 迭代精炼候选。论文发表于 EMNLP 2025，在不同参数规模的 policy 模型上验证有效。

INSIGHT用两个独立 value model 分别建模 planning value 与 search value，是给 Agentic RAG 中间步骤补监督的可操作方案：plan 对不对、检索 grounding 准不准分别打分，避免单一 outcome reward 把两类错误混在一起。社区搜索若上 agentic 多轮检索，可借鉴 reasoning tree 加 MCTS 做离线 step 质量估计、再用 Hierarchical Beam Search 控制线上候选爆炸；dual value 解耦也适用于召回质量与改写规划质量需要分别归因的场景。

SCICONVBENCH: Benchmarking LLMs on Multi-Turn Clarification for Task Formulation in Computational Science

现有 LLM 科学助手基准默认问题已 well-posed，只评知识检索、推理、代码、工具调用；但真实科学协助往往从 ill-posed 请求开始，必须先经多轮对话澄清才能可靠计算。SCICONVBENCH 在流体力学、固体力学、材料科学、偏微分方程四个计算科学领域构造多轮澄清基准，针对两类互补能力：disambiguation（主动追问缺失信息）和检测并纠正含内部矛盾的错误请求。这把评测向任务表述阶段前移，把对话澄清能力从笼统的指令遵循中单独拆出来量化。

INSIGHT对社区搜索的直接价值在 query 理解：用户短文本 query 常常 ill-posed，信息缺失或自相矛盾。SCICONVBENCH 把主动追问缺失信息和识别并纠正矛盾输入拆成两个可独立度量的能力，正好对应搜索里的 query clarification 与 query 纠错。可借鉴其评测协议来设计对话式搜索与澄清式 query 改写的离线评估，先衡量是否该追问、追问什么，再衡量检索质量，而不是把澄清能力混在端到端相关性指标里。

Nithin Somasekharan, Youssef Hassan, Shiyao Lin, Gihan Panapitiya, Patrick Emami

Empirical Research Assistance (ERA): From Nature publication to catalyzing Computational Discovery

Google

Google Research 公布 ERA（Empirical Research Assistance），一个基于 Gemini、用 tree search 做科学计算实验迭代的 deep-research agent，成果发表于 Nature（2026-05-19）。给定科学问题与成功判据，ERA 会检索文献、生成代码、探索多种解法、组合不同技术并评估结果，针对目标在上千个候选选项中做 tree search 优化输出代码。在基因组学、公共卫生、卫星影像分析、神经科学预测、时间序列预测、数学等多个基准上达到专家级表现。这是工业界把 deep research agent 用于真实科研发现的代表性实践，并经 Nature 同行评审验证。

INSIGHTERA 的可借鉴点是目标判据加 tree search over 上千候选解法这一 agent 框架：把开放问题转成给定 success criteria 的搜索问题，让 agent 在解法空间里组合检索、代码、评估并自评。对社区搜索的迁移意义在于，复杂检索任务（多步信息聚合型 query）也可建模成带显式成功判据的 tree search，用自评信号筛选检索-推理路径；Nature 级验证说明这类 deep research agent 的可靠性边界已能支撑高价值场景，但依赖闭源 Gemini，落地需自研同等规模 policy。

Eser Aygün, Gheorghe Comanici, Shibl Mourad, Lizzie Dorfman, Michael Brenner et al.

MementoGUI: Learning Agentic Multimodal Memory Control for Long-Horizon GUI Agents

GUI agent 在长程任务里要跨多次界面跳转维护任务状态，现有做法要么原始历史回放（冗余截图淹没模型），要么纯文本 memory（丢掉后续决策需要的局部视觉证据）。MementoGUI 是一个可插拔的 agentic memory 框架，给 MLLM GUI agent 配一个学习得到的 controller MementoCore，做在线的 memory 选择、压缩与检索：把长程 GUI 控制建模成在线 memory-control 问题，working memory 选择性保留任务相关界面事件（文本摘要加 ROI 级视觉证据），episodic memory 检索可复用的历史轨迹。memory 不再是固定上下文，而是被主动管理的对象。

INSIGHTMementoCore 这种学一个 memory 控制器、在线决定记什么、压多少、取哪段的设计，对任何长程 agent（含 agentic 搜索、deep research）的上下文管理都通用。社区搜索若做多轮会话式检索，可借鉴其 working 与 episodic 双层 memory：working 层保留当前 query 相关的检索证据摘要，episodic 层复用相似历史会话的检索轨迹，避免把全部历史塞进上下文；ROI 级证据保留也提示，压缩 memory 时要保留可定位的细粒度证据而非只留文本摘要。

Ziyun Zeng, Hang Hua, Bocheng Zou, Mu Cai, Rogerio Feris

RAPT: Retrieval-Augmented Post-hoc Thresholding for Multi-Label Classification

工业多标签文档理解流水线先给候选标签打分再阈值或排序成标签集，这一早期选择步骤直接影响下游抽取精度与人工核验成本。实践中 OCR 噪声、标签不均衡、实例相关的标签基数、错误代价不对称会让全局分数阈值很脆、随文档格式演化难维护。RAPT 是一个面向部署的 retrieval-augmented 分数阈值 wrapper，post-hoc 套在已有分类器外、无需重训：只要预测器能给出用于相似检索的文档表示与每标签置信度（度量学习 encoder、微调 transformer 分类器均可），就能用检索到的相似文档动态决定阈值，是模型无关的轻量改造。

INSIGHTRAPT 的可迁移点是用检索近邻动态定阈值替代全局静态阈值，且 post-hoc、模型无关、不重训，这正是搜索排序与相关性二分阈值的常见痛点。社区搜索里相关与不相关的截断阈值常因 query 分布漂移而失效，可借鉴 RAPT：用 query 或 doc 表示检索相似历史样本，按近邻局部确定截断阈值，作为现有相关性模型的外挂层，部署成本低、不动主模型，适合先做小流量验证。

Lasal Jayawardena, Nirmalie Wiratunga, Ikechukwu Nkisi-Orji, Darren Nicol

SkillsVote: Lifecycle Governance of Agent Skills from Collection, Recommendation to Evolution

长程 LLM agent 的轨迹本可沉淀成可复用经验，但原始轨迹噪声大、难治理。SkillsVote 把 Agent Skill 当作经验 schema，把可执行脚本与非执行的流程指引耦合在一起。开放 skill 生态里存在冗余、质量参差、环境敏感的产物，盲目更新会污染后续上下文。SkillsVote 提出从采集、推荐到演化的 skill 生命周期治理框架：先对百万级开源语料按环境需求、质量、可验证性做 profiling，再为可验证的 skill 合成任务；执行前对结构化 skill 库做 agentic library search 暴露指引性 skill 上下文，执行后把轨迹分解成 skill 关联子任务，把结果归因到 skill 使用、agent 探索、环境等因素。

INSIGHTSkillsVote 把 agent 经验复用做成带质量门禁的生命周期：采集时按可验证性筛、推荐时做 agentic library search、演化时按归因决定是否更新，避免经验库被低质轨迹污染。对搜索与推荐侧自研 agent 平台有参考价值——沉淀 query 改写模板、检索策略等技能时，需要类似的可验证性 profiling 和执行后归因机制，否则技能库随规模增长会反噬上下文质量；执行后把成败归因到 skill、探索、环境的拆分，也是 agent 经验治理可直接借用的评估维度。

Hongyi Liu, Haoyan Yang, Tao Jiang, Bo Tang, Feiyu Xiong

AI for Auto-Research: Roadmap & User Guide

AI 辅助科研正越过一个门槛：全自动系统已能以约 15 美元生成一篇研究论文，长程 agent 能执行实验、起草手稿、模拟评审。但这一生产力前沿暴露更深的诚信问题——在科研压力下，即便前沿 LLM 仍会编造结果、漏掉隐藏错误、无法可靠判断新颖性。本文研究截至 2026 年 4 月的进展，按四个认识论阶段对研究全生命周期做端到端分析：Creation（想法生成、文献综述、编码与实验、表格与图）、Writing（论文写作）、Validation（同行评审、rebuttal 与修订）、Dissemination（海报、幻灯、视频、社媒、项目页、交互 agent），识别出可靠协助与不可靠自动化之间一条随阶段变化的清晰边界。

INSIGHT这是一份 deep research 与 auto-research agent 的领域路线图，价值在于给出哪些阶段 agent 已可靠、哪些仍不可靠的 stage-dependent 边界，而非新方法。对要做 deep research 类搜索产品的团队，可借鉴其四阶段划分（Creation、Writing、Validation、Dissemination）来界定 agent 能力边界：文献检索与编码实验阶段相对可靠，而新颖性判断、隐藏错误检测仍需人审，提示在搜索型研究助手里把检索加综合自动化、把结论可信度判断留给人审或显式验证模块。

Lingdong Kong, Xian Sun, Wei Chow, Linfeng Li, Kevin Qinghong Lin

AtlasVA: Self-Evolving Visual Skill Memory for Teacher-Free VLM Agents

VLM agent 越来越依赖 memory-augmented RL 跨长程任务复用经验，但多数框架把 memory 存成文本、且依赖闭源 teacher 模型来总结或精炼，这与空间决策不匹配：几何先验被压成有损语言，稀疏交互只能靠延迟的文本反馈监督。AtlasVA 主张可复用经验应保持视觉 grounded，提出 teacher-free 的视觉技能记忆框架，把 memory 组织成三层互补结构：spatial heatmaps、visual exemplars、symbolic text skills；并直接从轨迹统计与轻量网格启发式演化出 danger 与 affinity atlas，把这些自演化 atlas 作为势函数复用，全程不需 teacher 模型。

INSIGHTAtlasVA 的两点对 agent 记忆设计有一般性启发：一是 teacher-free，用轨迹统计加轻量启发式自演化经验图，省掉对更大 teacher 的依赖（与本期 SD-Search 的无外部 teacher 思路呼应）；二是分层记忆要按模态保留信息，视觉用 heatmap 与 exemplar 而非全压成文本，避免有损语言化。虽然其本身是视觉空间决策、与 UGC 文本搜索业务相关性低，但自演化加模态保真的分层 memory 可作为搜索侧长程 agent 记忆结构的对照设计。

Pan Wang, Yihao Hu, Xiujin Liu, Jingchu Yang, Hang Wang
