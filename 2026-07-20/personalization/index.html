Aligning Recommendations with User Popularity Preferences

针对推荐系统把热门内容一刀切地推给所有用户、进而放大头部效应的问题，论文提出 Popularity Quantile Calibration 衡量个人历史偏好与推荐结果的流行度错配，并用 SPREE 在推理阶段沿流行度方向自适应调节序列模型激活。多数据集实验显示，该方法持续改善用户级校准，同时基本保持推荐准确率。

LRSA: LLM-RecSys alignment for time-specific next POI recommendation.

SShanghai University

针对下一兴趣点推荐中 ID 行为偏好与大模型文本知识存在语义鸿沟的问题，LRSA 先筛选高影响轨迹微调大模型，再以旋转对齐把用户偏好和 LLM token 映射到统一空间，并通过分层提示融合轨迹与地点文本。在 NYC、TKY、Gowalla 上，Acc@1 相对最新 ID/LLM 方法平均提升 24.39%/9.93%，NDCG@5 提升 25.26%/12.79%。

INSIGHT该方法表明，LLM 接入个性化排序的瓶颈往往不是模型知识不足，而是行为 ID 空间与语言空间没有对齐。社区搜推可借鉴“高价值序列采样—轻量旋转映射—分阶段提示学习”的渐进路径，把短文本语义注入既有用户序列模型；但 POI 的时空先验较强，迁移前应在 UGC 点击序列上重做消融与延迟评估。

Jinhui Zhu, Xiangfeng Luo, Xin Yao, Xiao Wei

03 3.40

LLM-UP: SIGIR 2026 Workshop on LLM-powered User Profiling for Search and Recommendation.

UQAAnhui UniversityGriffith University

LLM-UP 聚焦用大模型从自然语言和行为记录中抽取、归纳并推理用户偏好，系统讨论传统手工特征或纯交互画像难以覆盖的意图、上下文和时间变化。SIGIR 2026 议程包含自动用户画像、可验证生成式推荐和双意图表示等工作，并集中梳理画像保真度、动态更新、评测、隐私及责任部署问题；该条目为研讨会综述，不报告统一基准结果。

INSIGHT对社区搜索与推荐团队，LLM 用户画像更适合作为可解释的旁路特征和评测对象，而非直接替换稳定的 ID 行为塔。可先用画像摘要增强冷启动和长尾兴趣，再通过可验证约束、时间衰减与隐私隔离控制幻觉和陈旧偏好；由于研讨会证据以议题汇总为主，落地前仍需建立离线增益、线上 CTR 与画像一致性的联合实验。

Hongzhi Yin, Wei Yuan, Yi Zhang, Joel Mackenzie, Quoc Viet Hung Nguyen
