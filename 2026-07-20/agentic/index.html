SmartSearch: Process Reward-Guided Query Refinement for Search Agents

论文针对搜索 Agent 多轮推理中间查询质量差、一次偏航拖垮整条轨迹的问题，提出双层信用评估、低质查询定点改写与 SFT→DPO→GRPO 三阶段训练。基于 Qwen2.5-3B，在四个知识密集型基准上平均 EM/F1 达 37.5/47.2，较次优方法分别提升 25%/19%。

DeepResearch-9K: A Challenging Benchmark Dataset of Deep-Research Agent

BaiduCityUSShenzhen Technology University

论文发布 DeepResearch-9K：包含 9000 个可验证问题、三级难度和 Tongyi-DeepResearch-30B-A3B 生成的完整检索轨迹，并开源支持多轮联网、GRPO/PPO 与多种奖励的 DeepResearch-R1。教师模型总准确率仅 55.84%，最高难度降至 23.73%，显示长链搜索仍有巨大缺口。

INSIGHT数据集把难度直接绑定到工具调用深度：最高级任务至少需要 15 次独立搜索，并通过实体遮蔽与跨文档约束阻断关键词捷径。搜索团队可用同样方法构造复杂 UGC 调研集，把最终正确率与搜索次数、轨迹质量同时纳入离线评估，再比较 Zero-RL 和 SFT+RL 的收益。

Tongzhou Wu, Yuhao Wang, Xinyu Ma, Xiuqiang He, Shuaiqiang Wang, Dawei Yin, Xiangyu Zhao

阿里云百炼知识库（Knowledge Studio）：迈入 Agentic RAG 4.0时代

Alibaba

Knowledge Studio 将意图理解、查询改写、知识库路由、多轮检索、结果验证和可溯源生成串成 Agentic RAG 闭环，提供语义搜索、章节浏览、精读、页面浏览、SQL 和文件获取 6 类工具。系统最多联合 15 个知识库，并以 qwen3-vl-rerank 统一图文跨库排序。

INSIGHT企业级 Agentic RAG 的关键不是无限增加检索轮次，而是给模型分层工具和明确停止条件：先路由知识库，再选择粗搜、章节浏览或精读，结构化问题切到 SQL。社区搜索可借鉴跨库权重与统一重排，把帖子、问答、评论等异构索引先校准再交给 Agent 验证，避免直接拼接不可比的分数。

基于 PostgreSQL 构建 Agentic RAG 应用

Tencent

腾讯云给出以 PostgreSQL 为数据底座的 Agentic RAG 架构，将关系数据、向量检索、查询优化、多步推理和工具调用放进统一链路。Agent 可根据问题主动规划检索策略并迭代补充证据，适合同时依赖文档片段与结构化业务字段的企业知识问答，但文档未披露量化基准。

INSIGHT对搜索系统最有价值的是“检索与计算共库”思路：语义召回负责找到 UGC 证据，SQL 负责精确过滤、聚合和权限约束，Agent 只做路由与循环控制。落地时应先限定最大反思轮数、工具白名单与召回范围，并分别记录向量检索、SQL 和生成阶段耗时，防止复杂问题拖垮尾延迟。
