An Efficient Framework for Whole-Page Reranking via Single-Modal Supervision

针对搜索结果页同时混排文本、图片、视频和大模型答案时整页标注成本过高的问题，论文提出 SMAR：先训练各模态排序器，再筛选预算受控的跨模态页面做少量标注，并蒸馏模态内偏好。Qilin 与 CrossRank 实验将标注成本降低 70%—90%，仍超过全量标注基线，并在百度 App 完成离线与在线 A/B 验证。

02 4.15

REaR: Retrieve, Expand and Refine for Effective Multitable Retrieval

Microsoft

REaR 面向需要联合多张表回答问题的检索任务，将流程拆成检索、扩展、精炼三步：先找语义相关表，再用预计算列向量补入可连接表，最后剪除弱关联噪声。方法无需 LLM，在 BIRD、MMQA、Spider 上兼容稠密与稀疏检索；以 BGE 为例，MMQA 全召回率由 60.18% 提升到 65.83%，并改善下游 SQL 执行。

INSIGHT该方法把“query 与单文档相关”扩展为“候选之间能否组合”，说明多源检索不能只按独立相似度取 Top-K。社区搜索若要联合帖子、评论、作者与地点等异构内容，可离线计算字段或实体的可连接性，在首轮召回后补齐结构上相关的证据，再用轻量精炼恢复精度，避免在线调用大模型带来的成本。

Rishita Agarwal, Himanshu Singhal, Peter Baile Chen, Manan Roy Choudhury, Dan Roth, Vivek Gupta

Don’t Be Misled by Style: A Style-Adaptive Reranker for Capturing Effective Knowledge in Retrieval-Augmented Generation

针对开放域 RAG 语料风格混杂、重排器容易把文风误当相关性的现象，论文提出 SARK。它让 LLM 同时生成段落级“有助/有害”标签和列表级相对偏好，再以风格增强的多任务学习联合优化 2 类目标。ACL 2026 的多模型实验显示，SARK 在混合风格条件下持续提升下游生成表现。

INSIGHTSARK 将监督焦点从表面语体转向“这段内容是否真正帮助回答”，并用点级分类与列表级排序互相校准。UGC 搜索中的口语、营销文案、模板化笔记和专业长文风格差异很大，可仿照该方案构造内容效用标签与风格扰动样本，降低 ranker 对文风、长度和格式捷径的依赖。

Ruwen Zhang, Bo Liu, Zhang Sheng Xiang, Yida Chen, Hantao Zhao, Ding Ding, Jiahui Jin, Jiuxin Cao

A Neighborhood Re-Ranking Model With Relation Constraint for Knowledge Graph Completion

论文研究知识图谱补全中的候选重排：现有模型依赖已观测事实隐式学习实体语义，且图神经网络聚合邻居时容易混入噪声。作者把关系约束与三元组结构信息显式注入邻域重排，分别建模源实体更新和邻域对目标预测的作用，以无额外类型标注的方式增强缺失链接判断。

INSIGHT可迁移价值在于把“邻域证据”从统一聚合改成受关系约束的独立重排信号，避免高连接节点或无关邻居淹没真正匹配项。社区搜索若已有用户、帖子、话题和地点图，可将 query 意图或关系类型作为门控条件，对图召回候选二次排序，而不是把所有邻域特征直接拼入主排序模型。

A scorecard for the AI age

OpenAI

文章提出用“每美元有用智能”替代席位数、活跃用户或单 token 成本来衡量 AI 系统，拆成 4 个问题：完成了多少有价值工作、每次成功任务的全链路成本、结果是否可靠、规模扩大后单位投入是否产出更多价值。它强调把重试、人工复核和失败成本纳入成功任务口径。

INSIGHT对 LLM 搜索功能，离线 nDCG 或模型调用单价不足以说明上线价值；更实用的仪表盘应把成功搜索会话、答案可靠率、人工兜底量、端到端成本与用户任务完成率联动。该框架可用于约束 query 改写、重排和答案生成的级联预算，但文章是管理实践框架，缺少对照实验，需结合自有 A/B 数据验证。

Sarah Friar
