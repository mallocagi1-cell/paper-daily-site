DREAM: Dense Retrieval Embeddings via Autoregressive Modeling

DREAM 针对稠密检索依赖人工标注正负样本对的痛点，提出用大模型自回归 next-token prediction 损失来监督检索器训练：将检索器算出的 query-文档相似度分数注入冻结 LLM 的部分注意力头，相似度决定 LLM 预测目标输出时对各候选文档的注意力权重，由此产生的预测损失通过注意力机制把梯度回传给检索器。在 BEIR 与 RTEB 两个检索基准、0.5B 到 3B 的多种 backbone 上，DREAM 一致超过现有基线。

Unifying Search and Recommendation in LLMs via Gradient Multi-Subspace Tuning

Leiden University

论文面向搜索与推荐(S&R)统一建模，将两者排序都改写成 LLM 上的条件生成，但指出全参数微调成本高、PEFT 又面临两大问题：任务间梯度冲突，以及过拟合微调数据导致用户意图理解漂移、损害通用知识。作者提出 GEMS(Gradient Multi-Subspace Tuning)：用 Multi-Subspace Decomposition 把共享与任务特定的优化信号拆到互补的低秩子空间以减少梯度相互干扰，用 Null-Space Projection 把参数更新约束在与通用知识空间正交的子空间内以抑制意图漂移。在基准数据集上，GEMS 在搜索和推荐任务上均超过 SOTA 基线。

INSIGHT该工作把"统一 S&R"的难点精确定位到 PEFT 下的梯度冲突与灾难性遗忘两点，并各给一个低秩子空间手段——对同时承载搜索与推荐的社区平台有直接借鉴：用一套 LLM + 子空间 LoRA 服务两条链路，省去维护两套模型。Null-Space Projection 保护通用域知识的思路，也适用于在垂域语料上微调时避免削弱大模型原有的语义理解能力。

Jujia Zhao, Zihan Wang, Shuaiqun Pan, Suzan Verberne, Zhaochun Ren

03 3.15

Reasoning over Semantic IDs Enhances Generative Recommendation

USTCNUS

SIDReasoner 研究生成式推荐中"对 Semantic ID(SID)做推理"的问题：现有生成式推荐把序列推荐写成"语言 token + 物品 SID token"统一空间上的自回归生成，但 itemic token 对 LLM 不具天然语义、推荐式 SID 推理又难评估、监督稀缺。方案分两阶段：先用更强教师模型合成的 SID 中心语料做多任务训练强化 SID-语言对齐，把物品 token 接地到语义与行为上下文；再用 outcome-driven 强化优化引导模型走向有效推理轨迹，无需显式推理标注。在三个真实数据集上，推理增强的 SID 生成式推荐在准确率、可解释性和跨域泛化上均有提升。

INSIGHT核心洞察是"生成式推荐能否推理，瓶颈在 SID 与语言的对齐"——不堆推理标注，而是先把物品 token 对齐到语言语义，再用结果驱动 RL 自举推理能力。对落地生成式推荐的团队，启示是 SID tokenizer 不能只看码本重建质量，更要看其语言可读性/对齐度；跨域泛化提升也说明对齐良好的 SID 有助于冷启动与跨场景迁移。

Yingzhi He, Yan Sun, Junfei Tan, Yuxin Chen, Xiaoyu Kong, Chunxu Shen, Xiang Wang, An Zhang 等 9 人

Verifiable Reasoning for LLM-based Generative Recommendation

MetaUSTCNUS📖 深度解读 · 16 分钟 →

VRec 针对 LLM 生成式推荐中"先推理再推荐反而掉点"的推理退化问题，提出 reason-verify-recommend 范式：在推理过程中交错插入验证以提供可靠反馈。作者确立两条设计原则——可靠性(验证须准确评估中间推理)与多维性(覆盖多个用户偏好维度)，并用多个 verifier 加 proxy prediction 目标实现，在不牺牲效率的前提下提升推荐质量与可扩展性。在四个真实数据集上，VRec 优于推理与非推理基线。

INSIGHT该工作点明"加了思维链不一定有用"，把可靠的中间验证作为生成式推荐推理的关键——这与 OneRec 系列"thinking 模式未必优于 non-thinking"的观察互相印证。对工程实践的启示：推荐里引入推理时要配套可验证的奖励/验证信号(多维 verifier)，否则推理可能引入噪声；proxy prediction 目标是一种低成本获取验证信号的可借鉴做法。作者含 Meta 团队成员，方向偏工业可扩展性。

Xinyu Lin, Hanqing Zeng, Hanchao Yu, Yinglong Xia, Jiang Zhang, Aashu Singh, Fei Liu, Wenjie Wang 等 11 人

Dialogue to Discovery: Attribute-Aware Preference Elicitation for Conversational Product Search Assistants

Adobe

Dialogue to Discovery(D2D)面向对话式商品搜索助手的偏好澄清问题：屏幕位有限、过早推荐易错配、过度追问又拖长对话导致流失。D2D 以商品属性结构为核心做属性导向的偏好澄清，自适应优先提出信息量最大的问题，并择时给出推荐，减少过早或偏离的建议。在从 Amazon Reviews 构建的三个数据集、基于多因子"功利型耐心"用户模拟中，D2D 相比 SOTA 把目标商品命中率提升 22.2–29.9%、会话放弃率降低 6.6–16.1%、平均对话长度缩短 27.5%，并有用户研究佐证满意度与效率提升。

INSIGHTD2D 的可借鉴点是把"问什么/何时推"建模成基于属性信息增益的决策——在社区搜索的多轮 query 澄清里同样适用：用属性/标签的区分度排序追问，能在更少轮次内逼近用户意图。27.5% 更短对话与放弃率下降说明"择时推荐"对体验和留存有实质影响，提示对话式检索不应一味追问或一味早推，而要量化每一步的信息增益与中断成本。

Sarthak Harne, Natwar Modani, Debabrata Mahapatra, Shubham Agarwal
