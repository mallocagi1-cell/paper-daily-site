INSPIRE: Intent-aware Neural Sponsored Product Retrieval for E-commerce

沃尔玛美国生鲜电商搜索中，食品饮料类目贡献了最高的搜索流量和赞助广告收入，但生鲜 query 普遍短、歧义大、未明确表达饮食偏好或规格变体等关键需求，用户意图与召回商品之间的细微错配会同时损害用户参与度和变现。论文提出 INSPIRE（Intent-aware Neural Sponsored Product Retrieval），一个面向赞助搜索的意图感知召回框架，利用结构化意图信号来对齐 query 与商品，让针对特定意图（如无糖、家庭装）设计的商品在合适时机被召回。方法落地于沃尔玛真实生鲜赞助搜索链路。

KEY INSIGHT · 对业务意味着什么短歧义 query 的意图理解是社区 UGC 短文本搜索的核心难题，与生鲜 query 高度同构。INSPIRE 的关键设计是把商品侧的结构化意图属性（饮食限制、规格变体）显式建模为召回阶段的对齐信号，让召回在 query-doc 语义相似度之外再引入意图维度的匹配。迁移到 UGC 搜索：可为帖子/问答标注结构化意图标签（适用人群、场景、规格），在短文本召回阶段与 query 解析出的意图对齐，缓解短 query 欠定问题；其赞助场景中按意图时机触发的控制策略，对广告与自然结果混排的社区搜索排序也有借鉴意义。

Unified Multi-Task Relevance Modeling for E-Commerce: Comparing Task Routing Architectures Across LLMs and Cross-Encoders

Walmart

电商相关性建模通常为 query-商品匹配、商品类型相似等六种不同的实体对关系各自训练独立模型，阻碍知识迁移且产生不一致的相关性信号。论文提出统一的多任务相关性框架：在共享的三档相关性标度下，对六个实体对任务联合训练一个模型，并系统比较三种任务路由架构（如何把任务身份传递给共享模型）。核心观察是 encoder 模型与 decoder-only 模型通过不同机制编码任务身份，因此任务路由架构的选择会非对称地影响这两类模型。论文对 LLM 与 cross-encoder 两个家族做了系统对照实验。

INSIGHT相关性是搜索的核心指标（nDCG），社区搜索同样面临 query-帖子、帖子-帖子等多种匹配关系各自建模、信号割裂的问题。这篇工作的可借鉴点是用统一标度加多任务联合训练把多种相关性任务收敛到一个模型，靠任务路由（task identity 注入方式）支撑差异化任务，省去为每种关系单独维护模型。其 encoder 与 decoder-only 对任务身份注入方式敏感度不同的结论很实用：若用 cross-encoder 做相关性精排，任务身份适合走特征或前缀注入；若用 LLM，则需注意 prompt 式任务标识带来的非对称影响，这直接关系到 UGC 搜索相关性模型的选型与多任务设计。

Md Omar Faruk Rokon, Jhalak Nilesh Acharya, Shasvat Desai, Hong Yao, Kuang-chih Lee

03 3.50

Macro Graph of Experts for Billion-Scale Multi-Task Recommendation

Jinan University

十亿级多任务推荐中，不同任务对应各自的十亿级图结构，传统多任务学习只用单点的 user/item embedding，忽略了图结构蕴含的协同信息。论文提出 Macro Graph of Experts（MGOE）框架，首次用宏观图 embedding 捕捉任务特定的宏观特征，并建模任务专家之间的相关性。核心组件包括 Macro Graph Bottom——让多任务模型首次能有效吸收图信息；以及 Macro Prediction Tower——在任务间动态融合宏观知识。MGOE 已规模化部署，支撑线上多任务学习。

INSIGHT多目标排序（点击、时长、互动等）是搜索与推荐共用的范式，MGOE 给出了把图结构注入 MMoE 类多任务底座的具体做法。其关键设计是宏观图 bottom：把任务特定大图预先压成 macro graph embedding 作为专家输入，避免逐样本在线图卷积的时延，同时保留图协同信号。对社区搜索的启示：用户-帖子-作者构成的异构交互图可压成宏观 embedding，作为多目标精排的底层特征；Macro Prediction Tower 的任务间知识动态融合，也可用于平衡相关性与 CTR 等存在冲突的目标。

Hongyu Yao, Zijin Hong, Hao Chen, Zhiqing Li, Qijie Shen, Zuobin Ying, Qihua Feng, Huan Gong 等 9 人
