SPAR: Enhancing Industrial-Scale Generative POI Recommendation via Real-World Spatial Perception

论文面向工业级生成式 POI 推荐，指出仅依赖行为序列和协同信号生成 Semantic ID，会让结果兴趣相符却远离用户实时位置。SPAR 从 Semantic ID 构造、空间知识学习与生成保持三个阶段显式注入距离、方向和可达性，使生成目标同时满足偏好与真实城市空间约束。

hLLM: Single Pass Decoding for Generative Reranking

hLLM 针对生成式排序逐 token 解码的时延瓶颈，把输出看成候选与名次之间的排列分配问题。模型从预填充隐状态一次性读出 N×K 的位置得分矩阵，再用匈牙利算法求最优匹配，从而以 O(1) 次前向传播生成合法全排列，避免自回归解码及事后修复。

INSIGHT它把“生成排序”从语言生成问题重写成受约束的组合优化问题，是很适合在线重排的工程化思路。UGC 搜索可保留 LLM 的上下文理解与列表建模能力，同时用单次前向和确定性分配控制尾延迟，并天然杜绝重复名次、漏项等格式错误。

Emil Laftchiev, Prachi Agrawal, Moe Kayali, Bixing Yan, Qi Xu, Zijie Lei, Chen Qiu, Zhi Hua, Ke Li 等 10 人

MERGED: Multimodal Entity Resolution via Generated Expert Reasoning Distillation

MERGED 解决电商多模态实体消歧规则频繁变化、人工标注慢且缺少推理依据的问题。多个大视觉语言模型同时为商品对生成标签和结构化理由；一致样本用于监督微调，分歧样本经元评审器转成 DPO 偏好对，再把判断能力蒸馏到 7B 学生模型，全程无需人工标注。

INSIGHT对 UGC 搜索的重复内容识别、相似帖子聚合和弱监督标注，这套“多教师理由生成—分歧裁决—小模型偏好学习”链路很有借鉴价值。核心不是只蒸馏答案，而是保留可审计的判断依据，使业务规则改变后能低成本重建数据并部署较小模型。

You-Lin Chen, Kyoungjun Park, Bin Xu, Prithviraj Sen, Pedro Herrero-Vidal

RecEvolve: A Knowledge-Driven Autonomous Agent System for Recommender Systems

RecEvolve 将推荐模型研究的构思、代码实现、离线训练和指标评估交给知识驱动的闭环智能体，并直接在生产级双塔召回模型上验证。系统从零完成 40 余次自主训练，识别并突破隐藏架构瓶颈，使 NDCG 相对提升约 20%，线上用户满意度进一步提升 3.77%。

INSIGHT这项工作展示了生成式智能体如何真正进入推荐研发闭环，而不只是生成实验建议。实践重点是把知识库、代码环境、训练任务和严谨评测连接成可回滚流程；对社区搜推团队，可优先用于高频消融和召回塔结构搜索，但上线仍需人工门禁与流量实验。

Beyond Retrieval: Learning Compact User Representations for Scalable LLM Personalization

TAP-PER 试图摆脱把完整用户历史检索进提示词或为每位用户保存独立适配器的两类扩展瓶颈。它把动态偏好编码为轻量用户状态前缀，以时间注意机制更新紧凑表示，再作为前缀条件控制 LLM 行为，从而降低对检索质量、提示设计和用户级参数存储的依赖。

INSIGHT对于长行为序列，先学习可更新的紧凑用户状态，再将其注入生成模型，比每次拼接历史更稳定也更节省上下文。社区搜索可把近期意图与长期兴趣拆成不同时间尺度的前缀，但需要关注状态陈旧、隐私隔离以及新用户没有足够行为时的退化策略。

ViSAR: Training-Free Adaptive-k Retrieval for Visual Document Question Answering

ViSAR 面向视觉文档问答中固定 top-k 检索带来的无效上下文和生成时延。方法无需训练，直接在晚交互 embedding 空间构造查询条件化的页面相似矩阵，按语义激活强度动态决定检索页数；跨多种编码器和视觉语言模型实验中，RAG 时延最多降低 58.7%，且准确率保持或提升。

INSIGHT固定候选量并不适合难度差异很大的社区查询，动态 k 可以同时改善成本和噪声。虽然论文场景是视觉文档，其“根据相似度结构而非固定阈值决定证据量”的机制可迁移到多模态帖子召回，并作为生成式回答前的轻量预算控制层。

Adrien Mialland, Marc Plantevit, Julien Gallois, Céline Robardet

PRO-Step: Step-level Process Reward Optimization for Retrieval-Augmented Generation

PRO-Step 针对多跳 RAG 早期检索错误会沿推理链传播，而终局奖励无法定位中间失败的问题。它训练同时判断逻辑有效性与证据支撑度的生成式过程奖励模型，用奖励模型引导的价值树搜索构造正确步骤与缺陷步骤偏好对，再以逐步 DPO 优化检索推理策略。

INSIGHT生成式搜索训练不应只看最终答案是否正确，还要逐步核验检索证据与推理动作是否一致。对复杂 UGC 查询，可把每轮 query 改写、召回结果和结论分别打分，减少模型偶然猜中答案却学习到错误检索路径；代价是需要可靠的过程评审与搜索预算。

MinKeon Kim, Namjun Lee, Jaekwang Kim

Learning Evidence Sufficiency Boundaries for Selective Answering in Grounded Multi-Hop QA

论文研究多跳问答中证据不足时模型仍会给出貌似合理答案的问题，并提出“证据充分性边界”训练。方法构造从不支持、部分支持到首次充分及冗余证据的有序链，联合监督拒答层级、边界翻转间隔、边界后稳定性和答案召回，在三个多跳数据集上评估选择性回答。

INSIGHT社区生成式搜索需要学习何时停止检索和何时拒答，而不是只优化回答率。将同一查询的证据集合按充分程度排序，可显式训练“从拒答到回答”的临界点；这有助于降低短文本歧义和碎片证据导致的幻觉，也便于把风险阈值按业务场景调整。

Haruto Sato, Yuki Tanaka, Ren Nakamura, Aoi Kobayashi, Mei Ito

Incremental Pooled LLM Evaluation for Cost-Effective Retrieval Model Selection

该研究用 LLM 判断多个检索系统结果的并集，并在新增系统时只标注其新增文档，从而复用统一判断池。方法在 4 个基准、11 个稀疏/稠密/混合系统上验证，并用于比较金融新闻问答的 62 种配置；考虑 qrels 的自助法不确定性后，97% 的系统两两顺序得以保留。

INSIGHT生成式搜推的迭代速度常被重复人工标注拖慢，增量判断池能把新模型评测成本限制在真正新增的候选上。落地时应保留统一文档池、判断版本和置信区间，并定期抽样人工校准 LLM 评审偏差，避免评测器偏好反向塑造检索系统。

Max Nelson, Hanoz Bhathena, Aviral Joshi, Saket Sharma

Skim and Skip: Hierarchical Adaptive Inference for Efficient Multimodal Retrieval

SAS 针对多模态大模型作为统一检索编码器时的高推理成本，利用 token 贡献不均和查询所需深度不同两种异质性。框架先做 token 级证据筛选，仅保留影响最终 embedding 的信息，再按样本自适应决定推理深度，避免所有输入都经过完整层数的均匀密集计算。

INSIGHT多模态 UGC 召回可把“删哪些 token”和“跑多少层”作为两个独立预算旋钮：先裁剪低价值图文证据，再让简单查询提前退出。该设计适合高 QPS 编码服务，但实际部署必须监控长尾语义和弱信号内容是否被过早丢弃，并设置保守回退路径。
