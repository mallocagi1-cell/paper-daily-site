The Voronoi Bottleneck: Capacity-Aware Dense Retrieval for Product Search

这篇论文面向电商/UGC 搜索中双塔稠密召回容量不足的问题，指出固定维度内积向量会形成“Voronoi Bottleneck”，无法表达所有 query-document 相关性模式。作者把 Voronoi complexity 与 sign-rank 联系起来，提出无需相关性标签即可预测单 query 检索失败的 Capacity Utilization Score，报告 AUC 大于 0.8。训练侧提出 AT-DW-InfoNCE/DART，在 10 万 query 的合成商品搜索语料上 Recall@100 从 83.0 提升到 84.9，且推理阶段零额外开销。

Why Advanced Encoders Lag on Sparse Retrieval? The Answer and an Approach to Bridging Vocabulary Gaps

这篇 SIGIR 2026 论文解释了一个反直觉现象：ModernBERT 等新编码器在稠密检索中更强，但在 learned sparse retrieval 中反而落后于 BERT-base。作者把根因归结为 Vocabulary Gap，即现代 tokenizer 的大小写敏感、原始表面词表把同一语义拆成冗余形态，浪费稀疏维度并削弱词项匹配。提出的 Vocabulary Transfer 通过语义初始化和 Activation Potential Calibration 迁移到更适合稀疏检索的规范化词表，使 ModernBERT 在 BEIR 上达到 52.4 nDCG，相比原方案提升 +4.7。

INSIGHT这对 UGC 搜索特别实用：短文本 query 往往混合错别字、大小写、品牌词和口语变体，稀疏召回仍然承担高精确匹配职责。论文说明换更强 encoder 不一定能自动提升稀疏检索，词表归一化和激活校准可能比盲目扩大模型更关键；实践上可以把 VT 作为 BM25/稀疏神经召回升级方案，在保留可解释词项信号的同时吸收现代 encoder 的语义能力。

Zhichao Geng, Yang Yang

Multi-Turn Agentic Scientific Literature Search via Workflow Induction

UIUCTTogether AIUPennStanford

PaperPilot 面向多轮科学文献搜索，把检索从一次性 query 改写为可执行、可检查、可编辑的工作流归纳问题。系统围绕 anchor paper 和用户 query 构造 DAG，包含关键词搜索、引文扩展、过滤、打分、重排和证据抽取等算子，并用监督工作流模仿与偏好优化训练。实验显示 PaperPilot-9B 在多轮交互中把 Hit@5 从 58.0 提升到 77.0，MRR 从 47.5 提升到 59.4，nDCG@10 从 26.8 提升到 32.5，同时工作流执行错误从 9.5% 降到 0%。

INSIGHT虽然场景是文献搜索而非社区帖子搜索，但“显式工作流 + 可编辑检索算子”的设计值得借鉴。对于复杂 UGC 搜索，可以把 query 理解、召回扩展、过滤、重排和证据抽取拆成可观测 DAG，让用户反馈不仅改写 query，也调整后续检索策略；这比把多轮意图全部藏在 LLM prompt 中更容易调试、回放和做线上归因。

Jisen Li, Bingxuan Li, Nanyi Jiang, Xuying Ning, Xiyao Wang, Yifan Shen, Heng Wang, Yuqing Jian 等 13 人

Libra: Training the Environment for Agentic Information Retrieval

Libra 研究 agentic information retrieval 中的“环境可训练”问题，不直接优化检索模型，而是让仓库内的层级 Markdown catalog 随失败案例自我演化。系统用 Prompter 生成合成定位 query，让冻结 Solver 在 catalog 中导航，再由 Healer 根据定位失败重写 catalog。作者在 12 个 SWE-bench Lite 仓库上观察到代码定位准确率随环境修复持续、近似对数式提升，并且修复后的 catalog 能跨不同 LLM 和问题集零样本迁移。

INSIGHT对搜索系统来说，这篇论文的价值不在排序模型本身，而在“索引内容可被主动修复”的思路。社区搜索中常见失败不是召回模型完全不会匹配，而是帖子标签、摘要、实体别名和结构化索引不足；Libra 提示可以从失败 query 自动生成可导航的中间索引或 topic catalog，让后续召回拥有更好的语义路标，再把这些环境改动作为可审计资产沉淀。

Xuan Zhao, Andy Chiu, Gengyu Wang
