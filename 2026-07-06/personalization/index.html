POEM: Partial-Order Enhanced Real-Time Sequential Modeling for Recommendation

POEM 针对实时推荐中用户兴趣漂移和上下文变化的问题，把多阶段排序链路里的预测 CTR、预测观看时长等上游分数转成动态偏序序列。方法包含按实时排序分动态分组采样、多目标分数融合、层次化样本学习、图挖掘 hard negative 与 margin pairwise loss，使序列模型不只依赖静态点击历史。论文直接面向工业推荐级联链路，适合短视频、信息流和社区内容推荐中的实时重排场景。

Real-Time Hard Negative Sampling via LLM-based Clustering for Large-Scale Two-Tower Retrieval

📖 深度解读 · 10 分钟 →

这篇论文改进大规模推荐双塔召回训练中的负采样问题：常见 in-batch 或 out-of-batch 负样本过易，模型很快学会，难以提升区分能力。作者用 LLM 学到的媒体表征做聚类，在训练时从同簇生成实时 hard negatives，框架面向数十亿训练样本并控制额外计算复杂度。论文报告在公开数据集和大规模线上系统中均优于行业常用负采样方案。

INSIGHT核心价值在于把 LLM 语义能力放在训练数据构造层，而不是直接放到线上召回路径，因此更容易控制延迟和成本。对于社区 UGC 推荐/搜索，很多相似帖子、视频或问答只在细粒度意图上不同，同簇 hard negative 能逼迫双塔模型学习更细的用户偏好边界。实践上可先离线构建语义簇，再逐步替换部分随机负样本或 in-batch 负样本做 A/B 验证。

Ivan Ji, Liuyi Hu, Harrison Zhao, Lei Huang, Qunshu Zhang, Max Fan, Aameek Singh

DPIFrame: A Dual-Level Parallelism Acceleration Framework for CTR Model Inference

DPIFrame 面向 CTR 模型线上推理效率，指出深度 CTR 模型的串行计算模式与 GPU 并行结构之间存在错配。系统提出模块内和模块间双层并行、面向 embedding 操作的多表 lookup 算法，以及广度优先的 GPU stream 调度。两组真实数据集实验显示，embedding 延迟相比 PyTorch 降低 23.0 倍，整体 GPU 推理相对 PyTorch、TorchRec、HugeCTR、OneFlow 分别加速 5.83 倍、4.29 倍、2.15 倍和 2.0 倍。

INSIGHT虽然这是偏工程系统的论文，但对个性化精排很关键：CTR/CVR 模型的特征交互越复杂，线上瓶颈越常落在 embedding lookup 和细粒度算子调度上。DPIFrame 的可借鉴点是先重排执行图与 embedding 访问模式，再谈模型结构升级，这能为更复杂的多目标排序模型释放推理预算。对高 QPS UGC 排序链路，可优先评估多表 lookup 合并、stream 调度和模块级并行是否能降低尾延迟。

Breaking the Filter Bubble: A Semantic Pareto-DQN Framework for Multi-Objective Recommendation

本文关注推荐系统因单一即时互动目标导致的过滤气泡和语义同质化问题，将推荐建模为语义多目标 MDP。方法用高保真语义 embedding 与 Pareto-DQN，把 engagement、diversity、provider fairness 作为不可简单合并的独立奖励，并用 hypervolume action selection 维持 Pareto 前沿。MovieLens small 实验显示，该策略能提升多样性和公平性等辅助目标，同时只牺牲少量 engagement。

INSIGHT这篇论文适合提醒个性化团队：多目标排序不应只停留在线性加权，尤其当目标之间存在价值冲突时，Pareto 前沿比固定权重更可解释。它的工业落地仍需更大规模数据和线上校验，但语义状态轨迹方差可作为监控过滤气泡的一个实用信号。社区内容推荐可以先在重排层试验多目标候选集约束，而不是直接替换主排序模型。

Claudio Lucio Do Val Lopes, Lucca Machado da Silva, Andre de Oliveira Brandao

从月球漫步到赛博都市，WBench 测出了世界模型的边界

Meituan

这是美团技术博客的 WBench/世界模型工程实践文章，来自 crawler 的 blog_rss 结果，并非个性化推荐核心论文。它主要讨论世界模型能力边界和动态评测，对推荐排序、CTR/CVR 或用户建模没有直接方法贡献；本次保留它是因为硬去重后只剩这一条大厂工程博客可用于行业实践覆盖。其价值更多在评测方法和复杂动态环境基准，而不是可直接迁移到推荐精排。

INSIGHT对个性化推荐的可借鉴点较间接：如果团队正在探索基于生成模型或世界模型的用户模拟，可以参考这类动态基准的任务设计和评测思路。但它不应被当作推荐系统模型更新的主依据，也不适合作为短期 CTR/nDCG 优化方案。实际排序团队应把注意力放在本期更相关的 POEM、hard negative sampling 和 CTR 推理加速论文上。
