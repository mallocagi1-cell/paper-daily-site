Spend Search Where It Pays: Value-Guided Structured Sampling and Optimization for Generative Recommendation

该论文解决生成式推荐模型中强化学习微调的两大核心难题：低概率高回报分支被过早剪枝（探索不足）和共享高概率前缀的轨迹回报高度相关（优势压缩）。提出 V-STAR 框架，包含价值引导高效解码（Value-Guided Efficient Decoding）识别高价值搜索路径，以及 Sibling-GRPO 利用树结构改善学习信号。在离线和在线数据集上验证了该方法在延迟约束下实现更好的推荐准确性和多样性。

To Memorize or to Retrieve: Scaling Laws for RAG-Considerate Pretraining

该论文系统研究语言模型预训练中参数化知识（模型记忆）与非参数化知识（检索增强）之间的 scaling trade-off。作者训练了从 30M 到 3B 参数的 OLMo-2 模型，预训练数据量达 100B tokens，同时变化预训练语料和检索库大小。核心发现：检索在所有模型规模上一致优于纯参数化基线，但检索的边际价值随模型大小、任务类型和训练饱和度显著变化。提出了可预测数据资源分配的 scaling 框架。

INSIGHT这项研究为 RAG 系统的资源分配提供了定量指导——在固定计算预算下，何时应该增大模型、何时应该扩大检索库。对于搜索推荐系统而言，这直接关系到是投资更大的排序模型还是更丰富的文档索引。论文发现检索对小模型的提升最大，这为中小团队使用 RAG 增强轻量级推荐模型提供了理论依据。Scaling law 框架可直接指导生成式推荐系统的参数分配策略。

Karan Singh, Michael Yu, Varun Gangal, Zhuofu Tao, Sachin Kumar, Emmy Liu, Steven Y. Feng

Using Predefined Vector Systems to Speed Up Neural Network Multimillion Class Classification

该论文提出利用预定义向量系统将神经网络百万级别分类的复杂度从 O(n) 降至 O(1)。通过将标签预测与已知几何性质的向量系统中的最近聚类中心搜索关联，仅需识别 embedding 的最大和最小值即可完成预测。实验表明，相比传统方法实现了高达 11.6 倍的整体加速，同时保持训练精度并支持新类别检测。

INSIGHT对于拥有百万级物品库的推荐系统而言，softmax 层或全量余弦相似度计算是推理延迟的主要瓶颈。该方法通过预定义的 latent space 几何结构实现 O(1) 检索，本质上是在 embedding 空间中建立了一种确定性的哈希索引。这为生成式推荐模型的最终 item 解码阶段（从 Semantic ID 映射到具体物品）提供了新的加速思路。不过，该方法对 latent space 几何有特定要求，工程落地需要额外验证。

Nikita Gabdullin, Ilya Androsov

Retrieval-of-Thought: Efficient Reasoning via Reusing Thoughts

该论文提出 Retrieval-of-Thought (RoT)，通过复用历史推理步骤来加速大型推理模型。将推理步骤组织为带有顺序和语义边的思维图（thought graph），支持快速检索和灵活重组。推理时检索与查询相关的节点，通过奖励引导遍历组装定制化模板指导生成。实验结果显示：输出 token 减少 40%，推理延迟降低 82%，成本降低 59%，同时保持准确性。

INSIGHTRoT 的核心思想——缓存并复用历史推理轨迹——对 LLM-based 推荐系统有直接启示。在推荐场景中，相似用户请求的推理过程高度重复（如相似 query 的候选理解和排序逻辑），可以构建推理缓存图实现显著加速。82% 的延迟降低使得原本因推理成本过高而无法上线的 reasoning-based 推荐策略变得可行。这对需要 LLM 参与排序或生成解释的推荐系统特别有价值。

Ammar Ahmed, Azal Ahmad Khan, Ayaan Ahmad, Sheng Di, Zirui Liu, Ali Anwar

Universal YOCO for Efficient Depth Scaling

Microsoft

该论文提出 Universal YOCO (YOCO-U)，将 YOCO decoder-decoder 架构与递归计算相结合。通过浅层注意力层的参数共享实现多次迭代，保持恒定的全局 KV 缓存和线性预填充。部分递归增强了表示深度。在通用和长上下文基准测试中保持强竞争力，为高效注意力架构与递归计算的结合提供了新范式。

INSIGHTYOCO-U 的核心创新在于用递归计算换取深度——在不增加参数的情况下获得更深表示。对于大规模推荐系统中的序列建模（如 HSTU 类架构），恒定的 KV 缓存意味着随用户行为序列增长，内存成本不会线性膨胀。这解决了生成式推荐模型在长用户历史建模中的关键瓶颈。微软团队（Furu Wei）的持续高效架构研究值得跟踪。

Yutao Sun, Li Dong, Tianzhu Ye, Shaohan Huang, Jianyong Wang, Furu Wei

Toward Holistic Evaluation of Recommender Systems Powered by Generative Models

Google

该论文针对生成式模型驱动的推荐系统提出全面评估框架。识别了两类评估挑战：现有问题被生成式输出放大（如偏见、隐私），以及全新风险如物品幻觉。提出包含场景化评估和多指标检查的整体方法——涵盖相关性、事实依据、偏差检测和策略合规性。作者（含 Google Research 和 UCSD）为研究者和实践者提供了系统评估这类系统并确保负责任部署的方法论。

INSIGHT随着越来越多团队部署生成式推荐系统，评估方法论的缺失成为关键短板。该框架指出了传统 offline metrics（如 nDCG、Recall）无法覆盖的维度：物品幻觉率、事实一致性、策略合规性。对于搜索推荐场景，特别需要关注生成式模型可能推荐不存在的物品或生成不准确的描述。该框架可直接用于建立内部生成式推荐系统的质量保障体系。

Yashar Deldjoo, Nikhil Mehta, Maheswaran Sathiamoorthy, Shuai Zhang, Pablo Castells, Julian McAuley

DR-LoRA: Dynamic Rank LoRA for Fine-Tuning Mixture-of-Experts Models

该论文提出 DR-LoRA，解决 MoE 大模型微调中所有专家模块分配相同 LoRA 秩的不合理问题。通过专家显著性评分（结合路由频率和基于梯度的秩重要性）动态识别哪些专家需要更多容量。初始化时所有专家使用小的活跃秩，根据评分自适应分配。在 3 个 MoE 模型和 6 个任务上的实验表明，该方法显著优于传统均匀秩 LoRA。

INSIGHTMoE 架构已成为大规模推荐模型的主流选择（如 Meta 的 Foundation-Expert 范式），DR-LoRA 的动态秩分配思想可直接应用于推荐场景中的 MoE 模型微调。相比均匀分配，自适应地给重要专家更多参数、给不活跃专家更少参数，能在相同参数预算下获得更好的下游适配效果。这对需要频繁针对新场景/新领域微调大模型的推荐系统团队尤为实用。

Guanzhi Deng, Bo Li, Ronghao Chen, Xiujin Liu, Zhuo Han, Huacan Wang, Lijie Wen, Linqi Song

CRoPE: Efficient Parametrization of Rotary Positional Embedding

该论文发现 Rotary Positional Embedding (RoPE) 的标准实现中 Q/K/V 投影并非等价于复数线性变换，存在约 50% 的参数冗余。提出 CRoPE，使用复数线性变换作为更自然的参数化方式，将注意力模块参数量减少近 50%。实证表明移除这一冗余对模型性能几乎无影响，同时提供了更高效的参数使用和更清晰的表示空间解释。

INSIGHTRoPE 是当前主流 Transformer 架构（包括 LLaMA、Qwen 等用于推荐的基座模型）的标准位置编码。CRoPE 的发现意味着注意力模块中存在大量浪费的参数——这在推荐场景中尤为重要，因为在线推理需要极致的参数效率。作为 drop-in replacement，CRoPE 可以在不牺牲质量的前提下显著减小模型体积，降低部署成本。适合在新训练或微调推荐模型时直接采用。

Beicheng Lou, Zifei Xu, Vivian W. H. Wong

Brainstacks: Cross-Domain Cognitive Capabilities via Frozen MoE-LoRA Stacks for Continual LLM Learning

该论文提出 Brainstacks，一种支持持续多领域微调的模块化架构。将领域专业知识封装为冻结的 adapter stack，在推理时叠加到共享的冻结基座模型上。关键组件包括：MoE-LoRA 路由（QLoRA 4-bit 量化）、残差提升（冻结已训练 stack 后添加新 stack）、正交投影防遗忘、元路由器发现跨领域认知迁移能力。在 TinyLlama 和 Gemma 上的实验显示更快收敛且跨域保持生成质量。一个有趣发现：医疗提示 97% 的情况路由到 chat+math stack。

INSIGHT推荐系统面临多场景、多领域的持续适配挑战——电商、社区、短视频等场景需要不同的专业知识。Brainstacks 的冻结 stack 叠加方案提供了一种不会遗忘旧领域知识的增量学习路径。医疗路由到 math stack 的发现暗示领域间存在非直觉的知识迁移，这对多场景推荐模型的架构设计有启发意义。4-bit 量化+MoE-LoRA 的组合也为资源受限环境下的多领域推荐提供了实用方案。

Mohammad R. Abu Ayyash

ORBIT: Scalable and Verifiable Data Generation for Search Agents on a Tight Budget

WWaterloo

该论文提出 ORBIT，一个包含 20K 推理密集型查询和可验证简短答案的训练数据集，通过低成本框架生成（不依赖付费 API）。方法包含四阶段：种子创建、QA 对生成、自我验证和外部验证。数据集覆盖 15 个领域，每对需要 4-5 步推理和外部搜索验证。使用 GRPO 在 Qwen3-4B 上训练后，ORBIT-4B 在 sub-4B 搜索 agent 中表现优异。

INSIGHTORBIT 展示了用低成本合成数据训练搜索 agent 的可行性——20K 高质量样本即可让 4B 模型成为有效的搜索 agent。这对需要构建 LLM-based 搜索推荐系统的团队有直接参考价值：通过精心设计的合成数据+GRPO 训练，小模型也能具备多步推理搜索能力。四阶段验证流程（特别是外部搜索验证）可借鉴用于构建推荐场景的训练数据质量保障。

Nandan Thakur, Zijian Chen, Xueguang Ma, Jimmy Lin
