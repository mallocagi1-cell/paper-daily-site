UniMixer: A Unified Architecture for Scaling Laws in Recommendation Systems

本文提出 UniMixer，一种统一的推荐系统 scaling 架构。当前推荐模型的三大主流 scaling 架构（attention-based、TokenMixer-based、factorization-machine-based）在设计哲学和结构上存在根本差异。UniMixer 将基于规则的 TokenMixer 转换为等价的参数化结构，构建广义参数化特征混合模块，使 token 混合模式可在训练中优化学习，从而在统一框架下实现更高效的 scaling。

Aligning Recommendations with User Popularity Preferences

📖 深度解读 · 7 分钟 →

本文研究推荐系统中的流行度偏差问题，提出 Popularity Quantile Calibration 度量框架来量化用户历史流行度偏好与推荐结果之间的不对齐程度。基于此提出 SPREE，一种面向序列推荐模型的推理时激活引导方法——在表示空间中识别流行度方向，并根据每位用户的个人流行度偏好自适应地调节模型激活，实现个性化的流行度校准。

INSIGHTSPREE 的核心创新在于将 activation steering 技术应用到推荐场景。与需要重训练的去偏方法不同，SPREE 仅在推理时调整模型表示，无需修改训练流程，部署成本极低。对于 UGC 搜索场景，这种方法可以帮助平衡热门内容与长尾内容的曝光，避免「马太效应」，提升内容生态多样性。

GRank: Towards Target-Aware and Streamlined Industrial Retrieval with a Generate-Rank Framework

GRank 提出一种无结构化索引的工业级检索范式，统一了目标感知学习与以用户为中心的检索。核心创新包括：(1) 基于 GPU 加速 MIPS 的目标感知生成器，实现个性化候选生成；(2) 解决了传统双塔架构表达力不足和生成式模型缺乏精确目标感知匹配的问题；(3) 避免了树/图/量化等结构化索引的高昂构建和维护成本。

INSIGHTGRank 对推荐系统检索层的实践意义重大：它证明了无需构建和维护复杂的结构化索引（如 HNSW、量化索引），通过 GPU 加速的 MIPS 即可实现高效检索。这大幅降低了工程复杂度和运维成本。同时，目标感知的设计使检索阶段能捕捉更细粒度的 user-item 交互，有望提升全链路推荐效果。

Uncertainty-Aware Variational Reward Factorization via Probabilistic Preference Bases for LLM Personalization

本文提出 VRF（Variational Reward Factorization），一种不确定性感知的 LLM 个性化框架。通过将奖励分解为共享基函数和用户特定权重，用变分编码器推断用户偏好分布，利用 Wasserstein 距离匹配共享概率基，并通过方差衰减损失降权不确定估计。在三个基准上，VRF 在已见/未见用户、少样本场景和不同不确定性水平下均超越所有基线。

INSIGHTVRF 将概率建模引入奖励分解，解决了用户偏好数据稀缺时的个性化难题。其变分推断框架可自然处理冷启动用户（通过先验分布），方差衰减损失机制避免在数据不足时过拟合。这一思路可迁移到推荐系统的用户建模中：用概率偏好空间替代确定性用户向量，提升对长尾用户的推荐质量。

MOON3.0: Reasoning-aware Multimodal Representation Learning for E-commerce Product Understanding

Alibaba

MOON3.0 提出了推理感知的多模态表示学习方法，解决电商产品理解中的三大挑战：长上下文推理导致模型对关键信息的注意力稀释、SFT 仅鼓励僵化模仿限制推理策略探索、细粒度细节在全局嵌入中被淹没。通过利用 MLLM 的推理能力显式建模细粒度产品属性，结合 RL 训练探索有效的推理策略。

INSIGHTMOON3.0 的核心启示在于：传统的 MLLM 特征提取（作为黑箱编码器）无法捕捉电商产品的细粒度属性差异。引入显式推理链（CoT）配合强化学习，使模型能主动分析产品属性间的细微差异，这对于搜索排序中的相关性判断（如区分相似但不同规格的商品）极具参考价值。

Criterion Validity of LLM-as-Judge for Business Outcomes in Conversational Commerce

本文在大型中文相亲平台上研究 LLM-as-Judge 的效标效度——即质量评分是否真正关联下游业务转化。采用 7 维评估框架，发现维度级异质性显著：需求引导（D1, ρ=0.368）和节奏策略（D3, ρ=0.354）与转化显著相关（Bonferroni 校正后），而上下文记忆（D5, ρ=0.018）无显著关联。研究表明不同评估维度对业务结果的贡献差异巨大。

INSIGHT该研究的核心启示是：在使用 LLM-as-Judge 评估对话系统时，不能假设所有评分维度都与业务目标等权相关。实践中应基于真实业务标签验证各维度的效标效度，用经验权重替代均权聚合。这一方法论可迁移到搜索/推荐场景中的离线评估体系设计，避免「评分高但转化低」的脱节问题。

HiMA-Ecom: Enabling Joint Training of Hierarchical Multi-Agent E-commerce Assistants

HiMA-Ecom 是首个面向电商场景的层次化多 Agent 基准，包含 22.8K 实例，涵盖 Agent 级 SFT 数据和系统级联合强化学习数据。提出 HiMA-R1 联合训练方法和 VR-GRPO（Variance-Reduction Group Relative Policy Optimization），通过初始轨迹蒙特卡罗采样降低方差，实现主 Agent 与子 Agent 的协同优化。

INSIGHT该工作对电商推荐系统的启示在于：多 Agent 协同已成为复杂电商场景（如购买咨询、售后服务）的新范式。VR-GRPO 的方差降低技术解决了多 Agent RL 训练不稳定的核心难题。但其对基础设施要求较高（需要完整的 agent 训练管线），更适合大规模电商平台借鉴。

MSA-Thinker: Discrimination-Calibration Reasoning with Hint-Guided Reinforcement Learning for Multimodal Sentiment Analysis

MSA-Thinker 提出融合判别-校准推理的多模态情感分析框架，利用 Hint-guided RL 解决 SFT 训练中黑箱推理可解释性不足的问题。通过教师模型（Qwen3Omni-30B）合成高质量 CoT 数据进行冷启动 SFT，构建包含宏观判别和微观校准的推理范式，有效提升困难样本上的探索效率。

INSIGHT该工作虽聚焦情感分析，但其 Hint-guided RL 框架对推荐系统中的用户意图理解有借鉴价值。在 UGC 搜索场景中，用户评论和帖子的情感分析可辅助内容理解和排序。其判别-校准二阶段推理设计可迁移到搜索相关性判断——先粗判再精调，提升难例准确率。

Learning Shared Representations for Multi-Task Linear Bandits

本文提出基于低秩共享表示的多任务线性 Bandit 算法。考虑 T 个并发线性 Bandit 任务共享维度 r ≪ min{d,T} 的潜在表示，设计新的 OFUL 算法：先通过探索阶段收集数据，用谱初始化估计共享模型，再在新构建的置信集上进行 OFUL 学习。提供了置信集的理论保证和遗憾界分析。

INSIGHT多任务低秩表示学习在推荐系统中的对应场景是：多个推荐任务（如 CTR、CVR、停留时长）共享底层用户-物品表示。该工作的理论框架为多目标推荐中的探索-利用权衡提供了形式化分析工具，其谱初始化方法也可启发实际多任务模型的初始化策略。

Simple Projection-Free Algorithm for Contextual Recommendation with Logarithmic Regret and Robustness

本文提出一种高效的上下文推荐算法，在达到 O(d log T) 遗憾界的同时避免了 Online Newton Step 方法所需的 Mahalanobis 投影计算瓶颈。核心思路是利用上下文推荐固有的 improper 性质，采用类似二阶感知器的更新规则。该算法对可能的次优动作反馈也具有鲁棒性。

INSIGHT该工作的实践价值在于其算法效率优势：去除投影步骤使得在线推荐系统中的上下文 Bandit 部署更加轻量。对次优反馈的鲁棒性在实际推荐场景中尤为重要——用户的隐式反馈（如点击、跳过）本质上是带噪声的次优信号。理论结果可为在线排序策略的选择提供参考。
