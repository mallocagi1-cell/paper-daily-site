Beyond Interleaving: Causal Attention Reformulations for Generative Recommender Systems

针对生成式推荐系统中 item-action token 交织导致序列长度翻倍的效率问题，提出 AttnLFA 和 AttnMVP 两种因果注意力架构，通过显式编码 item-to-action 的因果依赖关系，消除交织依赖并将序列复杂度降低约50%。在大规模商品推荐数据上，AttnMVP 相比交织基线 eval loss 降低0.80%，训练时间缩短12%，同时 Normalized Entropy 指标也有提升。该论文投稿 KDD 2026。

Breaking User-Centric Agency: A Tri-Party Framework for Agent-Based Recommendation

针对现有 Agent 推荐系统仅以用户为中心的局限性，提出 TriRec 三方框架，同时考虑用户偏好、商品曝光和平台公平性。分两阶段运作：先由 item agent 进行个性化自我推广以改善匹配和缓解冷启动，再由 platform agent 通过多目标优化在相关性、效用和公平性之间重新排序。实验表明该方法能同时提升推荐精度和公平性。

INSIGHTTriRec 的三方博弈框架突破了传统推荐中单一用户视角的局限，让 item 端也参与到匹配过程中（类似搜索广告中的竞价机制）。对社区搜索而言，多方利益平衡（用户搜索意图、内容创作者曝光需求、平台生态健康）是一个重要但少有系统解决方案的问题，TriRec 提供了可参考的框架思路。

Yaxin Gong, Chongming Gao, Chenxiao Fan, Wenjie Wang, Fuli Feng, Xiangnan He

UtilityMax Prompting: A Formal Framework for Multi-Objective Large Language Model Optimization

提出 UtilityMax Prompting 框架，用形式化数学语言替代自然语言来指定 LLM 多目标任务。将任务建模为影响图（influence diagram），LLM 的响应作为决策变量，定义效用函数引导模型在概率分布上进行显式推理以最大化期望效用。在 MovieLens 1M 多目标推荐任务上，该方法在 Precision 和 NDCG 指标上优于自然语言提示基线，跨三个前沿模型均有一致改进。

INSIGHT该工作将 LLM-as-recommender 的提示设计从经验性的自然语言提升到形式化数学框架层面。通过影响图建模让 LLM 能对多个目标分量进行显式推理，避免了自然语言提示中的模糊性和主观解读。对于搜索排序中需要平衡相关性、多样性、时效性等多目标的场景，这种形式化提示框架提供了一种更可控的 LLM 排序方案。

Ofir Marom
