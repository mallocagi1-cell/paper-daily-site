Meta-Reinforcement Learning with Self-Reflection for Agentic Search

针对搜索 Agent 的强化学习训练提出 MR-Search 框架，核心创新在于跨 episode 的元学习：模型不仅在单次搜索中学习，还能利用历史搜索经验进行自我反思，动态调整搜索策略。采用多轮 RL 算法实现细粒度的 credit assignment，在 8 个基准上比标准 RL 方法提升 9.2%-19.3%。该方法直接解决了搜索 Agent 的核心挑战——如何从失败搜索中学习和改进。

Ares: Adaptive Reasoning Effort Selection for Efficient LLM Agents

UC Santa Barbara

针对 LLM Agent 推理成本过高的问题，提出 Ares 框架：使用轻量级路由器根据交互历史动态选择每一步的推理深度。关键创新是自动识别完成任务所需的最小推理量，并据此微调路由器。在 TAU-Bench、BrowseComp-Plus、WebArena 三个 Agent 基准上，实现最高 52.7% 的推理 token 节省，性能损失极小。

INSIGHTAres 的自适应推理深度策略对搜索系统的 LLM 部署有重要参考价值。搜索场景中不同 query 复杂度差异很大——简单的「附近美食」和复杂的多条件筛选需要完全不同的处理深度。Ares 的路由器机制可以用来动态分配搜索系统中的计算预算，简单 query 快速返回，复杂 query 调用深度推理，在延迟和效果间取得最优平衡。

Reason and Verify: A Framework for Faithful Retrieval-Augmented Generation

提出面向特定领域的忠实 RAG 框架，核心是将显式推理与忠实性验证整合到检索生成管线中。包含神经 query 改写、cross-encoder 重排序和基于证据片段的 rationale 生成三个关键组件。引入了包含 8 个类别的验证分类体系来评估 rationale 质量。在 BioASQ 和 PubMedQA 基准上，较小模型即达到有竞争力的结果。被 Canadian AI 2026 接收。

INSIGHT该框架的 query 改写-重排序-rationale 生成管线可直接映射到社区搜索场景：用户输入模糊 query 后，先改写为精确搜索 query，cross-encoder 重排序候选结果，最后生成有依据的摘要。其 8 类验证分类体系也适合作为社区搜索中 AI 生成答案质量的评估标准，确保搜索结果摘要忠实于源帖子内容。

Eeham Khan, Luis Rodriguez, Marc Queudot

Strategic Navigation or Stochastic Search? How Agents and Humans Reason Over Document Collections

构建 MADQA 基准，包含 2,250 个由人类专家编写的问题，覆盖 800 篇多样化 PDF 文档。提出基于经典测试理论的评估框架，测量 accuracy-effort 权衡。核心发现：当前最佳 Agent 在原始准确率上与人类搜索者相当，但它们主要依赖暴力搜索策略而非战略性推理，与 oracle 性能仍有约 20% 的差距，且与人类在不同问题子集上成功。

INSIGHT这项研究揭示了 Agent 搜索的一个深层问题：当前 Agent 通过大量检索弥补推理不足，而非像人类那样有策略地搜索。对社区搜索系统的启示是：仅靠增加检索次数和扩大候选集无法根本提升搜索质量，关键在于让 Agent 学会像人类一样的搜索策略——先判断信息类型，再选择最可能找到答案的来源。这种 accuracy-effort 评估框架也适合评估搜索系统效率。

DocSage: An Information Structuring Agent for Multi-Doc Multi-Entity Question Answering

提出 DocSage Agent 处理多文档、多实体的复杂问答。三个核心组件：动态 schema 发现识别关键实体和关系、带纠错机制的结构化信息抽取、以及感知 schema 的关系推理。将非结构化文本转化为语义连贯的关系表，支持 SQL 查询和跨文档实体对齐。相比现有长上下文 LLM 和 RAG 系统，准确率提升超过 27%。

INSIGHTDocSage 的'非结构化文本 -> 结构化关系表 -> SQL 查询'管线对社区搜索有直接应用价值。社区帖子天然是非结构化的，但用户搜索往往涉及结构化需求（如'找 XX 产品的用户评价对比'）。将帖子内容结构化后用 SQL 精确查询，可以大幅提升复杂搜索需求的满足率，特别是需要跨帖子实体对齐的场景。

One Supervisor, Many Modalities: Adaptive Tool Orchestration for Autonomous Queries

提出多模态 Agent AI 框架，由中央 Supervisor 协调文本、图像、音频、视频和文档五种模态的专用工具。Supervisor 动态分解查询并路由到合适的工具，实现自主多模态处理。相比层级式基线，响应时间减少 72%，交互返工减少 85%，成本降低 67%，同时保持准确率不变。

INSIGHT该框架的 Supervisor 路由模式对社区搜索系统的多模态扩展有参考意义：社区内容包含文字、图片、视频等多种模态，传统搜索只处理文本。引入 Supervisor Agent 可以将多模态查询（如'找包含猫咪的搞笑视频帖子'）分解为文本搜索+图像理解+视频理解的组合，由各专用模型并行处理。72% 的时间减少表明工程可行性。

WideSeek-R1: Exploring Width Scaling for Broad Information Seeking via Multi-Agent Reinforcement Learning

TTsinghua University / Microsoft Research

挑战搜索 Agent 的深度扩展范式，转而探索宽度扩展：通过多 Agent 并行搜索替代单 Agent 深度推理。提出 lead-agent-subagent 框架，用多 Agent 强化学习联合训练，主 Agent 负责分解任务，子 Agent 并行执行搜索。在广泛信息搜集任务上，性能可随并行子 Agent 数量持续提升，且小模型集群可匹敌大模型单 Agent。

INSIGHT宽度扩展为搜索系统的架构设计提供了新思路：不必依赖单个超大模型处理所有检索任务，而是用多个小模型并行处理不同搜索子任务。在社区搜索中，可将一个复杂查询分解为多个并行子查询（内容搜索、用户搜索、时间筛选），由不同专用模型并行执行再汇总，既降低推理延迟又提升覆盖率。这种架构思路在工程落地上比单一大模型更可控。

Safe and Scalable Web Agent Learning via Recreated Websites

Georgia Tech

提出 VeriEnv 框架，利用 LLM 自动将真实网站克隆为可执行的合成环境，使 Web Agent 可以在安全的沙箱中自主生成训练任务并获得确定性奖励。解决了 Web Agent 训练中的核心问题：与真实网站交互存在安全风险，且标注成本高。训练出的 Agent 可泛化到未见过的网站，且效果随环境规模持续提升。

INSIGHTVeriEnv 的网站克隆思路对社区搜索 Agent 的训练有启发：可以将线上社区页面克隆为离线训练环境，让搜索 Agent 在安全沙箱中练习搜索、浏览、筛选等操作。这解决了 Agent 训练中最大的实践障碍——无法在线上系统中做 RL 探索。合成环境的可扩展性也意味着可以低成本生成大量训练场景覆盖长尾 query。

WebFactory: Automated Compression of Foundational Language Intelligence into Grounded Web Agents

提出 WebFactory，一个全自动闭环 RL 训练管线，将 LLM 编码的互联网知识压缩到可操作的 GUI Agent 中。集成了环境合成、知识驱动的任务生成、LLM 轨迹收集、分解奖励训练和 Agent 评估。仅用 10 个网站的合成数据训练的 Agent，效果可媲美大规模人工标注数据训练的 Agent，且在迁移基准上超越基础模型。

INSIGHTWebFactory 证明了少量网站的合成数据即可训练出有效的 Web Agent，这降低了搜索 Agent 训练的门槛。其'知识压缩'思路——将大模型的互联网理解能力蒸馏到小型可操作 Agent 中——可应用于社区搜索：用大模型理解社区内容结构，训练小型 Agent 执行实际搜索操作，在效率和成本间取得平衡。

VSearcher: Long-Horizon Multimodal Search Agent via Reinforcement Learning

提出 VSearcher 多模态搜索 Agent，利用强化学习使静态视觉语言模型具备长程 Web 交互能力，支持文本搜索、图像搜索和网页浏览的多轮工具调用。开发了合成数据方法生成复杂多模态问题，并建立了 MM-SearchExam 基准评估多模态搜索 Agent 能力。在 Web 检索任务上超越同量级多模态搜索系统。

INSIGHTVSearcher 展示了如何通过 RL 将普通视觉语言模型升级为主动搜索 Agent，这对社区搜索的多模态化有参考价值。社区中大量内容是图文混合的，VSearcher 的文本搜索+图像搜索+浏览三种工具的组合方式，可以用来构建社区内容的多模态检索 Agent——根据 query 自动决定是搜索文字、搜索图片还是直接浏览帖子详情页。
