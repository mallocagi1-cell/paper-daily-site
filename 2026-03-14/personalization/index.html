LASER: An Efficient Target-Aware Segmented Attention Framework for End-to-End Long Sequence Modeling

针对推荐系统中超长用户行为序列建模面临的 I/O 延迟高和注意力计算复杂度呈二次增长的问题，提出 LASER 框架。核心包含两大创新：(1) SeqVault——基于 DRAM-SSD 混合索引的统一 schema 感知服务基础设施，将检索延迟降低 50%、CPU 占用减少 75%；(2) 全局堆叠目标注意力 (GSTA) 模块，通过 sigmoid 过滤机制压缩长序列并捕获跨段依赖。在小红书超过 1 亿日活用户的大规模线上 A/B 测试中，ADVV 提升 2.36%，收入提升 2.08%。

CAMMSR: Category-Guided Attentive Mixture of Experts for Multimodal Sequential Recommendation

HKU📖 深度解读 · 3 分钟 →

针对多模态序列推荐中现有方法依赖启发式融合策略、无法捕捉用户-模态交互的动态性和上下文敏感性的问题，提出 CAMMSR。核心创新是类别引导的注意力混合专家 (CAMoE) 模块，从多视角学习专化的 item 表征并显式建模跨模态协同，通过辅助类别预测任务动态分配模态权重。同时引入模态交换对比学习增强跨模态表征对齐。在 4 个公开数据集上持续超越 SOTA 基线。被 ICDE 2026 录用。

INSIGHTCAMMSR 的核心启示在于：用户对不同模态信息（文本、图片）的偏好并非固定不变，而是随品类和上下文动态变化。MoE 结构天然适合处理这种异质性——不同专家负责不同模态视角的特征提取，通过类别信号引导门控实现自适应融合。对于社区搜索场景中帖子包含文字、图片等多模态内容的情况，该方法可直接借鉴：根据搜索 query 的类别动态调整对不同模态特征的关注权重，提升多模态内容排序的精准度。

Jinfeng Xu, Zheyu Chen, Shuo Yang, Jinze Li, Hewei Wang, Yijie Li, Jianheng Tang, Yunhuai Liu 等 9 人

FlexRec: Adapting LLM-based Recommenders for Flexible Needs via Reinforcement Learning

YaleSnap

提出 FlexRec 框架，通过强化学习训练 LLM 在不同推荐场景下按需调整排序行为。核心解决两个问题：(1) 序列级奖励导致的粗粒度信用分配无法提供精细训练信号；(2) 交互反馈稀疏且噪声大，导致更新不稳定。采用闭集自回归排序设定，LLM 基于用户上下文和显式需求指令生成候选集的排列。方法通过 token 级奖励分解和课程式 RL 训练策略提升训练效率和稳定性。

INSIGHTFlexRec 的核心价值在于探索了 LLM + RL 在推荐排序中的新范式：通过自然语言指令定义推荐需求（如「偏重新鲜度」或「偏重相关性」），让排序模型按需灵活切换。这与传统固定目标函数的排序模型形成鲜明对比。对搜索推荐系统的启示是：未来排序模型可能从「训练时固定目标」演进到「推理时动态指令驱动」，实现更灵活的个性化。Token 级奖励分解的思路也可借鉴到现有 RL 调优的推荐模型中。

Yijun Pan, Weikang Qiu, Qiyao Ma, Mingxuan Ju, Tong Zhao, Neil Shah, Rex Ying

Refine-POI: Reinforcement Fine-Tuned Large Language Models for Next Point-of-Interest Recommendation

UNSWUUvA

针对 LLM 用于 POI 推荐时 Semantic ID 拓扑盲编码和 SFT 方法「答案固化」两大问题，提出 Refine-POI。核心创新包括：(1) 层次化自组织映射 (SOM) 量化策略生成拓扑感知 Semantic ID，确保码本中坐标邻近性反映语义相似性；(2) 强化微调 (RLFT) 替代 SFT，支持 top-k 排序列表生成和推理能力学习。方法突破了传统 SFT 只能产生 top-1 预测的局限。

INSIGHTRefine-POI 中的拓扑感知 Semantic ID 设计值得关注：传统推荐系统中 item ID 的编码往往与语义无关，而该方法通过 SOM 层次量化确保 ID 空间保持语义拓扑结构，使 LLM 能更好地利用 ID 间的相对关系进行推理。对社区搜索场景的启示是：UGC 内容的 ID 编码如果能融入语义信息（如主题、发布者社区属性），可能有助于提升 LLM 辅助排序的效果。RLFT 替代 SFT 训练排序模型也是重要趋势。

Peibo Li, Shuang Ao, Hao Xue, Yang Song, Maarten de Rijke, Johan Barthélemy, Tomasz Bednarz 等 8 人

Social Knowledge for Cross-Domain User Preference Modeling

University of Haifa

提出利用大规模社交网络建模实现跨领域用户偏好预测。将用户投射到从 Twitter 大规模社交网络学习的社交 embedding 空间中，在目标领域零样本设定下实现有效的个性化推荐。实验表明，该方法相比强基线（popularity-based）有显著提升，并揭示了 embedding 空间中的人口统计特征与用户偏好的相关性。研究还探索了 LLM 辅助社交建模的潜力。

INSIGHT该工作的核心启示是社交关系图谱蕴含丰富的用户偏好信息，且这种信息具有跨领域迁移能力。在社区搜索场景中，用户的社交关系（关注、互动、社区归属）可作为冷启动和跨域推荐的重要信号源。零样本偏好预测能力对新用户或新内容品类的个性化排序特别有价值。社交 embedding + LLM 的组合思路值得探索。

Nir Lotan, Adir Solomon, Ido Guy, Einat Minkov

Sharpness-Aware Minimization for Generalized Embedding Learning in Federated Recommendation

ZJU

针对联邦推荐系统中通用 item embedding 学习的稳定性问题，提出 FedRecGEL 框架。在跨设备场景下，本地数据分布的异质性和稀疏性导致学习泛化 embedding 极为困难。FedRecGEL 将联邦优化重构为寻找 embedding 损失景观中的平坦最小值问题，通过锐度感知最小化 (SAM) 确保 embedding 在不同客户端数据分布上的泛化能力。提出适配联邦场景的高效 SAM 变体，降低计算和通信开销。

INSIGHTFedRecGEL 的技术贡献在于将 SAM 引入联邦推荐场景，但其核心洞察——通过寻找平坦最小值提升 embedding 泛化性——具有更广泛的适用性。在集中式推荐系统中，不同用户群体（子场景）之间的数据异质性同样会导致 embedding 过拟合局部分布。SAM 类正则化方法可借鉴用于提升社区搜索中 item embedding 在多样化用户群体上的泛化表现。

Fengyuan Yu, Xiaohua Feng, Yuyuan Li, Changwang Zhang, Jun Wang, Chaochao Chen
