KEY INSIGHT · 对业务意味着什么LLM可以作为无偏「标注员」为未曝光物品生成高质量伪标签，消除预排序模型仅在曝光数据上训练导致的选择偏差，对长尾内容尤其有效。业务关联 社区搜索中大量UGC内容属于长尾/未曝光内容，该方法可直接用于改善搜索召回后的预排序精度，提升长尾帖子的曝光公平性和搜索nDCG。证据 在大规模生产系统中部署，CTR提升3.07%，同时显著增强推荐多样性和长尾物品发现能力。

From Logs to Language: Learning Optimal Verbalization for LLM-Based Recommendation in Production

提出数据驱动框架，用强化学习优化用户行为日志到自然语言的转换，提升LLM推荐系统效果。

INSIGHT行为日志的「语言化」方式显著影响LLM推荐质量，通过RL训练的verbalization agent可自动学习最优转换策略，比手工模板提升明显。

业务关联社区搜索场景中用户有丰富的浏览/点击/搜索日志，该方法提供了将这些结构化日志高效转换为LLM可理解输入的生产级方案，可用于个性化搜索排序。

证据在大规模工业流式数据集上，学习的verbalization方式在发现类推荐准确率上实现最高93%的相对提升；RL agent自动学到用户兴趣摘要、噪声过滤、语法规范化等策略。

PRECTR-V2: Unified Relevance-CTR Framework with Cross-User Preference Mining, Exposure Bias Correction, and LLM-Distilled Encoder Optimization

📖 深度解读 · 9 分钟 →

统一搜索相关性匹配与CTR预测的框架升级版，引入跨用户偏好挖掘、曝光偏差校正和LLM蒸馏优化。

INSIGHT搜索系统中相关性和CTR两个核心目标应统一建模而非独立优化，V2通过跨用户偏好挖掘解决冷启动、曝光偏差校正提升泛化、LLM蒸馏增强语义理解。

业务关联直接匹配社区搜索的核心需求：nDCG（相关性）和CTR的联合优化。跨用户偏好挖掘对低活用户较多的社区场景尤为重要。

证据在PRECTR基础上解决了低活/新用户偏好建模、高相关性曝光分布偏移、编码器延迟等三大工业挑战；采用LLM蒸馏优化编码器语义能力并满足延迟约束。

IntRR: A Framework for Integrating SID Redistribution and Length Reduction

提出IntRR框架解决生成式推荐中 Semantic ID 的索引-推荐目标不一致和序列膨胀问题。

INSIGHT生成式推荐的核心瓶颈在于 Semantic ID 编码：索引阶段的优化目标与推荐目标错位，且层级ID展平导致序列过长。IntRR通过ID重分配和长度压缩双管齐下解决。

业务关联若社区搜索引入生成式召回范式，该框架可大幅降低推理延迟（序列长度缩减），同时提升召回质量，是生成式推荐工程化的重要技术。

证据在基准数据集上的实验表明，IntRR在推荐准确率和效率上均显著优于代表性生成式基线方法，同时实现了SID质量与序列长度的双重优化。

Zesheng Wang, Longfei Xu, Weidong Deng, Huimin Yan, Kaikui Liu, Xiangxiang Chu

HiGR: Efficient Generative Slate Recommendation via Hierarchical Planning and Multi-Objective Preference Alignment

提出HiGR高效生成式列表推荐框架，通过层级规划和多目标偏好对齐解决推理效率和多业务目标权衡。

INSIGHT生成式列表推荐的关键在于全局规划而非逐item解码，层级规划策略可同时兼顾推理效率和多目标（如相关性+多样性+新鲜度）业务需求。

业务关联社区搜索的SERP就是典型的列表推荐场景，该方法可同时优化搜索结果的相关性、多样性和时效性，减少生成式推荐的线上推理延迟。

证据离线推荐质量超越SOTA基线10%以上，推理速度提升5倍；在腾讯服务数亿用户的平台上线，平均观看时长提升1.22%，平均播放量提升1.73%。

HiSAC: Hierarchical Sparse Activation Compression for Ultra-long Sequence Modeling in Recommenders

📖 深度解读 · 12 分钟 →

提出分层稀疏激活压缩框架HiSAC，在推荐系统中高效建模超长用户行为序列。

INSIGHT超长用户行为序列的端到端建模在生产中不可行，HiSAC通过多级 Semantic ID 编码和层级投票机制实现个性化的序列压缩，保留长尾兴趣同时满足延迟要求。

业务关联社区搜索用户的浏览/搜索历史通常很长，该方法可高效编码用户长期兴趣用于个性化搜索排序，在生产延迟限制下提升个性化效果。

证据部署在淘宝「猜你喜欢」首页，线上A/B测试CTR提升1.65%，同时实现显著的压缩和成本降低。

Turning Semantics into Topology: LLM-Driven Attribute Augmentation for Collaborative Filtering

提出TAGCF框架，将LLM的语义知识转化为图拓扑结构增强协同过滤。

INSIGHTLLM语义信息最有效的利用方式不是直接做推理或简单特征拼接，而是转化为协同过滤图的拓扑连接——这在保持可扩展性的同时引入了丰富的语义信号。

业务关联社区搜索可用该方法将LLM对UGC内容的语义理解转化为内容间的拓扑关系，增强基于协同过滤的个性化召回效果。

证据在多个基准数据集和多种CF骨干网络上验证了一致性提升，包括冷启动场景的鲁棒性验证；代码已匿名开源。

Diffusion Generative Recommendation with Continuous Tokens

提出ContRec框架，将扩散模型的连续token引入LLM推荐系统，避免离散化导致的信息损失。

INSIGHT现有LLM推荐系统依赖向量量化的离散token存在信息损失，用扩散模型在连续空间直接建模物品表征可显著提升推荐精度，是生成式推荐的新范式。

业务关联为社区搜索的生成式召回提供了新方向：连续token避免了量化误差，可能在语义匹配精度上优于离散ID方案。

证据在4个数据集上的实验表明，ContRec在传统和SOTA的LLM推荐系统上均取得一致性优势。

Towards Generalizable and Efficient Large-Scale Generative Recommenders

📖 深度解读 · 8 分钟 →

Netflix将生成式推荐模型从百万参数扩展到十亿参数级别，验证了推荐系统的Scaling Law新规律。

INSIGHT推荐系统的Scaling Law不同于NLP的Chinchilla定律：模型规模增大需要配合多token预测和冷启动适配等对齐策略，才能将规模收益转化为生产效果提升。

业务关联为社区搜索的模型规模化提供了参考：直接增大模型不一定有效，需要特定的对齐策略确保规模收益落地。

证据模型从O(1M)参数扩展到O(1B)参数，在Netflix推荐任务上取得显著提升；发现了不同于Chinchilla定律和log-scale定律的新Scaling Law规律；采用多token预测和冷启动适配策略实现生产落地。
