From Logs to Language: Learning Optimal Verbalization for LLM-Based Recommendation in Production

用强化学习训练文本化智能体，自动学习将用户交互日志转化为LLM推荐系统的最优自然语言输入。

INSIGHT模板拼接不是最优方案——RL 智能体自主学会了兴趣摘要、噪声过滤和语法精炼策略，发现推荐准确率相对提升高达 93%，证明输入表示工程在 LLM 推荐中至关重要。

业务关联社区搜索可借鉴此方法将用户搜索/浏览日志转化为 LLM 可理解的文本，优化 query 理解和个性化重排，尤其适用于 LLM-based 搜索排序场景。

证据在工业流式数据上测试，发现类推荐准确率相对提升 93%；智能体自主发展出兴趣摘要、噪声过滤、语法精炼三种策略。

PRECTR-V2: Unified Relevance-CTR Framework with Cross-User Preference Mining, Exposure Bias Correction, and LLM-Distilled Encoder Optimization

📖 深度解读 · 9 分钟 →

提出统一搜索相关性与CTR预估的框架V2版本，新增跨用户偏好挖掘、曝光偏差校正和LLM蒸馏编码器。

INSIGHT搜索相关性和CTR可以在统一框架内协同优化：通过挖掘全局相关性偏好解决冷启动问题，用噪声注入构造困难负样本校正排序偏差，并用LLM知识蒸馏替代冻结BERT。

业务关联该框架直接解决社区搜索中相关性 (nDCG) 和点击率 (CTR) 的协同优化问题，特别是跨用户偏好挖掘可缓解低活跃用户和新用户的冷启动难题。

证据在前版 PRECTR 基础上，跨用户偏好挖掘提升低活跃用户相关性匹配；LLM蒸馏轻量编码器替代冻结 BERT 后 CTR 微调效果显著改善。

Generative Pseudo-Labeling for Pre-Ranking with LLMs

📖 深度解读 · 10 分钟 →

利用LLM生成伪标签解决预排序阶段的训练-服务偏差问题，改善长尾内容的预排序效果。

INSIGHT预排序模型只在已曝光样本上训练但需对全部召回候选打分，LLM 可为未曝光物品生成高质量伪标签，避免传统负采样的误标注和蒸馏方法的偏差传播。

业务关联社区搜索的预排序环节同样面临曝光偏差问题，尤其是长尾UGC内容（如冷门帖子）的排序质量可通过 LLM 伪标签显著改善。

证据解决了预排序中训练-服务偏差导致的样本选择偏差问题，在长尾内容推荐上泛化能力优于传统负采样和有偏蒸馏方法。

Adapting the Facebook Reels RecSys AI Model Based on User Feedback

Meta 提出 UTIS（用户真实兴趣调研）模型，超越点赞和观看时长等代理指标，直接利用用户反馈优化 Reels 推荐。

INSIGHT代理指标（点赞、观看时长）并不总能反映用户真实兴趣——通过直接建模用户反馈信号，UTIS 模型帮助推荐系统发掘更多小众优质内容，提升长期用户满意度。

业务关联社区搜索的排序模型也依赖 CTR 等代理指标，Meta 的经验表明直接融入用户反馈信号可改善内容推荐质量，尤其适用于 UGC 平台的内容多样性提升。

证据在 Facebook Feed 和 Reels 上部署，有效提升小众优质内容的曝光率；UTIS 模型作为 Reels 推荐系统的核心反馈信号之一在生产环境中运行。

Position-Aware Sequential Attention for Accurate Next Item Recommendations

提出核化自注意力机制，通过独立的位置核与语义信息解耦，增强序列推荐中的时序建模能力。

INSIGHT加性位置 embedding 使注意力机制对序列顺序仅表面敏感——独立的可学习位置核可在不与语义信息纠缠的前提下调制注意力权重，实现多尺度序列建模。

业务关联社区搜索中的用户行为序列（搜索→点击→浏览）具有明确时序性，改进位置编码可提升搜索 session 内的行为建模和 next-item 预测精度。

证据在多个 next-item 预测基准数据集上一致优于 SASRec、BERT4Rec 等主流序列推荐 baseline。

Turning Semantics into Topology: LLM-Driven Attribute Augmentation for Collaborative Filtering

提出 TAGCF 框架，利用 LLM 分析用户-物品关系并转化为图拓扑中的中间节点，增强协同过滤。

INSIGHTLLM 语义知识不必直接替代协同过滤——将语义信号转化为图的拓扑连接（中间属性节点），通过自适应关系加权图卷积动态评估不同关系类型的重要性，在冷启动场景效果显著。

业务关联社区搜索中新帖子和新用户的冷启动问题突出，TAGCF 利用 LLM 语义丰富协同信号的思路可用于改善冷启动推荐质量。

证据在多个推荐数据集上提升推荐精度，冷启动场景下表现尤为突出，验证了框架的有效性和鲁棒性。

IntRR: A Framework for Integrating SID Redistribution and Length Reduction

提出集成 Semantic ID 重分布和序列长度压缩的生成式推荐框架，解决索引目标与推荐目标不对齐问题。

INSIGHT生成式推荐中 Semantic ID 的索引阶段目标与推荐阶段目标存在错位，且层级ID展平导致序列膨胀——IntRR 通过动态重分布和长度压缩同时解决这两个瓶颈。

业务关联生成式推荐是下一代推荐系统的重要方向，IntRR 的 SID 优化技术为社区平台未来向生成式推荐架构演进提供了关键的效率改进方案。

证据解决了SID索引-推荐目标不对齐和序列长度膨胀两大问题，在生成式推荐基准上推理效率和推荐质量均有提升。

Modality-Guided Mixture of Graph Experts with Entropy-Triggered Routing for Multimodal Recommendation

提出 MAGNET 框架，用模态引导的图专家混合网络和渐进熵触发路由策略解决多模态推荐中的模态冲突问题。

INSIGHT多模态信号本质上异构且可能在特定场景下冲突——共享融合路径导致表征纠缠和模态失衡，按模态分配专家图网络并用熵驱动路由可实现更精准的融合。

业务关联社区 UGC 内容包含文本、图片等多模态信息，MAGNET 的模态感知融合策略可改善多模态社区内容的推荐和搜索排序质量。

证据在多个多模态推荐基准上验证，在稀疏反馈和长尾分布场景下效果尤为显著，缓解了模态失衡问题。

E-MMKGR: A Unified Multimodal Knowledge Graph Framework for E-commerce Applications

构建电商专用多模态知识图谱，通过 GNN 传播和 KG 优化学习统一物品表示，支持推荐和检索多任务。

INSIGHT现有多模态推荐依赖固定模态集合和任务特定目标——统一的多模态知识图谱可提供共享语义基础，一套表示同时服务推荐、检索、分类等多个下游任务。

业务关联社区搜索中帖子包含文本、图片等多模态内容，E-MMKGR 的统一表示学习思路可用于构建社区内容的多模态知识图谱，同时支撑搜索和推荐。

证据在 Amazon 真实数据集上推荐 Recall@10 提升最高 10.18%；商品检索准确率比纯向量检索提升 21.72%。
