RSAT: Structured Attribution Makes Small Language Models Faithful Table Reasoners

针对 SLM 在表格问答中无法验证「哪些单元格支撑了哪一步推理」的可信度问题，作者提出 RSAT：两阶段训练框架，让 1-8B 的小模型在生成 step-by-step 推理时同时输出单元格级引用。Phase 1 用 SFT 学习结构化 JSON 输出格式；Phase 2 使用 GRPO 优化由 NLI 忠实性、引用合法性与简洁性组成的复合奖励。在 Qwen2.5 (1.5B/3B/7B) 与 Llama 3 (1B/3B/8B) 共 6 个模型上，忠实性从 0.224 提升至 0.826（3.7× 提升），引用合法性达 0.992；ablation 显示去掉忠实性奖励，分数从 0.97 跌到 0.03。

Why Do LLMs Struggle in Strategic Play? Broken Links Between Observations, Beliefs, and Actions

UUT Austin

本文系统剖析 LLM Agent 在不完全信息策略博弈中的失败机理。作者用 Llama 3.1、Qwen3、gpt-oss 三类开放权重模型做实验，揭示两条关键断链：(1) observation-belief gap——模型内部探针解码的 belief 比模型的口头报告更准，但在多跳推理下会迅速衰减，并出现首因/近因偏置以及偏离贝叶斯一致性；(2) belief-action gap——内部 belief 转化为动作的链路较弱，模型常按表面信念而非内部实际信念行动。

INSIGHT对于 Agent 化搜索场景，本文给出了「内部表征 ≠ 外部输出」「多步推理会导致 belief 漂移」的实证证据，提示在 Agent Pipeline 中应显式地把「belief 提取 → 决策」做成可观测的中间产物（如外置工作记忆、显式推理图）而不是依赖 LLM 自我报告。对设计基于 LLM 的查询改写、复杂问答 Agent 时，应控制推理跳数、引入校准机制（probing classifier）来缓解 belief 漂移。

Jan Sobotka, Mustafa O. Karabag, Ufuk Topcu

Are You the A-hole? A Fair, Multi-Perspective Ethical Reasoning Framework

面向高冲突场景下的多观点聚合，作者提出神经-符号融合框架：用 LLM 把自然语言判断映射成可解释的逻辑谓词及其置信权重，再编码为 Z3 求解器中的软约束，将聚合问题转化为加权 MaxSAT 优化任务，求最大一致性裁决。在 Reddit r/AmItheAsshole 数据上，系统生成的逻辑一致裁决与多数投票标签出现 62% 分歧，但与独立专家标注一致率达 86%。

INSIGHT对社区 UGC 场景的启示是显著的：当帖子涉及争议或评论冲突时，简单多数票/加权 CTR 可能放大偏见，本文给出可在线推理的「LLM-生成约束 + SAT 求解」范式，可用于评论排序中的「多视角综合分」、争议帖去噪、社区合规审核 Agent 等。MaxSAT 编码也使得最终决策具有可解释性，便于审核人复核——这是把 LLM Agent 输出转成可信赖业务决策的实用路径。

Sheza Munir, Ahanaf Rodoshi, Sumin Lee, Feiran Chang, Xujie Si, Syed Ishtiaque Ahmed

04 3.55

Persona-Grounded Safety Evaluation of AI Companions in Multi-Turn Conversations

面向 AI 陪伴 Agent 的安全风险，作者提出首个端到端可扩展的多轮对话安全评估框架。框架包含四模块：基于临床/心理量表验证的 persona 构建、persona-specific 场景生成、带 dialogue refinement 的多轮模拟（保持 persona 一致性）、以及伤害评估。对 Replika 进行评估，构造了覆盖抑郁、焦虑、PTSD、饮食障碍、incel 等高危群体的 9 个 persona，采集了 1674 对对话用于伤害打分。

INSIGHT对社区/客服 Agent 来说，多轮对话中长期 persona 漂移和场景诱导失败是关键风险。本文给出的 persona-driven simulation 范式（构造 → 场景 → 多轮模拟 → 伤害打分）可直接迁移到 UGC 社区的「Agent 多轮回复」上线前红队评估、敏感话题处理回归测试，特别适合做青少年/弱势群体子场景的离线安全把关。dialogue refinement 模块对解决 LLM 模拟用户「跑偏」是重要工程点。

Prerna Juneja, Lika Lomidze

Budget-Aware Routing for Long Clinical Text

针对长文本场景下 LLM Agent 调用成本/延迟受限的问题，作者把 budget-aware 上下文选择形式化为带 token 预算的 knapsack 子集选择问题，提出 RCD：单调子模目标，平衡相关性、覆盖度与多样性；并在句子/章节/窗口/聚类四种切片粒度上比较，再设计依据预算自适应的 routing heuristic。在 MIMIC discharge notes、Cochrane abstracts 与 L-Eval 三个数据集上表明，最优策略随评估场景变化，所提路由能在严格 token 预算下稳定接近无预算上限性能。

INSIGHT在 Agentic RAG 体系中，「检索回多少 chunk、塞多少进 prompt」往往是延迟与质量的主要折衷点。本文将其建模成子模优化 + 自适应 routing，思路可直接迁移到搜索/推荐场景的 Agent 工作流：例如多轮 Agent 在每跳设定 token 预算上限，按 RCD 分数挑 chunk 进入下一步推理。对工程实现也很友好——子模优化可贪心近似，无需复杂训练，而 routing heuristic 让线上不同流量等级（VIP / 风控审核 / 普通搜索）共享一套上下文压缩组件。

Khizar Qureshi, Geoffrey Martin, Yifan Peng

Proceedings of the Workshop on Information Retrieval's Role in RAG Systems (IR-RAG 2025) co-located with SIGIR 2025

SIGIR 2025 同期举办的 IR-RAG 2025 Workshop 论文集，主题聚焦「IR 在 RAG 系统中的角色」，由 Meta、Sapienza 大学等机构共同组织。Workshop 文章覆盖检索器与生成器的协同优化、混合检索（dense + sparse）在 RAG 中的对比、retrieval-aware 提示工程、Agent 多步检索与 reranking、以及 RAG 系统评估方法等，把传统 IR 工具箱与 Agentic RAG 实践串了起来。

INSIGHT对工业搜索/UGC 推荐团队，IR-RAG workshop 提供了一个汇聚视角：RAG 不是「向量检索 + LLM」这么简单，而需要把 IR 的 query reformulation、learning-to-rank、负样本挖掘等积累系统性嫁接到 Agent pipeline 中。建议把该 workshop 作为「过去半年 RAG/Agent 工业实践趋势」入门读物，挑选与社区 UGC 检索强相关的若干文章（如 retrieval reformulation、负样本利用）逐篇精读。

Optimize Supply Chain Decision Systems Using NVIDIA cuOpt Agent Skills

NVIDIA

NVIDIA 开发者博客介绍如何用 cuOpt Agent Skills 模式构建供应链决策系统。Agent Skills 把传统优化求解器（cuOpt）封装为 LLM Agent 可调用的细粒度工具：配送路径规划、库存再平衡、产能约束求解等被拆成独立 skill，由 LLM Agent 在多目标任务中按需编排，结合实时数据触发求解器，再让 LLM 解释结果给业务方。文章给出 Agent Skill 模式与单纯 function calling 的差异及在复杂决策问题上的优势。

INSIGHTAgent Skills 是 2026 年 LLM Agent 工程的重要范式：把高价值领域引擎（求解器、风控规则、推荐策略服务等）拆成原子 skill，让 Agent 自由组合调用。对搜索/推荐团队的启示在于——把 query 改写、QU 服务、个性化召回等内部能力封装成 skill，可以用 LLM Agent 编排来响应复杂搜索意图（如多轮筛选、跨场景比较），同时保持线上低延迟核心链路不变。本文示范了 Agent + 求解器结合的稳定生产架构。

How OpenAI delivers low-latency voice AI at scale

OpenAI

OpenAI 发文披露其语音 AI（Voice Mode + Realtime API）背后的低延迟基础设施。核心是重写了 WebRTC 栈以承载实时 Voice AI：在全球边缘节点完成音频编解码与抗丢包、端到端 RTT 控制、对话轮次（turn-taking）的 endpointing 与打断检测，并把语义层与传输层的时序信号深度融合，使语音 Agent 能流畅地承接和打断对话。

INSIGHT对正在尝试「语音 Agent + 搜索」的团队，本文是少见的工业级实时基础设施披露。关键工程经验包括：把 turn-taking 与 endpointing 当作语义任务而非纯 VAD 来设计；让 WebRTC、模型推理、工具调用共享同一时间轴以做端到端的延迟预算管理。社区 UGC 场景若要做语音问答 Agent（如「读评论 + 互动」「电台模式 Agent」），可参考本文的边缘部署策略与对话状态机设计。

Chat2Trade: Automating Financial RFQ Parsing with Fine-Tuned LLMs

已录用 KDD 2026

KDD 2026 接收论文，把金融场外 RFQ（Request-for-Quote）流程中非结构化中英文聊天消息自动解析为结构化交易要素的工业级方案。作者构造了高质量的 RFQ 标注数据集，针对开源 LLM 进行多任务微调，覆盖产品识别、数量、报价、时效等字段抽取，并设计了交易侧的纠错与回查链路，把模型部署到券商业务系统中替代人工解析。

INSIGHTChat2Trade 是把 LLM Agent 嵌入「专业领域非结构化输入 → 结构化下游系统」业务链路的代表案例。对社区 UGC 搜索来说，本文方法论（领域指令微调 + 高质量行业语料 + 错误回查 Agent）可迁移到「UGC 帖子分类/属性抽取」「评论中的关键事实抽取喂入索引」等任务。其多字段抽取的训练目标设计，比单纯 NER 适合更复杂的复合属性场景。

Yixuan Cao, Chunhao Yang, Yifan Wang, Jian Wang, Kun Wan

Agentic AI for Substance Use Education: Integrating Regulatory and Scientific Knowledge Sources

作者搭建了一个面向药物使用教育的 Agentic Web 应用：把美国 DEA 监管数据库与 PubMed peer-reviewed 文献做实时融合，使用 RAG 检索 102 篇精筛文档构成的语义切片向量库，并对 PubMed 做动态在线查询。系统由检索-生成-引用核查多 Agent 编排，并由 5 名领域专家组成评审小组，对系统在权威性、上下文敏感、即时性等维度上做盲评。

INSIGHT本文示范了「双源 Agentic RAG」架构：把权威静态语料（DEA 法规）与高时效动态查询（PubMed API）共生检索，并以专家盲评作为最终把关。这套架构对社区/电商 UGC 场景同样适用——可把站内静态知识（FAQ、规则库）和动态实时召回（最新 UGC 帖子、热搜）融合到同一 Agent，再加合规审核 Agent 做兜底。专家盲评流程也提示我们：Agentic 应用需要建立结构化人审通路而非只看自动指标。

Kosar Haghani, Zahra Kolagar, Mohammed Atiquzzaman
