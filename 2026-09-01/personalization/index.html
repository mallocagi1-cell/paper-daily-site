HubMixer: Progressive Latent Hub Mixing for Parameter-Efficient Feature Interaction in Recommendation

针对推荐与广告排序中异构特征直接全量混合导致参数浪费的问题，HubMixer 用少量可学习 latent hub 依次执行特征归纳、hub 间高阶交互和 token 条件化回写，复杂度从 token 两两交互转为与 T×H 成正比。快手招聘短视频业务的 7 天 A/B 测试覆盖 7.2% 流量，简历投递转化率显著提升 5.48%，模型已全量部署。

02 4.10

Personalized and Multi-View Representation for Federated Cold-Start Recommendation

POSTECHUIUC📖 深度解读 · 13 分钟 →

PMFRec 面向服务端看不到用户交互、客户端又看不到专有物品属性的双边约束，解决零交互新物品的联邦冷启动。它用用户专属表示生成器、多视图编码器、物品自适应门控与正交约束融合协同和属性知识；在 CiteULike 与 3 个 XING 规模设置共 4 组数据上评估，覆盖 Recall、Precision、NDCG 的 @5/@10/@20 指标。

INSIGHT关键工程价值是把原先需要反复交换的协同表示与属性表示合并为单一物品表示，并用闭式岭回归拟合用户映射，减少客户端正则项和通信负担。对于 UGC 新内容冷启，可把文本、作者与主题属性拆成互补视图，再用用户级门控生成不同冷内容表示；同时要评估 LDP 预算 ε=4、8、10 下的效果退化。

Jaehyung Lim, Wonbin Kweon, Woojoo Kim, Junyoung Kim, Dongha Kim, Hwanjo Yu

03 4.10

Information-Guided Selective Modality-Interest Alignment for Multimodal Recommendation

AMUR 针对多模态推荐把所有图文信号无差别对齐、弱相关模态反而引入噪声的问题，提出信息论驱动的选择性模态—兴趣对齐框架。方法显式增强与用户兴趣相关的信息并抑制无关信号，在多个真实推荐数据集及不同骨干模型上进行对比和消融；论文于 2026-08-31 发布，直接覆盖多模态个性化场景。

INSIGHT对社区内容推荐而言，图片、正文、标题和互动统计不应使用固定融合权重；应先估计每种模态对当前用户兴趣的有效信息量，再决定对齐强度。该设计适合以旁路模块接入现有多模态召回或排序模型，并通过分模态消融检查收益是否来自真正的兴趣匹配，而不是额外参数规模。

Wenze Ma, Chenyu Sun, Yanmin Zhu, Qiwen Gu, Xuhao Zhao

SG-UMP: Sequence-Guided Universal Multimodal Prioritization Calculation Framework

SG-UMP 解决多模态序列推荐同时存在用户偏好差异和数据集级模态偏置的问题，以可插拔方式加入 Module Combiner 与 Module Router：前者组合不同模态处理单元，后者依据交互序列动态决定模块优先级。论文在 4 个真实数据集、多个推荐骨干和多模态设置上均报告稳定增益，强调无需重写主干即可适配。

INSIGHT比固定的图文融合层更值得借鉴的是“按用户序列路由处理顺序”：同一帖子对视觉敏感用户与文本敏感用户应经过不同模态路径。落地时可把 router 输出记录为可观测特征，并按用户活跃度、内容类型与冷启动阶段切片验证；由于证据主要是离线实验，进入线上前仍需重点测路由开销和稳定性。

Xinyi Zhang, Yutong Li, Peijie Sun

05 3.65

UniGCRec: Unified User-Item Quantization for Generative Cross-Domain Recommendation

Microsoft

UniGCRec 面向跨域序列推荐在用户或物品重叠很低时迁移失效的问题，同时把用户画像与物品量化为融合语义、协同信号的 CSC-ID。生成器以用户 CSC-ID 前缀和目标域历史为条件预测下一物品，并用 trie 约束保证输出属于目标域；KDD 2026 论文在公开多域基准上相对强基线取得一致提升。

INSIGHT用户与物品使用同一离散 ID 空间，使跨域迁移从隐式序列向量变成可控的显式偏好锚点，能减少无关源域信号被错误搬运。对搜索与推荐联动场景，可尝试用统一离散码连接搜索行为、社区消费和电商兴趣，但应保留域约束解码，并监控量化码坍缩与长尾物品覆盖。

Chaoyue Ding, Jiahao Liu, Dongsheng Li, Shengkang Gu, H. Gu, Peng Zhang, Ning Gu, Tun Lu

06 3.55

UCB-Based Feature Engineering for Cold-Start in Recommenders

该 KDD 2026 工作把冷启动特征工程建模为基于 UCB 的不确定性探索：在交互极少时，不只利用当前最强特征，还主动探索置信区间较宽、可能带来增益的信号。方法覆盖新用户与新物品场景，目标是在有限观测预算下平衡 exploitation 与 exploration；公开页面确认论文于 2026 年 8 月进入 KDD 论文序列。

INSIGHT冷启动阶段的核心并非一次性选定静态特征，而是根据反馈逐步调整特征采集优先级。社区业务可把内容语义、作者质量、少量早期互动和跨场景行为视为候选臂，用 UCB 控制探索流量；上线时必须限制单臂预算并设置保底排序，避免不确定性奖励放大低质内容曝光。
