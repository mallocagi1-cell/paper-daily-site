UniFormer: Efficient and Unified Model-Centric Scaling for Industrial Recommendation

针对工业推荐里组件各自扩参（行为建模、特征交互、任务建模分别 scaling）缺乏统一框架的问题，UniFormer 把整个建模空间拆成特征空间与任务空间，分别用堆叠的 Feature-space / Task-space Interaction Module 建模，并用语义 token 化实现 user-item 解耦做到 request 级推理加速；多序列 cross-attention 分别刻画异构行为以防偏好坍塌，多视角 FFN 支持各组件灵活扩参。快手与快手极速版双场景在线 A/B：App 时长 +0.101%/+0.260%，观看时长 +0.729%/+1.113%。

ScaleToT: Generalizing Structured LLM Reasoning for Billion-Scale Low-Activity User Modeling

Kuaishou

针对数十亿低活用户缺乏交互历史、LLM 在稀疏 profile 上推理不可靠且全量推理算力不可承受的问题，ScaleToT 先用 LLM 在小样本上构造带类型的 user-state chain（有界熵引导的 Tree-of-Thought 精炼），再用 SFT + OSIPO（Outcome-Driven Segment-Aware Implicit Reward 策略优化）把推理蒸馏进 student，最后迁移到轻量 profile encoder，使其余用户无需 LLM 推理即可获得推理信号。广告 LTV 场景在线 A/B 使 LT30 +6.738%，离线只对 7.32% 人群跑 LLM 推理，大幅压低算力。

INSIGHT给 LLM 推理 + 蒸馏到轻量 encoder 提供了一条可上量的路径：仅对 7.32% 高价值人群跑 LLM、其余靠 encoder 共享推理表征，把算力压到可接受范围。对低活/冷启用户建模，typed user-state chain 比自由文本 CoT 更可控；OSIPO 这类按 segment 给隐式 reward 的策略优化，值得在 LTV/留存类目标上借鉴。

SocialPersona: Benchmarking Personalized Profiling and Response with Multimodal Social-Media Context

HIT

现有个性化评测多停留在记住用户在对话里明说的偏好，SocialPersona 转而考查 MLLM 能否从用户社媒时间线（文本+图像+时间戳）反推 revealed preference。基准取自 171 名真实非营销用户的长时间线，含 2,597 条人工核验偏好标签、覆盖 7 个兴趣域，并区分稳定兴趣与近期兴趣；设构造结构化用户画像和按画像生成回复两个任务。实验显示模型能识别粗粒度兴趣域，但在细粒度、近期兴趣上明显下降，画像用于对话个性化时进一步退化。

INSIGHT对社区 UGC 平台直接相关——从用户自然留下的帖子/图片反推兴趣，正是 feed 与搜索个性化的上游。两个发现可落地：一是文本与图像提供互补偏好信号，单模态画像会漏信息；二是近期兴趣最难捕捉，提示线上画像要单独维护短期兴趣通道，而非只靠长期累积。

Qinkai Zhang, Yanyan Zhao, Xin Lu, Yulin Hu, Pengtao Han, Bing Qin

From Clicks to Intent: Cross-Platform Session Embeddings with LLM-Distilled Taxonomy for Financial Services Recommendations

Capital One

金融场景里登录前 web 浏览（探索新产品）与登录后 app 行为（账户服务）差异大，且匿名 web session 难与认证账户做实体对齐，导致 web 意图信号在登录后个性化中被浪费。本文用自监督 Transformer 把多模态点击流编码成紧凑 session embedding，再用 LLM 生成意图 taxonomy 并蒸馏成可解释标签。移动首页 tile 排序上 session embedding 把 macro Recall@1 提升 1.88%、Log Loss 降低 13.38%；转化预测上 embedding 比 LLM 标签高 4.3%（micro F1），蒸馏层以约 7% 性能损失换超低延迟可解释标签。

INSIGHT给出自监督 session 表征 + LLM 蒸馏 taxonomy 的双产出范式：embedding 喂排序/转化等量化任务，蒸馏标签做可解释与冷启。对社区搜索同样适用——把登录前后跨端点击流统一成 session embedding，可把游客期意图带入登录后排序；蒸馏标签 7% 损失换超低延迟，是在线可解释特征的合理取舍。

TRUST: Item-Calibrated Interval Evidence for Temporal Session-Based Recommendation

UTS

时序 session 推荐常直接用绝对时间间隔，隐含假设相同间隔对不同 item 含义相同。作者实证发现该假设不成立：每个 item 有自己的间隔分布，间隔应相对该 item 的经验分布来解读。TRUST 据此提出一个打分函数，把 item 校准后的间隔证据注入全局邻居采样、session 图编码与兴趣聚合三个环节。多个公开数据集上稳定优于时序与非时序基线，作为 model-agnostic 插件还能提升已有时序 session 推荐器；消融显示在各模块内校准时间信号比直接删掉模块更有效。

INSIGHT一个低成本可迁移的改进点：把时间间隔从绝对值改成相对该 item 的分布分位，再接进采样/编码/聚合。因为是 model-agnostic 打分函数，可作为插件加到现有 GNN/序列 session 模型上，适合社区短行为序列里同样隔 1 小时、对热门贴和长尾贴意义不同的场景。

Linjiang Guo, Nitin Bisht, Shiqing Wu, Yifan Yin, Guandong Xu

AgentX: Towards Agent-Driven Self-Iteration of Industrial Recommender Systems

Kuaishou

推荐算法迭代仍受限于想法到上线依赖人写代码、开 A/B、归因，创新随人头线性增长。AgentX 是已在生产部署的多智能体系统，把这条链做成自我进化引擎：Brainstorm Agent 综合历史实验/架构/数据/外部研究产出可执行提案并排序；Developing Agent 基于仓库上下文生成生产级代码并做多维可靠性校验；Evaluation Agent 带 guardrail 否决做安全灰度 A/B，把成功与失败都沉淀为结构化知识；Harness Evolution 层（SGPO）把执行轨迹蒸成语义梯度反过来打磨各 Agent。

INSIGHT把实验经验变成可复利的资产——失败实验也结构化沉淀，这点对推荐团队的研发提效最有借鉴。SGPO 用语义梯度更新 Agent，把强化学习式的轨迹蒸馏迁到 Agent 自我改进上；落地门槛在于 guardrail 与可靠性校验体系，没有这套安全网，自动改生产代码风险极高。

NOVA: A Verification-Aware Agent Harness for Architecture Evolution in Industrial Recommender Systems

ByteDance

工业广告推荐靠架构演进（RankMixer、TokenMixer-Large、MixFormer 等）持续提升，但人工开发成本高；AutoML 只调超参，通用 LLM 编码 Agent 只保证代码能跑而非是合法的推荐架构，易出静默失效。NOVA 提出 verification-aware 的 Agent harness：用 architecture gradient（类 SGD 的不可微更新信号，聚合历史修改、校验诊断、指标反馈与轨迹记忆）指导下一步改动；verification cascade 逐级校验结构语义/可执行/离线有效/在线影响，无效候选早停并记为禁止方向；L1–L4 按风险路由，高风险交人工。部署于工业广告系统，L2/L3 任务有效通过率 54.5%/60.0%，文献到生产周期人工耗时缩短 13 倍以上；在线 A/B 三个 pCVR 目标 GMV +1.25%/+1.70%/+2.02%，pCVR bias 降 58.8%/66.7%/37.3%。

INSIGHT关键创新是验证级联 + 架构梯度——把 recsys 特有的有效性检查（结构语义、离线指标、在线影响）做成早停门，挡住能跑但拉垮指标的静默失效，这正是通用编码 Agent 改推荐模型最大的坑。L1–L4 按风险分级、高风险转人工，是自动化改生产模型可落地的安全设计；pCVR bias 同步下降说明架构搜索目标要带校准约束。

Attributed, But Not Incremental: Cannibalization-Corrected Attribution for Large-Scale Advertising

ByteDance

大规模付费拉新里，付费归因的转化（如 DNU 日新增用户）会在付费渠道与自然流量/品牌流量重叠时系统性高估真实增量，扭曲增量 ROI 与预算决策。本文提出实验校准的归因修正框架：用 incrementality 实验作因果锚点，把稀疏的 lift 测量转成每日修正估计，再在结构一致性约束下把校准后的 cannibalization 量分摊到业务层级，使修正信号在生产粒度可用。离线 forward-in-time 验证显示其校准误差显著低于原始归因与细粒度 ML 基线；在多个 TikTok 全球市场部署后，实测 cannibalization rate 下降约 15 个百分点。

INSIGHT提醒做增长/广告的团队：归因数字不等于增量，付费与自然流量重叠会让预算分配失真。方法论可借鉴——用少量 incrementality 实验当因果锚，把稀疏 lift 外推成每日、可分摊到业务层级的修正量，比纯 ML 归因更稳。对社区平台的增长投放与渠道诊断，这套实验锚 + 结构一致性分摊思路可直接迁移。

Donghui Li, Bowen Yuan, Zili Yang, Qinxin Chen, Lijing Song

EMA-FS: Accelerating GBDT Training via Gain-Informed Feature Screening

GBDT（以 LightGBM 为例）训练时 65–70% 时间花在逐特征建直方图上，而随机子采样（feature_fraction）丢特征时不看预测价值。EMA-FS 维护每个特征 split gain 的指数滑动平均，热身后只对历史 gain 排名 top-K 的特征建直方图，保留高增益、筛掉低增益，且兼容 LightGBM 直方图相减技巧、无需改核心。在欺诈检测、广告 CTR、工业质检等数据上：500 维合成集加速 2.61×，432 维 IEEE-CIS Fraud 在 30% 保留率下 1.45×；70% 保留率时 AUC +0.11 且 1.34× 加速；极稀疏数据无加速。另给出 S-EMA-FS 用 gain 加权随机采样统一确定性与随机两种策略，约 120 行 C++。

INSIGHT一个即插即用的训练提速点：CTR/风控等仍重度依赖 GBDT 的链路，用 gain EMA 做有信息的特征筛选比随机子采样更划算，70% 保留率还能小涨 AUC。约 120 行 C++、兼容直方图相减、向后兼容，迁移成本极低；但对极稀疏特征无收益，需先看自家特征稠密度再决定是否上。

Yan Song

Scoring Is Not Enough: Addressing Gaps in Utility-fairness Trade-offs for Ranking

UUIC

检索/推荐里普遍用学到的打分函数对 item 排序以最大化效用，公平性研究也多在打分上做效用-公平权衡。本文用一系列反例证明：相比纯效用目标，打分函数无法达到所有效用-公平权衡点——无论打分是确定的还是随机的、公平性在单 query 还是跨 query 度量，结论都成立。正面结果是：半贪心（semi-greedy）的后处理能在可计算的代价下逼近穷举后处理的理想权衡。

INSIGHT给排序公平性敲警钟：只调打分函数（即便随机化）存在理论上达不到的权衡区，想要更好的效用-公平折中要在排序后处理阶段做。对需要满足多样性/曝光公平约束的社区 feed，结论提示把公平约束放到 re-rank 后处理（半贪心）比硬塞进打分模型更有效，且半贪心代价可控。

Shubham Singh, Ian A. Kash, Mesrob I. Ohannessian
