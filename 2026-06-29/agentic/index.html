Why Multi-Step Tool-Use Reinforcement Learning Collapses and How Supervisory Signals Fix It

工具调用让 LLM 完成复杂任务，agentic RL 近期被用来增强工具使用能力，但纯 RL 在工具任务上常不稳定甚至“灾难性崩溃”——性能骤降、工具调用结构失效。论文分析发现崩溃源于特定控制 token 的概率异常飙升，破坏了结构化执行，而底层工具使用能力其实仍完好，只是被格式问题掩盖。作者系统考察了多种监督信号（off-policy 监督、提示引导、错误示例监督等）在同步与交错（interleaved）两种训练方案下的效果，发现交错式监督能稳住训练、修复结构崩溃。

Beyond Function Calling: Benchmarking Tool-Using Agents under Tool-Environment Unreliability

LLM 越来越多作为 agent 通过调用外部工具环境完成任务，但现有工具使用基准大多假设工具环境干净、稳定、可信，对工具环境的不可靠性考察不足。论文提出 ToolBench-X，评测 agent 在“可恢复”可靠性风险下的表现：包含跨多领域的可执行多步任务，覆盖串行、并行、混合工作流，每个任务配确定性工具和唯一标准答案以便自动评测。从干净环境出发注入五类结构化风险——规格漂移、调用错误、执行失败、输出漂移、跨源冲突，且每个注入实例仍可解。

INSIGHT现实里搜索/工具 agent 调的 API 会超时、返回脏数据、不同源给冲突答案，ToolBench-X 把这些“可恢复风险”做成可控注入的基准，比干净环境基准更贴近生产。五类风险（尤其跨源冲突、输出漂移）正是社区搜索接多路召回/外部服务时的常见故障；用它压测能暴露 agent 在工具不可靠时是硬崩还是能恢复，是上线前 robustness 评估的实用工具。

Yang Tian, Zhengpeng Shi, Bo Zhao

03 3.45

Semantic Consistency Policy Optimization for Reinforcement Learning of LLM Agents

群组式 RL（如 GRPO）通过从轨迹结果推导步级 credit 来后训练长程稀疏奖励的 LLM agent，但这把某一步的 credit 绑死在其 rollout 的最终成败上：语义近乎相同的中间步，仅因所在轨迹最终成功或失败而获得相反 credit，给相似动作发出冲突梯度，也浪费了失败 rollout 里部分正确的进展。论文提出 SCPO，一种无价值函数的奖励塑形方法：把每个失败步与同组成功“兄弟”轨迹中的对应步比对，为沿成功兄弟方向的新进展补正的步级 credit。

INSIGHT“语义相同的中间步因最终成败被打反号”这一 credit 不一致问题，在多步搜索/推理 agent 里普遍存在——同一次合理的检索动作可能因后续无关错误被惩罚。SCPO 用同组成功兄弟回捞失败轨迹里的正确子步，是 value-free、易接在 GRPO 上的改造，对训练多轮检索 agent 时回收“部分正确进展”很有借鉴价值。

Peng Xu, Sijia Chen, Junzhuo Li, Xuming Hu

04 3.45

To Isolate or to Score? Model-Adaptive Assessment for Cost-Efficient Multi-Agent RAG

面向 RAG 的多 agent 文档评估计算开销大，迫使实践者转向更小的可部署模型，但这些小模型的评估机制尚不清楚。论文在 7B–9B 指令模型、多个 QA 基准上做了受控研究，发现一个鲜明二分：对较弱基座，主导机制是“逐文档隔离”——无评分的隔离竟能匹配完整多 agent 评估，说明化解多文档上下文混淆（而非打分质量）带来高达 50 个百分点的增益；对强基座则打分质量才重要，作者提出 Reasoning-Score Coupling 这一无标签扰动探针来分类打分行为。

INSIGHT这个“弱模型靠隔离、强模型靠打分”的二分很反直觉也很实用：上线小模型做 RAG 文档评估时，先把多文档拆开逐条处理消除上下文干扰，可能比堆多 agent 打分更划算（最高 50pp）。对成本敏感的社区搜索 RAG，等于给出按基座能力选择评估策略的决策依据，避免无脑上多 agent。

Jungseob Lee, Chanjun Park, Heuiseok Lim

OPID: On-Policy Skill Distillation for Agentic Reinforcement Learning

基于结果的 RL 给语言 agent 提供稳定优化骨架，但稀疏的轨迹级奖励难以指明哪些中间决策该被强化或抑制；on-policy 自蒸馏能给 token 级稠密监督，但已有的技能条件方法依赖外部技能库或检索的特权上下文，维护成本高且常与当前策略诱导的状态分布失配。论文提出 OPID，直接从已完成的 on-policy 轨迹中抽取技能监督，把轨迹后见之明表示为分层技能：episode 级技能刻画全局工作流或失败规避规则，step 级技能刻画具体动作。

INSIGHTOPID 的关键是技能监督完全来自当前策略自己的成功轨迹，绕开了外部技能记忆、检索特权上下文与状态分布失配的问题，对长程多轮 agent（含多步搜索）的训练更稳。分层技能（全局工作流 + 步级动作）的拆法可借鉴到搜索 agent：用成功 session 自蒸馏出“何时该继续检索、何时该收敛”的步级信号，缓解稀疏奖励下的 credit 分配难题。

06 3.35

Semantic Early-Stopping for Iterative LLM Agent Loops

Writer 起草、Critic 修订这类多 agent LLM 循环几乎都靠固定迭代上限（max_iterations）终止，这是个“语法层”的开关：它看不见答案是否还在改进，于是对简单输入过度消耗 token、对困难输入又过早截断。论文研究语义早停：当连续草稿的 embedding 在语义上不再变化（带耐心窗口的 cosine 距离）且答案质量不再提升时停止循环。贡献包括可机器验证的确定性终止与良定义证明、judge 高效的评测协议，并把距离序列收敛当作经验验证的猜想而非过度宣称的 Banach 压缩。

INSIGHTagentic 搜索/RAG 的迭代轮数一向用固定上限拍脑袋，简单查询浪费、难查询被砍。用“连续草稿语义不再变 + 质量不再升”做早停，是省 token 又不牺牲难样本的实用机制。对多轮检索 agent，可把这套语义收敛判据接到“是否再检索一轮”的决策上，按 query 难度自适应分配检索预算。

Knowledge-augmented Agentic AI for Mental Health Medication Information Seeking

患者越来越多在线检索用药信息，但精神类药物的安全知识分裂在权威但抽象的监管不良事件记录与贴近体验却未经验证的患者叙述之间。论文构建一个 provenance-aware、基于知识图谱的多 agent 框架，统一 466,525 条 Reddit 帖、60,782 条 WebMD 评论和二十年 FDA 不良事件（FAERS）记录，覆盖九种抗抑郁药；其 LLM 实体识别管线对照医生标注，药物 F1 达 0.969、病症 F1 达 0.973，强调区分“证据”与“轶事”。

INSIGHT这是少见的把权威源与 UGC（Reddit/WebMD 评论）在 agent 框架里融合且严格保留出处的工作，方法学上和社区搜索高度相关——都要在用户生成内容与权威内容间做可信度分层。provenance-aware 的多 agent 设计提示：社区搜索做 RAG 时应给每条召回标注来源与可信度，让答案能区分“网友说”和“权威说”，而非一锅炖。

08 3.15

Localizing RL-Induced Tool Use to a Single Crosscoder Feature

RL 微调会重塑语言模型内部表征以激发工具使用等 agentic 行为，但其机制基础尚不清楚。论文用 Dedicated Feature Crosscoders (DFC) 在 Qwen2.5-3B 上分离出一小组介导工具调用能力的 RL 专属特征：在 48 组 crosscoder 超参扫描中，编码-解码重构使 RL 模型的工具正确率提升 +31.1±9.7 个百分点，并把工具调用能力被动迁移到冻结的基座模型 +6.8±5.0 个百分点（称为 capability spillover/能力溢出）。

INSIGHT把“RL 学到的工具调用能力”定位到极少数可解释特征，并展示无需重训就能把该能力迁移到基座（+6.8pp 溢出），为低成本控制 agent 行为提供了新思路。对工程团队意味着：理解工具调用能力存在哪、能否免训练地开关或迁移，可能省去为每个工具 agent 重跑 RL 的代价；目前还偏研究阶段（3B 小模型），但方向有想象空间。

09 3.10

Diagnosing and Mitigating Compounding Failures in Agentic Persuasion via Taxonomic Strategy Retrieval

多步开放环境中的基础模型 agent 常受“复合错误”困扰，早期失误污染长程轨迹；多 agent 辩论（MAD）在确定性领域有效，但在劝说等主观任务上 agent 会严重问题漂移和谄媚趋同。论文指出标准 RAG 中的“语义泄漏”是这些失败的可复现触发器——标准 RAG 偏好词面重叠而非逻辑必要性。为消除泄漏，提出 Taxonomic Strategy RAG (TS-RAG)：把策略经由离散的类别瓶颈路由，将论证结构与话题内容解耦；零样本跨域评测显示其显著改善了抽象逻辑的迁移。

INSIGHT“标准 RAG 偏好 vocabulary overlap 而非 logical necessity”这一诊断直击稠密检索的老问题——召回最像的不等于最该用的。TS-RAG 用类别瓶颈把“论证结构”与“话题词面”解耦，给检索加一层抽象路由。对社区搜索相关性同样有启示：当 query 需要的是逻辑/意图匹配而非字面相似时，纯 embedding 召回会泄漏话题词面，需要结构化中间表示来纠偏。

Pradyumna Narayana, Sana Ayromlou, Purvi Sehgal
