From Feature Interaction to Feature Generation: A Generative Paradigm of CTR Prediction Models

提出监督特征生成（SFG）框架，将 CTR 预估从判别式「特征交叉」范式转向生成式「特征生成」范式。

INSIGHTSFG 可直接改造 FM、DeepFM、xDeepFM、DCN V2 等现有模型，缓解 embedding 维度坍缩和信息冗余问题，是 CTR 模型的范式级升级。

业务关联社区搜索的点击率预估模型可直接套用 SFG 框架改造现有排序模型（如 DCN V2），在不改变整体架构的情况下获得性能提升。

证据在 Criteo、Avazu、MovieLens 等多个数据集上，SFG 改造后的模型一致性超越原始版本；代码已开源（GitHub: USTC-StarTeam/GE4Rec）；被 ICML 2025 接收。

Generative Data Transformation: From Mixed to Unified Data

提出数据中心框架 Taesar，通过对比解码机制将混合域数据转化为目标域对齐的统一数据，解决推荐系统中的数据稀疏和冷启动问题。

INSIGHT从「模型中心」转向「数据中心」范式，用生成式方法做跨域数据对齐，而非依赖复杂的多域架构设计，降低了工程复杂度。

业务关联社区搜索场景中 UGC 内容分布不均匀、新内容冷启动是常见痛点，Taesar 的跨域数据生成方法可用于丰富训练数据，提升长尾内容的排序质量。

证据采用对比解码机制进行目标域对齐的序列再生成；论文声明在多个推荐场景下验证了效果，具体指标待完整论文确认。

NoRA: Breaking the Linear Ceiling of Low-Rank Adaptation via Manifold Expansion

提出 NoRA（非线性秩适配），通过 SiLU 门控和结构化 dropout 实现流形扩展，突破 LoRA 的线性天花板。

INSIGHTNoRA 在 rank 64 时的 PPL（3.89）优于 LoRA 在 rank 512 时的表现（3.90），意味着可用 8 倍更少的参数达到更好效果，对推荐模型微调意义重大。

业务关联社区搜索中排序模型的 LLM 微调可采用 NoRA 替代 LoRA，在相同资源下获得更好的适配效果，特别适用于多场景/多任务的高效微调。

证据SlimOrca benchmark 上 NoRA rank-64 PPL 3.89 vs LoRA rank-512 PPL 3.90；参数效率提升 8 倍。

Less is More: Benchmarking LLM Based Recommendation Agents

系统评测了 GPT-4o-mini、DeepSeek-V3、Qwen2.5-72B、Gemini 2.5 Flash 四款 LLM 在推荐场景中不同上下文长度下的表现。

INSIGHT增加上下文长度（5→50 items）对推荐质量无显著提升（质量分 0.17–0.23 持平），但使用短上下文可节省约 88% 推理成本。

业务关联对社区搜索中使用 LLM 做推荐增强的方案有直接指导意义：无需喂入大量历史行为，短上下文即可达到同等推荐质量，大幅降低成本。

证据4 款 LLM × 5 种上下文长度（5/10/20/30/50 items）；REGEN 数据集；推理成本可降低约 88%。

On-Device Large Language Models for Sequential Recommendation

提出 OD-LLM 压缩框架，集成 token 级归一化、低秩分解和渐进对齐，使 LLM 可在端侧设备上高效运行序列推荐。

INSIGHT模型大小压缩一半后推荐效果无损，为端侧个性化推荐（如 App 内本地推荐）开辟了新的技术路径。

业务关联社区 App 的客户端推荐场景可参考 OD-LLM 的压缩方案，在不牺牲推荐质量的前提下实现低延迟的端侧序列推荐。

证据模型大小压缩至原始 50% 后效果无损失；集成 token-level normalization + low-rank decomposition + progressive alignment 三项技术。

ULTRA: Urdu Language Transformer-based Recommendation Architecture

提出 ULTRA 双 embedding 架构，通过查询长度感知路由机制将短查询和长查询分别导向不同语义管道，实现乌尔都语个性化新闻推荐。

INSIGHT查询长度感知的双管道路由机制是可迁移的设计模式：短查询侧重意图匹配（标题级），长查询侧重语义理解（内容级）。

业务关联社区搜索中短文本查询和长查询的检索策略差异显著，ULTRA 的查询路由思路可应用于中文 UGC 搜索的多策略召回设计。

证据在乌尔都语新闻推荐数据集上验证；采用阈值驱动的查询分流和双 embedding 语义管道。
