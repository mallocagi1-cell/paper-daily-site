KEY INSIGHT · 对业务意味着什么生成式推荐在工业界可行的关键不只是模型架构，还在于 boosting 式负采样策略——让新模型专攻现有集成的薄弱区域，从而提升整体推荐多样性和覆盖度。业务关联 该方法将用户行为序列直接输入 Transformer 做 next-item prediction，与社区搜索中用户浏览→搜索→点击的行为序列建模思路高度一致，可迁移至 UGC 内容推荐和搜索排序场景。证据 BFCM 2025 期间处理 2.2 万亿边缘请求，覆盖 8100 万独立消费者；模型展现出明确的 scaling 行为（验证 loss 随模型容量增长持续下降）；已在 NeurIPS 2025 做相关报告。

PROMISE: Process Reward Models Unlock Test-Time Scaling Laws in Generative Recommendations

📖 深度解读 · 11 分钟 →

首次在生成式推荐中验证了 Test-Time Scaling Laws，提出 PRM 引导的 Beam Search 让小模型通过增加推理计算超越大模型。

INSIGHT生成式推荐中 Semantic ID 的层级生成与 LLM 的 Chain-of-Thought 推理存在结构性类比——早期生成错误会导致「语义漂移」，而过程奖励模型 (PRM) 可在每一步修剪错误分支，这为推荐系统的推理时扩展提供了全新范式。

业务关联对搜索排序系统而言，test-time scaling 意味着可以用较小模型+更多推理计算来替代大模型部署，在保持效果的同时显著降低在线服务成本，适合对延迟敏感的社区搜索场景。

证据离线实验表明小模型通过 PRM 引导搜索可超越更大基线模型；已在真实线上推荐系统中验证有效；首次在生成式推荐领域建立了鲁棒的推理时计算-性能幂律关系。

Chengcheng Guo, Kuo Cai, Yu Zhou, Qiang Luo, Ruiming Tang, Han Li, Kun Gai, Guorui Zhou

超全&超细的生成式推荐业界落地实践梳理

系统梳理了百度 COBRA、快手 OneRec、阿里 HeterRec 等主流生成式推荐的工业落地实践路线。

INSIGHT生成式推荐的工业路线已趋于收敛：语义 ID 构造→生成式预训练→RL 偏好对齐→推理解码策略，与 LLM 训练路线高度同构。快手 OneRec 通过 Iterative Preference Alignment 解决了训练目标与业务指标不一致的问题。

业务关联综述覆盖了国内头部平台的落地经验（快手短视频、百度搜索、阿里电商），其中百度 COBRA 的搜索场景经验可直接参考，语义 ID 编码思路可迁移至 UGC 短文本检索。

证据快手 OneRec-V1 全量上线后用户观看时长 (Watch Time) 提升 1.6%；阿里 GPSD 验证了 Transformer 参数从 13K 扩展到 0.3B 时严格遵循 Scaling Law；腾讯 OnePiece 同时验证了语义生成和嵌入检索的幂律缩放。

Search-P1: Path-Centric Reward Shaping for Stable and Efficient Agentic RAG Training

提出基于路径的奖励塑形方法，解决 Agentic RAG 训练中 RL 奖励稀疏导致的不稳定问题，让 LLM 学会动态决定何时及检索什么。

INSIGHT传统 RAG 的单轮检索难以应对复杂多跳推理；Agentic RAG 虽然赋予 LLM 动态检索决策能力，但 RL 训练面临奖励稀疏问题。路径级奖励塑形将最终结果的奖励分配到每个检索决策节点，显著提升训练稳定性和效率。

业务关联社区搜索中用户 query 常需要多步推理（如跨帖关联、追溯讨论链），Agentic RAG 的路径级奖励训练可帮助搜索系统学会更精准的多步检索策略，提升复杂 query 的搜索质量。

证据相比基线 RL 方法，在 multi-hop QA 基准上实现更稳定的训练收敛和更高的最终效果；训练效率显著提升。

Towards Faithful Industrial RAG: A Reinforced Co-adaptation Framework for Advertising QA

针对工业广告问答场景提出强化学习联合适配 RAG 框架，重点解决生产环境中 URL 捏造等幻觉问题导致的合规与商业风险。

INSIGHT工业级 RAG 部署的核心痛点不是通用幻觉，而是特定类型的幻觉（如捏造 URL），这些幻觉在广告场景中会直接导致经济损失和合规风险。检索器与生成器的联合强化学习适配是解决这一问题的有效途径。

业务关联社区搜索同样面临内容真实性问题——搜索结果需要链接到真实帖子 URL，不能出现捏造链接。该框架的 URL 幻觉抑制思路可直接应用于 UGC 搜索的 RAG 增强场景。

证据在工业广告 QA 数据集上验证有效，显著降低了 URL 捏造率；强化学习联合训练相比独立训练检索器和生成器取得更好效果。

LLMs as Orchestrators: Constraint-Compliant Multi-Agent Optimization for Recommendation Systems

提出 DualAgent-Rec 框架，由 LLM 协调 Exploitation Agent（准确性+硬约束）和 Exploration Agent（多样性+无约束帕累托搜索）实现推荐系统的约束优化。

INSIGHT现有多目标推荐方法将业务约束视为软惩罚导致频繁违约；DualAgent-Rec 首次将 LLM 作为调度器，在保证硬约束 100% 满足的前提下进行多目标帕累托优化，实现了准确性与多样性的有效平衡。

业务关联社区搜索同样需要在相关性、多样性、时效性等多目标间做权衡，且存在内容合规等硬约束。DualAgent-Rec 的 LLM 调度+双 Agent 架构可迁移至搜索排序的多目标优化场景。

证据在 Amazon Reviews 2023 数据集上实现 100% 约束满足率，Pareto 超体积 (hypervolume) 比强基线提升 4-6%；WWW 2026 Workshop 论文。

Search More, Think Less: Rethinking Long-Horizon Agentic Search for Efficiency and Generalization

提出 SMTL 框架，用并行搜索扩展替代深度推理扩展，在长序列搜索场景中降低推理成本的同时提升泛化能力。

INSIGHT搜索型 Agent 的性能提升不应只依赖推理深度（think more），而应通过扩展搜索广度（search more）来降低成本并提升跨场景泛化能力。这颠覆了当前主流的 deep reasoning 路线。

业务关联社区搜索中的复杂 query（如多意图 query、长尾 query）需要多步搜索推理。SMTL 的并行搜索扩展思路可降低多步检索的延迟，更适合对响应时间敏感的搜索场景。

证据在多个异构搜索场景中验证了 SMTL 的泛化能力优于基于深度推理的基线方法，推理成本显著降低。

SmartChunk Retrieval: Query-Aware Chunk Compression with Planning for Efficient Document RAG

提出基于 query 感知的自适应分块压缩方法，替代 RAG 中固定大小分块的静态策略，提升检索精度和生成效率。

INSIGHT静态分块是当前 RAG 系统的主要瓶颈——固定大小切分忽略了文档结构和 query 意图。根据 query 动态调整分块粒度和压缩程度，可以用更少的 token 传递更相关的上下文信息。

业务关联UGC 内容长度差异大（短评论 vs 长帖子），固定分块策略效果不稳定。SmartChunk 的 query-aware 自适应分块可提升社区搜索中不同长度 UGC 内容的检索精度。

证据在文档 RAG 基准上相比固定分块方法提升了检索精度和生成质量，同时减少了输入 token 数量。

Rejection Mixing: Fast Semantic Propagation of Mask Tokens for Efficient DLLM Inference

解决扩散语言模型并行解码中的「组合矛盾」问题，通过在离散解码过程中集成连续表示实现高效语义传播。

INSIGHT扩散语言模型的并行解码面临「组合矛盾」——并行生成的 token 形成语义不一致的组合。ReMix 通过将连续表示引入离散解码过程来保持位置间依赖关系，这对基于扩散的生成式推荐（Diffusion-based GRS）的推理效率优化有直接启发。

业务关联扩散式生成推荐是生成式推荐三大范式之一。ReMix 的高效并行解码技术可降低扩散式生成模型的在线推理延迟，适用于对响应时间有严格要求的搜索推荐场景。

证据在 DLLM 推理基准上显著改善了质量-速度权衡，通过连续表示的语义传播解决了并行 token 的语义不一致问题。

Yushi Ye, Feng Hong, Huangjie Zheng, Xu Chen, Zhiyong Chen, Yanfeng Wang, Jiangchao Yao
