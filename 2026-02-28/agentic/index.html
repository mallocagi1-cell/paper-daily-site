MiroFlow: Towards High-Performance and Robust Open-Source Agent Framework for General Deep Research Tasks

提出开源 Agent 框架 MiroFlow，通过 Agent Graph 灵活编排、深度推理模式和鲁棒工作流，在多个 Agent 基准上达到 SOTA。

INSIGHTAgent 框架需解决三个核心问题：工作流编排灵活性、性能稳定性和对商业 API 的依赖。MiroFlow 通过 Agent Graph + 可选深度推理模式 + 鲁棒执行引擎统一解决，且完全开源。

业务关联可作为社区搜索的 Agentic 基础框架，支持搜索+推理+工具调用的多步编排，尤其适用于复杂 UGC 内容理解场景。

证据在 GAIA、BrowseComp、WebWalkerQA 等多个 Agent 基准上达到 SOTA，且复现稳定，解决了 Agent 框架常见的不稳定问题。

03 4.10

SideQuest: Model-Driven KV Cache Management for Long-Horizon Agentic Reasoning

提出 SideQuest 方法，利用大推理模型自身对上下文 token 的判断进行 KV Cache 压缩，解决长程 Agentic 推理中的内存瓶颈。

INSIGHT让推理模型自己判断哪些 token 有用（而非依赖启发式规则），将 KV cache 管理作为与主任务并行的辅助任务执行，仅需 215 个样本训练即可有效工作。

业务关联对于社区搜索中的 deep research 场景（如多轮检索+跨文档推理），该方法可显著降低推理成本和延迟，使 Agentic 搜索在生产环境中更可行。

证据SideQuest 在保持推理质量的同时减少 KV cache 内存消耗，仅用 215 个训练样本就超越了现有启发式 KV 压缩方法。

WebThinker: Empowering Large Reasoning Models with Deep Research Capability

WebThinker 让大推理模型在思考过程中自主搜索网页、导航和撰写报告，实现端到端的 Think-Search-Draft 策略，NeurIPS 2025 发表。

INSIGHT将搜索行为嵌入推理链内部（而非 RAG 外挂），模型在遇到知识缺口时自主发起搜索，搜索结果直接融入思考过程。通过迭代在线 DPO 进一步提升工具调用质量。

业务关联WebThinker 的 Think-Search-Draft 范式可直接应用于社区搜索中的复杂查询处理：当简单检索无法回答时，系统自动触发深度搜索+推理，提升长尾 query 的回答质量。

证据在 GPQA、GAIA、WebWalkerQA、HLE 等基准上显著优于现有方法，使用 QwQ-32B 作为推理模型，已被 NeurIPS 2025 接收。

SIGHT: Reinforcement Learning with Self-Evidence and Information-Gain Diverse Branching for Search Agent

提出 SIGHT 框架，通过自证据蒸馏和信息增益引导的多样化分支策略，解决搜索 Agent 多轮检索中的隧道视觉问题。

INSIGHT多轮搜索 Agent 的核心瓶颈不是检索能力，而是噪声累积导致的隧道视觉——早期检索中的噪声被强行解读后引发不可逆错误。SIGHT 用信息增益分数识别关键节点，仅在高信息增益路径上分支。

业务关联社区搜索中的复杂查询（如多条件筛选、隐含意图理解）需要多轮检索。SIGHT 的去噪+信息增益分支机制可直接提升多轮搜索 Agent 在此类场景下的准确率和效率。

证据通过自证据蒸馏（SES）将原始搜索结果过滤为高保真证据，信息增益引导的分支策略有效避免了对噪声路径的无效探索。

Wenlin Zhong, Jinluan Yang, Yiquan Wu, Yi Liu, Jianhang Yao, Kun Kuang

06 4.05

RT-RAG: Reasoning in Trees: Improving Retrieval-Augmented Generation for Multi-Hop Question Answering

提出 RT-RAG 框架，将多跳问题系统分解为显式推理树，结合实体分析和共识选择减少错误传播，被 WWW 2026 接收。

INSIGHT迭代式 RAG 的核心问题是错误传播——每一步的局部决策错误会沿推理链级联放大。RT-RAG 用树结构替代链结构，通过共识选择多条路径的最优分解，从根本上减少错误传播。

业务关联社区搜索中的复杂查询往往需要多跳推理。RT-RAG 的推理树方法可直接集成到搜索后处理环节，提升多跳查询的准确率。

证据在 3 个多跳 QA 基准上平均 F1 +7.0%、EM +6.0%，被 GLOW@WWW 2026 接收，代码已开源。

Yuling Shi, Maolin Sun, Zijun Liu, Mo Yang, Yixiong Fang, Tianran Sun, Xiaodong Gu

RELOOP: Recursive Retrieval with Multi-Hop Reasoner and Planners for Heterogeneous QA

提出 RELOOP 框架，用层次化序列统一文档、表格、知识图谱的表示，实现结构感知的递归检索和多跳推理。

INSIGHT异构数据源的统一检索是实际搜索系统的核心痛点。RELOOP 的关键创新是 HSEQ——将不同数据类型编码为可逆的层次化序列，Head Agent 指导检索方向，Iteration Agent 通过结构操作精准获取证据。

业务关联社区搜索涉及多种 UGC 数据类型（帖子、问答、评论、表格、标签）。RELOOP 的异构数据统一检索能力可解决社区搜索中跨类型数据融合的难题。

证据在 HotpotQA（纯文本）、HybridQA/TAT-QA（表格+文本）、MetaQA（知识图谱）上均取得一致提升，同时控制 token 和 API 调用预算。

Exploratory Memory-Augmented LLM Agent via Hybrid On- and Off-Policy Optimization

提出混合 RL 框架 EMPO2，结合记忆增强的探索机制与 on/off-policy 优化，大幅提升 LLM Agent 的探索和泛化能力。

INSIGHT当前 LLM Agent 的 RL 训练依赖预训练知识，在需要发现新状态的环境中失效。EMPO2 的核心创新是记忆驱动的探索——Agent 利用记忆引导探索，混合更新策略确保有无记忆都表现良好。

业务关联社区搜索中用户查询模式持续变化（新话题、新表达），搜索 Agent 需要主动探索新信息源。EMPO2 的探索式记忆机制可帮助搜索 Agent 快速适应新领域。

证据在 ScienceWorld 上相比 GRPO 提升 128.6%，在 WebShop 上提升 11.3%；OOD 测试中仅需少量试验+记忆即可适应新任务，无需参数更新。

09 3.85

DeepResearcher: Scaling Deep Research via Reinforcement Learning in Real-world Environments

首个在真实网络环境中通过 RL 端到端训练 Deep Research Agent 的框架，Agent 学会导航开放网络而非固定语料库。

INSIGHT传统 RAG 假设信息存在于固定语料库中，但现实搜索环境是嘈杂、动态的开放网络。DeepResearcher 首次证明可以直接在真实 Web 环境中进行 RL 训练，让 Agent 学会处理噪声和不确定性。

业务关联社区搜索的内容池动态更新（新帖子、新话题），DeepResearcher 的开放环境 RL 训练方法可帮助搜索系统在动态 UGC 环境中持续优化检索策略。

证据相比 prompt engineering 基线提升 28.9 分，相比 RAG-based RL Agent 提升 7.2 分，在真实 Web 搜索环境中验证。

An Empirical Study on Reinforcement Learning for Reasoning-Search Interleaved LLM Agents

系统实证研究了 RL 训练搜索 Agent 的关键因素：奖励设计、LLM 选择和搜索引擎集成，来自 Google Research。

INSIGHT格式奖励（format rewards）对搜索 Agent 性能提升显著，而中间检索奖励作用有限。搜索引擎的选择对 RL 训练动态和推理鲁棒性有实质性影响。

业务关联对于社区搜索中部署 RL 训练的搜索 Agent，该研究提供了直接可用的工程指导：优先设计好格式奖励，慎重选择搜索后端，不必过度投入中间步骤奖励。

证据在多个 QA 基准上系统对比了奖励设计、模型规模、推理能力和搜索引擎选择的影响，代码已开源可复现。

Bowen Jin, Jinsung Yoon, Priyanka Kargupta, Sercan O. Arik, Jiawei Han
