Isotonic Layer: A Universal Framework for Generic Recommendation Debiasing

该论文提出 Isotonic Layer，一种可微分的分段线性拟合框架，可直接嵌入神经网络架构中实现推荐系统的去偏与校准。通过将特征空间分段并优化非负斜率施加全局单调归纳偏置，将有偏观测映射回真实效用值。支持上下文特征（如展示位置、设备类型）的可学习 embedding，可对任意上下文组合进行针对性校准。在 LinkedIn 生产环境 A/B 测试中显著优于基线系统，被 KDD 2026 接收。

Revisiting Feature Interactions from the Perspective of Quadratic Neural Networks for Click-through Rate Prediction

Huawei📖 深度解读 · 4 分钟 →

从二次神经网络 (QNN) 视角重新审视 CTR 预估中的 Hadamard Product 特征交互机制，揭示了 QNN 在扩展特征空间和提供平滑非线性近似方面的能力。通过理论分析和 25 种 QNN 神经元格式的实证评估，提出了 Multi-Head Khatri-Rao Product 替代 Hadamard Product，以及 Self-Ensemble Loss 增强计算效率。最终提出的 QNN-alpha 在 6 个公开数据集上达到新 SOTA，同时保持低推理延迟和良好可扩展性。KDD 2025 接收。

INSIGHT揭示了 mid-activation 比传统 post-activation 更适合 QNN 的关键发现，为 CTR 模型的特征交互设计提供了新理论基础。Multi-Head Khatri-Rao Product 是 Hadamard Product 的严格上位替代，可直接应用于现有 CTR 模型（如 DCNv2、xDeepFM）中提升效果。该方法在 6 个数据集上的全面验证和低延迟特性使其具备很强的工业部署可行性。

Honghao Li, Yiwen Zhang, Yi Zhang, Lei Sang, Jieming Zhu

Feed m Birds with One Scone: Accelerating Multi-task Gradient Balancing via Bi-level Optimization

Meta📖 深度解读 · 4 分钟 →

提出 MARIGOLD 框架，将多任务学习 (MTL) 中的模型训练与梯度平衡统一建模为双层优化问题，通过零阶方法高效求解。MGDA 类方法的核心瓶颈在于需要访问所有任务梯度带来的计算开销，MARIGOLD 利用双层优化结构避免了这一成本。在公开数据集和工业规模数据集上均验证了方法的效率优势和性能提升，显著加速了多任务梯度平衡过程。

INSIGHT揭示了多任务梯度平衡方法内在的层次结构（模型训练与梯度平衡的耦合），为 MTL 优化提供了新的理论视角。零阶优化避免了对所有任务梯度的昂贵计算，这对推荐系统中常见的 CTR/CVR/时长等多目标联合优化场景尤为重要。Meta 的工业规模验证表明该方法可直接应用于大规模推荐排序系统。

Efficient Personalized Reranking with Semi-Autoregressive Generation and Online Knowledge Distillation

HuaweiUSTC📖 深度解读 · 17 分钟 →

提出 PSAD 框架，解决生成式重排序中生成质量与推理延迟的固有矛盾。教师模型采用半自回归生成器平衡质量与效率，通过在线知识蒸馏将排序知识传递给轻量评分网络实现实时推理。同时引入 User Profile Network (UPN) 注入用户意图并建模兴趣动态，增强用户-物品特征交互。在三个大规模公开数据集上显著优于现有最优基线，兼顾排序性能与推理效率。

INSIGHT半自回归 + 在线蒸馏的组合巧妙解决了生成式重排序的部署难题：教师模型捕获列表级依赖，学生模型实现低延迟推理。这种师生框架可迁移到搜索结果重排序场景，特别适合对延迟敏感的在线服务。UPN 的用户意图注入机制为个性化排序提供了有效的用户建模方案。

T-REX: Transformer-Based Category Sequence Generation for Grocery Basket Recommendation

Amazon📖 深度解读 · 4 分钟 →

Amazon 提出 T-REX，一种面向在线生鲜购物的 Transformer 序列推荐架构。针对生鲜场景的重复购买模式和复杂商品关系，设计了三项关键创新：稀疏购物模式的动态序列分割采样策略、自适应时间位置编码方案、以及降低维度同时保持推荐质量的品类级建模方法。与 BERT4Rec 等掩码语言模型相比，T-REX 的因果掩码更适合下一篮预测任务。在大规模离线实验和在线 A/B 测试中均获显著提升。

INSIGHT品类级建模是一个值得借鉴的降维策略——在保持推荐质量的同时大幅降低计算复杂度。因果掩码优于双向掩码的发现对序列推荐模型设计有指导意义。Amazon 的在线 A/B 验证和动态序列分割策略为处理稀疏用户行为序列提供了工业级解决方案。

Rethinking Personalization in Large Language Models at the Token Level

AlibabaPeking University

提出 PerContrast 方法，通过因果干预估计每个输出 token 对个性化的贡献度，进而开发 PerCE 损失函数，在训练时自适应加权高个性化度的 token。该方法认识到不同 token 对个性化结果的贡献程度不同，从 token 粒度重新审视 LLM 个性化问题。在 LongLaMP 数据集上平均提升超过 10%，最高达 68.04%，且具备跨任务和跨场景的迁移能力。阿里巴巴与北京大学合作。

INSIGHTToken 级别的个性化度量与加权训练是一个新颖且实用的思路——不是所有 token 都需要个性化，精确识别并强化关键 token 可以在低成本下显著提升效果。因果干预方法提供了可解释的个性化度量，对搜索/推荐系统中的个性化排序和个性化摘要生成有直接启示。

Generalizing Linear Autoencoder Recommenders with Decoupled Expected Quadratic Loss

Kent State UniversityAuburn University

将线性自编码器推荐模型 EDLAE 的目标函数推广为 Decoupled Expected Quadratic Loss (DEQL)，发现了超参数 b>0 范围内的新闭式解，突破了原始 EDLAE 仅支持 b=0 的限制。基于 Miller 矩阵逆定理设计了高效算法保证 b>0 情形的计算可行性。在基准数据集上 b>0 的 DEQL 解优于 b=0 的 EDLAE 基线。论文被 ICLR 2026 接收。

INSIGHT线性自编码器推荐模型的数学推广揭示了此前被忽略的超参数空间（b>0），为简单高效的协同过滤模型提供了性能上限的提升。闭式解+高效矩阵逆算法的组合使其非常适合需要低延迟、可解释推荐的场景。ICLR 2026 的接收证明了其理论贡献。

Ruixin Guo, Xinyu Li, Hao Zhou, Yang Zhou, Ruoming Jin

Benchmark Leakage Trap: Can We Trust LLM-based Recommendation?

Nanjing UniversityTianjin University

识别并系统研究了 LLM 推荐系统中此前被忽视的基准数据泄露问题。通过在基础模型上进行持续预训练模拟多种数据泄露场景，发现了数据泄露的双重效应：领域相关泄露导致虚假性能提升，误导性地夸大模型能力；而领域无关泄露则通常降低推荐准确率。实验揭示数据泄露是 LLM 推荐系统评估中一个关键但此前未被充分考虑的因素。代码已开源。

INSIGHT对 LLM 推荐领域的评估可靠性敲响警钟——当前基于公开基准的 SOTA 结果可能受到数据泄露的严重影响。双重效应（领域相关 vs 无关泄露）的发现为设计更可靠的 LLM 推荐评估方案提供了依据。对于正在将 LLM 引入推荐系统的团队，这项工作提供了必要的评估方法论反思。

Mingqiao Zhang, Qiyao Peng, Yumeng Wang, Chunyuan Liu, Hongtao Liu

Multi-TAP: Multi-criteria Target Adaptive Persona Modeling for Cross-Domain Recommendation

UUNIST

提出 Multi-TAP 框架解决跨域推荐中的域内偏好异质性问题。不同于现有方法依赖粗粒度行为信号，Multi-TAP 通过语义化的 Persona 建模显式捕获用户偏好的多面性，并基于目标域条件选择性迁移源域信号以保持相关性。在真实世界数据集上一致性地超越现有跨域推荐 SOTA 方法。代码已开源。

INSIGHT语义 Persona 建模将用户的多面偏好结构化表示，比传统的行为 embedding 更具可解释性和可迁移性。目标域条件化的选择性知识迁移避免了负迁移问题。这种思路可应用于社区搜索中用户在不同内容类型（问答、帖子、评论）间的偏好迁移。

Daehee Kang, Yeon-Chang Lee

LMMRec: LLM-driven Motivation-aware Multimodal Recommendation

提出基于 LLM 驱动的动机感知多模态推荐系统 LMMRec。不同于将用户动机视为交互数据中的隐变量，LMMRec 利用评论文本等异构信息显式建模用户行为驱动因素。解决了两个关键挑战：噪声环境下的稳定跨模态对齐，以及识别不同模态中与动机相关的有效特征。通过 LLM 提取和融合多模态动机信号，实现了对用户决策过程和内容偏好的深层理解。

INSIGHT从用户动机层面理解推荐行为是一个有价值的研究方向——超越了传统的行为模式匹配，试图回答用户'为什么'点击/购买的问题。利用 LLM 从评论文本中提取动机信号是一种低成本的用户理解增强方式，可应用于 UGC 社区中理解用户搜索和浏览的深层意图。
