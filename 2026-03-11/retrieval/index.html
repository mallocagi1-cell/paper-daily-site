A Systematic Investigation of Document Chunking Strategies and Embedding Sensitivity

本文首次对稠密检索中的文档分块策略进行了大规模、跨领域的系统评测。研究覆盖 36 种分块方法（包括固定长度、语义、结构感知、层次化、自适应和 LLM 辅助等），在 6 个不同知识领域上使用 5 种 embedding 模型进行基准测试。结果表明内容感知分块（尤其是 Paragraph Group Chunking）显著优于简单固定长度分块，最佳策略的 nDCG@5 达到 0.459，Hit@5 达到 59%。

KEY INSIGHT · 对业务意味着什么该研究揭示了分块策略对检索质量的巨大影响：段落分组（Paragraph Group Chunking）在所有领域中一致表现最优，而固定长度切分可能导致语义信息碎片化。对搜索系统的启示在于：在 RAG 或语义搜索场景中，投入时间优化分块策略的收益远大于单纯更换 embedding 模型。5 种 embedding 模型的对比也为搜索工程实践中模型选型提供了实证参考。

Approximate Nearest Neighbor Search for Modern AI: A Projection-Augmented Graph Approach

📖 深度解读 · 8 分钟 →

本文提出 Projection-Augmented Graph (PAG)，一种面向现代 AI 应用的近似最近邻搜索框架。作者总结了现代 AI 应用对 ANNS 的六大关键需求：高查询效率、快速索引构建、低内存占用、高维可扩展性、不同检索规模的鲁棒性、以及支持在线插入。PAG 通过在图索引中集成投影技术，利用精确距离和近似距离的非对称比较来减少不必要的精确距离计算。在 6 个现代数据集上的实验验证了 PAG 的一致优势。

INSIGHTPAG 的核心创新在于将投影技术与图索引统一，通过统计检验引导的非对称距离比较来加速搜索过程。这种方法同时满足了六大实际需求，特别是在高维空间和在线插入场景下的优势，直接适用于搜索系统中的 embedding-based 召回层。对于向量搜索基础设施的升级具有重要参考价值。

Kejing Lu, Zhenpeng Pan, Jianbin Qin, Yoshiharu Ishikawa, Chuan Xiao

MrBERT: Modern Multilingual Encoders via Vocabulary, Domain, and Dimensional Adaptation

MrBERT 是基于 ModernBERT 架构的多语言编码器系列（150M-300M 参数），在 35 种语言和代码上预训练。通过词汇表适配、领域适配和维度适配三种策略，在加泰罗尼亚语和西班牙语任务上达到 SOTA，同时在生物医学和法律领域保持强劲表现。集成 Matryoshka Representation Learning (MRL) 支持灵活的向量尺寸，可显著降低推理和存储成本。模型已开源发布。

INSIGHTMRL（俄罗斯套娃表征学习）是该模型对搜索系统最有价值的特性：它允许根据延迟和质量需求动态调整向量维度，在不同维度间灵活选择而无需重新训练。对于多语言 UGC 搜索场景，MrBERT 的多语言能力和高效推理设计提供了一种开箱即用的编码器选择。ModernBERT 架构的效率优势也值得排序模型工程团队关注。

Rethinking Deep Research from the Perspective of Web Content Distribution Matching

本文提出 WeDas 框架，从 Web 内容分布匹配的视角重新审视深度搜索 Agent 的设计。现有深度搜索框架将搜索引擎视为静态工具，导致 Agent 生成的查询与索引结构之间存在错配。WeDas 引入 Query-Result Alignment Score 量化 Agent 意图与检索结果的兼容性，并通过少样本探测机制迭代估计该分数，使 Agent 能够根据当前内容分布动态调整子目标。

INSIGHTWeDas 的核心洞察在于：搜索引擎的索引结构本身决定了什么样的查询能获得好结果。这对搜索系统的启示是双重的：一方面，查询理解/改写模块需要感知索引的内容分布特征；另一方面，Agent 驱动的搜索场景需要将检索结果质量作为反馈信号来迭代优化查询。作为即插即用模块，WeDas 的设计模式可迁移到各类搜索优化场景。

Zixuan Yu, Zhenheng Tang, Tongliang Liu, Chengqi Zhang, Xiaowen Chu, Bo Han

UIS-Digger: Towards Comprehensive Research Agent Systems for Real-world Unindexed Information Seeking

本文识别并探索了未索引信息检索(UIS)问题——搜索引擎爬虫未抓取的关键信息（如被忽略的内容、动态网页、嵌入式文件等）。即便最先进的搜索 Agent 在传统基准上表现优异（GAIA 70.90），在 UIS 场景下性能急剧下降（UIS-QA 仅 24.55）。作者构建了首个 UIS 基准 UIS-QA（110 个专家标注的 QA 对），并提出 UIS-Digger 多 Agent 框架来应对这一挑战。

INSIGHTUIS 问题揭示了搜索系统的一个盲区：大量有价值的信息（动态页面、PDF 嵌入内容等）未被搜索引擎索引，导致传统检索 Pipeline 完全忽略这些内容。对搜索系统设计的启示在于：需要建设针对未索引内容的补充检索通道；多 Agent 协作框架为处理复杂信息获取任务提供了新思路。70.90 到 24.55 的性能落差也提醒我们评估搜索系统时需要考虑索引覆盖率这一关键维度。

Chang Liu, Chuqiao Kuang, Tianyi Zhuang, Yuxin Cheng, Huichi Zhou, Xiaoguang Li, Lifeng Shang

Amortizing Maximum Inner Product Search with Learned Support Functions

本文提出 Amortized MIPS，一种基于学习的最大内积搜索方法。核心洞察是 MIPS 的值函数等价于键向量集合的支撑函数（support function），该函数是凸的且 1-齐次的，其梯度恰好是数据库中的最优键。基于此，作者提出两种互补方法：(1) SupportNet——用输入凸神经网络建模支撑函数，通过自动微分恢复最优键；(2) 直接回归最优键。这种方法将 MIPS 的计算成本分摊到固定查询分布上。

INSIGHT将 MIPS 值函数视为支撑函数的数学洞察非常优雅——凸性和 1-齐次性保证了梯度直接指向最优键。这为 embedding-based 检索提供了一种全新的理论视角和潜在加速方案。对于搜索系统中高频查询的向量检索场景，amortized 方法可以将计算成本从在线推理转移到离线学习，特别适合查询分布相对稳定的场景。不过目前更偏理论研究，实际部署还需进一步验证。

Theo X. Olausson, João Monteiro, Michal Klein, Marco Cuturi

Fine-Grained Table Retrieval Through the Lens of Complex Queries

本文提出 DCTR（Decomposition with Connectivity-aware Table Retrieval），一种面向复杂查询的细粒度表格检索方法。该方法通过类型化查询分解和全局连接感知机制来处理关系数据库上的开放域问答。研究沿着查询复杂度和数据复杂度两个轴评估检索效果，在行业对齐的基准数据集上展示了 DCTR 在高度复合查询和密集连接数据库上的鲁棒性。

INSIGHT查询分解的思想对搜索系统设计有直接借鉴意义：将复杂查询拆分为类型化子查询，再结合数据结构的全局连接信息进行检索。这种 decompose-then-retrieve 的模式可以迁移到社区搜索中处理复杂查询意图的场景，尤其是涉及多个条件或跨多个内容源的查询。查询复杂度和数据复杂度两个维度的评估框架也值得搜索评测体系参考。

Wojciech Kosiuk, Xingyu Ji, Yeounoh Chung, Fatma Özcan, Madelon Hulsebos

A Hybrid LTR-based System via Social Context Embedding for Recommending Solutions of Software Bugs in Developer Communities

本文提出一种基于社交上下文 embedding 的混合 Learning-to-Rank 系统，用于在 Stack Overflow 等开发者社区中推荐软件 bug 的解决方案。系统利用众包 Q&A 的知识，通过深度学习技术构建 LTR 模型，将 Stack Overflow 的社交上下文特征（如投票数、用户声誉、回答时间等）作为 embedding 输入。

INSIGHT该工作的核心启示在于将社交上下文信号融入 LTR 模型——这与社区搜索场景高度相关。在 UGC 社区搜索中，用户互动信号（点赞数、评论质量、作者可信度等）是判断内容相关性的重要特征。将这些社交信号通过 embedding 方式融入排序模型，比简单的特征拼接可能捕获更丰富的交互模式。这种方法可以迁移到 UGC 平台的搜索排序中。

A Dynamic Self-Evolving Extraction System

本文提出 DySECT（Dynamic Self-Evolving Extraction and Curation Toolkit），一种持续自进化的信息抽取系统。该系统通过 LLM 增量填充可扩展知识库（KB），并通过概率知识和图推理进行知识库的自丰富。DySECT 解决了文档检索、排序和相关性估计中的关键挑战——领域特定准确性、术语变化适应和罕见表述的处理。

INSIGHTDySECT 的自进化设计对搜索系统有重要启示：搜索引擎需要持续适应新术语、新概念和领域知识的变化。通过 LLM 自动构建和更新知识库，搜索系统可以实现更精准的实体识别和结构化信息抽取，从而提升 query 理解和文档相关性评估的质量。自扩展知识图谱对于维护搜索系统的长期准确性具有参考价值。

Moin Amin-Naseri, Hannah Kim, Estevam Hruschka

Deterministic Fuzzy Triage for Legal Compliance Classification and Evidence Retrieval

本文研究了基于确定性双编码器和模糊分类带的法律合规分类与证据检索方法。使用 RoBERTa-base 双编码器（512 维投影 + 余弦相似度）在 ACORD 基准上训练分级条款检索，在 CUAD 派生的二分类合规数据集上微调。五次随机种子实验显示 NDCG@5 为 0.38-0.42，NDCG@10 为 0.45-0.50，AUC 达到 0.98-0.99。

INSIGHT该工作的价值在于展示了简单双编码器在专业领域检索中的有效性——不需要复杂的大模型即可达到可用的检索质量。对搜索工程的启示：确定性推理过程对合规性要求高的场景很重要；模糊分类带的设计思路可以迁移到搜索相关性的分级判断中；小模型加双编码器的组合在垂直领域仍有竞争力。

Rian Atri
