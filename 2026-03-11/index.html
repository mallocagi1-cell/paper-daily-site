Verifiable Reasoning for LLM-based Generative Recommendation

针对 LLM 生成式推荐中推理退化（同质化推理和错误累积）的问题，提出 VRec 框架，首创 reason-verify-recommend 三段式范式，在推理过程中交叉插入验证环节以提供可靠反馈。核心设计包含混合验证器（mixture of verifiers）确保多维度验证，以及代理预测目标保障可靠性。在四个真实数据集上验证，VRec 在不牺牲效率的前提下显著提升推荐效果和可扩展性，代码已开源。

One Model Is Enough: Native Retrieval Embeddings from LLM Agent Hidden States

📖 深度解读 · 10 分钟 →

提出让 LLM Agent 直接利用自身 hidden states 进行检索，消除传统「生成查询文本 + 独立 embedding 模型」的双模型流水线。通过在 LLM 之上添加轻量投影头，结合对齐损失、对比学习和排序蒸馏三种训练目标，在 QReCC 对话搜索基准上保持了基线 97% 的检索质量（Recall@10 和 MRR@10），同时消除了独立 embedding 模型的基础设施开销。

INSIGHT该工作验证了 LLM 内部表征直接用于检索的可行性，为「一个模型统一理解与检索」提供了实证支持。这意味着在生成式检索系统中，不必维护独立的 embedding 服务——LLM hidden states 本身就是高质量的检索表征。对搜索系统架构而言，这种单模型方案可显著降低部署复杂度和推理延迟，尤其适合对话式搜索等需要上下文理解的场景。

Deep Research for Recommender Systems

RUC📖 深度解读 · 17 分钟 →

提出推荐系统的 Deep Research 范式，用综合性的用户中心报告替代传统的物品列表推荐。具体实现了 RecPilot 多智能体框架，包含两个核心组件：用户轨迹模拟 Agent（自主探索物品空间）和自进化报告生成 Agent（将探索结果整合为可解释报告）。在公开数据集上的实验表明，RecPilot 在用户行为建模上表现优异，并能生成高说服力的报告，显著减少用户评估物品的认知负担。

INSIGHT该工作标志着推荐系统从「被动过滤工具」向「主动研究助手」的范式跃迁。传统推荐只给出列表，用户需自行对比和决策；而 Deep Research 范式让系统替用户完成探索、比较、综合的全流程。这一思路对社区搜索场景极具启发性——当用户搜索复杂话题时，系统可以不只返回帖子列表，而是生成一份综合多篇帖子观点的报告。多 Agent 协作的架构设计也为 LLM 驱动的下一代搜推系统提供了参考蓝图。

Scaling Multilingual Semantic Search in Uber Eats Delivery

Uber

Uber Eats 的生产级多语言语义检索系统，统一了门店、菜品和杂货零售三个垂类的检索能力。基于 Qwen2 两塔模型，使用数亿匿名 query-document 交互数据进行微调，训练结合 InfoNCE（in-batch 负采样）和 triplet-NCE（hard negative）双损失，并引入 Matryoshka Representation Learning 实现单模型多维度 embedding 输出。在 6 个市场、3 个垂类上均取得显著的召回提升，论文涵盖完整的数据构建、模型架构、大规模训练和评估流程。

INSIGHT这是一篇难得的工业落地全链路论文。两个关键技术选择值得借鉴：(1) 基于 Qwen2 这样的 LLM 基础模型构建检索双塔，而非传统 BERT，代表了行业向 LLM 基础模型迁移的趋势；(2) MRL（Matryoshka）技术使单模型支持多种 embedding 维度，在存储成本和检索质量之间灵活权衡。对多语言/多垂类搜索场景尤其有参考价值：一个统一模型替代多个独立模型的方案可大幅降低维护成本。

Bo Ling, Zheng Liu, Haoyang Chen, Divya Nagar, Luting Yang, Mehul Parsana

Continual Low-Rank Adapters for LLM-based Generative Recommender Systems

UIUC

针对 LLM 推荐系统面临的持续学习问题——用户、物品和偏好随时间演变——提出 PESO（Proximally rEgularized Single evolving lOra）方法。不同于现有 LoRA 持续学习方法仅关注保留旧任务性能，PESO 认识到推荐的特殊性：过时偏好反而有害。通过近端正则化将当前适配器锚定到最近冻结状态，PESO 能灵活平衡适应与保留，更好地捕捉最近用户行为。理论分析证明该设计提供了数据感知的方向性指导。

INSIGHT该工作揭示了推荐系统持续学习的独特性：与传统 NLP 任务不同，推荐中旧的偏好可能是过时的噪音而非需要保留的知识。这一洞察对 LLM 推荐系统的工程实践极具指导意义——在更新模型时不应盲目保留所有历史能力，而应侧重近期行为模式。PESO 基于 LoRA 的轻量设计使其易于集成到现有 LLM 推荐流水线中，特别适合用户兴趣快速变化的场景。

Hyunsik Yoo, Ting-Wei Li, SeongKu Kang, Zhining Liu, Charlie Xu, Qilin Qi, Hanghang Tong

High-Fidelity Pruning for Large Language Models

提出基于信息熵的 LLM 剪枝方法 HFPrune，解决传统 Taylor 展开剪枝仅依赖 one-hot 交叉熵损失（只考虑单个预测 token）的局限。利用模型输出分布的信息熵评估神经元重要性，无需额外 teacher 模型即可实现自蒸馏级别的重要性评估。在 LLaMA 和 Qwen 系列模型的 zero-shot 基准测试中，一致性地超越现有剪枝方法，代码和权重已开源。

INSIGHT信息熵作为剪枝准则的核心优势在于它考虑了模型的完整输出分布，而非仅关注 top-1 预测。这对于部署 LLM 推荐系统意义重大——生成式推荐器需要保持丰富的输出分布以支持多样化推荐，传统剪枝方法可能损害这种多样性。HFPrune 在 LLaMA/Qwen 系列上的适用性意味着可直接应用于基于这些模型的推荐系统，实现低成本部署而不显著损失推荐多样性。

Yijun Zhu, Jianxin Wang, Chengchao Shen

ERASE -- A Real-World Aligned Benchmark for Unlearning in Recommender Systems

UUvA

推出 ERASE 大规模推荐系统遗忘基准，解决现有 MU 基准与真实场景脱节的问题（仅关注协同过滤、假设不切实际的大批量删除请求、忽略顺序遗忘和效率约束）。覆盖三类核心任务（协同过滤、会话推荐、篮子推荐），评估 7 种遗忘算法在 9 个公开数据集和 9 个模型上的表现，生成超过 600GB 可复用工件。发现近似遗忘在部分场景可媲美重训练，但推荐专用方法在重复遗忘任务上显著优于通用方法。

INSIGHT随着 GDPR 等隐私法规的推进，推荐系统的数据遗忘能力日益重要。该基准的核心贡献是将遗忘评测从理想化场景拉回现实：真实系统面临的是小批量、顺序化的删除请求，且需兼顾模型性能与效率。对搜推系统而言，关键发现是：推荐专用遗忘方法在反复遗忘场景下更可靠，且注意力和 RNN 架构的模型存在特定脆弱性。这对选择模型架构和设计数据合规流程有直接参考意义。

Pierre Lubitzsch, Maarten de Rijke, Sebastian Schelter

Why Large Language Models can Secretly Outperform Embedding Similarity in Information Retrieval

从理论层面论证 LLM 推理式相关性判断（LLM-RJS）相比 embedding 相似度检索（NERS）的潜在优势，指出相似度是对相关性的「短视」解释。在 TREC-DL 2019 段落检索上对比实验发现，LLM-RJS 在标准评测中未显现优势；深入分析发现这是因为人工标注本身也存在「短视」偏差——推理型 LLM-RJS 的假阳性主要源于标注错误而非模型错误。结论是 LLM-RJS 确实能克服短视局限，但现有标注数据集无法正确评估这一优势。

INSIGHT该发现对搜索系统评测方法论有重要警示：当我们用传统标注数据评估 LLM 排序时，可能系统性地低估了 LLM 的真实能力。对于正在探索 LLM 重排序的搜索团队而言，这意味着离线指标的提升幅度可能无法反映线上真实收益——需要设计更深层的相关性标注协议，或直接依赖在线 A/B 测试来评判 LLM 排序的实际效果。这也从评估维度支持了生成式搜索范式的价值。

Matei Benescu, Ivo Pascal de Jong

PIRA-Bench: A Transition from Reactive GUI Agents to GUI-based Proactive Intent Recommendation Agents

CUHK

提出 PIRA-Bench 基准，评估多模态大模型（MLLM）在连续弱监督视觉输入上的主动意图推荐能力。不同于现有反应式 GUI Agent（用户给指令才执行），PIRA-Bench 模拟真实屏幕活动中的长序列轨迹（含噪声浏览、无意义操作和多线程任务切换）。同时提出 PIRF（记忆感知状态跟踪框架），使通用 MLLM 能管理多任务线程并主动推荐用户下一步意图。

INSIGHT从反应式到主动式推荐是 AI 助手的重要演进方向。该工作将推荐问题扩展到 GUI 交互场景，通过连续视觉输入主动预判用户意图——这与搜推系统中根据用户实时行为序列主动推荐的思路一脉相承。PIRF 的记忆感知和状态跟踪设计对构建上下文感知的推荐系统有参考价值，尤其是在处理长序列、多意图交织的复杂用户行为建模上。

Yuxiang Chai, Shunye Tang, Han Xiao, Rui Liu, Hongsheng Li

Rank4Gen: RAG-Preference-Aligned Document Set Selection and Ranking

针对 RAG 中检索排序与生成器偏好不对齐的问题，提出 Rank4Gen，一种 RAG 偏好对齐的文档集选择与排序方法。现有排序模型主要优化 query-document 相关性，但这与生成器对证据选择和引用的偏好存在偏差，限制了回复质量。Rank4Gen 通过对齐排序模型与下游生成器的偏好，考虑文档集组合层面的偏好差异，实现更优的 RAG 回复质量。

INSIGHT该工作揭示了一个实践中常被忽视的问题：检索阶段优化的目标（query 相关性）与生成阶段真正需要的（对生成有帮助的证据组合）并不一致。这对于生成式搜索系统的架构设计有直接启示——排序模型不应仅优化传统的相关性指标，还需考虑下游 LLM 生成器的偏好。这种端到端优化思路可推广到搜推系统中 LLM 排序与展示生成之间的对齐问题。
