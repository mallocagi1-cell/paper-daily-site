GenRec: A Preference-Oriented Generative Framework for Large-Scale Recommendation

GenRec 面向京东 App 大规模推荐中的翻页输出不一致、长行为序列成本与偏好对齐难题，在单一解码器中引入页级下一词预测、非对称 Token Merger 和 GRPO-SR。Token Merger 将输入长度约压缩 2 倍；持续一个月的线上 A/B 实验中，点击数提升 9.5%，成交数提升 8.7%。

Differentiable Semantic ID for Generative Recommendation

AmazonTelefónicaUniversity of GlasgowShandong UniversityLeiden University

DIGER 解决 Semantic ID 分词器只优化内容重建、无法接收推荐损失的问题，以 Gumbel 噪声和两种不确定性衰减实现端到端可微索引并抑制码本坍塌。在 3 个公开数据集上，B-Shop 的 NDCG@10 从两阶段基线 0.0331 提至 0.0376，I-Shop 从 0.0797 提至 0.0844。

INSIGHT关键不是继续扩大神经召回骨干，而是让索引空间直接服务排序目标：训练早期用随机探索覆盖更多编码，后期降低噪声贴近确定性推理。对短文本 UGC，可把帖子文本编码与下一次点击目标联合训练，减少“语义相近但兴趣不可区分”的 ID 冲突；论文已开源代码，适合离线小流量验证。

Junchen Fu, Xuri Ge, Alexandros Karatzoglou, Ioannis Arapakis, Suzan Verberne, Joemon M. Jose 等 7 人

LLM-RS: A Large Language Model-Based Sequential Recommendation with Reasoning

IIMSIUCairo UniversityPPort Said UniversityBadr University

LLM-RS 将序列推荐拆为偏好画像、候选推理和解释生成 3 个阶段，并比较 LoRA 微调、RAG 与混合方案。其混合版本在 4 个数据集上较最强 LLM 基线平均提升 4.1% NDCG@10，较 BERT4Rec 提升 12.3%；用户研究中的推荐采纳率提高 28%。

INSIGHT显式推理的价值不仅是可解释性，也能把长历史中的偏好证据带入重排；但单次调用 GPT-4 的成本意味着它更适合作为小候选集的末级重排器。社区搜索可先由现有召回产生 Top-100，再检索 Top-5 内容证据供推理，避免让 LLM 承担全库检索并控制延迟。

Mohamed A. Ali et al.

Leveraging graph path evidence for explainable recommender systems

Kyung Hee University

KAPER 用知识图谱路径为 LLM 推荐重排和解释提供结构化证据，系统包含序列召回、路径挖掘、统一 LLM 推理 3 个组件。路径筛选综合时效、频次、偏差与 TF-IDF 共 4 类偏好信号，并加入时间衰减和路径长度惩罚；多数据集实验显示其准确率与解释质量均优于对照方法。

INSIGHT与把用户历史全文塞进提示词相比，先筛选“用户—内容—属性”短路径能同时减少上下文噪声和幻觉。社区 UGC 可将作者、话题、实体、互动关系构成轻量图谱，再用 4 信号复合分数挑选证据；需要注意出版方公开摘要未披露绝对指标，落地前应复现其重排增益与调用成本。

Suji Kim, Namhun Kim, Jaekyeong Kim
