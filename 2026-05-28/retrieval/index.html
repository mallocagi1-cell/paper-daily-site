Gemini Embedding 2: A Native Multimodal Embedding Model from Gemini

Google 发布 Gemini Embedding 2，是基于 Gemini 多模态主干的原生多模态向量模型，可在统一表示空间下编码视频、音频、图像和文本，并支持任意模态交错输入。模型采用大规模对比学习配合多任务多阶段训练，在 MSCOCO 上达到 62.9 R@1、Vatex 上 68.8 NDCG@10、MTEB multilingual 69.9、MTEB Code 84.0，全面超越各单模态专用模型。论文同时给出 RAG、推荐和搜索等下游使用场景的适配方案。

Credit-assigned Policy Gradient for Early Stage Retrieval in Two-stage Ranking

CornellMeta📖 深度解读 · 9 分钟 →

针对搜索/推荐/RAG 中两阶段排序（早期召回 ESR + 后排 LSR）端到端训练的难题，作者指出 vanilla policy gradient (V-PG) 在 ESR 上方差爆炸，因为它对整个候选集联合概率求梯度，忽略了单个候选的贡献。论文提出 credit-assigned policy gradient (CA-PG)：把梯度归到「目标物品被任何候选集选中」的边际概率上，对候选集大小做了边际化。理论上证明在常见 LSR 假设下 CA-PG 与 V-PG 期望一致但方差大幅降低，在合成与真实数据上 NDCG/Recall@K 明显优于 V-PG 和 distillation 基线。

INSIGHTCA-PG 提供了一个真正可工业落地的 ESR 端到端 RL 训练方案：核心改动只在策略梯度的归因公式，不需要改变现有 two-stage 架构。对社区搜索的直接价值是把目前主要用 distillation/CTR 标签训练的召回侧升级为以下游 nDCG/CTR 为目标的强化学习训练，且不会因候选集动辄 1000+ 而方差崩溃。论文里 marginal probability 重写技巧也可以迁移到推荐多目标排序中的候选集级 reward 分解问题。

Haruka Kiyohara, Mihaela Curmei, Ariel Evnine, Shankar Kalyanaraman, Israel Nir, Ana-Roxana Pop 等 10 人

Is Position Bias in Dense Retrievers Built In-or Learned from Data?

论文系统性回答 Dense Retriever 的位置偏置（query 相关证据靠后则召回率下降）究竟来自模型架构还是训练数据。作者构造了证据出现在文档开头/中间/结尾的合成训练集，对 8 个不同架构的预训练模型分别在 skewed 和 balanced 分布上微调。结果显示：训练分布的偏置方向几乎完全决定了排序模型的偏置方向；用 position-balanced 训练数据可把 position-aware benchmark 上的位置敏感度降低 57%–87%，在标准 BEIR/MS MARCO 上指标无损。

INSIGHT对社区 UGC 搜索的启示极为直接：帖子正文里答案往往出现在中部或末尾（用户讨论后才给结论），原生 dense retriever 会系统性低估这类高质量结果。该论文给出了一种零模型改动的解法——在训练数据中对证据位置做 balanced 重采样，就能把偏置降到原来的 1/3，且不损失主流 benchmark 指标。生产上可以直接在 hard-negative 挖掘和正样本生成里加入位置 perturbation 来缓解长帖子的召回劣势。

Daegon Yu, SeungYoon Han, Woomyoung Park

The Coverage Illusion: From Pre-retrieval Routing Failure to Post-retrieval Cascades in a Production RAG System

Aarhus University

丹麦国家百科全书生产 RAG 系统的真实流量复盘：在 20,000 条 query-workflow 对上比较了 5 种召回工作流。合成 query 评测显示 90%+ 查询需要 LLM augmentation (HyDE / query expansion) 才能拿到高 coverage，但真实用户 query 在生产 deferral 策略下仅 27.8% 真正需要 augmentation。作者把这一差距命名为 Coverage Illusion，归因于合成 query 与真实 query 分布的结构性失配。论文进一步证明 pre-retrieval routing 无法预判，只能用 post-retrieval 级联来判断要不要触发 LLM 重写。

INSIGHT这篇是少有的一手生产数据 RAG 案例研究，对社区搜索 LLM-as-rewriter 的成本控制极具指导意义：把 HyDE/expansion 对所有 query 一刀切的方案换成 post-retrieval deferral cascade，可以把 LLM 调用量从 100% 砍到 27.8%，且 coverage 几乎不降。值得借鉴的是它把召回失败信号（top-k 分数分布、相关性置信度）作为是否触发二次召回/重写的特征，这比目前主流的 query intent 分类器 routing 更稳健。也提醒做 query rewriting offline 评测时一定要混入真实 query 分布，否则会大幅高估增益。

Zafar Hussain, Kristoffer Nielbo

Generalized Range Filtering Approximate Nearest Neighbor Search: Containment and Overlap [Technical Report]

Xidian UniversityCUHK

面向真实向量检索系统中的「带范围过滤」需求（价格区间、时间区间、有效期等），论文把传统单点过滤 ANN 推广到 range-range (RR) 谓词：给定查询区间 [l_q, r_q] 和每个向量自带区间 [l_i, r_i]，支持 containment、overlap 及其析取的用户自定义关系。作者基于分段索引和图索引提出统一框架，证明在不同 RR 谓词下都能达到优于现有 range-filter ANN 基线的 recall-latency Pareto 前沿，并给出完整的代码与可复现实验。

INSIGHT社区搜索/推荐的向量召回长期被「单点 filter」假设束缚，遇到「最近 7 天发布」「评分 4–5 分」「售价区间」这种范围条件就只能后处理，召回质量和延迟都很差。这篇把范围谓词原生融入图索引的方案，是当前能直接接入 HNSW/IVF 索引的 ANN 增强工作中工业可用性最强的一个。其 containment+overlap 双谓词形式可直接覆盖时效性筛选 + 类目区间这类组合查询，避免重新构建带 metadata 的 ColBERT/SCANN pipeline。

Yingfan Liu, Tong Wu, Jiadong Xie, Yang Zhao, Jeffrey Xu Yu, Jiangtao Cui

From PDF to RAG-Ready: Evaluating Document Conversion Frameworks for Domain-Specific Question Answering

University of Porto

系统性对比 Docling、MinerU、Marker 与 DeepSeek OCR 四款开源 PDF→Markdown 转换框架在 RAG 下游 QA 任务上的影响。在 36 份葡萄牙语行政文档（1706 页 ~49 万词）上跑 50 个 benchmark 问题，每个配置重复 50 次 LLM-as-judge 评分，并用 Wilcoxon signed-rank 检验 + Cohen's d 报告效应量。两个基线为 naïve PDFLoader (86.2%) 与人工 markdown (91.3%)。Docling 配合 hierarchical splitting 取得开源框架中的最佳成绩，DeepSeek OCR 在扫描件场景下显著超越其他三家。

INSIGHT社区搜索越来越多接入富文档（运营资料、商家长文、政策公告）做 RAG 召回，PDF 解析质量直接决定 chunk 召回的天花板。这篇给了一份难得的「按配置可复现」的横向评测，明确指出：hierarchical splitting > fixed-size splitting，且 splitter 的影响往往大于 converter 本身。结合工程经验，Docling + hierarchical chunker 是当前性价比最高的默认配置；扫描类长文则应切换到 DeepSeek OCR。该工作的 21 配置 × 50 次 LLM-as-judge 框架也可直接套用到中文 UGC 文档预处理选型评测中。

José Guilherme Marques dos Santos, Ricardo Yang, Rui Humberto Pereira, Alexandre Sousa 等 11 人

LLM-guided Hierarchical Search for End-to-end Reasoning Intensive Retrieval

AmazonUCLAUUT Austin

针对 reasoning-intensive 检索（相关性判断需要对 query-doc 做语义推理而非词面/主题相似）的失效问题，作者跳出「便宜 embedding 召回 + LLM verifier」的标准范式，提出 LLM 直接与语料库通过分层可导航索引交互的新范式：完全没有 embedding-based retriever，LLM 在树状索引上自顶向下逐步收敛到目标文档。文章在 BRIGHT、ReasonIR-bench 等推理密集型 IR benchmark 上对比 SOTA dense retriever + LLM verifier 方案，无 embedding 路径下取得显著更高的 nDCG@10 和 Recall@k。

INSIGHT社区搜索中越来越多用户用自然语言提问、追问、做对比，这类 query 用 embedding 召回长期不在状态。这篇提供了一种「干掉 embedding」的另类思路：把 corpus 组织成层级索引，让 LLM 像导航一样下钻定位，避开 embedding 表征不足导致的 top-k miss。实际落地难点是分层索引构建成本和 LLM 推理延迟，短期内仅适合长尾难 query 的二次召回兜底，但其层级 navigation prompt 设计、LLM 直接做 retriever 的范式值得关注。

Nilesh Gupta, Wei-Cheng Chang, Ngot Bui, Cho-Jui Hsieh, Inderjit S. Dhillon

Rethinking Agentic RAG: Toward LLM-Driven Logical Retrieval Beyond Embeddings

Fudan

作者主张 agentic RAG 应该把控制权交给 LLM 来表达检索意图，而非堆叠 dense / hybrid / graph 等复杂后端。框架让 LLM 用结构化逻辑表达式（AND/OR/NOT、字段约束、属性范围）写出检索意图，retrieval 后端只需要轻量的倒排索引来精确执行。论文证明这种「LLM 写表达式 + 倒排索引执行」的范式在多轮 RAG benchmark 上效果与复杂混合检索可比，但每次调用的延迟和成本显著更低，并大幅提高了可解释性。

INSIGHT这是与当前「越复杂越好」的检索后端潮流相反的一个观点：对中文社区 UGC 搜索来说，字段化 query（话题、地区、时间、作者）本就常见，把 LLM 当 query parser 写出可执行布尔逻辑反而比训练专门的 query understanding 模型更直接。值得借鉴：用 LLM 输出 DSL → 倒排执行的 pipeline 简单、可审计，且 LLM 出错时的 fallback 与回滚都比 dense 召回错位更可控。它和 #4 Coverage Illusion 一起，代表了 2026 年的一股「化繁为简」回归——把 LLM 用在写规则、做决策上，而不是无脑塞进 retriever 里。

Yuqi Zeng, Qixiang Deng, Yulei Wan, Ruiquan Jiang, Xiaoqing Zheng, Xuanjing Huang

ICICLE: Expanding Retrieval with In-Context Documents

NTUJHU

针对生成式检索（GR）增量索引代价高的问题——加新文档要更新参数、重训且会灾难性遗忘——作者把增量 GR 重新定义为 in-context retrieval：新文档以 inference-time 的 docid-document 证据提供给模型。ICICLE 包含三个关键组件：[COPY] 路由机制决定从参数记忆还是 context 证据生成 docid、preference-based calibration 校准两路得分、长上下文适配。MS MARCO 与 NQ320K 上对新加入文档的召回显著优于持续训练 baseline，原索引文档的性能保持不变（不再遗忘）。

INSIGHT对社区搜索的启示在于「新帖召回不重训」：UGC 社区每日新增百万级帖子，传统生成式检索/dense retriever 都需要频繁微调才能跟上。ICICLE 把新文档以「外挂」证据形式塞进 context，让 LLM 自己决定走参数路还是上下文路，实测能召回新文档同时不忘老文档。短期落地难点是 context 容量，但论文给出的 [COPY] 路由 + preference calibration 的范式可以与 frozen embedding 索引并存，作为「冷启动新内容」专用召回路。

Yu-Chen Den, Yung-Yu Shih, Zhi Rui Tam, Kuan-Yu Chen, Pu-Jen Cheng, Yun-Nung Chen, Eugene Yang

RICE-PO: Turning Retrieval Interactions into Credit Signals for Reasoning Agents

UMass Amherst

针对多轮检索 agent 的信用分配难题——可执行动作（查询、摘要）能被检索器直接评估，而隐含的推理步骤（CoT 思考）无法直接观测——作者提出 critic-free 的 RICE-PO 框架：选高不确定性的可执行动作做锚点，用 retrieval metric 评估局部 counterfactual 分支，只有当「推理 → 动作」的影响强时才把 credit 反传到隐性推理步骤。在多个 reasoning-intensive IR benchmark 上 RICE-PO 优于 GRPO/PPO 等通用 RL 基线，训练更稳定且无需价值网络。

INSIGHT对社区搜索里越来越流行的「多轮检索 + 推理」agent 来说，这是一条更稳的训练路径：传统 outcome reward 会污染中间推理步骤的更新，RICE-PO 用 counterfactual 局部评估筛出真正影响动作的推理步骤再赋值。落地上可借鉴的是用 retrieval metric（如 hit@k 提升量）作为细粒度 reward 来源，比 LLM-as-judge 既便宜又稳定。对当前主流的 GRPO 训练 search agent 是直接的方案改良。

Mingchen Li, Hansi Zeng, Zhuo Qian, Jiatan Huang, Hamed Zamani, Hong Yu
