CMSL: Constructive Multi-Sequence Learning for Recommendation Systems

针对单一行为序列中多兴趣相互争抢注意力、形成上下文污染的问题，Meta 提出 CMSL，在隐空间主动构造多条主题序列并分别建模。模型以 300亿至500亿条样本、128 张 H100 训练；四个线上场景的排序 NE 改善 0.06%至0.13%，召回 A/B 指标提升 0.092%至0.171%。

Prompt Generation Technical Report

Alibaba📖 深度解读 · 9 分钟 →

论文把生成式搜推的特征处理从模型代码中解耦，以两份声明式 JSON 统一离线训练和在线服务，并用四类特征、三种可组合组件完成组装与压缩。该框架已部署于淘宝搜索，线上 A/B 实验使成交笔数提升 0.47%、GMV 提升 0.51%，并复用于多个搜索推荐团队。

INSIGHT最值得借鉴的不是某个网络结构，而是把特征契约设为训练与服务的唯一事实源，从根源上减少特征不一致和场景定制代码。社区搜索若采用生成式召回，可先统一行为、内容、数值与向量特征的配置式 token 化，再在同一标准接口上做序列压缩和推理优化。

ZoRRO: A Zero-Weight Personalized Recommender System for Scalable News Recommendation

JJP/Politikens Media GroupZZOZODDTUUCSD

ZoRRO 用文章时效衰减、语义相似度与类别相似度构成无训练参数的新闻推荐器，可直接接入快速更新的内容池。在含 3700万曝光、100万用户和12.5万篇文章的 EB-NeRD 上，AUC 为63.80，高于 NRMS 的62.46；六天线上 A/B 中 CTR 接近深度模型，同时推理速度超过其600倍。

INSIGHT新鲜内容密集的社区场景未必需要复杂用户塔：预计算内容向量，再将时效与用户历史相似度显式组合，能显著降低冷启动和服务成本。但 ZoRRO 的线上多样性为0.54、低于 NRMS 的0.72，说明 CTR 接近并不代表内容生态相同，必须联动监控覆盖率、主题和情绪分布。

Tokenizing Numerical and Embedding Features for LLM RecSys

论文将数值特征和上游稠密向量映射为 soft token，并在共享参数的 Qwen3-0.6B 双塔中先做交互融合，再送入标准 LLM token 接口。三个 Amazon 数据集上均优于文本基线；Toys 数据集 Recall@10 从0.0945升至0.1064，NDCG@10 从0.0463升至0.0536。

INSIGHTLLM 推荐无需放弃成熟的统计特征和 embedding 管线，关键是把异构信号对齐到统一 token 空间，并在进入主干前显式建模交互。对 UGC 排序可将作者质量、时效、互动率和内容向量软 token 化；结果也表明直接拼接不稳，Toys 上交互融合 Recall@5 为0.0695，而拼接仅0.0575。

05 4.35

One Adapts to Any: Meta Reward Modeling for Personalized LLM Alignment.

已录用 SIGIR 2026

MRM 将每位用户的奖励模型表示为共享基础奖励函数的加权组合，并用 MAML 式双层优化学习可快速适配的初始化；RPO 进一步提高难学用户权重。在 PRISM 与 Reddit TLDR 上，未见用户总体准确率达到64.9%，去除元学习后为63.1%；最差10%用户为37.9%，高于消融版本36.1%。

INSIGHT相比为每位用户从头训练参数，学习“如何用少量反馈完成个性化”更适合长尾与新用户。社区推荐可把点击、停留、负反馈等目标拆成基础奖励，再只适配用户组合权重；不过该方法来自 LLM 偏好对齐，迁移到 CTR/CVR 前应验证奖励可辨识性和线上延迟。

Normative Alignment of Recommender Systems via Internal Label Shift

JJP/Politikens Media GroupZZOZODDTUUCSD

NAILS 把公平、多样性和编辑价值等全局目标表述为推荐系统内部的标签迁移：调整用户条件物品分布，使类别等属性的边际分布逼近目标，同时保留原模型偏好且无需重训。实验显示属性对齐持续改善、用户参与损失很小，并把一个全局约束转成可插拔的后处理层。

INSIGHT该方法适合需要同时管理 CTR 与内容生态的场景：先由现有排序模型给出个性化分数，再在类别层施加目标分布，可避免频繁重训主模型。落地时应把目标分布按人群与时段分层，并同步观察 nDCG、点击率和供给曝光偏差，防止全局配额掩盖局部用户损失。

RecRec: Recursive Refinement for Sequential Recommendation

RecRec 不再用一次前向编码直接得到用户偏好，而是维护紧凑潜状态，通过共享递归模块反复吸收交互证据，并用 evidence-anchored correction gate 抑制深层递归的语义漂移。三个基准上达到或超过序列、图和推理增强模型，参数量仅390万至1400万。

INSIGHT共享递归单元提供了“增加推理步数而不线性增加参数”的扩展路径，适合资源受限的实时推荐；锚定原始行为证据则是避免兴趣状态越迭代越偏的关键。可在社区用户塔中用固定步数递归更新短期兴趣，并通过门控保留原始点击序列，先评估收益与额外时延的拐点。

Pervez Shaik, Prosenjit Biswas, Abhinav Thorat, Ravi Kolla, Niranjan Pedanekar

Stream-aware Side Adaptation for Large Pre-trained Multimodal Embedding Models in Sequential Recommendation

University of Glasgow

Stresa 冻结 Qwen3-VL-Embedding 2B/8B 主干，以 SHAF 保留跨层历史侧流记忆，并用 ReSA 选择性更新残差流，解决普通 side adapter 随深度退化的问题。在 MicroLens-50K 上 HR@10 从0.0813升至0.0841、NDCG@10 从0.0437升至0.0456；三套公开数据均领先基线。

INSIGHT多模态推荐适配的瓶颈不只是参数量，而是深层信息在逐层融合中被覆盖。冻结大模型、缓存隐藏状态并训练小型侧路，可降低迭代成本；对图文 UGC 可重点复用 SHAF 的历史流保留与 ReSA 的选择性更新，但论文序列截断为10，长历史场景仍需独立验证。

Junchen Fu, Kaiwen Zheng, Ioannis Arapakis, Wenhao Deng, Xin Xin, Joemon M. Jose, Xuri Ge

SMC-Rec: Spectral Semantic Memory Convolution with Uncertainty-Guided Learning for Sequential Recommendation

SMC-Rec 面向长行为序列，将语义记忆压缩、频谱卷积和不确定性引导学习结合，试图在保留长期偏好的同时控制计算量。论文覆盖消融、语义几何、不确定性分组、鲁棒性、稀疏用户和冷启动共6类分析，证据指向收益来自校准后的记忆压缩，而非单一辅助模块。

INSIGHT对长序列推荐，先压缩可复用的语义记忆，再在频域建模周期与长期模式，可能比对全部行为做全注意力更经济。不确定性分组也可用于社区冷启动：对证据不足的用户降低高风险个性化强度；但该来源尚缺可核验的线上数据，进入生产前应复现公开基准和延迟曲线。

Ruijia Guo, Zhiyuan Chen, Xingyue Xie, Hao Bai

面向高卷入度产品的对话推荐系统——基于模块化多阶段方法

研究面向汽车、家电等高卷入度产品，把咨询阶段纳入强化学习状态，并组合对话策略、属性选择、知识图谱与理想点推荐3个模块。作者在国内汽车论坛真实购买数据和仿真交互数据两类设置上验证，结果显示系统能以更少轮次获得更高推荐准确率。

INSIGHT对意图不明确且决策成本高的查询，系统应主动选择最有信息量的属性提问，而不是一次性生成推荐列表。社区搜索可将该思路用于复杂消费决策和内容探索：分阶段维护偏好状态、把提问策略与候选排序解耦；但摘要未公开具体增益，工程试点前需补充全文指标与用户中断率。
