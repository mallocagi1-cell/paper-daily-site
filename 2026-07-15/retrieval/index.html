Multilingual Semantic Retrieval for Apple Music Search

Apple 面向 150 多个地区的音乐搜索，训练 3.05 亿参数多语种双塔，并用分位数分布匹配把稠密召回与词法索引融合，无需重训下游排序。离线 Hit@10 相对提升 69%；全球 A/B 中转化率提升 2.28%，无结果率下降 86%，尾部查询转化率提升 7.93%。

Scaling and Stabilizing Large-Scale Embedding-Based Retrieval

Walmart

Walmart 针对双塔训练候选窄、线上需区分数亿商品的落差，结合跨批次在线采样与 cross-encoder、元数据驱动的离线难负例挖掘，使负例多样性扩大一个数量级；再用热启动蒸馏把 DistilBERT 平滑迁移至 GTE-base。线上部署后 NDCG@5 提升 7.34%，总营收提升 0.50%。

INSIGHT召回升级的关键不只是换大骨干，而是同时修复负例分布和继承旧模型的领域知识。社区搜索可把曝光未点、同主题但意图不符、地域或实体冲突样本组合成混合难负例；骨干迁移时先蒸馏旧模型，再引入新监督，能减少召回集合剧烈漂移对排序与业务指标的冲击。

MMRM: A Multiplex Multimodal Representation Model for Product Ranking in E-commerce Search

JD

京东提出 MMRM，用共享多模态骨干、任务专属 token 与投影层，在一次推理中同时学习多种协同信号，再基于搜索行为序列构造任务专属用户表示用于多任务排序。该系统已在京东搜索部署并服务数百万日常用户，论文报告离线与线上均取得显著收益，但摘要未披露具体增幅。

INSIGHT多模态表征不应只作为静态 item 特征，而应按点击、转化等目标生成多路表征，并进一步参与用户行为序列建模。社区 UGC 搜索可让同一帖子产生文本相关、视觉相关、互动质量等任务向量，在共享骨干上保持一次编码，再由各排序目标选择对应通道，兼顾成本与多目标差异。

Zhen-Lin Chen, Maosen Sheng, Peng Lin, Jianmin Chen, Zhuojian Xiao, Dongyue Wang, Xiwei Zhao

04 4.55

Score-Only Distillation for Compact Dense Retrieval

论文只使用教师的候选打分向量蒸馏紧凑稠密检索器，不依赖隐藏状态；核心是行中心化分数目标与节省内存的全对 PairMSE。八项任务上最多追回基座到教师差距的 50%；0.6B 学生的 query 编码快 4.7 倍、文档编码快 9.7 倍，但跨协议迁移效果仍不稳定。

INSIGHT只蒸馏相对排序分数可绕开教师架构和表示维度耦合，适合将昂贵线上 embedding 模型压到可服务规模。落地时应固定候选生成与难负例协议，把收益视为“同分布压缩”而非通用迁移；社区搜索可先在高频 query 和稳定内容库验证延迟、召回率与 nDCG 的联合前沿。

Kirill Dubovikov, Martin Takac, Salem Lahlou

05 4.45

Semantic Search for AI Agents at Scale: Retrieval and Ranking for LinkedIn’s Hiring Assistant

LinkedIn

LinkedIn 的 MUSE 面向 13 亿以上会员，以 LLM 解析自然语言资格条件，用 2048 维 Matryoshka 向量做 IVFPQ 召回、4096 维向量进入 DCNv2 排序，query 编码 p95 低于 100ms。两周 A/B 中 HRR 提升 2.7%，InMail 发送提升 4.1%，候选量下降约 4%。

INSIGHT同一语义表征同时服务 L1 召回和 L2 排序，可减少两阶段目标错位；其完整链路还表明 ANN 近似误差与属性后过滤损失会相乘。社区搜索可复用分层评估：先测 Recall、MAP、nDCG，再回放生产 query，最后做线上实验；同时监控高相关率与结果供给量，避免只优化 CTR。

Nikita Zhiltsov, Achyuthan Jootoo Ramesh Bapu, Nikhil Thakur, Dan Liu

SVD-RAG: Efficient Tree-Organized Retrieval-Augmented Generation via Singular Value Decomposition

SVD-RAG 在稠密句向量矩阵上用奇异值分解抽取树节点摘要，替代 RAPTOR 的 LLM 摘要调用，并以能量阈值自适应压缩。它减少约 85% token，建树快 317 倍；MRR 为 0.867 对 0.875，Recall@1 为 0.483 对 0.458，并较平面检索提升 4.2 倍 Recall@1。

INSIGHT层次检索的摘要节点未必需要生成模型；对语义较集中的 UGC 主题簇，SVD 能以确定性、可复现方式保留主要信息，显著降低离线构建成本。建议把它用于长帖、问答串或专题聚合的上层索引，同时保留原文细粒度召回，并用内容复杂度阈值控制压缩率。

Zhihui Sun

The Retrieval Bottleneck: Scaling Laws for Reinforcement Learning in RAG

Nanjing UniversityBaidu

ACL 2026 论文在三个知识密集基准上研究 RAG 的强化学习扩展规律，提出“检索瓶颈假设”：检索质量决定性能上限，目标函数、奖励和 off-policy 方法主要改变算力效率。其 S 形扩展律可用稳定配置外推 4 倍训练算力下的表现，误差仅 3.1%。

INSIGHT继续堆 RL 算力无法补回缺失证据，检索召回率应先于生成策略成为扩容门槛。对社区搜索问答，可按检索质量分桶画出训练收益曲线：低召回桶优先改 query 理解、索引和候选覆盖，高召回桶再优化奖励；论文还发现最佳文档数会随训练推进而增加，需联动调节 top-k。

Shu Zhou, Jinman Leng, Yufei Song, Xin Wang, Tao Fan, Hao Wang

When Vision Meets Texts in Listwise Reranking.

已录用 SIGIR 2026

SIGIR 2026 的 Rank-Nexus 以 2B 视觉语言模型做图文 listwise 重排，通过文本、图像、联合图文三阶段渐进蒸馏缩小模态差距。它仅用 7.5% 文本和 3% 图像训练数据，在 DL19、DL20 的 nDCG@10 达 74.60、70.00；处理时间 2 秒，优于 RankZephyr 的 8.92 秒。

INSIGHT多模态重排的瓶颈可能是训练数据质量与课程顺序，而不是参数规模或长推理链。社区帖子同时含标题、正文和图片，可先分别学会文本排序与图像匹配，再联合做列表级排序；精选 4000 条高质量样本达到峰值，也提示清洗和覆盖度比盲目扩大蒸馏集更重要。

Hongyi Cai

09 4.25

Boolean queries are all you need?

University of Waterloo

论文让 LLM 搜索代理只调用布尔检索器，在 TREC 2024 RAG 的 MS MARCO V2.1 去重集合上，以 86 个 topic、每题最多 100 次模型调用进行查询规划。系统仅按匹配子串密度排序，取得 NDCG@10 0.6863，超过许多稠密、稀疏及学习稀疏的一阶段检索器。

INSIGHT复杂代理不一定需要复杂索引：LLM 可把语义推理转化为多轮结构化布尔表达式，让廉价可解释的匹配器承担执行。社区搜索可在专名、事件、数字条件等高精确需求上增加代理式布尔通道，但该结论仅来自公开单一集合，且每题 100 次调用成本高，需先约束调用预算并做泄漏检查。

Charles L. A. Clarke, Mark D. Smucker

The Effect of Multi-Lingual and Keyword Adversarial Injection on LLM Relevance Judgment

论文在 TREC Deep Learning 集合、两个开源模型和既有判分提示上，测试指令型与内容型跨语言注入，覆盖八种高低资源语言。结果显示，多语种 query 注入能显著抬高 LLM 相关性分数并绕过现有防御；即使修补防御，攻击也可继续适配规避，暴露自动标注链路的系统性风险。

INSIGHTLLM 相关性判分器必须把 query 和文档视为不可信输入，尤其不能假设非主语言内容更安全。社区搜索若用 LLM 生成训练标签或评测 nDCG，应加入八语种注入回归集、关键词异常监控和模型间交叉裁决；防御不能只靠静态提示词，还要在解析、隔离与异常分数层设置独立保护。

Nguyen Khoi Vo, Duy Duong Tuong, Oleg Zendel, Mark Sanderson
