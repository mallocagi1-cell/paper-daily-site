WeGR: Unified Generative Retrieval for Industrial Search Systems in WeChat

WeGR 将协同行为感知的 CoCo-VAE 语义码与动态视野策略优化 DHPO 结合，解决工业生成检索中的码本塌缩及精确匹配奖励稀疏问题。微信电商搜索线上实验报告订单、CTR、CVR 相对提升 2.539%、1.508%、1.381%，CPU/GPU 使用量分别减少 25.5%/26.1%；这些是电商生产结果，尚非社区 UGC 验证。

Computed, not Memorized: Bit-Factorized Identifiers for Efficient Generative Retrieval

本文提出按位分解的数字文档 ID，使 token 得分由各 bit 的模型表示共同计算，减少依靠索引训练死记文档码的问题。在三个检索基准评估中，未见文档 Hit@10 提升超过 20 个百分点，NQ320K 与 TriviaQA 推理延迟最高降低 7 倍；MS MARCO 无额外训练时比更新权重的方法低约 3 个百分点。

INSIGHT社区帖子持续新增，生成索引能否在不重训时为新内容打分，比静态语料上的单次召回更关键。可借鉴组合式 ID 评分，分别测试新旧文档、固定候选预算和延迟；论文数字来自不同基准，不能把最高加速与最大召回增益当作同一配置的承诺。

I-Fan Lin, Zhen Zhang, Faegheh Hasibi, Suzan Verberne

UniSGR-V2: Stepwise Target-Side Feature Anticipation and Crossing for Generative Recommendation

Alibaba

UniSGR-V2 在正文提出 TacGR：每层语义码生成前预测连续目标属性，并在解码器内交叉，配合语义锚定辅助塔与单向可见掩码。Lazada 的 24.2 亿样本实验中，点击 HR@100 从 UniSGR 的 0.3031 升至 0.3148；40 天线上 A/B 的订单量和 GMV 分别相对提高 5.55% 和 3.09%。

INSIGHT目标内容尚未生成时无法查真实属性，逐层连续预测为生成召回提供了补充条件。迁移社区场景可预测主题或内容形态，但必须同时约束可学习标签避免塌缩，并隔离噪声传播；配对前向保持解码次数不增，不等于实际延迟或计算量没有增加。

Jun Yang, Jiasi Chen, Jiawei Sun, Ziyue Guo, Jianan Yan, Tao Luo, Xiaoyi Zeng

HASTE: Hierarchical and Attribute-aware Supervision for Generative Recommendation

Glance

HASTE 为生成式推荐引入层级 Semantic ID 损失和属性辅助监督，强化粗到细表示并改善长尾物品学习。层级损失约带来 2 倍收敛加速；Amazon Fashion-140k 上总体 Recall@5 从 0.0243 升至 0.0297，长尾 Recall@10 从 0.0169 升至 0.0215。不同数据与指标仍有退步，不能概括为全部领先。

INSIGHT社区搜索可在已有生成召回骨干上先试层级监督及主题属性损失，再决定是否增大模型。要分别观察粗码正确率、长尾内容和浅层 nDCG，避免把收敛加速等同于服务加速；商品颜色与材质监督不能直接照搬到帖子，需选择可靠且不会泄漏标签的属性。

Tripti Shukla, Shwetha Somasundaram, Akshat Gupta, Rohit Garg, Paul Duff, Ian Anderson

Personalized LLM Recommendation with Semantic IDs: Autoregressive Beam Search vs. Multi-Token Prediction

已录用 NeurIPS 2026 WorkshopNetflix

Netflix 在统一的多任务推荐 LLM 中比较单头自回归 beam search 与并行多 token 预测，并为后者引入联合 SID 排序损失。Qwen3-8B 规模下，自回归方案在排序与内容问答上更强，训练美元成本约为 MTP 的 1/2.6；相对旧非 SID 基线，冷启动排序提高 77%、内容问答准确率提高 22%。

INSIGHT生成帖子 ID 的吞吐提升不能替代排序质量、内容理解与训练成本评估。社区搜索可按相同 backbone、SID 和预算比较两种解码方式，重点记录冷启动帖子与语言能力回归；正文发现扩展 SID 词表会影响语言指标，需要独立验证多任务干扰。

Sejoon Oh, Fernando Amat Gil, Evan Smothers, Dan Iter, Mark Thornburg, Dawit Mureja Argaw 等 14 人

AlignPoison: Conditional Targeted Poisoning of Generative Recommenders via Decoding-Aligned Prefixes

AlignPoison 研究自回归生成式推荐在有限交互注入与黑盒推荐接口条件下的定向投毒风险，分析解码前缀对恶意目标曝光的作用。实验表明不足 1% 的合成交互即可增强触发条件下的目标推广，所提方法在单模态和多模态生成推荐基准上，ASR lift 相对比较最高增加 16.3 个百分点。

INSIGHT社区 UGC 交互容易受到刷量影响，生成式召回的安全审计需要覆盖语义前缀与解码路径，而不只是最终点击率。应按异常行为来源、触发上下文和头尾内容分别检查曝光集中度；论文的攻击成功率用于压力测试，不能解读成推荐质量改善或线上真实攻击发生率。

Zhuoxuan Zhang, Jinhao Duan, Xinyu Zhao, Jinduo Guo, Shuai Shao, Rui Li, Luke Simon, Zhun Deng 等 10 人

Many Right Answers, One Training Example: Removing Responder Noise from GRPO for LLM Recommenders

ReMaRk 针对同一推荐请求有多个有效人工回复时的奖励噪声，按请求采样，并对所有回复中的物品并集统一计算奖励。原 Rank-GRPO 的优势方差中约 85% 来自抽到哪条回复；在七个骨干、三个数据集上，新方法以 25%–53% 的训练步数达到原方法 2000 步的验证召回水平。

INSIGHT社区问答与帖子推荐往往有多个正确答案，逐回复构造 RL 样本会把标注差异当作质量差异。可将同一 query 或请求下的有效结果联合成正例集合，保持请求采样均衡；同时审计并集中的弱相关项与流行度偏置，验证省下的是步数还是实际 GPU 小时。

Xin Li, Hao Jiang, Jinghao Guo, Weisi Lin, Chau Yuen

From Interests to Semantic IDs: Retrieval-Grounded Credit Assignment for Generative Recommendation

本文将生成推荐的推理轨迹拆成历史摘要、兴趣假设和最终 Semantic ID，由冻结检索器逐条验证兴趣能否召回目标，为有效假设分配局部奖励。论文在 3 个 Amazon Reviews 数据集验证该设计，并在 Video Games 做 oracle 兴趣选择分析；公开摘要未给出统一提升幅度，本报告不补造百分比。

INSIGHT核心启示是区分“最终 ID 命中”与“哪条兴趣假设提供了有效信息”，为推理片段提供可验证监督。社区搜索可用冻结内容索引检验 query 假设，并隔离该奖励对最终 ID 段的更新；引入检索器会增加训练复杂度，其偏置也需要与原始用户行为交叉验证。

Mengdan Zhu, Yufan Zhao, Yao Zhao, Sophie Di, Tao Di, Yulan Yan, Sridhar Iyer, Liang Zhao

Eval4DiRec: A Unified and Systematic Evaluation Framework for Diffusion-based Recommender Systems

Eval4DiRec 将扩散推荐的预处理、训练、推理与评估流程统一，避免不同实验设置导致不公平比较。框架支持 14 个代表模型、覆盖 5 类推荐场景，并公开代码与数据；这些数量体现评估覆盖范围，摘要未给出可统一引用的单一准确率增益，不应补造性能数字。

INSIGHT如果社区团队尝试扩散式生成推荐，可先复用统一的数据切分与候选评估协议建立基线，再比较自回归与扩散路线。实践价值在于检查实验可复现性和推理预算，而不是把框架覆盖模型数当成效果优势；原论文发表于 9 月 28 日，本轮属于更新发现。

SimInter: Evidence-Grounded User Simulation with Interview-Based Profile Enrichment for Conversational Recommender Systems

SimInter 用基于历史证据的合成访谈丰富用户画像，并在写入画像前审核虚构与刻板印象，用于对话推荐模拟。实验模拟 300 名 ReDial 用户，在配对的 100 人子集上，过滤后的偏好维度熵从 0.859 提高至 1.619；人工评估中 94.3% 的属性主张获得全部或部分证据支持。

INSIGHT对社区对话推荐，模拟器可用于检查多轮偏好表达和冷启动追问，但偏好熵增加不能直接证明推荐更准确。可借鉴先审计再丰富画像的流程，并对用户主张保留历史证据；以真人样本校准模拟器，避免把同类 LLM 互评得到的多样性结果当作线上 CTR。

Erfan Shahabi, Amirhossein Roshandel, Mohammad Sadegh Sadeghi, Azadeh Shakery
