Alloc-MoE: Budget-Aware Expert Activation Allocation for Efficient Mixture-of-Experts Inference

针对 Mixture-of-Experts (MoE) 模型推理中大量专家激活导致的延迟瓶颈，提出 Alloc-MoE 框架，引入“激活预算”概念并在两个层级优化专家分配：Alloc-L 通过灵敏度分析和动态规划实现跨层最优分配，Alloc-T 基于路由分数在 token 级别动态重分配激活。在 DeepSeek-V2-Lite 上以一半激活预算实现 1.15× prefill 和 1.34× decode 加速，同时保持模型性能。论文已被 ACL 2026 录用。

Open-TQ-Metal: Fused Compressed-Domain Attention for Long-Context LLM Inference on Apple Silicon

首次实现在 Apple Silicon 上的融合压缩域注意力计算，通过自定义 Metal compute shader 直接对 int4 量化的 KV cache 执行注意力运算（无需反量化），使 Llama 3.1 70B 在单台 64GB Mac 上支持 128K 上下文推理。在 128K 上下文长度下，注意力计算获得 48× 加速，KV cache 内存从 40GB 降至 12.5GB（3.2× 压缩），token 预测精度与 FP16 推理持平。基于 Gemma 4 31B 和 Llama 3.1 70B 的 330 组实验验证。

INSIGHT该工作的突破在于“计算在压缩域进行”的设计理念——跳过传统的反量化-计算-再量化流程，直接在 int4 表示上执行注意力。这不仅大幅降低内存占用，更消除了反量化带来的延迟开销。对于需要在边缘设备或低成本硬件上部署长上下文 LLM 的搜索场景（如文档级 reranking），这种压缩域融合计算的思路具有重要的工程参考价值。代码已开源。

Sai Vegasena

ShadowPEFT: Shadow Network for Parameter-Efficient Fine-Tuning

PolyU

提出 ShadowPEFT，一种集中式参数高效微调方法。与 LoRA 对每层权重独立施加低秩调整不同，ShadowPEFT 引入跨 transformer 层演化的“并行影子状态”，通过影子网络跨层传递适配信息。在可训练参数量相当的条件下，ShadowPEFT 匹配或优于 LoRA 和 DoRA。由于影子模块独立于主干网络，该方法天然适配边缘计算部署场景。

INSIGHTShadowPEFT 的创新点在于将微调信号的传播从“每层独立”变为“跨层演化”，使得少量可训练参数能携带更丰富的跨层语义。影子模块与主干分离的设计特别适合搜索/推荐场景中的多任务部署——可以为不同任务维护独立的轻量影子网络，共享同一个冻结的基础模型，降低多任务 serving 的资源开销。对于需要在单一基座模型上支撑多个垂直搜索任务的团队值得关注。

Xianming Li, Zongxi Li, Tsz-fung Andrew Lee, Jing Li, Haoran Xie, Qing Li

04 3.75

Micro Language Models Enable Instant Responses

UUWMeta

针对智能手表、智能眼镜等边缘设备无法持续运行语言模型而云推理又有多秒延迟的问题，提出 μLMs（微语言模型）——仅 8-30M 参数的超小模型。μLMs 在设备端生成回复的前 4-8 个词以掩盖云端延迟，配合纠错机制实现端云无缝衔接。实验表明这些超小模型在开头生成质量上可匹配 70M-256M 参数模型，证明了“数量级不对称协作”的可行性。

INSIGHTμLMs 展示了一种实用的端云协作架构：用极小模型负责“第一印象”（前几个 token），大模型负责“全面回答”。这种设计思路对搜索产品体验优化有启发——可以用微模型在本地即时生成搜索建议的前缀或摘要片段，同时异步等待服务端返回完整结果。关键是纠错机制确保了无缝过渡，用户无感知地从本地切换到云端输出。

Wen Cheng, Tuochao Chen, Karim Helwani, Sriram Srinivasan, Luke Zettlemoyer, Shyamnath Gollakota

Two-dimensional early exit optimisation of LLM inference

提出二维早退策略，协调 LLM 推理中的层级早退（layer-wise）和句子级早退（sentence-wise），实现乘法级计算节省。在 Llama 3.1/3.2、Gemma、Qwen（3B-8B）四个模型和三个情感分类数据集上验证，对简单任务在最优层级早退基础上额外获得 1.4–2.3× 加速。该方法使用轻量分类适配器，与量化和剪枝技术兼容。

INSIGHT该工作揭示了一个被忽视的优化维度：在层级早退的基础上叠加输入粒度（句子级）的动态退出，两者的加速效果可以相乘而非相加。对于搜索排序场景中使用 LLM 做分类/相关性判断的系统，二维早退可以在保持精度的前提下大幅降低推理成本。且该方法与主流量化方案兼容，可叠加使用，是一个低侵入、高收益的推理优化手段。

Jan Hůla, David Adamczyk, Tomáš Filip, Martin Pavlíček, Petr Sosík

Don't Waste Bits! Adaptive KV-Cache Quantization for Lightweight On-Device LLMs

提出自适应 KV-cache 量化方法，根据 token 重要性动态分配比特宽度（2/4/8/FP16），替代传统的统一量化。轻量控制器基于 token 频率、质量分数、注意力方差和基于熵的不确定性等特征，在解码过程中实时选择量化精度。在 SmolLM-360M 的 HellaSwag 基准上，解码延迟降低 17.75%，精度比静态量化提升 7.60 分，仅比全精度推理低 0.30 分。论文已被 CVPR 2026 录用。

INSIGHT自适应量化的核心思想是“重要的 token 用更多比特，不重要的 token 激进压缩”，这符合注意力机制中信息分布不均匀的本质特征。对于搜索系统中的 LLM 推理，可以借鉴该思路：query 相关的关键 token 保持高精度，背景信息 token 用低比特表示。不过目前仅在 360M 小模型上验证，向大模型的迁移效果有待确认。

Sayed Pedram Haeri Boroujeni, Niloufar Mehrabi, Patrick Woods, Gabriel Hillesheim, Abolfazl Razi

KV Cache Offloading for Context-Intensive Tasks

评估了主流 KV-cache 卸载技术在上下文密集任务上的表现，引入 Text2JSON 基准（从原始文本提取结构化知识）。实验发现现有的 KV cache 卸载方法在 Llama 3 和 Qwen 3 上导致严重的性能退化。深入分析识别出两个失败机制：低秩投影问题和不可靠的标志位选择，并提出了改进策略，在多个模型和基准上提升了精度。

INSIGHT这项工作对 KV cache 压缩领域发出了重要警示：现有的压缩/卸载技术在“信息密集型”任务上表现远比标准基准上差。对于搜索/推荐系统中需要从长文档中提取结构化信息的场景（如 RAG 管线），盲目应用 KV cache 压缩可能导致关键信息丢失。建议在部署前用领域特定的信息抽取任务（而非通用 benchmark）评估压缩方法的实际效果。

Andrey Bocharnikov, Ivan Ermakov, Denis Kuznedelev, Vyacheslav Zhdanovskiy, Yegor Yershov
