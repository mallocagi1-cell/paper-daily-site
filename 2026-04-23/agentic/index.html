Mango: Multi-Agent Web Navigation via Global-View Optimization

本文解决了现有 Web Agent 从根 URL 出发导致导航效率低下的问题，提出 Mango 多智能体网页导航框架。核心思路是将 URL 选择建模为多臂老虎机问题，利用 Thompson Sampling 自适应分配导航预算，并引入 episodic memory 从历史尝试中学习。在 WebVoyager 上达到 63.6%、WebWalkerQA 上达到 52.5% 的成功率，超越最佳基线 26.8%。

Evaluation-driven Scaling for Scientific Discovery

Stanford

本文提出 SimpleTES 框架，系统研究如何通过评估驱动的 scaling 来增强 LLM 在科学发现中的迭代优化能力。框架结合并行探索、反馈驱动精炼和局部选择三种策略，在 6 个领域 21 个问题上取得显著提升，包括量子电路设计开销降低 24.5%、突破已有数学记录等。训练数据还可使模型提升效率并泛化到新问题。

INSIGHT该工作将 Agentic 循环中的评估环节提升为一等公民，揭示了 trial-and-error 发现循环的 scaling 规律。对搜索推荐系统的启示在于：自动化超参搜索、特征工程等迭代优化任务可采用类似的评估驱动框架，让 Agent 在反馈循环中持续改进。并行探索 + 局部选择的组合策略值得在搜索 Agent 的多轮检索中借鉴。

Temporal Leakage in Search-Engine Date-Filtered Web Retrieval: A Retrospective Forecasting Case Study

本文系统审计了 Google 和 DuckDuckGo 的日期过滤功能在 Web 检索中的时间泄漏问题。发现 Google 有 71%、DuckDuckGo 有 81% 的查询至少存在一个包含截止日期后信息的页面，答案直接泄露的比例分别为 41% 和 55%。使用泄漏文档时，LLM 预测的 Brier 分数从 0.24 降至 0.10（虚高）。泄漏模式包括更新文章、相关内容模块和元数据不可靠等。

INSIGHT对 Agentic Search 系统而言，本文揭示了一个关键可靠性问题：依赖搜索引擎日期过滤的 Agent 可能获取到时间污染的信息，导致推理结果不可信。建议采用冻结时间戳的网页快照或更强的检索防护措施。这对构建 Deep Research Agent 的数据时效性控制有直接指导意义。

Ali El Lahib, Ying-Jieh Xia, Zehan Li, Yuxuan Wang, Xinyu Pi

What Makes an LLM a Good Optimizer? A Trajectory Analysis of LLM-Guided Evolutionary Search

本文对 15 个 LLM 在 8 个优化任务上的进化搜索轨迹进行大规模分析，揭示了好的 LLM 优化器的核心特征。优秀的 LLM 优化器充当"局部精炼器"，频繁产生增量改进并逐步在语义空间中聚焦搜索；表现差的模型则出现"语义漂移"，偶有突破但随后停滞。解决方案新颖性本身不能预测性能，新颖性只在搜索足够局部化时才有益。

INSIGHT该研究为使用 LLM 作为搜索/推荐系统中优化 Agent 提供了关键洞察：应鼓励 LLM 做局部精炼而非大幅跳跃。在 Agentic 搜索场景中，Agent 的检索策略也应遵循类似原则——围绕高性能区域进行增量式探索，而非随机发散。轨迹分析方法论可用于评估和改进搜索 Agent 的行为模式。

Xinhao Zhang, Xi Chen, François Portet, Maxime Peyrard

ClawNet: Human-Symbiotic Agent Network for Cross-User Autonomous Cooperation

本文提出 ClawNet 跨用户自主协作框架，首次将 AI Agent 从单用户服务扩展到多用户代理协作。引入"人类共生 Agent 范式"，每个用户拥有专属 Agent 系统进行跨用户协作。核心机制包括：分层身份结构（Manager Agent + 上下文特定 Identity Agent）、范围化授权控制、全面操作审计日志。通过中央编排器实现身份绑定和授权验证。

INSIGHTClawNet 开创了跨用户 Agent 协作的基础设施层，这对搜索推荐系统有深远意义：未来的 Agentic 搜索可能涉及多用户 Agent 间的信息共享和协作检索（如团队知识管理、协作搜索）。其分层身份和授权机制为构建安全的多 Agent 搜索系统提供了参考架构。

Zhiqin Yang, Zhenyuan Zhang, Xianzhang Jia, Jun Song, Wei Xue, Yonggang Zhang, Yike Guo

Chat2Workflow: A Benchmark for Generating Executable Visual Workflows with Natural Language

本文提出 Chat2Workflow 基准，研究 LLM 从自然语言指令生成可执行可视化工作流的能力。基准来源于真实业务工作流，可直接部署在 Dify 和 Coze 等平台。实验表明，当前领先 LLM 在生成正确、稳定、可执行的工作流方面仍面临挑战，特别是在复杂或变化的需求场景下。Agentic 方法取得了一定改进但空间仍大。

INSIGHTChat2Workflow 揭示了当前 LLM 在 Agent 工作流自动化中的瓶颈：复杂需求下工作流的正确性和稳定性不足。对搜索推荐团队而言，这指出了将 LLM Agent 应用于搜索 pipeline 自动编排（如查询理解→检索→排序→重排的自动组装）时需要关注的可靠性问题。Dify/Coze 的工业部署路径提供了直接的实践参考。

Yi Zhong, Buqiang Xu, Yijun Wang, Zifei Shan, Shuofei Qiao, Guozhou Zheng, Ningyu Zhang

From Verbatim to Gist: Distilling Pyramidal Multimodal Memory via Semantic Information Bottleneck for Long-Horizon Video Agents

本文提出 MM-Mem 金字塔式多模态记忆架构，基于模糊痕迹理论将信息分层组织——从原始感知数据到语义摘要。采用语义信息瓶颈（SIB）目标函数和 SIB-GRPO 优化方法，平衡压缩与任务相关性保留。引入熵驱动检索机制，仅在需要时访问详细信息。在 4 个基准上达到 SOTA，offline 和 streaming 任务均表现优异。

INSIGHTMM-Mem 的金字塔记忆架构和信息瓶颈方法为 Agentic 系统的长程记忆管理提供了理论基础。搜索 Agent 在多轮检索中面临类似的信息过载问题，可借鉴分层记忆思路：将早期检索结果压缩为 gist 级摘要，仅在需要时检索原文细节。熵驱动的选择性检索机制对控制 Agent 的 token 消耗也有实际价值。

Niu Lian, Yuting Wang, Hanshu Yao, Jinpeng Wang, Bin Chen, Yaowei Wang, Min Zhang, Shu-Tao Xia

Characterizing AlphaEarth Embedding Geometry for Agentic Environmental Reasoning

Google

本文分析了 Google AlphaEarth 64 维 embedding 的流形几何结构，涵盖 1210 万美国大陆样本（2017-2023），发现有效维度仅 13.3，84% 的位置切空间旋转超过 60°。基于此构建了包含 9 个专用工具的 Agentic 系统，通过 FAISS 索引的 embedding 数据库进行检索链处理环境查询，在多步比较任务上达到 4.28/5.0 的分数。

INSIGHT本文展示了一种典型的 Agentic 工具使用模式：先理解 embedding 空间的几何特性，再设计专用工具链进行检索推理。这种"embedding 理解 → 工具设计 → 检索链"的范式可迁移到搜索推荐场景，例如理解用户/商品 embedding 空间的结构后设计针对性的 Agent 工具。Google AlphaEarth 的流形分析方法也可用于诊断搜索 embedding 空间的质量。

Mashrekur Rahman, Samuel J. Barrett, Christina Last

STAR-Teaming: A Strategy-Response Multiplex Network Approach to Automated LLM Red Teaming

本文提出 STAR-Teaming，一种基于策略-响应多重网络的自动化 LLM 红队测试框架（ACL 2026 Findings）。将多 Agent 系统（MAS）与多重网络优化结合，通过语义社区组织发现有效攻击策略。在更低计算成本下实现更高的攻击成功率（ASR），同时提升了 LLM 漏洞的可解释性。代码已开源。

INSIGHTSTAR-Teaming 的多 Agent 协作 + 网络优化范式对搜索 Agent 的安全性测试有直接参考价值。搜索推荐系统中的 LLM Agent 同样需要安全红队测试，该框架的策略-响应网络方法可用于系统性发现搜索 Agent 的漏洞。多重网络的语义社区发现也可迁移到搜索策略的自动发现场景。

MinJae Jung, YongTaek Lim, Chaeyun Kim, Junghwan Kim, Kihyun Kim, Minwoo Kim
