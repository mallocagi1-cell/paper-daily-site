LoopCTR: Unlocking the Loop Scaling Power for Click-Through Rate Prediction

针对 Transformer 类 CTR 模型通过堆叠参数扩展带来的计算和存储瓶颈，提出 LoopCTR 循环缩放范式。核心思路是通过共享模型层的递归复用来增加训练时计算量，从而将计算量与参数量增长解耦。LoopCTR 采用三明治架构，配合超连接残差 (Hyper-Connected Residuals) 和 MoE，在每个循环深度进行过程监督 (Process Supervision)，实现「训练多轮循环、推理零循环」策略——单次前向传播即超越所有基线。在三个公开基准和一个工业数据集上取得 SOTA，Oracle 分析进一步揭示 0.02-0.04 AUC 的未开发提升空间。

CS3: Efficient Online Capability Synergy for Two-Tower Recommendation

📖 深度解读 · 7 分钟 →

针对双塔模型在大规模候选召回中表达能力受限、embedding 空间对齐不足和特征交叉缺失的问题，提出 Capability Synergy (CS3) 在线框架。CS3 包含三个机制：(1) Cycle-Adaptive Structure 通过自适应特征去噪在每个塔内进行自修正；(2) Cross-Tower Synchronization 通过轻量级双塔互感知提升 embedding 对齐；(3) Cascade-Model Sharing 跨阶段复用知识增强一致性。该框架在保持实时约束的同时显著增强了双塔检索器的能力。

INSIGHTCS3 直接解决了推荐系统多阶段流水线中双塔架构的核心痛点：双塔隔离导致的表达力不足。Cross-Tower Synchronization 特别值得关注——它在不引入 late interaction 高延迟的前提下实现了塔间信息同步，这对在线学习场景下保持召回质量至关重要。对于 UGC 社区搜索，双塔模型是主力召回手段，CS3 提供了一条不牺牲延迟即可提升召回质量的实用路径。

Lixiang Wang, Shaoyun Shi, Peng Wang, Wenjin Wu, Peng Jiang

A Mechanism and Optimization Study on the Impact of Information Density on User-Generated Content Named Entity Recognition

揭示了 NER 模型在 UGC（社交媒体等用户生成内容）上性能崩溃的统一根因：信息密度 (Information Density) 过低。通过分层混杂控制重采样实验，排除了实体稀有度和标注一致性等因素后，证明信息密度是独立的关键因子。提出 Attention Spectrum Analysis (ASA) 方法量化低信息密度如何导致注意力散射，并据此设计了针对性的优化策略。该研究对 UGC 场景下的文本理解任务提供了机制层面的解释。

INSIGHT对 UGC 社区搜索而言，这项研究直接解释了为什么传统 NER 模型在帖子、评论等短文本上表现不佳——问题不在于表层噪声（错别字、新词等），而在于 UGC 文本的结构性稀疏导致信息密度过低。ASA 方法将这一机制量化为注意力散射现象，为优化 UGC 场景下的命名实体识别和 query 理解提供了新的诊断工具。对于社区搜索平台，提升 NER 准确率可直接改善 query 理解和内容标签质量，进而提升搜索相关性。

Jiang Xiaobo, Dinghong Lai, Song Qiu, Yadong Deng, Xinkai Zhan

GraphRAG-IRL: Personalized Recommendation with Graph-Grounded Inverse Reinforcement Learning and LLM Re-ranking

提出 GraphRAG-IRL 混合推荐框架，结合图增强特征构建、逆强化学习 (IRL) 和 LLM 个性化重排序。在物品、类别和概念上构建异构知识图谱，检索个体和社区偏好上下文，用这些信号训练 Maximum Entropy IRL 模型进行校准预排序，然后仅对短候选列表应用 LLM 重排序。该方法旨在解决纯 LLM 提示排序存在的校准差、顺序敏感和流行度偏差问题。

INSIGHTGraphRAG-IRL 的核心设计是分而治之：用 IRL 模型负责大规模候选的校准排序（解决 LLM 排序的校准和效率问题），再用 LLM 仅处理短列表的精排（发挥 LLM 语义理解优势）。这种 IRL + LLM 的级联架构为搜索推荐系统引入 LLM 提供了务实方案——不是让 LLM 替代排序模型，而是让 LLM 在其擅长的小规模精排场景发挥价值，值得在 UGC 搜索的精排阶段借鉴。

Siqi Liang, Xiawei Wang, Yudi Zhang, Jiaying Zhou

From Top-1 to Top-K: A Reproducibility Study and Benchmarking of Counterfactual Explanations for Recommender Systems

系统性复现并评估了 11 种推荐系统反事实解释 (Counterfactual Explanation) 方法，涵盖原生解释器 (LIME-RS、SHAP、PRINCE、ACCENT、LXR、GREASE) 和图神经网络专用解释器。提出统一评估框架，从三个维度评估：解释格式（隐式/显式）、评估层级（单项/列表级）和扰动范围（用户交互向量/用户-物品交互图）。解决了现有方法评估协议不一致、数据集和指标各异导致的可复现性问题。

INSIGHT这项基准工作对推荐系统可解释性研究具有重要参考价值。统一评估框架揭示了不同解释方法在 Top-K 场景下的真实表现差异，为从业者选择合适的解释方法提供了实证依据。对于 UGC 社区搜索，可解释性可用于理解排序模型为何将特定帖子排在前面，帮助运营团队发现并修正排序异常。LIME-RS 和 SHAP 作为模型无关方法，可直接应用于现有搜索排序模型的诊断。

CAST: Modeling Semantic-Level Transitions for Complementary-Aware Sequential Recommendation

针对序列推荐中互补关系建模的核心挑战——基于共购统计的方法容易将流行度偏差导致的虚假相关误判为真正的互补关系——提出 CAST 模型。核心方法是在语义编码层面建模物品间的细粒度语义转换，避免将语义编码聚合为粗糙的物品表征。通过捕捉物品规格等细粒度语义来识别可靠的互补关系，有效区分真实互补与虚假共购。

INSIGHTCAST 解决的虚假互补关系问题在实际推荐系统中非常常见：两个物品高频共购不一定说明它们互补，可能只是都很热门。在语义编码层面而非物品表征层面建模转换关系是关键设计——这保留了识别互补性所需的细粒度信息。对于 UGC 社区搜索中的相关内容推荐场景，这种细粒度语义建模思路可用于识别帖子间的真实主题关联，而非仅依赖共浏览统计。

AutoAdapt: Automated domain adaptation for large language models

Microsoft

微软研究院发布的 AutoAdapt 框架，实现大语言模型的自动化领域适应。该方法能够在目标域数据有限的情况下，自动选择最优的适应策略（如 LoRA、prompt tuning 等），将通用 LLM 高效迁移到特定垂直领域。框架提供了系统化的方法来评估和选择适应路径，降低了 LLM 领域适应的工程门槛。

INSIGHTAutoAdapt 提供的自动化领域适应方案对搜索推荐场景有直接参考价值：将通用 LLM 适配到 UGC 社区搜索的特定领域（如论坛帖子、问答内容），无需大量领域标注数据即可提升模型在垂直场景下的理解能力。微软作为工业级 AI 部署的领先者，其方法论通常考虑了规模化部署的实际约束，AutoAdapt 的策略自动选择机制可减少团队在 LLM 适应方案上的试错成本。

VoteGCL: Enhancing Graph-based Recommendations with Majority-Voting LLM-Rerank Augmentation

针对推荐系统中用户-物品交互稀疏导致的性能下降和流行度偏差问题，提出基于 LLM 多次重排和多数投票的数据增强框架 VoteGCL。通过 few-shot 方式多次提示 LLM 对物品重排序，用多数投票聚合结果生成高置信度合成交互数据，并基于测度集中不等式提供理论保证。将增强数据整合到图对比学习框架中，有效缓解分布偏移和流行度偏差。

INSIGHTVoteGCL 的多数投票策略是将 LLM 引入推荐数据增强的稳健方案——单次 LLM 排序结果不可靠，但多次采样后投票可显著提升一致性，且有理论收敛保证。图对比学习的引入有效缓解了合成数据引入的分布偏移。对于 UGC 社区搜索，在交互数据稀疏的新内容或长尾查询场景下，这种 LLM 辅助数据增强加图学习的思路可用于冷启动优化。

Reproducibility and Artifact Consistency of the SIGIR 2022 Recommender Systems Papers Based on Message Passing

系统评估了 SIGIR 2022 中基于消息传递的推荐系统论文的可复现性和代码数据一致性。研究发现许多声称 SOTA 的图神经网络推荐方法在标准化评估协议下的表现与原论文报告存在显著差异，部分方法甚至不优于简单基线。该工作为推荐系统社区在方法选型时提供了可靠的参考依据。

INSIGHT这项大规模复现研究对推荐系统从业者的方法选型具有实际指导意义：许多 GNN 推荐方法的论文报告效果被高估，在统一评估下表现平庸。在引入图神经网络等复杂方法到搜索推荐系统前，应先与简单但调优充分的基线进行公平对比，避免论文驱动的技术选型。这项工作提醒我们关注可复现性，在实际系统中选择经得起独立验证的方法。

Maurizio Ferrari Dacrema, Michael Benigni, Nicola Ferro

RecSys-Fairness: A Framework for Reducing Group Unfairness in Recommendations

提出 RecSys-Fairness 框架，系统性减少推荐系统中的群体不公平性。框架提供标准化工具和方法，用于检测、量化和缓解推荐结果中对不同用户群体的偏差，涵盖曝光公平性和结果公平性等多个维度。作为通用框架可适配主流推荐算法。

INSIGHT推荐公平性是工业推荐系统日益重要的维度。RecSys-Fairness 提供的标准化框架可帮助社区搜索平台评估排序结果是否对不同创作者群体存在系统性偏差（如头部创作者过度曝光、新创作者冷启动困难）。在搜索推荐系统中引入公平性约束时，该框架提供的量化指标和缓解策略可作为起点，尤其适合需要平衡内容生态健康度与搜索相关性的 UGC 平台。

Rafael Vargas Mesquita dos Santos, Giovanni V. Comarela
