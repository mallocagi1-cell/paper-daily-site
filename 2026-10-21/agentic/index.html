OpenSaC: A Python Library for Search as Code in Deep Research Agents

深度研究常把时间花在反复调用搜索工具上。OpenSaC 让模型编写程序，组合搜索、阅读、重排和本地处理，只把需要的证据送回上下文。在 BrowseComp 上，平均模型 token 用量减少 37.8%。

EG-GRPO: Evidence-Guided Step-level Credit Assignment for Deep Search Agents

RUCAAnt Group

搜索智能体常到最后才知道答案对错，难以学到哪次检索有用。EG-GRPO 把首次找到支持证据的步骤记为进展，并在相近知识状态间比较动作。4B 模型在 GAIA 上达到 45.9% 准确率。

INSIGHT只奖励第一次找到的新证据，可以避免重复引用反复得分。比较动作时还要考虑已经掌握的线索，否则接近完成的轨迹会天然占优；论文用逐级放宽分组的办法缓解状态样本稀疏。

Sijia Luo, Mengjie Gao, Yuxiao He, Mengshu Sun, Cuiping Li, Hong Chen, Jing Zhang

ClueFlow: Learning Long-Horizon Search through Attributed Research-State Transitions

长程搜索训练很难分清哪些浏览动作真正推进了答案。ClueFlow 把来源、研究状态变化和最终结论连起来，再用这些联系分配监督和奖励。在受控实验中，只用约 30% 的训练 token 就能达到全轮监督的效果。

INSIGHT证据进入状态的过程，比单独保存浏览记录更有训练价值。即使最终答错，轨迹中经过核验的有效状态变化仍可用于学习；这能回收失败搜索里的局部进展，减少把整条轨迹一并丢弃的浪费。

Yicheng Wang, Wentao Tan, Yidan Huang, Yifei Liu, Qiong Cao

Learning to Program Retrievals: Composing Search Primitives via Reinforcement Learning

KAISTMeta

多步问答需要灵活组合检索，而固定工具链限制了搜索策略。研究让模型生成可执行的检索程序，并对失败程序做受约束的局部修改来辅助训练。4B 模型在七项问答测试上的平均精确匹配率为 51.5%。

INSIGHT检索范围和模型阅读量可以分开控制。程序先在本地合并、去重和重排，再打印少量证据进入上下文。这样可以扩大候选搜索范围，又不必让模型逐段读取所有召回内容，适合复杂社区问答的证据收集。

Kyuyoung Kim, Zilin Xiao, Zhiyuan Wang, Avinash Atreya, Ke Yang, Jinwoo Shin, Kecheng Hao

HybridResearcher: Bridging the Structured-Unstructured Boundary for Deep Research Agents

企业问题常要同时查表格和网页，小模型容易在两类证据之间断链。HybridResearcher 围绕连接两侧信息的实体合成训练轨迹，并要求单侧证据不能独立解题。相比基座，4B 模型的 pass@8 提升 30.0 个百分点。

INSIGHT训练样本必须真的需要跨来源推理。把两个独立问题拼在一起并不够；连接实体应来自已有任务的答案，并检查缺少任意一侧都无法完成。这给“结构化属性加帖子证据”的搜索任务提供了明确的数据构造办法。

OpenVLHarness: Real World Visual Agentic Tool-Use with Multimodal Memory

视觉推理有时缺的不是思考时间，而是可核对的外部证据。OpenVLHarness 统一工具接口，把图像、结构化数据和网页保存成可引用的记忆，再让程序组合它们。在受控评测中，平均得分提升 9.7—12.6 个百分点。

INSIGHT工具输出要同时满足可读和可追溯。把视觉证据保存成可寻址文件，后续动作才能重用同一份观察，而不必靠文字摘要猜测图像细节。对社区图文问答，这比单纯增加推理预算更贴近证据缺失的问题。

The Scheduler Is a Hidden Retriever: How Asynchrony Shapes Evidence Acquisition in Search Agents

异步搜索中，结果先后到达会让智能体走向不同路线。研究按子问题等待证据完整，再以独立于完成顺序的规则分配共享搜索。在三个基准上，这种调度相较提前决策最多提升 12.6 个百分点准确率。

INSIGHT调度规则也会改变召回结果。哪条证据先到，会影响下一次搜索，影响还可能在所有初始结果到齐后继续存在。评估搜索策略时固定证据集合仍不够，还要记录到达顺序、释放条件和共享搜索预算。

Ruiyang Ren, Yuhao Wang, Yinan Zhang, Chunyan Miao

Amazon

MemT-1.0: Towards Memory-Native Evolution

长期交互需要保留经验，但保存完整上下文缓存很占资源。MemT-1.0 把可更新记忆融入模型计算，用多存储结构扩大容量，再训练模型使用积累的经验。在 128K 历史长度下，Nano 端到端推理约加速 1.86 倍。

INSIGHT持久记忆不必等同于完整缓存。稳定更新的内部状态可以压缩历史，但也改变了信息保留方式。评估这类记忆模型时，既要测延迟和存储，也要检查关键事实能否被找回，以及通用任务能力是否保留。

Zhiyu Li, Zeyu Zhang, Linyun Liu, Yiwei Bu, Chenyang Xi

AdaExploreBench: Benchmarking LLM Agents for Proactive Exploration and Test-time Adaptation in Evolving Environments

环境规则改变后，智能体可能继续沿用已经失效的经验。AdaExploreBench 隐藏规则并让它们悄悄变化，测试模型能否主动找证据并重新探索。评测八个模型时，GPT-6 Sol 的校准准确率为 61.9%。

INSIGHT知道如何推理，不等于知道何时重新找证据。给足线索或移除规则漂移后，模型表现明显更好。搜索产品可以把知识变更、过期证据和重新检索触发条件单列成评测维度，暴露静态问答集看不到的故障。

Rui Wang, Zishen Lai, Jiayu Liu, Cheng Qian, Jeonghwan Kim
