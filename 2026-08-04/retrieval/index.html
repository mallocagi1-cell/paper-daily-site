Semantic Retrieval for Product Search in E-Commerce

Flipkart 以 Qwen3-Embedding-4B 构建 256 维双塔，先在 700 万查询商品对上做带假负例掩码的对比学习，再用 200 万分级偏好样本进行 ROAR 对齐。2.5 万查询离线评测中 MAP@8 提升 5.57 个点，线上 CTR、加购和订单分别提升 2.39%、4.58%、2.62%。

Behavioral Feature Boosting via Substitute Relationships for E-commerce Search

Amazon

Amazon 为缺少交互的新商品寻找平均 5 个、最多 10 个替代品，再聚合点击、加购、购买和销量等行为特征，为排序模型提供冷启动信号。基于约 300 万查询的 LambdaMART 实验中，购买量提升 1.32%、销量提升 0.51%、点击提升 1.82%，并完成四周线上 A/B 测试后投入生产。

INSIGHT这类方法不要求改造主排序架构，适合迁移到新帖子、零互动回答等 UGC 冷启动场景：先通过内容与作者等信号找可靠替代项，再对行为特征做受控平滑。上线前应建立替代关系置信阈值和类目约束，防止热门内容的噪声被放大，并分新旧内容观察相关性与曝光公平性。

Chaosheng Dong, Michinari Momma, Yijia Wang, Yan Gao, Yi Sun

Learning to Summarize for Search Relevance with Reinforcement Learning

Walmart

Walmart 的 ReLSum 不优化通用摘要质量，而以排序器的相关性反馈作为强化学习奖励，离线生成并缓存只依赖商品的短摘要。查询仅在训练期用于计算奖励，因此线上不增加生成延迟；大规模生产数据上同时改善 nDCG 与召回，A/B 测试的访客订单数和每单件数也显著增长，尾部查询收益更突出。

INSIGHT对长帖或噪声 UGC，可把“摘要”视为可学习的索引字段，而不是展示文案：用冻结的 cross-encoder 或线上相关性代理作为奖励，离线压缩真正影响匹配的证据。该设计兼顾重排质量与服务成本，但应检查摘要是否丢失否定、时效和立场信息，并用原文通道兜底。

Nitin Yadav, Changsung Kang, Hongwei Shang

A Case-Driven Multi-Agent Framework for E-Commerce Search Relevance

ByteDance

ByteDance 将搜索相关性治理拆为标注、优化和用户三个协作智能体，并以坏例检索、全局记忆和专用相关性模型形成每日闭环。候选生成使真实标签覆盖率提升 7.9%，查询结构识别的属性与品牌 F1 分别提升 3.9、2.7 个点，线上成对评测胜率提升 6.91%，资源优化还降低 21% GPU 负载。

INSIGHT真正的新意不是多智能体数量，而是把 bad case 从发现、归因、策略生成到复验变成可追踪资产。社区搜索团队可先做轻量版本：统一沉淀 query-doc 失败案例、历史修复和评测反馈，再让代理提出召回或排序实验；涉及规则变更和上线决策时保留人工审核，避免自动闭环固化偏差。

Global E-Commerce Search Relevance Team

From Unstructured to Structured: LLM-Guided Attribute Graphs for Entity Search and Ranking

Amazon

Amazon 先离线用 LLM 抽取类目感知属性并构建商品属性图，线上以 bge-m3 召回 50–80 个候选，再由 Claude 3.5 Sonnet v2 基于结构化属性重排。人工评测中 P@1 从 51.36% 升至 57.14%；每商品提示词从约 700 降至 300 token，单请求减少 2.04 万 token 并节省约 250ms。

INSIGHT将昂贵的 LLM 理解前移为可复用结构，是比逐文档在线推理更稳的工程路线。社区搜索可离线抽取主题、实体、时效、地域和内容类型，构成稀疏属性图，再与向量召回融合；上线前需监控属性漂移、抽取错误传播和长尾覆盖，敏感属性则不应进入个性化排序。

Yilun Zhu, Nikhita Vedula, Shervin Malmasi

Optimal Re-Ranking Depth

University of GlasgowUniversity of Waterloo

论文把二阶段重排深度视为查询级决策，而非固定超参，并发现候选越多并不总能提高效果。IR-DCG@10 预测器在保持检索有效性的同时，将平均重排深度最多压缩 3 倍；在 MSMARCO DEV 上，理想 oracle 可提升超过 7% 的效果并把平均深度减少 5 倍，说明按查询分配算力有明显空间。

INSIGHT社区搜索的短查询差异很大：明确实体词可能只需浅重排，模糊意图或长尾表达才值得调用更贵模型。可从首阶段分数分布、候选相似度和查询特征训练深度预测器，并设置最小深度与质量护栏；评测必须同时报告 nDCG、P95/P99 延迟和平均 token 成本，防止只优化均值。

Siqin Huo, Andrew Parry, Charlie Clarke, Debasis Ganguly

QuDAR: Query-Wise Dual-Perspective Adaptive Retrieval

KAIST

QuDAR 同时在稀疏与稠密检索器、原始与扩展查询两个维度做查询级动态融合，以首二名分差等置信信号或 GPT-4o-mini 的盲相关性评分确定权重。在四个 BEIR 数据集上，FiQA 的 nDCG@10 从静态平均 0.2143 提至 0.2837，HotpotQA 从 0.5529 提至 0.6579。

INSIGHT固定 hybrid 权重会掩盖不同查询对词法精确性和语义扩展的需求。可先用无需训练的 top-1/top-2 margin 做低成本路由：专名、标签和缩写偏稀疏，口语化与长尾表达偏稠密；只有低置信查询再调用 LLM 估权。需要单独评估 query expansion 的错误放大与额外延迟。

Joeun Kim, Seunghyouk Yoon, Xuan-Bach Le, Youngeun Nam, Doyoung Kim, Hwanjun Song, Jae-Gil Lee

Latent Terms: Dense Retrievers Contain Trivially Extractable BM25-ready Zipfian Vocabularies

MMixedbread

论文用稀疏自编码器解释冻结稠密检索器的激活，把呈 Zipf 分布的潜变量直接当作 BM25 词项，无需稀疏监督、难负例或显式稀疏正则。Contriever 在 BEIR 平均 nDCG@10 从 0.415 升至 0.474，LIMIT 的 R@100 从 0.0530 跃升至 0.7295；但部分多向量底座的平均效果会下降。

INSIGHT该工作提示稠密模型内部已经形成可索引的“概念词表”，有机会同时获得语义泛化、倒排效率和一定可解释性。落地时应把它作为现有混合召回的增量通道，而非立即替代向量索引；先比较 postings 规模、查询延迟、长尾术语召回，并按底座模型检查潜词转换是否损伤原有效果。

Benjamin Clavie, Sean Lee, Aamir Shakir, Makoto P. Kato

Learning to Rank with Multi-Criteria LLM-Judge Annotations

University of New Hampshire

研究把 LLM judge 从单一相关性标注器改为排序特征生成器，分别评估精确匹配、覆盖度、主题性和上下文契合度，再训练学习排序模型。在 TREC DL 2019、2020、2023 上，四类判据带来 14%–36% 的 nDCG@20 提升；弱基线更依赖上下文契合，强基线则重新提高原始检索分数的权重。

INSIGHT多维判据比一个总分更利于诊断社区搜索：结果可能主题相关却缺少上下文，或覆盖用户意图但不够精确。可让 LLM 离线生成四维软标签，配合点击和人工判断训练轻量 LTR；需用校准集检查判据相关性、偏见和成本，并防止同一模型既产标签又评测造成自证循环。

Naghmeh Farzi, Laura Dietz

TELLER: Dual-Path Iterative Preference Optimization for Table Entity Linking

University of Galway

TELLER 面向表格实体链接，先从 Wikidata 召回并排序候选，再对直接回答路径做迭代 DPO，对推理路径使用长度归一化且带正则的偏好优化，使训练持续聚焦模型残余错误。TableInstruct 从 94.35 提至 94.50，MammoTab V2 直接路径从 87.59 提至 88.20，推理路径从 79.09 提至 81.85。

INSIGHT对带实体、标签和结构字段的 UGC 搜索，最值得借鉴的是用每轮失败样本重建偏好对，而不是长期依赖静态 hard negative；长度归一化也能避免长解释天然占优。迁移时可将实体候选召回与语义检索分层，优先在别名、缩写和歧义实体上验证，但论文的表格场景与普通短文本仍有明显域差。
