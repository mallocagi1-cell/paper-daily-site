DSIRM: Learning Query-Bridged Discrete Semantic Identifiers for E-commerce Relevance Modeling

针对电商搜索相关性中连续 embedding 难以刻画细粒度属性差异、而无监督量化生成的离散 Semantic ID（SID）缺乏 query 相关性的问题，提出 DSIRM。物品侧用 query-bridged 对比量化，把 query-item 交互监督注入残差量化（RQ），学到相关性感知的语义划分；query 侧用生成式 LLM 直接从文本预测 item SID，覆盖长尾 query 与意图歧义；再用 query 与 item SID 的层次前缀匹配产出判别特征。Tmall 生产数据离线 AUC +1.54%，线上 UCTR +0.13%、UCTCVR +0.25%。

KEY INSIGHT · 对业务意味着什么把 Semantic ID 生成从无监督量化升级为带 query 监督的对比量化，是社区搜索相关性建模可直接借鉴的思路：SID 不再只编码物品内容，而是编码在何种 query 下两个物品应共享语义桶。query 侧用生成式 LLM 预测 SID 覆盖长尾，与 item 侧 SID 做前缀匹配，离散信号与稠密向量互补——这种 hybrid 架构对短文本 UGC 的细粒度相关性区分尤其有参考价值。

Breaking the Likelihood Trap: Consistent Generative Recommendation with Graph-structured Model

Kuaishou

生成式重排把重排建模为整体序列生成任务，但普遍陷入似然陷阱——高似然序列往往重复、人感质量低，限制用户参与度。CONGRATS 提出两点：图结构模型（Graph-structured Model）通过探索多条路径生成更多样的序列，扩展解码空间并用图转移显式建模物品依赖以提升准确率；一致性可微训练引入 evaluator 让模型直接从用户偏好学习，对齐人感质量。在公开数据集上超过 SOTA 重排方法，并在快手（3 亿 DAU）线上部署取得业务收益。

INSIGHT点出并系统性破解了生成式重排的似然陷阱：单纯最大化序列似然会塌缩到重复、单调的列表。用图结构解码替代线性自回归，把多样性做进解码空间而非靠后处理打散；再用可微 evaluator 把人感质量/用户偏好直接接入训练目标。对搜索结果页重排有直接启发——重排不只追求点击似然，更要建模列表级一致性与多样性。

Qiya Yang, Xiaoxi Liang, Zeping Xiao, Ying Cao, Yingjie Deng, Yuxin Ren, Yalong Wang, Yongqi Liu

Beyond Retrieval: Learning Compact User Representations for Scalable LLM Personalization

LLM 个性化通常走两条路：输入级（检索用户历史、拼 profile prompt）对检索质量与 prompt 设计敏感；参数级（每用户维护 PEFT 模块）存储与维护成本随用户规模线性增长。TAP-PER 提出基于前缀的框架，把用户偏好编码为可学习的轻量用户状态前缀 embedding，免去显式 prompt 构造，也避免每用户重适配器。它把用户建模拆为 user-state 与 query-conditioned 两部分并引入时间信号刻画兴趣演化。在 6 个 LaMP 任务上，per-user 参数比 OPPU 少 130 倍，1000 用户规模下总参数约为 PER-PCS 的一半。

INSIGHT给可扩展 LLM 个性化提供了介于 prompt 注入与每用户 adapter 之间的第三条路：用轻量前缀 embedding 表示用户状态，参数量与用户数解耦。把用户建模拆成 user-state（长期）+ query-conditioned（当前意图）符合搜索个性化的直觉。130x 参数压缩对亿级用户的工程落地是关键——这正是社区搜索做 per-user 个性化时绕不开的存储/维护成本问题。

Heng Cao, Fan Zhang, Jian Yao, Yujie Zheng, Changlin Zhao, Lu Hao, Yuxuan Wei, Wangze Ni, Huaiyu Fu 等 11 人

Improving the Efficiency and Effectiveness of LLM Knowledge Distillation for Conversational Search

University of Amsterdam

对话式搜索靠 LLM 改写 query 提升效果，但推理期调用 LLM 代价高。常见做法是从 LLM query 改写中做知识蒸馏，近期工作用 KL 散度（KLD）放松与教师信号的对齐。本文系统研究 KLD 蒸馏若干未被充分探讨的方面：发现在 KLD 目标上加对比损失能显著提升精度向排序指标，并考察了对比采样策略的影响。在 TopiOCQA 上实现约 2× FLOPS 下降，Recall@100 仅下降 ≤2%。

INSIGHT对话式搜索里用大 LLM 改写 query 但又不想付推理成本是普遍痛点，本文给出可操作的蒸馏配方：KLD + 对比损失，且对比采样策略对精度向指标影响显著。2× FLOPS、Recall@100 损失 ≤2% 的性价比对线上 query 理解链路有直接参考——把 LLM 改写能力蒸馏进轻量模型，是社区搜索 query 改写降本的现实路径。

Stan Fris, Jan Hutter, Jan Henrik Bertrand, Simon Lupart, Mohammad Aliannejadi

SAILRec: Steering LLM Attention to Dual-Side Semantically Aligned Collaborative Embeddings for Recommendation

LLM 推荐器常注入用户-物品交互的协同 embedding，但提供不等于用好。通过诊断式注意力分析，作者发现协同 embedding 的利用是深度相关、对齐敏感的：浅层过早干扰、深层协同证据不足。SAILRec 提出双侧语义对齐 + 层次注意力引导：物品侧 embedding 对齐物品文本语义、用户侧对齐基于码本的语义画像；同时抑制浅层协同干扰、在深层决策层强化协同证据。在 MovieLens-1M 与 Amazon-Book 上稳定优于代表性基线，消融与 masking 分析验证设计有效。

INSIGHT回答了一个被忽视的问题——LLM 拿到协同 embedding 后到底有没有用、在哪一层用。诊断结论利用度随深度变化且对齐敏感很有方法论价值：与其堆更多协同信号，不如引导注意力在正确的层使用它。双侧语义对齐（物品对齐文本、用户对齐码本画像）的思路，对把协同信号塞进 LLM 做搜索排序时如何避免被内部语义知识淹没，有借鉴意义。

Xi Wu, Jiale Wang, Zihan Wang, Yichen Gao, Xiaocui Yang, Shi Feng, Daling Wang, Yifei Zhang

Bridging Short Videos and Live Streams: Reasoning-Guided Multimodal LLMs for Cross-Domain Representation Learning

Kuaishou📖 深度解读 · 7 分钟 →

直播是核心转化场景但行为数据稀疏、冷启动严重，而短视频流量大、行为信号丰富。把短视频上的用户兴趣迁移到直播推荐可缓解冷启动。短视频与直播都是复杂多模态物品，融合多模态信号能提升效果，但多模态 LLM（MLLM）在跨域推荐中应用尚少。本文提出 RGCD-Rep，一个推理引导的跨域表征学习框架，资源高效地引入 MLLM 推理来对齐短视频与直播表征。在快手直播推荐（日服务超 4 亿用户）部署后，A/B 测试在多个核心业务指标上取得显著收益。

INSIGHT针对直播冷启动用短视频→直播跨域迁移，是 UGC 平台普遍可复用的范式。亮点在于资源高效地引入 MLLM 推理——不是直接拿 MLLM 在线推理，而是用其推理能力做表征对齐，绕开 MLLM 的在线延迟问题。对社区搜索里高频内容→低频/新内容的兴趣迁移与多模态表征对齐，提供了工业级落地参考。

EviRank: Evidence-Based Confidence Estimation for LLM-Based Ranking

LLM 用于推荐/排序有可靠性隐患：领域覆盖有限且本身有随机性。已有不确定性量化方法有两个问题：为问答设计的全局置信度无法揭示排序列表里哪些位置不可靠；从模型内部抽取的细粒度置信度在所有位置都偏低且均匀，无法用于过滤。EviRank 提出基于证据的置信度估计，给出位置级、可区分的可靠性信号以筛除不可靠预测。

INSIGHT把 LLM 排序结果到底哪几个位置不可信做成可操作的位置级置信度，是 LLM-in-ranking 落地的实用工具。指出现有内部置信度均匀偏低不可用这一失败模式很有价值。对在搜索排序中引入 LLM 又担心其随机性/幻觉的团队，position-aware confidence 可作为兜底过滤与人审触发的依据。

Meng Yan, Cai Xv, Xujing Wang, Ziyu Guan, Wei Zhao

CD-LLMCARS: Cross Domain Fine-Tuned Large Language Model for Context-Aware Recommender Systems

传统推荐面临冷启动（信息有限）与上下文理解不足两大问题。CD-LLMCARS 提出跨域微调的上下文感知推荐：用多域信息微调 Llama 2，增强生成与用户语境对齐的推荐结果，借大模型的语义理解缓解冷启动并更准确刻画用户综合偏好。

INSIGHT用跨域微调 LLM（Llama 2）做上下文感知推荐，核心是借多域知识迁移缓解单域冷启动。对社区搜索里新用户/新内容的语义化理解有参考，但属较常规的 LLM 微调推荐路线，需关注微调成本与在线推理代价。

基于交互行为语义模式增强的ID推荐方法 (Enhanced ID Recommendation Method Utilizing Semantic Patterns of Interactive Behaviors)

面向基于 ID 的推荐，提出用交互行为的语义模式增强 ID 表示。在保留 ID 推荐高效性的前提下，挖掘用户交互行为中的语义模式注入 ID embedding，以缓解纯 ID 表示缺乏语义、对长尾与冷启动不友好的问题。

INSIGHT在纯 ID 高效但无语义与 Semantic ID/生成式重但强语义之间取折中：把交互行为的语义模式注入传统 ID 表示。对线上仍以 ID 体系为主、又想引入语义信号的搜索推荐系统，是一种渐进式、低改造成本的增强思路。

Wang Yuanlai, Bai Yu, Lian Peng
