Make It Long, Keep It Fast: End-to-End 10k-Sequence Modeling at Billion Scale on Douyin Recommendation

本文提出一套生产级长序列建模方案，将抖音推荐系统的用户历史序列扩展到 10k 长度同时维持线上延迟与成本预算。核心包含三项创新：Stacked Target-to-History Cross Attention (STCA) 用目标对历史的堆叠交叉注意力替代历史自注意力，将复杂度从二次降到线性；Request Level Batching (RLB) 在同一用户/请求内聚合多个目标共享 user 侧编码，大幅降低序列相关的存储、通信与计算；长度外推训练策略 (短窗训练、长窗推理) 使模型泛化到生产长度。系统已在抖音亿级 DAU 推荐场景全量上线，离线 AUC 与在线核心指标均有显著提升。

LEAPS: An LLM-Empowered Adaptive Plugin in Taobao AI Search

AlibabaTaobao📖 深度解读 · 10 分钟 →

针对 LLM 时代用户搜索从关键词转向自然语言多约束查询的趋势，本文提出 LEAPS——在淘宝 AI 搜索现有架构两端附加 LLM 插件，采用 'Broaden-and-Refine' 范式。上游 Query Expander 通过逆向数据增强、后验知识 SFT、多样性感知 RL 三阶段训练，对原始 query 生成自适应互补的查询组合最大化候选集；下游 Relevance Verifier 综合多源信号过滤噪声召回。LEAPS 已在淘宝 AI 搜索线上部署，相比基线显著缓解了精确 NL query 零结果与简化 query 噪声多两种极端。

INSIGHTLEAPS 的 Broaden-and-Refine 思路对 UGC 社区搜索极具参考价值：与其重写搜索主链路，不如在两端各挂 LLM 插件——上游做 query 多样化扩展提高召回覆盖、下游做语义级精排过滤兜底相关性。三阶段训练策略 (逆向数据增强→后验 SFT→多样性 RL) 给出了一条可落地的 LLM query 扩展模型训练范式，避免了直接 zero-shot 调用 LLM 的高成本与不稳定。Relevance Verifier 也提示我们：将 LLM 作为下游过滤器比作为主排序器更易工程化。

Lei Wang, Jinhang Wu, Zhibin Wang, Biye Li

Conditional Memory Enhanced Item Representation for Generative Recommendation

City University of Hong Kong

生成式推荐 (GR) 通过自回归生成 Semantic ID (SID) 预测目标 item。现有 item 级表征要么直接合并 SID-token embedding 致信息损失加剧，要么靠外部网络注入语义但破坏 SID 结构证据。本文提出 Conditional Memory Enhanced Item Representation：构造一个条件记忆库，根据 SID 上下文动态检索并融合记忆向量，既保留 SID 结构性，也补充外部语义信息。多个公开 benchmark 上 Recall@K、NDCG@K 较强基线 (TIGER 等) 均有稳定提升，量化 ID 冲突率下降。

INSIGHT生成式推荐里 SID 是双刃剑：结构性带来生成可行性，但量化损失与 ID collision 直接打掉表征上限。'条件记忆' 思路本质是把 item 表征拆成 SID 骨架 + 上下文检索补丁，既给生成器明确的 token 路径，又能在 token 共享场景动态补全语义。对于做生成式推荐/检索的团队，这套范式可以直接套到现有 TIGER/HSTU 体系——不改 SID 编码器，只在 decoder 端的 item embedding 注入一个轻量 memory 检索头，是低风险高 ROI 的方向。

Ziwei Liu, Yejing Wang, Shengyu Zhou, Xinhang Li, Xiangyu Zhao

A Cascaded Generative Approach for e-Commerce Recommendations

Walmart

电商个性化货架传统上由静态主题、召回、点级排序组件拼装而成，限制了页面语义连贯性与动态个性化。本文提出 Cascaded Merchandising 框架，将货架构建分解为两个生成任务：(i) placement-level theme generation 生成模块主题，(ii) per-placement constrained keyword generation 驱动商品召回。通过 teacher-student 微调，使开源小模型在生产延迟/成本约束下逼近闭源大模型表现，离线 A/B 显示主题相关性、CTR 等指标均显著优于传统流水线。

INSIGHT本文用 '生成式调度' 替代静态规则的思路对社区/电商内容化场景有强启示：复杂排序问题不一定要在排序层解，把主题/坑位/召回 query 都看作可生成的中间产物，让 LLM 在更高层做 page-level 规划，下游召回器只负责执行。Teacher-student 蒸馏路径解决了工业落地的成本痛点——闭源大模型蒸到开源小模型基本不掉点。该框架对 UGC 社区的多坑位混排、模块化推荐 (问答/帖子/视频混合) 都可借鉴。

Moein Hasani, Hamidreza Shahidi, Trace Levinson, Yuan Zhong, Guanghua Shu, Vinesh Gudla 等 7 人

TwiSTAR: Think Fast, Think Slow, Then Act — Generative Recommendation with Adaptive Reasoning

基于 Semantic ID 的生成式推荐当前要么对所有用户都用 fast 直接生成 (准确率不足) 要么都用 slow CoT 推理 (延迟成本高)。TwiSTAR 提出 'Think Fast, Think Slow, Then Act' 框架：LLM 配备三个工具——快速 SID 召回器、轻量候选 ranker、显式生成 rationale 的 slow reasoning 模型，由 planner 根据用户序列难度自适应分配推理力度。同时把 item-to-item 协同知识转写成自然语言注入 slow 模型作为协同常识。在公开 benchmark 上 NDCG@10 较纯 fast/纯 slow 基线均提升，平均推理成本仅为纯 slow 的约 40%。

INSIGHT工业推荐落地 LLM 推理最大的两个矛盾是准确率与延迟，TwiSTAR 给出了一个工程性极强的折衷：用 planner 把简单/难样本分桶，让大部分流量走 fast 路径，难样本才升级到 slow CoT。这套思路完全可以套到 RAG/LLM 排序/agentic search 等场景，是 production LLM serving 通用范式。另外把协同信号转成自然语言喂 slow 模型作为 commonsense 的做法值得借鉴——比纯 prompt user-item ID 更易让 LLM 利用其先验知识。

Shiteng Cao, Kaian Jiang, Yunlong Gong, Zhiheng Li

RecRM-Bench: Benchmarking Multidimensional Reward Modeling for Agentic Recommender Systems

Meituan

当前 agentic 推荐系统 (LLM agent 做推荐) 大量依赖单维度终态奖励 (用户最终交互)，忽视了指令遵循、复杂意图理解等中间能力。本文提出 RecRM-Bench：迄今规模最大的 agentic 推荐 RM 基准，覆盖 100 万+ 条目，四大评估维度——指令遵循、事实性、用户意图理解、推荐质量，并提供细粒度子任务划分。作者基于该 benchmark 全面对比了多种开源/闭源 LLM-as-judge 与训练好的 RM 模型，揭示主流 LLM 在多步意图分解与显式偏好捕捉上的明显短板。

INSIGHT对要把 LLM agent 落到推荐/搜索上的团队，这套多维 reward 设计直接对应工业关注的几条主线：是否听话执行业务规则、是否事实正确、是否真正理解意图、最终推荐质量。从单维度 click reward 升级到多维 RM，是 agentic RL 训练范式的必经一步。这套 benchmark 也可以作为内部 LLM 评估的 reference，避免只看离线 NDCG 而忽视 instruction-following 等关键工业能力。Meituan 的工业背景说明该问题在国内搜推团队已是真实痛点。

Wenwen Zeng, Jinhui Zhang, Hao Chen, Zhaoyu Hu, Yongqi Liang, Jiajun Chai, Dengcan Liu, Zhenfeng Liu 等 13 人

HSUGA: LLM-Enhanced Recommendation with Hierarchical Semantic Understanding and Group-Aware Alignment

FFiTTencent

LLM 增强的序列推荐存在两个痛点：长序列直接喂 LLM 难以可靠抽取偏好；对所有用户用同一套 embedding 利用策略忽视活跃度差异。HSUGA 引入两个轻量插件：HSU (Hierarchical Semantic Understanding) 把长序列分段两阶段挖掘偏好，先局部偏好再聚合全局偏好；GAA (Group-Aware Alignment) 按用户活跃度分群，对不同群组采用差异化的 LLM 语义 embedding 利用策略。在 Amazon、ML-1M 等公开数据集上 NDCG/HR 相比 LLM4Rec 强基线稳定提升，对低活用户提升尤为明显。

INSIGHT工业场景里用户活跃度差异极大 (社区/电商都是)，HSUGA 提示我们 'embedding 一刀切利用' 是典型次优做法。Group-Aware Alignment 思路可以直接拷贝到现有 LLM-as-encoder 体系——按活跃度分桶并训练不同的 adapter 是低成本高收益。HSU 的分段递归式偏好挖掘对长序列场景也比直接拼接喂 LLM 更稳：先短段抽取再聚合，与 RAG 'map-reduce' 思路一脉相承，对 token 限制紧的小模型尤为友好。

Guorui Li, Dugang Liu, Lei Li, Xing Tang, Zhong Ming

FedMM: Federated Collaborative Signal Quantization for Multi-Market CTR Prediction

FFiTTencent

跨国/跨市场推荐 (MMR) 通常用预训练+微调，忽略市场间隐私；联邦学习虽保隐私但 ID 空间在市场间不共享，传统 embedding 聚合失效。FedMM 提出基于离散 codebook 的联邦协同信号量化方法：每个市场把本地交互信号量化为共享 codebook 的离散 token 进行隐私安全聚合，不直接传 ID embedding。在多个 CTR benchmark 上 FedMM 在保护隐私前提下接近中心化训练性能，相比传统 FedAvg 在异质市场上 AUC 显著提升。

INSIGHTCodebook 量化的本质是给跨域/跨场景特征建立一个共享的 'discrete vocabulary'，这个思路在生成式推荐 (SID)、长尾 ID 处理、多场景多任务推荐里都已被反复验证。FedMM 把它用到联邦多市场是一个干净的 instantiation。对国内做多业态 (外卖/酒旅/到店/即时零售) 互通的搜推团队特别有借鉴价值——不必直接共享原始 user/item ID，只共享 codebook token 既能跨场景迁移又能满足合规。

Jun Zhang, Dugang Liu, Xing Tang, Xiuqiang He, Zhong Ming

Debiasing Message Passing to Mitigate Popularity Bias in GNN-based Collaborative Filtering

University of Illinois Chicago

基于 GNN 的协同过滤 (LightGCN 等) 受流行度偏差影响严重——交互分布偏斜叠加多阶消息传递放大热门 item 影响、抑制长尾。已有重加权/正则/因果/后处理方案在 GNN 设定下效果有限，因为它们没有直接对抗聚合中传播的偏差。本文提出 DPAA：将自适应的 embedding 感知交互加权直接嵌入消息聚合层，根据当前 embedding 估计动态计算去偏权重，避免静态启发式。在 LastFM、Yelp、Gowalla 等数据集上长尾 item Recall 显著提升，head item 性能基本不掉。

INSIGHTGNN 推荐工业系统普遍存在 'embedding 越训越向热门收敛' 的问题，本文给出了一个原生在消息传递阶段做去偏的范式，比离线重采样或重排更彻底。Embedding-aware 动态加权说明：去偏不能只看交互频次，要结合当前模型对 item 的 'familiarity' 自适应调整。对社区/UGC 场景尤其有意义——长尾内容曝光决定生态健康，把去偏从后置规则下沉到模型训练目标是更可持续的方向。

Md Aminul Islam, Ahmed Sayeed Faruk, Sourav Medya, Elena Zheleva

Localization Boosting for Growth Markets: Mitigating Cross-Locale Behavioral Bias in Learning-to-Rank

Adobe

Adobe Express 国际化扩张中遇到 cross-locale 行为偏差：仅用 click 信号训练 LTR 会把美国本地热门模板过曝到非美 locale。本文系统证明 click-only 训练会压制语义本地化特征，单纯加 VLM 相关性标签可改善语义对齐但无法保住本地内容可见度。作者提出多目标 LTR 框架：行为监督 + VLM 派生相关性 + locale-aware boosting，5 个 locale 上同时提升相关性与本地内容稳定曝光。

INSIGHT对要做多市场/多区域分发的产品 (社区跨城、电商跨国、内容跨语种)，这套框架揭示了一条隐蔽风险：单一行为信号 (click) 会自动放大主流市场偏好，造成长尾市场内容能见度恶化、最终拖低用户体验。'行为 + 语义 + locale boosting' 三层目标分解给出了直接可复用的多目标设计——其中 VLM/LLM 派生的标注信号已逐渐成为工业 LTR 标配。对社区搜索而言：地域、品类、新老用户等都是潜在的 'locale'，单一全局训练会自动 over-serve 头部。

Suryaa Veerabathiran Seran, Ashwin Naresh Kumar, Tracy Holloway King, Jing Zheng
