MIRA: An LLM-Assisted Benchmark for Multi-Category Integrated Retrieval

MIRA 针对当前搜索系统在异构数据源（文档/数据集/工具/论文）上的统一检索评测缺失问题，构建了一个基于大型社科搜索平台的多类别集成检索基准。论文用 LLM 辅助生成跨类别的真实意图查询与相关性标注，覆盖多种检索粒度与类别感知排序场景，能够同时评估 BM25、稠密检索器（如 BGE、E5）和 LLM 重排序方法。实验显示，主流稠密检索器在跨类别检索时召回质量明显下滑，而类别感知的重排序可以将 nDCG@10 提升 8–15 个点。

Caraman at SemEval-2026 Task 8: Three-Stage Multi-Turn Retrieval with Query Rewriting, Hybrid Search, and Cross-Encoder Reranking

Babes-Bolyai University

论文针对多轮 RAG 场景下后续问题的上下文依赖问题，提出三段式检索流水线：(1) 用 LoRA 微调的 Qwen2.5-7B 把 follow-up 问题改写为独立 query，(2) BM25 与稠密检索通过 RRF 融合得到混合候选集，(3) 用 BGE-reranker-v2-m3 做 cross-encoder 重排。系统在 SemEval-2026 Task 8 (MTRAGEval) 官方测试集上 nDCG@5 = 0.531，在 38 个参赛系统中排第 8 名，验证了改写+混合+重排在多轮检索任务上的有效组合。

INSIGHT这是工业搜索召排架构的标准组合（rewriter → hybrid retrieve → cross-encoder rerank）首次在多轮场景的公开 benchmark 上被系统化验证。三个值得借鉴的工程点：(a) 用小模型 LoRA 改写而非纯 prompt，把多轮上下文显式压成独立 query，避免稠密向量的长上下文衰减；(b) BM25 与稠密的 RRF 融合在多领域（多 domain）下比单一检索更稳健；(c) BGE-reranker-v2-m3 作为开源 cross-encoder 已经足以在多领域取得高 nDCG，团队不必从零训练 reranker。

David-Maximilian Caraman, Gheorghe Cosmin Silaghi

Much of Geospatial Web Search Is Beyond Traditional GIS

UCL

论文用稠密句向量 + 轻量 SetFit 分类器 + 密度聚类，对全量 MS MARCO（101 万条真实 Bing query）做地理意图识别，发现实际地理类查询占 18.0%，约为原 Bing 标签 (6.17%) 的 3 倍。进一步把这些 query 聚类成包括 routing、property、地点画像、附近 POI 等几十个子意图，发现传统 GIS 系统只能覆盖其中一小部分。论文公开了 query 集和子意图标签。

INSIGHT地理搜索远不止「找 POI/路线」，这一发现对所有 LBS 业务（地图、外卖、本地生活、出行）都是重要校准信号。对工业搜索：可用同样方法（稠密 embedding + SetFit + clustering）在自己业务的 query log 上做意图分布的「再发现」，可能会发现头部 query 比当前 Schema 设计预期的更复杂。SetFit 在低样本下分类效果好，非常适合做「无监督 + 少量标注」的 query intent 体系迭代。

Ilya Ilyankou, Stefano Cavazzi, James Haworth

AgentDisCo: Towards Disentanglement and Collaboration in Open-ended Deep Research Agents

AgentDisCo 把开放式 deep research 任务建模为信息探索（exploration）与利用（exploitation）的对抗优化，拆分为两个 agent：critic agent 评估当前大纲并改写 search query，generator agent 检索新结果并重写报告。两 agent 通过迭代博弈逐步收敛，避免现有方法把探索与利用揉在同一 LLM 调用里的「幻觉与重复检索」问题。在多个 deep research benchmark 上长尾问题正确率显著高于单 agent baseline。

INSIGHT对搜索/Agent 搜索方向，最大启示是 query 改写应当 driven by current evidence gap，而不是凭空 rewrite。把 critic（基于当前大纲找 gap）和 generator（基于 gap 检索+整合）显式解耦，是构建可控、可追溯 deep research 产品的关键架构。这种 critic-generator 闭环也可以迁移到 RAG 中：让 critic 模型读已经检索回来的文档判断「还缺什么」，再触发下一轮 hybrid retrieval。

Jiarui Jin, Zexuan Yan, Shijian Wang, Wenxiang Jiao, Yuan Lu

ClinicalBench: Stress-Testing Assertion-Aware Retrieval for Cross-Admission Clinical QA on MIMIC-IV

论文针对临床 QA 中「否定/时态/患者-家属归因」等断言敏感属性会颠覆正确答案的问题，构建 EpiKG（每个事实带 assertion 标签和 temporality 标签的患者知识图谱），并通过 question intent 路由检索。ClinicalBench 包含 43 例 MIMIC-IV 患者、9 类 assertion 敏感问题共 400 题。7 条件消融实验显示 assertion-aware 检索可将正确率提升 12–25 点，远超纯稠密检索 baseline。

INSIGHT对工业搜索/QA 系统，最大启示是当文档中存在大量否定、时态、归因等「反向语义」时，常规稠密 embedding 会把「未发生」和「发生」映射到相近空间，导致严重错召回。可借鉴 EpiKG 的做法：在索引阶段抽取 assertion 标签（如 NEGATED、HISTORICAL、HYPOTHETICAL）并显式作为过滤维度，比纯 embedding 更可靠。对商品搜索同样有借鉴价值（例如「不含麸质」vs「含麸质」的 query-doc 匹配）。

Alex Stinard

Matching Meaning at Scale: Evaluating Semantic Search for 18th-Century Intellectual History through the Case of Locke

University of Helsinki

论文系统评估了 off-the-shelf 语义搜索（multilingual-e5-large 等）在 18 世纪英文文献中发现 Locke 思想传播 paraphrase 与隐式引用的能力，对比传统词级 text reuse 检测。基于专家标注的 semantic taxonomy，发现语义搜索能覆盖词级方法漏掉的约 45% paraphrase 引用，但在隐式 engagement 上 precision 仅 0.31，召回提升带来明显的噪声。

INSIGHT对工业搜索的现实意义是：稠密语义检索能显著扩召回（尤其是低字面重叠的相关内容），但单独用会引入大量「语义近邻 ≠ 业务相关」噪声。论文展示的实践方法值得借鉴——把任务拆成「严格引用 vs paraphrase vs implicit engagement」分层评测，对应到电商/内容搜索就是「完全匹配 / 同义改写 / 主题相关」三档，分别用不同检索/重排策略。

Yu Wu, Ananth Mahadevan, Filip Ginter, Michael Mathioudakis, Mikko Tolonen

EHR-RAGp: Retrieval-Augmented Prototype-Guided Foundation Model for Electronic Health Records

NNYU Abu Dhabi

EHR-RAGp 提出「原型引导的检索增强」框架解决 EHR 长轨迹、事件异构、时间不规则问题：先离线聚类历史患者轨迹得到 K 个原型轨迹，在线推理时检索与当前患者最相似的 top-k 原型，作为 RAG 上下文喂给 foundation model 做诊断/预后预测。在多任务（死亡率、再入院、长 LoS）上 AUROC 比固定窗口 baseline 提升 2.5–6.8 点，且对稀疏患者收益最大。

INSIGHT原型检索（prototype retrieval）这一思路对推荐/搜索冷启动有直接借鉴：先离线把用户/商品聚类成「行为原型」，在线遇到稀疏新对象时检索原型作为 context 填充。相比纯 embedding 检索，原型可解释、可控、对噪声鲁棒。EHR 这种「长序列检索+生成」的模式正在跨域扩散，对长用户行为序列建模的搜推团队值得跟踪。

Saeed Shurrab, Mariam Al-Omari, Dana El Samad, Farah E. Shamout

MedHopQA: A Disease-Centered Multi-Hop Reasoning Benchmark and Evaluation Framework for LLM-Based Biomedical Question Answering

NIH

针对现有生物医学 QA benchmark 在选择题猜答案、训练数据污染等问题上能力区分度下降，MedHopQA 提出疾病为中心的多跳推理数据集，把答案隐式分布在多篇文献中，强制模型同时做检索与多跳推理。开放式生成评估而非多选；GPT-4 类大模型 EM 仅 28%，专门微调的检索增强模型可提升到 41%，远未饱和。

INSIGHT多跳检索任务正成为评估 RAG/搜索 agent 的关键 lens：单跳检索-阅读已被现代稠密 + reranker 解决到饱和，区分模型能力的瓶颈在「如何把信息拆成多步、每步检索不同侧」。对搜索 Agent 团队：可以把多跳推理 query log 单独拉出来做指标，并尝试 ReAct / Plan-Solve 类的迭代检索策略。

Rezarta Islamaj, Robert Leaman, Joey Chan, Nicholas Wan, Qiao Jin, et al.

Context Convergence Improves Answering Inferential Questions

University of Innsbruck

论文研究开放域 QA 中需要「推理出答案」而非「直接检索答案」的推断型问题，提出 convergence 度量：衡量一组 hint 句子有效排除错误选项的程度。基于该度量重排序检索段落后，作为 LLM 的 context 喂入。实验显示在 inferential QA 子集上 EM 比相似度排序提升 4.7–7.2 点，且对小模型增益更大。

INSIGHT现有 reranker 优化的目标都是「句-query 相似度」，但对推断型 query 真正有用的是「能否帮助排除错误候选答案」——这是一个全新的 reranking 目标。对搜索/推荐 reranker 团队值得思考：除相关性外，是否可以引入「信息互补性」或「区分度」作为重排维度，让 top-k 文档对 query 形成「证据互补」而非「重复相关」。

Jamshid Mozafari, Bhawna Piryani, Adam Jatowt

Transform Video Into Instantly Searchable, Actionable Intelligence with AI Agents and Skills

NVIDIA

NVIDIA 介绍如何用 AI agents + Skills 构建从视频流到结构化、可搜索情报的端到端流水线：底层用 VLM 抽取分段级语义描述并存入向量库，上层用专门化 Skill agent（事件检测、摘要、问答）按需调用，支持开放词表的视频检索查询。工程上结合 NVIDIA Cosmos NeMo Retriever 与 VSS（Video Search and Summarization）blueprint，给出从摄入到查询的部署模板。

INSIGHT对内容/视频搜索团队，视频检索正从「标签+元数据匹配」全面转向「VLM 抽取 → 向量索引 → agent 调用」的开放语义路径。落地启示：(1) 视频要在分段（shot/scene）粒度而非整段做向量化，否则 query 命中精度差；(2) 单纯向量检索不够，需要 agentic 编排（先粗检 → 再精读 → 再总结）；(3) NVIDIA 提供的 NeMo Retriever blueprint 是国产团队搭建自己的视频 RAG 时一个可对标的参考架构。
