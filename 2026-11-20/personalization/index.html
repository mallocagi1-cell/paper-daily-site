X-split Argus: Learning Reusable History Tokens for Efficient CTR Prediction

工业广告点击率预测既要抓住用户的长期偏好，也要跟上近期意图，但每次给候选打分都把完整行为历史重算一遍，算力和延迟都很难扛。一套广告排序框架把历史压缩器和在线排序器一起训练：离线把过往行为压成一套可复用的历史 token，在线排序只用交叉注意力读取这些 token 和近期事件，候选之间不必重复扫描长历史。离线评估里，相对线上原模型，归一化熵相对下降 0.81%。部署到大规模实时竞价系统后，为期七天的 A/B 试验中，反映广告主转化金额的指标相对提高 4.65%，点击量相对提高 2.96%；服务同等流量大约要多用 15% 的同型号在线 GPU。把长历史压成可复用的离线表征，排序才能在预算内做厚。

MARS Technical Report

工业推荐通常是检索、粗排、精排和重排的级联，但通道要不要开、名额怎么分、用哪套模型、分数如何融合，往往仍是工程师按场景统一调好、对所有用户一视同仁的。一套近线智能体把个性化从单阶段打分扩到整条链路的编排：它为每个用户生成一份七维配置，校验后写入缓存，在线级联异步读取，不必等待大模型当场推理。在淘宝五类营销场景、覆盖逾千万日活用户的为期两周 A/B 试验里，各场景关键指标的点估计均为正，其中访客购买率最大相对提高 5.22%，成交总额最大相对提高 7.34%；评测部署的在线服务路径平均延迟还比原系统低 12 毫秒。级联怎么走，也可以按用户来编，而不必让在线请求去等大模型。

MLE Agents: Autonomous ML Engineering in Large-scale Recommendation Systems

要改进大规模搜索排序或推荐模型，工程师通常得自己提假设、改代码、训练再评估，周期长，也容易只在熟悉的方向里打转。一套人在回路上的机器学习工程师智能体，可以在工业级搜索排序器上提出改动、写成代码、启动训练并阅读离线评估，再决定是否留下；人仍把住目标设计、搜索方向和最终模型审查。一次战役完成了 1097 次候选实验，接受率为 29.6%，高于目标函数和搜索约束都不同的此前战役的 15.6%。其中最好的模型在大规模 A/B 试验里把搜索量提高了 0.23%，有些架构改动是团队此前从未在这条链路上试过的。在工业改模里，环路怎么设计，往往和底座模型一样关键。

Matthew Li, Albert Liang, Dilip Raj

Variance-Optimal Counterfactual Policy Design for Sample-Efficient Online A/B Testing

上线新的推荐或排序策略前通常要做 A/B 试验，一旦新策略和线上策略经常选出同一动作，这些重合样本对估计效果差异帮助很小，却会把方差抬高，试验就得耗掉大量流量。现有降方差方法多半是在收集方案定死后再改估计器，或只优化两组之间的流量切分，无法把样本送到两种策略意见不一致的动作上。这里把动作如何抽样、观测如何用来估计处理效应放在一起优化，并利用历史日志为估计配置对照变量。在模拟的策略 A/B 中，基于模型对照的设计只需平衡试验 39% 到 51% 的评估流量，就能达到相同均方误差。在一万次评估互动时，统计功效还能提高到平衡试验的 1.5 到 2.1 倍。策略试验要把样本用在两种策略真正分叉的地方。

Shashank Gupta, Subhadeep Maji

PGPO: Prototype-Guided Progressive Obfuscation for Privacy-Preserving LLM-Enhanced Recommendation

大模型增强的推荐会把物品的文本侧信息编进语义向量，却可能被反演攻击还原出敏感属性。现有输入侧防护要么依赖可信采集，要么在本地扰动 token，常常把物品之间的相对关系也搅乱了，推荐效用跟着掉。这里把目标改成关系保真：语义要偏移到难以还原，但物品之间的相对关系还得留下来。方法先为高影响的原型词学习感知拓扑的混淆锚点，再沿静态语义图传播，并用差异、结构一致和语义约束来优化。在两个基准上，各类混淆方法都能把反演攻击成功率相对原始描述降低一半以上；对传统协同过滤模型，相对原文上限，推荐指标下降通常不到 2%，下游效果也好于只扰动 token 的做法。保隐私不一定非得以拆掉物品关系为代价。

Shengxiang Lin, Jiajie Su, Pengyang Zhou, Xiang Chen, Xiaolin Zheng, Feng Tian, Chaochao Chen

AgentTailor: Dual-Gate LLM-Assisted Re-ranking for Personalized Long-Tail Recommendation

推荐系统很容易出现头部物品占满曝光、大量长尾物品几乎没机会被看见的情况。现有长尾方法常常靠全局重新加权，或把排序过程做成不透明的模型，既难按个人去提高长尾曝光，又容易伤到整体推荐效果。一套模块化的大模型辅助框架把这件事拆成两段：先用语义召回取出语义上相近的候选池，让相关的长尾物品有机会进入后续排序；再由一条按需启用的长尾专支路，依据证据做重排。这条支路用双门控来调节长尾压力：激活门决定要不要调用大模型去做基于证据的评估，放置门再决定提炼出的证据是否允许进入最终排序。长尾曝光要先保证被召回来，再决定要不要为此调用大模型。

Jinpeng Chen, Zhenye Yang, Huan Li, Kaimin Wei, Senzhang Wang, Hongbo Gao

DyNA-Mixer: Decoupling Time and Topology for Scalable Dynamic Node Affinity Prediction

连续时间动态图保留了互动的先后、时刻和强度，对推荐和交易网络重要，但研究长期停在只预测未来会不会连上，许多应用还要预报互动有多强，并在全部候选上排序。动态节点亲和预测把任务扩成连续目标和全候选排序，既要刻画多尺度时间演变和全图协同，又不能对每个节点对都做昂贵预报。一套方法把时间预报和协同结构建模拆开，用多尺度时间预报刻画成对亲和变化，再用虚拟协同图在查询时刻聚合相关互动，并只对近期仍有非零亲和的节点对做昂贵计算。在四个时序图基准上，NDCG@10 都达到当时最好，最大基准相对最强基线，测试集相对提高 17.8%。强度预测可以做全候选排序，也不必对所有节点对付同样的计算。

Yuanxing Zheng, Liping Wang, Xuemin Lin
