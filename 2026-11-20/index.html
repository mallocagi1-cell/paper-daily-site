Optimize the Cob, Then the Kernel: Optimizing Beam Search for Generative Recommendation Inference

生成式推荐的推理和普通大模型服务很不一样：输入很长，beam 很宽，输出却只有固定的几个 token。现有引擎常把每条 beam 当成互不相关的序列来批处理，共享前缀的 KV 会被重复读取；每一步生成还要单独调用一次引擎，主机制梁处理和运行时的缓存块管理都堆在步骤之间。这里用 Tree Attention 把各条 beam 沿序列维拼在一起，去掉重复的 KV 访问，再配上预先生成的部分注意力掩码、静态 KV 分配、图编译、算子融合和词表约束解码。不用自定义算子，在昇腾 NPU 上相对 vLLM，端到端最多可加速约 25 倍，生成延迟也能接近使用自定义算子的现有方案。先把整条生成流水线做对，再考虑要不要自写算子。

CONCORD-Rec: Catalog-Conditioned Modality Utility for Semantic-ID Diffusion Recommendation

用离散 Semantic ID 做多模态生成式推荐时，历史里的影像或文本并不总是在减少目录中的歧义，有的只是改了 token 的预测；模态一旦缺失、劣化或相互冲突，均匀融合还可能把误导信息带进逐步去噪。一套方法用反事实的目录划分效用来监督模态门控：在相同的可行目录和部分遮蔽的 Semantic ID 上，比较有无某一模态时目标分组的损失，再按位置、按可用性分配有界的模态修正，并保留纯行为预测作为回退。在 MicroLens-100K 上，干净条件下 NDCG@20 相对均匀融合提高 4.00%，在 30% 的模态缺失时相对提高 7.95%，说明内容不完整时，按位置分配模态仍然有用。模态有没有用，要看它能不能缩小当前目录里的候选范围。

Improving LLM-Based Recommenders with Conservative Generative Flow Networks

生成流网络近来被用来提高大模型推荐的多样性、减轻流行度偏差，但多数目标仍是按在线式假设来写的。离线推荐只能在一份固定日志里学习，token 转移只覆盖这份数据所能支持的前缀，若把子轨迹平衡目标原样搬过来，问题会变得不可辨识，还可能把概率质量分到数据并不支持的区域。文章把这种失效形式化，并指出三类会让学到的策略偏离数据隐含策略的来源：流被高估、前向质量泄漏，以及后向补偿。对应的保守目标会显式惩罚不被支持的前向流，并在数据集约束下做策略学习。离线推荐不能把为在线设定写的流网络目标原样搬过来。

Xuan Yu, Feng Niu, Rui Zhu, Yudong Zhang, Xu Wang, Yang Wang

Mitigating Reward Hacking in LLM-based Recommendation: A Preference Optimization Approach

给大模型推荐做后期适配时，DPO 这类偏好优化能加强成对偏好的区分，却容易出现奖励被钻空子的情况：模型抓住奖励信号里的缺陷，训练指标看起来涨了，推荐效果却没有真正变好。从梯度角度看，成对更新对正样本和未采样负样本之间的排序几乎不起作用，会形成一块不敏感区域。在 Bradley-Terry 模型下，这类区域可以占掉偏好空间的相当一部分，不可避免地让排序走偏，因为模型没有真正学会把正样本从那些从未成对出现过的负样本里分开。方法为此引入伪负样本，用模拟出的偏好优化去压这类钻空子的行为，让更新也能触及原先几乎不受影响的排序。只盯成对偏好，还不够约束对未采样物品的排序。

Heyu Chen, Junkang Wu, Guoqing Hu, Kexin Huang, Xiang Wang, Jiancan Wu

Token-Efficient Long-Term Interest Sketching and Internalized Reasoning for LLM-based Recommendation

用大模型给推荐做偏好推理时，会碰上两件很实际的事。用户历史往往又长又吵，动辄上百条，截断会丢掉刻画长期兴趣所需的信号；而在只解码的结构里，思维链还要逐步生成推理 token，推理延迟很难真正上线。一套框架同时处理这两头：先不把原始历史整段喂进去，而是把物品描述编码并聚类，做成长度受限的兴趣速写，用来保留稳定偏好、压掉噪声，让模型在有限的 token 预算里仍能看到长期兴趣；同时把推理内化进模型，而不必每次都把理由 token 逐个写出来。这样，推荐推理既不必吞下整段嘈杂历史，也不必为每一次打分付出逐步生成长篇理由的代价。长期兴趣要先被压短，推理也不必每次都写在字面上。

Zhihao Ding, Jinming Li, Shuai Mu, Jieming Shi

06 3.70

Self-EvolveRec: Self-Evolving Recommender Systems with LLM-based Directional Feedback

想自动设计推荐模型时，神经网络结构搜索往往被人手划定的算子空间框住，创新只能发生在预先定义好的算子里。近年用大模型在开放代码空间里演化，又主要盯着 NDCG 或命中率这类标量，模型错在哪里、下一步该往哪改，反馈是没有方向的。一套框架补上方向性反馈：用用户模拟器给出定性批评，再用诊断工具做定量的内部检查，并让诊断标准随着推荐结构一起演化，避免评估尺子本身停在旧结构上。在 CDs 数据集上从 SASRec 出发，NDCG@5 从 0.3559 提高到 0.3865，也高于同一起点上的 DeepEvolve（0.3610）。自动改推荐模型，需要能指出问题在哪、该往哪改的反馈，而不只是一个分数。

Steering Diffusion Models Towards Credible Content Recommendation

扩散模型因为善于刻画物品内容和用户行为的复杂分布，已经被用进推荐系统，推荐效果往往也不错。可现有方法常常只追推荐准不准，并不去管推荐内容是否可信，于是可能生成假新闻、不实信息这类不可信内容，对社会带来的伤害并不小。一套方法想把扩散模型推向更可信的内容推荐：它把扩散目标改写成，鼓励按与偏好相关的信号来生成，同时抑制按不可信内容作为条件的生成，并设计解耦的扩散过程，以减轻不可信内容对生成过程的影响，同时尽量保住推荐准确性。内容推荐不能只看准不准，还要看生成出来的东西是否可信。

RxDiff: Discrete Diffusion for Medication Recommendation with Inference-Time Safety Control

用药推荐要给出疗效好、药物相互作用又少的组合，难处正在于处方是组合出来的：药与药之间会互相影响，不能当成互不相关的标签来逐个打。判别方法常常把每种药单独预测，忽略这些依赖；自回归方法虽然引入了顺序依赖，却强加了任意的生成次序，还会把错误累积下去。两类做法都主要在训练时用惩罚来压相互作用，对单张处方在推理时的调控能力有限。文章把用药推荐写成离散扩散：迭代去噪可以双向修改已有选择，并在每一步加入推理时对相互作用的感知调节，让安全约束不必只留在训练损失里。药物组合的安全约束，应该能在推理过程里被实时管住。

Jinke Feng, Wenjie Du, Xuchang Zhong, Yang Wang

SMI: Ontology-Grounded Semantic IDs for Hierarchy-Aware Medical Concept Representation

生物医学语言模型在临床任务上表征很强，却常常抓不住医疗概念之间的层级，越稀有、越细的临床编码就越难用，因为忽略层级的向量会随着概念变少而越来越不说明问题。一套无需再训练的方法，把每个诊断、操作或药物概念的 Semantic ID 定义成专家本体里从粗到细的路径，再把冻结的生物医学模型向量按这些层级聚合，让粗粒度语义能够托住细粒度编码。基础做法对各个层级均匀聚合，也可按验证集为不同层级选择权重。在 MIMIC-IV 的药物推荐上，按验证集选择层级权重的变体，AUPRC、F 分数和 Jaccard 分别为 77.6%、65.3% 和 50.5%，显著优于最强基线。把层级写进标识本身，罕见概念才能借到上层的语义。
