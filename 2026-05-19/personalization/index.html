Generative Long-term User Interest Modeling for Click-Through Rate Prediction

针对超长用户行为序列下 CTR 预估的两阶段框架 (GSU 检索 top-k 行为 + ESU 注意力建模) 的两个痛点——以目标 item 为中心的 GSU 会漏掉其它潜在兴趣、且基于 pairwise 相似度的匹配检索随行为增长而耗时，论文提出生成式长期兴趣模型 GenLI。GenLI 由兴趣生成模块 IGM、行为检索模块 BRM、兴趣融合模块 IFM 组成：IGM 生成多个目标无关的兴趣分布、显式编码行为间交互信息以保证兴趣完整多样；BRM 用一次 lookup 选取相关行为，把逐行为加权的时间复杂度降到 O(1)；IFM 用门控机制生成最终兴趣特征。整体在精度与在线服务效率间取得更好平衡。

Fortress: A Case Study in Stabilizing Search Recommendations via Temporal Data Augmentation and Feature Pruning

📖 深度解读 · 6 分钟 →

搜索与推荐的预测模型常因部分输入特征带来分数波动而出现「时间维度不稳定」，在多阶段系统中会因上下游分数不一致而损害可靠性与体验。论文提出通用框架 Fortress，通过定位并裁剪导致分数随时间不一致的特征来提升模型稳定性与精度，遵循四步流程：(1) 采集历史快照、按时间切分数据集以捕获同一实体跨周期的分数波动；(2) 识别预测不稳定的样本；(3) 隔离并移除引发不稳定的特征；(4) 仅用稳定特征重训模型。论文还指出来自 LLM/BERT 的语义特征虽利于泛化但可能引入不稳定，需要纳入该裁剪流程评估。

INSIGHT把「特征稳定性」当成一个可量化、可裁剪的工程目标，而非泛泛追求精度——这对多阶段搜索/推荐链路（召回→粗排→精排）尤其关键，因为上游分数抖动会被下游放大。可直接借鉴的设计是用时间切分的历史快照构造「同实体跨周期分数波动」数据集来定位不稳定特征，并对引入语义噪声的 LLM/BERT 特征保持警惕：泛化收益与线上稳定性需要联合权衡。

LLM-EDT: Large Language Model Enhanced Cross-domain Sequential Recommendation with Dual-phase Training

跨域序列推荐 (CDSR) 面临两大问题：不平衡问题（某一域交互主导整条行为序列，难以学到弱域的域特异特征）与迁移问题（混合序列中难以刻画用户跨域偏好，导致特定域 next-item 预测差）。论文提出 LLM-EDT：用「可迁移 item 增强器」自适应生成用户可能的跨域行为以缓解不平衡、同时控制无关噪声；用「双阶段训练」让域特异线程获得域共享背景以缓解迁移问题；用「域感知画像模块」对各域偏好做摘要并自适应聚合成完整用户画像以解决粗粒度画像问题。在三个公开数据集上验证有效性。

INSIGHT把 LLM 同时当作「跨域行为生成器」和「域感知画像器」，并用双阶段训练显式解耦域共享与域特异表征，给社区多场景（搜索/推荐/问答）共用用户表征提供了思路：与其在混合序列里隐式学跨场景偏好，不如让 LLM 显式做带噪声控制的行为补全 + 分场景画像摘要再聚合。其「先补域间行为、再分域画像、最后聚合」的三步设计可迁移到多频道 UGC 个性化。

Ziwei Liu, Qidong Liu, Wanyu Wang, Yejing Wang, Pengyue Jia, Tong Xu, Wei Huang, Chong Chen 等 9 人

Agent4POI: Agentic Context-Conditioned Affordance Reasoning for Multimodal Point-of-Interest Recommendation

现有多模态 POI 推荐把每个 POI 编码为与上下文无关的静态 embedding，无法解释「同一家咖啡馆为何周一适合独自办公、周五晚上适合聚会庆祝」。论文首先形式化证明：在标准双线性打分下，任何预计算编码器都无法满足上下文敏感的排序，从而论证必须在推理时生成 item 侧表征。Agent4POI 反转计算顺序：给定情境上下文，四阶段 LLM agent 先生成上下文相关的 affordance 查询 (Phase 1)，再对图像/评论/元数据证据执行五步跨模态思维链 (Phase 2)，产出带不确定性、植根于 Gibson affordance 理论的上下文相关表征用于排序。

INSIGHT「静态 item embedding 在双线性打分下无法做上下文敏感排序」的不可能性证明，是对推荐系统双塔/向量检索范式的一次理论敲打：当排序强依赖情境（时间、场合、同行人）时，item 表征必须随上下文在推理时动态生成，而非离线固化。对社区内容推荐的启示是——高价值场景可考虑推理时 item 侧重表征；但四阶段 agent + 五步 CoT 的在线开销极高，落地需做表征缓存/蒸馏，短期更适合离线重排或长尾场景。

Jinze Wang, Yangchen Zeng, Tiehua Zhang, Lu Zhang, Yuze Liu, Yongchao Liu, Xingjun Ma, Zhu Sun

Logging Policy Design for Off-Policy Evaluation

离线策略评估 (OPE) 用某个 logging policy 收集的数据来估计目标策略（如推荐系统）的价值，使高风险实验无需上线即可进行，但估计精度高度依赖 logging policy 的设计。论文研究「如何设计 logging policy 使给定目标策略的 OPE 误差最小」，刻画了一个根本的 reward-coverage 权衡：把概率质量集中在高回报动作上能降方差，但会漏掉目标策略可能采取动作的信号。论文给出统一的 logging policy 设计框架，并在目标策略与回报分布 (i) 已知、(ii) 未知、(iii) 通过先验/带噪估计部分已知 三种典型信息状态下推导最优 logging policy。

INSIGHT把「探索日志怎么打」从经验直觉提升为可优化问题：reward-coverage 权衡说明纯按线上模型分数采样的日志会系统性低估那些当前模型很少曝光、但新模型会偏好的动作——这正是推荐/搜索离线评估常年偏乐观的根因之一。可借鉴的是按「目标策略信息已知程度」分档设计采样策略：信息越少越应向覆盖倾斜，为后续模型迭代保留可评估的信号。

Connor Douglas, Joel Persson, Foster Provost

On the Factual Consistency of Text-based Explainable Recommendation Models

基于文本的可解释推荐用自然语言解释来佐证推荐项以提升用户信任与系统透明度，但「这些 LLM 生成的解释是否与可用证据事实一致」长期未被充分研究。论文提出一套评估文本可解释推荐事实一致性的完整框架：用基于 prompt 的流水线让 LLM 从评论中抽取原子级解释性陈述，构造聚焦事实内容的 ground truth；在 Amazon Reviews 数据集的五个品类上构建增强基准做细粒度评估；并提出结合 LLM 与 NLI 的陈述级对齐指标，同时衡量事实一致性与解释质量。

INSIGHT可解释推荐的「流畅 ≠ 事实正确」是 LLM 生成解释落地的核心风险——论文把评估从整体打分细化到「原子陈述级 + LLM/NLI 双重对齐」，提供了可复用的评测方法学。对社区场景（如给 UGC 推荐/搜索结果附 LLM 理由）的直接启示是：上线 LLM 解释前必须建陈述级事实一致性基准，否则会以「看起来可信」的幻觉解释损害用户信任。

Ben Kabongo, Vincent Guigue
