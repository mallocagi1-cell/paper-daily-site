Argus: Evidence Assembly for Scalable Deep Research Agents

针对 deep research agent 并行 rollout 重复采集证据、聚合上下文撑爆模型窗口的问题，提出 Argus：Searcher 以 ReAct 方式为子查询收集证据轨迹，Navigator 维护共享证据图（evidence graph），校验缺失片段、调度 Searcher 补全，并在完整图上推理生成可溯源答案。Navigator 用强化学习训练 verify/dispatch/synthesize，Searcher 保持标准 ReAct 独立训练。基于 35B-A3B MoE，单 Searcher 在 8 个 benchmark 平均 +5.5 分，8 路并行 +12.7 分，64 路并行在 BrowseComp 达 86.2，超过所有对比的闭源 agent，且 Navigator 推理上下文稳定在 21.5K token 以内。

Process Rewards with Learned Reliability

现有过程奖励模型（PRM）每步只输出一个分数，下游只能把不完美的步级预测当作可靠信号。BetaPRM 是一个分布式 PRM，同时预测步级成功概率与该预测的可靠性：基于 Monte Carlo 续采的步级成功监督，用 Beta-Binomial 似然学习 Beta 信念，而非回归到有限样本成功率的点目标。基于此可靠性信号提出 Adaptive Computation Allocation（ACA）：在高奖励解可靠时停止、对不确定前缀追加算力。在 4 个 backbone × 4 个推理 benchmark 上提升 PRM 引导的 Best-of-N，ACA 相比固定预算 Best-of-16 在提升答案准确率的同时最多省 33.57% token。

INSIGHTPRM 输出'分数+可信度'比单点分数更有用——可信度让下游区分'该信的奖励'和'不确定的奖励'，从而按需分配算力。这对 agentic 搜索/RL 的奖励设计有直接借鉴：步级奖励本身带噪，显式建模奖励不确定性可避免在错误中间步上浪费搜索预算。社区搜索若用 LLM 重排+Best-of-N，可用类似可靠性门控做自适应早停，省成本。

Jinyuan Li, Langlin Huang, Chengsong Huang, Shaoyang Xu, Donghong Cai, Yuyi Yang, Wenxuan Zhang 等 8 人

Response-Conditioned Parallel-to-Sequential Orchestration for Multi-Agent Systems

多智能体协作通常要么纯并行（独立作答再聚合）、要么纯串行（按拓扑逐步精炼），两者都难以在'最小化通信与延迟'和'最大化最终准确率'间兼得。Nexa 提出 response-conditioned 可训练策略：先并行执行，将各 agent 响应嵌入共享语义空间，再预测一个稀疏有向无环通信图——图为空则保持纯并行，非空则执行一次串行消息传播。策略是轻量 transformer，无需外部 LLM 裁判或奖励模型，也不需手工搜索测试时拓扑；论文证明所得图构造上无环、严格包含纯并行，并给出基于策略梯度的训练方法，学到的通信策略在 agent 数量/任务/底座变化时可复用。

INSIGHT多 agent 编排不必在并行与串行间二选一：用一个'看了并行结果再决定要不要串行通信'的轻量策略，按 query 难度动态决定是否追加一轮串行精炼。对 agentic 搜索系统的启示：检索/推理子 agent 的通信拓扑可学习且与底座解耦，避免对每个新任务手调 pipeline；轻量策略不依赖额外 LLM 裁判，推理开销可控。

Nurbek Tastan, Alex Iacob, Lorenzo Sani, Meghdad Kurmanji, Nicholas D. Lane, Samuel Horvath 等 7 人

DeepSlide: From Artifacts to Presentation Delivery

现有 AI 幻灯片生成只优化'产物'（视觉合理的 deck），却忽视'交付过程'（节奏、叙事、演讲准备）。DeepSlide 是一个 human-in-the-loop 多智能体系统，覆盖需求澄清、带时间预算的叙事规划、证据 grounding 的 slide-script 生成、注意力增强与排练支持，集成四个组件：带每节点时间预算的可控逻辑链规划器、轻量内容树检索器（grounding）、带样式继承的 Markov 式顺序渲染、最小修复的沙箱执行保证可渲染。提出 dual-scoreboard benchmark 把静态产物质量与动态交付质量分开评估，在 20 个领域上产物质量持平强基线、交付指标（叙事流畅度、节奏精度、slide-script 协同）显著更优。

INSIGHT把'内容树检索器做 grounding + 带时间预算的逻辑链规划器 + 沙箱执行最小修复'组合成可落地的多 agent 流水线，是值得借鉴的工程范式：检索器负责事实接地、规划器负责结构与预算约束、沙箱保证产物可用。对搜索/推荐内容生成的启示：把'可控规划'与'检索 grounding'解耦，并用沙箱+最小修复保证线上可渲染/可用，是降低 LLM 生成不可控性的实用手段。

Ming Yang, Zhiwei Zhang, Jiahang Li, Haoseng Liu, Yuzheng Cai, Weiguo Zheng

Calibrating LLMs with Semantic-level Reward

标准 RLVR 用二元正确性奖励训练，对置信度无感知——对'自信但错误'的预测不施加惩罚，从而损害校准。近期工作让模型输出 verbalized confidence 并奖励其与正确性一致，但 verbalized confidence 在 token 级校准，对语义相同但表述不同的变体不一致。本文提出语义级奖励：在语义层面而非 token 层面建模与奖励置信度一致性，使模型在医疗问答、法律推理等高风险场景下产出更校准的不确定性估计，缓解'自信错答'问题。

INSIGHT奖励应作用在语义层而非 token 层——同义改写不应导致置信度漂移。这对在搜索/推荐里用 RLVR 训练 LLM 答案/重排有直接意义：若用模型置信度做拒答或人工兜底路由，token 级校准会被表述变体破坏，语义级奖励能让置信度阈值更稳定可用。

Fengfei Yu, Ruijia Niu, Dongxia Wu, Yian Ma, Rose Yu

Falkor-IRAC: Graph-Constrained Generation for Verified Legal Reasoning in Indian Judicial AI

法律推理不是语义相似度检索：判决书编码了先例传播、程序状态转移、依法推断等约束性符号推理，向量 RAG 无法忠实表达，导致幻觉先例、过时法条引用、无依据推理链。Falkor-IRAC 提出图约束生成框架，将生成接地在 IRAC（Issue/Rule/Analysis/Conclusion）知识图的结构化推理上，并设有 Verifier Agent 校验引用、拒绝伪造引用。提出 graph-native 评估指标（引用接地准确率、路径有效率、幻觉先例率、冲突检测率）；当前为 51 篇最高法院判决的概念验证+500+ 篇 InIRAC 标注集，与向量 RAG 基线的定量对比留作未来工作。

INSIGHT对'先例/法条'这类强约束知识，图约束生成 + Verifier Agent 拒绝伪造引用，比纯向量 RAG 更能抑制幻觉——核心是把领域结构（IRAC）显式编码进知识图并在生成时约束。对社区搜索的启示：高可信场景（如医疗/法律/政策类 UGC 问答）可在 RAG 上叠加结构化校验 agent 做引用核验；但该文仅 PoC、无 baseline 对比，证据强度有限，落地前需补对照实验。

OpenAI and Dell partner to bring Codex to hybrid and on-premise enterprise environments

OpenAIDell

OpenAI 与 Dell 合作，把 Codex 编码 agent 带入混合云与本地（on-premise）企业环境，目标是让企业在自有数据与工作流内安全部署 AI 编码智能体。这是一条产业动向信号：deep research / coding agent 的落地正从纯云 API 走向需要数据驻留、合规与私有化部署的企业场景。

INSIGHTagentic 系统的产业落地瓶颈正从'模型能力'转向'部署形态'——数据驻留、本地化、合规是企业采用 coding/research agent 的关键门槛。对搜索/推荐团队的启示：评估引入 agent 能力时，私有化部署与数据边界是和效果同等重要的工程约束，选型时需把'能否 on-prem/混合部署'纳入考量。
