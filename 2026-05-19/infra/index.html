PSD: Pushing the Pareto Frontier of Diffusion LLMs via Parallel Speculative Decoding

扩散式大模型 (dLLM) 通过迭代去噪掩码序列生成文本，虽然每步能并行预测所有掩码位置，但去噪迭代次数多导致推理昂贵。降本可走两条路：空间上每步多解掩 (unmask) 多个 token，时间上把多步去噪折叠进一次验证调用。论文提出 Parallel Speculative Decoding (PSD)，一个 training-free 框架同时在两个轴上加速：用单次前向的置信度分数，按可配置的自适应解掩策略选位置，并在不增加额外模型调用的情况下构造多深度投机草稿；最后一次批量验证用分层接受 (hierarchical acceptance)，保留与更新预测一致的最深草稿。在三个 dLLM 上覆盖推理与代码生成任务验证。

02 3.70

Measuring Maximum Activations in Open Large Language Models

Baidu

激活值的动态范围是低比特量化、激活缩放与稳定推理的一阶约束。已有工作刻画 outlier feature 与 massive activation 时用的是 2024 年前 LLaMA 风格模型，下游激活量化栈一直沿用旧结论，未针对 post-LLaMA 开源模型潮重新审视。论文用统一管线 (5000 样本多领域语料、按家族定制 tokenization、对 embedding/hidden state/attention/MLP·MoE/SwiGLU gate/final norm 用相同 hook) 测量 27 个 checkpoint、8 个开源家族的全局与逐层最大激活，覆盖 dense、MoE、视觉语言、中间训练态与指令微调变体。发现全局最大值跨度接近四个数量级。

INSIGHT这是一份面向部署的测量基线，价值在统一管线下横向可比：把激活动态范围按家族/代际/训练阶段拆开看，揭示旧 outlier 结论在新开源模型上不再适用，跨度近四个数量级意味着固定 clip/scale 的激活量化配置在不同家族间会失效。对搜索/推荐工程的直接用途：在为线上 LLM reranker 或 query 模型选 W8A8/W4A8 量化方案前，应按目标模型家族重测激活最大值再定 scale，而不是套用社区默认值。

Luxuan Chen, Han Tian, Xinran Chen, Rui Kong, Fang Wang, Jiamin Chen, Yuchen Li, Jiashu Zhao 等 11 人

03 3.53

Always Learning, Always Mixing: Efficient and Simple Data Mixing All The Time

数据配比 (data mixing) 决定如何组合不同来源/类型的数据，贯穿语言模型训练全程：预训练阶段它决定模型质量，持续学习与适配阶段它决定保留与新学什么。已有方法只解决生命周期的单一阶段——有的依赖绑定单一训练阶段的小代理模型，有的假设固定领域集合，持续学习则缺乏原则性指导。论文主张数据配比本质是一个贯穿训练全程、反复出现的在线决策问题，需要统一解法。提出 OP-Mix (On-Policy Mix)，核心洞察是候选数据混合可通过对直接训练得到的低秩 adapter 做插值来廉价模拟，从而在预训练到持续适配的整个生命周期内统一决策配比。

INSIGHT把数据配比框成在线决策、并用低秩 adapter 插值廉价模拟候选混合，是相对依赖代理模型方法的关键区别——不必为每个阶段单独训代理模型即可估计某个混合的效果。对搜索/推荐训练的启示：在持续用新增 UGC 语料/点击日志增量适配检索或重排模型时，可借鉴 adapter 插值来低成本预估新旧领域配比对相关性与遗忘的影响，避免每次重训代理模型。

Michael Y. Hu, Apurva Gandhi, Kyunghyun Cho, Tal Linzen, Pratyusha Sharma

04 3.28

RoPE Distinguishes Neither Positions Nor Tokens in Long Contexts, Provably

Amazon

论文从理论上指出 Rotary Positional Embeddings (RoPE) 在 Transformer 长上下文模型中的内在局限。分析抽离上下文具体内容，只依赖上下文长度。证明随上下文变长，RoPE 注意力变得不可预测并失去两个关键性质：一是局部性偏置 (locality bias)——RoPE 不再更倾向近位置而非远位置；二是 token 相关性一致性——某个 key 向量在一个位置上注意力分数更高，在另一个位置上可能反而更低。两种失效的出错概率都趋近 0.5，与随机猜测无异。论文进一步证明，把 key token 移到不同位置、甚至换成不同 token，注意力分数都可能保持不变，说明 RoPE 无法区分位置也无法区分 token。

INSIGHT贡献是给出与内容无关、仅依赖长度的可证明结论：长上下文下 RoPE 同时丢失位置区分与 token 区分能力，失败概率趋近 0.5。这对长文档检索、长 query/长会话理解的部署是直接警示——单纯靠扩长上下文窗口而仍用原生 RoPE，远距离匹配信号在理论上不可靠。落地上更应优先考虑分段检索/重排或位置编码改造，而非盲目把整篇 UGC 长文塞进单次长上下文推理。

Yufeng Du, Phillip Harris, Minyang Tian, Eliu A Huerta, Srikanth Ronanki, Subendhu Rongali 等 8 人

05 3.20

Differentially Private Motif-Preserving Multi-modal Hashing

跨模态哈希把图像与文本编码成紧凑二值码以支持高效检索，SOTA 方法依赖由用户交互构建的语义相似图做监督，但这类图编码了敏感行为模式，易受链接重构攻击。已有隐私保护方法在图结构数据上失效：DP-SGD 把样本独立处理会破坏关系基元 (relational motif)；图合成方法在无标度网络上局部敏感度无界，hub 节点单边修改可使三角形计数变化达 O(N)，需注入过量噪声——论文称之为 Hubness Explosion。提出 DMP-MH，一个 Sanitize-then-Distill 框架，把隐私与表示学习解耦：先通过确定性裁剪节点度数来界定敏感度，给 L2 敏感度封顶，再做蒸馏。

INSIGHTHubness Explosion 的提出点明了在无标度交互图上做差分隐私的真实瓶颈——hub 节点导致单边敏感度无界。Sanitize-then-Distill 的设计把隐私预算花在度数裁剪界定敏感度上，再把净化后的结构蒸馏进表示，避免 DP-SGD 破坏 motif。对社区平台的启示：UGC 图文检索若用用户点击/交互图做监督，存在行为泄露风险；先按度数裁剪界定敏感度再蒸馏的思路，给“用交互图训哈希码又要可证明隐私”提供了可借鉴范式，但需图结构数据与 DP 工程，落地门槛较高。

Zehua Cheng, Wei Dai, Jiahao Sun

06 3.20

Dynamic Chunking for Diffusion Language Models

块离散扩散语言模型按固定大小的位置块自回归分解序列，把块内并行去噪与跨块条件解耦。论文指出这种刚性切分浪费了序列中已有的结构：按位置而非内容定义的块会把语义连贯的 token 拆开、把无关 token 凑在一起。提出 Dynamic Chunking Diffusion Model (DCDM)，用内容定义的语义块替代位置块。核心是 Chunking Attention——一个可微层，把 token 路由进 K 个由可学习子空间参数化的簇，并由扩散目标端到端塑形。得到的簇分配诱导出一个 chunk-causal 注意力掩码，离散扩散去噪器在其下按语义块自回归分解序列似然，严格泛化了固定位置块的设定。

INSIGHT把扩散语言模型的分块从位置驱动改为内容驱动，Chunking Attention 作为可微聚类层让分块由扩散目标端到端学习，是相对固定块基线的核心创新；chunk-causal 掩码严格泛化固定块，保证不劣化。对搜索的相关性偏弱（属 dLLM 架构研究），但若未来用扩散式生成做 query 扩展或摘要式重排，按语义块而非固定窗口分解可能改善长短文本混合 UGC 的生成质量，值得作为前沿架构跟踪。

Yichen Zhu, Xiaoming Shi, Peng Zhao, Weiyu Chen, Debing Zhang, James Kwok

paper.json: A Coordination Convention for LLM-Agent-Actionable Papers

LLM agent 已常常是论文的第一（有时唯一）读者，负责略读子论断、抽取复现步骤、泛化适用范围。标准散文体论文在这一角色下反复出错：子论断无法在子论文粒度被引用、把适用范围过度外推到论文未测试的范围、画图命令埋在代码库而非论文里。论文提出 paper.json——随 PDF 一起分发的伴随 JSON 文件，用轻量约定逐一应对：稳定的 claim ID (C1)、显式的 does-not-claim 列表 (C2)、逐图精确 shell 命令 (C3)、稳定的定义 ID (C5)；第五条约定 (C4) 认为最小可行合规——为已完成论文手写 JSON、不动人类可读正文——可在一小时内完成。C1/C2/C3/C5 是开放邀约：agent 读到合规论文即可据此精确引用与复现。

INSIGHT把“论文给 agent 读”这一新现实显式建模，用伴随 JSON 提供稳定 claim/定义 ID、显式不主张范围与逐图复现命令，针对的是 agent 误用论文的三类具体失败。实用性高在于零侵入、手写一小时可达最小合规。对搜索/推荐团队的间接启示：若内部用 agent 做文献调研或自动复现，给关键技术文档加一层结构化“可被 agent 精确引用/执行”的元数据，能显著降低 agent 过度外推与复现失败的概率。

Arquimedes Canedo
